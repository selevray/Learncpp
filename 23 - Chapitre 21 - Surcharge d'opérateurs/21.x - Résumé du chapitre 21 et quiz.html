21.x — Résumé du chapitre 21 et quiz

Dans ce chapitre, nous avons exploré les surcharges d'opérateurs, la surcharge des conversions de types (typecasts) ainsi que les sujets liés au constructeur de copie.

Résumé

La surcharge d'opérateurs est une variante de la surcharge de fonctions qui vous permet de surcharger les opérateurs pour vos classes. Lorsque vous surchargez des opérateurs, leur intention doit rester aussi proche que possible de leur intention d'origine. Si la signification d'un opérateur appliqué à une classe personnalisée n'est pas claire et intuitive, utilisez plutôt une fonction nommée.

Les opérateurs peuvent être surchargés sous la forme d'une fonction normale, d'une fonction amie (friend) ou d'une fonction membre. Les règles empiriques suivantes peuvent vous aider à déterminer la forme la mieux adaptée à une situation donnée :

  • Si vous surchargez l'affectation (=), l'indexation ([]), l'appel de fonction (()) ou la sélection de membre (->), faites-le sous forme de fonction membre.
  • Si vous surchargez un opérateur unaire, faites-le sous forme de fonction membre.
  • Si vous surchargez un opérateur binaire qui modifie son opérande de gauche (par exemple operator+=), faites-le sous forme de fonction membre si c'est possible.
  • Si vous surchargez un opérateur binaire qui ne modifie pas son opérande de gauche (par exemple operator+), faites-le sous forme de fonction normale ou de fonction amie.

Les conversions de types peuvent être surchargées pour fournir des fonctions de conversion, utilisables pour convertir explicitement ou implicitement votre classe en un autre type.

Un constructeur de copie est un type particulier de constructeur utilisé pour initialiser un objet à partir d'un autre objet du même type. Les constructeurs de copie sont utilisés pour l'initialisation directe/uniforme à partir d'un objet de même type, l'initialisation par copie (Fraction f = Fraction(5,3)), ainsi que lors du passage ou du renvoi d'un paramètre par valeur.

Si vous ne fournissez pas de constructeur de copie, le compilateur en crée un pour vous. Les constructeurs de copie fournis par le compilateur utilisent une initialisation membre à membre (memberwise), c'est-à-dire que chaque membre de la copie est initialisé à partir du membre correspondant de l'original. Le constructeur de copie peut être éliminé à des fins d'optimisation, même s'il a des effets de bord ; ne comptez donc pas sur son exécution effective.

Par défaut, les constructeurs sont considérés comme des constructeurs de conversion, ce qui signifie que le compilateur peut les utiliser pour convertir implicitement des objets d'autres types en objets de votre classe. Vous pouvez éviter cela en plaçant le mot-clé explicit devant votre constructeur. Vous pouvez également supprimer des fonctions dans votre classe, y compris le constructeur de copie et l'opérateur d'affectation surchargé, si vous le souhaitez. Cela provoquera une erreur de compilation si une fonction supprimée devait être appelée.

L'opérateur d'affectation peut être surchargé pour permettre l'affectation de votre classe. Si vous ne fournissez pas d'opérateur d'affectation surchargé, le compilateur en crée un pour vous. Les opérateurs d'affectation surchargés doivent toujours inclure une vérification d'auto-affectation (sauf si elle est gérée naturellement, ou si vous utilisez l'idiome copy and swap).

Les débutants confondent souvent le moment où l'on utilise l'opérateur d'affectation et le constructeur de copie, mais la règle est assez simple :

  • Si un nouvel objet doit être créé avant que la copie puisse avoir lieu, le constructeur de copie est utilisé (remarque : cela inclut le passage ou le renvoi d'objets par valeur).
  • Si aucun nouvel objet n'a besoin d'être créé avant la copie, l'opérateur d'affectation est utilisé.

Par défaut, le constructeur de copie et les opérateurs d'affectation fournis par le compilateur effectuent une initialisation ou une affectation membre à membre, qui est une copie superficielle (shallow copy). Si votre classe alloue dynamiquement de la mémoire, cela entraînera probablement des problèmes, car plusieurs objets finiront par pointer vers la même mémoire allouée. Dans ce cas, vous devrez définir explicitement ces fonctions afin d'effectuer une copie profonde (deep copy). Mieux encore, évitez de gérer vous-même la mémoire lorsque c'est possible et utilisez les classes de la bibliothèque standard.

#include <iostream>
#include <cstdint> // for fixed width integers

class Average
{
private:
    std::int32_t m_total{ 0 }; // the sum of all numbers we've seen so far
    int m_numbers{ 0 }; // the count of numbers we've seen so far

public:
    Average()
    {
    }

    friend std::ostream& operator<<(std::ostream& out, const Average& average)
    {
        // Handle case where we haven't seen any numbers yet
        if (average.m_numbers == 0)
        {
            out << 0;
            return out;
        }

        // Our average is the sum of the numbers we've seen divided by the count of the numbers we've seen
        // We need to remember to do a floating point division here, not an integer division
        out << static_cast<double>(average.m_total) / average.m_numbers;

        return out;
    }

    // Because operator+= modifies its left operand, we'll write it as a member
    Average& operator+=(std::int32_t num)
    {
        // Increment our total by the new number
        m_total += num;
        // And increase the count by 1
        ++m_numbers;

        // return *this in case someone wants to chain +='s together
        return *this;
    }
};

int main()
{
    Average avg{};
    std::cout << avg << '\n';

    avg += 4;
    std::cout << avg << '\n';

    avg += 8;
    std::cout << avg << '\n';

    avg += 24;
    std::cout << avg << '\n';

    avg += -10;
    std::cout << avg << '\n';

    (avg += 6) += 10; // 2 calls chained together
    std::cout << avg << '\n';

    Average copy{ avg };
    std::cout << copy << '\n';

    return 0;
}

b) Faut-il fournir un constructeur de copie ou un opérateur d'affectation défini par l'utilisateur pour cette classe ?

c) Pourquoi utiliser std::int32_t plutôt que int ?

Solution

int peut faire 16 bits sur certaines plateformes, ce qui signifierait que notre objet Average ne pourrait avoir un numérateur maximal que de 32 767. Utiliser std::int32_t garantit une valeur entière de 32 bits, ce qui nous donne une plage de valeurs bien plus grande.

#include <iostream>
#include <cassert> // for assert

class IntArray
{
private:
    int m_length{ 0 };
    int* m_array{ nullptr };

public:
    explicit IntArray(int length)
        : m_length{ length }
    {
        assert(length > 0 && "IntArray length should be a positive integer");

        m_array = new int[static_cast<std::size_t>(m_length)] {};
    }

    // Copy constructor that does a deep copy
    IntArray(const IntArray& array)
        : m_length{ array.m_length }
    {
        // Allocate a new array
        m_array = new int[static_cast<std::size_t>(m_length)] {};

        // Copy elements from original array to new array
        for (int count{ 0 }; count < array.m_length; ++count)
            m_array[count] = array.m_array[count];
    }

    ~IntArray()
    {
        delete[] m_array;
    }

    // If you're getting crazy values here you probably forgot to do a deep copy in your copy constructor
    friend std::ostream& operator<<(std::ostream& out, const IntArray& array)
    {
        for (int count{ 0 }; count < array.m_length; ++count)
        {
            out << array.m_array[count] << ' ';
        }
        return out;
    }

    int& operator[] (const int index)
    {
        assert(index >= 0);
        assert(index < m_length);
        return m_array[index];
    }

    // Assignment operator that does a deep copy
    IntArray& operator= (const IntArray& array)
    {
        // self-assignment guard
        if (this == &array)
            return *this;

        // If this array already exists, delete it so we don't leak memory
        delete[] m_array;

        m_length = array.m_length;

        // Allocate a new array
        m_array = new int[static_cast<std::size_t>(m_length)] {};

        // Copy elements from original array to new array
        for (int count{ 0 }; count < array.m_length; ++count)
            m_array[count] = array.m_array[count];

        return *this;
    }

};

IntArray fillArray()
{
    IntArray a(5);
    a[0] = 5;
    a[1] = 8;
    a[2] = 2;
    a[3] = 3;
    a[4] = 6;

    return a;
}

int main()
{
    IntArray a{ fillArray() };

    // If you're getting crazy values here you probably forgot to do a deep copy in your copy constructor
    std::cout << a << '\n';

    auto& ref{ a }; // we're using this reference to avoid compiler self-assignment errors
    a = ref;

    IntArray b(1);
    b = a;

    a[4] = 7; // change value in a, b should not change

    // If you're getting crazy values here you probably forgot to do self-assignment check
    // If b ends in 7, you probably forgot to do a deep copy in your copy assignment
    std::cout << b << '\n';

    return 0;
}

Question n° 4

Question bonus : celle-ci est un peu plus délicate.

Un nombre à virgule flottante est un nombre avec une partie décimale dont le nombre de chiffres après la virgule peut varier. Un nombre à virgule fixe est un nombre avec une partie fractionnaire dont le nombre de chiffres est fixe.

Dans ce quiz, nous allons écrire une classe qui implémente un nombre à virgule fixe avec deux chiffres fractionnaires (par exemple 12.34, 3.00 ou 1278.99). Supposons que la plage de la classe soit de -32768.99 à 32767.99, que la partie fractionnaire puisse contenir deux chiffres quelconques, que nous ne voulons pas d'erreurs de précision et que nous souhaitons économiser de l'espace.

> Étape n° 1

Quel(s) type(s) de membre(s) pensez-vous devoir utiliser pour implémenter notre nombre à virgule fixe avec 2 chiffres après la virgule ? (Assurez-vous de lire la réponse avant de passer aux questions suivantes.)

Solution

Il existe de nombreuses façons d'implémenter un nombre à virgule fixe. Comme un nombre à virgule fixe est essentiellement un cas particulier de nombre à virgule flottante (où le nombre de chiffres après la virgule est fixe au lieu de variable), utiliser un nombre à virgule flottante peut sembler un choix évident. Mais les nombres à virgule flottante posent des problèmes de précision. Avec un nombre fixe de chiffres décimaux, nous pouvons raisonnablement énumérer toutes les valeurs fractionnaires possibles (dans notre cas, de ,00 à ,99), donc utiliser un type de données qui pose des problèmes de précision n'est pas le meilleur choix.

Une meilleure solution consiste à utiliser un entier signé de 16 bits pour stocker la partie non fractionnaire du nombre, et un entier signé de 8 bits pour stocker la partie fractionnaire.

#include <cassert>
#include <cstdint> // for fixed width integers
#include <iostream>

class FixedPoint2
{
private:
    std::int16_t m_base{}; // here's our non-fractional part
    std::int8_t m_decimal{}; // here's our factional part

public:
    FixedPoint2(std::int16_t base = 0, std::int8_t decimal = 0)
        : m_base{ base }, m_decimal{ decimal }
    {
        // If either (or both) of the non-fractional and fractional part of the number are negative, the number should be treated as negative
        if (m_base < 0 || m_decimal < 0)
        {
            // Make sure base is negative
            if (m_base > 0)
                m_base = -m_base;
            // Make sure decimal is negative
            if (m_decimal > 0)
                m_decimal = -m_decimal;
        }
    }

    explicit operator double() const
    {
        return m_base + (static_cast<double>(m_decimal) / 100);
    }
};

// This doesn't require access to the internals of the class, so it can be defined outside the class
std::ostream& operator<<(std::ostream& out, const FixedPoint2& fp)
{
    out << static_cast<double>(fp);
    return out;
}

int main()
{
    FixedPoint2 a{ 34, 56 };
    std::cout << a << '\n';
    std::cout << static_cast<double>(a) << '\n';
    assert(static_cast<double>(a) == 34.56);

    FixedPoint2 b{ -2, 8 };
    assert(static_cast<double>(b) == -2.08);

    FixedPoint2 c{ 2, -8 };
    assert(static_cast<double>(c) == -2.08);

    FixedPoint2 d{ -2, -8 };
    assert(static_cast<double>(d) == -2.08);

    FixedPoint2 e{ 0, -5 };
    assert(static_cast<double>(e) == -0.05);

    FixedPoint2 f{ 0, 10 };
    assert(static_cast<double>(f) == 0.1);

    return 0;
}

{

    std::int8_t m_decimal{}; // here's our factional part

public:
    FixedPoint2(std::int16_t base = 0, std::int8_t decimal = 0)

Solution 
#include <cassert>
#include <cmath>
#include <cstdint> // for fixed width integers
#include <iostream>

class FixedPoint2
{
private:
    std::int16_t m_base{}; // here's our non-fractional part
    std::int8_t m_decimal{}; // here's our factional part

public:
    FixedPoint2(std::int16_t base = 0, std::int8_t decimal = 0)
        : m_base{ base }, m_decimal{ decimal }
    {
        // If either (or both) of the non-fractional and fractional part of the number are negative, the number should be treated as negative
        if (m_base < 0 || m_decimal < 0)
        {
            // Make sure base is negative
            if (m_base > 0)
                m_base = -m_base;
            // Make sure decimal is negative
            if (m_decimal > 0)
                m_decimal = -m_decimal;
        }

        // If decimal is out of bounds (in either direction),
        // adjust the decimal so it's in bounds,
        // and adjust base to account for the number of units removed from the decimal
        // h/t to reader David Pinheiro for simplifying this
        m_base += m_decimal / 100;    // integer division
        m_decimal = m_decimal % 100;  // integer remainder
    }

    // We'll delegate to the prior constructor so we don't have to duplicate the negative number and overflow handling logic
    FixedPoint2(double d) :
        FixedPoint2(
            static_cast<std::int16_t>(std::trunc(d)),
            static_cast<std::int8_t>(std::round(d * 100) - std::trunc(d) * 100)
        )
    {
    }

    explicit operator double() const
    {
        return m_base + (static_cast<double>(m_decimal) / 100);
    }
};

// This doesn't require access to the internals of the class, so it can be defined outside the class
std::ostream& operator<<(std::ostream& out, const FixedPoint2& fp)
{
    out << static_cast<double>(fp);
    return out;
}

int main()
{
    FixedPoint2 a{ 0.01 };
    std::cout << a << '\n';
    assert(static_cast<double>(a) == 0.01);

    FixedPoint2 b{ -0.01 };
    assert(static_cast<double>(b) == -0.01);

    FixedPoint2 c{ 1.9 }; // make sure we handle single digit decimal
    assert(static_cast<double>(c) == 1.9);

    FixedPoint2 d{ 5.01 }; // stored as 5.0099999... so we'll need to round this
    assert(static_cast<double>(d) == 5.01);

    FixedPoint2 e{ -5.01 }; // stored as -5.0099999... so we'll need to round this
    assert(static_cast<double>(e) == -5.01);

    // Handle case where the argument's decimal rounds to 100 (need to increase base by 1)
    FixedPoint2 f { 106.9978 }; // should be stored with base 107 and decimal 0
    assert(static_cast<double>(f) == 107.0);

    // Handle case where the argument's decimal rounds to -100 (need to decrease base by 1)
    FixedPoint2 g { -106.9978 }; // should be stored with base -107 and decimal 0
    assert(static_cast<double>(g) == -107.0);

    return 0;
}

Indice : additionnez vos deux FixedPoint2 en exploitant la conversion en double, additionnez les résultats, puis reconvertissez en FixedPoint2. Cela gère élégamment les dépassements décimaux.

Indice : pour operator>>, utilisez votre constructeur à partir d'un double pour créer un objet anonyme de type FixedPoint2, et affectez-le au paramètre de fonction FixedPoint2.

Solution 
#include <cassert>
#include <cmath>
#include <cstdint> // for fixed width integers
#include <iostream>

class FixedPoint2
{
private:
    std::int16_t m_base{}; // here's our non-fractional part
    std::int8_t m_decimal{}; // here's our factional part

public:
    FixedPoint2(std::int16_t base = 0, std::int8_t decimal = 0)
        : m_base{ base }, m_decimal{ decimal }
    {
        // If either (or both) of the non-fractional and fractional part of the number are negative, the number should be treated as negative
        if (m_base < 0 || m_decimal < 0)
        {
            // Make sure base is negative
            if (m_base > 0)
                m_base = -m_base;
            // Make sure decimal is negative
            if (m_decimal > 0)
                m_decimal = -m_decimal;
        }

        // If decimal is out of bounds (in either direction),
        // adjust the decimal so it's in bounds,
        // and adjust base to account for the number of units removed from the decimal
        // h/t to reader David Pinheiro for simplifying this
        m_base += m_decimal / 100;    // integer division
        m_decimal = m_decimal % 100;  // integer remainder
    }

    FixedPoint2(double d) :
        FixedPoint2(
            static_cast<std::int16_t>(std::trunc(d)),
            static_cast<std::int8_t>(std::round(d * 100) - std::trunc(d) * 100)
        )
    {
    }

    explicit operator double() const
    {
        return m_base + (static_cast<double>(m_decimal) / 100);
    }

    friend bool operator==(const FixedPoint2& fp1, const FixedPoint2& fp2)
    {
        return fp1.m_base == fp2.m_base && fp1.m_decimal == fp2.m_decimal;
    }

    FixedPoint2 operator-() const
    {
        // Cast to double, make the double negative, then convert back to FixedPoint2
        // h/t to reader EmtyC for this version
        return FixedPoint2{ -static_cast<double>(*this) };
    }
};

// This doesn't require access to the internals of the class, so it can be defined outside the class
std::ostream& operator<<(std::ostream& out, const FixedPoint2& fp)
{
    out << static_cast<double>(fp);
    return out;
}

std::istream& operator>>(std::istream& in, FixedPoint2& fp)
{
    double d{};
    in >> d;
    fp = FixedPoint2{ d };

    return in;
}

FixedPoint2 operator+(const FixedPoint2& fp1, const FixedPoint2& fp2)
{
    return FixedPoint2{ static_cast<double>(fp1) + static_cast<double>(fp2) };
}

int main()
{
    assert(FixedPoint2{ 0.75 } == FixedPoint2{ 0.75 });    // Test equality true
    assert(!(FixedPoint2{ 0.75 } == FixedPoint2{ 0.76 })); // Test equality false

    // Test additional cases -- h/t to reader Sharjeel Safdar for these test cases
    assert(FixedPoint2{ 0.75 } + FixedPoint2{ 1.23 } == FixedPoint2{ 1.98 });    // both positive, no decimal overflow
    assert(FixedPoint2{ 0.75 } + FixedPoint2{ 1.50 } == FixedPoint2{ 2.25 });    // both positive, with decimal overflow
    assert(FixedPoint2{ -0.75 } + FixedPoint2{ -1.23 } == FixedPoint2{ -1.98 }); // both negative, no decimal overflow
    assert(FixedPoint2{ -0.75 } + FixedPoint2{ -1.50 } == FixedPoint2{ -2.25 }); // both negative, with decimal overflow
    assert(FixedPoint2{ 0.75 } + FixedPoint2{ -1.23 } == FixedPoint2{ -0.48 });  // second negative, no decimal overflow
    assert(FixedPoint2{ 0.75 } + FixedPoint2{ -1.50 } == FixedPoint2{ -0.75 });  // second negative, possible decimal overflow
    assert(FixedPoint2{ -0.75 } + FixedPoint2{ 1.23 } == FixedPoint2{ 0.48 });   // first negative, no decimal overflow
    assert(FixedPoint2{ -0.75 } + FixedPoint2{ 1.50 } == FixedPoint2{ 0.75 });   // first negative, possible decimal overflow

    FixedPoint2 a{ -0.48 };
    assert(static_cast<double>(a) == -0.48);
    assert(static_cast<double>(-a) == 0.48);

    std::cout << "Enter a number: "; // enter 5.678
    std::cin >> a;
    std::cout << "You entered: " << a << '\n';

    return 0;
}
