21.14 — Surcharge d'opérateurs et modèles de fonctions

Dans la leçon 11.7 -- Instanciation des modèles de fonctions, nous avons vu comment le compilateur utilise les modèles de fonctions pour instancier des fonctions, lesquelles sont ensuite compilées. Nous avons également noté que ces fonctions peuvent ne pas compiler si le code du modèle tente une opération que le type effectif ne supporte pas (par exemple, ajouter la valeur entière 1 à un std::string).

Dans cette leçon, nous allons examiner quelques exemples où nos fonctions instanciées ne compilent pas parce que nos classes effectives ne supportent pas ces opérateurs, et montrer comment définir ces opérateurs pour que les fonctions instanciées compilent.

Opérateurs, appels de fonctions et modèles de fonctions

Commençons par créer une classe simple :

class Cents
{
private:
    int m_cents{};
public:
    Cents(int cents)
        : m_cents { cents }
    {
    }

    friend std::ostream& operator<< (std::ostream& ostr, const Cents& c)
    {
        ostr << c.m_cents;
        return ostr;
    }
};

et définissons un modèle de fonction max :

template <typename T>
const T& max(const T& x, const T& y)
{
    return (x < y) ? y : x;
}

Voyons maintenant ce qui se passe lorsque nous essayons d'appeler max() avec des objets de type Cents :

#include <iostream>

class Cents
{
private:
    int m_cents{};
public:
    Cents(int cents)
        : m_cents { cents }
    {
    }

    friend std::ostream& operator<< (std::ostream& ostr, const Cents& c)
    {
        ostr << c.m_cents;
        return ostr;
    }
};

template <typename T>
const T& max(const T& x, const T& y)
{
    return (x < y) ? y : x;
}

int main()
{
    Cents nickel{ 5 };
    Cents dime{ 10 };

    Cents bigger { max(nickel, dime) };
    std::cout << bigger << " is bigger\n";

    return 0;
}

C++ va créer une instance de template pour max() ressemblant à ceci :

template <>
const Cents& max(const Cents& x, const Cents& y)
{
    return (x < y) ? y : x;
}

Puis il essaiera de compiler cette fonction. Voyez-vous le problème ? C++ ne sait pas comment évaluer x < y lorsque x et y sont de type Cents ! Par conséquent, cela produira une erreur de compilation.

Pour contourner ce problème, il suffit de surcharger operator< pour toute classe avec laquelle nous souhaitons utiliser max :

#include <iostream>

class Cents
{
private:
    int m_cents {};
public:
    Cents(int cents)
        : m_cents { cents }
    {
    }

    friend bool operator< (const Cents& c1, const Cents& c2)
    {
        return (c1.m_cents < c2.m_cents);
    }

    friend std::ostream& operator<< (std::ostream& ostr, const Cents& c)
    {
        ostr << c.m_cents;
        return ostr;
    }
};

template <typename T>
const T& max(const T& x, const T& y)
{
    return (x < y) ? y : x;
}

int main()
{
    Cents nickel{ 5 };
    Cents dime { 10 };

    Cents bigger { max(nickel, dime) };
    std::cout << bigger << " is bigger\n";

    return 0;
}

Cela fonctionne comme prévu et affiche :


10 is bigger

Un autre exemple

Voyons un autre exemple de modèle de fonction qui ne fonctionne pas à cause d'opérateurs surchargés manquants.

La fonction modèle suivante calcule la moyenne de plusieurs objets stockés dans un tableau :

#include <iostream>

template <typename T>
T average(const T* myArray, int numValues)
{
    T sum { 0 };
    for (int count { 0 }; count < numValues; ++count)
        sum += myArray[count];

    sum /= numValues;
    return sum;
}

int main()
{
    int intArray[] { 5, 3, 2, 1, 4 };
    std::cout << average(intArray, 5) << '\n';

    double doubleArray[] { 3.12, 3.45, 9.23, 6.34 };
    std::cout << average(doubleArray, 4) << '\n';

    return 0;
}

Cela produit les valeurs :


3
5.535

Comme vous pouvez le voir, cela fonctionne très bien pour les types fondamentaux !

Voyons maintenant ce qui se passe lorsque nous appelons cette fonction avec notre classe Cents :

#include <iostream>

template <typename T>
T average(const T* myArray, int numValues)
{
    T sum { 0 };
    for (int count { 0 }; count < numValues; ++count)
        sum += myArray[count];

    sum /= numValues;
    return sum;
}

class Cents
{
private:
    int m_cents {};
public:
    Cents(int cents)
        : m_cents { cents }
    {
    }
};

int main()
{
    Cents centsArray[] { Cents { 5 }, Cents { 10 }, Cents { 15 }, Cents { 14 } };
    std::cout << average(centsArray, 4) << '\n';

    return 0;
}

Le compilateur s'affole et produit une multitude de messages d'erreur ! Le premier message d'erreur sera quelque chose comme :


error C2679: binary << : no operator found which takes a right-hand operand of type Cents (or there is no acceptable conversion)

Rappelez-vous que average() renvoie un objet Cents, et que nous essayons de l'envoyer vers std::cout avec operator<<. Or, nous n'avons pas encore défini operator<< pour notre classe Cents. Faisons-le :

#include <iostream>

template <typename T>
T average(const T* myArray, int numValues)
{
    T sum { 0 };
    for (int count { 0 }; count < numValues; ++count)
        sum += myArray[count];

    sum /= numValues;
    return sum;
}

class Cents
{
private:
    int m_cents {};
public:
    Cents(int cents)
        : m_cents { cents }
    {
    }

    friend std::ostream& operator<< (std::ostream& out, const Cents& cents)
    {
        out << cents.m_cents << " cents ";
        return out;
    }
};

int main()
{
    Cents centsArray[] { Cents { 5 }, Cents { 10 }, Cents { 15 }, Cents { 14 } };
    std::cout << average(centsArray, 4) << '\n';

    return 0;
}

Si nous compilons à nouveau, nous obtiendrons une autre erreur :

error C2676: binary += : Cents does not define this operator or a conversion to a type acceptable to the predefined operator

Cette erreur est en réalité causée par l'instance de modèle créée lors de l'appel à average(const Cents*, int). Rappelez-vous que lorsque nous appelons une fonction modèle, le compilateur « découpe » une copie de la fonction où les paramètres de type du modèle (les types substituts) ont été remplacés par les types effectifs de l'appel. Voici l'instance de modèle de average() lorsque T est un objet Cents :

template <>
Cents average(const Cents* myArray, int numValues)
{
    Cents sum { 0 };
    for (int count { 0 }; count < numValues; ++count)
        sum += myArray[count];

    sum /= numValues;
    return sum;
}

La raison de ce message d'erreur est la ligne suivante :

        sum += myArray[count];

Ici, sum est un objet Cents, mais nous n'avons pas défini operator+= pour les objets Cents ! Nous devons définir cette fonction pour que average() puisse fonctionner avec Cents. En regardant plus loin, nous voyons que average() utilise aussi operator/=, nous allons donc le définir également :

#include <iostream>

template <typename T>
T average(const T* myArray, int numValues)
{
    T sum { 0 };
    for (int count { 0 }; count < numValues; ++count)
        sum += myArray[count];

    sum /= numValues;
    return sum;
}

class Cents
{
private:
    int m_cents {};
public:
    Cents(int cents)
        : m_cents { cents }
    {
    }

    friend std::ostream& operator<< (std::ostream& out, const Cents& cents)
    {
        out << cents.m_cents << " cents ";
        return out;
    }

    Cents& operator+= (const Cents &cents)
    {
        m_cents += cents.m_cents;
        return *this;
    }

    Cents& operator/= (int x)
    {
        m_cents /= x;
        return *this;
    }
};

int main()
{
    Cents centsArray[] { Cents { 5 }, Cents { 10 }, Cents { 15 }, Cents { 14 } };
    std::cout << average(centsArray, 4) << '\n';

    return 0;
}

Enfin, notre code compile et s'exécute ! Voici le résultat :


11 cents

Notez que nous n'avons pas eu besoin de modifier average() pour qu'elle fonctionne avec des objets de type Cents. Nous avons simplement dû définir les opérateurs utilisés par average() pour la classe Cents, et le compilateur s'est chargé du reste !
