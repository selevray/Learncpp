21.2 — Surcharge des opérateurs arithmétiques à l'aide de fonctions amies

Certains des opérateurs les plus utilisés en C++ sont les opérateurs arithmétiques, à savoir l'opérateur d'addition (+), de soustraction (-), de multiplication (*) et de division (/). Notez que tous les opérateurs arithmétiques sont des opérateurs binaires, c'est-à-dire qu'ils prennent deux opérandes, un de chaque côté de l'opérateur. Ces quatre opérateurs se surchargent exactement de la même manière.

Il existe en fait trois façons de surcharger des opérateurs : la méthode par fonction membre, la méthode par fonction amie et la méthode par fonction ordinaire. Dans cette leçon, nous verrons la méthode par fonction amie (car elle est plus intuitive pour la plupart des opérateurs binaires). La leçon suivante traitera de la méthode par fonction ordinaire. Enfin, dans une leçon ultérieure de ce chapitre, nous aborderons la méthode par fonction membre. Nous résumerons également plus en détail quand utiliser chacune d'elles.

Surcharge des opérateurs à l'aide de fonctions amies

Considérez la classe suivante :

class Cents
{
private:
    int m_cents {};

public:
    Cents(int cents) : m_cents{ cents } { }
    int getCents() const { return m_cents; }
};

L'exemple suivant montre comment surcharger l'opérateur d'addition (+) pour additionner deux objets « Cents » :

#include <iostream>

class Cents
{
private:
    int m_cents {};

public:
    Cents(int cents) : m_cents{ cents } { }

    // addition Cents + Cents à l'aide d'une fonction amie
    friend Cents operator+(const Cents& c1, const Cents& c2);

    int getCents() const { return m_cents; }
};

// note : cette fonction n'est pas une fonction membre !
Cents operator+(const Cents& c1, const Cents& c2)
{
    // utilise le constructeur de Cents et operator+(int, int)
    // nous pouvons accéder directement à m_cents car il s'agit d'une fonction amie
    return c1.m_cents + c2.m_cents;
}

int main()
{
    Cents cents1{ 6 };
    Cents cents2{ 8 };
    Cents centsSum{ cents1 + cents2 };
    std::cout << "I have " << centsSum.getCents() << " cents.\n";

    return 0;
}

Ce programme produit le résultat suivant :


I have 14 cents.

Surcharger l'opérateur d'addition (+) revient simplement à déclarer une fonction nommée operator+, à lui donner deux paramètres du type des opérandes à additionner, à choisir un type de retour approprié, puis à écrire la fonction.

Dans le cas de notre objet Cents, l'implémentation de operator+() est très simple. Tout d'abord, les types des paramètres : dans cette version de operator+, nous allons additionner deux objets Cents, donc notre fonction prend deux objets de type Cents. Ensuite, le type de retour : notre operator+ renvoie un résultat de type Cents, c'est donc notre type de retour.

Enfin, l'implémentation : pour additionner deux objets Cents, il faut réellement additionner le membre m_cents de chacun d'eux. Comme notre fonction operator+() surchargée est une amie de la classe, nous pouvons accéder directement au membre m_cents de ses paramètres. De plus, comme m_cents est un entier, et que C++ sait additionner des entiers à l'aide de la version intégrée de l'opérateur plus pour les opérandes entiers, nous pouvons simplement utiliser l'opérateur + pour effectuer l'addition.

La surcharge de l'opérateur de soustraction (-) est tout aussi simple :

#include <iostream>

class Cents
{
private:
    int m_cents {};

public:
    explicit Cents(int cents) : m_cents{ cents } { }

    // addition Cents + Cents à l'aide d'une fonction amie
    friend Cents operator+(const Cents& c1, const Cents& c2);

    // soustraction Cents - Cents à l'aide d'une fonction amie
    friend Cents operator-(const Cents& c1, const Cents& c2);

    int getCents() const { return m_cents; }
};

// note : cette fonction n'est pas une fonction membre !
Cents operator+(const Cents& c1, const Cents& c2)
{
    // utilise le constructeur de Cents et operator+(int, int)
    // nous pouvons accéder directement à m_cents car il s'agit d'une fonction amie
    return Cents { c1.m_cents + c2.m_cents };
}

// note : cette fonction n'est pas une fonction membre !
Cents operator-(const Cents& c1, const Cents& c2)
{
    // utilise le constructeur de Cents et operator-(int, int)
    // nous pouvons accéder directement à m_cents car il s'agit d'une fonction amie
    return Cents { c1.m_cents - c2.m_cents };
}

int main()
{
    Cents cents1{ 6 };
    Cents cents2{ 2 };
    Cents centsSum{ cents1 - cents2 };
    std::cout << "I have " << centsSum.getCents() << " cents.\n";

    return 0;
}

Surcharger l'opérateur de multiplication (*) et l'opérateur de division (/) est aussi simple que de définir respectivement les fonctions operator* et operator/.

Les fonctions amies peuvent être définies à l'intérieur de la classe

Bien que les fonctions amies ne soient pas membres de la classe, elles peuvent tout de même être définies à l'intérieur de celle-ci si on le souhaite :

#include <iostream>

class Cents
{
private:
    int m_cents {};

public:
    explicit Cents(int cents) : m_cents{ cents } { }

    // addition Cents + Cents à l'aide d'une fonction amie
        // Cette fonction n'est pas considérée comme un membre de la classe, bien que sa définition soit à l'intérieur de celle-ci
    friend Cents operator+(const Cents& c1, const Cents& c2)
    {
        // utilise le constructeur de Cents et operator+(int, int)
        // nous pouvons accéder directement à m_cents car il s'agit d'une fonction amie
        return Cents { c1.m_cents + c2.m_cents };
    }

    int getCents() const { return m_cents; }
};

int main()
{
    Cents cents1{ 6 };
    Cents cents2{ 8 };
    Cents centsSum{ cents1 + cents2 };
    std::cout << "I have " << centsSum.getCents() << " cents.\n";

    return 0;
}

Cette approche convient pour les opérateurs surchargés dont l'implémentation est triviale.

Surcharge des opérateurs pour des opérandes de types différents

Il arrive souvent que vous souhaitiez que vos opérateurs surchargés fonctionnent avec des opérandes de types différents. Par exemple, si nous avons Cents(4), nous pouvons vouloir y ajouter l'entier 6 pour obtenir Cents(10).

Lorsque C++ évalue l'expression x + y, x devient le premier paramètre et y le second. Lorsque x et y ont le même type, il importe peu d'écrire x + y ou y + x : dans les deux cas, la même version de operator+ est appelée. En revanche, lorsque les opérandes ont des types différents, x + y n'appelle pas la même fonction que y + x.

Par exemple, Cents(4) + 6 appelle operator+(Cents, int), tandis que 6 + Cents(4) appelle operator+(int, Cents). Par conséquent, lorsque nous surchargeons des opérateurs binaires pour des opérandes de types différents, nous devons en réalité écrire deux fonctions, une pour chaque cas. Voici un exemple :

#include <iostream>

class Cents
{
private:
    int m_cents {};

public:
    explicit Cents(int cents) : m_cents{ cents } { }

    // addition Cents + int à l'aide d'une fonction amie
    friend Cents operator+(const Cents& c1, int value);

    // addition int + Cents à l'aide d'une fonction amie
    friend Cents operator+(int value, const Cents& c1);


    int getCents() const { return m_cents; }
};

// note : cette fonction n'est pas une fonction membre !
Cents operator+(const Cents& c1, int value)
{
    // utilise le constructeur de Cents et operator+(int, int)
    // nous pouvons accéder directement à m_cents car il s'agit d'une fonction amie
    return Cents { c1.m_cents + value };
}

// note : cette fonction n'est pas une fonction membre !
Cents operator+(int value, const Cents& c1)
{
    // utilise le constructeur de Cents et operator+(int, int)
    // nous pouvons accéder directement à m_cents car il s'agit d'une fonction amie
    return Cents { c1.m_cents + value };
}

int main()
{
    Cents c1{ Cents{ 4 } + 6 };
    Cents c2{ 6 + Cents{ 4 } };

    std::cout << "I have " << c1.getCents() << " cents.\n";
    std::cout << "I have " << c2.getCents() << " cents.\n";

    return 0;
}

Notez que les deux fonctions surchargées ont la même implémentation : elles font la même chose, elles reçoivent simplement leurs paramètres dans un ordre différent.

Un autre exemple

Examinons un autre exemple :

#include <iostream>

class MinMax
{
private:
    int m_min {}; // La plus petite valeur vue jusqu'à présent
    int m_max {}; // La plus grande valeur vue jusqu'à présent

public:
    MinMax(int min, int max)
        : m_min { min }, m_max { max }
    { }

    int getMin() const { return m_min; }
    int getMax() const { return m_max; }

    friend MinMax operator+(const MinMax& m1, const MinMax& m2);
    friend MinMax operator+(const MinMax& m, int value);
    friend MinMax operator+(int value, const MinMax& m);
};

MinMax operator+(const MinMax& m1, const MinMax& m2)
{
    // Obtient la plus petite valeur vue dans m1 et m2
    int min{ m1.m_min < m2.m_min ? m1.m_min : m2.m_min };

    // Obtient la plus grande valeur vue dans m1 et m2
    int max{ m1.m_max > m2.m_max ? m1.m_max : m2.m_max };

    return MinMax { min, max };
}

MinMax operator+(const MinMax& m, int value)
{
    // Obtient la plus petite valeur vue dans m et value
    int min{ m.m_min < value ? m.m_min : value };

    // Obtient la plus grande valeur vue dans m et value
    int max{ m.m_max > value ? m.m_max : value };

    return MinMax { min, max };
}

MinMax operator+(int value, const MinMax& m)
{
    // appelle operator+(MinMax, int)
    return m + value;
}

int main()
{
    MinMax m1{ 10, 15 };
    MinMax m2{ 8, 11 };
    MinMax m3{ 3, 12 };

    MinMax mFinal{ m1 + m2 + 5 + 8 + m3 + 16 };

    std::cout << "Result: (" << mFinal.getMin() << ", " <<
        mFinal.getMax() << ")\n";

    return 0;
}

La classe MinMax garde la trace des valeurs minimale et maximale vues jusqu'à présent. Nous avons surchargé l'opérateur + à 3 reprises, afin de pouvoir additionner deux objets MinMax ou ajouter des entiers à des objets MinMax.

Cet exemple produit le résultat suivant :


Result: (3, 16)

Vous remarquerez qu'il s'agit des valeurs minimale et maximale que nous avons ajoutées à mFinal.

Expliquons plus en détail comment s'évalue l'expression « MinMax mFinal { m1 + m2 + 5 + 8 + m3 + 16 } ». Rappelez-vous que operator+ s'évalue de gauche à droite, donc m1 + m2 s'évalue en premier. Cela correspond à un appel à operator+(m1, m2), qui produit la valeur de retour MinMax(8, 15). Vient ensuite MinMax(8, 15) + 5, qui correspond à un appel à operator+(MinMax(8, 15), 5) et produit MinMax(5, 15). Puis MinMax(5, 15) + 8 s'évalue de la même manière pour produire MinMax(5, 15). Ensuite, MinMax(5, 15) + m3 donne MinMax(3, 15). Enfin, MinMax(3, 15) + 16 donne MinMax(3, 16). Ce résultat final sert alors à initialiser mFinal.

Autrement dit, cette expression s'évalue comme « MinMax mFinal = (((((m1 + m2) + 5) + 8) + m3) + 16) », chaque opération successive renvoyant un objet MinMax qui devient l'opérande de gauche de l'opérateur suivant.

Implémenter des opérateurs à l'aide d'autres opérateurs

Dans l'exemple ci-dessus, notez que nous avons défini operator+(int, MinMax) en appelant operator+(MinMax, int), qui produit le même résultat. Cela nous permet de réduire l'implémentation de operator+(int, MinMax) à une seule ligne, ce qui rend le code plus facile à maintenir en limitant la redondance et en simplifiant la compréhension de la fonction.

Il est souvent possible de définir des opérateurs surchargés en appelant d'autres opérateurs surchargés. Vous devriez le faire lorsque cela produit un code plus simple. Lorsque l'implémentation est triviale (par exemple une seule ligne), il peut ou non être utile de procéder ainsi.

class Fraction
{
private:
    int m_numerator { 0 };
    int m_denominator { 1 };

public:
    explicit Fraction(int numerator, int denominator=1)
        : m_numerator{numerator}, m_denominator{denominator}

Nous conservons

le constructeur Fraction(int, int) non explicit est utilisé pour construire une nouvelle Fraction à partir de 2. Cette nouvelle Fraction est ensuite multipliée par f2 à l'aide de l'opérateur Fraction * Fraction.

Comme cela nécessite de convertir 2 en Fraction, c'est légèrement plus lent que l'implémentation avec des surcharges spécifiques pour la multiplication par un entier.

e) Pour aller plus loin : la fraction 2/4 est égale à 1/2, mais 2/4 n'est pas réduite à sa plus simple expression. Nous pouvons réduire n'importe quelle fraction à sa forme irréductible en calculant le plus grand commun diviseur (PGCD) du numérateur et du dénominateur, puis en divisant le numérateur et le dénominateur par ce PGCD.

std::gcd() a été ajoutée à la bibliothèque standard en C++17 (dans l'en-tête <numeric>).

Si vous utilisez un compilateur plus ancien, vous pouvez utiliser cette fonction pour calculer le PGCD :

#include <cmath> // pour std::abs

int gcd(int a, int b) {
    return (b == 0) ? std::abs(a) : gcd(b, a % b);
}

Solution 
#include <iostream>
#include <numeric> // pour std::gcd

// Cette version de la classe Fraction réduit automatiquement les fractions
class Fraction
{
private:
    int m_numerator{ 0 };
    int m_denominator{ 1 };

public:
    explicit Fraction(int numerator, int denominator = 1)
        : m_numerator{ numerator }, m_denominator{ denominator }
    {
        // Nous plaçons reduce() dans le constructeur pour garantir que toute fraction créée soit réduite !
        // Comme tous les opérateurs surchargés créent de nouvelles Fraction, nous pouvons garantir l'appel ici
        reduce();
    }

    void reduce()
    {
        int gcd{ std::gcd(m_numerator, m_denominator) };
        if (gcd) // S'assure de ne pas diviser par 0
        {
            m_numerator /= gcd;
            m_denominator /= gcd;
        }
    }

    friend Fraction operator*(const Fraction& f1, const Fraction& f2);
    friend Fraction operator*(const Fraction& f1, int value);
    friend Fraction operator*(int value, const Fraction& f1);

    void print() const
    {
        std::cout << m_numerator << '/' << m_denominator << '\n';
    }
};

Fraction operator*(const Fraction& f1, const Fraction& f2)
{
    return Fraction { f1.m_numerator * f2.m_numerator, f1.m_denominator * f2.m_denominator };
}

Fraction operator*(const Fraction& f1, int value)
{
    return Fraction { f1.m_numerator * value, f1.m_denominator };
}

Fraction operator*(int value, const Fraction& f1)
{
    return Fraction { f1 * value };
}

int main()
{
    Fraction f1{ 2, 5 };
    f1.print();

    Fraction f2{ 3, 8 };
    f2.print();

    Fraction f3{ f1 * f2 };
    f3.print();

    Fraction f4{ f1 * 2 };
    f4.print();

    Fraction f5{ 2 * f2 };
    f5.print();

    Fraction f6{ Fraction{1, 2} * Fraction{2, 3} * Fraction{3, 4} };
    f6.print();

    Fraction f7{ 0, 6 };
    f7.print();

    return 0;
}
