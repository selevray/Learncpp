21.7 — Surcharge des opérateurs de comparaison

Dans la leçon 6.7 -- Relational operators and floating point comparisons, nous avons étudié les six opérateurs de comparaison. Surcharger ces opérateurs de comparaison est relativement simple (vous avez vu ce que j'ai fait ici ?), car ils suivent les mêmes schémas que ceux que nous avons déjà vus pour surcharger d'autres opérateurs.

Comme les opérateurs de comparaison sont tous des opérateurs binaires qui ne modifient pas leur opérande de gauche, nous allons faire de nos opérateurs de comparaison surchargés des fonctions amies (friend).

Voici un exemple de classe Car avec des opérateurs operator== et operator!= surchargés.

#include <iostream>
#include <string>
#include <string_view>

class Car
{
private:
    std::string m_make;
    std::string m_model;

public:
    Car(std::string_view make, std::string_view model)
        : m_make{ make }, m_model{ model }
    {
    }

    friend bool operator== (const Car& c1, const Car& c2);
    friend bool operator!= (const Car& c1, const Car& c2);
};

bool operator== (const Car& c1, const Car& c2)
{
    return (c1.m_make == c2.m_make &&
            c1.m_model == c2.m_model);
}

bool operator!= (const Car& c1, const Car& c2)
{
    return (c1.m_make != c2.m_make ||
            c1.m_model != c2.m_model);
}

int main()
{
    Car corolla{ "Toyota", "Corolla" };
    Car camry{ "Toyota", "Camry" };

    if (corolla == camry)
        std::cout << "a Corolla and Camry are the same.\n";

    if (corolla != camry)
        std::cout << "a Corolla and Camry are not the same.\n";

    return 0;
}

Le code ici devrait être simple.

Qu'en est-il de operator< et operator> ? Que signifierait qu'une Car soit plus grande ou plus petite qu'une autre Car ? Nous ne pensons généralement pas les voitures de cette façon. Comme les résultats de operator< et operator> ne seraient pas immédiatement intuitifs, il vaut peut-être mieux ne pas définir ces opérateurs.

Bonne pratique

Ne définissez que les opérateurs surchargés qui ont un sens intuitif pour votre classe.

Cependant, il existe une exception courante à la recommandation ci-dessus. Que faire si nous voulons trier une liste de Car ? Dans ce cas, nous pourrions vouloir surcharger les opérateurs de comparaison pour qu'ils renvoient le ou les membres selon lesquels vous êtes le plus susceptible de vouloir trier. Par exemple, un operator< surchargé pour Car pourrait trier selon la marque puis le modèle, par ordre alphabétique.

Certaines classes conteneurs de la bibliothèque standard (classes qui contiennent des ensembles d'autres classes) exigent un operator< surchargé afin de pouvoir garder leurs éléments triés.

Voici un autre exemple surchargeant les 6 opérateurs de comparaison logiques :

#include <iostream>

class Cents
{
private:
    int m_cents;

public:
    Cents(int cents)
    : m_cents{ cents }
    {}

    friend bool operator== (const Cents& c1, const Cents& c2);
    friend bool operator!= (const Cents& c1, const Cents& c2);

    friend bool operator< (const Cents& c1, const Cents& c2);
    friend bool operator> (const Cents& c1, const Cents& c2);

    friend bool operator<= (const Cents& c1, const Cents& c2);
    friend bool operator>= (const Cents& c1, const Cents& c2);
};

bool operator== (const Cents& c1, const Cents& c2)
{
    return c1.m_cents == c2.m_cents;
}

bool operator!= (const Cents& c1, const Cents& c2)
{
    return c1.m_cents != c2.m_cents;
}

bool operator> (const Cents& c1, const Cents& c2)
{
    return c1.m_cents > c2.m_cents;
}

bool operator< (const Cents& c1, const Cents& c2)
{
    return c1.m_cents < c2.m_cents;
}

bool operator<= (const Cents& c1, const Cents& c2)
{
    return c1.m_cents <= c2.m_cents;
}

bool operator>= (const Cents& c1, const Cents& c2)
{
    return c1.m_cents >= c2.m_cents;
}

int main()
{
    Cents dime{ 10 };
    Cents nickel{ 5 };

    if (nickel > dime)
        std::cout << "a nickel is greater than a dime.\n";
    if (nickel >= dime)
        std::cout << "a nickel is greater than or equal to a dime.\n";
    if (nickel < dime)
        std::cout << "a dime is greater than a nickel.\n";
    if (nickel <= dime)
        std::cout << "a dime is greater than or equal to a nickel.\n";
    if (nickel == dime)
        std::cout << "a dime is equal to a nickel.\n";
    if (nickel != dime)
        std::cout << "a dime is not equal to a nickel.\n";

    return 0;
}

Ceci est également assez simple.

Minimiser la redondance des comparaisons

Dans l'exemple ci-dessus, remarquez à quel point l'implémentation de chacun des opérateurs de comparaison surchargés est semblable. Les opérateurs de comparaison surchargés tendent à présenter un haut degré de redondance, et plus l'implémentation est complexe, plus la redondance est importante.

Heureusement, beaucoup d'opérateurs de comparaison peuvent être implémentés à l'aide des autres opérateurs de comparaison :

  • operator!= peut être implémenté comme !(operator==)
  • operator> peut être implémenté comme operator< avec l'ordre des paramètres inversé
  • operator>= peut être implémenté comme !(operator<)
  • operator<= peut être implémenté comme !(operator>)

Cela signifie que nous n'avons besoin d'implémenter la logique que pour operator== et operator<, et que les quatre autres opérateurs de comparaison peuvent être définis à partir de ces deux-là ! Voici un exemple Cents mis à jour qui l'illustre :

#include <iostream>

class Cents
{
private:
    int m_cents;

public:
    Cents(int cents)
        : m_cents{ cents }
    {}

    friend bool operator== (const Cents& c1, const Cents& c2) { return c1.m_cents == c2.m_cents; }
    friend bool operator!= (const Cents& c1, const Cents& c2) { return !(operator==(c1, c2)); }

    friend bool operator< (const Cents& c1, const Cents& c2) { return c1.m_cents < c2.m_cents; }
    friend bool operator> (const Cents& c1, const Cents& c2) { return operator<(c2, c1); }

    friend bool operator<= (const Cents& c1, const Cents& c2) { return !(operator>(c1, c2)); }
    friend bool operator>= (const Cents& c1, const Cents& c2) { return !(operator<(c1, c2)); }

};

int main()
{
    Cents dime{ 10 };
    Cents nickel{ 5 };

    if (nickel > dime)
        std::cout << "a nickel is greater than a dime.\n";
    if (nickel >= dime)
        std::cout << "a nickel is greater than or equal to a dime.\n";
    if (nickel < dime)
        std::cout << "a dime is greater than a nickel.\n";
    if (nickel <= dime)
        std::cout << "a dime is greater than or equal to a nickel.\n";
    if (nickel == dime)
        std::cout << "a dime is equal to a nickel.\n";
    if (nickel != dime)
        std::cout << "a dime is not equal to a nickel.\n";

    return 0;
}

Ainsi, si nous devons un jour modifier quelque chose, nous n'avons besoin de mettre à jour que operator== et operator< au lieu des six opérateurs de comparaison !

L'opérateur spatial <=> (C++20)

C++20 introduit l'opérateur spatial (« spaceship operator ») (operator<=>), qui nous permet de réduire à 2 au maximum, et parfois à 1 seule, le nombre de fonctions de comparaison à écrire !

Solution 
#include <algorithm>
#include <iostream>
#include <string>
#include <string_view>
#include <vector>

class Car
{
private:
    std::string m_make;
    std::string m_model;

public:
    Car(std::string_view make, std::string_view model)
        : m_make{ make }, m_model{ model }
    {
    }

    friend bool operator==(const Car& c1, const Car& c2);
    friend bool operator!=(const Car& c1, const Car& c2);

    friend std::ostream& operator<<(std::ostream& out, const Car& c)
    {
        out << '(' << c.m_make << ", " << c.m_model << ')';
        return out;
    }

    // h/t to reader Olivier for the initial version of the function
    friend bool operator<(const Car& c1, const Car& c2)
    {
        if (c1.m_make != c2.m_make) // If the car is not the same make...
            return c1.m_make < c2.m_make; // ...then compare the make

        return c1.m_model < c2.m_model; // otherwise compare the model
    }
};

bool operator==(const Car& c1, const Car& c2)
{
    return c1.m_make == c2.m_make && c1.m_model == c2.m_model;
}

bool operator!= (const Car& c1, const Car& c2)
{
    return !operator==(c1, c2);
}

int main()
{
    std::vector<Car> cars{
      { "Toyota", "Corolla" },
      { "Honda", "Accord" },
      { "Toyota", "Camry" },
      { "Honda", "Civic" }
    };

    std::sort(cars.begin(), cars.end()); // requires an overloaded Car::operator<

    for (const auto& car : cars)
        std::cout << car << '\n'; // requires an overloaded Car::operator<<

    return 0;
}
