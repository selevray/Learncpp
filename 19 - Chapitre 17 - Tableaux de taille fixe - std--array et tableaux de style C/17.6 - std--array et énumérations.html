17.6 — std::array et énumérations

Dans la leçon 16.9 -- Indexation des tableaux et longueur à l'aide d'énumérateurs, nous avons abordé les tableaux et les énumérations.

Maintenant que nous disposons de constexpr std::array dans notre boîte à outils, nous allons poursuivre cette discussion et présenter quelques astuces supplémentaires.

Utiliser static_assert pour garantir le nombre correct d'initialiseurs de tableau

Lors de l'initialisation d'un constexpr std::array avec CTAD, le compilateur déduit la taille du tableau à partir du nombre d'initialiseurs. Si moins d'initialiseurs que prévu sont fournis, le tableau sera plus court que prévu, et l'indexer peut conduire à un comportement indéfini.

Par exemple :

#include <array>
#include <iostream>

enum StudentNames
{
    kenny, // 0
    kyle, // 1
    stan, // 2
    butters, // 3
    cartman, // 4
    max_students // 5
};

int main()
{
    constexpr std::array testScores { 78, 94, 66, 77 }; // oups, seulement 4 valeurs

    std::cout << "Cartman a obtenu une note de " << testScores[StudentNames::cartman] << '\n'; // comportement indéfini dû à un indice invalide

    return 0;
}

Chaque fois que le nombre d'initialiseurs d'un constexpr std::array peut être raisonnablement vérifié, vous pouvez le faire à l'aide d'un static_assert :

#include <array>
#include <iostream>

enum StudentNames
{
    kenny, // 0
    kyle, // 1
    stan, // 2
    butters, // 3
    cartman, // 4
    max_students // 5
};

int main()
{
    constexpr std::array testScores { 78, 94, 66, 77 };

    // Vérifier que le nombre de notes est identique au nombre d'élèves
    static_assert(std::size(testScores) == max_students); // erreur de compilation : la condition de static_assert a échoué

    std::cout << "Cartman a obtenu une note de " << testScores[StudentNames::cartman] << '\n';

    return 0;
}

Ainsi, si vous ajoutez plus tard un nouvel énumérateur mais oubliez d'ajouter l'initialiseur correspondant à testScores, le programme ne compilera pas.

Vous pouvez également utiliser un static_assert pour vérifier que deux constexpr std::array différents ont la même longueur.

Utiliser des tableaux constexpr pour une meilleure entrée et sortie des énumérations

Dans la leçon 13.5 -- Introduction à la surcharge des opérateurs d'entrée et de sortie, nous avons présenté plusieurs façons d'afficher et de saisir les noms des énumérateurs. Pour cela, nous disposions de fonctions utilitaires qui convertissaient un énumérateur en chaîne et inversement. Chacune de ces fonctions possédait son propre jeu (dupliqué) de littéraux de chaîne, et nous devions explicitement coder la logique de vérification de chacun :

constexpr std::string_view getPetName(Pet pet)
{
    switch (pet)
    {
    case cat:   return "cat";
    case dog:   return "dog";
    case pig:   return "pig";
    case whale: return "whale";
    default:    return "???";
    }
}

constexpr std::optional<Pet> getPetFromString(std::string_view sv)
{
    if (sv == "cat")   return cat;
    if (sv == "dog")   return dog;
    if (sv == "pig")   return pig;
    if (sv == "whale") return whale;

    return {};
}

Cela signifie que si nous ajoutons un nouvel énumérateur, nous devrons penser à mettre à jour ces fonctions.

Améliorons un peu ces fonctions. Lorsque les valeurs de nos énumérateurs commencent à 0 et se suivent séquentiellement (ce qui est vrai pour la plupart des énumérations), nous pouvons utiliser un tableau pour contenir le nom de chaque énumérateur.

Cela nous permet de faire deux choses :

  1. Indexer le tableau avec la valeur de l'énumérateur pour obtenir son nom.
  2. Utiliser une boucle pour parcourir tous les noms et associer un nom à l'énumérateur correspondant grâce à son indice.
#include <array>
#include <iostream>
#include <string>
#include <string_view>

namespace Color
{
    enum Type
    {
        black,
        red,
        blue,
        max_colors
    };

    // Utiliser le suffixe sv pour que std::array déduise le type std::string_view
    using namespace std::string_view_literals; // pour le suffixe sv
    constexpr std::array colorName { "black"sv, "red"sv, "blue"sv };

    // Vérifier que nous avons défini des chaînes pour toutes nos couleurs
    static_assert(std::size(colorName) == max_colors);
};

constexpr std::string_view getColorName(Color::Type color)
{
    // Nous pouvons indexer le tableau avec l'énumérateur pour obtenir son nom
    return Color::colorName[static_cast<std::size_t>(color)];
}

// Apprendre à operator<< à afficher une Color
// std::ostream est le type de std::cout
// Le type de retour et le type du paramètre sont des références (pour éviter des copies) !
std::ostream& operator<<(std::ostream& out, Color::Type color)
{
    return out << getColorName(color);
}

// Apprendre à operator>> à lire une Color par son nom
// Nous passons color par référence non constante pour que la fonction puisse modifier sa valeur
std::istream& operator>> (std::istream& in, Color::Type& color)
{
    std::string input {};
    std::getline(in >> std::ws, input);

    // Parcourir la liste des noms pour voir si nous trouvons un nom correspondant
    for (std::size_t index=0; index < Color::colorName.size(); ++index)
    {
        if (input == Color::colorName[index])
        {
            // Si nous trouvons un nom correspondant, nous pouvons obtenir la valeur de l'énumérateur à partir de son indice
            color = static_cast<Color::Type>(index);
            return in;
        }
    }

    // Nous n'avons trouvé aucune correspondance, donc l'entrée était invalide
    // nous mettons donc le flux d'entrée dans l'état d'échec
    in.setstate(std::ios_base::failbit);

    // En cas d'échec d'extraction, operator>> initialise à zéro les types fondamentaux
    // Décommentez la ligne suivante pour que cet opérateur fasse de même
    // color = {};
    return in;
}

int main()
{
    auto shirt{ Color::blue };
    std::cout << "Votre chemise est " << shirt << '\n';

    std::cout << "Entrez une nouvelle couleur : ";
    std::cin >> shirt;
    if (!std::cin)
        std::cout << "Invalide\n";
    else
        std::cout << "Votre chemise est maintenant " << shirt << '\n';

    return 0;
}

Ce programme affiche :


Votre chemise est blue
Entrez une nouvelle couleur : red
Votre chemise est maintenant red

Boucles for basées sur un intervalle et énumérations

Il arrive parfois qu'il soit utile de parcourir les énumérateurs d'une énumération. Bien que cela soit possible avec une boucle for utilisant un indice entier, cela nécessite probablement beaucoup de conversions statiques de l'indice entier vers notre type d'énumération.

#include <array>
#include <iostream>
#include <string_view>

namespace Color
{
    enum Type
    {
        black,
        red,
        blue,
        max_colors
    };

    // Utiliser le suffixe sv pour que std::array déduise le type std::string_view
    using namespace std::string_view_literals; // pour le suffixe sv
    constexpr std::array colorName { "black"sv, "red"sv, "blue"sv };

    // Vérifier que nous avons défini des chaînes pour toutes nos couleurs
    static_assert(std::size(colorName) == max_colors);
};

constexpr std::string_view getColorName(Color::Type color)
{
    return Color::colorName[color];
}

// Apprendre à operator<< à afficher une Color
// std::ostream est le type de std::cout
// Le type de retour et le type du paramètre sont des références (pour éviter des copies) !
std::ostream& operator<<(std::ostream& out, Color::Type color)
{
    return out << getColorName(color);
}

int main()
{
    // Utiliser une boucle for pour parcourir toutes nos couleurs
    for (int i=0; i < Color::max_colors; ++i )
        std::cout << static_cast<Color::Type>(i) << '\n';

    return 0;
}

Malheureusement, les boucles for basées sur un intervalle ne permettent pas de parcourir les énumérateurs d'une énumération :

#include <array>
#include <iostream>
#include <string_view>

namespace Color
{
    enum Type
    {
        black,
        red,
        blue,

    // Utiliser le suffixe sv pour que std::array déduise le type std::string_view

    // Vérifier que nous avons défini des chaînes pour toutes nos couleurs
    static_assert(std::size(colorName) == max_colors);
};

constexpr std::string_view getColorName(Color::Type color)
{
    return Color::colorName[color];
}

// Apprendre à operator<< à afficher une Color
// std::ostream est le type de std::cout
// Le type de retour et le type du paramètre sont des références (pour éviter des copies) !
std::ostream& operator<<(std::ostream& out, Color::Type color)
{
    return out << getColorName(color);
}

int main()
{
    for (auto c: Color::Type) // erreur de compilation : impossible de parcourir l'énumération
        std::cout << c < '\n';

    return 0;
}

Il existe de nombreuses solutions créatives. Comme nous pouvons utiliser une boucle for basée sur un intervalle sur un tableau, l'une des solutions les plus directes consiste à créer un constexpr std::array contenant chacun de nos énumérateurs, puis à parcourir ce tableau. Cette méthode ne fonctionne que si les énumérateurs ont des valeurs uniques.

#include <array>
#include <iostream>
#include <string_view>

namespace Color
{
    enum Type
    {
        black,     // 0
        red,       // 1
        blue,      // 2
        max_colors // 3
    };

    using namespace std::string_view_literals; // pour le suffixe sv
    constexpr std::array colorName { "black"sv, "red"sv, "blue"sv };
    static_assert(std::size(colorName) == max_colors);

    constexpr std::array types { black, red, blue }; // Un std::array contenant tous nos énumérateurs
    static_assert(std::size(types) == max_colors);
};

constexpr std::string_view getColorName(Color::Type color)
{
    return Color::colorName[color];
}

// Apprendre à operator<< à afficher une Color
// std::ostream est le type de std::cout
// Le type de retour et le type du paramètre sont des références (pour éviter des copies) !
std::ostream& operator<<(std::ostream& out, Color::Type color)
{
    return out << getColorName(color);
}

int main()
{
    for (auto c: Color::types) // ok : on peut utiliser une boucle for basée sur un intervalle avec un std::array
        std::cout << c << '\n';

    return 0;
}

Dans l'exemple ci-dessus, comme le type des éléments de Color::types est Color::Type, la variable c sera déduite en tant que Color::Type, ce qui est exactement ce que nous voulons !

Ce programme affiche :


black
red
blue

Solution 
#include <array>
#include <iostream>
#include <string>
#include <string_view>

namespace Animal
{
    enum Type
    {
        chicken,
        dog,
        cat,
        elephant,
        duck,
        snake,
        max_animals
    };

    struct Data
    {
        std::string_view name{};
        int legs{};
        std::string_view sound{};
    };

    constexpr std::array types { chicken, dog, cat, elephant, duck, snake };
    constexpr std::array data {
        Data{ "chicken",    2, "cluck" },
        Data{ "dog",        4, "woof" },
        Data{ "cat",        4, "meow" },
        Data{ "elephant",   4, "pawoo" },
        Data{ "duck",       2, "quack" },
        Data{ "snake",      0, "hissss" },
    };

    static_assert(std::size(types) == max_animals);
    static_assert(std::size(data) == max_animals);
}

// Apprendre à operator>> à lire un Animal par son nom
// Nous passons animal par référence non constante pour que la fonction puisse modifier sa valeur
std::istream& operator>> (std::istream& in, Animal::Type& animal)
{
    std::string input {};
    std::getline(in >> std::ws, input);

    // Voir si nous trouvons une correspondance
    for (std::size_t index=0; index < Animal::data.size(); ++index)
    {
        if (input == Animal::data[index].name)
        {
            animal = static_cast<Animal::Type>(index);
            return in;
        }
    }

    // Nous n'avons trouvé aucune correspondance, donc l'entrée était invalide
    // nous mettons donc le flux d'entrée dans l'état d'échec
    in.setstate(std::ios_base::failbit);
    return in;
}

void printAnimalData(Animal::Type type)
{
    const Animal::Data& animal { Animal::data[type] };
    std::cout << "A " << animal.name << " has " << animal.legs << " legs and says " << animal.sound << ".\n";
}

int main()
{
    std::cout << "Entrez un animal : ";
    Animal::Type type{};
    std::cin >> type;

    // Si la saisie de l'utilisateur ne correspond pas
    if (!std::cin)
    {
        std::cin.clear();
        std::cout << "That animal couldn't be found.\n";
        type = Animal::max_animals; // valeur invalide pour qu'aucune correspondance n'ait lieu ci-dessous
    }
    else
        printAnimalData(type);


    std::cout << "\nHere is the data for the rest of the animals:\n";
    for (auto a : Animal::types)
    {
        if (a != type)
            printAnimalData(a);
    }

    return 0;
}
