5.7 — Introduction à std::string

Dans la leçon 5.2 -- Literals, nous avons présenté les littéraux de chaîne de style C :

#include <iostream>

int main()
{
    std::cout << "Hello, world!"; // "Hello world!" est un littéral de chaîne de style C.
    return 0;
}

Les littéraux de chaîne de style C sont tout à fait utilisables, mais les variables de chaîne de style C ont un comportement étrange, sont difficiles à manipuler (par exemple, on ne peut pas affecter une nouvelle valeur à une variable de chaîne de style C avec l'opérateur d'affectation) et sont dangereuses (par exemple, si vous copiez une chaîne de style C plus longue dans l'espace alloué à une chaîne plus courte, cela provoque un comportement indéfini). En C++ moderne, il est préférable d'éviter les variables de chaîne de style C.

Heureusement, C++ a introduit deux autres types de chaînes, beaucoup plus simples et plus sûrs à utiliser : std::string et std::string_view (C++17). Contrairement aux types que nous avons vus précédemment, std::string et std::string_view ne sont pas des types fondamentaux : ce sont des types classes, que nous étudierons plus tard. Toutefois, leur utilisation de base est simple et suffisamment utile pour que nous les présentions ici.

Présentation de std::string

La façon la plus simple de manipuler des chaînes en C++ est d'utiliser le type std::string, défini dans l'en-tête <string>.

Nous pouvons créer des objets de type std::string comme n'importe quel autre objet :

#include <string> // permet d'utiliser std::string

int main()
{
    std::string name {}; // chaîne vide

    return 0;
}

Comme pour les variables ordinaires, vous pouvez initialiser ou affecter des valeurs à des objets std::string de la manière attendue :

#include <string>

int main()
{
    std::string name { "Alex" }; // initialise name avec le littéral de chaîne "Alex"
    name = "John";               // remplace la valeur de name par "John"

    return 0;
}

Notez qu'une chaîne peut aussi être composée de caractères numériques :

std::string myID{ "45" }; // "45" n'est pas équivalent à l'entier 45 !

Sous forme de chaîne, les nombres sont traités comme du texte, et non comme des nombres : on ne peut donc pas les manipuler comme des nombres (par exemple, les multiplier). C++ ne convertit pas automatiquement les chaînes en valeurs entières ou flottantes, ni l'inverse (il existe toutefois des moyens de le faire, que nous verrons dans une leçon ultérieure).

Affichage d'une std::string avec std::cout

Les objets std::string peuvent être affichés comme prévu avec std::cout :

#include <iostream>
#include <string>

int main()
{
    std::string name { "Alex" };
    std::cout << "My name is: " << name << '\n';

    return 0;
}

Ce programme affiche :


My name is: Alex

Une chaîne vide n'affiche rien :

#include <iostream>
#include <string>

int main()
{
    std::string empty{ };
    std::cout << '[' << empty << ']';

    return 0;
}

Ce qui affiche :


[]

std::string peut gérer des chaînes de longueurs différentes

L'une des fonctionnalités les plus pratiques de std::string est de pouvoir stocker des chaînes de longueurs différentes :

#include <iostream>
#include <string>

int main()
{
    std::string name { "Alex" }; // initialise name avec le littéral de chaîne "Alex"
    std::cout << name << '\n';

    name = "Jason";              // remplace par une chaîne plus longue
    std::cout << name << '\n';

    name = "Jay";                // remplace par une chaîne plus courte
    std::cout << name << '\n';

    return 0;
}

Ce programme affiche :


Alex
Jason
Jay

Dans l'exemple ci-dessus, name est initialisé avec la chaîne "Alex", qui contient cinq caractères (quatre caractères explicites et un caractère de fin de chaîne nul). Nous affectons ensuite à name une chaîne plus longue, puis une chaîne plus courte. std::string gère cela sans aucun problème ! Vous pouvez même stocker de très longues chaînes dans une std::string.

C'est l'une des raisons de la puissance de std::string.

Point clé

Si std::string n'a pas assez de mémoire pour stocker une chaîne, il demandera de la mémoire supplémentaire (à l'exécution) en utilisant une forme d'allocation mémoire appelée allocation dynamique. Cette capacité à obtenir de la mémoire supplémentaire est ce qui rend std::string si flexible, mais aussi relativement lent.

Nous étudierons l'allocation dynamique dans un chapitre ultérieur.

Saisie d'une chaîne avec std::cin

Utiliser std::string avec std::cin peut réserver quelques surprises ! Considérez l'exemple suivant :

#include <iostream>
#include <string>

int main()
{
    std::cout << "Enter your full name: ";
    std::string name{};
    std::cin >> name; // cela ne fonctionnera pas comme prévu, car std::cin s'arrête à la première espace blanche

    std::cout << "Enter your favorite color: ";
    std::string color{};
    std::cin >> color;

    std::cout << "Your name is " << name << " and your favorite color is " << color << '\n';

    return 0;
}

Voici le résultat d'une exécution de ce programme :


Enter your full name: John Doe
Enter your favorite color: Your name is John and your favorite color is Doe

Hmm, ce n'est pas le résultat attendu ! Que s'est-il passé ? En fait, lorsqu'on utilise operator>> pour extraire une chaîne de std::cin, operator>> ne renvoie les caractères que jusqu'à la première espace blanche rencontrée. Les autres caractères restent dans std::cin, en attendant la prochaine extraction.

Ainsi, lorsque nous avons utilisé operator>> pour extraire la saisie dans la variable name, seul "John" a été extrait, et " Doe" est resté dans std::cin. Ensuite, lorsque nous avons utilisé operator>> pour extraire la saisie dans la variable color, il a extrait "Doe" au lieu d'attendre que nous saisissions une couleur. Le programme se termine alors.

Utiliser std::getline() pour saisir du texte

Pour lire une ligne complète de texte dans une chaîne, il est préférable d'utiliser la fonction std::getline(). std::getline() prend deux arguments : le premier est std::cin, et le second est votre variable de chaîne.

Voici le même programme que précédemment, avec std::getline() :

#include <iostream>
#include <string> // Pour std::string et std::getline

int main()
{
    std::cout << "Enter your full name: ";
    std::string name{};
    std::getline(std::cin >> std::ws, name); // lit une ligne complète de texte dans name

    std::cout << "Enter your favorite color: ";
    std::string color{};
    std::getline(std::cin >> std::ws, color); // lit une ligne complète de texte dans color

    std::cout << "Your name is " << name << " and your favorite color is " << color << '\n';

    return 0;
}

Maintenant, le programme fonctionne comme prévu :


Enter your full name: John Doe
Enter your favorite color: blue
Your name is John Doe and your favorite color is blue

Qu'est-ce que std::ws ?

Dans la leçon 4.8 -- Floating point numbers, nous avons étudié les manipulateurs de sortie, qui permettent de modifier la façon dont la sortie est affichée. Dans cette leçon, nous avons utilisé le manipulateur de sortie std::setprecision() pour changer le nombre de chiffres significatifs affichés par std::cout.

C++ prend aussi en charge les manipulateurs d'entrée, qui modifient la façon dont les entrées sont acceptées. Le manipulateur d'entrée std::ws demande à std::cin d'ignorer les espaces blancs situés en début de saisie avant l'extraction. Les espaces blancs en début de chaîne sont les caractères d'espacement (espaces, tabulations, retours à la ligne) qui se trouvent au début de la chaîne.

Voyons pourquoi c'est utile. Considérez le programme suivant :

#include <iostream>
#include <string>

int main()
{
    std::cout << "Pick 1 or 2: ";
    int choice{};
    std::cin >> choice;

    std::cout << "Now enter your name: ";
    std::string name{};
    std::getline(std::cin, name); // remarque : pas de std::ws ici

    std::cout << "Hello, " << name << ", you picked " << choice << '\n';

    return 0;
}

Voici un exemple de sortie de ce programme :


Pick 1 or 2: 2
Now enter your name: Hello, , you picked 2

Ce programme vous demande d'abord de saisir 1 ou 2, et attend que vous le fassiez. Jusque-là, tout va bien. Ensuite, il vous demande votre nom. Cependant, il n'attend pas réellement que vous saisissiez votre nom ! Il affiche la chaîne « Hello » puis se termine.

Lorsque vous saisissez une valeur avec operator>>, std::cin ne capture pas seulement la valeur : il capture aussi le caractère de retour à la ligne ('\n') généré lorsque vous appuyez sur la touche Entrée. Ainsi, lorsque vous tapez 2 puis appuyez sur Entrée, std::cin capture la chaîne "2\n". Il extrait ensuite la valeur 2 vers la variable choice, en laissant le retour à la ligne dans le flux pour plus tard. Puis, lorsque std::getline() tente d'extraire du texte vers name, il constate que "\n" attend déjà dans std::cin et en déduit que nous avons saisi une chaîne vide auparavant ! Ce n'est évidemment pas ce que l'on voulait.

Nous pouvons modifier le programme précédent pour utiliser le manipulateur d'entrée std::ws, afin que std::getline() ignore les espaces blancs en début de saisie :

#include <iostream>
#include <string>

int main()
{
    std::cout << "Pick 1 or 2: ";
    int choice{};
    std::cin >> choice;

    std::cout << "Now enter your name: ";
    std::string name{};
    std::getline(std::cin >> std::ws, name); // remarque : std::ws ajouté ici

    std::cout << "Hello, " << name << ", you picked " << choice << '\n';

    return 0;
}

Ce programme fonctionne désormais comme prévu.


Pick 1 or 2: 2
Now enter your name: Alex
Hello, Alex, you picked 2

Bonne pratique

Si vous utilisez std::getline() pour lire des chaînes, utilisez le manipulateur d'entrée std::cin >> std::ws pour ignorer les espaces blancs en début de saisie. Cela doit être fait à chaque appel de std::getline(), car l'effet de std::ws ne se conserve pas d'un appel à l'autre.

Point clé

Lors d'une extraction vers une variable, l'opérateur d'extraction (>>) ignore les espaces blancs en début de saisie. Il s'arrête d'extraire lorsqu'il rencontre un espace blanc qui n'est pas en début de saisie.

std::getline() n'ignore pas les espaces blancs en début de saisie. Si vous voulez qu'il les ignore, passez std::cin >> std::ws comme premier argument. Il s'arrête d'extraire lorsqu'il rencontre un retour à la ligne.

La longueur d'une std::string

Si nous voulons connaître le nombre de caractères d'une std::string, nous pouvons interroger l'objet std::string pour obtenir sa longueur. La syntaxe est différente de ce que vous avez vu jusqu'ici, mais reste assez simple :

#include <iostream>
#include <string>

int main()
{
    std::string name{ "Alex" };
    std::cout << name << " has " << name.length() << " characters\n";

    return 0;
}

Ce programme affiche :


Alex has 4 characters

Bien que std::string doive être terminée par un caractère nul (depuis C++11), la longueur renvoyée pour une std::string n'inclut pas le caractère de fin de chaîne nul implicite.

Notez que, au lieu d'écrire length(name) pour obtenir la longueur, nous écrivons name.length(). La fonction length() n'est pas une fonction autonome ordinaire : c'est un type particulier de fonction, imbriqué dans std::string, appelé fonction membre. Comme la fonction membre length() est déclarée à l'intérieur de std::string, on la note parfois std::string::length() dans la documentation.

Nous verrons plus en détail les fonctions membres, y compris comment en écrire, dans une leçon ultérieure.

Point clé

Avec les fonctions ordinaires, on appelle function(object). Avec les fonctions membres, on appelle object.function().

Notez également que std::string::length() renvoie une valeur entière non signée (très probablement de type size_t). Si vous voulez affecter la longueur à une variable int, vous devez la convertir avec static_cast pour éviter les avertissements du compilateur concernant les conversions entre signé et non signé :

int length { static_cast<int>(name.length()) };

Pour les lecteurs avancés

En C++20, vous pouvez aussi utiliser la fonction std::ssize() pour obtenir la longueur d'une std::string sous la forme d'un type entier signé de grande taille (généralement std::ptrdiff_t) :

#include <iostream>
#include <string>

int main()
{
    std::string name{ "Alex" };
    std::cout << name << " has " << std::ssize(name) << " characters\n";

    return 0;
}

Comme un ptrdiff_t peut être plus grand qu'un int, si vous voulez stocker le résultat de std::ssize() dans une variable int, vous devez convertir ce résultat avec static_cast :

int len { static_cast<int>(std::ssize(name)) };

L'initialisation d'une std::string est coûteuse

Chaque fois qu'une std::string est initialisée, une copie de la chaîne qui sert à l'initialiser est créée. Copier des chaînes est coûteux : il faut donc veiller à limiter le nombre de copies.

Ne passez pas de std::string par valeur

Lorsqu'une std::string est passée par valeur à une fonction, le paramètre std::string doit être instancié et initialisé avec l'argument. Cela entraîne une copie coûteuse. Nous verrons ce qu'il faut faire à la place (utiliser std::string_view) dans la leçon 5.8 -- Introduction to std::string_view.

Bonne pratique

Ne passez pas de std::string par valeur, car cela entraîne une copie coûteuse.

Astuce

Dans la plupart des cas, utilisez plutôt un paramètre std::string_view (présenté dans la leçon 5.8 -- Introduction to std::string_view).

Renvoyer une std::string

Lorsqu'une fonction renvoie une valeur par copie à l'appelant, cette valeur de retour est normalement copiée depuis la fonction vers l'appelant. On pourrait donc penser qu'il ne faut pas renvoyer une std::string par valeur, car cela reviendrait à renvoyer une copie coûteuse.

Cependant, en règle générale, il est acceptable de renvoyer une std::string par valeur lorsque l'expression de l'instruction return correspond à l'un des cas suivants :

  • Une variable locale de type std::string.
  • Une std::string renvoyée par valeur par un autre appel de fonction ou un autre opérateur.
  • Un temporaire de type std::string créé dans l'instruction return.

Pour les lecteurs avancés

std::string prend en charge une fonctionnalité appelée sémantique de déplacement, qui permet à un objet devant être détruit à la fin de la fonction d'être renvoyé par valeur sans être copié. Le fonctionnement de la sémantique de déplacement dépasse le cadre de cet article introductif ; nous la présentons dans la leçon 16.5 -- Returning std::vector, and an introduction to move semantics.

Dans la plupart des autres cas, évitez de renvoyer une std::string par valeur, car cela entraînerait une copie coûteuse.

Astuce

Si vous renvoyez un littéral de chaîne de style C, utilisez plutôt un type de retour std::string_view (présenté dans la leçon 5.9 -- std::string_view (part 2)).

Pour les lecteurs avancés

Dans certains cas, une std::string peut aussi être renvoyée par référence (const), ce qui est une autre façon d'éviter une copie. Nous en discutons dans les leçons 12.12 -- Return by reference and return by address et 14.6 -- Access functions.

Littéraux pour std::string

Les littéraux de chaîne entre guillemets (comme « Hello, world! ») sont par défaut des chaînes de style C, et ont donc un type particulier.

Nous pouvons créer des littéraux de type std::string en ajoutant le suffixe s après le littéral de chaîne entre guillemets. Le s doit être en minuscule.

#include <iostream>
#include <string> // pour std::string

int main()
{
    using namespace std::string_literals; // accès facile au suffixe s

    std::cout << "foo\n";   // sans suffixe, c'est un littéral de chaîne de style C
    std::cout << "goo\n"s;  // le suffixe s crée un littéral std::string

    return 0;
}

Astuce

Le suffixe « s » se trouve dans l'espace de noms std::literals::string_literals.

La façon la plus concise d'accéder aux suffixes littéraux est la directive using using namespace std::literals. Cependant, elle importe tous les littéraux de la bibliothèque standard dans la portée de la directive, ce qui introduit beaucoup d'éléments dont vous n'aurez probablement pas besoin.

Nous recommandons using namespace std::string_literals, qui n'importe que les littéraux de std::string.

Nous étudierons les directives using dans la leçon 7.13 -- Using declarations and using directives. C'est l'un des rares cas où il est généralement acceptable d'utiliser using sur un espace de noms entier, car les suffixes qui y sont définis ont peu de chances d'entrer en conflit avec votre code. Évitez ce type de directive using en dehors des fonctions dans les fichiers d'en-tête.

Vous n'aurez probablement pas souvent besoin des littéraux std::string (il est tout à fait possible d'initialiser un objet std::string avec un littéral de chaîne de style C), mais nous verrons quelques cas dans des leçons ultérieures (impliquant la déduction de type) où utiliser des littéraux std::string plutôt que des littéraux de chaîne de style C simplifie les choses (voir 10.8 -- Type deduction for objects using the auto keyword pour un exemple).

Pour les lecteurs avancés

"Hello"s correspond à std::string { "Hello", 5 }, qui crée une std::string temporaire initialisée avec le littéral de chaîne de style C « Hello » (dont la longueur est de 5, sans compter le caractère de fin de chaîne nul implicite).

Chaînes constexpr

Si vous essayez de définir une constexpr std::string, votre compilateur générera probablement une erreur :

#include <iostream>
#include <string>

int main()
{
    using namespace std::string_literals;

    constexpr std::string name{ "Alex"s }; // erreur de compilation

    std::cout << "My name is: " << name;

    return 0;
}

Cela se produit parce que constexpr std::string n'est pas du tout pris en charge en C++17 ou en versions antérieures, et ne fonctionne que dans des cas très limités en C++20/23. Si vous avez besoin de chaînes constexpr, utilisez plutôt std::string_view (présenté dans la leçon 5.8 -- Introduction to std::string_view).

Conclusion

std::string est complexe, car elle s'appuie sur de nombreuses fonctionnalités du langage que nous n'avons pas encore abordées. Heureusement, vous n'avez pas besoin de comprendre toutes ces complexités pour utiliser std::string dans des tâches simples, comme la saisie et l'affichage de texte. Nous vous encourageons à commencer dès maintenant à expérimenter avec les chaînes ; nous verrons d'autres fonctionnalités des chaînes plus tard.

Un petit quiz

Question n° 1

Écrivez un programme qui demande à l'utilisateur de saisir son nom complet et son âge. En sortie, indiquez à l'utilisateur la somme de son âge et du nombre de caractères de son nom (utilisez la fonction membre std::string::length() pour obtenir la longueur de la chaîne). Par simplicité, comptez les espaces du nom comme des caractères.

Exemple de sortie :


Enter your full name: John Doe
Enter your age: 32
Your age + length of name is: 40

Rappel : nous devons veiller à ne pas mélanger des valeurs signées et non signées. std::string::length() renvoie une valeur non signée. Si vous utilisez C++20, utilisez std::ssize() pour obtenir la longueur sous forme de valeur signée. Sinon, convertissez avec static_cast la valeur renvoyée par std::string::length() en int.

Solution 
#include <iostream>
#include <string>

int main()
{
    std::cout << "Enter your full name: ";
    std::string name{};
    std::getline(std::cin >> std::ws, name); // lit une ligne complète de texte dans name

    std::cout << "Enter your age: ";
    int age{}; // age doit être un entier, et non une chaîne, pour pouvoir faire des calculs
    std::cin >> age;

    // age est signé, et name.length() est non signé -- nous ne devrions pas mélanger les deux
    // Nous allons convertir name.length() en valeur signée
    int nameLen { static_cast<int>(name.length()) }; // nombre de caractères dans name (espaces inclus)
    std::cout << "Your age + length of name is: " << age + nameLen << '\n';

    return 0;
}
