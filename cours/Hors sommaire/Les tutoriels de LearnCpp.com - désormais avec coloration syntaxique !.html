Les tutoriels de LearnCpp.com : désormais avec coloration syntaxique !

Ça y est, c'est enfin là. Si votre navigateur prend en charge JavaScript, les exemples de code des tutoriels affichent désormais la numérotation des lignes et la coloration syntaxique. Par exemple, au lieu de :


Cents& Cents::operator= (const Cents &cSource)
{
    // on vérifie l'auto-affectation en comparant l'adresse de
    // l'objet implicite et celle du paramètre
    if (this == &cSource)
        return *this;

    // on effectue la copie
    m_nCents = cSource.m_nCents;

    // on retourne l'objet existant
    return *this;
}

vous verrez maintenant :

Cents& Cents::operator= (const Cents &cSource)
{
    // on vérifie l'auto-affectation en comparant l'adresse de
    // l'objet implicite et celle du paramètre
    if (this == &cSource)
        return *this;

    // on effectue la copie
    m_nCents = cSource.m_nCents;

    // on retourne l'objet existant
    return *this;
}

Je travaille toujours à convertir les anciens tutoriels vers le nouveau format. Comme il y en a plus de 100, cela peut me prendre un certain temps.

Si vous essayez de sélectionner à la souris le code coloré pour le coller dans un autre document (ou dans un compilateur), les numéros de ligne seront copiés eux aussi. Utilisez plutôt la fonction « copier dans le presse-papiers » située en haut de l'extrait de code. Elle place le code dans votre presse-papiers, que vous pourrez ensuite coller normalement dans un autre document.

Si cela ne fonctionne pas pour vous, utilisez « afficher en texte brut », qui affiche le code sans coloration syntaxique ni numérotation des lignes, et copiez-le ensuite de la manière habituelle.

J'espère que ce changement apportera une valeur ajoutée à votre expérience avec C++.
