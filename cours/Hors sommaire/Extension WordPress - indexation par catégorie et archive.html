Extension WordPress : indexation par catégorie et archive

Par défaut, WordPress affiche les listes de catégories et d'archives sous forme de blog, c'est-à-dire en montrant soit des extraits, soit le contenu complet des N derniers articles (selon le thème). C'est agréable à lire, mais peu pratique pour retrouver un article précis.

Category/Archive Indexing est une extension WordPress qui remplace ces listes de type blog par une liste de liens vers chaque article. Elle fonctionne également avec les étiquettes de Simple Tagging Plugin.


(L'apparence réelle peut varier selon le thème)

Pour mieux vous faire une idée de ce que permet cette extension, voici quelques exemples de pages de ce site : un index de catégorie, une étiquette du nuage de tags, et un lien depuis l'archive mensuelle.

Pour installer l'extension :

  1. Téléchargez l'extension.
  2. Envoyez l'extension dans le répertoire wp-content/plugins.
  3. Activez l'extension.

L'extension fournit trois fonctions :

function CAI_Header($headerStyleStart='<h2>', $headerStyleEnd='</h2>')

CAI_Header() affiche un titre sur la page, entouré des éléments $headerStyleStart et $headerStyleEnd. Sur l'image ci-dessus, elle est responsable de l'en-tête « Category: WordPress ».

function CAI_SetNumberOfPosts($limit)

CAI_SetNumberOfPosts() détermine le nombre de liens à afficher. Si vous voulez afficher tous les liens d'une catégorie ou d'une archive, définissez une valeur arbitrairement grande, par exemple 99999. Si vous n'appelez pas cette fonction, la valeur par défaut est le nombre d'articles que vous avez configuré pour la page d'accueil.

function CAI_DisplayLink($beforeLink='', $afterLink='<br>')

CAI_DisplayLink affiche réellement le lien lui-même, et doit être placée à l'intérieur de the_loop. Elle comporte deux paramètres qui vous permettent de personnaliser le style. $beforeLink peut être défini à <li> si vous souhaitez afficher vos liens dans une liste ordonnée ou non ordonnée.

Malheureusement, l'extension ne fonctionne pas « telle quelle ». Pour l'utiliser, vous devez modifier (ou créer) un fichier archive.php et/ou category.php dans le répertoire de votre thème. Vous pouvez utiliser le modèle suivant pour les deux, qui fonctionne avec de nombreux thèmes :


<?php get_header(); ?>
<?php get_sidebar(); ?> <!-- Supprimez cette ligne si elle provoque une erreur -->

<div class="something"> <!-- Remplacez cette div pour correspondre à votre thème -->
<?php CAI_Header(); ?>

<?php CAI_SetNumberOfPosts(99999); ?>

<?php while (have_posts()) : the_post(); ?>
<?php CAI_DisplayLink(); ?>
</div>

<?php get_footer(); ?>

L'élément HTML div doit être adapté à votre thème. Il indique au navigateur comment mettre en forme la liste de liens. La meilleure façon de savoir quoi utiliser est de regarder à l'intérieur de votre index.php. La première div que vous rencontrez est probablement celle que vous voulez. Il vous suffit de remplacer la div du modèle ci-dessus par la première div de votre index.php, et cela devrait probablement fonctionner.

Par exemple, la première div trouvée dans l'index.php du thème wp-andreas01-12 est <div id="content">. Pour ce thème, <div class="something"> doit être remplacée par <div id="content">.

Vous pouvez également modifier les paramètres des fonctions CAI pour les adapter à vos goûts.

Les fans de Tiga trouveront dans le fichier zip suivant un archive.php et un category.php. Extrayez-les dans le répertoire wp-content/themes/tiga-06.
