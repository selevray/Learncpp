Corruption de la base de données / Problèmes du site

Nous avons connu une panne majeure du site hier soir, avec une base de données corrompue. Ceux d'entre vous qui connaissent bien le fonctionnement de WordPress savent que la base de données contient tout : tout le contenu, tous les commentaires et toutes les données de configuration. Quand la base de données tombe, le site tombe avec elle. Heureusement, la base est sauvegardée régulièrement.

Cependant, il semble que certains fichiers du site aient aussi été corrompus, et les sauvegardes refusent de se restaurer correctement (pourquoi, c'est toujours un mystère pour moi). Le moyen le plus rapide de remettre le site en route a été de passer à la dernière version de WordPress, ce qui a éliminé les fichiers corrompus ainsi que d'autres problèmes de base de données. En revanche, le thème du site (l'apparence et l'ergonomie) et certaines extensions personnalisées doivent être un peu retravaillés pour fonctionner avec la nouvelle version de WordPress.

Ainsi, pour l'instant, le contenu est en ligne, ce qui est le plus important, mais vous remarquerez que le site a un aspect bizarre et que certaines choses ne fonctionnent plus, comme les commentaires en fil de discussion. Si vous constatez autre chose qui semble cassé, merci de le signaler ci-dessous et je m'en occuperai.

Au cours des prochains jours, je travaillerai à remettre tout en état de marche. D'autres périodes d'indisponibilité pourraient survenir pendant cette transition. Je vous présente mes excuses pour les interruptions passées et à venir : je sais que beaucoup d'entre vous utilisent ce site pour leur développement personnel, éducatif et professionnel, et je m'efforce de le maintenir en fonctionnement autant que possible.

Merci, comme toujours, de votre visite.

Alex
