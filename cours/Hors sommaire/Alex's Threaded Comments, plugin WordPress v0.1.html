Alex's Threaded Comments, plugin WordPress v0.1

Je publie enfin la version 0.1 d'Alex's Threaded Comments, un plugin WordPress qui permet d'ajouter des commentaires en fils de discussion (threaded) à votre site web. Ce plugin est en fait une simple dérivation du remarquable plugin Brian's Threaded Comments (v1.5.12). J'y ai ajouté quelques corrections de bugs, quelques nouvelles fonctionnalités et un nouveau look. Merci à Brian pour tout ce travail.

Ce site utilise actuellement ce plugin. Vous pouvez donc jeter un œil à la section des commentaires ci-dessous pour vous faire une idée de son rendu.

Voici ce qui a été ajouté ou corrigé :

  • Correction du problème de disparition de la zone de commentaire et de la réinitialisation de la racine (reroot).
  • Remplacement des champs nom, e-mail et URL par une note de connexion si l'utilisateur est connecté.
  • Utilisation d'images externes pour que les compteurs de statistiques ne soient pas gonflés.
  • Ajout d'une option (dans les réglages du plugin) pour filtrer les pingbacks.
  • Ajout de la possibilité de changer la couleur de la barre de titre si le message a été publié par un administrateur (via CSS).
  • Modification du style CSS de base pour un rendu plus épuré.
  • Correction, en grande partie, des problèmes de rendu sous IE6, ou contournement de ceux-ci.

Vous pouvez télécharger ce plugin ici. Lisez le fichier HowToInstall.txt inclus pour savoir comment installer le plugin.

Ce plugin fonctionne bien avec le plugin WP AJAX Edit Comments.

Comme je n'ai pas écrit le code original de ce plugin, je n'ai pas l'intention d'offrir un support technique pour celui-ci. Cependant, si vous rencontrez un problème, vous pouvez publier un message sur mon forum WordPress, et peut-être qu'une bonne âme vous répondra. Si vous avez des suggestions de fonctionnalités futures ou de corrections de bugs que vous aimeriez voir, vous pouvez les poster ici.

Bonne découverte.
