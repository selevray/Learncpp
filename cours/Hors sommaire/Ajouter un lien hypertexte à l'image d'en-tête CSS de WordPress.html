Ajouter un lien hypertexte à l'image d'en-tête CSS de WordPress

Une question qui me pose problème depuis une semaine est de savoir comment faire pointer l'image d'en-tête de WordPress vers le site lui-même. Beaucoup de thèmes WordPress utilisent correctement la propriété CSS background-image pour afficher l'image d'en-tête. Malheureusement, il n'existe aucun moyen direct de modifier la feuille de style CSS pour transformer l'image en lien.

Il est toutefois possible de le faire en modifiant le fichier header.php.

Beaucoup de thèmes contiennent une ligne semblable à celle-ci : <div class="header">

Pour rendre votre en-tête cliquable, remplacez la ligne ci-dessus dans header.php par :

<div class="header" onclick="location.href='<?php bloginfo('url'); ?>';" style="cursor: pointer;">

Notez que cette méthode rend cliquable la totalité de la zone d'en-tête, et non seulement l'image, qui peut n'en occuper qu'une partie.

Merci à vkaryl sur wordpress.org pour l'idée de base.

Remarque : si votre header.php utilise une balise HTML img classique, il suffit d'entourer celle-ci d'une balise d'ancrage a : <img src="pathtoheader"> devient <a href="<?php bloginfo('url'); ?>"><img src="pathtoheader"></a>
