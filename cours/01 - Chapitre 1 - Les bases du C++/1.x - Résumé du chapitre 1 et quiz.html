1.x — Résumé du chapitre 1 et quiz

Résumé du chapitre

Une instruction (statement) est un type d'instruction qui amène le programme à effectuer une action. Les instructions se terminent souvent par un point-virgule.

Une fonction (function) est un ensemble d'instructions exécutées séquentiellement. Tout programme C++ doit contenir une fonction spéciale nommée main. Lorsque vous exécutez votre programme, l'exécution commence au début de la fonction main.

En programmation, le nom d'une fonction (ou d'un objet, d'un type, d'un modèle, etc.) est appelé son identifiant (identifier).

Les règles qui régissent la construction des éléments du langage C++ sont appelées syntaxe (syntax). Une erreur de syntaxe (syntax error) se produit lorsque vous enfreignez les règles grammaticales du langage.

Les commentaires (comments) permettent au programmeur de laisser des notes dans le code. C++ prend en charge deux types de commentaires. Les commentaires de ligne commencent par // et se terminent à la fin de la ligne. Les commentaires de bloc commencent par /* et se terminent au symbole */ correspondant. N'imbriquez pas les commentaires de bloc.

Vous pouvez utiliser les commentaires pour désactiver temporairement des lignes ou des sections de code. C'est ce qu'on appelle « mettre du code en commentaire » (commenting out).

Les données (data) sont toute information qui peut être déplacée, traitée ou stockée par un ordinateur. Une donnée isolée est appelée une valeur (value). Parmi les exemples courants de valeurs, on trouve des lettres (par exemple a), des nombres (par exemple 5) et du texte (par exemple Hello).

Une variable est une zone de mémoire nommée que nous pouvons utiliser pour stocker des valeurs. Pour créer une variable, on utilise une instruction appelée instruction de définition (definition statement). Lorsque le programme est exécuté, chaque variable définie est instanciée (instantiated), ce qui signifie qu'on lui attribue une adresse mémoire.

Un type de données (data type) indique au compilateur comment interpréter une donnée afin d'en faire une valeur significative. Un entier (integer) est un nombre qui peut s'écrire sans partie fractionnaire, comme 4, 27, 0, -2 ou -12.

L'affectation par copie (copy assignment), via operator=, permet de donner une valeur à une variable déjà créée.

Le fait de spécifier une valeur initiale pour un objet s'appelle l'initialisation (initialization), et la syntaxe utilisée pour initialiser un objet est appelée un initialiseur (initializer).

De manière simplifiée, C++ prend en charge 6 types de base d'initialisation :

Type d'initialisation Exemple Remarque
Initialisation par défaut (default-initialization) int x; Dans la plupart des cas, laisse la variable avec une valeur indéterminée
Initialisation par copie (copy-initialization) int x = 5;
Initialisation directe (direct-initialization) int x ( 5 );
Initialisation directe par liste (direct-list-initialization) int x { 5 }; Les conversions restrictives sont interdites
Initialisation par copie de liste (copy-list-initialization) int x = { 5 }; Les conversions restrictives sont interdites
Initialisation par valeur (value-initialization) int x {}; Effectue généralement une initialisation à zéro

L'initialisation directe est parfois appelée initialisation par parenthèses, et l'initialisation par liste (y compris l'initialisation par valeur) est parfois appelée initialisation uniforme ou initialisation par accolades (brace-initialization). Vous devriez privilégier l'initialisation par accolades par rapport aux autres formes d'initialisation, et privilégier l'initialisation plutôt que l'affectation.

Bien que vous puissiez définir plusieurs variables dans une seule instruction, il est préférable de définir et d'initialiser chaque variable sur sa propre ligne, dans une instruction séparée.

std::cout et operator<< nous permettent d'afficher le résultat d'une expression dans la console.

std::endl affiche un caractère de saut de ligne, forçant le curseur de la console à passer à la ligne suivante, et vide le tampon de sortie (flush) en envoyant à la console toute sortie en attente. Le caractère '\n' affiche également un saut de ligne, mais laisse le système décider du moment où vider le tampon. Prenez garde à ne pas utiliser '/n' (barre oblique).

std::cin et operator>> nous permettent de récupérer une valeur saisie au clavier.

Une variable à laquelle aucune valeur n'a été donnée est appelée une variable non initialisée (uninitialized variable). Tenter d'obtenir la valeur d'une variable non initialisée produira un comportement indéfini (undefined behavior), qui peut se manifester de bien des façons.

C++ réserve un ensemble de noms appelés mots-clés (keywords). Ceux-ci ont une signification particulière dans le langage et ne peuvent pas être utilisés comme noms de variables.

Une constante littérale (literal constant) est une valeur fixe insérée directement dans le code source. Par exemple, 5 et « Hello world! ».

Une opération (operation) est un processus impliquant zéro ou plusieurs valeurs d'entrée, appelées opérandes (operands). L'opération précise à effectuer est indiquée par l'opérateur (operator) fourni. Le résultat d'une opération produit une valeur de sortie.

Les opérateurs unaires (unary) prennent un opérande. Les opérateurs binaires (binary) prennent deux opérandes, souvent appelés gauche et droite. Les opérateurs ternaires (ternary) prennent trois opérandes. Les opérateurs nullaires (nullary) ne prennent aucun opérande.

Une expression (expression) est une suite de littéraux, de variables, d'opérateurs et d'appels de fonctions qui est évaluée pour produire une seule valeur de sortie. Le calcul de cette valeur de sortie s'appelle l'évaluation (evaluation). La valeur produite est le résultat (result) de l'expression.

Une instruction d'expression (expression statement) est une expression transformée en instruction en plaçant un point-virgule à la fin de l'expression.

Lorsque vous écrivez des programmes, ajoutez quelques lignes ou une fonction, compilez, corrigez les erreurs éventuelles et vérifiez que cela fonctionne. N'attendez pas d'avoir écrit un programme entier avant de le compiler pour la première fois !

Concentrez-vous sur le fonctionnement de votre code. Une fois certain de conserver un morceau de code, vous pouvez alors consacrer du temps à supprimer (ou mettre en commentaire) le code temporaire ou de débogage, ajouter des commentaires, gérer les cas d'erreur, formater votre code, veiller à respecter les bonnes pratiques, supprimer la logique redondante, etc.

Les programmes de premier jet sont souvent désordonnés et imparfaits. La plupart du code nécessite un nettoyage et un affinement pour devenir excellent !

Quiz

Question n° 1

Quelle est la différence entre l'initialisation et l'affectation ? Combien de fois une variable peut-elle être initialisée ou se voir affecter une valeur ?

Solution

L'initialisation fournit à une variable une valeur initiale (au moment de sa création). L'affectation donne à une variable une nouvelle valeur après qu'elle a déjà été définie.

Une variable n'étant créée qu'une seule fois, elle ne peut être initialisée qu'une seule fois. Elle peut se voir affecter une valeur autant de fois que souhaité.

Question n° 2

Quand se produit un comportement indéfini ? Quelles sont les conséquences d'un comportement indéfini ?

Solution

Un comportement indéfini se produit lorsque le programmeur fait quelque chose que le langage C++ ne définit pas précisément. Les conséquences peuvent être à peu près n'importe quoi, du plantage à un résultat erroné, en passant par un fonctionnement correct malgré tout.

Question n° 3

Écrivez un programme qui demande à l'utilisateur de saisir un nombre, puis un second nombre. Le programme doit indiquer à l'utilisateur le résultat de l'addition et de la soustraction des deux nombres.

La sortie du programme doit correspondre à ce qui suit (en supposant les saisies 6 et 4) :


Enter an integer: 6
Enter another integer: 4
6 + 4 is 10.
6 - 4 is 2.

Indice : pour afficher un point et un saut de ligne, utilisez ".\n", et non '.\n'.

Solution 
#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    int x{};
    std::cin >> x;

    std::cout << "Enter another integer: ";
    int y{};
    std::cin >> y;

    std::cout << x << " + " << y << " is " << x + y << ".\n";
    std::cout << x << " - " << y << " is " << x - y << ".\n";

    return 0;
}
