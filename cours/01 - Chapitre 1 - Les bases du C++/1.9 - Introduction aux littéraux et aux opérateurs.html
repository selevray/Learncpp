1.9 — Introduction aux littéraux et aux opérateurs

Littéraux

Considérez les deux instructions suivantes :

std::cout << "Hello world!";
int x { 5 };

Qu'est-ce que ‘"Hello world!"’ et ‘5’ ? Ce sont des littéraux. Un littéral (aussi appelé constante littérale) est une valeur fixe insérée directement dans le code source.

Les littéraux et les variables ont tous deux une valeur (et un type). Contrairement à une variable (dont la valeur peut être définie et modifiée respectivement par l'initialisation et l'affectation), la valeur d'un littéral est fixe et ne peut pas être modifiée. Le littéral 5 a toujours la valeur 5. C'est pourquoi les littéraux sont appelés constantes.

Pour mieux mettre en évidence la différence entre littéraux et variables, examinons ce court programme :

#include <iostream>

int main()
{
    std::cout << 5 << '\n'; // affiche la valeur d'un littéral

    int x { 5 };
    std::cout << x << '\n'; // affiche la valeur d'une variable
    return 0;
}

À la ligne 5, nous affichons la valeur 5 dans la console. Lorsque le compilateur compile ce code, il génère du code qui amène std::cout à afficher la valeur 5. Cette valeur 5 est compilée dans l'exécutable et peut être utilisée directement.

À la ligne 7, nous créons une variable nommée x et l'initialisons avec la valeur 5. Le compilateur génère du code qui copie le littéral 5 dans l'emplacement mémoire attribué à x. À la ligne 8, lorsque nous affichons x, le compilateur génère du code qui amène std::cout à afficher la valeur présente à l'emplacement mémoire de x (qui vaut 5).

Ainsi, les deux instructions d'affichage font la même chose (afficher la valeur 5). Mais dans le cas du littéral, la valeur 5 peut être affichée directement. Dans le cas de la variable, la valeur 5 doit être lue depuis la mémoire que la variable représente.

Cela explique aussi pourquoi un littéral est constant alors qu'une variable peut être modifiée. La valeur d'un littéral est placée directement dans l'exécutable, et l'exécutable lui-même ne peut plus être modifié une fois créé. La valeur d'une variable est placée en mémoire, et le contenu de cette mémoire peut être modifié pendant l'exécution du programme.

Point clé

Les littéraux sont des valeurs insérées directement dans le code source. Ces valeurs apparaissent généralement directement dans le code exécutable (sauf si elles sont supprimées par l'optimisation).

Les objets et les variables représentent des emplacements mémoire qui contiennent des valeurs. Ces valeurs peuvent être lues à la demande.

Opérateurs

En mathématiques, une opération est un processus impliquant zéro ou plusieurs valeurs d'entrée (appelées opérandes) qui produit une nouvelle valeur (appelée valeur de sortie). L'opération précise à effectuer est désignée par un symbole appelé opérateur.

Par exemple, dès l'enfance, nous apprenons que 2 + 3 vaut 5. Dans ce cas, les littéraux 2 et 3 sont les opérandes, et le symbole + est l'opérateur qui indique d'appliquer l'addition mathématique aux opérandes pour produire la nouvelle valeur 5.

En C++, les opérations fonctionnent comme vous pourriez vous y attendre. Par exemple :

#include <iostream>

int main()
{
    std::cout << 1 + 2 << '\n';

    return 0;
}

Dans ce programme, les littéraux 1 et 2 sont les opérandes de l'opérateur plus (+), qui produit la valeur de sortie 3. Cette valeur de sortie est ensuite affichée dans la console. En C++, la valeur de sortie d'une opération est souvent appelée valeur de retour.

Vous êtes probablement déjà familier avec les opérateurs arithmétiques standard tels qu'utilisés en mathématiques, notamment l'addition (+), la soustraction (-), la multiplication (*) et la division (/). En C++, l'affectation (=) est aussi un opérateur, de même que l'insertion (<<), l'extraction (>>) et l'égalité (==). Alors que la plupart des opérateurs ont des symboles pour noms (par ex. + ou ==), certains opérateurs sont des mots-clés (par ex. new, delete et throw).

Note de l'auteur

Pour des raisons qui deviendront claires lorsque nous étudierons les opérateurs plus en détail, pour les opérateurs représentés par des symboles, il est courant d'accoler le symbole de l'opérateur au mot operator.

Par exemple, l'opérateur plus s'écrit operator+, et l'opérateur d'extraction s'écrit operator>>.

Le nombre d'opérandes qu'un opérateur prend en entrée est appelé arité de l'opérateur. Peu de gens connaissent ce mot, alors ne le lâchez pas dans une conversation en espérant que quelqu'un comprendra de quoi vous parlez. En C++, les opérateurs se répartissent en quatre arités différentes :

Les opérateurs unaires agissent sur un seul opérande. Un exemple d'opérateur unaire est l'opérateur -. Par exemple, avec -5, operator- prend l'opérande littéral 5 et inverse son signe pour produire la nouvelle valeur de sortie -5.

Les opérateurs binaires agissent sur deux opérandes (souvent appelés gauche et droite, car l'opérande gauche apparaît à gauche de l'opérateur et l'opérande droite à sa droite). Un exemple d'opérateur binaire est l'opérateur +. Par exemple, avec 3 + 4, operator+ prend l'opérande gauche 3 et l'opérande droite 4 et applique l'addition mathématique pour produire la nouvelle valeur de sortie 7. Les opérateurs d'insertion (<<) et d'extraction (>>) sont des opérateurs binaires, prenant std::cout ou std::cin à gauche, et la valeur à afficher ou la variable dans laquelle saisir une valeur à droite.

Les opérateurs ternaires agissent sur trois opérandes. Il n'en existe qu'un seul en C++ (l'opérateur conditionnel), que nous verrons plus tard.

Les opérateurs nullaires agissent sur zéro opérande. Il n'en existe qu'un seul en C++ (l'opérateur throw), que nous verrons également plus tard.

Notez que certains opérateurs ont plusieurs significations selon leur utilisation. Par exemple, operator- a deux contextes. Il peut être utilisé sous forme unaire pour inverser le signe d'un nombre (par ex. pour convertir 5 en -5, ou inversement), ou sous forme binaire pour effectuer une soustraction (par ex. 4 - 3).

Enchaînement des opérateurs

Les opérateurs peuvent être enchaînés de sorte que la sortie d'un opérateur puisse servir d'entrée à un autre opérateur. Par exemple, pour 2 * 3 + 4, l'opérateur de multiplication s'exécute en premier et convertit l'opérande gauche 2 et l'opérande droite 3 en la valeur de retour 6 (qui devient l'opérande gauche de l'opérateur plus). Ensuite, l'opérateur plus s'exécute et convertit l'opérande gauche 6 et l'opérande droite 4 en la nouvelle valeur 10.

Nous reviendrons plus en détail sur l'ordre d'exécution des opérateurs lorsque nous étudierons les opérateurs de façon approfondie. Pour l'instant, il suffit de savoir que les opérateurs arithmétiques s'exécutent dans le même ordre qu'en mathématiques standard : d'abord les parenthèses, puis les exposants, puis les multiplications et divisions, enfin les additions et soustractions. Cet ordre est parfois abrégé en PEMDAS, ou développé en mnémotechnique anglaise « Please Excuse My Dear Aunt Sally ».

Note de l'auteur

Dans certains pays, PEMDAS est enseigné sous les noms PEDMAS, BEDMAS, BODMAS ou BIDMAS.

Valeurs de retour et effets de bord

La plupart des opérateurs en C++ utilisent simplement leurs opérandes pour calculer une valeur de retour. Par exemple, -5 produit la valeur de retour -5 et 2 + 3 produit la valeur de retour 5. Quelques opérateurs ne produisent pas de valeur de retour (comme delete et throw). Nous verrons plus tard ce qu'ils font.

Certains opérateurs ont des comportements supplémentaires. On dit qu'un opérateur (ou une fonction) qui a un effet observable en plus de produire une valeur de retour possède un effet de bord (side effect). Par exemple, x = 5 a pour effet de bord d'affecter la valeur 5 à la variable x. La valeur modifiée de x est observable (par exemple en affichant la valeur de x) même après la fin de l'exécution de l'opérateur. std::cout << 5 a pour effet de bord d'afficher 5 dans la console. On peut constater que 5 a été affiché dans la console même après la fin de l'exécution de std::cout << 5.

Terminologie

Dans le langage courant, le terme « effet de bord » désigne généralement un résultat secondaire (souvent négatif ou inattendu) d'une autre chose (comme la prise d'un médicament). Par exemple, un effet secondaire courant des antibiotiques oraux est la diarrhée. Ainsi, on considère souvent les effets de bord comme des choses à éviter, ou comme accessoires par rapport au but principal.

En C++, le terme « effet de bord » a un sens différent : il désigne un effet observable d'un opérateur ou d'une fonction, au-delà de la production d'une valeur de retour.

Comme l'affectation a pour effet observable de modifier la valeur d'un objet, cela est considéré comme un effet de bord. Nous utilisons certains opérateurs (par ex. l'opérateur d'affectation) principalement pour leurs effets de bord (plutôt que pour la valeur de retour qu'ils produisent). Dans de tels cas, l'effet de bord est à la fois bénéfique et prévisible (et c'est la valeur de retour qui est souvent accessoire).

Pour les lecteurs avancés

Pour les opérateurs que nous appelons principalement pour leurs valeurs de retour (par ex. operator+ ou operator*), il est généralement évident quelles seront leurs valeurs de retour (par ex. la somme ou le produit des opérandes).

Pour les opérateurs que nous appelons principalement pour leurs effets de bord (par ex. operator= ou operator<<), il n'est pas toujours évident quelles valeurs de retour ils produisent (le cas échéant). Par exemple, quelle valeur de retour attendriez-vous de x = 5 ?

Tant operator= que operator<< (lorsqu'il sert à afficher des valeurs dans la console) renvoient leur opérande gauche. Ainsi, x = 5 renvoie x, et std::cout << 5 renvoie std::cout. Cela permet d'enchaîner ces opérateurs.

Par exemple, x = y = 5 est évalué comme x = (y = 5). D'abord, y = 5 affecte 5 à y. Cette opération renvoie ensuite y, qui peut alors être affecté à x.

std::cout << "Hello " << "world!" est évalué comme (std::cout << "Hello ") << "world!". Cela affiche d'abord "Hello " dans la console. Cette opération renvoie std::cout, qui peut alors être utilisé pour afficher "world!" dans la console également.

Nous reparlerons de l'ordre d'évaluation des opérateurs dans la leçon 6.1 -- Priorité et associativité des opérateurs.

Quiz

Question n° 1

Pour chacun des éléments suivants, indiquez la sortie produite :

a)

std::cout << 3 + 4 << '\n';
Solution

7

b)

std::cout << 3 + 4 - 5 << '\n';
Solution

2

c)

std::cout << 2 + 3 * 4 << '\n';
Solution
  1. La multiplication est prioritaire sur l'addition, donc 3 * 4 est calculé en premier, ce qui donne 12. 2 + 12 vaut 14.

d) Bonus :

int x { 2 };
std::cout << (x = 5) << '\n';
Solution
  1. x = 5 affecte la valeur 5 à x, puis renvoie x. La valeur de x (désormais 5) est ensuite affichée dans la console.
