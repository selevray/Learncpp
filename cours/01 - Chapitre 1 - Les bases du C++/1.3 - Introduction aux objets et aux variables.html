1.3 — Introduction aux objets et aux variables

Données et valeurs

Dans la leçon 1.1 -- Instructions et structure d'un programme, vous avez appris que la majorité des instructions d'un programme sont des instructions (statements), et que les fonctions sont des groupes d'instructions exécutées séquentiellement. Les instructions à l'intérieur de la fonction effectuent des actions qui produisent (espérons-le) le résultat pour lequel le programme a été conçu.

Mais comment les programmes produisent-ils réellement des résultats ? Ils le font en manipulant (lisant, modifiant et écrivant) des données. En informatique, une donnée est toute information qui peut être déplacée, traitée ou stockée par un ordinateur.

Point clé

Un programme est un ensemble d'instructions qui manipulent des données pour produire un résultat souhaité.

Les programmes informatiques (aussi bien sous forme de code source que compilés) sont techniquement des données également, puisqu'ils peuvent être déplacés, traités et stockés. Cependant, dans le contexte d'un programme informatique, on utilise généralement le terme « code » pour désigner le programme lui-même, et « données » pour désigner les informations avec lesquelles le programme travaille pour produire un résultat.

Un programme peut obtenir des données à traiter de bien des façons : à partir d'un fichier ou d'une base de données, par le réseau, par la saisie de l'utilisateur au clavier, ou par le programmeur qui place directement les données dans le code source du programme. Dans le programme « Hello world » de la leçon mentionnée précédemment, le texte « Hello world! » était inséré directement dans le code source, fournissant ainsi une donnée au programme. Le programme manipule ensuite cette donnée en l'envoyant à l'écran pour l'afficher.

En programmation, une donnée isolée est appelée une valeur (parfois appelée valeur de donnée). Parmi les exemples courants de valeurs, on trouve :

  • Les nombres (par exemple 5 ou -6.7).
  • Les caractères, placés entre apostrophes (par exemple 'H' ou '$'). Un seul symbole peut être utilisé.
  • Le texte, qui doit être placé entre guillemets (par exemple "Hello" ou "H"). Un texte peut contenir 0 caractère ou plus.

Point clé

Les valeurs placées entre apostrophes sont interprétées par le compilateur comme des valeurs de caractère.
Les valeurs placées entre guillemets sont interprétées par le compilateur comme des valeurs de texte.
Les valeurs numériques ne sont pas entourées de guillemets.

Les valeurs placées directement dans le code source sont appelées littéraux (literals). Nous étudierons les littéraux en détail dans la leçon 5.2 -- Littéraux.

L'une des opérations les plus courantes sur les valeurs consiste à les afficher à l'écran. Par exemple :

#include <iostream> // pour std::cout

int main()
{
    std::cout << 5;       // affiche le littéral numérique `5`
    std::cout << -6.7;    // affiche le littéral numérique `-6.7`
    std::cout << 'H';     // affiche le littéral caractère `H`
    std::cout << "Hello"; // affiche le littéral texte `Hello`

    return 0;
}

Si une valeur de caractère ou de texte n'est pas correctement entourée de guillemets, le compilateur essaiera de l'interpréter comme du code C++. Cela entraînera presque toujours une erreur de compilation.

Les littéraux sont le moyen le plus simple de fournir des valeurs à votre programme, mais ils présentent quelques inconvénients. Les littéraux sont des valeurs en lecture seule : leur valeur ne peut pas être modifiée. Ainsi, si nous voulons stocker des données en mémoire, nous avons besoin d'un autre moyen.

Mémoire vive (RAM)

La mémoire principale d'un ordinateur est appelée mémoire vive (Random Access Memory, souvent abrégée en RAM). Lorsque nous exécutons un programme, le système d'exploitation charge le programme en RAM. Toutes les données codées en dur dans le programme lui-même (par exemple le texte « Hello, world! ») sont chargées à ce moment-là.

Le système d'exploitation réserve également de la RAM supplémentaire que le programme peut utiliser pendant son exécution. Ces emplacements servent couramment à stocker des valeurs saisies par l'utilisateur, des données lues depuis un fichier ou le réseau, ou des valeurs calculées pendant l'exécution (par exemple la somme de deux valeurs) afin de pouvoir les réutiliser plus tard.

Vous pouvez considérer la RAM comme une série de boîtes numérotées pouvant servir à stocker des données pendant l'exécution du programme.

Dans certains langages plus anciens (comme l'Applesoft BASIC), vous pouviez accéder directement à ces boîtes (par exemple, vous pouviez écrire une instruction pour « aller chercher la valeur stockée dans la case mémoire numéro 7532 »).

Objets et variables

En C++, l'accès direct à la mémoire est déconseillé. Nous accédons plutôt à la mémoire de manière indirecte, par l'intermédiaire d'un objet. Un objet représente une zone de stockage (généralement de la RAM ou un registre du processeur) pouvant contenir une valeur. Les objets possèdent également des propriétés associées, que nous aborderons dans de prochaines leçons.

La manière dont le compilateur et le système d'exploitation attribuent la mémoire aux objets dépasse le cadre de cette leçon. L'idée essentielle est que, plutôt que de dire « va chercher la valeur stockée dans la case mémoire numéro 7532 », nous pouvons dire « va chercher la valeur stockée par cet objet » et laisser le compilateur déterminer où et comment récupérer la valeur. Nous pouvons ainsi nous concentrer sur l'utilisation des objets pour stocker et récupérer des valeurs, sans nous soucier de l'emplacement exact qu'ils occupent en mémoire.

Bien que les objets en C++ puissent être sans nom (anonymes), nous leur donnons le plus souvent un nom à l'aide d'un identifiant. Un objet doté d'un nom est appelé une variable.

Point clé

Un objet sert à stocker une valeur en mémoire. Une variable est un objet qui possède un nom (identifiant).

Nommer nos objets nous permet de les référencer à nouveau plus loin dans le programme.

Terminologie

En programmation générale, le terme objet désigne généralement un objet sans nom en mémoire, une variable ou une fonction. En C++, le terme objet a une définition plus restreinte qui exclut les fonctions. Lorsque nous utilisons le terme objet dans cette série de tutoriels, c'est cette définition plus restreinte du C++ que nous entendons.

Définition de variable

Pour utiliser une variable dans notre programme, nous devons indiquer au compilateur que nous en voulons une. La manière la plus courante de le faire est d'utiliser un type particulier d'instruction de déclaration appelé définition (nous préciserons la différence entre déclaration et définition plus tard, dans la leçon 2.7 -- Déclarations anticipées et définitions).

Point clé

Une instruction de définition permet d'indiquer au compilateur que nous voulons utiliser une variable dans notre programme.

Voici un exemple de définition d'une variable nommée x :

int x; // définit une variable nommée x (de type int)

À la compilation (lorsque le programme est compilé), en rencontrant cette instruction, le compilateur note que nous voulons une variable portant le nom x et que cette variable a le type de données int (nous reviendrons sur les types de données dans un instant). À partir de ce point (avec certaines limitations que nous verrons dans une leçon ultérieure), chaque fois que nous utiliserons l'identifiant x dans notre code, le compilateur saura que nous faisons référence à cette variable.

Le compilateur gère pour nous tous les autres détails concernant cette variable, notamment la quantité de mémoire dont l'objet a besoin, le type de stockage dans lequel il sera placé (par exemple en RAM ou dans un registre du processeur), son emplacement par rapport aux autres objets, le moment de sa création et de sa destruction, etc.

On dit qu'une variable créée par une instruction de définition est définie à l'endroit où se trouve cette instruction. Pour l'instant, vos variables doivent être définies à l'intérieur de fonctions (comme dans main()).

Voici un programme complet contenant une instruction de définition de variable :

int main()
{
    int x; // définition de la variable x

    return 0;
}

Création de variable

À l'exécution (lorsque le programme est chargé en mémoire et lancé), chaque objet se voit attribuer un emplacement de stockage réel (dans la RAM ou un registre du processeur) qu'il peut utiliser pour stocker des valeurs. Le processus qui consiste à réserver du stockage pour l'usage d'un objet s'appelle allocation. Une fois l'allocation effectuée, l'objet a été créé et peut être utilisé.

Pour l'exemple, supposons que la variable x soit instanciée à l'emplacement mémoire 140. Chaque fois que le programme utilise la variable x, il accède à la valeur située à l'emplacement mémoire 140.

Point clé

Un objet est « créé » une fois qu'un stockage réel a été réservé pour son usage.

Lorsque le programme ci-dessus est exécuté, l'exécution commence en haut de main(). La mémoire de x est allouée. Puis le programme se termine.

Types de données

Jusqu'ici, nous avons vu que les objets sont des zones de stockage pouvant contenir une valeur (la manière exacte dont les données sont stockées fera l'objet d'une leçon ultérieure). Un type de données (plus couramment appelé simplement type) détermine le genre de valeur (par exemple un nombre, une lettre, un texte, etc.) que l'objet va stocker.

Dans l'exemple ci-dessus, notre variable x a reçu le type int, ce qui signifie que la variable x stockera une valeur entière. Un entier (integer) est un nombre qui peut s'écrire sans partie fractionnaire, comme 4, 27, 0, -2 ou -12. En bref, nous pouvons dire que x est une variable entière.

En C++, le type d'un objet doit être connu à la compilation, et ce type ne peut pas être modifié sans recompiler le programme. Cela signifie qu'une variable entière ne peut contenir que des valeurs entières. Si vous voulez stocker un autre genre de valeur, vous devrez utiliser un autre type.

Point clé

Le type de données d'un objet doit être connu à la compilation (afin que le compilateur sache quelle quantité de mémoire cet objet requiert).

Les entiers ne sont que l'un des nombreux types que C++ prend en charge nativement. À titre d'illustration, voici un autre exemple de définition d'une variable de type double :

double width; // définit une variable nommée width, de type double

C++ vous permet également de créer vos propres types personnalisés. C'est une chose que nous ferons beaucoup dans les prochaines leçons, et c'est en partie ce qui rend C++ puissant.

Dans ces chapitres introductifs, nous nous en tiendrons aux variables entières, car elles sont conceptuellement simples, mais nous explorerons bientôt bon nombre des autres types offerts par C++ (y compris double).

Définition de plusieurs variables

Il est possible de définir plusieurs variables du même type dans une seule instruction, en séparant les noms par une virgule. L'extrait de code suivant :

int a;
int b;

est en pratique équivalent à celui-ci :

int a, b;

Lorsque l'on définit plusieurs variables de cette façon, trois erreurs courantes sont souvent commises par les programmeurs débutants (aucune n'est grave, puisque le compilateur les signale et vous demande de les corriger) :

La première erreur consiste à donner un type à chaque variable lorsque l'on définit des variables les unes après les autres.

int a, int b; // faux (erreur de compilation)

int a, b; // correct

La deuxième erreur consiste à essayer de définir des variables de types différents dans la même instruction, ce qui n'est pas autorisé. Les variables de types différents doivent être définies dans des instructions séparées.

int a, double b; // faux (erreur de compilation)

int a; double b; // correct (mais déconseillé)

// correct et recommandé (plus facile à lire)
int a;
double b;

Nous aborderons la troisième difficulté dans la prochaine leçon, lorsque nous parlerons de l'initialisation des variables.

Bonne pratique

Bien que le langage vous le permette, évitez de définir plusieurs variables du même type dans une seule instruction. Définissez plutôt chaque variable dans une instruction séparée, sur sa propre ligne (puis utilisez un commentaire d'une ligne pour documenter son rôle).

Résumé

En C++, nous utilisons des objets pour accéder à la mémoire. Un objet nommé est appelé une variable. Chaque variable possède un identifiant, un type et une valeur (ainsi que quelques autres attributs qui ne sont pas pertinents ici). Le type d'une variable sert à déterminer comment la valeur en mémoire doit être interprétée.

Les variables sont en réalité créées à l'exécution, lorsque la mémoire est allouée pour leur usage.

Dans la prochaine leçon, nous verrons comment attribuer des valeurs à nos variables et comment les utiliser concrètement.

Quiz

Question n° 1

Qu'est-ce qu'une donnée ?

Solution

Une donnée est toute information qui peut être déplacée, traitée ou stockée par un ordinateur.

Question n° 2

Qu'est-ce qu'une valeur ?

Solution

Une valeur est une lettre (par exemple a), un nombre (par exemple 5), un texte (par exemple Hello) ou une instance de tout autre concept utile pouvant être représenté sous forme de données.

Question n° 3

Qu'est-ce qu'un objet ?

Solution

Un objet est une zone de stockage (généralement en mémoire) pouvant contenir une valeur.

Question n° 4

Qu'est-ce qu'une variable ?

Solution

Une variable est un objet qui possède un nom.

Question n° 5

Qu'est-ce qu'un identifiant ?

Solution

Un identifiant est le nom par lequel une variable est accédée.

Question n° 6

À quoi sert un type de données ?

Solution

Un type de données détermine le genre de valeur (par exemple un nombre, une lettre, un texte, etc.) que l'objet va stocker.

Question n° 7

Qu'est-ce qu'un entier ?

Solution

Un entier est un nombre qui peut s'écrire sans partie fractionnaire.
