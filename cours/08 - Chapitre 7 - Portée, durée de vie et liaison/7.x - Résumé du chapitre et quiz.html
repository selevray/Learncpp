7.x — Résumé du chapitre et quiz

Bilan du chapitre

Nous avons couvert beaucoup de matière dans ce chapitre. Bon travail, vous progressez très bien !

Une instruction composée ou bloc est un groupe de zéro instruction ou plus que le compilateur traite comme s'il s'agissait d'une seule instruction. Les blocs commencent par un symbole { et se terminent par un symbole }, les instructions à exécuter étant placées entre les deux. Les blocs peuvent être utilisés partout où une instruction unique est autorisée. Aucun point-virgule n'est nécessaire à la fin d'un bloc. Les blocs sont souvent utilisés avec les instructions if pour exécuter plusieurs instructions.

Les espaces de noms définis par l'utilisateur (user-defined namespaces) sont des espaces de noms que vous définissez vous-même pour vos propres déclarations. Les espaces de noms fournis par C++ (comme l'espace de noms global) ou par des bibliothèques (comme namespace std) ne sont pas considérés comme des espaces de noms définis par l'utilisateur.

Vous pouvez accéder à une déclaration d'un espace de noms via l'opérateur de résolution de portée (::). Cet opérateur indique au compilateur que l'identifiant spécifié par l'opérande de droite doit être recherché dans la portée de l'opérande de gauche. Si aucun opérande de gauche n'est fourni, l'espace de noms global est supposé.

Les variables locales sont des variables définies à l'intérieur d'une fonction (y compris les paramètres de fonction). Les variables locales ont une portée de bloc (block scope), ce qui signifie qu'elles sont visibles depuis leur point de définition jusqu'à la fin du bloc dans lequel elles sont définies. Les variables locales ont une durée de stockage automatique (automatic storage duration), ce qui signifie qu'elles sont créées au point de définition et détruites à la fin du bloc dans lequel elles sont définies.

Un nom déclaré dans un bloc imbriqué peut masquer (shadow ou name hiding) une variable de même nom dans un bloc extérieur. Cela doit être évité.

Les variables globales sont des variables définies en dehors de toute fonction. Les variables globales ont une portée de fichier (file scope), ce qui signifie qu'elles sont visibles depuis leur point de déclaration jusqu'à la fin du fichier dans lequel elles sont déclarées. Les variables globales ont une durée de stockage statique (static duration), ce qui signifie qu'elles sont créées au démarrage du programme et détruites à sa fin. Évitez autant que possible l'initialisation dynamique des variables statiques.

L'liaison (linkage) d'un identifiant détermine si d'autres déclarations de ce nom désignent ou non le même objet. Les variables locales n'ont pas de liaison. Les identifiants à liaison interne (internal linkage) peuvent être vus et utilisés dans un seul fichier, mais ne sont pas accessibles depuis d'autres fichiers. Les identifiants à liaison externe (external linkage) peuvent être vus et utilisés aussi bien dans le fichier où ils sont définis que depuis d'autres fichiers source (via une déclaration anticipée).

Évitez autant que possible les variables globales non constantes. Les globales const sont généralement considérées comme acceptables. Utilisez des variables inline (inline variables) pour les constantes globales si votre compilateur est compatible C++17.

Les variables locales peuvent recevoir une durée de stockage statique grâce au mot-clé static.

Un nom qualifié (qualified name) est un nom qui inclut une portée associée (par exemple std::string). Un nom non qualifié (unqualified name) est un nom qui ne comporte pas de qualificateur de portée (par exemple string).

Les instructions using (incluant les déclarations using et les directives using) peuvent être utilisées pour éviter d'avoir à qualifier les identifiants avec un espace de noms explicite. Une déclaration using permet d'utiliser un nom non qualifié (sans portée) comme alias d'un nom qualifié. Une directive using importe tous les identifiants d'un espace de noms dans la portée de la directive. Ces deux formes doivent généralement être évitées.

L'expansion en ligne (inline expansion) est un procédé dans lequel un appel de fonction est remplacé par le code de la définition de la fonction appelée. Une fonction déclarée avec le mot-clé inline est appelée fonction inline (inline function).

Les fonctions et variables inline ont deux exigences principales :

  • Le compilateur doit pouvoir voir la définition complète d'une fonction ou variable inline dans chaque unité de traduction où elle est utilisée (une déclaration anticipée ne suffit pas à elle seule). La définition peut apparaître après le point d'utilisation si une déclaration anticipée est également fournie.
  • Chaque définition d'une fonction ou variable inline doit être identique, sans quoi il en résulte un comportement indéfini.

Dans le C++ moderne, le terme inline a évolué pour signifier « plusieurs définitions sont autorisées ». Ainsi, une fonction inline est une fonction qui a le droit d'être définie dans plusieurs fichiers. Le C++17 a introduit les variables inline (inline variables), qui sont des variables autorisées à être définies dans plusieurs fichiers.

Les fonctions et variables inline sont particulièrement utiles pour les bibliothèques en-tête seul (header-only libraries), c'est-à-dire une ou plusieurs fichiers d'en-tête qui implémentent une fonctionnalité (aucun fichier .cpp n'est inclus).

Enfin, C++ prend en charge les espaces de noms anonymes (unnamed namespaces), qui traitent implicitement tout leur contenu comme s'il avait une liaison interne. C++ prend aussi en charge les espaces de noms inline (inline namespaces), qui offrent des capacités de versionnement élémentaires pour les espaces de noms.

Quiz

Question n° 1

Corrigez le programme suivant :

#include <iostream>

int main()
{
    std::cout << "Enter a positive number: ";
    int num{};
    std::cin >> num;


    if (num < 0)
        std::cout << "Negative number entered.  Making positive.\n";
        num = -num;

    std::cout << "You entered: " << num;

    return 0;
}
Solution 
#include <iostream>

int main()
{
    std::cout << "Enter a positive number: ";
    int num{};
    std::cin >> num;


    if (num < 0)
    { // un bloc est nécessaire ici pour que les deux instructions s'exécutent si num < 0
        std::cout << "Negative number entered.  Making positive.\n";
        num = -num;
    }

    std::cout << "You entered: " << num;

    return 0;
}

Question n° 2

Écrivez un fichier nommé constants.h qui permet d'exécuter le programme suivant. Si votre compilateur est compatible C++17, utilisez une variable constexpr inline. Sinon, utilisez une variable constexpr ordinaire. maxClassSize doit avoir la valeur 35.

main.cpp :

#include "constants.h"
#include <iostream>

int main()
{
    std::cout << "How many students are in your class? ";
    int students{};
    std::cin >> students;


    if (students > Constants::maxClassSize)
        std::cout << "There are too many students in this class";
    else
        std::cout << "This class isn't too large";

    return 0;
}
Solution

constants.h :

#ifndef CONSTANTS_H
#define CONSTANTS_H

namespace Constants
{
    inline constexpr int maxClassSize{ 35 }; // supprimez le mot-clé inline si votre compilateur n'est pas compatible C++17
}
#endif

main.cpp :

#include "constants.h"
#include <iostream>

int main()
{
    std::cout << "How many students are in your class? ";
    int students{};
    std::cin >> students;


    if (students > Constants::maxClassSize)
        std::cout << "There are too many students in this class";
    else
        std::cout << "This class isn't too large";

    return 0;
}

Question n° 3

Écrivez une fonction int accumulate(int x). Cette fonction doit renvoyer la somme de toutes les valeurs de x qui lui ont été transmises.

Indice

Indice : utilisez une variable locale statique pour stocker la somme.

Le programme suivant doit s'exécuter et produire la sortie indiquée dans les commentaires :

#include <iostream>

int main()
{
    std::cout << accumulate(4) << '\n'; // affiche 4
    std::cout << accumulate(3) << '\n'; // affiche 7
    std::cout << accumulate(2) << '\n'; // affiche 9
    std::cout << accumulate(1) << '\n'; // affiche 10

    return 0;
}
Solution 
#include <iostream>

int accumulate(int x)
{
    static int sum{ 0 }; // sum est initialisée à 0 au démarrage du programme
    sum += x;
    return sum;
}

int main()
{
    std::cout << accumulate(4) << '\n'; // affiche 4
    std::cout << accumulate(3) << '\n'; // affiche 7
    std::cout << accumulate(2) << '\n'; // affiche 9
    std::cout << accumulate(1) << '\n'; // affiche 10

    return 0;
}

3b) Bonus : quels sont deux inconvénients de la fonction accumulate() ci-dessus ?

Solution
  1. Il n'existe pas de moyen conventionnel de réinitialiser l'accumulation sans redémarrer le programme.
  2. Il n'existe pas de moyen conventionnel de faire fonctionner plusieurs accumulateurs en parallèle.

Pour les lecteurs avancés

Ces deux inconvénients peuvent être résolus en utilisant des foncteurs (21.10 -- Surcharge de l'opérateur parenthèses) au lieu d'une variable locale statique.
