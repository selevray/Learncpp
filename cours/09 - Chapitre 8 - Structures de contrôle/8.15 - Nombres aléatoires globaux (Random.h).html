8.15 — Nombres aléatoires globaux (Random.h)

Que se passe-t-il si nous voulons utiliser un générateur de nombres aléatoires dans plusieurs fonctions ou fichiers ? Une solution consiste à créer (et initialiser) notre PRNG dans la fonction main(), puis à le passer partout où nous en avons besoin. Mais cela représente beaucoup de passages de paramètres pour quelque chose que nous n'utilisons peut-être que de façon sporadique, et à de nombreux endroits différents. Faire transiter un tel objet dans tout notre code encombrerait fortement celui-ci.

Autre possibilité : créer une variable locale static de type std::mt19937 dans chaque fonction qui en a besoin (static pour qu'elle ne soit initialisée qu'une seule fois). Cependant, il est excessif que chaque fonction utilisant un générateur aléatoire définisse et initialise son propre générateur local, et le faible nombre d'appels à chaque générateur peut dégrader la qualité des résultats.

Ce que nous voulons vraiment, c'est un unique objet PRNG que nous puissions partager et utiliser partout, dans toutes nos fonctions et tous nos fichiers. La meilleure option consiste à créer un objet générateur de nombres aléatoires global (à l'intérieur d'un espace de noms !). Vous vous souvenez que nous vous avons conseillé d'éviter les variables globales non const ? Ce cas constitue une exception.

Voici une solution simple, uniquement constituée d'un en-tête, que vous pouvez #include dans tout fichier de code ayant besoin d'accéder à un std::mt19937 aléatoire et initialisé automatiquement :

Random.h :

#ifndef RANDOM_MT_H
#define RANDOM_MT_H

#include <chrono>
#include <random>

// This header-only Random namespace implements a self-seeding Mersenne Twister.
// Requires C++17 or newer.
// It can be #included into as many code files as needed (The inline keyword avoids ODR violations)
// Freely redistributable, courtesy of learncpp.com (https://www.learncpp.com/cpp-tutorial/global-random-numbers-random-h/)
namespace Random
{
    // Returns a seeded Mersenne Twister
    // Note: we'd prefer to return a std::seed_seq (to initialize a std::mt19937), but std::seed can't be copied, so it can't be returned by value.
    // Instead, we'll create a std::mt19937, seed it, and then return the std::mt19937 (which can be copied).
    inline std::mt19937 generate()
    {
        std::random_device rd{};

        // Create seed_seq with clock and 7 random numbers from std::random_device
        std::seed_seq ss{
            static_cast<std::seed_seq::result_type>(std::chrono::steady_clock::now().time_since_epoch().count()),
                rd(), rd(), rd(), rd(), rd(), rd(), rd() };

        return std::mt19937{ ss };
    }

    // Here's our global std::mt19937 object.
    // The inline keyword means we only have one global instance for our whole program.
    inline std::mt19937 mt{ generate() }; // generates a seeded std::mt19937 and copies it into our global object

    // Generate a random int between [min, max] (inclusive)
        // * also handles cases where the two arguments have different types but can be converted to int
    inline int get(int min, int max)
    {
        return std::uniform_int_distribution{min, max}(mt);
    }

    // The following function templates can be used to generate random numbers in other cases

    // See https://www.learncpp.com/cpp-tutorial/function-template-instantiation/
    // You can ignore these if you don't understand them

    // Generate a random value between [min, max] (inclusive)
    // * min and max must have the same type
    // * return value has same type as min and max
    // * Supported types:
    // *    short, int, long, long long
    // *    unsigned short, unsigned int, unsigned long, or unsigned long long
    // Sample call: Random::get(1L, 6L);             // returns long
    // Sample call: Random::get(1u, 6u);             // returns unsigned int
    template <typename T>
    T get(T min, T max)
    {
        return std::uniform_int_distribution<T>{min, max}(mt);
    }

    // Generate a random value between [min, max] (inclusive)
    // * min and max can have different types
        // * return type must be explicitly specified as a template argument
    // * min and max will be converted to the return type
    // Sample call: Random::get<std::size_t>(0, 6);  // returns std::size_t
    // Sample call: Random::get<std::size_t>(0, 6u); // returns std::size_t
    // Sample call: Random::get<std::int>(0, 6u);    // returns int
    template <typename R, typename S, typename T>
    R get(S min, T max)
    {
        return get<R>(static_cast<R>(min), static_cast<R>(max));
    }
}

#endif

Utiliser Random.h

Générer des nombres aléatoires avec ce fichier est aussi simple que de suivre ces trois étapes :

  1. Copiez/collez le code ci-dessus dans un fichier nommé Random.h dans le répertoire de votre projet, puis enregistrez-le. Vous pouvez éventuellement ajouter Random.h à votre projet.
  2. Écrivez #include "Random.h" dans tout fichier .cpp de votre projet qui a besoin de générer des nombres aléatoires.
  3. Appelez Random::get(min, max) pour générer un nombre aléatoire compris entre min et max (inclus). Aucune initialisation ni configuration n'est nécessaire.

Voici un programme d'exemple illustrant différentes utilisations de Random.h :

main.cpp :

#include "Random.h" // defines Random::mt, Random::get(), and Random::generate()
#include <cstddef> // for std::size_t
#include <iostream>

int main()
{
    // We can call Random::get() to generate random integral values
    // If the two arguments have the same type, the returned value will have that same type.
    std::cout << Random::get(1, 6) << '\n';   // returns int between 1 and 6
    std::cout << Random::get(1u, 6u) << '\n'; // returns unsigned int between 1 and 6

        // In cases where we have two arguments with different types
        // and/or if we want the return type to be different than the argument types
        // We must specify the return type using a template type argument (between the angled brackets)
    // See https://www.learncpp.com/cpp-tutorial/function-template-instantiation/
    std::cout << Random::get<std::size_t>(1, 6u) << '\n'; // returns std::size_t between 1 and 6

    // If we have our own distribution, we can access Random::mt directly

    // Let's create a reusable random number generator that generates uniform numbers between 1 and 6
    std::uniform_int_distribution die6{ 1, 6 }; // for C++14, use std::uniform_int_distribution<> die6{ 1, 6 };
    for (int count{ 1 }; count <= 10; ++count)
    {
        std::cout << die6(Random::mt) << '\t'; // generate a roll of the die here
    }

    std::cout << '\n';

    return 0;
}

Quelques remarques sur l'implémentation de Random.h (facultatif)

Normalement, définir des variables et des fonctions dans un fichier d'en-tête provoquerait des violations de la règle de définition unique (ODR) lorsque cet en-tête est inclus dans plusieurs fichiers source. Cependant, nous avons déclaré inline notre variable mt ainsi que les fonctions qui la soutiennent. Cela nous permet d'avoir des définitions dupliquées sans violer l'ODR, tant que toutes ces définitions sont identiques. Comme nous #includeons ces définitions depuis un fichier d'en-tête (plutôt que de les saisir manuellement ou de les copier/coller), nous pouvons garantir qu'elles sont identiques. Les fonctions et variables inline ont été ajoutées au langage principalement pour rendre possible ce type de fonctionnalité uniquement constituée d'en-têtes.

Contenu associé

Nous abordons les fonctions et variables inline dans la leçon 7.9 -- Fonctions et variables inline.

L'autre difficulté à surmonter concerne l'initialisation de notre objet global Random::mt, car nous voulons qu'il s'initialise automatiquement, afin de ne pas avoir à penser à appeler explicitement une fonction d'initialisation pour qu'il fonctionne correctement. Notre initialiseur doit être une expression. Or, pour initialiser un std::mt19937, nous avons besoin de plusieurs objets auxiliaires (un std::random_device et un std::seed_seq), qui doivent être définis sous forme d'instructions. C'est là qu'une fonction auxiliaire s'avère utile. Un appel de fonction est une expression, nous pouvons donc utiliser la valeur de retour d'une fonction comme initialiseur. Et à l'intérieur même de la fonction, nous pouvons employer toute combinaison d'instructions nécessaire. Ainsi, notre fonction generate() crée et renvoie un objet std::mt19937 entièrement initialisé (à partir de l'horloge système et de std::random_device), que nous utilisons comme initialiseur de notre objet global Random::mt.
