8.11 — Instructions break et continue

Break

Bien que vous ayez déjà vu l'instruction break dans le contexte des instructions switch (8.5 -- Bases de l'instruction switch), elle mérite un traitement plus complet, car elle peut aussi être utilisée avec d'autres types d'instructions de contrôle de flux. L'instruction break provoque la fin d'une boucle while, do-while, for ou d'une instruction switch : l'exécution se poursuit avec l'instruction suivant la boucle ou le switch quitté.

Interrompre un switch

Dans le contexte d'une instruction switch, un break est généralement utilisé à la fin de chaque cas pour signifier que le cas est terminé (ce qui empêche la poursuite vers les cas suivants, appelée fallthrough) :

#include <iostream>

void printMath(int x, int y, char ch)
{
    switch (ch)
    {
    case '+':
        std::cout << x << " + " << y << " = " << x + y << '\n';
        break; // ne pas poursuivre vers le cas suivant
    case '-':
        std::cout << x << " - " << y << " = " << x - y << '\n';
        break; // ne pas poursuivre vers le cas suivant
    case '*':
        std::cout << x << " * " << y << " = " << x * y << '\n';
        break; // ne pas poursuivre vers le cas suivant
    case '/':
        std::cout << x << " / " << y << " = " << x / y << '\n';
        break;
    }
}

int main()
{
    printMath(2, 3, '+');

    return 0;
}

Consultez la leçon 8.6 -- Fallthrough et portée dans les switch pour plus d'informations sur le fallthrough, ainsi que d'autres exemples.

Interrompre une boucle

Dans le contexte d'une boucle, une instruction break peut être utilisée pour terminer la boucle prématurément. L'exécution se poursuit avec l'instruction suivant la fin de la boucle.

Par exemple :

#include <iostream>

int main()
{
    int sum{ 0 };

    // Permettre à l'utilisateur de saisir jusqu'à 10 nombres
    for (int count{ 0 }; count < 10; ++count)
    {
        std::cout << "Entrez un nombre à ajouter, ou 0 pour quitter : ";
        int num{};
        std::cin >> num;

        // quitter la boucle si l'utilisateur saisit 0
        if (num == 0)
            break; // quitter la boucle immédiatement

        // sinon, ajouter le nombre à notre somme
        sum += num;
    }

    // l'exécution reprend ici après le break
    std::cout << "La somme de tous les nombres saisis est : " << sum << '\n';

    return 0;
}

Ce programme permet à l'utilisateur de saisir jusqu'à 10 nombres et affiche à la fin la somme de tous les nombres saisis. Si l'utilisateur saisit 0, le break met fin à la boucle prématurément (avant que 10 nombres aient été saisis).

Voici un exemple d'exécution du programme ci-dessus :


Entrez un nombre à ajouter, ou 0 pour quitter : 5
Entrez un nombre à ajouter, ou 0 pour quitter : 2
Entrez un nombre à ajouter, ou 0 pour quitter : 1
Entrez un nombre à ajouter, ou 0 pour quitter : 0
La somme de tous les nombres saisis est : 8

Un break est également un moyen courant de sortir d'une boucle infinie volontaire :

#include <iostream>

int main()
{
    while (true) // boucle infinie
    {
        std::cout << "Entrez 0 pour quitter ou tout autre entier pour continuer : ";
        int num{};
        std::cin >> num;

        // quitter la boucle si l'utilisateur saisit 0
        if (num == 0)
            break;
    }

    std::cout << "Nous sommes sortis !\n";

    return 0;
}

Exemple d'exécution du programme ci-dessus :


Entrez 0 pour quitter ou tout autre entier pour continuer : 5
Entrez 0 pour quitter ou tout autre entier pour continuer : 3
Entrez 0 pour quitter ou tout autre entier pour continuer : 0
Nous sommes sortis !

Break ou return

Les nouveaux programmeurs ont parfois du mal à comprendre la différence entre break et return. Une instruction break termine le switch ou la boucle, et l'exécution se poursuit à la première instruction située après le switch ou la boucle. Une instruction return termine la fonction entière dans laquelle se trouve la boucle, et l'exécution reprend à l'endroit où la fonction a été appelée.

#include <iostream>

int breakOrReturn()
{
    while (true) // boucle infinie
    {
        std::cout << "Entrez 'b' pour break ou 'r' pour return : ";
        char ch{};
        std::cin >> ch;

        if (ch == 'b')
            break; // l'exécution se poursuivra à la première instruction après la boucle

        if (ch == 'r')
            return 1; // return fera revenir immédiatement la fonction à l'appelant (ici, main())
    }

    // la sortie de la boucle par break reprend ici

    std::cout << "Nous sommes sortis de la boucle\n";

    return 0;
}

int main()
{
    int returnValue{ breakOrReturn() };
    std::cout << "La fonction breakOrReturn a renvoyé " << returnValue << '\n';

    return 0;
}

Voici deux exécutions de ce programme :


Entrez 'b' pour break ou 'r' pour return : r
La fonction breakOrReturn a renvoyé 1


Entrez 'b' pour break ou 'r' pour return : b
Nous sommes sortis de la boucle
La fonction breakOrReturn a renvoyé 0

Continue

L'instruction continue offre un moyen pratique de terminer l'itération courante d'une boucle sans mettre fin à la boucle entière.

Voici un exemple d'utilisation de continue :

#include <iostream>

int main()
{
    for (int count{ 0 }; count < 10; ++count)
    {
        // si le nombre est divisible par 4, passer cette itération
        if ((count % 4) == 0)
            continue; // passer à l'itération suivante

        // si le nombre n'est pas divisible par 4, continuer
        std::cout << count << '\n';

        // l'instruction continue saute jusqu'ici
    }

    return 0;
}

Ce programme affiche tous les nombres de 0 à 9 qui ne sont pas divisibles par 4 :


1
2
3
5
6
7
9

Une instruction continue fait sauter le point d'exécution courant jusqu'au bas du corps de la boucle en cours.

Dans le cas d'une boucle for, l'instruction de fin de la boucle (dans l'exemple ci-dessus, ++count) s'exécute tout de même après un continue (puisque celui-ci intervient avant la fin du corps de la boucle).

Soyez prudent lorsque vous utilisez une instruction continue avec des boucles while ou do-while. Ces boucles modifient généralement la valeur des variables utilisées dans la condition à l'intérieur du corps de la boucle. Si l'utilisation d'un continue fait sauter ces lignes, la boucle peut devenir infinie !

Considérez le programme suivant :

#include <iostream>

int main()
{
    int count{ 0 };
    while (count < 10)
    {
        if (count == 5)
            continue; // saute à la fin du corps de la boucle

        std::cout << count << '\n';

        ++count; // cette instruction n'est jamais exécutée une fois count égal à 5

        // l'instruction continue saute jusqu'ici
    }

    return 0;
}

Ce programme est censé afficher tous les nombres entre 0 et 9, sauf 5. Mais il affiche en réalité :


0
1
2
3
4

puis entre dans une boucle infinie. Lorsque count vaut 5, l'instruction if évalue à true, et le continue fait sauter l'exécution jusqu'au bas de la boucle. La variable count n'est jamais incrémentée. Par conséquent, à l'itération suivante, count vaut toujours 5, la condition du if est toujours vraie, et le programme boucle indéfiniment.

Bien sûr, vous savez déjà que si vous disposez d'une variable compteur évidente, vous devriez utiliser une boucle for plutôt qu'une boucle while ou do while.

Le débat sur l'utilisation de break et continue

De nombreux manuels mettent en garde les lecteurs contre l'utilisation de break et continue dans les boucles, à la fois parce qu'ils font sauter le flux d'exécution d'un endroit à un autre, et parce qu'ils peuvent rendre la logique plus difficile à suivre. Par exemple, un break au milieu d'une logique complexe peut passer inaperçu, ou il peut ne pas être évident dans quelles conditions il doit être déclenché.

Cependant, utilisés à bon escient, break et continue peuvent rendre les boucles plus lisibles en limitant le nombre de blocs imbriqués et en réduisant le besoin de logique de boucle compliquée.

Par exemple, considérez le programme suivant :

#include <iostream>

int main()
{
    int count{ 0 }; // compte le nombre de fois où la boucle itère
    bool keepLooping { true }; // contrôle si la boucle se termine ou non
    while (keepLooping)
    {
        std::cout << "Entrez 'e' pour quitter cette boucle ou tout autre caractère pour continuer : ";
        char ch{};
        std::cin >> ch;

        if (ch == 'e')
            keepLooping = false;
        else
        {
            ++count;
            std::cout << "Nous avons itéré " << count << " fois\n";
        }
    }

    return 0;
}

Ce programme utilise une variable booléenne pour contrôler si la boucle continue ou non, ainsi qu'un bloc imbriqué qui ne s'exécute que si l'utilisateur ne quitte pas.

Voici une version plus facile à comprendre, utilisant une instruction break :

#include <iostream>

int main()
{
    int count{ 0 }; // compte le nombre de fois où la boucle itère
    while (true) // boucler jusqu'à ce que l'utilisateur termine
    {
        std::cout << "Entrez 'e' pour quitter cette boucle ou tout autre caractère pour continuer : ";
        char ch{};
        std::cin >> ch;

        if (ch == 'e')
            break;

        ++count;
        std::cout << "Nous avons itéré " << count << " fois\n";
    }

    return 0;
}

Dans cette version, grâce à une seule instruction break, nous avons évité l'utilisation d'une variable booléenne (et la nécessité de comprendre à la fois son usage prévu et l'endroit où sa valeur est modifiée), une instruction else et un bloc imbriqué.

L'instruction continue est utilisée de manière plus efficace en haut d'une boucle for, pour sauter des itérations lorsqu'une certaine condition est remplie. Cela nous permet d'éviter un bloc imbriqué.

Par exemple, au lieu de ceci :

#include <iostream>

int main()
{
    for (int count{ 0 }; count < 10; ++count)
    {
        // si le nombre n'est pas divisible par 4...
        if ((count % 4) != 0) // bloc imbriqué
        {
                // afficher le nombre
                std::cout << count << '\n';
        }
    }

    return 0;
}

Nous pouvons écrire ceci :

#include <iostream>

int main()
{
    for (int count{ 0 }; count < 10; ++count)
    {
        // si le nombre est divisible par 4, passer cette itération
        if ((count % 4) == 0)
            continue;

        // aucun bloc imbriqué nécessaire

        std::cout << count << '\n';
    }

    return 0;
}

Minimiser le nombre de variables utilisées et limiter le nombre de blocs imbriqués améliorent la compréhension du code plus qu'un break ou un continue ne la nuit. Pour cette raison, nous estimons qu'un usage judicieux de break ou continue est acceptable.

Bonne pratique

Utilisez break et continue lorsqu'ils simplifient la logique de votre boucle.

Le débat sur l'utilisation des retours anticipés

Un argument similaire peut être avancé pour les instructions return. Une instruction return qui n'est pas la dernière instruction d'une fonction est appelée un retour anticipé (early return). De nombreux programmeurs estiment que les retours anticipés doivent être évités. Une fonction qui ne possède qu'une seule instruction return en bas de la fonction a une certaine simplicité : on peut supposer que la fonction prend ses arguments, effectue sa logique et renvoie un résultat sans écart. Les retours supplémentaires compliquent la logique.

L'argument inverse est que les retours anticipés permettent à votre fonction de se terminer dès qu'elle a fini, ce qui évite de lire une logique inutile et réduit le besoin de blocs imbriqués conditionnels, ce qui rend votre code plus lisible.

Certains développeurs adoptent un compromis : ne recourir aux retours anticipés qu'en début de fonction pour valider les paramètres (détecter les mauvais arguments reçus), puis n'avoir qu'un seul return ensuite.

Notre position est que les retours anticipés sont plus utiles que nuisibles, mais nous reconnaissons qu'il y a un peu d'art dans cette pratique.

Bonne pratique

Utilisez les retours anticipés lorsqu'ils simplifient la logique de votre fonction.
