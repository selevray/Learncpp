8.1 — Introduction au contrôle de flux

Lorsqu'un programme est exécuté, le processeur commence l'exécution au début de main(), exécute un certain nombre d'instructions (dans l'ordre séquentiel par défaut), puis le programme se termine à la fin de main(). La séquence précise d'instructions exécutées par le processeur s'appelle le chemin d'exécution du programme (ou simplement chemin).

Considérons le programme suivant :

#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";

    int x{};
    std::cin >> x;

    std::cout << "You entered " << x << '\n';

    return 0;
}

Le chemin d'exécution de ce programme comprend les lignes 5, 7, 8, 10 et 12, dans cet ordre. C'est un exemple de programme linéaire (ou « en ligne droite », straight-line program). Les programmes linéaires suivent le même chemin (exécutent les mêmes instructions dans le même ordre) à chaque exécution.

Cependant, ce n'est souvent pas ce que nous souhaitons. Par exemple, si nous demandons une saisie à l'utilisateur et qu'il entre une valeur invalide, nous aimerions idéalement lui demander de faire un autre choix. Ce n'est pas possible dans un programme linéaire. En effet, l'utilisateur peut saisir des valeurs invalides à plusieurs reprises, si bien que le nombre de fois où nous devrons lui redemander un choix n'est connu qu'à l'exécution.

Heureusement, C++ fournit plusieurs instructions de contrôle de flux (aussi appelées instructions de flux de contrôle), c'est-à-dire des instructions qui permettent au programmeur de modifier le chemin d'exécution normal du programme. Vous en avez déjà vu un exemple avec les instructions if (présentées dans la leçon 4.10 -- Introduction aux instructions if), qui nous permettent d'exécuter une instruction seulement si une expression conditionnelle est vraie.

Lorsqu'une instruction de contrôle de flux fait passer le point d'exécution à une instruction non séquentielle, on parle de branchement.

Catégories d'instructions de contrôle de flux

Catégorie Signification Implémentée en C++ par
Instructions conditionnelles Fait exécuter une séquence de code seulement si une condition est remplie. if, else, switch
Sauts Demande au processeur de reprendre l'exécution des instructions à un autre emplacement. goto, break, continue
Appels de fonction Saute à un autre emplacement, puis revient. appels de fonction, return
Boucles Exécute répétitivement une séquence de code zéro fois ou plus, jusqu'à ce qu'une condition soit remplie. while, do-while, for, boucle sur intervalle (ranged-for)
Arrêts Termine le programme. std::exit(), std::abort()
Exceptions Une forme particulière de contrôle de flux conçue pour la gestion des erreurs. try, throw, catch

Nous étudierons toutes ces catégories en détail tout au long de ce chapitre, à l'exception des exceptions (ha !), auxquelles nous consacrerons un chapitre entier plus tard (chapitre 27).

Avant ce chapitre, le nombre de choses que vous pouviez faire réaliser à un programme était assez limité. Savoir contrôler le flux de votre programme (en particulier à l'aide des boucles) rend possibles toutes sortes de choses intéressantes ! Vous ne serez plus limité à des programmes jouets : vous pourrez écrire des programmes réellement utiles.

C'est ici que le plaisir commence vraiment. Alors, allons-y !
