8.4 — Instructions if constexpr

Normalement, la condition d'une instruction if est évaluée à l'exécution.

Cependant, considérons le cas où la condition est une expression constante, comme dans l'exemple suivant :

#include <iostream>

int main()
{
    constexpr double gravity{ 9.8 };

    // rappel : les littéraux à virgule flottante de faible précision du même type peuvent être comparés pour l'égalité
    if (gravity == 9.8) // expression constante, toujours vraie
        std::cout << "Gravity is normal.\n";   // sera toujours exécutée
    else
        std::cout << "We are not on Earth.\n"; // ne sera jamais exécutée

    return 0;
}

Comme gravity est constexpr et initialisée avec la valeur 9.8, la condition gravity == 9.8 doit valoir true. Par conséquent, l'instruction du else ne sera jamais exécutée.

Évaluer à l'exécution une condition constexpr est un gaspillage, puisque le résultat ne变era jamais. Il est également inutile de compiler dans l'exécutable du code qui ne pourra jamais être exécuté.

Instructions if constexpr (C++17)

C++17 introduit l'instruction if constexpr, qui exige que la condition soit une expression constante. La condition d'une instruction if constexpr est évaluée à la compilation.

Si la condition constexpr vaut true, l'ensemble du if-else est remplacé par l'instruction du cas vrai. Si la condition constexpr vaut false, l'ensemble du if-else est remplacé par l'instruction du cas faux (si elle existe) ou par rien (s'il n'y a pas de else).

Pour utiliser une instruction if constexpr, on ajoute le mot-clé constexpr après if :

#include <iostream>

int main()
{
    constexpr double gravity{ 9.8 };

    if constexpr (gravity == 9.8) // utilise maintenant constexpr if
        std::cout << "Gravity is normal.\n";
    else
        std::cout << "We are not on Earth.\n";

    return 0;
}

Lorsque le code ci-dessus est compilé, le compilateur évalue la condition à la compilation, constate qu'elle vaut toujours true, et ne conserve que l'instruction unique std::cout << "Gravity is normal.\n";.

Autrement dit, il compile ceci :

int main()
{
    constexpr double gravity{ 9.8 };

    std::cout << "Gravity is normal.\n";

    return 0;
}

Bonne pratique

Privilégiez les instructions if constexpr aux instructions if non constexpr lorsque la condition est une expression constante.

Les compilateurs modernes et les instructions if avec des conditions constexpr (C++17)

À des fins d'optimisation, les compilateurs modernes traitent généralement les instructions if non constexpr dont la condition est constexpr comme s'il s'agissait d'instructions if constexpr. Cependant, ils ne sont pas obligés de le faire.

Un compilateur qui rencontre une instruction if non constexpr avec une condition constexpr peut émettre un avertissement vous conseillant d'utiliser if constexpr à la place. Cela garantit que l'évaluation à la compilation aura lieu (même si les optimisations sont désactivées).
