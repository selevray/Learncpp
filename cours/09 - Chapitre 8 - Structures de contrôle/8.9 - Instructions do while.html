8.9 — Instructions do while

Imaginons que nous voulions afficher à l'utilisateur un menu et lui demander de faire un choix, puis de le redemander si son choix est invalide. Il est clair que le menu et la saisie doivent se trouver dans une boucle (pour pouvoir demander à l'utilisateur une saisie valide autant de fois que nécessaire), mais quel type de boucle choisir ?

Comme une boucle while évalue sa condition au départ, ce n'est pas un choix idéal. Nous pourrions résoudre le problème ainsi :

#include <iostream>

int main()
{
    // selection doit être déclarée en dehors de la boucle while, pour pouvoir l'utiliser ensuite
    int selection {}; // initialisée par valeur à 0

    while (selection < 1 || selection > 4)
    {
        std::cout << "Please make a selection: \n";
        std::cout << "1) Addition\n";
        std::cout << "2) Subtraction\n";
        std::cout << "3) Multiplication\n";
        std::cout << "4) Division\n";
        std::cin >> selection;
    }

    // faire quelque chose avec selection ici
    // par exemple une instruction switch

    std::cout << "You selected option #" << selection << '\n';

    return 0;
}

Mais cela ne fonctionne que parce que la valeur initiale 0 de selection ne fait pas partie des valeurs valides (1, 2, 3 ou 4). Et si 0 était un choix valide ? Il faudrait alors choisir une autre valeur initiale pour représenter « invalide », ce qui nous ferait introduire des nombres magiques (5.2 -- Littéraux) dans notre code.

Nous pourrions aussi ajouter une nouvelle variable pour suivre la validité de la saisie :

#include <iostream>

int main()
{
    int selection {};
    bool invalid { true }; // nouvelle variable uniquement pour contrôler la boucle

    while (invalid)
    {
        std::cout << "Please make a selection: \n";
        std::cout << "1) Addition\n";
        std::cout << "2) Subtraction\n";
        std::cout << "3) Multiplication\n";
        std::cout << "4) Division\n";

        std::cin >> selection;
        invalid = (selection < 1 || selection > 4);
    }

    // faire quelque chose avec selection ici
    // par exemple une instruction switch

    std::cout << "You selected option #" << selection << '\n';

    return 0;
}

Cette solution évite le nombre magique, mais elle introduit une variable supplémentaire uniquement pour garantir que la boucle s'exécute au moins une fois, ce qui ajoute de la complexité et des risques d'erreurs.

Instructions do while

Pour résoudre des problèmes de ce type, C++ propose l'instruction do-while (do while) :


do
    statement; // peut être une instruction simple ou un bloc d'instructions
while (condition);

Une instruction do while est une structure de boucle qui fonctionne comme une boucle while, à ceci près que l'instruction est toujours exécutée au moins une fois. Après l'exécution de l'instruction, la boucle do-while évalue la condition. Si elle vaut true, le flux d'exécution revient au début de la boucle do-while et l'exécute à nouveau.

Voici l'exemple ci-dessus réécrit avec une boucle do-while au lieu d'une boucle while :

#include <iostream>

int main()
{
    // selection doit être déclarée en dehors de la boucle do-while, pour pouvoir l'utiliser ensuite
    int selection {};

    do
    {
        std::cout << "Please make a selection: \n";
        std::cout << "1) Addition\n";
        std::cout << "2) Subtraction\n";
        std::cout << "3) Multiplication\n";
        std::cout << "4) Division\n";
        std::cin >> selection;
    }
    while (selection < 1 || selection > 4);

    // faire quelque chose avec selection ici
    // par exemple une instruction switch

    std::cout << "You selected option #" << selection << '\n';

    return 0;
}

Nous avons ainsi évité à la fois les nombres magiques et les variables supplémentaires.

Un point important dans l'exemple ci-dessus : la variable selection doit être déclarée en dehors du bloc do. Si elle était déclarée à l'intérieur, elle serait détruite à la fin du bloc, c'est-à-dire avant l'évaluation de la condition. Or nous avons besoin de cette variable dans la condition du while. Par conséquent, selection doit être déclarée en dehors du bloc do (même si elle n'était pas utilisée plus loin dans la fonction).

En pratique, les boucles do-while ne sont pas très courantes. Placer la condition en bas de la boucle masque la condition de boucle, ce qui peut conduire à des erreurs. Pour cette raison, de nombreux développeurs recommandent d'éviter complètement les boucles do-while. Nous adoptons une position plus nuancée : à choix équivalent, nous recommandons de préférer la boucle while à la boucle do-while.

Bonne pratique

À choix équivalent, préférez la boucle while à la boucle do-while.
