21.10 — Surcharge de l'opérateur parenthèse

Tous les opérateurs surchargés que vous avez vus jusqu'ici permettent de définir le type des paramètres de l'opérateur, mais pas leur nombre (qui est fixé par le type de l'opérateur). Par exemple, operator== prend toujours deux paramètres, alors que operator! en prend toujours un. L'opérateur parenthèse (operator()) est un opérateur particulièrement intéressant, car il permet de faire varier à la fois le type et le nombre de paramètres qu'il reçoit.

Deux points sont à garder à l'esprit. Premièrement, l'opérateur parenthèse doit être implémenté comme une fonction membre. Deuxièmement, en C++ non orienté objet, l'opérateur () sert à appeler des fonctions. Dans le cas des classes, operator() est simplement un opérateur ordinaire qui appelle une fonction (nommée operator()), comme n'importe quel autre opérateur surchargé.

Un exemple

Prenons un exemple qui se prête à la surcharge de cet opérateur :

class Matrix
{
private:
    double data[4][4]{};
};

Les matrices sont un élément clé de l'algèbre linéaire, et sont souvent utilisées pour la modélisation géométrique et l'infographie 3D. Dans ce cas, il vous suffit de reconnaître que la classe Matrix est un tableau bidimensionnel de doubles de taille 4 × 4.

Dans la leçon sur la surcharge de l'opérateur crochet, vous avez appris que l'on pouvait surcharger operator[] pour donner un accès direct à un tableau unidimensionnel privé. Cependant, ici, nous voulons accéder à un tableau bidimensionnel privé. Avant le C++23, operator[] est limité à un seul paramètre, et ne suffit donc pas pour indexer directement un tableau à deux dimensions.

En revanche, comme l'opérateur () peut prendre autant de paramètres que nous le souhaitons, nous pouvons déclarer une version de operator() qui prend deux paramètres entiers d'indice, et l'utiliser pour accéder à notre tableau bidimensionnel. Voici un exemple :

#include <cassert> // pour assert()

class Matrix
{
private:
    double m_data[4][4]{};

public:
    double& operator()(int row, int col);
    double operator()(int row, int col) const; // pour les objets const
};

double& Matrix::operator()(int row, int col)
{
    assert(row >= 0 && row < 4);
    assert(col >= 0 && col < 4);

    return m_data[row][col];
}

double Matrix::operator()(int row, int col) const
{
    assert(row >= 0 && row < 4);
    assert(col >= 0 && col < 4);

    return m_data[row][col];
}

Nous pouvons maintenant déclarer une Matrix et accéder à ses éléments ainsi :

#include <iostream>

int main()
{
    Matrix matrix;
    matrix(1, 2) = 4.5;
    std::cout << matrix(1, 2) << '\n';

    return 0;
}

ce qui produit le résultat :


4.5

Surchargeons maintenant à nouveau l'opérateur (), cette fois sous une forme qui ne prend aucun paramètre :

#include <cassert> // pour assert()
class Matrix
{
private:
    double m_data[4][4]{};

public:
    double& operator()(int row, int col);
    double operator()(int row, int col) const;
    void operator()();
};

double& Matrix::operator()(int row, int col)
{
    assert(row >= 0 && row < 4);
    assert(col >= 0 && col < 4);

    return m_data[row][col];
}

double Matrix::operator()(int row, int col) const
{
    assert(row >= 0 && row < 4);
    assert(col >= 0 && col < 4);

    return m_data[row][col];
}

void Matrix::operator()()
{
    // réinitialise tous les éléments de la matrice à 0.0
    for (int row{ 0 }; row < 4; ++row)
    {
        for (int col{ 0 }; col < 4; ++col)
        {
            m_data[row][col] = 0.0;
        }
    }
}

Et voici notre nouvel exemple :

#include <iostream>

int main()
{
    Matrix matrix{};
    matrix(1, 2) = 4.5;
    matrix(); // efface la matrice
    std::cout << matrix(1, 2) << '\n';

    return 0;
}

ce qui produit le résultat :


0

Comme l'opérateur () est si souple, on peut être tenté de l'utiliser à de nombreuses fins différentes. Cependant, cela est fortement déconseillé, car le symbole () ne donne aucune indication sur ce que fait l'opérateur. Dans notre exemple ci-dessus, il aurait mieux valu écrire la fonctionnalité d'effacement sous la forme d'une fonction nommée clear() ou erase(), car matrix.erase() est plus facile à comprendre que matrix() (qui pourrait faire n'importe quoi !).

Remarque : depuis le C++23, vous pouvez utiliser operator[] avec plusieurs indices. Cela fonctionne exactement comme operator() ci-dessus.

Le plaisir des foncteurs

L'opérateur () est aussi couramment surchargé pour implémenter des foncteurs (ou objets fonctions), c'est-à-dire des classes qui se comportent comme des fonctions. L'avantage d'un foncteur par rapport à une fonction ordinaire est que les foncteurs peuvent stocker des données dans des variables membres (puisqu'ce sont des classes).

Voici un foncteur simple :

#include <iostream>

class Accumulator
{
private:
    int m_counter{ 0 };

public:
    int operator() (int i) { return (m_counter += i); }

    void reset() { m_counter = 0; } // facultatif
};

int main()
{
    Accumulator acc{};
    std::cout << acc(1) << '\n'; // affiche 1
    std::cout << acc(3) << '\n'; // affiche 4

    Accumulator acc2{};
    std::cout << acc2(10) << '\n'; // affiche 10
    std::cout << acc2(20) << '\n'; // affiche 30

    return 0;
}

Notez que l'utilisation de notre Accumulator ressemble à un appel de fonction ordinaire, mais que l'objet Accumulator conserve une valeur cumulée.

L'avantage des foncteurs est que nous pouvons instancier autant d'objets foncteurs distincts que nécessaire, et les utiliser tous simultanément. Les foncteurs peuvent aussi avoir d'autres fonctions membres (par exemple reset()) qui rendent certains services pratiques.

Conclusion

L'opérateur () est parfois surchargé avec deux paramètres pour indexer des tableaux multidimensionnels, ou pour extraire un sous-ensemble d'un tableau unidimensionnel (les deux paramètres définissant le sous-ensemble à renvoyer). Pour tout le reste, il vaut probablement mieux écrire une fonction membre dont le nom est plus explicite.

L'opérateur () est aussi souvent surchargé pour créer des foncteurs. Bien que les foncteurs simples (comme l'exemple ci-dessus) soient assez faciles à comprendre, les foncteurs sont généralement utilisés dans des sujets plus avancés et méritent leur propre leçon.

Quiz

Question n° 1

Écrivez une classe nommée MyString qui contient un std::string. Surchargez operator<< pour afficher la chaîne. Surchargez operator() pour renvoyer la sous-chaîne qui commence à l'indice donné par le premier paramètre (sous forme de MyString). La longueur de la sous-chaîne est définie par le second paramètre.

Le code suivant doit fonctionner :

int main()
{
    MyString s { "Hello, world!" };
    std::cout << s(7, 5) << '\n'; // commence à l'indice 7 et renvoie 5 caractères

    return 0;
}

Il doit afficher :


world

Indice : vous pouvez utiliser std::string::substr pour obtenir une sous-chaîne d'un std::string.

Solution 
#include <cassert>
#include <iostream>
#include <string>
#include <string_view>

class MyString
{
private:
    std::string m_string{};

public:
    MyString(std::string_view string = {})
        :m_string{ string }
    {
    }

    MyString operator()(int start, int length)
    {
        assert(start >= 0);
        assert(start + length <= static_cast<int>(m_string.length()) && "MyString::operator(int, int): Substring is out of range");

        return MyString { m_string.substr(
            static_cast<std::string::size_type>(start),
            static_cast<std::string::size_type>(length)
            )};
    }

    friend std::ostream& operator<<(std::ostream& out, const MyString& s)
    {
        out << s.m_string;

        return out;
    }
};

int main()
{
    MyString s{ "Hello, world!" };
    std::cout << s(7, 5) << '\n'; // commence à l'indice 7 et renvoie 5 caractères

    return 0;
}

Question n° 2

Cette question de quiz est bonus.

> Étape n° 1

Pourquoi le code ci-dessus est-il inefficace si nous n'avons pas besoin de modifier la sous-chaîne renvoyée ?

Solution

Dans notre operator(), std::string::substr renvoie un std::string, ce qui signifie que lors de l'appel, nous faisons une copie d'une partie de la chaîne source. Notre operator() surchargé utilise cette copie pour construire un nouveau MyString, qui contient un membre std::string, ce qui réalise une autre copie. Nous renvoyons ensuite ce MyString à l'appelant, ce qui fait une troisième copie. Le compilateur supprimera probablement certaines de ces copies par optimisation, mais au moins un std::string (contenant la sous-chaîne résultante) doit être conservé.

Nous n'avons besoin d'une copie de la sous-chaîne que si nous comptons la modifier, ou si elle doit survivre à la chaîne d'origine. Ce n'est généralement pas le cas, donc nous faisons des copies coûteuses dont nous n'avons typiquement pas besoin.

> Étape n° 2

Que pourrions-nous faire à la place ?

Solution

std::string_view permet de visualiser une sous-chaîne d'une chaîne existante sans en faire de copie. Si notre operator() renvoyait un std::string_view, l'appelant pourrait utiliser ce std::string_view lorsque cela suffit, ou le convertir en std::string ou MyString s'il doit modifier ou conserver la sous-chaîne.

> Étape n° 3

Mettez à jour operator() de la solution de la question précédente pour qu'il renvoie la sous-chaîne sous forme de std::string_view.

Indice : std::string::substr() renvoie un std::string. std::string_view::substr() renvoie un std::string_view. Faites très attention à ne pas renvoyer un std::string_view pendant (dangling) !

Indice

Indice : ne créez aucun temporaire std::string, car il serait détruit à la fin de la fonction, et tout std::string_view qui le référencerait deviendrait pendant.

Indice

Indice : la création de temporaires std::string_view est acceptable, tant qu'ils sont des vues de m_string.

Solution 
#include <cassert>
#include <iostream>
#include <string>
#include <string_view>

class MyString
{
private:
    std::string m_string{};

public:
    MyString(std::string_view string = {})
        :m_string{ string }
    {
    }

    std::string_view operator()(int start, int length)
    {
        assert(start >= 0);
        assert(start + length <= static_cast<int>(m_string.length()) && "MyString::operator(int, int): Substring is out of range");

        // Crée un std::string_view de m_string, pour pouvoir utiliser std::string_view::substr() au lieu de std::string::substr()
        return std::string_view{ m_string }.substr(
            static_cast<std::string_view::size_type>(start),
            static_cast<std::string_view::size_type>(length)
        );
    }

    friend std::ostream& operator<<(std::ostream& out, const MyString& s)
    {
        out << s.m_string;

        return out;
    }
};

int main()
{
    MyString s{ "Hello, world!" };
    std::cout << s(7, 5) << '\n'; // commence à l'indice 7 et renvoie 5 caractères

    return 0;
}

Examinons plus en détail return std::string_view{ m_string }.substr();. D'abord, nous créons un std::string_view temporaire de m_string, ce qui est peu coûteux et nous permet d'accéder aux fonctions membres de std::string_view. Ensuite, nous appelons std::string_view::substr sur ce temporaire pour obtenir notre sous-chaîne (une vue non terminée par un caractère nul de m_string). Nous renvoyons ensuite cette vue à l'appelant. Comme le std::string_view renvoyé reste une vue de m_string (qui reste dans sa portée), il ne pend pas.

Au final, nous créons 3 std::string_view au lieu de 3 std::string, ce qui est plus efficace.
