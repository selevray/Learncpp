21.6 — Surcharge des opérateurs unaires +, - et !

Surcharge des opérateurs unaires

Contrairement aux opérateurs vus jusqu'ici, le plus unaire (+), le moins unaire (-) et la négation logique (!) sont tous des opérateurs unaires, c'est-à-dire qu'ils n'opèrent que sur un seul opérande. Comme ils n'agissent que sur l'objet auquel ils sont appliqués, leurs surcharges sont généralement implémentées sous forme de fonctions membres. Les trois opérateurs s'implémentent de manière identique.

Voyons comment implémenter operator- pour la classe Cents utilisée dans un exemple précédent :

#include <iostream>

class Cents
{
private:
    int m_cents {};

public:
    Cents(int cents): m_cents{cents} {}

    // Surcharge de -Cents en tant que fonction membre
    Cents operator-() const;

    int getCents() const { return m_cents; }
};

// note : cette fonction est une fonction membre !
Cents Cents::operator-() const
{
    return -m_cents; // comme le type de retour est Cents, ceci effectue une conversion implicite de int vers Cents grâce au constructeur Cents(int)
}

int main()
{
    const Cents nickle{ 5 };
    std::cout << "A nickle of debt is worth " << (-nickle).getCents() << " cents\n";

    return 0;
}

Cela devrait être simple. Notre opérateur moins unaire (-) surchargé est un opérateur unaire implémenté comme fonction membre ; il ne prend donc aucun paramètre (il opère sur l'objet *this). Il renvoie un objet Cents qui est l'opposé de la valeur originale. Comme operator- ne modifie pas l'objet Cents, nous pouvons (et devons) en faire une fonction const (afin qu'elle puisse être appelée sur des objets Cents constants).

Notez qu'il n'y a pas de confusion entre l'opérateur moins unaire operator- et l'opérateur moins binaire operator-, car ils n'ont pas le même nombre de paramètres.

Voici un autre exemple. L'opérateur ! est l'opérateur de négation logique : si une expression s'évalue à « true », operator! renvoie false, et inversement. On le rencontre couramment appliqué à des variables booléennes pour tester si elles sont vraies ou non :

if (!isHappy)
    std::cout << "I am not happy!\n";
else
    std::cout << "I am so happy!\n";

Pour les entiers, 0 s'évalue à false et toute autre valeur à true. operator! appliqué à un entier renvoie donc true pour la valeur 0 et false sinon.

En généralisant ce concept, on peut dire que operator! doit s'évaluer à true si l'état de l'objet est « faux », « zéro », ou quel que soit l'état d'initialisation par défaut.

L'exemple suivant montre une surcharge à la fois de operator- et de operator! pour une classe Point définie par l'utilisateur :

#include <iostream>

class Point
{
private:
    double m_x {};
    double m_y {};
    double m_z {};

public:
    Point(double x=0.0, double y=0.0, double z=0.0):
        m_x{x}, m_y{y}, m_z{z}
    {
    }

    // Convertit un Point en son équivalent opposé
    Point operator- () const;

    // Renvoie true si le point est situé à l'origine
    bool operator! () const;

    double getX() const { return m_x; }
    double getY() const { return m_y; }
    double getZ() const { return m_z; }
};

// Convertit un Point en son équivalent opposé
Point Point::operator- () const
{
    return { -m_x, -m_y, -m_z };
}

// Renvoie true si le point est à l'origine, false sinon
bool Point::operator! () const
{
    return (m_x == 0.0 && m_y == 0.0 && m_z == 0.0);
}

int main()
{
    Point point{}; // utilise le constructeur par défaut pour initialiser à (0.0, 0.0, 0.0)

    if (!point)
        std::cout << "point is set at the origin.\n";
    else
        std::cout << "point is not set at the origin.\n";

    return 0;
}

L'opérateur ! surchargé pour cette classe renvoie la valeur booléenne « true » si le Point est initialisé à sa valeur par défaut, aux coordonnées (0.0, 0.0, 0.0). Le code ci-dessus produit donc le résultat suivant :


point is set at the origin.

Un petit quiz

  1. Implémentez la surcharge de l'opérateur unaire operator+ pour la classe Point. L'opérateur unaire operator+ renvoie simplement son opérande (il ne rend pas positives les valeurs négatives).
Solution

Voici la solution évidente :

Point Point::operator+ () const
{
    return { m_x, m_y, m_z };
}

Mais comme le Point que nous renvoyons est exactement celui sur lequel nous opérons, la version suivante fonctionne également :

Point Point::operator+ () const
{
    return *this;
}

Notez que nous renvoyons une copie par valeur plutôt qu'une référence constante. En effet, les utilisateurs de cette fonction s'attendront probablement à pouvoir modifier l'objet renvoyé.
