10.2 — Promotion des nombres à virgule flottante et entière

Dans la leçon 4.3 -- Taille des objets et opérateur sizeof, nous avons indiqué que le C++ garantit une taille minimale pour chacun des types fondamentaux. Toutefois, la taille réelle de ces types peut varier selon le compilateur et l'architecture.

Cette variabilité a été autorisée afin que les types int et double puissent être fixés à la taille qui maximise les performances sur une architecture donnée. Par exemple, un ordinateur 32 bits peut généralement traiter 32 bits de données à la fois. Dans ce cas, un int aura très probablement une largeur de 32 bits, car c'est la taille « naturelle » des données sur lesquelles le processeur opère (et probablement la plus performante).

Petit rappel

Le nombre de bits qu'utilise un type de données s'appelle sa largeur. Un type de données plus large utilise davantage de bits, et un type plus étroit en utilise moins.

Mais que se passe-t-il lorsque nous voulons faire manipuler par notre processeur 32 bits une valeur sur 8 bits (comme un char) ou sur 16 bits ? Certains processeurs 32 bits (comme les processeurs x86 32 bits) peuvent manipuler directement des valeurs sur 8 ou 16 bits. Cependant, cela est souvent plus lent que la manipulation de valeurs sur 32 bits ! D'autres processeurs 32 bits (comme les PowerPC 32 bits) ne peuvent opérer que sur des valeurs de 32 bits, et il faut alors recourir à des astuces pour manipuler des valeurs plus étroites.

La promotion numérique

Le C++ se veut portable et performant sur un large éventail d'architectures. Ses concepteurs n'ont donc pas voulu supposer qu'un processeur donné saurait manipuler efficacement des valeurs plus étroites que sa taille de données naturelle.

Pour répondre à ce problème, le C++ définit une catégorie de conversions de types appelées informellement les promotions numériques (numeric promotions). Une promotion numérique est la conversion de certains types numériques étroits (comme un char) vers certains types numériques plus larges (généralement int ou double) qui peuvent être traités efficacement.

Toutes les promotions numériques préservent la valeur. Une conversion préservant la valeur (aussi appelée conversion sûre) est une conversion dans laquelle chaque valeur possible du type source peut être convertie en une valeur égale du type destination.

Comme les promotions sont sûres, le compilateur les utilise librement au besoin, et n'émet aucun avertissement lorsqu'il le fait.

La promotion numérique réduit la redondance

La promotion numérique résout aussi un autre problème. Considérons le cas où vous souhaitez écrire une fonction affichant une valeur de type int :

#include <iostream>

void printInt(int x)
{
    std::cout << x << '\n';
}

Bien que ce soit simple, que se passe-t-il si nous voulons aussi pouvoir afficher une valeur de type short ou de type char ? Sans conversions de types, il faudrait écrire une fonction d'affichage différente pour short, une autre pour char. Et n'oublions pas une version pour unsigned char, signed char, unsigned short, wchar_t, char8_t, char16_t et char32_t ! On voit vite que cela devient ingérable.

La promotion numérique vient ici à notre secours : nous pouvons écrire des fonctions dont les paramètres sont de type int et/ou double (comme la fonction printInt() ci-dessus). Le même code peut ensuite être appelé avec des arguments de types pouvant être promus numériquement vers les types des paramètres de la fonction.

Catégories de promotions numériques

Les règles de promotion numérique se divisent en deux sous-catégories : les promotions entières (integral promotions) et les promotions à virgule flottante (floating point promotions). Seules les conversions listées dans ces catégories sont considérées comme des promotions numériques.

Promotions à virgule flottante

Commençons par la plus simple.

Selon les règles de promotion à virgule flottante, une valeur de type float peut être convertie en une valeur de type double.

Cela signifie que nous pouvons écrire une fonction prenant un double, puis l'appeler avec une valeur de type double ou de type float :

#include <iostream>

void printDouble(double d)
{
    std::cout << d << '\n';
}

int main()
{
    printDouble(5.0); // aucune conversion nécessaire
    printDouble(4.0f); // promotion numérique de float en double

    return 0;
}

Dans le second appel à printDouble(), le littéral float 4.0f est promu en double, de sorte que le type de l'argument corresponde au type du paramètre de la fonction.

Promotions entières

Les règles de promotion entière sont plus complexes.

Selon les règles de promotion entière, les conversions suivantes peuvent être effectuées :

  • signed char ou signed short peuvent être convertis en int.
  • unsigned char, char8_t et unsigned short peuvent être convertis en int si int peut contenir toute la plage du type, ou en unsigned int sinon.
  • Si char est signé par défaut, il suit les règles de conversion de signed char ci-dessus. S'il est non signé par défaut, il suit les règles de conversion de unsigned char ci-dessus.
  • bool peut être converti en int, false devenant 0 et true devenant 1.

En supposant un octet de 8 bits et une taille de int de 4 octets ou plus (ce qui est courant de nos jours), ce qui précède signifie essentiellement que bool, char, signed char, unsigned char, signed short et unsigned short sont tous promus en int.

Il existe quelques autres règles de promotion entière, moins utilisées. Elles sont décrites à l'adresse https://en.cppreference.com/w/cpp/language/implicit_conversion#Integral_promotion.

Dans la plupart des cas, cela nous permet d'écrire une fonction prenant un paramètre int, puis de l'utiliser avec une grande variété d'autres types entiers. Par exemple :

#include <iostream>

void printInt(int x)
{
    std::cout << x << '\n';
}

int main()
{
    printInt(2);

    short s{ 3 }; // il n'existe pas de suffixe de littéral pour short, nous utilisons donc une variable ici
    printInt(s); // promotion numérique de short en int

    printInt('a'); // promotion numérique de char en int
    printInt(true); // promotion numérique de bool en int

    return 0;
}

Deux points méritent d'être notés ici. D'abord, sur certaines architectures (par exemple avec des int de 2 octets), il est possible que certains types entiers non signés soient promus en unsigned int plutôt qu'en int.

Ensuite, certains types non signés plus étroits (comme unsigned char) peuvent être promus en types signés plus larges (comme int). Ainsi, bien que la promotion entière préserve la valeur, elle ne préserve pas nécessairement la signature (signé/non signé) du type.

Toutes les conversions vers un type plus large ne sont pas des promotions numériques

Certaines conversions vers un type plus large (comme char vers short, ou int vers long) ne sont pas considérées comme des promotions numériques en C++ (ce sont des conversions numériques, que nous verrons prochainement dans la leçon 10.3 -- Conversions numériques). En effet, ces conversions ne servent pas l'objectif qui consiste à convertir de petits types en types plus grands pouvant être traités plus efficacement.

La distinction est surtout théorique. Toutefois, dans certains cas, le compilateur privilégie les promotions numériques aux conversions numériques. Nous verrons des exemples où cela fait une différence lorsque nous aborderons la résolution de surcharge de fonctions (dans la prochaine leçon 11.3 -- Résolution de surcharge de fonctions et correspondances ambiguës).
