26.x — Résumé du chapitre 26 et quiz

Les modèles (templates) permettent d'écrire des fonctions ou des classes à l'aide de types substituts, de sorte que l'on puisse générer autant de versions identiques de la fonction ou de la classe qu'il y a de types différents. Une fonction ou une classe qui a été instanciée s'appelle une instance de fonction ou de classe.

Toute fonction ou classe modèle doit commencer par une déclaration de paramètres de modèle, qui indique au compilateur que la fonction ou la classe qui suit est un modèle. Dans cette déclaration, on précise les paramètres de type ou les paramètres d'expression. Les paramètres de type sont de simples types substituts, normalement nommés T, T1, T2 ou d'autres noms d'une seule lettre (par exemple S). Les paramètres d'expression sont en général de type entier, mais il peut aussi s'agir d'un pointeur ou d'une référence vers une fonction, un objet de classe ou une fonction membre.

Séparer la définition d'une classe modèle de la définition de ses fonctions membres ne fonctionne pas comme pour les classes ordinaires : vous ne pouvez pas placer la définition de la classe dans un fichier d'en-tête et les définitions des fonctions membres dans un fichier .cpp. Il est en général préférable de tout garder dans un fichier d'en-tête, les définitions des fonctions membres étant placées sous la classe.

La spécialisation de modèle peut être utilisée lorsque l'on veut remplacer le comportement par défaut de la fonction ou de la classe modèle pour un type précis. Si tous les types sont remplacés, on parle de spécialisation complète (full specialization). Les classes supportent également la spécialisation partielle, où seuls certains paramètres du modèle sont spécialisés. Les fonctions ne peuvent pas être partiellement spécialisées.

De nombreuses classes de la bibliothèque standard du C++ utilisent des modèles, notamment std::array et std::vector. Les modèles servent souvent à implémenter des classes conteneurs, afin qu'un conteneur soit écrit une seule fois et utilisable avec n'importe quel type approprié.

Quiz

  1. Il est parfois utile de définir des données qui vont par paires. Écrivez une classe modèle nommée Pair1 qui permet à l'utilisateur de définir un seul type de modèle, utilisé pour les deux valeurs de la paire. La fonction suivante doit fonctionner :
int main()
{
    Pair1<int> p1 { 5, 8 };
    std::cout << "Pair: " << p1.first() << ' ' << p1.second() << '\n';

    const Pair1<double> p2 { 2.3, 4.5 };
    std::cout << "Pair: " << p2.first() << ' ' << p2.second() << '\n';

    return 0;
}

et afficher :


Pair: 5 8
Pair: 2.3 4.5
Solution 
#include <iostream>

template <typename T>
class Pair1
{
private:
    T m_x {};
    T m_y {};

public:
    Pair1(const T& x, const T& y)
        : m_x{ x }, m_y{ y }
    {
    }

    T& first() { return m_x; }
    T& second() { return m_y; }
    const T& first() const { return m_x; }
    const T& second() const { return m_y; }
};

int main()
{
    Pair1<int> p1 { 5, 8 };
    std::cout << "Pair: " << p1.first() << ' ' << p1.second() << '\n';

    const Pair1<double> p2 { 2.3, 4.5 };
    std::cout << "Pair: " << p2.first() << ' ' << p2.second() << '\n';

    return 0;
}
  1. Écrivez une classe Pair qui permet de spécifier un type distinct pour chacune des deux valeurs de la paire.

Remarque : nous nommons cette classe différemment de la précédente, car le C++ ne permet pas actuellement de « surcharger » des classes qui ne diffèrent que par le nombre ou le type de leurs paramètres de modèle.

Le programme suivant doit fonctionner :

int main()
{
    Pair<int, double> p1 { 5, 6.7 };
    std::cout << "Pair: " << p1.first() << ' ' << p1.second() << '\n';

    const Pair<double, int> p2 { 2.3, 4 };
    std::cout << "Pair: " << p2.first() << ' ' << p2.second() << '\n';

    return 0;
}

et afficher :


Pair: 5 6.7
Pair: 2.3 4

Indice : pour définir un modèle utilisant deux types différents, séparez les deux types par une virgule dans la déclaration des paramètres de modèle. Voir la leçon 11.8 -- Modèles de fonctions avec plusieurs types de modèle pour plus d'informations.

Solution 
#include <iostream>

template <typename T, typename S>
class Pair
{
private:
    T m_x;
    S m_y;

public:
    Pair(const T& x, const S& y)
        : m_x{x}, m_y{y}
    {
    }

    T& first() { return m_x; }
    S& second() { return m_y; }
    const T& first() const { return m_x; }
    const S& second() const { return m_y; }
};

int main()
{
    Pair<int, double> p1 { 5, 6.7 };
    std::cout << "Pair: " << p1.first() << ' ' << p1.second() << '\n';

    const Pair<double, int> p2 { 2.3, 4 };
    std::cout << "Pair: " << p2.first() << ' ' << p2.second() << '\n';

    return 0;
}
  1. Une paire chaîne-valeur (string-value pair) est un type particulier de paire dont la première valeur est toujours de type chaîne, et dont la seconde valeur peut être de n'importe quel type. Écrivez une classe modèle nommée StringValuePair qui hérite d'une classe Pair partiellement spécialisée (en utilisant std::string comme premier type, et en laissant l'utilisateur spécifier le second type).

Le programme suivant doit s'exécuter :

int main()
{
    StringValuePair<int> svp { "Hello", 5 };
    std::cout << "Pair: " << svp.first() << ' ' << svp.second() << '\n';

    return 0;
}

et afficher :


Pair: Hello 5

Indice : lorsque vous appelez le constructeur de Pair depuis le constructeur de StringValuePair, n'oubliez pas d'inclure les paramètres de modèle dans le nom de la classe Pair.

Solution 
#include <iostream>
#include <string>
#include <string_view>

template <typename T, typename S>
class Pair
{
private:
    T m_x{};
    S m_y{};

public:
    Pair(const T& x, const S& y)
        : m_x{ x }, m_y{ y }
    {
    }

    T& first() { return m_x; }
    S& second() { return m_y; }
    const T& first() const { return m_x; }
    const S& second() const { return m_y; }
};

template <typename S>
class StringValuePair : public Pair<std::string, S>
{
public:
    StringValuePair(std::string_view key, const S& value)
                // un std::string_view ne se convertit pas implicitement en std::string, nous devons être explicites
        : Pair<std::string, S>{ static_cast<std::string>(key), value }
    {
    }
};

int main()
{
    StringValuePair<int> svp{ "Hello", 5 };
    std::cout << "Pair: " << svp.first() << ' ' << svp.second() << '\n';

    return 0;
}
