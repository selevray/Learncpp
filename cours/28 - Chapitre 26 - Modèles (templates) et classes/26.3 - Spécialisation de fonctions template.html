26.3 — Spécialisation de fonctions template

Lorsqu'il instancie une fonction template pour un type donné, le compilateur génère une copie de la fonction templatée en remplaçant les paramètres de type du template par les types réellement utilisés dans la déclaration de la variable. Cela signifie qu'une fonction aura les mêmes détails d'implémentation pour chaque type instancié (en utilisant simplement des types différents). Si, la plupart du temps, c'est exactement ce que vous voulez, il arrive parfois qu'il soit utile d'implémenter une fonction templatée légèrement différemment pour un type de données spécifique.

Utiliser une fonction non template

Considérons l'exemple suivant :

#include <iostream>

template <typename T>
void print(const T& t)
{
    std::cout << t << '\n';
}

int main()
{
    print(5);
    print(6.7);

    return 0;
}

Ce programme affiche :


5
6.7

Supposons maintenant que nous souhaitions que les valeurs de type double (et seulement celles-ci) soient affichées en notation scientifique.

Une façon d'obtenir un comportement différent pour un type donné consiste à définir une fonction non template :

#include <iostream>

template <typename T>
void print(const T& t)
{
    std::cout << t << '\n';
}

void print(double d)
{
    std::cout << std::scientific << d << '\n';
}

int main()
{
    print(5);
    print(6.7);

    return 0;
}

Lorsque le compilateur doit résoudre l'appel print(6.7), il constate que print(double) a déjà été défini par nos soins, et utilise cette version plutôt que d'instancier une version à partir de print(const T&).

Ce programme produit le résultat suivant :


5
6.700000e+000

Un avantage de cette manière de définir les fonctions est que la fonction non template n'a pas besoin d'avoir la même signature que la fonction template. Notez que print(const T&) passe son argument par référence constante, alors que print(double) le passe par valeur.

En règle générale, privilégiez la définition d'une fonction non template lorsque cette option est disponible.

Spécialisation de fonctions template

Une autre façon d'obtenir un résultat similaire consiste à utiliser la spécialisation explicite de template. La spécialisation explicite de template (souvent abrégée en spécialisation de template) est une fonctionnalité qui nous permet de définir explicitement différentes implémentations d'un template pour des types ou des valeurs spécifiques. Lorsque tous les paramètres du template sont spécialisés, on parle de spécialisation complète. Lorsque seuls certains paramètres sont spécialisés, on parle de spécialisation partielle.

Créons une spécialisation de print<T> pour le cas où T est un double :

#include <iostream>

// Voici notre template primaire (doit venir en premier)
template <typename T>
void print(const T& t)
{
    std::cout << t << '\n';
}

// Une spécialisation complète du template primaire print<T> pour le type double
// Les spécialisations complètes ne sont pas implicitement inline ; il faut donc
// ajouter inline si elle est placée dans un fichier d'en-tête
template<>                          // déclaration de paramètres de template vide
void print<double>(const double& d) // spécialisée pour le type double
{
    std::cout << std::scientific << d << '\n'; 
}

int main()
{
    print(5);
    print(6.7);

    return 0;
}

Pour spécialiser un template, le compilateur doit d'abord avoir vu une déclaration du template primaire. Le template primaire de l'exemple ci-dessus est print<T>(const T&).

Examinons maintenant de plus près notre spécialisation de fonction template :

template<>                          // déclaration de paramètres de template vide
void print<double>(const double& d) // spécialisée pour le type double

Tout d'abord, nous avons besoin d'une déclaration de paramètres de template afin que le compilateur sache que nous faisons quelque chose en rapport avec les templates. Cependant, dans ce cas, nous n'avons besoin d'aucun paramètre de template, nous utilisons donc une paire de chevrons vide. Comme la spécialisation ne comporte aucun paramètre de template, il s'agit d'une spécialisation complète.

Sur la ligne suivante, print<double> indique au compilateur que nous spécialisons la fonction template primaire print pour le type double. La spécialisation doit avoir la même signature que le template primaire (à ceci près qu'elle remplace T par double partout où le template primaire l'utilise). Comme le template primaire possède un paramètre de type const T&, la spécialisation doit posséder un paramètre de type const double&. La spécialisation ne peut pas passer par valeur si le template primaire passe par référence (ou inversement).

Cet exemple affiche le même résultat que précédemment.

Notez que si une fonction non template et une spécialisation de fonction template correspondantes existent toutes deux, c'est la fonction non template qui est prioritaire. Par ailleurs, les spécialisations complètes ne sont pas implicitement inline ; si vous en définissez une dans un fichier d'en-tête, veillez à la déclarer inline afin d'éviter des violations de la règle de définition unique (ODR).

Attention

Les spécialisations complètes ne sont pas implicitement inline (les spécialisations partielles le sont). Si vous placez une spécialisation complète dans un fichier d'en-tête, elle doit être marquée inline afin de ne pas provoquer de violations de l'ODR lorsqu'elle est incluse dans plusieurs unités de traduction.

Comme les fonctions ordinaires, les spécialisations de fonctions template peuvent être supprimées (à l'aide de = delete) si vous souhaitez que tout appel résolu vers cette spécialisation produise une erreur de compilation.

En général, évitez les spécialisations de fonctions template au profit de fonctions non template chaque fois que c'est possible.

Spécialisation de fonctions template pour les fonctions membres ?

Considérons maintenant le template de classe suivant :

#include <iostream>

template <typename T>
class Storage
{
private:
    T m_value {};
public:
    Storage(T value)
      : m_value { value }
    {
    }

    void print()
    {
        std::cout << m_value << '\n';
    }
};

int main()
{
    // Définissons quelques conteneurs
    Storage i { 5 };
    Storage d { 6.7 };

    // Affichons quelques valeurs
    i.print();
    d.print();
}

Ce programme affiche :

5
6.7

Supposons que nous souhaitions à nouveau créer une version de la fonction print() qui affiche les doubles en notation scientifique. Cependant, cette fois, print() est une fonction membre : nous ne pouvons donc pas définir une fonction non membre. Comment faire alors ?

Bien qu'il puisse sembler que nous devions utiliser une spécialisation de fonction template, ce n'est pas le bon outil. Remarquez que i.print() appelle Storage<int>::print() et que d.print() appelle Storage<double>::print(). Par conséquent, si nous voulons modifier le comportement de cette fonction lorsque T est un double, nous devons spécialiser Storage<double>::print(), qui est une spécialisation de template de classe, et non une spécialisation de fonction template !

Comment procéder ? Nous aborderons la spécialisation de template de classe dans la prochaine leçon.
