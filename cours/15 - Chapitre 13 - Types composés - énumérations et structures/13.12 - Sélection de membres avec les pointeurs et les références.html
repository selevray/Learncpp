13.12 — Sélection de membres avec les pointeurs et les références

Sélection de membres pour les structures et les références vers des structures

Dans la leçon 13.7 -- Introduction aux structures, aux membres et à la sélection de membres, nous avons montré que vous pouvez utiliser l'opérateur de sélection de membre (.) pour sélectionner un membre d'un objet structure :

#include <iostream>

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

int main()
{
    Employee joe { 1, 34, 65000.0 };

    // Utilisez l'opérateur de sélection de membre (.) pour sélectionner un membre d'un objet structure
    ++joe.age; // Joe a fêté son anniversaire
    joe.wage = 68000.0; // Joe a obtenu une promotion

    return 0;
}

Comme les références à un objet se comportent exactement comme l'objet lui-même, nous pouvons également utiliser l'opérateur de sélection de membre (.) pour sélectionner un membre d'une référence à une structure :

#include <iostream>

struct Employee
{
    int id{};
    int age{};
    double wage{};
};

void printEmployee(const Employee& e)
{
    // Utilisez l'opérateur de sélection de membre (.) pour sélectionner un membre d'une référence à une structure
    std::cout << "Id: " << e.id << '\n';
    std::cout << "Age: " << e.age << '\n';
    std::cout << "Wage: " << e.wage << '\n';
}

int main()
{
    Employee joe{ 1, 34, 65000.0 };

    ++joe.age;
    joe.wage = 68000.0;

    printEmployee(joe);

    return 0;
}

Sélection de membres pour les pointeurs vers des structures

Cependant, l'opérateur de sélection de membre (.) ne peut pas être utilisé directement sur un pointeur vers une structure :

#include <iostream>

struct Employee
{
    int id{};
    int age{};
    double wage{};
};

int main()
{
    Employee joe{ 1, 34, 65000.0 };

    ++joe.age;
    joe.wage = 68000.0;

    Employee* ptr{ &joe };
    std::cout << ptr.id << '\n'; // Erreur de compilation : impossible d'utiliser l'opérateur . avec des pointeurs

    return 0;
}

Avec les variables normales ou les références, nous pouvons accéder directement aux objets. En revanche, comme les pointeurs contiennent des adresses, nous devons d'abord déréférencer le pointeur pour obtenir l'objet avant de pouvoir faire quoi que ce soit avec lui. Une façon d'accéder à un membre depuis un pointeur vers une structure est donc la suivante :

#include <iostream>

struct Employee
{
    int id{};
    int age{};
    double wage{};
};

int main()
{
    Employee joe{ 1, 34, 65000.0 };

    ++joe.age;
    joe.wage = 68000.0;

    Employee* ptr{ &joe };
    std::cout << (*ptr).id << '\n'; // Pas idéal, mais ça fonctionne : d'abord déréférencer ptr, puis utiliser la sélection de membre

    return 0;
}

Cependant, cette écriture est un peu laide, d'autant plus que nous devons mettre l'opération de déréférencement entre parenthèses pour qu'elle soit prioritaire sur la sélection de membre.

Pour obtenir une syntaxe plus claire, C++ propose un opérateur de sélection de membre depuis un pointeur (->) (parfois appelé opérateur flèche) qui permet de sélectionner des membres à partir d'un pointeur vers un objet :

#include <iostream>

struct Employee
{
    int id{};
    int age{};
    double wage{};
};

int main()
{
    Employee joe{ 1, 34, 65000.0 };

    ++joe.age;
    joe.wage = 68000.0;

    Employee* ptr{ &joe };
    std::cout << ptr->id << '\n'; // Mieux : utilisez -> pour sélectionner un membre depuis un pointeur vers un objet

    return 0;
}

Cet opérateur de sélection de membre depuis un pointeur (->) fonctionne de la même manière que l'opérateur de sélection de membre (.), mais il effectue implicitement le déréférencement du pointeur avant de sélectionner le membre. Ainsi, ptr->id est équivalent à (*ptr).id.

L'opérateur flèche n'est pas seulement plus facile à écrire, il est aussi beaucoup moins sujet aux erreurs, car l'indirection est effectuée implicitement, et il n'y a donc pas de problème de priorité à craindre. Par conséquent, lorsque vous accédez à un membre via un pointeur, utilisez toujours l'opérateur -> plutôt que l'opérateur ..

Bonne pratique

Lorsque vous utilisez un pointeur pour accéder à un membre, utilisez l'opérateur de sélection de membre depuis un pointeur (->) plutôt que l'opérateur de sélection de membre (.).

Enchaînement de operator->

Si le membre accédé via operator-> est un pointeur vers un type de classe, operator-> peut être appliqué à nouveau dans la même expression pour accéder au membre de ce type de classe.

L'exemple suivant l'illustre (grâce au lecteur Luna) :

#include <iostream>

struct Point
{
    double x {};
    double y {};
};

struct Triangle
{
    Point* a {};
    Point* b {};
    Point* c {};
};

int main()
{
    Point a {1,2};
    Point b {3,7};
    Point c {10,2};

    Triangle tr { &a, &b, &c };
    Triangle* ptr {&tr};

    // ptr est un pointeur vers un Triangle, qui contient des membres qui sont des pointeurs vers un Point
    // Pour accéder au membre y du Point c du Triangle pointé par ptr, les deux écritures suivantes sont équivalentes :

    // Accès via l'opérateur .
    std::cout << (*(*ptr).c).y << '\n'; // Laid !

    // Accès via l'opérateur ->
    std::cout << ptr -> c -> y << '\n'; // Bien plus agréable
}

Lorsque plusieurs operator-> sont enchaînés (par exemple ptr->c->y), l'expression peut être difficile à lire. Ajouter des espaces entre les membres et les operator-> (par exemple ptr -> c -> y) peut rendre un peu plus facile la distinction entre les membres accédés et l'opérateur.

Mélange de pointeurs et de non-pointeurs pour les membres

L'opérateur de sélection de membre s'applique toujours à la variable actuellement sélectionnée. Si vous avez un mélange de pointeurs et de membres ordinaires, vous pouvez rencontrer des sélections de membres où . et -> sont utilisés l'un après l'autre :

#include <iostream>
#include <string>

struct Paw
{
    int claws{};
};

struct Animal
{
    std::string name{};
    Paw paw{};
};

int main()
{
    Animal puma{ "Puma", { 5 } };

    Animal* ptr{ &puma };

    // ptr est un pointeur, on utilise ->
    // paw n'est pas un pointeur, on utilise .

    std::cout << (ptr->paw).claws << '\n';

    return 0;
}

Notez que dans le cas de (ptr->paw).claws, les parenthèses ne sont pas nécessaires, car operator-> et operator. s'évaluent tous deux de gauche à droite, mais elles améliorent légèrement la lisibilité.
