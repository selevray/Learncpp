13.4 — Conversion d'une énumération vers et depuis une chaîne de caractères

Dans la leçon précédente (13.3 -- Conversions entières des énumérateurs non scopés), nous avons présenté un exemple de ce type :

#include <iostream>

enum Color
{
    black, // 0
    red,   // 1
    blue,  // 2
};

int main()
{
    Color shirt{ blue };

    std::cout << "Your shirt is " << shirt << '\n';

    return 0;
}

Ce programme affiche :


Your shirt is 2

Comme operator<< ne sait pas afficher un Color, le compilateur convertit implicitement Color en une valeur entière et affiche celle-ci à la place.

La plupart du temps, afficher une énumération sous forme de valeur entière (comme 2) n'est pas ce que nous voulons. Nous souhaitons généralement afficher le nom de l'énumérateur représenté (par exemple blue). C++ ne fournit pas de moyen prêt à l'emploi pour y parvenir, nous devons donc trouver nous-mêmes une solution. Heureusement, ce n'est pas très difficile.

Obtenir le nom d'un énumérateur

La manière habituelle d'obtenir le nom d'un énumérateur consiste à écrire une fonction qui prend un énumérateur en paramètre et renvoie son nom sous forme de chaîne. Mais cela suppose de savoir quelle chaîne renvoyer pour un énumérateur donné.

Il existe deux méthodes courantes pour y parvenir.

Dans la leçon 8.5 -- Bases de l'instruction switch, nous avons indiqué qu'une instruction switch peut opérer sur une valeur entière ou sur une valeur énumérée. Dans l'exemple suivant, nous utilisons une instruction switch pour sélectionner un énumérateur et renvoyer la chaîne littérale de couleur correspondante :

#include <iostream>
#include <string_view>

enum Color
{
    black,
    red,
    blue,
};

constexpr std::string_view getColorName(Color color)
{
    switch (color)
    {
    case black: return "black";
    case red:   return "red";
    case blue:  return "blue";
    default:    return "???";
    }
}

int main()
{
    constexpr Color shirt{ blue };

    std::cout << "Your shirt is " << getColorName(shirt) << '\n';

    return 0;
}

Ce programme affiche :


Your shirt is blue

Dans l'exemple ci-dessus, nous effectuons un switch sur color, qui contient l'énumérateur passé en argument. À l'intérieur du switch, nous avons une étiquette de cas pour chaque énumérateur de Color. Chaque cas renvoie le nom de la couleur correspondante sous forme de chaîne littérale de style C. Cette chaîne est implicitement convertie en std::string_view, qui est renvoyée à l'appelant. Nous avons également un cas default qui renvoie "???", au cas où l'utilisateur passerait une valeur inattendue.

Rappel

Comme les chaînes littérales de style C existent pendant toute la durée du programme, il est correct de renvoyer un std::string_view qui observe une chaîne littérale de style C. Lorsque le std::string_view est copié vers l'appelant, la chaîne littérale observée existe toujours.

La fonction est constexpr afin que nous puissions utiliser le nom de la couleur dans une expression constante.

Contenu associé

Les fonctions constexpr sont présentées dans la leçon F.1 -- Fonctions constexpr.

Bien que cela nous permette d'obtenir le nom d'un énumérateur, écrire std::cout << getColorName(shirt) est moins agréable que std::cout << shirt pour afficher ce nom à l'écran. Nous apprendrons à std::cout à afficher une énumération dans la leçon à venir 13.5 -- Introduction à la surcharge des opérateurs d'entrée/sortie.

La seconde méthode pour associer les énumérateurs à des chaînes consiste à utiliser un tableau. Nous la présentons dans la leçon 17.6 -- std::array et les énumérations.

Entrée d'une énumération non scopée

Examinons maintenant un cas d'entrée. Dans l'exemple suivant, nous définissons une énumération Pet. Comme Pet est un type défini par le programme, le langage ne sait pas comment lire un Pet avec std::cin :

#include <iostream>

enum Pet
{
    cat,   // 0
    dog,   // 1
    pig,   // 2
    whale, // 3
};

int main()
{
    Pet pet { pig };
    std::cin >> pet; // erreur de compilation : std::cin ne sait pas lire un Pet

    return 0;
}

Une manière simple de contourner ce problème consiste à lire un entier, puis à utiliser static_cast pour le convertir en un énumérateur du type énuméré approprié :

#include <iostream>
#include <string_view>

enum Pet
{
    cat,   // 0
    dog,   // 1
    pig,   // 2
    whale, // 3
};

constexpr std::string_view getPetName(Pet pet)
{
    switch (pet)
    {
    case cat:   return "cat";
    case dog:   return "dog";
    case pig:   return "pig";
    case whale: return "whale";
    default:    return "???";
    }
}

int main()
{
    std::cout << "Enter a pet (0=cat, 1=dog, 2=pig, 3=whale): ";

    int input{};
    std::cin >> input; // lecture d'un entier

    if (input < 0 || input > 3)
        std::cout << "You entered an invalid pet\n";
    else
    {
        Pet pet{ static_cast<Pet>(input) }; // conversion de notre entier en Pet via static_cast
        std::cout << "You entered: " << getPetName(pet) << '\n';
    }

    return 0;
}

Cette solution fonctionne, mais elle est un peu maladroite. Notez également que nous ne devons effectuer static_cast<Pet>(input) qu'après avoir vérifié que input se situe dans la plage des énumérateurs.

Obtenir une énumération à partir d'une chaîne

Plutôt que de saisir un nombre, il serait plus agréable que l'utilisateur tape une chaîne représentant un énumérateur (par exemple « pig »), et que nous puissions convertir cette chaîne en l'énumérateur Pet correspondant. Toutefois, cela demande de résoudre deux difficultés.

Premièrement, on ne peut pas faire de switch sur une chaîne. Il faut donc utiliser autre chose pour comparer la chaîne saisie par l'utilisateur. L'approche la plus simple consiste à utiliser une série d'instructions if.

Deuxièmement, quel énumérateur Pet renvoyer si l'utilisateur saisit une chaîne invalide ? Une option serait d'ajouter un énumérateur représentant « aucun/invalide » et de le renvoyer. Cependant, une meilleure option consiste à utiliser std::optional.

Contenu associé

Nous présentons std::optional dans la leçon 12.15 -- std::optional.

#include <iostream>
#include <optional> // pour std::optional
#include <string>
#include <string_view>

enum Pet
{
    cat,   // 0
    dog,   // 1
    pig,   // 2
    whale, // 3
};

constexpr std::string_view getPetName(Pet pet)
{
    switch (pet)
    {
    case cat:   return "cat";
    case dog:   return "dog";
    case pig:   return "pig";
    case whale: return "whale";
    default:    return "???";
    }
}

constexpr std::optional<Pet> getPetFromString(std::string_view sv)
{
    // On ne peut faire de switch que sur une valeur entière (ou une énumération), pas sur une chaîne
    // il faut donc utiliser des instructions if ici
    if (sv == "cat")   return cat;
    if (sv == "dog")   return dog;
    if (sv == "pig")   return pig;
    if (sv == "whale") return whale;

    return {};
}

int main()
{
    std::cout << "Enter a pet: cat, dog, pig, or whale: ";
    std::string s{};
    std::cin >> s;

    std::optional<Pet> pet { getPetFromString(s) };

    if (!pet)
        std::cout << "You entered an invalid pet\n";
    else
        std::cout << "You entered: " << getPetName(*pet) << '\n';

    return 0;
}

Dans la solution ci-dessus, nous utilisons une série d'instructions if-else pour effectuer des comparaisons de chaînes. Si la chaîne saisie correspond à celle d'un énumérateur, nous renvoyons l'énumérateur correspondant. Si aucune chaîne ne correspond, nous renvoyons {}, ce qui signifie « aucune valeur ».

Pour les lecteurs avancés

Notez que la solution ci-dessus ne reconnaît que les lettres minuscules. Si vous souhaitez reconnaître quelle que soit la casse, vous pouvez utiliser la fonction suivante pour convertir la saisie de l'utilisateur en minuscules :

#include <algorithm> // pour std::transform
#include <cctype>    // pour std::tolower
#include <iterator>  // pour std::back_inserter
#include <string>
#include <string_view>

// Cette fonction renvoie une std::string qui est la version en minuscules du std::string_view passé en argument.
// Seul un mappage caractère par caractère 1:1 peut être effectué par cette fonction
std::string toASCIILowerCase(std::string_view sv)
{
    std::string lower{};
    std::transform(sv.begin(), sv.end(), std::back_inserter(lower),
        [](char c)
        { 
            return static_cast<char>(std::tolower(static_cast<unsigned char>(c)));
        });
    return lower;
}

Cette fonction parcourt chaque caractère de std::string_view sv, le convertit en minuscule à l'aide de std::tolower() (avec l'aide d'une lambda), puis ajoute ce caractère minuscule à lower.

Nous présentons les lambdas dans la leçon 20.6 -- Introduction aux lambdas (fonctions anonymes).

Comme pour le cas de la sortie, il serait préférable de pouvoir simplement écrire std::cin >> pet. Nous aborderons ce point dans la leçon à venir 13.5 -- Introduction à la surcharge des opérateurs d'entrée/sortie.
