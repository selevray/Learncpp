13.10 — Passer et retourner des structures

Considérons un employé représenté par trois variables indépendantes :

int main()
{
    int id { 1 };
    int age { 24 };
    double wage { 52400.0 };

    return 0;
}

Si nous voulons passer cet employé à une fonction, nous devons passer trois variables :

#include <iostream>

void printEmployee(int id, int age, double wage)
{
    std::cout << "ID:   " << id << '\n';
    std::cout << "Age:  " << age << '\n';
    std::cout << "Wage: " << wage << '\n';
}

int main()
{
    int id { 1 };
    int age { 24 };
    double wage { 52400.0 };

    printEmployee(id, age, wage);

    return 0;
}

Passer trois variables d'employé séparément n'est pas si gênant, mais imaginez une fonction qui doit recevoir 10 ou 12 variables d'employé. Passer chaque variable individuellement serait long et source d'erreurs. De plus, si nous ajoutons un nouvel attribut à notre employé (par exemple le nom), nous devons modifier toutes les déclarations, toutes les définitions et tous les appels de fonctions pour accepter le nouveau paramètre et le nouvel argument !

Passer des structures (par référence)

Un grand avantage des structures par rapport aux variables individuelles est que nous pouvons passer la structure entière à une fonction qui doit travailler avec ses membres. Les structures sont généralement passées par référence (le plus souvent par référence constante) afin d'éviter de faire des copies.

#include <iostream>

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

void printEmployee(const Employee& employee) // notez le passage par référence ici
{
    std::cout << "ID:   " << employee.id << '\n';
    std::cout << "Age:  " << employee.age << '\n';
    std::cout << "Wage: " << employee.wage << '\n';
}

int main()
{
    Employee joe { 14, 32, 24.15 };
    Employee frank { 15, 28, 18.27 };

    // Afficher les informations de Joe
    printEmployee(joe);

    std::cout << '\n';

    // Afficher les informations de Frank
    printEmployee(frank);

    return 0;
}

Dans l'exemple ci-dessus, nous passons un Employee entier à printEmployee() (deux fois, une fois pour joe et une fois pour frank).

Le programme ci-dessus affiche :


ID:   14
Age:  32
Wage: 24.15

ID:   15
Age:  28
Wage: 18.27

Comme nous passons l'objet structure entier (et non ses membres individuellement), nous n'avons besoin que d'un seul paramètre, quel que soit le nombre de membres de la structure. Et si, plus tard, nous décidons d'ajouter de nouveaux membres à notre structure Employee, nous n'aurons pas à modifier la déclaration de la fonction ni l'appel ! Le nouveau membre sera automatiquement pris en compte.

Nous abordons la question de savoir quand passer une structure par valeur ou par référence dans la leçon 12.6 -- Passage par référence lvalue constante.

Passer des structures temporaires

Dans l'exemple précédent, nous avons créé la variable Employee nommée joe avant de la passer à la fonction printEmployee(). Cela nous permet de donner un nom à la variable, ce qui peut être utile pour la documentation. Mais cela exige aussi deux instructions (une pour créer joe, une pour utiliser joe).

Lorsque nous n'utilisons une variable qu'une seule fois, devoir lui donner un nom et séparer sa création de son utilisation peut complexifier le code. Dans ce cas, il peut être préférable d'utiliser un objet temporaire. Un objet temporaire n'est pas une variable : il n'a donc pas d'identifiant.

Voici le même exemple que précédemment, mais où les variables joe et frank ont été remplacées par des objets temporaires :

#include <iostream>

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

void printEmployee(const Employee& employee) // notez le passage par référence ici
{
    std::cout << "ID:   " << employee.id << '\n';
    std::cout << "Age:  " << employee.age << '\n';
    std::cout << "Wage: " << employee.wage << '\n';
}

int main()
{
    // Afficher les informations de Joe
    printEmployee(Employee { 14, 32, 24.15 }); // construit un Employee temporaire à passer à la fonction (type explicitement indiqué) (à privilégier)

    std::cout << '\n';

    // Afficher les informations de Frank
    printEmployee({ 15, 28, 18.27 }); // construit un Employee temporaire à passer à la fonction (type déduit du paramètre)

    return 0;
}

Nous pouvons créer un Employee temporaire de deux façons. Dans le premier appel, nous utilisons la syntaxe Employee { 14, 32, 24.15 }. Elle indique au compilateur de créer un objet Employee et de l'initialiser avec les valeurs fournies. C'est la syntaxe à privilégier, car elle indique clairement le type de l'objet temporaire créé, et le compilateur ne peut pas mal interpréter nos intentions.

Dans le second appel, nous utilisons la syntaxe { 15, 28, 18.27 }. Le compilateur est suffisamment intelligent pour comprendre que les arguments fournis doivent être convertis en Employee pour que l'appel de fonction réussisse. Notez que cette forme est considérée comme une conversion implicite : elle ne fonctionnera donc pas dans les cas où seules les conversions explicites sont acceptées.

Contenu associé

Nous revenons plus en détail sur les objets temporaires de type classe et sur les conversions dans la leçon 14.13 -- Objets temporaires de classe.

Quelques précisions supplémentaires sur les objets temporaires : ils sont créés et initialisés à l'endroit de leur définition, et détruits à la fin de l'expression complète dans laquelle ils sont créés. Par ailleurs, l'évaluation d'un objet temporaire est une expression de valeur r (rvalue) : il ne peut être utilisé qu'aux endroits où les valeurs r sont acceptées. Lorsqu'un objet temporaire est utilisé comme argument de fonction, il ne se lie qu'aux paramètres qui acceptent des valeurs r. Cela inclut le passage par valeur et le passage par référence constante, et exclut le passage par référence non constante et le passage par adresse.

Retourner des structures

Considérons le cas d'une fonction qui doit retourner un point dans l'espace cartésien à trois dimensions. Un tel point possède 3 attributs : une coordonnée x, une coordonnée y et une coordonnée z. Mais une fonction ne peut retourner qu'une seule valeur. Comment alors renvoyer les 3 coordonnées à l'utilisateur ?

Une façon courante consiste à retourner une structure :

#include <iostream>

struct Point3d
{
    double x { 0.0 };
    double y { 0.0 };
    double z { 0.0 };
};

Point3d getZeroPoint()
{
    // Nous pouvons créer une variable et retourner cette variable (nous l'améliorerons ci-dessous)
    Point3d temp { 0.0, 0.0, 0.0 };
    return temp;
}

int main()
{
    Point3d zero{ getZeroPoint() };

    if (zero.x == 0.0 && zero.y == 0.0 && zero.z == 0.0)
        std::cout << "The point is zero\n";
    else
        std::cout << "The point is not zero\n";

    return 0;
}

Ce programme affiche :


The point is zero

Les structures définies à l'intérieur de fonctions sont généralement retournées par valeur, afin de ne pas retourner une référence pendante (dangling).

Dans la fonction getZeroPoint() ci-dessus, nous créons un nouvel objet nommé (temp) uniquement pour pouvoir le retourner :

Point3d getZeroPoint()
{
    // Nous pouvons créer une variable et retourner cette variable (nous l'améliorerons ci-dessous)
    Point3d temp { 0.0, 0.0, 0.0 };
    return temp;
}

Le nom de l'objet (temp) n'apporte pas vraiment de valeur documentaire ici.

Nous pouvons améliorer légèrement la fonction en retournant plutôt un objet temporaire (sans nom / anonyme) :

Point3d getZeroPoint()
{
    return Point3d { 0.0, 0.0, 0.0 }; // retourne un Point3d anonyme
}

Dans ce cas, un Point3d temporaire est construit, copié vers l'appelant, puis détruit à la fin de l'expression. Remarquez à quel point c'est plus clair (une ligne au lieu de deux, et inutile de vérifier si temp est utilisé plusieurs fois).

Contenu associé

Nous abordons plus en détail les objets anonymes dans la leçon 14.13 -- Objets temporaires de classe.

Déduction du type de retour

Lorsque la fonction possède un type de retour explicite (par exemple Point3d), nous pouvons même omettre le type dans l'instruction return :

Point3d getZeroPoint()
{
    // Nous avons déjà indiqué le type lors de la déclaration de la fonction
    // donc nous n'avons pas besoin de le répéter ici
    return { 0.0, 0.0, 0.0 }; // retourne un Point3d anonyme
}

Il s'agit d'une conversion implicite.

Notez également que, comme nous retournons ici uniquement des valeurs nulles, nous pouvons utiliser des accolades vides pour retourner un Point3d initialisé par valeur :

Point3d getZeroPoint()
{
    // Nous pouvons utiliser des accolades vides pour initialiser par valeur tous les membres
    return {};
}

Les structures sont une brique essentielle

Bien que les structures soient utiles en elles-mêmes, les classes (qui sont au cœur du C++ et de la programmation orientée objet) s'appuient directement sur les concepts que nous venons de présenter. Bien comprendre les structures (en particulier les membres de données, l'accès aux membres et l'initialisation par défaut des membres) facilitera d'autant votre passage aux classes.

Quiz

Question n° 1

Vous exploitez un site web et souhaitez calculer vos revenus publicitaires. Écrivez un programme qui vous permet de saisir 3 données :

  • Le nombre de publicités visionnées.
  • Le pourcentage d'utilisateurs ayant cliqué sur une publicité.
  • Le gain moyen par publicité cliquée.

Stockez ces 3 valeurs dans une structure. Passez cette structure à une autre fonction qui affiche chacune des valeurs. La fonction d'affichage doit également afficher le montant gagné dans la journée (multipliez entre eux les 3 champs).

Indice

Indice : si vous stockez le pourcentage sous forme d'entier, vous devrez aussi diviser par 100 lors du calcul du gain journalier.

Solution 
#include <iostream>

// Nous devons d'abord définir notre structure Advertising
struct Advertising
{
    int adsShown {};
    double clickThroughRatePercentage {};
    double averageEarningsPerClick {};
};

Advertising getAdvertising()
{
    Advertising temp {};
    std::cout << "How many ads were shown today? ";
    std::cin >> temp.adsShown;
    std::cout << "What percentage of ads were clicked on by users? ";
    std::cin >> temp.clickThroughRatePercentage;
    std::cout << "What was the average earnings per click? ";
    std::cin >> temp.averageEarningsPerClick;

    return temp;
}

void printAdvertising(const Advertising& ad)
{
    std::cout << "Number of ads shown: " << ad.adsShown << '\n';
    std::cout << "Click through rate: " << ad.clickThroughRatePercentage << '\n';
    std::cout << "Average earnings per click: $" << ad.averageEarningsPerClick << '\n';

    // La ligne suivante est scindée pour en réduire la longueur
    // Nous devons diviser ad.clickThroughRatePercentage par 100 car c'est un pourcentage sur 100, et non un multiplicateur
    std::cout << "Total Earnings: $"
        << (ad.adsShown * ad.clickThroughRatePercentage / 100 * ad.averageEarningsPerClick) << '\n';
}

int main()
{
    // Déclarer une variable de structure Advertising
    Advertising ad{ getAdvertising() };
    printAdvertising(ad);

    return 0;
}

Question n° 2

Créez une structure pour contenir une fraction. Cette structure doit posséder un membre entier numerator (numérateur) et un membre entier denominator (dénominateur).

Écrivez une fonction qui lit une Fraction saisie par l'utilisateur, et utilisez-la pour lire deux objets fraction. Écrivez une autre fonction qui multiplie deux Fraction entre elles et retourne le résultat sous forme de Fraction (vous n'avez pas besoin de simplifier la fraction). Écrivez enfin une fonction qui affiche une fraction.

La sortie de votre programme doit correspondre à ce qui suit :


Enter a value for the numerator: 1
Enter a value for the denominator: 2

Enter a value for the numerator: 3
Enter a value for the denominator: 4

Your fractions multiplied together: 3/8

Lors de la multiplication de deux fractions, le numérateur du résultat est le produit des deux numérateurs, et le dénominateur du résultat est le produit des deux dénominateurs.

Solution 
#include <iostream>

struct Fraction
{
    int numerator{ 0 };
    int denominator{ 1 };
};

Fraction getFraction()
{
    Fraction temp{};
    std::cout << "Enter a value for numerator: ";
    std::cin >> temp.numerator;
    std::cout << "Enter a value for denominator: ";
    std::cin >> temp.denominator;
    std::cout << '\n';

    return temp;
}

constexpr Fraction multiply(const Fraction& f1, const Fraction& f2)
{
    return { f1.numerator * f2.numerator, f1.denominator * f2.denominator };
}

void printFraction(const Fraction& f)
{
    std::cout << f.numerator << '/' << f.denominator << '\n';
}

int main()
{
    Fraction f1{ getFraction() };
    Fraction f2{ getFraction() };

    std::cout << "Your fractions multiplied together: ";

    printFraction(multiply(f1, f2));

    return 0;
}

Question n° 3

Dans la solution de la question précédente, pourquoi getFraction() retourne-t-elle par valeur plutôt que par référence ?

Solution

Parce que notre temp de type Fraction est une variable locale, qui sort de portée à la fin de la fonction. Si nous retournions temp par référence, nous renverrions une référence pendante à l'appelant.
