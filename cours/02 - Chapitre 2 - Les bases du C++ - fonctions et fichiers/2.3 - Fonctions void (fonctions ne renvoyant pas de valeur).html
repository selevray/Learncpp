2.3 — Fonctions void (fonctions ne renvoyant pas de valeur)

Dans une leçon précédente (2.1 -- Introduction aux fonctions), nous avons indiqué que la syntaxe de la définition d'une fonction ressemble à ceci :


typeRetour identifiant() // identifiant remplacé par le nom de votre fonction
{
// Votre code ici
}

Bien que nous ayons montré des exemples de fonctions dont le type de retour est void, nous n'avons pas expliqué ce que cela signifie. Dans cette leçon, nous allons étudier les fonctions dont le type de retour est void.

Valeurs de retour void

Les fonctions ne sont pas obligées de renvoyer une valeur à l'appelant. Pour indiquer au compilateur qu'une fonction ne renvoie pas de valeur, on utilise le type de retour void. Par exemple :

#include <iostream>

// void signifie que la fonction ne renvoie pas de valeur à l'appelant
void printHi()
{
    std::cout << "Hi" << '\n';

    // Cette fonction ne renvoie pas de valeur, donc aucune instruction return n'est nécessaire
}

int main()
{
    printHi(); // ok : la fonction printHi() est appelée, aucune valeur n'est renvoyée

    return 0;
}

Dans l'exemple ci-dessus, la fonction printHi a un comportement utile (elle affiche « Hi ») mais elle n'a pas besoin de renvoyer quoi que ce soit à l'appelant. C'est pourquoi printHi a un type de retour void.

Lorsque main appelle printHi, le code de printHi s'exécute et « Hi » est affiché. À la fin de printHi, le contrôle revient à main et le programme poursuit son exécution.

Une fonction qui ne renvoie pas de valeur est appelée fonction ne renvoyant pas de valeur (ou fonction void).

Les fonctions void n'ont pas besoin d'instruction return

Une fonction void retourne automatiquement à l'appelant à la fin de la fonction. Aucune instruction return n'est requise.

Une instruction return (sans valeur de retour) peut être utilisée dans une fonction void : une telle instruction fait revenir la fonction à l'appelant à l'endroit où elle est exécutée. C'est exactement ce qui se produit de toute façon à la fin de la fonction. Par conséquent, placer une instruction return vide à la fin d'une fonction void est redondant :

#include <iostream>

// void signifie que la fonction ne renvoie pas de valeur à l'appelant
void printHi()
{
    std::cout << "Hi" << '\n';

    return; // indique au compilateur de revenir à l'appelant : c'est redondant, car le retour se produira de toute façon à la fin de la fonction !
} // la fonction revient à l'appelant ici

int main()
{
    printHi();

    return 0;
}

Bonne pratique

Ne placez pas d'instruction return à la fin d'une fonction ne renvoyant pas de valeur.

Les fonctions void ne peuvent pas être utilisées dans des expressions qui requièrent une valeur

Certains types d'expressions requièrent des valeurs. Par exemple :

#include <iostream>

int main()
{
    std::cout << 5; // ok : 5 est une valeur littérale que nous envoyons à la console pour être affichée
    std::cout << ;  // erreur de compilation : aucune valeur fournie

    return 0;
}

Dans le programme ci-dessus, la valeur à afficher doit être fournie à droite de std::cout <<. Si aucune valeur n'est fournie, le compilateur produit une erreur de syntaxe. Comme le second appel à std::cout ne fournit aucune valeur à afficher, cela provoque une erreur.

Considérons maintenant le programme suivant :

#include <iostream>

// void signifie que la fonction ne renvoie pas de valeur à l'appelant
void printHi()
{
    std::cout << "Hi" << '\n';
}

int main()
{
    printHi(); // ok : la fonction printHi() est appelée, aucune valeur n'est renvoyée

    std::cout << printHi(); // erreur de compilation

    return 0;
}

Le premier appel à printHi() a lieu dans un contexte qui ne requiert pas de valeur. Comme la fonction ne renvoie pas de valeur, cela ne pose aucun problème.

Le second appel à la fonction printHi() ne compile même pas. La fonction printHi a un type de retour void, c'est-à-dire qu'elle ne renvoie pas de valeur. Pourtant, cette instruction tente d'envoyer la valeur de retour de printHi à std::cout pour l'afficher. std::cout ne sait pas comment traiter cela (quelle valeur afficherait-il ?). Par conséquent, le compilateur signale une erreur. Vous devrez mettre en commentaire cette ligne de code pour que votre programme compile.

Astuce

Certaines instructions requièrent que des valeurs soient fournies, d'autres non.

Lorsqu'une instruction se compose uniquement d'un appel de fonction (par exemple le premier printHi() dans l'exemple ci-dessus), nous appelons la fonction pour son comportement, et non pour sa valeur de retour. Dans ce cas, nous pouvons appeler soit une fonction ne renvoyant pas de valeur, soit une fonction renvoyant une valeur en ignorant cette valeur de retour.

Lorsque nous appelons une fonction dans un contexte qui requiert une valeur (par exemple std::cout), une valeur doit être fournie. Dans un tel contexte, nous ne pouvons appeler que des fonctions renvoyant une valeur.

#include <iostream>

// Fonction qui ne renvoie pas de valeur
void returnNothing()
{
}

// Fonction qui renvoie une valeur
int returnFive()
{
    return 5;
}

int main()
{
    // Lorsqu'une fonction est appelée seule, aucune valeur n'est requise
    returnNothing(); // ok : nous pouvons appeler une fonction qui ne renvoie pas de valeur
    returnFive();    // ok : nous pouvons appeler une fonction qui renvoie une valeur, et ignorer cette valeur de retour

    // Lorsqu'une fonction est appelée dans un contexte qui requiert une valeur (comme std::cout)
    std::cout << returnFive();    // ok : nous pouvons appeler une fonction qui renvoie une valeur, et cette valeur sera utilisée
    std::cout << returnNothing(); // erreur de compilation : nous ne pouvons pas appeler une fonction qui renvoie void dans ce contexte

    return 0;
}

Renvoyer une valeur depuis une fonction void est une erreur de compilation

Tenter de renvoyer une valeur depuis une fonction ne renvoyant pas de valeur provoque une erreur de compilation :

void printHi() // Cette fonction ne renvoie pas de valeur
{
    std::cout << "In printHi()" << '\n';

    return 5; // erreur de compilation : nous tentons de renvoyer une valeur
}

Quiz

Question n° 1

Examinez les programmes suivants et indiquez ce qu'ils affichent, ou s'ils ne compilent pas.

1a)

#include <iostream>

void printA()
{
    std::cout << "A\n";
}

void printB()
{
    std::cout << "B\n";
}

int main()
{
    printA();
    printB();

    return 0;
}
Solution

Ce programme affiche les lettres A et B, sur des lignes séparées.

1b)

#include <iostream>

void printA()
{
    std::cout << "A\n";
}

int main()
{
    std::cout << printA() << '\n';

    return 0;
}
Solution

Ce programme ne compile pas. La fonction printA() renvoie void, valeur qui ne peut pas être envoyée à std::cout pour être affichée. Cela produira une erreur de compilation.
