2.4 — Introduction aux paramètres et arguments de fonction

Dans la leçon précédente, nous avons vu qu'une fonction pouvait renvoyer une valeur à l'appelant. Nous l'avons utilisé pour créer une fonction modulaire getValueFromUser, utilisée dans ce programme :

#include <iostream>

int getValueFromUser()
{
    std::cout << "Enter an integer: ";
    int input{};
    std::cin >> input;  

    return input;
}

int main()
{
    int num { getValueFromUser() };

    std::cout << num << " doubled is: " << num * 2 << '\n';

    return 0;
}

Mais que se passe-t-il si nous voulons aussi placer l'affichage dans sa propre fonction ? Vous pourriez essayer quelque chose comme ceci :

#include <iostream>

int getValueFromUser()
{
    std::cout << "Enter an integer: ";
    int input{};
    std::cin >> input;  

    return input;
}

// This function won't compile
void printDouble()
{
    std::cout << num << " doubled is: " << num * 2 << '\n';
}

int main()
{
    int num { getValueFromUser() };

    printDouble();

    return 0;
}

Cela ne compilera pas, car la fonction printDouble ne connaît pas l'identifiant num. Vous pourriez essayer de définir num comme variable à l'intérieur de printDouble() :

void printDouble()
{
    int num{}; // we added this line
    std::cout << num << " doubled is: " << num * 2 << '\n';
}

Certes, cela corrige l'erreur de compilation et permet au programme de compiler, mais le programme ne fonctionne toujours pas correctement (il affiche toujours « 0 doubled is: 0 »). Le cœur du problème est que la fonction printDouble n'a aucun moyen d'accéder à la valeur saisie par l'utilisateur.

Nous avons besoin d'un moyen de transmettre la valeur de la variable num à la fonction printDouble, afin que printDouble puisse utiliser cette valeur dans le corps de la fonction.

Paramètres et arguments de fonction

Dans de nombreux cas, il est utile de pouvoir transmettre des informations à une fonction appelée, afin que celle-ci dispose de données à traiter. Par exemple, si nous voulions écrire une fonction qui additionne deux nombres, nous avons besoin d'un moyen d'indiquer à la fonction quels deux nombres additionner lors de l'appel. Sinon, comment la fonction saurait-elle quoi additionner ? C'est le rôle des paramètres et des arguments de fonction.

Un paramètre de fonction est une variable utilisée dans l'en-tête d'une fonction. Les paramètres de fonction fonctionnent presque exactement comme les variables définies à l'intérieur de la fonction, à une différence près : ils sont initialisés avec une valeur fournie par l'appelant de la fonction.

Les paramètres de fonction se définissent dans l'en-tête de la fonction, entre les parenthèses qui suivent le nom de la fonction, les paramètres multiples étant séparés par des virgules.

Voici quelques exemples de fonctions avec différents nombres de paramètres :

// This function takes no parameters
// It does not rely on the caller for anything
void doPrint()
{
    std::cout << "In doPrint()\n";
}

// This function takes one integer parameter named x
// The caller will supply the value of x
void printValue(int x)
{
    std::cout << x << '\n';
}

// This function has two integer parameters, one named x, and one named y
// The caller will supply the value of both x and y
int add(int x, int y)
{
    return x + y;
}

Un argument est une valeur transmise depuis l'appelant vers la fonction lors d'un appel de fonction :

doPrint(); // this call has no arguments
printValue(6); // 6 is the argument passed to function printValue()
add(2, 3); // 2 and 3 are the arguments passed to function add()

Notez que plusieurs arguments sont également séparés par des virgules.

Comment les paramètres et les arguments fonctionnent ensemble

Lorsqu'une fonction est appelée, tous ses paramètres sont créés comme des variables, et la valeur de chacun des arguments est copiée dans le paramètre correspondant (par initialisation par copie). Ce processus s'appelle passage par valeur. Les paramètres de fonction qui utilisent le passage par valeur sont appelés paramètres valeur.

Par exemple :

#include <iostream>

// This function has two integer parameters, one named x, and one named y
// The values of x and y are passed in by the caller
void printValues(int x, int y)
{
    std::cout << x << '\n';
    std::cout << y << '\n';
}

int main()
{
    printValues(6, 7); // This function call has two arguments, 6 and 7

    return 0;
}

Lorsque la fonction printValues est appelée avec les arguments 6 et 7, le paramètre x de printValues est créé et initialisé avec la valeur 6, et le paramètre y de printValues est créé et initialisé avec la valeur 7.

Ce qui donne le résultat suivant :


6
7

Notez que le nombre d'arguments doit en général correspondre au nombre de paramètres de la fonction, sans quoi le compilateur produira une erreur. L'argument passé à une fonction peut être n'importe quelle expression valide (puisque l'argument sert simplement d'initialiseur au paramètre, et que les initialiseurs peuvent être n'importe quelle expression valide).

Corriger notre programme d'exemple

Nous disposons maintenant de l'outil nécessaire pour corriger le programme présenté au début de la leçon :

#include <iostream>

int getValueFromUser()
{
    std::cout << "Enter an integer: ";
    int input{};
    std::cin >> input;  

    return input;
}

void printDouble(int value) // This function now has an integer parameter
{
    std::cout << value << " doubled is: " << value * 2 << '\n';
}

int main()
{
    int num { getValueFromUser() };

    printDouble(num);

    return 0;
}

Dans ce programme, la variable num est d'abord initialisée avec la valeur saisie par l'utilisateur. Ensuite, la fonction printDouble est appelée, et la valeur de l'argument num est copiée dans le paramètre value de printDouble. La fonction printDouble utilise alors la valeur du paramètre value.

Utiliser les valeurs de retour comme arguments

Dans le problème précédent, nous constatons que la variable num n'est utilisée qu'une seule fois, pour transporter la valeur de retour de la fonction getValueFromUser jusqu'à l'argument de l'appel à printDouble.

Nous pouvons légèrement simplifier l'exemple ci-dessus ainsi :

#include <iostream>

int getValueFromUser()
{
    std::cout << "Enter an integer: ";
    int input{};
    std::cin >> input;  

    return input;
}

void printDouble(int value)
{
    std::cout << value << " doubled is: " << value * 2 << '\n';
}

int main()
{
    printDouble(getValueFromUser());

    return 0;
}

Ici, nous utilisons directement la valeur de retour de la fonction getValueFromUser comme argument de la fonction printDouble !

Bien que ce programme soit plus concis (et montre clairement que la valeur lue par l'utilisateur ne servira à rien d'autre), vous trouverez peut-être cette « syntaxe compacte » un peu difficile à lire. Si vous préférez rester sur la version qui utilise une variable, c'est tout à fait acceptable.

Comment les paramètres et les valeurs de retour fonctionnent ensemble

En combinant paramètres et valeur de retour, nous pouvons créer des fonctions qui reçoivent des données en entrée, effectuent un calcul avec celles-ci, puis renvoient le résultat à l'appelant.

Voici un exemple très simple de fonction qui additionne deux nombres et renvoie le résultat à l'appelant :

#include <iostream>

// add() takes two integers as parameters, and returns the result of their sum
// The values of x and y are determined by the function that calls add()
int add(int x, int y)
{
    return x + y;
}

// main takes no parameters
int main()
{
    std::cout << add(4, 5) << '\n'; // Arguments 4 and 5 are passed to function add()
    return 0;
}

L'exécution commence en haut de main. Lorsque add(4, 5) est évalué, la fonction add est appelée, le paramètre x étant initialisé avec la valeur 4 et le paramètre y avec la valeur 5.

L'instruction return de la fonction add évalue x + y pour produire la valeur 9, qui est renvoyée à main. Cette valeur 9 est ensuite envoyée à std::cout pour être affichée dans la console.

9

D'autres exemples

Examinons quelques appels de fonctions supplémentaires :

#include <iostream>

int add(int x, int y)
{
    return x + y;
}

int multiply(int z, int w)
{
    return z * w;
}

int main()
{
    std::cout << add(4, 5) << '\n'; // within add() x=4, y=5, so x+y=9
    std::cout << add(1 + 2, 3 * 4) << '\n'; // within add() x=3, y=12, so x+y=15

    int a{ 5 };
    std::cout << add(a, a) << '\n'; // evaluates (5 + 5)

    std::cout << add(1, multiply(2, 3)) << '\n'; // evaluates 1 + (2 * 3)
    std::cout << add(1, add(2, 3)) << '\n'; // evaluates 1 + (2 + 3)

    return 0;
}

Ce programme produit la sortie suivante :


9
15
10
7
6

La première instruction est directe.

Dans la deuxième instruction, les arguments sont des expressions qui sont évaluées avant d'être transmises. Ici, 1 + 2 s'évalue à 3, donc 3 est copié dans le paramètre x. 3 * 4 s'évalue à 12, donc 12 est copié dans le paramètre y. add(3, 12) donne 15.

La paire d'instructions suivante est aussi relativement simple :

    int a{ 5 };
    std::cout << add(a, a) << '\n'; // evaluates (5 + 5)

Dans ce cas, add() est appelée et la valeur de a est copiée dans les deux paramètres x et y. Comme a vaut 5, add(a, a) = add(5, 5), ce qui donne 10.

Examinons maintenant la première instruction délicate de l'ensemble :

    std::cout << add(1, multiply(2, 3)) << '\n'; // evaluates 1 + (2 * 3)

Lorsque la fonction add est exécutée, le programme doit déterminer les valeurs des paramètres x et y. x est simple, puisque nous lui passons directement l'entier 1. Pour obtenir la valeur du paramètre y, il faut d'abord évaluer multiply(2, 3). Le programme appelle multiply et initialise z = 2 et w = 3, de sorte que multiply(2, 3) renvoie la valeur entière 6. Cette valeur de retour 6 peut alors servir à initialiser le paramètre y de la fonction add. add(1, 6) renvoie l'entier 7, qui est ensuite transmis à std::cout pour affichage.

De façon plus concise :
add(1, multiply(2, 3)) s'évalue en add(1, 6), qui s'évalue en 7

L'instruction suivante paraît complexe, car l'un des arguments donnés à add est un autre appel à add.

    std::cout << add(1, add(2, 3)) << '\n'; // evaluates 1 + (2 + 3)

Mais ce cas fonctionne exactement comme le précédent. add(2, 3) est d'abord résolu, donnant la valeur de retour 5. On peut alors résoudre add(1, 5), qui s'évalue à la valeur 6, transmise à std::cout pour affichage.

De façon plus concise :
add(1, add(2, 3)) s'évalue en add(1, 5), qui s'évalue en 6

Paramètres non référencés et paramètres sans nom

Dans certains cas, vous rencontrerez des fonctions dont certains paramètres ne sont pas utilisés dans le corps de la fonction. On les appelle des paramètres non référencés.

Par exemple, de manière triviale :

void doSomething(int count) // warning: unreferenced parameter count
{
    // This function used to do something with count but it is not used any longer
}

int main()
{
    doSomething(4);

    return 0;
}

Tout comme pour les variables locales inutilisées, votre compilateur vous avertira probablement que la variable count a été définie mais n'est pas utilisée.

Dans une définition de fonction, le nom d'un paramètre est facultatif. Ainsi, lorsqu'un paramètre doit exister sans être utilisé dans le corps de la fonction, vous pouvez simplement omettre son nom. Un paramètre sans nom est appelé paramètre sans nom (unnamed parameter) :

void doSomething(int) // ok: unnamed parameter will not generate warning
{
}

Le guide de style C++ de Google recommande d'utiliser un commentaire pour documenter ce que représentait le paramètre sans nom :

void doSomething(int /*count*/)
{
}

Note de l'auteur

Vous vous demandez sans doute pourquoi on écrirait une fonction dont un paramètre n'est pas utilisé. Cela arrive le plus souvent dans des cas similaires à ceux-ci :

  1. Supposons qu'une fonction ait un seul paramètre. Plus tard, la fonction est modifiée et la valeur du paramètre n'est plus nécessaire. Si l'on supprimait simplement ce paramètre devenu inutile, tous les appels existants à la fonction cesseraient de fonctionner (car l'appel fournirait plus d'arguments que la fonction n'en accepte). Il faudrait alors retrouver chaque appel à la fonction et supprimer l'argument superflu. Cela peut représenter beaucoup de travail (et nécessiter beaucoup de nouveaux tests). Cela pourrait même être impossible si nous ne contrôlons pas tout le code qui appelle la fonction. Nous pouvons donc plutôt conserver le paramètre tel quel et lui faire simplement ne rien faire.

Pour les lecteurs avancés

D'autres cas où cela se produit :

  1. Les opérateurs ++ et -- ont des variantes préfixée et postfixée (par exemple ++foo et foo++). Un paramètre de fonction non référencé permet de distinguer si une surcharge de tel opérateur concerne le cas préfixé ou postfixé. Nous aborderons ce point dans la leçon 21.8 -- Surcharge des opérateurs d'incrémentation et de décrémentation.
  2. Lorsque nous devons déterminer quelque chose à partir du type (plutôt que de la valeur) d'un paramètre de type template.

Note de l'auteur

Si les paramètres sans nom ne vous semblent pas encore clairs, ne vous inquiétez pas. Nous les rencontrerons à nouveau dans les prochaines leçons, lorsque nous disposerons de davantage de contexte pour expliquer leur utilité.

Bonne pratique

Lorsqu'un paramètre de fonction existe mais n'est pas utilisé dans le corps de la fonction, ne lui donnez pas de nom. Vous pouvez éventuellement placer ce nom dans un commentaire.

Conclusion

Les paramètres de fonction et les valeurs de retour sont les mécanismes clés qui permettent d'écrire des fonctions réutilisables : ils nous permettent d'écrire des fonctions qui accomplissent des tâches et renvoient des résultats obtenus ou calculés à l'appelant, sans connaître à l'avance les entrées ou sorties précises.

Quiz

Question n° 1

Qu'est-ce qui ne va pas dans ce fragment de programme ?

#include <iostream>

void multiply(int x, int y)
{
    return x * y;
}

int main()
{
    std::cout << multiply(4, 5) << '\n';

    return 0;
}
Solution

multiply() a un type de retour void, ce qui signifie qu'il s'agit d'une fonction qui ne renvoie pas de valeur. Comme la fonction tente de renvoyer une valeur (via une instruction return), cela produira une erreur de compilation. Le type de retour devrait être int.

Question n° 2

Quelles sont les deux erreurs dans ce fragment de programme ?

#include <iostream>

int multiply(int x, int y)
{
    int product { x * y };
}

int main()
{
    std::cout << multiply(4) << '\n';

    return 0;
}
Solution

Problème 1 : main() passe un seul argument à multiply(), alors que multiply() en requiert deux. Problème 2 : multiply() n'a pas d'instruction return.

Question n° 3

Quelle valeur le programme suivant affiche-t-il ?

#include <iostream>

int add(int x, int y, int z)
{
    return x + y + z;
}

int multiply(int x, int y)
{
    return x * y;
}

int main()
{
    std::cout << multiply(add(1, 2, 3), 4) << '\n';

    return 0;
}
Solution

multiply est appelée avec x = add(1, 2, 3) et y = 4. Le processeur évalue d'abord x = add(1, 2, 3), ce qui donne 1 + 2 + 3, soit x = 6. multiply(6, 4) = 24, qui est la réponse.

Question n° 4

Écrivez une fonction nommée doubleNumber() qui prend un paramètre entier. La fonction doit renvoyer le double de la valeur du paramètre.

Solution 
int doubleNumber(int x)
{
    return 2 * x;
}

Question n° 5

Écrivez un programme complet qui lit un entier saisi par l'utilisateur, le double à l'aide de la fonction doubleNumber() écrite à la question précédente, puis affiche la valeur doublée dans la console.

Solution 
#include <iostream>

int doubleNumber(int x)
{
    return 2 * x;
}

int main()
{
    std::cout << "Enter an integer value: ";
    int x{};
    std::cin >> x;
    std::cout << doubleNumber(x) << '\n';

    return 0;
}
