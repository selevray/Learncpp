F.X — Résumé du chapitre F et quiz

Une fonction constexpr est une fonction autorisée à être appelée dans une expression constante. Pour qu'une fonction soit une fonction constexpr, il suffit de placer le mot-clé constexpr devant le type de retour. Les fonctions constexpr ne sont garanties d'être évaluées à la compilation que lorsqu'elles sont utilisées dans un contexte qui exige une expression constante. Dans les autres cas, elles peuvent être évaluées à la compilation (si elles remplissent les conditions) ou à l'exécution. Les fonctions constexpr sont implicitement inline, et le compilateur doit voir la définition complète d'une fonction constexpr pour pouvoir l'appeler à la compilation.

Une fonction consteval est une fonction qui doit obligatoirement être évaluée à la compilation. Par ailleurs, les fonctions consteval suivent les mêmes règles que les fonctions constexpr.

Quiz

Question n° 1

Ajoutez const et/ou constexpr au programme suivant :

#include <iostream>

// gets tower height from user and returns it
double getTowerHeight()
{
    std::cout << "Enter the height of the tower in meters: ";
    double towerHeight{};
    std::cin >> towerHeight;
    return towerHeight;
}

// Returns ball height from ground after "seconds" seconds
double calculateBallHeight(double towerHeight, int seconds)
{
    double gravity{ 9.8 };

    // Using formula: [ s = u * t + (a * t^2) / 2 ], here u(initial velocity) = 0
    double distanceFallen{ (gravity * (seconds * seconds)) / 2.0 };
    double currentHeight{ towerHeight - distanceFallen };

    return currentHeight;
}

// Prints ball height above ground
void printBallHeight(double ballHeight, int seconds)
{
    if (ballHeight > 0.0)
        std::cout << "At " << seconds << " seconds, the ball is at height: " << ballHeight << " meters\n";
    else
        std::cout << "At " << seconds << " seconds, the ball is on the ground.\n";
}

// Calculates the current ball height and then prints it
// This is a helper function to make it easier to do this
void printCalculatedBallHeight(double towerHeight, int seconds)
{
    double ballHeight{ calculateBallHeight(towerHeight, seconds) };
    printBallHeight(ballHeight, seconds);
}

int main()
{
    double towerHeight{ getTowerHeight() };

    printCalculatedBallHeight(towerHeight, 0);
    printCalculatedBallHeight(towerHeight, 1);
    printCalculatedBallHeight(towerHeight, 2);
    printCalculatedBallHeight(towerHeight, 3);
    printCalculatedBallHeight(towerHeight, 4);
    printCalculatedBallHeight(towerHeight, 5);

    return 0;
}
Solution 
#include <iostream>

// Cette fonction ne doit pas être rendue constexpr, car les entrées et sorties ne peuvent se faire qu'à l'exécution.
// Les versions de `operator<<` et `operator>>` qui effectuent les entrées et sorties ne supportent pas constexpr.
double getTowerHeight()
{
    std::cout << "Enter the height of the tower in meters: ";
    double towerHeight{};
    std::cin >> towerHeight;
    return towerHeight;
}

// Returns height from ground after "seconds" seconds
// Cette fonction est rendue constexpr, car elle se contente de calculer une valeur à partir de ses entrées et de la retourner.
// Les calculs arithmétiques peuvent être effectués à la compilation, et aucune fonction non constexpr n'est appelée.
// Rappel : une fonction constexpr peut être évaluée à la compilation ou à l'exécution.
//   Si ses arguments sont constexpr, elle peut être appelée à la compilation.
//   Ici, elle est appelée à l'exécution, car l'argument towerHeight n'est pas constexpr.
// Si une fonction peut être rendue constexpr, elle doit l'être.
// Rappel : les paramètres de fonction ne sont pas constexpr, même dans une fonction constexpr.
constexpr double calculateBallHeight(double towerHeight, int seconds)
{
    constexpr double gravity{ 9.8 }; // constexpr, car c'est une constante de compilation

    // Using formula: [ s = u * t + (a * t^2) / 2 ], here u(initial velocity) = 0
    // Ces variables ne peuvent pas être constexpr, car leurs initialisations ne sont pas des expressions constantes
    const double distanceFallen{ (gravity * (seconds * seconds)) / 2.0 };
    const double currentHeight{ towerHeight - distanceFallen };

    return currentHeight;
}

// Cette fonction ne doit pas être rendue constexpr, car les entrées et sorties ne peuvent se faire qu'à l'exécution.
// Les versions de `operator<<` et `operator>>` qui effectuent les entrées et sorties ne supportent pas constexpr.
void printBallHeight(double ballHeight, int seconds)
{
    if (ballHeight > 0.0)
        std::cout << "At " << seconds << " seconds, the ball is at height: " << ballHeight << " meters\n";
    else
        std::cout << "At " << seconds << " seconds, the ball is on the ground.\n";
}

// Cette fonction ne doit pas être rendue constexpr, car les entrées et sorties ne peuvent se faire qu'à l'exécution.
// Les versions de `operator<<` et `operator>>` qui effectuent les entrées et sorties ne supportent pas constexpr.
void printCalculatedBallHeight(double towerHeight, int seconds)
{
    // height ne peut être que const (et non constexpr), car son initialisation n'est pas une expression constante
    const double ballHeight{ calculateBallHeight(towerHeight, seconds) };
    printBallHeight(ballHeight, seconds);
}

int main()
{
    // towerHeight ne peut être que const (et non constexpr), car son initialisation n'est pas une expression constante
    const double towerHeight{ getTowerHeight() };

    printCalculatedBallHeight(towerHeight, 0);
    printCalculatedBallHeight(towerHeight, 1);
    printCalculatedBallHeight(towerHeight, 2);
    printCalculatedBallHeight(towerHeight, 3);
    printCalculatedBallHeight(towerHeight, 4);
    printCalculatedBallHeight(towerHeight, 5);

    return 0;
}
