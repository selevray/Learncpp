11.4 — Suppression de fonctions

Dans certains cas, il est possible d'écrire des fonctions qui ne se comportent pas comme souhaité lorsqu'elles sont appelées avec des valeurs de certains types.

Considérez l'exemple suivant :

#include <iostream>

void printInt(int x)
{
    std::cout << x << '\n';
}

int main()
{
    printInt(5);    // ok : affiche 5
    printInt('a');  // affiche 97 -- est-ce logique ?
    printInt(true); // affiche 1 -- est-ce logique ?

    return 0;
}

Cet exemple affiche :


5
97
1

Alors que printInt(5) est manifestement correct, les deux autres appels à printInt() sont plus discutables. Avec printInt('a'), le compilateur détermine qu'il peut promouvoir 'a' en la valeur entière 97 afin de faire correspondre l'appel de fonction à la définition de la fonction. Il promeut de même true en la valeur entière 1. Et il le fait sans aucune erreur.

Supposons que nous estimions qu'il n'a pas de sens d'appeler printInt() avec une valeur de type char ou bool. Que pouvons-nous faire ?

Supprimer une fonction à l'aide du spécificateur = delete

Lorsque nous disposons d'une fonction que nous ne voulons explicitement pas rendre appelable, nous pouvons la définir comme supprimée (deleted) à l'aide du spécificateur = delete. Si le compilateur fait correspondre un appel de fonction à une fonction supprimée, la compilation est interrompue avec une erreur de compilation.

Voici une version mise à jour de l'exemple précédent utilisant cette syntaxe :

#include <iostream>

void printInt(int x)
{
    std::cout << x << '\n';
}

void printInt(char) = delete; // les appels à cette fonction interrompent la compilation
void printInt(bool) = delete; // les appels à cette fonction interrompent la compilation

int main()
{
    printInt(97);   // ok

    printInt('a');  // erreur de compilation : fonction supprimée
    printInt(true); // erreur de compilation : fonction supprimée

    printInt(5.0);  // erreur de compilation : correspondance ambiguë

    return 0;
}

Examinons rapidement certains de ces cas. D'abord, printInt('a') correspond exactement à printInt(char), qui est supprimée. Le compilateur produit donc une erreur de compilation. printInt(true) correspond exactement à printInt(bool), qui est supprimée, et produit donc également une erreur de compilation.

printInt(5.0) est un cas intéressant, dont le résultat peut sembler inattendu. Tout d'abord, le compilateur vérifie si une correspondance exacte printInt(double) existe. Ce n'est pas le cas. Ensuite, le compilateur tente de trouver la meilleure correspondance. Bien que printInt(int) soit la seule fonction non supprimée, les fonctions supprimées sont tout de même prises en compte comme candidates lors de la résolution de surcharge. Comme aucune de ces fonctions n'est clairement la meilleure correspondance, le compilateur émet une erreur de correspondance ambiguë.

Point clé

= delete signifie « j'interdis ceci », et non « ceci n'existe pas ».

Les fonctions supprimées participent à toutes les étapes de la résolution de surcharge (et pas seulement à l'étape de correspondance exacte). Si une fonction supprimée est sélectionnée, il en résulte une erreur de compilation.

Pour les lecteurs avancés

D'autres types de fonctions peuvent être supprimés de manière similaire.

Nous traitons de la suppression de fonctions membres dans la leçon 14.14 -- Introduction au constructeur de copie, et de la suppression de spécialisations de modèles de fonctions dans la leçon 11.7 -- Instanciation des modèles de fonctions.

Supprimer toutes les surcharges non correspondantes (avancé)

Supprimer plusieurs surcharges de fonctions individuellement fonctionne bien, mais peut être verbeux. Il peut arriver que nous voulions qu'une certaine fonction ne soit appelée qu'avec des arguments dont les types correspondent exactement aux paramètres de la fonction. Nous pouvons y parvenir en utilisant un modèle de fonction (présenté dans la prochaine leçon 11.6 -- Modèles de fonctions) de la manière suivante :

#include <iostream>

// Cette fonction sera prioritaire pour les arguments de type int
void printInt(int x)
{
    std::cout << x << '\n';
}

// Ce modèle de fonction sera prioritaire pour les arguments d'autres types
// Comme ce modèle de fonction est supprimé, les appels à celui-ci interrompent la compilation
template <typename T>
void printInt(T x) = delete;

int main()
{
    printInt(97);   // ok
    printInt('a');  // erreur de compilation
    printInt(true); // erreur de compilation

    return 0;
}
