6.2 — Opérateurs arithmétiques

Opérateurs arithmétiques unaires

Il existe deux opérateurs arithmétiques unaires : le plus unaire (+) et le moins unaire (-). Pour rappel, les opérateurs unaires sont des opérateurs qui ne prennent qu'un seul opérande.

Opérateur Symbole Forme Opération
Plus unaire + +x Valeur de x
Moins unaire - -x Opposé de x

L'opérateur moins unaire renvoie l'opérande multiplié par -1. Autrement dit, si x vaut 5, -x vaut -5.

L'opérateur plus unaire renvoie la valeur de l'opérande. Autrement dit, +5 vaut 5, et +x vaut x. En général, vous n'aurez pas besoin de cet opérateur, car il est redondant. Il a été ajouté principalement pour assurer une symétrie avec l'opérateur moins unaire.

Pour la lisibilité, ces deux opérateurs doivent être placés immédiatement devant l'opérande (par exemple -x, et non - x).

Ne confondez pas l'opérateur moins unaire avec l'opérateur de soustraction binaire, qui utilise le même symbole. Par exemple, dans l'expression x = 5 - -3;, le premier moins est l'opérateur de soustraction binaire, et le second est l'opérateur moins unaire.

Opérateurs arithmétiques binaires

Il existe 5 opérateurs arithmétiques binaires. Les opérateurs binaires sont des opérateurs qui prennent un opérande de gauche et un opérande de droite.

Opérateur Symbole Forme Opération
Addition + x + y x plus y
Soustraction - x - y x moins y
Multiplication * x * y x multiplié par y
Division / x / y x divisé par y
Reste % x % y Le reste de la division de x par y

Les opérateurs d'addition, de soustraction et de multiplication fonctionnent exactement comme dans la vie courante, sans particularité.

La division et le reste nécessitent quelques explications supplémentaires. Nous parlerons de la division ci-dessous, et du reste dans la prochaine leçon.

Division entière et division en virgule flottante

Le plus simple est de considérer l'opérateur de division comme ayant deux « modes » différents.

Si l'un (ou les deux) des opérandes est une valeur en virgule flottante, l'opérateur de division effectue une division en virgule flottante. La division en virgule flottante renvoie une valeur en virgule flottante, et la partie fractionnaire est conservée. Par exemple, 7.0 / 4 = 1.75, 7 / 4.0 = 1.75 et 7.0 / 4.0 = 1.75. Comme pour toutes les opérations arithmétiques en virgule flottante, des erreurs d'arrondi peuvent survenir.

Si les deux opérandes sont des entiers, l'opérateur de division effectue à la place une division entière. La division entière supprime toute partie fractionnaire et renvoie une valeur entière. Par exemple, 7 / 4 = 1, car la partie fractionnaire du résultat est supprimée. De même, -7 / 4 = -1, car la fraction est supprimée.

Utiliser static_cast<> pour effectuer une division en virgule flottante avec des entiers

Ce qui précède soulève la question suivante : si nous avons deux entiers et que nous voulons les diviser sans perdre la partie fractionnaire, comment faire ?

Dans la leçon 4.12 -- Introduction à la conversion de types et static_cast, nous avons montré comment utiliser l'opérateur static_cast<> pour convertir un char en entier afin qu'il s'affiche comme un entier plutôt que comme un caractère.

De la même manière, nous pouvons utiliser static_cast<> pour convertir un entier en nombre en virgule flottante, afin d'effectuer une division en virgule flottante plutôt qu'une division entière. Considérez le code suivant :

#include <iostream>

int main()
{
    constexpr int x{ 7 };
    constexpr int y{ 4 };

    std::cout << "int / int = " << x / y << '\n';
    std::cout << "double / int = " << static_cast<double>(x) / y << '\n';
    std::cout << "int / double = " << x / static_cast<double>(y) << '\n';
    std::cout << "double / double = " << static_cast<double>(x) / static_cast<double>(y) << '\n';

    return 0;
}

Ce programme produit le résultat suivant :


int / int = 1
double / int = 1.75
int / double = 1.75
double / double = 1.75

Ce qui précède illustre que si l'un des opérandes est un nombre en virgule flottante, le résultat sera une division en virgule flottante, et non une division entière.

Division par 0 et 0.0

La division entière par un diviseur égal à 0 provoque un comportement indéfini, car le résultat est mathématiquement indéfini !

#include <iostream>

int main()
{
    constexpr int apples { 12 };
    std::cout << "You have " << apples << " apples. Enter how many people to divide them between: ";
    int x {};
    std::cin >> x;

    std::cout << "Each person gets " << apples / x << " whole apples.\n"; // apples and x are int, so this is integer division

    return 0;
}

Si vous exécutez le programme ci-dessus et saisissez 0, votre programme plantera probablement. Essayez-le, cela ne nuira pas à votre ordinateur.

Le résultat d'une division par la valeur en virgule flottante 0.0 dépend de l'implémentation (c'est-à-dire que le comportement est déterminé par le compilateur et l'architecture). Sur les architectures qui prennent en charge le format en virgule flottante IEEE754, le résultat sera NaN ou Inf. Sur les autres architectures, il s'agira probablement d'un comportement indéfini.

Contenu associé

Nous abordons NaN et Inf dans la leçon 4.8 -- Nombres en virgule flottante.

Vous pouvez observer le comportement de votre programme en exécutant le programme suivant et en saisissant 0 ou 0.0 :

#include <iostream>

int main()
{
    constexpr int apples { 12 };
    std::cout << "You have " << apples << " apples. Enter how many servings of apples you want: ";

    double d {};
    std::cin >> d;

    std::cout << "Each serving is " << apples / d << " apples.\n"; // d is double, so this is floating point division

    return 0;
}

Opérateurs d'affectation arithmétique

Opérateur Symbole Forme Opération
Affectation par addition += x += y Ajoute y à x
Affectation par soustraction -= x -= y Soustrait y de x
Affectation par multiplication *= x *= y Multiplie x par y
Affectation par division /= x /= y Divise x par y
Affectation par reste %= x %= y Place le reste de x / y dans x

Jusqu'à présent, lorsque vous deviez ajouter 4 à une variable, vous avez probablement écrit ceci :

x = x + 4; // ajoute 4 à la valeur existante de x

Cela fonctionne, mais c'est un peu lourd, et cela nécessite deux opérateurs pour être exécuté (operator+ et operator=).

Comme l'écriture d'instructions telles que x = x + 4 est très courante, C++ fournit cinq opérateurs d'affectation arithmétique pour plus de commodité. Au lieu d'écrire x = x + 4, vous pouvez écrire x += 4. Au lieu de x = x * y, vous pouvez écrire x *= y.

Ainsi, ce qui précède devient :

x += 4; // ajoute 4 à la valeur existante de x

Opérateurs modifiants et non modifiants

Un opérateur capable de modifier la valeur de l'un de ses opérandes est couramment appelé opérateur modifiant. En C++, la plupart des opérateurs sont non modifiants : ils utilisent simplement leurs opérandes pour calculer et renvoyer une valeur. Cependant, deux catégories d'opérateurs intégrés modifient leur opérande de gauche (en plus de renvoyer une valeur) :

  • Les opérateurs d'affectation, y compris l'opérateur d'affectation standard (=), les opérateurs d'affectation arithmétique (+=, -=, *=, /= et %=), et les opérateurs d'affectation binaire (<<=, >>=, &=, |= et ^=).
  • Les opérateurs d'incrémentation et de décrémentation (++ et -- respectivement). Nous les étudions dans la leçon 6.4 -- Opérateurs d'incrémentation/décrémentation et effets de bord.

Ne font pas partie de cette liste les opérateurs ==, !=, <= et >=, car ce sont des opérateurs relationnels (de comparaison) non modifiants (le = signifie « est égal à »). Nous les étudions dans la leçon 6.7 -- Opérateurs relationnels et comparaisons en virgule flottante.

Pour les lecteurs avancés

Les opérateurs surchargés peuvent être redéfinis pour avoir un comportement différent de celui des opérateurs intégrés, y compris la modification de l'opérande de gauche alors que la version intégrée ne le fait pas (ou inversement). Par exemple, la version surchargée de operator<< utilisée pour la sortie modifie son opérande de gauche (l'objet flux de sortie).
