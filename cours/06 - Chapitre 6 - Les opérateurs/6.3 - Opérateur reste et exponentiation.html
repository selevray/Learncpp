6.3 — Opérateur reste et exponentiation

L'opérateur reste (operator%)

L'opérateur reste (remainder operator), aussi appelé couramment opérateur modulo (modulo operator) ou modulo (modulus operator), renvoie le reste d'une division entière. Par exemple, 7 / 4 donne 1 avec un reste de 3, donc 7 % 4 vaut 3. De même, 25 / 7 donne 3 avec un reste de 4, donc 25 % 7 vaut 4. L'opérateur reste ne fonctionne qu'avec des opérandes entiers.

Il est particulièrement utile pour tester si un nombre est divisible exactement par un autre (c'est-à-dire si la division ne laisse aucun reste) : si x % y vaut 0, alors x est divisible exactement par y.

#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    int x{};
    std::cin >> x;

    std::cout << "Enter another integer: ";
    int y{};
    std::cin >> y;

    std::cout << "The remainder is: " << x % y << '\n';

    if ((x % y) == 0)
        std::cout << x << " is evenly divisible by " << y << '\n';
    else
        std::cout << x << " is not evenly divisible by " << y << '\n';

    return 0;
}

Voici deux exécutions de ce programme :


Enter an integer: 6
Enter another integer: 3
The remainder is: 0
6 is evenly divisible by 3


Enter an integer: 6
Enter another integer: 4
The remainder is: 2
6 is not evenly divisible by 4

Essayons maintenant un exemple où le second nombre est plus grand que le premier :


Enter an integer: 2
Enter another integer: 4
The remainder is: 2
2 is not evenly divisible by 4

Un reste de 2 peut sembler un peu surprenant au premier abord, mais c'est simple : 2 / 4 vaut 0 (en division entière) avec un reste de 2. Dès que le second nombre est plus grand que le premier, il ne peut diviser le premier que 0 fois, si bien que le premier nombre devient le reste.

Reste avec des nombres négatifs

L'opérateur reste peut aussi travailler avec des opérandes négatifs. x % y renvoie toujours un résultat dont le signe est celui de x.

En exécutant le programme ci-dessus :


Enter an integer: -6
Enter another integer: 4
The remainder is: -2
-6 is not evenly divisible by 4


Enter an integer: 6
Enter another integer: -4
The remainder is: 2
6 is not evenly divisible by -4

Dans les deux cas, on constate que le reste prend le signe du premier opérande.

Nomenclature

La norme C++ ne donne pas vraiment de nom à operator%. Toutefois, la norme C++20 indique : « l'opérateur binaire % produit le reste de la division de la première expression par la seconde ».

Bien que operator% soit souvent appelé opérateur « modulo » ou « modulus », cela peut prêter à confusion, car le modulo en mathématiques est souvent défini d'une manière qui donne un résultat différent de celui de operator% en C++ lorsqu'un seul des opérandes (et un seul) est négatif.

Par exemple, en mathématiques :
-21 modulo 4 = 3
-21 reste 4 = -1

Pour cette raison, nous pensons que le nom « reste » (remainder) est plus exact que « modulo » pour désigner operator%.

Lorsque le premier opérande peut être négatif, il faut bien garder à l'esprit que le reste peut lui aussi être négatif. Par exemple, vous pourriez être tenté d'écrire une fonction qui indique si un nombre est impair, de la manière suivante :

bool isOdd(int x)
{
    return (x % 2) == 1; // fails when x is -5
}

Cependant, cette fonction échoue lorsque x est un nombre impair négatif, comme -5, car -5 % 2 vaut -1, et -1 != 1.

Pour cette raison, si vous comparez le résultat d'une opération reste, il vaut mieux le comparer à 0, qui n'est pas concerné par le problème des signes :

bool isOdd(int x)
{
    return (x % 2) != 0; // could also write return (x % 2)
}

Bonne pratique

Comparez, si possible, le résultat de l'opérateur reste (operator%) à 0.

Et l'opérateur d'exposant ?

Vous remarquerez que l'opérateur ^ (couramment utilisé pour désigner l'exponentiation en mathématiques) correspond en C++ à un OU exclusif bit à bit (Bitwise XOR), comme vu dans la leçon O.3 -- Manipulation de bits avec les opérateurs bit à bit et les masques de bits. Le C++ ne possède pas d'opérateur d'exposant.

Pour calculer une puissance en C++, incluez l'en-tête <cmath> et utilisez la fonction pow() :

#include <cmath>

double x{ std::pow(3.0, 4.0) }; // 3 à la puissance 4

Notez que les paramètres (ainsi que la valeur de retour) de la fonction pow() sont de type double. En raison des erreurs d'arrondi propres aux nombres à virgule flottante, les résultats de pow() peuvent ne pas être exacts (même si vous lui passez des entiers).

Si vous voulez calculer une puissance entière, le mieux est d'écrire votre propre fonction. La fonction suivante implémente l'exponentiation entière (en utilisant l'algorithme d'« exponentiation par carrés », peu intuitif mais efficace) :

#include <cassert> // pour assert
#include <cstdint> // pour std::int64_t
#include <iostream>

// note: exp must be non-negative
// note: does not perform range/overflow checking, use with caution
constexpr std::int64_t powint(std::int64_t base, int exp)
{
    assert(exp >= 0 && "powint: exp parameter has negative value");

    // Traitement du cas 0
    if (base == 0)
        return (exp == 0) ? 1 : 0;

    std::int64_t result{ 1 };
    while (exp > 0)
    {
        if (exp & 1)  // si exp est impair
            result *= base;
        exp /= 2;
        base *= base;
    }

    return result;
}

int main()
{
    std::cout << powint(7, 12) << '\n'; // 7 à la puissance 12

    return 0;
}

Produit :


13841287201

Ne vous inquiétez pas si vous ne comprenez pas le fonctionnement de cette fonction : il n'est pas nécessaire de le comprendre pour l'appeler.

Pour les lecteurs avancés

Le spécificateur constexpr permet à une fonction d'être évaluée à la compilation si elle est utilisée dans une expression constante ; sinon, elle se comporte comme une fonction ordinaire et est évaluée à l'exécution.

Avertissement

Dans la grande majorité des cas, l'exponentiation entière provoque un dépassement de capacité du type entier. C'est probablement la raison pour laquelle une telle fonction n'a pas été incluse dans la bibliothèque standard.

Voici une version plus sûre de la fonction d'exponentiation ci-dessus, qui vérifie les dépassements de capacité :

#include <cassert> // pour assert
#include <cstdint> // pour std::int64_t
#include <iostream>
#include <limits> // pour std::numeric_limits

// A safer (but slower) version of powint() that checks for overflow
// note: exp must be non-negative
// Returns std::numeric_limits<std::int64_t>::max() if overflow occurs
constexpr std::int64_t powint_safe(std::int64_t base, int exp)
{
    assert(exp >= 0 && "powint_safe: exp parameter has negative value");

    // Traitement du cas 0
    if (base == 0)
        return (exp == 0) ? 1 : 0;

    std::int64_t result { 1 };

    // Pour faciliter les vérifications de bornes, on s'assure que base est positif
    // On inversera le résultat à la fin si nécessaire
    bool negativeResult{ false };

    if (base < 0)
    {
        base = -base;
        negativeResult = (exp & 1);
    }

    while (exp > 0)
    {
        if (exp & 1) // si exp est impair
        {
            // Vérifie si le résultat va déborder lorsqu'il est multiplié par base
            if (result > std::numeric_limits<std::int64_t>::max() / base)
            {
                std::cerr << "powint_safe(): result overflowed\n";
                return std::numeric_limits<std::int64_t>::max();
            }

            result *= base;
        }

        exp /= 2;

        // Si on a terminé, on sort ici
        if (exp <= 0)
            break;

        // La suite ne doit être exécutée que si on va effectuer une nouvelle itération

        // Vérifie si base va déborder lorsqu'il est multiplié par lui-même
        if (base > std::numeric_limits<std::int64_t>::max() / base)
        {
            std::cerr << "powint_safe(): base overflowed\n";
            return std::numeric_limits<std::int64_t>::max();
        }

        base *= base;
    }

    if (negativeResult)
        return -result;

    return result;
}

int main()
{
    std::cout << powint_safe(7, 12) << '\n'; // 7 à la puissance 12
    std::cout << powint_safe(70, 12) << '\n'; // 70 à la puissance 12 (renvoie la valeur maximale d'un entier 64 bits)

    return 0;
}

C'est l'heure du quiz

Question n° 1

À quoi l'expression suivante est-elle évaluée ? 6 + 5 * 4 % 3

Solution

Comme * et % ont une priorité supérieure à +, le + sera évalué en dernier. On peut réécrire l'expression ainsi : 6 + (5 * 4 % 3). Les opérateurs * et % ont la même priorité, il faut donc regarder l'associativité pour les départager. L'associativité des opérateurs * et % est de gauche à droite, on évalue donc d'abord l'opérateur de gauche. On peut réécrire l'expression ainsi : 6 + ((5 * 4) % 3).

6 + ((5 * 4) % 3) = 6 + (20 % 3) = 6 + 2 = 8

Question n° 2

Écrivez un programme qui demande à l'utilisateur de saisir un entier et lui indique si ce nombre est pair ou impair. Écrivez une fonction constexpr appelée isEven() qui renvoie true si l'entier qui lui est passé est pair, et false sinon. Utilisez l'opérateur reste pour tester si le paramètre entier est pair. Assurez-vous que isEven() fonctionne avec les nombres positifs et négatifs.

Indice

Indice : vous pourriez avoir besoin d'instructions if et de l'opérateur de comparaison (==) pour ce programme. Consultez la leçon 4.9 -- Les valeurs booléennes si vous avez besoin de revoir comment faire.

Votre programme doit produire le résultat suivant :


Enter an integer: 5
5 is odd
Solution 
#include <iostream>

constexpr bool isEven(int x)
{
    // si x % 2 == 0, 2 divise exactement notre nombre, qui est donc pair
    return (x % 2) == 0;
}

int main()
{
    std::cout << "Enter an integer: ";
    int x{};
    std::cin >> x;

    if (isEven(x))
        std::cout << x << " is even\n";
    else
        std::cout << x << " is odd\n";

    return 0;
}

Remarque : vous avez peut-être été tenté d'écrire la fonction isEven() de la manière suivante :

constexpr bool isEven(int x)
{
    if ((x % 2) == 0)
        return true;
    else
        return false;
}

Bien que cela fonctionne, c'est plus compliqué que nécessaire. Voyons comment la simplifier. Tout d'abord, extrayons la condition de l'instruction if et affectons-la à un booléen séparé :

constexpr bool isEven(int x)
{
    bool isEven = (x % 2) == 0;
    if (isEven) // isEven est vrai
        return true;
    else // isEven est faux
        return false;
}

Remarquez maintenant que l'instruction if ci-dessus signifie en substance « si isEven est vrai, renvoyer true, sinon si isEven est faux, renvoyer false ». Dans ce cas, il suffit de renvoyer isEven :

constexpr bool isEven(int x)
{
    bool isEven = (x % 2) == 0;
    return isEven;
}

Et comme nous n'utilisons la variable isEven qu'une seule fois, autant la supprimer :

constexpr bool isEven(int x)
{
    return (x % 2) == 0;
}
