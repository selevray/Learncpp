6.x — Résumé du chapitre 6 et quiz

Bilan rapide

Utilisez toujours des parenthèses pour lever toute ambiguïté sur la priorité des opérateurs, dès qu'il existe un doute ou un risque de confusion.

Les opérateurs arithmétiques fonctionnent comme en mathématiques classiques. L'opérateur de reste (%) renvoie le reste d'une division entière.

Les opérateurs d'incrémentation et de décrémentation permettent d'augmenter ou de diminuer facilement un nombre. Évitez autant que possible leurs versions postfixées.

Méfiez-vous des effets de bord, en particulier en ce qui concerne l'ordre d'évaluation des paramètres de fonction. N'utilisez pas plusieurs fois, dans une même instruction, une variable soumise à un effet de bord.

L'opérateur virgule peut regrouper plusieurs instructions en une seule. Écrire les instructions séparément est généralement préférable.

L'opérateur conditionnel (?:) (parfois appelé opérateur arithmétique if) est un opérateur ternaire (un opérateur qui prend 3 opérandes). Pour une opération conditionnelle de la forme c ? x : y, si la condition c vaut true, alors x est évalué, sinon y est évalué. L'opérateur conditionnel doit généralement être mis entre parenthèses, selon les règles suivantes :

  • Mettez l'ensemble de l'opérateur conditionnel entre parenthèses lorsqu'il est utilisé dans une expression composée (une expression contenant d'autres opérateurs).
  • Pour la lisibilité, mettez la condition entre parenthèses si elle contient des opérateurs (autres que l'opérateur d'appel de fonction).

Les opérateurs relationnels peuvent comparer des nombres à virgule flottante. Faites attention lorsque vous utilisez l'égalité et la différence sur des nombres à virgule flottante.

Les opérateurs logiques permettent de former des conditions composées.

Quiz

Complétez le programme suivant :

#include <iostream>

// Écrivez la fonction getQuantityPhrase() ici

// Écrivez la fonction getApplesPluralized() ici

int main()
{
    constexpr int maryApples { 3 };
    std::cout << "Mary has " << getQuantityPhrase(maryApples) << ' ' << getApplesPluralized(maryApples) << ".\n";

    std::cout << "How many apples do you have? ";
    int numApples{};
    std::cin >> numApples;

    std::cout << "You have " << getQuantityPhrase(numApples) << ' ' << getApplesPluralized(numApples) << ".\n";

    return 0;
}

Exemple de sortie :


Mary has a few apples.
How many apples do you have? 1
You have a single apple.

getQuantityPhrase() doit prendre un unique paramètre de type int représentant la quantité d'un objet et renvoyer le descripteur suivant :

  • < 0 = « negative »
  • 0 = « no »
  • 1 = « a single »
  • 2 = « a couple of »
  • 3 = « a few »

  • 3 = « many »

getApplesPluralized() doit prendre un unique paramètre de type int représentant la quantité de pommes et renvoyer ce qui suit :

  • 1 = « apple »
  • sinon = « apples »

Cette fonction doit utiliser l'opérateur conditionnel.

Indice

Indice : il est possible de renvoyer une chaîne littérale de style C sous forme de std::string_view depuis une fonction.

Solution 
#include <iostream>
#include <string_view>

std::string_view getQuantityPhrase(int num)
{
    if (num < 0)
        return "negative";
    if (num == 0)
        return "no";
    if (num == 1)
        return "a single";
    if (num == 2)
        return "a couple of";
    if (num == 3)
        return "a few";
    return "many";
}

std::string_view getApplesPluralized(int num)
{
    return (num == 1) ? "apple" : "apples";
}

int main()
{
    constexpr int maryApples { 3 };
    std::cout << "Mary has " << getQuantityPhrase(maryApples) << ' ' << getApplesPluralized(maryApples) << ".\n";

    std::cout << "How many apples do you have? ";
    int numApples{};
    std::cin >> numApples;

    std::cout << "You have " << getQuantityPhrase(numApples) << ' ' << getApplesPluralized(numApples) << ".\n";

    return 0;
}
