28.5 — États des flux et validation des entrées

États des flux

La classe ios_base contient plusieurs indicateurs d'état qui signalent les différentes situations pouvant survenir lors de l'utilisation des flux :

Indicateur Signification
goodbit Tout va bien
badbit Une erreur fatale s'est produite (par exemple, le programme a tenté de lire au-delà de la fin d'un fichier)
eofbit Le flux a atteint la fin d'un fichier
failbit Une erreur non fatale s'est produite (par exemple, l'utilisateur a saisi des lettres alors que le programme attendait un entier)

Bien que ces indicateurs soient définis dans ios_base, comme ios dérive de ios_base et que ios s'écrit plus rapidement qu'ios_base, on y accède généralement via ios (par exemple sous la forme std::ios::failbit).

ios fournit également un certain nombre de fonctions membres permettant d'accéder commodément à ces états :

Fonction membre Signification
good() Renvoie true si le goodbit est positionné (le flux est correct)
bad() Renvoie true si le badbit est positionné (une erreur fatale s'est produite)
eof() Renvoie true si l'eofbit est positionné (le flux est à la fin d'un fichier)
fail() Renvoie true si le failbit est positionné (une erreur non fatale s'est produite)
clear() Efface tous les indicateurs et remet le flux dans l'état goodbit
clear(state) Efface tous les indicateurs et positionne l'indicateur passé en paramètre
rdstate() Renvoie les indicateurs actuellement positionnés
setstate(state) Positionne l'indicateur passé en paramètre

Le bit le plus souvent rencontré est le failbit, positionné lorsque l'utilisateur saisit une entrée invalide. Par exemple, considérons le programme suivant :

std::cout << "Enter your age: ";
int age {};
std::cin >> age;

Notez que ce programme attend de l'utilisateur qu'il saisisse un entier. Cependant, si l'utilisateur saisit des données non numériques, comme « Alex », cin ne pourra rien extraire vers age, et le failbit sera positionné.

Si une erreur survient et qu'un flux est positionné sur autre chose que le goodbit, les opérations ultérieures sur ce flux seront ignorées. Cette situation peut être corrigée en appelant la fonction clear().

Validation des entrées

La validation des entrées (input validation) consiste à vérifier que la saisie de l'utilisateur respecte un ensemble de critères. On peut généralement la diviser en deux types : la validation de chaînes et la validation numérique.

Avec la validation de chaînes, on accepte toute saisie de l'utilisateur sous forme de chaîne, puis on accepte ou on rejette cette chaîne selon qu'elle est correctement formatée. Par exemple, si l'on demande à l'utilisateur de saisir un numéro de téléphone, on peut vouloir s'assurer que les données comportent dix chiffres. Dans la plupart des langages (en particulier les langages de script comme Perl et PHP), cela se fait à l'aide d'expressions régulières. La bibliothèque standard C++ dispose elle aussi d'une bibliothèque d'expressions régulières. Les expressions régulières étant lentes comparées à une validation manuelle des chaînes, il ne faut les utiliser que si les performances (à la compilation comme à l'exécution) importent peu, ou si la validation manuelle est trop fastidieuse.

Avec la validation numérique, on s'intéresse généralement à vérifier que le nombre saisi par l'utilisateur se situe dans un intervalle donné (par exemple entre 0 et 20). Cependant, contrairement à la validation de chaînes, l'utilisateur peut saisir des choses qui ne sont pas du tout des nombres, et il faut gérer ces cas également.

Pour nous aider, C++ fournit plusieurs fonctions utiles permettant de déterminer si des caractères donnés sont des chiffres ou des lettres. Les fonctions suivantes se trouvent dans l'en-tête cctype :

Fonction Signification
std::isalnum(int) Renvoie une valeur non nulle si le paramètre est une lettre ou un chiffre
std::isalpha(int) Renvoie une valeur non nulle si le paramètre est une lettre
std::iscntrl(int) Renvoie une valeur non nulle si le paramètre est un caractère de contrôle
std::isdigit(int) Renvoie une valeur non nulle si le paramètre est un chiffre
std::isgraph(int) Renvoie une valeur non nulle si le paramètre est un caractère imprimable qui n'est pas un espace blanc
std::isprint(int) Renvoie une valeur non nulle si le paramètre est un caractère imprimable (espaces blancs compris)
std::ispunct(int) Renvoie une valeur non nulle si le paramètre n'est ni alphanumérique ni un espace blanc
std::isspace(int) Renvoie une valeur non nulle si le paramètre est un espace blanc
std::isxdigit(int) Renvoie une valeur non nulle si le paramètre est un chiffre hexadécimal (0-9, a-f, A-F)

Validation de chaînes

Prenons un exemple simple de validation de chaîne en demandant à l'utilisateur de saisir son nom. Notre critère de validation sera que l'utilisateur ne saisisse que des caractères alphabétiques ou des espaces. Si un autre caractère est rencontré, la saisie sera rejetée.

Lorsqu'il s'agit d'entrées de longueur variable, la meilleure façon de valider des chaînes (hormis l'usage d'une bibliothèque d'expressions régulières) consiste à parcourir chaque caractère de la chaîne et à vérifier qu'il respecte le critère de validation. C'est exactement ce que nous allons faire ici, ou plutôt, c'est ce que std::all_of fait pour nous.

#include <algorithm> // std::all_of
#include <cctype> // std::isalpha, std::isspace
#include <iostream>
#include <ranges>
#include <string>
#include <string_view>

bool isValidName(std::string_view name)
{
  return std::ranges::all_of(name, [](char ch) {
    return std::isalpha(ch) || std::isspace(ch);
  });

  // Avant C++20, sans les ranges
  // return std::all_of(name.begin(), name.end(), [](char ch) {
  //    return std::isalpha(ch) || std::isspace(ch);
  // });
}

int main()
{
  std::string name{};

  do
  {
    std::cout << "Enter your name: ";
    std::getline(std::cin, name); // récupère la ligne entière, espaces compris
  } while (!isValidName(name));

  std::cout << "Hello " << name << "!\n";
}

Notez que ce code n'est pas parfait : l'utilisateur pourrait saisir comme nom « asf w jweo s di we ao » ou une autre suite de mots dénuée de sens, voire, pire encore, une simple suite d'espaces. On pourrait en partie remédier à cela en affinant nos critères de validation pour n'accepter que des chaînes contenant au moins un caractère et au plus un espace.

Voyons maintenant un autre exemple où l'on demande à l'utilisateur de saisir son numéro de téléphone. Contrairement au nom d'un utilisateur, qui est de longueur variable et dont les critères de validation sont identiques pour chaque caractère, un numéro de téléphone a une longueur fixe, mais les critères de validation dépendent de la position du caractère. En conséquence, nous allons adopter une approche différente pour valider la saisie du numéro de téléphone. Ici, nous allons écrire une fonction qui vérifie la saisie de l'utilisateur par rapport à un modèle prédéfini. Le modèle fonctionne de la manière suivante :

Un # correspond à n'importe quel chiffre de la saisie de l'utilisateur.
Un @ correspond à n'importe quel caractère alphabétique de la saisie de l'utilisateur.
Un _ correspond à n'importe quel espace blanc.
Un ? correspond à n'importe quel caractère.
Sinon, les caractères de la saisie de l'utilisateur et du modèle doivent correspondre exactement.

Ainsi, si nous demandons à la fonction de faire correspondre le modèle « (###) ###-#### », cela signifie que nous attendons de l'utilisateur qu'il saisisse un caractère « ( », trois chiffres, un caractère « ) », un espace, trois chiffres, un tiret, puis quatre chiffres supplémentaires. Si l'un de ces éléments ne correspond pas, la saisie sera rejetée.

Voici le code :

#include <algorithm> // std::equal
#include <cctype> // std::isdigit, std::isspace, std::isalpha
#include <iostream>
#include <map>
#include <ranges>
#include <string>
#include <string_view>

bool inputMatches(std::string_view input, std::string_view pattern)
{
    if (input.length() != pattern.length())
    {
        return false;
    }

    // Cette table définit tous les symboles spéciaux pouvant correspondre à une plage de saisie utilisateur
    // Chaque symbole est associé à une fonction qui détermine si la saisie est valide pour ce symbole
    static const std::map<char, int (*)(int)> validators{
      { '#', &std::isdigit },
      { '_', &std::isspace },
      { '@', &std::isalpha },
      { '?', [](int) { return 1; } }
    };

    // Avant C++20, utilisez
    // return std::equal(input.begin(), input.end(), pattern.begin(), [](char ch, char mask) -> bool {
    // ...

    return std::ranges::equal(input, pattern, [](char ch, char mask) -> bool {
        auto found{ validators.find(mask) };

        if (found != validators.end())
        {
            // L'élément courant du modèle a été trouvé dans validators. Appelle la
            // fonction correspondante.
            return (*found->second)(ch);
        }

        // L'élément courant du modèle n'a pas été trouvé dans validators. Les
        // caractères doivent correspondre exactement.
        return ch == mask;
        }); // fin de la lambda
}

int main()
{
    std::string phoneNumber{};

    do
    {
        std::cout << "Enter a phone number (###) ###-####: ";
        std::getline(std::cin, phoneNumber);
    } while (!inputMatches(phoneNumber, "(###) ###-####"));

    std::cout << "You entered: " << phoneNumber << '\n';
}

Cette fonction nous permet d'imposer à l'utilisateur de respecter exactement notre format. Cependant, elle reste soumise à plusieurs contraintes : si #, @, _ et ? sont des caractères valides dans la saisie de l'utilisateur, cette fonction ne fonctionnera pas, car ces symboles ont reçu une signification particulière. De plus, contrairement aux expressions régulières, il n'existe aucun symbole de modèle signifiant « un nombre variable de caractères peut être saisi ». Ainsi, un tel modèle ne pourrait pas servir à s'assurer que l'utilisateur saisit deux mots séparés par un espace blanc, car il ne peut pas gérer le fait que les mots sont de longueurs variables. Pour ce type de problème, l'approche sans modèle est généralement plus appropriée.

Validation numérique

Lorsqu'on traite une saisie numérique, la solution évidente consiste à utiliser l'opérateur d'extraction pour extraire la saisie vers un type numérique. En testant le failbit, on peut alors savoir si l'utilisateur a saisi un nombre ou non.

Essayons cette approche :

#include <iostream>
#include <limits>

int main()
{
    int age{};

    while (true)
    {
        std::cout << "Enter your age: ";
        std::cin >> age;

        if (std::cin.fail()) // aucune extraction n'a eu lieu
        {
            std::cin.clear(); // remet les bits d'état à goodbit afin de pouvoir utiliser ignore()
            std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n'); // vide la mauvaise saisie du flux
            continue; // on recommence
        }

        if (age <= 0) // vérifie que l'âge est positif
            continue;

        break;
    }

    std::cout << "You entered: " << age << '\n';
}

Si l'utilisateur saisit un entier, l'extraction réussit. std::cin.fail() vaut alors false, le bloc conditionnel est ignoré et, en supposant que l'utilisateur ait saisi un nombre positif, on atteint l'instruction break, ce qui quitte la boucle.

Si l'utilisateur saisit une entrée commençant par une lettre, l'extraction échoue. std::cin.fail() vaut alors true et nous entrons dans le bloc conditionnel. À la fin de ce bloc, on atteint l'instruction continue, qui renvoie au début de la boucle while, et l'utilisateur est invité à saisir de nouveau.

Cependant, il reste un cas que nous n'avons pas testé : celui où l'utilisateur saisit une chaîne commençant par des chiffres mais contenant ensuite des lettres (par exemple « 34abcd56 »). Dans ce cas, les chiffres initiaux (34) sont extraits vers age, le reste de la chaîne (« abcd56 ») reste dans le flux d'entrée, et le failbit n'est PAS positionné. Cela pose deux problèmes potentiels :

  1. Si vous souhaitez que cette saisie soit valide, vous avez maintenant des données parasites dans votre flux.
  2. Si vous ne souhaitez pas que cette saisie soit valide, elle n'est pas rejetée (et vous avez tout de même des données parasites dans votre flux).

Corrigeons le premier problème. C'est facile :

#include <iostream>
#include <limits>

int main()
{
    int age{};

    while (true)
    {
        std::cout << "Enter your age: ";
        std::cin >> age;

        if (std::cin.fail()) // aucune extraction n'a eu lieu
        {
            std::cin.clear(); // remet les bits d'état à goodbit afin de pouvoir utiliser ignore()
            std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n'); // vide la mauvaise saisie du flux
            continue; // on recommence
        }

        std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n'); // vide les éventuelles saisies supplémentaires du flux

        if (age <= 0) // vérifie que l'âge est positif
            continue;

      break;
    }

    std::cout << "You entered: " << age << '\n';
}

Si vous ne voulez pas qu'une telle saisie soit valide, il faudra un peu plus de travail. Heureusement, la solution précédente nous fait déjà parcourir la moitié du chemin. Nous pouvons utiliser la fonction gcount() pour déterminer combien de caractères ont été ignorés. Si la saisie était valide, gcount() devrait renvoyer 1 (le caractère de fin de ligne qui a été écarté). S'il renvoie plus de 1, l'utilisateur a saisi quelque chose qui n'a pas été extrait correctement, et nous devons lui demander une nouvelle saisie. Voici un exemple :

#include <iostream>
#include <limits>

int main()
{
    int age{};

    while (true)
    {
        std::cout << "Enter your age: ";
        std::cin >> age;

        if (std::cin.fail()) // aucune extraction n'a eu lieu
        {
            std::cin.clear(); // remet les bits d'état à goodbit afin de pouvoir utiliser ignore()
            std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n'); // vide la mauvaise saisie du flux
            continue; // on recommence
        }

        std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n'); // vide les éventuelles saisies supplémentaires du flux
        if (std::cin.gcount() > 1) // si nous avons vidé plus d'un caractère supplémentaire
        {
            continue; // nous considérons cette saisie comme invalide
        }

        if (age <= 0) // vérifie que l'âge est positif
        {
            continue;
        }

        break;
    }

    std::cout << "You entered: " << age << '\n';
}

Validation numérique sous forme de chaîne

L'exemple précédent représentait beaucoup de travail pour obtenir une simple valeur ! Une autre façon de traiter une saisie numérique consiste à la lire sous forme de chaîne, puis à tenter de la convertir en type numérique. Le programme suivant utilise cette méthode :

#include <charconv> // std::from_chars
#include <iostream>
#include <limits>
#include <optional>
#include <string>
#include <string_view>

// std::optional<int> renvoie soit un int, soit rien
std::optional<int> extractAge(std::string_view age)
{
    int result{};
    const auto end{ age.data() + age.length() }; // obtient l'itérateur de fin de la chaîne de style C sous-jacente

    // Tente d'analyser un int à partir de age
    // Si une erreur quelconque s'est produite...
    if (std::from_chars(age.data(), end, result).ec != std::errc{})
    {
        return {}; // renvoie rien
    }

    if (result <= 0) // vérifie que l'âge est positif
    {
        return {}; // renvoie rien
    }

    return result; // renvoie une valeur int
}

int main()
{
    int age{};

    while (true)
    {
        std::cout << "Enter your age: ";
        std::string strAge{};

        // Tente de récupérer une ligne de saisie
        if (!std::getline(std::cin >> std::ws, strAge))
        {
            // En cas d'échec, nettoie et recommence
            std::cin.clear();
            std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');    
            continue;
        }

        // Tente d'extraire l'âge
        auto extracted{ extractAge(strAge) };

        // En cas d'échec, on recommence
        if (!extracted)
            continue;

        age = *extracted; // récupère la valeur
        break;
    }

  std::cout << "You entered: " << age << '\n';
}

Le fait que cette approche demande plus ou moins de travail que l'extraction numérique directe dépend de vos paramètres et de vos contraintes de validation.

Comme vous le voyez, la validation des entrées en C++ demande beaucoup de travail. Heureusement, nombre de ces tâches (par exemple la validation numérique sous forme de chaîne) peuvent facilement être transformées en fonctions réutilisables dans des situations très variées.
