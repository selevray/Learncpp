28.4 — Classes de flux pour les chaînes de caractères

Jusqu'à présent, tous les exemples d'entrées/sorties que vous avez vus écrivaient dans cout ou lisaient depuis cin. Il existe cependant un autre ensemble de classes, les classes de flux pour les chaînes de caractères (string streams), qui vous permettent d'utiliser les opérateurs d'insertion (<<) et d'extraction (>>), familiers, pour manipuler des chaînes. Comme istream et ostream, les flux de chaînes disposent d'un tampon (buffer) pour contenir des données. Cependant, contrairement à cin et cout, ces flux ne sont pas reliés à un canal d'entrée/sortie (clavier, écran, etc.). L'une des principales utilisations des flux de chaînes consiste à mettre en tampon une sortie pour un affichage ultérieur, ou à traiter une entrée ligne par ligne.

Il existe six classes de flux pour les chaînes : istringstream (dérivée de istream), ostringstream (dérivée de ostream) et stringstream (dérivée de iostream) servent à lire et écrire des chaînes de caractères normaux. wistringstream, wostringstream et wstringstream servent à lire et écrire des chaînes de caractères larges. Pour utiliser les stringstream, vous devez inclure l'en-tête sstream.

Il existe deux façons d'introduire des données dans un stringstream :

  1. Utiliser l'opérateur d'insertion (<<) :
std::stringstream os {};
os << "en garde!\n"; // insère "en garde!" dans le stringstream
  1. Utiliser la fonction str(string) pour définir la valeur du tampon :
std::stringstream os {};
os.str("en garde!"); // définit le tampon du stringstream à "en garde!"

Il existe de même deux façons d'extraire des données d'un stringstream :

  1. Utiliser la fonction str() pour récupérer le contenu du tampon :
std::stringstream os {};
os << "12345 67.89\n";
std::cout << os.str();

Ce programme affiche :


12345 67.89
  1. Utiliser l'opérateur d'extraction (>>) :
std::stringstream os {};
os << "12345 67.89"; // insère une chaîne de nombres dans le flux

std::string strValue {};
os >> strValue;

std::string strValue2 {};
os >> strValue2;

// affiche les nombres séparés par un tiret
std::cout << strValue << " - " << strValue2 << '\n';

Ce programme affiche :


12345 - 67.89

Notez que l'opérateur >> parcourt la chaîne : chaque utilisation successive de >> renvoie la valeur extractible suivante du flux. En revanche, str() renvoie la valeur complète du flux, même si >> a déjà été utilisé sur celui-ci.

Conversion entre chaînes et nombres

Comme les opérateurs d'insertion et d'extraction savent travailler avec tous les types de base, nous pouvons les utiliser pour convertir des chaînes en nombres, ou inversement.

Commençons par convertir des nombres en chaîne :

std::stringstream os {};

constexpr int nValue { 12345 };
constexpr double dValue { 67.89 };
os << nValue << ' ' << dValue;

std::string strValue1, strValue2;
os >> strValue1 >> strValue2;

std::cout << strValue1 << ' ' << strValue2 << '\n';

Cet extrait affiche :


12345 67.89

Convertissons maintenant une chaîne numérique en nombre :

std::stringstream os {};
os << "12345 67.89"; // insère une chaîne de nombres dans le flux
int nValue {};
double dValue {};

os >> nValue >> dValue;

std::cout << nValue << ' ' << dValue << '\n';

Ce programme affiche :


12345 67.89

Vider un stringstream pour le réutiliser

Il existe plusieurs façons de vider le tampon d'un stringstream.

  1. Le remettre à la chaîne vide à l'aide de str() avec une chaîne C vide :
std::stringstream os {};
os << "Hello ";

os.str(""); // efface le tampon

os << "World!";
std::cout << os.str();
  1. Le remettre à la chaîne vide à l'aide de str() avec un objet std::string vide :
std::stringstream os {};
os << "Hello ";

os.str(std::string{}); // efface le tampon

os << "World!";
std::cout << os.str();

Ces deux programmes produisent le même résultat :


World!

Lorsque vous videz un stringstream, il est également recommandé d'appeler la fonction clear() :

std::stringstream os {};
os << "Hello ";

os.str(""); // efface le tampon
os.clear(); // réinitialise les indicateurs d'erreur

os << "World!";
std::cout << os.str();

clear() réinitialise les indicateurs d'erreur éventuellement positionnés et ramène le flux à l'état ok. Nous reparlerons plus en détail de l'état des flux et des indicateurs d'erreur dans la prochaine leçon.
