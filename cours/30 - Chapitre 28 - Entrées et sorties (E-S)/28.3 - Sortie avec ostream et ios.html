28.3 — Sortie avec ostream et ios

Dans cette section, nous allons examiner différents aspects de la classe de sortie d'iostream (ostream).

L'opérateur d'insertion

L'opérateur d'insertion (<<) sert à placer des informations dans un flux de sortie. C++ fournit des opérations d'insertion prédéfinies pour tous les types de données intégrés, et vous avez déjà vu comment surcharger l'opérateur d'insertion pour vos propres classes.

Dans la leçon sur les flux, vous avez vu que istream et ostream dérivent tous deux d'une classe appelée ios. L'un des rôles de ios (et de ios_base) est de contrôler les options de formatage de la sortie.

Formatage

Il existe deux façons de modifier les options de formatage : les indicateurs (flags) et les manipulateurs. Vous pouvez considérer les indicateurs comme des variables booléennes que l'on peut activer et désactiver. Les manipulateurs sont des objets placés dans un flux qui modifient la manière dont les données sont saisies et affichées.

Pour activer un indicateur, utilisez la fonction setf() avec l'indicateur approprié en paramètre. Par exemple, par défaut, C++ n'affiche pas le signe + devant les nombres positifs. Toutefois, en utilisant l'indicateur std::ios::showpos, nous pouvons modifier ce comportement :

std::cout.setf(std::ios::showpos); // active l'indicateur std::ios::showpos
std::cout << 27 << '\n';

Cela produit le résultat suivant :


+27

Il est possible d'activer plusieurs indicateurs ios en même temps à l'aide de l'opérateur OU bit à bit (|) :

std::cout.setf(std::ios::showpos | std::ios::uppercase); // active les indicateurs std::ios::showpos et std::ios::uppercase
std::cout << 1234567.89f << '\n';

Cela affiche :


+1.23457E+06

Pour désactiver un indicateur, utilisez la fonction unsetf() :

std::cout.setf(std::ios::showpos); // active l'indicateur std::ios::showpos
std::cout << 27 << '\n';
std::cout.unsetf(std::ios::showpos); // désactive l'indicateur std::ios::showpos
std::cout << 28 << '\n';

Cela produit le résultat suivant :


+27
28

Il reste une subtilité à mentionner concernant setf(). De nombreux indicateurs appartiennent à des groupes, appelés groupes de formatage. Un groupe de formatage est un ensemble d'indicateurs qui proposent des options de formatage similaires (parfois mutuellement exclusives). Par exemple, un groupe nommé « basefield » contient les indicateurs « oct », « dec » et « hex », qui contrôlent la base des valeurs entières. Par défaut, l'indicateur « dec » est activé. Par conséquent, si nous écrivons :

std::cout.setf(std::ios::hex); // tente d'activer l'affichage hexadécimal
std::cout << 27 << '\n';

Nous obtenons le résultat suivant :


27

Cela n'a pas fonctionné ! La raison est que setf() ne fait qu'activer des indicateurs : il n'est pas assez intelligent pour désactiver les indicateurs mutuellement exclusifs. Par conséquent, lorsque nous avons activé std::hex, std::ios::dec était toujours actif, et std::ios::dec semble prévaloir. Il existe deux façons de contourner ce problème.

La première consiste à désactiver std::ios::dec pour que seul std::hex soit actif :

std::cout.unsetf(std::ios::dec); // désactive l'affichage décimal
std::cout.setf(std::ios::hex); // active l'affichage hexadécimal
std::cout << 27 << '\n';

Nous obtenons maintenant le résultat attendu :


1b

La seconde façon consiste à utiliser une autre forme de setf() qui prend deux paramètres : le premier est l'indicateur à activer, et le second est le groupe de formatage auquel il appartient. Avec cette forme de setf(), tous les indicateurs du groupe sont désactivés, et seul l'indicateur passé en paramètre est activé. Par exemple :

// Active std::ios::hex comme seul indicateur de std::ios::basefield
std::cout.setf(std::ios::hex, std::ios::basefield);
std::cout << 27 << '\n';

Cela produit également le résultat attendu :


1b

Utiliser setf() et unsetf() reste peu pratique ; C++ propose donc une seconde façon de modifier les options de formatage : les manipulateurs. L'avantage des manipulateurs est qu'ils savent activer et désactiver les indicateurs appropriés. Voici un exemple d'utilisation de quelques manipulateurs pour changer la base :

std::cout << std::hex << 27 << '\n'; // affiche 27 en hexadécimal
std::cout << 28 << '\n'; // on est toujours en hexadécimal
std::cout << std::dec << 29 << '\n'; // retour au décimal

Ce programme produit la sortie suivante :


1b
1c
29

En général, utiliser des manipulateurs est beaucoup plus simple que d'activer et désactiver des indicateurs. De nombreuses options sont disponibles à la fois par indicateurs et par manipulateurs (comme le changement de base) ; cependant, d'autres options ne sont disponibles que par l'un ou l'autre moyen, il est donc important de savoir utiliser les deux.

À ce stade, vous devriez voir le lien entre le formatage par indicateurs et le formatage par manipulateurs. Dans les exemples suivants, nous utiliserons les manipulateurs, sauf lorsqu'ils ne sont pas disponibles.

Précision, notation et point décimal

À l'aide de manipulateurs (ou d'indicateurs), il est possible de modifier la précision et le format d'affichage des nombres à virgule flottante. Plusieurs options de formatage se combinent de manière assez complexe, nous allons donc les examiner de plus près.

std::ios::floatfield (aucun) Utilise fixed pour les nombres avec peu de chiffres, scientific sinon
std::ios::floatfield std::ios::showpoint Affiche toujours un point décimal et des zéros finaux pour les valeurs à virgule flottante

std::showpoint Affiche un point décimal et des zéros finaux pour les valeurs à virgule flottante

std::setprecision(int) Définit la précision des nombres à virgule flottante (défini dans l'en-tête iomanip)
Fonction membre Signification

std::cout << std::setprecision(5) << 123.456 << '\n';

Largeur, caractères de remplissage et justification

En général, lorsque vous affichez des nombres, ceux-ci sont imprimés sans tenir compte de l'espace qui les entoure. Il est cependant possible de justifier à gauche ou à droite l'affichage des nombres. Pour cela, nous devons d'abord définir une largeur de champ, qui correspond au nombre de caractères de sortie occupés par une valeur. Si le nombre affiché est plus court que la largeur de champ, il sera justifié à gauche ou à droite (selon le choix). Si le nombre est plus long que la largeur de champ, il ne sera pas tronqué : il débordera du champ.

Groupe Indicateur Signification
std::ios::adjustfield std::ios::internal Justifie à gauche le signe du nombre, et à droite la valeur
std::ios::adjustfield std::ios::left Justifie à gauche le signe et la valeur
std::ios::adjustfield std::ios::right Justifie à droite le signe et la valeur (par défaut)
Manipulateur Signification
std::internal Justifie à gauche le signe du nombre, et à droite la valeur
std::left Justifie à gauche le signe et la valeur
std::right Justifie à droite le signe et la valeur
std::setfill(char) Définit le paramètre comme caractère de remplissage (défini dans l'en-tête iomanip)
std::setw(int) Définit la largeur de champ pour la saisie et la sortie avec le paramètre (défini dans l'en-tête iomanip)
Fonction membre Signification
std::basic_ostream::fill() Renvoie le caractère de remplissage courant
std::basic_ostream::fill(char) Définit le caractère de remplissage et renvoie l'ancien caractère de remplissage
std::ios_base::width() Renvoie la largeur de champ courante
std::ios_base::width(int) Définit la largeur de champ courante et renvoie l'ancienne largeur de champ

Pour utiliser l'un de ces formateurs, nous devons d'abord définir une largeur de champ. Cela peut se faire avec la fonction membre width(int) ou avec le manipulateur setw(). Notez que la justification à droite est le comportement par défaut.

std::cout << -12345 << '\n'; // affiche la valeur par défaut sans largeur de champ
std::cout << std::setw(10) << -12345 << '\n'; // affiche avec la valeur par défaut et une largeur de champ
std::cout << std::setw(10) << std::left << -12345 << '\n'; // affiche justifié à gauche
std::cout << std::setw(10) << std::right << -12345 << '\n'; // affiche justifié à droite
std::cout << std::setw(10) << std::internal << -12345 << '\n'; // affiche avec justification interne

Cela produit le résultat suivant :


-12345
    -12345
-12345
    -12345
-    12345

Il faut noter que setw() et width() n'affectent que l'instruction de sortie suivante. Ils ne sont pas persistants, contrairement à certains autres indicateurs et manipulateurs.

Définissons maintenant un caractère de remplissage et refaisons le même exemple :

std::cout.fill('*');
std::cout << -12345 << '\n'; // affiche la valeur par défaut sans largeur de champ
std::cout << std::setw(10) << -12345 << '\n'; // affiche avec la valeur par défaut et une largeur de champ
std::cout << std::setw(10) << std::left << -12345 << '\n'; // affiche justifié à gauche
std::cout << std::setw(10) << std::right << -12345 << '\n'; // affiche justifié à droite
std::cout << std::setw(10) << std::internal << -12345 << '\n'; // affiche avec justification interne

Cela produit le résultat suivant :


-12345
****-12345
-12345****
****-12345
-****12345

Notez que tous les espaces vides du champ ont été remplis par le caractère de remplissage.

La classe ostream et la bibliothèque iostream contiennent d'autres fonctions de sortie, indicateurs et manipulateurs qui peuvent être utiles selon vos besoins. Comme pour la classe istream, ces sujets relèvent davantage d'un tutoriel ou d'un ouvrage consacré à la bibliothèque standard.
