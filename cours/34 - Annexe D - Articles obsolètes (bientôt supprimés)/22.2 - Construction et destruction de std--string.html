22.2 — Construction et destruction de std::string

Dans cette leçon, nous allons voir comment construire des objets std::string, ainsi que créer des chaînes à partir de nombres et inversement.

Construction de chaînes

Les classes de chaînes disposent de plusieurs constructeurs permettant de créer des chaînes. Nous les examinons chacun ci-dessous.

Construire des chaînes à partir de nombres

Une lacune notable de la classe std::string est l'impossibilité de créer une chaîne directement à partir d'un nombre. Par exemple :

    std::string sFour{ 4 };

produit l'erreur suivante :


c:vcprojectstest2test2test.cpp(10) : error C2664: 'std::basic_string<_Elem,_Traits,_Ax>::basic_string(std::basic_string<_Elem,_Traits,_Ax>::_Has_debug_it)' : cannot convert parameter 1 from 'int' to 'std::basic_string<_Elem,_Traits,_Ax>::_Has_debug_it'

Vous vous souvenez de ce que j'ai dit sur les messages d'erreur effrayants produits par les classes de chaînes ? L'information pertinente ici est :

cannot convert parameter 1 from 'int' to 'std::basic_string

Autrement dit, le compilateur a tenté de convertir votre int en chaîne, et a échoué.

La façon la plus simple de convertir des nombres en chaînes consiste à faire appel à la classe std::ostringstream. std::ostringstream est déjà prête à accepter des entrées de sources variées, y compris des caractères, des nombres, des chaînes, etc. Elle peut également produire des chaînes (soit via l'opérateur d'extraction >>, soit via la fonction str()). Pour plus d'informations sur std::ostringstream, voir 28.4 -- Classes de flux pour les chaînes.

Voici une solution simple pour créer un std::string à partir de différents types d'entrées :

#include <iostream>
#include <sstream>
#include <string>

template <typename T>
inline std::string ToString(T tX)
{
    std::ostringstream oStream;
    oStream << tX;
    return oStream.str();
}

Voici un exemple de code pour le tester :

int main()
{
    std::string sFour{ ToString(4) };
    std::string sSixPointSeven{ ToString(6.7) };
    std::string sA{ ToString('A') };
    std::cout << sFour << '\n';
    std::cout << sSixPointSeven << '\n';
    std::cout << sA << '\n';
}

Et la sortie :


4
6.7
A

Notez que cette solution omet toute vérification d'erreur. Il est possible que l'insertion de tX dans oStream échoue. Une réponse appropriée serait de lever une exception si la conversion échoue.

Contenu associé

La bibliothèque standard contient également une fonction nommée std::to_string() qui peut être utilisée pour convertir des nombres en std::string. Bien que ce soit une solution plus simple pour les cas de base, la sortie de std::to_string peut différer de celle de std::cout ou de notre fonction ToString() ci-dessus. Certaines de ces différences sont actuellement documentées ici.

Convertir des chaînes en nombres

De manière similaire à la solution précédente :

#include <iostream>
#include <sstream>
#include <string>

template <typename T>
inline bool FromString(const std::string& sString, T& tX)
{
    std::istringstream iStream(sString);
    return !(iStream >> tX).fail(); // extrait la valeur dans tX, renvoie le succès ou non
}

Voici un exemple de code pour le tester :

int main()
{
    double dX;
    if (FromString("3.4", dX))
        std::cout << dX << '\n'; 
    if (FromString("ABC", dX))
        std::cout << dX << '\n'; 
}

Et la sortie :


3.4

Notez que la seconde conversion a échoué et renvoyé false.
