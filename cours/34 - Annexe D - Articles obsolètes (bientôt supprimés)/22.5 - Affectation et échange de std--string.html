22.5 — Affectation et échange de std::string

Affectation de chaînes

La façon la plus simple d'affecter une valeur à une chaîne est d'utiliser la fonction surchargée operator=. Il existe également une fonction membre assign() qui duplique une partie de cette fonctionnalité.
string& string::operator= (const string& str) string& string::assign (const string& str) string& string::operator= (const char str)* string& string::assign (const char str)* string& string::operator= (char c) - Ces fonctions affectent des valeurs de différents types à la chaîne.- Ces fonctions renvoient *this afin de pouvoir être « enchaînées ».- Notez qu'il n'existe pas de fonction assign() prenant un seul char. Exemple de code : ```cpp std::string sString;

// Affectation d'une valeur de type string sString = std::string("One"); std::cout << sString << '\n';

const std::string sTwo("Two"); sString.assign(sTwo); std::cout << sString << '\n';

// Affectation d'une chaîne de style C sString = "Three"; std::cout << sString << '\n';

sString.assign("Four"); std::cout << sString << '\n';

// Affectation d'un char sString = '5'; std::cout << sString << '\n';

// Affectation en chaîne std::string sOther; sString = sOther = "Six"; std::cout << sString << ' ' << sOther << '\n'; Sortie : One Two Three Four 5 Six Six ``` |

La fonction membre assign() existe aussi sous quelques autres formes :

| | | --- | | string& string::assign (const string& str, size_type index, size_type len) - Affecte une sous-chaîne de str, à partir de index, et de longueur len.- Lève une exception out_of_range si l'indice est hors limites.- Renvoie *this afin de pouvoir être « enchaînée ». Exemple de code : ```cpp const std::string sSource("abcdefg"); std::string sDest;

sDest.assign(sSource, 2, 4); // affecte une sous-chaîne de source à partir de l'indice 2, de longueur 4 std::cout << sDest << '\n'; Sortie : cdef ``` |
string& string::assign (const char chars, size_type len)* - Affecte len caractères du tableau de style C chars.- Lève une exception length_error si le résultat dépasse le nombre maximal de caractères.- Renvoie *this afin de pouvoir être « enchaînée ». Exemple de code : ```cpp std::string sDest;

sDest.assign("abcdefg", 4); std::cout << sDest << '\n'; Sortie : abcd ``` Cette fonction est potentiellement dangereuse et son utilisation n'est pas recommandée. |
string& string::assign (size_type len, char c) - Affecte len occurrences du caractère c.- Lève une exception length_error si le résultat dépasse le nombre maximal de caractères.- Renvoie *this afin de pouvoir être « enchaînée ». Exemple de code : ```cpp std::string sDest;

sDest.assign(4, 'g'); std::cout << sDest << '\n'; Sortie : gggg ``` |

Échange de valeurs

Si vous avez deux chaînes et souhaitez échanger leurs valeurs, vous pouvez utiliser deux fonctions nommées swap().

| | | --- | | void string::swap (string& str) void swap (string& str1, string& str2) - Ces deux fonctions échangent la valeur des deux chaînes. La fonction membre échange *this et str, la fonction globale échange str1 et str2.- Ces fonctions sont efficaces et doivent être utilisées à la place d'affectations pour échanger des chaînes. Exemple de code : ```cpp std::string sStr1("red"); std::string sStr2("blue");

std::cout << sStr1 << ' ' << sStr2 << '\n'; swap(sStr1, sStr2); std::cout << sStr1 << ' ' << sStr2 << '\n'; sStr1.swap(sStr2); std::cout << sStr1 << ' ' << sStr2 << '\n'; Sortie : red blue blue red red blue ``` |
