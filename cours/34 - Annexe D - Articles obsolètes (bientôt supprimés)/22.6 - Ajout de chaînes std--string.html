22.6 — Ajout de chaînes std::string

Ajout en fin de chaîne

Ajouter des chaînes à la fin d'une chaîne existante est facile, en utilisant indifféremment operator+=, append() ou push_back().
string& string::operator+= (const string& str) string& string::append (const string& str) - Les deux fonctions ajoutent les caractères de str à la chaîne.- Les deux fonctions renvoient *this afin de pouvoir être « enchaînées ».- Les deux fonctions lèvent une exception length_error si le résultat dépasse le nombre maximal de caractères. Exemple de code : ```cpp std::string sString{"one"};

sString += std::string{" two"};

std::string sThree{" three"}; sString.append(sThree);

std::cout << sString << '\n'; Sortie : one two three ``` |

Il existe aussi une variante de append() qui permet d'ajouter une sous-chaîne :
string& string::append (const string& str, size_type index, size_type num) - Cette fonction ajoute num caractères de str, à partir de la position index, à la chaîne.- Renvoie *this afin de pouvoir être « enchaînée ».- Lève une exception out_of_range si index est hors limites.- Lève une exception length_error si le résultat dépasse le nombre maximal de caractères. Exemple de code : ```cpp std::string sString{"one "};

const std::string sTemp{"twothreefour"}; sString.append(sTemp, 3, 5); // ajoute la sous-chaîne de sTemp commençant à l'indice 3, de longueur 5 std::cout << sString << '\n'; Sortie : one three ``` |

Les opérateurs += et la fonction append() disposent aussi de versions travaillant sur des chaînes de style C :
string& string::operator+= (const char str)* string& string::append (const char str)* - Les deux fonctions ajoutent les caractères de str à la chaîne.- Les deux fonctions renvoient *this afin de pouvoir être « enchaînées ».- Les deux fonctions lèvent une exception length_error si le résultat dépasse le nombre maximal de caractères.- str ne doit pas être NULL. Exemple de code : ```cpp std::string sString{"one"};

sString += " two"; sString.append(" three"); std::cout << sString << '\n'; Sortie : one two three ``` |

Il existe une variante supplémentaire de append() qui travaille sur des chaînes de style C :
string& string::append (const char str, size_type len)* - Ajoute les len premiers caractères de str à la chaîne.- Renvoie *this afin de pouvoir être « enchaînée ».- Lève une exception length_error si le résultat dépasse le nombre maximal de caractères.- Ignore les caractères spéciaux (y compris ”) Exemple de code : ```cpp std::string sString{"one "};

sString.append("threefour", 5); std::cout << sString << '\n'; Sortie : one three ``` Cette fonction est dangereuse et son utilisation n'est pas recommandée. |

Il existe également des fonctions permettant d'ajouter des caractères isolés. Notez que la fonction membre non opérateur qui ajoute un caractère se nomme push_back(), et non append() !
string& string::operator+= (char c) void string::push_back (char c) - Les deux fonctions ajoutent le caractère c à la chaîne.- L'opérateur += renvoie *this afin de pouvoir être « enchaîné ».- Les deux fonctions lèvent une exception length_error si le résultat dépasse le nombre maximal de caractères. Exemple de code : ```cpp std::string sString{"one"};

sString += ' '; sString.push_back('2'); std::cout << sString << '\n'; Sortie : one 2 ``` |

Vous vous demandez peut-être pourquoi cette fonction s'appelle push_back() et non append(). Ce choix suit une convention de nommage utilisée pour les piles, où push_back() est la fonction qui ajoute un seul élément à la fin de la pile. Si l'on considère une chaîne comme une pile de caractères, utiliser push_back() pour ajouter un caractère en fin de chaîne a du sens. Cependant, l'absence de fonction append() pour les caractères me paraît incohérente !

Il existe en fait une fonction append() pour les caractères, qui se présente ainsi :
string& string::append (size_type num, char c) - Ajoute num occurrences du caractère c à la chaîne.- Renvoie *this afin de pouvoir être « enchaînée ».- Lève une exception length_error si le résultat dépasse le nombre maximal de caractères. Exemple de code : ```cpp std::string sString{"aaa"};

sString.append(4, 'b'); std::cout << sString << '\n'; Sortie : aaabbbb ``` |

Il existe une dernière variante de append() qui travaille avec des itérateurs :
string& string::append (InputIterator start, InputIterator end) - Ajoute tous les caractères de l'intervalle [start, end) (en incluant start, mais sans inclure end)- Renvoie *this afin de pouvoir être « enchaînée ».- Lève une exception length_error si le résultat dépasse le nombre maximal de caractères.
