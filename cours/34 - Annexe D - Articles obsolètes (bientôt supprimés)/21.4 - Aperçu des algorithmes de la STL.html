21.4 — Aperçu des algorithmes de la STL

En plus des classes conteneurs et des itérateurs, la STL fournit également un certain nombre d'algorithmes génériques permettant de travailler avec les éléments des classes conteneurs. Ils vous permettent de faire des choses comme rechercher, trier, insérer, réordonner, supprimer et copier des éléments de la classe conteneur.

Notez que les algorithmes sont implémentés sous forme de fonctions qui opèrent à l'aide d'itérateurs. Cela signifie que chaque algorithme n'a besoin d'être implémenté qu'une seule fois, et qu'il fonctionnera généralement automatiquement avec tous les conteneurs fournissant un ensemble d'itérateurs (y compris vos propres classes conteneurs). Bien que cela soit très puissant et permette d'écrire rapidement du code complexe, cela a aussi un revers : certaines combinaisons d'algorithmes et de types de conteneurs peuvent ne pas fonctionner, provoquer des boucles infinies, ou fonctionner mais avec des performances extrêmement médiocres. Utilisez-les donc à vos risques et périls.

La STL fournit un assez grand nombre d'algorithmes ; nous n'en aborderons ici que quelques-uns parmi les plus courants et les plus simples d'utilisation. Les autres (ainsi que tous les détails) seront traités dans un chapitre consacré aux algorithmes de la STL.

Pour utiliser n'importe lequel des algorithmes de la STL, il suffit d'inclure le fichier d'en-tête algorithm.

min_element et max_element

Les algorithmes std::min_element et std::max_element recherchent respectivement l'élément minimal et l'élément maximal d'une classe conteneur. std::iota génère une suite contiguë de valeurs.

#include <algorithm> // std::min_element et std::max_element
#include <iostream>
#include <list>
#include <numeric> // std::iota

int main()
{
    std::list<int> li(6);
    // Remplit li avec des nombres à partir de 0.
    std::iota(li.begin(), li.end(), 0);

    std::cout << *std::min_element(li.begin(), li.end()) << ' '
              << *std::max_element(li.begin(), li.end()) << '\n';

    return 0;
}

Affiche :

0 5

find (et list::insert)

Dans cet exemple, nous utiliserons l'algorithme std::find() pour rechercher une valeur dans la classe list, puis la fonction list::insert() pour ajouter une nouvelle valeur dans la liste à cet endroit.

#include <algorithm>
#include <iostream>
#include <list>
#include <numeric>

int main()
{
    std::list<int> li(6);
    std::iota(li.begin(), li.end(), 0);

    // Recherche la valeur 3 dans la liste
    auto it{ std::find(li.begin(), li.end(), 3) };

    // Insère 8 juste avant 3.
    li.insert(it, 8);

    for (int i : li) // boucle for avec itérateurs
        std::cout << i << ' ';

    std::cout << '\n';

    return 0;
}

Ceci affiche les valeurs


0 1 2 8 3 4 5

Lorsqu'un algorithme de recherche ne trouve pas ce qu'il cherche, il renvoie l'itérateur de fin. Si nous ne savions pas avec certitude que 3 est un élément de li, nous devrions vérifier si std::find l'a trouvé avant d'utiliser l'itérateur renvoyé pour quoi que ce soit d'autre.

if (it == li.end())
{
  std::cout << "3 was not found\n";
}
else
{
  // ...
}

sort et reverse

Dans cet exemple, nous allons trier un vecteur puis l'inverser.

#include <iostream>
#include <vector>
#include <algorithm>

int main()
{
    std::vector<int> vect{ 7, -3, 6, 2, -5, 0, 4 };

    // trie le vecteur
    std::sort(vect.begin(), vect.end());

    for (int i : vect)
    {
        std::cout << i << ' ';
    }

    std::cout << '\n';

    // inverse le vecteur
    std::reverse(vect.begin(), vect.end());

    for (int i : vect)
    {
        std::cout << i << ' ';
    }

    std::cout << '\n';

    return 0;
}

Ce programme produit le résultat suivant :


-5 -3 0 2 4 6 7
7 6 4 2 0 -3 -5

Par ailleurs, nous pourrions passer une fonction de comparaison personnalisée comme troisième argument à std::sort. Plusieurs fonctions de comparaison sont disponibles dans l'en-tête <functional>, que nous pouvons utiliser sans avoir à les écrire nous-mêmes. Nous pouvons passer std::greater à std::sort et supprimer l'appel à std::reverse. Le vecteur sera alors trié du plus grand au plus petit directement.

Notez que std::sort() ne fonctionne pas sur les classes conteneurs de type liste : la classe list fournit sa propre fonction membre sort(), nettement plus efficace que la version générique.

Conclusion
