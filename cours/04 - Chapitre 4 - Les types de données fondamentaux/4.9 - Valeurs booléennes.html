4.9 — Valeurs booléennes

Dans la vie courante, il est fréquent de poser ou de recevoir des questions auxquelles on peut répondre par « oui » ou « non ». « Une pomme est-elle un fruit ? » Oui. « Aimez-vous les asperges ? » Non.

Considérons maintenant une affirmation similaire, à laquelle on peut répondre par « vrai » ou « faux » : « Les pommes sont des fruits ». C'est clairement vrai. Ou bien : « J'aime les asperges ». Absolument faux (beurk !).

Ce genre de phrases, qui n'ont que deux issues possibles, oui/vrai ou non/faux, est si courant que de nombreux langages de programmation proposent un type spécial pour les manipuler. Ce type s'appelle le type booléen (note : « Boolean » s'écrit avec une majuscule en anglais, car il tire son nom de son inventeur, George Boole).

Variables booléennes

Les variables booléennes sont des variables qui ne peuvent prendre que deux valeurs possibles : true (vrai) et false (faux).

Pour déclarer une variable booléenne, on utilise le mot-clé bool.

bool b;

Pour initialiser une variable booléenne avec la valeur true ou false, ou lui affecter une de ces valeurs, on utilise les mots-clés true et false.

bool b1 { true };
bool b2 { false };
b1 = false;
bool b3 {}; // initialisation par défaut à false

De même que l'opérateur moins unaire (-) permet de rendre un entier négatif, l'opérateur NON logique (!) permet de faire basculer une valeur booléenne de true à false, ou de false à true :

bool b1 { !true }; // b1 sera initialisée avec la valeur false
bool b2 { !false }; // b2 sera initialisée avec la valeur true

Les valeurs booléennes ne sont pas réellement stockées dans les variables booléennes sous forme des mots « true » ou « false ». Elles sont en fait stockées sous forme de valeurs entières : true est stocké comme l'entier 1, et false comme l'entier 0. De même, lorsque des valeurs booléennes sont évaluées, elles ne donnent pas réellement « true » ou « false ». Elles s'évaluent en les entiers 0 (faux) ou 1 (vrai). Comme les booléens stockent des valeurs entières, ils sont considérés comme un type entier (type intégral).

Afficher des valeurs booléennes

Lorsque l'on affiche des valeurs booléennes, std::cout affiche 0 pour false et 1 pour true :

#include <iostream>

int main()
{
    std::cout << true << '\n'; // true s'évalue en 1
    std::cout << !true << '\n'; // !true s'évalue en 0

    bool b {false};
    std::cout << b << '\n'; // b vaut false, ce qui s'évalue en 0
    std::cout << !b << '\n'; // !b vaut true, ce qui s'évalue en 1
    return 0;
}

Affiche :


1
0
0
1

Utiliser std::boolalpha pour afficher true ou false

Si vous voulez que std::cout affiche true ou false au lieu de 0 ou 1, vous pouvez envoyer std::boolalpha vers std::cout. Cela n'affiche rien, mais modifie la manière dont std::cout affiche les valeurs bool.

Voici un exemple :

#include <iostream>

int main()
{
    std::cout << true << '\n';
    std::cout << false << '\n';

    std::cout << std::boolalpha; // affiche les booléens sous forme true ou false

    std::cout << true << '\n';
    std::cout << false << '\n';
    return 0;
}

Cela affiche :


1
0
true
false

Vous pouvez utiliser std::noboolalpha pour rétablir le comportement précédent.

Conversion d'un entier en booléen

Lors d'une initialisation uniforme, vous pouvez initialiser une variable à l'aide des littéraux entiers 0 (pour false) et 1 (pour true) (mais vous devriez vraiment utiliser false et true à la place). Les autres littéraux entiers provoquent des erreurs de compilation :

#include <iostream>

int main()
{
    bool bFalse { 0 }; // correct : initialisée à false
    bool bTrue  { 1 }; // correct : initialisée à true
    bool bNo    { 2 }; // erreur : les conversions restrictives sont interdites

    std::cout << bFalse << bTrue << bNo << '\n';

    return 0;
}

En revanche, dans tout contexte où un entier peut être converti en booléen, l'entier 0 est converti en false, et tout autre entier est converti en true :

#include <iostream>

int main()
{
    std::cout << std::boolalpha; // affiche les booléens sous forme true ou false

    bool b1 = 4 ; // l'initialisation par copie permet la conversion implicite de int en bool
    std::cout << b1 << '\n';

    bool b2 = 0 ; // l'initialisation par copie permet la conversion implicite de int en bool
    std::cout << b2 << '\n';

    return 0;
}

Cela affiche :


true
false

Remarque : bool b1 = 4; peut générer un avertissement. Si c'est le cas, vous devrez désactiver le traitement des avertissements comme des erreurs pour compiler l'exemple.

Saisir des valeurs booléennes

La saisie de valeurs booléennes à l'aide de std::cin déroute parfois les programmeurs débutants.

Considérons le programme suivant :

#include <iostream>

int main()
{
    bool b{}; // initialisation par défaut à false
    std::cout << "Enter a boolean value: ";
    std::cin >> b;
    std::cout << "You entered: " << b << '\n';

    return 0;
}


Enter a Boolean value: true
You entered: 0

Comment ça ?

Par défaut, std::cin n'accepte que des saisies numériques pour les variables booléennes : 0 correspond à false et 1 à true. Toute autre valeur numérique sera interprétée comme true et fera passer std::cin en mode d'échec. Toute valeur non numérique sera interprétée comme false et fera également passer std::cin en mode d'échec.

Contenu associé

Nous abordons le mode d'échec (et la manière d'en sortir) dans la leçon 9.5 -- std::cin et gestion des saisies invalides.

Dans ce cas, comme nous avons saisi true, std::cin a échoué silencieusement et a affecté false à b. Par conséquent, lorsque std::cout affiche la valeur de b, il affiche 0.

Pour que std::cin accepte les mots false et true comme saisies, vous devez d'abord envoyer std::boolalpha vers std::cin :

#include <iostream>

int main()
{
    bool b{};
    std::cout << "Enter a boolean value: ";

    // Permet à l'utilisateur de saisir 'true' ou 'false' pour les booléens
    // La casse est significative : True ou TRUE ne fonctionneront pas
    std::cin >> std::boolalpha;
    std::cin >> b;

    // Affichons aussi les valeurs bool sous forme `true` ou `false`
    std::cout << std::boolalpha;
    std::cout << "You entered: " << b << '\n';

    return 0;
}

Toutefois, lorsque std::boolalpha est activé pour la saisie, les valeurs numériques ne sont plus acceptées (elles s'évaluent en false et font passer std::cin en mode d'échec).

Attention

Activer std::boolalpha pour la saisie n'acceptera que false ou true en minuscules. Les variantes avec des majuscules ne seront pas acceptées. 0 et 1 ne seront également plus acceptés.

Notez que nous utilisons std::cin >> std::boolalpha; pour saisir des valeurs booléennes sous forme true ou false, et std::cout << std::boolalpha; pour les afficher sous cette même forme. Ce sont deux réglages indépendants, qui peuvent être activés (avec std::boolalpha) ou désactivés (avec std::noboolalpha) séparément.

Valeurs de retour booléennes

Les valeurs booléennes servent souvent de valeurs de retour aux fonctions qui vérifient si quelque chose est vrai ou non. Ces fonctions commencent généralement par le mot is (par exemple isEqual, « est égal ») ou has (par exemple hasCommonDivisor, « a un diviseur commun »).

Considérons l'exemple suivant, assez proche du précédent :

#include <iostream>

// renvoie true si x et y sont égaux, false sinon
bool isEqual(int x, int y)
{
    return x == y; // operator== renvoie true si x est égal à y, et false sinon
}

int main()
{
    std::cout << "Enter an integer: ";
    int x{};
    std::cin >> x;

    std::cout << "Enter another integer: ";
    int y{};
    std::cin >> y;

    std::cout << std::boolalpha; // affiche les booléens sous forme true ou false

    std::cout << x << " and " << y << " are equal? ";
    std::cout << isEqual(x, y) << '\n'; // renverra true ou false

    return 0;
}

Voici la sortie de deux exécutions de ce programme :


Enter an integer: 5
Enter another integer: 5
5 and 5 are equal? true


Enter an integer: 6
Enter another integer: 4
6 and 4 are equal? false

Comment cela fonctionne-t-il ? Nous lisons d'abord les valeurs entières de x et y. Ensuite, l'expression isEqual(x, y) est évaluée. Dans la première exécution, cela donne un appel de fonction isEqual(5, 5). À l'intérieur de cette fonction, 5 == 5 est évalué, ce qui produit la valeur true. La valeur true est renvoyée à l'appelant pour être affichée par std::cout. Dans la seconde exécution, l'appel isEqual(6, 4) renvoie la valeur false.

Les valeurs booléennes demandent un peu d'habitude, mais une fois que vous les avez bien assimilées, elles sont très rafraîchissantes par leur simplicité ! Les valeurs booléennes occupent aussi une place immense dans le langage : vous finirez par les utiliser plus que tous les autres types fondamentaux réunis !

Nous poursuivrons notre exploration des valeurs booléennes dans la prochaine leçon.
