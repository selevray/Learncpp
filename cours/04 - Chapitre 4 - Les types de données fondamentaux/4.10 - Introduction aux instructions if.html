4.10 — Introduction aux instructions if

Imaginons que vous alliez au marché et que votre colocataire vous dise : « s'ils ont des fraises en promotion, achètes-en ». C'est une instruction conditionnelle : vous n'exécutez une action (« en acheter ») que si la condition (« ils ont des fraises en promotion ») est vraie.

De telles conditions sont courantes en programmation, car elles nous permettent d'introduire des comportements conditionnels dans nos programmes. L'instruction conditionnelle la plus simple en C++ s'appelle une instruction if. Une instruction if permet d'exécuter une (ou plusieurs) lignes de code uniquement si une condition est vraie.

La forme la plus simple d'une instruction if est la suivante :


if (condition) instruction_si_vrai;

Pour une meilleure lisibilité, on l'écrit plus souvent ainsi :


if (condition)
    instruction_si_vrai;

Une condition (aussi appelée expression conditionnelle) est une expression qui s'évalue en une valeur booléenne.

Si la condition d'une instruction if s'évalue à la valeur booléenne true, alors instruction_si_vrai est exécutée. Si la condition s'évalue à la valeur booléenne false, alors instruction_si_vrai est ignorée.

Un exemple de programme utilisant une instruction if

Considérons le programme suivant :

#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    int x {};
    std::cin >> x;

    if (x == 0)
        std::cout << "The value is zero\n";

    return 0;
}

Voici la sortie d'une exécution de ce programme :


Enter an integer: 0
The value is zero

Examinons plus en détail son fonctionnement.

Tout d'abord, l'utilisateur saisit un entier. Ensuite, la condition x == 0 est évaluée. L'opérateur d'égalité (==) permet de tester si deux valeurs sont égales. L'opérateur == renvoie true si les opérandes sont égaux, et false sinon. Comme x vaut 0 et que 0 == 0 est vrai, cette expression s'évalue à true.

La condition ayant été évaluée à true, l'instruction qui la suit s'exécute et affiche The value is zero.

Voici une autre exécution de ce programme :


Enter an integer: 5

Dans ce cas, x == 0 s'évalue à false. L'instruction suivante est ignorée, le programme se termine et rien d'autre n'est affiché.

Attention

Les instructions if n'exécutent conditionnellement qu'une seule instruction. Nous verrons comment exécuter conditionnellement plusieurs instructions dans la leçon 8.2 -- Instructions if et blocs.

If-else

Reprenons l'exemple précédent. Et si nous voulions indiquer à l'utilisateur que le nombre saisi est non nul ?

Nous pourrions écrire quelque chose comme ceci :

#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    int x {};
    std::cin >> x;

    if (x == 0)
        std::cout << "The value is zero\n";
    if (x != 0)
        std::cout << "The value is non-zero\n";

    return 0;
}

Ou bien ceci :

#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    int x {};
    std::cin >> x;

    bool zero { (x == 0) };
    if (zero)
        std::cout << "The value is zero\n";
    if (!zero)
        std::cout << "The value is non-zero\n";

    return 0;
}

Ces deux programmes sont plus complexes que nécessaire. Nous pouvons plutôt utiliser une autre forme de l'instruction if, appelée if-else. Elle s'écrit ainsi :


if (condition)
    instruction_si_vrai;
else
    instruction_si_faux;

Si la condition s'évalue à la valeur booléenne true, instruction_si_vrai s'exécute. Sinon, c'est instruction_si_faux qui s'exécute.

Modifions le programme précédent pour utiliser un if-else.

#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    int x {};
    std::cin >> x;

    if (x == 0)
        std::cout << "The value is zero\n";
    else
        std::cout << "The value is non-zero\n";

    return 0;
}

Ce programme produit désormais la sortie suivante :


Enter an integer: 0
The value is zero


Enter an integer: 5
The value is non-zero

Enchaîner les instructions if

Il arrive que nous voulions vérifier successivement si plusieurs choses sont vraies ou fausses. Pour cela, nous pouvons enchaîner une instruction if (ou if-else) à un if-else précédent, comme ceci :

#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    int x {};
    std::cin >> x;

    if (x > 0)
        std::cout << "The value is positive\n";
    else if (x < 0)
        std::cout << "The value is negative\n";
    else 
        std::cout << "The value is zero\n";

    return 0;
}

L'opérateur inférieur strict (<) permet de tester si une valeur est inférieure à une autre. De même, l'opérateur supérieur strict (>) permet de tester si une valeur est supérieure à une autre. Ces deux opérateurs renvoient des valeurs booléennes.

Voici la sortie de quelques exécutions de ce programme :


Enter an integer: 4
The value is positive


Enter an integer: -3
The value is negative


Enter an integer: 0
The value is zero

Notez que vous pouvez enchaîner autant d'instructions if que vous avez de conditions à évaluer. Nous verrons un exemple où c'est utile dans le quiz.

Valeurs de retour booléennes et instructions if

Dans la leçon précédente (4.9 -- Les valeurs booléennes), nous avons écrit ce programme utilisant une fonction qui renvoie une valeur booléenne :

#include <iostream>

// returns true if x and y are equal, false otherwise
bool isEqual(int x, int y)
{
    return x == y; // operator== returns true if x equals y, and false otherwise
}

int main()
{
    std::cout << "Enter an integer: ";
    int x {};
    std::cin >> x;

    std::cout << "Enter another integer: ";
    int y {};
    std::cin >> y;

    std::cout << std::boolalpha; // print bools as true or false

    std::cout << x << " and " << y << " are equal? ";
    std::cout << isEqual(x, y); // will return true or false

    std::cout << '\n';

    return 0;
}

Améliorons ce programme à l'aide d'une instruction if :

#include <iostream>

// returns true if x and y are equal, false otherwise
bool isEqual(int x, int y)
{
    return x == y; // operator== returns true if x equals y, and false otherwise
}

int main()
{
    std::cout << "Enter an integer: ";
    int x {};
    std::cin >> x;

    std::cout << "Enter another integer: ";
    int y {};
    std::cin >> y;

    if (isEqual(x, y))
        std::cout << x << " and " << y << " are equal\n";
    else
        std::cout << x << " and " << y << " are not equal\n";

    return 0;
}

Deux exécutions de ce programme :


Enter an integer: 5
Enter another integer: 5
5 and 5 are equal


Enter an integer: 6
Enter another integer: 4
6 and 4 are not equal

Dans ce cas, notre expression conditionnelle est simplement un appel à la fonction isEqual, qui renvoie une valeur booléenne.

Conditions non booléennes

Dans tous les exemples précédents, nos conditions étaient soit des valeurs booléennes (true ou false), soit des variables booléennes, soit des fonctions renvoyant une valeur booléenne. Que se passe-t-il si votre condition est une expression qui ne s'évalue pas en une valeur booléenne ?

Dans ce cas, le résultat de l'expression conditionnelle est converti en valeur booléenne : les valeurs non nulles sont converties en true, et la valeur zéro est convertie en false.

Ainsi, si nous écrivons ceci :

#include <iostream>

int main()
{
    int x { 4 };
    if (x) // nonsensical, but for the sake of example...
        std::cout << "hi\n";
    else
        std::cout << "bye\n";

    return 0;
}

Ce programme affichera hi, car x vaut 4, une valeur non nulle qui est convertie en true, ce qui provoque l'exécution de l'instruction qui suit la condition.

Point clé

if (x) signifie « si x est non nul/non vide ».

Instructions if et retours anticipés

Une instruction return qui n'est pas la dernière instruction d'une fonction est appelée un retour anticipé (early return). Une telle instruction provoque le retour de la fonction vers l'appelant dès son exécution, avant que la fonction ne retourne normalement à l'appelant (d'où le terme « anticipé »).

Un retour anticipé inconditionnel n'est pas utile :

void print()
{
    std::cout << "A" << '\n';

    return; // the function will always return to the caller here

    std::cout << "B" << '\n'; // this will never be printed
}

Comme std::cout << "B" << '\n'; ne sera jamais exécutée, autant la supprimer : notre instruction return n'est alors plus anticipée.

En revanche, combinés à des instructions if, les retours anticipés permettent de conditionner la valeur de retour de notre fonction.

#include <iostream>

// returns the absolute value of x
int abs(int x) 
{
    if (x < 0)
        return -x; // early return (only when x < 0)

    return x;
}

int main()
{
    std::cout << abs(4) << '\n'; // prints 4
    std::cout << abs(-3) << '\n'; // prints 3

    return 0;
}

Lorsque abs(4) est appelée, x vaut 4. if (x < 0) est faux, donc le retour anticipé n'est pas exécuté. La fonction renvoie x (valeur 4) à l'appelant à la fin de la fonction.

Lorsque abs(-3) est appelée, x vaut -3. if (x < 0) est vrai, donc le retour anticipé est exécuté. La fonction renvoie -x (valeur 3) à l'appelant à ce moment-là.

Historiquement, les retours anticipés étaient mal vus. Cependant, en programmation moderne, ils sont plus largement acceptés, en particulier lorsqu'ils permettent de simplifier une fonction ou d'interrompre une fonction tôt à cause d'une condition d'erreur.

Question n° 1

Qu'est-ce qu'un retour anticipé, et quel est son comportement ?

Solution

Un retour anticipé est une instruction return qui intervient avant la dernière ligne d'une fonction. Elle provoque le retour immédiat de la fonction vers l'appelant.

Question n° 2

Un nombre premier est un entier supérieur à 1 qui n'est divisible exactement que par 1 et par lui-même. Écrivez un programme qui demande à l'utilisateur de saisir un chiffre de 0 à 9 (inclus). Si l'utilisateur saisit un chiffre de cet intervalle qui est premier (2, 3, 5 ou 7), affichez « The digit is prime ». Sinon, affichez « The digit is not prime ».

Indice

Indice : utilisez une chaîne d'instructions if-else pour comparer le nombre saisi par l'utilisateur aux nombres premiers, afin de voir s'il y a correspondance.

Solution 
#include <iostream>

bool isPrime(int x)
{
    if (x == 2) // if user entered 2, the digit is prime
        return true;
    else if (x == 3) // if user entered 3, the digit is prime
        return true;
    else if (x == 5) // if user entered 5, the digit is prime
        return true;
    else if (x == 7) // if user entered 7, the digit is prime
        return true;

    return false; // if the user did not enter 2, 3, 5, 7, the digit must not be prime
}

int main()
{
    std::cout << "Enter a number 0 through 9: ";
    int x {};
    std::cin >> x;

    if ( isPrime(x) )
        std::cout << "The digit is prime\n";
    else
        std::cout << "The digit is not prime\n";

    return 0;
}

Pour les lecteurs avancés

Si la fonction isPrime() ci-dessus vous paraît un peu verbeuse et répétitive, c'est effectivement le cas. Nous pouvons écrire isPrime() de façon plus compacte et plus efficace en utilisant des notions que nous présenterons dans de futures leçons.

En utilisant l'opérateur OU logique (||) (6.8 -- Les opérateurs logiques) :

bool isPrime(int x)
{
    return x == 2 || x == 3 || x == 5 || x == 7; // if user entered 2 or 3 or 5 or 7 the digit is prime
}

En utilisant une instruction switch (8.5 -- Bases de l'instruction switch) :

bool isPrime(int x)
{
    switch (x)
    {
        case 2: // if the user entered 2
        case 3: // or if the user entered 3
        case 5: // or if the user entered 5
        case 7: // or if the user entered 7
            return true; // then the digit is prime
    }

    return false; // otherwise the digit must not be prime
}

Question n° 3

Comment réduire la longueur du code suivant (sans modifier la mise en forme) ?

#include <iostream>

bool isAllowedToTakeFunRide()
{
  std::cout << "How tall are you? (cm)\n";

  double height{};
  std::cin >> height;

  if (height >= 140.0)
    return true;
  else
    return false;
}

int main()
{
  if (isAllowedToTakeFunRide())
    std::cout << "Have fun!\n";
  else
    std::cout << "Sorry, you're too short.\n";

  return 0;
}
Solution

Nous n'avons pas besoin de l'instruction if dans isAllowedToTakeFunRide(). L'expression height >= 140.0 s'évalue en un bool, qui peut être renvoyé directement.

bool isAllowedToTakeFunRide()
{
  std::cout << "How tall are you? (cm)\n";

  double height{};
  std::cin >> height;

  return height >= 140.0;
}

Vous n'avez jamais besoin d'une instruction if de la forme :

if (condition)
  return true;
else
  return false;

Elle peut être remplacée par l'instruction unique return condition.
