19.2 — Allocation dynamique de tableaux

En plus de l'allocation dynamique de valeurs isolées, nous pouvons aussi allouer dynamiquement des tableaux de variables. Contrairement à un tableau de taille fixe, dont la taille doit être connue à la compilation, l'allocation dynamique d'un tableau permet de choisir sa longueur à l'exécution (ce qui signifie que la longueur n'a pas besoin d'être une expression constante, constexpr).

Note de l'auteur

Dans ces leçons, nous allons allouer dynamiquement des tableaux de style C, qui sont le type de tableau alloué dynamiquement le plus courant.

Bien qu'il soit possible d'allouer dynamiquement un std::array, il est généralement préférable d'utiliser dans ce cas un std::vector non alloué dynamiquement.

Pour allouer un tableau dynamiquement, on utilise la forme tableau de new et delete (souvent appelée new[] et delete[]) :

#include <cstddef>
#include <iostream>

int main()
{
    std::cout << "Enter a positive integer: ";
    std::size_t length{};
    std::cin >> length;

    int* array{ new int[length]{} }; // utilisation de new pour tableau. Notez que length n'a pas besoin d'être constant !

    std::cout << "I just allocated an array of integers of length " << length << '\n';

    array[0] = 5; // affecte la valeur 5 à l'élément 0

    delete[] array; // utilisation de delete pour tableau afin de libérer le tableau

    // il n'est pas nécessaire d'affecter nullptr/0 à array ici, car il sort de portée immédiatement après

    return 0;
}

Comme nous allouons un tableau, C++ sait qu'il doit utiliser la version tableau de new et non la version pour valeur isolée. En pratique, l'opérateur new[] est appelé, même si les crochets ne sont pas placés à côté du mot-clé new.

La longueur d'un tableau alloué dynamiquement est de type std::size_t. Si vous utilisez un int qui n'est pas constexpr, vous devrez effectuer un static_cast vers std::size_t, car cette conversion est considérée comme un rétrécissement (narrowing conversion) et votre compilateur émettra sinon un avertissement.

Notez que cette mémoire est allouée dans une zone différente de celle utilisée pour les tableaux de taille fixe, la taille du tableau peut donc être très grande. Vous pouvez exécuter le programme ci-dessus et allouer un tableau de longueur 1 000 000 (voire 100 000 000) sans problème. Essayez ! C'est pour cette raison que les programmes qui ont besoin de beaucoup de mémoire en C++ l'allouent généralement dynamiquement.

Libération dynamique des tableaux

Lorsqu'on libère un tableau alloué dynamiquement, on doit utiliser la version tableau de delete, c'est-à-dire delete[].

Cela indique au processeur qu'il doit nettoyer plusieurs variables au lieu d'une seule. L'une des erreurs les plus courantes chez les programmeurs débutants en allocation dynamique de mémoire consiste à utiliser delete au lieu de delete[] pour libérer un tableau alloué dynamiquement. Utiliser la version pour valeur isolée de delete sur un tableau entraîne un comportement indéfini, pouvant provoquer une corruption de données, des fuites de mémoire, des plantages ou d'autres problèmes.

Une question souvent posée à propos de delete[] est : « Comment delete[] sait-il quelle quantité de mémoire libérer ? » La réponse est que new[] garde en mémoire la quantité de mémoire allouée pour une variable, afin que delete[] puisse libérer la quantité exacte. Malheureusement, cette taille ou longueur n'est pas accessible au programmeur.

Les tableaux dynamiques sont presque identiques aux tableaux de taille fixe

Dans la leçon 17.8 -- Décroissance des tableaux de style C, vous avez appris qu'un tableau de taille fixe contient l'adresse mémoire de son premier élément. Vous avez aussi appris qu'un tableau de taille fixe peut se dégrader (decay) en un pointeur pointant sur le premier élément du tableau. Sous cette forme dégradée, la longueur du tableau de taille fixe n'est plus disponible (et donc sizeof() ne peut plus donner sa taille), mais, à part cela, il y a peu de différences.

Un tableau dynamique commence sa vie comme un pointeur pointant sur le premier élément du tableau. Il possède donc les mêmes limitations : il ne connaît ni sa longueur ni sa taille. Un tableau dynamique fonctionne exactement comme un tableau de taille fixe dégradé, à la différence près que le programmeur est responsable de sa libération via le mot-clé delete[].

Initialisation des tableaux alloués dynamiquement

Si vous souhaitez initialiser à 0 un tableau alloué dynamiquement, la syntaxe est très simple :

int* array{ new int[length]{} };

Avant C++11, il n'existait pas de moyen simple d'initialiser un tableau dynamique avec une valeur non nulle (les listes d'initialisation ne fonctionnaient que pour les tableaux de taille fixe). Il fallait donc parcourir le tableau et affecter explicitement la valeur de chaque élément.

int* array = new int[5];
array[0] = 9;
array[1] = 7;
array[2] = 5;
array[3] = 3;
array[4] = 1;

Super pénible !

Cependant, à partir de C++11, il est désormais possible d'initialiser des tableaux dynamiques à l'aide de listes d'initialisation !

int fixedArray[5] = { 9, 7, 5, 3, 1 }; // initialisation d'un tableau de taille fixe avant C++11
int* array{ new int[5]{ 9, 7, 5, 3, 1 } }; // initialisation d'un tableau dynamique depuis C++11
// Pour éviter de répéter le type, on peut utiliser auto. C'est souvent fait pour les types aux noms longs.
auto* array{ new int[5]{ 9, 7, 5, 3, 1 } };

Notez que cette syntaxe ne comporte pas d'opérateur = entre la longueur du tableau et la liste d'initialisation.

Pour assurer la cohérence, les tableaux de taille fixe peuvent aussi être initialisés avec l'initialisation uniforme :

int fixedArray[]{ 9, 7, 5, 3, 1 }; // initialisation d'un tableau de taille fixe en C++11
char fixedArray[]{ "Hello, world!" }; // initialisation d'un tableau de taille fixe en C++11

Indiquer explicitement la taille du tableau est facultatif.

Redimensionnement des tableaux

L'allocation dynamique d'un tableau permet de fixer sa longueur au moment de l'allocation. Cependant, C++ ne fournit pas de moyen intégré pour redimensionner un tableau déjà alloué. Il est possible de contourner cette limitation en allouant dynamiquement un nouveau tableau, en y copiant les éléments, puis en libérant l'ancien tableau. Cette méthode est cependant source d'erreurs, en particulier lorsque le type des éléments est une classe (les classes obéissent à des règles spéciales pour leur création).

Par conséquent, nous vous recommandons d'éviter de le faire vous-même. Utilisez plutôt std::vector.

Quiz

Question n° 1

Écrivez un programme qui :

  • demande à l'utilisateur combien de noms il souhaite saisir ;
  • alloue dynamiquement un tableau de std::string ;
  • demande à l'utilisateur de saisir chaque nom ;
  • appelle std::sort pour trier les noms (voir 18.1 -- Tri d'un tableau par sélection et 17.9 -- Arithmétique des pointeurs et indexation) ;
  • affiche la liste triée des noms.

std::string prend en charge la comparaison de chaînes à l'aide des opérateurs de comparaison < et >. Vous n'avez pas besoin d'implémenter vous-même la comparaison de chaînes.

Votre sortie doit ressembler à ceci :


How many names would you like to enter? 5
Enter name #1: Jason
Enter name #2: Mark
Enter name #3: Alex
Enter name #4: Chris
Enter name #5: John

Here is your sorted list:
Name #1: Alex
Name #2: Chris
Name #3: Jason
Name #4: John
Name #5: Mark

Rappel

Vous pouvez utiliser std::getline() pour lire des noms contenant des espaces (voir la leçon 5.7 -- Introduction à std::string).

Rappel

Pour utiliser std::sort() avec un pointeur vers un tableau, calculez manuellement le début et la fin :

std::sort(array, array + arrayLength);
Solution 
#include <algorithm> // std::sort
#include <cstddef>
#include <iostream>
#include <string>

std::size_t getNameCount()
{
    std::cout << "How many names would you like to enter? ";
    std::size_t length{};
    std::cin >> length;

    return length;
}

// Demande à l'utilisateur de saisir tous les noms
void getNames(std::string* names, std::size_t length)
{
    for (std::size_t i{ 0 }; i < length; ++i)
    {
        std::cout << "Enter name #" << i + 1 << ": ";
        std::getline(std::cin >> std::ws, names[i]);
    }
}

// Affiche les noms triés
void printNames(std::string* names, std::size_t length)
{
    std::cout << "\nHere is your sorted list:\n";

    for (std::size_t i{ 0 }; i < length; ++i)
        std::cout << "Name #" << i + 1 << ": " << names[i] << '\n';
}

int main()
{
    std::size_t length{ getNameCount() };

    // Alloue un tableau pour contenir les noms
    auto* names{ new std::string[length]{} };

    getNames(names, length);

    // Trie le tableau
    std::sort(names, names + length);

    printNames(names, length);

    // ne pas oublier d'utiliser delete pour tableau
    delete[] names;
    // il n'est pas nécessaire d'affecter nullptr/0 à names ici, car il sort de portée
    // immédiatement après

    return 0;
}
