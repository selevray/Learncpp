19.4 — Pointeurs vers des pointeurs et tableaux multidimensionnels dynamiques

Cette leçon est facultative, destinée aux lecteurs avancés qui souhaitent en apprendre davantage sur C++. Aucune leçon future ne s'appuie sur celle-ci.

Un pointeur vers un pointeur (pointer to a pointer) est exactement ce que son nom laisse penser : un pointeur qui contient l'adresse d'un autre pointeur.

Pointeurs vers des pointeurs

Un pointeur ordinaire vers un int se déclare avec un seul astérisque :

int* ptr; // pointeur vers un int, un astérisque

Un pointeur vers un pointeur vers un int se déclare avec deux astérisques :

int** ptrptr; // pointeur vers un pointeur vers un int, deux astérisques

Un pointeur vers un pointeur fonctionne comme un pointeur normal : vous pouvez le déréférencer pour obtenir la valeur pointée. Comme cette valeur est elle-même un pointeur, vous pouvez la déréférencer à nouveau pour atteindre la valeur sous-jacente. Ces déréférencements peuvent être enchaînés :

int value { 5 };

int* ptr { &value };
std::cout << *ptr << '\n'; // Déréférence le pointeur vers int pour obtenir la valeur int

int** ptrptr { &ptr };
std::cout << **ptrptr << '\n'; // déréférence pour obtenir le pointeur vers int, déréférence à nouveau pour obtenir la valeur int

Le programme ci-dessus affiche :


5
5

Notez qu'il n'est pas possible d'initialiser directement un pointeur vers un pointeur avec une valeur :

int value { 5 };
int** ptrptr { &&value }; // non valide

En effet, l'opérateur d'adresse (operator&) requiert une lvalue, alors que &value est une rvalue.

En revanche, un pointeur vers un pointeur peut être initialisé à null :

int** ptrptr { nullptr };

Tableaux de pointeurs

Les pointeurs vers des pointeurs ont quelques utilisations. La plus courante consiste à allouer dynamiquement un tableau de pointeurs :

int** array { new int*[10] }; // alloue un tableau de 10 pointeurs vers int

Cela fonctionne exactement comme un tableau alloué dynamiquement classique, à ceci près que les éléments du tableau sont de type « pointeur vers entier » au lieu d'entier.

Tableaux dynamiques à deux dimensions

Une autre utilisation courante des pointeurs vers des pointeurs consiste à faciliter la création de tableaux multidimensionnels alloués dynamiquement (voir 17.12 -- Tableaux multidimensionnels de style C pour un rappel sur les tableaux multidimensionnels).

Contrairement à un tableau fixe à deux dimensions, qui peut facilement se déclarer ainsi :

int array[10][5];

l'allocation dynamique d'un tableau à deux dimensions est un peu plus délicate. Vous pourriez être tenté d'essayer quelque chose comme ceci :

int** array { new int[10][5] }; // ne fonctionnera pas !

Mais cela ne fonctionnera pas.

Il existe deux solutions possibles. Si la dimension la plus à droite du tableau est constexpr, vous pouvez écrire :

int x { 7 }; // non constant
int (*array)[5] { new int[x][5] }; // la dimension la plus à droite doit être constexpr

Les parenthèses sont nécessaires pour que le compilateur comprenne que array est un pointeur vers un tableau de 5 int (qui correspond, dans ce cas, à la première ligne d'un tableau multidimensionnel de 7 lignes). Sans les parenthèses, le compilateur interpréterait cela comme int* array[5], c'est-à-dire un tableau de 5 int*.

C'est un bon endroit pour utiliser la déduction automatique de type :

int x { 7 }; // non constant
auto array { new int[x][5] }; // tellement plus simple !

Malheureusement, cette solution relativement simple ne fonctionne pas si la dimension la plus à droite n'est pas une constante connue à la compilation. Dans ce cas, il faut se compliquer un peu. D'abord, on alloue un tableau de pointeurs (comme expliqué ci-dessus). Ensuite, on parcourt ce tableau de pointeurs et on alloue un tableau dynamique pour chacun de ses éléments. Notre tableau dynamique à deux dimensions est donc un tableau dynamique unidimensionnel de tableaux dynamiques unidimensionnels !

int** array { new int*[10] }; // alloue un tableau de 10 pointeurs vers int : ce sont nos lignes
for (int count { 0 }; count < 10; ++count)
    array[count] = new int[5]; // ce sont nos colonnes

On peut ensuite accéder à notre tableau comme d'habitude :

array[9][4] = 3; // Équivalent à (array[9])[4] = 3;

Avec cette méthode, comme chaque colonne du tableau est allouée dynamiquement de façon indépendante, il est possible de créer des tableaux dynamiques à deux dimensions qui ne sont pas rectangulaires. Par exemple, on peut créer un tableau en forme de triangle :

int** array { new int*[10] }; // alloue un tableau de 10 pointeurs vers int : ce sont nos lignes
for (int count { 0 }; count < 10; ++count)
    array[count] = new int[count+1]; // ce sont nos colonnes

Dans l'exemple ci-dessus, notez que array[0] est un tableau de longueur 1, array[1] un tableau de longueur 2, etc.

La désallocation d'un tableau dynamique à deux dimensions avec cette méthode nécessite également une boucle :

for (int count { 0 }; count < 10; ++count)
    delete[] array[count];
delete[] array; // ceci doit être fait en dernier

Notez que l'on libère le tableau dans l'ordre inverse de sa création (d'abord les éléments, puis le tableau lui-même). Si l'on libérait array avant les colonnes, il faudrait accéder à de la mémoire déjà libérée pour supprimer les colonnes, ce qui entraînerait un comportement indéfini.

Comme l'allocation et la désallocation de tableaux à deux dimensions sont complexes et faciles à mal faire, il est souvent plus simple de « aplatir » un tableau à deux dimensions (de taille x par y) en un tableau unidimensionnel de taille x * y :

// Au lieu de ceci :
int** array { new int*[10] }; // alloue un tableau de 10 pointeurs vers int : ce sont nos lignes
for (int count { 0 }; count < 10; ++count)
    array[count] = new int[5]; // ce sont nos colonnes

// Faites plutôt ceci
int *array { new int[50] }; // un tableau 10x5 aplati en un seul tableau

Une simple formule permet ensuite de convertir un indice de ligne et de colonne d'un tableau à deux dimensions rectangulaire en un indice unique pour le tableau unidimensionnel :

int getSingleIndex(int row, int col, int numberOfColumnsInArray)
{
     return (row * numberOfColumnsInArray) + col;
}

// affecte 3 à array[9,4] en utilisant notre tableau aplati
array[getSingleIndex(9, 4, 5)] = 3;

Passer un pointeur par adresse

De même que l'on peut utiliser un paramètre pointeur pour modifier la valeur réelle de l'argument passé, on peut passer à une fonction un pointeur vers un pointeur et utiliser ce pointeur pour modifier la valeur du pointeur qu'il désigne (encore un peu confus ?).

Toutefois, si l'on veut qu'une fonction puisse modifier ce que pointe un argument pointeur, il est en général préférable d'utiliser à la place une référence vers un pointeur. Ceci est traité dans la leçon 12.11 -- Passage par adresse (partie 2).

Pointeur vers un pointeur vers un pointeur vers…

Il est également possible de déclarer un pointeur vers un pointeur vers un pointeur :

int*** ptrx3;

Cela peut servir à allouer dynamiquement un tableau tridimensionnel. Toutefois, cela nécessiterait une boucle dans une boucle, et il est extrêmement compliqué d'obtenir un résultat correct.

On peut même déclarer un pointeur vers un pointeur vers un pointeur vers un pointeur :

int**** ptrx4;

Ou davantage, si vous le souhaitez.

En pratique, ces constructions sont peu utilisées, car il est rare de nécessiter autant de niveaux d'indirection.

Conclusion

Nous recommandons d'éviter les pointeurs vers des pointeurs, sauf si aucune autre option n'est disponible, car ils sont complexes à utiliser et potentiellement dangereux. Il est déjà assez facile de déréférencer un pointeur nul ou pendant avec des pointeurs ordinaires : c'est doublement facile avec un pointeur vers un pointeur, puisqu'il faut un double déréférencement pour atteindre la valeur sous-jacente !
