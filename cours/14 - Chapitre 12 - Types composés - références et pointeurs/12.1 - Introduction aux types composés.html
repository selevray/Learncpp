12.1 — Introduction aux types composés

Dans la leçon 4.1 -- Introduction aux types de données fondamentaux, nous avons présenté les types de données fondamentaux, c'est-à-dire les types de base que C++ fournit dans le cœur du langage.

Nous avons beaucoup utilisé ces types fondamentaux dans nos programmes jusqu'ici, en particulier le type int. Et bien que ces types fondamentaux soient extrêmement utiles pour des usages simples, ils ne couvrent pas tous nos besoins dès que nous commençons à faire des choses plus complexes.

Par exemple, imaginez que vous écriviez un programme de calcul qui multiplie deux fractions. Comment représenteriez-vous une fraction dans votre programme ? Vous pourriez utiliser une paire d'entiers (un pour le numérateur, un pour le dénominateur), comme ceci :

#include <iostream>

int main()
{
    // Notre première fraction
    int num1 {};
    int den1 {};

    // Notre seconde fraction
    int num2 {};
    int den2 {};

    // Sert à consommer (retirer) la barre oblique entre le numérateur et le dénominateur
    char ignore {};

    std::cout << "Enter a fraction: ";
    std::cin >> num1 >> ignore >> den1;

    std::cout << "Enter a fraction: ";
    std::cin >> num2 >> ignore >> den2;

    std::cout << "The two fractions multiplied: "
        << num1 * num2 << '/' << den1 * den2 << '\n';

    return 0;
}

Et une exécution de ce programme :


Enter a fraction: 1/2
Enter a fraction: 3/4
The two fractions multiplied: 3/8

Bien que ce programme fonctionne, il pose plusieurs problèmes que nous pouvons améliorer. D'abord, chaque paire d'entiers n'est que faiblement liée : en dehors des commentaires et du contexte d'utilisation dans le code, rien n'indique que le numérateur et le dénominateur forment une paire. Ensuite, en suivant le principe DRY (don't repeat yourself, « ne vous répétez pas »), nous devrions créer une fonction qui gère la saisie d'une fraction par l'utilisateur (avec une gestion des erreurs). Or, une fonction ne peut renvoyer qu'une seule valeur : comment renverrions-nous alors le numérateur et le dénominateur à l'appelant ?

Imaginez maintenant un autre cas : vous écrivez un programme qui doit conserver une liste d'identifiants d'employés. Comment pourriez-vous procéder ? Vous pourriez essayer quelque chose comme ceci :

int main()
{
    int id1 { 42 };
    int id2 { 57 };
    int id3 { 162 };
    // et ainsi de suite
}

Mais que faire si vous aviez 100 employés ? Il faudrait d'abord taper 100 noms de variables. Et si vous deviez tous les afficher ? Ou les passer à une fonction ? Vous auriez beaucoup de saisie à faire. Cette approche ne passe tout simplement pas à l'échelle.

Il est clair que les types fondamentaux ne nous mèneront pas très loin.

Types composés

Heureusement, C++ prend en charge un second ensemble de types de données : les types composés (parfois appelés aussi types composites). Ce sont des types définis à partir d'autres types de données existants. Les types composés possèdent des propriétés et des comportements supplémentaires qui les rendent utiles pour résoudre certains types de problèmes.

Point clé

Tout type de données est soit un type fondamental, soit un type composé. La norme du langage C++ définit explicitement la catégorie à laquelle appartient chaque type.

Comme nous le montrerons dans ce chapitre et dans les suivants, nous pouvons utiliser les types composés pour résoudre élégamment tous les problèmes que nous venons de présenter.

C++ prend en charge les types composés suivants :

  • Fonctions
  • Tableaux de style C

  • Types pointeurs :

  • Pointeur vers un objet

  • Pointeur vers une fonction

  • Types pointeurs vers membre :

  • Pointeur vers un membre de donnée

  • Pointeur vers une fonction membre

  • Types référence :

  • Références lvalue

  • Références rvalue

  • Types énumérés :

  • Énumérations non délimitées (unscoped)

  • Énumérations délimitées (scoped)

  • Types classe :

  • Structs

  • Classes
  • Unions

Vous utilisez déjà régulièrement un type composé : les fonctions. Par exemple, considérez cette fonction :

void doSomething(int x, double y)
{
}

Le type de cette fonction est void(int, double). Notez que ce type est composé de types fondamentaux, ce qui en fait un type composé. Bien sûr, les fonctions possèdent aussi leurs propres comportements particuliers, par exemple celui d'être appelables.

Comme il y a beaucoup de matière à couvrir, nous le ferons sur plusieurs chapitres. Dans ce chapitre, nous présenterons les types composés les plus directs, notamment les références lvalue et les pointeurs. Dans le prochain chapitre, nous aborderons les énumérations non délimitées, les énumérations délimitées et notre premier type classe : les structs. Puis, dans les chapitres suivants, nous introduirons les classes et étudierons certains des types de tableaux les plus utiles. Cela inclut std::string (présenté dans la leçon 5.7 -- Introduction à std::string), qui est en fait un type classe !

Terminologie

Un type classe est un type qui est une struct, une classe ou une union. Nous utiliserons souvent ce terme dans les leçons à venir.
