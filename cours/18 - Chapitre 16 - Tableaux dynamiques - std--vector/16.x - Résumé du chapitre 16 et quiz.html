16.x — Résumé du chapitre 16 et quiz

Encouragements

Ce chapitre n'est pas facile. Nous y avons vu beaucoup de matière et mis au jour quelques-uns des défauts du C++. Bravo d'être arrivé jusqu'au bout !

Les tableaux sont l'une des clés qui vous donnent accès à une grande partie de la puissance de vos programmes C++.

Revue du chapitre

Un conteneur (container) est un type de données qui fournit un espace de stockage pour une collection d'objets anonymes (appelés éléments). On utilise généralement des conteneurs lorsque l'on doit manipuler un ensemble de valeurs liées entre elles.

Le nombre d'éléments d'un conteneur est souvent appelé sa longueur (length) ou parfois son nombre (count). En C++, le terme taille (size) est également couramment utilisé pour désigner le nombre d'éléments d'un conteneur. Dans la plupart des langages de programmation (C++ compris), les conteneurs sont homogènes, c'est-à-dire que tous leurs éléments doivent être du même type.

La bibliothèque des conteneurs (Containers library) fait partie de la bibliothèque standard du C++ et contient plusieurs types de classes qui implémentent des conteneurs courants. Une classe qui implémente un conteneur est parfois appelée classe conteneur (container class).

Un tableau (array) est un type de conteneur qui stocke une suite de valeurs de manière contiguë (chaque élément est placé à un emplacement mémoire adjacent, sans trou). Les tableaux permettent un accès rapide et direct à n'importe quel élément.

Le C++ propose trois types de tableaux principaux : les tableaux de style C, la classe conteneur std::vector et la classe conteneur std::array.

std::vector est l'une des classes conteneurs de la bibliothèque standard qui implémente un tableau. std::vector est défini dans l'en-tête <vector> sous la forme d'un modèle de classe (class template), dont le paramètre de type précise le type des éléments. Ainsi, std::vector<int> déclare un std::vector dont les éléments sont de type int.

Les conteneurs disposent généralement d'un constructeur spécial appelé constructeur de liste (list constructor), qui permet de construire une instance du conteneur à partir d'une liste d'initialisation (initializer list). Utilisez l'initialisation par liste avec une liste de valeurs pour construire un conteneur contenant ces valeurs.

En C++, la façon la plus courante d'accéder aux éléments d'un tableau consiste à utiliser le nom du tableau avec l'opérateur d'indexation (operator[]). Pour sélectionner un élément précis, on fournit entre les crochets de cet opérateur une valeur entière qui identifie l'élément voulu. Cette valeur entière est appelée indice (subscript), ou plus informellement index. Le premier élément est accédé avec l'index 0, le deuxième avec l'index 1, etc. Comme l'indexation commence à 0 et non à 1, on dit que les tableaux en C++ sont indexés à partir de zéro (zero-based).

operator[] ne effectue aucune vérification des bornes (bounds checking) : il ne vérifie pas si l'index se situe entre 0 et N-1 (inclus). Passer un index invalide à operator[] entraîne un comportement indéfini (undefined behavior).

Les tableaux font partie des rares conteneurs qui autorisent l'accès aléatoire (random access) : chaque élément peut être atteint directement et à la même vitesse, quel que soit le nombre d'éléments du conteneur.

Lors de la construction d'un objet de type classe, un constructeur de liste correspondant est privilégié par rapport aux autres constructeurs compatibles. Lorsque vous construisez un conteneur (ou tout type ayant un constructeur de liste) avec des initialisateurs qui ne sont pas des valeurs d'éléments, utilisez l'initialisation directe.

std::vector v1 { 5 }; // définit un vector de 1 élément contenant la valeur `5`.
std::vector v2 ( 5 ); // définit un vector de 5 éléments initialisés par valeur.

std::vector peut être déclaré const, mais pas constexpr.

Chacune des classes conteneurs de la bibliothèque standard définit un typedef membre imbriqué nommé size_type (parfois noté T::size_type), qui est un alias du type utilisé pour la longueur (et pour les indices, s'ils sont supportés) du conteneur. size_type est presque toujours un alias de std::size_t, mais il peut être modifié (dans de rares cas) pour utiliser un autre type. On peut raisonnablement supposer que size_type est un alias de std::size_t.

Lorsque l'on accède au membre size_type d'une classe conteneur, il faut le qualifier par le nom complet et templatisé de cette classe. Par exemple, std::vector<int>::size_type.

On peut demander la longueur d'un objet conteneur à l'aide de la fonction membre size(), qui renvoie la longueur sous la forme d'un size_type non signé. En C++17, on peut aussi utiliser la fonction non membre std::size().

En C++20, la fonction non membre std::ssize() renvoie la longueur sous la forme d'un entier signé de grande taille (généralement std::ptrdiff_t, le type signé normalement associé à std::size_t).

Accéder aux éléments d'un tableau à l'aide de la fonction membre at() effectue une vérification des bornes à l'exécution (et lève une exception de type std::out_of_range si les bornes sont dépassées). Si l'exception n'est pas interceptée, l'application est terminée.

operator[] et la fonction membre at() acceptent tous deux des index non constants. Toutefois, ils attendent tous deux un index de type size_type, qui est un type entier non signé. Cela pose des problèmes de conversion de signe lorsque les index ne sont pas des expressions constantes (constexpr).

Un objet de type std::vector peut être passé à une fonction comme n'importe quel autre objet. Si l'on passe un std::vector par valeur, une copie coûteuse est effectuée. C'est pourquoi on passe généralement un std::vector par référence (constante) afin d'éviter ces copies.

On peut utiliser un modèle de fonction pour passer à une fonction un std::vector dont les éléments sont de n'importe quel type. Vous pouvez utiliser un assert() pour vérifier que le vector passé a bien la longueur attendue.

Le terme sémantique de copie (copy semantics) désigne les règles qui déterminent comment les copies d'objets sont réalisées. Lorsque l'on dit que la sémantique de copie est invoquée, cela signifie que l'on a fait quelque chose qui va copier un objet.

Lorsque la propriété des données est transférée d'un objet à un autre, on dit que ces données ont été déplacées (moved).

La sémantique de déplacement (move semantics) désigne les règles qui déterminent comment les données d'un objet sont déplacées vers un autre objet. Lorsque la sémantique de déplacement est invoquée, tout membre de données qui peut être déplacé l'est, et tout membre qui ne peut pas être déplacé est copié. La capacité à déplacer les données plutôt qu'à les copier rend la sémantique de déplacement plus efficace que la sémantique de copie, surtout lorsqu'elle permet de remplacer une copie coûteuse par un déplacement peu coûteux.

Normalement, lorsqu'un objet est initialisé ou affecté à partir d'un objet du même type, la sémantique de copie est utilisée (en supposant que la copie n'est pas éliminée). La sémantique de déplacement est automatiquement utilisée à la place lorsque le type de l'objet la supporte et que l'initialisateur ou l'objet dont on affecte la valeur est une rvalue.

Nous pouvons renvoyer par valeur des types capables de déplacement (comme std::vector et std::string). Ces types déplaceront leurs valeurs à moindre coût au lieu de réaliser une copie coûteuse.

Le fait d'accéder à chaque élément d'un conteneur dans un certain ordre s'appelle le parcours (traversal), ou parcourir le conteneur. Le parcours est aussi parfois appelé itération sur le conteneur ou itérer à travers le conteneur.

Les boucles sont souvent utilisées pour parcourir un tableau, une variable de boucle servant alors d'index. Attention aux erreurs de décalage d'un (off-by-one), où le corps de la boucle s'exécute une fois de trop ou une fois de moins.

Une boucle for basée sur un intervalle (range-based for loop, parfois appelée boucle for-each) permet de parcourir un conteneur sans avoir à indexer explicitement. Privilégiez les boucles for basées sur un intervalle plutôt que les boucles for classiques lorsque vous parcourez des conteneurs.

Utilisez la déduction de type (auto) avec les boucles for basées sur un intervalle afin que le compilateur déduise le type de l'élément du tableau. La déclaration de l'élément doit utiliser une référence (constante) chaque fois que vous passeriez normalement ce type d'élément par référence (constante). Envisagez d'utiliser systématiquement const auto&, sauf si vous avez besoin de travailler sur des copies. Cela garantit qu'aucune copie n'est faite, même si le type des éléments est modifié par la suite.

Les énumérations non délimitées (unscoped) peuvent être utilisées comme indices, ce qui permet de donner une information sur la signification de l'index.

Ajouter un énumérateur de « comptage » supplémentaire est utile chaque fois que l'on a besoin d'un énumérateur représentant la longueur du tableau. Vous pouvez utiliser assert ou static_assert pour vérifier que la longueur d'un tableau est égale à celle de l'énumérateur de comptage, afin de vous assurer que le tableau est initialisé avec le nombre attendu d'initialisateurs.

Les tableaux dont la longueur doit être définie au moment de l'instanciation et ne peut plus être modifiée ensuite sont appelés tableaux de taille fixe (fixed-size arrays) ou tableaux de longueur fixe (fixed-length arrays). Un tableau dynamique (dynamic array, aussi appelé tableau redimensionnable, resizable array) est un tableau dont la taille peut être modifiée après l'instanciation. C'est cette capacité à être redimensionné qui rend std::vector si particulier.

Un std::vector peut être redimensionné après son instanciation en appelant la fonction membre resize() avec la nouvelle longueur souhaitée.

Dans le contexte d'un std::vector, la capacité (capacity) correspond au nombre d'éléments pour lesquels le std::vector a alloué de l'espace de stockage, et la longueur (length) correspond au nombre d'éléments effectivement utilisés. On peut demander la capacité d'un std::vector via la fonction membre capacity().

Lorsqu'un std::vector modifie la quantité d'espace de stockage qu'il gère, ce processus est appelé réallocation (reallocation). Comme la réallocation nécessite généralement de copier chaque élément du tableau, elle est coûteuse. Il faut donc éviter autant que raisonnablement possible les réallocations.

Les indices valides pour l'opérateur d'indexation (operator[]) et la fonction membre at() sont fondés sur la longueur du vector, et non sur sa capacité.

std::vector possède une fonction membre nommée shrink_to_fit() qui demande au vector de réduire sa capacité pour correspondre à sa longueur. Cette demande n'est pas contraignante (non-binding).

L'ordre dans lequel les éléments sont ajoutés à une pile et retirés de celle-ci peut être décrit comme dernier entré, premier sorti (last-in, first-out, LIFO). La dernière assiette empilée sera la première à être retirée. En programmation, une pile (stack) est un type de conteneur dans lequel l'insertion et le retrait des éléments suivent un fonctionnement LIFO. Cela est couramment implémenté par deux opérations nommées push (empiler) et pop (dépiler).

Les fonctions membres push_back() et emplace_back() de std::vector augmentent la longueur d'un std::vector et provoquent une réallocation si la capacité ne suffit pas à insérer la valeur. Lorsqu'un push déclenche une réallocation, std::vector alloue généralement une capacité supplémentaire, afin de pouvoir ajouter d'autres éléments sans déclencher une nouvelle réallocation lors de l'ajout suivant.

La fonction membre resize() modifie la longueur du vector et, si nécessaire, sa capacité. La fonction membre reserve() ne modifie que la capacité, si nécessaire.

Pour augmenter le nombre d'éléments d'un std::vector :

  • Utilisez resize() lorsque vous accédez au vector par indexation. Cela modifie la longueur du vector, de sorte que vos indices seront valides.
  • Utilisez reserve() lorsque vous accédez au vector à l'aide des opérations de pile. Cela augmente la capacité sans modifier la longueur du vector.

push_back() et emplace_back() empilent tous deux un élément. Si l'objet à empiler existe déjà, push_back() et emplace_back() sont équivalents. En revanche, lorsque l'on crée un objet temporaire dans le but de l'empiler dans le vector, emplace_back() peut être plus efficace. Préférez emplace_back() lorsque vous créez un nouvel objet temporaire à ajouter au conteneur, ou lorsque vous devez accéder à un constructeur explicite. Dans les autres cas, préférez push_back().

Il existe une implémentation spéciale pour std::vector<bool>, qui peut être plus économe en espace pour les valeurs booléennes en regroupant de la même façon 8 valeurs booléennes dans un octet.

std::vector<bool> n'est pas un vector (il n'est pas obligatoirement contigu en mémoire), il ne contient pas non plus de valeurs bool (il contient une collection de bits), et il ne satisfait pas la définition d'un conteneur en C++. Bien que std::vector<bool> se comporte comme un vector dans la plupart des cas, il n'est pas entièrement compatible avec le reste de la bibliothèque standard. Du code qui fonctionne avec d'autres types d'éléments peut ne pas fonctionner avec std::vector<bool>. Il faut donc généralement éviter std::vector<bool>.

Définissez une énumération non délimitée dans un espace de noms pour identifier les différents types d'objets. Définissez un std::vector pour stocker le nombre d'objets de chaque type que le joueur transporte. Le joueur doit commencer avec 1 potion de soin, 5 torches et 10 flèches. Utilisez un assert pour vérifier que le tableau contient le bon nombre d'initialisateurs.

#include <cassert>
#include <iostream>
#include <vector>

namespace Items
{
    enum Type
    {
        health_potion,
        torch,
        arrow,
        max_items
    };
}

// Les quantités d'objets d'inventaire doivent être entières : nous n'avons donc pas besoin d'un modèle de fonction ici

    for (auto e: inventory)
        sum += e;
    return sum;

{
    std::vector inventory { 1, 5, 10 };

> Étape n° 2

Modifiez votre programme de l'étape précédente pour qu'il affiche maintenant :


You have 1 health potion
You have 5 torches
You have 10 arrows
You have 16 total items

Utilisez une boucle pour afficher le nombre d'objets et le nom de chaque objet de l'inventaire. Gérez correctement l'accord au pluriel des noms.

Solution 
#include <cassert>
#include <iostream>
#include <string_view>
#include <type_traits> // pour std::is_integral et std::is_enum
#include <vector>

namespace Items
{
    enum Type: int
    {
        health_potion,
        torch,
        arrow,
        max_items
    };
}

std::string_view getItemNamePlural(Items::Type type)
{
    switch (type)
    {
        case Items::health_potion:  return "health potions";
        case Items::torch:          return "torches";
        case Items::arrow:          return "arrows";

        default:                    return "???";
    }
}

std::string_view getItemNameSingular(Items::Type type)
{
    switch (type)
    {
        case Items::health_potion:  return "health potion";
        case Items::torch:          return "torch";
        case Items::arrow:          return "arrow";

        default:                    return "???";
    }
}

// Fonction utilitaire pour convertir `value` en un objet de type std::size_t
// UZ est le suffixe des littéraux de type std::size_t.
template <typename T>
constexpr std::size_t toUZ(T value)
{
    // vérifie que T est un type entier
    static_assert(std::is_integral<T>() || std::is_enum<T>());

    return static_cast<std::size_t>(value);
}


void printInventoryItem(const std::vector<int>& inventory, Items::Type type)
{
    bool plural { inventory[toUZ(type)] != 1 };
    std::cout << "You have " << inventory[toUZ(type)] << ' ';
    std::cout << (plural ? getItemNamePlural(type) : getItemNameSingular(type)) << '\n';
}

// Les quantités d'objets d'inventaire doivent être entières : nous n'avons donc pas besoin d'un modèle de fonction ici
int countTotalItems(const std::vector<int>& inventory)
{
    int sum { 0 };
    for (auto e: inventory)
        sum += e;
    return sum;
}

int main()
{
    std::vector inventory { 1, 5, 10 };
    assert(std::size(inventory) == Items::max_items); // vérifie que notre inventaire contient le bon nombre d'initialisateurs

    // Comme on ne peut pas parcourir un type énuméré avec une boucle basée sur un intervalle, nous utilisons ici une boucle for classique
    for (int i=0; i < Items::max_items; ++i)
    {
        auto item { static_cast<Items::Type>(i) };
        printInventoryItem(inventory, item);
    }

    std::cout << "You have " << countTotalItems(inventory) << " total items\n";

    return 0;
}

Question n° 3

Écrivez une fonction qui prend un std::vector et renvoie une std::pair contenant les indices des éléments ayant les valeurs minimale et maximale du tableau. La documentation de std::pair se trouve ici. Appelez la fonction sur les deux vectors suivants :

    std::vector v1 { 3, 8, 2, 5, 7, 8, 3 };
    std::vector v2 { 5.5, 2.7, 3.3, 7.6, 1.2, 8.8, 6.6 };

Le programme doit afficher ceci :


With array ( 3, 8, 2, 5, 7, 8, 3 ):
The min element has index 2 and value 2
The max element has index 1 and value 8

With array ( 5.5, 2.7, 3.3, 7.6, 1.2, 8.8, 6.6 ):
The min element has index 4 and value 1.2
The max element has index 5 and value 8.8
Solution 
#include <iostream>
#include <vector>

template <typename T>
std::pair<std::size_t, std::size_t> findMinMaxIndices(const std::vector<T>& v)
{
    // On suppose que l'élément 0 est à la fois le minimum et le maximum
    std::size_t minIndex { 0 };
    std::size_t maxIndex { 0 };

    // On parcourt les éléments restants pour voir si l'on trouve un élément plus petit ou plus grand
    for (std::size_t index { 1 }; index < v.size(); ++index)
    {
        if (v[index] < v[minIndex])
            minIndex = index;
        if (v[index] > v[maxIndex])
            maxIndex = index;
    }

    return { minIndex, maxIndex };
}

template <typename T>
void printArray(const std::vector<T>& v)
{
    bool comma { false };
    std::cout << "With array ( ";
    for (const auto& e: v)
    {
        if (comma)
            std::cout << ", ";

        std::cout << e;
        comma = true;
    }
    std::cout << " ):\n";
}

int main()
{
    std::vector v1 { 3, 8, 2, 5, 7, 8, 3 };
    printArray(v1);

    auto m1 { findMinMaxIndices(v1) };
    std::cout << "The min element has index " << m1.first << " and value " << v1[m1.first] << '\n';
    std::cout << "The max element has index " << m1.second << " and value " << v1[m1.second] << '\n';

    std::cout << '\n';

    std::vector v2 { 5.5, 2.7, 3.3, 7.6, 1.2, 8.8, 6.6 };
    printArray(v2);

    auto m2 { findMinMaxIndices(v2) };
    std::cout << "The min element has index " << m2.first << " and value " << v2[m2.first] << '\n';
    std::cout << "The max element has index " << m2.second << " and value " << v2[m2.second] << '\n';

    return 0;
}

Question n° 4

Modifiez le programme précédent pour que l'utilisateur puisse saisir autant d'entiers qu'il le souhaite. Arrêtez la saisie lorsque l'utilisateur entre -1.

Affichez le vector et trouvez les éléments minimum et maximum.

Lorsqu'il est exécuté avec la saisie 3 8 5 2 3 7 -1, le programme doit produire la sortie suivante :


Enter numbers to add (use -1 to stop): 3 8 5 2 3 7 -1
With array ( 3, 8, 5, 2, 3, 7 ):
The min element has index 3 and value 2
The max element has index 1 and value 8

Gérez de façon raisonnable le cas où l'utilisateur saisit -1 comme première valeur.

Solution 
#include <iostream>
#include <limits>
#include <vector>

template <typename T>
std::pair<std::size_t, std::size_t> findMinMaxIndices(const std::vector<T>& v)
{
    // On suppose que l'élément 0 est à la fois le minimum et le maximum
    std::size_t minIndex { 0 };
    std::size_t maxIndex { 0 };

    // On parcourt les éléments restants pour voir si l'on trouve un élément plus petit ou plus grand
    for (std::size_t index { 1 }; index < v.size(); ++index)
    {
        if (v[index] < v[minIndex])
            minIndex = index;
        if (v[index] > v[maxIndex])
            maxIndex = index;
    }

    return { minIndex, maxIndex };
}

template <typename T>
void printArray(const std::vector<T>& v)
{
    bool comma { false };
    std::cout << "With array ( ";
    for (const auto& e: v)
    {
        if (comma)
            std::cout << ", ";

        std::cout << e;
        comma = true;
    }
    std::cout << " ):\n";
}

int main()
{
    std::vector<int> v1 { };
    std::cout << "Enter numbers to add (use -1 to stop): ";

    while (true)
    {
        int input{};
        std::cin >> input;
        if (input == -1)
            break;

        if (!std::cin) // si l'extraction précédente a échoué
        {
            std::cin.clear(); // on revient au mode de fonctionnement « normal »
            std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n'); // et on supprime la mauvaise saisie
            continue;
        }

        v1.push_back(input);
    }

    // Si le tableau est vide
    if (v1.size() == 0)
    {
        std::cout << "The array has no elements\n";
    }
    else
    {
        printArray(v1);

        auto m1 { findMinMaxIndices(v1) };
        std::cout << "The min element has index " << m1.first << " and value " << v1[m1.first] << '\n';
        std::cout << "The max element has index " << m1.second << " and value " << v1[m1.second] << '\n';
    }

    return 0;
}

Question n° 5

Implémentons le jeu C++man (qui sera notre version du célèbre jeu d'enfants Hangman.

Si vous n'avez jamais joué au pendu, voici les règles abrégées :

Règles générales :

  • L'ordinateur choisit un mot au hasard et dessine un tiret bas pour chaque lettre du mot.
  • Le joueur gagne s'il devine toutes les lettres du mot avant de faire X mauvaises réponses (X étant configurable).

À chaque tour :

  • Le joueur devine une seule lettre.
  • Si le joueur a déjà proposé cette lettre, cela ne compte pas et la partie continue.
  • Si l'un des tirets bas représente cette lettre, ces tirets sont remplacés par la lettre et la partie continue.
  • Si aucun tiret bas ne représente cette lettre, le joueur perd l'une de ses mauvaises réponses.

État :

  • Le joueur doit savoir combien de mauvaises réponses il lui reste.
  • Le joueur doit savoir quelles lettres il a proposées de façon incorrecte (par ordre alphabétique).

> Étape n° 4

Objectif : terminer le jeu.

Tâches :

  • Ajoutez l'affichage du nombre total de mauvaises réponses restantes.
  • Ajoutez l'affichage des lettres incorrectes proposées.
  • Ajoutez la condition de victoire ou de défaite, ainsi que les messages correspondants.
Solution 
#include <iostream>
#include <string_view>
#include <vector>
#include "Random.h"

namespace Settings
{
    constexpr int wrongGuessesAllowed { 6 };
}

namespace WordList
{
    // Définissez ici votre liste de mots
    std::vector<std::string_view> words { "mystery", "broccoli" , "account", "almost", "spaghetti", "opinion", "beautiful", "distance", "luggage" };

    std::string_view getRandomWord()
    {
        return words[Random::get<std::size_t>(0, words.size()-1)];
    }
}

class Session
{
private:
    // Données de la session de jeu
    std::string_view m_word { WordList::getRandomWord() };
    int m_wrongGuessesLeft { Settings::wrongGuessesAllowed };
    std::vector<bool> m_letterGuessed { std::vector<bool>(26) };

    std::size_t toIndex(char c) const { return static_cast<std::size_t>((c % 32)-1); }

public:
    std::string_view getWord() const { return m_word; }

    int wrongGuessesLeft() const { return m_wrongGuessesLeft; }
    void removeGuess() { --m_wrongGuessesLeft; }

    bool isLetterGuessed(char c) const { return m_letterGuessed[toIndex(c)]; }
    void setLetterGuessed(char c) { m_letterGuessed[toIndex(c)] = true; }

    bool isLetterInWord(char c) const
    {
        for (auto ch: m_word) // parcourt chaque lettre du mot
        {
            if (ch == c)
                return true;
        }

        return false;
    }

    bool won()
    {
        for (auto c: m_word) // parcourt chaque lettre du mot
        {
            if (!isLetterGuessed(c))
                return false;
        }

        return true;
    }
};

void draw(const Session& s)
{
    std::cout << '\n';

    std::cout << "The word: ";
    for (auto c: s.getWord()) // parcourt chaque lettre du mot
    {
        if (s.isLetterGuessed(c))
            std::cout << c;
        else
            std::cout << '_';
    }

    std::cout << "   Wrong guesses: ";
    for (int i=0; i < s.wrongGuessesLeft(); ++i)
        std::cout << '+';


    for (char c='a'; c <= 'z'; ++c)
        if (s.isLetterGuessed(c) && !s.isLetterInWord(c))
            std::cout << c;

    std::cout << '\n';
}

char getGuess(const Session& s)
{
    while (true)
    {
        std::cout << "Enter your next letter: ";

        char c{};
        std::cin >> c;

        // Si l'utilisateur a fait une erreur, on recommence
        if (!std::cin)
        {
            // On corrige la situation
            std::cin.clear();
            std::cout << "That wasn't a valid input.  Try again.\n";
            std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
            continue;
        }

        // On supprime les saisies superflues
        std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');

        // Si l'utilisateur a saisi un caractère invalide, on recommence
        if (c < 'a' || c > 'z')
        {
            std::cout << "That wasn't a valid input.  Try again.\n";
            continue;
        }

        // Si la lettre a déjà été proposée, on recommence
        if (s.isLetterGuessed(c))
        {
            std::cout << "You already guessed that.  Try again.\n";
            continue;
        }

        // Si l'on est arrivé ici, la proposition est valide
        return c;
    }
}

void handleGuess(Session &s, char c)
{
    s.setLetterGuessed(c);

    if (s.isLetterInWord(c))
    {
        std::cout << "Yes, '" << c << "' is in the word!\n";
        return;
    }

    std::cout << "No, '" << c << "' is not in the word!\n";
    s.removeGuess();
}

int main()
{
    std::cout << "Welcome to C++man (a variant of Hangman)\n";
    std::cout << "To win: guess the word.  To lose: run out of pluses.\n";

    Session s{};

    while (s.wrongGuessesLeft() && !s.won())
    {
        draw(s);
        char c { getGuess(s) };
        handleGuess(s, c);
    }

    // Affiche l'état final du jeu
    draw(s);

    if (!s.wrongGuessesLeft())
        std::cout << "You lost!  The word was: " << s.getWord() << '\n';
    else
        std::cout << "You won!\n";

    return 0;
}
