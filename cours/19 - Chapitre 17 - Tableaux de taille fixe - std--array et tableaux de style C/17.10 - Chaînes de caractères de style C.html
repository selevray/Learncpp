17.10 — Chaînes de caractères de style C

Dans la leçon 17.7 -- Introduction aux tableaux de style C, nous avons présenté les tableaux de style C, qui permettent de définir une collection séquentielle d'éléments :

    int testScore[30] {}; // un tableau de 30 int, indices de 0 à 29

Dans la leçon 5.2 -- Littéraux, nous avons défini une chaîne comme une collection de caractères séquentiels (comme « Hello, world! »), et présenté les littéraux de chaîne de style C. Nous avons également noté que le littéral de chaîne de style C « Hello, world! » a pour type const char[14] (13 caractères explicites plus 1 caractère de fin de chaîne, le caractère nul, qui est implicite).

Si vous n'aviez pas encore fait le rapprochement, il doit maintenant être évident que les chaînes de style C ne sont que des tableaux de style C dont le type d'élément est char ou const char !

Bien que les littéraux de chaîne de style C soient parfaitement utilisables dans notre code, les objets chaînes de style C sont tombés en désuétude en C++ moderne, car ils sont difficiles à manipuler et dangereux (std::string et std::string_view en sont les remplaçants modernes). Quoi qu'il en soit, vous pouvez encore rencontrer des objets chaînes de style C dans du code ancien, et il serait inconvenant de ne pas les aborder du tout.

Dans cette leçon, nous allons donc examiner les points essentiels concernant les objets chaînes de style C en C++ moderne.

Définir des chaînes de style C

Pour définir une variable chaîne de style C, il suffit de déclarer une variable tableau de style C de type char (ou const char / constexpr char) :

char str1[8]{};                    // un tableau de 8 char, indices de 0 à 7

const char str2[]{ "string" };     // un tableau de 7 char, indices de 0 à 6
constexpr char str3[] { "hello" }; // un tableau de 6 const char, indices de 0 à 5

N'oubliez pas qu'il faut un caractère supplémentaire pour le caractère de fin de chaîne (null) implicite.

Lorsque vous définissez une chaîne de style C avec un initialiseur, nous vous recommandons vivement d'omettre la longueur du tableau et de laisser le compilateur la calculer. Ainsi, si l'initialiseur change par la suite, vous n'aurez pas à penser à mettre la longueur à jour, et il n'y a aucun risque d'oublier l'élément supplémentaire destiné au caractère de fin de chaîne.

Les chaînes de style C subissent la dégradation (decay)

Dans la leçon 17.8 -- Dégradation des tableaux de style C, nous avons vu que les tableaux de style C se dégradent en pointeur dans la plupart des circonstances. Comme les chaînes de style C sont des tableaux de style C, elles subissent également cette dégradation : les littéraux de chaîne de style C se dégradent en const char*, et les tableaux de chaînes de style C se dégradent en const char* ou char* selon que le tableau est const ou non. Et lorsqu'une chaîne de style C se dégrade en pointeur, la longueur de la chaîne (codée dans les informations de type) est perdue.

Cette perte d'information sur la longueur est la raison pour laquelle les chaînes de style C possèdent un caractère de fin de chaîne. La longueur de la chaîne peut être recalculée (de façon peu efficace) en comptant le nombre d'éléments entre le début de la chaîne et le caractère de fin de chaîne.

Afficher une chaîne de style C

Lorsqu'il affiche une chaîne de style C, std::cout écrit les caractères jusqu'à rencontrer le caractère de fin de chaîne. Ce caractère marque la fin de la chaîne, ce qui permet d'afficher aussi les chaînes dégradées (qui ont perdu leur information de longueur).

#include <iostream>

void print(char ptr[])
{
    std::cout << ptr << '\n'; // affiche la chaîne
}

int main()
{
    char str[]{ "string" };
    std::cout << str << '\n'; // affiche string

    print(str);

    return 0;
}

Si vous essayez d'afficher une chaîne qui ne possède pas de caractère de fin de chaîne (par exemple parce que celui-ci a été écrasé d'une manière ou d'une autre), le résultat sera un comportement indéfini. Le plus probable dans ce cas est que tous les caractères de la chaîne soient affichés, puis que le programme continue d'afficher tout ce qui se trouve dans les emplacements mémoire adjacents (interprétés comme des caractères) jusqu'à tomber sur un octet contenant 0 (qui sera interprété comme caractère de fin de chaîne) !

Lire des chaînes de style C

Considérons le cas où nous demandons à l'utilisateur de lancer un dé autant de fois qu'il le souhaite, et de saisir les nombres obtenus sans espaces (par exemple 524412616). Combien de caractères l'utilisateur va-t-il saisir ? Nous n'en savons rien.

Comme les chaînes de style C sont des tableaux de taille fixe, la solution consiste à déclarer un tableau plus grand que ce dont nous aurons probablement besoin :

#include <iostream>

int main()
{
    char rolls[255] {}; // déclare un tableau assez grand pour contenir 254 caractères + le caractère de fin de chaîne
    std::cout << "Enter your rolls: ";
    std::cin >> rolls;
    std::cout << "You entered: " << rolls << '\n';

    return 0;
}

Avant C++20, std::cin >> rolls extrayait autant de caractères que possible vers rolls (en s'arrêtant au premier caractère d'espacement après des caractères non blancs). Rien n'empêche l'utilisateur de saisir plus de 254 caractères (involontairement ou de façon malveillante). Si cela arrive, la saisie de l'utilisateur déborde du tableau rolls et il en résulte un comportement indéfini.

Point clé

Le dépassement de tableau (array overflow) ou dépassement de tampon (buffer overflow) est un problème de sécurité informatique qui survient lorsqu'on copie dans un espace de stockage plus de données que celui-ci ne peut en contenir. Dans ce cas, la mémoire juste après cet espace de stockage est écrasée, ce qui entraîne un comportement indéfini. Des acteurs malveillants peuvent exploiter ces failles pour écraser le contenu de la mémoire, dans l'espoir de modifier le comportement du programme à leur avantage.

En C++20, operator>> a été modifié de sorte qu'il ne fonctionne plus que pour la saisie de chaînes de style C non dégradées. Cela permet à operator>> d'extraire uniquement autant de caractères que la longueur de la chaîne de style C le permet, évitant ainsi le dépassement. Mais cela signifie aussi que vous ne pouvez plus utiliser operator>> pour saisir dans des chaînes de style C dégradées.

La méthode recommandée pour lire des chaînes de style C avec std::cin est la suivante :

#include <iostream>
#include <iterator> // pour std::size

int main()
{
    char rolls[255] {}; // déclare un tableau assez grand pour contenir 254 caractères + le caractère de fin de chaîne
    std::cout << "Enter your rolls: ";
    std::cin.getline(rolls, std::size(rolls));
    std::cout << "You entered: " << rolls << '\n';

    return 0;
}

Cet appel à cin.getline() lit jusqu'à 254 caractères (espaces compris) dans rolls. Les caractères en trop sont ignorés. Comme getline() prend une longueur en paramètre, nous pouvons indiquer le nombre maximal de caractères à accepter. Avec un tableau non dégradé, c'est facile : nous pouvons utiliser std::size() pour obtenir la longueur du tableau. Avec un tableau dégradé, nous devons déterminer la longueur autrement. Et si nous fournissons une mauvaise longueur, notre programme peut mal fonctionner ou présenter des failles de sécurité.

En C++ moderne, pour stocker le texte saisi par l'utilisateur, il est plus sûr d'utiliser std::string, car std::string s'adapte automatiquement pour contenir autant de caractères que nécessaire.

Modifier des chaînes de style C

Un point important à noter est que les chaînes de style C suivent les mêmes règles que les tableaux de style C. Cela signifie que vous pouvez initialiser la chaîne lors de sa création, mais que vous ne pouvez plus lui affecter de valeurs avec l'opérateur d'affectation après cela !

char str[]{ "string" }; // ok
str = "rope";           // pas ok !

Cela rend l'utilisation des chaînes de style C un peu maladroite.

Comme les chaînes de style C sont des tableaux, vous pouvez utiliser l'opérateur [] pour modifier des caractères individuels de la chaîne :

#include <iostream>

int main()
{
    char str[]{ "string" };
    std::cout << str << '\n';
    str[1] = 'p';
    std::cout << str << '\n';

    return 0;
}

Ce programme affiche :


string
spring

Obtenir la longueur d'une chaîne de style C

Comme les chaînes de style C sont des tableaux de style C, vous pouvez utiliser std::size() (ou, en C++20, std::ssize()) pour obtenir la longueur de la chaîne en tant que tableau. Il y a deux précautions à prendre :

  1. Cela ne fonctionne pas sur les chaînes dégradées.
  2. Cela renvoie la longueur réelle du tableau de style C, et non la longueur de la chaîne.
#include <iostream>

int main()
{
    char str[255]{ "string" }; // 6 caractères + le caractère de fin de chaîne
    std::cout << "length = " << std::size(str) << '\n'; // affiche length = 255

    char *ptr { str };
    std::cout << "length = " << std::size(ptr) << '\n'; // erreur de compilation

    return 0;
}

Une solution alternative consiste à utiliser la fonction strlen(), qui se trouve dans l'en-tête <cstring>. strlen() fonctionne sur les tableaux dégradés et renvoie la longueur de la chaîne contenue, sans compter le caractère de fin de chaîne :

#include <cstring> // pour std::strlen
#include <iostream>

int main()
{
    char str[255]{ "string" }; // 6 caractères + le caractère de fin de chaîne
    std::cout << "length = " << std::strlen(str) << '\n'; // affiche length = 6

    char *ptr { str };
    std::cout << "length = " << std::strlen(ptr) << '\n';   // affiche length = 6

    return 0;
}

Cependant, std::strlen() est lent, car elle doit parcourir tout le tableau en comptant les caractères jusqu'à rencontrer le caractère de fin de chaîne.

Autres fonctions de manipulation des chaînes de style C

Comme les chaînes de style C sont le principal type de chaîne en C, le langage C fournit de nombreuses fonctions pour les manipuler. Ces fonctions ont été héritées par C++ à travers l'en-tête <cstring>.

Voici quelques-unes des plus utiles que vous pourrez rencontrer dans du code ancien :

  • strlen() -- renvoie la longueur d'une chaîne de style C
  • strcpy(), strncpy(), strcpy_s() -- écrase une chaîne de style C avec une autre
  • strcat(), strncat() -- ajoute une chaîne de style C à la fin d'une autre
  • strcmp(), strncmp() -- compare deux chaînes de style C (renvoie 0 si elles sont égales)

À l'exception de strlen(), nous recommandons généralement d'éviter ces fonctions.

Évitez les objets chaînes de style C non const

Sauf si vous avez une raison précise et impérieuse d'utiliser des chaînes de style C non const, mieux vaut les éviter : elles sont peu pratiques à manipuler et sujettes aux dépassements, ce qui provoque un comportement indéfini (et constitue un risque de sécurité potentiel).

Dans le rare cas où vous devriez réellement travailler avec des chaînes de style C ou des tailles de tampon fixes (par exemple pour des appareils à mémoire limitée), nous vous recommandons d'utiliser une bibliothèque tierce de chaînes à longueur fixe, bien testée et conçue à cet effet.

Bonne pratique

Évitez les objets chaînes de style C non const au profit de std::string.

Moment du quiz

Question n° 1

Écrivez une fonction qui affiche une chaîne de style C caractère par caractère. Utilisez un pointeur et l'arithmétique des pointeurs pour parcourir chaque caractère de la chaîne et afficher ce caractère. Écrivez une fonction main qui teste la fonction avec le littéral de chaîne « Hello, world! ».

Solution 
#include <iostream>

// str pointera vers la première lettre de la chaîne de style C.
// Notez que str pointe vers un const char, nous ne pouvons donc pas modifier les valeurs qu'il pointe.
// En revanche, nous pouvons faire pointer str vers autre chose. Cela ne modifie pas la valeur de l'argument.
void printCString(const char str[])
{
    // Tant que nous n'avons pas rencontré le caractère de fin de chaîne
    while (*str != '\0')
    {
        // afficher le caractère courant
        std::cout << *str;

        // et utiliser l'arithmétique des pointeurs pour passer au caractère suivant
        ++str;
    }
}

int main()
{
    printCString("Hello world!");

    std::cout << '\n';

    return 0;
}

Question n° 2

Reprenez la question n° 1, mais cette fois la fonction doit afficher la chaîne à l'envers.

Solution 
#include <iostream>

void printCStringBackwards(const char str[])
{
    // Nous ne pouvons pas modifier str cette fois (nous en avons besoin plus tard)
    // Nous définissons donc un nouveau pointeur ayant la même adresse que str
    const char *ptr{ str };

    // Trouver le caractère de fin de chaîne
    while (*ptr != '\0')
        ++ptr;

    // Puis reculer et afficher les caractères jusqu'à ce que ptr revienne à str
    while (ptr-- != str)
    {
        std::cout << *ptr;
    } 
}

int main()
{
    printCStringBackwards("Hello world!");

    std::cout << '\n';

    return 0;
}
