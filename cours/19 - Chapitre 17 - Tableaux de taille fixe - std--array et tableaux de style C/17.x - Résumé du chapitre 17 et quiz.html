17.x — Résumé du chapitre 17 et quiz

Bilan du chapitre

Les tableaux de taille fixe (ou tableaux de longueur fixe, fixed-size arrays / fixed-length arrays) exigent que leur longueur soit connue au moment de l'instanciation, et cette longueur ne peut plus être modifiée ensuite. Les tableaux de style C et std::array sont tous deux des tableaux de taille fixe. Les tableaux dynamiques peuvent être redimensionnés à l'exécution. std::vector est un tableau dynamique.

La longueur d'un std::array doit être une expression constante. Le plus souvent, la valeur fournie pour la longueur sera un littéral entier, une variable constexpr ou un énumérateur d'une énumération non scoped.

std::array est un agrégat (aggregate). Cela signifie qu'il n'a aucun constructeur et qu'il est initialisé par initialisation d'agrégat (aggregate initialization).

Définissez votre std::array comme constexpr chaque fois que c'est possible. Si votre std::array n'est pas constexpr, envisagez plutôt d'utiliser un std::vector.

Utilisez la déduction d'argument de modèle de classe (CTAD, class template argument deduction) pour laisser le compilateur déduire le type et la longueur d'un std::array à partir de ses initialiseurs.

std::array est implémenté comme une structure template dont la déclaration ressemble à ceci :

template<typename T, std::size_t N> // N est un paramètre template non-type
struct array;

Le paramètre template non-type représentant la longueur du tableau (N) est de type std::size_t.

Pour obtenir la longueur d'un std::array :

  • On peut demander à un objet std::array sa longueur à l'aide de la fonction membre size() (qui renvoie la longueur sous forme de size_type non signé).
  • En C++17, on peut utiliser la fonction non membre std::size() (qui, pour std::array, appelle simplement la fonction membre size(), et renvoie donc la longueur sous forme de size_type non signé).
  • En C++20, on peut utiliser la fonction non membre std::ssize(), qui renvoie la longueur sous la forme d'un grand type entier signé (généralement std::ptrdiff_t).

Ces trois fonctions renvoient la longueur sous forme de valeur constexpr, sauf lorsqu'elles sont appelées sur un std::array passé par référence. Ce défaut a été corrigé en C++23 par P2280.

Pour indexer un std::array :

  • Utilisez l'opérateur d'indexation (operator[]). Aucune vérification de bornes n'est effectuée dans ce cas, et passer un indice invalide provoque un comportement indéfini.
  • Utilisez la fonction membre at(), qui effectue l'indexation avec une vérification des bornes à l'exécution. Nous vous recommandons d'éviter cette fonction, car nous voulons généralement vérifier les bornes avant l'indexation, ou bien effectuer une vérification des bornes à la compilation.
  • Utilisez le modèle de fonction std::get(), qui prend l'indice comme argument template non-type, et effectue une vérification des bornes à la compilation.

Vous pouvez passer à une fonction des std::array de types d'éléments et de longueurs différents, à l'aide d'un modèle de fonction dont la déclaration de paramètres template est template <typename T, std::size_t N>. Ou bien, en C++20, utilisez template <typename T, auto N>.

Renvoyer un std::array par valeur crée une copie du tableau et de tous ses éléments. Cela peut toutefois convenir si le tableau est petit et que ses éléments ne coûtent pas cher à copier. Utiliser un paramètre de sortie (out parameter) peut être un meilleur choix dans certains contextes.

Lorsque vous initialisez un std::array avec une struct, une classe ou un tableau, sans préciser le type de l'élément pour chaque initialiseur, vous devez ajouter une paire de accolades supplémentaire afin que le compilateur interprète correctement ce qu'il doit initialiser. C'est une conséquence de l'initialisation d'agrégat, et les autres types de conteneurs de la bibliothèque standard (qui utilisent des constructeurs prenant une liste) n'exigent pas ces doubles accolades dans ces cas.

Les agrégats en C++ prennent en charge un concept appelé élision d'accolades (brace elision), qui définit des règles indiquant quand plusieurs accolades peuvent être omises. En général, vous pouvez omettre les accolades lorsque vous initialisez un std::array avec des valeurs scalaires (uniques), ou lorsque vous initialisez avec des types classes ou des tableaux dont le type est explicitement indiqué pour chaque élément.

Vous ne pouvez pas créer de tableau de références, mais vous pouvez créer un tableau de std::reference_wrapper, qui se comporte comme une référence lvalue modifiable.

Quelques points méritent d'être notés au sujet de std::reference_wrapper :

  • operator= réaffecte un std::reference_wrapper (change l'objet référencé).
  • std::reference_wrapper<T> se convertit implicitement en T&.
  • La fonction membre get() permet d'obtenir un T&. C'est utile lorsque nous voulons modifier la valeur de l'objet référencé.

Les fonctions std::ref() et std::cref() existent comme raccourcis pour créer des objets encapsulés de type std::reference_wrapper et const std::reference_wrapper.

Utilisez static_assert chaque fois que possible pour vérifier qu'un std::array constexpr utilisant la CTAD possède le bon nombre d'initialiseurs.

Les tableaux de style C ont été hérités du langage C et font partie intégrante du cœur du langage C++. Comme ils font partie du cœur du langage, les tableaux de style C possèdent leur propre syntaxe de déclaration. Dans une déclaration de tableau de style C, nous utilisons des crochets ([]) pour indiquer au compilateur qu'un objet déclaré est un tableau de style C. À l'intérieur des crochets, nous pouvons facultativement fournir la longueur du tableau, qui est une valeur entière de type std::size_t indiquant au compilateur le nombre d'éléments contenus dans le tableau. La longueur d'un tableau de style C doit être une expression constante.

Les tableaux de style C sont des agrégats, ce qui signifie qu'ils peuvent être initialisés par initialisation d'agrégat. Lorsque vous utilisez une liste d'initialisation pour initialiser tous les éléments d'un tableau de style C, il est préférable d'omettre la longueur et de laisser le compilateur la calculer.

Les tableaux de style C peuvent être indexés via operator[]. L'indice d'un tableau de style C peut être un entier signé ou non signé, ou une énumération non scoped. Cela signifie que les tableaux de style C ne sont pas soumis à tous les problèmes de conversion de signe liés à l'indexation que présentent les classes conteneurs de la bibliothèque standard !

Les tableaux de style C peuvent être const ou constexpr.

Pour obtenir la longueur d'un tableau de style C :

  • En C++17, on peut utiliser la fonction non membre std::size(), qui renvoie la longueur sous forme de std::size_t non signé.
  • En C++20, on peut utiliser la fonction non membre std::ssize(), qui renvoie la longueur sous la forme d'un grand type entier signé (généralement std::ptrdiff_t).

Dans la plupart des cas, lorsqu'un tableau de style C est utilisé dans une expression, il est implicitement converti en pointeur vers le type de l'élément, initialisé avec l'adresse du premier élément (d'indice 0). Familièrement, on appelle cela la dégradation du tableau (array decay), ou simplement decay.

L'arithmétique des pointeurs (pointer arithmetic) est une fonctionnalité qui nous permet d'appliquer certains opérateurs arithmétiques entiers (addition, soustraction, incrémentation ou décrémentation) à un pointeur afin de produire une nouvelle adresse mémoire. Étant donné un pointeur ptr, ptr + 1 renvoie l'adresse du prochain objet en mémoire (en fonction du type pointé).

Utilisez l'indexation par crochets lorsque vous indexez à partir du début du tableau (élément 0), afin que les indices du tableau correspondent à l'élément. Utilisez l'arithmétique des pointeurs lorsque vous vous positionnez de manière relative à partir d'un élément donné.

Les chaînes de caractères de style C sont simplement des tableaux de style C dont le type d'élément est char ou const char. À ce titre, elles subissent la dégradation en pointeur.

La dimension d'un tableau est le nombre d'indices nécessaires pour sélectionner un élément.

Un tableau ne contenant qu'une seule dimension est appelé tableau à une dimension (single-dimensional array) ou tableau unidimensionnel (one-dimensional array), parfois abrégé en tableau 1d. Un tableau de tableaux est appelé tableau à deux dimensions (two-dimensional array), parfois abrégé en tableau 2d, car il possède deux indices. Les tableaux comportant plus d'une dimension sont appelés tableaux multidimensionnels (multidimensional arrays). L'aplatissement (flattening) d'un tableau est un procédé qui réduit sa dimensionnalité (souvent jusqu'à une seule dimension).

En C++23, std::mdspan est une vue qui fournit une interface de tableau multidimensionnel pour une séquence contiguë d'éléments.

Question n° 1

Qu'est-ce qui ne va pas dans chacun de ces extraits, et comment le corrigeriez-vous ?

a)

#include <array>
#include <iostream>

int main()
{
    std::array arr { 0, 1, 2, 3 };

    for (std::size_t count{ 0 }; count <= std::size(arr); ++count)
    {
        std::cout << arr[count] << ' ';
    }

    std::cout << '\n';

    return 0;
}
Solution

La boucle for contient une erreur de off-by-one et tente d'accéder à l'élément de tableau d'indice 4, qui n'existe pas.

Solution : la condition de la boucle for doit utiliser < au lieu de <=.

b)

#include <iostream>

void printArray(int array[])
{
    for (int element : array)
    {
        std::cout << element << ' ';
    }
}

int main()
{
    int array[] { 9, 7, 5, 3, 1 };

    printArray(array);

    std::cout << '\n';

    return 0;
}
Solution

array subit une dégradation en pointeur lorsqu'il est passé à printArray(). Les boucles for basées sur un intervalle ne peuvent pas fonctionner avec un pointeur vers un tableau, car la taille du tableau n'est pas connue.

Solution : utilisez plutôt std::array, qui ne subit pas de dégradation.

c)

#include <array>
#include <iostream>

int main()
{
    std::cout << "Enter the number of test scores: ";
    std::size_t length{};
    std::cin >> length;

    std::array<int, length> scores;

    for (std::size_t i { 0 } ; i < length; ++i)
    {
        std::cout << "Enter score " << i << ": ";
        std::cin >> scores[i];
    }
    return 0;
}
Solution

length n'est pas une expression constante et ne peut pas servir à définir la longueur d'un std::array.

Solution : utilisez plutôt un std::vector.

#include <array>
#include <iostream>
#include <string_view>

namespace Potion
{
    enum Type
    {
    healing,
    mana,
    speed,
    invisibility,
    max_potions
    };

    constexpr std::array types { healing, mana, speed, invisibility }; // Un tableau de nos énumérateurs

    // On pourrait les placer dans une struct, mais comme nous n'avons que deux attributs, nous les gardons séparés pour le moment
    // Nous définissons explicitement le type d'élément afin de ne pas avoir à utiliser le suffixe sv
    constexpr std::array<std::string_view, max_potions> name { "healing", "mana", "speed", "invisibility" };
    constexpr std::array cost { 20, 30, 12, 50 };

    static_assert(std::size(types) == max_potions);  // vérifie que 'types' contient le bon nombre d'énumérateurs

    static_assert(std::size(name) == max_potions);

        std::cout << p << ") " << Potion::name[p] << " costs " << Potion::cost[p] << '\n';

    shop();

    return 0;

#include <array>
#include <iostream>
#include <limits> // pour std::numeric_limits
#include <string_view>
#include "Random.h"

namespace Potion
{
    enum Type
    {
        healing,
        mana,
        speed,
        invisibility,
        max_potions
    };

    constexpr std::array types { healing, mana, speed, invisibility }; // Un tableau de nos énumérateurs

    // On pourrait les placer dans une struct, mais comme nous n'avons que deux attributs, nous les gardons séparés pour le moment
    // Nous définissons explicitement le type d'élément afin de ne pas avoir à utiliser le suffixe sv
    constexpr std::array<std::string_view, max_potions> name { "healing", "mana", "speed", "invisibility" };
    constexpr std::array cost { 20, 30, 12, 50 };

    static_assert(std::size(types) == max_potions);  // vérifie que 'types' contient le bon nombre d'énumérateurs
    static_assert(std::size(cost) == max_potions);
    static_assert(std::size(name) == max_potions);
}

class Player
{
private:
    static constexpr int s_minStartingGold { 80 };
    static constexpr int s_maxStartingGold { 120 };

    std::string m_name {};
    int m_gold {};
    std::array<int, Potion::max_potions> m_inventory { };

public:
    explicit Player(std::string_view name) :
        m_name { name },
        m_gold { Random::get(s_minStartingGold, s_maxStartingGold) }
    { 
    }

    // renvoie false si le joueur ne peut pas se le permettre, true si l'achat est effectué
    bool buy(Potion::Type type)
    {
        if (m_gold < Potion::cost[type])
            return false;

        m_gold -= Potion::cost[type];
        ++m_inventory[type];
        return true;
    }

    int gold() const { return m_gold; }
    int inventory(Potion::Type p) const { return m_inventory[p]; }
};

void ignoreLine()
{
    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
}

int charNumToInt(char c)
{
    return c - '0';
}

Potion::Type whichPotion()
{
    std::cout << "Enter the number of the potion you'd like to buy, or 'q' to quit: ";
    char input{};
    while (true)
    {
        std::cin >> input;
        if (!std::cin)
        {
            std::cin.clear(); // on revient en mode de fonctionnement « normal »
            ignoreLine(); // et on supprime la mauvaise saisie
            continue;
        }

        // S'il y a une saisie superflue, on traite le cas comme un échec
        if (!std::cin.eof() && std::cin.peek() != '\n')
        {
            std::cout << "I didn't understand what you said.  Try again: ";
            ignoreLine(); // ignore toute saisie superflue
            continue;
        }

        if (input == 'q')
            return Potion::max_potions;

        // Convertit le char en nombre et vérifie qu'il s'agit d'une sélection de potion valide
        int val { charNumToInt(input) };
        if (val >= 0 && val < Potion::max_potions)
            return static_cast<Potion::Type>(val);

        // Ce n'était pas une sélection de potion valide
        std::cout << "I didn't understand what you said.  Try again: ";
        ignoreLine();
    }
}

void shop(Player &player)
{
    while (true)
    {
        std::cout << "Here is our selection for today:\n";

        for (auto p: Potion::types)
            std::cout << p << ") " << Potion::name[p] << " costs " << Potion::cost[p] << '\n';

        Potion::Type which { whichPotion() };
        if (which == Potion::max_potions)
            return;

        bool success { player.buy(which) };
        if (!success)
            std::cout << "You can not afford that.\n\n";
        else
            std::cout << "You purchased a potion of " << Potion::name[which] << ".  You have " << player.gold() << " gold left.\n\n";
    }
}

void printInventory(Player& player)
{
    std::cout << "Your inventory contains: \n";

    for (auto p: Potion::types)
    {
        if (player.inventory(p) > 0)
            std::cout << player.inventory(p) << "x potion of " << Potion::name[p] << '\n';
    }

    std::cout << "You escaped with " << player.gold() << " gold remaining.\n";
}

int main()
{
    std::cout << "Welcome to Roscoe's potion emporium!\n";
    std::cout << "Enter your name: ";

    std::string name{};
    std::cin >> name;

    Player player { name };

    std::cout << "Hello, " << name << ", you have " << player.gold() << " gold.\n\n";

    shop(player);

    std::cout << '\n';

    printInventory(player);

    std::cout << "\nThanks for shopping at Roscoe's potion emporium!\n";

    return 0;
}

Question n° 4

Bon, utilisons maintenant nos Card et Deck pour implémenter une version simplifiée du Blackjack ! Si vous ne connaissez pas déjà le Blackjack, l'article Wikipedia sur le Blackjack en donne un résumé.

Voici les règles de notre version du Blackjack :

  • Le croupier reçoit une carte au départ (dans la réalité, il en reçoit deux, mais l'une est face cachée, donc cela n'a pas d'importance à ce stade).
  • Le joueur reçoit deux cartes au départ.
  • Le joueur joue en premier.
  • Un joueur peut « tirer » (hit) ou « rester » (stand) à plusieurs reprises.
  • Si le joueur « reste », son tour est terminé et son score est calculé à partir des cartes qu'il a reçues.
  • Si le joueur « tire », il reçoit une autre carte et la valeur de cette carte est ajoutée à son score total.
  • Un as compte normalement pour 1 ou pour 11 (selon ce qui est le plus avantageux pour le score total). Par souci de simplicité, nous le compterons ici comme 11.
  • Si le joueur dépasse un score de 21, il saute (bust) et perd immédiatement.
  • Lorsque le joueur a terminé, c'est au tour du croupier.
  • Le croupier tire des cartes jusqu'à atteindre un score de 17 ou plus, moment où il doit s'arrêter.
  • Si le croupier dépasse un score de 21, il saute et le joueur gagne immédiatement.
  • Sinon, si le joueur a un score supérieur à celui du croupier, le joueur gagne. Dans le cas contraire, le joueur perd (nous considérerons par souci de simplicité que les égalités sont des victoires du croupier).

Dans notre version simplifiée du Blackjack, nous ne gardons pas la trace des cartes précises reçues par le joueur et par le croupier. Nous ne suivons que la somme des valeurs des cartes reçues par le joueur et par le croupier. Cela simplifie les choses.

Nous devrons modifier cette fonction pour qu'elle renvoie trois possibilités : victoire du croupier, victoire du joueur, égalité. La meilleure façon de procéder serait de définir une énumération pour ces trois options, et de faire renvoyer à la fonction l'énumérateur approprié.

c) Exercice bonus : intégrez les deux idées ci-dessus dans votre jeu de Blackjack. Notez que vous devrez afficher la carte initiale du croupier et les deux cartes initiales du joueur, afin qu'ils sachent s'ils possèdent un as ou non.

Voici un exemple de sortie :


The dealer is showing JH (10)
You are showing AH 7D (18)
(h) to hit, or (s) to stand: h
You were dealt JD.  You now have: 18
(h) to hit, or (s) to stand: s
The dealer flips a 6C.  They now have: 16
The dealer flips a AD.  They now have: 17
You win!
Solution 
#include <algorithm> // pour std::shuffle
#include <array>
#include <cassert>
#include <iostream>
#include "Random.h"

namespace Settings
{
    // Score maximum avant de perdre.
    constexpr int bust{ 21 };

    // Score minimum que le croupier doit atteindre.
    constexpr int dealerStopsAt{ 17 };
}

struct Card
{
    enum Rank
    {
        rank_ace,
        rank_2,
        rank_3,
        rank_4,
        rank_5,
        rank_6,
        rank_7,
        rank_8,
        rank_9,
        rank_10,
        rank_jack,
        rank_queen,
        rank_king,

        max_ranks
    };

    enum Suit
    {
        suit_club,
        suit_diamond,
        suit_heart,
        suit_spade,

        max_suits
    };

    static constexpr std::array allRanks { rank_ace, rank_2, rank_3, rank_4, rank_5, rank_6, rank_7, rank_8, rank_9, rank_10, rank_jack, rank_queen, rank_king };
    static constexpr std::array allSuits { suit_club, suit_diamond, suit_heart, suit_spade };

    Rank rank{};
    Suit suit{};

    friend std::ostream& operator<<(std::ostream& out, const Card &card)
    {
        static constexpr std::array ranks { 'A', '2', '3', '4', '5', '6', '7', '8', '9', 'T', 'J', 'Q', 'K' };
        static constexpr std::array suits { 'C', 'D', 'H', 'S' };

        out << ranks[card.rank] << suits[card.suit];
        return out;
    }

    int value() const
    {
        static constexpr std::array rankValues { 11, 2, 3, 4, 5, 6, 7, 8, 9, 10, 10, 10, 10 };
        return rankValues[rank];
    }
};

class Deck
{
private:
    std::array<Card, 52> m_cards {};
    std::size_t m_nextCardIndex { 0 };

public:
    Deck()
    {
        std::size_t count { 0 };
        for (auto suit: Card::allSuits)
            for (auto rank: Card::allRanks)
                m_cards[count++] = Card{rank, suit};
    }

    void shuffle()
    {
        std::shuffle(m_cards.begin(), m_cards.end(), Random::mt);
        m_nextCardIndex = 0;
    }

    Card dealCard()
    {
        assert(m_nextCardIndex != 52 && "Deck::dealCard ran out of cards");
        return m_cards[m_nextCardIndex++];
    }

};

class Player
{
private:
    int m_score{ };
    int m_ace11Count { 0 }; // nombre d'as valant 11 points que possède le joueur

public:
    // Nous utilisons une fonction pour ajouter la carte au score du joueur
    // car nous devons maintenant compter les as
    void addToScore(Card card)
    {
        m_score += card.value();
        if (card.rank == Card::rank_ace)
            ++m_ace11Count; // les as valent 11 points au départ
        consumeAces();
    }

    // Décrémente aceCount de 1 et
    void consumeAces()
    {
        // Si le joueur devait sauter, on regarde si l'on peut faire passer des as de 11 points à 1
        while (m_score > Settings::bust && m_ace11Count > 0)
        {
            m_score -= 10;
            --m_ace11Count;
        }
    }

    int score() { return m_score; }
};

bool playerWantsHit()
{
    while (true)
    {
        std::cout << "(h) to hit, or (s) to stand: ";

        char ch{};
        std::cin >> ch;

        switch (ch)
        {
            case 'h':
                return true;
            case 's':
                return false;
        }
    }
}

// Renvoie true si le joueur a sauté. False sinon.
bool playerTurn(Deck& deck, Player& player)
{
    while (player.score() < Settings::bust && playerWantsHit())
    {
        Card card { deck.dealCard() };
        player.addToScore(card);

        std::cout << "You were dealt " << card  << ". You now have: " << player.score() << '\n';
    }

    if (player.score() > Settings::bust)
    {
        std::cout << "You went bust!\n";
        return true;
    }

    return false;
}


// Renvoie true si le croupier a sauté. False sinon.
bool dealerTurn(Deck& deck, Player& dealer)
{
    while (dealer.score() < Settings::dealerStopsAt)
    {
        Card card { deck.dealCard() };
        dealer.addToScore(card);

        std::cout << "The dealer flips a " << card << ".  They now have: " << dealer.score() << '\n';
    }

    if (dealer.score() > Settings::bust)
    {
        std::cout << "The dealer went bust!\n";
        return true;
    }

    return false;
}

enum class GameResult
{
    playerWon,
    dealerWon,
    tie
};

GameResult playBlackjack()
{
    Deck deck{};
    deck.shuffle();

    Player dealer{};
    Card card1 { deck.dealCard() };
    dealer.addToScore(card1);
    std::cout << "The dealer is showing " << card1 << " (" << dealer.score() << ")\n";

    Player player{};
    Card card2 { deck.dealCard() };
    Card card3 { deck.dealCard() };
    player.addToScore(card2);
    player.addToScore(card3);
    std::cout << "You are showing " << card2 << ' ' << card3 << " (" << player.score() << ")\n";

    if (playerTurn(deck, player)) // si le joueur a sauté
        return GameResult::dealerWon;

    if (dealerTurn(deck, dealer)) // si le croupier a sauté
        return GameResult::playerWon;

    if (player.score() == dealer.score())
        return GameResult::tie;

    return (player.score() > dealer.score() ? GameResult::playerWon : GameResult::dealerWon);
}

int main()
{
    switch (playBlackjack())
    {
    case GameResult::playerWon:
        std::cout << "You win!\n";
        return 0;
    case GameResult::dealerWon:
        std::cout << "You lose!\n";
        return 0;
    case GameResult::tie:
        std::cout << "It's a tie.\n";
        return 0;
    }

    return 0;
}
