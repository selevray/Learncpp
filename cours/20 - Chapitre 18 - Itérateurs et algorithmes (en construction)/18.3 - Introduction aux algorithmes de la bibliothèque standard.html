18.3 — Introduction aux algorithmes de la bibliothèque standard

Les débutants passent souvent beaucoup de temps à écrire des boucles personnalisées pour accomplir des tâches relativement simples, comme trier, compter ou rechercher dans des tableaux. Ces boucles peuvent poser problème, tant par la facilité avec laquelle on peut y commettre une erreur que par leur maintenabilité, car elles sont souvent difficiles à comprendre.

La recherche, le comptage et le tri étant des opérations très courantes, la bibliothèque standard C++ fournit de nombreuses fonctions qui permettent de les réaliser en quelques lignes de code. De plus, ces fonctions de la bibliothèque standard sont déjà testées, efficaces, fonctionnent avec de nombreux types de conteneurs différents, et beaucoup d'entre elles supportent la parallélisation (la capacité d'affecter plusieurs threads du processeur à la même tâche pour la accomplir plus rapidement).

Les fonctionnalités de la bibliothèque d'algorithmes se répartissent généralement en trois catégories :

  • Inspecteurs -- Utilisés pour consulter (sans les modifier) les données d'un conteneur. Parmi les exemples, on trouve la recherche et le comptage.
  • Mutateurs -- Utilisés pour modifier les données d'un conteneur. Parmi les exemples, on trouve le tri et le mélange.
  • Facilitateurs -- Utilisés pour produire un résultat à partir des valeurs des données membres. Parmi les exemples, on trouve les objets qui multiplient des valeurs, ou les objets qui déterminent l'ordre dans lequel des paires d'éléments doivent être triées.

Ces algorithmes se trouvent dans la bibliothèque algorithms. Dans cette leçon, nous explorerons quelques-uns des algorithmes les plus courants, mais il en existe bien d'autres. Nous vous encourageons à consulter la référence liée pour découvrir tout ce qui est disponible !

Remarque : tous ces algorithmes utilisent des itérateurs. Si vous n'êtes pas familier avec les itérateurs de base, veuillez revoir la leçon 18.2 -- Introduction aux itérateurs.

Utiliser std::find pour trouver un élément par sa valeur

std::find recherche la première occurrence d'une valeur dans un conteneur. std::find prend 3 paramètres : un itérateur vers le premier élément de la séquence, un itérateur vers la fin de la séquence, et la valeur à rechercher. Elle renvoie un itérateur pointant vers l'élément (s'il est trouvé) ou vers la fin du conteneur (si l'élément n'est pas trouvé).

Par exemple :

#include <algorithm>
#include <array>
#include <iostream>

int main()
{
    std::array arr{ 13, 90, 99, 5, 40, 80 };

    std::cout << "Enter a value to search for and replace with: ";
    int search{};
    int replace{};
    std::cin >> search >> replace;

    // Validation des entrées omise

    // std::find renvoie un itérateur pointant vers l'élément trouvé (ou vers la fin du conteneur)
    // on le stocke dans une variable, en utilisant l'inférence de type pour déduire le type de
    // l'itérateur (puisque cela nous importe peu)
    auto found{ std::find(arr.begin(), arr.end(), search) };

    // Les algorithmes qui ne trouvent pas ce qu'ils cherchent renvoient l'itérateur de fin.
    // On peut y accéder en utilisant la fonction membre end().
    if (found == arr.end())
    {
        std::cout << "Could not find " << search << '\n';
    }
    else
    {
        // Remplacer l'élément trouvé.
        *found = replace;
    }

    for (int i : arr)
    {
        std::cout << i << ' ';
    }

    std::cout << '\n';

    return 0;
}

Exemple d'exécution lorsque l'élément est trouvé


Enter a value to search for and replace with: 5 234
13 90 99 234 40 80

Exemple d'exécution lorsque l'élément n'est pas trouvé


Enter a value to search for and replace with: 0 234
Could not find 0
13 90 99 5 40 80

Utiliser std::find_if pour trouver un élément qui satisfait une condition

Il arrive que l'on veuille savoir si un conteneur contient une valeur qui satisfait une condition (par exemple, une chaîne qui contient une sous-chaîne précise), plutôt qu'une valeur exacte. Dans ce cas, std::find_if est parfaitement adapté.

La fonction std::find_if fonctionne de manière similaire à std::find, mais au lieu de passer une valeur précise à rechercher, on passe un objet appelable, comme un pointeur de fonction (ou une lambda, que nous verrons plus tard). Pour chaque élément parcouru, std::find_if appelle cette fonction (en lui passant l'élément en argument), et la fonction peut renvoyer true si une correspondance est trouvée, ou false sinon.

Voici un exemple où nous utilisons std::find_if pour vérifier si un élément contient la sous-chaîne « nut » :

#include <algorithm>
#include <array>
#include <iostream>
#include <string_view>

// Notre fonction renverra true si l'élément correspond
bool containsNut(std::string_view str)
{
    // std::string_view::find renvoie std::string_view::npos si la sous-chaîne n'est pas trouvée.
    // Sinon, elle renvoie l'indice où la sous-chaîne apparaît dans str.
    return str.find("nut") != std::string_view::npos;
}

int main()
{
    std::array<std::string_view, 4> arr{ "apple", "banana", "walnut", "lemon" };

    // Parcourir notre tableau pour voir si des éléments contiennent la sous-chaîne "nut"
    auto found{ std::find_if(arr.begin(), arr.end(), containsNut) };

    if (found == arr.end())
    {
        std::cout << "No nuts\n";
    }
    else
    {
        std::cout << "Found " << *found << '\n';
    }

    return 0;
}

Sortie


Found walnut

Si vous deviez écrire l'exemple ci-dessus à la main, vous auriez besoin d'au moins trois boucles (une pour parcourir le tableau, et deux pour trouver la sous-chaîne). Les fonctions de la bibliothèque standard nous permettent de faire la même chose en quelques lignes de code !

Utiliser std::count et std::count_if pour compter les occurrences

std::count et std::count_if recherchent toutes les occurrences d'un élément ou d'un élément satisfaisant une condition.

Dans l'exemple suivant, nous comptons le nombre d'éléments qui contiennent la sous-chaîne « nut » :

#include <algorithm>
#include <array>
#include <iostream>
#include <string_view>

bool containsNut(std::string_view str)
{
    return str.find("nut") != std::string_view::npos;
}

int main()
{
    std::array<std::string_view, 5> arr{ "apple", "banana", "walnut", "lemon", "peanut" };

    auto nuts{ std::count_if(arr.begin(), arr.end(), containsNut) };

    std::cout << "Counted " << nuts << " nut(s)\n";

    return 0;
}

Sortie


Counted 2 nut(s)

Utiliser std::sort pour un tri personnalisé

Nous avons déjà utilisé std::sort pour trier un tableau par ordre croissant, mais std::sort peut faire bien plus. Il existe une version de std::sort qui prend une fonction comme troisième paramètre, ce qui nous permet de trier comme bon nous semble. Cette fonction prend deux paramètres à comparer, et renvoie true si le premier argument doit être placé avant le second. Par défaut, std::sort trie les éléments par ordre croissant.

Utilisons std::sort pour trier un tableau par ordre décroissant, à l'aide d'une fonction de comparaison personnalisée nommée greater :

#include <algorithm>
#include <array>
#include <iostream>

bool greater(int a, int b)
{
    // Placer @a avant @b si @a est supérieur à @b.
    return (a > b);
}

int main()
{
    std::array arr{ 13, 90, 99, 5, 40, 80 };

    // Passer greater à std::sort
    std::sort(arr.begin(), arr.end(), greater);

    for (int i : arr)
    {
        std::cout << i << ' ';
    }

    std::cout << '\n';

    return 0;
}

Sortie


99 90 80 40 13 5

Une fois de plus, au lieu d'écrire nos propres boucles, nous pouvons trier notre tableau comme nous le souhaitons en quelques lignes de code !

Notre fonction greater nécessite 2 arguments, mais nous ne lui en passons aucun. D'où viennent-ils donc ? Lorsque nous utilisons une fonction sans parenthèses (), il ne s'agit que d'un pointeur de fonction, et non d'un appel. Vous vous en souvenez peut-être lorsque nous avons essayé d'afficher une fonction sans parenthèses et que std::cout a affiché « 1 ». std::sort utilise ce pointeur et appelle la fonction greater réelle avec deux éléments quelconques du tableau. Nous ne savons pas avec quels éléments greater sera appelée, car l'algorithme de tri utilisé par std::sort en interne n'est pas défini. Nous reviendrons plus en détail sur les pointeurs de fonction dans un chapitre ultérieur.

Astuce

Comme le tri par ordre décroissant est très courant, C++ fournit pour cela un type personnalisé (nommé std::greater), qui fait partie de l'en-tête functional. Dans l'exemple ci-dessus, nous pouvons remplacer :

  std::sort(arr.begin(), arr.end(), greater); // appelle notre fonction greater personnalisée

par :

  std::sort(arr.begin(), arr.end(), std::greater{}); // utilise le comparateur greater de la bibliothèque standard
  // Avant C++17, il fallait préciser le type des éléments lors de la création de std::greater
  std::sort(arr.begin(), arr.end(), std::greater<int>{}); // utilise le comparateur greater de la bibliothèque standard

Notez que std::greater{} a besoin des accolades, car il ne s'agit pas d'une fonction appelable. C'est un type, et pour l'utiliser, nous devons instancier un objet de ce type. Les accolades instancient un objet anonyme de ce type (qui est ensuite passé en argument à std::sort).

Pour les lecteurs avancés

Pour expliquer plus en détail comment std::sort utilise la fonction de comparaison, nous devons prendre du recul et revenir à une version modifiée de l'exemple du tri par sélection de la leçon 18.1 -- Tri d'un tableau par sélection.

#include <iostream>
#include <iterator>
#include <utility>

void sort(int* begin, int* end)
{
    for (auto startElement{ begin }; startElement != end-1; ++startElement)
    {
        auto smallestElement{ startElement };

        // std::next renvoie un pointeur vers l'élément suivant, comme le ferait (startElement + 1).
        for (auto currentElement{ std::next(startElement) }; currentElement != end; ++currentElement)
        {
            if (*currentElement < *smallestElement)
            {
                smallestElement = currentElement;
            }
        }

        std::swap(*startElement, *smallestElement);
    }
}

int main()
{
    int array[]{ 2, 1, 9, 4, 5 };

    sort(std::begin(array), std::end(array));

    for (auto i : array)
    {
        std::cout << i << ' ';
    }

    std::cout << '\n';

    return 0;
}

Jusqu'ici, rien de nouveau : sort trie toujours les éléments par ordre croissant. Pour ajouter une fonction de comparaison, nous devons utiliser un nouveau type, std::function<bool(int, int)>, pour stocker une fonction qui prend 2 paramètres de type int et renvoie un bool. Considérez ce type comme magique pour le moment : nous l'expliquerons dans le chapitre 20.

void sort(int* begin, int* end, std::function<bool(int, int)> compare)

Nous pouvons maintenant passer une fonction de comparaison comme greater à sort, mais comment sort l'utilise-t-elle ? Il suffit de remplacer la ligne

if (*currentElement < *smallestElement)

par

if (compare(*currentElement, *smallestElement))

Ainsi, l'appelant de sort peut choisir la manière de comparer deux éléments.

#include <functional> // std::function
#include <iostream>
#include <iterator>
#include <utility>

// sort accepte une fonction de comparaison
void sort(int* begin, int* end, std::function<bool(int, int)> compare)
{
    for (auto startElement{ begin }; startElement != end-1; ++startElement)
    {
        auto smallestElement{ startElement };

        for (auto currentElement{ std::next(startElement) }; currentElement != end; ++currentElement)
        {
            // la fonction de comparaison sert à vérifier si l'élément courant doit être placé
            // avant l'élément actuellement « le plus petit ».
            if (compare(*currentElement, *smallestElement))
            {
                smallestElement = currentElement;
            }
        }

        std::swap(*startElement, *smallestElement);
    }
}

int main()
{
    int array[]{ 2, 1, 9, 4, 5 };

    // utiliser std::greater pour trier par ordre décroissant
    // (Nous devons utiliser le sélecteur d'espace de noms global pour éviter une collision
    // entre notre fonction sort et std::sort.)
    ::sort(std::begin(array), std::end(array), std::greater{});

    for (auto i : array)
    {
        std::cout << i << ' ';
    }

    std::cout << '\n';

    return 0;
}

Utiliser std::for_each pour appliquer une opération à tous les éléments d'un conteneur

std::for_each prend une liste en entrée et applique une fonction personnalisée à chaque élément. C'est utile lorsque nous voulons effectuer la même opération sur chaque élément d'une liste.

Voici un exemple où nous utilisons std::for_each pour doubler tous les nombres d'un tableau :

#include <algorithm>
#include <array>
#include <iostream>

void doubleNumber(int& i)
{
    i *= 2;
}

int main()
{
    std::array arr{ 1, 2, 3, 4 };

    std::for_each(arr.begin(), arr.end(), doubleNumber);

    for (int i : arr)
    {
        std::cout << i << ' ';
    }

    std::cout << '\n';

    return 0;
}

Sortie


2 4 6 8

Pour les développeurs débutants, cet algorithme paraît souvent le plus inutile, car le code équivalent avec une boucle for basée sur un intervalle est plus court et plus simple. Pourtant, std::for_each présente certains avantages. Comparons std::for_each à une boucle for basée sur un intervalle.

std::ranges::for_each(arr, doubleNumber); // Depuis C++20, nous n'avons pas à utiliser begin() et end().
// std::for_each(arr.begin(), arr.end(), doubleNumber); // Avant C++20

for (auto& i : arr)
{
    doubleNumber(i);
}

Avec std::for_each, nos intentions sont claires : appeler doubleNumber avec chaque élément de arr. Dans la boucle for basée sur un intervalle, nous devons ajouter une nouvelle variable, i. Cela ouvre la porte à plusieurs erreurs qu'un programmeur peut commettre lorsqu'il est fatigué ou peu attentif. D'une part, il pourrait y avoir une conversion implicite si nous n'utilisons pas auto. Nous pourrions oublier l'esperluette, et doubleNumber n'affecterait alors pas le tableau. Nous pourrions aussi passer par erreur une variable autre que i à doubleNumber. Ces erreurs ne peuvent pas se produire avec std::for_each.

De plus, std::for_each peut ignorer des éléments au début ou à la fin d'un conteneur. Par exemple, pour ignorer le premier élément de arr, std::next peut être utilisé pour faire avancer begin vers l'élément suivant.

std::for_each(std::next(arr.begin()), arr.end(), doubleNumber);
// arr vaut maintenant [1, 4, 6, 8]. Le premier élément n'a pas été doublé.

Cela n'est pas possible avec une boucle for basée sur un intervalle.

Comme de nombreux algorithmes, std::for_each peut être parallélisé pour accélérer le traitement, ce qui le rend mieux adapté aux grands projets et aux volumes de données importants qu'une boucle for basée sur un intervalle.

Performance et ordre d'exécution

De nombreux algorithmes de la bibliothèque d'algorithmes garantissent un certain comportement quant à leur exécution. Il s'agit généralement de garanties de performance ou de garanties sur l'ordre dans lequel ils s'exécutent. Par exemple, std::for_each garantit que chaque élément ne sera accédé qu'une seule fois, et que les éléments seront accédés dans l'ordre séquentiel croissant.

Si la plupart des algorithmes offrent une certaine garantie de performance, peu d'entre eux garantissent l'ordre d'exécution. Pour ces algorithmes, nous devons veiller à ne pas faire d'hypothèses sur l'ordre dans lequel les éléments seront accédés ou traités.

Par exemple, si nous utilisions un algorithme de la bibliothèque standard pour multiplier la première valeur par 1, la deuxième par 2, la troisième par 3, etc., nous devrions éviter tout algorithme qui ne garantit pas un ordre d'exécution séquentiel croissant !

Les algorithmes suivants garantissent un ordre d'exécution séquentiel : std::for_each, std::copy, std::copy_backward, std::move et std::move_backward. De nombreux autres algorithmes (en particulier ceux qui utilisent un itérateur d'avance) sont implicitement séquentiels en raison de l'exigence de l'itérateur d'avance.

Bonne pratique

Avant d'utiliser un algorithme particulier, assurez-vous que les garanties de performance et d'ordre d'exécution conviennent à votre cas d'utilisation.

Intervalles (ranges) en C++20

Devoir passer explicitement arr.begin() et arr.end() à chaque algorithme est un peu fastidieux. Mais ne craignez rien : C++20 introduit les intervalles (ranges), qui nous permettent de simplement passer arr. Cela rendra notre code encore plus court et plus lisible.

Conclusion

La bibliothèque d'algorithmes offre une multitude de fonctionnalités utiles qui peuvent rendre votre code plus simple et plus robuste. Nous n'en avons présenté qu'un petit sous-ensemble dans cette leçon, mais comme la plupart de ces fonctions fonctionnent de manière très similaire, une fois que vous savez comment en utiliser quelques-unes, vous pourrez utiliser la plupart des autres.
