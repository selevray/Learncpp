Révision du chapitre

Le dérapage de périmètre (scope creep) se produit lorsque les fonctionnalités d'un projet dépassent ce qui était prévu au départ du projet ou de la phase concernée.

La vérification logicielle consiste à tester si le logiciel fonctionne comme prévu dans tous les cas. Un test unitaire (unit test) est un test conçu pour vérifier isolément une petite partie du code (généralement une fonction ou un appel) afin de s'assurer qu'un comportement particulier se produit comme prévu. Les frameworks de tests unitaires (unit test frameworks) peuvent vous aider à organiser vos tests unitaires. Le test d'intégration (integration testing) vérifie l'intégration de plusieurs unités ensemble, afin de s'assurer qu'elles fonctionnent correctement.

La couverture de code (code coverage) désigne la part du code source exécutée pendant les tests. La couverture des instructions (statement coverage) désigne le pourcentage d'instructions d'un programme qui ont été exécutées par les routines de test. La couverture des branches (branch coverage) désigne le pourcentage de branches qui ont été exécutées par les routines de test. La couverture des boucles (loop coverage, également appelée test 0, 1, 2) signifie que, si vous avez une boucle, vous devez vous assurer qu'elle fonctionne correctement lorsqu'elle itère 0 fois, 1 fois et 2 fois.

Le chemin heureux (happy path) est le chemin d'exécution qui se produit lorsqu'aucune erreur n'est rencontrée. Un chemin malheureux (sad path) est un chemin où survient une erreur ou un état d'échec. Une erreur non récupérable (non-recoverable error, également appelée erreur fatale, fatal error) est une erreur suffisamment grave pour que le programme ne puisse pas continuer à s'exécuter. Un programme qui gère bien les cas d'erreur est robuste.

Un tampon (buffer) est une zone de mémoire réservée pour stocker temporairement des données pendant qu'elles sont déplacées d'un endroit à un autre.

Le processus qui consiste à vérifier que la saisie utilisateur correspond à ce que le programme attend est appelé validation des entrées (input validation).

std::cerr est un flux de sortie (comme std::cout) conçu pour afficher les messages d'erreur.

Une précondition (precondition) est une condition qui doit toujours être vraie avant l'exécution d'un segment de code. Un invariant (invariant) est une condition qui doit être vraie pendant l'exécution d'un composant. Une postcondition (postcondition) est une condition qui doit toujours être vraie après l'exécution d'un code.

Une assertion (assertion) est une expression qui sera vraie à moins qu'il n'y ait un bogue dans le programme. En C++, les assertions à l'exécution sont généralement implémentées à l'aide de la macro de préprocesseur assert. Les assertions sont généralement désactivées dans le code non destiné au débogage. Une static_assert est une assertion évaluée à la compilation.

Les assertions doivent servir à documenter les cas logiquement impossibles. La gestion des erreurs doit servir à traiter les cas possibles.

Quiz

Question n° 1

Dans un quiz de la leçon 8.x -- Résumé du chapitre 8 et quiz, nous avons implémenté un jeu de Plus ou moins (Hi-Lo).

Mettez à jour votre solution précédente pour gérer les suppositions invalides (par exemple 'x'), les suppositions hors bornes (par exemple 0 ou 101), ainsi que les suppositions valides contenant des caractères superflus (par exemple 43x). Gérez également le cas où l'utilisateur saisit des caractères supplémentaires lorsque le jeu lui demande s'il veut rejouer.

Indice : écrivez une fonction séparée pour gérer la saisie de la supposition de l'utilisateur (avec la gestion d'erreurs associée).

Solution 
#include <iostream>
#include <limits>   // pour std::numeric_limits
#include "Random.h" // https://www.learncpp.com/cpp-tutorial/global-random-numbers-random-h/

int getGuess(int count, int min, int max)
{
    while (true) // boucle jusqu'à ce que l'utilisateur saisisse une entrée valide
    {
        std::cout << "Guess #" << count << ": ";

        int guess {};
        std::cin >> guess;

        bool success { std::cin };
        std::cin.clear(); // on revient au mode de fonctionnement « normal » (si nécessaire)
        std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n'); // supprime toute saisie superflue

        // Si rien n'a été extrait ou si la supposition extraite est hors bornes, on recommence
        if (!success || guess < min || guess > max)
            continue;

        return guess;
    }
}

// renvoie true si l'utilisateur a gagné, false s'il a perdu
bool playHiLo(int guesses, int min, int max)
{
    std::cout << "Let's play a game. I'm thinking of a number between " << min << " and " << max << ". You have " << guesses << " tries to guess what it is.\n";
    int number{ Random::get(min, max) }; // c'est le nombre que l'utilisateur doit deviner

    // Parcourt toutes les tentatives
    for (int count{ 1 }; count <= guesses; ++count)
    {
        int guess{ getGuess(count, min, max) };

        if (guess > number)
            std::cout << "Your guess is too high.\n";
        else if (guess < number)
            std::cout << "Your guess is too low.\n";
        else // guess == number, donc l'utilisateur a gagné
        {
            std::cout << "Correct! You win!\n";
            return true;
        }
    }

    // L'utilisateur a perdu
    std::cout << "Sorry, you lose. The correct number was " << number << '\n';
    return false; // si l'utilisateur a perdu
}

bool playAgain()
{
    // Redemande à l'utilisateur s'il veut rejouer jusqu'à ce qu'il choisisse y ou n.
    while (true)
    {
        char ch{};
        std::cout << "Would you like to play again (y/n)? ";
        std::cin >> ch;

        // supprime toute saisie superflue
        std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');

        switch (ch)
        {
        case 'y': return true;
        case 'n': return false;
        }
    }
}

int main()
{
    constexpr int guesses { 7 }; // l'utilisateur dispose de ce nombre de tentatives
    constexpr int min     { 1 };
    constexpr int max     { 100 };

    do
    {
        playHiLo(guesses, min, max);
    } while (playAgain());

    std::cout << "Thank you for playing.\n";

    return 0;
}
