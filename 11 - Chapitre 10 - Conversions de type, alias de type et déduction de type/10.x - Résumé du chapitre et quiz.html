Bravo d'être arrivé jusqu'ici. Les règles de conversion standard sont assez complexes : ne vous inquiétez pas si vous ne comprenez pas toutes les subtilités.

Résumé du chapitre

Le processus qui consiste à convertir une valeur d'un type de données vers un autre type de données s'appelle une conversion de type (type conversion).

La conversion de type implicite (aussi appelée conversion automatique de type ou coercition) est effectuée chaque fois qu'un type de données est attendu, mais qu'un type différent est fourni. Si le compilateur sait comment effectuer la conversion entre les deux types, il la réalise. Dans le cas contraire, la compilation échoue avec une erreur.

Le langage C++ définit un certain nombre de conversions intégrées entre ses types fondamentaux (ainsi que quelques conversions pour des types plus avancés), appelées conversions standard (standard conversions). Elles comprennent les promotions numériques, les conversions numériques et les conversions arithmétiques.

Une promotion numérique (numeric promotion) est la conversion de certains petits types numériques vers certains types plus grands (généralement int ou double), afin que le processeur puisse opérer sur des données correspondant à la taille naturelle de son architecture. Les promotions numériques comprennent les promotions entières (integral promotions) et les promotions en virgule flottante (floating-point promotions). Les promotions numériques sont préservatrices de valeur (value-preserving) : il n'y a aucune perte de valeur ni de précision. Toutes les conversions vers un type plus large ne sont pas des promotions.

Une conversion numérique (numeric conversion) est une conversion de type entre types fondamentaux qui n'est pas une promotion numérique. Une conversion restrictive (narrowing conversion) est une conversion numérique pouvant entraîner une perte de valeur ou de précision.

En C++, certains opérateurs binaires exigent que leurs opérandes soient du même type. Si des opérandes de types différents sont fournis, un ou les deux opérandes seront implicitement convertis vers des types identiques, selon un ensemble de règles appelé les conversions arithmétiques usuelles (usual arithmetic conversions).

La conversion de type explicite (explicit type conversion) est effectuée lorsque le programmeur demande explicitement une conversion au moyen d'un transtypage (cast). Un transtypage représente une demande explicite du programmeur d'effectuer une conversion de type. C++ prend en charge 5 types de transtypages : C-style casts, static casts, const casts, dynamic casts et reinterpret casts. En général, vous devriez éviter les C-style casts, les const casts et les reinterpret casts. static_cast sert à convertir une valeur d'un type vers une valeur d'un autre type ; c'est de loin le transtypage le plus utilisé en C++.

Les typedefs (définitions de type) et les alias de type (type aliases) permettent au programmeur de créer un synonyme pour un type de données. Ces alias ne sont pas de nouveaux types : ils se comportent exactement comme le type qu'ils désignent. Les typedefs et les alias de type n'apportent aucune sécurité de typage ; il faut veiller à ne pas supposer qu'un alias est différent du type qu'il désigne.

Le mot-clé auto a plusieurs usages. Tout d'abord, auto peut servir à la déduction de type (type deduction, aussi appelée type inference), qui déduit le type d'une variable à partir de son initialiseur. La déduction de type supprime les const et les références : pensez à les rajouter si vous en voulez.

auto peut aussi servir de type de retour de fonction, afin que le compilateur déduise le type de retour à partir des instructions return de la fonction, bien que cela doive être évité pour les fonctions ordinaires. auto est utilisé dans la syntaxe de retour en fin de déclaration (trailing return syntax).

Quiz

Question n° 1

Quel type de conversion se produit dans chacun des cas suivants ? Les réponses possibles sont : aucune conversion nécessaire, promotion numérique, conversion numérique, ne compile pas à cause d'une conversion restrictive. Supposez que int et long occupent tous deux 4 octets.

int main()
{
    int a { 5 }; // 1a
    int b { 'a' }; // 1b
    int c { 5.4 }; // 1c
    int d { true }; // 1d
    int e { static_cast<int>(5.4) }; // 1e

    double f { 5.0f }; // 1f
    double g { 5 }; // 1g

    // Section bonus
    long h { 5 }; // 1h

    float i { f }; // 1i (utilise la variable f définie précédemment)
    float j { 5.0 }; // 1j

}

1a)

Solution

Aucune conversion nécessaire

1b)

Solution

Promotion numérique du caractère 'a' en int

1c)

Solution

Ne compile pas à cause d'une conversion restrictive

1d)

Solution

Promotion numérique du booléen true en int

1e)

Solution

Conversion numérique du double 5.4 en int

1f)

Solution

Promotion numérique de float en double

1g)

Solution

Conversion numérique de int en double

1h)

Solution

Conversion numérique de int en long (cette conversion est triviale, mais c'est tout de même une conversion)

1i)

Solution

Ne compile pas à cause d'une conversion restrictive de double en float

1j)

Solution

Conversion numérique de double en float (cela est autorisé puisque 5.0 est constexpr et se trouve dans l'intervalle de float)

Question n° 2

2a) Mettez à jour le programme suivant pour utiliser des alias de type pour les valeurs en degrés et en radians :

#include <iostream>

namespace constants
{
    constexpr double pi { 3.14159 };
}

double convertToRadians(double degrees)
{
    return degrees * constants::pi / 180;
}

int main()
{
    std::cout << "Enter a number of degrees: ";
    double degrees{};
    std::cin >> degrees;

    double radians { convertToRadians(degrees) };
    std::cout << degrees << " degrees is " << radians << " radians.\n";

    return 0;
}
Solution 
#include <iostream>

namespace constants
{
    constexpr double pi{ 3.14159 };
}

using Degrees = double;
using Radians = double;

Radians convertToRadians(Degrees degrees)
{
    return degrees * constants::pi / 180;
}

int main()
{
    std::cout << "Enter a number of degrees: ";
    Degrees degrees{};
    std::cin >> degrees;

    Radians radians{ convertToRadians(degrees) };
    std::cout << degrees << " degrees is " << radians << " radians.\n";

    return 0;
}

2b) En reprenant les définitions de degrees et radians de la solution de la question précédente, expliquez pourquoi l'instruction suivante compile ou ne compile pas :

radians = degrees;
Solution

Elle compile. radians a pour type Radians, qui est un alias de double. degrees a pour type Degrees, qui est également un alias de double. Il s'agit donc simplement de l'affectation d'une valeur double à une variable de type double.
