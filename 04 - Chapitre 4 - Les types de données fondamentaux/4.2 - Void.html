4.2 — Void

Le type void est le plus simple à expliquer. En résumé, void signifie « aucun type » !

void est notre premier exemple de type incomplet (incomplete type). Un type incomplet est un type qui a été déclaré mais pas encore défini. Le compilateur connaît l'existence de tels types, mais ne dispose pas de suffisamment d'informations pour déterminer la quantité de mémoire à allouer pour les objets de ce type. void est volontairement incomplet, puisqu'il représente l'absence de type, et ne peut donc pas être défini.

Les types incomplets ne peuvent pas être instanciés :

void value; // ne fonctionne pas, une variable ne peut pas être définie avec le type incomplet void

void est typiquement utilisé dans plusieurs contextes différents.

Fonctions qui ne renvoient pas de valeur

Le plus souvent, void sert à indiquer qu'une fonction ne renvoie pas de valeur :

void writeValue(int x) // void ici signifie : pas de valeur de retour
{
    std::cout << "The value of x is: " << x << '\n';
    // pas d'instruction return, car cette fonction ne renvoie pas de valeur
}

Si vous utilisez une instruction return pour tenter de renvoyer une valeur depuis une telle fonction, cela produit une erreur de compilation :

void noReturn(int x) // void ici signifie : pas de valeur de retour
{
    std::cout << "The value of x is: " << x << '\n';

    return 5; // erreur
}

Sur Visual Studio 2017, cela produisait l'erreur :


error C2562: 'noReturn': 'void' function returning a value

Obsolète : fonctions sans paramètres

En C, void sert à indiquer qu'une fonction ne prend aucun paramètre :

int getValue(void) // void ici signifie : aucun paramètre
{
    int x{};
    std::cin >> x;

    return x;
}

Bien que ce code se compile en C++ (pour des raisons de compatibilité ascendante), cet usage du mot-clé void est considéré comme obsolète (deprecated) en C++. Le code suivant est équivalent et préféré en C++ :

int getValue() // une liste de paramètres vide équivaut à un void implicite
{
    int x{};
    std::cin >> x;

    return x;
}

Bonne pratique

Utilisez une liste de paramètres vide plutôt que void pour indiquer qu'une fonction n'a pas de paramètres.
