4.x — Résumé du chapitre et quiz

Résumé du chapitre

Le plus petit élément de mémoire est le chiffre binaire, aussi appelé bit. La plus petite quantité de mémoire pouvant être adressée (accédée) directement est l'octet (byte). La norme actuelle est qu'un octet vaut 8 bits.

Un type de données indique au compilateur comment interpréter le contenu de la mémoire d'une manière significative.

C++ fournit la prise en charge de nombreux types fondamentaux, notamment les nombres à virgule flottante, les entiers, les booléens, les caractères (char), les pointeurs nuls et void.

Void sert à indiquer l'absence de type. Il est principalement utilisé pour indiquer qu'une fonction ne renvoie pas de valeur.

Les différents types occupent des quantités de mémoire différentes, et cette quantité peut varier selon la machine.

Contenu associé

Consultez 4.3 -- Tailles des objets et opérateur sizeof pour un tableau indiquant la taille minimale de chaque type fondamental.

L'opérateur sizeof permet d'obtenir la taille d'un type, en octets.

Les entiers signés servent à représenter des nombres entiers positifs, négatifs et nul. L'ensemble des valeurs qu'un type de données donné peut contenir s'appelle son intervalle (range). Avec les entiers, faites attention aux dépassements de capacité (overflow) et aux problèmes de division entière.

Les entiers non signés ne contiennent que des nombres positifs (et 0). Il faut généralement les éviter, sauf pour manipuler des bits.

Les entiers de taille fixe sont des entiers dont la taille est garantie, mais ils peuvent ne pas exister sur toutes les architectures. Les entiers « rapides » (fast) et « minimaux » (least) sont les entiers les plus rapides et les plus petits ayant au moins une certaine taille. std::int8_t et std::uint8_t doivent généralement être évités, car ils se comportent souvent comme des char plutôt que comme des entiers.

size_t est un type entier non signé utilisé pour représenter la taille ou la longueur des objets.

La notation scientifique est une manière abrégée d'écrire des nombres longs. C++ la prend en charge avec les nombres à virgule flottante. Les chiffres de la mantisse (la partie située avant le e) sont appelés les chiffres significatifs.

Les nombres à virgule flottante (floating point) désignent un ensemble de types conçus pour représenter des nombres réels (y compris ceux ayant une partie fractionnaire). La précision d'un nombre définit le nombre de chiffres significatifs qu'il peut représenter sans perte d'information. Une erreur d'arrondi (rounding error) peut survenir lorsqu'on stocke, dans un nombre à virgule flottante, plus de chiffres significatifs que sa précision ne le permet. Les erreurs d'arrondi surviennent constamment, même avec des nombres simples comme 0.1. C'est pourquoi vous ne devez pas comparer directement des nombres à virgule flottante.

Le type booléen (Boolean) sert à stocker une valeur true ou false.

Les instructions if permettent d'exécuter une ou plusieurs lignes de code si une condition est vraie. L'expression conditionnelle d'une instruction if est interprétée comme une valeur booléenne. Une instruction else peut être utilisée pour exécuter une instruction lorsque la condition d'un if précédent est fausse.

Char sert à stocker des valeurs interprétées comme des caractères ASCII. Avec les char, veillez à ne pas confondre les codes ASCII et les nombres. Pour afficher un char sous forme de valeur entière, il faut utiliser static_cast.

Les chevrons (crochets angulaires) servent typiquement en C++ à représenter quelque chose qui nécessite un type paramétrable. Ils sont utilisés avec static_cast pour déterminer vers quel type de données l'argument doit être converti (par exemple, static_cast<int>(x) renvoie la valeur de x sous forme d'int).

Note de l'auteur

Les quiz deviennent plus difficiles à partir d'ici. Ceux qui vous demandent d'écrire un programme sont conçus pour vérifier que vous savez combiner plusieurs notions présentées dans les leçons. Prévoyez de passer du temps sur ces problèmes. Si vous débutez en programmation, ne vous attendez pas à pouvoir y répondre immédiatement.

Rappelez-vous que le but est de vous aider à identifier ce que vous maîtrisez et les notions qui demandent un travail supplémentaire. Si vous avez un peu de mal, ce n'est pas grave.

Voici quelques conseils :

  • N'essayez pas d'écrire toute la solution d'un coup. Écrivez une fonction, testez-la pour vous assurer qu'elle fonctionne comme prévu, puis continuez.
  • Utilisez votre débogueur pour repérer où les choses vont de travers.
  • Relisez les réponses des quiz des leçons précédentes du chapitre, car elles contiennent souvent des notions similaires.

Si vous êtes vraiment bloqué, n'hésitez pas à consulter la solution, mais prenez le temps de comprendre ce que fait chaque ligne avant de continuer. Tant que vous repartez en ayant compris les concepts, peu importe que vous ayez trouvé la solution seul ou que vous ayez dû la consulter.

Écrivez le programme suivant : on demande à l'utilisateur de saisir 2 nombres à virgule flottante (utilisez des double). Il doit ensuite saisir l'un des symboles mathématiques suivants : +, -, * ou /. Le programme calcule le résultat des deux nombres saisis et affiche le résultat. Si l'utilisateur saisit un symbole invalide, le programme n'affiche rien.

Exemple de programme :


Enter a double value: 6.2
Enter a double value: 5
Enter +, -, *, or /: *
6.2 * 5 is 31
Indice

Indice : écrivez trois fonctions : une pour obtenir une valeur double, une pour obtenir le symbole arithmétique, et une pour calculer et afficher le résultat.

Indice

Indice : utilisez des instructions if et operator== pour comparer la saisie de l'utilisateur au symbole arithmétique voulu.

Indice

Indice : envisagez un retour anticipé (early return), présenté dans la leçon 4.10 -- Introduction aux instructions if, si l'utilisateur ne fournit pas une opération prise en charge.

Solution 
#include <iostream>

double getDouble()
{
    std::cout << "Enter a double value: ";
    double x{};
    std::cin >> x;
    return x;
}

char getOperator()
{
    std::cout << "Enter +, -, *, or /: ";
    char operation{};
    std::cin >> operation;
    return operation;
}

void printResult(double x, char operation, double y)
{
    double result{};

    if (operation == '+')
        result = x + y;
    else if (operation == '-')
        result = x - y;
    else if (operation == '*')
        result = x * y;
    else if (operation == '/')
        result = x / y;
    else        // si l'utilisateur n'a pas fourni une opération prise en charge
        return; // retour anticipé

    std::cout << x << ' ' << operation << ' ' << y << " is " << result << '\n';
}

int main()
{
    double x { getDouble() };
    double y { getDouble() };

    char operation { getOperator() };

    printResult(x, operation, y);

    return 0;
}

Question n° 3

Exercice facultatif : celui-ci est un peu plus difficile.

Écrivez un court programme simulant la chute d'une balle lâchée du sommet d'une tour. Pour commencer, demandez à l'utilisateur la hauteur de la tour en mètres. Supposez la pesanteur normale (9,8 m/s²) et que la balle n'a pas de vitesse initiale (elle ne bouge pas au départ). Le programme doit afficher la hauteur de la balle au-dessus du sol après 0, 1, 2, 3, 4 et 5 secondes. La balle ne doit pas passer sous le sol (hauteur 0).

Utilisez une fonction pour calculer la hauteur de la balle après x secondes. La fonction peut calculer la distance parcourue par la balle après x secondes avec la formule suivante : distance parcourue = constante_gravitationnelle * x_secondes² / 2

Résultat attendu :


Enter the height of the tower in meters: 100
At 0 seconds, the ball is at height: 100 meters
At 1 seconds, the ball is at height: 95.1 meters
At 2 seconds, the ball is at height: 80.4 meters
At 3 seconds, the ball is at height: 55.9 meters
At 4 seconds, the ball is at height: 21.6 meters
At 5 seconds, the ball is on the ground.

Remarque : selon la hauteur de la tour, la balle peut ne pas atteindre le sol en 5 secondes, ce n'est pas grave. Nous améliorerons ce programme une fois les boucles étudiées. Remarque : le symbole ^ n'est pas un exposant en C++. Implémentez la formule avec des multiplications plutôt qu'avec une exponentiation. Remarque : pensez à utiliser des littéraux double pour les double, par exemple 2.0 plutôt que 2.

Solution 
#include <iostream>

// Récupère la hauteur de la tour auprès de l'utilisateur et la renvoie
double getTowerHeight()
{
    std::cout << "Enter the height of the tower in meters: ";
    double towerHeight{};
    std::cin >> towerHeight;
    return towerHeight;
}

// Renvoie la hauteur actuelle de la balle après "seconds" secondes
double calculateBallHeight(double towerHeight, int seconds)
{
    double gravity { 9.8 };

    // Formule utilisée : s = (u * t) + (a * t^2) / 2
    // ici u (vitesse initiale) = 0, donc (u * t) = 0
    double fallDistance { gravity * (seconds * seconds) / 2.0 };
    double ballHeight { towerHeight - fallDistance };

    // Si la balle serait sous le sol, on la place au sol
    if (ballHeight < 0.0)
        return 0.0;

    return ballHeight;
}

// Affiche la hauteur de la balle au-dessus du sol
void printBallHeight(double ballHeight, int seconds)
{
    if (ballHeight > 0.0)
        std::cout << "At " << seconds << " seconds, the ball is at height: " << ballHeight << " meters\n";
    else
        std::cout << "At " << seconds << " seconds, the ball is on the ground.\n";
}

// Calcule la hauteur actuelle de la balle puis l'affiche
// C'est une fonction auxiliaire qui rend cette opération plus facile à lire
void calculateAndPrintBallHeight(double towerHeight, int seconds)
{
    double ballHeight{ calculateBallHeight(towerHeight, seconds) };
    printBallHeight(ballHeight, seconds);
}

int main()
{
    double towerHeight{ getTowerHeight() };

    calculateAndPrintBallHeight(towerHeight, 0);
    calculateAndPrintBallHeight(towerHeight, 1);
    calculateAndPrintBallHeight(towerHeight, 2);
    calculateAndPrintBallHeight(towerHeight, 3);
    calculateAndPrintBallHeight(towerHeight, 4);
    calculateAndPrintBallHeight(towerHeight, 5);

    return 0;
}

Pour ce programme, nous avons 3 tâches : obtenir la hauteur initiale de la tour, calculer la hauteur actuelle de la balle et afficher cette hauteur. Selon la bonne pratique qui veut qu'une fonction ne fasse qu'une seule chose, nous avons une fonction distincte pour chacune de ces tâches. calculateAndPrintBallHeight() est une fonction auxiliaire qui rend le calcul et l'affichage plus lisibles lorsqu'elle est appelée depuis main().
