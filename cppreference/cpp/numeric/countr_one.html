std::countr_one

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <bit>

template< class T >
constexpr int countr_one( T x ) noexcept;  // (depuis C++20)

Renvoie le nombre de bits consécutifs 1 dans la valeur de x, à partir du bit de poids faible (« droite »).

Cette surcharge participe à la résolution de surcharge uniquement si T est un type entier non signé (c'est-à-dire unsigned char, unsigned short, unsigned int, unsigned long, unsigned long long, ou un type entier non signé étendu).

Paramètres

  • x — valeur de type entier non signé

Valeur de retour

Le nombre de bits consécutifs 1 dans la valeur de x, à partir du bit de poids faible.

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_bitops 201907L (C++20) Opérations sur les bits

Exemple

#include <bit>
#include <bitset>
#include <cstdint>
#include <iostream>

int main()
{
    for (const std::uint8_t i : {0, 0b11111111, 0b11111110, 0b11100011})
        std::cout << "countr_one( " << std::bitset<8>(i) << " ) = "
                  << std::countr_one(i) << '\n';
}

Output:

countr_one( 00000000 ) = 0
countr_one( 11111111 ) = 8
countr_one( 11111110 ) = 0
countr_one( 11100011 ) = 2
