std::bit_ceil

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <bit>

template< class T >
constexpr T bit_ceil( T x );  // (depuis C++20)

Calcule la plus petite puissance entière de deux qui ne soit pas inférieure à x.

Si cette valeur n'est pas représentable dans T, le comportement est indéfini. L'appel de cette fonction est autorisé dans l'évaluation constante uniquement si le comportement indéfini ne se produit pas.

Cette surcharge participe à la résolution de surcharge uniquement si T est un type entier non signé (c'est-à-dire unsigned char, unsigned short, unsigned int, unsigned long, unsigned long long, ou un type entier non signé étendu).

Paramètres

  • x — valeur de type entier non signé

Valeur de retour

La plus petite puissance entière de deux qui ne soit pas inférieure à x.

Exceptions

Ne lève aucune exception.

Notes

Avant P1956R1, le nom proposé pour ce modèle de fonction était ceil2.

Implémentation possible

Voir les implémentations possibles dans libstdc++ (gcc) et libc++ (clang).

template<std::unsigned_integral T>
    requires !std::same_as<T, bool> && !std::same_as<T, char> &&
             !std::same_as<T, char8_t> && !std::same_as<T, char16_t> &&
             !std::same_as<T, char32_t> && !std::same_as<T, wchar_t>
constexpr T bit_ceil(T x) noexcept
{
    if (x <= 1u)
        return T(1);
    if constexpr (std::same_as<T, decltype(+x)>)
        return T(1) << std::bit_width(T(x - 1));
    else
    {   // pour les types soumis à la promotion entière
        constexpr int offset_for_ub =
            std::numeric_limits<unsigned>::digits - std::numeric_limits<T>::digits;
        return T(1u << (std::bit_width(T(x - 1)) + offset_for_ub) >> offset_for_ub);
    }
}

Exemple

#include <bit>
#include <bitset>
#include <iostream>

int main()
{
    using bin = std::bitset<8>;
    for (auto x{0U}; 0XA != x; ++x)
        std::cout << "bit_ceil( " << bin(x) << " ) = "
                  << bin(std::bit_ceil(x)) << '\n';
}
