template< class T, class Abi = /*native-abi*/<T> >
class basic_simd;  // (1) (depuis C++26)

template< class T, /*simd-size-type*/ N = /*simd-size-v*/<T, /*native-abi*/<T>> >
using simd = basic_simd<T, /*deduce-abi-t*/<T, N>>;  // (2) (depuis C++26)

La spécialisation 1) std::basic_simd est un type à parallélisme de données. Le tag ABI par défaut est déterminé par l'implémentation à la compilation.

  1. std::simd est un modèle d'alias qui permet aux utilisateurs de spécifier la largeur à une taille donnée. La largeur par défaut est déterminée par l'implémentation à la compilation.

Chaque spécialisation de basic_simd est un type complet. La spécialisation est

  • activée, si T est un type vectorisable, et s'il existe une valeur M dans l'intervalle [1,64] telle que Abi soit deduce-abi-t<T, M>,
  • sinon désactivée, si T n'est pas un type vectorisable,
  • sinon, il est défini par l'implémentation si une telle spécialisation est activée.

Si basic_simd<T, Abi> est désactivée, la spécialisation a tous ses constructeur par défaut, destructeur, constructeur de copie et opérateur d'affectation par copie supprimés. En outre, seuls les types membres ci-dessous sont présents.

Si basic_simd<T, Abi> est activée, basic_simd<T, Abi> est TriviallyCopyable.

  • Abi — type d'étiquette utilisé pour déterminer la largeur et le stockage
  • N — la largeur du type à parallélisme de données ; le nombre d'éléments

Guide de déduction

template< class R, class... Ts >
basic_simd( R&& r, Ts... ) -> /* voir ci-dessous */;  // (depuis C++26)

Le guide de déduction n'est présent que si :

  • R modélise contiguous_range et sized_range, et
  • ranges::size(r) est une expression constante.

Le type déduit est équivalent à std::simd<ranges::range_value_t<R>, ranges::size(r)>.

Notes

Il est recommandé aux implémentations de prendre en charge les conversions explicites entre les spécialisations activées de basic_simd et les types appropriés définis par l'implémentation. Ces types appropriés sont des types vectoriels non standard disponibles dans l'implémentation.
