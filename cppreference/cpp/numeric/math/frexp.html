Défini dans l'en-tête <cmath>

template< class Integer >
double      frexp ( Integer num, int* exp );  // (A) (constexpr depuis C++23)

1-3) Décompose la valeur à virgule flottante num donnée en une fraction normalisée et un exposant entier de base deux.La bibliothèque fournit des surcharges de std::frexp pour tous les types à virgule flottante non qualifiés cv comme type du paramètre num. (depuis C++23)

A) Des surcharges supplémentaires sont fournies pour tous les types entiers, qui sont traités comme double.

(depuis C++11)

Paramètres

  • num — valeur à virgule flottante ou entière
  • exp — pointeur vers la valeur entière où stocker l'exposant

Valeur de retour

Si num vaut zéro, renvoie zéro et stocke zéro dans *exp.

Sinon (si num n'est pas nul), si aucune erreur ne se produit, renvoie la valeur x dans l'intervalle (-1, -0.5], [0.5, 1) et stocke une valeur entière dans *exp telle que x×2(*exp)
== num.

Si la valeur à stocker dans *exp est en dehors de l'intervalle de int, le comportement est non spécifié.

Gestion des erreurs

Cette fonction n'est soumise à aucune des erreurs spécifiées dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si num vaut ±0, il est renvoyé sans modification, et 0 est stocké dans *exp.
  • Si num vaut ±∞, il est renvoyé, et une valeur non spécifiée est stockée dans *exp.
  • Si num est NaN, NaN est renvoyé, et une valeur non spécifiée est stockée dans *exp.
  • Aucune exception à virgule flottante n'est levée.
  • Si FLT_RADIX vaut 2 (ou une puissance de 2), la valeur renvoyée est exacte, le mode d'arrondi courant est ignoré.

Notes

Sur un système binaire (où FLT_RADIX vaut 2), std::frexp peut être implémentée comme

{
    *exp = (value == 0) ? 0 : (int)(1 + std::logb(value));
    return std::scalbn(value, -(*exp));
}

La fonction std::frexp, ainsi que sa duale, std::ldexp, peut être utilisée pour manipuler la représentation d'un nombre à virgule flottante sans manipulation directe de bits.

Les surcharges supplémentaires ne sont pas tenues d'être fournies exactement comme (A). Elles doivent seulement suffire à garantir que pour leur argument num de type entier, std::frexp(num, exp) a le même effet que std::frexp(static_cast<double>(num), exp).

Exemple

Compare différentes fonctions de décomposition des nombres à virgule flottante :

#include <cmath>
#include <iostream>
#include <limits>

int main()
{
    double f = 123.45;
    std::cout << "Given the number " << f << " or " << std::hexfloat
              << f << std::defaultfloat << " in hex,\n";

    double f3;
    double f2 = std::modf(f, &f3);
    std::cout << "modf() makes " << f3 << " + " << f2 << '\n';

    int i;
    f2 = std::frexp(f, &i);
    std::cout << "frexp() makes " << f2 << " * 2^" << i << '\n';

    i = std::ilogb(f);
    std::cout << "logb()/ilogb() make " << f / std::scalbn(1.0, i)
              << " * " << std::numeric_limits<double>::radix
              << "^" << std::ilogb(f) << '\n';
}

Sortie possible :

Given the number 123.45 or 0x1.edccccccccccdp+6 in hex,
modf() makes 123 + 0.45
frexp() makes 0.964453 * 2^7
logb()/ilogb() make 1.92891 * 2^6
