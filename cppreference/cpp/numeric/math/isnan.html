Surcharges supplémentaires

Défini dans l'en-tête <cmath>

template< class Integer >
bool isnan( Integer num );  // (A) (depuis C++11) (constexpr depuis C++23)
  1. Détermine si le nombre à virgule flottante num donné est une valeur NaN (not-a-number).La bibliothèque fournit des surcharges pour tous les types à virgule flottante non qualifiés cv comme type du paramètre num. (depuis C++23)

S) La surcharge SIMD effectue un std::isnan élément par élément sur v_num.

(Voir math-floating-point et deduced-simd-t pour leurs définitions.)

(depuis C++26)

A) Des surcharges supplémentaires sont fournies pour tous les types entiers, qui sont traités comme double.

Paramètres

  • num — valeur à virgule flottante ou entière
  • v_num — un objet data-parallel de spécialisation std::basic_simd dont le type d'élément est un type à virgule flottante

Valeur de retour

  1. true si num est un NaN, false sinon.

S) Un objet masque data-parallel dont le ie élément vaut true si v_num[i] est un NaN, false sinon, pour tout i de l'intervalle [0,v_num.size()).

Notes

Il existe de nombreuses valeurs NaN différentes, avec des bits de signe et des charges utiles différents, voir std::nan et std::numeric_limits::quiet_NaN.

Les valeurs NaN ne sont jamais égales à elles-mêmes ni à d'autres valeurs NaN. Selon IEEE-754, la copie d'un NaN n'est pas tenue de préserver sa représentation binaire (signe et charge utile), bien que la plupart des implémentations le fassent.

Une autre façon de tester si une valeur à virgule flottante est NaN consiste à la comparer à elle-même : bool is_nan(double x) { return x != x; }.

GCC et Clang prennent en charge une option -ffinite-math (également impliquée par -ffast-math), qui permet au compilateur correspondant de supposer l'inexistence de valeurs flottantes IEEE-754 particulières telles que NaN, l'infini ou le zéro négatif. Autrement dit, std::isnan est supposée renvoyer toujours false avec cette option.

Les surcharges supplémentaires ne sont pas tenues d'être fournies exactement comme (A). Elles doivent seulement suffire à garantir que pour leur argument num de type entier, std::isnan(num) a le même effet que std::isnan(static_cast<double>(num)).

Exemple

#include <cfloat>
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::boolalpha
              << "isnan(NaN) = " << std::isnan(NAN) << '\n'
              << "isnan(Inf) = " << std::isnan(INFINITY) << '\n'
              << "isnan(0.0) = " << std::isnan(0.0) << '\n'
              << "isnan(DBL_MIN/2.0) = " << std::isnan(DBL_MIN / 2.0) << '\n'
              << "isnan(0.0 / 0.0)   = " << std::isnan(0.0 / 0.0) << '\n'
              << "isnan(Inf - Inf)   = " << std::isnan(INFINITY - INFINITY) << '\n';
}

Output:

isnan(NaN) = true
isnan(Inf) = false
isnan(0.0) = false
isnan(DBL_MIN/2.0) = false
isnan(0.0 / 0.0)   = true
isnan(Inf - Inf)   = true
