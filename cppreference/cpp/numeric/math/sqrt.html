Paramètres

  • num — valeur à virgule flottante ou entière

Valeur de retour

Si aucune erreur ne se produit, la racine carrée de num (({\small \sqrt{num} })√num) est renvoyée.

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Une erreur de domaine se produit si num est inférieur à zéro.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si l'argument est inférieur à -0, FE_INVALID est levée et NaN est renvoyé.
  • Si l'argument vaut +∞ ou ±0, il est renvoyé sans modification.
  • Si l'argument est NaN, NaN est retourné.

Notes

std::sqrt est requise par la norme IEEE d'être correctement arrondie à partir du résultat en précision infinie. En particulier, le résultat exact est produit s'il peut être représenté dans le type à virgule flottante. Les seules autres opérations qui l'exigent sont les opérateurs arithmétiques et la fonction std::fma. Les autres fonctions, y compris std::pow, ne sont pas soumises à cette contrainte.

Les surcharges supplémentaires ne sont pas tenues d'être fournies exactement comme (A). Elles doivent seulement suffire à garantir que pour leur argument num de type entier, std::sqrt(num) a le même effet que std::sqrt(static_cast<double>(num)).

Exemple

#include <cerrno>
#include <cfenv>
#include <cmath>
#include <cstring>
#include <iostream>
// #pragma STDC FENV_ACCESS ON

int main()
{
    // utilisation normale
    std::cout << "sqrt(100) = " << std::sqrt(100) << '\n'
              << "sqrt(2) = " << std::sqrt(2) << '\n'
              << "golden ratio = " << (1 + std::sqrt(5)) / 2 << '\n';

    // valeurs spéciales
    std::cout << "sqrt(-0) = " << std::sqrt(-0.0) << '\n';

    // gestion des erreurs
    errno = 0;
    std::feclearexcept(FE_ALL_EXCEPT);

    std::cout << "sqrt(-1.0) = " << std::sqrt(-1) << '\n';
    if (errno == EDOM)
        std::cout << "    errno = EDOM " << std::strerror(errno) << '\n';
    if (std::fetestexcept(FE_INVALID))
        std::cout << "    FE_INVALID raised\n";
}
