Surcharges supplémentaires

Défini dans l'en-tête <cmath>

template< class Integer >
bool signbit( Integer num );  // (A) (depuis C++11) (constexpr depuis C++23)
  1. Détermine si le nombre à virgule flottante donné num est négatif.La bibliothèque fournit des surcharges pour tous les types à virgule flottante non qualifiés cv comme type du paramètre num. (depuis C++23)

S) La surcharge SIMD effectue un std::signbit élément par élément sur v_num.

(Voir math-floating-point et deduced-simd-t pour leurs définitions.)

(depuis C++26)

A) Des surcharges supplémentaires sont fournies pour tous les types entiers, qui sont traités comme double.

Paramètres

  • num — valeur à virgule flottante ou entière
  • v_num — un objet data-parallel de spécialisation std::basic_simd dont le type d'élément est un type à virgule flottante

Valeur de retour

  1. true si num est négative, false sinon.

S) Un objet masque de parallélisme de données dont le i-ème élément vaut true si v_num[i] est négatif, ou false sinon, pour tout i dans l'intervalle [0,v_num.size()).

Notes

Cette fonction détecte le bit de signe des zéros, des infinis et des NaN. Avec std::copysign, std::signbit est l'un des deux seuls moyens portables d'examiner le signe d'un NaN.

Les surcharges supplémentaires ne sont pas tenues d'être fournies exactement comme (A). Elles doivent seulement suffire à garantir que pour leur argument num de type entier, std::signbit(num) a le même effet que std::signbit(static_cast<double>(num)).

Exemple

#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::boolalpha
              << "signbit(+0.0) = " << std::signbit(+0.0) << '\n'
              << "signbit(-0.0) = " << std::signbit(-0.0) << '\n'
              << "signbit(+nan) = " << std::signbit(+NAN) << '\n'
              << "signbit(-nan) = " << std::signbit(-NAN) << '\n'
              << "signbit(+inf) = " << std::signbit(+INFINITY) << '\n'
              << "signbit(-inf) = " << std::signbit(-INFINITY) << '\n';
}

Output:

signbit(+0.0) = false
signbit(-0.0) = true
signbit(+nan) = false
signbit(-nan) = true
signbit(+inf) = false
signbit(-inf) = true
