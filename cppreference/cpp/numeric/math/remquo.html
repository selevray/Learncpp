Surcharges supplémentaires

Défini dans l'en-tête <cmath>

template< class Arithmetic1, class Arithmetic2 >
/* type à virgule flottante commun */
    remquo( Arithmetic1 x, Arithmetic2 y, int* quo );  // (A) (depuis C++11) (constexpr depuis C++23)

1-3) Calcule le reste en virgule flottante de l'opération de division x / y comme le fait la fonction std::remainder(). De plus, le signe et au moins les trois derniers bits de poids faible de x / y seront stockés dans quo, suffisants pour déterminer l'octant du résultat au sein d'une période.La bibliothèque fournit des surcharges de std::remquo pour tous les types à virgule flottante non qualifiés cv, comme type des paramètres x et y. (depuis C++23)

A) Des surcharges supplémentaires sont fournies pour toutes les autres combinaisons de types arithmétiques.

Paramètres

  • x, y — valeurs à virgule flottante ou entières
  • quo — pointeur vers int pour stocker le signe et quelques bits de x / y

Valeur de retour

En cas de succès, retourne le reste en virgule flottante de la division x / y tel que défini dans std::remainder, et stocke, dans *quo, le signe et au moins trois des bits de poids faible de x / y (formellement, stocke une valeur dont le signe est celui de x / y et dont la magnitude est congrue modulo 2n
à la magnitude du quotient entier de x / y, où n est un entier défini par l'implémentation supérieur ou égal à 3).

Si y est nul, la valeur stockée dans *quo est non spécifiée.

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur de portée se produit par sous-dépassement, le résultat correct est retourné si les subnormaux sont supportés.

Si y est nul, mais que l'erreur de domaine ne se produit pas, zéro est retourné.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Une erreur de domaine peut se produire si y vaut zéro.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Le mode d'arrondi courant n'a aucun effet.
  • FE_INEXACT n'est jamais levée.
  • Si x vaut ±∞ et y n'est pas NaN, NaN est renvoyé et FE_INVALID est levé.
  • Si y vaut ±0 et x n'est pas NaN, NaN est renvoyé et FE_INVALID est levé.
  • Si x ou y est NaN, NaN est retourné.

Notes

POSIX exige qu'une erreur de domaine se produise si x est infini ou si y vaut zéro.

Cette fonction est utile pour implémenter des fonctions périodiques lorsque la période est exactement représentable en virgule flottante : lors du calcul de sin(πx) pour un x très grand, appeler std::sin directement peut entraîner une grande erreur, mais si l'argument de la fonction est d'abord réduit avec std::remquo, les bits de poids faible du quotient peuvent servir à déterminer le signe et l'octant du résultat au sein de la période, tandis que le reste peut servir à calculer la valeur avec une grande précision.

Sur certaines plateformes, cette opération est prise en charge par le matériel (et, par exemple, sur les processeurs Intel, FPREM1 laisse exactement 3 bits de précision dans le quotient une fois terminée).

Les surcharges supplémentaires ne sont pas tenues d'être fournies exactement comme (A). Il suffit qu'elles soient suffisantes pour garantir que, pour leur premier argument num1 et second argument num2 :

  • Si num1 ou num2 est de type long double, alors std::remquo(num1, num2, quo) a le même effet que std::remquo(static_cast<long double>(num1), static_cast<long double>(num2), quo).
  • Sinon, si num1 et/ou num2 est de type double ou de type entier, alors std::remquo(num1, num2, quo) a le même effet que std::remquo(static_cast<double>(num1), static_cast<double>(num2), quo).
  • Sinon, si num1 ou num2 est de type float, alors std::remquo(num1, num2, quo) a le même effet que std::remquo(static_cast<float>(num1), static_cast<float>(num2), quo).

(jusqu'à C++23)

Si num1 et num2 ont des types arithmétiques, alors std::remquo(num1, num2, quo) a le même effet que std::remquo(static_cast</*type à virgule flottante commun*/>(num1), static_cast</*type à virgule flottante commun*/>(num2), quo), où /*type à virgule flottante commun*/ est le type à virgule flottante ayant le plus grand rang de conversion en virgule flottante et le plus grand sous-rang de conversion en virgule flottante parmi les types de num1 et num2 ; les arguments de type entier sont considérés comme ayant le même rang de conversion en virgule flottante que double.

S'il n'existe aucun type à virgule flottante ayant le plus grand rang et sous-rang, alors la résolution de surcharge ne donne aucun candidat utilisable parmi les surcharges fournies.

(depuis C++23)

Exemple

#include <cfenv>
#include <cmath>
#include <iostream>

#ifndef __GNUC__
#pragma STDC FENV_ACCESS ON
#endif

const double pi = std::acos(-1); // ou std::numbers::pi depuis C++20

double cos_pi_x_naive(double x)
{
    return std::cos(pi * x);
}

// la période est 2, les valeurs sont (0;0.5) positives, (0.5;1.5) négatives, (1.5,2) positives
double cos_pi_x_smart(double x)
{
    int quadrant;
    double rem = std::remquo(x, 1, &quadrant);
    quadrant = static_cast<unsigned>(quadrant) % 2; // La période est 2.
    return quadrant == 0 ?  std::cos(pi * rem)
                         : -std::cos(pi * rem);
}

int main()
{
    std::cout << std::showpos
              << "naive:\n"
              << "  cos(pi * 0.25) = " << cos_pi_x_naive(0.25) << '\n'
              << "  cos(pi * 1.25) = " << cos_pi_x_naive(1.25) << '\n'
              << "  cos(pi * 2.25) = " << cos_pi_x_naive(2.25) << '\n'
              << "smart:\n"
              << "  cos(pi * 0.25) = " << cos_pi_x_smart(0.25) << '\n'
              << "  cos(pi * 1.25) = " << cos_pi_x_smart(1.25) << '\n'
              << "  cos(pi * 2.25) = " << cos_pi_x_smart(2.25) << '\n'
              << "naive:\n"
              << "  cos(pi * 1000000000000.25) = "
              << cos_pi_x_naive(1000000000000.25) << '\n'
              << "  cos(pi * 1000000000001.25) = "
              << cos_pi_x_naive(1000000000001.25) << '\n'
              << "smart:\n"
              << "  cos(pi * 1000000000000.25) = "
              << cos_pi_x_smart(1000000000000.25) << '\n'
              << "  cos(pi * 1000000000001.25) = "
              << cos_pi_x_smart(1000000000001.25) << '\n';

    // gestion des erreurs
    std::feclearexcept(FE_ALL_EXCEPT);

    int quo;
    std::cout << "remquo(+Inf, 1) = " << std::remquo(INFINITY, 1, &quo) << '\n';
    if (fetestexcept(FE_INVALID))
        std::cout << "  FE_INVALID raised\n";
}
