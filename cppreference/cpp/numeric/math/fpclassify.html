std::fpclassify

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cmath>

int fpclassify( float num );
int fpclassify( double num );
int fpclassify( long double num );  // (depuis C++11) (jusqu'à C++23)

constexpr int fpclassify( /* type à virgule flottante */ num );  // (depuis C++23)

Surcharges supplémentaires

Défini dans l'en-tête <cmath>

template< class Integer >
int fpclassify( Integer num );  // (A) (depuis C++11) (constexpr depuis C++23)
  1. Catégorise une valeur à virgule flottante num dans les catégories suivantes : zéro, subnormale, normale, infinie, NAN, ou catégorie définie par l'implémentation.La bibliothèque fournit des surcharges de std::fpclassify pour tous les types à virgule flottante non qualifiés cv comme type du paramètre num. (depuis C++23)

A) Des surcharges supplémentaires sont fournies pour tous les types entiers, qui sont traités comme double.

Paramètres

  • num — valeur à virgule flottante ou entière

Valeur de retour

l'une de FP_INFINITE, FP_NAN, FP_NORMAL, FP_SUBNORMAL, FP_ZERO ou un type défini par l'implémentation, indiquant la catégorie de num.

Notes

Les surcharges supplémentaires ne sont pas tenues d'être fournies exactement comme (A). Elles doivent seulement suffire à garantir que pour leur argument num de type entier, std::fpclassify(num) a le même effet que std::fpclassify(static_cast<double>(num)).

Exemple

#include <cfloat>
#include <cmath>
#include <iostream>

auto show_classification(double x)
{
    switch (std::fpclassify(x))
    {
        case FP_INFINITE:
            return "Inf";
        case FP_NAN:
            return "NaN";
        case FP_NORMAL:
            return "normal";
        case FP_SUBNORMAL:
            return "subnormal";
        case FP_ZERO:
            return "zero";
        default:
            return "unknown";
    }
}

int main()
{
    std::cout << "1.0/0.0 is " << show_classification(1 / 0.0) << '\n'
              << "0.0/0.0 is " << show_classification(0.0 / 0.0) << '\n'
              << "DBL_MIN/2 is " << show_classification(DBL_MIN / 2) << '\n'
              << "-0.0 is " << show_classification(-0.0) << '\n'
              << "1.0 is " << show_classification(1.0) << '\n';
}

Output:

1.0/0.0 is Inf
0.0/0.0 is NaN
DBL_MIN/2 is subnormal
-0.0 is zero
1.0 is normal
