Défini dans l'en-tête <cmath>

template< class Integer >
double      modf ( Integer num, double* iptr );  // (A) (constexpr depuis C++23)

1-3) Décompose la valeur à virgule flottante donnée num en parties entière et fractionnaire, chacune ayant le même type et le même signe que num. La partie entière (au format à virgule flottante) est stockée dans l'objet pointé par iptr.La bibliothèque fournit des surcharges de std::modf pour tous les types à virgule flottante non qualifiés cv comme type du paramètre num et comme type pointé de iptr. (depuis C++23)

A) Des surcharges supplémentaires sont fournies pour tous les types entiers, qui sont traités comme double.

(depuis C++11)

Paramètres

  • num — valeur à virgule flottante ou entière
  • iptr — pointeur vers la valeur à virgule flottante où stocker la partie entière

Valeur de retour

Si aucune erreur ne se produit, renvoie la partie fractionnaire de num avec le même signe que num. La partie entière est placée dans la valeur pointée par iptr.

La somme de la valeur renvoyée et de la valeur stockée dans *iptr donne num (à l'arrondi près).

Gestion des erreurs

Cette fonction n'est soumise à aucune des erreurs spécifiées dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si num vaut ±0, ±0 est renvoyé, et ±0 est stocké dans *iptr.
  • Si num vaut ±∞, ±0 est renvoyé, et ±∞ est stocké dans *iptr.
  • Si num est NaN, NaN est renvoyé, et NaN est stocké dans *iptr.
  • La valeur renvoyée est exacte, le mode d'arrondi courant est ignoré.

Notes

Cette fonction se comporte comme si elle était implémentée ainsi :

double modf(double num, double* iptr)
{
#pragma STDC FENV_ACCESS ON
    int save_round = std::fegetround();
    std::fesetround(FE_TOWARDZERO);
    *iptr = std::nearbyint(num);
    std::fesetround(save_round);
    return std::copysign(std::isinf(num) ? 0.0 : num - (*iptr), num);
}

Les surcharges supplémentaires ne sont pas tenues d'être fournies exactement comme (A). Elles doivent seulement suffire à garantir que pour leur argument num de type entier, std::modf(num, iptr) a le même effet que std::modf(static_cast<double>(num), iptr).

Exemple

Compare différentes fonctions de décomposition des nombres à virgule flottante :

#include <cmath>
#include <iostream>
#include <limits>

int main()
{
    double f = 123.45;
    std::cout << "Given the number " << f << " or " << std::hexfloat
              << f << std::defaultfloat << " in hex,\n";

    double f3;
    double f2 = std::modf(f, &f3);
    std::cout << "modf() makes " << f3 << " + " << f2 << '\n';

    int i;
    f2 = std::frexp(f, &i);
    std::cout << "frexp() makes " << f2 << " * 2^" << i << '\n';

    i = std::ilogb(f);
    std::cout << "logb()/ilogb() make " << f / std::scalbn(1.0, i) << " * "
              << std::numeric_limits<double>::radix
              << "^" << std::ilogb(f) << '\n';

    // valeurs spéciales
    f2 = std::modf(-0.0, &f3);
    std::cout << "modf(-0) makes " << f3 << " + " << f2 << '\n';
    f2 = std::modf(-INFINITY, &f3);
    std::cout << "modf(-Inf) makes " << f3 << " + " << f2 << '\n';
}

Sortie possible :

Given the number 123.45 or 0x1.edccccccccccdp+6 in hex,
modf() makes 123 + 0.45
frexp() makes 0.964453 * 2^7
logb()/ilogb() make 1.92891 * 2^6
modf(-0) makes -0 + -0
modf(-Inf) makes -INF + -0
