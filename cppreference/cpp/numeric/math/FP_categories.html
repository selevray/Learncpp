FP_NORMAL, FP_SUBNORMAL, FP_ZERO, FP_INFINITE, FP_NAN

#define FP_INFINITE  /* implementation defined */  // (depuis C++11)

#define FP_NAN       /* implementation defined */  // (depuis C++11)

Les macros FP_NORMAL, FP_SUBNORMAL, FP_ZERO, FP_INFINITE, FP_NAN représentent chacune une catégorie distincte de nombres à virgule flottante. Elles se développent toutes en expression constante entière.

Constante Explication

  • FP_NORMAL — indique que la valeur est normale, c'est-à-dire ni infinie, ni sous-normale, ni non-nombre (NaN), ni nulle
  • FP_SUBNORMAL — indique que la valeur est sous-normale
  • FP_ZERO — indique que la valeur est zéro positif ou négatif
  • FP_INFINITE — indique que la valeur ne peut pas être représentée par le type sous-jacent (infini positif ou négatif)
  • FP_NAN — indique que la valeur est un non-nombre (NaN)

Exemple

#include <cfloat>
#include <cmath>
#include <iostream>

auto show_classification(double x)
{
    switch (std::fpclassify(x))
    {
        case FP_INFINITE:
            return "Inf";
        case FP_NAN:
            return "NaN";
        case FP_NORMAL:
            return "normal";
        case FP_SUBNORMAL:
            return "subnormal";
        case FP_ZERO:
            return "zero";
        default:
            return "unknown";
    }
}

int main()
{
    std::cout << "1.0/0.0 is " << show_classification(1 / 0.0) << '\n'
              << "0.0/0.0 is " << show_classification(0.0 / 0.0) << '\n'
              << "DBL_MIN/2 is " << show_classification(DBL_MIN / 2) << '\n'
              << "-0.0 is " << show_classification(-0.0) << '\n'
              << "1.0 is " << show_classification(1.0) << '\n';
}

Output:

1.0/0.0 is Inf
0.0/0.0 is NaN
DBL_MIN/2 is subnormal
-0.0 is zero
1.0 is normal
