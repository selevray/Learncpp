(depuis C++11)

Paramètres

  • num — valeur à virgule flottante ou entière

Valeur de retour

Si aucune erreur ne se produit, la tangente hyperbolique inverse de num (tanh-1
(num), ou artanh(num)), est retournée.

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur de pôle se produit, ±HUGE_VAL, ±HUGE_VALF, ou ±HUGE_VALL est retourné (avec le signe correct).

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'argument n'est pas dans l'intervalle [-1,+1], une erreur d'intervalle se produit.

Si l'argument est ±1, une erreur de pôle se produit.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • si l'argument est ±0, il est retourné sans modification.
  • si l'argument est ±1, ±∞ est retourné et FE_DIVBYZERO est levée.
  • si |num|>1, NaN est retourné et FE_INVALID est levée.
  • si l'argument est NaN, NaN est renvoyé.

Notes

Bien que la norme C (à laquelle C++ renvoie pour cette fonction) nomme cette fonction « arc tangente hyperbolique », les fonctions inverses des fonctions hyperboliques sont les fonctions d'aire. Leur argument est l'aire d'un secteur hyperbolique, et non un arc. Le nom correct est « tangente hyperbolique inverse » (utilisé par POSIX) ou « tangente hyperbolique d'aire ».

POSIX spécifie qu'en cas de sous-dépassement, num est retourné sans modification, et si cela n'est pas pris en charge, une valeur définie par l'implémentation non supérieure à DBL_MIN, FLT_MIN, et LDBL_MIN est retournée.

Les surcharges supplémentaires ne sont pas tenues d'être fournies exactement comme (A). Elles doivent seulement suffire à garantir que pour leur argument num de type entier, std::atanh(num) a le même effet que std::atanh(static_cast<double>(num)).

Exemple

#include <cerrno>
#include <cfenv>
#include <cfloat>
#include <cmath>
#include <cstring>
#include <iostream>
// #pragma STDC FENV_ACCESS ON

int main()
{
    std::cout << "atanh(0) = " << std::atanh(0) << '\n'
              << "atanh(-0) = " << std::atanh(-0.0) << '\n'
              << "atanh(0.9) = " << std::atanh(0.9) << '\n';

    // gestion des erreurs
    errno = 0;
    std::feclearexcept(FE_ALL_EXCEPT);

    std::cout << "atanh(-1) = " << std::atanh(-1) << '\n';

    if (errno == ERANGE)
        std::cout << "    errno == ERANGE: " << std::strerror(errno) << '\n';
    if (std::fetestexcept(FE_DIVBYZERO))
        std::cout << "    FE_DIVBYZERO raised\n";
}
