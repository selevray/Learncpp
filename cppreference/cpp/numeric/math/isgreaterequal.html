Surcharges supplémentaires

Défini dans l'en-tête <cmath>

template< class Arithmetic1, class Arithmetic2 >
bool isgreaterequal( Arithmetic1 x, Arithmetic2 y );  // (A) (depuis C++11) (constexpr depuis C++23)
  1. Détermine si le nombre à virgule flottante x est supérieur ou égal au nombre à virgule flottante y, sans lever d'exceptions de virgule flottante.La bibliothèque fournit des surcharges pour tous les types à virgule flottante non qualifiés cv comme type des paramètres x et y. (depuis C++23)

A) Des surcharges supplémentaires sont fournies pour toutes les autres combinaisons de types arithmétiques.

Paramètres

  • x, y — valeurs à virgule flottante ou entières

Valeur de retour

true si x >= y, false sinon.

Notes

L'opérateur intégré operator>= pour les nombres à virgule flottante peut lever FE_INVALID si l'un des arguments ou les deux sont NaN. Cette fonction est une version « silencieuse » de operator>=.

Les surcharges supplémentaires ne sont pas tenues d'être fournies exactement comme (A). Il suffit qu'elles soient suffisantes pour garantir que, pour leur premier argument num1 et second argument num2 :

  • Si num1 ou num2 est de type long double, alors std::isgreaterequal(num1, num2) a le même effet que std::isgreaterequal(static_cast<long double>(num1), static_cast<long double>(num2)).
  • Sinon, si num1 et/ou num2 est de type double ou de type entier, alors std::isgreaterequal(num1, num2) a le même effet que std::isgreaterequal(static_cast<double>(num1), static_cast<double>(num2)).
  • Sinon, si num1 ou num2 est de type float, alors std::isgreaterequal(num1, num2) a le même effet que std::isgreaterequal(static_cast<float>(num1), static_cast<float>(num2)).

(jusqu'à C++23)

Si num1 et num2 ont des types arithmétiques, alors std::isgreaterequal(num1, num2) a le même effet que std::isgreaterequal(static_cast</*type à virgule flottante commun*/>(num1), static_cast</*type à virgule flottante commun*/>(num2)), où /*type à virgule flottante commun*/ est le type à virgule flottante ayant le plus grand rang de conversion en virgule flottante et le plus grand sous-rang de conversion en virgule flottante parmi les types de num1 et num2 ; les arguments de type entier sont considérés comme ayant le même rang de conversion en virgule flottante que double.

S'il n'existe aucun type à virgule flottante ayant le plus grand rang et sous-rang, alors la résolution de surcharge ne donne aucun candidat utilisable parmi les surcharges fournies.

(depuis C++23)
