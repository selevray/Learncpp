Défini dans l'en-tête <cinttypes>

std::intmax_t abs( std::intmax_t num );  // (6) (depuis C++11) (constexpr depuis C++23)

std::intmax_t imaxabs( std::intmax_t num );  // (7) (depuis C++11) (constexpr depuis C++23)

Calcule la valeur absolue du nombre entier num. Le comportement est indéfini si le résultat ne peut pas être représenté par le type de retour.

Si std::abs est appelée avec un argument entier non signé qui ne peut pas être converti en int par promotion entière, le programme est mal formé.

La surcharge (6) de std::abs pour std::intmax_t est fournie dans <cinttypes> si et seulement si std::intmax_t est un type entier étendu.

(depuis C++11)

Paramètres

  • num — valeur entière

Valeur de retour

La valeur absolue de num (c.-à-d. |num|), si elle est représentable.

Notes

Dans les systèmes en complément à 2, la valeur absolue de la valeur la plus négative est hors de l'intervalle ; par exemple, pour le type en complément à 2 de 32 bits int, INT_MIN vaut -2147483648, mais le résultat attendu 2147483648 est supérieur à INT_MAX, qui vaut 2147483647.

Exemple

#include <climits>
#include <cstdlib>
#include <iostream>

int main()
{
    std::cout << std::showpos
              << "abs(+3) = " << std::abs(3) << '\n'
              << "abs(-3) = " << std::abs(-3) << '\n';

//  std::cout << std::abs(INT_MIN); // comportement indéfini sur les systèmes en complément à 2
}

Output:

abs(+3) = +3
abs(-3) = +3
