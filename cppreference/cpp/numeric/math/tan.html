Défini dans l'en-tête <cmath>

template< class Integer >
double      tan ( Integer num );  // (A) (constexpr depuis C++26)

1-3) Calcule la tangente de num (exprimé en radians).La bibliothèque fournit des surcharges de std::tan pour tous les types à virgule flottante non qualifiés cv comme type du paramètre. (depuis C++23)

S) La surcharge SIMD effectue un std::tan élément par élément sur v_num.

(Voir math-floating-point et deduced-simd-t pour leurs définitions.)

(depuis C++26)

A) Des surcharges supplémentaires sont fournies pour tous les types entiers, qui sont traités comme double.

(depuis C++11)

Paramètres

  • num — valeur à virgule flottante ou entière représentant un angle en radians

Valeur de retour

Si aucune erreur ne se produit, la tangente de num (tan(num)) est renvoyée.

Le résultat peut avoir peu ou pas de signification si la valeur absolue de num est grande.

(jusqu'à C++11)

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • si l'argument est ±0, il est retourné sans modification.
  • si l'argument vaut ±∞, NaN est renvoyé et FE_INVALID est levé.
  • si l'argument est NaN, NaN est renvoyé.

Notes

Le cas où l'argument est infini n'est pas spécifié comme erreur de domaine en C (à laquelle C++ renvoie), mais il est défini comme erreur de domaine selon POSIX.

La fonction possède des pôles mathématiques en π(1/2 + n) ; cependant, aucune représentation courante à virgule flottante ne peut représenter π/2 exactement, il n'existe donc aucune valeur de l'argument pour laquelle une erreur de pôle se produise.

Les surcharges supplémentaires ne sont pas tenues d'être fournies exactement comme (A). Elles doivent seulement suffire à garantir que pour leur argument num de type entier, std::tan(num) a le même effet que std::tan(static_cast<double>(num)).

Exemple

#include <cerrno>
#include <cfenv>
#include <cmath>
#include <iostream>

// #pragma STDC FENV_ACCESS ON
const double pi = std::acos(-1); // ou std::numbers::pi de C++20

int main()
{
    // utilisation typique
    std::cout << "tan(1*pi/4) = " << std::tan(1*pi/4) << '\n' // 45°
              << "tan(3*pi/4) = " << std::tan(3*pi/4) << '\n' // 135°
              << "tan(5*pi/4) = " << std::tan(5*pi/4) << '\n' // -135°
              << "tan(7*pi/4) = " << std::tan(7*pi/4) << '\n'; // -45°

    // valeurs spéciales
    std::cout << "tan(+0) = " << std::tan(0.0) << '\n'
              << "tan(-0) = " << std::tan(-0.0) << '\n';

    // gestion des erreurs
    std::feclearexcept(FE_ALL_EXCEPT);

    std::cout << "tan(INFINITY) = " << std::tan(INFINITY) << '\n';
    if (std::fetestexcept(FE_INVALID))
        std::cout << "    FE_INVALID raised\n";
}
