Surcharges supplémentaires

Défini dans l'en-tête <cmath>

template< class Integer >
int ilogb ( Integer num );  // (A) (depuis C++11) (constexpr depuis C++23)

1-3) Extrait la valeur de l'exposant non biaisé de l'argument à virgule flottante num, et la renvoie sous forme de valeur entière signée.La bibliothèque fournit des surcharges de std::ilogb pour tous les types à virgule flottante non qualifiés cv comme type du paramètre num. (depuis C++23)

  1. Se développe en expression constante entière dont la valeur est soit INT_MIN, soit -INT_MAX.

  2. Se développe en expression constante entière dont la valeur est soit INT_MIN, soit +INT_MAX.

A) Des surcharges supplémentaires sont fournies pour tous les types entiers, qui sont traités comme double.

Formellement, l'exposant non biaisé est la partie entière de logr|num| sous forme de valeur entière signée, pour num non nul, où r vaut std::numeric_limits<T>::radix et T est le type à virgule flottante de num.

Paramètres

  • num — valeur à virgule flottante ou entière

Valeur de retour

Si aucune erreur ne se produit, l'exposant non biaisé de num est renvoyé sous forme de valeur int signée.

Si num vaut zéro, FP_ILOGB0 est renvoyé.

Si num est infini, INT_MAX est renvoyé.

Si num est un NaN, FP_ILOGBNAN est renvoyé.

Si le résultat correct est supérieur à INT_MAX ou inférieur à INT_MIN, la valeur de retour est non spécifiée.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Une erreur de domaine ou d'intervalle peut se produire si num vaut zéro, est infini ou NaN.

Si le résultat correct est supérieur à INT_MAX ou inférieur à INT_MIN, une erreur de domaine ou d'intervalle peut se produire.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si le résultat correct est supérieur à INT_MAX ou inférieur à INT_MIN, FE_INVALID est levée.
  • Si num vaut ±0, ±∞ ou NaN, FE_INVALID est levée.
  • Dans tous les autres cas, le résultat est exact (FE_INEXACT n'est jamais levée) et le mode d'arrondi courant est ignoré.

Notes

Si num n'est ni nul, ni infini, ni NaN, la valeur renvoyée est exactement équivalente à static_cast<int>(std::logb(num)).

POSIX exige qu'une erreur de domaine se produise si num vaut zéro, est infini, NaN, ou si le résultat correct est en dehors de l'intervalle de int.

POSIX exige également que, sur les systèmes conformes XSI, la valeur renvoyée lorsque le résultat correct est supérieur à INT_MAX soit INT_MAX, et la valeur renvoyée lorsque le résultat correct est inférieur à INT_MIN soit INT_MIN.

Le résultat correct peut être représenté comme int sur toutes les implémentations connues. Pour qu'un dépassement se produise, INT_MAX doit être inférieur à LDBL_MAX_EXP * std::log2(FLT_RADIX) ou INT_MIN doit être supérieur à LDBL_MIN_EXP - LDBL_MANT_DIG) * std::log2(FLT_RADIX).

La valeur de l'exposant renvoyée par std::ilogb est toujours inférieure de 1 à l'exposant renvoyé par std::frexp en raison des différentes exigences de normalisation : pour l'exposant e renvoyé par std::ilogb, |numr-e
| est compris entre 1 et r (typiquement entre 1 et 2), mais pour l'exposant e renvoyé par std::frexp, |num2-e
| est compris entre 0.5 et 1.

Les surcharges supplémentaires ne sont pas tenues d'être fournies exactement comme (A). Elles doivent seulement suffire à garantir que pour leur argument num de type entier, std::ilogb(num) a le même effet que std::ilogb(static_cast<double>(num)).

Exemple

Compare différentes fonctions de décomposition des nombres à virgule flottante :

#include <cfenv>
#include <cmath>
#include <iostream>
#include <limits>

// #pragma STDC FENV_ACCESS ON

int main()
{
    double f = 123.45;
    std::cout << "Given the number " << f << " or " << std::hexfloat
              << f << std::defaultfloat << " in hex,\n";

    double f3;
    double f2 = std::modf(f, &f3);
    std::cout << "modf() makes " << f3 << " + " << f2 << '\n';

    int i;
    f2 = std::frexp(f, &i);
    std::cout << "frexp() makes " << f2 << " * 2^" << i << '\n';

    i = std::ilogb(f);
    std::cout << "logb()/ilogb() make " << f / std::scalbn(1.0, i) << " * "
              << std::numeric_limits<double>::radix
              << "^" << std::ilogb(f) << '\n';

    // gestion des erreurs
    std::feclearexcept(FE_ALL_EXCEPT);

    std::cout << "ilogb(0) = " << std::ilogb(0) << '\n';
    if (std::fetestexcept(FE_INVALID))
        std::cout << "    FE_INVALID raised\n";
}
