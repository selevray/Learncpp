Les surcharges supplémentaires ne sont pas tenues d'être fournies exactement comme (A). Il suffit qu'elles soient suffisantes pour garantir que, pour leur premier argument num1 et second argument num2 :

  • Si num1 ou num2 est de type long double, alors std::beta(num1, num2) a le même effet que std::beta(static_cast<long double>(num1), static_cast<long double>(num2)).
  • Sinon, si num1 et/ou num2 est de type double ou de type entier, alors std::beta(num1, num2) a le même effet que std::beta(static_cast<double>(num1), static_cast<double>(num2)).
  • Sinon, si num1 ou num2 est de type float, alors std::beta(num1, num2) a le même effet que std::beta(static_cast<float>(num1), static_cast<float>(num2)).

(jusqu'à C++23)

Si num1 et num2 ont des types arithmétiques, alors std::beta(num1, num2) a le même effet que std::beta(static_cast</* type à virgule flottante commun */>(num1), static_cast</* type à virgule flottante commun */>(num2)), où /* type à virgule flottante commun */ est le type à virgule flottante ayant le plus grand rang de conversion en virgule flottante et le plus grand sous-rang de conversion en virgule flottante parmi les types de num1 et num2 ; les arguments de type entier sont considérés comme ayant le même rang de conversion en virgule flottante que double.

S'il n'existe aucun type à virgule flottante ayant le plus grand rang et sous-rang, alors la résolution de surcharge ne donne aucun candidat utilisable parmi les surcharges fournies.

(depuis C++23)

Exemple

#include <cassert>
#include <cmath>
#include <iomanip>
#include <iostream>
#include <numbers>
#include <string>

long binom_via_beta(int n, int k)
{
    return std::lround(1 / ((n + 1) * std::beta(n - k + 1, k + 1)));
}

long binom_via_gamma(int n, int k)
{
    return std::lround(std::tgamma(n + 1) /
                      (std::tgamma(n - k + 1) *
                       std::tgamma(k + 1)));
}

int main()
{
    std::cout << "Pascal's triangle:\n";
    for (int n = 1; n < 10; ++n)
    {
        std::cout << std::string(20 - n * 2, ' ');
        for (int k = 1; k < n; ++k)
        {
            std::cout << std::setw(3) << binom_via_beta(n, k) << ' ';
            assert(binom_via_beta(n, k) == binom_via_gamma(n, k));
        }
        std::cout << '\n';
    }

    // Un contrôle ponctuel
    const long double p = 0.123; // une valeur aléatoire dans [0, 1]
    const long double q = 1 - p;
    const long double π = std::numbers::pi_v<long double>;
    std::cout << "\n\n" << std::setprecision(19)
              << "β(p,1-p)   = " << std::beta(p, q) << '\n'
              << "π/sin(π*p) = " << π / std::sin(π * p) << '\n';
}
