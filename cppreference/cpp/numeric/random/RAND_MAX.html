RAND_MAX

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdlib>

#define RAND_MAX /*implementation defined*/

Se développe en une expression constante entière égale à la valeur maximale renvoyée par la fonction std::rand. Cette valeur dépend de l'implémentation. Il est garanti que cette valeur est au moins égale à 32767.

Exemple

#include <climits>
#include <cstdlib>
#include <ctime>
#include <iostream>

int main()
{
    // utilise l'heure courante comme graine pour le générateur aléatoire
    std::srand(std::time(NULL));

    std::cout << "RAND_MAX: " << RAND_MAX << '\n'
              << "INT_MAX: " << INT_MAX << '\n'
              << "Random value on [0,1]: "
              << static_cast<double>(std::rand()) / RAND_MAX << '\n';
}

Sortie possible :

RAND_MAX: 2147483647
INT_MAX: 2147483647
Random value on [0,1]: 0.618608
