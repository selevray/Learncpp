std::seed_seq

Défini dans l'en-tête <random>

class seed_seq;  // (depuis C++11)

std::seed_seq consomme une séquence de données entières et produit un nombre demandé de valeurs entières non signées de 32 bits, à partir des données consommées. Les valeurs produites sont réparties sur toute la plage de 32 bits, même si les valeurs consommées sont proches.

Elle permet d'initialiser un grand nombre de moteurs de nombres aléatoires, ou un générateur nécessitant beaucoup d'entropie, à partir d'une petite graine ou d'une séquence de graines initiale mal répartie.

std::seed_seq satisfait les exigences de SeedSequence.

Exemple

#include <cstdint>
#include <iostream>
#include <random>

int main()
{
    std::seed_seq seq{1, 2, 3, 4, 5};
    std::vector<std::uint32_t> seeds(10);
    seq.generate(seeds.begin(), seeds.end());
    for (std::uint32_t n : seeds)
        std::cout << n << '\n';
}
