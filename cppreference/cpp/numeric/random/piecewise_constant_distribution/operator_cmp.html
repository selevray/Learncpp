operator==,!=(std::piecewise_constant_distribution)

friend bool operator==( const piecewise_constant_distribution& lhs,
                        const piecewise_constant_distribution& rhs );  // (1) (depuis C++11)

friend bool operator!=( const piecewise_constant_distribution& lhs,
                        const piecewise_constant_distribution& rhs );  // (2) (depuis C++11) (jusqu'à C++20)

Compare deux objets de distribution. Deux objets de distribution sont égaux lorsque les valeurs des paramètres et l'état interne sont identiques.

  1. Compare deux objets de distribution pour l'égalité.

  2. Compare deux objets de distribution pour l'inégalité.

Ces fonctions ne sont pas visibles par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peuvent être trouvées que par recherche dépendant des arguments lorsque std::piecewise_constant_distribution<ResultType> est une classe associée des arguments.

L'opérateur != est synthétisé à partir de operator==.

(depuis C++20)

Paramètres

  • lhs, rhs — objets de distribution à comparer

Valeur de retour

  1. true si les objets de distribution sont égaux, false sinon.

  2. true si les objets de distribution ne sont pas égaux, false sinon.

Complexité

Constante.
