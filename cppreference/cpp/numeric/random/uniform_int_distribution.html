std::uniform_int_distribution

template< class IntType = int >
class uniform_int_distribution;  // (depuis C++11)

Produit des valeurs entières aléatoires (\small i)i, uniformément réparties sur l'intervalle fermé (\small[a, b])[a, b], c'est-à-dire distribuées selon la fonction de probabilité discrète

({\small P(i|a,b) =}\frac{1}{b - a + 1})P(i|a,b) =
1
b − a + 1

.

std::uniform_int_distribution satisfait toutes les exigences de RandomNumberDistribution.

Paramètres de modèle

  • IntType — Le type de résultat produit par le générateur. L'effet est indéfini si ce n'est pas l'un de short, int, long, long long, unsigned short, unsigned int, unsigned long ou unsigned long long.

Exemple

Ce programme simule le lancer de dés à 6 faces.

#include <iostream>
#include <random>

int main()
{
    std::random_device rd;  // une source de graine pour le moteur de nombres aléatoires
    std::mt19937 gen(rd()); // mersenne_twister_engine initialisé avec rd()
    std::uniform_int_distribution<> distrib(1, 6);

    // Utilise distrib pour transformer l'unsigned int aléatoire
    // généré par gen en un int dans [1, 6]
    for (int n = 0; n != 10; ++n)
        std::cout << distrib(gen) << ' ';
    std::cout << '\n';
}
