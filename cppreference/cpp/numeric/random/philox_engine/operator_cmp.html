operator==(std::philox_engine)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

friend bool operator==( const philox_engine& lhs, const philox_engine& rhs );  // (depuis C++26)

Compare deux moteurs de nombres pseudo-aléatoires. Deux moteurs sont égaux si leurs états internes sont équivalents, c'est-à-dire s'ils généreraient des valeurs équivalentes pour tout nombre d'appels de operator().

Cette fonction n'est pas visible par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peut être trouvée que par la recherche dépendante des arguments lorsque decltype(*this) est une classe associée aux arguments.

L'opérateur != est synthétisé à partir de operator==.

Paramètres

  • lhs, rhs — moteurs à comparer

Valeur de retour

true si les moteurs sont égaux, false sinon.
