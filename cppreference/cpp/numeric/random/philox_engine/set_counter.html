void set_counter( const std::array<result_type, n>& c );  // (depuis C++26)

Définit le compteur du moteur de nombres aléatoires.

  • Pour chaque entier k dans [0,n), définit (\scriptsize X_k )Xk à (\scriptsize c_{n-1-k} \mod 2^w )cn-1-k mod 2w
    .
  • La valeur de j est mise à n - 1.[1]
  1. ↑ Comme j est défini à n - 1, la transition d'état suivante génère toujours de nouvelles valeurs aléatoires.

Paramètres

  • c — séquence de compteur à utiliser pour définir le compteur
