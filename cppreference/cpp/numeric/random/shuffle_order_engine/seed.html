Réinitialise l'état interne du moteur sous-jacent à l'aide d'une nouvelle valeur de graine.

  1. Initialise le moteur sous-jacent avec la valeur de graine par défaut. Appelle effectivement e.seed(), où e est le moteur sous-jacent.

  2. Initialise le moteur sous-jacent avec la valeur de graine value. Appelle effectivement e.seed(value), où e est le moteur sous-jacent.

  3. Initialise le moteur sous-jacent avec la séquence de graine seq. Appelle effectivement e.seed(seq), où e est le moteur sous-jacent.

Cette surcharge ne participe à la résolution de surcharge que si SeedSeq satisfait les exigences de SeedSequence.

Paramètres

  • value — valeur de graine à utiliser pour l'initialisation de l'état interne du moteur sous-jacent
  • seq — séquence de graine à utiliser pour l'initialisation de l'état interne du moteur sous-jacent

Exceptions

  1. Si SeedSeq n'est pas std::seed_seq, lève les exceptions levées par l'appel seq.generate.
