std::gamma_distribution

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <random>

template< class RealType = double >
class gamma_distribution;  // (depuis C++11)

Produit des valeurs à virgule flottante positives aléatoires x, distribuées selon la fonction de densité de probabilité :

(\mathsf{p}(x\mid\alpha,\beta) = \frac{e^{-x/\beta} }{\beta^\alpha\cdot\Gamma(\alpha)}\cdot x^{\alpha-1} )P(x|α,β) =
e-x/β
βα · Γ(α)

· xα-1

où α est appelé paramètre de forme et β est appelé paramètre d'échelle. Le paramètre de forme est parfois noté par la lettre k et le paramètre d'échelle parfois par la lettre θ.

Pour un α à virgule flottante, la valeur obtenue est la somme de α variables aléatoires indépendantes à distribution exponentielle, dont chacune a une moyenne de β.

std::gamma_distribution satisfait RandomNumberDistribution.

Paramètres de modèle

  • RealType — Le type de résultat produit par le générateur. L'effet est indéfini si ce n'est pas l'un de float, double ou long double.

Exemple

#include <iomanip>
#include <iostream>
#include <map>
#include <random>
#include <string>

int main()
{
    std::random_device rd;
    std::mt19937 gen(rd());

    // Une loi gamma avec alpha = 1 et beta = 2
    // approche une loi exponentielle.
    std::gamma_distribution<> d(1, 2);

    std::map<int, int> hist;
    for (int n = 0; n != 10000; ++n)
        ++hist[2 * d(gen)];

    for (auto const& [x, y] : hist)
        if (y / 100.0 > 0.5)
            std::cout << std::fixed << std::setprecision(1)
                      << x / 2.0 << '-' << (x + 1) / 2.0 << ' '
                      << std::string(y / 100, '*') << '\n';
}
