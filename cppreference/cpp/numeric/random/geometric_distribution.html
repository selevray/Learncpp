std::geometric_distribution

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <random>

template< class IntType = int >
class geometric_distribution;  // (depuis C++11)

Produit des valeurs entières non négatives aléatoires i, distribuées selon la fonction de probabilité discrète :

(P(i|p) = p \cdot (1-p)^i)P(i|p) = p · (1 − p)i

La valeur représente le nombre d'échecs dans une série d'essais indépendants oui/non (chacun réussit avec la probabilité p), avant qu'exactement 1 succès ne se produise.

std::geometric_distribution<>(p) est exactement équivalent à std::negative_binomial_distribution<>(1, p). C'est aussi la contrepartie discrète de std::exponential_distribution.

std::geometric_distribution satisfait RandomNumberDistribution.

Paramètres de modèle

  • IntType — Le type de résultat produit par le générateur. L'effet est indéfini si ce n'est pas l'un de short, int, long, long long, unsigned short, unsigned int, unsigned long ou unsigned long long.

Exemple

std::geometric_distribution<>(0.5) est la valeur par défaut et représente le nombre de lancers de pièce nécessaires pour obtenir face.

#include <iomanip>
#include <iostream>
#include <map>
#include <random>
#include <string>

int main()
{
    std::random_device rd;
    std::mt19937 gen(rd());

    std::geometric_distribution<> d;
        // identique à
        // std::negative_binomial_distribution<> d(1, 0.5):

    std::map<int, int> hist;
    for (int n = 0; n != 10000; ++n)
        ++hist[d(gen)];

    for (auto [x, y] : hist)
    {
        const char c = x < 10 ? x + '0' : x - 10 + 'a';
        std::cout << c << ' ' << std::string(y / 100, '*') << '\n';
    }
}
