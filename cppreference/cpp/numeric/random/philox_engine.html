std::philox_engine est un moteur de nombres aléatoires basé sur un compteur.

Paramètres de modèle

  • UIntType — Le type de résultat généré par le générateur. Le comportement est indéfini si ce n'est pas l'un de unsigned short, unsigned int, unsigned long ou unsigned long long.
  • w — la taille du mot en bits
  • n — le nombre de mots
  • r — le nombre de tours
  • consts — la séquence de multiplicateurs et de constantes de tour utilisée pour générer les nombres aléatoires

Si l'une des valeurs suivantes n'est pas true, le programme est mal formé :

  • sizeof...(consts) == n
  • n == 2 || n == 4 || n == 8 || n == 16
  • 0 < r
  • 0 < w && w <= std::numeric_limits<UIntType>::digits

Propriétés du générateur

Dans la description suivante, soit (\scriptsize Q_i )Qi désignant le i-ième élément de la séquence Q, l'indice commençant à zéro.

La taille des états de philox_engine est (\scriptsize O(n))O(n), chacun est composé de quatre parties :

  • Une séquence X de n valeurs entières, où chaque valeur est dans [0,2w).

    • Cette séquence représente une grande valeur de compteur entier non signé (\scriptsize Z=\sum_{j=0}^{n-1} X \cdot 2^{wj} )Z=∑n-1
      j=0X⋅2wj
      de (\scriptsize n \cdot w )n⋅w bits.

  • Une séquence K de n / 2 clés de type UIntType.

  • Un tampon Y de n valeurs produites de type UIntType.

  • Un index j dans le tampon Y.

L'algorithme de transition de philox_engine ((\scriptsize TA(X_i) )TA(Xi)) est défini comme suit :

  • Si j n'est pas n - 1, incrémente j de 1.[1]
  • Si j est n - 1, effectue les opérations suivantes :[2]
  1. Génère une nouvelle séquence de n valeurs aléatoires (voir ci-dessous) et la stocke dans Y.
  2. Incrémente le compteur Z de 1.
  3. Remet j à 0.

L'algorithme de génération de philox_engine est (\scriptsize GA(X_i)=Y_j )GA(Xi)=Yj.

  1. ↑ Dans ce cas, l'appel suivant de l'algorithme de génération renvoie la valeur suivante générée dans le tampon.
  2. ↑ Dans ce cas, le tampon est rafraîchi, et l'appel suivant de l'algorithme de génération renvoie la première valeur du nouveau tampon.

Génération de valeurs aléatoires

Les valeurs aléatoires sont générées à partir des paramètres suivants :

  • le nombre de tours r
  • la séquence de compteur courante X
  • la séquence de clés K
  • la séquence de multiplicateurs M
  • la séquence de constantes de tour C

Les séquences M et C sont formées à partir des valeurs du pack de paramètres de modèle consts, qui représente les constantes (\scriptsize M_k )Mk et (\scriptsize C_k )Ck sous la forme [(\scriptsize M_0 )M0,(\scriptsize C_0 )C0,(\scriptsize M_1 )M1,(\scriptsize C_1 )C1,... , ...,(\scriptsize M_{n/2-1} )Mn/2-1,(\scriptsize C_{n/2-1} )Cn/2-1].

Les nombres aléatoires sont générés par le processus suivant :

  1. Initialise la séquence de sortie S avec les éléments de X.
  2. Met à jour les éléments de S pendant r tours.
  3. Remplace les valeurs du tampon Y par les valeurs de S.
