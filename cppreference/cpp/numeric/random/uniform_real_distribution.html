std::uniform_real_distribution

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <random>

template< class RealType = double >
class uniform_real_distribution;  // (depuis C++11)

Produit des valeurs flottantes aléatoires (\small x)x, uniformément réparties sur l'intervalle (\small [a, b))[a, b), c'est-à-dire distribuées selon la fonction de densité de probabilité :

({\small P(x|a,b) =} \frac{1}{b-a})P(x|a,b) =
1
b − a

.

std::uniform_real_distribution satisfait toutes les exigences de RandomNumberDistribution.

Paramètres de modèle

  • RealType — Le type de résultat produit par le générateur. L'effet est indéfini si ce n'est pas l'un de float, double ou long double.

Types membres

Type membre Définition

  • result_type (C++11) — RealType
  • param_type (C++11) — le type de l'ensemble de paramètres, voir RandomNumberDistribution.

  • reset (C++11) — réinitialise l'état interne de la distribution (fonction membre publique)

  • param (C++11) — obtient ou définit l'objet de paramètre de distribution (fonction membre publique)
  • min (C++11) — renvoie la valeur minimale potentiellement générée (fonction membre publique)

Notes

Il est difficile de créer une distribution sur l'intervalle fermé (\small[a, b])[a, b] à partir de cette distribution. Utiliser std::nextafter(b, std::numeric_limits<RealType>::max()) comme second paramètre ne fonctionne pas toujours à cause des erreurs d'arrondi.

La plupart des implémentations existantes ont un bogue : elles peuvent parfois renvoyer (\small b)b (GCC #63176 LLVM #18767 MSVC STL #1074). On pensait initialement que cela ne se produisait que lorsque RealType est float et que LWG issue 2524 est présent, mais il a depuis été montré que ni l'un ni l'autre n'est nécessaire pour déclencher le bogue.

Exemple

Affiche 10 nombres aléatoires entre 1 et 2.

#include <iostream>
#include <random>

int main()
{
    std::random_device rd;  // Sera utilisé pour obtenir une graine pour le moteur de nombres aléatoires
    std::mt19937 gen(rd()); // mersenne_twister_engine standard initialisé avec rd()
    std::uniform_real_distribution<> dis(1.0, 2.0);
    for (int n = 0; n < 10; ++n)
        // Utilise dis pour transformer l'unsigned int aléatoire généré par gen en un
        // double dans [1, 2). Chaque appel à dis(gen) génère un nouveau double aléatoire.
        std::cout << dis(gen) << ' ';
    std::cout << '\n';
}
