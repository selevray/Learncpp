std::discrete_distribution

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <random>

template< class IntType = int >
class discrete_distribution;  // (depuis C++11)

std::discrete_distribution produit des entiers aléatoires sur l'intervalle [0,n), où la probabilité de chaque entier individuel i est définie comme wi/S, soit le poids du ie entier divisé par la somme de tous les n poids.

std::discrete_distribution satisfait toutes les exigences de RandomNumberDistribution.

Paramètres de modèle

  • IntType — Le type de résultat produit par le générateur. L'effet est indéfini si ce n'est pas l'un de short, int, long, long long, unsigned short, unsigned int, unsigned long ou unsigned long long.

Types membres

Type membre Définition

  • result_type (C++11) — IntType
  • param_type (C++11) — le type de l'ensemble de paramètres, voir RandomNumberDistribution.

Fonctions membres

  • (constructeur) (C++11) — construit une nouvelle distribution (fonction membre publique)
  • reset (C++11) — réinitialise l'état interne de la distribution (fonction membre publique)

##### Génération {#Generation}

  • operator() (C++11) — génère le nombre aléatoire suivant de la distribution (fonction membre publique)

##### Caractéristiques {#Characteristics}

  • probabilities — obtient la liste des probabilités (fonction membre publique)
  • param (C++11) — obtient ou définit l'objet de paramètre de distribution (fonction membre publique)
  • min (C++11) — renvoie la valeur minimale potentiellement générée (fonction membre publique)
  • max (C++11) — renvoie la valeur maximale potentiellement générée (fonction membre publique)

Fonctions non membres

  • operator==operator!= (C++11) (C++11) (removed in C++20) — compare deux objets de distribution (fonction)
  • operator<<operator>> (C++11) — effectue l'entrée et la sortie de flux sur une distribution de nombres pseudo-aléatoires (modèle de fonction)

Exemple

#include <iomanip>
#include <iostream>
#include <map>
#include <random>

int main()
{
    std::random_device rd;
    std::mt19937 gen(rd());
    std::discrete_distribution<> d({40, 10, 10, 40});
    std::map<int, int> map;

    for (int n = 0; n < 1e4; ++n)
        ++map[d(gen)];

    for (const auto& [num, count] : map)
        std::cout << num << " generated " << std::setw(4) << count << " times\n";
}
