negative_binomial_distribution() : negative_binomial_distribution(1) {}  // (1) (depuis C++11)

explicit negative_binomial_distribution( IntType k, double p = 0.5 );  // (2) (depuis C++11)

explicit negative_binomial_distribution( const param_type& params );  // (3) (depuis C++11)

Construit un nouvel objet de distribution.

  1. Utilise k et p comme paramètres de distribution.

  2. Utilise params comme paramètres de distribution.

Paramètres

  • k — le paramètre de distribution k (nombre de succès)
  • p — le paramètre de distribution p (probabilité qu'un essai produise true)
  • params — l'ensemble des paramètres de distribution

Notes

Exige que 0 < p ≤ 1 et 0 < k.

Si p == 1, les appels ultérieurs à la surcharge operator() qui n'accepte pas d'objet param_type provoqueront un comportement indéfini.

Le std::negative_binomial_distribution construit par défaut est équivalent au std::geometric_distribution construit par défaut.
