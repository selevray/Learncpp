std::rand

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdlib>

int rand();

Renvoie une valeur entière pseudo-aléatoire de l'intervalle [0,RAND_MAX].

std::srand() initialise le générateur de nombres pseudo-aléatoires utilisé par rand(). Si rand() est utilisé avant tout appel à std::srand(), rand() se comporte comme s'il avait été initialisé avec std::srand(1).

Chaque fois que rand() est initialisé avec std::srand(), il doit produire la même suite de valeurs lors d'appels successifs.

D'autres fonctions de la bibliothèque standard peuvent appeler rand. Il est défini par l'implémentation quelles fonctions le font.

Il est défini par l'implémentation si rand() est compatible avec les threads.

Valeur de retour

Valeur entière pseudo-aléatoire comprise entre 0 et RAND_MAX.

Notes

Aucune garantie n'est donnée quant à la qualité de la suite aléatoire produite. Par le passé, certaines implémentations de rand() ont présenté de graves lacunes dans le caractère aléatoire, la distribution et la période de la suite produite (dans un exemple bien connu, le bit de poids faible alternait simplement entre 1 et 0 entre les appels).

rand() n'est pas recommandé pour des besoins sérieux de génération de nombres aléatoires. Il est recommandé d'utiliser les installations de génération de nombres aléatoires de C++11 pour remplacer rand(). (depuis C++11)

Exemple

La fonction bounded_rand() ci-dessous est une version adaptée de Debiased Modulo (Once).

#include <cstdlib>
#include <ctime>
#include <initializer_list>
#include <iostream>

unsigned bounded_rand(unsigned range)
{
    for (unsigned x, r;;)
        if (x = rand(), r = x % range, x - r <= -range)
            return r;
}

int main()
{
    std::srand(std::time({})); // utilise l'heure courante comme graine pour le générateur aléatoire
    const int random_value = std::rand();
    std::cout << "Random value on [0, " << RAND_MAX << "]: " << random_value << '\n';

    for (const unsigned sides : {2, 4, 6, 8})
    {
        std::cout << "Roll " << sides << "-sided die 8 times: ";
        for (int n = 8; n; --n)
            std::cout << 1 + bounded_rand(sides) << ' ';

        std::cout << '\n';
    }
}
