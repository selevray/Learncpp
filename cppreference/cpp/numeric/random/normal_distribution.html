Ici (\small\mu)μ est la moyenne et (\small\sigma)σ est l'écart type (stddev).

std::normal_distribution satisfait toutes les exigences de RandomNumberDistribution.

Paramètres de modèle

  • RealType — Le type de résultat produit par le générateur. L'effet est indéfini si ce n'est pas l'un de float, double ou long double.

Exemple

#include <cmath>
#include <iomanip>
#include <iostream>
#include <map>
#include <random>
#include <string>

int main()
{
    std::random_device rd{};
    std::mt19937 gen{rd()};

    // Les valeurs proches de la moyenne sont les plus probables. L'écart type
    // influe sur la dispersion des valeurs générées par rapport à la moyenne.
    std::normal_distribution d{5.0, 2.0};

    // Tire un échantillon de la distribution normale et l'arrondit à un entier.
    auto random_int = [&d, &gen]{ return std::lround(d(gen)); };

    std::map<long, unsigned> histogram{};
    for (auto n{10000}; n; --n)
        ++histogram[random_int()];

    for (const auto [k, v] : histogram)
        std::cout << std::setw(2) << k << ' ' << std::string(v / 200, '*') << '\n';
}
