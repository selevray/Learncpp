std::poisson_distribution

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <random>

template< class IntType = int >
class poisson_distribution;  // (depuis C++11)

Produit des valeurs entières non négatives aléatoires i, distribuées selon la fonction de probabilité discrète :

(P(i | \mu) = \frac{e^{-\mu}\mu^i}{i!})P(i|μ) =
e-μ ·μi
i!

La valeur obtenue est la probabilité d'exactement i occurrences d'un événement aléatoire si le nombre attendu, moyen d'occurrences dans les mêmes conditions (sur le même intervalle de temps ou d'espace) est μ.

std::poisson_distribution satisfait RandomNumberDistribution.

Paramètres de modèle

  • IntType — Le type de résultat produit par le générateur. L'effet est indéfini si ce n'est pas l'un de short, int, long, long long, unsigned short, unsigned int, unsigned long ou unsigned long long.

  • param_type (C++11) — le type de l'ensemble de paramètres, voir RandomNumberDistribution.

Exemple

#include <iomanip>
#include <iostream>
#include <map>
#include <random>
#include <string>

int main()
{
    std::random_device rd;
    std::mt19937 gen(rd());

    // Si un événement se produit en moyenne 4 fois par minute, à quelle
    // fréquence se produit-il n fois en une minute ?
    std::poisson_distribution<> d(4);

    std::map<int, int> hist;
    for (int n = 0; n != 10000; ++n)
        ++hist[d(gen)];

    for (auto [x, y] : hist)
        std::cout << std::hex << x << ' '
                  << std::string(y / 100, '*') << '\n';
}
