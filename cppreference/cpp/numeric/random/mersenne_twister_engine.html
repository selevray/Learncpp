mersenne_twister_engine est un moteur de nombres aléatoires basé sur l'algorithme Mersenne Twister. Il produit des nombres aléatoires entiers non signés de haute qualité, mais non sécurisés cryptographiquement, de type UIntType, dans l'intervalle (\scriptsize {[0,2^w)})[0, 2w
).

Paramètres de modèle

  • UIntType — Le type de résultat généré par le générateur. Le comportement est indéfini si ce n'est pas l'un de unsigned short, unsigned int, unsigned long ou unsigned long long.
  • w — la puissance de deux qui détermine l'intervalle des valeurs générées par le moteur
  • n — le degré de récurrence
  • m — le mot médian, un décalage utilisé dans la relation de récurrence définissant l'état
  • r — le nombre de bits du masque de bits inférieur, aussi appelé valeur de torsion
  • a — le masque xor conditionnel, c'est-à-dire les coefficients de la matrice de torsion sous forme normale rationnelle
  • u, d, s, b, t, c, l — les 1er à 7e composantes de la matrice de mélange des bits (tempering)
  • f — le multiplicateur d'initialisation

Si l'une des restrictions suivantes est violée, le programme est mal formé :

  • m se trouve dans [1,n].

  • Les expressions suivantes sont toutes true :

    • w >= 3
    • w >= r
    • w >= u
    • w >= s
    • w >= t
    • w >= l
    • w <= std::numeric_limits<UIntType>::digits

  • Étant donné (1u << w) - 1u comme w1, les expressions suivantes sont toutes true :

    • a <= w1
    • b <= w1
    • c <= w1
    • d <= w1
    • f <= w1

Propriétés du générateur

La taille des états de mersenne_twister_engine est n, chacun consistant en une suite X de n valeurs de type result_type. (\scriptsize X_j)Xj désigne la (\scriptsize j\mod n)j mod ne valeur (en commençant à 0) de X.

Étant donné les notations d'opérations bit à bit suivantes :

  • (\scriptsize \mathsf{bitand})bitand, le ET bit à bit intégré.
  • (\scriptsize \mathsf{xor})xor, le OU exclusif bit à bit intégré.
  • (\scriptsize \mathsf{lshift})lshift, le décalage à gauche bit à bit intégré.
  • (\scriptsize \mathsf{rshift})rshift, le décalage à droite bit à bit intégré.

L'algorithme de transition de mersenne_twister_engine ((\scriptsize TA(x_i))TA(xi)) est défini comme suit :

  1. Concatène les w - r bits de poids fort de (\scriptsize X_{i-n})Xi-n avec les r bits de poids faible de (\scriptsize X_{i+1-n})Xi+1-n pour obtenir une valeur entière non signée Y.
  2. Soit y égal à (\scriptsize a \cdot (Y\ \mathsf{bitand}\ 1))a·(Y bitand 1), et affecte à (\scriptsize X_i)Xi la valeur (\scriptsize X_{i+m−n}\ \mathsf{xor}\ (Y\ \mathsf{rshift}\ 1)\ \mathsf{xor}\ y)Xi+m−n xor (Y rshift 1) xor y.

L'algorithme de génération de mersenne_twister_engine ((\scriptsize GA(x_i))GA(xi)) est défini comme suit :

  1. Soit (\scriptsize z_1)z1 égal à (\scriptsize X_i\ \mathsf{xor}\ ((X_i\ \mathsf{rshift}\ u)\ \mathsf{bitand}\ d))Xi xor ((Xi rshift u) bitand d).
  2. Soit (\scriptsize z_2)z2 égal à (\scriptsize z_1\ \mathsf{xor}\ (((z_1\ \mathsf{lshift}\ s)\mod 2^w)\ \mathsf{bitand}\ b))Xi xor (((Xi lshift s) mod 2w
    ) bitand b).
  3. Soit (\scriptsize z_3)z3 égal à (\scriptsize z_2\ \mathsf{xor}\ (((z_2\ \mathsf{lshift}\ t)\mod 2^w)\ \mathsf{bitand}\ c))Xi xor (((Xi lshift t) mod 2w
    ) bitand c).
  4. Soit (\scriptsize z_4)z4 égal à (\scriptsize z_3\ \mathsf{xor}\ (z_3\ \mathsf{rshift}\ l))z3 xor (z3 rshift l).
  5. Renvoie (\scriptsize z_4)z4 comme résultat (c'est-à-dire (\scriptsize GA(x_i)=z_4)GA(xi)=z4).
