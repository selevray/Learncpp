Construit le moteur de nombres pseudo-aléatoires.

  1. Le constructeur par défaut.
  • Si le moteur construit par défaut est de type std::mt19937, la 10000e invocation consécutive de celui-ci produit la valeur 4123659995.
  • Si le moteur construit par défaut est de type std::mt19937_64, la 10000e invocation consécutive de celui-ci produit la valeur 9981545732273789042.

    comme p, l'état initial du moteur est déterminé comme suit :
  1. Affecte (\scriptsize X_{-n} )X-n à value % p.
  2.   1. Construit le moteur avec une suite de germes seq. Étant donné std::size_t(w / 32) + 1 comme k, l'état initial du moteur est déterminé comme suit :

  1. Le constructeur de copie. Lors de la construction, *this == other est true.
