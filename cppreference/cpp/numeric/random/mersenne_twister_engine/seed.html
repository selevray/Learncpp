std::mersenne_twister_engine<UIntType,w,n,m,r,a,u,d,s,b,t,c,l,f>::seed

void seed( result_type value = default_seed );  // (1) (depuis C++11)

template< class SeedSeq >
void seed( SeedSeq& seq );  // (2) (depuis C++11)

Définit l'état du moteur de nombres pseudo-aléatoires.

  1. Juste après la définition de l'état, *this == std::mersenne_twister_engine(value) est true.

  2. Juste après la définition de l'état, *this == std::mersenne_twister_engine(seq) est true.

Paramètres

  • value — valeur de germe à utiliser pour définir l'état
  • seq — suite de germes à utiliser pour définir l'état

Exceptions

  1. Si SeedSeq n'est pas std::seed_seq, lève les exceptions levées par l'appel seq.generate.

Complexité

  1. Identique à std::mersenne_twister_engine(value).

  2. Identique à std::mersenne_twister_engine(seq).

Exemple

#include <iostream>
#include <random>

int main()
{
    std::mt19937 gen;

    // Initialise le moteur avec un unsigned int
    gen.seed(1);
    std::cout << "after seed by 1: " << gen() << '\n';

    // Initialise le moteur avec deux unsigned int
    std::seed_seq sseq{1, 2};
    gen.seed(sseq);
    std::cout << "after seed by {1,2}: " << gen() << '\n';
}
