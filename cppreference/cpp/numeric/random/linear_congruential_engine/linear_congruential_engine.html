Construit le moteur de nombres pseudo-aléatoires.

  1. Le constructeur par défaut.
  • Si le moteur construit par défaut est de type std::minstd_rand0, la 10000e invocation consécutive de celui-ci produit la valeur 1043618065.
  • Si le moteur construit par défaut est de type std::minstd_rand, la 10000e invocation consécutive de celui-ci produit la valeur 399268537.
  1. Construit le moteur avec une valeur de germe value. L'état initial du moteur est déterminé comme suit :
  • Si c % m == 0 et value % m == 0 valent tous deux true, l'état est 1.
  • Sinon, l'état est value % m.
  1. Construit le moteur avec une suite de germes seq. Étant donné std::size_t(std::log2(m) / 32) + 1 comme k, l'état initial du moteur est déterminé comme suit :
  1. Crée un objet tableau fictif a de longueur k + 3.
  2. Appelle seq.generate(a + 0, a + k + 3).
  3. Soit S égal à (\scriptsize (\sum^{k-1}{j=0} a{j+3} \cdot 2^{32j}) \mod m )(∑k-1
    j=0 aj+3·232j
    ) mod m.
  4. Si c % m == 0 et S == 0 valent tous deux true, définit l'état du moteur à 1. Sinon, définit l'état du moteur à S.

Cette surcharge ne participe à la résolution de surcharge que si SeedSeq satisfait les exigences de SeedSequence.

  1. Le constructeur de copie. Lors de la construction, *this == other est true.

Paramètres

  • value — valeur de germe à utiliser pour l'initialisation de l'état interne
  • seq — suite de germes à utiliser pour l'initialisation de l'état interne

Complexité

1,2) Constante.

  1. Identique à la complexité de l'appel seq.generate.

  2. Constante.

Exceptions

  1. Si SeedSeq n'est pas std::seed_seq, lève les exceptions levées par l'appel seq.generate.
