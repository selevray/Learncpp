std::random_device::entropy

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

double entropy() const noexcept;  // (depuis C++11)

Obtient une estimation de l'entropie du périphérique de nombres aléatoires, qui est une valeur à virgule flottante comprise entre 0 et log2(max()+1) (égale à std::numeric_limits<unsigned int>::digits). Si le périphérique possède n états dont les probabilités individuelles sont P0,...,Pn-1, l'entropie du périphérique S est définie comme

S = −∑n-1
i=0 Pilog(Pi)

Un générateur de nombres aléatoires déterministe (par exemple un moteur pseudo-aléatoire) a une entropie nulle.

Valeur de retour

La valeur de l'entropie du périphérique, ou zéro si cela ne s'applique pas.

Notes

Cette fonction n'est pas entièrement implémentée dans certaines bibliothèques standard. Par exemple, LLVM libc++ antérieure à la version 12 renvoie toujours zéro bien que le périphérique soit non déterministe. En comparaison, l'implémentation de Microsoft Visual C++ renvoie toujours 32, et boost.random renvoie 10.

L'entropie du périphérique du noyau Linux /dev/urandom peut être obtenue en utilisant ioctl RNDGETENTCNT — c'est ce qu'utilise std::random_device::entropy() dans GNU libstdc++ à partir de la version 8.1.

Exemple

Exemple de sortie sur l'une des implémentations

#include <iostream>
#include <random>

int main()
{
    std::random_device rd;
    std::cout << rd.entropy() << '\n';
}
