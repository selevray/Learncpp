template<
    class Engine,
    std::size_t K
> class shuffle_order_engine;  // (depuis C++11)

shuffle_order_engine est un adaptateur de moteur de nombres aléatoires qui mélange les nombres aléatoires générés par le moteur de base. Il maintient une table de taille K et fournit un nombre choisi aléatoirement dans cette table lorsqu'on le demande, en le remplaçant par un nombre généré par le moteur de base.
