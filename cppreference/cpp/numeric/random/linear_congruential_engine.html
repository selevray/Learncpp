linear_congruential_engine est un moteur de nombres pseudo-aléatoires basé sur un générateur congruentiel linéaire (LCG).

Paramètres de modèle

  • UIntType — Le type de résultat généré par le générateur. Le comportement est indéfini si ce n'est pas l'un de unsigned short, unsigned int, unsigned long ou unsigned long long.
  • a — le terme multiplicatif
  • c — le terme d'incrément
  • m — le terme de module

Lorsque m n'est pas nul, si a >= m ou c >= m vaut true, le programme est mal formé.

Propriétés du générateur

La taille des états de linear_congruential_engine est 1, chacun d'eux étant constitué d'un unique entier.

Le module effectif (\scriptsize m_0)m0 est défini comme suit :

  • Si m n'est pas nul, (\scriptsize m_0)m0 vaut m.
  • Si m est nul, (\scriptsize m_0)m0 vaut la valeur de std::numeric_limits<result_type>::max() plus 1 (ce qui signifie que (\scriptsize m_0)m0 n'a pas besoin d'être représentable en result_type).

L'algorithme de transition de linear_congruential_engine est (\scriptsize TA(x_i) = (a \cdot x_i + c)\mod m_0)TA(xi) = (a·xi+c) mod m0.

L'algorithme de génération de linear_congruential_engine est (\scriptsize GA(x_i) = (a \cdot x_i + c)\mod m_0)GA(xi) = (a·xi+c) mod m0.

Le nombre pseudo-aléatoire généré avec l'état courant est aussi l'état suivant.
