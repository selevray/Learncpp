template<
    class Engine,
    std::size_t P, std::size_t R
> class discard_block_engine;  // (depuis C++11)

discard_block_engine est un adaptateur de moteur de nombres pseudo-aléatoires qui écarte une certaine quantité de données produites par le moteur de base. De chaque bloc de taille P généré par le moteur de base, l'adaptateur ne conserve que R nombres, en écartant le reste.

Paramètres de modèle

  • Engine — le type du moteur encapsulé.
  • P — la taille d'un bloc. Il est attendu que (\small{P>0})P > 0.
  • R — le nombre de nombres utilisés par bloc. Il est attendu que (\small{0<R\le P})0 < R ≤ P.

Exigences sur les types

  • Engine doit satisfaire aux exigences de RandomNumberEngine.
