std::generate_canonical

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <random>

template< class RealType, std::size_t Bits, class Generator >
RealType generate_canonical( Generator& g );  // (depuis C++11)

Génère un nombre aléatoire à virgule flottante dans l'intervalle [0,1).

Pour générer suffisamment d'entropie, generate_canonical() appellera g() exactement (\small k)k fois, où (\small k = \max(1, \lceil \frac{b}{\log_2 R} \rceil))k = max(1, ⌈ b / log2 R ⌉) et

  • b = std::min(Bits, std::size_t {std::numeric_limits<RealType>::digits}),
  • R = g.max() - g.min() + 1.

Paramètres

  • g — générateur à utiliser pour acquérir de l'entropie

Valeur de retour

Valeur à virgule flottante dans l'intervalle [0,1).

Exceptions

Aucune, à l'exception de celles levées par g.

Notes

Certaines implémentations existantes ont un bogue qui peut occasionnellement renvoyer 1.0 si RealType vaut float GCC #63176 LLVM #18767 MSVC STL #1074. Il s'agit de LWG issue 2524.

Exemple

Produit des nombres aléatoires avec 10 bits d'aléa : cela ne peut produire que k * R valeurs distinctes.

#include <iostream>
#include <random>

int main()
{
    std::random_device rd;
    std::mt19937 gen(rd());
    for (int n = 0; n < 10; ++n)
        std::cout << std::generate_canonical<double, 10>(gen) << ' ';
    std::cout << '\n';
}
