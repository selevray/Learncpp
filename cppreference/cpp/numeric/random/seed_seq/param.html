std::seed_seq::param

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class OutputIt >
void param( OutputIt dest ) const;  // (depuis C++11)

Copie les graines stockées dans l'intervalle commençant par dest. Équivalent à std::copy(v ﻿.begin(), v ﻿.end(), dest);.

Si les valeurs de type result_type ne sont pas writable vers dest, le programme est mal formé.

Si OutputIt ne satisfait pas aux exigences de LegacyOutputIterator, le comportement est indéfini.

Paramètres

  • dest — l'itérateur de début de l'intervalle de sortie

Exceptions

Ne lève que les exceptions levées par les opérations sur dest.

Exemple

#include <iostream>
#include <iterator>
#include <random>

int main()
{
    std::seed_seq s1 = {-1, 0, 1};
    s1.param(std::ostream_iterator<int>(std::cout, " "));
}

Output:

-1 0 1
