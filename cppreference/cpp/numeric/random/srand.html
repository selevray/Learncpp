void srand( unsigned seed );

Initialise le générateur de nombres pseudo-aléatoires utilisé par std::rand() avec la valeur seed.

Si std::rand() est utilisé avant tout appel à srand(), std::rand() se comporte comme s'il avait été initialisé avec srand(1).

Chaque fois que std::rand() est initialisé avec la même seed, il doit produire la même séquence de valeurs.

srand() n'est pas garanti thread-safe.

Paramètres

  • seed — la valeur de graine

Valeur de retour

(aucune)

Notes

En règle générale, le générateur de nombres pseudo-aléatoires ne doit être initialisé qu'une seule fois, avant tout appel à rand(), au début du programme. Il ne doit pas être réinitialisé de façon répétée, ni à chaque fois que l'on souhaite générer un nouveau lot de nombres pseudo-aléatoires.

La pratique standard consiste à utiliser le résultat d'un appel à std::time(0) comme graine. Cependant, std::time renvoie une valeur std::time_t, et std::time_t n'est pas garanti être de type entier. En pratique, toutefois, toutes les implémentations majeures définissent std::time_t comme un type entier, ce que POSIX exige également.

Exemple

#include <cstdlib>
#include <ctime>
#include <iostream>

int main()
{
    std::srand(std::time(0)); // utilise l'heure courante comme graine pour le générateur aléatoire
    std::cout << "Random value on [0, " << RAND_MAX << "]: " << std::rand() << '\n';
}

Sortie possible :

Random value on [0, 2147483647]: 1373858591
