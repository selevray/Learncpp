std::piecewise_constant_distribution

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <random>

template< class RealType = double >
class piecewise_constant_distribution;  // (depuis C++11)

std::piecewise_constant_distribution produit des nombres flottants aléatoires, uniformément répartis dans chacun des plusieurs sous-intervalles [bi, bi+1), chacun avec son propre poids wi. L'ensemble des bornes des intervalles et l'ensemble des poids sont les paramètres de cette distribution.

La densité de probabilité pour tout bi ≤ x <bi+1 est
wi
S (bi+1 - bi)

, où S est la somme de tous les poids.

std::piecewise_constant_distribution satisfait toutes les exigences de RandomNumberDistribution.

Paramètres de modèle

  • RealType — Le type de résultat produit par le générateur. L'effet est indéfini si ce n'est pas l'un de float, double ou long double.

Types membres

Type membre Définition

  • result_type (C++11) — RealType
  • param_type (C++11) — le type de l'ensemble de paramètres, voir RandomNumberDistribution.

  • (constructeur) (C++11) — construit une nouvelle distribution (fonction membre publique)
  • reset (C++11) — réinitialise l'état interne de la distribution (fonction membre publique)

  • operator() (C++11) — génère le nombre aléatoire suivant de la distribution (fonction membre publique)

##### Caractéristiques {#Characteristics}

  • intervalsdensities — renvoie les paramètres de distribution (fonction membre publique)
  • param (C++11) — obtient ou définit l'objet de paramètre de distribution (fonction membre publique)
  • min (C++11) — renvoie la valeur minimale potentiellement générée (fonction membre publique)

Exemple

#include <iostream>
#include <map>
#include <random>
#include <string>

int main()
{
    std::random_device rd;
    std::mt19937 gen(rd());
    // 50 % du temps, générer un nombre aléatoire entre 0 et 1
    // 50 % du temps, générer un nombre aléatoire entre 10 et 15
    std::vector<double> i {0, 1, 10, 15};
    std::vector<double> w {1, 0, 1};
    std::piecewise_constant_distribution<> d(i.begin(), i.end(), w.begin());

    std::map<int, int> hist;
    for (int n {}; n < 1e4; ++n)
        ++hist[d(gen)];

    for (std::cout << std::hex << std::uppercase; auto [x, y] : hist)
        std::cout << x << ' ' << std::string(y / 100, '*') << '\n';
}
