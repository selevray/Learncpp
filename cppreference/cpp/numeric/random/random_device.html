std::random_device

class random_device;  // (depuis C++11)

std::random_device est un générateur de nombres aléatoires entiers à distribution uniforme qui produit des nombres non déterministes.

std::random_device peut être implémenté à l'aide d'un moteur de nombres pseudo-aléatoires défini par l'implémentation si une source non déterministe (par exemple un périphérique matériel) n'est pas disponible pour l'implémentation. Dans ce cas, chaque objet std::random_device peut générer la même suite de nombres.

Notes

Une implémentation notable où std::random_device est déterministe dans les anciennes versions de MinGW-w64 (bug 338, corrigé depuis GCC 9.2). Les dernières versions de MinGW-w64 peuvent être téléchargées depuis GCC with the MCF thread model.

Exemple

#include <iostream>
#include <map>
#include <random>
#include <string>

int main()
{
    std::random_device rd;
    std::map<int, int> hist;
    std::uniform_int_distribution<int> dist(0, 9);

    for (int n = 0; n != 20000; ++n)
        ++hist[dist(rd)]; // remarque : démonstration uniquement : les performances de nombreuses
                          // implémentations de random_device se dégradent fortement
                          // une fois le réservoir d'entropie épuisé. En pratique,
                          // random_device n'est généralement utilisé que pour initialiser
                          // un PRNG tel que mt19937

    for (auto [x, y] : hist)
        std::cout << x << " : " << std::string(y / 100, '*') << '\n';
}
