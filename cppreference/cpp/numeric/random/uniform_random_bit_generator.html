std::uniform_random_bit_generator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <random>

template< class G >
concept uniform_random_bit_generator =
    std::invocable<G&> && std::unsigned_integral<std::invoke_result_t<G&>> &&
    requires {
        { G::min() } -> std::same_as<std::invoke_result_t<G&>>;
        { G::max() } -> std::same_as<std::invoke_result_t<G&>>;
        requires std::bool_constant<(G::min() < G::max())>::value;
    };  // (depuis C++20)

Le concept uniform_random_bit_generator<G> spécifie que G est le type d'un générateur de bits aléatoires uniformes, c'est-à-dire que les objets de type G sont un objet fonction renvoyant des valeurs entières non signées telles que chaque valeur de l'intervalle des résultats possibles a (idéalement) une probabilité égale d'être renvoyée.

Exigences sémantiques

uniform_random_bit_generator<G> n'est modélisé que si, pour tout objet g de type G :

  • g() appartient à l'intervalle [G::min(),G::max()],
  • g() a une complexité constante amortie.

Notes

Pour satisfaire l'exigence std::bool_constant<(G::min() < G::max())>::value, G::min() et G::max() doivent tous deux être des expressions constantes, et le résultat de la comparaison doit être true.
