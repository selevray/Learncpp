Produit des valeurs entières non négatives aléatoires i, distribuées selon la fonction de probabilité discrète :

(P(i|k, p) = \binom{k + i - 1}{i} \cdot p^k \cdot (1 - p)^i)P(i|k,p) =⎛

La valeur représente le nombre d'échecs dans une série d'essais indépendants oui/non (chacun réussit avec une probabilité p), avant que exactement k succès ne surviennent.

std::negative_binomial_distribution satisfait RandomNumberDistribution.

Exemple

#include <iomanip>
#include <iostream>
#include <map>
#include <random>
#include <string>

int main()
{
    std::random_device rd;
    std::mt19937 gen(rd());
    // Pat fait du porte-à-porte pour vendre des biscuits
    // À chaque maison, il y a 75 % de chances qu'elle vende une boîte
    // combien de fois sera-t-elle éconduite avant de vendre 5 boîtes ?
    std::negative_binomial_distribution<> d(5, 0.75);

    std::map<int, int> hist;
    for (int n = 0; n != 10000; ++n)
        ++hist[d(gen)];

    for (auto [x, y] : hist)
        std::cout << std::hex << x << ' ' << std::string(y / 100, '*') << '\n';
}
