template<

    std::size_t W,
    class UIntType
> class independent_bits_engine;  // (depuis C++11)

independent_bits_engine est un adaptateur de moteur de nombres aléatoires qui produit des nombres aléatoires avec un nombre de bits différent de celui du moteur encapsulé.

Paramètres de modèle

  • Engine — le type du moteur encapsulé
  • W — le nombre de bits que les nombres générés doivent avoir
  • UIntType — le type des nombres pseudo-aléatoires générés. Le comportement est indéfini sauf si ce paramètre est non qualifié cv et est l'un de unsigned short, unsigned int, unsigned long ou unsigned long long.

Exigences sur les types

  • Engine doit satisfaire aux exigences de RandomNumberEngine.
  • W doit être strictement supérieur à zéro, et non supérieur à std::numeric_limits<UIntType>::digits.
