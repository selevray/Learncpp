std::exponential_distribution

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <random>

template< class RealType = double >
class exponential_distribution;  // (depuis C++11)

Produit des valeurs à virgule flottante non négatives aléatoires (\small x)x, distribuées selon la fonction de densité de probabilité :

(\small P(x|\lambda) = \lambda e^{-\lambda x})P(x|λ) = λe-λx

La valeur obtenue est le temps ou la distance jusqu'au prochain événement aléatoire si des événements aléatoires se produisent à taux constant (\small\lambda)λ par unité de temps ou de distance. Par exemple, cette distribution décrit le temps entre les clics d'un compteur Geiger ou la distance entre les mutations ponctuelles dans un brin d'ADN.

C'est l'équivalent continu de std::geometric_distribution.

std::exponential_distribution satisfait RandomNumberDistribution.

Paramètres de modèle

  • RealType — Le type de résultat produit par le générateur. L'effet est indéfini si ce n'est pas l'un de float, double ou long double.

  • result_type (C++11) — RealType
  • param_type (C++11) — le type de l'ensemble de paramètres, voir RandomNumberDistribution.

Notes

Certaines implémentations peuvent parfois renvoyer l'infini si RealType vaut float. Il s'agit de LWG issue 2524.

Exemple

#include <iomanip>
#include <iostream>
#include <map>
#include <random>
#include <string>

int main()
{
    std::random_device rd;
    std::mt19937 gen(rd());

    // si les particules se désintègrent en moyenne une fois par seconde,
    // combien de temps, en secondes, jusqu'à la suivante ?
    std::exponential_distribution<> d(1);

    std::map<int, int> hist;
    for (int n = 0; n != 10000; ++n)
        ++hist[2 * d(gen)];

    for (auto const& [x, y] : hist)
        std::cout << std::fixed << std::setprecision(1)
                  << x / 2.0 << '-' << (x + 1) / 2.0 << ' '
                  << std::string(y / 200, '*') << '\n';
}
