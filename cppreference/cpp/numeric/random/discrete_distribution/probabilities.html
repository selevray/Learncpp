std::discrete_distribution<IntType>::probabilities

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

std::vector<double> probabilities() const;  // (depuis C++11)

Obtient un std::vector<double> contenant les probabilités individuelles de chaque entier généré par cette distribution.

Paramètres

(aucune)

Valeur de retour

Un objet de type std::vector<double>.

Exemple

#include <iostream>
#include <random>
#include <vector>

int main()
{
    std::discrete_distribution<> d({40, 10, 10, 40});
    std::vector<double> p = d.probabilities();
    for (auto n : p)
        std::cout << n << ' ';
    std::cout << '\n';
}

Output:

0.4 0.1 0.1 0.4
