std::discrete_distribution<IntType>::discrete_distribution

template< class InputIt >

Construit un nouvel objet de distribution.

  1. Constructeur par défaut. Construit la distribution avec un poids unique p = {1}. Cette distribution génère toujours 0.

  2. Construit la distribution avec des poids dans l'intervalle [first,last). Si first == last, les effets sont les mêmes que ceux du constructeur par défaut.

  3. Construit la distribution avec des poids dans weights. Appelle effectivement discrete_distribution(weights.begin(), weights.end()).

  4. Construit la distribution avec count poids générés à l'aide de la fonction unary_op. Chacun des poids est égal à wi = unary_op(xmin + δ(i + 0.5)), où δ =
(xmax − xmin)
count

et i ∈ {0, ..., count − 1}. xmin et xmax doivent être tels que δ > 0. Si count == 0 les effets sont les mêmes que ceux du constructeur par défaut.

  1. Construit la distribution avec params comme paramètres de distribution.

Paramètres

  • first, last — l'intervalle d'éléments définissant les nombres à utiliser comme poids. Le type des éléments référencés par InputIterator doit être convertible en double

  • weights — liste d'initialisation contenant les poids

  • unary_op — objet fonction unaire qui sera appliqué.

    La signature de la fonction doit être équivalente à la suivante :

    Ret fun(const Type &a);

    La signature n'a pas besoin d'avoir const &.
    Le type Type doit être tel qu'un objet de type double puisse être déréférencé puis implicitement converti en Type. Le type Ret doit être tel qu'un objet de type double puisse être déréférencé et qu'on puisse lui affecter une valeur de type Ret.

  • params — l'ensemble des paramètres de distribution

Exigences sur les types

  • InputIt doit satisfaire aux exigences de LegacyInputIterator.
