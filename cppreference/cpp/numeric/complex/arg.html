std::arg(std::complex)

Surcharges supplémentaires (depuis C++11)

Défini dans l'en-tête <complex>

float       arg( float f );
double      arg( double f );
long double arg( long double f );  // (jusqu'à C++23)

template< class FloatingPoint >
FloatingPoint
            arg( FloatingPoint f );  // (depuis C++23)

template< class Integer >
double      arg( Integer i );  // (B)
  1. Calcule l'argument (en radians) du nombre complexe z.

A,B) Des surcharges supplémentaires sont fournies pour tous les types entiers et à virgule flottante, qui sont traités comme des nombres complexes dont la partie imaginaire est nulle.

(depuis C++11)

Paramètres

  • z — valeur complexe
  • f — valeur à virgule flottante
  • i — valeur entière

Valeur de retour

  1. std::atan2(std::imag(z), std::real(z)). Si aucune erreur ne se produit, il s'agit de l'argument de z dans l'intervalle [−π; π].

A) Zéro si f est positif ou +0, π si f est négatif ou -0, NaN sinon.

B) Zéro si i est non négatif, π s'il est négatif.

Notes

Les surcharges supplémentaires ne sont pas tenues d'être fournies exactement comme (A,B). Elles doivent seulement suffire à garantir que pour leur argument num :

  • Si num a un type à virgule flottante standard (jusqu'à C++23) T, alors std::arg(num) a le même effet que std::arg(std::complex<T>(num)).
  • Sinon, si num a un type entier, alors std::arg(num) a le même effet que std::arg(std::complex<double>(num)).

Exemple

#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z1(1, 0);
    std::complex<double> z2(0, 0);
    std::complex<double> z3(0, 1);
    std::complex<double> z4(-1, 0);
    std::complex<double> z5(-1, -0.0);
    double f = 1.;
    int i = -1;

    std::cout << "phase angle of " << z1 << " is " << std::arg(z1) << '\n'
              << "phase angle of " << z2 << " is " << std::arg(z2) << '\n'
              << "phase angle of " << z3 << " is " << std::arg(z3) << '\n'
              << "phase angle of " << z4 << " is " << std::arg(z4) << '\n'
              << "phase angle of " << z5 << " is " << std::arg(z5) << " "
                 "(the other side of the cut)\n"
              << "phase angle of " << f << " is " << std::arg(f) << '\n'
              << "phase angle of " << i << " is " << std::arg(i) << '\n';

}

Output:

phase angle of (1,0) is 0
phase angle of (0,0) is 0
phase angle of (0,1) is 1.5708
phase angle of (-1,0) is 3.14159
phase angle of (-1,-0) is -3.14159 (the other side of the cut)
phase angle of 1 is 0
phase angle of -1 is 3.14159
