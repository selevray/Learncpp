template< class T >
complex<T> tanh( const complex<T>& z );  // (depuis C++11)

Calcule la tangente hyperbolique complexe d'une valeur complexe z.

Paramètres

  • z — valeur complexe

Valeur de retour

Si aucune erreur ne se produit, la tangente hyperbolique complexe de z est renvoyée.

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées de manière cohérente avec math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • std::tanh(std::conj(z)) == std::conj(std::tanh(z)).
  • std::tanh(-z) == -std::tanh(z).
  • Si z vaut (+0,+0), le résultat est (+0,+0).
  • Si z vaut (x,+∞) (pour tout x fini[1]), le résultat est (NaN,NaN) et FE_INVALID est levée.
  • Si z vaut (x,NaN) (pour tout x fini[2]), le résultat est (NaN,NaN) et FE_INVALID peut être levée.
  • Si z vaut (+∞,y) (pour tout y fini positif), le résultat est (1,+0).
  • Si z vaut (+∞,+∞), le résultat est (1,±0) (le signe de la partie imaginaire n'est pas spécifié).
  • Si z vaut (+∞,NaN), le résultat est (1,±0) (le signe de la partie imaginaire n'est pas spécifié).
  • Si z vaut (NaN,+0), le résultat est (NaN,+0).
  • Si z vaut (NaN,y) (pour tout y non nul), le résultat est (NaN,NaN) et FE_INVALID peut être levée.
  • Si z vaut (NaN,NaN), le résultat est (NaN,NaN).
  1. ↑ selon C11 DR471, ceci n'est valable que pour x non nul. Si z vaut (0,∞), le résultat devrait être (0,NaN).
  2. ↑ selon C11 DR471, ceci n'est valable que pour x non nul. Si z vaut (0,NaN), le résultat devrait être (0,NaN).

Notes

La définition mathématique de la tangente hyperbolique est tanh z =
ez -e-z
ez +e-z

.

La tangente hyperbolique est une fonction analytique sur le plan complexe et n'a aucune coupure de branche. Elle est périodique par rapport à la composante imaginaire, de période πi, et possède des pôles du premier ordre le long de la droite imaginaire, aux coordonnées (0, π(1/2 + n)). Cependant, aucune représentation courante en virgule flottante ne peut représenter π/2 exactement, il n'existe donc aucune valeur de l'argument pour laquelle une erreur de pôle se produit.

Exemple

#include <cmath>
#include <complex>
#include <iostream>

int main()
{
    std::cout << std::fixed;
    std::complex<double> z(1.0, 0.0); // se comporte comme la tangente hyperbolique réelle le long de la droite réelle
    std::cout << "tanh" << z << " = " << std::tanh(z)
              << " (tanh(1) = " << std::tanh(1) << ")\n";

    std::complex<double> z2(0.0, 1.0); // se comporte comme la tangente le long de la droite imaginaire
    std::cout << "tanh" << z2 << " = " << std::tanh(z2)
              << " ( tan(1) = " << std::tan(1) << ")\n";
}

Output:

tanh(1.000000,0.000000) = (0.761594,0.000000) (tanh(1) = 0.761594)
tanh(0.000000,1.000000) = (0.000000,1.557408) ( tan(1) = 1.557408)
