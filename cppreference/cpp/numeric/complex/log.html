template< class T >
std::complex<T> log( const std::complex<T>& z );

Calcule le logarithme naturel complexe (de base e) d'une valeur complexe z, avec une coupure de branche le long de l'axe réel négatif.

Paramètres

  • z — valeur complexe

Valeur de retour

Si aucune erreur ne se produit, le logarithme naturel complexe de z est renvoyé, dans l'intervalle d'une bande de largeur [−iπ, +iπ] le long de l'axe imaginaire et mathématiquement non borné le long de l'axe réel.

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées de manière cohérente avec math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • La fonction est continue au niveau de la coupure de branche en tenant compte du signe de la partie imaginaire
  • std::log(std::conj(z)) == std::conj(std::log(z))
  • Si z vaut (-0,+0), le résultat est (-∞,π) et FE_DIVBYZERO est levé
  • Si z vaut (+0,+0), le résultat est (-∞,+0) et FE_DIVBYZERO est levé
  • Si z vaut (x,+∞) (pour tout x fini), le résultat est (+∞,π/2)
  • Si z vaut (x,NaN) (pour tout x fini), le résultat est (NaN,NaN) et FE_INVALID peut être levé
  • Si z vaut (-∞,y) (pour tout y fini positif), le résultat est (+∞,π)
  • Si z vaut (+∞,y) (pour tout y fini positif), le résultat est (+∞,+0)
  • Si z vaut (-∞,+∞), le résultat est (+∞,3π/4)
  • Si z vaut (+∞,+∞), le résultat est (+∞,π/4)
  • Si z vaut (±∞,NaN), le résultat est (+∞,NaN)
  • Si z vaut (NaN,y) (pour tout y fini), le résultat est (NaN,NaN) et FE_INVALID peut être levé
  • Si z vaut (NaN,+∞), le résultat est (+∞,NaN)
  • Si z vaut (NaN,NaN), le résultat est (NaN,NaN)

Notes

Le logarithme naturel d'un nombre complexe z dont les composantes en coordonnées polaires sont (r,θ) vaut ln r + i(θ+2nπ), avec la valeur principale ln r + iθ.

La sémantique de cette fonction est destinée à être cohérente avec la fonction C clog.

Exemple

#include <cmath>
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z {0.0, 1.0}; // r = 1, θ = pi / 2
    std::cout << "2 * log" << z << " = " << 2.0 * std::log(z) << '\n';

    std::complex<double> z2 {sqrt(2.0) / 2, sqrt(2.0) / 2}; // r = 1, θ = pi / 4
    std::cout << "4 * log" << z2 << " = " << 4.0 * std::log(z2) << '\n';

    std::complex<double> z3 {-1.0, 0.0}; // r = 1, θ = pi
    std::cout << "log" << z3 << " = " << std::log(z3) << '\n';
    std::complex<double> z4 {-1.0, -0.0}; // l'autre côté de la coupure
    std::cout << "log" << z4 << " (the other side of the cut) = " << std::log(z4) << '\n';
}

Sortie possible :

2 * log(0,1) = (0,3.14159)
4 * log(0.707107,0.707107) = (0,3.14159)
log(-1,0) = (0,3.14159)
log(-1,-0) (the other side of the cut) = (0,-3.14159)
