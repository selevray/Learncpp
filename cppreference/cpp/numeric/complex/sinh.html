template< class T >
complex<T> sinh( const complex<T>& z );  // (depuis C++11)

Calcule le sinus hyperbolique complexe d'une valeur complexe z.

Paramètres

  • z — valeur complexe

Valeur de retour

Si aucune erreur ne se produit, le sinus hyperbolique complexe de z est renvoyé.

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées de manière cohérente avec math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • std::sinh(std::conj(z)) == std::conj(std::sinh(z))
  • std::sinh(z) == -std::sinh(-z)
  • Si z vaut (+0,+0), le résultat est (+0,+0)
  • Si z vaut (+0,+∞), le résultat est (±0,NaN) (le signe de la partie réelle n'est pas spécifié) et FE_INVALID est levé
  • Si z vaut (+0,NaN), le résultat est (±0,NaN)
  • Si z vaut (x,+∞) (pour tout x fini positif), le résultat est (NaN,NaN) et FE_INVALID est levée
  • Si z vaut (x,NaN) (pour tout x fini positif), le résultat est (NaN,NaN) et FE_INVALID peut être levée
  • Si z vaut (+∞,+0), le résultat est (+∞,+0)
  • Si z vaut (+∞,y) (pour tout y fini positif), le résultat est +∞cis(y)
  • Si z vaut (+∞,+∞), le résultat est (±∞,NaN) (le signe de la partie réelle n'est pas spécifié) et FE_INVALID est levé
  • Si z vaut (+∞,NaN), le résultat est (±∞,NaN) (le signe de la partie réelle n'est pas spécifié)
  • Si z vaut (NaN,+0), le résultat est (NaN,+0)
  • Si z vaut (NaN,y) (pour tout y fini non nul), le résultat est (NaN,NaN) et FE_INVALID peut être levé
  • Si z vaut (NaN,NaN), le résultat est (NaN,NaN)

où cis(y) vaut cos(y) + i sin(y).

Notes

La définition mathématique du sinus hyperbolique est sinh z =
ez -e-z
2

.

Le sinus hyperbolique est une fonction entière dans le plan complexe et n'a aucune coupure de branche. Elle est périodique par rapport à la composante imaginaire, de période 2πi.

Exemple

#include <cmath>
#include <complex>
#include <iostream>

int main()
{
    std::cout << std::fixed;
    std::complex<double> z(1.0, 0.0); // se comporte comme le sinh réel le long de la droite réelle
    std::cout << "sinh" << z << " = " << std::sinh(z)
              << " (sinh(1) = " << std::sinh(1) << ")\n";

    std::complex<double> z2(0.0, 1.0); // se comporte comme le sinus le long de la droite imaginaire
    std::cout << "sinh" << z2 << " = " << std::sinh(z2)
              << " ( sin(1) = " << std::sin(1) << ")\n";
}

Output:

sinh(1.000000,0.000000) = (1.175201,0.000000) (sinh(1) = 1.175201)
sinh(0.000000,1.000000) = (0.000000,0.841471) ( sin(1) = 0.841471)
