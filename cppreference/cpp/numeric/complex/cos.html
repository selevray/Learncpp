template< class T >
complex<T> cos( const complex<T>& z );

Calcule le cosinus complexe d'une valeur complexe z.

Paramètres

  • z — valeur complexe

Valeur de retour

Si aucune erreur ne se produit, le cosinus complexe de z est renvoyé.

Les erreurs et les cas particuliers sont traités comme si l'opération était implémentée par std::cosh(i * z), où i est l'unité imaginaire.

Notes

Le cosinus est une fonction entière sur le plan complexe et n'a pas de coupures de branche.

La définition mathématique du cosinus est cos z =
eiz +e-iz
2

.

Exemple

#include <cmath>
#include <complex>
#include <iostream>

int main()
{
    std::cout << std::fixed;
    std::complex<double> z(1.0, 0.0); // se comporte comme le cosinus réel le long de la droite réelle
    std::cout << "cos" << z << " = " << std::cos(z)
              << " ( cos(1) = " << std::cos(1) << ")\n";

    std::complex<double> z2(0.0, 1.0); // se comporte comme le cosh réel le long de la droite imaginaire
    std::cout << "cos" << z2 << " = " << std::cos(z2)
              << " (cosh(1) = " << std::cosh(1) << ")\n";
}

cos(0.000000,1.000000) = (1.543081,-0.000000) (cosh(1) = 1.543081)
