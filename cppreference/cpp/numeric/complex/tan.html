template< class T >
complex<T> tan( const complex<T>& z );

Calcule la tangente complexe d'une valeur complexe z.

Paramètres

  • z — valeur complexe

Valeur de retour

Si aucune erreur ne se produit, la tangente complexe de z est renvoyée.

Les erreurs et les cas particuliers sont traités comme si l'opération était implémentée par -i * std::tanh(i * z), où i est l'unité imaginaire.

Notes

La tangente est une fonction analytique sur le plan complexe et n'a aucune coupure de branche. Elle est périodique par rapport à la composante réelle, de période πi, et possède des pôles du premier ordre le long de la droite réelle, aux coordonnées (π(1/2 + n), 0). Cependant, aucune représentation courante en virgule flottante ne peut représenter π/2 exactement, il n'existe donc aucune valeur de l'argument pour laquelle une erreur de pôle se produit.

La définition mathématique de la tangente est tan z =
i(e-iz -eiz )
e-iz +eiz

.

Exemple

#include <cmath>
#include <complex>
#include <iostream>

int main()
{
    std::cout << std::fixed;
    std::complex<double> z(1.0, 0.0); // se comporte comme la tangente réelle le long de la droite réelle
    std::cout << "tan" << z << " = " << std::tan(z)
              << " ( tan(1) = " << std::tan(1) << ")\n";

    std::complex<double> z2(0.0, 1.0); // se comporte comme tanh le long de la droite imaginaire
    std::cout << "tan" << z2 << " = " << std::tan(z2)
              << " (tanh(1) = " << std::tanh(1) << ")\n";
}

Output:

tan(1.000000,0.000000) = (1.557408,0.000000) ( tan(1) = 1.557408)
tan(0.000000,1.000000) = (0.000000,0.761594) (tanh(1) = 0.761594)
