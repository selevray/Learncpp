std::sin(std::complex)

template< class T >
complex<T> sin( const complex<T>& z );

Calcule le sinus complexe d'une valeur complexe z.

Paramètres

  • z — valeur complexe

Valeur de retour

Si aucune erreur ne se produit, le sinus complexe de z est renvoyé.

Les erreurs et les cas particuliers sont traités comme si l'opération était implémentée par -i * std::sinh(i * z), où i est l'unité imaginaire.

Notes

Le sinus est une fonction entière sur le plan complexe et n'a aucune coupure de branche.

La définition mathématique du sinus est sin z =
eiz -e-iz
2i

.

Exemple

#include <cmath>
#include <complex>
#include <iostream>

int main()
{
    std::cout << std::fixed;
    std::complex<double> z(1.0, 0.0); // se comporte comme le sinus réel le long de la droite réelle
    std::cout << "sin" << z << " = " << std::sin(z)
              << " ( sin(1) = " << std::sin(1) << ")\n";

    std::complex<double> z2(0.0, 1.0); // se comporte comme sinh le long de la droite imaginaire
    std::cout << "sin" << z2 << " = " << std::sin(z2)
              << " (sinh(1) = " << std::sinh(1) << ")\n";
}

Output:

sin(1.000000,0.000000) = (0.841471,0.000000) ( sin(1) = 0.841471)
sin(0.000000,1.000000) = (0.000000,1.175201) (sinh(1) = 1.175201)
