std::asinh(std::complex)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <complex>

template< class T >
complex<T> asinh( const complex<T>& z );  // (depuis C++11)

Calcule l'arc sinus hyperbolique complexe d'une valeur complexe z, avec des coupures de branche à l'extérieur de l'intervalle [−i; +i] le long de l'axe imaginaire.

Paramètres

  • z — valeur complexe

Valeur de retour

Si aucune erreur ne se produit, l'arc sinus hyperbolique complexe de z est renvoyé, dans l'intervalle d'une bande mathématiquement non bornée le long de l'axe réel et dans l'intervalle [−iπ/2; +iπ/2] le long de l'axe imaginaire.

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées de manière cohérente avec math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • std::asinh(std::conj(z)) == std::conj(std::asinh(z))
  • std::asinh(-z) == -std::asinh(z)
  • Si z vaut (+0,+0), le résultat est (+0,+0)
  • Si z vaut (x,+∞) (pour tout x fini positif), le résultat est (+∞,π/2)
  • Si z vaut (x,NaN) (pour tout x fini), le résultat est (NaN,NaN) et FE_INVALID peut être levé
  • Si z vaut (+∞,y) (pour tout y fini positif), le résultat est (+∞,+0)
  • Si z vaut (+∞,+∞), le résultat est (+∞,π/4)
  • Si z vaut (+∞,NaN), le résultat est (+∞,NaN)
  • Si z vaut (NaN,+0), le résultat est (NaN,+0)
  • Si z vaut (NaN,y) (pour tout y fini non nul), le résultat est (NaN,NaN) et FE_INVALID peut être levé
  • Si z vaut (NaN,+∞), le résultat est (±∞,NaN) (le signe de la partie réelle n'est pas spécifié)
  • Si z vaut (NaN,NaN), le résultat est (NaN,NaN)

Notes

Bien que la norme C++ nomme cette fonction « arc sinus hyperbolique complexe », les fonctions inverses des fonctions hyperboliques sont les fonctions d'aire. Leur argument est l'aire d'un secteur hyperbolique, et non un arc. Le nom correct est « sinus hyperbolique inverse complexe » et, moins courant, « sinus hyperbolique d'aire complexe ».

Le sinus hyperbolique inverse est une fonction multivaluée et nécessite une coupure de branche dans le plan complexe. La coupure de branche est conventionnellement placée sur les segments de droite (-i∞,-i) et (i,i∞) de l'axe imaginaire.

La définition mathématique de la valeur principale du sinus hyperbolique inverse est asinh z = ln(z + √1+z2
).

Exemple

#include <complex>
#include <iostream>

int main()
{
    std::cout << std::fixed;
    std::complex<double> z1(0.0, -2.0);
    std::cout << "asinh" << z1 << " = " << std::asinh(z1) << '\n';

    std::complex<double> z2(-0.0, -2);
    std::cout << "asinh" << z2 << " (the other side of the cut) = "
              << std::asinh(z2) << '\n';

    // pour tout z, asinh(z) = asin(iz) / i
    std::complex<double> z3(1.0, 2.0);
    std::complex<double> i(0.0, 1.0);
    std::cout << "asinh" << z3 << " = " << std::asinh(z3) << '\n'
              << "asin" << z3 * i << " / i = " << std::asin(z3 * i) / i << '\n';
}

Output:

asinh(0.000000,-2.000000) = (1.316958,-1.570796)
asinh(-0.000000,-2.000000) (the other side of the cut) = (-1.316958,-1.570796)
asinh(1.000000,2.000000) = (1.469352,1.063440)
asin(-2.000000,1.000000) / i = (1.469352,1.063440)
