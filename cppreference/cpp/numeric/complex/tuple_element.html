std::tuple_element<std::complex>

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <complex>

template< std::size_t I, class T >
struct tuple_element<I, std::complex<T>>;  // (depuis C++26)

Les spécialisations partielles de std::tuple_element pour std::complex donnent un accès à la compilation au type de nombre réel et imaginaire sous-jacent d'un complex, à l'aide d'une syntaxe semblable à celle des tuples. Elles sont fournies pour la prise en charge des liaisons structurées. Le programme est mal formé si I >= 2.

Exemple

#include <complex>
#include <type_traits>

static_assert([z = std::complex<float>()]
{
    using T = decltype(z);
    return
#if __cpp_lib_tuple_like >= 202311L
        std::is_same_v<std::tuple_element_t<0, T>, float> &&
        std::is_same_v<std::tuple_element_t<1, T>, float> &&
#endif
        std::is_same_v<T::value_type, float>;
}());

int main() {}
