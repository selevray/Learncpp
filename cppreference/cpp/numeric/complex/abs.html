template< class T >
T abs( const complex<T>& z );

Renvoie le module du nombre complexe z.

Paramètres

  • z — valeur complexe

Valeur de retour

Si aucune erreur ne se produit, renvoie la valeur absolue (également appelée norme, module ou magnitude) de z.

Les erreurs et les cas particuliers sont traités comme si la fonction était implémentée par std::hypot(std::real(z), std::imag(z)).

Exemple

#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(1, 1);
    std::cout << z << " cartesian is rho = " << std::abs(z)
              << " theta = " << std::arg(z) << " polar\n";
}

Output:

(1,1) cartesian is rho = 1.41421 theta = 0.785398 polar
