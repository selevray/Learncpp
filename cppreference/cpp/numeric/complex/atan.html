std::atan(std::complex)

template< class T >
complex<T> atan( const complex<T>& z );  // (depuis C++11)

Calcule l'arc tangente complexe d'une valeur complexe z. Une coupure de branche existe à l'extérieur de l'intervalle [−i, +i] le long de l'axe imaginaire.

Paramètres

  • z — valeur complexe

Valeur de retour

Si aucune erreur ne se produit, l'arc tangente complexe de z est renvoyée, dans l'intervalle d'une bande non bornée le long de l'axe imaginaire et dans l'intervalle [−π/2, +π/2] le long de l'axe réel.

Les erreurs et les cas particuliers sont traités comme si l'opération était implémentée par -i * std::atanh(i * z), où i est l'unité imaginaire.

Notes

La tangente inverse (ou arc tangente) est une fonction multivaluée et nécessite une coupure de branche dans le plan complexe. La coupure de branche est conventionnellement placée sur les segments de droite (-∞i,-i) et (+i,+∞i) de l'axe imaginaire.

La définition mathématique de la valeur principale de la tangente inverse est atan z = -
1
2

i [ln(1 - iz) - ln (1 + iz)].

Exemple

#include <cmath>
#include <complex>
#include <iostream>

int main()
{
    std::cout << std::fixed;
    std::complex<double> z1(0.0, 2.0);
    std::cout << "atan" << z1 << " = " << std::atan(z1) << '\n';

    std::complex<double> z2(-0.0, 2.0);
    std::cout << "atan" << z2 << " (the other side of the cut) = "
              << std::atan(z2) << '\n';

    std::complex<double> z3(0.0, INFINITY);
    std::cout << "2 * atan" << z3 << " = " << 2.0 * std::atan(z3) << '\n';
}

Output:

atan(0.000000,2.000000) = (1.570796,0.549306)
atan(-0.000000,2.000000) (the other side of the cut) = (-1.570796,0.549306)
2 * atan(0.000000,inf) = (3.141593,0.000000)
