std::cosh(std::complex)

template< class T >
complex<T> cosh( const complex<T>& z );  // (depuis C++11)

Calcule le cosinus hyperbolique complexe d'une valeur complexe z.

Paramètres

  • z — valeur complexe

Valeur de retour

Si aucune erreur ne se produit, le cosinus hyperbolique complexe de z est renvoyé.

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées de manière cohérente avec math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • std::cosh(std::conj(z)) == std::conj(std::cosh(z))
  • std::cosh(z) == std::cosh(-z)
  • Si z vaut (+0,+0), le résultat est (1,+0)
  • Si z vaut (+0,+∞), le résultat est (NaN,±0) (le signe de la partie imaginaire n'est pas spécifié) et FE_INVALID est levé
  • Si z vaut (+0,NaN), le résultat est (NaN,±0) (le signe de la partie imaginaire est non spécifié)
  • Si z vaut (x,+∞) (pour tout x fini non nul), le résultat est (NaN,NaN) et FE_INVALID est levé
  • Si z vaut (x,NaN) (pour tout x fini non nul), le résultat est (NaN,NaN) et FE_INVALID peut être levé
  • Si z vaut (+∞,+0), le résultat est (+∞,+0)
  • Si z vaut (+∞,y) (pour tout y fini non nul), le résultat est +∞cis(y)
  • Si z vaut (+∞,+∞), le résultat est (±∞,NaN) (le signe de la partie réelle n'est pas spécifié) et FE_INVALID est levé
  • Si z vaut (+∞,NaN), le résultat est (+∞,NaN)
  • Si z vaut (NaN,+0), le résultat est (NaN,±0) (le signe de la partie imaginaire est non spécifié)
  • Si z vaut (NaN,+y) (pour tout y fini non nul), le résultat est (NaN,NaN) et FE_INVALID peut être levé
  • Si z vaut (NaN,NaN), le résultat est (NaN,NaN)

où cis(y) vaut cos(y) + i sin(y).

Notes

La définition mathématique du cosinus hyperbolique est cosh z =
ez +e-z

.

Le cosinus hyperbolique est une fonction entière dans le plan complexe et n'a pas de coupures de branche. Elle est périodique par rapport à la composante imaginaire, de période 2πi.

Exemples

#include <cmath>
#include <complex>
#include <iostream>

int main()
{
    std::cout << std::fixed;
    std::complex<double> z(1.0, 0.0); // se comporte comme le cosh réel le long de la droite réelle
    std::cout << "cosh" << z << " = " << std::cosh(z)
              << " (cosh(1) = " << std::cosh(1) << ")\n";

    std::complex<double> z2(0.0, 1.0); // se comporte comme le cosinus réel le long de la droite imaginaire
    std::cout << "cosh" << z2 << " = " << std::cosh(z2)
              << " ( cos(1) = " << std::cos(1) << ")\n";
}

Output:

cosh(1.000000,0.000000) = (1.543081,0.000000) (cosh(1) = 1.543081)
cosh(0.000000,1.000000) = (0.540302,0.000000) ( cos(1) = 0.540302)
