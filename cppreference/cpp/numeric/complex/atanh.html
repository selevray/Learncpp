std::atanh(std::complex)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <complex>

template< class T >
complex<T> atanh( const complex<T>& z );  // (depuis C++11)

Calcule l'arc tangente hyperbolique complexe de z, avec des coupures de branche à l'extérieur de l'intervalle [−1; +1] le long de l'axe réel.

Paramètres

  • z — valeur complexe

Valeur de retour

Si aucune erreur ne se produit, l'arc tangente hyperbolique complexe de z est renvoyée, dans l'intervalle d'une demi-bande mathématiquement non bornée le long de l'axe réel et dans l'intervalle [−iπ/2; +iπ/2] le long de l'axe imaginaire.

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées de manière cohérente avec math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • std::atanh(std::conj(z)) == std::conj(std::atanh(z))
  • std::atanh(-z) == -std::atanh(z)
  • Si z vaut (+0,+0), le résultat est (+0,+0)
  • Si z vaut (+0,NaN), le résultat est (+0,NaN)
  • Si z vaut (+1,+0), le résultat est (+∞,+0) et FE_DIVBYZERO est levé
  • Si z vaut (x,+∞) (pour tout x fini positif), le résultat est (+0,π/2)
  • Si z vaut (x,NaN) (pour tout x fini non nul), le résultat est (NaN,NaN) et FE_INVALID peut être levé
  • Si z vaut (+∞,y) (pour tout y fini positif), le résultat est (+0,π/2)
  • Si z vaut (+∞,+∞), le résultat est (+0,π/2)
  • Si z vaut (+∞,NaN), le résultat est (+0,NaN)
  • Si z vaut (NaN,y) (pour tout y fini), le résultat est (NaN,NaN) et FE_INVALID peut être levé
  • Si z vaut (NaN,+∞), le résultat est (±0,π/2) (le signe de la partie réelle n'est pas spécifié)
  • Si z vaut (NaN,NaN), le résultat est (NaN,NaN)

Notes

Bien que la norme C++ nomme cette fonction « arc tangente hyperbolique complexe », les fonctions inverses des fonctions hyperboliques sont les fonctions d'aire. Leur argument est l'aire d'un secteur hyperbolique, et non un arc. Le nom correct est « tangente hyperbolique inverse complexe » et, moins courant, « tangente hyperbolique d'aire complexe ».

La tangente hyperbolique inverse est une fonction multivaluée et nécessite une coupure de branche dans le plan complexe. La coupure de branche est conventionnellement placée sur les segments de droite (-∞,-1] et [+1,+∞) de l'axe réel.

La définition mathématique de la valeur principale de la tangente hyperbolique inverse est atanh z =

Exemple

#include <complex>
#include <iostream>

int main()
{
    std::cout << std::fixed;
    std::complex<double> z1(2.0, 0.0);
    std::cout << "atanh" << z1 << " = " << std::atanh(z1) << '\n';

    std::complex<double> z2(2.0, -0.0);
    std::cout << "atanh" << z2 << " (the other side of the cut) = "
              << std::atanh(z2) << '\n';

    // pour tout z, atanh(z) = atanh(iz) / i
    std::complex<double> z3(1.0, 2.0);
    std::complex<double> i(0.0, 1.0);
    std::cout << "atanh" << z3 << " = " << std::atanh(z3) << '\n'
              << "atan" << z3 * i << " / i = " << std::atan(z3 * i) / i << '\n';
}

Output:

atanh(2.000000,0.000000) = (0.549306,1.570796)
atanh(2.000000,-0.000000) (the other side of the cut) = (0.549306,-1.570796)
atanh(1.000000,2.000000) = (0.173287,1.178097)
atan(-2.000000,1.000000) / i = (0.173287,1.178097)
