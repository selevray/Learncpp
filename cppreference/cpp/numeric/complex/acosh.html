std::acosh(std::complex)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <complex>

template< class T >
complex<T> acosh( const complex<T>& z );  // (depuis C++11)

Calcule l'arc cosinus hyperbolique complexe d'une valeur complexe z, avec une coupure de branche pour les valeurs inférieures à 1 le long de l'axe réel.

Paramètres

  • z — valeur complexe

Valeur de retour

Si aucune erreur ne se produit, l'arc cosinus hyperbolique complexe de z est renvoyé, dans l'intervalle d'une demi-bande de valeurs non négatives le long de l'axe réel et dans l'intervalle [−iπ; +iπ] le long de l'axe imaginaire.

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées de manière cohérente avec math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • std::acosh(std::conj(z)) == std::conj(std::acosh(z)).
  • Si z vaut (±0,+0), le résultat est (+0,π/2).
  • Si z vaut (x,+∞) (pour tout x fini), le résultat est (+∞,π/2).
  • Si z vaut (x,NaN) (pour tout[1] x fini), le résultat est (NaN,NaN) et FE_INVALID peut être levé.
  • Si z vaut (-∞,y) (pour tout y fini positif), le résultat est (+∞,π).
  • Si z vaut (+∞,y) (pour tout y fini positif), le résultat est (+∞,+0).
  • Si z vaut (-∞,+∞), le résultat est (+∞,3π/4).
  • Si z vaut (±∞,NaN), le résultat est (+∞,NaN).
  • Si z vaut (NaN,y) (pour tout y fini), le résultat est (NaN,NaN) et FE_INVALID peut être levé.
  • Si z vaut (NaN,+∞), le résultat est (+∞,NaN).
  • Si z vaut (NaN,NaN), le résultat est (NaN,NaN).
  1. ↑ selon C11 DR471, cela n'est vrai que pour x non nul. Si z vaut (0,NaN), le résultat doit être (NaN,π/2).

Notes

Bien que la norme C++ nomme cette fonction « arc cosinus hyperbolique complexe », les fonctions inverses des fonctions hyperboliques sont les fonctions d'aire. Leur argument est l'aire d'un secteur hyperbolique, et non un arc. Le nom correct est « cosinus hyperbolique inverse complexe », et, plus rarement, « cosinus hyperbolique d'aire complexe ».

Le cosinus hyperbolique inverse est une fonction multivaluée et nécessite une coupure de branche sur le plan complexe. La coupure de branche est conventionnellement placée sur le segment de droite (-∞,+1) de l'axe réel.

La définition mathématique de la valeur principale du cosinus hyperbolique inverse est acosh z = ln(z + √z+1 √z-1).

Pour tout z, acosh(z) =
√z-1
√1-z

acos(z), ou simplement i acos(z) dans le demi-plan supérieur du plan complexe.

Exemple

#include <complex>
#include <iostream>

int main()
{
    std::cout << std::fixed;
    std::complex<double> z1(0.5, 0);
    std::cout << "acosh" << z1 << " = " << std::acosh(z1) << '\n';

    std::complex<double> z2(0.5, -0.0);
    std::cout << "acosh" << z2 << " (the other side of the cut) = "
              << std::acosh(z2) << '\n';

    // dans le demi-plan supérieur, acosh = i acos
    std::complex<double> z3(1, 1), i(0, 1);
    std::cout << "acosh" << z3 << " = " << std::acosh(z3) << '\n'
              << "i*acos" << z3 << " = " << i*std::acos(z3) << '\n';
}

Output:

acosh(0.500000,0.000000) = (0.000000,-1.047198)
acosh(0.500000,-0.000000) (the other side of the cut) = (0.000000,1.047198)
acosh(1.000000,1.000000) = (1.061275,0.904557)
i*acos(1.000000,1.000000) = (1.061275,0.904557)
