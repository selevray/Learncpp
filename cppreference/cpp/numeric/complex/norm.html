Notes

La norme calculée par cette fonction est aussi appelée norme de corps ou carré absolu.

La norme euclidienne d'un nombre complexe est fournie par std::abs, dont le calcul est plus coûteux. Dans certaines situations, elle peut être remplacée par std::norm, par exemple si abs(z1) > abs(z2) alors norm(z1) > norm(z2).

Les surcharges supplémentaires ne sont pas tenues d'être fournies exactement comme (A,B). Elles doivent seulement suffire à garantir que pour leur argument num :

  • Si num a un type à virgule flottante standard (jusqu'à C++23) T, alors std::norm(num) a le même effet que std::norm(std::complex<T>(num)).
  • Sinon, si num a un type entier, alors std::norm(num) a le même effet que std::norm(std::complex<double>(num)).

Exemple

#include <cassert>
#include <complex>
#include <iostream>

int main()
{
    constexpr std::complex<double> z {3.0, 4.0};
    static_assert(std::norm(z) == (z.real() * z.real() + z.imag() * z.imag()));
    static_assert(std::norm(z) == (z * std::conj(z)));
           assert(std::norm(z) == (std::abs(z) * std::abs(z)));
    std::cout << "std::norm(" << z << ") = " << std::norm(z) << '\n';
}

Output:

std::norm((3,4)) = 25
