std::countl_zero

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <bit>

template< class T >
constexpr int countl_zero( T x ) noexcept;  // (depuis C++20)

Renvoie le nombre de bits consécutifs 0 dans la valeur de x, à partir du bit de poids fort (« gauche »).

Cette surcharge participe à la résolution de surcharge uniquement si T est un type entier non signé (c'est-à-dire unsigned char, unsigned short, unsigned int, unsigned long, unsigned long long, ou un type entier non signé étendu).

Paramètres

  • x — valeur de type entier non signé

Valeur de retour

Le nombre de bits consécutifs 0 dans la valeur de x, à partir du bit de poids fort.

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_bitops 201907L (C++20) Opérations sur les bits

Exemple

#include <bit>
#include <bitset>
#include <cstdint>
#include <iostream>

int main()
{
    for (const std::uint8_t i : {0, 0b11111111, 0b11110000, 0b00011110})
        std::cout << "countl_zero( " << std::bitset<8>(i) << " ) = "
                  << std::countl_zero(i) << '\n';
}

Output:

countl_zero( 00000000 ) = 8
countl_zero( 11111111 ) = 0
countl_zero( 11110000 ) = 0
countl_zero( 00011110 ) = 3
