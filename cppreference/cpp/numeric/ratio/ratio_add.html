std::ratio_add

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ratio>

template< class R1, class R2 >
using ratio_add = /* voir ci-dessous */;  // (depuis C++11)

Le modèle d'alias std::ratio_add désigne le résultat de l'addition de deux fractions rationnelles exactes représentées par les spécialisations std::ratio R1 et R2.

Le résultat est une spécialisation std::ratio std::ratio<U, V>, telle que, étant donnés Num == R1::num * R2::den + R2::num * R1::den et Denom == R1::den * R2::den (calculés sans débordement arithmétique), U vaut std::ratio<Num, Denom>::num et V vaut std::ratio<Num, Denom>::den.

Notes

Si U ou V n'est pas représentable dans std::intmax_t, le programme est mal formé. Si Num ou Denom n'est pas représentable dans std::intmax_t, le programme est mal formé, sauf si l'implémentation fournit des valeurs correctes pour U et V.

La définition ci-dessus exige que le résultat de std::ratio_add<R1, R2> soit déjà réduit à ses termes les plus simples ; par exemple, std::ratio_add<std::ratio<1, 3>, std::ratio<1, 6>> est du même type que std::ratio<1, 2>.

Exemple

#include <iostream>
#include <ratio>

int main()
{
    using two_third = std::ratio<2, 3>;
    using one_sixth = std::ratio<1, 6>;
    using sum = std::ratio_add<two_third, one_sixth>;

    std::cout << "2/3 + 1/6 = " << sum::num << '/' << sum::den << '\n';
}

Output:

2/3 + 1/6 = 5/6
