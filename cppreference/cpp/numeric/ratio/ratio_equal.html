std::ratio_equal

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ratio>

template< class R1, class R2 >
struct ratio_equal : std::integral_constant<bool, /* voir ci-dessous */> { };  // (depuis C++11)

Si les rapports R1 et R2 sont égaux, fournit la constante membre value égale à true. Sinon, value vaut false.

Modèle de variable auxiliaire

template< class R1, class R2 >
constexpr bool ratio_equal_v = ratio_equal<R1, R2>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si R1::num == R2::num && R1::den == R2::den, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Implémentation possible

template< class R1, class R2 >
struct ratio_equal : public std::integral_constant <
                                 bool,
                                 R1::num == R2::num && R1::den == R2::den
                            > {};

Exemple

#include <iostream>
#include <ratio>

int main()
{
    constexpr bool equ = std::ratio_equal_v<std::ratio<2,3>,
                                            std::ratio<6,9>>;
    static_assert(equ);
    std::cout << "2/3 " << (equ ? "==" : "!=") << " 6/9\n";
}

Output:

2/3 == 6/9
