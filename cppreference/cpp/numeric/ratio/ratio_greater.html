std::ratio_greater

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ratio>

template< class R1, class R2 >
struct ratio_greater : std::integral_constant<bool, /* voir ci-dessous */> { };  // (depuis C++11)

Si le rapport R1 est supérieur au rapport R2, fournit la constante membre value égale à true. Sinon, value vaut false.

Modèle de variable auxiliaire

template< class R1, class R2 >
constexpr bool ratio_greater_v = ratio_greater<R1, R2>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si R1::num * R2::den > R2::num * R1::den, ou expression équivalente évitant le débordement, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Exemple

#include <iostream>
#include <ratio>

int main()
{
    static_assert(std::ratio_greater<std::ratio<3, 4>, std::ratio<1, 2>>::value,
                  "3/4 > 1/2");

    if (std::ratio_greater<std::ratio<11, 12>, std::ratio<10, 11>>::value)
        std::cout << "11/12 > 10/11" "\n";

    // Depuis C++17
    static_assert(std::ratio_greater_v<std::ratio<12, 13>, std::ratio<11, 12>>);

    if constexpr (std::ratio_greater_v<std::ratio<12, 13>, std::ratio<11, 12>>)
        std::cout << "12/13 > 11/12" "\n";
}

Output:

11/12 > 10/11
12/13 > 11/12
