std::ratio_greater_equal

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ratio>

template< class R1, class R2 >
struct ratio_greater_equal : std::integral_constant<bool, /* voir ci-dessous */> { };  // (depuis C++11)

Si le rapport R1 est supérieur ou égal au rapport R2, fournit la constante membre value égale à true. Sinon, value vaut false.

Modèle de variable auxiliaire

template< class R1, class R2 >
constexpr bool ratio_greater_equal_v = ratio_greater_equal<R1, R2>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si R1::num * R2::den >= R2::num * R1::den, ou expression équivalente évitant le débordement, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Exemple

#include <ratio>

int main()
{
    static_assert(std::ratio_greater_equal<
        std::ratio<2, 3>,
        std::ratio<2, 3>>::value, "2/3 >= 2/3");

    // depuis C++17
    static_assert(std::ratio_greater_equal_v<
        std::ratio<999'998, 999'999>,
        std::ratio<999'997, 999'998>>);
}
