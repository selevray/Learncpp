std::sub_sat

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <numeric>

template< class T >
constexpr T sub_sat( T x, T y ) noexcept;  // (depuis C++26)

Calcule la soustraction saturante x - y. Cette opération (contrairement aux opérations arithmétiques sur les entiers natives) se comporte comme si c'était une opération mathématique avec un intervalle infini. Soit q le résultat d'une telle opération. Renvoie :

  • q, si q est représentable comme une valeur de type T. Sinon,
  • la plus grande ou la plus petite valeur de type T, selon celle qui est la plus proche de q.

Cette surcharge participe à la résolution de surcharge uniquement si T est un type entier, c'est-à-dire : signed char, short, int, long, long long, un type entier signé étendu, ou une version non signée de ces types. En particulier, T ne doit pas être (éventuellement qualifié cv) bool, char, wchar_t, char8_t, char16_t ou char32_t, car ces types ne sont pas destinés à l'arithmétique.

Paramètres

  • x, y — valeurs entières

Valeur de retour

x - y saturé.

Notes

Contrairement aux opérateurs arithmétiques intégrés sur les entiers, la promotion intégrale ne s'applique pas aux arguments x et y.

Si deux arguments de types différents sont passés, l'appel ne compile pas, c'est-à-dire que le comportement relatif à la déduction d'arguments de modèle est le même que pour std::min ou std::max.

La plupart des architectures matérielles modernes prennent efficacement en charge l'arithmétique par saturation sur les vecteurs SIMD, notamment SSE2 pour x86 et NEON pour ARM.

Implémentation possible

Voir libstdc++ (gcc).

Exemple

Peut être prévisualisé sur Compiler Explorer

#include <climits>
#include <numeric>

static_assert
(""
    && (std::sub_sat<int>(INT_MIN + 4, 3) == INT_MIN + 1) // non saturé
    && (std::sub_sat<int>(INT_MIN + 4, 5) == INT_MIN) // saturated
    && (std::sub_sat<int>(INT_MAX - 4, -3) == INT_MAX - 1) // non saturé
    && (std::sub_sat<int>(INT_MAX - 4, -5) == INT_MAX) // saturated
    && (std::sub_sat<unsigned>(4, 3) == 1) // non saturé
    && (std::sub_sat<unsigned>(4, 5) == 0) // saturated
);

int main() {}
