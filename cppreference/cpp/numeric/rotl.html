std::rotl

Défini dans l'en-tête <bit>

template< class T >
constexpr T rotl( T x, int s ) noexcept;  // (depuis C++20)

Calcule le résultat de la rotation binaire vers la gauche de la valeur de x de s positions. Cette opération est également connue sous le nom de décalage circulaire vers la gauche.

Formellement, soit N égal à std::numeric_limits<T>::digits et r égal à s % N.

  • Si r est 0, retourne x ;
  • si r est positif, retourne (x << r) | (x >> (N - r)) ;
  • si r est négatif, retourne std::rotr(x, -r).

Cette surcharge participe à la résolution de surcharge uniquement si T est un type entier non signé (c'est-à-dire unsigned char, unsigned short, unsigned int, unsigned long, unsigned long long, ou un type entier non signé étendu).

Paramètres

  • x — valeur de type entier non signé
  • s — nombre de positions de décalage

Valeur de retour

Le résultat de la rotation binaire vers la gauche de x de s positions.

Notes

Exemple

#include <bit>
#include <bitset>
#include <cstdint>
#include <iostream>

int main()
{
    using bin = std::bitset<8>;
    const std::uint8_t x{0b00011101};
    std::cout << bin(x) << " <- x\n";
    for (const int s : {0, 1, 4, 9, -1})
        std::cout << bin(std::rotl(x, s)) << " <- rotl(x, " << s << ")\n";
}

Output:

00011101 <- x
00011101 <- rotl(x, 0)
00111010 <- rotl(x, 1)
11010001 <- rotl(x, 4)
00111010 <- rotl(x, 9)
10001110 <- rotl(x, -1)
