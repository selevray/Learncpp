std::bit_floor

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <bit>

template< class T >
constexpr T bit_floor( T x ) noexcept;  // (depuis C++20)

Si x n'est pas nul, calcule la plus grande puissance entière de deux qui ne soit pas supérieure à x. Si x vaut zéro, renvoie zéro.

Cette surcharge participe à la résolution de surcharge uniquement si T est un type entier non signé (c'est-à-dire unsigned char, unsigned short, unsigned int, unsigned long, unsigned long long, ou un type entier non signé étendu).

Paramètres

  • x — valeur entière non signée

Valeur de retour

Zéro si x vaut zéro ; sinon, la plus grande puissance entière de deux qui ne soit pas supérieure à x.

Notes

Avant P1956R1, le nom proposé pour ce modèle de fonction était floor2.

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_int_pow2 202002L (C++20) Opérations entières sur les puissances de 2

Implémentation possible

template<std::unsigned_integral T>
    requires !std::same_as<T, bool> && !std::same_as<T, char> &&
             !std::same_as<T, char8_t> && !std::same_as<T, char16_t> &&
             !std::same_as<T, char32_t> && !std::same_as<T, wchar_t>
constexpr T bit_floor(T x) noexcept
{
    if (x != 0)
        return T{1} << (std::bit_width(x) - 1);
    return 0;
}

Exemple

#include <bit>
#include <bitset>
#include <iostream>

int main()
{
    using bin = std::bitset<8>;
    for (unsigned x{}; x != 012; ++x)
        std::cout << "bit_floor( " << bin(x) << " ) = "
                  << bin(std::bit_floor(x)) << '\n';
}
