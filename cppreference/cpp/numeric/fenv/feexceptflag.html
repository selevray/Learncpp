int fegetexceptflag( std::fexcept_t* flagp, int excepts );  // (1) (depuis C++11)

int fesetexceptflag( const std::fexcept_t* flagp, int excepts );  // (2) (depuis C++11)

  1. Tente d'obtenir le contenu complet des indicateurs d'exception à virgule flottante listés dans l'argument masque de bits excepts, qui est un OU bit à bit des macros d'exception à virgule flottante.

  2. Tente de copier le contenu complet des indicateurs d'exception à virgule flottante listés dans excepts depuis flagp vers l'environnement à virgule flottante. Ne lève aucune exception, modifie uniquement les indicateurs.

Le contenu complet d'un indicateur d'exception à virgule flottante n'est pas nécessairement une valeur booléenne indiquant si l'exception est levée ou effacée. Par exemple, il peut s'agir d'une struct qui contient l'état booléen et l'adresse du code ayant déclenché l'exception. Ces fonctions obtiennent l'ensemble de ce contenu et le lisent ou l'écrivent dans flagp dans un format défini par l'implémentation.

Paramètres

  • flagp — pointeur vers un objet std::fexcept_t où les indicateurs seront stockés ou lus
  • excepts — masque de bits listant les indicateurs d'exception à lire ou à définir

Valeur de retour

0 en cas de succès, valeur non nulle sinon.
