std::fetestexcept

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cfenv>

int fetestexcept( int excepts );  // (depuis C++11)

Détermine lesquelles des exceptions à virgule flottante du sous-ensemble spécifié sont actuellement positionnées. L'argument excepts est un OU bit à bit des macros d'exception à virgule flottante.

Paramètres

  • excepts — masque de bits listant les indicateurs d'exception à tester

Valeur de retour

OU bit à bit des macros d'exception à virgule flottante qui sont à la fois incluses dans excepts et correspondent à des exceptions à virgule flottante actuellement positionnées.

Exemple

#include <cfenv>
#include <cmath>
#include <iostream>

// #pragma STDC FENV_ACCESS ON

volatile double zero = 0.0; // volatile inutile là où FENV_ACCESS est pris en charge
volatile double one = 1.0;  // volatile inutile là où FENV_ACCESS est pris en charge

int main()
{
    std::feclearexcept(FE_ALL_EXCEPT);
    std::cout <<  "1.0/0.0 = " << 1.0 / zero << '\n';
    if (std::fetestexcept(FE_DIVBYZERO))
        std::cout << "division by zero reported\n";
    else
        std::cout << "division by zero not reported\n";

    std::feclearexcept(FE_ALL_EXCEPT);
    std::cout << "1.0/10 = " << one / 10 << '\n';
    if (std::fetestexcept(FE_INEXACT))
        std::cout << "inexact result reported\n";
    else
        std::cout << "inexact result not reported\n";

    std::feclearexcept(FE_ALL_EXCEPT);
    std::cout << "sqrt(-1) = " << std::sqrt(-1) << '\n';
    if (std::fetestexcept(FE_INVALID))
        std::cout << "invalid result reported\n";
    else
        std::cout << "invalid result not reported\n";
}

Sortie possible :

1.0/0.0 = inf
division by zero reported
1.0/10 = 0.1
inexact result reported
sqrt(-1) = -nan
invalid result reported
