std::begin(std::valarray)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class T >
/* voir ci-dessous */ begin( valarray<T>& v );  // (1) (depuis C++11)

template< class T >
/* voir ci-dessous */ begin( const valarray<T>& v );  // (2) (depuis C++11)

La surcharge de std::begin pour valarray renvoie un itérateur de type non spécifié désignant le premier élément du tableau numérique.

  1. Le type de retour doit
  • satisfaire les exigences de mutable LegacyRandomAccessIterator,
  • modélise contiguous_iterator,

(depuis C++20)

  • avoir un type membre value_type, qui est T, et
  • avoir un type membre reference, qui est T&.
  1. Le type de retour doit
  • satisfaire les exigences de constant LegacyRandomAccessIterator,
  • modélise contiguous_iterator,

(depuis C++20)

  • avoir un type membre value_type, qui est T, et
  • avoir un type membre reference, qui est const T&.

L'itérateur renvoyé par cette fonction est invalidé lorsque la fonction membre resize() est appelée sur v ou lorsque la durée de vie de v se termine, selon l'événement qui survient en premier.

Paramètres

  • v — un tableau numérique

Valeur de retour

Itérateur vers la première valeur du tableau numérique.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Notes

Contrairement aux autres fonctions qui prennent des arguments std::valarray, begin() ne peut pas accepter les types de remplacement (tels que les types produits par les modèles d'expressions) pouvant être renvoyés par des expressions impliquant des valarray : std::begin(v1 + v2) n'est pas portable, std::begin(std::valarray<T>(v1 + v2)) doit être utilisé à la place.

L'objectif de cette fonction est de permettre aux boucles range for de fonctionner avec les valarray, et non de fournir une sémantique de conteneur.

Exemple

#include <algorithm>
#include <iostream>
#include <valarray>

void show(const std::valarray<int>& v)
{
    std::for_each(std::begin(v), std::end(v), [](int c)
    {
        std::cout << c << ' ';
    });
    std::cout << '\n';
};

int main()
{
    const std::valarray<int> x{47, 70, 37, 52, 90, 23, 17, 33, 22, 16, 21, 4};
    const std::valarray<int> y{25, 31, 71, 56, 21, 21, 15, 34, 21, 27, 12, 6};

    show(x);
    show(y);

    const std::valarray<int> z{x + y};

    for (char c : z)
        std::cout << c;
}

Output:

47 70 37 52 90 23 17 33 22 16 21 4
25 31 71 56 21 21 15 34 21 27 12 6
Hello, C++!
