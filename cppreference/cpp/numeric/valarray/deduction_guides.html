guides de déduction pour std::valarray

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <valarray>

template< typename T, std::size_t cnt >
valarray( const T(&)[cnt], std::size_t ) -> valarray<T>;  // (depuis C++17)

Ce guide de déduction est fourni pour std::valarray afin de permettre la déduction à partir d'un tableau et d'une taille (notez que la déduction à partir d'un pointeur et d'une taille est couverte par les guides implicites).

Exemple

#include <iostream>
#include <valarray>

int main()
{
    int a[] = {1, 2, 3, 4};
    std::valarray va(a, 3); // utilise un guide de déduction explicite
    for (int x : va)
        std::cout << x << ' ';
    std::cout << '\n';
}

Output:

1 2 3
