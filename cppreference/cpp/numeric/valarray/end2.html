std::end(std::valarray)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class T >
/* voir ci-dessous */ end( valarray<T>& v );  // (1) (depuis C++11)

template< class T >
/* voir ci-dessous */ end( const valarray<T>& v );  // (2) (depuis C++11)

La surcharge de std::end pour valarray renvoie un itérateur de type non spécifié désignant la position qui suit le dernier élément du tableau numérique.

  1. Le type de retour doit
  • satisfaire les exigences de mutable LegacyRandomAccessIterator,
  • modélise contiguous_iterator,

(depuis C++20)

  • avoir un type membre value_type, qui est T, et
  • avoir un type membre reference, qui est T&.
  1. Le type de retour doit
  • satisfaire les exigences de constant LegacyRandomAccessIterator,
  • modélise contiguous_iterator,

(depuis C++20)

  • avoir un type membre value_type, qui est T, et
  • avoir un type membre reference, qui est const T&.

L'itérateur renvoyé par cette fonction est invalidé lorsque la fonction membre resize() est appelée sur v ou lorsque la durée de vie de v se termine, selon l'événement qui survient en premier.

Paramètres

  • v — un tableau numérique

Valeur de retour

Itérateur vers la position qui suit la dernière valeur du tableau numérique.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Notes

Contrairement aux autres fonctions qui prennent des arguments std::valarray, end() ne peut pas accepter les types de remplacement (tels que les types produits par les modèles d'expressions) pouvant être renvoyés par des expressions impliquant des valarray : std::end(v1 + v2) n'est pas portable, std::end(std::valarray<T>(v1 + v2)) doit être utilisé à la place.

L'objectif de cette fonction est de permettre aux boucles range for de fonctionner avec les valarray, et non de fournir une sémantique de conteneur.

Exemple

#include <algorithm>
#include <iostream>
#include <valarray>

int main()
{
    const std::valarray<char> va
    {
        'H', 'e', 'l', 'l', 'o',
        ',', ' ',
        'C', '+', '+', '!', '\n'
    };

    std::for_each(std::begin(va), std::end(va),
                  [](char c){ std::cout << c; });
}

Output:

Hello, C++!
