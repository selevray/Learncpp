std::valarray<T>::max

T max() const;

Calcule la valeur maximale des éléments.

Si le tableau ne contient aucun élément, le comportement est indéfini.

La fonction ne peut être utilisée que si operator< est défini pour le type T.

Paramètres

(aucune)

Valeur de retour

Le maximum des éléments.

Exemple

#include <valarray>
#include <iostream>

int main()
{
    std::valarray<double> a{1, 2, 3, 4, 5, 6, 7, 8};
    std::cout << "Maximum value : " << a.max() << "\n";
}

Output:

Maximum value : 8
