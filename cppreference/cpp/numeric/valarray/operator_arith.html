Applique les opérateurs unaires à chaque élément du tableau numérique.

Paramètres

(aucune)

Valeur de retour

Un tableau numérique contenant des éléments dont les valeurs sont obtenues en appliquant l'opérateur correspondant aux valeurs de *this.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Notes

Chacun des opérateurs ne peut être instancié que si les exigences suivantes sont satisfaites :

  • L'opérateur indiqué peut être appliqué au type T.
  • La valeur du résultat peut être convertie sans ambiguïté en T (1-3) ou en bool (4).

La fonction peut être implémentée avec un type de retour différent de std::valarray. Dans ce cas, le type de remplacement a les propriétés suivantes :

  • Toutes les fonctions membres const de std::valarray sont fournies.
  • std::valarray, std::slice_array, std::gslice_array, std::mask_array et std::indirect_array peuvent être construits à partir du type de remplacement.
  • Pour chaque fonction prenant un const std::valarray<T>& sauf begin() et end() (depuis C++11), des fonctions identiques prenant les types de remplacement doivent être ajoutées ;
  • Pour chaque fonction prenant deux arguments const std::valarray<T>&, des fonctions identiques prenant chaque combinaison de const std::valarray<T>& et de types de remplacement doivent être ajoutées.
  • Le type de retour n'ajoute pas plus de deux niveaux d'imbrication de modèles par rapport au type d'argument le plus profondément imbriqué.

Exemple

#include <iostream>
#include <string_view>
#include <valarray>

template<typename T>
void print(std::string_view const note,
           std::valarray<T> const vala, // par valeur, voir les notes ci-dessus
           std::string_view const term = "\n")
{
    std::cout << note << std::boolalpha << std::showpos;
    for (T const element : vala)
        std::cout << '\t' << element;
    std::cout << term;
}

int main()
{
    std::valarray<int> x{1, 2, 3, 4};
    print<int>("x: ", x);
    print<int>("+x: ", +x);
    print<int>("+ + x: ", + + x);
    print<int>("-x: ", -x);
    print<int>("- - x: ", - - x, "\n\n");

    std::valarray<short> y{0, 1, -1, 0x7fff};
    print<short>("y: ", y);
    print<short>("~y: ", ~y);
    print<short>("~~y: ", ~~y, "\n\n");

    std::valarray<bool> z{true, false};
    print<bool>("z: ", z);
    print<bool>("!z: ", !z);
    print<bool>("!!z: ", !!z);
}
