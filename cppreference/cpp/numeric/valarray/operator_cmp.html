Compare chaque valeur du tableau numérique à une autre valeur.

  1. Renvoie un tableau numérique de bool contenant des éléments obtenus en appliquant l'opérateur de comparaison indiqué aux valeurs correspondantes de lhs et rhs.

Le comportement est indéfini si size() != v.size().

  1. Renvoie un tableau numérique de bool contenant des éléments obtenus en appliquant l'opérateur de comparaison indiqué à lhsv et à la valeur correspondante de rhs.

  2. Renvoie un tableau numérique de bool contenant des éléments obtenus en appliquant l'opérateur de comparaison indiqué à la valeur correspondante de lhs et à rhsv.

Paramètres

  • lhs, rhs — tableaux numériques à comparer
  • lhsv, rhsv — valeurs à comparer à chaque élément d'un tableau numérique

Valeur de retour

Un tableau numérique de bool contenant les résultats de comparaison des éléments correspondants.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Notes

Chacun des opérateurs ne peut être instancié que si les exigences suivantes sont satisfaites :

  • L'opérateur indiqué peut être appliqué au type T.
  • La valeur du résultat peut être convertie sans ambiguïté en bool.

La fonction peut être implémentée avec un type de retour différent de std::valarray. Dans ce cas, le type de remplacement a les propriétés suivantes :

  • Toutes les fonctions membres const de std::valarray sont fournies.
  • std::valarray, std::slice_array, std::gslice_array, std::mask_array et std::indirect_array peuvent être construits à partir du type de remplacement.
  • Pour chaque fonction prenant un const std::valarray<T>& sauf begin() et end() (depuis C++11), des fonctions identiques prenant les types de remplacement doivent être ajoutées ;
  • Pour chaque fonction prenant deux arguments const std::valarray<T>&, des fonctions identiques prenant chaque combinaison de const std::valarray<T>& et de types de remplacement doivent être ajoutées.
  • Le type de retour n'ajoute pas plus de deux niveaux d'imbrication de modèles par rapport au type d'argument le plus profondément imbriqué.

Exemple

#include <iostream>
#include <valarray>

int main()
{
    // met à zéro toutes les valeurs négatives d'un valarray
    std::valarray<int> v = {1, -1, 0, -3, 10, -1, -2};
    std::cout << "Before: ";
    for (auto n : v)
        std::cout << n << ' ';
    std::cout << '\n';
    v[v < 0] = 0;
    std::cout << "After: ";
    for (auto n : v)
        std::cout << n << ' ';
    std::cout << '\n';

    // convertit le résultat valarray<bool> de == en un seul bool
    std::valarray<int> a = {1, 2, 3};
    std::valarray<int> b = {2, 4, 6};

    std::cout << "2*a == b is " << std::boolalpha
              << (2 * a == b).min() << '\n';
}

Output:

Before: 1 -1 0 -3 10 -1 -2
After: 1 0 0 0 10 0 0
2*a == b is true
