Surcharges supplémentaires

Défini dans l'en-tête <cmath>

template< class Arithmetic1, class Arithmetic2, class Arithmetic3 >
constexpr /* type à virgule flottante commun */
    lerp( Arithmetic1 a, Arithmetic2 b, Arithmetic3 t ) noexcept;  // (A) (depuis C++20)
  1. Calcule l'interpolation linéaire entre a et b, si le paramètre t se situe dans [0,1) (l'extrapolation linéaire sinon), c'est-à-dire le résultat de (a+t(b−a))a+t(b−a) en tenant compte des imprécisions de calcul à virgule flottante.La bibliothèque fournit des surcharges pour tous les types à virgule flottante non qualifiés cv en tant que type des paramètres a, b et t. (depuis C++23)

A) Des surcharges supplémentaires sont fournies pour toutes les autres combinaisons de types arithmétiques.

Paramètres

  • a, b, t — valeurs à virgule flottante ou entières

Valeur de retour

(a + t(b − a))a + t(b − a)

Lorsque std::isfinite(a) && std::isfinite(b) vaut true, les propriétés suivantes sont garanties :

  • Si t == 0, le résultat est égal à a.
  • Si t == 1, le résultat est égal à b.
  • Si t >= 0 && t <= 1, le résultat est fini.
  • Si std::isfinite(t) && a == b, le résultat est égal à a.
  • Si std::isfinite(t) || (b - a != 0 && std::isinf(t)), le résultat n'est pas NaN.

Soit CMP(x, y) égal à 1 si x > y, -1 si x < y, et 0 sinon. Pour tout t1 et t2, le produit de

  • CMP(std::lerp(a, b, t2), std::lerp(a, b, t1)),
  • CMP(t2, t1), and
  • CMP(b, a)

est positif ou nul. (C'est-à-dire que std::lerp est monotone.)

Notes

Les surcharges supplémentaires ne sont pas tenues d'être fournies exactement comme (A). Elles doivent seulement être suffisantes pour garantir que pour leur premier argument num1, leur deuxième argument num2 et leur troisième argument num3 :

  • Si num1, num2 ou num3 a le type long double, alors std::lerp(num1, num2, num3) a le même effet que std::lerp(static_cast<long double>(num1), static_cast<long double>(num2), static_cast<long double>(num3)).
  • Sinon, si num1, num2 et/ou num3 a le type double ou un type entier, alors std::lerp(num1, num2, num3) a le même effet que std::lerp(static_cast<double>(num1), static_cast<double>(num2), static_cast<double>(num3)).
  • Sinon, si num1, num2 ou num3 a le type float, alors std::lerp(num1, num2, num3) a le même effet que std::lerp(static_cast<float>(num1), static_cast<float>(num2), static_cast<float>(num3)).

(jusqu'à C++23)

Si num1, num2 et num3 ont des types arithmétiques, alors std::lerp(num1, num2, num3) a le même effet que std::lerp(static_cast</*type à virgule flottante commun*/>(num1), static_cast</*type à virgule flottante commun*/>(num2), static_cast</*type à virgule flottante commun*/>(num3)), où /*type à virgule flottante commun*/ est le type à virgule flottante ayant le plus grand rang de conversion à virgule flottante et le plus grand sous-rang de conversion à virgule flottante parmi les types de num1, num2 et num3 ; les arguments de type entier sont considérés comme ayant le même rang de conversion à virgule flottante que double.

S'il n'existe aucun type à virgule flottante ayant le plus grand rang et sous-rang, alors la résolution de surcharge ne donne aucun candidat utilisable parmi les surcharges fournies.

(depuis C++23)

Exemple

#include <cassert>
#include <cmath>
#include <iostream>

float naive_lerp(float a, float b, float t)
{
    return a + t * (b - a);
}

int main()
{
    std::cout << std::boolalpha;

    const float a = 1e8f, b = 1.0f;
    const float midpoint = std::lerp(a, b, 0.5f);

    std::cout << "a = " << a << ", " << "b = " << b << '\n'
              << "midpoint = " << midpoint << '\n';

    std::cout << "std::lerp is exact: "
              << (a == std::lerp(a, b, 0.0f)) << ' '
              << (b == std::lerp(a, b, 1.0f)) << '\n';

    std::cout << "naive_lerp is exact: "
              << (a == naive_lerp(a, b, 0.0f)) << ' '
              << (b == naive_lerp(a, b, 1.0f)) << '\n';

    std::cout << "std::lerp(a, b, 1.0f) = " << std::lerp(a, b, 1.0f) << '\n'
              << "naive_lerp(a, b, 1.0f) = " << naive_lerp(a, b, 1.0f) << '\n';

    assert(not std::isnan(std::lerp(a, b, INFINITY))); // lerp peut valoir -inf ici

    std::cout << "Extrapolation demo, given std::lerp(5, 10, t):\n";
    for (auto t{-2.0}; t <= 2.0; t += 0.5)
        std::cout << std::lerp(5.0, 10.0, t) << ' ';
    std::cout << '\n';
}
