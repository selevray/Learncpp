Exigences nommées C++ : MoveAssignable (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Précise qu'une instance du type peut être affectée à partir d'un argument rvalue.

Exigences

Le type T satisfait MoveAssignable si

Soient

  • t, une expression lvalue modifiable de type T,
  • rv, une expression rvalue de type T.

Les expressions suivantes doivent être valides et produire les effets spécifiés.

Expression | Type de retour | Valeur de retour | Post-conditions

t = rv | T& | t | Si t et rv ne désignent pas le même objet, la valeur de t est équivalente à la valeur de rv avant l'affectation.

La nouvelle valeur de rv est non spécifiée.

Notes

Le type n'a pas besoin d'implémenter un opérateur d'affectation par déplacement pour satisfaire cette exigence de type : un opérateur d'affectation par copie qui prend son paramètre par valeur ou comme const Type&, se liera à un argument rvalue.

Si une classe MoveAssignable implémente un opérateur d'affectation par déplacement, elle peut également implémenter la sémantique de déplacement pour tirer parti du fait que la valeur de rv après l'affectation est non spécifiée.
