Exigences nommées C++ : LegacyInputIterator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un LegacyInputIterator est un LegacyIterator pouvant lire depuis l'élément pointé. LegacyInputIterator ne garantissent la validité que pour les algorithmes à passe unique : une fois qu'un LegacyInputIterator i a été incrémenté, toutes les copies de sa valeur précédente peuvent être invalidées.

Exigences

Type Définition

  • X — Un type d'itérateur d'entrée
  • T — Le type de valeur de X (c'est-à-dire std::iterator_traits<X>::value_type)
  • R — std::iterator_traits<X>::reference

Valeur Définition

  • i, j — Valeurs de type X ou const X
  • r — Une valeur de type X&

Autre Définition

  • m — Un identifiant pouvant désigner un membre de données ou une fonction membre

X satisfait LegacyInputIterator si toutes les conditions suivantes sont remplies :

  • X satisfait LegacyIterator.
  • X satisfait EqualityComparable.
  • Les expressions suivantes sont bien formées et ont la sémantique indiquée :

Domaine d'égalité

Le terme le domaine de == est utilisé au sens mathématique ordinaire pour désigner l'ensemble des valeurs pouvant être comparées à l'aide de ==. Cet ensemble peut changer au fil du temps.

Chaque algorithme impose des exigences supplémentaires sur le domaine d'égalité des valeurs d'itérateurs qu'il utilise. Ces exigences peuvent être déduites des utilisations que cet algorithme fait de == et !=.

Notes

Pour un itérateur d'entrée X qui n'est pas un LegacyForwardIterator, std::iterator_traits<X>::reference n'a pas besoin d'être un type référence : le déréférencement d'un itérateur d'entrée peut renvoyer un objet mandataire ou std::iterator_traits<X>::value_type lui-même par valeur (comme dans le cas de std::istreambuf_iterator).

Concept

Pour la définition de std::iterator_traits, le concept d'exposition suivant est défini.

template<class I>
concept __LegacyInputIterator =
__LegacyIterator<I> && std::equality_comparable<I> && requires(I i)
{
    typename std::incrementable_traits<I>::difference_type;
    typename std::indirectly_readable_traits<I>::value_type;
    typename std::common_reference_t<std::iter_reference_t<I>&&,
                                     typename std::indirectly_readable_traits<I>::value_type&>;
    *i++;
    typename std::common_reference_t<decltype(*i++)&&,
                                     typename std::indirectly_readable_traits<I>::value_type&>;
    requires std::signed_integral<typename std::incrementable_traits<I>::difference_type>;
};

où le concept __LegacyIterator réservé à l'exposition est décrit dans LegacyIterator.

(depuis C++20)
