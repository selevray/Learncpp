Exigences nommées C++ : RegexTraits (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

RegexTraits est une classe de traits qui abstrait les opérations nécessaires pour un type de caractère donné lorsqu'elle est utilisée comme arguments de paramètres de modèle de type pour std::basic_regex.

Exigences

Soient

  • CharT, un type de caractère
  • X, un type RegexTraits pour le type CharT
  • u, un objet de type X
  • v, un objet de type const X
  • p, une valeur de type const CharT*
  • I1, I2, itérateurs d'entrée
  • F1, F2, itérateurs avant
  • c, une valeur de type const CharT
  • s, un objet de type X::string_type
  • cs, un objet de type const X::string_type
  • b, une valeur de type bool
  • I, une valeur de type int
  • cl, un objet de type X::char_class_type
  • loc, un objet de type X::locale_type

expression | type de retour | semantics

X::char_type | CharT | Utilisé pour désigner le type de caractère.

X::string_type | std::basic_string<CharT>

X::locale_type | Un type CopyConstructible qui représente la locale utilisée par la classe de traits.

X::char_class_type | Un type BitmaskType qui représente une classification particulière de caractères.

X::length(p) | std::size_t | Valeur de retour : le plus petit i tel que p[i] == 0. La complexité est linéaire en i.

v.translate(c) | X::char_type | Valeur de retour : un caractère tel que pour tout caractère d considéré comme équivalent à c, alors v.translate(c) == v.translate(d).

v.translate_nocase(c) | X::char_type | Valeur de retour : un caractère tel que pour tout caractère C considéré comme équivalent à c sans tenir compte de la casse, alors v.translate_nocase(c) == v.translate_nocase(C).

v.transform(F1, F2) | X::string_type | Valeur de retour : une clé de tri pour la séquence de caractères désignée par l'intervalle d'itérateurs [F1, F2), telle que si la séquence de caractères [G1, G2) est triée avant la séquence de caractères [H1, H2), alors v.transform(G1, G2) < v.transform(H1, H2).

v.transform_primary(F1, F2) | X::string_type | Valeur de retour : une clé de tri pour la séquence de caractères désignée par l'intervalle d'itérateurs [F1, F2), telle que si la séquence de caractères [G1, G2) est triée avant la séquence de caractères [H1, H2) sans tenir compte de la casse, alors v.transform_primary(G1, G2) < v.transform_primary(H1, H2).

v.lookup_collatename(F1, F2) | X::string_type | Returns:

  • Une chaîne vide si la séquence de caractères n'est pas un élément de collationnement valide
  • Une séquence de caractères représentant l'élément de collationnement constitué de la séquence de caractères désignée par l'intervalle d'itérateurs [F1, F2), sinon

v.lookup_classname(F1, F2, b) | X::char_class_type |

  • Convertit la séquence de caractères désignée par l'intervalle d'itérateurs [F1, F2) en une valeur de type BitmaskType qui peut ensuite être passée à isctype
  • Les valeurs retournées par lookup_classname peuvent être combinées par un OU binaire ; la valeur résultante représente l'appartenance à l'une ou l'autre des classes de caractères correspondantes
  • Si b est vrai, le masque de bits retourné convient pour la reconnaissance de caractères sans tenir compte de leur casse.
  • Retourne 0 si la séquence de caractères n'est pas le nom d'une classe de caractères reconnue par X.
  • La valeur retournée doit être indépendante de la casse des caractères de la séquence.

v.isctype(c, cl) | bool | Valeur de retour : indique si c est un membre de l'une des classes de caractères désignées par cl ou non.

v.value(c, I) | int | Returns:

  • La valeur représentée par le chiffre c en base I si le caractère c est un chiffre valide en base I
  • -1 sinon

u.imbue(loc) | X::locale_type |

  • Imprègne u de la locale loc
  • Valeur de retour : la locale précédemment utilisée par u, le cas échéant

v.getloc() | X::locale_type | Valeur de retour : la locale précédemment utilisée par v, le cas échéant.

Bibliothèque standard
