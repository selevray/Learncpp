Exigences nommées C++ : DefaultConstructible

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Spécifie qu'une instance du type peut être construite par défaut.

Exigences

Le type T satisfait DefaultConstructible si toutes les instructions et expressions suivantes sont valides et produisent les effets spécifiés :

Expression/Instruction | Postcondition

T u; | L'objet u est initialisé par défaut.

T u{}; | L'objet u est initialisé par valeur ou initialisé par agrégat.

T()

T{}

| Un objet temporaire de type T est initialisé par valeur ou initialisé par agrégat.

Notes

Pour les objets de type classe non agrégat, un constructeur par défaut public doit être défini (soit défini par l'utilisateur, soit implicitement) pour satisfaire DefaultConstructible.

Les objets non const de type objet non classe sont toujours DefaultConstructible.

Les types non classe const ne sont pas DefaultConstructible.

Les types agrégat const ne sont pas DefaultConstructible si l'un de leurs membres est un objet de type non classe.

Les types non objets (types fonction, types référence, et le type void (éventuellement qualifié cv)) ainsi que les types non objets const ne sont jamais DefaultConstructible.

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.
