Exigences nommées C++ : RangeAdaptorClosureObject (depuis C++20)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les objets fermeture d'adaptateur d'intervalle sont des FunctionObjects appelables via l'opérateur tube : si C est un objet fermeture d'adaptateur d'intervalle et R est un range, ces deux expressions sont équivalentes :

C(R)
R | C

Deux objets fermeture d'adaptateur d'intervalle peuvent être enchaînés par operator| pour produire un autre objet fermeture d'adaptateur d'intervalle : si C et D sont des objets fermeture d'adaptateur d'intervalle, alors C | D produit un objet fermeture d'adaptateur d'intervalle E ayant les propriétés suivantes :

  • E stocke une copie de C et de D, initialisées directement sans liste à partir de std::forward<decltype((C))>(C) et std::forward<decltype((D))>(D) respectivement. Si une telle initialisation est invalide, C | D est également invalide.
  • Soient c et d les copies stockées (avec la même constness et la même catégorie de valeur que E), et R un objet range, les expressions suivantes sont équivalentes :
d(c(R))
R | c | d
E(R)
R | E // R | (C | D)

Remarques : operator() n'est pas pris en charge pour les versions qualifiées volatile ou qualifiées const volatile des types d'objets fermeture d'adaptateur d'intervalle.

Les objets dont le type est identique à l'un des objets suivants (en ignorant la qualification cv) sont des objets fermeture d'adaptateur d'intervalle :

  • objets adaptateurs d'intervalle unaires,
  • objets de types définis par l'utilisateur satisfaisant les exigences d'implémentation d'un objet fermeture d'adaptateur d'intervalle,

(depuis C++23)

  • les résultats de la liaison d'arguments finaux par des objets adaptateurs d'intervalle, et
  • les résultats de l'enchaînement de deux objets fermeture d'adaptateur d'intervalle par operator|.
