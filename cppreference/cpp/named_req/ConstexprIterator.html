Exigences nommées C++ : ConstexprIterator (depuis C++20)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un ConstexprIterator est un LegacyIterator qui peut être utilisé lors de l'évaluation d'une expression constante.

Exigences

Le type It satisfait ConstexprIterator si

  • Le type It satisfait certaines exigences d'itérateur MeowIterator

Et, pour chaque

  • purr, une opération sur It qui doit être prise en charge par MeowIterator,
  • kittens..., un ensemble d'arguments pour purr qui satisfait les exigences de cette opération,

Alors

  • purr(kittens...) peut être utilisé dans une expression constante si kittens... peut également être utilisé.

Bibliothèque standard

Les types suivants de la bibliothèque standard sont des ConstexprIterators.

  • array::iterator and array::const_iterator.
  • basic_string_view::iterator.
  • span::iterator.
  • vector::iterator and vector::const_iterator.
  • optional::iterator and optional::const_iterator

(depuis C++26)
