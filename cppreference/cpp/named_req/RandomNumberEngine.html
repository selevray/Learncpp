Exigences nommées C++ : RandomNumberEngine (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un moteur de nombres aléatoires est un objet fonction renvoyant des valeurs entières non signées telles que chaque valeur de l'ensemble des résultats possibles ait (idéalement) la même probabilité.

Tout moteur de nombres aléatoires est aussi un UniformRandomBitGenerator, et peut donc être branché dans toute distribution de nombres aléatoires afin d'obtenir un nombre aléatoire (formellement, une variable aléatoire).

Exigences

Un type satisfait RandomNumberEngine s'il satisfait UniformRandomBitGenerator et, étant donnés les types et valeurs suivants, les exigences sémantiques et de complexité du tableau ci-dessous sont satisfaites :

Type Définition

  • E — un type RandomNumberEngine
  • T — E::result_type

Valeur Définition

  • e — une valeur de type E
  • v — une lvalue de type E
  • x, y — valeurs de type (éventuellement qualifié const) E
  • s — une valeur de type T
  • q — une lvalue SeedSequence
  • z — une valeur de type unsigned long long
  • os — une lvalue dont le type est une spécialisation de std::basic_ostream
  • is — une lvalue dont le type est une spécialisation de std::basic_istream
  • n — la taille de l'état de E
  • TA — l'algorithme de transition de E
  • GA — l'algorithme de génération de E

Bibliothèque standard

Les installations suivantes de la bibliothèque standard satisfont RandomNumberEngine :

  • linear_congruential_engine (C++11) — implémente l'algorithme congruentiel linéaire (modèle de classe)
  • mersenne_twister_engine (C++11) — implémente l'algorithme de Mersenne twister (modèle de classe)
  • subtract_with_carry_engine (C++11) — implémente un algorithme de soustraction avec retenue (de Fibonacci retardé) (modèle de classe)
  • philox_engine (C++26) — un générateur parallélisable basé sur un compteur (modèle de classe)
  • discard_block_engine (C++11) — ignore une partie de la sortie d'un moteur de nombres aléatoires (modèle de classe)
  • independent_bits_engine (C++11) — regroupe la sortie d'un moteur de nombres aléatoires en blocs d'un nombre de bits spécifié (modèle de classe)
  • shuffle_order_engine (C++11) — fournit la sortie d'un moteur de nombres aléatoires dans un ordre différent (modèle de classe)

Les installations suivantes de la bibliothèque standard satisfont UniformRandomBitGenerator mais pas RandomNumberEngine :

  • random_device (C++11) — générateur de nombres aléatoires non déterministe utilisant une source d'entropie matérielle (classe)
