Exigences nommées C++ : NullablePointer (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Précise que le type est un objet de type pointeur pouvant être comparé à des objets std::nullptr_t.

Exigences

Le type doit satisfaire toutes les exigences suivantes :

  • EqualityComparable
  • DefaultConstructible
  • CopyConstructible
  • CopyAssignable
  • Swappable
  • Destructible

De plus, un objet initialisé par valeur de ce type doit produire une valeur nulle de ce type. Cette valeur nulle ne doit être équivalente qu'à elle-même. L'initialisation par défaut du type peut donner une valeur indéterminéeou erronée (depuis C++26).

Une valeur de ce type doit être convertible contextuellement en bool. L'effet de cette conversion retourne false si la valeur est équivalente à sa valeur nulle, et true sinon.

Aucune des opérations effectuées par ce type ne peut lever d'exceptions.

Le type doit satisfaire les expressions supplémentaires suivantes, étant donné deux valeurs p et q de ce type, et que np est une valeur de type std::nullptr_t (éventuellement qualifié const) :

Déclaration Effets

  • **Type p(np);

    Type p = np;** — Ensuite, p est équivalent à nullptr

Expression Effets

  • Type(np) — Un objet temporaire équivalent à nullptr

  • p = np — Doit retourner un Type&, et ensuite, p est équivalent à nullptr

  • p != q —

    Le type et la valeur satisfont les exigences BooleanTestable

    (jusqu'à C++20)

    decltype(p != q) modélise boolean-testable

    (depuis C++20)

    L'effet est !(p == q)

  • **p == np

    np == p** —

    Le type et la valeur des deux expressions satisfont les exigences BooleanTestable

    (jusqu'à C++20)

    decltype(p == np) et decltype(np == p) modélisent chacun boolean-testable

    (depuis C++20)

    L'effet est (p == Type())

  • **p != np

    np != p** —

    Le type et la valeur des deux expressions satisfont les exigences BooleanTestable

    (jusqu'à C++20)

    decltype(p != np) et decltype(np != p) modélisent chacun boolean-testable

    (depuis C++20)

    L'effet est !(p == np)

Notes

Notez que le déréférencement (operator* ou operator->) n'est pas requis pour un type NullablePointer. Un type minimaliste satisfaisant ces exigences est

class handle
{
    int id = 0;
public:
    handle() = default;
    handle(std::nullptr_t) {}
    explicit operator bool() const { return id != 0; }
    friend bool operator==(handle l, handle r) { return l.id == r.id; }
    friend bool operator!=(handle l, handle r) { return !(l == r); }
    // ou seulement un operator== par défaut (depuis C++20)
};

Bibliothèque standard

Les types suivants satisfont NullablePointer :

  • std::exception_ptr.

Les types suivants doivent satisfaire NullablePointer afin de communiquer avec les composants de la bibliothèque standard :

  • Les types membres X::pointer, X::const_pointer, X::void_pointer et X::const_void_pointer de tout type Allocator X.
  • Le type membre pointer de std::unique_ptr.
  • Le type de pointeur adapté de std::inout_ptr_t et std::out_ptr_t.

(depuis C++23)
