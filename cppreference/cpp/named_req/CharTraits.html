Exigences nommées C++ : CharTraits

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

CharTraits est une classe de traits qui abstrait les opérations de base sur les caractères et les chaînes pour un type de caractère donné. La plupart des classes de chaînes et d'entrées/sorties de la bibliothèque standard exigent un paramètre de modèle de type CharTraits en plus du paramètre de modèle de type de caractère correspondant.

Exigences

Aucune opération listée ci-dessous sur CharTraits ne peut lever d'exception.

Soient

  • CharT, un type de caractère
  • X, un type CharTraits pour le type CharT
  • c, d, valeurs de type CharT
  • p, q, valeurs de type const CharT*
  • s, une valeur de type CharT*
  • n, i, j, valeurs de type std::size_t
  • e, f, valeurs de type X::int_type
  • pos, une valeur de type X::pos_type
  • state, une valeur de type X::state_type
  • r, une lvalue de type CharT

Bibliothèque standard

CharTraits est requis par les modèles de classes de la bibliothèque standard suivants en tant que paramètre de modèle de type :

##### Chaînes {#Strings}

  • basic_string — stocke et manipule des séquences de caractères (modèle de classe)
  • basic_string_view (C++17) — vue de chaîne en lecture seule (modèle de classe)

##### Flux {#Streams}

  • basic_ios — gère un tampon de flux arbitraire (modèle de classe)
  • basic_istream — encapsule un périphérique abstrait donné (std::basic_streambuf) et fournit une interface d'entrée de haut niveau (modèle de classe)
  • basic_ifstream — implémente les opérations d'entrée de haut niveau sur les flux de fichiers (modèle de classe)
  • basic_istringstream — implémente les opérations d'entrée de haut niveau sur un flux de chaîne (modèle de classe)
  • basic_ispanstream (C++23) — implémente les opérations d'entrée sur un tampon de caractères de taille fixe (modèle de classe)
  • basic_ostream — encapsule un périphérique abstrait donné (std::basic_streambuf) et fournit une interface de sortie de haut niveau (modèle de classe)
  • basic_ofstream — implémente les opérations de sortie de haut niveau sur les flux de fichiers (modèle de classe)
  • basic_ostringstream — implémente les opérations de sortie de haut niveau sur un flux de chaîne (modèle de classe)
  • basic_osyncstream (C++20) — encapsuleur de flux de sortie synchronisé (modèle de classe)
  • basic_ospanstream (C++23) — implémente les opérations de sortie sur un tampon de caractères de taille fixe (modèle de classe)
  • basic_iostream — encapsule un périphérique abstrait donné (std::basic_streambuf) et fournit une interface d'entrée/sortie de haut niveau (modèle de classe)
  • basic_fstream — implémente les opérations d'entrée/sortie de haut niveau sur les flux de fichiers (modèle de classe)
  • basic_stringstream — implémente les opérations d'entrée/sortie de haut niveau sur un flux de chaîne (modèle de classe)
  • basic_spanstream (C++23) — implémente les opérations d'entrée/sortie sur un tampon de caractères de taille fixe (modèle de classe)

##### Itérateurs de flux {#Stream_iterators}

  • istream_iterator — itérateur d'entrée qui lit depuis std::basic_istream (modèle de classe)
  • ostream_iterator — itérateur de sortie qui écrit dans std::basic_ostream (modèle de classe)

##### Tampons de flux {#Stream_buffers}

  • basic_streambuf — abstrait un périphérique brut (modèle de classe)
  • basic_filebuf — implémente un périphérique de fichier brut (modèle de classe)
  • basic_stringbuf — implémente un périphérique de chaîne brut (modèle de classe)
  • basic_syncbuf (C++20) — encapsuleur de périphérique de sortie synchronisé (modèle de classe)
  • basic_spanbuf (C++23) — implémente un périphérique brut à tampon de caractères de taille fixe (modèle de classe)

##### Itérateurs de tampons de flux {#Stream_buffer_iterators}

  • istreambuf_iterator — itérateur d'entrée qui lit depuis std::basic_streambuf (modèle de classe)
  • ostreambuf_iterator — itérateur de sortie qui écrit dans std::basic_streambuf (modèle de classe)

CharTraits est satisfait par les spécialisations explicites suivantes de la bibliothèque standard de std::char_traits :

template<> class char_traits<char>;
template<> class char_traits<wchar_t>;
template<> class char_traits<char8_t>;
template<> class char_traits<char16_t>;
template<> class char_traits<char32_t>;  // (depuis C++20) (depuis C++11) (depuis C++11)

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 335 C++98 les exigences sur la surcharge binaire de assign n'empêchaient pas les affectations aux rvalues son premier argument ne peut être qu'une lvalue
LWG 352 C++98 X::state_type n'était requis que d'être CopyConstructible il est également requis d'être CopyAssignable et DefaultConstructible
LWG 3085 C++98 X::copy(s, p, n) n'exigeait que p et non dans [s,s + n), ce qui est trop faible[1] exige que [p,p + n) et [s,s + n) ne se chevauchent pas
  1. ↑ [p,p + n) et [s,s + n) peuvent se chevaucher ; utiliser std::memcpy pour implémenter X::copy entraîne un comportement indéfini dans ce cas.
