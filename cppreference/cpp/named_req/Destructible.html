Exigences nommées C++ : Destructible

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Spécifie qu'une instance du type peut être détruite.

Exigences

Le type T satisfait Destructible si

Soient

  • u, une expression de type T.

Les expressions suivantes doivent être valides et produire les effets spécifiés.

Expression Post-conditions
u.~T() Toutes les ressources possédées par u sont libérées, aucune exception n'est levée.

Notes

Les destructeurs sont appelés implicitement à la fin de la durée de vie de l'objet, par exemple en quittant la portée ou par l'expression delete. L'appel explicite du destructeur, tel qu'illustré dans le tableau des exigences de type, est rare.

Grâce à l'appel de pseudo-destructeur, tous les types scalaires satisfont l'exigence de Destructible, alors que les types tableau et les types référence ne la satisfont pas. Notez que std::is_destructible autorise les tableaux et les types référence.
