Exigences

Une FormattedOutputFunction est une fonction de sortie de flux qui effectue les opérations suivantes :

  • Construit un objet de type basic_ostream::sentry à durée de stockage automatique, qui effectue les opérations suivantes :

    • si eofbit ou badbit sont définis sur le flux de sortie, définit aussi failbit, et si les exceptions sur failbit sont activées dans le masque d'exceptions de ce flux de sortie ((exceptions() & failbit) != 0), lève ios_base::failure.
    • vide le flux de sortie lié par tie(), le cas échéant.

  • Vérifie l'état de la sentinelle en appelant sentry::operator bool(), ce qui équivaut à basic_ios::good.

  • Si la sentinelle a renvoyé false ou si le constructeur de la sentinelle a levé une exception, aucune sortie n'a lieu.

  • Si la sentinelle a renvoyé true, tente d'effectuer la sortie souhaitée en insérant les caractères dans le flux de sortie comme par un appel à rdbuf()->sputc(). Les autres membres publics de std::basic_ostream peuvent aussi être utilisés, mais les membres virtuels de rdbuf() autres que overflow(), xsputn() et sync() ne seront jamais appelés.

    • Si la sortie n'a pas pu être produite, définit failbit. Si les exceptions sur failbit sont activées dans le masque d'exceptions de ce flux ((exceptions() & failbit) != 0), lève ios_base::failure.
    • si une exception est levée pendant la sortie, définit badbit dans le flux de sortie. Si les exceptions sur badbit sont activées dans le masque d'exceptions de ce flux ((exceptions() & badbit) != 0), l'exception est aussi relancée.
    • Si aucune exception n'a été levée, renvoie *this.

  • Dans tous les cas, qu'il y ait sortie par exception ou par retour, le destructeur de la sentinelle est appelé avant de quitter cette fonction.

Remplissage

Les fonctions de sortie formatée déterminent le remplissage selon std::num_put::do_put() étape 3.

(jusqu'à C++14)

Si une fonction de sortie formatée d'un flux os détermine le remplissage, elle procède comme suit.

Étant donné une séquence de caractères CharT seq où CharT est le type de conteneur de caractères de os, si la longueur de seq est inférieure à os.width(), alors suffisamment de copies de os.fill() sont ajoutées à cette séquence si nécessaire pour compléter jusqu'à une largeur de os.width() caractères.

Si (os.flags() & std::ios_base::adjustfield) == std::ios_base::left est true, les caractères de remplissage sont placés après la séquence de caractères ; sinon, ils sont placés avant la séquence de caractères.

(depuis C++14)

Bibliothèque standard

Les fonctions suivantes de la bibliothèque standard sont des FormattedOutputFunctions.

  • basic_ostream::operator<<(std::basic_ostream&, int / long / double / void* / bool)
  • operator<<(std::basic_ostream&, char)
  • operator<<(std::basic_ostream&, char*)
  • operator<<(std::basic_ostream&, const std::bitset&)
  • operator<<(std::basic_ostream&, const std::basic_string&)
  • operator<< , lorsqu'appelée sur la valeur de retour de std::put_money
  • operator<<(std::basic_ostream&, std::basic_string_view)

(depuis C++17)

  • print(std::ostream&, std::format_string<Args...>, Args&&...),
  • println(std::ostream&, std::format_string<Args...>, Args&&...),
  • vprint_unicode(std::ostream&, std::string_view, std::format_args),
  • vprint_nonunicode(std::ostream&, std::string_view, std::format_args), sauf que (étant donné que os est un objet de flux de sortie) :
  • toute exception levée par l'appel à std::vformat est propagée, sans égard à la valeur de os.exceptions() et sans activer ios_base::badbit dans l'état d'erreur de os ;
  • si l'insertion dans os échoue, appelle os.setstate(ios_base::badbit) (qui peut lever ios_base::failure).

(depuis C++23)
