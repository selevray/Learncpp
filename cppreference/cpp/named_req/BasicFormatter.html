Exigences nommées C++ : BasicFormatter (depuis C++20)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

BasicFormatter est un type qui abstrait les opérations de formatage pour un type d'argument de formatage et un type de caractère donnés. Les spécialisations de std::formatter doivent satisfaire aux exigences de BasicFormatter.

Un BasicFormatter est un Formatter s'il est capable de formater à la fois des arguments const et non const.

Exigences

Un type satisfait BasicFormatter s'il est semi-régulier, c'est-à-dire s'il satisfait :

  • DefaultConstructible
  • CopyConstructible
  • CopyAssignable
  • Destructible
  • Swappable

Et, étant donnés les types et valeurs suivants, les expressions indiquées dans le tableau ci-dessous sont valides et ont la sémantique indiquée :

Type Définition

  • CharT — un type de caractère
  • Arg — un type d'argument de formatage
  • Formatter — un type Formatter pour les types Arg et CharT
  • OutputIt — un type LegacyOutputIterator
  • ParseCtx — std::basic_format_parse_context<CharT>
  • FmtCtx — std::basic_format_context<OutputIt, CharT>

Valeur Définition

  • f — une valeur de type (éventuellement qualifié const) Formatter
  • g — une valeur de type Formatter
  • arg — une lvalue de type Arg
  • t — une valeur d'un type convertible en Arg (éventuellement qualifié const)
  • parse_ctx — une lvalue de type ParseCtx satisfaisant toutes les conditions suivantes :
    • parse_ctx.begin() pointe vers le début du format-spec du champ de remplacement en cours de formatage dans la chaîne de format.
    • Si format-spec est absent ou vide, alors soit parse_ctx.begin() == parse_ctx.end(), soit *parse_ctx.begin() == '}'.
  • fmt_ctx — une lvalue de type FmtCtx

Expression | Type de retour | Sémantique

g.parse(parse_ctx) | ParseCtx::iterator |

  • Dans l'intervalle [parse_ctx.begin(),parse_ctx.end()), analyse le format-spec pour le type Arg jusqu'au premier caractère non apparié.
  • Lève std::format_error sauf si tout l'intervalle est analysé ou si le caractère non apparié est }. [note 1]
  • Stocke les spécificateurs de format analysés dans g et renvoie un itérateur de fin de l'intervalle analysé.

f.format(arg, fmt_ctx) | FmtCtx::iterator |

  • Formate arg selon les spécificateurs stockés dans f, écrit la sortie dans fmt_ctx.out() et renvoie un itérateur de fin de l'intervalle de sortie.
  • La sortie ne doit dépendre que de
    • arg,
    • fmt_ctx.locale(),
    • l'intervalle [parse_ctx.begin(),parse_ctx.end()) depuis le dernier appel à f.parse(parse_ctx), et
    • fmt_ctx.arg(n) pour toute valeur n de type std::size_t.
  1. ↑ Cela permet aux formateurs d'émettre des messages d'erreur significatifs.
