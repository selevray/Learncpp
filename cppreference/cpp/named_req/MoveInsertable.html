Exigences nommées C++ : MoveInsertable (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Précise qu'un objet du type peut être construit dans un stockage non initialisé à partir d'une rvalue de ce type, au moyen d'un allocateur donné.

Exigences

Étant donnés les types, valeurs et expressions suivants :

Type Définition

  • T — un type objet
  • A — un type d'allocateur
  • X — un type de conteneur satisfaisant toutes les conditions suivantes :
    • X::value_type est le même que T.
    • X::allocator_type est le même que std::allocator_traits<A>::rebind_alloc<T>.

Valeur Définition

  • m — une lvalue de type A
  • p — un pointeur de type T*

Expression Définition

  • rv — une expression désignant une rvalue de type T
  • expr — std::allocator_traits<A>::construct(m, p, rv)

T est MoveInsertable dans X si toutes les conditions suivantes sont satisfaites :

  • expr est bien formé.
  • Immédiatement après l'évaluation de expr, la valeur de *p est équivalente à la valeur de rv avant l'évaluation.

Notes

Si A vaut std::allocator<T>, alors cela appelle le placement new, comme par [::new((void*)p) T(rv) (jusqu'à C++20) | std::construct_at(p, rv) (depuis C++20)]. Cela impose en pratique que T soit constructible par déplacement.

Si std::allocator<T> ou un allocateur similaire est utilisé, une classe n'a pas besoin d'implémenter un constructeur de déplacement pour satisfaire cette exigence de type : un constructeur de copie qui prend un argument const T& peut lier des expressions rvalue. Si une classe MoveInsertable implémente un constructeur de déplacement, elle peut également implémenter la sémantique de déplacement pour tirer parti du fait que la valeur de rv après la construction est non spécifiée.

Bien qu'il soit exigé que construct personnalisé soit utilisé lors de la construction des éléments de std::basic_string jusqu'en C++23, toutes les implémentations n'utilisaient que le mécanisme par défaut. L'exigence est corrigée par P1072R10 pour correspondre à la pratique existante.
