Exigences nommées C++ : LayoutMapping (depuis C++23)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

LayoutMapping contrôle la correspondance entre un index multidimensionnel et un décalage unidimensionnel vers le handle de données dans std::mdspan.

Exigences

Un type M satisfait LayoutMapping s'il modélise copyable et equality_comparable, et que les éléments suivants sont true :

  • std::is_nothrow_move_constructible_v<M>
  • std::is_nothrow_move_assignable_v<M>
  • std::is_nothrow_swappable_v<M>

Et, étant donnés les types et valeurs suivants, les expressions indiquées dans le tableau ci-dessous sont valides et ont la sémantique indiquée :

Légende

Type Définition

  • M — une classe de correspondance de disposition

Valeur Définition

  • m — une valeur de type (éventuellement qualifié const) M
  • i, j — paquets d'entiers (éventuellement qualifiés const) qui sont des indices multidimensionnels dans m.extents()
  • r — un indice de rang (éventuellement qualifié const) de typename M::extents_type
  • d_r — un paquet d'entiers (éventuellement qualifiés const) pour lesquels sizeof...(d_r) == M::extents_type::rank() est true, l'élément à l'indice de rang r est égal à 1, et tous les autres éléments sont égaux à 0

Fonctions membres et opérateurs

Expression | Type de retour | Sémantique

m.extents() | const typename M::extents_type& | Renvoie une référence constante vers l'espace d'indices multidimensionnel associé

m(i...) | typename M::index_type |

  • Renvoie un entier non négatif o tel que o < std::numeric_limits<typename M::index_type>::max() et o <= std::numeric_limits<std::size_t>::max() sont tous deux true.
  • Une telle expression est équivalente à m(static_cast<typename M::index_type>(i)...).

m.required_span_size() | typename M::index_type |

  • Renvoie 1 plus la valeur maximale de m(i...) pour tous les i si la taille de l'espace d'indices multidimensionnel m.extents() n'est pas 0.
  • Sinon, renvoie 0.

m.is_unique() | bool | Ne renvoie true que si, pour chaque i et j où (i != j || ...) est true, m(i...) != m(j...) est true. [note 1]

m.is_exhaustive() | bool | Ne renvoie true que si, pour tout k de l'intervalle [0,m.required_span_size()), il existe un i tel que m(i...) est égal à k. [note 2]

m.is_strided() | bool | Ne renvoie true que si, pour chaque indice de rang r de m.extents(), il existe un entier s_r tel que, pour tout i où (i + d_r) est un indice multidimensionnel de m.extents(), m((i + d_r)...) - m(i...) est égal à s_r. [note 3]

m.stride(r) | typename M::index_type |

  • La précondition est que m.is_strided() est true.
  • Renvoie un pas s_r à l'indice de rang r tel que défini dans m.is_strided() ci-dessus.

M::is_always_unique() | bool |

  • Ne renvoie true que si m.is_unique() est true pour tous les objets possibles m de type M. [note 4]
  • La valeur de retour est toujours une expression constante.

M::is_always_exhaustive() | bool |

  • Ne renvoie true que si m.is_exhaustive() est true pour tous les objets possibles m de type M. [note 5]
  • La valeur de retour est toujours une expression constante.

M::is_always_strided() | bool |

  • Ne renvoie true que si m.is_strided() est true pour tous les objets possibles m de type M. [note 6]
  • La valeur de retour est toujours une expression constante.
  1. ↑ Une correspondance peut renvoyer false même si la condition est remplie. Pour certaines dispositions, il n'est pas forcément possible de déterminer efficacement si la disposition est unique.
  2. ↑ Identique au cas ci-dessus, mais dans le cas de dispositions exhaustives.
  3. ↑ Identique au cas ci-dessus, mais dans le cas de dispositions à pas.
  4. ↑ Une correspondance peut renvoyer false même si la condition est remplie. Pour certaines correspondances de disposition, il n'est pas forcément possible de déterminer si chaque instance est unique.
  5. ↑ Identique au cas ci-dessus, mais dans le cas d'instances exhaustives.
  6. ↑ Identique au cas ci-dessus, mais dans le cas d'instances à pas.

Concept

Pour les contraintes utilisées sous std::layout_stride::mapping, le concept suivant réservé à l'exposition est défini.

template< class M >
concept /*layout-mapping-alike*/ = requires
{
    requires /*is-extents*/<typename M::extents_type>;
    { M::is_always_strided() }    -> std::same_as<bool>;
    { M::is_always_exhaustive() } -> std::same_as<bool>;
    { M::is_always_unique() }     -> std::same_as<bool>;
    std::bool_constant<M::is_always_strided()>::value;
    std::bool_constant<M::is_always_exhaustive()>::value;
    std::bool_constant<M::is_always_unique()>::value;
};  // ( exposition uniquement* )

Définit les contraintes minimales d'utilisabilité de l'exigence LayoutMapping. Ce concept vérifie que les fonctions de trait de correspondance de prédicats ci-dessus existent, sont des expressions constantes et ont un type de retour de bool.

/*is-extents*/<E> est true si et seulement si E est une spécialisation de std::extents.

Bibliothèque standard

Les types de la bibliothèque standard suivants satisfont les exigences LayoutMapping :

  • mapping — un mapping de disposition de layout_left (modèle de classe membre publique de std::layout_left)
  • mapping — un mapping de disposition de layout_right (modèle de classe membre publique de std::layout_right)
  • mapping — un mapping de disposition de layout_stride (modèle de classe membre publique de std::layout_stride)
  • mapping — un mapping de disposition de layout_left_padded (modèle de classe membre publique de std::layout_left_padded<PaddingValue>)
  • mapping — un mapping de disposition de layout_right_padded (modèle de classe membre publique de std::layout_right_padded<PaddingValue>)
