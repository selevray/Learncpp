Exigences nommées C++ : LegacyContiguousIterator (depuis C++17)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un LegacyContiguousIterator est un LegacyIterator dont les éléments logiquement adjacents le sont aussi physiquement en mémoire.

Un pointeur vers un élément d'un tableau satisfait toutes les exigences de LegacyContiguousIterator.

Exigences

Le type It satisfait LegacyContiguousIterator si

  • Le type It satisfait LegacyIterator

Et, pour chaque

  • a, un itérateur déréférençable de type It
  • n, une valeur entière

tel que

  • a + n est une valeur d'itérateur valide et déréférençable

then

  • *(a + n) est équivalent à *(std::addressof(*a) + n).

Bibliothèque standard

Les types suivants de la bibliothèque standard sont des LegacyContiguousIterators.

  • array::iterator.
  • basic_string_view::iterator.
  • basic_string::iterator.
  • vector::iterator pour value_type autre que bool.
  • Le type de retour de begin(valarray) et de end(valarray).

Notes

Les pointeurs élaborés vers des types objets doivent aussi satisfaire LegacyContiguousIterator.

LegacyContiguousIterator est remplacé par le concept contiguous_iterator : les types d'itérateurs de la bibliothèque standard qui doivent satisfaire LegacyContiguousIterator en C++17 doivent modéliser contiguous_iterator en C++20.

(depuis C++20)
