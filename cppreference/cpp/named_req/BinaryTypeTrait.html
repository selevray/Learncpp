Exigences nommées C++ : BinaryTypeTrait (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Une BinaryTypeTrait est un modèle de classe qui décrit une relation entre ses deux paramètres de modèle de type à l'aide d'une std::integral_constant (typiquement std::bool_constant) spécialisation.

Exigences

  • DefaultConstructible and CopyConstructible.
  • Prend deux paramètres de modèle de type (des paramètres de modèle supplémentaires sont facultatifs et autorisés).
  • Dérivé publiquement et sans ambiguïté d'une spécialisation de std::integral_constant, appelée sa caractéristique de base.
  • Les noms de membres de la caractéristique de base ne sont pas masqués et sont disponibles sans ambiguïté.

Bibliothèque standard

Les modèles de classes suivants de la bibliothèque standard satisfont BinaryTypeTrait :

  • is_same (C++11) — vérifie si deux types sont identiques (modèle de classe)
  • is_base_of (C++11) — vérifie si un type est une base d'un autre type (modèle de classe)
  • is_virtual_base_of (C++26) — vérifie si un type est une base virtuelle de l'autre type (modèle de classe)
  • is_convertibleis_nothrow_convertible (C++11) (C++20) — vérifie si un type peut être converti en un autre type (modèle de classe)
  • is_layout_compatible (C++20) — vérifie si deux types sont layout-compatible (modèle de classe)
  • is_pointer_interconvertible_base_of (C++20) — vérifie si un type est une base (initiale) pointer-interconvertible d'un autre type (modèle de classe)
  • is_invocableis_invocable_ris_nothrow_invocableis_nothrow_invocable_r (C++17) — vérifie si un type peut être invoqué (comme par std::invoke) avec les types d'arguments donnés (modèle de classe)
  • uses_allocator (C++11) — vérifie si le type spécifié prend en charge la construction avec uses-allocator (modèle de classe)
