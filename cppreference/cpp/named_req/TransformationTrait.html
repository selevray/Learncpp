Exigences nommées C++ : TransformationTrait (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un TransformationTrait est un modèle de classe qui fournit une transformation de son paramètre de type de modèle.

Exigences

  • Prend un paramètre de type de modèle (des paramètres de modèle supplémentaires sont facultatifs et autorisés).
  • Le type transformé est un type imbriqué accessible publiquement nommé type.

Bibliothèque standard

Tous les traits de transformation de type satisfont TransformationTrait.

Les modèles de classes de la bibliothèque standard suivants satisfont également TransformationTrait.

  • std::tuple_element<std::tuple> (C++11) — obtient le type de l'élément spécifié (spécialisation de modèle de classe)
  • std::tuple_element<std::pair> (C++11) — obtient le type des éléments de pair (spécialisation de modèle de classe)
  • std::tuple_element<std::array> (C++11) — obtient le type des éléments de array (spécialisation de modèle de classe)
  • variant_alternativevariant_alternative_t (C++17) — obtient le type de l'alternative désignée par son indice, à la compilation (modèle de classe) (modèle d'alias)
