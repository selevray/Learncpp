Exigences nommées C++ : AllocatorAwareContainer (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un AllocatorAwareContainer est un Container qui détient une instance d'un Allocator et utilise cette instance dans toutes ses fonctions membres pour allouer et désallouer de la mémoire et pour construire et détruire des objets dans cette mémoire (ces objets peuvent être des éléments de conteneur, des nœuds ou, pour les conteneurs non ordonnés, des tableaux de compartiments), à l'exception près que les spécialisations de std::basic_string n'utilisent pas les allocateurs pour la construction/destruction de leurs éléments (depuis C++23).

Les règles suivantes s'appliquent à la construction de conteneurs :

  • Les constructeurs de copie des AllocatorAwareContainer obtiennent leurs instances d'allocateur en appelant std::allocator_traits<allocator_type>::select_on_container_copy_construction sur l'allocateur du conteneur copié.
  • Les constructeurs de déplacement obtiennent leurs instances d'allocateurs en construisant par déplacement à partir de l'allocateur appartenant à l'ancien conteneur.
  • Tous les autres constructeurs prennent un paramètre const allocator_type&.

La seule façon de remplacer un allocateur est l'affectation par copie, l'affectation par déplacement et l'échange :

  • L'affectation par copie ne remplace l'allocateur que si std::allocator_traits<allocator_type>::propagate_on_container_copy_assignment::value est true.
  • L'affectation par déplacement ne remplace l'allocateur que si std::allocator_traits<allocator_type>::propagate_on_container_move_assignment::value est true.
  • L'échange ne remplace l'allocateur que si std::allocator_traits<allocator_type>::propagate_on_container_swap::value est true. Plus précisément, il échange les instances d'allocateur par un appel non qualifié à la fonction non membre swap, voir Swappable.

Remarque : le comportement de l'échange de deux conteneurs ayant des allocateurs inégaux si propagate_on_container_swap est false est indéfini.

  • L'accesseur get_allocator() obtient une copie de l'allocateur qui a été utilisé pour construire le conteneur ou installé par la dernière opération de remplacement d'allocateur.

Exigences

Un type satisfait AllocatorAwareContainer s'il satisfait Container et, étant donnés les types et valeurs suivants, les exigences de sémantique et de complexité des tableaux ci-dessous sont satisfaites :

Type Définition

  • X — un type AllocatorAwareContainer
  • T — le value_type de X
  • A — le type d'allocateur utilisé par X

Valeur Définition

  • a, b — des lvalues non const de type X
  • c — une lvalue de type const X
  • t — une lvalue ou une rvalue const de type X
  • rv — une rvalue non const de type X
  • m — une valeur de type A

Notes

AllocatorAwareContainers appellent toujours std::allocator_traits<A>::construct(m, p, args) pour construire un objet de type T à p en utilisant args, avec m == get_allocator(). [Le construct par défaut de std::allocator appelle ::new((void*)p) T(args) (jusqu'à C++20) | std::allocator n'a pas de membre construct et std::construct_at(p, args) est appelé lors de la construction des éléments (depuis C++20)], mais les allocateurs spécialisés peuvent choisir une définition différente.

Bibliothèque standard

Tous les types de chaînes et conteneurs de la bibliothèque standard (sauf std::array et std::inplace_vector) sont des AllocatorAwareContainer :

  • basic_string — stocke et manipule des séquences de caractères (modèle de classe)
  • deque — file à double extrémité (modèle de classe)
  • forward_list (C++11) — liste simplement chaînée (modèle de classe)
  • list — liste doublement chaînée (modèle de classe)
  • vector — tableau dynamique contigu (modèle de classe)
  • map — collection de paires clé-valeur, triées par clés, les clés étant uniques (modèle de classe)
  • multimap — collection de paires clé-valeur, triées par clés (modèle de classe)
  • set — collection de clés uniques, triées par clés (modèle de classe)
  • multiset — collection de clés, triées par clés (modèle de classe)
  • unordered_map (C++11) — collection de paires clé-valeur, hachées par clés, les clés étant uniques (modèle de classe)
  • unordered_multimap (C++11) — collection de paires clé-valeur, hachée par clés (modèle de classe)
  • unordered_set (C++11) — collection de clés uniques, hachées par clés (modèle de classe)
  • unordered_multiset (C++11) — collection de clés, hachées par clés (modèle de classe)
