Exigences nommées C++ : Swappable

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Toute lvalue ou rvalue de ce type peut être échangée avec toute lvalue ou rvalue d'un autre type, à l'aide de l'appel de fonction non qualifié swap() dans le contexte où std::swap et les swap() définis par l'utilisateur sont tous deux visibles.

Exigences

Le type U est échangeable avec le type T si, pour tout objet u de type U et tout objet t de type T,

Expression Exigences Sémantique
#include <algorithm> // until C++11 #include <utility> // since C++11 using std::swap; swap(u, t); Après l'appel, la valeur de t est la valeur détenue par u avant l'appel, et la valeur de u est la valeur détenue par t avant l'appel. Appelle la fonction nommée swap() trouvée par résolution de surcharge parmi toutes les fonctions portant ce nom trouvées par recherche dépendante des arguments et les deux modèles std::swap définis dans l'en-tête [<algorithm> (jusqu'à C++11)
#include <algorithm> // until C++11 #include <utility> // since C++11 using std::swap; swap(t, u); Identique Identique

De nombreuses fonctions de la bibliothèque standard (par exemple, de nombreux algorithmes) attendent que leurs arguments satisfassent Swappable, ce qui signifie que chaque fois que la bibliothèque standard effectue un échange, elle utilise l'équivalent de using std::swap; swap(t, u);.

Les implémentations typiques font l'une des deux choses suivantes :

  1. Définissent un swap non membre dans l'espace de noms englobant, qui peut déléguer à un swap membre si l'accès à des membres de données non publics est nécessaire.

  2. Définissent une fonction amie dans la classe (cette approche masque le swap propre à la classe à la recherche de noms autre que ADL).

Notes

Il n'est pas spécifié si [<algorithm> (jusqu'à C++11) | <utility> (depuis C++11)] est effectivement inclus lorsque les fonctions de la bibliothèque standard effectuent l'échange ; l'utilisateur ne doit donc pas s'attendre à ce que swap() fourni par l'utilisateur soit inclus.

Exemple

#include <iostream>
#include <vector>

struct IntVector
{
    std::vector<int> v;

    IntVector& operator=(IntVector) = delete; // non affectable

    void swap(IntVector& other)
    {
        v.swap(other.v);
    }

    void operator()(auto rem, auto term = " ")
    {
        std::cout << rem << "{{";
        for (int n{}; int e : v)
            std::cout << (n++ ? ", " : "") << e;
        std::cout << "}}" << term;
    }
};

void swap(IntVector& v1, IntVector& v2)
{
    v1.swap(v2);
}

int main()
{
    IntVector v1{{1, 1, 1, 1}}, v2{{2222, 2222}};

    auto prn = [&]{ v1("v1", ", "), v2("v2", ";\n"); };

//  std::swap(v1, v2); // Erreur du compilateur ! std::swap exige MoveAssignable
    prn();
    std::iter_swap(&v1, &v2); // OK : la bibliothèque appelle swap() non qualifié
    prn();
    std::ranges::swap(v1, v2); // OK : la bibliothèque appelle swap() non qualifié
    prn();
}

Output:

v1{{1, 1, 1, 1}}, v2{{2222, 2222}};
v1{{2222, 2222}}, v2{{1, 1, 1, 1}};
v1{{1, 1, 1, 1}}, v2{{2222, 2222}};
