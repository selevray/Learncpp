Exigences nommées C++ : Hash (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un Hash est un objet fonction dont la sortie ne dépend que de l'entrée et qui a une probabilité très faible de produire la même sortie pour des valeurs d'entrée différentes.

Exigences

Le type T satisfait Hash si

  • Le type T satisfait FunctionObject, CopyConstructible, Destructible, et

Soient

  • h, une valeur de type T ou const T, dont le type d'argument est Key,
  • k, une valeur de type convertible en Key ou const Key,
  • u, une expression lvalue de type Key.

Les expressions suivantes doivent être valides et produire les effets spécifiés.

Expression | Type de retour | Exigences

h(k) | std::size_t | La valeur retournée ne dépend que de la valeur de k pendant la durée du programme.

Toutes les évaluations de h(k) exécutées au cours d'une même exécution d'un programme donnent le même résultat pour la même valeur de k.

La probabilité de h(a) == h(b) pour a != b devrait tendre vers 1.0 / std::numeric_limits<std::size_t>::max().

h(u) | std::size_t | u n'est pas modifié.
