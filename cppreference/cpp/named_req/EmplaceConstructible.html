Exigences nommées C++ : EmplaceConstructible (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Spécifie qu'un objet du type peut être construit à partir d'un ensemble donné d'arguments dans un stockage non initialisé, par un allocateur donné.

Exigences

Le type T est EmplaceConstructible dans le Container X (dont value_type est identique à T) à partir des arguments args si, étant donné

  • A — un type d'allocateur
  • m — une lvalue de type A
  • p — le pointeur de type T* préparé par le conteneur
  • args — zéro argument ou plus

où X::allocator_type est identique à std::allocator_traits<A>::rebind_alloc<T>,

l'expression suivante est bien formée :

std::allocator_traits<A>::construct(m, p, args);

Si X n'est pas conscient des allocateurs ou est une spécialisation de std::basic_string, le terme est défini comme si A était std::allocator<T>, sauf qu'aucun objet allocateur n'a besoin d'être créé, et que les spécialisations définies par l'utilisateur de std::allocator ne sont pas instanciées.

Notes

Bien qu'il soit exigé que construct personnalisé soit utilisé lors de la construction des éléments de std::basic_string jusqu'en C++23, toutes les implémentations n'utilisaient que le mécanisme par défaut. L'exigence est corrigée par P1072R10 pour correspondre à la pratique existante.
