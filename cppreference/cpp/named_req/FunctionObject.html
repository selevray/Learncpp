Exigences nommées C++ : FunctionObject

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un type FunctionObject est le type d'un objet pouvant être utilisé à gauche de l'opérateur d'appel de fonction.

Exigences

Le type T satisfait FunctionObject si

  • Le type T satisfait std::is_object, et

Soient

  • f, une valeur de type T ou const T,
  • args, liste d'arguments appropriée, pouvant être vide.

Les expressions suivantes doivent être valides :

Expression Exigences
f(args) effectue un appel de fonction

Notes

Les fonctions et les références vers des fonctions ne sont pas des types d'objets fonction, mais peuvent être utilisées là où des types d'objets fonction sont attendus grâce à la conversion implicite de fonction en pointeur.

Bibliothèque standard

  • Tous les pointeurs vers des fonctions satisfont cette exigence.
  • Tous les objets fonction définis dans <functional>.
  • Certains types de retour des fonctions de <functional>.

Exemple

Illustre différents types d'objets fonction.

#include <functional>
#include <iostream>

void foo(int x) { std::cout << "foo(" << x << ")\n"; }
void bar(int x) { std::cout << "bar(" << x << ")\n"; }

int main()
{
    void(*fp)(int) = foo;
    fp(1); // appelle foo à l'aide du pointeur vers fonction

    std::invoke(fp, 2); // tous les types FunctionObject sont Callable

    auto fn = std::function(foo); // voir aussi le reste de <functional>
    fn(3);
    fn.operator()(3); // même effet que fn(3)

    struct S
    {
        void operator()(int x) const { std::cout << "S::operator(" << x << ")\n"; }
    } s;
    s(4); // appelle s.operator()
    s.operator()(4); // identique à s(4)

    auto lam = [](int x) { std::cout << "lambda(" << x << ")\n"; };
    lam(5); // appelle la lambda
    lam.operator()(5); // identique à lam(5)

    struct T
    {
        using FP = void (*)(int);
        operator FP() const { return bar; }
    } t;
    t(6); // t est converti en pointeur vers fonction
    static_cast<void (*)(int)>(t)(6); // identique à t(6)
    t.operator T::FP()(6); // identique à t(6)
}

Output:

foo(1)
foo(2)
foo(3)
foo(3)
S::operator(4)
S::operator(4)
lambda(5)
lambda(5)
bar(6)
bar(6)
bar(6)
