Exigences nommées C++ : RandomNumberEngineAdaptor (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un RandomNumberEngineAdaptor est un RandomNumberEngine qui transforme la sortie d'un autre RandomNumberEngine, ce dernier étant appelé moteur de base.

Exigences

Soient

  • B, a RandomNumberEngine
  • b, un objet de type B
  • A, un RandomNumberEngineAdaptor, adaptant B comme moteur de base
  • a, un objet de type A
function semantics
A::A(); Le moteur de base est initialisé comme par son constructeur par défaut.
bool operator==(const A& lhs, const A& rhs); Renvoie si le moteur de base de lhs est égal ou non au moteur de base de rhs.
A::A(result_type s); Le moteur de base est initialisé avec s.
template<class Sseq> A::A(Sseq& q); Le moteur de base est initialisé avec q.
void seed(); Invoque b.seed().
void seed(result_type s); Invoque b.seed(s).
template<class Sseq> void seed(Sseq& q); Invoque b.seed(q).

De plus

  • La complexité de chaque fonction de A ne dépasse pas la complexité de la fonction de B
  • L'état de A inclut l'état de B
  • La taille de l'état de A n'est pas inférieure à la taille de b
  • La copie de l'état de A inclut la copie de l'état de B
  • La représentation textuelle de A inclut la représentation textuelle de B

Bibliothèque standard

Les installations suivantes de la bibliothèque standard satisfont RandomNumberEngineAdaptor :

  • discard_block_engine (C++11) — ignore une partie de la sortie d'un moteur de nombres aléatoires (modèle de classe)
  • independent_bits_engine (C++11) — regroupe la sortie d'un moteur de nombres aléatoires en blocs d'un nombre de bits spécifié (modèle de classe)
  • shuffle_order_engine (C++11) — fournit la sortie d'un moteur de nombres aléatoires dans un ordre différent (modèle de classe)
