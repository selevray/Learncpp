Exigences nommées C++ : Container

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un Container est un objet utilisé pour stocker d'autres objets et qui gère la mémoire utilisée par les objets qu'il contient.

Exigences

Étant donnés les types et valeurs suivants :

Type Définition

  • T — un type objet
  • C — une classe conteneur contenant des objets de type T

Valeur Définition

  • u, v — des valeurs de type C ou const C
  • mv — une valeur de type C
  • cv — une valeur de type const C
  • lhs, rhs — des lvalues de type C
  • i, j — des valeurs de type C::iterator ou const C::iterator

C satisfait les exigences de Container si les types, instructions et expressions suivants sont bien formés et ont la sémantique spécifiée :
