Exigences nommées C++ : UniformRandomBitGenerator (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un générateur uniforme de bits aléatoires est un objet fonction renvoyant des valeurs entières non signées telles que chaque valeur de l'intervalle des résultats possibles a (idéalement) une probabilité égale.

Les générateurs uniformes de bits aléatoires ne sont pas destinés à être utilisés comme générateurs de nombres aléatoires : ils servent de source de bits aléatoires (générés en masse, pour l'efficacité). Tout générateur uniforme de bits aléatoires peut être branché sur n'importe quelle distribution de nombres aléatoires afin d'obtenir un nombre aléatoire (formellement, une variable aléatoire).

Exigences

Le type G satisfait UniformRandomBitGenerator si

Étant donné g, une valeur de type G, toutes les conditions suivantes sont satisfaites :

  • G::result_type est valide et désigne un type entier non signé.
  • Les expressions suivantes doivent être valides et avoir les effets spécifiés :

(jusqu'à C++20)

Expression | Type | Exigences

G::min() | G::result_type |

  • Renvoie la plus petite valeur que operator() de G peut renvoyer.
  • La valeur du résultat est strictement inférieure à G::max().
  • L'expression doit être une expression constante.

G::max() | G::result_type |

  • Renvoie la plus grande valeur que operator() de G peut renvoyer.
  • La valeur du résultat est strictement supérieure à G::min().
  • L'expression doit être une expression constante.

g() | G::result_type |

  • Renvoie une valeur dans l'intervalle fermé [G::min(),G::max()].
  • A une complexité constante amortie.

Toutes les conditions suivantes sont satisfaites :

  • G modélise uniform_random_bit_generator.
  • std::invoke_result_t<G&> est un type entier non signé.
  • G fournit un nom imbriqué typedef result_type, qui désigne le même type que std::invoke_result_t<G&>.

(depuis C++20)

Notes

Tous les RandomNumberEngines satisfont cette exigence.

Bibliothèque standard

Les installations suivantes de la bibliothèque standard attendent un type UniformRandomBitGenerator.

  • random_shuffleshuffle (until C++17) (C++11) — réorganise aléatoirement les éléments d'un intervalle (modèle de fonction)
  • sample (C++17) — sélectionne N éléments aléatoires d'une séquence (modèle de fonction)
  • generate_canonical (C++11) — répartit uniformément des valeurs réelles de précision donnée sur [0,1) (modèle de fonction)
  • uniform_int_distribution (C++11) — produit des valeurs entières réparties uniformément sur un intervalle (modèle de classe)
  • uniform_real_distribution (C++11) — produit des valeurs réelles réparties uniformément sur un intervalle (modèle de classe)

toutes les autres distributions de nombres aléatoires

Les installations suivantes de la bibliothèque standard satisfont UniformRandomBitGenerator sans satisfaire en plus RandomNumberEngine :

  • random_device (C++11) — générateur de nombres aléatoires non déterministe utilisant une source d'entropie matérielle (classe)
