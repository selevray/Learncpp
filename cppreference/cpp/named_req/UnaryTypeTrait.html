Exigences nommées C++ : UnaryTypeTrait (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un UnaryTypeTrait est un modèle de classe qui décrit une propriété de son paramètre de modèle de type avec une spécialisation std::integral_constant (généralement std::bool_constant).

Exigences

  • DefaultConstructible and CopyConstructible.
  • Prend un paramètre de type de modèle (des paramètres de modèle supplémentaires sont facultatifs et autorisés).
  • Dérivé publiquement et sans ambiguïté d'une spécialisation de std::integral_constant, appelée sa caractéristique de base.
  • Les noms de membres de la caractéristique de base ne sont pas masqués et sont disponibles sans ambiguïté.

Bibliothèque standard

Les traits de types suivants satisfont tous UnaryTypeTrait :

  • Catégories de types primaires
  • Catégories de types composés
  • Propriétés de types
  • Opérations prises en charge
  • Requêtes de propriétés

Les modèles de classes suivants de la bibliothèque standard satisfont également UnaryTypeTrait.

  • integral_constant (C++11) — constante de compilation du type spécifié avec la valeur spécifiée (modèle de classe)

  • negation (C++17) — métafonction de négation logique (modèle de classe)

  • std::tuple_size<std::tuple> (C++11) — obtient la taille de

    un tuple (spécialisation de modèle de classe)

  • std::tuple_size<std::array> (C++11) — obtient la taille d'un array (spécialisation de modèle de classe)

  • std::tuple_size<std::pair> (C++11) — obtient la taille d'un pair (spécialisation de modèle de classe)

  • variant_sizevariant_size_v (C++17) — obtient le nombre d'alternatives de variant à la compilation (modèle de classe) (modèle de variable)

  • is_bind_expression (C++11) — indique qu'un objet est une expression std::bind ou peut être utilisé comme telle (modèle de classe)

  • is_placeholder (C++11) — indique qu'un objet est un marqueur de place standard ou peut être utilisé comme tel (modèle de classe)

  • is_execution_policy (C++17) — teste si une classe représente une politique d'exécution (modèle de classe)
