Exigences nommées C++ : SharedTimedLockable (depuis C++14)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les exigences SharedTimedLockable décrivent les caractéristiques des types qui fournissent une sémantique de blocage partagé temporisé pour les agents d'exécution (threads, processus, tâches).

Exigences

  • SharedLockable

Pour que le type L soit SharedTimedLockable, étant donné

  • rel_time, une valeur d'une spécialisation de std::chrono::duration, et
  • abs_time, une valeur d'une spécialisation de std::chrono::time_point,

les conditions suivantes doivent être satisfaites pour un objet m de type L :

Expression Exigences Valeur de retour
m.try_lock_shared_for(rel_time) Bloque pendant la durée fournie rel_time ou jusqu'à ce qu'un verrou sur m soit acquis. true si le verrou a été acquis, false sinon.
m.try_lock_shared_until(abs_time) Bloque jusqu'à ce que le point temporel fourni abs_time soit atteint ou qu'un verrou sur m soit acquis. true si le verrou a été acquis, false sinon.

Notes

Les fonctions membres try_lock_shared_for et try_lock_shared_until obtiennent un verrou partagé sur m en cas de succès.

Bibliothèque standard

Les types de la bibliothèque standard suivants satisfont les exigences SharedTimedLockable :

  • shared_timed_mutex (C++14) — fournit un mécanisme d'exclusion mutuelle partagée et implémente le verrouillage avec délai d'attente (classe)
