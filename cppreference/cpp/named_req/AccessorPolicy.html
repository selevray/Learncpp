Exigences nommées C++ : AccessorPolicy (depuis C++23)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

AccessorPolicy définit comment les éléments sont accédés à partir d'un handle de données donné vers ces éléments et d'un index. Il est utilisé comme politique dans std::mdspan pour spécifier l'accès à une référence d'élément à l'aide d'un index 1D sous-jacent.

Exigences

Un type A satisfait AccessorPolicy s'il modélise copyable, et les éléments suivants sont true :

  • std::is_nothrow_move_constructible_v<A>
  • std::is_nothrow_move_assignable_v<A>
  • std::is_nothrow_swappable_v<A>

Et, étant donnés les types et valeurs suivants, les expressions indiquées dans le tableau ci-dessous sont valides et ont la sémantique indiquée :

Légende

Type Définition

  • A — un type de politique d'accesseur
  • OP — un type de politique de décalage

Valeur Définition

  • a — une valeur de type (éventuellement qualifié const) A
  • p — une valeur de type (éventuellement qualifié const) A::data_handle_type
  • i, j, n — valeurs de type std::size_t

Types membres

Nom | Type | Exigences

A::element_type | (non spécifié) |

  • Un type objet complet qui n'est pas un type classe abstraite

A::data_handle_type | (non spécifié) mais le type n'a pas besoin d'être element_type* |

  • Modélise copyable
  • Les conditions suivantes sont toutes true :
    • std::is_nothrow_move_constructible_v<typename A::data_handle_type>
    • std::is_nothrow_move_assignable_v<typename A::data_handle_type>
    • std::is_nothrow_swappable_v<typename A::data_handle_type>

A::reference | (non spécifié) mais le type n'a pas besoin d'être element_type& |

  • std::common_reference_with<typename A::reference&&, typename A::element_type&> is true

A::offset_policy | OP |

  • Satisfait les exigences de AccessorPolicy
  • std::constructible_from<OP, const A&> is true
  • typename OP::element_type et typename A::element_type sont du même type

Fonctions membres

Expression | Type de retour | Sémantique

a.access(p, i) | typename A::reference |

  • L'expression est préservant l'égalité.

a.offset(p, i) | typename A::offset_policy::data_handle_type |

  • Une valeur q telle que pour b égal à A::offset_policy(a), et tout entier n pour lequel [0,n) est un intervalle accessible[note 1] de p et a.

    • [0,n - i) est un intervalle accessible de q et b ; et
    • b.access(q, j) donne accès au même élément que a.access(p, i + j), pour chaque j de l'intervalle [0,n - i).

  • L'expression est préservant l'égalité.

  1. ↑ Un intervalle d'indices [0,N) est un intervalle accessible d'un handle de données donné et d'un accessor si, pour chaque indice de l'intervalle, la fonction membre access produit une référence valide vers un élément.

Bibliothèque standard

Les types de la bibliothèque standard suivants satisfont les exigences AccessorPolicy :

  • default_accessor (C++23) — un type pour l'accès indexé aux éléments de mdspan (modèle de classe)
  • aligned_accessor (C++26) — un type pour l'accès aligné aux éléments de mdspan (modèle de classe)

Défini dans l'espace de noms std::linalg

  • scaled_accessor (C++26) — std::mdspan politique d'accesseur dont la référence représente le produit d'un facteur d'échelle fixe et de la référence de son accesseur imbriqué std::mdspan (modèle de classe)
  • conjugated_accessor (C++26) — std::mdspan politique d'accesseur dont la référence représente le conjugué complexe de la référence de son accesseur imbriqué std::mdspan (modèle de classe)
