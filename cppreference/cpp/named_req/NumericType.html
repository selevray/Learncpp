Exigences nommées C++ : NumericType

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Spécifie que le type peut être utilisé comme argument de modèle de std::valarray.

Exigences

Pour qu'un type T soit un NumericType, il doit être un type objet non qualifié cv qui :

  • Satisfait aux exigences de DefaultConstructible, CopyConstructible, CopyAssignable et Destructible.
  • Aucune opération sur T ne peut lever d'exception.
