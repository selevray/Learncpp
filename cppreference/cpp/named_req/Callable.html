Exigences nommées C++ : Callable

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un type Callable est un type pour lequel les opérations INVOKE et INVOKE<R> (utilisées par, p. ex., std::function, std::bind et std::thread::thread) sont applicables.

INVOKE peut être effectué explicitement à l'aide de la fonction de bibliothèque std::invoke.

(depuis C++17)

INVOKE<R> peut être effectué explicitement à l'aide de la fonction de bibliothèque std::invoke_r.

(depuis C++23)

Exigences

Le type T satisfait Callable si

Soient

  • f, un objet de type T,
  • ArgTypes, liste appropriée de types d'arguments,
  • R, type de retour approprié.

Les expressions suivantes doivent être valides :

Expression Exigences
INVOKE<R>(f, std::declval<ArgTypes>()...) L'expression est bien formée dans un contexte non évalué.

Notes

Les pointeurs vers membres de données sont Callable, même si aucun appel de fonction n'a lieu.

Bibliothèque standard

En outre, les composants suivants de la bibliothèque standard acceptent tout type Callable (et pas seulement FunctionObject) :

  • function (C++11) — enveloppe copiable de tout objet appelable copiable (modèle de classe)
  • move_only_function (C++23) — enveloppe uniquement déplaçable de tout objet appelable prenant en charge les qualificateurs dans une signature d'appel donnée (modèle de classe)
  • copyable_function (C++26) — enveloppe copiable de tout objet appelable copiable prenant en charge les qualificateurs dans une signature d'appel donnée (modèle de classe)
  • function_ref (C++26) — enveloppe ne possédant pas l'objet de tout objet appelable (modèle de classe)
  • bind (C++11) — lie un ou plusieurs arguments à un objet fonction (modèle de fonction)
  • bind_frontbind_back (C++20) (C++23) — lie un nombre variable d'arguments, dans l'ordre, à un objet fonction (modèle de fonction)
  • reference_wrapper (C++11) — CopyConstructible et CopyAssignable enveloppe de référence (modèle de classe)
  • result_ofinvoke_result (C++11) (removed in C++20) (C++17) — déduit le type de résultat de l'appel d'un objet appelable avec un ensemble d'arguments (modèle de classe)
  • thread (C++11) — gère un thread distinct (classe)
  • jthread (C++20) — std::thread avec prise en charge de la jointure automatique et de l'annulation (classe)
  • call_once (C++11) — invoque une fonction une seule fois, même si elle est appelée depuis plusieurs threads (modèle de fonction)
  • async (C++11) — exécute une fonction de manière asynchrone (potentiellement dans un nouveau thread) et renvoie un std::future qui contiendra le résultat (modèle de fonction)
  • packaged_task (C++11) — empaquette une fonction pour stocker sa valeur de retour en vue d'une récupération asynchrone (modèle de classe)
