Exigences nommées C++ : Formatter (depuis C++20)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Formatter est un type qui abstrait les opérations de formatage pour un type d'argument de formatage et un type de caractère donnés. Les spécialisations de std::formatter fournies par la bibliothèque standard doivent satisfaire les exigences de Formatter, sauf indication contraire.

Un Formatter peut formater à la fois des arguments const et non const, typiquement en fournissant une fonction membre format qui prend une référence const.

Exigences

Un type satisfait Formatter s'il satisfait BasicFormatter et qu'étant donné les types et valeurs suivants, les expressions indiquées dans le tableau ci-dessous sont valides et ont la sémantique indiquée :

Type Définition

  • CharT — un type de caractère
  • Arg — un type d'argument de formatage
  • Formatter — un type Formatter pour les types Arg et CharT
  • OutputIt — un type LegacyOutputIterator
  • ParseCtx — std::basic_format_parse_context<CharT>
  • FmtCtx — std::basic_format_context<OutputIt, CharT>

Valeur Définition

  • f — une valeur de type (éventuellement qualifié const) Formatter
  • arg — une lvalue de type Arg
  • t — une valeur d'un type convertible en Arg (éventuellement qualifié const)
  • parse_ctx — une lvalue de type ParseCtx satisfaisant toutes les conditions suivantes :
    • parse_ctx.begin() pointe vers le début du format-spec du champ de remplacement en cours de formatage dans la chaîne de format.
    • Si format-spec est absent ou vide, alors soit parse_ctx.begin() == parse_ctx.end(), soit *parse_ctx.begin() == '}'.
  • fmt_ctx — une lvalue de type FmtCtx

Expression | Type de retour | Sémantique

f.format(t, fmt_ctx) | FmtCtx::iterator |

  • Formate t selon les spécificateurs stockés dans f, écrit la sortie dans fmt_ctx.out() et renvoie un itérateur de fin de l'intervalle de sortie.
  • La sortie ne peut dépendre que de
    • t,
    • fmt_ctx.locale(),
    • l'intervalle [parse_ctx.begin(),parse_ctx.end()) depuis le dernier appel à f.parse(parse_ctx), et
    • fmt_ctx.arg(n) pour toute valeur n de type std::size_t.

f.format(arg, fmt_ctx) | FmtCtx::iterator | Comme ci-dessus, mais ne modifie pas arg.
