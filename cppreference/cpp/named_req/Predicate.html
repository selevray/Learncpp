Exigences nommées C++ : Predicate

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les exigences Predicate décrivent un objet appelable qui renvoie une valeur BooleanTestable.

Predicate est généralement utilisé avec des algorithmes qui prennent des données d'entrée (objets/conteneurs individuels) et un prédicat, qui est ensuite appelé sur les données d'entrée pour décider de la suite à donner. Voici quelques exemples d'utilisation de prédicats dans la bibliothèque standard C++ :

  • std::all_of, std::any_of, std::none_of prennent en entrée un tableau d'éléments et un prédicat. Appellent le prédicat sur chaque élément d'entrée, et renvoient true si pour tous/au moins un/aucun élément, le prédicat renvoie true.

  • std::find_if prend une séquence d'éléments et un prédicat. Renvoie le premier élément de la séquence pour lequel le prédicat renvoie une valeur égale à true.

La description des fonctionnalités d'algorithmes donnée ci-dessus est sommaire et vise à expliquer Predicate en termes simples. Pour des informations détaillées, consultez les pages individuelles.

Autrement dit, si un algorithme prend un Predicate pred et un itérateur first, il doit pouvoir tester l'objet du type pointé par l'itérateur first à l'aide du prédicat donné, via une construction telle que if (pred(*first)) { /*...*/ }.

L'objet fonction pred ne doit appliquer aucune fonction non constante via l'itérateur déréférencé et doit accepter un argument const, avec le même comportement que l'argument soit const ou non-const. Cet objet fonction peut être un pointeur de fonction ou un objet d'un type disposant d'un opérateur d'appel de fonction approprié.
