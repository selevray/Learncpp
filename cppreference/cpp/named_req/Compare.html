Exigences nommées C++ : Compare

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Compare est un ensemble d'exigences attendues par certaines fonctionnalités de la bibliothèque standard, pour les types d'objets fonction fournis par l'utilisateur.

La valeur de retour de l'opération d'appel de fonction appliquée à un objet d'un type satisfaisant Compare, lorsqu'elle est convertie en bool, donne true si le premier argument de l'appel apparaît avant le second dans la relation d'ordre faible strict induite par ce type, et false sinon.

Comme pour toute BinaryPredicate, l'évaluation de cette expression ne doit pas appeler de fonctions non const via les itérateurs déréférencés et, syntaxiquement, l'appel de fonction doit accepter des arguments d'objet const, avec le même comportement que les arguments soient const ou non-const.

Exigences

Le type T satisfait Compare si

Soient

  • comp, un objet de type T,
  • equiv(a, b), une expression équivalente à !comp(a, b) && !comp(b, a).

Les expressions suivantes doivent être valides et avoir les effets spécifiés :

Expression | Type de retour | Exigences

comp(a, b) |

satisfait BooleanTestable

(jusqu'à C++20)

modélise boolean-testable

(depuis C++20)

| Établit une relation d'ordre faible strict avec les propriétés suivantes :

  • Pour tous a, comp(a, a) == false.
  • Si comp(a, b) == true alors comp(b, a) == false.
  • si comp(a, b) == true et comp(b, c) == true alors comp(a, c) == true.

equiv(a, b) | bool | Établit une relation d'équivalence avec les propriétés suivantes :

  • Pour tous a, equiv(a, a) == true.
  • Si equiv(a, b) == true, alors equiv(b, a) == true.
  • Si equiv(a, b) == true et equiv(b, c) == true, alors equiv(a, c) == true.

Note : comp induit un ordre total strict sur les classes d'équivalence déterminées par equiv.
