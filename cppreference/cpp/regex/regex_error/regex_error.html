  1. Construit un regex_error avec un ecode donné de type std::regex_constants::error_type.

  2. Constructeur de copie. Initialise le contenu avec celui de other. Si *this et other ont tous deux le type dynamique std::regex_error, alors std::strcmp(what(), other.what()) == 0.

Paramètres

  • ecode — code d'erreur indiquant l'erreur survenue lors de l'analyse de l'expression régulière
  • other — autre objet regex_error à copier
