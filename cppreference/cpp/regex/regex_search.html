Détermine s'il existe une correspondance entre l'expression régulière e et une sous-séquence de la séquence de caractères cible. Le résultat détaillé de la correspondance est stocké dans m (si présent).

1,2) La séquence de caractères cible est représentée par l'intervalle [first,last).

Si BidirIt ne satisfait pas aux exigences de LegacyBidirectionalIterator, le comportement est indéfini.

(jusqu'à C++23)

Si BidirIt ne modélise pas bidirectional_iterator, le comportement est indéfini.

(depuis C++23)

3,4) La séquence de caractères cible est représentée par l'intervalle [str,str + std::char_traits<CharT>::length(str)).

5,6) La séquence de caractères cible est représentée par la chaîne s.

  1. La séquence de caractères cible ne peut pas être représentée par une rvalue de type std::string.

Si aucune correspondance n'existe, les expressions suivantes impliquant m (si elle existe) doivent donner les valeurs spécifiées :

Expression Valeur
m.ready() true
m.size() 0
m.empty() true

Si une correspondance existe, pour tout entier de (0,m.size()) noté n, les expressions suivantes impliquant m doivent donner les valeurs spécifiées pour chaque surcharge listée ci-dessous :

Expression | Valeur

Surcharge (1) | Surcharge (3) | Surcharge (5)

m.ready() | true

m.size() | 1 + e.mark_count()

m.empty() | false

m.prefix().first | first | str | s.begin()

m.prefix().second | m[0].first

m.prefix().matched | m.prefix().first != m.prefix().second

m.suffix().first | m[0].second

m.suffix().second | last | std::char_traits<CharT>:: length(str) + str | s.end()

m.suffix().matched | m.suffix().first != m.suffix().second

m[0].first | le début de la séquence correspondant à e

m[0].second | la fin de la séquence correspondant à e

m[0].matched | true

m[n].first |

  • last si la sous-expression marquée n n'a pas participé à la correspondance
  • le début de la séquence sinon, correspondant à la sous-expression n sinon

m[n].second |

  • last si la sous-expression marquée n n'a pas participé à la correspondance
  • la fin de la séquence sinon, correspondant à la sous-expression n sinon

m[n].matched |

  • false si la sous-expression marquée n n'a pas participé à la correspondance
  • true sinon

Paramètres

  • first, last — l'intervalle de caractères cible
  • str — la chaîne C terminée par un caractère nul cible
  • s — le std::basic_string cible
  • m — les résultats de correspondance
  • e — l'expression régulière
  • flags — indicateurs utilisés pour déterminer la manière dont la correspondance sera effectuée

Valeur de retour

Renvoie true si une correspondance existe, false sinon.

Notes

Pour examiner toutes les correspondances de la séquence cible, std::regex_search peut être appelée dans une boucle, en repartant à chaque fois de m[0].second de l'appel précédent. std::regex_iterator offre une interface simple pour cette itération.

Exemple

#include <cstddef>
#include <iostream>
#include <regex>
#include <string>

int main()
{
    std::string lines[] = {"Roses are #ff0000",
                           "violets are #0000ff",
                           "all of my base are belong to you"};

    std::regex color_regex("#([a-f0-9]{2})"
                            "([a-f0-9]{2})"
                            "([a-f0-9]{2})");

    // correspondance simple
    for (const auto& line : lines)
        std::cout << line << ": " << std::boolalpha
                  << std::regex_search(line, color_regex) << '\n';
    std::cout << '\n';

    // affiche le contenu des sous-expressions marquées dans chaque correspondance
    std::smatch color_match;
    for (const auto& line : lines)
        if (std::regex_search(line, color_match, color_regex))
        {
            std::cout << "matches for '" << line << "'\n";
            std::cout << "Prefix: '" << color_match.prefix() << "'\n";
            for (std::size_t i = 0; i < color_match.size(); ++i)
                std::cout << i << ": " << color_match[i] << '\n';
            std::cout << "Suffix: '" << color_match.suffix() << "\'\n\n";
        }

    // recherche répétée (voir aussi std::regex_iterator)
    std::string log(R"(
        Speed:	366
        Mass:	35
        Speed:	378
        Mass:	32
        Speed:	400
	Mass:	30)");
    std::regex r(R"(Speed:\t\d*)");
    for (std::smatch sm; regex_search(log, sm, r);)
    {
        std::cout << sm.str() << '\n';
        log = sm.suffix();
    }

    // démonstration avec une chaîne de style C
    std::cmatch cm;
    if (std::regex_search("this is a test", cm, std::regex("test")))
        std::cout << "\nFound " << cm[0] << " at position "
                  << cm.prefix().length() << '\n';
}

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 2205 C++11 n pourrait être nul dans la postcondition ne peut être que positif
