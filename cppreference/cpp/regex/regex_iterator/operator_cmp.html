bool operator==( const regex_iterator& rhs ) const;  // (1) (depuis C++11)

Compare deux regex_iterator.

L'opérateur != est synthétisé à partir de operator==.

(depuis C++20)

Paramètres

  • rhs — un regex_iterator avec lequel comparer

Valeur de retour

Pour les besoins de l'exposé, supposons que regex_iterator contienne les membres suivants :

  • BidirIt begin;
  • BidirIt end;
  • const regex_type *pregex;
  • std::regex_constants::match_flag_type flags;
  • std::match_results<BidirIt> match;
  1. Renvoie true si *this et rhs sont tous deux des itérateurs de fin de séquence, ou si toutes les conditions suivantes sont vraies :
  • begin == rhs.begin
  • end == rhs.end
  • pregex == rhs.pregex
  • flags == rhs.flags
  • match[0] == rhs.match[0]
  1. Renvoie !(*this == rhs).
