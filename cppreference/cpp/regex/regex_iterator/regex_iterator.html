Construit un nouveau regex_iterator :

  1. Constructeur par défaut. Construit un itérateur de fin de séquence.

  2. Construit un regex_iterator à partir de la séquence de caractères [a,b), de l'expression régulière re et d'un indicateur m qui régit le comportement de la correspondance. Ce constructeur effectue un appel initial à std::regex_search avec ces données. Si le résultat de cet appel initial est false, *this est défini comme un itérateur de fin de séquence.

  3. Copie un regex_iterator.

  4. La surcharge (2) ne peut pas être appelée avec une expression régulière temporaire, car l'itérateur renvoyé serait immédiatement invalidé.

Paramètres

  • a — LegacyBidirectionalIterator vers le début de la séquence de caractères cible
  • b — LegacyBidirectionalIterator vers la fin de la séquence de caractères cible
  • re — expression régulière utilisée pour rechercher la séquence de caractères cible
  • m — indicateurs qui régissent le comportement de re

Exemple

#include <iostream>
#include <regex>
#include <string_view>

int main()
{
    constexpr std::string_view str{R"(
        #ONE: *p = &Mass;
        #Two: MOV %rd, 42
    )"};
    const std::regex re("[a-w]");

    // création de regex_iterator, surcharge (2)
    auto it = std::regex_iterator<std::string_view::iterator>
    {
        str.cbegin(), str.cend(),
        re // re est une lvalue ; si une expression immédiate était utilisée
           // à la place, par exemple std::regex{"[a-z]"}, cela produirait
           // une erreur, car la surcharge (4) est supprimée
    };

    for (decltype(it) last /* overload (1) */; it != last; ++it)
        std::cout << (*it).str();
    std::cout << '\n';
}

Output:

password
