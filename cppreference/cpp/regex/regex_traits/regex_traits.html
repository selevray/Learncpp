std::regex_traits<CharT>::regex_traits

regex_traits();

Construit par défaut l'objet std::regex_traits, y compris en construisant par défaut le membre privé std::locale ou tout autre état interne si nécessaire.

Paramètres

(aucune)

Valeur de retour

(aucune)

Exemple

#include <iostream>
#include <regex>

int main()
{
    std::locale::global(std::locale("en_US.utf8"));
    std::regex_traits<char> r1;
    std::regex_traits<wchar_t> r2;
    std::cout << "The regex locale is " << r1.getloc().name() << '\n';
}
