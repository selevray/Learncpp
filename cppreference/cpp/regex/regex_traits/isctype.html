std::regex_traits<CharT>::isctype

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool isctype( CharT c, char_class_type f ) const;

Détermine si le caractère c appartient à la classe de caractères identifiée par f, qui est à son tour une valeur renvoyée par lookup_classname() ou un OU binaire de plusieurs de ces valeurs.

La version de cette fonction fournie dans les spécialisations de la bibliothèque standard de std::regex_traits effectue les opérations suivantes :

  1. Convertit d'abord f en une valeur m de type std::ctype_base::mask.

Pour chaque catégorie std::ctype listée dans le tableau de la page lookup_classname(), si les bits de f correspondant à la catégorie sont activés, les bits correspondants de m seront également activés.

  1. Tente ensuite de classer le caractère dans la locale imprégnée en appelant std::use_facet<std::ctype<CharT>>(getloc()).is(m, c).
  • Si cet appel renvoie true, isctype() renverra également true.
  • Sinon, si c est égal à '_', et que f inclut le résultat de l'appel à lookup_classname() pour la classe de caractères [:w:], true est renvoyé, sinon false est renvoyé.

Paramètres

  • c — le caractère à classer
  • f — le masque de bits obtenu à partir d'un ou plusieurs appels à lookup_classname()

Valeur de retour

true si c est classé par f, false sinon.

Exemple

#include <iostream>
#include <regex>
#include <string>

int main()
{
    std::regex_traits<char> t;
    std::string str_alnum = "alnum";
    auto a = t.lookup_classname(str_alnum.begin(), str_alnum.end());
    std::string str_w = "w"; // [:w:] correspond à [:alnum:] plus '_'
    auto w = t.lookup_classname(str_w.begin(), str_w.end());
    std::cout << std::boolalpha
              << t.isctype('A', w) << ' ' << t.isctype('A', a) << '\n'
              << t.isctype('_', w) << ' ' << t.isctype('_', a) << '\n'
              << t.isctype(' ', w) << ' ' << t.isctype(' ', a) << '\n';
}

Output:

true true
true false
false false

Démontre une implémentation personnalisée des traits de regex de lookup_classname() / isctype() :

#include <cwctype>
#include <iostream>
#include <locale>
#include <regex>

// Ce trait de regex personnalisé utilise wctype/iswctype pour implémenter lookup_classname/isctype.
struct wctype_traits : std::regex_traits<wchar_t>
{
    using char_class_type = std::wctype_t;

    template<class It>
    char_class_type lookup_classname(It first, It last, bool = false) const
    {
        return std::wctype(std::string(first, last).c_str());
    }

    bool isctype(wchar_t c, char_class_type f) const
    {
        return std::iswctype(c, f);
    }
};

int main()
{
    std::locale::global(std::locale("ja_JP.utf8"));
    std::wcout.sync_with_stdio(false);
    std::wcout.imbue(std::locale());

    std::wsmatch m;
    std::wstring in = L"風の谷のナウシカ";
    // correspond à tous les caractères (ils sont classés comme alnum)
    std::regex_search(in, m, std::wregex(L"([[:alnum:]]+)"));
    std::wcout << "alnums: " << m[1] << '\n'; // prints "風の谷のナウシカ"
    // correspond uniquement aux katakana
    std::regex_search(in, m,
                      std::basic_regex<wchar_t, wctype_traits>(L"([[:jkata:]]+)"));
    std::wcout << "katakana: " << m[1] << '\n'; // prints "ナウシカ"
}

Output:

alnums: 風の谷のナウシカ
katakana: ナウシカ
