std::regex_traits<CharT>::transform

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class ForwardIt >
string_type transform( ForwardIt first, ForwardIt last) const;

Obtient la clé de tri pour la séquence de caractères [first,last), telle que si une clé de tri est inférieure à une autre clé de tri selon operator<, alors la séquence de caractères ayant produit la première clé de tri précède la séquence ayant produit la seconde, selon l'ordre de collationnement de la locale actuellement imprégnée.

Par exemple, lorsque l'indicateur de regex std::regex_constants::collate est activé, alors la séquence [a-b] correspondrait à un caractère c1 si traits.transform("a") <= traits.transform(c1) <= traits.transform("b"). Notez que cette fonction prend une séquence de caractères en argument pour s'adapter aux intervalles définis comme [[.ae.]-d].

Les spécialisations de la bibliothèque standard de std::regex_traits renvoient std::use_facet<std::collate<CharT>>(getloc()).transform(str.data(), str.data() + str.length()) pour une chaîne temporaire str construite comme string_type str(first, last).

Paramètres

  • first, last — une paire de LegacyForwardIterators qui détermine la séquence de caractères à comparer

Exigences sur les types

  • ForwardIt doit satisfaire aux exigences de LegacyForwardIterator.

Valeur de retour

La clé de collationnement pour la séquence de caractères [first,last) dans la locale actuellement imprégnée.
