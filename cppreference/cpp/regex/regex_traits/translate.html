Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

CharT translate( CharT c ) const;

Obtient la clé de comparaison pour le caractère c, de sorte que tous les caractères équivalents à ce caractère dans la locale imprégnée produisent la même clé.

Lorsque la bibliothèque regex doit comparer deux caractères c1 et c2 et que l'indicateur std::regex_constants::collate est true, elle exécute regex_traits<>::translate(c1) == regex_traits<>::translate(c2).

Les spécialisations de la bibliothèque standard de std::regex_traits renvoient c sans modification.

Paramètres

  • c — caractère dont l'équivalence doit être examinée

Valeur de retour

La clé de comparaison pour c dans la locale actuellement imprégnée.
