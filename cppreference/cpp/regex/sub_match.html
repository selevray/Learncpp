std::sub_match

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <regex>

template< class BidirIt >
class sub_match;  // (depuis C++11)

Le modèle de classe std::sub_match est utilisé par le moteur d'expressions régulières pour désigner les séquences de caractères correspondant aux sous-expressions marquées. Une correspondance est une paire [begin,end) dans l'intervalle cible apparié par l'expression régulière, mais avec des fonctions d'observation supplémentaires pour améliorer la clarté du code.

Seul le constructeur par défaut est accessible publiquement. Les instances de std::sub_match sont normalement construites et remplies dans le cadre d'un conteneur std::match_results lors du traitement de l'un des algorithmes regex.

Les fonctions membres renvoient des valeurs par défaut définies, sauf si le membre matched est true.

std::sub_match hérite de std::pair<BidirIt, BidirIt>, bien qu'il ne puisse pas être traité comme un objet std::pair, car les fonctions membres telles que l'affectation ne fonctionnent pas comme prévu.

Exigences de type

  • BidirIt doit satisfaire aux exigences de LegacyBidirectionalIterator.

Exemple

#include <cassert>
#include <iostream>
#include <regex>
#include <string>

int main()
{
    std::string sentence{"Friday the thirteenth."};
    const std::regex re{"([A-z]+) ([a-z]+) ([a-z]+)"};
    std::smatch words;
    std::regex_search(sentence, words, re);
    std::cout << std::boolalpha;
    for (const auto& m : words)
    {
        assert(m.matched);
        std::cout << "m: [" << m << "], m.length(): " << m.length() << ", "
                     "*m.first: '" << *m.first << "', "
                     "*m.second: '" << *m.second << "'\n";
    }
}

Output:

m: [Friday the thirteenth], m.length(): 21, *m.first: 'F', *m.second: '.'
m: [Friday], m.length(): 6, *m.first: 'F', *m.second: ' '
m: [the], m.length(): 3, *m.first: 't', *m.second: ' '
m: [thirteenth], m.length(): 10, *m.first: 't', *m.second: '.'
