std::match_results<BidirIt,Alloc>::str

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

string_type str( size_type n = 0 ) const;  // (depuis C++11)

Renvoie une chaîne représentant la sous-correspondance indiquée.

Si n == 0, une chaîne représentant l'expression entièrement correspondante est renvoyée.

Si 0 < n && n < size(), une chaîne représentant la ne sous-correspondance est renvoyée.

si n >= size(), une chaîne représentant la correspondance non trouvée est renvoyée.

L'appel est équivalent à string_type((*this)[n]);

ready() doit être true. Sinon, le comportement est indéfini.

Paramètres

  • n — nombre entier spécifiant la correspondance à renvoyer

Valeur de retour

Renvoie une chaîne représentant la correspondance ou sous-correspondance spécifiée.

Exemple

#include <iostream>
#include <regex>
#include <string>

int main()
{
    std::string target("baaaby");
    std::smatch sm;

    std::regex re1("a(a)*b");
    std::regex_search(target, sm, re1);
    std::cout << "entire match: " << sm.str(0) << '\n'
              << "submatch #1: " << sm.str(1) << '\n';

    std::regex re2("a(a*)b");
    std::regex_search(target, sm, re2);
    std::cout << "entire match: " << sm.str(0) << '\n'
              << "submatch #1: " << sm.str(1) << '\n';
}

Output:

entire match: aaab
submatch #1: a
entire match: aaab
submatch #1: aa
