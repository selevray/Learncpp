std::match_results<BidirIt,Alloc>::prefix

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

const_reference prefix() const;  // (depuis C++11)

Obtient une référence vers l'objet std::sub_match représentant la séquence cible comprise entre le début de la séquence cible et le début de la correspondance complète de l'expression régulière.

ready() doit être true. Sinon, le comportement est indéfini.

Valeur de retour

Référence vers le préfixe non correspondant.

Exemple

#include <iostream>
#include <regex>
#include <string>

int main()
{
    std::regex re("a(a)*b");
    std::string target("baaaby");
    std::smatch sm;

    std::regex_search(target, sm, re);
    std::cout << sm.prefix().str() << '\n';
}

Output:

b
