size_type size() const noexcept;  // (depuis C++11)

Renvoie le nombre de sous-correspondances, c'est-à-dire std::distance(begin(), end()).

Renvoie 0 si *this ne représente pas le résultat d'une correspondance réussie.

Paramètres

(aucune)

Valeur de retour

Le nombre de sous-correspondances.

Complexité

Constante.

Exemple

#include <iostream>
#include <regex>
#include <string>

int main()
{
    std::regex re("a(a)*b");
    std::string target("aaab");
    std::smatch sm;

    std::cout << sm.size() << '\n';

    std::regex_match(target, sm, re);
    std::cout << sm.size() << '\n';
}

Output:

0
2
