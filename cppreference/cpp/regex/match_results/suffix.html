std::match_results<BidirIt,Alloc>::suffix

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

const_reference suffix() const;  // (depuis C++11)

Obtient une référence vers l'objet std::sub_match représentant la séquence cible comprise entre la fin de la correspondance complète de l'expression régulière et la fin de la séquence cible.

ready() doit être true. Sinon, le comportement est indéfini.

Paramètres

(aucune)

Valeur de retour

Référence vers le suffixe non correspondant.

Exemple

#include <iostream>
#include <regex>
#include <string>

int main()
{
    std::regex re("a(a)*by");
    std::string target("baaaby123");
    std::smatch sm;

    std::regex_search(target, sm, re);
    std::cout << sm.suffix() << '\n';
}

Output:

123
