difference_type length( size_type n = 0 ) const;  // (depuis C++11)

Renvoie la longueur de la sous-correspondance spécifiée.

Si n == 0, la longueur de l'expression entière correspondante est renvoyée.

Si n > 0 && n < size(), la longueur de la ne sous-correspondance est renvoyée.

si n >= size(), une longueur de la correspondance non trouvée est renvoyée.

L'appel est équivalent à (*this)[n].length().

ready() doit être true. Sinon, le comportement est indéfini.

Paramètres

  • n — nombre entier spécifiant la correspondance à examiner

Valeur de retour

La longueur de la correspondance ou de la sous-correspondance spécifiée.
