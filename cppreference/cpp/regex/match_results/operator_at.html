const_reference operator[]( size_type n ) const;  // (depuis C++11)

Si n > 0 et n < size(), renvoie une référence vers le std::sub_match représentant la partie de la séquence cible correspondant au ne sous-motif capturé marqué.

Si n == 0, renvoie une référence vers le std::sub_match représentant la partie de la séquence cible correspondant à l'expression régulière entière.

si n >= size(), renvoie une référence vers un std::sub_match représentant une sous-expression non trouvée (un intervalle vide de la séquence cible).

ready() doit être true. Sinon, le comportement est indéfini.

Paramètres

  • n — nombre entier spécifiant la correspondance à renvoyer

Valeur de retour

Référence vers le std::sub_match représentant l'intervalle de correspondance spécifié dans la séquence cible.

Exemple

#include <iostream>
#include <regex>
#include <string>

int main()
{
    std::string target("baaaby");
    std::smatch sm;

    std::regex re1("a(a)*b");
    std::regex_search(target, sm, re1);
    std::cout << "entire match: " << sm[0] << '\n'
              << "submatch #1: " << sm[1] << '\n';

    std::regex re2("a(a*)b");
    std::regex_search(target, sm, re2);
    std::cout << "entire match: " << sm[0] << '\n'
              << "submatch #1: " << sm[1] << '\n';
}

Output:

entire match: aaab
submatch #1: a
entire match: aaab
submatch #1: aa
