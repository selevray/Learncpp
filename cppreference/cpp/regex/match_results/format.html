format produit une chaîne de format, en remplaçant les spécificateurs de format et les séquences d'échappement de cette chaîne par les données de correspondance provenant de *this.

  1. La séquence de caractères de format est définie par l'intervalle [fmt_first,fmt_last). La séquence de caractères résultante est copiée dans out.

  2. La séquence de caractères de format est définie par les caractères de fmt. La séquence de caractères résultante est copiée dans out.

3,4) La séquence de caractères de format est définie par les caractères de fmt et fmt_s respectivement. La séquence de caractères résultante est copiée dans un std::basic_string nouvellement construit, qui est renvoyé.

Le masque de bits flags détermine quels spécificateurs de format et quelles séquences d'échappement sont reconnus.

Le comportement de format est indéfini si ready() != true.

Paramètres

  • fmt_begin, fmt_end — pointeurs vers un intervalle de caractères définissant la séquence de caractères de format
  • fmt — std::basic_string définissant la séquence de caractères de format
  • fmt_s — pointeur vers une chaîne de caractères terminée par un caractère nul définissant la séquence de caractères de format
  • out — itérateur vers lequel la séquence de caractères résultante est copiée
  • flags — std::regex_constants::match_flag_type masque de bits spécifiant quels spécificateurs de format et quelles séquences d'échappement sont reconnus

Exigences sur les types

  • OutputIt doit satisfaire aux exigences de LegacyOutputIterator.

Valeur de retour

1,2) out

3,4) La chaîne nouvellement construite contenant la séquence de caractères résultante.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <iostream>
#include <regex>
#include <string>

int main()
{
    std::string s = "for a good time, call 867-5309";
    std::regex phone_regex("\\d{3}-\\d{4}");
    std::smatch phone_match;

    if (std::regex_search(s, phone_match, phone_regex))
    {
        std::string fmt_s = phone_match.format(
            "$`"   // $` désigne les caractères précédant la correspondance
            "[$&]" // $& désigne les caractères correspondants
            "$'"); // $' désigne les caractères suivant la correspondance
        std::cout << fmt_s << '\n';
    }
}

Output:

for a good time, call [867-5309]
