regex_replace utilise l'expression régulière re pour effectuer une substitution sur la séquence de caractères cible :

1,2) Copie les caractères de l'intervalle [first,last) vers out, en remplaçant toute séquence correspondant à re par les caractères formatés par fmt. Équivalent à :

using iter_type = std::regex_iterator<BidirIt, CharT, Traits>;
iter_type seq_begin(first, last, re, flags), seq_end;

using result_type = std::match_results<BidirIt>;
result_type m;

bool need_to_copy = (flags & std::regex_constants::format_no_copy) == 0;
bool format_all = (flags & std::regex_constants::format_first_only) != 0;

for (iter_type i = seq_begin; i != seq.end(); ++i)
{
    m = *i;
    if (need_to_copy)
        out = std::copy(m.prefix().first, m.prefix().second, out);
    if (format_all || i == seq_begin)
        out = /* replace-expr */
}

if (need_to_copy)
    out = m.ready()
              ? std::copy(m.suffix().first, m.suffix().second, out)
              : std::copy(first, last, out);

return out;

  1. L'expression /* replace-expr */ est m.format(out, fmt, flags).

  2. L'expression /* replace-expr */ est m.format(out, fmt, fmt + std::char_traits<CharT>::length(fmt), flags).

3,4) Équivalent à std::basic_string<CharT, STraits, SAlloc> result;regex_replace(std::back_inserter(result), str.begin(), str.end(), re, fmt, flags);return result;.

5,6) Équivalent à std::basic_string<CharT, STraits, SAlloc> result;regex_replace(std::back_inserter(result), s, s + std::char_traits<CharT>::length(s), re, fmt, flags);return result;.

Paramètres

  • first, last — l'intervalle de caractères cible
  • str — le std::string cible
  • s — la chaîne C terminée par un caractère nul cible
  • re — l'expression régulière
  • fmt — la chaîne de format de remplacement d'expression régulière ; la syntaxe exacte dépend de la valeur de flags
  • flags — indicateurs utilisés pour déterminer la manière dont la correspondance sera effectuée
  • out — itérateur de sortie pour stocker le résultat du remplacement

Valeur de retour

Comme décrit ci-dessus.

Exceptions

Peut lever std::regex_error pour signaler une condition d'erreur.

Exemple

#include <iostream>
#include <iterator>
#include <regex>
#include <string>

int main()
{
    std::string text = "Quick brown fox";
    std::regex vowel_re("a|e|i|o|u");

    // écrit les résultats dans un itérateur de sortie
    std::regex_replace(std::ostreambuf_iterator<char>(std::cout),
                       text.begin(), text.end(), vowel_re, "*");

    // construit une chaîne contenant les résultats
    std::cout << '\n' << std::regex_replace(text, vowel_re, "[$&]") << '\n';
}

Output:

Q**ck br*wn f*x
Q[u][i]ck br[o]wn f[o]x
