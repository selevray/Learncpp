std::sub_match<BidirIt>::swap

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void swap( sub_match& s ) noexcept(/* voir ci-dessous */);  // (depuis C++11)

Échange le contenu de deux objets sub-match. Équivalent à

this->pair<BidirIt, BidirIt>::swap(s);std::swap(matched, s.matched);

Paramètres

  • s — un sub_match avec lequel échanger

Exigences sur les types

  • BidirIt doit satisfaire aux exigences de LegacySwappable.

Exceptions

noexcept specification:noexcept(std::is_nothrow_swappable_v<BidirIt>)

Exemple

#include <cassert>
#include <iostream>
#include <regex>

int main()
{
    const char* s = "Quick red cat";
    std::sub_match<const char*> x, y;

    x.first = &s[0];
    x.second = &s[5];
    x.matched = false;

    y.first = &s[012];
    y.second = &s[13];
    y.matched = true;

    std::cout << "Before swap:\n";
    std::cout << "x.str() = [" << x.str() << "]\n";
    std::cout << "y.str() = [" << y.str() << "]\n";
    assert(!x.matched and y.matched);

    x.swap(y);

    std::cout << "After swap:\n";
    std::cout << "x.str() = [" << x.str() << "]\n";
    std::cout << "y.str() = [" << y.str() << "]\n";
    assert(x.matched and !y.matched);
}

Output:

Before swap:
x.str() = []
y.str() = [cat]
After swap:
x.str() = [cat]
y.str() = []
