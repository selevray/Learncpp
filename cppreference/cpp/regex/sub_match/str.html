Convertit en un objet du type std::basic_string sous-jacent.

  1. Une conversion implicite.

  2. Une conversion explicite.

Valeur de retour

La séquence de caractères correspondante sous forme d'objet du type std::basic_string sous-jacent. Si le membre matched est false, renvoie la chaîne vide.

Complexité

Linéaire en fonction de la longueur de la séquence de caractères sous-jacente.

Exemple

#include <cassert>
#include <iostream>
#include <regex>
#include <string>

int main()
{
    const std::string html{R"("<a href="https://cppreference.com/">)"};
    const std::regex re{"(http|https|ftp)://([a-z]+)\\.([a-z]{3})"};
    std::smatch parts;
    std::regex_search(html, parts, re);
    for (std::ssub_match const& sub : parts)
    {
        const std::string s = sub; // (1) conversion implicite
        assert(s == sub.str());    // (2)
        std::cout << s << '\n';
    }
}
