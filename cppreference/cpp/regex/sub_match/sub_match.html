constexpr sub_match();  // (depuis C++11)

Construit par défaut un std::sub_match. Le membre matched est initialisé à false et les membres hérités first et second sont value-initialisés.

C'est le seul constructeur accessible publiquement et défini.

Exemple

#include <cassert>
#include <regex>

int main()
{
    std::sub_match<const char*> s;
    assert(!s.matched);
}
