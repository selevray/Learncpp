operator<<(std::sub_match)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class CharT, class Traits, class BidirIt >
std::basic_ostream<CharT,Traits>&
    operator<<( std::basic_ostream<CharT,Traits>& os, const sub_match<BidirIt>& m );  // (depuis C++11)

Écrit la représentation de la sous-séquence correspondante m dans le flux de sortie os. Équivalent à os << m.str().

Paramètres

  • os — flux de sortie dans lequel écrire la représentation
  • m — un objet sub-match à écrire

Valeur de retour

os

Exemple

#include <iostream>
#include <regex>
#include <string>

int main()
{
    std::string sentence{"Quick red fox jumped over a lazy hare."};
    const std::regex re{"([A-z]+) ([a-z]+) ([a-z]+)"};
    std::smatch words;
    std::regex_search(sentence, words, re);
    for (const auto& m : words)
        // m est de type `const std::sub_match<std::string::const_iterator>&`
        std::cout << '[' << m << "] ";
    std::cout << '\n';
}

Output:

[Quick red fox] [Quick] [red] [fox]
