std::basic_regex<CharT,Traits>::mark_count

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

unsigned mark_count() const;  // (depuis C++11)

Renvoie le nombre de sous-expressions marquées (aussi appelées groupes de capture) dans l'expression régulière.

Paramètres

(aucune)

Valeur de retour

Le nombre de sous-expressions marquées dans l'expression régulière.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <iostream>
#include <regex>

int main()
{
    std::regex r1{"abcde"};
    std::cout << "r1 has " << r1.mark_count() << " subexpressions" << '\n';
    // Expected: 0

    std::regex r2{"ab(c)de"};
    std::cout << "r2 has " << r2.mark_count() << " subexpressions" << '\n';
    // Expected: 1

    std::regex r3{"a(bc)d(e)"};
    std::cout << "r3 has " << r3.mark_count() << " subexpressions" << '\n';
    // Expected: 2

    // Sous-expressions imbriquées
    std::regex r4{"abc(de(fg))"};
    std::cout << "r4 has " << r4.mark_count() << " subexpressions" << '\n';
    // Expected: 2

    // Parenthèses échappées
    std::regex r5{"a(bc\\(\\)de)"};
    std::cout << "r5 has " << r5.mark_count() << " subexpressions" << '\n';
    // Expected: 1

    // Utilisation de l'indicateur nosubs
    std::regex r6{"ab(c)de", std::regex_constants::nosubs};
    std::cout << "r6 has " << r6.mark_count() << " subexpressions" << '\n';
    // Expected: 0
}

r6 has 0 subexpressions
