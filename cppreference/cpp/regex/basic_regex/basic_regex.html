Construit une nouvelle expression régulière à partir d'une séquence de caractères interprétée selon les indicateurs f.

  1. Constructeur par défaut. Construit une expression régulière vide qui ne correspond à rien.

  2. Construit une regex à partir d'une chaîne terminée par un caractère nul s.

  3. Construit une regex à partir d'une séquence de count caractères, pointée par s.

  4. Constructeur de copie. Construit une regex en copiant other.

  5. Constructeur de déplacement. Construit une regex avec le contenu de other par sémantique de déplacement.

  6. Construit une regex à partir d'une chaîne str.

  7. Constructeur par intervalle. Construit la chaîne avec le contenu de l'intervalle [first,last).

  8. Constructeur par liste d'initialisation. Construit la chaîne avec le contenu de la liste d'initialisation init.

Paramètres

  • s — pointeur vers une chaîne terminée par un caractère nul
  • count — longueur d'une séquence de caractères utilisée pour initialiser la regex
  • first, last — intervalle d'une séquence de caractères utilisée pour initialiser la regex
  • str — un basic_string utilisé comme source pour initialiser la regex
  • other — une autre regex utilisée comme source pour initialiser la regex
  • init — liste d'initialisation utilisée pour initialiser la regex
  • f — indicateurs guidant l'interprétation de la séquence de caractères comme expression régulière

Exigences sur les types

  • ForwardIt doit satisfaire aux exigences de LegacyForwardIterator.

Exceptions

  1. Peut lever des exceptions définies par l'implémentation.

2,3) std::regex_error si l'expression régulière fournie n'est pas valide.

  1. Peut lever des exceptions définies par l'implémentation.

6-8) std::regex_error si l'expression régulière fournie n'est pas valide.

Exemple

#include <iomanip>
#include <iostream>
#include <regex>
#include <string>

void match_and_print(const std::string& text, const std::regex& pattern)
{
    std::sregex_iterator it(text.begin(), text.end(), pattern), it_end;
    int count = 0;
    for (; it != it_end; ++it)
    {
        const std::smatch& match = *it;
        std::cout << ++count << ". " << std::quoted(match.str()) << '\n';
    }
    std::cout << (count ? "\n" : "no match found\n\n");
}

int main()
{
    const std::string text = "Hello, World! 12345";

    // Correspond à un ou plusieurs chiffres
    std::string pattern_text = "\\d+";
    std::cout << "digits (" << pattern_text << "):\n";
    auto pattern = std::regex(pattern_text);
    match_and_print(text, pattern);

    // Correspond à un ou plusieurs caractères séparés par des espaces
    pattern_text = "[^\\s]+";
    std::cout << "words (" << pattern_text << "):\n";
    pattern = std::regex(pattern_text);
    match_and_print(text, pattern);

    // Correspond à un ou plusieurs caractères séparés par des espaces
    pattern_text = "[a-zA-Z]+";
    std::cout << "words without symbols and digits (" << pattern_text << "):\n";
    pattern = std::regex(pattern_text);
    match_and_print(text, pattern);

    // Correspond à un caractère qui n'est ni un chiffre ni une lettre
    pattern_text = "[^0-9A-Za-z]";
    std::cout << "symbol (" << pattern_text << "):\n";
    pattern = std::regex(pattern_text);
    match_and_print(text, pattern);

    // Correspond à une ou plusieurs minuscules
    pattern_text = "[a-z]+";
    std::cout << "lowercase (" << pattern_text << "):\n";
    pattern = std::regex(pattern_text);
    match_and_print(text, pattern);

    // Correspond à une ou plusieurs minuscules avec l'indicateur std::regex::icase
    pattern_text = "[a-z]+";
    std::cout << "lowercase with ignore case flag (" << pattern_text << "):\n";
    pattern = std::regex(pattern_text, std::regex::icase);
    match_and_print(text, pattern);

    // Correspond à une expression régulière POSIX basique
    pattern_text = "[[:digit:]]+";
    std::cout << "basic POSIX regex (" << pattern_text << "):\n";
    pattern = std::regex(pattern_text, std::regex::basic);
    match_and_print(text, pattern);

    // Correspond à une expression régulière POSIX étendue
    pattern_text = "[[:digit:]]+";
    std::cout << "extended POSIX regex (" << pattern_text << "):\n";
    pattern = std::regex(pattern_text, std::regex::extended);
    match_and_print(text, pattern);
}
