std::regex_traits

Défini dans l'en-tête <regex>

template< class CharT >
class regex_traits;  // (depuis C++11)

Le modèle de trait de type regex_traits fournit à std::basic_regex l'ensemble des types et fonctions nécessaires pour opérer sur le type CharT.

Puisque de nombreuses opérations regex sont sensibles à la locale (lorsque l'indicateur std::regex_constants::collate est activé), la classe regex_traits contient généralement une instance d'un std::locale comme membre privé.

Spécialisations standard

Deux spécialisations de std::regex_traits sont définies par la bibliothèque standard :

std::regex_traits<char>

std::regex_traits<wchar_t>

Ces spécialisations permettent d'utiliser std::basic_regex<char> (aussi appelé std::regex) et std::basic_regex<wchar_t> (aussi appelé std::wregex). Pour utiliser std::basic_regex avec d'autres types de caractères (par exemple, char32_t), il faut utiliser une classe de traits fournie par l'utilisateur.

Types membres

Type Définition

  • char_type — CharT
  • string_type — std::basic_string<CharT>
  • locale_type — La locale utilisée pour le comportement localisé de l'expression régulière. Doit être CopyConstructible
  • char_class_type — Représente une classification de caractères et peut contenir un ensemble spécifique à l'implémentation renvoyé par lookup_classname. Doit être un BitmaskType.
