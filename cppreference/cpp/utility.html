C++ comprend diverses bibliothèques utilitaires qui fournissent des fonctionnalités allant du comptage de bits à l'application partielle de fonctions. Ces bibliothèques peuvent être globalement réparties en deux groupes :

  • les bibliothèques de support du langage, et
  • les bibliothèques à usage général.

Support du langage

Les bibliothèques de support du langage fournissent des classes et des fonctions qui interagissent étroitement avec les fonctionnalités du langage et prennent en charge les idiomes courants du langage.

Support des types

Types de base (par exemple std::size_t, std::nullptr_t), RTTI (par exemple std::type_info)

Métaprogrammation (depuis C++11)

Traits de type (par exemple std::is_integral, std::rank), constantes de compilation (par exemple std::integer_sequence, std::ratio)

Contexte d'évaluation constante (depuis C++20)

Défini dans l'en-tête <type_traits>

  • is_constant_evaluated (C++20) — détecte si l'appel a lieu dans un contexte évalué de manière constante (fonction)
  • is_within_lifetime (C++26) — vérifie à la compilation si un pointeur se trouve dans la durée de vie de l'objet (fonction)

Propriétés d'implémentation (depuis C++20)

L'en-tête <version> fournit des informations dépendantes de l'implémentation sur la bibliothèque standard C++ (telles que le numéro de version et la date de publication). Il définit également les macros de test de fonctionnalités de la bibliothèque.

Utilitaires de programme

Terminaison (par exemple std::abort, std::atexit), environnement (par exemple std::system), signaux (par exemple std::raise)

Gestion de la mémoire dynamique

Pointeurs intelligents (par exemple std::shared_ptr), allocateurs (par exemple std::allocator ou std::pmr::memory_resource), gestion de mémoire de style C (par exemple std::malloc)

Gestion des erreurs

Exceptions (par exemple std::exception, std::terminate), assertions (par exemple assert)

Capture d'informations sur le code source (depuis C++20)

Défini dans l'en-tête <source_location>

  • source_location (C++20) — une classe représentant des informations sur le code source, telles que les noms de fichiers, les numéros de ligne et les noms de fonctions (classe)

Listes d'initialisation (depuis C++11)

Défini dans l'en-tête <initializer_list>

  • initializer_list (C++11) — fait référence à un tableau temporaire créé lors d'une initialisation par liste (modèle de classe)

Support des coroutines (depuis C++20)

Types pour le support des coroutines, par exemple std::coroutine_traits, std::coroutine_handle.

Fonctions variadiques

Prise en charge des fonctions acceptant un nombre arbitraire de paramètres (via par exemple va_start, va_arg, va_end).

Utilitaires à usage général

Échange

Défini dans l'en-tête <utility>

  • swap — échange les valeurs de deux objets (modèle de fonction)
  • exchange (C++14) — remplace l'argument par une nouvelle valeur et renvoie sa valeur précédente (modèle de fonction)

Défini dans l'en-tête <concepts>

  • ranges::swap (C++20) — échange les valeurs de deux objets (objet point de personnalisation)

Opérations sur les types (depuis C++11)

Défini dans l'en-tête <utility>

  • forward (C++11) — transmet un argument de fonction et utilise l'argument de modèle de type pour préserver sa catégorie de valeur (modèle de fonction)
  • forward_like (C++23) — transmet un argument de fonction comme s'il était converti vers la catégorie de valeur et la constness de l'expression du type spécifié par l'argument de modèle de type (modèle de fonction)
  • move (C++11) — convertit l'argument en xvalue (modèle de fonction)
  • move_if_noexcept (C++11) — convertit l'argument en xvalue si le constructeur de déplacement ne lève pas d'exception (modèle de fonction)
  • as_const (C++17) — obtient une référence const vers son argument (modèle de fonction)
  • declval (C++11) — obtient une référence à un objet du type argument de modèle pour une utilisation dans un contexte non évalué (modèle de fonction)
  • to_underlying (C++23) — convertit une énumération en son type sous-jacent (modèle de fonction)

Fonctions de comparaison d'entiers (depuis C++20)

Défini dans l'en-tête <utility>

  • cmp_equalcmp_not_equalcmp_lesscmp_greatercmp_less_equalcmp_greater_equal (C++20) — compare deux valeurs entières en garantissant que les nombres négatifs signés sont inférieurs aux nombres non signés (modèle de fonction)
  • in_range (C++20) — vérifie si une valeur entière est dans l'intervalle d'un type entier donné (modèle de fonction)

Opérateurs relationnels (jusqu'à C++20)

Paires et tuples

Défini dans l'en-tête <utility>

  • pair — implémente un tuple binaire, c'est-à-dire une paire de valeurs (modèle de classe)

Défini dans l'en-tête <tuple>

  • apply (C++17) — appelle une fonction avec un tuple d'arguments (modèle de fonction)
  • make_from_tuple (C++17) — construit un objet avec un tuple d'arguments (modèle de fonction)

Bitset

Défini dans l'en-tête <bitset>

  • bitset — implémente un tableau de bits de longueur constante (modèle de classe)

Manipulation de bits (depuis C++20)

L'en-tête <bit> fournit plusieurs modèles de fonctions permettant d'accéder, de manipuler et de traiter des bits individuels et des séquences de bits. L'ordre des octets (boutisme) des types scalaires peut être examiné via l'utilitaire std::endian.

Objets fonctions (depuis C++11)

Application partielle de fonctions (par exemple std::bind) et utilitaires associés : utilitaires de liaison tels que std::ref et std::placeholders, enveloppes polymorphes de fonctions : std::function, foncteurs prédéfinis (par exemple std::plus, std::equal_to), convertisseurs de pointeur vers membre en fonction std::mem_fn.

Prise en charge du hachage (depuis C++11)

Défini dans l'en-tête <functional>
