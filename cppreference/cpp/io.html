C++ comprend les bibliothèques d'entrée/sortie suivantes : une bibliothèque de style POO d'E/S basée sur les flux, famille de fonctions basées sur print (depuis C++23), et l'ensemble standard de fonctions d'E/S de style C.

E/S basées sur les flux

La bibliothèque d'entrée/sortie basée sur les flux est organisée autour de périphériques d'entrée/sortie abstraits. Ces périphériques abstraits permettent au même code de gérer les entrées/sorties vers des fichiers, des flux en mémoire ou des périphériques adaptateurs personnalisés effectuant des opérations arbitraires (par ex. compression) à la volée.

La plupart des classes sont des modèles, elles peuvent donc être adaptées à n'importe quel type de caractère de base. Des alias de types distincts sont fournis pour les types de caractères de base les plus courants (char et wchar_t). Les classes sont organisées selon la hiérarchie suivante :

La bibliothèque d'E/S basée sur les flux utilise des manipulateurs d'E/S (par ex. std::boolalpha, std::hex, etc.) pour contrôler le comportement des flux.

Fonctions print (depuis C++23)

Les fonctions de la famille print, prenant en compte Unicode, effectuent des E/S formatées sur du texte déjà formaté. Elles offrent tous les avantages de performance de std::format, sont indépendantes des paramètres régionaux par défaut, réduisent l'état global, évitent d'allouer un objet std::string temporaire et d'appeler operator<<, et, en général, rendent le formatage plus efficace par rapport aux iostreams et à stdio.

Les fonctions de type print suivantes sont fournies :

Défini dans l'en-tête <print>

  • print (C++23) — affiche vers stdout ou un flux de fichier à l'aide d'une représentation formatée des arguments (modèle de fonction)
  • println (C++23) — identique à std::print si ce n'est que chaque affichage se termine par un saut de ligne supplémentaire (modèle de fonction)
  • vprint_unicodevprint_unicode_buffered (C++23) — affiche vers un stdout capable d'Unicode ou un flux de fichier à l'aide d'une représentation des arguments à effacement de type (fonction)
  • vprint_nonunicodevprint_nonunicode_buffered (C++23) — affiche vers stdout ou un flux de fichier à l'aide d'une représentation des arguments à effacement de type (fonction)

Défini dans l'en-tête <ostream>

  • print(std::ostream) (C++23) — écrit une représentation formatée des arguments (modèle de fonction)
  • println(std::ostream) (C++23) — écrit une représentation formatée des arguments suivis de '\n' (modèle de fonction)

E/S de style C

C++ inclut également les fonctions d'entrée/sortie définies par C, telles que std::fopen, std::getc, etc.
