std::ranges::common_range

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ranges>

template< class T >
concept common_range =
    ranges::range<T> && std::same_as<ranges::iterator_t<T>, ranges::sentinel_t<T>>;  // (depuis C++20)

Le concept common_range est un raffinement de range pour lequel std::ranges::begin() et std::ranges::end() renvoient le même type (par exemple tous les conteneurs de la bibliothèque standard).

Exemple

#include <ranges>

struct A
{
    char* begin();
    char* end();
};
static_assert( std::ranges::common_range<A> );

struct B
{
    char* begin();
    bool end();
};  // non common_range : begin et end ont des types différents
static_assert( not std::ranges::common_range<B> );

struct C
{
    char* begin();
};  // non common_range, et même pas un intervalle : n'a pas de end()
static_assert( not std::ranges::common_range<C> );

int main() {}
