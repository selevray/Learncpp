std::ranges::views::values, std::ranges::values_view

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ranges>

template< class R >
using values_view = ranges::elements_view<R, 1>;  // (1) (depuis C++20)

namespace views {
    inline constexpr auto values = ranges::elements<1>;
}  // (2) (depuis C++20)

Prend un view de valeurs semblables à des tuples (par exemple std::tuple ou std::pair) et produit une vue dont le type de valeur est le second élément du type de valeur de la vue adaptée.

  1. Un alias pour ranges::elements_view<R, 1>.

  2. RangeAdaptorObject (et aussi RangeAdaptorClosureObject). L'expression views::values(e) est équivalente en expression à values_view<views::all_t<decltype((e))>>{e} pour toute sous-expression e appropriée.

Notes

values_view peut être utile pour extraire des valeurs de conteneurs associatifs, par exemple.

std::map<int, std::string> map{{1, "alpha"}, {2, "beta"}};
for (auto const& value : std::views::values(map))
    std::cout << value << ' ';
// affiche : alpha beta

Exemple

#include <iostream>
#include <map>
#include <ranges>

int main()
{
    const auto list = {std::pair{1, 11.1}, {2, 22.2}, {3, 33.3}};
    std::cout << "pair::second values in the list: ";
    for (double value : list | std::views::values)
        std::cout << value << ' ';

    std::map<char, int> map{{'A', 1}, {'B', 2}, {'C', 3}, {'D', 4}, {'E', 5}};
    auto odd = [](int x) { return 0 != (x & 1); };
    std::cout << "\nodd values in the map: ";
    for (int value : map | std::views::values | std::views::filter(odd))
        std::cout << value << ' ';
    std::cout << '\n';
}

Output:

pair::second values in the list: 11.1 22.2 33.3
odd values in the map: 1 3 5
