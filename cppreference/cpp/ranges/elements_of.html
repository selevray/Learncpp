std::ranges::elements_of

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ranges>

template< ranges::range R, class Allocator = std::allocator<std::byte> >
struct elements_of;  // (depuis C++23)

Encapsule un range. Les spécialisations de elements_of servent d'étiquette dans les ensembles de surcharges pour lever l'ambiguïté lorsqu'un intervalle doit être traité comme une séquence plutôt que comme une valeur unique.

Paramètres de modèle

  • R — un type qui satisfait range
  • Allocator — un type d'allocateur qui respecte les exigences de Allocator

Membres de données

Nom du membre Définition

  • range — un intervalle de type R (membre donnée publique)
  • allocator — un allocateur de type Allocator. Il possède un initialiseur de membre par défaut qui initialise par valeur lui-même (membre donnée publique)

Tous ces membres sont déclarés avec l'attribut [[no_unique_address]].

Guide de déduction

template< class R, class Allocator = std::allocator<std::byte> >
elements_of( R&&, Allocator = Allocator() ) -> elements_of<R&&, Allocator>;  // (depuis C++23)

Exemple

#include <any>
#include <generator>
#include <iostream>
#include <ranges>
#include <string_view>

template<bool Elementwise>
std::generator<std::any> gen(std::ranges::input_range auto&& r)
{
    if constexpr (Elementwise)
        co_yield std::ranges::elements_of(r); // produit chaque élément de r
    else
        co_yield r;                           // produit r comme une seule valeur
}

int main()
{
    auto test = std::string_view{"test"};

    for (std::any a : gen<true>(test))
        std::cout << '[' << std::any_cast<char>(a) << "] ";
    std::cout << '\n';

    for (std::any a : gen<false>(test))
        std::cout << '[' << std::any_cast<std::string_view>(a) << "] ";
    std::cout << '\n';
}

Output:

[t] [e] [s] [t]
[test]
