Signature d'appel

template< ranges::viewable_range R >
    requires /* voir ci-dessous */
constexpr ranges::view auto reverse( R&& r );  // (depuis C++20)

  1. Un adaptateur d'intervalle qui représente une vue de view sous-jacent dans l'ordre inverse.

  2. RangeAdaptorObject. L'expression views::reverse(e) est équivalente à une expression à l'une des expressions suivantes, sauf que e n'est évaluée qu'une seule fois :

  • e.base(), si le type de e est une spécialisation (éventuellement qualifiée cv) de reverse_view ;

  • sinon, si le type de e est (éventuellement qualifié cv) ranges::subrange<std::reverse_iterator<I>, std::reverse_iterator<I>, K> pour un certain type d'itérateur I et une valeur K de type ranges::subrange_kind :

    • ranges::subrange<I, I, K>(e.end().base(), e.begin().base(), e.size()), si K est ranges::subrange_kind::sized ;
    • sinon ranges::subrange<I, I, K>(e.end().base(), e.begin().base()) ;

  • sinon ranges::reverse_view{e}.

En d'autres termes, views::reverse déballe les vues inversées si possible.

Un reverse_view modélise toujours bidirectional_range et common_range, et il modélise borrowed_range, sized_range ou random_access_range si le type de vue sous-jacent V modélise le concept correspondant.

Modèles auxiliaires

template< class T >
constexpr bool enable_borrowed_range<std::ranges::reverse_view<T>> =
    ranges::enable_borrowed_range<T>;  // (depuis C++20)

Cette spécialisation de std::ranges::enable_borrowed_range fait en sorte que reverse_view satisfasse borrowed_range lorsque la vue sous-jacente le satisfait.

Exemple

#include <iostream>
#include <ranges>

int main()
{
    static constexpr auto il = {3, 1, 4, 1, 5, 9};

    std::ranges::reverse_view rv{il};
    for (int i : rv)
        std::cout << i << ' ';
    std::cout << '\n';

    for (int i : il | std::views::reverse)
        std::cout << i << ' ';
    std::cout << '\n';

    // operator[] est hérité de std::view_interface
    for (auto i{0U}; i != rv.size(); ++i)
        std::cout << rv[i] << ' ';
    std::cout << '\n';
}

Output:

9 5 1 4 1 3
9 5 1 4 1 3
9 5 1 4 1 3
