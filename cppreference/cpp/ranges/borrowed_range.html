std::ranges::borrowed_range, std::ranges::enable_borrowed_range

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ranges>

template< class R >
concept borrowed_range =
    ranges::range<R> &&
    (std::is_lvalue_reference_v<R> ||
     ranges::enable_borrowed_range<std::remove_cvref_t<R>>);  // (1) (depuis C++20)

template< class R >
constexpr bool enable_borrowed_range = false;  // (2) (depuis C++20)

  1. Le concept borrowed_range définit les exigences d'un intervalle tel qu'une fonction peut le prendre par valeur et renvoyer des itérateurs obtenus à partir de celui-ci sans danger de référence pendante.

  2. Le modèle de variable enable_borrowed_range sert à indiquer si un range est un borrowed_range. Le modèle primaire est défini comme false.

Exigences sémantiques

Soit U égal à std::remove_reference_t<T> si T est un type référence rvalue, et à T sinon. Étant donné une variable u de type U, T modélise borrowed_range uniquement si la validité des itérateurs obtenus à partir de u n'est pas liée à la durée de vie de cette variable.

Spécialisations

Les spécialisations de enable_borrowed_range pour toutes les spécialisations des modèles standard suivants sont définies comme true :

  • std::basic_string_view
  • std::span
  • std::ranges::subrange
  • std::ranges::ref_view
  • std::ranges::empty_view
  • std::ranges::iota_view

La spécialisation de enable_borrowed_range pour les adaptateurs d'intervalles standard suivants est définie comme true si et seulement si std::ranges::enable_borrowed_range<V> est true, où V est le type de vue sous-jacent :

  • std::ranges::owning_view
  • std::ranges::take_view
  • std::ranges::drop_view
  • std::ranges::drop_while_view
  • std::ranges::common_view
  • std::ranges::reverse_view
  • std::ranges::elements_view
  • std::ranges::adjacent_view

(depuis C++23)

La spécialisation pour std::ranges::zip_view est définie comme true si et seulement si (std::ranges::enable_borrowed_range<Vs> && ...) est true, où Vs... désignent tous les types de vue qu'elle adapte.

(depuis C++23)

Un programme peut spécialiser enable_borrowed_range en true pour les types définis par le programme non qualifiés cv qui modélisent borrowed_range, et en false pour les types qui ne le font pas. De telles spécialisations doivent pouvoir être utilisées dans une expression constante et avoir le type const bool.

Exemple

Démontre les spécialisations de enable_borrowed_range pour les types définis par le programme. De telles spécialisations protègent contre des résultats potentiellement pendants.

#include <algorithm>
#include <array>
#include <cstddef>
#include <iostream>
#include <ranges>
#include <span>
#include <type_traits>

template<typename T, std::size_t N>
struct MyRange : std::array<T, N> {};

template<typename T, std::size_t N>
constexpr bool std::ranges::enable_borrowed_range<MyRange<T, N>> = false;

template<typename T, std::size_t N>
struct MyBorrowedRange : std::span<T, N> {};

template<typename T, std::size_t N>
constexpr bool std::ranges::enable_borrowed_range<MyBorrowedRange<T, N>> = true;

int main()
{
    static_assert(std::ranges::range<MyRange<int, 8>>);
    static_assert(std::ranges::borrowed_range<MyRange<int, 8>> == false);
    static_assert(std::ranges::range<MyBorrowedRange<int, 8>>);
    static_assert(std::ranges::borrowed_range<MyBorrowedRange<int, 8>> == true);

    auto getMyRangeByValue = []{ return MyRange<int, 4>{{1, 2, 42, 3}}; };
    auto dangling_iter = std::ranges::max_element(getMyRangeByValue());
    static_assert(std::is_same_v<std::ranges::dangling, decltype(dangling_iter)>);
    // *dangling_iter; // erreur de compilation (c'est-à-dire que la protection contre les références pendantes fonctionne.)

    auto my = MyRange<int, 4>{{1, 2, 42, 3}};
    auto valid_iter = std::ranges::max_element(my);
    std::cout << *valid_iter << ' '; // OK: 42

    auto getMyBorrowedRangeByValue = []
    {
        static int sa[4]{1, 2, 42, 3};
        return MyBorrowedRange<int, std::size(sa)>{sa};
    };
    auto valid_iter2 = std::ranges::max_element(getMyBorrowedRangeByValue());
    std::cout << *valid_iter2 << '\n'; // OK: 42
}

Output:

42 42
