std::ranges::join_view<V>::begin

constexpr auto begin();  // (1) (depuis C++20)

constexpr auto begin() const
    requires ranges::input_range<const V> &&
             std::is_reference_v<ranges::range_reference_t<const V>>;  // (2) (depuis C++20)

Renvoie un itérateur vers le premier élément du join_view. Étant donné que base_ est la vue sous-jacente,

  1. Équivalent à
  • return /*iterator*/<true>{*this, ranges::begin(base_)}; si /*simple-view*/<V> est satisfait et ranges::range_reference_t<V> est de type référence. Sinon,
  • return /*iterator*/<false>{*this, ranges::begin(base_)};.
  1. Équivalent à return /*iterator*/<true>{*this, ranges::begin(base_)};.

Paramètres

(aucune)

Valeur de retour

Itérateur vers le premier élément.

Notes

Lorsque ranges::range_reference_t<V> n'est pas de type référence, c'est-à-dire que le déréférencement d'un itérateur de V renvoie un prvalue temporaire, le join_view n'est qu'un input_range, auquel cas seule l'itération monopasse est prise en charge, et les appels répétés à begin() peuvent ne pas donner de résultats significatifs.
