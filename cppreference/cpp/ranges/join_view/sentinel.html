Le type de retour de join_view::end lorsque l'un des intervalles sous-jacents (V ou ranges::range_reference_t<V>) n'est pas un common_range, ou lorsque le parent join_view n'est pas un forward_range.

Si V n'est pas une vue simple, Const vaut true pour les sentinelles renvoyées par les surcharges const, et false sinon. Si V est une vue simple, Const vaut true.
