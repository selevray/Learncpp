std::ranges::join_view<V>::iterator

Le type de retour de join_view::begin, et de join_view::end lorsque l'intervalle externe V et l'intervalle interne ranges::range_reference_t<V> satisfont tous deux common_range et que le parent join_view est un forward_range.

Si V n'est pas une vue simple (par exemple si ranges::iterator_t<const V> est invalide ou différent de ranges::iterator_t<V>), Const vaut true pour les itérateurs renvoyés par les surcharges const, et false sinon. Si V est une vue simple, Const vaut true si et seulement si ranges::range_reference_t<V> est une référence.
