Compare les itérateurs sous-jacents.

Soit current_ l'objet sous-jacent de type tuple-like contenant les itérateurs vers les éléments des vues adaptées.

  1. Returns:
  • x.current_ == y.current_ si /*all-bidirectional*/<Const, Views...> vaut true.
  • Sinon, true s'il existe un entier 0 <= i < sizeof...(Views) tel que bool(std::get<i>(x.current_) == std::get<i>(y.current_)) soit true.
  • Sinon, false.
  1. Équivalent à return x.current_ <=> y.current_;.
