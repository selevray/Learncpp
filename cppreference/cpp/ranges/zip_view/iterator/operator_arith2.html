Soit current_ désigne l'objet de type tuple sous-jacent d'itérateurs vers les éléments des vues adaptées.

1,2) Renvoie l'itérateur i incrémenté de n. Équivalent à : auto r = i; r += n; return r;.

  1. Renvoie l'itérateur i décrémenté de n. Équivalent à : auto r = i; r -= n; return r;.

  2. Soit DIST(k) égal à difference_type(std::get<k>(i.current_) - std::get<k>(j.current_)). Renvoie la plus petite valeur absolue parmi DIST(n) pour tous les entiers 0 <= n < sizeof...(Views).

Ces fonctions ne sont pas visibles par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peuvent être trouvées que par la recherche dépendante des arguments lorsque zip_view::iterator<Const> est une classe associée aux arguments.

Paramètres

  • i, j — les itérateurs.
  • n — position relative à l'emplacement courant.

Valeur de retour

1,2) une copie de i avancée de n

  1. une copie de i avancée de -n

  2. la distance entre i et j
