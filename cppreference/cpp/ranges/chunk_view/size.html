std::ranges::chunk_view<V>::size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr auto size() requires ranges::sized_range<V>;  // (1) (depuis C++23)

constexpr auto size() const requires ranges::sized_range<const V>;  // (2) (depuis C++23)

Renvoie le nombre d'éléments, qui est la plus petite valeur entière non inférieure au quotient de la division de la taille de la vue sous-jacente base_ par le membre de données sous-jacent n_, contenant le nombre passé au constructeur (0 si construit par défaut). Équivalent à

return __to_unsigned_like(__div_ceil(ranges::distance(base_), n_));

Paramètres

(aucune)

Valeur de retour

Le nombre d'éléments.

Exemple

#include <ranges>

int main()
{
    constexpr static auto v = {1, 2, 3, 4, 5};
    constexpr auto w{ std::ranges::chunk_view(v, 2) };
    static_assert(w.size() == (5 / 2 + (5 % 2 ? 1 : 0)));
}
