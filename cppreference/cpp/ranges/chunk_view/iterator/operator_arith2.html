Effectue une arithmétique sur iterator ou calcule la distance.

Soient current_, end_, n_ et missing_ les membres de données sous-jacents.

Équivalent à :

1,2) auto r = i; r += pos; return r;.

  1. auto r = i; r -= pos; return r;.

  2. return (i.current_ - j.current_ + i.missing_ - j.missing_) / i.n_;.

  3. return /*div-ceil*/(i.end_ - i.current_, i.n_);.

  4. return -(y - x);.

Ces fonctions ne sont pas visibles par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peuvent être trouvées que par la recherche dépendante des arguments lorsque chunk_view::iterator<Const> est une classe associée aux arguments.

Paramètres

  • i, j — les itérateurs
  • pos — la position relative à l'emplacement courant

Valeur de retour

1,2) Un itérateur incrémenté.

  1. Un itérateur décrémenté.

  2. Une distance (en nombre d'éléments, c'est-à-dire de fragments) entre les itérateurs donnés.

5,6) Une distance (en nombre d'éléments) entre l'itérateur donné et la sentinelle.
