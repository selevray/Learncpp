Fait avancer ou reculer l'itérateur.

Soit current_, end_ et n_ les membres de données sous-jacents de chunk_view::iterator.

  1. Équivalent à :
missing_ = ranges::advance(current_, n_, end_);
return *this;

Avant l'invocation, l'expression current_ != end_ doit être true, sinon le comportement est indéfini.

  1. Équivalent à : auto tmp = *this; ++*this; return tmp;.

  2. Équivalent à :

ranges::advance(current_, missing_ - n_);
missing_ = 0;
return *this;

  1. Équivalent à : auto tmp = *this; --*this; return tmp;.

  2. Équivalent à :

if (x > 0)
{
    ranges::advance(current_, n_ * (x - 1));
    missing_ = ranges::advance(current_, n_, end_);
}
else if (x < 0)
{
    ranges::advance(current_, n_ * x + missing_);
    missing_ = 0;
}
return *this;

Si x est positif, alors avant l'appel, l'expression ranges::distance(current_, end_) > n_ * (x - 1) doit être true (c'est-à-dire, informellement, le fragment demandé doit être « à l'intérieur » de la séquence sous-jacente). Si x est négatif, cette précondition est toujours satisfaite.

  1. Équivalent à : return *this += -x;.

Paramètres

Valeur de retour

2,4) une copie de *this réalisée avant la modification
