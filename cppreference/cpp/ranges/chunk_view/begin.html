std::ranges::chunk_view<V>::begin

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

V ne modélise que input_range

constexpr __outer_iterator begin();  // (1) (depuis C++23)

V modélise forward_range

constexpr auto begin() requires (!__simple_view<V>);  // (2) (depuis C++23)

constexpr auto begin() const requires ranges::forward_range<const V>;  // (3) (depuis C++23)

Renvoie un itérateur vers le premier élément de chunk_view.

Soit base_ désigne la vue sous-jacente.

  1. Disponible uniquement si V modélise input_range. Équivalent à :
current_ = ranges::begin(base_);
remainder_ = n_;
return __outer_iterator(*this);

current_, remainder_ et n_ sont des membres de données sous-jacents, à titre d'exposition uniquement, de chunk_view.

  1. Disponible si V modélise forward_range. Équivalent à : return iterator<false>(this, ranges::begin(base_));, où iterator est une classe imbriquée à titre d'exposition uniquement.

  2. Disponible si V modélise forward_range. Équivalent à : return iterator<true>(this, ranges::begin(base_));, où iterator est une classe imbriquée à titre d'exposition uniquement.

Paramètres

(aucune)

Valeur de retour

Un itérateur vers le premier élément de chunk_view, tel que décrit ci-dessus.
