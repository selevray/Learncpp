template< ranges::viewable_range R >

  1. Adapte un view donné dont l'itérateur et la sentinelle ont des types différents en un view qui est aussi un common_range. Un common_view a toujours le même type d'itérateur et de sentinelle.

  2. RangeAdaptorObject. Soit e une sous-expression. Alors l'expression views::common(e) est expression-équivalente à :

  • views::all(e), si c'est une expression bien formée et que decltype((e)) modélise common_range ;
  • common_view{e} sinon.

Guides de déduction

Modèles auxiliaires

template< class T >
constexpr bool enable_borrowed_range<std::ranges::common_view<T>> =
    ranges::enable_borrowed_range<T>;  // (depuis C++20)

Cette spécialisation de std::ranges::enable_borrowed_range fait que common_view satisfait borrowed_range lorsque la vue sous-jacente le satisfait.

Notes

common_view peut être utile pour travailler avec des algorithmes historiques qui attendent que l'itérateur et la sentinelle soient du même type.

Exemple

#include <iostream>
#include <iterator>
#include <list>
#include <numeric>
#include <ranges>

int main()
{
    auto v1 = {1, 2, 3, 4, 5};
    auto i1 = std::counted_iterator{v1.begin(), std::ssize(v1)};
    auto r1 = std::ranges::subrange{i1, std::default_sentinel};
//  auto e1 = std::accumulate(r1.begin(), r1.end(), 0); // error: "common range" required
    auto c1 = std::ranges::common_view{r1};
    std::cout << "accumulate: " << std::accumulate(c1.begin(), c1.end(), 0) << '\n';

    // hérité de ranges::view_interface :
    std::cout << "c1.front(): " << c1.front() << '\n';
    std::cout << "c1.back(): " << c1.back() << '\n';
    std::cout << "c1.data(): " << c1.data() << '\n';
    std::cout << "c1[0]: " << c1[0] << '\n';

    auto v2 = std::list{1, 2, 3, 4, 5};
    auto i2 = std::counted_iterator{v2.begin(), std::ssize(v2)};
    auto r2 = std::ranges::subrange{i2, std::default_sentinel};
//  auto e2 = std::accumulate(r2.begin(), r2.end(), 0); // error: "common range" required
    auto c2 = std::ranges::common_view{ r2 };
    std::cout << "accumulate: " << std::accumulate(c2.begin(), c2.end(), 0) << '\n';

    // hérité de ranges::view_interface :
    std::cout << "c2.front(): " << c2.front() << '\n';
//  auto e3 = c2.back(); // error: "bidirectional range" required
//  auto e4 = c2.data(); // error: "contiguous range" required
//  auto e5 = c2[0];     // error: "random access range" required
}
