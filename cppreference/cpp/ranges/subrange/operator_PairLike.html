Notes

Les types suivants de la bibliothèque standard sont de type paire :

  • std::pair<T, U>
  • std::tuple<T, U>
  • std::array<T, 2>
  • std::ranges::subrange<I, S, K>
  • std::complex<T>

(depuis C++26)

Un type défini par le programme et dérivé de l'un de ces types peut être un type de type paire, si

  • std::tuple_size et std::tuple_element sont correctement spécialisés pour lui, et
  • les appels à std::get<0> et std::get<1> pour sa valeur sont bien formés.

(jusqu'à C++23)

Comme les spécialisations de subrange sont des types range, leur conversion vers ces types n'est pas effectuée via cette fonction de conversion.

Les spécialisations de std::array ne peuvent pas être converties depuis subrange, car ce sont des types range.

Exemple

#include <iostream>
#include <ranges>
#include <string>
#include <utility>

using striter = std::string::const_iterator;

using legacy_strview = std::pair<striter, striter>;

void legacy_print(legacy_strview p)
{
    for (; p.first != p.second; ++p.first)
        std::cout << *p.first << ' ';
    std::cout << '\n';
}

int main()
{
    std::string dat{"ABCDE"};
    for (auto v{std::ranges::subrange{dat}}; v; v = {v.begin(), v.end() - 1})
    {
        /*...*/
        legacy_print(legacy_strview{v});
    }
}

A B C D
A B C
A B
