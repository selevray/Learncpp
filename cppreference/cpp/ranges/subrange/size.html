std::ranges::subrange<I,S,K>::size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr /*make-unsigned-like-t*/<std::iter_difference_t<I>> size() const
    requires (K == ranges::subrange_kind::sized);  // (depuis C++20)

Obtient le nombre d'éléments du subrange :

  • Si StoreSize est true, renvoie size_.
  • Sinon, renvoie to-unsigned-like ﻿(end_ - begin_ ﻿).

Pour la définition de /*make-unsigned-like-t*/, voir make-unsigned-like-t ﻿.

Valeur de retour

Comme décrit ci-dessus.

Exemple

#include <functional>
#include <iostream>
#include <ranges>
#include <utility>

int main()
{
    const auto v = {2, 2, 2, 7, 1, 1, 1, 1, 8, 2, 2, 2, 2, 2};

    // le type de valeur de views::chunk_by est ranges::subrange

    auto to_pair = [](auto sub) { return std::make_pair(sub[0], sub.size()); };
                                                                 /* ^^^^ */
    auto pairs = v | std::views::chunk_by(std::equal_to{})
                   | std::views::transform(to_pair);

    for (auto x : pairs bitor std::views::keys)
        std::cout << x << ' ';
    std::cout << '\n';
    for (auto x : pairs bitor std::views::values)
        std::cout << x << ' ';
    std::cout << '\n';
}

Output:

2 7 1 8 2
3 1 4 1 5
