Ces guides de déduction sont fournis pour std::ranges::subrange.

  1. Déduit les arguments de modèle à partir du type de l'itérateur et de la sentinelle. subrange est dimensionné si std::sized_sentinel_for<S, I> est satisfait, comme déterminé par l'argument de modèle par défaut.

  2. Déduit les arguments de modèle à partir du type de l'itérateur et de la sentinelle, la taille de l'intervalle étant spécifiée. subrange est toujours dimensionné.

  3. Déduit les arguments de modèle à partir du type de l'intervalle. subrange est dimensionné si la taille peut être obtenue à partir de l'intervalle ou de son itérateur et de sa sentinelle.

  4. Déduit les arguments de modèle à partir du type de l'intervalle, la taille de l'intervalle étant spécifiée. subrange est toujours dimensionné.

Pour la définition de /* make-unsigned-like-t */, voir make-unsigned-like-t ﻿.

Notes

Lors de la construction de l'objet subrange,

  • pour (1,2), le comportement est indéfini si la paire itérateur-sentinelle ne désigne pas un intervalle valide,
  • pour (2,4), le comportement est indéfini si la taille donnée n'est pas égale à la taille de l'intervalle.
