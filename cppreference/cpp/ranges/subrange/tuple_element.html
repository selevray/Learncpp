Les spécialisations partielles de std::tuple_element pour std::ranges::subrange donnent accès à la compilation au type d'itérateur ou de sentinelle d'un subrange, à l'aide de la syntaxe de type tuple. Elles sont fournies pour la prise en charge du liage structuré.

1,2) Obtient le type d'itérateur, c'est-à-dire I.

3,4) Obtient le type de sentinelle, c'est-à-dire S.

Types membres

Type membre Définition

  • type — (1,2) I (3,4) S

Notes

Comme les fonctions get pour subrange renvoient les itérateurs et sentinelles par valeur, le qualificateur const n'est pas ajouté aux types de résultat lorsque subrange est qualifié const (mais non volatile).

Si subrange est qualifié volatile, les types de résultat sont également qualifiés volatile, car la spécialisation partielle pour les types volatile ou const volatile est utilisée. Cet usage est obsolète.

Exemple

#include <iterator>
#include <list>
#include <ranges>
#include <type_traits>

int main()
{
    std::list<int> list{3, 1, 4, 1, 5, 9, 2, 6};

    std::ranges::subrange subrange
    {
        std::counted_iterator{std::begin(list), 4},
        std::default_sentinel
    };

    static_assert(
        std::is_same_v<
            std::tuple_element_t<0, decltype(subrange)>,
            // type défini par l'implémentation :
            std::counted_iterator<std::_List_iterator<int>>
            >);

    static_assert(
        std::is_same_v<
            std::tuple_element_t<1, decltype(subrange)>,
            std::default_sentinel_t
            >);
}
