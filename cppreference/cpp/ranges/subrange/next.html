std::ranges::subrange<I,S,K>::next

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr subrange next( std::iter_difference_t<I> n = 1 ) const&
    requires std::forward_iterator<I>;  // (1) (depuis C++20)

constexpr subrange next( std::iter_difference_t<I> n = 1 ) &&;  // (2) (depuis C++20)

Renvoie un subrange dont le begin_ est incrémenté (ou décrémenté si n est négatif). L'opération d'incrémentation (ou de décrémentation) effective est réalisée par advance().

  1. Retourne une copie de *this.

Équivalent à : auto tmp = *this;tmp.advance(n);return tmp;.

  1. Renvoie un subrange déplacé depuis *this.

Équivalent à : advance(n);return std::move(*this);.

Paramètre

  • n — nombre d'incréments maximal de l'itérateur

Valeur de retour

Comme décrit ci-dessus.

Notes

La différence entre cette fonction et advance() est que cette dernière effectue l'incrémentation (ou la décrémentation) sur place.

Exemple

#include <array>
#include <iterator>
#include <print>
#include <ranges>

int main()
{
    std::array arr{1, 2, 3, 4, 5, 6, 7};
    std::ranges::subrange sub{std::next(arr.begin(), 2), std::prev(arr.end(), 2)};
    std::println("1) sub: {}", sub);
    std::println("2) sub: {}", sub.next());
    std::println("3) sub: {}", sub.next(2));
}

Output:

1) sub: [3, 4, 5]
2) sub: [4, 5]
3) sub: [5]
