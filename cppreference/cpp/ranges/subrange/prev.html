std::ranges::subrange<I,S,K>::prev

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr subrange prev( std::iter_difference_t<I> n = 1 ) const
    requires std::bidirectional_iterator<I>;  // (depuis C++20)

Renvoie une copie de *this dont le begin_ est décrémenté (ou incrémenté si n est négatif). L'opération de décrémentation (ou d'incrémentation) effective est réalisée par advance().

Équivalent à :auto tmp = *this;tmp.advance(-n);return tmp;.

Paramètres

  • n — nombre de décrémentations de l'itérateur

Valeur de retour

Comme décrit ci-dessus.

Notes

La différence entre cette fonction et advance() est que cette dernière effectue la décrémentation (ou l'incrémentation) sur place.

Exemple

#include <iterator>
#include <list>
#include <print>
#include <ranges>

int main()
{
    std::list list{1, 2, 3, 4, 5};
    std::ranges::subrange sub{std::next(list.begin(), 2), std::prev(list.end(), 2)};
    std::println("{} {} {}", sub, sub.prev(), sub.prev(2));
}

Output:

[3] [2, 3] [1, 2, 3]
