std::ranges::get(std::ranges::subrange)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ranges>

template< std::size_t N, class I, class S, ranges::subrange_kind K >
    requires ((N == 0 && std::copyable<I>) || N == 1)
constexpr auto get( const ranges::subrange<I, S, K>& r );  // (1) (depuis C++20)

template< std::size_t N, class I, class S, ranges::subrange_kind K >
    requires (N < 2)
constexpr auto get( ranges::subrange<I, S, K>&& r );  // (2) (depuis C++20)

namespace std { using ranges::get; }  // (3) (depuis C++20)

Fournit la prise en charge du liage structuré.

  1. Obtient l'itérateur ou la sentinelle à partir d'une lvalue subrange (ou d'une rvalue const) lorsque N == 0 ou N == 1, respectivement.

  2. Identique à (1), sauf qu'il prend une rvalue subrange non const.

  3. Les surcharges de (1,2) sont importées dans l'espace de noms std, ce qui simplifie leur utilisation et fait de tout subrange dont l'itérateur est copiable un type de type paire.

Paramètres

  • r — a subrange

Valeur de retour

1,2) Si N est 0, renvoie r.begin(). Sinon (N est 1), renvoie r.end().

Exemple

#include <array>
#include <iostream>
#include <iterator>
#include <ranges>

int main()
{
    std::array a{1, -2, 3, -4};

    std::ranges::subrange sub_a{std::next(a.begin()), std::prev(a.end())};
    std::cout << *std::ranges::get<0>(sub_a) << ' '   // == *(begin(a) + 1)
              << *std::ranges::get<1>(sub_a) << '\n'; // == *(end(a) - 1)

    *std::get<0>(sub_a) = 42; // OK
//  *std::get<2>(sub_a) = 13; // Erreur : l'indice ne peut valoir que 0 ou 1
}

Output:

-2 -4
