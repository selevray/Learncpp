  1. Une fabrique d'intervalle qui produit un view sans aucun élément d'un type donné.

  2. Modèle de variable pour empty_view.

Fonctions membres

  • begin [statique] — renvoie nullptr (fonction membre statique publique)
  • end [statique] — renvoie nullptr (fonction membre statique publique)
  • data [statique] — renvoie nullptr (fonction membre statique publique)
  • size [statique] — renvoie 0 (fonction membre statique publique)
  • empty [statique] — renvoie true (fonction membre statique publique)

Modèles auxiliaires

template<class T>
constexpr bool ranges::enable_borrowed_range<ranges::empty_view<T>> = true;  // (depuis C++20)

Cette spécialisation de ranges::enable_borrowed_range rend empty_view conforme à borrowed_range.

Notes

Bien que empty_view obtienne les fonctions membres front, back et operator[] de view_interface, les appels à celles-ci entraînent toujours un comportement indéfini, puisqu'un empty_view est toujours vide.

La fonction de conversion operator bool héritée renvoie toujours false.

Exemple

#include <ranges>

int main()
{
    namespace ranges = std::ranges;

    ranges::empty_view<long> e;
    static_assert(ranges::empty(e)); // utilise operator bool
    static_assert(0 == e.size());
    static_assert(nullptr == e.data());
    static_assert(nullptr == e.begin());
    static_assert(nullptr == e.end());
    static_assert(nullptr == e.cbegin());
    static_assert(nullptr == e.cend());
}
