  1. Un adaptateur d'intervalle qui représente view des éléments d'une séquence sous-jacente, en commençant au début et en se terminant à une borne donnée.

  2. views::take est un RangeAdaptorObject. L'expression views::take(e, f) produit une vue représentant les f premiers éléments de e. Le résultat n'est pas nécessairement un take_view.

views::take(e, f) est équivalent en expression à (où T est std::remove_cvref_t<decltype((e))> et D est ranges::range_difference_t<decltype((e))>) :

  • ((void)f, decay-copy(e)), si T est un ranges::empty_view, sauf que les évaluations de e et f sont séquencées de manière indéterminée ;

  • U(ranges::begin(e), ranges::begin(e) + std::min<D>(ranges::distance(e), f)), si T est une spécialisation de std::span, std::basic_string_view ou ranges::subrange qui modélise à la fois random_access_range et sized_range, où U est

    • std::span<typename T::element_type>, si T est une spécialisation de std::span ;
    • T, si T est une spécialisation de std::basic_string_view ;
    • ranges::subrange<ranges::iterator_t<T>>, si T est une spécialisation de ranges::subrange ;

  • ranges::iota_view(*ranges::begin(e), *(ranges::begin(e) + std::min<D>(ranges::distance(e), f))), si T est une spécialisation de ranges::iota_view qui modélise à la fois random_access_range et sized_range ;

  • sinon, si T est une spécialisation de ranges::repeat_view :
  • views::repeat(*e.value_, std::min<D>(ranges::distance(e), f)), si T modélise sized_range ; dans ce cas e n'est évalué qu'une seule fois ;
  • views::repeat(*e.value_, static_cast<D>(e)) sinon ;

(depuis C++23)

  • sinon, take_view(e, f).

Dans tous les cas, decltype((f)) doit modéliser std::convertible_to<D>.

take_view modélise les concepts contiguous_range, random_access_range, bidirectional_range, forward_range, input_range et sized_range lorsque la vue sous-jacente V modélise les concepts respectifs. Il modélise common_range lorsque la vue sous-jacente V modélise à la fois random_access_range et sized_range.

template< class T >
constexpr bool enable_borrowed_range<std::ranges::take_view<T>> =
    ranges::enable_borrowed_range<T>;  // (depuis C++20)

Cette spécialisation de std::ranges::enable_borrowed_range fait en sorte que take_view satisfasse borrowed_range lorsque la vue sous-jacente le satisfait.

Exemple

#include <algorithm>
#include <iostream>
#include <ranges>

int main()
{
    namespace views = std::views;
    auto print = [](char x){ std::cout << x; };

    for (const char nums[]{'1', '2', '3'};
         int n : views::iota(0, 5))
    {
        std::cout << "take(" << n << "): ";
        // prend en toute sécurité au plus min(n, nums.size()) éléments :
        std::ranges::for_each(nums | views::take(n), print);
        std::cout << '\n';
    }
}

Output:

take(0):
take(1): 1
take(2): 12
take(3): 123
take(4): 123
