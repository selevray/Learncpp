std::ranges::iota_view<W, Bound>::empty

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr bool empty() const;  // (depuis C++20)

Vérifie si l'intervalle est vide (c.-à-d. si la valeur de début est identique à la valeur sentinelle).

Valeur de retour

value_ == bound_

Exemple

#include <cassert>
#include <ranges>

int main()
{
    auto a = std::ranges::iota_view<int, int>();
    assert(a.empty());

    auto b = std::ranges::iota_view(4);
    assert(!b.empty());

    auto c = std::ranges::iota_view(4, 8);
    assert(!c.empty());
}
