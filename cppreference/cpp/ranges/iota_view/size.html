std::ranges::iota_view<W, Bound>::size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr auto size() const
    requires (std::same_as<W, Bound> && /*advanceable*/<W>) ||
             (/*is-integer-like*/<W> && /*is-integer-like*/<Bound>) ||
             std::sized_sentinel_for<Bound, W>;  // (depuis C++20)

Renvoie la taille de la vue si la vue est bornée.

Pour les définitions de /*advanceable*/ et /*is-integer-like*/, voir advanceable et is-integer-like respectivement.

Valeur de retour

Si l'un de W et Bound n'est pas un type semblable à un entier, renvoie to-unsigned-like ﻿(bound_ - value_ ﻿).

Sinon, renvoie (value_ < 0) ? ( (bound_ < 0) ? to-unsigned-like ﻿(-value_ ﻿) - to-unsigned-like ﻿(-bound_ ﻿) : to-unsigned-like ﻿(bound_ ﻿) + to-unsigned-like ﻿(-value_ ﻿) ) : to-unsigned-like ﻿(bound_ ﻿) - to-unsigned-like ﻿(value_ ﻿).

Exemple

#include <cassert>
#include <ranges>

int main()
{
    unsigned initial_value{1}, bound{5};
    auto i{std::views::iota(initial_value, bound)};
    assert(i.size() == bound - initial_value and i.size() == 4);

    auto u{std::views::iota(8)};
    // assert(u.size()); // Erreur : size() n'est pas présent car « u » est non borné
}
