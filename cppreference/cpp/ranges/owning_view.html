std::ranges::owning_view

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ranges>

template< ranges::range R >
    requires std::movable<R> && (!/*is-initializer-list*/<R>)
class owning_view
    : public ranges::view_interface<owning_view<R>>  // (depuis C++20)

owning_view est un view qui possède de façon unique un range. Il est uniquement déplaçable et stocke ce range en lui.

La constante /*is-initializer-list*/<R> dans la clause requires est true si et seulement si std::remove_cvref_t<R> est une spécialisation de std::initializer_list.

  1. Constructeur par défaut. Initialise par valeur l'intervalle stocké à l'aide de son initialiseur de membre par défaut (= R()).

  2. Constructeur de déplacement. Construit par déplacement l'intervalle stocké à partir de celui de other.

  4. Le constructeur de copie est supprimé. owning_view est uniquement déplaçable.

Modèles auxiliaires

template< class T >
constexpr bool enable_borrowed_range<std::ranges::owning_view<T>> =
    ranges::enable_borrowed_range<T>;  // (depuis C++20)

Cette spécialisation de ranges::enable_borrowed_range fait en sorte que owning_view satisfasse borrowed_range lorsque l'intervalle sous-jacent le satisfait.

Exemple

#include <cassert>
#include <iostream>
#include <ranges>
#include <string>

int main()
{
    using namespace std::literals;
    std::ranges::owning_view ov{"cosmos"s}; // le type déduit de R est std::string ;
                                            // `ov` est le seul propriétaire de cette chaîne
    assert(
        ov.empty() == false &&
        ov.size() == 6 &&
        ov.size() == ov.base().size() &&
        ov.front() == 'c' &&
        ov.front() == *ov.begin() &&
        ov.back() == 's' &&
        ov.back() == *(ov.end() - 1) &&
        ov.data() == ov.base()
    );

    std::cout << "sizeof(ov): " << sizeof ov << '\n' // généralement égal à sizeof(R)
              << "range-for: ";
    for (const char ch : ov)
        std::cout << ch;
    std::cout << '\n';

    std::ranges::owning_view<std::string> ov2;
    assert(ov2.empty());
//  ov2 = ov; // erreur de compilation : l'opérateur d'affectation par copie est supprimé
    ov2 = std::move(ov); // OK
    assert(ov2.size() == 6);
}

Sortie possible :

sizeof(ov): 32
range-for: cosmos
