std::ranges::drop_while_view<V,Pred>::end

constexpr auto end();  // (depuis C++20)

Renvoie une sentinelle ou un itérateur représentant la fin de drop_while_view.

Revient effectivement à ranges::end(base_), où base_ est la vue sous-jacente.

Paramètres

(aucune)

Valeur de retour

Une sentinelle ou un itérateur représentant la fin de la vue.

Exemple

#include <cassert>
#include <iostream>
#include <ranges>

int main()
{
    static constexpr auto data = {0, -1, -2, 3, 1, 4, 1, 5};
    auto view = std::ranges::drop_while_view{data, [](int x) { return x <= 0; }};
    assert(view.end()[-1] == 5);
}
