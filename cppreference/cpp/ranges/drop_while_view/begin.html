std::ranges::drop_while_view<V,Pred>::begin

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr auto begin();  // (depuis C++20)

Renvoie un itérateur vers le premier élément de la vue.

Revient effectivement à ranges::find_if_not(base_, std::cref(pred())), où base_ est la vue sous-jacente. Le comportement est indéfini si *this ne stocke pas de prédicat.

Afin de fournir la complexité en temps constant amorti requise par le concept range, cette fonction met en cache le résultat dans l'objet drop_while_view pour une utilisation lors des appels suivants.

Paramètres

(aucune)

Valeur de retour

Itérateur vers le premier élément de la vue.

Exemple

#include <cassert>
#include <ranges>

int main()
{
    static constexpr auto data = {0, -1, -2, 3, 1, 4, 1, 5};
    auto view = std::ranges::drop_while_view{data, [](int x){ return x <= 0; }};
    assert(view.begin()[0] == 3);
}
