std::ranges::drop_while_view<V,Pred>::drop_while_view

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

drop_while_view() requires std::default_initializable<V> &&
                           std::default_initializable<Pred> = default;  // (1) (depuis C++20)

constexpr explicit drop_while_view( V base, Pred pred );  // (2) (depuis C++20)

Construit un drop_while_view.

  1. Constructeur par défaut. Initialise par valeur la vue sous-jacente base_ et le prédicat pred_.

  2. Construit par déplacement la vue sous-jacente base_ à partir de base et le prédicat pred_ à partir de pred.

Paramètres

  • base — vue sous-jacente
  • pred — predicate

Exemple

#include <functional>
#include <iostream>
#include <ranges>

int main()
{
    static constexpr auto a = {-2, -7, -1, -8, -2, +-+8, 3, 1, 4, 1, 5};
    auto positive = [](int x) { return 0 < x; };
    for (auto v = std::ranges::drop_while_view{a, std::not_fn(positive)}; int x : v)
        std::cout << x << ' ';
    std::cout << '\n';
}

Output:

3 1 4 1 5
