std::ranges::drop_while_view<V,Pred>::pred

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr const Pred& pred() const;  // (depuis C++20)

Retourne une référence au prédicat stocké.

Si *this ne stocke pas de prédicat (par exemple si une exception est levée lors de l'affectation à *this, qui construit par copie ou par déplacement un Pred), le comportement est indéfini.

Paramètres

(aucune)

Valeur de retour

Une référence au prédicat stocké pred_.

Exemple

#include <array>
#include <iomanip>
#include <iostream>
#include <ranges>

int main()
{
    constexpr std::array data{0, -1, -2, 3, 1, 4, 1, 5};

    auto view = std::ranges::drop_while_view
    {
        data, [](int x) { return x <= 0; }
    };

    std::cout << std::boolalpha;
    for (int x : data)
        std::cout << "predicate(" << std::setw(2) << x << ") : "
                  << view.pred()(x) << '\n';
}
