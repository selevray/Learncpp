  1. Produit une view contenant exactement un élément d'une valeur spécifiée.

  2. L'expression views::single(e) est équivalente à une expression à single_view<std::decay_t<decltype((e))>>(e) pour toute sous-expression e appropriée.

La durée de vie de l'élément est liée à celle du single_view parent. Copier single_view crée une copie de l'élément.

Objets de point de personnalisation

Le nom views::single désigne un objet de point de personnalisation, qui est un objet fonction const d'un type de classe littéral semiregular. À des fins d'exposition, la version sans qualificateurs cv de son type est désignée par __single_fn.

Toutes les instances de __single_fn sont égales. Les effets de l'invocation de différentes instances du type __single_fn sur les mêmes arguments sont équivalents, qu'il s'agisse ou non d'une lvalue ou d'une rvalue, et que l'expression désignant l'instance soit qualifiée const ou non (toutefois, une instance qualifiée volatile n'est pas tenue d'être invocable). Ainsi, views::single peut être copié librement et ses copies peuvent être utilisées de manière interchangeable.

Étant donné un ensemble de types Args..., si std::declval<Args>()... satisfont aux exigences relatives aux arguments de views::single ci-dessus, alors __single_fn modélise

  • std::invocable<__single_fn, Args...>,
  • std::invocable<const __single_fn, Args...>,
  • std::invocable<__single_fn&, Args...>, and
  • std::invocable<const __single_fn&, Args...>.

Sinon, aucun opérateur d'appel de fonction de __single_fn ne participe à la résolution de surcharge.

Construit un single_view.

  1. Initialise par défaut value_, qui initialise par valeur sa valeur contenue.

  2. Initialise value_ avec t.

  3. Initialise value_ avec std::move(t).

  4. Initialise value_ comme si par value_{std::in_place, std::forward<Args>(args)...}.

Notes

Pour un single_view, la fonction membre empty héritée renvoie toujours false, et la fonction de conversion operator bool héritée renvoie toujours true.

Exemple

#include <iomanip>
#include <iostream>
#include <ranges>
#include <string>
#include <tuple>

int main()
{
    constexpr std::ranges::single_view sv1{3.1415}; // utilise le constructeur (const T&)
    static_assert(sv1);
    static_assert(not sv1.empty());

    std::cout << "1) *sv1.data(): " << *sv1.data() << '\n'
              << "2) *sv1.begin(): " << *sv1.begin() << '\n'
              << "3)  sv1.size(): " << sv1.size() << '\n'
              << "4)  distance: " << std::distance(sv1.begin(), sv1.end()) << '\n';

    std::string str{"C++20"};
    std::cout << "5)  str = " << std::quoted(str) << '\n';
    std::ranges::single_view sv2{std::move(str)}; // utilise le constructeur (T&&)
    std::cout << "6) *sv2.data(): " << std::quoted(*sv2.data()) << '\n'
              << "7)  str = " << std::quoted(str) << '\n';

    std::ranges::single_view<std::tuple<int, double, std::string>>
        sv3{std::in_place, 42, 3.14, "😄"}; // utilise (std::in_place_t, Args&&... args)

    std::cout << "8)  sv3 holds a tuple: { "
              << std::get<0>(sv3[0]) << ", "
              << std::get<1>(sv3[0]) << ", "
              << std::get<2>(sv3[0]) << " }\n";
}

Output:

1) *sv1.data(): 3.1415
2) *sv1.begin(): 3.1415
3)  sv1.size(): 1
4)  distance: 1
5)  str = "C++20"
6) *sv2.data(): "C++20"
7)  str = ""
8)  sv3 holds a tuple: { 42, 3.14, 😄 }
