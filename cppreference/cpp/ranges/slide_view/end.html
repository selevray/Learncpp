std::ranges::slide_view<V>::end

constexpr auto end()

Renvoie une sentinelle ou un itérateur représentant la fin de slide_view.

  1. Soient base_ et n_ les membres de données sous-jacents. Équivalent à :
  • Si V modélise slide-caches-nothing, return iterator<false>(ranges::begin(base_) + ranges::range_difference_t<V>(size()), n_);.
  • Sinon, si V modélise slide-caches-last, return iterator<false>(ranges::prev(ranges::end(base_), n_ - 1, ranges::begin(base_)), n_);.
  • Sinon, si V modélise common_range, return iterator<false>(ranges::end(base_), ranges::end(base_), n_);.
  • Sinon, return sentinel(ranges::end(base_));.

Si V modélise slide-caches-last, cette fonction met en cache le résultat dans cached_end_ pour une utilisation lors des appels suivants. Ceci est nécessaire pour fournir la complexité amortie constante en temps requise par range.

  1. Équivalent à begin() + ranges::range_difference_t<const V>(size()).

Paramètres

(aucune)

Valeur de retour

Une sentinelle ou un itérateur représentant la fin de slide_view.

Exemple

#include <iostream>
#include <ranges>

int main()
{
    static constexpr auto source = {'A', 'B', 'C', 'D'};

    for (const auto subrange: source | std::views::slide(3))
    {
        std::cout << "[ ";
        for (auto it = subrange.begin(); it != subrange.end(); ++it)
            std::cout << *it << ' ';
        std::cout << "]\n";
    }
}

Output:

[ A B C ]
[ B C D ]
