std::ranges::slide_view<V>::slide_view

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr explicit slide_view( V base, ranges::range_difference_t<V> n );  // (depuis C++23)

Construit un slide_view en initialisant les membres de données sous-jacents :

  • construit par déplacement la vue sous-jacente base_ avec std::move(base),
  • la « taille de fenêtre » n_ avec n.

Paramètres

  • base — la vue source
  • n — la taille de la « fenêtre glissante »

Exemple

#include <algorithm>
#include <iostream>
#include <ranges>

int main()
{
    const auto source = {1, 2, 3, 4};

    auto slide = std::views::slide(source, 3);

    std::ranges::for_each(slide, [](std::ranges::viewable_range auto&& w)
    {
        std::cout << '[' << w[0] << ' ' << w[1] << ' ' << w[2] << "]\n";
    });
}

Output:

[1 2 3]
[2 3 4]
