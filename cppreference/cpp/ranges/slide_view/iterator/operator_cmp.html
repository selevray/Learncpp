Compare les itérateurs sous-jacents.

Soient current_ et last_ele_ les itérateurs sous-jacents vers le début et la fin de la fenêtre glissante, respectivement.

  1. Équivalent à :
  • return x.last_ele_ == y.last_ele_;, si last_ele_ est présent. Sinon,
  • return x.current_ == y.current_;.

  1. Équivalent à return x.current_ < y.current_;.

  2. Équivalent à return y < x;.

  3. Équivalent à return !(y < x);.

  4. Équivalent à return !(x < y);.

  5. Équivalent à return x.current_ <=> y.current_;.

Ces fonctions ne sont pas visibles par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peuvent être trouvées que par la recherche dépendante des arguments lorsque std::ranges::slide_view::iterator<Const> est une classe associée aux arguments.

L'opérateur != est synthétisé à partir de operator==.
