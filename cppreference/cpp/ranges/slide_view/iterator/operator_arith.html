Fait avancer ou reculer l'itérateur.

Soient current_ et last_ele_ les itérateurs sous-jacents vers le début et la fin de la fenêtre glissante.

  1. Équivalent à :
current_ = ranges::next(current_);
last_ele_ = ranges::next(last_ele_); // si last_ele_ est présent
return *this;

Avant l'invocation, current_ et last_ele_ (si présent) doivent être incrémentables.

  1. Équivalent à : auto tmp = *this; ++*this; return tmp;

  2. Équivalent à :

current_ = ranges::prev(current_);
last_ele_ = ranges::prev(last_ele_); // si last_ele_ est présent
return *this;

Avant l'invocation, current_ et last_ele_ (si présent) doivent être décrémentables.

  1. Équivalent à : auto tmp = *this; --*this; return tmp;

  2. Équivalent à :

current_ = current_ + n;
last_ele_ = last_ele_ + n; // si last_ele_ est présent
return *this;

Avant l'invocation, les expressions current_ + n et last_ele_ + n (si last_ele_ est présent) doivent avoir un comportement bien défini.

  1. Équivalent à :
current_ = current_ - n;
last_ele_ = last_ele_ - n; // si last_ele_ est présent
return *this;

Avant l'invocation, les expressions current_ - n et last_ele_ - n (si last_ele_ est présent) doivent avoir un comportement bien défini.

Paramètres

  • n — position relative à la position courante

Valeur de retour

1,3,5,6) *this

2,4) une copie de *this réalisée avant la modification
