Concepts auxiliaires

template< class R >
concept /*tiny-range*/ =
    ranges::sized_range<R> &&
    requires { /* is-statically-constexpr-sized */<R>; } &&
    (std::remove_reference_t<R>::size() <= 1);  // (3) ( exposition uniquement* )
  1. lazy_split_view prend un view et un délimiteur, et découpe le view en sous-intervalles selon le délimiteur.

Deux scénarios principaux sont pris en charge :

  • La vue est un input_range, le délimiteur est un seul élément (encapsulé dans un single_view).
  • La vue est un forward_range, le délimiteur est un view d'éléments.

  1. Un RangeAdaptorObject. L'expression views::lazy_split(e, f) est équivalente à une expression à lazy_split_view(e, f).

  2. Le concept /*tiny-range*/<Pattern> réservé à l'exposition est satisfait si Pattern satisfait sized_range, Pattern::size() est une expression constante et convient comme argument de modèle non type, et la valeur de Pattern::size() est inférieure ou égale à 1. En particulier, empty_view et single_view satisfont ce concept.

lazy_split_view modélise les concepts forward_range et input_range lorsque le view sous-jacent V modélise les concepts respectifs, et modélise common_range lorsque V modélise à la fois forward_range et common_range.

L'intervalle interne (ranges::range_reference_t<lazy_split_view>) modélise les concepts forward_range et input_range lorsque le view sous-jacent V modélise les concepts respectifs. Il ne modélise pas common_range et ne peut pas être utilisé avec les algorithmes qui attendent un bidirectional_range ou plus.

Contrairement à split_view, lazy_split_view ne maintient pas la continuité du sous-intervalle.

Guides de déduction

Notes

Le nom lazy_split_view est introduit par le rapport de défaut post-C++20 P2210R2. Il a le même mécanisme paresseux que celui de l'ancien split_view avant modification.

Exemple

#include <algorithm>
#include <iostream>
#include <ranges>
#include <string_view>

auto print = [](auto const& view)
{
    // `view` est de type std::views::lazy_split_view::__outer_iterator::value_type

    for (std::cout << "{ "; const auto element : view)
        std::cout << element << ' ';
    std::cout << "} ";
};

int main()
{
    constexpr static auto source = {0, 1, 0, 2, 3, 0, 4, 5, 6, 0, 7, 8, 9};
    constexpr int delimiter{0};
    constexpr std::ranges::lazy_split_view outer_view{source, delimiter};
    std::cout << "splits[" << std::ranges::distance(outer_view) << "]:  ";
    for (auto const& inner_view: outer_view)
        print(inner_view);

    constexpr std::string_view hello{"Hello C++ 20 !"};
    std::cout << "\n" "substrings: ";
    std::ranges::for_each(hello | std::views::lazy_split(' '), print);

    constexpr std::string_view text{"Hello-+-C++-+-20-+-!"};
    constexpr std::string_view delim{"-+-"};
    std::cout << "\n" "substrings: ";
    std::ranges::for_each(text | std::views::lazy_split(delim), print);
}

Output:

splits[5]:  { } { 1 } { 2 3 } { 4 5 6 } { 7 8 9 }
substrings: { H e l l o } { C + + } { 2 0 } { ! }
substrings: { H e l l o } { C + + } { 2 0 } { ! }
