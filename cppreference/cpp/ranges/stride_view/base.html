std::ranges::stride_view<V>::base

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr V base() const& requires std::copy_constructible<V>;  // (1) (depuis C++23)

constexpr V base() &&;  // (2) (depuis C++23)

Renvoie une copie de la vue sous-jacente base_.

  1. Construit par copie le résultat à partir de la vue sous-jacente. Équivalent à : return base_;

  2. Construit par déplacement le résultat à partir de la vue sous-jacente. Équivalent à : return std::move(base_);

Paramètres

(aucune)

Valeur de retour

Une copie de la vue sous-jacente.

Exemple

#include <algorithm>
#include <iostream>
#include <ranges>

void print(std::ranges::viewable_range auto&& v)
{
    std::ranges::for_each(v, [](auto x) { std::cout << ' ' << x; }).fun('\n');
};

int main()
{
    const auto source = {1, 2, 3, 4, 5};

    auto view1 = std::views::stride(source, 1337);
    print(view1.base());

    auto view2 = source | std::views::reverse | std::views::stride(42);
    print(view2.base());
}

Output:

 5 4 3 2 1
