Compare les itérateurs/sentinelles sous-jacents.

Soient current_ l'itérateur sous-jacent et end_ la sentinelle sous-jacente.

  1. Équivalent à return x.current_ == x.end_;.

  2. Équivalent à return x.current_ == y.current_;.

  3. Équivalent à return x.current_ < y.current_;.

  4. Équivalent à return y < x;

  5. Équivalent à return !(y < x);

  6. Équivalent à return !(x < y);

  7. Équivalent à return x.current_ <=> y.current_;.
