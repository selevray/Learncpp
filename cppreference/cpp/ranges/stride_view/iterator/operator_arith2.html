Incrémente ou décrémente l'itérateur.

Soient current_, end_, stride_ et missing_ les membres de données de l'itérateur.

1,2) Équivalent à auto r = i; r += n; return r;.

  1. Équivalent à auto r = i; r -= n; return r;.

  2. Soit N égal à x.current_ - y.current_. Renvoie :

  • (N + x.missing_ - y.missing_) / x.stride_, si Base modélise forward_range.
  • -/*div-ceil*/(-N, x.stride_), if N < 0.
  • /*div-ceil*/(N, x.stride_) sinon.

  1. Équivalent à return /*div-ceil*/(x.end_ - x.current_, x.stride_);.

  2. Équivalent à return -(s - x);.

Ces fonctions ne sont pas visibles par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peuvent être trouvées que par la recherche dépendante des arguments lorsque stride_view::iterator<Const> est une classe associée aux arguments.

Paramètres

  • x, y, i — les itérateurs
  • s — une sentinelle

Valeur de retour

1,2) Un itérateur incrémenté

  1. Un itérateur décrémenté

  2. Une distance entre les itérateurs donnés

5,6) Une distance entre l'itérateur donné et la sentinelle
