std::ranges::stride_view<V>::iterator<Const>::operator*

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr decltype(auto) operator*() const;  // (depuis C++23)

Renvoie l'élément pointé par l'itérateur sous-jacent current_ sous la forme V.

Équivalent à : return *current_;.

Paramètres

(aucune)

Valeur de retour

L'élément courant.

Notes

operator-> n'est pas fourni.

Exemple

#include <ranges>

int main()
{
    constexpr static auto v = {'a', 'b', 'c', 'd', 'e'};
    constexpr auto view{v | std::views::stride(2)};
    constexpr auto iter{view.begin() + 1};
    static_assert(*iter == 'c');
    static_assert(*(view.begin() + 2) == 'e');
}
