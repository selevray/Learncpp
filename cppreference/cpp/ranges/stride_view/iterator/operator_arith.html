Incrémente ou décrémente l'itérateur.

Soient current_, end_, stride_ et missing_ les membres de données de l'itérateur.

  1. Équivalent à
missing_ = ranges::advance(current_, stride_, end_);
return *this

. Avant l'appel, current_ ne doit pas être égal à end_.

  1. Équivalent à ++*this;.

  2. Équivalent à auto tmp = *this; ++*this; return tmp;.

  3. Équivalent à

ranges::advance(current_, missing_ - stride_);
missing_ = 0;
return *this;

  1. Équivalent à auto tmp = *this; --*this; return tmp;.

  2. Équivalent à

if (n > 0)
{
    ranges::advance(current_, stride_ * (n - 1));
    missing_ = ranges::advance(current_, stride_, end_);
}
else if (n < 0)
{
    ranges::advance(current_, stride_ * n + missing_);
    missing_ = 0;
}

return *this;

Si n > 0, alors avant l'appel à cette fonction, ranges::distance(current_, end_) doit être strictement supérieur à stride_ * (n - 1).

Notez que si n < 0, ranges::distance(current_, end_) est toujours strictement supérieur à stride_ * (n - 1) (non positif).
