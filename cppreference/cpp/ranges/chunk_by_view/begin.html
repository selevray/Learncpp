std::ranges::chunk_by_view<V,Pred>::begin

constexpr /*iterator*/ begin();  // (depuis C++23)

Renvoie un itérateur vers le premier élément du chunk_by_view.

Équivalent à :

ranges::iterator_t<V> iter;

if (begin_.has_value())
    iter = begin_.value();
else
{
    iter = /*find_next*/(ranges::begin(base()));
    begin_ = iter; // caching
}

return /*iterator*/(*this, ranges::begin(base()), iter);

Le comportement est indéfini si le prédicat sous-jacent pred_ ne contient pas de valeur.

Paramètres

(aucune)

Valeur de retour

Itérateur vers le premier élément.

Notes

Afin de fournir la complexité constante amortie exigée par le concept range, cette fonction met en cache le résultat dans le membre de données begin_ pour être utilisé lors des appels suivants.
