std::ranges::chunk_by_view<V,Pred>::pred

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr const Pred& pred() const;  // (depuis C++23)

Renvoie une référence vers l'objet Pred contenu. Équivalent à return *pred_;.

Le comportement est indéfini si pred_ ne contient pas de valeur.

Paramètres

(aucune)

Valeur de retour

Une référence vers l'objet Pred contenu.

Exemple

#include <cassert>
#include <concepts>
#include <functional>
#include <initializer_list>
#include <ranges>

int main()
{
    const auto v = {1, 1, 2, 2, 1, 1, 1};
    auto chunks = v | std::views::chunk_by(std::equal_to{});
    auto pred = chunks.pred();
    static_assert(std::same_as<decltype(pred), std::equal_to<>>);
    assert(pred(v.begin()[0], 1));
}
