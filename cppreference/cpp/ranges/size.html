Calcule le nombre d'éléments de t en temps constant.

Étant donnée la sous-expression dont t désigne l'objet résultat (éventuellement matérialisé) comme E, et le type de E comme T :

  • Si T est un tableau de borne inconnue, ranges::size(E) est mal formé.
  • Sinon, si T est un type tableau, ranges::size(E) est équivalente à une expression [decay-copy ﻿(std::extent_v<T>) (jusqu'à C++23) | auto(std::extent_v<T>) (depuis C++23)].
  • Sinon, si toutes les conditions suivantes sont satisfaites, ranges::size(E) est équivalente à une expression [decay-copy ﻿(t.size()) (jusqu'à C++23) | auto(t.size()) (depuis C++23)] :
    • ranges::disable_sized_range<std::remove_cv_t<T>> is false.
    • [decay-copy ﻿(t.size()) (jusqu'à C++23) | auto(t.size()) (depuis C++23)] est une expression valide de type de type entier.
  • Sinon, si toutes les conditions suivantes sont satisfaites, ranges::size(E) est équivalente à une expression [decay-copy ﻿(size(t)) (jusqu'à C++23) | auto(size(t)) (depuis C++23)] :
    • T est un type classe ou un type énumération.
    • ranges::disable_sized_range<std::remove_cv_t<T>> is false.
    • [decay-copy ﻿(size(t)) (jusqu'à C++23) | auto(size(t)) (depuis C++23)] est une expression valide de type de type entier, où la signification de size est établie comme si l'on effectuait uniquement une recherche dépendante des arguments.
  • Sinon, si toutes les conditions suivantes sont satisfaites, ranges::size(E) est équivalente à une expression to-unsigned-like ﻿(ranges::end(t) - ranges::begin(t)) :
    • T modélise forward_range.
    • Étant donné que le type de ranges::begin(t) est I et que le type de ranges::end(t) est S, à la fois sized_sentinel_for<S, I> et forward_iterator<I> sont modélisés.
    • to-unsigned-like ﻿(ranges::end(t) - ranges::begin(t)) est une expression valide.
  • Sinon, ranges::size(E) est mal formé.

Les cas mal formés diagnostiquables ci-dessus entraînent un échec de substitution lorsque ranges::size(E) apparaît dans le contexte immédiat d'une instanciation de modèle.

Objets de point de personnalisation

Le nom ranges::size désigne un objet de point de personnalisation, qui est un objet fonction const d'un type de classe littéral semiregular. À des fins d'exposition, la version sans qualificateurs cv de son type est désignée par __size_fn.

Toutes les instances de __size_fn sont égales. Les effets de l'invocation de différentes instances du type __size_fn sur les mêmes arguments sont équivalents, qu'il s'agisse ou non d'une lvalue ou d'une rvalue, et que l'expression désignant l'instance soit qualifiée const ou non (toutefois, une instance qualifiée volatile n'est pas tenue d'être invocable). Ainsi, ranges::size peut être copié librement et ses copies peuvent être utilisées de manière interchangeable.

Étant donné un ensemble de types Args..., si std::declval<Args>()... satisfont aux exigences relatives aux arguments de ranges::size ci-dessus, alors __size_fn modélise

  • std::invocable<__size_fn, Args...>,
  • std::invocable<const __size_fn, Args...>,
  • std::invocable<__size_fn&, Args...>, and
  • std::invocable<const __size_fn&, Args...>.

Sinon, aucun opérateur d'appel de fonction de __size_fn ne participe à la résolution de surcharge.

Notes

Chaque fois que ranges::size(e) est valide pour une expression e, le type de retour est semblable à un entier.

La norme C++20 exige que, si l'appel de fonction size sous-jacent renvoie une prvalue, la valeur de retour soit construite par déplacement à partir de l'objet temporaire matérialisé. Toutes les implémentations renvoient directement la prvalue à la place. Cette exigence est corrigée par la proposition post-C++20 P0849R8 pour correspondre aux implémentations.

L'expression ranges::distance(e) peut aussi servir à déterminer la taille d'un intervalle e. Contrairement à ranges::size(e), ranges::distance(e) fonctionne même si e est un intervalle sans taille, au prix d'une complexité linéaire dans ce cas.

Exemple

#include <iostream>
#include <ranges>
#include <type_traits>
#include <vector>

int main()
{
    auto v = std::vector<int>{};
    std::cout << "ranges::size(v) == " << std::ranges::size(v) << '\n';

    auto il = {7};     // std::initializer_list
    std::cout << "ranges::size(il) == " << std::ranges::size(il) << '\n';

    int array[]{4, 5}; // le tableau a une borne connue
    std::cout << "ranges::size(array) == " << std::ranges::size(array) << '\n';

    static_assert(std::is_signed_v<decltype(std::ranges::size(v))> == false);
}

Output:

ranges::size(v) == 0
ranges::size(il) == 1
ranges::size(array) == 2
