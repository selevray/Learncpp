Incrémente ou décrémente l'itérateur.

Soit current_ un tableau sous-jacent d'itérateurs.

  1. Équivalent à :
for (auto& i : current_)
    i = std::ranges::next(i);
return *this;

Le comportement est indéfini si, avant l'appel, current_.back() n'est pas incrémentable.

  1. Équivalent à :
auto tmp = *this;
++*this;
return tmp;
  1. Équivalent à :
for (auto& i : current_)
    i = std::ranges::prev(i);
return *this;

Le comportement est indéfini si, avant l'appel, current_.front() n'est pas décrémentable.

  1. Équivalent à :
auto tmp = *this;
--*this;
return tmp;
  1. Équivalent à :
for (auto& i : current_)
    i = i + n;
return *this;

Le comportement est indéfini si, avant l'appel, current_.back() + n n'a pas de comportement bien défini.

  1. Équivalent à :
for (auto& i : current_)
    i = i - n;
return *this;

Le comportement est indéfini si, avant l'appel, current_.front() - n n'a pas de comportement bien défini.

Paramètres

  • n — position relative à la position courante

Valeur de retour

1,3,5,6) *this

2,4) Une copie de *this faite avant la modification.

Exemple

#include <cassert>
#include <list>
#include <ranges>
#include <utility>
#include <vector>

int main()
{
    {
        auto v = std::vector{0, 1, 2, 3, 4, 5};
        auto i = (v | std::views::pairwise).begin();
        assert((*i == std::pair{0, 1}));
        ++i;                            // overload (1)
        assert((*i == std::pair{1, 2}));
        --i;                            // overload (3)
        assert((*i == std::pair{0, 1}));
        i += 2;                         // overload (5)
        assert((*i == std::pair{2, 3}));
        i -= 2;                         // overload (6)
        assert((*i == std::pair{0, 1}));
    }
    {
        auto v = std::list{0, 1, 2, 3, 4, 5};
        auto i = (v | std::views::pairwise).begin();
        assert((*i == std::pair{0, 1}));
        ++i;                            // overload (1)
        assert((*i == std::pair{1, 2}));
        --i;                            // overload (3)
        assert((*i == std::pair{0, 1}));
//      i += 2; // Erreur : v n'est pas un random_access_range ; surcharge (5)
//      i -= 2; // Erreur : v n'est pas un random_access_range ; surcharge (6)
    }
}
