Soit current_ le tableau sous-jacent d'itérateurs, et Base le type (éventuellement qualifié const) de la vue sous-jacente.

1,2) Renvoie l'itérateur i incrémenté de n. Équivalent à : auto r = i; r += n; return r;.

  1. Renvoie l'itérateur i décrémenté de n. Équivalent à : auto r = i; r -= n; return r;.

  2. Renvoie la distance entre i et j. Équivalent à : return i.current_.back() - j.current_.back();.

Paramètres

  • i, j — les itérateurs
  • n — position relative à la position courante

Valeur de retour

1,2) Un itérateur incrémenté.

  1. Un itérateur décrémenté.

  2. Une distance entre les itérateurs donnés.
