std::ranges::adjacent_view<V,N>::iterator<Const>::operator*

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr auto operator*() const;  // (depuis C++23)

Renvoie les éléments dans V vers lesquels pointe le tableau sous-jacent d'itérateurs.

Soit current_ un tableau sous-jacent d'itérateurs.

Équivalent à :

return /*tuple-transform*/([](auto& i) -> decltype(auto) { return *i; }, current_);

Paramètres

(aucune)

Valeur de retour

L'élément courant, qui est un std::tuple de références vers les éléments sous-jacents.

Notes

operator-> n'est pas fourni.

Exemple

#include <ranges>
#include <tuple>

int main()
{
    constexpr static auto v = {0, 1, 2, 3, 4, 5};
    //                               └──┬──┘
    //                                  └─────────────────┐
    constexpr auto view {v | std::views::adjacent<3>}; // │
    constexpr auto iter {view.begin() + 2};            // │
    //              ┌────────────────────┬────────────────┘
    //              │                 ┌──┴──┐
    static_assert(*iter == std::tuple{2, 3, 4});
}
