std::ranges::adjacent_view<V,N>::iterator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< bool Const >
class /*iterator*/  // (depuis C++23) ( exposition uniquement* )

Le type de retour de adjacent_view::begin, et de adjacent_view::end lorsque la vue sous-jacente V est une common_range.

Le type /*iterator*/<true> est renvoyé par les surcharges qualifiées const. Le type /*iterator*/<false> est renvoyé par les surcharges non qualifiées const.

Types membres

Type membre Définition

  • Base (privé) — const V si Const est true, sinon V. (type membre exposé uniquement)*
  • iterator_category — std::input_iterator_tag
  • iterator_concept —
    • std::random_access_iterator_tag, si Base modélise random_access_range. Sinon,
    • std::bidirectional_iterator_tag, si Base modélise bidirectional_range. Sinon,
    • std::forward_iterator_tag.
  • value_type — std::tuple</*REPEAT*/(ranges::range_value_t<Base>, N)...>;
  • difference_type — ranges::range_difference_t<Base>

Membres de données

Objet membre Définition

  • current_ (privé) — std::array<ranges::iterator_t<Base>, N>. (objet membre exposé uniquement)*

Fonctions membres

  • (constructeur) — construit un itérateur (fonction membre publique)
  • operator* — accède à l'élément (fonction membre publique)
  • operator[] — accède à un élément par son indice (fonction membre publique)
  • operator++operator++(int)operator--operator--(int)operator+=operator-= — fait avancer ou reculer les itérateurs sous-jacents (fonction membre publique)

Fonctions non membres

  • operator==operator<operator>operator<=operator>=operator<=> (C++23) — compare les itérateurs sous-jacents (fonction)
  • operator+operator- (C++23) — effectue l'arithmétique des itérateurs (fonction)
  • iter_move (C++23) — convertit le résultat du déréférencement de l'itérateur sous-jacent en son type de référence rvalue associé (fonction)
  • iter_swap (C++23) — échange les objets pointés par deux itérateurs sous-jacents (fonction)

Exemple

#include <cassert>
#include <concepts>
#include <list>
#include <ranges>
#include <tuple>
#include <utility>
#include <vector>

int main()
{
    auto v = std::vector{0, 1, 2, 3, 4, 5};
    auto i = (v | std::views::adjacent<3>).begin();
    using I = decltype(i);
    static_assert(std::same_as<I::value_type, std::tuple<int, int, int>>);
    static_assert(std::same_as<I::iterator_concept, std::random_access_iterator_tag>);
    // certains des opérateurs disponibles :
    ++i; i++; --i; i--; i += 2; i -= 2;
    assert(i[2] == std::tuple(2, 3, 4));
    using DI = decltype(*i);
    static_assert(std::same_as<DI, std::tuple<int&, int&, int&>>);
    std::get<1>(*i) = 42; // modifie v[1] via l'itérateur i
    assert(v[1] == 42);

    auto l = std::list{0, 1, 2, 3, 4, 5};
    auto j = (l | std::views::adjacent<3>).begin();
    using J = decltype(j);
    static_assert(std::same_as<J::value_type, std::tuple<int, int, int>>);
    static_assert(std::same_as<J::iterator_concept, std::bidirectional_iterator_tag>);
    ++j; --j; j++; j--; // certains des opérateurs disponibles
    // j += 2; j -= 2;       // erreur : ces opérateurs ne sont pas disponibles
    // std::ignore() = j[1]; //        pour un itérateur bidirectionnel
}
