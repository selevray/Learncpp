operator==(ranges::adjacent_view::iterator, ranges::adjacent_view::sentinel)

template< bool OtherConst >
    requires std::sentinel_for<ranges::sentinel_t<Base>,
                               ranges::iterator_t</*maybe-const*/<OtherConst, V>>>
friend constexpr bool operator==( const /*iterator*/<OtherConst>& x,
                                  const /*sentinel*/& y );  // (depuis C++23)

Compare l'itérateur sous-jacent de x avec la sentinelle sous-jacente de y.

Équivalent à : return x.current_.back() == y.end_, où current_ est le tableau sous-jacent d'itérateurs dans x, et end_ est la sentinelle sous-jacente dans y.

Cette fonction n'est pas visible par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peut être trouvée que par la recherche dépendante des arguments lorsque adjacent_view::sentinel<Const> est une classe associée aux arguments.

L'opérateur != est synthétisé à partir de operator==.

Paramètres

  • x — itérateur à comparer
  • y — sentinelle à comparer

Valeur de retour

true si l'itérateur sous-jacent stocké dans x est l'itérateur de fin.
