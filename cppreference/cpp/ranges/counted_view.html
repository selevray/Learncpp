std::ranges::views::counted

Défini dans l'en-tête <ranges>

inline constexpr /*unspecified*/ counted = /*unspecified*/;  // (depuis C++20)

Signature d'appel

template< class Iterator, class DifferenceType >
    requires /* voir ci-dessous */
constexpr /*span-or-subrange*/ counted( Iterator&& it, DifferenceType&& count );  // (depuis C++20)

Une vue counted présente un view des éléments de l'intervalle counted [i,n) pour un certain itérateur i et un entier non négatif n.

Un intervalle counted [i,n) est constitué des n éléments commençant par l'élément pointé par i et s'arrêtant avant l'élément, s'il existe, pointé par le résultat de n applications de ++i.

Si n == 0, l'intervalle counted est valide et vide. Sinon, l'intervalle counted n'est valide que si n est positif, i est déréférençable, et [++i,--n) est un intervalle counted valide.

Formellement, si it et count sont des expressions, T est std::decay_t<decltype((it))>, et D est std::iter_difference_t<T>, alors

si T modélise input_or_output_iterator et decltype((count)) modélise std::convertible_to<D>,

  • si T modélise contiguous_iterator, alors views::counted(it, count) est expression-équivalente à std::span(std::to_address(it), static_cast<std::size_t>(static_cast<D>(count))),
  • sinon, si T modélise random_access_iterator, alors views::counted(it, count) est expression-équivalente à ranges::subrange(it, it + static_cast<D>(count)),
  • sinon, views::counted(it, count) est expression-équivalente à ranges::subrange(std::counted_iterator(it, count), std::default_sentinel). Sinon, views::counted(it, count) est mal formé.

Objets de point de personnalisation

Le nom views::counted désigne un objet de point de personnalisation, qui est un objet fonction const d'un type de classe littéral semiregular. À des fins d'exposition, la version sans qualificateurs cv de son type est désignée par __counted_fn.

Toutes les instances de __counted_fn sont égales. Les effets de l'invocation de différentes instances du type __counted_fn sur les mêmes arguments sont équivalents, qu'il s'agisse ou non d'une lvalue ou d'une rvalue, et que l'expression désignant l'instance soit qualifiée const ou non (toutefois, une instance qualifiée volatile n'est pas tenue d'être invocable). Ainsi, views::counted peut être copié librement et ses copies peuvent être utilisées de manière interchangeable.

Étant donné un ensemble de types Args..., si std::declval<Args>()... satisfont aux exigences relatives aux arguments de views::counted ci-dessus, alors __counted_fn modélise

  • std::invocable<__counted_fn, Args...>,
  • std::invocable<const __counted_fn, Args...>,
  • std::invocable<__counted_fn&, Args...>, and
  • std::invocable<const __counted_fn&, Args...>.

Sinon, aucun opérateur d'appel de fonction de __counted_fn ne participe à la résolution de surcharge.

Notes

views::counted ne vérifie pas si l'intervalle est assez long pour fournir les count éléments : utilisez views::take si cette vérification est nécessaire.

Exemple

#include <iostream>
#include <ranges>

int main()
{
    const int a[]{1, 2, 3, 4, 5, 6, 7};
    for (int i : std::views::counted(a, 3))
        std::cout << i << ' ';
    std::cout << '\n';

    const auto il = {1, 2, 3, 4, 5};
    for (int i : std::views::counted(il.begin() + 1, 3))
        std::cout << i << ' ';
    std::cout << '\n';
}

Output:

1 2 3
2 3 4
