std::ranges::take_view<V>::end

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr auto end() requires (!/*simple-view*/<V>);  // (1) (depuis C++20)

constexpr auto end() const requires ranges::range<const V>;  // (2) (depuis C++20)

Renvoie une sentinelle ou un itérateur représentant la fin de la take_view. La fin de la take_view est soit celle qui suit immédiatement le counte élément de l'intervalle sous-jacent, soit la fin de l'intervalle sous-jacent si celui-ci contient moins de count éléments.

  1. Renvoie un take_view::/*sentinel*/<false>, un std::default_sentinel_t ou un ranges::iterator_t<V>.

  2. Renvoie un take_view::/*sentinel*/<true>, un std::default_sentinel_t ou un ranges::iterator_t<const V>.

La surcharge (1) ne participe pas à la résolution de surcharge si V est une vue simple (c'est-à-dire si V et const V sont des vues ayant les mêmes types d'itérateur et de sentinelle).

Paramètres

(aucune)

Valeur de retour

Le résultat dépend des concepts satisfaits par le type de vue sous-jacent Base, éventuellement qualifié const, à savoir V pour (1) ou const V pour (2).

Soit base_ la vue sous-jacente.

Le type de vue sous-jacent
satisfait ... | random_access_range

yes | no

sized_range | yes | ranges::begin(base_) + ranges::range_difference_t<Base_>(this->size()) | std::default_sentinel

no |

  1. /*sentinel*/<false>{ranges::end(base_)}

  2. /*sentinel*/<true>{ranges::end(base_)}

Exemple

#include <iostream>
#include <iterator>
#include <list>
#include <ranges>
#include <type_traits>
namespace ranges = std::ranges;
namespace views = std::views;

int main()
{
    const auto list1 = {3, 1, 4, 1, 5};
    const auto seq1{list1 | views::take(4)};
    static_assert(ranges::sized_range<decltype(seq1)> and
                  ranges::random_access_range<decltype(seq1)> and
                  std::is_same_v<decltype(seq1.end()), decltype(list1.end())>);
    for (auto it = seq1.begin(); it != seq1.end(); ++it)
        std::cout << *it << ' ';
    std::cout << '\n';

    std::list list2{2, 7, 1, 8, 2};
    const auto seq2{list2 | views::take(4)};
    static_assert(ranges::sized_range<decltype(seq2)> and
                  not ranges::random_access_range<decltype(seq2)> and
                  std::is_same_v<decltype(seq2.end()), std::default_sentinel_t>);
    for (auto it = seq2.begin(); it != std::default_sentinel; ++it)
        std::cout << *it << ' ';
    std::cout << '\n';
}

Output:

3 1 4 1
2 7 1 8
