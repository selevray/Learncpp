  1. Permet d'obtenir le type référence du type itérateur du type intervalle R.

  2. Permet d'obtenir le type référence constante du type itérateur du type intervalle R.

  3. Permet d'obtenir le type référence rvalue du type itérateur du type intervalle R.

  4. Permet d'obtenir le type référence commune du type itérateur du type intervalle R.
