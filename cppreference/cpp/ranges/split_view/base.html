std::ranges::split_view<V,Pattern>::base

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr V base() const& requires std::copy_constructible<V>;  // (1) (depuis C++20)

constexpr V base() &&;  // (2) (depuis C++20)

Renvoie une copie de la vue sous-jacente base_.

  1. Construit par copie le résultat à partir de la vue sous-jacente.

  2. Construit par déplacement le résultat à partir de la vue sous-jacente.

Valeur de retour

  1. Une copie de la vue sous-jacente.

  2. Une vue construite par déplacement à partir de la vue sous-jacente.

Exemple

#include <iomanip>
#include <iostream>
#include <ranges>
#include <string_view>

int main()
{
    constexpr std::string_view keywords{"this throw true try typedef typeid"};
    std::ranges::split_view split_view{keywords, ' '};
    std::cout << "base() = " << std::quoted(split_view.base()) << "\n"
                 "substrings: ";
    for (auto split : split_view)
        std::cout << std::quoted(std::string_view{split}) << ' ';
    std::cout << '\n';
}

Output:

base() = "this throw true try typedef typeid"
substrings: "this" "throw" "true" "try" "typedef" "typeid"
