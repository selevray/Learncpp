std::ranges::split_view<V,Pattern>::begin

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr /*iterator*/ begin();  // (depuis C++20)

Renvoie un itérateur vers le premier sous-intervalle trouvé.

Afin de fournir la complexité constante amortie requise par le concept range, cette fonction met en cache le résultat dans le split_view (au moyen du membre cached_begin_) pour être utilisé lors des appels suivants.

Soit base_ le membre de données sous-jacent. Équivalent à :

constexpr /*iterator*/ begin()
{
    if (!cached_begin_.has_value())
        cached_begin_ = this->find_next(ranges::begin(base_));
    return {*this, ranges::begin(base_), cached_begin_.value()};
}

Valeur de retour

Un itérateur.

Complexité

Complexité (\scriptsize \mathcal{O}(1)) amortieO(1).

Exemple

#include <iomanip>
#include <iostream>
#include <ranges>
#include <string_view>

int main()
{
    constexpr std::string_view sentence{"Keep..moving..forward.."};
    constexpr std::string_view delim{".."};
    std::ranges::split_view words{sentence, delim};

    std::cout << "begin(): " << std::quoted(std::string_view{*words.begin()})
              << "\nSubstrings: ";
    for (auto word : words)
        std::cout << std::quoted(std::string_view(word)) << ' ';

    std::ranges::split_view letters{sentence, std::string_view{""}};
    std::cout << "\nbegin(): " << std::quoted(std::string_view{*letters.begin()})
              << "\nLetters: ";
    for (auto letter : letters)
        std::cout << std::string_view(letter) << ' ';
    std::cout << '\n';
}

Output:

begin(): "Keep"
Substrings: "Keep" "moving" "forward" ""
begin(): "K"
Letters: K e e p . . m o v i n g . . f o r w a r d . .
