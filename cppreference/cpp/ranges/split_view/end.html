std::ranges::split_view<V,Pattern>::end

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr auto end() const;  // (depuis C++20)

Renvoie un itérateur ou un sentinelle représentant la fin du sous-intervalle résultant. Équivalent à :

constexpr auto end() { if constexpr (ranges::common_range<V>) return iterator{*this, ranges::end(base_), {}}; else return sentinel{*this}; }

Valeur de retour

Un itérateur ou une sentinelle.

Exemple

#include <cassert>
#include <ranges>
#include <string_view>

int main()
{
    constexpr std::string_view keywords{"bitand bitor bool break"};
    std::ranges::split_view kw{keywords, ' '};
    assert(4 == std::ranges::distance(kw.begin(), kw.end()));
}
