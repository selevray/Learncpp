Recherche la prochaine occurrence du motif dans la vue sous-jacente. Équivalent à :

auto [b, e] = ranges::search(ranges::subrange(it, ranges::end(base_)), pattern_); if (b != ranges::end(base_) and ranges::empty(pattern_)) { ++b; ++e; } return {b, e};

Paramètres

  • it — un itérateur vers la position à partir de laquelle commencer la recherche

Valeur de retour

Un sous-intervalle représentant la prochaine position du motif, s'il a été trouvé. Un sous-intervalle vide sinon.
