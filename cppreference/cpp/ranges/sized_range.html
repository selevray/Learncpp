std::ranges::sized_range, std::ranges::disable_sized_range

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ranges>

template< class T >
concept sized_range = ranges::range<T> &&
    requires(T& t) {
        ranges::size(t);
    };  // (1) (depuis C++20)

template< class >
constexpr bool disable_sized_range = false;  // (2) (depuis C++20)

  1. Le concept sized_range spécifie les exigences d'un type range qui connaît sa taille en temps constant grâce à la fonction size.

  2. Le disable_sized_range existe pour permettre l'utilisation de types d'intervalles qui fournissent une fonction size (membre ou non membre) mais ne modélisent pas en fait sized_range. Les utilisateurs peuvent spécialiser disable_sized_range pour des types définis par le programme sans qualificatif cv. Ces spécialisations doivent pouvoir être utilisées dans des expressions constantes et avoir le type const bool.

Exigences sémantiques

  1. Étant donné une lvalue t de type std::remove_reference_t<T>, T ne modélise sized_range que si

  • ranges::size(t)

    • a une complexité amortie constante en temps,
    • ne modifie pas la valeur de t d'une manière observable par des expressions préservant l'égalité, et
    • est égal à ranges::distance(ranges::begin(t), ranges::end(t)), et

  • si ranges::iterator_t<T> modélise forward_iterator, ranges::size(t) est bien défini indépendamment de l'évaluation de ranges::begin(t) (autrement dit, un intervalle dimensionné à passage unique peut n'accepter un appel à size qu'avant le premier appel à begin, mais un intervalle de type forward doit supporter size à tout moment).

Notes

disable_sized_range ne peut pas être utilisé pour exclure un intervalle dont l'itérateur et la sentinelle satisfont sized_sentinel_for ; std::disable_sized_sentinel_for doit être utilisé à la place.

disable_sized_range ne peut pas être spécialisé pour les types tableau ou les types référence.

Exemple

#include <forward_list>
#include <list>
#include <ranges>

static_assert
(
    std::ranges::sized_range<std::list<int>> and
    not std::ranges::sized_range<std::forward_list<int>>
);

int main() {}
