Signature d'appel

template< class T >
    requires /* voir ci-dessous */
constexpr bool empty( T&& t );  // (depuis C++20)

Détermine si t possède ou non des éléments.

Un appel à ranges::empty est expression-équivalente à :

  1. bool(t.empty()), si cette expression est valide.
  2. Sinon, (ranges::size(t) == 0), si cette expression est valide.
  3. Sinon, bool(ranges::begin(t) == ranges::end(t)), si cette expression est valide et que decltype(ranges::begin(t)) modélise std::forward_iterator.

Dans tous les autres cas, un appel à ranges::empty est mal formé, ce qui peut entraîner un échec de substitution lorsque ranges::empty(t) apparaît dans le contexte immédiat d'une instanciation de modèle.

Objets de point de personnalisation

Le nom ranges::empty désigne un objet de point de personnalisation, qui est un objet fonction const d'un type de classe littéral semiregular. À des fins d'exposition, la version sans qualificateurs cv de son type est désignée par __empty_fn.

Toutes les instances de __empty_fn sont égales. Les effets de l'invocation de différentes instances du type __empty_fn sur les mêmes arguments sont équivalents, qu'il s'agisse ou non d'une lvalue ou d'une rvalue, et que l'expression désignant l'instance soit qualifiée const ou non (toutefois, une instance qualifiée volatile n'est pas tenue d'être invocable). Ainsi, ranges::empty peut être copié librement et ses copies peuvent être utilisées de manière interchangeable.

Étant donné un ensemble de types Args..., si std::declval<Args>()... satisfont aux exigences relatives aux arguments de ranges::empty ci-dessus, alors __empty_fn modélise

  • std::invocable<__empty_fn, Args...>,
  • std::invocable<const __empty_fn, Args...>,
  • std::invocable<__empty_fn&, Args...>, and
  • std::invocable<const __empty_fn&, Args...>.

Sinon, aucun opérateur d'appel de fonction de __empty_fn ne participe à la résolution de surcharge.

Exemple

#include <iostream>
#include <ranges>
#include <vector>

template<std::ranges::input_range R>
void print(char id, R&& r)
{
    if (std::ranges::empty(r))
    {
        std::cout << '\t' << id << ") Empty\n";
        return;
    }

    std::cout << '\t' << id << ") Elements:";
    for (const auto& element : r)
        std::cout << ' ' << element;
    std::cout << '\n';
}

int main()
{
    {
        auto v = std::vector<int>{1, 2, 3};
        std::cout << "(1) ranges::empty uses std::vector::empty:\n";
        print('a', v);

        v.clear();
        print('b', v);
    }
    {
        std::cout << "(2) ranges::empty uses ranges::size(initializer_list):\n";
        auto il = {7, 8, 9};
        print('a', il);

        print('b', std::initializer_list<int>{});
    }
    {
        std::cout << "(2) ranges::empty on a raw array uses ranges::size:\n";
        int array[] = {4, 5, 6}; // le tableau a une borne connue
        print('a', array);
    }
    {
        struct Scanty : private std::vector<int>
        {
            using std::vector<int>::begin;
            using std::vector<int>::end;
            using std::vector<int>::push_back;
            // Remarque : empty() et size() sont toutes deux masquées
        };

        std::cout << "(3) calling ranges::empty on an object w/o empty() or size():\n";
        Scanty y;
        print('a', y);
        y.push_back(42);
        print('b', y);
    }
}

Output:

(1) ranges::empty uses std::vector::empty:
        a) Elements: 1 2 3
        b) Empty
(2) ranges::empty uses ranges::size(initializer_list):
        a) Elements: 7 8 9
        b) Empty
(2) ranges::empty on a raw array uses ranges::size:
        a) Elements: 4 5 6
(3) calling ranges::empty on an object w/o empty() or size():
        a) Empty
        b) Elements: 42
