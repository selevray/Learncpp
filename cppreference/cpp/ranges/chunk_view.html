chunk_view prend un view et un nombre n et produit un intervalle de vues (les fragments) de la vue d'origine, de sorte que chaque fragment, sauf éventuellement le dernier, ait la taille n. Ces fragments sont des sous-intervalles successifs et non chevauchants des éléments de la vue d'origine, dans l'ordre.

Soit s la taille de la vue d'origine. Si s n'est pas un multiple de n, la taille de la dernière vue produite est exactement s % n (le reste). Sinon, la taille de chaque fragment, y compris le dernier, est n.

La taille de la vue produite est /*div-ceil*/(s).

Si n n'est pas strictement supérieur à 0, le comportement est indéfini.

  1. Une implémentation qui prend en charge la vue sous-jacente V qui modélise uniquement input_range.

  2. Une spécialisation partielle qui prend en charge la vue sous-jacente V qui modélise forward_range ou plus fort. Modélise common_range si la vue sous-jacente V est forward_range, common_range, et soit sized_range, soit non bidirectional_range.

  3. Le nom views::chunk désigne un RangeAdaptorObject. Étant donné les sous-expressions e et n, l'expression views::chunk(e, n) est équivalente en expression à chunk_view(e, n).

  4. Calcule la plus petite valeur entière non inférieure au quotient de la division de num par denom. Équivalent à :

I r = num / denom;
if (num % denom)
    ++r;
return r;

Cette spécialisation de ranges::enable_borrowed_range fait satisfaire à chunk_view borrowed_range lorsque la vue sous-jacente V satisfait à la fois forward_range et borrowed_range.

Notes

Si V modélise input_range (1), l'itérateur de chunk_view possède un type dédié : outer_iterator::value_type, qui est lui-même une vue d'entrée.

Si V modélise forward_range ou un concept plus fort (2), chunk_view délègue à views::take pour son value_type.

Si V modélise bidirectional_range ou un concept plus fort (2), la nécessité de calculer correctement la taille du dernier morceau (à partir de l'itérateur de fin) impose que le type d'intervalle sous-jacent V soit sized_range.

Exemple

#include <algorithm>
#include <iostream>
#include <ranges>

auto print_subrange = [](std::ranges::viewable_range auto&& r)
{
    std::cout << '[';
    for (int pos{}; auto elem : r)
        std::cout << (pos++ ? " " : "") << elem;
    std::cout << "] ";
};

int main()
{
    const auto v = {1, 2, 3, 4, 5, 6};

    for (const unsigned width : std::views::iota(1U, 2U + v.size()))
    {
        auto const chunks = v | std::views::chunk(width);
        std::cout << "chunk(" << width << "): ";
        std::ranges::for_each(chunks, print_subrange);
        std::cout << '\n';
    }
}

Output:

chunk(2): [1 2] [3 4] [5 6]
chunk(3): [1 2 3] [4 5 6]
chunk(4): [1 2 3 4] [5 6]
chunk(5): [1 2 3 4 5] [6]
chunk(6): [1 2 3 4 5 6]
chunk(7): [1 2 3 4 5 6]
