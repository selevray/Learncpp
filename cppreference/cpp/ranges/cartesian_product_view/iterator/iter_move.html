Soit current_ le tuple d'itérateurs sous-jacent.

Équivalent à : return /*tuple-transform*/(ranges::iter_move, i.current_);

Cette fonction n'est pas visible par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peut être trouvée que par la recherche dépendante des arguments lorsque cartesian_product_view::iterator<Const> est une classe associée aux arguments.

Paramètres

  • i — iterator

Valeur de retour

Un tuple contenant le résultat de l'application de ranges::iter_move aux itérateurs sous-jacents stockés, convertis dans le type de retour, comme décrit ci-dessus.

Exceptions

La spécification d'exception est équivalente au ET logique des expressions suivantes :

  • noexcept(ranges::iter_move(std::get<N>(i.current_))) pour chaque entier 0 ≤ N ≤ sizeof...(Vs),
  • std::is_nothrow_move_constructible_v<ranges::range_rvalue_reference_t</*maybe-const*/<Const, T>>> pour chaque type T dans First, Vs....
