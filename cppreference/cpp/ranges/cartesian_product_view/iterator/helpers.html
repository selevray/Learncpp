std::ranges::cartesian_product_view::iterator::distance_from

template< class Tuple >
constexpr difference_type
    /*distance-from*/( const Tuple& t ) const;  // (depuis C++23) ( exposition uniquement* )

Renvoie la « distance » (c'est-à-dire le nombre de « sauts ») entre deux itérateurs.

Let:

  • Soit parent_ le pointeur sous-jacent vers cartesian_product_view
  • /*scaled-size*/(N) be:
    • le produit de static_cast<difference_type>(ranges::size(std::get<N>(parent_->bases_))) et /*scaled-size*/(N + 1) si N ≤ sizeof...(Vs), sinon
    • static_cast<difference_type>(1);
  • /*scaled-distance*/(N) soit le produit de static_cast<difference_type>(std::get<N>(current_) - std::get<N>(t)) et /*scaled-size*/(N + 1);
  • /*scaled-sum*/ soit la somme des /*scaled-distance*/(N) pour chaque entier 0 ≤ N ≤ sizeof...(Vs).

Returns: /*scaled-sum*/.

Le comportement est indéfini si /*scaled-sum*/ ne peut pas être représenté par difference_type.
