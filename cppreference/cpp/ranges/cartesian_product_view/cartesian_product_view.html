std::ranges::cartesian_product_view<First, Vs...>::cartesian_product_view

constexpr cartesian_product_view() = default;  // (1) (depuis C++23)

constexpr explicit cartesian_product_view( First first_base, Vs... bases );  // (2) (depuis C++23)

Construit un cartesian_product_view.

  1. Constructeur par défaut. Initialise par défaut le membre de données sous-jacent base_.

  2. Construit par déplacement le base_ sous-jacent en l'initialisant avec std::move(first_base), std::move(bases)....

Paramètres

  • first_base — la première vue objet à adapter
  • bases — le paquet d'objets vues à adapter

Exemple

#include <array>
#include <format>
#include <iostream>
#include <ranges>
#include <vector>

int main()
{
    auto x = std::array{'A', 'B'};
    auto y = std::vector{1, 2, 3};
    auto z = std::vector{-1, -2, -3};

    auto v = std::ranges::cartesian_product_view(x, y, z); // overload (2)

    for (int i{1}; auto const& [rx, ry, rz] : v)
        std::cout << std::format("({} {} {}){}", rx, ry, rz, (i++ % 3) ? ' ' : '\n');
}

Output:

(A 1 -1) (A 1 -2) (A 1 -3)
(A 2 -1) (A 2 -2) (A 2 -3)
(A 3 -1) (A 3 -2) (A 3 -3)
(B 1 -1) (B 1 -2) (B 1 -3)
(B 2 -1) (B 2 -2) (B 2 -3)
(B 3 -1) (B 3 -2) (B 3 -3)
