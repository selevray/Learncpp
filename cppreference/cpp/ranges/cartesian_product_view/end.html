Renvoie un itérateur ou une sentinelle représentant la fin de la cartesian_product_view.

Soit bases_ le tuple de vues sous-jacent.

1,2) Équivalent à

auto check = [](auto& rng) { return __begin_or_first_end(rng); };return iterator<__is_const>(/*tuple-transform*/(check, bases_));,

where:

  • __is_const est true pour la surcharge qualifiée const, et false sinon.
  • __is_empty est true si l'expression ranges::empty(rng) est true pour tout rng parmi les intervalles sous-jacents, sauf le premier, et false sinon.
  • __begin_or_first_end(rng) est équivalent à l'expression __is_empty ? ranges::begin(rng) : /*cartesian-common-arg-end*/(rng) si rng est le premier intervalle sous-jacent, et ranges::begin(rng) sinon.
  1. Équivalent à : return std::default_sentinel;.

Paramètres

(aucune)

Valeur de retour

Un itérateur vers l'élément suivant le dernier élément, ou une sentinelle qui se compare égale à l'itérateur de fin.

Exemple

#include <array>
#include <format>
#include <iostream>
#include <ranges>
#include <string_view>
#include <tuple>
using namespace std::literals;

int main()
{
    constexpr auto a = std::array{ "bool"sv, "goto"sv, "extern"sv, "long"sv }; /*
                                       ^         ^           ^         ^        */
    constexpr auto v = std::ranges::cartesian_product_view(a[0], a[1], a[2], a[3]);

    constexpr std::tuple<char const&,
                         char const&,
                         char const&,
                         char const&> last{*(v.end() - 1)};

    std::cout << std::format("{}{}{}{}{}",
                             std::get<0>(last),
                             std::get<1>(last),
                             std::get<2>(last),
                             std::get<3>(last), '\n');
}

Output:

long
