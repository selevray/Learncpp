std::ranges::cartesian_product_view<First, Vs...>::begin

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr iterator<false> begin()
    requires (!/*simple-view*/<First> || ... || !/*simple-view*/<Vs>);  // (1) (depuis C++23)

constexpr iterator<true> begin() const
    requires (ranges::range<const First> && ... && ranges::range<const Vs>);  // (2) (depuis C++23)

Renvoie un itérateur vers le premier élément du cartesian_product_view.

Soit bases_ le tuple des vues sous-jacentes.

  1. Équivalent à return /*iterator*/<false>(tuple-transform(ranges::begin, bases_));.

  2. Équivalent à return /*iterator*/<true>(tuple-transform(ranges::begin, bases_));.

Paramètres

(aucune)

Valeur de retour

Un itérateur vers le premier élément.

Exemple

#include <array>
#include <format>
#include <iostream>
#include <ranges>
#include <string_view>
#include <tuple>
using namespace std::literals;

int main()
{
    constexpr auto a = std::array{"Curiously"sv, "Recurring"sv, "Template"sv, "Pattern"sv};

    constexpr auto v = std::ranges::cartesian_product_view(a[0], a[1], a[2], a[3]);

    constexpr std::tuple<char const&,
                         char const&,
                         char const&,
                         char const&> first{*v.begin()};

    std::cout << std::format("{}{}{}{}{}",
                             std::get<0>(first),
                             std::get<1>(first),
                             std::get<2>(first),
                             std::get<3>(first),
                             '\n');
}
