Calcule le nombre d'éléments de t en temps constant, et convertit le résultat en type signé.

Étant donné la sous-expression dont t désigne l'objet résultat (éventuellement matérialisé) noté E :

  • Si ranges::size(t) est mal formé, ranges::ssize(E) l'est aussi.
  • Sinon, soit Signed égal à make-signed-like-t ﻿<decltype(ranges::size(t))> :
    • Si std::ptrdiff_t est plus large que Signed, ranges::ssize(E) est équivalent en expression à static_cast<std::ptrdiff_t>(ranges::size(t)).
    • Sinon, ranges::ssize(E) est équivalent en expression à static_cast<Signed>(ranges::size(t)).

Objets de point de personnalisation

Le nom ranges::ssize désigne un objet de point de personnalisation, qui est un objet fonction const d'un type de classe littéral semiregular. À des fins d'exposition, la version sans qualificateurs cv de son type est désignée par __ssize_fn.

Toutes les instances de __ssize_fn sont égales. Les effets de l'invocation de différentes instances du type __ssize_fn sur les mêmes arguments sont équivalents, qu'il s'agisse ou non d'une lvalue ou d'une rvalue, et que l'expression désignant l'instance soit qualifiée const ou non (toutefois, une instance qualifiée volatile n'est pas tenue d'être invocable). Ainsi, ranges::ssize peut être copié librement et ses copies peuvent être utilisées de manière interchangeable.

Étant donné un ensemble de types Args..., si std::declval<Args>()... satisfont aux exigences relatives aux arguments de ranges::ssize ci-dessus, alors __ssize_fn modélise

  • std::invocable<__ssize_fn, Args...>,
  • std::invocable<const __ssize_fn, Args...>,
  • std::invocable<__ssize_fn&, Args...>, and
  • std::invocable<const __ssize_fn&, Args...>.

Sinon, aucun opérateur d'appel de fonction de __ssize_fn ne participe à la résolution de surcharge.

Notes

Si ranges::ssize(e) est valide pour une expression e, le type de retour est un type semblable à un entier signé.

Exemple

#include <array>
#include <iostream>
#include <ranges>
#include <type_traits>

int main()
{
    std::array arr{1, 2, 3, 4, 5};
    auto s = std::ranges::ssize(arr);

    std::cout << "ranges::ssize(arr) = " << s << '\n'
              << "ranges::ssize is "
              << (std::is_signed_v<decltype(s)> ? "signed" : "unsigned")
              << '\n';

    std::cout << "reversed arr: ";

    for (--s; s >= 0; --s)
        std::cout << arr[s] << ' ';

    std::cout << "\n" "s = " << s << '\n';
}

Output:

ranges::ssize(arr) = 5
ranges::ssize is signed
reversed arr: 5 4 3 2 1
s = -1
