enum class subrange_kind : bool {
    unsized,
    sized
};  // (depuis C++20)

Indique si un std::ranges::subrange modélise std::ranges::sized_range ou non.

Constantes

Nom Explication

  • unsized — indique que le subrange ne modélise pas sized_range
  • sized — indique que le subrange modélise sized_range
