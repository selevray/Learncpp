Objet de point de personnalisation (depuis C++20)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Explication

Le nom cpo désigne un objet de point de personnalisation, qui est un objet fonction const d'un type de classe littéral semiregular. À des fins d'exposition, la version sans qualificateurs cv de son type est désignée par __cpo_fn.

Toutes les instances de __cpo_fn sont égales. Les effets de l'invocation de différentes instances du type __cpo_fn sur les mêmes arguments sont équivalents, qu'il s'agisse ou non d'une lvalue ou d'une rvalue, et que l'expression désignant l'instance soit qualifiée const ou non (toutefois, une instance qualifiée volatile n'est pas tenue d'être invocable). Ainsi, cpo peut être copié librement et ses copies peuvent être utilisées de manière interchangeable.

Étant donné un ensemble de types Args..., si std::declval<Args>()... satisfont aux exigences relatives aux arguments de cpo ci-dessus, alors __cpo_fn modélise

  • std::invocable<__cpo_fn, Args...>,
  • std::invocable<const __cpo_fn, Args...>,
  • std::invocable<__cpo_fn&, Args...>, and
  • std::invocable<const __cpo_fn&, Args...>.

Sinon, aucun opérateur d'appel de fonction de __cpo_fn ne participe à la résolution de surcharge.
