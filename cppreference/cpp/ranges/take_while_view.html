  1. Un adaptateur d'intervalle qui représente view des éléments d'une séquence sous-jacente, en commençant au début et en se terminant au premier élément pour lequel le prédicat renvoie false.

  2. RangeAdaptorObject. L'expression views::take_while(e, f) est équivalente à une expression à take_while_view(e, f) pour toutes sous-expressions appropriées e et f.

take_while_view modélise les concepts contiguous_range, random_access_range, bidirectional_range, forward_range et input_range lorsque la vue sous-jacente V modélise les concepts correspondants.

Exemple

#include <iostream>
#include <ranges>

int main()
{
    for (int year : std::views::iota(2020)
                  | std::views::take_while([](int y){ return y < 2026; }))
        std::cout << year << ' ';
    std::cout << '\n';

    const char note[]{"Today is yesterday's tomorrow!..."};
    auto not_dot = [](char c){ return c != '.'; };
    for (char x : std::ranges::take_while_view(note, not_dot))
        std::cout << x;
    std::cout << '\n';
}

Output:

2020 2021 2022 2023 2024 2025
Today is yesterday's tomorrow!
