constexpr auto begin() const
    requires ranges::forward_range<V> && ranges::forward_range<const V>;  // (2) (depuis C++20)

Renvoie un outer_iterator vers le premier élément du lazy_split_view.

Soit base_ la vue sous-jacente et current_ l'objet de mise en cache sous-jacent (peut être absent).

  1. Équivalent à
constexpr auto begin()
{
    if constexpr (ranges::forward_range<V>)
        return /*outer_iterator*/</*simple_view*/<V>>{*this, ranges::begin(base_)};
    else
    {
        current_ = ranges::begin(base_);
        return /*outer_iterator*/<false>{*this};
    }
}
  1. Équivalent à return /*outer_iterator*/<true>{*this, ranges::begin(base_)};.

Valeur de retour

outer_iterator vers le premier élément.
