std::ranges::lazy_split_view<V,Pattern>::end

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr auto end() requires ranges::forward_range<V> && ranges::common_range<V>;  // (1) (depuis C++20)

constexpr auto end() const;  // (2) (depuis C++20)

Renvoie un itérateur ou parfois une sentinelle représentant la fin du view. Soit base_ la vue sous-jacente.

  1. Renvoie un itérateur. Équivalent à : return /*outer_iterator*/</*simple_view*/<V>>{*this, ranges::end(base_)};.

  2. Renvoie un outer_iterator ou un std::default_sentinel.

Équivalent à :

if constexpr (ranges::forward_range<V> && ranges::forward_range<const V> &&
              ranges::common_range<const V>)
    return /*outer_iterator*/<true>{*this, ranges::end(base_)};
else
    return std::default_sentinel;

Valeur de retour

Un outer_iterator ou un std::default_sentinel représentant la fin du view.

Exemple

#include <iostream>
#include <ranges>
#include <string_view>

int main()
{
    constexpr std::string_view keywords{"false float for friend"};
    std::ranges::lazy_split_view kw{keywords, ' '};
    const auto count = std::ranges::distance(kw.begin(), kw.end());
    std::cout << "Words count: " << count << '\n';
}

Output:

Words count: 4
