std::ranges::lazy_split_view<V,Pattern>::base

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr V base() const& requires std::copy_constructible<V>;  // (1) (depuis C++20)

constexpr V base() &&;  // (2) (depuis C++20)

Renvoie une copie de la vue sous-jacente base_.

  1. Construit par copie le résultat à partir de la vue sous-jacente base_.

  2. Construit par déplacement le résultat à partir de la vue sous-jacente base_.

Valeur de retour

Une copie de la vue sous-jacente base_.

Exemple

#include <iostream>
#include <ranges>
#include <string_view>

void print(std::string_view rem, auto const& r, std::string_view post = "\n")
{
    for (std::cout << rem; auto const& e : r)
        std::cout << e;
    std::cout << post;
}

int main()
{
    constexpr std::string_view keywords{ "this,..throw,..true,..try,.." };
    constexpr std::string_view pattern{",.."};
    constexpr std::ranges::lazy_split_view lazy_split_view{keywords, pattern};
    print("base() = [", lazy_split_view.base(), "]\n"
          "substrings: ");
    for (auto const& split: lazy_split_view)
        print("[", split, "] ");
}

Output:

base() = [this,..throw,..true,..try,..]
substrings: [this] [throw] [true] [try] []
