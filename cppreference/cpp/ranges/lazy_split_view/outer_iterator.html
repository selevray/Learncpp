std::ranges::lazy_split_view<V, Pattern>::outer_iterator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< bool Const >
struct /*outer_iterator*/;  // (depuis C++20) ( réservé à l'exposition* )

Le type de retour de lazy_split_view::begin, et de lazy_split_view::end lorsque la vue sous-jacente est un common_range et forward_range.

Si V ou Pattern n'est pas une vue simple (par exemple si ranges::iterator_t<const V> est invalide ou différent de ranges::iterator_t<V>), Const est true pour les itérateurs renvoyés par les surcharges const, et false sinon. Si V est une vue simple, Const est true si et seulement si V est un forward_range.
