std::ranges::enumerate_view<V>::end

constexpr auto end() requires (!__simple_view<V>);  // (1) (depuis C++23)

Renvoie un itérateur ou un sentinel égal à l'itérateur de fin de enumerate_view.

Notons base_ la vue sous-jacente.

  1. Équivalent à :
if constexpr (ranges::forward_range<V> and

    return /*iterator*/<false>(ranges::end(base_), ranges::distance(base_));
else
