Le type de retour de enumerate_view::end lorsque la vue sous-jacente n'est pas une common_range.

Le type /*sentinel*/<true> est renvoyé par la surcharge qualifiée const. Le type /*sentinel*/<false> est renvoyé par la surcharge non qualifiée const.
