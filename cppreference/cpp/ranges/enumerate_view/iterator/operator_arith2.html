Effectue une arithmétique sur iterator ou calcule la distance.

pos_ est l'index sous-jacent, et Base est le type (éventuellement qualifié const) de la vue sous-jacente.

Équivalent à :

  1. auto temp = i; temp += n; return temp;

  2. return i + n;

  3. auto temp = i; temp -= n; return temp;

  4. return i.pos_ - j.pos_;

Ces fonctions ne sont pas visibles par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peuvent être trouvées que par la recherche dépendante des arguments lorsque enumerate_view::iterator<Const> est une classe associée aux arguments.

Paramètres

  • i, j — les itérateurs
  • n — position relative à la position courante

Valeur de retour

1,2) Un itérateur incrémenté.

  1. Un itérateur décrémenté.

  2. Une distance entre les itérateurs donnés.
