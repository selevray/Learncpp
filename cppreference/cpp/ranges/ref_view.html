std::ranges::ref_view

Défini dans l'en-tête <ranges>

template< ranges::range R >
    requires std::is_object_v<R>
class ref_view
    : public ranges::view_interface<ref_view<R>>  // (depuis C++20)

ref_view est une view des éléments d'un autre range. Il encapsule une référence à cet range.

Membres de données

Nom du membre Définition

  • r_ (privé) — Un pointeur de type R* vers l'intervalle sous-jacent. (objet membre à titre d'exposition)*

Fonctions membres

  • (constructeur) — construit un ref_view qui référence l'intervalle donné (fonction membre publique)
  • base — renvoie la référence vers l'intervalle référencé (fonction membre publique)
  • begin — renvoie l'itérateur de début de l'intervalle référencé (fonction membre publique)
  • end — renvoie la sentinelle de l'intervalle référencé (fonction membre publique)
  • empty — vérifie si l'intervalle référencé est vide (fonction membre publique)
  • size — renvoie la taille de l'sized_range référencé (fonction membre publique)
  • data — renvoie le pointeur vers le début de l'contiguous_range référencé (fonction membre publique)

std::ranges::ref_view::ref_view

template< /*different-from*/<ref_view> T >
    requires std::convertible_to<T, R&> && requires { _FUN(std::declval<T>()); }
constexpr ref_view( T&& t );  // (depuis C++20)

Initialise r_ avec std::addressof(static_cast<R&>(std::forward<T>(t))).

/*different-from*/<T, U> est satisfait si et seulement si std::remove_cvref_t<T> et std::remove_cvref_t<U> ne sont pas le même type, et que les surcharges de _FUN sont déclarées comme void _FUN(R&); void _FUN(R&&) = delete;.

Paramètres

  • t — intervalle vers référence

Modèles auxiliaires

template< class T >
constexpr bool enable_borrowed_range<ranges::ref_view<T>> = true;  // (depuis C++20)

Cette spécialisation de std::ranges::enable_borrowed_range fait en sorte que ref_view satisfasse borrowed_range.

Exemple

#include <iostream>
#include <ranges>

int main()
{
    const std::string s{"cosmos"};

    const std::ranges::take_view tv{s, 3};
    const std::ranges::ref_view rv{tv};

    std::cout
        << std::boolalpha
        << "call empty() : " << rv.empty() << '\n'
        << "call size()  : " << rv.size() << '\n'
        << "call begin() : " << *rv.begin() << '\n'
        << "call end()   : " << *(rv.end() - 1) << '\n'
        << "call data()  : " << rv.data() << '\n'
        << "call base()  : " << rv.base().size() << '\n' // ~> tv.size()
        << "range-for    : ";

    for (const auto c : rv)
        std::cout << c;
    std::cout << '\n';
}

Output:

call empty() : false
call size()  : 3
call begin() : c
call end()   : s
call data()  : cosmos
call base()  : 3
range-for    : cos
