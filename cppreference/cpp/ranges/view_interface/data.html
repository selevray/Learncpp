std::ranges::view_interface<D>::data

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr auto data()
    requires std::contiguous_iterator<ranges::iterator_t<D>>;  // (1) (depuis C++20)

constexpr auto data() const
    requires ranges::range<const D> &&
        std::contiguous_iterator<ranges::iterator_t<const D>>;  // (2) (depuis C++20)

La mise en œuvre par défaut de la fonction membre data() obtient l'adresse désignée par l'itérateur de début via std::to_address, qui est aussi l'adresse la plus basse du stockage contigu (impliqué par contiguous_iterator) référencé par la vue du type dérivé lorsque la vue n'est pas vide.

  1. Soit derived égal à static_cast<D&>(*this). Équivalent à return std::to_address(ranges::begin(derived));.

  2. Identique à (1), sauf que derived est static_cast<const D&>(*this).

Paramètres

(aucune)

Valeur de retour

L'adresse désignée par l'itérateur de début.

Notes

Les types dérivés suivants peuvent utiliser la mise en œuvre par défaut de data() :

  • std::ranges::common_view
  • std::ranges::drop_view
  • std::ranges::drop_while_view
  • std::ranges::ref_view
  • std::ranges::subrange
  • std::ranges::take_view
  • std::ranges::take_while_view

Les types suivants dérivent de std::ranges::view_interface et ne déclarent pas leur propre fonction membre data(), mais ils ne peuvent pas utiliser la mise en œuvre par défaut, car leurs types d'itérateurs ne satisfont jamais contiguous_iterator :

  • std::ranges::basic_istream_view
  • std::ranges::elements_view
  • std::ranges::filter_view
  • std::ranges::iota_view
  • std::ranges::join_view
  • std::ranges::lazy_split_view
  • std::ranges::reverse_view
  • std::ranges::split_view
  • std::ranges::transform_view

Exemple

#include <array>
#include <iostream>
#include <ranges>
#include <string_view>

int main() {
    constexpr std::string_view str { "Hello, C++20!" };
    std::cout << (str | std::views::drop(7)).data() << '\n';
    constexpr static std::array a { 1,2,3,4,5 };
    constexpr auto v { a | std::views::take(3) };
    static_assert( &a[0] == v.data() );
}
