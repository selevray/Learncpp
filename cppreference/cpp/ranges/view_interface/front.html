std::ranges::view_interface<D>::front

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr decltype(auto) front()
    requires ranges::forward_range<D>;  // (1) (depuis C++20)

constexpr decltype(auto) front() const
    requires ranges::forward_range<const D>;  // (2) (depuis C++20)

La mise en œuvre par défaut de la fonction membre front() renvoie le premier élément de la vue du type dérivé. Le fait que l'élément soit renvoyé par valeur ou par référence dépend du operator* du type d'itérateur.

  1. Soit derived égal à static_cast<D&>(*this). Équivalent à return *ranges::begin(derived);. Le comportement est indéfini si empty() est true (c'est-à-dire si l'itérateur de début est égal à la sentinelle), même si l'itérateur obtenu de la même façon est déréférençable.

  2. Identique à (1), sauf que derived est static_cast<const D&>(*this).

Paramètres

(aucune)

Valeur de retour

Le premier élément de la vue.

Notes

En C++20, aucun type dérivé de std::ranges::view_interface dans la bibliothèque standard ne fournit sa propre fonction membre front(). Presque tous ces types utilisent la mise en œuvre par défaut.

Une exception notable est std::ranges::basic_istream_view. Comme son type d'itérateur ne satisfait jamais forward_range, la vue ne peut pas utiliser la fonction front() héritée.

La fonction membre front() héritée est disponible pour std::ranges::empty_view, mais un appel à celle-ci entraîne toujours un comportement indéfini.
