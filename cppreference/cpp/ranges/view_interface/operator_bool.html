La mise en œuvre par défaut de la fonction membre operator bool vérifie si la vue n'est pas vide. Elle rend le type dérivé contextuellement convertible en bool.

  1. Soit derived égal à static_cast<D&>(*this). L'expression de la requires-clause est égale à requires { ranges::empty(derived); }, et le corps de la fonction est équivalent à return !ranges::empty(derived);.

  2. Identique à (1), sauf que derived est static_cast<const D&>(*this).

Paramètres

(aucune)

Valeur de retour

false si la valeur du type dérivé est vide (déterminé par std::ranges::empty), true sinon.

Notes

En C++20, aucun type dérivé de std::ranges::view_interface dans la bibliothèque standard ne fournit sa propre operator bool. Presque tous ces types utilisent la mise en œuvre par défaut.

Une exception notable est std::ranges::basic_istream_view. Comme son type d'itérateur ne satisfait jamais forward_iterator, la vue ne peut pas utiliser la fonction operator bool héritée.

Exemple

#include <array>
#include <iostream>
#include <ranges>

int main()
{
    const std::array ints {0, 1, 2, 3, 4};
    auto odds = ints | std::views::filter([](int i) { return 0 != i % 2; });
    auto negs = ints | std::views::filter([](int i) { return i < 0; });
    std::cout << std::boolalpha
              << "Has odd numbers: " << (!!odds) << ' ' << '\n'
              << "Has negative numbers: " << (!!negs) << ' ' << '\n';
}

Output:

Has odd numbers: true
Has negative numbers: false
