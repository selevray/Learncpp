std::ranges::elements_view<V,F>::iterator<Const>::operator[]

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr decltype(auto) operator[]( difference_type n ) const
    requires ranges::random_access_range<Base>;  // (depuis C++20)

Renvoie un élément à la position relative indiquée, comme si par /*get-element*/(this->base() + n), où pour une expression e, /*get-element*/(e) est

  • std::get<N>(*e), si ranges::range_reference_t<Base> est de type référence. Sinon,
  • static_cast<E>(std::get<N>(*e)), où E est std::remove_cv_t<std::tuple_element_t<N, ranges::range_reference_t<Base>>>.

Paramètres

  • n — position relative à la position courante

Valeur de retour

L'élément au déplacement n par rapport à la position courante.

Exemple

#include <iostream>
#include <ranges>
#include <string_view>
#include <tuple>

int main()
{
    using T = std::tuple<int, char, std::string_view>;

    const auto il =
    {
        T{1, 'A', "α"},
        T{2, 'B', "β"},
        T{3, 'C', "γ"},
    };

    std::cout << std::views::elements<0>(il)[1] << ' '   // 2
              << std::views::elements<1>(il)[1] << ' '   // B
              << std::views::elements<2>(il)[1] << '\n'; // β
}

Output:

2 B β
