std::ranges::elements_view<V,F>::iterator<Const>::operator*

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr decltype(auto) operator*() const;  // (depuis C++20)

Renvoie l'élément pointé par V l'itérateur sous-jacent.

Revient effectivement à /*get-element*/(this->base()), où pour une expression e, /*get-element*/(e) est

  • std::get<N>(*e), si ranges::range_reference_t<Base> est de type référence. Sinon,
  • static_cast<E>(std::get<N>(*e)), où E est std::remove_cv_t<std::tuple_element_t<N, ranges::range_reference_t<Base>>>.

Paramètres

(aucune)

Valeur de retour

L'élément courant.

Notes

operator-> n'est pas fourni.

Exemple

#include <iostream>
#include <ranges>
#include <string_view>
#include <tuple>

int main()
{
    using T = std::tuple<int, char, std::string_view>;

    const auto il = {
        T{1, 'A', "α"},
        T{2, 'B', "β"},
        T{3, 'C', "γ"},
    };

    const auto view {il | std::views::elements<2>};

    const auto iter {view.begin() + 1};

    std::cout << *iter << '\n';
}

Output:

β
