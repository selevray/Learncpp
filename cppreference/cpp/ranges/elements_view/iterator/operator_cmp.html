Compare les itérateurs sous-jacents.

  1. Équivalent à return x.base() == y.base();.

  2. Équivalent à return x.base() < y.base();.

  3. Équivalent à return y < x;.

  4. Équivalent à return !(y < x);.

  5. Équivalent à return !(x < y);.

  6. Équivalent à return x.base() <=> y.base();.

Ces fonctions ne sont pas visibles par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peuvent être trouvées que par la recherche dépendante des arguments lorsque std::ranges::elements_view::iterator<Const> est une classe associée aux arguments.

L'opérateur != est synthétisé à partir de operator==.
