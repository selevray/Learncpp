  1. Un adaptateur d'intervalle constitué des éléments de la séquence sous-jacente, en ignorant les N premiers éléments.

  2. RangeAdaptorObject. Sachant que T est std::remove_cvref_t<decltype((e))> et D est ranges::range_difference_t<decltype((e))>), l'expression views::drop(e, f) est expression-équivalente à :

  • ((void)f, decay-copy(e)), si T est un ranges::empty_view, sauf que les évaluations de e et f sont séquencées de manière indéterminée ;
  • sinon, T(ranges::begin(e) + inc, ranges::end(e), /*to-unsigned-like*/(ranges::distance(e) - inc)), si T est une spécialisation de ranges::subrange qui modélise à la fois random_access_range et sized_range, et T doit stocker la taille (voir ranges::subrange::subrange() pour les détails), où inc est std::min<D>(ranges::distance(e), f) ;
  • sinon, U(ranges::begin(e) + inc, ranges::end(e)), si T est une spécialisation de std::span, std::basic_string_view, ranges::iota_view ou ranges::subrange qui modélise à la fois random_access_range et sized_range, où U est
    • std::span<typename T::element_type>, si T est une spécialisation de std::span ;
    • T sinon ;
  • sinon, si T est une spécialisation de ranges::repeat_view :
  • views::repeat(*e.value_, ranges::distance(e) - inc), si T modélise sized_range ; dans ce cas e n'est évalué qu'une seule fois ;
  • ((void)e, auto(f)) sinon, sauf que les évaluations de e et f sont séquencées de manière indéterminée ;

(depuis C++23)

  • sinon, drop_view(e, f).

Dans tous les cas, decltype((f)) doit modéliser std::convertible_to<D>.

drop_view modélise les concepts contiguous_range, random_access_range, bidirectional_range, forward_range, input_range, common_range et sized_range lorsque la vue sous-jacente V modélise les concepts respectifs.

Guides de déduction

Modèles auxiliaires

template< class T >
constexpr bool enable_borrowed_range<std::ranges::drop_view<T>> =
    ranges::enable_borrowed_range<T>;  // (depuis C++20)

Cette spécialisation de ranges::enable_borrowed_range fait que drop_view satisfait borrowed_range lorsque la vue sous-jacente le satisfait.

Exemple

#include <iostream>
#include <ranges>

int main()
{
    const auto nums = {1, 2, 3, 4, 5, 6, 7};

    std::cout << "drop " << 2 << ": ";
    for (int i : std::ranges::drop_view{nums, 2})
        std::cout << i << ' ';
    std::cout << '\n';

    std::cout << "drop " << 3 << ": ";
    for (int i : nums | std::views::drop(3))
        std::cout << i << ' ';
    std::cout << '\n';

    std::cout << "drop " << 4 << ": ";
    for (int i : std::views::iota(1, 8) | std::views::drop(4))
        std::cout << i << ' ';
    std::cout << '\n';

    // Notez qu'ignorer plus d'éléments que n'en contient la séquence est valide :
    for (int dp : {5, 6, 7, 890, 100500})
    {
        std::cout << "drop " << dp << ": ";
        for (int i : std::views::iota(1, 8) | std::views::drop(dp))
            std::cout << i << ' ';
        std::cout << '\n';
    }
}
