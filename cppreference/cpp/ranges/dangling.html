std::ranges::dangling

Défini dans l'en-tête <ranges>

struct dangling;  // (depuis C++20)

dangling est un type de substitution et une classe vide, utilisé avec les alias de modèles ranges::borrowed_iterator_t et ranges::borrowed_subrange_t.

Lorsque certains algorithmes contraints qui renvoient habituellement un itérateur ou un sous-intervalle d'un range reçoivent un argument rvalue range particulier qui ne modélise pas borrowed_range, dangling est renvoyé à la place afin d'éviter de renvoyer des résultats potentiellement pendants.

Fonctions membres

std::ranges::dangling::dangling

constexpr dangling() noexcept = default;  // (1)

template<class... Args>
constexpr dangling(Args&&...) noexcept { }  // (2)

  1. dangling est trivialement constructible par défaut.

  2. dangling peut être construit à partir d'un nombre quelconque d'arguments de type quelconque non void. La construction n'a elle-même aucun effet de bord.

Autrement dit, après remplacement du type (par exemple un type d'itérateur) dans une initialisation bien formée non agrégat par dangling, l'initialisation résultante est également bien formée.

Exemple

#include <algorithm>
#include <array>
#include <iostream>
#include <ranges>
#include <type_traits>
#include <string_view>

int main()
{
    auto get_array_by_value = [] { return std::array{0, 1, 0, 1}; };
    auto dangling_iter = std::ranges::max_element(get_array_by_value());
    static_assert(std::is_same_v<std::ranges::dangling, decltype(dangling_iter)>);
//  std::cout << *dangling_iter << '\n'; // erreur de compilation : aucune correspondance pour 'operator*'
                                         // (le type de l'opérande est 'std::ranges::dangling')

    auto get_persistent_array = []() -> const std::array<int, 4>& {
        static constexpr std::array a{0, 1, 0, 1};
        return a;
    };
    auto valid_iter = std::ranges::max_element(get_persistent_array());
    static_assert(!std::is_same_v<std::ranges::dangling, decltype(valid_iter)>);
    std::cout << *valid_iter << ' '; // 1

    auto get_string_view = [] { return std::string_view{"alpha"}; };
    auto valid_iter2 = std::ranges::min_element(get_string_view());
        // OK : std::basic_string_view modélise borrowed_range
    static_assert(!std::is_same_v<std::ranges::dangling, decltype(valid_iter2)>);
    std::cout << '\'' << *valid_iter2 << '\'' << '\n'; // 'a'
}

Output:

1 'a'
