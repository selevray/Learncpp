std::ranges::common_view<V>::begin

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr auto begin() requires (!__simple_view<V>);  // (1) (depuis C++20)

constexpr auto begin() const requires range<const V>;  // (2) (depuis C++20)
  1. Renvoie un itérateur vers le premier élément du common_view, c'est-à-dire :
  • ranges::begin(base_), si ranges::random_access_range<V> et ranges::sized_range<V> sont satisfaits,
  • std::common_iterator<ranges::iterator_t<V>, ranges::sentinel_t<V>>(ranges::begin(base_)) sinon.

Ici base_ (le nom n'est destiné qu'à l'exposition) est la vue sous-jacente.

  1. Identique à (1), mais V est qualifié const.

Paramètres

(aucune)

Valeur de retour

Un itérateur vers le début de la vue sous-jacente.

Exemple

#include <iostream>
#include <numeric>
#include <ranges>
#include <string_view>

int main()
{
    constexpr auto common = std::views::iota(1)
                          | std::views::take(3)
                          | std::views::common
                          ;

    for (int i{}; int e : common)
        std::cout << (i++ ? " + " : "") << e;

    std::cout << " = " << std::accumulate(common.begin(), common.end(), 0) << '\n';
}

Output:

1 + 2 + 3 = 6
