std::ranges::common_view<V>::end

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr auto end() requires (!/*simple-view*/<V>);  // (1) (depuis C++20)

constexpr auto end() const requires ranges::range<const V>;  // (2) (depuis C++20)
  1. Renvoie un itérateur représentant la fin du common_view, c'est-à-dire :
  • ranges::begin(base_) + ranges::distance(base_), si ranges::random_access_range<V> et ranges::sized_range<V> sont satisfaits,
  • std::common_iterator<ranges::iterator_t<V>, ranges::sentinel_t<V>>(ranges::end(base_)) sinon.

Ici base_ (le nom n'est destiné qu'à l'exposition) est la vue sous-jacente.

  1. Identique à (1), mais V est qualifié const.

Paramètres

(aucune)

Valeur de retour

Un itérateur représentant la fin de la vue sous-jacente.

Exemple

#include <iostream>
#include <numeric>
#include <ranges>

int main()
{
    constexpr int n{4};

    constexpr auto v1 = std::views::iota(1)
                      | std::views::take(n)
                      | std::views::common
                      ;
    constexpr auto v2 = std::views::iota(2)
                      | std::views::take(n)
                      ;
    const int product = std::inner_product(v1.begin(), v1.end(),
                                           v2.begin(),
                                           0);
    std::cout << product << '\n';
}

Output:

40
