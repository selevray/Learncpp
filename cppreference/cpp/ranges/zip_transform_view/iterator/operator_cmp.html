Compare les itérateurs sous-jacents. Soit inner_ l'itérateur sous-jacent.

Équivalent à :

  1. return x.inner_ == y.inner_;

  2. return x.inner_ <=> y.inner_;

Les opérateurs <, <=, >, >= et != sont synthétisés à partir de operator<=> et operator== respectivement.
