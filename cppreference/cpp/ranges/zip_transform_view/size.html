std::ranges::zip_transform_view<F,Views...>::size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr auto size()
    requires ranges::sized_range</*InnerView*/>;  // (1) (depuis C++23)

constexpr auto size() const
    requires ranges::sized_range<const /*InnerView*/>  // (2) (depuis C++23)

Renvoie le nombre d'éléments de zip_transform_view. Fourni uniquement si chaque intervalle adapté sous-jacent satisfait sized_range.

1,2) Équivalent à : return zip_.size();.

Paramètres

(aucune)

Valeur de retour

Le nombre d'éléments, qui est la plus petite taille parmi toutes les tailles des views adaptés.

Exemple

#include <algorithm>
#include <cassert>
#include <deque>
#include <forward_list>
#include <functional>
#include <iostream>
#include <ranges>
#include <vector>

int main()
{
    auto x = std::vector{1, 2, 3, 4, 5};
    auto y = std::deque<short>{10, 20, 30};
    auto z = std::forward_list{100., 200.};

    auto v1 = std::views::zip_transform(std::plus{}, x, y);
    assert(v1.size() == std::min(x.size(), y.size()));
    assert(v1.size() == 3);
    for (int i : v1)
        std::cout << i << ' ';
    std::cout << '\n';

    [[maybe_unused]] auto v2 = std::views::zip_transform(std::plus{}, x, z);
//  auto sz = v2.size(); // Erreur : z n'a pas de size(), donc v2 non plus
    static_assert(not std::ranges::sized_range<decltype(z)>);
}

Output:

11 22 33
