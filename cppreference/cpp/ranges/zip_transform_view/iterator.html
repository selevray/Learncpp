Le type itérateur d'un zip_transform_view éventuellement qualifié const, renvoyé par zip_transform_view::begin et, dans certains cas, par zip_transform_view::end.

Le type /*iterator*/<true> ou /*iterator*/<false> traite les vues sous-jacentes comme qualifiées const ou non qualifiées const respectivement.
