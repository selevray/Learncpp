  1. Accepte un view de valeurs de type tuple, et produit une vue dont le type de valeur est celui du Ne élément du type de valeur de la vue adaptée.

  2. Chaque spécialisation de views::elements est un RangeAdaptorObject. L'expression views::elements<M>(e) est expression-équivalente à elements_view<views::all_t<decltype((e))>, M>{e} pour toute sous-expression appropriée e et expression constante M.

  3. Garantit que les éléments de la vue sous-jacente sont des valeurs de type tuple, voir tuple-like (depuis C++23).

  4. Garantit que des références pendantes ne peuvent pas être renvoyées.

elements_view modélise les concepts random_access_range, bidirectional_range, forward_range, input_range, common_range et sized_range lorsque la vue sous-jacente V modélise les concepts respectifs.

Modèles auxiliaires

template<class T, std::size_t N>

Cette spécialisation de ranges::enable_borrowed_range fait que elements_view satisfait borrowed_range lorsque la vue sous-jacente le satisfait.

Exemple

#include <iostream>
#include <ranges>
#include <string>
#include <tuple>
#include <vector>

int main()
{
    const std::vector<std::tuple<int, char, std::string>> vt
    {
        {1, 'A', "α"},
        {2, 'B', "β"},
        {3, 'C', "γ"},
        {4, 'D', "δ"},
        {5, 'E', "ε"},
    };

    for (int const e : std::views::elements<0>(vt))
        std::cout << e << ' ';
    std::cout << '\n';

    for (char const e : vt | std::views::elements<1>)
        std::cout << e << ' ';
    std::cout << '\n';

    for (std::string const& e : std::views::elements<2>(vt))
        std::cout << e << ' ';
    std::cout << '\n';
}

Output:

1 2 3 4 5
A B C D E
α β γ δ ε
