std::ranges::view_interface

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ranges>

template< class D >
    requires std::is_class_v<D> && std::same_as<D, std::remove_cv_t<D>>
class view_interface;  // (depuis C++20)

std::ranges::view_interface est un modèle de classe auxiliaire permettant de définir une interface de vue.

view_interface est typiquement utilisé avec CRTP :

class my_view : public std::ranges::view_interface<my_view>
{
public:
    auto begin() const { /*...*/ }
    auto end() const { /*...*/ }
    // empty() est fournie si begin() renvoie un itérateur d'avant
    // et si end() renvoie une sentinelle pour celui-ci.
};

Fonctions membres

  • empty — renvoie si la vue dérivée est vide. Fournie si elle satisfait sized_range ou forward_range. (fonction membre publique)
  • cbegin (C++23) — renvoie un itérateur constant vers le début de l'intervalle. (fonction membre publique)
  • cend (C++23) — renvoie une sentinelle pour l'itérateur constant de l'intervalle. (fonction membre publique)
  • operator bool — renvoie si la vue dérivée n'est pas vide. Fournie si ranges::empty lui est applicable. (fonction membre publique)
  • data — obtient l'adresse des données de la vue dérivée. Fournie si son type d'itérateur satisfait contiguous_iterator. (fonction membre publique)
  • size — renvoie le nombre d'éléments de la vue dérivée. Fournie si elle satisfait forward_range et si ses types de sentinelle et d'itérateur satisfont sized_sentinel_for. (fonction membre publique)
  • front — renvoie le premier élément de la vue dérivée. Fournie si elle satisfait forward_range. (fonction membre publique)
  • back — renvoie le dernier élément de la vue dérivée. Fournie si elle satisfait bidirectional_range et common_range. (fonction membre publique)
  • operator[] — renvoie le ne élément de la vue dérivée. Fournie si elle satisfait random_access_range. (fonction membre publique)

Exemple

#include <iostream>
#include <ranges>
#include <vector>

template<class T, class A>
class VectorView : public std::ranges::view_interface<VectorView<T, A>>
{
public:
    VectorView() = default;

    VectorView(const std::vector<T, A>& vec) :
        m_begin(vec.cbegin()), m_end(vec.cend())
    {}

    auto begin() const { return m_begin; }

    auto end() const { return m_end; }

private:
    typename std::vector<T, A>::const_iterator m_begin{}, m_end{};
};

int main()
{
    std::vector<int> v = {1, 4, 9, 16};

    VectorView view_over_v{v};

    // Nous pouvons itérer avec begin() et end().
    for (int n : view_over_v)
        std::cout << n << ' ';
    std::cout << '\n';

    // Nous obtenons operator[] gratuitement en héritant de view_interface
    // puisque nous satisfaisons le concept random_access_range.
    for (std::ptrdiff_t i = 0; i != view_over_v.size(); ++i)
        std::cout << "v[" << i << "] = " << view_over_v[i] << '\n';
}

Output:

1 4 9 16
v[0] = 1
v[1] = 4
v[2] = 9
v[3] = 16
