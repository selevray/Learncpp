Renvoie un itérateur ou une sentinelle représentant la fin du adjacent_transform_view.

Soit inner_ le ranges::adjacent_view sous-jacent.

  1. Équivalent à :
if constexpr (ranges::common_range<InnerView>)
    return /*iterator*/<false>(*this, inner_.end());
else
    return /*sentinel*/<false>(inner_.end());
  1. Équivalent à :
if constexpr (ranges::common_range<const InnerView>)
    return /*iterator*/<true>(*this, inner_.end());
else
    return /*sentinel*/<true>(inner_.end());

Paramètres

(aucune)

Valeur de retour

Un itérateur vers l'élément suivant le dernier élément, si la vue sous-jacente V modélise common_range. Sinon, une sentinelle qui se compare égale à l'itérateur de fin.

Notes

adjacent_transform_view<V,F,N> modélise common_range chaque fois que la vue sous-jacente V le fait.
