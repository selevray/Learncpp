Les surcharges de la fonction de conversion d'intervalle construisent un nouvel objet non vue à partir d'un intervalle source passé en premier argument, en appelant un constructeur prenant un intervalle, un constructeur à étiquette std::from_range_t de type ranged, un constructeur prenant une paire itérateur-sentinelle, ou en insérant par la fin chaque élément de l'intervalle source dans l'objet construit à partir des arguments.

  1. Construit un objet de type C à partir des éléments de r, de la manière suivante :

a) Si C ne satisfait pas input_range ou si std::convertible_to<ranges::range_reference_t<R>, ranges::range_value_t<C>> vaut true :

  1. Construction d'un objet non vue comme si l'on effectuait une initialisation directe (mais pas une initialisation directe par liste) d'un objet de type C à partir de l'intervalle source std::forward<R>(r) et du reste des arguments fonctionnels std::forward<Args>(args)..., si std::constructible_from<C, R, Args...> vaut true.

  2. Sinon, construction d'un objet non vue comme si l'on effectuait une initialisation directe (mais pas une initialisation directe par liste) d'un objet de type C à partir de l'étiquette de désambiguïsation supplémentaire std::from_range, de l'intervalle source std::forward<R>(r) et du reste des arguments fonctionnels std::forward<Args>(args)..., si std::constructible_from<C, std::from_range_t, R, Args...> vaut true.

  3. Sinon, construction d'un objet non vue comme si l'on effectuait une initialisation directe (mais pas une initialisation directe par liste) d'un objet de type C à partir de la paire itérateur-sentinelle (ranges::begin(r) comme itérateur et ranges::end(r) comme sentinelle, où l'itérateur et la sentinelle ont le même type ; autrement dit, l'intervalle source doit être un intervalle commun), et du reste des arguments fonctionnels std::forward<Args>(args)..., si toutes les conditions ci-dessous sont true :

  • ranges::common_range<R>
  • Si std::iterator_traits<ranges::iterator_t<R>>::iterator_category est valide et désigne un type qui satisfait std::derived_from<std::input_iterator_tag>
  • std::constructible_from<C, ranges::iterator_t<R>, ranges::sentinel_t<R>, Args...>
  1. Sinon, construction d'un objet intervalle non vue comme si l'on effectuait une initialisation directe (mais pas une initialisation directe par liste) d'un objet de type C à partir du reste des arguments fonctionnels std::forward<Args>(args)..., avec l'appel équivalent suivant après la construction :

if constexpr (ranges::sized_range<R> && /*reservable-container*/<C>) c.reserve(static_cast<ranges::range_size_t<C>>(ranges::size(r))); ranges::for_each(r, /*container-appender*/(c));

Chaque élément de r est ajouté à la fin de c. Les opérations ci-dessus sont valides si les deux conditions ci-dessous sont true :

  • std::constructible_from<C, Args...>
  • container-appendable<C, ranges::range_reference_t<R>>

3,4) Renvoie un wrapper d'appel à transmission parfaite qui est aussi un RangeAdaptorClosureObject.

  1. Vaut true s'il satisfait ranges::sized_range et peut être réservable.

  2. Vaut true si un élément de type Reference peut être ajouté à Container par un appel de fonction membre emplace_back, push_back, emplace ou insert.

  3. Renvoie un objet fonction dont l'appel est équivalent, en termes d'expression, à l'ajout d'un élément à un conteneur. L'expression de retour est équivalente à :

return [&c]<class Reference>(Reference&& ref) { if constexpr (requires { c.emplace_back(std::declval<Reference>()); }) c.emplace_back(std::forward<Reference>(ref)); else if constexpr (requires { c.push_back(std::declval<Reference>()); }) c.push_back(std::forward<Reference>(ref)); else if constexpr (requires { c.emplace(c.end(), std::declval<Reference>()); }) c.emplace(c.end(), std::forward<Reference>(ref)); else c.insert(c.end(), std::forward<Reference>(ref)); };

  1. Est utilisé dans la définition des conteneurs lors de la construction d'un intervalle d'entrée R dont le type de référence d'intervalle doit être convertible en T.

Paramètres

  • r — un objet intervalle source
  • args — liste des arguments de (1,2) pour construire un intervalle, ou (3,4) pour lier aux derniers paramètres de l'objet fermeture d'adaptateur d'intervalle

Exigences sur les types

  • C doit être un type classe non qualifié cv (1,3)

Valeur de retour

1,2) Un objet non vue construit.

3,4) Un objet fermeture d'adaptateur d'intervalle de type non spécifié, ayant les propriétés suivantes :

ranges::to type de retour

Objets membres

L'objet renvoyé se comporte comme s'il n'avait pas d'objet cible, et comme un objet std::tuple tup construit avec std::tuple<std::decay_t<Args>...>(std::forward<Args>(args)...), sauf que le comportement d'affectation de l'objet renvoyé est non spécifié et que les noms ne servent qu'à l'exposition.

Constructeurs

Le type de retour de ranges::to (3,4) se comporte comme si ses constructeurs de copie/déplacement effectuaient une copie/déplacement membre à membre. Il est CopyConstructible si tous ses objets membres (spécifiés ci-dessus) sont CopyConstructible, et MoveConstructible sinon.

Fonction membre operator()

Étant donné un objet G obtenu lors d'un appel antérieur à range::to</* voir ci-dessous */>(args...), lorsqu'un glvalue g désignant G est invoqué dans une expression d'appel de fonction g(r), l'invocation de l'objet stocké a lieu, comme si l'on effectuait

  • ranges::to</* voir ci-dessous */>(r, std::get<Ns>(g.tup)...), où
    • r est un objet intervalle source qui doit satisfaire input_range.
    • Ns est un paquet d'entiers 0, 1, ..., (sizeof...(Args) - 1).
    • g est une lvalue dans l'expression d'appel si elle est une lvalue dans l'expression d'appel, et une rvalue sinon. Ainsi std::move(g)(r) peut déplacer les arguments liés dans l'appel, alors que g(r) les copierait.
    • L'argument de modèle spécifié est (3) C ou (4) le type déduit d'un modèle de classe C qui ne doit pas satisfaire view.

Le programme est mal formé si g a un type qualifié volatile.

Exceptions

Ne lève une exception que si la construction d'un objet non vue lève une exception.

Notes

L'insertion d'éléments dans le conteneur peut impliquer une copie, moins efficace qu'un déplacement, car des références lvalue sont produites lors de l'appel d'indirection. Les utilisateurs peuvent choisir d'utiliser views::as_rvalue pour adapter l'intervalle afin que leurs éléments produisent toujours une référence rvalue lors de l'appel d'indirection, ce qui implique un déplacement.

Les parenthèses sont obligatoires lors de l'utilisation de la syntaxe par tuyau.

auto vec = r | std::ranges::to<std::vector>;   // Erreur
auto vec = r | std::ranges::to<std::vector>(); // OK

Un lien de prévisualisation : Compiler Explorer

#include <boost/container/devector.hpp>
#include <concepts>
#include <list>
#include <initializer_list>
#include <iostream>
#include <print>
#include <ranges>
#include <regex>
#include <string>
#include <vector>

int main()
{
    auto vec = std::views::iota(1, 5)
             | std::views::transform([](int v){ return v * 2; })
             | std::ranges::to<std::vector>();

    static_assert(std::same_as<decltype(vec), std::vector<int>>);
    std::println("{}", vec);

    auto list = vec | std::views::take(3) | std::ranges::to<std::list<double>>();
    std::println("{}", list);
}

void ctor_demos()
{
    // 1.a.1) Initialisation directe
    {
        char array[]{'a', 'b', '\0', 'c'};

        // Le type de l'argument est convertible en type de valeur du résultat :
        auto str_to = std::ranges::to<std::string>(array);
        // Équivalent à
        std::string str(array);

        // Le type du résultat n'est pas un intervalle d'entrée :
        auto re_to = std::ranges::to<std::regex>(array);
        // Équivalent à
        std::regex re(array);
    }

    // 1.a.2) constructeur from_range
    {
        auto list = {'a', 'b', '\0', 'c'};

        // Le type de l'argument est convertible en type de valeur du résultat :
        auto str_to = std::ranges::to<std::string>(list);
        // Équivalent à
        std::string str(std::from_range, list);

        // Le type du résultat n'est pas un intervalle d'entrée :
        auto pair_to = std::ranges::to<std::pair<std::from_range_t, bool>>(true);
        // Équivalent à
        std::pair<std::from_range_t, bool> pair(std::from_range, true);
    }

    // 1.a.3) constructeur à partir d'une paire d'itérateurs
    {
        auto list = {'a', 'b', '\0', 'c'};

        // Le type de l'argument est convertible en type de valeur du résultat :
        auto devector_to = std::ranges::to<boost::container::devector<char>>(list);
        // Équivalent à
        boost::container::devector<char> devector(std::ranges::begin(list),
                                                  std::ranges::end(list));

        // Le type du résultat n'est pas un intervalle d'entrée :
        std::regex re;
        auto it_to = std::ranges::to<std::cregex_iterator>(list, re);
        // Équivalent à
        std::cregex_iterator it(std::ranges::begin(list), std::ranges::end(list), re);
    }
}
