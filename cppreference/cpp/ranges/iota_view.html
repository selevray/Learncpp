  1. Une fabrique d'intervalle qui génère une séquence d'éléments en incrémentant répétitivement une valeur initiale. Peut être bornée ou non bornée (infinie).

  2. views::iota(e) et views::iota(e, f) sont équivalentes en expression à iota_view<std::decay_t<decltype((e))>>(e) et iota_view(e, f) respectivement, pour toutes les sous-expressions appropriées e et f.

Objets de point de personnalisation

Le nom views::iota désigne un objet de point de personnalisation, qui est un objet fonction const d'un type de classe littéral semiregular. À des fins d'exposition, la version sans qualificateurs cv de son type est désignée par __iota_fn.

Toutes les instances de __iota_fn sont égales. Les effets de l'invocation de différentes instances du type __iota_fn sur les mêmes arguments sont équivalents, qu'il s'agisse ou non d'une lvalue ou d'une rvalue, et que l'expression désignant l'instance soit qualifiée const ou non (toutefois, une instance qualifiée volatile n'est pas tenue d'être invocable). Ainsi, views::iota peut être copié librement et ses copies peuvent être utilisées de manière interchangeable.

Étant donné un ensemble de types Args..., si std::declval<Args>()... satisfont aux exigences relatives aux arguments de views::iota ci-dessus, alors __iota_fn modélise

  • std::invocable<__iota_fn, Args...>,
  • std::invocable<const __iota_fn, Args...>,
  • std::invocable<__iota_fn&, Args...>, and
  • std::invocable<const __iota_fn&, Args...>.

Sinon, aucun opérateur d'appel de fonction de __iota_fn ne participe à la résolution de surcharge.

Modèles auxiliaires

Cette spécialisation de ranges::enable_borrowed_range rend iota_view conforme à borrowed_range.

Exemple

#include <algorithm>
#include <iostream>
#include <ranges>

struct Bound
{
    int bound;
    bool operator==(int x) const { return x == bound; }
};

int main()
{
    for (int i : std::ranges::iota_view{1, 10})
        std::cout << i << ' ';
    std::cout << '\n';

    for (int i : std::views::iota(1, 10))
        std::cout << i << ' ';
    std::cout << '\n';

    for (int i : std::views::iota(1, Bound{10}))
        std::cout << i << ' ';
    std::cout << '\n';

    for (int i : std::views::iota(1) | std::views::take(9))
        std::cout << i << ' ';
    std::cout << '\n';

    std::ranges::for_each(std::views::iota(1, 10),
                          [](int i){ std::cout << i << ' '; });
    std::cout << '\n';
}
