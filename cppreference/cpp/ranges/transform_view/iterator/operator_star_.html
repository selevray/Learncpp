std::ranges::transform_view<V,F>::iterator<Const>::operator*

constexpr decltype(auto) operator*() const;  // (depuis C++20)

Renvoie l'élément transformé.

Revient en pratique à renvoyer std::invoke(*parent_->fun_, *current_), où *parent_->fun_ est la fonction de transformation stockée dans le transform_view parent, et current_ est l'itérateur sous-jacent vers V.

Paramètres

(aucune)

Valeur de retour

L'élément transformé.

Notes

operator-> n'est pas fourni.

Le comportement est indéfini si le pointeur vers le transform_view parent est nul (par exemple si *this a été construit par défaut).

Si *current_ est une prvalue, sa durée de vie se termine avant que cette fonction ne retourne. Si la fonction de transformation renvoie une référence ou un pointeur vers celle-ci, le résultat deviendrait une référence pendante.
