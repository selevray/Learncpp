constexpr decltype(auto) operator[]( difference_type n ) const
  requires ranges::random_access_range<Base>;  // (depuis C++20)

Renvoie l'élément situé à la position relative spécifiée, après transformation.

Revient en pratique à renvoyer std::invoke(*parent_->fun_, current_[n]), où *parent_->fun_ est la fonction de transformation stockée dans le transform_view parent, et current_ est l'itérateur sous-jacent vers V.

Paramètres

  • n — position relative à l'emplacement courant.
