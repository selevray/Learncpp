std::ranges::transform_view<V,F>::transform_view

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

transform_view() requires std::default_initializable<V> &&
                          std::default_initializable<F> = default;  // (1) (depuis C++20)

constexpr explicit transform_view( V base, F fun );  // (2) (depuis C++20)

Construit un transform_view.

  1. Constructeur par défaut. Initialise par valeur la vue sous-jacente base_ et la fonction de transformation fun_.

  2. Construit par déplacement la vue sous-jacente base_ à partir de base et la fonction de transformation fun_ à partir de fun.

Paramètres

  • base — view
  • fun — fonction de transformation

Exemple

Démontre l'approximation de π à l'aide du développement en série de l'arc tangente de 1 :
atan(1) = π/4 ≈ 1 - 1/3 + 1/5 - 1/7 + 1/9 - 1/11 + ...

#include <iomanip>
#include <iostream>
#include <numbers>
#include <numeric>
#include <ranges>

int main()
{
    std::cout << std::setprecision(15) << std::fixed;
    auto atan1term = std::ranges::views::transform(
        [](int n) { return ((n % 2) ? -1 : 1) * 1.0 / (2 * n + 1); }
    );
    for (const int iterations : {1, 2, 3, 4, 5, 10, 100, 1000, 1'000'000})
    {
        auto seq = std::ranges::views::iota(0, iterations) | atan1term;
        const double accum = std::accumulate(seq.begin(), seq.end(), 0.0);
        std::cout << "π ≈ " << 4 * accum << " (iterations: " << iterations << ")\n";
    }
    std::cout << "π ≈ " << std::numbers::pi << " (std::numbers::pi)\n";
}
