std::ranges::transform_view<V,F>::size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr auto size() requires ranges::sized_range<V>;  // (depuis C++20)

constexpr auto size() const requires ranges::sized_range<const V>;  // (depuis C++20)

Renvoie le nombre d'éléments.

Renvoie ranges::size(base_), où base_ est la vue sous-jacente.

Paramètres

(aucune)

Valeur de retour

Le nombre d'éléments.

Notes

Si V ne modélise pas forward_range, size() peut ne pas être bien défini après un appel à begin().

Exemple

#include <cassert>
#include <cctype>
#include <iostream>
#include <ranges>
#include <string>

int main()
{
    std::string s{"The length of this string is 42 characters"};
    auto to_upper = [](unsigned char c) -> char { return std::toupper(c); };
    auto tv = std::ranges::transform_view{s, to_upper};
    assert(tv.size() == 42);
    for (auto x : tv)
        std::cout << x;
}

Output:

THE LENGTH OF THIS STRING IS 42 CHARACTERS
