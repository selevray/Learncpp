operator==(ranges::take_while_view::sentinel)

friend constexpr bool operator==( const ranges::iterator_t<Base>& x,
                                  const /*sentinel*/& y );  // (depuis C++20)

Compare un take_while_view::/*sentinel*/ avec un itérateur dans la vue V (éventuellement qualifiée const). L'itérateur est obtenu généralement par un appel à take_while_view::begin.

Renvoie true si x est égal à la sentinelle sous-jacente de y (c.-à-d. y.base()), ou si le prédicat renvoie false lorsqu'il est appliqué à *x.

Cette fonction n'est pas visible par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peut être trouvée que par la recherche dépendante des arguments lorsque take_while_view::sentinel<Const> est une classe associée aux arguments.

L'opérateur != est synthétisé à partir de operator==.

Paramètres

  • x — itérateur à comparer
  • y — sentinel à comparer

Valeur de retour

y.end_ == x || !std::invoke(*y.pred_, *x), où end_ désigne la sentinelle stockée et pred_ désigne le pointeur stocké vers le prédicat.
