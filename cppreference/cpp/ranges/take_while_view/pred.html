std::ranges::take_while_view<V,Pred>::pred

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr const Pred& pred() const;  // (depuis C++20)

Renvoie une référence au prédicat stocké pred_.

Si *this ne stocke pas de prédicat (par exemple si une exception est levée lors de l'affectation à *this, qui construit par copie ou par déplacement un Pred), le comportement est indéfini.

Paramètres

(aucune)

Valeur de retour

Une référence au prédicat stocké.

Exemple

#include <ranges>

int main()
{
    static constexpr int a[]{1, 2, 3, 4, 5};
    constexpr auto v = a | std::views::take_while([](int x){ return x < 4; });
    const auto pred = v.pred();
    static_assert(pred(3));
}
