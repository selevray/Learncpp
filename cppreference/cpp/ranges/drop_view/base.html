std::ranges::drop_view<V>::base

constexpr V base() const& requires std::copy_constructible<V>;  // (1) (depuis C++20)

constexpr V base() &&;  // (2) (depuis C++20)

Renvoie une copie de la vue sous-jacente.

  1. Construit par copie le résultat à partir de la vue sous-jacente base_.

  2. Construit par déplacement le résultat à partir de la vue sous-jacente base_.

Paramètres

(aucune)

Valeur de retour

Une copie de la vue (adaptée) sous-jacente base_.

Exemple

#include <iostream>
#include <ranges>

namespace stq {
void println(auto, const auto& v)
{
    for (const auto& e : v)
        std::cout << e << ' ';
    std::cout << '\n';
}
}

int main()
{
    static constexpr int a[]{1, 2, 3, 4, 5};
    constexpr auto view = a | std::views::drop(2);
    stq::println("{}", view);
    const auto base = view.base();
    stq::println("{}", base);
}

Output:

3 4 5
1 2 3 4 5
