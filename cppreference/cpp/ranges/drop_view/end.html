std::ranges::drop_view<V>::end

Renvoie une sentinelle ou un itérateur représentant la fin de drop_view.

Revient effectivement à ranges::end(base_), où base_ est la vue sous-jacente.

Paramètres

(aucune)

Valeur de retour

Une sentinelle ou un itérateur représentant la fin de la vue.

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>
#include <ranges>

int main()
{
    namespace ranges = std::ranges;
    constexpr char url[]{"https://cppreference.com"};

    const auto p = std::distance(ranges::begin(url), ranges::find(url, '/'));
    auto site = ranges::drop_view{url, p + 2}; // supprime le préfixe "https://"

    for (auto it = site.begin(); it != site.end(); ++it)
        std::cout << *it;
    std::cout << '\n';
}
