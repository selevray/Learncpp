std::ranges::drop_view<V>::begin

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr auto begin()
    requires (!(/*simple-view*/<V> &&
                 ranges::random_access_range<const V> &&
                 ranges::sized_range<const V>));  // (1) (depuis C++20)

constexpr auto begin() const
    requires ranges::random_access_range<const V> &&
             ranges::sized_range<const V>;  // (2) (depuis C++20)

Renvoie un itérateur vers le premier élément de drop_view, c'est-à-dire un itérateur vers le N**e élément de la vue sous-jacente, ou vers la fin de la vue sous-jacente si elle comporte moins de N éléments.

Si V n'est pas un random_access_range ni un sized_range, afin de fournir la complexité en temps constant amorti requise par le concept range, la surcharge (1) met en cache le résultat dans l'objet drop_view pour une utilisation lors des appels suivants.

Paramètres

(aucune)

Valeur de retour

ranges::next(ranges::begin(base_), count_, ranges::end(base_)), où base_ est la vue sous-jacente et count_ est le nombre d'éléments à ignorer.

Exemple

#include <array>
#include <concepts>
#include <iostream>
#include <iterator>
#include <ranges>

void println(std::ranges::range auto const& range)
{
    for (auto const& elem : range)
        std::cout << elem;
    std::cout << '\n';
}

int main()
{
    std::array hi{'H', 'e', 'l', 'l', 'o', ',', ' ', 'C', '+', '+', '2', '0', '!'};
    println(hi);

    const auto pos = std::distance(hi.begin(), std::ranges::find(hi, 'C'));
    auto cxx = std::ranges::drop_view{hi, pos};
    std::cout << "*drop_view::begin() == '" << *cxx.begin() << "'\n";
//  *cxx.begin() = 'c'; // comportement indéfini : les 'views' doivent être utilisées comme des observateurs
    println(cxx);
}

*drop_view::begin() == 'C'
