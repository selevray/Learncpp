Enveloppe assignable (C++20)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class T >
    requires std::copy_constructible<T> && std::is_object_v<T>
class /*copyable-box*/;  // (depuis C++20) (jusqu'à C++23) ( exposition uniquement* )

template< class T >
    requires std::move_constructible<T> && std::is_object_v<T>
class /*movable-box*/;  // (depuis C++23) ( exposition uniquement* )

ranges::single_view, ranges::repeat_view, (depuis C++23) et les adaptateurs d'intervalles qui stockent un objet invocable sont spécifiés en termes de modèle de classe exposé uniquement [copyable-box (jusqu'à C++23) | movable-box (depuis C++23)]. Le nom présenté ici n'est destiné qu'à l'exposition.

L'enveloppe se comporte exactement comme std::optional<T>, sauf que le constructeur par défaut, l'opérateur d'affectation par copie et l'opérateur d'affectation par déplacement sont (conditionnellement) différents de ceux de std::optional, qui ajoute à T l'assignabilité lorsque nécessaire et lui permet de toujours satisfaire copyableou movable (depuis C++23).

Si T est déjà copyable, ou si std::is_nothrow_move_constructible_v<T> et std::is_nothrow_copy_constructible_v<T> sont true, /*copyable-box*/<T> ne peut stocker qu'un objet T, car il contient toujours une valeur.

(jusqu'à C++23)

Si T

  • est déjà copyable, ou
  • est copy_constructible et std::is_nothrow_move_constructible_v<T> et std::is_nothrow_copy_constructible_v<T> sont toutes deux true, ou
  • ne satisfait pas copy_constructible mais satisfait movable, ou
  • ne satisfait pas copy_constructible mais std::is_nothrow_move_constructible_v<T> est true,

/*movable-box*/<T> ne peut stocker qu'un objet T, car il contient toujours une valeur.

(depuis C++23)

Paramètres de modèle

  • T — le type de la valeur contenue doit être un type objet qui modélise [copy_constructible (jusqu'à C++23) | move_constructible (depuis C++23)]

Fonctions membres

Constructeur par défaut

constexpr /*copyable-box*/() noexcept(std::is_nothrow_default_constructible_v<T>)
    requires std::default_initializable<T>
    : /*copyable-box*/(std::in_place) { }  // (depuis C++20) (jusqu'à C++23)

constexpr /*movable-box*/() noexcept(std::is_nothrow_default_constructible_v<T>)
    requires std::default_initializable<T>
    : /*movable-box*/(std::in_place) { }  // (depuis C++23)

Le constructeur par défaut est fourni si et seulement si T modélise default_initializable.

Un wrapper construit par défaut contient un objet T initialisé par valeur.

constexpr /*copyable-box*/& operator=(/*copyable-box*/&& other) noexcept(std::is_nothrow_move_constructible_v<T>) { if (this != std::addressof(other)) if (other) emplace(std::move(*other)); else reset(); return *this; }

(jusqu'à C++23)

constexpr /*movable-box*/& operator=(/*movable-box*/&& other) noexcept(std::is_nothrow_move_constructible_v<T>) { if (this != std::addressof(other)) if (other) emplace(std::move(*other)); else reset(); return *this; }

(depuis C++23)

Sinon, il est identique à l'opérateur d'affectation par déplacement de std::optional.

Membres identiques à std::optional

Fonctions membres

  • (constructeur) — construit l'objet optional (fonction membre publique de std::optional<T>)
  • (destructeur) — détruit la valeur contenue, s'il y en a une (fonction membre publique de std::optional<T>)
  • operator= — affecte le contenu (fonction membre publique de std::optional<T>)

##### Observateurs {#Observers}

  • operator->operator* — accède à la valeur contenue (fonction membre publique de std::optional<T>)
  • operator boolhas_value — vérifie si l'objet contient une valeur (fonction membre publique de std::optional<T>)

##### Modificateurs {#Modifiers}

  • reset — détruit toute valeur contenue (fonction membre publique de std::optional<T>)
  • emplace — construit la valeur contenue sur place (fonction membre publique de std::optional<T>)

Notes

Un [copyable-box (jusqu'à C++23) | movable-box (depuis C++23)] ne contient aucune valeur que si

  • T ne modélise pas movable ou copyable, et une exception est levée lors de l'affectation par déplacement ou par copie respectivement, ou
  • il est initialisé/affecté à partir d'un autre wrapper sans valeur.

Avant P2325R3, le wrapper s'appelait semiregular-box dans la norme et satisfaisait toujours semiregular, car le constructeur par défaut était toujours fourni (qui pouvait construire un wrapper sans valeur).
