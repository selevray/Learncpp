C++ keyword: typename

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Utilisation

  • Dans la liste des paramètres de modèle d'une déclaration de modèle, typename peut être utilisé à la place de class pour déclarer des paramètres de modèle de typeet des paramètres de modèle template (depuis C++17).
  • Dans la déclaration ou la définition d'un modèle, typename peut être utilisé pour déclarer qu'un nom qualifié dépendant est un type.
  • typename peut être utilisé devant un nom de type qualifié non dépendant. Il n'a aucun effet dans ce cas.
  • Dans une clause requires pour des exigences sur les types

(depuis C++20)
