std::common_iterator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iterator>

template< std::input_or_output_iterator I, std::sentinel_for<I> S >
    requires ( !std::same_as<I, S> && std::copyable<I> )
class common_iterator;  // (depuis C++20)

std::common_iterator est un adaptateur d'itérateur I / sentinelle S qui peut représenter un intervalle non commun (où les types de I et S diffèrent) sous la forme d'un common_range, en contenant soit un itérateur soit une sentinelle, et en définissant les opérateurs de comparaison d'égalité appropriés operator==.

std::common_iterator peut servir de « pont » entre des séquences représentées par une paire itérateur/sentinelle et des fonctions héritées qui attendent des séquences de type common_range.

Membres de données

Nom du membre Définition

  • var — un objet de type std::variant<I, S> (objet membre réservé à l'exposition)*

Fonctions membres

  • (constructeur) (C++20) — construit un nouvel adaptateur d'itérateur (fonction membre publique)
  • operator= (C++20) — affecte un autre adaptateur d'itérateur (fonction membre publique)
  • operator*operator-> (C++20) — accède à l'élément pointé (fonction membre publique)
  • operator++operator++(int) (C++20) — fait avancer l'adaptateur d'itérateur (fonction membre publique)

Fonctions non membres

  • operator== (C++20) — compare les itérateurs ou sentinelles sous-jacents (modèle de fonction)
  • operator- (C++20) — calcule la distance entre deux adaptateurs d'itérateurs (modèle de fonction)
  • iter_move (C++20) — convertit le résultat du déréférencement de l'itérateur sous-jacent en son type de référence rvalue associé (fonction)
  • iter_swap (C++20) — échange les objets pointés par deux itérateurs sous-jacents (modèle de fonction)

Classes auxiliaires

  • std::incrementable_traits<std::common_iterator> (C++20) — calcule le type de différence associé au type std::common_iterator (spécialisation de modèle de classe)
  • std::iterator_traits<std::common_iterator> (C++20) — fournit une interface uniforme aux propriétés du type std::common_iterator (spécialisation de modèle de classe)

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>
#include <list>
#include <string>

template<class ForwardIter>
void fire(ForwardIter first, ForwardIter last)
{
    std::copy(first, last, std::ostream_iterator<std::string>{std::cout, " "});
}

int main()
{
    std::list<std::string> stars{"Pollux", "Arcturus", "Mira", "Aldebaran", "Sun"};

    using IT = std::common_iterator<
                   std::counted_iterator<std::list<std::string>::iterator>,
                   std::default_sentinel_t>;

    fire(IT(std::counted_iterator(stars.begin(), stars.size() - 1)),
         IT(std::default_sentinel));
}

Output:

Pollux Arcturus Mira Aldebaran
