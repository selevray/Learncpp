std::counted_iterator<I>::operator[]

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr decltype(auto) operator[]( std::iter_difference_t<I> n ) const
    requires std::random_access_iterator<I>;  // (depuis C++20)

Accède à l'élément situé à la position relative spécifiée. Le comportement est indéfini si n n'est pas strictement inférieur à la distance enregistrée jusqu'à la fin.

Paramètres

  • n — position relative à la position courante

Valeur de retour

this->base()[n]

Exemple

#include <array>
#include <iostream>
#include <iterator>
#include <list>

int main()
{
    std::array array{'A', 'B', 'C', 'D', 'E'};

    std::counted_iterator it{array.begin() + 1, /*count:*/ 3};

    for (int i{}; i != it.count(); ++i)
        std::cout << it[i] << ' ';
    std::cout << '\n';

    for (int i{}; i != it.count(); ++i)
        it[i] += ('E' - 'A');

    for (int i{}; i != it.count(); ++i)
        std::cout << it[i] << ' ';
    std::cout << '\n';

    std::list list{'X', 'Y', 'Z', 'W'};
    std::counted_iterator it2{list.begin(), 3};
//  char x = it2[0]; // Erreur : l'exigence `random_access_iterator` n'est pas satisfaite.
    std::cout << *it2 << '\n'; // OK
}

Output:

B C D
F G H
X
