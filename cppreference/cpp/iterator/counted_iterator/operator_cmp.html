operator==,<=>(std::counted_iterator)

template< std::common_with<I> I2 >
    friend constexpr bool operator==(
        const counted_iterator& x, const counted_iterator<I2>& y );  // (1) (depuis C++20)

template< std::common_with<I> I2 >
    friend constexpr strong_ordering operator<=>(
        const counted_iterator& x, const counted_iterator<I2>& y );  // (2) (depuis C++20)

Compare les longueurs sous-jacentes (c'est-à-dire les distances jusqu'à la fin).

  1. Vérifie si les longueurs sous-jacentes sont égales.

  2. Compare les longueurs sous-jacentes avec l'opérateur <=>.

Le comportement est indéfini si x et y ne pointent pas vers des éléments de la même séquence. Autrement dit, il doit exister un n tel que std::next(x.base(), x.count() + n) et std::next(y.base(), y.count() + n) désignent le même élément.

Les opérateurs <, <=, >, >= et != sont synthétisés à partir de operator<=> et operator== respectivement.

Ce modèle de fonction n'est pas visible par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peut être trouvé que par recherche dépendant des arguments lorsque std::counted_iterator<I> est une classe associée des arguments.

Paramètres

  • x, y — adaptateurs d'itérateurs

Valeur de retour

  1. x.count() == y.count()

  2. y.count() <=> x.count()

Notes

Puisque la longueur décroît au lieu de croître, l'ordre des arguments de operator<=> dans l'expression de comparaison sous-jacente est inversé, c'est-à-dire que y est lhs, x est rhs.

Exemple

#include <initializer_list>
#include <iterator>

int main()
{
    static constexpr auto v = {1, 2, 3, 4, 5, 6};
    constexpr std::counted_iterator<std::initializer_list<int>::iterator>
        it1{v.begin(), 5},
        it2{v.begin(), 5},
        it3{v.begin() + 1, 4},
        it4{v.begin(), 0};
    static_assert(it1 == it2);
    static_assert(it2 != it3);
    static_assert(it2 <  it3);
    static_assert(it1 <= it2);
    static_assert(it3 != std::default_sentinel);
    static_assert(it4 == std::default_sentinel);

//  it2 == std::counted_iterator{v.begin(), 4}; // UB : les opérandes ne désignent pas
                                                // des éléments de la même séquence
}
