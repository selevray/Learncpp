operator-(std::counted_iterator)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< std::common_with<I> I2 >
    friend constexpr std::iter_difference_t<I2> operator-(
        const counted_iterator& x, const counted_iterator<I2>& y );  // (depuis C++20)

Calcule la distance entre deux adaptateurs d'itérateurs.

Le comportement est indéfini si x et y ne pointent pas vers des éléments de la même séquence. Autrement dit, il doit exister un n tel que std::next(x.base(), x.count() + n) et std::next(y.base(), y.count() + n) désignent le même élément.

Ce modèle de fonction n'est pas visible par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peut être trouvé que par recherche dépendant des arguments lorsque std::counted_iterator<I> est une classe associée des arguments.

Paramètres

  • x, y — adaptateurs d'itérateurs dont calculer la différence

Valeur de retour

y.count() - x.count()

Notes

Puisque la longueur décroît au lieu de croître, l'ordre des arguments de operator- dans l'expression sous-jacente est inversé, c'est-à-dire que y est lhs et x est rhs.

Exemple

#include <initializer_list>
#include <iterator>

int main()
{
    static constexpr auto v = {1, 2, 3, 4, 5, 6};
    constexpr std::counted_iterator<std::initializer_list<int>::iterator>
        it1{v.begin(), 5},
        it2{it1 + 3},
        it3{v.begin(), 2};

    static_assert(it1 - it2 == -3);
    static_assert(it2 - it1 == +3);
//  static_assert(it1 - it3 == -3); // UB : les opérandes de operator- ne désignent pas
                                    // des éléments de la même séquence
}
