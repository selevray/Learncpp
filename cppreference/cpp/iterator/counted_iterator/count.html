std::counted_iterator<I>::count

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr std::iter_difference_t<I> count() const noexcept;  // (depuis C++20)

Renvoie la longueur sous-jacente, c'est-à-dire la distance jusqu'à la fin.

Paramètres

(aucune)

Valeur de retour

La longueur sous-jacente.

Exemple

#include <cassert>
#include <iostream>
#include <iterator>

int main()
{
    constexpr static auto il = {1, 2, 3, 4, 5};
    constexpr std::counted_iterator i1{il.begin() + 1, 3};
    static_assert(i1.count() == 3);
    auto i2{i1};
    for (; std::default_sentinel != i2; ++i2)
        std::cout << "*i2: " << *i2 << ", count(): " << i2.count() << '\n';
    assert(i2.count() == 0);
}

Output:

*i2: 2, count(): 3
*i2: 3, count(): 2
*i2: 4, count(): 1
