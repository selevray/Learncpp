operator+(std::counted_iterator)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

friend constexpr counted_iterator operator+(
    std::iter_difference_t<I> n, const counted_iterator& x )
        requires std::random_access_iterator<I>;  // (depuis C++20)

Renvoie un adaptateur d'itérateur avancé de n. Le comportement est indéfini si n est supérieur à la longueur enregistrée dans x (c'est-à-dire si x + n entraîne un comportement indéfini).

Cette fonction n'est pas visible par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peut être trouvée que par recherche dépendant des arguments lorsque std::counted_iterator<I> est une classe associée des arguments.

Paramètres

  • n — le nombre de positions dont l'itérateur doit être incrémenté
  • x — l'adaptateur d'itérateur à incrémenter

Valeur de retour

Un adaptateur d'itérateur égal à x + n.

Exemple

#include <iostream>
#include <iterator>
#include <list>
#include <vector>

int main()
{
    std::vector v{0, 1, 2, 3, 4, 5};
    std::counted_iterator<std::vector<int>::iterator> p{v.begin() + 1, 4};
    std::cout << "*p:" << *p << ", count:" << p.count() << '\n';
    std::counted_iterator<std::vector<int>::iterator> q{2 + p};
    std::cout << "*q:" << *q << ", count:" << q.count() << '\n';

    std::list l{6, 7, 8, 9};
    std::counted_iterator<std::list<int>::iterator> r{l.begin(), 3};
    std::cout << "*r:" << *r << ", count:" << r.count() << '\n';
//  auto s{2 + r}; // erreur : l'itérateur sous-jacent ne modélise pas
                   // not model std::random_access_iterator
}

Output:

*p:1, count:4
*q:3, count:2
*r:6, count:3
