Incrémente ou décrémente l'itérateur sous-jacent current et la distance jusqu'à la fin length.

Le comportement de ces fonctions est indéfini si length devait prendre une valeur négative.

  1. Pré-incrémente d'une unité. Équivaut à ++current; --length; return *this;.

  2. Post-incrémente de un. Équivalent à --length; try { return current++; } catch(...) { ++length; throw; }.

  3. Post-incrémente de un. Équivalent à counted_iterator temp{*this}; ++*this; return temp;.

  4. Pré-décrémente de un. Équivalent à --current; ++length; return *this;.

  5. Post-décrémente de un. Équivalent à counted_iterator temp{*this}; --*this; return temp;.

  6. Renvoie un adaptateur d'itérateur avancé de n. Équivalent à return counted_iterator(current + n, length - n);.

  7. Fait avancer l'adaptateur d'itérateur de n. Équivalent à current += n; length -= n; return *this;.

  8. Renvoie un adaptateur d'itérateur avancé de -n. Équivalent à return counted_iterator(current - n, length + n);.

  9. Fait avancer l'adaptateur d'itérateur de -n. Équivalent à current -= n; length += n; return *this;.

Paramètres

  • n — le nombre de positions dont l'adaptateur d'itérateur doit être incrémenté ou décrémenté

Valeur de retour

  1. *this

2,3) Une copie de *this faite avant la modification.

  1. *this

  2. Une copie de *this faite avant la modification.

  3. Un adaptateur d'itérateur avancé de n.

  4. *this

  5. Un adaptateur d'itérateur avancé de -n.

  6. *this

Exemple

#include <cassert>
#include <initializer_list>
#include <iterator>

int main()
{
    const auto v = {1, 2, 3, 4, 5, 6};
    std::counted_iterator<std::initializer_list<int>::iterator> it1{v.begin(), 5};

    ++it1;              assert(*it1 == 2 && it1.count() == 4); // (1)
    auto it2 = it1++;   assert(*it2 == 2 && *it1 == 3);        // (3)
    --it1;              assert(*it1 == 2 && it1.count() == 4); // (4)
    auto it3 = it1--;   assert(*it3 == 2 && *it1 == 1);        // (5)
    auto it4 = it1 + 3; assert(*it4 == 4 && it4.count() == 2); // (6)
    auto it5 = it4 - 3; assert(*it5 == 1 && it5.count() == 5); // (8)
    it1 += 3;           assert(*it1 == 4 && it1.count() == 2); // (7)
    it1 -= 3;           assert(*it1 == 1 && it1.count() == 5); // (9)
}
