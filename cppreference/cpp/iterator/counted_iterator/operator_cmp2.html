operator==(std::counted_iterator<I>, std::default_sentinel_t)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

friend constexpr bool operator==(
    const counted_iterator& x, std::default_sentinel_t );  // (depuis C++20)

Vérifie si la longueur sous-jacente (c'est-à-dire la distance jusqu'à la fin) est égale à 0.

Ce modèle de fonction n'est pas visible par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peut être trouvé que par recherche dépendant des arguments lorsque std::counted_iterator<I> est une classe associée des arguments.

L'opérateur != est synthétisé à partir de operator==.

Paramètres

  • x — un adaptateur d'itérateur

Valeur de retour

true si x.count() est égal à 0, false sinon.

Exemple

#include <initializer_list>
#include <iterator>

int main()
{
    static constexpr auto v = {1, 2, 3, 4};
    constexpr std::counted_iterator<std::initializer_list<int>::iterator>
        it1{v.begin(), 3},
        it2{v.begin(), 0};
    static_assert(it1 != std::default_sentinel);
    static_assert(it2 == std::default_sentinel);
    static_assert(std::default_sentinel != it1);
    static_assert(std::default_sentinel == it2);
}
