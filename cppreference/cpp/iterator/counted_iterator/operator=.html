std::counted_iterator<I>::operator=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class I2 >
    requires std::assignable_from<I&, const I2&>
constexpr counted_iterator& operator=( const counted_iterator<I2>& other );  // (depuis C++20)

L'itérateur sous-jacent et la longueur sont affectés avec ceux de other.

Paramètres

  • other — adaptateur d'itérateur à partir duquel affecter

Valeur de retour

*this

Exemple

#include <algorithm>
#include <cassert>
#include <initializer_list>
#include <iterator>

int main()
{
    auto a = {3, 1, 4, 1, 5, 9, 2};
    std::counted_iterator<std::initializer_list<int>::iterator> p(begin(a), size(a) - 2);
    std::counted_iterator<std::initializer_list<int>::iterator> q;
    assert(q.count() == 0);
    assert(q.count() != p.count());
    q = p;
    assert(q.count() == p.count());
    assert(std::ranges::equal(p, std::default_sentinel, q, std::default_sentinel));
}
