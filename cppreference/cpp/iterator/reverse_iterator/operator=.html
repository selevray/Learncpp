std::reverse_iterator<Iter>::operator=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class U >
reverse_iterator& operator=( const reverse_iterator<U>& other );  // (constexpr depuis C++17)

Affecte other.current à current.

Cette surcharge ne participe à la résolution de surcharge que si std::is_same_v<U, Iter> est false et que std::convertible_to<const U&, Iter> et std::assignable_from<Iter&, const U&> sont modélisés.

(depuis C++20)

Paramètres

  • other — adaptateur d'itérateur à affecter

Valeur de retour

*this

Exemple

#include <iostream>
#include <iterator>

int main()
{
    const int a1[]{0, 1, 2};
    int a2[]{0, 1, 2, 3};
    short a3[]{40, 41, 42};

    std::reverse_iterator<const int*> it1{std::crbegin(a1)};
    it1 = std::reverse_iterator<int*>{std::rbegin(a2)};   // OK
//  it1 = std::reverse_iterator<short*>{std::rbegin(a3)}; // Erreur de compilation :
                                                          // types de pointeurs incompatibles
    std::reverse_iterator<const short*> it2{nullptr};
    it2 = std::rbegin(a3); // OK
//  it2 = std::begin(a3);  // Erreur de compilation : aucune surcharge viable de operator=
    std::cout << *it2 << '\n';
}

Output:

42
