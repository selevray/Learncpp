std::reverse_iterator<Iter>::operator[]

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

/* unspecified */ operator[]( difference_type n ) const;  // (constexpr depuis C++17)

Renvoie une référence à l'élément situé à la position relative indiquée.

Paramètres

  • n — position relative à la position courante

Valeur de retour

current[-n - 1]

Notes

Le type de retour a été modifié par LWG issue 386 pour être non spécifié, car le type de retour de l'operator[] de l'itérateur sous-jacent était également non spécifié à l'époque.

Cependant, depuis N3066, le type de retour d'un LegacyRandomAccessIterator de operator[] doit être convertible en reference. Dans toutes les implémentations courantes, le type de retour est déclaré comme étant reference. Voir aussi LWG issue 2595.

Exemple

#include <array>
#include <cstddef>
#include <iostream>
#include <iterator>
#include <list>
#include <vector>

int main()
{
    int a[]{0, 1, 2, 3};
    std::reverse_iterator<int*> iter1{std::rbegin(a)};
    for (std::size_t i{}; i != std::size(a); ++i)
        std::cout << iter1[i] << ' '; // decltype(iter1[i]) est int&
    std::cout << '\n';

    std::vector v{0, 1, 2, 3};
    std::reverse_iterator<std::vector<int>::iterator> iter2{std::rbegin(v)};
    for (std::size_t i{}; i != std::size(v); ++i)
        std::cout << iter2[i] << ' '; // decltype(iter2[i]) est int&
    std::cout << '\n';

    // contexte constexpr
    constexpr static std::array<int, 4> z{0, 1, 2, 3};
    constexpr std::reverse_iterator<decltype(z)::const_iterator> iter3{std::crbegin(z)};
    static_assert(iter3[1] == 2);

    std::list li{0, 1, 2, 3};
    std::reverse_iterator<std::list<int>::iterator> iter4{std::rbegin(li)};
    *iter4 = 42;   // OK
//  iter4[0] = 13; // Erreur de compilation : l'itérateur sous-jacent
                   // ne modélise pas l'itérateur à accès aléatoire
}

Output:

3 2 1 0
3 2 1 0
