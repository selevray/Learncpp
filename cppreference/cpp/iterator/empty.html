template< class C >
constexpr auto empty( const C& c ) -> decltype(c.empty());  // (1) (depuis C++17)

template< class T, std::size_t N >
constexpr bool empty( const T (&array)[N] ) noexcept;  // (2) (depuis C++17)

template< class E >
constexpr bool empty( std::initializer_list<E> il ) noexcept;  // (3) (depuis C++17)

Retourne si l'intervalle donné est vide.

  1. Renvoie c.empty().

  2. Renvoie false.

  3. Renvoie il.size() == 0.

Paramètres

  • c — un conteneur ou une vue avec une fonction membre empty
  • array — un tableau de type quelconque
  • il — an std::initializer_list

Valeur de retour

  1. c.empty()

  2. false

  3. il.size() == 0

Exceptions

  1. Peut lever des exceptions définies par l'implémentation.

Notes

La surcharge pour std::initializer_list est nécessaire car elle n'a pas de fonction membre empty.

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_nonmember_container_access 201411L (C++17) std::size(), std::data(), and std::empty()

Implémentation possible

Première version

template<class C>
[[nodiscard]] constexpr auto empty(const C& c) -> decltype(c.empty())
{
    return c.empty();
}

Deuxième version

template<class T, std::size_t N>
[[nodiscard]] constexpr bool empty(const T (&array)[N]) noexcept
{
    return false;
}

Troisième version

template<class E>
[[nodiscard]] constexpr bool empty(std::initializer_list<E> il) noexcept
{
    return il.size() == 0;
}

Exemple

#include <iostream>
#include <vector>

template<class T>
void print(const T& container)
{
    if (std::empty(container))
        std::cout << "Empty\n";
    else
    {
        std::cout << "Elements:";
        for (const auto& element : container)
            std::cout << ' ' << element;
        std::cout << '\n';
    }
}

int main()
{
    std::vector<int> c = {1, 2, 3};
    print(c);
    c.clear();
    print(c);

    int array[] = {4, 5, 6};
    print(array);

    auto il = {7, 8, 9};
    print(il);
}

Output:

Elements: 1 2 3
Empty
Elements: 4 5 6
Elements: 7 8 9
