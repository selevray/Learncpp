std::sortable

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iterator>

template< class I, class Comp = ranges::less, class Proj = std::identity >
concept sortable =
    std::permutable<I> &&
    std::indirect_strict_weak_order<Comp, std::projected<I, Proj>>;  // (depuis C++20)

Le concept sortable spécifie les exigences pour les algorithmes qui permutent un intervalle en un intervalle ordonné selon Comp.

Exigences sémantiques

std::sortable<I, Comp, Proj> n'est modélisé que si tous les concepts qu'il subsume sont modélisés.
