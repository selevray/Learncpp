std::ostream_iterator

          class CharT = char,

template< class T,
          class CharT = char,
          class Traits = std::char_traits<CharT> >
class ostream_iterator;  // (depuis C++17)

std::ostream_iterator est un LegacyOutputIterator à passage unique qui écrit successivement des objets de type T dans l'objet std::basic_ostream pour lequel il a été construit, en utilisant operator<<. Une chaîne délimiteur optionnelle est écrite dans le flux de sortie après chaque opération d'écriture. L'opération d'écriture est effectuée lorsque l'itérateur (déréférencé ou non) est affecté. L'incrémentation de std::ostream_iterator ne fait rien.

Dans une implémentation typique, les seuls membres de données de std::ostream_iterator sont un pointeur vers le std::basic_ostream associé et un pointeur vers le premier caractère de la chaîne délimiteur.

Lors de l'écriture de caractères, std::ostreambuf_iterator est plus efficace, car il évite le coût de construction et de destruction de l'objet sentry à chaque caractère.

Exemple

#include <iostream>
#include <iterator>
#include <numeric>
#include <sstream>

int main()
{
    std::istringstream str("0.11 0.22 0.33 0.44");

    std::partial_sum(std::istream_iterator<double>(str),
                     std::istream_iterator<double>(),
                     std::ostream_iterator<double>(std::cout, ", "));
    std::cout << '\n';
}

Output:

0.11, 0.33, 0.66, 1.1,
