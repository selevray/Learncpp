std::indirectly_copyable

Défini dans l'en-tête <iterator>

template< class In, class Out >
concept indirectly_copyable =
    std::indirectly_readable<In> &&
    std::indirectly_writable<Out, std::iter_reference_t<In>>;  // (depuis C++20)

Le concept indirectly_copyable spécifie la relation entre un type indirectly_readable et un type qui est indirectly_writable. Le type indirectly_writable doit pouvoir copier directement l'objet que le type indirectly_readable référence.
