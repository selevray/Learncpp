std::default_sentinel_t, std::default_sentinel

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iterator>

struct default_sentinel_t {};  // (1) (depuis C++20)

inline constexpr default_sentinel_t default_sentinel{};  // (2) (depuis C++20)

  1. default_sentinel_t est un type de classe vide utilisé pour désigner la fin d'un intervalle. Il peut être utilisé avec des types d'itérateurs qui connaissent la borne de leur intervalle (par exemple, std::counted_iterator).

  2. default_sentinel est une constante de type default_sentinel_t.

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>
#include <list>

int main()
{
    std::list<int> l{3, 1, 4, 1, 5, 9, 2, 6};

    std::ranges::copy(std::counted_iterator(std::begin(l), 4),
        std::default_sentinel, std::ostream_iterator<int>{std::cout, " "});
    std::cout << '\n';
}

Output:

3 1 4 1
