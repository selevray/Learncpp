std::ostreambuf_iterator

Défini dans l'en-tête <iterator>

template< class CharT, class Traits = std::char_traits<CharT> >
class ostreambuf_iterator
    : public std::iterator<std::output_iterator_tag, void, void, void, void>  // (jusqu'à C++17)

template< class CharT, class Traits = std::char_traits<CharT> >
class ostreambuf_iterator;  // (depuis C++17)

std::ostreambuf_iterator est un LegacyOutputIterator à passage unique qui écrit successivement des caractères dans l'objet std::basic_streambuf pour lequel il a été construit. L'opération d'écriture effective est réalisée lorsque l'itérateur (déréférencé ou non) est affecté. L'incrémentation de std::ostreambuf_iterator ne fait rien.

Dans une implémentation typique, les seuls membres de données de std::ostreambuf_iterator sont un pointeur vers le std::basic_streambuf associé et un booléen indiquant si la condition de fin de fichier a été atteinte.
