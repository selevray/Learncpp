std::ostreambuf_iterator<CharT,Traits>::ostreambuf_iterator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

ostreambuf_iterator( streambuf_type* buffer ) throw();  // (jusqu'à C++11)

ostreambuf_iterator( streambuf_type* buffer ) noexcept;  // (depuis C++11)

ostreambuf_iterator( ostream_type& stream ) throw();  // (jusqu'à C++11)

ostreambuf_iterator( ostream_type& stream ) noexcept;  // (depuis C++11)

  1. Construit l'itérateur avec le membre privé streambuf_type* défini à buffer et le drapeau failed() défini à false. Le comportement est indéfini si buffer est un pointeur nul.

  2. Identique à ostreambuf_iterator(stream.rdbuf()).

Paramètres

  • stream — le flux de sortie dont rdbuf() sera accédé par cet itérateur
  • buffer — le tampon de flux de sortie auquel cet itérateur accédera

Exemple

#include <fstream>
#include <iostream>
#include <iterator>

int main()
{
    const char* file = "test.txt";
    {
        std::basic_filebuf<char> f;
        f.open(file, std::ios::out);
        std::ostreambuf_iterator<char> out1(&f);
        *out1 = 'a'; // écrit dans le fichier via un itérateur
    }

    // relit depuis le fichier
    char a;
    std::cout << ((std::ifstream{file} >> a), a) << std::endl;

    std::ostreambuf_iterator<wchar_t> out2{std::wcout};
    *out2 = L'b';
}

Output:

a
b
