/* proxy */ operator++( int );  // (2)

Fait avancer l'itérateur en appelant sbuf_->sbumpc() où sbuf_ est le pointeur mémorisé vers le tampon de flux.

Le comportement est indéfini si l'itérateur est l'itérateur de fin de flux.

Paramètres

(aucune)

Valeur de retour

  1. *this

  2. Un objet proxy contenant le caractère courant obtenu via operator*() et le pointeur sbuf_. La déréférenciation d'un objet proxy avec operator* donne le caractère mémorisé.

Le nom proxy est donné à titre explicatif uniquement.

Exceptions

Peut lever des exceptions définies par l'implémentation.
