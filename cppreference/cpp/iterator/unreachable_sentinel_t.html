std::unreachable_sentinel_t, std::unreachable_sentinel

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iterator>

struct unreachable_sentinel_t;  // (1) (depuis C++20)

inline constexpr unreachable_sentinel_t unreachable_sentinel{};  // (2) (depuis C++20)

  1. unreachable_sentinel_t est un type classe vide qui peut être utilisé pour désigner la « borne supérieure » d'un intervalle non borné.

  2. unreachable_sentinel est une constante de type unreachable_sentinel_t.

Fonctions non membres

  • operator== (C++20) — compare un unreachable_sentinel_t avec une valeur de tout weakly_incrementable type (modèle de fonction)

operator==(std::unreachable_sentinel_t)

template<std::weakly_incrementable I>
friend constexpr bool operator==( unreachable_sentinel_t, const I& ) noexcept
{ return false; }  // (depuis C++20)

unreachable_sentinel_t peut être comparé à tout weakly_incrementable type et le résultat est toujours false.

Ce modèle de fonction n'est pas visible par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peut être trouvé que par recherche dépendant des arguments lorsque std::unreachable_sentinel_t est une classe associée des arguments.

Exemple

#include <algorithm>
#include <cstddef>
#include <iostream>
#include <iterator>

template<class CharT>
constexpr std::size_t strlen(const CharT* s)
{
    return std::ranges::find(s, std::unreachable_sentinel, CharT{}) - s;
}

template<class CharT>
constexpr std::size_t find_first(const CharT* haystack, const CharT* needle)
{
    const char* needle_end = needle + strlen(needle);
    // search(begin, unreachable_sentinel) est généralement plus efficace que
    // search(begin, end) grâce à une comparaison de moins par cycle.
    // Mais « needle » DOIT ÊTRE PRÉSENT dans « haystack », sinon l'appel
    // est un comportement indéfini (ce qui constitue une erreur de compilation dans un contexte constexpr).
    auto found = std::ranges::search(haystack, std::unreachable_sentinel,
                                     needle, needle_end);
    return found.begin() - haystack;
}

int main()
{
    static_assert(strlen("The quick brown fox jumps over a lazy dog.") == 42);
    static_assert(find_first("unsigned short int", "short") == 9);
//  static_assert(find_first("long int", "float")); // erreur de compilation
}
