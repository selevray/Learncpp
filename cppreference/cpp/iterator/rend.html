Renvoie un itérateur vers la fin inverse de l'intervalle donné.

1,2) Renvoie c.rend(), qui est généralement un itérateur situé juste après la fin inverse de la séquence représentée par c.

  1. Si C est un Container standard, renvoie un objet C::reverse_iterator.

  2. Si C est un Container standard, renvoie un objet C::const_reverse_iterator.

  3. Renvoie un objet std::reverse_iterator<T*> vers la fin inverse de array.

  4. Renvoie un objet std::reverse_iterator<const T*> vers la fin inverse de il.

  5. Renvoie std::end(c), où c est toujours traité comme qualifié const.

Si C est un Container standard, renvoie un objet C::const_reverse_iterator.

Paramètres

  • c — un conteneur ou une vue disposant d'une fonction membre rend
  • array — un tableau de type quelconque
  • il — an std::initializer_list

Valeur de retour

1,2) c.rend()

  1. std::reverse_iterator<T*>(array)

  2. std::reverse_iterator<const T*>(il.begin())

  3. c.rend()

Exceptions

Peut lever des exceptions définies par l'implémentation.

Surcharges

Des surcharges personnalisées de rend peuvent être fournies pour les classes et énumérations qui n'exposent pas de fonction membre rend() appropriée, mais qui peuvent tout de même être parcourues.

Les surcharges de rend trouvées par recherche dépendante des arguments peuvent être utilisées pour personnaliser le comportement de std::ranges::rend et std::ranges::crend.

(depuis C++20)

Notes

La surcharge pour std::initializer_list est nécessaire car elle n'a pas de fonction membre rend.

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>
#include <vector>

int main()
{
    int a[]{4, 6, -3, 9, 10};
    std::cout << "C-style array `a` backwards: ";
    std::copy(std::rbegin(a), std::rend(a), std::ostream_iterator<int>(std::cout, " "));

    auto il = {3, 1, 4};
    std::cout << "\nstd::initializer_list `il` backwards: ";
    std::copy(std::rbegin(il), std::rend(il), std::ostream_iterator<int>(std::cout, " "));

    std::vector<int> v{4, 6, -3, 9, 10};
    std::cout << "\nstd::vector `v` backwards: ";
    std::copy(std::rbegin(v), std::rend(v), std::ostream_iterator<int>(std::cout, " "));
    std::cout << '\n';
}

Output:

C-style array `a` backwards: 10 9 -3 6 4
std::initializer_list `il` backwards: 4 1 3
std::vector `v` backwards: 10 9 -3 6 4
