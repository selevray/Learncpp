std::iterator_traits

template< class Iter >
struct iterator_traits;

template< class T >
struct iterator_traits<T*>;

template< class T >
struct iterator_traits<const T*>;  // (supprimé en C++20)

std::iterator_traits est la classe de trait de type qui fournit une interface uniforme aux propriétés des types LegacyIterator. Cela permet d'implémenter les algorithmes uniquement en termes d'itérateurs.

Le modèle peut être spécialisé pour des itérateurs définis par l'utilisateur afin que les informations sur l'itérateur puissent être obtenues même si le type ne fournit pas les typedefs habituels.

Les spécialisations utilisateur peuvent définir le type imbriqué iterator_concept comme l'une des balises de catégorie d'itérateur, pour indiquer la conformité aux concepts d'itérateur.

(depuis C++20)

Paramètres de modèle

  • Iter — le type d'itérateur dont on veut obtenir les propriétés

Types membres

Type imbriqué Définition

  • difference_type — Iter::difference_type
  • value_type — Iter::value_type
  • pointer — Iter::pointer
  • reference — Iter::reference
  • iterator_category — Iter::iterator_category

Si Iter n'a aucun des cinq types imbriqués ci-dessus, ce modèle n'a alors aucun membre portant l'un de ces noms (std::iterator_traits est compatible SFINAE).

Spécialisations

Ce trait de type peut être spécialisé pour des types fournis par l'utilisateur pouvant être utilisés comme itérateurs. La bibliothèque standard fournit des spécialisations partielles pour les types pointeurs T*, ce qui permet d'utiliser tous les algorithmes basés sur les itérateurs avec des pointeurs bruts.

La bibliothèque standard fournit également des spécialisations partielles pour certains adaptateurs d'itérateurs standard.

(depuis C++20)

Types imbriqués des spécialisations T*

Seulement spécialisé si std::is_object_v<T> est true.

(depuis C++20)

Type imbriqué Définition

  • difference_type — std::ptrdiff_t
  • value_type — [T (jusqu'à C++20) | std::remove_cv_t<T> (depuis C++20)]
  • pointer — T*
  • reference — T&
  • iterator_category — std::random_access_iterator_tag
  • iterator_concept (depuis C++20) — std::contiguous_iterator_tag

Types imbriqués des spécialisations const T*

Type imbriqué Définition

  • difference_type — std::ptrdiff_t
  • value_type — T
  • pointer — const T*
  • reference — const T&
  • iterator_category — std::random_access_iterator_tag

(jusqu'à C++20)

Spécialisations pour les types de la bibliothèque

  • std::iterator_traits<std::common_iterator> (C++20) — fournit une interface uniforme aux propriétés du type std::common_iterator (spécialisation de modèle de classe)
  • std::iterator_traits<std::counted_iterator> (C++20) — fournit une interface uniforme aux propriétés du type std::counted_iterator (spécialisation de modèle de classe)

Exemple

Montre une implémentation générique de std::reverse() pour les itérateurs bidirectionnels.

#include <iostream>
#include <iterator>
#include <list>
#include <vector>

template<class BidirIt>
void my_reverse(BidirIt first, BidirIt last)
{
    typename std::iterator_traits<BidirIt>::difference_type n = std::distance(first, last);
    for (--n; n > 0; n -= 2)
    {
        typename std::iterator_traits<BidirIt>::value_type tmp = *first;
        *first++ = *--last;
        *last = tmp;
    }
}

int main()
{
    std::vector<int> v{1, 2, 3, 4, 5};
    my_reverse(v.begin(), v.end());
    for (int n : v)
        std::cout << n << ' ';
    std::cout << '\n';

    std::list<int> l{1, 2, 3, 4, 5};
    my_reverse(l.begin(), l.end());
    for (int n : l)
        std::cout << n << ' ';
    std::cout << '\n';

    int a[]{1, 2, 3, 4, 5};
    my_reverse(a, a + std::size(a));
    for (int n : a)
        std::cout << n << ' ';
    std::cout << '\n';

//  std::istreambuf_iterator<char> i1(std::cin), i2;
//  my_reverse(i1, i2); // erreur de compilation : i1, i2 sont des itérateurs d'entrée
}

Output:

5 4 3 2 1
5 4 3 2 1
5 4 3 2 1
