std::indirectly_comparable

Défini dans l'en-tête <iterator>

template< class I1, class I2, class Comp,
          class Proj1 = std::identity, class Proj2 = std::identity >
concept indirectly_comparable =
    std::indirect_binary_predicate<Comp, std::projected<I1, Proj1>, std::projected<I2, Proj2>>;  // (depuis C++20)

Le concept indirectly_comparable spécifie l'exigence fondamentale d'algorithme pour comparer des valeurs entre deux intervalles indépendants.

Exigences sémantiques

indirectly_comparable n'est modélisé que si tous les concepts qu'il subsume sont modélisés.
