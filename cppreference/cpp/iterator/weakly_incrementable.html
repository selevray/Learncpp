std::weakly_incrementable

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iterator>

template< class I >
    concept weakly_incrementable =
        std::movable<I> &&
        requires(I i) {
            typename std::iter_difference_t<I>;
            requires /*is-signed-integer-like*/<std::iter_difference_t<I>>;
            { ++i } -> std::same_as<I&>; // n'est pas tenu d'être préservant l'égalité
            i++;                         // n'est pas tenu d'être préservant l'égalité
        };  // (depuis C++20)

Pour la définition de /*is-signed-integer-like*/, voir is-integer-like ﻿.

Ce concept spécifie les exigences sur les types qui peuvent être incrémentés avec les opérateurs d'incrémentation préfixe et postfixe, mais ces opérations d'incrémentation ne sont pas nécessairement préservant l'égalité, et le type lui-même n'est pas tenu d'être std::equality_comparable.

Pour les types std::weakly_incrementable, a == b n'implique pas que ++a == ++b. Les algorithmes sur les types faiblement incrémentables doivent être des algorithmes à passage unique. Ces algorithmes peuvent être utilisés avec des istream comme source des données d'entrée via std::istream_iterator.

Exigences sémantiques

Pour un objet i de type I, I modélise std::weakly_incrementable seulement si toutes les conditions suivantes sont satisfaites :

  • Les expressions ++i et i++ ont le même domaine.
  • Si i est incrémentable, alors ++i et i++ avancent tous deux i.
  • Si i est incrémentable, alors std::addressof(++i) == std::addressof(i).
