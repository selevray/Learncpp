std::ostream_iterator<T,CharT,Traits>::ostream_iterator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

ostream_iterator( ostream_type& stream, const CharT* delim );  // (1)

ostream_iterator( ostream_type& stream );  // (2)

Construit l'itérateur avec stream comme flux associé, en stockant l'adresse de stream.

  1. Utilise delim comme délimiteur.

  2. Utilise un pointeur nul comme délimiteur.

Paramètres

  • stream — le flux de sortie auquel cet itérateur accède
  • delim — la chaîne de caractères terminée par un caractère nul à insérer dans le flux après chaque sortie

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>
#include <numeric>

int main()
{
    std::ostream_iterator<char> oo{std::cout};
    std::ostream_iterator<int> i1{std::cout, ", "};
    std::fill_n(i1, 5, -1);
    *oo++ = '\n';

    std::ostream_iterator<double> i2{std::cout, "; "};
    *i2++ = 3.14;
    *i2++ = 2.71;
    *oo++ = '\n';

    std::common_iterator<std::counted_iterator<std::ostream_iterator<float>>,
                         std::default_sentinel_t>
        first{std::counted_iterator{std::ostream_iterator<float>{std::cout," ~ "}, 5}},
        last{std::default_sentinel};
    std::iota(first, last, 2.2);
    *oo++ = '\n';
}

Output:

-1, -1, -1, -1, -1,
3.14; 2.71;
2.2 ~ 3.2 ~ 4.2 ~ 5.2 ~ 6.2 ~
