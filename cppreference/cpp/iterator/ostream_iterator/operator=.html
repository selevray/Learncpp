std::ostream_iterator<T,CharT,Traits>::operator=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

ostream_iterator& operator=( const ostream_iterator& );  // (1)

ostream_iterator& operator=( const T& value );  // (2)

  1. Opérateur d'affectation par copie. Affecte le contenu de other

  2. Insère value dans le flux associé, puis insère le délimiteur, s'il a été spécifié à la construction.

Si out_stream est un pointeur vers le std::basic_ostream associé et que delim est le délimiteur spécifié lors de la construction de cet objet, alors l'effet est équivalent à

*out_stream << value; if (delim != 0) *out_stream << delim; return *this;

Paramètres

  • value — l'objet à insérer

Valeur de retour

*this

Notes

T peut être n'importe quelle classe disposant d'un operator<< défini par l'utilisateur.

Avant C++20, l'existence de l'opérateur d'affectation par copie reposait sur la génération implicite obsolète.

Exemple

#include <iostream>
#include <iterator>

int main()
{
    std::ostream_iterator<int> i1(std::cout, ", ");
    *i1++ = 1; // forme usuelle, utilisée par les algorithmes standard
    *++i1 = 2;
    i1 = 3; // ni * ni ++ ne sont nécessaires
    std::ostream_iterator<double> i2(std::cout);
    i2 = 3.14;
    std::cout << '\n';
}

Output:

1, 2, 3, 3.14
