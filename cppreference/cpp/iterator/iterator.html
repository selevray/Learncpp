std::iterator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iterator>

template<
    class Category,
    class T,
    class Distance = std::ptrdiff_t,
    class Pointer = T*,
    class Reference = T&
> struct iterator;  // (obsolète en C++17)

std::iterator est la classe de base fournie pour simplifier la définition des types requis pour les itérateurs.

Paramètres de modèle

  • Category — la catégorie de l'itérateur. Doit être l'une des balises de catégorie d'itérateur.
  • T — le type des valeurs qui peuvent être obtenues en déréférençant l'itérateur. Ce type doit être void pour les itérateurs de sortie.
  • Distance — un type pouvant servir à identifier la distance entre itérateurs
  • Pointer — définit un pointeur vers le type parcouru par l'itérateur (T)
  • Reference — définit une référence vers le type parcouru par l'itérateur (T)

Types membres

Type membre Définition

  • iterator_category — Category
  • value_type — T
  • difference_type — Distance
  • pointer — Pointer
  • reference — Reference

Exemple

L'exemple suivant montre comment implémenter un itérateur d'entrée en héritant de std::iterator

#include <algorithm>
#include <iostream>

template<long FROM, long TO>
class Range
{
public:
    // typedefs membres fournis par héritage de std::iterator
    class iterator : public std::iterator<
                                std::input_iterator_tag, // iterator_category
                                long,                    // value_type
                                long,                    // difference_type
                                const long*,             // pointer
                                long                     // reference
                            > {
        long num = FROM;
    public:
        explicit iterator(long _num = 0) : num(_num) {}
        iterator& operator++() { num = TO >= FROM ? num + 1: num - 1; return *this; }
        iterator operator++(int) { iterator retval = *this; ++(*this); return retval; }
        bool operator==(iterator other) const { return num == other.num; }
        bool operator!=(iterator other) const { return !(*this == other); }
        reference operator*() const { return num; }
    };
    iterator begin() { return iterator(FROM); }
    iterator end() { return iterator(TO >= FROM? TO + 1 : TO - 1); }
};

int main()
{
    // std::find requiert un itérateur d'entrée
    auto range = Range<15, 25>();
    auto itr = std::find(range.begin(), range.end(), 18);
    std::cout << *itr << '\n'; // 18

    // Range::iterator satisfait également les exigences de la boucle for basée sur les intervalles
    for (long l : Range<3, 5>())
        std::cout << l << ' '; // 3 4 5
    std::cout << '\n';
}

Output:

18
3 4 5
