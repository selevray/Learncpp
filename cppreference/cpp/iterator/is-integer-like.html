Type integer-class

Un type T est un type integer-class s'il appartient à un ensemble de types définis par l'implémentation qui se comportent comme le font les types entiers, comme défini ci-dessous. Un type integer-class n'est pas nécessairement un type classe.

Un type integer-class peut représenter (\scriptsize 2^N )2N
entiers consécutifs, où N, un entier positif, est appelé la largeur du type integer-class.

Un type integer-class est soit signé, soit non signé :

  • Un type integer-class signé peut représenter tous les entiers de [(\scriptsize -2^{N-1} )-2N-1
    ,(\scriptsize 2^{N-1}-1 )2N-1
    -1], où N est strictement supérieur à la largeur de chaque type entier signé.
  • Un type integer-class non signé peut représenter tous les entiers de [(\scriptsize 0 )0,(\scriptsize 2^N-1 )2N
    -1], où N est strictement supérieur à la largeur de chaque type entier non signé.

Tous les types integer-class modélisent regular et three_way_comparable<std::strong_ordering>.

Une expression E de type integer-class T est convertible contextuellement en bool comme si elle était faite par bool(E != T(0)).

Type integer-like

Un type autre que (éventuellement qualifié cv) bool est integer-like s'il modélise integral ou s'il est un type integer-class.

  • Un type integer-like est signed-integer-like s'il modélise signed_integral ou s'il est un type signed-integer-class.
  • Un type integer-like est unsigned-integer-like s'il modélise unsigned_integral ou s'il est un type unsigned-integer-class.

Comportements requis

Les expressions de type integer-class sont explicitement convertibles en tout type integer-like, et implicitement convertibles en tout type integer-class de largeur égale ou supérieure et de même signe. Les expressions de type entier sont à la fois implicitement et explicitement convertibles en tout type integer-class. Les conversions entre types entiers et types integer-class, et entre deux types integer-class, ne lèvent pas d'exception. Le résultat d'une telle conversion est l'unique valeur du type destination congrue à la valeur source modulo (\scriptsize 2^N )2N
, où N est la largeur du type destination.

Notons Int<T> le type suivant :

  • Si T est un type integer-class, Int<T> est un type entier étendu hypothétique unique, de même signe et de même largeur que T.
  • Si T est un type entier, notons Int<T> le même type que T.
