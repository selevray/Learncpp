std::move_iterator<Iter>::base

iterator_type base() const;  // (constexpr depuis C++17) (jusqu'à C++20)

constexpr const iterator_type& base() const& noexcept;  // (depuis C++20)

constexpr iterator_type base() &&;  // (2) (depuis C++20)

Renvoie l'itérateur sous-jacent.

  1. Renvoie une [copie de (jusqu'à C++20) | référence vers (depuis C++20)] l'itérateur sous-jacent.

  2. Renvoie un itérateur construit par déplacement à partir de l'itérateur sous-jacent.

Valeur de retour

  1. current

  2. std::move(current ﻿)

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>
#include <vector>

int main()
{
    std::vector<int> v{0, 1, 2, 3, 4};
    std::move_iterator<std::vector<int>::reverse_iterator>
        m1{v.rbegin()},
        m2{v.rend()};

    std::copy(m1.base(), m2.base(), std::ostream_iterator<int>(std::cout, " "));
    std::cout << '\n';
}

Output:

4 3 2 1 0
