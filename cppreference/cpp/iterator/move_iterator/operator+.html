template< class Iter >
move_iterator<Iter> operator+
    ( typename move_iterator<Iter>::difference_type n,
      const move_iterator<Iter>& it );  // (depuis C++11) (constexpr depuis C++17) (jusqu'à C++20)

template< class Iter >
constexpr move_iterator<Iter> operator+
    ( std::iter_difference_t<Iter> n, const move_iterator<Iter>& it );  // (depuis C++20)

Renvoie l'itérateur it incrémenté de n.

Cette surcharge ne participe à la résolution de surcharge que si it.base() + n est bien formé et a le type Iter.

(depuis C++20)

Paramètres

  • n — le nombre de positions dont l'itérateur doit être incrémenté
  • it — l'adaptateur d'itérateur à incrémenter

Valeur de retour

it + n
