Compare les itérateurs sous-jacents de lhs et rhs.

  1. Cette surcharge ne participe à la résolution de surcharge que si lhs.base() == rhs.base() est bien formé et convertible en bool.

3-6) Ces surcharges ne participent à la résolution de surcharge que si lhs.base() < rhs.base() est bien formé et convertible en bool.

L'opérateur != est synthétisé à partir de operator==.

(depuis C++20)

Paramètres

  • lhs, rhs — adaptateurs d'itérateurs à comparer

Valeur de retour

  1. lhs.base() == rhs.base()

  2. !(lhs == rhs)

  3. lhs.base() < rhs.base()

  4. !(rhs < lhs)

  5. rhs < lhs

  6. !(lhs < rhs)

  7. lhs.base() <=> rhs.base()

Exemple

#include <cassert>
#include <iterator>

int main()
{
    int a[]{9, 8, 7, 6};
    //            │  └───── x, y
    //            └──────── z

    // “x” et “y” sont égaux, mais “x” est supérieur à “z”
    std::move_iterator<int*>
        x{std::end(a) - 1},
        y{std::end(a) - 1},
        z{std::end(a) - 2};

    // comparaisons bidirectionnelles
    assert(  x == y );
    assert(!(x != y));
    assert(!(x <  y));
    assert(  x <= y );
    assert(!(x == z));
    assert(  x != z );
    assert(!(x <  z));
    assert(!(x <= z));

    // comparaisons à trois voies
    assert(  x <=> y == 0 );
    assert(!(x <=> y <  0));
    assert(!(x <=> y >  0));
    assert(!(x <=> z == 0));
    assert(!(x <=> z <  0));
    assert(  x <=> z >  0 );
}
