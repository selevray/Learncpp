std::move_iterator<Iter>::operator[]

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

/* unspecified */ operator[]( difference_type n ) const;  // (constexpr depuis C++17) (jusqu'à C++20)

constexpr reference operator[]( difference_type n ) const;  // (depuis C++20)

Renvoie une référence à l'élément situé à la position relative indiquée.

Paramètres

  • n — position relative à la position courante

Valeur de retour

[std::move(current ﻿[n]) (jusqu'à C++20) | ranges::iter_move(current + n) (depuis C++20)]

Notes

Le type de retour est non spécifié car le type de retour de operator[] de l'itérateur sous-jacent est également non spécifié (voir LegacyRandomAccessIterator).

(jusqu'à C++20)

Exemple

#include <cstddef>
#include <iomanip>
#include <iostream>
#include <iterator>
#include <list>
#include <string>
#include <vector>

void print(auto rem, const auto& v)
{
    for (std::cout << rem; const auto& e : v)
        std::cout << std::quoted(e) << ' ';
    std::cout << '\n';
}

int main()
{
    std::vector<std::string> p{"alpha", "beta", "gamma", "delta"}, q;
    print("1) p: ", p);

    std::move_iterator it{p.begin()};

    for (std::size_t t{}; t != p.size(); ++t)
        q.emplace_back(it[t]);

    print("2) p: ", p);
    print("3) q: ", q);

    std::list l{1, 2, 3};
    std::move_iterator it2{l.begin()};
//  it2[1] = 13; // Erreur de compilation : l'itérateur sous-jacent
                 // ne modélise pas l'itérateur à accès aléatoire
//  *it2 = 999;  // Erreur de compilation : utilisation d'une rvalue comme lvalue
}

Sortie possible :

1) p: "alpha" "beta" "gamma" "delta"
2) p: "" "" "" ""
3) q: "alpha" "beta" "gamma" "delta"
