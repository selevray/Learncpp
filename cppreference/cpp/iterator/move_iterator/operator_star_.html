reference operator*() const;  // (1) (depuis C++11) (constexpr depuis C++17)

pointer operator->() const;  // (2) (depuis C++11) (constexpr depuis C++17) (obsolète en C++20)

Renvoie une référence rvalue ou un pointeur vers l'élément courant.

Valeur de retour

  1. [static_cast<reference>(*current ﻿) (jusqu'à C++20) | ranges::iter_move(current ﻿) (depuis C++20)]

  2. current

Notes

operator-> est obsolète car le déréférencement de son résultat peut produire une lvalue. Cela peut entraîner un comportement inattendu.

Exemple

#include <iomanip>
#include <iostream>
#include <iterator>
#include <string>
#include <vector>

void print(auto rem, const auto& v)
{
    for (std::cout << rem; const auto& e : v)
        std::cout << std::quoted(e) << ' ';
    std::cout << '\n';
}

int main()
{
    std::vector<std::string> p{"alpha", "beta", "gamma", "delta"}, q;
    print("1) p: ", p);
    for (std::move_iterator it{p.begin()}, end{p.end()}; it != end; ++it)
    {
        it->push_back('!'); // appelle -> string::push_back(char)
        q.emplace_back(*it); // *it <- surcharge (1)
    }
    print("2) p: ", p);
    print("3) q: ", q);

    std::vector v{1, 2, 3};
    std::move_iterator it{v.begin()};
    // *it = 13; // erreur : utilisation d'une rvalue comme lvalue
}

Sortie possible :

1) p: "alpha" "beta" "gamma" "delta"
2) p: "" "" "" ""
3) q: "alpha!" "beta!" "gamma!" "delta!"
