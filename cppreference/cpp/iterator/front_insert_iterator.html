std::front_insert_iterator

Défini dans l'en-tête <iterator>

template< class Container >
class front_insert_iterator
    : public std::iterator<std::output_iterator_tag, void, void, void, void>  // (jusqu'à C++17)

template< class Container >
class front_insert_iterator;  // (depuis C++17)

std::front_insert_iterator est un LegacyOutputIterator qui insère des éléments au début d'un conteneur pour lequel il a été construit. La fonction membre push_front() du conteneur est appelée chaque fois que l'itérateur (qu'il soit déréférencé ou non) est affecté. L'incrémentation de std::front_insert_iterator n'a aucun effet.

Les types membres iterator_category, value_type, difference_type, pointer et reference doivent être obtenus par héritage de std::iterator<std::output_iterator_tag, void, void, void, void>.

Fonctions membres

  • (constructeur) — construit un nouveau front_insert_iterator (fonction membre publique)
  • operator= — insère un objet dans le conteneur associé (fonction membre publique)
  • operator* — sans opération (fonction membre publique)
  • operator++operator++(int) — sans opération (fonction membre publique)

Exemple

#include <algorithm>
#include <deque>
#include <iostream>
#include <iterator>
#include <vector>

namespace stb
{
    void println(auto, auto const& d)
    {
        std::ranges::copy(d, std::ostream_iterator<int>(std::cout, " "));
        std::cout << '\n';
    }
}

int main()
{
    std::vector<int> v{1, 2, 3, 4, 5};
    std::deque<int> d;

    std::copy(v.begin(), v.end(),
              std::front_insert_iterator<std::deque<int>>(d));
              // ou std::front_inserter(d)

    stb::println("{}", d);
}

Output:

5 4 3 2 1
