std::indirectly_swappable

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iterator>

template< class I1, class I2 = I1 >
concept indirectly_swappable =
    std::indirectly_readable<I1> &&
    std::indirectly_readable<I2> &&
    requires( const I1 i1, const I2 i2 )
    {
        ranges::iter_swap(i1, i1);
        ranges::iter_swap(i1, i2);
        ranges::iter_swap(i2, i1);
        ranges::iter_swap(i2, i2);
    };  // (depuis C++20)

Le concept indirectly_swappable spécifie une relation entre deux types modélisant respectivement std::indirectly_readable, où leurs types référencés peuvent être échangés.

Exigences sémantiques

I1 et I2 modélisent indirectly_swappable uniquement si tous les concepts qu'il subsume sont modélisés.

Préservation de l'égalité

Les expressions déclarées dans les requires expressions des concepts de la bibliothèque standard doivent être préservant l'égalité (sauf mention contraire).
