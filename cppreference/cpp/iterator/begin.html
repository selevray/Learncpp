Renvoie un itérateur vers le début de l'intervalle donné.

1,2) Renvoie c.begin(), qui est généralement un itérateur vers le début de la séquence représentée par c.

  1. Si C est un Container standard, renvoie un objet C::iterator.

  2. Si C est un Container standard, renvoie un objet C::const_iterator.

  3. Renvoie un pointeur vers le début de array.

  4. Renvoie std::begin(c), où c est toujours traité comme qualifié const.

Si C est un Container standard, renvoie un objet C::const_iterator.

Surcharges

Des surcharges personnalisées de begin peuvent être fournies pour les classes et énumérations qui n'exposent pas de fonction membre begin() appropriée, mais qui peuvent tout de même être parcourues. Les surcharges suivantes sont déjà fournies par la bibliothèque standard :

  • std::begin(std::initializer_list) (C++11) — surcharges std::begin (modèle de fonction)
  • std::begin(std::valarray) (C++11) — surcharges std::begin (modèle de fonction)
  • begin(std::filesystem::directory_iterator)end(std::filesystem::directory_iterator) (C++17) — prise en charge de la boucle for basée sur un intervalle (fonction)
  • begin(std::filesystem::recursive_directory_iterator)end(std::filesystem::recursive_directory_iterator) — prise en charge de la boucle for basée sur un intervalle (fonction)

De même que l'usage de swap (décrit dans Swappable), l'usage courant de la fonction begin dans un contexte générique équivaut à using std::begin; begin(arg);, ce qui permet à la fois aux surcharges sélectionnées par ADL pour les types définis par l'utilisateur et aux modèles de fonctions de la bibliothèque standard d'apparaître dans le même ensemble de surcharges.

template<typename Container, typename Function>
void for_each(Container&& cont, Function f)
{
    using std::begin;
    auto it = begin(cont);
    using std::end;
    auto end_it = end(cont);
    while (it != end_it)
    {
        f(*it);
        ++it;
    }
}

Les surcharges de begin trouvées par recherche dépendante des arguments peuvent servir à personnaliser le comportement de std::ranges::begin, std::ranges::cbegin et d'autres objets de point de personnalisation selon std::ranges::begin.

(depuis C++20)

Notes

Les surcharges non tableau reflètent exactement le comportement de C::begin. Leurs effets peuvent être surprenants si la fonction membre n'a pas d'implémentation raisonnable.

std::cbegin est introduit pour unifier l'accès aux intervalles membres et non membres. Voir aussi LWG issue 2128.

Si C est une vue à const superficielle, std::cbegin peut renvoyer un itérateur modifiable. Un tel comportement est inattendu pour certains utilisateurs. Voir aussi P2276 et P2278.

Exemple

#include <iostream>
#include <iterator>
#include <vector>

int main()
{
    std::vector<int> v = {3, 1, 4};
    auto vi = std::begin(v);
    std::cout << std::showpos << *vi << '\n';

    int a[] = {-5, 10, 15};
    auto ai = std::begin(a);
    std::cout << *ai << '\n';
}

Output:

+3
-5
