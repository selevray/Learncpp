Calcule les types associés d'un itérateur.

  1. Calcule le type valeur de T.
  • Si std::iterator_traits<std::remove_cvref_t<T>> n'est pas spécialisé, alors std::iter_value_t<T> est std::indirectly_readable_traits<std::remove_cvref_t<T>>::value_type.
  • Sinon, il est std::iterator_traits<std::remove_cvref_t<T>>::value_type.

  1. Calcule le type référence de T.

  2. Calcule le type de référence const de T.

  3. Calcule le type de différence de T.

  • Si std::iterator_traits<std::remove_cvref_t<T>> n'est pas spécialisé, alors std::iter_difference_t<T> est std::incrementable_traits<std::remove_cvref_t<T>>::difference_type.
  • Sinon, il est std::iterator_traits<std::remove_cvref_t<T>>::difference_type.

  1. Calcule le type de référence rvalue de T. La contrainte sur ce modèle d'alias est satisfaite si et seulement si l'expression ranges::iter_move(std::declval<T&>()) est valide et a un type référençable.

  2. Calcule le type de référence commun de T. C'est le type de référence commun entre son type de référence et une référence lvalue vers son type de valeur.

  3. Le concept dereferenceable réservé à l'exposition est satisfait si et seulement si l'expression *std::declval<T&>() est valide et a un type référençable.

  4. Le modèle d'alias indirect-value-t réservé à l'exposition désigne ce qui suit :

  • std::invoke_result_t<Proj&, /*indirect-value-t*/<I>> si T est identique à std::projected<I, Proj> pour certains types I et Proj.
  • Sinon, std::iter_value_t<T>&.
