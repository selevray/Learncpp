std::projected_value_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iterator>

template< std::indirectly_readable I,
          std::indirectly_regular_unary_invocable<I> Proj >
using projected_value_t =
    std::remove_cvref_t<std::invoke_result_t<Proj&, std::iter_value_t<I>&>>;  // (depuis C++26)

L'alias de modèle projected_value_t obtient le type de valeur en supprimant toute référence et les qualificateurs cv de premier niveau du type de résultat de l'application de Proj à std::iter_value_t<I>&.

projected_value_t est utilisé pour déterminer le type de valeur par défaut dans certains algorithmes, tels que ranges::contains.

Paramètres de modèle

  • I — un type indirectement lisible
  • Proj — projection appliquée à une référence lvalue vers le type de valeur de I
