template< std::sized_sentinel_for<Iter> S >
constexpr difference_type operator-( const S& s ) const;  // (1) (depuis C++23)

template< /*not-a-const-iterator*/ S >
    requires std::sized_sentinel_for<S, Iter>
friend constexpr difference_type
    operator-( const S& s, const basic_const_iterator& i );  // (2) (depuis C++23)

Renvoie la distance entre basic_const_iterator et sa sentinelle.

S satisfait le concept /*not-a-const-iterator*/ réservé à l'exposition si et seulement s'il n'est pas une spécialisation de basic_const_iterator.

Paramètres

  • i, s — itérateur et sentinelle dont on calcule la différence

Valeur de retour

  1. base() - s

  2. s - i.base()
