std::basic_const_iterator<Iter>::operator constant-iterator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< /*not-a-const-iterator*/ CI >
  requires /*constant-iterator*/<CI> &&
      std::convertible_to<Iter const&, CI>
constexpr operator CI() const &;  // (1) (depuis C++23)

template< /*not-a-const-iterator*/ CI >
  requires /*constant-iterator*/<CI> &&
      std::convertible_to<Iter, CI>
constexpr operator CI() &&;  // (2) (depuis C++23)

Renvoie l'itérateur constant converti vers lequel un itérateur sous-jacent current peut être explicitement ou implicitement convertible.

CI satisfait le concept /*not-a-const-iterator*/ réservé à l'exposition si et seulement s'il n'est pas une spécialisation de basic_const_iterator.

Valeur de retour

  1. current

  2. std::move(current)

Exemple

#include <iterator>
#include <ranges>
#include <vector>

void foo(std::vector<int>::const_iterator) {}

int main()
{
    auto v = std::vector<int>();
    {
        // ranges::cbegin ci-dessous renvoie vector<int>::const_iterator
        auto i1 = std::ranges::cbegin(v);
        foo(i1); // okay
    }

    auto t = v | std::views::take_while([](int const x) { return x < 100; });
    {
        // ranges::cbegin ci-dessous renvoie basic_const_iterator<vector<int>::iterator>
        auto i2 = std::ranges::cbegin(t);
        foo(i2); // erreur jusqu'à P2836R1
    }
}
