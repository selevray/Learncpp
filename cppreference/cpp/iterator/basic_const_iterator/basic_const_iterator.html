Construit un nouvel adaptateur d'itérateur.

  1. Constructeur par défaut. L'itérateur sous-jacent est initialisé par valeur.

  2. L'itérateur sous-jacent est initialisé avec std::move(x).

  3. L'itérateur sous-jacent est initialisé avec celui de other.

  4. L'itérateur sous-jacent est initialisé avec std::forward<T>(x).

Paramètres

  • x — itérateur à adapter
  • other — adaptateur d'itérateur à copier
