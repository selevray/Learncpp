constexpr std::iter_const_reference_t<Iter> operator*() const;  // (1) (depuis C++23)

constexpr const auto* operator->() const
    requires std::is_lvalue_reference_v<std::iter_reference_t<Iterator>> &&
        std::same_as<std::remove_cvref_t<std::iter_reference_t<Iterator>>,
                     value_type>;  // (2) (depuis C++23)

Renvoie une référence ou un pointeur vers la version const de l'élément courant.

  1. Renvoie static_cast<std::iter_const_reference_t<Iter>>(*base()).

  2. Si Iter modélise contiguous_iterator, renvoie std::to_address(base()) ; sinon, renvoie std::addressof(*base()).

Paramètres

(aucune)

Valeur de retour

  1. Référence vers const qui désigne l'élément courant. Le résultat peut être une prvalue (par exemple si *base() est une prvalue).

  2. Pointeur vers const qui pointe vers l'élément courant.
