Compare un basic_const_iterator avec une autre valeur.

L'opérateur != est synthétisé à partir de operator==.

I satisfait /*different-from*/<basic_const_iterator> si std::same_as<I, basic_const_iterator<Iter>> est faux.

Paramètres

  • s — une sentinelle pour Iter
  • y — une valeur à comparer

Valeur de retour

  1. base() == s

  2. base() < y.base()

  3. base() > y.base()

  4. base() <= y.base()

  5. base() >= y.base()

  6. base() <=> y.base()

  7. base() < y

  8. base() > y

  9. base() <= y

  10. base() >= y

  11. base() <=> y

Notes

La surcharge (1) peut être utilisée pour comparer deux valeurs basic_const_iterator<Iter> si Iter modélise sentinel_for<Iter>.
