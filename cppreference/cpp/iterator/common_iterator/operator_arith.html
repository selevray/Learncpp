Incrémente l'itérateur sous-jacent.

Le comportement est indéfini si l'objet membre sous-jacent std::variant var ne contient pas d'objet de type I, c'est-à-dire si std::holds_alternative<I>(var) est égal à false.

Soit it désignant l'itérateur de type I détenu par var, c'est-à-dire std::get<I>(var).

  1. Pré-incrémente d'une unité. Équivaut à ++it; return *this;.

  2. Post-incrémente d'une unité :

  • Équivaut à : auto tmp = *this; ++*this; return tmp;, si I modélise forward_iterator.

  • Équivaut à : return it++;, si la définition de variable auto&& ref = *it++; est bien formée, ou bien

    • std::indirectly_readable<I> or
    • std::constructible_from<std::iter_value_t<I>, std::iter_reference_t<I>> or
    • std::move_constructible<std::iter_value_t<I>> is false.

  • Équivaut à : postfix_proxy p(**this); ++*this; return p; sinon, où postfix_proxy est un type auxiliaire réservé à l'exposition (3).

Paramètres

(aucune)

Valeur de retour

  1. *this

  2. Une copie de *this effectuée avant la modification, ou le résultat d'un post-incrément de l'itérateur sous-jacent, ou un proxy conservant la valeur de l'élément courant, comme décrit ci-dessus.

Exemple

#include <algorithm>
#include <initializer_list>
#include <iostream>
#include <iterator>

int main()
{
    const auto il = {1, 2, 3, 4, 5, 6};

    using CI = std::common_iterator<
                   std::counted_iterator<std::initializer_list<int>::iterator>,
                   std::default_sentinel_t
                   >;

    CI first{std::counted_iterator{std::begin(il), std::ssize(il) - 2}};

    for (; first != std::default_sentinel; ++first)
        std::cout << *first << ' ';
    std::cout << '\n';
}

Output:

1 2 3 4
