operator==(std::common_iterator)

    requires std::sentinel_for<S, I2>
friend constexpr bool operator==( const common_iterator& x,
                                  const std::common_iterator<I2, S2>& y );  // (1) (depuis C++20)

template <class I2, std::sentinel_for<I> S2>
    requires std::sentinel_for<S, I2> && std::equality_comparable_with<I, I2>
friend constexpr bool operator==( const common_iterator& x,
                                  const std::common_iterator<I2, S2>& y );  // (2) (depuis C++20)

Compare les itérateurs et/ou sentinelles détenus par les objets membres sous-jacents std::variant var. Deux itérateurs non comparables ou deux sentinelles sont considérés comme égaux.

Le comportement est indéfini si l'un de x ou y est dans un état invalide, c'est-à-dire si x.var.valueless_by_exception() || y.var.valueless_by_exception() est égal à true.

Soit i égal à x.var.index() et j égal à y.var.index().

  1. Si i == j (c'est-à-dire si x et y contiennent tous deux des itérateurs ou tous deux des sentinelles), retourne true, sinon retourne std::get<i>(x.var) == std::get<j>(y.var).

  2. Si i == 1 && j == 1 (c'est-à-dire si x et y contiennent tous deux des sentinelles), retourne true, sinon retourne std::get<i>(x.var) == std::get<j>(y.var).

L'opérateur != est synthétisé à partir de operator==.

Ces modèles de fonction ne sont pas visibles par la recherche non qualifiée ou qualifiée ordinaire, et ne peuvent être trouvés que par recherche dépendante des arguments lorsque std::common_iterator<I> est une classe associée des arguments.

Paramètres

  • x, y — adaptateurs d'itérateurs à comparer

Valeur de retour

true si les itérateurs et/ou sentinelles sous-jacents sont égaux.

Exemple

#include <cassert>
#include <iterator>

int main()
{
    int a[]{0, 1, 2, 3};

    using CI = std::common_iterator<
                   std::counted_iterator<int*>,
                   std::default_sentinel_t
                   >;

    CI i1{std::counted_iterator{a + 0, 2}};
    CI i2{std::counted_iterator{a + 1, 2}};
    CI i3{std::counted_iterator{a + 0, 3}};
    CI i4{std::counted_iterator{a + 0, 0}};
    CI s1{std::default_sentinel};
    CI s2{std::default_sentinel};

    assert((i1 == i2) == true);
    assert((i1 == i3) == false);
    assert((i2 == i3) == false);
    assert((s1 == s2) == true);
    assert((i1 == s1) == false);
    assert((i4 == s1) == true);
}
