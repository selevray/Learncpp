operator-(std::common_iterator)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< std::sized_sentinel_for<I> I2, std::sized_sentinel_for<I> S2 >
    requires std::sized_sentinel_for<S, I2>
friend constexpr std::iter_difference_t<I2>
    operator-( const common_iterator& x, const std::common_iterator<I2, S2>& y );  // (depuis C++20)

Calcule la distance entre deux adaptateurs d'itérateurs. Deux sentinelles sont considérées comme égales.

Soit var désignant l'objet membre sous-jacent std::variant dans std::common_iterator, le comportement est indéfini si l'un de x ou y est invalide, c'est-à-dire si x.var.valueless_by_exception() || y.var.valueless_by_exception() est true.

Ce modèle de fonction n'est pas visible par la recherche non qualifiée ou qualifiée ordinaire, et ne peut être trouvé que par recherche dépendante des arguments lorsque std::common_iterator<I> est une classe associée des arguments.

Paramètres

  • x, y — adaptateurs d'itérateurs dont calculer la différence

Valeur de retour

  • 0 si x.var contient un objet S et y.var contient un objet S2, c'est-à-dire si les deux contiennent une sentinelle.
  • Sinon, alt_x - alt_y, où alt_x et alt_y sont les alternatives contenues respectivement dans x.var et y.var (soit deux itérateurs, soit un itérateur et une sentinelle).

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>

int main()
{
    int a[]{0, 1, 2, 3, 4, 5};

    using CI = std::common_iterator<
                   std::counted_iterator<int*>,
                   std::default_sentinel_t
                   >;

    CI i1{std::counted_iterator{a + 1, 2}};
    CI i2{std::counted_iterator{a, 3}};
    CI s1{std::default_sentinel};
    CI s2{std::default_sentinel};

    std::cout << (s2 - s1) << ' '
              << (i2 - i1) << ' '
              << (i1 - s1) << '\n';
}

Output:

0 -1 -2
