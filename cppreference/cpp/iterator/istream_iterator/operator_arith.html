std::istream_iterator<T,CharT,Traits,Distance>::operator++, operator++(int)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

istream_iterator& operator++();  // (1)

istream_iterator operator++( int );  // (2)

Lit une valeur depuis le flux sous-jacent (en utilisant son operator>>) et la stocke dans l'objet itérateur. Si la lecture échoue (le fail() du flux sous-jacent renvoie true), l'itérateur devient l'itérateur de fin de flux.

Le comportement est indéfini si l'itérateur est l'itérateur de fin de flux.

Paramètres

(aucune)

Valeur de retour

  1. *this

  2. Un istream_iterator qui contient une valeur inchangée.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 260 C++98 le type de retour de operator++(int) était istream_iterator& corrigé en istream_iterator
LWG 788 C++98 le operator void* du flux sous-jacent était utilisé pour déterminer si la lecture échoue, mais il a été supprimé par la résolution du LWG issue 468 utilise fail() à la place
