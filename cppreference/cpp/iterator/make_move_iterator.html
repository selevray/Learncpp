std::make_move_iterator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iterator>

template< class Iter >
std::move_iterator<Iter> make_move_iterator( Iter i );  // (depuis C++11) (constexpr depuis C++17)

make_move_iterator est un modèle de fonction utilitaire qui construit un std::move_iterator pour l'itérateur i donné, avec le type déduit du type de l'argument.

Paramètres

  • i — itérateur d'entrée à convertir en itérateur de déplacement

Valeur de retour

std::move_iterator<Iter>(std::move(i))

Exemple

#include <iomanip>
#include <iostream>
#include <iterator>
#include <list>
#include <string>
#include <vector>

auto print = [](const auto rem, const auto& seq)
{
    for (std::cout << rem; const auto& str : seq)
        std::cout << std::quoted(str) << ' ';
    std::cout << '\n';
};

int main()
{
    std::list<std::string> s{"one", "two", "three"};

    std::vector<std::string> v1(s.begin(), s.end()); // copy

    std::vector<std::string> v2(std::make_move_iterator(s.begin()),
                                std::make_move_iterator(s.end())); // move

    print("v1 now holds: ", v1);
    print("v2 now holds: ", v2);
    print("original list now holds: ", s);
}

Sortie possible :

v1 now holds: "one" "two" "three"
v2 now holds: "one" "two" "three"
original list now holds: "" "" ""
