std::incrementable

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iterator>

template< class I >
    concept incrementable =
        std::regular<I> &&
        std::weakly_incrementable<I> &&
        requires(I i) {
            { i++ } -> std::same_as<I>;
        };  // (depuis C++20)

Ce concept spécifie des exigences sur les types qui peuvent être incrémentés avec les opérateurs d'incrémentation préfixe et postfixe, dont les opérations d'incrémentation sont préservant l'égalité, et le type est std::equality_comparable.

Contrairement aux std::weakly_incrementable, qui ne supportent que les algorithmes à passe unique, les algorithmes unidirectionnels à passes multiples peuvent être utilisés avec des types qui modélisent std::incrementable.

Exigences sémantiques

I modélise std::incrementable seulement si, pour deux objets incrémentables quelconques a et b de type I :

  • bool(a == b) implique bool(a++ == b), et
  • bool(a == b) implique bool(((void)a++, a) == ++b).

Préservation de l'égalité

Les expressions déclarées dans les requires expressions des concepts de la bibliothèque standard doivent être préservant l'égalité (sauf mention contraire).
