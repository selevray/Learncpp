std::indirect_unary_predicate

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iterator>

template< class F, class I >
concept indirect_unary_predicate =
    std::indirectly_readable<I> &&
    std::copy_constructible<F> &&
    std::predicate<F&, /*indirect-value-t*/<I>> &&
    std::predicate<F&, std::iter_reference_t<I>>;  // (depuis C++20)

Le concept indirect_unary_predicate spécifie les exigences pour les algorithmes qui appellent des prédicats unaires comme arguments. La différence essentielle entre ce concept et std::predicate est qu'il s'applique au type que I référence, plutôt qu'à I lui-même.
