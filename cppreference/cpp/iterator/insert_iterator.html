std::insert_iterator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iterator>

template< class Container >
class insert_iterator : public std::iterator<std::output_iterator_tag,
                                             void, void, void, void>  // (jusqu'à C++17)

template< class Container >
class insert_iterator;  // (depuis C++17)

std::insert_iterator est un LegacyOutputIterator qui insère des éléments dans un conteneur pour lequel il a été construit, à la position pointée par l'itérateur fourni. La fonction membre insert() du conteneur est appelée chaque fois que l'itérateur (déréférencé ou non) est affecté. L'incrémentation de std::insert_iterator ne fait rien.

Les types membres iterator_category, value_type, difference_type, pointer et reference doivent être obtenus par héritage de std::iterator<std::output_iterator_tag, void, void, void, void>.

(jusqu'à C++17)

Fonctions membres

  • (constructeur) — construit un nouveau insert_iterator (fonction membre publique)
  • operator= — insère un objet dans le conteneur associé (fonction membre publique)
  • operator* — sans opération (fonction membre publique)
  • operator++operator++(int) — sans opération (fonction membre publique)

Objets membres

Nom du membre Définition

  • container (membre objet protégé) — un pointeur de type Container*
  • iter (membre objet protégé) — un itérateur de type [Container::iterator (jusqu'à C++20) | ranges::iterator_t<Container> (depuis C++20)]

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>
#include <list>
#include <vector>

int main()
{
    std::vector<int> v{1, 2, 3, 4, 5};
    std::list<int> l{-1, -2, -3};
    std::copy(v.begin(), v.end(), // peut être simplifié avec std::inserter
              std::insert_iterator<std::list<int>>(l, std::next(l.begin())));
    for (int n : l)
        std::cout << n << ' ';
    std::cout << '\n';
}

Output:

-1 1 2 3 4 5 -2 -3
