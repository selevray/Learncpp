template< class CharT >
class ctype_byname : public std::ctype<CharT>;

std::ctype_byname est une facette std::ctype qui encapsule les règles de classification des caractères de la locale spécifiée à sa construction.

Spécialisations

La bibliothèque standard garantit de fournir les spécialisations suivantes :

Défini dans l'en-tête <locale>

  • std::ctype_byname<char> — fournit la classification des caractères étroits (utilise une recherche dans une table pour la classification des caractères)
  • std::ctype_byname<wchar_t> — fournit la classification des caractères larges

Construit une nouvelle facette std::ctype_byname pour une locale avec name.

refs sert à la gestion des ressources : si refs == 0, l'implémentation détruit la facette lorsque le dernier objet std::locale qui la détient est détruit. Sinon, l'objet n'est pas détruit.

Notes

std::ctype_byname<char> a été déclarée à tort comme spécialisation explicite dans le synopsis de <locale>, et la déclaration a été supprimée par la résolution du LWG issue 1298, mais elle reste une spécialisation requise, tout comme std::ctype_byname<wchar_t>.

Exemple

#include <iostream>
#include <locale>

int main()
{
    wchar_t c = L'\u00de'; // lettre majuscule thorn

    std::locale loc("C");

    std::cout << "isupper('Þ', C locale) returned "
              << std::boolalpha << std::isupper(c, loc) << '\n';

    loc = std::locale(loc, new std::ctype_byname<wchar_t>("en_US.utf8"));

    std::cout << "isupper('Þ', C locale with Unicode ctype) returned "
              << std::boolalpha << std::isupper(c, loc) << '\n';
}

Output:

isupper('Þ', C locale) returned false
isupper('Þ', C locale with Unicode ctype) returned true
