std::num_put

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

template<
    class CharT,
    class OutputIt = std::ostreambuf_iterator<CharT>
> class num_put;

La classe std::num_put encapsule les règles de formatage des valeurs numériques sous forme de chaînes. Plus précisément, les types bool, long, unsigned long, long long, unsigned long long (depuis C++11), double, long double, void*, ainsi que tous les types implicitement convertibles vers ceux-ci (comme int ou float) sont pris en charge. Les opérateurs de sortie de formatage standard (comme cout << n;) utilisent la facette std::num_put de la locale du flux d'E/S pour générer la représentation textuelle des nombres.

Si une spécialisation de std::num_put n'est pas garantie d'être fournie par la bibliothèque standard (voir ci-dessous), les comportements de ses put() et do_put() ne sont pas garantis tels que spécifiés.

Spécialisations

La bibliothèque standard garantit de fournir les spécialisations suivantes (elles sont requises pour tout objet locale) :

Défini dans l'en-tête <locale>

  • std::num_put<char> — crée des représentations de nombres sous forme de chaînes étroites
  • std::num_put<wchar_t> — crée des représentations de nombres sous forme de chaînes larges

En outre, la bibliothèque standard garantit également de fournir toute spécialisation satisfaisant les exigences de types suivantes :

  • CharT est l'une des suivantes :
    • char,
    • wchar_t, and
    • tout autre type de conteneur de caractères défini par l'implémentation qui satisfait les exigences pour un caractère sur lequel l'un des composants iostream peut être instancié ; et
  • OutputIt doit satisfaire aux exigences de LegacyOutputIterator.

Exemple

#include <iostream>
#include <iterator>
#include <locale>
#include <string>

int main()
{
    double n = 1234567.89;
    std::cout.imbue(std::locale("de_DE.UTF-8"));
    std::cout << "Direct conversion to string:\n"
              << std::to_string(n) << '\n'
              << "Output using a german locale:\n"
              << std::fixed << n << '\n'
              << "Output using an american locale:\n";

    // utiliser directement la facette
    std::cout.imbue(std::locale("en_US.UTF-8"));
    auto& f = std::use_facet<std::num_put<char>>(std::cout.getloc());
    f.put(std::ostreambuf_iterator<char>(std::cout), std::cout, ' ', n);
    std::cout << '\n';
}

Sortie possible :

Direct conversion to string:
1234567.890000
Output using a german locale:
1.234.567,890000
Output using an american locale:
1,234,567.890000
