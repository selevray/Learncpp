Formate une valeur monétaire et écrit le résultat dans le flux de sortie.

1,2) Fonctions membres publiques, appellent la fonction membre do_put de la classe la plus dérivée.

  1. Les arguments numériques units sont convertis en chaîne de caractères larges comme si par ct.widen(buf1, buf1 + std::sprintf(buf1, "%.0Lf", units), buf2), où ct est la facette std::ctype imprégnée dans str.getloc(), et buf1 et buf2 sont des tampons de caractères suffisamment grands. La chaîne de caractères résultante buf2 est traitée, formatée et écrite dans out comme décrit ci-dessous.

  2. De la chaîne argument digits, seul le signe moins initial optionnel (déterminé en le comparant à ct.widen('-'), où ct est la facette std::ctype imprégnée dans str.getloc()) et les chiffres immédiatement suivants (tels que classés par ct) sont retenus comme séquence de caractères à traiter, formater et écrire dans out comme décrit ci-dessous.

Étant donnée la séquence de caractères issue des étapes précédentes, si le premier caractère est égal à ct.widen('-'), appelle mp.neg_format() pour obtenir le pattern de formatage ; sinon, appelle mp.pos_format(), où mp est la facette std::moneypunct<CharT, intl> imprégnée dans str.getloc().

Les séparateurs de milliers et les caractères de point décimal sont insérés selon les besoins de mp.grouping(), mp.frac_digits(), mp.decimal_point() et mp.thousands_sep(), et la chaîne résultante est placée dans la séquence de sortie à l'endroit où value apparaît dans le motif de formatage.

Si str.flags() & str.showbase est non nul (le manipulateur std::showbase a été utilisé), alors le symbole ou la chaîne de devise est généré en appelant mp.curr_symbol() et placé dans la séquence de sortie à l'endroit où symbol apparaît dans le motif de formatage.

Si mp.positive_sign() (dans le cas où le motif de formatage positif est utilisé) ou mp.negative_sign() (dans le cas où le motif de formatage négatif est utilisé) renvoie une chaîne de plus d'un caractère, le premier caractère renvoyé est placé dans la séquence de sortie à l'endroit où sign apparaît dans le motif de formatage, et les autres caractères sont placés après tous les autres caractères ; par exemple, le motif de formatage {sign, value, space, symbol} avec les unités 123 et un negative_sign valant "-" peut produire "-1.23 €", tandis qu'un negative_sign valant "()" produirait "(1.23 €)".

Si le nombre de caractères générés pour le format spécifié est inférieur à la valeur renvoyée par str.width(), alors des copies de fill sont insérées pour porter la longueur totale de la séquence de sortie à exactement str.width(), comme suit :

  • Si str.flags() & str.adjustfield est égal à str.internal, les caractères de remplissage sont insérés à l'endroit où none ou space apparaît dans le motif de formatage.
  • Sinon, si str.flags() & str.adjustfield est égal à str.left, les copies de fill sont ajoutées après tous les autres caractères.
  • Sinon, les caractères de remplissage sont placés avant tous les autres caractères.

Enfin, appelle str.width(0) pour annuler les effets de tout std::setw.

Valeur de retour

Un itérateur pointant immédiatement après le dernier caractère produit.

Notes

Les unités monétaires sont supposées être les plus petites unités non fractionnaires de la devise : des cents aux États-Unis, des yens au Japon.

Exemple

#include <iomanip>
#include <iostream>
#include <locale>

struct my_punct : std::moneypunct_byname<char, false>
{
    my_punct(const char* name) : moneypunct_byname(name) {}
    string_type do_negative_sign() const { return "()"; }
};

int main()
{
    std::locale loc("ru_RU.utf8");
    std::cout.imbue(loc);
    long double units = -123.45;
    std::cout << "In Russian locale, " << units << " prints as " << std::showbase;

    // remarque : ce qui suit est équivalent à simplement std::put_money(units)
    std::use_facet<std::money_put<char>>(loc).put(
        {std::cout}, false, std::cout, std::cout.fill(), units);
    std::cout << '\n';

    std::cout.imbue(std::locale(std::cout.getloc(), new my_punct("ru_RU.utf8")));
    std::cout << "With negative_sign set to \"()\", it prints as ";
    std::use_facet<std::money_put<char>>(loc).put(
        {std::cout}, false, std::cout, std::cout.fill(), units);
    std::cout << '\n';
}

Output:

In Russian locale, -123,45 prints as -1.23 руб
With negative_sign set to "()", it prints as (1.23 руб)
