std::money_put<CharT,OutputIt>::~money_put

Défini dans l'en-tête <locale>

protected: ~money_put();

Détruit une facette std::money_put. Ce destructeur est protégé et virtuel (en raison du destructeur de la classe de base qui est virtuel). Un objet de type std::money_put, comme la plupart des facettes, ne peut être détruit que lorsque le dernier objet std::locale qui implémente cette facette sort de sa portée, ou si une classe définie par l'utilisateur dérive de std::money_put et déclare un destructeur public.

Exemple

#include <iostream>
#include <locale>

struct Destructible_money_put : public std::money_put<wchar_t>
{
    Destructible_money_put(std::size_t refs = 0) : money_put(refs) {}
    // remarque : le destructeur implicite est public
};

int main()
{
    Destructible_money_put dc;
    // std::money_put<wchar_t> c; // erreur de compilation : destructeur protégé
}
