std::codecvt_mode

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <codecvt>

enum codecvt_mode {
    consume_header = 4,
    generate_header = 2,
    little_endian = 1
};  // (depuis C++11) (obsolète en C++17) (supprimé en C++26)

Les facettes std::codecvt_utf8, std::codecvt_utf16 et std::codecvt_utf8_utf16 acceptent comme argument de modèle une valeur optionnelle de type std::codecvt_mode, qui précise des fonctionnalités optionnelles de la conversion de chaînes Unicode.

Constantes

Défini dans l'en-tête <locale>

Valeur Signification

  • little_endian — supposer que l'entrée est en ordre d'octets little-endian (s'applique uniquement à l'entrée UTF-16, la valeur par défaut est big-endian)
  • consume_header — consommer la marque d'ordre des octets, si elle est présente au début de la séquence d'entrée, et (dans le cas de UTF-16) utiliser l'ordre d'octets qu'elle indique pour décoder le reste de l'entrée
  • generate_header — écrire la marque d'ordre des octets au début de la séquence de sortie

Les marques d'ordre des octets reconnues sont :

  • 0xfe 0xff — UTF-16 big-endian
  • 0xff 0xfe — UTF-16 little-endian
  • 0xef 0xbb 0xbf — UTF-8 (sans effet sur l'ordre des octets)

Si std::consume_header n'est pas sélectionné lors de la lecture d'un fichier commençant par une marque d'ordre des octets, le caractère Unicode U+FEFF (espace insécable de largeur nulle) sera lu comme premier caractère du contenu de la chaîne.

Exemple

L'exemple suivant montre la consommation du BOM UTF-8 :

#include <codecvt>
#include <cwchar>
#include <fstream>
#include <iostream>
#include <locale>
#include <string>

int main()
{
    // données UTF-8 avec BOM
    std::ofstream{"text.txt"} << "\ufeffz\u6c34\U0001d10b";

    // lire le fichier UTF-8 en ignorant le BOM
    std::wifstream fin{"text.txt"};
    fin.imbue(std::locale(fin.getloc(),
                          new std::codecvt_utf8<wchar_t, 0x10ffff, std::consume_header>));

    for (wchar_t c; fin.get(c);)
        std::cout << std::hex << std::showbase << (std::wint_t)c << '\n';
}

Output:

0x7a
0x6c34
0x1d10b
