std::num_get

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

template<
    class CharT,
    class InputIt = std::istreambuf_iterator<CharT>
> class num_get;

La classe std::num_get encapsule les règles d'analyse des représentations textuelles de valeurs numériques. Plus précisément, les types bool, unsigned short, unsigned int, long, unsigned long, long long, unsigned long long (depuis C++11), float, double, long double et void* sont pris en charge. Les opérateurs d'entrée formatée standard (tels que cin >> n;) utilisent la facette std::num_get de la locale du flux d'E/S pour analyser les représentations textuelles des nombres.

Si une spécialisation de std::num_get n'est pas garantie d'être fournie par la bibliothèque standard (voir ci-dessous), les comportements de ses get() et do_get() ne sont pas garantis tels que spécifiés.

Spécialisations

La bibliothèque standard garantit de fournir les spécialisations suivantes (elles sont requises pour tout objet locale) :

Défini dans l'en-tête <locale>

  • std::num_get<char> — crée l'analyse de nombres à partir de chaînes de caractères étroits
  • std::num_get<wchar_t> — crée l'analyse de nombres à partir de chaînes de caractères larges

En outre, la bibliothèque standard garantit également de fournir toute spécialisation satisfaisant les exigences de types suivantes :

  • CharT est l'une des suivantes :
    • char,
    • wchar_t, and
    • tout autre type de conteneur de caractères défini par l'implémentation qui satisfait les exigences pour un caractère sur lequel l'un des composants iostream peut être instancié ; et
  • InputIt doit satisfaire aux exigences de LegacyInputIterator.

Exemple

#include <iostream>
#include <iterator>
#include <locale>
#include <sstream>
#include <string>

int main()
{
    std::string de_double = "1.234.567,89";
    std::string us_double = "1,234,567.89";

    // analyser à l'aide de flux
    std::istringstream de_in(de_double);
    de_in.imbue(std::locale("de_DE.UTF-8"));
    double f1;
    de_in >> f1;

    std::istringstream us_in(de_double);
    us_in.imbue(std::locale("en_US.UTF-8"));
    double f2;
    us_in >> f2;

    std::cout << "Parsing " << de_double << " as double gives " << std::fixed
              << f1 << " in de_DE locale and " << f2 << " in en_US\n";

    // utiliser directement la facette
    std::istringstream s3(us_double);
    s3.imbue(std::locale("en_US.UTF-8"));

    auto& f = std::use_facet<std::num_get<char>>(s3.getloc());
    std::istreambuf_iterator<char> beg(s3), end;
    double f3;
    std::ios::iostate err;
    f.get(beg, end, s3, err, f3);

    std::cout << "parsing " << us_double
              << " as double using raw en_US facet gives " << f3 << '\n';
}

Output:

Parsing 1.234.567,89 as double gives 1234567.890000 in de_DE locale and 1.234000 in en_US
parsing 1,234,567.89 as double using raw en_US facet gives 1234567.890000

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 427 C++98 num_get devait garantir l'acceptation de tout CharT qui satisfait les exigences pour un caractère sur lequel l'un des composants iostream peut être instancié garantit uniquement d'accepter char, wchar_t et d'autres types de caractères définis par l'implémentation
