template< class CharT >
class numpunct_byname : public std::numpunct<CharT>;

std::numpunct_byname est une facette std::numpunct qui encapsule les préférences de ponctuation numérique d'une locale spécifiée à sa construction.

Spécialisations

La bibliothèque standard garantit de fournir les spécialisations suivantes :

Défini dans l'en-tête <locale>

  • std::numpunct_byname<char> — facette std::numpunct spécifique à la locale pour les E/S de caractères étroits
  • std::numpunct_byname<wchar_t> — facette std::numpunct spécifique à la locale pour les E/S de caractères larges

Construit une nouvelle facette std::numpunct_byname pour une locale avec name.

refs sert à la gestion des ressources : si refs == 0, l'implémentation détruit la facette lorsque le dernier objet std::locale qui la détient est détruit. Sinon, l'objet n'est pas détruit.

Exemple

Cet exemple montre comment appliquer les règles de ponctuation numérique d'une autre langue sans modifier le reste de la locale.

#include <iostream>
#include <locale>

int main()
{
    const double number = 1000.25;
    std::wcout << L"default locale: " << number << L'\n';
    std::wcout.imbue(std::locale(std::wcout.getloc(),
                                 new std::numpunct_byname<wchar_t>("ru_RU.UTF8")));
    std::wcout << L"default locale with russian numpunct: " << number << L'\n';
}

Output:

default locale: 1000.25
default locale with russian numpunct: 1 000,25
