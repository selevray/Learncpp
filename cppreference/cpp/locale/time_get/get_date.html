public:
iter_type get_date( iter_type beg, iter_type end, std::ios_base& str,
                    std::ios_base::iostate& err, std::tm* t ) const;  // (1)

protected:
virtual iter_type do_get_date( iter_type beg, iter_type end, std::ios_base& str,

  1. Fonction membre publique, appelle la fonction membre virtuelle protégée do_get_date de la classe la plus dérivée.

  2. Lit successivement les caractères de la séquence [beg,end) et analyse la valeur de date du calendrier selon le format par défaut attendu par cette locale, déterminé comme

date_order() Format
no_order "%m/%d/%y"
dmy "%d/%m/%y"
mdy "%m/%d/%y"
ymd "%y/%m/%d"
ydm "%y/%d/%m"

tel qu'utilisé par les fonctions std::get_time(), get(), et la fonction POSIX strptime().

La date analysée est stockée dans les champs correspondants de la structure std::tm pointée par l'argument t.

Si l'itérateur de fin est atteint avant qu'une date valide ait été lue, la fonction définit std::ios_base::eofbit dans err. Si une erreur d'analyse survient, la fonction définit std::ios_base::failbit dans err.

Paramètres

  • beg — itérateur désignant le début de la séquence à analyser
  • end — itérateur de fin, pointant juste après la fin de la séquence à analyser
  • str — un objet flux que cette fonction utilise pour obtenir les facettes de locale lorsque nécessaire, par exemple std::ctype pour ignorer les espaces ou std::collate pour comparer des chaînes
  • err — objet d'indicateurs d'erreur du flux, modifié par cette fonction pour signaler les erreurs
  • t — pointeur vers l'objet std::tm qui contiendra le résultat de cet appel de fonction

Valeur de retour

Itérateur pointant juste après le dernier caractère de [beg,end) qui a été reconnu comme faisant partie d'une date valide.

Notes

Pour les composantes alphabétiques du format de date par défaut (le cas échéant), cette fonction est généralement insensible à la casse.

En cas d'erreur d'analyse, la plupart des implémentations de cette fonction laissent *t inchangé.

L'implémentation peut prendre en charge d'autres formats de date en plus de ceux exigés par la norme.

Exemple

#include <ctime>
#include <iostream>
#include <iterator>
#include <locale>
#include <sstream>

void try_get_date(const std::string& s)
{
    std::cout << "Parsing the date out of '" << s
              << "' in the locale " << std::locale().name() << '\n';
    std::istringstream str(s);
    std::ios_base::iostate err = std::ios_base::goodbit;

    std::tm t;
    const std::time_get<char>& facet = std::use_facet<std::time_get<char>>(str.getloc());
    std::istreambuf_iterator<char> ret = facet.get_date({str}, {}, str, err, &t);
    str.setstate(err);

    if (str)
    {
        std::cout << "Day: " << t.tm_mday << ' '
                  << "Month: " << t.tm_mon + 1 << ' '
                  << "Year: " << t.tm_year + 1900 << '\n';
    }
    else
    {
        std::cout << "Parse failed. Unparsed string: ";
        std::copy(ret, {}, std::ostreambuf_iterator<char>(std::cout));
        std::cout << '\n';
    }
}
int main()
{
    std::locale::global(std::locale("en_US.utf8"));
    try_get_date("02/01/2013");
    try_get_date("02-01-2013");

    std::locale::global(std::locale("ja_JP.utf8"));
    try_get_date("2013年02月01日");
}

Output:

Parsing the date out of '02/01/2013' in the locale en_US.utf8
Day: 1 Month: 2 Year: 2013
Parsing the date out of '02-01-2013' in the locale en_US.utf8
Parse failed. Unparsed string: -01-2013
Parsing the date out of '2013年02月01日' in the locale ja_JP.utf8
Day: 1 Month: 2 Year: 2013
