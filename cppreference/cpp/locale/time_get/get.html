  1. Analyse la date et l'heure à partir de la séquence de caractères d'entrée [beg, end) selon le format fourni dans la séquence de caractères [fmtbeg, fmtend). Le format doit suivre le format décrit ci-dessous, bien que le traitement effectif de chaque spécificateur de format puisse être personnalisé en redéfinissant do_get. La fonction get effectue les opérations suivantes : d'abord, elle efface les bits d'erreur de err en exécutant err = std::ios_base::goodbit. Puis elle entre dans une boucle, qui se termine dès qu'une des conditions suivantes devient vraie (vérifiées dans cet ordre) :

a) Tous les caractères ont été lus depuis la chaîne de format (fmtbeg == fmtend).

b) Une erreur d'analyse s'est produite (err != std::ios_base::goodbit).

c) Tous les caractères ont été lus depuis la séquence d'entrée (beg == end. Si cette condition termine la boucle, la fonction définit à la fois eofbit et failbit dans err.

Dans le corps de la boucle, les étapes suivantes ont lieu :

a) Si le caractère suivant de la chaîne de format est '%', suivi d'un ou deux caractères formant un spécificateur de conversion std::get_time valide (voir ci-dessous), ces caractères sont utilisés dans l'appel do_get(beg, end, str, err, t, format, modifier), où format est le caractère de spécificateur de conversion principal et modifier est le modificateur facultatif (qui apparaît entre % et le caractère de format, s'il est présent). S'il n'y a pas de modificateur, la valeur '\0' est utilisée. Si la chaîne de format est ambiguë ou se termine trop tôt pour déterminer le spécificateur de conversion après '%', eofbit est défini dans err et la boucle se termine. Si, après l'appel à do_get, aucun bit d'erreur n'est défini dans err, la fonction incrémente fmtbeg pour pointer juste après le spécificateur de conversion et continue la boucle.

b) Si le caractère suivant est un espace, tel qu'indiqué par la locale fournie dans le flux str (c.-à-d. std::isspace(*fmtbeg, str.getloc()) == true), la fonction continue d'incrémenter fmtbeg jusqu'à ce qu'il soit égal à fmtend ou pointe vers un caractère qui n'est pas un espace.

c) Si le caractère suivant de la chaîne de format est équivalent au caractère suivant du flux d'entrée selon une comparaison insensible à la casse, la fonction avance les deux séquences d'un caractère ++fmtbeg, ++beg; et continue la boucle. Sinon, elle définit failbit dans err.

  1. Analyse un spécificateur de conversion à partir de la séquence d'entrée [beg, end) et met à jour la structure std::tm pointée par t en conséquence.

Tout d'abord, elle efface les bits d'erreur de err en exécutant err = std::ios_base::goodbit. Puis elle lit des caractères de la séquence d'entrée [beg, end) attendus par le spécificateur de format std::time_get formé en combinant '%', modifier (si ce n'est pas '\0') et format. Si les caractères ne forment pas un spécificateur de conversion valide, elle définit failbit dans err. Si la fin du flux d'entrée est atteinte après la lecture d'un caractère, elle définit eofbit dans err. Si la chaîne d'entrée a été analysée avec succès, elle met à jour les champs correspondants de *t.Pour les spécificateurs de conversion complexes, tels que '%x' ou '%c', ou les directives utilisant les modificateurs 'E' et 'O', la fonction peut ne pas parvenir à déterminer certaines valeurs à stocker dans *t. Dans ce cas, elle définit eofbit dans err et laisse ces champs dans un état non spécifié.

Paramètres

  • beg — itérateur désignant le début de la séquence à analyser
  • end — itérateur de fin, pointant juste après la fin de la séquence à analyser
  • str — un objet flux que cette fonction utilise pour obtenir les facettes de locale lorsque nécessaire, par exemple std::ctype pour ignorer les espaces ou std::collate pour comparer des chaînes
  • err — objet d'indicateurs d'erreur du flux, modifié par cette fonction pour signaler les erreurs
  • t — pointeur vers l'objet std::tm qui contiendra le résultat de cet appel de fonction
  • fmtbeg — pointeur vers le premier caractère d'une séquence de char_type caractères spécifiant le format de conversion (voir ci-dessous)
  • fmtend — pointeur vers l'emplacement juste après le dernier caractère d'une séquence de char_type caractères spécifiant le format de conversion
  • format — le caractère qui désigne un spécificateur de conversion
  • modifier — le modificateur facultatif qui peut apparaître entre % et le spécificateur de conversion

La chaîne de format est composée de zéro ou plusieurs spécificateurs de conversion, de caractères d'espacement et de caractères ordinaires (à l'exception de %). Chaque caractère ordinaire doit correspondre à un caractère du flux d'entrée selon une comparaison insensible à la casse. Chaque caractère d'espacement correspond à un espace arbitraire dans la chaîne d'entrée. Chaque spécification de conversion commence par %, suivi optionnellement de E ou O comme modificateur (ignoré si non pris en charge par la locale), suivi du caractère qui détermine le comportement du spécificateur. Les spécificateurs de format correspondent à la fonction POSIX strptime() :

Valeur de retour

Itérateur pointant juste après le dernier caractère de [beg, end) qui a été analysé avec succès.

Notes

La comparaison insensible à la casse des caractères qui ne sont ni des espaces ni '%' dans la chaîne de format utilise généralement, mais pas nécessairement, la facette std::collate de la locale fournie par str.

En cas d'erreur d'analyse, de nombreuses implémentations de cette fonction laissent *t totalement intact.

Il n'est pas spécifié si ces fonctions remettent à zéro les champs de *t qu'elles ne définissent pas directement : les programmes portables doivent initialiser chaque champ à zéro avant d'appeler get().

Exemple

#include <iomanip>
#include <iostream>
#include <locale>
#include <sstream>

int main()
{
    std::istringstream ss("2026-März-12 23:45:56");
    ss.imbue(std::locale("de_DE.utf8"));

    auto& f = std::use_facet<std::time_get<char>>(ss.getloc());
    std::tm t{};
    std::string s = "%Y-%b-%d %H:%M:%S";
    std::ios_base::iostate err = std::ios_base::goodbit;
    auto ret = f.get({ss}, {}, ss, err, &t, &s[0], &s[0] + s.size());
    ss.setstate(err);
    std::istreambuf_iterator<char> last{};

    if (ss)
    {
        std::cout << "Successfully parsed as " << std::put_time(&t, "%c") << '\n';
        if (ret != last)
        {
            std::cout << "Remaining content: ";
            std::copy(ret, last, std::ostreambuf_iterator<char>(std::cout));
        }
        else
            std::cout << "The input was fully consumed.";
    }
    else
    {
        std::cout << "Parse failed.\nUnparsed string: ";
        std::copy(ret, last, std::ostreambuf_iterator<char>(std::cout));
    }
    std::cout << '\n';
}

Output:

Successfully parsed as Sun Mar 12 23:45:56 2026
The input was fully consumed.
