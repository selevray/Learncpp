std::ctype<char>

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

template<>
class ctype<char>;

Cette spécialisation de std::ctype encapsule les fonctionnalités de classification de caractères pour le type char. Contrairement à std::ctype à usage général, qui utilise des fonctions virtuelles, cette spécialisation utilise une recherche dans une table pour classer les caractères (ce qui est généralement plus rapide).

La classe de base std::ctype<char> implémente une classification de caractères équivalente à la locale "C" minimale. Les règles de classification peuvent être étendues ou modifiées si elle est construite avec un argument de table de classification non par défaut, si elle est construite comme std::ctype_byname<char> ou comme facette dérivée définie par l'utilisateur. Toutes les fonctions membres formatées d'entrée de std::istream doivent utiliser std::ctype<char> pour la classification des caractères lors de l'analyse de l'entrée.

Exemple

L'exemple suivant montre comment modifier ctype<char> pour découper des valeurs séparées par des virgules en jetons :

#include <cstddef>
#include <iostream>
#include <locale>
#include <sstream>
#include <vector>

// Cette facette ctype classe les virgules et les fins de ligne comme espaces blancs
struct csv_whitespace : std::ctype<char>
{
    static const mask* make_table()
    {
        // faire une copie de la table de la locale "C"
        static std::vector<mask> v(classic_table(), classic_table() + table_size);
        v[','] |=  space; // comma sera classé comme espace blanc
        v[' '] &= ~space; // l'espace ne sera pas classé comme espace blanc
        return &v[0];
    }

    csv_whitespace(std::size_t refs = 0) : ctype(make_table(), false, refs) {}
};

int main()
{
    std::string in = "Column 1,Column 2,Column 3\n123,456,789";
    std::string token;

    std::cout << "Default locale:\n";
    std::istringstream s1(in);
    while (s1 >> token)
        std::cout << "  " << token << '\n';

    std::cout << "Locale with modified ctype:\n";
    std::istringstream s2(in);
    s2.imbue(std::locale(s2.getloc(), new csv_whitespace));
    while (s2 >> token)
        std::cout << "  " << token << '\n';
}

Output:

Default locale:
  Column
  1,Column
  2,Column
  3
  123,456,789
Locale with modified ctype:
  Column 1
  Column 2
  Column 3
  123
  456
  789
