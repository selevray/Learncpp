std::wstring_convert

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

template<
    class Codecvt,
    class Elem = wchar_t,
    class Wide_alloc = std::allocator<Elem>,
    class Byte_alloc = std::allocator<char>
> class wstring_convert;  // (depuis C++11) (obsolète en C++17) (supprimé en C++26)

Le modèle de classe std::wstring_convert effectue des conversions entre la chaîne d'octets std::string et la chaîne large std::basic_string<Elem>, en utilisant une facette de conversion de code individuelle Codecvt. std::wstring_convert prend la propriété de la facette de conversion et ne peut pas utiliser une facette gérée par une locale.

Les facettes standard utilisables avec std::wstring_convert sont std::codecvt_utf8 pour les conversions UTF-8/UCS-2 et UTF-8/UCS-4, et std::codecvt_utf8_utf16 pour les conversions UTF-8/UTF-16.
