std::money_put

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

template<
    class CharT,
    class OutputIt = std::ostreambuf_iterator<CharT>
> class money_put;

La classe std::money_put encapsule les règles de formatage des valeurs monétaires sous forme de chaînes. Le manipulateur d'E/S standard std::put_money utilise la facette std::money_put de la locale du flux d'E/S.

Diagramme d'héritage

Si une spécialisation de std::money_put n'est pas garantie d'être fournie par la bibliothèque standard (voir ci-dessous), les comportements de ses put() et do_put() ne sont pas garantis tels que spécifiés.

Spécialisations

La bibliothèque standard garantit de fournir les spécialisations suivantes (elles sont requises pour tout objet locale) :

Défini dans l'en-tête <locale>

  • std::money_put<char> — crée des représentations en chaînes étroites des valeurs monétaires
  • std::money_put<wchar_t> — crée des représentations en chaînes larges des valeurs monétaires

En outre, la bibliothèque standard garantit également de fournir toute spécialisation satisfaisant les exigences de types suivantes :

  • CharT est l'une des suivantes :
    • char,
    • wchar_t, and
    • tout autre type de conteneur de caractères défini par l'implémentation qui satisfait les exigences pour un caractère sur lequel l'un des composants iostream peut être instancié ; et
  • OutputIt doit satisfaire aux exigences de LegacyOutputIterator.

  • iter_type — OutputIt

  • put — invoque do_put (fonction membre publique)

Fonctions membres protégées

  • do_put [virtuelle] — formate une valeur monétaire et écrit dans le flux de sortie (fonction membre protégée virtuelle)

Exemple

#include <iomanip>
#include <iostream>
#include <iterator>
#include <locale>

int main()
{
    // en utilisant le manipulateur d'E/S
    std::cout.imbue(std::locale("en_US.UTF-8"));
    std::cout << "American locale: "
              << std::showbase << std::put_money(12345678.9) << '\n';

    // en utilisant directement la facette
    std::cout.imbue(std::locale("de_DE.UTF-8"));
    std::cout << "German locale: ";
    auto& f = std::use_facet<std::money_put<char>>(std::cout.getloc());
    f.put({std::cout}, false, std::cout, std::cout.fill(), 12345678.9);
    std::cout << '\n';
}

Output:

American locale: $123,456.79
German locale: 123.456,79 €

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 427 C++98 money_put devait garantir l'acceptation de tout CharT qui satisfait les exigences pour un caractère sur lequel l'un des composants iostream peut être instancié garantit uniquement d'accepter char, wchar_t et d'autres types de caractères définis par l'implémentation
LWG 2392 C++98 seul le type de caractère CharT pouvait être garanti comme accepté par money_put peut garantir d'accepter des types de conteneurs de caractères défini par l'implémentation
