std::setlocale

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <clocale>

char* setlocale( int category, const char* locale );

La fonction setlocale installe la locale système spécifiée ou une partie de celle-ci comme nouvelle locale C. Les modifications restent en vigueur et influencent l'exécution de toutes les fonctions de la bibliothèque C sensibles à la locale jusqu'au prochain appel à setlocale. Si locale est un pointeur nul, setlocale interroge la locale C courante sans la modifier.

Paramètres

  • category — identifiant de catégorie de locale, l'une des macros LC_xxx. Peut valoir 0.
  • locale — identifiant de locale propre au système. Peut être "" pour la locale préférée de l'utilisateur ou "C" pour la locale minimale

Valeur de retour

Pointeur vers une chaîne étroite terminée par un caractère nul identifiant la locale C après application des modifications, le cas échéant, ou pointeur nul en cas d'échec.

Une copie de la chaîne renvoyée ainsi que la catégorie utilisée dans cet appel à std::setlocale peut être utilisée ultérieurement dans le programme pour restaurer la locale à l'état qu'elle avait à la fin de cet appel.

Notes

Au démarrage du programme, l'équivalent de std::setlocale(LC_ALL, "C"); est exécuté avant l'exécution de tout code utilisateur.

Bien que le type de retour soit char*, modifier les caractères pointés est un comportement indéfini.

Comme setlocale modifie un état global qui affecte l'exécution des fonctions dépendantes de la locale, il est un comportement indéfini de l'appeler depuis un thread pendant qu'un autre thread exécute l'une des fonctions suivantes : std::fprintf, std::isprint, std::iswdigit, std::localeconv, std::tolower, std::fscanf, std::ispunct, std::iswgraph, std::mblen, std::toupper, std::isalnum, std::isspace, std::iswlower, std::mbstowcs, std::towlower, std::isalpha, std::isupper, std::iswprint, std::mbtowc, std::towupper, std::isblank, std::iswalnum, std::iswpunct, std::setlocale, std::wcscoll, std::iscntrl, std::iswalpha, std::iswspace, std::strcoll, std::wcstod, std::isdigit, std::iswblank, std::iswupper, std::strerror, std::wcstombs, std::isgraph, std::iswcntrl, std::iswxdigit, std::strtod, std::wcsxfrm, std::islower, std::iswctype, std::isxdigit.

POSIX définit aussi une locale nommée "POSIX", toujours accessible, qui est exactement équivalente à la locale "C" minimale par défaut.

POSIX précise également que le pointeur renvoyé, et pas seulement le contenu de la chaîne pointée, peut être invalidé par des appels ultérieurs à setlocale.

Exemple

#include <clocale>
#include <cstdio>
#include <ctime>
#include <cwchar>
#include <iterator>
#include <string>

int main()
{
    // Effectuer une « copie profonde » du nom de la locale courante.
    std::string prev_loc = std::setlocale(LC_ALL, nullptr);

    // La locale C sera l'anglais avec prise en charge d'UTF-8,
    // le point décimal sera allemand,
    // le formatage des dates et heures sera japonais.
    if (const char* loc = std::setlocale(LC_ALL, "en_US.UTF-8"))
        std::wprintf(L"New LC_ALL locale: %s\n", loc);
    if (const char* loc = std::setlocale(LC_NUMERIC, "de_DE.UTF-8"))
        std::wprintf(L"New LC_NUMERIC locale: %s\n", loc);
    if (const char* loc = std::setlocale(LC_TIME, "ja_JP.UTF-8"))
        std::wprintf(L"New LC_TIME locale: %s\n", loc);

    wchar_t buf[100];
    std::time_t t = std::time(nullptr);
    std::wcsftime(buf, std::size(buf), L"%A %c", std::localtime(&t));
    std::wprintf(L"Number: %.2f\nDate: %Ls\n", 3.14, buf);

    // Restaurer la locale précédente.
    if (const char* loc = std::setlocale(LC_ALL, prev_loc.c_str()))
        std::wprintf(L"Restorred LC_ALL locale: %s\n", loc);
}

New LC_NUMERIC locale: de_DE.UTF-8

Date: 日曜日 2022年11月06日 20時40分59秒
