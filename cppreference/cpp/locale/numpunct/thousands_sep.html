std::numpunct<CharT>::thousands_sep, do_thousands_sep

Défini dans l'en-tête <locale>

public:
char_type thousands_sep() const;  // (1)

protected:
virtual char_type do_thousands_sep() const;  // (2)

  1. Fonction membre publique, appelle la fonction membre do_thousands_sep de la classe la plus dérivée.

  2. Renvoie le caractère à utiliser comme séparateur entre les groupes de chiffres lors de l'analyse ou du formatage des entiers et des parties entières des valeurs à virgule flottante.

Valeur de retour

L'objet de type char_type à utiliser comme séparateur des milliers. Les spécialisations standard de std::numpunct renvoient ',' et L','.

Exemple

#include <iostream>
#include <locale>

struct space_out : std::numpunct<char>
{
    char do_thousands_sep()   const { return ' '; }  // séparer avec des espaces
    std::string do_grouping() const { return "\1"; } // groupes de 1 chiffre
};

int main()
{
    std::cout << "default locale: " << 12345678 << '\n';
    std::cout.imbue(std::locale(std::cout.getloc(), new space_out));
    std::cout << "locale with modified numpunct: " << 12345678 << '\n';
}

Output:

default locale: 12345678
locale with modified numpunct: 1 2 3 4 5 6 7 8
