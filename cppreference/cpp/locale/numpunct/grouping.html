public:
std::string grouping() const;  // (1)

protected:
virtual std::string do_grouping() const;  // (2)

  1. Fonction membre publique, appelle la fonction membre do_grouping de la classe la plus dérivée.

  2. Renvoie un std::string contenant, dans chaque élément char, le nombre de chiffres de chaque groupe de la sortie numérique formatée par num_put::put() (et donc par basic_ostream::operator<<).

Cette fonction renvoie une chaîne, vec, utilisée comme un vecteur de valeurs entières. (Par exemple, "\003" spécifie des groupes de 3 chiffres chacun, tandis que "3" implique des groupes de 51 chiffres chacun.). Chaque élément vec[i] représente le nombre de chiffres du ie groupe de chiffres de la partie entière du nombre, en comptant depuis la droite : vec[0] contient le nombre de chiffres du groupe le plus à droite, vec[1] celui du deuxième groupe depuis la droite, etc. Le regroupement indiqué par le dernier caractère, vec[vec.size()-1], est réutilisé de façon répétée pour regrouper tous les chiffres restants de la partie (gauche) du nombre. Si vec[i] est négatif ou nul ou égal à CHAR_MAX, la taille du groupe de chiffres correspondant est illimitée.

Valeur de retour

L'objet de type std::string contenant les groupes. Les spécialisations standard de std::numpunct renvoient une chaîne vide, indiquant l'absence de regroupement. Les regroupements typiques (par exemple la locale en_US) renvoient "\003".

Exemple

#include <iostream>
#include <limits>
#include <locale>

struct space_out : std::numpunct<char>
{
    char do_thousands_sep()   const { return ' ';  } // séparer avec des espaces
    std::string do_grouping() const { return "\1"; } // groupes de 1 chiffre
};

struct g123 : std::numpunct<char>
{
    std::string do_grouping() const { return "\1\2\3"; }
};

int main()
{
    std::cout << "Default locale: " << 12345678 << '\n';
    std::cout.imbue(std::locale(std::cout.getloc(), new space_out));
    std::cout << "Locale with modified numpunct: " << 12345678 << '\n';
    std::cout.imbue(std::locale(std::cout.getloc(), new g123));
    std::cout << "Locale with \\1\\2\\3 grouping: "
              << std::numeric_limits<unsigned long long>::max() << '\n'
              << "Same, for a floating-point number: "
              << std::fixed << 123456789.123456789 << '\n';
}

Output:

Default locale: 12345678
Locale with modified numpunct: 1 2 3 4 5 6 7 8
Locale with \1\2\3 grouping: 18,446,744,073,709,551,61,5
Same, for a floating-point number: 123,456,78,9.123457
