std::numpunct<CharT>::truename, do_truename, falsename, do_falsename

public:

virtual string_type do_truename() const;  // (3)

protected:
virtual string_type do_falsename() const;  // (4)

1,2) Fonction membre publique, appelle respectivement la fonction membre do_truename et do_falsename de la classe la plus dérivée.

  1. Renvoie la chaîne à utiliser comme représentation de la valeur booléenne true.

  2. Renvoie la chaîne à utiliser comme représentation de la valeur booléenne false.

Valeur de retour

1,3) L'objet de type string_type à utiliser comme représentation de true. Les spécialisations standard de std::numpunct renvoient "true" et L"true".

2,4) L'objet de type string_type à utiliser comme représentation de false. Les spécialisations standard de std::numpunct renvoient "false" et L"false".

Exemple

#include <iomanip>
#include <iostream>
#include <locale>

struct custom_tf : std::numpunct<char>
{
    std::string do_truename()  const { return {'t'}; }
    std::string do_falsename() const { return {'f'}; }
};

int main()
{
    std::cout << std::boolalpha;

    // sortie booléenne par défaut
    std::cout << "Default locale,\n"
                 "  boolalpha  true: " << true << "\n"
                 "  boolalpha false: " << false << "\n\n";

    // avec custom_tf appliqué à la locale
    std::cout.imbue(std::locale(std::cout.getloc(), new custom_tf));
    std::cout << "Locale with modified numpunct,\n"
                 "  boolalpha  true: " << true << "\n"
                 "  boolalpha false: " << false << '\n';
}

Output:

Default locale,
  boolalpha  true: true
  boolalpha false: false

Locale with modified numpunct,
  boolalpha  true: t
  boolalpha false: f
