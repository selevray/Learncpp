std::money_get

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

template<
    class CharT,
    class InputIt = std::istreambuf_iterator<CharT>
> class money_get;

Le modèle de classe std::money_get encapsule les règles d'analyse des valeurs monétaires à partir de flux de caractères. Le manipulateur d'E/S standard std::get_money utilise la facette std::money_get de la locale du flux d'E/S.

Diagramme d'héritage

Si une spécialisation de std::money_get n'est pas garantie d'être fournie par la bibliothèque standard (voir ci-dessous), les comportements de ses get() et do_get() ne sont pas garantis tels que spécifiés.

Spécialisations

La bibliothèque standard garantit de fournir les spécialisations suivantes (elles sont requises pour tout objet locale) :

Défini dans l'en-tête <locale>

  • std::money_get<char> — analyse les représentations en chaînes étroites des valeurs monétaires
  • std::money_get<wchar_t> — analyse les représentations en chaînes larges des valeurs monétaires

En outre, la bibliothèque standard garantit également de fournir toute spécialisation satisfaisant les exigences de types suivantes :

  • CharT est l'une des suivantes :
    • char,
    • wchar_t, and
    • tout autre type de conteneur de caractères défini par l'implémentation qui satisfait les exigences pour un caractère sur lequel l'un des composants iostream peut être instancié ; et
  • InputIt doit satisfaire aux exigences de LegacyInputIterator.

Exemple

#include <iomanip>
#include <iostream>
#include <iterator>
#include <locale>
#include <sstream>

int main()
{
    std::string str = "$1.11 $2.22 $3.33";
    std::cout << std::fixed << std::setprecision(2);

    std::cout << '\"' << str << "\" parsed with the I/O manipulator: ";
    std::istringstream s1(str);
    s1.imbue(std::locale("en_US.UTF-8"));

    long double val;
    while (s1 >> std::get_money(val))
        std::cout << val / 100 << ' ';
    std::cout << '\n';

    str = "USD  1,234.56";
    std::cout << '\"' << str << "\" parsed with the facet directly: ";
    std::istringstream s2(str);
    s2.imbue(std::locale("en_US.UTF-8"));

    auto& f = std::use_facet<std::money_get<char>>(s2.getloc());
    std::ios_base::iostate err;
    std::istreambuf_iterator<char> beg(s2), end;
    f.get(beg, end, true, s2, err, val);

    std::cout << val / 100 << '\n';
}

Output:

"$1.11 $2.22 $3.33" parsed with the I/O manipulator: 1.11 2.22 3.33
"USD  1,234.56" parsed with the facet directly: 1234.56

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 427 C++98 money_get devait garantir l'acceptation de tout CharT qui satisfait les exigences pour un caractère sur lequel l'un des composants iostream peut être instancié garantit uniquement d'accepter char, wchar_t et d'autres types de caractères définis par l'implémentation
LWG 2392 C++98 seul le type de caractère CharT pouvait être garanti comme accepté par money_get peut garantir d'accepter des types de conteneurs de caractères défini par l'implémentation
