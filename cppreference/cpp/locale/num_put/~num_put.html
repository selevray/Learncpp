std::num_put<CharT,OutputIt>::~num_put

Défini dans l'en-tête <locale>

protected: ~num_put();

Détruit une facette std::num_put. Ce destructeur est protégé et virtuel (en raison du destructeur de la classe de base qui est virtuel). Un objet de type std::num_put, comme la plupart des facettes, ne peut être détruit que lorsque le dernier objet std::locale qui implémente cette facette sort de sa portée, ou si une classe définie par l'utilisateur dérive de std::num_put et déclare un destructeur public.

Exemple

#include <iostream>
#include <locale>

struct Destructible_num_put : public std::num_put<wchar_t>
{
    Destructible_num_put(std::size_t refs = 0) : num_put(refs) {}
    // remarque : le destructeur implicite est public
};

int main()
{
    Destructible_num_put dc;
    // std::num_put<wchar_t> c; // erreur de compilation : destructeur protégé
}
