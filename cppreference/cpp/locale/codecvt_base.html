class codecvt_base;

La classe std::codecvt_base fournit les constantes d'état de conversion qui sont héritées et utilisées par les facettes std::codecvt.

Types membres

Type membre Définition

  • enum result { ok, partial, error, noconv }; — Type énuméré non scopé

Valeur Explication

  • ok — la conversion s'est terminée sans erreur
  • partial — tous les caractères source n'ont pas été convertis
  • error — a rencontré un caractère invalide
  • noconv — aucune conversion requise, les types d'entrée et de sortie sont identiques

Notes

La valeur std::codecvt_base::partial est utilisée pour indiquer que soit la plage de destination est trop courte pour recevoir les résultats de la conversion, soit l'entrée est tronquée au milieu d'un caractère multioctet par ailleurs valide.
