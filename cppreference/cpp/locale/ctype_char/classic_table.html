static const mask* classic_table() noexcept;  // (depuis C++11)

Renvoie la table de classification correspondant à la classification utilisée par la locale « C » minimale.

Paramètres

(aucune)

Valeur de retour

Un pointeur vers le premier élément de la table de classification (qui est un tableau de taille std::ctype<char>::table_size).

Notes

Les facettes std::ctype<char> construites par défaut utilisent cette table pour la classification.
