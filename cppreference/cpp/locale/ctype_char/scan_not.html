std::ctype<char>::scan_not

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

const char* scan_not( mask m, const char* beg, const char* end ) const;

Localise le premier caractère du tableau de caractères [beg,end) qui ne satisfait pas le masque de classification m, c'est-à-dire le premier caractère c tel que table()[(unsigned char)c] & m renverrait false.

Si (unsigned char)c >= std::ctype<char>::table_size, alors une valeur définie par l'implémentation est substituée à table()[(unsigned char)c], éventuellement différente selon les valeurs de c.

Paramètres

  • m — masque à rechercher
  • beg — pointeur vers le premier caractère d'un tableau de caractères dans lequel effectuer la recherche
  • end — pointeur vers la fin (un au-delà du dernier élément) du tableau de caractères dans lequel effectuer la recherche

Valeur de retour

Pointeur vers le premier caractère de [beg,end) qui ne satisfait pas le masque, ou end si aucun caractère de ce type n'a été trouvé.

Notes

Contrairement au modèle primaire std::ctype, cette spécialisation n'effectue pas d'appel de fonction virtuelle lors de la classification des caractères. Pour personnaliser le comportement, une classe dérivée peut fournir une table de classification non par défaut au constructeur de la classe de base.

Exemple

#include <iostream>
#include <iterator>
#include <locale>

int main()
{
    auto& f = std::use_facet<std::ctype<char>>(std::locale());

    // ignore les espaces de début
    char s1[] = "      \t\t\n  Test";
    const char* p1 = f.scan_not(std::ctype_base::space, std::begin(s1), std::end(s1));
    std::cout << '\'' << p1 << "'\n";

    // ignore les chiffres de début
    char s2[] = "123456789abcd";
    const char* p2 = f.scan_not(std::ctype_base::digit, std::begin(s2), std::end(s2));
    std::cout << '\'' << p2 << "'\n";
}

Output:

'Test'
'abcd'
