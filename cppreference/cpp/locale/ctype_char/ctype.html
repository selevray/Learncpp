std::ctype<char>::ctype

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

explicit ctype( const mask* tbl = 0, bool del = false, std::size_t refs = 0);

Crée une facette std::ctype<char> et transmet le compteur de références initial refs au constructeur de la classe de base, locale::facet::facet().

Si tbl est nul, classic_table() est utilisée par toutes les fonctions membres de classification. Sinon, tbl doit être un pointeur vers le premier élément d'un tableau de masques, d'une taille d'au moins std::ctype<char>::table_size, et ce tableau est utilisé par toutes les fonctions membres de classification de cette facette.

Si del est true, on suppose que le tableau a été alloué avec new[], et le destructeur de cette facette appellera delete[] tbl.

Paramètres

  • tbl — table de classification à utiliser ou pointeur nul
  • del — indicateur précisant si la table doit être supprimée
  • refs — compteur de références initial
