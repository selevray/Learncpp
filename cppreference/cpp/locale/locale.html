std::locale

Défini dans l'en-tête <locale>

class locale;

Un objet de la classe std::locale est un ensemble indexé immuable de facettes immuables. Chaque objet de flux de la bibliothèque d'entrée/sortie C++ est associé à un objet std::locale et utilise ses facettes pour l'analyse et le formatage de toutes les données. De plus, un objet locale est associé à chaque objet std::basic_regex. (depuis C++11) Les objets locale peuvent aussi servir de prédicats effectuant la collation de chaînes avec les conteneurs et algorithmes standard, et leurs facettes peuvent être consultées directement pour être obtenues ou modifiées.

Chaque locale construite dans un programme C++ contient au moins les facettes standard suivantes (c.-à-d. std::has_facet renvoie true pour tous ces types de facettes), mais un programme peut définir des spécialisations supplémentaires ou de nouvelles facettes et les ajouter à n'importe quel objet locale existant.

En interne, un objet locale est implémenté comme s'il s'agissait d'un pointeur à compteur de références vers un tableau (indexé par std::locale::id) de pointeurs à compteurs de références vers des facettes : copier une locale ne copie qu'un pointeur et incrémente plusieurs compteurs de références. Pour maintenir les garanties de sécurité des threads de la bibliothèque standard C++ (les opérations sur des objets différents sont toujours sûres vis-à-vis des threads), le compteur de références de la locale et celui de chaque facette sont mis à jour de manière sûre vis-à-vis des threads, de façon similaire à std::shared_ptr.

Types membres

Type Description

  • id — le type d'index de facette : chaque classe de facette doit déclarer ou hériter d'un membre statique public de ce type (classe)
  • facet — la classe de base de toutes les catégories de facettes : chaque facette de n'importe quelle catégorie dérive de ce type (classe)
  • category — int (typedef)

Les fonctions membres std::locale acceptant un argument category exigent l'une des valeurs de catégorie définies ci-dessus, ou l'union de deux ou plusieurs de ces valeurs. Les constantes LC ne sont pas acceptées.

Fonctions membres

  • (constructeur) — construit une nouvelle locale (fonction membre publique)
  • (destructeur) — détruit la locale et les facettes dont le compteur de références atteint zéro (fonction membre publique)
  • operator= — remplace une locale (fonction membre publique)
  • combine — construit une locale avec une facette identifiée à la compilation, copiée depuis une autre locale (fonction membre publique)
  • name — renvoie le nom de la locale ou "*" si elle est sans nom (fonction membre publique)
  • encoding (C++26) — renvoie le codage de caractères associé à la locale (fonction membre publique)
  • operator==operator!= (removed in C++20) — comparaison d'égalité entre objets locale (fonction membre publique)
  • operator() — compare lexicographiquement deux chaînes à l'aide de la facette collate de cette locale (fonction membre publique)
  • global [statique] — modifie la locale globale (fonction membre statique publique)
  • classic [statique] — obtient une référence à la locale « C » (fonction membre statique publique)

Exemple

Montre le prologue typique d'un programme sensible aux paramètres régionaux (multiplateforme).

#include <iostream>
#include <locale>

int main()
{
    std::wcout << L"User-preferred locale setting is "
               << std::locale("").name().c_str() << L'\n';
    // au démarrage, la locale globale est la locale « C »
    std::wcout << 1000.01 << L'\n';

    // remplace le paramètre régional global C++ et le paramètre régional « C » par le paramètre régional préféré de l'utilisateur
    std::locale::global(std::locale(""));
    // utilise le nouveau paramètre régional global pour les futures sorties de caractères larges
    std::wcout.imbue(std::locale());

    // affiche à nouveau le même nombre
    std::wcout << 1000.01 << L'\n';
}
