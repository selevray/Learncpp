Analyse une valeur monétaire depuis un itérateur d'entrée et écrit le résultat dans un long double ou une chaîne.

1,2) Fonctions membres publiques, appellent la fonction membre do_get de la classe la plus dérivée.

3,4) Lit des caractères depuis l'itérateur d'entrée beg, en s'attendant à trouver une valeur monétaire formatée selon les règles spécifiées par la facette std::ctype imprégnée dans str.getloc() (ct pour le reste de cette page), la facette std::moneypunct<CharT, intl> imprégnée dans str.getloc() (mp pour le reste de cette page), et les indicateurs de formatage du flux obtenus depuis str.flags().

Si l'itérateur d'entrée beg devient égal à end avant la fin de l'analyse, définit à la fois failbit et eofbit dans err. Si l'analyse échoue pour une autre raison, définit failbit dans err. Dans les deux cas, ne modifie pas le paramètre de sortie (units ou digits) en cas d'erreur.

Si l'analyse réussit, ne modifie pas err et stocke le résultat dans units ou digits.

Le pattern de formatage utilisé par cette fonction est toujours mp.neg_format().

Si mp.grouping() n'autorise pas les séparateurs de milliers, le premier séparateur rencontré est traité comme une erreur d'analyse ; sinon ils sont traités comme facultatifs.

Si money_base::space ou money_base::none est le dernier élément de pattern, l'analyseur ne tente pas de consommer d'espaces blancs après l'analyse des autres composantes de la valeur monétaire. Sinon, un ou plusieurs caractères d'espacement sont consommés à l'endroit où money_base::space apparaît.

Si l'indicateur showbase est défini dans str.flags(), le symbole monétaire ou la chaîne monétaire est requis ; sinon, le symbole monétaire est facultatif.

Si le premier caractère de la chaîne retournée par mp.positive_sign() ou mp.negative_sign() est trouvé à la position money_base::sign du motif de formatage, il est consommé, et les autres caractères de cette chaîne sont attendus et consommés après toutes les autres composantes de la valeur monétaire. Si mp.positive_sign() et mp.negative_sign() sont toutes deux non vides, le signe est requis et doit correspondre au premier caractère de l'une de ces chaînes. Si l'une de ces chaînes est vide, le signe est facultatif (et s'il est absent, le signe du résultat correspond à la chaîne vide). Si les deux chaînes sont vides, ou ont le même premier caractère, le résultat reçoit le signe positif. Si le paramètre de sortie est une chaîne (digits) et que le résultat est négatif, la valeur ct.widen('-') est stockée comme premier caractère du résultat.

Les chiffres de l'entrée sont extraits dans l'ordre où ils apparaissent et sont placés dans digits (après élargissement par ct.widen() si nécessaire), ou dans un tampon temporaire buf1, à partir duquel la valeur de units est construite comme si par

static const char src[] = "0123456789-";
CharT atoms[sizeof(src)];
ct.widen(src, src + sizeof(src) - 1, atoms);
for (int i = 0; i < n; ++i)
buf2[i] = src[find(atoms, atoms+sizeof(src), buf1[i]) - atoms];
buf2[n] = 0;
sscanf(buf2, "%Lf", &units);

(où n est le nombre de caractères extraits de l'entrée et stockés dans buf1, et buf2 est un autre tampon de caractères suffisamment grand).

Valeur de retour

Un itérateur pointant immédiatement après le dernier caractère reconnu comme partie valide de la chaîne monétaire en entrée.

Notes

Les unités monétaires sont supposées être les plus petites unités non fractionnaires de la devise : les cents aux États-Unis, les yens au Japon. Ainsi, la séquence d'entrée "$1,056.23" dans un paramètre régional américain produit le nombre 105623.0 dans units ou une chaîne "105623" dans digits.

Comme le symbole monétaire est optionnel si showbase est désactivé, alors que la negative_sign() multicaractère complète est obligatoire ; avec le motif de formatage {sign, value, space, symbol}, showbase désactivé et negative_sign valant "-", la chaîne "-1.23 €" est analysée comme -123 et laisse "€" non consommé dans le flux d'entrée ; mais si negative_sign vaut "()", la chaîne "(1.23 €)" est entièrement consommée.

Le manipulateur d'E/S std::get_money offre une interface plus simple pour cette fonction.

Exemple

#include <iostream>
#include <locale>
#include <sstream>

void demo_money_get(std::locale loc, const std::string& input)
{
    std::istringstream str(input);
    str.imbue(loc);
    long double units;

    // Le code suivant peut être écrit plus simplement avec std::get_money(units)
    std::ios_base::iostate err = std::ios_base::goodbit;
    std::istreambuf_iterator<char> ret =
        std::use_facet<std::money_get<char>>(loc).get(
            std::istreambuf_iterator<char>(str),
            std::istreambuf_iterator<char>(),
            false, str, err, units);
    str.setstate(err);
    std::istreambuf_iterator<char> last{};
    if (str)
    {
        std::cout << "Successfully parsed '" << str.str() << "' as "
                  << units / 100 << " units\n";
        if (ret != last)
        {
            std::cout << "Remaining content: '";
            std::copy(ret, last, std::ostreambuf_iterator<char>(std::cout));
            std::cout << "'\n";
        }
        else
            std::cout << "The input was fully consumed\n";
    }
    else
    {
        std::cout << "Parse failed. Unparsed string: '";
        std::copy(ret, last, std::ostreambuf_iterator<char>(std::cout));
        std::cout << "'\n";
    }
}

int main()
{
    demo_money_get(std::locale("en_US.utf8"), "-$5.12 abc");
    demo_money_get(std::locale("ms_MY.utf8"), "(RM5.12) def");
}

Output:

Successfully parsed '-$5.12 abc' as -5.12 units
Remaining content: ' abc'
Successfully parsed '(RM5.12) def' as -5.12 units
Remaining content: ' def'
