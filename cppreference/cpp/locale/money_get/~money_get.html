std::money_get<CharT,InputIt>::~money_get

Défini dans l'en-tête <locale>

protected: ~money_get();

Détruit une facette std::money_get. Ce destructeur est protégé et virtuel (en raison du destructeur de la classe de base qui est virtuel). Un objet de type std::money_get, comme la plupart des facettes, ne peut être détruit que lorsque le dernier objet std::locale qui implémente cette facette sort de sa portée, ou si une classe définie par l'utilisateur dérive de std::money_get et déclare un destructeur public.

Exemple

#include <iostream>
#include <locale>

struct Destructible_money_get : public std::money_get<wchar_t>
{
    Destructible_money_get(std::size_t refs = 0) : money_get(refs) {}
    // remarque : le destructeur implicite est public
};

int main()
{
    Destructible_money_get dc;
    // std::money_get<wchar_t> c; // erreur de compilation : destructeur protégé
}
