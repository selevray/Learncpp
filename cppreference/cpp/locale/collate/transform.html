std::collate<CharT>::transform, do_transform

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

public:
string_type transform( const CharT* low, const CharT* high ) const;  // (1)

protected:
virtual string_type do_transform( const CharT* low, const CharT* high ) const;  // (2)

  1. Fonction membre publique, appelle la fonction membre virtuelle protégée do_transform de la classe la plus dérivée.

  2. Convertit la séquence de caractères [low,high) en une chaîne qui, comparée lexicographiquement (par exemple avec operator< pour les chaînes) au résultat de l'appel de transform() sur une autre chaîne, produit le même résultat que l'appel de do_compare() sur ces deux mêmes chaînes.

Paramètres

  • low — pointeur vers le premier caractère de la séquence à transformer
  • high — pointeur vers la fin (un au-delà du dernier élément) de la séquence à transformer

Valeur de retour

La chaîne transformée afin que la comparaison lexicographique des chaînes transformées puisse être utilisée à la place de la collation des originales. Dans la locale « C », la chaîne renvoyée est la copie exacte de [low,high). Dans les autres locales, le contenu de la chaîne renvoyée est défini par l'implémentation, et sa taille peut être nettement plus grande.

Notes

En plus de son utilisation dans la collation, le format de la chaîne transformée, propre à l'implémentation, est connu de std::regex_traits<>::transform_primary, qui est capable d'extraire les informations de classe d'équivalence.

Exemple

#include <iomanip>
#include <iostream>
#include <locale>

int main()
{
    std::locale::global(std::locale("sv_SE.utf8"));
    auto& f = std::use_facet<std::collate<wchar_t>>(std::locale());

    std::wstring in1 = L"\u00e4ngel";
    std::wstring in2 = L"\u00e5r";

    std::wstring out1 = f.transform(&in1[0], &in1[0] + in1.size());
    std::wstring out2 = f.transform(&in2[0], &in2[0] + in2.size());

    std::wcout << "In the Swedish locale: ";
    if (out1 < out2)
        std::wcout << in1 << " before " << in2 << '\n';
    else
        std::wcout << in2 << " before " << in1 << '\n';

    std::wcout << "In lexicographic comparison: ";
    if (in1 < in2)
        std::wcout << in1 << " before " << in2 << '\n';
    else
        std::wcout << in2 << " before " << in1 << '\n';
}

Output:

In the Swedish locale: år before ängel
In lexicographic comparison: ängel before år
