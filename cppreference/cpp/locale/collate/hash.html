std::collate<CharT>::hash, std::collate<CharT>::do_hash

public:
long hash( const CharT* beg, const CharT* end ) const;  // (1)

protected:
virtual long do_hash( const CharT* beg, const CharT* end ) const;  // (2)

  1. Fonction membre publique, appelle la fonction membre virtuelle protégée do_hash de la classe la plus dérivée.

  2. Convertit la séquence de caractères [beg,end) en une valeur entière égale au hachage obtenu pour toutes les chaînes qui se collationnent de façon équivalente dans cette locale (compare() renvoie 0). Pour deux chaînes qui ne se collationnent pas de façon équivalente, la probabilité que leurs hachages soient égaux doit être très faible, tendant vers 1.0 / std::numeric_limits<unsigned long>::max().

Paramètres

  • beg — pointeur vers le premier caractère de la séquence à hacher
  • end — pointeur de fin, un au-delà, pour la séquence à hacher

Valeur de retour

La valeur de hachage qui respecte l'ordre de collationnement.

Note

Les locales fournies par le système ne collationnent normalement pas deux chaînes comme équivalentes (compare() ne renvoie pas 0) si basic_string::operator== renvoie false, mais une facette std::collate installée par l'utilisateur peut fournir des règles de collationnement différentes, par exemple en traitant comme équivalentes des chaînes ayant la même forme normalisée Unicode.

Exemple

Démontre un conteneur non ordonné sensible à la locale.

#include <iostream>
#include <locale>
#include <string>
#include <unordered_set>

struct CollateHash
{
    template<typename CharT>
    long operator()(const std::basic_string<CharT>& s) const
    {
        return std::use_facet<std::collate<CharT>>(std::locale()).hash(
                   &s[0], &s[0] + s.size()
               );
    }
};
struct CollateEq
{
    template<typename CharT>
    bool operator()(const std::basic_string<CharT>& s1,
                    const std::basic_string<CharT>& s2) const
    {
        return std::use_facet<std::collate<CharT>>(std::locale()).compare(
                     &s1[0], &s1[0] + s1.size(),
                     &s2[0], &s2[0] + s2.size()
               ) == 0;
    }
};

int main()
{
    std::locale::global(std::locale("en_US.utf8"));
    std::wcout.imbue(std::locale());

    std::unordered_set<std::wstring, CollateHash, CollateEq> s2 = {L"Foo", L"Bar"};
    for (auto& str : s2)
        std::wcout << str << ' ';
    std::cout << '\n';
}
