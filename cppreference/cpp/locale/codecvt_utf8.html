std::codecvt_utf8

template<
    class Elem,
    unsigned long Maxcode = 0x10ffff,
    std::codecvt_mode Mode = (std::codecvt_mode)0 >
class codecvt_utf8
    : public std::codecvt<Elem, char, std::mbstate_t>;  // (depuis C++11) (obsolète en C++17) (supprimé en C++26)

std::codecvt_utf8 est une facette std::codecvt qui encapsule la conversion entre une chaîne d'octets encodée en UTF-8 et une chaîne de caractères UCS-2 ou UTF-32 (selon le type de Elem). Cette facette std::codecvt peut être utilisée pour lire et écrire des fichiers UTF-8, en mode texte comme en mode binaire.

UCS-2 est un encodage archaïque qui est un sous-ensemble de UTF-16, qui ne code que les valeurs scalaires de l'intervalle U+0000-U+FFFF (plan multilingue de base).

Paramètres de modèle

  • Elem — soit char16_t, soit char32_t, soit wchar_t
  • Maxcode — la plus grande valeur de Elem que cette facette peut lire ou écrire sans erreur
  • Mode — une constante de type std::codecvt_mode

Notes

Bien que la norme exige que cette facette fonctionne avec UCS-2 lorsque la taille de Elem est de 16 bits, certaines implémentations utilisent UTF-16 à la place. Le terme « UCS-2 » a été déprécié et supprimé de l'ISO 10646.

Exemple

L'exemple suivant montre la différence entre les conversions UCS-2/UTF-8 et UTF-16/UTF-8 : le troisième caractère de la chaîne n'est pas un caractère UCS-2 valide.

#include <codecvt>
#include <cstdint>
#include <iostream>
#include <locale>
#include <string>

int main()
{
    // Données UTF-8. Le caractère U+1d10b, signe musical segno, ne tient pas dans l'UCS-2
    std::string utf8 = "z\u6c34\U0001d10b";

    // la facette de conversion standard UTF-8 / UTF-16
    std::wstring_convert<std::codecvt_utf8_utf16<char16_t>, char16_t> utf16conv;
    std::u16string utf16 = utf16conv.from_bytes(utf8);
    std::cout << "UTF-16 conversion produced " << utf16.size() << " code units:\n"
              << std::showbase << std::hex;
    for (char16_t c : utf16)
        std::cout << static_cast<std::uint16_t>(c) << ' ';

    // la facette de conversion standard UTF-8 / UCS-2
    std::wstring_convert<std::codecvt_utf8<char16_t>, char16_t> ucs2conv;
    try
    {
        std::u16string ucs2 = ucs2conv.from_bytes(utf8);
    }
    catch(const std::range_error& e)
    {
        std::u16string ucs2 = ucs2conv.from_bytes(utf8.substr(0, ucs2conv.converted()));
        std::cout << "\nUCS-2 failed after producing " << std::dec << ucs2.size()
                  << " characters:\n" << std::showbase << std::hex;
        for (char16_t c : ucs2)
            std::cout << static_cast<std::uint16_t>(c) << ' ';
        std::cout << '\n';
    }
}

Output:

UTF-16 conversion produced 4 code units:
0x7a 0x6c34 0xd834 0xdd0b
UCS-2 failed after producing 2 characters:
0x7a 0x6c34
