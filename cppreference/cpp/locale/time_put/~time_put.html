std::time_put<CharT,OutputIt>::~time_put

Défini dans l'en-tête <locale>

protected: ~time_put();

Détruit une facette std::time_put. Ce destructeur est protégé et virtuel (en raison du destructeur de la classe de base qui est virtuel). Un objet de type std::time_put, comme la plupart des facettes, ne peut être détruit que lorsque le dernier objet std::locale qui implémente cette facette sort de sa portée, ou si une classe définie par l'utilisateur dérive de std::time_put et déclare un destructeur public.

Exemple

#include <iostream>
#include <locale>

struct Destructible_time_put : public std::time_put<wchar_t>
{
    Destructible_time_put(std::size_t refs = 0) : time_put(refs) {}
    // remarque : le destructeur implicite est public
};

int main()
{
    Destructible_time_put dc;
    // std::time_put<wchar_t> c; // erreur de compilation : destructeur protégé
}
