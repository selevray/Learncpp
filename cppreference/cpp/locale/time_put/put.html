Convertit la date et l'heure du calendrier stockées dans l'objet std::tm pointé par t en chaîne de caractères, selon la chaîne de format [fmtbeg, fmtend). La chaîne de format est la même que celle utilisée par std::strftime, mais chaque spécificateur de format est traité par un appel individuel à do_put(), qui peut être personnalisé en étendant cette facette.

  1. Parcourt la séquence de caractères [fmtbeg, fmtend) en examinant les caractères. Chaque caractère qui ne fait pas partie d'une séquence de format est écrit immédiatement dans l'itérateur de sortie out. Pour identifier les séquences de format, cette fonction convertit le caractère suivant c de [fmtbeg, fmtend) en caractère étroit comme par std::ctype<char_type>(str.getloc()).narrow(c, 0) et, s'il est égal à '%', les un ou deux caractères suivants sont comparés à la liste des séquences de format reconnues par std::strftime, plus les formats supplémentaires définis par l'implémentation et pris en charge par cette locale. Pour chaque séquence de format valide, un appel à do_put(out, str, fill, t, format, modifier) est effectué, où format est le caractère de la séquence de format et modifier est le modificateur optionnel de la séquence ('E' ou 'O'). La valeur '\0' est utilisée si le modificateur est absent.

  2. Appelle la fonction membre do_put de la classe la plus dérivée.

  3. Convertit la date et l'heure du calendrier stockées dans l'objet std::tm pointé par t en chaîne de caractères, selon la séquence de conversion de format formée par la concaténation de '%', de la valeur de modifier si elle n'est pas '\0', et de la valeur de format. Le format est interprété de la même manière que la fonction std::strftime, sauf que les formats décrits comme dépendants de la locale sont définis par cette locale, et que des spécificateurs de format supplémentaires peuvent être pris en charge (l'argument fill est fourni pour que ces spécificateurs de format définis par l'implémentation l'utilisent). La chaîne est écrite dans l'itérateur de sortie out.

Paramètres

  • out — itérateur de sortie où le résultat de la conversion est écrit
  • str — un objet flux que cette fonction utilise pour obtenir les facettes de locale lorsque nécessaire, par ex. std::ctype pour convertir les caractères en étroits
  • t — pointeur vers l'objet std::tm dont les valeurs de date/heure sont obtenues
  • fmtbeg — pointeur vers le premier caractère d'une séquence de char_type caractères spécifiant le format de conversion
  • fmtend — pointeur un caractère après le dernier caractère d'une séquence de char_type caractères spécifiant le format de conversion
  • fill — caractère de remplissage (généralement l'espace)
  • format — le caractère qui désigne un spécificateur de conversion
  • modifier — le modificateur optionnel qui peut apparaître entre % et le spécificateur de conversion

Chaîne de format

La chaîne de format est constituée de zéro ou plusieurs spécificateurs de conversion et de caractères ordinaires (sauf %). Tous les caractères ordinaires, y compris le caractère nul terminal, sont copiés sans modification dans la chaîne de sortie. Chaque spécification de conversion commence par le caractère %, suivi éventuellement du modificateur E ou O (ignoré si la locale ne le prend pas en charge), puis du caractère qui détermine le comportement du spécificateur. Valeur de retour

Itérateur pointant un caractère après le dernier caractère produit.

Notes

Aucune gestion d'erreur n'est fournie.

Le caractère fill est fourni pour les spécificateurs de format définis par l'implémentation et pour les redéfinitions par l'utilisateur de do_put() qui utilisent une logique de remplissage et de cadrage. Ces implémentations utilisent généralement les indicateurs de formatage de str.

Exemple

#include <iostream>
#include <sstream>
#include <iomanip>
#include <ctime>

void try_time_put(const std::tm* t, const std::string& fmt)
{
    std::cout.imbue(std::locale());
    std::cout << "In the locale '" << std::cout.getloc().name() << "' : '";

    std::use_facet<std::time_put<char>>(std::cout.getloc()).put(
        {std::cout}, std::cout, ' ', t, &fmt[0], &fmt[0] + fmt.size());

    std::cout << "'\n";
}

int main()
{
    std::time_t t = std::time(NULL);
    std::tm tm = *std::localtime(&t);

    std::string fmt = "%c";
    std::cout << "Using the format string '" << fmt
              << "' to format the time: " << std::ctime(&t) << '\n';

    std::locale::global(std::locale("de_DE.utf8"));
    try_time_put(&tm, fmt);

    std::locale::global(std::locale("el_GR.utf8"));
    try_time_put(&tm, fmt);

    std::locale::global(std::locale("ja_JP.utf8"));
    try_time_put(&tm, fmt);
}
