std::ctype<CharT>::narrow, do_narrow

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

public:
char narrow( CharT c, char dflt ) const;  // (1)

public:
const CharT* narrow( const CharT* beg, const CharT* end,
                     char dflt, char* dst ) const;  // (2)

protected:
virtual char do_narrow( CharT c, char dflt ) const;  // (3)

protected:
virtual const CharT* do_narrow( const CharT* beg, const CharT* end,
                                char dflt, char* dst ) const;  // (4)

1,2) Fonction membre publique, appelle la fonction membre virtuelle protégée correspondante do_narrow surcharge de la classe la plus dérivée. La surcharge (1) appelle do_narrow(c, dflt), la surcharge (2) appelle do_narrow(beg, end, dflt, dst).

  1. Convertit le caractère (éventuellement large) c en représentation multioctet si le caractère peut être représenté par un seul octet (par exemple, les caractères ASCII en codage UTF-8 sont des octets simples). Renvoie dflt si une telle conversion n'existe pas.

  2. Pour chaque caractère du tableau de caractères [beg,end), écrit les caractères réduits (ou dflt lorsque la réduction échoue) aux emplacements successifs du tableau de caractères pointé par dst.

La réduction réussit toujours et est toujours réversible (en appelant widen()) pour tous les caractères du [jeu de caractères source de base (jusqu'à C++23) | jeu de caractères de base (depuis C++23)].

  • c'est-à-dire que do_widen(do_narrow(c, 0)) == c est toujours vrai pour tout caractère c du [jeu de caractères source de base (jusqu'à C++23) | jeu de caractères de base (depuis C++23)].

La réduction, si elle réussit, préserve toutes les catégories de classification de caractères connues de is().

  • c'est-à-dire que is(m, c) || !ctc.is(m, do_narrow(c, dflt)) est toujours true pour toute catégorie nommée ctype avec une facette ctype<char> ctc et une valeur ctype_base::mask m (sauf si do_narrow renvoie dflt).

La réduction de tout caractère chiffre garantit que si le résultat est soustrait du littéral de caractère '0', la différence est égale à la valeur numérique du caractère d'origine.

  • c'est-à-dire que pour tout caractère chiffre c, l'expression (do_narrow(c, dflt) - '0') évalue à la valeur numérique du caractère.

Paramètres

  • c — caractère à convertir
  • dflt — valeur par défaut à produire si la conversion échoue
  • beg — pointeur vers le premier caractère d'un tableau de caractères à convertir
  • end — pointeur vers la fin (un au-delà du dernier élément) du tableau de caractères à convertir
  • dst — pointeur vers le premier élément du tableau de caractères à remplir

Valeur de retour

1,3) Caractère réduit ou dflt si la réduction échoue.

2,4) end

Exemple

#include <iostream>
#include <locale>

void try_narrow(const std::ctype<wchar_t>& f, wchar_t c)
{
    char n = f.narrow(c, 0);
    if (n)
        std::wcout << '\'' << c << "' narrowed to " << +(unsigned char)n << '\n';
    else
        std::wcout << '\'' << c << "' could not be narrowed\n";
}

int main()
{
    std::locale::global(std::locale("en_US.utf8"));
    std::wcout.imbue(std::locale());
    std::wcout << std::hex << std::showbase << "In US English UTF-8 locale:\n";
    auto& f = std::use_facet<std::ctype<wchar_t>>(std::locale());
    try_narrow(f, L'A');
    try_narrow(f, L'Ａ');
    try_narrow(f, L'ě');

    std::locale::global(std::locale("cs_CZ.iso88592"));
    auto& f2 = std::use_facet<std::ctype<wchar_t>>(std::locale());
    std::wcout << "In Czech ISO-8859-2 locale:\n";
    try_narrow(f2, L'A');
    try_narrow(f2, L'Ａ');
    try_narrow(f2, L'ě');
}

Sortie possible :

In US English UTF-8 locale:
'A' narrowed to 0x41
'Ａ' could not be narrowed
'ě' could not be narrowed
In Czech ISO-8859-2 locale:
'A' narrowed to 0x41
'Ａ' could not be narrowed
'ě' narrowed to 0xec

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.
