std::ctype<CharT>::tolower, std::ctype<CharT>::do_tolower

1,2) Fonction membre publique, appelle la fonction membre virtuelle protégée do_tolower de la classe la plus dérivée.

  1. Convertit le caractère c en minuscule si une forme minuscule est définie par cette locale.

  2. Pour chaque caractère du tableau de caractères [beg,end) pour lequel une forme minuscule existe, remplace le caractère par cette forme minuscule.

Paramètres

  • c — caractère à convertir
  • beg — pointeur vers le premier caractère d'un tableau de caractères à convertir
  • end — pointeur vers la fin (un au-delà du dernier élément) du tableau de caractères à convertir

Valeur de retour

1,3) Caractère en minuscule ou c si aucune forme minuscule n'est listée par cette locale.

2,4) end

Notes

Seul un mappage de caractères 1:1 peut être effectué par cette fonction. Par exemple, la lettre grecque majuscule « Σ » a deux formes minuscules selon sa position dans un mot : « σ » et « ς ». Un appel à do_tolower ne peut pas être utilisé pour obtenir la forme minuscule correcte dans ce cas.

Exemple

#include <iostream>
#include <locale>

void try_lower(const std::ctype<wchar_t>& f, wchar_t c)
{
    wchar_t up = f.tolower(c);
    if (up != c)
        std::wcout << "Lower case form of \'" << c << "' is " << up << '\n';
    else
        std::wcout << '\'' << c << "' has no lower case form\n";
}

int main()
{
    std::locale::global(std::locale("en_US.utf8"));
    std::wcout.imbue(std::locale());
    std::wcout << "In US English UTF-8 locale:\n";
    auto& f = std::use_facet<std::ctype<wchar_t>>(std::locale());
    try_lower(f, L'Σ');
    try_lower(f, L'Ɛ');
    try_lower(f, L'Ａ');

    std::wstring str = L"HELLo, wORLD!";
    std::wcout << "Lowercase form of the string '" << str << "' is ";
    f.tolower(&str[0], &str[0] + str.size());
    std::wcout << '\'' << str << "'\n";
}

Output:

In US English UTF-8 locale:
Lower case form of 'Σ' is σ
Lower case form of 'Ɛ' is ɛ
Lower case form of 'Ａ' is ａ
Lowercase form of the string 'HELLo, wORLD!' is 'hello, world!'
