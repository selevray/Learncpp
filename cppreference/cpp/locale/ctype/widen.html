1,2) Fonction membre publique, appelle la fonction membre virtuelle protégée correspondante do_widen surcharge de la classe la plus dérivée. La surcharge (1) appelle do_widen(c), la surcharge (2) appelle do_widen(beg, end, dst).

  1. Convertit le caractère sur un octet c en sa représentation de caractère large correspondante, en utilisant la transformation la plus simple et raisonnable. En général, cela ne s'applique qu'aux caractères dont l'encodage multi-octets tient sur un seul octet (par exemple U+0000-U+007F en UTF-8).

  2. Pour chaque caractère du tableau de caractères [beg,end), écrit le caractère élargi correspondant dans les positions successives du tableau de caractères pointé par dst.

L'élargissement renvoie toujours un caractère large, mais seuls les caractères de [l'ensemble de caractères source de base (jusqu'à C++23) | l'ensemble de caractères de base (depuis C++23)] ont la garantie d'avoir une transformation d'élargissement unique, bien définie, et également garantie réversible (par narrow()). En pratique, tous les caractères dont la représentation multi-octets tient sur un seul octet sont généralement élargis vers leurs équivalents de caractères larges, et le reste des valeurs possibles sur un octet est généralement associé à la même valeur de remplacement, typiquement CharT(-1).

L'élargissement, en cas de succès, préserve toutes les catégories de classification de caractères connues de is().

Paramètres

  • c — caractère à convertir
  • dflt — valeur par défaut à produire si la conversion échoue
  • beg — pointeur vers le premier caractère d'un tableau de caractères à convertir
  • end — pointeur vers la fin (un au-delà du dernier élément) du tableau de caractères à convertir
  • dst — pointeur vers le premier élément du tableau de caractères à remplir

Valeur de retour

1,3) Caractère élargi.

2,4) end

Exemple

#include <iostream>
#include <locale>

void try_widen(const std::ctype<wchar_t>& f, char c)
{
    wchar_t w = f.widen(c);
    std::cout << "The single-byte character " << +(unsigned char)c
              << " widens to " << +w << '\n';
}

int main()
{
    std::locale::global(std::locale("cs_CZ.iso88592"));
    auto& f = std::use_facet<std::ctype<wchar_t>>(std::locale());
    std::cout << std::hex << std::showbase << "In Czech ISO-8859-2 locale:\n";
    try_widen(f, 'a');
    try_widen(f, '\xdf'); // Lettre allemande ß (U+00df) en ISO-8859-2
    try_widen(f, '\xec'); // Lettre tchèque ě (U+011b) en ISO-8859-2

    std::locale::global(std::locale("cs_CZ.utf8"));
    auto& f2 = std::use_facet<std::ctype<wchar_t>>(std::locale());
    std::cout << "In Czech UTF-8 locale:\n";
    try_widen(f2, 'a');
    try_widen(f2, '\xdf');
    try_widen(f2, '\xec');
}

Sortie possible :

In Czech ISO-8859-2 locale:
The single-byte character 0x61 widens to 0x61
The single-byte character 0xdf widens to 0xdf
The single-byte character 0xec widens to 0x11b
In Czech UTF-8 locale:
The single-byte character 0x61 widens to 0x61
The single-byte character 0xdf widens to 0xffffffff
The single-byte character 0xec widens to 0xffffffff
