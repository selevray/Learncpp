std::ctype<CharT>::~ctype

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

protected: ~ctype();

Détruit une facette std::ctype. Ce destructeur est protégé et virtuel (en raison du destructeur de la classe de base qui est virtuel). Un objet de type std::ctype, comme la plupart des facettes, ne peut être détruit que lorsque le dernier objet std::locale qui implémente cette facette sort de sa portée, ou si une classe définie par l'utilisateur dérive de std::ctype et déclare un destructeur public.

Exemple

#include <iostream>
#include <locale>

struct Destructible_ctype : public std::ctype<wchar_t>
{
    Destructible_ctype(std::size_t refs = 0) : ctype(refs) {}
    // remarque : le destructeur implicite est public
};

int main()
{
    Destructible_ctype dc;
    // std::ctype<wchar_t> c; // erreur de compilation : destructeur protégé
}
