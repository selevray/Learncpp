std::ctype<CharT>::scan_is, std::ctype<CharT>::do_scan_is

Défini dans l'en-tête <locale>

public:
const CharT* scan_is( mask m, const CharT* beg, const CharT* end ) const;  // (1)

protected:
virtual const CharT* do_scan_is( mask m, const CharT* beg, const CharT* end ) const;  // (2)

  1. Fonction membre publique, appelle la fonction membre virtuelle protégée do_scan_is de la classe la plus dérivée.

  2. Recherche le premier caractère du tableau de caractères [beg,end) qui satisfait le masque de classification m, c'est-à-dire le premier caractère c tel que is(m, c) renverrait true.

Paramètres

  • m — masque à rechercher
  • beg — pointeur vers le premier caractère d'un tableau de caractères dans lequel effectuer la recherche
  • end — pointeur vers la fin (un au-delà du dernier élément) du tableau de caractères dans lequel effectuer la recherche

Valeur de retour

Pointeur vers le premier caractère de [beg,end) qui satisfait le masque, ou end si aucun tel caractère n'a été trouvé.

Exemple

#include <clocale>
#include <iostream>
#include <iterator>
#include <locale>

int main()
{
    std::setlocale(LC_ALL, "en_US.utf8");
    std::wcout.imbue(std::locale("en_US.utf8"));
    auto& f = std::use_facet<std::ctype<wchar_t>>(std::wcout.getloc());

    // ignore jusqu'à la première lettre
    wchar_t s1[] = L"      \t\t\n  Кошка";
    const wchar_t* p1 = f.scan_is(std::ctype_base::alpha, std::begin(s1), std::end(s1));
    std::wcout << '\'' << p1 << "'\n";

    // ignore jusqu'à la première lettre
    wchar_t s2[] = L"123456789ネプネプ";
    const wchar_t* p2 = f.scan_is(std::ctype_base::alpha, std::begin(s2), std::end(s2));
    std::wcout << '\'' << p2 << "'\n";
}

Output:

'Кошка'
'ネプネプ'
