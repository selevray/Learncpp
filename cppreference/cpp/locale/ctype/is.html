std::ctype<CharT>::is, std::ctype<CharT>::do_is

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

public:
bool is( mask m, CharT c ) const;  // (1)

public:
const CharT* is( const CharT* low, const CharT* high, mask* vec ) const;  // (2)

protected:
virtual bool do_is( mask m, CharT c ) const;  // (3)

protected:
virtual const CharT* do_is( const CharT* low, const CharT* high, mask* vec ) const;  // (4)

1,2) Fonction membre publique, appelle la fonction membre virtuelle protégée do_is de la classe la plus dérivée.

  1. Vérifie si le caractère c est classé par le masque m.

  2. Pour chaque caractère du tableau de caractères [low,high), identifie le masque de classification complet (par exemple digit|xdigit|alnum|print|graph pour le chiffre '0' dans la locale par défaut) et stocke les masques dans les éléments correspondants du tableau pointé par vec.

Paramètres

  • c — caractère à classer
  • m — masque à utiliser pour classer un seul caractère
  • low — pointeur vers le premier caractère d'un tableau de caractères à classer
  • high — pointeur vers la fin (un au-delà du dernier élément) du tableau de caractères à classer
  • vec — pointeur vers le premier élément du tableau de masques à remplir

Valeur de retour

1,3) true si c est classé par m.

2,4) high

Exemple

#include <cstddef>
#include <iostream>
#include <locale>
#include <utility>
#include <vector>

// enveloppe utilitaire permettant de rendre destructibles les facettes liées à une locale
template<class Facet>
struct deletable_facet : Facet
{
    template<class ...Args>
    deletable_facet(Args&& ...args) : Facet(std::forward<Args>(args)...) {}
    ~deletable_facet() {}
};

int main()
{
    // classe un seul caractère à l'aide de la locale par défaut
    auto& f = std::use_facet<std::ctype<char>>(std::locale());
    char c = '0';
    if (f.is(std::ctype_base::digit, c)) // ou isdigit(c, locale());
        std::cout << '\'' << c << "' is a digit\n";

    // classe chaque caractère d'une chaîne à l'aide d'une locale nommée
    deletable_facet<std::ctype_byname<wchar_t>> f2("en_US.utf8");
    std::wstring str = L"z\u00df\u6c34\U0001d10b";
    std::vector<std::ctype_base::mask> vec(str.size());
    f2.is(&str[0], &str[0] + str.size(), &vec[0]);

    for (std::size_t n = 0; n < str.size(); ++n)
    {
        std::cout << std::hex << "U+" << static_cast<wint_t>(str[n]) << " is: ";
        if (vec[n] & std::ctype_base::alnum)
            std::cout << "alnum";
        if (vec[n] & std::ctype_base::punct)
            std::cout << "punct";
        std::cout << '\n';
    }
}

Output:

'0' is a digit
U+7a is: alnum
U+df is: alnum
U+6c34 is: alnum
U+1d10b is: punct
