std::locale::name

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

std::string name() const;

Renvoie le nom de la locale, c'est-à-dire le nom sous lequel elle est connue du système d'exploitation, tel que "POSIX" ou "en_US.UTF8" ou "English_United States.1252". Si la locale n'est pas une copie d'une locale fournie par le système, la chaîne "*" est renvoyée.

Valeur de retour

Le nom de la locale ou "*" si elle est sans nom.

Exemple

#include <iostream>
#include <locale>
#include <string>

int main()
{
    std::locale loc(std::locale(), new std::ctype<char>);
    std::cout << "The default locale is " << std::locale().name() << '\n'
              << "The user's locale is " << std::locale("").name() << '\n'
              << "A nameless locale is " << loc.name() << '\n';
}

Sortie possible :

The default locale is C
The user's locale is en_US.UTF8
A nameless locale is *
