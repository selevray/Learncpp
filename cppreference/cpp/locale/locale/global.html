std::locale::global

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static locale global( const locale& loc );

Remplace la locale C++ globale par loc, ce qui signifie que tous les appels futurs au constructeur par défaut de std::locale renverront désormais une copie de loc. Si loc a un nom, remplace également la locale C comme si par std::setlocale(LC_ALL, loc.name().c_str());. Cette fonction est le seul moyen de modifier la locale C++ globale, qui est par ailleurs équivalente à std::locale::classic() au démarrage du programme.

Paramètres

  • loc — la nouvelle locale C++ globale

Valeur de retour

La valeur précédente de la locale C++ globale.
