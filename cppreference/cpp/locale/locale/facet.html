std::locale::facet

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

class locale::facet;

std::locale::facet est la classe de base des facettes. Elle fournit une classe de base commune afin que les locales puissent stocker les pointeurs vers les facettes qu'elles implémentent dans un seul conteneur indexé, et elle prend en charge le comptage des références des facettes.

Chaque fois qu'une facette est ajoutée à une locale, la locale incrémente le compteur de références de la facette (par un mécanisme propre à l'implémentation). Chaque fois qu'une locale est détruite ou modifiée, elle décrémente le compteur de références de chaque facette qu'elle n'implémente plus. Lorsque le compteur de références d'une facette atteint zéro, la locale effectue delete static_cast<std::locale::facet*>(f); où f est le pointeur vers la facette.

Classe facette

Une classe est une facette si

  • elle est dérivée publiquement d'une autre facette, ou
  • c'est une classe dérivée de std::locale::facet et contient une déclaration accessible publiquement comme suit :

static ::std::locale::id id;

Fonctions membres

  • (constructeur) — construit une nouvelle facette avec le compteur de références spécifié (fonction membre protégée)
  • operator= — l'opérateur d'affectation par copie est supprimé (fonction membre protégée)
  • (destructeur) [virtuelle] — le destructeur est virtuel protégé (fonction membre virtuelle protégée)
