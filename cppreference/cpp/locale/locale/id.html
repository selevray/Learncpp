class locale::id;

La classe std::locale::id fournit une identification propre à l'implémentation d'une facette de locale. Chaque facette possède un membre statique public nommé id de type std::locale::id, et chaque objet std::locale conserve une liste des facettes qu'il implémente, indexées par leurs id.

Les facettes ayant le même id appartiennent à la même catégorie de facettes et se remplacent mutuellement lorsqu'elles sont ajoutées à un objet locale.

Fonctions membres

  • (constructeur) — construit un nouvel identifiant (fonction membre publique)
  • operator= — l'opérateur d'affectation par copie est supprimé (fonction membre publique)

Exemple

L'exemple suivant montre comment construire une facette personnalisée minimale.

#include <iostream>
#include <locale>

struct myfacet : std::locale::facet
{
    myfacet(std::size_t refs = 0) : facet(refs) {}
    static ::std::locale::id id;
};

std::locale::id myfacet::id;

int main()
{
    std::locale myloc(std::locale(), new myfacet);
    std::cout << "has_facet<myfacet>(myloc) returns " << std::boolalpha
              << std::has_facet<myfacet>(myloc) << '\n';
}

Output:

has_facet<myfacet>(myloc) returns true
