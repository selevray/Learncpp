std::locale::operator=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

const locale& operator=( const locale& other ) throw();  // (jusqu'à C++11)

const locale& operator=( const locale& other ) noexcept;  // (depuis C++11)

Crée une copie de other, remplaçant le contenu de *this. Les compteurs de références de toutes les facettes détenues par other sont incrémentés. Les compteurs de références de toutes les facettes précédemment détenues par *this sont décrémentés, et celles dont le compteur atteint zéro sont supprimées.

Valeur de retour

Renvoie *this, qui est désormais une copie de other.
