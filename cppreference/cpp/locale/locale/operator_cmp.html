std::locale::operator==, operator!=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool operator==( const locale& other ) const;  // (1)

bool operator!=( const locale& other ) const;  // (2) (jusqu'à C++20)

Compare deux locales pour l'égalité. Les locales nommées sont considérées comme égales si leurs noms sont égaux. Les locales sans nom sont considérées comme égales si ce sont des copies l'une de l'autre.

L'opérateur != est synthétisé à partir de operator==.

(depuis C++20)

Paramètres

  • other — un objet std::locale à comparer

Valeur de retour

  1. true si other est une copie de *this ou possède un nom identique, false sinon.

  2. false si other est une copie de *this ou possède un nom identique, true sinon.
