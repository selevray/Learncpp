std::locale::combine

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class Facet >
locale combine( const locale& other ) const;

Construit un objet locale qui est une copie de *this, à l'exception de la facette de type Facet, qui est copiée depuis other.

Le programme est mal formé si Facet n'est pas une facette ou s'il s'agit d'une facette qualifiée volatile.

Valeur de retour

La nouvelle locale, sans nom.

Exceptions

std::runtime_error si other n'implémente pas Facet.

Exemple

#include <iostream>
#include <locale>

int main()
{
    const double number = 1000.25;
    std::cout << "\"C\" locale: " << number << '\n';
    std::locale loc = std::locale()
        .combine<std::numpunct<char>>(std::locale("en_US.UTF8"));
    std::cout.imbue(loc);
    std::cout << "\"C\" locale with en_US numpunct: " << number << '\n';
}

Output:

"C" locale: 1000.25
"C" locale with en_US numpunct: 1,000.25
