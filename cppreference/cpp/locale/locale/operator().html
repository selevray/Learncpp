std::locale::operator()

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class CharT, class Traits, class Alloc >
bool operator()( const std::basic_string<CharT,Traits,Alloc>& s1,
                 const std::basic_string<CharT,Traits,Alloc>& s2 ) const;

Compare deux arguments de chaîne s1 et s2 selon les règles de comparaison lexicographique définies par le facet std::collate<CharT> de cette locale. Cet opérateur permet d'utiliser tout objet locale disposant d'un facet collate comme prédicat binaire dans les algorithmes standard (tels que std::sort) et dans les conteneurs ordonnés (tels que std::set).

Paramètres

  • s1 — la première chaîne à comparer
  • s2 — la seconde chaîne à comparer

Valeur de retour

true si s1 est lexicographiquement inférieure à s2, false sinon.

Implémentation possible

template<class CharT, class Traits, class Alloc>
bool operator()(const std::basic_string<CharT,Traits,Alloc>& s1,
                const std::basic_string<CharT,Traits,Alloc>& s2) const
{
    return std::use_facet<std::collate<CharT>>(*this).compare(
               s1.data(), s1.data() + s1.size(),
               s2.data(), s2.data() + s2.size()) < 0;
}

Exemple

Un vector de string peut être trié selon une locale non par défaut en utilisant l'objet locale comme comparateur :

#include <algorithm>
#include <cassert>
#include <locale>
#include <string>
#include <vector>

int main()
{
    std::vector<std::wstring> v = {L"жил", L"был", L"пёс"};
    std::sort(v.begin(), v.end(), std::locale("ru_RU.UTF8"));
    assert(v[0] == L"был");
    assert(v[1] == L"жил");
    assert(v[2] == L"пёс");
}
