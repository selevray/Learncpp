std::locale::locale

locale() throw();  // (jusqu'à C++11)

Construit un nouvel objet locale.

  1. Constructeur par défaut. Construit une copie de la locale globale C++, c'est-à-dire la locale utilisée en dernier comme argument de std::locale::global, ou une copie de std::locale::classic() si aucun appel à std::locale::global n'a été effectué.

  2. Constructeur de copie. Construit une copie de other.

3,4) Construit une copie de la locale système du std_name spécifié (tel que "C", ou "POSIX", ou "en_US.UTF-8", ou "English_US.1251"), si cette locale est prise en charge par le système d'exploitation. La locale construite de cette manière possède un nom.

  1. Équivalent à locale(std_name.c_str()).

  2. Construit une copie de other, à l'exception de toutes les facettes identifiées par l'argument cats, qui sont copiées depuis la locale système identifiée par son std_name. La locale construite de cette manière possède un nom si et seulement si other possède un nom.

  3. Équivalent à locale(other, std_name.c_str(), cats).

  4. Construit une copie de other, à l'exception de la facette de type Facet (généralement déduit du type de l'argument), qui est installée depuis f. Si f est un pointeur nul, la locale construite est une copie complète de other. Le programme est mal formé si Facet n'est pas une facette ou s'il s'agit d'une facette qualifiée volatile.

Si f est nul, la locale construite a le même nom que other. Sinon, la locale construite n'a pas de nom.

  1. Construit une copie de other, à l'exception de toutes les facettes identifiées par l'argument cats, qui sont copiées depuis one.

Si cats est égal à locale::none, la locale construite possède un nom si et seulement si other possède un nom. Sinon, la locale construite possède un nom si et seulement si other et one possèdent tous deux un nom.

Paramètres

  • other — une autre locale à copier
  • std_name — nom de la locale système à utiliser
  • f — pointeur vers une facette à fusionner avec other
  • cats — les catégories de facettes utilisées pour identifier les facettes à fusionner avec other
  • one — une autre locale dont prendre les facettes

Exceptions

3,5) std::runtime_error si le système d'exploitation ne possède aucune locale nommée std_name ou si std_name est un pointeur nul.

4,6) std::runtime_error si le système d'exploitation ne possède aucune locale nommée std_name.

Notes

La surcharge (7) est généralement appelée avec son second argument, f, obtenu directement d'une expression new : la locale est chargée d'appeler le delete correspondant depuis son propre destructeur.

Exemple

#include <codecvt>
#include <iostream>
#include <locale>

std::ostream& operator<< (std::ostream& os, const std::locale& loc)
{
    if (loc.name().length() <= 80)
        os << loc.name();
    else
        for (const auto c : loc.name())
            os << c << (c == ';' ? "\n  " : "");

    return os << '\n';
}

int main()
{
    std::locale l1;
    std::cout << "Name of a copy of the classic \"C\" locale: " << l1;

    std::locale l2("en_US.UTF-8");
    std::cout << "Name of unicode locale: " << l2;

    std::locale l3(l1, new std::codecvt_utf8<wchar_t>);
    std::cout << "Name of \"C\" locale except for codecvt: " << l3;

    std::locale l4(l1, l2, std::locale::ctype);
    std::cout << "Name of \"C\" locale except for ctype, which is unicode:\n  " << l4;
}
