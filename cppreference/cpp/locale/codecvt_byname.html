std::codecvt_byname

Défini dans l'en-tête <locale>

template< class InternT, class ExternT, class State >
class codecvt_byname : public std::codecvt<InternT, ExternT, State>;

std::codecvt_byname est une facette std::codecvt qui encapsule les règles de conversion de caractères multioctets/larges d'une locale spécifiée à sa construction.

Spécialisations

La bibliothèque standard garantit de fournir les spécialisations suivantes :

Défini dans l'en-tête <locale>

  • std::codecvt_byname<char, char, std::mbstate_t> — conversion identité
  • std::codecvt_byname<char16_t, char, std::mbstate_t>
    (depuis C++11) (obsolète en C++20)     — conversion entre UTF-16 et UTF-8
  • std::codecvt_byname<char16_t, char8_t, std::mbstate_t>
    (depuis C++20)     — conversion entre UTF-16 et UTF-8
  • std::codecvt_byname<char32_t, char, std::mbstate_t>
    (depuis C++11) (obsolète en C++20)     — conversion entre UTF-32 et UTF-8
  • std::codecvt_byname<char32_t, char8_t, std::mbstate_t>
    (depuis C++20)     — conversion entre UTF-32 et UTF-8
  • std::codecvt_byname<wchar_t, char, std::mbstate_t> — conversion spécifique à la locale entre chaîne de caractères larges et jeux de caractères étroits

Exemple

Cet exemple montre la lecture d'un fichier encodé en GB18030 à l'aide de la facette codecvt d'une locale compatible GB18030.

#include <fstream>
#include <iostream>
#include <locale>
#include <string>

int main()
{
    // encodage multioctet étroit GB18030
    std::ofstream("text.txt") << "\x7a"              // lettre 'z', U+007a
                                 "\x81\x30\x89\x38"  // lettre 'ß', U+00df
                                 "\xcb\xae"          // idéogramme CJK '水' (eau), U+6c34
                                 "\x94\x32\xbc\x35"; // signe musical '𝄋' (segno), U+1d10b

    std::wifstream fin("text.txt");
    fin.imbue(std::locale(fin.getloc(),
              new std::codecvt_byname<wchar_t, char, std::mbstate_t>("zh_CN.gb18030")));

    for (wchar_t c; fin.get(c);)
        std::cout << std::hex << std::showbase << static_cast<unsigned>(c) << '\n';
}
