template<

Le modèle de classe std::codecvt encapsule la conversion de chaînes de caractères, larges et multioctets, d'un codage à un autre. Toutes les opérations d'E/S sur fichiers effectuées via std::basic_fstream<CharT> utilisent la facette std::codecvt<CharT, char, std::mbstate_t> de la locale imprégnant le flux.

Spécialisations

La bibliothèque standard garantit de fournir les spécialisations suivantes (elles sont requises pour tout objet locale) :

Défini dans l'en-tête <locale>

  • std::codecvt<char, char, std::mbstate_t> — conversion identité
  • std::codecvt<char16_t, char, std::mbstate_t>
    (depuis C++11) (obsolète en C++20)     — conversion entre UTF-16 et UTF-8
  • std::codecvt<char16_t, char8_t, std::mbstate_t>
    (depuis C++20) (obsolète)     — conversion entre UTF-16 et UTF-8
  • std::codecvt<char32_t, char, std::mbstate_t>
    (depuis C++11) (obsolète en C++20)     — conversion entre UTF-32 et UTF-8
  • std::codecvt<char32_t, char8_t, std::mbstate_t>
    (depuis C++20) (obsolète)     — conversion entre UTF-32 et UTF-8
  • std::codecvt<wchar_t, char, std::mbstate_t> — conversion entre le jeu de caractères larges natif du système et les jeux de caractères étroits à octet unique

Exemple

L'exemple suivant lit un fichier UTF-8 à l'aide d'une locale qui implémente la conversion UTF-8 dans codecvt<wchar_t, char, std::mbstate_t> et convertit une chaîne UTF-8 en UTF-16 en utilisant l'une des spécialisations standard de std::codecvt.

#include <codecvt>
#include <cstdint>
#include <fstream>
#include <iomanip>
#include <iostream>
#include <locale>
#include <string>

// classe utilitaire permettant d'adapter les facettes liées à la locale pour wstring/wbuffer convert
template<class Facet>
struct deletable_facet : Facet
{
    template<class... Args>
    deletable_facet(Args&&... args) : Facet(std::forward<Args>(args)...) {}
    ~deletable_facet() {}
};

int main()
{
    // encodage multioctet étroit UTF-8
    std::string data = reinterpret_cast<const char*>(+u8"z\u00df\u6c34\U0001f34c");
                       // ou reinterpret_cast<const char*>(+u8"zß水🍌")
                       // ou "\x7a\xc3\x9f\xe6\xb0\xb4\xf0\x9f\x8d\x8c"

    std::ofstream("text.txt") << data;

    // en utilisant la facette codecvt de la locale fournie par le système
    std::wifstream fin("text.txt");
    // la lecture depuis wifstream utilisera codecvt<wchar_t, char, std::mbstate_t>
    // cette codecvt de la locale convertit UTF-8 en UCS4 (sur des systèmes comme Linux)
    fin.imbue(std::locale("en_US.UTF-8"));
    std::cout << "The UTF-8 file contains the following UCS4 code units:\n" << std::hex;
    for (wchar_t c; fin >> c;)
        std::cout << "U+" << std::setw(4) << std::setfill('0')
                  << static_cast<uint32_t>(c) << ' ';

    // en utilisant la facette codecvt standard (indépendante de la locale)
    std::wstring_convert<
        deletable_facet<std::codecvt<char16_t, char, std::mbstate_t>>, char16_t> conv16;
    std::u16string str16 = conv16.from_bytes(data);

    std::cout << "\n\nThe UTF-8 file contains the following UTF-16 code units:\n"
              << std::hex;
    for (char16_t c : str16)
        std::cout << "U+" << std::setw(4) << std::setfill('0')
                  << static_cast<uint16_t>(c) << ' ';
    std::cout << '\n';
}

Output:

The UTF-8 file contains the following UCS4 code units:
U+007a U+00df U+6c34 U+1f34c

The UTF-8 file contains the following UTF-16 code units:
U+007a U+00df U+6c34 U+d83c U+df4c
