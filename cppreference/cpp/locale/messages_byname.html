template< class CharT >
class messages_byname : public std::messages<CharT>;

std::messages_byname est une facette std::messages qui encapsule la récupération de chaînes depuis les catalogues de messages des paramètres régionaux spécifiés à sa construction.

Spécialisations

La bibliothèque standard garantit de fournir les spécialisations suivantes :

Défini dans l'en-tête <locale>

  • std::messages_byname<char> — accès aux catalogues de messages à caractères étroits/multioctets
  • std::messages_byname<wchar_t> — accès aux catalogues de messages à chaînes larges

Construit une nouvelle facette std::messages_byname pour une locale avec name.

refs sert à la gestion des ressources : si refs == 0, l'implémentation détruit la facette lorsque le dernier objet std::locale qui la détient est détruit. Sinon, l'objet n'est pas détruit.

Exemple

#include <iostream>
#include <locale>

void try_with(const std::locale& loc)
{
    const std::messages<char>& facet = std::use_facet<std::messages<char>>(loc);

    std::messages<char>::catalog cat = facet.open("sed", std::cout.getloc());
    if (cat < 0)
        std::cout << "Could not open \"sed\" message catalog\n";
    else
        std::cout << "\"No match\" "
                  << facet.get(cat, 0, 0, "No match") << '\n'
                  << "\"Memory exhausted\" "
                  << facet.get(cat, 0, 0, "Memory exhausted") << '\n';

    facet.close(cat);
}

int main()
{
    std::locale loc("en_US.utf8");
    std::cout.imbue(loc);

    try_with(std::locale(loc, new std::messages_byname<char>("de_DE.utf8")));
    try_with(std::locale(loc, new std::messages_byname<char>("fr_FR.utf8")));
    try_with(std::locale(loc, new std::messages_byname<char>("ja_JP.utf8")));
}
