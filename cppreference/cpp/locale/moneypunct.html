std::moneypunct

Défini dans l'en-tête <locale>

template< class CharT, bool International = false >
class moneypunct;

La facette std::moneypunct encapsule les préférences de format des valeurs monétaires. Les manipulateurs d'E/S de flux std::get_money et std::put_money utilisent std::moneypunct à std::money_get et std::money_put pour analyser les valeurs monétaires en entrée et formater les valeurs monétaires en sortie.

Spécialisations

La bibliothèque standard garantit de fournir les spécialisations suivantes (elles sont requises pour tout objet locale) :

Défini dans l'en-tête <locale>

  • std::moneypunct<char> — fournit les équivalents des préférences de la locale « C »
  • std::moneypunct<wchar_t> — fournit les équivalents en caractères larges des préférences de la locale « C »
  • std::moneypunct<char, true> — fournit les équivalents des préférences de la locale « C », avec les symboles monétaires internationaux
  • std::moneypunct<wchar_t, true> — fournit les équivalents en caractères larges des préférences de la locale « C », avec les symboles monétaires internationaux

  • struct pattern { char field[4]; }; — le type de format monétaire

Constante d'énumération Description

  • none — les espaces blancs sont autorisés mais non requis, sauf à la dernière position, où ils ne sont pas autorisés
  • space — un ou plusieurs caractères d'espacement sont requis
  • symbol — la séquence de caractères retournée par std::moneypunct::curr_symbol est requise
  • sign — le premier des caractères retournés par std::moneypunct::positive_sign ou std::moneypunct::negative_sign est requis
  • value — la valeur monétaire absolue est requise
