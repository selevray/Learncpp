std::ispunct(std::locale)

Défini dans l'en-tête <locale>

template< class CharT >
bool ispunct( CharT ch, const locale& loc );

Vérifie si le caractère donné est classé comme signe de ponctuation par la facette std::ctype de la locale donnée.

Paramètres

  • ch — character
  • loc — locale

Valeur de retour

Renvoie true si le caractère est classé comme ponctuation, false sinon.

Implémentation possible

template<class CharT>
bool ispunct(CharT ch, const std::locale& loc)
{
    return std::use_facet<std::ctype<CharT>>(loc).is(std::ctype_base::punct, ch);
}

Exemple

Démontre l'utilisation de std::ispunct() avec différentes locales (dépendant du système d'exploitation).

#include <iostream>
#include <locale>

int main()
{
    const wchar_t c = L'\u214b'; // esperluette renversée

    std::locale loc1("C");
    std::cout << "ispunct('⅋', C locale) returned "
              << std::boolalpha << std::ispunct(c, loc1) << '\n';

    std::locale loc2("en_US.UTF-8");
    std::cout << "ispunct('⅋', Unicode locale) returned "
              << std::boolalpha << std::ispunct(c, loc2) << '\n';
}

Sortie possible :

isalpha('⅋', C locale) returned false
isalpha('⅋', Unicode locale) returned true
