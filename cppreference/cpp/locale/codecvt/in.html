  1. Fonction membre publique, appelle la fonction membre do_in de la classe la plus dérivée.

  2. Si cette facette codecvt définit une conversion, traduit les caractères externes de l'intervalle source [from,from_end) en caractères internes, en plaçant les résultats dans les positions suivantes à partir de to. Ne convertit pas plus de from_end - from caractères externes et n'écrit pas plus de to_end - to caractères internes. Laisse from_next et to_next pointant un élément après le dernier élément converti avec succès.

Si cette facette codecvt ne définit pas de conversion, aucun caractère n'est converti. to_next prend la valeur de to, state est inchangé et std::codecvt_base::noconv est renvoyé.

do_in(state, from, from_end, from_next, to, to + 1, to_next) doit renvoyer ok si

  • cette facette codecvt est utilisée par basic_filebuf, et
  • do_in(state, from, from_end, from_next, to, to_end, to_next) renverrait ok alors que to != to_end.

Valeur de retour

Une valeur de type std::codecvt_base::result, indiquant le statut de réussite comme suit :

  • ok — conversion terminée
  • partial — espace insuffisant dans le tampon de sortie ou fin inattendue du tampon source
  • error — rencontre d'un caractère qui ne peut pas être converti
  • noconv — cette facette est sans conversion, aucune sortie écrite

La spécialisation sans conversion std::codecvt<char, char, std::mbstate_t> renvoie toujours std::codecvt_base::noconv.

Notes

Exige que from <= from_end && to <= to_end et que state représentent soit l'état de décalage initial, soit l'état obtenu en convertissant les caractères précédents de la séquence.

L'effet sur state est volontairement non spécifié. Dans les facettes standard, il sert à conserver l'état de décalage, comme lors de l'appel à std::mbsrtowcs, et est donc mis à jour pour refléter l'état de conversion après le dernier caractère externe traité ; mais une facette définie par l'utilisateur est libre de l'utiliser pour conserver tout autre état, par exemple pour compter le nombre de caractères spéciaux rencontrés.

Exemple

#include <iostream>
#include <locale>
#include <string>

int main()
{
    std::locale::global(std::locale("en_US.utf8"));
    auto const& f = std::use_facet<std::codecvt<wchar_t, char, std::mbstate_t>>
        (std::locale());
    std::string external = "z\u00df\u6c34\U0001d10b"; // ou u8"zß水𝄋"
                     // ou "\x7a\xc3\x9f\xe6\xb0\xb4\xf0\x9d\x84\x8b"

    // notez que ce qui suit peut être fait avec wstring_convert
    std::mbstate_t mb = std::mbstate_t(); // état de décalage initial
    std::wstring internal(external.size(), '\0');
    const char* from_next;
    wchar_t* to_next;
    f.in(mb, &external[0], &external[external.size()], from_next,
             &internal[0], &internal[internal.size()], to_next);
    // vérification des erreurs omise par souci de concision
    internal.resize(to_next - &internal[0]);

    std::wcout << L"The string in wide encoding: " << internal << '\n';
}

Output:

The string in wide encoding: zß水𝄋
