std::codecvt<InternT,ExternT,StateT>::~codecvt

Défini dans l'en-tête <locale>

protected: ~codecvt();

Détruit une facette std::codecvt. Ce destructeur est protégé et virtuel (en raison du destructeur de la classe de base qui est virtuel). Un objet de type std::codecvt, comme la plupart des facettes, ne peut être détruit que lorsque le dernier objet std::locale qui implémente cette facette sort de sa portée, ou si une classe définie par l'utilisateur dérive de std::codecvt et déclare un destructeur public.

Exemple

#include <iostream>
#include <locale>

struct Destructible_codecvt : public std::codecvt<wchar_t, char, std::mbstate_t>
{
    Destructible_codecvt(std::size_t refs = 0) : codecvt(refs) {}
    // remarque : le destructeur implicite est public
};

int main()
{
    Destructible_codecvt dc;
    // std::codecvt<wchar_t> c; // erreur de compilation : destructeur protégé
}
