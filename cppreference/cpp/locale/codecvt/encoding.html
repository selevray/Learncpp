  1. Fonction membre publique, appelle la fonction membre do_encoding de la classe la plus dérivée.

  2. Si l'encodage représenté par cette facette codecvt associe chaque caractère interne au même nombre constant de caractères externes, renvoie ce nombre. Si l'encodage est de longueur variable (par exemple UTF-8 ou UTF-16), renvoie 0. Si l'encodage dépend d'un état, renvoie -1.

Valeur de retour

Le nombre exact de caractères externT correspondant à un caractère internT, si ce nombre est constant. 0 si le nombre varie, -1 si l'encodage dépend d'un état.

La spécialisation sans conversion std::codecvt<char, char, std::mbstate_t> renvoie 1.

Exemple

#include <iostream>
#include <locale>

int main()
{
    std::cout << "en_US.utf8 is a variable-length encoding, encoding() returns "
              << std::use_facet<std::codecvt<wchar_t, char, std::mbstate_t>>(
                     std::locale("en_US.utf8")
                 ).encoding() << '\n';

    std::cout << "zh_CN.gb18030 is also variable-length, encoding() == "
              << std::use_facet<std::codecvt<wchar_t, char, std::mbstate_t>>(
                     std::locale("zh_CN.gb18030")
                 ).encoding() << '\n';

    std::cout << "ru_RU.koi8r is a single-byte encoding, encoding() == "
              << std::use_facet<std::codecvt<wchar_t, char, std::mbstate_t>>(
                     std::locale("ru_RU.koi8r")
                 ).encoding() << '\n';
}

Output:

en_US.utf8 is a variable-length encoding, encoding() returns 0
zh_CN.gb18030 is also variable-length, encoding() == 0
ru_RU.koi8r is a single-byte encoding, encoding() == 1
