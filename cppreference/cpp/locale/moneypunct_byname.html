std::moneypunct_byname est une facette std::moneypunct qui encapsule les préférences de formatage monétaire d'une locale spécifiée à sa construction.

Spécialisations

La bibliothèque standard garantit de fournir chaque spécialisation satisfaisant les exigences sur les types suivantes :

  • CharT est l'un de char et wchar_t, et
  • Intl est une spécialisation possible pour un paramètre bool.

Exemple

Cet exemple montre comment appliquer les règles de formatage monétaire d'une autre langue sans modifier le reste de la locale.

#include <iomanip>
#include <iostream>
#include <locale>

int main()
{
    long double mon = 1234567;
    std::locale::global(std::locale("en_US.utf8"));
    std::wcout.imbue(std::locale());
    std::wcout << L"american locale: " << std::showbase
               << std::put_money(mon) << '\n';
    std::wcout.imbue(std::locale(std::wcout.getloc(),
                                 new std::moneypunct_byname<wchar_t>("ru_RU.utf8")));
    std::wcout << L"american locale with russian moneypunct: "
               << std::put_money(mon) << '\n';
}

Output:

american locale: $12,345.67
american locale with russian moneypunct: 12 345.67 руб
