std::collate

Défini dans l'en-tête <locale>

template< class CharT >
class collate;

La classe std::collate encapsule la collation (comparaison) et le hachage des chaînes propres à la locale. Cette facette est utilisée par std::basic_regex et peut être appliquée, au moyen de std::locale::operator(), directement à tous les algorithmes standard qui attendent un prédicat de comparaison de chaînes.

Spécialisations

La bibliothèque standard garantit de fournir les spécialisations suivantes (elles sont requises pour tout objet locale) :

Défini dans l'en-tête <locale>

  • std::collate<char> — implémente l'ordre lexicographique des chaînes d'octets
  • std::collate<wchar_t> — implémente l'ordre lexicographique des chaînes larges

Types imbriqués

Type Définition

  • char_type — CharT
  • string_type — std::basic_string<CharT>

Membres de données

Membre Description

  • std::locale::id id [statique] — l'identifiant de la facette

Fonctions membres

  • (constructeur) — construit une nouvelle facette collate (fonction membre publique)
  • (destructeur) — détruit une facette collate (fonction membre protégée)
  • compare — invoque do_compare (fonction membre publique)
  • transform — invoque do_transform (fonction membre publique)
  • hash — invoque do_hash (fonction membre publique)

Fonctions membres protégées

  • do_compare [virtuelle] — compare deux chaînes selon les règles de collation de cette facette (fonction membre virtuelle protégée)
  • do_transform [virtuelle] — transforme une chaîne afin que la collation puisse être remplacée par une comparaison (fonction membre virtuelle protégée)
  • do_hash [virtuelle] — génère une valeur de hachage entière selon les règles de collation de cette facette (fonction membre virtuelle protégée)

Exemple

#include <algorithm>
#include <iostream>
#include <locale>
#include <string>
#include <vector>

int main()
{
    std::locale::global(std::locale("en_US.utf8"));
    std::wcout.imbue(std::locale(""));
    std::vector<std::wstring> v
    {
        L"ar", L"zebra", L"\u00f6grupp", L"Zebra",
        L"\u00e4ngel",L"\u00e5r", L"f\u00f6rnamn"
    };

    std::wcout << "Default locale collation order: ";
    std::sort(v.begin(), v.end());
    for (auto s : v)
        std::wcout << s << ' ';
    std::wcout << '\n';

    std::wcout << "English locale collation order: ";
    std::sort(v.begin(), v.end(), std::locale("en_US.UTF-8"));
    for (auto s : v)
        std::wcout << s << ' ';
    std::wcout << '\n';

    std::wcout << "Swedish locale collation order: ";
    std::sort(v.begin(), v.end(), std::locale("sv_SE.UTF-8"));
    for (auto s : v)
        std::wcout << s << ' ';
    std::wcout << '\n';
}

Output:

Default locale collation order: Zebra ar förnamn zebra ängel år ögrupp
English locale collation order: ängel ar år förnamn ögrupp zebra Zebra
Swedish locale collation order: ar förnamn zebra Zebra år ängel ögrupp
