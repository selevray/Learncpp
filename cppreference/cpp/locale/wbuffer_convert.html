std::wbuffer_convert

Défini dans l'en-tête <locale>

template<
    class Codecvt,
    class Elem = wchar_t,
    class Tr = std::char_traits<Elem>
> class wbuffer_convert : public std::basic_streambuf<Elem, Tr>  // (depuis C++11) (obsolète en C++17) (supprimé en C++26)

std::wbuffer_convert est un encapsulateur du tampon de flux de type std::basic_streambuf<char> qui lui donne l'apparence de std::basic_streambuf<Elem>. Toutes les E/S effectuées via std::wbuffer_convert subissent une conversion de caractères telle que définie par la facette Codecvt. std::wbuffer_convert prend la propriété de la facette de conversion et ne peut pas utiliser une facette gérée par une locale.

Les facettes standard utilisables avec std::wbuffer_convert sont std::codecvt_utf8 pour les conversions UTF-8/UCS-2 et UTF-8/UCS-4, et std::codecvt_utf8_utf16 pour les conversions UTF-8/UTF-16.

Ce modèle de classe rend la fonctionnalité de conversion implicite de caractères de std::basic_filebuf disponible pour tout std::basic_streambuf.
