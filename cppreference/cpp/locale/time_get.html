Défini dans l'en-tête <locale>

template<
    class CharT,
    class InputIt = std::istreambuf_iterator<CharT>
> class time_get;

Le modèle de classe std::time_get encapsule les règles d'analyse des dates et heures. Le manipulateur d'E/S std::get_time utilise la facette std::time_get de la locale du flux d'E/S pour convertir une saisie textuelle en objet std::tm.

Diagramme d'héritage

Si une spécialisation de std::time_get n'est pas garantie d'être fournie par la bibliothèque standard (voir ci-dessous), le comportement de ses fonctions membres (à l'exception du constructeur et du destructeur) n'est pas garanti comme spécifié.

Spécialisations

La bibliothèque standard garantit de fournir les spécialisations suivantes (elles sont requises pour tout objet locale) :

Défini dans l'en-tête <locale>

  • std::time_get<char> — analyse les représentations de chaînes étroites de dates et heures
  • std::time_get<wchar_t> — analyse les représentations de chaînes larges de dates et heures

En outre, la bibliothèque standard garantit également de fournir toute spécialisation satisfaisant les exigences de types suivantes :

  • CharT est l'un de char et wchar_t, et
  • InputIt doit satisfaire aux exigences de LegacyInputIterator.

Exemple

Remarque : choisissez clang pour observer la sortie. libstdc++ n'implémente pas correctement le spécificateur %b : bug 78714.

#include <iomanip>
#include <iostream>
#include <locale>
#include <sstream>

int main()
{
    std::tm t = {};
    std::istringstream ss("2011-Februar-18 23:12:34");
    ss.imbue(std::locale("de_DE.utf-8"));

    ss >> std::get_time(&t, "%Y-%b-%d %H:%M:%S");
    if (ss.fail())
        std::cout << "Parse failed\n";
    else
        std::cout << std::put_time(&t, "%c") << '\n';
}

Sortie possible :

Sun Feb 18 23:12:34 2011
