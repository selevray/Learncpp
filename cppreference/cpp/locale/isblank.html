std::isblank(std::locale)

Défini dans l'en-tête <locale>

template< class CharT >
bool isblank( CharT ch, const locale& loc );  // (depuis C++11)

Vérifie si le caractère donné est classé comme caractère d'espacement (blank) par la facette std::ctype de la locale donnée.

Paramètres

  • ch — character
  • loc — locale

Valeur de retour

Renvoie true si le caractère est classé comme caractère d'espacement, false sinon.

Implémentation possible

template<class CharT>
bool isblank(CharT ch, const std::locale& loc)
{
    return std::use_facet<std::ctype<CharT>>(loc).is(std::ctype_base::blank, ch);
}

Exemple

Démontre l'utilisation de isblank() avec différentes locales (dépendant du système d'exploitation).

#include <iostream>
#include <locale>

void try_with(wchar_t c, const char* loc)
{
    std::wcout << "isblank('" << c << "', locale(\"" << loc << "\")) returned "
               << std::boolalpha
               << std::isblank(c, std::locale(loc)) << '\n';
}

int main()
{
    const wchar_t IDEO_SPACE = L'\u3000'; // caractère Unicode « IDEOGRAPHIC SPACE »
    try_with(IDEO_SPACE, "C");
    try_with(IDEO_SPACE, "en_US.UTF-8");
}

Sortie possible :

isblank(' ', locale("C")) returned false
isblank(' ', locale("en_US.UTF-8")) returned true
