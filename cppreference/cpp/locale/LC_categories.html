LC_ALL, LC_COLLATE, LC_CTYPE, LC_MONETARY, LC_NUMERIC, LC_TIME

Défini dans l'en-tête <clocale>

#define LC_ALL      /* implementation defined */

#define LC_COLLATE  /* implementation defined */

#define LC_CTYPE    /* implementation defined */

#define LC_MONETARY /* implementation defined */

#define LC_NUMERIC  /* implementation defined */

#define LC_TIME     /* implementation defined */

Chacune des constantes macro ci-dessus se développe en expressions constantes entières à valeurs distinctes, utilisables comme premier argument de std::setlocale.

Constante Explication

  • LC_ALL — sélectionne la locale C entière
  • LC_COLLATE — sélectionne la catégorie de collation de la locale C
  • LC_CTYPE — sélectionne la catégorie de classification des caractères de la locale C
  • LC_MONETARY — sélectionne la catégorie de formatage monétaire de la locale C
  • LC_NUMERIC — sélectionne la catégorie de formatage numérique de la locale C
  • LC_TIME — sélectionne la catégorie de formatage temporel de la locale C

Des constantes macro supplémentaires, dont les noms commencent par LC_ suivi d'au moins une lettre majuscule, peuvent être définies dans <clocale>. Par exemple, la spécification POSIX exige LC_MESSAGES (qui contrôle std::perror et std::strerror) ; la norme ISO/IEC 30112:2014 (projet de 2014) définit en outre LC_IDENTIFICATION, LC_XLITERATE, LC_NAME, LC_ADDRESS, LC_TELEPHONE, LC_PAPER, LC_MEASUREMENT et LC_KEYBOARD, qui sont pris en charge par la bibliothèque C de GNU (à l'exception de LC_XLITERATE).

Exemple

#include <clocale>
#include <cstdio>
#include <ctime>
#include <cwchar>

int main()
{
    // la locale C sera l'anglais avec UTF-8 activé :
    std::setlocale(LC_ALL, "en_US.UTF-8");

    // le point décimal sera celui de l'allemand :
    std::setlocale(LC_NUMERIC, "de_DE.UTF-8");

    // le formatage des dates et heures sera celui du japonais :
    std::setlocale(LC_TIME, "ja_JP.UTF-8");

    wchar_t str[100];
    std::time_t t = std::time(nullptr);
    std::wcsftime(str, 100, L"%A %c", std::localtime(&t));
    std::wprintf(L"Number: %.2f\nDate: %Ls\n", 3.14, str);
}

Output:

Number: 3,14
Date: 日曜日 2022年11月06日 17時55分10秒
