std::has_facet

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

template< class Facet >
bool has_facet( const locale& loc ) throw();  // (jusqu'à C++11)

template< class Facet >
bool has_facet( const locale& loc ) noexcept;  // (depuis C++11)

Vérifie si la locale loc implémente la facette Facet.

Le programme est mal formé si Facet n'est pas une facette ou s'il s'agit d'une facette qualifiée volatile.

Paramètres

  • loc — l'objet locale à interroger

Valeur de retour

Renvoie true si la facette Facet a été installée dans la locale loc, false sinon.

Notes

std::has_facet doit renvoyer true pour toutes les locales loc si Facet est l'une des facettes standard données ici.

Exemple

#include <iostream>
#include <locale>

// facette personnalisée minimale
struct myfacet : public std::locale::facet
{
    static std::locale::id id;
};

std::locale::id myfacet::id;

int main()
{
    // loc est une locale "C" à laquelle myfacet a été ajoutée
    std::locale loc(std::locale::classic(), new myfacet);
    std::cout << std::boolalpha
              << "Can loc classify chars? "
              << std::has_facet<std::ctype<char>>(loc) << '\n'
              << "Can loc classify char32_t? "
              << std::has_facet<std::ctype<char32_t>>(loc) << '\n'
              << "Does loc implement myfacet? "
              << std::has_facet<myfacet>(loc) << '\n';
}

Output:

Can loc classify chars? true
Can loc classify char32_t? false
Does loc implement myfacet? true
