std::moneypunct<CharT,International>::curr_symbol, do_curr_symbol

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

public:
string_type curr_symbol() const;  // (1)

protected:
virtual string_type do_curr_symbol() const;  // (2)

  1. Fonction membre publique, appelle la fonction membre do_curr_symbol de la classe la plus dérivée.

  2. Renvoie la chaîne utilisée comme identifiant de devise par cette locale. Si International (le second paramètre de modèle de std::moneypunct) vaut false, l'identifiant est généralement un seul caractère (large), comme "￥" ou "$". Si International vaut true, l'identifiant est généralement une chaîne de quatre caractères contenant le code de devise ISO 4217 à trois caractères suivi d'une espace ("JPY " ou "USD ").

Valeur de retour

L'objet de type string_type contenant le symbole ou le code de devise.

Exemple

#include <iostream>
#include <locale>

void show_ccy(const char* locname)
{
    std::locale loc(locname);
    std::cout << locname << " currency symbol is "
              << std::use_facet<std::moneypunct<char, true>>(loc).curr_symbol()
              << "or " << std::use_facet<std::moneypunct<char>>(loc).curr_symbol()
              << " for short\n";
}

int main()
{
    show_ccy("en_US.utf8");
    show_ccy("ja_JP.utf8");
    show_ccy("sv_SE.utf8");
    show_ccy("ru_RU.utf8");
    show_ccy("vi_VN.utf8");
}

Output:

en_US.utf8 currency symbol is USD or $ for short
ja_JP.utf8 currency symbol is JPY or ￥ for short
sv_SE.utf8 currency symbol is SEK or kr for short
ru_RU.utf8 currency symbol is RUB or руб for short
vi_VN.utf8 currency symbol is VND or ₫ for short
