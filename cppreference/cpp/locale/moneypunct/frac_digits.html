std::moneypunct<CharT,International>::frac_digits, do_frac_digits

Défini dans l'en-tête <locale>

public:
int frac_digits() const;  // (1)

protected:
virtual int do_frac_digits() const;  // (2)

  1. Fonction membre publique, appelle la fonction membre do_frac_digits de la classe la plus dérivée.

  2. Renvoie le nombre de chiffres à afficher après le point décimal lors de l'affichage de valeurs monétaires.

Valeur de retour

Le nombre de chiffres à afficher après le point décimal. Dans les locales américaines courantes, cette valeur vaut 2.

Exemple

#include <iomanip>
#include <iostream>
#include <iterator>
#include <locale>

struct space_out : std::moneypunct<char>
{
    pattern do_pos_format() const { return {value, none, none, none}; }
    int do_frac_digits() const { return 0; }
    char_type do_thousands_sep() const { return ' '; }
    string_type do_grouping() const { return "\002"; }
};

int main()
{
    std::cout.imbue(std::locale("en_US.UTF-8"));
    std::cout << "american locale: " << std::showbase
              << std::put_money(12345678.0) << '\n';

    std::cout.imbue(std::locale(std::cout.getloc(), new space_out));
    std::cout << "locale with modified moneypunct: "
              << std::put_money(12345678.0) << '\n';
}

Output:

american locale: $123,456.78
locale with modified moneypunct: 12 34 56 78
