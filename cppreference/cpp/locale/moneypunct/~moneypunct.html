std::moneypunct<CharT,International>::~moneypunct

Défini dans l'en-tête <locale>

protected: ~moneypunct();

Détruit une facette std::moneypunct. Ce destructeur est protégé et virtuel (en raison du destructeur de la classe de base qui est virtuel). Un objet de type std::moneypunct, comme la plupart des facettes, ne peut être détruit que lorsque le dernier objet std::locale qui implémente cette facette sort de sa portée, ou si une classe définie par l'utilisateur dérive de std::moneypunct et déclare un destructeur public.

Exemple

#include <iostream>
#include <locale>

struct Destructible_moneypunct : public std::moneypunct<wchar_t>
{
    Destructible_moneypunct(std::size_t refs = 0) : moneypunct(refs) {}
    // remarque : le destructeur implicite est public
};

int main()
{
    Destructible_moneypunct dc;
    // std::moneypunct<wchar_t> c; // erreur de compilation : destructeur protégé
}
