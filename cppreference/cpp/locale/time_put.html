std::time_put

Défini dans l'en-tête <locale>

template<
    class CharT,
    class OutputIt = std::ostreambuf_iterator<CharT>
> class time_put;

Le modèle de classe std::time_put encapsule les règles de formatage des dates et heures. Le manipulateur d'E/S std::put_time utilise la facette std::time_put de la locale du flux d'E/S pour générer la représentation textuelle d'un objet std::tm.

Diagramme d'héritage

Si une spécialisation de std::time_put n'est pas garantie d'être fournie par la bibliothèque standard (voir ci-dessous), les comportements de ses put() et do_put() ne sont pas garantis tels que spécifiés.

Spécialisations

La bibliothèque standard garantit de fournir les spécialisations suivantes (elles sont requises pour tout objet locale) :

Défini dans l'en-tête <locale>

  • std::time_put<char> — crée des représentations de chaînes étroites de dates et heures
  • std::time_put<wchar_t> — crée des représentations de chaînes larges de dates et heures

En outre, la bibliothèque standard garantit également de fournir toute spécialisation satisfaisant les exigences de types suivantes :

  • CharT est l'un de char et wchar_t, et
  • OutputIt doit satisfaire aux exigences de LegacyOutputIterator.

  • iter_type — OutputIt

Fonctions membres

  • (destructeur) — détruit une facette time_put (fonction membre protégée)
  • put — invoque do_put (fonction membre publique)

Fonctions membres protégées

  • do_put [virtuelle] — formate la date/heure et l'écrit dans le flux de sortie (fonction membre virtuelle protégée)

Exemple

#include <codecvt>
#include <ctime>
#include <iomanip>
#include <iostream>

int main()
{
    std::time_t t = std::time(nullptr);
    std::wbuffer_convert<std::codecvt_utf8<wchar_t>> conv(std::cout.rdbuf());
    std::wostream out(&conv);
    out.imbue(std::locale("ja_JP.utf8"));

    // ce manipulateur d'E/S std::put_time utilise std::time_put<wchar_t>
    out << std::put_time(std::localtime(&t), L"%A %c") << '\n';
}

Output:

水曜日 2011年11月09日 12時32分05秒
