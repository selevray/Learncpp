template< class CharT >
bool isgraph( CharT ch, const locale& loc );

Vérifie si le caractère donné est classé comme caractère graphique (c'est-à-dire imprimable, espace exclu) par la facette std::ctype de la locale donnée.

Paramètres

  • ch — character
  • loc — locale

Valeur de retour

Renvoie true si le caractère est classé comme graphique, false sinon.

Implémentation possible

template<class CharT>
bool isgraph(CharT ch, const std::locale& loc)
{
    return std::use_facet<std::ctype<CharT>>(loc).is(std::ctype_base::graph, ch);
}

Exemple

Démontre l'utilisation de isgraph() avec différentes locales (dépendant du système d'exploitation).

#include <iostream>
#include <locale>

int main()
{
    const wchar_t c = L'\u2a0c'; // quadruple intégral

    std::locale loc1("C");
    std::cout << "isgraph('⨌', C locale) returned "
              << std::boolalpha << std::isgraph(c, loc1) << '\n';

    std::locale loc2("en_US.UTF-8");
    std::cout << "isgraph('⨌', Unicode locale) returned "
              << std::boolalpha << std::isgraph(c, loc2) << '\n';
}

Sortie possible :

isgraph('⨌', C locale) returned false
isgraph('⨌', Unicode locale) returned true
