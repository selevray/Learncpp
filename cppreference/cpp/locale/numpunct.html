std::numpunct

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale>

template< class CharT >
class numpunct;

La facette std::numpunct encapsule les préférences de ponctuation numérique. Les opérations d'E/S de flux utilisent std::numpunct à travers std::num_get et std::num_put pour analyser les entrées numériques et formater les sorties numériques.

Les nombres pris en charge par std::numpunct ont le format décrit ci-dessous. Ici digit représente l'ensemble de bases spécifié par l'argument fmtflags, thousands-sep et decimal-point sont les résultats des fonctions thousands_sep() et decimal_point() respectivement.

Le format des valeurs entières est le suivant :

integer     ::= [sign] units
sign        ::= plusminus
plusminus   ::= '+' | '-'
units       ::= digits [thousands-sep units]
digits      ::= digit [digits]

Le nombre de chiffres entre les thousand-sep (taille maximale de digits) est spécifié par le résultat de grouping().

Le format des valeurs à virgule flottante est le suivant :

floatval    ::= [sign] units [decimal-point [digits]] [e [sign] digits] |
                [sign]        decimal-point  digits   [e [sign] digits]
e           ::= 'e' | 'E'

Spécialisations

La bibliothèque standard garantit de fournir les spécialisations suivantes (elles sont requises pour tout objet locale) :

Défini dans l'en-tête <locale>

  • std::numpunct<char> — fournit les équivalents des préférences de la locale « C »
  • std::numpunct<wchar_t> — fournit les équivalents en caractères larges des préférences de la locale « C »

Types imbriqués

  • string_type — std::basic_string<CharT>

Membres de données

  • std::locale::id id [statique] — l'identifiant de la facette

Fonctions membres

  • (constructeur) — construit une nouvelle facette numpunct (fonction membre publique)
  • (destructeur) — détruit une facette numpunct (fonction membre protégée)
  • decimal_point — invoque do_decimal_point (fonction membre publique)
  • thousands_sep — invoque do_thousands_sep (fonction membre publique)
  • grouping — invoque do_grouping (fonction membre publique)
  • truenamefalsename — invoque do_truename ou do_falsename (fonction membre publique)

Fonctions membres protégées

  • do_decimal_point [virtuelle] — fournit le caractère à utiliser comme point décimal (fonction membre protégée virtuelle)
  • do_thousands_sep [virtuelle] — fournit le caractère à utiliser comme séparateur de milliers (fonction membre protégée virtuelle)
  • do_grouping [virtuelle] — fournit le nombre de chiffres entre chaque paire de séparateurs de milliers (fonction membre protégée virtuelle)
  • do_truenamedo_falsename [virtuelle] — fournit la chaîne à utiliser comme nom du booléen true et false (fonction membre protégée virtuelle)

Exemple

L'exemple suivant modifie les représentations sous forme de chaînes de true et false :

#include <iostream>
#include <locale>

struct french_bool : std::numpunct<char>
{
    string_type do_truename() const override { return "vrai"; }
    string_type do_falsename() const override { return "faux"; }
};

int main()
{
    std::cout << "default locale: "
              << std::boolalpha << true << ", " << false << '\n';
    std::cout.imbue(std::locale(std::cout.getloc(), new french_bool));
    std::cout << "locale with modified numpunct: "
              << std::boolalpha << true << ", " << false << '\n';
}

Output:

default locale: true, false
locale with modified numpunct: vrai, faux
