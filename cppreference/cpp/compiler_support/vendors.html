Oracle C++ (mis à jour 2017-07)

  • Le numéro de version est celui du compilateur, et non celui d'Oracle Studio
  • État de la prise en charge du langage de base C++11 dans 5.13
    • Prise en charge manquante de C++11 ajoutée dans 5.14 (la page contient une coquille et indique encore 5.13)
  • Fonctionnalités C++14 ajoutées dans 5.14
    • Prise en charge complète de C++14 ajoutée dans 5.15.
  • Oracle livre 4 implémentations de la bibliothèque standard C++ :
    • libCstd (RogueWave Standard Library version 2), antérieure à C++98
    • stlport4 (STLport Standard Library version 4.5.3), antérieure à C++03
    • stdcxx4 (Apache Standard Library version 4), antérieure à C++11
    • libstdc++ (bibliothèque d'exécution de GCC, prise en charge de C++11 et C++14 selon la version)

  • HPE Cray Clang C and C++ Quick Reference (14.0) (S-2179) Les versions à partir de 11 (jusqu'à au moins 14) sont basées sur Clang et l'on attend généralement une prise en charge correspondante du langage. Les fonctionnalités qui impliquent un comportement « intéressant » de génération de code ou d'édition de liens, comme les coroutines ou les modules, peuvent accuser un retard, car le compilateur prend en charge la génération de code pour les GPU et d'autres dispositifs similairement limités
