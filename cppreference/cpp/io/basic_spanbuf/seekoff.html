std::basic_spanbuf<CharT,Traits>::seekoff

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
pos_type seekoff( off_type off, std::ios_base::seekdir dir,
                  std::ios_base::openmode which =
                      std::ios_base::in | std::ios_base::out ) override;  // (depuis C++23)

Repositionne le pointeur suivant vers la zone get et/ou put, si possible, à la position correspondant exactement à off caractères depuis le début, la fin ou la position courante de la zone get et/ou put du tampon.

Soit n le nombre d'éléments CharT dans le tampon sous-jacent, ou 0 lorsqu'il n'y a pas de tampon sous-jacent ; cette fonction échoue si

  • le pointeur suivant vers la zone get et/ou put à repositionner est nul et le newoff calculé (voir ci-dessous) n'est pas nul, ce qui peut se produire s'il n'y a pas de tampon sous-jacent, ou si le *this n'est pas ouvert dans le mode requis par which, ou
  • dir vaut std::ios_base::cur et std::ios_base::in et std::ios_base::out sont tous deux définis dans which, ou
  • le newoff calculé n'est pas représentable dans off_type, est inférieur à zéro, ou supérieur à n.

newoff se calcule comme suit :

  • Si dir vaut std::ios_base::beg, newoff vaut off.
  • Si dir vaut std::ios_base::cur, newoff vaut
    • pptr() - pbase() + off si std::ios_base::out est défini dans which, ou
    • gptr() - eback() + off si std::ios_base::in est défini dans which.
  • Si dir vaut std::ios_base::end, newoff vaut
    • pptr() - pbase() + off si std::ios_base::out mais pas std::ios_base::in est défini dans le mode d'ouverture de *this,
    • sinon, off + n.

Cette fonction repositionne le pointeur suivant de la zone de lecture et/ou d'écriture à pbuf + newoff en cas de succès si std::ios_base::in et/ou std::ios_base::out est défini en conséquence dans which, où pbuf est le pointeur vers le début du tampon sous-jacent, ou la valeur de pointeur nul s'il n'existe aucun tampon sous-jacent.

Paramètres

  • off — position relative à laquelle définir le ou les pointeurs suivants

  • dir — définit la position de base à laquelle appliquer le décalage relatif. Elle peut être l'une des constantes suivantes :

    Constante Explication

    • beg — le début d'un flux
    • end — la fin d'un flux
    • cur — la position courante de l'indicateur de position du flux

  • which — définit si les séquences d'entrée, la séquence de sortie, ou les deux sont affectées. Il peut s'agir de l'une des constantes suivantes ou d'une combinaison de celles-ci :

    Constante Explication

    • in — affecte la séquence d'entrée
    • out — affecte la séquence de sortie

Valeur de retour

pos_type(newoff) en cas de succès, pos_type(off_type(-1)) en cas d'échec.
