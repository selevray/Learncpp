std::basic_spanbuf<CharT,Traits>::basic_spanbuf

basic_spanbuf() : basic_spanbuf(std::ios_base::in | std::ios_base::out) {}  // (1) (depuis C++23)

explicit basic_spanbuf( std::ios_base::openmode which )
    : basic_spanbuf(std::span<CharT>{}, which) {}  // (2) (depuis C++23)

explicit basic_spanbuf( std::span<CharT> buf, std::ios_base::openmode which =
                            std::ios_base::in | std::ios_base::out );  // (3) (depuis C++23)

basic_spanbuf( const basic_spanbuf& ) = delete;  // (4) (depuis C++23)

basic_spanbuf( basic_spanbuf&& rhs );  // (5) (depuis C++23)

  1. Constructeur par défaut. Crée un basic_spanbuf qui n'a aucun tampon sous-jacent et qui est ouvert en entrée et en sortie. Les pointeurs vers la zone get et la zone put sont fixés à la valeur de pointeur nul.

  2. Identique à (1), sauf que le basic_spanbuf est ouvert selon le mode spécifié par which.

  3. Crée un basic_spanbuf qui gère le tampon sous-jacent référencé par buf (ou n'a aucun tampon sous-jacent si buf est vide) et qui est ouvert selon le mode spécifié par which. Les pointeurs vers la zone get et la zone put sont fixés comme suit, ou à la valeur de pointeur nul si non mentionné dans le tableau :

Active des bits dans le mode d'ouverture
(affectant les pointeurs de la zone get) | Valeur de retour après la définition

eback() | gptr() | egptr()

std::ios_base::in | s.data() | s.data() | s.data() + s.size()

Active des bits dans le mode d'ouverture
(affectant les pointeurs de la zone put) | Valeur de retour après la définition

pbase() | pptr() | epptr()

std::ios_base::out && !std::ios_base::ate | s.data() | s.data() | s.data() + s.size()

std::ios_base::out && std::ios_base::ate | s.data() | s.data() + s.size() | s.data() + s.size()

  1. Le constructeur de copie est supprimé. basic_spanbuf n'est pas copiable.

  2. Constructeur de déplacement. Construit par déplacement le sous-objet de base std::basic_streambuf à partir de celui de rhs. Les pointeurs vers la zone get et la zone put, le mode d'ouverture et le tampon sous-jacent (le cas échéant) sont identiques à ceux de rhs avant la construction.
    Il est défini par l'implémentation de savoir si rhs conserve encore le tampon sous-jacent après la construction par déplacement.

Paramètres

  • buf — un std::span référençant le tampon sous-jacent

  • rhs — un autre basic_spanbuf

  • which — spécifie le mode d'ouverture du flux. C'est un type masque de bits, les constantes suivantes sont définies :

    Constante Explication

    • app — se positionne à la fin du flux avant chaque écriture
    • binary — ouvre en mode binaire
    • in — ouvre en lecture
    • out — ouvre en écriture
    • trunc — supprime le contenu du flux à l'ouverture
    • ate — se positionner à la fin du flux immédiatement après l'ouverture
    • noreplace (C++23) — ouvrir en mode exclusif

Notes

Ces constructeurs sont généralement appelés par les constructeurs de std::basic_ispanstream, std::basic_ospanstream et std::basic_spanstream.
