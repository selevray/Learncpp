std::basic_spanbuf<CharT,Traits>::setbuf

protected:
std::basic_streambuf<CharT, Traits>* setbuf( CharT *s, std::streamsize n ) override;  // (depuis C++23)

Fait effectuer des E/S à basic_spanbuf sur le tampon [s,s + n). Équivalent à l'appel de this->span(std::span<CharT>(s, n)) puis renvoie this.

Active des bits dans le mode d'ouverture
(affectant les pointeurs de la zone get) | Valeur de retour après la définition

eback() | gptr() | egptr()

std::ios_base::in | s | s | s + n

Active des bits dans le mode d'ouverture
(affectant les pointeurs de la zone put) | Valeur de retour après la définition

pbase() | pptr() | epptr()

std::ios_base::out && !std::ios_base::ate | s | s | s + n

std::ios_base::out && std::ios_base::ate | s | s + n | s + n

Cette fonction est protégée et virtuelle ; elle ne peut être appelée que par l'intermédiaire de pubsetbuf() ou depuis les fonctions membres d'une classe définie par l'utilisateur dérivée de std::basic_spanbuf.

Paramètres

  • s — pointeur vers le premier CharT du tampon fourni par l'utilisateur
  • n — le nombre d'éléments CharT du tampon fourni par l'utilisateur

Valeur de retour

this

Notes

Le tampon de flux std::strstreambuf obsolète ou le périphérique boost.IOStreams boost::basic_array peuvent également implémenter une mise en mémoire tampon des E/S sur un tableau char fourni par l'utilisateur.
