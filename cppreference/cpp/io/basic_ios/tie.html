std::basic_ios<CharT,Traits>::tie

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

std::basic_ostream<CharT, Traits>* tie() const;  // (1)

std::basic_ostream<CharT, Traits>* tie( std::basic_ostream<CharT, Traits>* str );  // (2)

Gère le flux lié. Un flux lié est un flux de sortie synchronisé avec la séquence contrôlée par le tampon de flux (rdbuf()), c'est-à-dire que flush() est appelé sur le flux lié avant toute opération d'entrée/sortie sur *this.

  1. Renvoie le flux lié actuel. S'il n'existe pas de flux lié, un pointeur nul est renvoyé.

  2. Définit le flux lié actuel à str. Renvoie le flux lié avant l'opération. S'il n'existe pas de flux lié, un pointeur nul est renvoyé. Si str n'est pas nul et que tie() est atteignable en parcourant la liste chaînée des objets de flux liés à partir de str->tie(), le comportement est indéfini.

Paramètres

  • str — un flux de sortie à définir comme flux lié

Valeur de retour

Le flux lié, ou un pointeur nul s'il n'existait pas de flux lié.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Notes

Par défaut, le flux standard std::cout est lié à std::cin et std::cerr. De même, son équivalent large std::wcout est lié à std::wcin et std::wcerr.

Exemple

#include <fstream>
#include <iomanip>
#include <iostream>
#include <string>

int main()
{
    std::ofstream os("test.txt");
    std::ifstream is("test.txt");
    std::string value("0");

    os << "Hello";
    is >> value;

    std::cout << "Result before tie(): " << std::quoted(value) << "\n";
    is.clear();
    is.tie(&os);

    is >> value;

    std::cout << "Result after tie(): " << std::quoted(value) << "\n";
}

Output:

Result before tie(): "0"
Result after tie(): "Hello"

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 835 C++98 deux flux pourraient être liés l'un à l'autre[1] (directement ou via un autre objet de flux intermédiaire) le comportement est indéfini dans ce cas
  1. ↑ std::basic_ostream::flush() est un UnformattedOutputFunction, il crée donc un objet sentry lors de son appel. Lorsque flush() est appelé sur un objet flux, le constructeur de l'objet sentry appelle flush() sur son flux lié, et cette flush() construit un autre objet sentry dont le constructeur appelle flush() sur le flux lié de ce flux, et ainsi de suite. Par conséquent, si les flux a et b sont liés (directement ou indirectement) l'un à l'autre, appeler a.flush() finira par appeler b.flush(), qui finira par appeler a.flush(), ce qui aboutira à une boucle infinie.
