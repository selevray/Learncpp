std::basic_ios<CharT,Traits>::copyfmt

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

basic_ios& copyfmt( const basic_ios& other );

Si other désigne le même objet que *this, n'a aucun effet. Sinon, copie l'état du flux other dans *this. Ceci se fait dans la séquence suivante :

  1. Appelle chaque fonction de rappel enregistrée par register_callback() en passant erase_event comme paramètre.

  2. Copie tous les objets membres de other vers *this à l'exception de rdstate(), du masque d'exceptions et de rdbuf(). En particulier, effectue des copies de la locale, des indicateurs de formatage, du contenu des tableaux std::ios_base::iword et std::ios_base::pword (mais pas des pointeurs iword et pword eux-mêmes), des fonctions de rappel et du flux lié.

  3. Appelle chaque fonction de rappel enregistrée par register_callback() en passant copyfmt_event comme paramètre.

  4. Copie le masque d'exceptions de other vers *this comme si on appelait exceptions(other.exceptions()).

Paramètres

  • other — un autre flux à utiliser comme source

Valeur de retour

*this

Notes

Le second parcours des fonctions de rappel peut servir à effectuer une copie profonde des objets définis par l'utilisateur pointés par les pointeurs de std::ios_base::pword.

copyfmt() peut être utilisé pour sauvegarder et restaurer l'état d'un flux. Boost fournit à cette fin une bibliothèque I/O state savers plus fine.

Exemple

Fait en sorte que l'objet std::ofstream « out » se comporte exactement comme std::cout, y compris le formatage, tie() vers std::cin, etc.

#include <bitset>
#include <climits>
#include <fstream>
#include <iostream>

int main()
{
    std::ofstream out;

    out.copyfmt(std::cout); // copie tout sauf rdstate et rdbuf
    out.clear(std::cout.rdstate()); // copie rdstate
    out.basic_ios<char>::rdbuf(std::cout.rdbuf()); // partage le tampon

    out << "Hello, world\n";

    auto bin = [](std::ios_base::fmtflags f)
    {
        return std::bitset<sizeof(std::ios_base::fmtflags) * CHAR_BIT>
            { static_cast<unsigned long long>(f) };
    };
    std::ofstream out2;
    std::cout << "1) out2.flags(): " << bin(out2.flags()) << '\n';
    std::cout << "2) cout.flags(): " << bin(std::cout.flags()) << '\n';
    std::cout.setf(std::ios::hex | std::ios::fixed | std::ios::boolalpha);
    std::cout << "3) cout.flags(): " << bin(std::cout.flags()) << '\n';
    out2.copyfmt(std::cout); // copie tout sauf rdstate et rdbuf
    std::cout << "4) out2.flags(): " << bin(out2.flags()) << '\n';
}

2) cout.flags(): 00000000000000000001000000000010
3) cout.flags(): 00000000000000000001000000001111
4) out2.flags(): 00000000000000000001000000001111

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 256 C++98 l'étape 3 appelait les fonctions de rappel enregistrées avec le type d'événement copy_event, qui n'est pas défini corrigé en copyfmt_event
LWG 292 C++98 si other désigne le même objet que *this, les objets membres étaient quand même copiés et les fonctions de rappel enregistrées étaient quand même appelées ne fait rien dans ce cas
