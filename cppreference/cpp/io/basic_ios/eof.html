std::basic_ios<CharT,Traits>::eof

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool eof() const;

Renvoie true si le flux associé a atteint la fin de fichier. Plus précisément, renvoie true si eofbit est défini dans rdstate().

Voir ios_base::iostate pour la liste des conditions qui positionnent eofbit.

Paramètres

(aucune)

Valeur de retour

true si une fin de fichier s'est produite, false sinon.

Notes

Cette fonction ne signale que l'état du flux tel que défini par la dernière opération d'E/S ; elle n'examine pas la source de données associée. Par exemple, si la dernière E/S était un get() ayant renvoyé le dernier octet d'un fichier, eof() renvoie false. Le get() suivant ne lit rien et définit eofbit. Ce n'est qu'alors que eof() renvoie true.

En usage courant, le traitement d'un flux d'entrée s'arrête à la moindre erreur. eof() et fail() peuvent alors être utilisés pour distinguer les différentes conditions d'erreur.

Exemple

#include <cstdlib>
#include <fstream>
#include <iostream>

int main()
{
    std::ifstream file("test.txt");
    if (!file) // operator! est utilisé ici
    {
        std::cout << "File opening failed\n";
        return EXIT_FAILURE;
    }

    // une boucle d'E/S typique en C++ utilise la valeur de retour de la fonction d'E/S
    // comme condition de contrôle de la boucle, operator bool() est utilisé ici
    for (int n; file >> n;)
       std::cout << n << ' ';
    std::cout << '\n';

    if (file.bad())
        std::cout << "I/O error while reading\n";
    else if (file.eof())
        std::cout << "End of file reached successfully\n";
    else if (file.fail())
        std::cout << "Non-integer data encountered\n";
}
