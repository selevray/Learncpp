std::basic_ios<CharT,Traits>::clear

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void clear( std::ios_base::iostate state = std::ios_base::goodbit );

Définit les indicateurs d'état d'erreur du flux en leur affectant la valeur de state. Par défaut, affecte std::ios_base::goodbit, ce qui a pour effet d'effacer tous les indicateurs d'état d'erreur.

Si rdbuf() est un pointeur nul (c'est-à-dire s'il n'y a pas de tampon de flux associé), alors state | std::ios_base::badbit est affecté.

Paramètres

  • state — nouvelle valeur des indicateurs d'état d'erreur. Il peut s'agir d'une combinaison des constantes suivantes :

    Constante Explication

    • goodbit — aucune erreur
    • badbit — erreur irrécupérable du flux
    • failbit — échec de l'opération d'entrée/sortie (erreur de formatage ou d'extraction)
    • eofbit — la séquence d'entrée associée a atteint la fin de fichier

Valeur de retour

(aucune)

Exceptions

Si le nouvel état d'erreur inclut un bit également inclus dans le masque exceptions(), lève une exception de type failure.

Exemple

clear() sans arguments peut être utilisé pour réinitialiser le failbit après une entrée inattendue ; pour std::cin.putback(c), voir ungetc.

#include <iostream>
#include <string>

int main()
{
    for (char c : {'\n', '4', '1', '.', '3', '\n', 'Z', 'Y', 'X'})
        std::cin.putback(c); // émule la saisie de l'utilisateur (non portable : voir Notes de ungetc)

    double n;
    while (std::cout << "Please, enter a number: " && !(std::cin >> n))
    {
        std::cin.clear();
        std::string line;
        std::getline(std::cin, line);
        std::cout << line << "\nI am sorry, but '" << line << "' is not a number\n";
    }
    std::cout << n << "\nThank you for entering the number " << n << '\n';
}

Output:

Please, enter a number: XYZ
I am sorry, but 'XYZ' is not a number
Please, enter a number: 3.14
Thank you for entering the number 3.14
