std::basic_ios<CharT,Traits>::operator bool

operator /* unspecified-boolean-type */() const;  // (1) (jusqu'à C++11)

explicit operator bool() const;  // (2) (depuis C++11)

Vérifie si le flux ne comporte aucune erreur.

  1. Renvoie une valeur qui s'évalue à false dans un contexte booléen si fail() renvoie true, sinon renvoie une valeur qui s'évalue à true dans un contexte booléen.

  2. Renvoie true si le flux ne comporte aucune erreur et est prêt pour les opérations d'E/S. Plus précisément, renvoie !fail().

Cet opérateur permet d'utiliser des flux et des fonctions renvoyant des références vers des flux comme conditions de boucle, ce qui donne les boucles de lecture idiomatiques du C++ telles que while (stream >> value) {...} ou while (std::getline(stream, string)) {...}. Ces boucles n'exécutent le corps de la boucle que si l'opération d'entrée a réussi.

Paramètres

(aucune)

Valeur de retour

  1. Une valeur qui s'évalue à true dans un contexte booléen si le flux ne comporte aucune erreur, une valeur qui s'évalue à false dans un contexte booléen sinon.

  2. true si le flux ne comporte aucune erreur, false sinon.

Notes

Cette conversion peut être utilisée dans les contextes où un bool est attendu (par ex. une condition if). Cependant, les conversions implicites (par ex. vers int) pouvant survenir avec bool ne sont pas autorisées.

En C++98, operator bool ne pouvait pas être fourni directement en raison du problème du safe bool. La solution initiale en C++98 consiste à fournir operator void*, qui renvoie un pointeur nul si fail() renvoie true, ou un pointeur non nul sinon. Elle a été remplacée par la résolution du LWG issue 468, qui permet d'appliquer l'idiome Safe Bool.

Depuis C++11, les fonctions de conversion peuvent être explicit. La résolution du LWG issue 1094 a introduit le operator bool explicite, et la conversion booléenne est désormais sûre.

Exemple

#include <iostream>
#include <sstream>

int main()
{
    std::istringstream s("1 2 3 error");
    int n;

    std::cout << std::boolalpha << "s is " << static_cast<bool>(s) << '\n';
    while (s >> n)
        std::cout << n << '\n';
    std::cout << "s is " << static_cast<bool>(s) << '\n';
}

Output:

s is true
1
2
3
s is false
