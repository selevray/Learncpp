std::locale imbue( const std::locale& loc );

Remplace la locale courante. Appelle effectivement ios_base::imbue(loc) et, s'il existe un tampon de flux associé (rdbuf() != 0), appelle rdbuf()->pubimbue(loc).

Paramètres

  • loc — la nouvelle locale

Valeur de retour

La locale précédente, telle que renvoyée par ios_base::imbue(loc).

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <iostream>
#include <locale>
#include <sstream>

int main()
{
    std::istringstream iss;
    iss.imbue(std::locale("en_US.UTF8"));

    std::cout << "Current locale: " << iss.getloc().name() << '\n';

    iss.imbue(std::locale());
    std::cout << "Global locale : " << iss.getloc().name() << '\n';
}

Output:

Current locale: en_US.UTF8
Global locale : C
