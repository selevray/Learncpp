std::basic_ios<CharT,Traits>::setstate

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void setstate( iostate state );

Définit les indicateurs d'erreur du flux state en plus des indicateurs déjà définis. Appelle essentiellement clear(rdstate() | state). Peut lever une exception.

Paramètres

  • state — indicateurs d'état d'erreur du flux à définir. Il peut s'agir d'une combinaison des constantes suivantes :

    Constante Explication

    • goodbit — aucune erreur
    • badbit — erreur irrécupérable du flux
    • failbit — échec de l'opération d'entrée/sortie (erreur de formatage ou d'extraction)
    • eofbit — la séquence d'entrée associée a atteint la fin de fichier

Valeur de retour

(aucune)

Exemple

#include <iostream>
#include <sstream>

int main()
{
    std::ostringstream stream;

    if (!stream.fail())
        std::cout << "stream is not fail\n";

    stream.setstate(std::ios_base::failbit);

    if (stream.fail())
        std::cout << "now stream is fail\n";

    if (!stream.good())
        std::cout << "and stream is not good\n";
}

Output:

stream is not fail
now stream is fail
and stream is not good
