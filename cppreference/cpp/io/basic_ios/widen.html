char_type widen( char c ) const;

Convertit un caractère c en son équivalent dans la locale actuelle. Le résultat est converti de char vers le type de caractère utilisé dans le flux si nécessaire.

Appelle effectivement std::use_facet< std::ctype<char_type> >(getloc()).widen(c).

Paramètres

  • c — caractère à convertir

Valeur de retour

Caractère converti en char_type
