std::basic_ios<CharT,Traits>::rdbuf

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

std::basic_streambuf<CharT, Traits>* rdbuf() const;  // (1)

std::basic_streambuf<CharT, Traits>* rdbuf( std::basic_streambuf<CharT, Traits>* sb );  // (2)

Gère le tampon de flux associé.

  1. Renvoie le tampon de flux associé. S'il n'existe pas de tampon de flux associé, renvoie un pointeur nul.

  2. Définit le tampon de flux associé à sb. L'état d'erreur est effacé par l'appel de clear(). Renvoie le tampon de flux associé avant l'opération. S'il n'existe pas de tampon de flux associé, renvoie un pointeur nul.

Paramètres

  • sb — Tampon de flux à associer.

Valeur de retour

Le tampon de flux associé, ou un pointeur nul s'il n'existait pas de tampon de flux associé.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <iostream>
#include <sstream>

int main()
{
    std::ostringstream local;
    auto cout_buff = std::cout.rdbuf(); // sauvegarde le pointeur vers le tampon de std::cout

    std::cout.rdbuf(local.rdbuf()); // remplace le tampon interne de std::cout par
                                    // tampon de l'objet « local »

    // désormais std::cout travaille avec le tampon « local »
    // vous ne voyez pas ce message
    std::cout << "some message";

    // retour à l'ancien tampon
    std::cout.rdbuf(cout_buff);

    // vous verrez ce message
    std::cout << "back to default buffer\n";

    // affiche le contenu de « local »
    std::cout << "local content: " << local.str() << "\n";
}

Output:

back to default buffer
local content: some message
