std::basic_istream<CharT,Traits>::readsome

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

std::streamsize readsome( char_type* s, std::streamsize count );

Extrait jusqu'à count caractères immédiatement disponibles du flux d'entrée. Les caractères extraits sont stockés dans le tableau de caractères pointé par s.

Se comporte comme UnformattedInputFunction. Après avoir construit et vérifié l'objet sentry,

  • Si rdbuf()->in_avail() == -1, appelle setstate(eofbit) et n'extrait aucun caractère.

  • Si rdbuf()->in_avail() == 0, n'extrait aucun caractère.

  • Si rdbuf()->in_avail() > 0, extrait std::min(rdbuf()->in_avail(), count) caractères et les stocke dans des emplacements successifs du tableau de caractères dont le premier élément est pointé par s.

Paramètres

  • s — pointeur vers le tableau de caractères dans lequel stocker les caractères
  • count — nombre maximal de caractères à lire

Valeur de retour

Le nombre de caractères réellement extraits.

Exceptions

failure si une erreur s'est produite (l'indicateur d'état d'erreur n'est pas goodbit) et que exceptions() est configuré pour lever une exception pour cet état.

Si une opération interne lève une exception, elle est capturée et badbit est mis. Si exceptions() est mis pour badbit, l'exception est relancée.

Notes

Le comportement de cette fonction est fortement dépendant de l'implémentation. Par exemple, utiliser readsome() avec std::ifstream conduit à des résultats importants et spécifiques à l'implémentation. Certaines implémentations de la bibliothèque remplissent le filebuf sous-jacent avec des données dès que std::ifstream ouvre un fichier, ce qui signifie que readsome() lit toujours des données et pourrait même lire le fichier entier. Avec d'autres implémentations, std::ifstream ne lit depuis un fichier que lorsqu'une opération d'entrée est invoquée, ce qui signifie qu'appeler readsome() immédiatement après l'ouverture du fichier n'extrait jamais aucun caractère. De même, appeler std::cin.readsome() peut renvoyer toute entrée console en attente et non traitée, ou toujours renvoyer zéro sans extraire aucun caractère.

Exemple

#include <cassert>
#include <iostream>
#include <sstream>

int main()
{
    char c[10] = "*********"; // c[9] == '\0'

    // std::stringbuf rend tout son tampon disponible pour une lecture non bloquante
    std::istringstream input("This is sample text.");

    auto r = input.readsome(c, 5); // lit 'This ' et stocke dans c[0] .. c[4]
    assert(r == 5);
    std::cout << c << '\n';

    r = input.readsome(c, 9); // lit 'is sample' et stocke dans c[0] .. c[8]
    assert(r == 9);
    std::cout << c << '\n';
}

Output:

This ****
is sample
