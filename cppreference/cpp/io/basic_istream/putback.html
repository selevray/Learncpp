std::basic_istream<CharT,Traits>::putback

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

basic_istream& putback( char_type ch );

Remet le caractère ch dans le flux d'entrée afin que le prochain caractère extrait soit ch.

Efface d'abord eofbit, puis se comporte comme UnformattedInputFunction. Après avoir construit et vérifié l'objet sentry, si rdbuf() n'est pas nul, appelle rdbuf()->sputbackc(ch), qui appelle rdbuf()->pbackfail(ch) si ch ne vaut pas le dernier caractère extrait.

Si rdbuf() est nul ou si rdbuf->sputbackc(ch) renvoie Traits::eof(), appelle setstate(badbit).

Dans tous les cas, remet à zéro le compteur gcount().

Paramètres

  • ch — caractère à remettre dans le flux d'entrée

Valeur de retour

*this

Exceptions

failure si une erreur s'est produite (l'indicateur d'état d'erreur n'est pas goodbit) et que exceptions() est configuré pour lever une exception pour cet état.

Si une opération interne lève une exception, elle est capturée et badbit est mis. Si exceptions() est mis pour badbit, l'exception est relancée.

Exemple

Illustre la différence entre putback() modifiant et non modifiant.

#include <iostream>
#include <sstream>

int main()
{
    std::stringstream s1("Hello, world"); // flux d'E/S
    s1.get();
    if (s1.putback('Y')) // modifie le tampon
        std::cout << s1.rdbuf() << '\n';
    else
        std::cout << "putback failed\n";

    std::cout << "--\n";

    std::istringstream s2("Hello, world"); // flux en entrée seule
    s2.get();
    if (s2.putback('Y')) // ne peut pas modifier le tampon en entrée seule
        std::cout << s2.rdbuf() << '\n';
    else
        std::cout << "putback failed\n";
    s2.clear();

    std::cout << "--\n";

    if (s2.putback('H')) // remise non modifiante
        std::cout << s2.rdbuf() << '\n';
    else
        std::cout << "putback failed\n";
}

Output:

Yello, world
--
putback failed
--
Hello, world
