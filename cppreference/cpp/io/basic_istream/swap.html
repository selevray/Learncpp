std::basic_istream<CharT,Traits>::swap

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
void swap( basic_istream& rhs );  // (depuis C++11)

Appelle basic_ios::swap(rhs) pour échanger tous les membres de données de la classe de base, à l'exception de rdbuf(), et échange les valeurs des compteurs gcount() entre *this et rhs. Cette fonction swap est protégée : elle est appelée par les fonctions swap des classes de flux d'entrée échangeables std::basic_ifstream et std::basic_istringstream, qui savent échanger correctement les tampons de flux associés.

Paramètres

  • rhs — objet basic_istream différent du même type à échanger

Exemple

#include <iostream>
#include <sstream>
#include <utility>

int main()
{
    std::istringstream s1("hello");
    std::istringstream s2("bye");

    s1.swap(s2); // OK, istringstream possède un swap() public
    std::swap(s1, s2); // OK, appelle s1.swap(s2)
//  std::cin.swap(s2); // ERREUR : swap est une fonction membre protégée

    std::cout << s1.rdbuf() << '\n';
}

Output:

hello
