std::basic_istream<CharT,Traits>::~basic_istream

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

virtual ~basic_istream();

Détruit le flux d'entrée.

Notes

Ce destructeur n'effectue aucune opération sur le tampon de flux sous-jacent (rdbuf()) : ce sont les destructeurs des flux d'entrée dérivés, tels que std::basic_ifstream et std::basic_istringstream, qui sont chargés d'appeler les destructeurs des tampons de flux.

Exemple

#include <iostream>
#include <sstream>

void print_stringbuf(std::streambuf* p)
{
    std::istream buf(p); // buf partage le tampon avec s1
    int n;
    buf >> n;
    std::cout << n;
} // appelle le destructeur de buf. p n'est pas affecté

int main()
{
    std::istringstream s1("10 20");
    print_stringbuf(s1.rdbuf());
    int n;
    s1 >> n;
    std::cout << ',' << n << '\n';
}

Output:

10,20
