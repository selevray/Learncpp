std::basic_istream<CharT,Traits>::seekg

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

basic_istream& seekg( pos_type pos );  // (1)

basic_istream& seekg( off_type off, std::ios_base::seekdir dir );  // (2)

Définit l'indicateur de position d'entrée de l'objet streambuf associé courant.

Avant toute autre chose, seekg efface eofbit.

(depuis C++11)

seekg se comporte comme UnformattedInputFunction, sauf que gcount() n'est pas affecté. Après avoir construit et vérifié l'objet sentry,

  1. si fail() != true, définit l'indicateur de position d'entrée à la valeur absolue pos (par rapport au début du fichier). Plus précisément, exécute rdbuf()->pubseekpos(pos, std::ios_base::in) (pubseekpos appelle à son tour seekpos du tampon spécifique, comme basic_filebuf::seekpos, basic_stringbuf::seekpos ou strstreambuf::seekpos). En cas d'échec, appelle setstate(std::ios_base::failbit).

  2. si fail() != true, définit l'indicateur de position d'entrée à la position off, relative à la position définie par dir. Plus précisément, exécute rdbuf()->pubseekoff(off, dir, std::ios_base::in). En cas d'échec, appelle setstate(std::ios_base::failbit).

Paramètres

  • pos — position absolue à laquelle définir l'indicateur de position d'entrée

  • off — position relative (positive ou négative) à laquelle définir l'indicateur de position d'entrée

  • dir — définit la position de base à laquelle appliquer le décalage relatif. Elle peut être l'une des constantes suivantes :

    Constante Explication

    • beg — le début d'un flux
    • end — la fin d'un flux
    • cur — la position courante de l'indicateur de position du flux

Valeur de retour

*this

Exceptions

failure si une erreur s'est produite (l'indicateur d'état d'erreur n'est pas goodbit) et que exceptions() est configuré pour lever une exception pour cet état.

Si une opération interne lève une exception, elle est capturée et badbit est mis. Si exceptions() est mis pour badbit, l'exception est relancée.

Notes

seekg(n) n'est pas nécessairement équivalent à seekg(n, ios::beg). std::basic_ifstream, par exemple, exige que la position absolue n provienne de tellg().

Exemple

#include <iostream>
#include <sstream>
#include <string>

int main()
{
    std::string str = "Hello, world";
    std::istringstream in(str);
    std::string word1, word2;

    in >> word1;
    in.seekg(0); // rewind
    in >> word2;

    std::cout << "word1 = " << word1 << '\n'
              << "word2 = " << word2 << '\n';
}

Output:

word1 = Hello,
word2 = Hello,

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 129 C++98 il n'existait aucun moyen d'indiquer un échec définit failbit en cas d'échec
LWG 136 C++98 seekg pouvait définir le flux de sortie ne définissait que le flux d'entrée
LWG 537 C++98 le type de off était off_type& corrigé en off_type
