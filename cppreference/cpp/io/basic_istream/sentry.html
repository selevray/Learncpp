std::basic_istream<CharT,Traits>::sentry

class sentry;

Un objet de classe basic_istream::sentry est construit dans la portée locale au début de chaque fonction membre de std::basic_istream qui effectue une entrée (formatée comme non formatée). Son constructeur prépare le flux d'entrée : il vérifie si le flux est déjà dans un état d'échec, vide les flux de sortie liés par tie(), ignore les espaces de début sauf si l'indicateur noskipws est défini, et effectue d'autres tâches définies par l'implémentation si nécessaire. Tout nettoyage nécessaire est effectué dans le destructeur, de sorte qu'il est garanti de se produire si des exceptions sont levées pendant l'entrée.

std::basic_istream::sentry::sentry

explicit sentry( std::basic_istream<CharT, Traits>& is, bool noskipws = false );

Prépare le flux pour une entrée formatée.

Si is.good() vaut false, appelle is.setstate(std::ios_base::failbit) et retourne. Sinon, si is.tie() n'est pas un pointeur nul, appelle is.tie()->flush() pour synchroniser la séquence de sortie avec les flux externes. Cet appel peut être supprimé si la zone put de is.tie() est vide. L'implémentation peut différer l'appel à flush() jusqu'à ce qu'un appel de is.rdbuf()->underflow() ait lieu. Si aucun appel de ce type n'a lieu avant la destruction de l'objet sentry, il peut être entièrement éliminé.

Si noskipws vaut zéro et is.flags() & std::ios_base::skipws est non nul, la fonction extrait et rejette tous les caractères d'espacement jusqu'à ce que le prochain caractère disponible ne soit plus un caractère d'espacement (tel que déterminé par la locale actuellement imprégnée dans is). Si is.rdbuf()->sbumpc() ou is.rdbuf()->sgetc() renvoie traits::eof(), la fonction appelle setstate(std::ios_base::failbit | std::ios_base::eofbit) (qui peut lever std::ios_base::failure).

Une préparation supplémentaire définie par l'implémentation peut avoir lieu, pouvant appeler setstate(std::ios_base::failbit) (qui peut lever std::ios_base::failure).

Si, une fois la préparation terminée, is.good() == true, alors tout appel ultérieur à operator bool renverra true.

Paramètres

  • is — flux d'entrée à préparer
  • noskipws — true si les espaces ne doivent pas être ignorés

Exceptions

std::ios_base::failure si la condition de fin de fichier se produit lors de l'ignorement des espaces.

std::basic_istream::sentry::operator bool

explicit operator bool() const;

Vérifie si la préparation du flux d'entrée a réussi.

Paramètres

(aucune)

Valeur de retour

true si l'initialisation du flux d'entrée a réussi, false sinon.

Exemple

#include <iostream>
#include <sstream>

struct Foo
{
    char n[5];
};

std::istream& operator>>(std::istream& is, Foo& f)
{
    std::istream::sentry s(is);
    if (s)
        is.read(f.n, 5);
    return is;
}

int main()
{
    std::string input = "   abcde";
    std::istringstream stream(input);
    Foo f;
    stream >> f;
    std::cout.write(f.n, 5);
    std::cout << '\n';
}

Output:

abcde
