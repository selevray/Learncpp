std::basic_istream<CharT,Traits>::ignore

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

basic_istream& ignore( std::streamsize count = 1, int_type delim = Traits::eof() );

Extrait et supprime des caractères du flux d'entrée jusqu'à delim inclus.

ignore se comporte comme un UnformattedInputFunction. Après avoir construit et vérifié l'objet sentry, il extrait des caractères du flux et les supprime jusqu'à ce que l'une des conditions suivantes se produise :

  • count caractères ont été extraits. Ce test est désactivé dans le cas particulier où count est égal à std::numeric_limits<std::streamsize>::max().

  • une condition de fin de fichier se produit dans la séquence d'entrée, auquel cas la fonction appelle setstate(eofbit).

  • le prochain caractère disponible c dans la séquence d'entrée est delim, selon Traits::eq_int_type(Traits::to_int_type(c), delim). Le caractère délimiteur est extrait et supprimé. Ce test est désactivé si delim est Traits::eof().

Paramètres

  • count — nombre de caractères à extraire
  • delim — caractère délimiteur où arrêter l'extraction. Il est également extrait

Valeur de retour

*this

Exceptions

failure si une erreur s'est produite (l'indicateur d'état d'erreur n'est pas goodbit) et que exceptions() est configuré pour lever une exception pour cet état.

Si une opération interne lève une exception, elle est capturée et badbit est mis. Si exceptions() est mis pour badbit, l'exception est relancée.

Exemple

L'exemple suivant utilise ignore pour ignorer les entrées non numériques :

#include <iostream>
#include <limits>
#include <sstream>

constexpr auto max_size = std::numeric_limits<std::streamsize>::max();

int main()
{
    std::istringstream input("1\n"
                             "some non-numeric input\n"
                             "2\n");
    for (;;)
    {
        int n;
        input >> n;

        if (input.eof() || input.bad())
            break;
        else if (input.fail())
        {
            input.clear(); // réinitialise failbit
            input.ignore(max_size, '\n'); // ignore les entrées incorrectes
        }
        else
            std::cout << n << '\n';
    }
}

Output:

1
2
