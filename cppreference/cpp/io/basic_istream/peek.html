std::basic_istream<CharT,Traits>::peek

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

int_type peek();

Se comporte comme UnformattedInputFunction. Après avoir construit et testé l'objet sentry, lit le caractère suivant du flux d'entrée sans l'extraire.

Paramètres

(aucune)

Valeur de retour

Si good() == true, renvoie le caractère suivant tel qu'obtenu par rdbuf()->sgetc().

Sinon, renvoie Traits::eof().

Exceptions

failure si une erreur s'est produite (l'indicateur d'état d'erreur n'est pas goodbit) et que exceptions() est configuré pour lever une exception pour cet état.

Si une opération interne lève une exception, elle est capturée et badbit est mis. Si exceptions() est mis pour badbit, l'exception est relancée.

Exemple

#include <iostream>
#include <sstream>

int main()
{
    std::istringstream s1("Hello, world.");
    char c1 = s1.peek();
    char c2 = s1.get();
    std::cout << "Peeked: " << c1 << " got: " << c2 << '\n';
}

Output:

Peeked: H got: H
