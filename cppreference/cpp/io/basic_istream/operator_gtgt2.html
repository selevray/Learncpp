1,2) Effectue des opérations d'entrée de caractères.

  1. Se comporte comme un FormattedInputFunction. Après la construction et la vérification de l'objet sentry, qui peut ignorer les espaces blancs initiaux, extrait un caractère et le stocke dans ch. Si aucun caractère n'est disponible, définit failbit (en plus de eofbit qui est défini comme l'exige un FormattedInputFunction).

  2. Se comporte comme un FormattedInputFunction. Après la construction et la vérification de l'objet sentry, qui peut ignorer les espaces blancs initiaux, extrait des caractères successifs et les stocke dans des emplacements successifs de un tableau de caractères dont le premier élément est pointé par (jusqu'à C++20) s. L'extraction s'arrête si l'une des conditions suivantes est remplie :

  • Un caractère d'espacement (tel que déterminé par la facette ctype<CharT>) est trouvé. Le caractère d'espacement n'est pas extrait.
  • Si st.width() est supérieur à zéro, st.width() - 1 caractères sont stockés.

(jusqu'à C++20)

  • n - 1 caractères sont stockés, où n est défini comme suit :
  • Si st.width() est supérieur à zéro, std::min(std::size_t(st.width()), N) ;
  • sinon, n vaut N.

(depuis C++20)

  • Une fin de fichier se produit dans la séquence d'entrée (ceci définit également eofbit).

Dans les deux cas, une valeur de caractère nul supplémentaire CharT() est stockée à la fin de la sortie. Si aucun caractère n'a été extrait, définit failbit (le caractère nul est tout de même écrit, à la première position de la sortie). Enfin, appelle st.width(0) pour annuler les effets de std::setw, le cas échéant.

  1. Appelle l'opérateur d'extraction approprié, avec une référence rvalue vers un objet de flux d'entrée (équivalent à st >> std::forward<T>(value)). Cette surcharge ne participe à la résolution de surcharge que si st >> std::forward<T>(value) est bien formé et que Istream est un type classe dérivé publiquement et sans ambiguïté de std::ios_base.

Notes

L'extraction d'un caractère unique qui est le dernier caractère du flux ne définit pas eofbit : ceci diffère des autres fonctions d'entrée formatées, comme l'extraction du dernier entier avec operator>>, mais ce comportement correspond à celui de std::scanf avec le spécificateur de format "%c".

Paramètres

  • st — flux d'entrée depuis lequel extraire les données
  • ch — référence à un caractère dans lequel stocker le caractère extrait
  • s — pointeur vers (jusqu'à C++20) un tableau de caractères dans lequel stocker les caractères extraits

Valeur de retour

1,2) st

  1. std::move(st)

Exemple

#include <iomanip>
#include <iostream>
#include <sstream>

int main()
{
    std::string input = "n greetings";
    std::istringstream stream(input);

    char c;
    const int MAX = 6;
    char cstr[MAX];

    stream >> c >> std::setw(MAX) >> cstr;
    std::cout << "c = " << c << '\n'
              << "cstr = " << cstr << '\n';

    double f;
    std::istringstream("1.23") >> f; // extraction de flux en rvalue
    std::cout << "f = " << f << '\n';
}

Output:

c = n
cstr = greet
f = 1.23

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 13 C++98 la définition de n mentionnait un nom inexistant eos remplacé par CharT()
LWG 68 C++98 aucun caractère nul n'était stocké à la fin de la sortie pour la surcharge (2) stocke un caractère nul
LWG 1203 C++98 la surcharge pour flux rvalue retournait une référence lvalue vers la classe de base retourne une référence rvalue vers la classe dérivée
LWG 2328 C++98 la surcharge pour flux rvalue exigeait qu'un autre argument soit une lvalue rendue capable d'accepter une rvalue
LWG 2534 C++98 la surcharge pour flux rvalue n'était pas contrainte constrained
