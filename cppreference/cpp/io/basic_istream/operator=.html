std::basic_istream<CharT,Traits>::operator=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
basic_istream& operator=( const basic_istream& rhs ) = delete;  // (1)

protected:
basic_istream& operator=( basic_istream&& rhs );  // (2) (depuis C++11)

  1. L'opérateur d'affectation par copie est protégé et est supprimé. Les flux d'entrée ne sont pas CopyAssignable.

  2. L'opérateur d'affectation par déplacement échange les valeurs gcount() et tous les membres de données de la classe de base, à l'exception de rdbuf(), avec rhs, comme si l'on appelait swap(*rhs). Cet opérateur d'affectation par déplacement est protégé : il n'est appelé que par les opérateurs d'affectation par déplacement des classes de flux d'entrée déplaçables dérivées std::basic_ifstream et std::basic_istringstream, qui savent correctement effectuer l'affectation par déplacement des tampons de flux associés.

Paramètres

  • rhs — l'objet basic_istream à partir duquel effectuer l'affectation vers *this

Exemple

#include <iostream>
#include <sstream>

int main()
{
    std::istringstream s1;
    s1 = std::istringstream("test"); // OK

//  std::cin = std::istringstream("test"); // ERREUR : 'operator=' est protégé
}
