std::basic_istream<CharT,Traits>::read

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

basic_istream& read( char_type* s, std::streamsize count );

Extrait des caractères du flux.

Se comporte comme UnformattedInputFunction. Après avoir construit et vérifié l'objet sentry, extrait des caractères et les stocke dans des emplacements successifs du tableau de caractères dont le premier élément est pointé par s. Les caractères sont extraits et stockés jusqu'à ce que l'une des conditions suivantes se produise :

  • count caractères ont été extraits et stockés.

  • la condition de fin de fichier se produit sur la séquence d'entrée (auquel cas setstate(failbit|eofbit) est appelée). Le nombre de caractères extraits avec succès peut être obtenu à l'aide de gcount().

Paramètres

  • s — pointeur vers le tableau de caractères dans lequel stocker les caractères
  • count — nombre de caractères à lire

Valeur de retour

*this

Exceptions

failure si une erreur s'est produite (l'indicateur d'état d'erreur n'est pas goodbit) et que exceptions() est configuré pour lever une exception pour cet état.

Si une opération interne lève une exception, elle est capturée et badbit est mis. Si exceptions() est mis pour badbit, l'exception est relancée.

Notes

Lorsqu'on utilise une locale sans conversion (la locale par défaut est sans conversion), la redéfinition de cette fonction dans std::basic_ifstream peut être optimisée pour les E/S groupées sans copie (au moyen de la redéfinition de std::streambuf::xsgetn).

Exemple

#include <cstdint>
#include <fstream>
#include <iostream>
#include <sstream>
#include <string>

int main()
{
    // read() est souvent utilisée pour les E/S binaires
    std::string bin = {'\x12', '\x12', '\x12', '\x12'};
    std::istringstream raw(bin);
    std::uint32_t n;
    if (raw.read(reinterpret_cast<char*>(&n), sizeof n))
        std::cout << std::hex << std::showbase << n << '\n';

    // prépare le fichier pour l'extrait suivant
    std::ofstream("test.txt", std::ios::binary) << "abcd1\nabcd2\nabcd3";

    // lit le fichier entier dans une chaîne
    if (std::ifstream is{"test.txt", std::ios::binary | std::ios::ate})
    {
        auto size = is.tellg();
        std::string str(size, '\0'); // construit la chaîne à la taille du flux
        is.seekg(0);
        if (is.read(&str[0], size))
            std::cout << str << '\n';
    }
}

Output:

0x12121212
abcd1
abcd2
abcd3
