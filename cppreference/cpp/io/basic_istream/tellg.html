std::basic_istream<CharT,Traits>::tellg

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

pos_type tellg();

Renvoie l'indicateur de position d'entrée de l'objet streambuf associé courant.

Se comporte comme UnformattedInputFunction, sauf que gcount() n'est pas affecté. Après la construction et la vérification de l'objet sentry, si fail() == true, renvoie pos_type(-1). Sinon, renvoie rdbuf()->pubseekoff(0, std::ios_base::cur, std::ios_base::in).

Paramètres

(aucune)

Valeur de retour

La position courante du pointeur de lecture en cas de succès, pos_type(-1) en cas d'échec.

Exceptions

failure si une erreur s'est produite (l'indicateur d'état d'erreur n'est pas goodbit) et que exceptions() est configuré pour lever une exception pour cet état.

Si une opération interne lève une exception, elle est capturée et badbit est mis. Si exceptions() est mis pour badbit, l'exception est relancée.

Exemple

#include <iostream>
#include <sstream>
#include <string>

int main()
{
    std::string str = "Hello, world";
    std::istringstream in(str);
    std::string word;
    in >> word;
    std::cout << "After reading the word \"" << word
              << "\" tellg() returns " << in.tellg() << '\n';
}

Output:

After reading the word "Hello," tellg() returns 6
