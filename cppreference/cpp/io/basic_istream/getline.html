std::basic_istream<CharT,Traits>::getline

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

basic_istream& getline( char_type* s, std::streamsize count );  // (1)

basic_istream& getline( char_type* s, std::streamsize count, char_type delim );  // (2)

Extrait des caractères du flux jusqu'à la fin de ligne ou le délimiteur spécifié delim.

La première surcharge est équivalente à getline(s, count, widen('\n')).

Se comporte comme UnformattedInputFunction. Après avoir construit et vérifié l'objet sentry, extrait des caractères de *this et les stocke dans les emplacements successifs du tableau dont le premier élément est pointé par s, jusqu'à ce que l'une des conditions suivantes se produise (testées dans l'ordre indiqué) :

  1. une condition de fin de fichier se produit dans la séquence d'entrée.
  2. le prochain caractère disponible c est le délimiteur, selon Traits::eq(c, delim). Le délimiteur est extrait (contrairement à basic_istream::get()) et compté dans gcount(), mais n'est pas stocké.
  3. count est non positif, ou count - 1 caractères ont été extraits (setstate(failbit) est appelé dans ce cas).

Si la fonction n'extrait aucun caractère, failbit est mis dans l'état d'erreur local avant l'appel de setstate().

Dans tous les cas, si count > 0, elle stocke ensuite un caractère nul CharT() à l'emplacement suivant du tableau et met à jour gcount().

Notes

Comme la condition #2 est testée avant la condition #3, la ligne d'entrée qui remplit exactement le tampon ne déclenche pas failbit.

Comme le caractère de fin est compté comme caractère extrait, une ligne d'entrée vide ne déclenche pas failbit.

Paramètres

  • s — pointeur vers la chaîne de caractères dans laquelle stocker les caractères
  • count — taille de la chaîne de caractères pointée par s
  • delim — caractère délimiteur où arrêter l'extraction. Il est extrait mais non stocké.

Valeur de retour

*this

Exceptions

failure si une erreur s'est produite (l'indicateur d'état d'erreur n'est pas goodbit) et que exceptions() est configuré pour lever une exception pour cet état.

Si une opération interne lève une exception, elle est capturée et badbit est mis. Si exceptions() est mis pour badbit, l'exception est relancée.

Exemple

#include <array>
#include <iostream>
#include <sstream>
#include <vector>

int main()
{
    std::istringstream input("abc|def|gh");
    std::vector<std::array<char, 4>> v;

    // note : la boucle suivante se termine lorsque std::ios_base::operator bool()
    // sur le flux renvoyé par getline() renvoie false
    for (std::array<char, 4> a; input.getline(&a[0], 4, '|');)
        v.push_back(a);

    for (auto& a : v)
        std::cout << &a[0] << '\n';
}

Output:

abc
def
gh
