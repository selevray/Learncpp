Extrait des valeurs d'un flux d'entrée.

1-11) Extrait une valeur en ignorant éventuellement les espaces blancs qui la précèdent. La valeur est stockée dans la référence donnée value.

Cette fonction se comporte comme un FormattedInputFunction. Après la construction et la vérification de l'objet sentry, qui peut ignorer les espaces blancs initiaux, extrait une valeur en appelant std::num_get::get().

  1. Extrait une valeur short en ignorant éventuellement les espaces blancs qui la précèdent. La valeur est stockée dans la référence donnée value.

Cette fonction se comporte comme un FormattedInputFunction. Après la construction et la vérification de l'objet sentry, qui peut ignorer les espaces blancs initiaux, extrait une valeur long lval en appelant std::num_get::get(). Ensuite :

  • Si lval < std::numeric_limits<short>::min(), définit failbit et stocke std::numeric_limits<short>::min() dans val.
  • Sinon, si std::numeric_limits<short>::max() < lval, définit failbit et stocke std::numeric_limits<short>::max() dans val.
  • Sinon, stocke static_cast<short>(lval) dans val.
  1. Extrait une valeur int en ignorant éventuellement les espaces blancs qui la précèdent. La valeur est stockée dans la référence donnée value.

Cette fonction se comporte comme un FormattedInputFunction. Après la construction et la vérification de l'objet sentry, qui peut ignorer les espaces blancs initiaux, extrait une valeur long lval en appelant std::num_get::get(). Ensuite :

  • Si lval < std::numeric_limits<int>::min(), définit failbit et stocke std::numeric_limits<int>::min() dans val.
  • Sinon, si std::numeric_limits<int>::max() < lval, définit failbit et stocke std::numeric_limits<int>::max() dans val.
  • Sinon, stocke static_cast<int>(lval) dans val.
  1. Extrait une valeur en virgule flottante étendue en ignorant éventuellement les espaces blancs qui la précèdent. La valeur est stockée dans la référence donnée value. La bibliothèque fournit des surcharges pour tous les types à virgule flottante étendue non qualifiés cv comme type référencé du paramètre value.

Détermine le type à virgule flottante standard FP comme suit :

  • Si le rang de conversion en virgule flottante de /* extended-floating-point-type */ est inférieur ou égal à celui de float, alors FP vaut float.
  • Sinon, si le rang de conversion en virgule flottante de /* extended-floating-point-type */ est inférieur ou égal à celui de double, alors FP vaut double.
  • Sinon, FP vaut long double.

Cette fonction se comporte comme un FormattedInputFunction. Après la construction et la vérification de l'objet sentry, qui peut ignorer les espaces blancs initiaux, extrait une valeur FP fval en appelant std::num_get::get(). Ensuite :

  • Si fval < -std::numeric_limits</* extended-floating-point-type */>::max(), définit failbit et stocke -std::numeric_limits</* extended-floating-point-type */>::max() dans val.
  • Sinon, si std::numeric_limits</* extended-floating-point-type */>::max() < fval, définit failbit et stocke std::numeric_limits</* extended-floating-point-type */>::max() dans val.
  • Sinon, stocke static_cast</* extended-floating-point-type */>(fval) dans val.

15-17) Appelle func(*this), où func est un manipulateur d'E/S.

  1. Se comporte comme un UnformattedInputFunction. Après la construction et la vérification de l'objet sentry, extrait toutes les données de *this et les stocke dans sb. L'extraction s'arrête si l'une des conditions suivantes est remplie :
  • une fin de fichier survient sur le flux d'entrée ;
  • l'insertion dans le flux de sortie échoue (auquel cas le caractère à insérer n'est pas extrait) ;
  • une exception se produit (auquel cas l'exception est capturée, et ne est relancée que si elle n'a inséré aucun caractère et que failbit est activé dans exceptions()). Dans les deux cas, stocke le nombre de caractères extraits dans la variable membre accédée par les appels ultérieurs à gcount(). Si sb est un pointeur nul ou si aucun caractère n'a été inséré dans sb, appelle setstate(failbit) (qui peut lever std::ios_base::failure si activé).

Si l'extraction échoue (par exemple si une lettre est saisie alors qu'un chiffre est attendu), zéro est écrit dans value et failbit est défini. Pour les entiers signés, si l'extraction donne une valeur trop grande ou trop petite pour tenir dans value, std::numeric_limits<T>::max() ou std::numeric_limits<T>::min() (respectivement) est écrit et le drapeau failbit est défini. Pour les entiers non signés, si l'extraction donne une valeur trop grande ou trop petite pour tenir dans value, std::numeric_limits<T>::max() est écrit et le drapeau failbit est défini.

Paramètres

  • value — référence à une valeur entière ou à virgule flottante dans laquelle stocker la valeur extraite
  • func — pointeur vers la fonction manipulateur d'E/S
  • sb — pointeur vers le tampon de flux dans lequel écrire toutes les données

Valeur de retour

1-16,18) *this

  1. func(*this)

Notes

Pour la surcharge (14), lorsque le type à virgule flottante étendue a un rang de conversion en virgule flottante qui n'est égal au rang d'aucun type à virgule flottante standard, un double arrondi lors de la conversion peut produire des résultats inexacts. std::from_chars() peut être utilisé dans les situations où une précision maximale est importante.

Exemple

#include <iomanip>
#include <iostream>
#include <sstream>

int main()
{
    std::string input = "41 3.14 false hello world";
    std::istringstream stream(input);

    int n;
    double f;
    bool b;

    stream >> n >> f >> std::boolalpha >> b;
    std::cout << "n = " << n << '\n'
              << "f = " << f << '\n'
              << "b = " << std::boolalpha << b << '\n';

    // extrait le reste à l'aide de la surcharge streambuf
    stream >> std::cout.rdbuf();
    std::cout << '\n';
}

Output:

n = 41
f = 3.14
b = false
hello world

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 64 C++98 il n'était pas clair si la surcharge (18) ne peut relancer que le std::ios_base::failure levé par l'appel de setstate(failbit) toutes les exceptions capturées peuvent être relancées
LWG 118 C++98 la surcharge (12,13) déléguait l'extraction à num_get::get, mais elle n'a pas de surcharges pour short et int une valeur long est extraite au lieu de short ou int
LWG 413 C++98 la surcharge (18) ne relançait que les exceptions levées lors de l'extraction de caractères de sb, alors que des caractères sont extraits de *this corrigé sb en *this
LWG 567 C++98 la surcharge (18) se comportait comme un FormattedInputFunction en raison de la résolution de LWG issue 60 elle se comporte comme un UnformattedInputFunction
LWG 661 C++98 les surcharges (12,13) ne stockaient pas le nombre extrait dans value à cause de la résolution du problème LWG 118 stocke le nombre si aucun dépassement ne se produit
LWG 696 C++98 value était inchangé en cas d'échec d'extraction mis à zéro ou aux valeurs minimale/ maximale
