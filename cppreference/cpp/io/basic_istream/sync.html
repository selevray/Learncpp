std::basic_istream<CharT,Traits>::sync

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

int sync();

Synchronise le tampon d'entrée avec la source de données associée.

Se comporte comme UnformattedInputFunction, sauf que gcount() n'est pas affecté. Après la construction et la vérification de l'objet sentry,

Si rdbuf() est un pointeur nul, renvoie -1.

Sinon, appelle rdbuf()->pubsync(). Si cette fonction renvoie -1, appelle setstate(badbit) et renvoie -1. Sinon, renvoie 0.

Paramètres

(aucune)

Valeur de retour

0 en cas de succès, -1 en cas d'échec ou si le flux ne prend pas en charge cette opération (non tamponné).

Notes

Comme pour readsome(), il est défini par l'implémentation de savoir si cette fonction fait quoi que ce soit avec les flux fournis par la bibliothèque. L'intention est généralement que la prochaine opération de lecture prenne en compte les modifications éventuellement apportées à la séquence d'entrée associée depuis le dernier remplissage de la zone de lecture du tampon de flux. Pour cela, sync() peut vider la zone de lecture, la remplir à nouveau, ou ne rien faire. Une exception notable est Visual Studio, où cette opération abandonne les entrées non traitées lorsqu'elle est appelée avec un flux d'entrée standard.

Exemple

Illustre l'utilisation du flux d'entrée sync() avec une entrée sur fichier. Notez que la sortie ici est définie par l'implémentation, car les appels à std::basic_filebuf::sync sont définis par l'implémentation pour les lectures.

#include <fstream>
#include <iostream>

void file_abc()
{
    std::ofstream f("test.txt");
    f << "abc\n";
}

void file_123()
{
    std::ofstream f("test.txt");
    f << "123\n";
}

int main()
{
    file_abc(); // le fichier contient maintenant "abc"
    std::ifstream f("test.txt");
    std::cout << "Reading from the file\n";
    char c;
    f >> c;
    std::cout << c;
    file_123(); // le fichier contient maintenant "123"
    f >> c;
    std::cout << c;
    f >> c;
    std::cout << c << '\n';
    f.close();

    file_abc(); // le fichier contient maintenant "abc"
    f.open("test.txt");
    std::cout << "Reading from the file, with sync()\n";
    f >> c;
    std::cout << c;
    file_123(); // le fichier contient maintenant "123"
    f.sync();
    f >> c;
    std::cout << c;
    f >> c;
    std::cout << c << '\n';
}
