std::fpos<State>::state

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

State state() const;  // (1)

void state( State st );  // (2)

Gère l'état de position dans le fichier.

  1. Renvoie la valeur de l'état de position dans le fichier.

  2. Remplace l'état de position dans le fichier par la valeur de st.

Pour les spécialisations de std::fpos utilisées dans la bibliothèque standard, State vaut toujours std::mbstate_t.

Paramètres

  • st — nouvelle valeur pour l'état

Valeur de retour

  1. La valeur courante de l'état fpos.

  2. (aucun)

Exemple

#include <cwchar>
#include <iostream>
#include <sstream>

int main()
{
    std::istringstream s("test");
    std::mbstate_t st = s.tellg().state();

    if (std::mbsinit(&st))
        std::cout << "The stream is in the initial shift state\n";
}

Output:

The stream is in the initial shift state
