class ios_base;

La classe ios_base est une classe polyvalente qui sert de classe de base à toutes les classes de flux d'E/S. Elle gère plusieurs types de données :

  1. informations d'état : indicateurs d'état du flux.

  2. informations de contrôle : indicateurs qui contrôlent le formatage des séquences d'entrée et de sortie ainsi que la locale imbriquée.

  3. stockage privé : structure de données indexée extensible qui permet à la fois les membres long et void*, qui peut être implémentée sous forme de deux tableaux de longueur arbitraire, d'un seul tableau de structures à deux éléments ou d'un autre conteneur.

  4. rappels : nombre arbitraire de fonctions définies par l'utilisateur à appeler depuis imbue(), std::basic_ios::copyfmt() et ~ios_base().

L'implémentation typique contient des constantes membres correspondant à toutes les valeurs de fmtflags, iostate, openmode et seekdir indiquées ci-dessous, des variables membres pour conserver la précision, la largeur et les indicateurs de formatage courants, le masque d'exceptions, l'état d'erreur du tampon, un conteneur redimensionnable contenant les fonctions de rappel, la locale actuellement imprégnée, le stockage privé, ainsi qu'une variable entière statique pour xalloc().
