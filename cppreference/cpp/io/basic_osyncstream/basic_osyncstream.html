std::basic_osyncstream<CharT,Traits,Allocator>::basic_osyncstream

Construit un nouveau flux de sortie synchronisé.

1-4) Construit le membre privé std::basic_syncbuf à l'aide du tampon et de l'allocateur fournis, et initialise la classe de base avec un pointeur vers le membre std::basic_streambuf.

  1. Constructeur de déplacement. Construit par déplacement la base std::basic_ostream et le membre std::basic_syncbuf à partir des sous-objets correspondants de other, puis appelle set_rdbuf avec le pointeur vers le std::basic_syncbuf sous-jacent nouvellement construit pour achever l'initialisation de la base. Après ce constructeur de déplacement, other.get_wrapped() renvoie nullptr et la destruction de other ne produit aucune sortie.

Paramètres

  • buf — pointeur vers le std::basic_streambuf qui sera encapsulé
  • os — référence à un std::basic_ostream dont rdbuf() sera encapsulé
  • a — l'allocateur à transmettre au constructeur du membre std::basic_syncbuf
  • other — autre osyncstream à partir duquel déplacer

Exemple

#include <iostream>
#include <string_view>
#include <syncstream>
#include <thread>

void worker(const int id, std::ostream &os)
{
    std::string_view block;
    switch (id)
    {
        default: [[fallthrough]];
        case 0: block = "██";
                break;
        case 1: block = "▓▓";
                break;
        case 2: block = "▒▒";
                break;
        case 3: block = "░░";
                break;
    }
    for (int i = 1; i <= 50; ++i)
        os << block << std::flush;
    os << std::endl;
}

int main()
{
    std::cout << "Synchronized output should not cause any interference:" << std::endl;
    {
        auto scout1 = std::osyncstream{std::cout};
        auto scout2 = std::osyncstream{std::cout};
        auto scout3 = std::osyncstream{std::cout};
        auto scout4 = std::osyncstream{std::cout};
        auto w1 = std::jthread{worker, 0, std::ref(scout1)};
        auto w2 = std::jthread{worker, 1, std::ref(scout2)};
        auto w3 = std::jthread{worker, 2, std::ref(scout3)};
        auto w4 = std::jthread{worker, 3, std::ref(scout4)};
    }

    std::cout << "\nLack of synchronization may cause some interference on output:"
              << std::endl;
    {
        auto w1 = std::jthread{worker, 0, std::ref(std::cout)};
        auto w2 = std::jthread{worker, 1, std::ref(std::cout)};
        auto w3 = std::jthread{worker, 2, std::ref(std::cout)};
        auto w4 = std::jthread{worker, 3, std::ref(std::cout)};
    }
}
