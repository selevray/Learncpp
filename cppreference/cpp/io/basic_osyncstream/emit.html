std::basic_osyncstream<CharT,Traits,Allocator>::emit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void emit();

Émet toute la sortie mise en tampon et exécute les vidages en attente, en appelant emit() sur le std::basic_syncbuf sous-jacent.

Paramètres

(aucune)

Exemple

#include <iostream>
#include <syncstream>

int main()
{
    {
        std::osyncstream bout(std::cout);
        bout << "Hello," << '\n'; // aucun vidage
        bout.emit(); // caractères transférés ; cout non vidé
        bout << "World!" << std::endl; // vidage noté ; cout non vidé
        bout.emit(); // caractères transférés ; cout vidé
        bout << "Greetings." << '\n'; // aucun vidage
    } // le destructeur appelle emit() : caractères transférés ; cout non vidé

    // emit peut être utilisé pour la gestion locale des exceptions sur le flux encapsulé
    std::osyncstream bout(std::cout);
    bout << "Hello, " << "World!" << '\n';
    try
    {
        bout.emit();
    }
    catch (...)
    {
        // gérer les exceptions
    }
}

Output:

Hello,
World!
Greetings.
Hello, World!
