std::basic_filebuf<CharT,Traits>::setbuf

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
virtual std::basic_streambuf<CharT, Traits>* setbuf( char_type* s, std::streamsize n )

Si s est un pointeur nul et n vaut zéro, le filebuf devient non bufferisé pour la sortie, ce qui signifie que pbase() et pptr() sont nuls et que toute sortie est immédiatement envoyée au fichier.

Sinon, un appel à setbuf() remplace le tampon interne (la séquence de caractères contrôlée) par le tableau de caractères fourni par l'utilisateur dont le premier élément est pointé par s, et permet à cet objet std::basic_filebuf d'utiliser jusqu'à n octets de ce tableau pour la mise en tampon.

Cette fonction est protégée et virtuelle ; elle ne peut être appelée que par l'intermédiaire de pubsetbuf() ou depuis les fonctions membres d'une classe définie par l'utilisateur dérivée de std::basic_filebuf.

Paramètres

  • s — pointeur vers le premier CharT du tampon fourni par l'utilisateur, ou nul
  • n — le nombre d'éléments CharT du tampon fourni par l'utilisateur, ou zéro

Valeur de retour

this

Notes

Les conditions d'utilisation de cette fonction et la manière dont le tampon fourni est utilisé sont définies par l'implémentation.

  • GCC 4.6 libstdc++ setbuf() ne peut être appelée que lorsque std::basic_filebuf n'est pas associé à un fichier (sans effet sinon). Avec un tampon fourni par l'utilisateur, la lecture du fichier lit n-1 octets à la fois.

  • Clang++3.0 libc++ setbuf() peut être appelée après l'ouverture du fichier, mais avant toute E/S (sinon risque de plantage). Avec un tampon fourni par l'utilisateur, la lecture du fichier lit le plus grand multiple de 4096 pouvant tenir dans le tampon.

  • Visual Studio 2010 setbuf() peut être appelée à tout moment, même après certaines E/S. Le contenu actuel du tampon, s'il existe, est perdu.

La norme ne définit aucun comportement pour cette fonction, si ce n'est que setbuf(0, 0) appelée avant toute E/S doit définir une sortie non bufferisée.

Exemple

Fournit un tampon de 10 Ko pour la lecture. Sous Linux, l'utilitaire strace peut être utilisé pour observer le nombre réel d'octets lus.

#include <fstream>
#include <iostream>
#include <string>

int main()
{
    int cnt = 0;
    std::ifstream file;
    char buf[10241];

    file.rdbuf()->pubsetbuf(buf, sizeof buf);
    file.open("/usr/share/dict/words");

    for (std::string line; getline(file, line);)
        ++cnt;
    std::cout << cnt << '\n';
}
