std::basic_filebuf<CharT,Traits>::seekpos

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
virtual pos_type seekpos( pos_type sp,
                          std::ios_base::openmode which = std::ios_base::in | std::ios_base::out );

Repositionne le pointeur de fichier, si possible, à la position indiquée par sp. Si le fichier associé n'est pas ouvert (is_open() == false), échoue immédiatement.

Le repositionnement s'effectue comme suit :

  1. Si le fichier est ouvert en écriture, écrit la zone de mise et toutes les séquences de désinitialisation requises par la locale actuellement imprégnée, en utilisant overflow().

  2. Repositionne le pointeur de fichier, comme si l'on appelait std::fsetpos().

  3. Si le fichier est ouvert en lecture, met à jour la zone de lecture si nécessaire.

Si sp n'a pas été obtenu en appelant seekoff() ou seekpos() sur le même fichier, le comportement est indéfini.

Paramètres

  • sp — position de fichier obtenue par seekoff() ou seekpos() appelées précédemment sur le même fichier

  • which — définit la ou les séquences d'entrée et/ou de sortie à affecter. Il peut s'agir d'une des constantes suivantes ou d'une combinaison de celles-ci :

    Constante Explication

    • in — affecte la séquence d'entrée
    • out — affecte la séquence de sortie

Valeur de retour

sp en cas de succès ou pos_type(off_type(-1)) en cas d'échec.

Notes

seekpos() est appelée par std::basic_streambuf::pubseekpos(), qui est appelée par les versions à un argument de std::basic_istream::seekg() et std::basic_ostream::seekp().

De nombreuses implémentations ne mettent pas à jour la zone de lecture dans seekpos(), en déléguant à underflow(), appelée par le sgetc() suivant.

Exemple

Sur certaines implémentations, la zone de lecture est vidée par seekpos() et le second underflow() est nécessaire pour observer les effets.

#include <fstream>
#include <iostream>

struct mybuf : std::filebuf
{
    pos_type seekpos(pos_type sp, std::ios_base::openmode which)
    {
        std::cout << "Before seekpos(" << sp << "), size of the get area is "
                  << egptr() - eback() << " with "
                  << egptr() - gptr() << " read positions available.\n";

        pos_type rc = std::filebuf::seekpos(sp, which);

        std::cout << "seekpos() returns " << rc << ".\nAfter the call, "
                  << "size of the get area is "
                  << egptr() - eback() << " with "
                  << egptr() - gptr() << " read positions available.\n";
// décommenter si la zone de lecture est vidée par seekpos()
//        std::filebuf::underflow();
//        std::cout << "après underflow() forcé, la taille de la zone de lecture est "
//                  << egptr() - eback() << " avec "
//                  << egptr() - gptr() << " positions de lecture disponibles.\n";

        return rc;
    }
};

int main()
{
    mybuf buf;
    buf.open("test.txt", std::ios_base::in);
    std::istream stream(&buf);
    stream.get(); // lire un caractère pour forcer underflow()
    stream.seekg(2);
}

Sortie possible :

Before seekpos(2), size of the get area is 110 with 109 read positions available.
seekpos() returns 2.
After the call, size of the get area is 110 with 108 read positions available.

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 55 C++98 seekpos renvoie une position de flux non définie invalide en cas d'échec pos_type(off_type(-1)) est renvoyé en cas d'échec
LWG 171 C++98 l'ordre des opérations de repositionnement n'était pas clair rendu clair
