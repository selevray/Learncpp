std::basic_filebuf<CharT,Traits>::overflow

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
virtual int_type overflow ( int_type c = Traits::eof() );

Écrit certaines données de la zone d'écriture vers la séquence de caractères associée (vers le fichier).

Se comporte comme la classe de base std::basic_streambuf::overflow, sauf que, pour écrire les données, elle utilise d'abord std::codecvt::out de la locale imprégnée pour convertir les caractères en représentation externe (éventuellement multioctet), stockée dans un tampon temporaire (alloué à la taille nécessaire), puis utilise les E/S de fichier pour copier tous les octets entièrement convertis dans le fichier.

Si std::codecvt::always_noconv est vrai, l'appel à std::codecvt::out peut être omis.

Si la conversion échoue avec std::codecvt_base::error, renvoie Traits::eof() sans tenter aucune sortie.

Si le fichier associé n'est pas ouvert (is_open() == false), renvoie Traits::eof() avant de faire quoi que ce soit.

Paramètres

(aucune)

Valeur de retour

Traits::not_eof(c) pour indiquer le succès ou Traits::eof() pour indiquer l'échec.
