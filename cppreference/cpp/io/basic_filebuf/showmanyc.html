std::basic_filebuf<CharT,Traits>::showmanyc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
virtual std::streamsize showmanyc()

Si implémentée, renvoie le nombre de caractères restant à lire dans le fichier.

Paramètres

(aucune)

Valeur de retour

Le nombre de caractères disponibles en lecture dans le fichier, ou -1 si la fin de fichier a été atteinte.

Notes

Cette fonction est facultative. Si elle n'est pas implémentée, elle renvoie 0 (puisque la version de la classe de base std::basic_streambuf::showmanyc est appelée)

Qu'elle soit implémentée ou non, cette fonction est normalement appelée par std::basic_streambuf::in_avail si la zone de lecture est vide.

Le nom de cette fonction signifie "stream: how many characters?" ; elle se prononce donc "S how many C", et non "show many C"

Exemple

test d'implémentation pour vérifier si showmanyc() est implémentée pour filebuf

#include <fstream>
#include <iostream>

struct mybuf : std::filebuf
{
     using std::filebuf::showmanyc;
};

int main()
{
    mybuf fin;
    fin.open("main.cpp", std::ios_base::in);
    std::cout << "showmanyc() returns " << fin.showmanyc() << '\n';
}
