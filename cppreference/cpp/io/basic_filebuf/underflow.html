std::basic_filebuf<CharT,Traits>::underflow

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
virtual int_type underflow()

Lit davantage de données dans la zone d'entrée.

Se comporte comme la classe de base std::basic_streambuf::underflow, sauf que pour lire les données de la séquence de caractères associée (le fichier) vers la zone de lecture, les octets sont d'abord lus depuis le fichier dans un tampon temporaire (alloué de la taille nécessaire), puis std::codecvt::in de la locale imprégnée est utilisé pour convertir la représentation externe (typiquement multi-octets) en forme interne, qui sert ensuite à remplir la zone de lecture. La conversion peut être omise si std::codecvt::always_noconv de la locale renvoie true.

Paramètres

(aucune)

Valeur de retour

Traits::to_int_type(*gptr()) (le premier caractère de la séquence en attente) en cas de succès, ou Traits::eof() en cas d'échec.

Exemple

#include <fstream>
#include <iostream>

struct mybuf : std::filebuf
{
    int underflow()
    {
         std::cout << "Before underflow(): size of the get area is "
                   << egptr()-eback() << " with "
                   << egptr()-gptr() << " read positions available\n";
         int rc = std::filebuf::underflow();
         std::cout << "underflow() returns " << rc << ".\nAfter the call, "
                   << "size of the get area is "
                   << egptr()-eback() << " with "
                   << egptr()-gptr() << " read positions available\n";
        return rc;
    }
};

int main()
{
    mybuf buf;
    buf.open("test.txt", std::ios_base::in);
    std::istream stream(&buf);
    while (stream.get()) ;
}
