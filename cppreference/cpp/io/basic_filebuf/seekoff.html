std::basic_filebuf<CharT,Traits>::seekoff

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
virtual pos_type seekoff( off_type off,
                          std::ios_base::seekdir dir,
                          std::ios_base::openmode which = std::ios_base::in | std::ios_base::out );

Repositionne le pointeur de fichier, si possible, à la position correspondant exactement à off caractères depuis le début, la fin ou la position courante du fichier (selon la valeur de dir).

Si le fichier associé n'est pas ouvert (is_open() == false), échoue immédiatement.

Si l'encodage multioctet est dépendant de l'état (codecvt::encoding() a renvoyé -1) ou de longueur variable (codecvt::encoding() a renvoyé 0) et que le décalage off n'est pas 0, échoue immédiatement : cette fonction ne peut pas déterminer le nombre d'octets correspondant à off caractères.

Si dir n'est pas std::basic_ios::cur ou que le décalage off n'est pas 0, et que la dernière opération effectuée sur cet objet filebuf était une sortie (c'est-à-dire que la zone d'écriture n'est pas vide, ou que la dernière fonction appelée était overflow()), alors appelle std::codecvt::unshift pour déterminer la séquence de désétatisation nécessaire, et écrit cette séquence dans le fichier en appelant overflow().

Convertit ensuite l'argument dir en une valeur whence de type int comme suit :

valeur de dir valeur de whence

  • std::basic_ios::beg — SEEK_SET
  • std::basic_ios::end — SEEK_END
  • std::basic_ios::cur — SEEK_CUR

Ensuite, si l'encodage des caractères est à largeur fixe (codecvt::encoding() renvoie un nombre positif width), déplace le pointeur de fichier comme si par std::fseek(file, width*off, whence).

Sinon, déplace le pointeur de fichier comme si par std::fseek(file, 0, whence).

L'argument openmode, requis par la signature de la fonction de la classe de base, est généralement ignoré, car std::basic_filebuf ne conserve qu'une seule position de fichier.

Paramètres

  • off — position relative à laquelle placer l'indicateur de position

  • dir — définit la position de base à laquelle appliquer le décalage relatif. Elle peut être l'une des constantes suivantes :

    Constante Explication

    • beg — le début d'un flux
    • end — la fin d'un flux
    • cur — la position courante de l'indicateur de position du flux

  • which — définit la ou les séquences d'entrée et/ou de sortie à affecter. Il peut s'agir d'une des constantes suivantes ou d'une combinaison de celles-ci :

    Constante Explication

    • in — affecte la séquence d'entrée
    • out — affecte la séquence de sortie

Valeur de retour

Un objet nouvellement construit de type pos_type qui stocke la position de fichier résultante, ou pos_type(off_type(-1)) en cas d'échec.

Notes

seekoff() est appelée par std::basic_streambuf::pubseekoff, qui est appelée par std::basic_istream::seekg, std::basic_ostream::seekp, std::basic_istream::tellg et std::basic_ostream::tellp.

Exemple

#include <fstream>
#include <iostream>
#include <locale>

template<typename CharT>
int get_encoding(const std::basic_istream<CharT>& stream)
{
    using Facet = std::codecvt<CharT, char, std::mbstate_t>;
    return std::use_facet<Facet>(stream.getloc()).encoding();
}

int main()
{
    // préparer un fichier de 10 octets contenant 4 caractères ("zß水𝄋") en UTF-8
    std::ofstream("text.txt") << "\x7a\xc3\x9f\xe6\xb0\xb4\xf0\x9d\x84\x8b";

    // ouvrir en utilisant un encodage sans conversion
    std::ifstream f1("text.txt");
    std::cout << "f1's locale's encoding() returns "
              << get_encoding(f1) << '\n'
              << "pubseekoff(3, beg) returns "
              << f1.rdbuf()->pubseekoff(3, std::ios_base::beg) << '\n'
              << "pubseekoff(0, end) returns "
              << f1.rdbuf()->pubseekoff(0, std::ios_base::end) << '\n';

    // ouvrir en utilisant UTF-8
    std::wifstream f2("text.txt");
    f2.imbue(std::locale("en_US.UTF-8"));
    std::cout << "f2's locale's encoding() returns "
              << get_encoding(f2) << '\n'
              << "pubseekoff(3, beg) returns "
              << f2.rdbuf()->pubseekoff(3, std::ios_base::beg) << '\n'
              << "pubseekoff(0, end) returns "
              << f2.rdbuf()->pubseekoff(0, std::ios_base::end) << '\n';
}

Output:

f1's locale's encoding() returns 1
pubseekoff(3, beg) returns 3
pubseekoff(0, end) returns 10
f2's locale's encoding() returns 0
pubseekoff(3, beg) returns -1
pubseekoff(0, end) returns 10
