std::basic_stringbuf

Défini dans l'en-tête <sstream>

template<
    class CharT,
    class Traits = std::char_traits<CharT>,
    class Allocator = std::allocator<CharT>
> class basic_stringbuf
    : public std::basic_streambuf<CharT, Traits>

std::basic_stringbuf est un std::basic_streambuf dont la séquence de caractères associée est une séquence de caractères arbitraires résidant en mémoire, qui peut être initialisée à partir d'une instance de std::basic_string ou mise à disposition sous forme d'une telle instance.

Les implémentations typiques de std::basic_stringbuf contiennent directement, en tant que membre de données, un objet de type std::basic_string ou un conteneur séquentiel redimensionnable équivalent, et l'utilisent à la fois comme séquence de caractères contrôlée (le tableau que pointent les six pointeurs de std::basic_streambuf) et comme séquence de caractères associée (la source des caractères pour toutes les opérations d'entrée et la cible de la sortie).

De plus, une implémentation typique contient un membre de données de type std::ios_base::openmode indiquant le mode d'E/S du flux associé (entrée seule, sortie seule, entrée/sortie, fin de flux, etc.).

Si la stratégie de sur-allocation est utilisée par overflow(), un pointeur supplémentaire de marque haute peut être stocké pour suivre le dernier caractère initialisé.

(depuis C++11)
