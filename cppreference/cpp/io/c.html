Entrées/sorties de fichiers de style C

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Le sous-ensemble d'E/S C de la bibliothèque standard C++ implémente les opérations d'entrée/sortie par flux de style C. L'en-tête <cstdio> fournit la prise en charge générique des opérations sur fichiers et des fonctions d'entrée/sortie pour caractères étroits et multioctets, et l'en-tête <cwchar> fournit des fonctions d'entrée/sortie pour caractères larges.

Les flux C sont désignés par des objets de type std::FILE qui ne peuvent être accédés et manipulés que par des pointeurs de type std::FILE*. Chaque flux C est associé à un périphérique physique externe (fichier, flux d'entrée standard, imprimante, port série, etc.).

Types

Défini dans l'en-tête <cstdio>

  • FILE — type objet, capable de contenir toutes les informations nécessaires au contrôle d'un flux d'E/S C (typedef)
  • fpos_t — type objet non tableau complet, capable de spécifier de manière unique une position dans un fichier, y compris son état d'analyse multioctet (typedef)
