std::basic_stringstream<CharT,Traits,Allocator>::view

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

std::basic_string_view<CharT, Traits> view() const noexcept;  // (depuis C++20)

Obtient une std::basic_string_view sur l'objet chaîne sous-jacent. Équivalent à return rdbuf()->view();.

Paramètres

(aucune)

Valeur de retour

Une std::basic_string_view sur l'objet chaîne sous-jacent.

Exemple

#include <iostream>
#include <sstream>

int main()
{
    // flux d'entrée/sortie
    std::stringstream buf1;
    buf1 << 69;
    int n = 0;
    buf1 >> n;
    std::cout << "1) buf1 = [" << buf1.view() << "], n = " << n << '\n';

    // flux de sortie en mode ajout
    std::ostringstream buf2("test", std::ios_base::ate);
    buf2 << '1';
    std::cout << "2) buf2 = [" << buf2.view() << "]\n";

    // flux d'entrée
    std::istringstream inbuf("-42");
    inbuf >> n;
    std::cout << "3) inbuf = [" << inbuf.view() << "], n = " << n << '\n';
}

Output:

1) buf1 = [69], n = 69
2) buf2 = [test1]
3) inbuf = [-42], n = -42
