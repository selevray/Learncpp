Gère le contenu de l'objet chaîne sous-jacent.

  1. Renvoie une copie de la chaîne sous-jacente. Équivalent à return rdbuf()->str();.

  2. Renvoie une copie de la chaîne sous-jacente, en utilisant a comme allocateur. Équivalent à return rdbuf()->str(a);.

  3. Renvoie une chaîne construite par déplacement à partir de la chaîne sous-jacente. Équivalent à return std::move(*rdbuf()).str();.

4,5) Remplace le contenu de la chaîne sous-jacente. Équivalent à rdbuf()->str(s);.

  1. Remplace le contenu de la chaîne sous-jacente. Équivalent à rdbuf()->str(std::move(s));.

  2. Remplace le contenu de la chaîne sous-jacente. Équivalent à rdbuf()->str(t);.

Cette surcharge ne participe à la résolution de surcharge que si is_convertible_v<const T&, basic_string_view<charT, traits>> est true.

Paramètres

  • s — nouveau contenu de la chaîne sous-jacente
  • t — un objet (convertible en std::basic_string_view) à utiliser comme nouveau contenu de la chaîne sous-jacente
  • a — allocateur utilisé pour construire la chaîne renvoyée

Valeur de retour

1,2) Une copie de l'objet chaîne sous-jacent.

  1. Une chaîne construite par déplacement à partir de l'objet chaîne sous-jacent.

4-7) (aucun)

Notes

La copie de la chaîne sous-jacente renvoyée par str est un objet temporaire détruit à la fin de l'expression ; appeler directement c_str() sur le résultat de str() (par exemple dans auto *ptr = out.str().c_str();) produit donc un pointeur pendant.

Exemple

#include <iostream>
#include <sstream>

int main()
{
    int n;

    std::istringstream in; // pourrait aussi utiliser in("1 2")
    in.str("1 2");
    in >> n;
    std::cout << "After reading the first int from \"1 2\", the int is "
              << n << ", str() = \"" << in.str() << "\"\n";

    std::ostringstream out("1 2");
    out << 3;
    std::cout << "After writing the int '3' to output stream \"1 2\""
              << ", str() = \"" << out.str() << "\"\n";

    std::ostringstream ate("1 2", std::ios_base::ate);
    ate << 3;
    std::cout << "After writing the int '3' to append stream \"1 2\""
              << ", str() = \"" << ate.str() << "\"\n";
}

Output:

After reading the first int from "1 2", the int is 1, str() = "1 2"
After writing the int '3' to output stream "1 2", str() = "3 2"
After writing the int '3' to append stream "1 2", str() = "1 23"
