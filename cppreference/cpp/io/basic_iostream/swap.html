protected:
void swap( basic_iostream& other );  // (depuis C++11)

Échange l'état avec un autre objet flux d'entrée/sortie. Appelle effectivement basic_istream<CharT,Traits>::swap(other).

Cette fonction membre est protégée : elle est appelée par les fonctions membres swap des classes de flux dérivées std::basic_stringstream et std::basic_fstream, qui savent échanger correctement les tampons de flux associés.

Paramètres

  • other — autre flux avec lequel échanger l'état

*this
