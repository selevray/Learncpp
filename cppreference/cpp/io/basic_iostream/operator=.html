basic_iostream& operator=( const basic_iostream& other ) = delete;  // (1)

protected:
basic_iostream& operator=( basic_iostream&& other );  // (2) (depuis C++11)

Affecte un autre objet flux.

  1. L'affectation par copie n'est pas autorisée.

  2. Affecte par déplacement un autre objet flux. Appelle effectivement swap(rhs). Cet opérateur d'affectation par déplacement est protégé : il est appelé par les opérateurs d'affectation par déplacement des classes de flux dérivées std::basic_stringstream et std::basic_fstream, qui savent comment affecter correctement par déplacement les tampons de flux associés.

Paramètres

  • other — autre flux dont copier l'état

Valeur de retour

*this
