std::ostrstream::str

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

char* str();  // (obsolète en C++98) (supprimé en C++26)

Renvoie le pointeur vers le début du tampon, après l'avoir figé. Appelle effectivement rdbuf()->str().

Paramètres

(aucune)

Valeur de retour

Pointeur vers le début du tampon du std::strstreambuf associé, ou pointeur nul si aucun tampon n'est disponible.

Notes

Avant un appel à str() qui utilise le résultat comme chaîne C, le tampon du flux doit être terminé par un caractère nul. La sortie ordinaire, par exemple avec stream << 1.2, ne stocke pas de caractère nul de fin, il doit être ajouté explicitement, typiquement avec le manipulateur std::ends.

Après un appel à str(), les flux dynamiques sont gelés. Un appel à freeze(false) est requis avant de quitter la portée dans laquelle cet objet ostrstream a été créé, sinon le destructeur provoquera une fuite de mémoire. De plus, toute sortie supplémentaire vers un flux gelé peut être tronquée une fois qu'elle atteint la fin du tampon alloué, ce qui peut laisser le tampon sans caractère nul de fin.

Exemple

#include <iostream>
#include <strstream>

int main()
{
    std::ostrstream dyn; // tampon de sortie alloué dynamiquement
    dyn << "Test: " << 1.23; // ne pas ajouter std::ends pour démontrer le comportement d'ajout
    std::cout << "The output stream holds \"";
    std::cout.write(dyn.str(), dyn.pcount()) << "\"\n";
    // le flux est maintenant gelé à cause de str()
    dyn << " More text" << std::ends;
    std::cout << "The output stream holds \"";
    std::cout.write(dyn.str(), dyn.pcount()) << "\"\n";
    dyn.freeze(false);
}
