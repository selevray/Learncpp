std::ostrstream::rdbuf

strstreambuf* rdbuf() const;  // (obsolète en C++98) (supprimé en C++26)

Renvoie un pointeur vers le std::strstreambuf associé, en supprimant son caractère constant (malgré le qualificateur const de la fonction membre).

Paramètres

(aucune)

Valeur de retour

Pointeur vers le std::strstreambuf associé, dont le caractère constant a été supprimé.

Exemple

#include <strstream>

int main()
{
    const std::ostrstream buf;
    std::strstreambuf* ptr = buf.rdbuf();
}
