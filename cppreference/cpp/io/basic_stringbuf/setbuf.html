std::basic_stringbuf<CharT,Traits,Allocator>::setbuf

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
virtual std::basic_streambuf<CharT, Traits>* setbuf( char_type* s, std::streamsize n )

Si s est un pointeur nul et n vaut zéro, cette fonction n'a aucun effet.

Sinon, l'effet est défini par l'implémentation : certaines implémentations ne font rien, tandis que d'autres effacent le membre std::string utilisé actuellement comme tampon et commencent à utiliser le tableau de caractères fourni par l'utilisateur de taille n, dont le premier élément est pointé par s, comme tampon et comme séquence de caractères d'entrée/sortie.

Cette fonction est protégée et virtuelle ; elle ne peut être appelée que par l'intermédiaire de pubsetbuf() ou depuis les fonctions membres d'une classe définie par l'utilisateur dérivée de std::basic_stringbuf.

Paramètres

  • s — pointeur vers le premier CharT du tampon fourni par l'utilisateur, ou nul
  • n — le nombre d'éléments CharT du tampon fourni par l'utilisateur, ou zéro

Valeur de retour

this

Notes

Le tampon de flux obsolète std::strstreambuf ou le device boost.IOStreams boost::basic_array peut être utilisé pour implémenter une mise en tampon d'E/S sur un tableau de char fourni par l'utilisateur de manière portable.

Exemple

Teste la fonctionnalité setbuf de stringstream.

#include <iostream>
#include <sstream>

int main()
{
    std::ostringstream ss;
    char c[1024] = {};
    ss.rdbuf()->pubsetbuf(c, 1024);
    ss << 3.14 << '\n';
    std::cout << c << '\n';
}

Output:

3.14 (on GNU g++/libstdc++ and SunPro C++/roguewave)
<nothing> (on MS Visual Studio 2010, SunPro C++/stlport4, CLang++/libc++)
