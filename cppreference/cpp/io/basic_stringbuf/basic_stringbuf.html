La base std::basic_streambuf et les membres de données à titre d'exposition uniquement buf et mode sont initialisés comme suit.

Après l'initialisation de ces sous-objets, les surcharges (3-12) initialisent les séquences d'entrée et de sortie comme si elles appelaient init_buf_ptrs().

1,2) La surcharge [(1) (jusqu'à C++11) | (2) (depuis C++11)] est le constructeur par défaut. Il est défini par l'implémentation de savoir si les pointeurs de séquence (eback(), gptr(), egptr(), pbase(), pptr(), epptr()) sont initialisés à des pointeurs nuls.

5,6) Une fois la construction terminée, str.empty() vaut true.

  1. Cette surcharge ne participe à la résolution de surcharge que si std::is_same_v<SAlloc, Allocator> est false.

10-12) Convertit implicitement t en une vue de chaîne sv comme si par std::basic_string_view<CharT, Traits> sv = t;, puis elle est utilisée comme ci-dessus dans le tableau.

Ces surcharges participent à la résolution de surcharge uniquement si std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>> est true.

13,14) La surcharge (13) est le constructeur de déplacement. Il est défini par l'implémentation de savoir si les six pointeurs de séquence de *this obtiennent les valeurs qu'avait rhs.

Une fois la construction terminée, rhs est vide mais utilisable, et

  • Soit rhs_p désignant l'état de rhs juste avant cette construction, les expressions suivantes s'évalueront à true :

    • str() == rhs_p.str()
    • getloc() == rhs_p.getloc()
    • gptr() - eback() == rhs_p.gptr() - rhs_p.eback()
    • egptr() - eback() == rhs_p.egptr() - rhs_p.eback()
    • pptr() - pbase() == rhs_p.pptr() - rhs_p.pbase()
    • epptr() - pbase() == rhs_p.epptr() - rhs_p.pbase()

  • Soit rhs_a désignant l'état de rhs juste après cette construction, les expressions suivantes s'évalueront à true :

    • !eback() || eback() != rhs_a.eback()
    • !gptr() || gptr() != rhs_a.gptr()
    • !egptr() || egptr() != rhs_a.egptr()
    • !pbase() || pbase() != rhs_a.pbase()
    • !pptr() || pptr() != rhs_a.pptr()
    • !epptr() || epptr() != rhs_a.epptr()
  1. Le constructeur de copie est supprimé ; std::basic_stringbuf n'est pas CopyConstructible.

Paramètres

  • s — un std::basic_string utilisé pour initialiser le tampon

  • t — un objet (convertible en std::basic_string_view) utilisé pour initialiser le tampon

  • a — un autre allocateur utilisé pour construire le std::basic_string interne

  • rhs — un autre basic_stringbuf

  • which — spécifie le mode d'ouverture du flux. C'est un type masque de bits, les constantes suivantes sont définies :

    Constante Explication

    • app — se positionne à la fin du flux avant chaque écriture
    • binary — ouvre en mode binaire
    • in — ouvre en lecture
    • out — ouvre en écriture
    • trunc — supprime le contenu du flux à l'ouverture
    • ate — se positionner à la fin du flux immédiatement après l'ouverture
    • noreplace (C++23) — ouvrir en mode exclusif

Notes

Généralement appelé par le constructeur de std::basic_stringstream.

Le niveau de prise en charge des modes d'ouverture autres que std::ios_base::in et std::ios_base::out varie selon les implémentations. C++11 spécifie explicitement la prise en charge de std::ios_base::ate dans str() et dans ce constructeur, mais std::ios_base::app, std::ios_base::trunc et std::ios_base::binary ont des effets différents selon les implémentations.

Exemple

Montre l'appel direct au constructeur de std::basic_stringbuf :

#include <iostream>
#include <sstream>

int main()
{
    // constructeur par défaut (mode = in | out)
    std::stringbuf buf1;
    buf1.sputc('1');
    std::cout << &buf1 << '\n';

    // constructeur à partir d'une chaîne en mode at-end (depuis C++11)
    std::stringbuf buf2("test", std::ios_base::in
                              | std::ios_base::out
                              | std::ios_base::ate);
    buf2.sputc('1');
    std::cout << &buf2 << '\n';

    // test du mode d'ajout (les résultats diffèrent selon les compilateurs)
    std::stringbuf buf3("test", std::ios_base::in
                              | std::ios_base::out
                              | std::ios_base::app);
    buf3.sputc('1');
    buf3.pubseekpos(1);
    buf3.sputc('2');
    std::cout << &buf3 << '\n';
}
