Obtient et définit la chaîne sous-jacente.

Dans les descriptions ci-dessous, buf et mode sont des membres de données réservés à l'exposition de *this.

  1. Crée et renvoie un objet std::basic_string contenant une copie de la séquence de caractères sous-jacente de ce std::basic_stringbuf. Pour les flux en entrée uniquement, la chaîne renvoyée contient les caractères de l'intervalle [eback(),egptr()). Pour les flux en entrée/sortie ou en sortie uniquement, contient les caractères de pbase() jusqu'au dernier caractère de la séquence, quelle que soit la valeur de egptr() et epptr().

La séquence de caractères membre d'un tampon ouvert en écriture peut être sur-allouée pour des raisons d'efficacité. Dans ce cas, seuls les caractères initialisés sont renvoyés : ce sont ceux obtenus de la chaîne argument du constructeur, de la chaîne argument du dernier appel à une surcharge du setter de str(), ou d'une opération d'écriture. Une implémentation typique utilisant la sur-allocation maintient un pointeur high-watermark pour suivre la fin de la partie initialisée du tampon, et cette surcharge renvoie les caractères de pbase() jusqu'au pointeur high-watermark.

Équivalent à return std::basic_string<CharT, Traits, Allocator>(view(), get_allocator());.

(depuis C++20)

  1. Identique à (1), sauf que a est utilisé pour construire le std::basic_string renvoyé. Équivalent à return std::basic_string<CharT, Traits, SAlloc>(view(), a);.

Cette surcharge ne participe à la résolution de surcharge que si SAlloc satisfait les exigences de Allocator.

  1. Crée un objet std::basic_string comme si on le construisait par déplacement à partir de la séquence de caractères sous-jacente de *this dans buf. buf peut devoir être ajusté pour contenir d'abord le même contenu que dans (1). Ensuite, définit buf comme vide et appelle init_buf_ptrs(), puis renvoie l'objet std::basic_string.

  2. Remplace la séquence de caractères sous-jacente comme si par buf = s, puis appelle init_buf_ptrs().

  3. Identique à (4), sauf que le type de l'allocateur de s n'est pas Allocator.

Cette surcharge ne participe à la résolution de surcharge que si std::is_same_v<SAlloc, Allocator> est false.

  1. Remplace la séquence de caractères sous-jacente comme si par buf = std::move(s), puis appelle init_buf_ptrs().

  2. Convertit implicitement t en vue de chaîne sv comme si par std::basic_string_view<CharT, Traits> sv = t;, puis remplace la séquence de caractères sous-jacente comme si par buf = sv, puis appelle init_buf_ptrs().

Cette surcharge ne participe à la résolution de surcharge que si std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>> est true.

Paramètres

  • s — un objet std::basic_string contenant la séquence de caractères de remplacement
  • t — un objet (convertible en std::basic_string_view) contenant la séquence de caractères de remplacement
  • a — allocateur à utiliser pour toutes les allocations mémoire du std::basic_string renvoyé

Valeur de retour

1-3) Un objet std::basic_string contenant la séquence de caractères sous-jacente de ce tampon.

4-7) (aucun)

Notes

Cette fonction est généralement accessible via std::basic_istringstream::str(), std::basic_ostringstream::str() ou std::basic_stringstream::str().

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_sstream_from_string_view 202306L (C++26) Interfacer les flux de chaînes avec std::string_view

Exemple

#include <iostream>
#include <sstream>

int main()
{
    int n;

    std::istringstream in;  // pourrait aussi utiliser in("1 2")
    in.rdbuf()->str("1 2"); // définir la zone de lecture
    in >> n;
    std::cout << "after reading the first int from \"1 2\", the int is "
              << n << ", str() = \"" << in.rdbuf()->str() << "\"\n"; // ou in.str()

    std::ostringstream out("1 2");
    out << 3;
    std::cout << "after writing the int '3' to output stream \"1 2\""
              << ", str() = \"" << out.str() << "\"\n";

    std::ostringstream ate("1 2", std::ios_base::ate); // C++11
    ate << 3;
    std::cout << "after writing the int '3' to append stream \"1 2\""
              << ", str() = \"" << ate.str() << "\"\n";
}

Output:

after reading the first int from "1 2", the int is 1, str() = "1 2"
after writing the int '3' to output stream "1 2", str() = "3 2"
after writing the int '3' to append stream "1 2", str() = "1 23"
