std::basic_stringbuf<CharT,Traits,Allocator>::underflow

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
virtual int_type underflow()

Lit le caractère suivant de la zone de lecture du tampon.

Specifically:

  1. Si la séquence d'entrée a une position de lecture disponible (egptr() > gptr()), renvoie Traits::to_int_type(*gptr())

  2. Sinon, si pptr() > egptr() (des caractères ont été insérés dans le flux depuis la dernière fois que overflow() a changé egptr()), étend la fin de la zone de lecture pour inclure les caractères insérés les plus récemment, en changeant egptr() pour qu'il soit égal à pptr(), puis renvoie Traits::to_int_type(*gptr())

  3. Sinon, renvoie Traits::eof().

Tout caractère du tampon qui a été initialisé, qu'il provienne de la chaîne passée au constructeur ou qu'il ait été ajouté par overflow(), est considéré comme faisant partie de la séquence d'entrée.

Paramètres

(aucune)

Valeur de retour

Traits::to_int_type(*gptr()) (le prochain caractère à lire dans la zone de lecture) en cas de succès, ou Traits::eof() en cas d'échec.

Exemple

#include <iostream>
#include <sstream>

struct mybuf : std::stringbuf
{
    mybuf(const std::string& new_str,
          std::ios_base::openmode which = std::ios_base::in | std::ios_base::out)
        : std::stringbuf(new_str, which) {}

    int_type overflow(int_type c)
    {
        std::cout << "Before overflow():  get area size is " << egptr() - eback()
                  << ", the put area size is " << epptr() - pbase() << '\n';
        int_type rc = std::stringbuf::overflow(c);
        std::cout << "After overflow():   get area size is " << egptr() - eback()
                  << ", put area size is " << epptr() - pbase() << '\n';
        return rc;
    }

    int_type underflow()
    {
        std::cout << "Before underflow(): get area size is " << egptr() - eback()
                  << ", put area size is " << epptr() - pbase() << '\n';
        int_type ch = std::stringbuf::underflow();
        std::cout << "After underflow():  get area size is " << egptr() - eback()
                  << ", put area size is " << epptr() - pbase() << '\n';

        if (ch == EOF)
            std::cout << "underflow() returns EOF\n";
        else
            std::cout << "underflow() returns '" << char(ch) << "'\n";
        return ch;
    }
};

int main()
{
    mybuf sbuf("123"); // flux en lecture-écriture
    std::iostream stream(&sbuf);
    int n;
    stream >> n; // appelle sgetc() quatre fois
                 // trois appels renvoient les caractères '1', '2', '3'
                 // le quatrième appel, gptr() == egptr() et underflow() est appelé
                 // underflow renvoie EOF
    std::cout << "n = " << n << '\n';
    stream.clear(); // efface le eofbit

    stream << "123456"; // sputc() est appelé 6 fois
                        // les trois premiers appels stockent "123" dans le tampon existant
                        // le 4e appel constate que pptr() == epptr() et appelle overflow()
                        // overflow() agrandit le tampon et définit egptr() à 4
                        // les 5e et 6e appels stockent '5' et '6', en faisant avancer pptr()

    stream >> n; // appelle sgetc() 4 fois
                 // le 1er appel renvoie le '4' rendu disponible par overflow()
                 // au 2e appel, egptr() == egptr() et underflow() est appelé
                 // underflow fait avancer egptr() pour qu'il soit égal à pptr() (qui vaut 6)
                 // le 3e sgetc() renvoie '6'
                 // le 4e sgetc() constate gptr() == egptr(), appelle underflow()
                 // underflow() renvoie EOF

    std::cout << "n = " << n << '\n';
}
