std::basic_stringbuf<CharT,Traits,Allocator>::init_buf_ptrs

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void init_buf_ptrs();  // ( exposition uniquement* )

Initialise les séquences d'entrée et de sortie à partir de buf selon mode. buf et mode sont des membres de données réservés à l'exposition de *this.

Immédiatement après le retour de cette fonction :

  • Si std::ios_base::out est positionné dans mode, pbase() pointe sur buf.front() et epptr() >= pbase() + buf.size() vaut true ;
    • de plus, si std::ios_base::ate est positionné dans mode, pptr() == pbase() + buf.size() vaut true,
    • sinon pptr() == pbase() vaut true.
  • Si std::ios_base::in est positionné dans mode, eback() pointe sur buf.front(), et gptr() == eback() && egptr() == eback() + buf.size() vaut true.

Notes

Pour des raisons d'efficacité, les opérations sur le tampon de flux peuvent violer les invariants de buf tant qu'il est encapsulé dans std::basic_stringbuf, par exemple en écrivant dans les caractères de l'intervalle [buf.data() + buf.size(),buf.data() + buf.capacity()).

Toutes les opérations récupérant un std::basic_string depuis buf garantissent que les invariants std::basic_string sont respectés pour la valeur renvoyée.
