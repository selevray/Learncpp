std::cin, std::wcin

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iostream>

extern std::istream cin;  // (1)

extern std::wistream wcin;  // (2)

Les objets globaux std::cin et std::wcin contrôlent l'entrée depuis un tampon de flux de type défini par l'implémentation (dérivé de std::streambuf), associé au flux d'entrée standard C stdin.

Ces objets sont garantis initialisés pendant ou avant la première construction d'un objet de type std::ios_base::Init, et sont utilisables dans les constructeurs et destructeurs d'objets statiques avec initialisation ordonnée (à condition que <iostream> soit inclus avant la définition de l'objet).

Tant que sync_with_stdio(false) n'a pas été émis, il est sûr d'accéder simultanément à ces objets depuis plusieurs threads, pour les entrées formatées comme non formatées.

Une fois std::cin construit, std::cin.tie() renvoie &std::cout, et de même, std::wcin.tie() renvoie &std::wcout. Cela signifie que toute opération d'entrée formatée sur std::cin entraîne un appel à std::cout.flush() si des caractères sont en attente de sortie.

Notes

Le « c » du nom fait référence à « character » (stroustrup.com FAQ) ; cin signifie « entrée de caractères » et wcin signifie « entrée de caractères larges ».

Exemple

#include <iostream>

struct Foo
{
    int n;
    Foo()
    {
        std::cout << "Enter n: "; // aucun vidage nécessaire
        std::cin >> n;
    }
};

Foo f; // objet statique

int main()
{
    std::cout << "f.n is " << f.n << '\n';
}

Sortie possible :

Enter n: 10
f.n is 10
