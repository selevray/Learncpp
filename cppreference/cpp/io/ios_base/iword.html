std::ios_base::iword

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

long& iword( int index );

Alloue d'abord ou redimensionne le stockage privé (tableau dynamique de long ou autre structure de données indexable) suffisamment pour rendre index un index valide, puis renvoie une référence vers l'élément long du stockage privé d'indice index.

La référence peut être invalidée par toute opération sur cet objet ios_base, y compris un autre appel à iword(), mais les valeurs stockées sont conservées, de sorte que la lecture depuis iword(index) avec le même indice plus tard produira la même valeur jusqu'au prochain appel à std::basic_ios::copyfmt(). La valeur peut être utilisée à toute fin. L'indice de l'élément doit être obtenu par un appel précédent à xalloc(), sinon le comportement est indéfini. Les nouveaux éléments sont initialisés à 0.

Si la fonction échoue (éventuellement à cause d'un échec d'allocation) et que *this est un sous-objet de classe de base d'un objet ou sous-objet basic_ios<>, appelle std::basic_ios<>::setstate(badbit) qui peut lever std::ios_base::failure.

Notes

L'usage typique du stockage iword est de transmettre des informations (par ex. des indicateurs de formatage personnalisés) depuis des manipulateurs d'E/S définis par l'utilisateur vers des operator<< et operator>> définis par l'utilisateur, ou vers des facettes de formatage définies par l'utilisateur et intégrées aux flux standard.

Paramètres

  • index — valeur d'indice de l'élément

Valeur de retour

Une référence vers l'élément.

Exceptions

Peut lever std::ios_base::failure lors de la mise à 1 du badbit.

Exemple

#include <iostream>
#include <string>

struct Foo
{
    static int foo_xalloc;
    std::string data;

    Foo(const std::string& s) : data(s) {}
};

// Alloue le stockage iword pour une utilisation avec des objets Foo
int Foo::foo_xalloc = std::ios_base::xalloc();

// Cet opérateur operator<< défini par l'utilisateur affiche la chaîne à l'envers si l'iword contient 1
std::ostream& operator<<(std::ostream& os, Foo& f)
{
    if (os.iword(Foo::foo_xalloc) == 1)
        return os << std::string(f.data.rbegin(), f.data.rend());
    else
        return os << f.data;
}

// Ce manipulateur d'E/S bascule le nombre stocké dans iword entre 0 et 1
std::ios_base& rev(std::ios_base& os)
{
    os.iword(Foo::foo_xalloc) = !os.iword(Foo::foo_xalloc);
    return os;
}

int main()
{
    Foo f("example");
    std::cout << f << '\n' << rev << f << '\n' << rev << f << '\n';
}
