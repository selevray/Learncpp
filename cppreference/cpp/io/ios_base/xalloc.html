std::ios_base::xalloc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static int xalloc();

Renvoie une valeur d'index unique (à l'échelle du programme) pouvant servir à accéder à un élément long et à un élément void* du stockage privé de std::ios_base en appelant iword() et pword(). L'appel à xalloc n'alloue pas de mémoire.

Cette fonction est thread-safe : l'accès concurrent par plusieurs threads ne provoque pas de course de données.

(depuis C++11)

Incrémente effectivement le prochain index unique disponible.

Valeur de retour

Entier unique à utiliser comme index de pword/iword.

Exemple

Utilise le stockage pword de la classe de base pour l'identification de type à l'exécution des objets de flux dérivés.

#include <iostream>

template<class CharT, class Traits = std::char_traits<CharT>>
class mystream : public std::basic_ostream<CharT, Traits>
{
public:
    static const int xindex;

    mystream(std::basic_ostream<CharT, Traits>& ostr) :
        std::basic_ostream<CharT, Traits>(ostr.rdbuf())
    {
        this->pword(xindex) = this;
    }

    void myfn()
    {
        *this << "[special handling for mystream]";
    }
};

// Chaque spécialisation de mystream obtient un index unique depuis xalloc()
template<class CharT, class Traits>
const int mystream<CharT, Traits>::xindex = std::ios_base::xalloc();

// Ce manipulateur d'E/S pourra reconnaître les ostream qui sont des mystream
// en recherchant le pointeur stocké dans pword
template<class CharT, class Traits>
std::basic_ostream<CharT, Traits>& mymanip(std::basic_ostream<CharT, Traits>& os)
{
    if (os.pword(mystream<CharT, Traits>::xindex) == &os)
        static_cast<mystream<CharT, Traits>&>(os).myfn();
    return os;
}

int main()
{
    std::cout << "cout, narrow-character test " << mymanip << '\n';

    mystream<char> myout(std::cout);
    myout << "myout, narrow-character test " << mymanip << '\n';

    std::wcout << "wcout, wide-character test " << mymanip << '\n';

    mystream<wchar_t> mywout(std::wcout);
    mywout << "mywout, wide-character test " << mymanip << '\n';
}

Output:

cout, narrow-character test
myout, narrow-character test [special handling for mystream]
wcout, wide-character test
mywout, wide-character test [special handling for mystream]
