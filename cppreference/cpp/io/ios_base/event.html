std::ios_base::event

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

enum event { erase_event, imbue_event, copyfmt_event };

Spécifie le type d'événement passé aux fonctions enregistrées par register_callback() lors d'événements particuliers. Les constantes suivantes sont définies :

Constante Explication

  • erase_event — émis lors de ~ios_base() ou de basic_ios::copyfmt() (avant la copie des membres)
  • imbue_event — émis lors de imbue()
  • copyfmt_event — émis lors de basic_ios::copyfmt() (après la copie des membres, mais avant la copie des paramètres d'exception)
