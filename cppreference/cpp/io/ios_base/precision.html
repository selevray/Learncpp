std::ios_base::precision

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

streamsize precision() const;  // (1)

streamsize precision( streamsize new_precision );  // (2)

Gère la précision (c.-à-d. le nombre de chiffres générés) de la sortie en virgule flottante effectuée par std::num_put::do_put.

  1. Renvoie la précision courante.

  2. Définit la précision à la valeur donnée. Renvoie la précision précédente.

La précision par défaut, établie par std::basic_ios::init, est 6.

Paramètres

  • new_precision — nouvelle valeur de précision

Valeur de retour

La précision avant l'appel de la fonction

Exemple

#include <iostream>

int main()
{
    const double d = 12.345678901234;
    std::cout << "The  default precision is " << std::cout.precision() << "\n\n";
    std::cout << "With default precision d is " << d << '\n';
    std::cout.precision(8);
    std::cout << "With high    precision d is " << d << '\n';
}

Output:

The  default precision is 6

With default precision d is 12.3457
With high    precision d is 12.345679
