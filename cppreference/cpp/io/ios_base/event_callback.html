std::ios_base::event_callback

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

typedef void ( *event_callback )( event type, ios_base& ios, int index );

Le type des fonctions de rappel qui peuvent être enregistrées à l'aide de register_callback() pour être appelées lors d'événements particuliers.

type est une valeur de type ios_base::event qui indique le type de l'événement qui invoquera ce rappel.

ios désigne l'objet flux pour lequel le rappel est invoqué : *this est passé en argument lorsque les rappels sont invoqués par les fonctions membres std::ios_base et std::basic_ios.

index est la valeur fournie par l'utilisateur et passée à register_callback() lors de l'enregistrement de la fonction.
