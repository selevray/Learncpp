std::ios_base::pword

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void*& pword( int index );

Alloue d'abord ou redimensionne le stockage privé (tableau dynamique de void* ou autre structure de données indexable) suffisamment pour rendre index un index valide, puis renvoie une référence vers l'élément void* du stockage privé d'indice index.

La référence peut être invalidée par toute opération sur cet objet ios_base, y compris un autre appel à pword(), mais les valeurs stockées sont conservées, de sorte que la lecture depuis pword(index) avec le même indice plus tard produira la même valeur jusqu'au prochain appel à std::basic_ios::copyfmt(). La valeur peut être utilisée à toute fin. L'indice de l'élément doit être obtenu par xalloc(), sinon le comportement est indéfini. Les nouveaux éléments sont initialisés à un pointeur nul.

Si la fonction échoue (éventuellement à cause d'un échec d'allocation) et que *this est un sous-objet de classe de base d'un objet ou sous-objet basic_ios<>, appelle std::basic_ios<>::setstate(badbit) qui peut lever std::ios_base::failure.

Paramètres

  • index — valeur d'indice de l'élément

Valeur de retour

Une référence vers l'élément.

Exceptions

Peut lever std::ios_base::failure lors de la mise à 1 du badbit.

Notes

Si les pointeurs stockés dans pword nécessitent une gestion, register_callback() peut être utilisé pour installer des gestionnaires qui effectuent une copie profonde ou une désallocation si nécessaire.

Exemple

Utilise le stockage pword de la classe de base pour l'identification de type à l'exécution des objets de flux dérivés.

#include <iostream>

template<class CharT, class Traits = std::char_traits<CharT>>
class mystream : public std::basic_ostream<CharT, Traits>
{
public:
    static const int xindex;

    mystream(std::basic_ostream<CharT, Traits>& ostr) :
        std::basic_ostream<CharT, Traits>(ostr.rdbuf())
    {
        this->pword(xindex) = this;
    }

    void myfn()
    {
        *this << "[special handling for mystream]";
    }
};

// Chaque spécialisation de mystream obtient un index unique depuis xalloc()
template<class CharT, class Traits>
const int mystream<CharT, Traits>::xindex = std::ios_base::xalloc();

// Ce manipulateur d'E/S pourra reconnaître les ostream qui sont des mystream
// en recherchant le pointeur stocké dans pword
template<class CharT, class Traits>
std::basic_ostream<CharT, Traits>& mymanip(std::basic_ostream<CharT, Traits>& os)
{
    if (os.pword(mystream<CharT, Traits>::xindex) == &os)
        static_cast<mystream<CharT, Traits>&>(os).myfn();
    return os;
}

int main()
{
    std::cout << "cout, narrow-character test " << mymanip << '\n';

    mystream<char> myout(std::cout);
    myout << "myout, narrow-character test " << mymanip << '\n';

    std::wcout << "wcout, wide-character test " << mymanip << '\n';

    mystream<wchar_t> mywout(std::wcout);
    mywout << "mywout, wide-character test " << mymanip << '\n';
}

Output:

cout, narrow-character test
myout, narrow-character test [special handling for mystream]
wcout, wide-character test
mywout, wide-character test [special handling for mystream]

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 36 C++98 la valeur stockée pourrait ne pas être conservée si la référence est invalidée la valeur stockée est conservée jusqu'au prochain appel de copyfmt()
LWG 41 C++98 la fonction positionne badbit d'elle-même en cas d'échec, mais ios_base ne fournit pas une telle interface badbit est positionné par basic_ios (si *this est un sous-objet de classe de base)
