std::ios_base::unsetf

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void unsetf( fmtflags flags );

Efface les indicateurs de formatage identifiés par flags.

Paramètres

  • flags — indicateurs de formatage à effacer. Il peut s'agir d'une combinaison des constantes des indicateurs de formatage.

Indicateurs de format

Constante Explication

  • dec — utiliser la base décimale pour les E/S d'entiers : voir std::dec
  • oct — utiliser la base octale pour les E/S d'entiers : voir std::oct
  • hex — utiliser la base hexadécimale pour les E/S d'entiers : voir std::hex
  • basefield — dec | oct | hex. Utile pour les opérations de masquage
  • left — alignement à gauche (ajoute des caractères de remplissage à droite) : voir std::left
  • right — alignement à droite (ajoute des caractères de remplissage à gauche) : voir std::right
  • internal — alignement interne (ajoute des caractères de remplissage au point désigné interne) : voir std::internal
  • adjustfield — left | right | internal. Utile pour les opérations de masquage
  • scientific — générer les types à virgule flottante en notation scientifique, ou en notation hexadécimale si combiné avec fixed : voir std::scientific
  • fixed — générer les types à virgule flottante en notation fixe, ou en notation hexadécimale si combiné avec scientific : voir std::fixed
  • floatfield — scientific | fixed. Utile pour les opérations de masquage
  • boolalpha — insérer et extraire le type bool au format alphanumérique : voir std::boolalpha
  • showbase — générer un préfixe indiquant la base numérique pour la sortie d'entiers, exiger l'indicateur de devise dans les E/S monétaires : voir std::showbase
  • showpoint — générer inconditionnellement un caractère de point décimal pour la sortie des nombres à virgule flottante : voir std::showpoint
  • showpos — générer un caractère + pour la sortie numérique non négative : voir std::showpos
  • skipws — ignorer les espaces blancs initiaux avant certaines opérations d'entrée : voir std::skipws
  • unitbuf — vider la sortie après chaque opération de sortie : voir std::unitbuf
  • uppercase — remplacer certaines lettres minuscules par leurs équivalents majuscules dans certaines opérations de sortie : voir std::uppercase
