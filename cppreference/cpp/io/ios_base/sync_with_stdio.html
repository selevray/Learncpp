std::ios_base::sync_with_stdio

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static bool sync_with_stdio( bool sync = true );

Définit si les flux standard C++ sont synchronisés avec les flux standard C après chaque opération d'entrée/sortie.

Les flux standard C++ sont les suivants : std::cin, std::cout, std::cerr, std::clog, std::wcin, std::wcout, std::wcerr et std::wclog.

Les flux standard C sont les suivants : stdin, stdout et stderr.

Pour un flux standard str, synchronisé avec le flux C f, les paires de fonctions suivantes ont un effet identique :

  1. std::fputc(f, c) and str.rdbuf()->sputc(c).

  2. std::fgetc(f) and str.rdbuf()->sbumpc().

  3. std::ungetc(c, f) and str.rdbuf()->sputbackc(c).

En pratique, cela signifie que les flux C++ synchronisés sont sans tampon, et que chaque opération d'E/S sur un flux C++ est immédiatement appliquée au tampon du flux C correspondant. Cela permet de mélanger librement les E/S C++ et C.

De plus, les flux C++ synchronisés sont garantis thread-safe (les caractères individuels écrits depuis plusieurs threads peuvent s'entrelacer, mais aucune course de données ne se produit).

Si la synchronisation est désactivée, les flux standard C++ peuvent mettre leurs E/S en tampon indépendamment, ce qui peut être nettement plus rapide dans certains cas.

Par défaut, les huit flux standard C++ sont synchronisés avec leurs flux C respectifs.

Si cette fonction est appelée après que des E/S ont eu lieu sur le flux standard, le comportement est défini par l'implémentation : les implémentations vont de l'absence d'effet à la destruction du tampon de lecture.

Paramètres

  • sync — le nouveau paramètre de synchronisation

Valeur de retour

État de la synchronisation avant l'appel à la fonction.

Exemple

#include <cstdio>
#include <iostream>

int main()
{
    std::ios::sync_with_stdio(false);
    std::cout << "a\n";
    std::printf("b\n");
    std::cout << "c\n";
}
