std::basic_streambuf<CharT,Traits>::in_avail

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

std::streamsize in_avail();

Renvoie le nombre de caractères disponibles dans la zone de lecture (get area). Si une position de lecture est disponible, renvoie effectivement egptr() - gptr(), la taille de la zone de lecture. Dans ce cas, le nombre d'octets renvoyé est le nombre d'octets pouvant être extraits du tampon sans appeler underflow().

Si la zone de lecture est vide, appelle showmanyc() pour déterminer le nombre d'octets disponibles dans la séquence de caractères associée. Dans ce cas, la valeur renvoyée est le nombre d'octets pouvant être extraits du tampon tout en garantissant que underflow() ne renverra pas Traits::eof.

Paramètres

(aucune)

Valeur de retour

Le nombre de caractères disponibles pour une lecture non bloquante (soit la taille de la zone de lecture, soit le nombre de caractères prêts à être lus dans la séquence de caractères associée), ou -1 si aucun caractère n'est disponible dans la séquence associée, autant que showmanyc() puisse le déterminer.
