std::basic_streambuf<CharT,Traits>::underflow

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
virtual int_type underflow();

Garantit qu'au moins un caractère est disponible dans la zone d'entrée en mettant à jour les pointeurs de la zone d'entrée (si nécessaire) et en lisant davantage de données depuis la séquence d'entrée (si applicable). Renvoie la valeur de ce caractère (convertie en int_type avec Traits::to_int_type(c)) en cas de succès, ou Traits::eof() en cas d'échec.

La fonction peut mettre à jour les pointeurs gptr, egptr et eback pour définir l'emplacement des données nouvellement chargées (le cas échéant). En cas d'échec, la fonction garantit que soit gptr() == nullptr, soit gptr() == egptr.

La version de la classe de base de la fonction ne fait rien. Les classes dérivées peuvent redéfinir cette fonction afin de permettre des mises à jour de la zone de lecture en cas d'épuisement.

Paramètres

(aucune)

Valeur de retour

La valeur du caractère pointé par le pointeur de lecture après l'appel en cas de succès, ou Traits::eof() sinon.

La version de la classe de base de la fonction renvoie traits::eof().

Note

Les fonctions publiques de std::streambuf n'appellent cette fonction que si gptr() == nullptr ou gptr() >= egptr().

Exemple

#include <iostream>
#include <sstream>

class null_filter_buf : public std::streambuf
{
    std::streambuf* src;
    char ch; // tampon d'un seul octet
protected:
    int underflow()
    {
        traits_type::int_type i;
        while ((i = src->sbumpc()) == '\0')
            ; // ignorer les zéros
        if (!traits_type::eq_int_type(i, traits_type::eof()))
        {
            ch = traits_type::to_char_type(i);
            setg(&ch, &ch, &ch+1); // rendre une position de lecture disponible
        }
        return i;
    }
public:
    null_filter_buf(std::streambuf* buf) : src(buf)
    {
        setg(&ch, &ch + 1, &ch + 1); // le tampon est initialement plein
    }
};

void filtered_read(std::istream& in)
{
    std::streambuf* orig = in.rdbuf();
    null_filter_buf buf(orig);
    in.rdbuf(&buf);
    for (char c; in.get(c);)
        std::cout << c;
    in.rdbuf(orig);
}

int main()
{
    char a[] = "This i\0s \0an e\0\0\0xample";
    std::istringstream in(std::string(std::begin(a), std::end(a)));
    filtered_read(in);
}
