std::basic_streambuf<CharT,Traits>::sgetc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

int_type sgetc();

Lit un caractère depuis la séquence d'entrée.

Si la position de lecture de la séquence d'entrée n'est pas disponible, retourne underflow(). Sinon retourne Traits::to_int_type(*gptr()).

Paramètres

(aucune)

Valeur de retour

La valeur du caractère pointé par le pointeur de lecture.

Exemple

#include <iostream>
#include <sstream>

int main()
{
    std::stringstream stream("Hello, world");
    std::cout << "sgetc() returned '" << (char)stream.rdbuf()->sgetc() << "'\n";
    std::cout << "peek() returned '" << (char)stream.peek() << "'\n";
    std::cout << "get() returned '" << (char)stream.get() << "'\n";
}

Output:

sgetc() returned 'H'
peek() returned 'H'
get() returned 'H'
