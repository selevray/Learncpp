protected:
void gbump( int count );

Saute count caractères dans la zone de lecture. Ceci est réalisé en ajoutant count au pointeur de lecture. Aucune vérification de sous-dépassement n'est effectuée.

Paramètres

  • count — nombre de caractères à sauter

Valeur de retour

(aucune)

Notes

Comme cette fonction prend un int, elle ne peut pas manipuler de tampons de plus de std::numeric_limits<int>::max() caractères (LWG issue 255).
