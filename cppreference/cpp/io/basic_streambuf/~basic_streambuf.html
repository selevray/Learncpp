std::basic_streambuf<CharT,Traits>::~basic_streambuf

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

virtual ~basic_streambuf();

Ce destructeur n'a aucun effet : les membres de cet basic_streambuf (les pointeurs et la locale) sont détruits conformément à la séquence habituelle de destruction de l'objet après le retour de ce destructeur. Cependant, comme il est déclaré public virtual, il permet de supprimer par un pointeur vers la classe de base les objets dérivés de std::basic_streambuf.

Paramètres

(aucune)

Exemple

#include <fstream>
#include <iostream>

int main()
{
    std::filebuf* fbp = new std::filebuf;
    fbp->open("test.txt", std::ios_base::out);
    fbp->sputn("Hello\n", 6);

    std::streambuf* sbp = fbp;
    delete sbp; // le fichier est fermé, la sortie est vidée et écrite

    std::ifstream f("test.txt");
    std::cout << f.rdbuf(); // proof
}

Output:

Hello
