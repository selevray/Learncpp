std::basic_streambuf<CharT,Traits>::showmanyc

protected:
virtual std::streamsize showmanyc();

Estime le nombre de caractères disponibles en entrée dans la séquence de caractères associée. underflow() est garantie de ne pas retourner Traits::eof() ni de lever une exception tant qu'au moins autant de caractères n'ont pas été extraits.

Paramètres

(aucune)

Valeur de retour

Le nombre de caractères assurément disponibles dans la séquence de caractères associée, ou -1 si showmanyc peut déterminer, sans bloquer, qu'aucun caractère n'est disponible. Si showmanyc retourne -1, underflow() et uflow() retourneront certainement Traits::eof ou lèveront une exception.

La version de la classe de base retourne 0, ce qui signifie « incertain s'il y a des caractères disponibles dans la séquence associée ».

Notes

Le nom de cette fonction signifie « flux : combien de caractères ? », il se prononce donc « S how many C », et non « show many C ».
