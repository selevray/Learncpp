std::basic_streambuf<CharT,Traits>::pbackfail

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
virtual int_type pbackfail( int_type c = Traits::eof() );

Cette fonction ne peut être appelée que si l'une des conditions suivantes est satisfaite :

  • gptr() est null,
  • gptr() == eback(), or
  • traits::eq(traits::to_char_type(c), gptr()[-1]) renvoie false.

Cette fonction est appelée par les fonctions publiques sungetc() et sputbackc() (qui, à leur tour, sont appelées par basic_istream::unget et basic_istream::putback) lorsque :

  1. Il n'existe aucune position de retour arrière dans la zone de lecture (pbackfail() est appelée sans arguments). Dans cette situation, le rôle de pbackfail() est de reculer la zone de lecture d'un caractère, si la séquence de caractères associée le permet (par exemple, un streambuf adossé à un fichier peut recharger le tampon depuis le fichier, en commençant un caractère plus tôt).

  2. L'appelant tente de remettre un caractère différent de celui récupéré précédemment (pbackfail() est appelée avec le caractère à remettre). Dans cette situation, le rôle de pbackfail() est de placer le caractère c dans la zone de lecture à la position juste avant basic_streambuf::gptr() et, si possible, de modifier la séquence de caractères associée pour refléter ce changement. Cela peut impliquer de reculer la zone de lecture comme dans le premier cas.

La version par défaut de cette fonction de la classe de base ne fait rien et renvoie Traits::eof() dans toutes les situations. Cette fonction est redéfinie par les classes dérivées : basic_stringbuf::pbackfail, basic_filebuf::pbackfail, strstreambuf::pbackfail, et doit être redéfinie par les classes de flux définies par l'utilisateur et par les bibliothèques tierces.

Paramètres

  • ch — caractère à remettre, ou Traits::eof() si seul un recul est demandé

Valeur de retour

Traits::eof() en cas d'échec, une autre valeur pour indiquer le succès. La version de la classe de base échoue toujours.
