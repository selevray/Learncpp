std::basic_streambuf<CharT,Traits>::sputbackc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

int_type sputbackc( char_type c );

Remet un caractère dans la zone de lecture.

Si une position de retour est disponible dans la zone de lecture (gptr() > eback()), et que le caractère c est égal au caractère situé une position à gauche de gptr() (tel que déterminé par Traits::eq(c, gptr()[-1])), alors décrémente simplement le pointeur suivant (gptr()).

Sinon, appelle pbackfail(Traits::to_int_type(c)) pour soit reculer dans la zone de lecture, soit modifier à la fois la zone de lecture et éventuellement la séquence de caractères associée.

La fonction de flux d'entrée-sortie basic_istream::putback est implémentée à l'aide de cette fonction.

Paramètres

  • c — caractère à remettre

Valeur de retour

Si une position de retour était disponible, retourne le caractère que pointe désormais le pointeur suivant, converti en int_type avec Traits::to_int_type(*gptr()). La prochaine lecture d'un seul caractère depuis ce streambuf retournera ce caractère.

Si aucune position de retour n'était disponible, retourne ce que pbackfail() retourne, soit Traits::eof() en cas d'échec.

Exemple

#include <iostream>
#include <sstream>

int main()
{
    std::stringstream s("abcdef"); // gptr() pointe sur 'a' dans "abcdef"
    std::cout << "Before putback, string holds " << s.str() << '\n';
    char c1 = s.get(); // c1 = 'a', gptr() pointe désormais sur 'b' dans "abcdef"
    char c2 = s.rdbuf()->sputbackc('z'); // identique à s.putback('z')
                                         // gptr() pointe désormais sur 'z' dans "zbcdef"
    std::cout << "After putback, string holds " << s.str() << '\n';
    char c3 = s.get(); // c3 = 'z', gptr() pointe désormais sur 'b' dans "zbcdef"
    char c4 = s.get(); // c4 = 'b', gptr() pointe désormais sur 'c' dans "zbcdef"
    std::cout << c1 << c2 << c3 << c4 << '\n';

    s.rdbuf()->sputbackc('b');  // gptr() pointe désormais sur 'b' dans "zbcdef"
    s.rdbuf()->sputbackc('z');  // gptr() pointe désormais sur 'z' dans "zbcdef"
    int eof = s.rdbuf()->sputbackc('x');  // rien à remettre : pbackfail() échoue
    if (eof == EOF)
        std::cout << "No room to putback after 'z'\n";
}

Output:

Before putback, string holds abcdef
After putback, string holds zbcdef
azzb
No room to putback after 'z'
