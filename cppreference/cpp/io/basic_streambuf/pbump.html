std::basic_streambuf<CharT,Traits>::pbump

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
void pbump( int count );

Repositionne le pointeur d'écriture (put pointer) (pptr()) de count caractères, où count peut être positif ou négatif. Aucune vérification n'est effectuée pour déplacer le pointeur en dehors de la zone d'écriture [pbase(),epptr()).

Si le pointeur est avancé puis que overflow() est appelée pour vider la zone d'écriture vers la séquence de caractères associée, l'effet est que des count caractères supplémentaires aux valeurs indéterminées sont écrits.

Paramètres

  • count — nombre à ajouter au pointeur d'écriture

Valeur de retour

(aucune)

Notes

Comme cette fonction prend un int, elle ne peut pas manipuler de tampons de plus de std::numeric_limits<int>::max() caractères (LWG issue 255).

Exemple

#include <fstream>
#include <iostream>
#include <string>

struct showput_streambuf : std::filebuf
{
    using std::filebuf::pbump; // exposer protégé
    std::string showput() const
    {
        return std::string(pbase(), pptr());
    }
};

int main()
{
    showput_streambuf mybuf;
    mybuf.open("test.txt", std::ios_base::out);
    std::ostream str(&mybuf);
    str << "This is a test" << std::flush << "1234";
    std::cout << "The put area contains: " << mybuf.showput() << '\n';
    mybuf.pbump(10);
    std::cout << "after pbump(10), it contains " << mybuf.showput() << '\n';
}

Output:

The put area contains: 1234
after pbump(10), it contains 1234 is a test
