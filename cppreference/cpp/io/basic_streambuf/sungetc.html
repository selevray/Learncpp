std::basic_streambuf<CharT,Traits>::sungetc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

int_type sungetc();

Si une position de remise en arrière est disponible dans la zone de lecture (gptr() > eback()), alors décrémente le pointeur next (gptr()) et renvoie le caractère vers lequel il pointe désormais.

Si aucune position de remise en arrière n'est disponible, alors appelle pbackfail() pour reculer dans la séquence d'entrée si possible.

La fonction de flux d'entrée-sortie basic_istream::unget est implémentée à l'aide de cette fonction.

Paramètres

(aucune)

Valeur de retour

Si une position de retour était disponible, retourne le caractère que pointe désormais le pointeur suivant, converti en int_type avec Traits::to_int_type(*gptr()). La prochaine lecture d'un seul caractère depuis ce streambuf retournera ce caractère.

Si aucune position de retour n'était disponible, retourne ce que pbackfail() retourne, soit Traits::eof() en cas d'échec.

Exemple

#include <iostream>
#include <sstream>

int main()
{
    std::stringstream s("abcdef"); // gptr() pointe sur 'a'
    char c1 = s.get(); // c = 'a', gptr() pointe maintenant sur 'b'
    char c2 = s.rdbuf()->sungetc(); // identique à s.unget() : gptr() pointe de nouveau sur 'a'
    char c3 = s.get(); // c3 = 'a', gptr() pointe maintenant sur 'b'
    char c4 = s.get(); // c4 = 'b', gptr() pointe maintenant sur 'c'
    std::cout << c1 << c2 << c3 << c4 << '\n';

    s.rdbuf()->sungetc();  // retour à 'b'
    s.rdbuf()->sungetc();  // retour à 'a'
    int eof = s.rdbuf()->sungetc();  // rien à remettre : pbackfail() échoue
    if (eof == EOF)
            std::cout << "Nothing to unget after 'a'\n";
}

Output:

aaab
Nothing to unget after 'a'
