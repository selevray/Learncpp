std::basic_streambuf<CharT,Traits>::overflow

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
virtual int_type overflow( int_type ch = Traits::eof() );

Garantit qu'il existe de la place dans la zone d'écriture (put area) pour au moins un caractère, en sauvegardant une sous-séquence initiale de caractères commençant à pbase() vers la séquence de sortie et en mettant à jour les pointeurs de la zone d'écriture (si nécessaire). Si ch n'est pas Traits::eof() (c.-à-d. Traits::eq_int_type(ch, Traits::eof()) != true), il est soit placé dans la zone d'écriture, soit directement sauvegardé dans la séquence de sortie.

La fonction peut mettre à jour les pointeurs pptr, epptr et pbase pour définir l'emplacement où écrire davantage de données. En cas d'échec, la fonction garantit que soit pptr() == nullptr, soit pptr() == epptr.

La version de la classe de base de la fonction ne fait rien. Les classes dérivées peuvent redéfinir cette fonction pour permettre des mises à jour de la zone d'écriture en cas d'épuisement.

Paramètres

  • ch — le caractère à stocker dans la zone d'écriture

Valeur de retour

Renvoie une valeur non spécifiée, différente de Traits::eof(), en cas de succès, Traits::eof() en cas d'échec.

La version de la classe de base de la fonction renvoie Traits::eof().

Note

Les sputc() et sputn() appellent cette fonction en cas de débordement (pptr() == nullptr ou pptr() >= epptr()).

Exemple

#include <array>
#include <cstddef>
#include <iostream>

// Tampon pour std::ostream implémenté par std::array
template<std::size_t size, class CharT = char>
struct ArrayedStreamBuffer : std::basic_streambuf<CharT>
{
    using Base = std::basic_streambuf<CharT>;
    using char_type = typename Base::char_type;
    using int_type = typename Base::int_type;

    ArrayedStreamBuffer()
    {
        // pointeurs de la zone d'écriture travaillant avec 'buffer'
        Base::setp(buffer.data(), buffer.data() + size);
    }

    int_type overflow(int_type ch)
    {
        std::cout << "overflow\n";
        return Base::overflow(ch);
    }

    void print_buffer()
    {
        for (char_type i : buffer)
        {
            if (i == 0)
                std::cout << "\\0";
            else
                std::cout << i;
            std::cout << ' ';
        }
        std::cout << '\n';
    }

private:
    std::array<char_type, size> buffer{}; // initialise par valeur buffer
};

int main()
{
    ArrayedStreamBuffer<10> streambuf;
    std::ostream stream(&streambuf);

    stream << "hello";
    streambuf.print_buffer();
    if (stream.good())
        std::cout << "stream is good\n";

    stream << "world";
    streambuf.print_buffer();
    if (stream.good())
        std::cout << "stream is good\n";

    stream << "!";
    streambuf.print_buffer();
    if (!stream.good())
        std::cout << "stream is not good\n";
}

Output:

h e l l o \0 \0 \0 \0 \0
stream is good
h e l l o w o r l d
stream is good
overflow
h e l l o w o r l d
stream is not good
