std::strstream::pcount

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

int pcount() const;  // (obsolète en C++98) (supprimé en C++26)

Renvoie le nombre de caractères qui ont été écrits dans la zone de mise de std::strstreambuf associé. Appelle effectivement rdbuf()->pcount().

Paramètres

(aucune)

Valeur de retour

Le nombre de caractères dans la zone de mise, ou zéro si rien n'a été écrit.

Exemple

#include <iostream>
#include <strstream>

int main()
{
    std::strstream dyn; // tampon de sortie alloué dynamiquement
    dyn << "Test: " << 1.23 << std::ends;
    std::cout << "The size of the output is " << dyn.pcount()
              << " and it holds \"" << dyn.str() << "\"\n";
    dyn.freeze(false);

    char buf[10];
    std::strstream user(buf, 10); // tampon de sortie fourni par l'utilisateur
    user << 1.23; // remarque : pas de std::ends
    std::cout.write(buf, user.pcount());
    std::cout << '\n';
}

Output:

The size of the output is 11 and it holds "Test: 1.23"
1.23
