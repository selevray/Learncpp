std::strstream::~strstream

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

virtual ~strstream();  // (obsolète en C++98) (supprimé en C++26)

Détruit un objet std::strstream, ce qui détruit aussi le membre std::strstreambuf, pouvant appeler la fonction de désallocation si le tampon sous-jacent a été alloué dynamiquement et n'est pas gelé.

Paramètres

(aucune)

Notes

Si str() a été appelé sur un strstream dynamique et que freeze(false) n'a pas été appelé après, ce destructeur provoque une fuite de mémoire.

Exemple

#include <iostream>
#include <strstream>

int main()
{
    {
        std::ostrstream s; // tampon dynamique
        s << 1.23 << std::ends;
        std::cout << s.str() << '\n';
        s.freeze(false);
    } // destructeur appelé, tampon désalloué

    {
        std::ostrstream s;
        s << 1.23 << std::ends;
        std::cout << s.str() << '\n';
//      buf.freeze(false);
    } // destructeur appelé, mémoire perdue

    {
        std::istrstream s("1.23"); // tampon constant
        double d;
        s >> d;
        std::cout << d << '\n';
    } // destructeur appelé, rien à désallouer
}

Output:

1.23
1.23
1.23
