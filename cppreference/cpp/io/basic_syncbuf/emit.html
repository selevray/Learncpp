std::basic_syncbuf<CharT,Traits,Allocator>::emit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool emit();

Transmet atomiquement toute la sortie en attente vers le flux enveloppé.

Tous les appels à emit() transférant des caractères vers le même objet de tampon de flux enveloppé semblent s'exécuter dans un ordre total, où chaque appel à emit() se synchronise avec les appels emit() suivants dans cet ordre total, même si ces appels sont effectués via différentes instances de std::basic_syncbuf/std::basic_osyncstream. En pratique, cela signifie que emit() prend un verrou associé de manière unique à l'objet de flux enveloppé : par exemple, il pourrait être conservé dans une table de hachage statique où l'adresse du flux enveloppé sert de clé.

Si un appel à sync a été effectué depuis le dernier appel à emit(), alors il vide également le flux enveloppé en appelant pubsync() sur celui-ci.

Paramètres

(aucune)

Valeur de retour

true si toutes les conditions suivantes sont vraies :

  • il existe un flux enveloppé (le pointeur de streambuf enveloppé n'est pas nul)
  • tous les caractères du stockage temporaire ont été envoyés avec succès dans le flux enveloppé
  • l'appel à pubsync(), s'il a été demandé, s'est également terminé avec succès.

Renvoie false dans le cas contraire.

Notes

Normalement appelé par le destructeur ou l'affectation par déplacement du std::basic_osyncstream propriétaire, ou par std::basic_osyncstream::emit.
