void set_emit_on_sync( bool b ) noexcept;

Modifie la politique emit-on-sync courante.

La valeur false (par défaut) indique que tout vidage est reporté jusqu'à un appel à emit.

La valeur true fait en sorte que les vidages soient appliqués immédiatement.

Paramètres

  • b — nouvelle valeur de la politique emit-on-sync
