std::cerr, std::wcerr

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iostream>

extern std::ostream cerr;  // (1)

extern std::wostream wcerr;  // (2)

Les objets globaux std::cerr et std::wcerr contrôlent la sortie vers un tampon de flux de type défini par l'implémentation (dérivé respectivement de std::streambuf et std::wstreambuf), associé au flux de sortie d'erreur standard C stderr.

Ces objets sont garantis d'être initialisés pendant ou avant la première fois qu'un objet de type std::ios_base::Init est construit, et sont disponibles pour utilisation dans les constructeurs et destructeurs d'objets statiques avec initialisation ordonnée (à condition que <iostream> soit inclus avant la définition de l'objet).

Sauf si std::ios_base::sync_with_stdio(false) a été émis, il est sûr d'accéder simultanément à ces objets depuis plusieurs threads, tant pour les sorties formatées que non formatées.

Une fois initialisés, (std::cerr.flags() & unitbuf) != 0 (idem pour std::wcerr), ce qui signifie que toute sortie envoyée à ces objets de flux est immédiatement vidée vers le système d'exploitation (via le destructeur de std::basic_ostream::sentry).

De plus, std::cerr.tie() retourne &std::cout (idem pour std::wcerr et std::wcout), ce qui signifie que toute opération de sortie sur std::cerr exécute d'abord std::cout.flush() (via le constructeur de std::basic_ostream::sentry).

Notes

Le « c » du nom fait référence à « character » (FAQ de stroustrup.com) ; cerr signifie « erreur de caractère (flux) » et wcerr signifie « erreur de caractère large (flux) ».

Exemple

La sortie vers stderr via std::cerr vide la sortie en attente sur std::cout, alors que la sortie vers stderr via std::clog ne le fait pas.

#include <chrono>
#include <iostream>
#include <thread>
using namespace std::chrono_literals;

void f()
{
    std::cout << "Output from thread...";
    std::this_thread::sleep_for(2s);
    std::cout << "...thread calls flush()" << std::endl;
}

int main()
{
    std::jthread t1{f};
    std::this_thread::sleep_for(1000ms);
    std::clog << "This output from main is not tie()'d to cout\n";
    std::cerr << "This output is tie()'d to cout\n";
}
