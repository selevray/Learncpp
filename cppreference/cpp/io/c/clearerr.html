std::clearerr

Défini dans l'en-tête <cstdio>

void clearerr( std::FILE* stream );

Réinitialise les indicateurs d'erreur et l'indicateur EOF pour le flux de fichier donné.

Paramètres

  • stream — le fichier dont les indicateurs d'erreur doivent être réinitialisés

Valeur de retour

(aucune)

Exemple

#include <cassert>
#include <cstdio>

int main()
{
    std::FILE* tmpf = std::tmpfile();
    std::fputs("cppreference.com\n", tmpf);
    std::rewind(tmpf);

    for (int ch; (ch = std::fgetc(tmpf)) != EOF; std::putchar(ch)) { }

    assert(std::feof(tmpf)); // la boucle doit normalement se terminer par EOF
    std::puts("End of file reached");

    std::clearerr(tmpf); // effacer EOF

    std::puts(std::feof(tmpf) ? "EOF indicator set"
                              : "EOF indicator cleared");
}

Output:

cppreference.com
End of file reached
EOF indicator cleared
