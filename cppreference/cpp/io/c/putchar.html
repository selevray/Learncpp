std::putchar

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdio>

int putchar( int ch );

Écrit le caractère ch vers stdout. En interne, le caractère est converti en unsigned char juste avant d'être écrit.

Équivalent à std::putc(ch, stdout).

Paramètres

  • ch — caractère à écrire

Valeur de retour

En cas de succès, renvoie le caractère écrit.

En cas d'échec, renvoie EOF et positionne l'indicateur error (voir std::ferror()) sur stdout.

Exemple

#include <cstdio>

int main()
{
    for (char c = 'a'; c != 'z'; ++c)
        std::putchar(c);

    // la valeur de retour de putchar n'est pas égale à l'argument
    int r = 0x1024;
    std::printf("\nr = 0x%x\n", r);
    r = std::putchar(r);
    std::printf("\nr = 0x%x\n", r);
}
