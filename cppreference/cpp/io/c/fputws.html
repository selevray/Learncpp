std::fputws

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cwchar>

int fputws( const wchar_t* str, std::FILE* stream );

Écrit chaque caractère large de la chaîne large terminée par un caractère nul str dans le flux de sortie stream, comme si on exécutait de façon répétée std::fputwc.

Le caractère large nul de fin de str n'est pas écrit.

Paramètres

  • str — chaîne large terminée par un caractère nul à écrire
  • stream — flux de sortie

Valeur de retour

En cas de succès, renvoie une valeur non négative

En cas d'échec, renvoie EOF et positionne l'indicateur error (voir std::ferror) sur stream.

Exemple

#include <clocale>
#include <cstdio>
#include <cwchar>

int main()
{
    std::setlocale(LC_ALL, "en_US.utf8");
    int rc = std::fputws(L"御休みなさい", stdout);

    if (rc == EOF)
        std::perror("fputws()"); // POSIX exige que errno soit positionné
}
