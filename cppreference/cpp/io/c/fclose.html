std::fclose

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdio>

int fclose( std::FILE* stream );

Ferme le flux de fichier donné. Toutes les données tamponnées non écrites sont vidées vers le système d'exploitation. Toutes les données tamponnées non lues sont abandonnées.

Que l'opération réussisse ou non, le flux n'est plus associé à un fichier, et la mémoire tampon allouée par std::setbuf ou std::setvbuf, le cas échéant, est également dissociée et désallouée si une allocation automatique a été utilisée.

Le comportement est indéfini si la valeur du pointeur stream est utilisée après le retour de fclose.

Paramètres

  • stream — le flux de fichier à fermer

Valeur de retour

0 en cas de succès, EOF sinon.

Exemple

#include <cstdio>
#include <cstdlib>

int main()
{
    int is_ok = EXIT_FAILURE;
    FILE* fp = std::fopen("/tmp/test.txt", "w+");
    if (!fp)
    {
        std::perror("File opening failed");
        return is_ok;
    }

    int c; // Remarque : int, et non char, est nécessaire pour gérer EOF
    while ((c = std::fgetc(fp)) != EOF) // Boucle standard de lecture de fichier en C
        std::putchar(c);

    if (std::ferror(fp))
        std::puts("I/O error when reading");
    else if (std::feof(fp))
    {
        std::puts("End of file reached successfully");
        is_ok = EXIT_SUCCESS;
    }

    std::fclose(fp);
    return is_ok;
}

Output:

End of file reached successfully
