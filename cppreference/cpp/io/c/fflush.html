std::fflush

Défini dans l'en-tête <cstdio>

int fflush( std::FILE* stream );

Pour les flux de sortie (et pour les flux de mise à jour dont la dernière opération était une sortie), écrit toutes les données non écrites du tampon de stream vers le périphérique de sortie associé.

Pour les flux d'entrée (et pour les flux de mise à jour dont la dernière opération était une entrée), le comportement est indéfini.

Si stream est un pointeur nul, tous les flux de sortie ouverts sont vidés, y compris ceux manipulés au sein de bibliothèques ou non directement accessibles au programme.

Paramètres

  • stream — le flux de fichier à vider

Valeur de retour

Renvoie zéro en cas de succès. Sinon, EOF est renvoyé et l'indicateur d'erreur du flux de fichier est positionné.

Notes

POSIX étend la spécification de fflush en définissant ses effets sur un flux d'entrée, tant que ce flux représente un fichier ou un autre périphérique à accès direct : dans ce cas, le pointeur de fichier POSIX est repositionné pour correspondre au pointeur du flux C (ce qui annule effectivement toute mise en tampon de lecture), et les effets de tout std::ungetc ou std::ungetwc qui n'ont pas encore été relus depuis le flux sont abandonnés.

Microsoft étend également la spécification de fflush en définissant ses effets sur un flux d'entrée : dans Visual Studio 2013 et antérieurs, elle abandonnait le tampon d'entrée ; dans Visual Studio 2015 et versions ultérieures, elle n'a aucun effet, les tampons sont conservés.
