std::fgets

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdio>

char* fgets( char* str, int count, std::FILE* stream );

Lit au plus count - 1 caractères depuis le flux de fichier donné et les stocke dans le tableau de caractères pointé par str. L'analyse s'arrête si un caractère de fin de ligne est rencontré, auquel cas str contiendra ce caractère de fin de ligne, ou si la fin de fichier survient. Si des octets sont lus et qu'aucune erreur ne survient, écrit un caractère nul à la position immédiatement après le dernier caractère écrit dans str.

Paramètres

  • str — pointeur vers un élément d'un tableau de char
  • count — nombre maximal de caractères à écrire (généralement la longueur de str)
  • stream — flux de fichier duquel lire les données

Valeur de retour

str en cas de succès, pointeur nul en cas d'échec.

Si la condition de fin de fichier est rencontrée, positionne l'indicateur eof sur stream (voir std::feof()). Ce n'est un échec que si aucun octet n'a été lu ; dans ce cas, un pointeur nul est renvoyé et le contenu du tableau pointé par str n'est pas modifié (c'est-à-dire que le premier octet n'est pas écrasé par un caractère nul).

Si l'échec a été causé par une autre erreur, positionne l'indicateur error (voir std::ferror()) sur stream. Le contenu du tableau pointé par str est indéterminé (il peut même ne pas être terminé par un caractère nul).

Notes

POSIX exige en outre que fgets positionne errno s'il rencontre un échec autre que la condition de fin de fichier.

Bien que la spécification de la norme soit peu claire dans les cas où count <= 1, les implémentations courantes font

  • si count < 1, ne rien faire, signaler une erreur,
  • if count == 1,
    • certaines implémentations ne font rien, signalent une erreur,
    • d'autres ne lisent rien, stockent zéro dans str[0], signalent un succès.

Exemple

#include <cstdio>
#include <cstdlib>
#include <iomanip>
#include <iostream>
#include <span>

void dump(std::span<const char> buf, std::size_t offset)
{
    std::cout << std::dec;
    for (char ch : buf)
        std::cout << (ch >= ' ' ? ch : '.'), offset--;
    std::cout << std::string(offset, ' ') << std::hex
              << std::setfill('0') << std::uppercase;
    for (unsigned ch : buf)
        std::cout << std::setw(2) << ch << ' ';
    std::cout << std::dec << '\n';
}

int main()
{
    std::FILE* tmpf = std::tmpfile();
    std::fputs("Alan Turing\n", tmpf);
    std::fputs("John von Neumann\n", tmpf);
    std::fputs("Alonzo Church\n", tmpf);

    std::rewind(tmpf);
    for (char buf[8]; std::fgets(buf, sizeof buf, tmpf) != nullptr;)
        dump(buf, 10);
}
