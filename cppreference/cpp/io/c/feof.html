std::feof

Défini dans l'en-tête <cstdio>

int feof( std::FILE* stream );

Vérifie si la fin du flux de fichier donné a été atteinte.

Paramètres

  • stream — le flux de fichier à vérifier

Valeur de retour

Valeur non nulle si la fin du flux a été atteinte, 0 sinon.

Notes

Cette fonction ne rapporte que l'état du flux tel que signalé par la dernière opération d'E/S ; elle n'examine pas la source de données associée. Par exemple, si la dernière E/S était un std::fgetc ayant renvoyé le dernier octet d'un fichier, std::feof renvoie zéro. Le std::fgetc suivant échoue et fait passer l'état du flux à fin de fichier. Ce n'est qu'alors que std::feof renvoie une valeur non nulle.

Dans un usage courant, le traitement d'un flux d'entrée s'arrête à la moindre erreur ; feof et std::ferror servent alors à distinguer les différentes conditions d'erreur.

Exemple

#include <cstdio>
#include <cstdlib>

int main()
{
    int is_ok = EXIT_FAILURE;
    FILE* fp = std::fopen("/tmp/test.txt", "w+");
    if (!fp)
    {
        std::perror("File opening failed");
        return is_ok;
    }

    int c; // Remarque : int, et non char, est nécessaire pour gérer EOF
    while ((c = std::fgetc(fp)) != EOF) // Boucle standard de lecture de fichier en C
        std::putchar(c);

    if (std::ferror(fp))
        std::puts("I/O error when reading");
    else if (std::feof(fp))
    {
        std::puts("End of file reached successfully");
        is_ok = EXIT_SUCCESS;
    }

    std::fclose(fp);
    return is_ok;
}

Output:

End of file reached successfully
