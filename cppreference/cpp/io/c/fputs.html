std::fputs

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdio>

int fputs( const char* str, std::FILE* stream );

Écrit chaque caractère de la chaîne terminée par un caractère nul str dans le flux de sortie stream, comme si l'on exécutait répétitivement std::fputc.

Le caractère nul de fin de str n'est pas écrit.

Paramètres

  • str — chaîne de caractères terminée par un caractère nul à écrire
  • stream — flux de sortie

Valeur de retour

En cas de succès, renvoie une valeur non négative

En cas d'échec, renvoie EOF et positionne l'indicateur error (voir std::ferror) sur stream.

Notes

La fonction associée std::puts ajoute un caractère de saut de ligne à la sortie, tandis que std::fputs écrit la chaîne sans modification.

Les différentes implémentations renvoient des nombres non négatifs différents : certaines renvoient le dernier caractère écrit, certaines renvoient le nombre de caractères écrits (ou INT_MAX si la chaîne était plus longue que cela), d'autres renvoient simplement une constante non négative, telle que zéro.

Exemple

#include <cstdio>

int main(void)
{
    int rc = std::fputs("Hello World", stdout);

    if (rc == EOF)
        std::perror("fputs()"); // POSIX exige que errno soit positionné
}

Output:

Hello World
