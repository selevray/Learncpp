std::freopen

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdio>

std::FILE* freopen( const char* filename, const char* mode, std::FILE* stream );

Tout d'abord, tente de fermer le fichier associé à stream, en ignorant toute erreur. Puis, si filename n'est pas nul, tente d'ouvrir le fichier spécifié par filename en utilisant mode comme si par std::fopen, et associe ce fichier au flux de fichier pointé par stream. Si filename est un pointeur nul, alors la fonction tente de rouvrir le fichier déjà associé à stream (il est défini par l'implémentation quels changements de mode sont autorisés dans ce cas).

Paramètres

  • filename — nom du fichier auquel associer le flux de fichier
  • mode — chaîne de caractères terminée par un caractère nul déterminant le nouveau mode d'accès au fichier
  • stream — le flux de fichier à modifier

Indicateurs d'accès au fichier

Chaîne de mode d'accès au fichier | Signification | Explication | Action si le fichier
existe déjà | Action si le fichier
n'existe pas

"r" | read | Ouvrir un fichier en lecture | lecture depuis le début | renvoyer NULL et positionner l'erreur

"w" | write | Créer un fichier en écriture | détruire le contenu | créer un nouveau

"a" | append | Ajouter à un fichier | écriture à la fin | créer un nouveau

"r+" | lecture étendue | Ouvrir un fichier en lecture/écriture | lecture depuis le début | renvoyer NULL et positionner l'erreur

"w+" | écriture étendue | Créer un fichier en lecture/écriture | détruire le contenu | créer un nouveau

"a+" | ajout étendu | Ouvrir un fichier en lecture/écriture | écriture à la fin | créer un nouveau

L'indicateur de mode d'accès au fichier "b" peut facultativement être spécifié pour ouvrir un fichier en mode binaire. Cet indicateur n'a aucun effet sur les systèmes POSIX, mais sous Windows, par exemple, il désactive le traitement spécial de '\n' et '\x1A'.
Pour les modes d'accès en ajout, les données sont écrites à la fin du fichier, quelle que soit la position courante de l'indicateur de position du fichier.

L'indicateur de mode d'accès au fichier "x" peut facultativement être ajouté aux spécificateurs "w" ou "w+". Cet indicateur force la fonction à échouer si le fichier existe, au lieu de l'écraser. (depuis C++17)

Le comportement est indéfini si le mode n'est pas l'une des chaînes énumérées ci-dessus. Certaines implémentations définissent des modes supplémentaires (par exemple Windows).

Valeur de retour

stream en cas de succès, un pointeur nul en cas d'échec.

Notes

std::freopen est le seul moyen de modifier l'orientation étroite/large d'un flux une fois établie par une opération d'E/S ou par std::fwide.

La version CRT de Microsoft de std::freopen ne prend en charge aucun changement de mode lorsque filename est un pointeur nul et la traite comme une erreur (voir documentation). Une solution de contournement possible est la fonction non standard _setmode().

Exemple

Le code suivant redirige stdout vers un fichier.

#include <cstdio>

int main()
{
    std::printf("stdout is printed to console\n");
    if (std::freopen("redir.txt", "w", stdout))
    {
        std::printf("stdout is redirected to a file\n"); // ceci est écrit dans redir.txt
        std::fclose(stdout);
    }
}

Output:

stdout is printed to console
