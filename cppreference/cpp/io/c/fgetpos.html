int fgetpos( std::FILE* stream, std::fpos_t* pos );

Obtient l'indicateur de position dans le fichier et l'état d'analyse courant (le cas échéant) pour le flux de fichier stream et les stocke dans l'objet pointé par pos. La valeur stockée n'a de sens que comme entrée de std::fsetpos.

Paramètres

  • stream — flux de fichier à examiner
  • pos — pointeur vers un objet fpos_t où stocker l'indicateur de position dans le fichier

Valeur de retour

0 en cas de succès, valeur non nulle sinon. Positionne aussi errno en cas d'échec.
