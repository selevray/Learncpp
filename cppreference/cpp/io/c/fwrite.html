std::fwrite

Défini dans l'en-tête <cstdio>

std::size_t fwrite( const void* buffer, std::size_t size, std::size_t count, std::FILE* stream );

Écrit jusqu'à count objets binaires du tableau donné buffer dans le flux de sortie stream. Les objets sont écrits comme si chaque objet était réinterprété comme un tableau de unsigned char, et std::fputc est appelée size fois pour chaque objet afin d'écrire ces unsigned char dans stream, dans l'ordre. L'indicateur de position dans le fichier du flux est avancé du nombre de caractères écrits.

Si les objets ne sont pas TriviallyCopyable, le comportement est indéfini.

En cas d'erreur, la valeur résultante de l'indicateur de position dans le fichier du flux est indéterminée.

Paramètres

  • buffer — pointeur vers le premier objet du tableau à écrire
  • size — taille de chaque objet
  • count — nombre d'objets à écrire
  • stream — flux de fichier de sortie dans lequel écrire

Valeur de retour

Nombre d'objets écrits avec succès, qui peut être inférieur à count en cas d'erreur.

Si size ou count est nul, fwrite renvoie zéro et n'effectue aucune autre action.

Exemple

#include <array>
#include <cstdio>
#include <vector>

int main ()
{
    // écrit le tampon dans le fichier
    if (std::FILE* f1 = std::fopen("file.bin", "wb"))
    {
        std::array<int, 3> v = {42, -1, 7}; // le stockage sous-jacent de std::array est un tableau
        std::fwrite(v.data(), sizeof v[0], v.size(), f1);
        std::fclose(f1);
    }

    // relit les mêmes données et les affiche sur la sortie standard
    if (std::FILE* f2 = std::fopen("file.bin", "rb"))
    {
        std::vector<int> rbuf(10); // le stockage sous-jacent de std::vector est également un tableau
        std::size_t sz = std::fread(rbuf.data(), sizeof rbuf[0], rbuf.size(), f2);
        std::fclose(f2);
        for (std::size_t n = 0; n < sz; ++n)
            std::printf("%d\n", rbuf[n]);
    }
}

Output:

42
-1
7
