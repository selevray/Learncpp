std::perror

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdio>

void perror( const char *s );

Affiche une description textuelle du code d'erreur actuellement stocké dans la variable système errno vers stderr.

La description est formée par la concaténation des composantes suivantes :

  • le contenu de la chaîne d'octets terminée par un caractère nul pointée par s, suivi de ": " (sauf si s est un pointeur nul ou si le caractère pointé par s est le caractère nul).
  • chaîne de message d'erreur définie par l'implémentation décrivant le code d'erreur stocké dans errno, suivie de '\n'. Cette chaîne de message d'erreur est identique au résultat de std::strerror(errno).

Paramètres

  • s — pointeur vers une chaîne terminée par un caractère nul contenant un message explicatif

Valeur de retour

(aucune)

Exemple

#include <cerrno>
#include <cmath>
#include <cstdio>

int main()
{
    double not_a_number = std::log(-1.0);
    if (errno == EDOM)
        std::perror("log(-1) failed");
    std::printf("%f\n", not_a_number);
}

Sortie possible :

log(-1) failed: Numerical argument out of domain
nan
