std::fseek

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdio>

int fseek( std::FILE* stream, long offset, int origin );

Définit l'indicateur de position de fichier pour le flux de fichier stream.

Si le stream est ouvert en mode binaire, la nouvelle position est exactement offset octets mesurés depuis le début du fichier si origin vaut SEEK_SET, depuis la position courante du fichier si origin vaut SEEK_CUR, et depuis la fin du fichier si origin vaut SEEK_END. Les flux binaires ne sont pas tenus de prendre en charge SEEK_END, en particulier si des octets nuls supplémentaires sont écrits.

Si le stream est ouvert en mode texte, les seules valeurs prises en charge pour offset sont zéro (qui fonctionne avec tout origin) et une valeur renvoyée par un appel antérieur à std::ftell sur un flux associé au même fichier (qui ne fonctionne qu'avec origin de SEEK_SET).

Si le stream est orienté caractères larges, les restrictions des flux texte et binaire s'appliquent toutes deux (le résultat de std::ftell est autorisé avec SEEK_SET et un décalage nul est autorisé depuis SEEK_SET et SEEK_CUR, mais pas depuis SEEK_END).

En plus de modifier l'indicateur de position de fichier, fseek annule les effets de std::ungetc et efface l'état de fin de fichier, le cas échéant.

Si une erreur de lecture ou d'écriture survient, l'indicateur d'erreur du flux (std::ferror) est positionné et la position du fichier n'est pas modifiée.

Paramètres

  • stream — flux de fichier à modifier
  • offset — nombre de caractères dont la position doit être décalée par rapport à origin
  • origin — position à laquelle offset est ajouté. Elle peut prendre l'une des valeurs suivantes : SEEK_SET, SEEK_CUR, SEEK_END

Valeur de retour

0 en cas de succès, valeur non nulle sinon.

Notes

Après un positionnement vers une position autre que la fin dans un flux large, l'appel suivant à toute fonction de sortie peut rendre le reste du fichier indéfini, par exemple en écrivant une séquence multioctet de longueur différente.

POSIX autorise le positionnement au-delà de la fin de fichier existante. Si une sortie est effectuée après ce positionnement, toute lecture de la zone vide renverra zéro octet. Lorsque le système de fichiers le permet, cela crée un fichier épars.

POSIX exige également que fseek effectue d'abord fflush s'il existe des données non écrites (mais la restauration de l'état de décalage est défini par l'implémentation). Les flux de fichiers C++ standard garantissent à la fois le vidage et la restauration de l'état de décalage : std::basic_filebuf::seekoff.

POSIX précise que fseek doit renvoyer -1 en cas d'erreur, et affecter errno pour indiquer l'erreur.

Sous Windows, _fseeki64 peut être utilisé pour travailler avec des fichiers de plus de 2 Gio.

Exemple

#include <cassert>
#include <cstdio>
#include <cstdint>
#include <fstream>
#include <vector>

int main()
{
    std::ofstream("dummy.nfo") << "8 bytes\n"; // créer le fichier

    std::FILE* fp = std::fopen("dummy.nfo", "rb");
    assert(fp);

    std::fseek(fp, 0, SEEK_END); // se positionner à la fin
    const std::size_t filesize = std::ftell(fp);
    std::vector<std::uint8_t> buffer(filesize);

    std::fseek(fp, 0, SEEK_SET); // se positionner au début
    std::fread(buffer.data(), sizeof(std::uint8_t), buffer.size(), fp);

    std::fclose(fp);
    std::printf("I've read %zi bytes\n", filesize);
}
