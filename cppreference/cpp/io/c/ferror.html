std::ferror

Défini dans l'en-tête <cstdio>

int ferror( std::FILE* stream );

Vérifie si le flux donné présente des erreurs.

Paramètres

  • stream — le flux de fichier à vérifier

Valeur de retour

Valeur non nulle si des erreurs se sont produites sur le flux de fichier, 0 sinon.

Exemple

#include <clocale>
#include <cstdio>
#include <cstdlib>
#include <cwchar>

int main()
{
    const char *fname = std::tmpnam(nullptr);
    std::FILE* f = std::fopen(fname, "wb");
    std::fputs("\xff\xff\n", f); // séquence de caractères UTF-8 non valide
    std::fclose(f);

    std::setlocale(LC_ALL, "en_US.utf8");
    f = std::fopen(fname, "rb");
    std::wint_t ch;
    while ((ch=std::fgetwc(f)) != WEOF) // tentative de lecture en UTF-8
        std::printf("%#x ", ch);

    if (std::feof(f))
        puts("EOF indicator set");
    if (std::ferror(f))
        puts("Error indicator set");
}

Output:

Error indicator set
