std::fputc, std::putc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdio>

int fputc( int ch, std::FILE* stream );
int putc( int ch, std::FILE* stream );

Écrit un caractère ch dans le flux de sortie donné stream.

En interne, le caractère est converti en unsigned char juste avant d'être écrit.

En C, putc() peut être implémentée comme une macro, ce qui est interdit en C++. Par conséquent, les appels à std::fputc() et std::putc() ont toujours le même effet.

Paramètres

  • ch — caractère à écrire
  • stream — flux de sortie

Valeur de retour

En cas de succès, renvoie le caractère écrit.

En cas d'échec, renvoie EOF et positionne l'indicateur error (voir std::ferror()) sur stream.

Exemple

#include <cstdio>

int main()
{
    for (char c = 'a'; c != 'z'; c++)
        std::putc(c, stdout);

    // la valeur de retour de putchar n'est pas égale à l'argument
    int r = 0x102A;
    std::printf("\nr = 0x%x\n", r);

    r = std::putchar(r);
    std::printf("\nr = 0x%x\n", r);
}

Sortie possible :

abcdefghijklmnopqrstuvwxy
r = 0x102A
*
r = 0x2A
