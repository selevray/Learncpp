std::setbuf

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdio>

void setbuf( std::FILE* stream, char* buffer );

Définit le tampon interne à utiliser pour les opérations d'E/S effectuées sur le flux C stream.

Si buffer n'est pas nul, équivalent à std::setvbuf(stream, buffer, _IOFBF, BUFSIZ).

Si buffer est nul, équivalent à std::setvbuf(stream, nullptr, _IONBF, 0), ce qui désactive la mise en tampon.

Paramètres

  • stream — le flux de fichier dont le tampon doit être défini
  • buffer — pointeur vers un tampon à utiliser par le flux. Si un pointeur nul est fourni, la mise en tampon est désactivée. S'il n'est pas nul, doit pouvoir contenir au moins BUFSIZ caractères

Valeur de retour

(aucune)

Notes

Si BUFSIZ n'est pas la taille de tampon appropriée, std::setvbuf peut être utilisée pour la modifier.

std::setvbuf doit également être utilisée pour détecter les erreurs, car std::setbuf n'indique ni succès ni échec.

Cette fonction ne peut être utilisée qu'après que stream a été associé à un fichier ouvert, mais avant toute autre opération (autre qu'un appel échoué à std::setbuf/std::setvbuf).

Une erreur courante consiste à définir le tampon de stdin ou stdout sur un tableau dont la durée de vie se termine avant la fin du programme :

int main()
{
    char buf[BUFSIZ];
    std::setbuf(stdin, buf);
} // la durée de vie de buf se termine, comportement indéfini

Exemple

std::setbuf peut être utilisée pour désactiver la mise en tampon des flux nécessitant une sortie immédiate.

#include <chrono>
#include <cstdio>
#include <thread>

int main()
{
    using namespace std::chrono_literals;

    std::setbuf(stdout, nullptr); // stdout sans tampon
    std::putchar('a'); // apparaît immédiatement sur un flux sans tampon
    std::this_thread::sleep_for(1s);
    std::putchar('b');
}

Output:

ab
