std::fread

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdio>

std::size_t fread( void* buffer, std::size_t size, std::size_t count, std::FILE* stream );

Lit jusqu'à count objets dans le tableau buffer depuis le flux d'entrée donné stream, comme si on appelait std::fgetc size fois pour chaque objet, et stocke les résultats, dans l'ordre obtenu, aux positions successives de buffer, qui est réinterprété comme un tableau de unsigned char. L'indicateur de position dans le fichier du flux est avancé du nombre de caractères lus.

Si les objets ne sont pas TriviallyCopyable, le comportement est indéfini.

Si une erreur se produit, la valeur résultante de l'indicateur de position dans le fichier du flux est indéterminée. Si un élément partiel est lu, sa valeur est indéterminée.

Paramètres

  • buffer — pointeur vers le premier objet du tableau à lire
  • size — taille de chaque objet en octets
  • count — nombre d'objets à lire
  • stream — flux de fichier d'entrée depuis lequel lire

Valeur de retour

Nombre d'objets lus avec succès, qui peut être inférieur à count si une erreur ou une condition de fin de fichier se produit.

Si size ou count est nul, fread renvoie zéro et n'effectue aucune autre action.

fread ne distingue pas la fin de fichier d'une erreur, et l'appelant doit utiliser std::feof et std::ferror pour déterminer laquelle s'est produite.

Exemple

#include <cstddef>
#include <cstdio>
#include <fstream>
#include <iomanip>
#include <iostream>
#include <vector>

int main()
{
    // Préparer le fichier
    std::ofstream("test.txt") << 1 << ' ' << 2 << '\n';
    std::FILE* f = std::fopen("test.txt", "r");

    std::vector<char> buf(4); // char est trivialement copiable
    const std::size_t n = std::fread(&buf[0], sizeof buf[0], buf.size(), f);

    std::cout << "Read " << n << " object" << (n > 1 ? "s" : "") << ": "
              << std::hex << std::uppercase << std::setfill('0');
    for (char n : buf)
        std::cout << "0x" << std::setw(2) << static_cast<short>(n) << ' ';
    std::cout << '\n';

    std::vector<std::string> buf2; // string n'est pas trivialement copiable
//  Cela entraînerait un comportement indéfini :
//  std::fread(&buf2[0], sizeof buf2[0], buf2.size(), f);
}
