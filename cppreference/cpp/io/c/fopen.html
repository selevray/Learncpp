std::fopen

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdio>

std::FILE* fopen( const char* filename, const char* mode );

Ouvre le fichier indiqué par filename et renvoie un flux de fichier associé à ce fichier. mode est utilisé pour déterminer le mode d'accès au fichier.

Paramètres

  • filename — nom du fichier auquel associer le flux de fichier
  • mode — chaîne de caractères terminée par un caractère nul déterminant le mode d'accès au fichier

Indicateurs d'accès au fichier

Chaîne de mode d'accès au fichier | Signification | Explication | Action si le fichier
existe déjà | Action si le fichier
n'existe pas

"r" | read | Ouvrir un fichier en lecture | lecture depuis le début | renvoyer NULL et positionner l'erreur

"w" | write | Créer un fichier en écriture | détruire le contenu | créer un nouveau

"a" | append | Ajouter à un fichier | écriture à la fin | créer un nouveau

"r+" | lecture étendue | Ouvrir un fichier en lecture/écriture | lecture depuis le début | renvoyer NULL et positionner l'erreur

"w+" | écriture étendue | Créer un fichier en lecture/écriture | détruire le contenu | créer un nouveau

"a+" | ajout étendu | Ouvrir un fichier en lecture/écriture | écriture à la fin | créer un nouveau

L'indicateur de mode d'accès au fichier "b" peut facultativement être spécifié pour ouvrir un fichier en mode binaire. Cet indicateur n'a aucun effet sur les systèmes POSIX, mais sous Windows, par exemple, il désactive le traitement spécial de '\n' et '\x1A'.
Pour les modes d'accès en ajout, les données sont écrites à la fin du fichier, quelle que soit la position courante de l'indicateur de position du fichier.

L'indicateur de mode d'accès au fichier "x" peut facultativement être ajouté aux spécificateurs "w" ou "w+". Cet indicateur force la fonction à échouer si le fichier existe, au lieu de l'écraser. (depuis C++17)

Le comportement est indéfini si le mode n'est pas l'une des chaînes énumérées ci-dessus. Certaines implémentations définissent des modes supplémentaires (par exemple Windows).

Valeur de retour

En cas de succès, renvoie un pointeur vers l'objet qui contrôle le flux de fichier ouvert, avec les bits eof et error effacés. Le flux est entièrement tamponné, sauf si filename désigne un périphérique interactif.

En cas d'erreur, renvoie un pointeur nul. POSIX exige que errno soit positionné dans ce cas.

Notes

Le format de filename est défini par l'implémentation et ne désigne pas nécessairement un fichier (par exemple, il peut s'agir de la console ou d'un autre périphérique accessible via l'API du système de fichiers). Sur les plateformes qui le permettent, filename peut inclure un chemin absolu ou relatif du système de fichiers.

Pour la désignation portable des répertoires et fichiers, voir la bibliothèque de système de fichiers C++ ou boost.filesystem.

Exemple

#include <cstdio>
#include <cstdlib>

int main()
{
    int is_ok = EXIT_FAILURE;
    FILE* fp = std::fopen("/tmp/test.txt", "w+");
    if (!fp)
    {
        std::perror("File opening failed");
        return is_ok;
    }

    int c; // Remarque : int, et non char, est nécessaire pour gérer EOF
    while ((c = std::fgetc(fp)) != EOF) // Boucle standard de lecture de fichier en C
        std::putchar(c);

    if (std::ferror(fp))
        std::puts("I/O error when reading");
    else if (std::feof(fp))
    {
        std::puts("End of file reached successfully");
        is_ok = EXIT_SUCCESS;
    }

    std::fclose(fp);
    return is_ok;
}

Output:

End of file reached successfully
