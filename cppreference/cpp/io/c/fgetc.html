std::fgetc, std::getc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdio>

int fgetc( std::FILE* stream );
int getc( std::FILE* stream );

Lit le caractère suivant depuis le flux d'entrée donné.

Paramètres

  • stream — le flux duquel lire le caractère

Valeur de retour

Le caractère obtenu en cas de succès, ou EOF en cas d'échec.

Si l'échec est dû à une condition de fin de fichier, positionne en plus l'indicateur eof (voir std::feof()) sur stream. Si l'échec est dû à une autre erreur, positionne l'indicateur error (voir std::ferror()) sur stream.

Exemple

#include <cstdio>
#include <cstdlib>

int main()
{
    int is_ok = EXIT_FAILURE;
    FILE* fp = std::fopen("/tmp/test.txt", "w+");
    if (!fp)
    {
        std::perror("File opening failed");
        return is_ok;
    }

    int c; // Remarque : int, et non char, est nécessaire pour gérer EOF
    while ((c = std::fgetc(fp)) != EOF) // Boucle standard de lecture de fichier en C
        std::putchar(c);

    if (std::ferror(fp))
        std::puts("I/O error when reading");
    else if (std::feof(fp))
    {
        std::puts("End of file reached successfully");
        is_ok = EXIT_SUCCESS;
    }

    std::fclose(fp);
    return is_ok;
}

Output:

End of file reached successfully
