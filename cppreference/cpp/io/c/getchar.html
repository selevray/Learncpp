std::getchar

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdio>

int getchar();

Lit le caractère suivant depuis stdin.

Équivalent à std::getc(stdin).

Paramètres

(aucune)

Valeur de retour

Le caractère obtenu en cas de succès, ou EOF en cas d'échec.

Si l'échec est dû à une condition de fin de fichier, positionne en plus l'indicateur eof (voir std::feof()) sur stdin. Si l'échec est dû à une autre erreur, positionne l'indicateur error (voir std::ferror()) sur stdin.

Exemple

std::getchar avec vérification des erreurs. Quitte le programme en saisissant le caractère ESC.

#include <cctype>
#include <cstdio>
#include <cstdlib>
#include <iomanip>
#include <iostream>

int main()
{
    for (int ch; (ch = std::getchar()) != EOF ;) // lit/affiche "abc" depuis stdin
    {
        if (std::isprint(ch))
            std::cout << static_cast<char>(ch) << '\n';
        if (ch == 27) // 'ESC' (escape) en ASCII
            return EXIT_SUCCESS;
    }

    // Teste la raison de l'atteinte de la fin de fichier.
    if (std::feof(stdin)) // si l'échec est causé par une condition de fin de fichier
        std::cout << "End of file reached\n";
    else if (std::ferror(stdin)) // si l'échec est causé par une autre erreur
    {
        std::perror("getchar()");
        std::cerr << "getchar() failed in file " << std::quoted(__FILE__)
                  << " at line # " << __LINE__ - 14 << '\n';
        std::exit(EXIT_FAILURE);
    }

    return EXIT_SUCCESS;
}
