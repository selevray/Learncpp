std::fpos_t

Défini dans l'en-tête <cstdio>

typedef /* défini par l'implémentation */ fpos_t;

std::fpos_t est un type d'objet complet non tableau, pouvant servir à stocker (par std::fgetpos) et restaurer (par std::fsetpos) la position et l'état de l'analyseur multioctet (le cas échéant) d'un flux C.

L'état de l'analyseur multioctet d'un flux C orienté caractères larges est représenté par un objet std::mbstate_t, dont la valeur est stockée dans une partie de la valeur d'un objet std::fpos_t par std::fgetpos.

Voir aussi

  • fsetpos — déplace l'indicateur de position dans le fichier vers un emplacement précis d'un fichier (fonction)
  • mbstate_t — informations d'état de conversion nécessaires pour parcourir les chaînes de caractères multioctets (classe)
  • fpos — représente une position absolue dans un flux ou un fichier (modèle de classe)
