std::fputwc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cwchar>

std::wint_t fputwc( wchar_t ch, std::FILE* stream );  // (1)

std::wint_t putwc( wchar_t ch, std::FILE* stream );  // (2)

Écrit un caractère large ch dans le flux de sortie donné stream.

  1. Peut être implémentée comme une macro et peut évaluer stream plus d'une fois.

Paramètres

  • ch — caractère large à écrire
  • stream — le flux de sortie

Valeur de retour

ch en cas de succès, WEOF en cas d'échec. Si une erreur d'encodage se produit, errno est défini à EILSEQ.

Exemple

#include <cerrno>
#include <clocale>
#include <cstdio>
#include <cstdlib>
#include <cwchar>
#include <initializer_list>

int main()
{
    std::setlocale(LC_ALL, "en_US.utf8");

    for (const wchar_t ch :
    {
        L'\u2200', // Nom Unicode : "FOR ALL"
        L'\n',
        L'∀',
    })
    {
        if (errno = 0; std::fputwc(ch, stdout) == WEOF)
        {
            std::puts(errno == EILSEQ
                ? "Encoding error in fputwc"
                : "I/O error in fputwc"
            );
            return EXIT_FAILURE;
        }
    }
    return EXIT_SUCCESS;
}
