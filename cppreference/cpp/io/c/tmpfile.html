std::tmpfile

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdio>

std::FILE* tmpfile();

Crée et ouvre un fichier temporaire portant un nom unique généré automatiquement.

Le fichier est ouvert en tant que fichier binaire en mise à jour (comme avec std::fopen avec le mode d'accès "wb+"). Au moins TMP_MAX fichiers peuvent être ouverts pendant la durée de vie d'un programme (cette limite peut être partagée avec std::tmpnam et peut être davantage limitée par FOPEN_MAX).

Si le programme ferme le fichier, par exemple en exécutant std::fclose, le fichier est automatiquement supprimé.

Si le programme se termine normalement (en appelant std::exit, en retournant de main, etc.), tous les fichiers ouverts en appelant std::tmpfile sont également supprimés automatiquement.

Si le programme se termine anormalement, il est défini par l'implémentation de savoir si ces fichiers temporaires sont supprimés.

Paramètres

(aucune)

Valeur de retour

Le flux de fichier associé, ou un pointeur nul si une erreur s'est produite.

Notes

Sur certaines implémentations (par exemple les anciens Linux), cette fonction crée, ouvre et supprime immédiatement le fichier du système de fichiers : tant qu'un descripteur de fichier ouvert vers un fichier supprimé est détenu par un programme, le fichier existe, mais comme il a été supprimé, son nom n'apparaît dans aucun répertoire, de sorte qu'aucun autre processus ne peut l'ouvrir. Une fois le descripteur de fichier fermé, ou une fois le programme terminé (normalement ou anormalement), l'espace occupé par le fichier est récupéré par le système de fichiers. Les Linux récents (depuis la version 3.11 ou ultérieure, selon le système de fichiers) créent ces fichiers temporaires invisibles en une seule étape, via un indicateur spécial de l'appel système open().

Sur certaines implémentations (par exemple Windows), des privilèges élevés sont requis, car la fonction peut créer le fichier temporaire dans un répertoire système.

Exemple

#include <cstdio>
#include <cstdlib>
#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;

int main()
{
    std::cout << "TMP_MAX = " << TMP_MAX << '\n'
              << "FOPEN_MAX = " << FOPEN_MAX << '\n';
    std::FILE* tmpf = std::tmpfile();
    std::fputs("Hello, world", tmpf);
    std::rewind(tmpf);
    char buf[6];
    std::fgets(buf, sizeof buf, tmpf);
    std::cout << buf << '\n';

    // Méthode propre à Linux pour afficher le nom du fichier tmpfile
    std::cout << fs::read_symlink(
                     fs::path("/proc/self/fd") / std::to_string(fileno(tmpf))
                 ) << '\n';
}
