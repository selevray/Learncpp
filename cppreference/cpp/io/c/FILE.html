std::FILE

Défini dans l'en-tête <cstdio>

typedef /* unspecified */ FILE;

Chaque objet std::FILE désigne un flux C.

La norme C (référencée par la norme C++) ne précise pas si std::FILE est un type d'objet complet. Bien qu'il soit possible de copier un std::FILE valide, utiliser un pointeur vers une telle copie comme argument d'une fonction d'E/S entraîne un comportement non spécifié. En d'autres termes, std::FILE peut être sémantiquement non copiable.

Les flux d'E/S peuvent être utilisés pour l'entrée et la sortie aussi bien non formatées que formatées. De plus, les fonctions qui gèrent l'entrée et la sortie peuvent aussi être sensibles aux paramètres régionaux (locale), de sorte que les conversions wide/multioctets sont effectuées si nécessaire.

État du flux

Outre les informations propres au système nécessaires pour accéder au périphérique (par exemple, un descripteur de fichier POSIX), chaque objet std::FILE contient directement ou indirectement les éléments suivants :

  1. Largeur de caractère : non définie, étroite ou large.
  2. État d'analyse pour les conversions entre caractères multioctets et caractères larges (un objet de type std::mbstate_t)
  3. État de la mémoire tampon : sans tampon, tamponné par ligne, entièrement tamponné.
  4. La mémoire tampon, qui peut être remplacée par une mémoire tampon externe fournie par l'utilisateur.
  5. Mode d'E/S : entrée, sortie ou mise à jour (à la fois entrée et sortie).
  6. Indicateur de mode binaire/texte.
  7. Indicateur d'état de fin de fichier.
  8. Indicateur d'état d'erreur.
  9. Indicateur de position dans le fichier, accessible sous la forme d'un objet de type std::fpos_t, qui, pour les flux larges, inclut l'état d'analyse.
  10. (depuis C++17) Verrou réentrant utilisé pour empêcher les courses de données lorsque plusieurs threads lisent, écrivent, positionnent ou interrogent la position d'un flux.

Orientation étroite et large

Un flux nouvellement ouvert n'a pas d'orientation. Le premier appel à std::fwide ou à une fonction d'E/S quelconque établit l'orientation : une fonction d'E/S large rend le flux orienté large ; une fonction d'E/S étroite rend le flux orienté étroit. Une fois définie, l'orientation ne peut être modifiée qu'avec std::freopen. Les fonctions d'E/S étroites ne peuvent pas être appelées sur un flux orienté large ; les fonctions d'E/S larges ne peuvent pas être appelées sur un flux orienté étroit. Les fonctions d'E/S larges convertissent entre caractères larges et multioctets comme si elles appelaient std::mbrtowc ou std::wcrtomb, avec l'état de conversion décrit par le flux. Contrairement aux chaînes de caractères multioctets valides dans un programme, les séquences de caractères multioctets dans le fichier peuvent contenir des caractères nuls intégrés et n'ont pas besoin de commencer ou de finir dans l'état de décalage initial.

L'état de conversion d'un flux orienté large est établi par la locale C installée au moment où l'orientation du flux est définie.

Modes binaire et texte

Un flux texte est une séquence ordonnée de caractères pouvant être organisée en lignes ; une ligne peut être décomposée en zéro caractère ou plus, suivis d'un caractère de fin de ligne '\n' (« newline »). Le fait que la dernière ligne doive se terminer par '\n' est défini par l'implémentation. De plus, des caractères peuvent devoir être ajoutés, modifiés ou supprimés en entrée et en sortie afin de respecter les conventions de représentation du texte du système d'exploitation (en particulier, sous Windows, les flux C convertissent '\n' en '\r\n' en sortie, et convertissent '\r\n' en '\n' en entrée).

Les données lues depuis un flux texte ne sont garanties égales aux données écrites précédemment dans ce flux que si chacune des conditions suivantes est vraie :

  • Les données ne se composent que de caractères imprimables et/ou des caractères de contrôle '\t' et '\n' (en particulier, sous Windows, le caractère '\0x1A' termine l'entrée).
  • Aucun caractère '\n' n'est immédiatement précédé de caractères d'espacement (ces espaces peuvent disparaître lorsque cette sortie est ensuite lue en entrée).
  • Le dernier caractère est '\n'.

Un flux binaire est une séquence ordonnée de caractères pouvant enregistrer de façon transparente des données internes. Les données lues depuis un flux binaire sont toujours égales aux données écrites précédemment dans ce flux, sauf qu'une implémentation peut ajouter un nombre indéterminé de caractères nuls à la fin du flux. Un flux binaire large n'a pas besoin de se terminer dans l'état de décalage initial.

Notes

POSIX exige explicitement que la facette LC_CTYPE de la locale C actuellement installée soit stockée dans l'objet FILE à l'instant où l'orientation du flux devient large ; POSIX exige que cette facette LC_CTYPE soit utilisée pour toutes les futures E/S sur ce flux jusqu'à ce que l'orientation soit modifiée, indépendamment de tout appel ultérieur à std::setlocale.

Il est prévu que chaque ligne de texte soit composée de données essentiellement lisibles par un humain. Les implémentations POSIX ne distinguent pas les flux texte et binaires (il n'existe aucune conversion particulière pour '\n' ni pour aucun autre caractère).
