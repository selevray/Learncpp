template< class... Args >
void println( std::ostream& os, std::format_string<Args...> fmt, Args&&... args );  // (1) (depuis C++23)

void println( std::ostream& os );  // (2) (depuis C++26)

Formate args selon la chaîne de format fmt avec '\n' ajouté (ce qui signifie que chaque sortie se termine par un saut de ligne), et insère le résultat dans le flux os.

  1. Équivalent à : std::print(os, "{}\n", std::format(os.getloc(), fmt, args...));

  2. Équivalent à : std::print(os, "\n");

Le comportement est indéfini si std::formatter<Ti, char> ne satisfait pas aux exigences BasicFormatter pour un Ti quelconque dans Args (comme l'exige std::make_format_args).

Paramètres

  • os — flux de sortie dans lequel insérer les données

  • fmt — un objet représentant la chaîne de format. La chaîne de format est composée de

    • caractères ordinaires (sauf { et }), qui sont recopiés sans modification dans la sortie,
    • séquences d'échappement {{ et }}, qui sont remplacées respectivement par { et } dans la sortie, et
    • champs de remplacement.

    Chaque champ de remplacement a le format suivant :

    { arg-id (facultatif) } | (1)

    { arg-id (facultatif) : format-spec } | (2)

    1. champ de remplacement sans spécification de format

    2. champ de remplacement avec une spécification de format

    • arg-id — spécifie l'indice de l'argument dans args dont la valeur doit être utilisée pour le formatage ; s'il est omis, les arguments sont utilisés dans l'ordre.

      Les arg-id ﻿s dans une chaîne de format doivent tous être présents ou tous être omis. Mélanger l'indexation manuelle et automatique est une erreur.

    • format-spec — la spécification de format définie par la spécialisation std::formatter pour l'argument correspondant. Ne peut pas commencer par }.

    • Pour les types de base et les types de chaînes standard, la spécification de format est interprétée comme spécification de format standard.

    • Pour les types chrono, la spécification de format est interprétée comme spécification de format chrono.

    • Pour les types d'intervalles, la spécification de format est interprétée comme spécification de format d'intervalle.
    • Pour std::pair et std::tuple, la spécification de format est interprétée comme spécification de format de tuple.
    • Pour std::thread::id et std::stacktrace_entry, voir spécification de format de thread id et spécification de format d'entrée de stacktrace.
    • Pour std::basic_stacktrace, aucun spécificateur de format n'est autorisé.

    (depuis C++23)

    • Pour std::filesystem::path, voir spécification de format de chemin.

    (depuis C++26)

    • Pour les autres types formatables, la spécification de format est déterminée par les spécialisations formatter définies par l'utilisateur.

  • args... — arguments à formater

Valeur de retour

(aucune)

Exceptions

  • std::bad_alloc en cas d'échec d'allocation.
  • Propage toute exception levée par un formatter, par exemple std::format_error, sans tenir compte de la valeur de os.exceptions() et sans activer ios_base::badbit dans l'état d'erreur de os.
  • Peut lever ios_base::failure causée par os.setstate(ios_base::badbit), qui est appelée si une insertion dans os échoue.

Notes
