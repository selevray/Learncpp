Insère un caractère ou une chaîne de caractères.

  1. Se comporte comme un FormattedOutputFunction. Après la construction et la vérification de l'objet sentry, insère le caractère ch. Si ch a le type char et que le type de conteneur de caractères de os n'est pas char, os.widen(ch) est inséré à la place.

Le remplissage est déterminé comme suit :

  • Si os.width() > 1, alors os.width() - 1 copies de os.fill() sont ajoutées au caractère de sortie pour former la séquence de caractères de sortie.
  • Si (out.flags() & std::ios_base::adjustfield) == std::ios_base::left, les caractères de remplissage sont placés après le caractère de sortie, sinon avant.

Après l'insertion, os.width(0) est appelée pour annuler les effets de std::setw, s'il y en a.

  1. Se comporte comme un FormattedOutputFunction. Après la construction et la vérification de l'objet sentry, insère les caractères successifs du tableau de caractères dont le premier élément est pointé par s.
  • Pour la première et la troisième surcharge (où CharT correspond au type de ch), exactement traits::length(s) caractères sont insérés.
  • Pour la deuxième surcharge, exactement std::char_traits<char>::length(s) caractères sont insérés.
  • Pour les deux dernières surcharges, exactement traits::length(reinterpret_cast<const char*>(s)) sont insérés.

Avant l'insertion, tous les caractères sont d'abord élargis à l'aide de os.widen(), puis le remplissage est déterminé comme suit :

  • Si le nombre de caractères à insérer est inférieur à os.width(), alors suffisamment de copies de os.fill() sont ajoutées à la séquence de caractères pour que sa longueur soit égale à os.width().
  • Si (out.flags() & std::ios_base::adjustfield) == std::ios_base::left, les caractères de remplissage sont ajoutés à la fin de la séquence de sortie, sinon ils sont ajoutés avant la séquence de sortie.

Après l'insertion, os.width(0) est appelée pour annuler les effets de std::setw, s'il y en a.

Si s est un pointeur nul, le comportement est indéfini.

  1. Appelle l'opérateur d'insertion approprié, à partir d'une référence rvalue sur un objet de flux de sortie (équivalent à os << value). Cette surcharge ne participe à la résolution de surcharge que si l'expression os << value est bien formée et que Ostream est un type classe dérivé publiquement et sans ambiguïté de std::ios_base.

  2. Les surcharges acceptant char16_t, char32_t etc. (ou une séquence terminée par un caractère nul de ceux-ci) sont supprimées : std::cout << u'X' n'est pas autorisé. Auparavant, elles affichaient une valeur entière ou un pointeur.

Paramètres

  • os — flux de sortie dans lequel insérer les données
  • ch — référence à un caractère à insérer
  • s — pointeur vers une chaîne de caractères à insérer

Valeur de retour

1,2) os

  1. std::move(os)

Notes

Avant LWG issue 1203, du code tel que (std::ostringstream() << 1.2).str() ne compile pas.

Exemple

#include <fstream>
#include <iostream>

void foo()
{
    // erreur : operator<< (basic_ostream<char, _Traits>&, char8_t) est supprimé
//  std::cout << u8'z' << '\n';
}

std::ostream& operator<<(std::ostream& os, char8_t const& ch)
{
    return os << static_cast<char>(ch);
}

int main()
{
    std::cout << "Hello, world" // utilise la surcharge `const char*`
              << '\n';          // utilise la surcharge `char`
    std::ofstream{"test.txt"} << 1.2; // utilise la surcharge rvalue

    std::cout << u8'!' << '\n'; // utilise operator<<(os, char8_t const&) défini par le programme
}

Output:

Hello, world
!

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 167 C++98 le nombre de caractères insérés pour toutes les surcharges dans (2) était traits::length(s) mise à jour des nombres pour les surcharges où CharT ne correspond pas au type de ch
LWG 1203 C++11 la surcharge pour un flux rvalue renvoyait une référence lvalue vers la classe de base retourne une référence rvalue vers la classe dérivée
LWG 2011 C++98 le remplissage était déterminé par std::num_put::do_put() déterminé par l'opérateur lui-même
LWG 2534 C++11 la surcharge pour flux rvalue n'était pas contrainte constrained
