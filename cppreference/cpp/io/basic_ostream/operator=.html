std::basic_ostream<CharT,Traits>::operator=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
basic_ostream& operator=( const basic_ostream& rhs ) = delete;  // (1)

protected:
basic_ostream& operator=( basic_ostream&& rhs );  // (2) (depuis C++11)

  1. L'opérateur d'affectation par copie est protégé et supprimé. Les flux de sortie ne sont pas CopyAssignable.

  2. L'opérateur d'affectation par déplacement échange toutes les données membres de la classe de base, à l'exception de rdbuf(), avec rhs, comme si l'on appelait swap(*rhs). Cet opérateur d'affectation par déplacement est protégé : il n'est appelé que par les opérateurs d'affectation par déplacement des classes de flux de sortie déplaçables dérivées std::basic_ofstream et std::basic_ostringstream, qui savent affecter correctement par déplacement les tampons de flux associés.

Paramètres

  • rhs — l'objet basic_ostream à partir duquel affecter *this

Exemple

#include <iostream>
#include <sstream>
#include <utility>

int main()
{
    std::ostringstream s;
//  std::cout = s;            // ERREUR : l'opérateur d'affectation par copie est supprimé
//  std::cout = std::move(s); // ERREUR : l'opérateur d'affectation par déplacement est protégé
    s = std::move(std::ostringstream() << 42); // OK, déplacé via derived
    std::cout << s.str() << '\n';
}

Output:

42
