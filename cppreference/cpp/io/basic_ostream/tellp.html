std::basic_ostream<CharT,Traits>::tellp

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

pos_type tellp();

Renvoie l'indicateur de position de sortie de l'objet streambuf associé courant.

Se comporte comme UnformattedOutputFunction (sauf qu'il n'effectue pas réellement de sortie). Après construction et vérification de l'objet sentry,

(depuis C++11)

Si fail()==true, renvoie pos_type(-1). Sinon, renvoie rdbuf()->pubseekoff(0, std::ios_base::cur, std::ios_base::out).

Paramètres

(aucune)

Valeur de retour

indicateur de position de sortie courant en cas de succès, pos_type(-1) si un échec se produit.

Exemple

#include <iostream>
#include <sstream>
int main()
{
    std::ostringstream s;
    std::cout << s.tellp() << '\n';
    s << 'h';
    std::cout << s.tellp() << '\n';
    s << "ello, world ";
    std::cout << s.tellp() << '\n';
    s << 3.14 << '\n';
    std::cout << s.tellp() << '\n' << s.str();
}

Output:

0
1
13
18
hello, world 3.14
