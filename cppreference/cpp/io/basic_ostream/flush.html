std::basic_ostream<CharT,Traits>::flush

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

basic_ostream& flush();

Écrit les modifications non validées dans la séquence de sortie sous-jacente. Se comporte comme un UnformattedOutputFunction.

Si rdbuf() est un pointeur nul, l'objet sentinelle n'est pas construit.

Sinon, après la construction et la vérification de l'objet sentinelle, appelle rdbuf()->pubsync(). Si l'appel renvoie -1, appelle setstate(badbit).

Paramètres

(aucune)

Valeur de retour

*this

Exceptions

Peut lever std::ios_base::failure si (exceptions() & badbit) != 0.

Exemple

#include <chrono>
#include <iostream>
#include <thread>

using namespace std::chrono_literals;

void f()
{
    std::cout << "Output from thread... ";
    for (int i{1}; i != 10; ++i)
    {
        std::this_thread::sleep_for(250ms);
        std::cout << i << ' ';

        // affiche trois nombres à la fois ;
        // l'effet n'est observable qu'en temps réel
        if (0 == (i % 3))
            std::cout.flush();
    }
    std::cout << std::endl; // vide également le tampon
}

int main()
{
    std::thread tr{f};
    std::this_thread::sleep_for(150ms);
    std::clog << "Output from main\n";
    tr.join();
}

Output:

Output from main
Output from thread... 1 2 3 4 5 6 7 8 9
