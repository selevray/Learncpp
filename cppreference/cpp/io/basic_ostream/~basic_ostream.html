std::basic_ostream<CharT,Traits>::~basic_ostream

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

virtual ~basic_ostream();

Détruit l'objet basic_ostream. Ce destructeur n'effectue aucune opération sur le tampon de flux sous-jacent (rdbuf()) : les destructeurs des flux de sortie dérivés tels que std::basic_ofstream et std::basic_ostringstream sont chargés d'appeler les destructeurs des tampons de flux.

Exemple

#include <iostream>
#include <sstream>

void add_words(std::streambuf* p)
{
    std::ostream buf(p); // buf partage le tampon avec s
    buf << " is the answer";
} // appelle le destructeur de buf. p n'est pas affecté

int main()
{
    std::ostringstream s;
    s << 42;
    add_words(s.rdbuf());
    s << ".";
    std::cout << s.str() << '\n';
}

Output:

42 is the answer.
