Cette fonction se comporte comme un FormattedOutputFunction. Après la construction et la vérification de l'objet sentry, insère une valeur en appelant std::num_put::put(). Si la condition de fin de fichier est rencontrée pendant la sortie (put().failed() == true), définit badbit.

Si c'est le cas, exécute setstate(badbit) et quitte. Sinon, extrait des caractères du flux d'entrée contrôlé par sb et les insère dans *this jusqu'à ce que l'une des conditions suivantes soit remplie :
  • une fin de fichier survient sur le flux d'entrée ;
  • l'insertion dans le flux de sortie échoue (auquel cas le caractère à insérer n'est pas extrait) ;
  • une exception survient (auquel cas l'exception est interceptée). Si aucun caractère n'a été inséré, exécute setstate(failbit). Si une exception a été levée lors de l'extraction, définit failbit et, si failbit est défini dans exceptions(), relève à nouveau l'exception.

18-20) Appelle func(*this). Ces surcharges sont utilisées pour implémenter les manipulateurs d'E/S de sortie tels que std::endl.

Paramètres

  • value — valeur entière, à virgule flottante, booléenne ou pointeur à insérer
  • func — fonction à appeler
  • sb — pointeur vers le tampon de flux à partir duquel lire les données

Valeur de retour

1-19) *this

  1. func(*this)

Notes

Il n'existe aucune surcharge pour les pointeurs vers des membres non statiques, pour les pointeurs vers des volatiles, (jusqu'à C++23) ni pour les pointeurs de fonction (autres que ceux dont la signature est acceptée par les surcharges (18-20)).

  • Tenter d'afficher de tels objets invoque une conversion implicite vers bool, et, pour toute valeur de pointeur non nulle, la valeur 1 est affichée (sauf si boolalpha est défini, auquel cas true est affiché).

Les arguments de caractère et de chaîne de caractères (par exemple, de type char ou const char*) sont traités par les surcharges non membres de operator<<.

  • Tenter d'afficher un caractère en utilisant la syntaxe d'appel de fonction membre (par exemple, std::cout.operator<<('c');) appellera l'une des surcharges de (2-5) ou de (11-14) et affichera la valeur numérique.
  • Tenter d'afficher une chaîne de caractères en utilisant la syntaxe d'appel de fonction membre appellera la surcharge (8) et affichera à la place la valeur du pointeur.

La surcharge (10) a été ajoutée par la résolution de LWG issue 2221, mais elle n'est jamais implémentée dans aucune implémentation de la bibliothèque standard en modes C++11/14.

Exemple

#include <iomanip>
#include <iostream>
#include <sstream>

int fun() { return 42; }

int main()
{
    std::istringstream input(" \"Some text.\" ");
    double f = 3.14;
    bool b = true;

    std::cout
        << fun()          // surcharge int (12)
        << ' '            // surcharge non membre
        << std::boolalpha // surcharge de fonction (18)
        << b              // surcharge bool (1)
        << " "            // surcharge non membre
        << std::fixed     // surcharge de fonction (18) à nouveau
        << f              // surcharge double (6)
        << input.rdbuf()  // surcharge streambuf
        << fun            // surcharge bool (1) : il n'existe pas de surcharge pour int(*)()
        << std::endl;     // surcharge de fonction (18) à nouveau

    int x = 0;
    int* p1 = &x;
    volatile int* p2 = &x;
    std::cout
        << "p1: " << p1 << '\n'  // surcharge `const void*`, affiche l'adresse
        << "p2: " << p2 << '\n'; // avant C++23 (P1147) : surcharge bool :), car
            // operator<<(const void*) ne correspond pas, car il supprime le `volatile`
            // qualificateur. Pour corriger cela, C++23 ajoute la surcharge `const volatile void*` (9),
            // qui affiche l'adresse comme attendu.
}

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 117 C++98 les surcharges (1-8,11-15) déléguaient l'insertion à num_put::put, mais elles n'ont pas de surcharges pour short, unsigned short, int, unsigned int et float ils sont convertis avant d'être passés à num_put::put
LWG 567 C++98 la surcharge (17) se comportait comme un FormattedOutputFunction en raison de la résolution de LWG issue 60 elle se comporte comme un UnformattedOutputFunction
