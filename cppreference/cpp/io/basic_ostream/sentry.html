std::basic_ostream<CharT,Traits>::sentry

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

class sentry;

Un objet de la classe basic_ostream::sentry est construit dans la portée locale au début de chaque fonction membre de std::basic_ostream qui effectue une sortie (formatée comme non formatée). Son constructeur prépare le flux de sortie : il vérifie si le flux est déjà dans un état d'échec, vide les flux de sortie liés par tie(), et effectue d'autres tâches définies par l'implémentation si nécessaire. Le nettoyage défini par l'implémentation, ainsi que le vidage du flux de sortie si nécessaire, est effectué dans le destructeur, de sorte qu'il est garanti de s'exécuter si des exceptions sont levées pendant la sortie.

Fonctions membres

  • (constructeur) — construit l'objet sentry. Toutes les tâches de préparation sont effectuées ici (fonction membre publique)
  • (destructeur) — finalise l'objet flux après une sortie formatée ou après une exception, si nécessaire (fonction membre publique)
  • operator= — l'opérateur d'affectation est supprimé (fonction membre publique)
  • operator bool — vérifie si la préparation de l'objet flux a réussi (fonction membre publique)

std::basic_ostream::sentry::sentry

explicit sentry( std::basic_ostream<CharT, Traits>& os );

Prépare le flux pour la sortie formatée.

Si os.good() vaut false, retourne. Sinon, si os.tie() n'est pas un pointeur nul, appelle os.tie()->flush() pour synchroniser la séquence de sortie avec les flux externes. Pendant la préparation, le constructeur peut appeler setstate(failbit) (qui peut lever std::ios_base::failure).

Si, une fois la préparation terminée, os.good() == true, alors tout appel ultérieur à operator bool renverra true.

Paramètres

  • os — flux de sortie à préparer

Exceptions

std::ios_base::failure si la condition de fin de fichier se produit.

std::basic_ostream::sentry::~sentry

~sentry();

Si (os.flags() & std::ios_base::unitbuf) && !std::uncaught_exception() && os.good()) vaut true, appelle os.rdbuf()->pubsync(). Si cette fonction renvoie -1, définit badbit dans os.rdstate() sans propager d'exception.

std::basic_ostream::sentry::operator bool

explicit operator bool() const;

Vérifie si la préparation du flux de sortie a réussi.

Paramètres

(aucune)

Valeur de retour

true si la préparation du flux de sortie a réussi, false sinon.

Exemple

#include <iostream>
#include <sstream>

struct Foo
{
    char n[6];
};

std::ostream& operator<<(std::ostream& os, Foo& f)
{
    std::ostream::sentry s(os);
    if (s)
        os.write(f.n, 5);
    return os;
}

int main()
{
    Foo f = {"abcde"};
    std::cout << f << '\n';
}

Output:

abcde
