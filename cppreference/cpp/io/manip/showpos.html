std::showpos, std::noshowpos

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ios>

std::ios_base& showpos( std::ios_base& str );  // (1)

std::ios_base& noshowpos( std::ios_base& str );  // (2)

Active ou désactive l'affichage du signe plus '+' dans la sortie des entiers non négatifs. Sans effet sur l'entrée.

  1. Active l'indicateur showpos du flux str comme si l'on appelait str.setf(std::ios_base::showpos).

  2. Désactive l'indicateur showpos du flux str comme si l'on appelait str.unsetf(std::ios_base::showpos).

Il s'agit d'un manipulateur d'E/S, il peut être appelé avec une expression telle que out << std::showpos pour tout out de type std::basic_ostream ou avec une expression telle que in >> std::showpos pour tout in de type std::basic_istream.

Paramètres

  • str — référence à un flux d'E/S

Valeur de retour

str (référence au flux après manipulation).

Exemple

#include <iostream>

int main()
{
    std::cout
        << "showpos: " << std::showpos << 42 << ' ' << 3.14 << ' ' << 0 << '\n'
        << "noshowpos: " << std::noshowpos << 42 << ' ' << 3.14 << ' ' << 0 << '\n';
}

Output:

showpos: +42 +3.14 +0
noshowpos: 42 3.14 0
