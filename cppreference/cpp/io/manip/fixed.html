std::fixed, std::scientific, std::hexfloat, std::defaultfloat

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ios>

std::ios_base& fixed( std::ios_base& str );  // (1)

std::ios_base& scientific( std::ios_base& str );  // (2)

std::ios_base& hexfloat( std::ios_base& str );  // (3) (depuis C++11)

std::ios_base& defaultfloat( std::ios_base& str );  // (4) (depuis C++11)

Modifie le formatage par défaut de la sortie des nombres à virgule flottante.

  1. Définit le floatfield du flux str à fixed comme si l'on appelait str.setf(std::ios_base::fixed, std::ios_base::floatfield).

  2. Définit le floatfield du flux str à scientific comme si l'on appelait str.setf(std::ios_base::scientific, std::ios_base::floatfield).

  3. Définit le floatfield du flux str à fixed et scientific simultanément, comme si l'on appelait str.setf(std::ios_base::fixed | std::ios_base::scientific, std::ios_base::floatfield). Cela active le formatage hexadécimal des nombres à virgule flottante.

  4. Définit le floatfield du flux str à zéro, comme si l'on appelait str.unsetf(std::ios_base::floatfield). Cela active le formatage par défaut des nombres à virgule flottante, qui diffère de fixed et de scientific.

Il s'agit d'un manipulateur d'E/S, il peut être appelé avec une expression telle que out << std::fixed pour tout out de type std::basic_ostream (ou avec une expression telle que in >> std::scientific pour tout in de type std::basic_istream).

Paramètres

  • str — référence à un flux d'E/S

Valeur de retour

str (référence au flux après manipulation).

Notes

Le formatage hexadécimal des nombres à virgule flottante ignore la précision du flux, comme l'exige la spécification de std::num_put::do_put.

Ces manipulateurs n'affectent pas l'analyse des nombres à virgule flottante.

Exemple

#include <iomanip>
#include <iostream>
#include <sstream>

enum class cap { title, middle, end };

void print(const char* text, double num, cap c)
{
    if (c == cap::title)
        std::cout <<
            "┌──────────┬────────────┬──────────────────────────┐\n"
            "│  number  │   iomanip  │      representation      │\n"
            "├──────────┼────────────┼──────────────────────────┤\n";
    std::cout << std::left
         << "│ " << std::setw(8) << text <<      " │ fixed      │ "
         << std::setw(24) << std::fixed  << num <<            " │\n"
         << "│ " << std::setw(8) << text <<      " │ scientific │ "
         << std::setw(24) << std::scientific << num <<        " │\n"
         << "│ " << std::setw(8) << text <<      " │ hexfloat   │ "
         << std::setw(24) << std::hexfloat << num <<          " │\n"
         << "│ " << std::setw(8) << text <<      " │ default    │ "
         << std::setw(24) << std::defaultfloat << num <<      " │\n";
    std::cout << (c != cap::end ?
            "├──────────┼────────────┼──────────────────────────┤\n" :
            "└──────────┴────────────┴──────────────────────────┘\n");
}

int main()
{
    print("0.0", 0.0, cap::title);
    print("0.01", 0.01, cap::middle);
    print("0.00001", 0.00001, cap::end);

    // Note; choisissez clang pour obtenir une sortie correcte
    double f;
    std::istringstream("0x1.8p+0") >> f;
    std::cout << "Parsing 0x1.8p+0 gives " << f << '\n';

    std::istringstream("0x1P-1022") >> f;
    std::cout << "Parsing 0x1P-1022 gives " << f << '\n';
}
