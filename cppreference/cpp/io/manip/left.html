std::left, std::right, std::internal

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ios>

std::ios_base& left( std::ios_base& str );  // (1)

std::ios_base& right( std::ios_base& str );  // (2)

std::ios_base& internal( std::ios_base& str );  // (3)

Modifie la position des caractères de remplissage dans un flux de sortie. left et right s'appliquent à tout type en cours de sortie, internal s'applique aux sorties entières, à virgule flottante et monétaires. N'a aucun effet sur l'entrée.

  1. Définit le adjustfield du flux str à left comme si l'on appelait str.setf(std::ios_base::left, std::ios_base::adjustfield).

  2. Définit le adjustfield du flux str à right comme si l'on appelait str.setf(std::ios_base::right, std::ios_base::adjustfield).

  3. Définit le adjustfield du flux str à internal comme si l'on appelait str.setf(std::ios_base::internal, std::ios_base::adjustfield).

La valeur par défaut initiale des flux standard est équivalente à right.

Il s'agit d'un manipulateur d'E/S. Il peut être appelé avec une expression telle que out << std::left pour tout out de type std::basic_ostream, ou avec une expression telle que in >> std::left pour tout in de type std::basic_istream.

Paramètres

  • str — référence à un flux d'E/S

Valeur de retour

str (référence au flux après manipulation).

Exemple

#include <iomanip>
#include <iostream>
#include <locale>

int main()
{
    std::cout.imbue(std::locale("en_US.utf8"));

    std::cout << "Default positioning:\n" << std::setfill('*')
              << std::setw(12) << -1.23  << '\n'
              << std::setw(12) << std::hex << std::showbase << 42 << '\n'
              << std::setw(12) << std::put_money(123, true) << "\n\n";

    std::cout << "Left positioning:\n" << std::left
              << std::setw(12) << -1.23  << '\n'
              << std::setw(12) << 42 << '\n'
              << std::setw(12) << std::put_money(123, true) << "\n\n";

    std::cout << "Internal positioning:\n" << std::internal
              << std::setw(12) << -1.23  << '\n'
              << std::setw(12) << 42 << '\n'
              << std::setw(12) << std::put_money(123, true) << "\n\n";

    std::cout << "Right positioning:\n" << std::right
              << std::setw(12) << -1.23  << '\n'
              << std::setw(12) << 42 << '\n'
              << std::setw(12) << std::put_money(123, true) << '\n';
}
