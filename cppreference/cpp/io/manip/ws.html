std::ws

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <istream>

template< class CharT, class Traits >
std::basic_istream<CharT, Traits>& ws( std::basic_istream<CharT, Traits>& is );

Supprime les espaces blancs en début de flux d'entrée.

Se comporte comme un UnformattedInputFunction, sauf que is.gcount() n'est pas modifié. Après la construction et la vérification de l'objet sentry, extrait des caractères du flux et les supprime jusqu'à ce que l'une des conditions suivantes se produise :

  • une condition de fin de fichier se produit dans la séquence d'entrée (auquel cas la fonction appelle setstate(eofbit) mais ne positionne pas failbit ; ceci ne s'applique pas si eofbit est déjà positionné sur is avant l'appel à ws, auquel cas la construction de l'objet sentry positionnerait failbit).

  • le prochain caractère disponible c dans la séquence d'entrée n'est pas un espace blanc selon std::isspace(c, is.getloc()). Le caractère non blanc n'est pas extrait.

Il s'agit d'un manipulateur d'E/S réservé à l'entrée, il peut être appelé avec une expression telle que in >> std::ws pour tout in de type std::basic_istream.

Paramètres

  • is — référence au flux d'entrée

Valeur de retour

is (référence au flux après l'extraction des espaces blancs consécutifs).

Notes

Si eofbit est positionné sur le flux avant l'appel, la construction de l'objet sentry positionnera failbit.

Exemple

#include <iomanip>
#include <iostream>
#include <istream>
#include <sstream>
#include <string>

int main()
{
    for (const char* str : {"     #1 test", "\t #2 test", "#3 test"})
    {
        std::string line;
        std::getline(std::istringstream{str}, line);
        std::cout << "getline returns:\t" << std::quoted(line) << '\n';

        std::istringstream iss{str};
        std::getline(iss >> std::ws, line);
        std::cout << "ws + getline returns:\t" << std::quoted(line) << '\n';
    }
}

Output:

getline returns:	"     #1 test"
ws + getline returns:	"#1 test"
getline returns:	"	 #2 test"
ws + getline returns:	"#2 test"
getline returns:	"#3 test"
ws + getline returns:	"#3 test"
