std::ends

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ostream>

template< class CharT, class Traits >
std::basic_ostream<CharT, Traits>& ends( std::basic_ostream<CharT, Traits>& os );

Insère un caractère nul dans la séquence de sortie os comme si l'on appelait os.put(CharT()).

Il s'agit d'un manipulateur d'E/S en sortie uniquement ; il peut être appelé avec une expression telle que out << std::ends pour tout out de type std::basic_ostream.

Notes

Ce manipulateur est généralement utilisé avec std::ostrstream, lorsque le tampon de sortie associé doit être terminé par un caractère nul pour être traité comme une chaîne C.

Contrairement à std::endl, ce manipulateur ne vide pas le flux.

Paramètres

  • os — référence à un flux de sortie

Valeur de retour

os (référence au flux après insertion du caractère nul).

Exemple

#include <cstdio>
#include <strstream>

int main()
{
    std::ostrstream oss;
    oss << "Sample text: " << 42 << std::ends;
    std::printf("%s\n", oss.str());
    oss.freeze(false); // activer la libération de la mémoire
}

Output:

Sample text: 42
