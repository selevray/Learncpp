std::put_time

Défini dans l'en-tête <iomanip>

template< class CharT >
/*unspecified*/ put_time( const std::tm* tmb, const CharT* fmt );  // (depuis C++11)

Utilisé dans une expression out << put_time(tmb, fmt), convertit les informations de date et d'heure d'un temps calendaire donné tmb en une chaîne de caractères selon la chaîne de format fmt, comme si l'on appelait std::strftime, std::wcsftime, ou un équivalent (selon CharT), conformément à la facette std::time_put de la locale actuellement associée au flux de sortie out.

Paramètres

  • tmb — pointeur vers la structure de temps calendaire obtenue à partir de std::localtime ou std::gmtime
  • fmt — pointeur vers une chaîne CharT terminée par un caractère nul spécifiant le format de conversion

Chaîne de format

La chaîne de format est constituée de zéro ou plusieurs spécificateurs de conversion et de caractères ordinaires (sauf %). Tous les caractères ordinaires, y compris le caractère nul terminal, sont copiés sans modification dans la chaîne de sortie. Chaque spécification de conversion commence par le caractère %, suivi éventuellement du modificateur E ou O (ignoré si la locale ne le prend pas en charge), puis du caractère qui détermine le comportement du spécificateur. Valeur de retour

Un objet de type non spécifié tel que

  • si out est un objet de type std::basic_ostream<CharT, Traits>, l'expression out << put_time(tmb, fmt)
    • a pour type std::basic_ostream<CharT, Traits>&
    • a pour valeur out
    • se comporte comme s'il appelait f(out, tmb, fmt)

où la fonction f est définie ainsi :

template<class CharT, class Traits>
void f(std::basic_ios<CharT, Traits>& str, const std::tm* tmb, const CharT* fmt)
{
    using Iter = std::ostreambuf_iterator<CharT, Traits>;
    using TimePut = std::time_put<CharT, Iter>;

    const TimePut& tp = std::use_facet<TimePut>(str.getloc());
    const Iter end = tp.put(Iter(str.rdbuf()), str, str.fill(), tmb,
        fmt, fmt + Traits::length(fmt));

    if (end.failed())
        str.setstate(std::ios_base::badbit);
}

Exemple

#include <ctime>
#include <iomanip>
#include <iostream>

int main()
{
    std::time_t t = std::time(nullptr);
    std::tm tm = *std::localtime(&t);

    std::cout.imbue(std::locale("ru_RU.utf8"));
    std::cout << "ru_RU: " << std::put_time(&tm, "%c %Z") << '\n';

    std::cout.imbue(std::locale("ja_JP.utf8"));
    std::cout << "ja_JP: " << std::put_time(&tm, "%c %Z") << '\n';
}

Sortie possible :

ru_RU: Ср. 28 дек. 2011 10:21:16 EST
ja_JP: 2011年12月28日 10時21分16秒 EST
