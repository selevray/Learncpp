std::dec, std::hex, std::oct

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ios>

std::ios_base& dec( std::ios_base& str );  // (1)

std::ios_base& hex( std::ios_base& str );  // (2)

std::ios_base& oct( std::ios_base& str );  // (3)

Modifie la base numérique par défaut pour les E/S d'entiers.

  1. Définit le basefield du flux str à dec comme si l'on appelait str.setf(std::ios_base::dec, std::ios_base::basefield).

  2. Définit le basefield du flux str à hex comme si l'on appelait str.setf(std::ios_base::hex, std::ios_base::basefield).

  3. Définit le basefield du flux str à oct comme si l'on appelait str.setf(std::ios_base::oct, std::ios_base::basefield).

Il s'agit d'un manipulateur d'E/S. Il peut être appelé avec une expression telle que out << std::hex pour tout out de type std::basic_ostream, ou avec une expression telle que in >> std::hex pour tout in de type std::basic_istream.

Paramètres

  • str — référence à un flux d'E/S

Valeur de retour

str (référence au flux après manipulation).

Exemple

#include <bitset>
#include <iostream>
#include <sstream>

int main()
{
    std::cout << "The number 42 in octal:   " << std::oct << 42 << '\n'
              << "The number 42 in decimal: " << std::dec << 42 << '\n'
              << "The number 42 in hex:     " << std::hex << 42 << '\n';
    int n;
    std::istringstream("2A") >> std::hex >> n;
    std::cout << std::dec << "Parsing \"2A\" as hex gives " << n << '\n';
    // la base de sortie reste active jusqu'à ce qu'elle soit modifiée
    std::cout << std::hex << "42 as hex gives " << 42
        << " and 21 as hex gives " << 21 << '\n';

    // Note : il n'existe aucun manipulateur d'E/S qui configure un flux pour afficher
    // des nombres au format binaire (par ex. bin). Si une sortie binaire est nécessaire
    // l'astuce std::bitset peut être utilisée :
    std::cout << "The number 42 in binary:  " << std::bitset<8>{42} << '\n';
}

Output:

The number 42 in octal:   52
The number 42 in decimal: 42
The number 42 in hex:     2a
Parsing "2A" as hex gives 42
42 as hex gives 2a and 21 as hex gives 15
The number 42 in binary:  00101010
