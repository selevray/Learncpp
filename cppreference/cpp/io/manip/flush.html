std::flush

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ostream>

template< class CharT, class Traits >
std::basic_ostream<CharT, Traits>& flush( std::basic_ostream<CharT, Traits>& os );

Vide la séquence de sortie os comme si l'on appelait os.flush().

Il s'agit d'un manipulateur d'E/S en sortie uniquement ; il peut être appelé avec une expression telle que out << std::flush pour tout out de type std::basic_ostream.

Notes

Ce manipulateur peut servir à produire immédiatement une ligne de sortie incomplète, par exemple lors de l'affichage de la sortie d'un processus long, de la journalisation de l'activité de plusieurs threads ou de la journalisation de l'activité d'un programme susceptible de planter de façon inattendue. Un vidage explicite de std::cout est également nécessaire avant un appel à std::system, si le processus lancé effectue des E/S à l'écran (un exemple courant est std::system("pause") sous Windows). Dans la plupart des autres scénarios d'E/S interactives usuels, std::endl est redondant lorsqu'il est utilisé avec std::cout, car toute entrée depuis std::cin, toute sortie vers std::cerr ou la fin du programme provoque un appel à std::cout.flush().

Lorsqu'une ligne de sortie complète doit être vidée, le manipulateur std::endl peut être utilisé.

Lorsque chaque opération de sortie doit être vidée, le manipulateur std::unitbuf peut être utilisé.

Paramètres

  • os — référence à un flux de sortie

Valeur de retour

os (référence au flux après manipulation).

Exemple

Sans std::flush, la sortie serait la même, mais pourrait ne pas apparaître en temps réel.

#include <chrono>
#include <iostream>

template<typename Diff>
void log_progress(Diff d)
{
    std::cout << std::chrono::duration_cast<std::chrono::milliseconds>(d) << " ... "
              << std::flush;
}

int main()
{
    volatile int sink = 0;

    auto t1 = std::chrono::high_resolution_clock::now();
    for (int j = 0; j < 5; ++j)
    {
        for (int n = 0; n < 10000; ++n)
            for (int m = 0; m < 20000; ++m)
                sink += m * n; // effectue un traitement
        auto now = std::chrono::high_resolution_clock::now();
        log_progress(now - t1);
    }
    std::cout << '\n';
}

Sortie possible :

567ms ... 1137ms ... 1707ms ... 2269ms ... 2842ms ...
