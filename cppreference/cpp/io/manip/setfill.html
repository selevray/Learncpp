std::setfill

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iomanip>

template< class CharT >
/*unspecified*/ setfill( CharT c );

Utilisé dans une expression out << setfill(c), définit le caractère de remplissage du flux out à c.

Paramètres

  • c — nouvelle valeur du caractère de remplissage

Valeur de retour

Un objet de type non spécifié tel que

  • si out est un objet de type std::basic_ostream<CharT, Traits>, l'expression out << setfill(c)
    • a pour type std::basic_ostream<CharT, Traits>&
    • a pour valeur out
    • se comporte comme s'il appelait f(out, c)

où la fonction f est définie ainsi :

template<class CharT, class Traits>
void f(std::basic_ios<CharT, Traits>& str, CharT c)
{
    // définit le caractère de remplissage
    str.fill(c);
}

Notes

Le caractère de remplissage actuel peut être obtenu avec std::ostream::fill.

Exemple

#include <iomanip>
#include <iostream>

int main()
{
    std::cout << "default fill: [" << std::setw(10) << 42 << "]\n"
              << "setfill('*'): [" << std::setfill('*')
                                   << std::setw(10) << 42 << "]\n";
}

Output:

default fill: [        42]
setfill('*'): [********42]
