std::get_money

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iomanip>

template< class MoneyT >
/*unspecified*/ get_money( MoneyT& mon, bool intl = false );  // (depuis C++11)

Lorsqu'il est utilisé dans une expression in >> get_money(mon, intl), analyse l'entrée de caractères comme une valeur monétaire, selon le facet std::money_get de la locale actuellement imprégnée dans in, et stocke la valeur dans mon.

L'opération d'extraction dans in >> get_money(mon, intl) se comporte comme un FormattedInputFunction.

Paramètres

  • mon — variable où la valeur monétaire sera écrite. Peut être long double ou std::basic_string
  • intl — attend de trouver les chaînes de devise internationale requises si true, attend des symboles monétaires facultatifs sinon

Valeur de retour

Un objet de type non spécifié tel que

  • si in est un objet de type std::basic_istream<CharT, Traits>, l'expression in >> get_money(mon, intl)
    • a pour type std::basic_istream<CharT, Traits>&
    • a pour valeur in
    • se comporte comme s'il appelait f(in, mon, intl)

où la fonction f est définie ainsi :

template<class CharT, class Traits, class MoneyT>
void f(std::basic_ios<CharT, Traits>& str, MoneyT& mon, bool intl)
{
    using Iter = std::istreambuf_iterator<CharT, Traits>;
    using MoneyGet = std::money_get<CharT, Iter>;

    std::ios_base::iostate err = std::ios_base::goodbit;
    const MoneyGet& mg = std::use_facet<MoneyGet>(str.getloc());

    mg.get(Iter(str.rdbuf()), Iter(), intl, str, err, mon);

    if (err != std::ios_base::goodbit)
        str.setstate(err);
}

Exemple

#include <iomanip>
#include <iostream>
#include <locale>
#include <sstream>

int main()
{
    std::istringstream in("$1,234.56 2.22 USD  3.33");
    long double v1, v2;
    std::string v3;

    in.imbue(std::locale("en_US.UTF-8"));
    in >> std::get_money(v1) >> std::get_money(v2) >> std::get_money(v3, true);

    if (in)
        std::cout << std::quoted(in.str()) << " parsed as: "
                  << v1 << ", " << v2 << ", " << v3 << '\n';
    else
        std::cout << "Parse failed";
}

Output:

"$1,234.56 2.22 USD  3.33" parsed as: 123456, 222, 333
