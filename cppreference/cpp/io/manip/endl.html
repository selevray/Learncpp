Défini dans l'en-tête <ostream>

template< class CharT, class Traits >
std::basic_ostream<CharT, Traits>& endl( std::basic_ostream<CharT, Traits>& os );

Insère un caractère de fin de ligne dans la séquence de sortie os et la vide comme si l'on appelait os.put(os.widen('\n')), suivi de os.flush().

Il s'agit d'un manipulateur d'E/S en sortie uniquement ; il peut être appelé avec une expression telle que out << std::endl pour tout out de type std::basic_ostream.

Notes

Ce manipulateur peut être utilisé pour produire immédiatement une ligne de sortie, par exemple lors de l'affichage de la sortie d'un processus de longue durée, de la journalisation de l'activité de plusieurs threads ou de la journalisation de l'activité d'un programme susceptible de planter de façon inattendue. Un vidage explicite de std::cout est également nécessaire avant un appel à std::system, si le processus lancé effectue des E/S à l'écran. Dans la plupart des autres scénarios d'E/S interactives courants, std::endl est redondant lorsqu'il est utilisé avec std::cout, car toute entrée depuis std::cin, toute sortie vers std::cerr ou toute fin de programme force un appel à std::cout.flush(). L'utilisation de std::endl à la place de '\n', encouragée par certaines sources, peut dégrader sensiblement les performances de sortie.

Dans de nombreuses implémentations, la sortie standard est tamponnée par ligne, et l'écriture de '\n' provoque de toute façon un vidage, sauf si std::ios::sync_with_stdio(false) a été exécuté. Dans ces situations, un endl inutile ne dégrade que les performances de l'écriture dans un fichier, et non celles de la sortie standard.

Les exemples de code de ce wiki suivent Bjarne Stroustrup et The C++ Core Guidelines en ne vidant la sortie standard que lorsque cela est nécessaire.

Lorsqu'une ligne de sortie incomplète doit être vidée, le manipulateur std::flush peut être utilisé.

Lorsque chaque caractère de sortie doit être vidé, le manipulateur std::unitbuf peut être utilisé.

Paramètres

  • os — référence à un flux de sortie

Valeur de retour

os (référence au flux après manipulation).

Exemple

Avec '\n' au lieu de endl, la sortie serait la même, mais pourrait ne pas apparaître en temps réel.

#include <chrono>
#include <iostream>

template<typename Diff>
void log_progress(Diff d)
{
    std::cout << std::chrono::duration_cast<std::chrono::milliseconds>(d)
              << " passed" << std::endl;
}

int main()
{
    std::cout.sync_with_stdio(false); // sur certaines plateformes, stdout se vide à chaque \n

    static volatile int sink{};
    const auto t1 = std::chrono::high_resolution_clock::now();
    for (int i = 0; i < 5; ++i)
    {
        for (int j = 0; j < 10000; ++j)
            for (int k = 0; k < 20000; ++k)
                sink += i * j * k; // effectue un traitement
        log_progress(std::chrono::high_resolution_clock::now() - t1);
    }
}
