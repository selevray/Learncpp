std::get_time

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iomanip>

template< class CharT >
/*unspecified*/ get_time( std::tm* tmb, const CharT* fmt );  // (depuis C++11)

Lorsqu'il est utilisé dans une expression in >> get_time(tmb, fmt), analyse l'entrée de caractères comme une valeur de date/heure selon la chaîne de format fmt, conformément au facet std::time_get de la locale actuellement imprégnée dans le flux d'entrée in. La valeur résultante est stockée dans un objet std::tm pointé par tmb.

Paramètres

  • tmb — pointeur valide vers l'objet std::tm où le résultat sera stocké

  • fmt — pointeur vers une chaîne CharT terminée par un caractère nul, spécifiant le format de conversion

    La chaîne de format se compose de zéro ou plusieurs spécificateurs de conversion, de caractères d'espacement et de caractères ordinaires (sauf %). Chaque caractère ordinaire doit correspondre à un caractère du flux d'entrée, en comparaison insensible à la casse. Chaque caractère d'espacement correspond à un espacement quelconque dans la chaîne d'entrée. Chaque spécification de conversion commence par %, suivi éventuellement du modificateur E ou O (ignoré si la locale ne le prend pas en charge), puis du caractère qui détermine le comportement du spécificateur. Les spécificateurs de format correspondent à la fonction POSIX strptime() :

    Conversion
    spécificateur     | Explication | Écrit dans les champs

    % | correspond à un % littéral. La spécification de conversion complète doit être %% | (aucune)

    t | correspond à n'importe quel espace | (aucune)

    n | correspond à n'importe quel espace | (aucune)

    Ey | analyse l'année comme décalage par rapport à la période du calendrier alternatif %EC de la locale | tm_year

    C | analyse les deux premiers chiffres de l'année comme nombre décimal (plage [00,99]) | tm_year

    Ow | analyse le jour de la semaine comme nombre décimal, où le dimanche vaut 0, en utilisant le système numérique alternatif, par exemple 二 est analysé comme 2 en locale ja_JP | tm_wday

Valeur de retour

Un objet de type non spécifié tel que

  • si in est un objet de type std::basic_istream<CharT, Traits>, l'expression in >> get_time(tmb, fmt)
    • a pour type std::basic_istream<CharT, Traits>&
    • a pour valeur in
    • se comporte comme s'il appelait f(in, tmb, fmt)

où la fonction f est définie ainsi :

template<class CharT, class Traits>
void f(std::basic_ios<CharT, Traits>& str, std::tm* tmb, const CharT* fmt)
{
    using Iter = std::istreambuf_iterator<CharT, Traits>;
    using TimeGet = time_get<CharT, Iter>;

    std::ios_base::iostate err = std::ios_base::goodbit;
    const TimeGet& tg = std::use_facet<TimeGet>(str.getloc());

    tg.get(Iter(str.rdbuf()), Iter(), str, err, tmb,
        fmt, fmt + Traits::length(fmt));

    if (err != std::ios_base::goodbit)
        str.setstate(err);
}

Notes

Comme spécifié dans std::time_get::do_get, que cette fonction appelle, il n'est pas spécifié si cette fonction met à zéro les champs de *tmb qui ne sont pas définis directement par les spécificateurs de conversion présents dans fmt : les programmes portables doivent initialiser chaque champ de *tmb à zéro avant d'appeler std::get_time.

Exemple

Remarque : choisissez clang ou gcc >= 12.1 pour observer la sortie. libstdc++ antérieure à 12.1 n'implémente pas correctement le spécificateur %b : bug #78714.

#include <iomanip>
#include <iostream>
#include <locale>
#include <sstream>

int main()
{
    std::tm t = {};
    std::istringstream ss("2011-Februar-18 23:12:34");
    ss.imbue(std::locale("de_DE.utf-8"));
    ss >> std::get_time(&t, "%Y-%b-%d %H:%M:%S");

    if (ss.fail())
        std::cout << "Parse failed\n";
    else
        std::cout << std::put_time(&t, "%c") << '\n';
}

Sortie possible :

Sun Feb 18 23:12:34 2011
