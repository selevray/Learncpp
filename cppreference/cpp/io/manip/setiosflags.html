std::setiosflags

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <iomanip>

/*unspecified*/ setiosflags( std::ios_base::fmtflags mask );

Utilisé dans une expression out << setiosflags(mask) ou in >> setiosflags(mask), définit tous les drapeaux de format du flux out ou in selon mask.

Paramètres

  • mask — masque binaire des drapeaux à définir

Valeur de retour

Un objet de type non spécifié tel que

  • si out est un objet de type std::basic_ostream<CharT, Traits>, l'expression out << setiosflags(mask)
    • a pour type std::basic_ostream<CharT, Traits>&
    • a pour valeur out
    • se comporte comme s'il appelait f(out, mask)
  • si in est un objet de type std::basic_istream<CharT, Traits>, l'expression in >> setiosflags(mask)
    • a pour type std::basic_istream<CharT, Traits>&
    • a pour valeur in
    • se comporte comme s'il appelait f(in, mask)

où la fonction f est définie ainsi :

void f(std::ios_base& str, std::ios_base::fmtflags mask)
{
    // définit les drapeaux spécifiés
    str.setf(mask);
}

Exemple

#include <iomanip>
#include <iostream>

int main()
{
    std::cout << std::resetiosflags(std::ios_base::dec)
              << std::setiosflags(  std::ios_base::hex
                                  | std::ios_base::uppercase
                                  | std::ios_base::showbase) << 42 << '\n';
}

Output:

0X2A

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.
