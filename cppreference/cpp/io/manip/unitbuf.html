std::unitbuf, std::nounitbuf

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ios>

std::ios_base& unitbuf( std::ios_base& str );  // (1)

std::ios_base& nounitbuf( std::ios_base& str );  // (2)

Active ou désactive le vidage automatique du flux de sortie après toute opération de sortie. Sans effet sur l'entrée.

  1. Active l'indicateur unitbuf du flux str comme si l'on appelait str.setf(std::ios_base::unitbuf).

  2. Désactive l'indicateur unitbuf du flux str comme si l'on appelait str.unsetf(std::ios_base::unitbuf).

Il s'agit d'un manipulateur d'E/S, il peut être appelé avec une expression telle que out << std::unitbuf pour tout out de type std::basic_ostream ou avec une expression telle que in >> std::unitbuf pour tout in de type std::basic_istream.

Notes

Le vidage est effectué dans le destructeur de l'objet std::basic_ostream::sentry, qui appelle str.rdbuf()->pubsync() si str.flags() & std::ios_base::unitbuf vaut true.

Les objets de sortie standard std::cerr et std::wcerr ont leur bit unitbuf activé par défaut.

Paramètres

  • str — référence à un flux d'E/S

Valeur de retour

str (référence au flux après manipulation).

Exemple

Sans std::unitbuf ni autre vidage explicite, la sortie est la même, mais n'apparaît pas en temps réel.

#include <chrono>
#include <iostream>

template<typename Diff>
void log_progress(Diff d)
{
    std::cout << std::chrono::duration_cast<std::chrono::milliseconds>(d)
              << " ... ";
}

int main()
{
    volatile int sink = 0;
    std::cout << std::unitbuf; // active le vidage automatique

    const auto start = std::chrono::high_resolution_clock::now();
    for (int j = 0; j < 5; ++j)
    {
        for (int n = 0; n < 10000; ++n)
            for (int m = 0; m < 20000; ++m)
                sink += m * n; // effectue un traitement
        log_progress(std::chrono::high_resolution_clock::now() - start);
    }
    std::cout << '\n';
}

Output:

571ms ... 1146ms ... 1722ms ... 2294ms ... 2865ms ...
