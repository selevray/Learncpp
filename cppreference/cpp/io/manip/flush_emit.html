std::flush_emit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ostream>

template< class CharT, class Traits >
std::basic_ostream<CharT, Traits>& flush_emit( std::basic_ostream<CharT, Traits>& os );  // (depuis C++20)

Vide la séquence de sortie os comme si l'on appelait os.flush(). Puis, si os.rdbuf() pointe effectivement vers un std::basic_syncbuf<CharT, Traits, Allocator> buf, appelle buf.emit().

Il s'agit d'un manipulateur d'E/S en sortie uniquement ; il peut être appelé avec une expression telle que out << std::flush_emit pour tout out de type std::basic_ostream.

Paramètres

  • os — référence à un flux de sortie

Valeur de retour

os (référence au flux après manipulation)
