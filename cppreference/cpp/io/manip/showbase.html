std::showbase, std::noshowbase

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ios>

std::ios_base& showbase( std::ios_base& str );  // (1)

std::ios_base& noshowbase( std::ios_base& str );  // (2)

  1. Active l'indicateur showbase du flux str comme si l'on appelait str.setf(std::ios_base::showbase).

  2. Désactive l'indicateur showbase du flux str comme si l'on appelait str.unsetf(std::ios_base::showbase).

Il s'agit d'un manipulateur d'E/S, il peut être appelé avec une expression telle que out << std::showbase pour tout out de type std::basic_ostream ou avec une expression telle que in >> std::showbase pour tout in de type std::basic_istream.

L'indicateur showbase affecte le comportement de la sortie des entiers (voir std::num_put::put), de l'entrée monétaire (voir std::money_get::get) et de la sortie monétaire (voir std::money_put::put).

Paramètres

  • str — référence à un flux d'E/S

Valeur de retour

str (référence au flux après manipulation).

Notes

Comme spécifié dans std::num_put::put, l'indicateur showbase dans la sortie des entiers agit comme le spécificateur de format # dans std::printf, ce qui signifie que le préfixe de base numérique n'est pas ajouté lors de la sortie de la valeur zéro.

Exemple

#include <iomanip>
#include <iostream>
#include <locale>
#include <sstream>

int main()
{
    // showbase affecte la sortie des nombres octaux et hexadécimaux
    std::cout << std::hex
              << "showbase: " << std::showbase << 42 << '\n'
              << "noshowbase: " << std::noshowbase << 42 << '\n';

    // et l'entrée comme la sortie des valeurs monétaires
    std::locale::global(std::locale("en_US.UTF8"));
    long double val = 0;
    std::istringstream("3.14") >> std::showbase >> std::get_money(val);
    std::cout << "With showbase, parsing 3.14 as money gives " << val << '\n';
    std::istringstream("3.14") >> std::noshowbase >> std::get_money(val);
    std::cout << "Without showbase, parsing 3.14 as money gives " << val << '\n';
}

Output:

showbase: 0x2a
noshowbase: 2a
With showbase, parsing 3.14 as money gives 0
Without showbase, parsing 3.14 as money gives 314
