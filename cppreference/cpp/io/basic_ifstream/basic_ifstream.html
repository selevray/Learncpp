Construit un nouveau flux de fichier.

  1. Constructeur par défaut : construit un flux non associé à un fichier : construit par défaut le std::basic_filebuf et construit la base avec le pointeur vers ce std::basic_filebuf construit par défaut.

2,3) D'abord, effectue les mêmes étapes que le constructeur par défaut, puis associe le flux à un fichier en appelant rdbuf()->open(filename, mode | std::ios_base::in) (voir std::basic_filebuf::open pour les détails des effets de cet appel). Si l'appel open() renvoie un pointeur nul, définit setstate(failbit). La surcharge (3) n'est fournie que si std::filesystem::path::value_type n'est pas char. (depuis C++17)

4,5) Identique à basic_ifstream(filename.c_str(), mode). (5) participe à la résolution de surcharge uniquement si FsPath est std::filesystem::path. (depuis C++17)

  1. Constructeur de déplacement. D'abord, construit par déplacement la classe de base à partir de other (ce qui n'affecte pas le pointeur rdbuf()), puis construit par déplacement le membre std::basic_filebuf, puis appelle this->set_rdbuf() pour installer le nouveau basic_filebuf comme pointeur rdbuf() dans la classe de base.

  2. Le constructeur de copie est supprimé : cette classe n'est pas copiable.

Paramètres

  • filename — le nom du fichier à ouvrir

  • mode — spécifie le mode d'ouverture du flux. Les constantes suivantes ainsi que le OU binaire entre elles peuvent être utilisées :

    Constante Explication

    • app — se positionne à la fin du flux avant chaque écriture
    • binary — ouvre en mode binaire
    • in — ouvre en lecture
    • out — ouvre en écriture
    • trunc — supprime le contenu du flux à l'ouverture
    • ate — se positionner à la fin du flux immédiatement après l'ouverture
    • noreplace (C++23) — ouvrir en mode exclusif

  • other — un autre flux de fichier à utiliser comme source

Exemple

#include <fstream>
#include <string>
#include <utility>

int main()
{
    std::ifstream f0;
    std::ifstream f1("test.bin", std::ios::binary);
    std::string name = "example.txt";
    std::ifstream f2(name);
    std::ifstream f3(std::move(f1));
}
