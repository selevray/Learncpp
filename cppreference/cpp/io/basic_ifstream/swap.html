std::basic_ifstream<CharT,Traits>::swap

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void swap( basic_ifstream& other );  // (depuis C++11)

Échange l'état du flux avec celui de other.

Ceci est fait en appelant basic_istream<CharT, Traits>::swap(other) et rdbuf()->swap(other.rdbuf()).

Paramètres

  • other — flux avec lequel échanger l'état

Valeur de retour

(aucune)

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <fstream>
#include <iomanip>
#include <iostream>
#include <string>

bool create_stream(std::fstream& fs, const std::string& path)
{
    try
    {
        std::fstream ts{path, ts.trunc | ts.in | ts.out};
        if (ts.is_open())
        {
            ts.swap(fs); // les objets de flux ne sont pas copiables
            return true;
        }
    }
    catch (...)
    {
        std::cout << "Exception!\n";
    }
    return false;
}

void use_stream(std::fstream& fs)
{
    fs.seekg(0);
    std::string data;
    fs >> data;
    std::cout << "data: " << std::quoted(data) << '\n';
}

int main()
{
    std::fstream fs;
    std::string path = "/tmp/test_file.txt";
    if (create_stream(fs, path))
    {
        fs.write(path.c_str(), path.length());
        use_stream(fs);
    }
}

Sortie possible :

data: "/tmp/test_file.txt"
