std::basic_ifstream<CharT,Traits>::is_open

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool is_open() const;

Vérifie si le flux de fichier a un fichier associé.

Appelle effectivement rdbuf()->is_open().

Paramètres

(aucune)

Valeur de retour

true si le flux de fichier a un fichier associé, false sinon.

Exemple

#include <fstream>
#include <iostream>
#include <string>

// ce fichier s'appelle main.cpp

bool file_exists(const std::string& str)
{
    std::ifstream fs(str);
    return fs.is_open();
}

int main()
{
    std::boolalpha(std::cout);
    std::cout << file_exists("main.cpp")  << '\n'
              << file_exists("strange_file") << '\n';
}
