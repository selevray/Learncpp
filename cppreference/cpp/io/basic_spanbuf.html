template<
    class CharT,
    class Traits = std::char_traits<CharT>
> class basic_spanbuf
    : public std::basic_streambuf<CharT, Traits>  // (depuis C++23)

std::basic_spanbuf est un std::basic_streambuf dont la séquence de caractères associée est une séquence de caractères arbitraires résidant en mémoire, qui peut être initialisée à partir d'une instance de std::span<CharT> ou mise à disposition sous forme d'une telle instance.

std::basic_spanbuf effectue des E/S sur un tampon fixe ; il ne tente donc pas d'obtenir un nouveau tampon lorsque le tampon sous-jacent est épuisé.

Notes

std::basic_spanbuf ne possède pas le tampon sous-jacent.

Il incombe aux programmeurs de s'assurer que le tampon sous-jacent reste valide pendant toute sa durée de vie lorsqu'il est utilisé par un objet std::basic_spanbuf. Une synchronisation supplémentaire peut être nécessaire si plusieurs threads manipulent le même tampon sous-jacent via des objets std::basic_spanbuf différents.
