std::basic_fstream<CharT,Traits>::close

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void close();

Ferme le fichier associé.

Appelle effectivement rdbuf()->close(). Si une erreur survient pendant l'opération, setstate(failbit) est appelé.

Paramètres

(aucune)

Valeur de retour

(aucune)

Notes

Cette fonction est appelée par le destructeur de basic_fstream lorsque l'objet flux sort de sa portée et n'est généralement pas invoquée directement.

Exemple

#include <fstream>
#include <iostream>
#include <string>

int main()
{
    std::fstream f1("example1", std::ios::out),
                 f2("example2", std::ios::out),
                 f3("example3", std::ios::out);

    std::cout << std::boolalpha
              << f1.is_open() << '\n'
              << f2.is_open() << '\n'
              << f3.is_open() << '\n';

    f1.close();
    f2.close();

    std::cout << f1.is_open() << '\n'
              << f2.is_open() << '\n'
              << f3.is_open() << '\n';
}
