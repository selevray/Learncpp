std::basic_fstream<CharT,Traits>::is_open

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool is_open() const;

Vérifie si le flux de fichier a un fichier associé.

Appelle effectivement rdbuf()->is_open().

Paramètres

(aucune)

Valeur de retour

true si le flux de fichier a un fichier associé, false sinon.

Exemple

#include <fstream>
#include <iostream>
#include <string>

int main()
{
    std::string filename = "some_file";

    std::fstream fs(filename, std::ios::in);

    std::cout << std::boolalpha;
    std::cout << "fs.is_open() = " << fs.is_open() << '\n';

    if (!fs.is_open())
    {
        fs.clear();
        fs.open(filename, std::ios::out);
        std::cout << "fs.is_open() = " << fs.is_open() << '\n';
    }
}

Sortie possible :

fs.is_open() = false
fs.is_open() = true
