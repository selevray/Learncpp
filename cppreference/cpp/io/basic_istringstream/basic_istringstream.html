Construit un nouveau flux de chaînes.

Soient

  • base_type en tant que std::basic_istream<CharT, Traits>, et
  • buf_type as std::basic_stringbuf<CharT, Traits, Allocator>,

la base std::basic_istream et le membre de données réservé à l'exposition sb sont initialisés comme suit.

Surcharge | base std::basic_istream | sb

(1) | base_type(std::addressof(sb))[1] | buf_type(mode | std::ios_base::in)

(2) | buf_type(std::ios_base::in)

(3) | buf_type(str, mode | std::ios_base::in)

(4) | buf_type(std::move(str), mode | std::ios_base::in)

(5) | buf_type(mode | std::ios_base::in, a)

(6) | buf_type(str, mode | std::ios_base::in, a)

(7) | buf_type(str, std::ios_base::in, a)

(8) | buf_type(str, mode | std::ios_base::in)

(9) | std::addressof(sb) | {t, mode | std::ios_base::in, Allocator()}

(10) | {t, mode | std::ios_base::in, a}

(11) | {t, std::ios_base::in, a}

(12) | construit par déplacement à partir de la base std::basic_istream de other | construit par déplacement à partir de other.sb

  1. ↑ La base std::basic_iostream était initialisée avec base_type(&sb) (pour les surcharges (1,3)) jusqu'à C++11.
  1. Cette surcharge ne participe à la résolution de surcharge que si std::is_same_v<SAlloc, Allocator> est false.

9-11) Ces surcharges participent à la résolution de surcharge uniquement si std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>> est true.

Paramètres

  • str — chaîne à utiliser comme contenu initial du flux de chaînes

  • t — un objet (convertible en std::basic_string_view) à utiliser comme contenu initial du flux de chaînes

  • a — allocateur utilisé pour allouer le contenu du flux de chaînes

  • mode — spécifie le mode d'ouverture du flux. C'est un BitmaskType, les constantes suivantes sont définies :

    Constante Explication

    • app — se positionne à la fin du flux avant chaque écriture
    • binary — ouvre en mode binaire
    • in — ouvre en lecture
    • out — ouvre en écriture
    • trunc — supprime le contenu du flux à l'ouverture
    • ate — se positionner à la fin du flux immédiatement après l'ouverture
    • noreplace (C++23) — ouvrir en mode exclusif

  • other — autre flux de chaînes à utiliser comme source

Notes

La construction d'objets basic_istringstream ponctuels dans une boucle serrée, par exemple lors de conversions de chaînes, peut être nettement plus coûteuse que d'appeler str() pour réutiliser le même objet.

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_sstream_from_string_view 202306L (C++26) Interfaçage des std::stringstream avec std::string_view, (9-11)

Exemple

#include <iostream>
#include <sstream>

int main()
{
    // constructeur par défaut (flux d'entrée/sortie)
    std::stringstream buf1;
    buf1 << 7;
    int n = 0;
    buf1 >> n;
    std::cout << "buf1 = " << buf1.str() << " n = " << n << '\n';

    // flux d'entrée
    std::istringstream inbuf("-10");
    inbuf >> n;
    std::cout << "n = " << n << '\n';

    // flux de sortie en mode ajout (C++11)
    std::ostringstream buf2("test", std::ios_base::ate);
    buf2 << '1';
    std::cout << buf2.str() << '\n';
}

Output:

buf1 = 7 n = 7
n = -10
test1
