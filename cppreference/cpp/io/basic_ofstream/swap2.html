std::swap(std::basic_ofstream)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class CharT, class Traits >
void swap( basic_ofstream<CharT, Traits>& lhs, basic_ofstream<CharT, Traits>& rhs );

Spécialise l'algorithme std::swap pour std::basic_ofstream. Échange l'état de lhs avec celui de rhs. Appelle effectivement lhs.swap(rhs).

Paramètres

  • lhs, rhs — flux dont l'état doit être échangé

Valeur de retour

(aucune)

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <fstream>
#include <iostream>
#include <string>

bool create_stream(std::ofstream& fs)
{
    try
    {
        std::string some_name = "/tmp/test_file.txt";
        std::ios_base::openmode some_flags = fs.trunc; // | autres drapeaux

        if (std::ofstream ts{some_name, some_flags}; ts.is_open())
        {
            std::swap(ts, fs); // les objets de flux ne sont pas copiables => swap
            return true;
        }
    }
    catch (...)
    {
        std::cout << "Exception!\n";
    }
    return false;
}

int main()
{
    if (std::ofstream fs; create_stream(fs))
    {
        // utiliser le flux fs
    }
}
