std::strstreambuf::pcount

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

int pcount() const;  // (obsolète en C++98) (supprimé en C++26)

Renvoie le nombre de caractères écrits dans la séquence de sortie.

Si le pointeur suivant de la zone d'écriture (std::streambuf::pptr()) est un pointeur nul, renvoie zéro.

Sinon, renvoie le pointeur suivant de la zone d'écriture moins le pointeur de début de la zone d'écriture, soit pptr() - pbase().

Paramètres

(aucune)

Valeur de retour

Le nombre de caractères écrits dans la zone d'écriture.

Exemple

#include <iostream>
#include <strstream>

int main()
{
    std::strstream dyn; // tampon de sortie alloué dynamiquement
    dyn << "Test: " << 1.23 << std::ends;
    std::strstreambuf* buf = dyn.rdbuf();
    std::cout << "The size of the output is "
              << buf->pcount() // ou simplement buf.pcount()
              << " and it holds \"" << dyn.str() << "\"\n";
    dyn.freeze(false); // après avoir appelé .str() sur un strstream dynamique

    char arr[10];
    std::ostrstream user(arr, 10); // tampon de sortie fourni par l'utilisateur
    buf = user.rdbuf();
    user << 1.23; // remarque : pas de std::ends
    std::cout.write(arr, buf->pcount()); // ou simplement user.pcount()
    std::cout << '\n';

    std::istrstream lit("1 2 3"); // tampon de taille fixe en lecture seule
    buf = lit.rdbuf();
    // istrstream n'a pas de membre pcount(), donc lit.pcount() ne fonctionnera pas
    std::cout << "Input-only pcount() = " << buf->pcount() << '\n';
}

Output:

The size of the output is 11 and it holds "Test: 1.23"
1.23
Input-only pcount() = 0
