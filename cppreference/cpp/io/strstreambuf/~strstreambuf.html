std::strstreambuf::~strstreambuf

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

virtual ~strstreambuf();  // (obsolète en C++98) (supprimé en C++26)

Détruit un objet std::strstreambuf. Si l'objet gère un tampon alloué dynamiquement (l'état du tampon est « allocated ») et si l'objet n'est pas gelé, libère le tampon à l'aide de la fonction de désallocation fournie à la construction, ou delete[] si aucune n'a été fournie.

Paramètres

(aucune)

Notes

Ce destructeur est généralement appelé par le destructeur de std::strstream.

Si str() a été appelé sur un strstream dynamique et que freeze(false) n'a pas été appelé après, ce destructeur provoque une fuite de mémoire.

Exemple

#include <iostream>
#include <strstream>

void* my_alloc(size_t n)
{
    std::cout << "my_alloc(" << n << ") called\n";
    return new char[n];
}

void my_free(void* p)
{
    std::cout << "my_free() called\n";
    delete[] (char*)p;
}

int main()
{
    {
        std::strstreambuf buf(my_alloc, my_free);
        std::ostream s(&buf);
        s << 1.23 << std::ends;
        std::cout << buf.str() << '\n';
        buf.freeze(false);
    } // destructeur appelé ici, tampon désalloué

    {
        std::strstreambuf buf(my_alloc, my_free);
        std::ostream s(&buf);
        s << 1.23 << std::ends;
        std::cout << buf.str() << '\n';
//      buf.freeze(false);
    } // destructeur appelé ici, fuite de mémoire !
}

Output:

my_alloc(4096) called
1.23
my_free() called
my_alloc(4096) called
1.23
