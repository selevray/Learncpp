Construit un objet std::strstreambuf : initialise la classe de base en appelant le constructeur par défaut de std::streambuf, initialise l'état du tampon à « dynamique » (le tampon sera alloué au besoin), initialise la taille allouée à la valeur fournie alsize, initialise les fonctions d'allocation et de désallocation à nul (utiliseront new[] et delete[]).

  2. Construit un objet std::strstreambuf : initialise la classe de base en appelant le constructeur par défaut de std::streambuf, initialise l'état du tampon à « dynamique » (le tampon sera alloué au besoin), initialise la taille allouée à une valeur non spécifiée, initialise la fonction d'allocation à palloc et la fonction de désallocation à pfree.

3-5) Construit un objet std::strstreambuf selon les étapes suivantes :

a) Initialise la classe de base en appelant le constructeur par défaut de std::streambuf.

b) Initialise l'état du tampon à « constant » (le tampon est un tampon de taille fixe fourni par l'utilisateur).

c) Détermine le nombre d'éléments du tableau fourni par l'utilisateur comme suit : si n est strictement supérieur à zéro, n est utilisé. Si n vaut zéro, std::strlen(gnext) est exécuté pour déterminer la taille du tampon. Si n est négatif, INT_MAX est utilisé.

d) Configure les pointeurs std::basic_streambuf comme suit : si pbeg est un pointeur nul, appelle setg(gnext, gnext, gnext + N). Si pbeg n'est pas un pointeur nul, exécute setg(gnext, gnext, pbeg) et setp(pbeg, pbeg + N), où N est le nombre d'éléments du tableau déterminé précédemment.

6-8) Identique à strstreambuf((char*)gnext, n), sauf que le bit « constant » est positionné dans le masque d'état du tampon (la sortie vers ce tampon n'est pas autorisée).

Paramètres

  • alsize — la taille initiale du tampon alloué dynamiquement
  • palloc — pointeur vers la fonction d'allocation fournie par l'utilisateur
  • pfree — pointeur vers la fonction de désallocation fournie par l'utilisateur
  • gnext — pointeur vers le début de la zone de lecture dans le tableau fourni par l'utilisateur
  • pbeg — pointeur vers le début de la zone d'écriture dans le tableau fourni par l'utilisateur
  • n — le nombre d'octets de la zone de lecture (si pbeg est nul) ou de la zone d'écriture (si pbeg n'est pas nul) du tableau fourni par l'utilisateur

Notes

Ces constructeurs sont généralement appelés par les constructeurs de std::strstream.

Exemple

#include <iostream>
#include <strstream>

int main()
{
    std::strstreambuf dyn; // dynamic
    std::strstream dyn_s; // flux équivalent
    dyn_s << 1.23 << std::ends;
    std::cout << dyn_s.str() << '\n';
    dyn_s.freeze(false);

    char buf[10];
    std::strstreambuf user(buf, 10, buf); // tampon de sortie fourni par l'utilisateur
    std::ostrstream user_s(buf, 10); // flux équivalent
    user_s << 1.23 << std::ends;
    std::cout << buf << '\n';

    std::strstreambuf lit("1 2 3", 5); // constant
    std::istrstream lit_s("1 2 3"); // flux équivalent
    int i, j, k;
    lit_s >> i >> j >> k;
    std::cout << i << ' ' << j << ' ' << k << '\n';
}

Output:

1.23
1.23
1 2 3
