std::strstreambuf::freeze

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void freeze( bool freezefl = true );  // (obsolète en C++98) (supprimé en C++26)

Si le tampon utilise une allocation dynamique, définit l'état gelé du flux à freezefl.

Tant que le flux est gelé, overflow() ne réalloue pas le tampon et le destructor ne désalloue pas le tampon (provoquant ainsi une fuite mémoire).

Paramètres

  • freezefl — nouvelle valeur de l'état de gel à définir

Valeur de retour

(aucune)

Notes

Chaque appel à str() gèle le flux afin de préserver la validité du pointeur qu'il retourne. Pour permettre au destructeur de désallouer le tampon, freeze(false) doit être appelé explicitement.

Exemple

Dans cet exemple, l'allocation initiale du tableau sous-jacent était de 16 octets.

#include <iostream>
#include <strstream>

int main()
{
    {
        std::strstream dyn; // tampon de lecture/écriture alloué dynamiquement
        dyn << "Test: " << 1.23; // remarque : pas de std::ends pour démontrer le comportement d'ajout
        std::cout << "dynamic buffer holds " << dyn.pcount() << " characters: '";
        std::cout.write(dyn.str(), dyn.pcount()) << "'\n";
        // le tampon est maintenant gelé, la sortie ultérieure ne fera pas croître le tampon
        dyn << "more output, hopefully enough to run out of the allocated space"
            << std::ends;
        std::cout << "After more output, it holds "
                  << dyn.pcount() << " characters: '" << dyn.str() << "'\n";
        dyn.freeze(false); // dégeler avant le destructeur
    } // mémoire libérée par le destructeur

    {
        char arr[20];
        std::ostrstream st(arr, sizeof arr); // tampon de taille fixe
        st << 1.23; // remarque : pas de std::ends pour démontrer le comportement d'ajout
        std::cout << "static buffer holds "
                  << st.pcount() << " characters: '";
        std::cout.write(st.str(), st.pcount());
        std::cout << "'\n";
        st << "more output, hopefully enough to run out of the allocated space"
           << std::ends;
        std::cout << "static buffer holds "
                  << st.pcount() << " characters: '";
        std::cout.write(st.str(), st.pcount());
        std::cout << "'\n";
    } // rien à désallouer, pas besoin de dégeler,
}

Output:

dynamic buffer holds 10 characters: 'Test: 1.23'
After more output, it holds 16 characters: 'Test: 1.23more o'
static buffer holds 4 characters: '1.23'
static buffer holds 20 characters: '1.23more output, hop'
