std::strstreambuf::setbuf

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
virtual streambuf* setbuf( char* s, std::streamsize n );  // (obsolète en C++98) (supprimé en C++26)

Si s est un pointeur nul et n vaut zéro, cette fonction n'a aucun effet.

Sinon, l'effet est défini par l'implémentation : certaines implémentations ne font rien, tandis que d'autres désallouent le tableau membre dynamique utilisé comme tampon et commencent à utiliser le tableau de caractères fourni par l'utilisateur de taille n, dont le premier élément est pointé par s.

Cette fonction est protégée et virtuelle ; elle ne peut être appelée que par l'intermédiaire de pubsetbuf() ou depuis les fonctions membres d'une classe définie par l'utilisateur dérivée de std::strstreambuf.

Paramètres

  • s — pointeur vers le premier octet du tampon fourni par l'utilisateur
  • n — le nombre d'octets du tampon fourni par l'utilisateur

Valeur de retour

this

Exemple

Test d'implémentation pour vérifier si setbuf() est pris en charge sur un strstream dynamique (sortie obtenue avec Sun Studio) :

#include <iostream>
#include <strstream>

int main()
{
    char a[100] = {};
    std::strstream str;
    str.rdbuf()->pubsetbuf(a, sizeof a);
    str << "Test string" << std::ends;
    std::cout << "user-provided buffer holds \"" << a << "\"\n";
}

user-provided buffer holds "Test string"

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.
