std::strstreambuf::str

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

char* str();  // (obsolète en C++98) (supprimé en C++26)

Appelle freeze(), puis renvoie une copie du pointeur de début de la zone de lecture, std::streambuf::eback().

Le début de la zone de lecture, pour tous les objets std::strstreambuf accessibles en écriture construits via l'interface fournie par std::strstream, est aussi le début de la zone d'écriture.

Paramètres

(aucune)

Valeur de retour

Une copie de eback(), qui peut être un pointeur nul.

Notes

Cette fonction est généralement appelée via l'interface std::strstream.

L'appel à freeze() garantit que le pointeur renvoyé reste valide jusqu'au prochain appel explicite à freeze(false) : sinon (sur un tampon dynamique) toute opération de sortie pourrait déclencher une réallocation du tampon, ce qui invaliderait le pointeur. Il provoque également une fuite mémoire dans le destructeur de std::strstreambuf, sauf si freeze(false) est appelée avant que le tampon (ou, plus couramment, le std::strstream qui le gère) ne soit détruit.

Exemple

#include <iostream>
#include <strstream>

int main()
{
    std::strstream dyn; // tampon de lecture/écriture alloué dynamiquement
    dyn << "Test: " << 1.23 << std::ends;
    std::strstreambuf* buf = dyn.rdbuf();
    std::cout << "R/W buffer holds [" << buf->str() // ou dyn.str()
              << "]\n";
    dyn.freeze(false); // après avoir appelé .str() sur un strstream dynamique

    char arr[10];
    std::ostrstream user(arr, 10); // tampon de taille fixe en écriture seule
    buf = user.rdbuf();
    user << 1.23 << std::ends;
    std::cout << "Write-only buffer holds [" << buf->str() // ou user.str()
              << "]\n";

    std::istrstream lit("1 2 3"); // tampon de taille fixe en lecture seule
    buf = lit.rdbuf();
    std::cout << "Read-only buffer holds [" << buf->str() // ou lit.str()
              << "]\n";
}

Output:

R/W buffer holds [Test: 1.23]
Write-only buffer holds [1.23]
Read-only buffer holds [1 2 31 2 3]
