std::strstreambuf::seekoff

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

protected:
virtual pos_type seekoff( off_type off,
                          ios_base::seekdir way,
                          ios_base::openmode which = ios_base::in | ios_base::out );  // (obsolète en C++98) (supprimé en C++26)

Repositionne std::basic_streambuf::gptr et/ou std::basic_streambuf::pptr, si possible, à la position correspondant exactement à off caractères depuis le début, la fin ou la position courante de la zone de lecture et/ou d'écriture du tampon.

  • Si which inclut ios_base::in et que ce tampon est ouvert en lecture, repositionne le pointeur de lecture std::basic_streambuf::gptr à l'intérieur de la zone de lecture comme décrit ci-dessous.
  • Si which inclut ios_base::out et que ce tampon est ouvert en écriture, repositionne le pointeur d'écriture std::basic_streambuf::pptr à l'intérieur de la zone d'écriture comme décrit ci-dessous.
  • Si which inclut à la fois ios_base::in et ios_base::out et que le tampon est ouvert à la fois en lecture et en écriture, et que way vaut ios_base::beg ou ios_base::end, repositionne à la fois les pointeurs de lecture et d'écriture comme décrit ci-dessous.
  • Sinon, cette fonction échoue.

Si le pointeur (gptr, pptr, ou les deux) est repositionné, cela se fait comme suit :

  1. Si le pointeur à repositionner est un pointeur nul et que le nouveau décalage newoff serait non nul, cette fonction échoue.

  2. Le nouveau décalage newoff du pointeur, de type off_type, est déterminé

a) si way == ios_base::beg, alors newoff vaut zéro

b) si way == ios_base::cur, alors newoff est la position courante du pointeur (gptr() - eback() ou pptr() - pbase())

c) si way == ios_base::end, alors newoff est la longueur de la partie initialisée entière du tampon (si une surallocation est utilisée, le pointeur de marque haute moins le pointeur de début)

  1. Si newoff + off est négatif ou hors des limites de la partie initialisée du tampon, la fonction échoue

  2. Sinon, le pointeur est affecté comme par gptr() = eback() + newoff + off ou pptr() = pbase() + newoff + off

Paramètres

  • off — position relative à laquelle définir le ou les pointeurs suivants

  • way — définit la position de base à laquelle appliquer le décalage relatif. Elle peut être l'une des constantes suivantes :

    Constante Explication

    • beg — le début d'un flux
    • end — la fin d'un flux
    • cur — la position courante de l'indicateur de position du flux

  • which — définit si les séquences d'entrée, la séquence de sortie, ou les deux sont affectées. Il peut s'agir de l'une des constantes suivantes ou d'une combinaison de celles-ci :

    Constante Explication

    • in — affecte la séquence d'entrée
    • out — affecte la séquence de sortie

Valeur de retour

pos_type(newoff) en cas de succès, pos_type(off_type(-1)) en cas d'échec et si pos_type ne peut pas représenter la position de flux résultante.

Exemple

#include <iostream>
#include <strstream>

int main()
{
    char a[] = "123";
    std::strstream ss(a, sizeof a); // entrée/sortie
    std::cout << "put pos = " << ss.tellp()
              << " get pos = " << ss.tellg() << '\n';

    // positionnement absolu des deux pointeurs
    ss.rdbuf()->pubseekoff(1, std::ios_base::beg); // avancer les deux
    std::cout << "put pos = " << ss.tellp()
              << " get pos = " << ss.tellg() << '\n';

    // essayer de déplacer les deux pointeurs de 1 vers l'avant depuis la position courante
    if (-1 == ss.rdbuf()->pubseekoff(1, std::ios_base::cur))
        std::cout << "moving both pointers from current position failed\n";
    std::cout << "put pos = " << ss.tellp()
              << " get pos = " << ss.tellg() << '\n';

    // déplacer le pointeur d'écriture de 1 vers l'avant, mais pas le pointeur de lecture
    // peut aussi être appelé ainsi : ss.seekp(1, std::ios_base::cur);
    ss.rdbuf()->pubseekoff(1, std::ios_base::cur, std::ios_base::out);
    std::cout << "put pos = " << ss.tellp()
              << " get pos = " << ss.tellg() << '\n';

    ss << 'a'; // écrire à la position d'écriture
    std::cout << "Wrote 'a' at put position, the buffer is now: '";
    std::cout.write(a, sizeof a);
    std::cout << "'\n";

    char ch;
    ss >> ch;
    std::cout << "reading at get position gives '" << ch << "'\n";
}

Output:

put pos = 0 get pos = 0
put pos = 1 get pos = 1
moving both pointers from current position failed
put pos = 1 get pos = 1
put pos = 2 get pos = 1
Wrote 'a' at put position, the buffer is now: '12a'
reading at get position gives '2'

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 55 C++98 seekoff renvoie une position de flux non définie invalide en cas d'échec pos_type(off_type(-1)) est renvoyé en cas d'échec
