C++ keyword: struct

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Utilisation

  • déclaration d'un type composé
  • déclaration d'une énumération à portée

(depuis C++11)

  • Si une fonction ou une variable existe dans la portée avec un nom identique à celui d'un type classe non union, struct peut être placé devant le nom pour lever l'ambiguïté, ce qui donne un spécificateur de type élaboré.

Exemple

struct Foo; // déclaration anticipée d'une struct

struct Bar  // définition d'une struct
{
    Bar(int i) : i(i + i) {}

    int i;
};

enum struct Pub // énumération à portée, depuis C++11
{
    b, d, p, q,
};

int main()
{
    Bar Bar(1);
    struct Bar Bar2(2); // type élaboré
}
