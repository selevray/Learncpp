C++ keyword: asm

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Utilisation

  • Déclaration d'un bloc d'assemblage en ligne

Exemple

Notez que, bien que cet exemple fonctionne bien avec GCC/Clang sur la plateforme x86_64 sous Linux, ce n'est pas garanti ailleurs, car la déclaration asm est conditionnellement supportée et (depuis C++11) définie par l'implémentation.

#include <cstring>

int main() noexcept
{
    const char* const c_string = "Hello, world!\n";
    asm
    (R"(
        movq $1, %%rax                 # syscall number for sys_write
        movq $1, %%rdi                 # file descriptor 1 (stdout)
        movq %0, %%rsi                 # pointer to the c‐string
        movq %1, %%rdx                 # length of the c‐string
        syscall                        # invokes an OS system-call handler
    )"
    :                                  // aucun opérande de sortie
    :   "r"(c_string),                 // entrée : pointeur vers la c‐chaîne
        "r"(std::strlen(c_string))     // entrée : taille de la c‐chaîne
    :   "%rax", "%rdi", "%rsi", "%rdx" // registres altérés
    );
}

Output:

Hello, world!
