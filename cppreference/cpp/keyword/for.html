C++ keyword: for

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Utilisation

  • Boucle for : comme déclaration de la boucle
  • boucle for basée sur un intervalle : comme déclaration de la boucle

(depuis C++11)

Exemple

#include <iostream>

int main() noexcept
{
    // La boucle 'for' suivante :
    // 1. (init-statement) Déclare un entier nommé 'i' et l'initialise avec la valeur '0'.
    // 2. (condition)      Vérifie si i est inférieur à 3 et, sinon, termine l'exécution de la boucle.
    // 3. (statement)      Écrit la valeur courante de l'entier 'i' sur stdout.
    // 4. (expression)     Pré-incrémente l'entier 'i' (augmente sa valeur de 1).
    // 5.                  Retourne au point 2 (condition).

                                // init-statement: int i{0};
                                // condition:      i < 3
    for (int i{0}; i < 3; ++i)  // expression:     ++i
        std::cout << i;         // statement:      std::cout << i;
}

Output:

012
