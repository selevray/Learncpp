C++ keyword: export

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Utilisation

Utilisé pour marquer une définition de modèle exportée, ce qui permet de déclarer, mais non définir, le même modèle dans d'autres unités de traduction.

(jusqu'à C++11)

Le mot-clé est inutilisé et réservé.

(depuis C++11) (jusqu'à C++20)

Marque une déclaration, un groupe de déclarations ou un autre module comme exporté par le module courant.

(depuis C++20)
