C++ keyword: class

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Utilisation

  • déclaration d'une classe
  • déclaration d'une énumération à portée

(depuis C++11)

  • Dans une déclaration de modèle, class peut être utilisé pour introduire des paramètres de modèle de type et des paramètres de modèle template
  • Si une fonction ou une variable de même nom qu'un type de classe existe dans la portée, class peut être placé devant le nom pour lever l'ambiguïté, ce qui produit un spécificateur de type élaboré

Exemple

class Foo; // déclaration anticipée d'une classe

class Bar  // définition d'une classe
{
public:
    Bar(int i) : m_i(i) {}
private:
    int m_i;
};

template<class T> // argument de modèle
void qux()
{
    T t;
}

enum class Pub // énumération à portée, depuis C++11
{
    b, d, p, q
};

int main()
{
    Bar Bar(1); // la variable Bar masque le type Bar
    Bar Bar2(2); // erreur de compilation
    class Bar Bar3(3); // type élaboré
}
