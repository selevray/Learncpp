C++ keyword: while

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Utilisation

  • Boucle while : comme déclaration de la boucle
  • boucle do-while : comme déclaration de la condition de fin de la boucle

Exemple

#include <iostream>

int main() noexcept
{
    int i{3};

    // La boucle 'while' suivante :
    // 1. (condition) Vérifie si la valeur de la variable 'i' est supérieure à zéro
    //                et si ce n'est pas le cas, termine l'exécution de la boucle à ce point.
    //                Décrémente après usage la variable 'i' (diminue sa valeur de 1).
    // 2. (instruction) Écrit la valeur courante de la variable 'i' sur stdout.
    // 3.             Retourne au point 1 (condition).

    while (i --> 0)     // condition: i-- > 0
        std::cout << i; // statement: std::cout << i;
}

Output:

210
