C++ keyword: return

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Utilisation

  • return instruction : comme déclaration de l'instruction

Exemple

#include <cstdlib>
#include <iostream>

[[nodiscard]] constexpr auto clamp(int value, int min, int max) noexcept
{
    if (value <= min)
        return min;
    else if (max <= value)
        return max;

    return value;
    // ne sera pas exécuté après l'instruction 'return'

    std::exit(value);
}

int main() noexcept
{
    std::cout << clamp(1, 2, 4);
    std::cout << clamp(3, 2, 4);
    std::cout << clamp(5, 2, 4);

    return 0; // la valeur '0' qui dans main() indique un succès
}

Output:

234
