C++ keyword: continue

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Utilisation

  • continue instruction : comme déclaration de l'instruction

Exemple

#include <iostream>
#include <string>

[[nodiscard]] constexpr auto get_digits(const std::string& string) noexcept
{
    std::string digits{};

    for (const auto& character: string)
    {
        if (character < '0' || character > '9') [[likely]]
            continue; // saute conditionnellement l'instruction suivante
        digits += character;
    }

    return digits;
}

int main() noexcept
{
    std::cout << get_digits("H3LL0, W0RLD!");
}

Output:

300
