Mot-clé C++ : reflexpr (TS reflection)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Utilisation

  1. Obtient la liste des membres d'un type class, ou la liste des énumérateurs d'un type enum.

  2. Obtient le nom du type et du membre.

  3. Détecte si un membre de données est static ou constexpr.

  4. Détecte si une fonction membre est virtual, public, protected ou private.

  5. Obtient la ligne et la colonne du code source lorsque le type est défini.

Exemple

reflexpr fournit les méta-informations de l'objet via les types méta-objets. Notez que std::reflect::get_data_members_t permet aux programmeurs de parcourir n'importe quelle classe, comme std::tuple.

#include <string>
#include <vector>

struct S
{
    int b;
    std::string s;
    std::vector<std::string> v;
};

// Reflection TS
#include <experimental/reflect>
using meta_S = reflexpr(S);
using mem = std::reflect::get_data_members_t<meta_S>;
using meta = std::reflect::get_data_members_t<mem>;
static_assert(std::reflect::is_public_v<meta>); // successful

int main() {}

Nous pouvons aussi connaître les informations de nom à partir de reflexpr :

#include <iostream>
#include <string>
#include <string_view>
// Reflection TS
#include <experimental/reflect>

template<typename Tp>
constexpr std::string_view nameof()
{
    using TpInfo = reflexpr(Tp);
    using aliased_Info = std::experimental::reflect::get_aliased_t<TpInfo>;
    return std::experimental::reflect::get_name_v<aliased_Info>;
}

int main()
{
    std::cout << nameof<std::string>() << '\n';
    static_assert(nameof<std::string>() == "basic_string"); // successful
}

Ceci est un exemple d'obtention de la portée d'un type dans la Reflection TS.

namespace Foo
{
    struct FooFoo
    {
        int FooFooFoo;
    };
}
namespace Bar
{
    using BarBar = ::Foo::FooFoo;
}
using BarBarInfo = reflexpr(::Bar::BarBar);
using BarBarScope = ::std::experimental::reflect::get_scope_t<BarBarInfo>; // Bar, pas Foo

struct Spam
{
    int SpamSpam;
};
struct Grok
{
    using GrokGrok = Spam::SpamSpam;
};
using GrokGrokInfo = reflexpr(::Grok::GrokGrok);
using GrokGrokScope = std::experimental::reflect::get_scope_t<GrokGrokInfo>; // Grok, pas Spam
