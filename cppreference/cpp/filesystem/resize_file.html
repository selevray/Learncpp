std::filesystem::resize_file

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <filesystem>

void resize_file( const std::filesystem::path& p,
                  std::uintmax_t new_size );  // (1) (depuis C++17)

void resize_file( const std::filesystem::path& p,
                  std::uintmax_t new_size,
                  std::error_code& ec ) noexcept;  // (2) (depuis C++17)

Modifie la taille du fichier régulier nommé par p, comme le fait POSIX truncate : si la taille du fichier était auparavant supérieure à new_size, le reste du fichier est supprimé. Si le fichier était auparavant plus petit que new_size, sa taille est augmentée et la nouvelle zone apparaît remplie de zéros.

Paramètres

  • p — chemin du fichier à redimensionner
  • new_size — taille que le fichier aura désormais
  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

Valeur de retour

(aucune)

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

  1. Lève std::filesystem::filesystem_error en cas d'erreur de l'API système sous-jacente, construite avec p comme premier argument de chemin et le code d'erreur du système comme argument de code d'erreur.

  2. Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.

Notes

Sur les systèmes qui prennent en charge les fichiers creux, l'augmentation de la taille du fichier n'augmente pas l'espace qu'il occupe sur le système de fichiers : l'allocation d'espace n'a lieu que lorsque des octets non nuls sont écrits dans le fichier.

Exemple

Montre l'effet qu'a la création d'un fichier creux sur l'espace libre.

#include <filesystem>
#include <fstream>
#include <iostream>
#include <locale>

int main()
{
    auto p = std::filesystem::temp_directory_path() / "example.bin";
    std::ofstream{p}.put('a');
    std::cout.imbue(std::locale{"en_US.UTF8"});
    std::cout << "File size:  " << std::filesystem::file_size(p) << '\n'
              << "Free space: " << std::filesystem::space(p).free << '\n';
    std::filesystem::resize_file(p, 64*1024); // redimensionne à 64 Ko
    std::cout << "File size:  " << std::filesystem::file_size(p) << '\n'
              << "Free space: " << std::filesystem::space(p).free << '\n';
    std::filesystem::remove(p);
}
