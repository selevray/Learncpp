std::filesystem::exists

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <filesystem>

bool exists( std::filesystem::file_status s ) noexcept;  // (1) (depuis C++17)

bool exists( const std::filesystem::path& p );  // (2) (depuis C++17)

bool exists( const std::filesystem::path& p, std::error_code& ec ) noexcept;  // (3) (depuis C++17)

Vérifie si le statut de fichier ou le chemin donné correspond à un fichier ou répertoire existant.

  1. Équivalent à status_known(s) && s.type() != file_type::not_found.

2,3) Soit s un std::filesystem::file_status déterminé comme si par status(p) ou status(p, ec) (les liens symboliques sont suivis), respectivement. Renvoie exists(s). La surcharge sans exception appelle ec.clear() si status_known(s).

Paramètres

  • s — statut de fichier à vérifier
  • p — chemin à examiner
  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

Valeur de retour

true si le chemin ou le statut de fichier donné correspond à un fichier ou répertoire existant, false sinon.

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

  1. Lève std::filesystem::filesystem_error en cas d'erreur de l'API système sous-jacente, construite avec p comme premier argument de chemin et le code d'erreur du système comme argument de code d'erreur.

  2. Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.

Aucune exception du système de fichiers n'est levée si l'objet n'existe pas (utiliser la valeur de retour).

Notes

Les informations fournies par cette fonction sont généralement aussi fournies comme sous-produit de l'itération sur les répertoires. Pendant l'itération sur les répertoires, appeler exists(*iterator) est moins efficace que exists(iterator->status()).

Exemple

#include <cstdint>
#include <filesystem>
#include <fstream>
#include <iostream>
namespace fs = std::filesystem;

void demo_exists(const fs::path& p, fs::file_status s = fs::file_status{})
{
    std::cout << p;
    if (fs::status_known(s) ? fs::exists(s) : fs::exists(p))
        std::cout << " exists\n";
    else
        std::cout << " does not exist\n";
}

int main()
{
    const fs::path sandbox{"sandbox"};
    fs::create_directory(sandbox);
    std::ofstream{sandbox/"file"}; // créer un fichier régulier
    fs::create_symlink("non-existing", sandbox/"symlink");

    demo_exists(sandbox);

    for (const auto& entry : fs::directory_iterator(sandbox))
        demo_exists(entry, entry.status()); // utiliser le statut mis en cache de l'entrée de répertoire

    fs::remove_all(sandbox);
}

Output:

"sandbox" exists
"sandbox/symlink" does not exist
"sandbox/file" exists
