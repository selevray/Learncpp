Renvoie ou modifie le chemin courant.

1,2) Renvoie le chemin absolu du répertoire de travail courant, obtenu comme si (au format natif) par POSIX getcwd. (2) renvoie path() si une erreur survient.

3,4) Change le répertoire de travail courant pour p, comme si par POSIX chdir.

Paramètres

  • p — chemin vers lequel modifier le répertoire de travail courant
  • ec — paramètre de sortie pour le rapport des erreurs dans les surcharges sans exception

Valeur de retour

1,2) Renvoie le répertoire de travail courant.

3,4) (aucun)

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

  1. Lève std::filesystem::filesystem_error en cas d'erreurs de l'API OS sous-jacente, construite avec le code d'erreur OS comme argument de code d'erreur.

  2. Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.

  3. Lève std::filesystem::filesystem_error en cas d'erreur de l'API système sous-jacente, construite avec p comme premier argument de chemin et le code d'erreur du système comme argument de code d'erreur.

  4. Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.

Notes

Le répertoire de travail courant est le répertoire, associé au processus, qui sert de point de départ à la résolution des chemins relatifs.

Le chemin courant, tel que renvoyé par de nombreux systèmes d'exploitation, est une variable globale dangereuse. Il peut être modifié de façon inattendue par des fonctions de bibliothèques tierces ou système, ou par un autre thread.

Exemple

#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;

int main()
{
    std::cout << "Current path is " << fs::current_path() << '\n'; // (1)
    fs::current_path(fs::temp_directory_path()); // (3)
    std::cout << "Current path is " << fs::current_path() << '\n';
}

Sortie possible :

Current path is "D:/local/ConsoleApplication1"
Current path is "E:/Temp"
