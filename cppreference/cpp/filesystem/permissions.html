Modifie les permissions d'accès du fichier vers lequel p se résout, comme le ferait POSIX fchmodat. Les liens symboliques sont suivis sauf si perm_options::nofollow est défini dans opts.

La seconde signature se comporte comme si elle était appelée avec opts défini à perm_options::replace.

Les effets dépendent de prms et opts comme suit :

  • Si opts vaut perm_options::replace, les permissions du fichier sont définies exactement à prms & std::filesystem::perms::mask (c'est-à-dire que chaque bit valide de prms est appliqué).
  • Si opts vaut perm_options::add, les permissions du fichier sont définies exactement à status(p).permissions() | (prms & perms::mask) (c'est-à-dire que tout bit valide activé dans prms mais pas dans les permissions actuelles du fichier est ajouté aux permissions du fichier).
  • Si opts vaut perm_options::remove, les permissions du fichier sont définies exactement à status(p).permissions() & ~(prms & perms::mask) (c'est-à-dire que tout bit valide désactivé dans prms mais activé dans les permissions actuelles du fichier est retiré des permissions du fichier).

opts doit n'avoir qu'un seul des éléments replace, add ou remove défini.

La surcharge sans exception ne prend aucune action particulière en cas d'erreur.

Paramètres

  • p — chemin à examiner
  • prms — permissions à définir, ajouter ou retirer
  • opts — options contrôlant l'action effectuée par cette fonction
  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

(aucune)

Notes

Les permissions ne sont pas nécessairement implémentées sous forme de bits, mais elles sont conceptuellement traitées de cette façon.

Certains bits de permission peuvent être ignorés sur certains systèmes, et la modification de certains bits peut en modifier automatiquement d'autres (par exemple, sur les plateformes ne distinguant pas propriétaire/groupe/tous, définir l'un des trois bits d'écriture définit les trois).

Exemple

#include <filesystem>
#include <fstream>
#include <iostream>

void demo_perms(std::filesystem::perms p)
{
    using std::filesystem::perms;
    auto show = [=](char op, perms perm)
    {
        std::cout << (perms::none == (perm & p) ? '-' : op);
    };
    show('r', perms::owner_read);
    show('w', perms::owner_write);
    show('x', perms::owner_exec);
    show('r', perms::group_read);
    show('w', perms::group_write);
    show('x', perms::group_exec);
    show('r', perms::others_read);
    show('w', perms::others_write);
    show('x', perms::others_exec);
    std::cout << '\n';
}

int main()
{
    std::ofstream("test.txt"); // créer un fichier

    std::cout << "Created file with permissions: ";
    demo_perms(std::filesystem::status("test.txt").permissions());

    std::filesystem::permissions(
        "test.txt",
        std::filesystem::perms::owner_all | std::filesystem::perms::group_all,
        std::filesystem::perm_options::add
    );

    std::cout << "After adding u+rwx and g+rwx:  ";
    demo_perms(std::filesystem::status("test.txt").permissions());

    std::filesystem::remove("test.txt");
}

Sortie possible :

Created file with permissions: rw-r--r--
After adding u+rwx and g+wrx:  rwxrwxr--
