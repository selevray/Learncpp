Paramètres

  • p — chemin vers l'objet du système de fichiers que l'itérateur de répertoire référencera
  • ec — paramètre de sortie pour le rapport des erreurs dans les surcharges sans exception
  • options — l'ensemble des options BitmaskType qui contrôlent le comportement de l'itérateur de répertoire
  • other — un autre itérateur de répertoire servant de source pour initialiser l'itérateur de répertoire

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

4,5) Lève std::filesystem::filesystem_error en cas d'erreur de l'API système sous-jacente, construite avec p comme premier argument de chemin et le code d'erreur du système comme argument de code d'erreur.

6,7) Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.

Notes

Les itérateurs de répertoire récursifs ne suivent pas les liens symboliques de répertoires par défaut. Pour activer ce comportement, spécifier directory_options::follow_directory_symlink parmi l'ensemble d'options options.
