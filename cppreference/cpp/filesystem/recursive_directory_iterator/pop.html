std::filesystem::recursive_directory_iterator::pop

void pop( std::error_code& ec );  // (2) (depuis C++17)

Déplace l'itérateur d'un niveau vers le haut dans la hiérarchie des répertoires. Invalide toutes les copies de la valeur précédente de *this.

Si le répertoire parent est en dehors de la hiérarchie de répertoires parcourue (c.-à-d. depth() == 0), définit *this comme itérateur de fin de répertoire.

Paramètres

  • ec — code d'erreur dans lequel stocker l'état de l'erreur

Valeur de retour

(aucune)

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

  1. Lève std::filesystem::filesystem_error en cas d'erreurs de l'API OS sous-jacente, construite avec le code d'erreur OS comme argument de code d'erreur.

  2. Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.
