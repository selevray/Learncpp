Fait avancer l'itérateur vers l'entrée suivante. Invalide toutes les copies de la valeur précédente de *this.

S'il ne reste plus d'entrées dans le répertoire actuellement parcouru, le parcours reprend dans le répertoire parent. Le processus est répété si le répertoire parent n'a pas d'entrées sœurs pouvant être parcourues. Si le parent de la hiérarchie de répertoires parcourue récursivement est atteint (il n'existe aucune entrée candidate à depth() == 0)), *this est défini comme itérateur de fin.

Sinon, si *this désigne un répertoire, on le parcourt si les conditions suivantes sont remplies :

  • disable_recursion_pending() n'a pas été appelé avant cet incrément, c'est-à-dire recursion_pending() == true.
  • Le répertoire n'est pas un lien symbolique ou le suivi des liens symboliques est activé, c'est-à-dire qu'au moins une des conditions suivantes est vraie :
    • !is_symlink((*this)->symlink_status()).
    • (options() & directory_options::follow_directory_symlink) != directory_options::none)

Paramètres

  • ec — code d'erreur dans lequel stocker l'état de l'erreur

Valeur de retour

*this

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

  1. Lève std::filesystem::filesystem_error en cas d'erreurs de l'API OS sous-jacente, construite avec le code d'erreur OS comme argument de code d'erreur.

  2. Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.
