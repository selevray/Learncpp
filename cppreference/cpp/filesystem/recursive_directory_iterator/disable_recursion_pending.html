std::filesystem::recursive_directory_iterator::disable_recursion_pending

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void disable_recursion_pending();  // (depuis C++17)

Désactive la récursion vers le sous-répertoire actuellement référencé, le cas échéant.

L'appel modifie l'indicateur de récursion en attente de l'itérateur de sorte que, la prochaine fois que increment sera appelé, l'itérateur avancera au sein du répertoire courant, même s'il désigne actuellement un sous-répertoire non encore visité.

L'état de l'indicateur de récursion en attente peut être interrogé avec recursion_pending(), qui vaut false après cet appel. Il est réinitialisé à true après increment, et sa valeur initiale est également true.

Le comportement est indéfini si *this est l'itérateur de fin.

Paramètres

(aucune)

Valeur de retour

(aucune)

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <cstdlib>
#include <filesystem>
#include <fstream>
#include <iostream>
#include <string>
namespace fs = std::filesystem;

int main()
{
    fs::current_path(fs::temp_directory_path());
    fs::create_directories("sandbox/a/b/c");
    fs::create_directories("sandbox/a/b/d/e");
    std::ofstream("sandbox/a/b/file1.txt");
    fs::create_symlink("a", "sandbox/syma");
    std::system("tree sandbox");
    for (auto i = fs::recursive_directory_iterator("sandbox");
         i != fs::recursive_directory_iterator();
         ++i)
    {
        std::cout << std::string(i.depth() * 2, ' ') << *i;
        if (fs::is_symlink(i->symlink_status()))
            std::cout << " -> " << fs::read_symlink(*i);
        std::cout << '\n';

        // ne pas descendre dans « b »
        if (i->path().filename() == "b")
            i.disable_recursion_pending();
    }
    fs::remove_all("sandbox");
}
