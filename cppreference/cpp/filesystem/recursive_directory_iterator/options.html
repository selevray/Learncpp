std::filesystem::directory_options options() const;  // (depuis C++17)

Renvoie les options qui affectent le parcours du répertoire. Les options ne peuvent être fournies qu'à la construction de l'itérateur de répertoire.

Si l'argument options n'a pas été fourni, renvoie std::filesystem::directory_options::none.

Paramètres

(aucune)

Valeur de retour

Les options effectives qui affectent le parcours du répertoire.

Exceptions

Ne lève aucune exception.
