bool recursion_pending() const;  // (depuis C++17)

Renvoie true si l'incrément suivant entraînera le parcours du répertoire actuellement référencé par *this.

Cette fonction renvoie true immédiatement après la construction ou un incrément. La récursion peut être désactivée via disable_recursion_pending().

Paramètres

(aucune)

Valeur de retour

true si l'incrément suivant parcourra le répertoire actuellement référencé, false sinon.

Exceptions

Ne lève aucune exception.
