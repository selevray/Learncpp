std::filesystem::recursive_directory_iterator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <filesystem>

class recursive_directory_iterator;  // (depuis C++17)

recursive_directory_iterator est un LegacyInputIterator qui parcourt les éléments directory_entry d'un répertoire, et, récursivement, les entrées de tous les sous-répertoires. L'ordre de parcours n'est pas spécifié, sauf que chaque entrée de répertoire n'est visitée qu'une seule fois.

Par défaut, les liens symboliques ne sont pas suivis, mais cela peut être activé en spécifiant l'option de répertoire follow_directory_symlink à la construction.

Les chemins spéciaux dot et dot-dot sont ignorés.

Si recursive_directory_iterator signale une erreur ou est avancé au-delà de la dernière entrée du répertoire de plus haut niveau, il devient égal à l'itérateur construit par défaut, aussi appelé itérateur de fin. Deux itérateurs de fin sont toujours égaux ; déréférencer ou incrémenter l'itérateur de fin est un comportement indéfini.

Si un fichier ou un répertoire est supprimé ou ajouté à l'arborescence après la création de l'itérateur de répertoire récursif, il n'est pas spécifié si ce changement sera observé par l'itérateur.

Si la structure des répertoires contient des cycles, l'itérateur de fin peut être inaccessible.

Ces spécialisations pour recursive_directory_iterator en font un borrowed_range et un view.

Notes

Un recursive_directory_iterator détient typiquement un pointeur à comptage de références (pour satisfaire la sémantique de copie superficielle de LegacyInputIterator) vers un objet d'implémentation, qui contient :

  • un conteneur (tel que std::vector) de directory_iterators non récursifs qui forme la pile de récursion,
  • le compteur de profondeur de récursion (accessible avec depth()),
  • les options de répertoire utilisées lors de la construction (accessibles avec options()),
  • l'indicateur de récursion en attente (accessible avec recursion_pending(), peut être combiné avec les options de répertoire pour économiser de l'espace).

Exemple

#include <filesystem>
#include <fstream>
#include <iostream>
#include <string>
namespace fs = std::filesystem;

int main()
{
    std::filesystem::current_path(std::filesystem::temp_directory_path());
    std::filesystem::create_directories("sandbox/a/b");
    std::ofstream("sandbox/file1.txt");
    std::filesystem::create_symlink("a", "sandbox/syma");

    // Itérer explicitement sur les éléments std::filesystem::directory_entry
    auto entry_length{3UZ};
    for (const fs::directory_entry& dir_entry :
            fs::recursive_directory_iterator("sandbox"))
    {
        std::cout << dir_entry << '\n';
        if (auto l{dir_entry.path().string().length()}; entry_length < l)
            entry_length = l;
    }
    std::cout << std::string(entry_length + 2, '-') << '\n';

    // Itérer sur les éléments std::filesystem::directory_entry en utilisant `auto`
    for (auto const& dir_entry : fs::recursive_directory_iterator("sandbox"))
        std::cout << dir_entry << '\n';

    std::filesystem::remove_all("sandbox");
}
