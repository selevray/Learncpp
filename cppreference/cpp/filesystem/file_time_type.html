std::filesystem::file_time_type

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <filesystem>

using file_time_type = std::chrono::time_point</*trivial-clock*/>;  // (depuis C++17) (jusqu'à C++20)

using file_time_type = std::chrono::time_point<std::chrono::file_clock>;  // (depuis C++20)

Représente l'heure d'un fichier.

/*trivial-clock*/ est un type défini par l'implémentation qui satisfait TrivialClock et qui suffit à représenter la résolution et la plage des valeurs de temps de fichier offertes par le système de fichiers.

(jusqu'à C++20)

Exemple

#include <chrono>
#include <filesystem>
#include <format>
#include <fstream>
#include <iostream>

using namespace std::chrono_literals;

int main()
{
    auto p = std::filesystem::temp_directory_path() / "example.bin";
    std::ofstream{p.c_str()}.put('a'); // créer un fichier

    std::filesystem::file_time_type ftime = std::filesystem::last_write_time(p);
    std::cout << std::format("File write time is {}\n", ftime);

    // déplacer l'heure d'écriture du fichier d'une heure dans le futur
    std::filesystem::last_write_time(p, ftime + 1h);

    // relire depuis le système de fichiers
    ftime = std::filesystem::last_write_time(p);
    std::cout << std::format("File write time is {}\n", ftime);

    std::filesystem::remove(p);
}

Sortie possible :

File write time is 2023-09-04 19:33:24.702639224
File write time is 2023-09-04 20:33:24.702639224
