enum class perms;  // (depuis C++17)

Ce type représente les permissions d'accès aux fichiers.

perms satisfait les exigences de BitmaskType (ce qui signifie que les opérateurs binaires operator&, operator|, operator^, operator~, operator&=, operator|= et operator^= sont définis pour ce type). none représente le masque de bits vide ; chaque autre énumérateur représente un élément de masque de bits distinct.

Les permissions d'accès modélisent les bits de permission POSIX, et chaque permission individuelle de fichier (telle que rapportée par filesystem::status) est une combinaison de certains des bits suivants :

Constantes membres

Constante membre | Valeur (octal) | Équivalent POSIX | Signification

none | 0 | Aucun bit de permission n'est défini

owner_read | 0400 | S_IRUSR | Le propriétaire du fichier a la permission de lecture

owner_write | 0200 | S_IWUSR | Le propriétaire du fichier a la permission d'écriture

owner_exec | 0100 | S_IXUSR | Le propriétaire du fichier a la permission d'exécution/recherche

owner_all | 0700 | S_IRWXU | Le propriétaire du fichier a les permissions de lecture, d'écriture et d'exécution/recherche

Équivalent à owner_read | owner_write | owner_exec

group_read | 040 | S_IRGRP | Le groupe d'utilisateurs du fichier a la permission de lecture

group_write | 020 | S_IWGRP | Le groupe d'utilisateurs du fichier a la permission d'écriture

group_exec | 010 | S_IXGRP | Le groupe d'utilisateurs du fichier a la permission d'exécution/recherche

group_all | 070 | S_IRWXG | Le groupe d'utilisateurs du fichier a les permissions de lecture, d'écriture et d'exécution/recherche

Équivalent à group_read | group_write | group_exec

others_read | 04 | S_IROTH | Les autres utilisateurs ont la permission de lecture

others_write | 02 | S_IWOTH | Les autres utilisateurs ont la permission d'écriture

others_exec | 01 | S_IXOTH | Les autres utilisateurs ont la permission d'exécution/recherche

others_all | 07 | S_IRWXO | Les autres utilisateurs ont les permissions de lecture, d'écriture et d'exécution/recherche

Équivalent à others_read | others_write | others_exec

all | 0777 | Tous les utilisateurs ont les permissions de lecture, d'écriture et d'exécution/recherche

Équivalent à owner_all | group_all | others_all

set_uid | 04000 | S_ISUID | Définit l'identifiant utilisateur sur celui du propriétaire du fichier lors de l'exécution

set_gid | 02000 | S_ISGID | Définit l'identifiant de groupe sur celui du groupe d'utilisateurs du fichier lors de l'exécution

sticky_bit | 01000 | S_ISVTX | Signification définie par l'implémentation, mais POSIX XSI précise que, lorsqu'il est défini sur un répertoire, seuls les propriétaires des fichiers peuvent supprimer des fichiers, même si le répertoire est accessible en écriture aux autres (utilisé avec /tmp)

mask | 07777 | Tous les bits de permission valides.

Équivalent à all | set_uid | set_gid | sticky_bit

De plus, les constantes suivantes de ce type sont définies ; elles ne représentent pas des permissions :

Constante membre Valeur (hexadécimal) Signification
unknown 0xFFFF Permissions inconnues (par ex. lorsque filesystem::file_status est créé sans permissions)

Notes

Les permissions ne sont pas nécessairement implémentées sous forme de bits, mais elles sont conceptuellement traitées de cette façon.

Certains bits de permission peuvent être ignorés sur certains systèmes, et la modification de certains bits peut en modifier automatiquement d'autres (par exemple, sur les plateformes ne distinguant pas propriétaire/groupe/tous, définir l'un des trois bits d'écriture définit les trois).

Exemple

#include <filesystem>
#include <fstream>
#include <iostream>

void demo_perms(std::filesystem::perms p)
{
    using std::filesystem::perms;
    auto show = [=](char op, perms perm)
    {
        std::cout << (perms::none == (perm & p) ? '-' : op);
    };
    show('r', perms::owner_read);
    show('w', perms::owner_write);
    show('x', perms::owner_exec);
    show('r', perms::group_read);
    show('w', perms::group_write);
    show('x', perms::group_exec);
    show('r', perms::others_read);
    show('w', perms::others_write);
    show('x', perms::others_exec);
    std::cout << '\n';
}

int main()
{
    std::ofstream("test.txt"); // créer un fichier

    std::cout << "Created file with permissions: ";
    demo_perms(std::filesystem::status("test.txt").permissions());

    std::filesystem::permissions(
        "test.txt",
        std::filesystem::perms::owner_all | std::filesystem::perms::group_all,
        std::filesystem::perm_options::add
    );

    std::cout << "After adding u+rwx and g+rwx:  ";
    demo_perms(std::filesystem::status("test.txt").permissions());

    std::filesystem::remove("test.txt");
}

Sortie possible :

Created file with permissions: rw-r--r--
After adding u+rwx and g+wrx:  rwxrwxr--
