1,2) Détermine le type et les attributs de l'objet du système de fichiers identifié par p, comme le fait POSIX stat (les liens symboliques sont suivis jusqu'à leur cible). Dans la description suivante, prms est le résultat de (m & perms::mask), où m est obtenu comme si l'on prenait st_mode de struct stat POSIX et qu'on le convertissait en type std::filesystem::perms.

  • Si p est un fichier régulier (comme le fait POSIX S_ISREG), renvoie file_status(file_type::regular, prms).
  • Si p est un répertoire (comme le fait POSIX S_ISDIR), renvoie file_status(file_type::directory, prms).
  • Si p est un fichier spécial de type bloc (comme le fait POSIX S_ISBLK), renvoie file_status(file_type::block, prms).
  • Si p est un fichier spécial de type caractère (comme le fait POSIX S_ISCHR), renvoie file_status(file_type::character, prms).
  • Si p est un fichier fifo ou un tube (comme le fait POSIX S_ISFIFO), renvoie file_status(file_type::fifo, prms).
  • Si p est un socket (comme le fait POSIX S_ISSOCK), renvoie file_status(file_type::socket, prms).
  • Si p a un type de fichier défini par l'implémentation, renvoie file_status(file_type::A, prms) où A est la constante file_type définie par l'implémentation pour ce type.
  • Si p n'existe pas, renvoie file_status(file_type::not_found).
  • Si p existe mais que ses attributs de fichier ne peuvent pas être déterminés, par exemple faute de permissions, renvoie file_status(file_type::unknown).
  • Si des erreurs empêchent même de savoir si p existe, la surcharge non lançante définit ec et renvoie file_status(file_type::none), et la surcharge lançante lève filesystem_error.
  • Sinon, renvoie file_status(file_type::unknown, prms).

3,4) Identique à (1,2), sauf que le comportement est celui de POSIX lstat (les liens symboliques ne sont pas suivis) :

  • Si p est un lien symbolique, renvoie file_status(file_type::symlink).

Paramètres

  • p — chemin à examiner
  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

Valeur de retour

L'état du fichier (un objet filesystem::file_status).

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

1,3) Lève std::filesystem::filesystem_error en cas d'erreur de l'API système sous-jacente, construite avec p comme premier argument de chemin et le code d'erreur du système comme argument de code d'erreur.

2,4) Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.

Notes

Les informations fournies par cette fonction sont généralement aussi fournies comme sous-produit de l'itération sur les répertoires, et peuvent être obtenues par les fonctions membres de filesystem::directory_entry. Pendant l'itération sur les répertoires, appeler status à nouveau est inutile.

Exemple

#include <cstdio>
#include <cstring>
#include <filesystem>
#include <fstream>
#include <iostream>
#include <sys/socket.h>
#include <sys/stat.h>
#include <sys/un.h>
#include <unistd.h>

namespace fs = std::filesystem;

void demo_status(const fs::path& p, fs::file_status s)
{
    std::cout << p;
    // alternative : switch(s.type()) { case fs::file_type::regular: ...}
    if (fs::is_regular_file(s))
        std::cout << " is a regular file\n";
    if (fs::is_directory(s))
        std::cout << " is a directory\n";
    if (fs::is_block_file(s))
        std::cout << " is a block device\n";
    if (fs::is_character_file(s))
        std::cout << " is a character device\n";
    if (fs::is_fifo(s))
        std::cout << " is a named IPC pipe\n";
    if (fs::is_socket(s))
        std::cout << " is a named IPC socket\n";
    if (fs::is_symlink(s))
        std::cout << " is a symlink\n";
    if (!fs::exists(s))
        std::cout << " does not exist\n";
}

int main()
{
    // créer des fichiers de différents types
    fs::create_directory("sandbox");
    fs::create_directory("sandbox/dir");
    std::ofstream{"sandbox/file"}; // créer un fichier régulier
    fs::create_symlink("file", "sandbox/symlink");

    mkfifo("sandbox/pipe", 0644);
    sockaddr_un addr;
    addr.sun_family = AF_UNIX;
    std::strcpy(addr.sun_path, "sandbox/sock");
    int fd = socket(PF_UNIX, SOCK_STREAM, 0);
    bind(fd, reinterpret_cast<sockaddr*>(&addr), sizeof addr);

    // démonstration des différents accesseurs de statut
    for (auto it{fs::directory_iterator("sandbox")}; it != fs::directory_iterator(); ++it)
        demo_status(*it, it->symlink_status()); // utiliser le statut mis en cache de l'entrée de répertoire
    demo_status("/dev/null", fs::status("/dev/null")); // appels directs à status
    demo_status("/dev/sda", fs::status("/dev/sda"));
    demo_status("sandbox/no", fs::status("/sandbox/no"));

    // nettoyage (préférer les suppresseurs personnalisés basés sur std::unique_ptr)
    close(fd);
    fs::remove_all("sandbox");
}

Sortie possible :

"sandbox/file" is a regular file
"sandbox/dir" is a directory
"sandbox/pipe" is a named IPC pipe
"sandbox/sock" is a named IPC socket
"sandbox/symlink" is a symlink
"/dev/null" is a character device
"/dev/sda" is a block device
"sandbox/no" does not exist
