std::filesystem::temp_directory_path

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <filesystem>

path temp_directory_path();  // (1) (depuis C++17)

path temp_directory_path( std::error_code& ec );  // (2) (depuis C++17)

Renvoie l'emplacement du répertoire adapté aux fichiers temporaires.

Paramètres

(aucune)

Valeur de retour

Un répertoire adapté aux fichiers temporaires. Le chemin est garanti d'exister et d'être un répertoire. La surcharge qui prend error_code& en argument renvoie un chemin vide en cas d'erreur.

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

  1. Lève std::filesystem::filesystem_error en cas d'erreur de l'API système sous-jacente, construite avec path to be returned comme premier argument de chemin et le code d'erreur du système comme argument de code d'erreur.

  2. Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.

Notes

Sur les systèmes POSIX, le chemin peut être celui spécifié dans les variables d'environnement TMPDIR, TMP, TEMP, TEMPDIR et, si aucune d'elles n'est spécifiée, le chemin "/tmp" est renvoyé.

Sur les systèmes Windows, le chemin est généralement celui renvoyé par GetTempPath.

Exemple

#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;

int main()
{
    std::cout << "Temp directory is " << fs::temp_directory_path() << '\n';
}

Sortie possible :

Temp directory is "C:\Windows\TEMP\"
