std::filesystem::is_other

bool is_other( std::filesystem::file_status s ) noexcept;  // (1) (depuis C++17)

Vérifie si le statut de fichier ou le chemin donné correspond à un fichier d'un type autre. C'est-à-dire que le fichier existe, mais n'est ni un fichier régulier, ni un répertoire, ni un lien symbolique.

  1. Équivalent à exists(s) && !is_regular_file(s) && !is_directory(s) && !is_symlink(s).

2,3) Équivalent à is_other(status(p)) ou is_other(status(p, ec)), respectivement.

Paramètres

  • s — statut de fichier à vérifier
  • p — chemin à examiner
  • ec — code d'erreur dans lequel stocker l'état de l'erreur

Valeur de retour

true si le fichier indiqué par p ou si le type indiqué par s désigne un fichier qui n'est ni un fichier régulier, ni un répertoire, ni un lien symbolique, false sinon. La surcharge ne lançant pas d'exception renvoie false si une erreur survient.

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

2,3) Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.
