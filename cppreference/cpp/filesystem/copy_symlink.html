void copy_symlink( const std::filesystem::path& from,
                   const std::filesystem::path& to,
                   std::error_code& ec ) noexcept;  // (2) (depuis C++17)

Copie un lien symbolique vers un autre emplacement.

  1. Appelle effectivement f(read_symlink(from), to) où f est create_symlink ou create_directory_symlink selon que from désigne un fichier ou un répertoire.

  2. Appelle effectivement f(read_symlink(from, ec), to, ec) où f est create_symlink ou create_directory_symlink selon que from désigne un fichier ou un répertoire.

Paramètres

  • from — chemin vers le lien symbolique à copier
  • to — chemin de destination du nouveau lien symbolique
  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

Valeur de retour

(aucune)

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

  1. Lève std::filesystem::filesystem_error en cas d'erreurs de l'API OS sous-jacente, construite avec from comme premier argument de chemin, to comme second argument de chemin, et le code d'erreur OS comme argument de code d'erreur.

  2. Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.
