std::filesystem::directory_entry::is_regular_file

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool is_regular_file() const;  // (1) (depuis C++17)

bool is_regular_file( std::error_code& ec ) const noexcept;  // (2) (depuis C++17)

Vérifie si l'objet pointé est un fichier régulier. Retourne effectivement :

  1. std::filesystem::is_regular_file(status()).

  2. std::filesystem::is_regular_file(status(ec)).

Paramètres

  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

Valeur de retour

true si l'objet du système de fichiers référencé est un fichier régulier, false sinon.

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

  1. Lève std::filesystem::filesystem_error en cas d'erreur de l'API système sous-jacente, construite avec p comme premier argument de chemin et le code d'erreur du système comme argument de code d'erreur.

  2. Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.

Exemple

#include <filesystem>
#include <iostream>
#include <string>

namespace fs = std::filesystem;

int main(int argc, const char* argv[])
{
    // Affiche tous les fichiers réguliers d'un répertoire 'dir'.
    try
    {
        const auto dir{argc == 2 ? fs::path{argv[1]} : fs::current_path()};

        std::cout << "Current dir: " << dir << '\n'
                  << std::string(40, '-') << '\n';

        for (fs::directory_entry const& entry : fs::directory_iterator(dir))
            if (entry.is_regular_file())
                std::cout << entry.path().filename() << '\n';
    }
    catch(const fs::filesystem_error& e)
    {
        std::cout << e.what() << '\n';
    }
}
