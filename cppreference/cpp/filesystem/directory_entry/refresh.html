std::filesystem::directory_entry::refresh

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void refresh();  // (1) (depuis C++17)

void refresh( std::error_code& ec ) noexcept;  // (2) (depuis C++17)

Examine l'objet du système de fichiers référencé par cette entrée de répertoire et stocke ses attributs pour les récupérer avec status, exists, is_regular_file, et les autres accesseurs d'état.

En cas d'erreur, la valeur de tous les attributs mis en cache est non spécifiée.

Paramètres

  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

Valeur de retour

(aucune)

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

  1. Lève std::filesystem::filesystem_error en cas d'erreur de l'API système sous-jacente, construite avec p comme premier argument de chemin et le code d'erreur du système comme argument de code d'erreur.

  2. Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.

Notes

De nombreuses API bas niveau du système d'exploitation pour parcourir un répertoire récupèrent les attributs des fichiers avec l'entrée de répertoire suivante. Les constructeurs et les fonctions membres non const de std::filesystem::directory_iterator stockent ces attributs, le cas échéant, dans le std::filesystem::directory_entry pointé sans appeler directory_entry::refresh, ce qui permet d'examiner les attributs des entrées de répertoire au fur et à mesure de leur itération, sans effectuer d'appels système supplémentaires.
