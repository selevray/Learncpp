std::filesystem::directory_entry::status, std::filesystem::directory_entry::symlink_status

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

std::filesystem::file_status status() const;  // (1) (depuis C++17)

std::filesystem::file_status status( std::error_code& ec ) const noexcept;  // (2) (depuis C++17)

std::filesystem::file_status symlink_status() const;  // (3) (depuis C++17)

1,2) Retourne l'état de l'entrée, comme déterminé par un appel à filesystem::status (les liens symboliques sont suivis jusqu'à leur cible).

3,4) Retourne l'état de l'entrée, comme déterminé par un appel à filesystem::symlink_status (les liens symboliques ne sont pas suivis).

Paramètres

  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

Valeur de retour

Le statut du fichier désigné par l'entrée.

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

1,3) Lève std::filesystem::filesystem_error en cas d'erreur de l'API système sous-jacente, construite avec p comme premier argument de chemin et le code d'erreur du système comme argument de code d'erreur.

2,4) Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.

Notes

De nombreuses API bas niveau du système d'exploitation pour parcourir un répertoire récupèrent les attributs des fichiers avec l'entrée de répertoire suivante. Les constructeurs et les fonctions membres non const de std::filesystem::directory_iterator stockent ces attributs, le cas échéant, dans le std::filesystem::directory_entry pointé sans appeler directory_entry::refresh, ce qui permet d'examiner les attributs des entrées de répertoire au fur et à mesure de leur itération, sans effectuer d'appels système supplémentaires.

Exemple

#include <cstdio>
#include <cstring>
#include <filesystem>
#include <fstream>
#include <iostream>
#include <sys/socket.h>
#include <sys/stat.h>
#include <sys/un.h>
#include <unistd.h>

namespace fs = std::filesystem;

void demo_status(const fs::path& p, fs::file_status s)
{
    std::cout << p;
    // alternative : switch(s.type()) { case fs::file_type::regular: ...}
    if (fs::is_regular_file(s))
        std::cout << " is a regular file\n";
    if (fs::is_directory(s))
        std::cout << " is a directory\n";
    if (fs::is_block_file(s))
        std::cout << " is a block device\n";
    if (fs::is_character_file(s))
        std::cout << " is a character device\n";
    if (fs::is_fifo(s))
        std::cout << " is a named IPC pipe\n";
    if (fs::is_socket(s))
        std::cout << " is a named IPC socket\n";
    if (fs::is_symlink(s))
        std::cout << " is a symlink\n";
    if (!fs::exists(s))
        std::cout << " does not exist\n";
}

int main()
{
    // créer des fichiers de différents types
    fs::create_directory("sandbox");
    fs::create_directory("sandbox/dir");
    std::ofstream{"sandbox/file"}; // créer un fichier régulier
    fs::create_symlink("file", "sandbox/symlink");

    mkfifo("sandbox/pipe", 0644);
    sockaddr_un addr;
    addr.sun_family = AF_UNIX;
    std::strcpy(addr.sun_path, "sandbox/sock");
    int fd = socket(PF_UNIX, SOCK_STREAM, 0);
    bind(fd, reinterpret_cast<sockaddr*>(&addr), sizeof addr);

    // démonstration des différents accesseurs de statut
    for (auto it{fs::directory_iterator("sandbox")}; it != fs::directory_iterator(); ++it)
        demo_status(*it, it->symlink_status()); // utiliser le statut mis en cache de l'entrée de répertoire
    demo_status("/dev/null", fs::status("/dev/null")); // appels directs à status
    demo_status("/dev/sda", fs::status("/dev/sda"));
    demo_status("sandbox/no", fs::status("/sandbox/no"));

    // nettoyage (préférer les suppresseurs personnalisés basés sur std::unique_ptr)
    close(fd);
    fs::remove_all("sandbox");
}

Sortie possible :

"sandbox/file" is a regular file
"sandbox/dir" is a directory
"sandbox/pipe" is a named IPC pipe
"sandbox/sock" is a named IPC socket
"sandbox/symlink" is a symlink
"/dev/null" is a character device
"/dev/sda" is a block device
"sandbox/no" does not exist

  • refresh — met à jour les attributs de fichier mis en cache (fonction membre publique)
  • exists — vérifie si l'entrée de répertoire référence un objet du système de fichiers existant (fonction membre publique)
  • is_block_file — vérifie si l'entrée de répertoire référence un périphérique de bloc (fonction membre publique)
  • is_character_file — vérifie si l'entrée de répertoire référence un périphérique caractère (fonction membre publique)
  • is_directory — vérifie si l'entrée de répertoire référence un répertoire (fonction membre publique)
  • is_fifo — vérifie si l'entrée de répertoire référence un tube nommé (fonction membre publique)
  • is_other — vérifie si l'entrée de répertoire référence un fichier autre (fonction membre publique)
  • is_regular_file — vérifie si l'entrée de répertoire référence un fichier régulier (fonction membre publique)

  • is_symlink — vérifie si l'entrée de répertoire référence un lien symbolique (fonction membre publique)
