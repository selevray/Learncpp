std::filesystem::absolute

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <filesystem>

path absolute( const std::filesystem::path& p );  // (1) (depuis C++17)

path absolute( const std::filesystem::path& p, std::error_code& ec );  // (2) (depuis C++17)

Renvoie un chemin désignant le même emplacement du système de fichiers que p, pour lequel filesystem::path::is_absolute() vaut true.

  1. Cette surcharge sans lancement d'exception renvoie un chemin construit par défaut si une erreur survient.

Paramètres

  • p — chemin à convertir en forme absolue
  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

Valeur de retour

Renvoie un chemin absolu (non nécessairement canonique) désignant le même fichier que p.

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

  1. Lève std::filesystem::filesystem_error en cas d'erreur de l'API système sous-jacente, construite avec p comme premier argument de chemin et le code d'erreur du système comme argument de code d'erreur.

  2. Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.

Notes

Les implémentations sont encouragées à ne pas considérer que l'inexistence de p est une erreur.

Pour les systèmes d'exploitation de type POSIX, std::filesystem::absolute(p) équivaut à std::filesystem::current_path() / p, sauf lorsque p est le chemin vide.

Pour Windows, std::filesystem::absolute peut être implémenté comme un appel à GetFullPathNameW.

Exemple

#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;

int main()
{
    std::filesystem::path p = "foo.c";
    std::cout << "Current path is " << std::filesystem::current_path() << '\n';
    std::cout << "Absolute path for " << p << " is " << fs::absolute(p) << '\n';
}

Sortie possible :

Current path is "/tmp/1666297965.0051296"
Absolute path for "foo.c" is "/tmp/1666297965.0051296/foo.c"
