std::filesystem::équivalent

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <filesystem>

bool equivalent( const std::filesystem::path& p1,
                 const std::filesystem::path& p2 );  // (1) (depuis C++17)

bool equivalent( const std::filesystem::path& p1,
                 const std::filesystem::path& p2,
                 std::error_code& ec ) noexcept;  // (2) (depuis C++17)

Vérifie si les chemins p1 et p2 désignent la même entité du système de fichiers.

Si l'un ou l'autre de p1 et p2 n'existe pas, une erreur est signalée.

La surcharge sans exception renvoie false en cas d'erreur.

Paramètres

  • p1, p2 — chemins à vérifier pour l'équivalence
  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

Valeur de retour

true si p1 et p2 désignent le même fichier ou répertoire et que leur statut de fichier est identique. false sinon.

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

  1. Lève std::filesystem::filesystem_error en cas d'erreurs de l'API OS sous-jacente, construite avec p1 comme premier argument de chemin, p2 comme second argument de chemin, et le code d'erreur OS comme argument de code d'erreur.

  2. Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.

Notes

Deux chemins sont considérés comme désignant la même entité du système de fichiers si les deux entités candidates désignées par ces chemins sont situées sur le même périphérique, au même emplacement. Pour POSIX, cela signifie que les membres st_dev et st_ino de leur structure POSIX stat structure, obtenue comme si par stat(), sont égaux.

En particulier, tous les liens physiques vers un même fichier ou répertoire sont équivalents, et un lien symbolique et sa cible sur le même système de fichiers sont équivalents.

Exemple

#include <cstdint>
#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;

int main()
{
    // équivalence des liens physiques
    fs::path p1 = ".";
    fs::path p2 = fs::current_path();
    if (fs::equivalent(p1, p2))
        std::cout << p1 << " is equivalent to " << p2 << '\n';

    // équivalence des liens symboliques
    for (const fs::path lib : {"/lib/libc.so.6", "/lib/x86_64-linux-gnu/libc.so.6"})
    {
        try
        {
            p2 = lib.parent_path() / fs::read_symlink(lib);
        }
        catch (std::filesystem::filesystem_error const& ex)
        {
            std::cout << ex.what() << '\n';
            continue;
        }

        if (fs::equivalent(lib, p2))
            std::cout << lib << " is equivalent to " << p2 << '\n';
    }
}
