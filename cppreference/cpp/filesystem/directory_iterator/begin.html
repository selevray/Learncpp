std::filesystem::begin(directory_iterator), std::filesystem::end(directory_iterator)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <filesystem>

directory_iterator begin( directory_iterator iter ) noexcept;  // (1) (depuis C++17)

directory_iterator end( directory_iterator ) noexcept;  // (2) (depuis C++17)

  1. Renvoie iter sans modification.

  2. Renvoie un directory_iterator construit par défaut, qui sert d'itérateur de fin. L'argument est ignoré.

Ces fonctions non membres permettent l'utilisation de directory_iterator avec les boucles for basées sur un intervalleet font de directory_iterator un type range (depuis C++20).

Paramètres

  • iter — a directory_iterator

Valeur de retour

  1. iter restent inchangés.

  2. Itérateur de fin (directory_iterator construit par défaut).

Exemple

#include <filesystem>
#include <fstream>
#include <iostream>
namespace fs = std::filesystem;

int main()
{
    fs::create_directories("sandbox/a/b");
    std::ofstream("sandbox/file1.txt");
    std::ofstream("sandbox/file2.txt");
    for (auto& p : fs::directory_iterator("sandbox"))
        std::cout << p << '\n';
    fs::remove_all("sandbox");
}

Sortie possible :

"sandbox/a"
"sandbox/file1.txt"
"sandbox/file2.txt"
