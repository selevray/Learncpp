std::filesystem::path::is_absolute,is_relative

bool is_absolute() const;  // (1) (depuis C++17)

bool is_relative() const;  // (2) (depuis C++17)

Vérifie si le chemin est absolu ou relatif. Un chemin absolu est un chemin qui identifie sans ambiguïté l'emplacement d'un fichier sans référence à un emplacement de départ supplémentaire. La première version renvoie true si le chemin, au format natif, est absolu, false sinon ; la seconde version fait l'inverse.

Paramètres

(aucune)

Valeur de retour

  1. true si le chemin est absolu, false sinon.

  2. false si le chemin est absolu, true sinon.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Notes

Le chemin "/" est absolu sur un système POSIX, mais relatif sous Windows.
