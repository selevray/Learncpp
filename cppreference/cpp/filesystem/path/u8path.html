std::filesystem::u8path

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <filesystem>

template< class Source >
std::filesystem::path u8path( const Source& source );  // (1) (depuis C++17) (obsolète en C++20)

template< class InputIt >
std::filesystem::path u8path( InputIt first, InputIt last );  // (2) (depuis C++17) (obsolète en C++20)

Construit un chemin p à partir d'une séquence encodée en UTF-8 de charsou char8_ts (depuis C++20), fournie soit comme un std::string, soit comme std::string_view, soit comme une chaîne multioctets terminée par un caractère nul, soit comme une paire d'itérateurs [first, last).

  • Si path::value_type est char et que l'encodage natif est UTF-8, construit directement un chemin comme par path(source) ou path(first, last). Remarque : c'est la situation typique d'un système POSIX utilisant Unicode, tel que Linux.
  • Sinon, si path::value_type est wchar_t et que l'encodage natif est UTF-16 (c'est la situation sous Windows), ou si path::value_type est char16_t (encodage natif garanti UTF-16) ou char32_t (encodage natif garanti UTF-32), convertit d'abord la séquence de caractères UTF-8 en une chaîne temporaire tmp de type path::string_type, puis le nouveau chemin est construit comme par path(tmp).
  • Sinon (pour les encodages de caractères étroits non UTF-8 et pour les wchar_t non UTF-16), convertit d'abord la séquence de caractères UTF-8 en une chaîne temporaire tmp encodée en UTF-32 de type std::u32string, puis le nouveau chemin est construit comme si par path(tmp) (cette voie est prise sur un système POSIX avec un système de fichiers à encodage multioctets ou monooctet non Unicode).

Paramètres

  • source — un std::string encodé en UTF-8, std::string_view, un pointeur vers une chaîne multioctets terminée par un caractère nul, ou un itérateur d'entrée dont le type de valeur char pointe vers une chaîne multioctets terminée par un caractère nul
  • first, last — paire de LegacyInputIterators qui spécifient une séquence de caractères encodée en UTF-8

Exigences sur les types

  • InputIt doit satisfaire aux exigences de LegacyInputIterator.
  • Le type de valeur de Source ou InputIt doit être char ou char8_t. (depuis C++20)

Valeur de retour

Le chemin construit à partir de la chaîne d'entrée après conversion de UTF-8 vers l'encodage natif de caractères du système de fichiers.

Exceptions

Peut lever std::bad_alloc si l'allocation mémoire échoue.

Notes

Sur les systèmes dont le format de chemin natif diffère du format de chemin générique (ni Windows ni les systèmes POSIX ne sont des exemples de tels systèmes d'exploitation), si l'argument de cette fonction utilise le format générique, il sera converti en format natif.

Exemple

#include <cstdio>
#ifdef _MSC_VER
#include <fcntl.h>
#include <io.h>
#else
#include <clocale>
#include <locale>
#endif
#include <filesystem>
#include <fstream>

int main()
{
#ifdef _MSC_VER
    _setmode(_fileno(stderr), _O_WTEXT);
#else
    std::setlocale(LC_ALL, "");
    std::locale::global(std::locale(""));
#endif

    std::filesystem::path p(u8"要らない.txt");
    std::ofstream(p) << "File contents"; // Avant LWG2676, utilise operator string_type()
                                         // sur MSVC, où string_type est wstring, uniquement
                                         // fonctionne grâce à une extension non standard.
                                         // Après LWG2676, utilise les nouveaux constructeurs de fstream

    // La représentation native de la chaîne peut être utilisée avec des API spécifiques au système d'exploitation
#ifdef _MSC_VER
    if (std::FILE* f = _wfopen(p.c_str(), L"r"))
#else
    if (std::FILE* f = std::fopen(p.c_str(), "r"))
#endif
    {
        for (int ch; (ch = fgetc(f)) != EOF; std::putchar(ch))
        {}
        std::fclose(f);
    }

    std::filesystem::remove(p);
}
