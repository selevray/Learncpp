std::filesystem::path::lexically_normal, std::filesystem::path::lexically_relative, std::filesystem::path::lexically_proximate

path lexically_normal() const;  // (1) (depuis C++17)

path lexically_relative( const path& base ) const;  // (2) (depuis C++17)

path lexically_proximate( const path& base ) const;  // (3) (depuis C++17)

  1. Renvoie *this converti en forme normale dans son format générique.

  2. Renvoie *this rendu relatif à base.

  • Premièrement, si root_name() != base.root_name() est true, ou si is_absolute() != base.is_absolute() est true, ou si (!has_root_directory() && base.has_root_directory()) est true, ou si un nom de fichier de relative_path() ou de base.relative_path() peut être interprété comme un root-name, renvoie un chemin construit par défaut.
  • Sinon, détermine d'abord le premier élément non concordant de *this et base comme si par auto [a, b] = mismatch(begin(), end(), base.begin(), base.end()), puis
    • si a == end() et b == base.end(), renvoie path("."),
    • sinon, définit N comme le nombre d'éléments de nom de fichier non vides qui ne sont ni dot ni dot-dot dans [b, base.end()), moins le nombre d'éléments de nom de fichier dot-dot. Si N < 0, renvoie un chemin construit par défaut,
    • sinon, si N = 0 et a == end() || a->empty(), renvoie path("."),
    • sinon renvoie un objet composé de
      • un path() construit par défaut suivi de
      • N applications de operator/=(path("..")), suivies de
      • une application de operator/= pour chaque élément de l'intervalle semi-ouvert [a,end()).
  1. Si la valeur de lexically_relative(base) n'est pas un chemin vide, la renvoie. Sinon renvoie *this.

Paramètres

(aucune)

Valeur de retour

  1. La forme normale du chemin.

  2. La forme relative du chemin.

  3. La forme proximale du chemin.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Notes

Ces conversions sont purement lexicales. Elles ne vérifient pas que les chemins existent, ne suivent pas les liens symboliques et n'accèdent pas du tout au système de fichiers. Pour les équivalents de lexically_relative et lexically_proximate qui suivent les liens symboliques, voir relative et proximate.

Sous Windows, le path renvoyé contient des antislashs (les séparateurs préférés).

Sous POSIX, aucun nom de fichier d'un chemin relatif n'est acceptable comme root-name.

Exemple

#include <cassert>
#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;

int main()
{
    assert(fs::path("a/./b/..").lexically_normal() == "a/");
    assert(fs::path("a/.///b/../").lexically_normal() == "a/");
    assert(fs::path("/a/d").lexically_relative("/a/b/c") == "../../d");
    assert(fs::path("/a/b/c").lexically_relative("/a/d") == "../b/c");
    assert(fs::path("a/b/c").lexically_relative("a") == "b/c");
    assert(fs::path("a/b/c").lexically_relative("a/b/c/x/y") == "../..");
    assert(fs::path("a/b/c").lexically_relative("a/b/c") == ".");
    assert(fs::path("a/b").lexically_relative("c/d") == "../../a/b");
    assert(fs::path("a/b").lexically_relative("/a/b") == "");
    assert(fs::path("a/b").lexically_proximate("/a/b") == "a/b");
}
