Accède au nom de chemin natif sous forme de chaîne de caractères.

  1. Équivalent à native().c_str().

  2. Renvoie la représentation au format natif du nom de chemin par référence.

  3. Renvoie la représentation au format natif du chemin, par valeur.

Paramètres

(aucune)

Valeur de retour

La représentation de chaîne native du nom de chemin, utilisant la syntaxe native, le type de caractère natif et l'encodage de caractères natif. Cette chaîne convient à une utilisation avec les API du système d'exploitation.

Notes

La fonction de conversion (3) est fournie afin que les API acceptant des noms de fichiers std::basic_string puissent utiliser des chemins sans modification du code.

Exemple

#include <cstdio>
#ifdef _MSC_VER
#include <fcntl.h>
#include <io.h>
#else
#include <clocale>
#include <locale>
#endif
#include <filesystem>
#include <fstream>

int main()
{
#ifdef _MSC_VER
    _setmode(_fileno(stderr), _O_WTEXT);
#else
    std::setlocale(LC_ALL, "");
    std::locale::global(std::locale(""));
#endif

    std::filesystem::path p(u8"要らない.txt");
    std::ofstream(p) << "File contents"; // Avant LWG2676, utilise operator string_type()
                                         // sur MSVC, où string_type est wstring, uniquement
                                         // fonctionne grâce à une extension non standard.
                                         // Après LWG2676, utilise les nouveaux constructeurs de fstream

    // La représentation native de la chaîne peut être utilisée avec des API spécifiques au système d'exploitation
#ifdef _MSC_VER
    if (std::FILE* f = _wfopen(p.c_str(), L"r"))
#else
    if (std::FILE* f = std::fopen(p.c_str(), "r"))
#endif
    {
        for (int ch; (ch = fgetc(f)) != EOF; std::putchar(ch))
        {}
        std::fclose(f);
    }

    std::filesystem::remove(p);
}
