std::filesystem::path::operator=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

path& operator=( const path& p );  // (1) (depuis C++17)

path& operator=( path&& p ) noexcept;  // (2) (depuis C++17)

path& operator=( string_type&& source );  // (3) (depuis C++17)

template< class Source >
path& operator=( const Source& source );  // (4) (depuis C++17)

  1. Remplace le contenu de *this par un chemin dont les représentations au format natif et au format générique sont égales à celles de p.

  2. Remplace le contenu de *this par un chemin dont les représentations au format natif et au format générique sont égales à celles de p, éventuellement en utilisant la sémantique de déplacement : p est laissé dans un état valide, mais non spécifié.

  3. Remplace le contenu de *this par une nouvelle valeur de chemin construite à partir de source au format détecté, qui est laissé dans un état valide, mais non spécifié. Équivalent à assign(std::move(source)).

  4. Remplace le contenu de *this par une nouvelle valeur de chemin construite à partir de source au format détecté, comme si par la surcharge (4) du constructeur de path. Équivalent à assign(source).

(4) participe à la résolution de surcharge uniquement si Source et path ne sont pas du même type, et que l'une des conditions suivantes est vraie :

  • Source est une spécialisation de std::basic_string ou std::basic_string_view, ou
  • std::iterator_traits<std::decay_t<Source>>::value_type est valide et désigne un type de caractère d'encodage éventuellement qualifié const (char, char8_t, (depuis C++20)char16_t, char32_t, ou wchar_t).

Paramètres

  • p — un chemin à affecter
  • source — un std::basic_string, std::basic_string_view, un pointeur vers une chaîne de caractères/caractères larges terminée par un caractère nul, ou un itérateur d'entrée pointant vers une séquence de caractères/caractères larges terminée par un caractère nul. Le type de caractère doit être l'un de char, char8_t, (depuis C++20)char16_t, char32_t, wchar_t

Valeur de retour

*this

Exemple

#include <filesystem>
namespace fs = std::filesystem;

int main()
{
    fs::path p = "C:/users/abcdef/AppData/Local";
    p = p / "Temp"; // affectation par déplacement
    const wchar_t* wstr = L"D:/猫.txt";
    p = wstr; // affectation depuis une source
}
