std::filesystem::operator/(std::filesystem::path)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

friend path operator/( const path& lhs, const path& rhs );  // (depuis C++17)

Concatène deux composants de chemin en utilisant le séparateur de répertoire préféré si approprié (voir operator/= pour les détails).

Renvoie effectivement path(lhs) /= rhs.

Cette fonction n'est pas visible par la recherche ordinaire non qualifiée ou qualifiée, et ne peut être trouvée que par recherche dépendante des arguments lorsque std::filesystem::path est une classe associée des arguments. Cela évite les conversions indésirables en présence d'une using namespace std::filesystem; directive using.

Paramètres

  • lhs, rhs — chemins à concaténer

Valeur de retour

Le résultat de la concaténation de chemins.

Exemple

#include <filesystem>
#include <iostream>

int main()
{
#   if defined(_WIN32) // see e.g. stackoverflow.com/questions/142508

    std::filesystem::path p = "C:";

    std::cout << "\"C:\" / \"Users\" / \"batman\" == " << p / "Users" / "batman" << '\n';

#   else // __linux__ etc

    std::filesystem::path p = "/home";

    std::cout << "\"/home\" / \"tux\" / \".fonts\" == " << p / "tux" / ".fonts" << '\n';

#   endif
}

Sortie possible :

Windows specific output:
"C:" / "Users" / "batman" == "C:Users\\batman"

Linux etc specific output:
"/home" / "tux" / ".fonts" == "/home/tux/.fonts"
