std::filesystem::hash_value

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <filesystem>

std::size_t hash_value( const std::filesystem::path& p ) noexcept;  // (depuis C++17)

Paramètres

  • p — un objet std::filesystem::path

Valeur de retour

Une valeur de hachage telle que si pour deux chemins p1 == p2, alors hash_value(p1) == hash_value(p2).

La valeur de retour est cohérente avec std::hash.

Notes

L'égalité de deux chemins est déterminée en comparant chaque composant séparément ; ainsi, par exemple "a//b" est égal à "a/b" et possède le même hash_value.

hash_value provient de la bibliothèque Boost.filesystem, où elle servait à l'interopérabilité avec boost.hash (qui appelle hash_value trouvée par recherche dépendante des arguments ou boost::hash_value lorsqu'elle est disponible).

Exemple

#include <cassert>
#include <cstddef>
#include <filesystem>
#include <iomanip>
#include <iostream>
#include <unordered_set>
namespace fs = std::filesystem;

void show_hash(fs::path const& p)
{
    std::cout << std::hex << std::uppercase << std::setw(16)
              << fs::hash_value(p) << " : " << p << '\n';
}

int main()
{
    auto tmp1 = fs::path{"/tmp"};
    auto tmp2 = fs::path{"/tmp/../tmp"};
    assert(!(tmp1 == tmp2));
    assert(fs::equivalent(tmp1, tmp2));
    show_hash(tmp1);
    show_hash(tmp2);

    for (auto s : {"/a///b", "/a//b", "/a/c", "...", "..", ".", ""})
        show_hash(s);

    // Un objet fonction de hachage à utiliser avec les conteneurs unordered_* :
    struct PathHash
    {
        std::size_t operator()(fs::path const& p) const noexcept
        {
            return fs::hash_value(p);
        }
    };
    std::unordered_set<fs::path, PathHash> dirs{
        "/bin", "/bin", "/lib", "/lib", "/opt", "/opt", "/tmp", "/tmp/../tmp"};
    for (fs::path const& p : dirs)
        std::cout << p << ' ';
    std::cout << '\n';
}
