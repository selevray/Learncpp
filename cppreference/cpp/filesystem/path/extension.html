std::filesystem::path::extension

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

path extension() const;  // (depuis C++17)

Renvoie l'extension du composant nom de fichier de la vue au format générique de *this.

Si le composant filename() du chemin au format générique contient un point (.) et n'est pas l'un des éléments spéciaux du système de fichiers dot ou dot-dot, alors l'extension est la sous-chaîne commençant au point le plus à droite (point inclus) et allant jusqu'à la fin du nom de chemin.

Si le premier caractère du nom de fichier est un point, ce point est ignoré (un nom de fichier comme « .profile » n'est pas considéré comme ayant une extension).

Si le nom de chemin est soit . soit .., ou si filename() ne contient pas le caractère '.', alors un chemin vide est renvoyé.

Un comportement supplémentaire peut être défini par les implémentations pour les systèmes de fichiers qui ajoutent des éléments supplémentaires (comme des flux de données alternatifs ou des noms de jeux de données partitionnés) aux extensions.

Paramètres

(aucune)

Valeur de retour

L'extension du chemin actuel, ou un chemin vide s'il n'y a pas d'extension.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Notes

L'extension renvoyée par cette fonction inclut un point afin de pouvoir distinguer le fichier qui se termine par un point (la fonction renvoie ".") d'un fichier sans extension (la fonction renvoie "").

Sur un système non POSIX, il est possible que p.stem() + p.extension() != p.filename() bien que les versions au format générique soient identiques.

Exemple

#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;

int main()
{
    std::cout << fs::path("/foo/bar.txt").extension() << '\n'
              << fs::path("/foo/bar.").extension() << '\n'
              << fs::path("/foo/bar").extension() << '\n'
              << fs::path("/foo/bar.txt/bar.cc").extension() << '\n'
              << fs::path("/foo/bar.txt/bar.").extension() << '\n'
              << fs::path("/foo/bar.txt/bar").extension() << '\n'
              << fs::path("/foo/.").extension() << '\n'
              << fs::path("/foo/..").extension() << '\n'
              << fs::path("/foo/.hidden").extension() << '\n'
              << fs::path("/foo/..bar").extension() << '\n';
}

Output:

".txt"
"."
""
".cc"
"."
""
""
""
""
".bar"
