template< class CharT, class Traits = std::char_traits<CharT>,
          class Alloc = std::allocator<CharT> >
std::basic_string<CharT,Traits,Alloc>
    generic_string( const Alloc& a = Alloc() ) const;  // (1) (depuis C++17)

std::string generic_string() const;

std::wstring generic_wstring() const;

std::u16string generic_u16string() const;

std::u32string generic_u32string() const;

std::string generic_u8string() const;  // (depuis C++17) (jusqu'à C++20)

std::u8string generic_u8string() const;  // (depuis C++20)

Renvoie le chemin interne au format générique, converti vers le type de chaîne spécifié. La conversion, le cas échéant, est définie comme suit :

  • Si path::value_type est char, la conversion, le cas échéant, dépend du système. C'est le cas sur les systèmes POSIX typiques (comme Linux), où l'encodage natif est UTF-8 et string() n'effectue aucune conversion.
  • Sinon, si path::value_type est wchar_t, la conversion, le cas échéant, n'est pas spécifiée. C'est le cas sous Windows, où wchar_t fait 16 bits et l'encodage natif est UTF-16.
  • Sinon, si path::value_type est char16_t, l'encodage natif est UTF-16 et la méthode de conversion n'est pas spécifiée.
  • Sinon, si path::value_type est char32_t, l'encodage natif est UTF-32 et la méthode de conversion n'est pas spécifiée.
  • Sinon, si path::value_type est char8_t, l'encodage natif est UTF-8 et la méthode de conversion n'est pas spécifiée.

Le caractère / est utilisé comme séparateur de répertoires.

  1. Toutes les allocations mémoire sont effectuées par a.

  2. L'encodage du résultat dans le cas de u8string() est toujours UTF-8.

Paramètres

  • a — allocateur avec lequel construire la chaîne

Exigences sur les types

  • CharT doit être l'un des types de caractères encodés (char, wchar_t, char8_t (depuis C++20), char16_t et char32_t).

Valeur de retour

Le nom de chemin interne au format générique, converti dans le type de chaîne spécifié.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <cstddef>
#include <filesystem>
#include <iomanip>
#include <iostream>
#include <span>
#include <string_view>

void print(std::string_view rem, auto const& str)
{
    std::cout << rem << std::hex << std::uppercase << std::setfill('0');
    for (const auto b : std::as_bytes(std::span{str}))
        std::cout << std::setw(2) << std::to_integer<unsigned>(b) << ' ';
    std::cout << '\n';
}

int main()
{
    std::filesystem::path p{"/家/屋"};
    std::cout << p << '\n';

    print("string    : ", p.generic_string());
    print("u8string  : ", p.generic_u8string());
    print("u16string : ", p.generic_u16string());
    print("u32string : ", p.generic_u32string());
    print("wstring   : ", p.generic_wstring());
}
