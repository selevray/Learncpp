std::filesystem::path::begin, std::filesystem::path::end

iterator begin() const;  // (1) (depuis C++17)

iterator end() const;  // (2) (depuis C++17)

  1. Renvoie un itérateur vers le premier élément du chemin. Si le chemin est vide, l'itérateur renvoyé est égal à end().

  2. Renvoie un itérateur situé juste après le dernier élément du chemin. Déréférencer cet itérateur est un comportement indéfini.

La séquence désignée par cette paire d'itérateurs se compose de ce qui suit :

  1. root-name (le cas échéant).
  2. root-directory (le cas échéant).
  3. Séquence de file-name, sans les séparateurs de répertoire.
  4. S'il y a un séparateur de répertoire après le dernier file-name du chemin, le dernier élément avant l'itérateur de fin est un élément vide.

Paramètres

(aucune)

Valeur de retour

  1. Itérateur vers le premier élément du chemin.

  2. Itérateur situé juste après la fin du chemin

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;

int main()
{
    const fs::path p =
#   ifdef _WIN32
        "C:\\users\\abcdef\\AppData\\Local\\Temp\\";
#   else
        "/home/user/.config/Cppcheck/Cppcheck-GUI.conf";
#   endif
    std::cout << "Examining the path " << p << " through iterators gives\n";
    for (auto it = p.begin(); it != p.end(); ++it)
        std::cout << *it << " │ ";
    std::cout << '\n';
}
