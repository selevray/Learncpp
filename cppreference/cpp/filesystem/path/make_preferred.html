std::filesystem::path::make_preferred

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

path& make_preferred();  // (depuis C++17)

Convertit tous les séparateurs de répertoires de la vue au format générique du chemin en séparateur de répertoires préféré.

Par exemple, sous Windows, où \ est le séparateur préféré, le chemin foo/bar sera converti en foo\bar.

Paramètres

(aucune)

Valeur de retour

*this

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

Windows peut utiliser / comme séparateur, mais préfère \, donc make_preferred convertit les barres obliques en antislashs. En revanche, POSIX n'utilise pas \ comme séparateur, car les antislashs sont des caractères valides dans un nom de fichier : le chemin Windows sur POSIX désigne en réalité un fichier nommé "a\\b\\c". Pour cette raison, les « séparateurs » ne sont pas convertis.

#include <filesystem>
#include <iostream>

int main()
{
    std::filesystem::path
        windows_path("a\\b\\c"),
        posix_path("a/b/c");

    std::cout
        << "Windows path: "
        << windows_path << " -> "
        << windows_path.make_preferred() << '\n'
        << "POSIX path: "
        << posix_path << " -> "
        << posix_path.make_preferred() << '\n';
}

Output:

// on Windows
Windows path: "a\\b\\c" -> "a\\b\\c"
POSIX path: "a/b/c" -> "a\\b\\c"

// on POSIX
Windows path: "a\\b\\c" -> "a\\b\\c"
POSIX path: "a/b/c" -> "a/b/c"
