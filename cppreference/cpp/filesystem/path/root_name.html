std::filesystem::path::root_name

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

path root_name() const;  // (depuis C++17)

Renvoie le nom de racine du chemin au format générique. Si le chemin (au format générique) ne comporte pas de nom de racine, renvoie path().

Paramètres

(aucune)

Valeur de retour

Le nom racine du chemin.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;

int main()
{
    std::cout << "Current root name is: " << fs::current_path().root_name() << '\n';
}

Sortie possible :

Current root name is: "C:"
