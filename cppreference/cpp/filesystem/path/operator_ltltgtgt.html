Effectue une entrée ou sortie de flux sur le chemin p. std::quoted est utilisé afin que les espaces ne provoquent pas de troncature lors d'une lecture ultérieure par l'opérateur d'entrée de flux.

Ces modèles de fonction ne sont pas visibles par la recherche ordinaire non qualifiée ou qualifiée, et ne peuvent être trouvés que par recherche dépendante des arguments lorsque std::filesystem::path est une classe associée des arguments. Cela évite les conversions indésirables en présence d'une using namespace std::filesystem; directive using.

Paramètres

  • os — flux sur lequel effectuer la sortie
  • is — flux sur lequel effectuer une entrée
  • p — chemin à insérer ou extraire

Valeur de retour

  1. os

  2. is

Exceptions

Peut lever des exceptions définies par l'implémentation.

Implémentation possible

operator<<

template<class CharT, class Traits>
friend std::basic_ostream<CharT,Traits>&
    operator<<(std::basic_ostream<CharT,Traits>& os, const path& p)
{
    os << std::quoted(p.string<CharT,Traits>());
    return os;
}

operator>>

template<class CharT, class Traits>
friend std::basic_istream<CharT,Traits>&
    operator>>(std::basic_istream<CharT,Traits>& is, path& p)
{
    std::basic_string<CharT, Traits> t;
    is >> std::quoted(t);
    p = t;
    return is;
}

Exemple

#include <filesystem>
#include <iostream>

int main()
{
    std::cout << std::filesystem::current_path() << '\n';
    std::cout << std::filesystem::temp_directory_path() << '\n';
}
