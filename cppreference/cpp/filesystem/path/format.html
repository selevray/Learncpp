std::filesystem::path::format

enum format {
    native_format,
    generic_format,
    auto_format
};  // (depuis C++17)

Détermine comment les représentations sous forme de chaînes des chemins sont interprétées par les constructeurs de std::filesystem::path qui acceptent des chaînes.

Constantes

Nom Explication

  • native_format — Format natif des chemins
  • generic_format — Format générique des chemins
  • auto_format — Format de chemin défini par l'implémentation, détecté automatiquement si possible

Notes

Sur les systèmes POSIX, il n'y a aucune différence entre le format natif et le format générique.
