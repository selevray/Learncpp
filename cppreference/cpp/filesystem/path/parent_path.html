std::filesystem::path::parent_path

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

path parent_path() const;  // (depuis C++17)

Renvoie le chemin du répertoire parent.

Si has_relative_path() renvoie faux, le résultat est une copie de *this. Sinon, le résultat est un chemin dont le nom de chemin au format générique est le plus long préfixe du nom de chemin au format générique de *this qui produit un élément de moins lors de l'itération.

Paramètres

(aucune)

Valeur de retour

Le chemin du répertoire parent, ou une copie de *this si has_relative_path() n'existe pas.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;

int main()
{
    for (fs::path p : {"/var/tmp/example.txt", "/", "/var/tmp/."})
        std::cout << "The parent path of " << p
                  << " is " << p.parent_path() << '\n';
}

Sortie possible :

The parent path of "/var/tmp/example.txt" is "/var/tmp"
The parent path of "/" is "/"
The parent path of "/var/tmp/." is "/var/tmp"
