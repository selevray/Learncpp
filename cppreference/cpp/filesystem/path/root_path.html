std::filesystem::path::root_path

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

path root_path() const;  // (depuis C++17)

Renvoie le chemin racine du chemin. Si le chemin ne comporte pas de chemin racine, renvoie path().

Renvoie effectivement root_name() / root_directory().

Paramètres

(aucune)

Valeur de retour

Le chemin racine du chemin.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;

int main()
{
    std::cout << "Current root path is: " << fs::current_path().root_path() << '\n';
}

Sortie possible :

Current root path is: "C:\"
