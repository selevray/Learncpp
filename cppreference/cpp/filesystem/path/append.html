  1. Si p.is_absolute() || (p.has_root_name() && p.root_name() != root_name()), alors remplace le chemin courant par p comme si par operator=(p) et termine.

  • Sinon, si p.has_root_directory(), alors supprime tout répertoire racine et tout le chemin relatif du nom de chemin au format générique de *this.

  • Sinon, si has_filename() || (!has_root_directory() && is_absolute()), alors ajoute path::preferred_separator au format générique de *this.

  • Dans tous les cas, ajoute le nom de chemin au format natif de p, en omettant tout root-name de son format générique, au format natif de *this.

// où « //host » est un nom de racine
path("//host")  / "foo" // le résultat est      « //host/foo » (ajoute avec séparateur)
path("//host/") / "foo" // le résultat est aussi « //host/foo » (ajoute sans séparateur)

// Sous POSIX,
path("foo") / ""      // le résultat est « foo/ » (ajoute)
path("foo") / "/bar"; // le résultat est « /bar » (remplace)

// Sous Windows,
path("foo") / "C:/bar";  // le résultat est « C:/bar » (remplace)
path("foo") / "C:";      // le résultat est « C: »     (remplace)
path("C:") / "";         // le résultat est « C: »     (ajoute, sans séparateur)
path("C:foo") / "/bar";  // donne « C:/bar »        (supprime le chemin relatif, puis ajoute)
path("C:foo") / "C:bar"; // donne « C:foo/bar »     (ajoute, en omettant le nom de racine de p)

(2) et (3) participent à la résolution de surcharge uniquement si Source et path ne sont pas du même type, et que l'une des conditions suivantes est vraie :

  • Source est une spécialisation de std::basic_string ou std::basic_string_view, ou
  • std::iterator_traits<std::decay_t<Source>>::value_type est valide et désigne un type de caractère d'encodage éventuellement qualifié const (char, char8_t, (depuis C++20)char16_t, char32_t, ou wchar_t).

Paramètres

  • p — nom de chemin à ajouter
  • source — std::basic_string, std::basic_string_view, chaîne multicaractère terminée par un caractère nul, ou itérateur d'entrée pointant vers une séquence multicaractère terminée par un caractère nul, représentant un nom de chemin (au format portable ou natif)
  • first, last — paire de LegacyInputIterators spécifiant une séquence multicaractère représentant un nom de chemin

Exigences sur les types

  • InputIt doit satisfaire aux exigences de LegacyInputIterator.
  • Le type de valeur de InputIt doit être l'un des types de caractères encodés (char, wchar_t, char16_t et char32_t).

Valeur de retour

*this

Exceptions

Peut lever std::bad_alloc si l'allocation mémoire échoue.

Notes

Ces fonctions produisent en pratique une approximation du sens du chemin argument p dans un environnement où *this est le répertoire de départ.

Exemple

La sortie est produite sous Windows.

#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;

int main()
{
    fs::path p1 = "C:";
    p1 /= "Users"; // n'insère pas de séparateur
    std::cout << "\"C:\" / \"Users\" == " << p1 << '\n';
    p1 /= "batman"; // insère fs::path::preferred_separator, '\' sous Windows
    std::cout << "\"C:\" / \"Users\" / \"batman\" == " << p1 << '\n';
}

Sortie possible :

"C:" / "Users" == "C:Users"
"C:" / "Users" / "batman" == "C:Users\\batman"
