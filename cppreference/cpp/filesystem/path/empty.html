std::filesystem::path::empty

bool empty() const noexcept;  // (depuis C++17)

Vérifie si le chemin au format générique est vide.

Paramètres

(aucune)

Valeur de retour

true si le chemin est vide, false sinon.

Notes

Un chemin vide peut être obtenu en appelant clear et en construisant par défaut un path. Il peut aussi être renvoyé par une fonction de décomposition de chemin (comme extension) si le composant correspondant est absent du chemin.

Un chemin vide est classé comme chemin relatif.
