std::filesystem::directory_options

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <filesystem>

enum class directory_options {
    none = /* unspecified */,
    follow_directory_symlink = /* unspecified */,
    skip_permission_denied = /* unspecified */
};  // (depuis C++17)

Ce type représente les options disponibles qui contrôlent le comportement de directory_iterator et recursive_directory_iterator.

directory_options satisfait les exigences de BitmaskType (ce qui signifie que les opérateurs binaires operator&, operator|, operator^, operator~, operator&=, operator|= et operator^= sont définis pour ce type). none représente le masque de bits vide ; chaque autre énumérateur représente un élément de masque de bits distinct.

Constantes membres

Constante membre Signification
none (Par défaut) Ignorer les liens symboliques vers des répertoires ; un refus de permission est une erreur.
follow_directory_symlink Suivre les liens symboliques vers des répertoires au lieu de les ignorer.
skip_permission_denied Ignorer les répertoires qui entraîneraient autrement des erreurs de refus de permission.
