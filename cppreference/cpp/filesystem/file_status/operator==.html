operator==(std::filesystem::file_status)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

friend bool operator==( const file_status& lhs, const file_status& rhs ) noexcept;  // (depuis C++20)

Vérifie si deux valeurs file_status sont égales, c'est-à-dire si les types et les permissions qu'elles représentent sont identiques.

Cette fonction n'est pas visible par la recherche non qualifiée ni par la recherche qualifiée ordinaires, et ne peut être trouvée que par la recherche dépendante des arguments lorsque std::filesystem::file_status est une classe associée des arguments.

L'opérateur != est synthétisé à partir de operator==.

Paramètres

  • lhs, rhs — valeurs file_status à comparer

Valeur de retour

lhs.type() == rhs.type() && lhs.permissions() == rhs.permissions()
