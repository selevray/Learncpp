Renvoie les chemins qui ont été stockés dans l'objet d'exception.

Paramètres

(aucune)

Valeur de retour

Références à la copie des paramètres path stockée par le constructeur.

Exemple

#include <cstdio>
#include <filesystem>
#include <iostream>

int main()
{
    const std::filesystem::path old_p{std::tmpnam(nullptr)},
                                new_p{std::tmpnam(nullptr)};
    try {
        std::filesystem::rename(old_p, new_p); // lève une exception car old_p n'existe pas
    }
    catch(std::filesystem::filesystem_error const& ex) {
        std::cout
            << "what():  " << ex.what() << '\n'
            << "path1(): " << ex.path1() << '\n'
            << "path2(): " << ex.path2() << '\n';
    }
}
