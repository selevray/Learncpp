Construit un nouvel objet filesystem_error.

1-3) Le code d'erreur est défini à ec et, optionnellement, les chemins impliqués dans l'opération ayant provoqué l'erreur sont définis à p1 et p2. what() après la construction renvoie une chaîne contenant what_arg (en supposant qu'elle ne contienne pas de caractère nul intégré). Si l'un ou les deux arguments path ne sont pas fournis, un path nul est utilisé à la place.

  1. Constructeur de copie. Initialise le contenu avec celui de other. Si *this et other ont tous deux le type dynamique std::filesystem_error::filesystem_error, alors std::strcmp(what(), other.what()) == 0.

Paramètres

  • what_arg — chaîne explicative
  • ec — code d'erreur propre à l'erreur système dépendant du système d'exploitation
  • p1, p2 — chemins impliqués dans l'opération ayant provoqué l'erreur système
  • other — autre objet filesystem_error à copier

Notes

Comme la copie de std::filesystem::filesystem_error n'est pas autorisée à lever d'exceptions, la chaîne explicative est généralement stockée en interne dans un espace de stockage à compteur de références alloué séparément. C'est aussi pourquoi il n'existe pas de constructeur prenant std::string&& : il devrait de toute façon copier le contenu.

Les implémentations courantes stockent également les objets path référencés par path1() et path2() dans l'espace de stockage à compteur de références.
