std::filesystem::hard_link_count

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <filesystem>

std::uintmax_t hard_link_count( const std::filesystem::path& p );  // (1) (depuis C++17)

std::uintmax_t hard_link_count( const std::filesystem::path& p,
                                std::error_code& ec ) noexcept;  // (2) (depuis C++17)

Renvoie le nombre de liens physiques pour l'objet du système de fichiers identifié par le chemin p.

La surcharge sans exception renvoie static_cast<uintmax_t>(-1) en cas d'erreur.

Paramètres

  • p — chemin à examiner
  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

Valeur de retour

Le nombre de liens physiques pour p.

Exceptions

Toute surcharge non marquée noexcept peut lever std::bad_alloc si l'allocation mémoire échoue.

  1. Lève std::filesystem::filesystem_error en cas d'erreur de l'API système sous-jacente, construite avec p comme premier argument de chemin et le code d'erreur du système comme argument de code d'erreur.

  2. Affecte à un paramètre std::error_code& le code d'erreur de l'API système si un appel échoue, et exécute ec.clear() si aucune erreur ne survient.

Exemple

#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;

int main()
{
    // Sur un système de fichiers de type POSIX, chaque répertoire possède au moins 2 liens physiques :
    // lui-même et le membre spécial de chemin "."
    fs::path p = fs::current_path();
    std::cout << "Number of hard links for current path is "
              << fs::hard_link_count(p) << '\n';

    // Chaque « .. » est un lien physique vers le répertoire parent, donc le nombre total
    // de liens physiques pour tout répertoire vaut 2 plus le nombre de sous-répertoires directs
    p = fs::current_path() / ".."; // Chaque double point est un lien physique vers le parent
    std::cout << "Number of hard links for .. is "
              << fs::hard_link_count(p) << '\n';
}

Sortie possible :

Number of hard links for current path is 2
Number of hard links for .. is 3
