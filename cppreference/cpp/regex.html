Bibliothèque des expressions régulières (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

La bibliothèque des expressions régulières fournit une classe qui représente des expressions régulières, qui sont une sorte de mini-langage utilisé pour effectuer une recherche de motifs dans des chaînes de caractères. Presque toutes les opérations sur les expressions régulières peuvent être caractérisées par l'action sur plusieurs des objets suivants :

  • Séquence cible. La séquence de caractères dans laquelle un motif est recherché. Il peut s'agir d'un intervalle délimité par deux itérateurs, d'une chaîne de caractères terminée par un caractère nul ou d'un std::string.

  • Motif. C'est l'expression régulière elle-même. Elle détermine ce qui constitue une correspondance. C'est un objet de type std::basic_regex, construit à partir d'une chaîne avec une grammaire particulière.

  • Tableau des correspondances. Les informations sur les correspondances peuvent être récupérées sous la forme d'un objet de type std::match_results.

  • Chaîne de remplacement. C'est une chaîne qui détermine comment remplacer les correspondances.

Grammaires des expressions régulières

Les motifs et les chaînes de remplacement prennent en charge les grammaires d'expressions régulières suivantes :

  • Grammaire ECMAScript modifiée des expressions régulières. C'est la grammaire par défaut.
  • Grammaire POSIX de base des expressions régulières.
  • Grammaire POSIX étendue des expressions régulières.
  • La grammaire des expressions régulières utilisée par l'utilitaire awk en POSIX.
  • La grammaire des expressions régulières utilisée par l'utilitaire grep en POSIX. Elle est en pratique identique à la grammaire POSIX de base des expressions régulières, avec en plus le saut de ligne '\n' comme séparateur d'alternatives.
  • La grammaire des expressions régulières utilisée par l'utilitaire grep, avec l'option -E, en POSIX. Elle est en pratique identique à la grammaire POSIX étendue des expressions régulières, avec en plus le saut de ligne '\n' comme séparateur d'alternatives, en plus de '|'.

Certaines variantes de grammaire (comme la correspondance insensible à la casse) sont également disponibles, voir cette page pour plus de détails.

Classes principales

Ces classes encapsulent une expression régulière ainsi que les résultats de la correspondance d'une expression régulière dans une séquence cible de caractères.

  • basic_regex (C++11) — objet d'expression régulière (modèle de classe)
  • sub_match (C++11) — identifie la séquence de caractères reconnue par une sous-expression (modèle de classe)
  • match_results (C++11) — identifie une correspondance d'expression régulière, y compris toutes les correspondances des sous-expressions (modèle de classe)

Algorithmes

Ces fonctions servent à appliquer l'expression régulière encapsulée dans un regex à une séquence cible de caractères.

  • regex_match (C++11) — tente de faire correspondre une expression régulière à une séquence de caractères entière (modèle de fonction)
  • regex_search (C++11) — tente de faire correspondre une expression régulière à une partie quelconque d'une séquence de caractères (modèle de fonction)
  • regex_replace (C++11) — remplace les occurrences d'une expression régulière par un texte de remplacement formaté (modèle de fonction)

Itérateurs

Les itérateurs de regex servent à parcourir l'ensemble des correspondances d'expressions régulières trouvées dans une séquence.

  • regex_iterator (C++11) — itère sur toutes les correspondances de regex dans une séquence de caractères (modèle de classe)
  • regex_token_iterator (C++11) — itère sur les sous-expressions spécifiées dans toutes les correspondances de regex d'une chaîne donnée, ou sur les sous-chaînes non reconnues (modèle de classe)

Exceptions

Cette classe définit le type des objets lancés comme exceptions pour signaler les erreurs de la bibliothèque des expressions régulières.

  • regex_error (C++11) — signale les erreurs générées par la bibliothèque des expressions régulières (classe)

Traits

La classe des traits de regex sert à encapsuler les aspects localisables d'un regex.

  • regex_traits (C++11) — fournit des métainformations sur un type de caractère, requises par la bibliothèque regex (modèle de classe)

Constantes

Défini dans l'espace de noms std::regex_constants

  • syntax_option_type (C++11) — options générales contrôlant le comportement de regex (typedef)
  • match_flag_type (C++11) — options propres à la correspondance (typedef)
  • error_type (C++11) — décrit les différents types d'erreurs de correspondance (typedef)

Exemple

#include <iostream>
#include <iterator>
#include <regex>
#include <string>

int main()
{
    std::string s = "Some people, when confronted with a problem, think "
        "\"I know, I'll use regular expressions.\" "
        "Now they have two problems.";

    std::regex self_regex("REGULAR EXPRESSIONS",
        std::regex_constants::ECMAScript | std::regex_constants::icase);
    if (std::regex_search(s, self_regex))
        std::cout << "Text contains the phrase 'regular expressions'\n";

    std::regex word_regex("(\\w+)");
    auto words_begin =
        std::sregex_iterator(s.begin(), s.end(), word_regex);
    auto words_end = std::sregex_iterator();

    std::cout << "Found "
              << std::distance(words_begin, words_end)
              << " words\n";

    const int N = 6;
    std::cout << "Words longer than " << N << " characters:\n";
    for (std::sregex_iterator i = words_begin; i != words_end; ++i)
    {
        std::smatch match = *i;
        std::string match_str = match.str();
        if (match_str.size() > N)
            std::cout << "  " << match_str << '\n';
    }

    std::regex long_word_regex("(\\w{7,})");
    std::string new_s = std::regex_replace(s, long_word_regex, "[$&]");
    std::cout << new_s << '\n';
}

Output:

Text contains the phrase 'regular expressions'
Found 20 words
Words longer than 6 characters:
  confronted
  problem
  regular
  expressions
  problems
Some people, when [confronted] with a [problem], think
"I know, I'll use [regular] [expressions]." Now they have two [problems].
