std::is_base_of

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class Base, class Derived >
struct is_base_of;  // (depuis C++11)

std::is_base_of est un BinaryTypeTrait.

Si Derived est dérivé de Base ou si les deux sont la même classe non union (dans les deux cas en ignorant la qualification cv), fournit la constante membre value égale à true. Sinon value vaut false.

Si Base et Derived sont tous deux des types classe non union, et qu'ils ne sont pas le même type (en ignorant la qualification cv), Derived doit être un type complet ; sinon le comportement est indéfini.

Si le programme ajoute des spécialisations pour std::is_base_ofou std::is_base_of_v (depuis C++17), le comportement est indéfini.

Modèle de variable auxiliaire

template< class Base, class Derived >
constexpr bool is_base_of_v = is_base_of<Base, Derived>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si Derived dérive de Base ou si les deux sont la même classe non union (dans les deux cas en ignorant la qualification cv), false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Notes

std::is_base_of<A, B>::value est true même si A est une classe de base privée, protégée ou ambiguë de B. Dans de nombreuses situations, std::is_convertible<B*, A*> est le test le plus approprié.

Bien qu'aucune classe ne soit sa propre base, std::is_base_of<T, T>::value vaut vrai car l'intention du trait est de modéliser la relation « est-un », et T est un T. Malgré cela, std::is_base_of<int, int>::value vaut false car seules les classes participent à la relation que ce trait modélise.

Implémentation possible

namespace details
{
    template<typename B>
    std::true_type test_ptr_conv(const volatile B*);
    template<typename>
    std::false_type test_ptr_conv(const volatile void*);

    template<typename B, typename D>
    auto test_is_base_of(int) -> decltype(test_ptr_conv<B>(static_cast<D*>(nullptr)));
    template<typename, typename>
    auto test_is_base_of(...) -> std::true_type; // base privée ou ambiguë
}

template<typename Base, typename Derived>
struct is_base_of :
    std::integral_constant<
        bool,
        std::is_class<Base>::value &&
        std::is_class<Derived>::value &&
        decltype(details::test_is_base_of<Base, Derived>(0))::value
    > {};

Exemple

#include <type_traits>

class A {};
class B : A {};
class C : B {};
class D {};
union E {};
using I = int;

static_assert
(
    std::is_base_of_v<A, A> == true &&
    std::is_base_of_v<A, B> == true &&
    std::is_base_of_v<A, C> == true &&
    std::is_base_of_v<A, D> != true &&
    std::is_base_of_v<B, A> != true &&
    std::is_base_of_v<E, E> != true &&
    std::is_base_of_v<I, I> != true
);

int main() {}
