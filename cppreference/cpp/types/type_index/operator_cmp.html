Compare les objets std::type_info sous-jacents.

1,2) Vérifie si les objets std::type_info sous-jacents désignent le même type.

3-7) Compare les objets std::type_info sous-jacents selon un ordre défini par l'implémentation. La comparaison est effectuée par type_info::before.

L'opérateur != est synthétisé à partir de operator==.

(depuis C++20)

Paramètres

  • rhs — un autre objet type_index à comparer

Valeur de retour

  1. true si les objets std::type_info sous-jacents désignent le même type, false sinon.

  2. true si les objets std::type_info sous-jacents ne désignent pas le même type, false sinon.

3-6) true si les types désignés par les objets std::type_info sous-jacents sont ordonnés selon l'ordre correspondant, false sinon.

  1. std::strong_ordering::equal si les objets std::type_info sous-jacents désignent le même type, sinon std::strong_ordering::less si l'objet std::type_info sous-jacent de *this précède celui de rhs dans l'ordre défini par l'implémentation, sinon std::strong_ordering::greater.
