Défini dans l'en-tête <typeindex>

template<> struct hash<std::type_index>;  // (depuis C++11)

La spécialisation de modèle de std::hash pour std::type_index permet aux utilisateurs d'obtenir les hachages d'objets de type std::type_index.

Le membre operator() renvoie effectivement la même valeur que hash_code().
