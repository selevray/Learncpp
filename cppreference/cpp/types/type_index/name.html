std::type_index::name

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

const char* name() const noexcept;  // (depuis C++11)

Renvoie le nom de l'objet std::type_info associé. Équivalent à appeler directement std::type_info::name().

Paramètres

(aucune)

Valeur de retour

Le nom de l'objet std::type_info associé.

Exemple

#include <iostream>
#include <typeindex>
int main() {
    std::cout << std::type_index(typeid(std::cout)).name();
}
