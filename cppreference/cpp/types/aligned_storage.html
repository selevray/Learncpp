std::aligned_storage

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< std::size_t Len, std::size_t Align = /* default-alignment */ >
struct aligned_storage;  // (depuis C++11) (obsolète en C++23)

Fournit le type imbriqué type, qui satisfait TrivialType et StandardLayoutType et convient comme stockage non initialisé pour tout objet dont la taille est au plus Len et dont l'exigence d'alignement est un diviseur de Align.

La valeur par défaut de Align est l'exigence d'alignement la plus stricte (la plus grande) pour tout objet dont la taille est au plus Len. Si la valeur par défaut n'est pas utilisée, Align doit être la valeur de alignof(T) pour un certain type T, sinon le comportement est indéfini.

Le comportement est indéfini si Len == 0.

Il est défini par l'implémentation de savoir si un alignement étendu quelconque est pris en charge.

Si le programme ajoute des spécialisations pour std::aligned_storage, le comportement est indéfini.

Types membres

Nom Définition

  • type — un type trivial et de disposition standard d'une taille d'au moins Len avec l'exigence d'alignement Align

Types auxiliaires

template< std::size_t Len, std::size_t Align = /* default-alignment */ >
using aligned_storage_t = typename aligned_storage<Len, Align>::type;  // (depuis C++14) (obsolète en C++23)

Notes

Le type défini par std::aligned_storage<>::type peut servir à créer des blocs mémoire non initialisés adaptés à la détention d'objets du type donné, éventuellement alignés plus strictement que leur exigence d'alignement naturelle, par exemple sur une frontière de cache ou de page.

Comme pour tout autre stockage non initialisé, les objets sont créés à l'aide d'un placement new et détruits par des appels explicites au destructeur.

Implémentation possible

Hormis l'argument par défaut, aligned_storage peut s'exprimer à l'aide de alignas :

template<std::size_t Len, std::size_t Align = /* alignement par défaut non implémenté */>
struct aligned_storage
{
    struct type
    {
        alignas(Align) unsigned char data[Len];
    };
};

Exemple

Une classe vector statique primitive, illustrant la création, l'accès et la destruction d'objets dans un stockage aligné.

#include <cstddef>
#include <iostream>
#include <new>
#include <string>
#include <type_traits>

template<class T, std::size_t N>
class static_vector
{
    // Stockage non initialisé correctement aligné pour N T
    std::aligned_storage_t<sizeof(T), alignof(T)> data[N];
    std::size_t m_size = 0;

public:
    // Créer un objet dans un stockage aligné
    template<typename ...Args> void emplace_back(Args&&... args)
    {
        if (m_size >= N) // Gestion possible des erreurs
            throw std::bad_alloc{};

        // Construire une valeur en mémoire du stockage aligné à l'aide de operator new placé
        ::new(&data[m_size]) T(std::forward<Args>(args)...);
        ++m_size;
    }

    // Accéder à un objet dans un stockage aligné
    const T& operator[](std::size_t pos) const
    {
        // Remarque : std::launder est nécessaire après le changement du modèle d'objet dans P0137R1
        return *std::launder(reinterpret_cast<const T*>(&data[pos]));
    }

    // Détruire les objets du stockage aligné
    ~static_vector()
    {
        for (std::size_t pos = 0; pos < m_size; ++pos)
            // Remarque : std::launder est nécessaire après le changement du modèle d'objet dans P0137R1
            std::destroy_at(std::launder(reinterpret_cast<T*>(&data[pos])));
    }
};

int main()
{
    static_vector<std::string, 10> v1;
    v1.emplace_back(5, '*');
    v1.emplace_back(10, '*');
    std::cout << v1[0] << '\n' << v1[1] << '\n';
}

**********

Voir aussi

  • alignas (C++11) — spécifie que le stockage de la variable doit être aligné sur une quantité spécifique (spécificateur)
  • alignment_of (C++11) — obtient les exigences d'alignement du type (modèle de classe)
  • aligned_alloc (C++17) — alloue de la mémoire alignée (fonction)
  • aligned_union (since C++11) (deprecated in C++23) — définit le type adapté à être utilisé comme stockage non initialisé pour tous les types donnés (modèle de classe)
  • max_align_t (C++11) — type trivial dont l'exigence d'alignement est aussi grande que celle de tout autre type scalaire (typedef)
  • launder (C++17) — barrière d'optimisation de pointeur (modèle de fonction)
