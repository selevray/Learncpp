std::is_aggregate

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_aggregate;  // (depuis C++17)

std::is_aggregate est un UnaryTypeTrait.

Si T est un type agrégat, fournit la constante membre value égale à true. Pour tout autre type, value vaut false.

Si T est un type incomplet autre qu'un type tableau ou void (éventuellement qualifié cv), le comportement est indéfini.

Si le programme ajoute des spécialisations pour std::is_aggregate ou std::is_aggregate_v, le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_aggregate_v = is_aggregate<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type agrégat, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Exemple

#include <algorithm>
#include <cassert>
#include <cstddef>
#include <new>
#include <string_view>
#include <type_traits>
#include <utility>

// Construit un T dans la mémoire non initialisée pointée par p en utilisant
// l'initialisation par liste pour les agrégats et l'initialisation sans liste sinon.
template<class T, class... Args>
T* construct(T* p, Args&&... args)
{
    if constexpr (std::is_aggregate_v<T>)
        return ::new (static_cast<void*>(p)) T{std::forward<Args>(args)...};
    else
        return ::new (static_cast<void*>(p)) T(std::forward<Args>(args)...);
}

struct A { int x, y; };
static_assert(std::is_aggregate_v<A>);

struct B
{
    int i;
    std::string_view str;

    B(int i, std::string_view str) : i(i), str(str) {}
};
static_assert(not std::is_aggregate_v<B>);

template <typename... Ts>
using aligned_storage_t = alignas(Ts...) std::byte[std::max({sizeof(Ts)...})];

int main()
{
    aligned_storage_t<A, B> storage;

    A& a = *construct(reinterpret_cast<A*>(&storage), 1, 2);
    assert(a.x == 1 and a.y == 2);

    B& b = *construct(reinterpret_cast<B*>(&storage), 3, "4");
    assert(b.i == 3 and b.str == "4");
}
