std::make_signed

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct make_signed;  // (depuis C++11)

Si T est un type entier (sauf bool) ou un type énumération, fournit le typedef membre type qui est le type entier signé correspondant à T, avec les mêmes qualificateurs cv.

Si T est signé ou non signé char, short, int, long, long long, le type signé de cette liste correspondant à T est fourni.

Si T est un type énumération ou char, wchar_t, char8_t (depuis C++20), char16_t, char32_t, le type entier signé ayant le plus petit rang et ayant la même sizeof que T est fourni.

Dans le cas contraire, le comportement est indéfini.

(jusqu'à C++20)

Sinon, le programme est mal formé.

(depuis C++20)

Si le programme ajoute des spécialisations pour std::make_signed, le comportement est indéfini.

Types membres

Nom Définition

  • type — le type entier signé correspondant à T

Types auxiliaires

template< class T >
using make_signed_t = typename make_signed<T>::type;  // (depuis C++14)

Exemple

#include <type_traits>

enum struct E : unsigned short {};

int main()
{
    using char_type = std::make_signed_t<unsigned char>;
    using int_type  = std::make_signed_t<unsigned int>;
    using long_type = std::make_signed_t<volatile unsigned long>;
    using enum_type = std::make_signed_t<E>;

    static_assert(
        std::is_same_v<char_type, signed char> and
        std::is_same_v<int_type, signed int> and
        std::is_same_v<long_type, volatile signed long> and
        std::is_same_v<enum_type, signed short>
    );
}
