std::integral_constant

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T, T v >
struct integral_constant;  // (depuis C++11)

std::integral_constant encapsule une constante statique du type spécifié. C'est la classe de base des traits de types C++.

Si le programme ajoute des spécialisations pour std::integral_constant, le comportement est indéfini.

Alias de modèles auxiliaires

Un alias de modèle auxiliaire std::bool_constant est défini pour le cas courant où T vaut bool.

template< bool B >
using bool_constant = integral_constant<bool, B>;  // (depuis C++17)

Spécialisations

Deux typedefs sont fournis pour le cas courant où T vaut bool :

  • false_type — std::integral_constant<bool, false>

Types membres

Fonctions membres

std::integral_constant::operator value_type

constexpr operator value_type() const noexcept;

Fonction de conversion. Renvoie la valeur encapsulée.

std::integral_constant::operator()

constexpr value_type operator()() const noexcept;  // (depuis C++14)

Renvoie la valeur encapsulée. Cette fonction permet à std::integral_constant de servir de source d'objets fonctions à la compilation.

Implémentation possible

template<class T, T v>
struct integral_constant
{
    static constexpr T value = v;
    using value_type = T;
    using type = integral_constant; // using injected-class-name
    constexpr operator value_type() const noexcept { return value; }
    constexpr value_type operator()() const noexcept { return value; } // depuis C++14
};

Exemple

#include <type_traits>

using two_t = std::integral_constant<int, 2>;
using four_t = std::integral_constant<int, 4>;

static_assert(not std::is_same_v<two_t, four_t>);
static_assert(two_t::value * 2 == four_t::value, "2*2 != 4");
static_assert(two_t() << 1 == four_t() >> 0, "2*2 != 4");

enum class E{ e1, e2 };
using c1 = std::integral_constant<E, E::e1>;
using c2 = std::integral_constant<E, E::e2>;
static_assert(c1::value != E::e2);
static_assert(c1() == E::e1);
static_assert(std::is_same_v<c2, c2>);

int main() {}
