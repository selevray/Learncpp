std::remove_pointer

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct remove_pointer;  // (depuis C++11)

Fournit le typedef membre type qui est le type pointé par T, ou, si T n'est pas un pointeur, alors type est identique à T.

Si le programme ajoute des spécialisations pour std::remove_pointer, le comportement est indéfini.

Types membres

Nom Définition

  • type — le type pointé par T ou T s'il n'est pas un pointeur

Types auxiliaires

template< class T >
using remove_pointer_t = typename remove_pointer<T>::type;  // (depuis C++14)

Implémentation possible

template<class T> struct remove_pointer { typedef T type; };
template<class T> struct remove_pointer<T*> { typedef T type; };
template<class T> struct remove_pointer<T* const> { typedef T type; };
template<class T> struct remove_pointer<T* volatile> { typedef T type; };
template<class T> struct remove_pointer<T* const volatile> { typedef T type; };

Exemple

#include <type_traits>

static_assert
(
    std::is_same_v<int, int> == true &&
    std::is_same_v<int, int*> == false &&
    std::is_same_v<int, int**> == false &&
    std::is_same_v<int, std::remove_pointer_t<int>> == true &&
    std::is_same_v<int, std::remove_pointer_t<int*>> == true &&
    std::is_same_v<int, std::remove_pointer_t<int**>> == false &&
    std::is_same_v<int, std::remove_pointer_t<int* const>> == true &&
    std::is_same_v<int, std::remove_pointer_t<int* volatile>> == true &&
    std::is_same_v<int, std::remove_pointer_t<int* const volatile>> == true
);

int main() {}
