std::is_compound

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_compound;  // (depuis C++11)

std::is_compound est un UnaryTypeTrait.

Si T est un type composé (c'est-à-dire tableau, fonction, pointeur vers objet, pointeur vers fonction, pointeur vers objet membre, pointeur vers fonction membre, référence, classe, union ou énumération, y compris leurs variantes qualifiées cv), fournit la constante membre value égale à true. Pour tout autre type, value vaut false.

Si le programme ajoute des spécialisations pour std::is_compound ou std::is_compound_v, le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_compound_v = is_compound<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type composé, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Notes

Les types composés sont les types construits à partir de types fondamentaux. Tout type C++ est soit fondamental, soit composé.

Implémentation possible

template<class T>
struct is_compound : std::integral_constant<bool, !std::is_fundamental<T>::value> {};

Exemple

#include <type_traits>
#include <iostream>

static_assert(not std::is_compound_v<int>);
static_assert(std::is_compound_v<int*>);
static_assert(std::is_compound_v<int&>);

void f();
static_assert(std::is_compound_v<decltype(f)>);
static_assert(std::is_compound_v<decltype(&f)>);

static_assert(std::is_compound_v<char[100]>);

class C {};
static_assert(std::is_compound_v<C>);

union U {};
static_assert(std::is_compound_v<U>);

enum struct E { e };
static_assert(std::is_compound_v<E>);
static_assert(std::is_compound_v<decltype(E::e)>);

struct S
{
    int i : 8;
    int j;
    void foo();
};
static_assert(not std::is_compound_v<decltype(S::i)>);
static_assert(not std::is_compound_v<decltype(S::j)>);
static_assert(std::is_compound_v<decltype(&S::j)>);
static_assert(std::is_compound_v<decltype(&S::foo)>);

int main()
{
    std::cout << "All checks have passed\n";
}
