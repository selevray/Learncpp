std::is_null_pointer

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_null_pointer;  // (depuis C++11)

std::is_null_pointer est un UnaryTypeTrait.

Vérifie si T est le type std::nullptr_t.

Fournit la constante membre value égale à true si T est le type std::nullptr_t, const std::nullptr_t, volatile std::nullptr_t ou const volatile std::nullptr_t.

Sinon, value est égal à false.

Si le programme ajoute des spécialisations pour std::is_null_pointerou std::is_null_pointer_v (depuis C++17), le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_null_pointer_v = is_null_pointer<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est le type std::nullptr_t (éventuellement qualifié cv), false sinon (constante statique publique membre)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Implémentation possible

template<class T>
struct is_null_pointer : std::is_same<std::nullptr_t, std::remove_cv_t<T>> {};

Notes

std::is_pointer vaut false pour std::nullptr_t car ce n'est pas un type pointeur natif.

Dans libc++, std::is_null_pointer n'est pas disponible en mode C++11.

Macro de test de fonctionnalité Valeur Std Fonctionnalité

Exemple

#include <type_traits>

static_assert(std::is_null_pointer_v<decltype(nullptr)>);
static_assert(!std::is_null_pointer_v<int*>);
static_assert(!std::is_pointer_v<decltype(nullptr)>);
static_assert(std::is_pointer_v<int*>);

int main()
{
}
