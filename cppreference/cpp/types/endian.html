std::endian

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <bit>

enum class endian
{
    little = /* défini par l'implémentation */,
    big    = /* défini par l'implémentation */,
    native = /* défini par l'implémentation */,
};  // (depuis C++20)

Indique l'boutisme de tous les types scalaires :

  • Si tous les types scalaires sont little-endian, std::endian::native vaut std::endian::little.
  • Si tous les types scalaires sont big-endian, std::endian::native vaut std::endian::big.

Les plateformes à cas limites sont également prises en charge :

  • Si tous les types scalaires ont sizeof égal à 1, le boutisme n'a pas d'importance et les trois valeurs, std::endian::little, std::endian::big et std::endian::native sont identiques.
  • Si la plateforme utilise un boutisme mixte, std::endian::native n'est égal ni à std::endian::big ni à std::endian::little.

Implémentation possible

enum class endian
{
#if defined(_MSC_VER) && !defined(__clang__)
    little = 0,
    big    = 1,
    native = little
#else
    little = __ORDER_LITTLE_ENDIAN__,
    big    = __ORDER_BIG_ENDIAN__,
    native = __BYTE_ORDER__
#endif
};

Exemple

#include <bit>
#include <iostream>

int main()
{
    if constexpr (std::endian::native == std::endian::big)
        std::cout << "big-endian\n";
    else if constexpr (std::endian::native == std::endian::little)
        std::cout << "little-endian\n";
    else
        std::cout << "mixed-endian\n";
}
