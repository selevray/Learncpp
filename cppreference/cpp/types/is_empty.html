std::is_empty

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_empty;  // (depuis C++11)

std::is_empty est un UnaryTypeTrait.

Si T est un type vide (c'est-à-dire un type classe non union sans membres de données non statiques autres que des champs de bits de taille 0, sans fonctions virtuelles, sans classes de base virtuelles et sans classes de base non vides), fournit la constante membre value égale à true. Pour tout autre type, value vaut false.

Si T est un type classe non union incomplet, le comportement est indéfini.

Si le programme ajoute des spécialisations pour std::is_empty ou std::is_empty_v, le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_empty_v = is_empty<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type classe vide, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Notes

Hériter de classes de base vides n'augmente généralement pas la taille d'une classe grâce à l'optimisation de base vide.

std::is_empty<T> et tous les autres traits de type sont des classes vides.

Exemple

#include <iostream>
#include <type_traits>

struct A {};
static_assert(std::is_empty_v<A> == true);

struct B { int m; };
static_assert(std::is_empty_v<B> == false);

struct C { static int m; };
static_assert(std::is_empty_v<C> == true);

struct D { virtual ~D(); };
static_assert(std::is_empty_v<D> == false);

union E {};
static_assert(std::is_empty_v<E> == false);

struct F { [[no_unique_address]] E e; };

struct G
{
    int:0;
    // La norme C++ autorise « à titre particulier, un champ de bits sans nom de largeur zéro
    // impose l'alignement du champ de bits suivant sur une limite d'unité d'allocation.
    // La largeur ne peut être zéro que lors de la déclaration d'un champ de bits sans nom.»
};
static_assert(std::is_empty_v<G>); // ne contient que des champs de bits sans nom de largeur zéro

int main()
{
    std::cout << std::boolalpha;
    std::cout << "F: " << std::is_empty_v<F> << '\n'; // le résultat dépend de l'ABI
}

Sortie possible :

F: true
