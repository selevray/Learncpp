std::is_pointer_interconvertible_with_class

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class S, class M >
constexpr bool is_pointer_interconvertible_with_class( M S::* mp ) noexcept;  // (depuis C++20)

Étant donné un objet s de type S, détermine si s.*mp désigne un sous-objet de s et si s est pointer-interconvertible avec son sous-objet s.*mp. Le programme est mal formé si S n'est pas un type complet.

Si S n'est pas un StandardLayoutType, ou si M n'est pas un type objet, ou si mp est égal à nullptr, le résultat est toujours false.

Paramètres

  • mp — un pointeur vers membre à détecter

Valeur de retour

true si s.*mp désigne un sous-objet de s et que s est pointer-interconvertible avec son sous-objet s.*mp, sinon false, où s est un objet de type S.

Notes

Le type d'une expression de pointeur vers membre &S::m n'est pas toujours M S::*, où m est de type M, car m peut être un membre hérité d'une classe de base de S. Les arguments de modèle peuvent être spécifiés afin d'éviter des résultats potentiellement surprenants.

S'il existe une valeur mp de type M S::* telle que std::is_pointer_interconvertible_with_class(mp) == true, alors reinterpret_cast<M&>(s) a un résultat bien défini et désigne le même sous-objet que s.*mp, où s est une lvalue valide de type S.

Sur les plateformes courantes, la représentation binaire de mp est entièrement à zéro si std::is_pointer_interconvertible_with_class(mp) == true.

Exemple

#include <type_traits>

struct Foo { int x; };
struct Bar { int y; };

struct Baz : Foo, Bar {}; // not standard-layout

static_assert( not std::is_same_v<decltype(&Baz::x), int Baz::*> );
static_assert( std::is_pointer_interconvertible_with_class(&Baz::x) );
static_assert( not std::is_pointer_interconvertible_with_class<Baz, int>(&Baz::x) );

int main() { }
