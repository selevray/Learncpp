std::remove_cvref

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct remove_cvref;  // (depuis C++20)

Si le type T est un type référence, fournit le typedef membre type qui est le type désigné par T, dont les qualificateurs cv de premier niveau ont été supprimés. Sinon, type est T dont les qualificateurs cv de premier niveau ont été supprimés.

Si le programme ajoute des spécialisations pour std::remove_cvref, le comportement est indéfini.

Types membres

Nom Définition

  • type — le type désigné par T ou T lui-même s'il n'est pas une référence, sans les qualificateurs cv de premier niveau

Types auxiliaires

template< class T >
using remove_cvref_t = remove_cvref<T>::type;  // (depuis C++20)

Implémentation possible

template<class T>
struct remove_cvref
{
    using type = std::remove_cv_t<std::remove_reference_t<T>>;
};

Exemple

#include <type_traits>

int main()
{
    static_assert(std::is_same_v<std::remove_cvref_t<int>, int>);
    static_assert(std::is_same_v<std::remove_cvref_t<int&>, int>);
    static_assert(std::is_same_v<std::remove_cvref_t<int&&>, int>);
    static_assert(std::is_same_v<std::remove_cvref_t<const int&>, int>);
    static_assert(std::is_same_v<std::remove_cvref_t<const int[2]>, int[2]>);
    static_assert(std::is_same_v<std::remove_cvref_t<const int(&)[2]>, int[2]>);
    static_assert(std::is_same_v<std::remove_cvref_t<int(int)>, int(int)>);
}
