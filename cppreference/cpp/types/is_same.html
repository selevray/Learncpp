std::is_same

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T, class U >
struct is_same;  // (depuis C++11)

Si T et U désignent le même type (en tenant compte des qualifications const/volatile), fournit la constante membre value égale à true. Sinon value vaut false.

La commutativité est satisfaite, c'est-à-dire que pour deux types quelconques T et U, is_same<T, U>::value == true si et seulement si is_same<U, T>::value == true.

Si le programme ajoute des spécialisations pour std::is_sameou std::is_same_v (depuis C++17), le comportement est indéfini.

Modèle de variable auxiliaire

template< class T, class U >
constexpr bool is_same_v = is_same<T, U>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T et U sont le même type, false sinon (constante statique publique membre)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Implémentation possible

template<class T, class U>
struct is_same : std::false_type {};

template<class T>
struct is_same<T, T> : std::true_type {};

Exemple

#include <cstdint>
#include <iostream>
#include <type_traits>

int main()
{
    std::cout << std::boolalpha;

    // quelques faits définis par l'implémentation

    // généralement vrai si 'int' fait 32 bits
    std::cout << std::is_same<int, std::int32_t>::value << ' '; // peut-être vrai
    // possiblement vrai si le modèle de données ILP64 est utilisé
    std::cout << std::is_same<int, std::int64_t>::value << ' '; // peut-être faux

    // mêmes tests que ci-dessus, sauf en utilisant le format std::is_same_v<T, U> de C++17
    std::cout << std::is_same_v<int, std::int32_t> << ' ';  // peut-être vrai
    std::cout << std::is_same_v<int, std::int64_t> << '\n'; // peut-être faux

    // comparer les types de quelques variables
    long double num1 = 1.0;
    long double num2 = 2.0;
    static_assert( std::is_same_v<decltype(num1), decltype(num2)> == true );

    // 'float' n'est jamais un type entier
    static_assert( std::is_same<float, std::int32_t>::value == false );

    // 'int' est implicitement 'signed'
    static_assert( std::is_same_v<int, int> == true );
    static_assert( std::is_same_v<int, unsigned int> == false );
    static_assert( std::is_same_v<int, signed int> == true );

    // contrairement aux autres types, 'char' n'est ni 'unsigned' ni 'signed'
    static_assert( std::is_same_v<char, char> == true );
    static_assert( std::is_same_v<char, unsigned char> == false );
    static_assert( std::is_same_v<char, signed char> == false );

    // le type T qualifié const n'est pas le même que T non const
    static_assert( !std::is_same<const int, int>() );
}
