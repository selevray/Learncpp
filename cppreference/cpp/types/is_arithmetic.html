std::is_arithmetic

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_arithmetic;  // (depuis C++11)

std::is_arithmetic est un UnaryTypeTrait.

Si T est un type arithmétique (c'est-à-dire un type entier ou un type à virgule flottante) ou une version cv-qualified de ceux-ci, fournit la constante membre value égale à true. Pour tout autre type, value vaut false.

Si le programme ajoute des spécialisations pour std::is_arithmeticou std::is_arithmetic_v (depuis C++17), le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_arithmetic_v = is_arithmetic<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type arithmétique, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Notes

Les types arithmétiques sont les types natifs pour lesquels les opérateurs arithmétiques (+, -, *, /) sont définis (éventuellement en combinaison avec les conversions arithmétiques usuelles).

Des spécialisations de std::numeric_limits sont fournies pour tous les types arithmétiques.

Implémentation possible

template<class T>
struct is_arithmetic : std::integral_constant<bool,
                                              std::is_integral<T>::value ||
                                              std::is_floating_point<T>::value> {};

Exemple

#include <atomic>
#include <cstddef>
#include <type_traits>

class A {};

enum class B : int { e };

static_assert(
    std::is_arithmetic_v<bool>            == true  and
    std::is_arithmetic_v<char>            == true  and
    std::is_arithmetic_v<char const>      == true  and
    std::is_arithmetic_v<int>             == true  and
    std::is_arithmetic_v<int const>       == true  and
    std::is_arithmetic_v<float>           == true  and
    std::is_arithmetic_v<float const>     == true  and
    std::is_arithmetic_v<std::size_t>     == true  and

    std::is_arithmetic_v<char&>           == false and
    std::is_arithmetic_v<char*>           == false and
    std::is_arithmetic_v<int&>            == false and
    std::is_arithmetic_v<int*>            == false and
    std::is_arithmetic_v<float&>          == false and
    std::is_arithmetic_v<float*>          == false and
    std::is_arithmetic_v<A>               == false and
    std::is_arithmetic_v<B>               == false and
    std::is_arithmetic_v<decltype(B::e)>  == false and
    std::is_arithmetic_v<std::byte>       == false and
    std::is_arithmetic_v<std::atomic_int> == false
);

int main() {}
