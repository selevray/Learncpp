std::is_scoped_enum

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_scoped_enum;  // (depuis C++23)

std::is_scoped_enum est un UnaryTypeTrait.

Vérifie si T est un type énumération à portée. Fournit la constante membre value égale à true si T est un type énumération à portée. Sinon, value est égale à false.

Si le programme ajoute des spécialisations pour std::is_scoped_enum ou std::is_scoped_enum_v, le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_scoped_enum_v = is_scoped_enum<T>::value;  // (depuis C++23)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type énumération à portée, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Implémentation possible

template<typename E>
struct is_scoped_enum : std::bool_constant<requires
{
    requires std::is_enum_v<E>;
    requires !std::is_convertible_v<E, std::underlying_type_t<E>>;
}>
{};

Exemple

#include <type_traits>

class A {};

enum E {};

enum struct Es { oz };

enum class Ec : int {};

int main()
{
    static_assert(std::is_scoped_enum_v<A> == false);
    static_assert(std::is_scoped_enum_v<E> == false);
    static_assert(std::is_scoped_enum_v<Es> == true);
    static_assert(std::is_scoped_enum_v<Ec> == true);
    static_assert(std::is_scoped_enum_v<int> == false);
}
