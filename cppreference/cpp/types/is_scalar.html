std::is_scalar

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_scalar;  // (depuis C++11)

std::is_scalar est un UnaryTypeTrait.

Si T est un type scalaire, fournit la constante membre value égale à true. Pour tout autre type, value vaut false.

Si le programme ajoute des spécialisations pour std::is_scalar ou std::is_scalar_v, le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_scalar_v = is_scalar<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type scalaire, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Notes

Chaque emplacement mémoire individuel du modèle mémoire C++, y compris les emplacements mémoire cachés utilisés par les fonctionnalités du langage (par ex. le pointeur vers la table virtuelle), a un type scalaire (ou est une séquence de champs de bits adjacents de longueur non nulle). L'ordonnancement des effets de bord dans l'évaluation d'expressions, la synchronisation entre threads et l'ordre de dépendance sont tous définis en termes d'objets scalaires individuels.

Implémentation possible

template<class T>
struct is_scalar : std::integral_constant<bool, std::is_arithmetic<T>::value
                                             || std::is_enum<T>::value
                                             || std::is_pointer<T>::value
                                             || std::is_member_pointer<T>::value
                                             || std::is_null_pointer<T>::value>
{};

Exemple

#include <iostream>
#include <type_traits>
#include <typeinfo>
#include <utility>

template<typename Head, typename... Tail>
void are_scalars(Head&& head, Tail&&... tail)
{
    using T = std::decay_t<decltype(head)>;

    std::cout << typeid(T).name() << " is "
              << (std::is_scalar_v<T> ? "" : "not ")
              << "a scalar\n";

    if constexpr (sizeof... (Tail))
    {
        are_scalars(std::forward<decltype(tail)>(tail)...);
    }
}

int main()
{
    struct S { int m; } s;
    int S::* mp = &S::m;
    enum class E { e };

    are_scalars(42, 3.14, E::e, "str", mp, nullptr, s);
}

Sortie possible :

int is a scalar
double is a scalar
main::E is a scalar
char const* is a scalar
int main::S::* is a scalar
nullptr is a scalar
main::S is not a scalar
