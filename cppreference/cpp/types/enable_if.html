std::enable_if

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< bool B, class T = void >
struct enable_if;  // (depuis C++11)

Si B est true, std::enable_if possède un typedef membre public type, égal à T ; sinon, il n'existe aucun typedef membre.

Cette métafonction est un moyen pratique de tirer parti de la SFINAE avant les concepts de C++20, en particulier pour retirer conditionnellement des fonctions de l'ensemble des candidats en fonction de traits de type, permettant des surcharges de fonctions ou des spécialisations distinctes selon ces différents traits de type.

std::enable_if peut être utilisé sous de nombreuses formes, notamment :

  • comme argument de fonction supplémentaire (non applicable à la plupart des surcharges d'opérateurs),
  • comme type de retour (non applicable aux constructeurs et aux destructeurs),
  • comme paramètre de modèle de classe ou de modèle de fonction.

Si le programme ajoute des spécialisations pour std::enable_if, le comportement est indéfini.

Types membres

Type Définition

  • type — soit T, soit aucun membre de ce type, selon la valeur de B

Types auxiliaires

template< bool B, class T = void >
using enable_if_t = typename enable_if<B,T>::type;  // (depuis C++14)

Implémentation possible

template<bool B, class T = void>
struct enable_if {};

template<class T>
struct enable_if<true, T> { typedef T type; };

Notes

Une erreur courante consiste à déclarer deux modèles de fonctions qui ne diffèrent que par leurs arguments de modèle par défaut. Cela ne fonctionne pas, car les déclarations sont traitées comme des redéclarations du même modèle de fonction (les arguments de modèle par défaut ne sont pas pris en compte dans l'équivalence des modèles de fonctions).

/* INCORRECT */

struct T
{
    enum { int_t, float_t } type;

    template<typename Integer,
             typename = std::enable_if_t<std::is_integral<Integer>::value>>
    T(Integer) : type(int_t) {}

    template<typename Floating,
             typename = std::enable_if_t<std::is_floating_point<Floating>::value>>
    T(Floating) : type(float_t) {} // erreur : traité comme une redéfinition
};

/* CORRECT */

struct T
{
    enum { int_t, float_t } type;

    template<typename Integer,
             std::enable_if_t<std::is_integral<Integer>::value, bool> = true>
    T(Integer) : type(int_t) {}

    template<typename Floating,
             std::enable_if_t<std::is_floating_point<Floating>::value, bool> = true>
    T(Floating) : type(float_t) {} // OK
};

Il faut prendre garde lors de l'utilisation de enable_if dans le type d'un paramètre de modèle non-type d'un modèle de fonction de portée d'espace de noms. Certaines spécifications d'ABI, comme l'ABI Itanium, n'incluent pas les parties dépendantes de l'instanciation des paramètres de modèle non-type dans le name mangling, ce qui signifie que des spécialisations de deux modèles de fonctions distincts pourraient finir avec le même nom mangled et être liées par erreur entre elles. Par exemple :

// première unité de traduction

struct X
{
    enum { value1 = true, value2 = true };
};

template<class T, std::enable_if_t<T::value1, int> = 0>
void func() {} // #1

template void func<X>(); // #2

// seconde unité de traduction

struct X
{
    enum { value1 = true, value2 = true };
};

template<class T, std::enable_if_t<T::value2, int> = 0>
void func() {} // #3

template void func<X>(); // #4

Les modèles de fonctions #1 et #3 ont des signatures différentes et sont des modèles distincts. Néanmoins, #2 et #4, bien qu'instanciations de modèles de fonctions différents, ont le même nom mangled dans l'ABI Itanium de C++ (_Z4funcI1XLi0EEvv), ce qui signifie que l'éditeur de liens considérera par erreur qu'il s'agit de la même entité.

Exemple

#include <iostream>
#include <new>
#include <string>
#include <type_traits>

namespace detail
{
    void* voidify(const volatile void* ptr) noexcept { return const_cast<void*>(ptr); }
}

// #1, activé via le type de retour
template<class T>
typename std::enable_if<std::is_trivially_default_constructible<T>::value>::type
    construct(T*)
{
    std::cout << "default constructing trivially default constructible T\n";
}

// identique à ci-dessus
template<class T>
typename std::enable_if<!std::is_trivially_default_constructible<T>::value>::type
    construct(T* p)
{
    std::cout << "default constructing non-trivially default constructible T\n";
    ::new(detail::voidify(p)) T;
}

// #2
template<class T, class... Args>
std::enable_if_t<std::is_constructible<T, Args&&...>::value> // Utilisation d'un type auxiliaire
    construct(T* p, Args&&... args)
{
    std::cout << "constructing T with operation\n";
    ::new(detail::voidify(p)) T(static_cast<Args&&>(args)...);
}

// #3, activé via un paramètre
template<class T>
void destroy(
    T*,
    typename std::enable_if<
        std::is_trivially_destructible<T>::value
    >::type* = 0)
{
    std::cout << "destroying trivially destructible T\n";
}

// #4, activé via un paramètre de modèle non-type
template<class T,
         typename std::enable_if<
             !std::is_trivially_destructible<T>{} &&
             (std::is_class<T>{} || std::is_union<T>{}),
             bool>::type = true>
void destroy(T* t)
{
    std::cout << "destroying non-trivially destructible T\n";
    t->~T();
}

// #5, activé via un paramètre de modèle de type
template<class T,
	 typename = std::enable_if_t<std::is_array<T>::value>>
void destroy(T* t) // note : la signature de la fonction n'est pas modifiée
{
    for (std::size_t i = 0; i < std::extent<T>::value; ++i)
        destroy((*t)[i]);
}

/*
template<class T,
	 typename = std::enable_if_t<std::is_void<T>::value>>
void destroy(T* t) {} // erreur : a la même signature que #5
*/

// la spécialisation partielle de A est activée via un paramètre de modèle
template<class T, class Enable = void>
class A {}; // modèle primaire

template<class T>
class A<T, typename std::enable_if<std::is_floating_point<T>::value>::type>
{}; // spécialisation pour les types à virgule flottante

int main()
{
    union { int i; char s[sizeof(std::string)]; } u;

    construct(reinterpret_cast<int*>(&u));
    destroy(reinterpret_cast<int*>(&u));

    construct(reinterpret_cast<std::string*>(&u), "Hello");
    destroy(reinterpret_cast<std::string*>(&u));

    A<int>{}; // OK : correspond au modèle primaire
    A<double>{}; // OK : correspond à la spécialisation partielle
}

Output:

default constructing trivially default constructible T
destroying trivially destructible T
constructing T with operation
destroying non-trivially destructible T
