std::alignment_of

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct alignment_of;  // (depuis C++11)

Fournit la constante membre value égale à l'exigence d'alignement du type T, comme si elle était obtenue par une expression alignof. Si T est un type tableau, renvoie les exigences d'alignement du type d'élément. Si T est un type référence, renvoie les exigences d'alignement du type référencé.

Si alignof(T) n'est pas une expression valide, le comportement est indéfini.

Si le programme ajoute des spécialisations pour std::alignment_ofou std::alignment_of_v (depuis C++17), le comportement est indéfini.

Modèle de variable auxiliaire

template< class T >
constexpr std::size_t alignment_of_v = alignment_of<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Type Définition

Implémentation possible

template<class T>
struct alignment_of : std::integral_constant<std::size_t, alignof(T)> {};

Notes

Ce trait de type est antérieur au mot-clé alignof, qui peut être utilisé pour obtenir la même valeur avec moins de verbosité.

Exemple

#include <cstdint>
#include <iostream>
#include <type_traits>

struct A {};
struct B
{
    std::int8_t p;
    std::int16_t q;
};

int main()
{
    std::cout << std::alignment_of<A>::value << ' ';
    std::cout << std::alignment_of<B>::value << ' ';
    std::cout << std::alignment_of<int>() << ' '; // syntaxe alternative
    std::cout << std::alignment_of_v<double> << '\n'; // syntaxe alternative C++17
}

Voir aussi

  • alignof (C++11) — interroge les exigences d'alignement d'un type (opérateur)
  • alignas (C++11) — spécifie que le stockage de la variable doit être aligné sur une quantité spécifique (spécificateur)
  • aligned_storage (since C++11) (deprecated in C++23) — définit le type adapté à être utilisé comme stockage non initialisé pour des types de taille donnée (modèle de classe)
  • aligned_union (since C++11) (deprecated in C++23) — définit le type adapté à être utilisé comme stockage non initialisé pour tous les types donnés (modèle de classe)
  • max_align_t (C++11) — type trivial dont l'exigence d'alignement est aussi grande que celle de tout autre type scalaire (typedef)
