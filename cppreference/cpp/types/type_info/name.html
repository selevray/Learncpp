std::type_info::name

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

const char* name() const;  // (noexcept depuis C++11)

Renvoie une chaîne de caractères terminée par un caractère nul, définie par l'implémentation, contenant le nom du type. Aucune garantie n'est donnée ; en particulier, la chaîne renvoyée peut être identique pour plusieurs types et changer entre les invocations d'un même programme.

Paramètres

(aucune)

Valeur de retour

Chaîne de caractères terminée par un caractère nul contenant le nom du type.

Notes

La durée de vie du tableau pointé par le pointeur renvoyé n'est pas spécifiée, mais en pratique il persiste tant que la structure de données RTTI du type donné existe, ce qui correspond à la durée de vie de l'application, sauf s'il est chargé depuis une bibliothèque dynamique (qui peut être déchargée).

Certaines implémentations (comme MSVC, IBM, Oracle) produisent un nom de type lisible par un humain. D'autres, notamment gcc et clang, renvoient le nom décoré (mangled), spécifié par l'Itanium C++ ABI. Le nom décoré peut être converti en forme lisible à l'aide d'une API propre à l'implémentation, telle que abi::__cxa_demangle directement ou via boost::core::demangle. Il peut aussi être transmis à l'utilitaire en ligne de commande c++filt -t.

Exemple

#include <boost/core/demangle.hpp>
#include <cstdlib>
#include <iostream>
#include <string>
#include <typeinfo>

struct Base { virtual ~Base() = default; };
struct Derived : Base {};

int main()
{
    Base b1;
    Derived d1;

    const Base* pb = &b1;
    std::cout << typeid(*pb).name() << '\n';
    pb = &d1;
    std::cout << typeid(*pb).name() << '\n';

    std::string real_name = boost::core::demangle(typeid(pb).name());
    std::cout << typeid(pb).name() << " => " << real_name << '\n';

    std::cout << "c++filt => " << std::flush;
    std::string s = typeid(pb).name();
    std::system(("c++filt -t " + s).data());
}
