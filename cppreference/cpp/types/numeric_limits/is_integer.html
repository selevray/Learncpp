std::numeric_limits<T>::is_integer

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static const bool is_integer;  // (jusqu'à C++11)

static constexpr bool is_integer;  // (depuis C++11)

La valeur de std::numeric_limits<T>::is_integer est true pour tous les types arithmétiques entiers T et false sinon. Cette constante a un sens pour toutes les spécialisations.

Spécialisations standard

T valeur de std::numeric_limits<T>::is_integer

  • /* non spécialisé */ — false
  • bool — true
  • char — true
  • signed char — true
  • unsigned char — true
  • wchar_t — true
  • char8_t (depuis C++20) — true
  • char16_t (depuis C++11) — true
  • char32_t (depuis C++11) — true
  • short — true
  • unsigned short — true
  • int — true
  • unsigned int — true
  • long — true
  • unsigned long — true
  • long long (depuis C++11) — true
  • unsigned long long (depuis C++11) — true
  • float — false
  • double — false
  • long double — false

Exemple

#include <cstddef>
#include <cstdint>
#include <limits>

static_assert
(
        std::numeric_limits<bool>::is_integer
    &&  std::numeric_limits<std::size_t>::is_integer
    &&  std::numeric_limits<std::int32_t>::is_integer
    &&  std::numeric_limits<std::int64_t>::is_integer
    &&  std::numeric_limits<decltype(42)>::is_integer
    && !std::numeric_limits<int*>::is_integer
    && !std::numeric_limits<float>::is_integer
    && !std::numeric_limits<double>::is_integer
    && !std::numeric_limits<long double>::is_integer
    && !std::numeric_limits<decltype([](){})>::is_integer // P0315R4
);

int main() {}
