enum float_denorm_style {
    denorm_indeterminate = -1,
    denorm_absent        = 0,
    denorm_present       = 1
};  // (obsolète en C++23)

Les constantes d'énumération de type std::float_denorm_style indiquent la prise en charge des valeurs subnormales par les types à virgule flottante.

Constantes d'énumération

Nom Définition

  • std::denorm_indeterminate — La prise en charge des valeurs subnormales ne peut pas être déterminée
  • std::denorm_absent — Le type ne prend pas en charge les valeurs subnormales
  • std::denorm_present — Le type autorise les valeurs subnormales
