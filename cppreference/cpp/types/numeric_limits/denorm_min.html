std::numeric_limits<T>::denorm_min

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static T denorm_min() throw();  // (jusqu'à C++11)

static constexpr T denorm_min() noexcept;  // (depuis C++11)

Renvoie la plus petite valeur subnormale strictement positive du type T, si std::numeric_limits<T>::has_denorm != std::denorm_absent, sinon renvoie std::numeric_limits<T>::min() pour les types à virgule flottante et T() pour tous les autres types. N'a de sens que pour les types à virgule flottante.

Valeur de retour

T std::numeric_limits<T>::denorm_min()

  • /* non spécialisé */ — T()
  • bool — false
  • char — 0
  • signed char — 0
  • unsigned char — 0
  • wchar_t — 0
  • char8_t (depuis C++20) — 0
  • char16_t (depuis C++11) — 0
  • char32_t (depuis C++11) — 0
  • short — 0
  • unsigned short — 0
  • int — 0
  • unsigned int — 0
  • long — 0
  • unsigned long — 0
  • long long (depuis C++11) — 0
  • unsigned long long depuis (depuis C++11) — 0
  • float — FLT_TRUE_MIN ((\scriptsize 2^{-149})2-149 si std::numeric_limits<float>::is_iec559 vaut true)
  • double — DBL_TRUE_MIN ((\scriptsize 2^{-1074})2-1074 si std::numeric_limits<double>::is_iec559 vaut true)
  • long double — LDBL_TRUE_MIN

Exemple

Démontre la structure binaire sous-jacente de denorm_min() et affiche les valeurs :

#include <cassert>
#include <cstdint>
#include <cstring>
#include <iostream>
#include <limits>

int main()
{
    // la plus petite valeur subnormale a un bit de signe = 0, un exposant = 0
    // et seul le bit de poids faible de la fraction vaut 1
    std::uint32_t denorm_bits = 0x0001;
    float denorm_float;
    std::memcpy(&denorm_float, &denorm_bits, sizeof(float));

    assert(denorm_float == std::numeric_limits<float>::denorm_min());

    std::cout << "float\tmin()\t\tdenorm_min()\n";
    std::cout << "\t" << std::numeric_limits<float>::min() << '\t';
    std::cout <<         std::numeric_limits<float>::denorm_min() << '\n';

    std::cout << "double\tmin()\t\tdenorm_min()\n";
    std::cout << "\t" << std::numeric_limits<double>::min() << '\t';
    std::cout <<         std::numeric_limits<double>::denorm_min() << '\n';
}

Voir aussi

  • min [statique] — renvoie la plus petite valeur finie du type non flottant donné, ou la plus petite valeur normale strictement positive du type à virgule flottante donné (fonction membre statique publique)
  • has_denorm [statique] — identifie le style de dénormalisation utilisé par le type à virgule flottante (constante membre statique publique)
  • lowest [statique] (C++11) — renvoie la plus petite valeur finie du type donné, c'est-à-dire la valeur la plus négative pour les types signés, 0 pour les types non signés (fonction membre statique publique)
