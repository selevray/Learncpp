std::numeric_limits<T>::has_signaling_NaN

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static const bool has_signaling_NaN;  // (jusqu'à C++11)

static constexpr bool has_signaling_NaN;  // (depuis C++11)

La valeur de std::numeric_limits<T>::has_signaling_NaN est true pour tous les types T capables de représenter la valeur spéciale « Not-A-Number signalant ». Cette constante a un sens pour tous les types à virgule flottante et est garantie d'être true si std::numeric_limits<T>::is_iec559 == true.
