std::numeric_limits<T>::radix

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static const int radix;  // (jusqu'à C++11)

static constexpr int radix;  // (depuis C++11)

La valeur de std::numeric_limits<T>::radix est la base du système de numération utilisé pour représenter le type. Elle vaut 2 pour tous les types numériques binaires, mais elle peut valoir, par exemple, 10 pour les types à virgule flottante décimale IEEE 754 ou pour des entiers décimaux codés binaires tiers. Cette constante a un sens pour toutes les spécialisations.
