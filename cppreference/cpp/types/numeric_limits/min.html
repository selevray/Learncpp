std::numeric_limits<T>::min

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <limits>

static T min() throw();  // (jusqu'à C++11)

static constexpr T min() noexcept;  // (depuis C++11)

Renvoie la plus petite valeur finie représentable par le type numérique T.

Pour les types à virgule flottante avec dénormalisation, min() renvoie la plus petite valeur normalisée positive. Notez que ce comportement peut surprendre, en particulier par rapport au comportement de min() pour les types entiers. Pour trouver la valeur qui n'a aucune valeur inférieure, utilisez lowest(). (depuis C++11)

min() n'a de sens que pour les types bornés et pour les types non signés non bornés.

Valeur de retour

T std::numeric_limits<T>::min()

  • /* non spécialisé */ — T()
  • bool — false
  • char — CHAR_MIN
  • signed char — SCHAR_MIN
  • unsigned char — 0
  • wchar_t — WCHAR_MIN
  • char8_t (depuis C++20) — 0
  • char16_t (depuis C++11) — 0
  • char32_t (depuis C++11) — 0
  • short — SHRT_MIN
  • unsigned short — 0
  • int — INT_MIN
  • unsigned int — 0
  • long — LONG_MIN
  • unsigned long — 0
  • long long (depuis C++11) — LLONG_MIN
  • unsigned long long (depuis C++11) — 0
  • float — FLT_MIN
  • double — DBL_MIN
  • long double — LDBL_MIN

Exemple

Démontre l'utilisation avec des types typedef, et la différence de signe du résultat entre les types entiers et à virgule flottante :

#include <cstddef>
#include <iomanip>
#include <iostream>
#include <limits>

// nous voulons afficher les types char sous forme d'entier sans les F initiaux
auto p(auto x) { return x; }
auto p(char x) { return x & static_cast<unsigned char>(-1); }

template <typename T>
void print_one(std::string_view type_name)
{
    constexpr T min = std::numeric_limits<T>::min();

    std::cout
        << std::dec << std::defaultfloat << std::setw(14) << type_name
        << " (" << std::setw(2) << sizeof(T) << " bytes): " << +min;

    if constexpr (min != 0)
        std::cout << " or " << std::showbase << std::hex << std::hexfloat << p(min);

    std::cout << '\n';
}

#define SHOW(T) print_one<T>(#T)

int main()
{
    SHOW(bool);
    SHOW(char);
    SHOW(unsigned char);
    SHOW(short);
    SHOW(unsigned short);
    SHOW(signed);
    SHOW(unsigned);
    SHOW(std::ptrdiff_t);
    SHOW(std::size_t);
    SHOW(float);
    SHOW(double);
    SHOW(long double);
}
