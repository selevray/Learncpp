std::numeric_limits<T>::round_error

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static T round_error() throw();  // (jusqu'à C++11)

static constexpr T round_error() noexcept;  // (depuis C++11)

Renvoie l'erreur d'arrondi maximale possible en ULP (unités du dernier rang) telle que définie par ISO 10967, qui peut varier de 0.5 (arrondi au chiffre le plus proche) à 1.0 (arrondi vers zéro ou vers l'infini). N'a de sens que si std::numeric_limits<T>::is_integer == false.
