std::is_pointer_interconvertible_base_of

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class Base, class Derived >
struct is_pointer_interconvertible_base_of;  // (depuis C++20)

Si Derived dérive de façon non ambiguë de Base et que chaque objet Derived est pointer-interconvertible avec son sous-objet Base, ou si les deux sont la même classe non union (dans les deux cas en ignorant la qualification cv), fournit la constante membre value égale à true. Sinon value vaut false.

Si Base et Derived sont tous deux des types classe non union et qu'ils ne sont pas le même type (en ignorant la qualification cv), Derived doit être un type complet ; sinon le comportement est indéfini.

Si le programme ajoute des spécialisations pour std::is_pointer_interconvertible_base_of ou std::is_pointer_interconvertible_base_of_v, le comportement est indéfini.

Modèle de variable auxiliaire

template< class Base, class Derived >
inline constexpr bool is_pointer_interconvertible_base_of_v =
    is_pointer_interconvertible_base_of<Base, Derived>::value;  // (depuis C++20)

Notes

std::is_pointer_interconvertible_base_of_v<T, U> peut être true même si T est une classe de base privée ou protégée de U.

Soit

  • U doit être un type objet complet,
  • T doit être un type objet complet avec une qualification cv non moindre que U,
  • u doit être une lvalue valide de U,

reinterpret_cast<T&>(u) a toujours un résultat bien défini si std::is_pointer_interconvertible_base_of_v<T, U> est true.

Si T et U ne sont pas le même type (en ignorant la qualification cv) et que T est une classe de base pointer-interconvertible de U, alors std::is_standard_layout_v<T> et std::is_standard_layout_v<U> sont true.

Si T est un type classe à disposition standard, alors toutes les classes de base de T (s'il en existe) sont des classes de base pointer-interconvertibles de T.

Exemple

#include <type_traits>

struct Foo {};

struct Bar {};

class Baz : Foo, public Bar { int x; };

class NonStdLayout : public Baz { int y; };

static_assert(std::is_pointer_interconvertible_base_of_v<Bar, Baz>);
static_assert(std::is_pointer_interconvertible_base_of_v<Foo, Baz>);
static_assert(not std::is_pointer_interconvertible_base_of_v<Baz, NonStdLayout>);
static_assert(std::is_pointer_interconvertible_base_of_v<NonStdLayout, NonStdLayout>);

int main() {}
