std::numeric_limits

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <limits>

template< class T > class numeric_limits;

Le modèle de classe std::numeric_limits fournit une manière standardisée d'interroger diverses propriétés des types arithmétiques (par exemple la plus grande valeur possible pour le type int est std::numeric_limits<int>::max()).

Ces informations sont fournies via des spécialisations du modèle std::numeric_limits. La bibliothèque standard fournit des spécialisations pour tous les types arithmétiques (ne liste que les spécialisations pour les types arithmétiques non qualifiés cv) :

La valeur de chaque membre d'une spécialisation de std::numeric_limits sur un type qualifié cv T est égale à la valeur du membre correspondant de la spécialisation sur le type non qualifié T. Par exemple, std::numeric_limits<int>::digits est égal à std::numeric_limits<const int>::digits.

Les alias de types arithmétiques (tels que std::size_t ou std::streamsize) peuvent aussi être examinés avec les traits de types std::numeric_limits.

Les types standard non arithmétiques, tels que std::complex<T> ou std::nullptr_t, n'ont pas de spécialisations.

Si l'implémentation définit des types de classe entière, des spécialisations de std::numeric_limits doivent aussi être fournies pour eux.

(depuis C++20)

Les implémentations peuvent fournir des spécialisations de std::numeric_limits pour des types propres à l'implémentation : par exemple GCC fournit std::numeric_limits<__int128>. Les bibliothèques non standard peuvent ajouter des spécialisations pour des types fournis par la bibliothèque, par exemple OpenEXR fournit std::numeric_limits<half> pour un type à virgule flottante de 16 bits.

Paramètres de modèle

  • T — un type dont on veut récupérer les propriétés numériques

Constantes membres

  • is_specialized [statique] — identifie les types pour lesquels std::numeric_limits est spécialisé (constante membre statique publique)
  • is_signed [statique] — identifie les types signés (constante membre statique publique)
  • is_integer [statique] — identifie les types entiers (constante membre statique publique)
  • is_exact [statique] — identifie les types exacts (constante membre statique publique)
  • has_infinity [statique] — identifie les types à virgule flottante pouvant représenter la valeur spéciale « infini positif » (constante membre statique publique)
  • has_quiet_NaN [statique] — identifie les types à virgule flottante pouvant représenter la valeur spéciale « quiet not-a-number » (NaN) (constante membre statique publique)
  • has_signaling_NaN [statique] — identifie les types à virgule flottante pouvant représenter la valeur spéciale « signaling not-a-number » (NaN) (constante membre statique publique)
  • has_denorm [statique] — identifie le style de dénormalisation utilisé par le type à virgule flottante (constante membre statique publique)
  • has_denorm_loss [statique] — identifie les types à virgule flottante qui détectent la perte de précision comme une perte de dénormalisation plutôt que comme un résultat inexact (constante membre statique publique)
  • round_style [statique] — identifie le style d'arrondi utilisé par le type (constante membre statique publique)
  • is_iec559 [statique] — identifie les types à virgule flottante IEC 559/IEEE 754 (constante membre statique publique)
  • is_bounded [statique] — identifie les types représentant un ensemble fini de valeurs (constante membre statique publique)
  • is_modulo [statique] — identifie les types qui gèrent les débordements par une arithmétique modulo (constante membre statique publique)
  • digits [statique] — nombre de chiffres radix pouvant être représentés sans modification (constante membre statique publique)
  • digits10 [statique] — nombre de chiffres décimaux pouvant être représentés sans modification (constante membre statique publique)
  • max_digits10 [statique] (C++11) — nombre de chiffres décimaux nécessaires pour distinguer toutes les valeurs de ce type (constante membre statique publique)
  • radix [statique] — la base (radix) ou base entière utilisée par la représentation du type donné (constante membre statique publique)
  • min_exponent [statique] — un de plus que la plus petite puissance négative de la base qui soit une valeur normalisée valide à virgule flottante (constante membre statique publique)
  • min_exponent10 [statique] — la plus petite puissance négative de dix qui soit une valeur normalisée valide à virgule flottante (constante membre statique publique)
  • max_exponent [statique] — un de plus que la plus grande puissance entière de la base qui soit une valeur finie valide à virgule flottante (constante membre statique publique)
  • max_exponent10 [statique] — la plus grande puissance entière de 10 qui soit une valeur finie valide à virgule flottante (constante membre statique publique)
  • traps [statique] — identifie les types pouvant provoquer le déclenchement de pièges lors d'opérations arithmétiques (constante membre statique publique)
  • tinyness_before [statique] — identifie les types à virgule flottante qui détectent le caractère infinitésimal avant arrondi (constante membre statique publique)

Fonctions membres

  • min [statique] — renvoie la plus petite valeur finie du type non flottant donné, ou la plus petite valeur normale strictement positive du type à virgule flottante donné (fonction membre statique publique)
  • lowest [statique] (C++11) — renvoie la plus petite valeur finie du type donné, c'est-à-dire la valeur la plus négative pour les types signés, 0 pour les types non signés (fonction membre statique publique)
  • max [statique] — renvoie la plus grande valeur finie du type donné (fonction membre statique publique)
  • epsilon [statique] — retourne la différence entre 1.0 et la valeur représentable suivante du type à virgule flottante donné (fonction membre statique publique)
  • round_error [statique] — retourne l'erreur d'arrondi maximale du type à virgule flottante donné (fonction membre statique publique)
  • infinity [statique] — renvoie la valeur d'infini positif du type à virgule flottante donné (fonction membre statique publique)
  • quiet_NaN [statique] — renvoie une valeur NaN silencieuse du type à virgule flottante donné (fonction membre statique publique)
  • signaling_NaN [statique] — renvoie une valeur NaN signalante du type à virgule flottante donné (fonction membre statique publique)
  • denorm_min [statique] — renvoie la plus petite valeur subnormale strictement positive du type à virgule flottante donné (fonction membre statique publique)

Classes auxiliaires

  • float_round_style — indique les modes d'arrondi des nombres à virgule flottante (enum)
  • float_denorm_style — indique les modes de dénormalisation des nombres à virgule flottante (enum)

Exemple

#include <iostream>
#include <limits>

int main()
{
    std::cout << "type\t│ lowest()\t│ min()\t\t│ max()\n"
              << "bool\t│ "
              << std::numeric_limits<bool>::lowest() << "\t\t│ "
              << std::numeric_limits<bool>::min() << "\t\t│ "
              << std::numeric_limits<bool>::max() << '\n'
              << "uchar\t│ "
              << +std::numeric_limits<unsigned char>::lowest() << "\t\t│ "
              << +std::numeric_limits<unsigned char>::min() << "\t\t│ "
              << +std::numeric_limits<unsigned char>::max() << '\n'
              << "int\t│ "
              << std::numeric_limits<int>::lowest() << "\t│ "
              << std::numeric_limits<int>::min() << "\t│ "
              << std::numeric_limits<int>::max() << '\n'
              << "float\t│ "
              << std::numeric_limits<float>::lowest() << "\t│ "
              << std::numeric_limits<float>::min() << "\t│ "
              << std::numeric_limits<float>::max() << '\n'
              << "double\t│ "
              << std::numeric_limits<double>::lowest() << "\t│ "
              << std::numeric_limits<double>::min() << "\t│ "
              << std::numeric_limits<double>::max() << '\n';
}

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 201 C++98 les spécialisations pour tous les types fondamentaux doivent être fournies types non arithmétiques exclus
LWG 559 C++98 on ne savait pas clairement si la spécialisation std::numeric_limits pour un type qualifié cv se comporte de la même manière que la spécialisation correspondante pour le type non qualifié cv ils ont le même comportement
