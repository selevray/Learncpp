std::underlying_type

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct underlying_type;  // (depuis C++11)

Si T est un type énumération (enum) complet, fournit un typedef membre type qui désigne le type sous-jacent de T.

Dans le cas contraire, le comportement est indéfini.

(jusqu'à C++20)

Sinon, si T n'est pas un type énumération, il n'existe aucun membre type. Sinon (T est un type énumération incomplet), le programme est mal formé.

(depuis C++20)

Si le programme ajoute des spécialisations pour std::underlying_type, le comportement est indéfini.

Types membres

Nom Définition

  • type — le type sous-jacent de T

Types auxiliaires

template< class T >
using underlying_type_t = typename underlying_type<T>::type;  // (depuis C++14)

Notes

Chaque type énumération possède un type sous-jacent, qui peut être

  1. spécifié explicitement (énumérations scoped et unscoped) ;
  2. omis, auquel cas il s'agit de int pour les énumérations scoped, ou d'un type entier défini par l'implémentation capable de représenter toutes les valeurs de l'enum (pour les énumérations unscoped).

Exemple

#include <iostream>
#include <type_traits>

enum e1 {};
enum class e2 {};
enum class e3 : unsigned {};
enum class e4 : int {};

int main()
{
    constexpr bool e1_t = std::is_same_v<std::underlying_type_t<e1>, int>;
    constexpr bool e2_t = std::is_same_v<std::underlying_type_t<e2>, int>;
    constexpr bool e3_t = std::is_same_v<std::underlying_type_t<e3>, int>;
    constexpr bool e4_t = std::is_same_v<std::underlying_type_t<e4>, int>;

    std::cout
        << "underlying type for 'e1' is " << (e1_t ? "int" : "non-int") << '\n'
        << "underlying type for 'e2' is " << (e2_t ? "int" : "non-int") << '\n'
        << "underlying type for 'e3' is " << (e3_t ? "int" : "non-int") << '\n'
        << "underlying type for 'e4' is " << (e4_t ? "int" : "non-int") << '\n';
}

Sortie possible :

underlying type for 'e1' is non-int
underlying type for 'e2' is int
underlying type for 'e3' is non-int
underlying type for 'e4' is int
