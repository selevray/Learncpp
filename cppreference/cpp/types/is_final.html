std::is_final

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_final;  // (depuis C++14)

std::is_final est un UnaryTypeTrait.

Si T est une classe final, fournit la constante membre value égale à true. Pour tout autre type, value vaut false.

Si T est un type classe incomplet, le comportement est indéfini.

Si le programme ajoute des spécialisations pour std::is_finalou std::is_final_v (depuis C++17), le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_final_v = is_final<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type classe final, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Notes

std::is_final est introduit par la résolution du LWG issue 2112.

Un union peut être déclaré final (et std::is_final le détectera), même si les unions ne peuvent en aucun cas servir de classes de base.

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_is_final 201402L (C++14) std::is_final

Exemple

#include <type_traits>

class A {};
static_assert(std::is_final_v<A> == false);

class B final {};
static_assert(std::is_final_v<B> == true);

union U final
{
    int x;
    double d;
};
static_assert(std::is_final_v<U> == true);

int main()
{
}
