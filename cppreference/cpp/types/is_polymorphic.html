std::is_polymorphic

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_polymorphic;  // (depuis C++11)

std::is_polymorphic est un UnaryTypeTrait.

Si T est une classe polymorphe (c'est-à-dire une classe non union qui déclare ou hérite d'au moins une fonction virtuelle), fournit la constante membre value égale à true. Pour tout autre type, value vaut false.

Si T est un type classe non union incomplet, le comportement est indéfini.

Si le programme ajoute des spécialisations pour std::is_polymorphic ou std::is_polymorphic_v, le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_polymorphic_v = is_polymorphic<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type classe polymorphe, false sinon (constante statique publique membre)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Implémentation possible

namespace detail
{
    template<class T>
    std::true_type detect_is_polymorphic(
        decltype(dynamic_cast<const volatile void*>(static_cast<T*>(nullptr)))
    );
    template<class T>
    std::false_type detect_is_polymorphic(...);
} // espace de noms detail

template<class T>
struct is_polymorphic : decltype(detail::detect_is_polymorphic<T>(nullptr)) {};

Exemple

#include <type_traits>

struct A { int m; };
static_assert(!std::is_polymorphic_v<A>);

struct B { virtual void foo(); };
static_assert(std::is_polymorphic_v<B>);

struct C : B {};
static_assert(std::is_polymorphic_v<C>);

struct D { virtual ~D() = default; };
static_assert(std::is_polymorphic_v<D>);

// Utilise l'héritage, mais pas le mot-clé virtual :
struct E : A {};
static_assert(!std::is_polymorphic_v<E>);

struct F : virtual A {};
static_assert(!std::is_polymorphic_v<F>);

struct AX : A {};
struct AY : A {};
struct XY : virtual AX, virtual AY {};
static_assert(!std::is_polymorphic_v<XY>);

int main() {}
