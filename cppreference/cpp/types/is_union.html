std::is_union

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_union;  // (depuis C++11)

std::is_union est un UnaryTypeTrait.

Vérifie si T est un type union. Fournit la constante membre value, égale à true si T est un type union. Sinon, value est égale à false.

Si le programme ajoute des spécialisations pour std::is_union ou std::is_union_v, le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_union_v = is_union<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type union, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Exemple

#include <type_traits>

struct A {};
static_assert(!std::is_union_v<A>);

typedef union
{
    int a;
    float b;
} B;
static_assert(std::is_union_v<B>);

struct C { B d; };
static_assert(!std::is_union_v<C>);

static_assert(!std::is_union_v<int>);

int main() {}
