offsetof

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstddef>

#define offsetof(type, member) /* implementation-defined */

La macro offsetof se développe en une expression constante entière de type std::size_t, dont la valeur est le décalage, en octets, depuis le début d'un objet du type spécifié jusqu'à son sous-objet spécifié, y compris les bits de remplissage le cas échéant.

Étant donné un objet o de type type et de durée de stockage statique, o.member doit être une expression constante lvalue qui désigne un sous-objet de o. Sinon, le comportement est indéfini. En particulier, si member est un membre de donnée statique, un champ de bits ou une fonction membre, le comportement est indéfini.

Si type n'est pas un [ PODType (jusqu'à C++11) | type standard-layout (depuis C++11)], [le résultat de offsetof est indéfini (jusqu'à C++17) | l'utilisation de la macro offsetof est conditionnellement prise en charge (depuis C++17)].

L'expression offsetof(type, member) n'est jamais dépendante du type et elle est dépendante de la valeur si et seulement si type est dépendant.

Exceptions

offsetof ne lève aucune exception.

L'expression noexcept(offsetof(type, member)) s'évalue toujours à true.

(depuis C++11)

Notes

Le décalage du premier membre d'un type standard-layout est toujours nul (l'optimisation de la base vide est obligatoire).

(depuis C++11)

offsetof ne peut pas être implémenté en C++ standard et nécessite la prise en charge du compilateur : GCC, LLVM.

member n'est pas restreint à un membre direct. Il peut désigner un sous-objet d'un membre donné, comme un élément d'un membre tableau. Ceci est spécifié par le C DR 496.

Il est spécifié en C23 que la définition d'un nouveau type contenant une virgule non parenthésée dans offsetof est un comportement indéfini, et une telle utilisation n'est généralement pas prise en charge par les implémentations en modes C++ : offsetof(struct Foo { int a, b; }, a) est rejeté par toutes les implémentations connues.

Exemple

#include <cstddef>
#include <iostream>

struct S
{
    char   m0;
    double m1;
    short  m2;
    char   m3;
//  private: int z; // avertissement : 'S' est un type à disposition non standard
};

int main()
{
    std::cout
        << "offset of char   m0 = " << offsetof(S, m0) << '\n'
        << "offset of double m1 = " << offsetof(S, m1) << '\n'
        << "offset of short  m2 = " << offsetof(S, m2) << '\n'
        << "offset of char   m3 = " << offsetof(S, m3) << '\n';
}

Sortie possible :

offset of char   m0 = 0
offset of double m1 = 8
offset of short  m2 = 16
offset of char   m3 = 18

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.
