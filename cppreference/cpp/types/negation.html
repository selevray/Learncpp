std::negation

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class B >
struct negation;  // (depuis C++17)

Forme la négation logique du trait de type B.

Le type std::negation<B> est un UnaryTypeTrait dont la caractéristique de base est std::bool_constant<!bool(B::value)>.

Si le programme ajoute des spécialisations pour std::negation ou std::negation_v, le comportement est indéfini.

Paramètres de modèle

  • B — tout type tel que l'expression bool(B::value) est une expression constante valide

Modèle de variable auxiliaire

template< class B >
constexpr bool negation_v = negation<B>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si B possède un membre ::value qui vaut false lorsqu'il est explicitement converti en bool, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Implémentation possible

template<class B>
struct negation : std::bool_constant<!bool(B::value)> { };

Exemple

#include <type_traits>

static_assert(
    std::is_same<
        std::bool_constant<false>,
        typename std::negation<std::bool_constant<true>>::type>::value,
    "");
static_assert(
    std::is_same<
        std::bool_constant<true>,
        typename std::negation<std::bool_constant<false>>::type>::value,
    "");

static_assert(std::negation_v<std::bool_constant<true>> == false);
static_assert(std::negation_v<std::bool_constant<false>> == true);

int main() {}
