std::common_reference

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class... T >
struct common_reference;  // (depuis C++20)

Détermine le type référence commun des types T..., c'est-à-dire le type vers lequel tous les types de T... peuvent être convertis ou liés. Si un tel type existe (selon les règles ci-dessous), le membre type désigne ce type. Sinon, il n'existe aucun membre type. Le comportement est indéfini si l'un des types de T... est un type incomplet autre que void (éventuellement qualifié cv).

Pour des types référence, common_reference tente de trouver un type référence auquel tous les types référence fournis peuvent être liés, mais peut renvoyer un type non référence s'il ne trouve pas un tel type référence.

  • Si sizeof...(T) vaut zéro, il n'existe aucun membre type.
  • Si sizeof...(T) vaut un (c'est-à-dire que T... ne contient qu'un seul type T0), le membre type désigne le même type que T0.
  • Si sizeof...(T) vaut deux (c'est-à-dire que T... contient deux types T1 et T2) :
    • Soit le type S le type de référence commun simple de T1 et T2 (tel que défini ci-dessous). Le type membre type désigne S si toutes les conditions ci-dessous sont satisfaites :
      • T1 et T2 sont tous deux des types référence
      • S est bien formée
  • std::is_convertible_v<std::add_pointer_t<T1>, std::add_pointer_t<S>> et std::is_convertible_v<std::add_pointer_t<T2>, std::add_pointer_t<S>> sont true ;

(depuis C++23)

  • Sinon, si std::basic_common_reference<std::remove_cvref_t<T1>, std::remove_cvref_t<T2>, T1Q, T2Q>::type existe, où TiQ est un modèle d'alias unaire tel que TiQ<U> soit U avec l'ajout des qualificateurs cv et de référence de Ti, alors le type membre type désigne ce type ;

    • Sinon, si decltype(false? val<T1>() : val<T2>()), où val est un modèle de fonction template<class T> T val();, est un type valide, alors le type membre type désigne ce type ;
    • Sinon, si std::common_type_t<T1, T2> est un type valide, alors le type membre type désigne ce type ;
    • Sinon, il n'existe aucun membre type.

  • Si sizeof...(T) est supérieur à deux (c'est-à-dire que T... est constitué des types T1, T2, R...), alors, si std::common_reference_t<T1, T2> existe, le membre type désigne std::common_reference_t<std::common_reference_t<T1, T2>, R...> si un tel type existe. Dans tous les autres cas, il n'existe aucun membre type.

Le type référence commun simple de deux types référence T1 et T2 est défini comme suit :

  • Si T1 est cv1 X& et T2 est cv2 Y& (c'est-à-dire que les deux sont des types référence lvalue) : leur type de référence commun simple est decltype(false? std::declval<cv12 X&>() : std::declval<cv12 Y&>()), où cv12 est l'union de cv1 et cv2, si ce type existe et est un type référence ;
  • Si T1 et T2 sont tous deux des types référence rvalue : si le type de référence commun simple de T1& et T2& (déterminé selon le point précédent) existe, alors soit C ce type, et son type référence rvalue correspondant. Si std::is_convertible_v<T1, C> et std::is_convertible_v<T2, C> sont tous deux true, alors le type de référence commun simple de T1 et T2 est C ;
  • Sinon, l'un des deux types doit être un type référence lvalue A& et l'autre un type référence rvalue B&& (A et B peuvent être qualifiés cv). Soit D le type de référence commun simple de A& et B const&, s'il existe. Si D existe et que std::is_convertible_v<B&&, D> est true, alors le type de référence commun simple est D ;
  • Sinon, il n'existe aucun type référence commun simple.

Types auxiliaires

template< class... T >
using common_reference_t = std::common_reference<T...>::type;

template< class T, class U, template<class> class TQual, template<class> class UQual >
struct basic_common_reference {};

Le modèle de classe basic_common_reference est un point de personnalisation qui permet aux utilisateurs d'influencer le résultat de common_reference pour les types définis par l'utilisateur (typiquement des références mandataires). Le modèle primaire est vide.

Spécialisations

Un programme peut spécialiser std::basic_common_reference<T, U, TQual, UQual> sur les deux premiers paramètres T et U si std::is_same_v<T, std::decay_t<T>> et std::is_same_v<U, std::decay_t<U>> sont tous deux true et qu'au moins l'un d'eux dépend d'un type défini par le programme.

Si une telle spécialisation possède un membre nommé type, il doit s'agir d'un membre public et non ambigu désignant un type vers lequel TQual<T> et UQual<U> sont convertibles. De plus, std::basic_common_reference<T, U, TQual, UQual>::type et std::basic_common_reference<U, T, UQual, TQual>::type doivent désigner le même type.

Un programme ne peut pas spécialiser basic_common_reference sur le troisième ou le quatrième paramètre, ni spécialiser common_reference lui-même. Un programme qui ajoute des spécialisations en violation de ces règles a un comportement indéfini.

La bibliothèque standard fournit les spécialisations suivantes de basic_common_reference :

  • std::basic_common_reference<std::pair> (C++23) — détermine le type de référence commun de deux pairs (spécialisation de modèle de classe)
  • std::basic_common_reference<tuple-like> (C++23) — détermine le type de référence commun d'un tuple et d'un type tuple-like (spécialisation de modèle de classe)
  • std::basic_common_reference<std::reference_wrapper> (C++23) — détermine le type de référence commun de reference_wrapper et d'un reference_wrapper non (spécialisation de modèle de classe)

Exemples

#include <concepts>
#include <type_traits>

static_assert(
    std::same_as<
        int&,
        std::common_reference_t<
            std::add_lvalue_reference_t<int>,
            std::add_lvalue_reference_t<int>&,
            std::add_lvalue_reference_t<int>&&,
            std::add_lvalue_reference_t<int>const,
            std::add_lvalue_reference_t<int>const&
        >
    >
);

int main() {}
