std::is_pod

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_pod;  // (depuis C++11) (obsolète en C++20)

std::is_pod est un UnaryTypeTrait.

Si T est un type POD (« plain old data type »), fournit la constante membre value égale à true. Pour tout autre type, value vaut false.

Si std::remove_all_extents_t<T> est un type incomplet et n'est pas (éventuellement qualifié cv) void, le comportement est indéfini.

Si le programme ajoute des spécialisations pour std::is_pod ou std::is_pod_v, le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_pod_v = is_pod<T>::value;  // (depuis C++17) (obsolète en C++20)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type POD, false sinon (constante statique publique membre)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Exemple

#include <type_traits>

struct A { int m; };
static_assert(std::is_pod_v<A> == true);

class B: public A { int m; };
static_assert(std::is_pod_v<B> == false);

struct C { virtual void foo(); };
static_assert(std::is_pod_v<C> == false);

int main() {}
