std::type_identity

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct type_identity;  // (depuis C++20)

Fournit le typedef membre type qui désigne T (c.-à-d. la transformation identité).

Si le programme ajoute des spécialisations pour std::type_identity, le comportement est indéfini.

Types membres

Nom Définition

  • type — T

Types auxiliaires

template< class T >
using type_identity_t = type_identity<T>::type;  // (depuis C++20)

Implémentation possible

template<class T>
struct type_identity { using type = T; };

Notes

std::type_identity peut être utilisé pour établir des contextes non déductibles dans la déduction d'arguments de modèle.

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_type_identity 201806L (C++20) std::type_identity

Exemple

#include <iostream>
#include <type_traits>

template<class T>
T foo(T a, T b) { return a + b; }

template<class T>
T bar(T a, std::type_identity_t<T> b) { return a + b; }

int main()
{
    // foo(4.2, 1); // erreur, types en conflit déduits pour 'T'
    std::cout << bar(4.2, 1) << '\n';  // OK, appelle bar<double>
}

Output:

5.2
