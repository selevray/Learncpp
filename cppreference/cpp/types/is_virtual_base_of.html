std::is_virtual_base_of

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class Base, class Derived >
struct is_virtual_base_of;  // (depuis C++26)

std::is_virtual_base_of est un BinaryTypeTrait.

Si Base est une classe de base virtuelle de Derived (en ignorant la qualification cv), fournit la constante membre value égale à true. Sinon value vaut false.

Si Base et Derived sont toutes deux des classes non union (en ignorant la qualification cv), Derived doit être un type complet ; sinon le comportement est indéfini.

Si le programme ajoute des spécialisations pour std::is_virtual_base_of ou std::is_virtual_base_of_v, le comportement est indéfini.

Modèle de variable auxiliaire

template< class Base, class Derived >
constexpr bool is_virtual_base_of_v = is_virtual_base_of<Base, Derived>::value;  // (depuis C++26)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si Derived dérive de la classe de base virtuelle Base (en ignorant la qualification cv), false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Notes

std::is_virtual_base_of_v<A, B> est true même si A est une classe de base privée, protégée ou ambiguë de B.

Si std::is_virtual_base_of_v<A, B> est true, alors std::is_base_of_v<A, B> est aussi true. Cependant, la réciproque n'est pas toujours vraie, car la vérification de l'héritage virtuel est plus précise. Dans ce cas, std::is_virtual_base_of_v<T, T> est false même si T est un type de classe qui n'est pas une union.

Exemple

#include <type_traits>

class A {};
class B : A {};
class C : B {};
class D : virtual A {};
class E : D {};

union F {};
using I = int;

static_assert
(
    std::is_virtual_base_of_v<A, A> != true &&
    std::is_virtual_base_of_v<A, B> != true &&
    std::is_virtual_base_of_v<A, D> == true &&
    std::is_virtual_base_of_v<D, E> != true &&
    std::is_virtual_base_of_v<F, F> != true &&
    std::is_virtual_base_of_v<I, I> != true
);

int main() {}
