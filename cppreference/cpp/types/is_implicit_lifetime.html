std::is_implicit_lifetime

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_implicit_lifetime;  // (depuis C++23)

std::is_implicit_lifetime est un UnaryTypeTrait.

Si T est un type à durée de vie implicite, fournit la constante membre value égale à true. Pour tout autre type, value vaut false.

Le comportement est indéfini si T est un type incomplet autre qu'un type tableau ou (éventuellement qualifié cv) void.

Si le programme ajoute des spécialisations pour std::is_implicit_lifetime ou std::is_implicit_lifetime_v, le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_implicit_lifetime_v = is_implicit_lifetime<T>::value;  // (depuis C++23)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type à durée de vie implicite, false sinon (constante membre statique publique)

Fonctions membres

Exemple

// Les types suivants sont collectivement appelés types à durée de vie implicite :
// * types scalaires :
//     * types arithmétiques
//     * types énumération
//     * types pointeurs
//     * types pointeur vers membre
//     * std::nullptr_t
// * types classe à durée de vie implicite
//     * est un agrégat dont le destructeur n'est pas fourni par l'utilisateur
//     * possède au moins un constructeur trivial éligible et un destructeur trivial,
//       destructeur non supprimé
// * types tableau
// * versions qualifiées cv de ces types.
#include <type_traits>

static_assert(std::is_implicit_lifetime_v<int>); // un type arithmétique est un type scalaire
static_assert(std::is_implicit_lifetime_v<const int>); // un type scalaire qualifié cv

enum E { e };
static_assert(std::is_implicit_lifetime_v<E>); // un type énumération est un type scalaire
static_assert(std::is_implicit_lifetime_v<int*>); // un type pointeur est un type scalaire
static_assert(std::is_implicit_lifetime_v<std::nullptr_t>); // type scalaire

struct S { int x, y; };
// S est une classe à durée de vie implicite : un agrégat sans destructeur fourni par l'utilisateur
static_assert(std::is_implicit_lifetime_v<S>);

static_assert(std::is_implicit_lifetime_v<int S::*>); // pointeur vers membre

struct X { ~X() = delete; };
// X n'est pas une classe à durée de vie implicite en raison d'un destructeur supprimé
static_assert(!std::is_implicit_lifetime_v<X>);

static_assert(std::is_implicit_lifetime_v<int[8]>); // type tableau
static_assert(std::is_implicit_lifetime_v<volatile int[8]>); // type tableau qualifié cv

int main() {}
