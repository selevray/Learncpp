std::void_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class... >
using void_t = void;  // (depuis C++17)

Métafonction utilitaire qui associe une séquence de types quelconques au type void. Cette métafonction est un moyen pratique d'exploiter SFINAE avant les concepts de C++20, en particulier pour retirer conditionnellement des fonctions de l'ensemble des candidats selon qu'une expression est valide dans un contexte non évalué (comme opérande de l'expression decltype), permettant d'avoir des surcharges de fonctions ou des spécialisations distinctes selon les opérations supportées.

Notes

Cette métafonction est utilisée en métaprogrammation de modèles pour détecter des types mal formés dans un contexte SFINAE :

// le modèle primaire gère les types qui n'ont pas de membre ::type imbriqué :
template<class, class = void>
struct has_type_member : std::false_type {};

// la spécialisation reconnaît les types qui possèdent un membre ::type imbriqué :
template<class T>
struct has_type_member<T, std::void_t<typename T::type>> : std::true_type {};

Elle peut aussi servir à détecter la validité d'une expression :

// le modèle primaire gère les types qui ne supportent pas la pré-incrémentation :
template<class, class = void>
struct has_pre_increment_member : std::false_type {};

// la spécialisation reconnaît les types qui supportent la pré-incrémentation :
template<class T>
struct has_pre_increment_member<T,
           std::void_t<decltype( ++std::declval<T&>() )>
       > : std::true_type {};

Jusqu'à la résolution du CWG issue 1558 (un défaut de C++11), les paramètres inutilisés des alias templates n'étaient pas garantis d'assurer SFINAE et pouvaient être ignorés ; les compilateurs anciens nécessitent donc une définition plus complexe de void_t, comme

template<typename... Ts>
struct make_void { typedef void type; };

template<typename... Ts>
using void_t = typename make_void<Ts...>::type;

Exemple

#include <iomanip>
#include <iostream>
#include <map>
#include <type_traits>
#include <vector>

// Modèle de variable qui vérifie si un type possède les fonctions membres begin() et end()
template<typename, typename = void>
constexpr bool is_iterable = false;

template<typename T>
constexpr bool is_iterable<
    T,
    std::void_t<decltype(std::declval<T>().begin()),
                decltype(std::declval<T>().end())
    >
> = true;

// Un trait d'itérateur dont value_type est le value_type du conteneur itéré,
// supporte même back_insert_iterator (où value_type est void)

template<typename T, typename = void>
struct iterator_trait : std::iterator_traits<T> {};

template<typename T>
struct iterator_trait<T, std::void_t<typename T::container_type>>
    : std::iterator_traits<typename T::container_type::iterator> {};

class A {};

#define SHOW(...) std::cout << std::setw(34) << #__VA_ARGS__ \
                            << " == " << __VA_ARGS__ << '\n'

int main()
{
    std::cout << std::boolalpha << std::left;
    SHOW(is_iterable<std::vector<double>>);
    SHOW(is_iterable<std::map<int, double>>);
    SHOW(is_iterable<double>);
    SHOW(is_iterable<A>);

    using container_t = std::vector<int>;
    container_t v;

    static_assert(std::is_same_v<
        container_t::value_type,
        iterator_trait<decltype(std::begin(v))>::value_type
    >);

    static_assert(std::is_same_v<
        container_t::value_type,
        iterator_trait<decltype(std::back_inserter(v))>::value_type
    >);
}

Output:

is_iterable<std::vector<double>>   == true
is_iterable<std::map<int, double>> == true
is_iterable<double>                == false
is_iterable<A>                     == false
