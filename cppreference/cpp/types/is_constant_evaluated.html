std::is_constant_evaluated

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

constexpr bool is_constant_evaluated() noexcept;  // (depuis C++20)

Détecte si l'appel de fonction a lieu dans un contexte évalué à la compilation. Renvoie true si l'évaluation de l'appel a lieu au sein de l'évaluation d'une expression ou d'une conversion qui est manifestement évaluée à la compilation ; sinon renvoie false.

Pour déterminer si les initialiseurs des variables suivantes sont manifestement évalués à la compilation, les compilateurs peuvent d'abord effectuer une évaluation à la compilation d'essai :

  • variables de type référence ou de type entier ou énumération qualifié const ;
  • variables à durée de stockage statique et à durée de stockage thread_local.

Il n'est pas recommandé de dépendre du résultat dans ce cas.

int y = 0;
const int a = std::is_constant_evaluated() ? y : 1;
// L'évaluation à la compilation d'essai échoue. L'évaluation à la compilation est abandonnée.
// La variable a est initialisée dynamiquement avec 1

const int b = std::is_constant_evaluated() ? 2 : y;
// L'évaluation à la compilation avec std::is_constant_evaluated() == true réussit.
// La variable b est initialisée statiquement avec 2

Paramètres

(aucune)

Valeur de retour

true si l'évaluation de l'appel a lieu au sein de l'évaluation d'une expression ou d'une conversion manifestement évaluée à la compilation ; sinon false.

Implémentation possible

// Cette implémentation requiert C++23 pour if consteval.
constexpr bool is_constant_evaluated() noexcept
{
    if consteval
    {
        return true;
    }
    else
    {
        return false;
    }
}

Notes

Lorsqu'elle est utilisée directement comme condition d'une déclaration static_assert ou d'une instruction constexpr if, std::is_constant_evaluated() renvoie toujours true.

Comme if consteval est absent en C++20, std::is_constant_evaluated est généralement implémenté à l'aide d'une extension du compilateur.

Exemple

#include <cmath>
#include <iostream>
#include <type_traits>

constexpr double power(double b, int x)
{
    if (std::is_constant_evaluated() && !(b == 0.0 && x < 0))
    {
        // Contexte d'évaluation à la compilation : utiliser un algorithme compatible avec constexpr.
        if (x == 0)
            return 1.0;
        double r {1.0};
        double p {x > 0 ? b : 1.0 / b};
        for (auto u = unsigned(x > 0 ? x : -x); u != 0; u /= 2)
        {
            if (u & 1)
                r *= p;
            p *= p;
        }
        return r;
    }
    else
    {
        // Laisser le générateur de code s'en charger.
        return std::pow(b, double(x));
    }
}

int main()
{
    // Un contexte d'expression constante
    constexpr double kilo = power(10.0, 3);
    int n = 3;
    // Pas une expression constante, car n ne peut pas être converti en rvalue
    // dans un contexte d'expression constante
    // Équivalent à std::pow(10.0, double(n))
    double mucho = power(10.0, n);

    std::cout << kilo << " " << mucho << "\n"; // (3)
}

Output:

1000 1000
