std::is_floating_point

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_floating_point;  // (depuis C++11)

std::is_floating_point est un UnaryTypeTrait.

Vérifie si T est un type à virgule flottante. Fournit la constante membre value égale à true, si T est le type float, double, long double, ou l'un des types à virgule flottante étendus (std::float16_t, std::float32_t, std::float64_t, std::float128_t ou std::bfloat16_t) (depuis C++23), y compris toutes les variantes qualifiées cv. Sinon, value est égal à false.

Si le programme ajoute des spécialisations pour std::is_floating_point ou std::is_floating_point_v, le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_floating_point_v = is_floating_point<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type à virgule flottante (éventuellement qualifié cv), false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Implémentation possible

template<class T>
struct is_floating_point
     : std::integral_constant<
         bool,
         // Remarque : types à virgule flottante standard
         std::is_same<float, typename std::remove_cv<T>::type>::value
         || std::is_same<double, typename std::remove_cv<T>::type>::value
         || std::is_same<long double, typename std::remove_cv<T>::type>::value
         // Remarque : types à virgule flottante étendus (C++23, si pris en charge)
         || std::is_same<std::float16_t, typename std::remove_cv<T>::type>::value
         || std::is_same<std::float32_t, typename std::remove_cv<T>::type>::value
         || std::is_same<std::float64_t, typename std::remove_cv<T>::type>::value
         || std::is_same<std::float128_t, typename std::remove_cv<T>::type>::value
         || std::is_same<std::bfloat16_t, typename std::remove_cv<T>::type>::value
     > {};

Exemple

#include <type_traits>

class A {};
static_assert(!std::is_floating_point_v<A>);

static_assert(std::is_floating_point_v<float>);
static_assert(!std::is_floating_point_v<float&>);
static_assert(std::is_floating_point_v<double>);
static_assert(!std::is_floating_point_v<double&>);
static_assert(!std::is_floating_point_v<int>);

int main() {}
