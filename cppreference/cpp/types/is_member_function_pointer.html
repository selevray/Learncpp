std::is_member_function_pointer

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_member_function_pointer;  // (depuis C++11)

std::is_member_function_pointer est un UnaryTypeTrait.

Vérifie si T est un pointeur vers fonction membre non statique. Fournit la constante membre value qui vaut true si T est un type pointeur vers fonction membre non statique. Sinon, value vaut false.

Si le programme ajoute des spécialisations pour std::is_member_function_pointer ou std::is_member_function_pointer_v, le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_member_function_pointer_v =
    is_member_function_pointer<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type pointeur vers fonction membre, false sinon (constante statique publique membre)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Implémentation possible

template<class T>
struct is_member_function_pointer_helper : std::false_type {};

template<class T, class U>
struct is_member_function_pointer_helper<T U::*> : std::is_function<T> {};

template<class T>
struct is_member_function_pointer
    : is_member_function_pointer_helper<typename std::remove_cv<T>::type> {};

Exemple

#include <type_traits>

class A
{
public:
    void member() {}
};

int main()
{
    // échoue à la compilation si A::member est un membre de données et non une fonction
    static_assert(std::is_member_function_pointer<decltype(&A::member)>::value,
                  "A::member is not a member function.");
}
