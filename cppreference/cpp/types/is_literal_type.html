std::is_literal_type

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_literal_type;  // (depuis C++11) (obsolète en C++17) (supprimé en C++20)

std::is_literal_type est un UnaryTypeTrait.

(Ce trait de type a été rendu obsolète[1] et supprimé[2] car il n'apporte qu'une valeur négligeable au code générique.)

Si T satisfait toutes les exigences de LiteralType, fournit la constante membre value égale à true. Pour tout autre type, value vaut false.

Si std::remove_all_extents_t<T> est un type incomplet et n'est pas (éventuellement qualifié cv) void, le comportement est indéfini.

Si le programme ajoute des spécialisations pour std::is_literal_type ou std::is_literal_type_v, le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_literal_type_v = is_literal_type<T>::value;  // (depuis C++17) (obsolète) (supprimé en C++20)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type littéral, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Notes

Seuls les types littéraux peuvent être utilisés comme paramètres ou valeurs de retour des fonctions constexpr. Seules les classes littérales peuvent avoir des fonctions membres constexpr.

Exemple

#include <type_traits>

struct A { int m; };
static_assert(std::is_literal_type_v<A> == true);

struct B { virtual ~B(); };
static_assert(std::is_literal_type_v<B> == false);

int main() {}
