std::is_integral

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_integral;  // (depuis C++11)

std::is_integral est un UnaryTypeTrait.

Vérifie si T est un type entier. Fournit la constante membre value égale à true, si T est le type bool, char, char8_t (depuis C++20), char16_t, char32_t, wchar_t, short, int, long, long long, ou tout type entier étendu défini par l'implémentation, y compris toutes les variantes signées, non signées et qualifiées cv. Sinon, value est égal à false.

Si le programme ajoute des spécialisations pour std::is_integral ou std::is_integral_v, le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_integral_v = is_integral<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type entier, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Implémentation possible

// Remarque : cette implémentation utilise les fonctionnalités de C++20
template<class T>
struct is_integral : std::bool_constant<
    requires (T t, T* p, void (*f)(T)) // le paramètre T* exclut les types référence
    {
        reinterpret_cast<T>(t); // Exclure les types classe
        f(0); // Exclure les types énumération
        p + t; // Exclure tout ce qui n'a pas encore été exclu, sauf les types entiers
    }> {};

Exemple

#include <type_traits>

static_assert
(
    std::is_integral_v<float> == false &&
    std::is_integral_v<int*> == false &&
    std::is_integral_v<int> == true &&
    std::is_integral_v<const int> == true &&
    std::is_integral_v<bool> == true &&
    std::is_integral_v<char> == true
);

class A {};
static_assert(std::is_integral_v<A> == false);

struct B { int x:4; };
static_assert(std::is_integral_v<B> == false);
using BF = decltype(B::x); // type du champ de bits
static_assert(std::is_integral_v<BF> == true);

enum E : int {};
static_assert(std::is_integral_v<E> == false);

template <class T>
constexpr T same(T i)
{
    static_assert(std::is_integral<T>::value, "Integral required.");
    return i;
}
static_assert(same('"') == 042);

int main() {}
