std::conditional

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< bool B, class T, class F >
struct conditional;  // (depuis C++11)

Fournit le typedef membre type, défini comme T si B est true à la compilation, ou comme F si B est false.

Si le programme ajoute des spécialisations pour std::conditional, le comportement est indéfini.

Types membres

Type membre Définition

  • type — T si B == true, F si B == false

Types auxiliaires

template< bool B, class T, class F >
using conditional_t = typename conditional<B,T,F>::type;  // (depuis C++14)

Implémentation possible

template<bool B, class T, class F>
struct conditional { using type = T; };

template<class T, class F>
struct conditional<false, T, F> { using type = F; };

Exemple

#include <iostream>
#include <type_traits>
#include <typeinfo>

int main()
{
    using Type1 = std::conditional<true, int, double>::type;
    using Type2 = std::conditional<false, int, double>::type;
    using Type3 = std::conditional<sizeof(int) >= sizeof(double), int, double>::type;

    std::cout << typeid(Type1).name() << '\n';
    std::cout << typeid(Type2).name() << '\n';
    std::cout << typeid(Type3).name() << '\n';
}
