std::is_function

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <type_traits>

template< class T >
struct is_function;  // (depuis C++11)

std::is_function est un UnaryTypeTrait.

Vérifie si T est un type fonction. Les types comme std::function, les lambdas, les classes avec operator() surchargé et les pointeurs vers des fonctions ne sont pas comptés comme types fonction. Fournit la constante membre value égale à true, si T est un type fonction. Sinon, value est égal à false.

Si le programme ajoute des spécialisations pour std::is_function ou std::is_function_v, le comportement est indéfini.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_function_v = is_function<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type fonction, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Notes

std::is_function peut être implémenté de manières bien plus simples. Des implémentations similaires à la suivante sont utilisées par les versions récentes de libc++, libstdc++ et MS STL :

template<class T>
struct is_function : std::integral_constant<
    bool,
    !std::is_const<const T>::value && !std::is_reference<T>::value
> {};

L'implémentation présentée ci-dessous est à visée pédagogique, car elle illustre la multitude de types fonction.

Exemple

#include <functional>
#include <type_traits>

int f();
static_assert(std::is_function_v<decltype(f)>);

static_assert(std::is_function_v<int(int)>);
static_assert(!std::is_function_v<int>);
static_assert(!std::is_function_v<decltype([]{})>);
static_assert(!std::is_function_v<std::function<void()>>);

struct O { void operator()() {} };
static_assert(std::is_function_v<O()>);

struct A
{
    static int foo();
    int fun() const&;
};
static_assert(!std::is_function_v<A>);
static_assert(std::is_function_v<decltype(A::foo)>);
static_assert(!std::is_function_v<decltype(&A::fun)>);

template<typename>
struct PM_traits {};
template<class T, class U>
struct PM_traits<U T::*> { using member_type = U; };

int main()
{
    using T = PM_traits<decltype(&A::fun)>::member_type; // T est int() const&
    static_assert(std::is_function_v<T>);
}
