Défini dans l'en-tête <typeinfo>

class type_info;

La classe type_info contient des informations propres à l'implémentation sur un type, notamment le nom du type et les moyens de comparer deux types pour l'égalité ou l'ordre de collationnement. C'est la classe renvoyée par l'opérateur typeid.

La classe type_info n'est ni CopyConstructible ni CopyAssignable.

Fonctions membres

  • (constructeur)[deleted] — n'a ni constructeur par défaut ni constructeur de copie (fonction membre publique)
  • (destructeur) [virtuelle] — le destructeur virtuel fait de type_info une classe polymorphe (fonction membre publique virtuelle)
  • operator=[deleted] — ne peut pas être affecté par copie (fonction membre publique)
  • operator==operator!= (removed in C++20) — vérifie si les objets désignent le même type (fonction membre publique)
  • before — vérifie si le type désigné précède le type désigné d'un autre objet type_info dans l'ordre défini par l'implémentation, c'est-à-dire ordonne les types désignés (fonction membre publique)
  • hash_code (C++11) — renvoie une valeur identique pour les mêmes types (fonction membre publique)
  • name — nom du type défini par l'implémentation (fonction membre publique)
