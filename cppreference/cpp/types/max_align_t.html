std::max_align_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstddef>

typedef /* défini par l'implémentation */ max_align_t;  // (depuis C++11)

std::max_align_t est un type à disposition standard [ TrivialType (jusqu'à C++26) | TriviallyCopyable type (depuis C++26)] dont l'exigence d'alignement est au moins aussi stricte (aussi grande) que celle de chaque type scalaire.

std::is_trivially_default_constructible_v<std::max_align_t> is true.

Notes

Les pointeurs renvoyés par des fonctions d'allocation telles que std::malloc sont convenablement alignés pour tout objet, ce qui signifie qu'ils sont alignés au moins aussi strictement que std::max_align_t.

Exemple

#include <cstddef>
#include <iostream>

int main()
{
    std::cout << alignof(std::max_align_t) << '\n';
}
