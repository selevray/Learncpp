Notes

Les noms supprimés sont considérés comme réservés et peuvent être réutilisés pour d'autres fonctionnalités dans de futures révisions de la bibliothèque standard.

Les noms réservés comme membres pour une standardisation antérieure ne peuvent pas être utilisés comme noms de macros de type objet dans du code portable.
