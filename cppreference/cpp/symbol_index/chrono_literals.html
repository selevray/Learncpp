Cette page tente de lister tous les symboles disponibles depuis la bibliothèque standard (bibliothèque de date et d'heure) dans l'espace de noms std::literals::chrono_literals. Les symboles sont écrits comme suit :

  • Noms de fonctions avec ().
  • Modèles avec <>.

Notes

Ces opérateurs sont déclarés dans l'espace de noms std::literals::chrono_literals, où literals et chrono_literals sont des espaces de noms en ligne. L'accès à ces opérateurs peut être obtenu avec :

  • using namespace std::literals,
  • using namespace std::chrono_literals, or
  • using namespace std::literals::chrono_literals.

De plus, dans l'espace de noms std::chrono, la directive using namespace literals::chrono_literals; est fournie par la bibliothèque standard, de sorte que si un programmeur utilise using namespace std::chrono; pour accéder aux classes de la bibliothèque chrono, les opérateurs littéraux correspondants deviennent également visibles.
