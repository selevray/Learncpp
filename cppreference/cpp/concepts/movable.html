std::movable

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <concepts>

template< class T >
concept movable =
    std::is_object_v<T> &&
    std::move_constructible<T> &&
    std::assignable_from<T&, T> &&
    std::swappable<T>;  // (depuis C++20)

Le concept movable<T> spécifie que T est un type d'objet pouvant être déplacé (c'est-à-dire qu'il peut être construit par déplacement, affecté par déplacement, et que des lvalues de type T peuvent être échangées).
