std::integral

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <concepts>

template< class T >
concept integral = std::is_integral_v<T>;  // (depuis C++20)

Le concept integral<T> est satisfait si et seulement si T est un type entier.

Exemple

#include <concepts>
#include <iostream>

void print(std::integral auto i)
{
    std::cout << "Integral: " << i << '\n';
}

void print(auto x)
{
    std::cout << "Non-integral: " << x << '\n';
}

int main()
{
    std::cout << std::boolalpha;

    static_assert(std::integral<bool>);
    print(true);

    static_assert(std::integral<char>);
    print('o');

    static_assert(std::integral<int>);
    print(007);

    static_assert( ! std::integral<double> );
    print(2e2);

    static_assert( ! std::integral<decltype("")> );
    print("∫∫∫");
}

Output:

Integral: true
Integral: o
Integral: 7
Non-integral: 200
Non-integral: ∫∫∫
