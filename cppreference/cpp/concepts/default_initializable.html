std::default_initializable

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <concepts>

template< class T >
concept default_initializable = std::constructible_from<T> && requires { T{}; } &&
                                /* T t; est bien formé, voir ci-dessous */;  // (depuis C++20)

Le concept default_initializable vérifie si des variables de type T peuvent être

  • initialisées par valeur (c'est-à-dire si T() est bien formé) ;
  • initialisées par liste directe à partir d'une liste d'initialisation vide (c'est-à-dire si T{} est bien formé) ; et
  • initialisé par défaut (c.-à-d. si T t; est bien formé).

Le contrôle d'accès est effectué comme si l'on se trouvait dans un contexte sans rapport avec T. Seule la validité du contexte immédiat de l'initialisation de la variable est prise en compte.

Implémentation possible

template<class T>
concept default_initializable =
    std::constructible_from<T> &&
    requires { T{}; ::new T; };
