boolean-testable

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class B >
concept __boolean_testable_impl = std::convertible_to<B, bool>;  // (1) (depuis C++20) ( réservé à l'exposition* )

template< class B >
concept boolean-testable =
    __boolean_testable_impl<B> &&
    requires (B&& b) {
        { !std::forward<B>(b) } -> __boolean_testable_impl;
    };  // (2) (depuis C++20) ( réservé à l'exposition* )

Le concept boolean-testable réservé à l'exposition spécifie les exigences pour les expressions convertibles en bool et pour lesquelles les opérateurs logiques ont le comportement habituel (y compris le court-circuit), même pour deux types boolean-testable différents.

Formellement, pour modéliser le concept __boolean_testable_impl réservé à l'exposition, le type ne doit définir aucun membre operator&& ni operator||, et aucune operator&& ni operator|| non membre viable ne doit être visible par recherche dépendante des arguments. De plus, étant donné une expression e telle que decltype((e)) est B, boolean-testable n'est modélisé que si bool(e) == !bool(!e).

Préservation de l'égalité

Les expressions déclarées dans les requires expressions des concepts de la bibliothèque standard doivent être préservant l'égalité (sauf mention contraire).

Notes

Des exemples de types boolean-testable incluent bool, std::true_type, std::bitset<N>::reference, et int*.
