std::move_constructible

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <concepts>

template< class T >
concept move_constructible = std::constructible_from<T, T> && std::convertible_to<T, T>;  // (depuis C++20)

Le concept move_constructible est satisfait si T est un type référence, ou s'il s'agit d'un type objet pour lequel un objet de ce type peut être construit à partir d'une rvalue de ce type dans les contextes d'initialisation directe et par copie, avec la sémantique habituelle.

Exigences sémantiques

Si T est un type objet, alors move_constructible<T> n'est modélisé que si, étant donné

  • rv, une rvalue de type T, et
  • u2, un objet distinct de type T égal à rv,

les propositions suivantes sont vraies :

  • Après la définition T u = rv;, u est égal à u2 ;
  • T(rv) est égal à u2 ; et
  • Si T n'est pas qualifié const, alors l'état résultant de rv (après que la définition/expression a été évaluée dans l'un des points ci-dessus) est valide mais non spécifié ; sinon, il est inchangé.
