std::equivalence_relation

Défini dans l'en-tête <concepts>

template< class R, class T, class U >
concept equivalence_relation = std::relation<R, T, U>;  // (depuis C++20)

Le concept equivalence_relation<R, T, U> spécifie que l'relation R impose une relation d'équivalence sur ses arguments.

Exigences sémantiques

Une relation r est une relation d'équivalence si

  • elle est réflexive : pour tout x, r(x, x) est true ;
  • elle est symétrique : pour tout a et b, r(a, b) est true si et seulement si r(b, a) est true ;
  • elle est transitive : r(a, b) && r(b, c) implique r(a, c).

Notes

La distinction entre relation et equivalence_relation est purement sémantique.
