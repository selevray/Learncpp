std::convertible_to

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <concepts>

template< class From, class To >
concept convertible_to =
    std::is_convertible_v<From, To> &&
    requires {
        static_cast<To>(std::declval<From>());
    };  // (depuis C++20)

Le concept convertible_to<From, To> spécifie qu'une expression de même type et même catégorie de valeur que celles de std::declval<From>() peut être convertie implicitement et explicitement vers le type To, et que les deux formes de conversion produisent des résultats égaux.

Exigences sémantiques

convertible_to<From, To> n'est modélisé que si, étant donné une fonction fun de type std::add_rvalue_reference_t<From>() telle que l'expression fun() est préservant l'égalité,

  • Soit

    • To n'est ni un type objet ni un type référence vers un objet, ou
    • static_cast<To>(fun()) est égal à []() -> To { return fun(); }(), et

  • L'une des conditions suivantes est vraie :

    • std::add_rvalue_reference_t<From> n'est pas un type référence vers un objet, ou
    • std::add_rvalue_reference_t<From> est une référence rvalue vers un type non qualifié const, et l'état résultant de l'objet référencé par fun() est valide mais non spécifié après l'une ou l'autre des expressions ci-dessus ; ou
    • l'objet référencé par fun() n'est pas modifié par l'une ou l'autre des expressions ci-dessus.

Préservation de l'égalité

Les expressions déclarées dans les requires expressions des concepts de la bibliothèque standard doivent être préservant l'égalité (sauf mention contraire).
