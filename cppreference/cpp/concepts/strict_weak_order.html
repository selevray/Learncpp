std::strict_weak_order

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <concepts>

template< class R, class T, class U >
concept strict_weak_order = std::relation<R, T, U>;  // (depuis C++20)

Le concept strict_weak_order<R, T, U> spécifie que relation R impose un ordre faible strict à ses arguments.

Exigences sémantiques

Une relation r est un ordre faible strict si

  • elle est irréflexive : pour tout x, r(x, x) est false ;
  • elle est transitive : pour tous a, b et c, si r(a, b) et r(b, c) sont tous deux true alors r(a, c) est true ;
  • soit e(a, b) égal à !r(a, b) && !r(b, a), alors e est transitive : e(a, b) && e(b, c) implique e(a, c).

Dans ces conditions, on peut montrer que e est une relation d'équivalence, et que r induit un ordre total strict sur les classes d'équivalence déterminées par e.

Notes

La distinction entre relation et strict_weak_order est purement sémantique.
