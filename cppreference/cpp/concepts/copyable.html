std::copyable

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <concepts>

template< class T >
concept copyable =
    std::copy_constructible<T> &&
    std::movable<T> &&
    std::assignable_from<T&, T&> &&
    std::assignable_from<T&, const T&> &&
    std::assignable_from<T&, const T>;  // (depuis C++20)

Le concept copyable<T> spécifie que T est un movable type objet qui peut aussi être copié (c'est-à-dire qu'il prend en charge la construction par copie et l'affectation par copie).
