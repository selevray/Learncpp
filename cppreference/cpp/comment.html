Commentaires

Les commentaires servent de documentation intégrée au code. Lorsqu'ils sont insérés dans un programme, ils sont effectivement ignorés par le compilateur ; ils sont uniquement destinés à servir de notes aux humains qui lisent le code source. Bien que la documentation spécifique ne fasse pas partie de la norme C++, plusieurs utilitaires existent pour analyser les commentaires selon différents formats de documentation.

Syntaxe

| | | | /* comment */ | (1) | | | | // comment | (2) | | |

  1. Souvent appelés commentaires « de style C » ou « multiligne ».

  2. Souvent appelés commentaires « de style C++ » ou « sur une ligne ».

Tous les commentaires sont supprimés du programme lors de la phase de traduction 3, en remplaçant chaque commentaire par un unique caractère d'espacement.

Style C

Les commentaires de style C servent généralement à commenter de grands blocs de texte, mais ils peuvent aussi commenter une seule ligne. Pour insérer un commentaire de style C, il suffit d'encadrer le texte avec /* et */ ; le contenu du commentaire sera alors ignoré par le compilateur. Bien que ce ne soit pas prévu par la norme C++, /** et */ sont souvent utilisés pour indiquer des blocs de documentation ; c'est légal, car le second astérisque est simplement traité comme faisant partie du commentaire. Les commentaires de style C ne peuvent pas être imbriqués.

Style C++

Les commentaires de style C++ servent généralement à commenter une seule ligne, mais plusieurs commentaires de style C++ peuvent être placés les uns à la suite des autres pour former un commentaire multiligne. Les commentaires de style C++ indiquent au compilateur d'ignorer tout le contenu compris entre // et un saut de ligne.

Notes

Comme les commentaires sont supprimés avant l'étape du préprocesseur, une macro ne peut pas former un commentaire, et un commentaire de style C non terminé ne déborde pas à partir d'un fichier inclus avec #include.

Outre la mise en commentaire, d'autres mécanismes utilisés pour exclure du code source sont

#if 0
    std::cout << "this will not be executed or even compiled\n";
#endif

and

if (false)
{
    std::cout << "this will not be executed\n";
}

    // sera affiché
