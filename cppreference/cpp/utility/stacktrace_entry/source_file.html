std::stacktrace_entry::source_file

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

std::string source_file() const;  // (depuis C++23)

Renvoie le nom présumé ou réel du fichier source qui contient lexicalement l'expression ou l'instruction dont l'évaluation est représentée par *this, ou une chaîne vide en cas d'échec autre qu'un échec d'allocation, par exemple lorsque *this est vide.

Soit source_file renvoie le nom présumé du fichier source et source_line renvoie le numéro de ligne présumé, soit source_file renvoie le nom réel du fichier source et source_line renvoie le numéro de ligne réel.

Paramètres

(aucune)

Valeur de retour

Le nom du fichier source spécifié ci-dessus en cas de succès, une chaîne vide en cas d'échec autre qu'un échec d'allocation.

Exceptions

Lève std::bad_alloc si la mémoire pour les structures de données internes ou la chaîne résultante ne peut pas être allouée.

Notes

Le nom présumé du fichier source est ce vers quoi se développe la macro prédéfinie __FILE__, et peut être modifié par la directive #line.
