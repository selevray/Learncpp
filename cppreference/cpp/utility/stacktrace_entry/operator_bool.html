std::stacktrace_entry::operator bool

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr explicit operator bool() const noexcept;  // (depuis C++23)

Vérifie si stacktrace_entry est non vide, c'est-à-dire s'il représente une évaluation dans une pile d'appels.

Paramètres

(aucune)

Valeur de retour

true si stacktrace_entry est non vide, false sinon.

Notes

Un stacktrace_entry non vide peut être obtenu à partir d'un std::basic_stacktrace créé par std::basic_stacktrace::current ou d'une copie d'un tel std::basic_stacktrace.

Un stacktrace_entry vide peut être créé par le constructeur par défaut.
