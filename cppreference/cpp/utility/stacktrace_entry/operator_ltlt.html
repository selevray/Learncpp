std::ostream& operator<<( std::ostream& os, const std::stacktrace_entry& f );  // (depuis C++23)

Insère la description de f dans le flux de sortie os. Équivalent à return os << std::to_string(f);.

Paramètres

  • os — un flux de sortie
  • f — un stacktrace_entry dont la description doit être insérée

Valeur de retour

os

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <iostream>
#include <stacktrace>

int main()
{
    for (const auto& f : std::stacktrace::current())
        std::cout << f << '\n';
}
