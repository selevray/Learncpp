std::stacktrace_entry::source_line

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

std::uint_least32_t source_line() const;  // (depuis C++23)

Renvoie un numéro de ligne à partir de 1 qui se rapporte lexicalement à l'évaluation représentée par *this, ou 0 en cas d'échec autre qu'un échec d'allocation, par exemple lorsque *this est vide.

Soit source_file renvoie le nom présumé du fichier source et source_line renvoie le numéro de ligne présumé, soit source_file renvoie le nom réel du fichier source et source_line renvoie le numéro de ligne réel.

Paramètres

(aucune)

Valeur de retour

Le numéro de ligne spécifié ci-dessus en cas de succès, 0 en cas d'échec autre qu'un échec d'allocation.

Exceptions

Lève std::bad_alloc si la mémoire pour les structures de données internes ne peut pas être allouée.

Notes

Le numéro de ligne présumé est ce vers quoi se développe la macro prédéfinie __LINE__, et peut être modifié par la directive #line.
Cette section est incomplète Raison : la définition de « numéro de ligne réel » est manquante (LWG issue 3507)

Cette fonction n'est pas tenue d'être noexcept car obtenir la ligne source nécessite une allocation sur certaines plateformes.
