Défini dans l'en-tête <stacktrace>

std::string to_string( const std::stacktrace_entry& f );  // (depuis C++23)

Renvoie une chaîne de caractères contenant une description de f.

La norme recommande que la description fournisse des informations sur l'évaluation contenue, y compris des informations provenant de f.source_file() et f.source_line().

Paramètres

  • f — un stacktrace_entry dont la description doit être renvoyée

Valeur de retour

Une chaîne de caractères contenant une description de f.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Notes

La prise en charge d'allocateurs personnalisés n'est pas fournie pour cette fonction, car les implémentations nécessitent généralement des allocations spécifiques à la plateforme, des appels système et un travail intensif en calcul, alors qu'un allocateur personnalisé n'apporte aucun avantage pour cette fonction, les opérations spécifiques à la plateforme prenant un ordre de grandeur de temps de plus que l'allocation.

Exemple

#include <stacktrace>
#include <string>
#include <iostream>

int main()
{
    auto st = std::stacktrace::current();
    std::cout <<
        "Description of an empty stacktrace entry:\n" +
        std::to_string(std::stacktrace_entry{}) << '\n';
    if (st.size() > 0) {
        std::cout <<
            "Description of a non-empty stacktrace entry:\n" +
            std::to_string(st[0]) << '\n';
    }
}

Sortie possible :

Description of an empty stacktrace entry:

Description of a non-empty stacktrace entry:
0x0000000000402DE9 in ./prog.exe
