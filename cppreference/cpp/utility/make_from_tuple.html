std::make_from_tuple

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <tuple>

template< class T, class Tuple >
constexpr T make_from_tuple( Tuple&& t );  // (depuis C++17) (jusqu'à C++23)

template< class T, tuple-like Tuple >
constexpr T make_from_tuple( Tuple&& t );  // (depuis C++23)

Construit un objet de type T, en utilisant les éléments du tuple t comme arguments du constructeur.

Étant donnée la fonction /*make-from-tuple-impl*/ réservée à l'exposé, définie comme suit :
template<class T, tuple-like Tuple, std::size_t... I> // aucune contrainte sur Tuple avant C++23 constexpr T /*make-from-tuple-impl*/(Tuple&& t, std::index_sequence<I...>) { return T(std::get<I>(std::forward<Tuple>(t))...); }

L'effet est équivalent à :
return /*make-from-tuple-impl*/<T>( std::forward<Tuple>(t), std::make_index_sequence<std::tuple_size_v<std::remove_reference_t<Tuple>>>{});.

Si

  • std::tuple_size_v<std::remove_reference_t<Tuple>> est 1 et std::reference_constructs_from_temporary_v< T, decltype(std::get<0>(std::declval<Tuple>()))> est true, ou

(depuis C++23)

  • std::is_constructible_v<T, decltype(std::get<I>(std::declval<Tuple>()))...> is false,

le programme est mal formé.

Paramètres

  • t — tuple dont les éléments doivent être utilisés comme arguments du constructeur de T

Valeur de retour

L'objet ou la référence T construit.

Notes

Tuple n'a pas besoin d'être std::tuple, il peut être n'importe quoi supportant std::get et std::tuple_size ; en particulier, std::array et std::pair peuvent être utilisés.

(jusqu'à C++23)

Tuple doit être de type semblable à un tuple, c'est-à-dire que chaque type qu'il contient doit être une spécialisation de std::tuple ou un autre type (tel que std::array et std::pair) modélisant tuple-like.

(depuis C++23)

En raison de l'élision de copie garantie, T n'a pas besoin d'être déplaçable.

Exemple

#include <iostream>
#include <tuple>

struct Foo
{
    Foo(int first, float second, int third)
    {
        std::cout << first << ", " << second << ", " << third << '\n';
    }
};

int main()
{
    auto tuple = std::make_tuple(42, 3.14f, 0);
    std::make_from_tuple<Foo>(std::move(tuple));
}

Output:

42, 3.14, 0
