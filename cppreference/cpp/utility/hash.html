template< class Key >
struct hash;  // (depuis C++11)

Les conteneurs associatifs non ordonnés std::unordered_set, std::unordered_multiset, std::unordered_map, std::unordered_multimap utilisent des spécialisations du modèle std::hash comme fonction de hachage par défaut.

Pour un type Key, chaque spécialisation std::hash<Key> est soit activée soit désactivée ﻿ :

  • Si std::hash<Key> n'est pas fourni par le programme ou l'utilisateur, elle est désactivée.

  • Sinon, std::hash<Key> est activée si toutes les conditions suivantes sont satisfaites :

    • Toutes les exigences suivantes sont satisfaites :
      • Hash (avec Key comme type de l'argument d'appel de fonction)
      • DefaultConstructible
      • CopyAssignable
      • Swappable
    • Étant donné les valeurs suivantes :
      • h, un objet de type std::hash<Key>.
      • k1 et k2, des objets de type Key. Toutes les exigences suivantes sont satisfaites :
      • Si k1 == k2 est true, h(k1) == h(k2) est aussi true.
      • Sauf si std::hash<Key> est une spécialisation définie par le programme, h(k1) ne lève jamais d'exception.

  • Sinon, std::hash<Key> est désactivée.

Les spécialisations désactivées ne satisfont pas Hash, ne satisfont pas FunctionObject, et les valeurs suivantes sont toutes false :

  • std::is_default_constructible<std::hash<Key>>::value
  • std::is_copy_constructible<std::hash<Key>>::value
  • std::is_move_constructible<std::hash<Key>>::value
  • std::is_copy_assignable<std::hash<Key>>::value
  • std::is_move_assignable<std::hash<Key>>::value

Autrement dit, elles existent, mais ne peuvent pas être utilisées.

Spécialisations de la bibliothèque standard

Chaque en-tête qui déclare le modèle std::hash fournit aussi des spécialisations activées de std::hash pour les types suivants :

  • tous les types arithmétiques non qualifiés cv
  • tous les types énumérés non qualifiés cv
  • tous les types pointeurs non qualifiés cv
  • std::nullptr_t

En outre, certains en-têtes fournissent aussi d'autres spécialisations activées de std::hash pour des types de la bibliothèque (voir ci-dessous).

Pour toutes les spécialisations de std::hash fournies par la bibliothèque standard, à l'exception des suivantes, toutes leurs fonctions membres sont noexcept :

  • std::hash<std::unique_ptr>

Notes

Les fonctions de hachage réelles dépendent de l'implémentation et ne sont pas tenues de satisfaire d'autres critères de qualité que ceux spécifiés ci-dessus. Notamment, certaines implémentations utilisent des fonctions de hachage triviales (identité) qui associent un entier à lui-même. Autrement dit, ces fonctions de hachage sont conçues pour fonctionner avec les conteneurs associatifs non ordonnés, mais pas comme des hachages cryptographiques, par exemple.

Les fonctions de hachage ne sont tenues de produire le même résultat pour une même entrée qu'au sein d'une seule exécution d'un programme ; cela permet des hachages salés qui préviennent les attaques par déni de service par collisions.

Il n'existe pas de spécialisation pour les chaînes C. std::hash<const char*> produit un hachage de la valeur du pointeur (l'adresse mémoire), il n'examine pas le contenu d'un tableau de caractères.

Des spécialisations supplémentaires pour std::pair et les types de conteneurs standard, ainsi que des fonctions utilitaires pour composer des hachages, sont disponibles dans boost::hash.

Exemple

#include <cstddef>
#include <functional>
#include <iomanip>
#include <iostream>
#include <string>
#include <unordered_set>

struct S
{
    std::string first_name;
    std::string last_name;
    bool operator==(const S&) const = default; // depuis C++20
};

// Avant C++20.
// bool operator==(const S& lhs, const S& rhs)
// {
//     return lhs.first_name == rhs.first_name && lhs.last_name == rhs.last_name;
// }

// Un hachage personnalisé peut être un objet fonction autonome.
struct MyHash
{
    std::size_t operator()(const S& s) const noexcept
    {
        std::size_t h1 = std::hash<std::string>{}(s.first_name);
        std::size_t h2 = std::hash<std::string>{}(s.last_name);
        return h1 ^ (h2 << 1); // ou utiliser boost::hash_combine
    }
};

// Une spécialisation personnalisée de std::hash peut être injectée dans l'espace de noms std.
template<>
struct std::hash<S>
{
    std::size_t operator()(const S& s) const noexcept
    {
        std::size_t h1 = std::hash<std::string>{}(s.first_name);
        std::size_t h2 = std::hash<std::string>{}(s.last_name);
        return h1 ^ (h2 << 1); // ou utiliser boost::hash_combine
    }
};

int main()
{
    std::string str = "Meet the new boss...";
    std::size_t str_hash = std::hash<std::string>{}(str);
    std::cout << "hash(" << std::quoted(str) << ") =\t" << str_hash << '\n';

    S obj = {"Hubert", "Farnsworth"};
    // Utilisation de l'objet fonction autonome.
    std::cout << "hash(" << std::quoted(obj.first_name) << ", "
              << std::quoted(obj.last_name) << ") =\t"
              << MyHash{}(obj) << " (using MyHash) or\n\t\t\t\t"
              << std::hash<S>{}(obj) << " (using injected specialization)\n";

    // Un hachage personnalisé permet d'utiliser des types personnalisés dans les conteneurs non ordonnés.
    // L'exemple utilisera la spécialisation std::hash<S> injectée ci-dessus,
    // pour utiliser MyHash à la place, passez-le comme second argument de modèle.
    std::unordered_set<S> names = {obj, {"Bender", "Rodriguez"}, {"Turanga", "Leela"}};
    for (auto const& s: names)
        std::cout << std::quoted(s.first_name) << ' '
                  << std::quoted(s.last_name) << '\n';
}
