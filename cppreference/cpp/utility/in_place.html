1,3,5) Les types/modèles de types std::in_place_t, std::in_place_type_t et std::in_place_index_t peuvent être utilisés dans la liste de paramètres du constructeur pour correspondre à l'étiquette voulue.

2,4,6) Les instances correspondantes std::in_place, std::in_place_type et std::in_place_index de (1,3,5) sont des étiquettes de désambiguïsation qui peuvent être passées aux constructeurs pour indiquer que l'objet contenu doit être construit sur place et, (pour les deux dernières) le type de l'objet à construire.

Bibliothèque standard

Les types suivants de la bibliothèque standard utilisent (1-6) comme étiquettes de désambiguïsation :

  • any (C++17) — objets contenant des instances de tout CopyConstructible type (classe)
  • expected (C++23) — un wrapper qui contient soit une valeur expected, soit une valeur d'erreur (modèle de classe)
  • move_only_function (C++23) — enveloppe uniquement déplaçable de tout objet appelable prenant en charge les qualificateurs dans une signature d'appel donnée (modèle de classe)
  • optional (C++17) — un conteneur qui peut ou non contenir un objet (modèle de classe)
  • variant (C++17) — une union discriminée sûre au niveau des types (modèle de classe)
