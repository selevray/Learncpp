Fin du programme

Les fonctions suivantes gèrent la terminaison du programme et le nettoyage des ressources.

Défini dans l'en-tête <cstdlib>

  • abort — provoque une terminaison anormale du programme (sans nettoyage) (fonction)
  • exit — provoque une fin normale du programme avec nettoyage (fonction)
  • quick_exit (C++11) — provoque une fin rapide du programme sans nettoyage complet (fonction)
  • _Exit (C++11) — provoque une fin normale du programme sans nettoyage (fonction)
  • atexit — enregistre une fonction à appeler lors de l'invocation normale de std::exit() (fonction)
  • at_quick_exit (C++11) — enregistre une fonction à appeler lors de l'invocation normale de std::quick_exit (fonction)
  • EXIT_SUCCESSEXIT_FAILURE — indique l'état d'exécution du programme (constante macro)

Flux de contrôle inatteignable

Défini dans l'en-tête <utility>

  • unreachable (C++23) — marque un point d'exécution inatteignable (fonction)

Communication avec l'environnement

Défini dans l'en-tête <cstdlib>

  • system — appelle le processeur de commandes de l'environnement hôte (fonction)
  • getenv — accès à la liste des variables d'environnement (fonction)

Signaux

Plusieurs fonctions et constantes macro pour la gestion des signaux sont fournies.

Défini dans l'en-tête <csignal>

  • signal — définit un gestionnaire de signal pour un signal particulier (fonction)
  • raise — exécute le gestionnaire de signal pour un signal particulier (fonction)
  • sig_atomic_t — le type entier pouvant être accédé comme une entité atomique depuis un gestionnaire de signal asynchrone (typedef)
  • SIG_DFLSIG_IGN — définit les stratégies de gestion des signaux (constante macro)
  • SIG_ERR — valeur de retour de signal indiquant qu'une erreur a été rencontrée (constante macro)

##### Types de signaux {#Signal_types}

  • SIGABRTSIGFPESIGILLSIGINTSIGSEGVSIGTERM — définit les types de signaux (constante macro)

  • longjmp — saute à l'emplacement spécifié (fonction)
