std::ranges::swap

Signature d'appel

template< class T, class U >
constexpr void ranges::swap( T&& t, U&& u ) noexcept(/* voir ci-dessous */);  // (depuis C++20)

Échange les valeurs référencées par t et u.

ranges::swap(t, u) est équivalent à l'expression :

  1. (void)swap(t, u), si t ou u a un type classe ou énumération, et que cette expression est valide, où la résolution de surcharge est effectuée dans l'espace de noms std::ranges avec le candidat supplémentaire template<class T> void swap(T&, T&) = delete;.
    • Si la fonction sélectionnée par la résolution de surcharge n'échange pas les valeurs référencées par t et u, le programme est mal formé ; aucun diagnostic requis.
  2. Sinon, (void)ranges::swap_ranges(t, u), si t et u sont des tableaux lvalue de même étendue (mais éventuellement de types d'éléments différents) et que ranges::swap(*t, *u) est une expression valide, sauf que noexcept((void)ranges::swap_ranges(t, u)) est égal à noexcept(ranges::swap(*t, *u)).
  3. Sinon, une expression qui échange les valeurs référencées de t et u, s'il s'agit de lvalues du même type V qui modélise std::move_constructible<V> et std::assignable_from<V&, V>.
    • Le résultat de l'application de l'opérateur noexcept à cette expression est égal à std::is_nothrow_move_constructible_v<V> && std::is_nothrow_move_assignable_v<V>.
    • Cette expression est une expression constante si
      • V est un LiteralType,
      • t = std::move(u)) et u = std::move(t) sont tous deux des sous-expressions constantes, et
      • les expressions complètes des initialiseurs des déclarations suivantes sont des sous-expressions constantes :
        • V v1(std::move(t));
        • V v2(std::move(u));
  4. Sinon, ranges::swap(t, u) est mal formé, ce qui peut entraîner un échec de substitution lorsque ranges::swap(t, u) apparaît dans le contexte immédiat d'une instanciation de modèle.

Objets de point de personnalisation

Le nom ranges::swap désigne un objet de point de personnalisation, qui est un objet fonction const d'un type de classe littéral semiregular. À des fins d'exposition, la version sans qualificateurs cv de son type est désignée par __swap_fn.

Toutes les instances de __swap_fn sont égales. Les effets de l'invocation de différentes instances du type __swap_fn sur les mêmes arguments sont équivalents, qu'il s'agisse ou non d'une lvalue ou d'une rvalue, et que l'expression désignant l'instance soit qualifiée const ou non (toutefois, une instance qualifiée volatile n'est pas tenue d'être invocable). Ainsi, ranges::swap peut être copié librement et ses copies peuvent être utilisées de manière interchangeable.

Étant donné un ensemble de types Args..., si std::declval<Args>()... satisfont aux exigences relatives aux arguments de ranges::swap ci-dessus, alors __swap_fn modélise

  • std::invocable<__swap_fn, Args...>,
  • std::invocable<const __swap_fn, Args...>,
  • std::invocable<__swap_fn&, Args...>, and
  • std::invocable<const __swap_fn&, Args...>.

Sinon, aucun opérateur d'appel de fonction de __swap_fn ne participe à la résolution de surcharge.

Exemple

#include <array>
#include <concepts>
#include <iostream>
#include <ranges>
#include <string_view>
#include <vector>

void print(std::string_view name,
           std::ranges::common_range auto const& p,
           std::ranges::common_range auto const& q)
{
    std::cout << name << "1{ ";
    for (auto const& i : p)
        std::cout << i << ' ';
    std::cout << "}, " << name << "2{ ";
    for (auto const& i : q)
        std::cout << i << ' ';
    std::cout << "}\n";
}

void print(std::string_view name, int p, int q)
{
    std::cout << name << "1 = " << p << ", " << name << "2 = " << q << '\n';
}

struct IntLike
{
    int v;
};

void swap(IntLike& lhs, int& rhs)
{
    std::swap(lhs.v, rhs);
}

void swap(int& lhs, IntLike& rhs)
{
    std::swap(lhs, rhs.v);
}

std::ostream& operator<<(std::ostream& out, IntLike i)
{
    return out << i.v;
}

int main()
{
    std::vector a1{10, 11, 12}, a2{13, 14};
    std::ranges::swap(a1, a2);
    print("a", a1, a2);

    std::array b1{15, 16, 17}, b2{18, 19, 20};
    std::ranges::swap(b1, b2);
    print("b", b1, b2);

    // std::array c1{1, 2, 3}; std::array c2{4, 5};
    // std::ranges::swap(c1, c2); // erreur : aucun swap trouvé par ADL

    int d1[]{21, 22, 23}, d2[]{24, 25, 26};
    std::ranges::swap(d1, d2);
    print("d", d1, d2);

    // int e1[]{1, 2, 3}, e2[]{4, 5};
    // std::ranges::swap(e1, e2); // erreur : extents non concordants

    // char f1[]{1, 2, 3};
    // int  f2[]{4, 5, 6};
    // std::ranges::swap(f1, f2); // erreur : aucun swap(*f1, *f2) trouvé par ADL

    IntLike g1[]{1, 2, 3};
    int     g2[]{4, 5, 6};
    std::ranges::swap(g1, g2); // swap hétérogène pris en charge
    print("g", g1, g2);

    int h1{27}, h2{28};
    std::ranges::swap(h1, h2);
    print("h", h1, h2);
}

Output:

a1{ 13 14 }, a2{ 10 11 12 }
b1{ 18 19 20 }, b2{ 15 16 17 }
d1{ 24 25 26 }, d2{ 21 22 23 }
g1{ 4 5 6 }, g2{ 1 2 3 }
h1 = 28, h2 = 27
