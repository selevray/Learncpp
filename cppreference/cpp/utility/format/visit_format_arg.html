std::visit_format_arg

Défini dans l'en-tête <format>

template< class Visitor, class Context >
/* voir ci-dessous */ visit_format_arg( Visitor&& vis, std::basic_format_arg<Context> arg );  // (depuis C++20) (obsolète en C++26)

Applique le visiteur vis à l'objet contenu dans arg.

Équivalent à std::visit(std::forward<Visitor>(vis), value), où value est le std::variant stocké dans arg.

Paramètres

  • vis — un Callable qui accepte toute alternative possible de arg
  • arg — un std::basic_format_arg à visiter

Valeur de retour

La valeur renvoyée par l'invocation sélectionnée du visiteur.

Notes

À partir de C++26, std::visit_format_arg est obsolète au profit des fonctions membres visit de std::basic_format_arg.
