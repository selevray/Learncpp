std::basic_format_context

Défini dans l'en-tête <format>

template< class OutputIt, class CharT >
class basic_format_context;  // (1) (depuis C++20)

using format_context = basic_format_context</* unspecified */, char>;  // (2) (depuis C++20)

using wformat_context = basic_format_context</* unspecified */, wchar_t>;  // (3) (depuis C++20)

Fournit un accès à l'état de formatage, constitué des arguments de formatage et de l'itérateur de sortie.

  1. L'argument de modèle non spécifié est un itérateur de sortie qui ajoute à std::string, tel que std::back_insert_iterator<std::string>. Les implémentations utilisent généralement un itérateur vers un type de tampon à effacement de type qui permet d'ajouter à tout conteneur contigu et redimensionnable.

  2. L'argument de modèle non spécifié est un itérateur de sortie qui ajoute à std::wstring.

Le comportement est indéfini si OutputIt ne modélise pas std::output_iterator<const CharT&>.

Un programme qui déclare une spécialisation explicite ou partielle de std::basic_format_context est mal formé, aucun diagnostic requis.

Les objets std::basic_format_context ne peuvent être créés que par l'implémentation. Le code utilisateur n'est autorisé à modifier le contexte de formatage que via la fonction format des spécialisations de std::formatter.

std::basic_format_context::arg

std::basic_format_arg<basic_format_context> arg( std::size_t id ) const;

Renvoie un std::basic_format_arg contenant le id-ième argument de args, où args est le pack de paramètres ou l'objet std::basic_format_args passé à la fonction de formatage.

Si id n'est pas inférieur au nombre d'arguments de formatage, renvoie un std::basic_format_arg construit par défaut (contenant un objet std::monostate).

std::basic_format_context::locale

std::locale locale();

Renvoie la locale passée à la fonction de formatage, ou un std::locale construit par défaut si la fonction de formatage ne prend pas de locale.

std::basic_format_context::out

iterator out();

Renvoie l'itérateur vers le tampon de sortie. Le résultat est construit par déplacement à partir de l'itérateur stocké.

std::basic_format_context::advance_to

void advance_to( iterator it );

Affecte par déplacement it à l'itérateur de sortie stocké. Après un appel à advance_to, l'appel suivant à out() renverra un itérateur ayant la valeur que it avait avant l'affectation.
