std::runtime_format

Défini dans l'en-tête <format>

/*runtime-format-string*/<char> runtime_format( std::string_view fmt ) noexcept;  // (1) (depuis C++26)

/*runtime-format-string*/<wchar_t> runtime_format( std::wstring_view fmt ) noexcept;  // (2) (depuis C++26)

Retourne un objet qui stocke une chaîne de format à l'exécution, directement utilisable par les fonctions de formatage destinées aux utilisateurs, et qui peut être implicitement converti en std::basic_format_string.

Paramètres

  • fmt — une vue de chaîne

Valeur de retour

Un objet contenant la chaîne de format à l'exécution, du type exposé à titre explicatif :

Modèle de classe runtime-format-string <CharT>

template< class CharT >
struct /*runtime-format-string*/;  // ( exposition uniquement* )

Objets membres

L'objet retourné contient un membre de données non statique exposé à titre explicatif str de type std::basic_string_view<CharT>.

Constructeurs et affectations

/*runtime-format-string*/( std::basic_string_view<CharT> s ) noexcept;  // (1)

/*runtime-format-string*/( const /*runtime-format-string*/& ) = delete;  // (2)

/*runtime-format-string*/& operator=( const /*runtime-format-string*/& ) = delete;  // (3)

  1. Initialise str avec s.

  2. Le constructeur de copie est explicitement supprimé. Le type n'est ni copiable ni déplaçable.

  3. L'affectation est explicitement supprimée.

Notes

Comme le type de retour de runtime_format n'est ni copiable ni déplaçable, tenter de passer runtime_fmt en tant que glvalue empêche la construction de std::basic_format_string, ce qui rend le programme mal formé. Pour construire std::basic_format_string avec runtime_format, la valeur retournée par runtime_format est passée directement à std::basic_format_string en tant que prvalue, où l'élision de copie est garantie.

auto runtime_fmt = std::runtime_format("{}");

auto s0 = std::format(runtime_fmt, 1); // error
auto s1 = std::format(std::move(runtime_fmt), 1); // still error
auto s2 = std::format(std::runtime_format("{}"), 1); // ok

Exemple

#include <format>
#include <print>
#include <string>
#include <string_view>

int main()
{
    std::print("Hello {}!\n", "world");

    std::string fmt;
    for (int i{}; i != 3; ++i)
    {
        fmt += "{} "; // construit la chaîne de format
        std::print("{} : ", fmt);
        std::println(std::runtime_format(fmt), "alpha", 'Z', 3.14, "unused");
    }
}

Output:

Hello world!
{}  : alpha
{} {}  : alpha Z
{} {} {}  : alpha Z 3.14
