std::format

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <format>

template< class... Args >
std::string format( std::format_string<Args...> fmt, Args&&... args );  // (1) (depuis C++20)

template< class... Args >
std::wstring format( std::wformat_string<Args...> fmt, Args&&... args );  // (2) (depuis C++20)

template< class... Args >
std::string format( const std::locale& loc,
                    std::format_string<Args...> fmt, Args&&... args );  // (3) (depuis C++20)

template< class... Args >
std::wstring format( const std::locale& loc,
                     std::wformat_string<Args...> fmt, Args&&... args );  // (4) (depuis C++20)

Formate args selon la chaîne de format fmt, et renvoie le résultat sous forme de chaîne. Si présent, loc est utilisé pour le formatage spécifique à la locale.

  1. Équivalent à return std::vformat(fmt.get(), std::make_format_args(args...));.

  2. Équivalent à return std::vformat(fmt.get(), std::make_wformat_args(args...));.

  3. Équivalent à return std::vformat(loc, fmt.get(), std::make_format_args(args...));.

  4. Équivalent à return std::vformat(loc, fmt.get(), std::make_wformat_args(args...));.

Depuis P2216R3, std::format effectue une vérification à la compilation de la chaîne de format (via le type auxiliaire std::format_string ou std::wformat_string). Si elle est jugée invalide pour les types des arguments à formater, une erreur de compilation est émise. Si la chaîne de format ne peut pas être une constante de compilation, ou si la vérification à la compilation doit être évitée, utilisez plutôt std::vformat ou std::runtime_format sur fmt (depuis C++26).

Les exigences suivantes s'appliquent à chaque type T dans Args, où CharT est char pour les surcharges (1,3), wchar_t pour les surcharges (2,4) :

  • std::formatter<T, CharT> doit satisfaire BasicFormatter
  • std::formatter<T, CharT>::parse() doit être constexpr depuis P2216R3 (std::vformat n'a pas cette exigence)

Paramètres

  • fmt — un objet représentant la chaîne de format. La chaîne de format est composée de

    • caractères ordinaires (sauf { et }), qui sont recopiés sans modification dans la sortie,
    • séquences d'échappement {{ et }}, qui sont remplacées respectivement par { et } dans la sortie, et
    • champs de remplacement.

    Chaque champ de remplacement a le format suivant :

    { arg-id (facultatif) } | (1)

    { arg-id (facultatif) : format-spec } | (2)

    1. champ de remplacement sans spécification de format

    2. champ de remplacement avec une spécification de format

    • arg-id — spécifie l'indice de l'argument dans args dont la valeur doit être utilisée pour le formatage ; s'il est omis, les arguments sont utilisés dans l'ordre.

      Les arg-id ﻿s dans une chaîne de format doivent tous être présents ou tous être omis. Mélanger l'indexation manuelle et automatique est une erreur.

    • format-spec — la spécification de format définie par la spécialisation std::formatter pour l'argument correspondant. Ne peut pas commencer par }.

    • Pour les types de base et les types de chaînes standard, la spécification de format est interprétée comme spécification de format standard.

    • Pour les types chrono, la spécification de format est interprétée comme spécification de format chrono.

    • Pour les types d'intervalles, la spécification de format est interprétée comme spécification de format d'intervalle.
    • Pour std::pair et std::tuple, la spécification de format est interprétée comme spécification de format de tuple.
    • Pour std::thread::id et std::stacktrace_entry, voir spécification de format de thread id et spécification de format d'entrée de stacktrace.
    • Pour std::basic_stacktrace, aucun spécificateur de format n'est autorisé.

    (depuis C++23)

    • Pour std::filesystem::path, voir spécification de format de chemin.

    (depuis C++26)

    • Pour les autres types formatables, la spécification de format est déterminée par les spécialisations formatter définies par l'utilisateur.

  • args... — arguments à formater

  • loc — std::locale utilisé pour le formatage spécifique à la locale

Valeur de retour

Une chaîne d'objet contenant le résultat formaté.

Exceptions

Lève std::bad_alloc en cas d'échec d'allocation. Propage aussi toute exception levée par un formateur.

Notes

Il n'est pas une erreur de fournir plus d'arguments que la chaîne de format n'en requiert :

std::format("{} {}!", "Hello", "world", "something"); // OK, produit "Hello world!"

Depuis P2216R3, c'est une erreur si la chaîne de format n'est pas une expression constante. std::vformat peut être utilisé dans ce cas.

std::string f(std::string_view runtime_format_string)
{
    // return std::format(runtime_format_string, "foo", "bar"); // erreur
    return std::vformat(runtime_format_string, std::make_format_args("foo", "bar")); // OK
}

std::runtime_format peut être utilisé directement sur std::format au lieu de std::vformat, qui nécessite std::basic_format_args comme argument.

std::string f(std::string_view runtime_format_string)
{
    return std::format(std::runtime_format(runtime_format_string), "foo", "bar");
}

(depuis C++26)

Exemple

#include <format>
#include <iostream>
#include <string>
#include <string_view>

template<typename... Args>
std::string dyna_print(std::string_view rt_fmt_str, Args&&... args)
{
    return std::vformat(rt_fmt_str, std::make_format_args(args...));
}

int main()
{
    std::cout << std::format("Hello {}!\n", "world");

    std::string fmt;
    for (int i{}; i != 3; ++i)
    {
        fmt += "{} "; // construit la chaîne de format
        std::cout << fmt << " : ";
        std::cout << dyna_print(fmt, "alpha", 'Z', 3.14, "unused");
        std::cout << '\n';
    }
}

Output:

Hello world!
{}  : alpha
{} {}  : alpha Z
{} {} {}  : alpha Z 3.14
