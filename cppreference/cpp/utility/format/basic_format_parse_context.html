Défini dans l'en-tête <format>

template< class CharT >
class basic_format_parse_context;  // (depuis C++20)

Fournit un accès à l'état d'analyse de la chaîne de format, constitué de l'intervalle de la chaîne de format en cours d'analyse et du compteur d'arguments pour l'indexation automatique.

Une instance de std::basic_format_parse_context est passée à Formatter lors de l'analyse de la spécification de format.

Un programme qui déclare une spécialisation explicite ou partielle de std::basic_format_parse_context est mal formé, aucun diagnostic requis.

std::basic_format_parse_context::check_dynamic_spec

template< class... Ts >
constexpr void check_dynamic_spec( std::size_t id ) noexcept;  // (depuis C++26)

Si id est supérieur ou égal à num_args fourni dans le constructeur, ou si le type de l'argument de format correspondant (après conversion en std::basic_format_arg) n'est pas l'un des types de Ts..., l'appel n'est pas une expression constante de base. Un appel à check_dynamic_spec n'a aucun effet à l'exécution.

Le programme est mal formé sauf si sizeof...(Ts) >= 1, les types de Ts... sont uniques, et chaque type est l'un de bool, char_type, int, unsigned int, long long int, unsigned long long int, float, double, long double, const char_type*, std::basic_string_view<char_type> ou const void*.
