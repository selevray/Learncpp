Le modèle de classe std::basic_format_string encapsule un std::basic_string_view qui sera utilisé par les fonctions de formatage.

Le constructeur de std::basic_format_string effectue des vérifications de chaîne de format à la compilationsauf si l'argument du constructeur est renvoyé par std::runtime_format (depuis C++26).

Fonctions membres

  • (constructeur) — construit un basic_format_string, levant une erreur de compilation si l'argument n'est pas une chaîne de format (fonction membre publique)
  • get — renvoie la chaîne encapsulée (fonction membre publique)

std::basic_format_string::basic_format_string

template< class T >
consteval basic_format_string( const T& s );  // (1)

basic_format_string( /* runtime-format-string */<CharT> s ) noexcept;  // (2) (depuis C++26)
  1. Construit un objet basic_format_string qui stocke une vue de la chaîne s. Si l'argument n'est pas une constante de compilation, ou s'il ne peut pas être analysé comme chaîne de format pour les types d'arguments de formatage Args, la construction est mal formée.

Cette surcharge ne participe à la résolution de surcharge que si const T& modélise std::convertible_to<std::basic_string_view<CharT>>.

  1. Construit un objet basic_format_string qui stocke une vue de la chaîne s telle que renvoyée par std::runtime_format. Il n'effectue aucune vérification de chaîne de format à la construction.

Paramètres

  • s — un objet représentant la chaîne de format. La chaîne de format est composée de

    • caractères ordinaires (sauf { et }), qui sont recopiés sans modification dans la sortie,
    • séquences d'échappement {{ et }}, qui sont remplacées respectivement par { et } dans la sortie, et
    • champs de remplacement.

    Chaque champ de remplacement a le format suivant :

    { arg-id (facultatif) } | (1)

    { arg-id (facultatif) : format-spec } | (2)

    1. champ de remplacement sans spécification de format

    2. champ de remplacement avec une spécification de format

    • arg-id — spécifie l'indice de l'argument dans args dont la valeur doit être utilisée pour le formatage ; s'il est omis, les arguments sont utilisés dans l'ordre.

      Les arg-id ﻿s dans une chaîne de format doivent tous être présents ou tous être omis. Mélanger l'indexation manuelle et automatique est une erreur.

    • format-spec — la spécification de format définie par la spécialisation std::formatter pour l'argument correspondant. Ne peut pas commencer par }.

    • Pour les types de base et les types de chaînes standard, la spécification de format est interprétée comme spécification de format standard.

    • Pour les types chrono, la spécification de format est interprétée comme spécification de format chrono.

    • Pour les types d'intervalles, la spécification de format est interprétée comme spécification de format d'intervalle.
    • Pour std::pair et std::tuple, la spécification de format est interprétée comme spécification de format de tuple.
    • Pour std::thread::id et std::stacktrace_entry, voir spécification de format de thread id et spécification de format d'entrée de stacktrace.
    • Pour std::basic_stacktrace, aucun spécificateur de format n'est autorisé.

    (depuis C++23)

    • Pour std::filesystem::path, voir spécification de format de chemin.

    (depuis C++26)

    • Pour les autres types formatables, la spécification de format est déterminée par les spécialisations formatter définies par l'utilisateur.

std::basic_format_string::get

constexpr std::basic_string_view<CharT> get() const noexcept;

Renvoie la vue de chaîne stockée.

Notes

Les modèles d'alias format_string et wformat_string utilisent std::type_identity_t pour inhiber la déduction d'arguments de modèle. Typiquement, lorsqu'ils apparaissent comme paramètre de fonction, leurs arguments de modèle sont déduits à partir d'autres arguments de la fonction.

template<class... Args>
std::string format(std::format_string<Args...> fmt, Args&&... args);

auto s = format("{} {}", 1.0, 2);
// Appelle format<double, int>. Les arguments sont déduits de 1.0, 2
// En raison de l'utilisation de type_identity_t dans format_string, la déduction d'arguments de modèle
// ne prend pas en compte le type de la chaîne de format.
