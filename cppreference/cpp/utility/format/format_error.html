Définit le type de l'objet exception levé pour signaler les erreurs de la bibliothèque de formatage.

format_error( const std::string& what_arg );  // (1)

format_error( const format_error& other ) noexcept;  // (3)

  1. Construit l'objet exception avec what_arg comme chaîne explicative. Après la construction, std::strcmp(what(), what_arg.c_str()) == 0.

  2. Construit l'objet exception avec what_arg comme chaîne explicative. Après la construction, std::strcmp(what(), what_arg) == 0.

  3. Constructeur de copie. Si *this et other ont tous deux pour type dynamique std::format_error, alors std::strcmp(what(), other.what()) == 0. Aucune exception ne peut être levée par le constructeur de copie.

Paramètres

  • what_arg — chaîne explicative
  • other — un autre objet exception à copier

Exceptions

1,2) Peut lever std::bad_alloc.

Notes

Comme la copie de std::format_error n'est pas autorisée à lever d'exceptions, ce message est généralement stocké en interne sous forme de chaîne à comptage de références allouée séparément. C'est aussi pour cette raison qu'il n'existe aucun constructeur acceptant std::string&& : il devrait de toute façon copier le contenu.

Une classe d'exception standard dérivée doit avoir un constructeur de copie publiquement accessible. Il peut être défini implicitement tant que les chaînes explicatives obtenues par what() sont les mêmes pour l'objet original et l'objet copié.

Exemple

#include <format>
#include <print>
#include <string_view>
#include <utility>

int main()
{
    try
    {
        auto x13{37};
        auto args{std::make_format_args(x13)};
        std::ignore = std::vformat("{:()}", args); // throws
    }
    catch(const std::format_error& ex)
    {
        std::println("{}", ex.what());
    }
}
