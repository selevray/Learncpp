La spécialisation de modèle de std::formatter pour std::pair et std::tuple permet aux utilisateurs de convertir une paire ou un tuple en sa représentation textuelle sous forme de collection d'éléments en utilisant des fonctions de formatage.

Le nom réservé à l'exposition /*pair-or-tuple*/ désigne soit le modèle de classe std::pair, soit std::tuple.

Cette spécialisation satisfait aux exigences Formatter si (std::formattable<const Ts, CharT> && ...) est true. Elle satisfait toujours aux exigences BasicFormatter.

Spécification de format

La syntaxe de tuple-format-spec est :

| | | | tuple-fill-and-align ﻿*(facultatif)* width ﻿*(facultatif)* tuple-type ﻿*(facultatif)* | | | |

tuple-fill-and-align est interprété de la même manière que fill-and-align, sauf que le fill dans tuple-fill-and-align est n'importe quel caractère autre que {, } ou :.

width est décrit dans spécification de largeur de format standard.

Le tuple-type modifie la manière dont un tuple est formaté, certaines options n'étant valables qu'avec certains types d'arguments.

Les types de présentation de tuple disponibles sont :

  • m : indique que les crochets ouvrant et fermant doivent être "" tandis que le séparateur doit être ": ".

    • Si m est choisi comme tuple-type, le programme est mal formé à moins que sizeof...(Ts) == 2 ne soit true.

  • n : indique que le séparateur, ainsi que les crochets ouvrant et fermant, doivent être "".

Objets membres

Nom du membre Définition

  • underlying_ (privé) — tableau des formateurs sous-jacents de type std::tuple<std::formatter<std::remove_cvref_t<Ts>, CharT>...> (membre objet exposé uniquement)*
  • separator_ (privé) — une chaîne représentant le séparateur du résultat formaté du tuple (par défaut ", ") (membre objet exposé uniquement)*
  • opening-bracket_ (privé) — une chaîne représentant le crochet ouvrant du résultat formaté du tuple (par défaut "(") (membre objet exposé uniquement)*
  • closing-bracket_ (privé) — une chaîne représentant le crochet fermant du résultat formaté du tuple (par défaut ")") (membre objet exposé uniquement)*

Fonctions membres

  • set_separator — définit un séparateur spécifié pour le résultat formaté du tuple (fonction membre publique)
  • set_brackets — définit des crochets ouvrant et fermant spécifiés pour le résultat formaté du tuple (fonction membre publique)
  • parse — analyse le spécificateur de format tel que spécifié par tuple-format-spec (fonction membre publique)
  • format — écrit la sortie formatée du tuple selon ce qui est spécifié par tuple-format-spec (fonction membre publique)

std::formatter<pair-or-tuple>::parse

template< class ParseContext >
constexpr auto parse( ParseContext& ctx ) -> ParseContext::iterator;

Analyse les spécificateurs de format comme un tuple-format-spec et stocke les spécificateurs analysés dans l'objet courant.

Si tuple-type ou l'option n est présente, les valeurs de opening-bracket, closing-bracket et separator sont modifiées selon les besoins.

Pour chaque élément e dans underlying_, appelle e.parse(ctx) pour analyser un format-spec vide et, si e.set_debug_format() est une expression valide, appelle e.set_debug_format().

Renvoie un itérateur situé après la fin de la tuple-format-spec.

std::formatter<pair-or-tuple>::format

template< class FormatContext >
FormatContext::iterator
format( /*maybe-const-pair-or-tuple*/<Ts...>& elems, FormatContext& ctx ) const;

/*maybe-const-pair-or-tuple*/ denotes:

  • const /*pair-or-tuple*/, si (std::formattable<const Ts, CharT> && ...) est true,
  • /*pair-or-tuple*/ sinon.

Écrit les éléments suivants dans ctx.out() selon ce qui est spécifié par tuple-format-spec, dans l'ordre :

  • opening-bracket_,

  • pour chaque indice I dans [0,sizeof...(Ts)) :

    • if I != 0, separator_,
    • le résultat de l'écriture de std::get<I>(elems) via std::get<I>(underlying_), et

  • closing-bracket_.

Renvoie un itérateur situé après la fin de l'intervalle de sortie.
