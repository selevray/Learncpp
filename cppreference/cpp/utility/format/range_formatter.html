std::range_formatter est un modèle de classe auxiliaire permettant d'implémenter les spécialisations de std::formatter pour les intervalles.

Spécificateur de format d'intervalle

La syntaxe de range-format-spec est :

| | | | range-fill-and-align ﻿*(facultatif)* width ﻿*(facultatif)* n(facultatif) range-type ﻿*(facultatif)* range-underlying-spec ﻿*(facultatif)* | | | |

range-fill-and-align est interprété de la même manière que fill-and-align, sauf que le fill dans range-fill-and-align est n'importe quel caractère autre que {, } ou :.

width est décrit dans spécification de largeur de format standard.

L'option n provoque le formatage de la plage sans les crochets ouvrant et fermant.

assert(std::format("{}", views::iota(1, 5)) == "[1, 2, 3, 4]");
assert(std::format("{:n}", views::iota(1, 5)) == "1, 2, 3, 4");

Le format-spec dans un range-underlying-spec (sa syntaxe est équivalente à : format-spec), s'il est présent, est interprété par le formateur d'élément de plage std::formatter<T, CharT>.

std::array ints{12, 10, 15, 14};

assert(std::format("{}", ints) == "[12, 10, 15, 14]");
assert(std::format("{::X}", ints) == "[C, A, F, E]");
assert(std::format("{:n:_^4}", ints) == "_12_, _10_, _15_, _14_");

Le range-type modifie la manière dont une plage est formatée, certaines options n'étant valables qu'avec certains types d'arguments.

Les types de présentation d'intervalle disponibles sont :

  • m : indique que la parenthèse ouvrante doit être "{", la parenthèse fermante doit être "}", le séparateur doit être ", ", et chaque élément de la plage doit être formaté comme si m était spécifié pour son tuple-type (dans tuple-format-spec).
    • Si m est choisi comme range-type, le programme est mal formé à moins que T soit une spécialisation de :
      • std::pair, or
      • std::tuple tel que std::tuple_size_v<T> == 2 soit true.
std::array char_pairs
{
    std::pair{'A', 5}, std::pair{'B', 10}, std::pair{'C', 12}
};

assert(std::format("{}", char_pairs) == "[('A', 5), ('B', 10), ('C', 12)]");
assert(std::format("{:m}", char_pairs) == "{'A': 5, 'B': 10, 'C': 12}");
  • s : indique que la plage doit être formatée comme une chaîne.
  • ?s : indique que la plage doit être formatée comme une chaîne échappée.
    • Si s ou ?s est choisi comme range-type, l'option n et range-underlying-spec ne doivent pas être incluses dans le spécificateur de format, et
    • le programme est mal formé à moins que T soit CharT.
std::array star{'S', 'T', 'A', 'R'};

assert(std::format("{}", star) == "['S', 'T', 'A', 'R']");
assert(std::format("{:s}", star) == "STAR");
assert(std::format("{:?s}", star) == "\"STAR\"");

Membres de données

Nom du membre Définition

  • std::formatter<T, CharT> underlying_ (privé) — le formateur sous-jacent pour les éléments (membre donnée exposition-only)*
  • std::basic_string_view<CharT> separator_ (privé) — une chaîne représentant le séparateur du résultat formaté de la plage. Le séparateur par défaut est ", ". (membre donnée exposition-only)*
  • std::basic_string_view<CharT> opening-bracket_ (privé) — une chaîne représentant la parenthèse ouvrante du résultat formaté de la plage. La parenthèse ouvrante par défaut est "[". (membre donnée exposition-only)*
  • std::basic_string_view<CharT> closing-bracket_ (privé) — une chaîne représentant la parenthèse fermante du résultat formaté de la plage. La parenthèse fermante par défaut est "]". (membre donnée exposition-only)*

Fonctions membres

  • set_separator — définit un séparateur spécifié pour le résultat formaté de la plage (fonction membre publique)
  • set_brackets — définit des parenthèses ouvrante et fermante spécifiées pour le résultat formaté de la plage (fonction membre publique)
  • underlying — renvoie le formateur sous-jacent (fonction membre publique)
  • parse — analyse le spécificateur de format tel que spécifié par range-format-spec (fonction membre publique)
  • format — écrit la sortie formatée de l'intervalle telle que spécifiée par range-format-spec (fonction membre publique)

std::range_formatter::parse

template< class ParseContext >
constexpr auto parse( ParseContext& ctx ) -> ParseContext::iterator;

Analyse les spécificateurs de format comme un range-format-spec et stocke les spécificateurs analysés dans l'objet courant.

Appelle underlying_.parse(ctx) pour analyser format-spec dans range-format-spec ou, si ce dernier n'est pas présent, un format-spec vide.

Si range-type ou l'option n est présente, les valeurs de opening-bracket_, closing-bracket_ et separator_ sont modifiées selon les besoins.

Il appelle underlying_.set_debug_format() si :

  • le range-type n'est ni s ni ?s,
  • underlying_.set_debug_format() est une expression valide, et
  • il n'existe aucun range-underlying-spec.

Renvoie un itérateur situé après la fin de la range-format-spec.

std::range_formatter::format

template< ranges::input_range R, class FormatContext >
  requires std::formattable<ranges::range_reference_t<R>, CharT> &&
           std::same_as<std::remove_cvref_t<ranges::range_reference_t<R>>, T>
auto format( R&& r, FormatContext& ctx ) const -> FormatContext::iterator;

Si le range-type était soit s, soit ?s, il écrit le std::basic_string<CharT>(std::from_range, r) formaté sous forme de chaîne ou de chaîne échappée, respectivement, dans ctx.out().

Sinon, il écrit ce qui suit dans ctx.out() comme spécifié par range-format-spec, dans l'ordre :

  • opening-bracket_,

  • pour chaque e formatable de l'intervalle r :

    • le résultat de l'écriture de e via underlying_, et
    • separator_, sauf si e est le dernier élément de r, et

  • closing-bracket_.

Renvoie un itérateur situé après la fin de l'intervalle de sortie.
