template< ranges::input_range R, class CharT >
struct /*range-default-formatter*/<range_format::map, R, CharT>;  // (depuis C++23) ( exposition uniquement* )

Le modèle de classe /*range-default-formatter*/ pour les types d'intervalles est spécialisé pour formater une plage sous forme de table de clés vers valeurs si std::format_kind<R> vaut std::range_format::map.

std::range-default-formatter<std::range_format::map>::range-default-formatter

constexpr /*range-default-formatter*/();

Équivalent à :
underlying_.set_brackets(STATICALLY_WIDEN<CharT>("{"), STATICALLY_WIDEN<CharT>("}"));underlying_.underlying().set_brackets({}, {});underlying_.underlying().set_separator(STATICALLY_WIDEN<charT>(": "));

où STATICALLY_WIDEN<CharT>("...") vaut "..." si CharT est char, et L"..." si CharT est wchar_t.

Le programme est mal formé à moins que :

  • element-type soit une spécialisation de std::pair, ou
  • element-type soit une spécialisation de std::tuple et std::tuple_size_v<element-type> soit 2.
