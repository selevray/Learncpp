    requires (K == std::range_format::string || K == std::range_format::debug_string)
struct /*range-default-formatter*/<K, R, CharT>;  // (depuis C++23) ( exposition uniquement* )

Le modèle de classe /*range-default-formatter*/ pour les types d'intervalles est spécialisé pour formater une plage sous forme de chaîne ou de chaîne échappée si std::format_kind<R> est soit std::range_format::string, soit std::range_format::debug_string.

Si ranges::input_range<const R> vaut true, le type de r est const R&. Sinon, le type est R&.

Soit s un std::basic_string<CharT> comme si on le construisait par s avec std::basic_string<CharT>(std::from_range, r) de sorte que ranges::equal(s, r) soit true.
