template< ranges::input_range R, class CharT >
struct /*range-default-formatter*/<range_format::sequence, R, CharT>;  // (depuis C++23) ( exposition uniquement* )

Le modèle de classe /*range-default-formatter*/ pour les types d'intervalles est spécialisé pour formater une plage sous forme de séquence d'éléments si std::format_kind<R> vaut std::range_format::sequence.
