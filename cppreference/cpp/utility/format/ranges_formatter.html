Modèles auxiliaires

template< std::range_format K, ranges::input_range R, class CharT >
struct /*range-default-formatter*/;  // ( exposition uniquement* )

La spécialisation de modèle de std::formatter pour les types intervalles permet aux utilisateurs de convertir un intervalle en sa représentation textuelle sous forme de collection d'éléments ou de chaîne, à l'aide des fonctions de formatage.

La spécialisation est dérivée de range-default-formatter<std::format_kind<R>, R, CharT>.

La spécialisation est activée si R satisfait input_range, std::format_kind<R> n'est pas std::range_format::disabled, et std::formattable<ranges::range_reference_t<R>, CharT> est true.

Cette spécialisation satisfait les exigences Formatter si const R modélise input_range et ranges::range_reference_t<const R> modélise std::formattable<CharT>. Elle satisfait toujours les exigences BasicFormatter.

Spécification de format

La syntaxe de range-format-spec est :

| | | | range-fill-and-align ﻿*(facultatif)* width ﻿*(facultatif)* n(facultatif) range-type ﻿*(facultatif)* range-underlying-spec ﻿*(facultatif)* | | | |

La syntaxe est entièrement décrite dans la spécification de format d'intervalle.

Pour les spécialisations de std::formatter où std::format_kind<R> est soit std::range_format::string soit std::range_format::debug_string, le format-spec est std-format-spec au lieu de range-format-spec (qui utilise std::formatter<std::basic_string<CharT>, CharT> comme formateur sous-jacent).

Spécialisations de range-default-formatter

  • range-default-formatter<std::range_format::sequence> (C++23) — utilitaire de formatage pour les intervalles sous forme de séquence (spécialisation de modèle de classe)
  • range-default-formatter<std::range_format::map> (C++23) — utilitaire de formatage pour les intervalles sous forme de dictionnaire (spécialisation de modèle de classe)
  • range-default-formatter<std::range_format::set> (C++23) — utilitaire de formatage pour les intervalles sous forme d'ensemble (spécialisation de modèle de classe)
  • range-default-formatter<std::range_format::string>range-default-formatter<std::range_format::debug_string> (C++23) — utilitaire de formatage pour les intervalles sous forme de chaîne ou de chaîne échappée (spécialisation de modèle de classe)
