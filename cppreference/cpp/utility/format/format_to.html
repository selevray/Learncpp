std::format_to

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <format>

template< class OutputIt, class... Args >
OutputIt format_to( OutputIt out,
                    std::format_string<Args...> fmt, Args&&... args );  // (1) (depuis C++20)

template< class OutputIt, class... Args >
OutputIt format_to( OutputIt out,
                    std::wformat_string<Args...> fmt, Args&&... args );  // (2) (depuis C++20)

template< class OutputIt, class... Args >
OutputIt format_to( OutputIt out, const std::locale& loc,
                    std::format_string<Args...> fmt, Args&&... args );  // (3) (depuis C++20)

template< class OutputIt, class... Args >
OutputIt format_to( OutputIt out, const std::locale& loc,
                    std::wformat_string<Args...> fmt, Args&&... args );  // (4) (depuis C++20)

Formate args selon la chaîne de format fmt, et écrit le résultat dans l'itérateur de sortie out. Si présent, loc est utilisé pour le formatage spécifique à la locale.

Équivalent à :

  1. return std::vformat_to(std::move(out), fmt.str, std::make_format_args(args...));

  2. return std::vformat_to(std::move(out), fmt.str, std::make_wformat_args(args...));

  3. return std::vformat_to(std::move(out), loc, fmt.str, std::make_format_args(args...));

  4. return std::vformat_to(std::move(out), loc, fmt.str, std::make_wformat_args(args...));.

Soit CharT égal à char pour les surcharges (1,3), wchar_t pour les surcharges (2,4).

Ces surcharges ne participent à la résolution de surcharge que si OutputIt satisfait le concept std::output_iterator<const CharT&>.

Si l'une des conditions suivantes est satisfaite, le comportement est indéfini :

  • OutputIt ne modélise pas std::output_iterator<const CharT&>.
  • std::formatter<Ti, CharT> ne satisfait pas aux exigences BasicFormatter (telles que requises par std::make_format_args et std::make_wformat_args) pour un Ti dans Args.

Paramètres

  • out — itérateur vers le tampon de sortie

  • fmt — un objet représentant la chaîne de format. La chaîne de format est composée de

    • caractères ordinaires (sauf { et }), qui sont recopiés sans modification dans la sortie,
    • séquences d'échappement {{ et }}, qui sont remplacées respectivement par { et } dans la sortie, et
    • champs de remplacement.

    Chaque champ de remplacement a le format suivant :

    { arg-id (facultatif) } | (1)

    { arg-id (facultatif) : format-spec } | (2)

    1. champ de remplacement sans spécification de format

    2. champ de remplacement avec une spécification de format

    • arg-id — spécifie l'indice de l'argument dans args dont la valeur doit être utilisée pour le formatage ; s'il est omis, les arguments sont utilisés dans l'ordre.

      Les arg-id ﻿s dans une chaîne de format doivent tous être présents ou tous être omis. Mélanger l'indexation manuelle et automatique est une erreur.

    • format-spec — la spécification de format définie par la spécialisation std::formatter pour l'argument correspondant. Ne peut pas commencer par }.

    • Pour les types de base et les types de chaînes standard, la spécification de format est interprétée comme spécification de format standard.

    • Pour les types chrono, la spécification de format est interprétée comme spécification de format chrono.

    • Pour les types d'intervalles, la spécification de format est interprétée comme spécification de format d'intervalle.
    • Pour std::pair et std::tuple, la spécification de format est interprétée comme spécification de format de tuple.
    • Pour std::thread::id et std::stacktrace_entry, voir spécification de format de thread id et spécification de format d'entrée de stacktrace.
    • Pour std::basic_stacktrace, aucun spécificateur de format n'est autorisé.

    (depuis C++23)

    • Pour std::filesystem::path, voir spécification de format de chemin.

    (depuis C++26)

    • Pour les autres types formatables, la spécification de format est déterminée par les spécialisations formatter définies par l'utilisateur.

  • args... — arguments à formater

  • loc — std::locale utilisé pour le formatage spécifique à la locale

Valeur de retour

Itérateur au-delà de la fin de l'intervalle de sortie.

Exceptions

Propage toute exception levée par les opérations du formateur ou de l'itérateur.

Notes

À partir de P2216R3, c'est une erreur si la chaîne de format n'est pas une expression constante. std::vformat_to ou std::runtime_format (depuis C++26) peut être utilisé dans ce cas.

Exemple

#include <format>
#include <iostream>
#include <iterator>
#include <string>

int main()
{
    std::string buffer;

    std::format_to
    (
        std::back_inserter(buffer), // < OutputIt
        "Hello, C++{}!\n",          // < fmt
        "20"                        // < arg
    );
    std::cout << buffer;
    buffer.clear();

    std::format_to
    (
        std::back_inserter(buffer), // < OutputIt
        "Hello, {0}::{1}!{2}",      // < fmt
        "std",                      // < arg {0}
        "format_to()",              // < arg {1}
        "\n",                       // < arg {2}
        "extra param(s)..."         // < unused
    );
    std::cout << buffer << std::flush;

    std::wstring wbuffer;
    std::format_to
    (
        std::back_inserter(wbuffer),// < OutputIt
        L"Hello, {2}::{1}!{0}",     // < fmt
        L"\n",                      // < arg {0}
        L"format_to()",             // < arg {1}
        L"std",                     // < arg {2}
        L"...is not..."             // < unused
        L"...an error!"             // < unused
    );
    std::wcout << wbuffer;
}

Output:

Hello, C++20!
Hello, std::format_to()!
Hello, std::format_to()!

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 3539 C++20 out ne pouvait pas être un itérateur à déplacement seul il peut l'être
P2216R3 C++20 lève std::format_error pour une chaîne de format invalide entraîne à la place une erreur à la compilation
P2418R2 C++20 les objets qui ne sont ni utilisables en const ni copiables (comme les objets de type générateur) ne sont pas formatables permettre le formatage de ces objets
P2508R1 C++20 il n'existe aucun nom visible par l'utilisateur pour cette fonctionnalité le nom basic_format_string est exposé
