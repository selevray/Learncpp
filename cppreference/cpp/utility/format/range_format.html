std::range_format

enum class range_format {
    disabled,
    map,
    set,
    sequence,
    string,
    debug_string
};  // (depuis C++23)

Spécifie comment un intervalle doit être formaté.

Constantes

Nom Explication

  • disabled — interdit au formateur par défaut des intervalles de formater un intervalle
  • map — permet de formater un intervalle sous forme de représentation de type dictionnaire avec des crochets "{", "}" modifiés et le séparateur ": " pour les types semblables à des paires sous-jacents, selon le format suivant : { key-1 : value-1, ..., key-n : value-n }
  • set — permet de formater un intervalle sous forme de représentation d'ensemble avec des crochets "{" et "}" modifiés, selon le format suivant : { key-1, ..., key-n }
  • sequence — permet de formater un intervalle sous forme de représentation de séquence avec les crochets par défaut "[", "]" et le séparateur ", ", selon le format suivant : [ element-1, ..., element-n ]
  • string — permet de formater une plage sous forme de chaîne
  • debug_string — permet de formater une plage sous forme de chaîne échappée
