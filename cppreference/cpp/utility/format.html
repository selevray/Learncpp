Bibliothèque de formatage (depuis C++20)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

La bibliothèque de formatage de texte offre une alternative sûre et extensible aux fonctions de la famille printf. Elle est destinée à compléter la bibliothèque d'flux d'entrée/sortie existante de C++.

Spécifications de format

Une spécification de format indique comment les objets sont formatés avec différents types d'options.

La mise en forme des objets de types de base et des types de chaînes standard utilise la spécification de format de base. D'autres composants de la bibliothèque peuvent aussi fournir leurs propres spécifications de format, voir ici pour plus de détails.

Fonctions de formatage

Défini dans l'en-tête <format>

  • format (C++20) — stocke la représentation formatée des arguments dans une nouvelle chaîne (modèle de fonction)
  • format_to (C++20) — écrit la représentation formatée de ses arguments via un itérateur de sortie (modèle de fonction)
  • format_to_n (C++20) — écrit la représentation formatée de ses arguments via un itérateur de sortie, sans dépasser la taille spécifiée (modèle de fonction)
  • formatted_size (C++20) — détermine le nombre de caractères nécessaires pour stocker la représentation formatée de ses arguments (modèle de fonction)

Concepts de formatage

Nous traitons intentionnellement l'ajout de std::basic_format_string (P2508) comme un rapport de défaut, car toutes les implémentations connues rendent ces composants disponibles en mode C++20, bien que cela ne soit pas officiellement classé ainsi.

Exemple

#include <cassert>
#include <format>

int main()
{
    std::string message = std::format("The answer is {}.", 42);
    assert(message == "The answer is 42.");
}
