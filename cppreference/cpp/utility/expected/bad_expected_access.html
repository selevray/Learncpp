class bad_expected_access : public std::bad_expected_access<void>  // (1) (depuis C++23)

  1. Définit un type d'objet à lever par std::expected::value lors de l'accès à un objet attendu qui contient une valeur inattendue. bad_expected_access<E> stocke une copie de la valeur inattendue.

  2. bad_expected_access<void> est la classe de base de toutes les autres spécialisations de bad_expected_access.

Paramètres

(aucune)

Valeur de retour

Pointeur vers une chaîne terminée par un caractère nul contenant des informations explicatives. La chaîne convient à la conversion et à l'affichage sous forme de std::wstring. Le pointeur est garanti valide au moins jusqu'à la destruction de l'objet exception dont il est obtenu, ou jusqu'à l'appel d'une fonction membre non const (par ex. l'opérateur d'affectation par copie) sur cet objet exception.

Notes

Les implémentations peuvent, sans y être obligées, redéfinir what().
