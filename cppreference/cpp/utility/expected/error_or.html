template< class G = E >
constexpr E error_or( G&& default_value ) const&;  // (1) (depuis C++23)

template< class G = E >
constexpr E error_or( G&& default_value ) &&;  // (2) (depuis C++23)

Renvoie la valeur inattendue si elle existe, sinon renvoie default_value.

  1. Si std::is_copy_constructible_v<E> ou std::is_convertible_v<G, E> est false, le programme est mal formé.

  2. Si std::is_move_constructible_v<E> ou std::is_convertible_v<G, E> est false, le programme est mal formé.

Paramètres

  • default_value — la valeur à utiliser si *this ne contient pas de valeur inattendue

Exigences sur les types

Valeur de retour

  1. has_value() ? std::forward<G>(default_value) : error()

  2. has_value() ? std::forward<G>(default_value) : std::move(error())
