Modèle primaire

constexpr T&& value() &&;  // (3) (depuis C++23)

void spécialisation partielle

constexpr void value() const&;  // (5) (depuis C++23)

constexpr void value() &&;  // (6) (depuis C++23)

Si *this contient une valeur attendue, renvoie une référence à la valeur contenue. Ne renvoie rien pour la spécialisation partielle void.

Sinon, lève une exception de type std::bad_expected_access<std::decay_t<E>> qui contient une copie de error().

1,2) Si std::is_copy_constructible_v<E> est false, le programme est mal formé.

3,4) Si std::is_copy_constructible_v<E> ou std::is_constructible_v<E, decltype(std::move(error()))> est false, le programme est mal formé.

  1. Si std::is_copy_constructible_v<E> est false, le programme est mal formé.

  2. Si std::is_move_constructible_v<E> est false, le programme est mal formé.

Valeur de retour

1,2) val

3,4) std::move(val)

Exceptions

1,2,5) Lève std::bad_expected_access(std::as_const(error())) si *this contient une valeur inattendue.

3,4,6) Lève std::bad_expected_access(std::move(error())) si *this contient une valeur inattendue.
