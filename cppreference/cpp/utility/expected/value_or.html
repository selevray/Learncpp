std::expected<T,E>::value_or

Modèle primaire

template< class U >
constexpr T value_or( U&& default_value ) const&;  // (1) (depuis C++23)

template< class U >
constexpr T value_or( U&& default_value ) &&;  // (2) (depuis C++23)

Renvoie la valeur attendue si elle existe, sinon renvoie default_value.

La spécialisation partielle void n'a pas ces fonctions membres.

  1. Si std::is_copy_constructible_v<T> ou std::is_convertible_v<U, T> est false, le programme est mal formé.

  2. Si std::is_move_constructible_v<T> ou std::is_convertible_v<U, T> est false, le programme est mal formé.

Paramètres

  • default_value — la valeur à utiliser si *this ne contient pas de valeur attendue

Valeur de retour

  1. has_value() ? **this : static_cast<T>(std::forward<U>(default_value))

  2. has_value() ? std::move(**this) : static_cast<T>(std::forward<U>(default_value))
