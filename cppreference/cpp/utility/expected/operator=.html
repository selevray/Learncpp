Affecte une nouvelle valeur à un objet expected existant.

Paramètres

  • other — un autre objet expected dont la valeur contenue doit être affectée
  • v — valeur à affecter à la valeur contenue
  • e — objet std::unexpected dont la valeur contenue doit être affectée
  • newval — la valeur contenue à construire
  • oldval — la valeur contenue à détruire
  • args — les arguments utilisés comme initialiseurs de newval

Modèle de fonction auxiliaire

Le modèle de fonction exposé uniquement reinit-expected est « défini » comme suit :

template<class NewType, class OldType, class... Args>
constexpr void reinit-expected(NewType& new_val, OldType& old_val, Args&&... args)
{
    // Cas 1 : la construction de “new_val” ne lève pas d'exception :
    // “new_val” peut être directement construit après destruction de “old_val”
    if constexpr (std::is_nothrow_constructible_v<NewType, Args...>)
    {
        std::destroy_at(std::addressof(old_val));
        std::construct_at(std::addressof(new_val), std::forward<Args>(args)...);
    }
    // Cas 2 : la construction par déplacement de “new_val” ne lève pas d'exception :
    // construire d'abord un objet temporaire NewType
    // (“old_val” reste intact si une exception est levée lors de cette construction)
    else if constexpr (std::is_nothrow_move_constructible_v<NewType>)
    {
        NewType temp(std::forward<Args>(args)...); // peut lever une exception
        std::destroy_at(std::addressof(old_val));
        std::construct_at(std::addressof(new_val), std::move(temp));
    }
    // Cas 3 : la construction de “new_val” peut lever une exception :
    // une sauvegarde de “old_val” est nécessaire afin de se rétablir après une exception
    else
    {
        OldType temp(std::move(old_val)); // peut lever une exception
        std::destroy_at(std::addressof(old_val));
        try
        {
            std::construct_at(std::addressof(new_val),
                              std::forward<Args>(args)...); // peut lever une exception
        }
        catch (...)
        {
            std::construct_at(std::addressof(old_val), std::move(temp));
            throw;
        }
    }
}

Ce modèle de fonction est appelé lorsque l'affectation va faire en sorte que *this contienne la valeur de l'autre alternative (c'est-à-dire de la valeur attendue vers la valeur inattendue, ou de la valeur inattendue vers la valeur attendue).

Dans ce cas, l'ancienne valeur oldval doit être détruite avant de construire la nouvelle valeur newval. Cependant, la construction de newval peut lever une exception. Afin de fournir une garantie forte d'exception, l'ancienne valeur doit être restaurée avant de relancer l'exception, de sorte que *this ait un état valide pendant que l'exception est traitée.
