Vérifie si *this représente une valeur attendue.

Valeur de retour

has_val

Notes

Un objet std::expected n'est jamais sans valeur. Si has_value() renvoie true, operator*() peut être utilisé pour accéder à la valeur attendue ; sinon, error() peut être utilisé pour accéder à la valeur inattendue.
