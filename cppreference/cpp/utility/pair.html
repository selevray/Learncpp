std::pair

template<
    class T1,
    class T2
> struct pair;

std::pair est un modèle de classe qui fournit un moyen de stocker deux objets hétérogènes en une seule unité. Une paire est un cas particulier de std::tuple à deux éléments.

Si ni T1 ni T2 n'est un type de classe éventuellement qualifié cv avec un destructeur non trivial, ni un tableau de tels types, le destructeur de pair est trivial.

Spécialisations auxiliaires

template< class T, class U >
constexpr bool enable_nonlocking_formatter_optimization<std::pair<T, U>>
 = enable_nonlocking_formatter_optimization<T> &&
   enable_nonlocking_formatter_optimization<U>;  // (depuis C++23)

Cette spécialisation de std::enable_nonlocking_formatter_optimization permet une implémentation efficace de std::print et de std::println pour l'affichage d'un objet pair lorsque T et U l'activent tous deux.
