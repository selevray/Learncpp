std::optional

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <optional>

template< class T >
class optional;  // (depuis C++17)

Le modèle de classe std::optional gère une valeur contenue optionnelle, c'est-à-dire une valeur pouvant être présente ou absente.

Un cas d'utilisation courant de optional est la valeur de retour d'une fonction susceptible d'échouer. Contrairement à d'autres approches, telles que std::pair<T, bool>, optional gère bien les objets coûteux à construire et est plus lisible, car l'intention est exprimée explicitement.

Toute instance de optional<T> contient à tout instant soit une valeur, soit aucune valeur.

Si un optional<T> contient une valeur, cette valeur est garantie d'être imbriquée dans l'objet optional, ce qui signifie qu'aucune allocation dynamique de mémoire n'a jamais lieu. Ainsi, un objet optional modélise un objet, et non un pointeur, bien que operator*() et operator->() soient définis.

Lorsqu'un objet de type optional<T> est converti contextuellement en bool, la conversion retourne true si l'objet contient une valeur et false s'il ne contient pas de valeur.

L'objet optional contient une valeur dans les conditions suivantes :

  • L'objet est initialisé ou affecté à partir d'une valeur de type T ou d'un autre optional qui contient une valeur.

L'objet ne contient pas de valeur dans les conditions suivantes :

  • L'objet est initialisé par défaut.
  • L'objet est initialisé ou affecté à partir d'une valeur de type std::nullopt_t ou d'un objet optional qui ne contient pas de valeur.
  • La fonction membre reset() est appelée.

L'objet optional est un view qui contient un élément s'il contient une valeur, ou zéro élément sinon s'il ne contient pas de valeur. La durée de vie de l'élément contenu est liée à l'objet.

(depuis C++26)

Il n'existe pas d'optional de références, de fonctions, de tableaux ou de cv void ; un programme est mal formé s'il instancie un optional avec un tel type. De plus, un programme est mal formé s'il instancie un optional avec les types d'étiquette (éventuellement qualifiés cv) std::nullopt_t ou std::in_place_t.

Paramètres de modèle

  • T — le type de la valeur dont on gère l'état d'initialisation. Le type doit satisfaire les exigences de Destructible (en particulier, les types tableau et référence ne sont pas autorisés).

Exemple

#include <iostream>
#include <optional>
#include <string>

// optional peut être utilisé comme type de retour d'une fabrique susceptible d'échouer
std::optional<std::string> create(bool b)
{
    if (b)
        return "Godzilla";
    return {};
}

// std::nullopt peut être utilisé pour créer n'importe quel std::optional (vide)
auto create2(bool b)
{
    return b ? std::optional<std::string>{"Godzilla"} : std::nullopt;
}

int main()
{
    std::cout << "create(false) returned "
              << create(false).value_or("empty") << '\n';

    // Les fonctions fabriques renvoyant optional peuvent être utilisées comme conditions de while et if
    if (auto str = create2(true))
        std::cout << "create2(true) returned " << *str << '\n';
}

Output:

create(false) returned empty
create2(true) returned Godzilla
