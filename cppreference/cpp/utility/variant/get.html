  1. Accesseur de valeur par indice : si v.index() == I, renvoie une référence vers la valeur stockée dans v. Sinon, lève std::bad_variant_access. L'appel est mal formé si I n'est pas un indice valide du variant.

  2. Accesseur de valeur par type : si v détient l'alternative T, renvoie une référence vers la valeur stockée dans v. Sinon, lève std::bad_variant_access. L'appel est mal formé si T n'est pas un élément unique de Types....

Paramètres de modèle

  • I — indice à rechercher
  • T — type unique à rechercher
  • Types... — types formant variant

Paramètres

  • v — a variant

Valeur de retour

Référence vers la valeur stockée dans le variant.

Exceptions

1,2) Lève std::bad_variant_access en cas d'erreur.

Exemple

#include <iostream>
#include <string>
#include <variant>

int main()
{
    std::variant<int, float> v{12}, w;
    std::cout << std::get<int>(v) << '\n';
    w = std::get<int>(v);
    w = std::get<0>(v); // même effet que la ligne précédente

//  std::get<double>(v); // erreur : aucun double dans [int, float]
//  std::get<3>(v);      // erreur : les indices valides sont 0 et 1

    try
    {
        w = 42.0f;
        std::cout << std::get<float>(w) << '\n'; // ok, affiche 42
        w = 42;
        std::cout << std::get<float>(w) << '\n'; // throws
    }
    catch (std::bad_variant_access const& ex)
    {
        std::cout << ex.what() << ": w contained int, not float\n";
    }
}
