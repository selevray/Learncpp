Construit un nouvel objet variant.

  1. Constructeur par défaut. Construit une variant contenant la valeur initialisée par valeur de la première alternative (index() vaut zéro).
  • Ce constructeur est constexpr si et seulement si l'initialisation par valeur du type d'alternative T_0 satisferait les exigences d'une fonction constexpr.
  • Cette surcharge ne participe à la résolution de surcharge que si std::is_default_constructible_v<T_0> est true.
  1. Constructeur de copie. Si other n'est pas valueless_by_exception, construit une variant contenant la même alternative que other et initialise directement la valeur contenue avec *std::get_if<other.index()>(std::addressof(other)). Sinon, initialise une variante valueless_by_exception.
  • Ce constructeur est défini comme supprimé sauf si std::is_copy_constructible_v<T_i> est true pour tout T_i dans Types....
  • Il est trivial si std::is_trivially_copy_constructible_v<T_i> est true pour tout T_i dans Types....
  1. Constructeur de déplacement. Si other n'est pas valueless_by_exception, construit une variant contenant la même alternative que other et initialise directement la valeur contenue avec std::move(*std::get_if<other.index()>(std::addressof(other))). Sinon, initialise une variante valueless_by_exception.
  • Cette surcharge participe à la résolution de surcharge uniquement si std::is_move_constructible_v<T_i> est true pour tout T_i dans Types....
  • Il est trivial si std::is_trivially_move_constructible_v<T_i> est true pour tout T_i dans Types....
  1. Constructeur de conversion. Construit une variant contenant le type d'alternative T_j qui serait sélectionné par la résolution de surcharge pour l'expression F(std::forward<T>(t)) s'il existait une surcharge de la fonction imaginaire F(T_i) pour chaque T_i dans Types..., sauf que les conversions restrictives ne sont pas prises en compte.

Formally:

  • Une surcharge F(T_i) n'est prise en compte que si la déclaration T_i x[] = { std::forward<T>(t) }; est valide pour une variable inventée x.

Initialise directement la valeur contenue comme par une initialisation directe sans liste à partir de std::forward<T>(t).

  • Cette surcharge ne participe à la résolution de surcharge que si
    • sizeof...(Types) > 0,
    • [std::decay_t<T> (jusqu'à C++20) | std::remove_cvref_t<T> (depuis C++20)] n'est ni le même type que variant, ni une spécialisation de std::in_place_type_t, ni une spécialisation de std::in_place_index_t,
    • std::is_constructible_v<T_j, T> is true,
    • et l'expression F(std::forward<T>(t)) (où F est l'ensemble ci-dessus de fonctions imaginaires) est bien formée.
  • Ce constructeur est un constructeur constexpr si le constructeur sélectionné de T_j est un constructeur constexpr.
std::variant<std::string> v("abc"); // OK
std::variant<std::string, std::string> w("abc"); // mal formé
std::variant<std::string, const char*> x("abc"); // OK, choisit const char*
std::variant<std::string, bool> y("abc"); // OK, choisit string ; bool n'est pas candidat
std::variant<float, long, double> z = 0; // OK, contient long
                                         // float et double ne sont pas candidats
  1. Construit une variant avec l'alternative spécifiée T et initialise la valeur contenue avec les arguments std::forward<Args>(args)....
  • Si le constructeur sélectionné de T est un constructeur constexpr, ce constructeur est également un constructeur constexpr.
  • Cette surcharge participe à la résolution de surcharge uniquement s'il existe exactement une occurrence de T dans Types... et que std::is_constructible_v<T, Args...> est true.
  1. Construit une variant avec l'alternative spécifiée T et initialise la valeur contenue avec les arguments il, std::forward<Args>(args)....
  • Si le constructeur sélectionné de T est un constructeur constexpr, ce constructeur est également un constructeur constexpr.
  • Cette surcharge participe à la résolution de surcharge uniquement s'il existe exactement une occurrence de T dans Types... et que std::is_constructible_v<T, initializer_list<U>&, Args...> est true.
  1. Construit une variant avec l'alternative T_i spécifiée par l'indice I et initialise la valeur contenue avec les arguments std::forward<Args>(args)....
  • Si le constructeur sélectionné de T_i est un constructeur constexpr, ce constructeur est également un constructeur constexpr.
  • Cette surcharge participe à la résolution de surcharge uniquement si I < sizeof...(Types) et std::is_constructible_v<T_i, Args...> est true.
  1. Construit une variant avec l'alternative T_i spécifiée par l'indice I et initialise la valeur contenue avec les arguments il, std::forward<Args>(args)....
  • Si le constructeur sélectionné de T_i est un constructeur constexpr, ce constructeur est également un constructeur constexpr.
  • Cette surcharge participe à la résolution de surcharge uniquement si I < sizeof...(Types) et std::is_constructible_v<T_i, std::initializer_list<U>&, Args...> est true.

Paramètres

  • other — un autre objet variant dont la valeur contenue doit être copiée/déplacée
  • t — valeur avec laquelle initialiser la valeur contenue
  • args... — arguments servant à initialiser la valeur contenue
  • il — liste d'initialisation servant à initialiser la valeur contenue

Exceptions

  1. Peut lever toute exception levée par l'initialisation par valeur de la première alternative.noexcept specification:noexcept(std::is_nothrow_default_constructible_v<T_0>)

  2. Peut lever toute exception levée par l'initialisation directe de n'importe quel T_i dans Types....

  3. Peut lever toute exception levée par le déplacement-construction de n'importe quel T_i dans Types....noexcept specification:noexcept((std::is_nothrow_move_constructible_v<Types> && ...))

  4. Peut lever toute exception levée par l'initialisation de l'alternative sélectionnée T_j.noexcept specification:noexcept(std::is_nothrow_constructible_v<T_j, T>)

5-8) Peut lever toute exception levée par l'appel du constructeur sélectionné de l'alternative sélectionnée.

Notes

MSVC STL a d'abord traité P0608R3 comme une modification de C++20. À partir de VS 2022 17.12, MSVC STL traite aussi P0608R3 comme un rapport de défaut contre C++17.

Exemple

#include <cassert>
#include <iostream>
#include <string>
#include <variant>
#include <vector>

using vector_t = std::vector<int>;

auto& operator<<(auto& out, const vector_t& v)
{
    out << "{ ";
    for (int e : v)
        out << e << ' ';
    return out << '}';
}

int main()
{
    // initialise par valeur la première alternative
    std::variant<int, std::string> var0;
    assert(std::holds_alternative<int>(var0) and
           var0.index() == 0 and
           std::get<int>(var0) == 0);

    // initialise la première alternative avec std::string{"STR"};
    std::variant<std::string, int> var1{"STR"};
    assert(var1.index() == 0);
    std::cout << "1) " << std::get<std::string>(var1) << '\n';

    // initialise la deuxième alternative avec int == 42;
    std::variant<std::string, int> var2{42};
    assert(std::holds_alternative<int>(var2));
    std::cout << "2) " << std::get<int>(var2) << '\n';

    // initialise la première alternative avec std::string{4, 'A'};
    std::variant<std::string, vector_t, float> var3
    {
        std::in_place_type<std::string>, 4, 'A'
    };
    assert(var3.index() == 0);
    std::cout << "3) " << std::get<std::string>(var3) << '\n';

    // initialise la deuxième alternative avec std::vector{1,2,3,4,5};
    std::variant<std::string, vector_t, char> var4
    {
        std::in_place_type<vector_t>, {1, 2, 3, 4, 5}
    };
    assert(var4.index() == 1);
    std::cout << "4) " << std::get<vector_t>(var4) << '\n';

    // initialise la première alternative avec std::string{"ABCDE", 3};
    std::variant<std::string, vector_t, bool> var5 {std::in_place_index<0>, "ABCDE", 3};
    assert(var5.index() == 0);
    std::cout << "5) " << std::get<std::string>(var5) << '\n';

    // initialise la deuxième alternative avec std::vector(4, 42);
    std::variant<std::string, vector_t, char> var6 {std::in_place_index<1>, 4, 42};
    assert(std::holds_alternative<vector_t>(var6));
    std::cout << "6) " << std::get<vector_t>(var6) << '\n';
}

Output:

1) STR
2) 42
3) AAAA
4) { 1 2 3 4 5 }
5) ABC
6) { 42 42 42 42 }

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 2901 C++17 constructeurs prenant en charge les allocateurs fournis mais variant ne peuvent pas correctement prendre en charge les allocateurs constructeurs supprimés
P0739R0 C++17 le modèle de constructeur de conversion interagit mal avec la déduction d'arguments de modèle de classe contrainte ajoutée
LWG 3024 C++17 le constructeur de copie ne participe pas à la résolution de surcharge si un type membre n'est pas copiable défini comme supprimé à la place
P0602R4 C++17 les constructeurs de copie/déplacement peuvent ne pas être triviaux même si les constructeurs sous-jacents sont triviaux requis pour propager la trivialité
P0608R3 C++17 le constructeur de conversion assemble aveuglément un ensemble de surcharges, conduisant à des conversions non voulues les conversions restrictives et booléennes ne sont pas prises en compte
P1957R2 C++17 le constructeur de conversion pour bool n'autorisait pas la conversion implicite La conversion de pointeur vers bool est restrictive et le constructeur de conversion n'a pas d' exception pour bool
