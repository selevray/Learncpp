std::variant<Types...>::index

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr std::size_t index() const noexcept;  // (depuis C++17)

Renvoie l'indice à partir de zéro de l'alternative actuellement détenue par le variant.

Si le variant est valueless_by_exception, renvoie variant_npos.

Exemple

#include <iostream>
#include <string>
#include <variant>

int main()
{
    std::variant<int, std::string> v = "abc";
    std::cout << "v.index = " << v.index() << '\n';
    v = {};
    std::cout << "v.index = " << v.index() << '\n';
}

Output:

v.index = 1
v.index = 0
