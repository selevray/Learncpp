std::bad_variant_access

Défini dans l'en-tête <variant>

class bad_variant_access : public std::exception  // (depuis C++17)

std::bad_variant_access est le type de l'exception levée dans les situations suivantes :

  • std::get(std::variant) appelé avec un indice ou un type ne correspondant pas à l'alternative actuellement active.
  • std::visit appelé pour visiter un variant qui est valueless_by_exception.
  • std::variant::visit appelé pour visiter un variant qui est valueless_by_exception.

(depuis C++26)

std::bad_variant_access::what

virtual const char* what() const noexcept;  // (depuis C++17)

Renvoie la chaîne explicative.

Valeur de retour

Pointeur vers une chaîne terminée par un caractère nul, définie par l'implémentation, contenant des informations explicatives. La chaîne convient à une conversion et à un affichage en tant que std::wstring. Le pointeur est garanti valide au moins jusqu'à la destruction de l'objet d'exception dont il est obtenu, ou jusqu'à l'appel d'une fonction membre non const (par ex. l'opérateur d'affectation par copie) sur cet objet d'exception.

La chaîne renvoyée est encodée avec le codage ordinaire des littéraux lors de l'évaluation constante.

(depuis C++26)

Notes

Les implémentations peuvent, sans y être obligées, redéfinir what().

Exemple

#include <iostream>
#include <variant>

int main()
{
    std::variant<int, float> v;
    v = 12;
    try
    {
        std::get<float>(v);
    }
    catch (const std::bad_variant_access& e)
    {
        std::cout << e.what() << '\n';
    }
}
