std::monostate

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <variant>

Défini dans l'en-tête <utility> (depuis C++26)

struct monostate { };  // (depuis C++17)

Type unitaire destiné à être utilisé comme alternative vide bien conçue dans std::variant. En particulier, une variante de types non constructibles par défaut peut lister std::monostate comme sa première alternative : cela rend la variante elle-même constructible par défaut.

Fonctions membres

  • (constructeur)(implicitly declared) — constructeur implicite trivial par défaut/copie/déplacement (fonction membre publique)
  • (destructeur)(implicitly declared) — destructeur implicite trivial (fonction membre publique)
  • operator=(implicitly declared) — affectation implicite triviale par copie/déplacement (fonction membre publique)

Fonctions non membres

std::operator==, !=, <, <=, >, >=, <=>(std::monostate)

constexpr bool operator==( monostate, monostate ) noexcept { return true; }  // (1) (depuis C++17)

constexpr bool operator!=( monostate, monostate ) noexcept { return false; }
constexpr bool operator< ( monostate, monostate ) noexcept { return false; }
constexpr bool operator> ( monostate, monostate ) noexcept { return false; }
constexpr bool operator<=( monostate, monostate ) noexcept { return true; }
constexpr bool operator>=( monostate, monostate ) noexcept { return true; }  // (depuis C++17) (jusqu'à C++20)

constexpr std::strong_ordering operator<=>( monostate, monostate ) noexcept
{
    return std::strong_ordering::equal;
}  // (depuis C++20)

Toutes les instances de std::monostate se comparent égales.

Les opérateurs <, <=, >, >= et != sont synthétisés à partir de operator<=> et operator== respectivement.

(depuis C++20)

Classes auxiliaires

std::hash<std::monostate>

template <>
struct std::hash<monostate>;  // (depuis C++17)

Spécialise l'algorithme std::hash pour std::monostate.

Exemple

#include <cassert>
#include <iostream>
#include <variant>

struct S
{
    S(int i) : i(i) {}
    int i;
};

int main()
{
    // Sans le type monostate, cette déclaration échouera.
    // En effet, S n'est pas constructible par défaut.
    std::variant<std::monostate, S> var;
    assert(var.index() == 0);

    try
    {
        std::get<S>(var); // lève une exception ! Nous devons affecter une valeur
    }
    catch(const std::bad_variant_access& e)
    {
        std::cout << e.what() << '\n';
    }

    var = 42;
    std::cout << "std::get: " << std::get<S>(var).i << '\n'
              << "std::hash: " << std::hex << std::showbase
              << std::hash<std::monostate>{}(std::monostate{}) << '\n';
}

Sortie possible :

std::get: wrong index for variant
std::get: 42
std::hash: 0xffffffffffffe19f
