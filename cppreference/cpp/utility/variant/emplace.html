std::variant<Types...>::emplace

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class T, class... Args >
T& emplace( Args&&... args );  // (1) (depuis C++17) (constexpr depuis C++20)

template< class T, class U, class... Args >
T& emplace( std::initializer_list<U> il, Args&&... args );  // (2) (depuis C++17) (constexpr depuis C++20)

template< std::size_t I, class... Args >
std::variant_alternative_t<I, variant>& emplace( Args&&... args );  // (3) (depuis C++17) (constexpr depuis C++20)

template< std::size_t I, class U, class... Args >
std::variant_alternative_t<I, variant>&
    emplace( std::initializer_list<U> il, Args&&... args );  // (4) (depuis C++17) (constexpr depuis C++20)

Crée une nouvelle valeur sur place, dans un objet variant existant

  1. Équivalent à emplace<I>(std::forward<Args>(args)...), où I est l'indice à partir de zéro de T dans Types....
  • Cette surcharge ne participe à la résolution de surcharge que si std::is_constructible_v<T, Args...> est true, et que T apparaît exactement une fois dans Types....
  1. Équivalent à emplace<I>(il, std::forward<Args>(args)...), où I est l'indice à partir de zéro de T dans Types....
  • Cette surcharge ne participe à la résolution de surcharge que si std::is_constructible_v<T, std::initializer_list<U>&, Args...> est true, et que T apparaît exactement une fois dans Types....
  1. Détruit d'abord la valeur actuellement contenue (le cas échéant). Puis initialise directement la valeur contenue comme si l'on construisait une valeur de type T_I avec les arguments std::forward<Args>(args).... Si une exception est levée, *this peut devenir valueless_by_exception.
  • Cette surcharge ne participe à la résolution de surcharge que si std::is_constructible_v<T_I, Args...> est true.
  • C'est une erreur de compilation si I n'est pas strictement inférieur à sizeof...(Types).
  1. Détruit d'abord la valeur actuellement contenue (le cas échéant). Puis initialise directement la valeur contenue comme si l'on construisait une valeur de type T_I avec les arguments il, std::forward<Args>(args).... Si une exception est levée, *this peut devenir valueless_by_exception.
  • Cette surcharge ne participe à la résolution de surcharge que si std::is_constructible_v<T_I, std::initializer_list<U>&, Args...> est true.
  • C'est une erreur de compilation si I n'est pas strictement inférieur à sizeof...(Types).

Paramètres

  • args — arguments du constructeur à utiliser lors de la construction de la nouvelle valeur
  • il — argument initializer_list à utiliser lors de la construction de la nouvelle valeur

Valeur de retour

Une référence vers la nouvelle valeur contenue.

Exceptions

1-4) Toute exception levée pendant l'initialisation de la valeur contenue.

Exemple

#include <iostream>
#include <string>
#include <variant>

int main()
{
    std::variant<std::string> v1;
    v1.emplace<0>("abc"); // OK
    std::cout << std::get<0>(v1) << '\n';
    v1.emplace<std::string>("def"); // OK
    std::cout << std::get<0>(v1) << '\n';

    std::variant<std::string, std::string> v2;
    v2.emplace<1>("ghi"); // OK
    std::cout << std::get<1>(v2) << '\n';
    // v2.emplace<std::string>("abc"); -> Error
}

Output:

abc
def
ghi
