std::variant<Types...>::valueless_by_exception

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr bool valueless_by_exception() const noexcept;  // (depuis C++17)

Renvoie false si et seulement si la variante contient une valeur.

Notes

Une variante peut devenir sans valeur lors de l'initialisation de la valeur contenue dans les situations suivantes :

  • (garanti) une exception est levée pendant une affectation par déplacement
  • (optionnel) une exception est levée pendant une affectation par copie
  • (optionnel) une exception est levée pendant une affectation changeant de type
  • (optionnel) une exception est levée pendant une emplace changeant de type

Comme variant n'est jamais autorisé à allouer de la mémoire dynamique, la valeur précédente ne peut pas être conservée et, par conséquent, restaurée dans ces situations. Les cas « optionnels » peuvent éviter de lever une exception si le type fournit des déplacements sans exception et si l'implémentation construit d'abord la nouvelle valeur sur la pile, puis la déplace dans la variante.

Cela s'applique même aux variantes de types non classes :

struct S
{
    operator int() { throw 42; }
};
std::variant<float, int> v{12.f}; // OK
v.emplace<1>(S()); // v peut être sans valeur

Une variante sans valeur à cause d'une exception — c'est-à-dire qui n'a pas de valeur à cause d'une exception précédente survenue dans l'une des situations listées ci-dessus — est considérée comme étant dans un état invalide :

  • index renvoie variant_npos
  • get lève bad_variant_access
  • visit et member-visit (depuis C++26) lèvent bad_variant_access

Exemple

#include <cassert>
#include <iostream>
#include <stdexcept>
#include <string>
#include <variant>

struct Demo
{
    Demo(int) {}
    Demo(const Demo&) { throw std::domain_error("copy ctor"); }
    Demo& operator= (const Demo&) = default;
};

int main()
{
    std::variant<std::string, Demo> var{"str"};
    assert(var.index() == 0);
    assert(std::get<0>(var) == "str");
    assert(var.valueless_by_exception() == false);

    try
    {
        var = Demo{555};
    }
    catch (const std::domain_error& ex)
    {
        std::cout << "1) Exception: " << ex.what() << '\n';
    }
    assert(var.index() == std::variant_npos);
    assert(var.valueless_by_exception() == true);

    // Maintenant var est « sans valeur », un état invalide causé
    // par une exception levée lors de l'affectation changeant de type.

    try
    {
        std::get<1>(var);
    }
    catch (const std::bad_variant_access& ex)
    {
        std::cout << "2) Exception: " << ex.what() << '\n';
    }

    var = "str2";
    assert(var.index() == 0);
    assert(std::get<0>(var) == "str2");
    assert(var.valueless_by_exception() == false);
}

Sortie possible :

1) Exception: copy ctor
2) Exception: std::get: variant is valueless
