std::variant_npos

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <variant>

inline constexpr std::size_t variant_npos = -1;  // (depuis C++17)

Il s'agit d'une valeur spéciale égale à la plus grande valeur représentable par le type std::size_t, utilisée comme valeur de retour de index() lorsque valueless_by_exception() vaut true.

#include <iostream>
#include <stdexcept>
#include <string>
#include <variant>

struct Demon
{
    Demon(int) {}
    Demon(const Demon&) { throw std::domain_error("copy ctor"); }
    Demon& operator= (const Demon&) = default;
};

int main()
{
    std::variant<int, Demon> var{42};
    std::cout
        << std::boolalpha
        << "index == npos: " << (var.index() == std::variant_npos) << '\n';

    try { var = Demon{666}; } catch (const std::domain_error& ex)
    {
        std::cout
            << "Exception: " << ex.what() << '\n'
            << "index == npos: " << (var.index() == std::variant_npos) << '\n'
            << "valueless: " << var.valueless_by_exception() << '\n';
    }
}

Sortie possible :

index == npos: false
Exception: copy ctor
index == npos: true
valueless: true
