std::holds_alternative

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <variant>

template< class T, class... Types >
constexpr bool holds_alternative( const std::variant<Types...>& v ) noexcept;  // (depuis C++17)

Vérifie si le variant v détient l'alternative T. L'appel est mal formé si T n'apparaît pas exactement une fois dans Types...

Paramètres

  • v — variant à examiner

Valeur de retour

true si le variant détient actuellement l'alternative T, false sinon.

Exemple

#include <cassert>
#include <string>
#include <variant>

int main()
{
    std::variant<int, std::string> v = "abc";
    assert(not std::holds_alternative<int>(v));
    assert(std::holds_alternative<std::string>(v));
}
