std::variant<Types...>::visit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class Self, class Visitor >
constexpr decltype(auto) visit( this Self&& self, Visitor&& vis );  // (1) (depuis C++26)

template< class R, class Self, class Visitor >
constexpr R visit( this Self&& self, Visitor&& vis );  // (2) (depuis C++26)

Applique le visiteur vis (un Callable pouvant être appelé avec n'importe quelle combinaison de types de la variante) à la variante détenue par self.

Étant donné le type V en tant que decltype(std::forward_like<Self>(std::declval<variant>())), l'appel équivalent est :

  1. return std::visit(std::forward<Visitor>(vis), (V) self);.

  2. return std::visit<R>(std::forward<Visitor>(vis), (V) self);.

Paramètres

  • vis — un Callable acceptant toutes les alternatives possibles de la variante
  • self — variante à passer au visiteur

Valeur de retour

  1. Le résultat de l'invocation de std::visit.

  2. Rien si R est void (éventuellement qualifié cv) ; sinon le résultat de l'invocation de std::visit<R>.

Exceptions

Ne lève une exception que si l'appel à std::visit lève une exception.

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_variant 202306L (C++26) membre visit

Exemple

#include <print>
#include <string>
#include <string_view>
#include <variant>

struct Base {};
struct Derived : Base {};

// type auxiliaire pour le visiteur
template<class... Ts>
struct overloads : Ts... { using Ts::operator()...; };

// la variante à visiter
using var_t = std::variant<int, std::string, Derived>;

int main()
{
    const auto visitor = overloads
    {
        [](int i){ std::print("int = {}\n", i); },
        [](std::string_view s){ std::println("string = “{}”", s); },
        [](const Base&){ std::println("base"); }
    };

    const var_t var1 = 42, var2 = "abc", var3 = Derived();

#if (__cpp_lib_variant >= 202306L)
    var1.visit(visitor);
    var2.visit(visitor);
    var3.visit(visitor);
#else
    std::visit(visitor, var1);
    std::visit(visitor, var2);
    std::visit(visitor, var3);
#endif
}

Output:

int = 42
string = “abc”
base
