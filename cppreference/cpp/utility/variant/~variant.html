std::variant<Types...>::~variant

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

~variant();  // (depuis C++17) (constexpr depuis C++20)

Si valueless_by_exception() est true, ne fait rien. Sinon, détruit l'objet actuellement contenu.

Ce destructeur est trivial si std::is_trivially_destructible_v<T_i> est true pour tous les T_i de Types....

Exemple

#include <cstdio>
#include <variant>

int main()
{
    struct X { ~X() { puts("X::~X();"); } };
    struct Y { ~Y() { puts("Y::~Y();"); } };

    {
        puts("entering block #1");
        std::variant<X,Y> var;
        puts("leaving block #1");
    }

    {
        puts("entering block #2");
        std::variant<X,Y> var{ std::in_place_index_t<1>{} }; // construit var(Y)
        puts("leaving block #2");
    }
}

Output:

entering block #1
leaving block #1
X::~X();
entering block #2
leaving block #2
Y::~Y();
