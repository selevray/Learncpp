std::variant_alternative, std::variant_alternative_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <variant>

template <std::size_t I, class T>
struct variant_alternative; /* undefined */  // (1) (depuis C++17)

template <std::size_t I, class... Types>
struct variant_alternative<I, variant<Types...>>;  // (2) (depuis C++17)

template <std::size_t I, class T> class variant_alternative<I, const T>;  // (3) (depuis C++17)

template <std::size_t I, class T>
class variant_alternative<I, volatile T>;
template <std::size_t I, class T>
class variant_alternative<I, const volatile T>;  // (3) (depuis C++17) (obsolète en C++20)

Fournit un accès indexé à la compilation aux types des alternatives de la variante éventuellement qualifiée cv, en combinant les qualificateurs cv de la variante (le cas échéant) avec ceux de l'alternative.

Formellement,

  1. satisfait aux exigences TransformationTrait avec un typedef membre type égal au type de l'alternative d'indice I

  2. satisfait aux exigences TransformationTrait avec un typedef membre type qui désigne respectivement std::add_const_t<std::variant_alternative_t<I,T>>, std::add_volatile_t<std::variant_alternative_t<I,T>> et std::add_cv_t<std::variant_alternative_t<I,T>>

Types membres

Type membre Définition

  • type — le type de la Ie alternative de la variante, où I doit appartenir à [0, sizeof...(Types)), sinon le programme est mal formé.

Alias de modèle auxiliaire

template <size_t I, class T>
using variant_alternative_t = typename variant_alternative<I, T>::type;  // (depuis C++17)

Exemple

#include <variant>
#include <iostream>

using my_variant = std::variant<int, float>;
static_assert(std::is_same_v
    <int,   std::variant_alternative_t<0, my_variant>>);
static_assert(std::is_same_v
    <float, std::variant_alternative_t<1, my_variant>>);
// Le qualificateur cv du type variante se propage au type d'alternative extrait.
static_assert(std::is_same_v
    <const int, std::variant_alternative_t<0, const my_variant>>);

int main()
{
    std::cout << "All static assertions passed.\n";
}

Output:

All static assertions passed.
