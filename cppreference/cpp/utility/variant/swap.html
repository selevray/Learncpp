std::variant<Types...>::swap

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void swap( variant& rhs ) noexcept(/* voir ci-dessous */);  // (depuis C++17) (constexpr depuis C++20)

Échange deux objets variant.

  • Si *this et rhs sont tous deux sans valeur par exception, ne fait rien.
  • Sinon, si *this et rhs contiennent la même alternative, appelle swap(*std::get_if<i>(this), *std::get_if<i>(std::addressof(rhs))) où i est index(). Si une exception est levée, l'état des valeurs dépend de la sûreté d'exception de la fonction swap appelée.
  • Sinon, échange les valeurs de rhs et *this. Si une exception est levée, l'état de *this et rhs dépend de la sûreté d'exception du constructeur de déplacement de la variante.

Le programme est mal formé à moins que les types T_i ne soient Swappable et que std::is_move_constructible_v<T_i> soit true pour tout T_i dans Types....

Paramètres

  • rhs — un objet variant avec lequel échanger

Valeur de retour

(aucune)

Exceptions

Si this->index() == rhs.index(), peut lever toute exception levée par swap(*std::get_if<i>(this), *std::get_if<i>(std::addressof(rhs))) avec i étant index().

Sinon, peut lever toute exception levée par les constructeurs de déplacement des alternatives actuellement contenues dans *this et rhs.

noexcept specification:noexcept(((std::is_nothrow_move_constructible_v<Types> && std::is_nothrow_swappable_v<Types>) && ...))

Exemple

#include <iostream>
#include <string>
#include <variant>

int main()
{
    std::variant<int, std::string> v1{2}, v2{"abc"};
    std::visit([](auto&& x) { std::cout << x << ' '; }, v1);
    std::visit([](auto&& x) { std::cout << x << '\n'; }, v2);
    v1.swap(v2);
    std::visit([](auto&& x) { std::cout << x << ' '; }, v1);
    std::visit([](auto&& x) { std::cout << x << '\n'; }, v2);
}

Output:

2 abc
abc 2
