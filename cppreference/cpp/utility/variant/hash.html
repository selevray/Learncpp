std::hash<std::variant>

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <variant>

template< class... Types >
struct hash<std::variant<Types...>>;  // (depuis C++17)

La spécialisation de modèle de std::hash pour le modèle std::variant permet d'obtenir les hachages d'objets variant.

La spécialisation std::hash<std::variant<Types...>> est activée (voir std::hash) si chaque spécialisation dans std::hash<std::remove_const_t<Types>>... est activée, et désactivée sinon.

Les fonctions membres de cette spécialisation ne sont pas garanties noexcept.

Paramètres de modèle

  • Types — les types des alternatives prises en charge par l'objet variant

Notes

Contrairement à std::hash<std::optional>, le hachage d'un variant n'est en général pas égal au hachage de la valeur contenue ; cela permet de distinguer des std::variant<int, int> détenant la même valeur comme des alternatives différentes.

Exemple

#include <iostream>
#include <string>
#include <variant>

using Var = std::variant<int, int, int, std::string>;

template<unsigned I>
void print(Var const& var)
{
    std::cout << "get<" << var.index() << "> = "
              << std::get<I>(var)
              << "\t" "# = "
              << std::hash<Var>{}(var) << '\n';
}

int main()
{
    Var var;
    std::get<0>(var) = 2020;
    print<0>(var);
    var.emplace<1>(2023);
    print<1>(var);
    var.emplace<2>(2026);
    print<2>(var);
    var = "C++";
    print<3>(var);
}

Sortie possible :

get<0> = 2020   # = 2020
get<1> = 2023   # = 2024
get<2> = 2026   # = 2028
get<3> = C++    # = 15518724754199266859
