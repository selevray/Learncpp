std::nontype, std::nontype_t

Défini dans l'en-tête <utility>

template< auto V >
struct nontype_t { explicit nontype_t() = default; };  // (1) (depuis C++26)

template< auto V >
constexpr std::nontype_t<V> nontype {};  // (2) (depuis C++26)

  1. Le modèle de classe std::nontype_t peut être utilisé dans la liste des paramètres du constructeur pour correspondre à l'étiquette prévue.

  2. L'instance std::nontype correspondante de (1) est un argument d'étiquette de désambiguïsation qui peut être passé aux constructeurs de std::function_ref pour indiquer que l'objet contenu doit être construit avec la valeur du paramètre de modèle non-type V.

Paramètres de modèle

  • V — paramètre de modèle non-type d'un type structurel.
