std::breakpoint_if_debugging

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <debugging>

void breakpoint_if_debugging() noexcept;  // (depuis C++26)

Point d'arrêt conditionnel : tente d'interrompre temporairement l'exécution du programme et de transférer le contrôle au débogueur s'il est capable de déterminer que celui-ci est présent. Sans effet sinon.

Formellement, le comportement de cette fonction est entièrement défini par l'implémentation. Équivalent à if (std::is_debugger_present()) std::breakpoint();.
