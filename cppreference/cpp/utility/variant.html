std::variant

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <variant>

template< class... Types >
class variant;  // (depuis C++17)

Le modèle de classe std::variant représente une union sûre vis-à-vis des types. Une instance de std::variant contient à tout moment soit une valeur de l'un de ses types alternatifs, soit, en cas d'erreur, aucune valeur (cet état est difficile à atteindre, voir valueless_by_exception).

Comme pour les unions, si un variant contient une valeur d'un certain type objet T, l'objet T est imbriqué dans l'objet variant lui-même. Un variant ne peut pas allouer de mémoire (dynamique) supplémentaire.

Un variant ne peut pas contenir de références, de tableaux, ni le type void.

Un variant peut contenir plusieurs fois le même type, et contenir des versions du même type qualifiées cv différemment.

Conformément au comportement des unions lors de l'initialisation d'agrégat, un variant construit par défaut contient une valeur de sa première alternative, sauf si cette alternative n'est pas constructible par défaut (auquel cas le variant n'est pas non plus constructible par défaut). La classe auxiliaire std::monostate peut être utilisée pour rendre de tels variants constructibles par défaut.

Un programme qui instancie la définition de std::variant sans arguments de modèle est mal formé. std::variant<std::monostate> peut être utilisé à la place.

Si un programme déclare une spécialisation explicite ou partielle de std::variant, le programme est mal formé, aucun diagnostic requis.

Paramètres de modèle

  • Types — les types pouvant être stockés dans ce variant. Tous les types doivent satisfaire aux exigences Destructible (en particulier, les types tableau et les types non objet ne sont pas autorisés).

Exemple

#include <cassert>
#include <iostream>
#include <string>
#include <variant>

int main()
{
    std::variant<int, float> v, w;
    v = 42; // v contient un int
    int i = std::get<int>(v);
    assert(42 == i); // succeeds
    w = std::get<int>(v);
    w = std::get<0>(v); // même effet que la ligne précédente
    w = v; // même effet que la ligne précédente

//  std::get<double>(v); // erreur : aucun double dans [int, float]
//  std::get<3>(v);      // erreur : les indices valides sont 0 et 1

    try
    {
        std::get<float>(w); // w contient un int, et non un float : lèvera une exception
    }
    catch (const std::bad_variant_access& ex)
    {
        std::cout << ex.what() << '\n';
    }

    using namespace std::literals;

    std::variant<std::string> x("abc");
    // les constructeurs de conversion fonctionnent lorsqu'ils ne sont pas ambigus
    x = "def"; // l'affectation avec conversion fonctionne aussi lorsqu'elle n'est pas ambiguë

    std::variant<std::string, void const*> y("abc");
    // conversions vers void const* lorsqu'un char const* est passé
    assert(std::holds_alternative<void const*>(y)); // succeeds
    y = "xyz"s;
    assert(std::holds_alternative<std::string>(y)); // succeeds
}
