std::initializer_list

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

(à ne pas confondre avec la liste d'initialisation de membres)

Défini dans l'en-tête <initializer_list>

template< class T >
class initializer_list;  // (depuis C++11)

Un objet de type std::initializer_list<T> est un objet mandataire léger qui donne accès à un tableau d'objets de type const T (pouvant être alloué en mémoire en lecture seule).

Un objet std::initializer_list est automatiquement construit lorsque :

  • une liste d'initialisation entre accolades est utilisée pour initialiser par liste un objet, lorsque le constructeur correspondant accepte un paramètre std::initializer_list,
  • une liste d'initialisation entre accolades est utilisée comme opérande de droite d'une affectation ou comme argument d'appel de fonction, et que l'opérateur ou la fonction d'affectation correspondant accepte un paramètre std::initializer_list,
  • une liste d'initialisation entre accolades est liée à auto, y compris dans une boucle for basée sur un intervalle.

std::initializer_list peut être implémenté comme une paire de pointeurs ou un pointeur et une longueur. La copie d'un std::initializer_list ne copie pas le tableau de support de la liste d'initialisation correspondante.

Le programme est mal formé si une spécialisation explicite ou partielle de std::initializer_list est déclarée.

Fonctions membres

  • (constructeur) — crée une liste d'initialisation vide (fonction membre publique)

##### Capacité {#Capacity}

  • size — retourne le nombre d'éléments de la liste d'initialisation (fonction membre publique)

##### Itérateurs {#Iterators}

  • begin — renvoie un pointeur vers le premier élément (fonction membre publique)
  • end — renvoie un pointeur vers un élément après le dernier (fonction membre publique)

Fonctions non membres

  • std::begin(std::initializer_list) (C++11) — surcharges std::begin (modèle de fonction)
  • std::end(std::initializer_list) (C++11) — spécialise std::end (modèle de fonction)

##### Modèles de fonctions libres surchargés pour std::initializer_list {#Free_function_templates_overloaded_for_std::initializer_list}

  • rbegincrbegin (C++14) — renvoie un itérateur inverse vers le début d'un conteneur ou d'un tableau (modèle de fonction)
  • rendcrend (C++14) — renvoie un itérateur inverse de fin pour un conteneur ou un tableau (modèle de fonction)
  • empty (C++17) — vérifie si le conteneur est vide (modèle de fonction)
  • data (C++17) — obtient le pointeur vers le tableau sous-jacent (modèle de fonction)

Exemple

#include <cassert>
#include <initializer_list>
#include <iostream>
#include <vector>

template<class T>
struct S
{
    std::vector<T> v;

    S(std::initializer_list<T> l) : v(l)
    {
         std::cout << "constructed with a " << l.size() << "-element list\n";
    }

    void append(std::initializer_list<T> l)
    {
        v.insert(v.end(), l.begin(), l.end());
    }

    std::pair<const T*, std::size_t> c_arr() const
    {
        return {&v[0], v.size()}; // initialisation par liste par copie dans une instruction return
                                  // ceci n'est PAS une utilisation de std::initializer_list
    }
};

template<typename T>
void templated_fn(T) {}

int main()
{
    S<int> s = {1, 2, 3, 4, 5}; // initialisation par liste par copie
    s.append({6, 7, 8});        // initialisation par liste dans un appel de fonction

    std::cout << "The vector now has " << s.c_arr().second << " ints:\n";
    for (auto n : s.v)
        std::cout << n << ' ';
    std::cout << '\n';

    std::cout << "Range-for over brace-init-list: \n";
    for (int x : {-1, -2, -3}) // la règle pour auto rend cette boucle basée sur intervalle possible
        std::cout << x << ' ';
    std::cout << '\n';

    auto al = {10, 11, 12}; // règle spéciale pour auto
    std::cout << "The list bound to auto has size() = " << al.size() << '\n';
    auto la = al; // une copie superficielle de l'objet proxy de premier niveau
    assert(la.begin() == al.begin()); // garanti : le tableau de support est le même

    std::initializer_list<int> il{-3, -2, -1};
    assert(il.begin()[2] == -1); // notez le remplacement de l'absence d'operator[]
    il = al; // copie superficielle
    assert(il.begin() == al.begin()); // guaranteed

//  templated_fn({1, 2, 3}); // erreur du compilateur ! "{1, 2, 3}" n'est pas une expression,
                             // elle n'a pas de type, et donc T ne peut pas être déduit
    templated_fn<std::initializer_list<int>>({1, 2, 3}); // OK
    templated_fn<std::vector<int>>({1, 2, 3});           // aussi OK
}

Output:

constructed with a 5-element list
The vector now has 8 ints:
1 2 3 4 5 6 7 8
Range-for over brace-init-list:
-1 -2 -3
The list bound to auto has size() = 3
