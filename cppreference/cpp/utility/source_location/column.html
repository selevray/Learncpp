std::source_location::column

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr std::uint_least32_t column() const noexcept;  // (depuis C++20)

Renvoie une valeur définie par l'implémentation représentant un décalage depuis le début de la ligne représentée par cet objet (c'est-à-dire le numéro de colonne). Les numéros de colonne sont supposés commencer à 1.

Paramètres

(aucune)

Valeur de retour

Valeur définie par l'implémentation représentant un décalage par rapport au début de la ligne représentée par cet objet (c'est-à-dire le numéro de colonne).

Une implémentation est encouragée à utiliser 0 lorsque le numéro de colonne est inconnu.

Exemple

#include <iostream>
#include <source_location>

template<typename T = std::source_location>
inline void pos(const T& location = T::current())
{
    std::cout
        << "("
        << location.line()
        << ':'
        << location.column()
        << ") ";
}

int main()
{
//      ↓: column #9
    pos(); std::cout << "Proxima\n";    // row #18
      pos(); std::cout << "Centauri\n"; // row #19
//        ↑: column #11
}

Sortie possible :

(18:9) Proxima
(19:11) Centauri
