std::source_location::function_name

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr const char* function_name() const noexcept;  // (depuis C++20)

Renvoie le nom de la fonction associée à la position représentée par cet objet, le cas échéant.

Paramètres

(aucune)

Valeur de retour

Si cet objet représente une position dans le corps d'une fonction, renvoie une chaîne d'octets terminée par un caractère nul, définie par l'implémentation, correspondant au nom de la fonction.

Sinon, une chaîne vide est renvoyée.

Exemple

std::source_location::function_name peut aider à obtenir les noms des fonctions (y compris les fonctions spéciales) ainsi que leurs signatures.

#include <cstdio>
#include <utility>
#include <source_location>

inline void print_function_name(
    const std::source_location& location = std::source_location::current())
{
    std::puts(location.function_name()); // affiche le nom de l'appelant
}

void foo(double &&) { print_function_name(); }

namespace bar { void baz() { print_function_name(); } }

template <typename T> auto pub(T) { print_function_name(); return 42; }

struct S {
    S() { print_function_name(); }
    S(int) { print_function_name(); }
    ~S() { print_function_name(); }
    S& operator=(S const&) { print_function_name(); return *this; }
    S& operator=(S&&) { print_function_name(); return *this; }
};

int main(int, char const* const[])
{
    print_function_name();
    foo(3.14);
    bar::baz();
    pub(0xFULL);
    S p;
    S q{42};
    p = q;
    p = std::move(q);
    [] { print_function_name(); }();
}
