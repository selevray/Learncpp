Renvoie un itérateur vers la première entrée du basic_stacktrace.

Si le basic_stacktrace est vide, l'itérateur renvoyé est égal à end().

range-begin-end.svg

Paramètres

(aucune)

Valeur de retour

Itérateur vers la première entrée.

Complexité

Constante.

Exemple

#include <algorithm>
#include <iostream>
#include <stacktrace>

int main()
{
    auto trace       = std::stacktrace::current();
    auto empty_trace = std::stacktrace{};

    // Affiche la trace d'appels.
    std::for_each(trace.begin(), trace.end(),
                  [](const auto& f) { std::cout << f << '\n'; });

    if (empty_trace.begin() == empty_trace.end())
        std::cout << "stacktrace 'empty_trace' is indeed empty.\n";
}
