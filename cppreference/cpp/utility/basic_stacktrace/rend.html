std::basic_stacktrace<Allocator>::rend, std::basic_stacktrace<Allocator>::crend

const_reverse_iterator rend()  const noexcept;  // (1) (depuis C++23)

const_reverse_iterator crend() const noexcept;  // (2) (depuis C++23)

Renvoie un itérateur inverse pointant au-delà de la dernière entrée du basic_stacktrace inversé. Il correspond à l'itérateur précédant la première entrée du basic_stacktrace d'origine. Cet itérateur sert de marqueur ; tenter de le déréférencer entraîne un comportement indéfini.

range-rbegin-rend.svg

Paramètres

(aucune)

Valeur de retour

L'itérateur de fin du basic_stacktrace inversé.

Complexité

Constante.

Exemple

#include <algorithm>
#include <iostream>
#include <stacktrace>

int main()
{
    auto trace       = std::stacktrace::current();
    auto empty_trace = std::stacktrace{};

    // Affiche la trace d'appels.
    std::for_each(trace.rbegin(), trace.rend(),
                  [](const auto& f) { std::cout << f << '\n'; });

    if (empty_trace.rbegin() == empty_trace.rend())
        std::cout << "stacktrace 'empty_trace' is indeed empty.\n";
}
