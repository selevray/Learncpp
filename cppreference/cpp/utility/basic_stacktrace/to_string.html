Défini dans l'en-tête <stacktrace>

template< class Allocator >
std::string to_string( const std::basic_stacktrace<Allocator>& st );  // (depuis C++23)

Renvoie une chaîne de caractères contenant une description de st.

La description d'un basic_stacktrace contient généralement la description de ses entrées, bien que le nombre de lignes ne doive pas nécessairement être égal à size().

Paramètres

  • st — un basic_stacktrace dont la description doit être renvoyée

Valeur de retour

Une chaîne de caractères contenant une description de st.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Notes

La prise en charge d'allocateurs personnalisés n'est pas fournie pour cette fonction, car les implémentations nécessitent généralement des allocations spécifiques à la plateforme, des appels système et un travail intensif en calcul, alors qu'un allocateur personnalisé n'apporte aucun avantage pour cette fonction, les opérations spécifiques à la plateforme prenant un ordre de grandeur de temps de plus que l'allocation.

Exemple

#include <stacktrace>
#include <string>
#include <iostream>

int main()
{
    auto trace = std::stacktrace::current();
    std::cout << std::to_string(trace) << '\n';
}
