std::basic_stacktrace<Allocator>::rbegin, std::basic_stacktrace<Allocator>::crbegin

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

const_reverse_iterator rbegin()  const noexcept;  // (1) (depuis C++23)

const_reverse_iterator crbegin() const noexcept;  // (2) (depuis C++23)

Renvoie un itérateur inverse vers la première entrée du basic_stacktrace inversé. Il correspond à la dernière entrée du basic_stacktrace d'origine. Si le basic_stacktrace est vide, l'itérateur renvoyé est égal à rend().

range-rbegin-rend.svg

Paramètres

(aucune)

Valeur de retour

Itérateur inverse vers la première entrée.

Complexité

Constante.

Exemple

#include <algorithm>
#include <iostream>
#include <stacktrace>

int main()
{
    auto trace       = std::stacktrace::current();
    auto empty_trace = std::stacktrace{};

    // Affiche la trace d'appels.
    std::for_each(trace.rbegin(), trace.rend(),
                  [](const auto& f) { std::cout << f << '\n'; });

    if (empty_trace.rbegin() == empty_trace.rend())
        std::cout << "stacktrace 'empty_trace' is indeed empty.\n";
}
