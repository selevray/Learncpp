                                     allocator_type() ) noexcept;  // (3) (depuis C++23)

Soit s[i] (0 ≤ i < n) désignant la (i+1)-ième entrée de la trace d'appels de l'évaluation courante dans le fil d'exécution courant, où n est le nombre d'entrées de la trace d'appels dans la stackentry.

  1. Tente de créer un basic_stacktrace composé de s[0], s[1], ..., s[n - 1].

  2. Tente de créer un basic_stacktrace composé de s[m], s[m + 1], ..., s[n - 1], où m vaut min(skip, n).

  3. Tente de créer un basic_stacktrace composé de s[m], s[m + 1], ..., s[o - 1], où m vaut min(skip, n) et o vaut min(skip + max_depth, n). Le comportement est indéfini si le skip + max_depth < skip (c'est-à-dire le résultat mathématique de skip + max_depth) déborde.

Dans tous les cas, alloc est stocké dans le basic_stacktrace créé et utilisé pour allouer le stockage des entrées de la trace d'appels.

Paramètres

  • alloc — allocateur à utiliser pour toutes les allocations mémoire du basic_stacktrace construit
  • skip — le nombre d'entrées de la trace d'appels à ignorer
  • max_depth — la profondeur maximale des entrées de la trace d'appels

Valeur de retour

Si l'allocation réussit, le basic_stacktrace décrit ci-dessus.

Sinon, un basic_stacktrace vide.
