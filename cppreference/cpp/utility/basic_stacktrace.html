La séquence d'invocation de l'évaluation courante (\small{ {x}{0} })x0 dans le fil d'exécution courant est une séquence (\small{ ({x}{0}, \dots, {x}{n})})(x0, ..., xn) d'évaluations telle que, pour (\small{i \ge 0})i≥0, (\small{ {x}{i} })xi est dans l'invocation de fonction (\small{ {x}_{i+1} })xi+1.

Une trace d'appels est une représentation approximative d'une séquence d'invocation et se compose d'entrées de trace d'appels.

Une entrée de trace d'appels représente une évaluation dans une trace d'appels. Elle est représentée par std::stacktrace_entry dans la bibliothèque standard C++.

Paramètres de modèle

  • Allocator — Un allocateur utilisé pour acquérir/libérer de la mémoire et pour construire/détruire les éléments dans cette mémoire. Le type doit satisfaire aux exigences de Allocator. Le programme est mal formé si Allocator::value_type n'est pas std::stacktrace_entry.

Notes

La prise en charge d'allocateurs personnalisés est fournie pour utiliser basic_stacktrace sur un chemin critique ou dans des environnements embarqués. Les utilisateurs peuvent allouer des objets stacktrace_entry sur la pile ou à un autre emplacement approprié.

La séquence d'objets std::stacktrace_entry détenus par un std::basic_stacktrace est immuable, et soit elle est vide, soit elle représente un intervalle contigu de la trace d'appels complète.

boost::stacktrace::basic_stacktrace (disponible dans Boost.Stacktrace) peut être utilisé à la place lorsque std::basic_stacktrace n'est pas disponible.

Exemple

La sortie obtenue avec Compiler Explorer : msvc et gcc.

#include <iostream>
#include <stacktrace>

int nested_func(int c)
{
    std::cout << std::stacktrace::current() << '\n';
    return c + 1;
}

int func(int b)
{
    return nested_func(b + 1);
}

int main()
{
    std::cout << func(777);
}
