std::forward_as_tuple

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <tuple>

template< class... Types >
std::tuple<Types&&...> forward_as_tuple( Types&&... args ) noexcept;  // (depuis C++11) (constexpr depuis C++14)

Construit un tuple de références vers les arguments de args, adapté à leur transmission comme arguments d'une fonction. Le tuple a des membres de données de type référence rvalue lorsque des rvalues sont utilisées comme arguments, et des membres de données de type référence lvalue sinon.

Paramètres

  • args — zéro ou plusieurs arguments à partir desquels construire le tuple

Valeur de retour

Un objet std::tuple créé comme si par std::tuple<Types&&...>(std::forward<Types>(args)...)

Notes

Si les arguments sont des temporaires, forward_as_tuple ne prolonge pas leur durée de vie ; ils doivent être utilisés avant la fin de l'expression complète.

Exemple

#include <iostream>
#include <map>
#include <string>
#include <tuple>

int main()
{
    std::map<int, std::string> m;

    m.emplace(std::piecewise_construct,
              std::forward_as_tuple(6),
              std::forward_as_tuple(9, 'g'));
    std::cout << "m[6] = " << m[6] << '\n';

    // Ce qui suit est une erreur : elle produit un
    // std::tuple<int&&, char&&> contenant deux références pendantes.
    //
    // auto t = std::forward_as_tuple(20, 'a');
    // m.emplace(std::piecewise_construct, std::forward_as_tuple(10), t);
}

Output:

m[6] = ggggggggg
