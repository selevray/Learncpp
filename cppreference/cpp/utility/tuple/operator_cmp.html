1,2) Compare chaque élément du tuple lhs avec l'élément correspondant du tuple rhs au moyen de operator==.

  1. Renvoie true si toutes les paires d'éléments correspondants sont égales.

  2. Renvoie !(lhs == rhs).

Si sizeof...(TTypes) n'est pas égal à sizeof...(UTypes), ou si std::get<i>(lhs) == std::get<i>(rhs) n'est pas une expression valide pour un i quelconque dans [0,sizeof...(Types)), le programme est mal formé.

Si le type et la catégorie de valeur de std::get<i>(lhs) == std::get<i>(rhs) ne satisfont pas aux exigences BooleanTestable pour un i quelconque dans [0,sizeof...(Types)), le comportement est indéfini.

(jusqu'à C++26)

Cette surcharge ne participe à la résolution de surcharge que si sizeof...(TTypes) est égal à sizeof...(UTypes), si std::get<i>(lhs) == std::get<i>(rhs) est une expression valide et si decltype(std::get<i>(lhs) == std::get<i>(rhs)) modélise boolean-testable pour chaque i dans [0,sizeof...(Types)).

(depuis C++26)

3-6) Compare lhs et rhs lexicographiquement au moyen de operator<, c'est-à-dire qu'il compare les premiers éléments ; s'ils sont équivalents, il compare les seconds éléments ; s'ils sont équivalents, il compare les troisièmes, et ainsi de suite.

  1. Pour des tuples vides, renvoie false. Pour des tuples non vides, l'effet est équivalent à
    if (std::get<0>(lhs) < std::get<0>(rhs)) return true; if (std::get<0>(rhs) < std::get<0>(lhs)) return false; if (std::get<1>(lhs) < std::get<1>(rhs)) return true; if (std::get<1>(rhs) < std::get<1>(lhs)) return false; ... return std::get<N - 1>(lhs) < std::get<N - 1>(rhs);

  2. Renvoie !(rhs < lhs).

  3. Renvoie rhs < lhs.

  4. Renvoie !(lhs < rhs).

Si sizeof...(TTypes) n'est pas égal à sizeof...(UTypes), ou si l'une des expressions de comparaison présentées dans les instructions d'équivalence n'est pas une expression valide, le programme est mal formé.

Si le type et la catégorie de valeur de l'une des expressions de comparaison présentées dans les instructions d'équivalence ne satisfont pas aux exigences BooleanTestable, le comportement est indéfini.

  1. Compare lhs et rhs lexicographiquement au moyen de synth-three-way, c'est-à-dire qu'il compare les premiers éléments ; s'ils sont équivalents, il compare les seconds éléments ; s'ils sont équivalents, il compare les troisièmes, et ainsi de suite.
  • Pour des tuples vides, renvoie std::strong_ordering::equal.
  • Pour des tuples non vides, l'effet est équivalent à

if (auto c = synth-three-way(std::get<0>(lhs), std::get<0>(rhs)); c != 0) return c; if (auto c = synth-three-way(std::get<1>(lhs), std::get<1>(rhs)); c != 0) return c; ... return synth-three-way(std::get<N - 1>(lhs), std::get<N - 1>(rhs));

  1. Identique à (1), à ceci près que rhs est un objet tuple-like, et que le nombre d'éléments de rhs est déterminé par std::tuple_size_v<UTuple>. Cette surcharge ne peut être trouvée que par recherche dépendante des arguments.

  2. Identique à (7), à ceci près que rhs est un objet tuple-like. /* Elems */ désigne le paquet de types std::tuple_element_t<i, UTuple> pour chaque i dans [0,std::tuple_size_v<UTuple>), dans l'ordre croissant. Cette surcharge ne peut être trouvée que par recherche dépendante des arguments.

Tous les opérateurs de comparaison sont court-circuités ; ils n'accèdent pas aux éléments du tuple au-delà de ce qui est nécessaire pour déterminer le résultat de la comparaison.

Les opérateurs <, <=, >, >= et != sont synthétisés à partir de operator<=> et operator== respectivement.

(depuis C++20)

Paramètres

  • lhs, rhs — tuples à comparer

Valeur de retour

1,8) true si std::get<i>(lhs) == std::get<i>(rhs) pour tout i dans [0,sizeof...(Types)), sinon false. Pour deux tuples vides, renvoie true.

  1. !(lhs == rhs)

  2. true si le premier élément non équivalent de lhs est inférieur à celui de rhs, false si le premier élément non équivalent de rhs est inférieur à celui de lhs ou s'il n'existe aucun élément non équivalent. Pour deux tuples vides, renvoie false.

  3. !(rhs < lhs)

  4. rhs < lhs

  5. !(lhs < rhs)

7,9) La relation entre la première paire d'éléments non équivalents, s'il y en a une, std::strong_ordering::equal sinon. Pour deux tuples vides, renvoie std::strong_ordering::equal.

Notes

Les opérateurs relationnels sont définis en fonction de la operator< de chaque élément.

(jusqu'à C++20)

Les opérateurs relationnels sont définis en termes de synth-three-way, qui utilise operator<=> si possible, sinon operator<.

En particulier, si un type d'élément ne fournit pas lui-même operator<=>, mais est implicitement convertible en un type comparable à trois voies, cette conversion sera utilisée à la place de operator<.

(depuis C++20)

Exemple

Parce que operator< est défini pour les tuples, des conteneurs de tuples peuvent être triés.

#include <algorithm>
#include <iostream>
#include <tuple>
#include <vector>

int main()
{
    std::vector<std::tuple<int, std::string, float>> v
    {
        {2, "baz", -0.1},
        {2, "bar", 3.14},
        {1, "foo", 10.1},
        {2, "baz", -1.1},
    };
    std::sort(v.begin(), v.end());

    for (const auto& p: v)
        std::cout << "{ " << get<0>(p)
                  << ", " << get<1>(p)
                  << ", " << get<2>(p)
                  << " }\n";
}

Output:

{ 1, foo, 10.1 }
{ 2, bar, 3.14 }
{ 2, baz, -1.1 }
{ 2, baz, -0.1 }
