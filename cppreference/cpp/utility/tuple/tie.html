std::tie

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <tuple>

template< class... Types >
std::tuple<Types&...> tie( Types&... args ) noexcept;  // (depuis C++11) (constexpr depuis C++14)

Crée un tuple de références lvalue vers ses arguments ou instances de std::ignore.

Paramètres

  • args — zéro ou plusieurs arguments lvalue à partir desquels construire le tuple.

Valeur de retour

Un objet std::tuple contenant des références lvalue.

Implémentation possible

template <typename... Args>
constexpr // depuis C++14
std::tuple<Args&...> tie(Args&... args) noexcept
{
    return {args...};
}

Notes

std::tie peut être utilisé pour décomposer une std::pair car std::tuple possède une affectation avec conversion depuis des paires :

bool result;
std::tie(std::ignore, result) = set.insert(value);

Exemple

  1. std::tie peut être utilisé pour introduire une comparaison lexicographique dans une struct ou pour décomposer un tuple ;
  2. std::tie peut fonctionner avec les liaisons structurées :
#include <cassert>
#include <iostream>
#include <set>
#include <string>
#include <tuple>

struct S
{
    int n;
    std::string s;
    float d;

    friend bool operator<(const S& lhs, const S& rhs) noexcept
    {
        // compare lhs.n à rhs.n,
        // puis lhs.s à rhs.s,
        // puis lhs.d à rhs.d
        // dans cet ordre, le premier résultat non égal est renvoyé
        // ou false si tous les éléments sont égaux
        return std::tie(lhs.n, lhs.s, lhs.d) < std::tie(rhs.n, rhs.s, rhs.d);
    }
};

int main()
{
    // Démonstration de comparaison lexicographique :
    std::set<S> set_of_s;

    S value{42, "Test", 3.14};
    std::set<S>::iterator iter;
    bool is_inserted;

    // Décomposer une paire :
    std::tie(iter, is_inserted) = set_of_s.insert(value);
    assert(is_inserted);

    // std::tie et liaisons structurées :
    auto position = [](int w) { return std::tuple(1 * w, 2 * w); };

    auto [x, y] = position(1);
    assert(x == 1 && y == 2);
    std::tie(x, y) = position(2); // réutiliser x, y avec tie
    assert(x == 2 && y == 4);

    // Les conversions implicites sont autorisées :
    std::tuple<char, short> coordinates(6, 9);
    std::tie(x, y) = coordinates;
    assert(x == 6 && y == 9);

    // Ignorer un élément :
    std::string z;
    std::tie(x, std::ignore, z) = std::tuple(1, 2.0, "Test");
    assert(x == 1 && z == "Test");
}
