std::uses_allocator<std::tuple>

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <tuple>

template< class... Types, class Alloc >
struct uses_allocator< std::tuple<Types...>, Alloc > : std::true_type { };  // (depuis C++11)

Cette spécialisation de std::uses_allocator informe les autres composants de la bibliothèque que les tuples prennent en charge la construction avec allocateur, bien qu'ils n'aient pas de allocator_type imbriqué.

Exemple

// myalloc est un Allocator à états doté d'un constructeur à un seul argument
// qui prend un int. Il n'a pas de constructeur par défaut.

    using innervector_t = std::vector<int, myalloc<int>>;
    using elem_t = std::tuple<int, innervector_t>;
    using Alloc = std::scoped_allocator_adaptor< myalloc<elem_t>, myalloc<int>>;

    Alloc a(1,2);
    std::vector<elem_t, Alloc> v(a);
    v.resize(1);                  // utilise l'allocateur #1 pour les éléments de v
    std::get<1>(v[0]).resize(10); // utilise l'allocateur #2 pour innervector_t
