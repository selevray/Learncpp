template< class T, class U >

constexpr std::partial_ordering
    partial_order( T&& t, U&& u ) noexcept(/* voir ci-dessous */);

Compare deux valeurs à l'aide de la comparaison à trois voies et produit un résultat de type std::partial_ordering.

Soient t et u des expressions, et T et U désignant respectivement decltype((t)) et decltype((u)) ; std::partial_order(t, u) est équivalent à l'expression :

  • Si std::is_same_v<std::decay_t<T>, std::decay_t<U>> est true :
    • std::partial_ordering(partial_order(t, u)), si c'est une expression bien formée avec résolution de surcharge effectuée dans un contexte ne contenant pas de déclaration de std::partial_order,
    • sinon, std::partial_ordering(std::compare_three_way()(t, u)), si elle est bien formée,
    • sinon, std::partial_ordering(std::weak_order(t, u)), si elle est bien formée.
  • Dans tous les autres cas, l'expression est mal formée, ce qui peut entraîner un échec de substitution lorsqu'elle apparaît dans le contexte immédiat d'une instanciation de modèle.

Objets de point de personnalisation

Le nom std::partial_order désigne un objet de point de personnalisation, qui est un objet fonction const d'un type de classe littéral semiregular. À des fins d'exposition, la version sans qualificateurs cv de son type est désignée par __partial_order_fn.

Toutes les instances de __partial_order_fn sont égales. Les effets de l'invocation de différentes instances du type __partial_order_fn sur les mêmes arguments sont équivalents, qu'il s'agisse ou non d'une lvalue ou d'une rvalue, et que l'expression désignant l'instance soit qualifiée const ou non (toutefois, une instance qualifiée volatile n'est pas tenue d'être invocable). Ainsi, std::partial_order peut être copié librement et ses copies peuvent être utilisées de manière interchangeable.

Étant donné un ensemble de types Args..., si std::declval<Args>()... satisfont aux exigences relatives aux arguments de std::partial_order ci-dessus, alors __partial_order_fn modélise

  • std::invocable<__partial_order_fn, Args...>,
  • std::invocable<const __partial_order_fn, Args...>,
  • std::invocable<__partial_order_fn&, Args...>, and
  • std::invocable<const __partial_order_fn&, Args...>.

Sinon, aucun opérateur d'appel de fonction de __partial_order_fn ne participe à la résolution de surcharge.
