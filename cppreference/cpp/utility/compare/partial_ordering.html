std::partial_ordering

Défini dans l'en-tête <compare>

class partial_ordering;  // (depuis C++20)

Le type de classe std::partial_ordering est le type de résultat d'une comparaison à trois voies qui :

  • Admet les six opérateurs relationnels (==, !=, <, <=, >, >=).

  • N'implique pas la substituabilité : si a est équivalent à b, f(a) peut ne pas être équivalent à f(b), où f désigne une fonction qui ne lit que l'état pertinent pour la comparaison accessible via les membres publics const de l'argument. Autrement dit, des valeurs équivalentes peuvent être distinguables.

  • Admet des valeurs incomparables : a < b, a == b et a > b peuvent tous être false.

Constantes

Le type std::partial_ordering possède quatre valeurs valides, implémentées comme membres de données statiques const de son type :

Nom Définition

  • inline constexpr std::partial_ordering less [statique] — une valeur valide indiquant la relation « inférieur à » (ordonné avant) (constante membre statique publique)
  • inline constexpr std::partial_ordering equivalent [statique] — une valeur valide indiquant l'équivalence (ni ordonné avant ni ordonné après) (constante membre statique publique)
  • inline constexpr std::partial_ordering greater [statique] — une valeur valide indiquant la relation « supérieur à » (ordonné après) (constante membre statique publique)
  • inline constexpr std::partial_ordering unordered [statique] — une valeur valide indiquant une relation avec une valeur incomparable (constante membre statique publique)

Conversions

std::partial_ordering ne peut pas être implicitement converti en d'autres types de catégorie de comparaison, alors que std::strong_ordering et std::weak_ordering sont tous deux implicitement convertibles en partial_ordering.

Comparaisons

Les opérateurs de comparaison sont définis entre les valeurs de ce type et le littéral 0. Cela permet les expressions a <=> b == 0 ou a <=> b < 0 qui peuvent servir à convertir le résultat d'un opérateur de comparaison à trois voies en une relation booléenne ; voir std::is_eq, std::is_lt, etc.

Ces fonctions ne sont pas visibles par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peuvent être trouvées que par la recherche dépendante des arguments lorsque std::partial_ordering est une classe associée aux arguments.

Le comportement d'un programme qui tente de comparer un partial_ordering avec autre chose que le littéral entier 0 est indéfini.

operator==

friend constexpr bool operator==( partial_ordering v, /*unspecified*/ u ) noexcept;  // (1)

friend constexpr bool
    operator==( partial_ordering v, partial_ordering w ) noexcept = default;  // (2)

Paramètres

  • v, w — valeurs std::partial_ordering à vérifier
  • u — un paramètre inutilisé de tout type acceptant l'argument littéral zéro

Valeur de retour

  1. true si v est equivalent, false si v est less, greater ou unordered

  2. true si les deux paramètres contiennent la même valeur, false sinon

Paramètres

  • v — une valeur std::partial_ordering à vérifier

Valeur de retour

  1. v.

  2. greater si v est less, less si v est greater, sinon v.

Notes

L'opérateur intégré operator<=> entre valeurs à virgule flottante utilise cet ordre : le zéro positif et le zéro négatif se comparent equivalent, mais peuvent être distingués, et les valeurs NaN se comparent unordered à toute autre valeur.
