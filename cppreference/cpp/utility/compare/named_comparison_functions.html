Ces fonctions prennent un résultat de comparaison à trois voies et le convertissent en le résultat de l'un des six opérateurs relationnels

Plus précisément, ces fonctions renvoient

  1. cmp == 0

  2. cmp != 0

  3. cmp < 0

  4. cmp <= 0

  5. cmp > 0

  6. cmp >= 0

Paramètres

  • cmp — le résultat de la comparaison à trois voies

Valeur de retour

bool le résultat de l'opération relationnelle correspondante
