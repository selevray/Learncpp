struct compare_three_way;  // (depuis C++20)

Objet fonction permettant d'effectuer des comparaisons. Déduit les types des paramètres et le type de retour de l'opérateur d'appel de fonction.

Types imbriqués

Type imbriqué Définition

  • is_transparent — unspecified

Fonctions membres

  • operator() — obtient le résultat de la comparaison à trois voies des deux arguments (fonction membre publique)

std::compare_three_way::operator()

template< class T, class U >
constexpr auto operator()( T&& t, U&& u ) const;

Étant donnée l'expression std::forward<T>(t) <=> std::forward<U>(u) comme expr :

  • Si expr produit un appel à l'opérateur intégré operator<=> comparant des pointeurs, en prenant le type de pointeur composite de t et u comme P :

    • Compare les deux pointeurs convertis (de type P) selon l'ordre total strict défini par l'implémentation sur les pointeurs :
      • Si t précède u, renvoie std::strong_ordering::less.
      • Si u précède t, renvoie std::strong_ordering::greater.
      • Sinon, renvoie std::strong_ordering::equal.
    • Si la séquence de conversion de T vers P ou la séquence de conversion de U vers P n'est pas préservant l'égalité, le comportement est indéfini.

  • Otherwise:

    • Renvoie le résultat de expr.
    • Si std::three_way_comparable_with<T, U> n'est pas modélisé, le comportement est indéfini.

Cette surcharge ne participe à la résolution de surcharge que si std::three_way_comparable_with<T, U> est satisfait.

Exemple

#include <compare>
#include <iostream>

struct Rational
{
    int num;
    int den; // > 0

    // Bien que la comparaison X <=> Y fonctionne, un appel direct
    // à std::compare_three_way{}(X, Y) exige que l'operator== soit défini
    // pour satisfaire std::three_way_comparable_with.
    constexpr bool operator==(Rational const&) const = default;
};

constexpr std::weak_ordering operator<=>(Rational lhs, Rational rhs)
{
    return lhs.num * rhs.den <=> rhs.num * lhs.den;
}

void print(std::weak_ordering value)
{
    value < 0 ? std::cout << "less\n" :
    value > 0 ? std::cout << "greater\n" :
                std::cout << "equal\n";
}

int main()
{
    Rational a{6, 5};
    Rational b{8, 7};
    print(a <=> b);
    print(std::compare_three_way{}(a, b));
}

Output:

greater
greater
