std::swap(std::pair)

Échange le contenu de x et y. Équivalent à x.swap(y).

  1. Cette surcharge ne participe à la résolution de surcharge que si std::is_swappable_v<first_type> && std::is_swappable_v<second_type> est true.

  2. Cette surcharge ne participe à la résolution de surcharge que si std::is_swappable_v<const first_type> && std::is_swappable_v<const second_type> est true.

(depuis C++17)

Paramètres

  • x, y — paires dont le contenu doit être échangé

Valeur de retour

(aucune)

Exceptions

noexcept specification:noexcept(noexcept(x.swap(y)))

Exemple

#include <iostream>
#include <utility>

int main()
{
    auto p1 = std::make_pair(10, 3.14);
    auto p2 = std::pair(12, 1.23); // CTAD, depuis C++17

    auto print_p1_p2 = [&](auto msg) {
        std::cout << msg
                  << "p1 = {" << std::get<0>(p1)
                  << ", "     << std::get<1>(p1) << "}, "
                  << "p2 = {" << std::get<0>(p2)
                  << ", "     << std::get<1>(p2) << "}\n";
    };

    print_p1_p2("Before p1.swap(p2): ");
    p1.swap(p2);
    print_p1_p2("After  p1.swap(p2): ");
    std::swap(p1, p2);
    print_p1_p2("After swap(p1, p2): ");
}

Output:

Before p1.swap(p2): p1 = {10, 3.14}, p2 = {12, 1.23}
After  p1.swap(p2): p1 = {12, 1.23}, p2 = {10, 3.14}
After swap(p1, p2): p1 = {10, 3.14}, p2 = {12, 1.23}
