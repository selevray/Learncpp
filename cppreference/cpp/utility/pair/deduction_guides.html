guides de déduction pour std::pair

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <utility>

template<class T1, class T2>
pair(T1, T2) -> pair<T1, T2>;  // (depuis C++17)

Un guide de déduction est fourni pour std::pair afin de prendre en compte les cas limites non couverts par les guides de déduction implicites, en particulier les arguments non copiables et la conversion tableau vers pointeur.

Exemple

#include <utility>

int main()
{
    int a[2], b[3];
    std::pair p{a, b}; // un guide de déduction explicite est utilisé dans ce cas
}
