std::make_pair

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <utility>

template< class T1, class T2 >
std::pair<T1, T2> make_pair( T1 x, T2 y );  // (jusqu'à C++11)

template< class T1, class T2 >
std::pair</*V1*/, /*V2*/> make_pair( T1&& x, T2&& y );  // (depuis C++11) (constexpr depuis C++14) (jusqu'à C++20)

template< class T1, class T2 >
constexpr std::pair<std::unwrap_ref_decay_t<T1>,
                    std::unwrap_ref_decay_t<T2>>
    make_pair( T1&& x, T2&& y );  // (depuis C++20)

Crée un objet std::pair, en déduisant le type cible à partir des types des arguments.

Étant donnés les types std::decay<T1>::type en tant que U1 et std::decay<T2>::type en tant que U2, les types /*V1*/ et /*V2*/ sont définis comme suit :

  • Si U1 est std::reference_wrapper<X>, /*V1*/ est X& ; sinon /*V1*/ est U1.
  • Si U2 est std::reference_wrapper<Y>, /*V2*/ est Y& ; sinon /*V2*/ est U2.

(depuis C++11) (jusqu'à C++20)

Paramètres

  • x, y — les valeurs à partir desquelles construire la paire

Valeur de retour

std::pair<T1, T2>(x, y)

(jusqu'à C++11)

std::pair</*V1*/, /*V2*/>(std::forward<T1>(x), std::forward<T2>(y))

(depuis C++11) (jusqu'à C++20)

std::pair<std::unwrap_ref_decay_t<T1>, std::unwrap_ref_decay_t<T2>> (std::forward<T1>(x), std::forward<T2>(y))

(depuis C++20)

Exemple

#include <functional>
#include <iostream>
#include <utility>

int main()
{
    int n = 1;
    int a[5] = {1, 2, 3, 4, 5};

    // construire une paire à partir de deux int
    auto p1 = std::make_pair(n, a[1]);
    std::cout << "The value of p1 is "
              << '(' << p1.first << ", " << p1.second << ")\n";

    // construire une paire à partir d'une référence vers int et d'un tableau (dégradé en pointeur)
    auto p2 = std::make_pair(std::ref(n), a);
    n = 7;
    std::cout << "The value of p2 is "
              << '(' << p2.first << ", " << *(p2.second + 2) << ")\n";
}

Output:

The value of p1 is (1, 2)
The value of p2 is (7, 3)
