Le type référence commun de deux pair est un pair des deux types référence communs des types d'éléments correspondants des deux pair, où les qualificateurs cv et de référence des pair sont appliqués à leurs types d'éléments.

Le type référence commun n'est défini que si les deux paires de types d'éléments correspondants ont des types référence communs.
