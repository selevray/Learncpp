Remplace le contenu de la paire.

  1. Opérateur d'affectation par copie. Remplace le contenu par une copie du contenu de other.

L'opérateur d'affectation est déclaré implicitement. Utiliser cet opérateur d'affectation rend le programme mal formé si l'un de T1 ou de T2 est un type qualifié const, ou un type référence, ou un type classe dont l'opérateur d'affectation par copie est inaccessible, ou un type tableau d'une telle classe.

(jusqu'à C++11)

Cette surcharge est définie comme supprimée si l'un de std::is_copy_assignable<T1>::value ou de std::is_copy_assignable<T2>::value est false.

(depuis C++11)

  1. Opérateur d'affectation par copie pour un opérande qualifié const.

Cette surcharge ne participe à la résolution de surcharge que si std::is_copy_assignable_v<const T1> et std::is_copy_assignable_v<const T2> sont tous deux true.

  1. Affecte other.first à first et other.second à second.

Cette surcharge ne participe à la résolution de surcharge que si std::is_assignable<T1&, const U1&>::value et std::is_assignable<T2&, const U2&>::value sont tous deux true.

(depuis C++11)

  1. Affecte other.first à first et other.second à second.

Cette surcharge ne participe à la résolution de surcharge que si std::is_assignable_v<const T1&, const U1&> et std::is_assignable_v<const T2&, const U2&> sont tous deux true.

  1. Opérateur d'affectation par déplacement. Remplace le contenu par celui de other en utilisant la sémantique de déplacement.

Cette surcharge ne participe à la résolution de surcharge que si std::is_move_assignable<T1>::value et std::is_move_assignable<T2>::value sont tous deux true.

  1. Opérateur d'affectation par déplacement pour un opérande qualifié const.

Cette surcharge ne participe à la résolution de surcharge que si std::is_assignable_v<const T1&, T1> et std::is_assignable_v<const T2&, T2> sont tous deux true.

  1. Affecte std::forward<U1>(p.first) à first et std::forward<U2>(p.second) à second.

Cette surcharge ne participe à la résolution de surcharge que si std::is_assignable<T1&, U1>::value et std::is_assignable<T2&, U2>::value sont tous deux true.

  1. Affecte std::forward<U1>(p.first) à first et std::forward<U2>(p.second) à second.

Cette surcharge ne participe à la résolution de surcharge que si std::is_assignable_v<const T1&, U1> et std::is_assignable_v<const T2&, U2> sont tous deux true.

  1. Affecte std::get<0>(std::forward<P>(u)) à first et std::get<1>(std::forward<P>(u)) à second.

Cette surcharge participe à la résolution de surcharge uniquement si

  • std::same_as<std::remove_cvref_t<P>, std::pair> is false,
  • std::remove_cvref_t<P> n'est pas une spécialisation de std::ranges::subrange,
  • std::is_assignable_v<T1&, decltype(std::get<0>(std::forward<P>(p)))> est true, et
  • std::is_assignable_v<T1&, decltype(std::get<1>(std::forward<P>(p)))> is true.
  1. Affecte std::get<0>(std::forward<P>(u)) à first et std::get<1>(std::forward<P>(u)) à second.

Cette surcharge participe à la résolution de surcharge uniquement si

  • std::same_as<std::remove_cvref_t<P>, std::pair> is false,
  • std::remove_cvref_t<P> n'est pas une spécialisation de std::ranges::subrange,
  • std::is_assignable_v<const T1&, decltype(std::get<0>(std::forward<P>(p)))> est true, et
  • std::is_assignable_v<const T1&, decltype(std::get<1>(std::forward<P>(p)))> is true.

Paramètres

  • other — paire de valeurs pour remplacer le contenu de cette paire
  • p — paire de valeurs de types éventuellement différents pour remplacer le contenu de cette paire
  • u — pair-like objet de valeurs pour remplacer le contenu de cette paire

Exigences sur les types

  • T1 doit satisfaire les exigences de CopyAssignable depuis U1. (jusqu'à C++11)
  • T2 doit satisfaire les exigences de CopyAssignable depuis U2. (jusqu'à C++11)

Valeur de retour

*this

Exceptions

1-4) Peut lever des exceptions définies par l'implémentation.

5)noexcept specification:noexcept( std::is_nothrow_move_assignable<T1>::value && std::is_nothrow_move_assignable<T2>::value )

6-10) Peut lever des exceptions définies par l'implémentation.

Exemple

#include <cstddef>
#include <iomanip>
#include <iostream>
#include <utility>
#include <vector>

template<class Os, class T>
Os& operator<<(Os& os, const std::vector<T>& v)
{
    os << '{';
    for (std::size_t t = 0; t != v.size(); ++t)
        os << v[t] << (t + 1 < v.size() ? ", " : "");
    return os << '}';
}

template<class Os, class U1, class U2>
Os& operator<<(Os& os, const std::pair<U1, U2>& pair)
{
    return os << '{' << pair.first << ", " << pair.second << '}';
}

int main()
{
    std::pair<int, std::vector<int>> p{1, {2}}, q{2, {5, 6}};

    p = q; // (1) operator=(const pair& other);
    std::cout << std::setw(23) << std::left
              << "(1) p = q;"
              << "p: " << p << "     q: " << q << '\n';

    std::pair<short, std::vector<int>> r{4, {7, 8, 9}};
    p = r; // (3) operator=(const pair<U1, U2>& other);
    std::cout << std::setw(23)
              << "(3) p = r;"
              << "p: " << p << "  r: " << r << '\n';

    p = std::pair<int, std::vector<int>>{3, {4}};
    p = std::move(q); // (5) operator=(pair&& other);
    std::cout << std::setw(23)
              << "(5) p = std::move(q);"
              << "p: " << p << "     q: " << q << '\n';

    p = std::pair<int, std::vector<int>>{5, {6}};
    p = std::move(r); // (7) operator=(pair<U1, U2>&& other);
    std::cout << std::setw(23)
              << "(7) p = std::move(r);"
              << "p: " << p << "  r: " << r << '\n';
}

Output:

(1) p = q;             p: {2, {5, 6}}     q: {2, {5, 6}}
(3) p = r;             p: {4, {7, 8, 9}}  r: {4, {7, 8, 9}}
(5) p = std::move(q);  p: {2, {5, 6}}     q: {2, {}}
(7) p = std::move(r);  p: {4, {7, 8, 9}}  r: {4, {}}
