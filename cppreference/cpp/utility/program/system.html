std::system

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdlib>

int system( const char* command );

Appelle le processeur de commandes de l'environnement hôte (par exemple /bin/sh, cmd.exe) avec le paramètre command. Renvoie une valeur définie par l'implémentation (généralement la valeur que retourne le programme invoqué).

Si command est un pointeur nul, vérifie si l'environnement hôte possède un processeur de commandes et renvoie une valeur non nulle si et seulement si ce processeur existe.

Paramètres

  • command — chaîne de caractères identifiant la commande à exécuter dans le processeur de commandes. Si un pointeur nul est donné, le processeur de commandes est vérifié pour son existence

Valeur de retour

Valeur définie par l'implémentation. Si command est un pointeur nul, renvoie une valeur non nulle si et seulement si le processeur de commandes existe.

Notes

Sur les systèmes POSIX, la valeur de retour peut être décomposée à l'aide de WEXITSTATUS et WSTOPSIG.

La fonction POSIX associée popen rend la sortie générée par command disponible pour l'appelant.

Un vidage explicite de std::cout est également nécessaire avant un appel à std::system, si le processus lancé effectue des E/S à l'écran.

Exemple

#include <cstdlib>
#include <fstream>
#include <iostream>

int main()
{
    std::system("ls -l >test.txt"); // exécute la commande UNIX "ls -l >test.txt"
    std::cout << std::ifstream("test.txt").rdbuf();
}
