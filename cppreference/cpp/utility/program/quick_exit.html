std::quick_exit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdlib>

[[noreturn]] void quick_exit( int exit_code ) noexcept;  // (depuis C++11)

Provoque une terminaison normale du programme sans nettoyer complètement les ressources.

Les fonctions passées à std::at_quick_exit sont appelées dans l'ordre inverse de leur enregistrement. Si une exception tente de se propager hors de l'une de ces fonctions, std::terminate est appelée. Après l'appel des fonctions enregistrées, std::_Exit(exit_code) appelle.

Les fonctions passées à std::atexit ne sont pas appelées.

Paramètres

  • exit_code — statut de sortie du programme

Valeur de retour

(aucune)

Exemple

#include <cstdlib>
#include <iostream>

template<int N>
void quick_exit_handler()
{
    std::cout << "quick_exit handler #" << N << std::endl; // le vidage est prévu
}

void at_exit_handler()
{
    std::cout << "at_exit handler\n";
}

int main()
{
    if (std::at_quick_exit(quick_exit_handler<1>) ||
        std::at_quick_exit(quick_exit_handler<2>))
    {
        std::cerr << "Registration failed\n";
        return EXIT_FAILURE;
    }

    std::atexit(at_exit_handler); // le gestionnaire ne sera pas appelé

    struct R { ~R() { std::cout << "destructor\n"; } } resource;

    /*...*/

    std::quick_exit(EXIT_SUCCESS);

    std::cout << "This statement is unreachable...\n";
}

Output:

quick_exit handler #2
quick_exit handler #1
