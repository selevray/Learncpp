std::getenv

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdlib>

char* getenv( const char* env_var );

Recherche dans la liste d'environnement fournie par l'environnement hôte (le système d'exploitation) une chaîne correspondant à la chaîne C pointée par env_var, et renvoie un pointeur vers la chaîne C associée au membre de la liste d'environnement correspondant.

Cette fonction n'est pas tenue d'être thread-safe. Un autre appel à getenv, ainsi qu'un appel aux fonctions POSIX setenv(), unsetenv() et putenv(), peuvent invalider le pointeur renvoyé par un appel précédent ou modifier la chaîne obtenue lors d'un appel précédent.

(jusqu'à C++11)

Cette fonction est thread-safe (l'appeler depuis plusieurs threads n'introduit pas de course de données) tant qu'aucune autre fonction ne modifie l'environnement hôte. En particulier, les fonctions POSIX setenv(), unsetenv() et putenv() introduiraient une course de données si elles étaient appelées sans synchronisation.

(depuis C++11)

Modifier la chaîne renvoyée par getenv provoque un comportement indéfini.

Paramètres

  • env_var — chaîne de caractères terminée par un caractère nul identifiant le nom de la variable d'environnement recherchée

Valeur de retour

Chaîne de caractères identifiant la valeur de la variable d'environnement, ou pointeur nul si cette variable n'est pas trouvée.

Notes

Sous POSIX, les variables d'environnement sont aussi accessibles via la variable globale environ, déclarée comme extern char** environ; dans <unistd.h>, et via le troisième argument optionnel, envp, de la fonction main.

Exemple

#include <cstdlib>
#include <iostream>

int main()
{
    if (const char* env_p = std::getenv("PATH"))
        std::cout << "Your PATH is: " << env_p << '\n';
}

Sortie possible :

Your PATH is: /usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:/usr/games
