std::longjmp

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <csetjmp>

void longjmp( std::jmp_buf env, int status );  // (jusqu'à C++17)

[[noreturn]] void longjmp( std::jmp_buf env, int status );  // (depuis C++17)

Charge le contexte d'exécution env sauvegardé par un appel précédent à setjmp. Cette fonction ne retourne pas. Le contrôle est transféré au site d'appel de la macro setjmp qui a initialisé env. Cette setjmp renvoie alors la valeur passée comme status.

Si la fonction ayant appelé setjmp a quitté, le comportement est indéfini (autrement dit, seuls les sauts longs vers le haut de la pile d'appels sont autorisés).

Restrictions supplémentaires en C++

En plus de C longjmp, C++ std::longjmp a un comportement plus restreint.

Si le remplacement de std::longjmp par throw et de setjmp par catch invoquait un destructeur non trivial pour un objet automatique quelconque, le comportement de cette std::longjmp est indéfini.

Le comportement est indéfini si std::longjmp est appelée dans une coroutine à un endroit où l'opérateur co_await peut être utilisé.

(depuis C++20)

Paramètres

  • env — variable désignant l'état d'exécution du programme sauvegardé par setjmp
  • status — la valeur à renvoyer par setjmp. Si elle est égale à 0, 1 est utilisée à la place

Valeur de retour

(aucune)

Notes

std::longjmp est le mécanisme utilisé en C pour gérer les conditions d'erreur inattendues lorsque la fonction ne peut pas retourner de résultat significatif. C++ utilise généralement la gestion des exceptions à cette fin.

Exemple

#include <array>
#include <cmath>
#include <csetjmp>
#include <cstdlib>
#include <format>
#include <iostream>

std::jmp_buf solver_error_handler;

std::array<double, 2> solve_quadratic_equation(double a, double b, double c)
{
    const double discriminant = b * b - 4.0 * a * c;
    if (discriminant < 0)
        std::longjmp(solver_error_handler, true); // Aller au gestionnaire d'erreurs

    const double delta = std::sqrt(discriminant) / (2.0 * a);
    const double argmin = -b / (2.0 * a);
    return {argmin - delta, argmin + delta};
}

void show_quadratic_equation_solution(double a, double b, double c)
{
    std::cout << std::format("Solving {}x² + {}x + {} = 0...\n", a, b, c);
    auto [x_0, x_1] = solve_quadratic_equation(a, b, c);
    std::cout << std::format("x₁ = {}, x₂ = {}\n\n", x_0, x_1);
}

int main()
{
    if (setjmp(solver_error_handler))
    {
        // Gestionnaire d'erreurs pour le solveur
        std::cout << "No real solution\n";
        return EXIT_FAILURE;
    }

    for (auto [a, b, c] : {std::array{1, -3, 2}, {2, -3, -2}, {1, 2, 3}})
        show_quadratic_equation_solution(a, b, c);

    return EXIT_SUCCESS;
}

Output:

Solving 1x² + -3x + 2 = 0...
x₁ = 1, x₂ = 2

Solving 2x² + -3x + -2 = 0...
x₁ = -0.5, x₂ = 2

Solving 1x² + 2x + 3 = 0...
No real solution

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
