std::_Exit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdlib>

[[noreturn]] void _Exit( int exit_code ) noexcept;  // (depuis C++11)

Provoque une terminaison normale du programme sans nettoyer complètement les ressources.

Les destructeurs des variables à durée de stockage automatique, thread local et statique ne sont pas appelés. Les fonctions passées à std::at_quick_exit() ou std::atexit() ne sont pas appelées. Le fait que les ressources ouvertes, comme les fichiers, soient fermées est défini par l'implémentation.

Si exit_code vaut 0 ou EXIT_SUCCESS, un statut défini par l'implémentation indiquant une terminaison réussie est renvoyé à l'environnement hôte. Si exit_code vaut EXIT_FAILURE, un statut défini par l'implémentation, indiquant une terminaison échouée, est renvoyé. Dans les autres cas, une valeur de statut définie par l'implémentation est renvoyée.

Une implémentation autonome doit fournir std::_Exit.

(depuis C++23)

Paramètres

  • exit_code — statut de sortie du programme

Valeur de retour

(aucune)

Notes

Bien que _Exit soit tenue d'être autonome depuis C++23, elle n'est pas tenue d'être disponible dans une implémentation C autonome.

Exemple

#include <iostream>

class Static
{
public:
    ~Static()
    {
        std::cout << "Static dtor\n";
    }
};

class Local
{
public:
    ~Local()
    {
        std::cout << "Local dtor\n";
    }
};

Static static_variable; // le destructeur de cet objet ne sera *pas* appelé

void atexit_handler()
{
    std::cout << "atexit handler\n";
}

int main()
{
    Local local_variable; // le destructeur de cet objet ne sera *pas* appelé

    // le gestionnaire ne sera *pas* appelé
    const int result = std::atexit(atexit_handler);

    if (result != 0)
    {
        std::cerr << "atexit registration failed\n";
        return EXIT_FAILURE;
    }

    std::cout << "test" << std::endl; // vidage depuis std::endl
        // doit être présent ici, sinon rien ne sera affiché
    std::_Exit(EXIT_FAILURE);
}

Output:

test
