EXIT_SUCCESS, EXIT_FAILURE

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdlib>

#define EXIT_SUCCESS /*implementation defined*/

#define EXIT_FAILURE /*implementation defined*/

Les macros EXIT_SUCCESS et EXIT_FAILURE se développent en expressions constantes entières, utilisables comme arguments de la fonction std::exit (et donc comme valeurs à renvoyer par la fonction main), et indiquent l'état d'exécution du programme.

Une implémentation autonome doit fournir EXIT_SUCCESS et EXIT_FAILURE.

(depuis C++23)

Constante Description

  • EXIT_SUCCESS — exécution réussie d'un programme
  • EXIT_FAILURE — exécution échouée d'un programme

Notes

Tant EXIT_SUCCESS que la valeur zéro indiquent un état d'exécution réussi du programme (voir std::exit), bien qu'il ne soit pas exigé que EXIT_SUCCESS soit égal à zéro.

Bien que EXIT_SUCCESS et EXIT_FAILURE soient tenues d'être autonomes depuis C++23, elles ne sont pas tenues d'être disponibles dans une implémentation C autonome.

Exemple

#include <cstdlib>
#include <iostream>

int main(int argc, char* argv[])
{
    if (argc <= 1)
    {
        std::cout << "At least one command-line argument required\n";
        return EXIT_FAILURE;
    }

    std::cout << argv[1] << '\n';
    return EXIT_SUCCESS;
}
