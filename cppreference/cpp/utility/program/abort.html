std::abort

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdlib>

void abort();  // (jusqu'à C++11)

[[noreturn]] void abort() noexcept;  // (depuis C++11)

Provoque une terminaison anormale du programme, sauf si SIGABRT est intercepté par un gestionnaire de signal passé à std::signal et que ce gestionnaire ne retourne pas.

Les destructeurs des variables de durée de stockage automatique, thread local (depuis C++11) et de durée de stockage statique ne sont pas appelés. Les fonctions enregistrées avec std::atexit() et std::at_quick_exit (depuis C++11) ne sont pas non plus appelées. Le fait que les ressources ouvertes, telles que les fichiers, soient fermées est défini par l'implémentation. Un statut défini par l'implémentation, indiquant une exécution non réussie, est renvoyé à l'environnement hôte.

Paramètres

(aucune)

Valeur de retour

Aucune, car elle ne retourne rien.

Exceptions

Ne lève aucune exception.

Notes

POSIX spécifie que la fonction abort() remplace le blocage ou l'ignorance du signal SIGABRT.

Certaines intrinsèques du compilateur, par exemple __builtin_trap (gcc, clang et icc) ou __fastfail/__debugbreak (msvc), peuvent être utilisées pour terminer le programme le plus rapidement possible.

Exemple

#include <csignal>
#include <cstdlib>
#include <iostream>

class Tester
{
public:
    Tester()  { std::cout << "Tester ctor\n"; }
    ~Tester() { std::cout << "Tester dtor\n"; }
};

Tester static_tester; // Destructeur non appelé

void signal_handler(int signal)
{
    if (signal == SIGABRT)
        std::cerr << "SIGABRT received\n";
    else
        std::cerr << "Unexpected signal " << signal << " received\n";
    std::_Exit(EXIT_FAILURE);
}

int main()
{
    Tester automatic_tester; // Destructeur non appelé

    // Installer le gestionnaire
    auto previous_handler = std::signal(SIGABRT, signal_handler);
    if (previous_handler == SIG_ERR)
    {
        std::cerr << "Setup failed\n";
        return EXIT_FAILURE;
    }

    std::abort(); // Déclencher SIGABRT
    std::cout << "This code is unreachable\n";
}

Output:

Tester ctor
Tester ctor
SIGABRT received
