std::bitset<N> operator&( const std::bitset<N>& lhs,

std::bitset<N> operator|( const std::bitset<N>& lhs,

template< std::size_t N >
std::bitset<N> operator^( const std::bitset<N>& lhs,
                          const std::bitset<N>& rhs );  // (3) (noexcept depuis C++11) (constexpr depuis C++23)

Effectue les opérations binaires AND, OR et XOR entre deux bitsets, lhs et rhs.

  1. Renvoie un std::bitset<N> contenant le résultat du AND binaire sur les paires de bits correspondantes de lhs et rhs.

  2. Renvoie un std::bitset<N> contenant le résultat du OR binaire sur les paires de bits correspondantes de lhs et rhs.

  3. Renvoie un std::bitset<N> contenant le résultat du XOR binaire sur les paires de bits correspondantes de lhs et rhs.

Paramètres

  • lhs — le bitset situé à gauche de l'opérateur
  • rhs — le bitset situé à droite de l'opérateur

Valeur de retour

  1. std::bitset<N>(lhs) &= rhs

  2. std::bitset<N>(lhs) |= rhs

  3. std::bitset<N>(lhs) ^= rhs

Exemple

#include <bitset>
#include <iostream>

int main()
{
    std::bitset<4> b1("0110");
    std::bitset<4> b2("0011");

    std::cout << "b1 & b2: " << (b1 & b2) << '\n';
    std::cout << "b1 | b2: " << (b1 | b2) << '\n';
    std::cout << "b1 ^ b2: " << (b1 ^ b2) << '\n';
}

Output:

b1 & b2: 0010
b1 | b2: 0111
b1 ^ b2: 0101
