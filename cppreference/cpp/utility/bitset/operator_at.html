std::bitset<N>::operator[]

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool operator[]( std::size_t pos ) const;  // (1) (constexpr depuis C++11)

reference operator[]( std::size_t pos );  // (2) (constexpr depuis C++23)

Accède au bit à la position pos. La première version renvoie la valeur du bit, la seconde version renvoie un objet de type std::bitset::reference permettant de modifier la valeur.

Contrairement à test(), ne lève pas d'exceptions : le comportement est indéfini si pos est hors limites.

Paramètres

  • pos — position du bit à renvoyer

Valeur de retour

  1. La valeur du bit demandé.

  2. Un objet de type std::bitset::reference, permettant d'écrire dans le bit demandé.

Exceptions

(aucune)

Exemple

#include <bitset>
#include <cstddef>
#include <iostream>

int main()
{
    std::bitset<8> b1{0b00101010}; // littéral binaire pour 42

    for (std::size_t i = 0; i < b1.size(); ++i)
        std::cout << "b1[" << i << "]: " << b1[i] << '\n';
    b1[0] = true; // modifie le premier bit via bitset::reference

    std::cout << "After setting bit 0, b1 holds " << b1 << '\n';
}

Output:

b1[0]: 0
b1[1]: 1
b1[2]: 0
b1[3]: 1
b1[4]: 0
b1[5]: 1
b1[6]: 0
b1[7]: 0
After setting bit 0, b1 holds 00101011
