std::bitset<N>::reference

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

class reference;

La classe std::bitset inclut std::bitset::reference comme classe imbriquée accessible publiquement. Cette classe sert d'objet mandataire pour permettre aux utilisateurs d'interagir avec les bits individuels d'un bitset, car les types C++ standard (comme les références et les pointeurs) ne sont pas suffisamment précis pour désigner des bits individuels.

L'utilisation principale de std::bitset::reference est de fournir une lvalue pouvant être renvoyée par operator[].

Toute lecture ou écriture dans un bitset effectuée via un std::bitset::reference peut potentiellement lire ou écrire dans l'ensemble du bitset sous-jacent.

Fonctions membres

  • (constructeur) — construit la référence. Il n'existe pas de constructeur par défaut. Le constructeur de copie est [implicitement déclaré (jusqu'à C++11) | par défaut (depuis C++11)]. Il peut exister un constructeur interne accessible uniquement à std::bitset lui-même. (fonction membre publique)
  • (destructeur) — détruit la référence (fonction membre publique)
  • operator= — affecte une bool au bit référencé (fonction membre publique)
  • operator bool — renvoie le bit référencé (fonction membre publique)
  • operator~ — renvoie le bit référencé inversé (fonction membre publique)
  • flip — bascule le bit référencé (fonction membre publique)

Exemple

#include <bitset>
#include <iostream>

int main()
{
    std::bitset<4> bs{0b1110};
    std::bitset<4>::reference ref = bs[2];

    auto info = [&](int id)
    {
        std::cout << id << ") bs: " << bs << "; ref bit: " << ref << '\n';
    };

    info(1);
    ref = false;
    info(2);
    ref = true;
    info(3);
    ref.flip();
    info(4);
    ref = bs[1]; // operator=( const reference& x )
    info(5);

    std::cout << "6) ~ref bit: " << ~ref << '\n';
}

Output:

1) bs: 1110; ref bit: 1
2) bs: 1010; ref bit: 0
3) bs: 1110; ref bit: 1
4) bs: 1010; ref bit: 0
5) bs: 1110; ref bit: 1
6) ~ref bit: 0
