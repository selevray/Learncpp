std::bitset<N>::operator&=,|=,^=,~

bitset& operator&=( const bitset& other );  // (1) (noexcept depuis C++11) (constexpr depuis C++23)

bitset& operator|=( const bitset& other );  // (2) (noexcept depuis C++11) (constexpr depuis C++23)

bitset& operator^=( const bitset& other );  // (3) (noexcept depuis C++11) (constexpr depuis C++23)

bitset operator~() const;  // (4) (noexcept depuis C++11) (constexpr depuis C++23)

Effectue les opérations ET, OU, XOR et NON binaires.

  1. Affecte aux bits le résultat du AND binaire sur les paires de bits correspondantes de *this et other.

  2. Affecte aux bits le résultat du OR binaire sur les paires de bits correspondantes de *this et other.

  3. Affecte aux bits le résultat du XOR binaire sur les paires de bits correspondantes de *this et other.

  4. Renvoie une copie temporaire de *this dont tous les bits sont inversés (NOT binaire).

Notez que &=, |= et ^= ne sont définis que pour des bitsets de même taille N.

Paramètres

  • other — un autre bitset

Valeur de retour

1-3) *this

  1. std::bitset<N>(*this).flip()

Exemple

#include <bitset>
#include <cstddef>
#include <iostream>
#include <string>

int main()
{
    const std::string pattern_str{"1001"};
    std::bitset<16> pattern{pattern_str}, dest;

    for (std::size_t i = dest.size() / pattern_str.size(); i != 0; --i)
    {
        dest <<= pattern_str.size();
        dest |= pattern;
        std::cout << dest << " (i = " << i << ")\n";
    }

    std::cout << ~dest << " (~dest)\n";
}

Output:

0000000000001001 (i = 4)
0000000010011001 (i = 3)
0000100110011001 (i = 2)
1001100110011001 (i = 1)
0110011001100110 (~dest)
