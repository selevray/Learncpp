std::bitset<N>::count

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

std::size_t count() const;  // (noexcept depuis C++11) (constexpr depuis C++23)

Renvoie le nombre de bits qui sont activés à true.

Valeur de retour

Nombre de bits activés à true.

Exemple

#include <bitset>
#include <iostream>

constexpr auto popcount(unsigned x) noexcept
{
    unsigned num{};
    for (; x; ++num, x &= (x - 1));
    return num;
};
static_assert(popcount(0b101010) == std::bitset<8>{0b101010}.count());

int main()
{
    std::bitset<8> b("00010010");
    std::cout << "Initial value: " << b << '\n';

    // Trouver le premier bit non activé
    std::size_t idx = 0;
    while (idx < b.size() && b.test(idx))
        ++idx;

    // Continuer à activer des bits jusqu'à ce que la moitié du bitset soit remplie
    while (idx < b.size() && b.count() < b.size() / 2)
    {
        b.set(idx);
        std::cout << "Setting bit " << idx << ": " << b << '\n';
        while (idx < b.size() && b.test(idx))
            ++idx;
    }
}

Output:

Initial value: 00010010
Setting bit 0: 00010011
Setting bit 2: 00010111
