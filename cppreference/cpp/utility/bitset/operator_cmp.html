std::bitset<N>::operator==, std::bitset<N>::operator!=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool operator==( const bitset& rhs ) const;  // (1) (noexcept depuis C++11) (constexpr depuis C++23)

bool operator!=( const bitset& rhs ) const;  // (2) (noexcept depuis C++11) (jusqu'à C++20)

  1. Renvoie true si tous les bits de *this et rhs sont égaux.

  2. Renvoie true si au moins un bit de *this et rhs diffère.

L'opérateur != est synthétisé à partir de operator==.

(depuis C++20)

Paramètres

  • rhs — bitset à comparer

Valeur de retour

  1. true si la valeur de chaque bit de *this est égale à la valeur du bit correspondant de rhs, sinon false.

  2. true si !(*this == rhs), sinon false.

Exemple

Compare les bitsets donnés pour déterminer s'ils sont identiques :

#include <bitset>
#include <iostream>

int main()
{
    std::bitset<4> b1(0b0011);
    std::bitset<4> b2(b1);
    std::bitset<4> b3(0b0100);

    std::cout << std::boolalpha;
    std::cout << "b1 == b2: " << (b1 == b2) << '\n';
    std::cout << "b1 == b3: " << (b1 == b3) << '\n';
    std::cout << "b1 != b3: " << (b1 != b3) << '\n';

//  b1 == std::bitset<3>{}; // erreur de compilation : types incompatibles
}

Output:

b1 == b2: true
b1 == b3: false
b1 != b3: true
