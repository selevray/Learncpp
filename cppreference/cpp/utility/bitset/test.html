std::bitset<N>::test

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool test( std::size_t pos ) const;  // (constexpr depuis C++23)

Renvoie la valeur du bit à la position pos (comptée à partir de 0).

Contrairement à operator[], elle effectue une vérification des bornes.

Paramètres

  • pos — position du bit à renvoyer (comptée à partir de 0)

Valeur de retour

true si le bit demandé est à 1, false sinon.

Exceptions

Lève std::out_of_range si pos ne correspond pas à une position de bit valide.

Exemple

#include <bit>
#include <bitset>
#include <cassert>
#include <iostream>
#include <stdexcept>

int main()
{
    std::bitset<10> b1("1111010000");

    std::size_t idx = 0;
    while (idx < b1.size() && !b1.test(idx))
        ++idx;

    assert(static_cast<int>(idx) == std::countr_zero(b1.to_ulong()));

    if (idx < b1.size())
        std::cout << "The first set bit is at index " << idx << '\n';
    else
        std::cout << "no set bits\n";

    try
    {
        std::bitset<0B10'1001'1010> bad;
        if (bad.test(bad.size()))
            std::cout << "Expect unexpected!\n";
    }
    catch (std::out_of_range const& ex)
    {
        std::cout << "Exception: " << ex.what() << '\n';
    }
}
