Convertit le contenu du bitset en chaîne de caractères. Utilise zero pour représenter les bits de valeur false et one pour représenter les bits de valeur true.

La chaîne résultante contient N caractères, le premier caractère correspondant au dernier bit (le N-1e) et le dernier caractère correspondant au premier bit.

Tous les arguments de type de modèle doivent être fournis, car les modèles de fonction ne peuvent pas avoir d'arguments de modèle par défaut. Les surcharges (2-4) sont fournies pour simplifier les appels de to_string :

  1. Utilise l'allocateur par défaut std::allocator.

  2. Utilise le trait de caractère par défaut std::char_traits et l'allocateur par défaut std::allocator.

  3. Utilise le type de caractère par défaut char, le trait de caractère par défaut std::char_traits et l'allocateur par défaut std::allocator.

(jusqu'à C++11)

Paramètres

  • zero — caractère à utiliser pour représenter false
  • one — caractère à utiliser pour représenter true

Valeur de retour

  1. La chaîne convertie.

  2. to_string<CharT, Traits, std::allocator<CharT>>(zero, one).

  3. to_string<CharT, std::char_traits<CharT>, std::allocator<CharT>>(zero, one).

  4. to_string<char, std::char_traits<char>, std::allocator<char>>(zero, one).

Exceptions

Peut lever std::bad_alloc depuis le constructeur std::basic_string.

Notes

Depuis C++11, les modèles de fonction peuvent avoir des arguments de modèle par défaut. LWG issue 1113 a supprimé les surcharges auxiliaires (2-4) et ajouté les arguments de modèle par défaut correspondants dans (1).

Exemple

#include <bitset>
#include <iostream>

int main()
{
    std::bitset<8> b{42};
    std::cout << b.to_string() << '\n'
              << b.to_string('*') << '\n'
              << b.to_string('O', 'X') << '\n';
}

Output:

00101010
**1*1*1*
OOXOXOXO

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

LWG 853 C++98 les surcharges (2-4) n'avaient pas les arguments par défaut ajoutés par LWG issue 396 également ajouté
