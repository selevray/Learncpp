Effectue un décalage binaire à gauche (vers les positions d'indice plus élevé) et un décalage binaire à droite (vers les positions d'indice plus bas). Des zéros sont introduits, et les bits qui sortiraient vers un indice hors limites sont supprimés (ignorés).

1,2) Effectue un décalage binaire à gauche. La version (2) est destructive, c'est-à-dire qu'elle effectue le décalage sur l'objet courant.

3,4) Effectue un décalage binaire à droite. La version (4) est destructive, c'est-à-dire qu'elle effectue le décalage sur l'objet courant.

Paramètres

  • pos — nombre de positions dont décaler les bits

Valeur de retour

1,3) Nouvel objet bitset contenant les bits décalés.

2,4) *this

Exemple

#include <bitset>
#include <iostream>

int main()
{
    std::bitset<8> b{0b01110010};
    std::cout << b << " (initial value)\n";

    for (; b.any(); b >>= 1)
    {
        while (!b.test(0))
            b >>= 1;
        std::cout << b << '\n';
    }

    std::cout << b << " (final value)\n";
}

Output:

01110010 (initial value)
00111001
00000111
00000011
00000001
00000000 (final value)
