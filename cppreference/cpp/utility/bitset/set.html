std::bitset<N>::set

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bitset& set();  // (1) (noexcept depuis C++11) (constexpr depuis C++23)

bitset& set( std::size_t pos, bool value = true );  // (2) (constexpr depuis C++23)

Met tous les bits à true ou met un seul bit à la valeur spécifiée.

  1. Met tous les bits à true.

  2. Met le bit à la position pos à la valeur value.

Paramètres

  • pos — la position (comptée à partir de 0, c'est-à-dire du bit de poids faible au bit de poids fort) du bit à mettre à jour
  • value — la valeur à affecter au bit

Valeur de retour

*this

Exceptions

  1. Lève std::out_of_range si pos ne correspond pas à une position de bit valide.

Exemple

#include <bitset>
#include <cstddef>
#include <iostream>

int main()
{
    std::bitset<8> b;
    std::cout << b << '\n';
    std::cout << b.set() << '\n';
    std::cout << b.reset() << '\n';

    for (std::size_t i = 1; i < b.size(); i += 2)
        b.set(i);

    std::cout << b << '\n';
}

Output:

00000000
11111111
00000000
10101010
