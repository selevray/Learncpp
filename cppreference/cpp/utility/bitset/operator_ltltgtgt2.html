operator<<,>>(std::bitset)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <bitset>

template< class CharT, class Traits, std::size_t N >
std::basic_ostream<CharT, Traits>&
    operator<<( std::basic_ostream<CharT, Traits>& os, const std::bitset<N>& x );  // (1)

template< class CharT, class Traits, std::size_t N >
std::basic_istream<CharT, Traits>&
    operator>>( std::basic_istream<CharT, Traits>& is, std::bitset<N>& x );  // (2)

Insère ou extrait un bitset depuis un flux de caractères.

  1. Écrit le bitset x dans le flux de caractères os comme si on le convertissait d'abord en std::basic_string<CharT, Traits> à l'aide de to_string(), puis qu'on l'écrivait dans os à l'aide de operator<< (qui est un FormattedOutputFunction pour les chaînes).
    Les caractères utilisés pour les uns et les zéros sont obtenus à partir de la locale courante du flux en appelant std::use_facet<std::ctype<CharT>>(os.getloc()).widen() avec '1' et '0' comme arguments.

  2. Se comporte comme un FormattedInputFunction. Après la construction et la vérification de l'objet sentry, qui peut ignorer les espaces initiaux, extrait jusqu'à N caractères de is et les stocke dans le bitset x.
    Les caractères sont extraits jusqu'à ce que

  • N caractères aient été lus,
  • une fin de fichier survienne dans is, ou
  • le caractère suivant ne soit ni is.widen('0') ni is.widen('1').

Si N > 0 et qu'aucun caractère n'est extrait, is.setstate(ios_base::failbit) est appelée.

Paramètres

  • os — le flux de caractères dans lequel écrire
  • is — le flux de caractères depuis lequel lire
  • x — le bitset à lire ou à écrire

Valeur de retour

  1. os

  2. is

Exemple

#include <bitset>
#include <iostream>
#include <sstream>

int main()
{
    std::string bit_string = "001101";
    std::istringstream bit_stream(bit_string);

    std::bitset<3> b1;
    bit_stream >> b1; // lit "001", le flux contient toujours "101"
    std::cout << b1 << '\n';

    std::bitset<8> b2;
    bit_stream >> b2; // lit "101", remplit l'ensemble de 8 bits avec "00000101"
    std::cout << b2 << '\n';
}

Output:

001
00000101
