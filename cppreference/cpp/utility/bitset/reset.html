std::bitset<N>::reset

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bitset& reset();  // (1) (noexcept depuis C++11) (constexpr depuis C++23)

bitset& reset( std::size_t pos );  // (2) (constexpr depuis C++23)

Met les bits à false.

  1. Met tous les bits à false

  2. Met le bit à la position pos à false.

Paramètres

  • pos — la position du bit à mettre à jour

Valeur de retour

*this

Exceptions

  1. Lève std::out_of_range si pos ne correspond pas à une position de bit valide.

Exemple

#include <bitset>
#include <iostream>

int main()
{
    std::bitset<8> b(42);
    std::cout << "Bitset is         " << b << '\n';
    b.reset(1);
    std::cout << "After b.reset(1): " << b << '\n';
    b.reset();
    std::cout << "After b.reset():  " << b << '\n';
}

Output:

Bitset is         00101010
After b.reset(1): 00101000
After b.reset():  00000000
