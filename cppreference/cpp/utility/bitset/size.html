std::bitset<N>::size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

std::size_t size() const;  // (noexcept depuis C++11) (constexpr depuis C++11)

Renvoie le nombre de bits que contient le bitset.

Paramètres

(aucune)

Valeur de retour

nombre de bits que contient le bitset, c'est-à-dire le paramètre de modèle N.

Exemple

#include <bitset>
#include <iostream>

int main()
{
    std::cout << std::bitset<0x400>().size() << '\n';
}

Output:

1024
