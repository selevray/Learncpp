std::bitset<N>::flip

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bitset& flip();  // (1) (noexcept depuis C++11) (constexpr depuis C++23)

bitset& flip( std::size_t pos );  // (2) (constexpr depuis C++23)

Inverse les bits, c'est-à-dire remplace les valeurs true par false et les valeurs false par true. Équivalent à une opération NOT logique sur une partie ou la totalité du bitset.

  1. Inverse tous les bits (comme operator~, mais sur place).

  2. Inverse le bit à la position pos.

Paramètres

  • pos — la position du bit à inverser

Valeur de retour

*this

Exceptions

  1. Lève std::out_of_range si pos ne correspond pas à une position de bit valide.

Exemple

#include <bitset>
#include <iostream>

int main()
{
    std::bitset<4> flops;

    std::cout << flops << '\n'
              << flops.flip(0) << '\n'
              << flops.flip(2) << '\n'
              << flops.flip() << '\n';
}

Output:

0000
0001
0101
1010
