Objets fonctions

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un objet fonction est tout objet pour lequel l'opérateur d'appel de fonction est défini. Le C++ fournit de nombreux objets fonctions intégrés ainsi que la prise en charge de la création et de la manipulation de nouveaux objets fonctions.

Invocation de fonctions

L'opération INVOKE(f, arg_0, arg_1, arg_2, ..., arg_N), réservée à l'exposé, est définie comme suit :

Soit le type Obj le type non qualifié de arg_0 (c'est-à-dire std::remove_cv<std::remove_reference<decltype(arg_0)>::type>::type)

  • Si f est un pointeur vers fonction membre de la classe C, alors INVOKE(f, obj, arg_1, arg_2, ..., arg_N) est équivalent à :

  • Si std::is_same<C, Obj>::value || std::is_base_of<C, Obj>::value est true

  • (obj.*f)(arg_1, arg_2, ..., arg_N) (appelle la fonction membre sur l'objet).

  • Si Obj est une spécialisation de std::reference_wrapper

  • (obj.get().*f)(arg_1, arg_2, ..., arg_N) (appelle la fonction membre sur l'objet spécialement référencé).

  • Sinon

  • ((*obj).*f)(arg_1, arg_2, ..., arg_N) (appelle la fonction membre sur l'objet déréférencé).

  • Sinon, si N == 0 et f est un pointeur vers membre de données de la classe C, alors INVOKE(mptr, obj) est équivalent à :

  • Si std::is_same<C, Obj>::value || std::is_base_of<C, Obj>::value est true

  • obj.*mptr (accède au membre de données de l'objet).

  • Si Obj est une spécialisation de std::reference_wrapper

  • obj.get().*mptr (accède au membre de données de l'objet spécialement référencé).

  • Sinon

  • (*obj).*mptr (accède au membre de données de l'objet déréférencé).

  • Sinon

  • INVOKE(f, arg_0, arg_1, arg_2, ..., arg_N) est équivalent à f(arg_0, arg_1, arg_2, ..., arg_N) (appelle l'appelable).

L'opération INVOKE<R>(f, arg_0, arg_1, arg_2, ..., arg_N), réservée à l'exposé, est définie comme suit :

  • Si R est (éventuellement qualifié cv) void

  • static_cast<void>(INVOKE(f, arg_0, arg_1, arg_2, ..., arg_N)).

  • Sinon

  • INVOKE(f, arg_0, arg_1, arg_2, ..., arg_N) est implicitement converti en R.

Soit le type Actual égal à decltype(INVOKE(f, arg_0, arg_1, arg_2, ..., arg_N))

  • Si std::reference_converts_from_temporary_v <R, Actual> est true
  • INVOKE<R>(f, arg_0, arg_1, arg_2, ..., arg_N) est mal formé.

(depuis C++23)

Enveloppes de fonctions

Ces classes d'enveloppes polymorphes permettent de stocker des objets fonctions arbitraires.

  • function (C++11) — enveloppe copiable de tout objet appelable copiable (modèle de classe)
  • move_only_function (C++23) — enveloppe uniquement déplaçable de tout objet appelable prenant en charge les qualificateurs dans une signature d'appel donnée (modèle de classe)
  • copyable_function (C++26) — enveloppe copiable de tout objet appelable copiable prenant en charge les qualificateurs dans une signature d'appel donnée (modèle de classe)
  • function_ref (C++26) — enveloppe ne possédant pas l'objet de tout objet appelable (modèle de classe)
  • bad_function_call (C++11) — l'exception levée lors de l'invocation d'un std::function (classe)
  • mem_fn (C++11) — crée un objet fonction à partir d'un pointeur vers membre (modèle de fonction)

Identité

std::identity est l'objet fonction identité : il renvoie son argument inchangé.

  • identity (C++20) — objet fonction qui renvoie son argument sans modification (classe)

Application partielle de fonctions

std::bind_front et std::bind permettent l'application partielle de fonction, c'est-à-dire la liaison d'arguments à des fonctions pour produire de nouvelles fonctions.

  • bind_frontbind_back (C++20) (C++23) — lie un nombre variable d'arguments, dans l'ordre, à un objet fonction (modèle de fonction)
  • bind (C++11) — lie un ou plusieurs arguments à un objet fonction (modèle de fonction)
  • is_bind_expression (C++11) — indique qu'un objet est une expression std::bind ou peut être utilisé comme telle (modèle de classe)
  • is_placeholder (C++11) — indique qu'un objet est un marqueur de place standard ou peut être utilisé comme tel (modèle de classe)

Défini dans l'espace de noms std::placeholders

  • _1, _2, _3, _4, ... (C++11) — marqueurs de place pour les arguments non liés dans une expression std::bind (constante)

Négateurs

std::not_fn crée un objet fonction qui inverse le résultat de l'appelable qui lui est passé.

  • not_fn (C++17) — crée un objet fonction qui renvoie le complément du résultat de l'objet fonction qu'il contient (modèle de fonction)

Chercheurs

Des searchers implémentant plusieurs algorithmes de recherche de chaînes sont fournis et peuvent être utilisés soit directement, soit avec std::search.

  • default_searcher (C++17) — implémentation de l'algorithme de recherche de la bibliothèque standard C++ (modèle de classe)
  • boyer_moore_searcher (C++17) — implémentation de l'algorithme de recherche de Boyer-Moore (modèle de classe)
  • boyer_moore_horspool_searcher (C++17) — implémentation de l'algorithme de recherche de Boyer-Moore-Horspool (modèle de classe)

Enveloppes de références

Les enveloppes de référence permettent de stocker des arguments par référence dans des objets fonctions copiables :

  • reference_wrapper (C++11) — CopyConstructible et CopyAssignable enveloppe de référence (modèle de classe)
  • refcref (C++11) (C++11) — crée un std::reference_wrapper avec un type déduit de son argument (modèle de fonction)
  • unwrap_referenceunwrap_ref_decay (C++20) (C++20) — obtient le type de référence enveloppé dans std::reference_wrapper (modèle de classe)

Objets fonctions transparents

Conteneurs associatifset conteneurs associatifs non ordonnés (depuis C++20) fournissent des opérations de rechercheet d'effacement (depuis C++23) hétérogène, mais elles ne sont activées que si le type d'objet fonction fourni T est transparent ﻿ : l'identifiant qualifié T::is_transparent est valide et désigne un type.

Tous les types d'objets fonctions transparents de la bibliothèque standard définissent un type imbriqué is_transparent. Cependant, les types d'objets fonctions transparents définis par l'utilisateur n'ont pas besoin de fournir directement is_transparent comme type imbriqué : il peut être défini dans une classe de base, à condition que T::is_transparent satisfasse l'exigence de transparence énoncée ci-dessus.

(depuis C++14)

Objets fonctions de comparaison contraints

Les objets fonctions de comparaison suivants sont contraints.

  • Les opérateurs d'égalité (ranges::equal_to et ranges::not_equal_to) exigent que les types des arguments satisfassent equality_comparable_with.
  • Les opérateurs relationnels (ranges::less, ranges::greater, ranges::less_equal et ranges::greater_equal) exigent que les types des arguments satisfassent totally_ordered_with.
  • L'opérateur de comparaison à trois voies (compare_three_way) exige que le type modélise three_way_comparable_with.

Tous ces objets fonctions sont transparents.

  • ranges::equal_to (C++20) — objet fonction contraint implémentant x == y (classe)
  • ranges::not_equal_to (C++20) — objet fonction contraint implémentant x != y (classe)
  • ranges::less (C++20) — objet fonction contraint implémentant x < y (classe)
  • ranges::greater (C++20) — objet fonction contraint implémentant x > y (classe)
  • ranges::less_equal (C++20) — objet fonction contraint implémentant x <= y (classe)
  • ranges::greater_equal (C++20) — objet fonction contraint implémentant x >= y (classe)
  • compare_three_way (C++20) — objet fonction contraint implémentant x <=> y (classe)

Éléments auxiliaires

Les éléments suivants, réservés à l'exposé, sont utilisés par plusieurs composants de la bibliothèque standard mais ne font pas partie de son interface.

template< class Fn, class... Args >
concept /*callable*/ =
    requires (Fn&& fn, Args&&... args) {
        std::forward<Fn>(fn)(std::forward<Args>(args)...);
    };  // (1) ( exposition uniquement* )

template< class Fn, class... Args >
concept /*nothrow-callable*/ =
    /*callable*/<Fn, Args...> &&
    requires (Fn&& fn, Args&&... args) {
        { std::forward<Fn>(fn)(std::forward<Args>(args)...) } noexcept;
    };  // (2) ( exposition uniquement* )

template< class Fn, class... Args >
using /*call-result-t*/ = decltype(std::declval<Fn>()(std::declval<Args>()...));  // (3) ( exposition uniquement* )

template< const auto& T >
using /*decayed-typeof*/ = decltype(auto(T));  // (4) ( exposition uniquement* )

(depuis C++26)
