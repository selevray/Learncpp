std::piecewise_construct, std::piecewise_construct_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <utility>

struct piecewise_construct_t { explicit piecewise_construct_t() = default; };  // (1) (depuis C++11)

constexpr std::piecewise_construct_t piecewise_construct{};  // (2) (depuis C++11) (inline depuis C++17)

  1. std::piecewise_construct_t est un type de balise de classe vide utilisé pour lever l'ambiguïté entre différentes fonctions prenant deux arguments tuple.

  2. La constante std::piecewise_construct est une instance de (1).

Les surcharges qui n'utilisent pas std::piecewise_construct_t supposent que chaque argument tuple devient un élément d'une paire. Les surcharges qui utilisent std::piecewise_construct_t supposent que chaque argument tuple sert à construire, élément par élément, un nouvel objet du type spécifié, qui deviendra l'élément de la paire.

Bibliothèque standard

Les types et fonctions suivants de la bibliothèque standard l'utilisent comme balise de levée d'ambiguïté :

  • pair — implémente un tuple binaire, c'est-à-dire une paire de valeurs (modèle de classe)
  • uses_allocator_construction_args (C++20) — prépare la liste d'arguments correspondant à la variante de construction avec utilisation d'allocateur requise par le type donné (modèle de fonction)
  • ranges::repeat_viewviews::repeat (C++23) — une view constituée d'une séquence générée en produisant répétitivement la même valeur (modèle de classe) (objet point de personnalisation)

Exemple

#include <iostream>
#include <tuple>
#include <utility>

struct Foo
{
    Foo(std::tuple<int, float>)
    {
        std::cout << "Constructed a Foo from a tuple\n";
    }

    Foo(int, float)
    {
        std::cout << "Constructed a Foo from an int and a float\n";
    }
};

int main()
{
    std::tuple<int, float> t(1, 3.14);

    std::cout << "Creating p1...\n";
    std::pair<Foo, Foo> p1(t, t);

    std::cout << "Creating p2...\n";
    std::pair<Foo, Foo> p2(std::piecewise_construct, t, t);
}

Output:

Creating p1...
Constructed a Foo from a tuple
Constructed a Foo from a tuple
Creating p2...
Constructed a Foo from an int and a float
Constructed a Foo from an int and a float
