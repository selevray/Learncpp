std::is_debugger_present

Défini dans l'en-tête <debugging>

bool is_debugger_present() noexcept;  // (depuis C++26)

Tente de déterminer si le programme est exécuté en présence d'un débogueur.

Par défaut, le comportement de cette fonction est entièrement défini par l'implémentation. Un programme C++ peut fournir la définition de cette signature pour remplacer le comportement de cette fonction.

Valeur de retour

La version par défaut retourne true si, à sa connaissance, le programme est exécuté sous un débogueur.

Notes

Cette fonction a pour but de permettre d'afficher des sorties supplémentaires pour aider à diagnostiquer des problèmes, d'exécuter du code de test supplémentaire, d'afficher une interface utilisateur supplémentaire pour faciliter le débogage, etc.

Cette fonction standardise de nombreuses installations similaires existantes : under_debugger de boost.test, IsDebuggerPresent() de l'API Win32, isDebuggerActive de Catch2, IsDebuggerPresent de Unreal Engine, etc.
