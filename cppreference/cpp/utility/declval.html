std::declval

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <utility>

template< class T >
typename std::add_rvalue_reference<T>::type declval() noexcept;  // (depuis C++11) (jusqu'à C++14) (uniquement non évalué)

template< class T >
std::add_rvalue_reference_t<T> declval() noexcept;  // (depuis C++14) (uniquement non évalué)

Modèle auxiliaire pour écrire des expressions apparaissant dans des contextes non évalués, typiquement l'opérande de decltype. Dans un contexte non évalué, ce modèle auxiliaire convertit tout type T (qui peut être un type incomplet) en une expression de ce type, ce qui permet d'utiliser les fonctions membres de T sans passer par les constructeurs.

std::declval ne peut être utilisée que dans des contextes non évalués et n'a pas besoin d'être définie ; c'est une erreur d'évaluer une expression qui contient cette fonction. Formellement, le programme est mal formé si cette fonction est utilisée au sens ODR.

Paramètres

(aucune)

Valeur de retour

Ne peut pas être évaluée et ne renvoie donc jamais de valeur. Le type de retour est T&& (les règles d'effondrement des références s'appliquent) sauf si T est (éventuellement qualifié cv) void, auquel cas le type de retour est T.

Notes

std::declval est couramment utilisée dans les modèles où les paramètres de modèle acceptables peuvent n'avoir aucun constructeur en commun, mais partager la même fonction membre dont le type de retour est nécessaire.

Implémentation possible

template<typename T>
typename std::add_rvalue_reference<T>::type declval() noexcept
{
    static_assert(false, "declval not allowed in an evaluated context");
}

Exemple

#include <iostream>
#include <utility>

struct Default
{
    int foo() const { return 1; }
};

struct NonDefault
{
    NonDefault() = delete;
    int foo() const { return 1; }
};

int main()
{
    decltype(Default().foo())               n1 = 1;     // le type de n1 est int
    decltype(std::declval<Default>().foo()) n2 = 1;     // same

//  decltype(NonDefault().foo())               n3 = n1; // erreur : pas de constructeur par défaut
    decltype(std::declval<NonDefault>().foo()) n3 = n1; // le type de n3 est int

    std::cout << "n1 = " << n1 << '\n'
              << "n2 = " << n2 << '\n'
              << "n3 = " << n3 << '\n';
}

Output:

n1 = 1
n2 = 1
n3 = 1
