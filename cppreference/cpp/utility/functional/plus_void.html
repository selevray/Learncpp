std::plus<void>

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <functional>

template<>
class plus<void>;  // (depuis C++14)

std::plus<void> est une spécialisation de std::plus dont le paramètre et la valeur de retour sont déduits.

Types membres

Type Définition

  • is_transparent — unspecified

Fonctions membres

  • operator() — renvoie la somme de deux arguments (fonction membre publique)

std::plus<void>::operator()

template< class T, class U >
constexpr auto operator()( T&& lhs, U&& rhs ) const
    -> decltype(std::forward<T>(lhs) + std::forward<U>(rhs));

Renvoie la somme de lhs et rhs.

Paramètres

  • lhs, rhs — valeurs à additionner

Valeur de retour

std::forward<T>(lhs) + std::forward<U>(rhs).

Exemple

#include <functional>
#include <iostream>

int main()
{
    auto string_plus = std::plus<void>{}; // « void » peut être omis
    std::string a = "Hello ";
    const char* b = "world";
    std::cout << string_plus(a, b) << '\n';
}

Output:

Hello world
