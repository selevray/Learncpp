std::reference_wrapper

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <functional>

template< class T >
class reference_wrapper;  // (depuis C++11)

std::reference_wrapper est un modèle de classe qui encapsule une référence dans un objet copiable et affectable.

Plus précisément, std::reference_wrapper est un wrapper CopyConstructible et CopyAssignable autour d'une référence vers un objet ou une référence vers une fonction de type T. Les instances de std::reference_wrapper sont des objets (on peut les copier ou les stocker dans des conteneurs), mais elles sont implicitement convertibles en T&, de sorte qu'elles peuvent être utilisées comme arguments des fonctions qui prennent le type sous-jacent par référence.

Si la référence stockée est Callable, std::reference_wrapper peut être appelé avec les mêmes arguments.

Les fonctions auxiliaires std::ref et std::cref sont souvent utilisées pour créer des objets std::reference_wrapper.

std::reference_wrapper sert à transmettre des objets par référence à std::bind, au constructeur de std::thread, ou aux fonctions auxiliaires std::make_pair et std::make_tuple. Il peut aussi servir de mécanisme pour stocker des références dans des conteneurs standard (comme std::vector) qui ne peuvent normalement pas contenir de références.

std::reference_wrapper est garanti être TriviallyCopyable.

(depuis C++17)

T peut être un type incomplet.

Implémentation possible

namespace detail
{
    template<class T> constexpr T& FUN(T& t) noexcept { return t; }
    template<class T> void FUN(T&&) = delete;
}

template<class T>
class reference_wrapper
{
public:
    // types
    using type = T;

    // construction/copie/destruction
    template<class U, class = decltype(
        detail::FUN<T>(std::declval<U>()),
        std::enable_if_t<!std::is_same_v<reference_wrapper, std::remove_cvref_t<U>>>()
    )>
    constexpr reference_wrapper(U&& u)
        noexcept(noexcept(detail::FUN<T>(std::forward<U>(u))))
        : _ptr(std::addressof(detail::FUN<T>(std::forward<U>(u)))) {}

    reference_wrapper(const reference_wrapper&) noexcept = default;

    // assignment
    reference_wrapper& operator=(const reference_wrapper& x) noexcept = default;

    // access
    constexpr operator T& () const noexcept { return *_ptr; }
    constexpr T& get() const noexcept { return *_ptr; }

    template<class... ArgTypes>
    constexpr std::invoke_result_t<T&, ArgTypes...>
        operator() (ArgTypes&&... args ) const
            noexcept(std::is_nothrow_invocable_v<T&, ArgTypes...>)
    {
        return std::invoke(get(), std::forward<ArgTypes>(args)...);
    }

private:
    T* _ptr;
};

// guides de déduction
template<class T>
reference_wrapper(T&) -> reference_wrapper<T>;

Exemple

Démontre l'utilisation de std::reference_wrapper comme conteneur de références, ce qui permet d'accéder au même conteneur via plusieurs indices.

#include <algorithm>
#include <functional>
#include <iostream>
#include <list>
#include <numeric>
#include <random>
#include <vector>

void println(auto const rem, std::ranges::range auto const& v)
{
    for (std::cout << rem; auto const& e : v)
        std::cout << e << ' ';
    std::cout << '\n';
}

int main()
{
    std::list<int> l(10);
    std::iota(l.begin(), l.end(), -4);

    // impossible d'utiliser shuffle sur une list (qui requiert un accès aléatoire), mais on peut l'utiliser sur un vector
    std::vector<std::reference_wrapper<int>> v(l.begin(), l.end());

    std::ranges::shuffle(v, std::mt19937{std::random_device{}()});

    println("Contents of the list: ", l);
    println("Contents of the list, as seen through a shuffled vector: ", v);

    std::cout << "Doubling the values in the initial list...\n";
    std::ranges::for_each(l, [](int& i) { i *= 2; });

    println("Contents of the list, as seen through a shuffled vector: ", v);
}
