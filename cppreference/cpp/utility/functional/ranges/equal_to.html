Objet fonction effectuant des comparaisons. Les types des paramètres de l'opérateur d'appel de fonction (mais pas le type de retour) sont déduits des arguments.

  • operator() — vérifie si les arguments sont égaux (fonction membre publique)

std::ranges::equal_to::operator()

template< class T, class U >
constexpr bool operator()( T&& t, U&& u ) const;

Étant donnée l'expression std::forward<T>(t) == std::forward<U>(u) comme expr :

  • Si expr produit un appel à l'opérateur intégré operator== comparant des pointeurs, en prenant le type de pointeur composite de t et u comme P :

    • Pour les deux pointeurs convertis (de type P), si un pointeur précède l'autre dans l'ordre total strict défini par l'implémentation sur les pointeurs, renvoie false, sinon renvoie true.
    • Si la séquence de conversion de T vers P ou la séquence de conversion de U vers P n'est pas préservant l'égalité, le comportement est indéfini.

  • Otherwise:

    • Renvoie le résultat de expr.
    • Si std::equality_comparable_with<T, U> n'est pas modélisé, le comportement est indéfini.

Cette surcharge ne participe à la résolution de surcharge que si std::equality_comparable_with<T, U> est satisfait.

Notes

Par rapport à std::equal_to, std::ranges::equal_to exige en plus que != soit valide, et que les deux types d'arguments soient comparables (de manière homogène) avec eux-mêmes (via la contrainte equality_comparable_with).
