Objet fonction effectuant des comparaisons. Déduit les types des paramètres de l'opérateur d'appel de fonction à partir des arguments (mais pas le type de retour).

std::ranges::less::operator()

template< class T, class U >
constexpr bool operator()( T&& t, U&& u ) const;

Étant donnée l'expression std::forward<T>(t) < std::forward<U>(u) comme expr :

  • Si expr produit un appel à l'opérateur intégré operator< comparant des pointeurs, en prenant le type de pointeur composite de t et u comme P :

    • Si le t converti précède le u converti (tous deux de type P) dans l'ordre total strict défini par l'implémentation sur les pointeurs, renvoie true, sinon renvoie false.
    • Si la séquence de conversion de T vers P ou la séquence de conversion de U vers P n'est pas préservant l'égalité, le comportement est indéfini.

  • Otherwise:

    • Renvoie le résultat de expr.
    • Si std::totally_ordered_with<T, U> n'est pas modélisé, le comportement est indéfini.

Cette surcharge ne participe à la résolution de surcharge que si std::totally_ordered_with<T, U> est satisfait.

S'il existe une expression expr1 de type T et une expression expr2 de U, telles que les résultats de comparaison de expr1 et expr2 violent le strict ordre total (les règles sont définies ci-dessous), le comportement est indéfini.

Les résultats de comparaison de expr1 et expr2 suivent un strict ordre total seulement si exactement une des expressions suivantes est true :

  • std::ranges::less{}(expr1, expr2)
  • std::ranges::less{}(expr2, expr1)
  • std::ranges::equal_to{}(expr1, expr2)

Notes

Contrairement à std::less, std::ranges::less exige que les six opérateurs de comparaison <, <=, >, >=, == et != soient valides (via la contrainte totally_ordered_with).
