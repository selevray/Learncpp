operator==(std::move_only_function)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

friend bool operator==( const std::move_only_function& f, std::nullptr_t ) noexcept;  // (depuis C++23)

Vérifie si l'enveloppe f possède une cible appelable en la comparant formellement à std::nullptr_t. Les enveloppes vides (c'est-à-dire sans cible) se comparent égales, les fonctions non vides se comparent non égales.

Cette fonction n'est pas visible par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peut être trouvée que par la recherche dépendante des arguments lorsque std::move_only_function<FunctionType> est une classe associée aux arguments.

L'opérateur != est synthétisé à partir de operator==.

Paramètres

  • f — std::move_only_function à comparer

Valeur de retour

!f.

Exemple

#include <functional>
#include <iostream>
#include <utility>

using SomeVoidFunc = std::move_only_function<void(int) const>;

class C {
public:
    C() = default;
    C(SomeVoidFunc func) : void_func_(std::move(func)) {}

    void default_func(int i) const { std::cout << i << '\n'; };

    void operator()() const
    {
        if (void_func_ == nullptr) // comparaison spécialisée avec nullptr
            default_func(7);
        else
            void_func_(7);
    }

private:
    SomeVoidFunc void_func_{};
};

void user_func(int i)
{
    std::cout << (i + 1) << '\n';
}

int main()
{
    C c1;
    C c2(user_func);
    c1();
    c2();
}

Output:

7
8
