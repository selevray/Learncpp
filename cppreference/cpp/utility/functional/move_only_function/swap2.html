swap(std::move_only_function)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

friend void swap( std::move_only_function& lhs, std::move_only_function& rhs ) noexcept;  // (depuis C++23)

Surcharge l'algorithme std::swap pour std::move_only_function. Échange l'état de lhs avec celui de rhs. Appelle effectivement lhs.swap(rhs).

Cette fonction n'est pas visible par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peut être trouvée que par la recherche dépendante des arguments lorsque std::move_only_function<FunctionType> est une classe associée aux arguments.

Paramètres

  • lhs, rhs — objets std::move_only_function dont les états doivent être échangés

Valeur de retour

(aucune)

Exemple

#include <concepts>
#include <functional>
#include <iostream>

void foo(const char* str, int x)
{
    std::cout << "foo(\"" << str << "\", " << x << ")\n";
}

void bar(const char* str, int x)
{
    std::cout << "bar(\"" << str << "\", " << x << ")\n";
}

int main()
{
    std::move_only_function<void(const char*, int) const> f1{foo};
    std::move_only_function<void(const char*, int) const> f2{bar};

    f1("f1", 1);
    f2("f2", 2);

    std::cout << "std::ranges::swap(f1, f2);\n";
    std::ranges::swap(f1, f2); // trouve l'ami caché

    f1("f1", 1);
    f2("f2", 2);
}

Output:

foo("f1", 1)
bar("f2", 2)
std::ranges::swap(f1, f2);
bar("f1", 1)
foo("f2", 2)
