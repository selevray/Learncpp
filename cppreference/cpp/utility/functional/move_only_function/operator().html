std::move_only_function::operator()

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

R operator()( Args... args ) /*cv*/ /*ref*/ noexcept(/*noex*/);  // (depuis C++23)

Invoque la cible appelable stockée avec les paramètres args. Les parties /*cv*/, /*ref*/ et /*noex*/ de operator() sont identiques à celles du paramètre de modèle de std::move_only_function.

Équivalent à return std::invoke_r<R>(/*cv-ref-cast*/(f), std::forward<Args>(args)...);, où f est une lvalue non qualifiée cv désignant l'objet cible de *this, et /*cv-ref-cast*/(f) est équivalent à :

  • f si cv ref est soit vide, soit &, ou
  • std::as_const(f) si cv ref est soit const, soit const &, ou
  • std::move(f) si cv ref est &&, ou
  • std::move(std::as_const(f)) si cv ref est const &&.

Le comportement est indéfini si *this est vide.

Paramètres

  • args — paramètres à transmettre à la cible appelable stockée

Valeur de retour

std::invoke_r<R>(/*cv-ref-cast*/(f), std::forward<Args>(args)...).

Exceptions

Propage l'exception levée par l'appel de fonction sous-jacent.

Exemple

L'exemple suivant montre comment std::move_only_function peut être passé par valeur à d'autres fonctions. Il montre également comment std::move_only_function peut stocker des lambdas.

#include <iostream>
#include <functional>

void call(std::move_only_function<int() const> f)  // peut être passé par valeur
{
    std::cout << f() << '\n';
}

int normal_function()
{
    return 42;
}

int main()
{
    int n = 1;
    auto lambda = [&n](){ return n; };
    std::move_only_function<int() const> f = lambda;
    call(std::move(f));

    n = 2;
    call(lambda);

    f = normal_function;
    call(std::move(f));
}

Output:

1
2
42
