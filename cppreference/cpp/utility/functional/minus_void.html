std::minus<void>

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <functional>

template<>
class minus<void>;  // (depuis C++14)

std::minus<void> est une spécialisation de std::minus dont le paramètre et la valeur de retour sont déduits.

Types membres

Type Définition

  • is_transparent — unspecified

Fonctions membres

  • operator() — renvoie la différence des deux arguments (fonction membre publique)

std::minus<void>::operator()

template< class T, class U >
constexpr auto operator()( T&& lhs, U&& rhs ) const
    -> decltype(std::forward<T>(lhs) - std::forward<U>(rhs));

Renvoie la différence de lhs et rhs.

Paramètres

  • lhs, rhs — valeurs à soustraire

Valeur de retour

std::forward<T>(lhs) - std::forward<U>(rhs).

Exemple

#include <complex>
#include <functional>
#include <iostream>

int main()
{
    auto complex_minus = std::minus<void>{}; // « void » peut être omis
    constexpr std::complex<int> z(4, 2);
    std::cout << complex_minus(z, 1) << '\n';
    std::cout << (z - 1) << '\n';
}

Output:

(3,2)
(3,2)
