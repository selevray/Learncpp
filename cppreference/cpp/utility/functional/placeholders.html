L'espace de noms std::placeholders contient les objets substituts [_1, ..., _N] où N est un nombre maximal défini par l'implémentation.

Lorsqu'ils sont utilisés comme argument d'une expression std::bind, les objets substituts sont stockés dans l'objet fonction généré, et lorsque cet objet fonction est invoqué avec des arguments non liés, chaque substitut _N est remplacé par le N-ième argument non lié correspondant.

Chaque substitut est déclaré comme si par extern /*unspecified*/ _1;.

(jusqu'à C++17)

Les implémentations sont encouragées à déclarer les substituts comme si par inline constexpr /*unspecified*/ _1;, bien que la norme autorise encore leur déclaration par extern /*unspecified*/ _1;.

(depuis C++17)

Les types des objets substituts sont DefaultConstructible et CopyConstructible, leurs constructeurs de copie et de déplacement par défaut ne lèvent pas d'exception, et pour tout substitut _N, le type std::is_placeholder<decltype(_N)> est défini, où std::is_placeholder<decltype(_N)> dérive de std::integral_constant<int, N>.

Exemple

Le code suivant montre la création d'objets fonctions avec des arguments substituts.

#include <functional>
#include <iostream>
#include <string>

void goodbye(const std::string& s)
{
    std::cout << "Goodbye " << s << '\n';
}

class Object
{
public:
    void hello(const std::string& s)
    {
        std::cout << "Hello " << s << '\n';
    }
};

int main()
{
    using namespace std::placeholders;

    using ExampleFunction = std::function<void(const std::string&)>;
    Object instance;
    std::string str("World");

    ExampleFunction f = std::bind(&Object::hello, &instance, _1);
    f(str); // équivalent à instance.hello(str)

    f = std::bind(&goodbye, std::placeholders::_1);
    f(str); // équivalent à goodbye(str)

    auto lambda = [](std::string pre, char o, int rep, std::string post)
    {
        std::cout << pre;
        while (rep-- > 0)
            std::cout << o;
        std::cout << post << '\n';
    };

    // liaison de la lambda :
    std::function<void(std::string, char, int, std::string)> g =
        std::bind(&decltype(lambda)::operator(), &lambda, _1, _2, _3, _4);
    g("G", 'o', 'o'-'g', "gol");
}

Output:

Hello World
Goodbye World
Goooooooogol
