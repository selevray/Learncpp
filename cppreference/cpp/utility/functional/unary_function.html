std::unary_function

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <functional>

template< typename ArgumentType, typename ResultType >
struct unary_function;  // (obsolète en C++11) (supprimé en C++17)

std::unary_function est une classe de base permettant de créer des objets fonctions à un argument.

std::unary_function ne définit pas operator() ; on s'attend à ce que les classes dérivées le définissent. std::unary_function fournit seulement deux types - argument_type et result_type - définis par les paramètres de modèle.

Certains adaptateurs d'objets fonctions de la bibliothèque standard, comme std::not1, exigent que les objets fonctions qu'ils adaptent définissent certains types ; std::not1 exige que l'objet fonction adapté possède un type nommé argument_type. Dériver des objets fonctions à un argument de std::unary_function est un moyen simple de les rendre compatibles avec ces adaptateurs.

std::unary_function est obsolète en C++11.

Types membres

Type Définition

  • argument_type — ArgumentType
  • result_type — ResultType

Exemple

#include <algorithm>
#include <functional>
#include <iostream>
#include <vector>

struct less_than_7 : std::unary_function<int, bool>
{
    bool operator()(int i) const { return i < 7; }
};

int main()
{
    std::vector<int> v(10, 7);
    v[0] = v[1] = v[2] = 6;

    std::cout << std::count_if(v.begin(), v.end(), std::not1(less_than_7()));

    // C++11 solution:
    // Convertir d'une façon ou d'une autre en std::function<bool (int)> - même avec une lambda
    // std::cout << std::count_if(v.begin(), v.end(),
    //     std::not1(std::function<bool (int)>([](int i) { return i < 7; })));
}

Output:

7
