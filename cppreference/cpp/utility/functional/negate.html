template< class T >

template< class T = void >
struct negate;  // (depuis C++14)

Objet fonction permettant d'effectuer une négation. Appelle effectivement operator- sur une instance du type T.

Spécialisations

La bibliothèque standard fournit une spécialisation de std::negate lorsque T n'est pas spécifié, ce qui laisse les types des paramètres et le type de retour à déduire.

  • negate<void> (C++14) — objet fonction implémentant -x déduisant les types des paramètres et de la valeur de retour (spécialisation de modèle de classe)

(depuis C++14)

Renvoie l'opposé de arg.

Paramètres

  • arg — valeur dont calculer l'opposé

Valeur de retour

Le résultat de -arg.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Implémentation possible
