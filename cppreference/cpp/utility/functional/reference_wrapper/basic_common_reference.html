Le type de référence commune d'un reference_wrapper (noté R) et d'un type T, appliqués respectivement avec les qualificateurs cv et de référence (notés RQ et TQ), est équivalent à un type de référence commune du type sous-jacent de R appliqué avec une référence lvalue et le TQ.

Le type de référence commune n'est défini que si R est le seul reference_wrapper, et que le type sous-jacent de R appliqué avec une référence lvalue et le TQ ont un type de référence commune vers lequel RQ doit être convertible.

La constante réservée à l'exposition /*is-ref-wrapper*/<R> vaut true si et seulement si R est une spécialisation de std::reference_wrapper.
