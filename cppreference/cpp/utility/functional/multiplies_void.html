std::multiplies<void>

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <functional>

template<>
class multiplies<void>;  // (depuis C++14)

std::multiplies<void> est une spécialisation de std::multiplies dont le paramètre et la valeur de retour sont déduits.

Types membres

Type Définition

  • is_transparent — unspecified

Fonctions membres

  • operator() — renvoie le produit de deux arguments (fonction membre publique)

std::multiplies<void>::operator()

template< class T, class U >
constexpr auto operator()( T&& lhs, U&& rhs ) const
    -> decltype(std::forward<T>(lhs) * std::forward<U>(rhs));

Renvoie le produit de lhs et rhs.

Paramètres

  • lhs, rhs — valeurs à multiplier

Valeur de retour

std::forward<T>(lhs) * std::forward<U>(rhs).

Exemple

#include <complex>
#include <functional>
#include <iostream>

int main()
{
    auto complex_multiplies = std::multiplies<void>{}; // « void » peut être omis
    constexpr std::complex z1{1.0, 2.0}, z2{3.0, 4.0};

    std::cout << std::showpos
              << complex_multiplies(z1, z2) << ' ' << z1 * z2 << '\n'
              << complex_multiplies(z1, 5.) << ' ' << z1 * 5. << '\n'
              << complex_multiplies(5., z1) << ' ' << 5. * z1 << '\n';
}

Output:

(-5,+10) (-5,+10)
(+5,+10) (+5,+10)
(+5,+10) (+5,+10)
