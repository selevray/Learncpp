std::bit_not

Défini dans l'en-tête <functional>

template< class T = void >
struct bit_not;  // (depuis C++14)

Objet fonction effectuant un NON bit à bit. Appelle effectivement operator~ sur le type T.

Spécialisations

La bibliothèque standard fournit une spécialisation de std::bit_not lorsque T n'est pas spécifié, ce qui laisse les types des paramètres et le type de retour à déduire.

  • bit_not<void> (C++14) — objet fonction implémentant ~x déduisant les types des paramètres et de la valeur de retour (spécialisation de modèle de classe)

Types membres

Type Définition

  • result_type (obsolète en C++17) (supprimé en C++20) — T
  • argument_type (obsolète en C++17) (supprimé en C++20) — T

Fonctions membres

  • operator() (C++14) — renvoie le résultat du NON bit à bit de son argument (fonction membre publique)

std::bit_not::operator()

constexpr T operator()( const T& arg ) const;  // (depuis C++14)

Renvoie le résultat du NON bit à bit de arg.

Paramètres

  • arg — valeur dont calculer le NON bit à bit

Valeur de retour

Le résultat de ~arg.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Implémentation possible

constexpr T operator()(const T& arg) const
{
    return ~arg;
}

Notes

Bien que std::bit_not ait été ajouté par la proposition N3421, postérieure à C++11, il est traité par les implémentations courantes comme faisant partie de la résolution de LWG issue 660 (sauf sa spécialisation transparente std::bit_not<>), et est donc disponible dans leur mode C++98/03.
