std::is_bind_expression

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <functional>

template< class T >
struct is_bind_expression;  // (depuis C++11)

Si T est un type produit par un appel à std::bind (mais pas std::bind_front ni std::bind_back), ce modèle dérive de std::true_type. Pour tout autre type (sauf spécialisation par l'utilisateur), ce modèle dérive de std::false_type.

Un programme peut spécialiser ce modèle pour un type défini par le programme T afin de mettre en œuvre UnaryTypeTrait avec la caractéristique de base de std::true_type pour indiquer que T doit être traité par std::bind comme s'il était le type d'une sous-expression bind : lorsqu'un objet fonction généré par bind est invoqué, un argument lié de ce type sera invoqué comme un objet fonction et recevra tous les arguments non liés passés à l'objet généré par bind.

Modèle de variable auxiliaire

template< class T >
constexpr bool is_bind_expression_v = is_bind_expression<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un objet fonction généré par std::bind, false sinon (constante statique membre publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Exemple

#include <functional>
#include <iostream>
#include <type_traits>

struct MyBind
{
    typedef int result_type;
    int operator()(int a, int b) const { return a + b; }
};

namespace std
{
    template<>
    struct is_bind_expression<MyBind> : public true_type {};
}

int f(int n1, int n2)
{
    return n1 + n2;
}

int main()
{
    // comme si bind(f, bind(MyBind(), _1, _2), 2)
    auto b = std::bind(f, MyBind(), 2);

    std::cout << "Adding 2 to the sum of 10 and 11 gives " << b(10, 11) << '\n';
}

Output:

Adding 2 to the sum of 10 and 11 gives 23
