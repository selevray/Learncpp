std::function

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <functional>

template< class >
class function; /* undefined */  // (depuis C++11)

template< class R, class... Args >
class function<R(Args...)>;  // (depuis C++11)

Le modèle de classe std::function est un enveloppeur de fonction polymorphe à usage général. Les instances de std::function peuvent stocker, copier et invoquer toute CopyConstructible Callable cible -- fonctions (via des pointeurs vers celles-ci), expressions lambda, expressions bind, ou autres objets fonctions, ainsi que des pointeurs vers des fonctions membres et des pointeurs vers des membres de données.

L'objet appelable stocké est appelé la cible de std::function. Si un std::function ne contient aucune cible, il est dit vide. Invoquer la cible d'un std::function vide lève std::bad_function_call exception.

std::function satisfait les exigences de CopyConstructible et de CopyAssignable.

Notes

Il faut prendre garde lorsqu'un std::function, dont le type de résultat est une référence, est initialisé à partir d'une expression lambda sans type de retour final. En raison du fonctionnement de la déduction de auto, une telle expression lambda renverra toujours une prvalue. Par conséquent, la référence obtenue se liera généralement à un temporaire dont la durée de vie se termine lorsque std::function::operator() renvoie.

(jusqu'à C++23)

Si un std::function renvoyant une référence est initialisé à partir d'une fonction ou d'un objet fonction renvoyant une prvalue (y compris une expression lambda sans type de retour final), le programme est mal formé, car lier la référence renvoyée à un objet temporaire est interdit.

(depuis C++23)

std::function<const int&()> F([] { return 42; }); // Erreur depuis C++23 : impossible de lier
                                                  // la référence renvoyée à un temporaire
int x = F(); // Comportement indéfini jusqu'à C++23 : le résultat de F() est une référence pendante

std::function<int&()> G([]() -> int& { static int i{0x2A}; return i; }); // OK

std::function<const int&()> H([i{052}] -> const int& { return i; }); // OK

Exemple

#include <functional>
#include <iostream>

struct Foo
{
    Foo(int num) : num_(num) {}
    void print_add(int i) const { std::cout << num_ + i << '\n'; }
    int num_;
};

void print_num(int i)
{
    std::cout << i << '\n';
}

struct PrintNum
{
    void operator()(int i) const
    {
        std::cout << i << '\n';
    }
};

int main()
{
    // stocker une fonction libre
    std::function<void(int)> f_display = print_num;
    f_display(-9);

    // stocker une lambda
    std::function<void()> f_display_42 = []() { print_num(42); };
    f_display_42();

    // stocker le résultat d'un appel à std::bind
    std::function<void()> f_display_31337 = std::bind(print_num, 31337);
    f_display_31337();

    // stocker un appel à une fonction membre
    std::function<void(const Foo&, int)> f_add_display = &Foo::print_add;
    const Foo foo(314159);
    f_add_display(foo, 1);
    f_add_display(314159, 1);

    // stocker un appel à un accesseur de membre de données
    std::function<int(Foo const&)> f_num = &Foo::num_;
    std::cout << "num_: " << f_num(foo) << '\n';

    // stocker un appel à une fonction membre et un objet
    using std::placeholders::_1;
    std::function<void(int)> f_add_display2 = std::bind(&Foo::print_add, foo, _1);
    f_add_display2(2);

    // stocker un appel à une fonction membre et un pointeur vers un objet
    std::function<void(int)> f_add_display3 = std::bind(&Foo::print_add, &foo, _1);
    f_add_display3(3);

    // stocker un appel à un objet fonction
    std::function<void(int)> f_display_obj = PrintNum();
    f_display_obj(18);

    auto factorial = [](int n)
    {
        // stocker un objet lambda pour émuler une "lambda récursive" ; attention au surcoût supplémentaire
        std::function<int(int)> fac = [&](int n) { return (n < 2) ? 1 : n * fac(n - 1); };
        // notez que "auto fac = [&](int n) {...};" ne fonctionne pas dans les appels récursifs
        return fac(n);
    };
    for (int i{5}; i != 8; ++i)
        std::cout << i << "! = " << factorial(i) << ";  ";
    std::cout << '\n';
}
