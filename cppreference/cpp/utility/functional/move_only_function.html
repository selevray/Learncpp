Le modèle de classe std::move_only_function est un enveloppeur de fonction polymorphe à usage général. Les objets std::move_only_function peuvent stocker et invoquer toute Callable cible constructible (sans qu'il soit requis qu'elle soit constructible par déplacement) — fonctions, expressions lambda, expressions bind, ou autres objets fonctions, ainsi que des pointeurs vers des fonctions membres et des pointeurs vers des objets membres.

L'objet appelable stocké est appelé la cible de std::move_only_function. Si un std::move_only_function ne contient aucune cible, il est dit vide. Contrairement à std::function, invoquer un std::move_only_function vide entraîne un comportement indéfini.

std::move_only_function prend en charge toutes les combinaisons possibles de qualificateurs cv (à l'exclusion de volatile), de qualificateurs ref et de spécificateurs noexcept fournis dans son paramètre de modèle. Ces qualificateurs et spécificateur (le cas échéant) sont ajoutés à son operator().

std::move_only_function satisfait les exigences de MoveConstructible et de MoveAssignable, mais ne satisfait pas CopyConstructible ni CopyAssignable.

Notes

Les implémentations peuvent stocker un objet appelable de petite taille dans l'objet std::move_only_function. Une telle optimisation pour petits objets est effectivement requise pour les pointeurs de fonction et les spécialisations de std::reference_wrapper, et ne peut s'appliquer qu'aux types T pour lesquels std::is_nothrow_move_constructible_v<T> est true.

Si une std::move_only_function renvoyant une référence est initialisée à partir d'une fonction ou d'un objet fonction renvoyant une prvalue (y compris une expression lambda sans type de retour final), le programme est mal formé, car lier la référence renvoyée à un objet temporaire est interdit. Voir aussi les std::function.

Exemple

#include <functional>
#include <future>
#include <iostream>

int main()
{
    std::packaged_task<double()> packaged_task([](){ return 3.14159; });

    std::future<double> future = packaged_task.get_future();

    auto lambda = [task = std::move(packaged_task)]() mutable { task(); };

//  std::function<void()> function = std::move(lambda); // Erreur
    std::move_only_function<void()> function = std::move(lambda); // OK

    function();

    std::cout << future.get();
}

Output:

3.14159
