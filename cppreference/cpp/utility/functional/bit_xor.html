Objet fonction effectuant un OU exclusif bit à bit. Appelle effectivement operator^ sur le type T.

Spécialisations

La bibliothèque standard fournit une spécialisation de std::bit_xor lorsque T n'est pas spécifié, ce qui laisse les types des paramètres et le type de retour à déduire.

  • bit_xor<void> (C++14) — objet fonction implémentant x ^ y déduisant les types des paramètres et de la valeur de retour (spécialisation de modèle de classe)

(depuis C++14)

Fonctions membres

std::bit_xor::operator()

T operator()( const T& lhs, const T& rhs ) const;  // (constexpr depuis C++14)

Renvoie le résultat du OU exclusif bit à bit de lhs et rhs.

Paramètres

  • lhs, rhs — valeurs dont calculer le OU exclusif bit à bit

Valeur de retour

Le résultat de lhs ^ rhs.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Implémentation possible

constexpr T operator()(const T& lhs, const T& rhs) const
{
    return lhs ^ rhs;
}
