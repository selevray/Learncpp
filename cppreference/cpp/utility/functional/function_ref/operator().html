std::function_ref::operator()

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

R operator()( Args... args ) const noexcept(/*noex*/);  // (depuis C++26)

Invoque le thunk-ptr stocké avec bound-entity comme premier paramètre et les autres paramètres args. La partie /*noex*/ de operator() est identique à celle du paramètre de modèle de std::function_ref.

Équivalent à return thunk-ptr(bound-entity, std::forward<Args>(args)...);.

Paramètres

  • args — paramètres restants à transmettre au thunk-ptr stocké

Valeur de retour

thunk-ptr(bound-entity, std::forward<Args>(args)...).

Exceptions

Propage l'exception levée par l'appel de fonction sous-jacent.
