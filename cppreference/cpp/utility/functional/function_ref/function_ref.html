std::function_ref::function_ref

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class F >
function_ref( F* f ) noexcept;  // (1) (depuis C++26)

template< class F >
function_ref( F&& f ) noexcept;  // (2) (depuis C++26)

template< auto f >
function_ref( std::nontype_t<f> ) noexcept;  // (3) (depuis C++26)

template< auto f, class U >
function_ref( std::nontype_t<f>, U&& obj ) noexcept;  // (4) (depuis C++26)

template< auto f, class T >
function_ref( std::nontype_t<f>, /*cv*/ T* obj ) noexcept;  // (5) (depuis C++26)

function_ref( const function_ref& other ) = default;  // (6) (depuis C++26)

Crée un nouveau std::function_ref.

  1. Initialise bound-entity avec f, et thunk-ptr avec l'adresse d'une fonction thunk. Le comportement est indéfini si f est un pointeur nul.
  • Cette surcharge ne participe à la résolution de surcharge que si std::is_function_v<F> et /*is-invocable-using*/<F> sont toutes deux true.
  1. Initialise bound-entity avec std::addressof(f), et thunk-ptr avec l'adresse d'une fonction thunk.
  • Soit T égal à std::remove_reference_t<F>. Cette surcharge ne participe à la résolution de surcharge que si :
    • std::remove_cvref_t<F> n'est pas du même type que function_ref,
    • std::is_member_pointer_v<T> est false, et
    • /*is-invocable-using*/</*cv*/ T&> is true.
  1. Initialise bound-entity avec un pointeur vers un objet non spécifié ou une valeur de pointeur nul, et thunk-ptr avec l'adresse d'une fonction thunk.
  • Soit F égal à decltype(f). Cette surcharge ne participe à la résolution de surcharge que si /*is-invocable-using*/<F> est true.
  • Le programme est mal formé si f != nullptr est false lorsque std::is_pointer_v<F> || std::is_member_pointer_v<F> est true.
  1. Initialise bound-entity avec std::addressof(obj), et thunk-ptr avec l'adresse d'une fonction thunk.
  • Soit T égal à std::remove_reference_t<U> et F égal à decltype(f). Cette surcharge ne participe à la résolution de surcharge que si :
    • std::is_rvalue_reference_v<U&&> est false, et
    • /*is-invocable-using*/<F, /*cv*/ T&> is true.
  • Le programme est mal formé si f != nullptr est false lorsque std::is_pointer_v<F> || std::is_member_pointer_v<F> est true.
  1. Initialise bound-entity avec obj, et thunk-ptr avec l'adresse d'une fonction thunk. Le comportement est indéfini si obj est un pointeur nul lorsque std::is_member_pointer_v<F> est true.
  • Soit F égal à decltype(f). Cette surcharge ne participe à la résolution de surcharge que si /*is-invocable-using*/<F, /*cv*/ T*> est true.
  • Le programme est mal formé si f != nullptr est false lorsque std::is_pointer_v<F> || std::is_member_pointer_v<F> est true.
  1. Le constructeur de copie défini par défaut copie le bound-entity et le thunk-ptr de other.

L'adresse d'une fonction thunk est utilisée pour initialiser thunk-ptr de telle sorte qu'un appel à thunk(bound-entity, call-args...) soit équivalent en expression à :

Surcharges Équivalence d'expression
(1,3) std::invoke_r<R>(f, call-args...)
(2) std::invoke_r<R>(static_cast<cv T&>(f), call-args...)
(4) std::invoke_r<R>(f, static_cast<cv T&>(obj), call-args...)
(5) std::invoke_r<R>(f, obj, call-args...)

/*is-invocable-using*/<T...> est true si et seulement si :

  • std::is_nothrow_invocable_r_v<R, T..., Args...> est true si noex est true, ou
  • std::is_invocable_r_v<R, T..., Args...> is true

Paramètres

  • other — un autre function_ref à copier
  • f — une fonction ou un objet Callable à encapsuler
  • obj — un objet ou un pointeur lié
