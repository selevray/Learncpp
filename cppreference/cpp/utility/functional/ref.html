std::ref, std::cref

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <functional>

template< class T >
std::reference_wrapper<T> ref( T& t ) noexcept;  // (1) (depuis C++11) (constexpr depuis C++20)

template< class T >
std::reference_wrapper<T>
    ref( std::reference_wrapper<T> t ) noexcept;  // (2) (depuis C++11) (constexpr depuis C++20)

template< class T >
void ref( const T&& ) = delete;  // (3) (depuis C++11)

template< class T >
std::reference_wrapper<const T> cref( const T& t ) noexcept;  // (4) (depuis C++11) (constexpr depuis C++20)

template< class T >
std::reference_wrapper<const T>
    cref( std::reference_wrapper<T> t ) noexcept;  // (5) (depuis C++11) (constexpr depuis C++20)

template< class T >
void cref( const T&& ) = delete;  // (6) (depuis C++11)

Les modèles de fonctions ref et cref sont des fonctions auxiliaires qui génèrent un objet de type std::reference_wrapper, en utilisant la déduction d'argument de modèle pour déterminer l'argument de modèle du résultat.

T peut être un type incomplet.

(depuis C++20)

Paramètres

  • t — référence lvalue vers un objet à encapsuler ou une instance de std::reference_wrapper

Valeur de retour

  1. std::reference_wrapper<T>(t)

  2. t

  3. std::reference_wrapper<const T>(t)

  4. t

L'enveloppe de référence rvalue 3,6) est supprimée.

Exemple

#include <functional>
#include <iostream>

void f(int& n1, int& n2, const int& n3)
{
    std::cout << "In function: " << n1 << ' ' << n2 << ' ' << n3 << '\n';
    ++n1; // incrémente la copie de n1 stockée dans l'objet fonction
    ++n2; // incrémente le n2 de main()
    // ++n3; // erreur de compilation
}

int main()
{
    int n1 = 1, n2 = 2, n3 = 3;
    std::function<void()> bound_f = std::bind(f, n1, std::ref(n2), std::cref(n3));
    n1 = 10;
    n2 = 11;
    n3 = 12;
    std::cout << "Before function: " << n1 << ' ' << n2 << ' ' << n3 << '\n';
    bound_f();
    std::cout << "After function: " << n1 << ' ' << n2 << ' ' << n3 << '\n';
}

Output:

Before function: 10 11 12
In function: 1 11 12
After function: 10 12 12
