std::function<R(Args...)>::operator bool

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

explicit operator bool() const noexcept;  // (depuis C++11)

Vérifie si *this stocke une cible fonction appelable, c'est-à-dire s'il n'est pas vide.

Paramètres

(aucune)

Valeur de retour

true si *this stocke une cible fonction appelable, false sinon.

Exemple

#include <functional>
#include <iostream>

void sampleFunction()
{
    std::cout << "This is the sample function!\n";
}

void checkFunc(std::function<void()> const& func)
{
    // Utilisez operator bool pour déterminer si la cible appelable est disponible.
    if (func)
    {
        std::cout << "Function is not empty! Calling function.\n";
        func();
    }
    else
        std::cout << "Function is empty. Nothing to do.\n";
}

int main()
{
    std::function<void()> f1;
    std::function<void()> f2(sampleFunction);

    std::cout << "f1: ";
    checkFunc(f1);

    std::cout << "f2: ";
    checkFunc(f2);
}

Output:

f1: Function is empty. Nothing to do.
f2: Function is not empty! Calling function.
This is the sample function!
