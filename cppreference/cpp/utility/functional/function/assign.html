std::function<R(Args...)>::assign

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class F, class Alloc >
void assign( F&& f, const Alloc& alloc );  // (depuis C++11) (supprimé en C++17)

Initialise la cible avec f. Le alloc est utilisé pour allouer la mémoire de toutes les structures de données internes que le function peut utiliser.

Équivalent à function(std::allocator_arg, alloc, std::forward<F>(f)).swap(*this);.

Paramètres

  • f — fonction appelable pour initialiser la cible avec
  • alloc — allocateur à utiliser pour allouer la mémoire des structures de données internes

Valeur de retour

(aucune)

Exceptions

Peut lever des exceptions définies par l'implémentation.
