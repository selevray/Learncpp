std::function<R(Args...)>::target_type

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

const std::type_info& target_type() const noexcept;  // (depuis C++11)

Renvoie le type de la fonction stockée.

Paramètres

(aucune)

Valeur de retour

typeid(T) si la fonction stockée a le type T, sinon typeid(void)

Exemple

#include <functional>
#include <iostream>

int f(int a) { return -a; }
void g(double) {}
int main()
{
    // fn1 et fn2 ont le même type, mais leurs cibles non
    std::function<int(int)> fn1(f),
                            fn2([](int a) {return -a;});
    std::cout << fn1.target_type().name() << '\n'
              << fn2.target_type().name() << '\n';

    // depuis C++17, les guides de déduction (CTAD) peuvent être utilisés
    std::cout << std::function{g}.target_type().name() << '\n';
}
