Construit un std::function à partir de sources variées.

1,2) Crée un vide std::function.

  1. Copie la cible de other vers la cible de *this.

Si other est vide, *this sera vide juste après l'appel également.

  1. Déplace la cible de other vers la cible de *this.

Si other est vide, *this sera vide juste après l'appel également.

other est dans un état valide mais non spécifié juste après l'appel.

  1. Initialise la cible avec std::forward<F>(f). La cible est de type std::decay<F>::type.

Si f est un pointeur nul vers une fonction, un pointeur nul vers un membre, ou une valeur vide d'une spécialisation de std::function, *this sera vide juste après l'appel.

Cette surcharge ne participe à la résolution de surcharge que si toutes les conditions suivantes sont satisfaites :

  • std::is_same_v<std::remove_cvref_t<F>, std::function<R(Args...)> is false.

(depuis C++23)

  • Une lvalue de type std::decay<F>::type est appelable pour les types d'arguments Args... et le type de retour R.

Si std::is_copy_constructible_v<std::decay_t<F>> ou std::is_constructible_v<std::decay_t<F>, F> est false, le programme est mal formé.

(depuis C++23)

Si F n'est pas CopyConstructible, le comportement est indéfini.

6-10) Identique à (1-5) sauf que alloc est utilisé pour allouer la mémoire de toutes les structures de données internes que le std::function peut utiliser.

Lorsque la cible est un pointeur de fonction ou un std::reference_wrapper, l'optimisation pour petits objets est garantie : ces cibles sont toujours stockées directement dans l'objet std::function, sans allocation dynamique. Les autres grands objets peuvent être construits dans un stockage alloué dynamiquement et accessibles par l'objet std::function via un pointeur.

Paramètres

  • other — l'objet fonction utilisé pour initialiser *this
  • f — un objet appelable utilisé pour initialiser *this
  • alloc — un Allocator utilisé pour l'allocation mémoire interne

Exigences sur les types

  • Alloc doit satisfaire aux exigences de Allocator.

Exceptions

3,8,9) Ne lève pas d'exception si la cible de other est un pointeur de fonction ou un std::reference_wrapper, sinon peut lever std::bad_alloc ou toute exception levée par le constructeur utilisé pour copier ou déplacer l'objet appelable stocké.

  1. Ne lève pas d'exception si la cible de other est un pointeur de fonction ou un std::reference_wrapper, sinon peut lever std::bad_alloc ou toute exception levée par le constructeur utilisé pour copier ou déplacer l'objet appelable stocké.

(jusqu'à C++20)

5,10) Ne lève pas d'exception si f est un pointeur de fonction ou un std::reference_wrapper, sinon peut lever std::bad_alloc ou toute exception levée par le constructeur de copie de l'objet appelable stocké.

Notes

La prise en charge des allocateurs de std::function était mal spécifiée et implémentée de manière incohérente. Certaines implémentations ne fournissent pas du tout les surcharges (6-10), certaines les fournissent mais ignorent l'argument allocateur fourni, et d'autres les fournissent et utilisent l'allocateur fourni pour la construction mais pas lorsque le std::function est réaffecté. Par conséquent, la prise en charge des allocateurs a été supprimée en C++17.

Exemple

#include <functional>
#include <iostream>
#include <utility>

void print_num(int i) { std::cout << "print_num(" << i << ")\n"; }

int main()
{
    std::function<void(int)> func1; // (1) constructeur vide
    try
    {
        func1(333 << 1);
    }
    catch (const std::bad_function_call& ex)
    {
        std::cout << "1) " << ex.what() << '\n';
    }

    std::function<void(int)> func2{nullptr}; // (2) constructeur vide
    try
    {
        func1(222 * 3);
    }
    catch (const std::bad_function_call& ex)
    {
        std::cout << "2) " << ex.what() << '\n';
    }

    func1 = print_num; // initialise func1 à l'aide de l'opérateur d'affectation

    std::function<void(int)> func3{func1}; // (3) constructeur de copie
    func3(33);

    std::function<void(int)> func4{std::move(func3)}; // (4) constructeur de déplacement,
                                                      // func3 dans un état non spécifié
    func4(44);

    std::function<void(int)> func5{print_num}; // (5) constructeur avec une fonction
    func5(55);

    // (5) constructeur avec une lambda
    std::function<void(int)> func6([](int i) { std::cout << "lambda(" << i << ")\n"; });
    func6(66);
}

2) bad_function_call
