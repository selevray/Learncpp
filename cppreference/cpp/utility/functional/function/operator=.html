std::function<R(Args...)>::operator=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

function& operator=( const function& other );  // (1) (depuis C++11)

function& operator=( function&& other );  // (2) (depuis C++11)

function& operator=( std::nullptr_t ) noexcept;  // (3) (depuis C++11)

template< class F >
function& operator=( F&& f );  // (4) (depuis C++11)

template< class F >
function& operator=( std::reference_wrapper<F> f ) noexcept;  // (5) (depuis C++11)

Affecte une nouvelle cible à std::function.

  1. Affecte une copie de la cible de other, comme si l'on exécutait function(other).swap(*this);

  2. Déplace la cible de other vers *this. other est dans un état valide avec une valeur non spécifiée.

  3. Supprime la cible courante. *this est vide après l'appel.

  4. Définit la cible de *this comme l'objet appelable f, comme si l'on exécutait function(std::forward<F>(f)).swap(*this);. Cet opérateur ne participe pas à la résolution de surcharge sauf si f est Callable pour les types d'arguments Args... et le type de retour R.

  5. Affecte à la cible de *this une copie de f, comme si l'on exécutait function(f).swap(*this);

Paramètres

  • other — un autre objet std::function dont copier la cible
  • f — un objet appelable avec lequel initialiser la cible

Exigences sur les types

  • F doit satisfaire aux exigences de Callable.

Valeur de retour

*this

Notes

Même avant la suppression du support des allocateurs de std::function en C++17, ces opérateurs d'affectation utilisent l'allocateur par défaut plutôt que l'allocateur de *this ou l'allocateur de other (voir LWG issue 2386).

Exemple

#include <cassert>
#include <functional>
#include <utility>

int inc(int n) { return n + 1; }

int main()
{
    std::function<int(int)> f1;
    std::function<int(int)> f2(inc);
    assert(f1 == nullptr and f2 != nullptr);

    f1 = f2; // overload (1)
    assert(f1 != nullptr and f1(1) == 2);

    f1 = std::move(f2); // overload (2)
    assert(f1 != nullptr and f1(1) == 2);
    // f2 est dans un état valide mais non spécifié

    f1 = nullptr; // overload (3)
    assert(f1 == nullptr);

    f1 = inc; // overload (4)
    assert(f1 != nullptr and f1(1) == 2);

    f1 = [](int n) { return n + n; }; // overload (4)
    assert(f1 != nullptr and f1(2) == 4);

    std::reference_wrapper<int(int)> ref1 = std::ref(inc);
    f1 = ref1; // overload (5)
    assert(f1 != nullptr and f1(1) == 2);
}

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.
