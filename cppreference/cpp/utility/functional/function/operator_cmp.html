operator==,!=(std::function)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <functional>

template< class R, class... ArgTypes >
bool operator==( const std::function<R(ArgTypes...)>& f,
                 std::nullptr_t ) noexcept;  // (1) (depuis C++11)

template< class R, class... ArgTypes >
bool operator==( std::nullptr_t,
                 const std::function<R(ArgTypes...)>& f ) noexcept;  // (2) (depuis C++11) (jusqu'à C++20)

template< class R, class... ArgTypes >
bool operator!=( const std::function<R(ArgTypes...)>& f,
                 std::nullptr_t ) noexcept;  // (3) (depuis C++11) (jusqu'à C++20)

template< class R, class... ArgTypes >
bool operator!=( std::nullptr_t,
                 const std::function<R(ArgTypes...)>& f ) noexcept;  // (4) (depuis C++11) (jusqu'à C++20)

Compare une std::function à un pointeur nul. Les fonctions vides (c'est-à-dire sans cible appelable) sont égales entre elles, les fonctions non vides sont différentes.

L'opérateur != est synthétisé à partir de operator==.

(depuis C++20)

Paramètres

  • f — std::function à comparer

Valeur de retour

1,2) !f

3,4) (bool) f

Exemple

#include <functional>
#include <iostream>

using SomeVoidFunc = std::function<void(int)>;

class C
{
public:
    C(SomeVoidFunc void_func = nullptr) : void_func_(void_func)
    {
        if (void_func_ == nullptr) // comparaison spécialisée avec nullptr
            void_func_ = std::bind(&C::default_func, this, std::placeholders::_1);
        void_func_(7);
    }

    void default_func(int i) { std::cout << i << '\n'; };

private:
    SomeVoidFunc void_func_;
};

void user_func(int i)
{
    std::cout << (i + 1) << '\n';
}

int main()
{
    C c1;
    C c2(user_func);
}

Output:

7
8
