std::unary_negate

Défini dans l'en-tête <functional>

template< class Predicate >
struct unary_negate : public std::unary_function<Predicate::argument_type, bool>;  // (jusqu'à C++11)

template< class Predicate >
struct unary_negate;  // (depuis C++11) (obsolète en C++17) (supprimé en C++20)

std::unary_negate est un objet fonction encapsulant qui renvoie le complément du prédicat unaire qu'il contient.

Le type de prédicat unaire doit définir un type membre argument_type, convertible vers le type de paramètre du prédicat. Les objets fonctions unaires obtenus à partir de std::ref, std::cref, std::negate, std::logical_not, std::mem_fn, std::function, std::hash, ou d'un autre appel à std::not1 possèdent ce type défini, de même que les objets fonctions dérivés du std::unary_function obsolète.

Les objets std::unary_negate sont facilement construits à l'aide de la fonction auxiliaire std::not1.

Exemple

#include <algorithm>
#include <functional>
#include <iostream>
#include <vector>

struct less_than_7 : std::unary_function<int, bool>
{
    bool operator()(int i) const { return i < 7; }
};

int main()
{
    std::vector<int> v(7, 7);
    v[0] = v[1] = v[2] = 6;

    std::unary_negate<less_than_7> not_less_than_7((less_than_7()));
    // C++11 solution:
    // Utiliser std::function<bool (int)>
    // std::function<bool (int)> not_less_than_7 =
    //     [](int x)->bool { return !less_than_7()(x); };

    std::cout << std::count_if(v.begin(), v.end(), not_less_than_7);
}

Output:

4
