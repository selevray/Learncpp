Enveloppe autour d'un pointeur vers fonction membre. L'instance de classe dont la fonction membre doit être appelée est passée sous forme de pointeur vers le operator().

  1. Enveloppe une fonction membre non const sans paramètre.

  2. Enveloppe une fonction membre const sans paramètre.

  3. Enveloppe une fonction membre non const avec un seul paramètre.

  4. Enveloppe une fonction membre const avec un seul paramètre.
