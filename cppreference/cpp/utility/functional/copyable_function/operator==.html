operator==(std::copyable_function)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

friend bool operator==( const std::copyable_function& f, std::nullptr_t ) noexcept;  // (depuis C++26)

Vérifie si l'enveloppe f possède une cible appelable en la comparant formellement à std::nullptr_t. Les enveloppes vides (c'est-à-dire sans cible) se comparent égales, les fonctions non vides se comparent non égales.

Cette fonction n'est pas visible par la recherche non qualifiée ordinaire ni par la recherche qualifiée, et ne peut être trouvée que par la recherche dépendante des arguments lorsque std::copyable_function<FunctionType> est une classe associée aux arguments.

L'opérateur != est synthétisé à partir de operator==.

Paramètres

  • f — std::copyable_function à comparer

Valeur de retour

!f.
