std::copyable_function::operator=

copyable_function& operator=( const copyable_function& other );  // (1) (depuis C++26)

copyable_function& operator=( copyable_function&& other );  // (2) (depuis C++26)

copyable_function& operator=( std::nullptr_t ) noexcept;  // (3) (depuis C++26)

template< class F >
copyable_function& operator=( F&& f );  // (4) (depuis C++26)

Affecte une nouvelle cible à std::copyable_function ou détruit sa cible.

  1. Affecte une copie de la cible de other à *this comme si l'on exécutait auto(other).swap(*this).

  2. Déplace la cible de other vers *this ou détruit la cible de *this (le cas échéant) si other est vide, par auto(std::move(other)).swap(*this). other est dans un état valide avec une valeur non spécifiée après l'affectation par déplacement.

  3. Détruit la cible courante si elle existe. *this est vide après l'appel.

  4. Définit la cible de *this comme l'appelable f, ou détruit la cible courante si f est un pointeur de fonction nul, un pointeur vers fonction membre nul, ou un std::copyable_function vide, comme si l'on exécutait copyable_function(std::forward<F>(f)).swap(*this);. Cette surcharge ne participe à la résolution de surcharge que si le constructeur de copyable_function à partir de F y participe. Le programme est mal formé ou a un comportement indéfini si l'appel du constructeur sélectionné est mal formé ou a un comportement indéfini.

Paramètres

  • other — un autre objet std::copyable_function dont copier ou déplacer la cible
  • f — un objet appelable pour initialiser la nouvelle cible avec

Valeur de retour

*this
