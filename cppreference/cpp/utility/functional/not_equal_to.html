std::not_equal_to

template< class T >
struct not_equal_to;  // (jusqu'à C++14)

template< class T = void >
struct not_equal_to;  // (depuis C++14)

Objet fonction pour effectuer des comparaisons. Sauf spécialisation, appelle operator!= sur le type T.

Spécialisations

La bibliothèque standard fournit une spécialisation de std::not_equal_to lorsque T n'est pas spécifié, ce qui laisse les types des paramètres et le type de retour à déduire.

  • not_equal_to<void> (C++14) — objet fonction implémentant x != y déduisant les types des paramètres et de la valeur de retour (spécialisation de modèle de classe)

(depuis C++14)

Types membres

Type Définition

  • result_type (obsolète en C++17) (supprimé en C++20) — bool
  • first_argument_type (obsolète en C++17) (supprimé en C++20) — T
  • second_argument_type (obsolète en C++17) (supprimé en C++20) — T

Ces types membres sont obtenus par héritage public de std::binary_function<T, T, bool>.

(jusqu'à C++11)

Fonctions membres

  • operator() — vérifie si les arguments sont différents (fonction membre publique)

std::not_equal_to::operator()

bool operator()( const T& lhs, const T& rhs ) const;  // (constexpr depuis C++14)

Vérifie si lhs est différent de rhs.

Paramètres

  • lhs, rhs — valeurs à comparer

Valeur de retour

true si lhs != rhs, false sinon.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Implémentation possible

constexpr bool operator()(const T& lhs, const T& rhs) const
{
    return lhs != rhs;
}
