std::is_placeholder

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <functional>

template< class T >
struct is_placeholder;  // (depuis C++11)

Si T est le type d'un (_1, _2, _3, ...) espace réservé standard, alors ce modèle dérive respectivement de std::integral_constant<int, 1>, std::integral_constant<int, 2>, std::integral_constant<int, 3>.

Si T n'est pas un type d'espace réservé standard, ce modèle dérive de std::integral_constant<int, 0>.

Un programme peut spécialiser ce modèle pour un type défini par le programme T afin de mettre en œuvre UnaryTypeTrait avec la caractéristique de base de std::integral_constant<int, N> avec N positif pour indiquer que T doit être traité comme le n-ième type d'espace réservé N.

std::bind utilise std::is_placeholder pour détecter les espaces réservés des arguments non liés.

Modèle de variable auxiliaire

template< class T >
constexpr int is_placeholder_v = is_placeholder<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — valeur d'espace réservé ou 0 pour les types qui ne sont pas des espaces réservés (constante statique membre publique)

Fonctions membres

  • operator int — convertit l'objet en int, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — int
  • type — std::integral_constant<int, value>

Exemple

#include <functional>
#include <iostream>
#include <type_traits>

struct My_2 {} my_2;

namespace std
{
    template<>
    struct is_placeholder<My_2> : public integral_constant<int, 2> {};
}

int f(int n1, int n2)
{
    return n1 + n2;
}

int main()
{
    std::cout << "Standard placeholder _5 is for the argument number "
              << std::is_placeholder_v<decltype(std::placeholders::_5)>
              << '\n';

    auto b = std::bind(f, my_2, 2);
    std::cout << "Adding 2 to 11 selected with a custom placeholder gives "
              << b(10, 11) // le premier argument, à savoir 10, est ignoré
              << '\n';
}

Output:

Standard placeholder _5 is for the argument number 5
Adding 2 to 11 selected with a custom placeholder gives 13
