std::divides<void>

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <functional>

template<>
class divides<void>;  // (depuis C++14)

std::divides<void> est une spécialisation de std::divides dont le paramètre et la valeur de retour sont déduits.

Types membres

Type Définition

  • is_transparent — unspecified

Fonctions membres

  • operator() — renvoie le quotient de deux arguments (fonction membre publique)

std::divides<void>::operator()

template< class T, class U >
constexpr auto operator()( T&& lhs, U&& rhs ) const
    -> decltype(std::forward<T>(lhs) / std::forward<U>(rhs));

Renvoie le quotient de lhs et rhs.

Paramètres

  • lhs, rhs — valeurs à diviser

Valeur de retour

std::forward<T>(lhs) / std::forward<U>(rhs).

Exemple

#include <complex>
#include <functional>
#include <iostream>

int main()
{
    auto complex_divides = std::divides<void>{}; // « void » peut être omis
    constexpr std::complex z1{8.0, 4.0}, z2{1.0, 2.0};

    std::cout << std::showpos
              << complex_divides(z1, z2) << ' ' << z1 / z2 << '\n'
              << complex_divides(z1, 5.) << ' ' << z1 / 5. << '\n'
              << complex_divides(6., z2) << ' ' << 6. / z2 << '\n';
}

Output:

(+3.2,-2.4) (+3.2,-2.4)
(+1.6,+0.8) (+1.6,+0.8)
(+1.2,-2.4) (+1.2,-2.4)
