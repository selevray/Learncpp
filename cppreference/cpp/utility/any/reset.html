std::any::reset

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void reset() noexcept;  // (depuis C++17)

Si *this contient une valeur, détruit la valeur contenue.

*this ne contient pas de valeur après cet appel.

Paramètres

(aucune)

Valeur de retour

(aucune)

Exemple

#include <any>
#include <cassert>

int main()
{
    std::any a{42};
    assert(a.has_value());
    a.reset();
    assert(not a.has_value());
}
