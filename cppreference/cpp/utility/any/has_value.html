std::any::has_value

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool has_value() const noexcept;  // (depuis C++17)

Vérifie si l'objet contient une valeur.

Paramètres

(aucune)

Valeur de retour

true si et seulement si l'instance contient une valeur.

Exemple

#include <any>
#include <cassert>
#include <string>

int main()
{
    std::any a0;
    assert(a0.has_value() == false);

    std::any a1 = 42;
    assert(a1.has_value() == true);
    assert(std::any_cast<int>(a1) == 42);
    a1.reset();
    assert(a1.has_value() == false);

    auto a2 = std::make_any<std::string>("Andromeda");
    assert(a2.has_value() == true);
    assert(std::any_cast<std::string&>(a2) == "Andromeda");
    a2.reset();
    assert(a2.has_value() == false);
}
