std::any::swap

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void swap( any& other ) noexcept;  // (depuis C++17)

Échange le contenu de deux objets any.

Paramètres

  • other — objet avec lequel échanger

Exemple

#include <any>
#include <print>
#include <string>
#include <string_view>

int main()
{
    std::any a = std::string{"King"};
    std::any b = std::string_view{"Queen"};
    std::println("a = {}", std::any_cast<std::string&>(a));
    std::println("b = {}", std::any_cast<std::string_view&>(b));
    std::println("swap(a, b)");
    a.swap(b);
    std::println("a = {}", std::any_cast<std::string_view&>(a));
    std::println("b = {}", std::any_cast<std::string&>(b));
}

Output:

a = King
b = Queen
swap(a, b)
a = Queen
b = King
