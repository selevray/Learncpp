std::any::~any

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

~any();  // (depuis C++17)

Détruit l'objet contenu, le cas échéant, comme par un appel à reset().

Exemple

#include <any>
#include <cstdio>

struct X
{
    X() { std::puts("X::X()"); }
    X(const X&) { std::puts("X::X(const X&)"); }
    ~X() { std::puts("X::~X()"); }
};

int main()
{
    std::any a{X{}};
    std::puts("Leaving main()...");
}

Output:

X::X()
X::X(const X&)
X::~X()
Leaving main()...
X::~X()
