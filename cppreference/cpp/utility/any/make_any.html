std::make_any

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <any>

template< class T, class... Args >
std::any make_any( Args&&... args );  // (1) (depuis C++17)

template< class T, class U, class... Args >
std::any make_any( std::initializer_list<U> il, Args&&... args );  // (2) (depuis C++17)

Construit un objet any contenant un objet de type T, en transmettant les arguments fournis au constructeur de T.

  1. Équivalent à return std::any(std::in_place_type<T>, std::forward<Args>(args)...);

  2. Équivalent à return std::any(std::in_place_type<T>, il, std::forward<Args>(args)...);

Exemple

#include <any>
#include <complex>
#include <functional>
#include <iostream>
#include <string>

int main()
{
    auto a0 = std::make_any<std::string>("Hello, std::any!\n");
    auto a1 = std::make_any<std::complex<double>>(0.1, 2.3);

    std::cout << std::any_cast<std::string&>(a0);
    std::cout << std::any_cast<std::complex<double>&>(a1) << '\n';

    using lambda = std::function<void(void)>;

    // Placer une lambda dans std::any. Tentative #1 (échec).
    std::any a2 = [] { std::cout << "Lambda #1.\n"; };
    std::cout << "a2.type() = \"" << a2.type().name() << "\"\n";

    // any_cast effectue une conversion vers <void(void)> mais le type réel ne l'est pas
    // un std::function..., mais ~ main::{lambda()#1}, et il est
    // unique pour chaque lambda. Donc, cela lève...
    try
    {
        std::any_cast<lambda>(a2)();
    }
    catch (std::bad_any_cast const& ex)
    {
        std::cout << ex.what() << '\n';
    }

    // Placer une lambda dans std::any. Tentative #2 (réussie).
    auto a3 = std::make_any<lambda>([] { std::cout << "Lambda #2.\n"; });
    std::cout << "a3.type() = \"" << a3.type().name() << "\"\n";
    std::any_cast<lambda>(a3)();
}
