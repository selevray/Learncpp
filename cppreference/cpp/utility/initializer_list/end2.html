Défini dans l'en-tête <initializer_list>

template< class E >
const E* end( std::initializer_list<E> il ) noexcept;  // (depuis C++11) (constexpr depuis C++14)

La surcharge de std::end pour initializer_list renvoie un pointeur vers un élément après le dernier de il.

Paramètres

  • il — an initializer_list

Valeur de retour

il.end()

Exemple

#include <cassert>
#include <initializer_list>
#include <iterator>
#include <numeric>

int main()
{
    std::initializer_list e = {2, 7, 1, 8, 2, 8, 1};
    assert(std::accumulate(std::begin(e), std::end(e), 13) == 42);
}
