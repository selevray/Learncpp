std::initializer_list<T>::end

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

const T* end() const noexcept;  // (depuis C++11) (constexpr depuis C++14)

Obtient un pointeur vers un élément après le dernier de la liste d'initialisation, c'est-à-dire begin() + size().

Si la liste d'initialisation est vide, les valeurs de begin() et end() sont non spécifiées, mais seront identiques.

Paramètres

(aucune)

Valeur de retour

Un pointeur vers un élément après le dernier de la liste d'initialisation

Complexité

Constante

Exemple

#include <initializer_list>
#include <numeric>

int main()
{
    static constexpr auto l = {3, 13, 13};
    static_assert(std::accumulate(l.begin(), l.end(), 13) == 42);
}
