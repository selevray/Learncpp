std::begin(std::initializer_list)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <initializer_list>

template< class E >
const E* begin( std::initializer_list<E> il ) noexcept;  // (depuis C++11) (constexpr depuis C++14)

La surcharge de std::begin pour initializer_list renvoie un pointeur vers le premier élément de il.

Paramètres

  • il — an initializer_list

Valeur de retour

il.begin()

Exemple

#include <algorithm>
#include <initializer_list>
#include <iostream>
#include <iterator>

int main()
{
    std::initializer_list ϕ = {'1', '.', '6', '1', '8', '0'};

    std::copy(std::begin(ϕ),
              std::end(ϕ),
              std::ostream_iterator<char>(std::cout, ""));

    std::cout << '\n';
}
