std::initializer_list<T>::initializer_list

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

initializer_list() noexcept;  // (depuis C++11) (constexpr depuis C++14)

Construit une liste d'initialisation vide.

Paramètres

(aucune)

Complexité

Constante

Notes

Malgré l'absence de constructeurs, il est possible de créer des listes d'initialisation non vides. Les instances de std::initializer_list sont construites implicitement lorsque :

  • une braced-init-list est utilisée dans une list-initialization, y compris l'initialisation de liste d'appel de fonction et les expressions d'affectation (à ne pas confondre avec les listes d'initialisation de constructeur)
  • une braced-init-list est liée à auto, y compris dans une boucle for à intervalle

Exemple

#include <initializer_list>
#include <iostream>

int main()
{
    std::initializer_list<int> empty_list;
    std::cout << "empty_list.size(): " << empty_list.size() << '\n';

    // créer des listes d'initialisation par list-initialization
    std::initializer_list<int> digits{1, 2, 3, 4, 5};
    std::cout << "digits.size(): " << digits.size() << '\n';

    // la règle spéciale pour auto signifie que 'fractions' a le
    // type std::initializer_list<double>
    auto fractions = {3.14159, 2.71828};
    std::cout << "fractions.size(): " << fractions.size() << '\n';

    // créer une liste d'initialisation constexpr (depuis C++14)
    static constexpr auto ab = {'a', 'b'};
    static_assert(ab.size() == 2 and *ab.begin() == 'a');
}

Output:

empty_list.size(): 0
digits.size(): 5
fractions.size(): 2
