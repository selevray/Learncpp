std::initializer_list<T>::begin

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

const T* begin() const noexcept;  // (depuis C++11) (constexpr depuis C++14)

Obtient un pointeur vers le premier élément de la liste d'initialisation.

Si la liste d'initialisation est vide, les valeurs de begin() et end() sont non spécifiées, mais seront identiques.

Paramètres

(aucune)

Valeur de retour

Un pointeur vers le premier élément de la liste d'initialisation

Complexité

Constante

Exemple

#include <initializer_list>

int main()
{
    static constexpr auto il = {42, 24};
    static_assert(*il.begin() == 0x2A);
    static_assert(il.begin()[1] == 030);
}
