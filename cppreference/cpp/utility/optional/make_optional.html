std::make_optional

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <optional>

template< class T >
constexpr std::optional<std::decay_t<T>> make_optional( T&& value );  // (1) (depuis C++17)

template< class T, class... Args >
constexpr std::optional<T> make_optional( Args&&... args );  // (2) (depuis C++17)

template< class T, class U, class... Args >
constexpr std::optional<T> make_optional( std::initializer_list<U> il,
                                          Args&&... args );  // (3) (depuis C++17)

  1. Crée un objet optional à partir de value. Appelle effectivement std::optional<std::decay_t<T>>(std::forward<T>(value)).

  2. Crée un objet optional construit sur place à partir de args.... Équivalent à return std::optional<T>(std::in_place, std::forward<Args>(args)...);.
    Cette surcharge ne participe à la résolution de surcharge que si std::is_constructible_v<T, Args...> est true.

  3. Crée un objet optional construit sur place à partir de il et args.... Équivalent à return std::optional<T>(std::in_place, il, std::forward<Args>(args)...);.
    Cette surcharge ne participe à la résolution de surcharge que si std::is_constructible_v<T, std::initializer_list<U>&, Args...> est true.

Paramètres

  • value — la valeur avec laquelle construire l'objet optionnel
  • il, args — arguments à passer au constructeur de T

Valeur de retour

L'objet optional construit.

Exceptions

Lève toute exception levée par le constructeur de T.

Notes

T n'a pas besoin d'être déplaçable pour les surcharges (2,3) grâce à l'élision de copie garantie.

Exemple

#include <iomanip>
#include <iostream>
#include <optional>
#include <string>
#include <vector>

int main()
{
    auto op1 = std::make_optional<std::vector<char>>({'a','b','c'});
    std::cout << "op1: ";
    for (char c : op1.value())
        std::cout << c << ',';
    auto op2 = std::make_optional<std::vector<int>>(5, 2);
    std::cout << "\nop2: ";
    for (int i : *op2)
        std::cout << i << ',';
    std::string str{"hello world"};
    auto op3 = std::make_optional<std::string>(std::move(str));
    std::cout << "\nop3: " << std::quoted(op3.value_or("empty value")) << '\n';
    std::cout << "str: " << std::quoted(str) << '\n';
}

Sortie possible :

op1: a,b,c,
op2: 2,2,2,2,2,
op3: "hello world"
str: ""
