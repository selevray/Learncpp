Remplace le contenu de *this par le contenu de other.

  1. Si *this contient une valeur avant l'appel, la valeur contenue est détruite en appelant son destructeur, comme si l'on appelait value().T::~T(). *this ne contient pas de valeur après cet appel.

2,3) Affecte l'état de other.

  • Si *this et other ne contiennent tous deux pas de valeur, la fonction n'a aucun effet.
  • Si *this contient une valeur mais que other n'en contient pas, la valeur contenue est détruite en appelant son destructeur. *this ne contient pas de valeur après l'appel.
  • Si other contient une valeur, alors selon que *this contient ou non une valeur, la valeur contenue est soit initialisée directement, soit affectée à partir de *other (2) ou de std::move(*other) (3). Notez qu'un optionnel déplacé contient toujours une valeur.
  • La surcharge (2) est supprimée lorsque std::is_copy_constructible_v<T> ou std::is_copy_assignable_v<T> est false. Elle est triviale si std::is_trivially_copy_constructible_v<T>, std::is_trivially_copy_assignable_v<T> et std::is_trivially_destructible_v<T> sont tous true.
  • La surcharge (3) ne participe pas à la résolution de surcharge lorsque std::is_move_constructible_v<T> ou std::is_move_assignable_v<T> est false. Elle est triviale si std::is_trivially_move_constructible_v<T>, std::is_trivially_move_assignable_v<T> et std::is_trivially_destructible_v<T> sont tous true.
  1. Affectation à transmission parfaite : selon que *this contient une valeur avant l'appel, la valeur contenue est soit initialisée directement à partir de std::forward<U>(value), soit affectée à partir de std::forward<U>(value). La fonction ne participe pas à la résolution de surcharge sauf si [std::decay_t<U> (jusqu'à C++20) | std::remove_cvref_t<U> (depuis C++20)] n'est pas std::optional<T>, std::is_constructible_v<T, U> est true, std::is_assignable_v<T&, U> est true, et qu'au moins une des conditions suivantes est vraie :
  • T n'est pas un type scalaire ;
  • std::decay_t<U> n'est pas T.

5,6) Affecte l'état de other.

  • Si *this et other ne contiennent tous deux pas de valeur, la fonction n'a aucun effet.
  • Si *this contient une valeur mais que other n'en contient pas, la valeur contenue est détruite en appelant son destructeur. *this ne contient pas de valeur après l'appel.
  • Si other contient une valeur, alors selon que *this contient ou non une valeur, la valeur contenue est soit initialisée directement, soit affectée à partir de *other (5) ou de std::move(*other) (6). Notez qu'un optionnel déplacé contient toujours une valeur.
  • Ces surcharges ne participent pas à la résolution de surcharge sauf si les conditions suivantes sont remplies :
    • T n'est pas constructible, convertible ou affectable à partir d'une expression quelconque de type (éventuellement const) std::optional<U>, c'est-à-dire que les 12 traits de type suivants sont tous false :
      • std::is_constructible_v<T, std::optional<U>&>
      • std::is_constructible_v<T, const std::optional<U>&>
      • std::is_constructible_v<T, std::optional<U>&&>
      • std::is_constructible_v<T, const std::optional<U>&&>
      • std::is_convertible_v<std::optional<U>&, T>
      • std::is_convertible_v<const std::optional<U>&, T>
      • std::is_convertible_v<std::optional<U>&&, T>
      • std::is_convertible_v<const std::optional<U>&&, T>
      • std::is_assignable_v<T&, std::optional<U>&>
      • std::is_assignable_v<T&, const std::optional<U>&>
      • std::is_assignable_v<T&, std::optional<U>&&>
      • std::is_assignable_v<T&, const std::optional<U>&&>
    • Pour la surcharge (5), std::is_constructible_v<T, const U&> et std::is_assignable_v<T&, const U&> sont tous deux true.
    • Pour la surcharge (6), std::is_constructible_v<T, U> et std::is_assignable_v<T&, U> sont tous deux true.

Paramètres

  • other — un autre objet optional dont la valeur contenue doit être affectée
  • value — valeur à affecter à la valeur contenue

Valeur de retour

*this

Exceptions

2-6) Lève toute exception levée par le constructeur ou l'opérateur d'affectation de T. Si une exception est levée, l'état d'initialisation de *this (et de other dans le cas de (2,3) et (5,6)) est inchangé, c'est-à-dire que si l'objet contenait une valeur, il en contient toujours une, et inversement. Le contenu de value et les valeurs contenues de *this et other dépendent des garanties de sécurité d'exception de l'opération à l'origine de l'exception (constructeur de copie, affectation par déplacement, etc.).

  1. A les éléments suivantsnoexcept specification:noexcept(std::is_nothrow_move_assignable_v<T> && std::is_nothrow_move_constructible_v<T>)

Notes

Un objet optional op peut être transformé en optional vide avec à la fois op = {}; et op = nullopt;. La première expression construit un objet optional vide avec {} et l'affecte à op.

Exemple

#include <iostream>
#include <optional>

int main()
{
    std::optional<const char*> s1 = "abc", s2; // constructor
    s2 = s1; // assignment
    s1 = "def"; // affectation avec décroissance (U = char[4], T = const char*)
    std::cout << *s2 << ' ' << *s1 << '\n';
}

Output:

abc def
