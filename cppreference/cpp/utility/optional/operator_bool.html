std::optional<T>::operator bool, std::optional<T>::has_value

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr explicit operator bool() const noexcept;  // (depuis C++17)

constexpr bool has_value() const noexcept;  // (depuis C++17)

Vérifie si *this contient une valeur.

Paramètres

(aucune)

Valeur de retour

true si *this contient une valeur, false si *this ne contient pas de valeur.

Exemple

#include <optional>
#include <iostream>

int main()
{
    std::cout << std::boolalpha;

    std::optional<int> opt;
    std::cout << opt.has_value() << '\n';

    opt = 43;
    if (opt)
        std::cout << "value set to " << opt.value() << '\n';
    else
        std::cout << "value not set\n";

    opt.reset();
    if (opt.has_value())
        std::cout << "value still set to " << opt.value() << '\n';
    else
        std::cout << "value no longer set\n";
}

Output:

false
value set to 43
value no longer set
