std::optional<T>::value_or

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class U >
constexpr T value_or( U&& default_value ) const&;  // (1) (depuis C++17)

template< class U >
constexpr T value_or( U&& default_value ) &&;  // (2) (depuis C++17)

Renvoie la valeur contenue si *this possède une valeur, sinon renvoie default_value.

  1. Équivalent à bool(*this) ? **this : static_cast<T>(std::forward<U>(default_value)).

  2. Équivalent à bool(*this) ? std::move(**this) : static_cast<T>(std::forward<U>(default_value)).

Paramètres

  • default_value — la valeur à utiliser si *this est vide

Exigences sur les types

  • T doit satisfaire les exigences de CopyConstructible pour utiliser la surcharge (1).
  • T doit satisfaire les exigences de MoveConstructible pour utiliser la surcharge (2).
  • U&& doit être convertible en T.

Valeur de retour

La valeur courante si *this possède une valeur, sinon default_value.

Exceptions

Toute exception levée par le constructeur sélectionné de la valeur de retour T.

Exemple

#include <cstdlib>
#include <iostream>
#include <optional>

std::optional<const char*> maybe_getenv(const char* n)
{
    if (const char* x = std::getenv(n))
        return x;
    else
        return {};
}

int main()
{
    std::cout << maybe_getenv("SHELL").value_or("(none)") << '\n';
    std::cout << maybe_getenv("MYPWD").value_or("(none)") << '\n';
}
