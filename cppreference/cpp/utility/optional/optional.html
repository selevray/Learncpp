Construit un nouvel objet optional.

  1. Construit un objet qui ne contient pas de valeur.

  2. Constructeur de copie : si other contient une valeur, initialise la valeur contenue comme si l'on initialisait directement (mais sans initialisation directe par liste) un objet de type T avec l'expression *other. Si other ne contient pas de valeur, construit un objet qui ne contient pas de valeur.

  • Ce constructeur est défini comme supprimé si std::is_copy_constructible_v<T> est false.
  • C'est un constructeur trivial si std::is_trivially_copy_constructible_v<T> est true.
  1. Constructeur de déplacement : si other contient une valeur, initialise la valeur contenue comme si l'on initialisait directement (mais sans initialisation directe par liste) un objet de type T avec l'expression std::move(*other), et ne rend pas other vide : un std::optional déplacé contient toujours une valeur, mais celle-ci a été déplacée. Si other ne contient pas de valeur, construit un objet qui ne contient pas de valeur.
  • Ce constructeur ne participe pas à la résolution de surcharge sauf si std::is_move_constructible_v<T> est true.
  • C'est un constructeur trivial si std::is_trivially_move_constructible_v<T> est true.
  1. Constructeur de copie par conversion : si other ne contient pas de valeur, construit un objet optional qui ne contient pas de valeur. Sinon, construit un objet optional qui contient une valeur, initialisée comme si l'on initialisait directement (mais sans initialisation directe par liste) un objet de type T avec l'expression *other.
  • Ce constructeur ne participe pas à la résolution de surcharge sauf si les conditions suivantes sont remplies :
    • std::is_constructible_v<T, const U&> is true.
    • Si T n'est pas (éventuellement qualifié cv) bool, T n'est pas constructible ou convertible à partir d'une expression quelconque de type (éventuellement const) std::optional<U>, c'est-à-dire que les 8 valeurs suivantes sont toutes false :
      • std::is_constructible_v<T, std::optional<U>&>
      • std::is_constructible_v<T, const std::optional<U>&>
      • std::is_constructible_v<T, std::optional<U>&&>
      • std::is_constructible_v<T, const std::optional<U>&&>
      • std::is_convertible_v<std::optional<U>&, T>
      • std::is_convertible_v<const std::optional<U>&, T>
      • std::is_convertible_v<std::optional<U>&&, T>
      • std::is_convertible_v<const std::optional<U>&&, T>
  • Ce constructeur est explicit si et seulement si std::is_convertible_v<const U&, T> est false.
  1. Constructeur de déplacement par conversion : si other ne contient pas de valeur, construit un objet optional qui ne contient pas de valeur. Sinon, construit un objet optional qui contient une valeur, initialisée comme si l'on initialisait directement (mais sans initialisation directe par liste) un objet de type T avec l'expression std::move(*other).
  • Ce constructeur ne participe pas à la résolution de surcharge sauf si les conditions suivantes sont remplies :

      • std::is_convertible_v<const std::optional<U>&&, T>
  • Ce constructeur est explicit si et seulement si std::is_convertible_v<U&&, T> est false.
  1. Construit un objet optional qui contient une valeur, initialisée comme si l'on initialisait directement (mais sans initialisation directe par liste) un objet de type T à partir des arguments std::forward<Args>(args)....
  • Si le constructeur sélectionné de T est un constructeur constexpr, ce constructeur est un constructeur constexpr.
  • La fonction ne participe pas à la résolution de surcharge sauf si std::is_constructible_v<T, Args...> est true.
  1. Construit un objet optional qui contient une valeur, initialisée comme si l'on initialisait directement (mais sans initialisation directe par liste) un objet de type T à partir des arguments ilist, std::forward<Args>(args)....
  • Si le constructeur sélectionné de T est un constructeur constexpr, ce constructeur est un constructeur constexpr.
  • La fonction ne participe pas à la résolution de surcharge sauf si std::is_constructible_v<T, std::initializer_list<U>&, Args...> est true.
  1. Construit un objet optional qui contient une valeur, initialisée comme si l'on initialisait directement (mais sans initialisation directe par liste) un objet de type T avec l'expression std::forward<U>(value).
  • Si le constructeur sélectionné de T est un constructeur constexpr, ce constructeur est un constructeur constexpr.
  • Ce constructeur ne participe pas à la résolution de surcharge sauf si les conditions suivantes sont remplies :
    • std::is_constructible_v<T, U&&> is true.
    • [std::decay_t<U> (jusqu'à C++20) | std::remove_cvref_t<U> (depuis C++20)] n'est ni std::in_place_t ni std::optional<T>.
    • Si T est (éventuellement qualifié cv) bool, [std::decay_t<U> (jusqu'à C++20) | std::remove_cvref_t<U> (depuis C++20)] n'est pas une spécialisation de std::optional.
  • Ce constructeur est explicit si et seulement si std::is_convertible_v<U&&, T> est false.

Paramètres

  • other — un autre objet optional dont la valeur contenue est copiée
  • value — valeur avec laquelle initialiser la valeur contenue
  • args... — arguments avec lesquels initialiser la valeur contenue
  • ilist — liste d'initialisation avec laquelle initialiser la valeur contenue

Exceptions

  1. Lève toute exception levée par le constructeur de T.

  2. Lève toute exception levée par le constructeur de T. Possède les caractéristiques suivantesnoexcept specification:noexcept(std::is_nothrow_move_constructible<T>::value)

4-8) Lève toute exception levée par le constructeur de T.

Guides de déduction

Notes

Avant la résolution du problème LWG 3836, la construction d'un std::optional<bool> à partir de std::optional<U> sélectionnait la surcharge (8) au lieu des surcharges (4,5) si U n'est pas bool. En effet, les surcharges (4,5) ne participaient pas à la résolution de surcharge si T (bool dans ce cas) peut être construit ou converti à partir de std::optional<U>, mais std::optional::operator bool rend la conversion possible pour tout U.

En conséquence, le std::optional<bool> construit contient toujours une valeur. Cette valeur est déterminée par la présence ou non d'une valeur dans l'objet std::optional<U> fourni, plutôt que par la valeur bool initialisée directement à partir de la valeur contenue :

std::optional<bool> op_false(false);
std::optional<int> op_zero(0);

std::optional<int> from_bool(op_false); // OK : contient 0 (initialisé à partir de false)
std::optional<bool> from_int(op_zero);  // DÉFAUT (LWG 3836) : contient true car
                                        // op_zero contient une valeur, même si l'initialisation
                                        // de bool à partir de cette valeur donne false

Exemple

#include <iostream>
#include <optional>
#include <string>

int main()
{
    std::optional<int> o1, // empty
                       o2 = 1, // initialisation à partir d'une rvalue
                       o3 = o2; // constructeur de copie

    // appelle le constructeur std::string( initializer_list<CharT> )
    std::optional<std::string> o4(std::in_place, {'a', 'b', 'c'});

    // appelle le constructeur std::string( size_type count, CharT ch )
    std::optional<std::string> o5(std::in_place, 3, 'A');

    // Construit par déplacement à partir de std::string en utilisant un guide de déduction pour choisir le type

    std::optional o6(std::string{"deduction"});

    std::cout << *o2 << ' ' << *o3 << ' ' << *o4 << ' ' << *o5  << ' ' << *o6 << '\n';
}

Output:

1 1 abc AAA deduction

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 3836 C++17 lors de la construction d'un std::optional<bool> à partir de std::optional<U>, la résolution de surcharge sélectionnerait la surcharge (8) si U n'est pas bool sélectionne toujours le constructeur de copie/déplacement avec conversion dans ce cas
P0602R4 C++17 les constructeurs de copie/déplacement peuvent ne pas être triviaux même si le constructeur sous-jacent est trivial requis pour propager la trivialité
P2231R1 C++20 les constructeurs de conversion (4,5) à partir d'un autre std::optional n'étaient pas constexpr alors que les opérations requises peuvent l'être en C++20 rendu constexpr
