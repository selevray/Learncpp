std::optional<T>::operator->, std::optional<T>::operator*

constexpr const T* operator->() const noexcept;  // (1) (depuis C++17)

constexpr T* operator->() noexcept;  // (1) (depuis C++17)

constexpr const T& operator*() const& noexcept;  // (2) (depuis C++17)

constexpr T& operator*() & noexcept;  // (2) (depuis C++17)

constexpr const T&& operator*() const&& noexcept;  // (2) (depuis C++17)

constexpr T&& operator*() && noexcept;  // (2) (depuis C++17)

Accède à la valeur contenue.

  1. Renvoie un pointeur vers la valeur contenue.

  2. Renvoie une référence vers la valeur contenue.

Le comportement est indéfini si *this ne contient pas de valeur.

Paramètres

(aucune)

Valeur de retour

Pointeur ou référence vers la valeur contenue.

Notes

Cet opérateur ne vérifie pas si l'optional contient une valeur ! Vous pouvez le faire manuellement en utilisant has_value() ou simplement operator bool(). Sinon, si un accès vérifié est nécessaire, value() ou value_or() peut être utilisé.

Exemple

#include <iomanip>
#include <iostream>
#include <optional>
#include <string>

int main()
{
    using namespace std::string_literals;

    std::optional<int> opt1 = 1;
    std::cout << "opt1: " << *opt1 << '\n';

    *opt1 = 2;
    std::cout << "opt1: " << *opt1 << '\n';

    std::optional<std::string> opt2 = "abc"s;
    std::cout << "opt2: " << std::quoted(*opt2) << ", size: " << opt2->size() << '\n';

    // Vous pouvez « prendre » la valeur contenue en appelant operator* sur une rvalue de type optional

    auto taken = *std::move(opt2);
    std::cout << "taken: " << std::quoted(taken) << "\n"
                 "opt2: " << std::quoted(*opt2) << ", size: " << opt2->size()  << '\n';
}

Output:

opt1: 1
opt1: 2
opt2: "abc", size: 3
taken: "abc"
opt2: "", size: 0
