std::nullopt_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <optional>

struct nullopt_t;  // (depuis C++17)

std::nullopt_t est un type de classe vide utilisé pour indiquer qu'un std::optional ne contient pas de valeur.

std::nullopt_t est une LiteralType non agrégat qui n'a pas de constructeur par défaut ni de constructeur à liste d'initialisation, mais possède un constructeur constexpr qui prend un type littéral défini par l'implémentation.

Notes

Les contraintes sur les constructeurs de nullopt_t existent pour prendre en charge à la fois op = {}; et op = nullopt; comme syntaxe pour désactiver un objet optional.

Une implémentation possible de cette classe est

struct nullopt_t {
    constexpr explicit nullopt_t(int) {}
};
