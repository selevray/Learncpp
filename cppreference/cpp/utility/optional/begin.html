std::optional<T>::begin

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr iterator begin() noexcept;  // (depuis C++26)

constexpr const_iterator begin() const noexcept;  // (depuis C++26)

Si *this contient une valeur, renvoie un itérateur vers la valeur contenue. Sinon, une valeur d'itérateur past-the-end.

range-begin-end.svg

Paramètres

(aucune)

Valeur de retour

Itérateur vers la valeur contenue si has_value() est true. Sinon, un itérateur past-the-end.

Complexité

Constante.

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_optional_range_support 202406L (C++26) Prise en charge des intervalles pour std::optional

Exemple

#include <optional>
#include <print>
#include <vector>

int main()
{
    constexpr std::optional<int> none = std::nullopt;
    constexpr std::optional<int> some = 42;

    static_assert(none.begin() == none.end());
    static_assert(some.begin() != some.end());

    // prise en charge de la boucle for basée sur un intervalle
    for (int i : none)
        std::println("'none' has a value of {}", i);

    for (int i : some)
        std::println("'some' has a value of {}", i);

    std::optional<std::vector<int>> many({0, 1, 2});
    for (const auto& v : many)
        std::println("'many' has a value of {}", v);
}

Output:

'some' has a value of 42
'many' has a value of [0, 1, 2]
