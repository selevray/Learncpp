std::optional<T>::end

Renvoie un itérateur de fin. Équivalent à return begin() + has_value();.

Paramètres

(aucune)

Valeur de retour

Itérateur de fin

Complexité

Constante.

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_optional_range_support 202406L (C++26) Prise en charge des intervalles pour std::optional

Exemple

#include <optional>
#include <print>

int main()
{
    constexpr std::optional<int> none = std::nullopt; // optional @1
    constexpr std::optional<int> some = 42;           // optional @2

    static_assert(none.begin() == none.end());
    static_assert(some.begin() != some.end());

    // prise en charge de la boucle for basée sur un intervalle
    for (int i : none)
        std::println("Optional @1 has a value of {}", i);

    for (int i : some)
        std::println("Optional @2 has a value of {}", i);
}

Output:

Optional @2 has a value of 42
