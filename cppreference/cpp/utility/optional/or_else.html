std::optional<T>::or_else

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class F >
constexpr optional or_else( F&& f ) const&;  // (1) (depuis C++23)

template< class F >
constexpr optional or_else( F&& f ) &&;  // (2) (depuis C++23)

Retourne *this si elle contient une valeur. Sinon, retourne le résultat de f.

Le programme est mal formé si std::remove_cvref_t<std::invoke_result_t<F>> n'est pas identique à std::optional<T>.

  1. Équivalent à return *this ? *this : std::forward<F>(f)();. Cette surcharge ne participe à la résolution de surcharge que si std::copy_constructible<T> et std::invocable<F> sont modélisés.

  2. Équivalent à return *this ? std::move(*this) : std::forward<F>(f)();. Cette surcharge ne participe à la résolution de surcharge que si std::move_constructible<T> et std::invocable<F> sont modélisés.

Paramètres

  • f — une fonction ou un objet Callable qui renvoie un std::optional<T>

Valeur de retour

*this ou le résultat de f, comme décrit ci-dessus.

Exemple

#include <iostream>
#include <optional>
#include <string>

int main()
{
    using maybe_int = std::optional<int>;

    auto valueless = []
    {
        std::cout << "Valueless: ";
        return maybe_int{0};
    };

    maybe_int x;
    std::cout << x.or_else(valueless).value() << '\n';

    x = 42;
    std::cout << "Has value: ";
    std::cout << x.or_else(valueless).value() << '\n';

    x.reset();
    std::cout << x.or_else(valueless).value() << '\n';
}

Output:

Valueless: 0
Has value: 42
Valueless: 0
