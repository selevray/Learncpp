Effectue des opérations de comparaison sur les objets optional.

1-7) Compare deux objets optional, lhs et rhs. Les valeurs contenues sont comparées (à l'aide de l'opérateur correspondant de T) uniquement si lhs et rhs contiennent toutes deux une valeur. Sinon,

  • lhs est considéré comme égal à rhs si, et seulement si, lhs et rhs ne contiennent pas de valeur.
  • lhs est considéré comme inférieur à rhs si, et seulement si, rhs contient une valeur et lhs n'en contient pas.

1-6) Soit @ l'opérateur de comparaison correspondant, pour chacune de ces fonctions :

Si l'expression correspondante *lhs @ *rhs est mal formée ou si son résultat n'est pas convertible en bool, le programme est mal formé.

(jusqu'à C++26)

Cette surcharge ne participe à la résolution de surcharge que si l'expression correspondante *lhs @ *rhs est bien formée et que son résultat est convertible en bool.

(depuis C++26)

8-20) Compare opt avec un nullopt. Équivalent à (1-6) lors de la comparaison avec un optional ne contenant pas de valeur.

Les opérateurs <, <=, >, >= et != sont synthétisés à partir de operator<=> et operator== respectivement.

(depuis C++20)

21-33) Compare opt avec un value. Les valeurs sont comparées (à l'aide de l'opérateur correspondant de T) uniquement si opt contient une valeur. Sinon, opt est considéré comme inférieur à value.

21-32) Soit @ l'opérateur de comparaison correspondant, pour chacune de ces fonctions :

Si l'expression correspondante *opt @ value ou value @ *opt (selon la position des opérandes) est mal formée ou si son résultat n'est pas convertible en bool, le programme est mal formé.

(jusqu'à C++26)

Cette surcharge ne participe à la résolution de surcharge que si toutes les conditions suivantes sont satisfaites :

  • U n'est pas une spécialisation de std::optional.
  • L'expression correspondante *opt @ value ou value @ *opt (selon la position des opérandes) est bien formée et son résultat est convertible en bool.

(depuis C++26)

Paramètres

  • lhs, rhs, opt — un objet optional à comparer
  • value — valeur à comparer à la valeur contenue

Valeur de retour

  1. lhs.has_value() != rhs.has_value() ? false : (lhs.has_value() == false ? true : *lhs == *rhs)

  2. lhs.has_value() != rhs.has_value() ? true : (lhs.has_value() == false ? false : *lhs != *rhs)

  3. !rhs ? false : (!lhs ? true : *lhs < *rhs)

  4. !lhs ? false : (!rhs ? true : *lhs > *rhs)

  5. !lhs ? true : (!rhs ? false : *lhs <= *rhs)

  6. !rhs ? true : (!lhs ? false : *lhs >= *rhs)

  7. lhs && rhs ? *lhs <=> *rhs : lhs.has_value() <=> rhs.has_value()

8,9) !opt

10,11) opt.has_value()

Exceptions
