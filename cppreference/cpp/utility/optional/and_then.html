std::optional<T>::and_then

Si *this contient une valeur, invoque f avec la valeur contenue comme argument, et renvoie le résultat de cet appel ; sinon, renvoie un std::optional vide.

Le type de retour (voir ci-dessous) doit être une spécialisation de std::optional (contrairement à transform()). Sinon, le programme est mal formé.

  1. Équivalent à
if (*this)
    return std::invoke(std::forward<F>(f), value());
else
    return std::remove_cvref_t<std::invoke_result_t<F, T&>>{};
  1. Équivalent à
if (*this)
    return std::invoke(std::forward<F>(f), value());
else
    return std::remove_cvref_t<std::invoke_result_t<F, const T&>>{};
  1. Équivalent à
if (*this)
    return std::invoke(std::forward<F>(f), std::move(value()));
else
    return std::remove_cvref_t<std::invoke_result_t<F, T>>{};
  1. Équivalent à
if (*this)
    return std::invoke(std::forward<F>(f), std::move(value());
else
    return std::remove_cvref_t<std::invoke_result_t<F, const T>>{};

Paramètres

  • f — une fonction appropriée ou un objet Callable qui renvoie un std::optional

Valeur de retour

Le résultat de f ou un std::optional vide, comme décrit ci-dessus.

Notes

Certains langages appellent cette opération flatmap.

Exemple

#include <charconv>
#include <iomanip>
#include <iostream>
#include <optional>
#include <ranges>
#include <string>
#include <string_view>
#include <vector>

std::optional<int> to_int(std::string_view sv)
{
    int r{};
    auto [ptr, ec]{std::from_chars(sv.data(), sv.data() + sv.size(), r)};
    if (ec == std::errc())
        return r;
    else
        return std::nullopt;
}

int main()
{
    using namespace std::literals;

    const std::vector<std::optional<std::string>> v
    {
        "1234", "15 foo", "bar", "42", "5000000000", " 5", std::nullopt, "-43"
    };

    for (auto&& x : v | std::views::transform(
        [](auto&& o)
        {
            // affiche en débogage le contenu de l'entrée optional<string>
            std::cout << std::left << std::setw(13)
                      << std::quoted(o.value_or("nullopt")) << " -> ";

            return o
                // si optional est nullopt, le convertit en optional avec la chaîne ""
                .or_else([]{ return std::optional{""s}; })
                // flatmap de chaînes vers entiers (en créant des optionals vides en cas d'échec)
                .and_then(to_int)
                // applique int à int + 1
                .transform([](int n) { return n + 1; })
                // reconvertit en chaînes
                .transform([](int n) { return std::to_string(n); })
                // remplace tous les optionals vides laissés par
                // and_then et ignorés par les transformations avec « NaN »
                .value_or("NaN"s);
        }))
        std::cout << x << '\n';
}

Output:

"1234"        -> 1235
"15 foo"      -> 16
"bar"         -> NaN
"42"          -> 43
"5000000000"  -> NaN
" 5"          -> NaN
"nullopt"     -> NaN
"-43"         -> -42

Voir aussi

  • value_or — renvoie la valeur contenue si elle est disponible, une autre valeur sinon (fonction membre publique)
  • transform (C++23) — renvoie un optional contenant la valeur contenue transformée si elle existe, ou un optional vide sinon (fonction membre publique)
  • or_else (C++23) — renvoie le optional lui-même s'il contient une valeur, ou le résultat de la fonction donnée sinon (fonction membre publique)
