Fonctions variadiques

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les fonctions variadiques sont des fonctions (par ex. std::printf) qui prennent un nombre variable d'arguments.

Pour déclarer une fonction variadique, une ellipse apparaît après la liste des paramètres, par ex. int printf(const char* format...);, ellipse qui peut être précédée d'une virgule facultative. Voir Arguments variadiques pour plus de détails sur la syntaxe, les conversions automatiques d'arguments et les alternatives.

Pour accéder aux arguments variadiques depuis le corps de la fonction, les outils de bibliothèque suivants sont fournis :

Défini dans l'en-tête <cstdarg>

  • va_start — permet l'accès aux arguments d'une fonction variadique (macro de fonction)
  • va_arg — accède au prochain argument de la fonction variadique (macro de fonction)
  • va_copy (C++11) — crée une copie des arguments de la fonction variadique (macro de fonction)
  • va_end — termine le parcours des arguments de la fonction variadique (macro de fonction)
  • va_list — contient les informations nécessaires à va_start, va_arg, va_end et va_copy (typedef)

Exemple

#include <cstdarg>
#include <iostream>

void simple_printf(const char* fmt...) // Le style C "const char* fmt, ..." est également valide
{
    va_list args;
    va_start(args, fmt);

    while (*fmt != '\0')
    {
        if (*fmt == 'd')
        {
            int i = va_arg(args, int);
            std::cout << i << '\n';
        }
        else if (*fmt == 'c')
        {
            // notez la conversion automatique vers un type entier
            int c = va_arg(args, int);
            std::cout << static_cast<char>(c) << '\n';
        }
        else if (*fmt == 'f')
        {
            double d = va_arg(args, double);
            std::cout << d << '\n';
        }
        ++fmt;
    }

    va_end(args);
}

int main()
{
    simple_printf("dcff", 3, 'a', 1.999, 42.5);
}

Output:

3
a
1.999
42.5
