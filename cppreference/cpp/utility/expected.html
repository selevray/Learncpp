std::expected

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <expected>

template< class T, class E >
class expected;  // (1) (depuis C++23)

template< class T, class E >
    requires std::is_void_v<T>
class expected<T, E>;  // (2) (depuis C++23)

Le modèle de classe std::expected fournit un moyen de représenter l'une de deux valeurs : une valeur attendue de type T, ou une valeur inattendue de type E. std::expected n'est jamais sans valeur.

  1. Le modèle principal. Contient la valeur attendue ou inattendue dans son propre stockage. Aucune allocation dynamique de mémoire n'a lieu.

  2. La spécialisation partielle void. Représente une valeur attendue de type void ou contient la valeur inattendue dans son propre stockage. Aucune allocation dynamique de mémoire n'a lieu.

Un programme est mal formé s'il instancie un expected avec un type référence, un type fonction, ou une spécialisation de std::unexpected. De plus, T ne doit pas être std::in_place_t ni std::unexpect_t.

Paramètres de modèle

  • T — le type de la valeur attendue. Ce type doit être soit (éventuellement qualifié cv) void, soit satisfaire les exigences de Destructible (en particulier, les types tableau et référence ne sont pas autorisés).
  • E — le type de la valeur inattendue. Ce type doit satisfaire les exigences de Destructible, et doit être un argument de modèle valide pour std::unexpected (en particulier, les tableaux, les types non objets et les types qualifiés cv ne sont pas autorisés).

  • error_or — renvoie la valeur inattendue si elle est présente, une autre valeur sinon (fonction membre publique)

##### Opérations monadiques {#Monadic_operations}

  • and_then — renvoie le résultat de la fonction donnée appliquée à la valeur attendue si elle existe ; sinon, renvoie expected lui-même (fonction membre publique)
  • transform — renvoie un expected contenant la valeur attendue transformée si elle existe ; sinon, renvoie le expected lui-même (fonction membre publique)
  • or_else — renvoie expected lui-même s'il contient une valeur attendue ; sinon, renvoie le résultat de la fonction donnée appliquée à la valeur inattendue (fonction membre publique)
  • transform_error — renvoie expected lui-même s'il contient une valeur attendue ; sinon, renvoie un expected contenant la valeur inattendue transformée (fonction membre publique)

Exemple

#include <cmath>
#include <expected>
#include <iomanip>
#include <iostream>
#include <string_view>

enum class parse_error
{
    invalid_input,
    overflow
};

auto parse_number(std::string_view& str) -> std::expected<double, parse_error>
{
    const char* begin = str.data();
    char* end;
    double retval = std::strtod(begin, &end);

    if (begin == end)
        return std::unexpected(parse_error::invalid_input);
    else if (std::isinf(retval))
        return std::unexpected(parse_error::overflow);

    str.remove_prefix(end - begin);
    return retval;
}

int main()
{
    auto process = [](std::string_view str)
    {
        std::cout << "str: " << std::quoted(str) << ", ";
        if (const auto num = parse_number(str); num.has_value())
            std::cout << "value: " << *num << '\n';
            // Si num n'avait pas de valeur, déréférencer num
            // entraînerait un comportement indéfini, et
            // num.value() lèverait std::bad_expected_access.
            // num.value_or(123) utilise la valeur par défaut spécifiée 123.
        else if (num.error() == parse_error::invalid_input)
            std::cout << "error: invalid input\n";
        else if (num.error() == parse_error::overflow)
            std::cout << "error: overflow\n";
        else
            std::cout << "unexpected!\n"; // ou appelle std::unreachable();
    };

    for (auto src : {"42", "42abc", "meow", "inf"})
        process(src);
}

Output:

str: "42", value: 42
str: "42abc", value: 42
str: "meow", error: invalid input
str: "inf", error: overflow
