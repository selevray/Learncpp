std::to_chars

std::to_chars_result

Convertit value en chaîne de caractères en remplissant successivement l'intervalle [first,last), où [first,last) doit être un intervalle valide.

  1. Formateurs d'entiers : value est converti en chaîne de chiffres dans la base donnée (sans zéros de tête superflus). Les chiffres de l'intervalle 10..35 (inclus) sont représentés par des caractères minuscules a..z. Si value est inférieur à zéro, la représentation commence par un signe moins. La bibliothèque fournit des surcharges pour tous les types entiers signés et non signés non qualifiés cv (depuis C++23), ainsi que pour le type char comme type du paramètre value.

  2. La surcharge pour bool est supprimée. std::to_chars rejette l'argument de type bool car le résultat serait "0"/"1" mais non "false"/"true" si elle était autorisée.

  3. value est converti en chaîne comme par std::printf dans la locale par défaut ("C"). Le spécificateur de conversion est f ou e (en privilégiant f en cas d'égalité), choisi selon l'exigence de représentation la plus courte : la représentation en chaîne se compose du plus petit nombre de caractères tel qu'il y ait au moins un chiffre avant le point de base (s'il est présent) et que l'analyse de la représentation à l'aide de la fonction std::from_chars correspondante restitue exactement value. S'il existe plusieurs de ces représentations, celle ayant la plus petite différence avec value est choisie, les égalités restantes étant départagées par l'arrondi selon std::round_to_nearest. La bibliothèque fournit des surcharges pour tous les types à virgule flottante standard (jusqu'à C++23) non qualifiés cv comme type du paramètre value.

  4. Identique à (3), mais la conversion spécifiée pour le printf simulé est f si fmt est std::chars_format::fixed, e si fmt est std::chars_format::scientific, a (mais sans « 0x » initial dans le résultat) si fmt est std::chars_format::hex, et g si fmt est chars_format::general. La bibliothèque fournit des surcharges pour tous les types à virgule flottante standard (jusqu'à C++23) non qualifiés cv comme type du paramètre value.

  5. Identique à (4), sauf que la précision est spécifiée par le paramètre precision plutôt que par l'exigence de représentation la plus courte. La bibliothèque fournit des surcharges pour tous les types à virgule flottante standard (jusqu'à C++23) non qualifiés cv comme type du paramètre value.

Paramètres

  • first, last — intervalle de caractères dans lequel écrire
  • value — la valeur à convertir en sa représentation en chaîne
  • base — base entière à utiliser : une valeur comprise entre 2 et 36 (inclus).
  • fmt — format de mise en forme des nombres à virgule flottante à utiliser, un masque de bits de type std::chars_format
  • precision — précision en virgule flottante à utiliser

Valeur de retour

En cas de succès, renvoie une valeur de type std::to_chars_result telle que ec est égal à std::errc value-initialisé et ptr est le pointeur pointant juste après le dernier caractère écrit. Notez que la chaîne n'est pas terminée par NUL.

En cas d'erreur, renvoie une valeur de type std::to_chars_result contenant std::errc::value_too_large dans ec, une copie de la valeur last dans ptr, et laisse le contenu de l'intervalle [first,last) dans un état non spécifié.

Exceptions

Ne lève aucune exception.

Notes

Contrairement aux autres fonctions de formatage des bibliothèques C++ et C, std::to_chars est indépendante de la locale, n'alloue pas de mémoire et ne lève pas d'exception. Seul un petit sous-ensemble des politiques de formatage utilisées par d'autres bibliothèques (telles que std::sprintf) est fourni. Ceci vise à permettre l'implémentation la plus rapide possible, utile dans les contextes courants à haut débit comme l'échange de texte (JSON ou XML).

La garantie que std::from_chars peut restituer exactement toute valeur à virgule flottante formatée par std::to_chars n'est fournie que si les deux fonctions proviennent de la même implémentation.

Il est nécessaire de convertir explicitement une valeur bool en un autre type entier pour la formater comme "0"/"1".

Exemple

#include <charconv>
#include <iomanip>
#include <iostream>
#include <string_view>
#include <system_error>

void show_to_chars(auto... format_args)
{
    const size_t buf_size = 10;
    char buf[buf_size]{};
    std::to_chars_result result = std::to_chars(buf, buf + buf_size, format_args...);

    if (result.ec != std::errc())
        std::cout << std::make_error_code(result.ec).message() << '\n';
    else
    {
        std::string_view str(buf, result.ptr - buf);
        std::cout << std::quoted(str) << '\n';
    }
}

int main()
{
    show_to_chars(42);
    show_to_chars(+3.14159F);
    show_to_chars(-3.14159, std::chars_format::fixed);
    show_to_chars(-3.14159, std::chars_format::scientific, 3);
    show_to_chars(3.1415926535, std::chars_format::fixed, 10);
}

Sortie possible :

"3.14159"
