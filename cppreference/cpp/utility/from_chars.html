std::from_chars

Défini dans l'en-tête <charconv>

std::from_chars_result
    from_chars( const char* first, const char* last,
                /* type entier */& value, int base = 10 );  // (1) (depuis C++17) (constexpr depuis C++23)

std::from_chars_result
    from_chars( const char* first, const char* last,
                /* type à virgule flottante */& value,
                std::chars_format fmt = std::chars_format::general );  // (2) (depuis C++17)

Analyse la séquence de caractères [first,last) selon un motif décrit ci-dessous. Si aucun caractère ne correspond au motif, ou si la valeur obtenue en analysant les caractères correspondants n'est pas représentable dans le type de value, value n'est pas modifié ; sinon, les caractères correspondant au motif sont interprétés comme une représentation textuelle d'une valeur arithmétique, qui est stockée dans value.

  1. Analyseurs d'entiers : attend le motif identique à celui utilisé par std::strtol dans les paramètres régionaux par défaut (« C ») et la base numérique non nulle donnée, sauf que
  • les préfixes "0x" ou "0X" ne sont pas reconnus si base vaut 16
  • seul le signe moins est reconnu (pas le signe plus), et seulement pour les types entiers signés de value
  • les espaces en début de chaîne ne sont pas ignorés.

La bibliothèque fournit des surcharges pour tous les types entiers signés et non signés non qualifiés cv (depuis C++23) ainsi que char comme type référencé du paramètre value.

  1. Analyseurs de nombres à virgule flottante : attend le motif identique à celui utilisé par std::strtod dans la locale par défaut (« C »), à l'exception que
  • le signe plus n'est pas reconnu en dehors de l'exposant (seul le signe moins est autorisé au début)
  • si fmt a std::chars_format::scientific défini mais pas std::chars_format::fixed, la partie exposant est obligatoire (sinon elle est facultative)
  • si fmt a std::chars_format::fixed défini mais pas std::chars_format::scientific, l'exposant facultatif n'est pas autorisé
  • si fmt vaut std::chars_format::hex, le préfixe "0x" ou "0X" n'est pas autorisé (la chaîne "0x123" est analysée comme la valeur "0" avec le reste non analysé "x123")
  • les espaces en début de chaîne ne sont pas ignorés.

Dans tous les cas, la valeur résultante est l'une des deux valeurs à virgule flottante au plus les plus proches de la valeur de la chaîne correspondant au motif, après arrondi selon std::round_to_nearest.

La bibliothèque fournit des surcharges pour tous les types à virgule flottante standard (jusqu'à C++23) non qualifiés cv comme type référencé du paramètre value.

Paramètres

  • first, last — intervalle de caractères valide à analyser
  • value — le paramètre de sortie où la valeur analysée est stockée en cas de succès
  • base — base entière à utiliser : une valeur comprise entre 2 et 36 (inclus).
  • fmt — format de mise en forme des nombres à virgule flottante à utiliser, un masque de bits de type std::chars_format

Valeur de retour

En cas de succès, renvoie une valeur de type std::from_chars_result telle que ptr pointe vers le premier caractère ne correspondant pas au motif, ou dont la valeur est égale à last si tous les caractères correspondent et que ec est initialisé par valeur.

Si aucun motif ne correspond, renvoie une valeur de type std::from_chars_result telle que ptr est égal à first et ec est égal à std::errc::invalid_argument. value n'est pas modifié.

Si le motif a correspondu, mais que la valeur analysée n'est pas dans l'intervalle représentable par le type de value, renvoie une valeur de type std::from_chars_result telle que ec est égal à std::errc::result_out_of_range et ptr pointe vers le premier caractère ne correspondant pas au motif. value n'est pas modifié.

Exceptions

Ne lève aucune exception.

Notes

Contrairement aux autres fonctions d'analyse des bibliothèques C++ et C, std::from_chars est indépendante de la locale, sans allocation et sans lever d'exception. Seul un petit sous-ensemble des politiques d'analyse utilisées par d'autres bibliothèques (comme std::sscanf) est fourni. Ceci permet une implémentation aussi rapide que possible, utile dans les contextes courants à haut débit tels que les échanges de texte (JSON ou XML).

La garantie que std::from_chars peut retrouver exactement toute valeur à virgule flottante formatée par std::to_chars n'est fournie que si les deux fonctions proviennent de la même implémentation.

Un motif constitué d'un signe sans chiffres qui le suivent est traité comme un motif ne correspondant à rien.

Exemple

#include <cassert>
#include <charconv>
#include <iomanip>
#include <iostream>
#include <optional>
#include <string_view>
#include <system_error>

int main()
{
    for (std::string_view const str : {"1234", "15 foo", "bar", " 42", "5000000000"})
    {
        std::cout << "String: " << std::quoted(str) << ". ";
        int result{};
        auto [ptr, ec] = std::from_chars(str.data(), str.data() + str.size(), result);

        if (ec == std::errc())
            std::cout << "Result: " << result << ", ptr -> " << std::quoted(ptr) << '\n';
        else if (ec == std::errc::invalid_argument)
            std::cout << "This is not a number.\n";
        else if (ec == std::errc::result_out_of_range)
            std::cout << "This number is larger than an int.\n";
    }

    // Démonstration de constexpr from_char en C++23 / démonstration de operator bool() en C++26 :
    auto to_int = [](std::string_view s) -> std::optional<int>
    {
        int value{};
#if __cpp_lib_to_chars >= 202306L
        if (std::from_chars(s.data(), s.data() + s.size(), value))
#else
        if (std::from_chars(s.data(), s.data() + s.size(), value).ec == std::errc{})
#endif
            return value;
        else
            return std::nullopt;
    };

    assert(to_int("42") == 42);
    assert(to_int("foo") == std::nullopt);
#if __cpp_lib_constexpr_charconv and __cpp_lib_optional >= 202106
    static_assert(to_int("42") == 42);
    static_assert(to_int("foo") == std::nullopt);
#endif
}

Output:

String: "1234". Result: 1234, ptr -> ""
String: "15 foo". Result: 15, ptr -> " foo"
String: "bar". This is not a number.
String: " 42". This is not a number.
String: "5000000000". This number is larger than an int.
