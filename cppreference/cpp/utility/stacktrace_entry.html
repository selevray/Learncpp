class stacktrace_entry;  // (depuis C++23)

La classe stacktrace_entry fournit des opérations permettant d'interroger des informations sur une évaluation dans une pile d'appels. Chaque objet stacktrace_entry est soit vide, soit représente une évaluation dans une pile d'appels.

stacktrace_entry modélise std::regular et std::three_way_comparable<std::strong_ordering>.

Types membres

  • (destructeur) — détruit le stacktrace_entry (fonction membre publique)
  • operator= — affecte le contenu d'un stacktrace_entry à un autre (fonction membre publique)

##### Observateurs {#Observers}

  • native_handle — obtient le handle natif défini par l'implémentation de stacktrace_entry (fonction membre publique)
  • operator bool — vérifie si le stacktrace_entry est vide (fonction membre publique)

##### Interrogation {#Query}

  • description — obtient la description de l'évaluation représentée par stacktrace_entry (fonction membre publique)
  • source_file — obtient le nom du fichier source qui contient lexicalement l'expression ou l'instruction dont l'évaluation est représentée par stacktrace_entry (fonction membre publique)
  • source_line — obtient le numéro de ligne qui se rapporte lexicalement à l'évaluation représentée par stacktrace_entry (fonction membre publique)
