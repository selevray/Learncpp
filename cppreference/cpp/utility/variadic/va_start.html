va_start

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdarg>

void va_start( std::va_list ap, parm_n );

La macro va_start permet d'accéder aux arguments variables suivant l'argument nommé parm_n.

va_start doit être invoquée avec une instance d'un objet va_list valide ap avant tout appel à va_arg.

Si parm_n est une expansion de paquet ou une entité résultant d'une capture de lambda, le programme est mal formé, aucun diagnostic requis.

(depuis C++11)

Si parm_n est de type référence, ou d'un type non compatible avec le type résultant des promotions d'arguments par défaut, le comportement est indéfini.

Paramètres

  • ap — un objet du type va_list
  • parm_n — le paramètre nommé précédant le premier paramètre variable

Valeur développée

(aucune)

Notes

va_start doit prendre en charge parm_n avec des operator& surchargés.

Exemple

#include <cstdarg>
#include <iostream>

int add_nums(int count...)
{
    int result = 0;
    std::va_list args;
    va_start(args, count);
    for (int i = 0; i < count; ++i)
        result += va_arg(args, int);
    va_end(args);
    return result;
}

int main()
{
    std::cout << add_nums(4, 25, 25, 50, 50) << '\n';
}

Output:

150
