std::basic_string_view

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <string_view>

template<
    class CharT,
    class Traits = std::char_traits<CharT>
> class basic_string_view;  // (depuis C++17)

Le modèle de classe basic_string_view décrit un objet pouvant référencer une séquence contiguë constante de CharT, le premier élément de la séquence se trouvant à la position zéro.

Pour un basic_string_view str, les pointeurs, itérateurs et références vers les éléments de str sont invalidés lorsqu'une opération invalide un pointeur dans l'intervalle [str.data(),str.data() + str.size()).

Toute spécialisation de std::basic_string_view est un type TriviallyCopyable.

(depuis C++23)

Une implémentation typique ne contient que deux membres : un pointeur vers CharT constant et une taille.

Notes

Il incombe au programmeur de s'assurer que std::string_view ne survit pas au tableau de caractères pointé :

std::string_view good{"a string literal"};
    // Cas « bon » : `good` pointe vers un tableau statique.
    // Les littéraux de chaîne résident dans un stockage de données persistant.

std::string_view bad{"a temporary string"s};
    // Cas « mauvais » : `bad` contient un pointeur pendant, car le temporaire std::string,
    // créé par std::operator""s, sera détruit à la fin de l'instruction.

Les spécialisations de std::basic_string_view sont déjà des types trivialement copiables dans toutes les implémentations existantes, même avant l'exigence formelle introduite en C++23.

Exemple

#include <iostream>
#include <string_view>

int main()
{
    constexpr std::string_view unicode[]{"▀▄─", "▄▀─", "▀─▄", "▄─▀"};

    for (int y{}, p{}; y != 6; ++y, p = ((p + 1) % 4))
    {
        for (int x{}; x != 16; ++x)
            std::cout << unicode[p];
        std::cout << '\n';
    }
}
