static const char_type*
    find( const char_type* ptr, std::size_t count, const char_type& ch );  // (constexpr depuis C++17)

Recherche le caractère ch dans les count premiers caractères de la séquence pointée par ptr.

Voir CharTraits pour les exigences générales sur les traits de caractères pour X::find.

Paramètres

  • ptr — pointeur vers une chaîne de caractères dans laquelle effectuer la recherche
  • count — le nombre de caractères à analyser
  • ch — le caractère à rechercher

Valeur de retour

Un pointeur vers le premier caractère de l'intervalle spécifié par [ptr,ptr + count) qui est égal à ch, ou un pointeur nul si non trouvé.

Complexité

Linéaire en count.
