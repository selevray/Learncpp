static int compare( const char_type* s1, const char_type* s2,
                    std::size_t count );  // (constexpr depuis C++17)

Compare les count premiers caractères des chaînes de caractères s1 et s2. La comparaison est effectuée lexicographiquement.

Si count vaut zéro, les chaînes sont considérées comme égales.

Voir CharTraits pour les exigences générales sur les traits de caractères pour X::compare.

Paramètres

  • s1, s2 — pointeurs vers les chaînes de caractères à comparer
  • count — le nombre de caractères à comparer dans chaque chaîne de caractères

Valeur de retour

Valeur négative si s1 est inférieur à s2.

0 si s1 est égale à s2.

Valeur positive si s1 est supérieur à s2.

Complexité

Linéaire en count.
