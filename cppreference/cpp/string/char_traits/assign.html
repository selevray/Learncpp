static void assign( char_type& c1, const char_type& c2 );  // (1) (noexcept depuis C++11) (constexpr depuis C++17)

static char_type* assign( char_type* ptr, std::size_t count, char_type c2 );  // (2) (constexpr depuis C++20)

  1. Affecte c2 à c1, se comporte de manière identique à c1 = c2.

  2. Affecte c2 à chacun des count caractères de la séquence de caractères pointée par ptr.

Voir CharTraits pour les exigences générales sur les traits de caractères pour X::assign.

Paramètres

  • c1 — caractère à affecter
  • c2 — valeur de caractère à affecter
  • ptr — pointeur vers une séquence de caractères à laquelle affecter
  • count — la longueur de la séquence de caractères

Valeur de retour

  1. (aucun)

  2. ptr

Complexité

  1. Constante.

  2. Linéaire en count.
