static int_type not_eof( int_type e );  // (constexpr depuis C++11) (noexcept depuis C++11)

Étant donné e, produit une valeur appropriée qui n'est pas équivalente à eof.

Cette fonction est généralement utilisée lorsqu'une valeur autre que eof doit être renvoyée, par exemple dans les implémentations de std::basic_streambuf::overflow().

Voir CharTraits pour les exigences générales sur les traits de caractères pour X::not_eof.

Paramètres

  • e — valeur à analyser

Valeur de retour

e si e et eof ne sont pas équivalents, ou une autre valeur non-eof sinon.

Complexité

Constante.
