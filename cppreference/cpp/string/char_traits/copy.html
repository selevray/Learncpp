static char_type*
    copy( char_type* dest, const char_type* src, std::size_t count );  // (constexpr depuis C++20)

Copie count caractères de la chaîne de caractères pointée par src vers la chaîne de caractères pointée par dest.

Si [dest,dest + count) et [src,src + count) se chevauchent, le comportement est indéfini.

Voir CharTraits pour les exigences générales sur les traits de caractères pour X::copy.

Paramètres

  • dest — pointeur vers une chaîne de caractères où copier
  • src — pointeur vers une chaîne de caractères à partir de laquelle copier
  • count — le nombre de caractères à copier

Valeur de retour

dest

Exceptions

Ne lève aucune exception.

Complexité

Linéaire en count.
