Chaînes multioctets terminées par un caractère nul

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Une chaîne multioctet terminée par un caractère nul (NTMBS), ou « chaîne multioctet », est une séquence d'octets non nuls suivie d'un octet de valeur zéro (le caractère nul de fin).

Chaque caractère stocké dans la chaîne peut occuper plus d'un octet. L'encodage utilisé pour représenter les caractères dans une chaîne de caractères multioctets dépend de la locale : il peut s'agir d'UTF-8, GB18030, EUC-JP, Shift-JIS, etc. Par exemple, le tableau de char {'\xe4','\xbd','\xa0','\xe5','\xa5','\xbd','\0'} est une NTMBS contenant la chaîne "你好" encodée en UTF-8 multioctet : les trois premiers octets encodent le caractère 你, les trois octets suivants encodent le caractère 好. La même chaîne encodée en GB18030 est le tableau de char {'\xc4', '\xe3', '\xba', '\xc3', '\0'}, où chacun des deux caractères est encodé sur une séquence de deux octets.

Dans certains encodages multioctets, une même séquence d'octets peut représenter des caractères différents selon les séquences d'octets précédentes, appelées « séquences de décalage ». Ces encodages sont dits dépendants de l'état : la connaissance de l'état de décalage courant est nécessaire pour interpréter chaque caractère. Une NTMBS n'est valide que si elle commence et se termine dans l'état de décalage initial : si une séquence de décalage a été utilisée, la séquence de retour correspondante doit être présente avant le caractère nul de fin. Exemples de tels encodages : le 7-bit JIS, BOCU-1 et SCSU.

Une chaîne de caractères multioctets est compatible en disposition avec une chaîne d'octets terminée par un caractère nul (NTBS), c'est-à-dire qu'elle peut être stockée, copiée et examinée à l'aide des mêmes outils, à l'exception du calcul du nombre de caractères. Si la locale correcte est active, les fonctions d'E/S gèrent aussi les chaînes multioctets. Les chaînes multioctets peuvent être converties vers et depuis des chaînes larges à l'aide des fonctions membres std::codecvt, std::wstring_convert, ou des fonctions de conversion suivantes, dépendantes de la locale :
