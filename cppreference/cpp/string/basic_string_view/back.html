std::basic_string_view<CharT,Traits>::back

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr const_reference back() const;  // (depuis C++17)

Renvoie une référence vers le dernier caractère de la vue. Le comportement est indéfini si empty() == true.

Paramètres

(aucune)

Valeur de retour

Référence au dernier caractère, équivalent à operator[](size() - 1).

Complexité

Constante.

Exemple

#include <iostream>
#include <string_view>

int main()
{
    for (std::string_view str{"ABCDEF"}; !str.empty(); str.remove_suffix(1))
        std::cout << str.back() << ' ' << str << '\n';
}

Output:

F ABCDEF
E ABCDE
D ABCD
C ABC
B AB
A A
