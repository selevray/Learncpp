Forme une vue de chaîne à partir d'un littéral de caractère.

  1. Renvoie std::string_view{str, len}.

  2. Renvoie std::u8string_view{str, len}.

  3. Renvoie std::u16string_view{str, len}.

  4. Renvoie std::u32string_view{str, len}.

  5. Renvoie std::wstring_view{str, len}.

Paramètres

  • str — pointeur vers le début du tableau de caractères brut du littéral
  • len — longueur du tableau de caractères brut du littéral

Valeur de retour

Le littéral std::basic_string_view.

Notes

Ces opérateurs sont déclarés dans l'espace de noms std::literals::string_view_literals, où literals et string_view_literals sont des espaces de noms en ligne. L'accès à ces opérateurs est possible avec l'un des éléments suivants :

  • using namespace std::literals,
  • using namespace std::string_view_literals, or
  • using namespace std::literals::string_view_literals.

Exemple

#include <iostream>
#include <string_view>
#include <typeinfo>

void print_each_character(const std::string_view sw)
{
    for (char c : sw)
        std::cout << (c == '\0' ? '@' : c);
    std::cout << '\n';
}

int main()
{
    using namespace std::literals;

    std::string_view s1 = "abc\0\0def";
    std::string_view s2 = "abc\0\0def"sv;

    std::cout << "s1.size(): " << s1.size() << "; s1: ";
    print_each_character(s1);
    std::cout << "s2.size(): " << s2.size() << "; s2: ";
    print_each_character(s2);

    std::cout << "substr(1, 4): " << "abcdef"sv.substr(1, 4) << '\n';

    auto value_type_info = []<typename T>(T)
    {
        using V = typename T::value_type;
        std::cout << "sizeof " << typeid(V).name() << ": " << sizeof(V) << '\n';
    };

    value_type_info("char A"sv);
    value_type_info(L"wchar_t ∀"sv);
    value_type_info(u8"char8_t ∆"sv);
    value_type_info(u"char16_t ∇"sv);
    value_type_info(U"char32_t ∃"sv);
    value_type_info(LR"(raw ⊞)"sv);
}
