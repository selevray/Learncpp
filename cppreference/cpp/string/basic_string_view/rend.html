std::basic_string_view<CharT,Traits>::rend, std::basic_string_view<CharT,Traits>::crend

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr const_reverse_iterator rend() const noexcept;  // (depuis C++17)

constexpr const_reverse_iterator crend() const noexcept;  // (depuis C++17)

Retourne un itérateur inverse vers le caractère suivant le dernier caractère de la vue inversée. Il correspond au caractère précédant le premier caractère de la vue non inversée. Ce caractère sert de marqueur ; tenter d'y accéder entraîne un comportement indéfini.

range-rbegin-rend.svg

Paramètres

(aucune)

Valeur de retour

const_reverse_iterator vers le caractère suivant le dernier caractère.

Complexité

Constante.

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>
#include <string_view>

int main()
{
    std::ostream_iterator<char> out_it(std::cout);
    std::string_view str_view("abcdef");

    std::copy(str_view.rbegin(), str_view.rend(), out_it);
    *out_it = '\n';

    std::copy(str_view.crbegin(), str_view.crend(), out_it);
    *out_it = '\n';
}
