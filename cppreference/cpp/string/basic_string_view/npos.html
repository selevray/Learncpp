static constexpr size_type npos = size_type(-1);  // (depuis C++17)

Il s'agit d'une valeur spéciale égale à la valeur maximale représentable par le type size_type. Le sens exact dépend du contexte, mais elle est généralement utilisée soit comme indicateur de fin de vue par les fonctions qui attendent un indice de vue, soit comme indicateur d'erreur par les fonctions qui renvoient un indice de vue.

Exemple

#include <string_view>

constexpr bool
contains(std::string_view const what, std::string_view const where) noexcept
{
    return std::string_view::npos != where.find(what);
}
