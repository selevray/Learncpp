std::basic_string_view<CharT,Traits>::find_first_not_of

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr size_type
    find_first_not_of( basic_string_view v, size_type pos = 0 ) const noexcept;  // (1) (depuis C++17)

constexpr size_type
    find_first_not_of( CharT ch, size_type pos = 0 ) const noexcept;  // (2) (depuis C++17)

constexpr size_type
    find_first_not_of( const CharT* s, size_type pos, size_type count ) const;  // (3) (depuis C++17)

constexpr size_type
    find_first_not_of( const CharT* s, size_type pos = 0 ) const;  // (4) (depuis C++17)

Recherche le premier caractère différent de tous les caractères de la séquence de caractères donnée.

  1. Recherche le premier caractère différent de tous les caractères de v dans cette vue, à partir de la position pos.

  2. Équivalent à find_first_not_of(basic_string_view(std::addressof(ch), 1), pos).

  3. Équivalent à find_first_not_of(basic_string_view(s, count), pos).

  4. Équivalent à find_first_not_of(basic_string_view(s), pos).

Paramètres

  • v — vue à rechercher
  • pos — position à laquelle commencer la recherche
  • count — longueur de la chaîne de caractères à comparer
  • s — pointeur vers une chaîne de caractères à comparer
  • ch — caractère à comparer

Valeur de retour

Position du premier caractère différent de tous les caractères de la chaîne donnée, ou std::string_view::npos si aucun tel caractère n'est trouvé.

Complexité

O(size() * v.size()) dans le pire cas.

Exemple

#include <string_view>
using namespace std::literals;

int main()
{
    static_assert(2 == "BCDEF"sv.find_first_not_of("ABC"));
                    //    ^
    static_assert(4 == "BCDEF"sv.find_first_not_of("ABC", 4));
                    //      ^
    static_assert(1 == "BCDEF"sv.find_first_not_of('B'));
                    //   ^
    static_assert(3 == "BCDEF"sv.find_first_not_of('D', 2));
                    //     ^
}
