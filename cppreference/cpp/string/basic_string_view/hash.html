Spécialisations de modèle de std::hash pour les différentes classes de vues, permettant de calculer le hachage des vues.

Ces hachages sont égaux aux hachages des classes std::basic_string correspondantes : si S est l'un des types basic_string standard, SV est le type de vue de chaîne correspondant, et s est un objet de type S, alors std::hash<S>()(s) == std::hash<SV>()(SV(s)).

Exemple

#include <iostream>
#include <string_view>
#include <unordered_set>
using namespace std::literals;

int main()
{
    std::cout << "\"A\"   #: " << std::hash<std::string_view>{}("A"sv) << '\n';
    std::cout << "L\"B\"  #: " << std::hash<std::wstring_view>{}(L"B"sv) << '\n';
    std::cout << "u8\"C\" #: " << std::hash<std::u8string_view>{}(u8"C"sv) << '\n';
    std::cout << "u\"D\"  #: " << std::hash<std::u16string_view>{}(u"D"sv) << '\n';
    std::cout << "U\"E\"  #: " << std::hash<std::u32string_view>{}(U"E"sv) << '\n';

    // std::hash pour la famille string_view permet de conserver ces types de vue
    // dans des conteneurs associatifs unordered_*, tels que unordered_set. Mais il faut garantir
    // que la durée de vie des chaînes référencées ne soit pas inférieure à celle du conteneur,
    // c'est-à-dire qu'aucune référence pendante ne se produise.

    std::unordered_set stars{"Rigel"sv, "Capella"sv, "Vega"sv, "Arcturus"sv};

    for (std::string_view const& s : stars)
        std::cout << s << ' ';
    std::cout << '\n';
}
