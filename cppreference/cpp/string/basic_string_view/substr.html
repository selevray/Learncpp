std::basic_string_view<CharT,Traits>::substr

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr basic_string_view substr( size_type pos = 0,
                                    size_type count = npos ) const;  // (depuis C++17)

Renvoie une vue de la sous-chaîne [pos,pos + rlen), où rlen est le plus petit de count et size() - pos.

Paramètres

  • pos — position du premier caractère
  • count — longueur demandée

Valeur de retour

Vue de la sous-chaîne [pos,pos + rlen).

Exceptions

std::out_of_range if pos > size().

Complexité

Constante.

Exemple

#include <cstddef>
#include <iostream>
#include <stdexcept>
#include <string_view>

int main()
{
    typedef std::size_t count_t, pos_t;

    constexpr std::string_view data{"ABCDEF"};

    std::cout << data.substr() << '\n'; // ABCDEF, c'est-à-dire data[0, 5] soit [0, 6)
    std::cout << data.substr(pos_t(1)) << '\n'; // BCDEF, c'est-à-dire [1, 6)
    std::cout << data.substr(pos_t(2), count_t(3)) << '\n'; // CDE, c'est-à-dire [2, 2 + 3)
    std::cout << data.substr(pos_t(4), count_t(42)) << '\n'; // EF, c'est-à-dire [4, 6)

    try
    {
        [[maybe_unused]]
        auto sub = data.substr(pos_t(666), count_t(1)); // lève : pos > size()
    }
    catch (std::out_of_range const& ex)
    {
        std::cout << ex.what() << '\n';
    }
}
