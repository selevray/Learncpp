std::basic_string_view<CharT,Traits>::at

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr const_reference at( size_type pos ) const;  // (depuis C++17)

Renvoie une référence const au caractère situé à la position pos spécifiée. Une vérification des bornes est effectuée ; une exception de type std::out_of_range est levée en cas d'accès invalide.

Paramètres

  • pos — position du caractère à renvoyer

Valeur de retour

Référence Const vers le caractère demandé.

Exceptions

Lève std::out_of_range si pos >= size().

Complexité

Constante.

Exemple

#include <iostream>
#include <stdexcept>
#include <string_view>

int main()
{
    std::string_view str_view("abcdef");

    try
    {
        for (std::size_t i = 0; true; ++i)
            std::cout << i << ": " << str_view.at(i) << '\n';
    }
    catch (const std::out_of_range& e)
    {
        std::cout << "Whooops. Index is out of range.\n";
        std::cout << e.what() << '\n';
    }
}

Sortie possible :

0: a
1: b
2: c
3: d
4: e
5: f
6: Whooops. Index is out of range.
