Compare deux vues.

Toutes les comparaisons sont effectuées via la fonction membre compare() (elle-même définie en termes de Traits::compare()) :

  • Deux vues sont égales si la taille de lhs et de rhs est identique et si chaque caractère de lhs possède un caractère équivalent dans rhs à la même position.

  • Les comparaisons d'ordre sont effectuées lexicographiquement : la comparaison est réalisée par une fonction équivalente à std::lexicographical_compare.

L'implémentation fournit suffisamment de surcharges supplémentaires constexpr et noexcept de ces fonctions afin qu'un objet basic_string_view<CharT,Traits> sv puisse être comparé à un autre objet t avec une conversion implicite en basic_string_view<CharT,Traits>, avec une sémantique identique à la comparaison de sv et basic_string_view<CharT,Traits>(t).

(jusqu'à C++20)

Le type de retour des opérateurs de comparaison à trois voies (/*comp-cat*/) est Traits::comparison_category si ce qualified-id désigne un type, std::weak_ordering sinon. Si /*comp-cat*/ n'est pas un type de catégorie de comparaison, le programme est mal formé.

Les opérateurs <, <=, >, >= et != sont synthétisés à partir de operator<=> et operator== respectivement.

(depuis C++20)

Paramètres

  • lhs, rhs — vues à comparer

Valeur de retour

1-6) true si la comparaison correspondante est vraie, false sinon.

  1. static_cast</*comp-cat*/>(lhs.compare(rhs) <=> 0).

Complexité

Linéaire en fonction de la taille des vues.

Notes

Des surcharges supplémentaires suffisantes peuvent être implémentées au moyen d'un contexte non déduit dans un type de paramètre.

(jusqu'à C++20)

Le type de résultat de la comparaison à trois voies de std::string_view, std::wstring_view, std::u8string_view, std::u16string_view et std::u32string_view est std::strong_ordering.

std::type_identity_t est utilisé pour un contexte non déduit, ce qui rend comparables à la vue de chaîne les arguments implicitement convertibles en type vue de chaîne.

(depuis C++20)
