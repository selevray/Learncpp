std::basic_string_view<CharT,Traits>::operator=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr basic_string_view& operator=( const basic_string_view& view ) noexcept = default;  // (depuis C++17)

Remplace la vue par celle de view.

Paramètres

  • view — vue à copier

Valeur de retour

*this

Complexité

Constante.

Exemple

#include <iostream>
#include <string_view>

int main()
{
    std::string_view v = "Hello, world";
    v = v.substr(7);
    std::cout << v << '\n';
}

Output:

world
