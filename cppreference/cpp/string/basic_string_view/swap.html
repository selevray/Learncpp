std::basic_string_view<CharT,Traits>::swap

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr void swap( basic_string_view& v ) noexcept;  // (depuis C++17)

Échange la vue avec celle de v.

Paramètres

  • v — vue avec laquelle échanger

Valeur de retour

(aucune)

Complexité

Constante.

Exemple

#include <iostream>
#include <string_view>

int main()
{
    std::string_view a = "AAA";
    std::string_view b = "BBBB";

    std::cout << "Before swap:\n"
                 "a = " << a << "\n"
                 "b = " << b << "\n\n";

    a.swap(b);

    std::cout << "After swap:\n"
                 "a = " << a << "\n"
                 "b = " << b << '\n';
}

Output:

Before swap:
a = AAA
b = BBBB

After swap:
a = BBBB
b = AAA
