operator<<(std::basic_string_view)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <string_view>

template< class CharT, class Traits >
std::basic_ostream<CharT, Traits>&
    operator<<( std::basic_ostream<CharT, Traits>& os,
                std::basic_string_view<CharT, Traits> v );  // (depuis C++17)

Se comporte comme un FormattedOutputFunction. Après construction et vérification de l'objet sentry, détermine le remplissage du format de sortie.

Stocke ensuite chaque caractère de la séquence résultante seq (le contenu de v avec remplissage) dans le flux de sortie os comme si l'on appelait os.rdbuf()->sputn(seq, n), où n est std::max(os.width(), str.size()).

Enfin, appelle os.width(0) pour annuler les effets de std::setw, le cas échéant.

Exceptions

Peut lever std::ios_base::failure si une exception est levée pendant la sortie.

Paramètres

  • os — un flux de sortie de caractères
  • v — la vue à insérer

Valeur de retour

os

Exemple

#include <iomanip>
#include <iostream>
#include <string_view>

int main()
{
    constexpr std::string_view s{"abc"};
    constexpr int width{5};

    // les propriétés fill/left/right sont conservées jusqu'à modification
    std::cout << std::setfill('-');
    std::cout << std::left;

    std::cout << '[' << std::setw(width) << s << "]\n";
    std::cout << '[' << std::setw(width) << s << "]\n";

    std::cout << std::right;
    std::cout << '[' << std::setw(width) << s << "]\n";

    // width est réinitialisé après chaque appel
    std::cout << '[' << s << "]\n";
}

Output:

[abc--]
[abc--]
[--abc]
[abc]
