std::basic_string_view<CharT,Traits>::ends_with

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr bool ends_with( basic_string_view sv ) const noexcept;  // (1) (depuis C++20)

constexpr bool ends_with( CharT ch ) const noexcept;  // (2) (depuis C++20)

constexpr bool ends_with( const CharT* s ) const;  // (3) (depuis C++20)

Vérifie si la vue de chaîne se termine par le suffixe donné, où

  1. le suffixe est une vue de chaîne. Renvoie en fait size() >= sv.size() && compare(size() - sv.size(), npos, sv) == 0.

  2. le suffixe est un seul caractère. Renvoie en fait !empty() && Traits::eq(back(), ch).

  3. le suffixe est une chaîne de caractères terminée par un caractère nul. Renvoie en fait ends_with(basic_string_view(s)).

Paramètres

  • sv — une vue de chaîne pouvant résulter d'une conversion implicite depuis std::basic_string
  • ch — un seul caractère
  • s — une chaîne de caractères terminée par un caractère nul

Valeur de retour

true si la vue de chaîne se termine par le suffixe fourni, false sinon.

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité

Exemple

#include <cassert>
#include <string_view>

int main()
{
    using namespace std::literals;

    assert
    (""
        // (1) ends_with( basic_string_view sv )
        && std::string_view("https://cppreference.com").ends_with(".com"sv) == true
        && std::string_view("https://cppreference.com").ends_with(".org"sv) == false

        // (2) ends_with( CharT c )
        && std::string_view("C++20").ends_with('0') == true
        && std::string_view("C++20").ends_with('3') == false

        // (3) ends_with( const CharT* s )
        && std::string_view("string_view").ends_with("view") == true
        && std::string_view("string_view").ends_with("View") == false
    );
}
