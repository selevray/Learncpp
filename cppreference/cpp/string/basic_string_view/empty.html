std::basic_string_view<CharT,Traits>::empty

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr bool empty() const noexcept;  // (depuis C++17)

Vérifie si la vue ne contient aucun caractère, c'est-à-dire si size() == 0.

Paramètres

(aucune)

Valeur de retour

true si la vue est vide, false sinon.

Complexité

Constante.

Exemple

#include <iostream>
#include <string_view>

// Affiche une chaîne entourée de guillemets simples, sa
// longueur et si elle est considérée comme vide.
void check_string(std::string_view ref)
{
    std::cout << std::boolalpha
              << "'" << ref << "' has " << ref.size()
              << " character(s); emptiness: " << ref.empty() << '\n';
}

int main(int argc, char **argv)
{
    // Une chaîne vide
    check_string("");

    // Presque toujours non vide : argv[0]
    if (argc > 0)
        check_string(argv[0]);
}

Sortie possible :

'' has 0 character(s); emptiness: true
'./a.out' has 7 character(s); emptiness: false
