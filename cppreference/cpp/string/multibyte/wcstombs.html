std::wcstombs

Défini dans l'en-tête <cstdlib>

std::size_t wcstombs( char* dst, const wchar_t* src, std::size_t len );

Convertit une séquence de caractères larges, depuis le tableau dont le premier élément est pointé par src, vers sa représentation multioctet étroite commençant dans l'état de décalage initial. Les caractères convertis sont stockés dans les éléments successifs du tableau char pointé par dst. Au plus len octets sont écrits dans le tableau de destination.

Chaque caractère est converti comme par un appel à std::wctomb, sauf que l'état de conversion de wctomb n'est pas modifié. La conversion s'arrête si :

  • Le caractère nul a été converti et stocké.
  • Un wchar_t a été trouvé qui ne correspond à aucun caractère valide dans la locale C courante.
  • Le prochain caractère multioctet à stocker dépasserait len.

Notes

Dans la plupart des implémentations, cette fonction met à jour un objet statique global de type std::mbstate_t lors du parcours de la chaîne, et ne peut pas être appelée simultanément par deux threads ; std::wcsrtombs doit être utilisée dans ces cas.

POSIX spécifie une extension courante : si dst est un pointeur nul, cette fonction retourne le nombre d'octets qui seraient écrits dans dst, si conversion il y avait. Un comportement similaire est standard pour std::wcsrtombs.

Paramètres

  • dst — pointeur vers le tableau de caractères étroits où le caractère multioctet sera stocké
  • src — pointeur vers le premier élément d'une chaîne large terminée par un caractère nul à convertir
  • len — nombre d'octets disponibles dans le tableau pointé par dst

Valeur de retour

En cas de succès, retourne le nombre d'octets (séquences de décalage comprises, mais à l'exclusion du '\0' terminal) écrits dans le tableau de caractères dont le premier élément est pointé par dst.

En cas d'erreur de conversion (si un caractère large invalide a été rencontré), retourne static_cast<std::size_t>(-1).

Exemple

#include <clocale>
#include <cstdlib>
#include <iostream>

int main()
{
    std::setlocale(LC_ALL, "en_US.utf8");
    // encodage multioctet étroit UTF-8
    const wchar_t* wstr = L"z\u00df\u6c34\U0001d10b"; // ou L"zß水𝄋"
    char mbstr[11];
    std::wcstombs(mbstr, wstr, 11);
    std::cout << "multibyte string: " << mbstr << '\n';
}

Output:

multibyte string: zß水𝄋
