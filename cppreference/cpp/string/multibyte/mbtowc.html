std::mbtowc

Défini dans l'en-tête <cstdlib>

int mbtowc( wchar_t* pwc, const char* s, std::size_t n );

Convertit un caractère multioctet dont le premier octet est pointé par s en un caractère large, écrit dans *pwc si pwc n'est pas nul.

Si s est un pointeur nul, réinitialise l'état de conversion global et détermine si des séquences de décalage sont utilisées.

Paramètres

  • s — pointeur vers le caractère multioctet
  • n — limite du nombre d'octets de s pouvant être examinés
  • pwc — pointeur vers le caractère large de sortie

Valeur de retour

Si s n'est pas un pointeur nul, retourne le nombre d'octets contenus dans le caractère multioctet, ou -1 si les premiers octets pointés par s ne forment pas un caractère multioctet valide, ou 0 si s pointe sur le caractère nul '\0'.

Si s est un pointeur nul, réinitialise son état de conversion interne pour représenter l'état de décalage initial et retourne 0 si l'encodage multioctet courant ne dépend pas d'un état (n'utilise pas de séquences de décalage), ou une valeur non nulle si l'encodage multioctet courant dépend d'un état (utilise des séquences de décalage).

Notes

Chaque appel à mbtowc met à jour l'état de conversion global interne (un objet statique de type std::mbstate_t, connu uniquement de cette fonction). Si l'encodage multioctet utilise des états de décalage, il faut veiller à éviter les retours en arrière ou les parcours multiples. Dans tous les cas, plusieurs threads ne doivent pas appeler mbtowc sans synchronisation : std::mbrtowc peut être utilisé à la place.

Exemple

#include <clocale>
#include <cstdlib>
#include <cstring>
#include <iostream>

int print_mb(const char* ptr)
{
    std::mbtowc(nullptr, 0, 0); // réinitialiser l'état de conversion
    const char* end = ptr + std::strlen(ptr);
    int ret{};
    for (wchar_t wc; (ret = std::mbtowc(&wc, ptr, end - ptr)) > 0; ptr += ret)
        std::wcout << wc;
    std::wcout << '\n';
    return ret;
}

int main()
{
    std::setlocale(LC_ALL, "en_US.utf8");
    // encodage multioctet étroit UTF-8
    const char* str = "z\u00df\u6c34\U0001d10b"; // ou "zß水𝄋"
                      // ou "\x7a\xc3\x9f\xe6\xb0\xb4\xf0\x9d\x84\x8b";
    print_mb(str);
}

Output:

zß水𝄋
