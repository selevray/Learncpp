std::wctomb

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdlib>

int wctomb( char* s, wchar_t wc );

Convertit un caractère large wc en codage multioctet et le stocke (séquences de décalage comprises) dans le tableau de caractères dont le premier élément est pointé par s. Au plus MB_CUR_MAX caractères sont stockés. La conversion dépend de la catégorie LC_CTYPE de la locale courante.

Si wc est le caractère nul, l'octet nul est écrit dans s, précédé des séquences de décalage nécessaires pour rétablir l'état de décalage initial.

Si s est un pointeur nul, réinitialise l'état de conversion global et détermine si des séquences de décalage sont utilisées.

Paramètres

  • s — pointeur vers le tableau de caractères de sortie
  • wc — caractère large à convertir

Valeur de retour

Si s n'est pas un pointeur nul, renvoie le nombre d'octets contenus dans la représentation multioctet de wc, ou -1 si wc n'est pas un caractère valide.

Si s est un pointeur nul, réinitialise son état de conversion interne pour représenter l'état de décalage initial et retourne 0 si l'encodage multioctet courant ne dépend pas d'un état (n'utilise pas de séquences de décalage), ou une valeur non nulle si l'encodage multioctet courant dépend d'un état (utilise des séquences de décalage).

Notes

Chaque appel à wctomb met à jour l'état de conversion global interne (un objet statique de type std::mbstate_t, connu seulement de cette fonction). Si l'encodage multioctet utilise des états de décalage, cette fonction n'est pas réentrante. Dans tous les cas, plusieurs threads ne doivent pas appeler wctomb sans synchronisation : std::wcrtomb peut être utilisée à la place.

Exemple

#include <clocale>
#include <cstdlib>
#include <iomanip>
#include <iostream>
#include <string>

void print_wide(const std::wstring& wstr)
{
    bool shifts = std::wctomb(nullptr, 0); // réinitialiser l'état de conversion
    std::cout << "shift sequences are " << (shifts ? "" : "not" )
              << " used\n" << std::uppercase << std::setfill('0');
    for (const wchar_t wc : wstr)
    {
        std::string mb(MB_CUR_MAX, '\0');
        const int ret = std::wctomb(&mb[0], wc);
        const char* s = ret > 1 ? "s" : "";
        std::cout << "multibyte char '" << mb << "' is " << ret
                  << " byte" << s << ": [" << std::hex;
        for (int i{0}; i != ret; ++i)
        {
            const int c = 0xFF & mb[i];
            std::cout << (i ? " " : "") << std::setw(2) << c;
        }
        std::cout << "]\n" << std::dec;
    }
}

int main()
{
    std::setlocale(LC_ALL, "en_US.utf8");
    // encodage multioctet étroit UTF-8
    std::wstring wstr = L"z\u00df\u6c34\U0001d10b"; // ou L"zß水𝄋"
    print_wide(wstr);
}

Output:

shift sequences are not used
multibyte char 'z' is 1 byte: [7A]
multibyte char 'ß' is 2 bytes: [C3 9F]
multibyte char '水' is 3 bytes: [E6 B0 B4]
multibyte char '𝄋' is 4 bytes: [F0 9D 84 8B]
