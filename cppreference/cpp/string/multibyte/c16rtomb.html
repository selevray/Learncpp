std::c16rtomb

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cuchar>

std::size_t c16rtomb( char* s, char16_t c16, std::mbstate_t* ps );  // (depuis C++11)

Convertit un point de code unique d'une représentation de caractères de 16 bits à longueur variable (typiquement UTF-16) en une représentation de caractère multioctet étroit.

Si s n'est pas un pointeur nul et que c16 est la dernière unité de code de 16 bits d'un encodage valide à longueur variable d'un point de code, la fonction détermine le nombre d'octets nécessaires pour stocker la représentation multioctet de ce point de code (y compris les éventuelles séquences de décalage, et en tenant compte de l'état de conversion multioctet courant *ps), et stocke cette représentation multioctet dans le tableau de caractères dont le premier élément est pointé par s, en mettant à jour *ps si nécessaire. Au plus MB_CUR_MAX octets peuvent être écrits par cette fonction.

Si s est un pointeur nul, l'appel équivaut à std::c16rtomb(buf, u'\0', ps) pour un tampon interne buf.

Si c16 n'est pas l'unité de code finale d'une représentation de 16 bits d'un caractère large, il n'écrit pas dans le tableau pointé par s, seul *ps est mis à jour.

Si c16 est le caractère large nul u'\0', un octet nul est stocké, précédé de toute séquence de décalage nécessaire pour rétablir l'état de décalage initial, et le paramètre d'état de conversion *ps est mis à jour pour représenter l'état de décalage initial.

L'encodage multioctet utilisé par cette fonction est spécifié par la locale C actuellement active.

Paramètres

  • s — pointeur vers le tableau de caractères étroits où le caractère multioctet sera stocké
  • c16 — le caractère 16 bits à convertir
  • ps — pointeur vers l'objet d'état de conversion utilisé lors de l'interprétation de la chaîne multioctet

Valeur de retour

En cas de succès, renvoie le nombre d'octets (y compris les séquences de décalage éventuelles) écrits dans le tableau de caractères dont le premier élément est pointé par s. Cette valeur peut être 0, par exemple lors du traitement du premier char16_t d'une paire de substitution.

En cas d'échec (si c16 n'est pas un caractère 16 bits valide), renvoie -1, stocke EILSEQ dans errno, et laisse *ps dans un état non spécifié.

Notes

La norme C++ délègue à la norme C la sémantique de cette fonction. Dans C11 tel que publié, contrairement à std::mbrtoc16, qui convertit un encodage multioctet à largeur variable (comme UTF-8) en encodage 16 bits à largeur variable (comme UTF-16), cette fonction ne peut convertir qu'un encodage 16 bits à unité unique, ce qui signifie qu'elle ne peut pas convertir UTF-16 en UTF-8, bien que ce soit l'intention initiale de cette fonction. Ceci a été corrigé par le rapport de défaut post-C11 DR488.

Exemple

L'exemple suppose que la correction du rapport de défaut 488 est appliquée.

#include <climits>
#include <clocale>
#include <cuchar>
#include <iomanip>
#include <iostream>
#include <string_view>

int main()
{
    std::setlocale(LC_ALL, "en_US.utf8");
    std::u16string_view strv = u"zß水🍌"; // ou z\u00df\u6c34\U0001F34C
    std::cout << "Processing " << strv.size() << " UTF-16 code units: [ ";
    for (char16_t c : strv)
        std::cout << std::showbase << std::hex << static_cast<int>(c) << ' ';
    std::cout << "]\n";

    std::mbstate_t state{};
    char out[MB_LEN_MAX]{};
    for (char16_t c : strv)
    {
        std::size_t rc = std::c16rtomb(out, c, &state);
        std::cout << static_cast<int>(c) << " converted to [ ";
        if (rc != (std::size_t) - 1)
            for (unsigned char c8 : std::string_view{out, rc})
                std::cout << +c8 << ' ';
        std::cout << "]\n";
    }
}

Output:

0x7a converted to [ 0x7a ]
0xdf converted to [ 0xc3 0x9f ]
0x6c34 converted to [ 0xe6 0xb0 0xb4 ]
0xd83c converted to [ ]
0xdf4c converted to [ 0xf0 0x9f 0x8d 0x8c ]
