struct mbstate_t;

Le type mbstate_t est un type non tableau trivial pouvant représenter n'importe lequel des états de conversion pouvant survenir dans un ensemble défini par l'implémentation de règles d'encodage multioctet supportées. Une valeur de mbstate_t initialisée à zéro représente l'état de conversion initial, bien que d'autres valeurs de mbstate_t puissent exister et représenter également l'état de conversion initial.

Une implémentation possible de mbstate_t est un type struct contenant un tableau représentant le caractère multioctet incomplet, un compteur entier indiquant le nombre d'octets du tableau ayant été traités, et une représentation de l'état de décalage courant.

Les fonctions suivantes ne doivent pas être appelées depuis plusieurs threads sans synchronisation avec l'argument std::mbstate_t* valant un pointeur nul, en raison de courses de données possibles : std::mbrlen, std::mbrtowc, std::mbsrtowcs, std::mbtowc, std::wcrtomb, std::wcsrtombs, std::wctomb.
