std::c32rtomb

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cuchar>

std::size_t c32rtomb( char* s, char32_t c32, std::mbstate_t* ps );  // (depuis C++11)

Convertit un caractère UTF-32 en sa représentation multioctet étroite.

Si s n'est pas un pointeur nul, la fonction détermine le nombre d'octets nécessaires pour stocker la représentation multioctet de c32 (y compris les éventuelles séquences de décalage, et en tenant compte de l'état de conversion multioctet courant *ps), et stocke cette représentation multioctet dans le tableau de caractères dont le premier élément est pointé par s, en mettant à jour *ps si nécessaire. Au plus MB_CUR_MAX octets peuvent être écrits par cette fonction.

Si s est un pointeur nul, l'appel équivaut à std::c32rtomb(buf, U'\0', ps) pour un tampon interne buf.

Si c32 est le caractère large nul U'\0', un octet nul est stocké, précédé de toute séquence de décalage nécessaire pour rétablir l'état de décalage initial, et le paramètre d'état de conversion *ps est mis à jour pour représenter l'état de décalage initial.

L'encodage multioctet utilisé par cette fonction est spécifié par la locale C actuellement active.

Paramètres

  • s — pointeur vers le tableau de caractères étroits où le caractère multioctet sera stocké
  • c32 — le caractère 32 bits à convertir
  • ps — pointeur vers l'objet d'état de conversion utilisé lors de l'interprétation de la chaîne multioctet

Valeur de retour

En cas de succès, renvoie le nombre d'octets (y compris les séquences de décalage) écrits dans le tableau de caractères dont le premier élément est pointé par s. Cette valeur peut être 0, par exemple lors du traitement du premier char32_t d'une séquence multi-char32_t de caractères (ce cas ne se produit pas en UTF-32).

En cas d'échec (si c32 n'est pas un caractère 32 bits valide), renvoie -1, stocke EILSEQ dans errno, et laisse *ps dans un état non spécifié.

Exemple

#include <climits>
#include <clocale>
#include <cuchar>
#include <iomanip>
#include <iostream>
#include <string_view>

int main()
{
    std::setlocale(LC_ALL, "en_US.utf8");
    std::u32string_view strv = U"zß水🍌"; // ou z\u00df\u6c34\U0001F34C
    std::cout << "Processing " << strv.size() << " UTF-32 code units: [ ";
    for (char32_t c : strv)
        std::cout << std::showbase << std::hex << static_cast<int>(c) << ' ';
    std::cout << "]\n";

    std::mbstate_t state{};
    char out[MB_LEN_MAX]{};
    for (char32_t c : strv)
    {
        std::size_t rc = std::c32rtomb(out, c, &state);
        std::cout << static_cast<int>(c) << " converted to [ ";
        if (rc != (std::size_t) - 1)
            for (unsigned char c8 : std::string_view{out, rc})
                std::cout << +c8 << ' ';
        std::cout << "]\n";
    }
}

Output:

Processing 4 UTF-32 code units: [ 0x7a 0xdf 0x6c34 0x1f34c ]
0x7a converted to [ 0x7a ]
0xdf converted to [ 0xc3 0x9f ]
0x6c34 converted to [ 0xe6 0xb0 0xb4 ]
0x1f34c converted to [ 0xf0 0x9f 0x8d 0x8c ]
