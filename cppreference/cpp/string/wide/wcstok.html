Défini dans l'en-tête <cwchar>

wchar_t* wcstok( wchar_t* str, const wchar_t* delim, wchar_t ** ptr);

Trouve le prochain jeton dans une chaîne de caractères larges terminée par un caractère nul pointée par str. Les caractères séparateurs sont identifiés par la chaîne de caractères larges terminée par un caractère nul pointée par delim.

Cette fonction est conçue pour être appelée plusieurs fois afin d'obtenir des jetons successifs de la même chaîne.

  • Si str != nullptr, l'appel est traité comme le premier appel à std::wcstok pour cette chaîne de caractères larges particulière. La fonction recherche le premier caractère large qui n'est pas contenu dans delim.

    • Si aucun tel caractère large n'est trouvé, il n'y a aucun jeton dans str et la fonction renvoie un pointeur nul.
    • Si un tel caractère large est trouvé, il est le début du jeton. La fonction recherche ensuite à partir de ce point le premier caractère large qui est contenu dans delim.
      • Si aucun tel caractère large n'est trouvé, str ne comporte qu'un seul jeton, et les appels futurs à std::wcstok renverront un pointeur nul.
      • Si un tel caractère large est trouvé, il est remplacé par le caractère large nul L'\0' et l'état de l'analyseur (généralement un pointeur vers le caractère large suivant) est stocké à l'emplacement fourni par l'utilisateur *ptr.
    • La fonction renvoie ensuite le pointeur vers le début du jeton.

  • Si str == nullptr, l'appel est traité comme un appel ultérieur à std::wcstok : la fonction reprend là où elle s'était arrêtée lors de l'invocation précédente avec le même *ptr. Le comportement est le même que si le pointeur vers le caractère large qui suit le dernier jeton détecté était passé comme str.

Paramètres

  • str — pointeur vers la chaîne de caractères larges terminée par un caractère nul à découper en jetons
  • delim — pointeur vers la chaîne de caractères larges terminée par un caractère nul identifiant les délimiteurs
  • ptr — pointeur vers un objet de type wchar_t*, utilisé par wcstok pour stocker son état interne

Valeur de retour

Pointeur vers le début du jeton suivant, ou pointeur nul s'il n'y a plus de jetons.

Note

Cette fonction est destructive : elle écrit les L'\0' caractères dans les éléments de la chaîne str. En particulier, un littéral de chaîne de caractères larges ne peut pas être utilisé comme premier argument de std::wcstok.

Contrairement à std::strtok, cette fonction ne met pas à jour le stockage statique : elle stocke l'état de l'analyseur à l'emplacement fourni par l'utilisateur.

Contrairement à la plupart des autres découpeurs, les délimiteurs dans std::wcstok peuvent être différents pour chaque jeton suivant, et peuvent même dépendre du contenu des jetons précédents.

Exemple

#include <cwchar>
#include <iostream>

int main()
{
    wchar_t input[100] = L"A bird came down the walk";
    wchar_t* buffer;
    wchar_t* token = std::wcstok(input, L" ", &buffer);
    while (token)
    {
        std::wcout << token << '\n';
        token = std::wcstok(nullptr, L" ", &buffer);
    }
}

Output:

A
bird
came
down
the
walk
