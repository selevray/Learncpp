const wchar_t* wcspbrk( const wchar_t* dest, const wchar_t* src );

wchar_t* wcspbrk(       wchar_t* dest, const wchar_t* src );

Trouve le premier caractère de la chaîne de caractères larges pointée par dest qui se trouve aussi dans la chaîne de caractères larges pointée par src.

Paramètres

  • dest — pointeur vers la chaîne large terminée par un caractère nul à analyser
  • src — pointeur vers la chaîne large terminée par un caractère nul contenant les caractères à rechercher

Valeur de retour

Pointeur vers le premier caractère de dest qui se trouve aussi dans src, ou un pointeur nul si aucun tel caractère n'existe.

Notes

Le nom signifie « wide character string pointer break », car elle renvoie un pointeur vers le premier caractère séparateur (« break »).

Exemple

#include <cwchar>
#include <iomanip>
#include <iostream>

int main()
{
    const wchar_t* str = L"Hello world, friend of mine!";
    const wchar_t* sep = L" ,!";

    unsigned int cnt = 0;
    do
    {
        str = std::wcspbrk(str, sep); // rechercher le séparateur
        std::wcout << std::quoted(str) << L'\n';
        if (str)
            str += std::wcsspn(str, sep); // ignorer le séparateur
        ++cnt; // incrémenter le nombre de mots
    } while (str && *str);

    std::wcout << L"There are " << cnt << L" words\n";
}

Output:

" world, friend of mine!"
", friend of mine!"
" of mine!"
" mine!"
"!"
There are 5 words
