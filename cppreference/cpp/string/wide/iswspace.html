std::iswspace

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cwctype>

int iswspace( wint_t ch );

Vérifie si le caractère large donné est un caractère d'espacement large, tel que classé par la locale C actuellement installée. Dans la locale par défaut, les caractères d'espacement sont les suivants :

  • Espace (0x20, ' ')
  • Saut de page (0x0c, '\f')
  • Saut de ligne (0x0a, '\n')
  • Retour chariot (0x0d, '\r')
  • Tabulation horizontale (0x09, '\t')
  • Tabulation verticale (0x0b, '\v').

Si la valeur de ch n'est ni représentable sous la forme d'un wchar_t, ni égale à la valeur de la macro WEOF, le comportement est indéfini.

Paramètres

  • ch — caractère large

Valeur de retour

Valeur non nulle si le caractère large est un caractère d'espacement, zéro sinon.

Notes

ISO 30112 définit les caractères d'espacement POSIX comme les caractères Unicode U+0009..U+000D, U+0020, U+1680, U+180E, U+2000..U+2006, U+2008..U+200A, U+2028, U+2029, U+205F et U+3000.

Exemple

Démontre l'utilisation de iswspace avec différentes locales.

#include <clocale>
#include <cwctype>
#include <iostream>

void try_with(wchar_t c, const char* loc)
{
    std::setlocale(LC_ALL, loc);
    std::wcout << "isspace('" << c << "') in " << loc << " locale returned "
               << std::boolalpha << static_cast<bool>(std::iswspace(c)) << '\n';
}

int main()
{
    const wchar_t EM_SPACE = L'\u2003'; // caractère Unicode « EM SPACE »
    try_with(EM_SPACE, "C");
    try_with(EM_SPACE, "en_US.UTF8");
}

Output:

isspace(' ') in C locale returned false
isspace(' ') in en_US.UTF8 locale returned true
