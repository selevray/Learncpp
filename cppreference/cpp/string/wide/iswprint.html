std::iswprint

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cwctype>

int iswprint( std::wint_t ch );

Vérifie si le caractère large donné peut être affiché, c'est-à-dire qu'il s'agit soit d'un chiffre (0123456789), d'une lettre majuscule (ABCDEFGHIJKLMNOPQRSTUVWXYZ), d'une lettre minuscule (abcdefghijklmnopqrstuvwxyz), d'un caractère de ponctuation ( !"#$%&'()*+,-./:;<=>?@[]^_`{!}~ ``), d'un espace, soit de tout caractère imprimable propre à la locale C courante.

Si la valeur de ch n'est ni représentable sous la forme d'un wchar_t, ni égale à la valeur de la macro WEOF, le comportement est indéfini.

Paramètres

  • ch — caractère large

Valeur de retour

Valeur non nulle si le caractère large peut être affiché, zéro sinon.

Notes

ISO 30112 précise quels caractères Unicode font partie de la catégorie POSIX print.

Exemple

#include <clocale>
#include <cwctype>
#include <iostream>

void demo_iswprint(std::string_view rem, const std::wint_t c)
{
    std::cout << std::boolalpha << std::hex << std::showbase
              << rem << "iswprint('" << c << "') = "
              << !!std::iswprint(c) << '\n';
}

int main()
{
    const wchar_t c1 = L'\u2002'; // espace cadratin (en-space)
    const wchar_t c2 = L'\u0082'; // coupure de ligne autorisée

    demo_iswprint("In default locale:\n", c1);

    std::setlocale(LC_ALL, "en_US.utf8");
    demo_iswprint("In Unicode locale:\n", c1);
    demo_iswprint("", c2);
}

Sortie possible :

In default locale:
iswprint('0x2002') = false
In Unicode locale:
iswprint('0x2002') = true
iswprint('0x82') = false
