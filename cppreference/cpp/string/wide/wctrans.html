std::wctrans_t wctrans( const char* str );

Construit une valeur de type std::wctrans_t qui décrit une catégorie LC_CTYPE de correspondance de caractères larges. Elle peut être l'une des correspondances standard, ou une correspondance propre à la locale, telle que "tojhira" ou "tojkata".

Paramètres

  • str — Chaîne C contenant le nom de la correspondance souhaitée.

    Les valeurs suivantes de str sont prises en charge dans toutes les locales C :

    Valeur de str Effet

    • "toupper" — identifie la correspondance utilisée par towupper
    • "tolower" — identifie la correspondance utilisée par towlower

Valeur de retour

Objet std::wctrans_t utilisable avec std::towctrans pour mapper des caractères larges selon la correspondance nommée de la locale C courante, ou zéro si str ne désigne pas une correspondance prise en charge par la locale C courante.
