std::wctype

Défini dans l'en-tête <cwctype>

std::wctype_t wctype( const char* str );

Construit une valeur de type std::wctype_t qui décrit une catégorie LC_CTYPE de classification de caractères larges. Elle peut être l'une des catégories de classification standard, ou une catégorie propre à la locale, telle que "jkanji".

Paramètres

  • str — Chaîne C contenant le nom de la catégorie souhaitée

Les valeurs suivantes de str sont prises en charge dans toutes les locales C :

valeur de str effect

  • "alnum" — identifie la catégorie utilisée par std::iswalnum
  • "alpha" — identifie la catégorie utilisée par std::iswalpha
  • "blank" — identifie la catégorie utilisée par std::iswblank (depuis C++11)
  • "cntrl" — identifie la catégorie utilisée par std::iswcntrl
  • "digit" — identifie la catégorie utilisée par std::iswdigit
  • "graph" — identifie la catégorie utilisée par std::iswgraph
  • "lower" — identifie la catégorie utilisée par std::iswlower
  • "print" — identifie la catégorie utilisée par std::iswprint
  • "space" — identifie la catégorie utilisée par std::iswspace
  • "upper" — identifie la catégorie utilisée par std::iswupper
  • "xdigit" — identifie la catégorie utilisée par std::iswxdigit

Valeur de retour

Objet std::wctype_t utilisable avec std::iswctype pour classer des caractères larges selon la catégorie nommée de la locale C courante, ou zéro si str ne désigne pas une catégorie prise en charge par la locale C courante.
