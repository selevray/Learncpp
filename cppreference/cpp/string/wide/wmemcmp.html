int wmemcmp( const wchar_t* lhs, const wchar_t* rhs, std::size_t count );

Compare les count premiers caractères larges des tableaux de caractères larges pointés par lhs et rhs. La comparaison s'effectue lexicographiquement.

Le signe du résultat est celui de la différence entre les valeurs de la première paire de caractères larges différents dans les tableaux comparés.

Si count vaut zéro, la fonction ne fait rien.

Paramètres

  • lhs, rhs — pointeurs vers les tableaux de caractères larges à comparer
  • count — nombre de caractères larges à examiner

Valeur de retour

Valeur négative si la valeur du premier caractère large différent dans lhs est inférieure à la valeur du caractère large correspondant dans rhs : lhs précède rhs dans l'ordre lexicographique.

0 si les count caractères larges de lhs et rhs sont tous égaux.

Valeur positive si la valeur du premier caractère large différent dans lhs est supérieure à la valeur du caractère large correspondant dans rhs : rhs précède lhs dans l'ordre lexicographique.

Notes

Cette fonction ne dépend pas de la locale et ne tient pas compte des valeurs des objets wchar_t qu'elle examine : les caractères nuls ainsi que les caractères larges invalides sont également comparés.

Exemple

#include <clocale>
#include <cwchar>
#include <iostream>
#include <locale>
#include <string>

void demo(const wchar_t* lhs, const wchar_t* rhs, std::size_t sz)
{
    std::wcout << std::wstring(lhs, sz);
    int rc = std::wmemcmp(lhs, rhs, sz);
    if (rc == 0)
        std::wcout << " compares equal to ";
    else if (rc < 0)
        std::wcout << " precedes ";
    else if (rc > 0)
        std::wcout << " follows ";
    std::wcout << std::wstring(rhs, sz) << " in lexicographical order\n";
}

int main()
{
    std::setlocale(LC_ALL, "en_US.utf8");
    std::wcout.imbue(std::locale("en_US.utf8"));

    wchar_t a1[] = {L'α',L'β',L'γ'};
    constexpr std::size_t sz = sizeof a1 / sizeof *a1;
    wchar_t a2[sz] = {L'α',L'β',L'δ'};

    demo(a1, a2, sz);
    demo(a2, a1, sz);
    demo(a1, a1, sz);
}

Sortie possible :

αβγ precedes αβδ in lexicographical order
αβδ follows αβγ in lexicographical order
αβγ compares equal to αβγ in lexicographical order
