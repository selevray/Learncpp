std::wcstoimax, std::wcstoumax

Défini dans l'en-tête <cinttypes>

std::intmax_t wcstoimax( const wchar_t* nptr, wchar_t** endptr, int base );  // (depuis C++11)

std::uintmax_t wcstoumax( const wchar_t* nptr, wchar_t** endptr, int base );  // (depuis C++11)

Interprète une valeur entière non signée dans une chaîne de caractères larges pointée par nptr.

Ignore les caractères d'espacement (identifiés en appelant std::iswspace) jusqu'à ce que le premier caractère non espace soit trouvé, puis prend autant de caractères que possible pour former une représentation valide d'entier non signé en base-n (où n=base) et les convertit en valeur entière. La valeur entière non signée valide est constituée des parties suivantes :

  • (facultatif) signe plus ou moins
  • (facultatif) préfixe (0) indiquant la base octale (s'applique uniquement lorsque la base vaut 8 ou 0)
  • (optionnel) préfixe (0x ou 0X) indiquant la base hexadécimale (ne s'applique que lorsque la base vaut 16 ou 0)
  • une suite de chiffres

L'ensemble des valeurs valides pour base est {0, 2, 3, ..., 36}. L'ensemble des chiffres valides pour les entiers en base-2 est {0, 1}, pour les entiers en base-3 est {0, 1, 2}, et ainsi de suite. Pour les bases supérieures à 10, les chiffres valides incluent les caractères alphabétiques, à partir de Aa pour un entier en base-11, jusqu'à Zz pour un entier en base-36. La casse des caractères est ignorée.

Des formats numériques supplémentaires peuvent être acceptés par la locale C actuellement installée.

Si la valeur de base vaut 0, la base numérique est détectée automatiquement : si le préfixe est 0, la base est octale ; si le préfixe est 0x ou 0X, la base est hexadécimale ; sinon, la base est décimale.

Si le signe moins faisait partie de la séquence d'entrée, la valeur numérique calculée à partir de la séquence de chiffres est niée comme par moins unaire dans le type de résultat, ce qui applique les règles de repliement modulo des entiers non signés.

La fonction place le pointeur pointé par endptr sur le caractère large suivant le dernier caractère interprété. Si endptr est un pointeur nul, il est ignoré.

Paramètres

  • nptr — pointeur vers la chaîne de caractères larges terminée par un caractère nul à interpréter
  • endptr — pointeur vers un pointeur vers un caractère large
  • base — base de la valeur entière interprétée

Valeur de retour

Valeur entière correspondant au contenu de str en cas de succès. Si la valeur convertie sort de l'intervalle du type de retour correspondant, une erreur d'intervalle se produit et INTMAX_MAX, INTMAX_MIN, UINTMAX_MAX ou 0 est renvoyé, selon le cas. Si aucune conversion ne peut être effectuée, 0 est renvoyé.

Exemple

#include <cinttypes>
#include <iostream>
#include <string>

int main()
{
    std::wstring str = L"helloworld";
    std::intmax_t val = std::wcstoimax(str.c_str(), nullptr, 36);
    std::wcout << str << " in base 36 is " << val << " in base 10\n";

    wchar_t* nptr;
    val = std::wcstoimax(str.c_str(), &nptr, 30);
    if (nptr != &str[0] + str.size())
        std::wcout << str << " in base 30 is invalid."
                   << " The first invalid digit is " << *nptr << '\n';
}

Output:

helloworld in base 36 is 1767707668033969 in base 10
helloworld in base 30 is invalid. The first invalid digit is w
