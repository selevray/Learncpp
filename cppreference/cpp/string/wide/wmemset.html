std::wmemset

Défini dans l'en-tête <cwchar>

wchar_t* wmemset( wchar_t* dest, wchar_t ch, std::size_t count );

Copie le caractère large ch dans chacun des count premiers caractères larges du tableau de caractères larges pointé par dest.

En cas de dépassement, le comportement est indéfini.

Si count vaut zéro, la fonction ne fait rien.

Paramètres

  • dest — pointeur vers le tableau de caractères larges à remplir
  • ch — caractère large de remplissage
  • count — nombre de caractères larges à remplir

Valeur de retour

Retourne une copie de dest.

Notes

Cette fonction ne dépend pas de la locale et ne tient pas compte des valeurs des objets wchar_t qu'elle écrit : les caractères nuls ainsi que les caractères larges invalides sont également écrits.

Exemple

#include <clocale>
#include <cwchar>
#include <iostream>
#include <locale>

int main()
{
    wchar_t ar[4] = {L'1', L'2', L'3', L'4'};
    std::wmemset(ar, L'\U0001f34c', 2); // remplace [12] par les 🍌 bananes
    std::wmemset(ar + 2, L'蕉', 2); // remplace [34] par les 蕉 bananes

    std::setlocale(LC_ALL, "en_US.utf8");
    std::wcout.imbue(std::locale("en_US.utf8"));
    std::wcout << std::wstring(ar, 4) << '\n';
}
