std::towctrans

std::wint_t towctrans( std::wint_t ch, std::wctrans_t desc );

Associe le caractère large ch en utilisant la catégorie de correspondance LC_CTYPE de la locale C actuelle identifiée par desc.

Si la valeur de ch n'est ni représentable sous la forme d'un wchar_t, ni égale à la valeur de la macro WEOF, le comportement est indéfini.

Paramètres

  • ch — le caractère large à associer
  • desc — la correspondance LC_CTYPE, obtenue à partir d'un appel à std::wctrans

Valeur de retour

La valeur associée de ch selon la correspondance identifiée par desc dans la facette LC_CTYPE de la locale C actuelle.

Exemple

L'exemple suivant montre la correspondance des caractères katakana vers hiragana.

#include <algorithm>
#include <clocale>
#include <cwctype>
#include <iostream>

std::wstring tohira(std::wstring str)
{
    std::transform(str.begin(), str.end(), str.begin(), [](wchar_t c)
    {
         return std::towctrans(c, std::wctrans("tojhira"));
    });
    return str;
}

int main()
{
    std::setlocale(LC_ALL, "ja_JP.UTF-8");
    std::wstring kana = L"ヒラガナ";
    std::wcout << "katakana characters " << kana
               << " are " << tohira(kana) << " in hiragana\n";
}

Output:

katakana characters ヒラガナ are ひらがな in hiragana
