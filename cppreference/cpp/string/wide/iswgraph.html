Défini dans l'en-tête <cwctype>

int iswgraph( std::wint_t ch );

Vérifie si le caractère large donné possède une représentation graphique, c'est-à-dire qu'il s'agit soit d'un chiffre (0123456789), d'une lettre majuscule (ABCDEFGHIJKLMNOPQRSTUVWXYZ), d'une lettre minuscule (abcdefghijklmnopqrstuvwxyz), d'un caractère de ponctuation ( !"#$%&'()*+,-./:;<=>?@[]^_`{|}~ ``), soit de tout caractère graphique propre à la locale C courante.

Si la valeur de ch n'est ni représentable sous la forme d'un wchar_t, ni égale à la valeur de la macro WEOF, le comportement est indéfini.

Paramètres

  • ch — caractère large

Valeur de retour

Valeur non nulle si le caractère large possède une représentation graphique, zéro sinon.

Notes

ISO 30112 précise quels caractères Unicode font partie de la catégorie POSIX graph.

Exemple

#include <clocale>
#include <cwctype>
#include <iostream>

int main()
{
    wchar_t c = L'\u2602'; // le caractère Unicode Parapluie ('☂')

    std::cout << std::hex << std::showbase << std::boolalpha
              << "in the default locale, iswgraph("
              << static_cast<std::wint_t>(c) << ") = "
              << static_cast<bool>(std::iswgraph(c)) << '\n';

    std::setlocale(LC_ALL, "en_US.utf8");
    std::cout << "in Unicode locale, iswgraph("
              << static_cast<std::wint_t>(c) << ") = "
              << static_cast<bool>(std::iswgraph(c)) << '\n';
}

Output:

in the default locale, iswgraph(0x2602) = false
in Unicode locale, iswgraph(0x2602) = true
