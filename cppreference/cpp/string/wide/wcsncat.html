Défini dans l'en-tête <cwchar>

wchar_t* wcsncat( wchar_t* dest, const wchar_t* src, std::size_t count );

Ajoute au plus count caractères larges de la chaîne de caractères larges pointée par src à la fin de la chaîne de caractères pointée par dest, en s'arrêtant si le caractère nul de fin est copié. Le caractère large src[0] remplace le caractère nul de fin de dest. Le caractère nul de fin est toujours ajouté à la fin (le nombre maximal de caractères larges que la fonction peut écrire est donc count + 1).

Le comportement est indéfini si le tableau de destination n'est pas assez grand pour contenir à la fois src et dest ainsi que le caractère large nul de fin.

Le comportement est indéfini si les chaînes se chevauchent.

Paramètres

  • dest — pointeur vers la chaîne large terminée par un caractère nul à laquelle ajouter
  • src — pointeur vers la chaîne large terminée par un caractère nul à copier
  • count — nombre maximal de caractères larges à copier

Valeur de retour

dest

Exemple

#include <clocale>
#include <cwchar>
#include <iostream>

int main(void)
{
    wchar_t str[50] = L"Земля, прощай.";
    std::wcsncat(str, L" ", 1);
    std::wcsncat(str, L"В добрый путь.", 8); // n'ajouter que les 8 premiers caractères larges

    std::setlocale(LC_ALL, "en_US.utf8");
    std::wcout.imbue(std::locale("en_US.utf8"));
    std::wcout << str << '\n';
}
