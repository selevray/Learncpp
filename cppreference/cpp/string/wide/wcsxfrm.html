std::wcsxfrm

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cwchar>

std::size_t wcsxfrm( wchar_t* dest, const wchar_t* src, std::size_t count );

Transforme la chaîne de caractères larges terminée par un caractère nul pointée par src en une forme définie par l'implémentation, de sorte que la comparaison de deux chaînes transformées avec std::wcscmp donne le même résultat que la comparaison des chaînes originales avec std::wcscoll, dans la locale C courante.

Les count premiers caractères de la chaîne transformée sont écrits dans destination, y compris le caractère nul de fin, et la longueur de la chaîne transformée complète est retournée, sans compter le caractère nul de fin.

Si count vaut 0, alors dest peut être un pointeur nul.

Notes

La longueur correcte du tampon pouvant recevoir la chaîne transformée entière est 1 + std::wcsxfrm(nullptr, src, 0).

Cette fonction est utilisée lorsque plusieurs comparaisons dépendantes de la locale sont effectuées sur la même chaîne de caractères larges ou le même ensemble de chaînes, car il est plus efficace d'utiliser std::wcsxfrm pour transformer toutes les chaînes une seule fois, puis de comparer ensuite les chaînes larges transformées avec std::wcscmp.

Paramètres

  • dest — pointeur vers le premier élément d'une chaîne de caractères larges terminée par un caractère nul dans laquelle écrire la chaîne transformée
  • src — pointeur vers la chaîne de caractères larges terminée par un caractère nul à transformer
  • count — nombre maximal de caractères à écrire en sortie

Valeur de retour

La longueur de la chaîne de caractères larges transformée, sans le caractère nul de fin.

Exemple

#include <cwchar>
#include <iostream>

int main()
{
    std::setlocale(LC_ALL, "sv_SE.utf8");

    std::wstring in1 = L"\u00e5r";
    std::wstring out1(1 + std::wcsxfrm(nullptr, in1.c_str(), 0), L' ');
    std::wstring in2 = L"\u00e4ngel";
    std::wstring out2(1 + std::wcsxfrm(nullptr, in2.c_str(), 0), L' ');

    std::wcsxfrm(&out1[0], in1.c_str(), out1.size());
    std::wcsxfrm(&out2[0], in2.c_str(), out2.size());

    std::wcout << "In the Swedish locale: ";
    if (out1 < out2)
        std::wcout << in1 << " before " << in2 << '\n';
    else
        std::wcout << in2 << " before " << in1 << '\n';

    std::wcout << "In lexicographical comparison: ";
    if (in1 < in2)
        std::wcout << in1 << " before " << in2 << '\n';
    else
        std::wcout << in2 << " before " << in1 << '\n';

}

Output:

In the Swedish locale: år before ängel
In lexicographical comparison: ängel before år
