wchar_t* wcsncpy( wchar_t* dest, const wchar_t* src, std::size_t count );

Copie au plus count caractères de la chaîne de caractères larges pointée par src (y compris le caractère large nul de fin) dans le tableau de caractères larges pointé par dest.

Si count est atteint avant que la chaîne entière src ait été copiée, le tableau de caractères larges résultant n'est pas terminé par un caractère nul.

Si, après la copie du caractère large nul de fin de src, count n'est pas atteint, des caractères larges nuls supplémentaires sont écrits dans dest jusqu'à ce que le total de count caractères ait été écrit.

Si les chaînes se chevauchent, le comportement est indéfini.

Paramètres

  • dest — pointeur vers le tableau de caractères larges de destination
  • src — pointeur vers la chaîne de caractères larges à copier
  • count — nombre maximal de caractères larges à copier

Valeur de retour

dest

Notes

En utilisation typique, count est la taille du tableau de destination.

Exemple

#include <cwchar>
#include <iostream>

int main()
{
    const wchar_t src[] = L"hi";
    wchar_t dest[6] = {L'a', L'b', L'c', L'd', L'e', L'f'};

    std::wcsncpy(dest, src, 5); // ceci copiera 'hi' et répétera \0 trois fois

    std::wcout << "The contents of dest are: ";
    for (const wchar_t c : dest)
    {
        if (c)
            std::wcout << c << ' ';
        else
            std::wcout << "\\0" << ' ';
    }
    std::wcout << '\n';
}

Output:

The contents of dest are: h i \0 \0 \0 f
