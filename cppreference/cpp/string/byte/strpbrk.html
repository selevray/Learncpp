std::strpbrk

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstring>

const char* strpbrk( const char* dest, const char* breakset );

char* strpbrk(       char* dest, const char* breakset );

Parcourt la chaîne d'octets terminée par un caractère nul pointée par dest à la recherche de tout caractère de la chaîne d'octets terminée par un caractère nul pointée par breakset, et renvoie un pointeur vers ce caractère.

Paramètres

  • dest — pointeur vers la chaîne d'octets terminée par un caractère nul à analyser
  • breakset — pointeur vers la chaîne d'octets terminée par un caractère nul contenant les caractères à rechercher

Valeur de retour

Pointeur vers le premier caractère de dest qui se trouve aussi dans breakset, ou pointeur nul si aucun tel caractère n'existe.

Notes

Le nom signifie « string pointer break » (pointeur de chaîne, rupture), car il renvoie un pointeur vers le premier caractère séparateur (« break »).

Exemple

#include <cstring>
#include <iomanip>
#include <iostream>

int main()
{
    const char* str = "hello world, friend of mine!";
    const char* sep = " ,!";

    unsigned int cnt = 0;
    do
    {
        str = std::strpbrk(str, sep); // rechercher le séparateur
        std::cout << std::quoted(str) << '\n';
        if (str)
            str += std::strspn(str, sep); // ignorer le séparateur
        ++cnt; // incrémenter le nombre de mots
    } while (str && *str);

    std::cout << "There are " << cnt << " words\n";
}

Output:

" world, friend of mine!"
", friend of mine!"
" of mine!"
" mine!"
"!"
There are 5 words
