std::memcpy

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstring>

void* memcpy( void* dest, const void* src, std::size_t count );

Copie count octets de l'objet pointé par src vers l'objet pointé par dest. Les deux objets sont réinterprétés comme des tableaux de unsigned char.

Si les objets se chevauchent, le comportement est indéfini.

Si dest ou src est un pointeur invalide ou nul, le comportement est indéfini, même si count vaut zéro.

Si les objets sont potentiellement superposés ou ne sont pas TriviallyCopyable, le comportement de memcpy n'est pas spécifié et peut être indéfini.

Paramètres

  • dest — pointeur vers l'emplacement mémoire de destination
  • src — pointeur vers l'emplacement mémoire source
  • count — nombre d'octets à copier

Valeur de retour

dest

Notes

std::memcpy peut être utilisée pour créer implicitement des objets dans le tampon de destination.

std::memcpy est censée être la routine de la bibliothèque la plus rapide pour copier de la mémoire vers la mémoire. Elle est généralement plus efficace que std::strcpy, qui doit parcourir les données qu'elle copie, ou std::memmove, qui doit prendre des précautions pour gérer les entrées qui se chevauchent.

Plusieurs compilateurs C++ transforment les boucles de copie mémoire appropriées en appels à std::memcpy.

Lorsque le crénelage strict (strict aliasing) interdit d'examiner la même mémoire comme valeurs de deux types différents, std::memcpy peut être utilisée pour convertir les valeurs.

Exemple

#include <cstdint>
#include <cstring>
#include <iostream>

int main()
{
    // utilisation simple
    char source[] = "once upon a daydream...", dest[4];
    std::memcpy(dest, source, sizeof dest);
    std::cout << "dest[4] = {";
    for (int n{}; char c : dest)
        std::cout << (n++ ? ", " : "") << '\'' << c << "'";
    std::cout << "};\n";

    // reinterpreting
    double d = 0.1;
//  std::int64_t n = *reinterpret_cast<std::int64_t*>(&d); // violation du strict aliasing
    std::int64_t n;
    std::memcpy(&n, &d, sizeof d); // OK

    std::cout << std::hexfloat << d << " is " << std::hex << n
              << " as a std::int64_t\n" << std::dec;

    // création d'objet dans le tampon de destination
    struct S
    {
        int x{42};
        void print() const { std::cout << '{' << x << "}\n"; }
    } s;
    alignas(S) char buf[sizeof(S)];
    S* ps = new (buf) S; // placement new
    std::memcpy(ps, &s, sizeof s);
    ps->print();
}

dest[4] = {'o', 'n', 'c', 'e'};
0x1.999999999999ap-4 is 3fb999999999999a as a std::int64_t
{42}
