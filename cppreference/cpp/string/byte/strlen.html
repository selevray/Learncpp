std::strlen

Défini dans l'en-tête <cstring>

std::size_t strlen( const char* str );

Renvoie la longueur de la chaîne d'octets donnée, c'est-à-dire le nombre de caractères d'un tableau de caractères dont le premier élément est pointé par str, jusqu'au premier caractère nul non inclus. Le comportement est indéfini s'il n'existe aucun caractère nul dans le tableau de caractères pointé par str.

Paramètres

  • str — pointeur vers la chaîne d'octets terminée par un caractère nul à examiner

Valeur de retour

La longueur de la chaîne terminée par un caractère nul str.

Implémentation possible

std::size_t strlen(const char* start)
{
    // NB : start n'est pas vérifié par rapport à nullptr !
    const char* end = start;
    while (*end != '\0')
        ++end;
    return end - start;
}

Exemple

#include <cstring>
#include <iostream>

int main()
{
    const char str[] = "dog cat\0mouse";

    std::cout << "without null character: " << std::strlen(str) << '\n'
              << "with null character: " << sizeof str << '\n';
}

Output:

without null character: 7
with null character: 14
