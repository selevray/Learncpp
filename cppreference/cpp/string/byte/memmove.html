std::memmove

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstring>

void* memmove( void* dest, const void* src, std::size_t count );

Copie count caractères de l'objet pointé par src vers l'objet pointé par dest. Les deux objets sont réinterprétés comme des tableaux de unsigned char.

Les objets peuvent se chevaucher : la copie s'effectue comme si les caractères étaient copiés dans un tableau de caractères temporaire, puis copiés de ce tableau vers dest.

Si dest ou src est un pointeur invalide ou nul, le comportement est indéfini, même si count vaut zéro.

Si les objets sont potentiellement superposés ou ne sont pas TriviallyCopyable, le comportement de memmove n'est pas spécifié et peut être indéfini.

Paramètres

  • dest — pointeur vers l'emplacement mémoire de destination
  • src — pointeur vers l'emplacement mémoire source
  • count — nombre d'octets à copier

Valeur de retour

dest

Notes

std::memmove peut être utilisée pour créer implicitement des objets dans le tampon de destination.

Bien que spécifiée « comme si » un tampon temporaire était utilisé, les implémentations réelles de cette fonction n'engendrent ni le surcoût d'une double copie ni de la mémoire supplémentaire. Pour les petits count, elle peut charger et écrire des registres ; pour les blocs plus grands, une approche courante (glibc et bsd libc) consiste à copier les octets en avant depuis le début du tampon si la destination commence avant la source, et en arrière depuis la fin sinon, avec un repli sur std::memcpy lorsqu'il n'y a aucun chevauchement.

Lorsque le crénelage strict (strict aliasing) interdit d'examiner la même mémoire comme valeurs de deux types différents, std::memmove peut être utilisée pour convertir les valeurs.

Exemple

#include <cstring>
#include <iostream>

int main()
{
    char str[] = "1234567890";
    std::cout << str << '\n';
    std::memmove(str + 4, str + 3, 3); // copie de [4, 5, 6] vers [5, 6, 7]
    std::cout << str << '\n';
}

Output:

1234567890
1234456890
