std::strerror

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstring>

char* strerror( int errnum );

Renvoie un pointeur vers la description textuelle du code d'erreur système errnum, identique à la description qui serait affichée par std::perror().

errnum est généralement obtenu à partir de la variable errno, mais la fonction accepte toute valeur de type int. Le contenu de la chaîne dépend de la locale.

La chaîne renvoyée ne doit pas être modifiée par le programme, mais peut être écrasée par un appel ultérieur à la fonction strerror. strerror n'est pas tenue d'être thread-safe. Les implémentations peuvent renvoyer des pointeurs différents vers des littéraux de chaînes statiques en lecture seule, ou renvoyer le même pointeur à chaque fois, pointant vers un tampon statique dans lequel strerror place la chaîne.

Paramètres

  • errnum — valeur entière désignant un code d'erreur

Valeur de retour

Pointeur vers une chaîne d'octets terminée par un caractère nul correspondant au code d'erreur errno errnum.

Notes

POSIX autorise les appels ultérieurs à strerror à invalider le pointeur renvoyé par un appel précédent. Il précise également que c'est la facette LC_MESSAGES de la locale qui contrôle le contenu de ces messages.

POSIX définit une version thread-safe appelée strerror_r. Glibc définit une version incompatible.

Exemple

#include <cerrno>
#include <clocale>
#include <cmath>
#include <cstring>
#include <iostream>

int main()
{
    const double not_a_number = std::log(-1.0);
    std::cout << not_a_number << '\n';

    if (errno == EDOM)
    {
        std::cout << "log(-1) failed: " << std::strerror(errno) << '\n';
        std::setlocale(LC_MESSAGES, "de_DE.utf8");
        std::cout << "Or, in German, " << std::strerror(errno) << '\n';
    }
}
