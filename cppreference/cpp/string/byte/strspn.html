size_t strspn( const char* dest, const char* src );

Renvoie la longueur du segment initial maximal (étendue) de la chaîne d'octets pointée par dest, qui ne est constitué que de caractères figurant dans la chaîne d'octets pointée par src.

Paramètres

  • dest — pointeur vers la chaîne d'octets terminée par un caractère nul à analyser
  • src — pointeur vers la chaîne d'octets terminée par un caractère nul contenant les caractères à rechercher

Valeur de retour

La longueur du segment initial maximal ne contenant que des caractères de la chaîne d'octets pointée par src.

Exemple

#include <cstring>
#include <iostream>
#include <string>

const char* low_alpha = "qwertyuiopasdfghjklzxcvbnm";

int main()
{
    std::string s = "abcde312$#@";

    std::size_t spnsz = std::strspn(s.c_str(), low_alpha);
    std::cout << "After skipping initial lowercase letters from '" << s
              << "'\nThe remainder is '" << s.substr(spnsz) << "'\n";
}

Output:

After skipping initial lowercase letters from 'abcde312$#@'
The remainder is '312$#@'
