std::memset

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstring>

void* memset( void* dest, int ch, std::size_t count );

Copie la valeur static_cast<unsigned char>(ch) dans chacun des count premiers caractères de l'objet pointé par dest. Si l'objet est un sous-objet potentiellement se chevauchant ou n'est pas TriviallyCopyable (par exemple un scalaire, une structure compatible C ou un tableau de type trivialement copiable), le comportement est indéfini. Si count est supérieur à la taille de l'objet pointé par dest, le comportement est indéfini.

Paramètres

  • dest — pointeur vers l'objet à remplir
  • ch — octet de remplissage
  • count — nombre d'octets à remplir

Valeur de retour

dest

Notes

std::memset peut être supprimé par optimisation (selon les règles as-if) si l'objet modifié par cette fonction n'est plus accédé pendant le reste de sa durée de vie (par exemple, gcc bug 8537). Pour cette raison, cette fonction ne peut pas être utilisée pour effacer la mémoire (par exemple pour remplir de zéros un tableau contenant un mot de passe).

Les solutions possibles incluent std::fill avec des pointeurs volatile, (C23) memset_explicit(), (C11) memset_s, explicit_bzero de FreeBSD ou SecureZeroMemory de Microsoft.

Exemple

#include <bitset>
#include <climits>
#include <cstring>
#include <iostream>

int main()
{
    int a[4];
    using bits = std::bitset<sizeof(int) * CHAR_BIT>;
    std::memset(a, 0b1111'0000'0011, sizeof a);
    for (int ai : a)
        std::cout << bits(ai) << '\n';
}

Output:

00000011000000110000001100000011
00000011000000110000001100000011
00000011000000110000001100000011
00000011000000110000001100000011
