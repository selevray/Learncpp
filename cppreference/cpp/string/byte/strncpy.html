std::strncpy

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstring>

char* strncpy( char* dest, const char* src, std::size_t count );

Copie au plus count caractères de la chaîne d'octets pointée par src (y compris le caractère nul de fin) dans le tableau de caractères pointé par dest.

Si count est atteint avant que la chaîne entière src ait été copiée, le tableau de caractères résultant n'est pas terminé par un caractère nul.

Si, après la copie du caractère nul de fin de src, count n'est pas atteint, des caractères nuls supplémentaires sont écrits dans dest jusqu'à ce que le total de count caractères soit écrit.

Si les chaînes se chevauchent, le comportement est indéfini.

Paramètres

  • dest — pointeur vers le tableau de caractères de destination
  • src — pointeur vers la chaîne d'octets source
  • count — nombre maximal de caractères à copier

Valeur de retour

dest

Exemple

#include <cstring>
#include <iostream>

int main()
{
    const char* src = "hi";
    char dest[6] = {'a', 'b', 'c', 'd', 'e', 'f'};
    std::strncpy(dest, src, 5);

    std::cout << "The contents of dest are: ";
    for (char c : dest)
    {
        if (c)
            std::cout << c << ' ';
        else
            std::cout << "\\0" << ' ';
    }
    std::cout << '\n';
}

Output:

The contents of dest are: h i \0 \0 \0 f
