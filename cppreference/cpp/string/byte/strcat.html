std::strcat

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstring>

char* strcat( char* dest, const char* src );

Ajoute une copie de la chaîne de caractères pointée par src à la fin de la chaîne de caractères pointée par dest. Le caractère src[0] remplace le caractère nul de fin de dest. La chaîne d'octets résultante est terminée par un caractère nul.

Le comportement est indéfini si le tableau de destination n'est pas assez grand pour contenir le contenu de src et de dest ainsi que le caractère nul de fin.

Le comportement est indéfini si les chaînes se chevauchent.

Paramètres

  • dest — pointeur vers la chaîne d'octets terminée par un caractère nul à laquelle ajouter
  • src — pointeur vers la chaîne d'octets terminée par un caractère nul à copier

Valeur de retour

dest

Notes

Comme strcat doit se positionner à la fin de dest à chaque appel, il est inefficace de concaténer de nombreuses chaînes en une seule à l'aide de strcat.

Exemple

#include <cstdio>
#include <cstring>

int main()
{
    char str[50] = "Hello ";
    char str2[50] = "World!";
    std::strcat(str, str2);
    std::strcat(str, " Goodbye World!");
    std::puts(str);
}

Output:

Hello World! Goodbye World!
