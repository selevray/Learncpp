std::strcpy

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstring>

char* strcpy( char* dest, const char* src );

Copie la chaîne de caractères pointée par src, y compris le caractère nul de fin, dans le tableau de caractères dont le premier élément est pointé par dest.

Le comportement est indéfini si le tableau dest n'est pas assez grand. Le comportement est indéfini si les chaînes se chevauchent.

Paramètres

  • dest — pointeur vers le tableau de caractères dans lequel écrire
  • src — pointeur vers la chaîne d'octets terminée par un caractère nul à copier

Valeur de retour

dest

Exemple

#include <cstring>
#include <iostream>
#include <memory>

int main()
{
    const char* src = "Take the test.";
//  src[0] = 'M'; // impossible de modifier un littéral de chaîne
    auto dst = std::make_unique<char[]>(std::strlen(src) + 1); // +1 pour le caractère nul de fin
    std::strcpy(dst.get(), src);
    dst[0] = 'M';
    std::cout << src << '\n' << dst.get() << '\n';
}

Output:

Take the test.
Make the test.
