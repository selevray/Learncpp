std::basic_string<CharT,Traits,Allocator>::operator basic_string_view

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

operator std::basic_string_view<CharT, Traits>() const noexcept;  // (depuis C++17) (constexpr depuis C++20)

Renvoie un std::basic_string_view, construit comme par std::basic_string_view<CharT, Traits>(data(), size()).

Paramètres

(aucune)

Valeur de retour

Une vue de chaîne représentant l'intégralité du contenu de la chaîne.

Notes

C'est au programmeur de s'assurer que la vue de chaîne résultante ne survit pas à la chaîne.

std::string get_string();
int f(std::string_view sv);

int x = f(get_string()); // OK
std::string_view sv = get_string(); // Mauvais : contient un pointeur pendant

Exemple

#include <iostream>
#include <string>
#include <string_view>

void show_wstring_size(std::wstring_view wcstr_v)
{
    std::cout << wcstr_v.size() << " code points\n";
}

int main()
{
    std::string cppstr = "ラーメン";   // chaîne étroite
    std::wstring wcstr = L"ラーメン";  // chaîne large

    // Conversion implicite de string vers string_view
    // via std::string::operator string_view :
    std::string_view cppstr_v = cppstr;

    std::cout << cppstr_v << '\n'
              << cppstr_v.size() << " code units\n";

    // Conversion implicite de wstring vers wstring_view
    // via std::wstring::operator wstring_view :
    show_wstring_size(wcstr);
}

Output:

ラーメン
12 code units
4 code points
