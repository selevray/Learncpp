std::basic_string<CharT,Traits,Allocator>::erase

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

basic_string& erase( size_type index = 0, size_type count = npos );  // (1) (constexpr depuis C++20)

iterator erase( iterator position );  // (jusqu'à C++11)

iterator erase( const_iterator position );  // (depuis C++11) (constexpr depuis C++20)

iterator erase( iterator first, iterator last );  // (jusqu'à C++11)

iterator erase( const_iterator first, const_iterator last );  // (depuis C++11) (constexpr depuis C++20)

Supprime les caractères spécifiés de la chaîne.

  1. Supprime std::min(count, size() - index) caractères à partir de index.

  2. Supprime le caractère situé à position.

Si position n'est pas un itérateur déréférençable sur *this, le comportement est indéfini.

  1. Supprime les caractères de l'intervalle [first,last).

Si first ou last n'est pas un itérateur valide sur *this, ou si [first,last) n'est pas un intervalle valide, le comportement est indéfini.

Paramètres

  • index — premier caractère à supprimer
  • count — nombre de caractères à supprimer
  • position — itérateur vers le caractère à supprimer
  • first, last — intervalle des caractères à supprimer

Valeur de retour

  1. *this

  2. Itérateur pointant vers le caractère immédiatement après le caractère effacé, ou end() si un tel caractère n'existe pas.

  3. Itérateur pointant vers le caractère last pointé avant l'effacement, ou end() si un tel caractère n'existe pas.

Exceptions

  1. std::out_of_range if index > size().

2,3) Ne lève aucune exception.

Si une exception est levée pour quelque raison que ce soit, cette fonction n'a aucun effet (garantie forte de sécurité d'exception).

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>
#include <string>

int main()
{
    std::string s = "This Is An Example";
    std::cout << "1) " << s << '\n';

    s.erase(7, 3); // efface " An" à l'aide de la surcharge (1)
    std::cout << "2) " << s << '\n';

    s.erase(std::find(s.begin(), s.end(), ' ')); // efface le premier ' ' ; surcharge (2)
    std::cout << "3) " << s << '\n';

    s.erase(s.find(' ')); // supprime les espaces de ' ' jusqu'à la fin de la chaîne ; surcharge (1)
    std::cout << "4) " << s << '\n';

    auto it = std::next(s.begin(), s.find('s')); // obtient un itérateur vers le premier 's'
    s.erase(it, std::next(it, 2)); // efface "sI" ; surcharge (3)
    std::cout << "5) " << s << '\n';
}

Output:

1) This Is An Example
2) This Is Example
3) ThisIs Example
4) ThisIs
5) This

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 27 C++98 la surcharge (3) n'a pas effacé le caractère last pointé, mais elle a renvoyé l'itérateur pointant vers le caractère immédiatement suivant ce caractère renvoie un itérateur pointant vers ce caractère
LWG 428 C++98 la surcharge (2) exigeait explicitement que position soit valide, mais SequenceContainer exige qu'il soit déréférençable (plus strict) suppression de l'exigence explicite
LWG 847 C++98 il n'y avait aucune garantie de sécurité d'exception ajout de la garantie forte d'exception
