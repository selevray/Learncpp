std::basic_string<CharT,Traits,Allocator>::resize

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void resize( size_type count );  // (1) (constexpr depuis C++20)

void resize( size_type count, CharT ch );  // (2) (constexpr depuis C++20)

Redimensionne la chaîne pour contenir count caractères.

Si la taille actuelle est inférieure à count, des caractères supplémentaires sont ajoutés :

  1. Initialise les caractères ajoutés à CharT() ('\0' si CharT est char).

  2. Initialise les caractères ajoutés à ch.

Si la taille actuelle est supérieure à count, la chaîne est réduite à ses count premiers éléments.

Paramètres

  • count — nouvelle taille de la chaîne
  • ch — caractère servant à initialiser les nouveaux caractères

Exceptions

std::length_error si count > max_size() est true. Toute exception levée par Allocator correspondant.

Si une exception est levée pour quelque raison que ce soit, cette fonction n'a aucun effet (garantie forte de sécurité d'exception).

Exemple

#include <iomanip>
#include <iostream>
#include <stdexcept>

int main()
{
    const unsigned desired_length{8};
    std::string long_string("Where is the end?");
    std::string short_string("H");

    std::cout << "Basic functionality:\n"
              << "Shorten:\n"
              << "1. Before: " << std::quoted(long_string) << '\n';
    long_string.resize(desired_length);
    std::cout << "2. After:  " << std::quoted(long_string) << '\n';

    std::cout << "Lengthen with a given value 'a':\n"
              << "3. Before: " << std::quoted(short_string) << '\n';
    short_string.resize(desired_length, 'a');
    std::cout << "4. After:  " << std::quoted(short_string) << '\n';

    std::cout << "Lengthen with char() == " << static_cast<int>(char()) << '\n'
              << "5. Before: " << std::quoted(short_string) << '\n';
    short_string.resize(desired_length + 3);
    std::cout << "6. After:  \"";
    for (char c : short_string)
        std::cout << (c == char() ? '@' : c);
    std::cout << "\"\n\n";

    std::cout << "Errors:\n";
    std::string s;

    try
    {
        // la taille est correcte, pas de length_error
        // (peut lever bad_alloc)
        s.resize(s.max_size() - 1, 'x');
    }
    catch (const std::bad_alloc& ex)
    {
        std::cout << "1. Exception: " << ex.what() << '\n';
    }

    try
    {
        // la taille est correcte, pas de length_error
        // (peut lever bad_alloc)
        s.resize(s.max_size(), 'x');
    }
    catch (const std::bad_alloc& ex)
    {
        std::cout << "2. Exception: " << ex.what() << '\n';
    }

    try
    {
        // la taille est INCORRECTE, lève length_error
        s.resize(s.max_size() + 1, 'x');
    }
    catch (const std::length_error& ex)
    {
        std::cout << "3. Length error: " << ex.what() << '\n';
    }
}

Sortie possible :

Basic functionality:
Shorten:
1. Before: "Where is the end?"
2. After:  "Where is"
Lengthen with a given value 'a':
3. Before: "H"
4. After:  "Haaaaaaa"
Lengthen with char() == 0
5. Before: "Haaaaaaa"
6. After:  "Haaaaaaa@@@"

Errors:
1. Exception: std::bad_alloc
2. Exception: std::bad_alloc
3. Length error: basic_string::_M_replace_aux

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 847 C++98 il n'y avait aucune garantie de sécurité d'exception ajout de la garantie forte de sécurité d'exception
LWG 2250 C++98 le comportement était indéfini si count > max_size() est true lève toujours une exception dans ce cas
