template< class CharT, class Traits, class Allocator >
std::basic_ostream<CharT, Traits>&
    operator<<( std::basic_ostream<CharT, Traits>& os,
                const std::basic_string<CharT, Traits, Allocator>& str );  // (1)

template< class CharT, class Traits, class Allocator >
std::basic_istream<CharT, Traits>&
    operator>>( std::basic_istream<CharT, Traits>& is,
                std::basic_string<CharT, Traits, Allocator>& str );  // (2)
  1. Se comporte comme un FormattedOutputFunction. Après construction et vérification de l'objet sentry, détermine le remplissage de format de sortie.

Insère ensuite chaque caractère de la séquence résultante seq (le contenu de str plus le remplissage) dans le flux de sortie os comme par l'appel de os.rdbuf()->sputn(seq, n), où n est std::max(os.width(), str.size()). Enfin, appelle os.width(0) pour annuler les effets de std::setw, le cas échéant.

Équivalent à return os << std::basic_string_view<CharT, Traits>(str);.

(depuis C++17)

  1. Se comporte comme un FormattedInputFunction. Après construction et vérification de l'objet sentry, qui peut ignorer les espaces initiaux, efface d'abord str avec str.erase(), puis lit des caractères depuis is et les ajoute à str comme par str.append(1, c), jusqu'à ce que l'une des conditions suivantes soit vraie :
  • N caractères sont lus, où N est is.width() si is.width() > 0, sinon N est str.max_size(),
  • la condition de fin de fichier survient dans le flux is, ou
  • std::isspace(c, is.getloc()) est true pour le caractère suivant c dans is (ce caractère d'espacement reste dans le flux d'entrée).

Si aucun caractère n'est extrait, std::ios::failbit est positionné sur is, ce qui peut lever std::ios_base::failure.

Enfin, appelle is.width(0) pour annuler les effets de std::setw, le cas échéant.

Exceptions

  1. Peut lever std::ios_base::failure si une exception est levée pendant la sortie.

  2. Peut lever std::ios_base::failure si aucun caractère n'est extrait de is (par exemple si le flux est en fin de fichier, ou ne contient que des espaces), ou si une exception est levée pendant l'entrée.

Paramètres

  • os — un flux de sortie de caractères
  • is — un flux d'entrée de caractères
  • str — la chaîne à insérer ou extraire

Valeur de retour

  1. os

  2. is

Exemple

#include <iostream>
#include <sstream>
#include <string>

int main()
{
    std::string greeting = "Hello, whirled!";
    std::istringstream iss(greeting);

    std::string hello_comma, whirled, word;

    iss >> hello_comma;
    iss >> whirled;

    std::cout << greeting << '\n'
              << hello_comma << '\n' << whirled << '\n';

    // Réinitialise le flux
    iss.clear();
    iss.seekg(0);

    while (iss >> word)
        std::cout << '+' << word << '\n';
}

Output:

Hello, whirled!
Hello,
whirled!
+Hello,
+whirled!

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 25 C++98 n était le plus petit de os.width() et str.size() n est le plus grand des deux
LWG 90 C++98 std::isspace(c, getloc()) était utilisé pour vérifier la présence d'espaces, mais getloc n'est pas déclaré dans <string> remplacé getloc() par is.getloc()
LWG 91 C++98 operator>> ne se comportait pas comme un FormattedInputFunction se comporte comme un FormattedInputFunction
LWG 211 C++98 operator>> ne positionnait pas failbit si aucun caractère n'est extrait définit failbit
LWG 435 C++98 des caractères étaient insérés par os.rdbuf()->sputn(str.data(), n), et la résolution de LWG issue 25 a rendu le comportement indéfini si os.width() est plus grand que str.size() détermine d'abord le remplissage puis insère à la place la séquence de caractères remplie
LWG 586 C++98 operator<< ne se comportait pas comme un FormattedOutputFunction se comporte comme un FormattedOutputFunction
