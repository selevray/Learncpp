std::basic_string<CharT,Traits,Allocator>::npos

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static const size_type npos = -1;

Il s'agit d'une valeur spéciale égale à la valeur maximale représentable par le type size_type. Le sens exact dépend du contexte, mais elle est généralement utilisée soit comme indicateur de fin de chaîne par les fonctions qui attendent un indice de chaîne, soit comme indicateur d'erreur par les fonctions qui renvoient un indice de chaîne.

Note

Bien que la définition utilise -1, size_type est un type entier non signé, et la valeur de npos est la plus grande valeur positive qu'il peut contenir, en raison de la conversion implicite de signé en non signé. C'est une manière portable de spécifier la plus grande valeur de tout type non signé.

Exemple

#include <bitset>
#include <iostream>
#include <string>

int main()
{
    // les fonctions de recherche de chaînes renvoient npos si rien n'est trouvé
    std::string s = "test";
    if (s.find('a') == s.npos)
        std::cout << "no 'a' in 'test'\n";

    // fonctions qui prennent des sous-chaînes en argument
    // utilisent npos comme indicateur « jusqu'à la fin »
    std::string s2(s, 2, std::string::npos);
    std::cout << s2 << '\n';

    std::bitset<5> b("aaabb", std::string::npos, 'a', 'b');
    std::cout << b << '\n';
}

Output:

no 'a' in 'test'
st
00011
