std::basic_string<CharT,Traits,Allocator>::empty

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool empty() const;  // (noexcept depuis C++11) (constexpr depuis C++20)

Vérifie si la chaîne ne contient aucun caractère, c'est-à-dire si begin() == end().

Paramètres

(aucune)

Valeur de retour

true si la chaîne est vide, false sinon

Complexité

Constante.

Exemple

#include <iostream>
#include <string>

int main()
{
    std::string s;
    std::boolalpha(std::cout);
    std::cout << "s.empty():" << s.empty() << "\t s:'" << s << "'\n";

    s = "Exemplar";
    std::cout << "s.empty():" << s.empty() << "\t s:'" << s << "'\n";

    s = "";
    std::cout << "s.empty():" << s.empty() << "\t s:'" << s << "'\n";
}

Output:

s.empty():true   s:''
s.empty():false  s:'Exemplar'
s.empty():true   s:''
