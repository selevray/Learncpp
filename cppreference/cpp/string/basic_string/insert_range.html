std::basic_string<CharT,Traits,Allocator>::insert_range

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< container-compatible-range<CharT> R >
constexpr iterator insert_range( const_iterator pos, R&& rg );  // (depuis C++23)

Insère les caractères de l'intervalle rg avant l'élément (s'il existe) pointé par pos.

Équivalent à

return insert(pos - begin(),
    std::basic_string(
        std::from_range,
        std​::​forward<R>(rg),
        get_allocator())
);

Si pos n'est pas un itérateur valide sur *this, le comportement est indéfini.

Paramètres

  • pos — itérateur avant lequel les caractères seront insérés
  • rg — un intervalle compatible avec un conteneur

Valeur de retour

Un itérateur qui pointe vers le premier caractère inséré, ou pos si aucun caractère n'a été inséré car rg était vide.

Complexité

Linéaire en fonction de la taille de rg.

Exceptions

Si std::allocator_traits<Allocator>::allocate lève une exception, elle est relancée.

Si l'opération devait faire dépasser size() à max_size(), lève std::length_error.

Si une exception est levée pour quelque raison que ce soit, cette fonction n'a aucun effet (garantie forte de sécurité d'exception).

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_containers_ranges 202202L (C++23) fonctions membres acceptant un intervalle compatible avec un conteneur

Exemple

#include <cassert>
#include <iterator>
#include <string>

int main()
{
    const auto source = {'l', 'i', 'b', '_'};
    std::string target{"__cpp_containers_ranges"};
    //                        ^l'insertion aura lieu
    //                         avant cette position

    const auto pos = target.find("container");
    assert(pos != target.npos);
    auto iter = std::next(target.begin(), pos);

#ifdef __cpp_lib_containers_ranges
    target.insert_range(iter, source);
#else
    target.insert(iter, source.begin(), source.end());
#endif

    assert(target == "__cpp_lib_containers_ranges");
    //                      ^^^^
}
