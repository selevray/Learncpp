           std::basic_string<CharT, Traits, Alloc>& rhs ) noexcept(/* voir ci-dessous */);  // (depuis C++17) (constexpr depuis C++20)

Spécialise l'algorithme std::swap pour std::basic_string. Échange le contenu de lhs et rhs.

Équivalent à lhs.swap(rhs).

Paramètres

  • lhs, rhs — chaînes dont le contenu doit être échangé

Valeur de retour

(aucune)

Complexité

Constante.

Exceptions

noexcept specification:noexcept(noexcept(lhs.swap(rhs)))

(depuis C++17)

Exemple

#include <iostream>
#include <string>

int main()
{
    std::string a = "AAA";
    std::string b = "BBBB";

    std::cout << "Before swap:\n"
                 "a = " << a << "\n"
                 "b = " << b << "\n\n";

    std::swap(a, b);

    std::cout << "After swap:\n"
                 "a = " << a << "\n"
                 "b = " << b << '\n';
}

Output:

Before swap:
a = AAA
b = BBBB

After swap:
a = BBBB
b = AAA
