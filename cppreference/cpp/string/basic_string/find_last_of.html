std::basic_string<CharT,Traits,Allocator>::find_last_of

template< class StringViewLike >
size_type
    find_last_of( const StringViewLike& t,
                  size_type pos = npos ) const noexcept(/* voir ci-dessous */);  // (5) (depuis C++17) (constexpr depuis C++20)

Recherche le dernier caractère égal à l'un des caractères de la séquence de caractères donnée. L'algorithme de recherche exact n'est pas spécifié. La recherche ne considère que l'intervalle [0,pos]. Si aucun des caractères de la séquence de caractères donnée n'est présent dans l'intervalle, npos est renvoyé.

  1. Recherche le dernier caractère égal à l'un des caractères de str.

  2. Recherche le dernier caractère égal à l'un des caractères de l'intervalle [s,s + count). Cet intervalle peut contenir des caractères nuls.

Si [s,s + count) n'est pas un intervalle valide, le comportement est indéfini.

  1. Recherche le dernier caractère égal à l'un des caractères de la chaîne de caractères pointée par s. La longueur de la chaîne est déterminée par le premier caractère nul à l'aide de Traits::length(s).

Si [s,s + Traits::length(s)) n'est pas un intervalle valide, le comportement est indéfini.

  1. Recherche le dernier caractère égal à ch.

  2. Convertit implicitement t en vue de chaîne sv comme si par std::basic_string_view<CharT, Traits> sv = t;, puis recherche le dernier caractère égal à l'un des caractères de sv.

Cette surcharge ne participe à la résolution de surcharge que si std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>> est true et std::is_convertible_v<const StringViewLike&, const CharT*> est false.

Dans tous les cas, l'égalité est vérifiée en appelant Traits::eq.

Paramètres

  • str — chaîne identifiant les caractères à rechercher
  • pos — position à laquelle la recherche doit se terminer
  • count — longueur de la chaîne de caractères identifiant les caractères à rechercher
  • s — pointeur vers une chaîne de caractères identifiant les caractères à rechercher
  • ch — caractère à rechercher
  • t — objet (convertible en std::basic_string_view) identifiant les caractères à rechercher

Valeur de retour

Position du caractère trouvé, ou npos si aucun tel caractère n'est trouvé.

Exceptions

1,4) Ne lève aucune exception.

5)noexcept specification:noexcept(std::is_nothrow_convertible_v<const T&, std::basic_string_view<CharT, Traits>>)

Si une exception est levée pour quelque raison que ce soit, cette fonction n'a aucun effet (garantie forte de sécurité d'exception).

Exemple

#include <iostream>
#include <string>

int main()
{
    const std::string path = "/root/config";
    auto const pos = path.find_last_of('/');
    const auto leaf = path.substr(pos + 1);

    std::cout << leaf << '\n';
}

Output:

config

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 141 C++98 la surcharge (1) ne pouvait renvoyer npos que si pos >= size() l'intervalle de recherche est [0,size()) dans ce cas
LWG 847 C++98 il n'y avait aucune garantie de sécurité d'exception ajout de la garantie forte de sécurité d'exception
LWG 2064 C++11 les surcharges (3,4) étaient noexcept removed
