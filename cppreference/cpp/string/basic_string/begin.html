Renvoie un itérateur vers le premier caractère de la chaîne.

begin() renvoie un itérateur modifiable ou constant, selon la constance de *this.

cbegin() renvoie toujours un itérateur constant. Il est équivalent à const_cast<const basic_string&>(*this).begin().

Paramètres

(aucune)

Valeur de retour

Itérateur vers le premier caractère.

Complexité

Constante.

Notes

libc++ rétroporte cbegin() au mode C++98.

Exemple

#include <iostream>
#include <string>

int main()
{
    std::string s("Exemplar");
    *s.begin() = 'e';
    std::cout << s << '\n';

    auto i = s.cbegin();
    std::cout << *i << '\n';
//  *i = 'E'; // erreur : i est un itérateur constant
}

Output:

exemplar
e
