std::basic_string<CharT,Traits,Allocator>::assign_range

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< container-compatible-range<CharT> R >
constexpr std::basic_string& assign_range( R&& rg );  // (depuis C++23)

Remplace le contenu de la chaîne par les valeurs de l'intervalle rg.

Équivalent à

return assign(
    std::basic_string(
        std::from_range,
        std​::​forward<R>(rg),
        get_allocator())
);

Paramètres

  • rg — un intervalle compatible avec un conteneur

Valeur de retour

*this

Complexité

Linéaire en fonction de la taille de rg.

Exceptions

Si l'opération devait faire dépasser size() à max_size(), lève std::length_error.

Si une exception est levée pour quelque raison que ce soit, cette fonction n'a aucun effet (garantie forte de sécurité d'exception).

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_containers_ranges 202202L (C++23) fonctions membres acceptant un intervalle compatible avec un conteneur

Exemple

#include <cassert>
#include <string>

int main()
{
    const auto source = {'s', 'o', 'u', 'r', 'c', 'e'};
    std::string destination{"destination"};

#ifdef __cpp_lib_containers_ranges
    destination.assign_range(source);
#else
    destination.assign(source.begin(), source.end());
#endif

    assert(destination == "source");
}
