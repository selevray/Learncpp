std::basic_string<CharT,Traits,Allocator>::swap

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void swap( basic_string& other );  // (jusqu'à C++17)

void swap( basic_string& other ) noexcept(/* voir ci-dessous */);  // (depuis C++17) (constexpr depuis C++20)

Échange le contenu de la chaîne avec celui de other. Tous les itérateurs et références peuvent être invalidés.

Si std::allocator_traits<Allocator>:: propagate_on_container_swap::value &&get_allocator() == s.get_allocator() est false, le comportement est indéfini.

(depuis C++11)

Paramètres

  • other — chaîne avec laquelle échanger le contenu

Complexité

Constante.

Exceptions

Aucune exception n'est levée.

(jusqu'à C++11)

Aucune exception n'est levée, sauf si le comportement est indéfini.

Si une exception est levée pour quelque raison que ce soit, cette fonction n'a aucun effet (garantie forte de sécurité d'exception).

(depuis C++11)

noexcept specification:noexcept(std::allocator_traits<Allocator>::propagate_on_container_swap::value || std::allocator_traits<Allocator>::is_always_equal::value)

(depuis C++17)

Exemple

#include <iostream>
#include <string>

int main()
{
    std::string a = "AAA";
    std::string b = "BBBB";

    std::cout << "Before swap:\n"
                 "a = " << a << "\n"
                 "b = " << b << "\n\n";

    a.swap(b);

    std::cout << "After swap:\n"
                 "a = " << a << "\n"
                 "b = " << b << '\n';
}

Output:

Before swap:
a = AAA
b = BBBB

After swap:
a = BBBB
b = AAA

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 403 C++98 swap() peut lever une exception aucune exception n'est levée
LWG 535 C++98 l'échange de chaînes ne préservait pas l'ordre des caractères l'ordre est également préservé
LWG 2151 (P1148R0) C++11 aucune exception n'a été levée dans le cas d'allocateurs non propagatifs inégaux le comportement est indéfini dans ce cas
