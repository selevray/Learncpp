std::basic_string<CharT,Traits,Allocator>::data

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

const CharT* data() const;  // (1) (noexcept depuis C++11) (constexpr depuis C++20)

CharT* data() noexcept;  // (2) (depuis C++17) (constexpr depuis C++20)

Renvoie un pointeur vers le tableau sous-jacent servant de stockage des caractères. Le pointeur est tel que l'intervalle

[data(),data() + size())

(jusqu'à C++11)

[data(),data() + size()]

(depuis C++11)

est valide et les valeurs qu'il contient correspondent aux valeurs stockées dans la chaîne.

Le tableau renvoyé n'est pas tenu d'être terminé par un caractère nul.

Si empty() renvoie true, le pointeur est un pointeur non nul qui ne doit pas être déréférencé.

(jusqu'à C++11)

Le tableau renvoyé est terminé par un caractère nul, c'est-à-dire que data() et c_str() remplissent la même fonction.

Si empty() renvoie true, le pointeur pointe vers un seul caractère nul.

(depuis C++11)

Le pointeur obtenu à partir de data() peut être invalidé par :

  • Le passage d'une référence non constante vers la chaîne à une fonction quelconque de la bibliothèque standard, ou
  • Appeler des fonctions membres non const sur la chaîne, à l'exclusion de operator[](), at(), front(), back(), begin(), end(), rbegin(), rend().

  1. Modifier le tableau de caractères accédé via la surcharge const de data a un comportement indéfini.

  2. Modifier le terminateur nul situé après la fin stocké à data() + size() avec une valeur autre que CharT() a un comportement indéfini.

Paramètres

(aucune)

Valeur de retour

Un pointeur vers le stockage de caractères sous-jacent.

data()[i] == operator[](i) pour chaque i dans [0,size()).

(jusqu'à C++11)

data() + i == std::addressof(operator[](i)) pour chaque i dans [0,size()].

(depuis C++11)

Complexité

Constante.

Exemple

#include <algorithm>
#include <cassert>
#include <cstring>
#include <string>

int main()
{
    std::string const s("Emplary");
    assert(s.size() == std::strlen(s.data()));
    assert(std::equal(s.begin(), s.end(), s.data()));
    assert(std::equal(s.data(), s.data() + s.size(), s.begin()));
    assert('\0' == *(s.data() + s.size()));
}
