Remplace les caractères de l'intervalle [begin() + pos,begin() + std::min(pos + count, size())) ou [first,last) par les caractères donnés.

1,2) Ces caractères sont remplacés par str.

  1. Ces caractères sont remplacés par une sous-chaîne [pos2,std::min(pos2 + count2, str.size())) de str.

4,5) Ces caractères sont remplacés par les caractères de l'intervalle [cstr,cstr + count2).

Si [cstr,cstr + count2) n'est pas un intervalle valide, le comportement est indéfini.

6,7) Ces caractères sont remplacés par les caractères de l'intervalle [cstr,cstr + Traits::length(cstr)).

8,9) Ces caractères sont remplacés par count2 copies de ch.

  1. Ces caractères sont remplacés par les caractères de l'intervalle [first2,last2), comme par replace(first, last, basic_string(first2, last2, get_allocator())).

  2. Ces caractères sont remplacés par les caractères de ilist.

12,13) Convertit implicitement t en vue de chaîne sv comme par std::basic_string_view<CharT, Traits> sv = t;, puis ces caractères sont remplacés par les caractères de sv.

Ces surcharges ne participent à la résolution de surcharge que si std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>> est true et std::is_convertible_v<const StringViewLike&, const CharT*> est false.

  1. Convertit implicitement t en vue de chaîne sv comme par std::basic_string_view<CharT, Traits> sv = t;, puis ces caractères sont remplacés par les caractères de la sous-vue sv.substr(pos2, count2).

Cette surcharge ne participe à la résolution de surcharge que si std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>> est true et std::is_convertible_v<const StringViewLike&, const CharT*> est false.

Si [begin(),first) ou [first,last) n'est pas un intervalle valide, le comportement est indéfini.

Paramètres

  • pos — début de la sous-chaîne qui va être remplacée
  • count — longueur de la sous-chaîne qui va être remplacée
  • first, last — intervalle de caractères qui va être remplacé
  • str — chaîne à utiliser pour le remplacement
  • pos2 — début de la sous-chaîne servant au remplacement
  • count2 — nombre de caractères servant au remplacement
  • cstr — pointeur vers la chaîne de caractères à utiliser pour le remplacement
  • ch — valeur du caractère à utiliser pour le remplacement
  • first2, last2 — intervalle de caractères à utiliser pour le remplacement
  • ilist — liste d'initialisation contenant les caractères à utiliser pour le remplacement
  • t — objet (convertible en std::basic_string_view) contenant les caractères à utiliser pour le remplacement

Exigences sur les types

  • InputIt doit satisfaire aux exigences de LegacyInputIterator.

Valeur de retour

*this.

Exceptions

  1. Lève std::out_of_range si pos > size().

  2. Lève std::out_of_range si pos > size() ou pos2 > str.size().

4,6,8) Lève std::out_of_range si pos > size().

12,14) Lève std::out_of_range si pos > size().

Si l'opération devait faire dépasser size() à max_size(), lève std::length_error.

Si une exception est levée pour quelque raison que ce soit, ces fonctions n'ont aucun effet (garantie forte de sécurité d'exception).
