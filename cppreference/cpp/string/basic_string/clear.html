std::basic_string<CharT,Traits,Allocator>::clear

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void clear();  // (noexcept depuis C++11) (constexpr depuis C++20)

Supprime tous les caractères de la chaîne comme si l'on exécutait erase(begin(), end()).

Tous les pointeurs, références et itérateurs sont invalidés.

Paramètres

(aucune)

Valeur de retour

(aucune)

Notes

Contrairement à std::vector::clear, la norme C++ n'exige pas explicitement que capacity soit inchangée par cette fonction, mais les implémentations existantes ne modifient pas la capacité. Cela signifie qu'elles ne libèrent pas la mémoire allouée (voir aussi shrink_to_fit).

Complexité

Linéaire par rapport à la taille de la chaîne, bien que les implémentations existantes opèrent en temps constant.

Exemple

#include <cassert>
#include <iostream>
#include <string>

int main()
{
    std::string s{"Exemplar"};
    std::string::size_type const capacity = s.capacity();

    s.clear();
    assert(s.empty());
    assert(s.size() == 0);
    std::cout << std::boolalpha << (s.capacity() == capacity) << '\n';
}
