std::basic_string<CharT,Traits,Allocator>::find_last_not_of

template< class StringViewLike >
size_type
    find_last_not_of( const StringViewLike& t,
                      size_type pos = npos ) const noexcept(/* voir ci-dessous */);  // (5) (depuis C++17) (constexpr depuis C++20)

Recherche le dernier caractère différent de tous les caractères de la séquence de caractères donnée. La recherche ne considère que l'intervalle [0,pos]. Si tous les caractères de l'intervalle se trouvent dans la séquence de caractères donnée, npos est renvoyé.

  1. Recherche le dernier caractère qui n'est égal à aucun des caractères de str.

  2. Recherche le dernier caractère qui n'est égal à aucun des caractères de l'intervalle [s,s + count). Cet intervalle peut contenir des caractères nuls.

Si [s,s + count) n'est pas un intervalle valide, le comportement est indéfini.

  1. Recherche le dernier caractère qui n'est égal à aucun des caractères de la chaîne de caractères pointée par s. La longueur de la chaîne est déterminée par le premier caractère nul à l'aide de Traits::length(s).

Si [s,s + Traits::length(s)) n'est pas un intervalle valide, le comportement est indéfini.

  1. Recherche le dernier caractère différent de ch.

  2. Convertit implicitement t en vue de chaîne sv comme si par std::basic_string_view<CharT, Traits> sv = t;, puis recherche le dernier caractère qui n'est égal à aucun des caractères de sv.

Cette surcharge ne participe à la résolution de surcharge que si std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>> est true et std::is_convertible_v<const StringViewLike&, const CharT*> est false.

Dans tous les cas, l'égalité est vérifiée en appelant Traits::eq.

Paramètres

  • str — chaîne identifiant les caractères à rechercher
  • pos — position à laquelle terminer la recherche
  • count — longueur de la chaîne de caractères identifiant les caractères à rechercher
  • s — pointeur vers une chaîne de caractères identifiant les caractères à rechercher
  • ch — caractère identifiant les caractères à rechercher
  • t — objet (convertible en std::basic_string_view) identifiant les caractères à rechercher

Valeur de retour

Position du caractère trouvé, ou npos si aucun tel caractère n'est trouvé.

Exceptions

1,4) Ne lève aucune exception.

5)noexcept specification:noexcept(std::is_nothrow_convertible_v< const T&, std::basic_string_view<CharT, Traits>>)

Si une exception est levée pour quelque raison que ce soit, cette fonction n'a aucun effet (garantie forte de sécurité d'exception).

Exemple

#include <iostream>
#include <string>

void show_pos(const std::string& str, std::string::size_type found)
{
    if (found != std::string::npos)
        std::cout << '[' << found << "] = \'" << str[found] << "\'\n";
    else
        std::cout << "not found\n";
}

int main()
{
    std::string str{"abc_123"};
    char const* skip_set{"0123456789"};
    std::string::size_type str_last_pos{std::string::npos};

    show_pos(str, str.find_last_not_of(skip_set)); // [3] = '_'

    str_last_pos = 2;
    show_pos(str, str.find_last_not_of(skip_set, str_last_pos)); // [2] = 'c'

    str_last_pos = 2;
    show_pos(str, str.find_last_not_of('c', str_last_pos)); // [1] = 'b'

    const char arr[]{'3', '4', '5'};
    show_pos(str, str.find_last_not_of(arr)); // [5] = '2'

    str_last_pos = 2;
    std::string::size_type skip_set_size{4};
    show_pos(str, str.find_last_not_of(skip_set,
                                       str_last_pos,
                                       skip_set_size)); // [2] = 'c'

    show_pos(str, str.find_last_not_of("abc")); // [6] = '3'

    str_last_pos = 2;
    show_pos(str, str.find_last_not_of("abc", str_last_pos)); // non trouvé
}

Output:

[3] = '_'
[2] = 'c'
[1] = 'b'
[5] = '2'
[2] = 'c'
[6] = '3'
not found

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 141 C++98 la surcharge (1) ne pouvait renvoyer npos que si pos >= size() l'intervalle de recherche est [0,size()) dans ce cas
LWG 847 C++98 il n'y avait aucune garantie de sécurité d'exception ajout de la garantie forte de sécurité d'exception
LWG 2064 C++11 les surcharges (3,4) étaient noexcept removed
LWG 2946 C++17 la surcharge (5) causait une ambiguïté dans certains cas évité en en faisant un modèle
P1148R0 C++11 C++17 noexcept pour les surcharges (4,5) a été supprimé par erreur par LWG2064/LWG2946 restored
