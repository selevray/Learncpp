reverse_iterator rbegin();  // (1) (noexcept depuis C++11) (constexpr depuis C++20)

const_reverse_iterator rbegin() const;  // (2) (noexcept depuis C++11) (constexpr depuis C++20)

const_reverse_iterator crbegin() const noexcept;  // (3) (depuis C++11) (constexpr depuis C++20)

Renvoie un itérateur inverse vers le premier caractère de la chaîne inversée. Il correspond au dernier caractère de la chaîne non inversée.

range-rbegin-rend.svg

Paramètres

(aucune)

Valeur de retour

Itérateur inverse vers le premier caractère.

Complexité

Constante.

Notes

libc++ rétroporte crbegin() au mode C++98.

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>
#include <string>

int main()
{
    std::string s("Exemplar!");
    *s.rbegin() = 'y';
    std::cout << s << '\n'; // "Exemplary"

    std::string c;
    std::copy(s.crbegin(), s.crend(), std::back_inserter(c));
    std::cout << c << '\n'; // "yralpmexE"
}
