Renvoie un itérateur vers le caractère suivant le dernier caractère de la chaîne. Ce caractère sert d'espace réservé ; tenter d'y accéder entraîne un comportement indéfini.

range-begin-end.svg

Paramètres

(aucune)

Valeur de retour

Itérateur vers le caractère suivant le dernier caractère.

Complexité

Constante.

Notes

libc++ rétroporte cend() au mode C++98.

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>
#include <string>

int main()
{
    std::string s("Exemparl");
    std::next_permutation(s.begin(), s.end());

    std::string c;
    std::copy(s.cbegin(), s.cend(), std::back_inserter(c));
    std::cout << c << '\n'; // "Exemplar"
}
