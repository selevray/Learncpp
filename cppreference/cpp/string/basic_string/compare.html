Compare deux séquences de caractères.

  1. Compare cette chaîne à str.

  2. Compare une sous-chaîne [pos1,pos1 + count1) de cette chaîne à str.

  • Si count1 > size() - pos1, la sous-chaîne est [pos1,size()).
  1. Compare une sous-chaîne [pos1,pos1 + count1) de cette chaîne à une sous-chaîne [pos2,pos2 + count2) de str.
  • Si count1 > size() - pos1, la première sous-chaîne est [pos1,size()).
  • Si count2 > str.size() - pos2, la seconde sous-chaîne est [pos2,str.size()).

  1. Compare cette chaîne à la séquence de caractères terminée par un caractère nul commençant au caractère pointé par s, de longueur Traits::length(s).

  2. Compare une sous-chaîne [pos1,pos1 + count1) de cette chaîne à la séquence de caractères terminée par un caractère nul commençant au caractère pointé par s, de longueur Traits::length(s).

  • Si count1 > size() - pos1, la sous-chaîne est [pos1,size()).
  1. Compare une sous-chaîne [pos1,pos1 + count1) de cette chaîne aux caractères de l'intervalle [s,s + count2). Les caractères de [s,s + count2) peuvent inclure des caractères nuls.
  • Si count1 > size() - pos1, la sous-chaîne est [pos1,size()).

7-9) Convertit implicitement t en une vue de chaîne sv comme si l'on appelait std::basic_string_view<CharT, Traits> sv = t;, puis

  1. compare cette chaîne à sv;

  2. compare une sous-chaîne [pos1,pos1 + count1) de cette chaîne à sv, comme si l'on appelait std::basic_string_view<CharT, Traits>(*this).substr(pos1, count1).compare(sv);

  3. compare une sous-chaîne [pos1,pos1 + count1) de cette chaîne à une sous-chaîne [pos2,pos2 + count2) de sv, comme si l'on appelait std::basic_string_view<CharT, Traits>(*this) .substr(pos1, count1).compare(sv.substr(pos2, count2)).

Ces surcharges ne participent à la résolution de surcharge que si std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>> est true et std::is_convertible_v<const StringViewLike&, const CharT*> est false..

Une séquence de caractères composée de count1 caractères commençant à data1 est comparée à une séquence de caractères composée de count2 caractères commençant à data2 comme suit :

  • Calculez d'abord le nombre de caractères à comparer, comme si l'on appelait size_type rlen = std::min(count1, count2).
  • Comparez ensuite les séquences en appelant Traits::compare(data1, data2, rlen). Pour les chaînes standard, cette fonction effectue une comparaison lexicographique caractère par caractère. Si le résultat est zéro (les séquences de caractères sont égales jusqu'ici), leurs tailles sont alors comparées comme suit :

Condition | Résultat | Valeur de retour

Traits::compare(data1, data2, rlen) < 0 | data1 est inférieur à data2 | <0

Traits::compare(data1, data2, rlen) == 0 | size1 < size2 | data1 est inférieur à data2 | <0

size1 == size2 | data1 est égal à data2 | 0

size1 > size2 | data1 est supérieur à data2 | >0

Traits::compare(data1, data2, rlen) > 0 | data1 est supérieur à data2 | >0

Paramètres

  • str — autre chaîne à comparer
  • s — pointeur vers la chaîne de caractères à comparer
  • count1 — nombre de caractères de cette chaîne à comparer
  • pos1 — position du premier caractère de cette chaîne à comparer
  • count2 — nombre de caractères de la chaîne donnée à comparer
  • pos2 — position du premier caractère de la chaîne donnée à comparer
  • t — objet (convertible en std::basic_string_view) à comparer

Valeur de retour

  • Valeur négative si *this précède la séquence de caractères spécifiée par les arguments, dans l'ordre lexicographique.
  • Zéro si les deux séquences de caractères sont équivalentes.
  • Valeur positive si *this suit la séquence de caractères spécifiée par les arguments, dans l'ordre lexicographique.

Exceptions

Les surcharges prenant des paramètres nommés pos1 ou pos2 lèvent std::out_of_range si l'argument est hors limites.

7)noexcept specification:noexcept(std::is_nothrow_convertible_v<const T&, std::basic_string_view<CharT, Traits>>)

8,9) Lève toute exception levée par la conversion en std::basic_string_view.

Si une exception est levée pour quelque raison que ce soit, cette fonction n'a aucun effet (garantie forte de sécurité d'exception).

Implémentation possible

overload (1)

template<class CharT, class Traits, class Alloc>
int std::basic_string<CharT, Traits, Alloc>::compare
    (const std::basic_string& s) const noexcept
{
    size_type lhs_sz = size();
    size_type rhs_sz = s.size();
    int result = traits_type::compare(data(), s.data(), std::min(lhs_sz, rhs_sz));
    if (result != 0)
        return result;
    if (lhs_sz < rhs_sz)
        return -1;
    if (lhs_sz > rhs_sz)
        return 1;
    return 0;
}

Notes

Pour les situations où la comparaison à trois voies n'est pas requise, std::basic_string fournit les opérateurs relationnels habituels (<, <=, ==, >, etc.).

Par défaut (avec le std::char_traits par défaut), cette fonction n'est pas sensible à la locale. Voir std::collate::compare pour la comparaison de chaînes à trois voies tenant compte de la locale.

Exemple

#include <cassert>
#include <iomanip>
#include <iostream>
#include <string>
#include <string_view>

void print_compare_result(std::string_view str1,
                          std::string_view str2,
                          int compare_result)
{
    if (compare_result < 0)
        std::cout << std::quoted(str1) << " comes before "
                  << std::quoted(str2) << ".\n";
    else if (compare_result > 0)
        std::cout << std::quoted(str2) << " comes before "
                  << std::quoted(str1) << ".\n";
    else
        std::cout << std::quoted(str1) << " and "
                  << std::quoted(str2) << " are the same.\n";
}

int main()
{
    std::string batman{"Batman"};
    std::string superman{"Superman"};
    int compare_result{0};

    // 1) Comparer avec une autre chaîne
    compare_result = batman.compare(superman);
    std::cout << "1) ";
    print_compare_result("Batman", "Superman", compare_result);

    // 2) Comparer une sous-chaîne avec une autre chaîne
    compare_result = batman.compare(3, 3, superman);
    std::cout << "2) ";
    print_compare_result("man", "Superman", compare_result);

    // 3) Comparer une sous-chaîne avec une autre sous-chaîne
    compare_result = batman.compare(3, 3, superman, 5, 3);
    std::cout << "3) ";
    print_compare_result("man", "man", compare_result);

    // Compare une sous-chaîne avec une autre sous-chaîne
    // par défaut jusqu'à la fin de l'autre chaîne
    assert(compare_result == batman.compare(3, 3, superman, 5));

    // 4) Compare avec un pointeur sur char
    compare_result = batman.compare("Superman");
    std::cout << "4) ";
    print_compare_result("Batman", "Superman", compare_result);

    // 5) Compare une sous-chaîne avec un pointeur sur char
    compare_result = batman.compare(3, 3, "Superman");
    std::cout << "5) ";
    print_compare_result("man", "Superman", compare_result);

    // 6) Compare une sous-chaîne avec une sous-chaîne d'un pointeur sur char
    compare_result = batman.compare(0, 3, "Superman", 5);
    std::cout << "6) ";
    print_compare_result("Bat", "Super", compare_result);
}

Output:

1) "Batman" comes before "Superman".
2) "Superman" comes before "man".
3) "man" and "man" are the same.
4) "Batman" comes before "Superman".
5) "Superman" comes before "man".
6) "Bat" comes before "Super".
