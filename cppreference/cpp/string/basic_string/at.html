std::basic_string<CharT,Traits,Allocator>::at

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

CharT& at( size_type pos );  // (1) (constexpr depuis C++20)

const CharT& at( size_type pos ) const;  // (2) (constexpr depuis C++20)

Renvoie une référence au caractère situé à la position spécifiée pos. La vérification des bornes est effectuée ; une exception de type std::out_of_range est levée en cas d'accès invalide.

Paramètres

  • pos — position du caractère à renvoyer

Valeur de retour

Référence au caractère demandé.

Exceptions

Lève std::out_of_range si pos >= size().

Si une exception est levée pour quelque raison que ce soit, ces fonctions n'ont aucun effet (garantie forte de sécurité d'exception).

Complexité

Constante.

Exemple

#include <iostream>
#include <stdexcept>
#include <string>

int main()
{
    std::string s("message"); // pour la capacité

    s = "abc";
    s.at(2) = 'x'; // OK
    std::cout << s << '\n';

    std::cout << "string size = " << s.size() << '\n';
    std::cout << "string capacity = " << s.capacity() << '\n';

    try
    {
        // Ceci lèvera une exception car le décalage demandé est supérieur à la taille actuelle.
        s.at(3) = 'x';
    }
    catch (std::out_of_range const& exc)
    {
        std::cout << exc.what() << '\n';
    }
}
