std::basic_string<CharT,Traits,Allocator>::operator=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

basic_string& operator=( const basic_string& str );  // (1) (constexpr depuis C++20)

basic_string& operator=( basic_string&& str )
    noexcept(/* voir ci-dessous */);  // (2) (depuis C++11) (constexpr depuis C++20)

basic_string& operator=( const CharT* s );  // (3) (constexpr depuis C++20)

basic_string& operator=( CharT ch );  // (4) (constexpr depuis C++20)

basic_string& operator=( std::initializer_list<CharT> ilist );  // (5) (depuis C++11) (constexpr depuis C++20)

template<class StringViewLike>
basic_string& operator=( const StringViewLike& t );  // (6) (depuis C++17) (constexpr depuis C++20)

basic_string& operator=( std::nullptr_t ) = delete;  // (7) (depuis C++23)

Remplace le contenu de la chaîne.

  1. Remplace le contenu par une copie de str. Si *this et str sont le même objet, cette fonction n'a aucun effet.

  2. Remplace le contenu par celui de str en utilisant la sémantique d'affectation par déplacement de SequenceContainer.

Contrairement aux affectations par déplacement des autres conteneurs séquentiels, les références, pointeurs et itérateurs vers les éléments de str peuvent être invalidés.

  1. Remplace le contenu par celui de la chaîne de caractères terminée par un caractère nul pointée par s, comme par assign(s, Traits::length(s)).

  2. Remplace le contenu par le caractère ch, comme par assign(std::addressof(ch), 1).

  3. Remplace le contenu par celui de la liste d'initialisation ilist, comme par assign(ilist.begin(), ilist.size()).

  4. Convertit implicitement t en string view sv comme par std::basic_string_view<CharT, Traits> sv = t;, puis remplace le contenu par celui de la sv comme par assign(sv).

Cette surcharge ne participe à la résolution de surcharge que si std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>> est true et std::is_convertible_v<const StringViewLike&, const CharT*> est false.

  1. std::basic_string ne peut pas être affecté à partir de nullptr.

Paramètres

  • ch — valeur avec laquelle initialiser les caractères de la chaîne
  • str — chaîne servant de source pour initialiser la chaîne
  • s — pointeur vers une chaîne de caractères terminée par un caractère nul servant de source pour initialiser la chaîne
  • ilist — std::initializer_list avec lequel initialiser la chaîne
  • t — objet convertible en std::basic_string_view pour initialiser la chaîne

Valeur de retour

*this

Complexité

  1. Linéaire en la taille de str.

  2. Linéaire en la taille de *this (formellement, chaque CharT doit être détruit). Si les allocateurs ne se comparent pas égaux et ne se propagent pas, alors également linéaire en la taille de str (une copie doit être faite).

  3. Linéaire en la taille de s.

  4. Constante.

  5. Linéaire en la taille de ilist.

  6. Linéaire en la taille de t.

Exceptions

2)noexcept specification:noexcept(std::allocator_traits<Allocator>:: propagate_on_container_move_assignment::value || std::allocator_traits<Allocator>::is_always_equal::value)

Si l'opération devait faire dépasser size() à max_size(), lève std::length_error.

Si une exception est levée pour quelque raison que ce soit, cette fonction n'a aucun effet (garantie forte de sécurité d'exception).

Exemple

#include <iomanip>
#include <iostream>
#include <string>

int main()
{
    std::string str1;
    std::string str2{"alpha"};

    // (1) operator=(const basic_string&);
    str1 = str2;
    std::cout << std::quoted(str1) << ' '   // "alpha"
              << std::quoted(str2) << '\n'; // "alpha"

    // (2) operator=(basic_string&&);
    str1 = std::move(str2);
    std::cout << std::quoted(str1) << ' '   // "alpha"
              << std::quoted(str2) << '\n'; // "" ou "alpha" (non spécifié)

    // (3) operator=(const CharT*);
    str1 = "beta";
    std::cout << std::quoted(str1) << '\n'; // "beta"

    // (4) operator=(CharT);
    str1 = '!';
    std::cout << std::quoted(str1) << '\n'; // "!"

    // (5) operator=(std::initializer_list<CharT>);
    str1 = {'g', 'a', 'm', 'm', 'a'};
    std::cout << std::quoted(str1) << '\n'; // "gamma"

    // (6) operator=(const T&);
    str1 = 35U; // équivalent à str1 = static_cast<char>(35U);
    std::cout << std::quoted(str1) << '\n'; // "#" (ASCII = 35)
}

Sortie possible :

"alpha" "alpha"
"alpha" ""
"beta"
"!"
"gamma"
"#"

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 847 C++98 il n'y avait aucune garantie de sécurité d'exception ajout de la garantie forte de sécurité d'exception
LWG 2063 C++11 l'opérateur d'affectation par déplacement ne respecte pas l'exigence sémantique de SequenceContainer follows
LWG 2946 C++17 la surcharge (6) causait une ambiguïté dans certains cas évité en en faisant un modèle
