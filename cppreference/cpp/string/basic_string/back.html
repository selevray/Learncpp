std::basic_string<CharT,Traits,Allocator>::back

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

CharT& back();  // (1) (constexpr depuis C++20)

const CharT& back() const;  // (2) (constexpr depuis C++20)

Renvoie une référence vers le dernier caractère de la chaîne. Le comportement est indéfini si empty() est true.

Paramètres

(aucune)

Valeur de retour

Référence au dernier caractère, équivalent à operator[](size() - 1).

Complexité

Constante.

Notes

Dans libstdc++, back() n'est pas disponible en mode C++98.

Exemple

#include <iostream>
#include <string>

int main()
{
    std::string s("Exemplary");
    char& back1 = s.back();
    back1 = 's';
    std::cout << s << '\n'; // "Exemplars"

    std::string const c("Exemplary");
    char const& back2 = c.back();
    std::cout << back2 << '\n'; // 'y'
}

Output:

Exemplars
y
