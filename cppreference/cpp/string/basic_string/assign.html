Remplace le contenu de la chaîne.

  1. Équivalent à return *this = str;.

  2. Équivalent à return *this = std::move(str);.

  3. Remplace le contenu par count copies du caractère ch.

Équivalent à clear(); resize(n, c); return *this;.

  1. Remplace le contenu par des copies des caractères de l'intervalle [s,s + count).

Si [s,s + count) n'est pas un intervalle valide, le comportement est indéfini.

  1. Équivalent à return assign(s, Traits::length(s));.

6,7) Remplace le contenu par des caractères d'une vue de chaîne sv construite à partir de t.

  • Si seul t est fourni, remplace le contenu par tous les caractères de sv.
  • Si pos est également fourni :
    • Si count est npos, remplace le contenu par tous les caractères de sv à partir de pos.
    • Sinon, remplace le contenu par les std::min(count, sv.size() - pos) caractères de sv à partir de pos.

Ces surcharges ne participent à la résolution de surcharge que si toutes les conditions suivantes sont satisfaites :

  • std::is_convertible_v<const SV&, std::basic_string_view<CharT, Traits>> is true.
  • std::is_convertible_v<const SV&, const CharT*> is false.

  1. Équivalent à std::basic_string_view<CharT, Traits> sv = t;return assign(sv.data(), sv.size());.

  2. Équivalent à std::basic_string_view<CharT, Traits> sv = t;return assign(sv.substr(pos, count));.

  3. Remplace le contenu par des caractères de str.

  • Si count est npos, remplace le contenu par tous les caractères de str à partir de pos.
  • Sinon, remplace le contenu par les std::min(count, str.size() - pos) caractères de str à partir de pos.

Équivalent à return assign(std::basic_string_view<CharT, Traits> (str).substr(pos, count));.

(depuis C++20)

  1. Équivalent à return assign(basic_string(first, last, get_allocator()));.

Cette surcharge ne participe à la résolution de surcharge que si InputIt satisfait aux exigences de LegacyInputIterator.

(depuis C++11)

  1. Équivalent à return assign(ilist.begin(), ilist.size());.

Paramètres

  • str — chaîne à utiliser comme source pour initialiser les caractères
  • count — taille de la chaîne résultante
  • ch — valeur avec laquelle initialiser les caractères de la chaîne
  • s — pointeur vers une chaîne de caractères à utiliser comme source pour initialiser la chaîne
  • t — objet (convertible en std::basic_string_view) avec lequel initialiser les caractères de la chaîne
  • pos — indice du premier caractère à prendre
  • first, last — intervalle à partir duquel copier les caractères
  • ilist — std::initializer_list avec lequel initialiser les caractères de la chaîne

Valeur de retour

*this

Exceptions

2)noexcept specification:noexcept(std::allocator_traits<Allocator>:: propagate_on_container_move_assignment::value || std::allocator_traits<Allocator>::is_always_equal::value)

Si l'opération devait faire dépasser size() à max_size(), lève std::length_error.

  1. Si pos > sv.size() vaut true, lève std::out_of_range.

  2. Si pos > str.size() vaut true, lève std::out_of_range.

Si une exception est levée pour quelque raison que ce soit, cette fonction n'a aucun effet (garantie forte de sécurité d'exception).

Exemple

#include <iostream>
#include <iterator>
#include <string>

int main()
{
    std::string s;
    // assign(size_type count, CharT ch)
    s.assign(4, '=');
    std::cout << s << '\n'; // "===="

    std::string const c("Exemplary");
    // assign(const basic_string& str)
    s.assign(c);
    std::cout << c << " == " << s << '\n'; // "Exemplary == Exemplary"

    // assign(const basic_string& str, size_type pos, size_type count)
    s.assign(c, 0, c.length() - 1);
    std::cout << s << '\n'; // "Exemplar";

    // assign(basic_string&& str)
    s.assign(std::string("C++ by ") + "example");
    std::cout << s << '\n'; // "C++ by example"

    // assign(const CharT* s, size_type count)
    s.assign("C-style string", 7);
    std::cout << s << '\n'; // "C-style"

    // assign(const CharT* s)
    s.assign("C-style\0string");
    std::cout << s << '\n'; // "C-style"

    char mutable_c_str[] = "C-style string";
    // assign(InputIt first, InputIt last)
    s.assign(std::begin(mutable_c_str), std::end(mutable_c_str) - 1);
    std::cout << s << '\n'; // "C-style string"

    // assign(std::initializer_list<CharT> ilist)
    s.assign({'C', '-', 's', 't', 'y', 'l', 'e'});
    std::cout << s << '\n'; // "C-style"
}

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 847 C++98 il n'y avait aucune garantie de sécurité d'exception ajout de la garantie forte de sécurité d'exception
LWG 2063 C++11 une note non normative indiquait que la surcharge (2) peut être implémentée par échange corrigé pour exiger l'affectation par déplacement
LWG 2250 C++98 le comportement de la surcharge (8) était indéfini si pos > str.size() vaut true lève toujours une exception dans ce cas
LWG 2579 C++98 la surcharge (1) et l'opérateur d'affectation par copie avaient des effets différents ils ont le même effet
LWG 2946 C++17 la surcharge (6) causait une ambiguïté dans certains cas évité en en faisant un modèle
