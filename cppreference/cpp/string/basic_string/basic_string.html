Construit une nouvelle chaîne à partir de diverses sources de données, en utilisant éventuellement l'allocateur fourni par l'utilisateur alloc.

  1. Le constructeur par défaut depuis C++11. Construit une chaîne vide avec un allocateur construit par défaut.

Si Allocator n'est pas DefaultConstructible, le comportement est indéfini.

  1. Le constructeur par défaut jusqu'à C++11. Construit une chaîne vide avec l'allocateur donné alloc.

  2. Construit une chaîne avec count copies du caractère ch.

Si CharT n'est pas CopyInsertable dans std::basic_string<CharT>, le comportement est indéfini.

(depuis C++11)

Cette surcharge ne participe à la résolution de surcharge que si Allocator satisfait aux exigences de Allocator.

(depuis C++17)

  1. Construit une chaîne avec le contenu de l'intervalle [first,last). Chaque itérateur de [first,last) est déréférencé exactement une fois.

Si InputIt ne satisfait pas aux exigences de LegacyInputIterator, la surcharge (3) est appelée à la place avec les arguments static_cast<size_type>(first), last et alloc.

(jusqu'à C++11)

Cette surcharge ne participe à la résolution de surcharge que si InputIt satisfait aux exigences de LegacyInputIterator.

Si CharT n'est pas EmplaceConstructible dans std::basic_string<CharT> depuis *first, le comportement est indéfini.

(depuis C++11)

  1. Construit une chaîne avec le contenu de l'intervalle rg. Chaque itérateur de rg est déréférencé exactement une fois.

Si CharT n'est pas EmplaceConstructible dans std::basic_string<CharT> depuis *ranges::begin(rg), le comportement est indéfini.

  1. Construit une chaîne avec le contenu de l'intervalle [s,s + count).

Si [s,s + count) n'est pas un intervalle valide, le comportement est indéfini.

  1. Équivalent à basic_string(s, Traits::length(s), alloc).

Cette surcharge ne participe à la résolution de surcharge que si Allocator satisfait aux exigences de Allocator.

(depuis C++17)

  1. std::basic_string ne peut pas être construit à partir de nullptr.

  2. Convertit implicitement t en vue de chaîne sv comme si par std::basic_string_view<CharT, Traits> sv = t;, puis construit une chaîne comme si par basic_string(sv.data(), sv.size(), alloc).

Cette surcharge ne participe à la résolution de surcharge que si std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>> est true et std::is_convertible_v<const StringViewLike&, const CharT*> est false.

  1. Convertit implicitement t en vue de chaîne sv comme si par std::basic_string_view<CharT, Traits> sv = t;, puis construit une chaîne comme si par basic_string(sv.substr(pos, n), alloc).

Cette surcharge ne participe à la résolution de surcharge que si std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>> est true.

11-18) Construit une chaîne avec (une partie de) le contenu de other. Si le type de other est basic_string&&, à la fin de la construction, other est dans un état valide mais non spécifié.

  1. Le constructeur de copie.

L'allocateur est obtenu comme si l'on appelait std::allocator_traits<Allocator>:: select_on_container_copy_construction (other.get_allocator()).

(depuis C++11)

  1. Le constructeur de déplacement. L'allocateur est obtenu par construction par déplacement à partir de other.get_allocator().

  2. Identique au constructeur de copie, sauf que alloc est utilisé comme allocateur.

Si CharT n'est pas CopyInsertable dans std::basic_string<CharT>, le comportement est indéfini.

  1. Identique au constructeur de déplacement, sauf que alloc est utilisé comme allocateur.

Si CharT n'est pas MoveInsertable dans std::basic_string<CharT>, le comportement est indéfini.

15,16) Construit une chaîne avec le contenu de l'intervalle [other.data() + pos,other.data() + other.size()).

17,18) Construit une chaîne avec le contenu de l'intervalle [other.data() + pos,other.data() + (pos + std::min(count, other.size() - pos))).

  1. Équivalent à basic_string(ilist.begin(), ilist.end()).

Paramètres

  • alloc — allocateur à utiliser pour toutes les allocations mémoire de cette chaîne
  • count — taille de la chaîne résultante
  • ch — valeur avec laquelle initialiser la chaîne
  • pos — position du premier caractère à inclure
  • first, last — intervalle à partir duquel copier les caractères
  • s — pointeur vers un tableau de caractères à utiliser comme source pour initialiser la chaîne
  • other — autre chaîne à utiliser comme source pour initialiser la chaîne
  • ilist — std::initializer_list avec lequel initialiser la chaîne
  • t — objet (convertible en std::basic_string_view) avec lequel initialiser la chaîne
  • rg — un intervalle compatible avec le conteneur

Complexité

1,2) Constante.

3-7) Linéaire en la taille de la chaîne.

9-11) Linéaire en la taille de la chaîne.

  1. Constante.

  2. Linéaire en la taille de la chaîne.

  3. Linéaire en la taille de la chaîne si alloc != other.get_allocator() est true, sinon constant.

15-19) Linéaire en la taille de la chaîne.

Exceptions

  1. std::out_of_range si pos est hors limites.

  2. ne lève aucune exception si alloc == str.get_allocator() est true.

15-18) std::out_of_range si pos > other.size() est true.

Lève std::length_error si la longueur de la chaîne construite dépasserait max_size() (par exemple, si count > max_size() pour (3)). Les appels à Allocator::allocate peuvent lever une exception.

Si une exception est levée pour quelque raison que ce soit, ces fonctions n'ont aucun effet (garantie forte de sécurité d'exception).

Notes

L'initialisation avec un littéral de chaîne contenant des caractères '\0' intégrés utilise la surcharge (7), qui s'arrête au premier caractère nul. Ceci peut être évité en spécifiant un autre constructeur ou en utilisant operator""s :

std::string s1 = "ab\0\0cd";   // s1 contient "ab"
std::string s2{"ab\0\0cd", 6}; // s2 contient "ab\0\0cd"
std::string s3 = "ab\0\0cd"s;  // s3 contient "ab\0\0cd"

Exemple

#include <cassert>
#include <cctype>
#include <iomanip>
#include <iostream>
#include <iterator>
#include <string>

int main()
{
    std::cout << "1)  string(); ";
    std::string s1;
    assert(s1.empty() && (s1.length() == 0) && (s1.size() == 0));
    std::cout << "s1.capacity(): " << s1.capacity() << '\n'; // unspecified

    std::cout << "3)  string(size_type count, CharT ch): ";
    std::string s2(4, '=');
    std::cout << std::quoted(s2) << '\n'; // "===="

    std::cout << "4)  string(InputIt first, InputIt last): ";
    char mutable_c_str[] = "another C-style string";
    std::string s4(std::begin(mutable_c_str) + 8, std::end(mutable_c_str) - 1);
    std::cout << std::quoted(s4) << '\n'; // "C-style string"

    std::cout << "6)  string(CharT const* s, size_type count): ";
    std::string s6("C-style string", 7);
    std::cout << std::quoted(s6) << '\n'; // "C-style", c'est-à-dire [0, 7)

    std::cout << "7)  string(CharT const* s): ";
    std::string s7("C-style\0string");
    std::cout << std::quoted(s7) << '\n'; // "C-style"

    std::cout << "11) string(string&): ";
    std::string const other11("Exemplar");
    std::string s11(other11);
    std::cout << std::quoted(s11) << '\n'; // "Exemplar"

    std::cout << "12) string(string&&): ";
    std::string s12(std::string("C++ by ") + std::string("example"));
    std::cout << std::quoted(s12) << '\n'; // "C++ by example"

    std::cout << "15) string(const string& other, size_type pos): ";
    std::string const other15("Mutatis Mutandis");
    std::string s15(other15, 8);
    std::cout << std::quoted(s15) << '\n'; // "Mutandis", c'est-à-dire [8, 16)

    std::cout << "17) string(const string& other, size_type pos, size_type count): ";
    std::string const other17("Exemplary");
    std::string s17(other17, 0, other17.length() - 1);
    std::cout << std::quoted(s17) << '\n'; // "Exemplar"

    std::cout << "19) string(std::initializer_list<CharT>): ";
    std::string s19({'C', '-', 's', 't', 'y', 'l', 'e'});
    std::cout << std::quoted(s19) << '\n'; // "C-style"
}
