  1. Ce guide de déduction est fourni pour std::basic_string afin de permettre la déduction à partir d'un intervalle d'itérateurs. Cette surcharge ne participe à la résolution de surcharge que si InputIt satisfait LegacyInputIterator et si Alloc satisfait Allocator.

2,3) Ces guides de déduction sont fournis pour std::basic_string afin de permettre la déduction à partir d'un std::basic_string_view. Le type de paramètre size_type dans (3) fait référence au type membre size_type du type déduit par le guide de déduction. Ces surcharges ne participent à la résolution de surcharge que si Alloc satisfait Allocator.

  1. Ce guide de déduction est fourni pour std::basic_string afin de permettre la déduction à partir d'une étiquette std::from_range_t et d'un input_range.

Remarque : la mesure dans laquelle la bibliothèque détermine qu'un type ne satisfait pas LegacyInputIterator n'est pas spécifiée, sauf qu'au minimum les types entiers ne sont pas qualifiés comme itérateurs d'entrée. De même, la mesure dans laquelle elle détermine qu'un type ne satisfait pas Allocator n'est pas spécifiée, sauf qu'au minimum le type membre Alloc::value_type doit exister et l'expression std::declval<Alloc&>().allocate(std::size_t{}) doit être bien formée lorsqu'elle est traitée comme opérande non évalué.

Notes

Les guides (2,3) sont nécessaires car les constructeurs std::basic_string de std::basic_string_view ont été transformés en modèles afin d'éviter des ambiguïtés dans le code existant, et ces modèles ne prennent pas en charge la déduction des arguments de modèle de classe.

Exemple

#include <cassert>
#include <string>
#include <vector>

int main()
{
    std::vector<char> v = {'a', 'b', 'c'};
    std::basic_string s1(v.begin(), v.end()); // utilise le guide de déduction (1)
    assert(s1 == "abc");

#if __cpp_lib_containers_ranges >= 202202L
    std::vector<wchar_t> v4{0x43, 43, 053, 0x32, 0x33};
    std::basic_string s4(std::from_range, v4); // utilise le guide de déduction (4)
    assert(s4 == L"C++23");
#endif
}
