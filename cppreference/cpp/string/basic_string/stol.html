Interprète une valeur entière signée contenue dans la chaîne str.

Soit ptr un pointeur interne (aux fonctions de conversion) de type char* (1,3,5) ou wchar_t* (2,4,6), selon le cas.

  1. Appelle std::strtol(str.c_str(), &ptr, base).

  2. Appelle std::wcstol(str.c_str(), &ptr, base).

  3. Appelle std::strtol(str.c_str(), &ptr, base).

  4. Appelle std::wcstol(str.c_str(), &ptr, base).

  5. Appelle std::strtoll(str.c_str(), &ptr, base).

  6. Appelle std::wcstoll(str.c_str(), &ptr, base).

Ignore tous les caractères d'espacement (tels qu'identifiés par l'appel à std::isspace) jusqu'à ce que le premier caractère non espace soit trouvé, puis prend autant de caractères que possible pour former une représentation valide d'entier en base base-n (où n=base) et les convertit en valeur entière. La valeur entière valide se compose des parties suivantes :

  • (facultatif) signe plus ou moins
  • (facultatif) préfixe (0) indiquant la base octale (s'applique uniquement lorsque la base vaut 8 ou 0)
  • (optionnel) préfixe (0x ou 0X) indiquant la base hexadécimale (ne s'applique que lorsque la base vaut 16 ou 0)
  • une suite de chiffres

L'ensemble des valeurs valides pour base est {0, 2, 3, ..., 36}. L'ensemble des chiffres valides pour les entiers en base-2 est {0, 1}, pour les entiers en base-3 est {0, 1, 2}, et ainsi de suite. Pour les bases supérieures à 10, les chiffres valides incluent les caractères alphabétiques, à partir de Aa pour un entier en base-11, jusqu'à Zz pour un entier en base-36. La casse des caractères est ignorée.

Des formats numériques supplémentaires peuvent être acceptés par la locale C actuellement installée.

Si la valeur de base vaut 0, la base numérique est détectée automatiquement : si le préfixe est 0, la base est octale ; si le préfixe est 0x ou 0X, la base est hexadécimale ; sinon, la base est décimale.

Si le signe moins faisait partie de la séquence d'entrée, la valeur numérique calculée à partir de la séquence de chiffres est niée comme par moins unaire dans le type de résultat.

Si pos n'est pas un pointeur nul, alors ptr recevra l'adresse du premier caractère non converti dans str.c_str(), et l'indice de ce caractère sera calculé et stocké dans *pos, donnant le nombre de caractères traités par la conversion.

Paramètres

  • str — la chaîne à convertir
  • pos — adresse d'un entier où stocker le nombre de caractères traités
  • base — la base de numération

Valeur de retour

Valeur entière correspondant au contenu de str.

Exceptions

  • std::invalid_argument si aucune conversion n'a pu être effectuée.
  • std::out_of_range si la valeur convertie sortirait de l'intervalle du type de résultat, ou si la fonction sous-jacente (std::strtol ou std::strtoll) met errno à ERANGE.

Exemple

#include <iomanip>
#include <iostream>
#include <stdexcept>
#include <string>
#include <utility>

int main()
{
    const auto data =
    {
        "45",
        "+45",
        " -45",
        "3.14159",
        "31337 with words",
        "words and 2",
        "12345678901",
    };

    for (const std::string s : data)
    {
        std::size_t pos{};
        try
        {
            std::cout << "std::stoi(" << std::quoted(s) << "): ";
            const int i{std::stoi(s, &pos)};
            std::cout << i << "; pos: " << pos << '\n';
        }
        catch (std::invalid_argument const& ex)
        {
            std::cout << "std::invalid_argument::what(): " << ex.what() << '\n';
        }
        catch (std::out_of_range const& ex)
        {
            std::cout << "std::out_of_range::what(): " << ex.what() << '\n';
            const long long ll{std::stoll(s, &pos)};
            std::cout << "std::stoll(" << std::quoted(s) << "): " << ll
                      << "; pos: " << pos << '\n';
        }
    }

    std::cout << "\nCalling with different radixes:\n";
    for (const auto& [s, base] : {std::pair<const char*, int>
        {"11",  2}, {"22",  3}, {"33",  4}, {"77",  8},
        {"99", 10}, {"FF", 16}, {"jJ", 20}, {"Zz", 36}})
    {
        const int i{std::stoi(s, nullptr, base)};
        std::cout << "std::stoi(" << std::quoted(s)
                  << ", nullptr, " << base << "): " << i << '\n';
    }
}
