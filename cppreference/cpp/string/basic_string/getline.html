getline lit des caractères depuis un flux d'entrée et les place dans une chaîne :

1,2) Se comporte comme UnformattedInputFunction, sauf que input.gcount() n'est pas affecté. Après la construction et la vérification de l'objet sentry, effectue les opérations suivantes :

  1. Appelle str.erase().

  2. Extrait des caractères de input et les ajoute à str jusqu'à ce que l'une des conditions suivantes soit remplie (vérifiées dans l'ordre indiqué)

a) condition de fin de fichier sur input, auquel cas getline définit eofbit.

b) le prochain caractère d'entrée disponible est delim, comme testé par Traits::eq(c, delim), auquel cas le caractère délimiteur est extrait de input, mais n'est pas ajouté à str.

c) str.max_size() caractères ont été stockés, auquel cas getline définit failbit et retourne.

  1. Si aucun caractère n'a été extrait quelle qu'en soit la raison (pas même le délimiteur écarté), getline définit failbit et retourne.

3,4) Identique à getline(input, str, input.widen('\n')), c'est-à-dire que le délimiteur par défaut est le caractère de fin de ligne.

Paramètres

  • input — le flux depuis lequel lire les données
  • str — la chaîne dans laquelle placer les données
  • delim — le caractère délimiteur

Valeur de retour

input

Notes

Lors de la lecture d'une entrée délimitée par des espaces (par exemple int n; std::cin >> n;), tout espace blanc qui suit, y compris un caractère de saut de ligne, reste dans le flux d'entrée. Ensuite, lors du passage à une entrée orientée ligne, la première ligne récupérée avec getline ne contiendra que cet espace. Dans le cas probable où ce comportement n'est pas souhaité, les solutions possibles incluent :

  • Un appel initial superflu explicite à getline.
  • Suppression des espaces consécutifs avec std::cin >> std::ws.
  • Ignorer tous les caractères restants de la ligne d'entrée avec cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');.

Exemple

L'exemple suivant montre comment utiliser la fonction getline pour lire la saisie utilisateur, et traiter un flux ligne par ligne, ou par parties d'une ligne à l'aide du paramètre delim.

#include <iostream>
#include <sstream>
#include <string>

int main()
{
    // saluer l'utilisateur
    std::string name;
    std::cout << "What is your name? ";
    std::getline(std::cin, name);
    std::cout << "Hello " << name << ", nice to meet you.\n";

    // lire le fichier ligne par ligne
    std::istringstream input;
    input.str("1\n2\n3\n4\n5\n6\n7\n");
    int sum = 0;
    for (std::string line; std::getline(input, line);)
        sum += std::stoi(line);
    std::cout << "\nThe sum is " << sum << ".\n\n";

    // utiliser un séparateur pour lire des parties de la ligne
    std::istringstream input2;
    input2.str("a;b;c;d");
    for (std::string line; std::getline(input2, line, ';');)
        std::cout << line << '\n';
}
