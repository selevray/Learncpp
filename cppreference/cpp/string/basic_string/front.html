std::basic_string<CharT,Traits,Allocator>::front

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

CharT& front();  // (1) (constexpr depuis C++20)

const CharT& front() const;  // (2) (constexpr depuis C++20)

Renvoie une référence vers le premier caractère de la chaîne. Le comportement est indéfini si empty() est true.

Paramètres

(aucune)

Valeur de retour

Référence au premier caractère, équivalent à operator[](0).

Complexité

Constante.

Notes

Dans libstdc++, front() n'est pas disponible en mode C++98.

Exemple

#include <iostream>
#include <string>

int main()
{
    std::string s("Exemplary");
    char& f1 = s.front();
    f1 = 'e';
    std::cout << s << '\n'; // "exemplary"

    std::string const c("Exemplary");
    char const& f2 = c.front();
    std::cout << &f2 << '\n'; // "Exemplary"
}

Output:

exemplary
Exemplary
