Ajoute des caractères supplémentaires à la chaîne.

  1. Ajoute count copies du caractère ch.

  2. Ajoute les caractères de l'intervalle [s,s + count).

Si [s,s + count) n'est pas un intervalle valide, le comportement est indéfini.

  1. Équivalent à return append(s, Traits::length(s));.

4,5) Ajoute les caractères d'une vue de chaîne sv construite à partir de t.

  • Si seul t est fourni, tous les caractères de sv sont ajoutés.
  • Si pos est également fourni :
    • Si count vaut npos, tous les caractères de sv à partir de pos sont ajoutés.
    • Sinon, les std::min(count, sv.size() - pos) caractères de sv à partir de pos sont ajoutés.

Ces surcharges ne participent à la résolution de surcharge que si toutes les conditions suivantes sont satisfaites :

  • std::is_convertible_v<const SV&, std::basic_string_view<CharT, Traits>> is true.
  • std::is_convertible_v<const SV&, const CharT*> is false.

  1. Équivalent à std::basic_string_view<CharT, Traits> sv = t;return append(sv.data(), sv.size());.

  2. Équivalent à std::basic_string_view<CharT, Traits> sv = t;return append(sv.substr(pos, count));.

6,7) Ajoute les caractères d'une autre chaîne str.

  • Si seul str est fourni, tous ses caractères sont ajoutés.
  • Si pos est également fourni :
    • Si count vaut npos, tous les caractères de str à partir de pos sont ajoutés.
    • Sinon, les std::min(count, str.size() - pos) caractères de str à partir de pos sont ajoutés.
  1. Équivalent à return append(str.data(), str.size());.
  1. Équivalent à return append(std::basic_string_view<CharT, Traits> (str).substr(pos, count));.

(depuis C++20)

  1. Équivalent à return append(basic_string(first, last, get_allocator()));.

Cette surcharge a le même effet que la surcharge (1) si InputIt est un type entier.

(jusqu'à C++11)

Cette surcharge ne participe à la résolution de surcharge que si InputIt satisfait aux exigences de LegacyInputIterator.

(depuis C++11)

  1. Équivalent à return append(ilist.begin(), ilist.size());.

Paramètres

  • count — nombre de caractères à ajouter
  • ch — valeur du caractère à ajouter
  • s — pointeur vers la chaîne de caractères à ajouter
  • t — objet convertible en std::basic_string_view contenant les caractères à ajouter
  • pos — l'indice du premier caractère à ajouter
  • str — chaîne à ajouter
  • first, last — intervalle de caractères à ajouter
  • ilist — liste d'initialisation contenant les caractères à ajouter

Valeur de retour

*this

Complexité

Il n'existe aucune garantie de complexité dans la norme ; les implémentations typiques se comportent de manière similaire à std::vector::insert().

Exceptions

Si l'opération devait faire dépasser size() à max_size(), lève std::length_error.

  1. Si pos > sv.size() vaut true, lève std::out_of_range.

  2. Si pos > str.size() vaut true, lève std::out_of_range.

Si une exception est levée pour quelque raison que ce soit, cette fonction n'a aucun effet (garantie forte de sécurité d'exception).

Exemple

#include <cassert>
#include <string>

int main()
{
    std::string str = "std::string";
    const char* cptr = "C-string";
    const char carr[] = "range";

    std::string result;

    // 1) Ajoute un char 3 fois.
    // Remarque : c'est la seule surcharge acceptant des « CharT ».
    result.append(3, '*');
    assert(result == "***");

    // 2) Ajoute une chaîne C de longueur fixe
    result.append(cptr, 5);
    assert(result == "***C-str");

    // 3) Ajoute une chaîne C terminée par un caractère nul
    // Remarque : comme « append » renvoie *this, on peut enchaîner les appels.
    result.append(1, ' ').append(cptr);
    assert(result == "***C-str C-string");

    // 6) Ajoute une chaîne entière
    result.append(1, ' ').append(str);
    assert(result == "***C-str C-string std::string");

    // 7) Ajoute une partie d'une chaîne
    result.append(str, 3, 2);
    assert(result == "***C-str C-string std::string::");

    // 8) Ajoute un intervalle
    result.append(&carr[2], &carr[3]);
    assert(result == "***C-str C-string std::string::n");

    // 9) Ajoute une liste d'initialisation
    result.append({'p', 'o', 's'});
    assert(result == "***C-str C-string std::string::npos");
}

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 847 C++98 il n'y avait aucune garantie de sécurité d'exception ajout de la garantie forte de sécurité d'exception
LWG 2250 C++98 le comportement de la surcharge (7) était indéfini si pos > str.size() vaut true lève toujours une exception dans ce cas
LWG 2788 C++98 la surcharge (8) utilisait un allocateur construit par défaut pour construire la chaîne temporaire obtient l'allocateur à partir de get_allocator()
LWG 2946 C++17 la surcharge (4) provoque une ambiguïté dans certains cas évité en en faisant un modèle
