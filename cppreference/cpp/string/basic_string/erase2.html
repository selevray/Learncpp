template< class CharT, class Traits, class Alloc, class U = CharT >
constexpr std::basic_string<CharT, Traits, Alloc>::size_type
    erase( std::basic_string<CharT, Traits, Alloc>& c, const U& value );  // (depuis C++26)

template< class CharT, class Traits, class Alloc, class Pred >
constexpr std::basic_string<CharT, Traits, Alloc>::size_type
    erase_if( std::basic_string<CharT, Traits, Alloc>& c, Pred pred );  // (2) (depuis C++20)
  1. Supprime de le conteneur tous les éléments égaux à value. Équivalent à
auto it = std::remove(c.begin(), c.end(), value);
auto r = c.end() - it;
c.erase(it, c.end());
return r;
  1. Supprime du conteneur tous les éléments satisfaisant le prédicat pred. Équivalent à
auto it = std::remove_if(c.begin(), c.end(), pred);
auto r = c.end() - it;
c.erase(it, c.end());
return r;

Paramètres

  • c — conteneur duquel supprimer

  • value — valeur à supprimer

  • pred — prédicat unaire qui renvoie true si l'élément doit être supprimé.

    L'expression pred(v) doit être convertible en bool pour chaque argument v de type (éventuellement const) CharT, quelle que soit la catégorie de valeur, et ne doit pas modifier v. Ainsi, un type de paramètre CharT&n'est pas autorisé, ni CharT sauf si pour CharT un déplacement équivaut à une copie (depuis C++11).

Valeur de retour

Le nombre d'éléments supprimés.

Complexité

Linéaire.

Exemple

#include <iomanip>
#include <iostream>
#include <string>

int main()
{
    std::string word{"startling"};
    std::cout << "Initially, word = " << std::quoted(word) << '\n';

    std::erase(word, 'l');
    std::cout << "After erase 'l': " << std::quoted(word) << '\n';

    auto erased = std::erase_if(word, [](char x)
    {
        return x == 'a' or x == 'r' or x == 't';
    });

    std::cout << "After erase all 'a', 'r', and 't': " << std::quoted(word) << '\n';
    std::cout << "Erased symbols count: " << erased << '\n';

#if __cpp_lib_algorithm_default_value_type
    std::erase(word, {'g'});
    std::cout << "After erase {'g'}: " << std::quoted(word) << '\n';
#endif
}

Sortie possible :

Initially, word = "startling"
After erase 'l', word = "starting"
After erase all 'a', 'r', and 't': "sing"
Erased symbols count: 4
After erase {'g'}: "sin"
