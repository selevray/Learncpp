std::basic_string<CharT,Traits,Allocator>::reserve

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void reserve( size_type new_cap = 0 );  // (jusqu'à C++20)

constexpr void reserve( size_type new_cap );  // (depuis C++20)

void reserve();  // (2) (depuis C++20) (obsolète en C++20) (supprimé en C++26)
  1. Informe un objet std::basic_string d'un changement de taille prévu, afin qu'il puisse gérer l'allocation de stockage de manière appropriée.
  • Si new_cap est supérieur à la capacity() actuelle, un nouveau stockage est alloué, et capacity() est rendue égale ou supérieure à new_cap.
  • Si new_cap est inférieur à la capacity() actuelle, il s'agit d'une demande de réduction non contraignante.
  • Si new_cap est inférieur à la size() actuelle, il s'agit d'une demande non contraignante de réduction à la taille ajustéeéquivalente à shrink_to_fit() (depuis C++11).

(jusqu'à C++20)

  • Si new_cap est inférieur ou égal à la capacity() actuelle, il n'y a aucun effet.

(depuis C++20)

Si un changement de capacité a lieu, tous les itérateurs et références, y compris l'itérateur past-the-end, sont invalidés.

  1. Une demande non contraignante de réduction à la taille ajustée. Après cet appel, capacity() a une valeur non spécifiée supérieure ou égale à size().

Paramètres

  • new_cap — nouvelle capacité de la chaîne

Valeur de retour

(aucune)

Exceptions

Lève std::length_error si new_cap est supérieur à max_size().

Peut lever toute exception levée par std::allocator_traits<Allocator>::allocate(), telle que std::bad_alloc.

Si une exception est levée pour quelque raison que ce soit, cette fonction n'a aucun effet (garantie forte de sécurité d'exception).

Complexité

Au plus linéaire en size() de la chaîne.

Exemple

#include <cassert>
#include <iostream>
#include <string>

int main()
{
    std::string s;
    std::cout << "1) Initially: " << s.capacity() << '\n';

    const std::string::size_type new_cap{101u};
    s.reserve(new_cap);
    assert(s.capacity() >= new_cap);
    std::cout << "2) After reserve(" << new_cap << "): " << s.capacity() << '\n';

    // en respectant le facteur de croissance de la capacité
    auto cap{s.capacity()};
    for (int check{}; check != 4; ++check)
    {
        while (cap == s.capacity())
            s += '$';
        cap = s.capacity();
        std::cout << (3) + check << ") Capacity: " << cap << '\n';
    }

//  s.reserve(); // obsolète/supprimé en C++20/26, utiliser :
    s.shrink_to_fit();
    std::cout << "7) After shrink_to_fit: " << s.capacity() << '\n';
}
