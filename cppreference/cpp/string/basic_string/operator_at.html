std::basic_string<CharT,Traits,Allocator>::operator[]

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

CharT& operator[]( size_type pos );  // (1) (constexpr depuis C++20)

const CharT& operator[]( size_type pos ) const;  // (2) (constexpr depuis C++20)

Renvoie une référence au caractère situé à la position spécifiée pos si pos < size(), ou une référence à CharT() si pos == size(). Aucune vérification des bornes n'est effectuée.

Si pos > size(), le comportement est indéfini.

Pour la surcharge (1), si pos == size(), le comportement est indéfinisi l'objet désigné par la référence renvoyée est modifié pour une valeur autre que CharT() (depuis C++11).

Paramètres

  • pos — position du caractère à renvoyer

Valeur de retour

Référence vers l'élément demandé si pos < size(), ou une référence vers CharT() si pos == size().

Complexité

Constante.

Exemple

#include <iostream>
#include <string>

int main()
{
    const std::string e("Exemplar");
    for (unsigned i = e.length() - 1; i != 0; i /= 2)
        std::cout << e[i];
    std::cout << '\n';

    const char* c = &e[0];
    std::cout << c << '\n'; // afficher comme chaîne C

    // Remplace le dernier caractère de s par 'y'
    std::string s("Exemplar ");
    s[s.size() - 1] = 'y'; // équivalent à s.back() = 'y';
    std::cout << s << '\n';
}

Output:

rmx
Exemplar

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 259 C++98 la surcharge non const pouvait renvoyer une lvalue const data()[pos], ce qui était mal formé modifié pour renvoyer *(begin() + pos)
LWG 2475 C++11 si pos == size(), le comportement de la modification de l' objet désigné par la référence renvoyée était indéfini bien défini si modifié en CharT()
