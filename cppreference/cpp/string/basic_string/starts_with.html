std::basic_string<CharT,Traits,Allocator>::starts_with

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr bool
    starts_with( std::basic_string_view<CharT,Traits> sv ) const noexcept;  // (1) (depuis C++20)

constexpr bool
    starts_with( CharT ch ) const noexcept;  // (2) (depuis C++20)

constexpr bool
    starts_with( const CharT* s ) const;  // (3) (depuis C++20)

Vérifie si la chaîne commence par le préfixe donné. Le préfixe peut être l'un des suivants :

  1. Une vue de chaîne sv (qui peut résulter d'une conversion implicite d'un autre std::basic_string).

  2. Un seul caractère ch.

  3. Une chaîne de caractères terminée par un caractère nul s.

Les trois surcharges renvoient effectivement std::basic_string_view<CharT, Traits>(data(), size()).starts_with(x), où x est le paramètre.

Paramètres

  • sv — une vue de chaîne pouvant résulter d'une conversion implicite d'un autre std::basic_string
  • ch — un seul caractère
  • s — une chaîne de caractères terminée par un caractère nul

Valeur de retour

true si la chaîne commence par le préfixe fourni, false sinon.

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_starts_ends_with 201711L (C++20) Vérification du préfixe et du suffixe de chaîne : starts_with() et ends_with()

Exemple

#include <cassert>
#include <string>
#include <string_view>

int main()
{
    using namespace std::literals;

    const auto str = "Hello, C++20!"s;

    assert
    (""
        && str.starts_with("He"sv)  // (1)
        && !str.starts_with("he"sv) // (1)
        && str.starts_with("He"s)   // (1) conversion implicite de la chaîne en string_view
        && !str.starts_with("he"s)  // (1) conversion implicite de la chaîne en string_view
        && str.starts_with('H')     // (2)
        && !str.starts_with('h')    // (2)
        && str.starts_with("He")    // (3)
        && !str.starts_with("he")   // (3)
    );
}
