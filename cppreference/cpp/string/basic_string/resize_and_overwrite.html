std::basic_string<CharT,Traits,Allocator>::resize_and_overwrite

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class Operation >
constexpr void resize_and_overwrite( size_type count, Operation op );  // (depuis C++23)

Redimensionne la chaîne pour contenir au plus count caractères, en utilisant l'opération fournie par l'utilisateur op pour modifier le contenu éventuellement indéterminé et définir la longueur. Cela évite le coût d'initialisation d'un std::string de taille adéquate lorsqu'il est destiné à être utilisé comme tableau de char rempli par, par exemple, un appel à une API C.

Cette fonction effectue les étapes suivantes :

  1. Obtient un stockage contigu contenant count + 1 caractères, et rend ses k premiers caractères égaux aux k premiers caractères de *this, où k est le plus petit de count et du résultat de size() avant l'appel à resize_and_overwrite. Soit p le pointeur vers le premier caractère du stockage.
    • L'égalité est déterminée comme en vérifiant this->compare(0, k, p, k) == 0.
    • Les caractères de [p + k,p + count] peuvent avoir des valeurs indéterminées.
  2. Évalue std::move(op)(p, count), soit r la valeur de retour.
  3. Remplace le contenu de *this par [p,p + r) (ce qui définit la longueur de *this à r). Invalide tous les pointeurs et références vers l'intervalle [p,p + count].

Si r n'est pas d'un type de type entier, le programme est mal formé.

Si l'une des conditions suivantes est satisfaite, le comportement est indéfini :

  • std::move(op)(p, count) lève une exception.
  • std::move(op)(p, count) modifie p ou count.
  • r n'est pas dans l'intervalle [0,count].
  • Tout caractère de l'intervalle [p,p + r) a une valeur indéterminée.

Il est recommandé aux implémentations d'éviter les copies et allocations inutiles en, par exemple, faisant en sorte que p soit égal au pointeur vers le début du stockage des caractères alloué pour *this après l'appel, lequel peut être identique au stockage existant de *this si count est inférieur ou égal à capacity().

Paramètres

  • count — la taille maximale possible de la nouvelle chaîne
  • op — l'objet fonction utilisé pour définir le nouveau contenu de la chaîne

Exceptions

std::length_error si count > max_size(). Toute exception levée par le Allocator correspondant.

Si une exception est levée par std::move(op)(p, count), le comportement est indéfini. Sinon, si une exception est levée, cette fonction n'a aucun effet.

Notes

resize_and_overwrite invalide tous les itérateurs, pointeurs et références vers *this, qu'une réallocation ait lieu ou non. Les implémentations peuvent supposer que le contenu de la chaîne n'est pas aliasé après l'appel à resize_and_overwrite.

Exemple

Lien pour tester l'exemple : compiler explorer.

#include <algorithm>
#include <cassert>
#include <cstddef>
#include <cstring>
#include <iomanip>
#include <iostream>
#include <string>
#include <string_view>
static_assert(__cpp_lib_string_resize_and_overwrite);

constexpr std::string_view fruits[]{"apple", "banana", "coconut", "date", "elderberry"};

int main()
{
    // Un cas simple : on ajoute uniquement fruits[0]. La taille de la chaîne sera augmentée.
    std::string s{"Food: "};
    s.resize_and_overwrite(16, [sz = s.size()](char* buf, std::size_t buf_size) noexcept
    {
        const auto to_copy = std::min(buf_size - sz, fruits[0].size());
        std::memcpy(buf + sz, fruits[0].data(), to_copy);
        return sz + to_copy;
    });
    std::cout << "1. " << std::quoted(s) << '\n';

    // Le cas de réduction de taille. Notez que la lambda de l'utilisateur est toujours invoquée.
    s.resize_and_overwrite(10, [](char* buf, int n) noexcept
    {
        return std::find(buf, buf + n, ':') - buf;
    });
    std::cout << "2. " << std::quoted(s) << '\n';

    std::cout << "3. Copy data until the buffer is full. Print data and sizes.\n";
    std::string food{"Food:"};
    const auto resize_to{27};
    std::cout << "Initially, food.size: " << food.size()
              << ", food.capacity: " << food.capacity()
              << ", resize_to: " << resize_to
              << ", food: " << std::quoted(food) << '\n';

    food.resize_and_overwrite
    (
        resize_to,
        [food_size = food.size()](char* p, std::size_t n) noexcept -> std::size_t
        {
            // p[0]..p[n] est l'intervalle assignable
            // p[0]..p[min(n, food_size) - 1] est l'intervalle lisible
            // (contenu initialement égal à la chaîne d'origine)

            // Affichage de débogage :
            std::cout << "In Operation(); n: " << n << '\n';

            // Copie fruits dans le tampon p tant qu'il reste assez d'espace.
            char* first = p + food_size;

            for (char* const end = p + n; const std::string_view fruit : fruits)
            {
                char* last = first + fruit.size() + 1;
                if (last > end)
                    break;
                *first++ = ' ';
                std::ranges::copy(fruit, first);
                first = last;
            }

            const auto final_size{static_cast<std::size_t>(first - p)};

            // Affichage de débogage :
            std::cout << "In Operation(); final_size: " << final_size << '\n';

            assert(final_size <= n);
            return final_size; // La valeur de retour est la nouvelle longueur effective
                               // de la chaîne, doit être dans l'intervalle 0..n
        }
    );

    std::cout << "Finally, food.size: " << food.size()
              << ", food.capacity: " << food.capacity()
              << ", food: " << std::quoted(food) << '\n';
}
