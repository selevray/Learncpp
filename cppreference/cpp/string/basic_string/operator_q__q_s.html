std::literals::string_literals::operator""s

std::string operator""s( const char* str, std::size_t len );  // (1) (depuis C++14) (constexpr depuis C++20)

constexpr std::u8string operator""s( const char8_t* str,
                                     std::size_t len );  // (2) (depuis C++20)

std::u16string operator""s( const char16_t* str, std::size_t len );  // (3) (depuis C++14) (constexpr depuis C++20)

std::u32string operator""s( const char32_t* str, std::size_t len );  // (4) (depuis C++14) (constexpr depuis C++20)

std::wstring operator""s( const wchar_t* str, std::size_t len );  // (5) (depuis C++14) (constexpr depuis C++20)

Forme un littéral de chaîne du type souhaité.

  1. Renvoie std::string{str, len}.

  2. Renvoie std::u8string{str, len}.

  3. Renvoie std::u16string{str, len}.

  4. Renvoie std::u32string{str, len}.

  5. Renvoie std::wstring{str, len}.

Paramètres

  • str — pointeur vers le début du tableau de caractères brut du littéral
  • len — longueur du tableau de caractères brut du littéral

Valeur de retour

Le littéral de chaîne.

Notes

Ces opérateurs sont déclarés dans l'espace de noms std::literals::string_literals, où literals et string_literals sont des espaces de noms en ligne. L'accès à ces opérateurs peut être obtenu avec l'une des directives suivantes using :

  • using namespace std::literals
  • using namespace std::string_literals
  • using namespace std::literals::string_literals

std::chrono::duration définit aussi operator""s pour représenter des secondes littérales, mais c'est un littéral arithmétique : 10.0s et 10s valent dix secondes, mais "10"s est une chaîne.

Exemple

#include <iostream>
#include <string>

void print_with_zeros(const auto note, const std::string& s)
{
    std::cout << note;
    for (const char c : s)
        c ? std::cout << c : std::cout << "₀";
    std::cout << " (size = " << s.size() << ")\n";
}

int main()
{
    using namespace std::string_literals;

    std::string s1 = "abc\0\0def";
    std::string s2 = "abc\0\0def"s;
    print_with_zeros("s1: ", s1);
    print_with_zeros("s2: ", s2);

    std::cout << "abcdef"s.substr(1,4) << '\n';
}

Output:

s1: abc (size = 3)
s2: abc₀₀def (size = 8)
bcde
