std::basic_string<CharT,Traits,Allocator>::push_back

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void push_back( CharT ch );  // (constexpr depuis C++20)

Ajoute le caractère ch à la fin de la chaîne.

Paramètres

  • ch — le caractère à ajouter

Valeur de retour

(aucune)

Complexité

Constant amorti.

Exceptions

Si l'opération devait faire dépasser size() à max_size(), lève std::length_error.

Si une exception est levée pour quelque raison que ce soit, cette fonction n'a aucun effet (garantie forte de sécurité d'exception).

Exemple

#include <iomanip>
#include <iostream>
#include <string>

int main()
{
    std::string str{"Short string"};
    std::cout << "1) " << std::quoted(str) << ", size: " << str.size() << '\n';

    str.push_back('!');
    std::cout << "2) " << std::quoted(str) << ", size: " << str.size() << '\n';
}

Output:

1) "Short string", size: 12
2) "Short string!", size: 13
