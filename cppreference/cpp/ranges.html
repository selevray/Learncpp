Bibliothèque des plages (depuis C++20)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

La bibliothèque des plages est une extension et une généralisation des bibliothèques d'algorithmes et d'itérateurs, qui les rend plus puissantes en les rendant composables et moins sujettes aux erreurs.

La bibliothèque crée et manipule des vues d'intervalles, des objets légers qui représentent indirectement des séquences parcourables (intervalles). Les intervalles sont une abstraction au-dessus de

  • [begin,end) – paires d'itérateurs, par exemple des intervalles créés par conversion implicite à partir de conteneurs. Tous les algorithmes qui prennent des paires d'itérateurs disposent désormais de surcharges acceptant des intervalles (par exemple ranges::sort)
  • begin+[0,size) – séquences comptées, par exemple l'intervalle renvoyé par views::counted
  • [begin,prédicat) – séquences à terminaison conditionnelle, par exemple l'intervalle renvoyé par views::take_while
  • [begin,..) – séquences non bornées, par exemple l'intervalle renvoyé par views::iota

La bibliothèque des plages comprend des algorithmes d'intervalles, appliqués aux intervalles de manière immédiate, et des adaptateurs d'intervalles, appliqués aux vues de manière paresseuse. Les adaptateurs peuvent être composés en pipelines, de sorte que leurs actions ont lieu au fur et à mesure du parcours de la vue.

Cache non propagé

Certains adaptateurs d'intervalles sont spécifiés en termes d'un modèle de classe exposition-only non-propagating-cache, qui se comporte presque comme std::optional<T> (voir la description pour les différences).

Type const conditionnel

template< bool Const, class T >
using /*maybe-const*/ = std::conditional_t<Const, const T, T>;  // ( exposition uniquement* )

L'alias de modèle /*maybe-const*/ est un raccourci utilisé pour appliquer conditionnellement un qualificateur const au type T.

Modèles auxiliaires de types semblables à des entiers

template< /*is-integer-like*/ T >
using /*make-signed-like-t*/<T> = /* voir la description */;  // (1) ( exposition uniquement* )

template< /*is-integer-like*/ T >
using /*make-unsigned-like-t*/<T> = /* voir la description */;  // (2) ( exposition uniquement* )

template< /*is-integer-like*/ T >
/*make-unsigned-like-t*/<T> /*to-unsigned-like*/( T t )
{
    return static_cast</*make-unsigned-like-t*/<T>>(t);
}  // (3) ( exposition uniquement* )
  1. Pour un type semblable à un entier T :
  • Si T est un type entier, /*make-signed-like-t*/<T> est std::make_signed_t<T>.
  • Sinon, /*make-signed-like-t*/<T> est un type correspondant non spécifié semblable à un entier signé de même largeur que T.
  1. Pour un type semblable à un entier T :
  • Si T est un type entier, /*make-unsigned-like-t*/<T> est std::make_unsigned_t<T>.
  • Sinon, /*make-signed-like-t*/<T> est un type correspondant non spécifié semblable à un entier non signé de même largeur que T.
  1. Convertit explicitement t en /*make-unsigned-like-t*/<T>.

Aides des objets de point de personnalisation

template< ranges::input_range R >
constexpr auto& /*possibly-const-range*/(R& r) noexcept
{
    if constexpr (ranges::input_range<const R>)
        return const_cast<const R&>(r);
    else
        return r;
}  // (1) ( exposition uniquement* )

template< class T >
constexpr auto /*as-const-pointer*/( const T* p ) noexcept
{
    return p;
}  // (2) ( exposition uniquement* )

Certains objets de point de personnalisation d'accès aux intervalles sont spécifiés en termes de ces modèles de fonctions réservés à l'exposition.

  1. /*possibly-const-range*/ retourne la version qualifiée const de r si const R modélise input_range ; sinon, retourne r sans aucune conversion.

  2. /*as-const-pointer*/ retourne un pointeur vers un objet de type constant.

Aides des adaptateurs d'intervalles

template< class F, class Tuple >
constexpr auto /*tuple-transform*/( F&& f, Tuple&& tuple )
{
    return std::apply([&]<class... Ts>(Ts&&... args)
    {
        return std::tuple<std::invoke_result_t<F&, Ts>...>
            (std::invoke(f, std::forward<Ts>(args))...);
    }, std::forward<Tuple>(tuple));
}  // (1) ( exposition uniquement* )

template< class F, class Tuple >
constexpr void /*tuple-for-each*/( F&& f, Tuple&& tuple )
{
    std::apply([&]<class... Ts>(Ts&&... args)
    {
        (static_cast<void>(std::invoke(f, std::forward<Ts>(args))), ...);
    }, std::forward<Tuple>(tuple));
}  // (2) ( exposition uniquement* )

template< class T >
constexpr T& /*as-lvalue*/( T&& t )
{
    return static_cast<T&>(t);
}  // (3) ( exposition uniquement* )

Certains adaptateurs d'intervalles sont spécifiés en termes de ces modèles de fonctions réservés à l'exposition.

  1. /*tuple-transform*/ retourne un nouveau tuple construit en appliquant f à chaque élément de tuple.

  2. /*tuple-for-each*/ applique f à chaque élément de tuple et ne retourne rien.

  3. /*as-lvalue*/ transmet la rvalue t comme lvalue.

Exemple

#include <iostream>
#include <ranges>

int main()
{
    auto const ints = {0, 1, 2, 3, 4, 5};
    auto even = [](int i) { return 0 == i % 2; };
    auto square = [](int i) { return i * i; };

    // la syntaxe « pipe » de composition des vues :
    for (int i : ints | std::views::filter(even) | std::views::transform(square))
        std::cout << i << ' ';

    std::cout << '\n';

    // une syntaxe de composition traditionnelle de type « fonctionnel » :
    for (int i : std::views::transform(std::views::filter(ints, even), square))
        std::cout << i << ' ';
}

Output:

0 4 16
0 4 16
