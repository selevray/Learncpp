constexpr explicit latch( std::ptrdiff_t expected );  // (1) (depuis C++20)

latch( const latch& ) = delete;  // (2) (depuis C++20)

  1. Construit un latch et initialise son compteur interne. Le comportement est indéfini si expected est négatif ou supérieur à max().

  2. Le constructeur de copie est supprimé. latch n'est ni copiable ni déplaçable.

Paramètres

  • expected — la valeur initiale du compteur interne

Exceptions

Ne lève aucune exception.
