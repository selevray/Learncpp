std::latch::try_wait

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool try_wait() const noexcept;  // (depuis C++20)

Renvoie true uniquement si le compteur interne a atteint zéro. Cette fonction peut renvoyer false de manière parasite avec une probabilité très faible, même si le compteur interne a atteint zéro.

Paramètres

(aucune)

Valeur de retour

Avec une probabilité très faible false, sinon cnt == 0, où cnt est la valeur du compteur interne.

Notes

La raison pour laquelle un résultat parasite est autorisé est de permettre aux implémentations d'utiliser un ordre mémoire plus relâché que std::memory_order_seq_cst.
