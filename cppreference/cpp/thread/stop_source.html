std::stop_source

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stop_token>

class stop_source;  // (depuis C++20)

La classe stop_source fournit le moyen d'émettre une demande d'arrêt, par exemple pour l'annulation de std::jthread. Une demande d'arrêt faite pour un objet stop_source est visible par tous les stop_sources et std::stop_tokens ayant le même état d'arrêt associé ; tout std::stop_callback(s) enregistré pour le ou les std::stop_token(s) associé(s) sera invoqué, et tout objet std::condition_variable_any en attente sur le ou les std::stop_token(s) associé(s) sera réveillé.

Une fois un arrêt demandé, il ne peut plus être retiré. Les demandes d'arrêt supplémentaires n'ont aucun effet.

  • (constructeur) — construit un nouvel objet stop_source (fonction membre publique)
  • (destructeur) — détruit l'objet stop_source (fonction membre publique)
  • operator= — affecte l'objet stop_source (fonction membre publique)

##### Modificateurs {#Modifiers}

  • request_stop — demande un arrêt pour l'état d'arrêt associé, le cas échéant (fonction membre publique)
  • swap — échange deux objets stop_source (fonction membre publique)

##### Observateurs {#Observers}

  • get_token — renvoie un stop_token pour l'état d'arrêt associé (fonction membre publique)
  • stop_requested — vérifie si l'état d'arrêt associé a reçu une demande d'arrêt (fonction membre publique)
  • stop_possible — vérifie si une demande d'arrêt peut être faite pour l'état d'arrêt associé (fonction membre publique)

Notes

Pour l'annulation std::jthread, l'objet stop_source doit être obtenu à partir de l'objet std::jthread au moyen de get_stop_source() ; ou l'arrêt doit être demandé directement à partir de l'objet std::jthread au moyen de request_stop(). Cela utilisera alors le même état d'arrêt associé que celui transmis à l'argument de fonction invoquée de std::jthread (c.-à-d. la fonction exécutée sur son thread).

Dans les autres cas, cependant, un stop_source peut être construit séparément à l'aide du constructeur par défaut, qui crée un nouvel état d'arrêt.

Exemple

#include <chrono>
#include <iostream>
#include <stop_token>
#include <thread>

using namespace std::chrono_literals;

void worker_fun(int id, std::stop_token stoken)
{
    for (int i = 10; i; --i)
    {
        std::this_thread::sleep_for(300ms);
        if (stoken.stop_requested())
        {
            std::printf("  worker%d is requested to stop\n", id);
            return;
        }
        std::printf("  worker%d goes back to sleep\n", id);
    }
}

int main()
{
    std::jthread threads[4];
    std::cout << std::boolalpha;
    auto print = [](const std::stop_source& source)
    {
        std::printf("stop_source stop_possible = %s, stop_requested = %s\n",
                    source.stop_possible() ? "true" : "false",
                    source.stop_requested() ? "true" : "false");
    };

    // Source commune
    std::stop_source stop_source;

    print(stop_source);

    // Créer des threads de travail
    for (int i = 0; i < 4; ++i)
        threads[i] = std::jthread(worker_fun, i + 1, stop_source.get_token());

    std::this_thread::sleep_for(500ms);

    std::puts("Request stop");
    stop_source.request_stop();

    print(stop_source);

    // Remarque : le destructeur de jthread appelle join, il n'est donc pas nécessaire d'appels explicites
}
