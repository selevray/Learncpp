std::future

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <future>

template< class T > class future;  // (1) (depuis C++11)

template< class T > class future<T&>;  // (2) (depuis C++11)

template<> class future<void>;  // (3) (depuis C++11)

Le modèle de classe std::future fournit un mécanisme pour accéder au résultat d'opérations asynchrones :

  • Une opération asynchrone (créée via std::async, std::packaged_task ou std::promise) peut fournir un objet std::future au créateur de cette opération asynchrone.

  • Le créateur de l'opération asynchrone peut alors utiliser diverses méthodes pour interroger, attendre ou extraire une valeur de std::future. Ces méthodes peuvent bloquer si l'opération asynchrone n'a pas encore fourni de valeur.

  • Lorsque l'opération asynchrone est prête à envoyer un résultat au créateur, elle peut le faire en modifiant l'état partagé (par exemple std::promise::set_value) lié à std::future du créateur.

Notez que std::future référence un état partagé qui n'est partagé avec aucun autre objet de retour asynchrone (contrairement à std::shared_future).

Fonctions membres

  • (constructeur) — construit l'objet futur (fonction membre publique)
  • (destructeur) — détruit l'objet futur (fonction membre publique)
  • operator= — déplace l'objet future (fonction membre publique)
  • share — transfère l'état partagé de *this vers un shared_future et le retourne (fonction membre publique)

##### Obtention du résultat {#Getting_the_result}

  • get — retourne le résultat (fonction membre publique)

##### État {#State}

  • valid — vérifie si le futur possède un état partagé (fonction membre publique)
  • wait — attend que le résultat devienne disponible (fonction membre publique)
  • wait_for — attend le résultat, retourne s'il n'est pas disponible pendant la durée de temporisation spécifiée (fonction membre publique)
  • wait_until — attend le résultat, retourne s'il n'est pas disponible avant que le point temporel spécifié soit atteint (fonction membre publique)

Exemples

#include <future>
#include <iostream>
#include <thread>

int main()
{
    // futur issu d'un packaged_task
    std::packaged_task<int()> task([]{ return 7; }); // encapsule la fonction
    std::future<int> f1 = task.get_future(); // obtient un futur
    std::thread t(std::move(task)); // lance sur un thread

    // futur issu d'un async()
    std::future<int> f2 = std::async(std::launch::async, []{ return 8; });

    // futur issu d'une promise
    std::promise<int> p;
    std::future<int> f3 = p.get_future();
    std::thread([&p]{ p.set_value_at_thread_exit(9); }).detach();

    std::cout << "Waiting..." << std::flush;
    f1.wait();
    f2.wait();
    f3.wait();
    std::cout << "Done!\nResults are: "
              << f1.get() << ' ' << f2.get() << ' ' << f3.get() << '\n';
    t.join();
}

Output:

Waiting...Done!
Results are: 7 8 9

Exemple avec exceptions

#include <future>
#include <iostream>
#include <thread>

int main()
{
    std::promise<int> p;
    std::future<int> f = p.get_future();

    std::thread t([&p]
    {
        try
        {
            // code susceptible de lever une exception
            throw std::runtime_error("Example");
        }
        catch (...)
        {
            try
            {
                // stocke toute exception levée dans la promise
                p.set_exception(std::current_exception());
            }
            catch (...) {} // set_exception() peut aussi lever une exception
        }
    });

    try
    {
        std::cout << f.get();
    }
    catch (const std::exception& e)
    {
        std::cout << "Exception from the thread: " << e.what() << '\n';
    }
    t.join();
}

Output:

Exception from the thread: Example
