Notes

Il n'est sûr d'invoquer le destructeur que si tous les threads ont été notifiés. Il n'est pas requis qu'ils aient quitté leurs fonctions d'attente respectives : certains threads peuvent encore attendre de réacquérir le verrou associé, ou attendre d'être ordonnancés après l'avoir réacquis.

Le programmeur doit s'assurer qu'aucun thread ne tente d'attendre sur *this une fois le destructeur commencé, en particulier lorsque les threads en attente appellent les fonctions d'attente dans une boucle ou utilisent les surcharges des fonctions d'attente qui prennent un prédicat.
