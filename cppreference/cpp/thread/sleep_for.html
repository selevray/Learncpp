std::this_thread::sleep_for

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <thread>

template< class Rep, class Period >
void sleep_for( const std::chrono::duration<Rep, Period>& sleep_duration );  // (depuis C++11)

Bloque l'exécution du thread courant pendant au moins la durée sleep_duration spécifiée.

Cette fonction peut bloquer pendant une durée supérieure à sleep_duration en raison de retards d'ordonnancement ou de contention de ressources.

La norme recommande d'utiliser une horloge stable (steady clock) pour mesurer la durée. Si une implémentation utilise à la place une horloge système, le temps d'attente peut également être sensible aux ajustements de l'horloge.

Paramètres

  • sleep_duration — durée de mise en sommeil

Valeur de retour

(aucune)

Exceptions

Toute exception levée par clock, time_point ou duration pendant l'exécution (les horloges, points temporels et durées fournis par la bibliothèque standard ne lèvent jamais d'exception).

Exemple

#include <chrono>
#include <iostream>
#include <thread>

int main()
{
    using namespace std::chrono_literals;

    std::cout << "Hello waiter\n" << std::flush;

    const auto start = std::chrono::high_resolution_clock::now();
    std::this_thread::sleep_for(2000ms);
    const auto end = std::chrono::high_resolution_clock::now();
    const std::chrono::duration<double, std::milli> elapsed = end - start;

    std::cout << "Waited " << elapsed << '\n';
}

Sortie possible :

Hello waiter
Waited 2000.13 ms
