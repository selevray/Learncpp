std::cv_status

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <condition_variable>

enum class cv_status {
    no_timeout,
    timeout
};  // (depuis C++11)

L'énumération à portée std::cv_status indique si une attente temporisée s'est terminée à cause d'un délai d'attente ou non.

std::cv_status est utilisé par les fonctions membres wait_for et wait_until de std::condition_variable et std::condition_variable_any.

Constantes membres

Nom Explication

  • no_timeout — la variable de condition a été réveillée avec notify_all, notify_one, ou de façon fallacieuse
  • timeout — la variable de condition a été réveillée par l'expiration du délai d'attente
