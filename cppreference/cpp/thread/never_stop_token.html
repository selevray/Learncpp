Défini dans l'en-tête <stop_token>

class never_stop_token;  // (depuis C++26)

La classe never_stop_token modélise unstoppable_token qui fournit des informations statiques indiquant qu'un arrêt n'est jamais possible ni demandé. C'est le type de jeton d'arrêt par défaut retourné par std::get_stop_token si aucun autre jeton d'arrêt associé n'est fourni dans l'objet interrogeable.
