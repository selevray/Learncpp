class shared_mutex;  // (depuis C++17)

La classe shared_mutex est une primitive de synchronisation pouvant être utilisée pour protéger des données partagées contre un accès simultané par plusieurs threads. Contrairement aux autres types de mutex, qui permettent un accès exclusif, un shared_mutex a deux niveaux d'accès :

  • partagé - plusieurs threads peuvent partager la propriété du même mutex.

  • exclusif - un seul thread peut posséder le mutex.

Si un thread a acquis le verrou exclusif (via lock, try_lock), aucun autre thread ne peut acquérir le verrou (y compris le verrou partagé).

Si un thread a acquis le verrou partagé (via lock_shared, try_lock_shared), aucun autre thread ne peut acquérir le verrou exclusif, mais peut acquérir le verrou partagé.

Ce n'est que lorsque le verrou exclusif n'a été acquis par aucun thread que le verrou partagé peut être acquis par plusieurs threads.

Au sein d'un même thread, un seul verrou (partagé ou exclusif) peut être acquis à la fois.

Les mutex partagés sont particulièrement utiles lorsque des données partagées peuvent être lues en toute sécurité par un nombre quelconque de threads simultanément, mais qu'un thread ne peut écrire ces mêmes données que lorsqu'aucun autre thread ne lit ou n'écrit en même temps.

La classe shared_mutex satisfait à toutes les exigences de SharedMutex et de StandardLayoutType.

Fonctions membres

  • (constructeur) — construit le mutex (fonction membre publique)
  • (destructeur) — détruit le mutex (fonction membre publique)
  • operator=[deleted] — non copiable par affectation (fonction membre publique)

##### Verrouillage exclusif {#Exclusive_locking}

  • lock — verrouille le mutex, bloque si le mutex n'est pas disponible (fonction membre publique)
  • try_lock — tente de verrouiller le mutex, retourne si le mutex n'est pas disponible (fonction membre publique)
  • unlock — déverrouille le mutex (fonction membre publique)

##### Verrouillage partagé {#Shared_locking}

  • lock_shared — verrouille le mutex en propriété partagée, bloque si le mutex n'est pas disponible (fonction membre publique)
  • try_lock_shared — tente de verrouiller le mutex en propriété partagée, renvoie si le mutex n'est pas disponible (fonction membre publique)
  • unlock_shared — déverrouille le mutex (propriété partagée) (fonction membre publique)

##### Descripteur natif {#Native_handle}

  • native_handle — retourne l'objet de descripteur natif sous-jacent défini par l'implémentation (fonction membre publique)

Exemple

La sortie ci-dessous a été générée sur une machine monocœur. Lorsque thread1 démarre, il entre pour la première fois dans la boucle et appelle increment() suivi de get(). Cependant, avant de pouvoir afficher la valeur renvoyée dans std::cout, l'ordonnanceur met thread1 en sommeil et réveille thread2, qui a évidemment largement le temps d'exécuter les trois itérations de la boucle d'un coup. De retour dans thread1, toujours à la première itération, il affiche enfin sa copie locale de la valeur du compteur, qui vaut 1, dans std::cout, puis exécute les deux itérations restantes. Sur une machine multicœur, aucun thread n'est mis en sommeil et la sortie a plus de chances d'être dans l'ordre croissant.

#include <iostream>
#include <mutex>
#include <shared_mutex>
#include <syncstream>
#include <thread>

class ThreadSafeCounter
{
public:
    ThreadSafeCounter() = default;

    // Plusieurs threads/lecteurs peuvent lire la valeur du compteur en même temps.
    unsigned int get() const
    {
        std::shared_lock lock(mutex_);
        return value_;
    }

    // Un seul thread/écrivain peut incrémenter/écrire la valeur du compteur.
    void increment()
    {
        std::unique_lock lock(mutex_);
        ++value_;
    }

    // Un seul thread/écrivain peut réinitialiser/écrire la valeur du compteur.
    void reset()
    {
        std::unique_lock lock(mutex_);
        value_ = 0;
    }

private:
    mutable std::shared_mutex mutex_;
    unsigned int value_{};
};

int main()
{
    ThreadSafeCounter counter;

    auto increment_and_print = [&counter]()
    {
        for (int i{}; i != 3; ++i)
        {
            counter.increment();
            std::osyncstream(std::cout)
                << std::this_thread::get_id() << ' ' << counter.get() << '\n';
        }
    };

    std::thread thread1(increment_and_print);
    std::thread thread2(increment_and_print);

    thread1.join();
    thread2.join();
}
