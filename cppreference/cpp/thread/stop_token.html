std::stop_token

Défini dans l'en-tête <stop_token>

class stop_token;  // (depuis C++20)

La classe stop_token fournit le moyen de vérifier si une demande d'arrêt a été faite ou peut l'être, pour son objet std::stop_source associé. C'est essentiellement une « vue » sûre pour les threads de l'état d'arrêt associé.

Le stop_token peut aussi être passé au constructeur de std::stop_callback, de sorte que le rappel soit invoqué si l'arrêt est demandé pour le std::stop_source associé de stop_token. Et stop_token peut être passé aux fonctions d'attente interruptible de std::condition_variable_any, pour interrompre l'attente de la variable de condition si un arrêt est demandé.

Notes

Un objet stop_token n'est généralement pas construit indépendamment, mais plutôt obtenu à partir d'un std::jthread ou d'un std::stop_source. Il partage ainsi le même état d'arrêt associé que le std::jthread ou le std::stop_source.

Exemple

#include <iostream>
#include <thread>

using namespace std::literals::chrono_literals;

void f(std::stop_token stop_token, int value)
{
    while (!stop_token.stop_requested())
    {
        std::cout << value++ << ' ' << std::flush;
        std::this_thread::sleep_for(200ms);
    }
    std::cout << std::endl;
}

int main()
{
    std::jthread thread(f, 5); // affiche 5 6 7 8... pendant environ 3 secondes
    std::this_thread::sleep_for(3s);
    // Le destructeur de jthread appelle request_stop() et join().
}
