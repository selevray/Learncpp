std::condition_variable

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <condition_variable>

class condition_variable;  // (depuis C++11)

std::condition_variable est une primitive de synchronisation utilisée avec un std::mutex pour bloquer un ou plusieurs threads jusqu'à ce qu'un autre thread modifie à la fois une variable partagée (la condition) et notifie le std::condition_variable.

Le thread qui souhaite modifier la variable partagée doit :

  1. Acquérir un std::mutex (généralement via std::lock_guard).
  2. Modifier la variable partagée pendant que le verrou est détenu.
  3. Appeler notify_one ou notify_all sur le std::condition_variable (peut être fait après avoir libéré le verrou).

Même si la variable partagée est atomique, elle doit être modifiée en possédant le mutex pour publier correctement la modification auprès du thread en attente.

Tout thread qui souhaite attendre sur un std::condition_variable doit :

  1. Acquérir un std::unique_lock<std::mutex> sur le mutex utilisé pour protéger la variable partagée.
  2. Effectuer l'une des opérations suivantes :
    1. Vérifier la condition, au cas où elle aurait déjà été mise à jour et notifiée.
    2. Appeler wait, wait_for ou wait_until sur le std::condition_variable (libère atomiquement le mutex et suspend l'exécution du thread jusqu'à ce que la variable de condition soit notifiée, qu'un délai d'attente expire ou qu'un réveil parasite se produise, puis réacquiert atomiquement le mutex avant de retourner).
    3. Vérifier la condition et reprendre l'attente si elle n'est pas satisfaite. or:
    4. Utiliser la surcharge avec prédicat de wait, wait_for et wait_until, qui effectue les mêmes trois étapes.

std::condition_variable ne fonctionne qu'avec std::unique_lock<std::mutex>, ce qui permet une efficacité maximale sur certaines plateformes. std::condition_variable_any fournit une variable de condition qui fonctionne avec tout objet BasicLockable, tel que std::shared_lock.

Les variables de condition permettent l'invocation concurrente des fonctions membres wait, wait_for, wait_until, notify_one et notify_all.

La classe std::condition_variable est une StandardLayoutType. Elle n'est pas CopyConstructible, MoveConstructible, CopyAssignable, ni MoveAssignable.

Exemple

std::condition_variable est utilisée conjointement avec un std::mutex pour faciliter la communication entre threads.

#include <condition_variable>
#include <iostream>
#include <mutex>
#include <string>
#include <thread>

std::mutex m;
std::condition_variable cv;
std::string data;
bool ready = false;
bool processed = false;

void worker_thread()
{
    // attend que main() envoie des données
    std::unique_lock lk(m);
    cv.wait(lk, []{ return ready; });

    // après l'attente, nous possédons le verrou
    std::cout << "Worker thread is processing data\n";
    data += " after processing";

    // renvoie des données à main()
    processed = true;
    std::cout << "Worker thread signals data processing completed\n";

    // le déverrouillage manuel est effectué avant la notification, pour éviter de réveiller
    // le thread en attente, qui se bloquerait à nouveau (voir notify_one pour plus de détails)
    lk.unlock();
    cv.notify_one();
}

int main()
{
    std::thread worker(worker_thread);

    data = "Example data";
    // envoie des données au thread de travail
    {
        std::lock_guard lk(m);
        ready = true;
        std::cout << "main() signals data ready for processing\n";
    }
    cv.notify_one();

    // attend le thread de travail
    {
        std::unique_lock lk(m);
        cv.wait(lk, []{ return processed; });
    }
    std::cout << "Back in main(), data = " << data << '\n';

    worker.join();
}

Output:

main() signals data ready for processing
Worker thread is processing data
Worker thread signals data processing completed
Back in main(), data = Example data after processing
