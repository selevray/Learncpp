std::packaged_task<R(Args...)>::reset

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void reset();  // (depuis C++11)

Réinitialise l'état en abandonnant les résultats des exécutions précédentes. Un nouvel état partagé est construit.

Équivalent à *this = packaged_task(std::move(f)), où f est la tâche stockée.

Paramètres

(aucune)

Valeur de retour

(aucune)

Exceptions

  • std::future_error si *this n'a pas d'état partagé. La condition d'erreur est définie à no_state.
  • std::bad_alloc s'il n'y a pas assez de mémoire pour un nouvel état partagé.
  • Toute exception levée par le constructeur de déplacement du nouveau packaged_task.

Exemple

#include <cmath>
#include <future>
#include <iostream>
#include <thread>

int main()
{
    std::packaged_task<int(int,int)> task([](int a, int b)
    {
        return std::pow(a, b);
    });
    std::future<int> result = task.get_future();
    task(2, 9);
    std::cout << "2^9 = " << result.get() << '\n';

    task.reset();
    result = task.get_future();
    std::thread task_td(std::move(task), 2, 10);
    task_td.join();
    std::cout << "2^10 = " << result.get() << '\n';
}

Output:

2^9 = 512
2^10 = 1024
