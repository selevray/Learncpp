std::packaged_task<R(Args...)>::packaged_task

Construit un nouvel objet std::packaged_task.

  1. Construit un objet std::packaged_task sans tâche et sans état partagé.

2,3) Construit un objet std::packaged_task avec un état partagé et une copie de la tâche, initialisé avec std::forward<F>(f).L'allocateur a est utilisé pour allouer la mémoire nécessaire au stockage de la tâche. (jusqu'à C++17)

Ces surcharges ne participent à la résolution de surcharge que si std::decay<F>::type n'est pas du même type que std::packaged_task<R(Args...)>.

Soient t1, t2, ..., tN des valeurs des types correspondants dans Args ; si INVOKE<R>(f, t1, t2, ..., tN) n'est pas une expression valide, le programme est mal formé.

(jusqu'à C++17)

Si std::is_invocable_r_v<R, F&, Args...> est false, le programme est mal formé.

(depuis C++17)

Si l'invocation de f elle-même et l'invocation d'une copie de f se comportent différemment, le comportement est indéfini.

  1. Le constructeur de copie est supprimé, std::packaged_task n'est que déplaçable.

  2. Construit un std::packaged_task avec l'état partagé et la tâche précédemment détenus par rhs, laissant rhs sans état partagé et avec une tâche déplacée.

Paramètres

  • f — la cible appelable (fonction, fonction membre, expression lambda, objet fonction) à exécuter
  • a — l'allocateur à utiliser pour stocker la tâche
  • rhs — le std::packaged_task à partir duquel déplacer

Exceptions

  1. Toute exception levée par le constructeur de copie/déplacement de f et éventuellement std::bad_alloc si l'allocation échoue.

  2. Toute exception levée par le constructeur de copie/déplacement de f et par la fonction allocate de l'allocateur si l'allocation de mémoire échoue.

Exemple

#include <future>
#include <iostream>
#include <thread>

int fib(int n)
{
    if (n < 3)
        return 1;
    else
        return fib(n - 1) + fib(n - 2);
}

int main()
{
    std::packaged_task<int(int)> fib_task(&fib);

    std::cout << "Starting task\n";
    auto result = fib_task.get_future();
    std::thread t(std::move(fib_task), 42);

    std::cout << "Waiting for task to finish..." << std::endl;
    std::cout << result.get() << '\n';

    std::cout << "Task complete\n";
    t.join();
}

Output:

Starting task
Waiting for task to finish...
267914296
Task complete
