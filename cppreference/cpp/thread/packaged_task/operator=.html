packaged_task& operator=( const packaged_task& ) = delete;  // (1) (depuis C++11)

packaged_task& operator=( packaged_task&& rhs ) noexcept;  // (2) (depuis C++11)

  1. L'opérateur d'affectation par copie est supprimé, std::packaged_task est uniquement déplaçable.

  2. Libère l'état partagé, s'il existe, détruit la tâche précédemment détenue, et déplace l'état partagé et la tâche appartenant à rhs dans *this. rhs est laissé sans état partagé et avec une tâche déplacée.

Paramètres
