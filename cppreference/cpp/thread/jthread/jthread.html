std::jthread::jthread

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

jthread() noexcept;  // (1) (depuis C++20)

jthread( jthread&& other ) noexcept;  // (2) (depuis C++20)

template< class F, class... Args >
explicit jthread( F&& f, Args&&... args );  // (3) (depuis C++20)

jthread( const jthread& ) = delete;  // (4) (depuis C++20)

Construit un nouvel objet std::jthread.

  1. Crée un nouvel objet std::jthread qui ne représente aucun thread.

  2. Constructeur de déplacement. Construit l'objet std::jthread pour représenter le fil d'exécution représenté auparavant par other. Après cet appel, other ne représente plus de fil d'exécution.

  3. Crée un nouvel objet std::jthread et l'associe à un fil d'exécution.

Le nouveau fil d'exécution commence à exécuter :

std::invoke(decay-copy(std::forward<F>(f)), get_stop_token(), decay-copy(std::forward<Args>(args))...)

(jusqu'à C++23)

std::invoke(auto(std::forward<F>(f)), get_stop_token(), auto(std::forward<Args>(args))...)

(depuis C++23)

si l'expression ci-dessus est bien formée, sinon commence à exécuter :

std::invoke(decay-copy(std::forward<F>(f)), decay-copy(std::forward<Args>(args))...).

(jusqu'à C++23)

std::invoke(auto(std::forward<F>(f)), auto(std::forward<Args>(args))...).

(depuis C++23)

[Les appels de decay-copy sont évalués (jusqu'à C++23) | Les valeurs produites par auto sont matérialisées (depuis C++23)] dans le fil courant, de sorte que toute exception levée pendant l'évaluation et la copie/déplacement des arguments le soit dans le fil courant, sans démarrer le nouveau fil.

Ces surcharges ne participent à la résolution de surcharge que si std::remove_cvref_t<F> n'est pas du même type que std::jthread.

Si l'un des éléments suivants est false, le programme est mal formé :

  • std::is_constructible_v<std::decay_t<F>, F>
  • (std::is_constructible_v<std::decay_t<Args>, Args> && ...)
  • std::is_invocable_v<std::decay_t<F>, std::decay_t<Args>...> ||std::is_invocable_v<std::decay_t<F>, std::stop_token, std::decay_t<Args>...>

L'achèvement de l'invocation du constructeur se synchronise avec le début de l'invocation de la copie de f sur le nouveau fil d'exécution.

  1. Le constructeur de copie est supprimé ; les fils ne sont pas copiables. Deux objets std::jthread ne peuvent pas représenter le même fil d'exécution.

Paramètres

  • other — un autre objet std::jthread avec lequel construire cet objet std::jthread
  • f — Callable objet à exécuter dans le nouveau fil
  • args — arguments à passer à la nouvelle fonction

Postconditions

  1. get_id() égal à std::jthread::id() (c.-à-d. joinable() renvoie false) et get_stop_source().stop_possible() est false.

  2. other.get_id() égal à std::jthread::id() et get_id() renvoie la valeur de other.get_id() avant le début de la construction.

  3. get_id() différent de std::jthread::id() (c.-à-d. joinable() renvoie true), et get_stop_source().stop_possible() est true.

Exceptions

  1. std::system_error si le fil n'a pas pu être démarré. L'exception peut représenter la condition d'erreur std::errc::resource_unavailable_try_again ou une autre condition d'erreur propre à l'implémentation.

Notes

Les arguments de la fonction du fil sont déplacés ou copiés par valeur. Si un argument par référence doit être passé à la fonction du fil, il doit être enveloppé (par ex. avec std::ref ou std::cref).

La valeur de retour de la fonction est ignorée. Si la fonction lève une exception, std::terminate est appelée. Pour renvoyer des valeurs de retour ou des exceptions au fil appelant, std::promise ou std::async peuvent être utilisés.

Exemple

#include <chrono>
#include <iostream>
#include <thread>
#include <utility>

using namespace std::literals;

void f1(int n)
{
    for (int i = 0; i < 5; ++i)
    {
        std::cout << "Thread 1 executing\n";
        ++n;
        std::this_thread::sleep_for(10ms);
    }
}

void f2(int& n)
{
    for (int i = 0; i < 5; ++i)
    {
        std::cout << "Thread 2 executing\n";
        ++n;
        std::this_thread::sleep_for(10ms);
    }
}

class foo
{
public:
    void bar()
    {
        for (int i = 0; i < 5; ++i)
        {
            std::cout << "Thread 3 executing\n";
            ++n;
            std::this_thread::sleep_for(10ms);
        }
    }
    int n = 0;
};

class baz
{
public:
    void operator()()
    {
        for (int i = 0; i < 5; ++i)
        {
            std::cout << "Thread 4 executing\n";
            ++n;
            std::this_thread::sleep_for(10ms);
        }
    }
    int n = 0;
};

int main()
{
    int n = 0;
    foo f;
    baz b;
    std::jthread t0; // t0 n'est pas un fil
    std::jthread t1(f1, n + 1); // passage par valeur
    std::jthread t2a(f2, std::ref(n)); // passage par référence
    std::jthread t2b(std::move(t2a)); // t2b exécute maintenant f2(). t2a n'est plus un fil
    std::jthread t3(&foo::bar, &f); // t3 exécute foo::bar() sur l'objet f
    std::jthread t4(b); // t4 exécute baz::operator() sur une copie de l'objet b
    t1.join();
    t2b.join();
    t3.join();
    std::cout << "Final value of n is " << n << '\n';
    std::cout << "Final value of f.n (foo::n) is " << f.n << '\n';
    std::cout << "Final value of b.n (baz::n) is " << b.n << '\n';
    // t4 se joint à la destruction
}
