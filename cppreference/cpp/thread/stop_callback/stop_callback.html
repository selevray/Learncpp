Construit un nouvel objet stop_callback, en sauvegardant et en enregistrant la fonction de rappel cb dans l'état d'arrêt associé de std::stop_token, pour une invocation ultérieure si l'arrêt est demandé sur le std::stop_source associé.

  1. Construit un stop_callback pour le st std::stop_token donné (copié), avec la fonction de rappel invocable donnée cb.

  2. Construit un stop_callback pour le st std::stop_token donné (déplacé), avec la fonction de rappel invocable donnée cb.

3,4) stop_callback n'est ni CopyConstructible ni MoveConstructible.

Les deux constructeurs ne participent à la résolution de surcharge que si Callback et C satisfont constructible_from de std::constructible_from<Callback, C>. Si Callback et C satisfont le concept mais ne satisfont pas son exigence sémantique, le comportement est indéfini.

Paramètres

  • st — un objet std::stop_token avec lequel enregistrer cet objet stop_callback
  • cb — le type à invoquer si l'arrêt est demandé

Exceptions

1,2)noexcept specification:noexcept(std::is_nothrow_constructible_v<Callback, C>)Toute exception levée par l'initialisation par constructeur du rappel donné dans l'objet stop_callback.

Notes

Si st.stop_requested() == true pour le std::stop_token transmis, alors la fonction de rappel est invoquée dans le thread courant avant que le constructeur ne retourne.
