std::this_thread::sleep_until

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <thread>

template< class Clock, class Duration >
void sleep_until( const std::chrono::time_point<Clock, Duration>& sleep_time );  // (depuis C++11)

Bloque l'exécution du thread courant jusqu'à ce que le sleep_time spécifié soit atteint.

Clock doit satisfaire aux exigences Clock.Le programme est mal formé si std::chrono::is_clock_v<Clock> est false. (depuis C++20)

La norme recommande d'utiliser l'horloge liée à sleep_time, auquel cas les ajustements de l'horloge peuvent être pris en compte. Ainsi, la durée du blocage peut être supérieure ou inférieure à sleep_time - Clock::now() au moment de l'appel, selon le sens de l'ajustement et selon qu'il est pris en charge par l'implémentation. La fonction peut aussi bloquer jusqu'après que sleep_time a été atteint, en raison de délais d'ordonnancement des processus ou de contention des ressources.

Paramètres

  • sleep_time — instant jusqu'auquel bloquer

Valeur de retour

(aucune)

Exceptions

Toute exception levée par Clock ou Duration (les horloges et durées fournies par la bibliothèque standard ne lèvent jamais d'exception).

Exemple

#include <chrono>
#include <iostream>
#include <thread>

auto now() { return std::chrono::steady_clock::now(); }

auto awake_time()
{
    using std::chrono::operator""ms;
    return now() + 2000ms;
}

int main()
{
    std::cout << "Hello, waiter...\n" << std::flush;
    const auto start{now()};
    std::this_thread::sleep_until(awake_time());
    std::chrono::duration<double, std::milli> elapsed{now() - start};
    std::cout << "Waited " << elapsed.count() << " ms\n";
}

Sortie possible :

Hello, waiter...
Waited 2000.17 ms
