std::condition_variable::native_handle

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

native_handle_type native_handle();  // (depuis C++11)

Accède au descripteur natif de *this.

La signification et le type du résultat de cette fonction sont définis par l'implémentation. Sur un système POSIX, il peut s'agir d'une valeur de type pthread_cond_t*. Sur un système Windows, il peut s'agir d'un PCONDITION_VARIABLE.

Paramètres

(aucune)

Valeur de retour

Le descripteur natif de cette variable de condition.
