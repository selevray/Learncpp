std::lock_guard<Mutex>::lock_guard

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

explicit lock_guard( mutex_type& m );  // (1) (depuis C++11)

lock_guard( mutex_type& m, std::adopt_lock_t t );  // (2) (depuis C++11)

lock_guard( const lock_guard& ) = delete;  // (3) (depuis C++11)

Acquiert la propriété du mutex m donné.

  1. Appelle effectivement m.lock().

  2. Acquiert la propriété du mutex m sans tenter de le verrouiller. Le comportement est indéfini si le thread courant ne détient pas un verrou non partagé (c'est-à-dire un verrou acquis par lock, try_lock, try_lock_for ou try_lock_until) sur m.

  3. Le constructeur de copie est supprimé.

Le comportement est indéfini si m est détruit avant l'objet lock_guard.

Paramètres

  • m — mutex dont il faut acquérir la propriété
  • t — paramètre d'étiquette utilisé pour sélectionner la version du constructeur sans verrouillage

Exceptions

  1. Relance toutes les exceptions levées par m.lock().

  2. Ne lève aucune exception.
