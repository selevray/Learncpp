std::thread::thread

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

thread() noexcept;  // (1) (depuis C++11)

thread( thread&& other ) noexcept;  // (2) (depuis C++11)

template< class F, class... Args >
explicit thread( F&& f, Args&&... args );  // (3) (depuis C++11)

thread( const thread& ) = delete;  // (4) (depuis C++11)

Construit un nouvel objet std::thread.

  1. Crée un nouvel objet std::thread qui ne représente pas de thread.

  2. Constructeur de déplacement. Construit l'objet std::thread pour représenter le fil d'exécution représenté auparavant par other. Après cet appel, other ne représente plus de fil d'exécution.

  3. Crée un nouvel objet std::thread et l'associe à un thread d'exécution. Le nouveau thread d'exécution commence à exécuter :

INVOKE(decay-copy(std::forward<F>(f)), decay-copy(std::forward<Args>(args))...)

(jusqu'à C++23)

std::invoke(auto(std::forward<F>(f)), auto(std::forward<Args>(args))...)

(depuis C++23)

[Les appels de decay-copy sont évalués (jusqu'à C++23) | Les valeurs produites par auto sont matérialisées (depuis C++23)] dans le fil courant, de sorte que toute exception levée pendant l'évaluation et la copie/déplacement des arguments le soit dans le fil courant, sans démarrer le nouveau fil.

Cette surcharge ne participe à la résolution de surcharge que si [std::decay<F>::type (jusqu'à C++20) | std::remove_cvref_t<F> (depuis C++20)] n'est pas le même type que std::thread.

Si l'une des conditions suivantes est satisfaite, le programme est mal formé :

  • F n'est pas MoveConstructible.
  • Tout type dans Args n'est pas MoveConstructible.
  • INVOKE(decay-copy(std::forward<F>(f)), decay-copy(std::forward<Args>(args))...) n'est pas une expression valide.

(jusqu'à C++20)

Si l'un des éléments suivants est false, le programme est mal formé :

  • std::is_constructible_v<std::decay_t<F>, F>
  • (std::is_constructible_v<std::decay_t<Args>, Args> && ...)
  • std::is_invocable_v<std::decay_t<F>, std::decay_t<Args>...>

(depuis C++20)

L'achèvement de l'invocation du constructeur se synchronise avec le début de l'invocation de la copie de f sur le nouveau fil d'exécution.

  1. Le constructeur de copie est supprimé ; les fils ne sont pas copiables. Deux objets std::thread ne peuvent pas représenter le même fil d'exécution.

Paramètres

  • other — autre objet thread avec lequel construire cet objet thread
  • f — Callable objet à exécuter dans le nouveau fil
  • args — arguments à passer à la nouvelle fonction

Postconditions

  1. get_id() égal à std::thread::id() (c.-à-d. joinable() est false).

  2. other.get_id() égal à std::thread::id() et get_id() renvoie la valeur de other.get_id() avant le début de la construction.

  3. get_id() différent de std::thread::id() (c.-à-d. joinable() est true).

Exceptions

  1. std::system_error si le fil n'a pas pu être démarré. L'exception peut représenter la condition d'erreur std::errc::resource_unavailable_try_again ou une autre condition d'erreur propre à l'implémentation.

Notes

Les arguments de la fonction du thread sont déplacés ou copiés par valeur. Si un argument de référence doit être passé à la fonction du thread, il doit être enveloppé (par exemple avec std::ref ou std::cref).

La valeur de retour de la fonction est ignorée. Si la fonction lève une exception, std::terminate est appelée. Pour renvoyer des valeurs de retour ou des exceptions au fil appelant, std::promise ou std::async peuvent être utilisés.

Exemple

#include <chrono>
#include <iostream>
#include <thread>
#include <utility>

void f1(int n)
{
    for (int i = 0; i < 5; ++i)
    {
        std::cout << "Thread 1 executing\n";
        ++n;
        std::this_thread::sleep_for(std::chrono::milliseconds(10));
    }
}

void f2(int& n)
{
    for (int i = 0; i < 5; ++i)
    {
        std::cout << "Thread 2 executing\n";
        ++n;
        std::this_thread::sleep_for(std::chrono::milliseconds(10));
    }
}

class foo
{
public:
    void bar()
    {
        for (int i = 0; i < 5; ++i)
        {
            std::cout << "Thread 3 executing\n";
            ++n;
            std::this_thread::sleep_for(std::chrono::milliseconds(10));
        }
    }
    int n = 0;
};

class baz
{
public:
    void operator()()
    {
        for (int i = 0; i < 5; ++i)
        {
            std::cout << "Thread 4 executing\n";
            ++n;
            std::this_thread::sleep_for(std::chrono::milliseconds(10));
        }
    }
    int n = 0;
};

int main()
{
    int n = 0;
    foo f;
    baz b;
    std::thread t1; // t1 n'est pas un thread
    std::thread t2(f1, n + 1); // passage par valeur
    std::thread t3(f2, std::ref(n)); // passage par référence
    std::thread t4(std::move(t3)); // t4 exécute maintenant f2(). t3 n'est plus un thread
    std::thread t5(&foo::bar, &f); // t5 exécute foo::bar() sur l'objet f
    std::thread t6(b); // t6 exécute baz::operator() sur une copie de l'objet b
    t2.join();
    t4.join();
    t5.join();
    t6.join();
    std::cout << "Final value of n is " << n << '\n';
    std::cout << "Final value of f.n (foo::n) is " << f.n << '\n';
    std::cout << "Final value of b.n (baz::n) is " << b.n << '\n';
}
