std::thread::~thread

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

~thread();  // (depuis C++11)

Détruit l'objet thread.

Si *this a un thread associé (joinable() == true), std::terminate() est appelée.

Notes

Un objet thread n'a plus de thread associé (et peut être détruit sans risque) après

  • avoir été construit par défaut.
  • avoir été déplacé depuis.
  • join() a été appelée.
  • detach() a été appelée.

Exemple

#include <thread>
using namespace std::chrono_literals;

int main()
{
    auto bleah = std::thread{[]{ std::this_thread::sleep_for(13ms); }};

}   // ~thread appelle std::terminate()

Sortie possible :

terminate called without an active exception
