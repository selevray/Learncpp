std::hash<std::thread::id>

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <thread>

template<> struct hash<std::thread::id>;  // (depuis C++11)

La spécialisation de modèle de std::hash pour la classe std::thread::id permet aux utilisateurs d'obtenir les empreintes (hachages) des identifiants de threads.

Exemple
Cette section est incomplète Raison : exemple utilisant hash de manière significative 
#include <chrono>
#include <iostream>
#include <thread>
#include <vector>
using namespace std::chrono_literals;

void foo()
{
    std::this_thread::sleep_for(10ms);
}

int main()
{
    std::vector<std::thread> v;
    for (int n = 0; n < 4; ++n)
        v.emplace_back(foo);

    std::hash<std::thread::id> hasher;
    for (auto& t : v)
    {
        std::cout << "thread " << t.get_id() << " hashes to "
                  << hasher(t.get_id()) << '\n';
        t.join();
    }
}
