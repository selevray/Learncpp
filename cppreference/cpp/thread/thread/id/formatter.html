template< class CharT >
struct formatter<std::thread::id, CharT>;  // (depuis C++23)

La spécialisation de modèle de std::formatter pour la classe std::thread::id permet aux utilisateurs de convertir un identifiant de thread en sa représentation textuelle à l'aide des fonctions de formatage.

Spécification de format

La syntaxe des spécifications de format est :

| | | | fill-and-align ﻿*(facultatif)* width ﻿*(facultatif)* | | | |

fill-and-align et width ont la même signification que dans la spécification de format standard. L'alignement par défaut est >.

La sortie formatée correspond à la sortie de operator<<, ajustée selon les spécificateurs de format.

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_formatters 202302L (C++23) Formatage de std::thread::id et std::stacktrace

Exemple

#include <format>
#include <iostream>
#include <thread>

int main()
{
    std::thread::id this_id = std::this_thread::get_id();
    std::thread::id null_id;

    std::cout << std::format("current thread id: {}\n", this_id);
    std::cout << std::format("{:=^10}\n", null_id);
}

Sortie possible :

current thread id: 140046396632256
