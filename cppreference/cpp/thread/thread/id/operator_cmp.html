bool operator> ( std::thread::id lhs, std::thread::id rhs ) noexcept;  // (5) (depuis C++11) (jusqu'à C++20)

bool operator>=( std::thread::id lhs, std::thread::id rhs ) noexcept;  // (6) (depuis C++11) (jusqu'à C++20)

std::strong_ordering operator<=>( std::thread::id lhs,
                                  std::thread::id rhs ) noexcept;  // (7) (depuis C++20)

Compare deux identifiants de thread.

1,2) Vérifie si lhs et rhs représentent soit le même thread, soit aucun thread.

3-7) Compare lhs et rhs selon un ordre total non spécifié.

Les opérateurs <, <=, >, >= et != sont synthétisés à partir de operator<=> et operator== respectivement.

(depuis C++20)

Paramètres

  • lhs, rhs — identifiants de thread à comparer

Valeur de retour

1-6) true si la relation correspondante est vraie, false sinon.

  1. std::strong_ordering::less si lhs est inférieur à rhs dans l'ordre total ; sinon std::strong_ordering::greater si rhs est inférieur à lhs dans l'ordre total ; sinon std::strong_ordering::equal.

Complexité

Constante.

Exemple

#include <cassert>
#include <chrono>
#include <iostream>
#include <thread>

int main()
{
    auto work = [] { std::this_thread::sleep_for(std::chrono::seconds(1)); };
    std::thread t1(work);
    std::thread t2(work);

    assert(t1.get_id() == t1.get_id() and
           t2.get_id() == t2.get_id() and
           t1.get_id() != t2.get_id());

    if (const auto cmp = t1.get_id() <=> t2.get_id(); cmp < 0)
        std::cout << "id1 < id2\n";
    else
        std::cout << "id1 > id2\n";

    std::cout << "id1: " << t1.get_id() << "\n"
                 "id2: " << t2.get_id() << '\n';

    t1.join();
    t2.join();
}
