std::thread::hardware_concurrency

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static unsigned int hardware_concurrency() noexcept;  // (depuis C++11)

Renvoie le nombre de threads concurrents pris en charge par l'implémentation. La valeur doit être considérée uniquement comme une indication.

Paramètres

(aucune)

Valeur de retour

Nombre de threads concurrents pris en charge. Si la valeur n'est pas bien définie ou n'est pas calculable, renvoie 0.

Exemple

#include <iostream>
#include <thread>

int main()
{
    unsigned int n = std::thread::hardware_concurrency();
    std::cout << n << " concurrent threads are supported.\n";
}

Sortie possible :

4 concurrent threads are supported.
