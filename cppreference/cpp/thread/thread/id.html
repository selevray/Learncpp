class thread::id;  // (depuis C++11)

La classe thread::id est une classe légère, trivialement copiable, qui sert d'identifiant unique aux objets std::thread et std::jthread (depuis C++20).

Les instances de cette classe peuvent aussi contenir la valeur particulière distincte qui ne représente aucun thread. Une fois qu'un thread est terminé, la valeur de std::thread::id peut être réutilisée par un autre thread.

Cette classe est conçue pour être utilisée comme clé dans les conteneurs associatifs, ordonnés comme non ordonnés.
