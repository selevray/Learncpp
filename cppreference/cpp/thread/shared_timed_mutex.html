std::shared_timed_mutex

Défini dans l'en-tête <shared_mutex>

class shared_timed_mutex;  // (depuis C++14)

La classe shared_timed_mutex est une primitive de synchronisation pouvant être utilisée pour protéger des données partagées contre un accès simultané par plusieurs threads. Contrairement aux autres types de mutex, qui permettent un accès exclusif, un shared_timed_mutex a deux niveaux d'accès :

  • exclusif - un seul thread peut posséder le mutex.

  • partagé - plusieurs threads peuvent partager la propriété du même mutex.

Les mutex partagés sont généralement utilisés lorsque plusieurs lecteurs peuvent accéder à la même ressource en même temps sans provoquer de data races, mais qu'un seul écrivain peut le faire.

De manière similaire à timed_mutex, shared_timed_mutex permet de tenter de revendiquer la propriété d'un shared_timed_mutex avec un délai, via les fonctions membres try_lock_for(), try_lock_until(), try_lock_shared_for(), try_lock_shared_until().

La classe shared_timed_mutex satisfait à toutes les exigences de SharedTimedMutex et de StandardLayoutType.

Fonctions membres

  • (constructeur) — construit le mutex (fonction membre publique)
  • (destructeur) — détruit le mutex (fonction membre publique)
  • operator=[deleted] — non copiable par affectation (fonction membre publique)

##### Verrouillage exclusif {#Exclusive_locking}

  • lock — verrouille le mutex, bloque si le mutex n'est pas disponible (fonction membre publique)
  • try_lock — tente de verrouiller le mutex, retourne si le mutex n'est pas disponible (fonction membre publique)
  • try_lock_for — tente de verrouiller le mutex, retourne si le mutex est resté indisponible pendant la durée de délai spécifiée (fonction membre publique)
  • try_lock_until — tente de verrouiller le mutex, retourne si le mutex est resté indisponible jusqu'à ce que le point temporel spécifié soit atteint (fonction membre publique)
  • unlock — déverrouille le mutex (fonction membre publique)

##### Verrouillage partagé {#Shared_locking}

  • lock_shared — verrouille le mutex en propriété partagée, bloque si le mutex n'est pas disponible (fonction membre publique)
  • try_lock_shared — tente de verrouiller le mutex en propriété partagée, renvoie si le mutex n'est pas disponible (fonction membre publique)
  • try_lock_shared_for — tente de verrouiller le mutex en propriété partagée, renvoie si le mutex est resté indisponible pendant la durée de délai spécifiée (fonction membre publique)
  • try_lock_shared_until — tente de verrouiller le mutex en propriété partagée, renvoie si le mutex est resté indisponible jusqu'à ce que le point temporel spécifié soit atteint (fonction membre publique)
  • unlock_shared — déverrouille le mutex (propriété partagée) (fonction membre publique)

Un opérateur d'affectation par copie pour une classe qui détient des ressources pouvant gérer plusieurs lecteurs, mais un seul écrivain.

#include <mutex>
#include <shared_mutex>

class R
{
    mutable std::shared_timed_mutex mut;
    /* data */
public:
    R& operator=(const R& other)
    {
        // exige la propriété exclusive pour écrire dans *this
        std::unique_lock<std::shared_timed_mutex> lhs(mut, std::defer_lock);
        // exige la propriété partagée pour lire depuis other
        std::shared_lock<std::shared_timed_mutex> rhs(other.mut, std::defer_lock);
        std::lock(lhs, rhs);
        /* affecte des données */
        return *this;
    }
};

int main()
{
    R r;
}
