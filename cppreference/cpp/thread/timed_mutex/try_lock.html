std::timed_mutex::try_lock

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool try_lock();  // (depuis C++11)

Tente de verrouiller le mutex. Retourne immédiatement. En cas d'acquisition réussie du verrou, retourne true, sinon retourne false.

Cette fonction peut échouer de façon fortuite et retourner false même si le mutex n'est actuellement verrouillé par aucun autre thread.

Si try_lock est appelé par un thread qui possède déjà le mutex, le comportement est indéfini.

Une opération unlock() antérieure sur le même mutex se synchronise avec (tel que défini dans std::memory_order) cette opération si elle retourne true. Notez qu'une opération lock() antérieure ne se synchronise pas avec cette opération si elle retourne false.

Paramètres

(aucune)

Valeur de retour

true si le verrou a été acquis avec succès, sinon false.

Exceptions

Ne lève aucune exception.
