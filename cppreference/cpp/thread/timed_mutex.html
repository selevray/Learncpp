std::timed_mutex

class timed_mutex;  // (depuis C++11)

La classe timed_mutex est une primitive de synchronisation qui peut être utilisée pour protéger des données partagées contre des accès simultanés de plusieurs threads.

De manière similaire à mutex, timed_mutex offre une sémantique de propriété exclusive et non récursive. En outre, timed_mutex permet de tenter d'acquérir la propriété d'un timed_mutex avec un délai d'attente via les fonctions membres try_lock_for() et try_lock_until().

La classe timed_mutex satisfait à toutes les exigences de TimedMutex et de StandardLayoutType.

##### Verrouillage {#Locking}

  • lock — verrouille le mutex, bloque si le mutex n'est pas disponible (fonction membre publique)
  • try_lock — tente de verrouiller le mutex, retourne si le mutex n'est pas disponible (fonction membre publique)
  • try_lock_for — tente de verrouiller le mutex, retourne si le mutex est resté indisponible pendant la durée de délai spécifiée (fonction membre publique)
  • try_lock_until — tente de verrouiller le mutex, retourne si le mutex est resté indisponible jusqu'à ce que le point temporel spécifié soit atteint (fonction membre publique)
  • unlock — déverrouille le mutex (fonction membre publique)
