std::barrier<CompletionFunction>::barrier

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr explicit barrier( std::ptrdiff_t expected,
                            CompletionFunction f = CompletionFunction());  // (1) (depuis C++20)

barrier( const barrier& ) = delete;  // (2) (depuis C++20)

  1. Définit à la fois le compte attendu initial pour chaque phase et le compte attendu courant pour la première phase à expected, initialise l'objet fonction de complétion avec std::move(f), puis démarre la première phase. Le comportement est indéfini si expected est négatif ou supérieur à max().

  2. Le constructeur de copie est supprimé. barrier n'est ni copiable ni déplaçable.

Paramètres

  • expected — valeur initiale du compte attendu
  • f — objet fonction de complétion à appeler lors de l'étape de complétion de phase

Exceptions

  1. Toute exception levée par le constructeur de déplacement de CompletionFunction.

Notes

expected peut valoir zéro. Cependant, appeler toute fonction membre non statique autre que le destructeur sur un tel barrier entraîne un comportement indéfini. En d'autres termes, un tel barrier ne peut être que détruit.
