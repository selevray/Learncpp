std::barrier<CompletionFunction>::arrive_and_wait

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void arrive_and_wait();  // (depuis C++20)

Décrémente atomiquement le compte attendu de 1, puis bloque au point de synchronisation de la phase courante jusqu'à ce que l'étape de complétion de la phase courante soit exécutée. Équivalent à wait(arrive());.

Le comportement est indéfini si le compte attendu pour la phase courante est nul.

Paramètres

(aucune)

Valeur de retour

(aucune)

Exceptions

Lève std::system_error avec un code d'erreur autorisé pour les types mutex en cas d'erreur.

Notes

Si le compte attendu courant est décrémenté à zéro lors de l'appel à cette fonction, l'étape de complétion de phase est exécutée et cette fonction ne bloque pas.

Si le compte attendu courant est nul avant l'appel à cette fonction, le compte attendu initial pour toutes les phases suivantes est également nul, ce qui signifie que barrier ne peut pas être réutilisée.
