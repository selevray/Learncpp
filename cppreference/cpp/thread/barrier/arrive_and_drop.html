std::barrier<CompletionFunction>::arrive_and_drop

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void arrive_and_drop();  // (depuis C++20)

Décrémente de un le compte attendu initial pour toutes les phases suivantes, puis décrémente de un le compte attendu pour la phase courante.

Cette fonction est exécutée de manière atomique. L'appel à cette fonction se produit fortement avant le début de l'étape de complétion de phase de la phase courante.

Le comportement est indéfini si le compte attendu pour la phase courante est nul.

Paramètres

(aucune)

Valeur de retour

(aucune)

Exceptions

Lève std::system_error avec un code d'erreur autorisé pour les types mutex en cas d'erreur.

Notes

Cette fonction peut provoquer le démarrage de l'étape de complétion de la phase courante.

Si le compte attendu courant est nul avant l'appel à cette fonction, le compte attendu initial pour toutes les phases suivantes est également nul, ce qui signifie que barrier ne peut pas être réutilisée.
