arrival_token arrive( std::ptrdiff_t n = 1 );  // (depuis C++20)

Construit un objet arrival_token associé au point de synchronisation de phase de la phase courante. Puis décrémente le compte attendu de n.

Cette fonction s'exécute de manière atomique. L'appel à cette fonction se produit fortement avant le début de l'étape de complétion de phase de la phase courante.

Le comportement est indéfini si n est inférieur ou égal à 0 ou supérieur au compte attendu pour la phase courante de la barrière.

Paramètres

  • n — la valeur de laquelle le compte attendu est diminué

Valeur de retour

L'objet arrival_token construit.

Exceptions

Lève std::system_error avec un code d'erreur autorisé pour les types mutex en cas d'erreur.

Notes

Cette fonction peut provoquer le démarrage de l'étape de complétion de la phase courante.
