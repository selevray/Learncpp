std::barrier<CompletionFunction>::wait

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void wait( arrival_token&& arrival ) const;  // (depuis C++20)

Si arrival est associé au point de synchronisation de phase de la phase courante de *this, bloque au point de synchronisation associé à arrival jusqu'à ce que l'étape de complétion de phase du point de synchronisation soit exécutée.

Sinon, si arrival est associé au point de synchronisation de phase de la phase immédiatement précédente de *this, retourne immédiatement.

Sinon, c'est-à-dire si arrival est associé au point de synchronisation de phase d'une phase antérieure de *this ou d'une phase d'un objet barrière autre que *this, le comportement est indéfini.

Paramètres

  • arrival — un arrival_token obtenu par un appel précédent à arrive sur le même barrier

Valeur de retour

(aucune)

Exceptions

Lève std::system_error avec un code d'erreur autorisé pour les types mutex en cas d'erreur.
