std::stop_callback

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stop_token>

template< class Callback >
class stop_callback;  // (depuis C++20)

Le modèle de classe stop_callback fournit un type d'objet RAII qui enregistre une fonction de rappel pour un objet std::stop_token associé, de sorte que la fonction de rappel soit invoquée lorsqu'un arrêt est demandé pour le std::stop_source associé à std::stop_token.

Les fonctions de rappel enregistrées via le constructeur de stop_callback sont invoquées soit dans le même thread qui invoque avec succès request_stop() pour un std::stop_source du std::stop_token associé à stop_callback ; soit, si l'arrêt a déjà été demandé avant l'enregistrement du constructeur, la fonction de rappel est invoquée dans le thread qui construit le stop_callback.

Plusieurs stop_callback peuvent être créés pour le même std::stop_token, depuis le même thread ou depuis des threads différents, de façon concurrente. Aucune garantie n'est fournie quant à l'ordre d'exécution, mais ils seront invoqués de façon synchrone ; sauf pour les stop_callback(s) construits après que l'arrêt a déjà été demandé pour le std::stop_token, comme décrit précédemment.

Si l'invocation d'un rappel se termine par une exception, alors std::terminate est appelé.

std::stop_callback n'est ni CopyConstructible, ni CopyAssignable, ni MoveConstructible, ni MoveAssignable.

Le paramètre de modèle Callback doit être à la fois invocable et destructible. Toute valeur de retour est ignorée.

Exemple

#include <chrono>
#include <condition_variable>
#include <iostream>
#include <mutex>
#include <sstream>
#include <thread>

using namespace std::chrono_literals;

// Utiliser une classe auxiliaire pour la diffusion atomique vers std::cout.
class Writer
{
    std::ostringstream buffer;
public:
    ~Writer()
    {
        std::cout << buffer.str();
    }
    Writer& operator<<(auto input)
    {
        buffer << input;
        return *this;
    }
};

int main()
{
    // Un thread de travail.
    // Il attendra jusqu'à ce qu'il soit demandé de s'arrêter.
    std::jthread worker([] (std::stop_token stoken)
    {
        Writer() << "Worker thread's id: " << std::this_thread::get_id() << '\n';
        std::mutex mutex;
        std::unique_lock lock(mutex);
        std::condition_variable_any().wait(lock, stoken,
            [&stoken] { return stoken.stop_requested(); });
    });

    // Enregistrer un rappel d'arrêt sur le thread de travail.
    std::stop_callback callback(worker.get_stop_token(), []
    {
        Writer() << "Stop callback executed by thread: "
            << std::this_thread::get_id() << '\n';
    });

    // Les objets Stop_callback peuvent être détruits prématurément pour empêcher l'exécution.
    {
        std::stop_callback scoped_callback(worker.get_stop_token(), []
        {
            // Ceci ne sera pas exécuté.
            Writer() << "Scoped stop callback executed by thread: "
                << std::this_thread::get_id() << '\n';
        });
    }

    // Démontrer quel thread exécute le stop_callback et quand.
    // Définir une fonction stopper.
    auto stopper_func = [&worker]
    {
        if (worker.request_stop())
            Writer() << "Stop request executed by thread: "
                << std::this_thread::get_id() << '\n';
        else
            Writer() << "Stop request not executed by thread: "
                << std::this_thread::get_id() << '\n';
    };

    // Faire concourir plusieurs threads pour arrêter le thread de travail.
    std::jthread stopper1(stopper_func);
    std::jthread stopper2(stopper_func);
    stopper1.join();
    stopper2.join();

    // Une fois qu'un arrêt a déjà été demandé,
    // un nouveau stop_callback s'exécute immédiatement.
    Writer() << "Main thread: " << std::this_thread::get_id() << '\n';
    std::stop_callback callback_after_stop(worker.get_stop_token(), []
    {
        Writer() << "Stop callback executed by thread: "
            << std::this_thread::get_id() << '\n';
    });
}
