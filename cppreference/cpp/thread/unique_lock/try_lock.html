std::unique_lock<Mutex>::try_lock

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool try_lock();  // (depuis C++11)

Tente de verrouiller (c.-à-d. d'en acquérir la propriété) le mutex associé sans bloquer. Appelle effectivement mutex()->try_lock().

std::system_error est levée s'il n'existe aucun mutex associé ou si le mutex est déjà verrouillé par ce std::unique_lock.

Paramètres

(aucune)

Valeur de retour

true si la propriété du mutex a été acquise avec succès, false sinon.

Exceptions

  • Toute exception levée par mutex()->try_lock() (les types Mutex ne lèvent pas d'exception dans try_lock, mais un Lockable personnalisé le pourrait).

  • S'il n'existe aucun mutex associé, lève std::system_error avec un code d'erreur de std::errc::operation_not_permitted.

  • Si le mutex est déjà verrouillé par ce std::unique_lock, std::system_error avec le code d'erreur std::errc::resource_deadlock_would_occur.

Exemple

Les exemples suivants tentent d'acquérir un mutex qui a été verrouillé puis déverrouillé.

#include <chrono>
#include <iostream>
#include <mutex>
#include <thread>
#include <vector>

using namespace std::chrono_literals;

int main()
{
    std::mutex counter_mutex;
    std::vector<std::thread> threads;
    using Id = int;

    auto worker_task = [&](Id id, std::chrono::seconds wait, std::chrono::seconds acquire)
    {
        // attendre quelques secondes avant d'acquérir le verrou.
        std::this_thread::sleep_for(wait);

        std::unique_lock<std::mutex> lock(counter_mutex, std::defer_lock);
        if (lock.try_lock())
            std::cout << '#' << id << ", lock acquired.\n";
        else
        {
            std::cout << '#' << id << ", failed acquiring lock.\n";
            return;
        }

        // garder le verrou un certain temps.
        std::this_thread::sleep_for(acquire);

        std::cout << '#' << id << ", releasing lock (via destructor).\n";
    };

    threads.emplace_back(worker_task, Id{0}, 0s, 2s);
    threads.emplace_back(worker_task, Id{1}, 1s, 0s);
    threads.emplace_back(worker_task, Id{2}, 3s, 0s);

    for (auto& thread : threads)
        thread.join();
}

Output:

#0, lock acquired.
#1, failed acquiring lock.
#0, releasing lock (via destructor).
#2, lock acquired.
#2, releasing lock (via destructor).

  • try_lock_for — tente de verrouiller (c.-à-d. d'en acquérir la propriété) le mutex associé TimedLockable, retourne si le mutex est resté indisponible pendant la durée spécifiée (fonction membre publique)

  • unlock — déverrouille (c.-à-d. libère la propriété de) le mutex associé (fonction membre publique)
