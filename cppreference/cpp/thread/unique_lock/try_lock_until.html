std::unique_lock<Mutex>::try_lock_until

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class Clock, class Duration >
bool try_lock_until( const std::chrono::time_point<Clock, Duration>& timeout_time );  // (depuis C++11)

Tente de verrouiller (c.-à-d. d'en acquérir la propriété) le mutex associé. Bloque jusqu'à ce que le timeout_time spécifié soit atteint ou que le verrou soit acquis, selon ce qui survient en premier. En cas d'acquisition réussie du verrou, retourne true, sinon retourne false. Peut bloquer plus longtemps que timeout_time jusqu'à ce que le point temporel spécifié soit atteint.

Appelle effectivement mutex()->try_lock_until(timeout_time).

std::system_error est levée s'il n'existe aucun mutex associé ou si le mutex est déjà verrouillé par le même thread.

Clock doit satisfaire aux exigences Clock. Le programme est mal formé si std::chrono::is_clock_v<Clock> est false. (depuis C++20)

Paramètres

  • timeout_time — point temporel maximal jusqu'auquel bloquer

Valeur de retour

true si la propriété du mutex a été acquise avec succès, false sinon.

Exceptions

  • Toute exception levée par mutex()->try_lock_until(timeout_time).

  • S'il n'existe aucun mutex associé, lève std::system_error avec un code d'erreur de std::errc::operation_not_permitted.

  • Si le mutex est déjà verrouillé, lève std::system_error avec un code d'erreur de std::errc::resource_deadlock_would_occur.
