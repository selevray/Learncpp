Construit un unique_lock, en verrouillant optionnellement le mutex fourni.

  1. Construit un unique_lock sans mutex associé.

  2. Constructeur de déplacement. Initialise le unique_lock avec le contenu de other. Laisse other sans mutex associé.

3-8) Construit un unique_lock avec m comme mutex associé. De plus :

  1. Verrouille le mutex associé en appelant m.lock().

  2. Ne verrouille pas le mutex associé.

  3. Tente de verrouiller le mutex associé sans bloquer en appelant m.try_lock(). Le comportement est indéfini si Mutex ne satisfait pas Lockable.

  4. Suppose que le thread appelant détient déjà un verrou non partagé (c.-à-d. un verrou acquis par lock, try_lock, try_lock_for ou try_lock_until) sur m. Le comportement est indéfini sinon.

  5. Tente de verrouiller le mutex associé en appelant m.try_lock_for(timeout_duration). Bloque jusqu'à ce que la timeout_duration spécifiée soit écoulée ou que le verrou soit acquis, selon ce qui survient en premier. Peut bloquer plus longtemps que timeout_duration. Le comportement est indéfini si Mutex ne satisfait pas TimedLockable.

  6. Tente de verrouiller le mutex associé en appelant m.try_lock_until(timeout_time). Bloque jusqu'à ce que le timeout_time spécifié soit atteint ou que le verrou soit acquis, selon ce qui survient en premier. Peut bloquer plus longtemps que jusqu'à ce que timeout_time soit atteint. Le comportement est indéfini si Mutex ne satisfait pas TimedLockable.

Paramètres

  • other — un autre unique_lock pour initialiser l'état
  • m — mutex à associer au verrou et dont on acquiert optionnellement la propriété
  • t — paramètre d'étiquette utilisé pour sélectionner les constructeurs avec différentes stratégies de verrouillage
  • timeout_duration — durée maximale de blocage
  • timeout_time — point temporel maximal jusqu'auquel bloquer

Exemple

#include <iostream>
#include <mutex>
#include <thread>
#include <utility>
#include <vector>

std::mutex m_a, m_b, m_c;
int a, b, c = 1;

void update()
{
    {   // Remarque : std::lock_guard ou atomic<int> peuvent être utilisés à la place
        std::unique_lock<std::mutex> lk(m_a);
        ++a;
    }

    {   // Remarque : voir std::lock et std::scoped_lock pour plus de détails et alternatives
        std::unique_lock<std::mutex> lk_b(m_b, std::defer_lock);
        std::unique_lock<std::mutex> lk_c(m_c, std::defer_lock);
        std::lock(lk_b, lk_c);
        b = std::exchange(c, b + c);
    }
}

int main()
{
    std::vector<std::thread> threads;
    for (unsigned i = 0; i < 12; ++i)
        threads.emplace_back(update);

    for (auto& i : threads)
        i.join();

    std::cout << a << "'th and " << a + 1 << "'th Fibonacci numbers: "
              << b << " and " << c << '\n';
}

Output:

12'th and 13'th Fibonacci numbers: 144 and 233
