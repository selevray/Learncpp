std::unique_lock<Mutex>::swap

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void swap( unique_lock& other ) noexcept;  // (depuis C++11)

Échange les états internes des objets verrou.

Paramètres

  • other — le verrou dont l'état est à échanger

Valeur de retour

(aucune)

Exemple

#include <iostream>
#include <mutex>

int main()
{
    std::mutex mtx1;
    std::unique_lock<std::mutex> guard1(mtx1);
    std::unique_lock<std::mutex> guard2;
    guard2.swap(guard1);

    if (!guard1 && guard2)
        std::cout << "swapped success\n";

    return 0;
}

Output:

swapped success
