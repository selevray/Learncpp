void unlock();  // (depuis C++11)

Déverrouille (c.-à-d. abandonne la propriété de) le mutex associé.

std::system_error est levée s'il n'y a pas de mutex associé ou si le mutex n'est pas verrouillé.

Paramètres

(aucune)

Valeur de retour

(aucune)

Exceptions

S'il n'existe aucun mutex associé ou si le mutex n'est pas verrouillé, std::system_error avec le code d'erreur std::errc::operation_not_permitted.
