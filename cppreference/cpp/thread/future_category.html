std::future_category

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <future>

const std::error_category& future_category() noexcept;  // (depuis C++11)

Obtient une référence vers l'objet de catégorie d'erreur statique pour les erreurs liées aux futurs et aux promesses. L'objet doit redéfinir la fonction virtuelle error_category::name() pour retourner un pointeur vers la chaîne "future". Il sert à identifier les codes d'erreur fournis dans les exceptions de type std::future_error.

Paramètres

(aucune)

Valeur de retour

Une référence vers l'objet statique de type d'exécution non spécifié, dérivé de std::error_category.
