std::shared_lock<Mutex>::try_lock

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool try_lock();  // (depuis C++14)

Tente de verrouiller le mutex associé en mode partagé sans blocage. Appelle effectivement mutex()->try_lock_shared().

std::system_error est levée s'il n'existe aucun mutex associé ou si le mutex est déjà verrouillé.

Paramètres

(aucune)

Valeur de retour

true si la propriété du mutex a été acquise avec succès, false sinon.

Exceptions

  • Toute exception levée par mutex()->try_lock_shared().

  • S'il n'existe aucun mutex associé, lève std::system_error avec un code d'erreur de std::errc::operation_not_permitted.

  • Si le mutex est déjà verrouillé, lève std::system_error avec un code d'erreur de std::errc::resource_deadlock_would_occur.
