Construit un shared_lock, en verrouillant optionnellement le mutex fourni.

  1. Construit un shared_lock sans mutex associé.

  2. Constructeur de déplacement. Initialise le shared_lock avec le contenu de other. Laisse other sans mutex associé.

3-8) Construit un shared_lock avec m comme mutex associé. De plus :

  1. Verrouille le mutex associé en mode partagé en appelant m.lock_shared().

  2. Ne verrouille pas le mutex associé.

  3. Tente de verrouiller le mutex associé en mode partagé sans blocage en appelant m.try_lock_shared().

  4. Suppose que le thread appelant détient déjà un verrou partagé (c.-à-d. un verrou acquis par lock_shared, try_lock_shared, try_lock_shared_for ou try_lock_shared_until) sur m. Le comportement est indéfini si ce n'est pas le cas.

  5. Tente de verrouiller le mutex associé en mode partagé en appelant m.try_lock_shared_for(timeout_duration), ce qui bloque jusqu'à ce que la timeout_duration spécifiée soit écoulée ou que le verrou soit acquis, selon ce qui survient en premier. Peut bloquer plus longtemps que timeout_duration. Le comportement est indéfini si Mutex ne satisfait pas aux exigences SharedTimedLockable.

  6. Tente de verrouiller le mutex associé en mode partagé en appelant m.try_lock_shared_until(timeout_time), ce qui bloque jusqu'à ce que le timeout_time spécifié soit atteint ou que le verrou soit acquis, selon ce qui survient en premier. Peut bloquer plus longtemps que jusqu'à ce que timeout_time soit atteint. Le comportement est indéfini si Mutex ne satisfait pas aux exigences SharedTimedLockable.

Paramètres

  • other — un autre shared_lock pour initialiser l'état
  • m — mutex à associer au verrou et dont on acquiert optionnellement la propriété
  • t — paramètre d'étiquette utilisé pour sélectionner les constructeurs avec différentes stratégies de verrouillage
  • timeout_duration — durée maximale de blocage
  • timeout_time — point temporel maximal jusqu'auquel bloquer

Exemple

#include <chrono>
#include <iostream>
#include <shared_mutex>
#include <syncstream>
#include <thread>

std::shared_timed_mutex m;
int i = 10;

void read_shared_var(int id)
{
     // les deux threads accèdent à l'entier i
     std::shared_lock<std::shared_timed_mutex> slk(m);
     const int ii = i; // lit i global

     std::osyncstream(std::cout) << '#' << id << " read i as " << ii << "...\n";
     std::this_thread::sleep_for(std::chrono::milliseconds(10));
     std::osyncstream(std::cout) << '#' << id << " woke up..." << std::endl;
}

int main()
{
     std::thread r1{read_shared_var, 1};
     std::thread r2{read_shared_var, 2};

     r1.join();
     r2.join();
}
