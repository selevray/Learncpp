std::shared_lock<Mutex>::unlock

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void unlock();  // (depuis C++14)

Déverrouille le mutex associé du mode partagé. Appelle effectivement mutex()->unlock_shared().

std::system_error est levée s'il n'y a pas de mutex associé ou si le mutex n'est pas verrouillé.

Paramètres

(aucune)

Valeur de retour

(aucune)

Exceptions

  • Toute exception levée par mutex()->unlock_shared().

  • S'il n'existe aucun mutex associé, lève std::system_error avec un code d'erreur de std::errc::operation_not_permitted.
