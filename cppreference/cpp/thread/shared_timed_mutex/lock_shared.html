std::shared_timed_mutex::lock_shared

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void lock_shared();  // (depuis C++14)

Acquiert la propriété partagée du mutex. Si un autre thread détient le mutex en propriété exclusive, un appel à lock_shared bloquera l'exécution jusqu'à ce que la propriété partagée puisse être acquise.

Si lock_shared est appelé par un thread qui possède déjà le mutex dans n'importe quel mode (exclusif ou partagé), le comportement est indéfini.

Si plus que le nombre maximal défini par l'implémentation de propriétaires partagés ont déjà verrouillé le mutex en mode partagé, lock_shared bloque l'exécution jusqu'à ce que le nombre de propriétaires partagés soit réduit. Le nombre maximal de propriétaires est garanti d'être au moins égal à 10000.

Une opération unlock() antérieure sur le même mutex synchronise-with (tel que défini dans std::memory_order) cette opération.

Paramètres

(aucune)

Valeur de retour

(aucune)

Exceptions

Lève std::system_error lorsque des erreurs surviennent, y compris les erreurs provenant du système d'exploitation sous-jacent qui empêcheraient lock de respecter ses spécifications. Le mutex n'est pas verrouillé si une exception est levée.

Notes

lock_shared() n'est généralement pas appelé directement : std::shared_lock est utilisé pour gérer le verrouillage partagé.
