std::promise<R>::set_exception

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void set_exception( std::exception_ptr p );  // (depuis C++11)

Stocke atomiquement le pointeur d'exception p dans l'état partagé et rend l'état prêt.

L'opération se comporte comme si set_value, set_exception, set_value_at_thread_exit et set_exception_at_thread_exit acquéraient un même mutex associé à l'objet promise lors de la mise à jour de cet objet.

Une exception est levée s'il n'existe pas d'état partagé ou si l'état partagé stocke déjà une valeur ou une exception.

Les appels à cette fonction n'introduisent pas de courses de données avec les appels à get_future (ils n'ont donc pas besoin de se synchroniser entre eux).

Paramètres

  • p — pointeur d'exception à stocker. Le comportement est indéfini si p est nul

Valeur de retour

(aucune)

Exceptions

std::future_error dans les conditions suivantes :

  • *this n'a pas d'état partagé. Le code d'erreur est défini à no_state.

  • L'état partagé stocke déjà une valeur ou une exception. Le code d'erreur est défini à promise_already_satisfied.

Exemple

#include <future>
#include <iostream>
#include <thread>

int main()
{
    std::promise<int> p;
    std::future<int> f = p.get_future();

    std::thread t([&p]
    {
        try
        {
            // code susceptible de lever une exception
            throw std::runtime_error("Example");
        }
        catch (...)
        {
            try
            {
                // stocke toute exception levée dans la promise
                p.set_exception(std::current_exception());
                // ou lever à la place une exception personnalisée
                // p.set_exception(std::make_exception_ptr(MyException("mine")));
            }
            catch (...) {} // set_exception() peut aussi lever une exception
        }
    });

    try
    {
        std::cout << f.get();
    }
    catch (const std::exception& e)
    {
        std::cout << "Exception from the thread: " << e.what() << '\n';
    }
    t.join();
}

Output:

Exception from the thread: Example
