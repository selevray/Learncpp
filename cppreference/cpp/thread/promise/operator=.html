promise& operator=( promise&& other ) noexcept;  // (1) (depuis C++11)

promise& operator=( const promise& rhs ) = delete;  // (2) (depuis C++11)

Affecte le contenu.

  1. Opérateur d'affectation par déplacement. Il abandonne d'abord l'état partagé (comme dans ~promise()), puis affecte l'état partagé de other comme en exécutant std::promise(std::move(other)).swap(*this).

  2. promise n'est pas affectable par copie.

Paramètres

  • other — un autre promise dont il faut acquérir l'état
