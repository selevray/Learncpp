std::promise<R>::set_value_at_thread_exit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Modèle principal

void set_value_at_thread_exit( const R& value );  // (1) (depuis C++11)

void set_value_at_thread_exit( R&& value );  // (2) (depuis C++11)

spécialisations de std:: promise < R & >

void set_value_at_thread_exit( R& value );  // (3) (depuis C++11)

spécialisation de std:: promise < void >

void set_value_at_thread_exit();  // (4) (depuis C++11)

Stocke value dans l'état partagé sans rendre l'état prêt immédiatement. L'état est rendu prêt lorsque le thread courant se termine, après la destruction de toutes les variables à durée de stockage thread_local.

L'opération se comporte comme si set_value, set_exception, set_value_at_thread_exit et set_exception_at_thread_exit acquéraient un même mutex associé à l'objet promise lors de la mise à jour de cet objet.

Les appels à cette fonction n'introduisent pas de courses de données avec les appels à get_future (ils n'ont donc pas besoin de se synchroniser entre eux).

Paramètres

  • value — valeur à stocker dans l'état partagé

Valeur de retour

(aucune)

Exceptions

std::future_error dans les conditions suivantes :

  • *this n'a pas d'état partagé. Le code d'erreur est défini à no_state.
  • L'état partagé stocke déjà une valeur ou une exception. Le code d'erreur est défini à promise_already_satisfied.

Additionally:

  1. Toute exception levée par le constructeur sélectionné pour copier un objet de type R.

  2. Toute exception levée par le constructeur sélectionné pour déplacer un objet de type R.

Exemple

#include <future>
#include <iostream>
#include <thread>

int main()
{
    using namespace std::chrono_literals;
    std::promise<int> p;
    std::future<int> f = p.get_future();
    std::thread([&p]
    {
        std::this_thread::sleep_for(1s);
        p.set_value_at_thread_exit(9);
    }).detach();

    std::cout << "Waiting... " << std::flush;
    f.wait();
    std::cout << "Done!\nResult is: " << f.get() << '\n';
}

Output:

Waiting... Done!
Result is: 9
