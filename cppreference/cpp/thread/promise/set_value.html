std::promise<R>::set_value

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Modèle principal

void set_value( const R& value );  // (1) (depuis C++11)

void set_value( R&& value );  // (2) (depuis C++11)

spécialisations de std:: promise < R & >

void set_value( R& value );  // (3) (depuis C++11)

spécialisation de std:: promise < void >

void set_value();  // (4) (depuis C++11)

1-3) Stocke atomiquement value dans l'état partagé et rend l'état prêt.

  1. Rend l'état prêt.

L'opération se comporte comme si set_value, set_exception, set_value_at_thread_exit et set_exception_at_thread_exit acquéraient un même mutex associé à l'objet promise lors de la mise à jour de cet objet.

Les appels à cette fonction n'introduisent pas de courses de données avec les appels à get_future (ils n'ont donc pas besoin de se synchroniser entre eux).

Paramètres

  • value — valeur à stocker dans l'état partagé

Valeur de retour

(aucune)

Exceptions

std::future_error dans les conditions suivantes :

  • *this n'a pas d'état partagé. Le code d'erreur est défini à no_state.
  • L'état partagé stocke déjà une valeur ou une exception. Le code d'erreur est défini à promise_already_satisfied.

Additionally:

  1. Toute exception levée par le constructeur sélectionné pour copier un objet de type R.

  2. Toute exception levée par le constructeur sélectionné pour déplacer un objet de type R.

Exemple

Cet exemple montre comment std::promise<void> peut être utilisé comme signaux entre threads.

#include <algorithm>
#include <cctype>
#include <chrono>
#include <future>
#include <iostream>
#include <iterator>
#include <sstream>
#include <thread>
#include <vector>

using namespace std::chrono_literals;

int main()
{
    std::istringstream iss_numbers{"3 4 1 42 23 -23 93 2 -289 93"};
    std::istringstream iss_letters{" a 23 b,e a2 k k?a;si,ksa c"};

    std::vector<int> numbers;
    std::vector<char> letters;
    std::promise<void> numbers_promise, letters_promise;

    auto numbers_ready = numbers_promise.get_future();
    auto letter_ready = letters_promise.get_future();

    std::thread value_reader([&]
    {
        // Opérations d'E/S
        std::copy(std::istream_iterator<int>{iss_numbers},
                  std::istream_iterator<int>{},
                  std::back_inserter(numbers));

        // notifie pour les nombres
        numbers_promise.set_value();

        std::copy_if(std::istreambuf_iterator<char>{iss_letters},
                     std::istreambuf_iterator<char>{},
                     std::back_inserter(letters),
                     ::isalpha);

        // notifie pour les lettres
        letters_promise.set_value();
    });

    numbers_ready.wait();

    std::sort(numbers.begin(), numbers.end());

    if (letter_ready.wait_for(1s) == std::future_status::timeout)
    {
        // affiche les nombres pendant l'obtention des lettres
        for (int num : numbers)
            std::cout << num << ' ';
        numbers.clear(); // les nombres ont déjà été affichés
    }

    letter_ready.wait();
    std::sort(letters.begin(), letters.end());

    // ne fait rien si les nombres ont déjà été affichés
    for (int num : numbers)
        std::cout << num << ' ';
    std::cout << '\n';

    for (char let : letters)
        std::cout << let << ' ';
    std::cout << '\n';

    value_reader.join();
}

Output:

-289 -23 1 2 3 4 23 42 93 93
a a a a b c e i k k k s s

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.
