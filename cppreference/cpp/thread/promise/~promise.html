~promise();  // (depuis C++11)

Abandonne l'état partagé :

  • si l'état partagé est prêt, libère celui-ci.
  • si l'état partagé n'est pas prêt, stocke un objet exception de type std::future_error avec une condition d'erreur std::future_errc::broken_promise, rend l'état partagé prêt puis le libère.
