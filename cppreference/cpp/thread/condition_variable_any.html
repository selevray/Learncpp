std::condition_variable_any

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <condition_variable>

class condition_variable_any;  // (depuis C++11)

La classe condition_variable_any est une généralisation de std::condition_variable. Alors que std::condition_variable ne fonctionne qu'avec std::unique_lock<std::mutex>, condition_variable_any peut opérer sur tout verrou satisfaisant les exigences BasicLockable.

Voir std::condition_variable pour la description de la sémantique des variables de condition.

La classe std::condition_variable_any est une StandardLayoutType. Elle n'est pas CopyConstructible, MoveConstructible, CopyAssignable, ni MoveAssignable.

Si le verrou est std::unique_lock<std::mutex>, std::condition_variable peut offrir de meilleures performances.

Notes

std::condition_variable_any peut être utilisée avec std::shared_lock afin d'attendre un std::shared_mutex en mode de propriété partagée.

Une utilisation possible de std::condition_variable_any avec des types de verrou Lockable personnalisés est de fournir des attentes interruptibles pratiques : l'opération de verrouillage personnalisée verrouillerait à la fois le mutex associé comme attendu, et effectuerait aussi la configuration nécessaire pour notifier cette variable de condition lorsque le signal d'interruption est reçu.[1]
