std::shared_lock

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <shared_mutex>

template< class Mutex >
class shared_lock;  // (depuis C++14)

La classe shared_lock est un wrapper de propriété de mutex partagé à usage général, permettant le verrouillage différé, le verrouillage temporisé et le transfert de la propriété du verrou. Verrouiller un shared_lock verrouille le mutex partagé associé en mode partagé (pour le verrouiller en mode exclusif, std::unique_lock peut être utilisé).

La classe shared_lock est déplaçable, mais non copiable : elle satisfait aux exigences de MoveConstructible et de MoveAssignable, mais pas à celles de CopyConstructible ni de CopyAssignable.

shared_lock satisfait aux exigences Lockable. Si Mutex satisfait aux exigences SharedTimedLockable, shared_lock satisfait aussi aux exigences TimedLockable.

Pour attendre sur un mutex partagé en mode de propriété partagée, std::condition_variable_any peut être utilisé (std::condition_variable requiert std::unique_lock et ne peut donc attendre qu'en mode de propriété exclusive).

Paramètres de modèle

  • Mutex — le type du mutex partagé à verrouiller. Le type doit satisfaire aux exigences SharedLockable

Types membres

Type Définition

  • mutex_type — Mutex

Fonctions membres

  • (constructeur) — construit un shared_lock, en verrouillant optionnellement le mutex fourni (fonction membre publique)
  • (destructeur) — déverrouille le mutex associé (fonction membre publique)
  • operator= — déverrouille le mutex, s'il est possédé, et acquiert la propriété d'un autre (fonction membre publique)

##### Verrouillage partagé {#Shared_locking}

  • lock — verrouille le mutex associé (fonction membre publique)
  • try_lock — tente de verrouiller le mutex associé (fonction membre publique)
  • try_lock_for — tente de verrouiller le mutex associé, pendant la durée spécifiée (fonction membre publique)
  • try_lock_until — tente de verrouiller le mutex associé, jusqu'à un point temporel spécifié (fonction membre publique)
  • unlock — déverrouille le mutex associé (fonction membre publique)

##### Modificateurs {#Modifiers}

  • swap — échange les membres de données avec un autre shared_lock (fonction membre publique)
  • release — dissocie le mutex sans le déverrouiller (fonction membre publique)

##### Observateurs {#Observers}

  • mutex — renvoie un pointeur vers le mutex associé (fonction membre publique)
  • owns_lock — teste si le verrou possède son mutex associé (fonction membre publique)
  • operator bool — teste si le verrou possède son mutex associé (fonction membre publique)

Fonctions non membres

  • std::swap(std::shared_lock) (C++14) — spécialise l'algorithme std::swap (modèle de fonction)
