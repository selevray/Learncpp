std::future<T>::valid

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool valid() const noexcept;  // (depuis C++11)

Vérifie si le futur fait référence à un état partagé.

C'est le cas uniquement pour les futurs qui n'ont pas été construits par défaut ni déplacés (c'est-à-dire renvoyés par std::promise::get_future(), std::packaged_task::get_future() ou std::async()) jusqu'au premier appel de get() ou share().

Le comportement est indéfini si une fonction membre autre que le destructeur, l'opérateur d'affectation par déplacement ou valid est appelée sur un future qui ne fait pas référence à un état partagé (bien que les implémentations soient encouragées à lever std::future_error indiquant no_state dans ce cas). Il est valide de déplacer un objet futur pour lequel valid() est false.

Paramètres

(aucune)

Valeur de retour

true si *this fait référence à un état partagé, sinon false.

Exemple

#include <future>
#include <iostream>

int main()
{
    std::promise<void> p;
    std::future<void> f = p.get_future();

    std::cout << std::boolalpha;

    std::cout << f.valid() << '\n';
    p.set_value();
    std::cout << f.valid() << '\n';
    f.get();
    std::cout << f.valid() << '\n';
}

Output:

true
true
false
