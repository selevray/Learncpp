std::future<T>::wait

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void wait() const;  // (depuis C++11)

Bloque jusqu'à ce que le résultat devienne disponible. valid() == true après l'appel.

Le comportement est indéfini si valid() == false avant l'appel de cette fonction.

Paramètres

(aucune)

Valeur de retour

(aucune)

Exceptions

Peut lever des exceptions définies par l'implémentation.

Notes

Les implémentations sont encouragées à détecter le cas où valid() == false avant l'appel, et à lever une std::future_error avec une condition d'erreur égale à std::future_errc::no_state.

Exemple

#include <chrono>
#include <future>
#include <iostream>
#include <thread>

int fib(int n)
{
    if (n < 3)
        return 1;
    else
        return fib(n - 1) + fib(n - 2);
}

int main()
{
    std::future<int> f1 = std::async(std::launch::async, []() { return fib(40); });
    std::future<int> f2 = std::async(std::launch::async, []() { return fib(43); });

    std::cout << "waiting... " << std::flush;
    const auto start = std::chrono::system_clock::now();

    f1.wait();
    f2.wait();

    const auto diff = std::chrono::system_clock::now() - start;
    std::cout << std::chrono::duration<double>(diff).count() << " seconds\n";

    std::cout << "f1: " << f1.get() << '\n';
    std::cout << "f2: " << f2.get() << '\n';
}

Sortie possible :

waiting... 1.61803 seconds
f1: 102334155
f2: 433494437
