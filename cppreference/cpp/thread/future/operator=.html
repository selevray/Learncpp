std::future<T>::operator=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

future& operator=( future&& other ) noexcept;  // (1) (depuis C++11)

future& operator=( const future& other ) = delete;  // (2) (depuis C++11)

Affecte le contenu d'un autre objet future.

  1. Libère tout état partagé et affecte par déplacement le contenu de other à *this. Après l'affectation, other.valid() == false et this->valid() donneront la même valeur que other.valid() avant l'affectation.

  2. std::future n'est pas CopyAssignable.

Paramètres

  • other — un std::future qui transférera l'état à *this

Valeur de retour

*this
