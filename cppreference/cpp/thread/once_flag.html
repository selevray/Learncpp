class once_flag;  // (depuis C++11)

La classe std::once_flag est une structure auxiliaire pour std::call_once.

Un objet de type std::once_flag passé à plusieurs appels à std::call_once permet à ces appels de se coordonner entre eux de sorte qu'un seul des appels aille réellement jusqu'à son terme.

std::once_flag n'est ni copiable ni déplaçable.

std::once_flag::once_flag

Construit un objet once_flag. L'état interne est initialisé pour indiquer qu'aucune fonction n'a encore été appelée.
