std::shared_future<T>::operator=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

shared_future& operator=( const shared_future& other );  // (depuis C++11) (jusqu'à C++17)

shared_future& operator=( const shared_future& other ) noexcept;  // (depuis C++17)

shared_future& operator=( shared_future&& other ) noexcept;  // (2) (depuis C++11)

Affecte le contenu d'un autre shared_future.

  1. Libère tout état partagé et affecte le contenu de other à *this. Après l'affectation, this->valid() == other.valid().

  2. Libère tout état partagé et effectue une affectation par déplacement du contenu de other vers *this. Après l'affectation, other.valid() == false et this->valid() donnent la même valeur que other.valid() avant l'affectation.

Paramètres

  • other — un std::shared_future qui transférera l'état à *this

Valeur de retour

*this
