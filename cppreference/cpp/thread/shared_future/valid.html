std::shared_future<T>::valide

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool valid() const noexcept;  // (depuis C++11)

Vérifie si le futur fait référence à un état partagé.

Ceci n'est vrai que pour les futures qui n'ont pas été construits par défaut ni déplacés. Contrairement à std::future, l'état partagé de std::shared_future n'est pas invalidé lorsque get() est appelé.

Le comportement est indéfini si une fonction membre autre que le destructeur, l'opérateur d'affectation par copie, l'opérateur d'affectation par déplacement ou valid est appelée sur un shared_future qui ne fait pas référence à un état partagé (bien que les implémentations soient encouragées à lever std::future_error indiquant no_state dans ce cas). Il est valide de déplacer ou copier depuis un objet shared_future pour lequel valid() vaut false.

Paramètres

(aucune)

Valeur de retour

true si *this fait référence à un état partagé, sinon false.

Exemple

#include <future>
#include <iostream>

int main()
{
    std::promise<void> p;
    std::shared_future<void> f = p.get_future();

    std::cout << std::boolalpha;

    std::cout << f.valid() << '\n';
    p.set_value();
    std::cout << f.valid() << '\n';
    f.get();
    std::cout << f.valid() << '\n';
}

Output:

true
true
true
