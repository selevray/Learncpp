std::shared_future<T>::wait_for

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class Rep, class Period >
std::future_status wait_for( const std::chrono::duration<Rep,Period>& timeout_duration ) const;  // (depuis C++11)

Attend que le résultat devienne disponible. Bloque jusqu'à ce que la timeout_duration spécifiée soit écoulée ou que le résultat devienne disponible, selon l'éventualité la première survenue. La valeur de retour indique l'état du résultat.

Si le futur est le résultat d'un appel à std::async qui utilisait une évaluation paresseuse, cette fonction retourne immédiatement sans attendre.

Cette fonction peut bloquer pendant une durée supérieure à timeout_duration en raison de retards d'ordonnancement ou de contention de ressources.

La norme recommande d'utiliser une horloge stable (steady clock) pour mesurer la durée. Si une implémentation utilise à la place une horloge système, le temps d'attente peut également être sensible aux ajustements de l'horloge.

Le comportement est indéfini si valid() est false avant l'appel de cette fonction.

Paramètres

  • timeout_duration — durée maximale de blocage

Valeur de retour

Constante Explication

  • future_status::deferred — L'état partagé contient une fonction différée utilisant l'évaluation paresseuse, donc le résultat ne sera calculé que lorsqu'il sera explicitement demandé
  • future_status::ready — Le résultat est prêt
  • future_status::timeout — Le délai d'attente a expiré

Exceptions

Toute exception levée par clock, time_point ou duration pendant l'exécution (les horloges, points temporels et durées fournis par la bibliothèque standard ne lèvent jamais d'exception).

Notes

Les implémentations sont encouragées à détecter le cas où valid == false avant l'appel, et à lever une std::future_error avec une condition d'erreur égale à std::future_errc::no_state.

Exemple

#include <chrono>
#include <future>
#include <iostream>
#include <thread>
using namespace std::chrono_literals;

int main()
{
    std::shared_future<int> future = std::async(std::launch::async, []()
    {
        std::this_thread::sleep_for(3s);
        return 8;
    });

    std::cout << "waiting...\n";
    std::future_status status;

    do
    {
        switch (status = future.wait_for(1s); status)
        {
            case std::future_status::deferred:
                std::cout << "deferred\n";
                break;
            case std::future_status::timeout:
                std::cout << "timeout\n";
                break;
            case std::future_status::ready:
                std::cout << "ready!\n";
                break;
        }
    }
    while (status != std::future_status::ready);

    std::cout << "result is " << future.get() << '\n';
}
