std::counting_semaphore<LeastMaxValue>::release

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void release( std::ptrdiff_t update = 1 );  // (depuis C++20)

Incrémente atomiquement le compteur interne de la valeur de update. Tout thread en attente que le compteur devienne supérieur à 0, par exemple parce qu'il est bloqué dans acquire, sera ensuite débloqué.

Cette opération se produit strictement avant les invocations de try_acquire qui observent le résultat des effets.

Préconditions

update >= 0 et update <= max() - counter sont true, où counter est la valeur du compteur interne.

Paramètres

  • update — la valeur dont il faut incrémenter le compteur interne

Exceptions

Peut lever std::system_error.
