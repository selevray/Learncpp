std::counting_semaphore<LeastMaxValue>::try_acquire_until

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class Clock, class Duration >
bool try_acquire_until( const std::chrono::time_point<Clock, Duration>& abs_time );  // (depuis C++20)

Tente de décrémenter atomiquement le compteur interne de 1 s'il est supérieur à 0 ; sinon bloque jusqu'à ce qu'il soit supérieur à 0 et puisse décrémenter avec succès le compteur interne, ou jusqu'à ce que le point temporel abs_time soit atteint.

Le programme est mal formé si std::chrono::is_clock_v<Clock> est false.

Préconditions

Clock satisfait aux exigences Clock.

Paramètres

  • abs_time — l'instant le plus tôt jusqu'auquel la fonction doit attendre pour échouer

Valeur de retour

true s'il a décrémenté le compteur interne, sinon false.

Exceptions

Peut lever std::system_error ou une exception liée au délai d'attente.

Notes

En pratique, la fonction peut mettre plus de temps que abs_time pour échouer.

  • try_acquire — tente de décrémenter le compteur interne sans bloquer (fonction membre publique)
  • try_acquire_for — tente de décrémenter le compteur interne, en bloquant pendant au plus une durée (fonction membre publique)
