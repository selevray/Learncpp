std::counting_semaphore<LeastMaxValue>::try_acquire

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool try_acquire() noexcept;  // (depuis C++20)

Tente de décrémenter atomiquement le compteur interne de 1 s'il est supérieur à 0 ; aucun blocage n'a lieu dans tous les cas.

Valeur de retour

true s'il a décrémenté le compteur interne, sinon false.

Notes

Les implémentations peuvent ne pas réussir la décrémentation du compteur même s'il était supérieur à 0, c'est-à-dire qu'elles peuvent échouer de façon fallacieuse et renvoyer false.

Voir aussi

  • release — incrémente le compteur interne et débloque les acquéreurs (fonction membre publique)
  • acquire — décrémente le compteur interne ou bloque jusqu'à pouvoir (fonction membre publique)
  • try_acquire_for — tente de décrémenter le compteur interne, en bloquant pendant au plus une durée (fonction membre publique)
  • try_acquire_until — tente de décrémenter le compteur interne, en bloquant jusqu'à un instant donné (fonction membre publique)
