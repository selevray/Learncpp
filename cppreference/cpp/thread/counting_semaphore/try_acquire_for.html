std::counting_semaphore<LeastMaxValue>::try_acquire_for

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class Rep, class Period >
bool try_acquire_for( const std::chrono::duration<Rep, Period>& rel_time );  // (depuis C++20)

Tente de décrémenter atomiquement le compteur interne de 1 s'il est supérieur à 0 ; sinon bloque jusqu'à ce qu'il soit supérieur à 0 et puisse décrémenter avec succès le compteur interne, ou jusqu'à ce que la durée rel_time soit écoulée.

Préconditions

(aucune)

Paramètres

  • rel_time — la durée minimale que la fonction doit attendre avant d'échouer

Valeur de retour

true s'il a décrémenté le compteur interne, sinon false.

Exceptions

Peut lever std::system_error ou une exception liée au délai d'attente.

Notes

En pratique, la fonction peut mettre plus de temps que rel_time pour échouer.

Voir aussi

  • release — incrémente le compteur interne et débloque les acquéreurs (fonction membre publique)
  • acquire — décrémente le compteur interne ou bloque jusqu'à pouvoir (fonction membre publique)
  • try_acquire — tente de décrémenter le compteur interne sans bloquer (fonction membre publique)
  • try_acquire_until — tente de décrémenter le compteur interne, en bloquant jusqu'à un instant donné (fonction membre publique)
