std::future_errc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <future>

enum class future_errc {
    broken_promise             = /* défini par l'implémentation */,
    future_already_retrieved   = /* défini par l'implémentation */,
    promise_already_satisfied  = /* défini par l'implémentation */,
    no_state                   = /* défini par l'implémentation */
};  // (depuis C++11)

L'énumération à portée std::future_errc définit les codes d'erreur signalés par std::future et les classes associées dans les objets d'exception std::future_error. Seuls quatre codes d'erreur sont requis, bien que l'implémentation puisse en définir d'autres. Comme la spécialisation appropriée de std::is_error_code_enum est fournie, les valeurs de type std::future_errc sont implicitement convertibles en std::error_code.

Tous les codes d'erreur sont distincts et non nuls.

Constantes membres

Nom Explication

  • broken_promise — la tâche asynchrone a abandonné son état partagé
  • future_already_retrieved — le contenu de l'état partagé a déjà été accédé via std::future
  • promise_already_satisfied — tentative de stocker une valeur deux fois dans l'état partagé
  • no_state — tentative d'accéder à std::promise ou std::future sans état partagé associé
