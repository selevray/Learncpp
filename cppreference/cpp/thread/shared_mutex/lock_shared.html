std::shared_mutex::lock_shared

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void lock_shared();  // (depuis C++17)

Acquiert la propriété partagée du mutex. Si un autre thread détient le mutex en propriété exclusive, un appel à lock_shared bloquera l'exécution jusqu'à ce que la propriété partagée puisse être acquise.

Si lock_shared est appelé par un thread qui possède déjà le mutex dans n'importe quel mode (exclusif ou partagé), le comportement est indéfini.

Si plus que le nombre maximal défini par l'implémentation de propriétaires partagés ont déjà verrouillé le mutex en mode partagé, lock_shared bloque l'exécution jusqu'à ce que le nombre de propriétaires partagés soit réduit. Le nombre maximal de propriétaires est garanti d'être au moins égal à 10000.

Une opération unlock() antérieure sur le même mutex synchronise-with (tel que défini dans std::memory_order) cette opération.

Paramètres

(aucune)

Valeur de retour

(aucune)

Exceptions

Lève std::system_error lorsque des erreurs surviennent, y compris les erreurs provenant du système d'exploitation sous-jacent qui empêcheraient lock de respecter ses spécifications. Le mutex n'est pas verrouillé si une exception est levée.

Notes

lock_shared() n'est généralement pas appelé directement : std::shared_lock est utilisé pour gérer le verrouillage partagé.

Exemple

#include <chrono>
#include <iostream>
#include <mutex>
#include <shared_mutex>
#include <syncstream>
#include <thread>
#include <vector>

std::mutex stream_mutx;
void print(auto v)
{
    std::unique_lock<std::mutex> lock(stream_mutx);
    std::cout << std::this_thread::get_id() << " saw: ";
    for (auto e : v)
        std::cout << e << ' ';
    std::cout << '\n';
}

int main()
{
    using namespace std::chrono_literals;
    constexpr int N_READERS = 5;
    constexpr int LAST = -999;

    std::shared_mutex smtx;
    int product = 0;

    auto writer = [&smtx, &product](int start, int end)
    {
        for (int i = start; i < end; ++i)
        {
            auto data = i;
            {
                std::unique_lock<std::shared_mutex> lock(smtx);
                product = data;
            }
            std::this_thread::sleep_for(3ms);
        }

        smtx.lock(); // verrouiller manuellement
        product = LAST;
        smtx.unlock();
    };

    auto reader = [&smtx, &product]()
    {
        int data = 0;
        std::vector<int> seen;
        do
        {
            {
                smtx.lock_shared(); // préférable d'utiliser : std::shared_lock lock(smtx);
                data = product;
                smtx.unlock_shared();
            }

            seen.push_back(data);
            std::this_thread::sleep_for(2ms);
        }
        while (data != LAST);

        print(seen);
    };

    std::vector<std::thread> threads;
    threads.emplace_back(writer, 1, 13);
    threads.emplace_back(writer, 42, 52);

    for (int i = 0; i < N_READERS; ++i)
        threads.emplace_back(reader);

    for (auto&& t : threads)
        t.join();
}
