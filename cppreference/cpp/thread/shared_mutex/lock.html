std::shared_mutex::lock

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void lock();  // (depuis C++17)

Acquiert la propriété exclusive du shared_mutex. Si un autre thread détient un verrou exclusif ou un verrou partagé sur le même shared_mutex, un appel à lock bloquera l'exécution jusqu'à ce que tous ces verrous soient libérés. Tant que shared_mutex est verrouillé en mode exclusif, aucun autre verrou, de quelque type que ce soit, ne peut également être détenu.

Si lock est appelé par un thread qui possède déjà le shared_mutex dans n'importe quel mode (exclusif ou partagé), le comportement est indéfini. Une opération unlock() antérieure sur le même mutex synchronise-with (tel que défini dans std::memory_order) cette opération.

Paramètres

(aucune)

Valeur de retour

(aucune)

Exceptions

Lève std::system_error lorsque des erreurs surviennent, y compris les erreurs provenant du système d'exploitation sous-jacent qui empêcheraient lock de respecter ses spécifications. Le mutex n'est pas verrouillé si une exception est levée.

Notes

lock() n'est généralement pas appelée directement : std::unique_lock, std::scoped_lock et std::lock_guard sont utilisés pour gérer le verrouillage exclusif.

Exemple

#include <chrono>
#include <iostream>
#include <mutex>
#include <shared_mutex>
#include <syncstream>
#include <thread>
#include <vector>

std::mutex stream_mutx;
void print(auto const& v)
{
    std::unique_lock<std::mutex> lock(stream_mutx);
    std::cout << std::this_thread::get_id() << " saw: ";
    for (auto e : v)
        std::cout << e << ' ';
    std::cout << '\n';
}

int main()
{
    using namespace std::chrono_literals;
    constexpr int N_READERS = 5;
    constexpr int LAST = -999;

    std::shared_mutex smtx;
    int product = 0;

    auto writer = [&smtx, &product](int start, int end)
    {
        for (int i = start; i < end; ++i)
        {
            auto data = i;
            {
                std::unique_lock<std::shared_mutex> lock(smtx); // préférable à :
                                                                // smtx.lock();
                product = data;
            }
            std::this_thread::sleep_for(3ms);
        }

        smtx.lock(); // verrouiller manuellement
        product = LAST;
        smtx.unlock();
    };

    auto reader = [&smtx, &product]
    {
        int data = 0;
        std::vector<int> seen;
        do
        {
            {
                // préférable d'utiliser :
                std::shared_lock lock(smtx); // smtx.lock_shared();
                data = product;
            }                                // smtx.unlock_shared();

            seen.push_back(data);
            std::this_thread::sleep_for(2ms);
        }
        while (data != LAST);

        print(seen);
    };

    std::vector<std::thread> threads;
    threads.emplace_back(writer, 1, 13);
    threads.emplace_back(writer, 42, 52);

    for (int i = 0; i < N_READERS; ++i)
        threads.emplace_back(reader);

    for (auto&& t : threads)
        t.join();
}
