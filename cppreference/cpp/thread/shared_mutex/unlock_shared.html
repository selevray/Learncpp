std::shared_mutex::unlock_shared

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void unlock_shared();  // (depuis C++17)

Libère le mutex de la propriété partagée détenue par le thread appelant.

Le mutex doit être verrouillé par le thread d'exécution courant en mode partagé, sinon le comportement est indéfini.

Cette opération synchronise-with (tel que défini dans std::memory_order) toute opération lock() ultérieure qui obtient la propriété du même mutex.

Paramètres

(aucune)

Valeur de retour

(aucune)

Exceptions

Ne lève aucune exception.

Notes

unlock_shared() n'est généralement pas appelé directement : std::shared_lock est utilisé pour gérer le verrouillage partagé.
