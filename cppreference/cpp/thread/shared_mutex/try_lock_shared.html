std::shared_mutex::try_lock_shared

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool try_lock_shared();  // (depuis C++17)

Tente de verrouiller le mutex en mode partagé. Renvoie immédiatement. En cas d'acquisition réussie du verrou, renvoie true, sinon renvoie false.

Cette fonction peut échouer de façon fortuite et renvoyer false même si le mutex n'est actuellement verrouillé en exclusif par aucun autre thread.

Une opération unlock() antérieure sur le même mutex synchronise-with (tel que défini dans std::memory_order) cette opération si elle renvoie true.

Le comportement est indéfini si le thread appelant possède déjà le mutex, quel que soit le mode.

Paramètres

(aucune)

Valeur de retour

true si le verrou a été acquis avec succès, sinon false.

Exceptions

Ne lève aucune exception.
