friend bool operator==( const stop_source& lhs, const stop_source& rhs ) noexcept;  // (depuis C++20)

Compare deux valeurs stop_source.

Cette fonction n'est pas visible par une recherche non qualifiée ou qualifiée ordinaire, et ne peut être trouvée que par recherche dépendante de l'argument lorsque std::stop_source est une classe associée aux arguments.

L'opérateur != est synthétisé à partir de operator==.

Paramètres

  • lhs, rhs — stop_source à comparer

Valeur de retour

true si lhs et rhs ont le même état d'arrêt, ou ne possèdent tous deux aucun état d'arrêt ; sinon false.
