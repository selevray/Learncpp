std::stop_source::request_stop

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool request_stop() noexcept;  // (depuis C++20)

Émet une demande d'arrêt sur l'état d'arrêt, si l'objet stop_source possède un état d'arrêt et qu'aucune demande d'arrêt n'a encore été faite.

La détermination est effectuée de manière atomique, et si l'arrêt a été demandé, l'état d'arrêt est mis à jour atomiquement afin d'éviter les situations de concurrence, de sorte que :

  • stop_requested() et stop_possible() peuvent être invoqués de façon concurrente sur d'autres stop_token et stop_source du même état d'arrêt ;
  • request_stop() peut être invoqué de façon concurrente sur d'autres objets stop_source, et un seul effectuera réellement la demande d'arrêt.

Voir toutefois la section Notes.

Paramètres

(aucune)

Valeur de retour

true si l'objet stop_source possède un état d'arrêt et que cette invocation a émis une demande d'arrêt, sinon false.

Postconditions

stop_possible() est false ou stop_requested() est true.

Notes

Si request_stop() émet effectivement une demande d'arrêt (c.-à-d. renvoie true), alors tous les stop_callback enregistrés pour le même état d'arrêt associé seront invoqués de façon synchrone, sur le même thread que celui sur lequel request_stop() est émis. Si l'invocation d'un rappel se termine par une exception, std::terminate est appelé.

Si l'objet stop_source possède un état d'arrêt mais qu'une demande d'arrêt a déjà été faite, cette fonction renvoie false. Toutefois, rien ne garantit qu'un autre objet stop_source qui vient de demander (avec succès) l'arrêt ne soit pas encore en train d'invoquer une fonction stop_callback.

Si request_stop() émet effectivement une demande d'arrêt (c.-à-d. renvoie true), alors toutes les variables de condition de type de base std::condition_variable_any enregistrées avec une attente interruptible pour des stop_token associés à l'état d'arrêt de stop_source seront notifiées.
