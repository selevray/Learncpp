std::stop_token get_token() const noexcept;  // (depuis C++20)

Renvoie un objet stop_token associé à l'état d'arrêt de stop_source, si stop_source possède un état d'arrêt ; sinon renvoie un stop_token construit par défaut (vide).

Paramètres

(aucune)

Valeur de retour
