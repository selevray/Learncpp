std::unique_lock

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <mutex>

template< class Mutex >
class unique_lock;  // (depuis C++11)

La classe unique_lock est un wrapper de propriété de mutex à usage général, permettant le verrouillage différé, les tentatives de verrouillage limitées dans le temps, le verrouillage récursif, le transfert de propriété du verrou et l'utilisation avec les variables de condition.

La classe unique_lock est déplaçable mais non copiable -- elle satisfait les exigences de MoveConstructible et MoveAssignable mais pas celles de CopyConstructible ou CopyAssignable.

La classe unique_lock satisfait les exigences BasicLockable. Si Mutex satisfait les exigences Lockable, unique_lock satisfait aussi les exigences Lockable (par ex. : peut être utilisé dans std::lock) ; si Mutex satisfait les exigences TimedLockable, unique_lock satisfait aussi les exigences TimedLockable.

Paramètres de modèle

  • Mutex — le type du mutex à verrouiller. Le type doit satisfaire aux exigences BasicLockable

Types imbriqués

Type Définition

  • mutex_type — Mutex

Fonctions membres

  • (constructeur) — construit un unique_lock, en verrouillant éventuellement (c.-à-d. en en acquérant la propriété) le mutex fourni (fonction membre publique)
  • (destructeur) — déverrouille (c.-à-d. abandonne la propriété de) le mutex associé, s'il est possédé (fonction membre publique)
  • operator= — déverrouille (c.-à-d. abandonne la propriété de) le mutex, s'il est possédé, et en acquiert la propriété d'un autre (fonction membre publique)

##### Verrouillage {#Locking}

  • lock — verrouille (c.-à-d. en acquiert la propriété) le mutex associé (fonction membre publique)
  • try_lock — tente de verrouiller (c.-à-d. prend la propriété de) le mutex associé sans bloquer (fonction membre publique)
  • try_lock_for — tente de verrouiller (c.-à-d. d'en acquérir la propriété) le mutex associé TimedLockable, retourne si le mutex est resté indisponible pendant la durée spécifiée (fonction membre publique)
  • try_lock_until — tente de verrouiller (c.-à-d. d'en acquérir la propriété) le mutex associé TimedLockable, retourne si le mutex est resté indisponible jusqu'à ce que le point temporel spécifié soit atteint (fonction membre publique)
  • unlock — déverrouille (c.-à-d. libère la propriété de) le mutex associé (fonction membre publique)

##### Modificateurs {#Modifiers}

  • swap — échange l'état avec un autre std::unique_lock (fonction membre publique)
  • release — dissocie le mutex associé sans le déverrouiller (c.-à-d. sans en abandonner la propriété) (fonction membre publique)

##### Observateurs {#Observers}

  • mutex — renvoie un pointeur vers le mutex associé (fonction membre publique)
  • owns_lock — teste si le verrou possède (c.-à-d. a verrouillé) son mutex associé (fonction membre publique)
  • operator bool — teste si le verrou possède (c.-à-d. a verrouillé) son mutex associé (fonction membre publique)

Fonctions non membres

  • std::swap(std::unique_lock) (C++11) — spécialise l'algorithme std::swap (modèle de fonction)

Exemple

#include <iostream>
#include <mutex>
#include <thread>

struct Box
{
    explicit Box(int num) : num_things{num} {}

    int num_things;
    std::mutex m;
};

void transfer(Box& from, Box& to, int num)
{
    // ne prend pas encore réellement les verrous
    std::unique_lock lock1{from.m, std::defer_lock};
    std::unique_lock lock2{to.m, std::defer_lock};

    // verrouille les deux unique_locks sans interblocage
    std::lock(lock1, lock2);

    from.num_things -= num;
    to.num_things += num;

    // les mutex « from.m » et « to.m » sont déverrouillés dans les destructeurs de unique_lock
}

int main()
{
    Box acc1{100};
    Box acc2{50};

    std::thread t1{transfer, std::ref(acc1), std::ref(acc2), 10};
    std::thread t2{transfer, std::ref(acc2), std::ref(acc1), 5};

    t1.join();
    t2.join();

    std::cout << "acc1: " << acc1.num_things << "\n"
                 "acc2: " << acc2.num_things << '\n';
}

Output:

acc1: 95
acc2: 55
