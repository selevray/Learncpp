std::packaged_task

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <future>

template< class > class packaged_task; //non défini  // (1) (depuis C++11)

template< class R, class ...ArgTypes >
class packaged_task<R(ArgTypes...)>;  // (2) (depuis C++11)

Le modèle de classe std::packaged_task encapsule toute cible Callable (fonction, expression lambda, expression bind ou un autre objet fonction) afin qu'elle puisse être invoquée de manière asynchrone. Sa valeur de retour ou l'exception levée est stockée dans un état partagé auquel on peut accéder via des objets std::future.

Comme std::function, std::packaged_task est un conteneur polymorphe compatible avec les allocateurs : la cible appelable stockée peut être allouée sur le tas ou avec un allocateur fourni.

(jusqu'à C++17)

Guides de déduction (depuis C++17)

Exemple

#include <cmath>
#include <functional>
#include <future>
#include <iostream>
#include <thread>

// fonction unique pour éviter la désambiguïsation de l'ensemble de surcharges de std::pow
int f(int x, int y) { return std::pow(x, y); }

void task_lambda()
{
    std::packaged_task<int(int, int)> task([](int a, int b)
    {
        return std::pow(a, b);
    });
    std::future<int> result = task.get_future();

    task(2, 9);

    std::cout << "task_lambda:\t" << result.get() << '\n';
}

void task_bind()
{
    std::packaged_task<int()> task(std::bind(f, 2, 11));
    std::future<int> result = task.get_future();

    task();

    std::cout << "task_bind:\t" << result.get() << '\n';
}

void task_thread()
{
    std::packaged_task<int(int, int)> task(f);
    std::future<int> result = task.get_future();

    std::thread task_td(std::move(task), 2, 10);
    task_td.join();

    std::cout << "task_thread:\t" << result.get() << '\n';
}

int main()
{
    task_lambda();
    task_bind();
    task_thread();
}

Output:

task_lambda: 512
task_bind:   2048
task_thread: 1024
