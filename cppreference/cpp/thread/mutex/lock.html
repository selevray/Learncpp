std::mutex::lock

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void lock();  // (depuis C++11)

Verrouille le mutex. Si un autre thread a déjà verrouillé le mutex, un appel à lock bloquera l'exécution jusqu'à ce que le verrou soit acquis.

Si lock est appelé par un thread qui possède déjà le mutex, le comportement est indéfini : par exemple, le programme peut se bloquer (interblocage). Une implémentation capable de détecter cette utilisation invalide est encouragée à lever une std::system_error avec la condition d'erreur resource_deadlock_would_occur au lieu de se bloquer.

Les opérations unlock() antérieures sur le même mutex se synchronisent avec (tel que défini dans std::memory_order) cette opération.

Paramètres

(aucune)

Valeur de retour

(aucune)

Exceptions

Lève std::system_error lorsque des erreurs surviennent, y compris les erreurs provenant du système d'exploitation sous-jacent qui empêcheraient lock de respecter ses spécifications. Le mutex n'est pas verrouillé si une exception est levée.

Notes

lock() n'est généralement pas appelée directement : std::unique_lock, std::scoped_lock et std::lock_guard sont utilisés pour gérer le verrouillage exclusif.

Exemple

Cet exemple montre comment lock et unlock peuvent être utilisés pour protéger des données partagées.

#include <chrono>
#include <iostream>
#include <mutex>
#include <thread>

int g_num = 0; // protégé par g_num_mutex
std::mutex g_num_mutex;

void slow_increment(int id)
{
    for (int i = 0; i < 3; ++i)
    {
        g_num_mutex.lock();
        ++g_num;
        // notez que le mutex synchronise aussi la sortie
        std::cout << "id: " << id << ", g_num: " << g_num << '\n';
        g_num_mutex.unlock();

        std::this_thread::sleep_for(std::chrono::milliseconds(234));
    }
}

int main()
{
    std::thread t1{slow_increment, 0};
    std::thread t2{slow_increment, 1};
    t1.join();
    t2.join();
}

Sortie possible :

id: 0, g_num: 1
id: 1, g_num: 2
id: 1, g_num: 3
id: 0, g_num: 4
id: 0, g_num: 5
id: 1, g_num: 6
