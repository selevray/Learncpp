constexpr mutex() noexcept;  // (1) (depuis C++11)

mutex( const mutex& ) = delete;  // (2) (depuis C++11)

  1. Construit le mutex. Le mutex est à l'état déverrouillé après la fin du constructeur.

  2. Le constructeur de copie est supprimé.

Paramètres

(aucune)

Notes

Comme le constructeur par défaut est constexpr, les mutex statiques sont initialisés dans le cadre de l'initialisation statique non locale, avant que toute initialisation dynamique non locale ne commence. Cela permet de verrouiller un mutex en toute sécurité dans le constructeur de n'importe quel objet statique.
