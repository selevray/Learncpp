std::mutex::unlock

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void unlock();  // (depuis C++11)

Déverrouille le mutex.

Le mutex doit être verrouillé par le thread d'exécution courant, sinon le comportement est indéfini.

Cette opération se synchronise avec (tel que défini dans std::memory_order) toute opération de verrouillage ultérieure qui obtient la propriété du même mutex.

Paramètres

(aucune)

Valeur de retour

(aucune)

Exceptions

Ne lève aucune exception.

Notes

unlock() n'est généralement pas appelée directement : std::unique_lock et std::lock_guard sont utilisés pour gérer le verrouillage exclusif.

Exemple

Cet exemple montre comment lock et unlock peuvent être utilisés pour protéger des données partagées.

#include <chrono>
#include <iostream>
#include <mutex>
#include <thread>

int g_num = 0; // protégé par g_num_mutex
std::mutex g_num_mutex;

void slow_increment(int id)
{
    for (int i = 0; i < 3; ++i)
    {
        g_num_mutex.lock();
        int g_num_running = ++g_num;
        g_num_mutex.unlock();
        std::cout << id << " => " << g_num_running << '\n';

        std::this_thread::sleep_for(std::chrono::seconds(1));
    }
}

int main()
{
    std::thread t1(slow_increment, 0);
    std::thread t2(slow_increment, 1);
    t1.join();
    t2.join();
}

Sortie possible :

0 => 1
1 => 2
0 => 3
1 => 4
0 => 5
1 => 6
