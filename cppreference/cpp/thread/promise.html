std::promise

template< class R > class promise<R&>;  // (2) (depuis C++11)

template<> class promise<void>;  // (3) (depuis C++11)

  1. Modèle de base.

  2. Spécialisation non void, utilisée pour communiquer des objets entre threads.

  3. Spécialisation void, utilisée pour communiquer des événements sans état.

Le modèle de classe std::promise fournit un mécanisme pour stocker une valeur ou une exception, récupérée ultérieurement de manière asynchrone via un objet std::future créé par l'objet std::promise. Notez que l'objet std::promise ne doit être utilisé qu'une seule fois.

Chaque promesse est associée à un état partagé, qui contient des informations d'état et un résultat qui peut ne pas être encore évalué, évalué à une valeur (éventuellement void) ou évalué à une exception. Une promesse peut effectuer trois opérations sur l'état partagé :

  • mise à l'état prêt : la promesse stocke le résultat ou l'exception dans l'état partagé. Marque l'état comme prêt et débloque tout thread en attente d'un futur associé à l'état partagé.
  • libère : la promesse abandonne sa référence à l'état partagé. Si c'était la dernière référence de ce type, l'état partagé est détruit. Sauf s'il s'agit d'un état partagé créé par std::async qui n'est pas encore prêt, cette opération ne bloque pas.
  • abandonne : la promesse stocke l'exception de type std::future_error avec le code d'erreur std::future_errc::broken_promise, rend l'état partagé prêt, puis le libère.

La promesse est l'extrémité « push » du canal de communication promesse-futur : l'opération qui stocke une valeur dans l'état partagé se synchronise avec (comme défini dans std::memory_order) le retour réussi de toute fonction qui attend l'état partagé (comme std::future::get). Un accès concurrent au même état partagé peut autrement entrer en conflit : par exemple, plusieurs appelants de std::shared_future::get doivent soit tous être en lecture seule, soit fournir une synchronisation externe.

Fonctions membres

  • (constructeur) — construit l'objet promesse (fonction membre publique)
  • (destructeur) — détruit l'objet promesse (fonction membre publique)
  • operator= — affecte l'état partagé (fonction membre publique)
  • swap — échange deux objets promise (fonction membre publique)

##### Obtention du résultat {#Getting_the_result}

  • get_future — renvoie un future associé au résultat promis (fonction membre publique)

##### Définition du résultat {#Setting_the_result}

  • set_value — définit le résultat à une valeur spécifique (fonction membre publique)
  • set_value_at_thread_exit — définit le résultat à une valeur spécifique tout en ne livrant la notification qu'à la sortie du thread (fonction membre publique)
  • set_exception — définit le résultat pour indiquer une exception (fonction membre publique)
  • set_exception_at_thread_exit — définit le résultat pour indiquer une exception tout en ne livrant la notification qu'à la sortie du thread (fonction membre publique)

Exemple

Cet exemple montre comment promise<int> peut être utilisé comme signaux entre threads.

#include <chrono>
#include <future>
#include <iostream>
#include <numeric>
#include <thread>
#include <vector>

void accumulate(std::vector<int>::iterator first,
                std::vector<int>::iterator last,
                std::promise<int> accumulate_promise)
{
    int sum = std::accumulate(first, last, 0);
    accumulate_promise.set_value(sum); // Notifier le futur
}

void do_work(std::promise<void> barrier)
{
    std::this_thread::sleep_for(std::chrono::seconds(1));
    barrier.set_value();
}

int main()
{
    // Démontre l'utilisation de promise<int> pour transmettre un résultat entre threads.
    std::vector<int> numbers = {1, 2, 3, 4, 5, 6};
    std::promise<int> accumulate_promise;
    std::future<int> accumulate_future = accumulate_promise.get_future();
    std::thread work_thread(accumulate, numbers.begin(), numbers.end(),
                            std::move(accumulate_promise));

    // future::get() attendra jusqu'à ce que le futur ait un résultat valide et le récupère.
    // Appeler wait() avant get() n'est pas nécessaire
    // accumulate_future.wait(); // attendre le résultat
    std::cout << "result=" << accumulate_future.get() << '\n';
    work_thread.join(); // attendre la fin du thread

    // Démontre l'utilisation de promise<void> pour signaler un état entre threads.
    std::promise<void> barrier;
    std::future<void> barrier_future = barrier.get_future();
    std::thread new_work_thread(do_work, std::move(barrier));
    barrier_future.wait();
    new_work_thread.join();
}

Output:

result=21
