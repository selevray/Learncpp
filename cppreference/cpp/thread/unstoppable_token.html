std::unstoppable_token

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stop_token>

template< class Token >
concept unstoppable_token =
    std::stoppable_token<Token> &&
    requires (const Token tok) {
        requires std::bool_constant<(!tok.stop_possible())>::value;
    };  // (depuis C++26)

Le concept unstoppable_token<Token> spécifie une exigence supplémentaire pour un stoppable_token dont le type ne permet pas l'arrêt. C'est-à-dire que l'expression tok.stop_possible() doit pouvoir être utilisée dans une expression constante et retourne false.
