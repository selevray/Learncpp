std::launch

Défini dans l'en-tête <future>

enum class launch : /* unspecified */ {
    async =    /* unspecified */,
    deferred = /* unspecified */,
    /* défini par l'implémentation */
};  // (depuis C++11)

std::launch est un BitmaskType. Il spécifie la politique de lancement pour une tâche exécutée par la fonction std::async.

Constantes

Les constantes suivantes, désignant des bits individuels, sont définies par la bibliothèque standard :

Nom Explication

  • async — la tâche est exécutée dans un thread différent, éventuellement en la créant et en la lançant d'abord
  • deferred — la tâche est exécutée dans le thread appelant lors de la première demande de son résultat (évaluation paresseuse)

De plus, les implémentations sont autorisées à :

  • définir des bits et masques de bits supplémentaires pour spécifier des restrictions sur les interactions entre tâches applicables à un sous-ensemble des politiques de lancement, et
  • activer ces masques de bits supplémentaires pour la première surcharge (par défaut) de std::async.
