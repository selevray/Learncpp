std::lock_guard

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <mutex>

template< class Mutex >
class lock_guard;  // (depuis C++11)

La classe lock_guard est un wrapper de mutex qui fournit un mécanisme pratique de type RAII pour posséder un mutex pendant la durée d'un bloc de portée.

Lorsqu'un objet lock_guard est créé, il tente de prendre la propriété du mutex qui lui est donné. Lorsque le contrôle quitte la portée dans laquelle l'objet lock_guard a été créé, le lock_guard est détruit et le mutex est libéré.

La classe lock_guard n'est pas copiable.

Paramètres de modèle

  • Mutex — le type du mutex à verrouiller. Le type doit satisfaire aux exigences BasicLockable

Types membres

Type membre Définition

  • mutex_type — Mutex

Fonctions membres

  • (constructeur) — construit un lock_guard, en verrouillant éventuellement le mutex donné (fonction membre publique)
  • (destructeur) — détruit l'objet lock_guard, déverrouille le mutex sous-jacent (fonction membre publique)
  • operator=[deleted] — non copiable par affectation (fonction membre publique)

Notes

Une erreur courante chez les débutants consiste à « oublier » de donner un nom à une variable lock_guard, par exemple std::lock_guard(mtx); (qui construit par défaut un objet lock_guard nommé mtx) ou std::lock_guard{mtx}; (qui construit un objet prvalue immédiatement détruit), ce qui fait qu'aucun verrou détenant un mutex n'est réellement construit pour le reste de la portée.

std::scoped_lock offre une alternative à lock_guard qui permet de verrouiller plusieurs mutex à l'aide d'un algorithme d'évitement d'interblocage.

(depuis C++17)

Exemple

Démontre des incréments sûrs et non sûrs d'une variable volatile par deux threads.

#include <iostream>
#include <mutex>
#include <string_view>
#include <syncstream>
#include <thread>

volatile int g_i = 0;
std::mutex g_i_mutex;  // protège g_i

void safe_increment(int iterations)
{
    const std::lock_guard<std::mutex> lock(g_i_mutex);
    while (iterations-- > 0)
        g_i = g_i + 1;
    std::cout << "thread #" << std::this_thread::get_id() << ", g_i: " << g_i << '\n';

    // g_i_mutex est automatiquement libéré lorsque lock sort de portée
}

void unsafe_increment(int iterations)
{
    while (iterations-- > 0)
        g_i = g_i + 1;
    std::osyncstream(std::cout) << "thread #" << std::this_thread::get_id()
                                << ", g_i: " << g_i << '\n';
}

int main()
{
    auto test = [](std::string_view fun_name, auto fun)
    {
        g_i = 0;
        std::cout << fun_name << ":\nbefore, g_i: " << g_i << '\n';
        {
            std::jthread t1(fun, 1'000'000);
            std::jthread t2(fun, 1'000'000);
        }
        std::cout << "after, g_i: " << g_i << "\n\n";
    };
    test("safe_increment", safe_increment);
    test("unsafe_increment", unsafe_increment);
}
