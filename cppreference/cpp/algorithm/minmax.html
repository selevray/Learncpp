Renvoie le plus petit et le plus grand des valeurs données.

1,2) Renvoie des références vers le plus petit et le plus grand de a et b.

  1. Utilise operator< pour comparer les valeurs.

Si T n'est pas LessThanComparable, le comportement est indéfini.

  1. Utilise la fonction de comparaison comp pour comparer les valeurs.

3,4) Renvoie le plus petit et le plus grand des valeurs de la liste d'initialisation ilist.

Si ilist.size() vaut zéro, ou si T n'est pas CopyConstructible, le comportement est indéfini.

  1. Utilise operator< pour comparer les valeurs.

Si T n'est pas LessThanComparable, le comportement est indéfini.

  1. Utilise la fonction de comparaison comp pour comparer les valeurs.

Paramètres

  • a, b — les valeurs à comparer

  • ilist — liste d'initialisation contenant les valeurs à comparer

  • comp — objet fonction de comparaison (c'est-à-dire un objet qui satisfait aux exigences de Compare) qui renvoie true si le premier argument est inférieur au second.

    La signature de la fonction de comparaison doit être équivalente à la suivante :

    bool cmp(const Type1& a, const Type2& b);

    Bien que la signature n'ait pas besoin de const&, la fonction ne doit pas modifier les objets qui lui sont passés et doit pouvoir accepter toutes les valeurs de type (éventuellement const) Type1 et Type2, quelle que soit la catégorie de valeur (ainsi, Type1& n'est pas autorisé, pas plus que Type1, sauf si pour Type1 un déplacement est équivalent à une copie (depuis C++11)).
    Les types Type1 et Type2 doivent être tels qu'un objet de type T puisse être converti implicitement vers chacun d'eux.

Valeur de retour

1,2) Renvoie le résultat de std::pair<const T&, const T&>(a, b) si a < b ou si a est équivalent à b. Renvoie le résultat de std::pair<const T&, const T&>(b, a) si b < a.

3,4) Une paire dont le premier élément est la plus petite valeur de ilist et dont le second est la plus grande. Si plusieurs éléments sont équivalents au plus petit, celui le plus à gauche est renvoyé. Si plusieurs éléments sont équivalents au plus grand, celui le plus à droite est renvoyé.

Complexité

  1. Exactement une comparaison utilisant operator<.

  2. Exactement une application de la fonction de comparaison comp.

Implémentation possible

minmax (1)

template<class T>
constexpr std::pair<const T&, const T&> minmax(const T& a, const T& b)
{
    return (b < a) ? std::pair<const T&, const T&>(b, a)
                   : std::pair<const T&, const T&>(a, b);
}

minmax (2)

template<class T, class Compare>
constexpr std::pair<const T&, const T&> minmax(const T& a, const T& b, Compare comp)
{
    return comp(b, a) ? std::pair<const T&, const T&>(b, a)
                      : std::pair<const T&, const T&>(a, b);
}

minmax (3)

template<class T>
constexpr std::pair<T, T> minmax(std::initializer_list<T> ilist)
{
    auto p = std::minmax_element(ilist.begin(), ilist.end());
    return std::pair(*p.first, *p.second);
}

minmax (4)

template<class T, class Compare>
constexpr std::pair<T, T> minmax(std::initializer_list<T> ilist, Compare comp)
{
    auto p = std::minmax_element(ilist.begin(), ilist.end(), comp);
    return std::pair(*p.first, *p.second);
}

Notes

Pour les surcharges (1,2), si l'un des paramètres est un temporaire, la référence renvoyée devient une référence pendante à la fin de l'expression complète contenant l'appel à minmax :

int n = 1;
auto p = std::minmax(n, n + 1);
int m = p.first; // ok
int x = p.second; // comportement indéfini

// Notez que les liaisons structurées ont le même problème
auto [mm, xx] = std::minmax(n, n + 1);
xx; // comportement indéfini

Exemple

#include <algorithm>
#include <cstdlib>
#include <ctime>
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> v{3, 1, 4, 1, 5, 9, 2, 6};
    std::srand(std::time(0));
    std::pair<int, int> bounds = std::minmax(std::rand() % v.size(),
                                             std::rand() % v.size());

    std::cout << "v[" << bounds.first << "," << bounds.second << "]: ";
    for (int i = bounds.first; i < bounds.second; ++i)
        std::cout << v[i] << ' ';
    std::cout << '\n';
}

Sortie possible :

v[2,7]: 4 1 5 9 2
