template< class T >
void swap( T& a, T& b );  // (1) (conditionnellement noexcept depuis C++11) (constexpr depuis C++20)

template< class T2, std::size_t N >
void swap( T2 (&a)[N], T2 (&b)[N] );  // (2) (conditionnellement noexcept depuis C++11) (constexpr depuis C++20)

Échange les valeurs données.

  1. Échange les valeurs a et b.

Cette surcharge ne participe à la résolution de surcharge que si std::is_move_constructible_v<T> && std::is_move_assignable_v<T> est true.

(depuis C++17)

  1. Échange les tableaux a et b. Équivalent à std::swap_ranges(a, a + N, b).

Cette surcharge ne participe à la résolution de surcharge que si std::is_swappable_v<T2> est true.

(depuis C++17)

Paramètres

  • a, b — les valeurs à échanger

Exigences sur les types

  • T doit satisfaire les exigences de [ CopyConstructible et CopyAssignable (jusqu'à C++11) | MoveConstructible et MoveAssignable (depuis C++11)].
  • T2 doit satisfaire aux exigences de Swappable.

Valeur de retour

(aucune)

Exceptions

(aucune)

(jusqu'à C++11)

noexcept specification:noexcept( std::is_nothrow_move_constructible<T>::value && std::is_nothrow_move_assignable<T>::value )

(depuis C++11)

noexcept specification:noexcept(noexcept(swap(*a, *b)))La recherche de l'identifiant swap dans la spécification d'exception trouve ce modèle de fonction en plus de tout ce que trouvent les règles de recherche habituelles, rendant la spécification d'exception équivalente à C++17 std::is_nothrow_swappable.

(depuis C++11) (jusqu'à C++17)

noexcept specification:noexcept(std::is_nothrow_swappable_v<T2>)

(depuis C++17)

Complexité

  1. Constante.

  2. Linéaire en N.

Spécialisations

std::swap peut être spécialisé dans l'espace de noms std pour des types définis par le programme, mais de telles spécialisations ne sont pas trouvées par ADL (l'espace de noms std n'est pas l'espace de noms associé au type défini par le programme).

(jusqu'à C++20)

La manière attendue de rendre un type défini par le programme échangeable est de fournir une fonction non membre swap dans le même espace de noms que le type : voir Swappable pour plus de détails.

Exemple

#include <algorithm>
#include <iostream>

namespace Ns
{
    class A
    {
        int id {};

        friend void swap(A& lhs, A& rhs)
        {
            std::cout << "swap(" << lhs << ", " << rhs << ")\n";
            std::swap(lhs.id, rhs.id);
        }

        friend std::ostream& operator<<(std::ostream& os, A const& a)
        {
            return os << "A::id=" << a.id;
        }

    public:
        A(int i) : id {i} {}
        A(A const&) = delete;
        A& operator = (A const&) = delete;
    };
}

int main()
{
    int a = 5, b = 3;
    std::cout << a << ' ' << b << '\n';
    std::swap(a, b);
    std::cout << a << ' ' << b << '\n';

    Ns::A p {6}, q {9};
    std::cout << p << ' ' << q << '\n';
//  std::swap(p, q); // erreur, les exigences sur les types ne sont pas satisfaites
    swap(p, q);      // OK, ADL trouve le `swap` ami approprié
    std::cout << p << ' ' << q << '\n';
}

Output:

5 3
3 5
A::id=6 A::id=9
swap(A::id=6, A::id=9)
A::id=9 A::id=6

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 227 C++98 T n'était pas tenu d'être CopyConstructible ou DefaultConstructible (un objet temporaire de type T pourrait ne pas pouvoir être construit) T doit également être CopyConstructible
LWG 809 C++98 les tableaux ne pouvaient pas être échangés ajout de la surcharge (2)
LWG 2554 C++11 l'échange de tableaux multidimensionnels ne peut jamais être noexcept en raison de problèmes de recherche de noms rendu fonctionnel
