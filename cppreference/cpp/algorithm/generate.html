std::generate

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <algorithm>

template< class ForwardIt, class Generator >
void generate( ForwardIt first, ForwardIt last, Generator g );  // (1) (constexpr depuis C++20)

template< class ExecutionPolicy, class ForwardIt, class Generator >
void generate( ExecutionPolicy&& policy,
               ForwardIt first, ForwardIt last, Generator g );  // (2) (depuis C++17)

  1. Affecte à chaque élément de l'intervalle [first,last) une valeur générée par l'objet fonction générateur donné g.

  2. Identique à (1), mais exécuté selon policy.

Cette surcharge ne participe à la résolution de surcharge que si toutes les conditions suivantes sont satisfaites :

std::is_execution_policy_v<std::decay_t<ExecutionPolicy>> is true.

(jusqu'à C++20)

std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>> is true.

(depuis C++20)

Paramètres

  • first, last — l'intervalle d'éléments à générer

  • policy — la politique d'exécution à utiliser

  • g — objet fonction générateur qui sera appelé.

    La signature de la fonction doit être équivalente à la suivante :

    Ret fun();

    Le type Ret doit être tel qu'un objet de type ForwardIt puisse être déréférencé et qu'on puisse lui affecter une valeur de type Ret.

Exigences sur les types

  • ForwardIt doit satisfaire aux exigences de LegacyForwardIterator.

Complexité

Exactement std::distance(first, last) invocations de g() et affectations.

Exceptions

La surcharge avec un paramètre de modèle nommé ExecutionPolicy signale les erreurs comme suit :

  • Si l'exécution d'une fonction invoquée dans le cadre de l'algorithme lève une exception et ExecutionPolicy est l'une des politiques standard, std::terminate est appelée. Pour toute autre ExecutionPolicy, le comportement est défini par l'implémentation.
  • Si l'algorithme échoue à allouer de la mémoire, std::bad_alloc est levée.

Implémentation possible

template<class ForwardIt, class Generator>
constexpr //< depuis C++20
void generate(ForwardIt first, ForwardIt last, Generator g)
{
    for (; first != last; ++first)
        *first = g();
}

Exemple

#include <algorithm>
#include <iostream>
#include <vector>

void println(std::string_view fmt, const auto& v)
{
    for (std::cout << fmt; const auto& e : v)
        std::cout << e << ' ';
    std::cout << '\n';
};

int f()
{
    static int i;
    return ++i;
}

int main()
{
    std::vector<int> v(5);

    std::generate(v.begin(), v.end(), f);
    println("v: ", v);

    // Initialise avec les valeurs par défaut 0,1,2,3,4 à partir d'une fonction lambda
    // Équivalent à std::iota(v.begin(), v.end(), 0);
    std::generate(v.begin(), v.end(), [n = 0] () mutable { return n++; });
    println("v: ", v);
}

Output:

v: 1 2 3 4 5
v: 0 1 2 3 4
