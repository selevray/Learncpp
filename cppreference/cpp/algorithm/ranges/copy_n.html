Type auxiliaire

template< class I, class O >
using copy_n_result = ranges::in_out_result<I, O>;  // (2) (depuis C++20)
  1. Copie exactement n valeurs de l'intervalle commençant à first vers l'intervalle commençant à result en effectuant *(result + i) = *(first + i) pour chaque entier dans [0,n). Le comportement est indéfini si result se trouve dans l'intervalle [first,first + n) (ranges::copy_backward peut être utilisé à la place dans ce cas).

Les entités de type fonction décrites sur cette page sont des objets fonctions d'algorithme (appelés de manière informelle niebloids), c'est-à-dire :

  • Les listes d'arguments de modèle explicites ne peuvent pas être spécifiées lors de l'appel de l'un d'entre eux.
  • Aucun d'entre eux n'est visible par la recherche dépendante des arguments.
  • Lorsque l'un d'entre eux est trouvé par la recherche non qualifiée normale comme nom situé à gauche de l'opérateur d'appel de fonction, la recherche dépendante des arguments est inhibée.

Paramètres

  • first — le début de la plage des éléments à copier
  • n — nombre d'éléments à copier
  • result — le début de l'intervalle de destination

Valeur de retour

ranges::copy_n_result{first + n, result + n} ou, plus formellement, une valeur de type ranges::in_out_result qui contient un itérateur std::input_iterator égal à ranges::next(first, n) et un itérateur std::weakly_incrementable égal à ranges::next(result, n).

Complexité

Exactement n affectations.

Notes

En pratique, les implémentations de std::ranges::copy_n peuvent éviter les affectations multiples et utiliser des fonctions de copie en bloc telles que std::memmove si le type de valeur est TriviallyCopyable et que les types d'itérateurs satisfont contiguous_iterator. Alternativement, cette accélération de copie peut être introduite pendant une phase d'optimisation du compilateur.

Lors de la copie de plages qui se chevauchent, std::ranges::copy_n convient lorsque la copie se fait vers la gauche (le début de la plage de destination est en dehors de la plage source), tandis que std::ranges::copy_backward convient lorsque la copie se fait vers la droite (la fin de la plage de destination est en dehors de la plage source).

Implémentation possible

struct copy_n_fn
{
    template<std::input_iterator I, std::weakly_incrementable O>
    requires std::indirectly_copyable<I, O>
    constexpr ranges::copy_n_result<I, O>
        operator()(I first, std::iter_difference_t<I> n, O result) const
    {
        for (std::iter_difference_t<I> i {}; i != n; ++i, ++first, ++result)
            *result = *first;
        return {std::move(first), std::move(result)};
    }
};

inline constexpr copy_n_fn copy_n {};

Exemple

#include <algorithm>
#include <iomanip>
#include <iostream>
#include <iterator>
#include <string>
#include <string_view>

int main()
{
    const std::string_view in {"ABCDEFGH"};
    std::string out;

    std::ranges::copy_n(in.begin(), 4, std::back_inserter(out));
    std::cout << std::quoted(out) << '\n';

    out = "abcdefgh";
    const auto res = std::ranges::copy_n(in.begin(), 5, out.begin());
    std::cout
        << "*(res.in): '" << *(res.in) << "', distance: "
        << std::distance(std::begin(in), res.in) << '\n'
        << "*(res.out): '" << *(res.out) << "', distance: "
        << std::distance(std::begin(out), res.out) << '\n';
}

Output:

"ABCD"
*(res.in): 'F', distance: 5
*(res.out): 'f', distance: 5
