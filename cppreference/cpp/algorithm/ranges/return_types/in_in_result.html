std::ranges::in_in_result

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <algorithm>

template< class I1, class I2 >
struct in_in_result;  // (depuis C++20)

ranges::in_in_result est un modèle de classe qui permet de stocker deux itérateurs en une seule unité.

Ce modèle de classe n'a pas de classes de base ni de membres déclarés autres que ceux présentés ci-dessous. Il convient donc à une utilisation avec des liaisons structurées.

Toutes les fonctions membres spéciales de ce modèle de classe sont implicitement déclarées, ce qui fait que les spécialisations sont des classes agrégats, et propagent la trivialité, le caractère potentiellement lanceur d'exceptions et le caractère constexpr des opérations correspondantes sur les membres de données.

Paramètres de modèle

  • I1, I2 — les types des itérateurs que ranges::in_in_result stocke.

Membres de données

Nom du membre Définition

  • in1 — une valeur (censée être un itérateur) de type I1. (objet membre public)
  • in2 — une valeur (censée être un itérateur) de type I2. (objet membre public)

Tous ces membres sont déclarés avec l'attribut [[no_unique_address]].

Convertit *this en le résultat en construisant chaque membre de données du résultat à partir du membre correspondant de *this.

  1. Équivalent à return {in1, in2};.

  2. Équivalent à return {std::move(in1), std::move(in2)};.

Bibliothèque standard

Les fonctions de la bibliothèque standard suivantes utilisent ranges::in_in_result comme type de retour :

##### Fonctions d'algorithme {#Algorithm_functions}

  • ranges::mismatch (C++20) — trouve la première position où deux intervalles diffèrent (objet fonction d'algorithme)
  • ranges::swap_ranges (C++20) — échange deux intervalles d'éléments (objet fonction d'algorithme)

Synopsis

namespace std::ranges
{
    template<class I1, class I2>
    struct in_in_result
    {
        [[no_unique_address]] I1 in1;
        [[no_unique_address]] I2 in2;

        template<class II1, class II2>
        requires std::convertible_to<const I1&, II1> && std::convertible_to<const I2&, II2>
        constexpr operator in_in_result<II1, II2>() const &
        {
            return {in1, in2};
        }

        template<class II1, class II2>
        requires std::convertible_to<I1, II1> && std::convertible_to<I2, II2>
        constexpr operator in_in_result<II1, II2>() &&
        {
            return {std::move(in1), std::move(in2)};
        }
    };
}

Notes

Chaque algorithme de la bibliothèque standard qui utilise cette famille de types de retour déclare un nouveau type alias, par exemple using merge_result = in_in_out_result<I1, I2, O>;.

Les noms de ces alias sont formés en ajoutant le suffixe « _result » au nom de l'algorithme. Ainsi, le type de retour de std::ranges::merge peut être désigné par std::ranges::merge_result.

Contrairement à std::pair et std::tuple, ce modèle de classe possède des membres de données aux noms significatifs.

Exemple

#include <algorithm>
#include <iostream>
#include <ranges>

int main()
{
    constexpr static auto in1 = {1, 2, 3, 4};
    constexpr static auto in2 = {1, 2, 4, 5};

    constexpr auto result {std::ranges::mismatch(in1, in2)};

    static_assert(2 == std::ranges::distance(in1.begin(), result.in1));
    static_assert(2 == std::ranges::distance(in2.begin(), result.in2));
}
