std::ranges::in_out_out_result

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <algorithm>

template< class I, class O1, class O2 >
struct in_out_out_result;  // (depuis C++20)

ranges::in_out_out_result est un modèle de classe qui permet de stocker trois itérateurs en une seule unité.

Ce modèle de classe n'a pas de classes de base ni de membres déclarés autres que ceux présentés ci-dessous. Il convient donc à une utilisation avec des liaisons structurées.

Toutes les fonctions membres spéciales de ce modèle de classe sont implicitement déclarées, ce qui fait que les spécialisations sont des classes agrégats, et propagent la trivialité, le caractère potentiellement lanceur d'exceptions et le caractère constexpr des opérations correspondantes sur les membres de données.

Paramètres de modèle

  • I, O1, O2 — les types des objets que ranges::in_out_out_result stocke.

Membres de données

Nom du membre Définition

  • in — une valeur (censée être un itérateur) de type I. (objet membre public)
  • out1 — une valeur (censée être un itérateur) de type O1. (objet membre public)
  • out2 — une valeur (censée être un itérateur) de type O2. (objet membre public)

Tous ces membres sont déclarés avec l'attribut [[no_unique_address]].

Synopsis

namespace std::ranges
{
    template<class I, class O1, class O2>
    struct in_out_out_result
    {
        [[no_unique_address]] I  in;
        [[no_unique_address]] O1 out1;
        [[no_unique_address]] O2 out2;

        template<class II, class OO1, class OO2>
        requires std::convertible_to<const I&, II> &&
                 std::convertible_to<const O1&, OO1> &&
                 std::convertible_to<const O2&, OO2>
        constexpr operator in_out_out_result<II, OO1, OO2>() const &
        {
            return {in, out1, out2};
        }

        template<class II, class OO1, class OO2>
        requires std::convertible_to<I, II> &&
                 std::convertible_to<O1, OO1> &&
                 std::convertible_to<O2, OO2>
        constexpr operator in_out_out_result<II, OO1, OO2>() &&
        {
            return {std::move(in), std::move(out1), std::move(out2)};
        }
    };
}

Notes

Chaque algorithme de la bibliothèque standard qui utilise cette famille de types de retour déclare un nouveau type alias, par exemple using merge_result = in_in_out_result<I1, I2, O>;.

Les noms de ces alias sont formés en ajoutant le suffixe « _result » au nom de l'algorithme. Ainsi, le type de retour de std::ranges::merge peut être désigné par std::ranges::merge_result.

Contrairement à std::pair et std::tuple, ce modèle de classe possède des membres de données aux noms significatifs.

Exemple

#include <algorithm>
#include <array>
#include <cctype>
#include <iostream>
#include <iterator>
#include <ranges>
#include <string_view>

void print(std::string_view rem, auto first, auto last)
{
    for (std::cout << rem << ": { "; first != last; ++first)
        std::cout << *first << ' ';
    std::cout << "}\n";
}

int main()
{
    constexpr std::string_view in {"TvEeNcStOoRr"};
    std::array<char, in.size()> o1, o2;

    const auto result = std::ranges::partition_copy(in, o1.begin(), o2.begin(),
        [](char c) { return std::isupper(c); });

    print("in", in.begin(), result.in);
    print("o1", o1.begin(), result.out1);
    print("o2", o2.begin(), result.out2);
}

Output:

in: { T v E e N c S t O o R r }
o1: { T E N S O R }
o2: { v e c t o r }
