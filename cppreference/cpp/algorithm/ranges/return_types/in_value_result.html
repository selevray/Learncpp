std::ranges::in_value_result

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <algorithm>

template< class I, class T >
struct in_value_result;  // (depuis C++23)

ranges::in_value_result est un modèle de classe qui permet de stocker un itérateur et une valeur en une seule unité.

Ce modèle de classe n'a pas de classes de base ni de membres déclarés autres que ceux présentés ci-dessous. Il convient donc à une utilisation avec des liaisons structurées.

Toutes les fonctions membres spéciales de ce modèle de classe sont implicitement déclarées, ce qui fait que les spécialisations sont des classes agrégats, et propagent la trivialité, le caractère potentiellement lanceur d'exceptions et le caractère constexpr des opérations correspondantes sur les membres de données.

Paramètres de modèle

  • I, T — les types des objets que ranges::in_value_result stocke.

Membres de données

Nom du membre Définition

  • in — une valeur (censée être un itérateur) de type I. (objet membre public)
  • value — une valeur (censée être une valeur stockée) de type T. (objet membre public)

Tous ces membres sont déclarés avec l'attribut [[no_unique_address]].

Convertit *this en le résultat en construisant chaque membre de données du résultat à partir du membre correspondant de *this.

  1. Équivalent à return {in, value};.

  2. Équivalent à return {std::move(in), std::move(value)};.

Bibliothèque standard

Les fonctions de la bibliothèque standard suivantes utilisent ranges::in_value_result comme type de retour :

##### Fonctions d'algorithme {#Algorithm_functions}

  • ranges::fold_left_with_iter (C++23) — replie à gauche une plage d'éléments, et retourne une pair (itérateur, valeur) (objet fonction d'algorithme)
  • ranges::fold_left_first_with_iter (C++23) — replie à gauche une plage d'éléments en utilisant le premier élément comme valeur initiale, et retourne une pair (itérateur, optional) (objet fonction d'algorithme)

Synopsis

namespace std::ranges
{
    template<class I, class T>
    struct in_value_result
    {
        [[no_unique_address]] I in;
        [[no_unique_address]] T value;

        template<class I2, class T2>
        requires convertible_to<const I&, I2> && convertible_to<const T&, T2>
        constexpr operator in_value_result<I2, T2>() const &
        {
            return {in, value};
        }

        template<class I2, class T2>
        requires convertible_to<I, I2> && convertible_to<T, T2>
        constexpr operator in_value_result<I2, T2>() &&
        {
            return {std::move(in), std::move(value)};
        }
    };
}

Notes

Chaque algorithme de la bibliothèque standard qui utilise cette famille de types de retour déclare un nouveau type alias, par exemple using merge_result = in_in_out_result<I1, I2, O>;.

Les noms de ces alias sont formés en ajoutant le suffixe « _result » au nom de l'algorithme. Ainsi, le type de retour de std::ranges::merge peut être désigné par std::ranges::merge_result.

Contrairement à std::pair et std::tuple, ce modèle de classe possède des membres de données aux noms significatifs.

Exemple

#include <algorithm>
#include <cassert>
#include <functional>

int main()
{
    const auto v = {1, 2, 3};
    const auto ret = std::ranges::fold_left_with_iter(v, 4, std::plus<>());
    assert(ret.in == v.end());
    assert(ret.value == 1 + 2 + 3 + 4);
}
