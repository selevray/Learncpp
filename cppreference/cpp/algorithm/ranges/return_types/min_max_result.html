std::ranges::min_max_result

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <algorithm>

template< class T >
struct min_max_result;  // (depuis C++20)

ranges::min_max_result est un modèle de classe qui permet de stocker deux objets ou références de même type en une seule unité.

Ce modèle de classe n'a pas de classes de base ni de membres déclarés autres que ceux présentés ci-dessous. Il convient donc à une utilisation avec des liaisons structurées.

Toutes les fonctions membres spéciales de ce modèle de classe sont implicitement déclarées, ce qui fait que les spécialisations sont des classes agrégats, et propagent la trivialité, le caractère potentiellement lanceur d'exceptions et le caractère constexpr des opérations correspondantes sur les membres de données.

Paramètres de modèle

  • T — le type des objets ou références que ranges::min_max_result stocke.

Membres de données

Nom du membre Définition

  • min — peut être une référence à, une copie de, ou un itérateur de type T vers un élément minimal d'un intervalle. (objet membre public)
  • max — peut être une référence à, une copie de, ou un itérateur de type T vers un élément maximal d'un intervalle (objet membre public)

Tous ces membres sont déclarés avec l'attribut [[no_unique_address]].

  1. Équivalent à return {min, max};.

  2. Équivalent à return {std::move(min), std::move(max)};.

Bibliothèque standard

Les fonctions de la bibliothèque standard suivantes utilisent ranges::min_max_result comme type de retour :

##### Fonctions d'algorithme {#Algorithm_functions}

  • ranges::minmax (C++20) — renvoie le plus petit et le plus grand de deux éléments (objet fonction d'algorithme)
  • ranges::minmax_element (C++20) — renvoie les éléments les plus petit et le plus grand d'un intervalle (objet fonction d'algorithme)

Synopsis

namespace std::ranges
{
    template<class T>
    struct min_max_result
    {
        [[no_unique_address]] T min;
        [[no_unique_address]] T max;

        template<class T2>
        requires std::convertible_to<const T&, T2>
        constexpr operator min_max_result<T2>() const &
        {
            return {min, max};
        }

        template<class T2>
        requires std::convertible_to<T, T2>
        constexpr operator min_max_result<T2>() &&
        {
            return {std::move(min), std::move(max)};
        }
    };
}

Notes

Chaque algorithme de la bibliothèque standard qui utilise cette famille de types de retour déclare un nouveau type alias, par exemple using merge_result = in_in_out_result<I1, I2, O>;.

Les noms de ces alias sont formés en ajoutant le suffixe « _result » au nom de l'algorithme. Ainsi, le type de retour de std::ranges::merge peut être désigné par std::ranges::merge_result.

Contrairement à std::pair et std::tuple, ce modèle de classe possède des membres de données aux noms significatifs.

Exemple

#include <algorithm>
#include <ranges>

int main()
{
    constexpr static auto v = {3, 1, 4, 1, 5, 9, 2};
    {
        constexpr auto result = std::ranges::minmax(v);
        static_assert(1 == result.min && 9 == result.max);
    }
    {
        constexpr auto result = std::ranges::minmax_element(v);
        static_assert(1 == *result.min && 9 == *result.max);
    }
}
