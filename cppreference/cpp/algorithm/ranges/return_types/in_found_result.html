std::ranges::in_found_result

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <algorithm>

template< class I >
struct in_found_result;  // (depuis C++20)

ranges::in_found_result est un modèle de classe qui fournit un moyen de stocker un itérateur et un indicateur booléen en une seule unité.

Ce modèle de classe n'a pas de classes de base ni de membres déclarés autres que ceux présentés ci-dessous. Il convient donc à une utilisation avec des liaisons structurées.

Toutes les fonctions membres spéciales de ce modèle de classe sont implicitement déclarées, ce qui fait que les spécialisations sont des classes agrégats, et propagent la trivialité, le caractère potentiellement lanceur d'exceptions et le caractère constexpr des opérations correspondantes sur les membres de données.

Paramètres de modèle

  • I — le type de l'itérateur que ranges::in_found_result stocke.

Membres de données

Nom du membre Définition

  • in — une valeur (censée être un itérateur) de type I. Elle est déclarée avec l'attribut [[no_unique_address]]. (membre donnée public)
  • found — un indicateur booléen (pouvant indiquer si un intervalle approprié a été trouvé) de type bool. (membre donnée public)

  1. Équivalent à return {in, found};.

  2. Équivalent à return {std::move(in), found};.

Bibliothèque standard

Les fonctions de la bibliothèque standard suivantes utilisent ranges::in_found_result comme type de retour :

##### Fonctions d'algorithme {#Algorithm_functions}

  • ranges::next_permutation (C++20) — génère la permutation lexicographique suivante supérieure d'un intervalle d'éléments (objet fonction d'algorithme)
  • ranges::prev_permutation (C++20) — génère la permutation lexicographique immédiatement inférieure d'un intervalle d'éléments (objet fonction algorithmique)

Synopsis

namespace std::ranges
{
    template<class I>
    struct in_found_result
    {
        [[no_unique_address]] I in;
        bool found;

        template<class I2>
        requires std::convertible_to<const I&, I2>
        constexpr operator in_found_result<I2>() const &
        {
            return {in, found};
        }

        template<class I2>
        requires std::convertible_to<I, I2>
        constexpr operator in_found_result<I2>() &&
        {
            return {std::move(in), found};
        }
    };
}

Notes

Chaque algorithme de la bibliothèque standard qui utilise cette famille de types de retour déclare un nouveau type alias, par exemple using merge_result = in_in_out_result<I1, I2, O>;.

Les noms de ces alias sont formés en ajoutant le suffixe « _result » au nom de l'algorithme. Ainsi, le type de retour de std::ranges::merge peut être désigné par std::ranges::merge_result.

Contrairement à std::pair et std::tuple, ce modèle de classe possède des membres de données aux noms significatifs.

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>
#include <ranges>

int main()
{
    int v[] {1, 2, 3};

    const auto result = std::ranges::next_permutation(v);

    std::ranges::for_each(std::cbegin(v), result.in, [](int e) {std::cout << e << ' ';});

    std::cout << std::boolalpha << "\n" "result.found: " << result.found << '\n';
}

Output:

1 3 2
result.found = true
