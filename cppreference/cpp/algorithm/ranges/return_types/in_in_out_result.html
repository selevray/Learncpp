std::ranges::in_in_out_result

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <algorithm>

template< class I1, class I2, class O >
struct in_in_out_result;  // (depuis C++20)

ranges::in_in_out_result est un modèle de classe qui permet de stocker trois itérateurs en une seule unité.

Ce modèle de classe n'a pas de classes de base ni de membres déclarés autres que ceux présentés ci-dessous. Il convient donc à une utilisation avec des liaisons structurées.

Toutes les fonctions membres spéciales de ce modèle de classe sont implicitement déclarées, ce qui fait que les spécialisations sont des classes agrégats, et propagent la trivialité, le caractère potentiellement lanceur d'exceptions et le caractère constexpr des opérations correspondantes sur les membres de données.

Paramètres de modèle

  • I1, I2, O — les types des itérateurs que ranges::in_in_out_result stocke.

Membres de données

Nom du membre Définition

  • in1 — une valeur (censée être un itérateur) de type I1. (objet membre public)
  • in2 — une valeur (censée être un itérateur) de type I2. (objet membre public)
  • out — une valeur (censée être un itérateur) de type O. (objet membre public)

Tous ces membres sont déclarés avec l'attribut [[no_unique_address]].

Bibliothèque standard

Les fonctions de la bibliothèque standard suivantes utilisent ranges::in_in_out_result comme type de retour :

##### Fonctions d'algorithme {#Algorithm_functions}

  • ranges::transform (C++20) — applique une fonction à un intervalle d'éléments (objet fonction algorithmique)
  • ranges::merge (C++20) — fusionne deux intervalles triés (objet fonction d'algorithme)
  • ranges::set_union (C++20) — calcule l'union de deux ensembles (objet fonction d'algorithme)
  • ranges::set_intersection (C++20) — calcule l'intersection de deux ensembles (objet fonction d'algorithme)
  • ranges::set_symmetric_difference (C++20) — calcule la différence symétrique entre deux ensembles (objet fonction d'algorithme)

Synopsis

namespace std::ranges
{
    template<class I1, class I2, class O>
    struct in_in_out_result
    {
        [[no_unique_address]] I1 in1;
        [[no_unique_address]] I2 in2;
        [[no_unique_address]] O  out;

        template<class II1, class II2, class OO>
        requires std::convertible_to<const I1&, II1> &&
                 std::convertible_to<const I2&, II2> &&
                 std::convertible_to<const O&, OO>
        constexpr operator in_in_out_result<II1, II2, OO>() const &
        {
            return {in1, in2, out};
        }

        template<class II1, class II2, class OO>
        requires std::convertible_to<I1, II1> &&
                 std::convertible_to<I2, II2> &&
                 std::convertible_to<O, OO>
        constexpr operator in_in_out_result<II1, II2, OO>() &&
        {
            return {std::move(in1), std::move(in2), std::move(out)};
        }
    };
}

Notes

Chaque algorithme de la bibliothèque standard qui utilise cette famille de types de retour déclare un nouveau type alias, par exemple using merge_result = in_in_out_result<I1, I2, O>;.

Les noms de ces alias sont formés en ajoutant le suffixe « _result » au nom de l'algorithme. Ainsi, le type de retour de std::ranges::merge peut être désigné par std::ranges::merge_result.

Contrairement à std::pair et std::tuple, ce modèle de classe possède des membres de données aux noms significatifs.

Exemple

#include <algorithm>
#include <array>
#include <iostream>
#include <iterator>
#include <ranges>

void print(auto rem, auto first, auto last)
{
    for (std::cout << rem << ": "; first != last; ++first)
        std::cout << *first << ' ';
    std::cout << '\n';
}

int main()
{
    constexpr static auto in1 = {1, 2, 3, 4, 5, 5};
    constexpr static auto in2 = {3, 4, 5, 6, 7};
    std::array<int, std::size(in1) + std::size(in2)> out;

    const auto result = std::ranges::merge(in1, in2, out.begin());
    print("in1", in1.begin(), result.in1);
    print("in2", in2.begin(), result.in2);
    print("out", out.begin(), result.out);
}

Output:

in1: 1 2 3 4 5 5
in2: 3 4 5 6 7
out: 1 2 3 3 4 4 5 5 5 6 7
