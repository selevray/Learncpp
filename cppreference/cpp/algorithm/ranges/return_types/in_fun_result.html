std::ranges::in_fun_result

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <algorithm>

template< class I, class F >
struct in_fun_result;  // (depuis C++20)

ranges::in_fun_result est un modèle de classe qui permet de stocker un itérateur et un objet fonction en une seule unité.

Ce modèle de classe n'a pas de classes de base ni de membres déclarés autres que ceux présentés ci-dessous. Il convient donc à une utilisation avec des liaisons structurées.

Toutes les fonctions membres spéciales de ce modèle de classe sont implicitement déclarées, ce qui fait que les spécialisations sont des classes agrégats, et propagent la trivialité, le caractère potentiellement lanceur d'exceptions et le caractère constexpr des opérations correspondantes sur les membres de données.

Paramètres de modèle

  • I — le type de l'itérateur que ranges::in_fun_result stocke.
  • F — le type de l'objet fonction que ranges::in_fun_result stocke.

Membres de données

Nom du membre Définition

  • in — une valeur (censée être un itérateur) de type I. (objet membre public)
  • fun — une valeur (censée être un objet fonction) de type F. (objet membre public)

Tous ces membres sont déclarés avec l'attribut [[no_unique_address]].

  1. Équivalent à return {in, fun};.

  2. Équivalent à return {std::move(in), std::move(fun)};.

Bibliothèque standard

Les fonctions de la bibliothèque standard suivantes utilisent ranges::in_fun_result comme type de retour :

##### Fonctions d'algorithme {#Algorithm_functions}

  • ranges::for_each (C++20) — applique une fonction à un intervalle d'éléments (objet fonction algorithmique)
  • ranges::for_each_n (C++20) — applique un objet fonction aux N premiers éléments d'une séquence (objet fonction algorithmique)

Synopsis

namespace std::ranges
{
    template<class I, class F>
    struct in_fun_result
    {
        [[no_unique_address]] I in;
        [[no_unique_address]] F fun;

        template<class I2, class F2>
        requires std::convertible_to<const I&, I2> && std::convertible_to<const F&, F2>
        constexpr operator in_fun_result<I2, F2>() const &
        {
            return {in, fun};
        }

        template<class I2, class F2>
        requires std::convertible_to<I, I2> && std::convertible_to<F, F2>
        constexpr operator in_fun_result<I2, F2>() &&
        {
            return {std::move(in), std::move(fun)};
        }
    };
}

Notes

Chaque algorithme de la bibliothèque standard qui utilise cette famille de types de retour déclare un nouveau type alias, par exemple using merge_result = in_in_out_result<I1, I2, O>;.

Les noms de ces alias sont formés en ajoutant le suffixe « _result » au nom de l'algorithme. Ainsi, le type de retour de std::ranges::merge peut être désigné par std::ranges::merge_result.

Contrairement à std::pair et std::tuple, ce modèle de classe possède des membres de données aux noms significatifs.

Exemple

#include <algorithm>
#include <cassert>
#include <iostream>
#include <iterator>
#include <ranges>

int main()
{
    int v[]{1, 2, 3};

    const std::ranges::in_fun_result res1 = std::ranges::for_each_n(
        v, std::size(v),
        [](int& x) { return x = -x; } // lambda de négation
    );
    assert(res1.in == std::end(v));

    const std::ranges::in_fun_result res2 = std::ranges::for_each(
        std::begin(v),
        res1.in,
        [](int x) { std::cout << x << ' '; } // lambda d'affichage
    );

    std::cout << "│ ";

    std::ranges::for_each(v, res1.fun); // utilise la lambda de négation
    std::ranges::for_each(v, res2.fun); // utilise la lambda d'affichage
    std::cout << '\n';
}

Output:

-1 -2 -3 │ 1 2 3
