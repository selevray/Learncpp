  1. Affecte la valeur value donnée aux éléments de l'intervalle [first,last).

  2. Identique à (1), mais utilise r comme intervalle source, comme si l'on utilisait ranges::begin(r) comme first et ranges::end(r) comme last.

Les entités de type fonction décrites sur cette page sont des objets fonctions d'algorithme (appelés de manière informelle niebloids), c'est-à-dire :

  • Les listes d'arguments de modèle explicites ne peuvent pas être spécifiées lors de l'appel de l'un d'entre eux.
  • Aucun d'entre eux n'est visible par la recherche dépendante des arguments.
  • Lorsque l'un d'entre eux est trouvé par la recherche non qualifiée normale comme nom situé à gauche de l'opérateur d'appel de fonction, la recherche dépendante des arguments est inhibée.

Paramètres

  • first, last — l'intervalle des éléments à modifier
  • r — l'intervalle des éléments à modifier
  • value — la valeur à affecter

Valeur de retour

Un itérateur de sortie égal à last.

Complexité

Exactement last - first affectations.

Implémentation possible

struct fill_fn
{
    template<class O, std::sentinel_for<O> S, class T = std::iter_value_t<O>>
    requires std::output_iterator<O, const T&>
    constexpr O operator()(O first, S last, const T& value) const
    {
        while (first != last)
            *first++ = value;

        return first;
    }

    template<class R, class T = ranges::range_value_t<R>>
    requires ranges::output_range<R, const T&>
    constexpr ranges::borrowed_iterator_t<R> operator()(R&& r, const T& value) const
    {
        return (*this)(ranges::begin(r), ranges::end(r), value);
    }
};

inline constexpr fill_fn fill;

Exemple

#include <algorithm>
#include <complex>
#include <iostream>
#include <vector>

void println(const auto& seq)
{
    for (const auto& e : seq)
        std::cout << e << ' ';
    std::cout << '\n';
}

int main()
{
    std::vector<int> v{0, 1, 2, 3, 4, 5};

    // définir tous les éléments à -1 en utilisant la surcharge (1)
    std::ranges::fill(v.begin(), v.end(), -1);
    println(v);

    // définir tous les éléments à 10 en utilisant la surcharge (2)
    std::ranges::fill(v, 10);
    println(v);

    std::vector<std::complex<double>> nums{{1, 3}, {2, 2}, {4, 8}};
    println(nums);
    #ifdef __cpp_lib_algorithm_default_value_type
        std::ranges::fill(nums, {4, 2}); // T est déduit
    #else
        std::ranges::fill(nums, std::complex<double>{4, 2});
    #endif
    println(nums);
}

(1,3) (2,2) (4,8)
(4,2) (4,2) (4,2)
