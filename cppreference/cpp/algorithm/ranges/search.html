std::ranges::search

  1. Recherche la première occurrence de la séquence d'éléments [first2,last2) dans l'intervalle [first1,last1). Les éléments sont comparés à l'aide du prédicat binaire pred après avoir été projetés respectivement par proj2 et proj1.

  2. Identique à (1), mais utilise r1 comme premier intervalle source et r2 comme second intervalle source, comme si l'on utilisait ranges::begin(r1) en tant que first1, ranges::end(r1) en tant que last1, ranges::begin(r2) en tant que first2, et ranges::end(r2) en tant que last2.

Les entités de type fonction décrites sur cette page sont des objets fonctions d'algorithme (appelés de manière informelle niebloids), c'est-à-dire :

  • Les listes d'arguments de modèle explicites ne peuvent pas être spécifiées lors de l'appel de l'un d'entre eux.
  • Aucun d'entre eux n'est visible par la recherche dépendante des arguments.
  • Lorsque l'un d'entre eux est trouvé par la recherche non qualifiée normale comme nom situé à gauche de l'opérateur d'appel de fonction, la recherche dépendante des arguments est inhibée.

Paramètres

  • first1, last1 — l'intervalle d'éléments à examiner (aussi appelé botte de foin)
  • first2, last2 — l'intervalle d'éléments à rechercher (aussi appelé aiguille)
  • r1 — l'intervalle d'éléments à examiner (aussi appelé botte de foin)
  • r2 — l'intervalle d'éléments à rechercher (aussi appelé aiguille)
  • pred — prédicat binaire à appliquer aux éléments projetés
  • proj1 — projection à appliquer aux éléments de la première plage
  • proj2 — projection à appliquer aux éléments de la seconde plage

Valeur de retour

  1. Renvoie une valeur ranges::subrange correspondant à la première occurrence de la séquence [first2,last2) (aussi appelée needle) dans l'intervalle [first1,last1) (aussi appelé haystack), après application des projections proj1 et proj2 aux éléments des deux séquences respectivement, puis application du prédicat binaire pred pour comparer les éléments projetés.

Si aucune occurrence n'est trouvée, ranges::subrange{last1, last1} est renvoyé.

Si l'intervalle à rechercher (aussi appelé needle) est vide, c'est-à-dire first2 == last2, alors ranges::subrange{first1, first1} est renvoyé.

  1. Identique à (1) mais avec le type de retour ranges::borrowed_subrange_t<R1>.

Complexité

Au plus S * N applications du prédicat correspondant et de chaque projection, où
(1) S = ranges::distance(first2, last2) et N = ranges::distance(first1, last1) ;
(2) S = ranges::distance(r2) et N = ranges::distance(r1).

Implémentation possible

struct search_fn
{
    template<std::forward_iterator I1, std::sentinel_for<I1> S1,
             std::forward_iterator I2, std::sentinel_for<I2> S2,
             class Pred = ranges::equal_to,
             class Proj1 = std::identity,
             class Proj2 = std::identity>
    requires std::indirectly_comparable<I1, I2, Pred, Proj1, Proj2>
    constexpr ranges::subrange<I1>
        operator()(I1 first1, S1 last1, I2 first2, S2 last2, Pred pred = {},
                   Proj1 proj1 = {}, Proj2 proj2 = {}) const
    {
        for (;; ++first1)
        {
            I1 it1 = first1;
            for (I2 it2 = first2;; ++it1, ++it2)
            {
                if (it2 == last2)
                    return {first1, it1};
                if (it1 == last1)
                    return {it1, it1};
                if (!std::invoke(pred, std::invoke(proj1, *it1), std::invoke(proj2, *it2)))
                    break;
            }
        }
    }

    template<ranges::forward_range R1, ranges::forward_range R2,
             class Pred = ranges::equal_to,
             class Proj1 = std::identity,
             class Proj2 = std::identity>
    requires std::indirectly_comparable<ranges::iterator_t<R1>,
                                        ranges::iterator_t<R2>, Pred, Proj1, Proj2>
    constexpr ranges::borrowed_subrange_t<R1>
        operator()(R1&& r1, R2&& r2, Pred pred = {},
                   Proj1 proj1 = {}, Proj2 proj2 = {}) const
    {
        return (*this)(ranges::begin(r1), ranges::end(r1),
                       ranges::begin(r2), ranges::end(r2),
                       std::move(pred), std::move(proj1), std::move(proj2));
    }
};

inline constexpr search_fn search {};

Exemple

#include <algorithm>
#include <cctype>
#include <iostream>
#include <iterator>
#include <string_view>

using namespace std::literals;

void print(int id, const auto& haystack, const auto& needle, const auto& found)
{
    std::cout << id << ") search(\"" << haystack << "\", \"" << needle << "\"); ";
    const auto first = std::distance(haystack.begin(), found.begin());
    const auto last = std::distance(haystack.begin(), found.end());
    if (found.empty())
        std::cout << "not found;";
    else
    {
        std::cout << "found: \"";
        for (const auto x : found)
            std::cout << x;
        std::cout << "\";";
    }
    std::cout << " subrange: {" << first << ", " << last << "}\n";
}

int main()
{
    constexpr auto haystack {"abcd abcd"sv};
    constexpr auto needle {"bcd"sv};

    // la recherche utilise les paires d'itérateurs begin()/end() :
    constexpr auto found1 = std::ranges::search(
        haystack.begin(), haystack.end(),
        needle.begin(), needle.end());
    print(1, haystack, needle, found1);

    // la recherche utilise les intervalles r1, r2 :
    constexpr auto found2 = std::ranges::search(haystack, needle);
    print(2, haystack, needle, found2);

    // l'intervalle « needle » est vide :
    constexpr auto none {""sv};
    constexpr auto found3 = std::ranges::search(haystack, none);
    print(3, haystack, none, found3);

    // « needle » ne sera pas trouvé :
    constexpr auto awl {"efg"sv};
    constexpr auto found4 = std::ranges::search(haystack, awl);
    print(4, haystack, awl, found4);

    // la recherche utilise un comparateur et des projections personnalisés :
    constexpr auto bodkin {"234"sv};
    auto found5 = std::ranges::search(haystack, bodkin,
        [](const int x, const int y) { return x == y; }, // pred
        [](const int x) { return std::toupper(x); }, // proj1
        [](const int y) { return y + 'A' - '1'; }); // proj2
    print(5, haystack, bodkin, found5);
}

Output:

1) search("abcd abcd", "bcd"); found: "bcd"; subrange: {1, 4}
2) search("abcd abcd", "bcd"); found: "bcd"; subrange: {1, 4}
3) search("abcd abcd", ""); not found; subrange: {0, 0}
4) search("abcd abcd", "efg"); not found; subrange: {9, 9}
5) search("abcd abcd", "234"); found: "bcd"; subrange: {1, 4}
