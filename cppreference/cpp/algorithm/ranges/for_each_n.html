Types auxiliaires

template< class I, class F >
using for_each_n_result = ranges::in_fun_result<I, F>;  // (2) (depuis C++20)
  1. Applique l'objet fonction f donné au résultat projeté par proj du déréférencement de chaque itérateur de l'intervalle [first,first + n), dans l'ordre.

Si le type d'itérateur est modifiable, f peut modifier les éléments de l'intervalle via l'itérateur déréférencé. Si f renvoie un résultat, celui-ci est ignoré. Si n est inférieur à zéro, le comportement est indéfini.

Les entités de type fonction décrites sur cette page sont des objets fonctions d'algorithme (appelés de manière informelle niebloids), c'est-à-dire :

  • Les listes d'arguments de modèle explicites ne peuvent pas être spécifiées lors de l'appel de l'un d'entre eux.
  • Aucun d'entre eux n'est visible par la recherche dépendante des arguments.
  • Lorsque l'un d'entre eux est trouvé par la recherche non qualifiée normale comme nom situé à gauche de l'opérateur d'appel de fonction, la recherche dépendante des arguments est inhibée.

Paramètres

  • first — itérateur désignant le début de l'intervalle auquel appliquer la fonction
  • n — le nombre d'éléments auxquels appliquer la fonction
  • f — la fonction à appliquer à l'intervalle projeté [first,first + n)
  • proj — projection à appliquer aux éléments

Valeur de retour

Un objet {first + n, std::move(f)}, où first + n peut être évalué comme std::ranges::next(std::move(first), n) selon la catégorie de l'itérateur.

Complexité

Exactement n applications de f et proj.

Implémentation possible

struct for_each_n_fn
{
    template<std::input_iterator I, class Proj = std::identity,
             std::indirectly_unary_invocable<std::projected<I, Proj>> Fun>
    constexpr for_each_n_result<I, Fun>
        operator()(I first, std::iter_difference_t<I> n, Fun fun, Proj proj = Proj{}) const
    {
        for (; n-- > 0; ++first)
            std::invoke(fun, std::invoke(proj, *first));
        return {std::move(first), std::move(fun)};
    }
};

inline constexpr for_each_n_fn for_each_n {};

Exemple

#include <algorithm>
#include <array>
#include <iostream>
#include <ranges>
#include <string_view>

struct P
{
    int first;
    char second;
    friend std::ostream& operator<<(std::ostream& os, const P& p)
    {
        return os << '{' << p.first << ",'" << p.second << "'}";
    }
};

auto print = [](std::string_view name, auto const& v)
{
    std::cout << name << ": ";
    for (auto n = v.size(); const auto& e : v)
        std::cout << e << (--n ? ", " : "\n");
};

int main()
{
    std::array a {1, 2, 3, 4, 5};
    print("a", a);
    // Opposer les trois premiers nombres :
    std::ranges::for_each_n(a.begin(), 3, [](auto& n) { n *= -1; });
    print("a", a);

    std::array s { P{1,'a'}, P{2, 'b'}, P{3, 'c'}, P{4, 'd'} };
    print("s", s);
    // Opposer les membres de données 'P::first' à l'aide d'une projection :
    std::ranges::for_each_n(s.begin(), 2, [](auto& x) { x *= -1; }, &P::first);
    print("s", s);
    // Mettre en majuscules les membres de données 'P::second' à l'aide d'une projection :
    std::ranges::for_each_n(s.begin(), 3, [](auto& c) { c -= 'a'-'A'; }, &P::second);
    print("s", s);
}

Output:

a: 1, 2, 3, 4, 5
a: -1, -2, -3, 4, 5
s: {1,'a'}, {2,'b'}, {3,'c'}, {4,'d'}
s: {-1,'a'}, {-2,'b'}, {3,'c'}, {4,'d'}
s: {-1,'A'}, {-2,'B'}, {3,'C'}, {4,'d'}
