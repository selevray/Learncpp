Effectue un pliage à gauche des éléments de l'intervalle donné, c'est-à-dire renvoie le résultat de l'évaluation de l'expression en chaîne :
f(f(f(f(x1, x2), x3), ...), xn), où x1, x2, ..., xn sont les éléments de l'intervalle.

Informellement, ranges::fold_left_first se comporte comme la surcharge de std::accumulate qui accepte un prédicat binaire, sauf que *first est utilisé en interne comme élément initial.

Le comportement est indéfini si [first,last) n'est pas un intervalle valide.

  1. L'intervalle est [first,last). Équivalent à return ranges::fold_left_first_with_iter(std::move(first), last, f).value.

  2. Identique à (1), sauf qu'il utilise r comme intervalle, comme si l'on utilisait ranges::begin(r) comme first et ranges::end(r) comme last.

Paramètres

  • first, last — l'intervalle des éléments à replier
  • r — l'intervalle des éléments à replier
  • f — l'objet fonction binaire

Valeur de retour

Un objet de type std::optional<U> qui contient le résultat du repli à gauche fold de l'intervalle donné sur f, où U est équivalent à decltype(ranges::fold_left(std::move(first), last, std::iter_value_t<I>(*first), f)).

Si l'intervalle est vide, std::optional<U>() est retourné.

Implémentations possibles

struct fold_left_first_fn
{
    template<std::input_iterator I, std::sentinel_for<I> S,
             /*indirectly-binary-left-foldable*/<std::iter_value_t<I>, I> F>
    requires
        std::constructible_from<std::iter_value_t<I>, std::iter_reference_t<I>>
    constexpr auto operator()(I first, S last, F f) const
    {
        using U = decltype(
            ranges::fold_left(std::move(first), last, std::iter_value_t<I>(*first), f)
        );
        if (first == last)
            return std::optional<U>();
        std::optional<U> init(std::in_place, *first);
        for (++first; first != last; ++first)
            *init = std::invoke(f, std::move(*init), *first);
        return std::move(init);
    }

    template<ranges::input_range R,
             /*indirectly-binary-left-foldable*/<
                 ranges::range_value_t<R>, ranges::iterator_t<R>> F>
    requires
        std::constructible_from<ranges::range_value_t<R>, ranges::range_reference_t<R>>
    constexpr auto operator()(R&& r, F f) const
    {
        return (*this)(ranges::begin(r), ranges::end(r), std::ref(f));
    }
};

inline constexpr fold_left_first_fn fold_left_first;

Complexité

Exactement ranges::distance(first, last) - 1 (en supposant que l'intervalle n'est pas vide) applications de l'objet fonction f.

Exemple

#include <algorithm>
#include <functional>
#include <iostream>
#include <ranges>
#include <utility>
#include <vector>

int main()
{
    std::vector v{1, 2, 3, 4, 5, 6, 7, 8};

    auto sum = std::ranges::fold_left_first(v.begin(), v.end(), std::plus<int>()); // (1)
    std::cout << "*sum: " << sum.value() << '\n';

    auto mul = std::ranges::fold_left_first(v, std::multiplies<int>()); // (2)
    std::cout << "*mul: " << mul.value() << '\n';

    // calcule le produit des std::pair::second de toutes les paires du vector :
    std::vector<std::pair<char, float>> data {{'A', 3.f}, {'B', 3.5f}, {'C', 4.f}};
    auto sec = std::ranges::fold_left_first
    (
        data | std::ranges::views::values, std::multiplies<>()
    );
    std::cout << "*sec: " << *sec << '\n';

    // utilise un objet fonction défini par le programme (expression lambda) :
    auto val = std::ranges::fold_left_first(v, [](int x, int y) { return x + y + 13; });
    std::cout << "*val: " << *val << '\n';
}

Output:

*sum: 36
*mul: 40320
*sec: 42
*val: 127
