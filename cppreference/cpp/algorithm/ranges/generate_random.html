Tente de générer des nombres aléatoires à l'aide de la fonction membre generate_random du générateur de nombres aléatoires ou de la distribution, qui devrait être plus efficace. Revient à une génération élément par élément si aucune fonction membre generate_random n'est disponible.

Soit l'opération de repli l'appel de ranges::generate(std::forward<R>(r), std::ref(g)) ou de ranges::generate(std::forward<R>(r), [&d, &g] { return std::invoke(d, g); }) pour (1) ou (3) respectivement.

  1. Appelle g.generate_random(std::forward<R>(r)) si cette expression est bien formée.

Sinon, soit I égal à std::invoke_result_t<G&>. Si R modélise sized_range, remplit r avec ranges::size(r) valeurs de I en effectuant un nombre non spécifié d'appels de la forme g() ou g.generate_random(s), si une telle expression est bien formée pour une valeur N et un objet s de type std::span<I, N>.

Sinon, effectue l'opération de repli.

  1. Appelle d.generate_random(std::forward<R>(r), g) si cette expression est bien formée.

Sinon, soit I égal à std::invoke_result_t<D&, G&>. Si R modélise sized_range, remplit r avec ranges::size(r) valeurs de type I en effectuant un nombre non spécifié d'appels de la forme std::invoke(d, g) ou d.generate_random(s, g), si une telle expression est bien formée pour une valeur N et un objet s de type std::span<I, N>.

Sinon, effectue l'opération de repli.

2,4) Équivalent à (1,3) respectivement, où r est obtenu à partir de ranges::subrange<O, S>(std::move(first), last).

Si les effets de (1) ou de (3) ne sont pas équivalents à ceux de l'opération de repli correspondante, le comportement est indéfini.

La valeur de N peut différer d'un appel à l'autre. Les implémentations peuvent choisir des valeurs plus petites pour des intervalles plus courts.

Les entités de type fonction décrites sur cette page sont des objets fonctions d'algorithme (appelés de manière informelle niebloids), c'est-à-dire :

  • Les listes d'arguments de modèle explicites ne peuvent pas être spécifiées lors de l'appel de l'un d'entre eux.
  • Aucun d'entre eux n'est visible par la recherche dépendante des arguments.
  • Lorsque l'un d'entre eux est trouvé par la recherche non qualifiée normale comme nom situé à gauche de l'opérateur d'appel de fonction, la recherche dépendante des arguments est inhibée.

Paramètres

  • first, last — paire itérateur-sentinelle désignant l'intervalle dans lequel les nombres aléatoires sont écrits
  • r — intervalle dans lequel les nombres aléatoires sont écrits
  • g — générateur uniforme de bits aléatoires
  • d — objet de distribution de nombres aléatoires

Notes

Au moment de la standardisation de std::ranges::generate_random, aucun générateur de nombres aléatoires ni aucune distribution de la bibliothèque standard ne fournit de fonction membre generate_random.

std::ranges::generate_random peut être plus efficace lorsqu'il est utilisé avec un générateur de nombres aléatoires défini par l'utilisateur qui encapsule une API vectorisée sous-jacente.

Exemple

#include <algorithm>
#include <iomanip>
#include <iostream>
#include <random>

int main()
{
    std::default_random_engine eng;
    std::default_random_engine::result_type rs[16]{};
    std::ranges::generate_random(rs, eng);

    std::cout << std::left;
    for (int i{}; auto n : rs)
        std::cout << std::setw(11) << n << (++i % 4 ? ' ' : '\n');
}
