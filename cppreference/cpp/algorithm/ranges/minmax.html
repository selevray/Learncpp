Renvoie la plus petite et la plus grande des valeurs projetées données.

  1. Renvoie des références vers le plus petit et le plus grand de a et b.

  2. Renvoie la plus petite et la plus grande des valeurs de la liste d'initialisation r.

  3. Renvoie la plus petite et la plus grande des valeurs de l'intervalle r.

Les entités de type fonction décrites sur cette page sont des objets fonctions d'algorithme (appelés de manière informelle niebloids), c'est-à-dire :

  • Les listes d'arguments de modèle explicites ne peuvent pas être spécifiées lors de l'appel de l'un d'entre eux.
  • Aucun d'entre eux n'est visible par la recherche dépendante des arguments.
  • Lorsque l'un d'entre eux est trouvé par la recherche non qualifiée normale comme nom situé à gauche de l'opérateur d'appel de fonction, la recherche dépendante des arguments est inhibée.

Paramètres

  • a, b — les valeurs à comparer
  • r — une plage non vide de valeurs à comparer
  • comp — comparaison à appliquer aux éléments projetés
  • proj — projection à appliquer aux éléments

Valeur de retour

  1. {b, a} si, selon leur valeur projetée respective, b est plus petit que a ; sinon elle renvoie {a, b}.

2,3) {s, l}, où s et l sont respectivement la plus petite et la plus grande valeur de r, selon leur valeur projetée. Si plusieurs valeurs sont équivalentes à la plus petite ou à la plus grande, renvoie la plus petite valeur la plus à gauche et la plus grande valeur la plus à droite. Si la plage est vide (ce que détermine ranges::distance(r)), le comportement est indéfini.

Complexité

  1. Exactement une comparaison et deux applications de la projection.

2,3) Au plus 3 / 2 * ranges::distance(r) comparaisons et deux fois plus d'applications de la projection.

Implémentation possible

struct minmax_fn
{
    template<class T, class Proj = std::identity,
             std::indirect_strict_weak_order<
                 std::projected<const T*, Proj>> Comp = ranges::less>
    constexpr ranges::minmax_result<const T&>
         operator()(const T& a, const T& b, Comp comp = {}, Proj proj = {}) const
    {
        if (std::invoke(comp, std::invoke(proj, b), std::invoke(proj, a)))
            return {b, a};

        return {a, b};
    }

    template<std::copyable T, class Proj = std::identity,
             std::indirect_strict_weak_order<
                 std::projected<const T*, Proj>> Comp = ranges::less>
    constexpr ranges::minmax_result<T>
        operator()(std::initializer_list<T> r, Comp comp = {}, Proj proj = {}) const
    {
        auto result = ranges::minmax_element(r, std::ref(comp), std::ref(proj));
        return {*result.min, *result.max};
    }

    template<ranges::input_range R, class Proj = std::identity,
             std::indirect_strict_weak_order<
                 std::projected<ranges::iterator_t<R>, Proj>> Comp = ranges::less>
    requires std::indirectly_copyable_storable<ranges::iterator_t<R>,
                                               ranges::range_value_t<R>*>
    constexpr ranges::minmax_result<ranges::range_value_t<R>>
        operator()(R&& r, Comp comp = {}, Proj proj = {}) const
    {
        auto result = ranges::minmax_element(r, std::ref(comp), std::ref(proj));
        return {std::move(*result.min), std::move(*result.max)};
    }
};

inline constexpr minmax_fn minmax;

Notes

Pour la surcharge (1), si l'un des paramètres est un temporaire, la référence renvoyée devient une référence pendante à la fin de l'expression complète qui contient l'appel à minmax :

int n = 1;
auto p = std::ranges::minmax(n, n + 1);
int m = p.min; // ok
int x = p.max; // comportement indéfini

// Notez que les liaisons structurées ont le même problème
auto [mm, xx] = std::ranges::minmax(n, n + 1);
xx; // comportement indéfini

Exemple

#include <algorithm>
#include <array>
#include <iostream>
#include <random>

int main()
{
    namespace ranges = std::ranges;

    constexpr std::array v{3, 1, 4, 1, 5, 9, 2, 6, 5};

    std::random_device rd;
    std::mt19937_64 generator(rd());
    std::uniform_int_distribution<> distribution(0, ranges::distance(v)); // [0..9]

    // auto bounds = ranges::minmax(distribution(generator), distribution(generator));
    // UB : références pendantes : bounds.min et bounds.max ont le type `const int&`.

    const int x1 = distribution(generator);
    const int x2 = distribution(generator);
    auto bounds = ranges::minmax(x1, x2); // OK : références obtenues vers les lvalues x1 et x2

    std::cout << "v[" << bounds.min << ":" << bounds.max << "]: ";
    for (int i = bounds.min; i < bounds.max; ++i)
        std::cout << v[i] << ' ';
    std::cout << '\n';

    auto [min, max] = ranges::minmax(v);
    std::cout << "smallest: " << min << ", " << "largest: " << max << '\n';
}

Sortie possible :

v[3:9]: 1 5 9 2 6 5
smallest: 1, largest: 9
