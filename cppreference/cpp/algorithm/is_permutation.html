Vérifie si [first1,last1) est une permutation d'un intervalle commençant à first2 :

  • Pour les surcharges (1,2), la seconde plage contient std::distance(first1, last1) éléments.
  • Pour les surcharges (3,4), la seconde plage est [first2,last2).

1,3) Les éléments sont comparés à l'aide de operator==.

2,4) Les éléments sont comparés à l'aide du prédicat binaire donné p.

Si ForwardIt1 et ForwardIt2 ont des types de valeur différents, le programme est mal formé.

Si la fonction de comparaison n'est pas une relation d'équivalence, le comportement est indéfini.

Paramètres

  • first1, last1 — l'intervalle d'éléments à comparer

  • first2, last2 — le second intervalle à comparer

  • p — prédicat binaire qui renvoie true si les éléments doivent être considérés comme égaux.

    La signature de la fonction prédicat doit être équivalente à ce qui suit :

    bool pred(const Type1 &a, const Type2 &b);

    Bien que la signature n'ait pas besoin de const &, la fonction ne doit pas modifier les objets qui lui sont passés et doit pouvoir accepter toutes les valeurs de type (éventuellement const) Type1 et Type2 quelle que soit la catégorie de valeur (ainsi, Type1 & n'est pas autorisé, ni Type1 sauf si pour Type1 un déplacement équivaut à une copie (depuis C++11)).
    Les types Type1 et Type2 doivent être tels que des objets de types InputIt1 et InputIt2 puissent être déréférencés puis implicitement convertis en Type1 et Type2 respectivement.

Exigences sur les types

  • ForwardIt1, ForwardIt2 doit satisfaire aux exigences de LegacyForwardIterator.

Valeur de retour

true si l'intervalle [first1,last1) est une permutation de l'intervalle [first2,last2), false sinon.

Complexité

Étant donné (\scriptsize N)N valant std::distance(first1, last1) :

  1. Exactement (\scriptsize N)N comparaisons utilisant operator== si les deux intervalles sont égaux, sinon (\scriptsize O(N^2))O(N2
    ) comparaisons dans le pire cas.

  2. Exactement (\scriptsize N)N applications du prédicat p si les deux intervalles sont égaux, sinon (\scriptsize O(N^2))O(N2
    ) applications dans le pire cas.

3,4) Si ForwardIt1 et ForwardIt2 sont tous deux LegacyRandomAccessIterator, et que last1 - first1 != last2 - first2 vaut true, aucune comparaison n'est effectuée.

Otherwise:

  1. Exactement (\scriptsize N)N comparaisons utilisant operator== si les deux intervalles sont égaux, sinon (\scriptsize O(N^2))O(N2
    ) comparaisons dans le pire cas.

  2. Exactement (\scriptsize N)N applications du prédicat p si les deux intervalles sont égaux, sinon (\scriptsize O(N^2))O(N2
    ) applications dans le pire cas.

Implémentation possible

template<class ForwardIt1, class ForwardIt2>
bool is_permutation(ForwardIt1 first, ForwardIt1 last,
                    ForwardIt2 d_first)
{
    // ignorer le préfixe commun
    std::tie(first, d_first) = std::mismatch(first, last, d_first);

    // parcourir le reste en comptant le nombre d'occurrences de chaque élément
    // de [first, last) apparaissant dans [d_first, d_last)
    if (first != last)
    {
        ForwardIt2 d_last = std::next(d_first, std::distance(first, last));
        for (ForwardIt1 i = first; i != last; ++i)
        {
            if (i != std::find(first, i, *i))
                continue; // ce *i a été vérifié

            auto m = std::count(d_first, d_last, *i);
            if (m == 0 || std::count(i, last, *i) != m)
                return false;
        }
    }
    return true;
}

Note

std::is_permutation peut être utilisé pour les tests, notamment pour vérifier la correction des algorithmes de réarrangement (par exemple tri, mélange, partitionnement). Si x est un intervalle d'origine et y un intervalle permuté, alors std::is_permutation(x, y) == true signifie que y contiennent les « mêmes » éléments, éventuellement à d'autres positions.

Exemple

#include <algorithm>
#include <iostream>

template<typename Os, typename V>
Os& operator<<(Os& os, const V& v)
{
    os << "{ ";
    for (const auto& e : v)
        os << e << ' ';
    return os << '}';
}

int main()
{
    static constexpr auto v1 = {1, 2, 3, 4, 5};
    static constexpr auto v2 = {3, 5, 4, 1, 2};
    static constexpr auto v3 = {3, 5, 4, 1, 1};

    std::cout << v2 << " is a permutation of " << v1 << ": " << std::boolalpha
              << std::is_permutation(v1.begin(), v1.end(), v2.begin()) << '\n'
              << v3 << " is a permutation of " << v1 << ": "
              << std::is_permutation(v1.begin(), v1.end(), v3.begin()) << '\n';
}

Output:

{ 3 5 4 1 2 } is a permutation of { 1 2 3 4 5 }: true
{ 3 5 4 1 1 } is a permutation of { 1 2 3 4 5 }: false
