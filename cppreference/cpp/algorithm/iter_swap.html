std::iter_swap

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <algorithm>

template< class ForwardIt1, class ForwardIt2 >
void iter_swap( ForwardIt1 a, ForwardIt2 b );  // (constexpr depuis C++20)

Échange les valeurs des éléments désignés par les itérateurs donnés.

Si l'une des conditions suivantes est satisfaite, le comportement est indéfini :

  • a ou b n'est pas déréférençable.
  • *a n'est pas Swappable avec *b.

Paramètres

  • a, b — itérateurs vers les éléments à échanger

Exigences sur les types

  • ForwardIt1, ForwardIt2 doit satisfaire aux exigences de LegacyForwardIterator.

Valeur de retour

(aucune)

Complexité

Constante.

Notes

Ce modèle de fonction modélise la sémantique de l'opération d'échange donnée par Swappable. C'est-à-dire que les surcharges de swap trouvées par ADL ainsi que le repli de std::swap sont prises en compte.

Implémentation possible

template<class ForwardIt1, class ForwardIt2>
constexpr //< depuis C++20
void iter_swap(ForwardIt1 a, ForwardIt2 b)
{
    using std::swap;
    swap(*a, *b);
}

Exemple

Voici une implémentation du tri par sélection en C++.

#include <algorithm>
#include <iostream>
#include <random>
#include <string_view>
#include <vector>

template<class ForwardIt>
void selection_sort(ForwardIt begin, ForwardIt end)
{
    for (ForwardIt it = begin; it != end; ++it)
        std::iter_swap(it, std::min_element(it, end));
}

void println(std::string_view rem, std::vector<int> const& v)
{
    std::cout << rem;
    for (int e : v)
        std::cout << e << ' ';
    std::cout << '\n';
}

template<int min, int max>
int rand_int()
{
    static std::uniform_int_distribution dist(min, max);
    static std::mt19937 gen(std::random_device{}());
    return dist(gen);
}

int main()
{
    std::vector<int> v;
    std::generate_n(std::back_inserter(v), 20, rand_int<-9, +9>);

    std::cout << std::showpos;
    println("Before sort: ", v);
    selection_sort(v.begin(), v.end());
    println("After sort:  ", v);
}
