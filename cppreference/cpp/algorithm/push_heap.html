std::push_heap

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <algorithm>

template< class RandomIt >
void push_heap( RandomIt first, RandomIt last );  // (1) (constexpr depuis C++20)

template< class RandomIt, class Compare >
void push_heap( RandomIt first, RandomIt last, Compare comp );  // (2) (constexpr depuis C++20)

Insère l'élément à la position last - 1 dans le tas [first,last - 1). Le tas après l'insertion sera [first,last).

  1. Le tas est défini par rapport à [operator< (jusqu'à C++20) | std::less{} (depuis C++20)].

  2. Le tas est défini par rapport à comp.

Si l'une des conditions suivantes est satisfaite, le comportement est indéfini :

  • [first,last - 1) n'est pas un tas par rapport au comparateur correspondant.
  • Le type de *first n'est pas Swappable.

(jusqu'à C++11)

  • RandomIt n'est pas ValueSwappable.
  • Le type de *first n'est pas MoveConstructible.
  • Le type de *first n'est pas MoveAssignable.

(depuis C++11)

Paramètres

  • first, last — l'intervalle indiquant le tas après l'insertion

  • comp — objet fonction de comparaison (c'est-à-dire un objet qui satisfait aux exigences de Compare) qui renvoie true si le premier argument est inférieur au second.

    La signature de la fonction de comparaison doit être équivalente à la suivante :

    bool cmp(const Type1& a, const Type2& b);

    Bien que la signature n'ait pas besoin de const&, la fonction ne doit pas modifier les objets qui lui sont passés et doit pouvoir accepter toutes les valeurs de type (éventuellement const) Type1 et Type2 quelle que soit la catégorie de valeur (ainsi, Type1& n'est pas autorisé, ni Type1 sauf si pour Type1 un déplacement est équivalent à une copie (depuis C++11)).
    Les types Type1 et Type2 doivent être tels qu'un objet de type RandomIt puisse être déréférencé puis implicitement converti vers chacun d'eux.

Exigences sur les types

  • RandomIt doit satisfaire aux exigences de LegacyRandomAccessIterator.
  • Compare doit satisfaire aux exigences de Compare.

Complexité

Étant donné (\scriptsize N)N valant std::distance(first, last) :

  1. Au plus (\scriptsize \log(N))log(N) comparaisons utilisant [operator< (jusqu'à C++20) | std::less{} (depuis C++20)].

  2. Au plus (\scriptsize \log(N))log(N) applications de la fonction de comparaison comp.

Exemple

#include <algorithm>
#include <iostream>
#include <string_view>
#include <vector>

void println(std::string_view rem, const std::vector<int>& v)
{
    std::cout << rem;
    for (int e : v)
        std::cout << e << ' ';
    std::cout << '\n';
}

int main()
{
    std::vector<int> v{3, 1, 4, 1, 5, 9};

    std::make_heap(v.begin(), v.end());
    println("after make_heap: ", v);

    v.push_back(6);
    println("after push_back: ", v);

    std::push_heap(v.begin(), v.end());
    println("after push_heap: ", v);
}

Output:

after make_heap: 9 5 4 1 1 3
after push_back: 9 5 4 1 1 3 6
after push_heap: 9 5 6 1 1 3 4
