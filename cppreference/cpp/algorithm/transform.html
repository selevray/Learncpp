std::transform

std::transform applique la fonction donnée aux éléments du ou des intervalles d'entrée donnés, et stocke le résultat dans un intervalle de sortie commençant à d_first.

  1. L'opération unaire unary_op est appliquée aux éléments de [first1,last1).

Si unary_op invalide un itérateur ou modifie un élément dans l'un des intervalles suivants, le comportement est indéfini :

  • [first1,last1].
  • L'intervalle de std::distance(first1, last1) + 1 éléments commençant à d_first.
  1. L'opération binaire binary_op est appliquée à des paires d'éléments de deux intervalles : [first1,last1) et un autre intervalle de std::distance(first1, last1) éléments commençant à first2.

Si binary_op invalide un itérateur ou modifie un élément dans l'un des intervalles suivants, le comportement est indéfini :

  • [first1,last1].
  • L'intervalle de std::distance(first1, last1) + 1 éléments commençant à first2.
  • L'intervalle de std::distance(first1, last1) + 1 éléments commençant à d_first.

2,4) Identique à (1,3), mais exécuté selon policy.

Ces surcharges ne participent à la résolution de surcharge que si toutes les conditions suivantes sont satisfaites :

std::is_execution_policy_v<std::decay_t<ExecutionPolicy>> is true.

(jusqu'à C++20)

std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>> is true.

(depuis C++20)

Paramètres

  • first1, last1 — le premier intervalle d'éléments à transformer

  • first2 — le début du second intervalle d'éléments à transformer

  • d_first — le début de l'intervalle de destination, peut être égal à first1 ou first2

  • policy — la politique d'exécution à utiliser

  • unary_op — objet fonction unaire qui sera appliqué.

    La signature de la fonction doit être équivalente à la suivante :

    Ret fun(const Type &a);

    La signature n'a pas besoin d'avoir const &.
    Le type Type doit être tel qu'un objet de type InputIt puisse être déréférencé puis implicitement converti en Type. Le type Ret doit être tel qu'un objet de type OutputIt puisse être déréférencé et qu'on puisse lui affecter une valeur de type Ret.

  • binary_op — objet fonction d'opération binaire qui sera appliqué.

    La signature de la fonction doit être équivalente à la suivante :

    Ret fun(const Type1 &a, const Type2 &b);

    La signature n'a pas besoin d'avoir const &.
    Les types Type1 et Type2 doivent être tels que des objets de types InputIt1 et InputIt2 puissent être déréférencés puis implicitement convertis en Type1 et Type2 respectivement. Le type Ret doit être tel qu'un objet de type OutputIt puisse être déréférencé et qu'on puisse lui affecter une valeur de type Ret.

Exigences sur les types

  • InputIt, InputIt1, InputIt2 doit satisfaire aux exigences de LegacyInputIterator.
  • OutputIt doit satisfaire aux exigences de LegacyOutputIterator.
  • ForwardIt1, ForwardIt2, ForwardIt3 doit satisfaire aux exigences de LegacyForwardIterator.

Valeur de retour

Itérateur de sortie vers l'élément qui suit le dernier élément transformé.

Complexité

Étant donné (\scriptsize N)N valant std::distance(first1, last1) :

1,2) Exactement (\scriptsize N)N applications de unary_op.

3,4) Exactement (\scriptsize N)N applications de binary_op.

Exceptions

Les surcharges avec un paramètre de modèle nommé ExecutionPolicy signalent les erreurs comme suit :

  • Si l'exécution d'une fonction invoquée dans le cadre de l'algorithme lève une exception et ExecutionPolicy est l'une des politiques standard, std::terminate est appelée. Pour toute autre ExecutionPolicy, le comportement est défini par l'implémentation.
  • Si l'algorithme échoue à allouer de la mémoire, std::bad_alloc est levée.

Implémentation possible

transform (1)

template<class InputIt, class OutputIt, class UnaryOp>
constexpr //< depuis C++20
OutputIt transform(InputIt first1, InputIt last1,
                   OutputIt d_first, UnaryOp unary_op)
{
    for (; first1 != last1; ++d_first, ++first1)
        *d_first = unary_op(*first1);

    return d_first;
}

transform (3)

template<class InputIt1, class InputIt2,
         class OutputIt, class BinaryOp>
constexpr //< depuis C++20
OutputIt transform(InputIt1 first1, InputIt1 last1, InputIt2 first2,
                   OutputIt d_first, BinaryOp binary_op)
{
    for (; first1 != last1; ++d_first, ++first1, ++first2)
        *d_first = binary_op(*first1, *first2);

    return d_first;
}

Notes

std::transform ne garantit pas l'application dans l'ordre de unary_op ni de binary_op. Pour appliquer une fonction à une séquence dans l'ordre, ou pour appliquer une fonction qui modifie les éléments d'une séquence, utilisez std::for_each.

Exemple

#include <algorithm>
#include <cctype>
#include <iomanip>
#include <iostream>
#include <string>
#include <utility>
#include <vector>

void print_ordinals(const std::vector<unsigned>& ordinals)
{
    std::cout << "ordinals: ";
    for (unsigned ord : ordinals)
        std::cout << std::setw(3) << ord << ' ';
    std::cout << '\n';
}

char to_uppercase(unsigned char c)
{
    return std::toupper(c);
}

void to_uppercase_inplace(char& c)
{
    c = to_uppercase(c);
}

void unary_transform_example(std::string& hello, std::string world)
{
    // Transforme la chaîne en majuscules sur place

    std::transform(hello.cbegin(), hello.cend(), hello.begin(), to_uppercase);
    std::cout << "hello = " << std::quoted(hello) << '\n';

    // version de for_each (voir Notes ci-dessus)
    std::for_each(world.begin(), world.end(), to_uppercase_inplace);
    std::cout << "world = " << std::quoted(world) << '\n';
}

void binary_transform_example(std::vector<unsigned> ordinals)
{
    // Transforme les nombres en leurs valeurs doublées

    print_ordinals(ordinals);

    std::transform(ordinals.cbegin(), ordinals.cend(), ordinals.cbegin(),
                   ordinals.begin(), std::plus<>{});

    print_ordinals(ordinals);
}

int main()
{
    std::string hello("hello");
    unary_transform_example(hello, "world");

    std::vector<unsigned> ordinals;
    std::copy(hello.cbegin(), hello.cend(), std::back_inserter(ordinals));
    binary_transform_example(std::move(ordinals));
}

Output:

hello = "HELLO"
world = "WORLD"
ordinals:  72  69  76  76  79
ordinals: 144 138 152 152 158
