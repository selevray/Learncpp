Supprime tous les éléments satisfaisant des critères spécifiques de l'intervalle [first,last) et retourne un itérateur past-the-end vers la nouvelle fin de l'intervalle.

  1. Supprime tous les éléments égaux à value (en utilisant operator==).

  2. Supprime tous les éléments pour lesquels le prédicat p retourne true.

2,4) Identique à (1,3), mais exécuté selon policy.

Ces surcharges ne participent à la résolution de surcharge que si toutes les conditions suivantes sont satisfaites :

std::is_execution_policy_v<std::decay_t<ExecutionPolicy>> is true.

(jusqu'à C++20)

std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>> is true.

(depuis C++20)

Si le type de valeur de ForwardIt n'est pas CopyAssignable, le comportement est indéfini.

(jusqu'à C++11)

Si le type de *first n'est pas MoveAssignable, le comportement est indéfini.

(depuis C++11)

Explication

La suppression se fait en décalant les éléments de l'intervalle de telle sorte que les éléments qui ne doivent pas être supprimés apparaissent au début de l'intervalle.

  • Le décalage se fait par [affectation par copie (jusqu'à C++11) | affectation par déplacement (depuis C++11)].
  • L'opération de suppression est stable : l'ordre relatif des éléments non supprimés reste le même.
  • La séquence sous-jacente de [first,last) n'est pas raccourcie par l'opération de suppression. Soit result l'itérateur retourné :
    • Tous les itérateurs de [result,last) restent déréférençables.
  • Chaque élément de [result,last) se trouve dans un état valide mais non spécifié, car l'affectation par déplacement peut éliminer des éléments en déplaçant ceux qui se trouvaient initialement dans cet intervalle.

(depuis C++11)

Paramètres

  • first, last — l'intervalle d'éléments à traiter

  • value — la valeur des éléments à supprimer

  • policy — la politique d'exécution à utiliser

  • p — prédicat unaire qui renvoie true si l'élément doit être supprimé.

    L'expression p(v) doit être convertible en bool pour chaque argument v de type (éventuellement const) VT, où VT est le type de valeur de ForwardIt, quelle que soit la catégorie de valeur, et ne doit pas modifier v. Ainsi, un type de paramètre de VT& n'est pas autorisé, ni VT sauf si pour VT un déplacement est équivalent à une copie (depuis C++11).

Exigences sur les types

  • ForwardIt doit satisfaire aux exigences de LegacyForwardIterator.
  • UnaryPredicate doit satisfaire aux exigences de Predicate.

Valeur de retour

Itérateur de fin (past-the-end) du nouvel intervalle de valeurs (si ce n'est pas end, il pointe vers une valeur non spécifiée, de même que les itérateurs vers les valeurs situées entre cet itérateur et end).

Complexité

Étant donné (\scriptsize N)N valant std::distance(first, last) :

1,2) Exactement (\scriptsize N)N comparaisons utilisant operator==.

3,4) Exactement (\scriptsize N)N applications du prédicat p.

Exceptions

Les surcharges avec un paramètre de modèle nommé ExecutionPolicy signalent les erreurs comme suit :

  • Si l'exécution d'une fonction invoquée dans le cadre de l'algorithme lève une exception et ExecutionPolicy est l'une des politiques standard, std::terminate est appelée. Pour toute autre ExecutionPolicy, le comportement est défini par l'implémentation.
  • Si l'algorithme échoue à allouer de la mémoire, std::bad_alloc est levée.

Implémentation possible

remove (1)

template<class ForwardIt, class T = typename std::iterator_traits<ForwardIt>::value_type>
ForwardIt remove(ForwardIt first, ForwardIt last, const T& value)
{
    first = std::find(first, last, value);
    if (first != last)
        for (ForwardIt i = first; ++i != last;)
            if (!(*i == value))
                *first++ = std::move(*i);
    return first;
}

remove_if (3)

template<class ForwardIt, class UnaryPred>
ForwardIt remove_if(ForwardIt first, ForwardIt last, UnaryPred p)
{
    first = std::find_if(first, last, p);
    if (first != last)
        for (ForwardIt i = first; ++i != last;)
            if (!p(*i))
                *first++ = std::move(*i);
    return first;
}

Notes

Un appel à remove est généralement suivi d'un appel à la fonction membre erase d'un conteneur pour supprimer effectivement les éléments du conteneur. Ces deux appels constituent ensemble ce que l'on appelle l'idiome Erase-remove.

Le même effet peut également être obtenu à l'aide des fonctions non membres suivantes :

  • std::erase, qui possède des surcharges pour tous les conteneurs de séquence standard.
  • std::erase_if, qui possède des surcharges pour tous les conteneurs standard.

(depuis C++20)

Les fonctions membres de conteneur de nom similaire list::remove, list::remove_if, forward_list::remove et forward_list::remove_if effacent les éléments supprimés.

Ces algorithmes ne peuvent pas être utilisés avec des conteneurs associatifs tels que std::set et std::map car leurs types d'itérateurs ne se déréférencent pas en types MoveAssignable (les clés de ces conteneurs ne sont pas modifiables).

La bibliothèque standard définit également une surcharge de std::remove dans <cstdio>, qui prend un const char* et sert à supprimer des fichiers.

Comme std::remove prend value par référence, il peut avoir un comportement inattendu si c'est une référence à un élément de l'intervalle [first,last).

Exemple

Le code suivant supprime tous les espaces d'une chaîne en décalant vers la gauche tous les caractères qui ne sont pas des espaces, puis en effaçant le surplus. C'est un exemple de l'idiome Erase-remove.

#include <algorithm>
#include <cassert>
#include <cctype>
#include <complex>
#include <iostream>
#include <string>
#include <string_view>
#include <vector>

int main()
{
    std::string str1{"Text with some   spaces"};

    auto noSpaceEnd = std::remove(str1.begin(), str1.end(), ' ');

    // Les espaces ne sont supprimés de la chaîne que logiquement.
    // Notez que l'on utilise une vue : la chaîne d'origine n'est toujours pas réduite :
    std::cout << std::string_view(str1.begin(), noSpaceEnd)
              << " size: " << str1.size() << '\n';

    str1.erase(noSpaceEnd, str1.end());

    // Les espaces sont supprimés physiquement de la chaîne.
    std::cout << str1 << " size: " << str1.size() << '\n';

    std::string str2 = "Text\n with\tsome \t  whitespaces\n\n";
    str2.erase(std::remove_if(str2.begin(),
                              str2.end(),
                              [](unsigned char x) { return std::isspace(x); }),
               str2.end());
    std::cout << str2 << '\n';

    std::vector<std::complex<double>> nums{{2, 2}, {1, 3}, {4, 8}};
    #ifdef __cpp_lib_algorithm_default_value_type
        nums.erase(std::remove(nums.begin(), nums.end(), {1, 3}), nums.end());
    #else
        nums.erase(std::remove(nums.begin(), nums.end(), std::complex<double>{1, 3}),
                   nums.end());
    #endif
    assert((nums == std::vector<std::complex<double>>{{2, 2}, {4, 8}}));
}

Output:

Textwithsomespaces size: 18
Textwithsomewhitespaces
