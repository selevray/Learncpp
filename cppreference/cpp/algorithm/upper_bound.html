Recherche le premier élément de l'intervalle partitionné [first,last) qui est ordonné après value.

  1. L'ordre est déterminé par operator< :

Renvoie le premier itérateur iter dans [first,last) où bool(value < *iter) vaut true, ou last si aucun iter de ce type n'existe.

Si les éléments elem de [first,last) ne sont pas partitionnés par rapport à l'expression bool(value < elem), le comportement est indéfini.

(jusqu'à C++20)

Équivalent à std::upper_bound(first, last, value, std::less{}).

(depuis C++20)

  1. L'ordre est déterminé par comp :

Renvoie le premier itérateur iter dans [first,last) où bool(comp(value, *iter)) vaut true, ou last si aucun iter de ce type n'existe.

Si les éléments elem de [first,last) ne sont pas partitionnés par rapport à l'expression bool(comp(value, elem)), le comportement est indéfini.

Paramètres

  • first, last — l'intervalle partitionné d'éléments à examiner

  • value — valeur à comparer aux éléments

  • comp — prédicat binaire qui renvoie true si le premier argument est ordonné avant le second.

    La signature de la fonction prédicat doit être équivalente à ce qui suit :

    bool pred(const Type1 &a, const Type2 &b);

    Bien que la signature n'ait pas besoin d'avoir const &, la fonction ne doit pas modifier les objets qui lui sont passés et doit pouvoir accepter toutes les valeurs de type (éventuellement const) Type1 et Type2 quelle que soit la catégorie de valeur (ainsi, Type1 & n'est pas autorisé, ni Type1 sauf si pour Type1 un déplacement est équivalent à une copie (depuis C++11)).
    Le type Type1 doit être tel qu'un objet de type T puisse être implicitement converti en Type1. Le type Type2 doit être tel qu'un objet de type ForwardIt puisse être déréférencé puis implicitement converti en Type2.

Exigences sur les types

  • ForwardIt doit satisfaire aux exigences de LegacyForwardIterator.
  • Compare doit satisfaire aux exigences de BinaryPredicate. Il n'est pas requis qu'il satisfasse Compare.

Valeur de retour

Itérateur vers le premier élément de l'intervalle [first,last) ordonné après value, ou last si aucun tel élément n'est trouvé.

Complexité

Étant donné (\scriptsize N)N valant std::distance(first, last) :

  1. Au plus (\scriptsize \log_{2}(N)+O(1))log2(N)+O(1) comparaisons avec value en utilisant [operator< (jusqu'à C++20) | std::less{} (depuis C++20)].

  2. Au plus (\scriptsize \log_{2}(N)+O(1))log2(N)+O(1) applications du comparateur comp.

Toutefois, si ForwardIt n'est pas un LegacyRandomAccessIterator, le nombre d'incréments d'itérateur est linéaire en (\scriptsize N)N. Notamment, les itérateurs std::map, std::multimap, std::set et std::multiset ne sont pas à accès aléatoire, et leurs fonctions membres upper_bound doivent donc être préférées.

template<class ForwardIt, class T = typename std::iterator_traits<ForwardIt>::value_type>
ForwardIt upper_bound(ForwardIt first, ForwardIt last, const T& value)
{
    return std::upper_bound(first, last, value, std::less{});
}

upper_bound (2)

template<class ForwardIt, class T = typename std::iterator_traits<ForwardIt>::value_type,
         class Compare>
ForwardIt upper_bound(ForwardIt first, ForwardIt last, const T& value, Compare comp)
{
    ForwardIt it;
    typename std::iterator_traits<ForwardIt>::difference_type count, step;
    count = std::distance(first, last);

    while (count > 0)
    {
        it = first;
        step = count / 2;
        std::advance(it, step);

        if (!comp(value, *it))
        {
            first = ++it;
            count -= step + 1;
        }
        else
            count = step;
    }

    return first;
}

Notes

Bien que std::upper_bound ne requière que [first,last) soit partitionné, cet algorithme est généralement utilisé dans le cas où [first,last) est trié, de sorte que la recherche dichotomique soit valide pour tout value.

Pour tout itérateur iter dans [first,last), std::upper_bound requiert que value < *iter et comp(value, *iter) soient bien formés, tandis que std::lower_bound requiert à la place que *iter < value et comp(*iter, value) soient bien formés.

Exemple

#include <algorithm>
#include <cassert>
#include <complex>
#include <iostream>
#include <vector>

struct PriceInfo { double price; };

int main()
{
    const std::vector<int> data{1, 2, 4, 5, 5, 6};

    for (int i = 0; i < 7; ++i)
    {
        // Recherche le premier élément supérieur à i
        auto upper = std::upper_bound(data.begin(), data.end(), i);

        std::cout << i << " < ";
        upper != data.end()
            ? std::cout << *upper << " at index " << std::distance(data.begin(), upper)
            : std::cout << "not found";
        std::cout << '\n';
    }

    std::vector<PriceInfo> prices{{100.0}, {101.5}, {102.5}, {102.5}, {107.3}};

    for (double to_find : {102.5, 110.2})
    {
        auto prc_info = std::upper_bound(prices.begin(), prices.end(), to_find,
            [](double value, const PriceInfo& info)
            {
                return value < info.price;
            });

        prc_info != prices.end()
            ? std::cout << prc_info->price << " at index " << prc_info - prices.begin()
            : std::cout << to_find << " not found";
        std::cout << '\n';
    }

    using CD = std::complex<double>;
    std::vector<CD> nums{{1, 0}, {2, 2}, {2, 1}, {3, 0}, {3, 1}};
    auto cmpz = [](CD x, CD y) { return x.real() < y.real(); };
    #ifdef __cpp_lib_algorithm_default_value_type
        auto it = std::upper_bound(nums.cbegin(), nums.cend(), {2, 0}, cmpz);
    #else
        auto it = std::upper_bound(nums.cbegin(), nums.cend(), CD{2, 0}, cmpz);
    #endif
    assert((*it == CD{3, 0}));
}
