std::move_backward

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <algorithm>

template< class BidirIt1, class BidirIt2 >
BidirIt2 move_backward( BidirIt1 first, BidirIt1 last, BidirIt2 d_last );  // (depuis C++11) (constexpr depuis C++20)

Déplace les éléments de l'intervalle [first,last), vers un autre intervalle se terminant à d_last. Les éléments sont déplacés dans l'ordre inverse (le dernier élément est déplacé en premier), mais leur ordre relatif est préservé.

Si d_last se trouve dans (first,last], le comportement est indéfini. Dans ce cas, std::move peut être utilisé à la place.

Paramètres

  • first, last — l'intervalle des éléments à déplacer
  • d_last — fin de l'intervalle de destination

Exigences sur les types

  • BidirIt1, BidirIt2 doit satisfaire aux exigences de LegacyBidirectionalIterator.

Valeur de retour

Itérateur dans l'intervalle de destination, pointant vers le dernier élément déplacé.

Complexité

Exactement std::distance(first, last) affectations par déplacement.

Implémentation possible

template<class BidirIt1, class BidirIt2>
BidirIt2 move_backward(BidirIt1 first, BidirIt1 last, BidirIt2 d_last)
{
    while (first != last)
        *(--d_last) = std::move(*(--last));

    return d_last;
}

Notes

Lors du déplacement d'intervalles qui se chevauchent, std::move convient lorsqu'on déplace vers la gauche (le début de l'intervalle de destination est en dehors de l'intervalle source), tandis que std::move_backward convient lorsqu'on déplace vers la droite (la fin de l'intervalle de destination est en dehors de l'intervalle source).

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>
#include <string>
#include <string_view>
#include <vector>

using container = std::vector<std::string>;

void print(std::string_view comment, const container& src, const container& dst = {})
{
    auto prn = [](std::string_view name, const container& cont)
    {
        std::cout << name;
        for (const auto &s : cont)
            std::cout << (s.empty() ? "∙" : s.data()) << ' ';
        std::cout << '\n';
    };
    std::cout << comment << '\n';
    prn("src: ", src);
    if (dst.empty())
        return;
    prn("dst: ", dst);
}

int main()
{
    container src{"foo", "bar", "baz"};
    container dst{"qux", "quux", "quuz", "corge"};
    print("Non-overlapping case; before move_backward:", src, dst);
    std::move_backward(src.begin(), src.end(), dst.end());
    print("After:", src, dst);

    src = {"snap", "crackle", "pop", "lock", "drop"};
    print("Overlapping case; before move_backward:", src);
    std::move_backward(src.begin(), std::next(src.begin(), 3), src.end());
    print("After:", src);
}

Output:

Non-overlapping case; before move_backward:
src: foo bar baz
dst: qux quux quuz corge
After:
src: ∙ ∙ ∙
dst: qux foo bar baz
Overlapping case; before move_backward:
src: snap crackle pop lock drop
After:
src: ∙ ∙ snap crackle pop
