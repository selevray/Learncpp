Fusionne deux intervalles triés consécutifs [first,middle) et [middle,last) en un seul intervalle trié [first,last).

  1. Si [first,middle) ou [middle,last) n'est pas trié selon [operator< (jusqu'à C++17) | std::less{} (depuis C++20)], le comportement est indéfini.

  2. Si [first,middle) ou [middle,last) n'est pas trié selon comp, le comportement est indéfini.

2,4) Identique à (1,3), mais exécuté selon policy.

Ces surcharges ne participent à la résolution de surcharge que si toutes les conditions suivantes sont satisfaites :

std::is_execution_policy_v<std::decay_t<ExecutionPolicy>> is true.

(jusqu'à C++20)

std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>> is true.

(depuis C++20)

Cette fonction de fusion est stable, ce qui signifie que, pour des éléments équivalents dans les deux intervalles d'origine, les éléments du premier intervalle (en conservant leur ordre d'origine) précèdent les éléments du second intervalle (en conservant leur ordre d'origine).

Si l'une des conditions suivantes est satisfaite, le comportement est indéfini :

  • [first,middle) ou [middle,last) n'est pas un intervalle valide.
  • Le type de *first n'est pas Swappable.

(jusqu'à C++11)

  • BiditIt n'est pas ValueSwappable.
  • Le type de *first n'est pas MoveConstructible.
  • Le type de *first n'est pas MoveAssignable.

(depuis C++11)

Paramètres

  • first — le début du premier intervalle trié

  • middle — la fin du premier intervalle trié et le début du second

  • last — la fin du second intervalle trié

  • policy — la politique d'exécution à utiliser

  • comp — objet fonction de comparaison (c'est-à-dire un objet qui satisfait aux exigences de Compare) qui renvoie true si le premier argument est inférieur au second (c'est-à-dire est ordonné avant).

    La signature de la fonction de comparaison doit être équivalente à la suivante :

    bool cmp(const Type1& a, const Type2& b);

    Bien que la signature n'ait pas besoin de comporter const&, la fonction ne doit pas modifier les objets qui lui sont passés et doit pouvoir accepter toutes les valeurs de type (éventuellement const) Type1 et Type2 quelle que soit la catégorie de valeur (ainsi, Type1& n'est pas autorisé, ni Type1 sauf si pour Type1 un déplacement est équivalent à une copie (depuis C++11)).
    Les types Type1 et Type2 doivent être tels qu'un objet de type BidirIt puisse être déréférencé puis implicitement converti en chacun d'eux.

Exigences sur les types

  • BidirIt doit satisfaire aux exigences de LegacyBidirectionalIterator.
  • Compare doit satisfaire aux exigences de Compare.

Complexité

Étant donné (\scriptsize N)N valant std::distance(first, last) :

  1. Exactement (\scriptsize N-1)N-1 comparaisons utilisant [operator< (jusqu'à C++20) | std::less{} (depuis C++20)] si suffisamment de mémoire supplémentaire est disponible, (\scriptsize O(N \cdot \log(N)))O(N⋅log(N)) comparaisons sinon.

  2. (\scriptsize O(N \cdot \log(N)))O(N⋅log(N)) comparaisons en utilisant [operator< (jusqu'à C++20) | std::less{} (depuis C++20)].

  3. Exactement (\scriptsize N-1)N-1 applications de la fonction de comparaison comp si suffisamment de mémoire supplémentaire est disponible, (\scriptsize O(N \cdot \log(N)))O(N⋅log(N)) applications sinon.

  4. (\scriptsize O(N \cdot \log(N)))O(N⋅log(N)) applications de la fonction de comparaison comp.

Exceptions

Les surcharges avec un paramètre de modèle nommé ExecutionPolicy signalent les erreurs comme suit :

  • Si l'exécution d'une fonction invoquée dans le cadre de l'algorithme lève une exception et ExecutionPolicy est l'une des politiques standard, std::terminate est appelée. Pour toute autre ExecutionPolicy, le comportement est défini par l'implémentation.
  • Si l'algorithme échoue à allouer de la mémoire, std::bad_alloc est levée.

Exemple

Le code suivant est une implémentation du tri fusion.

#include <algorithm>
#include <iostream>
#include <vector>

template<class Iter>
void merge_sort(Iter first, Iter last)
{
    if (last - first > 1)
    {
        Iter middle = first + (last - first) / 2;
        merge_sort(first, middle);
        merge_sort(middle, last);
        std::inplace_merge(first, middle, last);
    }
}

int main()
{
    std::vector<int> v{8, 2, -2, 0, 11, 11, 1, 7, 3};
    merge_sort(v.begin(), v.end());
    for (const auto& n : v)
        std::cout << n << ' ';
    std::cout << '\n';
}

Output:

-2 0 1 2 3 7 8 11 11
