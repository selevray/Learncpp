std::unique

Supprime tous les éléments sauf le premier de chaque groupe consécutif d'éléments équivalents de l'intervalle [first,last) et renvoie un itérateur passé la fin vers la nouvelle fin de l'intervalle.

  1. Les éléments sont comparés à l'aide de operator==.

Si operator== n'établit pas une relation d'équivalence, le comportement est indéfini.

  1. Les éléments sont comparés à l'aide du prédicat binaire donné p.

Si p n'établit pas une relation d'équivalence, le comportement est indéfini.

2,4) Identique à (1,3), mais exécuté selon policy.

Ces surcharges ne participent à la résolution de surcharge que si toutes les conditions suivantes sont satisfaites :

std::is_execution_policy_v<std::decay_t<ExecutionPolicy>> is true.

(jusqu'à C++20)

std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>> is true.

(depuis C++20)

Explication

La suppression se fait en décalant les éléments de l'intervalle de telle sorte que les éléments qui ne doivent pas être supprimés apparaissent au début de l'intervalle.

  • Le décalage se fait par [affectation par copie (jusqu'à C++11) | affectation par déplacement (depuis C++11)].
  • L'opération de suppression est stable : l'ordre relatif des éléments non supprimés reste le même.
  • La séquence sous-jacente de [first,last) n'est pas raccourcie par l'opération de suppression. Soit result l'itérateur retourné :
    • Tous les itérateurs de [result,last) restent déréférençables.
  • Chaque élément de [result,last) se trouve dans un état valide mais non spécifié, car l'affectation par déplacement peut éliminer des éléments en déplaçant ceux qui se trouvaient initialement dans cet intervalle.

(depuis C++11)

Paramètres

  • first, last — l'intervalle d'éléments à traiter

  • policy — la politique d'exécution à utiliser

  • p — prédicat binaire qui renvoie true si les éléments doivent être considérés comme égaux.

    La signature de la fonction prédicat doit être équivalente à ce qui suit :

    bool pred(const Type1 &a, const Type2 &b);

    Bien que la signature n'ait pas besoin de comporter const &, la fonction ne doit pas modifier les objets qui lui sont passés et doit pouvoir accepter toutes les valeurs de type (éventuellement const) Type1 et Type2 quelle que soit la catégorie de valeur (ainsi, Type1 & n'est pas autorisé, ni Type1 sauf si pour Type1 un déplacement est équivalent à une copie (depuis C++11)).
    Les types Type1 et Type2 doivent être tels qu'un objet de type ForwardIt puisse être déréférencé puis implicitement converti en chacun d'eux.

Exigences sur les types

  • ForwardIt doit satisfaire aux exigences de LegacyForwardIterator.
  • Le type de ForwardIt déréférencé doit satisfaire les exigences de MoveAssignable.

Valeur de retour

Un ForwardIt vers la nouvelle fin de l'intervalle.

Complexité

Étant donné (\scriptsize N)N valant std::distance(first, last) :

1,2) Exactement (\scriptsize max(0,N-1))max(0,N-1) comparaisons utilisant operator==.

3,4) Exactement (\scriptsize max(0,N-1))max(0,N-1) applications du prédicat p.

Exceptions

Les surcharges avec un paramètre de modèle nommé ExecutionPolicy signalent les erreurs comme suit :

  • Si l'exécution d'une fonction invoquée dans le cadre de l'algorithme lève une exception et ExecutionPolicy est l'une des politiques standard, std::terminate est appelée. Pour toute autre ExecutionPolicy, le comportement est défini par l'implémentation.
  • Si l'algorithme échoue à allouer de la mémoire, std::bad_alloc est levée.

Implémentation possible

Voir aussi les implémentations dans libstdc++, libc++ et MSVC STL.

unique (1)

template<class ForwardIt>
ForwardIt unique(ForwardIt first, ForwardIt last)
{
    if (first == last)
        return last;

    ForwardIt result = first;
    while (++first != last)
        if (!(*result == *first) && ++result != first)
            *result = std::move(*first);

    return ++result;
}

unique (3)

template<class ForwardIt, class BinaryPredicate>
ForwardIt unique(ForwardIt first, ForwardIt last, BinaryPredicate p)
{
    if (first == last)
        return last;

    ForwardIt result = first;
    while (++first != last)
        if (!p(*result, *first) && ++result != first)
            *result = std::move(*first);

    return ++result;
}

Notes

Un appel à unique est généralement suivi d'un appel à la fonction membre erase d'un conteneur pour supprimer effectivement les éléments du conteneur.

Exemple

#include <algorithm>
#include <iostream>
#include <vector>

int main()
{
    // un vecteur contenant plusieurs éléments en double
    std::vector<int> v{1, 2, 1, 1, 3, 3, 3, 4, 5, 4};
    auto print = [&](int id)
    {
        std::cout << "@" << id << ": ";
        for (int i : v)
            std::cout << i << ' ';
        std::cout << '\n';
    };
    print(1);

    // supprime les doublons consécutifs (adjacents)
    auto last = std::unique(v.begin(), v.end());
    // v contient maintenant {1 2 1 3 4 5 4 x x x}, où « x » est indéterminé
    v.erase(last, v.end());
    print(2);

    // trier puis appliquer unique, pour supprimer tous les doublons
    std::sort(v.begin(), v.end()); // {1 1 2 3 4 4 5}
    print(3);

    last = std::unique(v.begin(), v.end());
    // v contient maintenant {1 2 3 4 5 x x}, où « x » est indéterminé
    v.erase(last, v.end());
    print(4);
}

Output:

@1: 1 2 1 1 3 3 3 4 5 4
@2: 1 2 1 3 4 5 4
@3: 1 1 2 3 4 4 5
@4: 1 2 3 4 5
