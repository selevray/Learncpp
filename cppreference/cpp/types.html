Types de base et macros supplémentaires

Défini dans l'en-tête <cstddef>

  • size_t — type entier non signé renvoyé par l'opérateur sizeof (typedef)
  • ptrdiff_t — type entier signé renvoyé lors de la soustraction de deux pointeurs (typedef)
  • nullptr_t (C++11) — le type du littéral de pointeur nul nullptr (typedef)
  • NULL — constante de pointeur nul définie par l'implémentation (constante macro)
  • max_align_t (C++11) — type trivial dont l'exigence d'alignement est aussi grande que celle de tout autre type scalaire (typedef)
  • offsetof — décalage en octets depuis le début d'un type à disposition standard jusqu'au membre spécifié (macro de fonction)
  • byte (C++17) — le type d'octet (enum)

Défini dans l'en-tête <stdalign.h>

Identification de type à l'exécution

Défini dans l'en-tête <typeinfo>

  • type_info — contient des informations sur un type, la classe renvoyée par l'opérateur typeid (classe)
  • bad_typeid — exception lancée si un argument d'une expression typeid est nul (classe)
  • bad_cast — exception lancée par une expression dynamic_cast invalide, c'est-à-dire lorsqu'un transtypage vers un type référence échoue (classe)

Défini dans l'en-tête <typeindex>

  • type_index (C++11) — enveloppe autour d'un objet type_info, pouvant servir d'index dans les conteneurs associatifs et les conteneurs associatifs non ordonnés (classe)
