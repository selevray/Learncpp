C++ fournit des outils de métaprogrammation, tels que les traits de types, l'arithmétique rationnelle à la compilation et les suites d'entiers à la compilation.

Définitions

Les types suivants sont collectivement appelés types référençables :

  • types objets
  • types de fonctions sans cv ni ref
  • types référence

Pour tout type référençable T, une référence vers celui-ci peut être créée[1].

  1. ↑ Pour les types référence, cela peut se faire via l'effondrement de références.

Traits de types

Les traits de types définissent des interfaces à base de modèles, évaluées à la compilation, permettant d'interroger les propriétés des types.

Tenter de spécialiser un modèle défini dans l'en-tête <type_traits> et listé sur cette page entraîne un comportement indéfini, sauf que std::common_type et std::basic_common_reference (depuis C++20) peuvent être spécialisés selon les besoins de la description.

Un modèle défini dans l'en-tête <type_traits> peut être instancié avec un type incomplet, sauf indication contraire, malgré l'interdiction générale d'instancier des modèles de la bibliothèque standard avec des types incomplets.

Traits de types unaires

Les traits de types unaires permettent d'interroger à la compilation les propriétés booléennes d'un type.

Tous ces traits de types satisfont UnaryTypeTrait ; la caractéristique de base de chaque trait est soit std::true_type, soit std::false_type, selon que la condition correspondante est remplie.

Requêtes de propriétés

Les traits de requête de propriétés permettent d'interroger à la compilation les propriétés entières d'un type.

Tous ces traits de types satisfont UnaryTypeTrait ; la caractéristique de base de chaque trait est std::integral_constant<std::size_t, Value>, où Value est le résultat de la requête de la propriété correspondante.

Défini dans l'en-tête <type_traits>

  • alignment_of (C++11) — obtient les exigences d'alignement du type (modèle de classe)
  • rank (C++11) — obtient le nombre de dimensions d'un type tableau (modèle de classe)
  • extent (C++11) — obtient la taille d'un type tableau selon une dimension spécifiée (modèle de classe)
