decay-copy

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class T >
typename std::decay<T>::type decay-copy( T&& value );  // (depuis C++11) (jusqu'à C++20) ( exposition uniquement* )

template< class T >
    requires std::convertible_to<T, std::decay_t<T>>
constexpr std::decay_t<T> decay-copy( T&& value )
    noexcept(std::is_nothrow_convertible_v<T, std::decay_t<T>>);  // (depuis C++20) ( réservé à l'exposition* )

Renvoie std::forward<T>(value) (converti implicitement en type décomposé), une copie prvalue décomposée de value.

Paramètres

  • value — la valeur à copier

Valeur de retour

Une copie décomposée de value sous forme de prvalue.

Notes

decay-copy a été introduit par la résolution du LWG issue 929. Il est d'abord utilisé dans la bibliothèque de support de la concurrence pour garantir que les arguments sont décomposés lors du passage par valeur, puis il est utilisé dans la bibliothèque des plages.

La fonctionnalité du langage auto(x) introduite en C++23 permet également de créer des copies décomposées sous forme de prvalues. La seule différence est que decay-copy matérialise toujours matérialise value et produit une copie, alors que auto(expr) ne fait rien si expr est une prvalue.

Toutes les utilisations de decay-copy dans la bibliothèque standard (voir ci-dessous), à l'exception de views::all, ranges::take_view et ranges::drop_view, sont remplacées par auto(x) depuis C++23.
