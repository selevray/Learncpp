std::rethrow_if_nested

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <exception>

template< class E >
void rethrow_if_nested( const E& e );  // (depuis C++11) (constexpr depuis C++26)

Si E n'est pas un type de classe polymorphe, ou si std::nested_exception est une classe de base inaccessible ou ambiguë de E, il n'y a aucun effet.

Sinon, effectue

if (auto p = dynamic_cast<const std::nested_exception*>(std::addressof(e)))
    p->rethrow_nested();

Paramètres

  • e — l'objet d'exception à relancer

Notes

Contrairement à de nombreuses fonctions apparentées, cette fonction n'est pas destinée à être appelée avec un std::exception_ptr mais plutôt avec une référence d'exception réelle.

Implémentation possible

namespace details
{
    template<class E>
    struct can_dynamic_cast
        : std::integral_constant<bool,
              std::is_polymorphic<E>::value &&
              (!std::is_base_of<std::nested_exception, E>::value ||
                std::is_convertible<E*, std::nested_exception*>::value)
          > {};

    template<class T>
    void rethrow_if_nested_impl(const T& e, std::true_type)
    {
        if (auto nep = dynamic_cast<const std::nested_exception*>(std::addressof(e)))
            nep->rethrow_nested();
    }

    template<class T>
    void rethrow_if_nested_impl(const T&, std::false_type) {}
}

template<class T>
void rethrow_if_nested(const T& t)
{
    details::rethrow_if_nested_impl(t, details::can_dynamic_cast<T>());
}

Exemple

Démontre la construction et la récursion à travers un objet d'exception imbriquée.

#include <exception>
#include <fstream>
#include <iostream>
#include <stdexcept>
#include <string>

// affiche la chaîne explicative d'une exception. Si l'exception est imbriquée,
// effectue un appel récursif pour afficher la chaîne explicative de l'exception qu'elle contient
void print_exception(const std::exception& e, int level =  0)
{
    std::cerr << std::string(level, ' ') << "exception: " << e.what() << '\n';
    try
    {
        std::rethrow_if_nested(e);
    }
    catch (const std::exception& nestedException)
    {
        print_exception(nestedException, level + 1);
    }
    catch (...) {}
}

// fonction d'exemple qui capture une exception et l'enveloppe dans une exception imbriquée
void open_file(const std::string& s)
{
    try
    {
        std::ifstream file(s);
        file.exceptions(std::ios_base::failbit);
    }
    catch (...)
    {
        std::throw_with_nested(std::runtime_error("Couldn't open " + s));
    }
}

// fonction d'exemple qui capture une exception et l'enveloppe dans une exception imbriquée
void run()
{
    try
    {
        open_file("nonexistent.file");
    }
    catch (...)
    {
        std::throw_with_nested(std::runtime_error("run() failed"));
    }
}

// exécute la fonction d'exemple ci-dessus et affiche l'exception capturée
int main()
{
    try
    {
        run();
    }
    catch (const std::exception& e)
    {
        print_exception(e);
    }
}
