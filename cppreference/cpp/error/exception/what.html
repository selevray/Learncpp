virtual const char* what() const throw();  // (jusqu'à C++11)

virtual const char* what() const noexcept;  // (depuis C++11) (constexpr depuis C++26)

Renvoie la chaîne explicative.

Paramètres

(aucune)

Valeur de retour

Pointeur vers une chaîne terminée par un caractère nul contenant une information explicative. Le pointeur est garanti valide au moins jusqu'à la destruction de l'objet exception dont il est obtenu, ou jusqu'à l'appel d'une fonction membre non const sur cet objet exception.

La chaîne renvoyée est encodée avec le codage ordinaire des littéraux lors de l'évaluation constante.

(depuis C++26)
