std::unexpected

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <exception>

void unexpected();  // (jusqu'à C++11)

[[noreturn]] void unexpected();  // (obsolète en C++11) (supprimé en C++17)

std::unexpected() est appelée par le runtime C++ lorsqu'une spécification d'exception dynamique est violée : une exception est levée depuis une fonction dont la spécification d'exception interdit les exceptions de ce type.

std::unexpected() peut aussi être appelée directement depuis le programme.

Dans les deux cas, std::unexpected appelle le gestionnaire installé actuellement std::unexpected_handler. Le std::unexpected_handler par défaut appelle std::terminate.

Si un destructeur réinitialise le gestionnaire unexpected pendant le déroulement de la pile et que ce déroulement conduit ensuite à l'appel de unexpected, c'est le gestionnaire installé à la fin de l'expression throw qui sera appelé (note : il était ambigu de savoir si la relance appliquait les nouveaux gestionnaires).

(jusqu'à C++11)

Si un destructeur réinitialise le gestionnaire unexpected pendant le déroulement de la pile, il n'est pas spécifié quel gestionnaire sera appelé si ce déroulement conduit ensuite à l'appel de unexpected.

(depuis C++11)

Exceptions

Lève toute exception levée par le std::unexpected_handler actuellement installé.

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.
