std::error_condition::operator=

template< class ErrorConditionEnum >
error_condition& operator=( ErrorConditionEnum e ) noexcept;  // (1) (depuis C++11)

error_condition& operator=( const error_condition& other ) = default;  // (2) (depuis C++11) (déclaré implicitement)

error_condition& operator=( error_condition&& other ) = default;  // (3) (depuis C++11) (déclaré implicitement)

Affecte un contenu à une condition d'erreur.

  1. Affecte la condition d'erreur pour l'énumération e. Appelle effectivement make_error_condition qui n'est trouvée que par la recherche dépendante des arguments pour e, puis remplace *this par le résultat. Cette surcharge ne participe à la résolution de surcharge que si std::is_error_condition_enum<ErrorConditionEnum>::value est true.

2,3) L'opérateur d'affectation par copie et l'opérateur d'affectation par déplacement définis implicitement affectent le contenu de other à *this.

Paramètres

  • e — énumération de condition d'erreur
  • other — une autre condition d'erreur servant à l'affectation

Valeur de retour

*this.
