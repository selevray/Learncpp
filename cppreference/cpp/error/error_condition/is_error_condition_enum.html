std::is_error_condition_enum

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <system_error>

template< class T >
struct is_error_condition_enum;  // (depuis C++11)

Si T est une énumération de condition d'erreur (telle que std::errc), ce modèle fournit la constante membre value égale à true. Pour tout autre type, value vaut false.

Ce modèle peut être spécialisé pour un type défini par le programme afin d'indiquer que ce type est éligible aux conversions implicites std::error_condition.

Modèle de variable auxiliaire

template< class T >
inline constexpr bool is_error_condition_enum_v =
    is_error_condition_enum<T>::value;  // (depuis C++17)
