Compare deux conditions d'erreur.

  1. Vérifie si lhs et rhs sont égaux.

  2. Vérifie si lhs et rhs sont différents.

  3. Vérifie si lhs est strictement inférieur à rhs.

  4. Obtient le résultat de la comparaison à trois voies de lhs et rhs.

  5. Vérifie si code est une correspondance sémantique de cond.

  6. Vérifie si code n'est pas une correspondance sémantique de cond.

Les opérateurs <, <=, >, >= et != sont synthétisés à partir de operator<=> et operator== respectivement.

(depuis C++20)

Paramètres

  • lhs, rhs, cond — conditions d'erreur à comparer
  • code — le code d'erreur à comparer

Valeur de retour

  1. true si la catégorie d'erreur et la valeur d'erreur sont égales.

  2. true si la catégorie d'erreur ou la valeur d'erreur ne sont pas égales.

  3. true si lhs.category() < rhs.category(). Sinon, true si lhs.category() == rhs.category() && lhs.value() < rhs.value(). Sinon, false.

  4. lhs.category() <=> rhs.category() s'il n'est pas std::strong_ordering::equal. Sinon, lhs.value() <=> rhs.value().

  5. true si l'un de code.category().equivalent(code.value(), cond) ou cond.category().equivalent(code, cond.value()).

  6. true si aucun de code.category().equivalent(code.value(), cond) ni cond.category().equivalent(code, cond.value()).
