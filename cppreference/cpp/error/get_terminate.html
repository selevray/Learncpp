std::terminate_handler get_terminate() noexcept;  // (depuis C++11)

Renvoie le std::terminate_handler actuellement installé, qui peut être un pointeur nul.

Cette fonction est thread-safe. Tout appel préalable à std::set_terminate synchronise-avec (voir std::memory_order) cette fonction.

Paramètres

(aucune)

Valeur de retour

Le std::terminate_handler actuellement installé.
