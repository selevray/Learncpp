std::make_exception_ptr

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <exception>

template< class E >
std::exception_ptr make_exception_ptr( E e ) noexcept;  // (depuis C++11) (constexpr depuis C++26)

Crée un std::exception_ptr qui contient une référence vers une copie de e. Cela se fait comme si l'on exécutait le code suivant :

try
{
    throw e;
}
catch(...)
{
    return std::current_exception();
}

Paramètres

  • e — objet exception dont on crée une référence vers la copie

Valeur de retour

Une instance de std::exception_ptr contenant une référence vers la copie de e, ou vers une instance de std::bad_alloc, ou vers une instance de std::bad_exception (voir std::current_exception).

Notes

Le paramètre est passé par valeur et est soumis au découpage (slicing).
