std::system_error::system_error

system_error( const system_error& other ) noexcept;  // (5) (depuis C++11)

Construit un nouvel objet d'erreur système.

  1. Construit avec le code d'erreur ec.

  2. Construit avec le code d'erreur ec et la chaîne explicative what_arg. La chaîne renvoyée par what() est garantie de contenir what_arg comme sous-chaîne.

  3. Construit avec le code d'erreur sous-jacent ev et la catégorie d'erreur associée ecat.

  4. Construit avec le code d'erreur sous-jacent ev, la catégorie d'erreur associée ecat et la chaîne explicative what_arg. La chaîne renvoyée par what() est garantie de contenir what_arg comme sous-chaîne (en supposant qu'elle ne contienne pas de caractère nul intégré).

  5. Constructeur de copie. Initialise le contenu avec celui de other. Si *this et other ont tous deux le type dynamique std::system_error, alors std::strcmp(what(), other.what()) == 0.

Paramètres

  • ec — code d'erreur
  • ev — code d'erreur sous-jacent dans l'énumération associée à ecat
  • ecat — la catégorie d'erreur
  • what_arg — chaîne explicative
  • other — un autre system_error à copier

Exemple

Démontre comment créer une exception system_error à partir d'une valeur errno.

#include <iostream>
#include <system_error>

int main()
{
    try
    {
        throw std::system_error(EDOM, std::generic_category(), "FIX ME");
    }
    catch (const std::system_error& ex)
    {
        std::cout << "code:    [" << ex.code() << "]\n"
                     "message: [" << ex.code().message() << "]\n"
                     "what:    [" << ex.what() << "]\n";
    }
}
