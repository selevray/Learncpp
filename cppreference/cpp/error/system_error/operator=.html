std::system_error::operator=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

system_error& operator=( const system_error& other ) noexcept;  // (depuis C++11)

Affecte le contenu avec celui de other. Si *this et other ont tous deux le type dynamique std::system_error, alors std::strcmp(what(), other.what()) == 0 après l'affectation.

Paramètres

  • other — un autre objet system_error à affecter

Valeur de retour

*this

Exemple

#include <cassert>
#include <cstring>
#include <iostream>
#include <system_error>

void print(const std::system_error& e)
{
    std::cout << "code:    [" << e.code() << "]\n"
                 "message: [" << e.code().message() << "]\n"
                 "what:    [" << e.what() << "]\n\n";
}

int main()
{
    std::system_error e1(EDOM, std::generic_category(), "Error info #1");
    print(e1);

    std::system_error e2(EIO, std::system_category(), "Error info #2");
    print(e2);

    e1 = e2;
    assert(std::strcmp(e1.what(), e2.what()) == 0);
    print(e1);
}
