std::error_code

class error_code;  // (depuis C++11)

std::error_code représente une valeur de code d'erreur dépendante de la plateforme. Chaque objet std::error_code contient une valeur de code d'erreur provenant du système d'exploitation ou d'une interface de bas niveau, ainsi qu'un pointeur vers un objet de type std::error_category, qui correspond à ladite interface. Il n'est pas exigé que les valeurs de code d'erreur soient uniques entre les différentes catégories d'erreurs.
