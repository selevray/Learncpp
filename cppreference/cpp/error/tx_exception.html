Défini dans l'en-tête <stdexcept>

template< class T >
class tx_exception : public std::runtime_error;  // (TM TS)

Définit un type d'exception pouvant être utilisé pour annuler et restaurer une transaction atomique initiée par le mot-clé atomic_cancel.

Si T n'est pas TriviallyCopyable, le programme qui spécialise std::tx_exception<T> est mal formé.
