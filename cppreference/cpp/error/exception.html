std::exception

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <exception>

class exception;

Fournit une interface cohérente pour gérer les erreurs via l'expression throw.

Toutes les exceptions générées par la bibliothèque standard héritent de std::exception.

Toutes les fonctions membres de std::exception sont constexpr.

(depuis C++26)

Fonctions membres

  • (constructeur) — construit l'objet exception (fonction membre publique)
  • (destructeur) [virtuelle] — détruit l'objet exception (fonction membre publique virtuelle)
  • operator= — copie l'objet exception (fonction membre publique)
  • what [virtuelle] — renvoie une chaîne explicative (fonction membre publique virtuelle)

Exigences sur les exceptions standard

Chaque classe de la bibliothèque standard T qui dérive de std::exception possède les fonctions membres publiques suivantes, chacune d'elles [ne lève pas d'exception (jusqu'à C++11) | ayant une spécification d'exception non levante (depuis C++11)]:

  • constructeur par défaut (sauf si d'autres constructeurs sont fournis)
  • constructeur de copie
  • opérateur d'affectation par copie

Le constructeur de copie et l'opérateur d'affectation par copie satisfont la postcondition suivante :

  • Si deux objets lhs et rhs ont tous deux le type dynamique T et que lhs est une copie de rhs, alors std::strcmp(lhs.what(), rhs.what()) est égal à 0.

La fonction membre what() de chacun de ces T satisfait les contraintes spécifiées pour std::exception::what().
