std::generic_category

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <system_error>

const std::error_category& generic_category() noexcept;  // (depuis C++11)

Obtient une référence vers l'objet de catégorie d'erreur statique pour les erreurs génériques. L'objet doit redéfinir la fonction virtuelle error_category::name() pour renvoyer un pointeur vers la chaîne "generic". Il sert à identifier les conditions d'erreur correspondant aux codes POSIX errno.

Paramètres

(aucune)

Valeur de retour

Une référence vers l'objet statique de type d'exécution non spécifié, dérivé de std::error_category.

Exemple

#include <cerrno>
#include <iostream>
#include <string>
#include <system_error>

int main()
{
    std::error_condition econd = std::generic_category().default_error_condition(EDOM);
    std::cout << "Category: " << econd.category().name() << '\n'
              << "Value: " << econd.value() << '\n'
              << "Message: " << econd.message() << '\n';
}

Output:

Category: generic
Value: 33
Message: Numerical argument out of domain
