std::exception_ptr

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <exception>

using exception_ptr = /*unspecified*/  // (depuis C++11)

std::exception_ptr est un type de pointeur pouvant être nul, qui gère un objet exception qui a été lancé et capturé avec std::current_exception. Une instance de std::exception_ptr peut être passée à une autre fonction, éventuellement sur un autre thread, où l'exception peut être relancée et traitée avec une clause catch.

Un std::exception_ptr construit par défaut est un pointeur nul ; il ne pointe vers aucun objet exception.

Deux instances de std::exception_ptr ne sont égales que si elles sont toutes deux nulles ou si elles pointent vers le même objet exception.

std::exception_ptr n'est implicitement convertible vers aucun type arithmétique, énumération ou pointeur. Il est convertible contextuellement en bool, et vaut false s'il est nul, true sinon.

L'objet exception référencé par un std::exception_ptr reste valide tant qu'il subsiste au moins un std::exception_ptr qui le référence : std::exception_ptr est un pointeur intelligent à propriété partagée (note : ceci s'ajoute aux règles habituelles de durée de vie des objets exception).

std::exception_ptr satisfait les exigences de NullablePointer.

Exemple

#include <exception>
#include <iostream>
#include <stdexcept>
#include <string>

void handle_eptr(std::exception_ptr eptr) // le passage par valeur est OK
{
    try
    {
        if (eptr)
            std::rethrow_exception(eptr);
    }
    catch(const std::exception& e)
    {
        std::cout << "Caught exception: '" << e.what() << "'\n";
    }
}

int main()
{
    std::exception_ptr eptr;

    try
    {
        [[maybe_unused]]
        char ch = std::string().at(1); // ceci génère un std::out_of_range
    }
    catch(...)
    {
        eptr = std::current_exception(); // capture
    }

    handle_eptr(eptr);

} // le destructeur de std::out_of_range est appelé ici, lorsque eptr est détruit

Sortie possible :

Caught exception: 'basic_string::at: __n (which is 1) >= this->size() (which is 0)'
