Défini dans l'en-tête <stdexcept>

class runtime_error;

Définit un type d'objet à lever comme exception. Il signale les erreurs dues à des événements hors de la portée du programme et qui ne peuvent pas être facilement prévues.

std::runtime_error::runtime_error

runtime_error( const std::string& what_arg );  // (1)

runtime_error( const char* what_arg );  // (2)

runtime_error( const runtime_error& other );  // (3) (noexcept depuis C++11)

  1. Construit l'objet exception avec what_arg comme chaîne explicative. Après la construction, std::strcmp(what(), what_arg.c_str()) == 0.

  2. Construit l'objet exception avec what_arg comme chaîne explicative. Après la construction, std::strcmp(what(), what_arg) == 0.

  3. Constructeur de copie. Si *this et other ont tous deux pour type dynamique std::runtime_error, alors std::strcmp(what(), other.what()) == 0. Aucune exception ne peut être levée par le constructeur de copie.

Paramètres

  • what_arg — chaîne explicative
  • other — un autre objet exception à copier

Exceptions

1,2) Peut lever std::bad_alloc.

Notes

Comme la copie de std::runtime_error n'est pas autorisée à lever d'exceptions, ce message est généralement stocké en interne sous forme de chaîne à comptage de références allouée séparément. C'est aussi pour cette raison qu'il n'existe aucun constructeur acceptant std::string&& : il devrait de toute façon copier le contenu.

Avant la résolution du LWG issue 254, le constructeur autre que de copie ne pouvait accepter que std::string. Il rendait l'allocation dynamique obligatoire pour construire un objet std::string.

Après la résolution du LWG issue 471, une classe d'exception standard dérivée doit disposer d'un constructeur de copie accessible publiquement. Il peut être défini implicitement tant que les chaînes explicatives obtenues par what() sont identiques pour l'objet original et l'objet copié.

std::runtime_error::operator=
