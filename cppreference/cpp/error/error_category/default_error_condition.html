std::error_category::default_error_condition

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

virtual std::error_condition default_error_condition( int val ) const noexcept;  // (depuis C++11)

Renvoie la condition d'erreur correspondant à la valeur d'erreur donnée.

Équivalent à std::error_condition(val, *this).

Les classes dérivées de error_category peuvent surcharger cette fonction afin de faire correspondre certaines valeurs d'erreur à une catégorie générique. Par exemple, std::system_category surcharge cette fonction pour faire correspondre les valeurs d'erreur qui correspondent aux valeurs POSIX errno à std::generic_category.

Paramètres

  • val — valeur d'erreur pour laquelle renvoyer la condition d'erreur

Valeur de retour

La condition d'erreur correspondant au code d'erreur donné.
