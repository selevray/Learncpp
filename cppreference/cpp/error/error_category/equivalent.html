std::error_category::equivalent

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

virtual bool equivalent( int code,
                         const std::error_condition& condition ) const noexcept;  // (1) (depuis C++11)

virtual bool equivalent( const std::error_code& code,
                         int condition ) const noexcept;  // (2) (depuis C++11)

Vérifie si le code d'erreur est équivalent à une condition d'erreur pour la catégorie d'erreur représentée par *this.

  1. Équivalent à default_error_condition(code) == condition.

  2. Équivalent à *this == code.category() && code.value() == condition.

Paramètres

  • code — indique le code d'erreur à comparer
  • condition — indique la condition d'erreur à comparer

Valeur de retour

true si le code d'erreur est équivalent à la condition d'erreur donnée pour la catégorie d'erreur représentée par *this, false sinon.
