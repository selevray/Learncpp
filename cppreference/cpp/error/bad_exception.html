std::bad_exception

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <exception>

class bad_exception;

std::bad_exception est le type de l'exception levée par l'environnement d'exécution C++ dans les situations suivantes :

  • Si std::exception_ptr stocke une copie de l'exception capturée et si le constructeur de copie de l'objet exception capturé par std::current_exception lève une exception, l'exception capturée est une instance de std::bad_exception.

(depuis C++11)

  • Si une spécification d'exception dynamique est violée et si std::unexpected lève ou relance une exception qui viole toujours la spécification d'exception, mais que la spécification autorise std::bad_exception, std::bad_exception est levée.

(jusqu'à C++17)

Exemple

Ne se compile que dans les modes C++14 ou antérieurs (peut générer des avertissements).

#include <exception>
#include <iostream>
#include <stdexcept>

void my_unexp()
{
    throw;
}

void test()
    throw(std::bad_exception) // Spécifications d'exception dynamiques
                              // sont obsolètes depuis C++11
{
    throw std::runtime_error("test");
}

int main()
{
    std::set_unexpected(my_unexp); // Obsolète en C++11, supprimé en C++17

    try
    {
        test();
    }
    catch (const std::bad_exception& e)
    {
        std::cerr << "Caught " << e.what() << '\n';
    }
}
