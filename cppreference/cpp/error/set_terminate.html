std::set_terminate

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <exception>

std::terminate_handler set_terminate( std::terminate_handler f ) throw();  // (jusqu'à C++11)

std::terminate_handler set_terminate( std::terminate_handler f ) noexcept;  // (depuis C++11)

Définit f comme nouvelle fonction de gestion globale de terminaison et renvoie le gestionnaire précédemment installé std::terminate_handler. f doit terminer l'exécution du programme sans retourner à son appelant, sinon le comportement est indéfini.

Cette fonction est thread-safe. Chaque appel à std::set_terminate synchronise-avec (voir std::memory_order) les appels ultérieurs à std::set_terminate et std::get_terminate.

(depuis C++11)

Paramètres

  • f — pointeur vers une fonction de type std::terminate_handler, ou pointeur nul

Valeur de retour

Le gestionnaire de terminaison précédemment installé, ou une valeur de pointeur nul si aucun n'a été installé.

Exemple

#include <cstdlib>
#include <exception>
#include <iostream>

int main()
{
    std::set_terminate([]()
    {
        std::cout << "Unhandled exception\n" << std::flush;
        std::abort();
    });
    throw 1;
}

Sortie possible :

Unhandled exception
bash: line 7:  7743 Aborted                 (core dumped) ./a.out

Le gestionnaire de terminaison fonctionne aussi pour les threads lancés, il peut donc servir d'alternative à l'enveloppement de la fonction du thread dans un bloc try/catch. Dans l'exemple suivant, comme l'exception n'est pas gérée, std::terminate sera appelée.

#include <iostream>
#include <thread>

void run()
{
    throw std::runtime_error("Thread failure");
}

int main()
{
    try
    {
        std::thread t{run};
        t.join();
        return EXIT_SUCCESS;
    }
    catch (const std::exception& ex)
    {
        std::cerr << "Exception: " << ex.what() << '\n';
    }
    catch (...)
    {
        std::cerr << "Unknown exception caught\n";
    }
    return EXIT_FAILURE;
}

Sortie possible :

terminate called after throwing an instance of 'std::runtime_error'
  what():  Thread failure
Aborted (core dumped)

Avec l'introduction du gestionnaire de terminaison, l'exception levée depuis un thread autre que le thread principal peut être analysée, et la sortie peut se faire proprement.

#include <iostream>
#include <thread>

class foo
{
public:
    foo() { std::cerr << "foo::foo()\n"; }
    ~foo() { std::cerr << "foo::~foo()\n"; }
};

// Objet statique, dont le destructeur est appelé à la sortie
foo f;

void run()
{
    throw std::runtime_error("Thread failure");
}

int main()
{
    std::set_terminate([]()
    {
        try
        {
            std::exception_ptr eptr{std::current_exception()};
            if (eptr)
            {
                std::rethrow_exception(eptr);
            }
            else
            {
                std::cerr << "Exiting without exception\n";
            }
        }
        catch (const std::exception& ex)
        {
            std::cerr << "Exception: " << ex.what() << '\n';
        }
        catch (...)
        {
            std::cerr << "Unknown exception caught\n";
        }
        std::exit(EXIT_FAILURE);
    });

    std::thread t{run};
    t.join();
}

Output:

foo::foo()
Exception: Thread failure
foo::~foo()
