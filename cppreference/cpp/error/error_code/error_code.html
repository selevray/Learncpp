Construit un nouveau code d'erreur.

  1. Construit un code d'erreur avec la valeur par défaut. Équivalent à error_code(0, std::system_category()).

  2. Construit un code d'erreur avec ec comme code d'erreur dépendant de la plateforme et ecat comme catégorie d'erreur correspondante.

  3. Construit un code d'erreur à partir d'une énumération de code d'erreur e. Équivalent à make_error_code(e), où make_error_code n'est trouvé que par recherche dépendante des arguments. Cette surcharge ne participe à la résolution de surcharge que si std::is_error_code_enum<ErrorCodeEnum>::value est true.

4,5) Constructeur de copie et constructeur de déplacement définis implicitement. Initialise le code d'erreur avec le contenu de other.

Paramètres

  • other — autre code d'erreur avec lequel initialiser
  • ec — code d'erreur dépendant de la plateforme avec lequel construire
  • ecat — catégorie d'erreur correspondant à ec
  • e — énumération de code d'erreur avec laquelle construire
