std::is_error_code_enum

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <system_error>

template< class T >
struct is_error_code_enum;  // (depuis C++11)

Si T est une énumération de code d'erreur (telle que std::io_errc et std::future_errc), ce modèle fournit la constante membre value égale à true. Pour tout autre type, value est false.

Ce modèle peut être spécialisé pour un type défini par le programme afin d'indiquer que le type est éligible à la conversion implicite std::error_code.

Modèle de variable auxiliaire

template< class T >
constexpr bool is_error_code_enum_v = is_error_code_enum<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est une énumération de code d'erreur, false sinon (constante membre statique publique)

Fonctions membres

  • operator() (C++14) — renvoie value (fonction membre publique)
