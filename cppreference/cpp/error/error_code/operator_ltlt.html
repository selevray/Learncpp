template< class CharT, class Traits >
std::basic_ostream<CharT, Traits>&
    operator<<( basic_ostream<CharT, Traits>& os, const error_code& ec );  // (depuis C++11)

Effectue une opération de sortie sur le flux pour le code d'erreur ec.

Équivalent à os << ec.category().name() << ':' << ec.value().

Paramètres

  • os — flux de sortie dans lequel insérer les données
