std::set_unexpected

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <exception>

std::unexpected_handler set_unexpected( std::unexpected_handler f ) throw();  // (jusqu'à C++11)

std::unexpected_handler set_unexpected( std::unexpected_handler f ) noexcept;  // (obsolète en C++11) (supprimé en C++17)

Fait de f le nouveau std::unexpected_handler global et renvoie le std::unexpected_handler précédemment installé.

Cette fonction est thread-safe. Chaque appel à std::set_unexpected synchronise-avec (voir std::memory_order) les appels suivants à std::set_unexpected et std::get_unexpected

(depuis C++11)

Paramètres

  • f — pointeur vers une fonction de type std::unexpected_handler, ou pointeur nul

Valeur de retour

Le gestionnaire unexpected précédemment installé, ou une valeur de pointeur nul si aucun n'était installé.
