std::error_code make_error_code( std::errc e ) noexcept;  // (depuis C++11)

Crée une valeur de code d'erreur pour l'énumération errc e.

Équivalent à std::error_code(static_cast<int>(e), std::generic_category())

Paramètres

  • e — énumération de code d'erreur pour laquelle créer le code d'erreur

Valeur de retour

Code d'erreur correspondant à e.
