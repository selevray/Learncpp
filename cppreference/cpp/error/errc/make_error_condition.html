std::make_error_condition(std::errc)

Défini dans l'en-tête <system_error>

std::error_condition make_error_condition( std::errc e ) noexcept;  // (depuis C++11)

Crée une condition d'erreur pour une valeur errc e. Définit la valeur d'erreur à int(e) et la catégorie d'erreur à std::generic_category.

Paramètres

  • e — valeur d'erreur standard

Valeur de retour

Condition d'erreur pour e.

Exemple

#include <iostream>
#include <string>
#include <system_error>

int main()
{
    auto err = std::make_error_condition(std::errc::invalid_argument);
    std::cout << err.message() << '\n';
}
