std::system_error

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <system_error>

class system_error;  // (depuis C++11)

std::system_error est le type de l'exception levée par diverses fonctions de la bibliothèque (typiquement les fonctions qui interagissent avec les mécanismes du système d'exploitation, par ex. le constructeur de std::thread) lorsque l'exception a un std::error_code associé, qui peut être signalé.

Fonctions membres

  • (constructeur) — construit l'objet system_error (fonction membre publique)
  • operator= — remplace l'objet system_error (fonction membre publique)
  • code — renvoie le code d'erreur (fonction membre publique)
  • what [virtuelle] — renvoie une chaîne explicative (fonction membre publique virtuelle)

Hérité de std::exception

Fonctions membres

  • (destructeur) [virtuelle] — détruit l'objet d'exception (fonction membre publique virtuelle de std::exception)
  • what [virtuelle] — renvoie une chaîne explicative (fonction membre publique virtuelle de std::exception)

Exemple

#include <iostream>
#include <system_error>
#include <thread>

int main()
{
    try
    {
        std::thread().detach(); // tentative de détacher un objet qui n'est pas un thread
    }
    catch(const std::system_error& e)
    {
        std::cout << "Caught system_error with code "
                     "[" << e.code() << "] meaning "
                     "[" << e.what() << "]\n";
    }
}
