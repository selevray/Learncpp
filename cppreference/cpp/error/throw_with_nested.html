std::throw_with_nested

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <exception>

template< class T >
[[noreturn]] void throw_with_nested( T&& t );  // (depuis C++11) (constexpr depuis C++26)

Si std::decay<T>::type est un type de classe non final et non union qui n'est ni std::nested_exception ni dérivé de std::nested_exception, lève une exception d'un type non spécifié qui dérive publiquement à la fois de std::nested_exception et de std::decay<T>::type, et construite à partir de std::forward<T>(t). Le constructeur par défaut de la classe de base nested_exception appelle std::current_exception, en capturant l'objet exception actuellement traité, le cas échéant, dans un std::exception_ptr.

Sinon, lève std::forward<T>(t).

Exige que std::decay<T>::type soit CopyConstructible.

Paramètres

  • t — l'objet exception à lever

Notes

Exemple

Démontre la construction et la récursion à travers un objet d'exception imbriquée.

#include <exception>
#include <fstream>
#include <iostream>
#include <stdexcept>
#include <string>

// affiche la chaîne explicative d'une exception. Si l'exception est imbriquée,
// effectue un appel récursif pour afficher la chaîne explicative de l'exception qu'elle contient
void print_exception(const std::exception& e, int level =  0)
{
    std::cerr << std::string(level, ' ') << "exception: " << e.what() << '\n';
    try
    {
        std::rethrow_if_nested(e);
    }
    catch (const std::exception& nestedException)
    {
        print_exception(nestedException, level + 1);
    }
    catch (...) {}
}

// fonction d'exemple qui capture une exception et l'enveloppe dans une exception imbriquée
void open_file(const std::string& s)
{
    try
    {
        std::ifstream file(s);
        file.exceptions(std::ios_base::failbit);
    }
    catch (...)
    {
        std::throw_with_nested(std::runtime_error("Couldn't open " + s));
    }
}

// fonction d'exemple qui capture une exception et l'enveloppe dans une exception imbriquée
void run()
{
    try
    {
        open_file("nonexistent.file");
    }
    catch (...)
    {
        std::throw_with_nested(std::runtime_error("run() failed"));
    }
}

// exécute la fonction d'exemple ci-dessus et affiche l'exception capturée
int main()
{
    try
    {
        run();
    }
    catch (const std::exception& e)
    {
        print_exception(e);
    }
}
