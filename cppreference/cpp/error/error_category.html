std::error_category

class error_category;  // (depuis C++11)

std::error_category sert de classe de base aux types de catégories d'erreurs spécifiques, tels que std::system_category, std::iostream_category, etc. Chaque classe de catégorie spécifique définit la correspondance error_code - error_condition et contient les chaînes explicatives de tous les error_conditions. Les objets des classes de catégories d'erreurs sont traités comme des singletons, passés par référence.
