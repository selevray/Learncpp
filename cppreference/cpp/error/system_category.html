std::system_category

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <system_error>

const std::error_category& system_category() noexcept;  // (depuis C++11)

Obtient une référence vers l'objet de catégorie d'erreur statique pour les erreurs signalées par le système d'exploitation. L'objet doit redéfinir la fonction virtuelle std::error_category::name() pour renvoyer un pointeur vers la chaîne "system". Il doit aussi redéfinir la fonction virtuelle std::error_category::default_error_condition() pour faire correspondre les codes d'erreur qui correspondent aux valeurs POSIX errno à std::generic_category.

Paramètres

(aucune)

Valeur de retour

Une référence vers l'objet statique de type d'exécution non spécifié, dérivé de std::error_category.

Notes

Sous Windows, system_category() associe généralement certains codes d'erreur Windows à des codes POSIX. Sous POSIX, system_category() tend à être équivalent à std::generic_category(), à part le nom.

Exemple

#include <iomanip>
#include <iostream>
#include <string>
#include <system_error>

int main()
{
    for (int const code : {EDOM, 10001})
    {
        const std::error_condition econd =
            std::system_category().default_error_condition(code);

        std::cout << "Category: " << econd.category().name() << '\n'
                  << "Value:    " << econd.value() << '\n'
                  << "Message:  " << econd.message() << "\n\n";
    }
}

Sortie possible :

Category: generic
Value:    33
Message:  Numerical argument out of domain

Category: system
Value:    10001
Message:  Unknown error 10001
