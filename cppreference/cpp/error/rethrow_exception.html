std::rethrow_exception

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <exception>

[[noreturn]] void rethrow_exception( std::exception_ptr p );  // (depuis C++11) (constexpr depuis C++26)

Lève l'objet d'exception précédemment capturé référencé par le pointeur d'exception p, ou une copie de cet objet.

Il n'est pas spécifié si une copie est faite. Si une copie est faite, son stockage est alloué de manière non spécifiée.

Le comportement est indéfini si p est nul.

Paramètres

  • p — std::exception_ptr non nul

Exceptions

L'objet d'exception référencé par p si aucune copie n'est faite.

Sinon, une copie de cet objet d'exception si l'implémentation a réussi à copier l'objet d'exception.

Sinon, std::bad_alloc ou l'exception levée lors de la copie de l'objet d'exception, si l'allocation ou la copie échoue, respectivement.

Notes

Avant P1675R2, rethrow_exception n'était pas autorisée à copier l'objet d'exception, ce qui est irréalisable sur certaines plateformes où les objets d'exception sont alloués sur la pile.

Exemple

#include <exception>
#include <iostream>
#include <stdexcept>
#include <string>

void handle_eptr(std::exception_ptr eptr) // le passage par valeur est OK
{
    try
    {
        if (eptr)
            std::rethrow_exception(eptr);
    }
    catch(const std::exception& e)
    {
        std::cout << "Caught exception: '" << e.what() << "'\n";
    }
}

int main()
{
    std::exception_ptr eptr;

    try
    {
        [[maybe_unused]]
        char ch = std::string().at(1); // ceci génère un std::out_of_range
    }
    catch(...)
    {
        eptr = std::current_exception(); // capture
    }

    handle_eptr(eptr);

} // le destructeur de std::out_of_range est appelé ici, lorsque eptr est détruit
