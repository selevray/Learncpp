std::nested_exception

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <exception>

class nested_exception;  // (depuis C++11)

std::nested_exception est une classe mixin polymorphe qui peut capturer et stocker l'exception courante, ce qui permet d'imbriquer des exceptions de types quelconques les unes dans les autres.

Toutes les fonctions membres de std::nested_exception sont constexpr.

(depuis C++26)

Fonctions membres

  • (constructeur) — construit un nested_exception (fonction membre publique)
  • (destructeur) [virtuelle] — détruit une nested exception (fonction membre publique virtuelle)
  • operator= — remplace le contenu d'un nested_exception (fonction membre publique)
  • rethrow_nested — lève l'exception stockée (fonction membre publique)
  • nested_ptr — obtient un pointeur vers l'exception stockée (fonction membre publique)

Fonctions non membres

  • throw_with_nested (C++11) — lève son argument avec std::nested_exception mélangé à (modèle de fonction)
  • rethrow_if_nested (C++11) — lève l'exception depuis un std::nested_exception (modèle de fonction)

Exemple

Démontre la construction et la récursion à travers un objet d'exception imbriquée.

#include <exception>
#include <fstream>
#include <iostream>
#include <stdexcept>
#include <string>

// affiche la chaîne explicative d'une exception. Si l'exception est imbriquée,
// effectue un appel récursif pour afficher la chaîne explicative de l'exception qu'elle contient
void print_exception(const std::exception& e, int level =  0)
{
    std::cerr << std::string(level, ' ') << "exception: " << e.what() << '\n';
    try
    {
        std::rethrow_if_nested(e);
    }
    catch (const std::exception& nestedException)
    {
        print_exception(nestedException, level + 1);
    }
    catch (...) {}
}

// fonction d'exemple qui capture une exception et l'enveloppe dans une exception imbriquée
void open_file(const std::string& s)
{
    try
    {
        std::ifstream file(s);
        file.exceptions(std::ios_base::failbit);
    }
    catch (...)
    {
        std::throw_with_nested(std::runtime_error("Couldn't open " + s));
    }
}

// fonction d'exemple qui capture une exception et l'enveloppe dans une exception imbriquée
void run()
{
    try
    {
        open_file("nonexistent.file");
    }
    catch (...)
    {
        std::throw_with_nested(std::runtime_error("run() failed"));
    }
}

// exécute la fonction d'exemple ci-dessus et affiche l'exception capturée
int main()
{
    try
    {
        run();
    }
    catch (const std::exception& e)
    {
        print_exception(e);
    }
}
