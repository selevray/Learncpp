Défini dans l'en-tête <text_encoding>

struct text_encoding;  // (depuis C++26)

La classe text_encoding fournit un mécanisme d'identification des encodages de caractères. Elle sert à déterminer le codage des littéraux de caractères ordinaires de l'environnement de traduction à la compilation, et l'encodage de caractères de l'environnement d'exécution à l'exécution.

Chaque objet text_encoding encapsule un schéma d'encodage de caractères, identifié de manière unique par un énumérateur dans text_encoding::id et par un nom correspondant représenté par une chaîne d'octets terminée par un caractère nul. Ceux-ci sont accessibles via les fonctions membres mib() et name(), respectivement. La détermination du fait qu'un objet représente un schéma d'encodage implémenté dans l'environnement de traduction ou d'exécution est définie par l'implémentation.

La classe text_encoding est un type TriviallyCopyable. L'objet tableau représentant le nom correspondant du schéma d'encodage est imbriqué dans l'objet text_encoding lui-même. Le nom stocké est limité à un maximum de max_name_length caractères, à l'exclusion du caractère nul '\0'.

La classe prend en charge les encodages de caractères enregistrés et non enregistrés. Les encodages enregistrés sont ceux du registre des jeux de caractères IANA, à l'exclusion des encodages suivants :

  • NATS-DANO (33)
  • NATS-DANO-ADD (34).

En outre, la classe permet d'accéder, pour les encodages de caractères enregistrés, à :

  1. Nom principal : le nom officiel spécifié dans le registre.
  2. Alias : un sur-ensemble défini par l'implémentation des alias du registre.
  3. Valeur MIBenum : un identifiant unique permettant d'identifier les encodages de caractères codés.

Les encodages non enregistrés peuvent être représentés avec un énumérateur id::other ou id::unknown et un nom personnalisé.

Un objet text_encoding e dont la valeur MIBenum n'est ni id::other ni id::unknown maintient les invariants suivants :

  • *e.name() != '\0' est true, et
  • e.mib() == std::text_encoding(e.name()).mib() is true.

Notes

Lorsqu'on travaille avec des codages de caractères, il est important de noter que les noms principaux ou les alias de deux codages de caractères enregistrés distincts ne sont pas équivalents lorsqu'ils sont comparés à l'aide de Charset Alias Matching, tel que décrit par la Unicode Technical Standard.

Par commodité, les énumérateurs de text_encoding::id sont introduits comme membres de text_encoding et peuvent être accédés directement. Cela signifie que text_encoding::ASCII et text_encoding::id::ASCII désignent la même entité.

Il est recommandé que l'implémentation traite les codages enregistrés comme non interchangeables. De plus, le nom principal d'un codage enregistré ne doit pas être utilisé pour décrire un codage non enregistré similaire mais différent, sauf s'il existe un précédent clair pour le faire.

Exemple

#include <locale>
#include <print>
#include <text_encoding>

int main()
{
    // le codage du littéral est connu à la compilation
    constexpr std::text_encoding literal_encoding = std::text_encoding::literal();

    // vérifier le codage du littéral
    static_assert(literal_encoding.mib() != std::text_encoding::other &&
                  literal_encoding.mib() != std::text_encoding::unknown);

    // le codage de l'environnement n'est connu qu'à l'exécution
    std::text_encoding env_encoding = std::text_encoding::environment();

    // codage associé à la locale par défaut
    std::text_encoding locale_encoding = std::locale("").encoding();

    std::println("The literal encoding is {}", literal_encoding.name());
    std::println("The aliases of literal encoding:");
    for (const char* alias_name : literal_encoding.aliases())
        std::println(" -> {}", alias_name);

    if (env_encoding == locale_encoding)
        std::println("Both environment and locale encodings are the same");

    std::println("The environment encoding is {}", env_encoding.name());
    std::println("The aliases of environment encoding:");
    for (const char* alias_name : env_encoding.aliases())
        std::println(" -> {}", alias_name);
}
