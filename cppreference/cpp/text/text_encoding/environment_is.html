std::text_encoding::environment_is

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< id I >
static bool environment_is();  // (depuis C++26)

Vérifie si l'encodage de l'environnement est égal à l'encodage dont la valeur MIBenum est la valeur spécifiée I. Un appel à cette fonction est équivalent à return environment() == I;.

Cette fonction est supprimée sauf si CHAR_BIT est 8.

Paramètres de modèle

  • I — un text_encoding::id dont la valeur doit être comparée

Valeur de retour

true si environment() est égal à I; false sinon.
