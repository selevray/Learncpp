std::text_encoding::literal

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static consteval text_encoding literal() noexcept;  // (depuis C++26)

Construit un nouvel objet text_encoding représentant l'encodage des littéraux de caractères ordinaires. Il sert à déterminer l'encodage de caractères appliqué aux littéraux de caractère ordinaires ou de chaîne (par exemple "This is literal").

Cette fonction est supprimée sauf si CHAR_BIT est 8.

Paramètres

(aucune)

Valeur de retour

L'objet contenant la représentation de l'encodage des littéraux ordinaires.

Notes

Cette fonction peut être implémentée en construisant text_encoding à l'aide de macros intégrées propres au compilateur, telles que __clang_literal_encoding__ pour Clang, ou __GNUC_EXECUTION_CHARSET_NAME pour GCC. Ces macros, connues à la compilation, se développent en un littéral de chaîne étroite contenant le nom du jeu de caractères d'exécution étroit utilisé (encodage des littéraux ordinaires).

La valeur renvoyée par literal() peut dépendre d'options du compilateur telles que -fexec-charset=encoding-name dans GCC ou Clang, ou /execution-charset:encoding-name dans MSVC.

Exemple

Cet exemple démontre l'assertion selon laquelle l'encodage des littéraux ordinaires devrait être UTF-8.

#include <text_encoding>

static_assert(std::text_encoding::literal() == std::text_encoding::UTF8);

int main()
{
    // si l'encodage des littéraux est UTF-8, alors cette chaîne littérale sans préfixe est
    // encodée en UTF-8
    constexpr char green_heart[] = "\N{GREEN HEART}";

    // cette chaîne littérale avec préfixe est toujours encodée en UTF-8, quel que soit l'
    // encodage des littéraux
    constexpr char8_t green_heart_u8[] = u8"\N{GREEN HEART}";
}
