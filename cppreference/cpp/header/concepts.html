### Concepts {#Concepts}

##### Concepts du langage de base {#Core_language_concepts}

  • same_as (C++20) — spécifie qu'un type est identique à un autre type (concept)
  • derived_from (C++20) — spécifie qu'un type dérive d'un autre type (concept)
  • convertible_to (C++20) — spécifie qu'un type est implicitement convertible en un autre type (concept)
  • common_reference_with (C++20) — spécifie que deux types partagent un type de référence commun (concept)
  • common_with (C++20) — spécifie que deux types partagent un type commun (concept)
  • integral (C++20) — spécifie qu'un type est un type entier (concept)
  • signed_integral (C++20) — spécifie qu'un type est un type entier signé (concept)
  • unsigned_integral (C++20) — spécifie qu'un type est un type entier non signé (concept)
  • floating_point (C++20) — spécifie qu'un type est un type à virgule flottante (concept)
  • assignable_from (C++20) — spécifie qu'un type est affectable à partir d'un autre type (concept)
  • swappableswappable_with (C++20) — spécifie qu'un type peut être échangé, ou que deux types peuvent être échangés entre eux (concept)
  • destructible (C++20) — spécifie qu'un objet du type peut être détruit (concept)
  • constructible_from (C++20) — spécifie qu'une variable du type peut être construite à partir de, ou liée à, un ensemble de types d'arguments (concept)
  • default_initializable (C++20) — spécifie qu'un objet d'un type peut être construit par défaut (concept)
  • move_constructible (C++20) — spécifie qu'un objet d'un type peut être construit par déplacement (concept)
  • copy_constructible (C++20) — spécifie qu'un objet d'un type peut être construit par copie et construit par déplacement (concept)

##### Concepts de comparaison {#Comparison_concepts}

  • equality_comparableequality_comparable_with (C++20) — spécifie que l'opérateur == est une relation d'équivalence (concept)
  • totally_orderedtotally_ordered_with (C++20) — spécifie que les opérateurs de comparaison du type définissent un ordre total (concept)

##### Concepts d'objet {#Object_concepts}

  • movable (C++20) — spécifie qu'un objet d'un type peut être déplacé et échangé (concept)
  • copyable (C++20) — spécifie qu'un objet d'un type peut être copié, déplacé et échangé (concept)
  • semiregular (C++20) — spécifie qu'un objet d'un type peut être copié, déplacé, échangé et construit par défaut (concept)
  • regular (C++20) — spécifie qu'un type est régulier, c'est-à-dire qu'il est à la fois semiregular et equality_comparable (concept)

##### Concepts d'objets appelables {#Callable_concepts}

  • invocableregular_invocable (C++20) — spécifie qu'un type appelable peut être invoqué avec un ensemble donné de types d'arguments (concept)
  • predicate (C++20) — spécifie qu'un type appelable est un prédicat booléen (concept)
  • relation (C++20) — spécifie qu'un type appelable est une relation binaire (concept)
  • equivalence_relation (C++20) — spécifie qu'un relation impose une relation d'équivalence (concept)
  • strict_weak_order (C++20) — spécifie qu'un relation impose un ordre faible strict (concept)

### Objets points de personnalisation {#Customization_point_objects}

  • ranges::swap (C++20) — échange les valeurs de deux objets (objet point de personnalisation)

  requires {
    static_cast<common_type_t<T, U>>(declval<T>());
    static_cast<common_type_t<T, U>>(declval<U>());

  common_reference_with<add_lvalue_reference_t<const T>,

  common_reference_with<

    common_reference_t<add_lvalue_reference_t<const T>, add_lvalue_reference_t<const U>>>;

concept assignable_from =
  is_lvalue_reference_v<LHS> &&
  common_reference_with<const remove_reference_t<LHS>&, const remove_reference_t<RHS>&> &&
  requires(LHS lhs, RHS&& rhs) {
    {
      lhs = std::forward<RHS>(rhs)
    } -> same_as<LHS>;
  };

Concept swappable_with

template<class T, class U>
concept swappable_with = common_reference_with<T, U> && requires(T&& t, U&& u) {
  ranges::swap(std::forward<T>(t), std::forward<T>(t));
  ranges::swap(std::forward<U>(u), std::forward<U>(u));
  ranges::swap(std::forward<T>(t), std::forward<U>(u));
  ranges::swap(std::forward<U>(u), std::forward<T>(t));
};
