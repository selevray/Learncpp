En-tête de la bibliothèque standard <cstdio>

Cet en-tête faisait à l'origine partie de la bibliothèque standard C sous le nom <stdio.h>.

Cet en-tête fait partie de la bibliothèque d'entrées/sorties de style C.

### Types {#Types}

  • FILE — type objet, capable de contenir toutes les informations nécessaires au contrôle d'un flux d'E/S C (typedef)
  • fpos_t — type objet non tableau complet, capable de spécifier de manière unique une position dans un fichier, y compris son état d'analyse multioctet (typedef)
  • size_t — type entier non signé renvoyé par l'opérateur sizeof (typedef)

### Macros {#Macros}

  • NULL — constante de pointeur nul définie par l'implémentation (constante macro)
  • stdinstdoutstderr — expression de type FILE* associée au flux d'entrée expression de type FILE* associée au flux de sortie expression de type FILE* associée au flux de sortie d'erreur (constante macro)
  • EOF — expression constante entière de type int et de valeur négative (constante macro)
  • FOPEN_MAX — nombre de fichiers pouvant être ouverts simultanément (constante macro)
  • FILENAME_MAX — taille nécessaire pour un tableau de char afin de contenir le nom de fichier pris en charge le plus long (constante macro)
  • BUFSIZ — taille du tampon utilisé par std::setbuf (constante macro)
  • _IOFBF_IOLBF_IONBF — argument de std::setbuf indiquant une entrée/sortie entièrement tamponnée argument de std::setbuf indiquant une entrée/sortie tamponnée par ligne argument de std::setbuf indiquant une entrée/sortie sans tampon (constante macro)
  • SEEK_SETSEEK_CURSEEK_END — argument de std::fseek indiquant une recherche depuis le début du fichier argument de std::fseek indiquant une recherche depuis la position courante dans le fichier argument de std::fseek indiquant une recherche depuis la fin du fichier (constante macro)
  • TMP_MAX — nombre maximal de noms de fichiers uniques pouvant être générés par std::tmpnam (constante macro)
  • L_tmpnam — taille nécessaire pour un tableau de char afin de contenir le résultat de std::tmpnam (constante macro)

### Fonctions {#Functions}

##### Accès aux fichiers {#File_access}

  • fopen — ouvre un fichier (fonction)
  • freopen — ouvre un flux existant avec un nom différent (fonction)
  • fclose — ferme un fichier (fonction)
  • fflush — synchronise un flux de sortie avec le fichier réel (fonction)
  • setbuf — définit le tampon d'un flux de fichier (fonction)
  • setvbuf — définit le tampon et sa taille pour un flux de fichier (fonction)

##### Entrées/sorties directes {#Direct_input.2Foutput}

  • fread — lit depuis un fichier (fonction)
  • fwrite — écrit dans un fichier (fonction)

##### Entrées/sorties non formatées {#Unformatted_input.2Foutput}

  • fputcputc — écrit un caractère dans un flux de fichier (fonction)
  • fputs — écrit une chaîne de caractères dans un flux de fichier (fonction)
  • getchar — lit un caractère depuis stdin (fonction)
  • gets (deprecated in C++11) (removed in C++14) — lit une chaîne de caractères depuis stdin (fonction)
  • putchar — écrit un caractère dans stdout (fonction)
  • puts — écrit une chaîne de caractères dans stdout (fonction)
  • ungetc — replace un caractère dans un flux de fichier (fonction)

##### Positionnement dans le fichier {#File_positioning}

  • ftell — renvoie l'indicateur de position courante dans le fichier (fonction)
  • fgetpos — obtient l'indicateur de position dans le fichier (fonction)
  • fseek — déplace l'indicateur de position dans le fichier vers un emplacement précis d'un fichier (fonction)
  • fsetpos — déplace l'indicateur de position dans le fichier vers un emplacement précis d'un fichier (fonction)
  • rewind — déplace l'indicateur de position dans le fichier au début d'un fichier (fonction)

##### Gestion des erreurs {#Error_handling}

  • clearerr — efface les erreurs (fonction)
  • feof — vérifie la fin de fichier (fonction)
  • ferror — vérifie la présence d'une erreur de fichier (fonction)
  • perror — affiche une chaîne de caractères correspondant à l'erreur courante dans stderr (fonction)

##### Opérations sur les fichiers {#Operations_on_files}

  • remove — supprime un fichier (fonction)
  • rename — renomme un fichier (fonction)
  • tmpfile — crée et ouvre un fichier temporaire à suppression automatique (fonction)
  • tmpnam — renvoie un nom de fichier unique (fonction)
