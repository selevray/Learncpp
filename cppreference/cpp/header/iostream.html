En-tête de la bibliothèque standard <iostream>

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Cet en-tête fait partie de la bibliothèque Entrées/sorties.

L'inclusion de <iostream> se comporte comme si elle définissait un objet à durée de stockage statique de type std::ios_base::Init, dont le constructeur initialise les objets de flux standard s'il s'agit du premier objet std::ios_base::Init construit, et dont le destructeur vide ces objets (sauf cin et wcin) s'il s'agit du dernier objet std::ios_base::Init détruit.

### Inclusions {#Includes}

  • <ios> (C++11) — classe std::ios_base, modèle de classe std::basic_ios et typedefs
  • <streambuf> (C++11) — modèle de classe std::basic_streambuf
  • <istream> (C++11) — modèle de classe std::basic_istream et typedefs
  • <ostream> (C++11) — modèles de classe std::basic_ostream, std::basic_iostream et typedefs

### Objets {#Objects}

  • cinwcin — lit depuis le flux d'entrée standard C stdin (objet global)
  • coutwcout — écrit dans le flux de sortie standard C stdout (objet global)
  • cerrwcerr — écrit dans le flux d'erreur standard C stderr, sans tampon (objet global)
  • clogwclog — écrit dans le flux d'erreur standard C stderr (objet global)
