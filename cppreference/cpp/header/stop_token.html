En-tête de la bibliothèque standard <stop_token> (depuis C++20)

Cet en-tête fait partie de la bibliothèque prise en charge des threads.

### Classes {#Classes}

  • stop_token (C++20) — une interface permettant de vérifier si une demande d'annulation de std::jthread a été faite (classe)
  • stop_source (C++20) — classe représentant une demande d'arrêt d'un ou plusieurs std::jthread (classe)
  • stop_callback (C++20) — une interface permettant d'enregistrer des rappels sur l'annulation de std::jthread (modèle de classe)
  • never_stop_token (C++26) — fournit une interface de jeton d'arrêt indiquant qu'un arrêt n'est jamais possible ni demandé (classe)
  • inplace_stop_token (C++26) — un jeton d'arrêt qui référence l'état d'arrêt de son objet std::inplace_stop_source associé (classe)
  • inplace_stop_source (C++26) — un stoppable-source qui est l'unique propriétaire de l'état d'arrêt (classe)
  • inplace_stop_callback (C++26) — un rappel d'arrêt pour std::inplace_stop_token (modèle de classe)

### Modèles d'alias {#Alias_templates}

  • stop_callback_for_t (C++26) — obtient le type de rappel pour un type de jeton d'arrêt donné (modèle d'alias)

### Concepts {#Concepts}

  • stoppable_token (C++26) — spécifie l'interface de base des jetons d'arrêt, permettant de vérifier les demandes d'arrêt et si une demande d'arrêt est possible (concept)
  • unstoppable_token (C++26) — spécifie un jeton d'arrêt qui ne permet pas l'arrêt (concept)

### Étiquettes {#Tags}

  • nostopstatenostopstate_t (C++20) — une étiquette utilisée pour stop_source afin d'indiquer l'absence d'état d'arrêt associé lors de la construction (étiquette)
