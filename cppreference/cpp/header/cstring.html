En-tête de la bibliothèque standard <cstring>

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Cet en-tête faisait à l'origine partie de la bibliothèque standard C sous le nom <string.h>.

Cet en-tête concerne les chaînes d'octets de style C terminées par un caractère nul.

Macros

  • NULL — constante de pointeur nul définie par l'implémentation (constante macro)

Types

  • size_t — type entier non signé renvoyé par l'opérateur sizeof (typedef)

Fonctions

##### Manipulation de chaînes {#String_manipulation}

  • strcpy — copie une chaîne dans une autre (fonction)
  • strncpy — copie un certain nombre de caractères d'une chaîne dans une autre (fonction)
  • strcat — concatène deux chaînes (fonction)
  • strncat — concatène un certain nombre de caractères de deux chaînes (fonction)
  • strxfrm — transforme une chaîne de sorte que strcmp produise le même résultat que strcoll (fonction)

##### Examen de chaînes {#String_examination}

  • strlen — renvoie la longueur d'une chaîne donnée (fonction)
  • strcmp — compare deux chaînes (fonction)
  • strncmp — compare un certain nombre de caractères de deux chaînes (fonction)
  • strcoll — compare deux chaînes selon les paramètres régionaux courants (fonction)
  • strchr — trouve la première occurrence d'un caractère (fonction)
  • strrchr — trouve la dernière occurrence d'un caractère (fonction)
  • strspn — renvoie la longueur du segment initial maximal composé uniquement de caractères figurant dans une autre chaîne d'octets , (fonction)
  • strcspn — renvoie la longueur du segment initial maximal composé uniquement de caractères ne figurant pas dans une autre chaîne d'octets , (fonction)
  • strpbrk — trouve la première position de n'importe quel caractère d'un ensemble de séparateurs (fonction)
  • strstr — trouve la première occurrence d'une sous-chaîne de caractères (fonction)
  • strtok — trouve le prochain jeton dans une chaîne d'octets (fonction)

##### Manipulation de tableaux de caractères {#Character_array_manipulation}

  • memchr — recherche dans un tableau la première occurrence d'un caractère (fonction)
  • memcmp — compare deux tampons (fonction)
  • memset — remplit un tampon avec un caractère (fonction)
  • memcpy — copie un tampon dans un autre (fonction)
  • memmove — déplace un tampon vers un autre (fonction)

##### Divers {#Miscellaneous}

  • strerror — renvoie une version textuelle d'un code d'erreur donné (fonction)

Notes
