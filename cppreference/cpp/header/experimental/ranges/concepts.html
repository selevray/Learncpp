Concepts du langage de base

Défini dans l'espace de noms std::experimental::ranges

  • Same — spécifie qu'un type est identique à un autre type (concept)
  • DerivedFrom — spécifie qu'un type dérive d'un autre type (concept)
  • ConvertibleTo — spécifie qu'un type est implicitement convertible en un autre type (concept)
  • CommonReference — spécifie que deux types partagent un type de référence commun (concept)
  • Common — spécifie que deux types partagent un type commun (concept)
  • Integral — spécifie qu'un type est un type entier (concept)
  • SignedIntegral — spécifie qu'un type est un type entier signé (concept)
  • UnsignedIntegral — spécifie qu'un type est un type entier non signé (concept)
  • Assignable — spécifie qu'un type est affectable à partir d'un autre type (concept)
  • SwappableSwappableWith — spécifie qu'un type peut être échangé, ou que deux types peuvent être échangés entre eux (concept)

Concepts de comparaison

Défini dans l'espace de noms std::experimental::ranges

  • Boolean — spécifie qu'un type peut être utilisé dans des contextes booléens (concept)
  • WeaklyEqualityComparableWith — spécifie que deux types peuvent être comparés pour l'égalité à l'aide des opérateurs == et != (concept)
  • EqualityComparableEqualityComparableWith — spécifie que l'opérateur == est une relation d'équivalence (concept)
  • StrictTotallyOrderedStrictTotallyOrderedWith — spécifie que les opérateurs de comparaison du type définissent un ordre total (concept)

Concepts d'objet

Défini dans l'espace de noms std::experimental::ranges

  • Destructible — spécifie qu'un objet du type peut être détruit (concept)
  • Constructible — spécifie qu'une variable du type peut être construite à partir de, ou liée à, un ensemble de types d'arguments (concept)
  • DefaultConstructible — spécifie qu'un objet d'un type peut être construit par défaut (concept)
  • MoveConstructible — spécifie qu'un objet d'un type peut être construit par déplacement (concept)
  • CopyConstructible — spécifie qu'un objet d'un type peut être construit par copie et construit par déplacement (concept)
  • Movable — spécifie qu'un objet d'un type peut être déplacé et échangé (concept)
  • Copyable — spécifie qu'un objet d'un type peut être copié, déplacé et échangé (concept)
  • Semiregular — spécifie qu'un objet d'un type peut être copié, déplacé, échangé et construit par défaut (concept)
  • Regular — spécifie qu'un type est régulier, c'est-à-dire qu'il est à la fois Semiregular et EqualityComparable (concept)

Concepts d'objets appelables

Défini dans l'espace de noms std::experimental::ranges

  • InvocableRegularInvocable — spécifie qu'un type appelable peut être invoqué avec un ensemble donné de types d'arguments (concept)
  • Predicate — spécifie qu'un type appelable est un prédicat booléen (concept)
  • Relation — spécifie qu'un type appelable est une relation binaire (concept)
  • StrictWeakOrder — spécifie qu'un Relation impose un ordre faible strict (concept)
