Concepts liés aux itérateurs

Défini dans l'espace de noms std::experimental::ranges

Concepts d'itérateurs

  • Readable — spécifie qu'un type est lisible en appliquant l'opérateur * (concept)
  • Writable — spécifie qu'une valeur peut être écrite dans l'objet référencé par un itérateur (concept)
  • WeaklyIncrementable — spécifie qu'un type Semiregular peut être incrémenté avec les opérateurs d'incrémentation préfixe et postfixe (concept)
  • Incrementable — spécifie que l'opération d'incrémentation sur un type WeaklyIncrementable préserve l'égalité et que le type est EqualityComparable (concept)
  • Iterator — spécifie que des objets d'un type peuvent être incrémentés et déréférencés (concept)
  • Sentinel — spécifie que les objets d'un type sont une sentinelle pour un type Iterator (concept)
  • SizedSentinel — spécifie que l'opérateur - peut être appliqué à un itérateur et à une sentinelle pour calculer leur différence en temps constant (concept)
  • InputIterator — spécifie qu'un type est un itérateur d'entrée, c'est-à-dire que ses valeurs référencées peuvent être lues et qu'il peut être incrémenté en préfixe et en postfixe (concept)
  • OutputIterator — spécifie qu'un type est un itérateur de sortie pour un type de valeur donné, c'est-à-dire que des valeurs de ce type peuvent y être écrites et qu'il peut être incrémenté en préfixe et en postfixe (concept)
  • ForwardIterator — spécifie qu'un InputIterator est un itérateur avant, prenant en charge la comparaison d'égalité et les parcours multiples (concept)
  • BidirectionalIterator — spécifie qu'un ForwardIterator est un itérateur bidirectionnel, prenant en charge le déplacement en arrière (concept)
  • RandomAccessIterator — spécifie qu'un BidirectionalIterator est un itérateur à accès aléatoire, prenant en charge l'avancement en temps constant et l'indexation (concept)

Concepts des appelables indirects

  • IndirectUnaryInvocableIndirectRegularUnaryInvocable — spécifie qu'un type appelable peut être invoqué avec le résultat de la déréférenciation d'un type Readable (concept)
  • IndirectUnaryPredicate — spécifie qu'un objet appelable, lorsqu'il est invoqué avec le résultat de la déréférenciation d'un type Readable, satisfait Predicate (concept)
  • IndirectRelation — spécifie qu'un objet appelable, lorsqu'il est invoqué avec le résultat de la déréférenciation de certains types Readable, satisfait Relation (concept)
  • IndirectStrictWeakOrder — spécifie qu'un objet appelable, lorsqu'il est invoqué avec le résultat de la déréférenciation de certains types Readable, satisfait StrictWeakOrder (concept)

Exigences communes aux algorithmes

  • IndirectlyMovable — spécifie que des valeurs peuvent être déplacées d'un type Readable vers un type Writable (concept)
  • IndirectlyMovableStorable — spécifie que des valeurs peuvent être déplacées d'un type Readable vers un type Writable, et que le déplacement peut être effectué via un objet intermédiaire (concept)
  • IndirectlyCopyable — spécifie que des valeurs peuvent être copiées d'un type Readable vers un type Writable (concept)
  • IndirectlyCopyableStorable — spécifie que des valeurs peuvent être copiées d'un type Readable vers un type Writable, et que la copie peut être effectuée via un objet intermédiaire (concept)
  • IndirectlySwappable — spécifie que les valeurs référencées par deux types Readable peuvent être échangées (concept)
  • IndirectlyComparable — spécifie que les valeurs référencées par deux types Readable peuvent être comparées (concept)
  • Permutable — spécifie les exigences communes des algorithmes qui réordonnent les éléments sur place (concept)
  • Mergeable — spécifie les exigences des algorithmes qui fusionnent des séquences triées en une séquence de sortie en copiant les éléments (concept)
  • Sortable — spécifie les exigences communes des algorithmes qui permutent des séquences en séquences ordonnées (concept)

Utilitaires de concepts

  • indirect_result_of — calcule le résultat de l'invocation d'un objet appelable sur le résultat de la déréférenciation de certains ensembles de types Readable (modèle de classe)
  • projected — modèle auxiliaire permettant de spécifier les contraintes des algorithmes acceptant des projections (modèle de classe)

  • iter_swap — échange les valeurs référencées par deux objets déréférençables (objet point de personnalisation)

  • value_type — obtient le type de valeur d'un type Readable (modèle de classe)

Opérations sur les itérateurs

Défini dans l'espace de noms std::experimental::ranges

  • advance — fait avancer un itérateur de la distance donnée (modèle de fonction)
  • distance — renvoie la distance entre un itérateur et une sentinelle, ou entre le début et la fin d'un intervalle (modèle de fonction)
  • next — incrémente un itérateur (modèle de fonction)
  • prev — décrémente un itérateur (modèle de fonction)

Adaptateurs d'itérateurs

Défini dans l'espace de noms std::experimental::ranges

  • reverse_iterator — adaptateur d'itérateur pour un parcours en ordre inverse (modèle de classe)
  • back_insert_iterator — adaptateur d'itérateur pour l'insertion à la fin d'un conteneur (modèle de classe)
  • front_insert_iterator — adaptateur d'itérateur pour l'insertion au début d'un conteneur (modèle de classe)
  • insert_iterator — adaptateur d'itérateur pour l'insertion dans un conteneur (modèle de classe)
  • move_iterator — adaptateur d'itérateur qui se déréférence en référence rvalue (modèle de classe)
  • move_sentinel — adaptateur de sentinelle à utiliser avec move_iterator (modèle de classe)
  • common_iterator — adapte une paire itérateur-sentinelle en un type d'itérateur commun à utiliser avec les algorithmes hérités (modèle de classe)
  • counted_iterator — adaptateur d'itérateur qui conserve la trace de sa distance par rapport à sa position de départ (modèle de classe)
  • default_sentinel — type sentinelle vide à utiliser avec les types d'itérateurs qui connaissent la borne de leur intervalle (classe)
  • dangling — enveloppe pour un itérateur potentiellement pendant (modèle de classe)
  • safe_iterator_t — modèle d'alias qui enveloppe le type d'itérateur d'un intervalle rvalue avec dangling (modèle d'alias)
  • unreachable — type sentinelle utilisé avec n'importe quel itérateur pour désigner un intervalle infini (classe)

  • ostream_iterator — itérateur de sortie qui écrit dans std::basic_ostream (modèle de classe)
