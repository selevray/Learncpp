Concepts d'intervalles

Défini dans l'espace de noms std::experimental::ranges

  • Range — spécifie qu'un type est un intervalle, c'est-à-dire qu'il fournit un itérateur begin et une sentinelle end (concept)
  • SizedRange — spécifie qu'un intervalle connaît sa taille en temps constant (concept)
  • View — spécifie qu'un intervalle est une vue, c'est-à-dire qu'il a une copie, un déplacement et une affectation en temps constant (concept)
  • BoundedRange — spécifie qu'un intervalle a des types itérateur et sentinelle identiques (concept)
  • InputRange — spécifie un intervalle dont le type itérateur satisfait InputIterator (concept)
  • OutputRange — spécifie un intervalle dont le type itérateur satisfait OutputIterator (concept)
  • ForwardRange — spécifie un intervalle dont le type itérateur satisfait ForwardIterator (concept)
  • BidirectionalRange — spécifie un intervalle dont le type itérateur satisfait BidirectionalIterator (concept)
  • RandomAccessRange — spécifie un intervalle dont le type itérateur satisfait RandomAccessIterator (concept)

Accès aux intervalles

Défini dans l'espace de noms std::experimental::ranges

  • begincbegin — renvoie un itérateur vers le début d'un intervalle (objet point de personnalisation)
  • endcend — renvoie un itérateur vers la fin d'un intervalle (objet point de personnalisation)
  • rbegincrbegin — renvoie un itérateur inverse vers un intervalle (objet point de personnalisation)
  • rendcrend — renvoie un itérateur inverse de fin vers un intervalle (objet point de personnalisation)

Primitives des intervalles

Défini dans l'espace de noms std::experimental::ranges

  • size — obtient la taille d'un intervalle dont la taille peut être calculée en temps constant (objet de point de personnalisation)
  • empty — vérifie si un intervalle est vide (objet point de personnalisation)
  • datacdata — obtient un pointeur vers le début d'un intervalle contigu (objet point de personnalisation)
  • iterator_tsentinel_t — obtient les types itérateur et sentinelle d'un intervalle (modèle d'alias)
