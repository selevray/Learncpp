### Concepts {#Concepts}

  • Object (reflection TS) — spécifie qu'un type est un type d'objet méta (concept)
  • ObjectSequence (reflection TS) — spécifie qu'un type d'objet méta est un type de séquence d'objets méta (concept)
  • TemplateParameterScope (reflection TS) — spécifie qu'un type d'objet méta reflète une portée de paramètre de modèle (concept)
  • Named (reflection TS) — spécifie qu'un type d'objet méta reflète une entité ou un alias ayant un nom associé (éventuellement vide) (concept)
  • Alias (reflection TS) — spécifie qu'un type d'objet méta reflète un alias de type, un alias d'espace de noms, ou un alias introduit par une déclaration using (concept)
  • RecordMember (reflection TS) — spécifie qu'un type d'objet méta reflète un member-declaration d'une classe (concept)
  • Enumerator (reflection TS) — spécifie qu'un type d'objet méta reflète un énumérateur (concept)
  • Variable (reflection TS) — spécifie qu'un type d'objet méta reflète une variable ou un membre de données (concept)
  • ScopeMember (reflection TS) — spécifie qu'un type d'objet méta satisfait RecordMember, Enumerator ou Variable, ou reflète un espace de noms autre que l'espace de noms global (concept)
  • Typed (reflection TS) — spécifie qu'un type d'objet méta reflète une entité ayant un type (concept)
  • Namespace (reflection TS) — spécifie qu'un type d'objet méta reflète un espace de noms (concept)
  • GlobalScope (reflection TS) — spécifie qu'un type d'objet méta reflète l'espace de noms global (concept)
  • Class (reflection TS) — spécifie qu'un type d'objet méta reflète un type de classe non union (concept)
  • Enum (reflection TS) — spécifie qu'un type d'objet méta reflète un type énumération (concept)
  • Record (reflection TS) — spécifie qu'un type d'objet méta reflète un type de classe (concept)
  • Scope (reflection TS) — spécifie qu'un type d'objet méta reflète un espace de noms, une classe, une énumération, une fonction, un type de fermeture, une portée de paramètre de modèle (concept)
  • Type (reflection TS) — spécifie qu'un type d'objet méta reflète un type (concept)
  • Constant (reflection TS) — spécifie qu'un type d'objet méta reflète un énumérateur ou une variable constexpr (concept)
  • Base (reflection TS) — spécifie qu'un type d'objet méta reflète une classe de base directe obtenue à partir de get_base_classes (concept)
  • FunctionParameter (reflection TS) — spécifie qu'un type d'objet méta reflète un paramètre de fonction (concept)
  • Callable (reflection TS) — spécifie qu'un type d'objet méta reflète une fonction (y compris les constructeurs et destructeurs) (concept)
  • Expression (reflection TS) — spécifie qu'un type d'objet méta reflète une expression (concept)
  • ParenthesizedExpression (reflection TS) — spécifie qu'un type d'objet méta reflète une expression entre parenthèses (concept)
  • FunctionCallExpression (reflection TS) — spécifie qu'un type d'objet méta reflète un function-call-expression (concept)
  • FunctionalTypeConversion (reflection TS) — spécifie qu'un type d'objet méta reflète un functional-type-conv-expression (concept)
  • Function (reflection TS) — spécifie qu'un type d'objet méta reflète une fonction (à l'exclusion des constructeurs et destructeurs) (concept)
  • MemberFunction (reflection TS) — spécifie qu'un type d'objet méta reflète une fonction membre (à l'exclusion des constructeurs et destructeurs) (concept)
  • SpecialMemberFunction (reflection TS) — spécifie qu'un type d'objet méta reflète une fonction membre spéciale (concept)
  • Constructor (reflection TS) — spécifie qu'un type d'objet méta reflète un constructeur (concept)
  • Destructor (reflection TS) — spécifie qu'un type d'objet méta reflète un destructeur (concept)
  • Operator (reflection TS) — spécifie qu'un type d'objet méta reflète une fonction opérateur ou une fonction de conversion (concept)
  • ConversionOperator (reflection TS) — spécifie qu'un type d'objet méta reflète une fonction de conversion (concept)
  • Lambda (reflection TS) — spécifie qu'un type d'objet méta reflète le type de fermeture d'une expression lambda non générique (concept)
  • LambdaCapture (reflection TS) — spécifie qu'un type d'objet méta reflète une capture de lambda (concept)

### Classes {#Classes}

##### Object opérations {#Object_operations}

  • reflects_same (reflection TS) — vérifie si deux types de méta-objets reflètent la même entité ou le même alias (modèle de classe)
  • get_source_line (reflection TS) — obtient le numéro de ligne présumé de la déclaration de l'entité ou de l'alias reflété (modèle de classe)
  • get_source_column (reflection TS) — obtient le numéro de colonne défini par l'implémentation de la déclaration de l'entité ou de l'alias reflété (modèle de classe)
  • get_source_file_name (reflection TS) — obtient le nom de fichier présumé de la déclaration de l'entité ou de l'alias reflété (modèle de classe)

##### ObjectSequence opérations {#ObjectSequence_operations}

  • get_size (reflection TS) — obtient la taille d'une séquence de méta-objets (modèle de classe)
  • get_element (reflection TS) — obtient le type de méta-objet d'indice donné dans une séquence (modèle de classe)
  • unpack_sequence (reflection TS) — applique un modèle à la séquence de méta-objets (modèle de classe)

##### Named opérations {#Named_operations}

  • is_unnamed (reflection TS) — vérifie si l'entité réfléchie ou l'alias est nommé (modèle de classe)
  • get_name (reflection TS) — obtient le nom non qualifié de l'entité ou de l'alias reflété (modèle de classe)
  • get_display_name (reflection TS) — obtient le nom d'affichage défini par l'implémentation de l'entité ou de l'alias reflété (modèle de classe)

##### Alias opérations {#Alias_operations}

  • get_alias (reflection TS) — obtient le type de méta-objet reflétant l'entité associée à l'alias reflété (modèle de classe)

##### Type opérations {#Type_operations}

  • get_type (reflection TS) — obtient le type de méta-objet reflétant le type de l'entité ou de l'alias reflété (modèle de classe)
  • get_reflected_type (reflection TS) — obtient le type de l'entité ou de l'alias reflété (modèle de classe)
  • is_enum (reflection TS) — vérifie si le type de méta-objet reflète un type énumération (modèle de classe)
  • is_union (reflection TS) — vérifie si le type de méta-objet reflète un type union (modèle de classe)
  • uses_class_keyuses_struct_key (reflection TS) — vérifie si le type de méta-objet reflète un type classe non union dont la déclaration utilise class ou struct respectivement (modèle de classe)

##### ScopeMember opérations {#ScopeMember_operations}

  • get_scope (reflection TS) — obtient le type de méta-objet reflétant la portée de l'entité ou de l'alias reflété (modèle de classe)

##### Base opérations {#Base_operations}

  • get_class (reflection TS) — obtient le type de méta-objet reflétant la classe de base dans la relation de classe de base donnée (modèle de classe)

##### Opérations RecordMember et Base {#RecordMember_and_Base_operations}

  • is_public (reflection TS) — vérifie si le membre ou la classe de base reflété est public (modèle de classe)
  • is_protected (reflection TS) — vérifie si le membre ou la classe de base reflété est protégé (modèle de classe)
  • is_private (reflection TS) — vérifie si le membre ou la classe de base reflété est privé (modèle de classe)

##### Record opérations {#Record_operations}

  • get_public_data_membersget_accessible_data_membersget_data_members (reflection TS) — obtient un type de séquence de méta-objets dont les éléments reflètent les membres de données publics, accessibles ou tous les membres de données de la classe reflétée (modèle de classe)
  • get_public_member_functionsget_accessible_member_functionsget_member_functions (reflection TS) — obtient un type de séquence de méta-objets dont les éléments reflètent les fonctions membres publiques, accessibles ou toutes les fonctions membres de la classe reflétée (modèle de classe)
  • get_constructors (reflection TS) — obtient un type de séquence de méta-objets dont les éléments reflètent tous les constructeurs de la classe reflétée (modèle de classe)
  • get_operators (reflection TS) — obtient un type de séquence de méta-objets dont les éléments reflètent toutes les fonctions opérateurs et toutes les fonctions de conversion déclarées dans la classe reflétée (modèle de classe)
  • get_destructor (reflection TS) — obtient le type de méta-objet reflétant le destructeur de la classe reflétée (modèle de classe)
  • get_public_member_typesget_accessible_member_typesget_member_types (reflection TS) — obtient un type de séquence de méta-objets dont les éléments reflètent les types membres imbriqués ou les typedef membres publics, accessibles ou tous ceux de la classe reflétée (modèle de classe)
  • get_public_base_classesget_accessible_base_classesget_base_classes (reflection TS) — obtient un type de séquence de méta-objets dont les éléments reflètent les classes de base publiques, accessibles ou toutes les classes de base de la classe reflétée (modèle de classe)

##### Enum opérations {#Enum_operations}

  • is_scoped_enum (reflection TS) — vérifie si l'énumération reflétée est à portée limitée (modèle de classe)
  • get_enumerators (reflection TS) — obtient un type de séquence de méta-objets dont les éléments reflètent les énumérateurs de l'énumération reflétée (modèle de classe)
  • get_underlying_type (reflection TS) — obtient le type de méta-objet reflétant le type sous-jacent de l'énumération reflétée (modèle de classe)

##### Variable opérations {#Variable_operations}

  • get_constant (reflection TS) — obtient la valeur de la variable reflétée qui est une expression constante (modèle de classe)
  • is_thread_local (reflection TS) — vérifie si la variable est déclarée avec thread_local (modèle de classe)

##### FunctionParameter opérations {#FunctionParameter_operations}

  • has_default_argument (reflection TS) — vérifie si le paramètre reflété possède un argument par défaut (modèle de classe)

##### Callable opérations {#Callable_operations}

  • get_parameters (reflection TS) — obtient un type de séquence de méta-objets dont les éléments reflètent les paramètres de la fonction reflétée (modèle de classe)
  • is_vararg (reflection TS) — vérifie si la liste des paramètres de la fonction reflétée contient un paramètre ellipse (modèle de classe)
  • is_noexcept (reflection TS) — vérifie si la fonction reflétée est non lançante (modèle de classe)
  • is_deleted (reflection TS) — vérifie si la fonction reflétée est supprimée (modèle de classe)

##### Opérations Variable et Callable {#Variable_and_Callable_operations}

  • is_constexpr (reflection TS) — vérifie si la variable ou la fonction reflétée est constexpr (modèle de classe)

##### Opérations Namespace et Callable {#Namespace_and_Callable_operations}

  • is_inline (reflection TS) — vérifie si l'espace de noms ou la fonction reflété est inline (modèle de classe)

##### ParenthesizedExpression opérations {#ParenthesizedExpression_operations}

  • get_subexpression (reflection TS) — obtient le type de méta-objet reflétant l'expression sans parenthèses de l'expression entre parenthèses reflétée (modèle de classe)

##### FunctionCallExpression opérations {#FunctionCallExpression_operations}

  • get_callable (reflection TS) — obtient le type de méta-objet reflétant la fonction dans le function-call-expression (modèle de classe) réfléchi

##### FunctionalTypeConversion opérations {#FunctionalTypeConversion_operations}

  • get_constructor (reflection TS) — obtient le type de méta-objet reflétant le constructeur dans functional-type-conv-expression (modèle de classe)

##### Opérations Variable et Function {#Variable_and_Function_operations}

  • get_pointer (reflection TS) — obtient l'adresse de la variable ou de la fonction reflétée, ou la valeur de pointeur vers membre du membre non statique reflété (modèle de classe)

##### MemberFunction opérations {#MemberFunction_operations}

  • is_constis_volatilehas_lvalueref_qualifierhas_rvalueref_qualifier (reflection TS) — vérifie si la fonction membre reflétée est déclarée avec le qualificateur const, volatile, & ou && respectivement (modèle de classe)
  • is_override (reflection TS) — vérifie si la fonction membre reflétée redéfinit une fonction membre de la classe de base (modèle de classe)

##### Opérations Record et MemberFunction {#Record_and_MemberFunction_operations}

  • is_final (reflection TS) — vérifie si la classe ou la fonction membre reflétée est marquée avec final (modèle de classe)

##### Opérations Variable et MemberFunction {#Variable_and_MemberFunction_operations}

  • is_static (reflection TS) — vérifie si la variable reflétée a une durée de stockage statique, ou si la fonction membre reflétée est statique (modèle de classe)

##### SpecialMemberFunction opérations {#SpecialMemberFunction_operations}

  • is_implicitly_declared (reflection TS) — vérifie si la fonction membre spéciale reflétée est déclarée implicitement (modèle de classe)
  • is_defaulted (reflection TS) — vérifie si la fonction membre spéciale reflétée est défaillie (defaulted) dans sa première déclaration (modèle de classe)

##### Opérations Constructor et ConversionOperator {#Constructor_and_ConversionOperator_operations}

  • is_explicit (reflection TS) — vérifie si le constructeur ou la fonction de conversion reflété est déclaré avec explicit (modèle de classe)

##### Opérations MemberFunction et Destructor {#MemberFunction_and_Destructor_operations}

  • is_virtual (reflection TS) — vérifie si la fonction membre reflétée est virtuelle (modèle de classe)
  • is_pure_virtual (reflection TS) — vérifie si la fonction membre reflétée est virtuelle pure (modèle de classe)

##### Lambda opérations {#Lambda_operations}

  • get_captures (reflection TS) — obtient un type de séquence de méta-objets dont les éléments reflètent les captures du type fermeture reflété (modèle de classe)
  • uses_default_copy_captureuses_default_reference_capture (reflection TS) — vérifie si la capture par défaut de l'expression lambda du type fermeture reflété est = ou & respectivement (modèle de classe)
  • is_call_operator_const (reflection TS) — vérifie si le operator() du type fermeture reflété est déclaré avec const (modèle de classe)

##### LambdaCapture opérations {#LambdaCapture_operations}

  • is_explictly_captured (reflection TS) — vérifie si la capture lambda reflétée est capturée explicitement (modèle de classe)
  • is_init_capture (reflection TS) — vérifie si la capture lambda reflétée est une capture d'initialisation (init-capture) (modèle de classe)
