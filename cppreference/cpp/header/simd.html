### Classes {#Classes}

  • basic_simd (C++26) — type vectoriel à parallélisme de données (modèle de classe)
  • simd (C++26) — alias de modèle pratique pour basic_simd pouvant spécifier sa largeur (alias de modèle)
  • basic_simd_mask (C++26) — type data-parallel dont le type d'élément est bool (modèle de classe)
  • simd_mask (C++26) — alias de modèle pratique pour basic_simd_mask pouvant spécifier sa largeur (alias de modèle)
  • simd_flags (C++26) — indicateurs de chargement et de stockage pour les types data-parallel (modèle de classe)
  • simd_alignment (C++26) — obtient un alignement approprié pour simd_flag_aligned (modèle de classe)
  • rebind_simd (C++26) — modifie le type d'élément du type data-parallel (modèle de classe)
  • resize_simd (C++26) — modifie la largeur du type data-parallel (modèle de classe)
