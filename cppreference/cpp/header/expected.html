### Classes {#Classes}

  • expected (C++23) — un wrapper qui contient soit une valeur expected, soit une valeur d'erreur (modèle de classe)
  • unexpected (C++23) — représenté comme une valeur inattendue (modèle de classe)
  • bad_expected_access (C++23) — exception signalant un accès contrôlé à un expected qui contient une valeur inattendue (modèle de classe)
  • unexpectunexpect_t (C++23) — étiquette de construction sur place pour une valeur inattendue dans expected (étiquette)
