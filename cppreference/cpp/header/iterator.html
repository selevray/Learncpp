### Concepts {#Concepts}

##### Concepts d'itérateurs {#Iterator_concepts}

  • indirectly_readable (C++20) — spécifie qu'un type est indirectement lisible en appliquant l'opérateur * (concept)
  • indirectly_writable (C++20) — spécifie qu'une valeur peut être écrite dans l'objet référencé par un itérateur (concept)
  • weakly_incrementable (C++20) — spécifie qu'un type semiregular peut être incrémenté avec les opérateurs d'incrémentation préfixe et postfixe (concept)
  • incrementable (C++20) — spécifie que l'opération d'incrémentation sur un type weakly_incrementable est préservant l'égalité et que le type est equality_comparable (concept)
  • input_or_output_iterator (C++20) — spécifie que des objets d'un type peuvent être incrémentés et déréférencés (concept)
  • sentinel_for (C++20) — spécifie qu'un type est une sentinelle pour un type input_or_output_iterator (concept)
  • sized_sentinel_for (C++20) — spécifie que l'opérateur - peut être appliqué à un itérateur et à une sentinelle pour calculer leur différence en temps constant (concept)
  • input_iterator (C++20) — spécifie qu'un type est un itérateur d'entrée, c'est-à-dire que ses valeurs référencées peuvent être lues et qu'il peut être incrémenté en préfixe et en postfixe (concept)
  • output_iterator (C++20) — spécifie qu'un type est un itérateur de sortie pour un type de valeur donné, c'est-à-dire que des valeurs de ce type peuvent y être écrites et qu'il peut être incrémenté en préfixe et en postfixe (concept)
  • forward_iterator (C++20) — spécifie qu'un input_iterator est un itérateur avant, prenant en charge la comparaison d'égalité et les parcours multiples (concept)
  • bidirectional_iterator (C++20) — spécifie qu'un forward_iterator est un itérateur bidirectionnel, prenant en charge le déplacement en arrière (concept)
  • random_access_iterator (C++20) — spécifie qu'un bidirectional_iterator est un itérateur à accès aléatoire, prenant en charge l'avancement en temps constant et l'indexation (concept)
  • contiguous_iterator (C++20) — spécifie qu'un random_access_iterator est un itérateur contigu, désignant des éléments contigus en mémoire (concept)

##### Concepts de callables indirects {#Indirect_callable_concepts}

  • indirectly_unary_invocableindirectly_regular_unary_invocable (C++20) (C++20) — spécifie qu'un type callable peut être invoqué avec le résultat du déréférencement d'un type indirectly_readable (concept)
  • indirect_unary_predicate (C++20) — spécifie qu'un type callable, lorsqu'il est invoqué avec le résultat du déréférencement d'un type indirectly_readable, satisfait predicate (concept)
  • indirect_binary_predicate (C++20) — spécifie qu'un type callable, lorsqu'il est invoqué avec le résultat du déréférencement de deux types indirectly_readable, satisfait predicate (concept)
  • indirect_equivalence_relation (C++20) — spécifie qu'un type callable, lorsqu'il est invoqué avec le résultat du déréférencement de deux types indirectly_readable, satisfait equivalence_relation (concept)
  • indirect_strict_weak_order (C++20) — spécifie qu'un type callable, lorsqu'il est invoqué avec le résultat du déréférencement de deux types indirectly_readable, satisfait strict_weak_order (concept)

##### Exigences communes des algorithmes {#Common_algorithm_requirements}

  • indirectly_movable (C++20) — spécifie que des valeurs peuvent être déplacées d'un type indirectly_readable vers un type indirectly_writable (concept)
  • indirectly_movable_storable (C++20) — spécifie que des valeurs peuvent être déplacées d'un type indirectly_readable vers un type indirectly_writable et que le déplacement peut être effectué via un objet intermédiaire (concept)
  • indirectly_copyable (C++20) — spécifie que des valeurs peuvent être copiées d'un type indirectly_readable vers un type indirectly_writable (concept)
  • indirectly_copyable_storable (C++20) — spécifie que des valeurs peuvent être copiées d'un type indirectly_readable vers un type indirectly_writable et que la copie peut être effectuée via un objet intermédiaire (concept)
  • indirectly_swappable (C++20) — spécifie que les valeurs référencées par deux types indirectly_readable peuvent être échangées (concept)
  • indirectly_comparable (C++20) — spécifie que les valeurs référencées par deux types indirectly_readable peuvent être comparées (concept)
  • permutable (C++20) — spécifie les exigences communes des algorithmes qui réordonnent les éléments sur place (concept)
  • mergeable (C++20) — spécifie les exigences des algorithmes qui fusionnent des séquences triées en une séquence de sortie en copiant les éléments (concept)
  • sortable (C++20) — spécifie les exigences communes des algorithmes qui permutent des séquences en séquences ordonnées (concept)
