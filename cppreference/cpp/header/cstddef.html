Cet en-tête faisait à l'origine partie de la bibliothèque standard C sous le nom <stddef.h>.

Cet en-tête fait partie de la bibliothèque utilitaire.

### Macros {#Macros}

  • NULL — constante de pointeur nul définie par l'implémentation (constante macro)
  • offsetof — décalage en octets depuis le début d'un type à disposition standard jusqu'au membre spécifié (macro de fonction)

### Types {#Types}

  • size_t — type entier non signé renvoyé par l'opérateur sizeof (typedef)
  • ptrdiff_t — type entier signé renvoyé lors de la soustraction de deux pointeurs (typedef)
  • nullptr_t (C++11) — le type du littéral de pointeur nul nullptr (typedef)
  • max_align_t (C++11) — type trivial dont l'exigence d'alignement est aussi grande que celle de tout autre type scalaire (typedef)
  • byte (C++17) — le type d'octet (enum)

### Fonctions {#Functions}

  • to_integer (C++17) — convertit std::byte en entier (modèle de fonction)
