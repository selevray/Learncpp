std::pmr::null_memory_resource

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory_resource>

std::pmr::memory_resource* null_memory_resource() noexcept;  // (depuis C++17)

Renvoie un pointeur vers un memory_resource qui n'effectue aucune allocation.

Valeur de retour

Renvoie un pointeur p vers un objet à durée de stockage statique d'un type dérivé de std::pmr::memory_resource, avec les propriétés suivantes :

  • sa fonction allocate() lève toujours std::bad_alloc ;
  • sa fonction deallocate() n'a aucun effet ;
  • pour tout memory_resource r, p->is_equal(r) renvoie &r == p.

La même valeur est renvoyée à chaque fois que cette fonction est appelée.

Exemple

Le programme illustre l'utilisation principale de null_memory_resource : s'assurer qu'un pool de mémoire qui nécessite de la mémoire allouée sur la pile n'allouera PAS de mémoire sur le tas s'il a besoin de davantage de mémoire.

#include <array>
#include <cstddef>
#include <iostream>
#include <memory_resource>
#include <string>
#include <unordered_map>

int main()
{
    // allouer de la mémoire sur la pile
    std::array<std::byte, 20000> buf;

    // sans allocation de secours sur le tas
    std::pmr::monotonic_buffer_resource pool{buf.data(), buf.size(),
                                             std::pmr::null_memory_resource()};

    // allouer trop de mémoire
    std::pmr::unordered_map<long, std::pmr::string> coll{&pool};
    try
    {
        for (std::size_t i = 0; i < buf.size(); ++i)
        {
            coll.emplace(i, "just a string with number " + std::to_string(i));

            if (i && i % 50 == 0)
                std::clog << "size: " << i << "...\n";
        }
    }
    catch (const std::bad_alloc& e)
    {
        std::cerr << e.what() << '\n';
    }

    std::cout << "size: " << coll.size() << '\n';
}
