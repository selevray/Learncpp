std::destroy_at

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class T >
void destroy_at( T* p );  // (depuis C++17) (jusqu'à C++20)

template< class T >
constexpr void destroy_at( T* p );  // (depuis C++20)

Si T n'est pas un type tableau, appelle le destructeur de l'objet pointé par p, comme si par p->~T().

Si T est un type tableau, [le programme est mal formé (jusqu'à C++20) | détruit récursivement les éléments de *p dans l'ordre, comme si en appelant std::destroy(std::begin(*p), std::end(*p)) (depuis C++20)].

Paramètres

  • p — un pointeur vers l'objet à détruire

Valeur de retour

(aucune)

Implémentation possible

template<class T>
constexpr void destroy_at(T* p)
{
    if constexpr (std::is_array_v<T>)
        for (auto &elem : *p)
            (destroy_at)(std::addressof(elem));
    else
        p->~T();
}
// C++17 version:
// template<class T> void destroy_at(T* p) { p->~T(); }

Notes

destroy_at déduit le type de l'objet à détruire et évite donc de l'écrire explicitement dans l'appel au destructeur.

Lorsque destroy_at est appelé lors de l'évaluation d'une expression constante e, l'argument p doit pointer vers un objet dont la durée de vie a commencé pendant l'évaluation de e.

(depuis C++20)

Exemple

L'exemple suivant montre comment utiliser destroy_at pour détruire une séquence contiguë d'éléments.

#include <iostream>
#include <memory>
#include <new>

struct Tracer
{
    int value;
    ~Tracer() { std::cout << value << " destructed\n"; }
};

int main()
{
    alignas(Tracer) unsigned char buffer[sizeof(Tracer) * 8];

    for (int i = 0; i < 8; ++i)
        new(buffer + sizeof(Tracer) * i) Tracer{i}; //construire manuellement des objets

    auto ptr = std::launder(reinterpret_cast<Tracer*>(buffer));

    for (int i = 0; i < 8; ++i)
        std::destroy_at(ptr + i);
}

Output:

0 destructed
1 destructed
2 destructed
3 destructed
4 destructed
5 destructed
6 destructed
7 destructed
