template< class T = void >

template< class T >
struct owner_less<std::shared_ptr<T>>;  // (2) (depuis C++11)

template< class T >
struct owner_less<std::weak_ptr<T>>;  // (3) (depuis C++11)

template<>
struct owner_less<void>;  // (4) (depuis C++17)

Cet objet fonction fournit un ordre basé sur le propriétaire (par opposition à basé sur la valeur) de types mixtes pour std::weak_ptr et std::shared_ptr. L'ordre est tel que deux pointeurs intelligents ne sont équivalents que s'ils sont tous deux vides ou s'ils partagent la propriété, même si les valeurs des pointeurs bruts obtenus par get() sont différentes (par exemple parce qu'ils pointent vers des sous-objets différents au sein du même objet).

  1. L'ordre basé sur le propriétaire pour types mixtes n'est pas fourni pour des types autres que std::shared_ptr et std::weak_ptr.

  2. L'ordre basé sur le propriétaire pour types mixtes de std::shared_ptr.

C'est le prédicat de comparaison préféré lors de la construction de conteneurs associatifs avec std::shared_ptr comme clés, c'est-à-dire std::map<std::shared_ptr<T>, U, std::owner_less<std::shared_ptr<T>>>.

  1. L'ordre basé sur le propriétaire pour types mixtes de std::weak_ptr.

C'est le prédicat de comparaison préféré lors de la construction de conteneurs associatifs avec std::weak_ptr comme clés, c'est-à-dire std::map<std::weak_ptr<T>, U, std::owner_less<std::weak_ptr<T>>>.

  1. La spécialisation void déduit les types de paramètres à partir des arguments.

Le operator< par défaut n'est pas défini pour les pointeurs faibles, et peut considérer à tort deux pointeurs partagés vers le même objet comme non équivalents (voir std::shared_ptr::owner_before).

Spécialisations

La bibliothèque standard fournit une spécialisation de std::owner_less lorsque T n'est pas spécifié. Dans ce cas, les types de paramètres sont déduits des arguments (chacun doit toujours être soit un std::shared_ptr soit un std::weak_ptr).

  • owner_less<void> — objet fonction fournissant un ordre basé sur le propriétaire de types mixtes pour pointeurs partagés et faibles, quel que soit le type de la cible (spécialisation de modèle de classe)

(depuis C++17)

                 const std::shared_ptr<T>& rhs ) const noexcept;  // (depuis C++11)

Compare lhs et rhs en utilisant la sémantique basée sur le propriétaire. Appelle effectivement lhs.owner_before(rhs).

L'ordre est une relation d'ordre faible strict.

lhs et rhs sont équivalents seulement s'ils sont tous deux vides ou partagent la propriété.

Paramètres

  • lhs, rhs — pointeurs à propriété partagée à comparer

Valeur de retour

true si lhs est inférieur à rhs selon l'ordre basé sur le propriétaire, false sinon.
