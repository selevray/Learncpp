std::enable_shared_from_this<T>::shared_from_this

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

std::shared_ptr<T> shared_from_this();  // (1) (depuis C++11)

std::shared_ptr<T const> shared_from_this() const;  // (2) (depuis C++11)

Renvoie un std::shared_ptr<T> qui partage la propriété de *this avec tous les std::shared_ptr existants qui référencent *this.

Valeur de retour

std::shared_ptr<T>(weak_this ﻿)

Exceptions

Si shared_from_this est appelé sur un objet qui n'est pas précédemment partagé par std::shared_ptr, std::bad_weak_ptr est levée par le constructeur de std::shared_ptr.

Exemple

#include <iostream>
#include <memory>

struct Foo : public std::enable_shared_from_this<Foo>
{
    Foo() { std::cout << "Foo::Foo\n"; }
    ~Foo() { std::cout << "Foo::~Foo\n"; }
    std::shared_ptr<Foo> getFoo() { return shared_from_this(); }
};

int main()
{
    Foo *f = new Foo;
    std::shared_ptr<Foo> pf1;

    {
        std::shared_ptr<Foo> pf2(f);
        pf1 = pf2->getFoo(); // partage la propriété de l'objet avec pf2
    }

    std::cout << "pf2 is gone\n";
}

Output:

Foo::Foo
pf2 is gone
Foo::~Foo
