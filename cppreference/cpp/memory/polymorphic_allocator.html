Le modèle de classe std::pmr::polymorphic_allocator est un Allocator qui présente un comportement d'allocation différent selon le std::pmr::memory_resource à partir duquel il est construit. Comme memory_resource utilise le polymorphisme à l'exécution pour gérer les allocations, des instances de conteneurs différentes ayant polymorphic_allocator pour type d'allocateur statique sont interopérables, mais peuvent se comporter comme si elles avaient des types d'allocateurs différents.

Toutes les spécialisations de polymorphic_allocator satisfont aux exigences de complétude des allocateurs.

La fonction membre polymorphic_allocator::construct effectue une construction avec propagation d'allocateur, de sorte que les éléments d'un conteneur utilisant un polymorphic_allocator utilisent ce même allocateur pour leurs propres allocations. Par exemple, un std::pmr::vector<std::pmr::string> utilisera le même memory_resource pour le stockage de vector et pour le stockage de chaque string.

Pour les allocateurs non polymorphes, une propagation similaire peut être obtenue à l'aide de std::scoped_allocator_adaptor.

Notes

polymorphic_allocator ne se propage pas lors de l'affectation par copie, de l'affectation par déplacement ou de l'échange d'un conteneur. Par conséquent, l'affectation par déplacement d'un conteneur utilisant un polymorphic_allocator peut lever une exception, et l'échange de deux conteneurs utilisant un polymorphic_allocator dont les allocateurs ne se comparent pas égaux entraîne un comportement indéfini.
