std::pmr::unsynchronized_pool_resource::options

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

std::pmr::pool_options options() const;  // (depuis C++17)

Renvoie les options qui contrôlent le comportement de mise en pool de cette ressource.

Les valeurs de la structure renvoyée peuvent différer de celles fournies au constructeur de la façon suivante :

  • Les valeurs nulles seront remplacées par les valeurs par défaut définies par l'implémentation ;
  • Les tailles peuvent être arrondies à une granularité non spécifiée.
