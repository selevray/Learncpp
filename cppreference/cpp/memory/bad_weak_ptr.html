std::bad_weak_ptr

Défini dans l'en-tête <memory>

class bad_weak_ptr;  // (depuis C++11)

std::bad_weak_ptr est le type de l'objet lancé comme exception par les constructeurs de std::shared_ptr qui prennent std::weak_ptr en argument, lorsque le std::weak_ptr désigne un objet déjà supprimé.

Construit un nouvel objet bad_weak_ptr avec une chaîne d'octets terminée par un caractère nul définie par l'implémentation, accessible via what().

  1. Constructeur par défaut.

  2. Constructeur de copie. Si *this et other ont tous deux le type dynamique std::bad_weak_ptr, alors std::strcmp(what(), other.what()) == 0.

Paramètres

Affecte le contenu avec celui de other. Si *this et other ont tous deux le type dynamique std::bad_weak_ptr, alors std::strcmp(what(), other.what()) == 0 après l'affectation.

std::bad_weak_ptr::what

virtual const char* what() const noexcept;  // (depuis C++11)

Renvoie la chaîne explicative.

Valeur de retour

Pointeur vers une chaîne terminée par un caractère nul, définie par l'implémentation, contenant des informations explicatives. La chaîne convient à une conversion et à un affichage en tant que std::wstring. Le pointeur est garanti valide au moins jusqu'à la destruction de l'objet d'exception dont il est obtenu, ou jusqu'à l'appel d'une fonction membre non const (par ex. l'opérateur d'affectation par copie) sur cet objet d'exception.

La chaîne renvoyée est encodée avec le codage ordinaire des littéraux lors de l'évaluation constante.

(depuis C++26)

Notes

Les implémentations peuvent, sans y être obligées, redéfinir what().

Exemple

#include <iostream>
#include <memory>

int main()
{
    std::shared_ptr<int> p1(new int(42));
    std::weak_ptr<int> wp(p1);
    p1.reset();
    try
    {
        std::shared_ptr<int> p2(wp);
    }
    catch (const std::bad_weak_ptr& e)
    {
        std::cout << e.what() << '\n';
    }
}
