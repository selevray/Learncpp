std::pmr::memory_resource::do_deallocate

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

virtual void do_deallocate( void* p, std::size_t bytes, std::size_t alignment ) = 0;  // (depuis C++17)

Libère le stockage pointé par p.

p doit avoir été renvoyé par un appel précédent à allocate(bytes, alignment) sur une memory_resource qui compare égale à *this, et le stockage qu'il pointe ne doit pas encore avoir été libéré, sinon le comportement est indéfini.

Exceptions

Ne lève aucune exception.
