std::pmr::memory_resource::allocate

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void* allocate( std::size_t bytes,
                std::size_t alignment = alignof(std::max_align_t) );  // (depuis C++17)

Alloue un stockage d'une taille d'au moins bytes octets, aligné sur le alignment spécifié.

Équivalent à return do_allocate(bytes, alignment);.

Exceptions

Lève une exception si un stockage de la taille et de l'alignement demandés ne peut pas être obtenu.
