std::pmr::operator==, std::pmr::operator!=

Défini dans l'en-tête <memory_resource>

bool operator==( const std::pmr::memory_resource& a,
                 const std::pmr::memory_resource& b ) noexcept;  // (1) (depuis C++17)

bool operator!=( const std::pmr::memory_resource& a,
                 const std::pmr::memory_resource& b ) noexcept;  // (2) (depuis C++17) (jusqu'à C++20)

Compare les memory_resource a et b pour l'égalité. Deux memory_resource sont égaux si et seulement si la mémoire allouée depuis l'un des memory_resource peut être désallouée depuis l'autre, et réciproquement.

L'opérateur != est synthétisé à partir de operator==.

(depuis C++20)

Valeur de retour

  1. &a == &b || a.is_equal(b)

  2. !(a == b)
