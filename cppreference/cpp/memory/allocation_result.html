template< class Pointer, class SizeType = std::size_t >
struct allocation_result;  // (depuis C++23)

allocation_result Les spécialisations sont renvoyées par la fonction membre allocate_at_least des types Allocator appropriés (par exemple std::allocator::allocate_at_least) et std::allocator_traits::allocate_at_least.

Chaque spécialisation de allocation_result n'a aucune classe de base ni aucun membre déclaré autre que ptr et count, elle convient donc à l'initialisation par agrégat et à la liaison structurée.

Paramètres de modèle

  • Pointer — généralement std::allocator_traits<Alloc>::pointer, où Alloc est un type Allocator
  • SizeType — généralement std::allocator_traits<Alloc>::size_type, où Alloc est un type Allocator

Membres de données

Nom du membre Définition

  • ptr — un pointeur de type Pointer qui est généralement utilisé pour l'adresse du premier élément du stockage alloué par allocate_at_least (objet membre public)
  • count — une valeur de type SizeType qui est généralement utilisée pour le nombre réel d'éléments du stockage alloué par allocate_at_least (objet membre public)

Notes

Pointer et SizeType sont un pointeur vers un type objet et std::make_unsigned_t<std::ptrdiff_t> (qui est presque toujours identique à std::size_t) par défaut.
