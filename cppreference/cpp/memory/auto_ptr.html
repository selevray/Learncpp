template< class T > class auto_ptr;  // (1) (obsolète en C++11) (supprimé en C++17)

template<> class auto_ptr<void>;  // (2) (obsolète en C++11) (supprimé en C++17)

auto_ptr est un pointeur intelligent qui gère un objet obtenu via une expression new et supprime cet objet lorsque auto_ptr lui-même est détruit. Il peut servir à assurer la sûreté en cas d'exception pour les objets alloués dynamiquement, à transférer la propriété d'objets alloués dynamiquement à des fonctions et à renvoyer des objets alloués dynamiquement depuis des fonctions.

Copier un auto_ptr copie le pointeur et transfère la propriété à la destination : la construction par copie et l'affectation par copie de auto_ptr modifient toutes deux leur argument de droite, et la « copie » n'est pas égale à l'original. En raison de cette sémantique de copie inhabituelle, auto_ptr ne peut pas être placé dans les conteneurs standard. std::unique_ptr est préféré pour cet usage et les autres. (depuis C++11)

  1. Une spécialisation pour le type void est fournie ; elle déclare le typedef element_type, mais aucune fonction membre.

Un modèle de classe supplémentaire auto_ptr_ref est mentionné dans toute la documentation. C'est un type défini par l'implémentation qui détient une référence vers auto_ptr. L'implémentation peut fournir au modèle un nom différent, ou implémenter de toute autre manière les fonctions qui le renvoient ou l'acceptent en paramètre.
