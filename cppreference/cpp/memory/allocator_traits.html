std::allocator_traits

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class Alloc >
struct allocator_traits;  // (depuis C++11)

Le modèle de classe allocator_traits fournit la manière standardisée d'accéder aux différentes propriétés des Allocators. Les conteneurs standard et les autres composants de la bibliothèque standard accèdent aux allocateurs par ce modèle, ce qui permet d'utiliser n'importe quel type de classe comme allocateur, à condition que la spécialisation fournie par l'utilisateur de std::allocator_traits implémente toutes les fonctionnalités requises.

Un programme qui déclare une spécialisation explicite ou partielle de std::allocator_traits est mal formé, aucun diagnostic requis.

(depuis C++23)

Le std::allocator_traits par défaut, non spécialisé, contient les membres suivants :

Types membres

Type Définition

  • allocator_type — Alloc
  • value_type — Alloc::value_type
  • pointer — Alloc::pointer s'il est présent, sinon value_type*
  • const_pointer — Alloc::const_pointer s'il est présent, sinon std::pointer_traits<pointer>::rebind<const value_type>
  • void_pointer — Alloc::void_pointer s'il est présent, sinon std::pointer_traits<pointer>::rebind<void>
  • const_void_pointer — Alloc::const_void_pointer s'il est présent, sinon std::pointer_traits<pointer>::rebind<const void>
  • difference_type — Alloc::difference_type s'il est présent, sinon std::pointer_traits<pointer>::difference_type
  • size_type — Alloc::size_type s'il est présent, sinon std::make_unsigned<difference_type>::type
  • propagate_on_container_copy_assignment — Alloc::propagate_on_container_copy_assignment s'il est présent, sinon std::false_type
  • propagate_on_container_move_assignment — Alloc::propagate_on_container_move_assignment s'il est présent, sinon std::false_type
  • propagate_on_container_swap — Alloc::propagate_on_container_swap s'il est présent, sinon std::false_type
  • is_always_equal — Alloc::is_always_equal s'il est présent, sinon std::is_empty<Alloc>::type

Alias de modèles membres

Type Définition

  • rebind_alloc<T> — Alloc::rebind<T>::other s'il est présent, sinon SomeAllocator<T, Args> si ce Alloc est de la forme SomeAllocator<U, Args>, où Args est zéro ou plusieurs arguments de type
  • rebind_traits<T> — std::allocator_traits<rebind_alloc<T>>

Fonctions membres

  • allocate [statique] — alloue du stockage non initialisé à l'aide de l'allocateur (fonction membre statique publique)
  • allocate_at_least [statique] (C++23) — alloue un espace de stockage au moins aussi grand que la taille demandée via un allocateur (fonction membre statique publique)
  • deallocate [statique] — désalloue l'espace de stockage à l'aide de l'allocateur (fonction membre statique publique)
  • construct [statique] — construit un objet dans le stockage alloué (modèle de fonction)
  • destroy [statique] — détruit un objet stocké dans le stockage alloué (modèle de fonction)
  • max_size [statique] — renvoie la taille maximale d'objet prise en charge par l'allocateur (fonction membre statique publique)
  • select_on_container_copy_construction [statique] — obtient l'allocateur à utiliser après la copie d'un conteneur standard (fonction membre statique publique)
