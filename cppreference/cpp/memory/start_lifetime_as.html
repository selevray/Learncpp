1-4) crée implicitement un objet complet de type T (dont l'adresse est p) ainsi que les objets qu'il contient. La valeur de chaque objet créé obj de type TriviallyCopyable U est déterminée de la même manière que pour un appel à std::bit_cast<U>(E), sauf que le stockage n'est pas réellement accédé, où E est la lvalue de type U désignant obj. Sinon, les valeurs de ces objets créés sont non spécifiées.

  • T doit être un ImplicitLifetimeType et doit être un type complet. Sinon, le programme est mal formé.

  • Le comportement est indéfini si :

    • [p,(char*)p + sizeof(T)) ne désigne pas une zone de stockage alloué qui soit un sous-ensemble de la zone de stockage accessible via p, ou
    • la zone n'est pas convenablement alignée pour T.

  • Notez que la valeur non spécifiée peut être indéterminée.

5-8) crée implicitement un tableau dont le type d'élément est T et la longueur n. Plus précisément, si n > 0 est true, cela équivaut à std::start_lifetime_as<U>(p) où U est le type « tableau de n T ». Sinon, la fonction n'a aucun effet.

  • T doit être un type complet. Sinon, le programme est mal formé.
  • Le comportement est indéfini si :
    • p non nul n'est pas convenablement aligné pour un tableau de T, ou
    • n <= std::size_t(-1) / sizeof(T) est false, ou
    • n > 0 et [(char*)p,(char*)p + (n * sizeof(T))) ne désignent pas une région de stockage alloué qui soit un sous-ensemble de la région de stockage accessible via p.

Paramètres

  • p — l'adresse de la région constituée des objets
  • n — le nombre d'éléments du tableau à créer

Valeur de retour

1-4) Un pointeur vers l'objet complet décrit ci-dessus.

5-8) Un pointeur vers le premier élément du tableau créé, s'il y en a un ; sinon, un pointeur qui compare égal à p.

Notes

new (void_ptr) unsigned char[size] ou new (void_ptr) std::byte[size] fonctionne comme une version non typée de std::start_lifetime_as, mais ne conserve pas la représentation de l'objet.

std::start_lifetime_as gère les types non tableaux ainsi que les tableaux de borne connue, tandis que std::start_lifetime_as_array gère les tableaux de borne inconnue.

Exemple

#include <complex>
#include <iostream>
#include <memory>

int main()
{
    alignas(std::complex<float>) unsigned char network_data[sizeof(std::complex<float>)]
    {
        0xcd, 0xcc, 0xcc, 0x3d, 0xcd, 0xcc, 0x4c, 0x3e
    };

//  auto d = *reinterpret_cast<std::complex<float>*>(network_data);
//  std::cout << d << '\n'; // UB : network_data ne pointe pas vers un complex<float>

//  auto d1 = *std::launder(reinterpret_cast<std::complex<float>*>(network_data));
//  std::cout << d1 << '\n'; // UB : les objets créés implicitement ont une durée de stockage dynamique
//                                  durée de stockage et ont une valeur indéterminée initialement,
//                                  même lorsqu'un tableau qui fournit le stockage pour
//                                  eux contient des octets déterminés.
//                                  Voir aussi CWG2721.

    auto d2 = *std::start_lifetime_as<std::complex<float>>(network_data);
    std::cout << d2 << '\n'; // OK
}
