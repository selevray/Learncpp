std::default_delete

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class T > struct default_delete;  // (1) (depuis C++11)

template< class T > struct default_delete<T[]>;  // (2) (depuis C++11)

std::default_delete est la politique de destruction par défaut utilisée par std::unique_ptr lorsqu'aucun deleter n'est spécifié. Les spécialisations de default_delete sont des classes vides sur les implémentations courantes, et utilisées dans l'optimisation de classe de base vide.

  1. Le default_delete non spécialisé utilise delete pour désallouer la mémoire d'un seul objet.

  2. Une spécialisation partielle pour les types tableaux utilisant delete[] est également fournie.

Fonctions membres

  • (constructeur) — construit un objet default_delete (fonction membre publique)
  • operator() — supprime l'objet ou le tableau (fonction membre publique)

std::default_delete::default_delete

constexpr default_delete() noexcept = default;  // (1)

Spécialisations des modèles primaires

template< class U >
default_delete( const default_delete<U>& d ) noexcept;  // (2) (depuis C++11) (constexpr depuis C++23)

Spécialisations pour les tableaux

template< class U >
default_delete( const default_delete<U[]>& d ) noexcept;  // (3) (depuis C++11) (constexpr depuis C++23)

  1. Construit un objet std::default_delete.

  2. Construit un objet std::default_delete<T> à partir d'un autre objet std::default_delete.

Cette surcharge ne participe à la résolution de surcharge que si U* est implicitement convertible en T*.

  1. Construit un objet std::default_delete<T[]> à partir d'un autre objet std::default_delete<U[]>.

Cette surcharge ne participe à la résolution de surcharge que si U(*)[] est implicitement convertible en T(*)[].

Paramètres

  • d — un supprimeur à copier

Notes

Le modèle de constructeur de conversion de std::default_delete rend possible la conversion implicite de std::unique_ptr<Derived> en std::unique_ptr<Base>.

std::default_delete::operator()

Spécialisations des modèles primaires

void operator()( T* ptr ) const;  // (1) (depuis C++11) (constexpr depuis C++23)

Spécialisations pour les tableaux

template< class U >
void operator()( U* ptr ) const;  // (2) (depuis C++11) (constexpr depuis C++23)

  1. Appelle delete sur ptr.

  2. Appelle delete[] sur ptr.

Cette surcharge ne participe à la résolution de surcharge que si U(*)[] est implicitement convertible en T(*)[].

Si U est un type incomplet, le programme est mal formé.

Paramètres

  • ptr — un objet ou un tableau à supprimer

Exceptions

Aucune garantie d'exception.

Invocation sur des types incomplets

Au point du code où operator() est appelé, le type doit être complet. Dans certaines implémentations, un static_assert est utilisé pour s'assurer qu'il en est bien ainsi. La raison de cette exigence est qu'appeler delete sur un type incomplet est un comportement indéfini en C++ si le type de classe complet possède un destructeur non trivial ou une fonction de désallocation, car le compilateur n'a aucun moyen de savoir si de telles fonctions existent et doivent être invoquées.

Exemple

#include <algorithm>
#include <memory>
#include <vector>

int main()
{
//  {
//      std::shared_ptr<int> shared_bad(new int[10]);
//  } // le destructeur appelle delete, comportement indéfini

    {
        std::shared_ptr<int> shared_good(new int[10], std::default_delete<int[]>());
    } // OK : le destructeur appelle delete[]

    {
        std::unique_ptr<int> ptr(new int(5));
    } // unique_ptr<int> utilise default_delete<int>

    {
        std::unique_ptr<int[]> ptr(new int[10]);
    } // unique_ptr<int[]> utilise default_delete<int[]>

    // default_delete peut être utilisé partout où un foncteur de suppression est nécessaire
    std::vector<int*> v;
    for (int n = 0; n < 100; ++n)
        v.push_back(new int(n));
    std::for_each(v.begin(), v.end(), std::default_delete<int>());
}
