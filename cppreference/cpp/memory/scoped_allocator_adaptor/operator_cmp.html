template< class OuterAlloc1, class OuterAlloc2, class... InnerAllocs >
bool operator==( const scoped_allocator_adaptor<OuterAlloc1, InnerAllocs...>& lhs,
                 const scoped_allocator_adaptor<OuterAlloc2, InnerAllocs...>& rhs ) noexcept;  // (depuis C++11)

template< class OuterAlloc1, class OuterAlloc2, class... InnerAllocs >
bool operator!=( const scoped_allocator_adaptor<OuterAlloc1, InnerAllocs...>& lhs,
                 const scoped_allocator_adaptor<OuterAlloc2, InnerAllocs...>& rhs ) noexcept;  // (depuis C++11) (jusqu'à C++20)

Compare deux adaptateurs d'allocateurs à portée. Deux tels allocateurs sont égaux si :

  • lhs.outer_allocator() == rhs.outer_allocator(), and
  • if sizeof...(InnerAllocs) > 0, lhs.inner_allocator() == rhs.inner_allocator().

L'opérateur != est synthétisé à partir de operator==.

(depuis C++20)

Paramètres

  • lhs, rhs — adaptateurs d'allocateurs à portée à comparer

Valeur de retour

  1. Renvoie true si lhs et rhs sont égaux, false sinon.

  2. Renvoie true si lhs et rhs ne sont pas égaux, false sinon.
