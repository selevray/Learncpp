std::scoped_allocator_adaptor<OuterAlloc,InnerAlloc...>::destroy

Défini dans l'en-tête <scoped_allocator>

template< class T >
void destroy( T* p );  // (depuis C++11)

Utilise l'allocateur externe pour appeler le destructeur de l'objet pointé par p, en appelant

std::allocator_traits<OUTERMOST>::destroy(OUTERMOST(*this), p)

où OUTERMOST est le type renvoyé par l'appel à this->outer_allocator(), puis en appelant récursivement la fonction membre outer_allocator() sur le résultat de cet appel jusqu'à atteindre le type qui n'a pas une telle fonction membre.

Paramètres

  • p — pointeur vers l'objet qui va être détruit

Valeur de retour

(aucune)
