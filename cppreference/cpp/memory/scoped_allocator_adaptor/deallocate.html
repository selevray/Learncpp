void deallocate( pointer p, size_type n ) noexcept;  // (depuis C++11)

Utilise l'allocateur externe pour désallouer le stockage référencé par p, en appelant std::allocator_traits<OuterAlloc>::deallocate(outer_allocator(), p, n).

Paramètres

  • p — pointeur vers la mémoire précédemment allouée
  • n — le nombre d'objets pour lesquels la mémoire a été allouée

(aucune)
