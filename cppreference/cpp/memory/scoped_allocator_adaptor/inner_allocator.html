std::scoped_allocator_adaptor<OuterAlloc,InnerAlloc...>::inner_allocator

inner_allocator_type& inner_allocator() noexcept;  // (1) (depuis C++11)

const inner_allocator_type& inner_allocator() const noexcept;  // (2) (depuis C++11)

Obtient une référence vers l'allocateur interne utilisé pour déclarer ce scoped_allocator_adaptor.

Si sizeof...(InnerAllocs) == 0, c'est-à-dire si aucun allocateur interne n'a été déclaré, renvoie *this. Sinon renvoie une référence vers std::scoped_allocator_adaptor<InnerAllocs...>, c'est-à-dire un allocateur à portée composé de tous les allocateurs internes de *this, le premier allocateur interne devenant l'allocateur externe.

Paramètres

(aucune)

Valeur de retour

Une référence vers l'allocateur interne, qui est lui-même un std::scoped_allocator_adaptor.
