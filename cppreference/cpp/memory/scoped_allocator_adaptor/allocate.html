std::scoped_allocator_adaptor<OuterAlloc,InnerAlloc...>::allocate

pointer allocate( size_type n );  // (1) (depuis C++11)

pointer allocate( size_type n, const_void_pointer hint );  // (2) (depuis C++11)

Utilise l'allocateur externe pour allouer un stockage non initialisé.

  1. Appelle std::allocator_traits<OuterAlloc>::allocate(outer_allocator(), n).

  2. Fournit en plus une indication de localité mémoire, en appelant std::allocator_traits<OuterAlloc>::allocate(outer_allocator(), n, hint).

Paramètres

  • n — le nombre d'objets pour lesquels allouer un stockage
  • hint — pointeur vers un emplacement mémoire voisin

Valeur de retour

Le pointeur vers le stockage alloué.
