std::raw_storage_iterator

Défini dans l'en-tête <memory>

template< class OutputIt, class T >
class raw_storage_iterator
    : public std::iterator<std::output_iterator_tag, void, void, void, void>;  // (jusqu'à C++17)

template< class OutputIt, class T >
class raw_storage_iterator;  // (depuis C++17) (obsolète en C++17) (supprimé en C++20)

L'itérateur de sortie std::raw_storage_iterator permet aux algorithmes standard de stocker des résultats dans une mémoire non initialisée. Chaque fois que l'algorithme écrit un objet de type T à l'itérateur déréférencé, l'objet est construit par copie à l'emplacement du stockage non initialisé pointé par l'itérateur. Le paramètre de modèle OutputIt est n'importe quel type satisfaisant les exigences de LegacyOutputIterator et pour lequel operator* est défini pour renvoyer un objet, tel que operator& renvoie un objet de type T*. En général, le type T* est utilisé comme OutputIt.

Exigences de type

  • OutputIt doit satisfaire aux exigences de LegacyOutputIterator.

Fonctions membres

  • (constructeur) — crée un nouveau raw_storage_iterator (fonction membre publique)
  • operator= — construit un objet à l'emplacement pointé dans le tampon (fonction membre publique)
  • operator* — déréférence l'itérateur (fonction membre publique)
  • operator++operator++(int) — avance l'itérateur (fonction membre publique)
  • base (since C++17) — donne accès à l'itérateur encapsulé (fonction membre publique)

Note

std::raw_storage_iterator a été rendu obsolète principalement en raison de son comportement non sûr vis-à-vis des exceptions. Contrairement à std::uninitialized_copy, il ne gère pas correctement les exceptions lors d'opérations telles que std::copy, pouvant entraîner des fuites de ressources, faute de suivre le nombre d'objets construits avec succès et de les détruire correctement en présence d'exceptions.

Exemple

#include <algorithm>
#include <iostream>
#include <memory>
#include <string>

int main()
{
    const std::string s[] = {"This", "is", "a", "test", "."};
    std::string* p = std::allocator<std::string>().allocate(5);

    std::copy(std::begin(s), std::end(s),
              std::raw_storage_iterator<std::string*, std::string>(p));

    for (std::string* i = p; i != p + 5; ++i)
    {
        std::cout << *i << '\n';
        i->~basic_string<char>();
    }
    std::allocator<std::string>().deallocate(p, 5);
}

Output:

This
is
a
test
.
