std::assume_aligned

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< std::size_t N, class T >
constexpr T* assume_aligned( T* ptr );  // (depuis C++20)

Informe l'implémentation que l'objet pointé par ptr est aligné sur au moins N. L'implémentation peut utiliser cette information pour générer du code plus efficace, mais elle ne peut faire cette hypothèse que si l'objet est accédé via la valeur de retour de assume_aligned.

N doit être une puissance de 2. Le comportement est indéfini si ptr ne pointe pas vers un objet de type T (en ignorant la qualification cv à chaque niveau), ou si l'alignement de l'objet n'est pas au moins N.

Valeur de retour

ptr.

Exceptions

Ne lève aucune exception.

Notes

Pour s'assurer que le programme profite des optimisations activées par assume_aligned, il est important d'accéder à l'objet via sa valeur de retour :

void f(int* p)
{
    int* p1 = std::assume_aligned<256>(p);
    // Utilisez p1, et non p, pour bénéficier de l'hypothèse d'alignement.
    // Cependant, le programme a un comportement indéfini si p n'est pas aligné
    // que p1 soit utilisé ou non.
}

Il incombe au programme de s'assurer que l'hypothèse d'alignement est effectivement vérifiée. Un appel à assume_aligned n'amène pas le compilateur à vérifier ou à imposer cette condition.
