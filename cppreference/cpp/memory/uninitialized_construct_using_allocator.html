std::uninitialized_construct_using_allocator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class T, class Alloc, class... Args >
constexpr T* uninitialized_construct_using_allocator( T* p,
                                                      const Alloc& alloc,
                                                      Args&&... args );  // (depuis C++20)

Crée un objet du type donné T au moyen de construction utilisant un allocateur à l'emplacement de mémoire non initialisé indiqué par p.

Équivalent à

return std::apply(
    [&]<class... Xs>(Xs&&...xs)
    {
        return std::construct_at(p, std::forward<Xs>(xs)...);
    },
    std::uses_allocator_construction_args<T>(alloc, std::forward<Args>(args)...));

Paramètres

  • p — l'emplacement mémoire où l'objet sera placé
  • alloc — l'allocateur à utiliser
  • args — les arguments à passer au constructeur de T

Valeur de retour

Pointeur vers l'objet nouvellement créé de type T.

Exceptions

Peut lever toute exception levée par le constructeur de T, notamment std::bad_alloc.
