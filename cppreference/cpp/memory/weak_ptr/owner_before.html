std::weak_ptr<T>::owner_before

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class Y >
bool owner_before( const weak_ptr<Y>& other ) const noexcept;

template< class Y >
bool owner_before( const std::shared_ptr<Y>& other ) const noexcept;

Vérifie si ce weak_ptr précède other selon un ordre défini par l'implémentation, basé sur le propriétaire (par opposition à un ordre basé sur les valeurs). L'ordre est tel que deux pointeurs intelligents ne sont équivalents que s'ils sont tous deux vides ou s'ils possèdent le même objet, même si les valeurs des pointeurs obtenues par get() sont différentes (par exemple parce qu'ils pointent vers des sous-objets différents au sein du même objet).

Cet ordre permet d'utiliser les pointeurs partagés et faibles comme clés dans des conteneurs associatifs, typiquement via std::owner_less.

Paramètres

  • other — le std::shared_ptr ou le std::weak_ptr à comparer

Valeur de retour

true si *this précède other, false sinon. Les implémentations courantes comparent les adresses des blocs de contrôle.

Exemple

#include <iostream>
#include <memory>

struct Foo
{
    int n1;
    int n2;
    Foo(int a, int b) : n1(a), n2(b) {}
};

int main()
{
    auto p1 = std::make_shared<Foo>(1, 2);
    std::shared_ptr<int> p2(p1, &p1->n1);
    std::shared_ptr<int> p3(p1, &p1->n2);

    std::cout << std::boolalpha
              << "p2 < p3 " << (p2 < p3) << '\n'
              << "p3 < p2 " << (p3 < p2) << '\n'
              << "p2.owner_before(p3) " << p2.owner_before(p3) << '\n'
              << "p3.owner_before(p2) " << p3.owner_before(p2) << '\n';

    std::weak_ptr<int> w2(p2);
    std::weak_ptr<int> w3(p3);
    std::cout
//            << "w2 < w3 " << (w2 < w3) << '\n' // ne compile pas
//            << "w3 < w2 " << (w3 < w2) << '\n' // ne compile pas
              << "w2.owner_before(w3) " << w2.owner_before(w3) << '\n'
              << "w3.owner_before(w2) " << w3.owner_before(w2) << '\n';
}

Output:

p2 < p3 true
p3 < p2 false
p2.owner_before(p3) false
p3.owner_before(p2) false
w2.owner_before(w3) false
w3.owner_before(w2) false
