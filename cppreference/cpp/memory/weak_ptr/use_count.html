std::weak_ptr<T>::use_count

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

long use_count() const noexcept;  // (depuis C++11)

Renvoie le nombre d'instances shared_ptr qui partagent la propriété de l'objet géré, ou 0 si l'objet géré a déjà été supprimé, c'est-à-dire si *this est vide.

Paramètres

(aucune)

Valeur de retour

Le nombre d'instances shared_ptr partageant la propriété de l'objet géré au moment de l'appel.

Notes

L'utilisation et le comportement de cette fonction sont similaires à ceux de std::shared_ptr::use_count, mais elle renvoie un compte différent.

Exemple

#include <iostream>
#include <memory>

std::weak_ptr<int> gwp;

void observe_gwp()
{
    std::cout << "use_count(): " << gwp.use_count() << "\t id: ";
    if (auto sp = gwp.lock())
        std::cout << *sp << '\n';
    else
        std::cout << "??\n";
}

void share_recursively(std::shared_ptr<int> sp, int depth)
{
    observe_gwp(); // : 2 3 4
    if (1 < depth)
        share_recursively(sp, depth - 1);
    observe_gwp(); // : 4 3 2
}

int main()
{
    observe_gwp();
    {
        auto sp = std::make_shared<int>(42);
        gwp = sp;
        observe_gwp(); // : 1
        share_recursively(sp, 3); // : 2 3 4 4 3 2
        observe_gwp(); // : 1
    }
    observe_gwp(); // : 0
}

Output:

use_count(): 1   id: 42
use_count(): 2   id: 42
use_count(): 3   id: 42
use_count(): 4   id: 42
use_count(): 4   id: 42
use_count(): 3   id: 42
use_count(): 2   id: 42
use_count(): 1   id: 42
use_count(): 0   id: ??
