guides de déduction pour std::weak_ptr

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class T >
weak_ptr( std::shared_ptr<T> ) -> weak_ptr<T>;  // (depuis C++17)

Un guide de déduction est fourni pour std::weak_ptr afin de couvrir le cas limite non traité par les guides de déduction implicites.

Exemple

#include <memory>

int main()
{
    auto p = std::make_shared<int>(42);
    std::weak_ptr w{p}; // un guide de déduction explicite est utilisé dans ce cas
}
