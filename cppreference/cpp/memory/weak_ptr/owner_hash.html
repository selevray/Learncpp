Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

std::size_t owner_hash() const noexcept;  // (depuis C++26)

Renvoie une valeur non spécifiée telle que pour tout objet other où owner_equal(other) est true, owner_hash() == other.owner_hash() est true.

Ce hachage permet d'utiliser les pointeurs partagés et faibles comme clés dans des conteneurs associatifs non ordonnés, typiquement via std::owner_hash.

Valeur de retour

Une valeur identique pour tout objet std::shared_ptr ou std::weak_ptr partageant la même propriété.
