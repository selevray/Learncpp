std::declare_no_pointers

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

void declare_no_pointers( char *p, std::size_t n );  // (depuis C++11) (supprimé en C++23)

Informe le ramasse-miettes ou le détecteur de fuites que la zone mémoire spécifiée (n octets commençant à l'octet pointé par p) ne contient aucun pointeur traçable. Si une partie de la zone se trouve dans un objet alloué, la zone entière doit être contenue dans le même objet.

Paramètres

  • p — pointeur vers le début de l'intervalle
  • n — le nombre d'octets de l'intervalle

Valeur de retour

(aucune)

Exceptions

Ne lève aucune exception.
