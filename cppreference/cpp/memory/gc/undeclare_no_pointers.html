void undeclare_no_pointers( char *p, std::size_t n );  // (depuis C++11) (supprimé en C++23)

Retire un intervalle précédemment enregistré avec std::declare_no_pointers().

Paramètres

  • p — pointeur vers le début de l'intervalle précédemment enregistré avec std::declare_no_pointers
  • n — le nombre d'octets de l'intervalle, même valeur que celle utilisée précédemment avec std::declare_no_pointers

Valeur de retour

(aucune)

Exceptions

Ne lève aucune exception.
