std::get_pointer_safety

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

std::pointer_safety get_pointer_safety() noexcept;  // (depuis C++11) (supprimé en C++23)

Obtient le modèle de sécurité des pointeurs défini par l'implémentation, qui est une valeur de type std::pointer_safety.

Paramètres

(aucune)

Valeur de retour

La sécurité des pointeurs utilisée par cette implémentation.

Exemple

#include <iostream>
#include <memory>

int main()
{
    std::cout << "Pointer safety: ";
    switch (std::get_pointer_safety())
    {
        case std::pointer_safety::strict:
            std::cout << "strict\n";
            break;
        case std::pointer_safety::preferred:
            std::cout << "preferred\n";
            break;
        case std::pointer_safety::relaxed:
            std::cout << "relaxed\n";
            break;
    }
}
