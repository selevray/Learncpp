std::shared_ptr<T>::unique

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool unique() const noexcept;  // (obsolète en C++17) (supprimé en C++20)

Vérifie si *this est la seule instance shared_ptr gérant l'objet courant, c.-à-d. si use_count() == 1.

Paramètres

(aucune)

Valeur de retour

true si *this est la seule instance shared_ptr gérant l'objet courant, false sinon.

Notes

Cette fonction a été rendue obsolète en C++17 et supprimée en C++20 car use_count() == 1 n'a pas de sens dans un environnement multithread (voir Notes dans use_count).

Exemple

#include <iostream>
#include <memory>

int main()
{
    auto sp1 = std::make_shared<int>(5);
    std::cout << std::boolalpha;
    std::cout << "sp1.unique() == " << sp1.unique() << '\n';

    std::shared_ptr<int> sp2 = sp1;
    std::cout << "sp1.unique() == " << sp1.unique() << '\n';
}

Output:

sp1.unique() == true
sp1.unique() == false
