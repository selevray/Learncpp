guides de déduction pour std::shared_ptr

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class T >
shared_ptr( std::weak_ptr<T> ) -> shared_ptr<T>;  // (1) (depuis C++17)

template< class T, class D >
shared_ptr( std::unique_ptr<T, D> ) -> shared_ptr<T>;  // (2) (depuis C++17)

Ces guides de déduction sont fournis pour std::shared_ptr afin de couvrir les cas limites non traités par les guides de déduction implicites.

Notez qu'il n'existe aucune déduction d'argument de modèle de classe à partir de types pointeurs, car il est impossible de distinguer les pointeurs obtenus à partir des formes tableau et non tableau de new.

Exemple

#include <memory>

int main()
{
    auto p = std::make_shared<int>(42);
    std::weak_ptr w{p};    // un guide de déduction explicite est utilisé dans ce cas
    std::shared_ptr p2{w}; // un guide de déduction explicite est utilisé dans ce cas
}
