std::shared_ptr<T>::reset

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void reset() noexcept;  // (1) (depuis C++11)

template< class Y >
void reset( Y* ptr );  // (2) (depuis C++11)

template< class Y, class Deleter >
void reset( Y* ptr, Deleter d );  // (3) (depuis C++11)

template< class Y, class Deleter, class Alloc >
void reset( Y* ptr, Deleter d, Alloc alloc );  // (4) (depuis C++11)

Remplace l'objet géré par un objet pointé par ptr. Un deleter optionnel d peut être fourni, il sera ensuite utilisé pour détruire le nouvel objet lorsqu'aucun objet shared_ptr ne le possède. Par défaut, l'expression delete est utilisée comme deleter. L'expression delete appropriée correspondant au type fourni est toujours sélectionnée ; c'est pourquoi la fonction est implémentée comme un modèle utilisant un paramètre distinct Y.

Si *this possède déjà un objet et qu'il en est le dernier shared_ptr propriétaire, l'objet est détruit via le deleter qu'il possède.

Si l'objet pointé par ptr est déjà possédé, la fonction entraîne généralement un comportement indéfini.

  1. Libère la propriété de l'objet géré, le cas échéant. Après l'appel, *this ne gère aucun objet. Équivalent à shared_ptr().swap(*this);.

2-4) Remplace l'objet géré par un objet pointé par ptr. Y doit être un type complet et implicitement convertible en T. De plus :

  1. Utilise l'expression delete comme deleter. Une expression delete valide doit être disponible, c'est-à-dire que delete ptr doit être bien formée, avoir un comportement bien défini et ne lever aucune exception. Équivalent à shared_ptr<T>(ptr).swap(*this);.

  2. Utilise le deleter spécifié d comme deleter. Deleter doit être appelable pour le type T, c'est-à-dire que d(ptr) doit être bien formée, avoir un comportement bien défini et ne lever aucune exception. Deleter doit être CopyConstructible, et son constructeur de copie et son destructeur ne doivent lever aucune exception. Équivalent à shared_ptr<T>(ptr, d).swap(*this);.

  3. Identique à (3), mais utilise en plus une copie de alloc pour l'allocation des données à usage interne. Alloc doit être un Allocator. Le constructeur de copie et le destructeur ne doivent lever aucune exception. Équivalent à shared_ptr<T>(ptr, d, alloc).swap(*this);.

Paramètres

  • ptr — pointeur vers un objet dont il faut acquérir la propriété
  • d — deleter à stocker pour la suppression de l'objet
  • alloc — allocateur à utiliser pour les allocations internes

Valeur de retour

(aucune)

Exceptions

  1. std::bad_alloc si la mémoire supplémentaire requise n'a pas pu être obtenue. Peut lever une exception définie par l'implémentation pour d'autres erreurs. delete ptr est appelé si une exception survient.

3,4) std::bad_alloc si la mémoire supplémentaire requise n'a pas pu être obtenue. Peut lever une exception définie par l'implémentation pour d'autres erreurs. d(ptr) est appelé si une exception survient.

Exemple

#include <iostream>
#include <memory>

struct Foo
{
    Foo(int n = 0) noexcept : bar(n)
    {
        std::cout << "Foo::Foo(), bar = " << bar << " @ " << this << '\n';
    }
    ~Foo()
    {
        std::cout << "Foo::~Foo(), bar = " << bar << " @ " << this << '\n';
    }
    int getBar() const noexcept { return bar; }
private:
    int bar;
};

int main()
{
    std::cout << "1) unique ownership\n";
    {
        std::shared_ptr<Foo> sptr = std::make_shared<Foo>(100);

        std::cout << "Foo::bar = " << sptr->getBar() << ", use_count() = "
                  << sptr.use_count() << '\n';

        // Réinitialise le shared_ptr sans lui fournir une nouvelle instance de Foo.
        // L'ancienne instance sera détruite après cet appel.
        std::cout << "call sptr.reset()...\n";
        sptr.reset(); // appelle ici le destructeur de Foo
        std::cout << "After reset(): use_count() = " << sptr.use_count()
                  << ", sptr = " << sptr << '\n';
    }   // Pas d'appel au destructeur de Foo, il a été effectué plus tôt dans reset().

    std::cout << "\n2) unique ownership\n";
    {
        std::shared_ptr<Foo> sptr = std::make_shared<Foo>(200);

        std::cout << "Foo::bar = " << sptr->getBar() << ", use_count() = "
                  << sptr.use_count() << '\n';

        // Réinitialise le shared_ptr, en lui fournissant une nouvelle instance de Foo.
        // L'ancienne instance sera détruite après cet appel.
        std::cout << "call sptr.reset()...\n";
        sptr.reset(new Foo{222});
        std::cout << "After reset(): use_count() = " << sptr.use_count()
                  << ", sptr = " << sptr << "\nLeaving the scope...\n";
    }   // Appelle le destructeur de Foo.

    std::cout << "\n3) multiple ownership\n";
    {
        std::shared_ptr<Foo> sptr1 = std::make_shared<Foo>(300);
        std::shared_ptr<Foo> sptr2 = sptr1;
        std::shared_ptr<Foo> sptr3 = sptr2;

        std::cout << "Foo::bar = " << sptr1->getBar() << ", use_count() = "
                  << sptr1.use_count() << '\n';

        // Réinitialise le shared_ptr sptr1, en lui fournissant une nouvelle instance de Foo.
        // L'ancienne instance restera partagée entre sptr2 et sptr3.
        std::cout << "call sptr1.reset()...\n";
        sptr1.reset(new Foo{333});

        std::cout << "After reset():\n"
                  << "sptr1.use_count() = " << sptr1.use_count()
                  << ", sptr1 @ " << sptr1 << '\n'
                  << "sptr2.use_count() = " << sptr2.use_count()
                  << ", sptr2 @ " << sptr2 << '\n'
                  << "sptr3.use_count() = " << sptr3.use_count()
                  << ", sptr3 @ " << sptr3 << '\n'
                  << "Leaving the scope...\n";
    }   // Appelle deux destructeurs : 1) celui de Foo possédé par sptr1,
        // 2) celui de Foo partagé entre sptr2/sptr3.
}
