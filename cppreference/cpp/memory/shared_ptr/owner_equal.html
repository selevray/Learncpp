std::shared_ptr<T>::owner_equal

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class Y >
bool owner_equal( const std::shared_ptr<Y>& other ) const noexcept;  // (1) (depuis C++26)

template< class Y >
bool owner_equal( const std::weak_ptr<Y>& other ) const noexcept;  // (2) (depuis C++26)

Vérifie si ce shared_ptr et other partagent la propriété ou sont tous deux vides. La comparaison est telle que deux pointeurs intelligents ne sont équivalents que s'ils sont tous deux vides ou s'ils possèdent le même objet, même si les valeurs des pointeurs obtenues par get() sont différentes (par exemple parce qu'ils pointent vers des sous-objets différents au sein du même objet).

La fonction membre owner_equal est une relation d'équivalence telle que !owner_before(other) && !other.owner_before(*this) est true si et seulement si owner_equal(other) est true.

Cet ordre permet d'utiliser les pointeurs partagés et faibles comme clés dans des conteneurs associatifs non ordonnés, typiquement via std::owner_equal.

Paramètres

  • other — le std::shared_ptr ou le std::weak_ptr à comparer

Valeur de retour

true si *this et other partagent la propriété ou sont tous deux vides. Sinon, renvoie false.
