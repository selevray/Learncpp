std::get_deleter

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class Deleter, class T >
Deleter* get_deleter( const std::shared_ptr<T>& p ) noexcept;  // (depuis C++11)

Accès au deleter du p. Si le pointeur intelligent partagé p possède un deleter de type cv-unqualified Deleter (par exemple s'il a été créé avec l'un des constructeurs qui prennent un deleter en paramètre), alors renvoie un pointeur vers le deleter. Sinon, renvoie un pointeur nul.

Paramètres

  • p — un pointeur intelligent partagé dont le deleter doit être accédé

Valeur de retour

Un pointeur vers le deleter possédé ou nullptr. Le pointeur retourné est valide au moins tant qu'il reste au moins une instance de shared_ptr qui le possède.

Notes

Le pointeur retourné peut survivre à la dernière shared_ptr si, par exemple, des std::weak_ptr subsistent et que l'implémentation ne détruit le deleter qu'à la destruction de tout le bloc de contrôle.

Exemple

Démontre que le deleter de std::shared_ptr est indépendant du type de shared_ptr.

#include <iostream>
#include <memory>

struct Foo { int i; };
void foo_deleter(Foo* p)
{
    std::cout << "foo_deleter called!\n";
    delete p;
}

int main()
{
    std::shared_ptr<int> aptr;

    {
        // crée un shared_ptr qui possède un Foo et un deleter
        auto foo_p = new Foo;
        std::shared_ptr<Foo> r(foo_p, foo_deleter);
        aptr = std::shared_ptr<int>(r, &r->i); // constructeur d'aliasing
        // aptr pointe désormais sur un int, mais gère l'ensemble du Foo
    } // r est détruit (le deleter n'est pas appelé)

    // obtient un pointeur vers le deleter :
    if (auto del_p = std::get_deleter<void(*)(Foo*)>(aptr))
    {
        std::cout << "shared_ptr<int> owns a deleter\n";
        if (*del_p == foo_deleter)
            std::cout << "...and it equals &foo_deleter\n";
    }
    else
        std::cout << "The deleter of shared_ptr<int> is null!\n";
} // deleter appelé ici

Output:

shared_ptr<int> owns a deleter
...and it equals &foo_deleter
foo_deleter called!
