  1. Construit un objet de type T et l'enveloppe dans un std::shared_ptr en utilisant args comme liste de paramètres pour le constructeur de T. L'objet est construit comme si par l'expression [::new (pv) T(v) (jusqu'à C++20) | std::allocator_traits<A2>::construct(a, pv, v) (depuis C++20)], où pv est un pointeur interne void* vers un stockage adapté à contenir un objet de type T et a est une copie de l'allocateur rebindé à std::remove_cv_t<T>. Le stockage est généralement plus grand que sizeof(T) afin d'utiliser une seule allocation pour le bloc de contrôle du pointeur partagé et pour l'objet T. Le constructeur std::shared_ptr appelé par cette fonction active shared_from_this avec un pointeur vers l'objet nouvellement construit de type T. Toute l'allocation mémoire est effectuée à l'aide d'une copie de alloc, qui doit satisfaire aux exigences Allocator. Cette surcharge ne participe à la résolution de surcharge que si T n'est pas un type tableau.

2,3) Identique à (1), mais l'objet construit est un tableau éventuellement multidimensionnel dont chaque élément non tableau est initialisé comme si par l'expression std::allocator_traits<A2>::construct(a2, pv) où a2 de type A2 est la copie de l'allocateur rebindé pour gérer des objets de type std::remove_cv_t<std::remove_all_extents_t<T>>. La surcharge (2) crée un tableau de taille N le long de sa première dimension. Les éléments du tableau sont initialisés dans l'ordre croissant de leurs adresses, et lorsque leur durée de vie se termine ils sont détruits dans l'ordre inverse de leur construction initiale.

4,5) Identique à (2,3), mais les éléments du tableau sont initialisés à partir de la valeur par défaut u. Si std::remove_extent_t<T> n'est pas lui-même un type tableau, cela est effectué comme si par la même expression d'allocateur que dans (1), sauf que l'allocateur est rebindé au std::remove_cv_t<std::remove_all_extents_t<T>>. Sinon, cela est effectué comme si en initialisant chaque élément non tableau du tableau (éventuellement multidimensionnel) avec l'élément correspondant de u en utilisant la même expression d'allocateur que dans (1), sauf que l'allocateur est rebindé au type std::remove_cv_t<std::remove_all_extents_t<T>>. La surcharge (4) crée un tableau de taille N le long de la première dimension. Les éléments du tableau sont initialisés dans l'ordre croissant de leurs adresses, et lorsque leur durée de vie se termine ils sont détruits dans l'ordre inverse de leur construction initiale.

  1. Identique à (1) si T n'est pas un type tableau et à (3) si T est U[N], sauf que l'objet créé est initialisé par défaut.

  2. Identique à (2), sauf que les éléments individuels du tableau sont initialisés par défaut.

Pour allocate_shared, l'objet (ou les éléments individuels du tableau pour (2-5)) (depuis C++20) sont détruits via l'expression std::allocator_traits<A2>::destroy(a, p), où p est un pointeur vers l'objet et a est une copie de l'allocateur passé à allocate_shared, rebindé au type de l'objet détruit.

Pour allocate_shared_for_overwrite, l'objet (ou les éléments individuels si T est un type tableau) sera détruit par p->~X(), où p est un pointeur vers l'objet et X son type.

(depuis C++20)

Paramètres

  • alloc — le Allocator à utiliser
  • args... — liste d'arguments avec lesquels une instance de T sera construite
  • N — taille du tableau à utiliser
  • u — la valeur initiale servant à initialiser chaque élément du tableau

Valeur de retour

std::shared_ptr d'une instance du type T.

Exceptions

Peut lever les exceptions levées par Alloc::allocate() ou par le constructeur de T. Si une exception est levée, (1) n'a aucun effet. Si une exception est levée pendant la construction du tableau, les éléments déjà initialisés sont détruits dans l'ordre inverse (depuis C++20).

Notes

Comme std::make_shared, cette fonction n'effectue généralement qu'une seule allocation, et place à la fois l'objet T et le bloc de contrôle dans le bloc mémoire alloué (la norme recommande mais n'exige pas cela, toutes les implémentations connues le font). Une copie de alloc est stockée dans le bloc de contrôle afin de pouvoir l'utiliser pour désallouer celui-ci lorsque les compteurs de références forts et faibles atteignent zéro.

Contrairement à std::shared_ptr constructors, std::allocate_shared n'accepte pas de destructeur personnalisé distinct : l'allocateur fourni est utilisé pour la destruction du bloc de contrôle et de l'objet T, ainsi que pour la désallocation de leur bloc mémoire partagé.

std::shared_ptr prend en charge les types tableaux (depuis C++17), mais std::allocate_shared non. Cette fonctionnalité est prise en charge par boost::allocate_shared.

(jusqu'à C++20)

Un constructeur active shared_from_this avec un pointeur ptr de type U* signifie qu'il détermine si U possède une classe de base non ambiguë et accessible (depuis C++17) qui est une spécialisation de std::enable_shared_from_this, et si c'est le cas, le constructeur évalue if (ptr != nullptr && ptr->weak_this ﻿.expired()) ptr->weak_this = std::shared_ptr<std::remove_cv_t<U>> (*this, const_cast<std::remove_cv_t<U>*>(ptr));.

L'affectation à weak_this n'est pas atomique et entre en conflit avec tout accès concurrent potentiel au même objet. Cela garantit que les appels futurs à shared_from_this() partageront la propriété avec le std::shared_ptr créé par ce constructeur à partir d'un pointeur brut.

Le test ptr->weak_this ﻿.expired() dans le code ci-dessus garantit que weak_this n'est pas réaffecté s'il indique déjà un propriétaire. Ce test est requis depuis C++17.

Exemple

#include <cstddef>
#include <iostream>
#include <memory>
#include <memory_resource>
#include <vector>

class Value
{
    int i;

public:
    Value(int i) : i(i) { std::cout << "Value(), i = " << i << '\n'; }
    ~Value() { std::cout << "~Value(), i = " << i << '\n'; }
    void print() const { std::cout << "i = " << i << '\n'; }
};

int main()
{
    // Créer un allocateur polymorphe utilisant la ressource tampon monotone
    std::byte buffer[sizeof(Value) * 8];
    std::pmr::monotonic_buffer_resource resource(buffer, sizeof(buffer));
    std::pmr::polymorphic_allocator<Value> allocator(&resource);

    std::vector<std::shared_ptr<Value>> v;

    for (int i{}; i != 4; ++i)
        // Utiliser std::allocate_shared avec l'allocateur personnalisé
        v.emplace_back(std::allocate_shared<Value>(allocator, i));

    for (const auto& sp : v)
        sp->print();

} //< Tous les pointeurs partagés nettoieront automatiquement leurs ressources lorsqu'ils sortiront de leur portée.
