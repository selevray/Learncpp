std::shared_ptr<T>::operator<<

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class T, class U, class V >
std::basic_ostream<U, V>& operator<<( std::basic_ostream<U, V>& os, const std::shared_ptr<T>& ptr );

Insère la valeur du pointeur stocké dans ptr dans le flux de sortie os.

Équivalent à os << ptr.get().

Paramètres

  • os — un std::basic_ostream dans lequel insérer ptr
  • ptr — les données à insérer dans os

Valeur de retour

os

Exemple

#include <iostream>
#include <memory>

class Foo {};

int main()
{
    auto sp = std::make_shared<Foo>();
    std::cout << sp << '\n';
    std::cout << sp.get() << '\n';
}
