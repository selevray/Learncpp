  1. Construit un objet de type T et l'enveloppe dans un std::shared_ptr en utilisant args comme liste de paramètres pour le constructeur de T. L'objet est construit comme si par l'expression ::new (pv) T(std::forward<Args>(args)...), où pv est un pointeur void* interne vers un stockage adapté pour contenir un objet de type T. Le stockage est généralement plus grand que sizeof(T) afin d'utiliser une seule allocation pour le bloc de contrôle du pointeur partagé et pour l'objet T. Le constructeur std::shared_ptr appelé par cette fonction permet à shared_from_this d'être initialisé avec un pointeur vers l'objet nouvellement construit de type T.

Cette surcharge ne participe à la résolution de surcharge que si T n'est pas un type tableau.

(depuis C++20)

2,3) Identique à (1), mais l'objet construit est un tableau éventuellement multidimensionnel dont les éléments non tableaux de type std::remove_all_extents_t<T> sont initialisés par valeur comme si par l'expression de placement-new ::new(pv) std::remove_all_extents_t<T>(). La surcharge (2) crée un tableau de taille N selon la première dimension. Les éléments du tableau sont initialisés dans l'ordre croissant de leurs adresses, et lorsque leur durée de vie se termine, ils sont détruits dans l'ordre inverse de leur construction initiale.

4,5) Identique à (2,3), mais chaque élément est initialisé à partir de la valeur par défaut u. Si U n'est pas un type tableau, cela est effectué comme si par la même expression de placement-new que dans (1) ; sinon, cela est effectué comme si par l'initialisation de chaque élément non tableau du tableau (éventuellement multidimensionnel) avec l'élément correspondant de u, avec la même expression de placement-new que dans (1). La surcharge (4) crée un tableau de taille N selon la première dimension. Les éléments du tableau sont initialisés dans l'ordre croissant de leurs adresses, et lorsque leur durée de vie se termine, ils sont détruits dans l'ordre inverse de leur construction initiale.

  1. Identique à (1) si T n'est pas un type tableau et à (3) si T est U[N], sauf que l'objet créé est initialisé par défaut.

  2. Identique à (2), sauf que les éléments individuels du tableau sont initialisés par défaut.

Dans chaque cas, l'objet (ou les éléments individuels si T est un type tableau) (depuis C++20) sera détruit par p->~X(), où p est un pointeur vers l'objet et X son type.

Paramètres

  • args — liste d'arguments avec lesquels une instance de T sera construite
  • N — taille du tableau à utiliser
  • u — la valeur initiale servant à initialiser chaque élément du tableau

Valeur de retour

std::shared_ptr d'une instance du type T.

Exceptions

Peut lever std::bad_alloc ou toute exception levée par le constructeur de T. Si une exception est levée, les fonctions n'ont aucun effet. Si une exception est levée pendant la construction du tableau, les éléments déjà initialisés sont détruits dans l'ordre inverse. (depuis C++20)

Notes

Cette fonction peut être utilisée comme alternative à std::shared_ptr<T>(new T(args...)). Les compromis sont :

  • std::shared_ptr<T>(new T(args...)) effectue au moins deux allocations (une pour l'objet T et une pour le bloc de contrôle du pointeur partagé), alors que std::make_shared<T> n'effectue généralement qu'une seule allocation (la norme le recommande mais ne l'exige pas ; toutes les implémentations connues le font).
  • Si un std::weak_ptr référence le bloc de contrôle créé par std::make_shared après la fin de la durée de vie de tous les propriétaires partagés, la mémoire occupée par T persiste jusqu'à ce que tous les propriétaires faibles soient eux aussi détruits, ce qui peut être indésirable si sizeof(T) est volumineux.
  • std::shared_ptr<T>(new T(args...)) peut appeler un constructeur non public de T s'il est exécuté dans un contexte où il est accessible, alors que std::make_shared exige un accès public au constructeur sélectionné.
  • Contrairement aux constructeurs std::shared_ptr, std::make_shared n'autorise pas de deleter personnalisé.
  • std::make_shared utilise ::new, donc si un comportement particulier a été défini à l'aide d'un operator new spécifique à la classe, il différera de std::shared_ptr<T>(new T(args...)).
  • std::shared_ptr prend en charge les types tableaux (depuis C++17), mais std::make_shared non. Cette fonctionnalité est prise en charge par boost::make_shared.

(jusqu'à C++20)

  • du code tel que f(std::shared_ptr<int>(new int(42)), g()) peut provoquer une fuite mémoire si g est appelé après new int(42) et lève une exception, alors que f(std::make_shared<int>(42), g()) est sûr, car les deux appels de fonctions ne sont jamais entrelacés.

(jusqu'à C++17)

Un constructeur active shared_from_this avec un pointeur ptr de type U* signifie qu'il détermine si U possède une classe de base non ambiguë et accessible (depuis C++17) qui est une spécialisation de std::enable_shared_from_this, et si c'est le cas, le constructeur évalue if (ptr != nullptr && ptr->weak_this ﻿.expired()) ptr->weak_this = std::shared_ptr<std::remove_cv_t<U>> (*this, const_cast<std::remove_cv_t<U>*>(ptr));.

L'affectation à weak_this n'est pas atomique et entre en conflit avec tout accès concurrent potentiel au même objet. Cela garantit que les appels futurs à shared_from_this() partageront la propriété avec le std::shared_ptr créé par ce constructeur à partir d'un pointeur brut.

Le test ptr->weak_this ﻿.expired() dans le code ci-dessus garantit que weak_this n'est pas réaffecté s'il indique déjà un propriétaire. Ce test est requis depuis C++17.

Exemple

#include <iostream>
#include <memory>
#include <type_traits>
#include <vector>

struct C
{
    // constructeurs nécessaires (jusqu'à C++20)
    C(int i) : i(i) {}
    C(int i, float f) : i(i), f(f) {}
    int i;
    float f{};
};

int main()
{
    // utiliser `auto` pour le type de `sp1`
    auto sp1 = std::make_shared<C>(1); // overload (1)
    static_assert(std::is_same_v<decltype(sp1), std::shared_ptr<C>>);
    std::cout << "sp1->{ i:" << sp1->i << ", f:" << sp1->f << " }\n";

    // expliciter le type de `sp2`
    std::shared_ptr<C> sp2 = std::make_shared<C>(2, 3.0f); // overload (1)
    static_assert(std::is_same_v<decltype(sp2), std::shared_ptr<C>>);
    static_assert(std::is_same_v<decltype(sp1), decltype(sp2)>);
    std::cout << "sp2->{ i:" << sp2->i << ", f:" << sp2->f << " }\n";

    // shared_ptr vers un float[64] initialisé par valeur ; surcharge (2) :
    std::shared_ptr<float[]> sp3 = std::make_shared<float[]>(64);

    // shared_ptr vers un long[5][3][4] initialisé par valeur ; surcharge (2) :
    std::shared_ptr<long[][3][4]> sp4 = std::make_shared<long[][3][4]>(5);

    // shared_ptr vers un short[128] initialisé par valeur ; surcharge (3) :
    std::shared_ptr<short[128]> sp5 = std::make_shared<short[128]>();

    // shared_ptr vers un int[7][6][5] initialisé par valeur ; surcharge (3) :
    std::shared_ptr<int[7][6][5]> sp6 = std::make_shared<int[7][6][5]>();

    // shared_ptr vers un double[256], où chaque élément vaut 2.0 ; surcharge (4) :
    std::shared_ptr<double[]> sp7 = std::make_shared<double[]>(256, 2.0);

    // shared_ptr vers un double[7][2], où chaque double[2]
    // élément vaut {3.0, 4.0} ; surcharge (4) :
    std::shared_ptr<double[][2]> sp8 = std::make_shared<double[][2]>(7, {3.0, 4.0});

    // shared_ptr vers un vector<int>[4], où chaque vector
    // contient {5, 6} ; surcharge (4) :
    std::shared_ptr<std::vector<int>[]> sp9 =
        std::make_shared<std::vector<int>[]>(4, {5, 6});

    // shared_ptr vers un float[512], où chaque élément vaut 1.0 ; surcharge (5) :
    std::shared_ptr<float[512]> spA = std::make_shared<float[512]>(1.0);

    // shared_ptr vers un double[6][2], où chaque élément double[2]
    // vaut {1.0, 2.0} ; surcharge (5) :
    std::shared_ptr<double[6][2]> spB = std::make_shared<double[6][2]>({1.0, 2.0});

    // shared_ptr vers un vector<int>[4], où chaque vector
    // contient {5, 6} ; surcharge (5) :
    std::shared_ptr<std::vector<int>[4]> spC =
        std::make_shared<std::vector<int>[4]>({5, 6});
}

Output:

sp1->{ i:1, f:0 }
sp2->{ i:2, f:3 }
