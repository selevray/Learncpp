std::pmr::synchronized_pool_resource::do_allocate

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

virtual void* do_allocate( std::size_t bytes, std::size_t alignment );  // (depuis C++17)

Alloue un stockage.

Si le pool sélectionné pour un bloc de taille bytes ne peut pas satisfaire la requête à partir de ses structures de données internes, appelle allocate() sur la ressource mémoire amont pour obtenir de la mémoire.

Si la taille demandée est supérieure à ce que le plus grand pool peut gérer, la mémoire est allouée en appelant allocate() sur la ressource mémoire amont.

Valeur de retour

Un pointeur vers un stockage alloué d'une taille d'au moins bytes octets, aligné sur l'alignment spécifié si un tel alignement est pris en charge, et sur alignof(std::max_align_t) sinon.

Exceptions

Ne lève rien, sauf si l'appel de allocate() sur la ressource mémoire amont lève une exception.
