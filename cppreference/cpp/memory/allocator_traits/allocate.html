std::allocator_traits<Alloc>::allocate

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

static pointer allocate( Alloc& a, size_type n );  // (1) (depuis C++11) (constexpr depuis C++20)

static pointer allocate( Alloc& a, size_type n, const_void_pointer hint );  // (2) (depuis C++11) (constexpr depuis C++20)

Utilise l'allocateur a pour allouer n * sizeof(Alloc::value_type) octets de stockage non initialisé. Un tableau de type Alloc::value_type[n] est créé dans le stockage, mais aucun de ses éléments n'est construit.

  1. Appelle a.allocate(n).

  2. Passe en outre l'indice de localité mémoire hint. Appelle a.allocate(n, hint) si possible. Si ce n'est pas possible (par exemple a n'a pas de fonction membre à deux arguments allocate), appelle a.allocate(n).

Paramètres

  • a — allocateur à utiliser
  • n — le nombre d'objets pour lesquels allouer un stockage
  • hint — pointeur vers un emplacement mémoire voisin

Valeur de retour

Le pointeur renvoyé par l'appel à a.allocate(n).

Notes

Alloc::allocate n'était pas tenu de créer un objet tableau avant P0593R6, qui a rendu l'utilisation d'un allocateur non par défaut pour std::vector et certains autres conteneurs mal définie selon une lecture stricte de la spécification du langage de base.

Après l'appel de allocate et avant la construction des éléments, l'arithmétique des pointeurs de Alloc::value_type* est bien définie dans le tableau alloué, mais le comportement est indéfini si des éléments sont accédés.
