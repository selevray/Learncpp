std::allocator_traits<Alloc>::destroy

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class T >
static void destroy( Alloc& a, T* p );  // (depuis C++11) (constexpr depuis C++20)

Appelle le destructeur de l'objet pointé par p. Si possible, le fait en appelant a.destroy(p). Si ce n'est pas possible (par exemple Alloc n'a pas la fonction membre destroy()), alors appelle [directement le destructeur de *p, comme p->~T() (jusqu'à C++20) | std::destroy_at(p) (depuis C++20)].

Paramètres

  • a — allocateur à utiliser pour la destruction
  • p — pointeur vers l'objet en cours de destruction

Valeur de retour

(aucune)

Notes

Comme cette fonction fournit le repli automatique vers un appel direct au destructeur, la fonction membre destroy() est une exigence optionnelle Allocator depuis C++11.
