std::allocator_traits<Alloc>::allocate_at_least

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static constexpr std::allocation_result<pointer, size_type>
    allocate_at_least( Alloc& a, size_type n );  // (depuis C++23)

allocate_at_least appelle a.allocate_at_least(n) et renvoie son résultat si l'appel est bien formé, sinon, il est équivalent à return {a.allocate(n), n};.

allocator_at_least tente d'allouer un stockage pour au moins n value_type objets, et fournit un mécanisme de repli qui alloue un stockage pour exactement n objets.

Paramètres

  • a — un allocateur utilisé pour allouer le stockage
  • n — la borne inférieure du nombre d'objets pour lesquels allouer du stockage

Valeur de retour

a.allocate_at_least(n) s'il est bien formé.

Sinon, std::allocation_result<pointer, size_type>{a.allocate(n), n}.

Exceptions

Lève les exceptions levées par la fonction d'allocation sélectionnée, dans les mêmes circonstances.

Notes

La fonction membre allocate_at_least des types Allocator est principalement fournie pour les conteneurs contigus, par ex. std::vector et std::basic_string, afin de réduire les réallocations en faisant correspondre leur capacité à la taille effectivement allouée lorsque c'est possible. Comme allocate_at_least fournit un mécanisme de repli, il peut être directement utilisé lorsque c'est approprié.

Étant donné un objet allocateur a de type Alloc, notons result la valeur renvoyée par std::allocator_traits<Alloc>::allocate_at_least(a, n) ; le stockage doit être désalloué par a.deallocate(result.ptr, m) (généralement appelé via std::allocator_traits<Alloc>::deallocate(a, result.ptr, m)) afin d'éviter une fuite de mémoire.

L'argument m utilisé lors de la désallocation ne doit pas être inférieur à n ni supérieur à result.count, sinon le comportement est indéfini. Notez que n est toujours égal à result.count si l'allocateur ne fournit pas allocate_at_least, ce qui signifie que m doit être égal à n.
