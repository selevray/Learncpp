std::allocator_traits<Alloc>::max_size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

static size_type max_size( const Alloc& a ) noexcept;  // (depuis C++11) (constexpr depuis C++20)

Si possible, obtient la taille d'allocation maximale théoriquement possible à partir de l'allocateur a, en appelant a.max_size().

Si ce qui précède n'est pas possible (par exemple Alloc n'a pas la fonction membre max_size()), alors renvoie std::numeric_limits<size_type>::max() / sizeof(value_type).

Paramètres

  • a — allocateur à interroger

Valeur de retour

Taille d'allocation maximale théorique.

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 2162 C++11 max_size n'était pas tenu d'être noexcept required
LWG 2466 C++11 la taille d'allocation maximale théorique en octets a été renvoyée en repli la taille en éléments est renvoyée

Exemple

#include <iostream>
#include <memory>
#include <locale>

int main()
{
    std::allocator<short> b;
    std::allocator<int> d;

    const auto p = std::allocator_traits<decltype(b)>::max_size(b);
    const auto q = std::allocator_traits<decltype(d)>::max_size(d);

    std::cout.imbue(std::locale("en_US.UTF-8"));
    std::cout << std::uppercase
              << "p = " << std::dec << p << " = 0x" << std::hex << p << '\n'
              << "q = " << std::dec << q << " = 0x" << std::hex << q << '\n';
}

Sortie possible :

p = 9,223,372,036,854,775,807 = 0x7,FFF,FFF,FFF,FFF,FFF
q = 4,611,686,018,427,387,903 = 0x3,FFF,FFF,FFF,FFF,FFF
