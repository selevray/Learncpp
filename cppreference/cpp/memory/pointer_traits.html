std::pointer_traits

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class Ptr >
struct pointer_traits;  // (1) (depuis C++11)

template< class T >
struct pointer_traits<T*>;  // (2) (depuis C++11)

Le modèle de classe pointer_traits fournit la manière standardisée d'accéder à certaines propriétés des types de type pointeur (pointeurs sophistiqués, tels que boost::interprocess::offset_ptr). Le modèle standard std::allocator_traits s'appuie sur pointer_traits pour déterminer les valeurs par défaut des différents typedefs requis par Allocator.

  1. Le modèle pointer_traits non spécialisé déclare conditionnellement les membres suivants :

Soit /*element-type-of*/<Ptr> égal à

  • Ptr::element_type s'il est présent ;
  • sinon, T si Ptr est une spécialisation de modèle de classe Template<T, Args...>, où Args... est zéro ou plusieurs arguments de type ;
  • sinon, non défini.

Si /*element-type-of*/<Ptr> n'est pas défini, le modèle primaire n'a aucun membre spécifié sur cette page.

Type Définition

Notes

L'alias de modèle de membre rebind permet, étant donné un type de type pointeur qui pointe vers T, d'obtenir le même type de type pointeur qui pointe vers U. Par exemple,

using another_pointer = std::pointer_traits<std::shared_ptr<int>>::rebind<double>;
static_assert(std::is_same<another_pointer, std::shared_ptr<double>>::value);

Une spécialisation pour les types de pointeurs intelligents définis par l'utilisateur peut fournir une fonction membre statique supplémentaire to_address pour personnaliser le comportement de std::to_address.

Exemple

#include <iostream>
#include <memory>

template<class Ptr>
struct BlockList
{
    // Prédéfinit un bloc mémoire
    struct block;

    // Définit un pointeur vers un bloc mémoire à partir du type de pointeur Ptr
    // Si Ptr est un T* quelconque, block_ptr_t est block*
    // Si Ptr est smart_ptr<T>, block_ptr_t est smart_ptr<block>
    using block_ptr_t = typename std::pointer_traits<Ptr>::template rebind<block>;

    struct block
    {
        std::size_t size{};
        block_ptr_t next_block{};
    };

    block_ptr_t free_blocks;
};

int main()
{
    [[maybe_unused]]
    BlockList<int*> bl1;
    // Le type de bl1.free_blocks est BlockList<int*>:: block*

    BlockList<std::shared_ptr<char>> bl2;
    // Le type de bl2.free_blocks est
    // std::shared_ptr<BlockList<std::shared_ptr<char>>::block>
    std::cout << bl2.free_blocks.use_count() << '\n';
}
