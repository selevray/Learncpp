std::pmr::polymorphic_allocator<T>::allocate_object

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class U >
U* allocate_object( std::size_t n = 1 );  // (depuis C++20)

Alloue un espace de stockage pour n objets de type U à l'aide de la ressource mémoire sous-jacente.

Si std::numeric_limits<std::size_t>::max() / sizeof(U) < n, lève std::bad_array_new_length, sinon équivalent à return static_cast<U*>(allocate_bytes(n * sizeof(U), alignof(U)));.

Paramètres

  • n — le nombre d'objets pour lesquels allouer un stockage

Valeur de retour

Un pointeur vers le stockage alloué.

Notes

Cette fonction a été introduite pour être utilisée avec l'allocateur totalement spécialisé std::pmr::polymorphic_allocator<>, mais elle peut être utile dans toute spécialisation, comme raccourci évitant de devoir effectuer un rebind de std::pmr::polymorphic_allocator<T> vers std::pmr::polymorphic_allocator<U>.

Comme U n'est pas déduit, il doit être fourni comme argument de modèle lors de l'appel à cette fonction.

Exceptions

Lève std::bad_array_new_length si n > std::numeric_limits<std::size_t>::max() / sizeof(U) ; peut également être toute exception levée par l'appel à resource()->allocate.
