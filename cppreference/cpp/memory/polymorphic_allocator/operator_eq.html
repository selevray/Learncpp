Compare deux allocateurs polymorphes. Deux allocateurs polymorphes sont égaux si leur ressource mémoire sous-jacente est égale.

  1. Renvoie *lhs.resource() == *rhs.resource().

  2. Identique à (1), permettant la conversion vers polymorphic_allocator.
    Cette fonction n'est pas visible par la recherche non qualifiée ordinaire ou qualifiée, et ne peut être trouvée que par la recherche dépendant des arguments lorsque std::pmr::polymorphic_allocator est une classe associée des arguments.

  3. Renvoie !(lhs == rhs).

  4. Identique à (3), permettant la conversion vers polymorphic_allocator.
    Cette fonction n'est pas visible par la recherche non qualifiée ordinaire ou qualifiée, et ne peut être trouvée que par la recherche dépendant des arguments lorsque std::pmr::polymorphic_allocator est une classe associée des arguments.

L'opérateur != est synthétisé à partir de operator==.

(depuis C++20)

Paramètres

  • lhs, rhs — allocateurs polymorphes à comparer

Valeur de retour

1,2) *lhs.resource() == *rhs.resource()

3,4) !(lhs == rhs)
