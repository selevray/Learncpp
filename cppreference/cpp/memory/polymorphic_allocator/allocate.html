std::pmr::polymorphic_allocator<T>::allocate

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

T* allocate( std::size_t n );  // (depuis C++17)

Alloue un espace de stockage pour n objets de type T à l'aide de la ressource mémoire sous-jacente. Équivalent à return static_cast<T*>(resource()->allocate(n * sizeof(T), alignof(T)));.

Paramètres

  • n — le nombre d'objets pour lesquels allouer un stockage

Valeur de retour

Un pointeur vers le stockage alloué.

Exceptions

Lève std::bad_array_new_length si n > std::numeric_limits<std::size_t>::max() / sizeof(T) ; peut également lever toute exception levée par l'appel à resource()->allocate.
