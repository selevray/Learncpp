std::pmr::polymorphic_allocator<T>::deallocate_object

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class U >
void deallocate_object( U* p, std::size_t n = 1 );  // (depuis C++20)

Désalloue le stockage pointé par p, qui doit avoir été alloué à partir d'un std::pmr::memory_resource x égal à *resource(), en utilisant x.allocate(n * sizeof(U), alignof(U)), typiquement via un appel à allocate_object<U>(n).

Équivalent à deallocate_bytes(p, n * sizeof(U), alignof(U));.

Paramètres

  • p — pointeur vers la mémoire à désallouer
  • n — nombre d'objets de type U pour lesquels la mémoire a été allouée

Exceptions

Ne lève aucune exception.

Notes

Cette fonction a été introduite pour être utilisée avec l'allocateur totalement spécialisé std::pmr::polymorphic_allocator<>, mais elle peut être utile dans toute spécialisation.
