std::realloc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdlib>

void* realloc( void* ptr, std::size_t new_size );

Réalloue la zone mémoire donnée (crée implicitement des objets dans la zone de destination). Elle doit avoir été allouée précédemment par std::malloc, std::calloc ou std::realloc et ne pas encore avoir été libérée par std::free, sinon les résultats sont indéfinis.

La réallocation s'effectue soit :

a) en agrandissant ou en réduisant la zone existante désignée par ptr, si possible. Le contenu de la zone reste inchangé jusqu'à la plus petite des tailles nouvelle et ancienne. Si la zone est agrandie, le contenu de la nouvelle partie du tableau est indéfini.

b) en allouant un nouveau bloc mémoire de new_size octets, en copiant la zone mémoire d'une taille égale à la plus petite des tailles nouvelle et ancienne, et en libérant l'ancien bloc.

S'il n'y a pas assez de mémoire, l'ancien bloc mémoire n'est pas libéré et un pointeur nul est renvoyé.

Si ptr est un pointeur nul, le comportement est le même qu'un appel à std::malloc(new_size).

Si new_size vaut zéro, le comportement est défini par l'implémentation : un pointeur nul peut être renvoyé (auquel cas l'ancien bloc mémoire peut ou non être libéré) ou un pointeur non nul pouvant ne pas être utilisé pour accéder au stockage. Cet usage est obsolète (via C DR 400). (depuis C++20)

Les fonctions suivantes doivent être thread-safe :

  • Les versions de la bibliothèque de operator new et de operator delete
  • Les versions de remplacement définies par l'utilisateur des operator new et operator delete globales
  • std::calloc, std::malloc, std::realloc, std::aligned_alloc (depuis C++17), std::free

Les appels à ces fonctions qui allouent ou libèrent une unité de stockage donnée se produisent selon un ordre total unique, et chaque appel de désallocation happens-before l'allocation suivante (le cas échéant) dans cet ordre.

(depuis C++11)

Paramètres

  • ptr — pointeur vers la zone mémoire à réallouer
  • new_size — nouvelle taille du tableau

Valeur de retour

En cas de succès, renvoie un pointeur vers le début de la mémoire nouvellement allouée. Pour éviter une fuite mémoire, le pointeur renvoyé doit être désalloué avec std::free ou std::realloc. Le pointeur d'origine ptr est invalidé et tout accès à celui-ci est un comportement indéfini (même si la réallocation a été effectuée sur place).

En cas d'échec, renvoie un pointeur nul. Le pointeur d'origine ptr reste valide et peut devoir être désalloué avec std::free.

Notes

La réallocation pouvant impliquer une copie octet par octet (qu'elle agrandisse ou réduise la zone), il est nécessaire (mais non suffisant) que ces objets soient de type TriviallyCopyable.

Certaines bibliothèques non standard définissent un trait de type « BitwiseMovable » ou « Relocatable », qui décrit un type n'ayant pas :

  • de références externes (par exemple des nœuds d'une liste ou d'un arbre qui contient une référence vers un autre élément), et
  • de références internes (par exemple un pointeur vers membre pouvant contenir l'adresse d'un autre membre).

Les objets de ce type peuvent être accédés après que leur zone de stockage a été réallouée, même si leurs constructeurs de copie ne sont pas triviaux.

Exemple

#include <cassert>
#include <cstdlib>
#include <new>

class MallocDynamicBuffer
{
    char* p;
public:
    explicit MallocDynamicBuffer(std::size_t initial = 0) : p(nullptr)
    {
        resize(initial);
    }

    ~MallocDynamicBuffer() { std::free(p); }

    void resize(std::size_t newSize)
    {
        if (newSize == 0) // cette vérification n'est pas strictement nécessaire,
        {
            std::free(p); // mais le realloc de taille nulle est obsolète en C
            p = nullptr;
        }
        else
        {
            if (void* mem = std::realloc(p, newSize))
                p = static_cast<char*>(mem);
            else
                throw std::bad_alloc();
        }
    }

    char& operator[](size_t n) { return p[n]; }
    char operator[](size_t n) const { return p[n]; }
};

int main()
{
    MallocDynamicBuffer buf1(1024);
    buf1[5] = 'f';
    buf1.resize(10); // shrink
    assert(buf1[5] == 'f');
    buf1.resize(1024); // grow
    assert(buf1[5] == 'f');
}
