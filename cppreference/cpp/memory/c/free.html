std::free

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdlib>

void free( void* ptr );

Libère l'espace précédemment alloué par std::malloc, std::calloc, std::aligned_alloc (depuis C++17), ou std::realloc.

Si ptr est un pointeur nul, la fonction ne fait rien.

Le comportement est indéfini si la valeur de ptr n'est pas égale à une valeur précédemment renvoyée par std::malloc, std::calloc, std::aligned_alloc (depuis C++17), ou std::realloc.

Le comportement est indéfini si la zone mémoire désignée par ptr a déjà été libérée, c'est-à-dire si std::free ou std::realloc a déjà été appelée avec ptr comme argument et qu'aucun appel à std::malloc, std::calloc, std::aligned_alloc (depuis C++17), ou std::realloc n'a ensuite produit un pointeur égal à ptr.

Le comportement est indéfini si, après le retour de std::free, un accès est effectué via le pointeur ptr (sauf si une autre fonction d'allocation a produit par hasard une valeur de pointeur égale à ptr).

Les fonctions suivantes doivent être thread-safe :

  • Les versions de la bibliothèque de operator new et de operator delete
  • Les versions de remplacement définies par l'utilisateur des operator new et operator delete globales
  • std::calloc, std::malloc, std::realloc, std::aligned_alloc (depuis C++17), std::free

Les appels à ces fonctions qui allouent ou libèrent une unité de stockage donnée se produisent selon un ordre total unique, et chaque appel de désallocation happens-before l'allocation suivante (le cas échéant) dans cet ordre.

(depuis C++11)

Paramètres

  • ptr — pointeur vers la mémoire à libérer

Valeur de retour

(aucune)

Notes

La fonction accepte le pointeur nul (et n'y fait rien) afin de réduire le nombre de cas particuliers. Que l'allocation réussisse ou non, le pointeur renvoyé par une fonction d'allocation peut être passé à std::free.

Exemple

#include <cstdlib>

int main()
{
    int* p1 = (int*)std::malloc(10 * sizeof *p1);
    std::free(p1); // tout pointeur alloué doit être libéré

    int* p2 = (int*)std::calloc(10, sizeof *p2);
    int* p3 = (int*)std::realloc(p2, 1000 * sizeof *p3);
    if (!p3) // p3 nul signifie que realloc a échoué et p2 doit être libéré.
        std::free(p2);
    std::free(p3); // p3 peut être libéré qu'il soit nul ou non.
}
