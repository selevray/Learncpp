std::malloc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdlib>

void* malloc( std::size_t size );

Alloue size octets de stockage non initialisé.

Si l'allocation réussit, renvoie un pointeur vers le premier octet (le plus bas) du bloc mémoire alloué, aligné convenablement pour tout type scalaire (au moins aussi strictement que std::max_align_t) (crée implicitement des objets dans la zone de destination).

Si size vaut zéro, le comportement est défini par l'implémentation (un pointeur nul peut être renvoyé, ou un pointeur non nul pouvant ne pas être utilisé pour accéder au stockage, mais devant être passé à std::free).

Les fonctions suivantes doivent être thread-safe :

  • Les versions de la bibliothèque de operator new et de operator delete
  • Les versions de remplacement définies par l'utilisateur des operator new et operator delete globales
  • std::calloc, std::malloc, std::realloc, std::aligned_alloc (depuis C++17), std::free

Les appels à ces fonctions qui allouent ou libèrent une unité de stockage donnée se produisent selon un ordre total unique, et chaque appel de désallocation happens-before l'allocation suivante (le cas échéant) dans cet ordre.

(depuis C++11)

Paramètres

  • size — nombre d'octets à allouer

Valeur de retour

En cas de succès, retourne le pointeur vers le début de la mémoire nouvellement allouée. Pour éviter une fuite mémoire, le pointeur retourné doit être libéré avec std::free() ou std::realloc().

En cas d'échec, retourne un pointeur nul.

Notes

Cette fonction n'appelle pas de constructeurs et n'initialise la mémoire d'aucune façon. Il n'existe pas de pointeurs intelligents prêts à l'emploi qui pourraient garantir l'appel de la fonction de désallocation correspondante. La méthode préférée d'allocation mémoire en C++ consiste à utiliser les fonctions compatibles RAII std::make_unique, std::make_shared, les constructeurs de conteneurs, etc., et, dans le code de bibliothèque bas niveau, l'expression new.

Pour charger un gros fichier, le mappage de fichier via des fonctions propres au système, par exemple mmap sous POSIX ou CreateFileMapping(A/W) avec MapViewOfFile sous Windows, est préférable à l'allocation d'un tampon pour la lecture du fichier.

Exemple

#include <cstdlib>
#include <iostream>
#include <memory>
#include <string>

int main()
{
    constexpr std::size_t size = 4;
    if (auto ptr = reinterpret_cast<std::string*>(std::malloc(size * sizeof(std::string))))
    {
        try
        {
            for (std::size_t i = 0; i < size; ++i)
                std::construct_at(ptr + i, 5, 'a' + i);
            for (std::size_t i = 0; i < size; ++i)
                std::cout << "ptr[" << i << "] == " << ptr[i] << '\n';
            std::destroy_n(ptr, size);
        }
        catch (...) {}
        std::free(ptr);
    }
}

Output:

p[0] == aaaaa
p[1] == bbbbb
p[2] == ccccc
p[3] == ddddd
