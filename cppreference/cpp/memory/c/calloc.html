std::calloc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <cstdlib>

void* calloc( std::size_t num, std::size_t size );

Alloue de la mémoire pour un tableau de num objets de taille size, l'initialise avec tous les bits à zéro (crée implicitement des objets dans la zone de destination).

Si l'allocation réussit, renvoie un pointeur vers le premier octet (le plus bas) du bloc mémoire alloué, aligné convenablement pour tout type d'objet.

Si size vaut zéro, le comportement est défini par l'implémentation (un pointeur nul peut être renvoyé, ou un pointeur non nul pouvant ne pas être utilisé pour accéder au stockage).

Les fonctions suivantes doivent être thread-safe :

  • Les versions de la bibliothèque de operator new et de operator delete
  • Les versions de remplacement définies par l'utilisateur des operator new et operator delete globales
  • std::calloc, std::malloc, std::realloc, std::aligned_alloc (depuis C++17), std::free

Les appels à ces fonctions qui allouent ou libèrent une unité de stockage donnée se produisent selon un ordre total unique, et chaque appel de désallocation happens-before l'allocation suivante (le cas échéant) dans cet ordre.

(depuis C++11)

Paramètres

  • num — nombre d'objets
  • size — taille de chaque objet

Valeur de retour

En cas de succès, retourne le pointeur vers le début de la mémoire nouvellement allouée. Pour éviter une fuite mémoire, le pointeur retourné doit être libéré avec std::free() ou std::realloc().

En cas d'échec, retourne un pointeur nul.

Notes

En raison des exigences d'alignement, le nombre d'octets alloués n'est pas nécessairement égal à num * size.

L'initialisation à tous les bits à zéro ne garantit pas qu'un nombre à virgule flottante ou un pointeur soit initialisé respectivement à 0.0 et à la valeur de pointeur nul (bien que cela soit vrai sur toutes les plateformes courantes).

À l'origine (en C89), la prise en charge de la taille zéro a été ajoutée pour accueillir du code tel que

OBJ *p = calloc(0, sizeof(OBJ)); // placeholder de « longueur nulle »
...
while (1)
{
    p = realloc(p, c * sizeof(OBJ)); // réallocations jusqu'à ce que la taille se stabilise
    ... // code qui peut modifier c ou sortir de la boucle
}

Exemple

#include <cstdlib>
#include <iostream>

int main()
{
    int* p1 = (int*)std::calloc(4, sizeof(int)); // alloue et met à zéro un tableau de 4 int
    int* p2 = (int*)std::calloc(1, sizeof(int[4])); // idem, en nommant directement le type du tableau
    int* p3 = (int*)std::calloc(4, sizeof *p3); // identique, sans répéter le nom du type

    if (p2)
        for (int n = 0; n < 4; ++n) // afficher le tableau
            std::cout << "p2[" << n << "] == " << p2[n] << '\n';

    std::free(p1);
    std::free(p2);
    std::free(p3);
}

Output:

p2[0] == 0
p2[1] == 0
p2[2] == 0
p2[3] == 0
