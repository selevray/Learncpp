std::align

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

void* align( std::size_t alignment,
             std::size_t size,
             void*& ptr,
             std::size_t& space );  // (depuis C++11)

Étant donné un pointeur ptr vers un tampon de taille space, renvoie un pointeur aligné selon l'alignment spécifié pour size octets et diminue l'argument space du nombre d'octets utilisés pour l'alignement. La première adresse alignée est renvoyée.

La fonction ne modifie le pointeur que s'il est possible d'insérer dans le tampon le nombre d'octets voulu aligné selon l'alignement donné. Si le tampon est trop petit, la fonction ne fait rien et renvoie nullptr.

Le comportement est indéfini si alignment n'est pas une puissance de deux.

Paramètres

  • alignment — l'alignement souhaité
  • size — la taille du stockage à aligner
  • ptr — pointeur vers un stockage contigu (un tampon) d'au moins space octets
  • space — la taille du tampon dans lequel opérer

Valeur de retour

La valeur ajustée de ptr, ou la valeur de pointeur nul si l'espace fourni est trop petit.

Exemple

Démontre l'utilisation de std::align pour placer en mémoire des objets de types différents.

#include <iostream>
#include <memory>

template<std::size_t N>
struct MyAllocator
{
    char data[N];
    void* p;
    std::size_t sz;
    MyAllocator() : p(data), sz(N) {}
    template<typename T>
    T* aligned_alloc(std::size_t a = alignof(T))
    {
        if (std::align(a, sizeof(T), p, sz))
        {
            T* result = reinterpret_cast<T*>(p);
            p = (char*)p + sizeof(T);
            sz -= sizeof(T);
            return result;
        }
        return nullptr;
    }
};

int main()
{
    MyAllocator<64> a;
    std::cout << "allocated a.data at " << (void*)a.data
              << " (" << sizeof a.data << " bytes)\n";

    // allouer un char
    if (char* p = a.aligned_alloc<char>())
    {
        *p = 'a';
        std::cout << "allocated a char at " << (void*)p << '\n';
    }

    // allouer un int
    if (int* p = a.aligned_alloc<int>())
    {
        *p = 1;
        std::cout << "allocated an int at " << (void*)p << '\n';
    }

    // allouer un int, aligné sur une frontière de 32 octets
    if (int* p = a.aligned_alloc<int>(32))
    {
        *p = 2;
        std::cout << "allocated an int at " << (void*)p << " (32 byte alignment)\n";
    }
}

Sortie possible :

allocated a.data at 0x7ffd0b331f80 (64 bytes)
allocated a char at 0x7ffd0b331f80
allocated an int at 0x7ffd0b331f84
allocated an int at 0x7ffd0b331fa0 (32 byte alignment)

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 2377 C++11 alignment doit être une valeur d'alignement fondamentale ou un alignement étendu pris en charge doivent seulement être une puissance de deux

Voir aussi

  • alignof (C++11) — interroge les exigences d'alignement d'un type (opérateur)
  • alignas (C++11) — spécifie que le stockage de la variable doit être aligné sur une quantité spécifique (spécificateur)
  • aligned_storage (since C++11) (deprecated in C++23) — définit le type adapté à être utilisé comme stockage non initialisé pour des types de taille donnée (modèle de classe)
  • assume_aligned (C++20) — informe le compilateur qu'un pointeur est aligné (modèle de fonction)
