std::unique_ptr

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template<
    class T,
    class Deleter = std::default_delete<T>
> class unique_ptr;  // (1) (depuis C++11)

template <
    class T,
    class Deleter
> class unique_ptr<T[], Deleter>;  // (2) (depuis C++11)

std::unique_ptr est un pointeur intelligent qui possède (est responsable de) et gère un autre objet via un pointeur, puis détruit cet objet lorsque unique_ptr sort de sa portée.

L'objet est détruit à l'aide du déleteur associé lorsque l'un des événements suivants se produit :

  • l'objet unique_ptr gestionnaire est détruit.
  • l'objet unique_ptr gestionnaire se voit affecter un autre pointeur via operator= ou reset().

L'objet est détruit, à l'aide d'un déleteur potentiellement fourni par l'utilisateur, en appelant get_deleter()(ptr). Le déleteur par défaut (std::default_delete) utilise l'opérateur delete, qui détruit l'objet et libère la mémoire.

Un unique_ptr peut aussi ne posséder aucun objet, auquel cas il est décrit comme vide.

Il existe deux versions de std::unique_ptr :

  1. Gère un objet unique (par exemple alloué avec new).
  2. Gère un tableau d'objets alloué dynamiquement (par exemple alloué avec new[]).

La classe satisfait les exigences de MoveConstructible et de MoveAssignable, mais ni de CopyConstructible ni de CopyAssignable.

Exigences sur les types

  • Deleter doit être FunctionObject ou une référence lvalue vers un FunctionObject ou une référence lvalue vers une fonction, appelable avec un argument de type unique_ptr<T, Deleter>::pointer.

Notes

Seul un unique_ptr non const peut transférer la propriété de l'objet géré vers un autre unique_ptr. Si la durée de vie d'un objet est gérée par un const std::unique_ptr, elle est limitée à la portée dans laquelle le pointeur a été créé.

std::unique_ptr est couramment utilisé pour gérer la durée de vie des objets, notamment :

  • assurer la sécurité d'exception aux classes et fonctions qui manipulent des objets à durée de vie dynamique, en garantissant la destruction lors d'une sortie normale comme lors d'une sortie par exception.

  • transmettre la propriété d'objets à durée de vie dynamique et à propriétaire unique à des fonctions.

  • acquérir la propriété d'objets à durée de vie dynamique et à propriétaire unique à partir de fonctions.

  • comme type d'élément dans des conteneurs compatibles avec le déplacement, tels que std::vector, qui contiennent des pointeurs vers des objets alloués dynamiquement (par exemple si un comportement polymorphe est souhaité).

std::unique_ptr peut être construit pour un type incomplet T, par exemple pour faciliter son utilisation comme poignée dans l'idiome pImpl. Si le déleteur par défaut est utilisé, T doit être complet au point du code où le déleteur est invoqué, ce qui se produit dans le destructeur, dans l'opérateur d'affectation par déplacement et dans la fonction membre reset de std::unique_ptr. (En revanche, std::shared_ptr ne peut pas être construit à partir d'un pointeur brut vers un type incomplet, mais peut être détruit lorsque T est incomplet). Notez que si T est une spécialisation de modèle de classe, l'utilisation de unique_ptr comme opérande, par exemple !p, exige que les paramètres de T soient complets en raison de l'ADL.

Si T est une classe dérivée d'une certaine base B, alors std::unique_ptr<T> est implicitement convertible en std::unique_ptr<B>. Le déleteur par défaut du std::unique_ptr<B> résultant utilisera operator delete pour B, ce qui entraîne un comportement indéfini sauf si le destructeur de B est virtual. Notez que std::shared_ptr se comporte différemment : std::shared_ptr<B> utilisera le operator delete pour le type T, et l'objet possédé sera correctement détruit même si le destructeur de B n'est pas virtual.

Contrairement à std::shared_ptr, std::unique_ptr peut gérer un objet via tout type de poignée personnalisé qui satisfait NullablePointer. Cela permet, par exemple, de gérer des objets situés en mémoire partagée, en fournissant un Deleter qui définit typedef boost::offset_ptr pointer; ou un autre pointeur sophistiqué.

Types membres

Type membre Définition

  • pointer — std::remove_reference<Deleter>::type::pointer si ce type existe, sinon T*. Doit satisfaire NullablePointer
  • element_type — T, le type de l'objet géré par ce unique_ptr
  • deleter_type — Deleter, l'objet fonction ou la référence lvalue vers une fonction ou un objet fonction, à appeler depuis le destructeur

Fonctions membres

  • (constructeur) — construit un nouveau unique_ptr (fonction membre publique)
  • (destructeur) — détruit l'objet géré s'il existe (fonction membre publique)
  • operator= — affecte le unique_ptr (fonction membre publique)

##### Modificateurs {#Modifiers}

  • release — renvoie un pointeur vers l'objet géré et libère la propriété (fonction membre publique)
  • reset — remplace l'objet géré (fonction membre publique)
  • swap — échange les objets gérés (fonction membre publique)

##### Observateurs {#Observers}

  • get — renvoie un pointeur vers l'objet géré (fonction membre publique)
  • get_deleter — renvoie le deleter utilisé pour la destruction de l'objet géré (fonction membre publique)
  • operator bool — vérifie s'il existe un objet géré associé (fonction membre publique)

Exemple

#include <cassert>
#include <cstdio>
#include <fstream>
#include <iostream>
#include <locale>
#include <memory>
#include <stdexcept>

// classe auxiliaire pour la démonstration du polymorphisme à l'exécution ci-dessous
struct B
{
    virtual ~B() = default;

    virtual void bar() { std::cout << "B::bar\n"; }
};

struct D : B
{
    D() { std::cout << "D::D\n"; }
    ~D() { std::cout << "D::~D\n"; }

    void bar() override { std::cout << "D::bar\n"; }
};

// une fonction consommant un unique_ptr peut le prendre par valeur ou par référence rvalue
std::unique_ptr<D> pass_through(std::unique_ptr<D> p)
{
    p->bar();
    return p;
}

// fonction auxiliaire pour la démonstration du deleter personnalisé ci-dessous
void close_file(std::FILE* fp)
{
    std::fclose(fp);
}

// démonstration d'une liste chaînée basée sur unique_ptr
struct List
{
    struct Node
    {
        int data;
        std::unique_ptr<Node> next;
    };

    std::unique_ptr<Node> head;

    ~List()
    {
        // détruit les nœuds de la liste séquentiellement dans une boucle, le destructeur par défaut
        // appellerait récursivement le destructeur de son `next`, ce qui
        // provoquerait un débordement de pile pour des listes suffisamment grandes.
        while (head)
        {
            auto next = std::move(head->next);
            head = std::move(next);
        }
    }

    void push(int data)
    {
        head = std::unique_ptr<Node>(new Node{data, std::move(head)});
    }
};

int main()
{
    std::cout << "1) Unique ownership semantics demo\n";
    {
        // Crée une ressource (possédée de manière unique)
        std::unique_ptr<D> p = std::make_unique<D>();

        // Transfère la propriété à `pass_through`,
        // qui à son tour retransfère la propriété via la valeur de retour
        std::unique_ptr<D> q = pass_through(std::move(p));

        // p est maintenant dans un état « vide » après déplacement, égal à nullptr
        assert(!p);
    }

    std::cout << "\n" "2) Runtime polymorphism demo\n";
    {
        // Crée une ressource dérivée et pointe vers elle via le type de base
        std::unique_ptr<B> p = std::make_unique<D>();

        // La liaison dynamique fonctionne comme attendu
        p->bar();
    }

    std::cout << "\n" "3) Custom deleter demo\n";
    std::ofstream("demo.txt") << 'x'; // prépare le fichier à la lecture
    {
        using unique_file_t = std::unique_ptr<std::FILE, decltype(&close_file)>;
        unique_file_t fp(std::fopen("demo.txt", "r"), &close_file);
        if (fp)
            std::cout << char(std::fgetc(fp.get())) << '\n';
    } // `close_file()` est appelée ici (si `fp` n'est pas nul)

    std::cout << "\n" "4) Custom lambda-expression deleter and exception safety demo\n";
    try
    {
        std::unique_ptr<D, void(*)(D*)> p(new D, [](D* ptr)
        {
            std::cout << "destroying from a custom deleter...\n";
            delete ptr;
        });

        throw std::runtime_error(""); // `p` fuirait ici s'il s'agissait d'un pointeur ordinaire
    }
    catch (const std::exception&)
    {
        std::cout << "Caught exception\n";
    }

    std::cout << "\n" "5) Array form of unique_ptr demo\n";
    {
        std::unique_ptr<D[]> p(new D[3]);
    } // `D::~D()` est appelé 3 fois

    std::cout << "\n" "6) Linked list demo\n";
    {
        List wall;
        const int enough{1'000'000};
        for (int beer = 0; beer != enough; ++beer)
            wall.push(beer);

        std::cout.imbue(std::locale("en_US.UTF-8"));
        std::cout << enough << " bottles of beer on the wall...\n";
    } // détruit toutes les bières
}
