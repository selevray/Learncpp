std::swap(std::unique_ptr)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class T, class D >
void swap( std::unique_ptr<T, D>& lhs, std::unique_ptr<T, D>& rhs ) noexcept;  // (depuis C++11) (constexpr depuis C++23)

Spécialise l'algorithme std::swap pour std::unique_ptr. Échange le contenu de lhs et rhs. Appelle lhs.swap(rhs).

Cette fonction ne participe pas à la résolution de surcharge sauf si std::is_swappable_v<D> est true.

(depuis C++17)

Paramètres

  • lhs, rhs — pointeurs intelligents dont le contenu doit être échangé

Valeur de retour

(aucune)

Complexité

Constante.

Exemple

#include <iostream>
#include <memory>
#include <string>

struct Foo {
    Foo(int _val) : val(_val) { std::cout << "Foo...\n"; }
    ~Foo() { std::cout << "~Foo...\n"; }
    std::string print() { return std::to_string(val); }
    int val;
};

int main()
{
    std::unique_ptr<Foo> p1 = std::make_unique<Foo>(100);
    std::unique_ptr<Foo> p2 = std::make_unique<Foo>(200);
    auto print = [&]() {
        std::cout << " p1=" << (p1 ? p1->print() : "nullptr");
        std::cout << " p2=" << (p2 ? p2->print() : "nullptr") << '\n';
    };
    print();

    std::swap(p1, p2);
    print();

    p1.reset();
    print();

    std::swap(p1, p2);
    print();
}

Output:

Foo...
Foo...
 p1=100 p2=200
 p1=200 p2=100
~Foo...
 p1=nullptr p2=100
 p1=100 p2=nullptr
~Foo...
