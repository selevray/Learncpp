std::unique_ptr<T,Deleter>::swap

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void swap( unique_ptr& other ) noexcept;  // (depuis C++11)

Échange les objets gérés et les suppresseurs associés de *this et d'un autre objet unique_ptr other.

Paramètres

  • other — un autre objet unique_ptr avec lequel échanger l'objet géré et le suppresseur

Valeur de retour

(aucune)

Exemple

#include <iostream>
#include <memory>

struct Foo
{
    Foo(int _val) : val(_val) { std::cout << "Foo...\n"; }
    ~Foo() { std::cout << "~Foo...\n"; }
    int val;
};

int main()
{
    std::unique_ptr<Foo> up1(new Foo(1));
    std::unique_ptr<Foo> up2(new Foo(2));

    up1.swap(up2);

    std::cout << "up1->val:" << up1->val << '\n';
    std::cout << "up2->val:" << up2->val << '\n';
}

Output:

Foo...
Foo...
up1->val:2
up2->val:1
~Foo...
~Foo...
