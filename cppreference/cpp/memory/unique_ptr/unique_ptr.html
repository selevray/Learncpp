  1. Construit un std::unique_ptr ne possédant rien. Initialise par valeur le pointeur stocké et le suppresseur stocké. Exige que Deleter soit DefaultConstructible et que la construction ne lève pas d'exception. Ces surcharges ne participent à la résolution de surcharge que si std::is_default_constructible<Deleter>::value est true et que Deleter n'est pas un type pointeur.

  2. Construit un std::unique_ptr qui possède p, en initialisant le pointeur stocké avec p et en initialisant par valeur le suppresseur stocké. Exige que Deleter soit DefaultConstructible et que la construction ne lève pas d'exception. Cette surcharge ne participe à la résolution de surcharge que si std::is_default_constructible<Deleter>::value est true et que Deleter n'est pas un type pointeur.

Ce constructeur n'est pas sélectionné par la déduction d'arguments de modèle de classe.

(depuis C++17)

3,4) Construit un objet std::unique_ptr qui possède p, en initialisant le pointeur stocké avec p et en initialisant un suppresseur D comme indiqué ci-dessous (selon que D est un type référence ou non).

a) Si D est un type non référence A, alors les signatures sont :

unique_ptr(pointer p, const A& d) noexcept;  // (1) (exige que Deleter soit nothrow- CopyConstructible )

unique_ptr(pointer p, A&& d) noexcept;  // (2) (exige que Deleter soit nothrow- MoveConstructible )

b) Si D est un type référence lvalue A&, alors les signatures sont :

unique_ptr(pointer p, A& d) noexcept;  // (1)

unique_ptr(pointer p, A&& d) = delete;  // (2)

c) Si D est un type référence lvalue const A&, alors les signatures sont :

unique_ptr(pointer p, const A& d) noexcept;  // (1)

unique_ptr(pointer p, const A&& d) = delete;  // (2)

Dans tous les cas le suppresseur est initialisé à partir de std::forward<decltype(d)>(d). Ces surcharges ne participent à la résolution de surcharge que si std::is_constructible<D, decltype(d)>::value est true.

Ces deux constructeurs ne sont pas sélectionnés par la déduction d'arguments de modèle de classe.

(depuis C++17)

2-4) Dans la spécialisation pour les tableaux, se comportent comme les constructeurs prenant un paramètre pointeur du modèle primaire, sauf qu'ils ne participent en outre pas à la résolution de surcharge sauf si l'une des conditions suivantes est vraie :

  • U est le même type que pointer, ou
  • U est std::nullptr_t, ou
  • pointer est le même type que element_type* et U est un type pointeur V* tel que V(*)[] est implicitement convertible en element_type(*)[].

  1. Construit un unique_ptr en transférant la propriété de u vers *this et stocke le pointeur nul dans u. Ce constructeur ne participe à la résolution de surcharge que si std::is_move_constructible<Deleter>::value est true. Si Deleter n'est pas un type référence, exige qu'il soit nothrow-MoveConstructible (si Deleter est une référence, get_deleter() et u.get_deleter() après la construction par déplacement font référence à la même valeur).

  2. Construit un unique_ptr en transférant la propriété de u vers *this, où u est construit avec un suppresseur spécifié (E). Cela dépend de si E est un type référence, comme suit :

a) si E est un type référence, ce suppresseur est construit par copie à partir du suppresseur de u (exige que cette construction ne lève pas d'exception),

b) si E est un type non référence, ce suppresseur est construit par déplacement à partir du suppresseur de u (exige que cette construction ne lève pas d'exception).

Ce constructeur ne participe à la résolution de surcharge que si toutes les conditions suivantes sont vraies :

a) unique_ptr<U, E>::pointer est implicitement convertible en pointer,

b) U n'est pas un type tableau,

c) soit Deleter est un type référence et E est le même type que Deleter, soit Deleter n'est pas un type référence et E est implicitement convertible en Deleter.

  1. Dans la spécialisation pour les tableaux, se comporte comme dans le modèle primaire, sauf qu'il ne participera à la résolution de surcharge que si toutes les conditions suivantes sont vraies :
  • U est un type tableau,
  • pointer est le même type que element_type*,
  • unique_ptr<U,E>::pointer est le même type que unique_ptr<U,E>::element_type*,
  • unique_ptr<U,E>::element_type(*)[] est convertible en element_type(*)[],
  • soit Deleter est un type référence et E est le même type que Deleter, soit Deleter n'est pas un type référence et E est implicitement convertible en Deleter.

  1. Le constructeur de copie est explicitement supprimé.

  2. Construit un unique_ptr où le pointeur stocké est initialisé avec u.release() et le suppresseur stocké est initialisé par valeur. Ce constructeur ne participe à la résolution de surcharge que si U* est implicitement convertible en T* et Deleter est le même type que std::default_delete<T>.

Paramètres

  • p — un pointeur vers un objet à gérer
  • d1, d2 — un suppresseur à utiliser pour détruire l'objet
  • u — un autre pointeur intelligent dont acquérir la propriété

Notes

Au lieu d'utiliser la surcharge (2) avec new, il est souvent préférable d'utiliser std::make_unique<T>.

(depuis C++14)

std::unique_ptr<Derived> est implicitement convertible en std::unique_ptr<Base> via la surcharge (6) (car le pointeur géré et std::default_delete sont tous deux implicitement convertibles).

Comme le constructeur par défaut est constexpr, static unique_ptrs sont initialisés dans le cadre de l'initialisation statique non locale, avant que toute initialisation dynamique non locale ne commence. Cela permet d'utiliser un unique_ptr en toute sécurité dans le constructeur de n'importe quel objet statique.

Il n'existe aucune déduction d'arguments de modèle de classe à partir d'un type pointeur, car il est impossible de distinguer un pointeur obtenu à partir des formes tableau et non tableau de new.

(depuis C++17)

Exemple

#include <iostream>
#include <memory>

struct Foo // objet à gérer
{
    Foo() { std::cout << "Foo ctor\n"; }
    Foo(const Foo&) { std::cout << "Foo copy ctor\n"; }
    Foo(Foo&&) { std::cout << "Foo move ctor\n"; }
    ~Foo() { std::cout << "~Foo dtor\n"; }
};

struct D // deleter
{
    D() {};
    D(const D&) { std::cout << "D copy ctor\n"; }
    D(D&) { std::cout << "D non-const copy ctor\n"; }
    D(D&&) { std::cout << "D move ctor \n"; }
    void operator()(Foo* p) const
    {
        std::cout << "D is deleting a Foo\n";
        delete p;
    };
};

int main()
{
    std::cout << "Example constructor(1)...\n";
    std::unique_ptr<Foo> up1; // up1 est vide
    std::unique_ptr<Foo> up1b(nullptr); // up1b est vide

    std::cout << "Example constructor(2)...\n";
    {
        std::unique_ptr<Foo> up2(new Foo); //up2 possède désormais un Foo
    } // Foo supprimé

    std::cout << "Example constructor(3)...\n";
    D d;
    {   // le type du déleteur n'est pas une référence
        std::unique_ptr<Foo, D> up3(new Foo, d); // déleteur copié
    }
    {   // le type du déleteur est une référence
        std::unique_ptr<Foo, D&> up3b(new Foo, d); // up3b détient une référence vers d
    }

    std::cout << "Example constructor(4)...\n";
    {   // le déleteur n'est pas une référence
        std::unique_ptr<Foo, D> up4(new Foo, D()); // déleteur déplacé
    }

    std::cout << "Example constructor(5)...\n";
    {
        std::unique_ptr<Foo> up5a(new Foo);
        std::unique_ptr<Foo> up5b(std::move(up5a)); // transfert de propriété
    }

    std::cout << "Example constructor(6)...\n";
    {
        std::unique_ptr<Foo, D> up6a(new Foo, d); // D est copié
        std::unique_ptr<Foo, D> up6b(std::move(up6a)); // D est déplacé

        std::unique_ptr<Foo, D&> up6c(new Foo, d); // D est une référence
        std::unique_ptr<Foo, D> up6d(std::move(up6c)); // D est copié
    }

#if (__cplusplus < 201703L)
    std::cout << "Example constructor(7)...\n";
    {
        std::auto_ptr<Foo> up7a(new Foo);
        std::unique_ptr<Foo> up7b(std::move(up7a)); // transfert de propriété
    }
#endif

    std::cout << "Example array constructor...\n";
    {
        std::unique_ptr<Foo[]> up(new Foo[3]);
    } // trois objets Foo supprimés
}
