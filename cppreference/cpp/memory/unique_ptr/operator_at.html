std::unique_ptr<T,Deleter>::operator[]

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

T& operator[]( std::size_t i ) const;  // (depuis C++11) (constexpr depuis C++23)

operator[] donne accès aux éléments d'un tableau géré par un unique_ptr.

Le paramètre i doit être inférieur au nombre d'éléments du tableau ; sinon, le comportement est indéfini.

Cette fonction membre n'est fournie que pour les spécialisations pour types tableaux.

Paramètres

  • i — l'indice de l'élément à renvoyer

Valeur de retour

Renvoie l'élément à l'indice i, c.-à-d. get()[i].

Exemple

#include <iostream>
#include <memory>

int main()
{
    const int size = 10;
    std::unique_ptr<int[]> fact(new int[size]);

    for (int i = 0; i < size; ++i)
        fact[i] = (i == 0) ? 1 : i * fact[i - 1];

    for (int i = 0; i < size; ++i)
        std::cout << i << "! = " << fact[i] << '\n';
}

Output:

0! = 1
1! = 1
2! = 2
3! = 6
4! = 24
5! = 120
6! = 720
7! = 5040
8! = 40320
9! = 362880
