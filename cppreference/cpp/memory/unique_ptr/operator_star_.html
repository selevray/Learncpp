std::unique_ptr<T,Deleter>::operator*, std::unique_ptr<T,Deleter>::operator->

typename std::add_lvalue_reference<T>::type operator*() const
    noexcept(noexcept(*std::declval<pointer>()));  // (1) (depuis C++11) (constexpr depuis C++23)

pointer operator->() const noexcept;  // (2) (depuis C++11) (constexpr depuis C++23)

operator* et operator-> donnent accès à l'objet possédé par *this.

Le comportement est indéfini si get() == nullptr.

Ces fonctions membres ne sont fournies pour unique_ptr que pour les objets uniques, c'est-à-dire le modèle primaire.

Paramètres

(aucune)

Valeur de retour

  1. Renvoie l'objet possédé par *this, équivalent à *get().

  2. Renvoie un pointeur vers l'objet possédé par *this, c'est-à-dire get().

Exceptions

  1. Peut lever une exception si pointer possède un operator* qui lève une exception.

Notes

L'utilisation de std::add_lvalue_reference permet d'instancier std::unique_ptr<void> puisque void& n'est pas autorisé en C++ alors que std::add_lvalue_reference<void> produit void. Voir LWG673 pour plus de détails.

Exemple

#include <iostream>
#include <memory>

struct Foo
{
    void bar() { std::cout << "Foo::bar\n"; }
};

void f(const Foo&)
{
    std::cout << "f(const Foo&)\n";
}

int main()
{
    std::unique_ptr<Foo> ptr(new Foo);

    ptr->bar();
    f(*ptr);
}

Output:

Foo::bar
f(const Foo&)
