std::hash<std::unique_ptr>

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class T, class Deleter >
struct hash<std::unique_ptr<T, Deleter>>;  // (depuis C++11)

La spécialisation de modèle de std::hash pour std::unique_ptr<T, Deleter> permet aux utilisateurs d'obtenir les hachages d'objets de type std::unique_ptr<T, Deleter>.

La spécialisation std::hash<std::unique_ptr<T,D>> est activée (voir std::hash) si std::hash<typename std::unique_ptr<T,D>::pointer> est activé, et est désactivée sinon.

Lorsqu'elle est activée, pour un std::unique_ptr<T, D> p donné, cette spécialisation garantit que std::hash<std::unique_ptr<T, D>>()(p) == std::hash<typename std::unique_ptr<T, D>::pointer>()(p.get()).

Les fonctions membres de cette spécialisation ne sont pas garanties noexcept, car le pointeur peut être un pointeur sophistiqué et son hachage pourrait lever une exception.

Exemple

#include <functional>
#include <iostream>
#include <memory>

struct Foo
{
    Foo(int num) : nr(num) { std::cout << "Foo(" << nr << ")\n"; }

    ~Foo() { std::cout << "~Foo()\n"; }

    bool operator==(const Foo &other) const { return nr == other.nr; };

    int nr;
};

int main()
{
    std::cout << std::boolalpha << std::hex;

    Foo* foo = new Foo(5);
    std::unique_ptr<Foo> up(foo);
    std::cout << "hash(up):    " << std::hash<std::unique_ptr<Foo>>()(up) << '\n'
              << "hash(foo):   " << std::hash<Foo*>()(foo) << '\n'
              << "*up==*foo:   " << (*up == *foo) << "\n\n";

    std::unique_ptr<Foo> other = std::make_unique<Foo>(5);
    std::cout << "hash(up):    " << std::hash<std::unique_ptr<Foo>>()(up) << '\n'
              << "hash(other): " << std::hash<std::unique_ptr<Foo>>()(other) << '\n'
              << "*up==*other: " <<(*up == *other) << "\n\n";
}
