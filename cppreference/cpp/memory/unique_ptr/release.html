std::unique_ptr<T,Deleter>::release

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

pointer release() noexcept;  // (depuis C++11) (constexpr depuis C++23)

Libère la possession de l'objet géré, le cas échéant.

get() renvoie nullptr après l'appel.

L'appelant est responsable du nettoyage de l'objet (par exemple à l'aide de get_deleter()).

Paramètres

(aucune)

Valeur de retour

Pointeur vers l'objet géré, ou nullptr s'il n'y avait pas d'objet géré, c'est-à-dire la valeur qui aurait été renvoyée par get() avant l'appel.

Exemple

#include <cassert>
#include <iostream>
#include <memory>

struct Foo
{
    Foo() { std::cout << "Foo\n"; }
    ~Foo() { std::cout << "~Foo\n"; }
};

// La propriété de la ressource Foo est transférée lors de l'appel à cette fonction
void legacy_api(Foo* owning_foo)
{
    std::cout << __func__ << '\n';
    // [code hérité que plus personne ne comprend ni n'ose toucher]
    // [...]
    delete owning_foo;
}

int main()
{
    std::unique_ptr<Foo> managed_foo(new Foo);
    // [code qui pourrait renvoyer, lever une exception ou quelque chose de ce genre]
    // [...]
    legacy_api(managed_foo.release());

    assert(managed_foo == nullptr);
}

Output:

Foo
legacy_api
~Foo
