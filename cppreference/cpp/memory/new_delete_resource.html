std::pmr::new_delete_resource

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory_resource>

std::pmr::memory_resource* new_delete_resource() noexcept;  // (depuis C++17)

Renvoie un pointeur vers un memory_resource qui utilise la operator new globale et operator delete pour allouer de la mémoire.

Valeur de retour

Renvoie un pointeur p vers un objet à durée de stockage statique d'un type dérivé de std::pmr::memory_resource, avec les propriétés suivantes :

  • sa fonction allocate() utilise ::operator new pour allouer la mémoire ;
  • sa fonction deallocate() utilise ::operator delete pour désallouer la mémoire ;
  • pour tout memory_resource r, p->is_equal(r) renvoie &r == p.

La même valeur est renvoyée à chaque fois que cette fonction est appelée.
