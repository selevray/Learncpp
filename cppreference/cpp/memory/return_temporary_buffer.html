std::return_temporary_buffer

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class T >
void return_temporary_buffer( T* p );  // (obsolète en C++17) (supprimé en C++20)

Désalloue le stockage référencé par p.

Si p n'est pas une valeur de pointeur renvoyée par un appel précédent à std::get_temporary_buffer, ou a été invalidé par un appel intermédiaire à std::return_temporary_buffer, le comportement est indéfini.

Paramètres

  • p — le pointeur faisant référence au stockage à désallouer

Valeur de retour

(aucune)

Exceptions

Ne lève aucune exception.

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>
#include <memory>
#include <string>

int main()
{
    const std::string s[] = {"string", "1", "test", "..."};
    const auto p = std::get_temporary_buffer<std::string>(4);
    // exige que p.first soit passé à return_temporary_buffer
    // (attention aux points de sortie anticipée et aux exceptions), ou mieux, utiliser :
    std::unique_ptr<std::string, void(*)(std::string*)> on_exit(p.first,
    [](std::string* p)
    {
        std::cout << "returning temporary buffer...\n";
        std::return_temporary_buffer(p);
    });

    std::copy(s, s + p.second,
              std::raw_storage_iterator<std::string*, std::string>(p.first));
    // a le même effet que : std::uninitialized_copy(s, s + p.second, p.first);
    // exige que chaque chaîne de p soit détruite individuellement
    // (attention aux points de sortie anticipée et aux exceptions)

    std::copy(p.first, p.first + p.second,
              std::ostream_iterator<std::string>{std::cout, "\n"});

    std::for_each(p.first, p.first + p.second, [](std::string& e)
    {
        e.~basic_string<char>();
    }); // identique à : std::destroy(p.first, p.first + p.second);

    // libérer manuellement la mémoire si la technique de type unique_ptr n'est pas utilisée :
    // std::return_temporary_buffer(p.first);
}

Output:

string
1
test
...
returning temporary buffer...
