std::inout_ptr_t<Smart,Pointer,Args...>::inout_ptr_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

explicit inout_ptr_t( Smart &sp, Args... args );  // (1) (depuis C++23)

inout_ptr_t( const inout_ptr_t& ) = delete;  // (2) (depuis C++23)

  1. Crée un inout_ptr_t. Adapte sp comme si elle se liait au membre Smart&, capture chaque argument t dans args... comme si elle initialisait le membre correspondant de type T dans Args... avec std::forward<T>(t), puis initialise le Pointer stocké avec sp si Smart est un type pointeur, sinon, l'initialise avec sp.get(). sp.release() peut être appelée si Smart n'est pas un type pointeur, auquel cas elle ne sera pas rappelée dans le destructeur.

  2. Le constructeur de copie est explicitement supprimé. inout_ptr_t n'est ni copiable ni déplaçable.

Paramètres

  • sp — l'objet (typiquement un pointeur intelligent) à adapter
  • args... — les arguments utilisés pour la réinitialisation à capturer

Valeur de retour

(aucune)

Exceptions

Peut lever des exceptions définies par l'implémentation.

Notes

Si Smart n'est pas un type pointeur et que sp.release() n'est pas appelée par le constructeur, elle peut être appelée par le destructeur avant la réinitialisation de sp.

Chaque argument de args... est déplacé dans le inout_ptr_t créé s'il s'agit d'un type objet, ou transmis tel quel dans le inout_ptr_t créé s'il s'agit d'un type référence.

Le constructeur de inout_ptr_t peut lever des exceptions. Par exemple, lorsque sp est un pointeur intrusif avec un bloc de contrôle, l'allocation du nouveau bloc de contrôle peut être effectuée dans le constructeur plutôt que dans le destructeur.
