void destroy( pointer p );  // (1) (jusqu'à C++11)

template< class U >
void destroy( U* p );  // (2) (depuis C++11) (obsolète en C++17) (supprimé en C++20)

Appelle le destructeur de l'objet pointé par p.

  1. Appelle p->~T().

  2. Appelle p->~U().

Paramètres

  • p — pointeur vers l'objet qui va être détruit

(aucune)
