std::allocator<T>::construct

void construct( pointer p, const_reference val );  // (1) (jusqu'à C++11)

template< class U, class... Args >
void construct( U* p, Args&&... args );  // (2) (depuis C++11) (obsolète en C++17) (supprimé en C++20)

Construit un objet de type T dans le stockage non initialisé alloué pointé par p, en utilisant le placement new global.

  1. Appelle ::new((void*)p) T(val).

  2. Appelle ::new((void*)p) U(std::forward<Args>(args)...).

Paramètres

  • p — pointeur vers un stockage non initialisé alloué
  • val — la valeur à utiliser comme argument du constructeur de copie
  • args... — les arguments du constructeur à utiliser

Valeur de retour

(aucune)
