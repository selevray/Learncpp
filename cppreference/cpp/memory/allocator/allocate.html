std::allocator<T>::allocate

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

pointer allocate( size_type n, const void* hint = 0 );  // (jusqu'à C++17)

T* allocate( std::size_t n, const void* hint );  // (depuis C++17) (obsolète) (supprimé en C++20)

T* allocate( std::size_t n );  // (depuis C++17) (jusqu'à C++20)

constexpr T* allocate( std::size_t n );  // (depuis C++20)

Alloue n * sizeof(T) octets de stockage non initialisé en appelant ::operator new(std::size_t) ou ::operator new(std::size_t, std::align_val_t) (depuis C++17), mais le moment et la manière dont cette fonction est appelée sont non spécifiés. Le pointeur hint peut être utilisé pour fournir une localité de référence : l'allocateur, si l'implémentation le prend en charge, tentera d'allouer le nouveau bloc mémoire aussi près que possible de hint.

Ensuite, cette fonction crée un tableau de type T[n] dans le stockage et en démarre la durée de vie, mais ne démarre pas la durée de vie de ses éléments.

L'utilisation de cette fonction est mal formée si T est un type incomplet.

Pour utiliser cette fonction dans une expression constante, le stockage alloué doit être désalloué pendant l'évaluation de la même expression.

(depuis C++20)

Paramètres

  • n — le nombre d'objets pour lesquels allouer un stockage
  • hint — pointeur vers un emplacement mémoire voisin

Valeur de retour

Pointeur vers le premier élément d'un tableau de n objets de type T dont les éléments n'ont pas encore été construits.

Exceptions

Lève std::bad_array_new_length si std::numeric_limits<std::size_t>::max() / sizeof(T) < n.

(depuis C++11)

Lève std::bad_alloc si l'allocation échoue.

Notes

La formulation « moment et manière non spécifiés » permet de combiner ou d'éliminer des allocations sur le tas effectuées par les conteneurs de la bibliothèque standard, bien que ces optimisations soient interdites pour les appels directs à ::operator new. Par exemple, cela est implémenté par libc++ ([1] et [2]).

Après l'appel de allocate() et avant la construction des éléments, l'arithmétique des pointeurs de T* est bien définie dans le tableau alloué, mais le comportement est indéfini si des éléments sont accédés.

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.
