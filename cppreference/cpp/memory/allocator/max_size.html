std::allocator<T>::max_size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

size_type max_size() const throw();  // (jusqu'à C++11)

size_type max_size() const noexcept;  // (depuis C++11) (obsolète en C++17) (supprimé en C++20)

Renvoie la valeur maximale théoriquement possible de n, pour laquelle l'appel allocate(n, 0) pourrait réussir.

Dans la plupart des implémentations, cela renvoie std::numeric_limits<size_type>::max() / sizeof(value_type).

Paramètres

(aucune)

Valeur de retour

La taille d'allocation maximale prise en charge.
