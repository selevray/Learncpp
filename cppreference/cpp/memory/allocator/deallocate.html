std::allocator<T>::deallocate

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void deallocate( T* p, std::size_t n );  // (constexpr depuis C++20)

Désalloue le stockage référencé par le pointeur p, qui doit être un pointeur obtenu par un appel antérieur à allocate()ou allocate_at_least() (depuis C++23).

L'argument n doit être égal au premier argument de l'appel à allocate() qui a initialement produit p, ou se trouver dans l'intervalle [m,count] si p est obtenu d'un appel à allocate_at_least(m) qui a renvoyé {p, count} (depuis C++23) ; sinon, le comportement est indéfini.

Appelle ::operator delete(void*) ou ::operator delete(void*, std::align_val_t) (depuis C++17), mais le moment et la manière de l'appel sont non spécifiés.

Lors de l'évaluation d'une expression constante, cette fonction doit désallouer le stockage alloué pendant l'évaluation de la même expression.

(depuis C++20)

Paramètres

  • p — pointeur obtenu de allocate()ou allocate_at_least() (depuis C++23)
  • n — nombre d'objets précédemment passés à allocate(), ou nombre compris entre le nombre demandé et le nombre réellement alloué via allocate_at_least() (peut être égal à l'une ou l'autre borne) (depuis C++23)

Valeur de retour

(aucune)

Exemple

#include <algorithm>
#include <cstddef>
#include <iostream>
#include <memory>
#include <string>

class S
{
    inline static int n{1};
    int m{};
    void pre() const { std::cout << "#" << m << std::string(m, ' '); }
public:
    S(int x) : m{n++} { pre(); std::cout << "S::S(" << x << ");\n"; }
    ~S() { pre(); std::cout << "S::~S();\n"; }
    void id() const { pre(); std::cout << "S::id();\n"; }
};

int main()
{
    constexpr std::size_t n{4};
    std::allocator<S> allocator;
    try
    {
        S* s = allocator.allocate(n); // peut lever une exception
        for (std::size_t i{}; i != n; ++i)
        {
        //  allocator.construct(&s[i], i + 42); // supprimé en C++20
            std::construct_at(&s[i], i + 42);   // depuis C++20
        }
        std::for_each_n(s, n, [](const auto& e) { e.id(); });
        std::destroy_n(s, n);
        allocator.deallocate(s, n);
    }
    catch (std::bad_array_new_length const& ex) { std::cout << ex.what() << '\n'; }
    catch (std::bad_alloc const& ex) { std::cout << ex.what() << '\n'; }
}
