Compare deux allocateurs par défaut. Comme les allocateurs par défaut sont sans état, deux allocateurs par défaut sont toujours égaux.

  1. Renvoie true.

  2. Renvoie false.

L'opérateur != est synthétisé à partir de operator==.

(depuis C++20)

Paramètres

  • lhs, rhs — allocateurs par défaut à comparer

Valeur de retour

  1. true

  2. false
