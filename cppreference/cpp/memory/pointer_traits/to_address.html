std::pointer_traits<Ptr>::to_address

Défini dans l'en-tête <memory>

static element_type* to_address( pointer p ) noexcept;  // (depuis C++20) (membre optionnel d'une spécialisation définie par le programme)

Construit un pointeur brut qui référence le même objet que son argument de type pointeur ("pointeur sophistiqué").

Cette fonction, si définie, est l'inverse de pointer_to, et existe comme point de personnalisation à appeler par std::to_address.

Paramètres

  • p — pointeur sophistiqué / objet de type pointeur

Valeur de retour

Un pointeur brut de type element_type* qui référence le même emplacement mémoire que l'argument p.
