std::pointer_traits<Ptr>::pointer_to

static pointer
pointer_to( element_type& r );  // (1) (depuis C++11) (membre de la spécialisation pointer_traits<Ptr> )

static pointer
pointer_to( element_type& r ) noexcept;  // (depuis C++11) (jusqu'à C++20) (membre de la spécialisation pointer_traits<T*> )

static constexpr pointer
pointer_to( element_type& r ) noexcept;  // (depuis C++20) (membre de la spécialisation pointer_traits<T*> )

Construit un pointeur déréférençable ou un objet de type pointeur ("pointeur sophistiqué") vers son argument.

  1. La version de cette fonction dans le modèle non spécialisé std::pointer_traits appelle simplement Ptr::pointer_to(r), et si Ptr ne fournit pas de fonction membre statique pointer_to, l'instanciation de cette fonction est une erreur de compilation.

  2. La version de cette fonction dans la spécialisation de std::pointer_traits pour les types pointeurs renvoie std::addressof(r).

Paramètres

  • r — référence à un objet de type element_type&, sauf si element_type est void, auquel cas le type de r est non spécifié

Valeur de retour

Un pointeur déréférençable vers r, de type pointer_traits<>::pointer.

Exceptions

  1. Non spécifié (généralement identique à Ptr::pointer_to).

Notes

La version de la bibliothèque Boost.Intrusive de cette fonction renvoie pointer(std::addressof(r)) si Ptr::pointer_to n'existe pas.
