std::out_ptr

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class Pointer = void, class Smart, class... Args >
auto out_ptr( Smart& s, Args&&... args );  // (depuis C++23)

Renvoie un std::out_ptr_t avec des arguments de modèle déduits qui capture les arguments pour la réinitialisation par référence.

Le programme est mal formé si la construction de la valeur de retour (voir ci-dessous) est mal formée.

Paramètres

  • s — l'objet (typiquement un pointeur intelligent) à adapter
  • args... — les arguments à capturer pour la réinitialisation

Valeur de retour

std::out_ptr_t<Smart, P, Args&&>(s, std::forward<Args>(args)...), où P est

  • Pointer, si Pointer n'est pas identique à void. Sinon,
  • Smart::pointer, si elle est valide et désigne un type. Sinon,
  • Smart::element_type*, si Smart::element_type est valide et désigne un type. Sinon,
  • std::pointer_traits<Smart>::element_type*.

Notes

Les utilisateurs peuvent spécifier l'argument de modèle pour le paramètre de modèle Pointer, afin d'interopérer avec des fonctions étrangères qui prennent un Pointer*.

Comme tous les arguments de réinitialisation sont capturés par référence, le out_ptr_t renvoyé doit être un objet temporaire détruit à la fin de l'expression complète contenant l'appel à la fonction étrangère, afin d'éviter les références pendantes.

Exemple

Utilisez std::out_ptr pour adapter un pointeur intelligent pour sqlite3_open, qui attend un sqlite3** comme paramètre de sortie.

#include <memory>
#include <sqlite3.h>

int main()
{
    auto close_db = [](sqlite3* db) { sqlite3_close(db); };

    {
        // ouvrir une base de données en mémoire, et gérer sa durée de vie avec std::unique_ptr
        std::unique_ptr<sqlite3, decltype(close_db)> up;
        sqlite3_open(":memory:", std::out_ptr(up));

        sqlite3* db = up.get();
        // faire quelque chose avec db ...
    }
    {
        // identique à ci-dessus, mais utiliser un std::shared_ptr
        std::shared_ptr<sqlite3> sp;
        sqlite3_open(":memory:", std::out_ptr(sp, close_db));

        sqlite3* db = sp.get();
        // faire quelque chose avec db ...
    }
}
