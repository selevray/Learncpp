voidify

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class T >
void* voidify( T& obj ) noexcept;  // ( exposition uniquement* ) (constexpr depuis C++17)

Renvoie l'adresse de obj (implicitement convertie en void*).

Paramètres

  • obj — l'objet dont l'adresse sera prise

Valeur de retour

&obj

(jusqu'à C++11)

std::addressof(obj)

(depuis C++11)

Notes

Cette fonction, réservée à l'exposé, est introduite par P0896R4. Elle sert à décrire les effets des algorithmes de mémoire non initialisée qui construisent des objets dans des zones de mémoire non initialisées. Le pointeur résultat est utilisé comme placement-params d'une expression new de placement.

Initialement, la valeur de retour était const_cast<void*>(static_cast<const volatile void*>(std::addressof(obj))), ce qui violait la const-correction. Les conversions explicites ont été supprimées par la résolution de LWG issue 3870, et la seule conversion restante est la conversion implicite en void*.

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.
