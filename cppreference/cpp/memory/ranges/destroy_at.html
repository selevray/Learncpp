std::ranges::destroy_at

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

Signature d'appel

template< std::destructible T >
constexpr void destroy_at( T* p ) noexcept;  // (depuis C++20)

Si T n'est pas un type tableau, appelle le destructeur de l'objet pointé par p, comme par p->~T(). Sinon, détruit récursivement les éléments de *p dans l'ordre, comme en appelant std::destroy(std::begin(*p), std::end(*p)).

Les entités de type fonction décrites sur cette page sont des objets fonctions d'algorithme (appelés de manière informelle niebloids), c'est-à-dire :

  • Les listes d'arguments de modèle explicites ne peuvent pas être spécifiées lors de l'appel de l'un d'entre eux.
  • Aucun d'entre eux n'est visible par la recherche dépendante des arguments.
  • Lorsque l'un d'entre eux est trouvé par la recherche non qualifiée normale comme nom situé à gauche de l'opérateur d'appel de fonction, la recherche dépendante des arguments est inhibée.

Paramètres

  • p — un pointeur vers l'objet à détruire

Valeur de retour

(aucune)

Implémentation possible

struct destroy_at_fn
{
    template<std::destructible T>
    constexpr void operator()(T *p) const noexcept
    {
        if constexpr (std::is_array_v<T>)
            for (auto &elem : *p)
                operator()(std::addressof(elem));
        else
            p->~T();
    }
};

inline constexpr destroy_at_fn destroy_at{};

Notes

destroy_at déduit le type de l'objet à détruire et évite donc de l'écrire explicitement dans l'appel au destructeur.

Lorsque destroy_at est appelé lors de l'évaluation d'une expression constante e, l'argument p doit pointer vers un objet dont la durée de vie a commencé pendant l'évaluation de e.

Exemple

L'exemple suivant montre comment utiliser ranges::destroy_at pour détruire une séquence contiguë d'éléments.

#include <iostream>
#include <memory>
#include <new>

struct Tracer
{
    int value;
    ~Tracer() { std::cout << value << " destructed\n"; }
};

int main()
{
    alignas(Tracer) unsigned char buffer[sizeof(Tracer) * 8];

    for (int i = 0; i < 8; ++i)
        new(buffer + sizeof(Tracer) * i) Tracer{i}; //construire manuellement des objets

    auto ptr = std::launder(reinterpret_cast<Tracer*>(buffer));

    for (int i = 0; i < 8; ++i)
        std::ranges::destroy_at(ptr + i);
}

Output:

0 destructed
1 destructed
2 destructed
3 destructed
4 destructed
5 destructed
6 destructed
7 destructed
