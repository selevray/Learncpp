std::enable_shared_from_this

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class T >
class enable_shared_from_this;  // (depuis C++11)

std::enable_shared_from_this permet à un objet t actuellement géré par un std::shared_ptr nommé pt de générer en toute sécurité des instances supplémentaires de std::shared_ptr pt1, pt2 etc. qui partagent toutes la propriété de t avec pt.

Hériter publiquement de std::enable_shared_from_this<T> fournit au type T une fonction membre shared_from_this. Si un objet t de type T est géré par un std::shared_ptr<T> nommé pt, alors appeler T::shared_from_this renverra un nouveau std::shared_ptr<T> qui partage la propriété de t avec pt.

Membres de données

Membre Description

  • mutable std::weak_ptr<T> weak_this — l'objet suivant le bloc de contrôle du premier propriétaire partagé de *this (objet membre exposé uniquement)*

Fonctions membres

  • (constructeur) — construit un objet enable_shared_from_this (fonction membre protégée)
  • (destructeur) — détruit un objet enable_shared_from_this (fonction membre protégée)
  • operator= — renvoie une référence à *this (fonction membre protégée)
  • shared_from_this — renvoie un std::shared_ptr qui partage la propriété de *this (fonction membre publique)
  • weak_from_this (C++17) — renvoie un std::weak_ptr qui partage la propriété de *this (fonction membre publique)

Notes

Les constructeurs de std::shared_ptr détectent la présence d'une base enable_shared_from_this non ambiguë et accessible (c'est-à-dire que l'héritage public est obligatoire) et affectent le std::shared_ptr nouvellement créé à weak_this s'il n'est pas déjà possédé par un std::shared_ptr vivant. Construire un std::shared_ptr pour un objet déjà géré par un autre std::shared_ptr ne consultera pas weak_this et conduira donc à un comportement indéfini.

Il est permis d'appeler shared_from_this uniquement sur un objet déjà partagé, c'est-à-dire sur un objet géré par std::shared_ptr<T>. Sinon, std::bad_weak_ptr est levée (par le constructeur de std::shared_ptr à partir d'un weak_this construit par défaut ﻿).

enable_shared_from_this fournit l'alternative sûre à une expression comme std::shared_ptr<T>(this), qui risque de provoquer la destruction de this plus d'une fois par plusieurs propriétaires qui ignorent l'existence les uns des autres (voir l'exemple ci-dessous).

Exemple

#include <iostream>
#include <memory>

class Good : public std::enable_shared_from_this<Good>
{
public:
    std::shared_ptr<Good> getptr()
    {
        return shared_from_this();
    }
};

class Best : public std::enable_shared_from_this<Best>
{
    struct Private{ explicit Private() = default; };

public:
    // Le constructeur n'est utilisable que par cette classe
    Best(Private) {}

    // Tous les autres doivent utiliser cette fonction de fabrique
    // Ainsi, tous les objets Best seront contenus dans un shared_ptr
    static std::shared_ptr<Best> create()
    {
        return std::make_shared<Best>(Private());
    }

    std::shared_ptr<Best> getptr()
    {
        return shared_from_this();
    }
};

struct Bad
{
    std::shared_ptr<Bad> getptr()
    {
        return std::shared_ptr<Bad>(this);
    }
    ~Bad() { std::cout << "Bad::~Bad() called\n"; }
};

void testGood()
{
    // Bien : les deux shared_ptr partagent le même objet
    std::shared_ptr<Good> good0 = std::make_shared<Good>();
    std::shared_ptr<Good> good1 = good0->getptr();
    std::cout << "good1.use_count() = " << good1.use_count() << '\n';
}

void misuseGood()
{
    // Mal : shared_from_this est appelé sans qu'un std::shared_ptr ne possède l'appelant
    try
    {
        Good not_so_good;
        std::shared_ptr<Good> gp1 = not_so_good.getptr();
    }
    catch (std::bad_weak_ptr& e)
    {
        // comportement indéfini (jusqu'à C++17) et std::bad_weak_ptr levée (depuis C++17)
        std::cout << e.what() << '\n';
    }
}

void testBest()
{
    // Best : identique, mais impossible de l'allouer sur la pile :
    std::shared_ptr<Best> best0 = Best::create();
    std::shared_ptr<Best> best1 = best0->getptr();
    std::cout << "best1.use_count() = " << best1.use_count() << '\n';

    // Best stackBest; // <- Ne compilera pas car Best::Best() est privé.
}

void testBad()
{
    // Mauvais, chaque shared_ptr pense être le seul propriétaire de l'objet
    std::shared_ptr<Bad> bad0 = std::make_shared<Bad>();
    std::shared_ptr<Bad> bad1 = bad0->getptr();
    std::cout << "bad1.use_count() = " << bad1.use_count() << '\n';
} // UB : double suppression de Bad

int main()
{
    testGood();
    misuseGood();

    testBest();

    testBad();
}
