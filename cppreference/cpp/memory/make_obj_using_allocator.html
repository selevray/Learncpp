std::make_obj_using_allocator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class T, class Alloc, class... Args >
constexpr T make_obj_using_allocator( const Alloc& alloc, Args&&... args );  // (depuis C++20)

Crée un objet du type donné T au moyen d'une construction avec allocateur.

Équivalent à

return std::make_from_tuple<T>(
    std::uses_allocator_construction_args<T>(alloc, std::forward<Args>(args)...)
);

Paramètres

  • alloc — l'allocateur à utiliser
  • args — les arguments à passer au constructeur de T

Valeur de retour

L'objet nouvellement créé de type T.

Exceptions

Peut lever toute exception levée par le constructeur de T, notamment std::bad_alloc.
