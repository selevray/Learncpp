std::to_address

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class Ptr >
constexpr auto to_address( const Ptr& p ) noexcept;  // (1) (depuis C++20)

template< class T >
constexpr T* to_address( T* p ) noexcept;  // (2) (depuis C++20)

Obtient l'adresse représentée par p sans former de référence vers l'objet pointé par p.

  1. Surcharge pour pointeur élaboré : si l'expression std::pointer_traits<Ptr>::to_address(p) est bien formée, retourne le résultat de cette expression. Sinon, retourne std::to_address(p.operator->()).

  2. Surcharge pour pointeur brut : si T est un type fonction, le programme est mal formé. Sinon, retourne p sans modification.

Paramètres

  • p — pointeur élaboré ou brut

Valeur de retour

Pointeur brut qui représente la même adresse que p.

Implémentation possible

template<class T>
constexpr T* to_address(T* p) noexcept
{
    static_assert(!std::is_function_v<T>);
    return p;
}

template<class T>
constexpr auto to_address(const T& p) noexcept
{
    if constexpr (requires{ std::pointer_traits<T>::to_address(p); })
        return std::pointer_traits<T>::to_address(p);
    else
        return std::to_address(p.operator->());
}

Notes

std::to_address peut être utilisé même lorsque p ne référence pas un stockage dans lequel un objet a été construit, auquel cas std::addressof(*p) ne peut pas être utilisé car il n'existe aucun objet valide auquel le paramètre de std::addressof puisse se lier.

La surcharge pour pointeur élaboré de std::to_address inspecte la spécialisation std::pointer_traits<Ptr>. Si l'instanciation de cette spécialisation est elle-même mal formée (typiquement parce que element_type ne peut pas être défini), cela produit une erreur franche en dehors du contexte immédiat et rend le programme mal formé.

std::to_address peut en outre être utilisé sur des itérateurs qui satisfont std::contiguous_iterator.

Exemple

#include <memory>

template<class A>
auto allocator_new(A& a)
{
    auto p = a.allocate(1);
    try
    {
        std::allocator_traits<A>::construct(a, std::to_address(p));
    }
    catch (...)
    {
        a.deallocate(p, 1);
        throw;
    }
    return p;
}

template<class A>
void allocator_delete(A& a, typename std::allocator_traits<A>::pointer p)
{
    std::allocator_traits<A>::destroy(a, std::to_address(p));
    a.deallocate(p, 1);
}

int main()
{
    std::allocator<int> a;
    auto p = allocator_new(a);
    allocator_delete(a, p);
}
