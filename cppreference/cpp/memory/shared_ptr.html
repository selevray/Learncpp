std::shared_ptr

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class T > class shared_ptr;  // (depuis C++11)

std::shared_ptr est un pointeur intelligent qui conserve la propriété partagée d'un objet via un pointeur. Plusieurs objets shared_ptr peuvent posséder le même objet. L'objet est détruit et sa mémoire désallouée lorsque l'un des événements suivants se produit :

  • le dernier shared_ptr restant possédant l'objet est détruit ;
  • le dernier shared_ptr restant possédant l'objet se voit affecter un autre pointeur via operator= ou reset().

L'objet est détruit à l'aide d'une delete-expression ou d'un suppresseur personnalisé fourni à shared_ptr lors de la construction.

Un shared_ptr peut partager la propriété d'un objet tout en stockant un pointeur vers un autre objet. Cette fonctionnalité permet de pointer vers des objets membres tout en possédant l'objet auquel ils appartiennent. Le pointeur stocké est celui auquel accèdent get(), les opérateurs de déréférencement et de comparaison. Le pointeur géré est celui transmis au suppresseur lorsque le nombre d'utilisations atteint zéro.

Un shared_ptr peut aussi ne posséder aucun objet, auquel cas il est appelé vide (un shared_ptr vide peut avoir un pointeur stocké non nul si le constructeur d'alias a été utilisé pour le créer).

Toutes les spécialisations de shared_ptr satisfont les exigences de CopyConstructible, CopyAssignable et LessThanComparable et sont convertibles contextuellement en bool.

Toutes les fonctions membres (y compris le constructeur de copie et l'opérateur d'affectation par copie) peuvent être appelées par plusieurs threads sur des objets shared_ptr différents sans synchronisation supplémentaire, même si ces objets sont des copies et partagent la propriété du même objet. Si plusieurs threads d'exécution accèdent au même objet shared_ptr sans synchronisation et qu'un de ces accès utilise une fonction membre non const de shared_ptr, une course de données se produit ; la std::atomic<shared_ptr> peut être utilisée pour l'empêcher.

Notes

La propriété d'un objet ne peut être partagée avec un autre shared_ptr qu'en copiant sa valeur par construction ou par affectation vers un autre shared_ptr. Construire un nouveau shared_ptr à l'aide du pointeur brut sous-jacent possédé par un autre shared_ptr conduit à un comportement indéfini.

std::shared_ptr peut être utilisé avec un type incomplet T. Cependant, le constructeur à partir d'un pointeur brut (template<class Y> shared_ptr(Y*)) et la fonction membre template<class Y> void reset(Y*) ne peuvent être appelés qu'avec un pointeur vers un type complet (notez que std::unique_ptr peut être construit à partir d'un pointeur brut vers un type incomplet).

Le T dans std::shared_ptr<T> peut être un type fonction : dans ce cas il gère un pointeur de fonction plutôt qu'un pointeur d'objet. Cela est parfois utilisé pour garder une bibliothèque dynamique ou un plugin chargé tant qu'une de ses fonctions est référencée :

void del(void(*)()) {}

void fun() {}

int main()
{
    std::shared_ptr<void()> ee(fun, del);
    (*ee)();
}

Notes d'implémentation

Dans une implémentation typique, shared_ptr ne contient que deux pointeurs :

  • le pointeur stocké (celui renvoyé par get()) ;
  • un pointeur vers le bloc de contrôle.

Le bloc de contrôle est un objet alloué dynamiquement qui contient :

  • soit un pointeur vers l'objet géré, soit l'objet géré lui-même ;
  • le suppresseur (à type effacé) ;
  • l'allocateur (à type effacé) ;
  • le nombre de shared_ptr qui possèdent l'objet géré ;
  • le nombre de weak_ptr qui référencent l'objet géré.

Lorsqu'un shared_ptr est créé en appelant std::make_shared ou std::allocate_shared, la mémoire du bloc de contrôle et celle de l'objet géré sont créées par une seule allocation. L'objet géré est construit sur place dans un membre de données du bloc de contrôle. Lorsqu'un shared_ptr est créé via l'un des constructeurs shared_ptr, l'objet géré et le bloc de contrôle doivent être alloués séparément. Dans ce cas, le bloc de contrôle stocke un pointeur vers l'objet géré.

Le pointeur détenu directement par le shared_ptr est celui renvoyé par get(), tandis que le pointeur/objet détenu par le bloc de contrôle est celui qui sera supprimé lorsque le nombre de propriétaires partagés atteint zéro. Ces pointeurs ne sont pas nécessairement égaux.

Le destructeur de shared_ptr décrémente le nombre de propriétaires partagés du bloc de contrôle. Si ce compteur atteint zéro, le bloc de contrôle appelle le destructeur de l'objet géré. Le bloc de contrôle ne se désalloue pas tant que le compteur std::weak_ptr n'a pas lui aussi atteint zéro.

Dans les implémentations existantes, le nombre de pointeurs faibles est incrémenté ([1], [2]) s'il existe un pointeur partagé vers le même bloc de contrôle.

Pour satisfaire les exigences de sécurité des threads, les compteurs de références sont généralement incrémentés à l'aide d'un équivalent de std::atomic::fetch_add avec std::memory_order_relaxed (la décrémentation exige un ordre plus strict pour détruire le bloc de contrôle en toute sécurité).

Exemple

#include <chrono>
#include <iostream>
#include <memory>
#include <mutex>
#include <thread>

using namespace std::chrono_literals;

struct Base
{
    Base() { std::cout << "Base::Base()\n"; }

    // Remarque : un destructeur non virtuel convient ici
    ~Base() { std::cout << "Base::~Base()\n"; }
};

struct Derived : public Base
{
    Derived() { std::cout << "Derived::Derived()\n"; }

    ~Derived() { std::cout << "Derived::~Derived()\n"; }
};

void print(auto rem, std::shared_ptr<Base> const& sp)
{
    std::cout << rem << "\n\tget() = " << sp.get()
              << ", use_count() = " << sp.use_count() << '\n';
}

void thr(std::shared_ptr<Base> p)
{
    std::this_thread::sleep_for(987ms);
    std::shared_ptr<Base> lp = p; // sûr vis-à-vis des threads, bien que le
                                  // le use_count partagé est incrémenté
    {
        static std::mutex io_mutex;
        std::lock_guard<std::mutex> lk(io_mutex);
        print("Local pointer in a thread:", lp);
    }
}

int main()
{
    std::shared_ptr<Base> p = std::make_shared<Derived>();

    print("Created a shared Derived (as a pointer to Base)", p);

    std::thread t1{thr, p}, t2{thr, p}, t3{thr, p};
    p.reset(); // libère la propriété depuis main

    print("Shared ownership between 3 threads and released ownership from main:", p);

    t1.join();
    t2.join();
    t3.join();

    std::cout << "All threads completed, the last one deleted Derived.\n";
}

Exemple

#include <iostream>
#include <memory>

struct MyObj
{
    MyObj() { std::cout << "MyObj constructed\n"; }

    ~MyObj() { std::cout << "MyObj destructed\n"; }
};

struct Container : std::enable_shared_from_this<Container> // remarque : héritage public
{
    std::shared_ptr<MyObj> memberObj;

    void CreateMember() { memberObj = std::make_shared<MyObj>(); }

    std::shared_ptr<MyObj> GetAsMyObj()
    {
        // Utiliser un shared_ptr d'alias pour un membre
        return std::shared_ptr<MyObj>(shared_from_this(), memberObj.get());
    }
};

#define COUT(str) std::cout << '\n' << str << '\n'

#define DEMO(...) std::cout << #__VA_ARGS__ << " = " << __VA_ARGS__ << '\n'

int main()
{
    COUT("Creating shared container");
    std::shared_ptr<Container> cont = std::make_shared<Container>();
    DEMO(cont.use_count());
    DEMO(cont->memberObj.use_count());

    COUT("Creating member");
    cont->CreateMember();
    DEMO(cont.use_count());
    DEMO(cont->memberObj.use_count());

    COUT("Creating another shared container");
    std::shared_ptr<Container> cont2 = cont;
    DEMO(cont.use_count());
    DEMO(cont->memberObj.use_count());
    DEMO(cont2.use_count());
    DEMO(cont2->memberObj.use_count());

    COUT("GetAsMyObj");
    std::shared_ptr<MyObj> myobj1 = cont->GetAsMyObj();
    DEMO(myobj1.use_count());
    DEMO(cont.use_count());
    DEMO(cont->memberObj.use_count());
    DEMO(cont2.use_count());
    DEMO(cont2->memberObj.use_count());

    COUT("Copying alias obj");
    std::shared_ptr<MyObj> myobj2 = myobj1;
    DEMO(myobj1.use_count());
    DEMO(myobj2.use_count());
    DEMO(cont.use_count());
    DEMO(cont->memberObj.use_count());
    DEMO(cont2.use_count());
    DEMO(cont2->memberObj.use_count());

    COUT("Resetting cont2");
    cont2.reset();
    DEMO(myobj1.use_count());
    DEMO(myobj2.use_count());
    DEMO(cont.use_count());
    DEMO(cont->memberObj.use_count());

    COUT("Resetting myobj2");
    myobj2.reset();
    DEMO(myobj1.use_count());
    DEMO(cont.use_count());
    DEMO(cont->memberObj.use_count());

    COUT("Resetting cont");
    cont.reset();
    DEMO(myobj1.use_count());
    DEMO(cont.use_count());
}
