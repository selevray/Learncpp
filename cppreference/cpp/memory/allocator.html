std::allocator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class T >
struct allocator;  // (1)

template<>
struct allocator<void>;  // (2) (obsolète en C++17) (supprimé en C++20)

Le modèle de classe std::allocator est l'Allocator par défaut utilisé par tous les conteneurs de la bibliothèque standard si aucun allocateur défini par l'utilisateur n'est fourni. L'allocateur par défaut est sans état : toutes les instances de cet allocateur sont interchangeables, se comparent égales et peuvent désallouer la mémoire allouée par toute autre instance du même type d'allocateur.

La spécialisation explicite pour void ne possède pas les typedefs membres reference, const_reference, size_type et difference_type. Cette spécialisation ne déclare aucune fonction membre.

(jusqu'à C++20)

L'allocateur par défaut satisfait aux exigences de complétude de l'allocateur.

(depuis C++17)

Types membres

Type Définition

  • value_type — T
  • pointer (obsolète en C++17) (supprimé en C++20) — T*
  • const_pointer (obsolète en C++17) (supprimé en C++20) — const T*
  • reference (obsolète en C++17) (supprimé en C++20) — T&
  • const_reference (obsolète en C++17) (supprimé en C++20) — const T&
  • size_type — std::size_t
  • difference_type — std::ptrdiff_t
  • propagate_on_container_move_assignment (C++11) — std::true_type
  • rebind (obsolète en C++17) (supprimé en C++20) — template< class U > struct rebind { typedef allocator<U> other; };
  • is_always_equal (C++11) (obsolète en C++23) (supprimé en C++26) — std::true_type

Fonctions membres

  • (constructeur) — crée une nouvelle instance d'allocateur (fonction membre publique)
  • (destructeur) — détruit une instance d'allocateur (fonction membre publique)
  • address (until C++20) — obtient l'adresse d'un objet, même si operator& est surchargé (fonction membre publique)
  • allocate — alloue un stockage non initialisé (fonction membre publique)
  • allocate_at_least (C++23) — alloue un stockage non initialisé d'au moins la taille demandée (fonction membre publique)
  • deallocate — désalloue le stockage (fonction membre publique)
  • max_size (until C++20) — renvoie la plus grande taille d'allocation prise en charge (fonction membre publique)
  • construct (until C++20) — construit un objet dans le stockage alloué (fonction membre publique)
  • destroy (until C++20) — détruit un objet dans le stockage alloué (fonction membre publique)

Fonctions non membres

  • operator==operator!= (removed in C++20) — compare deux instances d'allocateur (fonction membre publique)

Notes

Le modèle de classe membre rebind fournit un moyen d'obtenir un allocateur pour un autre type. Par exemple, std::list<T, A> alloue des nœuds d'un type interne Node<T>, en utilisant l'allocateur [A::rebind<Node<T>>::other (jusqu'à C++11) | std::allocator_traits<A>::rebind_alloc<Node<T>>, qui est implémenté à l'aide de A::rebind<Node<T>>::other si A est un std::allocator (depuis C++11)].

Le type membre is_always_equal est obsolète en raison du problème LWG 3170, car il fait que les allocateurs personnalisés dérivés de std::allocator sont traités par défaut comme toujours égaux. std::allocator_traits<std::allocator<T>>::is_always_equal n'est pas obsolète et sa constante membre value vaut true pour tout T.

Exemple

#include <iostream>
#include <memory>
#include <string>

int main()
{
    // allocateur par défaut pour les int
    std::allocator<int> alloc1;

    // démonstration des rares membres directement utilisables
    static_assert(std::is_same_v<int, decltype(alloc1)::value_type>);
    int* p1 = alloc1.allocate(1); // espace pour un int
    alloc1.deallocate(p1, 1);     // et il a disparu

    // Ceux-ci peuvent toutefois être utilisés via les traits, donc inutile
    using traits_t1 = std::allocator_traits<decltype(alloc1)>; // Le trait correspondant
    p1 = traits_t1::allocate(alloc1, 1);
    traits_t1::construct(alloc1, p1, 7);  // construit l'int
    std::cout << *p1 << '\n';
    traits_t1::deallocate(alloc1, p1, 1); // désalloue l'espace pour un int

    // allocateur par défaut pour les chaînes
    std::allocator<std::string> alloc2;
    // traits correspondants
    using traits_t2 = std::allocator_traits<decltype(alloc2)>;

    // Le rebinding de l'allocateur via le trait pour les chaînes donne le même type
    traits_t2::rebind_alloc<std::string> alloc_ = alloc2;

    std::string* p2 = traits_t2::allocate(alloc2, 2); // espace pour 2 chaînes

    traits_t2::construct(alloc2, p2, "foo");
    traits_t2::construct(alloc2, p2 + 1, "bar");

    std::cout << p2[0] << ' ' << p2[1] << '\n';

    traits_t2::destroy(alloc2, p2 + 1);
    traits_t2::destroy(alloc2, p2);
    traits_t2::deallocate(alloc2, p2, 2);
}

Output:

7
foo bar
