std::owner_hash

struct owner_hash;  // (depuis C++26)

Cet objet fonction fournit un hachage basé sur le propriétaire (par opposition à basé sur la valeur) de std::weak_ptr et std::shared_ptr.

Équivalent à return key.owner_hash();.

Paramètres

  • key — pointeur à propriété partagée à hacher

Valeur de retour

Une valeur de hachage identique pour tout objet std::shared_ptr ou std::weak_ptr partageant la même propriété.
