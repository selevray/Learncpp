std::set_new_handler

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <new>

std::new_handler set_new_handler( std::new_handler new_p ) throw();  // (jusqu'à C++11)

std::new_handler set_new_handler( std::new_handler new_p ) noexcept;  // (depuis C++11)

Remplace new_p comme nouvelle fonction globale de gestion de new-handler et renvoie le new-handler précédemment installé.

La fonction new-handler est la fonction appelée par les fonctions d'allocation chaque fois qu'une tentative d'allocation de mémoire échoue. Son but prévu est l'un de trois :

  1. rendre plus de mémoire disponible,

  2. terminer le programme (par exemple en appelant std::terminate),

  3. lever une exception de type std::bad_alloc ou dérivée de std::bad_alloc.

L'implémentation par défaut lève std::bad_alloc. L'utilisateur peut installer son propre new-handler, qui peut offrir un comportement différent de celui par défaut.

Si new-handler retourne, la fonction d'allocation répète la tentative d'allocation précédemment échouée et rappelle le new-handler si l'allocation échoue de nouveau. Pour mettre fin à la boucle, new-handler peut appeler std::set_new_handler(nullptr) : si, après une tentative d'allocation échouée, la fonction d'allocation constate que std::get_new_handler renvoie une valeur de pointeur nul, elle lèvera std::bad_alloc.

Au démarrage du programme, new-handler est un pointeur nul.

Cette fonction est thread-safe. Chaque appel à std::set_new_handler se synchronise avec (voir std::memory_order) les appels ultérieurs à std::set_new_handler et std::get_new_handler.

(depuis C++11)

Paramètres

  • new_p — pointeur vers une fonction de type std::new_handler, ou pointeur nul

Valeur de retour

Le new-handler précédemment installé, ou une valeur de pointeur nul si aucun n'a été installé.

Exemple

#include <iostream>
#include <new>

void handler()
{
    std::cout << "Memory allocation failed, terminating\n";
    std::set_new_handler(nullptr);
}

int main()
{
    std::set_new_handler(handler);
    try
    {
        while (true)
        {
            new int[1000'000'000ul]();
        }
    }
    catch (const std::bad_alloc& e)
    {
        std::cout << e.what() << '\n';
    }
}
