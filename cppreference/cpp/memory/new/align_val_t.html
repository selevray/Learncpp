std::align_val_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <new>

enum class align_val_t : std::size_t {};  // (depuis C++17)

Les expressions new et expressions delete, lorsqu'elles sont utilisées avec des objets dont l'exigence d'alignement est supérieure à __STDCPP_DEFAULT_NEW_ALIGNMENT__, transmettent cette exigence d'alignement comme argument de type std::align_val_t à la fonction d'allocation ou de désallocation sélectionnée.

Notes

L'alignement (tel qu'obtenu par alignof) est de type std::size_t, mais les formes placement des fonctions d'allocation et de désallocation qui prennent std::size_t comme paramètre supplémentaire sont déjà utilisées, donc ce type est utilisé à la place.
