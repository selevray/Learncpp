std::nothrow

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <new>

struct nothrow_t {};  // (jusqu'à C++11)

struct nothrow_t { explicit nothrow_t() = default; };  // (depuis C++11)

extern const std::nothrow_t nothrow;  // (2)

std::nothrow_t est un type de classe vide utilisé pour lever l'ambiguïté entre les surcharges des fonctions d'allocation lançantes et non lançantes. std::nothrow en est une constante.

Exemple

#include <iostream>
#include <new>

int main()
{
    try
    {
        while (true)
        {
            new int[100000000ul];   // surcharge lançante
        }
    }
    catch (const std::bad_alloc& e)
    {
        std::cout << e.what() << '\n';
    }

    while (true)
    {
        int* p = new(std::nothrow) int[100000000ul]; // surcharge non lançante
        if (p == nullptr)
        {
            std::cout << "Allocation returned nullptr\n";
            break;
        }
    }
}

Output:

std::bad_alloc
Allocation returned nullptr
