std::get_new_handler

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <new>

std::new_handler get_new_handler() noexcept;  // (depuis C++11)

Renvoie le new-handler actuellement installé, qui peut être un pointeur nul.

Cette fonction est sûre vis-à-vis des threads. Un appel précédent à std::set_new_handler se synchronise avec (voir std::memory_order) les appels suivants à std::get_new_handler.

Paramètres

(aucune)

Valeur de retour

Le new-handler actuellement installé, qui peut être une valeur de pointeur nul.
