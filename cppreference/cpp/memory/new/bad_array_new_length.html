std::bad_array_new_length

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <new>

class bad_array_new_length;  // (depuis C++11)

std::bad_array_new_length est le type de l'objet lancé comme exception par les expressions new pour signaler des longueurs de tableau invalides si

  1. La longueur du tableau est négative,
  2. La taille totale du nouveau tableau dépasserait la valeur maximale définie par l'implémentation,
  3. Le nombre de clauses d'initialisation (initializer-clauses) dépasse le nombre d'éléments à initialiser.

Seule la première dimension du tableau peut lever cette exception ; les dimensions autres que la première sont des expressions constantes et sont vérifiées à la compilation.

std::bad_array_new_length::what

virtual const char* what() const noexcept;  // (depuis C++11) (constexpr depuis C++26)

Renvoie la chaîne explicative.

Valeur de retour

Pointeur vers une chaîne terminée par un caractère nul, définie par l'implémentation, contenant des informations explicatives. La chaîne convient à une conversion et à un affichage en tant que std::wstring. Le pointeur est garanti valide au moins jusqu'à la destruction de l'objet d'exception dont il est obtenu, ou jusqu'à l'appel d'une fonction membre non const (par ex. l'opérateur d'affectation par copie) sur cet objet d'exception.

La chaîne renvoyée est encodée avec le codage ordinaire des littéraux lors de l'évaluation constante.

(depuis C++26)

Exemple

Trois conditions dans lesquelles std::bad_array_new_length doit être lancée :

#include <climits>
#include <iostream>
#include <new>

int main()
{
    try
    {
        int negative = -1;
        new int[negative];
    }
    catch (const std::bad_array_new_length& e)
    {
        std::cout << "1) " << e.what() << ": negative size\n";
    }

    try
    {
        int small = 1;
        new int[small]{1,2,3};
    }
    catch (const std::bad_array_new_length& e)
    {
        std::cout << "2) " << e.what() << ": too many initializers\n";
    }

    try
    {
        long large = LONG_MAX;
        new int[large][1000];
    }
    catch (const std::bad_array_new_length& e)
    {
        std::cout << "3) " << e.what() << ": too large\n";
    }

    std::cout << "End\n";
}

Sortie possible :

1) std::bad_array_new_length: negative size
2) std::bad_array_new_length: too many initializers
3) std::bad_array_new_length: too large
End
