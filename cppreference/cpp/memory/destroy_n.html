std::destroy_n

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <memory>

template< class ForwardIt, class Size >
ForwardIt destroy_n( ForwardIt first, Size n );  // (depuis C++17) (jusqu'à C++20)

template< class ForwardIt, class Size >
constexpr ForwardIt destroy_n( ForwardIt first, Size n );  // (depuis C++20)

template< class ExecutionPolicy, class ForwardIt, class Size >
ForwardIt destroy_n( ExecutionPolicy&& policy, ForwardIt first, Size n );  // (2) (depuis C++17)
  1. Détruit les n objets de l'intervalle commençant à first, comme si par
for (; n > 0; (void) ++first, --n)
    std::destroy_at(std::addressof(*first));
  1. Identique à (1), mais exécuté selon policy. Cette surcharge ne participe à la résolution de surcharge que si toutes les conditions suivantes sont satisfaites :

std::is_execution_policy_v<std::decay_t<ExecutionPolicy>> is true.

(jusqu'à C++20)

std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>> is true.

(depuis C++20)

Paramètres

  • first — le début de l'intervalle d'éléments à détruire
  • n — le nombre d'éléments à détruire
  • policy — la politique d'exécution à utiliser

Exigences sur les types

  • ForwardIt doit satisfaire aux exigences de LegacyForwardIterator.
  • Aucun incrément, affectation, comparaison ou déréférencement via des instances valides de ForwardIt ne peut lever d'exception.

Valeur de retour

La fin de l'intervalle d'objets qui ont été détruits (c'est-à-dire std::next(first, n)).

Complexité

Linéaire en n.

Exceptions

La surcharge avec un paramètre de modèle nommé ExecutionPolicy signale les erreurs comme suit :

  • Si l'exécution d'une fonction invoquée dans le cadre de l'algorithme lève une exception et ExecutionPolicy est l'une des politiques standard, std::terminate est appelée. Pour toute autre ExecutionPolicy, le comportement est défini par l'implémentation.
  • Si l'algorithme échoue à allouer de la mémoire, std::bad_alloc est levée.

Implémentation possible

template<class ForwardIt, class Size>
constexpr // depuis C++20
ForwardIt destroy_n(ForwardIt first, Size n)
{
    for (; n > 0; (void) ++first, --n)
        std::destroy_at(std::addressof(*first));
    return first;
}

Exemple

L'exemple suivant montre comment utiliser destroy_n pour détruire une séquence contiguë d'éléments.

#include <iostream>
#include <memory>
#include <new>

struct Tracer
{
    int value;
    ~Tracer() { std::cout << value << " destructed\n"; }
};

int main()
{
    alignas(Tracer) unsigned char buffer[sizeof(Tracer) * 8];

    for (int i = 0; i < 8; ++i)
        new(buffer + sizeof(Tracer) * i) Tracer{i}; //construire manuellement des objets

    auto ptr = std::launder(reinterpret_cast<Tracer*>(buffer));

    std::destroy_n(ptr, 8);
}

Output:

0 destructed
1 destructed
2 destructed
3 destructed
4 destructed
5 destructed
6 destructed
7 destructed
