Lit atomiquement la valeur de *object et retourne cette valeur.

1,2) L'ordre de synchronisation mémoire est std::memory_order_seq_cst.

3,4) L'ordre de synchronisation mémoire est order.

Si order est l'un de std::memory_order::release et std::memory_order::acq_rel, le comportement est indéfini.

Paramètres

  • object — pointeur vers l'objet atomic_flag à lire
  • order — l'ordre de synchronisation mémoire

Valeur de retour

La valeur lue atomiquement.
