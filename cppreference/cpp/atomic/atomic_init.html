std::atomic_init

template< class T >
void atomic_init
    ( std::atomic<T>* obj,
      typename std::atomic<T>::value_type desired ) noexcept;  // (1) (depuis C++11) (obsolète en C++20)

template< class T >
void atomic_init
    ( volatile std::atomic<T>* obj,
      typename std::atomic<T>::value_type desired ) noexcept;  // (2) (depuis C++11) (obsolète en C++20)

Initialise l'objet atomique obj construit par défaut avec la valeur desired. La fonction n'est pas atomique : un accès concurrent depuis un autre thread, même via une opération atomique, constitue une course aux données.

Si obj n'a pas été construit par défaut, ou si cette fonction est appelée deux fois sur le même obj, le comportement est indéfini.

Paramètres

  • obj — pointeur vers un objet atomique à initialiser
  • desired — la valeur avec laquelle initialiser l'objet atomique

Valeur de retour

(aucune)

Notes

Cette fonction est fournie pour la compatibilité avec C. Si la compatibilité n'est pas requise, std::atomic peut être initialisé par leurs constructeurs non par défaut.
