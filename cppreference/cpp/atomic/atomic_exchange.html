std::atomic_exchange, std::atomic_exchange_explicit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <atomic>

template< class T >
T atomic_exchange( std::atomic<T>* obj,
                   typename std::atomic<T>::value_type desired ) noexcept;  // (1) (depuis C++11)

template< class T >
T atomic_exchange( volatile std::atomic<T>* obj,
                   typename std::atomic<T>::value_type desired ) noexcept;  // (2) (depuis C++11)

template< class T >
T atomic_exchange_explicit( std::atomic<T>* obj,
                            typename std::atomic<T>::value_type desired,
                            std::memory_order order ) noexcept;  // (3) (depuis C++11)

template< class T >
T atomic_exchange_explicit( volatile std::atomic<T>* obj,
                            typename std::atomic<T>::value_type desired,
                            std::memory_order order ) noexcept;  // (4) (depuis C++11)

1,2) Remplace atomiquement la valeur pointée par obj par la valeur de desired et retourne la valeur obj détenue précédemment, comme si par obj->exchange(desired).

3,4) Remplace atomiquement la valeur pointée par obj par la valeur de desired et retourne la valeur obj détenue précédemment, comme si par obj->exchange(desired, order).

Paramètres

  • obj — pointeur vers l'objet atomique à modifier
  • desired — la valeur à stocker dans l'objet atomique
  • order — l'ordre de synchronisation mémoire

Valeur de retour

La valeur détenue précédemment par l'objet atomique pointé par obj.

Exemple

Un mutex spinlock peut être implémenté en espace utilisateur à l'aide d'une opération d'échange atomique, similaire à std::atomic_flag_test_and_set :

#include <atomic>
#include <iostream>
#include <thread>
#include <vector>

std::atomic<bool> lock(false); // vaut true lorsqu'il est verrouillé
                               // vaut false lorsqu'il est déverrouillé

int new_line{1}; // l'accès est synchronisé via une variable de verrou atomique

void f(int n)
{
    for (int cnt = 0; cnt < 100; ++cnt)
    {
        while (std::atomic_exchange_explicit(&lock, true, std::memory_order_acquire))
            ; // attente active jusqu'à acquisition
        std::cout << n << (new_line++ % 80 ? "" : "\n");
        std::atomic_store_explicit(&lock, false, std::memory_order_release);
    }
}

int main()
{
    std::vector<std::thread> v;
    for (int n = 0; n < 8; ++n)
        v.emplace_back(f, n);
    for (auto& t : v)
        t.join();
}
