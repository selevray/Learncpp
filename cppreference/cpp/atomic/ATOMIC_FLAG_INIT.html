ATOMIC_FLAG_INIT

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <atomic>

#define ATOMIC_FLAG_INIT /* implementation-defined */  // (depuis C++11)

Définit l'initialiseur utilisable pour initialiser std::atomic_flag à l'état effacé (false) sous la forme std::atomic_flag v = ATOMIC_FLAG_INIT;. Il n'est pas spécifié s'il peut être utilisé avec d'autres contextes d'initialisation.

Si le drapeau est un objet complet ayant une durée de stockage statique, cette initialisation est statique.

C'est la seule façon d'initialiser std::atomic_flag à une valeur définie : la valeur conservée après toute autre initialisation est non spécifiée.

(jusqu'à C++20)

Cette macro n'est plus nécessaire, car le constructeur par défaut de std::atomic_flag l'initialise à l'état effacé. Elle est conservée pour la compatibilité avec C.

(depuis C++20)

Exemple

#include <atomic>

std::atomic_flag static_flag = ATOMIC_FLAG_INIT; // initialisation statique,
// garantie d'être disponible pendant l'initialisation dynamique d'objets statiques.

int main()
{
    std::atomic_flag automatic_flag = ATOMIC_FLAG_INIT; // garanti de fonctionner
//    std::atomic_flag another_flag(ATOMIC_FLAG_INIT); // non spécifié
}
