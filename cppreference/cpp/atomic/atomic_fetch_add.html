std::atomic_fetch_add, std::atomic_fetch_add_explicit

template< class T >
T atomic_fetch_add( std::atomic<T>* obj,
                    typename std::atomic<T>::difference_type arg ) noexcept;  // (1) (depuis C++11)

template< class T >
T atomic_fetch_add( volatile std::atomic<T>* obj,

template< class T >
T atomic_fetch_add_explicit( std::atomic<T>* obj,
                             typename std::atomic<T>::difference_type arg,
                             std::memory_order order ) noexcept;  // (3) (depuis C++11)

template< class T >
T atomic_fetch_add_explicit( volatile std::atomic<T>* obj,
                             typename std::atomic<T>::difference_type arg,
                             std::memory_order order ) noexcept;  // (4) (depuis C++11)

Effectue une addition atomique. Ajoute atomiquement arg à la valeur pointée par obj et retourne la valeur obj détenue précédemment. L'opération est effectuée comme si la suite suivante était exécutée :

1,2) obj->fetch_add(arg)

3,4) obj->fetch_add(arg, order)

Si std::atomic<T> n'a pas de membre fetch_add (ce membre n'est fourni que pour les types entiers, à virgule flottante (depuis C++20) et pointeurs à l'exception de bool), le programme est mal formé.

Paramètres

  • obj — pointeur vers l'objet atomique à modifier
  • arg — la valeur à ajouter à la valeur stockée dans l'objet atomique
  • order — l'ordre de synchronisation mémoire

Valeur de retour

La valeur immédiatement antérieure aux effets de cette fonction dans l'ordre de modification de *obj.

Exemple

Un verrou à écrivain unique et lecteurs multiples peut être réalisé avec std::atomic_fetch_add. Notez que cette implémentation simpliste n'est pas exempte de blocage (lockout-free).

#include <atomic>
#include <chrono>
#include <iostream>
#include <string>
#include <thread>
#include <vector>

using namespace std::chrono_literals;

// signification de cnt :
//  5 : lecteurs et écrivain sont en concurrence. Il n'y a aucun lecteur ou écrivain actif.
//  4...0 : il y a 1...5 lecteurs actifs, l'écrivain est bloqué.
// -1 : l'écrivain a gagné la course et les lecteurs sont bloqués.

const int N = 5; // quatre lecteurs concurrents sont autorisés
std::atomic<int> cnt(N);

std::vector<int> data;

void reader(int id)
{
    for (;;)
    {
        // lock
        while (std::atomic_fetch_sub(&cnt, 1) <= 0)
            std::atomic_fetch_add(&cnt, 1);

        // read
        if (!data.empty())
            std::cout << ("reader " + std::to_string(id) +
                          " sees " + std::to_string(*data.rbegin()) + '\n');
        if (data.size() == 25)
            break;

        // unlock
        std::atomic_fetch_add(&cnt, 1);

        // pause
        std::this_thread::sleep_for(1ms);
    }
}

void writer()
{
    for (int n = 0; n < 25; ++n)
    {
        // lock
        while (std::atomic_fetch_sub(&cnt, N + 1) != N)
            std::atomic_fetch_add(&cnt, N + 1);

        // write
        data.push_back(n);
        std::cout << "writer pushed back " << n << '\n';

        // unlock
        std::atomic_fetch_add(&cnt, N + 1);

        // pause
        std::this_thread::sleep_for(1ms);
    }
}

int main()
{
    std::vector<std::thread> v;
    for (int n = 0; n < N; ++n)
        v.emplace_back(reader, n);
    v.emplace_back(writer);

    for (auto& t : v)
        t.join();
}

Output:

writer pushed back 0
reader 2 sees 0
reader 3 sees 0
reader 1 sees 0
<...>
reader 2 sees 24
reader 4 sees 24
reader 1 sees 24
