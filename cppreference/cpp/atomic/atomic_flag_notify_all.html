void atomic_flag_notify_all( std::atomic_flag* object ) noexcept;  // (1) (depuis C++20)

void atomic_flag_notify_all( volatile std::atomic_flag* object ) noexcept;  // (2) (depuis C++20)

Effectue des opérations de notification atomiques.

Débloque tous les threads bloqués dans des opérations d'attente atomiques (c'est-à-dire std::atomic_flag_wait(), std::atomic_flag_wait_explicit(), ou std::atomic_flag::wait()) sur *object, s'il y en a ; sinon ne fait rien.

Équivalent à object->notify_all().

Paramètres

  • object — pointeur vers l'objet atomic_flag à notifier

Valeur de retour

(aucune)

Notes

Cette forme de détection de changement est souvent plus efficace qu'un simple polling ou que des spinlocks purs.
