ATOMIC_VAR_INIT

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <atomic>

#define ATOMIC_VAR_INIT(value) /* implementation-defined */  // (depuis C++11) (obsolète en C++20)

Se développe en une expression pouvant servir à initialiser un objet std::atomic pouvant être initialisé à partir de value. Si l'objet atomique a une durée de stockage statique, cette initialisation est une initialisation constante.

Notes

Accéder à la variable pendant son initialisation depuis un autre thread, même via une opération atomique, constitue une course de données (cela peut se produire si l'adresse est immédiatement transmise à un autre thread avec une opération std::memory_order_relaxed)

Cette macro est principalement fournie pour la compatibilité avec C ; elle se comporte de la même manière que le constructeur de std::atomic.

Exemple

#include <atomic>
#include <iostream>

int main()
{
    std::atomic<int> a = ATOMIC_VAR_INIT(1);
    // std::atomic<int> a(1);   // alternative propre à C++
    std::cout << "Initialized std::atomic<int> as: " << a << '\n';
}

Output:

Initialized std::atomic<int> as: 1
