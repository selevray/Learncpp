std::kill_dependency

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <atomic>

template< class T >
T kill_dependency( T y ) noexcept;  // (depuis C++11)

Indique au compilateur que l'arbre de dépendances initié par une opération de chargement atomique std::memory_order_consume ne s'étend pas au-delà de la valeur de retour de std::kill_dependency ; autrement dit, l'argument ne transporte pas de dépendance vers la valeur de retour.

Ceci peut servir à éviter des barrières std::memory_order_acquire inutiles lorsque la chaîne de dépendances quitte la portée de la fonction (et que la fonction n'a pas l'attribut [[carries_dependency]]).

Paramètres

  • y — l'expression dont la valeur de retour doit être retirée d'un arbre de dépendances

Valeur de retour

Retourne y, qui ne fait plus partie d'un arbre de dépendances.

Exemples

file1.cpp:

struct Foo
{
    int* a;
    int* b;
};

std::atomic<Foo*> foo_head[10];
int foo_array[10][10];

// l'opération consume démarre une chaîne de dépendances qui s'échappe de cette fonction
[[carries_dependency]] Foo* f(int i)
{
    return foo_head[i].load(memory_order_consume);
}

// la chaîne de dépendances entre dans cette fonction par le paramètre de droite et est
// interrompue avant la fin de la fonction (donc aucune opération acquire supplémentaire n'a lieu)
int g(int* x, int* y [[carries_dependency]])
{
    return std::kill_dependency(foo_array[*x][*y]);
}

file2.cpp:

[[carries_dependency]] struct Foo* f(int i);
int g(int* x, int* y [[carries_dependency]]);

int c = 3;
void h(int i)
{
    Foo* p;
    p = f(i); // la chaîne de dépendances démarrée dans f se poursuit dans p sans acquire inutile
    do_something_with(g(&c, p->a)); // p->b n'est pas chargé depuis le cache
    do_something_with(g(p->a, &c)); // l'argument de gauche n'a pas l'attribut carries_dependency
                                    // attribut : une barrière acquire mémoire peut être émise
                                    // p->b devient visible avant l'appel à g()
}
