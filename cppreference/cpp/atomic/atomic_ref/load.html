std::atomic_ref<T>::load

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

value_type load( std::memory_order order =
                     std::memory_order_seq_cst ) const noexcept;  // (constexpr depuis C++26)

Charge et renvoie atomiquement la valeur courante de l'objet référencé. La mémoire est affectée selon la valeur de order.

Si order n'est aucun de std::memory_order_relaxed, std::memory_order_consume, std::memory_order_acquire ou std::memory_order_seq_cst, le comportement est indéfini.

Paramètres

  • order — contraintes d'ordre mémoire à appliquer

Valeur de retour

La valeur courante de l'objet référencé.
