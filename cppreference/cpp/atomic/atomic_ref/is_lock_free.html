bool is_lock_free() const noexcept;  // (depuis C++20)

Vérifie si les opérations atomiques sur cet objet sont sans verrou.

Paramètres

(aucune)

Valeur de retour

true si les opérations atomiques sur cet objet sont sans verrou, false sinon.

Notes

Tous les types atomiques, à l'exception de std::atomic_flag, peuvent être implémentés à l'aide de mutex ou d'autres opérations de verrouillage, plutôt que d'instructions atomiques sans verrou du processeur. Les types atomiques peuvent aussi être parfois sans verrou, par exemple si seuls les accès mémoire alignés sont naturellement atomiques sur une architecture donnée ; les objets non alignés de ce même type doivent alors utiliser des verrous.

La norme C++ recommande (sans l'imposer) que les opérations atomiques sans verrou soient aussi indépendantes de l'adresse, c'est-à-dire utilisables pour la communication entre processus via une mémoire partagée.
