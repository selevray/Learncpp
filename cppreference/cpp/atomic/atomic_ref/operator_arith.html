std::atomic_ref<T>::operator++,++(int),--,--(int)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Fourni uniquement lorsque T est un type entier autre que cv bool ou un type pointeur vers objet

value_type operator++() const noexcept;  // (1) (depuis C++20)

value_type operator++( int ) const noexcept;  // (2) (depuis C++20)

value_type operator--() const noexcept;  // (3) (depuis C++20)

value_type operator--( int ) const noexcept;  // (4) (depuis C++20)

Incrémente ou décrémente de manière atomique la valeur courante de l'objet référencé. Ces opérations sont des opérations de lecture-modification-écriture.

  1. Effectue une pré-incrémentation atomique. Équivalent à return fetch_add(1) + 1;.

  2. Effectue une post-incrémentation atomique. Équivalent à return fetch_add(1);.

  3. Effectue une pré-décrémentation atomique. Équivalent à return fetch_sub(1) - 1;

  4. Effectue une post-décrémentation atomique. Équivalent à return fetch_sub(1);.

  • Pour les types entiers signés, l'arithmétique est définie en utilisant la représentation en complément à deux. Il n'existe aucun résultat indéfini.
  • Pour les types pointeur vers objet, le résultat peut être une adresse indéfinie, mais les opérations n'ont par ailleurs aucun comportement indéfini. Le programme est mal formé si std::remove_pointer_t<T> n'est pas un type objet complet.

Ces surcharges ne participent à la résolution de surcharge que si std::is_const_v<T> est false.

Valeur de retour

1,3) La valeur de l'objet référencé après la modification.

2,4) La valeur de l'objet référencé avant la modification.

Notes

Contrairement à la plupart des opérateurs de pré-incrémentation et de pré-décrémentation, les opérateurs de pré-incrémentation et de pré-décrémentation pour atomic_ref ne renvoient pas de référence vers l'objet modifié. Ils renvoient à la place une copie de la valeur stockée.

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.
