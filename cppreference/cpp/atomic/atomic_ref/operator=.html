value_type operator=( value_type desired ) const noexcept;  // (1) (constexpr depuis C++26)

atomic_ref& operator=( const atomic_ref& ) = delete;  // (2)

  1. Équivalent à store(desired); return desired;. Cette surcharge ne participe à la résolution de surcharge que si std::is_const_v<T> est false.

  2. atomic_ref n'est pas CopyAssignable.

Notes

Contrairement à la plupart des opérateurs d'affectation, l'opérateur d'affectation pour atomic_ref ne renvoie pas de référence à son argument de gauche. Il renvoie à la place une copie de la valeur stockée.

Rapports de défauts
