std::atomic_ref<T>::operator&=,|=,^=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Fourni uniquement lorsque T est un type entier autre que cv bool

value_type operator&=( value_type arg ) const noexcept;  // (1) (depuis C++20)

value_type operator|=( value_type arg ) const noexcept;  // (2) (depuis C++20)

value_type operator^=( value_type arg ) const noexcept;  // (3) (depuis C++20)

Remplace atomiquement la valeur courante de l'objet référencé par le résultat d'un calcul impliquant la valeur précédente et arg. Ces opérations sont des opérations de lecture-modification-écriture.

  • operator&= effectue un ET bit à bit atomique. Équivalent à return fetch_and(arg) & arg;.
  • operator!= effectue un OU bit à bit atomique. Équivalent à return fetch_or(arg) | arg;.
  • operator^= effectue un OU exclusif bit à bit atomique. Équivalent à return fetch_xor(arg) ^ arg;.

Ces surcharges ne participent à la résolution de surcharge que si std::is_const_v<T> est false.

Paramètres

  • arg — l'argument de l'opération arithmétique

Valeur de retour

La valeur résultante (c'est-à-dire le résultat de l'application de l'opérateur binaire correspondant à la valeur immédiatement précédant les effets de la fonction membre correspondante).

Notes

Contrairement à la plupart des opérateurs d'affectation composée, les opérateurs d'affectation composée pour atomic_ref ne renvoient pas de référence vers leurs arguments de gauche. Ils renvoient à la place une copie de la valeur stockée.
