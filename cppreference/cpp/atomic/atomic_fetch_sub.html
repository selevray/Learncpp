std::atomic_fetch_sub, std::atomic_fetch_sub_explicit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <atomic>

template< class T >
T atomic_fetch_sub( std::atomic<T>* obj,
                    typename std::atomic<T>::difference_type arg ) noexcept;  // (1) (depuis C++11)

template< class T >
T atomic_fetch_sub( volatile std::atomic<T>* obj,
                    typename std::atomic<T>::difference_type arg ) noexcept;  // (2) (depuis C++11)

template< class T >
T atomic_fetch_sub_explicit( std::atomic<T>* obj,
                             typename std::atomic<T>::difference_type arg,
                             std::memory_order order ) noexcept;  // (3) (depuis C++11)

template< class T >
T atomic_fetch_sub_explicit( volatile std::atomic<T>* obj,
                             typename std::atomic<T>::difference_type arg,
                             std::memory_order order ) noexcept;  // (4) (depuis C++11)

Effectue une soustraction atomique. Soustrait atomiquement arg à la valeur pointée par obj et retourne la valeur obj détenue précédemment. L'opération est effectuée comme si la suite suivante était exécutée :

1,2) obj->fetch_sub(arg)

3,4) obj->fetch_sub(arg, order)

Si std::atomic<T> n'a pas de membre fetch_sub (ce membre n'est fourni que pour les types entiers, à virgule flottante (depuis C++20) et pointeurs à l'exception de bool), le programme est mal formé.

Paramètres

  • obj — pointeur vers l'objet atomique à modifier
  • arg — la valeur à soustraire de la valeur stockée dans l'objet atomique
  • order — l'ordre de synchronisation mémoire

Valeur de retour

La valeur immédiatement antérieure aux effets de cette fonction dans l'ordre de modification de *obj.

Exemple

Plusieurs threads peuvent utiliser std::atomic_fetch_sub pour traiter simultanément un conteneur indexé.

#include <atomic>
#include <iostream>
#include <numeric>
#include <string>
#include <thread>
#include <vector>

const int N = 50;
std::atomic<int> cnt;
std::vector<int> data(N);

void reader(int id)
{
    for (;;)
    {
        int idx = atomic_fetch_sub_explicit(&cnt, 1, std::memory_order_relaxed);
        if (idx >= 0)
            std::cout << "reader " << std::to_string(id) << " processed item "
                      << std::to_string(data[idx]) << '\n';
        else
        {
            std::cout << "reader " << std::to_string(id) << " done\n";
            break;
        }
    }
}

int main()
{
    std::iota(data.begin(), data.end(), 1);
    cnt = data.size() - 1;

    std::vector<std::thread> v;
    for (int n = 0; n < 5; ++n)
        v.emplace_back(reader, n);
    for (auto& t : v)
        t.join();
}

Output:

reader 2 processed item 50
reader 1 processed item 44
reader 4 processed item 46
<....>
reader 0 done
reader 4 done
reader 3 done
