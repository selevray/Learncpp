std::atomic<T>::load

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

T load( std::memory_order order
            = std::memory_order_seq_cst ) const noexcept;  // (1) (depuis C++11)

T load( std::memory_order order
            = std::memory_order_seq_cst ) const volatile noexcept;  // (2) (depuis C++11)

Charge atomiquement et renvoie la valeur courante de la variable atomique. La mémoire est affectée selon la valeur de order.

Si order est l'un de std::memory_order_release et std::memory_order_acq_rel, le comportement est un comportement indéfini.

Elle est obsolète si std::atomic<T>::is_always_lock_free vaut false et que la surcharge (2) participe à la résolution de surcharge.

(depuis C++20)

Paramètres

  • order — contraintes d'ordre mémoire à appliquer

Valeur de retour

La valeur courante de la variable atomique.
