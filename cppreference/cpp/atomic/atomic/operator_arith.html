Incrémente ou décrémente atomiquement la valeur courante. L'opération est une opération de type lecture-modification-écriture.

  • operator++() effectue une pré-incrémentation atomique. Équivaut à return fetch_add(1) + 1;.
  • operator++(int) effectue une post-incrémentation atomique. Équivaut à return fetch_add(1);.
  • operator--() effectue une pré-décrémentation atomique. Équivaut à return fetch_sub(1) - 1;.
  • operator--(int) effectue une post-décrémentation atomique. Équivaut à return fetch_sub(1);.

1-8) Pour les types entiers signés, l'arithmétique est définie avec une représentation en complément à deux. Il n'existe aucun résultat indéfini.

9-16) Le résultat peut être une adresse indéfinie, mais les opérations n'ont par ailleurs aucun comportement indéfini.

Si T n'est pas un type objet complet, le programme est mal formé.

Il est obsolète si std::atomic<T>::is_always_lock_free vaut false et qu'une surcharge volatile participe à la résolution de surcharge.

(depuis C++20)

Valeur de retour

operator++() et operator--() renvoient la valeur de la variable atomique après la modification. Formellement, il s'agit du résultat de l'incrémentation/décrémentation de la valeur qui précède immédiatement les effets de cette fonction dans l'ordre de modification de *this.

operator++(int) et operator--(int) renvoient la valeur de la variable atomique avant la modification. Formellement, il s'agit de la valeur qui précède immédiatement les effets de cette fonction dans l'ordre de modification de *this.

Notes

Contrairement à la plupart des opérateurs de pré-incrémentation et pré-décrémentation, ceux des types atomiques ne renvoient pas de référence vers l'objet modifié. Ils renvoient à la place une copie de la valeur stockée.

Exemple

#include <atomic>
#include <chrono>
#include <iomanip>
#include <iostream>
#include <mutex>
#include <random>
#include <string>
#include <thread>

std::atomic<int> atomic_count{0};

std::mutex cout_mutex;
int completed_writes{0};

constexpr int global_max_count{72};
constexpr int writes_per_line{8};
constexpr int max_delay{100};

template<int Max>
int random_value()
{
    static std::uniform_int_distribution<int> distr{1, Max};
    static std::random_device engine;
    static std::mt19937 noise{engine()};
    static std::mutex rand_mutex;
    std::lock_guard lock{rand_mutex};
    return distr(noise);
}

int main()
{
    auto work = [](const std::string id)
    {
        for (int count{}; (count = ++atomic_count) <= global_max_count;)
        {
            std::this_thread::sleep_for(
                std::chrono::milliseconds(random_value<max_delay>()));

            // affiche l'`id` du thread et la valeur de `count`
            {
                std::lock_guard lock{cout_mutex};

                const bool new_line = ++completed_writes % writes_per_line == 0;

                std::cout << id << std::setw(3) << count << "  "
                          << (new_line ? "\n" : "") << std::flush;
            }
        }
    };

    std::jthread j1(work, "░"), j2(work, "▒"), j3(work, "▓"), j4(work, "█");
}
