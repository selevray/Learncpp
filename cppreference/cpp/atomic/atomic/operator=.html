std::atomic<T>::operator=

T operator=( T desired ) noexcept;  // (1) (depuis C++11)

T operator=( T desired ) volatile noexcept;  // (2) (depuis C++11)

atomic& operator=( const atomic& ) = delete;  // (3) (depuis C++11)

atomic& operator=( const atomic& ) volatile = delete;  // (4) (depuis C++11)

1,2) Affecte atomiquement desired à la variable atomique. Équivaut à store(desired).

Elle est obsolète si std::atomic<T>::is_always_lock_free vaut false et que la surcharge (2) participe à la résolution de surcharge.

(depuis C++20)

3,4) Les variables atomiques ne sont pas CopyAssignable.

Paramètres

  • desired — valeur à affecter

Valeur de retour

1,2) desired

Notes

Contrairement à la plupart des opérateurs d'affectation, les opérateurs d'affectation des types atomiques ne renvoient pas de référence vers leur argument de gauche. Ils renvoient à la place une copie de la valeur stockée.
