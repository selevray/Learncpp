Remplace atomiquement la valeur courante par le résultat d'un calcul impliquant la valeur précédente et arg. L'opération est une opération de type lecture-modification-écriture.

  • operator+= effectue une addition atomique. Équivaut à return fetch_add(arg) + arg;.
  • operator-= effectue une soustraction atomique. Équivaut à return fetch_sub(arg) - arg;.

1-4) Pour les types entiers signés, l'arithmétique est définie avec une représentation en complément à deux. Il n'existe aucun résultat indéfini.

Pour les types à virgule flottante, l'environnement en virgule flottante en vigueur peut être différent de celui du thread appelant. L'opération n'a pas besoin de respecter les traits std::numeric_limits correspondants, mais y est encouragée. Si le résultat n'est pas une valeur représentable pour son type, le résultat est non spécifié, mais l'opération n'a par ailleurs aucun comportement indéfini.

(depuis C++20)

5-8) Le résultat peut être une adresse indéfinie, mais les opérations n'ont par ailleurs aucun comportement indéfini.

Si T n'est pas un type objet complet, le programme est mal formé.

Elle est obsolète si std::atomic<T>::is_always_lock_free vaut false et qu'une surcharge volatile participe à la résolution de surcharge.

(depuis C++20)

Paramètres

  • arg — l'argument de l'opération arithmétique

Valeur de retour

La valeur résultante (c.-à-d. le résultat de l'application de l'opérateur binaire correspondant à la valeur qui précède immédiatement les effets de la fonction membre correspondante dans l'ordre de modification de *this).

Notes

Contrairement à la plupart des opérateurs d'affectation composée, ceux des types atomiques ne renvoient pas de référence vers leurs arguments de gauche. Ils renvoient à la place une copie de la valeur stockée.
