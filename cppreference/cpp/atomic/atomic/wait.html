std::atomic<T>::wait

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void wait( T old, std::memory_order order =
                      std::memory_order_seq_cst ) const noexcept;  // (1) (depuis C++20) (constexpr depuis C++26)

void wait( T old,
           std::memory_order order =
               std::memory_order_seq_cst ) const volatile noexcept;  // (2) (depuis C++20)

Effectue des opérations d'attente atomiques. Se comporte comme si elle exécutait de façon répétée les étapes suivantes :

  • Compare la représentation de la valeur de this->load(order) avec celle de old.
    • Si elles sont égales, bloque jusqu'à ce que *this soit notifié par notify_one() ou notify_all(), ou que le thread soit débloqué de manière fortuite.
    • Sinon, retourne.

Ces fonctions ne sont garanties de retourner que si la valeur a changé, même si l'implémentation sous-jacente se débloque de manière fortuite.

Si order n'est aucun de std::memory_order_relaxed, std::memory_order_consume, std::memory_order_acquire ou std::memory_order_seq_cst, le comportement est indéfini.

Paramètres

  • old — la valeur que l'objet de atomic ne doit plus contenir
  • order — contraintes d'ordre mémoire à appliquer

Notes

Cette forme de détection de changement est souvent plus efficace qu'un simple polling ou que des spinlocks purs.

En raison du problème ABA, des changements transitoires de old vers une autre valeur puis de retour vers old peuvent être manqués, et ne pas débloquer.

La comparaison est bit à bit (similaire à std::memcmp) ; aucun opérateur de comparaison n'est utilisé. Les bits de remplissage qui ne participent jamais à la représentation de la valeur d'un objet sont ignorés.

Exemple

#include <atomic>
#include <chrono>
#include <future>
#include <iostream>
#include <thread>

using namespace std::literals;

int main()
{
    std::atomic<bool> all_tasks_completed{false};
    std::atomic<unsigned> completion_count{};
    std::future<void> task_futures[16];
    std::atomic<unsigned> outstanding_task_count{16};

    // Lance plusieurs tâches qui prennent des durées différentes,
    // puis décrémente le nombre de tâches en cours.
    for (std::future<void>& task_future : task_futures)
        task_future = std::async([&]
        {
            // Cette attente représente un travail réel...
            std::this_thread::sleep_for(50ms);

            ++completion_count;
            --outstanding_task_count;

            // Lorsque le nombre de tâches tombe à zéro, notifie
            // le thread en attente (ici le thread principal).
            if (outstanding_task_count.load() == 0)
            {
                all_tasks_completed = true;
                all_tasks_completed.notify_one();
            }
        });

    all_tasks_completed.wait(false);

    std::cout << "Tasks completed = " << completion_count.load() << '\n';
}

Output:

Tasks completed = 16
