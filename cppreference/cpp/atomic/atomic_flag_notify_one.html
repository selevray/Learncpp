std::atomic_flag_notify_one

void atomic_flag_notify_one( std::atomic_flag* object ) noexcept;  // (1) (depuis C++20)

void atomic_flag_notify_one( volatile std::atomic_flag* object ) noexcept;  // (2) (depuis C++20)

Effectue des opérations de notification atomiques.

S'il existe un thread bloqué dans une opération d'attente atomique (c'est-à-dire std::atomic_flag_wait(), std::atomic_flag_wait_explicit(), ou std::atomic_flag::wait()) sur *object, alors débloque au moins un tel thread ; sinon ne fait rien.

Équivalent à object->notify_one().

Paramètres

  • object — pointeur vers l'objet atomic_flag à notifier

Valeur de retour

(aucune)

Notes

Cette forme de détection de changement est souvent plus efficace qu'un simple polling ou que des spinlocks purs.
