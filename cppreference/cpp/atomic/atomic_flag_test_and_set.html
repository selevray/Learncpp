std::atomic_flag_test_and_set, std::atomic_flag_test_and_set_explicit

                                        std::memory_order order ) noexcept;  // (4) (depuis C++11)

Modifie atomiquement l'état d'un std::atomic_flag pointé par obj à positionné (true) et retourne la valeur qu'il contenait auparavant.

1,2) L'ordre de synchronisation mémoire est std::memory_order_seq_cst.

3,4) L'ordre de synchronisation mémoire est order.

Paramètres

  • obj — pointeur vers std::atomic_flag à accéder
  • order — l'ordre de synchronisation mémoire

Valeur de retour

La valeur précédemment contenue par le drapeau pointé par obj.

Notes

std::atomic_flag_test_and_set et std::atomic_flag_test_and_set_explicit peuvent être implémentés respectivement comme obj->test_and_set() et obj->test_and_set(order).

Exemple

Un mutex spinlock peut être implémenté en espace utilisateur à l'aide d'un std::atomic_flag.

#include <atomic>
#include <iostream>
#include <thread>
#include <vector>

std::atomic_flag lock = ATOMIC_FLAG_INIT;

void f(int n)
{
    for (int cnt = 0; cnt < 100; ++cnt)
    {
        while (std::atomic_flag_test_and_set_explicit(&lock, std::memory_order_acquire))
            ; // attend en boucle jusqu'à ce que le verrou soit acquis
        std::cout << "Output from thread " << n << '\n';
        std::atomic_flag_clear_explicit(&lock, std::memory_order_release);
    }
}

int main()
{
    std::vector<std::thread> v;
    for (int n = 0; n < 10; ++n)
        v.emplace_back(f, n);
    for (auto& t : v)
        t.join();
}
