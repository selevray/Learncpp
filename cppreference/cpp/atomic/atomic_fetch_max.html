template< class T >
T atomic_fetch_max_explicit( volatile std::atomic<T>* obj,

                             std::memory_order order ) noexcept;  // (4) (depuis C++26)

Remplace atomiquement la valeur pointée par obj par le résultat de std::max entre l'ancienne valeur de obj et arg. Retourne la valeur obj détenue précédemment. L'opération est effectuée comme si la suite suivante était exécutée :

1,2) obj->fetch_max(arg)

3,4) obj->fetch_max(arg, order)

Si std::atomic<T> n'a pas de membre fetch_max (ce membre n'est fourni que pour les types entiers et pointeurs à l'exception de bool), le programme est mal formé.

Paramètres

  • obj — pointeur vers l'objet atomique à modifier
  • arg — la valeur à combiner via std::max avec la valeur stockée dans l'objet atomique
  • order — l'ordre de synchronisation mémoire

Valeur de retour

La valeur immédiatement antérieure aux effets de cette fonction dans l'ordre de modification de *obj.
