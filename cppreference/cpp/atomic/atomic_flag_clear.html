void atomic_flag_clear_explicit( volatile std::atomic_flag* obj,
                                 std::memory_order order ) noexcept;  // (3) (depuis C++11)

void atomic_flag_clear_explicit( std::atomic_flag* obj,
                                 std::memory_order order ) noexcept;  // (4) (depuis C++11)

Modifie atomiquement l'état du std::atomic_flag pointé par obj à effacé (false).

1,2) L'ordre de synchronisation mémoire est std::memory_order_seq_cst.

3,4) L'ordre de synchronisation mémoire est order.

Si order est l'un de std::memory_order_consume, std::memory_order_acquire et std::memory_order_acq_rel, le comportement est indéfini.

Paramètres

  • obj — pointeur vers std::atomic_flag à accéder
  • order — l'ordre de synchronisation mémoire

Notes

std::atomic_flag_clear et std::atomic_flag_clear_explicit peuvent être implémentés respectivement comme obj->clear() et obj->clear(order).
