std::atomic_flag

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <atomic>

class atomic_flag;  // (depuis C++11)

std::atomic_flag est un type booléen atomique. Contrairement à toutes les spécialisations de std::atomic, il est garanti sans verrou. Contrairement à std::atomic<bool>, std::atomic_flag ne fournit pas d'opérations de lecture ou d'écriture.

Fonctions membres

  • (constructeur) — construit un atomic_flag (fonction membre publique)
  • operator=[deleted] — l'opérateur d'affectation (supprimé) (fonction membre publique)
  • clear — définit atomiquement le drapeau à false (fonction membre publique)
  • test_and_set — définit atomiquement le drapeau à true et obtient sa valeur précédente (fonction membre publique)
  • test (C++20) — retourne atomiquement la valeur du drapeau (fonction membre publique)
  • wait (C++20) — bloque le thread jusqu'à notification et changement de la valeur atomique (fonction membre publique)
  • notify_one (C++20) — notifie au moins un thread en attente sur l'objet atomique (fonction membre publique)
  • notify_all (C++20) — notifie tous les threads bloqués en attente sur l'objet atomique (fonction membre publique)

Exemple

Une démonstration de mutex spinlock peut être implémentée en espace utilisateur à l'aide d'un atomic_flag. Notez que les mutex spinlock sont extrêmement douteux en pratique.

#include <atomic>
#include <iostream>
#include <mutex>
#include <thread>
#include <vector>

class mutex
{
    std::atomic_flag m_{};

  public:
    void lock() noexcept
    {
        while (m_.test_and_set(std::memory_order_acquire))
#if defined(__cpp_lib_atomic_wait) && __cpp_lib_atomic_wait >= 201907L
            // Depuis C++20, les verrous ne peuvent être acquis qu'après notification dans le unlock,
            // évitant toute attente active inutile.
            // Notez que, même si wait garantit qu'il ne retourne qu'après que la valeur a
            // changé, le verrou est acquis après la prochaine vérification de la condition.
            m_.wait(true, std::memory_order_relaxed)
#endif
                ;
    }
    bool try_lock() noexcept
    {
        return !m_.test_and_set(std::memory_order_acquire);
    }
    void unlock() noexcept
    {
        m_.clear(std::memory_order_release);
#if defined(__cpp_lib_atomic_wait) && __cpp_lib_atomic_wait >= 201907L
        m_.notify_one();
#endif
    }
};

static mutex m;

static int out{};

void f(std::size_t n)
{
    for (std::size_t cnt{}; cnt < 40; ++cnt)
    {
        std::lock_guard lock{m};
        std::cout << n << ((++out % 40) == 0 ? '\n' : ' ');
    }
}

int main()
{
    std::vector<std::thread> v;
    for (std::size_t n{}; n < 10; ++n)
        v.emplace_back(f, n);
    for (auto &t : v)
        t.join();
}
