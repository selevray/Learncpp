std::atomic_ref

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <atomic>

template< class T >
struct atomic_ref;  // (depuis C++20)

Le modèle de classe std::atomic_ref applique des opérations atomiques à l'objet qu'il référence.

Pendant toute la durée de vie de l'objet std::atomic_ref, l'objet qu'il référence est considéré comme un objet atomique. Si un thread écrit dans un objet atomique pendant qu'un autre thread lit depuis celui-ci, le comportement est bien défini (voir modèle mémoire pour plus de détails sur les courses de données). En outre, les accès aux objets atomiques peuvent établir une synchronisation inter-threads et ordonner les accès mémoire non atomiques comme spécifié par std::memory_order.

La durée de vie d'un objet doit dépasser la durée de vie de tous les std::atomic_ref qui référencent cet objet. Tant qu'une instance std::atomic_ref référençant un objet existe, l'objet doit être accédé exclusivement via ces instances std::atomic_ref. Aucun sous-objet d'un objet référencé par un objet std::atomic_ref ne peut être référencé simultanément par un autre objet std::atomic_ref.

Les opérations atomiques appliquées à un objet via un std::atomic_ref sont atomiques par rapport aux opérations atomiques appliquées via tout autre std::atomic_ref référençant le même objet.

Comme les références du langage de base, la constance est superficielle pour std::atomic_ref : il est possible de modifier la valeur référencée via un objet const std::atomic_ref.

Si l'une des conditions suivantes est satisfaite, le programme est mal formé :

  • std::is_trivially_copyable_v<T> is false.
  • is_always_lock_free est false et std::is_volatile_v<T> est true.

std::atomic_ref is CopyConstructible.

Spécialisations

La norme spécifie que std::atomic_ref possède les spécialisations suivantes :

template<>
struct atomic_ref</*type entier*/>;  // (1) (depuis C++20)

template<>
struct atomic_ref</*type à virgule flottante*/>;  // (2) (depuis C++20)

template< class /*type pointeur*/ >
    requires /* voir ci-dessous */
struct atomic_ref</*type pointeur*/>;  // (3) (depuis C++20)

  1. /*type entier*/ désigne un type entier éventuellement qualifié cv, autre que cv bool.

  2. /*type à virgule flottante*/ désigne un type à virgule flottante éventuellement qualifié cv.

  3. La spécialisation partielle est fournie pour les /*type pointeur*/ qui sont des types pointeur vers objet éventuellement qualifiés cv.

Notes

Les implémentations peuvent fusionner les spécialisations indiquées. Par exemple, la STL de MSVC les fusionne toutes dans le modèle primaire.

Lorsque T est cv void ou un type fonction, std::atomic_ref<T*> (c'est-à-dire std::atomic_ref<void*>, std::atomic_ref<int(*)()> etc.) n'a pas difference_type ni aucune opération nécessitant une arithmétique de pointeursou une comparaison relationnelle (depuis C++26).
