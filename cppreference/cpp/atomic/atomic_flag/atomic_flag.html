  1. Initialise std::atomic_flag dans un état clair.

(depuis C++20)

  1. Le constructeur de copie est supprimé ; std::atomic_flag n'est pas copiable.

De plus, std::atomic_flag peut être initialisé par valeur dans un état clair avec l'expression ATOMIC_FLAG_INIT. Pour un atomic_flag de durée de stockage statique, cela garantit une initialisation statique : le drapeau peut être utilisé dans les constructeurs d'objets statiques.
