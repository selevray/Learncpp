Signature d'appel

execution::sender auto just_stopped();  // (depuis C++26)

Une fabrique d'émetteurs qui retourne un émetteur qui s'achève immédiatement en appelant le set_stopped() du récepteur.

L'expression just_stopped() est équivalente à une expression à /*make-sender*/(just_stopped)

Objets de point de personnalisation

Le nom execution::just_stopped désigne un objet de point de personnalisation, qui est un objet fonction const d'un type de classe littéral semiregular. La version sans qualificateurs cv de son type est un type d'étiquette désigné par execution::just_stopped_t.

Toutes les instances de execution::just_stopped_t sont égales. Les effets de l'invocation de différentes instances du type execution::just_stopped_t sur les mêmes arguments sont équivalents, qu'il s'agisse ou non d'une lvalue ou d'une rvalue, et que l'expression désignant l'instance soit qualifiée const ou non (toutefois, une instance qualifiée volatile n'est pas tenue d'être invocable). Ainsi, execution::just_stopped peut être copié librement et ses copies peuvent être utilisées de manière interchangeable.

Étant donné un ensemble de types Args..., si std::declval<Args>()... satisfont aux exigences relatives aux arguments de execution::just_stopped ci-dessus, alors execution::just_stopped_t modélise

  • std::invocable<execution::just_stopped_t, Args...>,
  • std::invocable<const execution::just_stopped_t, Args...>,
  • std::invocable<execution::just_stopped_t&, Args...>, and
  • std::invocable<const execution::just_stopped_t&, Args...>.

Sinon, aucun opérateur d'appel de fonction de execution::just_stopped_t ne participe à la résolution de surcharge.
