std::execution::then

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <execution>

execution::sender auto then( execution::sender auto input,
                             std::invocable</*values-sent-by*/(input)...> function );  // (depuis C++26)

Paramètres

  • input — émetteur qui, une fois exécuté, envoie les valeurs sur lesquelles la fonction s'exécute
  • function — invocable à appeler par le nouvel émetteur enchaîné à l'émetteur d'entrée

Valeur de retour

Retourne un émetteur décrivant le graphe de tâches décrit par l'émetteur d'entrée, avec un nœud supplémentaire invoquant la fonction fournie avec les valeurs envoyées par l'émetteur d'entrée comme arguments.

then garantit que function ne commence pas à s'exécuter tant que l'émetteur retourné n'est pas démarré.

Exemple

Utilisation possible de execution::then.

execution::sender auto input = get_input();
execution::sender auto snd = execution::then(input, [](auto... args)
{
    std::print(args...);
});
// snd décrit le travail décrit par pred
// suivi de l'affichage de toutes les valeurs envoyées par pred
