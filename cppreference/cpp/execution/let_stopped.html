execution::sender auto let_stopped( execution::sender auto input,
                                    std::invocable auto function );  // (depuis C++26)

Paramètres

  • input — émetteur qui, dès qu'il est arrêté, envoie le « jeton d'arrêt » pour exécuter la fonction
  • function — invocable à appeler avec les erreurs en cas d'erreur provenant de l'émetteur d'entrée

Valeur de retour

Retourne un émetteur décrivant le graphe de tâches décrit par l'émetteur d'entrée, avec un nœud supplémentaire invoqué lorsque le signal « stopped » est envoyé.
