Défini dans l'en-tête <execution>

execution::sender auto
    let_value( execution::sender auto input,
               std::invocable</*values-sent-by*/(input)...> function );  // (depuis C++26)

Paramètres

  • input — émetteur qui, une fois exécuté, envoie les valeurs sur lesquelles la fonction s'exécute
  • function — invocable à appeler avec les valeurs de l'émetteur d'entrée

Valeur de retour

Retourne un émetteur décrivant le graphe de tâches décrit par l'émetteur d'entrée, avec un nœud supplémentaire invoquant la fonction fournie avec les valeurs envoyées par l'émetteur d'entrée comme arguments.

let_value est similaire à then ; cependant, là où l'émetteur retourné par then envoie exactement ce que la fonction finit par retourner, let_value exige que la fonction retourne un émetteur, et l'émetteur retourné par let_value envoie les valeurs envoyées par l'émetteur retourné par le rappel.
