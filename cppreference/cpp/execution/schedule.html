Pour une sous-expression sch, l'expression schedule(sch) est équivalente à une expression à sch.schedule().

Objets de point de personnalisation

Le nom execution::schedule désigne un objet de point de personnalisation, qui est un objet fonction const d'un type de classe littéral semiregular. La version sans qualificateurs cv de son type est un type d'étiquette désigné par execution::schedule_t.

Toutes les instances de execution::schedule_t sont égales. Les effets de l'invocation de différentes instances du type execution::schedule_t sur les mêmes arguments sont équivalents, qu'il s'agisse ou non d'une lvalue ou d'une rvalue, et que l'expression désignant l'instance soit qualifiée const ou non (toutefois, une instance qualifiée volatile n'est pas tenue d'être invocable). Ainsi, execution::schedule peut être copié librement et ses copies peuvent être utilisées de manière interchangeable.

Étant donné un ensemble de types Args..., si std::declval<Args>()... satisfont aux exigences relatives aux arguments de execution::schedule ci-dessus, alors execution::schedule_t modélise

  • std::invocable<execution::schedule_t, Args...>,
  • std::invocable<const execution::schedule_t, Args...>,
  • std::invocable<execution::schedule_t&, Args...>, and
  • std::invocable<const execution::schedule_t&, Args...>.

Sinon, aucun opérateur d'appel de fonction de execution::schedule_t ne participe à la résolution de surcharge.
