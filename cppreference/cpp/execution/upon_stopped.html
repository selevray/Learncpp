Défini dans l'en-tête <execution>

execution::sender auto upon_stopped( execution::sender auto input,
                                     std::invocable auto function );  // (depuis C++26)

Paramètres

  • input — expéditeur qui, dès qu'il obtient un « stop token », notifie le nouveau nœud pour qu'il exécute la fonction
  • function — invocable à appeler dans le cas où un signal « stopped » est envoyé à l'expéditeur d'entrée

Valeur de retour

Renvoie un expéditeur décrivant le graphe de tâches décrit par l'expéditeur d'entrée, auquel on ajoute un nœud qui invoque la fonction fournie dans le cas où le signal « stopped » est envoyé à l'expéditeur d'entrée.
