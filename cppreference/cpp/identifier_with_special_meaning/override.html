Identificateur C++ à signification spéciale : override (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Utilisation

  • spécificateur override

Exemple

struct b
{
    void f0() {};
    void f1() {};
    virtual void f2() {};
    virtual void f3() {};
    virtual void f4() {};
    virtual void f5() {};
};

struct d : b
{
    void f0() {};                        // OK. Ni b::f0 ni d::f0 ne sont virtuelles.
    void f1() override {};               // Erreur : impossible de surcharger b::f1, qui n'est pas virtuelle.
    void f2() override {};               // OK. La fonction membre d::f2 est virtuelle.
    virtual void f3() {};                // OK. Le spécificateur 'override' est facultatif.
    virtual void f4() override {};       // OK. 'override' garantit que b::f4 est virtuelle.
    virtual void f5() override final {}; // OK. d::f5 est à la fois surchargée et final.
};
