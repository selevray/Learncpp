Utilisation

  • module déclaration : déclare que l'unité de traduction courante est une unité de module
  • Débute un fragment global de module d'une unité de module
  • Débute un fragment privé de module d'une unité de module

Exemple

module;            // débute un fragment global de module

#include <string>

export module foo; // termine un fragment global de module
                   // déclare l'unité d'interface de module primaire du module nommé 'foo'
                   // débute la partie utile (purview) d'une unité de module

export std::string f();

module : private;  // termine la partie de l'unité d'interface de module qui
                   // peut affecter le comportement d'autres unités de traduction
                   // débute un fragment privé de module

std::string f()
{
    return "foo";
}
