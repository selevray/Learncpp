Utilisation

  • module déclaration d'importation : importe un ensemble d'unités de traduction

Exemple

export module foo;

import bar;   // importe toutes les unités d'interface de module de bar
import :baz;  // importe la partition de module nommée baz du module foo
import <set>; // importe une unité d'en-tête synthétisée formée à partir de l'en-tête <set>
