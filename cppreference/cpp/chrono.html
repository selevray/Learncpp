Utilitaires de date et d'heure

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

C++ prend en charge deux types de manipulation du temps :

  • La bibliothèque chrono, un ensemble souple de types qui suivent le temps avec des degrés de précision variés (par exemple std::chrono::time_point).
  • Bibliothèque de date et d'heure de style C (par exemple std::time).

Bibliothèque chrono (depuis C++11)

La bibliothèque chrono définit [trois (jusqu'à C++20) | cinq (depuis C++20)] types principaux ainsi que des fonctions utilitaires et des typedefs courants :

  • clocks
  • points temporels
  • durations
  • dates calendaires
  • informations sur les fuseaux horaires

(depuis C++20)

Horloges

Une horloge se compose d'un point de départ (ou époque) et d'une fréquence de graduation. Par exemple, une horloge peut avoir une époque au 1er janvier 1970 et graduer chaque seconde. C++ définit plusieurs types d'horloges :

Défini dans l'en-tête <chrono>

Défini dans l'espace de noms std::chrono

  • system_clock (C++11) — heure murale fournie par l'horloge temps réel à l'échelle du système (classe)
  • steady_clock (C++11) — horloge monotone qui ne sera jamais ajustée (classe)
  • high_resolution_clock (C++11) — l'horloge ayant la plus courte période de tick disponible (classe)
  • is_clockis_clock_v (C++20) — détermine si un type est une Clock (modèle de classe) (modèle de variable)
  • utc_clock (C++20) — Clock pour le temps universel coordonné (UTC) (classe)
  • tai_clock (C++20) — Clock pour le temps atomique international (TAI) (classe)
  • gps_clock (C++20) — Clock pour le temps GPS (classe)
  • file_clock (C++20) — Clock utilisé pour l'heure de fichier (typedef)
  • local_t (C++20) — pseudo-horloge représentant l'heure locale (classe)

Point temporel

Un point temporel est une durée écoulée depuis l'époque d'une horloge spécifique.

Défini dans l'en-tête <chrono>

Défini dans l'espace de noms std::chrono

  • time_point (C++11) — un instant (modèle de classe)
  • clock_time_conversion (C++20) — classe de traits définissant comment convertir les points temporels d'une horloge en une autre (modèle de classe)
  • clock_cast (C++20) — convertit des points temporels d'une horloge vers une autre (modèle de fonction)

Durée

Une durée se compose d'un intervalle de temps, défini comme un certain nombre de graduations d'une unité de temps donnée. Par exemple, « 42 secondes » pourrait être représenté par une durée constituée de 42 graduations d'une unité de temps d'une seconde.

Défini dans l'en-tête <chrono>

Défini dans l'espace de noms std::chrono

  • duration (C++11) — un intervalle de temps (modèle de classe)

Heure du jour (depuis C++20)

hh_mm_ss découpe une durée représentant le temps écoulé depuis minuit en heures, minutes, secondes et fractions de seconde, selon le cas. Il s'agit principalement d'un outil de formatage.

Bibliothèque de date et d'heure de style C

Des fonctions de date et d'heure de style C sont également fournies, telles que std::time_t, std::difftime et CLOCKS_PER_SEC.

Exemple

Mesure et affiche le temps d'exécution d'un appel de fonction.

#include <chrono>
#include <iostream>

long Fibonacci(unsigned n)
{
    return n < 2 ? n : Fibonacci(n - 1) + Fibonacci(n - 2);
}

int main()
{
    const auto start{std::chrono::steady_clock::now()};
    const auto fb{Fibonacci(42)};
    const auto end{std::chrono::steady_clock::now()};
    const std::chrono::duration<double> elapsed_seconds{end - start};

    std::cout << "Fibonacci(42): " << fb << "\nElapsed time: ";
//  std::cout << elapsed_seconds.count() << "s\n"; // Avant C++20
    std::cout << elapsed_seconds << '\n'; // operator<< de chrono::duration en C++20
}
