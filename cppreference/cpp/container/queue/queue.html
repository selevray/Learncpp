Construit un nouveau conteneur sous-jacent de l'adaptateur de conteneur à partir de diverses sources de données.

  1. Constructeur par défaut. Initialise par valeur le conteneur.

  2. Construit par copie le conteneur sous-jacent c avec le contenu de cont. C'est aussi le constructeur par défaut. (jusqu'à C++11)

  3. Construit par déplacement le conteneur sous-jacent c avec std::move(cont).

  4. Constructeur de copie. L'adaptateur est construit par copie avec le contenu de other.c.

  5. Constructeur de déplacement. L'adaptateur est construit avec std::move(other.c).

  6. Construit le conteneur sous-jacent c avec le contenu de l'intervalle [first,last). Cette surcharge ne participe à la résolution de surcharge que si InputIt satisfait LegacyInputIterator.

7-12) Ces constructeurs ne participent à la résolution de surcharge que si std::uses_allocator<Container, Alloc>::value vaut true, c'est-à-dire si le conteneur sous-jacent est un conteneur prenant en compte les allocateurs (vrai pour tous les conteneurs de la bibliothèque standard utilisables avec queue).

  1. Construit le conteneur sous-jacent en utilisant alloc comme allocateur, comme par c(alloc).

  2. Construit le conteneur sous-jacent avec le contenu de cont et en utilisant alloc comme allocateur, comme par c(cont, alloc).

  3. Construit le conteneur sous-jacent avec le contenu de cont en utilisant la sémantique de déplacement tout en utilisant alloc comme allocateur, comme par c(std::move(cont), alloc).

  4. Construit l'adaptateur avec le contenu de other.c et en utilisant alloc comme allocateur, comme par c(other.c, alloc).

  5. Construit l'adaptateur avec le contenu de other en utilisant la sémantique de déplacement tout en utilisant alloc comme allocateur, comme par c(std::move(other.c), alloc).

  6. Construit le conteneur sous-jacent avec le contenu de l'intervalle [first,last) en utilisant alloc comme allocateur, comme par c(first, last, alloc). Cette surcharge ne participe à la résolution de surcharge que si InputIt satisfait LegacyInputIterator.

  7. Construit le conteneur sous-jacent avec ranges::to<Container>(std::forward<R>(rg)).

  8. Construit le conteneur sous-jacent avec ranges::to<Container>(std::forward<R>(rg), alloc).

Paramètres

  • alloc — allocateur à utiliser pour toutes les allocations mémoire du conteneur sous-jacent
  • other — un autre adaptateur de conteneur à utiliser comme source pour initialiser le conteneur sous-jacent
  • cont — conteneur à utiliser comme source pour initialiser le conteneur sous-jacent
  • first, last — intervalle d'éléments [first,last) avec lesquels initialiser
  • rg — une plage compatible avec le conteneur, c'est-à-dire un input_range dont les éléments sont convertibles en T

Exigences sur les types

  • Alloc doit satisfaire aux exigences de Allocator.
  • Container doit satisfaire les exigences de Container. Les constructeurs prenant un paramètre allocateur ne participent à la résolution de surcharge que si Container satisfait les exigences de AllocatorAwareContainer.
  • InputIt doit satisfaire aux exigences de LegacyInputIterator.

Complexité

Identique à l'opération correspondante du conteneur encapsulé.

Exemple

#include <cassert>
#include <deque>
#include <iostream>
#include <memory>
#include <ranges>
#include <queue>

int main()
{
    std::queue<int> c1;
    c1.push(5);
    assert(c1.size() == 1);

    std::queue<int> c2(c1);
    assert(c2.size() == 1);

    std::deque<int> deq{3, 1, 4, 1, 5};
    std::queue<int> c3(deq); // overload (2)
    assert(c3.size() == 5);

# ifdef __cpp_lib_adaptor_iterator_pair_constructor
    const auto il = {2, 7, 1, 8, 2};
    std::queue<int> c4{il.begin(), il.end()}; // C++23, (6)
    assert(c4.size() == 5);
# endif

# if __cpp_lib_containers_ranges >= 202202L
    // C++23, surcharge (13)
    auto c5 = std::queue(std::from_range_t, std::ranges::iota(0, 42));
    assert(c5.size() == 42);

    // le même effet avec la syntaxe pipe, utilise en interne la surcharge (13)
    auto c6 = std::ranges::iota(0, 42) | std::ranges::to<std::queue>();
    assert(c6.size() == 42);

    std::allocator<int> alloc;

    // C++23, surcharge (14)
    auto c7 = std::queue(std::from_range_t, std::ranges::iota(0, 42), alloc);
    assert(c7.size() == 42);

    // le même effet avec la syntaxe pipe, utilise en interne la surcharge (14)
    auto c8 = std::ranges::iota(0, 42) | std::ranges::to<std::queue>(alloc);
    assert(c8.size() == 42);
# endif
}
