template< class T, class Container >
void swap( std::queue<T, Container>& lhs,
           std::queue<T, Container>& rhs );  // (depuis C++11) (jusqu'à C++17)

template< class T, class Container >
void swap( std::queue<T, Container>& lhs,
           std::queue<T, Container>& rhs )
               noexcept(/* voir ci-dessous */);  // (depuis C++17)

Spécialise l'algorithme std::swap pour std::queue. Échange le contenu de lhs et rhs. Appelle lhs.swap(rhs).

Cette surcharge ne participe à la résolution de surcharge que si std::is_swappable_v<Container> est true.

(depuis C++17)

Paramètres

  • lhs, rhs — conteneurs dont le contenu doit être échangé

Valeur de retour

(aucune)

Complexité

Identique à l'échange des conteneurs sous-jacents.

Exceptions

noexcept specification:noexcept(noexcept(lhs.swap(rhs)))

(depuis C++17)

Notes

Bien que les surcharges de std::swap pour les adaptateurs de conteneurs soient introduites en C++11, les adaptateurs de conteneurs peuvent déjà être échangés par std::swap en C++98. Ces appels à std::swap ont généralement une complexité temporelle linéaire, mais une meilleure complexité peut être fournie.

Exemple

#include <algorithm>
#include <iostream>
#include <queue>

int main()
{
    std::queue<int> alice;
    std::queue<int> bob;

    auto print = [](const auto& title, const auto& cont)
    {
        std::cout << title << " size=" << cont.size();
        std::cout << " front=" << cont.front();
        std::cout << " back=" << cont.back() << '\n';
    };

    for (int i = 1; i < 4; ++i)
        alice.push(i);
    for (int i = 7; i < 11; ++i)
        bob.push(i);

    // Affiche l'état avant swap
    print("Alice:", alice);
    print("Bobby:", bob);

    std::cout << "-- SWAP\n";
    std::swap(alice, bob);

    // Affiche l'état après swap
    print("Alice:", alice);
    print("Bobby:", bob);
}

Output:

Alice: size=3 front=1 back=3
Bobby: size=4 front=7 back=10
-- SWAP
Alice: size=4 front=7 back=10
Bobby: size=3 front=1 back=3
