std::queue<T,Container>::empty

bool empty() const;

Vérifie si le conteneur sous-jacent ne contient aucun élément. Équivalent à : return c.empty().

Paramètres

(aucune)

Valeur de retour

true si le conteneur sous-jacent est vide, false sinon.

Complexité

Constante.

Exemple

#include <cassert>
#include <queue>

int main()
{
    std::queue<int> queue;
    assert(queue.empty());

    queue.push(42);
    assert(!queue.empty());

    queue.pop();
    assert(queue.empty());
}
