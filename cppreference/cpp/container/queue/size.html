std::queue<T,Container>::size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

size_type size() const;

Renvoie le nombre d'éléments de l'adaptateur de conteneur. Équivalent à : return c.size().

Paramètres

(aucune)

Valeur de retour

Le nombre d'éléments de l'adaptateur de conteneur.

Complexité

Constante.

Exemple

#include <cassert>
#include <queue>

int main()
{
    std::queue<int> queue;
    assert(queue.size() == 0);

    const int count = 8;
    for (int i = 0; i != count; ++i)
        queue.push(i);
    assert(queue.size() == count);
}
