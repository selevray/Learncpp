std::unordered_map<Key,T,Hash,KeyEqual,Allocator>::count

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

size_type count( const Key& key ) const;  // (1) (depuis C++11)

template< class K >
size_type count( const K& x ) const;  // (2) (depuis C++20)

  1. Renvoie le nombre d'éléments dont la clé est égale à l'argument spécifié key, qui est soit 0 soit 1, puisque ce conteneur n'autorise pas les doublons.

  2. Renvoie le nombre d'éléments dont la clé est équivalente à l'argument spécifié x. Cette surcharge ne participe à la résolution de surcharge que si Hash::is_transparent et KeyEqual::is_transparent sont valides et désignent chacun un type. Cela suppose qu'un tel Hash est appelable avec les types K et Key, et que le KeyEqual est transparent, ce qui, ensemble, permet d'appeler cette fonction sans construire d'instance de Key.

Paramètres

  • key — valeur de clé des éléments à compter
  • x — une valeur de n'importe quel type pouvant être comparée de façon transparente à une clé

Valeur de retour

  1. Nombre d'éléments de clé key, soit 1 soit 0.

  2. Nombre d'éléments dont la clé est équivalente à x.

Complexité

Constante en moyenne, linéaire au pire par rapport à la taille du conteneur.

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_generic_unordered_lookup 201811L (C++20) Recherche par comparaison hétérogène dans les conteneurs associatifs non ordonnés, surcharge (2)

Exemple

#include <iostream>
#include <string>
#include <unordered_map>

int main()
{
    std::unordered_map<int, std::string> dict = {
        {1, "one"}, {6, "six"}, {3, "three"}
    };
    dict.insert({4, "four"});
    dict.insert({5, "five"});
    dict.insert({6, "six"});

    std::cout << "dict: { ";
    for (auto const& [key, value] : dict)
        std::cout << '[' << key << "]=" << value << ' ';
    std::cout << "}\n\n";

    for (int i{1}; i != 8; ++i)
        std::cout << "dict.count(" << i << ") = " << dict.count(i) << '\n';
}

Sortie possible :

dict: { [5]=five [4]=four [1]=one [6]=six [3]=three }

dict.count(1) = 1
dict.count(2) = 0
dict.count(3) = 1
dict.count(4) = 1
dict.count(5) = 1
dict.count(6) = 1
dict.count(7) = 0
