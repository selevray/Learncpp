std::unordered_map<Key,T,Hash,KeyEqual,Allocator>::contains

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool contains( const Key& key ) const;  // (1) (depuis C++20)

template< class K >
bool contains( const K& x ) const;  // (2) (depuis C++20)

  1. Vérifie s'il existe un élément dont la clé est équivalente à key dans le conteneur.

  2. Vérifie s'il existe un élément dont la clé est équivalente à la valeur x. Cette surcharge ne participe à la résolution de surcharge que si Hash::is_transparent et KeyEqual::is_transparent sont valides et désignent chacun un type. Cela suppose qu'un tel Hash est appelable avec les types K et Key, et que le KeyEqual est transparent, ce qui, ensemble, permet d'appeler cette fonction sans construire d'instance de Key.

Paramètres

  • key — valeur de clé de l'élément à rechercher
  • x — une valeur de n'importe quel type pouvant être comparée de façon transparente à une clé

Valeur de retour

true s'il existe un tel élément, sinon false.

Complexité

Constante en moyenne, linéaire au pire par rapport à la taille du conteneur.

Exemple

#include <iostream>
#include <unordered_map>

int main()
{
    std::unordered_map<int, char> example{{1, 'a'}, {2, 'b'}};

    for (int x : {2, 5})
        if (example.contains(x))
            std::cout << x << ": Found\n";
        else
            std::cout << x << ": Not found\n";
}

Output:

2: Found
5: Not found
