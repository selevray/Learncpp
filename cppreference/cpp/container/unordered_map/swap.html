std::unordered_map<Key,T,Hash,KeyEqual,Allocator>::swap

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void swap( unordered_map& other );  // (depuis C++11) (jusqu'à C++17)

void swap( unordered_map& other ) noexcept(/* voir ci-dessous */);  // (depuis C++17)

Échange le contenu du conteneur avec celui de other. N'invoque aucune opération de déplacement, de copie ou d'échange sur les éléments individuels.

Tous les itérateurs et références restent valides. L'itérateur end() est invalidé. Les objets Hash et KeyEqual doivent être Swappable, et ils sont échangés à l'aide d'appels non qualifiés à la fonction non membre swap.

Si std::allocator_traits<allocator_type>::propagate_on_container_swap::value est true, alors les allocateurs sont échangés via un appel non qualifié à la fonction non membre swap. Sinon, ils ne sont pas échangés (et si get_allocator() != other.get_allocator(), le comportement est indéfini).

(depuis C++11)

Paramètres

  • other — conteneur avec lequel échanger le contenu

Exceptions

Toute exception levée par l'échange des objets Hash ou KeyEqual.

(jusqu'à C++17)

noexcept specification:noexcept(std::allocator_traits<Allocator>::is_always_equal::value && std::is_nothrow_swappable<Hash>::value && std::is_nothrow_swappable<key_equal>::value)

(depuis C++17)

Complexité

Constante.

Exemple

#include <iostream>
#include <string>
#include <utility>
#include <unordered_map>

// afficher un std::pair
template<class Os, class U, class V>
Os& operator<<(Os& os, const std::pair<U, V>& p)
{
    return os << p.first << ':' << p.second;
}

// afficher un conteneur
template<class Os, class Co>
Os& operator<<(Os& os, const Co& co)
{
    os << '{';
    for (auto const& i : co)
        os << ' ' << i;
    return os << " }\n";
}

int main()
{
    std::unordered_map<std::string, std::string>
        m1{{"γ", "gamma"}, {"β", "beta"}, {"α", "alpha"}, {"γ", "gamma"}},
        m2{{"ε", "epsilon"}, {"δ", "delta"}, {"ε", "epsilon"}};

    const auto& ref = *(m1.begin());
    const auto iter = std::next(m1.cbegin());

    std::cout << "──────── before swap ────────\n"
              << "m1: " << m1 << "m2: " << m2 << "ref: " << ref
              << "\niter: " << *iter << '\n';

    m1.swap(m2);

    std::cout << "──────── after swap ────────\n"
              << "m1: " << m1 << "m2: " << m2 << "ref: " << ref
              << "\niter: " << *iter << '\n';

    // Notez que chaque itérateur désignant un élément d'un conteneur avant
    // l'échange désigne le même élément dans l'autre conteneur après l'échange.
    // Il en va de même pour les références.
}

Sortie possible :

──────── before swap ────────
m1: { α:alpha β:beta γ:gamma }
m2: { δ:delta ε:epsilon }
ref: α:alpha
iter: β:beta
──────── after swap ────────
m1: { δ:delta ε:epsilon }
m2: { α:alpha β:beta γ:gamma }
ref: α:alpha
iter: β:beta
