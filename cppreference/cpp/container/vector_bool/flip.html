std::vector<bool,Allocator>::flip

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <vector>

void flip();  // (constexpr depuis C++20)

Bascule chaque bool (le remplace par sa valeur opposée) dans le vector.

Exemple

#include <iostream>
#include <vector>

void print(const std::vector<bool>& vb)
{
    for (const bool b : vb)
        std::cout << b;
    std::cout << '\n';
}

int main()
{
    std::vector<bool> v{0, 1, 0, 1};
    print(v);
    v.flip();
    print(v);
}

Output:

0101
1010
