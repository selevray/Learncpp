std::multiset<Key,Compare,Allocator>::extract

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

node_type extract( const_iterator position );  // (1) (depuis C++17)

node_type extract( const Key& k );  // (2) (depuis C++17)

template< class K >
node_type extract( K&& x );  // (3) (depuis C++23)

  1. Dissocie le nœud qui contient l'élément pointé par position et renvoie un node handle qui le possède.

  2. Si le conteneur contient un élément dont la clé est équivalente à k, détache le nœud qui contient le premier élément de ce type du conteneur et renvoie un descripteur de nœud qui le possède. Sinon, renvoie un descripteur de nœud vide.

  3. Identique à (2). Cette surcharge ne participe à la résolution de surcharge que si l'id qualifié Compare::is_transparent est valide et désigne un type, et que ni iterator ni const_iterator n'est implicitement convertible depuis K. Elle permet d'appeler cette fonction sans construire d'instance de Key.

Dans les deux cas, aucun élément n'est copié ou déplacé ; seuls les pointeurs internes des nœuds du conteneur sont réaffectés (un rééquilibrage peut avoir lieu, comme avec erase()).

L'extraction d'un nœud n'invalide que les itérateurs vers l'élément extrait. Les pointeurs et références vers l'élément extrait restent valides, mais ne peuvent pas être utilisés tant que l'élément est possédé par un node handle : ils redeviennent utilisables si l'élément est inséré dans un conteneur.

Paramètres

  • position — un itérateur valide vers ce conteneur
  • k — une clé permettant d'identifier le nœud à extraire
  • x — une valeur de n'importe quel type pouvant être comparée de manière transparente à une clé identifiant le nœud à extraire

Valeur de retour

Un node handle qui possède l'élément extrait, ou un node handle vide si l'élément n'est pas trouvé dans (2,3).

Exceptions

  1. Ne lève aucune exception.

2,3) Toute exception levée par l'objet Compare.

Complexité

  1. Constant amorti.

2,3) log(size())

Notes

extract est le seul moyen de retirer d'un ensemble un objet qui n'est que déplaçable :

std::set<move_only_type> s;
s.emplace(...);
move_only_type mot = std::move(s.extract(s.begin()).value());

Exemple

#include <algorithm>
#include <iostream>
#include <string_view>
#include <set>

void print(std::string_view comment, const auto& data)
{
    std::cout << comment;
    for (auto datum : data)
        std::cout << ' ' << datum;

    std::cout << '\n';
}

int main()
{
    std::multiset<int> cont{1, 2, 3};

    print("Start:", cont);

    // Extraire le node handle et modifier la clé
    auto nh = cont.extract(1);
    nh.value() = 4;

    print("After extract and before insert:", cont);

    // Réinsérer le node handle
    cont.insert(std::move(nh));

    print("End:", cont);
}

Output:

Start: 1 2 3
After extract and before insert: 2 3
End: 2 3 4
