reverse_iterator rend();  // (1) (noexcept depuis C++11)

Renvoie un itérateur inverse vers l'élément suivant le dernier élément du multiset inversé. Il correspond à l'élément précédant le premier élément du multiset non inversé. Cet élément sert de marqueur ; tenter d'y accéder entraîne un comportement indéfini.

Paramètres

(aucune)

Valeur de retour

Itérateur inverse vers l'élément suivant le dernier élément.

Complexité

Constante.

Notes

Comme iterator et const_iterator sont des itérateurs constants (et peuvent en fait être du même type), il n'est pas possible de modifier les éléments du conteneur via un itérateur renvoyé par l'une de ces fonctions membres.

libc++ rétroporte crend() au mode C++98.

Exemple

#include <iostream>
#include <set>

int main()
{
    std::multiset<unsigned> rep{1, 2, 3, 4, 1, 2, 3, 4};

    for (auto it = rep.crbegin(); it != rep.crend(); ++it)
    {
        for (auto n = *it; n > 0; --n)
            std::cout << "⏼" << ' ';
        std::cout << '\n';
    }
}
