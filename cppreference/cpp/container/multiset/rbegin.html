Retourne un itérateur inverse vers le premier élément du multiset inversé. Il correspond au dernier élément du multiset non inversé. Si le multiset est vide, l'itérateur retourné est égal à rend().

Paramètres

(aucune)

Valeur de retour

Itérateur inverse vers le premier élément.

Complexité

Constante.

Notes

Comme iterator et const_iterator sont des itérateurs constants (et peuvent en fait être du même type), il n'est pas possible de modifier les éléments du conteneur via un itérateur renvoyé par l'une de ces fonctions membres.

Le itérateur sous-jacent de l'itérateur inverse renvoyé est l'itérateur de fin. Par conséquent, l'itérateur renvoyé est invalidé si et quand l'itérateur de fin est invalidé.

libc++ rétroporte crbegin() au mode C++98.

Exemple

#include <iostream>
#include <set>

int main()
{
    std::multiset<unsigned> rep{1, 2, 3, 4, 1, 2, 3, 4};

    for (auto it = rep.crbegin(); it != rep.crend(); ++it)
    {
        for (auto n = *it; n > 0; --n)
            std::cout << "⏼" << ' ';
        std::cout << '\n';
    }
}
