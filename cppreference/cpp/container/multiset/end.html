Retourne un itérateur vers l'élément suivant le dernier élément du multiset.

Cet élément sert de marqueur ; tenter d'y accéder entraîne un comportement indéfini.

range-begin-end.svg

Paramètres

(aucune)

Valeur de retour

Itérateur vers l'élément suivant le dernier élément.

Complexité

Constante.

Notes

Comme iterator et const_iterator sont des itérateurs constants (et peuvent en fait être du même type), il n'est pas possible de modifier les éléments du conteneur via un itérateur renvoyé par l'une de ces fonctions membres.

libc++ rétroporte cend() au mode C++98.

Exemple

#include <iostream>
#include <iterator>
#include <set>
#include <string>

int main()
{
    const std::multiset<std::string> words =
    {
        "some", "not", "sorted", "words",
        "will", "come", "out", "sorted",
    };

    for (auto it = words.begin(); it != words.end(); )
    {
        auto count = words.count(*it);
        std::cout << *it << ":\t" << count << '\n';
        std::advance(it, count); // tous les count éléments ont des clés équivalentes
    }
}

Output:

come:	1
not:	1
out:	1
some:	1
sorted:	2
will:	1
words:	1
