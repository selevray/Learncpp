std::stack<T,Container>::emplace

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class... Args >
void emplace( Args&&... args );  // (depuis C++11) (jusqu'à C++17)

template< class... Args >
decltype(auto) emplace( Args&&... args );  // (depuis C++17)

Ajoute un nouvel élément au sommet de la pile. L'élément est construit sur place, c'est-à-dire qu'aucune opération de copie ou de déplacement n'est effectuée. Le constructeur de l'élément est appelé avec exactement les mêmes arguments que ceux fournis à la fonction.

Appelle effectivement c.emplace_back(std::forward<Args>(args)...);.

Paramètres

  • args — arguments à transmettre au constructeur de l'élément

Valeur de retour

(aucune)

(jusqu'à C++17)

La valeur ou la référence, le cas échéant, renvoyée par l'appel ci-dessus à Container::emplace_back.

(depuis C++17)

Complexité

Identique à la complexité de Container::emplace_back.

Exemple

#include <iostream>
#include <stack>

struct S
{
    int id;

    S(int i, double d, std::string s) : id{i}
    {
        std::cout << "S::S(" << i << ", " << d << ", \"" << s << "\");\n";
    }
};

int main()
{
    std::stack<S> stack;
    const S& s = stack.emplace(42, 3.14, "C++"); // requis en C++17 pour la valeur de retour
    std::cout << "id = " << s.id << '\n';
}

Output:

S::S(42, 3.14, "C++")
id = 42
