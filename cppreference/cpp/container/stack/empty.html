std::stack<T,Container>::empty

bool empty() const;

Vérifie si le conteneur sous-jacent ne contient aucun élément. Équivalent à : return c.empty().

Paramètres

(aucune)

Valeur de retour

true si le conteneur sous-jacent est vide, false sinon.

Complexité

Constante.

Exemple

#include <cassert>
#include <stack>

int main()
{
    std::stack<int> stack;
    assert(stack.empty());

    stack.push(42);
    assert(!stack.empty());

    stack.pop();
    assert(stack.empty());
}
