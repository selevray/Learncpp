        class T,
        class Hash = std::hash<Key>,
        class KeyEqual = std::equal_to<Key>
    > using unordered_map =
          std::unordered_map<Key, T, Hash, KeyEqual,

}  // (2) (depuis C++17)

std::unordered_map est un conteneur associatif qui contient des paires clé-valeur à clés uniques. La recherche, l'insertion et la suppression d'éléments ont une complexité constante en moyenne.

En interne, les éléments ne sont pas triés selon un ordre particulier, mais organisés en compartiments (buckets). Le compartiment dans lequel un élément est placé dépend entièrement du hachage de sa clé. Les clés ayant le même code de hachage se trouvent dans le même compartiment. Cela permet un accès rapide aux éléments individuels, puisqu'une fois le hachage calculé, il désigne exactement le compartiment dans lequel l'élément est placé.

Deux clés sont considérées comme équivalentes si le prédicat d'égalité des clés de la table renvoie true pour ces deux clés. Si deux clés sont équivalentes, la fonction de hachage doit renvoyer la même valeur pour ces deux clés.

std::unordered_map satisfait les exigences de Container, AllocatorAwareContainer, UnorderedAssociativeContainer.

Invalidation des itérateurs

Opérations Invalidés
Toutes les opérations en lecture seule, swap, std::swap Jamais
clear, rehash, reserve, operator= Toujours
insert, emplace, emplace_hint, operator[] Seulement si cela provoque un rehachage
erase Seulement pour l'élément effacé

Notes

  • Les fonctions swap n'invalident aucun des itérateurs à l'intérieur du conteneur, mais elles invalident l'itérateur marquant la fin de la zone d'échange.

  • Les références et pointeurs vers la clé ou la donnée stockées dans le conteneur ne sont invalidés que par l'effacement de cet élément, même lorsque l'itérateur correspondant est invalidé.

Exemple

#include <iostream>
#include <string>
#include <unordered_map>

int main()
{
    // Créer une unordered_map de trois chaînes (qui associent des chaînes)
    std::unordered_map<std::string, std::string> u =
    {
        {"RED", "#FF0000"},
        {"GREEN", "#00FF00"},
        {"BLUE", "#0000FF"}
    };

    // Lambda auxiliaire pour afficher les paires clé-valeur
    auto print_key_value = [](const auto& key, const auto& value)
    {
        std::cout << "Key:[" << key << "] Value:[" << value << "]\n";
    };

    std::cout << "Iterate and print key-value pairs of unordered_map, being\n"
                 "explicit with their types:\n";
    for (const std::pair<const std::string, std::string>& n : u)
        print_key_value(n.first, n.second);

    std::cout << "\nIterate and print key-value pairs using C++17 structured binding:\n";
    for (const auto& [key, value] : u)
        print_key_value(key, value);

    // Ajouter deux nouvelles entrées à la unordered_map
    u["BLACK"] = "#000000";
    u["WHITE"] = "#FFFFFF";

    std::cout << "\nOutput values by key:\n"
                 "The HEX of color RED is:[" << u["RED"] << "]\n"
                 "The HEX of color BLACK is:[" << u["BLACK"] << "]\n\n";

    std::cout << "Use operator[] with non-existent key to insert a new key-value pair:\n";
    print_key_value("new_key", u["new_key"]);

    std::cout << "\nIterate and print key-value pairs, using `auto`;\n"
                 "new_key is now one of the keys in the map:\n";
    for (const auto& n : u)
        print_key_value(n.first, n.second);
}
