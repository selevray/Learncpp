std::array

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <array>

template<
    class T,
    std::size_t N
> struct array;  // (depuis C++11)

std::array est un conteneur qui encapsule des tableaux de taille fixe.

Ce conteneur est un type agrégat ayant la même sémantique qu'une struct contenant un tableau de style C T[N] comme seul membre de données non statique. Contrairement à un tableau de style C, il ne se convertit pas automatiquement en T*. En tant que type agrégat, il peut être initialisé par initialisation d'agrégat avec au plus N initialiseurs convertibles en T : std::array<int, 3> a = {1, 2, 3};.

La struct combine les performances et l'accessibilité d'un tableau de style C avec les avantages d'un conteneur standard, comme la connaissance de sa propre taille, la prise en charge de l'affectation, les itérateurs à accès aléatoire, etc.

std::array satisfait les exigences de Container et de ReversibleContainer, sauf qu'un tableau construit par défaut n'est pas vide et que la complexité de l'échange est linéaire, satisfait les exigences de ContiguousContainer, (depuis C++17) et satisfait partiellement les exigences de SequenceContainer.

Il existe un cas particulier pour un tableau de longueur nulle (N == 0). Dans ce cas, array.begin() == array.end() renvoie une valeur unique. L'appel de front() ou back() sur un tableau de taille nulle entraîne un comportement indéfini.

Un tableau peut aussi être utilisé comme tuple de N éléments de même type.

Invalidation des itérateurs

En règle générale, les itérateurs vers un tableau ne sont jamais invalidés pendant toute la durée de vie du tableau. Il faut toutefois noter que, pendant swap, l'itérateur continue de pointer vers le même élément du tableau et change donc de valeur.

Paramètres de modèle

  • T — le type d'élément doit être MoveConstructible et MoveAssignable.
  • N — le nombre d'éléments du tableau ou 0.

Guides de déduction

(depuis C++17)

Exemple

#include <algorithm>
#include <array>
#include <iostream>
#include <iterator>
#include <string>

int main()
{
    // La construction utilise l'initialisation d'agrégat
    std::array<int, 3> a1{{1, 2, 3}}; // Double accolades requises en C++11 avant
                                      // la révision CWG 1270 (non nécessaire en C++11
                                      // après la révision et en C++14 et au-delà)

    std::array<int, 3> a2 = {1, 2, 3}; // Double accolades jamais requises après =

    // Les opérations de conteneur sont prises en charge
    std::sort(a1.begin(), a1.end());
    std::ranges::reverse_copy(a2, std::ostream_iterator<int>(std::cout, " "));
    std::cout << '\n';

    // La boucle for basée sur un intervalle est prise en charge
    std::array<std::string, 2> a3{"E", "\u018E"};
    for (const auto& s : a3)
        std::cout << s << ' ';
    std::cout << '\n';

    // Guide de déduction pour la création de tableau (depuis C++17)
    [[maybe_unused]] std::array a4{3.0, 1.0, 4.0}; // std::array<double, 3>

    // Le comportement des éléments non spécifiés est le même que pour les tableaux natifs
    [[maybe_unused]] std::array<int, 2> a5; // Pas d'initialisation par liste, a5[0] et a5[1]
                                            // sont initialisés par défaut
    [[maybe_unused]] std::array<int, 2> a6{}; // Initialisation par liste, les deux éléments sont initialisés par valeur
                                              // initialisés par valeur, a6[0] = a6[1] = 0
    [[maybe_unused]] std::array<int, 2> a7{1}; // Initialisation par liste, l'élément non spécifié est initialisé par valeur
                                               // initialisé par valeur, a7[0] = 1, a7[1] = 0
}

Output:

3 2 1
E Ǝ
