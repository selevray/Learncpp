std::swap(std::flat_multiset)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <flat_set>

friend void swap( std::flat_multiset& lhs, std::flat_multiset& rhs ) noexcept;  // (depuis C++23)

Spécialise l'algorithme std::swap pour std::flat_multiset. Échange le contenu de lhs et rhs. Appelle lhs.swap(rhs).

Paramètres

  • lhs, rhs — conteneurs dont le contenu doit être échangé

Valeur de retour

(aucune)

Complexité

Identique à l'échange des conteneurs sous-jacents.

Exemple

#include <algorithm>
#include <iostream>
#include <flat_set>

int main()
{
    std::flat_multiset<int> alice{1, 2, 3};
    std::flat_multiset<int> bob{7, 8, 9, 10};

    auto print = [](const int& n) { std::cout << ' ' << n; };

    // Affiche l'état avant swap
    std::cout << "Alice:";
    std::for_each(alice.begin(), alice.end(), print);
    std::cout << "\nBobby:";
    std::for_each(bob.begin(), bob.end(), print);
    std::cout << '\n';

    std::cout << "-- SWAP\n";
    std::swap(alice, bob);

    // Affiche l'état après swap
    std::cout << "Alice:";
    std::for_each(alice.begin(), alice.end(), print);
    std::cout << "\nBobby:";
    std::for_each(bob.begin(), bob.end(), print);
    std::cout << '\n';
}

Output:

Alice: 1 2 3
Bobby: 7 8 9 10
-- SWAP
Alice: 7 8 9 10
Bobby: 1 2 3
