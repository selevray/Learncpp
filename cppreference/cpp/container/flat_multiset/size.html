std::flat_multiset<Key,Compare,KeyContainer>::size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

size_type size() const noexcept;  // (depuis C++23)

Renvoie le nombre d'éléments de l'adaptateur de conteneur. Équivalent à : return c.size().

Paramètres

(aucune)

Valeur de retour

Le nombre d'éléments de l'adaptateur de conteneur.

Complexité

Constante.

Exemple

#include <cassert>
#include <flat_set>

int main()
{
    std::flat_multiset<int> nums{4, 2, 4, 2};
    assert(nums.size() == 4);
}
