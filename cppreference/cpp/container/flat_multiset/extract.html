std::flat_multiset<Key,Compare,KeyContainer>::extract

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

container_type extract() &&;  // (depuis C++23)

Extrait le conteneur adapté c. Équivalent à return std::move(c);.

Après cette opération *this est vide, même si une exception est levée.

Paramètres

(aucune)

Valeur de retour

std::move(c).

Complexité

Constante.

Exemple

#include <cassert>
#include <flat_set>
#include <print>
#include <type_traits>
#include <vector>

int main()
{
    std::flat_multiset<int> set{1, 2, 3};
    const auto size = set.size();

    auto c = set.extract();
    assert(c.size() == size);
    assert(set.empty());
    assert(set.keys().empty());
    assert(set.values().empty());

    // Le conteneur de clés par défaut est std::vector :
    static_assert(std::is_same_v<decltype(c), std::vector<int>>);

    std::println("{}", c);
}

Output:

[1, 2, 3]
