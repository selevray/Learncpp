std::forward_list<T,Allocator>::resize

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void resize( size_type count );  // (1) (depuis C++11)

void resize( size_type count, const value_type& value );  // (2) (depuis C++11)

Redimensionne le conteneur pour qu'il contienne count éléments, ne fait rien si count == std::distance(begin(), end()) (c'est-à-dire si count est égal à la taille actuelle).

Si la taille actuelle est supérieure à count, le conteneur est réduit à ses count premiers éléments.

Si la taille actuelle est inférieure à count, alors :

  1. Des éléments insérés par défaut supplémentaires sont ajoutés à la fin.

  2. Des copies supplémentaires de value sont ajoutées à la fin.

Paramètres

  • count — nouvelle taille du conteneur
  • value — la valeur avec laquelle initialiser les nouveaux éléments

Exigences sur les types

  • T doit satisfaire les exigences de DefaultInsertable pour utiliser la surcharge (1).
  • T doit satisfaire les exigences de CopyInsertable pour utiliser la surcharge (2).

Complexité

Linéaire en la différence entre la taille actuelle et count. Complexité supplémentaire possible due au parcours de la liste pour atteindre le premier élément à effacer / la position de fin pour l'insertion.

Notes

Si l'initialisation par valeur de la surcharge (1) est indésirable, par exemple si les éléments sont de type non classe et que la mise à zéro n'est pas nécessaire, elle peut être évitée en fournissant un Allocator::construct personnalisé.

Exemple

#include <forward_list>
#include <iostream>

void print(auto rem, const std::forward_list<int>& c)
{
    for (std::cout << rem; const int el : c)
        std::cout << el << ' ';
    std::cout << '\n';
}

int main()
{
    std::forward_list<int> c = {1, 2, 3};
    print("The forward_list holds: ", c);

    c.resize(5);
    print("After resize up to 5: ", c);

    c.resize(2);
    print("After resize down to 2: ", c);

    c.resize(6, 4);
    print("After resize up to 6 (initializer = 4): ", c);
}

Output:

The forward_list holds: 1 2 3
After resize up to 5: 1 2 3 0 0
After resize down to 2: 1 2
After resize up to 6 (initializer = 4): 1 2 4 4 4 4
