Retourne un itérateur vers l'élément suivant le dernier élément du forward_list.

Cet élément sert de marqueur ; tenter d'y accéder entraîne un comportement indéfini.

range-begin-end.svg

Paramètres

(aucune)

Valeur de retour

Itérateur vers l'élément suivant le dernier élément.

Complexité

Constante.

Exemple

#include <algorithm>
#include <iostream>
#include <numeric>
#include <string>
#include <forward_list>

int main()
{
    std::forward_list<int> nums{1, 2, 4, 8, 16};
    std::forward_list<std::string> fruits{"orange", "apple", "raspberry"};
    std::forward_list<char> empty;

    // Affiche forward_list.
    std::for_each(nums.begin(), nums.end(), [](const int n) { std::cout << n << ' '; });
    std::cout << '\n';

    // Additionne tous les entiers de forward_list nums (s'il y en a), en n'affichant que le résultat.
    std::cout << "Sum of nums: "
              << std::accumulate(nums.begin(), nums.end(), 0) << '\n';

    // Affiche le premier fruit de forward_list fruits, après avoir vérifié qu'il y en a.
    if (!fruits.empty())
        std::cout << "First fruit: " << *fruits.begin() << '\n';

    if (empty.begin() == empty.end())
        std::cout << "forward_list 'empty' is indeed empty.\n";
}

Output:

1 2 4 8 16
Sum of nums: 31
First fruit: orange
forward_list 'empty' is indeed empty.
