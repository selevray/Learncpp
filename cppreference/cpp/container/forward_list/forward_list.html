Construit un nouveau forward_list à partir de diverses sources de données, en utilisant éventuellement un allocateur fourni par l'utilisateur alloc.

  1. Le constructeur par défaut. Construit un forward_list vide avec un allocateur construit par défaut.

Si Allocator n'est pas DefaultConstructible, le comportement est indéfini.

  1. Construit un forward_list vide avec l'allocateur donné alloc.

  2. Construit un forward_list avec count objets insérés par défaut de T. Aucune copie n'est effectuée.

Si T n'est pas DefaultInsertable dans std::forward_list<T>, le comportement est indéfini.

  1. Construit un forward_list avec count copies d'éléments de valeur value.

Si T n'est pas CopyInsertable dans std::forward_list<T>, le comportement est indéfini.

  1. Construit un forward_list avec le contenu de l'intervalle [first,last). Chaque itérateur de [first,last) est déréférencé exactement une fois.

Cette surcharge ne participe à la résolution de surcharge que si InputIt satisfait les exigences de LegacyInputIterator.

Si T n'est pas EmplaceConstructible dans std::forward_list<T> depuis *first, le comportement est indéfini.

  1. Construit un forward_list avec le contenu de l'intervalle rg. Chaque itérateur de rg est déréférencé exactement une fois.

Si T n'est pas EmplaceConstructible dans std::forward_list<T> depuis *ranges::begin(rg), le comportement est indéfini.

7-10) Construit un forward_list avec le contenu de other.

  1. Le constructeur de copie. L'allocateur est obtenu comme en appelant std::allocator_traits<Allocator>:: select_on_container_copy_construction (other.get_allocator()).

  2. Le constructeur de déplacement. L'allocateur est obtenu par construction par déplacement à partir de other.get_allocator().

  3. Identique au constructeur de copie, sauf que alloc est utilisé comme allocateur.

Si T n'est pas CopyInsertable dans std::forward_list<T>, le comportement est indéfini.

  1. Identique au constructeur de déplacement, sauf que alloc est utilisé comme allocateur.

Si T n'est pas MoveInsertable dans std::forward_list<T>, le comportement est indéfini.

  1. Équivalent à forward_list(il.begin(), il.end(), alloc).

Paramètres

  • alloc — allocateur à utiliser pour toutes les allocations mémoire de ce conteneur
  • count — la taille du conteneur
  • value — la valeur avec laquelle initialiser les éléments du conteneur
  • first, last — l'intervalle dont copier les éléments
  • other — autre conteneur servant de source pour initialiser les éléments du conteneur
  • init — liste d'initialisation pour initialiser les éléments du conteneur
  • rg — un intervalle compatible avec le conteneur

Complexité

1,2) Constante.

3,4) Linéaire en count.

  1. Linéaire en std::distance(first, last).

  2. Linéaire en ranges::distance(rg).

  3. Linéaire en other.size().

  4. Constante.

  5. Linéaire en other.size().

  6. Linéaire en other.size() si alloc != other.get_allocator(), sinon constante.

  7. Linéaire en init.size().

Exceptions

Les appels à Allocator::allocate peuvent lever une exception.

Notes

Après la construction par déplacement du conteneur (surcharge (8)), les références, pointeurs et itérateurs (autres que l'itérateur de fin) vers other restent valides, mais désignent des éléments qui sont désormais dans *this. La norme actuelle fournit cette garantie via l'énoncé général de [container.reqmts]/67, et une garantie plus directe est à l'étude via LWG issue 2321.

Exemple

#include <forward_list>
#include <iostream>
#include <string>

template<typename T>
std::ostream& operator<<(std::ostream& s, const std::forward_list<T>& v)
{
    s.put('{');
    for (char comma[]{'\0', ' ', '\0'}; const auto& e : v)
        s << comma << e, comma[0] = ',';
    return s << "}\n";
}

int main()
{
    // Syntaxe de liste d'initialisation C++11 :
    std::forward_list<std::string> words1{"the", "frogurt", "is", "also", "cursed"};
    std::cout << "1: " << words1;

    // words2 == words1
    std::forward_list<std::string> words2(words1.begin(), words1.end());
    std::cout << "2: " << words2;

    // words3 == words1
    std::forward_list<std::string> words3(words1);
    std::cout << "3: " << words3;

    // words4 vaut {"Mo", "Mo", "Mo", "Mo", "Mo"}
    std::forward_list<std::string> words4(5, "Mo");
    std::cout << "4: " << words4;

    const auto rg = {"cat", "cow", "crow"};
#ifdef __cpp_lib_containers_ranges
    std::forward_list<std::string> words5(std::from_range, rg); // overload (6)
#else
    std::forward_list<std::string> words5(rg.begin(), rg.end()); // overload (5)
#endif
    std::cout << "5: " << words5;
}

Output:

1: {the, frogurt, is, also, cursed}
2: {the, frogurt, is, also, cursed}
3: {the, frogurt, is, also, cursed}
4: {Mo, Mo, Mo, Mo, Mo}
5: {cat, cow, crow}

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
