std::forward_list<T,Allocator>::remove, remove_if

void remove( const T& value );  // (depuis C++11) (jusqu'à C++20)

size_type remove( const T& value );  // (depuis C++20)

template< class UnaryPredicate >
void remove_if( UnaryPredicate p );  // (depuis C++11) (jusqu'à C++20)

template< class UnaryPredicate >
size_type remove_if( UnaryPredicate p );  // (depuis C++20)

Supprime tous les éléments satisfaisant des critères donnés. N'invalide que les itérateurs et références vers les éléments supprimés.

  1. Supprime tous les éléments égaux à value (en utilisant operator==).

  2. Supprime tous les éléments pour lesquels le prédicat p retourne true.

Paramètres

  • value — valeur des éléments à supprimer

  • p — prédicat unaire qui renvoie true si l'élément doit être supprimé.

    L'expression p(v) doit être convertible en bool pour chaque argument v de type (éventuellement const) T, quelle que soit la catégorie de valeur, et ne doit pas modifier v. Ainsi, un type de paramètre T&n'est pas autorisé, ni T sauf si pour T un déplacement équivaut à une copie (depuis C++11).

Exigences sur les types

  • UnaryPredicate doit satisfaire aux exigences de Predicate.

Valeur de retour

(aucune)

(jusqu'à C++20)

Le nombre d'éléments supprimés.

(depuis C++20)

Complexité

Étant donné (\scriptsize N)N valant std::distance(begin(), end()) :

  1. Exactement (\scriptsize N)N comparaisons utilisant operator==.

  2. Exactement (\scriptsize N)N applications du prédicat p.

Exemple

#include <forward_list>
#include <iostream>

int main()
{
    std::forward_list<int> l = {1, 100, 2, 3, 10, 1, 11, -1, 12};

    auto count1 = l.remove(1);
    std::cout << count1 << " elements equal to 1 were removed\n";

    auto count2 = l.remove_if([](int n){ return n > 10; });
    std::cout << count2 << " elements greater than 10 were removed\n";

    std::cout << "Finally, the list contains: ";
    for (int n : l)
        std::cout << n << ' ';
    std::cout << '\n';
}

Output:

2 elements equal to 1 were removed
3 elements greater than 10 were removed
Finally, the list contains: 2 3 10 -1
