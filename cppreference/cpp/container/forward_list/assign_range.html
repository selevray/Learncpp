std::forward_list<T,Allocator>::assign_range

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< container-compatible-range<T> R >
void assign_range( R&& rg );  // (depuis C++23)

Remplace les éléments du conteneur par une copie de chaque élément de rg.

Tous les itérateurs (y compris l'itérateur end()) et toutes les références aux éléments sont invalidés.

Chaque itérateur de l'intervalle rg est déréférencé exactement une fois.

Le comportement est indéfini si rg chevauche le conteneur.

Paramètres

  • rg — un input_range dont le type de référence est convertible en type d'élément du conteneur

Exigences sur les types

  • std::assignable_from<T&, ranges::range_reference_t<R>> doit être modélisé. Sinon, le programme est mal formé.
  • T doit être EmplaceConstructible dans le conteneur à partir de *ranges::begin(rg). Sinon, le comportement est indéfini.

Valeur de retour

(aucune)

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_containers_ranges 202202L (C++23) Construction et insertion prenant en compte les plages

Exemple

#include <algorithm>
#include <cassert>
#include <forward_list>
#include <list>

int main()
{
    const auto source = std::list{2, 7, 1};
    auto destination = std::forward_list{3, 1, 4};
#ifdef __cpp_lib_containers_ranges
    destination.assign_range(source);
#else
    destination.assign(source.cbegin(), source.cend());
#endif
    assert(std::ranges::equal(source, destination));
}
