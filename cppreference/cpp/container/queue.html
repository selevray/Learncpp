std::queue

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <queue>

template<
    class T,
    class Container = std::deque<T>
> class queue;

Le modèle de classe std::queue est un adaptateur de conteneur qui fournit la fonctionnalité d'une file, plus précisément une structure de données FIFO (premier entré, premier sorti).

Le modèle de classe agit comme un encapsulage du conteneur sous-jacent : seul un ensemble spécifique de fonctions est fourni. La file ajoute les éléments à l'arrière du conteneur sous-jacent et les retire à l'avant.

Paramètres de modèle

  • T — Le type des éléments stockés. Le programme est mal formé si T n'est pas du même type que Container::value_type.

  • Container — Le type du conteneur sous-jacent utilisé pour stocker les éléments. Le conteneur doit satisfaire les exigences de SequenceContainer. De plus, il doit fournir les fonctions suivantes avec la sémantique habituelle :

    • back(), e.g., std::deque::back(),
    • front(), e.g. std::list::front(),
    • push_back(), e.g., std::deque::push_back(),
    • pop_front(), e.g., std::list::pop_front().

    Les conteneurs standard std::deque et std::list satisfont ces exigences.

Exemple

#include <cassert>
#include <iostream>
#include <queue>

int main()
{
    std::queue<int> q;

    q.push(0); // back ajoute 0
    q.push(1); // q = 0 1
    q.push(2); // q = 0 1 2
    q.push(3); // q = 0 1 2 3

    assert(q.front() == 0);
    assert(q.back() == 3);
    assert(q.size() == 4);

    q.pop(); // supprime l'élément de tête, 0
    assert(q.size() == 3);

    // Affiche et retire tous les éléments. Notez que std::queue ne
    // prend pas en charge begin()/end(), donc une boucle for basée sur un intervalle ne peut pas être utilisée.
    std::cout << "q: ";
    for (; !q.empty(); q.pop())
        std::cout << q.front() << ' ';
    std::cout << '\n';
    assert(q.size() == 0);
}

Output:

q: 1 2 3

DR Appliqué à Comportement publié Comportement correct

LWG 2566 C++98 Exigence manquante pour Container::value_type mal formé si T n'est pas du même type que Container::value_type
  1. ↑ Par exemple des conteneurs semblables à std::vector<bool> avec la prise en charge supplémentaire de pop_front(). La résolution de ce DR
    ajoute la prise en charge de std::vector<bool> pour std::stack et std::priority_queue. Les modifications concernant std::queue
    visent à maintenir la cohérence.
