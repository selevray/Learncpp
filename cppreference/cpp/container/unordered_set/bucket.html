std::unordered_set<Key,Hash,KeyEqual,Allocator>::bucket

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

size_type bucket( const Key& key ) const;  // (1) (depuis C++11)

template< typename K >
size_type bucket( const K& x ) const;  // (2) (depuis C++26)

  1. Renvoie l'indice du compartiment de la clé key. Les éléments (le cas échéant) dont les clés sont équivalentes à key se trouvent toujours dans ce compartiment.

  2. Renvoie l'indice du compartiment pour une clé qui se compare équivalente à la valeur x. Les éléments (le cas échéant) dont les clés se comparent comme équivalentes à x se trouvent toujours dans ce compartiment. Cette surcharge ne participe à la résolution de surcharge que si Hash::is_transparent et KeyEqual::is_transparent sont valides et désignent chacun un type. Cela suppose que ce Hash est appelable avec des arguments de type K et Key, et que le KeyEqual est transparent, ce qui permet, ensemble, d'appeler cette fonction sans construire d'instance de Key.

La valeur renvoyée n'est valide que pour les instances du conteneur pour lesquelles bucket_count() renvoie la même valeur (par exemple, rehash() invalide la valeur obtenue précédemment).

Le comportement est indéfini si bucket_count() vaut zéro.

Paramètres

  • key — la valeur de la clé à examiner
  • x — une valeur de n'importe quel type pouvant être comparée de façon transparente à une clé

Valeur de retour

Indice du compartiment de la clé demandée.

Complexité

Constante.
