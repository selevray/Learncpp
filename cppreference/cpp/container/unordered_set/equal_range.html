std::unordered_set<Key,Hash,KeyEqual,Allocator>::equal_range

1,2) Renvoie un intervalle contenant tous les éléments de clé key du conteneur. L'intervalle est défini par deux itérateurs, le premier pointant vers le premier élément de l'intervalle recherché et le second pointant au-delà du dernier élément de l'intervalle.

3,4) Renvoie un intervalle contenant tous les éléments du conteneur dont la clé est équivalente à x. Cette surcharge ne participe à la résolution de surcharge que si Hash::is_transparent et KeyEqual::is_transparent sont valides et désignent chacun un type. Cela suppose qu'un tel Hash est appelable avec les types K et Key, et que le KeyEqual est transparent, ce qui, ensemble, permet d'appeler cette fonction sans construire d'instance de Key.

Paramètres

  • key — valeur de clé à laquelle comparer les éléments
  • x — une valeur de n'importe quel type pouvant être comparée de façon transparente à une clé

Valeur de retour

std::pair contenant une paire d'itérateurs définissant l'intervalle recherché. S'il n'existe aucun tel élément, des itérateurs de fin (voir end()) sont renvoyés comme les deux éléments de la paire.

Complexité

Cas moyen linéaire en le nombre d'éléments de clé key, cas le pire linéaire en la taille du conteneur.
