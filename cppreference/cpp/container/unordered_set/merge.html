Tente d'extraire (« épisser ») chaque élément de source et de l'insérer dans *this en utilisant la fonction de hachage et le prédicat d'égalité des clés de *this. S'il existe dans *this un élément dont la clé est équivalente à la clé d'un élément de source, cet élément n'est pas extrait de source. Aucun élément n'est copié ou déplacé, seuls les pointeurs internes des nœuds du conteneur sont redirigés. Tous les pointeurs et références vers les éléments transférés restent valides, mais désignent désormais des éléments de *this, et non de source. Les itérateurs désignant les éléments transférés, ainsi que tous les itérateurs désignant *this, sont invalidés. Les itérateurs désignant les éléments restant dans source restent valides.

Le comportement est indéfini si get_allocator() != source.get_allocator().

Paramètres

  • source — conteneur compatible à partir duquel transférer les nœuds

Valeur de retour

(aucune)

Complexité

Cas moyen O(N), pire cas O(N * size() + N), où N est source.size().

Exemple

#include <iostream>
#include <unordered_set>

// afficher un conteneur
template<class Os, class K>
Os& operator<<(Os& os, const std::unordered_set<K>& v)
{
    os << '[' << v.size() << "] {";
    bool o{};
    for (const auto& e : v)
        os << (o ? ", " : (o = 1, " ")) << e;
    return os << " }\n";
}

int main()
{
    std::unordered_set<char>
        p{'C', 'B', 'B', 'A'},
        q{'E', 'D', 'E', 'C'};

    std::cout << "p: " << p << "q: " << q;

    p.merge(q);

    std::cout << "p.merge(q);\n" << "p: " << p << "q: " << q;
}

Sortie possible :

p: [3] { A, B, C }
q: [3] { C, D, E }
p.merge(q);
p: [5] { E, D, A, B, C }
q: [1] { C }
