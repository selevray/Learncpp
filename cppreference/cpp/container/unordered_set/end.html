Retourne un itérateur vers l'élément suivant le dernier élément du unordered_set.

Cet élément sert de marqueur ; tenter d'y accéder entraîne un comportement indéfini.

range-begin-end.svg

Paramètres

(aucune)

Valeur de retour

Itérateur vers l'élément suivant le dernier élément.

Complexité

Constante.

Notes

Comme iterator et const_iterator sont des itérateurs constants (et peuvent en fait être du même type), il n'est pas possible de modifier les éléments du conteneur via un itérateur renvoyé par l'une de ces fonctions membres.

Exemple

#include <iostream>
#include <unordered_set>

struct Point { double x, y; };

int main()
{
    Point pts[3] = {{1, 0}, {2, 0}, {3, 0}};

    // points est un ensemble contenant les adresses de points
    std::unordered_set<Point*> points = { pts, pts + 1, pts + 2 };

    // Remplace chaque coordonnée y de (i, 0) par i^2 et affiche le point
    for (auto iter = points.begin(); iter != points.end(); ++iter)
    {
        (*iter)->y = ((*iter)->x) * ((*iter)->x); // iter est un pointeur vers Point*
        std::cout << "(" << (*iter)->x << ", " << (*iter)->y << ") ";
    }
    std::cout << '\n';

    // Maintenant, avec la boucle basée sur l'intervalle, on augmente chaque coordonnée y de 10
    for (Point* i : points)
    {
        i->y += 10;
        std::cout << "(" << i->x << ", " << i->y << ") ";
    }
}

Sortie possible :

(3, 9) (1, 1) (2, 4)
(3, 19) (1, 11) (2, 14)
