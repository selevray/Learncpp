std::unordered_set<Key,Hash,KeyEqual,Allocator>::find

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

iterator find( const Key& key );  // (1) (depuis C++11)

const_iterator find( const Key& key ) const;  // (2) (depuis C++11)

template< class K >
iterator find( const K& x );  // (3) (depuis C++20)

template< class K >
const_iterator find( const K& x ) const;  // (4) (depuis C++20)

1,2) Trouve un élément dont la clé est équivalente à key.

3,4) Recherche un élément dont la clé est équivalente à la valeur x. Cette surcharge ne participe à la résolution de surcharge que si Hash::is_transparent et KeyEqual::is_transparent sont valides et désignent chacun un type. Cela suppose qu'un tel Hash est appelable avec les types K et Key, et que le KeyEqual est transparent, ce qui, ensemble, permet d'appeler cette fonction sans construire d'instance de Key.

Paramètres

  • key — valeur de clé de l'élément à rechercher
  • x — une valeur de n'importe quel type pouvant être comparée de façon transparente à une clé

Valeur de retour

Un itérateur vers l'élément demandé. Si aucun élément de ce type n'est trouvé, l'itérateur past-the-end (voir end()) est renvoyé.

Complexité

Constante en moyenne, linéaire au pire par rapport à la taille du conteneur.

Exemple

#include <cstddef>
#include <functional>
#include <iostream>
#include <source_location>
#include <string>
#include <string_view>
#include <unordered_set>

using namespace std::literals;

namespace logger { bool enabled{false}; }

inline void who(const std::source_location sloc = std::source_location::current())
{
    if (logger::enabled)
        std::cout << sloc.function_name() << '\n';
}

struct string_hash // Hachage transparent de C++20
{
    using hash_type = std::hash<std::string_view>;
    using is_transparent = void;

    std::size_t operator()(const char* str) const
    {
        who();
        return hash_type{}(str);
    }
    std::size_t operator()(std::string_view str) const
    {
        who();
        return hash_type{}(str);
    }
    std::size_t operator()(std::string const& str) const
    {
        who();
        return hash_type{}(str);
    }
};

int main()
{
    std::unordered_set<int> example{1, 2, -10};

    std::cout << "Simple comparison demo:\n" << std::boolalpha;
    if (auto search = example.find(2); search != example.end())
        std::cout << "Found " << *search << '\n';
    else
        std::cout << "Not found\n";

    std::unordered_set<std::string, string_hash, std::equal_to<>> set{"one"s, "two"s};

    logger::enabled = true;
    std::cout << "Heterogeneous lookup for unordered containers (transparent hashing):\n"
              << (set.find("one")   != set.end()) << '\n'
              << (set.find("one"s)  != set.end()) << '\n'
              << (set.find("one"sv) != set.end()) << '\n';
}
