1-6) Ces guides de déduction sont fournis pour unordered_set afin de permettre la déduction à partir d'un intervalle d'itérateurs (surcharges (1,3,4)) et std::initializer_list (surcharges (2,5,6)). Cette surcharge ne participe à la résolution de surcharge que si InputIt satisfait LegacyInputIterator, Alloc satisfait Allocator, ni Hash ni Pred ne satisfont Allocator, Hash n'est pas un type entier.

7-10) Ces guides de déduction sont fournis pour unordered_set afin de permettre la déduction à partir d'une étiquette std::from_range_t et d'un input_range.

Remarque : la mesure dans laquelle la bibliothèque détermine qu'un type ne satisfait pas LegacyInputIterator n'est pas spécifiée, sauf qu'au minimum les types entiers ne sont pas qualifiés comme itérateurs d'entrée. De même, la mesure dans laquelle elle détermine qu'un type ne satisfait pas Allocator n'est pas spécifiée, sauf qu'au minimum le type membre Alloc::value_type doit exister et l'expression std::declval<Alloc&>().allocate(std::size_t{}) doit être bien formée lorsqu'elle est traitée comme opérande non évalué.

Le type du paramètre size_type dans ces guides fait référence au type membre size_type du type déduit par le guide de déduction.
