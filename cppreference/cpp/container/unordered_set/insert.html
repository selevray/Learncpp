Insère un ou plusieurs éléments dans le conteneur, si celui-ci ne contient pas déjà un élément avec une clé équivalente.

1,2) Insère value.

3,4) Insère value, en utilisant hint comme suggestion non contraignante quant à l'endroit où la recherche doit commencer.

  1. Insère les éléments de l'intervalle [first,last). Si plusieurs éléments de l'intervalle ont des clés équivalentes, il n'est pas spécifié lequel est inséré (en attente de LWG2844).

  2. Insère les éléments de la liste d'initialisation ilist. Si plusieurs éléments de l'intervalle ont des clés équivalentes, il n'est pas spécifié lequel est inséré (en attente de LWG2844).

  3. Si nh est un node handle vide, ne fait rien. Sinon, insère l'élément possédé par nh dans le conteneur , si celui-ci ne contient pas déjà un élément avec une clé équivalente à nh.key(). Le comportement est indéfini si nh n'est pas vide et que get_allocator() != nh.get_allocator().

  4. Si nh est un handle de nœud vide, ne fait rien et renvoie l'itérateur de fin. Sinon, insère dans le conteneur l'élément possédé par nh, si le conteneur ne contient pas déjà un élément dont la clé est équivalente à nh.key(), et renvoie l'itérateur pointant vers l'élément de clé équivalente à nh.key() (que l'insertion ait réussi ou échoué). Si l'insertion réussit, nh est déplacé, sinon il conserve la possession de l'élément. hint est utilisé comme suggestion non contraignante quant à l'endroit où la recherche doit commencer. Le comportement est indéfini si nh n'est pas vide et get_allocator() != nh.get_allocator().

  5. Si *this contient déjà un élément qui se compare de manière transparente équivalent à obj, ne fait rien. Sinon, construit un objet u de value_type avec std::forward<K>(obj), puis insère u dans *this. Si equal_range(u) != hash_function()(obj) || contains(u) vaut true, le comportement est indéfini. Le value_type doit être EmplaceConstructible dans unordered_set à partir de std::forward<K>(obj). Cette surcharge ne participe à la résolution de surcharge que si Hash::is_transparent et KeyEqual::is_transparent sont valides et désignent chacun un type. Cela suppose que ce Hash est appelable avec les types K et Key, et que le KeyEqual est transparent, ce qui, ensemble, permet d'appeler cette fonction sans construire d'instance de Key.

  6. Si *this contient déjà un élément qui se compare de manière transparente équivalent à obj, ne fait rien.

Sinon, construit un objet u de value_type avec std::forward<K>(obj), puis insère u dans *this. Template:hint est utilisé comme suggestion non contraignante indiquant où la recherche doit commencer. Si equal_range(u) != hash_function()(obj) || contains(u) vaut true, le comportement est indéfini. Le value_type doit être EmplaceConstructible dans unordered_set à partir de std::forward<K>(obj). Cette surcharge ne participe à la résolution de surcharge que si :

  • std::is_convertible_v<K&&, const_iterator> et std::is_convertible_v<K&&, iterator> sont tous deux false, et
  • Hash::is_transparent et KeyEqual::is_transparent sont valides et désignent chacun un type. Cela suppose que ce Hash est appelable avec les types K et Key, et que le KeyEqual est transparent,

ce qui, ensemble, permet d'appeler cette fonction sans construire d'instance de Key.

Si après l'opération le nouveau nombre d'éléments est supérieur à l'ancien max_load_factor() * bucket_count(), une réorganisation (rehashing) a lieu.
Si une réorganisation se produit (due à l'insertion), tous les itérateurs sont invalidés. Sinon (pas de réorganisation), les itérateurs ne sont pas invalidés. Si l'insertion réussit, les pointeurs et références vers l'élément obtenus pendant qu'il est détenu par le handle de nœud sont invalidés, et les pointeurs et références obtenus vers cet élément avant son extraction redeviennent valides. (depuis C++17)

Paramètres

  • hint — itérateur, utilisé comme suggestion quant à l'endroit où insérer le contenu
  • value — valeur de l'élément à insérer
  • first, last — intervalle d'éléments à insérer
  • ilist — liste d'initialisation à partir de laquelle insérer les valeurs
  • nh — un node handle compatible
  • obj — une valeur de n'importe quel type pouvant être comparée de façon transparente à une clé

Exigences sur les types

  • InputIt doit satisfaire aux exigences de LegacyInputIterator.

Valeur de retour

1,2) Une paire composée d'un itérateur vers l'élément inséré (ou vers l'élément qui a empêché l'insertion) et d'une valeur bool égale à true si et seulement si l'insertion a eu lieu.

3,4) Un itérateur vers l'élément inséré, ou vers l'élément qui a empêché l'insertion.

5,6) (aucun)

  1. Un objet de insert_return_type dont les membres sont initialisés comme suit :
  • Si nh est vide, inserted vaut false, position vaut end(), et node est vide.
  • Sinon, si l'insertion a eu lieu, inserted vaut true, position pointe vers l'élément inséré, et node est vide.
  • Si l'insertion a échoué, inserted vaut false, node a la valeur précédente de nh, et position pointe vers un élément de clé équivalente à nh.key().

  1. Itérateur de fin si nh était vide, itérateur pointant vers l'élément inséré si l'insertion a eu lieu, et itérateur pointant vers un élément de clé équivalente à nh.key() en cas d'échec.

  2. Une paire composée d'un itérateur vers l'élément inséré (ou vers l'élément qui a empêché l'insertion) et d'une valeur bool égale à true si et seulement si l'insertion a eu lieu.

  3. Un itérateur vers l'élément inséré, ou vers l'élément qui a empêché l'insertion.

Exceptions

1-4) Si une exception est levée par une opération quelconque, l'insertion n'a aucun effet.

Complexité

1-4) Cas moyen : O(1), cas le pire O(size()).

5,6) Cas moyen : O(N), où N est le nombre d'éléments à insérer. Cas le pire : O(N * size() + N).

7-10) Cas moyen : O(1), cas le pire O(size()).

Notes

L'insertion avec indication (3,4) ne renvoie pas de booléen afin d'avoir la même signature que l'insertion positionnelle des conteneurs séquentiels, tels que std::vector::insert. Cela permet de créer des insertion génériques comme std::inserter. Une façon de vérifier le succès d'une insertion avec indication consiste à comparer size() avant et après.

Exemple

#include <array>
#include <iostream>
#include <unordered_set>

std::ostream& operator<<(std::ostream& os, std::unordered_set<int> const& s)
{
    for (os << '[' << s.size() << "] { "; int i : s)
        os << i << ' ';
    return os << "}\n";
}

int main ()
{
    std::unordered_set<int> nums{2, 3, 4};

    std::cout << "1) Initially: " << nums << std::boolalpha;
    auto p = nums.insert(1); // insérer un élément, surcharge (1)
    std::cout << "2) '1' was inserted: " << p.second << '\n';
    std::cout << "3) After insertion: " << nums;

    nums.insert(p.first, 0); // insérer avec indication, surcharge (3)
    std::cout << "4) After insertion: " << nums;

    std::array<int, 4> a = {10, 11, 12, 13};
    nums.insert(a.begin(), a.end()); // insérer un intervalle, surcharge (5)
    std::cout << "5) After insertion: " << nums;

    nums.insert({20, 21, 22, 23}); // insérer initializer_list, (6)
    std::cout << "6) After insertion: " << nums;

    std::unordered_set<int> other_nums = {42, 43};
    auto node = other_nums.extract(other_nums.find(42));
    nums.insert(std::move(node)); // insérer un nœud, surcharge (7)
    std::cout << "7) After insertion: " << nums;

    node = other_nums.extract(other_nums.find(43));
    nums.insert(nums.begin(), std::move(node)); // insérer un nœud avec indication, (8)
    std::cout << "8) After insertion: " << nums;
}
