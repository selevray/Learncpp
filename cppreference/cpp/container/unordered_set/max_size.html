std::unordered_set<Key,Hash,KeyEqual,Allocator>::max_size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

size_type max_size() const noexcept;  // (depuis C++11)

Renvoie le nombre maximal d'éléments que le conteneur peut contenir en raison des limites du système ou de l'implémentation de la bibliothèque, c.-à-d. std::distance(begin(), end()) pour le plus grand conteneur.

Paramètres

(aucune)

Valeur de retour

Nombre maximal d'éléments.

Complexité

Constante.

Notes

Cette valeur reflète généralement la limite théorique de la taille du conteneur, au plus std::numeric_limits<difference_type>::max(). À l'exécution, la taille du conteneur peut être limitée à une valeur inférieure à max_size() par la quantité de RAM disponible.

Exemple

#include <iostream>
#include <locale>
#include <unordered_set>

int main()
{
    std::unordered_set<char> p;
    std::unordered_set<long> q;

    std::cout.imbue(std::locale("en_US.UTF-8"));
    std::cout << std::uppercase
              << "p.max_size() = " << std::dec << p.max_size() << " = 0x"
              << std::hex << p.max_size() << '\n'
              << "q.max_size() = " << std::dec << q.max_size() << " = 0x"
              << std::hex << q.max_size() << '\n';
}

Sortie possible :

p.max_size() = 1,152,921,504,606,846,975 = 0xFFF,FFF,FFF,FFF,FFF
q.max_size() = 1,152,921,504,606,846,975 = 0xFFF,FFF,FFF,FFF,FFF
