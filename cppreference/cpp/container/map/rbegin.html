reverse_iterator rbegin();  // (1) (noexcept depuis C++11)

const_reverse_iterator rbegin() const;  // (2) (noexcept depuis C++11)

const_reverse_iterator crbegin() const noexcept;  // (3) (depuis C++11)

Retourne un itérateur inverse vers le premier élément du map inversé. Il correspond au dernier élément du map non inversé. Si le map est vide, l'itérateur retourné est égal à rend().

range-rbegin-rend.svg

Paramètres

(aucune)

Valeur de retour

Itérateur inverse vers le premier élément.

Complexité

Constante.

Notes

Le itérateur sous-jacent de l'itérateur inverse renvoyé est l'itérateur de fin. Par conséquent, l'itérateur renvoyé est invalidé si et quand l'itérateur de fin est invalidé.

libc++ rétroporte crbegin() au mode C++98.

Exemple

#include <iomanip>
#include <iostream>
#include <string_view>
#include <map>

int main()
{
    const std::map<int, std::string_view> coins
    {
        {10, "dime"},
        {100, "dollar"},
        {50, "half dollar"},
        {5, "nickel"},
        {1, "penny"},
        {25, "quarter"}
    }; // entrées d'initialisation dans l'ordre alphabétique des noms

    std::cout << "US coins in circulation, largest to smallest denomination:\n";
    for (auto it = coins.crbegin(); it != coins.crend(); ++it)
        std::cout << std::setw(11) << it->second << " = ¢" << it->first << '\n';
}

Output:

US coins in circulation, largest to smallest denomination:
     dollar = ¢100
half dollar = ¢50
    quarter = ¢25
       dime = ¢10
     nickel = ¢5
      penny = ¢1
