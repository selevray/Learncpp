std::map<Key,T,Compare,Allocator>::erase

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

iterator erase( iterator pos );  // (1)

iterator erase( const_iterator pos );  // (2) (depuis C++11)

iterator erase( iterator first, iterator last );  // (jusqu'à C++11)

iterator erase( const_iterator first, const_iterator last );  // (depuis C++11)

size_type erase( const Key& key );  // (4)

template< class K >
size_type erase( K&& x );  // (5) (depuis C++23)

Supprime les éléments spécifiés du conteneur.

1,2) Supprime l'élément en pos.

  1. Supprime les éléments de l'intervalle [first,last), qui doit être un intervalle valide dans *this.

  2. Supprime l'élément (s'il existe) dont la clé est équivalente à key.

  3. Supprime tous les éléments dont la clé est équivalente à la valeur x. Cette surcharge ne participe à la résolution de surcharge que si le qualified-id Compare::is_transparent est valide et désigne un type, et que ni iterator ni const_iterator ne sont convertibles implicitement depuis K. Elle permet d'appeler cette fonction sans construire une instance de Key.

Les références et les itérateurs vers les éléments effacés sont invalidés. Les autres références et itérateurs ne sont pas affectés.

L'itérateur pos doit être valide et déréférençable. Ainsi, l'itérateur end() (qui est valide mais n'est pas déréférençable) ne peut pas être utilisé comme valeur pour pos.

Paramètres

  • pos — itérateur vers l'élément à supprimer
  • first, last — plage d'éléments à supprimer
  • key — valeur de clé des éléments à supprimer
  • x — une valeur de tout type pouvant être comparée de manière transparente à une clé désignant les éléments à supprimer

Valeur de retour

1-3) Itérateur suivant le dernier élément supprimé.

  1. Nombre d'éléments supprimés (0 ou 1).

  2. Nombre d'éléments supprimés.

Exceptions

1-3) Ne lève aucune exception.

4,5) Toute exception levée par l'objet Compare.

Complexité

Étant donné une instance c de map :

1,2) Constante amortie

  1. log(c.size()) + std::distance(first, last)

  2. log(c.size()) + c.count(key)

  3. log(c.size()) + c.count(x)

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité

Exemple

#include <map>
#include <iostream>

int main()
{
    std::map<int, std::string> c =
    {
        {1, "one"}, {2, "two"}, {3, "three"},
        {4, "four"}, {5, "five"}, {6, "six"}
    };

    // supprime tous les nombres impairs de c
    for (auto it = c.begin(); it != c.end();)
    {
        if (it->first % 2 != 0)
            it = c.erase(it);
        else
            ++it;
    }

    for (auto& p : c)
        std::cout << p.second << ' ';
    std::cout << '\n';
}

Output:

two four six

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 130 C++98 la type de retour des surcharges (1) et (3) était void (ce qui n'est pas cohérent avec l'exigence erase() sur les conteneurs de séquence) corrigé en iterator
LWG 2059 C++11 remplacer la surcharge (1) par la surcharge (2) a introduit une nouvelle ambiguïté rétabli la surcharge (1)
