Tente d'extraire (« épisser ») chaque élément de source et de l'insérer dans *this en utilisant l'objet de comparaison de *this. S'il existe un élément dans *this dont la clé est équivalente à la clé d'un élément de source, alors cet élément n'est pas extrait de source. Aucun élément n'est copié ou déplacé ; seuls les pointeurs internes des nœuds du conteneur sont redirigés. Tous les pointeurs et références vers les éléments transférés restent valides, mais désignent désormais des éléments de *this, et non de source.

Le comportement est indéfini si get_allocator() != source.get_allocator().

Paramètres

  • source — conteneur compatible à partir duquel transférer les nœuds

Valeur de retour

(aucune)

Exceptions

Ne lève pas d'exception sauf si la comparaison en lève une.

Complexité

N * log(size() + N)), où N est source.size().

Exemple

#include <iostream>
#include <map>
#include <string>

int main()
{
    std::map<int, std::string> ma{{1, "apple"}, {5, "pear"}, {10, "banana"}};
    std::map<int, std::string> mb{{2, "zorro"}, {4, "batman"}, {5, "X"}, {8, "alpaca"}};
    std::map<int, std::string> u;
    u.merge(ma);
    std::cout << "ma.size(): " << ma.size() << '\n';
    u.merge(mb);
    std::cout << "mb.size(): " << mb.size() << '\n';
    std::cout << "mb.at(5): " << mb.at(5) << '\n';
    for (auto const& kv : u)
        std::cout << kv.first << ", " << kv.second << '\n';
}

Output:

ma.size(): 0
mb.size(): 1
mb.at(5): X
1, apple
2, zorro
4, batman
5, pear
8, alpaca
10, banana
