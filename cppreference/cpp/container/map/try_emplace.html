Si une clé équivalente à k existe déjà dans le conteneur, ne fait rien. Sinon, insère un nouvel élément dans le conteneur avec la clé k et une valeur construite avec args. Dans ce cas :

  1. Se comporte comme emplace, sauf que l'élément est construit comme
    value_type(std::piecewise_construct, std::forward_as_tuple(k), std::forward_as_tuple(std::forward<Args>(args)...))

  2. Se comporte comme emplace, sauf que l'élément est construit comme
    value_type(std::piecewise_construct, std::forward_as_tuple(std::move(k)), std::forward_as_tuple(std::forward<Args>(args)...))

  3. Se comporte comme emplace, sauf que l'élément est construit comme
    value_type(std::piecewise_construct, std::forward_as_tuple(std::forward<K>(k)), std::forward_as_tuple(std::forward<Args>(args)...))

  4. Se comporte comme emplace_hint, sauf que l'élément est construit comme
    value_type(std::piecewise_construct, std::forward_as_tuple(k), std::forward_as_tuple(std::forward<Args>(args)...))

  5. Se comporte comme emplace_hint, sauf que l'élément est construit comme
    value_type(std::piecewise_construct, std::forward_as_tuple(std::move(k)), std::forward_as_tuple(std::forward<Args>(args)...))

  6. Se comporte comme emplace_hint, sauf que l'élément est construit comme
    value_type(std::piecewise_construct, std::forward_as_tuple(std::forward<K>(k)), std::forward_as_tuple(std::forward<Args>(args)...))

1-6) Si value_type n'est pas EmplaceConstructible dans map à partir de l'expression correspondante, le comportement est indéfini.

  1. Cette surcharge ne participe à la résolution de surcharge que si toutes les conditions suivantes sont satisfaites :
  • std::is_convertible_v<K&&, const_iterator> et std::is_convertible_v<K&&, iterator> sont tous deux false.
  • L'identifiant qualifié Compare::is_transparent est valide et désigne un type.

Si equal_range(u.first) == equal_range(k) est false, le comportement est indéfini, où u est le nouvel élément à insérer.

  1. Cette surcharge ne participe à la résolution de surcharge que si l'id qualifié Compare::is_transparent est valide et désigne un type.

Si equal_range(u.first) == equal_range(k) est false, le comportement est indéfini, où u est le nouvel élément à insérer.

Aucun itérateur ni aucune référence n'est invalidé.

Paramètres

  • k — la clé utilisée à la fois pour la recherche et pour l'insertion si elle n'est pas trouvée
  • hint — itérateur vers la position avant laquelle le nouvel élément sera inséré
  • args — arguments à transmettre au constructeur de l'élément

Valeur de retour

1-3) Identique à emplace :
Une paire composée d'un itérateur vers l'élément inséré (ou vers l'élément qui a empêché l'insertion) et d'une valeur bool égale à true si et seulement si l'insertion a eu lieu.

4-6) Identique à emplace_hint :
Un itérateur vers l'élément inséré, ou vers l'élément qui a empêché l'insertion.

Complexité

1-3) Identique à emplace :
Logarithmique en fonction de la taille du conteneur.

4-6) Identique à emplace_hint :
Logarithmique en fonction de la taille du conteneur en général, mais constante amortie si le nouvel élément est inséré juste avant hint.

Notes

Contrairement à insert ou emplace, ces fonctions ne déplacent pas les arguments rvalue si l'insertion n'a pas lieu, ce qui permet de manipuler facilement des tables dont les valeurs sont de types non copiables, tels que std::map<std::string, std::unique_ptr<foo>>. De plus, try_emplace traite la clé et les arguments de mapped_type séparément, contrairement à emplace, qui exige que les arguments construisent un value_type (c'est-à-dire un std::pair).

Les surcharges (3,6) peuvent être appelées sans construire d'objet de type Key.

Exemple

#include <iostream>
#include <string>
#include <map>
#include <utility>

void print_node(const auto& node)
{
    std::cout << '[' << node.first << "] = " << node.second << '\n';
}

void print_result(auto const& pair)
{
    std::cout << (pair.second ? "inserted: " : "ignored:  ");
    print_node(*pair.first);
}

int main()
{
    using namespace std::literals;
    std::map<std::string, std::string> m;

    print_result(m.try_emplace("a", "a"s));
    print_result(m.try_emplace("b", "abcd"));
    print_result(m.try_emplace("c", 10, 'c'));
    print_result(m.try_emplace("c", "Won't be inserted"));

    for (const auto& p : m)
        print_node(p);
}

Output:

inserted: [a] = a
inserted: [b] = abcd
inserted: [c] = cccccccccc
ignored:  [c] = cccccccccc
[a] = a
[b] = abcd
[c] = cccccccccc
