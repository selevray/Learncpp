std::stack

Défini dans l'en-tête <stack>

template<
    class T,
    class Container = std::deque<T>
> class stack;

La classe std::stack est un adaptateur de conteneur qui offre au programmeur les fonctionnalités d'une pile, plus précisément une structure de données LIFO (last-in, first-out).

Le modèle de classe agit comme un enveloppeur du conteneur sous-jacent : seul un ensemble spécifique de fonctions est fourni. La pile ajoute et retire les éléments à l'arrière du conteneur sous-jacent, appelé sommet de la pile.

Paramètres de modèle

  • T — Le type des éléments stockés. Le programme est mal formé si T n'est pas du même type que Container::value_type.

  • Container — Le type du conteneur sous-jacent utilisé pour stocker les éléments. Le conteneur doit satisfaire les exigences de SequenceContainer. De plus, il doit fournir les fonctions suivantes avec la sémantique habituelle :

    • back(), e.g., std::vector::back(),
    • push_back(), e.g., std::deque::push_back(),
    • pop_back(), e.g., std::list::pop_back().

    Les conteneurs standard std::vector (y compris std::vector<bool>), std::deque et std::list satisfont ces exigences. Par défaut, si aucune classe de conteneur n'est spécifiée pour une instanciation donnée de la classe pile, le conteneur standard std::deque est utilisé.
