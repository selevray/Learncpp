Retourne un itérateur vers le premier élément du set.

Si le set est vide, l'itérateur retourné sera égal à end().

range-begin-end.svg

Paramètres

(aucune)

Valeur de retour

Itérateur vers le premier élément.

Complexité

Constante.

Notes

Comme iterator et const_iterator sont des itérateurs constants (et peuvent en fait être du même type), il n'est pas possible de modifier les éléments du conteneur via un itérateur renvoyé par l'une de ces fonctions membres.

libc++ rétroporte cbegin() au mode C++98.

Exemple

#include <algorithm>
#include <iostream>
#include <set>

int main()
{
    std::set<int> set{3, 1, 4, 1, 5, 9, 2, 6, 5};
    std::for_each(set.cbegin(), set.cend(), [](int x)
    {
        std::cout << x << ' ';
    });
    std::cout << '\n';
}

Output:

1 2 3 4 5 6 9
