std::set<Key,Compare,Allocator>::count

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

size_type count( const Key& key ) const;  // (1)

template< class K >
size_type count( const K& x ) const;  // (2) (depuis C++14)

Renvoie le nombre d'éléments dont la clé se compare équivalente à l'argument spécifié.

  1. Renvoie le nombre d'éléments de clé key. Ce nombre vaut 1 ou 0, car ce conteneur n'autorise pas les doublons.

  2. Renvoie le nombre d'éléments dont la clé se compare équivalente à la valeur x. Cette surcharge participe à la résolution de surcharge uniquement si le qualified-id Compare::is_transparent est valide et désigne un type. Cela permet d'appeler cette fonction sans construire d'instance de Key.

Paramètres

  • key — valeur de clé des éléments à compter
  • x — valeur alternative à comparer aux clés

Valeur de retour

Nombre d'éléments dont la clé se compare équivalente à key ou x, ce nombre valant, pour la surcharge (1), 1 ou 0.

Complexité

Logarithmique en la taille du conteneur, plus linéaire en le nombre d'éléments trouvés.

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_generic_associative_lookup 201304L (C++14) Recherche de comparaison hétérogène dans les conteneurs associatifs ; surcharge (2)

Exemple

#include <functional>
#include <iostream>
#include <set>

struct S
{
    int x;
    S(int i) : x{i} { std::cout << "S{" << i << "} "; }
    bool operator<(S const& s) const { return x < s.x; }
};

struct R
{
    int x;
    R(int i) : x{i} { std::cout << "R{" << i << "} "; }
    bool operator<(R const& r) const { return x < r.x; }
};

bool operator<(R const& r, int i) { return r.x < i; }
bool operator<(int i, R const& r) { return i < r.x; }

int main()
{
    std::set<int> t{3, 1, 4, 1, 5};
    std::cout << t.count(1) << ", " << t.count(2) << ".\n";

    std::set<S> s{3, 1, 4, 1, 5};
    std::cout << ": " << s.count(1) << ", " << s.count(2) << ".\n";
        // Deux objets temporaires S{1} et S{2} ont été créés.
        // L'objet fonction de comparaison est par défaut std::less<S>,
        // qui n'est pas transparent (n'a pas de type membre is_transparent).

    std::set<R, std::less<>> r{3, 1, 4, 1, 5};
    std::cout << ": " << r.count(1) << ", " << r.count(2) << ".\n";
        // Recherche hétérogène C++14 ; aucun objet temporaire n'a été créé.
        // Le comparateur std::less<void> possède déjà is_transparent prédéfini.
}

Output:

1, 0.
S{3} S{1} S{4} S{1} S{5} : S{1} 1, S{2} 0.
R{3} R{1} R{4} R{1} R{5} : 1, 0.
