Construit un nouveau conteneur à partir de diverses sources de données, en utilisant éventuellement l'allocateur fourni par l'utilisateur alloc ou l'objet fonction de comparaison comp.

1-3) Construit un conteneur vide.

4,5) Construit le conteneur avec le contenu de l'intervalle [first,last). Si plusieurs éléments de l'intervalle ont des clés équivalentes selon la comparaison, l'élément inséré n'est pas spécifié (en attente de LWG2844).

Si [first,last) n'est pas un intervalle valide, le comportement est indéfini.

6,7) Constructeur de copie. Construit le conteneur avec une copie du contenu de other.

Si alloc n'est pas fourni, l'allocateur est obtenu en appelant std::allocator_traits<allocator_type>:: select_on_container_copy_construction(other.get_allocator()).

(depuis C++11)

Lors de la déduction d'arguments de modèle de classe, seul le premier argument contribue à la déduction du paramètre de modèle Allocator du conteneur.

(depuis C++23)

8,9) Constructeur de déplacement. Construit le conteneur avec le contenu de other en utilisant la sémantique de déplacement. Si alloc n'est pas fourni, l'allocateur est obtenu par construction par déplacement à partir de l'allocateur appartenant à other.

Lors de la déduction d'arguments de modèle de classe, seul le premier argument contribue à la déduction du paramètre de modèle Allocator du conteneur.

(depuis C++23)

10,11) Constructeur à partir d'une liste d'initialisation. Construit le conteneur avec le contenu de la liste d'initialisation init.Si plusieurs éléments de l'intervalle ont des clés équivalentes selon la comparaison, l'élément inséré n'est pas spécifié (en attente de LWG2844).

12,13) Construit le conteneur avec le contenu de rg. Si plusieurs éléments de l'intervalle ont des clés équivalentes selon la comparaison, l'élément inséré n'est pas spécifié (en attente de LWG2844).

Paramètres

  • alloc — allocateur à utiliser pour toutes les allocations mémoire de ce conteneur
  • comp — objet fonction de comparaison à utiliser pour toutes les comparaisons de clés
  • first, last — l'intervalle dont copier les éléments
  • other — autre conteneur servant de source pour initialiser les éléments du conteneur
  • init — liste d'initialisation pour initialiser les éléments du conteneur
  • rg — un intervalle compatible avec le conteneur, c'est-à-dire un input_range dont les éléments sont convertibles en value_type

Exigences sur les types

  • InputIt doit satisfaire aux exigences de LegacyInputIterator.
  • Compare doit satisfaire aux exigences de Compare.
  • Allocator doit satisfaire aux exigences de Allocator.

Complexité

1-3) Constante.

4,5) (\scriptsize N \cdot log(N))N·log(N) où (\scriptsize N)N est std::distance(first, last) en général, linéaire en (\scriptsize N)N si [first,last) est déjà trié selon value_comp().

6,7) Linéaire en la taille de other.

8,9) Constante. Si alloc est donné et alloc != other.get_allocator(), alors linéaire.

10,11) (\scriptsize N \cdot log(N))N·log(N) où (\scriptsize N)N est init.size() en général, linéaire en (\scriptsize N)N si init est déjà trié selon value_comp().

12,13) (\scriptsize N \cdot log(N))N·log(N) où (\scriptsize N)N est ranges::distance(rg) en général, linéaire en (\scriptsize N)N si rg est déjà trié selon value_comp().

Exceptions

Les appels à Allocator::allocate peuvent lever une exception.

Notes

Après la construction par déplacement du conteneur (surcharge (8,9)), les références, pointeurs et itérateurs (autres que l'itérateur de fin) vers other restent valides, mais désignent des éléments qui sont désormais dans *this. La norme actuelle fournit cette garantie via l'énoncé général de [container.reqmts]/67, et une garantie plus directe est à l'étude via LWG issue 2321.

Bien que non formellement requis avant C++23, certaines implémentations ont déjà placé le paramètre de modèle Allocator dans des contextes non déduits dans les modes antérieurs.

Macro de test de fonctionnalité Valeur Std Fonctionnalité

Exemple

#include <cmath>
#include <iostream>
#include <set>
#include <string>

struct Point { double x, y; };

struct PointCmp
{
    bool operator()(const Point& lhs, const Point& rhs) const
    {
        return std::hypot(lhs.x, lhs.y) < std::hypot(rhs.x, rhs.y);
    }
};

std::ostream& operator<<(std::ostream& os, Point pt)
{
    return os << '(' << pt.x << ',' << pt.x << ')';
}

void println(auto rem, const auto& seq)
{
    std::cout << rem << '{';
    for (auto n{seq.size()}; const auto& elm : seq)
        std::cout << elm << (--n ? ", " : "");
    std::cout << "}\n";
}

int main()
{
    // (1) Constructeur par défaut
    std::set<std::string> a;
    a.insert("horse");
    a.insert("cat");
    a.insert("dog");
    println("1) a: ", a);

    // (4) Constructeur à partir d'un intervalle
    std::set<std::string> b(a.find("dog"), a.end());
    println("2) b: ", b);

    // (6) Constructeur de copie
    std::set<std::string> c(a);
    c.insert("another horse");
    println("3) c: ", c);

    // (8) Constructeur de déplacement
    std::set<std::string> d(std::move(a));
    println("4) d: ", d);
    println("5) a: ", a);

    // (10) Constructeur à partir d'une liste d'initialisation
    std::set<std::string> e{"one", "two", "three", "five", "eight"};
    println("6) e: ", e);

    // Comparaison personnalisée
    std::set<Point, PointCmp> f = {{2, 5}, {3, 4}, {1, 1}};
    f.insert({1, -1}); // Cela échoue car le module de (1,-1) est égal à celui de (1,1)
    println("7) f: ", f);

    // (12) Constructeur par intervalle
    const auto w = {"Eurybia", "Theia", "Rhea", "Aura", "Mnemosyne", "Mnemosyne"};
#if __cpp_lib_containers_ranges
    std::set<std::string> g(std::from_range, w); // overload (12)
#else
    std::set<std::string> g(w.begin(), w.end()); // repli sur (4)
#endif
    println("8) g: ", g);
}

Sortie possible :

1) a: {cat, dog, horse}
2) b: {dog, horse}
3) c: {another horse, cat, dog, horse}
4) d: {cat, dog, horse}
5) a: {}
6) e: {eight, five, one, three, two}
7) f: {(1,1), (3,3), (2,2)}
8) g: {Aura, Eurybia, Mnemosyne, Rhea, Theia}
