std::set<Key,Compare,Allocator>::contains

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

bool contains( const Key& key ) const;  // (1) (depuis C++20)

template< class K >
bool contains( const K& x ) const;  // (2) (depuis C++20)

  1. Vérifie s'il existe un élément dont la clé est équivalente à key dans le conteneur.

  2. Vérifie s'il existe un élément dont la clé se compare équivalente à la valeur x. Cette surcharge participe à la résolution de surcharge uniquement si le qualified-id Compare::is_transparent est valide et désigne un type. Cela permet d'appeler cette fonction sans construire d'instance de Key.

Paramètres

  • key — valeur de clé de l'élément à rechercher
  • x — une valeur de n'importe quel type pouvant être comparée de façon transparente à une clé

Valeur de retour

true s'il existe un tel élément, sinon false.

Complexité

Logarithmique en la taille du conteneur.

Exemple

#include <iostream>
#include <set>

int main()
{
    std::set<int> example{1, 2, 3, 4};

    for (int x : {2, 5})
        if (example.contains(x))
            std::cout << x << ": Found\n";
        else
            std::cout << x << ": Not found\n";
}

Output:

2: Found
5: Not found
