Insère un ou plusieurs éléments dans le conteneur, si celui-ci ne contient pas déjà un élément avec une clé équivalente.

1,2) Insère value.

3,4) Insère value à la position la plus proche possible de la position juste avant pos.

  1. Insère les éléments de l'intervalle [first,last). Si plusieurs éléments de l'intervalle ont des clés équivalentes, il n'est pas spécifié lequel est inséré (en attente de LWG2844).

  2. Insère les éléments de la liste d'initialisation ilist. Si plusieurs éléments de l'intervalle ont des clés équivalentes, il n'est pas spécifié lequel est inséré (en attente de LWG2844).

  3. Si nh est un node handle vide, ne fait rien. Sinon, insère l'élément possédé par nh dans le conteneur , si celui-ci ne contient pas déjà un élément avec une clé équivalente à nh.key(). Le comportement est indéfini si nh n'est pas vide et que get_allocator() != nh.get_allocator().

  4. Si nh est un node handle vide, ne fait rien et renvoie l'itérateur de fin. Sinon, insère l'élément possédé par nh dans le conteneur, si celui-ci ne contient pas déjà un élément avec une clé équivalente à nh.key(), et renvoie l'itérateur pointant vers l'élément de clé équivalente à nh.key() (que l'insertion ait réussi ou échoué). Si l'insertion réussit, nh est déplacé, sinon il conserve la possession de l'élément. L'élément est inséré à la position la plus proche possible de la position juste avant pos. Le comportement est indéfini si nh n'est pas vide et que get_allocator() != nh.get_allocator().

  5. Si *this contient déjà un élément qui compare de façon transparente équivalent à x, ne fait rien. Sinon, construit un objet u du value_type avec std::forward<K>(x) puis insère u dans *this. Si equal_range(u) == equal_range(x) vaut false, le comportement est indéfini. Le value_type doit être EmplaceConstructible dans set depuis std::forward<K>(x). Cette surcharge ne participe à la résolution de surcharge que si l'identifiant qualifié Compare::is_transparent est valide et désigne un type. Elle permet d'appeler cette fonction sans construire d'instance de Key.

  6. Si *this contient déjà un élément qui compare de façon transparente équivalent à x, ne fait rien. Sinon, construit un objet u du value_type avec std::forward<K>(x) puis insère u dans *this à la position la plus proche possible de la position juste avant pos. Si equal_range(u) == equal_range(x) vaut false, le comportement est indéfini. Le value_type doit être EmplaceConstructible dans set depuis std::forward<K>(x). Cette surcharge ne participe à la résolution de surcharge que si :

  • std::is_convertible_v<K&&, const_iterator> et std::is_convertible_v<K&&, iterator> sont tous deux false, et
  • l'identifiant qualifié Compare::is_transparent est valide et désigne un type,

ce qui permet d'appeler cette fonction sans construire une instance de Key.

Aucun itérateur ni aucune référence n'est invalidé. Si l'insertion réussit, les pointeurs et références vers l'élément obtenus pendant qu'il est détenu par le node handle sont invalidés, et les pointeurs et références obtenus vers cet élément avant son extraction redeviennent valides. (depuis C++17)

Paramètres

  • pos — itérateur vers la position avant laquelle le nouvel élément sera inséré
  • value — valeur de l'élément à insérer
  • first, last — intervalle d'éléments à insérer
  • ilist — liste d'initialisation à partir de laquelle insérer les valeurs
  • nh — un node handle compatible
  • x — une valeur de n'importe quel type pouvant être comparée de façon transparente à une clé

Exigences sur les types

  • InputIt doit satisfaire aux exigences de LegacyInputIterator.

Valeur de retour

1,2) Une paire composée d'un itérateur vers l'élément inséré (ou vers l'élément qui a empêché l'insertion) et d'une valeur bool égale à true si et seulement si l'insertion a eu lieu.

3,4) Un itérateur vers l'élément inséré, ou vers l'élément qui a empêché l'insertion.

5,6) (aucun)

  1. Un objet de insert_return_type dont les membres sont initialisés comme suit :
  • Si nh est vide, inserted vaut false, position vaut end(), et node est vide.
  • Sinon, si l'insertion a eu lieu, inserted vaut true, position pointe vers l'élément inséré, et node est vide.
  • Si l'insertion a échoué, inserted vaut false, node a la valeur précédente de nh, et position pointe vers un élément de clé équivalente à nh.key().

  1. Itérateur de fin si nh était vide, itérateur pointant vers l'élément inséré si l'insertion a eu lieu, et itérateur pointant vers un élément de clé équivalente à nh.key() en cas d'échec.

  2. Une paire composée d'un itérateur vers l'élément inséré (ou vers l'élément qui a empêché l'insertion) et d'une valeur bool égale à true si et seulement si l'insertion a eu lieu.

  3. Un itérateur vers l'élément inséré, ou vers l'élément qui a empêché l'insertion.

Exceptions

1-4) Si une exception est levée par une opération quelconque, l'insertion n'a aucun effet.

Complexité

1,2) Logarithmique en la taille du conteneur, O(log(size())).

3,4) Constante amortie si l'insertion a lieu à la position juste [après (jusqu'à C++11) | avant (depuis C++11)] pos, logarithmique en la taille du conteneur sinon.

5,6) O(N·log(size() + N)), où N est le nombre d'éléments à insérer.

  1. Logarithmique en la taille du conteneur, O(log(size())).

  2. Constante amortie si l'insertion a lieu à la position juste avant pos, logarithmique en la taille du conteneur sinon.

  3. Logarithmique en la taille du conteneur, O(log(size())).

  4. Constante amortie si l'insertion a lieu à la position juste avant pos, logarithmique en la taille du conteneur sinon.

Notes

L'insertion avec indication (3,4) ne renvoie pas de booléen afin d'avoir la même signature que l'insertion positionnelle des conteneurs séquentiels, tels que std::vector::insert. Cela permet de créer des insertion génériques comme std::inserter. Une façon de vérifier le succès d'une insertion avec indication consiste à comparer size() avant et après.

Les surcharges (5,6) sont souvent implémentées comme une boucle qui appelle la surcharge (3) avec end() comme indication ; elles sont optimisées pour ajouter une séquence triée (comme un autre std::set) dont le plus petit élément est supérieur au dernier élément de *this.

Exemple

#include <cassert>
#include <iostream>
#include <set>

int main()
{
    std::set<int> set;

    auto result_1 = set.insert(3);
    assert(result_1.first != set.end()); // c'est un itérateur valide
    assert(*result_1.first == 3);
    if (result_1.second)
        std::cout << "insert done\n";

    auto result_2 = set.insert(3);
    assert(result_2.first == result_1.first); // même itérateur
    assert(*result_2.first == 3);
    if (!result_2.second)
        std::cout << "no insertion\n";
}

Output:

insert done
no insertion

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
