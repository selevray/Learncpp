Renvoie le nombre d'étendues dynamiques situées avant l'indice i. Si i <= rank() est false, le comportement est indéfini.

Paramètres

  • i — l'indice

Valeur de retour

Le nombre de Er avec r < i pour lesquels Er est une étendue dynamique.
