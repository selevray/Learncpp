Construit un extents. On peut construire extents uniquement à partir des étendues dynamiques, qui sont toutes les valeurs stockées, ou à partir de toutes les étendues avec une précondition.

  1. Constructeur par défaut. Initialise toutes les étendues dynamiques à zéro.

  2. Conversion à partir d'un autre objet extents. Après la construction, *this == other est true.

  • Le comportement est indéfini si

    • other.extent(r) != static_extent(r) pour tout r pour lequel static_extent(r) représente une étendue statique, ou
    • other.extent(r) n'est pas représentable comme valeur de type IndexType pour tout rang r dans other.

  • Cette surcharge ne participe à la résolution de surcharge que si

    • sizeof...(OtherExtents) == rank() est true, et
    • ((OtherExtents == std::dynamic_extent || Extents == std::dynamic_extent || OtherExtents == Extents) && ...) is true.

  • Ce constructeur est explicit si

    • ((Extents != std::dynamic_extent && OtherExtents == std::dynamic_extent) || ...) est true, ou
    • std::numeric_limits<IndexType>::max() < std::numeric_limits<OtherIndexType>::max() is true.
  1. Soit N égal à sizeof...(exts) et exts_arr égal à std::array<IndexType, N>{static_cast<IndexType>(std::move(exts))...}, équivalent à extents(exts_arr).

  • Cette surcharge ne participe à la résolution de surcharge que si

    • (std::is_convertible_v<OtherIndexTypes, IndexType> && ...) is true,
    • (std::is_nothrow_constructible_v<IndexType, OtherIndexTypes> && ...) est true, et
    • N == rank_dynamic() || N == rank() is true.

  • Le comportement est indéfini si

    • N != rank_dynamic() et exts_arr[r] est différent de static_extent(r) pour tout r pour lequel static_extent(r) représente une étendue statique, ou
    • un élément de exts est négatif ou non représentable comme valeur de type IndexType.

4,5) Si N égale rank_dynamic(), pour tout d dans [0,rank_dynamic()), direct-non-list-initializes dynamic-extents[d] avec std::as_const(exts[d]). Sinon, pour tout d dans [0,rank_dynamic()), direct-non-list-initializes dynamic-extents[d] avec std::as_const(exts[dynamic-index-inv(d)]).

  • Cette surcharge ne participe à la résolution de surcharge que si

    • std::is_convertible_v<const OtherIndexType&, IndexType> is true,
    • std::is_nothrow_constructible_v<IndexType, const OtherIndexType&> est true, et
    • N == rank_dynamic() || N == rank() is true.

  • Le comportement est indéfini si

    • N != rank_dynamic() et exts[r] est différent de static_extent(r) pour tout r pour lequel static_extent(r) représente une étendue statique, ou
    • exts[r] est négatif ou non représentable comme valeur de type IndexType pour tout indice de rang r.

Paramètres

  • other — un autre extents à partir duquel convertir
  • exts — représente les étendues
