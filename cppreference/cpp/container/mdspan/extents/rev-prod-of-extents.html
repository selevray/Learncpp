std::extents<IndexType,Extents...>::rev-prod-of-extents

constexpr std::size_t /*rev-prod-of-extents*/( rank_type i ) const noexcept;  // (depuis C++23) ( exposition uniquement* )

Renvoie le produit des tailles des extents dont l'indice est supérieur à i. Le comportement est indéfini si i < rank() vaut false.

Paramètres

  • i — un indice au-delà duquel les tailles des extents correspondants seront multipliées entre elles

Valeur de retour

Si i + 1 < rank() vaut true, renvoie le produit des extent(k) pour tous les k de l'intervalle [i + 1,rank()), sinon 1.
