operator==(std::extents)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class OtherIndexType, std::size_t... OtherExtents >
friend constexpr bool operator==(
    const extents& lhs, const extents<OtherIndexType, OtherExtents...>& rhs ) noexcept;  // (depuis C++23)

Compare deux extents. Renvoie true si lhs.rank() est égal à rhs.rank() et lhs.extent(r) est égal à rhs.extent(r) pour chaque indice de rang r de rhs ; sinon renvoie false.

Paramètres

  • lhs, rhs — extents dont les valeurs sont à comparer

Valeur de retour

true si les extents représentés par lhs et rhs sont égaux, false sinon
