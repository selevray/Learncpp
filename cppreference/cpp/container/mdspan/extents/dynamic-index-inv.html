Renvoie le nombre r tel que dans l'intervalle [0,r + 1) il y ait exactement [0,i + 1) étendues dynamiques. Si i <= rank_dynamic() est false, le comportement est indéfini.

Paramètres

  • i — l'indice

Valeur de retour

La valeur minimale de r telle que dynamic-index(r + 1) == i + 1 soit true.
