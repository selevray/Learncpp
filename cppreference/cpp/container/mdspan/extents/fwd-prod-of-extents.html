std::extents<IndexType,Extents...>::fwd-prod-of-extents

constexpr std::size_t /*fwd-prod-of-extents*/( rank_type i ) const noexcept;  // (depuis C++23) ( exposition uniquement* )

Renvoie le produit des tailles des extents dont l'indice est inférieur à i. Le comportement est indéfini si i <= rank() vaut false.

Paramètres

  • i — L'indice de fin de l'intervalle des extents à multiplier entre eux.

Valeur de retour

Si i > 0 vaut true, renvoie le produit des extent(k) pour tous les k de l'intervalle [0,i), sinon 1.
