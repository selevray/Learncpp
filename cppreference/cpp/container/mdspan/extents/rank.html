std::extents<IndexType,Extents...>::rank

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static constexpr rank_type rank() const noexcept;  // (depuis C++23)

Renvoie le nombre de dimensions dans extents.

Paramètres

(aucune)

Valeur de retour

Le nombre de dimensions.

Exemple

#include <iostream>
#include <mdspan>

int main()
{
    std::extents<int, 1, 2> e1;
    std::extents<int, 3, 4, std::dynamic_extent> e2(5);
    std::cout << e1.rank() << ", " << e2.rank() << '\n';
}

Output:

2, 3
