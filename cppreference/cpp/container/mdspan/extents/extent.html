std::extents<IndexType,Extents...>::extent

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr index_type extent( rank_type i ) const noexcept;  // (depuis C++23)

Renvoie la taille d'étendue dynamique d'un extents à un rang d'indice donné.

Paramètres

  • i — L'indice de rang dont on veut obtenir la taille d'étendue

Valeur de retour

La taille d'étendue dynamique d'un extents à un rang d'indice donné.

Exemple

#include <iostream>
#include <mdspan>

int main()
{
    std::extents<int, 1, 2> e1;
    std::extents<int, 3, std::dynamic_extent, std::dynamic_extent> e2(4, 5);
    std::cout << e1.extent(0) << ", " << e1.extent(1) << '\n';
    std::cout << e2.extent(0) << ", " << e2.extent(1) << ", " << e2.extent(2) << '\n';
}

Output:

1, 2
3, 4, 5
