std::extents<IndexType,Extents...>::index-cast

template< class OtherIndexType >
static constexpr auto /*index-cast*/( OtherIndexType&& i ) noexcept;  // (depuis C++23) ( exposition uniquement* )

Convertit l'indice i de type OtherIndexType en un certain type entier.

Équivalent à :

  • return i;, si OtherIndexType est un type entier autre que bool et
  • return static_cast<index_type>(i); sinon.

Paramètres

  • i — l'indice à convertir

Valeur de retour

Indice converti.

Notes

Un appel à cette fonction renvoie toujours un type entier autre que bool. Les types de classe entiers peuvent utiliser la branche static_cast sans perte de précision, car les sites d'appel de cette fonction sont déjà contraints par la convertibilité de OtherIndexType vers index_type.
