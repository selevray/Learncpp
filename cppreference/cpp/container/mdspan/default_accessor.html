std::default_accessor

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <mdspan>

template< class ElementType >
class default_accessor;  // (depuis C++23)

Une spécialisation du modèle de classe std::default_accessor est le AccessorPolicy par défaut utilisé par std::mdspan si aucune politique d'accesseur fournie par l'utilisateur n'est spécifiée.

Chaque spécialisation de default_accessor modélise semiregular et est TriviallyCopyable.

Paramètres de modèle

  • ElementType — le type d'élément. Doit être un type objet complet qui n'est ni un type classe abstrait ni un type tableau. Sinon, le programme est mal formé

Types membres

Type membre Définition

  • offset_policy — default_accessor
  • element_type — ElementType
  • reference — ElementType&
  • data_handle_type — ElementType*

Fonctions membres

  • (constructeur) — construit un default_accessor (fonction membre publique)
  • access — renvoie le nième élément fourni par les arguments (fonction membre publique)
  • offset — renvoie un descripteur de données avancé d'une valeur de décalage (fonction membre publique)

std::default_accessor::default_accessor

constexpr default_accessor() noexcept = default;  // (1)

template< class OtherElementType >
constexpr default_accessor( default_accessor<OtherElementType> ) noexcept {}  // (2)

  1. Construit par défaut un default_accessor.

  2. Construit un default_accessor à partir de default_accessor<OtherElementType>. Le constructeur n'a aucun effet visible. Cette surcharge ne participe à la résolution de surcharge que si std::is_convertible_v<OtherElementType(*)[], element_type(*)[]> est vrai.

std::default_accessor::access

constexpr reference access( data_handle_type p, std::size_t i ) const noexcept;

Équivalent à return p[i];.

std::default_accessor::offset

constexpr data_handle_type offset( data_handle_type p, std::size_t i ) const noexcept;

Équivalent à return p + i;.
