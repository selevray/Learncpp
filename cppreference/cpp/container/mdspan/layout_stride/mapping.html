std::layout_stride::mapping

template< class Extents >
class layout_stride::mapping;  // (depuis C++23)

Le modèle de classe layout_stride::mapping contrôle la manière dont les indices multidimensionnels sont associés, avec des pas définis par l'utilisateur, à une valeur unidimensionnelle représentant le décalage.

Chaque spécialisation de mapping est un LayoutMapping et un type TriviallyCopyable qui satisfait regular.

Le programme est mal formé si la taille de l'espace d'indices multidimensionnel Extents() n'est pas représentable comme valeur de type Extents::index_type lorsque Extents::rank_dynamic() vaut 0.

Paramètres de modèle

  • Extents — précise le nombre de dimensions, leurs tailles, et lesquelles sont connues à la compilation. Doit être une spécialisation de std::extents.
