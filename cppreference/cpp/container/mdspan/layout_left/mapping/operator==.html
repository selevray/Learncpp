template< class OtherExtents >
friend constexpr bool operator==( const mapping& lhs,
                                  const mapping<OtherExtents>& rhs ) noexcept;  // (depuis C++23)

Compare deux mappings de mise en page du même type de mise en page en fonction de leurs extents sous-jacents.

Les mappings de mise en page lhs et rhs sont égaux si lhs.extents() et rhs.extents() sont égaux.

Cette surcharge ne participe à la résolution de surcharge que si extents_type::rank() == OtherExtents::rank() est true.

Paramètres

  • lhs, rhs — mappings de mise en page dont les extents sont à comparer

Valeur de retour

true si lhs.extents() == rhs.extents() est true, false sinon
