std::layout_left::mapping<Extents>::stride

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr index_type stride(rank_type i) const noexcept;  // (depuis C++23)

Renvoie le pas du mapping à un indice de rang i. Équivalent à return extents().fwd-prod-of-extents(i);.

Cette surcharge ne participe à la résolution de surcharge que si extents_type::rank() > 0 est true.

Le comportement est indéfini si i >= extents_type::rank() est true.

Paramètres

  • i — un indice de rang dans l'intervalle [0,extents_type::rank())

Valeur de retour

Le pas à un indice de rang spécifié.
