std::layout_right::mapping<Extents>::operator()

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class... Indices >
constexpr index_type operator()( Indices... indices ) const noexcept;  // (depuis C++23)

Associe l'indice multidimensionnel indices à une valeur de décalage.

Équivalent à return ((static_cast<index_type>(indices) * stride(P)) + ... + 0); où P est un pack tel que std::is_same_v<std::index_sequence_for<Indices...>, std::index_sequence<P...>> vaut true.

Cette surcharge ne participe à la résolution de surcharge que si :

  • sizeof...(Indices) == extents_type::rank() is true,
  • (std::is_convertible_v<Indices, index_type> && ...) est true, et
  • (std::is_nothrow_constructible_v<index_type, Indices> && ...) is true.

Si extents_type::index-cast(i) n'est pas un indice multidimensionnel dans extents(), le comportement est indéfini.

Paramètres

  • indices — l'indice multidimensionnel dans l'objet extents sous-jacent

Valeur de retour

La valeur de décalage.
