  1. Représente un espace d'indices multidimensionnel de rang égal à sizeof...(Extents).

  2. Un modèle d'alias pratique pour un extents entièrement dynamique. Soit d désignant std::dynamic_extent, chaque spécialisation de celui-ci dextents<IndexType, Rank> est équivalente à extents<IndexType /*, d, d, ..., d*/> (c'est-à-dire que d est répété un total de Rank fois).

  3. Un modèle d'alias pratique pour un extents entièrement dynamique avec std::size_t comme type d'indice par défaut.

Chaque spécialisation de extents modélise regular et est TriviallyCopyable.

Paramètres de modèle

  • IndexType — le type de chaque Extents non dynamique. Doit être un type entier signé ou non signé. Sinon, le programme est mal formé
  • Extents — représente l'extent (taille d'un intervalle d'entiers) pour chaque indice de rang. Chacun de ses éléments est soit égal à std::dynamic_extent (dans ce cas, il représente un extent dynamique dont la taille est déterminée à l'exécution), soit représentable comme valeur de type IndexType (il représente alors un extent statique et la taille de l'extent est simplement cette valeur), sinon le programme est mal formé
  • Rank — désigne le rang d'un extents entièrement dynamique
