static constexpr std::size_t static_extent( rank_type r ) noexcept;  // (depuis C++23)

Détermine statiquement l'extension d'un mdspan à l'indice de rang r. Si l'indice de rang r correspond à une extension dynamique, renvoie std::dynamic_extent. Équivalent à return Extents::static_extent(r);.

Paramètres

  • r — L'indice de rang dont on veut obtenir la taille statique d'extent

Valeur de retour

La taille d'extension statique, ou std::dynamic_extent.
