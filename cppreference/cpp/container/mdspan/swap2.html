friend constexpr void swap( mdspan& x, mdspan& y ) noexcept;  // (depuis C++23)

Surcharge l'algorithme std::swap pour std::mdspan. Échange l'état de x avec celui de y. Équivalent à :

std::swap(x.acc_, y.acc_); std::swap(x.map_, y.map_); std::swap(x.ptr_, y.ptr_);
