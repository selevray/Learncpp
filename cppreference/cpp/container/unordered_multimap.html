std::unordered_multimap

namespace pmr {
    template<
        class Key,
        class T,
        class Hash = std::hash<Key>,
        class Pred = std::equal_to<Key>
    > using unordered_multimap =
          std::unordered_multimap<Key, T, Hash, Pred,
              std::pmr::polymorphic_allocator<std::pair<const Key, T>>>;
}  // (2) (depuis C++17)

std::unordered_multimap est un conteneur associatif non ordonné qui prend en charge les clés équivalentes (un unordered_multimap peut contenir plusieurs copies de chaque valeur de clé) et qui associe aux clés des valeurs d'un autre type. La classe unordered_multimap prend en charge les itérateurs avant. La recherche, l'insertion et la suppression ont une complexité constante en moyenne.

En interne, les éléments ne sont pas triés selon un ordre particulier, mais organisés en compartiments. Le compartiment dans lequel un élément est placé dépend entièrement du hachage de sa clé. Cela permet un accès rapide aux éléments individuels, puisqu'une fois le hachage calculé, il désigne exactement le compartiment dans lequel l'élément est placé.

L'ordre d'itération de ce conteneur n'a pas à être stable (ainsi, par exemple, std::equal ne peut pas être utilisé pour comparer deux std::unordered_multimap), sauf que chaque groupe d'éléments dont les clés sont équivalentes (égales selon key_eq() utilisé comme comparateur) forme un sous-intervalle contigu dans l'ordre d'itération, également accessible avec equal_range().

std::unordered_multimap satisfait les exigences de Container, AllocatorAwareContainer, UnorderedAssociativeContainer.
