std::erase_if (std::flat_set)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <flat_set>

template< class Key, class Compare, class KeyContainer,
          class Pred >
std::flat_set<Key, Compare, KeyContainer>::size_type
    erase_if( std::flat_set<Key, Compare, KeyContainer>& c,
              Pred pred );  // (depuis C++23)

Supprime de c tous les éléments qui satisfont le prédicat pred.

Le prédicat pred est satisfait si l'expression bool(pred(std::as_const(e))) vaut true, où e est un élément quelconque de c.

Key doit être MoveAssignable. Sinon, le comportement est indéfini.

Paramètres

  • c — adaptateur de conteneur duquel supprimer
  • pred — prédicat renvoyant true si l'élément doit être supprimé

Valeur de retour

Le nombre d'éléments supprimés.

Complexité

Exactement c.size() applications du prédicat pred.

Exceptions

Si erase_if lève une exception, c reste dans un état valide mais non spécifié (éventuellement vide).

Notes

L'algorithme est stable, c'est-à-dire que l'ordre des éléments non supprimés reste inchangé.

Exemple

#include <iostream>
#include <flat_set>

void println(auto rem, auto const& container)
{
    std::cout << rem << '{';
    for (char sep[]{0, ' ', 0}; const auto& item : container)
        std::cout << sep << item, *sep = ',';
    std::cout << "}\n";
}

int main()
{
    std::flat_set data{3, 3, 4, 5, 5, 6, 6, 7, 2, 1, 0};
    println("Original:\n", data);

    auto divisible_by_3 = [](auto const& x) { return (x % 3) == 0; };

    const auto count = std::erase_if(data, divisible_by_3);

    println("Erase all items divisible by 3:\n", data);
    std::cout << count << " items erased.\n";
}

Output:

Original:
{0, 1, 2, 3, 4, 5, 6, 7}
Erase all items divisible by 3:
{1, 2, 4, 5, 7}
3 items erased.
