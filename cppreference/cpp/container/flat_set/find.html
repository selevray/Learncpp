std::flat_set<Key,Compare,KeyContainer>::find

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

iterator find( const Key& key );  // (1) (depuis C++23)

const_iterator find( const Key& key ) const;  // (2) (depuis C++23)

template< class K >
iterator find( const K& x );  // (3) (depuis C++23)

template< class K >
const_iterator find( const K& x ) const;  // (4) (depuis C++23)

1,2) Trouve un élément dont la clé est équivalente à key.

3,4) Trouve un élément dont la clé se compare équivalente à la valeur x. Cette surcharge ne participe à la résolution de surcharge que si l'id-qualifié Compare::is_transparent est valide et désigne un type. Elle permet d'appeler cette fonction sans construire une instance de Key.

Paramètres

  • key — valeur de clé de l'élément à rechercher
  • x — une valeur de n'importe quel type pouvant être comparée de façon transparente à une clé

Valeur de retour

Un itérateur vers l'élément demandé. Si aucun élément de ce type n'est trouvé, l'itérateur past-the-end (voir end()) est renvoyé.

Complexité

Logarithmique en la taille du conteneur.

Exemple

#include <iostream>
#include <flat_set>

struct LightKey
{
    int x;
};

struct FatKey
{
    int x;
    int data[1000]; // un gros blob
};

// Comme détaillé ci-dessus, le conteneur doit utiliser std::less<> (ou un autre
// comparateur transparent) pour accéder à ces surcharges. Cela inclut les surcharges standard,
// comme la comparaison entre std::string et std::string_view.
bool operator<(const FatKey& fk, const LightKey& lk) { return fk.x < lk.x; }
bool operator<(const LightKey& lk, const FatKey& fk) { return lk.x < fk.x; }
bool operator<(const FatKey& fk1, const FatKey& fk2) { return fk1.x < fk2.x; }

int main()
{
    // Démonstration de comparaison simple.
    std::flat_set<int> example{1, 2, 3, 4};

    if (auto search = example.find(2); search != example.end())
        std::cout << "Found " << (*search) << '\n';
    else
        std::cout << "Not found\n";

    // Démonstration de comparaison transparente.
    std::flat_set<FatKey, std::less<>> example2{{1, {}}, {2, {}}, {3, {}}, {4, {}}};

    LightKey lk = {2};
    if (auto search = example2.find(lk); search != example2.end())
        std::cout << "Found " << search->x << '\n';
    else
        std::cout << "Not found\n";
}

Output:

Found 2
Found 2
