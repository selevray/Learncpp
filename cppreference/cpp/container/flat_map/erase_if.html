std::erase_if (std::flat_map)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <flat_map>

template< class Key, class T, class Compare, class KeyContainer, class MappedContainer,
          class Pred >
std::flat_map<Key, T, Compare, KeyContainer, MappedContainer>::size_type
    erase_if( std::flat_map<Key, T, Compare, KeyContainer, MappedContainer>& c,
              Pred pred );  // (depuis C++23)

Supprime de c tous les éléments qui satisfont le prédicat pred.

Le prédicat pred est satisfait si l'expression bool(pred(std::pair<const Key&, const T&>(e))) vaut true, où e est un élément quelconque de c.

Key et T doivent être MoveAssignable. Sinon, le comportement est indéfini.

Paramètres

  • c — adaptateur de conteneur duquel supprimer
  • pred — prédicat renvoyant true si l'élément doit être supprimé

Valeur de retour

Le nombre d'éléments supprimés.

Complexité

Exactement c.size() applications du prédicat pred.

Exceptions

Si erase_if lève une exception, c reste dans un état valide mais non spécifié (éventuellement vide).

Notes

L'algorithme est stable, c'est-à-dire que l'ordre des éléments non supprimés reste inchangé.

Exemple

#include <iostream>
#include <flat_map>

void println(auto rem, auto const& container)
{
    std::cout << rem << '{';
    for (char sep[]{0, ' ', 0}; const auto& [key, value] : container)
        std::cout << sep << '{' << key << ", " << value << '}', *sep = ',';
    std::cout << "}\n";
}

int main()
{
    std::flat_map<int, char> data
    {
        {1, 'a'}, {2, 'b'}, {3, 'c'}, {4, 'd'},
        {5, 'e'}, {4, 'f'}, {5, 'g'}, {5, 'g'},
    };
    println("Original:\n", data);

    const auto count = std::erase_if(data, [](const auto& item)
    {
        auto const& [key, value] = item;
        return (key & 1) == 1;
    });

    println("Erase items with odd keys:\n", data);
    std::cout << count << " items removed.\n";
}

Output:

Original:
{{1, a}, {2, b}, {3, c}, {4, d}, {5, e}}
Erase items with odd keys:
{{2, b}, {4, d}}
3 items removed.
