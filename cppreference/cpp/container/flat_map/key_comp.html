std::flat_map<Key,T,Compare,KeyContainer,MappedContainer>::key_comp

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

key_compare key_comp() const;  // (depuis C++23)

Renvoie l'objet fonction qui compare les clés, qui est une copie de l'argument constructeur comp de ce conteneur.

Paramètres

(aucune)

Valeur de retour

L'objet fonction de comparaison des clés.

Complexité

Constante.

Exemple

#include <iostream>
#include <flat_map>
#include <utility>

// Exemple de fonction de comparaison de clés du module 97
struct ModCmp
{
    bool operator()(int lhs, int rhs) const
    {
        return (lhs % 97) < (rhs % 97);
    }
};

int main()
{
    std::flat_map<int, char, ModCmp> cont;
    cont = {{1, 'a'}, {2, 'b'}, {3, 'c'}, {4, 'd'}, {5, 'e'}};

    auto comp_func = cont.key_comp();

    for (const auto it : cont)
    {
        const bool before = comp_func(it.first, 100);
        const bool after = comp_func(100, it.first);

        std::cout << "Key (" << it.first << ',' << it.second << ") ";
        if (!before && !after)
            std::cout << "equivalent to key (100)\n";
        else if (before)
            std::cout << "goes before key (100)\n";
        else if (after)
            std::cout << "goes after key (100)\n";
        else
            std::unreachable();
    }
}

Output:

(1,a) goes before key (100)
(2,b) goes before key (100)
(3,c) equivalent to key (100)
(4,d) goes after key (100)
(5,e) goes after key (100)
