std::flat_map<Key,T,Compare,KeyContainer,MappedContainer>::extract

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

containers extract() &&;  // (depuis C++23)

Extrait les conteneurs adaptés c. Équivalent à return std::move(c);.

Après cette opération *this est vide, même si une exception est levée.

Paramètres

(aucune)

Valeur de retour

std::move(c).

Complexité

Constante.

Exemple

#include <cassert>
#include <flat_map>
#include <print>
#include <type_traits>
#include <vector>

int main()
{
    std::flat_map<int, double> map{{1, 1.1}, {2, 2.2}, {3, 3.3}};
    const auto size = map.size();

    auto c = map.extract();
    assert(c.keys.size() == size);
    assert(c.values.size() == size);
    assert(map.empty());
    assert(map.keys().empty());
    assert(map.values().empty());

    // Les conteneurs de clés et de valeurs par défaut sont std::vector :
    static_assert(std::is_same_v<decltype(c.keys), std::vector<int>>);
    static_assert(std::is_same_v<decltype(c.value), std::vector<int>>);

    std::println("keys: {}", c.keys);
    std::println("values: {}", c.values);
}

Output:

keys: [1, 2, 3]
values: [1.1, 2.2, 3.3]
