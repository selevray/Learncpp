std::flat_map<Key,T,Compare,KeyContainer,MappedContainer>::keys

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

const key_container_type& keys() const noexcept;  // (depuis C++23)

Renvoie une référence constante vers le conteneur de clés adapté. Équivalent à return c.keys;.

Paramètres

(aucune)

Valeur de retour

Le conteneur de clés sous-jacent.

Complexité

Constante.

Exemple

#include <flat_map>
#include <print>
#include <type_traits>
#include <vector>

int main()
{
    std::flat_map<int, double> adaptor{{1, 1.1}, {2, 2.2}, {3, 3.3}};

    // Le conteneur de clés par défaut est std::vector :
    static_assert(std::is_same_v<decltype(adaptor.keys()), const std::vector<int>&>);

    std::println("{}", adaptor.keys());
}

Output:

[1, 2, 3]
