std::flat_map<Key,T,Compare,KeyContainer,MappedContainer>::operator[]

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

T& operator[]( const Key& key );  // (1) (depuis C++23)

T& operator[]( Key&& key );  // (2) (depuis C++23)

template< class K >
T& operator[]( K&& x );  // (3) (depuis C++23)

Renvoie une référence à la valeur associée à une clé équivalente à key ou x respectivement, en effectuant une insertion si cette clé n'existe pas déjà.

  1. Insère un objet value_type construit sur place si la clé n'existe pas. Équivalent à return try_emplace(x).first->second;.

  2. Insère un objet value_type construit sur place si la clé n'existe pas. Équivalent à return try_emplace(std::move(x)).first->second;

  3. Insère un objet value_type construit sur place s'il n'existe aucune clé transparemment équivalente à la valeur x.

Équivalent à return this->try_emplace(std::forward<K>(x)).first->second;. Cette surcharge ne participe à la résolution de surcharge que si l'id-qualifié Compare::is_transparent est valide et désigne un type. Elle permet d'appeler cette fonction sans construire d'instance de Key.
Les informations sur l'invalidation des itérateurs sont reprises de ici

Paramètres

  • key — la clé de l'élément à rechercher
  • x — une valeur de n'importe quel type pouvant être comparée de façon transparente à une clé

Valeur de retour

1,2) Une référence à la valeur associée du nouvel élément si aucun élément de clé key n'existait. Sinon, une référence à la valeur associée de l'élément existant dont la clé est équivalente à key.

  1. Une référence à la valeur associée du nouvel élément si aucun élément dont la clé est équivalente à la valeur x n'existait. Sinon, une référence à la valeur associée de l'élément existant dont la clé est équivalente à x.

Exceptions

Si une exception est levée par une opération, l'insertion n'a aucun effet.

Complexité

Logarithmique en la taille du conteneur, plus le coût de l'insertion (le cas échéant) d'un élément vide.

Notes

operator[] n'est pas const car elle insère la clé si elle n'existe pas. Si ce comportement est indésirable ou si le conteneur est const, at peut être utilisé.

insert_or_assign renvoie plus d'informations que operator[] et ne nécessite pas que le type associé soit constructible par défaut.

Exemple

#include <iostream>
#include <string>
#include <flat_map>

void println(auto const comment, auto const& map)
{
    std::cout << comment << '{';
    for (const auto& pair : map)
        std::cout << '{' << pair.first << ": " << pair.second << '}';
    std::cout << "}\n";
}

int main()
{
    std::flat_map<char, int> letter_counts{{'a', 27}, {'b', 3}, {'c', 1}};

    println("letter_counts initially contains: ", letter_counts);

    letter_counts['b'] = 42; // met à jour une valeur existante
    letter_counts['x'] = 9;  // insère une nouvelle valeur

    println("after modifications it contains: ", letter_counts);

    // compte le nombre d'occurrences de chaque mot
    // (le premier appel à operator[] a initialisé le compteur à zéro)
    std::flat_map<std::string, int>  word_map;
    for (const auto& w : {"this", "sentence", "is", "not", "a", "sentence",
                          "this", "sentence", "is", "a", "hoax"})
        ++word_map[w];
    word_map["that"]; // insère simplement la paire {"that", 0}

    for (const auto& [word, count] : word_map)
        std::cout << count << " occurrence(s) of word '" << word << "'\n";
}

Output:

letter_counts initially contains: {{a: 27}{b: 3}{c: 1}}
after modifications it contains: {{a: 27}{b: 42}{c: 1}{x: 9}}
2 occurrence(s) of word 'a'
1 occurrence(s) of word 'hoax'
2 occurrence(s) of word 'is'
1 occurrence(s) of word 'not'
3 occurrence(s) of word 'sentence'
0 occurrence(s) of word 'that'
2 occurrence(s) of word 'this'

Voir aussi

  • at — accède à l'élément spécifié avec vérification des bornes (fonction membre publique)
  • insert_or_assign — insère un élément ou affecte à l'élément courant si la clé existe déjà (fonction membre publique)
  • try_emplace — insère sur place si la clé n'existe pas, ne fait rien si la clé existe (fonction membre publique)
