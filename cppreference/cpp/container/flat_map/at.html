std::flat_map<Key,T,Compare,KeyContainer,MappedContainer>::at

T& at( const Key& key );  // (1) (depuis C++23)

const T& at( const Key& key ) const;  // (2) (depuis C++23)

template< class K >

Renvoie une référence à la valeur associée de l'élément ayant la clé spécifiée. Si aucun élément de ce type n'existe, une exception de type std::out_of_range est levée.

1,2) La clé est équivalente à key.

3,4) La clé se compare équivalente à la valeur x. La référence à la valeur associée est obtenue comme si par l'expression this->find(x)->second.

L'expression this->find(x) doit être bien formée et avoir un comportement bien défini, sinon le comportement est indéfini.

Ces surcharges participent à la résolution de surcharge uniquement si le qualified-id Compare::is_transparent est valide et désigne un type. Cela permet d'appeler cette fonction sans construire d'instance de Key.

Paramètres

  • key — la clé de l'élément à rechercher
  • x — une valeur de n'importe quel type pouvant être comparée de façon transparente à une clé

Valeur de retour

Une référence à la valeur associée de l'élément demandé.

Exceptions

1,2) std::out_of_range si le conteneur ne possède pas d'élément avec la key spécifiée.

3,4) std::out_of_range si le conteneur ne possède pas l'élément spécifié, c'est-à-dire si find(x) == end() vaut true.

Complexité

Logarithmique en la taille du conteneur.

Exemple

#include <cassert>
#include <iostream>
#include <flat_map>

struct LightKey { int o; };
struct HeavyKey { int o[1000]; };

// Le conteneur doit utiliser std::less<> (ou un autre Comparator transparent) pour
// accéder aux surcharges (3,4). Cela inclut les surcharges standard, telles que
// la comparaison entre std::string et std::string_view.
bool operator<(const HeavyKey& x, const LightKey& y) { return x.o[0] < y.o; }
bool operator<(const LightKey& x, const HeavyKey& y) { return x.o < y.o[0]; }
bool operator<(const HeavyKey& x, const HeavyKey& y) { return x.o[0] < y.o[0]; }

int main()
{
    std::flat_map<int, char> map{{1, 'a'}, {2, 'b'}};
    assert(map.at(1) == 'a');
    assert(map.at(2) == 'b');
    try
    {
        map.at(13);
    }
    catch(const std::out_of_range& ex)
    {
        std::cout << "1) out_of_range::what(): " << ex.what() << '\n';
    }

#ifdef __cpp_lib_associative_heterogeneous_insertion
    // Démonstration de comparaison transparente.
    std::flat_map<HeavyKey, char, std::less<>> map2{{{1}, 'a'}, {{2}, 'b'}};
    assert(map2.at(LightKey{1}) == 'a');
    assert(map2.at(LightKey{2}) == 'b');
    try
    {
        map2.at(LightKey{13});
    }
    catch(const std::out_of_range& ex)
    {
        std::cout << "2) out_of_range::what(): " << ex.what() << '\n';
    }
#endif
}

1) out_of_range::what(): map::at:  key not found
2) out_of_range::what(): map::at:  key not found
