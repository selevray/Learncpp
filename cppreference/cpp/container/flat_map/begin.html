Retourne un itérateur vers le premier élément du flat_map.

Si le flat_map est vide, l'itérateur retourné sera égal à end().

range-begin-end.svg

Paramètres

(aucune)

Valeur de retour

Itérateur vers le premier élément.

Complexité

Constante.

Exemple

#include <iostream>
#include <flat_map>

int main()
{
    std::flat_map<int, double> map{{4, 4.13}, {9, 9.24}, {1, 1.09}};

    for (auto it = map.cbegin(); it != map.cend(); ++it)
        std::cout << '[' << it->first << "] = " << it->second << '\n';

    // Contrairement aux itérateurs bidirectionnels de std::map, les itérateurs de std::flat_map
    // sont à accès aléatoire, ils peuvent donc être utilisés avec l'opérateur[] :
    auto it = map.cbegin();
    assert(it[0] == map[1]);
    assert(it[1] == map[4]);
    assert(it[2] == map[9]);
}

Output:

[1] = 1.09
[4] = 4.13
[9] = 9.24
