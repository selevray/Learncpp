std::flat_map<Key,T,Compare,KeyContainer,MappedContainer>::equal_range

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

std::pair<iterator, iterator> equal_range( const Key& key );  // (1) (depuis C++23)

std::pair<const_iterator, const_iterator> equal_range( const Key& key ) const;  // (2) (depuis C++23)

template< class K >
std::pair<iterator, iterator> equal_range( const K& x );  // (3) (depuis C++23)

template< class K >
std::pair<const_iterator, const_iterator> equal_range( const K& x ) const;  // (4) (depuis C++23)

Renvoie un intervalle contenant tous les éléments ayant la clé donnée dans le conteneur. L'intervalle est défini par deux itérateurs : l'un pointe vers le premier élément qui n'est pas inférieur à key, l'autre vers le premier élément supérieur à key. Alternativement, le premier itérateur peut être obtenu avec lower_bound(), et le second avec upper_bound().

1,2) Compare les clés à key.

3,4) Compare les clés à la valeur x. Cette surcharge ne participe à la résolution de surcharge que si le qualified-id Compare::is_transparent est valide et désigne un type. Elle permet d'appeler cette fonction sans construire une instance de Key.

Paramètres

  • key — valeur de clé à laquelle comparer les éléments
  • x — valeur alternative pouvant être comparée à Key

Valeur de retour

std::pair contenant une paire d'itérateurs définissant l'intervalle recherché : le premier pointant vers le premier élément qui n'est pas inférieur à key et le second pointant vers le premier élément supérieur à key.

Si aucun élément n'est pas inférieur à key, un itérateur past-the-end (voir end()) est renvoyé comme premier élément. De même, si aucun élément n'est supérieur à key, un itérateur past-the-end est renvoyé comme second élément.

Complexité

Logarithmique en la taille du conteneur.

Exemple

#include <iostream>
#include <flat_map>

int main()
{
    const std::flat_map<int, const char*> m
    {
        {0, "zero"},
        {1, "one"},
        {2, "two"}
    };

    auto p = m.equal_range(1);
    for (auto& q = p.first; q != p.second; ++q)
        std::cout << "m[" << q->first << "] = " << q->second << '\n';

    if (p.second == m.find(2))
        std::cout << "end of equal_range (p.second) is one-past p.first\n";
    else
        std::cout << "unexpected; p.second expected to be one-past p.first\n";

    auto pp = m.equal_range(-1);
    if (pp.first == m.begin())
        std::cout << "pp.first is iterator to first not-less than -1\n";
    else
        std::cout << "unexpected pp.first\n";

    if (pp.second == m.begin())
        std::cout << "pp.second is iterator to first element greater-than -1\n";
    else
        std::cout << "unexpected pp.second\n";

    auto ppp = m.equal_range(3);
    if (ppp.first == m.end())
        std::cout << "ppp.first is iterator to first not-less than 3\n";
    else
        std::cout << "unexpected ppp.first\n";

    if (ppp.second == m.end())
        std::cout << "ppp.second is iterator to first element greater-than 3\n";
    else
        std::cout << "unexpected ppp.second\n";
}

Output:

m[1] = one
end of equal_range (p.second) is one-past p.first
pp.first is iterator to first not-less than -1
pp.second is iterator to first element greater-than -1
ppp.first is iterator to first not-less than 3
ppp.second is iterator to first element greater-than 3
