std::flat_map<Key,T,Compare,KeyContainer,MappedContainer>::rend, std::flat_map<Key,T,Compare,KeyContainer,MappedContainer>::crend

reverse_iterator rend() noexcept;  // (1) (depuis C++23)

const_reverse_iterator rend() const noexcept;  // (2) (depuis C++23)

const_reverse_iterator crend() const noexcept;  // (3) (depuis C++23)

Renvoie un itérateur inverse vers l'élément suivant le dernier élément du flat_map inversé. Il correspond à l'élément précédant le premier élément du flat_map non inversé. Cet élément sert de marqueur ; tenter d'y accéder entraîne un comportement indéfini.

range-rbegin-rend.svg

Paramètres

(aucune)

Valeur de retour

Itérateur inverse vers l'élément suivant le dernier élément.

Complexité

Constante.

Exemple

#include <chrono>
#include <iomanip>
#include <iostream>
#include <string_view>
#include <flat_map>

using namespace std::chrono;

int main()
{
    const std::flat_map<year_month_day, int> messages
    {
        {February/17/2023, 10},
        {February/17/2023, 20},
        {February/16/2022, 30},
        {October/22/2022, 40},
        {June/14/2022, 50},
        {November/23/2021, 60},
        {December/10/2022, 55},
        {December/12/2021, 45},
        {April/1/2020, 42},
        {April/1/2020, 24}
    };

    std::cout << "Messages received (date order is reversed):\n";
    for (auto it = messages.crbegin(); it != messages.crend(); ++it)
        std::cout << it->first << " : " << it->second << '\n';
}
