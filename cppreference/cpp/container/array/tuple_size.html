std::tuple_size<std::array>

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <array>

template< class T, std::size_t N >
struct tuple_size< std::array<T, N> > :
    std::integral_constant<std::size_t, N>
{ };  // (depuis C++11)

Fournit un accès au nombre d'éléments d'un std::array sous forme d'expression constante à la compilation.

Modèle de variable auxiliaire

template< class T >
constexpr std::size_t tuple_size_v = tuple_size<T>::value;  // (depuis C++17)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — N, le nombre d'éléments du tableau (constante membre statique publique)

Fonctions membres

  • operator std::size_t — convertit l'objet en std::size_t, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — std::size_t
  • type — std::integral_constant<std::size_t, value>

Exemple

#include <array>

int main()
{
    auto arr = std::to_array("ABBA");
    static_assert(std::tuple_size<decltype(arr)>{} == 5);
}
