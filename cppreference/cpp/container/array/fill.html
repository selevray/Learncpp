std::array<T,N>::fill

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void fill( const T& value );  // (depuis C++11) (constexpr depuis C++20)

Affecte la value à tous les éléments du conteneur.

Paramètres

  • value — la valeur à affecter aux éléments

Valeur de retour

(aucune)

Complexité

Linéaire en la taille du conteneur.

Exemple

#include <array>
#include <cstddef>
#include <iostream>

int main()
{
    constexpr std::size_t xy = 4;

    using Cell = std::array<unsigned char, 8>;

    std::array<Cell, xy * xy> board;

    board.fill({0xE2, 0x96, 0x84, 0xE2, 0x96, 0x80, 0, 0}); // "▄▀";

    for (std::size_t count{}; Cell c : board)
        std::cout << c.data() << ((++count % xy) ? "" : "\n");
}
