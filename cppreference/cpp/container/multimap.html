std::multimap

template<
    class Key,
    class T,
    class Compare = std::less<Key>,
    class Allocator = std::allocator<std::pair<const Key, T>>
> class multimap;  // (1)

namespace pmr {
    template<
        class Key,
        class T,
        class Compare = std::less<Key>
    > using multimap = std::multimap<Key, T, Compare,
        std::pmr::polymorphic_allocator<std::pair<const Key, T>>>;
}  // (2) (depuis C++17)

std::multimap est un conteneur associatif qui contient une liste triée de paires clé-valeur, tout en autorisant plusieurs entrées ayant la même clé. Le tri est effectué selon la fonction de comparaison Compare, appliquée aux clés. Les opérations de recherche, d'insertion et de suppression ont une complexité logarithmique.

Les itérateurs de std::multimap parcourent les clés dans un ordre non décroissant, où l'ordre non décroissant est défini par la comparaison utilisée lors de la construction. Autrement dit, étant donné

  • m, a std::multimap
  • it_l et it_r, des itérateurs déréférençables vers m, avec it_l < it_r.

m.value_comp()(*it_r, *it_l) == false (du plus petit au plus grand si l'on utilise la comparaison par défaut).

L'ordre des paires clé-valeur dont les clés sont équivalentes selon la comparaison est l'ordre d'insertion et ne change pas.

(depuis C++11)

Partout où la bibliothèque standard utilise les exigences Compare, l'équivalence est déterminée en utilisant la relation d'équivalence décrite à Compare. En termes imprécis, deux objets a et b sont considérés comme équivalents si aucun des deux n'est inférieur à l'autre : !comp(a, b) && !comp(b, a).

std::multimap satisfait les exigences de Container, AllocatorAwareContainer, AssociativeContainer et ReversibleContainer.
