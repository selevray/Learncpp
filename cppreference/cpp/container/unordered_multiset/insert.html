Insère un ou plusieurs éléments dans le conteneur.

1,2) Insère value.

3,4) Insère value, en utilisant hint comme suggestion non contraignante quant à l'endroit où la recherche doit commencer.

  1. Insère les éléments de l'intervalle [first,last).

  2. Insère les éléments de la liste d'initialisation ilist.

  3. Si nh est un node handle vide, ne fait rien. Sinon, insère l'élément possédé par nh dans le conteneur et renvoie un itérateur pointant vers l'élément inséré. Le comportement est indéfini si nh n'est pas vide et get_allocator() != nh.get_allocator().

  4. Si nh est un node handle vide, ne fait rien et renvoie l'itérateur de fin. Sinon, insère l'élément possédé par nh dans le conteneur, et renvoie l'itérateur pointant vers l'élément dont la clé est équivalente à nh.key(). hint est utilisé comme suggestion non contraignante quant à l'endroit où la recherche doit commencer. Le comportement est indéfini si nh n'est pas vide et get_allocator() != nh.get_allocator().

Si après l'opération le nouveau nombre d'éléments est supérieur à l'ancien max_load_factor() * bucket_count(), une réorganisation (rehashing) a lieu.
Si une réorganisation se produit (due à l'insertion), tous les itérateurs sont invalidés. Sinon (pas de réorganisation), les itérateurs ne sont pas invalidés. Si l'insertion réussit, les pointeurs et références vers l'élément obtenus pendant qu'il est détenu par le handle de nœud sont invalidés, et les pointeurs et références obtenus vers cet élément avant son extraction redeviennent valides. (depuis C++17)

Paramètres

  • hint — itérateur, utilisé comme suggestion quant à l'endroit où insérer le contenu
  • value — valeur de l'élément à insérer
  • first, last — intervalle d'éléments à insérer
  • ilist — liste d'initialisation à partir de laquelle insérer les valeurs
  • nh — un node handle compatible

Exigences sur les types

  • InputIt doit satisfaire aux exigences de LegacyInputIterator.

Valeur de retour

1-4) Un itérateur vers l'élément inséré.

5,6) (aucun)

7,8) Itérateur de fin si nh était vide, itérateur pointant vers l'élément inséré sinon.

Exceptions

1-4) Si une exception est levée par une opération quelconque, l'insertion n'a aucun effet.
Cette section est incomplète Raison : cas 5,6

Complexité

1-4) Cas moyen : O(1), cas le pire O(size()).

5,6) Cas moyen : O(N), où N est le nombre d'éléments à insérer. Cas le pire : O(N * size() + N).

7,8) Cas moyen : O(1), cas le pire O(size()).
