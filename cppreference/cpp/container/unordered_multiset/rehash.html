std::unordered_multiset<Key,Hash,KeyEqual,Allocator>::rehash

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void rehash( size_type count );  // (depuis C++11)

Modifie le nombre de compartiments à une valeur n qui n'est pas inférieure à count et satisfait n >= size() / max_load_factor(), puis réorganise le conteneur, c'est-à-dire place les éléments dans les compartiments appropriés en tenant compte du changement du nombre total de compartiments.

Paramètres

  • count — borne inférieure du nouveau nombre de compartiments

Valeur de retour

(aucune)

Complexité

Cas moyen linéaire par rapport à la taille du conteneur, pire cas quadratique.

Notes

rehash(0) peut être utilisé pour forcer une réorganisation inconditionnelle, par exemple après la suspension de la réorganisation automatique en augmentant temporairement max_load_factor().
