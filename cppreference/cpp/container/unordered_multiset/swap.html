std::unordered_multiset<Key,Hash,KeyEqual,Allocator>::swap

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void swap( unordered_multiset& other );  // (depuis C++11) (jusqu'à C++17)

void swap( unordered_multiset& other ) noexcept(/* voir ci-dessous */);  // (depuis C++17)

Échange le contenu du conteneur avec celui de other. N'invoque aucune opération de déplacement, de copie ou d'échange sur les éléments individuels.

Tous les itérateurs et références restent valides. L'itérateur end() est invalidé. Les objets Hash et KeyEqual doivent être Swappable, et ils sont échangés à l'aide d'appels non qualifiés à la fonction non membre swap.

Si std::allocator_traits<allocator_type>::propagate_on_container_swap::value est true, alors les allocateurs sont échangés via un appel non qualifié à la fonction non membre swap. Sinon, ils ne sont pas échangés (et si get_allocator() != other.get_allocator(), le comportement est indéfini).

(depuis C++11)

Paramètres

  • other — conteneur avec lequel échanger le contenu

Exceptions

Toute exception levée par l'échange des objets Hash ou KeyEqual.

(jusqu'à C++17)

noexcept specification:noexcept(std::allocator_traits<Allocator>::is_always_equal::value && std::is_nothrow_swappable<Hash>::value && std::is_nothrow_swappable<key_equal>::value)

(depuis C++17)

Complexité

Constante.

Exemple

#include <iostream>
#include <unordered_set>

template<class Os, class Co> Os& operator<<(Os& os, const Co& co)
{
    os << '{';
    for (auto const& i : co)
        os << ' ' << i;
    return os << " } ";
}

int main()
{
    std::unordered_multiset<int> a1{3, 1, 3, 2}, a2{5, 4, 5};

    auto it1 = std::next(a1.begin());
    auto it2 = std::next(a2.begin());

    const int& ref1 = *(a1.begin());
    const int& ref2 = *(a2.begin());

    std::cout << a1 << a2 << *it1 << ' ' << *it2 << ' ' << ref1 << ' ' << ref2 << '\n';
    a1.swap(a2);
    std::cout << a1 << a2 << *it1 << ' ' << *it2 << ' ' << ref1 << ' ' << ref2 << '\n';

    // Notez que chaque itérateur faisant référence à un élément d'un conteneur avant l'échange
    // fait référence au même élément dans l'autre conteneur après l'échange. Il en va de même
    // pour les références.
}

Sortie possible :

{ 2 3 3 1 } { 4 5 5 } 3 5 2 4
{ 4 5 5 } { 2 3 3 1 } 3 5 2 4
