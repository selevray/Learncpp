std::unordered_multiset<Key,Hash,KeyEqual,Allocator>::size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

size_type size() const noexcept;  // (depuis C++11)

Renvoie le nombre d'éléments du conteneur, c'est-à-dire std::distance(begin(), end()).

Paramètres

(aucune)

Valeur de retour

Le nombre d'éléments du conteneur.

Complexité

Constante.

Exemple

#include <cassert>
#include <unordered_set>

int main()
{
    std::unordered_multiset<int> nums{4, 2, 4, 2};
    assert(nums.size() == 4);
}
