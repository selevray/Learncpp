std::unordered_multiset<Key,Hash,KeyEqual,Allocator>::clear

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void clear() noexcept;  // (depuis C++11)

Efface tous les éléments du conteneur. Après cet appel, size() renvoie zéro.

Invalide toutes les références, tous les pointeurs et tous les itérateurs désignant les éléments contenus. Peut aussi invalider les itérateurs de fin (past-the-end).

Paramètres

(aucune)

Valeur de retour

(aucune)

Complexité

Linéaire en la taille du conteneur, c'est-à-dire le nombre d'éléments.

Exemple

#include <iostream>
#include <string_view>
#include <unordered_set>

void print_info(std::string_view rem, const std::unordered_multiset<int>& v)
{
    std::cout << rem << "{ ";
    for (const auto& value : v)
        std::cout << value << ' ';
    std::cout << "}\n";
    std::cout << "Size=" << v.size() << '\n';
}

int main()
{
    std::unordered_multiset<int> container{1, 2, 3};
    print_info("Before clear: ", container);
    container.clear();
    print_info("After clear: ", container);
}

Sortie possible :

Before clear: { 1 2 3 }
Size=3
After clear: { }
Size=0
