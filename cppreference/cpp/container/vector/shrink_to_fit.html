std::vector<T,Allocator>::shrink_to_fit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void shrink_to_fit();  // (constexpr depuis C++20)

Demande la libération de la capacité inutilisée.

Il s'agit d'une demande non contraignante de réduire capacity() à size(). Il dépend de l'implémentation que la demande soit satisfaite ou non.

Si une réallocation a lieu, tous les itérateurs (y compris l'itérateur end()) et toutes les références aux éléments sont invalidés. Si aucune réallocation n'a lieu, aucun itérateur ni aucune référence n'est invalidé.

Si T n'est pas MoveInsertable dans std::vector<T, Allocator>, le comportement est indéfini.

(depuis C++11)

Complexité

Au plus linéaire en fonction de la taille du conteneur.

Exceptions

Si une exception est levée autrement que par le constructeur de déplacement d'un non-CopyInsertable T, il n'y a aucun effet.

(depuis C++11)

Notes

Dans libstdc++, shrink_to_fit() n'est pas disponible en mode C++98.

Exemple

#include <iostream>
#include <vector>

int main()
{
    std::vector<int> v;
    std::cout << "Default-constructed capacity is " << v.capacity() << '\n';
    v.resize(100);
    std::cout << "Capacity of a 100-element vector is " << v.capacity() << '\n';
    v.resize(50);
    std::cout << "Capacity after resize(50) is " << v.capacity() << '\n';
    v.shrink_to_fit();
    std::cout << "Capacity after shrink_to_fit() is " << v.capacity() << '\n';
    v.clear();
    std::cout << "Capacity after clear() is " << v.capacity() << '\n';
    v.shrink_to_fit();
    std::cout << "Capacity after shrink_to_fit() is " << v.capacity() << '\n';
    for (int i = 1000; i < 1300; ++i)
        v.push_back(i);
    std::cout << "Capacity after adding 300 elements is " << v.capacity() << '\n';
    v.shrink_to_fit();
    std::cout << "Capacity after shrink_to_fit() is " << v.capacity() << '\n';
}

Sortie possible :

Capacity after shrink_to_fit() is 0

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 755 C++98 std::vector ne disposait pas d'opérations explicites de réduction à la taille (shrink-to-fit) provided
LWG 2033 C++98 C++11 1. l'exigence de complexité manquait (C++98) 2. T n'était pas requis d'être MoveInsertable (C++11) 1. ajouté 2. requis
LWG 2223 C++98 C++11 1. les références, pointeurs et itérateurs n'étaient pas invalidés (C++98) 2. il n'existait aucune garantie de sécurité d'exception (C++11) 1. ils peuvent être invalidés 2. ajouté
