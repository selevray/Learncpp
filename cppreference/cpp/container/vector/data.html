std::vector<T,Allocator>::data

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

T* data();  // (1) (noexcept depuis C++11) (constexpr depuis C++20)

const T* data() const;  // (2) (noexcept depuis C++11) (constexpr depuis C++20)

Retourne un pointeur vers le tableau sous-jacent servant de stockage des éléments. Le pointeur est tel que l'intervalle [data(),data() + size()) est toujours un intervalle valide, même si le conteneur est vide (data() n'est alors pas déréférençable).

Paramètres

(aucune)

Valeur de retour

Pointeur vers le stockage sous-jacent des éléments. Pour les conteneurs non vides, le pointeur retourné compare égal à l'adresse du premier élément.

Complexité

Constante.

Notes

Si size() vaut 0, data() peut ou non retourner un pointeur nul.

Exemple

#include <cstddef>
#include <iostream>
#include <span>
#include <vector>

void pointer_func(const int* p, std::size_t size)
{
    std::cout << "data = ";
    for (std::size_t i = 0; i < size; ++i)
        std::cout << p[i] << ' ';
    std::cout << '\n';
}

void span_func(std::span<const int> data) // depuis C++20
{
    std::cout << "data = ";
    for (const int e : data)
        std::cout << e << ' ';
    std::cout << '\n';
}

int main()
{
    std::vector<int> container{1, 2, 3, 4};

    // Préférer container.data() à &container[0]
    pointer_func(container.data(), container.size());

    // std::span est une alternative plus sûre à un pointeur et une taille séparés.
    span_func({container.data(), container.size()});
}

Output:

data = 1 2 3 4
data = 1 2 3 4
