std::vector<T,Allocator>::clear

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void clear();  // (noexcept depuis C++11) (constexpr depuis C++20)

Efface tous les éléments du conteneur. Après cet appel, size() renvoie zéro.

Invalide toutes les références, tous les pointeurs et itérateurs désignant des éléments contenus. Les itérateurs au-delà de la fin sont également invalidés.

Laisse la capacity() du vecteur inchangée (Remarque : la restriction de la norme sur les modifications de capacité figure dans la spécification de reserve(), voir SO).

Paramètres

(aucune)

Valeur de retour

(aucune)

Complexité

Linéaire en la taille du conteneur, c'est-à-dire le nombre d'éléments.

Exemple

#include <iostream>
#include <string_view>
#include <vector>

void print_info(std::string_view rem, const std::vector<int>& v)
{
    std::cout << rem << "{ ";
    for (const auto& value : v)
        std::cout << value << ' ';
    std::cout << "}\n";
    std::cout << "Size=" << v.size() << ", Capacity=" << v.capacity() << '\n';
}

int main()
{
    std::vector<int> container{1, 2, 3};
    print_info("Before clear: ", container);
    container.clear();
    print_info("After clear: ", container);
}

Output:

Before clear: { 1 2 3 }
Size=3, Capacity=3
After clear: { }
Size=0, Capacity=3
