std::vector<T,Allocator>::assign

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void assign( size_type count, const T& value );  // (1) (constexpr depuis C++20)

template< class InputIt >
void assign( InputIt first, InputIt last );  // (2) (constexpr depuis C++20)

void assign( std::initializer_list<T> ilist );  // (3) (depuis C++11) (constexpr depuis C++20)

Remplace le contenu du conteneur.

  1. Remplace le contenu par count copies de la valeur value.

  2. Remplace le contenu par des copies de celles de l'intervalle [first,last).

Si l'un des arguments est un itérateur dans *this, le comportement est indéfini.

Cette surcharge a le même effet que la surcharge (1) si InputIt est un type entier.

(jusqu'à C++11)

Cette surcharge ne participe à la résolution de surcharge que si InputIt satisfait LegacyInputIterator.

(depuis C++11)

  1. Remplace le contenu par les éléments de ilist.

Tous les itérateurs (y compris l'itérateur end()) et toutes les références aux éléments sont invalidés.

Paramètres

  • count — la nouvelle taille du conteneur
  • value — la valeur avec laquelle initialiser les éléments du conteneur
  • first, last — l'intervalle dont copier les éléments
  • ilist — std::initializer_list dont copier les valeurs

Complexité

  1. Linéaire en count.

  2. Linéaire en la distance entre first et last.

  3. Linéaire en ilist.size().

Exemple

Le code suivant utilise assign pour ajouter plusieurs caractères à un std::vector<char> :

#include <vector>
#include <iostream>
#include <string>

int main()
{
    std::vector<char> characters;

    auto print_vector = [&]()
    {
        for (char c : characters)
            std::cout << c << ' ';
        std::cout << '\n';
    };

    characters.assign(5, 'a');
    print_vector();

    const std::string extra(6, 'b');
    characters.assign(extra.begin(), extra.end());
    print_vector();

    characters.assign({'C', '+', '+', '1', '1'});
    print_vector();
}

Output:

a a a a a
b b b b b b
C + + 1 1
