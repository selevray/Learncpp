Compare le contenu de deux vector.

1,2) Vérifie si le contenu de lhs et de rhs est égal, c'est-à-dire qu'ils ont le même nombre d'éléments et que chaque élément de lhs est égal à l'élément de rhs situé à la même position.

3-6) Compare le contenu de lhs et rhs lexicographiquement. La comparaison est effectuée par une fonction équivalente à std::lexicographical_compare.

  1. Compare le contenu de lhs et rhs lexicographiquement. La comparaison est effectuée comme si l'on appelait std::lexicographical_compare_three_way(lhs.begin(), lhs.end(), rhs.begin(), rhs.end(), synth-three-way).

Le type de retour est le type de retour de synth-three-way (c'est-à-dire synth-three-way-result ﻿<T>).

Si aucune des conditions suivantes n'est satisfaite, le comportement est indéfini :

  • T modélise three_way_comparable.
  • < est défini pour des valeurs de type (éventuellement qualifié const) T, et < est une relation d'ordre total.

Les opérateurs <, <=, >, >= et != sont synthétisés à partir de operator<=> et operator== respectivement.

(depuis C++20)

Paramètres

  • lhs, rhs — vectors dont le contenu doit être comparé
  • T doit satisfaire les exigences de EqualityComparable pour pouvoir utiliser les surcharges (1,2).
  • T doit satisfaire les exigences de LessThanComparable pour pouvoir utiliser les surcharges (3-6). La relation d'ordre doit établir un ordre total.

Valeur de retour

  1. true si le contenu des vector est égal, false sinon.

  2. true si le contenu des vector n'est pas égal, false sinon.

  3. true si le contenu de lhs est lexicographiquement inférieur à celui de rhs, false sinon.

  4. true si le contenu de lhs est lexicographiquement inférieur ou égal à celui de rhs, false sinon.

  5. true si le contenu de lhs est lexicographiquement supérieur à celui de rhs, false sinon.

  6. true si le contenu de lhs est lexicographiquement supérieur ou égal à celui de rhs, false sinon.

  7. L'ordre relatif de la première paire d'éléments non équivalents de lhs et rhs, s'il en existe, lhs.size() <=> rhs.size() sinon.

Complexité

1,2) Constant si lhs et rhs sont de tailles différentes, sinon linéaire en fonction de la taille de vector.

3-7) Linéaire en fonction de la taille de vector.

Notes

Les opérateurs relationnels sont définis en termes de operator< du type d'élément.

(jusqu'à C++20)

Les opérateurs relationnels sont définis en termes de synth-three-way, qui utilise operator<=> si possible, sinon operator<.

En particulier, si l'élément ne fournit pas lui-même operator<=>, mais est implicitement convertible en un type comparable à trois voies, cette conversion sera utilisée à la place de operator<.

(depuis C++20)

Exemple

#include <cassert>
#include <compare>
#include <vector>

int main()
{
    const std::vector
        a{1, 2, 3},
        b{1, 2, 3},
        c{7, 8, 9, 10};

    assert
    (""
        "Compare equal containers:" &&
        (a != b) == false &&
        (a == b) == true &&
        (a < b) == false &&
        (a <= b) == true &&
        (a > b) == false &&
        (a >= b) == true &&
        (a <=> b) != std::weak_ordering::less &&
        (a <=> b) != std::weak_ordering::greater &&
        (a <=> b) == std::weak_ordering::equivalent &&
        (a <=> b) >= 0 &&
        (a <=> b) <= 0 &&
        (a <=> b) == 0 &&

        "Compare non equal containers:" &&
        (a != c) == true &&
        (a == c) == false &&
        (a < c) == true &&
        (a <= c) == true &&
        (a > c) == false &&
        (a >= c) == false &&
        (a <=> c) == std::weak_ordering::less &&
        (a <=> c) != std::weak_ordering::equivalent &&
        (a <=> c) != std::weak_ordering::greater &&
        (a <=> c) < 0 &&
        (a <=> c) != 0 &&
        (a <=> c) <= 0 &&
    "");
}
