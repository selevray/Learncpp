Construit un nouveau vector à partir de diverses sources de données, en utilisant éventuellement un allocateur fourni par l'utilisateur alloc.

  1. Le constructeur par défaut depuis C++11. Construit un vector vide avec un allocateur construit par défaut.

Si Allocator n'est pas DefaultConstructible, le comportement est indéfini.

  1. Le constructeur par défaut jusqu'à C++11. Construit un vector vide avec l'allocateur donné alloc.

  2. Construit un vector avec count objets insérés par défaut de T. Aucune copie n'est effectuée.

Si T n'est pas DefaultInsertable dans std::vector<T>, le comportement est indéfini.

  1. Construit un vector avec count copies d'éléments de valeur value.

Si T n'est pas CopyInsertable dans std::vector<T>, le comportement est indéfini.

(depuis C++11)

  1. Construit un vector avec le contenu de l'intervalle [first,last). Chaque itérateur de [first,last) est déréférencé exactement une fois.

Si InputIt ne satisfait pas aux exigences de LegacyInputIterator, la surcharge (4) est appelée à la place avec les arguments static_cast<size_type>(first), last et alloc.

(jusqu'à C++11)

Cette surcharge ne participe à la résolution de surcharge que si InputIt satisfait aux exigences de LegacyInputIterator.

Si l'une des conditions suivantes est satisfaite, le comportement est indéfini :

  • T n'est pas EmplaceConstructible dans std::vector<T> à partir de *first.
  • Iter ne satisfait pas aux exigences de LegacyForwardIterator, et T n'est pas MoveInsertable dans std::vector<T>.

(depuis C++11)

  1. Construit un vector avec le contenu de l'intervalle rg. Chaque itérateur de rg est déréférencé exactement une fois.

Si l'une des conditions suivantes est satisfaite, le comportement est indéfini :

  • T n'est pas EmplaceConstructible dans std::vector<T> à partir de *ranges::begin(rg).
  • R ne modélise ni sized_range ni forward_range, et T n'est pas MoveInsertable dans std::vector<T>.

7-10) Construit un vector avec le contenu de other.

  1. Le constructeur de copie.

L'allocateur est obtenu comme si l'on appelait std::allocator_traits<Allocator>:: select_on_container_copy_construction (other.get_allocator()).

(depuis C++11)

  1. Le constructeur de déplacement. L'allocateur est obtenu par construction par déplacement à partir de other.get_allocator().

  2. Identique au constructeur de copie, sauf que alloc est utilisé comme allocateur.

Si T n'est pas CopyInsertable dans std::vector<T>, le comportement est indéfini.

  1. Identique au constructeur de déplacement, sauf que alloc est utilisé comme allocateur.

Si T n'est pas MoveInsertable dans std::vector<T>, le comportement est indéfini.

  1. Équivalent à vector(il.begin(), il.end(), alloc).

Paramètres

  • alloc — allocateur à utiliser pour toutes les allocations mémoire de ce conteneur
  • count — la taille du conteneur
  • value — la valeur avec laquelle initialiser les éléments du conteneur
  • first, last — l'intervalle dont copier les éléments
  • other — autre conteneur servant de source pour initialiser les éléments du conteneur
  • init — liste d'initialisation pour initialiser les éléments du conteneur
  • rg — un intervalle compatible avec le conteneur

Complexité

1,2) Constante.

3,4) Linéaire en count.

  1. Étant donné std::distance(first, last) en tant que N :

  • Si first et last sont tous deux des itérateurs avant, bidirectionnels ou à accès aléatoire,

    • Le constructeur de copie de T n'est appelé que N fois, et
    • Aucune réallocation n'a lieu.

  • Sinon (first et last sont de simples itérateurs d'entrée),

    • Le constructeur de copie de T est appelé O(N) fois, et
    • Une réallocation a lieu O(log N) fois.
  1. Étant donné ranges::distance(rg) en tant que N :

  • Si R modélise ranges::forward_range ou ranges::sized_range,

    • Initialise exactement N éléments à partir du résultat de la déréférenciation d'itérateurs successifs de rg, et
    • Aucune réallocation n'a lieu.

  • Sinon (R modélise un intervalle d'entrée),

    • Le constructeur de copie ou de déplacement de T est appelé O(N) fois, et
    • Une réallocation a lieu O(log N) fois.

  1. Linéaire en other.size().

  2. Constante.

  3. Linéaire en other.size().

  4. Linéaire en other.size() si alloc != other.get_allocator(), sinon constante.

  5. Linéaire en init.size().

Exceptions

Les appels à Allocator::allocate peuvent lever une exception.

Notes

Après la construction par déplacement du conteneur (surcharge (8)), les références, pointeurs et itérateurs (autres que l'itérateur de fin) vers other restent valides, mais désignent des éléments qui sont désormais dans *this. La norme actuelle fournit cette garantie via l'énoncé général de [container.reqmts]/67, et une garantie plus directe est à l'étude via LWG issue 2321.

Exemple

#include <iostream>
#include <string>
#include <vector>

template<typename T>
std::ostream& operator<<(std::ostream& s, const std::vector<T>& v)
{
    s.put('{');
    for (char comma[]{'\0', ' ', '\0'}; const auto& e : v)
        s << comma << e, comma[0] = ',';
    return s << "}\n";
}

int main()
{
    // Syntaxe de liste d'initialisation C++11 :
    std::vector<std::string> words1{"the", "frogurt", "is", "also", "cursed"};
    std::cout << "1: " << words1;

    // words2 == words1
    std::vector<std::string> words2(words1.begin(), words1.end());
    std::cout << "2: " << words2;

    // words3 == words1
    std::vector<std::string> words3(words1);
    std::cout << "3: " << words3;

    // words4 vaut {"Mo", "Mo", "Mo", "Mo", "Mo"}
    std::vector<std::string> words4(5, "Mo");
    std::cout << "4: " << words4;

    const auto rg = {"cat", "cow", "crow"};
#ifdef __cpp_lib_containers_ranges
    std::vector<std::string> words5(std::from_range, rg); // overload (6)
#else
    std::vector<std::string> words5(rg.begin(), rg.end()); // overload (5)
#endif
    std::cout << "5: " << words5;
}

Output:

1: {the, frogurt, is, also, cursed}
2: {the, frogurt, is, also, cursed}
3: {the, frogurt, is, also, cursed}
4: {Mo, Mo, Mo, Mo, Mo}
5: {cat, cow, crow}
