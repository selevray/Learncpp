std::vector<T,Allocator>::pop_back

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void pop_back();  // (constexpr depuis C++20)

Supprime le dernier élément du conteneur.

Appeler pop_back sur un conteneur vide entraîne un comportement indéfini.

Les itérateurs et références vers le dernier élément sont invalidés. L'itérateur end() est également invalidé.

Paramètres

(aucune)

Valeur de retour

(aucune)

Complexité

Constante.

Exceptions

Ne lève aucune exception.

Exemple

#include <vector>
#include <iostream>

namespace stq {
template<typename T>
void println(auto, const T& xz)
{
    std::cout << '[';
    bool first{true};
    for (auto const& x : xz)
        std::cout << (first ? first = false, "" : ", ") << x;
    std::cout << "]\n";
}
}

int main()
{
    std::vector<int> numbers{1, 2, 3};
    stq::println("{}", numbers);
    while (not numbers.empty())
    {
        numbers.pop_back();
        stq::println("{}", numbers);
    }
}

Output:

[1, 2, 3]
[1, 2]
[1]
[]
