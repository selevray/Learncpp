std::vector<T,Allocator>::front

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

reference front();  // (1) (constexpr depuis C++20)

const_reference front() const;  // (2) (constexpr depuis C++20)

Retourne une référence au premier élément du conteneur.

Appeler front sur un conteneur vide entraîne un comportement indéfini.

Paramètres

(aucune)

Valeur de retour

Référence au premier élément.

Complexité

Constante.

Notes

Pour un conteneur c, l'expression c.front() est équivalente à *c.begin().

Exemple

Le code suivant utilise front pour afficher le premier élément d'un std::vector<char> :

#include <cassert>
#include <vector>

int main()
{
    std::vector<char> letters{'a', 'b', 'c', 'd'};
    assert(letters.front() == 'a');
}
