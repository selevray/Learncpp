guides de déduction pour std::vector

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <vector>

template< class InputIt,
          class Alloc = std::allocator<
              typename std::iterator_traits<InputIt>::value_type> >
vector( InputIt, InputIt, Alloc = Alloc() )
    -> vector<typename std::iterator_traits<InputIt>::value_type, Alloc>;  // (1) (depuis C++17)

template< ranges::input_range R,
          class Alloc = std::allocator<ranges::range_value_t<R>> >
vector( std::from_range_t, R&&, Alloc = Alloc() )
    -> vector<ranges::range_value_t<R>, Alloc>;  // (2) (depuis C++23)

  1. Ce guide de déduction est fourni pour vector afin de permettre la déduction à partir d'un intervalle d'itérateurs. Cette surcharge ne participe à la résolution de surcharge que si InputIt satisfait LegacyInputIterator et Alloc satisfait Allocator.

  2. Ce guide de déduction est fourni pour vector afin de permettre la déduction à partir d'une balise std::from_range_t et d'un input_range.

Remarque : la mesure dans laquelle la bibliothèque détermine qu'un type ne satisfait pas LegacyInputIterator n'est pas spécifiée, sauf qu'au minimum les types entiers ne sont pas qualifiés comme itérateurs d'entrée. De même, la mesure dans laquelle elle détermine qu'un type ne satisfait pas Allocator n'est pas spécifiée, sauf qu'au minimum le type membre Alloc::value_type doit exister et l'expression std::declval<Alloc&>().allocate(std::size_t{}) doit être bien formée lorsqu'elle est traitée comme opérande non évalué.

Exemple

#include <vector>

int main()
{
    std::vector<int> v = {1, 2, 3, 4};

    // utilise un guide de déduction explicite pour déduire std::vector<int>
    std::vector x(v.begin(), v.end());

    // déduit std::vector<std::vector<int>::iterator>
    // la première phase de la résolution de surcharge pour l'initialisation par liste sélectionne le candidat
    // synthétisé à partir du constructeur prenant std::initializer_list ; la seconde phase n'est pas effectuée
    // et le guide de déduction n'a aucun effet
    std::vector y{v.begin(), v.end()};
}
