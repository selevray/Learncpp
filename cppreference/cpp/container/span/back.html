std::span<T,Extent>::back

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr reference back() const;  // (depuis C++20)

Retourne une référence vers le dernier élément du span.

Appeler back sur un span vide entraîne un comportement indéfini.

Paramètres

(aucune)

Valeur de retour

Une référence vers l'élément arrière.

Complexité

Constante.

Notes

Pour un span c, l'expression c.back() est équivalente à *(c.end() - 1).

Exemple

#include <iostream>
#include <span>

void print_forward(std::span<const int> const span)
{
    for (auto n{span.size()}; n != 0; --n)
        std::cout << span.last(n).front() << ' ';
    std::cout << '\n';
}

void print_backward(std::span<const int> const span)
{
    for (auto n{span.size()}; n != 0; --n)
        std::cout << span.first(n).back() << ' ';
    std::cout << '\n';
}

int main()
{
    constexpr int numbers[]{0, 1, 2, 3, 4};
    print_forward(numbers);
    print_backward(numbers);
}

Output:

0 1 2 3 4
4 3 2 1 0
