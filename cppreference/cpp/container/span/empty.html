std::span<T,Extent>::empty

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr bool empty() const noexcept;  // (depuis C++20)

Vérifie si le span est vide.

Paramètres

(aucune)

Valeur de retour

true si le span est vide (c'est-à-dire size() == 0) ; false sinon.

Exemple

#include <iomanip>
#include <iostream>
#include <span>

int main()
{
    std::span<const char> span{"ABCDEF"};

    while (!span.empty())
    {
        std::cout << std::quoted(span.data()) << '\n';
        span = span.last(span.size() - 1);
    }
}

Output:

"ABCDEF"
"BCDEF"
"CDEF"
"DEF"
"EF"
"F"
""
