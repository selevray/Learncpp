std::span<T,Extent>::data

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr pointer data() const noexcept;  // (depuis C++20)

Retourne un pointeur vers le début de la séquence.

Valeur de retour

Un pointeur vers le début de la séquence.

Exemple

#include <iostream>
#include <span>

int main()
{
    constexpr char str[] = "ABCDEF\n";

    const std::span sp{str};

    for (auto n{sp.size()}; n != 2; --n)
        std::cout << sp.last(n).data();
}

Output:

ABCDEF
BCDEF
CDEF
DEF
EF
F
