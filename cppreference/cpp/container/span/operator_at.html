std::span<T,Extent>::operator[]

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr reference operator[]( size_type idx ) const;  // (depuis C++20)

Retourne une référence vers le idxe élément de la séquence. Le comportement est indéfini si idx est hors intervalle (c'est-à-dire si elle est supérieure ou égale à size()).

Paramètres

  • idx — l'indice de l'élément à accéder

Valeur de retour

Une référence vers le idxe élément de la séquence, c'est-à-dire data()[idx].

Exceptions

Ne lève aucune exception.

Exemple

#include <cstddef>
#include <iostream>
#include <span>
#include <utility>

void reverse(std::span<int> span)
{
    for (std::size_t i = 0, j = std::size(span); i < j; ++i)
    {
        --j;
        std::swap(span[i], span[j]);
    }
}

void print(std::span<const int> const span)
{
    for (int element : span)
        std::cout << element << ' ';
    std::cout << '\n';
}

int main()
{
    int data[]{1, 2, 3, 4, 5};
    print(data);
    reverse(data);
    print(data);
}

Output:

1 2 3 4 5
5 4 3 2 1
