std::span<T,Extent>::size_bytes

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr size_type size_bytes() const noexcept;  // (depuis C++20)

Retourne la taille de la séquence en octets.

Paramètres

(aucune)

Valeur de retour

La taille de la séquence en octets, c'est-à-dire size() * sizeof(element_type).

Exemple

#include <cstdint>
#include <span>

int main()
{
    constexpr static std::int32_t a[]{1, 2, 3, 4, 5};
    constexpr static std::span s{a};

    static_assert
    (
        sizeof(int32_t) == 4 &&
        std::size(a) == 5 &&
        sizeof a == 20 &&
        s.size() == 5 &&
        s.size_bytes() == 20
    );
}
