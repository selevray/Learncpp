Construit un span.

  1. Construit un span vide dont data() == nullptr et size() == 0.
  • Cette surcharge ne participe à la résolution de surcharge que si extent == 0 || extent == std::dynamic_extent.
  1. Construit un span qui est une vue sur l'intervalle [first,first + count) ; le span résultant a data() == std::to_address(first) et size() == count.
  • Le comportement est indéfini si [first,first + count) n'est pas un intervalle valide, si It ne modélise pas réellement contiguous_iterator, ou si extent != std::dynamic_extent && count != extent.
  • Cette surcharge ne participe à la résolution de surcharge que si
    • It satisfait contiguous_iterator,
    • la conversion de std::iter_reference_t<It> vers element_type est au plus une conversion de qualification.
  1. Construit un span qui est une vue sur l'intervalle [first,last) ; le span résultant a data() == std::to_address(first) et size() == last-first.
  • Le comportement est indéfini si [first,last) n'est pas un intervalle valide, si It ne modélise pas réellement contiguous_iterator, si End ne modélise pas réellement sized_sentinel_for pour It, ou si extent != std::dynamic_extent && last-first != extent.
  • Cette surcharge ne participe à la résolution de surcharge que si
    • It satisfait contiguous_iterator,
    • End satisfait sized_sentinel_for pour It,
    • la conversion de std::iter_reference_t<It> vers element_type est au plus une conversion de qualification, et
    • std::is_convertible_v<End, std::size_t> is false.

4-6) Construit un span qui est une vue sur le tableau arr ; le span résultant a size() == N et data() == std::data(arr).

  • Ces surcharges ne participent à la résolution de surcharge que si extent == std::dynamic_extent || N == extent est true et que la conversion de std::remove_pointer_t<decltype(data(arr))> vers element_type est au plus une conversion de qualification.
  1. Construit un span qui est une vue sur l'intervalle range ; le span résultant a size() == std::ranges::size(range) et data() == std::ranges::data(range).
  • Le comportement est indéfini si R ne modélise pas réellement contiguous_range et sized_range, ou si R ne modélise pas borrowed_range alors que element_type n'est pas const, ou si extent != dynamic_extent et std::ranges::size(range) != extent sont true.
  • Cette surcharge ne participe à la résolution de surcharge que si
    • R satisfait contiguous_range et sized_range,
    • soit R satisfait borrowed_range, soit std::is_const_v<element_type> est true,
    • std::remove_cvref_t<R> n'est pas une spécialisation de std::span,
    • std::remove_cvref_t<R> n'est pas une spécialisation de std::array,
    • std::is_array_v<std::remove_cvref_t<R>> vaut faux, et
    • la conversion de std::ranges::range_reference_t<R> vers element_type est au plus une conversion de qualification.
  1. Construit un span qui est une vue sur la liste d'initialisation il ; le span résultant a size() == il.size() et data() == il.begin().
  • Le comportement est indéfini si extent != dynamic_extent et il.size() != extent sont true.
  • Cette surcharge ne participe à la résolution de surcharge que si std::is_const_v<element_type> est true.
  1. Constructeur de conversion à partir d'un autre span source ; le span résultant a size() == source.size() et data() == source.data().
  • Le comportement est indéfini si extent != dynamic_extent et source.size() != extent sont true.
  • Cette surcharge ne participe à la résolution de surcharge que si au moins l'un de extent == std::dynamic_extent, N == std::dynamic_extent et N == extent est true et que la conversion de U vers element_type est au plus une conversion de qualification.
  1. Le constructeur de copie défini par défaut copie la taille et le pointeur de données ; le span résultant a size() == other.size() et data() == other.data().

Paramètres

  • first — itérateur vers le premier élément de la séquence
  • count — nombre d'éléments de la séquence
  • last — itérateur au-delà du dernier élément de la séquence, ou autre sentinelle
  • arr — tableau pour lequel construire une vue
  • range — intervalle pour lequel construire une vue
  • source — autre span à partir duquel convertir
  • other — autre span à partir duquel copier

Exceptions

  1. Ne lève aucune exception.

  2. Lève les mêmes exceptions, dans les mêmes conditions, que last - first.

  3. Lève les mêmes exceptions, dans les mêmes conditions, que std::ranges::size(r) et std::ranges::data(r).

Exemple

#include <array>
#include <iostream>
#include <span>
#include <vector>

void print_span(std::span<const int> s)
{
    for (int n : s)
        std::cout << n << ' ';
    std::cout << '\n';
}

int main()
{
    int c[]{1, 2, 3};
    print_span(c); // construit à partir d'un tableau

    std::array a{4, 5, 6};
    print_span(a); // construit à partir de std::array

    std::vector v{7, 8, 9};
    print_span(v); // construit à partir de std::vector

#if __cpp_lib_span_initializer_list
    print_span({0, 1, 2}); // construit à partir de initializer_list
#else
    print_span({{0, 1, 2}}); // idem, une solution de contournement
#endif
}

Output:

1 2 3
4 5 6
7 8 9
0 1 2
