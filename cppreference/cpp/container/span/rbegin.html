Retourne un itérateur inverse vers le premier élément du span inversé. Il correspond au dernier élément du span non inversé. Si le span est vide, l'itérateur retourné est égal à rend().

range-rbegin-rend.svg

Paramètres

(aucune)

Valeur de retour

Itérateur inverse vers le premier élément.

Complexité

Constante.

Notes

Le itérateur sous-jacent de l'itérateur inverse renvoyé est l'itérateur de fin. Par conséquent, l'itérateur renvoyé est invalidé si et quand l'itérateur de fin est invalidé.

Exemple

#include <algorithm>
#include <iostream>
#include <iterator>
#include <span>

int main()
{
    constexpr std::span<const char> code{"@droNE_T0P_w$s@s#_SECRET_a,p^42!"};

    auto hack = [](const unsigned O) { return O - 0141 < 120; };

    std::copy_if(code.rbegin(), code.rend(),
        std::ostream_iterator<const char>(std::cout), hack);

    std::cout << '\n';
}

Output:

password
