std::span<T,Extent>::last

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< std::size_t Count >
constexpr std::span<element_type, Count> last() const;  // (1) (depuis C++20)

constexpr std::span<element_type, std::dynamic_extent> last( size_type Count ) const;  // (2) (depuis C++20)

Obtient un span qui est une vue sur les Count derniers éléments de ce span. Le programme est mal formé si Count > Extent. Le comportement est indéfini si Count > size().

Valeur de retour

Un span r qui est une vue sur les Count derniers éléments de *this, tel que r.data() == this->data() + (this->size() - Count) && r.size() == Count.

Exemple

#include <iostream>
#include <span>
#include <string_view>

void println(std::string_view const title, auto const& container)
{
    std::cout << title << '[' << std::size(container) << "]{ ";
    for (auto const& elem : container)
        std::cout << elem << ", ";
    std::cout << "};\n";
};

void run(std::span<const int> span)
{
    println("span: ", span);

    std::span<const int, 3> span_last = span.last<3>();
    println("span.last<3>(): ", span_last);

    std::span<const int, std::dynamic_extent> span_last_dynamic = span.last(2);
    println("span.last(2): ", span_last_dynamic);
}

int main()
{
    int a[8]{1, 2, 3, 4, 5, 6, 7, 8};
    println("int a", a);
    run(a);
}

Output:

int a[8]{ 1, 2, 3, 4, 5, 6, 7, 8, };
span: [8]{ 1, 2, 3, 4, 5, 6, 7, 8, };
span.last<3>(): [3]{ 6, 7, 8, };
span.last(2): [2]{ 7, 8, };
