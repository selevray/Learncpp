std::priority_queue<T,Container,Compare>::push_range

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< container-compatible-range<value_type> R >
void push_range( R&& rg );  // (depuis C++23)

Insère une copie de chaque élément de rg dans priority_queue, comme si l'on effectuait :

  • c.append_range(std::forward<R>(rg)) si cette expression est valide (c'est-à-dire si le conteneur sous-jacent c possède une fonction membre append_range appropriée), ou
  • ranges::copy(rg, std::back_inserter(c)) sinon.

Rétablit ensuite la propriété de tas comme si l'on appelait ranges::make_heap(c, comp). Après l'insertion, ranges::is_heap(c, comp) est true.

Chaque itérateur de l'intervalle rg est déréférencé exactement une fois.

Paramètres

  • rg — une plage compatible avec le conteneur, c'est-à-dire un input_range dont les éléments sont convertibles en T

Valeur de retour

(aucune)

Complexité

La complexité de c.append_range plus la complexité de ranges::make_heap(c, comp).

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_containers_ranges 202202L (C++23) Construction et insertion prenant en compte les plages

Exemple

#include <algorithm>
#include <iostream>
#include <ranges>
#include <queue>

template<typename Adaptor>
requires (std::ranges::input_range<typename Adaptor::container_type>)
void println(auto, const Adaptor& adaptor)
{
    struct Container : Adaptor // donne accès au membre protégé Adaptor::Container c;
    {
        auto const& container() const { return this->c; }
    };

    for (auto const& elem : static_cast<const Container&>(adaptor).container())
        std::cout << elem << ' ';
    std::cout << '\n';
}

int main()
{
    std::priority_queue<int> adaptor;
    const auto rg = {1, 3, 2, 4};

#ifdef __cpp_lib_containers_ranges
    adaptor.push_range(rg);
#else
    std::ranges::for_each(rg, [&adaptor](auto e){ adaptor.push(e); });
#endif

    println("{}", adaptor);
}

Output:

4 3 2 1
