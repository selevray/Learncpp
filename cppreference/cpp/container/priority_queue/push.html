std::priority_queue<T,Container,Compare>::push

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void push( const value_type& value );  // (1)

void push( value_type&& value );  // (2) (depuis C++11)

Ajoute l'élément donné value à la file de priorité.

  1. Équivalent à : c.push_back(value); std::push_heap(c.begin(), c.end(), comp);.

  2. Équivalent à : c.push_back(std::move(value)); std::push_heap(c.begin(), c.end(), comp);.

Paramètres

  • value — la valeur de l'élément à ajouter

Valeur de retour

(aucune)

Complexité

Nombre logarithmique de comparaisons plus la complexité de Container::push_back.

Exemple

#include <iostream>
#include <queue>

struct Event
{
    int priority{};
    char data{' '};

    friend bool operator<(Event const& lhs, Event const& rhs)
    {
        return lhs.priority < rhs.priority;
    }

    friend std::ostream& operator<<(std::ostream& os, Event const& e)
    {
        return os << '{' << e.priority << ", '" << e.data << "'}";
    }
};

int main()
{
    std::priority_queue<Event> events;

    std::cout << "Fill the events queue:\t";

    for (auto const e : {Event{6,'L'}, {8,'I'}, {9,'S'}, {1,'T'}, {5,'E'}, {3,'N'}})
    {
        std::cout << e << ' ';
        events.push(e);
    }

    std::cout << "\nProcess events:\t\t";

    for (; !events.empty(); events.pop())
    {
        Event const& e = events.top();
        std::cout << e << ' ';
    }

    std::cout << '\n';
}

Output:

Fill the events queue:  {6, 'L'} {8, 'I'} {9, 'S'} {1, 'T'} {5, 'E'} {3, 'N'}
Process events:         {9, 'S'} {8, 'I'} {6, 'L'} {5, 'E'} {3, 'N'} {1, 'T'}
