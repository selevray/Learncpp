Construit un nouveau conteneur sous-jacent de l'adaptateur de conteneur à partir de diverses sources de données.

  1. Constructeur par défaut. Initialise par valeur le comparateur et le conteneur sous-jacent.

  2. Construit par copie le foncteur de comparaison comp à partir du contenu de compare. Initialise par valeur le conteneur sous-jacent c.

  3. Construit par copie le conteneur sous-jacent c à partir du contenu de cont. Construit par copie le foncteur de comparaison comp à partir du contenu de compare. Appelle std::make_heap(c.begin(), c.end(), comp). C'est aussi le constructeur par défaut. (jusqu'à C++11)

  4. Construit par déplacement le conteneur sous-jacent c avec std::move(cont). Construit par copie le foncteur de comparaison comp avec compare. Appelle std::make_heap(c.begin(), c.end(), comp).

  5. Constructeur de copie. Le conteneur sous-jacent est construit par copie avec other.c. Le foncteur de comparaison est construit par copie avec other.comp. (déclaré implicitement)

  6. Constructeur de déplacement. Le conteneur sous-jacent est construit avec std::move(other.c). Le foncteur de comparaison est construit avec std::move(other.comp). (déclaré implicitement)

7-9) Constructeurs à paire d'itérateurs. Ces surcharges ne participent à la résolution de surcharge que si InputIt satisfait LegacyInputIterator.

  1. Construit c comme si par c(first, last) et comp à partir de compare. Appelle ensuite std::make_heap(c.begin(), c.end(), comp);.

  2. Construit par copie c à partir de cont et comp à partir de compare. Appelle ensuite c.insert(c.end(), first, last);, puis appelle std::make_heap(c.begin(), c.end(), comp);.

  3. Construit par déplacement c à partir de std::move(cont) et construit par copie comp à partir de compare. Appelle ensuite c.insert(c.end(), first, last);, puis appelle std::make_heap(c.begin(), c.end(), comp);.

10-15) Constructeurs étendus par allocateur. Ces surcharges ne participent à la résolution de surcharge que si std::uses_allocator<container_type, Alloc>::value est true, c'est-à-dire si le conteneur sous-jacent est un conteneur conscient de l'allocateur (vrai pour tous les conteneurs de la bibliothèque standard).

  1. Construit le conteneur sous-jacent en utilisant alloc comme allocateur. Appelle effectivement c(alloc). comp est initialisé par valeur.

  2. Construit le conteneur sous-jacent en utilisant alloc comme allocateur. Appelle effectivement c(alloc). Construit par copie comp à partir de compare.

  3. Construit le conteneur sous-jacent avec le contenu de cont et en utilisant alloc comme allocateur, comme si par c(cont, alloc). Construit par copie comp à partir de compare. Appelle ensuite std::make_heap(c.begin(), c.end(), comp).

  4. Construit le conteneur sous-jacent avec le contenu de cont en utilisant la sémantique de déplacement et en utilisant alloc comme allocateur, comme si par c(std::move(cont), alloc). Construit par copie comp à partir de compare. Appelle ensuite std::make_heap(c.begin(), c.end(), comp).

  5. Construit le conteneur sous-jacent avec le contenu de other.c et en utilisant alloc comme allocateur. Appelle effectivement c(other.c, alloc). Construit par copie comp à partir de other.comp.

  6. Construit le conteneur sous-jacent avec le contenu de other en utilisant la sémantique de déplacement tout en utilisant alloc comme allocateur. Appelle effectivement c(std::move(other.c), alloc). Construit par déplacement comp à partir de other.comp.

16-19) Constructeurs étendus par allocateur à paire d'itérateurs. Identiques à (7-9), sauf que alloc est utilisé pour construire le conteneur sous-jacent. Ces surcharges ne participent à la résolution de surcharge que si std::uses_allocator<container_type, Alloc>::value est true et que InputIt satisfait LegacyInputIterator.

  1. Initialise comp avec compare et c avec ranges::to<Container>(std::forward<R>(rg)). Appelle ensuite std::make_heap(c.begin(), c.end(), comp).

  2. Initialise comp avec compare et c avec ranges::to<Container>(std::forward<R>(rg), alloc). Appelle ensuite std::make_heap(c.begin(), c.end(), comp).

  3. Initialise c avec ranges::to<Container>(std::forward<R>(rg), alloc). Appelle ensuite std::make_heap(c.begin(), c.end(), comp).

Notez que la manière dont une implémentation vérifie qu'un type satisfait LegacyInputIterator est non spécifiée, sauf que les types entiers doivent être rejetés.

Paramètres

  • alloc — allocateur à utiliser pour toutes les allocations mémoire du conteneur sous-jacent
  • other — un autre adaptateur de conteneur à utiliser comme source pour initialiser le conteneur sous-jacent
  • cont — conteneur à utiliser comme source pour initialiser le conteneur sous-jacent
  • compare — l'objet fonction de comparaison pour initialiser le foncteur de comparaison sous-jacent
  • first, last — un intervalle [first,last) d'éléments avec lesquels initialiser
  • rg — une plage compatible avec le conteneur, c'est-à-dire un input_range dont les éléments sont convertibles en T

Exigences sur les types

  • Alloc doit satisfaire aux exigences de Allocator.
  • Compare doit satisfaire aux exigences de Compare.
  • Container doit satisfaire aux exigences de Container. Les constructeurs étendus par allocateur ne sont définis que si Container satisfait aux exigences de AllocatorAwareContainer.
  • InputIt doit satisfaire aux exigences de LegacyInputIterator.

Exemple

#include <complex>
#include <functional>
#include <iostream>
#include <queue>
#include <vector>

int main()
{
    std::priority_queue<int> pq1;
    pq1.push(5);
    std::cout << "pq1.size() = " << pq1.size() << '\n';

    std::priority_queue<int> pq2 {pq1};
    std::cout << "pq2.size() = " << pq2.size() << '\n';

    std::vector<int> vec {3, 1, 4, 1, 5};
    std::priority_queue<int> pq3 {std::less<int>(), vec};
    std::cout << "pq3.size() = " << pq3.size() << '\n';

    for (std::cout << "pq3 : "; !pq3.empty(); pq3.pop())
        std::cout << pq3.top() << ' ';
    std::cout << '\n';

    // Démonstration avec un comparateur personnalisé :

    using my_value_t = std::complex<double>;
    using my_container_t = std::vector<my_value_t>;

    auto my_comp = [](const my_value_t& z1, const my_value_t& z2)
    {
        return z2.real() < z1.real();
    };

    std::priority_queue<my_value_t,
                        my_container_t,
                        decltype(my_comp)> pq4{my_comp};

    using namespace std::complex_literals;
    pq4.push(5.0 + 1i);
    pq4.push(3.0 + 2i);
    pq4.push(7.0 + 3i);

    for (; !pq4.empty(); pq4.pop())
    {
        const auto& z = pq4.top();
        std::cout << "pq4.top() = " << z << '\n';
    }

    // TODO : constructeurs de C++23 compatibles avec la bibliothèque des plages
}
