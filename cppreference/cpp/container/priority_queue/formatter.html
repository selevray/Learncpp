template< class CharT, class T, std::formattable<CharT> Container, class... U >
struct formatter<std::priority_queue<T, Container, U...>, CharT>;  // (depuis C++23)

La spécialisation de modèle de std::formatter pour le type d'adaptateur de conteneur std::priority_queue permet aux utilisateurs de convertir le conteneur sous-jacent en sa représentation textuelle sous forme de collection d'éléments à l'aide de fonctions de formatage.

La spécialisation est activée si std::formattable<Container, CharT> est true.
