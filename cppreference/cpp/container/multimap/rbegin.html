std::multimap<Key,T,Compare,Allocator>::rbegin, std::multimap<Key,T,Compare,Allocator>::crbegin

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

reverse_iterator rbegin();  // (1) (noexcept depuis C++11)

const_reverse_iterator rbegin() const;  // (2) (noexcept depuis C++11)

const_reverse_iterator crbegin() const noexcept;  // (3) (depuis C++11)

Retourne un itérateur inverse vers le premier élément du multimap inversé. Il correspond au dernier élément du multimap non inversé. Si le multimap est vide, l'itérateur retourné est égal à rend().

range-rbegin-rend.svg

Paramètres

(aucune)

Valeur de retour

Itérateur inverse vers le premier élément.

Complexité

Constante.

Notes

Le itérateur sous-jacent de l'itérateur inverse renvoyé est l'itérateur de fin. Par conséquent, l'itérateur renvoyé est invalidé si et quand l'itérateur de fin est invalidé.

libc++ rétroporte crbegin() au mode C++98.

Exemple

#include <algorithm>
#include <iostream>
#include <string>
#include <map>

int main()
{
    std::multimap<std::string, int> map
    {
        {"█", 1},
        {"▒", 5},
        {"░", 3},
        {"▓", 7},
        {"▓", 8},
        {"░", 4},
        {"▒", 6},
        {"█", 2}
    };

    std::cout << "Print out in reverse order using const reverse iterators:\n";
    std::for_each(map.crbegin(), map.crend(),
        [](std::pair<const std::string, int> const& e)
        {
            std::cout << "{ \"" << e.first << "\", " << e.second << " };\n";
        });

    map.rbegin()->second = 42; // OK : la valeur non const est modifiable
//  map.crbegin()->second = 42; // Error : impossible de modifier la valeur const
}
