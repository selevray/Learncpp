Tente d'extraire ("épisser") chaque élément de source et de l'insérer dans *this en utilisant l'objet de comparaison de *this.

Aucun élément n'est copié ou déplacé ; seuls les pointeurs internes des nœuds du conteneur sont réaffectés. Tous les pointeurs et références vers les éléments transférés restent valides, mais désignent désormais des éléments de *this, et non de source.

Le comportement est indéfini si get_allocator() != source.get_allocator().

Paramètres

  • source — conteneur compatible à partir duquel transférer les nœuds

Valeur de retour

(aucune)

Exceptions

Ne lève pas d'exception sauf si la comparaison en lève une.

Complexité

N * log(size() + N)), où N est source.size().

Exemple

#include <iostream>
#include <map>
#include <string>

int main()
{
    std::multimap<int, std::string> ma{{1, "apple"}, {5, "pear"}, {10, "banana"}};
    std::multimap<int, std::string> mb{{2, "zorro"}, {4, "batman"}, {5, "X"}, {8, "alpaca"}};
    std::multimap<int, std::string> u;
    u.merge(ma);
    std::cout << "ma.size(): " << ma.size() << '\n';
    u.merge(mb);
    std::cout << "mb.size(): " << mb.size() << '\n';

    for (auto const& kv : u)
        std::cout << kv.first << ", " << kv.second << '\n';
}

Output:

ma.size(): 0
mb.size(): 0
1, apple
2, zorro
4, batman
5, pear
5, X
8, alpaca
10, banana
