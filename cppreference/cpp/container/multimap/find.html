std::multimap<Key,T,Compare,Allocator>::find

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

iterator find( const Key& key );  // (1)

const_iterator find( const Key& key ) const;  // (2)

template< class K >
iterator find( const K& x );  // (3) (depuis C++14)

template< class K >
const_iterator find( const K& x ) const;  // (4) (depuis C++14)

1,2) Trouve un élément dont la clé est équivalente à key. S'il existe plusieurs éléments avec la clé demandée dans le conteneur, l'un quelconque d'entre eux peut être renvoyé.

3,4) Trouve un élément dont la clé se compare équivalente à la valeur x. Cette surcharge ne participe à la résolution de surcharge que si l'id-qualifié Compare::is_transparent est valide et désigne un type. Elle permet d'appeler cette fonction sans construire une instance de Key.

Paramètres

  • key — valeur de clé de l'élément à rechercher
  • x — une valeur de n'importe quel type pouvant être comparée de façon transparente à une clé

Valeur de retour

Un itérateur vers l'élément demandé. Si aucun élément de ce type n'est trouvé, l'itérateur past-the-end (voir end()) est renvoyé.

Complexité

Logarithmique en la taille du conteneur.

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_generic_associative_lookup 201304L (C++14) Recherche par comparaison hétérogène dans les conteneurs associatifs ; surcharges (3,4)

Exemple

#include <iostream>
#include <map>

struct LightKey
{
    int x;
};

struct FatKey
{
    int x;
    int data[1000]; // un gros blob
};

// Comme détaillé ci-dessus, le conteneur doit utiliser std::less<> (ou un autre
// comparateur transparent) pour accéder à ces surcharges. Cela inclut les surcharges standard,
// comme la comparaison entre std::string et std::string_view.
bool operator<(const FatKey& fk, const LightKey& lk) { return fk.x < lk.x; }
bool operator<(const LightKey& lk, const FatKey& fk) { return lk.x < fk.x; }
bool operator<(const FatKey& fk1, const FatKey& fk2) { return fk1.x < fk2.x; }

int main()
{
    // Démonstration de comparaison simple.
    std::multimap<int, char> example{{1, 'a'}, {2, 'b'}};

    if (auto search = example.find(2); search != example.end())
        std::cout << "Found " << search->first << ' ' << search->second << '\n';
    else
        std::cout << "Not found\n";

    // Démonstration de comparaison transparente.
    std::multimap<FatKey, char, std::less<>> example2{{{1, {}}, 'a'}, {{2, {}}, 'b'}};

    LightKey lk = {2};
    if (auto search = example2.find(lk); search != example2.end())
        std::cout << "Found " << search->first.x << ' ' << search->second << '\n';
    else
        std::cout << "Not found\n";

    // Obtention d'itérateurs constants.
    // Le compilateur décide de renvoyer un itérateur de type (non) const selon la façon
    // d'accéder à la map ; pour empêcher une modification intentionnelle, l'une des options les plus simples
    // est d'accéder à la map via une référence constante.
    const auto& example2ref = example2;
    if (auto search = example2ref.find(lk); search != example2.end())
    {
        std::cout << "Found " << search->first.x << ' ' << search->second << '\n';
    //  search->second = 'c'; // erreur : affectation du membre
                              // 'std::pair<const FatKey, char>::second'
                              // dans un objet en lecture seule
    }
}

Output:

Found 2 b
Found 2 b
Found 2 b
