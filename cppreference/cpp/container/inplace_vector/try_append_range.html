std::inplace_vector<T,N>::try_append_range

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< container-compatible-range<T> R >
constexpr std::ranges::borrowed_iterator_t<R> try_append_range( R&& rg );  // (depuis C++26)

Ajoute des copies des éléments initiaux de rg avant end(), jusqu'à ce que tous les éléments soient insérés ou que le stockage interne soit épuisé (c.-à-d. que size() == capacity() est true).

Tous les itérateurs et références restent valides. L'itérateur end() est invalidé.

Chaque itérateur de rg est déréférencé au plus une fois.

Paramètres

  • rg — une plage compatible avec le conteneur, c'est-à-dire un input_range dont les éléments sont convertibles en T

Exigences sur les types

  • T doit être EmplaceConstructible dans inplace_vector à partir de *ranges::begin(rg). Sinon, le comportement est indéfini.

Valeur de retour

Un itérateur pointant sur le premier élément de rg qui n'a pas été inséré dans *this, ou ranges::end(rg) si un tel élément n'existe pas.

Complexité

Linéaire en fonction du nombre d'éléments insérés.

Exceptions

Toute exception levée par l'initialisation de l'élément inséré.

inplace_vector fournit la garantie d'exception de base, c.-à-d. que tous les éléments du conteneur présents avant l'appel sont conservés, et que tous les éléments déjà insérés (avant l'exception, le cas échéant) sont également conservés.

Exemple

#include <cassert>
#include <initializer_list>
#include <inplace_vector>

int main()
{
    using I = std::inplace_vector<int, 8>;
    auto nums = I{1, 2, 3};
    const auto rg = {-1, -2, -3};

    auto it = nums.try_append_range(rg);
    assert(nums.size() == 6);
    assert((nums == I{1, 2, 3, -1, -2, -3}));
    assert(it == rg.end());

    it = nums.try_append_range(rg);
    assert(nums.size() == 8);
    assert((nums == I{1, 2, 3, -1, -2, -3, -1, -2}));
    assert(it == rg.begin() + 2);
}
