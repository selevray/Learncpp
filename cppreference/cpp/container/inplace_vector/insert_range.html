std::inplace_vector<T,N>::insert_range

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< container-compatible-range<T> R >
constexpr iterator insert_range( const_iterator pos, R&& rg );  // (depuis C++26)

Insère, dans l'ordre non inversé, des copies des éléments de rg avant pos.

Chaque itérateur de l'intervalle rg est déréférencé exactement une fois.

rg ne doit pas chevaucher le conteneur. Sinon, le comportement est indéfini.

Paramètres

  • pos — itérateur avant lequel le contenu sera inséré (pos peut être l'itérateur end())
  • rg — une plage compatible avec le conteneur, c'est-à-dire un input_range dont les éléments sont convertibles en T

Exigences sur les types

  • T doit être EmplaceConstructible dans inplace_vector à partir de *ranges::begin(rg). Sinon, le comportement est indéfini.

Valeur de retour

Un iterator qui pointe vers la copie du premier élément inséré dans inplace_vector, ou vers pos si rg est vide.

Exceptions

  • std::bad_alloc, si ranges::distance(rg) + size() > capacity(). Les éléments de *this ne sont pas modifiés.
  • Toute exception levée par l'insertion (c.-à-d. par le constructeur de copie/déplacement, l'opérateur d'affectation par copie/déplacement de T) ou par toute opération LegacyInputIterator. Les éléments de *this dans l'intervalle [0,pos) ne sont pas modifiés.

Exemple

#include <cassert>
#include <inplace_vector>
#include <iterator>
#include <new>
#include <print>

int main()
{
    auto v = std::inplace_vector<int, 8>{0, 1, 2, 3};
    auto pos = std::next(v.begin(), 2);
    assert(*pos == 2);
    const auto rg = {-1, -2, -3};
    v.insert_range(pos, rg);
    std::println("{}", v);

    try
    {
        assert(v.size() + rg.size() > v.capacity());
        v.insert_range(pos, rg); // lève une exception : pas d'espace
    }
    catch(const std::bad_alloc& ex)
    {
        std::println("{}", ex.what());
    }
}

Sortie possible :

[0, 1, -1, -2, -3, 2, 3]
