std::inplace_vector<T,N>::shrink_to_fit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static constexpr void shrink_to_fit() noexcept;  // (depuis C++26)

Ne fait rien.

En théorie, cette fonction est une demande non contraignante de réduction de la capacité afin que le stockage interne ne contienne que size() éléments. Cependant, une telle demande est toujours ignorée par le conteneur à capacité fixe std::inplace_vector<T, N>.

Paramètres

(aucune)

Valeur de retour

(aucune)

Complexité

Constante.

Notes

Cette fonction existe pour la compatibilité avec les interfaces de type vector.
