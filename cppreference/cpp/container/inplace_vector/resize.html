std::inplace_vector<T,N>::resize

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr void resize( size_type count );  // (1) (depuis C++26)

constexpr void resize( size_type count, const value_type& value );  // (2) (depuis C++26)

Redimensionne le conteneur pour qu'il contienne count éléments, ne fait rien si count == size().

Si la taille actuelle est supérieure à count, le conteneur est réduit à ses count premiers éléments.

Si la taille actuelle est inférieure à count, alors :

  1. Des éléments insérés par défaut supplémentaires sont ajoutés à la fin.

  2. Des copies supplémentaires de value sont ajoutées à la fin.

Paramètres

  • count — nouvelle taille du conteneur
  • value — la valeur avec laquelle initialiser les nouveaux éléments

Exigences sur les types

  • T doit satisfaire les exigences de DefaultInsertable pour utiliser la surcharge (1).
  • T doit satisfaire les exigences de CopyInsertable pour utiliser la surcharge (2).

Complexité

Linéaire en fonction de la différence entre la taille actuelle et count.

Exceptions

1,2) Lève std::bad_alloc si count > N.

Si une exception est levée pour quelque raison que ce soit, ces fonctions n'ont aucun effet (garantie forte de sécurité d'exception).

Exemple

#include <inplace_vector>
#include <print>

int main()
{
    std::inplace_vector<int, 6> v(6, 9);
    std::println("Initially, v = {}", v);

    v.resize(2);
    std::println("After resize(2), v = {}", v);

    v.resize(4);
    std::println("After resize(4), v = {}", v);

    v.resize(6, -1);
    std::println("After resize(6, -1), v = {}", v);

    try
    {
        std::print("Trying resize(13): ");
        v.resize(13); // lève une exception, car count > N ; v est laissé inchangé
    }
    catch(const std::bad_alloc& ex)
    {
        std::println("ex.what(): {}", ex.what());
    }
    std::println("After exception, v = {}", v);
}

Sortie possible :

Initially, v = [9, 9, 9, 9, 9, 9]
After resize(2), v = [9, 9]
After resize(4), v = [9, 9, 0, 0]
After resize(6, -1), v = [9, 9, 0, 0, -1, -1]
Trying resize(13): ex.what(): std::bad_alloc
After exception, v = [9, 9, 0, 0, -1, -1]
