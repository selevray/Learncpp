std::inplace_vector<T,N>::capacity

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static constexpr size_type capacity() noexcept;  // (depuis C++26)

Renvoie la capacité du stockage interne (inplace). Équivalent à : return N;.

Paramètres

(aucune)

Valeur de retour

Le nombre maximal d'éléments que le conteneur peut contenir.

Complexité

Constante.

Notes

Comme chaque std::inplace_vector<T, N> est un conteneur à capacité fixe, la valeur renvoyée par capacity est égale à N (qui est également la valeur renvoyée par max_size()).

Exemple

#include <inplace_vector>

int main()
{
    constexpr std::inplace_vector<int, 4> v1;
    static_assert(v1.capacity() == 4 && v1.max_size() == 4);

    constexpr std::inplace_vector<int, 0> v2;
    static_assert(v2.capacity() == 0 && v2.max_size() == 0);
}
