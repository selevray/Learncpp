operator==,<=>(std::inplace_vector)

constexpr friend bool operator==( const std::inplace_vector<T, N>& lhs,
                                  const std::inplace_vector<T, N>& rhs );  // (1) (depuis C++26)

constexpr friend synth-three-way-result<T>
    operator<=>( const std::inplace_vector<T, N>& lhs,
                 const std::inplace_vector<T, N>& rhs );  // (2) (depuis C++26)

Compare le contenu de deux std::inplace_vector.

  1. Vérifie si le contenu de lhs et de rhs est égal, c'est-à-dire qu'ils ont le même nombre d'éléments et que chaque élément de lhs est égal à l'élément de rhs situé à la même position.

  2. Compare le contenu de lhs et rhs lexicographiquement. La comparaison est effectuée comme si l'on appelait
    std::lexicographical_compare_three_way(lhs.begin(), lhs.end(), rhs.begin(), rhs.end(), synth-three-way);.

Le type de retour est le type de retour de synth-three-way (c'est-à-dire synth-three-way-result ﻿<T>).

Au moins une des conditions suivantes doit être satisfaite :

  • T modélise three_way_comparable.
  • < est défini pour des valeurs de type (éventuellement qualifié const) T, et < est une relation d'ordre total.

Dans le cas contraire, le comportement est indéfini.

Les opérateurs <, <=, >, >= et != sont synthétisés à partir de operator<=> et operator== respectivement.

Paramètres

  • lhs, rhs — std::inplace_vectors dont le contenu doit être comparé
  • T doit satisfaire les exigences de EqualityComparable pour pouvoir utiliser les surcharges (1).

Valeur de retour

  1. true si le contenu des std::inplace_vector est égal, false sinon.

  2. L'ordre relatif de la première paire d'éléments non équivalents de lhs et rhs, s'il en existe, lhs.size() <=> rhs.size() sinon.

Complexité

  1. Constant si lhs et rhs sont de tailles différentes, sinon linéaire en fonction de la taille de std::inplace_vector.

  2. Linéaire en fonction de la taille de std::inplace_vector.

Notes

Les opérateurs relationnels sont définis en termes de synth-three-way, qui utilise operator<=> si possible, sinon operator<.

En particulier, si l'élément ne fournit pas lui-même operator<=>, mais est implicitement convertible en un type comparable à trois voies, cette conversion sera utilisée à la place de operator<.

Exemple

#include <inplace_vector>

int main()
{
    constexpr std::inplace_vector<int, 4>
        a{1, 2, 3},
        b{1, 2, 3},
        c{7, 8, 9, 10};

    static_assert
    (""
        "Compare equal containers:" &&
        (a != b) == false &&
        (a == b) == true &&
        (a < b) == false &&
        (a <= b) == true &&
        (a > b) == false &&
        (a >= b) == true &&
        (a <=> b) >= 0 &&
        (a <=> b) <= 0 &&
        (a <=> b) == 0 &&

        "Compare non equal containers:" &&
        (a != c) == true &&
        (a == c) == false &&
        (a < c) == true &&
        (a <= c) == true &&
        (a > c) == false &&
        (a >= c) == false &&
        (a <=> c) < 0 &&
        (a <=> c) != 0 &&
        (a <=> c) <= 0 &&
    "");
}
