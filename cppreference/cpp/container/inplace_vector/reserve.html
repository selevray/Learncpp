std::inplace_vector<T,N>::reserve

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static constexpr void reserve( size_type new_cap );  // (depuis C++26)

Ne fait rien, si ce n'est qu'elle peut lever std::bad_alloc. La demande d'augmentation de la capacité (c.-à-d. de la taille du stockage interne) est ignorée car std::inplace_vector<T, N> est un conteneur à capacité fixe.

Paramètres

  • new_cap — nouvelle capacité de inplace_vector, en nombre d'éléments

Valeur de retour

(aucune)

Complexité

Constante.

Exceptions

std::bad_alloc si new_cap > capacity() est true.

Notes

Cette fonction existe pour la compatibilité avec les interfaces de type vector.

Exemple

#include <cassert>
#include <inplace_vector>
#include <iostream>

int main()
{
    std::inplace_vector<int, 4> v{1, 2, 3};
    assert(v.capacity() == 4 && v.size() == 3);

    v.reserve(2); // ne fait rien
    assert(v.capacity() == 4 && v.size() == 3);

    try
    {
        v.reserve(13); // lève une exception, car la capacité demandée > N ; v est laissé inchangé
    }
    catch(const std::bad_alloc& ex)
    {
        std::cout << ex.what() << '\n';
    }
    assert(v.capacity() == 4 && v.size() == 3);
}
