std::inplace_vector<T,N>::rend, std::inplace_vector<T,N>::crend

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr reverse_iterator rend() noexcept;  // (1) (depuis C++26)

constexpr const_reverse_iterator rend() const noexcept;  // (2) (depuis C++26)

constexpr const_reverse_iterator crend() const noexcept;  // (3) (depuis C++26)

Renvoie un itérateur inverse vers l'élément suivant le dernier élément du inplace_vector inversé. Il correspond à l'élément précédant le premier élément du inplace_vector non inversé. Cet élément sert de marqueur ; tenter d'y accéder entraîne un comportement indéfini.

range-rbegin-rend.svg

Paramètres

(aucune)

Valeur de retour

Itérateur inverse vers l'élément suivant le dernier élément.

Complexité

Constante.

Exemple

#include <algorithm>
#include <iostream>
#include <inplace_vector>

int main()
{
    std::inplace_vector<int, 11> a{1, 11, 11, 35, 0, 12, 79, 76, 76, 69, 40};

    // Affiche les éléments du conteneur dans l'ordre inverse à l'aide de const_reverse_iterator.
    std::for_each(a.crbegin(), a.crend(), [](int e){ std::cout << e << ' '; });
    std::cout << '\n';

    // Modifie chaque élément du conteneur à l'aide de reverse_iterator non const.
    std::for_each(a.rbegin(), a.rend(), [](int& e){ e += 32; });

    // Affiche les éléments sous forme de char dans l'ordre inverse à l'aide de const_reverse_iterator.
    std::for_each(a.crbegin(), a.crend(), [](char e){ std::cout << e; });
    std::cout << '\n';
}

Output:

40 69 76 76 79 12 0 35 11 11 1
