std::inplace_vector<T,N>::emplace

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class... Args >
constexpr iterator emplace( const_iterator position, Args&&... args );  // (depuis C++26)

Insère un nouvel élément dans le conteneur directement avant pos. En général, l'élément est construit à l'aide d'un new placement pour le construire sur place à l'emplacement fourni par le conteneur. Les arguments args... sont transmis au constructeur sous la forme std::forward<Args>(args)....

Paramètres

  • pos — itérateur avant lequel le nouvel élément sera construit
  • args — arguments à transmettre au constructeur de l'élément

Exigences sur les types

  • T doit satisfaire aux exigences de EmplaceConstructible.

Valeur de retour

Un itérateur vers l'élément inséré.

Complexité

Linéaire : la distance entre pos et la fin du conteneur + 1.

Exceptions

  • Lève std::bad_alloc si avant l'invocation size() == capacity(). La fonction n'a aucun effet (garantie forte d'exception).
  • Toute exception levée par l'initialisation de l'élément inséré ou par toute opération LegacyInputIterator. Les éléments de [0,pos) ne sont pas modifiés.

Exemple

#include <cassert>
#include <inplace_vector>
#include <new>
#include <utility>

int main()
{
    using P = std::pair<int, int>;
    using I = std::inplace_vector<P, 3>;
    auto nums = I{{0, 1}, {2, 3}};

    auto it = nums.emplace(nums.begin() + 1, -1, -2);
    assert((*it == P{-1, -2}));
    assert((nums == I{P{0, 1}, {-1, -2}, {2, 3}}));

    try
    {
        nums.emplace(nums.begin(), 1, 3); // lève une exception : pas d'espace
    }
    catch(const std::bad_alloc& ex)
    {
        std::cout << ex.what() << '\n';
    }
}
