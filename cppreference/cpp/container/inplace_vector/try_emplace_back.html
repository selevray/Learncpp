std::inplace_vector<T,N>::try_emplace_back

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class... Args >
constexpr pointer try_emplace_back( Args&&... args );  // (depuis C++26)

Ajoute conditionnellement un objet de type T à la fin du conteneur.

Si size() == capacity() est true, il n'y a aucun effet. Sinon, ajoute un objet d'initialisation direct non par liste avec std::forward<Args>(args)... de type T.

Aucun itérateur ni aucune référence n'est invalidé, sauf end(), qui est invalidé si l'insertion a lieu.

Paramètres

  • args — arguments à transmettre au constructeur de l'élément

Exigences sur les types

  • T doit être EmplaceConstructible vers inplace_vector depuis std::forward<Args>(args)....

Valeur de retour

std::addressof(back()) si size() < capacity(), nullptr sinon.

Complexité

Constante.

Exceptions

Toute exception levée par l'initialisation de l'élément inséré. Si une exception est levée pour quelque raison que ce soit, cette fonction n'a aucun effet (garantie forte d'exception).

Exemple

#include <cassert>
#include <complex>
#include <inplace_vector>

int main()
{
    using namespace std::complex_literals;
    using C = std::complex<double>;
    using I = std::inplace_vector<C, 3>;
    auto v = I{1.0 + 2.0i, 3.0 + 4.0i};

    C* c = v.try_emplace_back(5.0, 6.0);
    assert(*c == 5.0 + 6.0i);
    assert((v == I{1.0 + 2.0i, 3.0 + 4.0i, 5.0 + 6.0i}));

    c = v.try_emplace_back(7.0, 8.0); // pas d'espace => pas d'insertion
    assert(c == nullptr);
    assert((v == I{1.0 + 2.0i, 3.0 + 4.0i, 5.0 + 6.0i}));
}
