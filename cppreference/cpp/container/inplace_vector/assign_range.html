std::inplace_vector<T,N>::assign_range

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< container-compatible-range<T> R >
constexpr void assign_range( R&& rg );  // (depuis C++26)

Remplace les éléments du conteneur par une copie de chaque élément de rg.
Cette section est incomplète

Chaque itérateur de l'intervalle rg est déréférencé exactement une fois.

Le comportement est indéfini si rg chevauche le conteneur.

Paramètres

  • rg — un input_range dont le type de référence est convertible en type d'élément du conteneur

Exigences sur les types

  • std::assignable_from<T&, ranges::range_reference_t<R>> doit être modélisé. Sinon, le programme est mal formé.
  • T doit être EmplaceConstructible dans le conteneur à partir de *ranges::begin(rg). Sinon, le comportement est indéfini.

Valeur de retour

(aucune)

Exceptions

  • bad_alloc, if std::ranges::distance(rg) > capacity().
  • Toute exception levée par l'initialisation de l'élément inséré.

Exemple

#include <algorithm>
#include <cassert>
#include <initializer_list>
#include <inplace_vector>
#include <iostream>
#include <new>

int main()
{
    const auto source = {1, 2, 3};
    std::inplace_vector<int, 4> destination{4, 5};
    destination.assign_range(source);
    assert(std::ranges::equal(destination, source));

    try
    {
        const auto bad = {-1, -2, -3, -4, -5};
        destination.assign_range(bad); // lève une exception : bad.size() > destination.capacity()
    }
    catch(const std::bad_alloc& ex)
    {
        std::cout << ex.what() << '\n';
    }
}
