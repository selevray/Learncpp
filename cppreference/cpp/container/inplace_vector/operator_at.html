std::inplace_vector<T,N>::operator[]

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr reference operator[]( size_type pos );  // (1) (depuis C++26)

constexpr const_reference operator[]( size_type pos ) const;  // (2) (depuis C++26)

Retourne une référence à l'élément situé à la position spécifiée pos. Aucune vérification des bornes n'est effectuée.

Paramètres

  • pos — position de l'élément à retourner

Valeur de retour

Référence à l'élément demandé.

Complexité

Constante.

Notes

Contrairement à std::map::operator[], cet opérateur n'insère jamais de nouvel élément dans le conteneur. Accéder à un élément inexistant via cet opérateur est un comportement indéfini.

Exemple

Le code suivant utilise operator[] pour lire et écrire dans un std::inplace_vector<int, N> :

#include <inplace_vector>
#include <iostream>

int main()
{
    std::inplace_vector<int, 4> numbers{2, 4, 6, 8};

    std::cout << "Second element: " << numbers[1] << '\n';

    numbers[0] = 5;

    std::cout << "All numbers:";
    for (auto i : numbers)
        std::cout << ' ' << i;
    std::cout << '\n';
}

Output:

Second element: 4
All numbers: 5 4 6 8
