std::inplace_vector<T,N>::swap

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr void swap( inplace_vector& other ) noexcept(/* voir ci-dessous */);  // (depuis C++26)

Échange le contenu du conteneur avec celui de other. Ne fait pas en sorte que les itérateurs et références soient associés à l'autre conteneur.

Paramètres

  • other — conteneur avec lequel échanger le contenu

Valeur de retour

(aucune)

Exceptions

noexcept specification:noexcept(N == 0 || (std::is_nothrow_swappable_v<T> && std::is_nothrow_move_constructible_v<T>))

Complexité

Linéaire en fonction de la taille du conteneur.

Exemple

#include <inplace_vector>
#include <print>

int main()
{
    std::inplace_vector<int, 3> a1{1, 2, 3}, a2{4, 5, 6};

    auto i1 = a1.begin();
    auto i2 = a2.begin();
    int& r1 = a1[1];
    int& r2 = a2[1];

    auto print_them_all = [&](auto rem)
    {
        std::println("{}a1 = {}, a2 = {}, *i1 = {}, *i2 = {}, r1 = {}, r2 = {}",
                     rem, a1, a2, *i1, *i2, r1, r2);
    };

    print_them_all("Before swap:\n");
    a1.swap(a2);
    print_them_all("After swap:\n");

    // Notez qu'après swap() les itérateurs et les références restent associés à leurs
    // emplacements d'origine, par exemple i1 pointe sur l'élément a1[0], r1 fait référence à a1[1].
}

Output:

Before swap:
a1 = [1, 2, 3], a2 = [4, 5, 6], *i1 = 1, *i2 = 4, r1 = 2, r2 = 5
After swap:
a1 = [4, 5, 6], a2 = [1, 2, 3], *i1 = 4, *i2 = 1, r1 = 5, r2 = 2
