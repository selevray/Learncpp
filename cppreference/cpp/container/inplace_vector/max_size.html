std::inplace_vector<T,N>::max_size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static constexpr size_type max_size() noexcept;  // (depuis C++26)

Retourne le nombre maximal d'éléments que le conteneur peut contenir.

Paramètres

(aucune)

Valeur de retour

Nombre maximal d'éléments, c'est-à-dire N.

Complexité

Constante.

Notes

Comme chaque std::inplace_vector<T, N> est un conteneur à capacité fixe, la valeur renvoyée par max_size est égale à N (qui est également la valeur renvoyée par capacity()).

Exemple

#include <iostream>
#include <locale>
#include <inplace_vector>

int main()
{
    std::inplace_vector<char, 10> p;
    std::inplace_vector<long, 10> q;

    std::cout.imbue(std::locale("en_US.UTF-8"));
    std::cout << std::uppercase
              << "p.max_size() = " << std::dec << p.max_size() << " = 0x"
              << std::hex << p.max_size() << '\n'
              << "q.max_size() = " << std::dec << q.max_size() << " = 0x"
              << std::hex << q.max_size() << '\n';
}

Output:

p.max_size() = 10 = 0xA
q.max_size() = 10 = 0xA
