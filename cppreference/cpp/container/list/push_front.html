std::list<T,Allocator>::push_front

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void push_front( const T& value );  // (1)

void push_front( T&& value );  // (2) (depuis C++11)

Ajoute l'élément donné value au début du conteneur.

Aucun itérateur ni aucune référence n'est invalidé.

Paramètres

  • value — la valeur de l'élément à ajouter au début

Valeur de retour

(aucune)

Complexité

Constante.

Exceptions

Si une exception est levée pour quelque raison que ce soit, ces fonctions n'ont aucun effet (garantie forte de sécurité d'exception).

Exemple

#include <list>
#include <iomanip>
#include <iostream>
#include <string>

int main()
{
    std::list<std::string> letters;

    letters.push_front("abc");
    std::string s{"def"};
    letters.push_front(std::move(s));

    std::cout << "std::list letters holds: ";
    for (auto&& e : letters)
        std::cout << std::quoted(e) << ' ';

    std::cout << "\nMoved-from string s holds: " << std::quoted(s) << '\n';
}

Sortie possible :

std::list letters holds: "def" "abc"
Moved-from string s holds: ""
