std::list<T,Allocator>::unique

Supprime tous les doublons consécutifs du conteneur. Seul le premier élément de chaque groupe d'éléments égaux est conservé. N'invalide que les itérateurs et références vers les éléments supprimés.

  1. Utilise operator== pour comparer les éléments.

  2. Utilise p pour comparer les éléments.

Le comportement est indéfini si le comparateur correspondant n'établit pas une relation d'équivalence.

Paramètres

  • p — prédicat binaire qui renvoie true si les éléments doivent être considérés comme égaux.

    La signature de la fonction prédicat doit être équivalente à ce qui suit :

    bool pred(const Type1 &a, const Type2 &b);

    Bien que la signature n'ait pas besoin de comporter const &, la fonction ne doit pas modifier les objets qui lui sont passés et doit pouvoir accepter toutes les valeurs de type (éventuellement const) Type1 et Type2 quelle que soit la catégorie de valeur (ainsi, Type1 & n'est pas autorisé, ni Type1 sauf si pour Type1 un déplacement est équivalent à une copie (depuis C++11)).
    Les types Type1 et Type2 doivent être tels qu'un objet de type list<T,Allocator>::const_iterator puisse être déréférencé puis implicitement converti en chacun d'eux.

Exigences sur les types

  • BinaryPredicate doit satisfaire aux exigences de BinaryPredicate.

Valeur de retour

(aucune)

(jusqu'à C++20)

Le nombre d'éléments supprimés.

(depuis C++20)

Complexité

Si empty() vaut true, aucune comparaison n'est effectuée.

Sinon, étant donné (\scriptsize N)N comme std::distance(begin(), end()) :

  1. Exactement (\scriptsize N-1)N-1 comparaisons utilisant operator==.

  2. Exactement (\scriptsize N-1)N-1 applications du prédicat p.

Exemple

#include <iostream>
#include <list>

std::ostream& operator<< (std::ostream& os, std::list<int> const& container)
{
    for (int val : container)
        os << val << ' ';
    return os << '\n';
}

int main()
{
    std::list<int> c{1, 2, 2, 3, 3, 2, 1, 1, 2};
    std::cout << "Before unique(): " << c;
    const auto count1 = c.unique();
    std::cout << "After unique():  " << c
              << count1 << " elements were removed\n";

    c = {1, 2, 12, 23, 3, 2, 51, 1, 2, 2};
    std::cout << "\nBefore unique(pred): " << c;

    const auto count2 = c.unique([mod = 10](int x, int y)
    {
        return (x % mod) == (y % mod);
    });

    std::cout << "After unique(pred):  " << c
              << count2 << " elements were removed\n";
}

Output:

Before unique(): 1 2 2 3 3 2 1 1 2
After unique():  1 2 3 2 1 2
3 elements were removed

Before unique(pred): 1 2 12 23 3 2 51 1 2 2
After unique(pred):  1 2 23 2 51 2
4 elements were removed
