std::list<T,Allocator>::splice

void splice( const_iterator pos, list& other, const_iterator it );  // (3)

void splice( const_iterator pos, list& other,

void splice( const_iterator pos, list&& other,
             const_iterator first, const_iterator last );  // (6) (depuis C++11)

Transfère des éléments d'une liste à une autre.

Aucun élément n'est copié ni déplacé, seuls les pointeurs internes des nœuds de la liste sont redirigés. Aucun itérateur ni référence n'est invalidé ; les itérateurs vers les éléments déplacés restent valides, mais désignent désormais des éléments de *this, et non de other.

1,2) Transfère tous les éléments de other vers *this. Les éléments sont insérés avant l'élément pointé par pos. Le conteneur other devient vide après l'opération.

3,4) Transfère l'élément pointé par it de other vers *this. L'élément est inséré avant l'élément pointé par pos.

5,6) Transfère les éléments de l'intervalle [first,last) de other vers *this. Les éléments sont insérés avant l'élément pointé par pos.

Le comportement est indéfini si

  • get_allocator() != other.get_allocator(),
  • pour les surcharges (1,2), *this et other font référence au même objet,
  • pour les surcharges (3,4), it n'est pas un itérateur déréférençable dans other, ou
  • pour les surcharges (5,6),
    • [first,last) n'est pas un intervalle valide dans other, ou
    • pos se trouve dans [first,last).

Paramètres

  • pos — élément devant lequel le contenu sera inséré
  • other — un autre conteneur duquel transférer le contenu
  • it — l'élément à transférer de other vers *this
  • first, last — l'intervalle d'éléments à transférer de other vers *this

Valeur de retour

(aucune)

Exceptions

Ne lève aucune exception.

Complexité

1-4) Constante.

5,6) Constante si other fait référence au même objet que *this, sinon linéaire en std::distance(first, last).

Exemple

#include <iostream>
#include <list>

std::ostream& operator<<(std::ostream& ostr, const std::list<int>& list)
{
    for (auto& i : list)
        ostr << ' ' << i;

    return ostr;
}

int main ()
{
    std::list<int> list1{1, 2, 3, 4, 5};
    std::list<int> list2{10, 20, 30, 40, 50};

    auto it = list1.begin();
    std::advance(it, 2);

    list1.splice(it, list2);

    std::cout << "list1:" << list1 << '\n';
    std::cout << "list2:" << list2 << '\n';

    list2.splice(list2.begin(), list1, it, list1.end());

    std::cout << "list1:" << list1 << '\n';
    std::cout << "list2:" << list2 << '\n';
}

Output:

list1: 1 2 10 20 30 40 50 3 4 5
list2:
list1: 1 2 10 20 30 40 50
list2: 3 4 5

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
LWG 250 C++98 les références et itérateurs vers le(s) élément(s) déplacé(s) ont tous été invalidés ils font référence ou pointent vers le(s) même(s) élément(s) dans *this
N2525 C++98 La complexité O(1) de l'épissage ne pouvait pas être garantie si get_allocator() != other.get_allocator() le comportement est indéfini dans ce cas
