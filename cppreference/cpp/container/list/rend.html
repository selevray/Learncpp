std::list<T,Allocator>::rend, std::list<T,Allocator>::crend

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

reverse_iterator rend();  // (1) (noexcept depuis C++11)

const_reverse_iterator rend() const;  // (2) (noexcept depuis C++11)

const_reverse_iterator crend() const noexcept;  // (3) (depuis C++11)

Renvoie un itérateur inverse vers l'élément suivant le dernier élément du list inversé. Il correspond à l'élément précédant le premier élément du list non inversé. Cet élément sert de marqueur ; tenter d'y accéder entraîne un comportement indéfini.

range-rbegin-rend.svg

Paramètres

(aucune)

Valeur de retour

Itérateur inverse vers l'élément suivant le dernier élément.

Complexité

Constante.

Notes

libc++ rétroporte crend() au mode C++98.

Exemple

#include <algorithm>
#include <iostream>
#include <numeric>
#include <string>
#include <list>

int main()
{
    std::list<int> nums{1, 2, 4, 8, 16};
    std::list<std::string> fruits{"orange", "apple", "raspberry"};
    std::list<char> empty;

    // Affiche la liste.
    std::for_each(nums.rbegin(), nums.rend(), [](const int n) { std::cout << n << ' '; });
    std::cout << '\n';

    // Additionne tous les entiers de la liste nums (s'il y en a), en n'affichant que le résultat.
    std::cout << "Sum of nums: "
              << std::accumulate(nums.rbegin(), nums.rend(), 0) << '\n';

    // Affiche le premier fruit de la liste fruits, après avoir vérifié qu'il en existe un.
    if (!fruits.empty())
        std::cout << "First fruit: " << *fruits.rbegin() << '\n';

    if (empty.rbegin() == empty.rend())
        std::cout << "list 'empty' is indeed empty.\n";
}

Output:

16 8 4 2 1
Sum of nums: 31
First fruit: raspberry
list 'empty' is indeed empty.
