std::list<T,Allocator>::size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

size_type size() const;  // (jusqu'à C++11)

size_type size() const noexcept;  // (depuis C++11)

Renvoie le nombre d'éléments du conteneur, c'est-à-dire std::distance(begin(), end()).

Paramètres

(aucune)

Valeur de retour

Le nombre d'éléments du conteneur.

Complexité

Constante ou linéaire.

(jusqu'à C++11)

Constante.

(depuis C++11)

Exemple

Le code suivant utilise size pour afficher le nombre d'éléments d'un std::list :

#include <iostream>
#include <list>

int main()
{
    std::list<int> nums{1, 3, 5, 7};

    std::cout << "nums contains " << nums.size() << " elements.\n";
}

Output:

nums contains 4 elements.
