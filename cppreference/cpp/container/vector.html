std::vector

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <vector>

template<
    class T,
    class Allocator = std::allocator<T>
> class vector;  // (1)

namespace pmr {
    template< class T >
    using vector = std::vector<T, std::pmr::polymorphic_allocator<T>>;
}  // (2) (depuis C++17)

  1. std::vector est un conteneur séquentiel qui encapsule des tableaux à taille dynamique.

  2. std::pmr::vector est un template d'alias qui utilise un allocateur polymorphe.

Les éléments sont stockés de manière contiguë, ce qui signifie que les éléments peuvent être accédés non seulement par des itérateurs, mais aussi à l'aide de décalages sur des pointeurs ordinaires vers les éléments. Cela signifie qu'un pointeur vers un élément d'un vector peut être passé à toute fonction attendant un pointeur vers un élément d'un tableau.

Le stockage du vector est géré automatiquement, et il est agrandi au besoin. Les vectors occupent généralement plus d'espace que les tableaux statiques, car davantage de mémoire est allouée pour gérer une croissance future. Ainsi, un vector n'a pas besoin de réallouer à chaque insertion d'élément, mais seulement lorsque la mémoire supplémentaire est épuisée. La quantité totale de mémoire allouée peut être obtenue à l'aide de la fonction capacity(). La mémoire excédentaire peut être rendue au système par un appel à shrink_to_fit()[1].

Les réallocations sont généralement des opérations coûteuses en termes de performance. La fonction reserve() peut être utilisée pour éliminer les réallocations lorsque le nombre d'éléments est connu à l'avance.

La complexité (efficacité) des opérations courantes sur les vectors est la suivante :

  • Accès aléatoire - constante 𝓞(1).
  • Insertion ou suppression d'éléments à la fin - constant amorti 𝓞(1).
  • Insertion ou suppression d'éléments - linéaire par rapport à la distance jusqu'à la fin du vector 𝓞(n).

std::vector (pour T autre que bool) satisfait aux exigences de Container, AllocatorAwareContainer (depuis C++11), SequenceContainer, ContiguousContainer (depuis C++17) et ReversibleContainer.

Les fonctions membres de std::vector sont constexpr : il est possible de créer et d'utiliser des objets std::vector dans l'évaluation d'une expression constante.

Cependant, les objets std::vector ne peuvent généralement pas être constexpr, car toute mémoire allouée dynamiquement doit être libérée dans la même évaluation d'expression constante.

(depuis C++20)

  1. ↑ Dans libstdc++, shrink_to_fit() n'est pas disponible en mode C++98.

Exemple

#include <iostream>
#include <vector>

int main()
{
    // Créer un vector contenant des entiers
    std::vector<int> v = {8, 4, 5, 9};

    // Ajouter deux entiers supplémentaires au vecteur
    v.push_back(6);
    v.push_back(9);

    // Écraser l'élément à la position 2
    v[2] = -1;

    // Afficher le vecteur
    for (int n : v)
        std::cout << n << ' ';
    std::cout << '\n';
}

Output:

8 4 -1 9 6 9
