Retourne un itérateur vers l'élément suivant le dernier élément du flat_multimap.

Cet élément sert de marqueur ; tenter d'y accéder entraîne un comportement indéfini.

range-begin-end.svg

Paramètres

(aucune)

Valeur de retour

Itérateur vers l'élément suivant le dernier élément.

Complexité

Constante.

Exemple

#include <iostream>
#include <flat_map>

int main()
{
    std::flat_multimap<int, int> map{{4, 13}, {9, 94}, {1, 19}, {4, 42}};

    for (auto it = map.cbegin(); it != map.cend(); ++it)
        std::cout << '[' << it->first << "] = " << it->second << '\n';

    // Contrairement aux itérateurs bidirectionnels de std::multimap, les itérateurs de std::flat_multimap
    // sont à accès aléatoire, ils peuvent donc être utilisés avec l'opérateur[] :
    auto it = map.cbegin();
    assert(it[1] == 19);
    assert(it[4] == 13);
    assert(it[4] == 42);
    assert(it[9] == 94);
}

Output:

[1] = 19
[4] = 13
[4] = 42
[9] = 94
