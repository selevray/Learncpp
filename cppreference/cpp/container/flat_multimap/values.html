std::flat_multimap<Key,T,Compare,KeyContainer,MappedContainer>::values

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

const mapped_container_type& values() const noexcept;  // (depuis C++23)

Renvoie une référence constante vers le conteneur de valeurs adapté. Équivalent à return c.values;.

Paramètres

(aucune)

Valeur de retour

Le conteneur de valeurs sous-jacent.

Complexité

Constante.

Exemple

#include <flat_map>
#include <print>
#include <type_traits>
#include <vector>

int main()
{
    std::flat_multimap<int, double> map{{1, 1.1}, {2, 2.2}, {3, 3.3}};

    // Le conteneur de valeurs par défaut est std::vector :
    static_assert(std::is_same_v<decltype(map.values()), const std::vector<int>&>);

    std::println("{}", map.values());
}

Output:

[1.1, 2.2, 3.3]
