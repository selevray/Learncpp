std::swap(std::flat_multimap)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <flat_map>

friend void swap( std::flat_multimap& lhs, std::flat_multimap& rhs ) noexcept;  // (depuis C++23)

Spécialise l'algorithme std::swap pour std::flat_multimap. Échange le contenu de lhs et rhs. Appelle lhs.swap(rhs).

Paramètres

  • lhs, rhs — conteneurs dont le contenu doit être échangé

Valeur de retour

(aucune)

Complexité

Identique à l'échange des conteneurs sous-jacents.

Exemple

#include <algorithm>
#include <iostream>
#include <flat_map>

int main()
{
    std::flat_multimap<int, char> alice{{1, 'a'}, {2, 'b'}, {3, 'c'}};
    std::flat_multimap<int, char> bob{{7, 'Z'}, {8, 'Y'}, {9, 'X'}, {10, 'W'}};

    auto print = [](std::pair<const int, char>& n)
    {
        std::cout << ' ' << n.first << ':' << n.second;
    };

    // Affiche l'état avant swap
    std::cout << "Alice:";
    std::for_each(alice.begin(), alice.end(), print);
    std::cout << "\nBobby:";
    std::for_each(bob.begin(), bob.end(), print);
    std::cout << '\n';

    std::cout << "-- SWAP\n";
    std::swap(alice, bob);

    // Affiche l'état après swap
    std::cout << "Alice:";
    std::for_each(alice.begin(), alice.end(), print);
    std::cout << "\nBobby:";
    std::for_each(bob.begin(), bob.end(), print);
    std::cout << '\n';
}

Output:

Alice: 1:a 2:b 3:c
Bobby: 7:Z 8:Y 9:X 10:W
-- SWAP
Alice: 7:Z 8:Y 9:X 10:W
Bobby: 1:a 2:b 3:c
