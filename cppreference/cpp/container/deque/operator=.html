deque& operator=( deque&& other ) noexcept(/* voir ci-dessous */);  // (depuis C++17)

deque& operator=( std::initializer_list<value_type> ilist );  // (3) (depuis C++11)

Remplace le contenu du conteneur.

  1. Opérateur d'affectation par copie. Remplace le contenu par une copie du contenu de other.

Si std::allocator_traits<allocator_type>::propagate_on_container_copy_assignment::value est true, l'allocateur de *this est remplacé par une copie de other. Si l'allocateur de *this après l'affectation se compare différemment de son ancienne valeur, l'ancien allocateur est utilisé pour désallouer la mémoire, puis le nouvel allocateur est utilisé pour l'allouer avant de copier les éléments. Sinon, la mémoire appartenant à *this peut être réutilisée lorsque c'est possible. Dans tous les cas, les éléments appartenant initialement à *this peuvent être soit détruits, soit remplacés par une affectation par copie élément par élément.

(depuis C++11)

  1. Opérateur d'affectation par déplacement. Remplace le contenu par celui de other en utilisant la sémantique de déplacement (c.-à-d. les données de other sont déplacées depuis other vers ce conteneur). other se trouve ensuite dans un état valide mais non spécifié.

Si std::allocator_traits<allocator_type>::propagate_on_container_move_assignment::value est true, l'allocateur de *this est remplacé par une copie de celui de other. Si c'est false et que les allocateurs de *this et other ne se comparent pas égaux, *this ne peut pas prendre possession de la mémoire possédée par other et doit déplacer par affectation chaque élément individuellement, en allouant de la mémoire supplémentaire avec son propre allocateur si nécessaire. Dans tous les cas, tous les éléments appartenant à l'origine à *this sont soit détruits, soit remplacés par une affectation par déplacement élément par élément.

  1. Remplace le contenu par celui identifié par la liste d'initialisation ilist.

Paramètres

  • other — un autre conteneur à utiliser comme source de données
  • ilist — liste d'initialisation à utiliser comme source de données

Valeur de retour

*this

Complexité

  1. Linéaire en fonction de la taille de *this et de other.

  2. Linéaire en fonction de la taille de *this, sauf si les allocateurs ne se comparent pas égaux et ne se propagent pas, auquel cas linéaire en fonction de la taille de *this et de other.

  3. Linéaire en fonction de la taille de *this et de ilist.

Exceptions

1-3) Peut lever des exceptions définies par l'implémentation.

(jusqu'à C++17)

2)noexcept specification:noexcept(std::allocator_traits<Allocator>::is_always_equal::value)

(depuis C++17)

Notes

Après l'affectation par déplacement du conteneur (surcharge (2)), sauf si l'affectation par déplacement élément par élément est imposée par des allocateurs incompatibles, les références, pointeurs et itérateurs (autres que l'itérateur de fin) vers other restent valides, mais désignent des éléments qui sont désormais dans *this. La norme actuelle fournit cette garantie via l'énoncé général de [container.reqmts]/67, et une garantie plus directe est à l'étude via LWG issue 2321.

Exemple

Le code suivant utilise operator= pour affecter un std::deque à un autre :

#include <initializer_list>
#include <iostream>
#include <iterator>
#include <deque>

void print(auto const comment, auto const& container)
{
    auto size = std::size(container);
    std::cout << comment << "{ ";
    for (auto const& element : container)
        std::cout << element << (--size ? ", " : " ");
    std::cout << "}\n";
}

int main()
{
    std::deque<int> x{1, 2, 3}, y, z;
    const auto w = {4, 5, 6, 7};

    std::cout << "Initially:\n";
    print("x = ", x);
    print("y = ", y);
    print("z = ", z);

    std::cout << "Copy assignment copies data from x to y:\n";
    y = x;
    print("x = ", x);
    print("y = ", y);

    std::cout << "Move assignment moves data from x to z, modifying both x and z:\n";
    z = std::move(x);
    print("x = ", x);
    print("z = ", z);

    std::cout << "Assignment of initializer_list w to z:\n";
    z = w;
    print("w = ", w);
    print("z = ", z);
}

Output:

Initially:
x = { 1, 2, 3 }
y = { }
z = { }
Copy assignment copies data from x to y:
x = { 1, 2, 3 }
y = { 1, 2, 3 }
Move assignment moves data from x to z, modifying both x and z:
x = { }
z = { 1, 2, 3 }
Assignment of initializer_list w to z:
w = { 4, 5, 6, 7 }
z = { 4, 5, 6, 7 }
