std::deque<T,Allocator>::at

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

reference at( size_type pos );  // (1)

const_reference at( size_type pos ) const;  // (2)

Retourne une référence à l'élément situé à la position spécifiée pos, avec vérification des bornes.

Si pos n'est pas dans l'intervalle du conteneur, une exception de type std::out_of_range est levée.

Paramètres

  • pos — position de l'élément à retourner

Valeur de retour

Référence à l'élément demandé

Exceptions

std::out_of_range if pos >= size().

Complexité

Constante.

Exemple

#include <chrono>
#include <cstddef>
#include <iostream>
#include <deque>
#include <stdexcept>

int main()
{
    std::deque<int> data{1, 2, 4, 5, 5, 6};

    // Définir l'élément 1
    data.at(1) = 88;

    // Lire l'élément 2
    std::cout << "Element at index 2 has value " << data.at(2) << '\n';

    std::cout << "data size = " << data.size() << '\n';

    try
    {
        // Essayer de définir un élément à une position aléatoire >= size()
        auto moon_phase = []
        {
            return std::chrono::system_clock::now().time_since_epoch().count() % 8;
        };
        data.at(data.size() + moon_phase()) = 13;
    }
    catch(const std::out_of_range& ex)
    {
        std::cout << ex.what() << '\n';
    }

    // Afficher les valeurs finales
    std::cout << "data:";
    for (int elem : data)
        std::cout << ' ' << elem;
    std::cout << '\n';
}
