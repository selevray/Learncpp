std::deque<T,Allocator>::rbegin, std::deque<T,Allocator>::crbegin

reverse_iterator rbegin();  // (1) (noexcept depuis C++11)

const_reverse_iterator rbegin() const;  // (2) (noexcept depuis C++11)

const_reverse_iterator crbegin() const noexcept;  // (3) (depuis C++11)

Retourne un itérateur inverse vers le premier élément du deque inversé. Il correspond au dernier élément du deque non inversé. Si le deque est vide, l'itérateur retourné est égal à rend().

Paramètres

(aucune)

Valeur de retour

Itérateur inverse vers le premier élément.

Complexité

Constante.

Notes

Le itérateur sous-jacent de l'itérateur inverse renvoyé est l'itérateur de fin. Par conséquent, l'itérateur renvoyé est invalidé si et quand l'itérateur de fin est invalidé.

libc++ rétroporte crbegin() au mode C++98.

Exemple

#include <algorithm>
#include <iostream>
#include <numeric>
#include <string>
#include <deque>

int main()
{
    std::deque<int> nums{1, 2, 4, 8, 16};
    std::deque<std::string> fruits{"orange", "apple", "raspberry"};
    std::deque<char> empty;

    // Afficher le deque.
    std::for_each(nums.rbegin(), nums.rend(), [](const int n) { std::cout << n << ' '; });
    std::cout << '\n';

    // Additionne tous les entiers du deque nums (s'il y en a), en n'affichant que le résultat.
    std::cout << "Sum of nums: "
              << std::accumulate(nums.rbegin(), nums.rend(), 0) << '\n';

    // Affiche le premier fruit du deque fruits, après avoir vérifié qu'il y en a.
    if (!fruits.empty())
        std::cout << "First fruit: " << *fruits.rbegin() << '\n';

    if (empty.rbegin() == empty.rend())
        std::cout << "deque 'empty' is indeed empty.\n";
}

Output:

16 8 4 2 1
Sum of nums: 31
First fruit: raspberry
deque 'empty' is indeed empty.
