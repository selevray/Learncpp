std::deque<T,Allocator>::append_range

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< container-compatible-range<T> R >
void append_range( R&& rg );  // (depuis C++23)

Insère des copies des éléments de l'intervalle rg avant end(), dans l'ordre non inversé.

Tous les itérateurs (y compris l'itérateur end()) sont invalidés. Aucune référence n'est invalidée.

Chaque itérateur de rg est déréférencé exactement une fois.

Paramètres

  • rg — une plage compatible avec le conteneur, c'est-à-dire un input_range dont les éléments sont convertibles en T

Exigences sur les types

  • T doit être EmplaceConstructible dans deque à partir de *ranges::begin(rg). Sinon, le comportement est indéfini.

Valeur de retour

(aucune)

Complexité

Linéaire en la taille de rg. Le nombre d'appels au constructeur de T est exactement égal à std::ranges::size(rg)).

Exceptions

S'il est levé une exception autrement que par le constructeur de copie, le constructeur de déplacement, l'opérateur d'affectation ou l'opérateur d'affectation par déplacement de T, il n'y a aucun effet. Si une exception est levée lors de l'insertion d'un seul élément à l'une des extrémités, il n'y a aucun effet. Sinon, si une exception est levée par le constructeur de déplacement d'un non-CopyInsertable T, les effets sont non spécifiés.

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_containers_ranges 202202L (C++23) Construction et insertion prenant en compte les plages

Exemple

#include <cassert>
#include <deque>
#include <list>

int main()
{
    auto head = std::deque{1, 2, 3, 4};
    const auto tail = std::list{-5, -6, -7};
#ifdef __cpp_lib_containers_ranges
    head.append_range(tail);
#else
    head.insert(head.end(), tail.cbegin(), tail.cend());
#endif
    assert((head == std::deque{1, 2, 3, 4, -5, -6, -7}));
}
