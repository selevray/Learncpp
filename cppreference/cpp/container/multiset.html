std::multiset

template<
    class Key,
    class Compare = std::less<Key>,
    class Allocator = std::allocator<Key>
> class multiset;  // (1)

namespace pmr {
    template<
        class Key,
        class Compare = std::less<Key>
    > using multiset = std::multiset<Key, Compare, std::pmr::polymorphic_allocator<Key>>;
}  // (2) (depuis C++17)

std::multiset est un conteneur associatif contenant un ensemble trié d'objets de type Key. Contrairement à set, plusieurs clés aux valeurs équivalentes sont autorisées. Le tri est effectué à l'aide de la fonction de comparaison de clés Compare. Les opérations de recherche, d'insertion et de suppression ont une complexité logarithmique.

Partout où la bibliothèque standard utilise les exigences Compare, l'équivalence est déterminée en utilisant la relation d'équivalence décrite à Compare. En termes imprécis, deux objets a et b sont considérés comme équivalents si aucun des deux n'est inférieur à l'autre : !comp(a, b) && !comp(b, a).

L'ordre des éléments équivalents selon la comparaison est l'ordre d'insertion et ne change pas.

(depuis C++11)

std::multiset satisfait les exigences de Container, AllocatorAwareContainer, AssociativeContainer et ReversibleContainer.

Notes

Les types membres iterator et const_iterator peuvent être des alias du même type. Cela signifie que définir une paire de surcharges de fonctions utilisant ces deux types comme types de paramètres peut violer la règle de une seule définition. Comme iterator est convertible en const_iterator, une seule fonction ayant un const_iterator comme type de paramètre fonctionnera à la place.
