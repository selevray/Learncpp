std::unordered_multimap<Key,T,Hash,KeyEqual,Allocator>::insert_range

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< container-compatible-range<value_type> R >
void insert_range( R&& rg );  // (depuis C++23)

Insère une copie de chaque élément de l'intervalle rg.

Chaque itérateur de l'intervalle rg est déréférencé exactement une fois. Le comportement est indéfini si rg chevauche le conteneur.

Si après l'opération le nouveau nombre d'éléments est supérieur à l'ancien max_load_factor() * bucket_count(), une réorganisation (rehashing) a lieu.
Si une réorganisation se produit (due à l'insertion), tous les itérateurs sont invalidés. Sinon (pas de réorganisation), les itérateurs ne sont pas invalidés.

Paramètres

  • rg — une plage compatible avec le conteneur, c'est-à-dire un input_range dont les éléments sont convertibles en T

Exigences sur les types

  • value_type doit être EmplaceConstructible dans unordered_multimap depuis *ranges::begin(rg). Sinon, le comportement est indéfini.

Valeur de retour

(aucune)

Complexité

Cas moyen O(N), où N est ranges::distance(rg), pire cas O(N·(a.size() + 1)).

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_lib_containers_ranges 202202L (C++23) Construction et insertion prenant en compte les plages

Exemple

#include <iostream>
#include <unordered_map>
#include <utility>

void println(auto, auto const& container)
{
    for (const auto& [key, value] : container)
        std::cout << '{' << key << ',' << value << '}' << ' ';
    std::cout << '\n';
}

int main()
{
    auto container = std::unordered_multimap{std::pair{1, 11}, {3, 33}, {2, 22}, {4, 44}};
    const auto rg = {std::pair{-1, -11}, {3, -33}, {-2, -22}};
#ifdef __cpp_lib_containers_ranges
    container.insert_range(rg);
#else
    container.insert(rg.begin(), rg.end());
#endif
    println("{}", container);
}

Sortie possible :

{1,11} {-2,-22} {3,-33} {3,33} {2,22} {-1,-11} {4,44}
