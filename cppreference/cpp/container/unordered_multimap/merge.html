Tente d'extraire (« épisser ») chaque élément de source et de l'insérer dans *this en utilisant la fonction de hachage et le prédicat d'égalité des clés de *this.

Aucun élément n'est copié ou déplacé, seuls les pointeurs internes des nœuds du conteneur sont redirigés. Tous les pointeurs et références vers les éléments transférés restent valides, mais désignent désormais les éléments de *this, et non de source. Les itérateurs désignant les éléments transférés et tous les itérateurs désignant *this sont invalidés.

Le comportement est indéfini si get_allocator() != source.get_allocator().

Paramètres

  • source — conteneur compatible à partir duquel transférer les nœuds

Valeur de retour

(aucune)

Complexité

Cas moyen O(N), pire cas O(N * size() + N), où N est source.size().

Exemple

#include <iostream>
#include <string>
#include <unordered_map>
#include <utility>

// afficher un std::pair
template<class Os, class U, class V>
Os& operator<<(Os& os, const std::pair<U,V>& p)
{
    return os << '{' << p.first << ", " << p.second << '}';
}

// afficher un conteneur associatif
template<class Os, class K, class V>
Os& operator<<(Os& os, const std::unordered_multimap<K, V>& v)
{
    os << '[' << v.size() << "] {";
    bool o{};
    for (const auto& e : v)
        os << (o ? ", " : (o = 1, "")) << e;
    return os << "}\n";
}

int main()
{
    std::unordered_multimap<std::string, int>
        p{{"C", 3}, {"B", 2}, {"A", 1}, {"A", 0}},
        q{{"E", 6}, {"E", 7}, {"D", 5}, {"A", 4}};

    std::cout << "p: " << p << "q: " << q;

    p.merge(q);

    std::cout << "p.merge(q);\n" << "p: " << p << "q: " << q;
}

Sortie possible :

p: [4] {{A, 1}, {A, 0}, {B, 2}, {C, 3}}
q: [4] {{A, 4}, {D, 5}, {E, 6}, {E, 7}}
p.merge(q);
p: [8] {{E, 6}, {E, 7}, {C, 3}, {A, 1}, {A, 0}, {A, 4}, {D, 5}, {B, 2}}
q: [0] {}
