std::unordered_multimap<Key,T,Hash,KeyEqual,Allocator>::erase

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

iterator erase( iterator pos );  // (1) (depuis C++11)

iterator erase( const_iterator pos );  // (2) (depuis C++11)

iterator erase( const_iterator first, const_iterator last );  // (3) (depuis C++11)

size_type erase( const Key& key );  // (4) (depuis C++11)

template< class K >
size_type erase( K&& x );  // (5) (depuis C++23)

Supprime les éléments spécifiés du conteneur. L'ordre des éléments restants est préservé. (Cela permet d'effacer des éléments individuels pendant le parcours du conteneur.)

1,2) Supprime l'élément en pos.

  1. Supprime les éléments de l'intervalle [first,last), qui doit être un intervalle valide dans *this.

  2. Supprime tous les éléments dont la clé est équivalente à key.

  3. Supprime tous les éléments dont la clé est équivalente à la valeur x. Cette surcharge ne participe à la résolution de surcharge que si Hash::is_transparent et KeyEqual::is_transparent sont valides et désignent chacun un type, et que ni iterator ni const_iterator n'est implicitement convertible depuis K. Cela suppose qu'un tel Hash est appelable avec les types K et Key, et que le KeyEqual est transparent, ce qui, ensemble, permet d'appeler cette fonction sans construire d'instance de Key.

Les références et itérateurs vers les éléments effacés sont invalidés. Les autres itérateurs et références ne sont pas invalidés.

L'itérateur pos doit être valide et déréférençable. Ainsi, l'itérateur end() (qui est valide mais n'est pas déréférençable) ne peut pas être utilisé comme valeur pour pos.

Paramètres

  • pos — itérateur vers l'élément à supprimer
  • first, last — plage d'éléments à supprimer
  • key — valeur de clé des éléments à supprimer
  • x — une valeur de tout type pouvant être comparée de manière transparente à une clé désignant les éléments à supprimer

Valeur de retour

1-3) Itérateur suivant le dernier élément supprimé.

  1. Nombre d'éléments supprimés.

  2. Nombre d'éléments supprimés.

Exceptions

1-3) Ne lève aucune exception.

4,5) Toute exception levée par le Hash et l'objet KeyEqual.

Complexité

Étant donné une instance c de unordered_multimap :

1,2) Cas moyen : constant, cas le pire : c.size().

  1. Cas moyen : std::distance(first, last), cas le pire : c.size().

  2. Cas moyen : c.count(key), cas le pire : c.size().

  3. Cas moyen : c.count(x), cas le pire : c.size().

Exemple

#include <unordered_map>
#include <iostream>

int main()
{
    std::unordered_multimap<int, std::string> c =
    {
        {1, "one"}, {2, "two"}, {3, "three"},
        {4, "four"}, {5, "five"}, {6, "six"}
    };

    // supprime tous les nombres impairs de c
    for (auto it = c.begin(); it != c.end();)
    {
        if (it->first % 2 != 0)
            it = c.erase(it);
        else
            ++it;
    }

    for (auto& p : c)
        std::cout << p.second << ' ';
    std::cout << '\n';
}
