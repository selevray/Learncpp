std::chrono::duration_values

Défini dans l'en-tête <chrono>

template< class Rep >
struct duration_values;  // (depuis C++11)

Le type std::chrono::duration_values définit trois durées courantes :

  • std::chrono::duration_values::zero
  • std::chrono::duration_values::min
  • std::chrono::duration_values::max

Les fonctions membres statiques zero, min et max de std::chrono::duration délèguent leur travail à ces fonctions.

Ce type peut être spécialisé si la représentation Rep nécessite une implémentation spécifique pour renvoyer ces objets durée.

Fonctions membres

  • zero [statique] — renvoie une représentation de longueur nulle (fonction membre statique publique)
  • min [statique] — renvoie la plus petite représentation possible (fonction membre statique publique)
  • max [statique] — renvoie la plus grande représentation possible (fonction membre statique publique)
