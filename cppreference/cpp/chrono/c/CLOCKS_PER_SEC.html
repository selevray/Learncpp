CLOCKS_PER_SEC

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ctime>

#define CLOCKS_PER_SEC /* implementation-defined */

Se développe en une expression (pas nécessairement une constante à la compilation) de type std::clock_t égale au nombre de ticks d'horloge par seconde, tel que renvoyé par std::clock().

Notes

POSIX définit CLOCKS_PER_SEC comme 1'000'000, quelle que soit la précision réelle de std::clock().

Exemple

#include <ctime>
#include <iostream>
#include <locale>

int main()
{
    const std::clock_t cps{CLOCKS_PER_SEC};
    std::cout.imbue(std::locale("en_US.utf8"));
    std::cout << cps << '\n';
}
