std::mktime

Défini dans l'en-tête <ctime>

std::time_t mktime( std::tm* time );

Convertit une heure locale du calendrier en temps écoulé depuis l'epoch, sous forme d'objet std::time_t. time->tm_wday et time->tm_yday sont ignorés. Les valeurs de time peuvent sortir de leurs plages normales.

Une valeur négative de time->tm_isdst amène mktime à déterminer si l'heure d'été était en vigueur.

Si la conversion réussit, l'objet time est modifié. Tous les champs de time sont mis à jour pour rentrer dans leurs plages valides. time->tm_wday et time->tm_yday sont recalculés à partir des autres champs.

Paramètres

  • time — pointeur vers un objet std::tm spécifiant l'heure locale du calendrier à convertir

Valeur de retour

Temps écoulé depuis l'epoch sous forme d'objet std::time_t en cas de succès, ou -1 si time ne peut pas être représenté comme objet std::time_t.

Notes

Si l'objet std::tm provient de std::get_time ou de la fonction POSIX strptime, la valeur de tm_isdst est indéterminée et doit être définie explicitement avant d'appeler mktime.

Exemple

Construire une heure locale explicitement.

#include <ctime>
#include <iomanip>
#include <iostream>
#include <sstream>

int main()
{
    setenv("TZ", "/usr/share/zoneinfo/America/Los_Angeles", 1); // Spécifique à POSIX

    std::tm tm{}; // Initialisation à zéro
    tm.tm_year = 2020 - 1900; // 2020
    tm.tm_mon = 2 - 1; // Février
    tm.tm_mday = 15; // 15th
    tm.tm_hour = 10;
    tm.tm_min = 15;
    tm.tm_isdst = 0; // Pas d'heure d'été
    std::time_t t = std::mktime(&tm);
    std::tm local = *std::localtime(&t);

    std::cout << "local: " << std::put_time(&local, "%c %Z") << '\n';
}

Sortie possible :

local: Sat Feb 15 10:15:00 2020 PST
