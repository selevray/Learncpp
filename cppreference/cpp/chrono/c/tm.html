struct tm;

Structure contenant une date et une heure calendaires décomposées en leurs composantes.

Objets membres

  • int tm_sec — secondes après la minute – [[0,61] (jusqu'à C++11) | [0,60] (depuis C++11)][note 1] (objet membre public)
  • int tm_min — minutes après l'heure – [0,59] (objet membre public)
  • int tm_hour — heures depuis minuit – [0,23] (objet membre public)
  • int tm_mday — jour du mois – [1,31] (objet membre public)
  • int tm_mon — mois depuis janvier – [0,11] (objet membre public)
  • int tm_year — années depuis 1900 (objet membre public)
  • int tm_wday — jours depuis dimanche – [0,6] (objet membre public)
  • int tm_yday — jours depuis le 1er janvier – [0,365] (objet membre public)
  • int tm_isdst — Indicateur d'heure d'été. La valeur est positive si l'heure d'été est en vigueur, nulle si non, et négative si aucune information n'est disponible. (objet membre public)
  1. ↑ L'intervalle permet une seconde intercalaire positive. Deux secondes intercalaires dans la même minute ne sont pas autorisées (l'intervalle [0,61] était un défaut introduit en C89 et corrigé en C99).

Notes

Les bibliothèques C BSD, GNU et musl prennent en charge deux membres supplémentaires, standardisés dans POSIX.1-2024.

  • long tm_gmtoff — secondes à l'est de UTC (objet membre public)
  • const char tm_zone* — abréviation du fuseau horaire (objet membre public)

Exemple

#include <ctime>
#include <iostream>

int main()
{
    std::tm tm{};
    tm.tm_year = 2022 - 1900;
    tm.tm_mday = 1;
    std::mktime(&tm);

    std::cout << std::asctime(&tm); // note : '\n' final implicite
}

Sortie possible :

Sat Jan  1 00:00:00 2022
