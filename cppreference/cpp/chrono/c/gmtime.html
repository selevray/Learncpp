std::gmtime

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ctime>

std::tm* gmtime( const std::time_t* time );

Convertit un temps écoulé depuis l'epoch, exprimé par une valeur std::time_t, en temps du calendrier exprimé en temps universel coordonné (UTC).

Paramètres

  • time — pointeur vers un objet time_t à convertir

Valeur de retour

Pointeur vers un objet std::tm interne statique en cas de succès, sinon pointeur nul. La structure peut être partagée entre std::gmtime, std::localtime et std::ctime et peut être écrasée à chaque appel.

Notes

Cette fonction peut ne pas être thread-safe.

POSIX exige que cette fonction affecte errno à EOVERFLOW si elle échoue parce que l'argument est trop grand.

Exemple

#include <ctime>
#include <iomanip>
#include <iostream>
#include <sstream>

int main()
{
    setenv("TZ", "/usr/share/zoneinfo/Europe/London", 1); // Spécifique à POSIX

    std::tm tm{}; // get_time ne initialise pas tous les champs, d'où {}
    tm.tm_year = 2020 - 1900; // 2020
    tm.tm_mon = 7 - 1; // Juillet
    tm.tm_mday = 15; // 15th
    tm.tm_hour = 10;
    tm.tm_min = 15;
    tm.tm_isdst = 1; // Heure d'été à Londres
    std::time_t t = std::mktime(&tm);

    std::cout << "UTC:   " << std::put_time(std::gmtime(&t), "%c %Z") << '\n';
    std::cout << "local: " << std::put_time(std::localtime(&t), "%c %Z") << '\n';
}

Sortie possible :

UTC:   Wed Jul 15 09:15:00 2020 GMT
local: Wed Jul 15 10:15:00 2020 BST
