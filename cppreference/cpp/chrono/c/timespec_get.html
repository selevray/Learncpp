std::timespec_get

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <ctime>

int timespec_get( std::timespec* ts, int base );  // (1) (depuis C++17)

#define TIME_UTC /* implementation-defined */  // (2) (depuis C++17)

  1. Modifie l'objet std::timespec pointé par ts pour contenir l'heure calendaire courante dans la base de temps base.

  2. Se développe en une valeur utilisable comme argument base de std::timespec_get.

D'autres constantes macro commençant par TIME_ peuvent être fournies par l'implémentation pour indiquer des bases de temps supplémentaires.

Si base vaut TIME_UTC, alors

  • ts->tv_sec est défini au nombre de secondes écoulées depuis une époque définie par l'implémentation, tronqué à une valeur entière,
  • le membre ts->tv_nsec reçoit le nombre entier de nanosecondes, arrondi à la résolution de l'horloge système.

Paramètres

  • ts — pointeur vers un objet de type std::timespec
  • base — TIME_UTC ou une autre valeur entière non nulle indiquant la base de temps

Valeur de retour

La valeur de base en cas de succès, zéro sinon.

Notes

La fonction POSIX clock_gettime(CLOCK_REALTIME, ts) peut également être utilisée pour remplir un std::timespec avec le temps écoulé depuis l'Epoch.

Exemple

#include <ctime>
#include <iostream>

int main()
{
    std::timespec ts;
    std::timespec_get(&ts, TIME_UTC);
    char buf[100];
    std::strftime(buf, sizeof buf, "%D %T", std::gmtime(&ts.tv_sec));
    std::cout << "Current time: " << buf << '.' << ts.tv_nsec << " UTC\n";
}
