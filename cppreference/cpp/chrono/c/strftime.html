std::size_t strftime( char* str, std::size_t count, const char* format, const std::tm* tp );

Convertit les informations de date et d'heure d'un temps du calendrier tp en chaîne de caractères multioctets terminée par un caractère nul str, selon la chaîne de format format. Au plus count octets sont écrits.

Paramètres

  • str — pointeur vers le premier élément du tableau de char destiné à la sortie
  • count — nombre maximal d'octets à écrire
  • format — pointeur vers une chaîne de caractères multioctets terminée par un caractère nul spécifiant le format de conversion
  • tp — pointeur vers l'objet contenant les informations de date et d'heure à convertir

Chaîne de format

La chaîne de format est constituée de zéro ou plusieurs spécificateurs de conversion et de caractères ordinaires (sauf %). Tous les caractères ordinaires, y compris le caractère nul terminal, sont copiés sans modification dans la chaîne de sortie. Chaque spécification de conversion commence par le caractère %, suivi éventuellement du modificateur E ou O (ignoré si la locale ne le prend pas en charge), puis du caractère qui détermine le comportement du spécificateur. Valeur de retour

Le nombre d'octets écrits dans le tableau de caractères pointé par str, sans compter le '\0' de fin, en cas de succès. Si count est atteint avant que la chaîne entière ait pu être stockée, 0 est renvoyé et le contenu est indéterminé.

Exemple

#include <ctime>
#include <iostream>
#include <iterator>
#include <locale>

void utcExample()
{
    // Exemple du format UTC RFC 3339, très populaire
    std::time_t time = std::time({});
    char timeString[std::size("yyyy-mm-ddThh:mm:ssZ")];
    std::strftime(std::data(timeString), std::size(timeString),
                  "%FT%TZ", std::gmtime(&time));
    std::cout << timeString << '\n';
}

int main()
{
    std::time_t t = std::time(nullptr);
    char mbstr[100];

    if (std::strftime(mbstr, sizeof(mbstr), "%A %c", std::localtime(&t)))
        std::cout << mbstr << '\n';

    std::locale::global(std::locale("ja_JP.utf8"));
    if (std::strftime(mbstr, sizeof(mbstr), "%A %c", std::localtime(&t)))
        std::cout << mbstr << '\n';

    utcExample();
}
