std::chrono::utc_clock

Défini dans l'en-tête <chrono>

class utc_clock;  // (depuis C++20)

L'horloge std::chrono::utc_clock est un Clock qui représente le temps universel coordonné (UTC). Elle mesure le temps depuis 00:00:00 UTC, jeudi 1er janvier 1970, secondes intercalaires comprises.

utc_clock satisfait aux exigences Clock. Il ne satisfait pas aux exigences TrivialClock, sauf si l'implémentation peut garantir que now() ne lève pas d'exception.

Types membres

Type membre Définition

  • rep — type arithmétique signé représentant le nombre de ticks dans la durée de l'horloge
  • period — un type std::ratio représentant la période d'un tick de l'horloge, en secondes
  • duration — std::chrono::duration<rep, period>, capable de représenter des durées négatives
  • time_point — std::chrono::time_point<std::chrono::utc_clock>

Notes

L'époque UTC officielle est le 1er janvier 1972. utc_clock utilise à la place le 1er janvier 1970, afin d'être cohérent avec std::chrono::system_clock.
