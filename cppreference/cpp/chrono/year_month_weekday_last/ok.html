std::chrono::year_month_weekday_last::ok

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr bool ok() const noexcept;  // (depuis C++20)

Vérifie si cet objet représente une date valide. Comme un year_month_weekday_last représente le dernier jour de la semaine d'un mois donné, il est valide tant que l'année, le mois et le jour de la semaine sont valides.

Valeur de retour

year().ok() && month().ok() && weekday().ok()

Exemple

#include <cassert>
#include <chrono>
using namespace std::chrono;

int main()
{
    auto ymwdl{Tuesday[last]/11/2020};
    assert(ymwdl.ok());
    ymwdl = Tuesday[last]/-2/2021;
    assert(!ymwdl.ok());
    ymwdl += months(0); // Normaliser le mois
    assert(ymwdl.ok());
}
