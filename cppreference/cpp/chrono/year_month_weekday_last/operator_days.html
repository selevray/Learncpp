std::chrono::year_month_weekday_last::operator sys_days, std::chrono::year_month_weekday_last::operator local_days

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr operator std::chrono::sys_days() const noexcept;  // (1) (depuis C++20)

constexpr explicit operator std::chrono::local_days() const noexcept;  // (2) (depuis C++20)

Convertit *this en std::chrono::time_point représentant la même date que cet year_month_weekday_last.

  1. Si ok() est true, renvoie un sys_days qui représente le dernier weekday() du year() et de month(). Sinon, la valeur retournée est non spécifiée.

  2. Identique à (1), mais renvoie local_days au lieu de sys_days. Équivalent à local_days(sys_days(*this).time_since_epoch()).

Exemple

#include <chrono>
#include <iostream>
using namespace std::chrono;

int main()
{
    constexpr auto ymwdl{Tuesday[last]/11/2021};
    static_assert(static_cast<local_days>(ymwdl) ==
                  static_cast<local_days>(November/30/2021));
    // conversion d'un format basé sur des champs vers un format basé sur des numéros de série pour ajouter des jours
    constexpr auto sd = static_cast<sys_days>(ymwdl);
    constexpr year_month_day ymd{sd + days(42)};
    std::cout << ymd << '\n';
}
