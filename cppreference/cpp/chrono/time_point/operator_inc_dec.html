Modifie le point dans le temps que *this représente d'un tick de duration.

Si d_ est une variable membre contenant la durée (c'est-à-dire le temps écoulé depuis l'epoch) de cet objet time_point,

  1. Équivalent à ++d_; return *this;.

  2. Équivalent à return time_point(d_++).

  3. Équivalent à --d_; return *this;.

  4. Équivalent à return time_point(d_--);.

Paramètres

(aucune)

Valeur de retour

1,3) Une référence à ce time_point après modification.

2,4) Une copie du time_point effectuée avant modification.
