Compare deux points temporels. La comparaison se fait en comparant les résultats time_since_epoch() pour les points temporels.

1,2) Vérifie si les points temporels lhs et rhs désignent le même point temporel pour l'horloge donnée.

3-6) Compare les points temporels lhs et rhs.

  1. Compare les points temporels lhs et rhs. Le type de retour est déduit de lhs.time_since_epoch() <=> rhs.time_since_epoch(), et donc du type du résultat de la comparaison à trois voies de Dur1 et Dur2.

L'opérateur != est synthétisé à partir de operator==.

(depuis C++20)

Paramètres

  • lhs, rhs — points temporels à comparer

Valeur de retour

  1. true si le lhs et le rhs désignent le même point temporel, false sinon.

  2. true si le lhs et le rhs désignent des points temporels différents, false sinon.

  3. true si le lhs désigne un point temporel antérieur à rhs, false sinon.

  4. true si le lhs désigne un point temporel antérieur à rhs, ou le même point temporel que rhs, false sinon.

  5. true si le lhs désigne un point temporel postérieur à rhs, false sinon.

  6. true si le lhs désigne un point temporel postérieur à rhs, ou le même point temporel que rhs, false sinon.

  7. lhs.time_since_epoch() <=> rhs.time_since_epoch().

Exceptions

Peut lever des exceptions définies par l'implémentation.

Notes

Les opérateurs de comparaison à trois voies de time_point n'étaient pas constexpr en C++11, cela a été corrigé en C++14.
