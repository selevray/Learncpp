std::chrono::local_info

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <chrono>

struct local_info;  // (depuis C++20)

La classe local_info décrit le résultat de la conversion d'un std::chrono::local_time en un std::chrono::sys_time.

  • Si le résultat de la conversion est unique, alors result == local_info::unique, first est rempli avec le std::chrono::sys_info correct, et second est initialisé à zéro.
  • Si le local_time est inexistant, alors result == local_info::nonexistent, first est rempli avec le std::chrono::sys_info qui se termine juste avant le local_time, et second est rempli avec le std::chrono::sys_info qui commence juste après le local_time.
  • Si le local_time est ambigu, alors result == local_info::ambiguous, first est rempli avec le std::chrono::sys_info qui se termine juste après le local_time, et second est rempli avec le std::chrono::sys_info qui commence juste avant le local_time.

Il s'agit d'une structure de données de bas niveau ; les conversions typiques de local_time vers sys_time l'utiliseront implicitement plutôt qu'explicitement.
