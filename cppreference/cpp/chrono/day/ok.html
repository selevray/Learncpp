std::chrono::day::ok

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr bool ok() const noexcept;  // (depuis C++20)

Vérifie si la valeur de jour stockée dans *this est dans l'intervalle valide, c'est-à-dire [1,31].

Valeur de retour

true si la valeur de jour stockée dans *this est dans l'intervalle [1,31]. Sinon false.

Exemple

#include <chrono>
using namespace std::chrono_literals;

constexpr std::chrono::day d0{00};
constexpr std::chrono::day d1{13};
constexpr std::chrono::day d2{42};

static_assert
(
    d0 == 0d && !d0.ok() &&
    d1 == 13d && d1.ok() &&
    d2 == 42d && !d2.ok()
);

int main() {}
