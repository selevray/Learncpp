template<> struct hash<std::chrono::day>;  // (depuis C++26)

La spécialisation de modèle de std::hash pour std::chrono::day permet aux utilisateurs d'obtenir les hachages des objets de type std::chrono::day. Cette spécialisation est activée.

Le operator() de cette spécialisation est noexcept.
