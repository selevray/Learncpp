1,2) Ajoute ds.count() jours à d.

  1. Soustrait ds.count() jours de d.

  2. Calcule la différence, en jours, entre deux day x et y.

Valeur de retour

1,2) std::chrono::day(unsigned(d) + ds.count())

  1. std::chrono::day(unsigned(d) - ds.count())

  2. std::chrono::days(int(unsigned(x)) - int(unsigned(y)))

Notes

1-3) Si le résultat se situait hors de l'intervalle [0,255], la valeur réellement stockée est non spécifiée.

Exemple

#include <cassert>
#include <chrono>

int main()
{
    std::chrono::day d{15};

    d = d + std::chrono::days(2);
    assert(d == std::chrono::day(17));

    d = d - std::chrono::days(3);
    assert(d == std::chrono::day(14));

    constexpr std::chrono::days ds = std::chrono::day(16) - std::chrono::day(14);
    static_assert(ds == std::chrono::days(2));
}
