std::chrono::day::operator+=, std::chrono::day::operator-=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr std::chrono::day& operator+=( const std::chrono::days& d ) noexcept;  // (1) (depuis C++20)

constexpr std::chrono::day& operator-=( const std::chrono::days& d ) noexcept;  // (2) (depuis C++20)

Ajoute ou soustrait d.count() jours à la valeur du jour.

  1. Équivalent à *this = *this + d;.

  2. Équivalent à *this = *this - d;.

Valeur de retour

Une référence à ce day après modification.

Notes

Si le résultat se situait hors de l'intervalle [0,255], la valeur réellement stockée est non spécifiée.

Exemple

#include <cassert>
#include <chrono>

int main()
{
    std::chrono::day d{15};

    d += std::chrono::days(2);
    assert(d == std::chrono::day(17));

    d -= std::chrono::days{3};
    assert(d == std::chrono::day(14));
}
