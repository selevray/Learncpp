Ajoute ou soustrait 1 à la valeur du jour.

1,2) Effectue *this += std::chrono::days{1};.

3,4) Effectue *this -= std::chrono::days{1};.

Paramètres

(aucune)

Valeur de retour

1,3) Une référence à ce day après modification.

2,4) Une copie du day effectuée avant modification.

Notes

Si le résultat se situait hors de l'intervalle [0,255], la valeur réellement stockée est non spécifiée.

Exemple

#include <cassert>
#include <chrono>

int main()
{
    std::chrono::day d{15};

    ++d;
    assert(d == std::chrono::day(16));

    --d;
    assert(d == std::chrono::day(15));
}
