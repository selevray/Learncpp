std::chrono::operator<<(std::chrono::day)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <chrono>

template< class CharT, class Traits >
std::basic_ostream<CharT, Traits>&
    operator<<( std::basic_ostream<CharT, Traits>& os, const std::chrono::day& d );  // (depuis C++20)

Forme un std::basic_string<CharT> s constitué de la valeur du jour stockée dans d, formatée comme un nombre décimal, avec un zéro initial si le résultat serait sinon un seul chiffre décimal. Ensuite, si !d.ok(), ajoute " is not a valid day" à la chaîne formatée. Insère cette chaîne dans os.

Équivalent à

return os << (d.ok() ? std::format(STATICALLY_WIDEN<CharT>("{:%d}"), d) : std::format(STATICALLY_WIDEN<CharT>("{:%d} is not a valid day"), d));

où STATICALLY_WIDEN<CharT>("...") vaut "..." si CharT est char, et L"..." si CharT est wchar_t.

Valeur de retour

os

Exemple

#include <chrono>
#include <iostream>

int main()
{
    constexpr std::chrono::day d1{31}, d2{7}, d3{42}, d4{};
    std::cout << d1 << '\n'
              << d2 << '\n'
              << d3 << '\n'
              << d4 << '\n';
}

Sortie possible :

31
07
42 is not a valid day
00 is not a valid day
