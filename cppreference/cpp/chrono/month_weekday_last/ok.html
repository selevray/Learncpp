std::chrono::month_weekday_last::ok

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr bool ok() const noexcept;  // (depuis C++20)

Vérifie si les objets month et weekday_last contenus sont valides.

Valeur de retour

month().ok() && weekday_last().ok()

Exemple

#include <chrono>
#include <iostream>

int main()
{
    std::cout << std::boolalpha;

    auto mwdl{std::chrono::March/std::chrono::Wednesday[std::chrono::last]};
    std::cout << (mwdl.ok()) << ' ';
    mwdl = {std::chrono::month(3)/std::chrono::weekday(42)[std::chrono::last]};
    std::cout << (mwdl.ok()) << '\n';
}

Output:

true false
