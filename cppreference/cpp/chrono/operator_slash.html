Ces surcharges de operator/ fournissent une syntaxe conventionnelle pour la création de dates du calendrier grégorien prolepse.

Pour la création d'une date complète, l'un quelconque des trois ordres suivants est accepté :

  • year/month/day,
  • month/day/year,
  • day/month/year.

Dans chaque cas, day peut être remplacé par l'un des éléments suivants :

  • std::chrono::last, pour le dernier jour du mois ;
  • weekday[i], pour le ie jour de la semaine du mois ;
  • weekday[std::chrono::last], pour le dernier jour de la semaine du mois.

Un entier simple est accepté si sa signification est non ambiguë à partir des types des autres opérandes : 2005y/4/5 est autorisé, mais 5/April/2005 ne l'est pas.

Les types de dates partielles (year_month, month_day, etc.) peuvent être créés en n'appliquant pas le second operator/ dans aucun des trois ordres.

Exemple

#include <chrono>
using namespace std::chrono;

constexpr auto ym{2021y/8};
static_assert(ym == year_month(year(2021), August));

constexpr auto md{9/15d};
static_assert(md == month_day(September, day(15)));

constexpr auto mdl{October/last};
static_assert(mdl == month_day_last(month(10)));

constexpr auto mw{11/Monday[3]};
static_assert(mw == month_weekday(November, Monday[3]));

constexpr auto mwdl{December/Sunday[last]};
static_assert(mwdl == month_weekday_last(month(12), weekday_last(Sunday)));

// Les 3 ordres année/mois/jour réellement utilisés par les humains sur cette planète et au-delà :
constexpr auto ymd{year(2021)/January/day(23)};
static_assert(ymd == month{1}/23/2021);
static_assert(ymd == day{23}/1/2021);
static_assert(ymd == year_month_day(2021y, month(January), 23d));

int main() {}
