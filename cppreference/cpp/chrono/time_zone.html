std::chrono::time_zone

Défini dans l'en-tête <chrono>

class time_zone;  // (depuis C++20)

La classe time_zone représente toutes les transitions de fuseau horaire pour une zone géographique donnée.

Les utilisateurs ne peuvent pas construire d'objets time_zone. L'implémentation de la bibliothèque crée les objets time_zone lorsqu'elle initialise la base de données des fuseaux horaires et fournit un accès const à ces objets.

time_zone n'est pas copiable mais possède un constructeur de déplacement et un opérateur d'affectation par déplacement par défaut. Cependant, comme les utilisateurs n'ont qu'un accès const aux objets time_zone, ces fonctions ne peuvent pas être appelées dans le code utilisateur sans provoquer un comportement indéfini.

Fonctions membres

  • name — obtient le nom de ce time_zone (fonction membre publique)
  • get_info — obtient des informations associées à un sys_time ou local_time (fonction membre publique)
  • to_sys — convertit un local_time dans ce fuseau horaire en un sys_time (fonction membre publique)
  • to_local — convertit un sys_time en un local_time dans ce fuseau horaire (fonction membre publique)

Fonctions non membres

  • operator==operator<=> (C++20) — compare deux objets time_zone (fonction)
