class time_zone_link;  // (depuis C++20)

La classe time_zone_link représente un nom alternatif pour un fuseau horaire.

Les utilisateurs ne peuvent pas construire d'objets time_zone_link. L'implémentation de la bibliothèque crée les objets time_zone_link lorsqu'elle initialise la base de données des fuseaux horaires et fournit un accès const à ces objets.

time_zone_link n'est pas copiable mais possède un constructeur de déplacement et un opérateur d'affectation par déplacement par défaut. Cependant, comme les utilisateurs n'ont qu'un accès const aux objets time_zone_link, ces fonctions ne peuvent pas être appelées dans le code utilisateur sans provoquer un comportement indéfini.
