template< class Duration >
class hh_mm_ss;  // (depuis C++20)

Le modèle de classe hh_mm_ss découpe une std::chrono::duration en une heure « décomposée » telle que heures:minutes:secondes, la précision du découpage étant déterminée par le paramètre de modèle Duration. Il s'agit avant tout d'un outil de formatage.

Duration doit être une spécialisation de std::chrono::duration, sinon le programme est mal formé.

Constantes membres

  • constexpr unsigned fractional_width [statique] — le plus petit entier possible dans l'intervalle [0,18] tel que precision (voir ci-dessous) représente exactement la valeur de Duration{1}, ou 6 s'il n'existe pas d'entier (constante membre statique publique)
