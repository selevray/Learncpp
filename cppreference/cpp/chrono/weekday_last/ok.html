std::chrono::weekday_last::ok

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr bool ok() const noexcept;  // (depuis C++20)

Vérifie si l'objet jour de la semaine stocké dans *this est valide.

Valeur de retour

weekday().ok()

Exemple

#include <chrono>
#include <iostream>

int main()
{
    std::cout << std::boolalpha;

    auto wdl{std::chrono::Tuesday[std::chrono::last]};
    std::cout << (wdl.ok()) << ' ';

    wdl = {std::chrono::weekday(42)[std::chrono::last]};
    std::cout << (wdl.ok()) << '\n';
}

true false
