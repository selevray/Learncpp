std::chrono::month::operator unsigned

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr explicit operator unsigned() const noexcept;  // (depuis C++20)

Renvoie la valeur du mois stockée dans *this.

Valeur de retour

La valeur du mois stockée dans *this.

Exemple

#include <chrono>
#include <iostream>

int main()
{
    constexpr std::chrono::month m{6};
    constexpr unsigned p = static_cast<unsigned>(m);
    constexpr unsigned q = static_cast<unsigned>(std::chrono::September);
    std::cout << "The month is: " << p << '\n'
              << "September is: " << q << '\n';
}

Output:

The month is: 6
September is: 9
