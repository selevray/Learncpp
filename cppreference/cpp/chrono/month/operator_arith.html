std::chrono::month::operator+=, std::chrono::month::operator-=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr std::chrono::month& operator+=( const std::chrono::months& m ) noexcept;  // (1) (depuis C++20)

constexpr std::chrono::month& operator-=( const std::chrono::months& m ) noexcept;  // (2) (depuis C++20)

Ajoute ou soustrait m.count() à la valeur de mois, en réduisant le résultat modulo 12 à un entier dans l'intervalle [1,12].

  1. Effectue *this = *this + m;.

  2. Effectue *this = *this - m;.

Valeur de retour

Une référence à ce month après modification.

Notes

Après un appel à l'une de ces fonctions, ok() vaut toujours true si aucun dépassement n'a eu lieu pendant l'opération.

Exemple

#include <chrono>
#include <iostream>

int main()
{
    std::cout << std::boolalpha;

    std::chrono::month m{6};
    m += std::chrono::months(2);
    std::cout << (m == std::chrono::month(8)) << ' '
              << (m == std::chrono::August) << ' ';

    m -= std::chrono::months(3);
    std::cout << (m == std::chrono::month(5)) << ' '
              << (m == std::chrono::May) << ' ';

    m = std::chrono::October;
    m += std::chrono::months{8}; // ((10 += 8 == 18) % 12) == 6;
    std::cout << (m == std::chrono::June) << ' ';

    m -= std::chrono::months{std::chrono::December - std::chrono::February}; // -= 10
    // (6 -= 10) == -4; -4 % 12 == (12 - 4) == 8
    std::cout << (m == std::chrono::August) << '\n';
}
