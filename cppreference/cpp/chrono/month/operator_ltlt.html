std::chrono::operator<<(std::chrono::month)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <chrono>

template< class CharT, class Traits >
std::basic_ostream<CharT, Traits>&
    operator<<( std::basic_ostream<CharT, Traits>& os, const std::chrono::month& m );  // (depuis C++20)

Si !m.ok(), insère unsigned(m) suivi de " is not a valid month" vers os. Sinon, forme un std::basic_string<CharT> s constitué du nom abrégé du mois représenté par m, déterminé à l'aide de la locale associée à os, et insère s dans os.

Équivalent à

return os << (m.ok() ? std::format(os.getloc(), STATICALLY_WIDEN<CharT>("{:L%b}"), m) : std::format(os.getloc(), STATICALLY_WIDEN<CharT>("{} is not a valid month"), unsigned(m)));

où STATICALLY_WIDEN<CharT>("...") vaut "..." si CharT est char, et L"..." si CharT est wchar_t.

Valeur de retour

os

Notes

Cet operator<< est principalement destiné à un usage de débogage. Pour contrôler le formatage, utilisez std::format.
