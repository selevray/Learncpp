constexpr std::strong_ordering operator<=>( const std::chrono::month& x,

Compare les deux std::chrono::month x et y.

Les opérateurs <, <=, >, >= et != sont synthétisés à partir de operator<=> et operator== respectivement.

Valeur de retour

  1. unsigned(x) == unsigned(y)

  2. unsigned(x) <=> unsigned(y)

Exemple

#include <chrono>

int main()
{
    constexpr std::chrono::month m1{6}, m2{8};

    static_assert
    (
        m1 < m2 && m1 == m1 && m1 <= m2 &&
        m2 > m1 && m2 != m1 && m2 >= m1 &&
        m1 <=> m2 != 0
    );
}
