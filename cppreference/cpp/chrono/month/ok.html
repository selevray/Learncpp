std::chrono::month::ok

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr bool ok() const noexcept;  // (depuis C++20)

Vérifie si la valeur de mois stockée dans *this est dans la plage valide, c'est-à-dire [1,12].

Valeur de retour

true si la valeur de mois stockée dans *this est dans l'intervalle [1,12]. Sinon false.

Exemple

#include <chrono>
#include <iostream>

int main()
{
    for (const unsigned mm : {6u, 0u, 16U})
    {
        std::cout << mm << ": ";
        const std::chrono::month m{mm};
        m.ok() ? std::cout << "month is valid\n"
               : std::cout << "month is invalid\n";
    }
}

Output:

6: month is valid
0: month is invalid
16: month is invalid
