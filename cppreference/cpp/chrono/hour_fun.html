constexpr bool is_am( const std::chrono::hours& h ) noexcept;  // (1) (depuis C++20)

constexpr bool is_pm( const std::chrono::hours& h ) noexcept;  // (2) (depuis C++20)

constexpr std::chrono::hours make12( const std::chrono::hours& h ) noexcept;  // (3) (depuis C++20)

constexpr std::chrono::hours make24( const std::chrono::hours& h,
                                     bool is_pm ) noexcept;  // (4) (depuis C++20)

Ces fonctions facilitent la conversion entre une heure du jour au format sur 12 heures et une heure du jour au format sur 24 heures.

  1. Détecte si l'heure au format sur 24 heures est du matin (ante meridiem, avant midi).

  2. Détecte si l'heure au format sur 24 heures est de l'après-midi (post meridiem, après midi).

  3. Renvoie l'équivalent sur 12 heures d'une heure au format sur 24 heures.

  4. Renvoie l'équivalent sur 24 heures d'une heure au format sur 12 heures h, où is_pm détermine si l'heure est de l'après-midi.

Paramètres

  • h — heure au format sur 12 ou 24 heures à détecter
  • is_pm — indique si l'heure au format sur 12 heures est de l'après-midi

Valeur de retour

  1. 0h <= h && h <= 11h

  2. 12h <= h && h <= 23h

  3. Si h est dans l'intervalle [0h,23h], renvoie l'équivalent sur 12 heures dans l'intervalle [1h,12h]. Sinon, la valeur de retour est non spécifiée.

  4. Si h est dans l'intervalle [1h,12h], renvoie l'équivalent sur 24 heures dans l'intervalle [0h,11h] si is_pm vaut false, ou dans l'intervalle [12h,23h] sinon. Sinon, la valeur de retour est non spécifiée.

Exemple

#include <chrono>
#include <iomanip>
#include <iostream>
#include <utility>

int main()
{
    using namespace std::chrono;

    static_assert(
        is_am(10h) &&  is_am(11h) && !is_am(12h) && !is_am(23h) &&
       !is_pm(10h) && !is_pm(11h) &&  is_pm(12h) &&  is_pm(23h)
    );

    std::cout << "make12():\n";

    for (const hours hh : {0h, 1h, 11h, 12h, 13h, 23h})
    {
        const hours am{make12(hh)};
        std::cout << std::setw(2) << hh.count() << "h == "
                  << std::setw(2) << am.count() << (is_am(hh) ? "h a.m.\n" : "h p.m.\n");
    }

    std::cout << "\nmake24():\n";

    using p = std::pair<hours, bool>;

    for (const auto& [hh, pm] : {p{1h, 0}, p{12h, 0}, p{1h, 1}, p{12h, 1}})
    {
        std::cout << std::setw(2) << hh.count()
                  << (pm ? "h p.m." : "h a.m.")
                  << " == " << std::setw(2)
                  << make24(hh, pm).count() << "h\n";
    }
}
