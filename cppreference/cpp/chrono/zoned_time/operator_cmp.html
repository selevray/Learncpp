std::chrono::operator==(std::chrono::zoned_time)

template< class Duration1, class Duration2, class TimeZonePtr >
bool operator==( const std::chrono::zoned_time<Duration1, TimeZonePtr>& x,
                 const std::chrono::zoned_time<Duration2, TimeZonePtr>& y );  // (depuis C++20)

Compare les deux valeurs zoned_time x et y. Deux objets zoned_time sont égaux si leurs instants et leurs pointeurs de fuseau horaire sont tous deux égaux selon operator==.

L'opérateur != est synthétisé à partir de operator==.

Valeur de retour

x.get_time_zone() == y.get_time_zone() && x.get_sys_time() == y.get_sys_time(), sauf que les comparaisons sont effectuées directement sur les membres de données non statiques de x et y, sans aucune copie.
