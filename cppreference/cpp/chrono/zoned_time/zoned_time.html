Construit un objet zoned_time, en initialisant le pointeur de fuseau horaire stocké et l'instant stocké selon le tableau suivant, où traits est std::chrono::zoned_traits<TimeZonePtr> :

Surcharge | Pointeur de fuseau horaire (noté zone) | Point temporel (un std::chrono::sys_time<duration>) | Notes

(1) | traits::default_zone() | construit par défaut | (a)

(2) | st

(3) | other.get_time_zone() | other.get_sys_time() | (b)

(4) | other.get_time_zone() | other.get_sys_time() | (e)

(5) | std::move(z) | construit par défaut

(6) | traits::locate_zone(name) | (c)

(7) | std::move(z) | st

(8) | traits::locate_zone(name) | (c)

(9) | std::move(z) | zone->to_sys(tp) | (d)

(10) | traits::locate_zone(name) | (c,d)

(11) | std::move(z) | zone->to_sys(tp, c) | (d)

(12) | traits::locate_zone(name) | (c,d)

(13,14) | std::move(z) | zt.get_sys_time() | (e)

(15,16) | traits::locate_zone(name) | (c,e)

a) Les constructeurs spécifiés pour appeler traits::default_zone() (1,2) ne participent pas à la résolution de surcharge si cette expression n'est pas bien formée.

b) Le constructeur de copie par défaut (3) est défini comme supprimé si std::is_copy_constructible_v<TimeZonePtr> est faux.

c) Les constructeurs avec un paramètre std::string_view name (6,8,10,12,15,16) ne participent pas à la résolution de surcharge si traits::locate_zone(name) n'est pas bien formé ou si cette expression n'est pas convertible en TimeZonePtr.

d) Les constructeurs spécifiés pour appeler zone->to_sys (9-12) ne participent pas à la résolution de surcharge si cette expression d'appel n'est pas bien formée ou si le résultat n'est pas convertible en std::chrono::sys_time<duration>.

e) Les constructeurs avec un paramètre de modèle Duration2 (4,13-16) ne participent pas à la résolution de surcharge si Duration2 n'est pas convertible en Duration.

Le comportement est indéfini si le pointeur de fuseau horaire (initialisé comme décrit ci-dessus) ne désigne pas un fuseau horaire.

Notes

zoned_time n'a pas de constructeur de déplacement, et tenter de le déplacer effectuera une copie à la place, en utilisant le constructeur de copie par défaut (3). Ainsi, lorsque TimeZonePtr est un type uniquement déplaçable, zoned_time est immuable : il ne peut être ni déplacé ni copié.

Les constructeurs (14,16) acceptent un paramètre std::chrono::choose, mais ce paramètre n'a aucun effet.

Exemple

#include <chrono>
#include <iostream>
#include <string_view>

int main()
{
    using std::chrono_literals::operator""y;
    using std::operator""sv;

    std::cout << std::chrono::zoned_time{} << " : default\n";

    constexpr std::string_view location1{"America/Phoenix"sv};
    std::cout << std::chrono::zoned_time{location1} << " : " << location1 << '\n';

    const std::chrono::time_zone* timeZonePtr = std::chrono::locate_zone("UTC");
    std::cout << std::chrono::zoned_time{timeZonePtr} << " : UTC time zone\n";

    constexpr auto location2{"Europe/Rome"sv};
    std::cout << std::chrono::zoned_time{location2, std::chrono::local_days{2021y/12/31}}
              << " : " << location2 << '\n';

    constexpr auto location3{"Europe/Rome"sv};
    constexpr auto some_date = std::chrono::sys_time<std::chrono::days>{2021y/12/31};
    std::cout << std::chrono::zoned_time{location3, some_date}
              << " : " << location3 << '\n';

    const auto now =
        std::chrono::floor<std::chrono::minutes>(std::chrono::system_clock::now());
    constexpr auto location4{"Europe/Rome"sv};
    std::cout << std::chrono::zoned_time{location4, now} << " : " << location4 << '\n';

    constexpr auto NewYork{"America/New_York"sv};
    constexpr auto Tokyo{"Asia/Tokyo"sv};
    const std::chrono::zoned_time tz_Tokyo{Tokyo, now};
    const std::chrono::zoned_time tz_NewYork{NewYork, now};
    std::cout << std::chrono::zoned_time{Tokyo, tz_NewYork} << " : " << Tokyo << '\n';
    std::cout << std::chrono::zoned_time{NewYork, tz_Tokyo} << " : " << NewYork << '\n';
}
