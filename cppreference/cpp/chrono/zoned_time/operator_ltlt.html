Défini dans l'en-tête <chrono>

template< class CharT, class Traits, class Duration, class TimeZonePtr >
std::basic_ostream<CharT, Traits>&
    operator<<( std::basic_ostream<CharT, Traits>& os,
                const std::chrono::zoned_time<Duration, TimeZonePtr>& tp );  // (depuis C++20)

Écrit tp dans le flux os, comme par std::format(os.getloc(), fmt, tp), où fmt est "{:L%F %T %Z}" si CharT est char, ou L"{:L%F %T %Z}" si CharT est wchar_t.

Paramètres

  • os — flux de sortie
  • tp — zoned_time vers la sortie

Valeur de retour

os
