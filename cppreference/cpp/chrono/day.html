std::chrono::day

Défini dans l'en-tête <chrono>

class day;  // (depuis C++20)

La classe day représente un jour dans un mois. Son intervalle normal est [1,31], mais elle peut contenir n'importe quel nombre dans [0,255].

day est un TriviallyCopyable StandardLayoutType.

  • ok — vérifie si la valeur du jour stockée est dans l'intervalle normal (fonction membre publique)
