std::chrono::clock_time_conversion

Défini dans l'en-tête <chrono>

template< class Dest, class Source >
struct clock_time_conversion {};  // (depuis C++20)

std::chrono::clock_time_conversion est un trait qui spécifie comment convertir un std::chrono::time_point de l'horloge Source en celui de l'horloge Dest. Il le fait en fournissant un operator() appelable en const acceptant un argument de type std::chrono::time_point<Source, Duration> et renvoyant un std::chrono::time_point<Dest, OtherDuration> représentant un point temporel équivalent. La durée du point temporel renvoyé est calculée à partir de la durée source d'une manière qui varie pour chaque spécialisation. clock_time_conversion n'est normalement utilisé qu'indirectement, via std::chrono::clock_cast.

Un programme peut spécialiser clock_time_conversion si au moins un des paramètres de modèle est un type d'horloge défini par l'utilisateur.

Le modèle primaire est une struct vide. La norme définit les spécialisations suivantes :

template< class Clock >
struct clock_time_conversion<Clock, Clock>;  // (1) (depuis C++20)

template<>
struct clock_time_conversion<std::chrono::system_clock, std::chrono::system_clock>;  // (2) (depuis C++20)

template<>
struct clock_time_conversion<std::chrono::utc_clock, std::chrono::utc_clock>;  // (3) (depuis C++20)

template<>
struct clock_time_conversion<std::chrono::system_clock, std::chrono::utc_clock>;  // (4) (depuis C++20)

template<>
struct clock_time_conversion<std::chrono::utc_clock, std::chrono::system_clock>;  // (5) (depuis C++20)

template< class Clock >
struct clock_time_conversion<Clock, std::chrono::system_clock>;  // (6) (depuis C++20)

template< class Clock >
struct clock_time_conversion<std::chrono::system_clock, Clock>;  // (7) (depuis C++20)

template< class Clock >
struct clock_time_conversion<Clock, std::chrono::utc_clock>;  // (8) (depuis C++20)

template< class Clock >
struct clock_time_conversion<std::chrono::utc_clock, Clock>;  // (9) (depuis C++20)

1-3) Conversion identité : operator() renvoie une copie de l'argument.

4,5) Conversions entre std::chrono::sys_time et std::chrono::utc_time : operator() appelle std::chrono::utc_clock::to_sys et std::chrono::utc_clock::from_sys, respectivement.

6,7) Conversions depuis et vers std::chrono::sys_time lorsque Clock prend en charge from_sys et to_sys : operator() appelle Clock::to_sys et Clock::from_sys, respectivement.

8,9) Conversions depuis et vers std::chrono::utc_time lorsque Clock prend en charge from_utc et to_utc : operator() appelle Clock::to_utc et Clock::from_utc, respectivement.

Convertit l'argument std::chrono::time_point vers l'horloge de destination.

1-3) Conversion identité. Renvoie t inchangé.

  1. Renvoie std::chrono::utc_clock::to_sys(t).

  2. Renvoie std::chrono::utc_clock::from_sys(t).

  3. Renvoie Clock::from_sys(t). Cette surcharge ne participe à la résolution de surcharge que si l'expression Clock::from_sys(t) est bien formée. Le programme est mal formé si Clock::from_sys(t) ne renvoie pas std::chrono::time_point<Clock, Duration> où Duration est une spécialisation valide de std::chrono::duration.

  4. Renvoie Clock::to_sys(t). Cette surcharge ne participe à la résolution de surcharge que si l'expression Clock::to_sys(t) est bien formée. Le programme est mal formé si Clock::to_sys(t) ne renvoie pas std::chrono::sys_time<Duration> où Duration est une spécialisation valide de std::chrono::duration.

  5. Renvoie Clock::from_utc(t). Cette surcharge ne participe à la résolution de surcharge que si l'expression Clock::from_utc(t) est bien formée. Le programme est mal formé si Clock::from_utc(t) ne renvoie pas std::chrono::time_point<Clock, Duration> où Duration est une spécialisation valide de std::chrono::duration.

  6. Renvoie Clock::to_utc(t). Cette surcharge ne participe à la résolution de surcharge que si l'expression Clock::to_utc(t) est bien formée. Le programme est mal formé si Clock::to_utc(t) ne renvoie pas std::chrono::utc_time<Duration> où Duration est une spécialisation valide de std::chrono::duration.

Paramètres

  • t — point temporel à convertir
