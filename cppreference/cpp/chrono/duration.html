std::chrono::duration

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <chrono>

template<
    class Rep,
    class Period = std::ratio<1>
> class duration;  // (depuis C++11)

Le modèle de classe std::chrono::duration représente un intervalle de temps.

Il est constitué d'un nombre de ticks de type Rep et d'une période de tick, où la période de tick est un rationnel à la compilation fraction représentant le temps en secondes d'un tick au suivant.

La seule donnée stockée dans une duration est un nombre de ticks de type Rep. Si Rep est à virgule flottante, alors le duration peut représenter des fractions de ticks. Period fait partie du type de la durée et n'est utilisé que lors des conversions entre différentes durées.

Remarque : chacun des types de durée prédéfinis jusqu'à hours couvre un intervalle d'au moins ±292 ans.

Chacun des types de durée prédéfinis days, weeks, months et years couvre un intervalle d'au moins ±40000 ans. years est égal à 365,2425 days (la durée moyenne d'une année grégorienne). months est égal à 30,436875 days (exactement 1/12 de years).

Notes

L'intervalle de temps réel (en secondes) contenu dans un objet durée d est approximativement égal à d.count() * D::period::num / D::period::den, où D est de type chrono::duration<> et d est un objet de ce type.

Exemple

Cet exemple montre comment définir plusieurs types de durée personnalisés et convertir entre types :

#include <chrono>
#include <iostream>

using namespace std::chrono_literals;

template<typename T1, typename T2>
using mul = std::ratio_multiply<T1, T2>;

int main()
{
    using microfortnights = std::chrono::duration<float,
        mul<mul<std::ratio<2>, std::chrono::weeks::period>, std::micro>>;
    using nanocenturies = std::chrono::duration<float,
        mul<mul<std::hecto, std::chrono::years::period>, std::nano>>;
    using fps_24 = std::chrono::duration<double, std::ratio<1, 24>>;

    std::cout << "1 second is:\n";

    // conversion d'échelle entière sans perte de précision : pas de cast
    std::cout << std::chrono::milliseconds(1s).count() << " milliseconds\n"
              << std::chrono::microseconds(1s).count() << " microseconds\n"
              << std::chrono::nanoseconds(1s).count() << " nanoseconds\n";

    // conversion d'échelle entière avec perte de précision : nécessite un cast
    std::cout << std::chrono::duration_cast<std::chrono::minutes>(1s).count()
              << " minutes\n";
    // alternative à duration_cast :
    std::cout << 1s / 1min << " minutes\n";

    // conversion d'échelle à virgule flottante : pas de cast
    std::cout << microfortnights(1s).count() << " microfortnights\n"
              << nanocenturies(1s).count() << " nanocenturies\n"
              << fps_24(1s).count() << " frames at 24fps\n";
}
