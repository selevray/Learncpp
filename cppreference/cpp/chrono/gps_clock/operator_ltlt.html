std::chrono::operator<<(std::chrono::gps_time)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <chrono>

template< class CharT, class Traits, class Duration >
std::basic_ostream<CharT, Traits>&
    operator<<( std::basic_ostream<CharT, Traits>& os,
                const std::chrono::gps_time<Duration>& tp );  // (depuis C++20)

Envoie tp dans le flux os, comme si par os << std::format(os.getloc(), STATICALLY-WIDEN("{:L%F %T}"), tp), où STATICALLY_WIDEN<CharT>("{:L%F %T}") vaut "{:L%F %T}" si CharT est char, et L"{:L%F %T}" si CharT est wchar_t.

Valeur de retour

os
