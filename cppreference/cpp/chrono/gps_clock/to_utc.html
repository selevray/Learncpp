std::chrono::gps_clock::to_utc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class Duration >
static std::chrono::utc_time<std::common_type_t<Duration, std::chrono::seconds>>
    to_utc( const std::chrono::gps_time<Duration>& t ) noexcept;  // (depuis C++20)

Convertit le gps_time t en un utc_time représentant le même point temporel.

Valeur de retour

Un std::chrono::utc_time représentant le même point temporel que t, calculé comme si par construction d'une valeur du type de retour à partir de t.time_since_epoch() puis addition de 315964809s (315964809 est le nombre de secondes entre les époques des deux horloges : 1980-01-06 00:00:00 UTC pour gps_clock et 1970-01-01 00:00:00 UTC pour utc_clock).
