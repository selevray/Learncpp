std::chrono::duration<Rep,Period>::count

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr rep count() const;  // (depuis C++11)

Renvoie le nombre de ticks de cette durée.

Paramètres

(aucune)

Valeur de retour

Le nombre de ticks de cette durée.

Exemple

#include <chrono>
#include <iostream>

int main()
{
    std::chrono::milliseconds ms{3}; // 3 milliseconds
    // 6000 microsecondes construites à partir de 3 millisecondes
    std::chrono::microseconds us = 2 * ms;
    // Horloge à 30 Hz utilisant des ticks fractionnaires
    std::chrono::duration<double, std::ratio<1, 30>> hz30(3.5);

    std::cout << "3 ms duration has " << ms.count() << " ticks\n"
              << "6000 us duration has " << us.count() << " ticks\n"
              << "3.5 30Hz duration has " << hz30.count() << " ticks\n";
}

Output:

3 ms duration has 3 ticks
6000 us duration has 6000 ticks
3.5 30Hz duration has 3.5 ticks
