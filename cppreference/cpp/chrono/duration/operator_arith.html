Implémente le plus unaire et le moins unaire pour les durées.

Si rep_ est une variable membre contenant le nombre de ticks d'un objet durée, et D est le type de retour,

  1. Équivalent à return D(*this);.

  2. Équivalent à return D(-rep_);.

Paramètres

(aucune)

Valeur de retour

  1. Une copie de cet objet durée.

  2. Une copie de cet objet durée, avec le nombre de ticks opposé.

Exemple

#include <chrono>
#include <iostream>

int main()
{
    constexpr std::chrono::seconds s1(-052);
    constexpr std::chrono::seconds s2 = -s1;

    std::cout << "Negated " << s1 << " are " << s2 << '\n';
}

Output:

Negated -42s are 42s
