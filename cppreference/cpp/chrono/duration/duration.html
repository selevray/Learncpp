std::chrono::duration<Rep,Period>::duration

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr duration() = default;  // (1) (depuis C++11)

duration( const duration& ) = default;  // (2) (depuis C++11)

template< class Rep2 >
constexpr explicit duration( const Rep2& r );  // (3) (depuis C++11)

template< class Rep2, class Period2 >
constexpr duration( const duration<Rep2, Period2>& d );  // (4) (depuis C++11)

Construit une nouvelle duration à partir de l'une de plusieurs sources de données optionnelles.

  1. Le constructeur par défaut.

  2. Le constructeur de copie.

  3. Construit une durée avec r ticks.

Cette surcharge ne participe à la résolution de surcharge que si toutes les conditions suivantes sont satisfaites :

  • is_convertible<const Rep2&, Rep>::value is true.
  • L'une des conditions suivantes est satisfaite :[1]
    • std::chrono::treat_as_floating_point<Rep>::value is true.
    • std::chrono::treat_as_floating_point<Rep2>::value is false.
  1. Construit une durée en convertissant d en une période et un nombre de ticks appropriés, comme si par std::chrono::duration_cast<duration>(d).count().

Cette surcharge ne participe à la résolution de surcharge que si aucun dépassement n'est provoqué lors de la conversion, et si l'une des conditions suivantes est satisfaite :[2]

  • std::chrono::treat_as_floating_point<Rep>::value is true.
  • Toutes les conditions suivantes sont satisfaites :
    • std::ratio_divide<Period2, Period>::den is 1.
    • std::chrono::treat_as_floating_point<Rep2>::value is false.
  1. ↑ Autrement dit, une durée avec un nombre de ticks entier ne peut pas être construite à partir d'une valeur à virgule flottante, mais une durée avec un nombre de ticks à virgule flottante peut être construite à partir d'une valeur entière.
  2. ↑ Autrement dit, soit la durée utilise des ticks à virgule flottante, soit Period2 est exactement divisible par Period.

Paramètres

  • r — un nombre de ticks
  • d — une durée à copier

Exemple

Le code suivant montre plusieurs exemples (valides et invalides) de construction de durées :

#include <chrono>

int main()
{
    std::chrono::hours h(1); // une heure
    std::chrono::milliseconds ms{3}; // 3 milliseconds
    std::chrono::duration<int, std::kilo> ks(3); // 3000 seconds

    // erreur : treat_as_floating_point<int>::value == false,
    // Cette durée n'autorise que des nombres entiers de ticks
//  std::chrono::duration<int, std::kilo> d3(3.5);

    // Horloge à 30 Hz utilisant des ticks fractionnaires
    std::chrono::duration<double, std::ratio<1, 30>> hz30(3.5);

    // 3000 microsecondes construites à partir de 3 millisecondes
    std::chrono::microseconds us = ms;
    // erreur : 1/1000000 n'est pas divisible par 1/1000
//  std::chrono::milliseconds ms2 = us
    std::chrono::duration<double, std::milli> ms2 = us; // 3.0 milliseconds
}
