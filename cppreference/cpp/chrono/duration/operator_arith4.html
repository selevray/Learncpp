Effectue les opérations arithmétiques de base entre deux durées ou entre une durée et un nombre de ticks.

  1. Convertit les deux durées en leur type commun et crée une durée dont le nombre de ticks est la somme des nombres de ticks après conversion.

  2. Convertit les deux durées en leur type commun et crée une durée dont le nombre de ticks est égal au nombre de ticks rhs soustrait au nombre de ticks lhs après conversion.

3,4) Convertit la durée d en une durée dont le rep est le type commun entre Rep1 et Rep2, et multiplie le nombre de ticks après conversion par s. Ces surcharges ne participent à la résolution de surcharge que si s est convertible en typename std::common_type<Rep1, Rep2>::type.

  1. Convertit la durée d en une durée dont le rep est le type commun entre Rep1 et Rep2, et divise le nombre de ticks après conversion par s. Cette surcharge ne participe à la résolution de surcharge que si s est convertible en typename std::common_type<Rep1, Rep2>::type et que Rep2 n'est pas une spécialisation de duration.

  2. Convertit les deux durées en leur type commun et divise le nombre de ticks de lhs après conversion par le nombre de ticks de rhs après conversion. Notez que la valeur de retour de cet opérateur n'est pas une durée.

  3. Convertit la durée d en une durée dont le rep est le type commun entre Rep1 et Rep2, et crée une durée dont le nombre de ticks est le reste de la division du nombre de ticks, après conversion, par s. Cette surcharge ne participe à la résolution de surcharge que si s est convertible en typename std::common_type<Rep1, Rep2>::type et que Rep2 n'est pas une spécialisation de duration.

  4. Convertit les deux durées en leur type commun et crée une durée dont le nombre de ticks est le reste de la division des nombres de ticks après conversion.

Paramètres

  • lhs — durée située à gauche de l'opérateur
  • rhs — durée située à droite de l'opérateur
  • d — l'argument durée pour les opérateurs à arguments mixtes
  • s — argument non durée pour les opérateurs à arguments mixtes

Valeur de retour

En supposant que CD est le type de retour de la fonction et CD<A, B> = std::common_type<A, B>::type, alors :

  1. CD(CD(lhs).count() + CD(rhs).count())

  2. CD(CD(lhs).count() - CD(rhs).count())

3,4) CD(CD(d).count() * s)

  1. CD(CD(d).count() / s)

  2. CD(lhs).count() / CD(rhs).count() (le type de retour de cet opérateur n'est pas une durée)

  3. CD(CD(d).count() % s)

  4. CD(CD(lhs).count() % CD(rhs).count())

Exemple

#include <chrono>
#include <iostream>

int main()
{
    // Arithmétique simple :
    std::chrono::seconds s = std::chrono::hours(1)
                           + 2 * std::chrono::minutes(10)
                           + std::chrono::seconds(70) / 10;
    std::cout << "1 hour + 2*10 min + 70/10 sec = " << s << " (seconds)\n";

    using namespace std::chrono_literals;

    // Différence entre la division d'une durée par un nombre
    // et la division d'une durée par une autre durée :
    std::cout << "Dividing that by 2 minutes gives "
              << s / 2min << '\n'
              << "Dividing that by 2 gives "
              << (s / 2).count() << " seconds\n";

    // L'opérateur de reste est utile pour déterminer où
    // dans un intervalle de temps se situe cette durée particulière, par exemple pour
    // la décomposer en heures, minutes et secondes :
    std::cout << s << " (seconds) = "
              << std::chrono::duration_cast<std::chrono::hours>(
                 s) << " (hour) + "
              << std::chrono::duration_cast<std::chrono::minutes>(
                 s % 1h) << " (minutes) + "
              << std::chrono::duration_cast<std::chrono::seconds>(
                 s % 1min) << " (seconds)\n";

    constexpr auto sun_earth_distance{150'000'000ULL}; // km
    constexpr auto speed_of_light{300000ULL}; // km/sec
    std::chrono::seconds t(sun_earth_distance / speed_of_light); // sec
    std::cout << "A photon flies from the Sun to the Earth in "
              << t / 1min << " minutes " << t % 1min << " (seconds)\n";
}

Output:

1 hour + 2*10 min + 70/10 sec = 4807s (seconds)
Dividing that by 2 minutes gives 40
Dividing that by 2 gives 2403 seconds
4807s (seconds) = 1h (hour) + 20min (minutes) + 7s (seconds)
A photon flies from the Sun to the Earth in 8 minutes 20s (seconds)
