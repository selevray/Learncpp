std::chrono::duration<Rep,Period>::zero

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static constexpr duration zero();  // (jusqu'à C++20)

static constexpr duration zero() noexcept;  // (depuis C++20)

Renvoie une durée de longueur nulle.

Si la représentation rep de la durée nécessite une autre implémentation pour renvoyer une durée de longueur nulle, std::chrono::duration_values peut être spécialisé pour renvoyer la valeur souhaitée.

Paramètres

(aucune)

Valeur de retour

Renvoie duration(std::chrono::duration_values<rep>::zero()).

Exemple

#include <chrono>
#include <ratio>

template<typename X, typename Y>
using dura = std::chrono::duration<X, Y>;

static_assert
(
    (std::chrono::hours::zero() == std::chrono::nanoseconds::zero()) &&
    (dura<short, std::nano>::zero() == dura<int, std::deci>::zero()) &&
    (dura<short, std::deca>::zero() == dura<long, std::exa>::zero()) &&
    (dura<long, std::atto>::zero().count() == dura<float, std::exa>::zero().count())
);

int main() {}
