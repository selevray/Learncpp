std::chrono::duration_cast

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <chrono>

template< class ToDuration, class Rep, class Period >
constexpr ToDuration duration_cast( const std::chrono::duration<Rep, Period>& d );  // (depuis C++11)

Convertit une std::chrono::duration en une durée d'un type différent ToDuration.

La fonction ne participe à la résolution de surcharge que si ToDuration est une spécialisation de std::chrono::duration.

Soit

  • ToRep be typename ToDuration::rep,
  • ToPeriod be typename ToDuration::period,
  • CF be std::ratio_divide<Period, ToPeriod>,
  • CR be std::common_type<Rep, ToRep, std::intmax_t>::type,
  • cr_count be static_cast<CR>(d.count()),
  • cr_num doit être static_cast<CR>(CF::num), et
  • cr_den be static_cast<CR>(CF::den),

le résultat est :

CF::num

1 | not 1

CF::den | 1 | ToDuration(static_cast<ToRep> (d.count())) | ToDuration(static_cast<ToRep> (cr_count * cr_num))

not 1 | ToDuration(static_cast<ToRep> (cr_count / cr_den)) | ToDuration(static_cast<ToRep> (cr_count * cr_num / cr_den))

Paramètres

  • d — durée à convertir

Valeur de retour

d converti en une durée de type ToDuration.

Notes

Aucune conversion implicite n'est utilisée. Les multiplications et divisions sont évitées autant que possible, s'il est connu à la compilation qu'un ou plusieurs paramètres valent 1. Les calculs sont effectués dans le type le plus large disponible, puis convertis, comme avec static_cast, vers le type du résultat uniquement une fois terminés.

La conversion entre durées entières dont la période source est exactement divisible par la période cible (par exemple heures vers minutes) ou entre durées à virgule flottante peut être effectuée avec des transtypages ordinaires ou implicitement via constructeurs std::chrono::duration, sans qu'il soit nécessaire de duration_cast.

La conversion d'une durée à virgule flottante en une durée entière est soumise à un comportement indéfini lorsque la valeur à virgule flottante est NaN, infinie, ou trop grande pour être représentée par le type entier cible. Sinon, la conversion vers une durée entière est soumise à une troncature, comme toute static_cast vers un type entier.

Exemple

Cet exemple mesure le temps d'exécution d'une fonction.

#include <chrono>
#include <iostream>
#include <ratio>
#include <thread>

void f()
{
    std::this_thread::sleep_for(std::chrono::seconds(1));
}

int main()
{
    const auto t1 = std::chrono::high_resolution_clock::now();
    f();
    const auto t2 = std::chrono::high_resolution_clock::now();

    // durée à virgule flottante : pas besoin de duration_cast
    const std::chrono::duration<double, std::milli> fp_ms = t2 - t1;

    // durée entière : nécessite duration_cast
    const auto int_ms = std::chrono::duration_cast<std::chrono::milliseconds>(t2 - t1);

    // conversion d'une durée entière en une durée entière de
    // unité de temps divisible plus courte : pas besoin de duration_cast
    const std::chrono::duration<long, std::micro> int_usec = int_ms;

    std::cout << "f() took " << fp_ms << ", or "
              << int_ms << " (whole milliseconds), or "
              << int_usec << " (whole microseconds)\n";
}

Sortie possible :

f() took 1000.14ms, or 1000ms (whole milliseconds), or 1000000us (whole microseconds)
