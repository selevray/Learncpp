std::chrono::abs(std::chrono::duration)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <chrono>

template< class Rep, class Period >
constexpr std::chrono::duration<Rep, Period> abs( std::chrono::duration<Rep, Period> d );  // (depuis C++17)

Renvoie la valeur absolue de la durée d. Plus précisément, si d >= d.zero(), renvoie d, sinon renvoie -d.

La fonction ne participe pas à la résolution de surcharge sauf si std::numeric_limits<Rep>::is_signed est true.

Paramètres

  • d — duration

Valeur de retour

Valeur absolue de d.

Implémentation possible

template<class Rep, class Period,
    class = std::enable_if_t<std::numeric_limits<Rep>::is_signed>>
constexpr std::chrono::duration<Rep, Period> abs(std::chrono::duration<Rep, Period> d)
{
    return d >= d.zero() ? +d : -d;
}

Exemple

#include <chrono>
#include <iostream>

int main()
{
    using namespace std::chrono;

    static_assert(abs(-42s) == std::chrono::abs(42s));

    std::cout << "abs(+3min) = " << abs(3min).count() << '\n'
              << "abs(-3min) = " << abs(-3min).count() << '\n';
}

Output:

abs(+3min) = 3
abs(-3min) = 3
