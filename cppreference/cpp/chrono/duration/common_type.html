std::common_type<std::chrono::duration>

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <chrono>

template< class Rep1, class Period1, class Rep2, class Period2 >
struct common_type<std::chrono::duration<Rep1, Period1>,
                   std::chrono::duration<Rep2, Period2>>;  // (depuis C++11)

Expose le type nommé type, qui est le type commun de deux std::chrono::durations, dont la période est le plus grand commun diviseur de Period1 et Period2.

Types membres

Type membre Définition

  • type — std::chrono::duration<typename std::common_type<Rep1, Rep2>::type, /* voir la note */>

Note

La période de la durée résultante peut être calculée en formant un rapport entre le plus grand commun diviseur de Period1::num et Period2::num et le plus petit commun multiple de Period1::den et Period2::den.

Exemple

#include <chrono>
#include <iostream>
#include <type_traits>

// std::chrono trouve déjà le plus grand commun diviseur,
// probablement en utilisant std::common_type<>. Nous faisons le type
// déduction de l'extérieur.

template<typename T,typename S>
constexpr auto durationDiff(const T& t, const S& s)
    -> typename std::common_type<T,S>::type
{
    typedef typename std::common_type<T,S>::type Common;
    return Common(t) - Common(s);
}

int main()
{
    using namespace std::literals;

    constexpr auto ms = 30ms;
    constexpr auto us = 1100us;
    constexpr auto diff = durationDiff(ms, us);

    std::cout << ms << " - " << us << " = " << diff << '\n';
}

Output:

30ms - 1100us = 28900us
