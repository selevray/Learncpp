template< class Rep, class Period >
struct hash<std::chrono::duration<Rep, Period>>;  // (depuis C++26)

La spécialisation de modèle de std::hash pour std::chrono::duration permet aux utilisateurs d'obtenir les empreintes (hachages) des objets de type std::chrono::duration<Rep, Period>. Cette spécialisation est activée si et seulement si std::hash<Rep> et std::hash<Period> sont toutes deux activées.
