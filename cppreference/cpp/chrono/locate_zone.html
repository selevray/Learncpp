std::chrono::locate_zone

Défini dans l'en-tête <chrono>

const std::chrono::time_zone* locate_zone( std::string_view tz_name );  // (depuis C++20)

Fonction utilitaire permettant de localiser un fuseau horaire dans la base de données des fuseaux horaires. Équivalente à std::chrono::get_tzdb().locate_zone(tz_name).

Exceptions

std::runtime_error si le fuseau horaire spécifié est introuvable, ou si c'est la première référence à la base de données des fuseaux horaires et que celle-ci ne peut pas être initialisée.

Notes

Un appel à cette fonction qui constitue la première référence à la base de données des fuseaux horaires entraîne son initialisation.
