template< class CharT, class Traits, class Duration >
std::basic_ostream<CharT, Traits>&
    operator<<( std::basic_ostream<CharT, Traits>& os,
                const std::chrono::sys_days& tp );  // (2) (depuis C++20)

Envoie tp dans le flux os.

  1. Équivalent à :
return os << std::format(os.getloc(), STATICALLY-WIDEN<CharT>("{:L%F %T}"), tp);

où STATICALLY_WIDEN<CharT>("{:L%F %T}") est "{:L%F %T}" si CharT est char, et L"{:L%F %T}" si CharT est wchar_t.

Cette surcharge ne participe à la résolution de surcharge que si std::chrono::treat_as_floating_point_v<typename Duration::rep> est false et Duration(1) < std::chrono::days(1).

  1. Équivalent à os << std::chrono::year_month_day(tp);.
