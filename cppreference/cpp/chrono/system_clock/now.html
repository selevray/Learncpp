std::chrono::system_clock::now

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static std::chrono::time_point<std::chrono::system_clock> now() noexcept;  // (depuis C++11)

Renvoie un point temporel représentant l'instant présent.

Valeur de retour

Un point temporel représentant l'heure actuelle.

Exemple

#include <chrono>
#include <iostream>

int main()
{
    const auto now = std::chrono::system_clock::now();
    const std::time_t t_c = std::chrono::system_clock::to_time_t(now);
    std::cout << "The system clock is currently at " << std::ctime(&t_c);
}
