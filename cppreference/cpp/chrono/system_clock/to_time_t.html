std::chrono::system_clock::to_time_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static std::time_t to_time_t( const time_point& t ) noexcept;  // (depuis C++11)

Convertit t en type std::time_t.

Si std::time_t a une précision plus faible, il est défini par l'implémentation de savoir si la valeur est arrondie ou tronquée.

Paramètres

  • t — point temporel de l'horloge système à convertir

Valeur de retour

Une valeur std::time_t représentant t.

Exemple

Obtient l'heure actuelle en std::time_t de deux manières.

#include <chrono>
#include <ctime>
#include <iostream>
#include <thread>
using namespace std::chrono_literals;

int main()
{
    // L'ancienne manière
    std::time_t oldt = std::time({});

    std::this_thread::sleep_for(2700ms);

    // La nouvelle manière
    auto const now = std::chrono::system_clock::now();
    std::time_t newt = std::chrono::system_clock::to_time_t(now);

    std::cout << "newt - oldt == " << newt - oldt << " s\n";
}

Sortie possible :

newt - oldt == 3 s
