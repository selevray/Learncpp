std::chrono::time_zone::get_info

template< class Duration >
std::chrono::sys_info get_info( const std::chrono::sys_time<Duration>& tp ) const;  // (depuis C++20)

template< class Duration >
std::chrono::local_info get_info( const std::chrono::local_time<Duration>& tp ) const;  // (depuis C++20)

Obtient des informations sur ce fuseau horaire au point dans le temps tp.

Valeur de retour

  1. Une structure std::chrono::sys_info i contenant les informations de fuseau horaire en vigueur pour ce fuseau horaire au point dans le temps tp. tp sera dans l'intervalle [i.begin,i.end).

  2. Une structure std::chrono::local_info contenant des informations sur l'heure locale tp dans ce fuseau horaire.
