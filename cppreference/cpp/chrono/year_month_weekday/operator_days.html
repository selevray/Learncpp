std::chrono::year_month_weekday::operator sys_days, std::chrono::year_month_weekday::operator local_days

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr operator std::chrono::sys_days() const noexcept;  // (1) (depuis C++20)

constexpr explicit operator std::chrono::local_days() const noexcept;  // (2) (depuis C++20)

Convertit *this en std::chrono::time_point représentant la même date que cet year_month_weekday.

  1. Si year().ok() && month().ok() && weekday().ok() :
  • Si index() == 0, renvoie un sys_days qui représente la date 7 jours avant le premier weekday() de l'année et du mois.
  • Sinon, renvoie un sys_days qui représente la date (index() - 1) * 7 jours après le premier weekday() de l'année et du mois.

Sinon, la valeur de retour est non spécifiée.

  1. Identique à (1), mais renvoie local_days au lieu de sys_days. Équivalent à local_days(sys_days(*this).time_since_epoch()).

Exemple

#include <chrono>
#include <iostream>
using namespace std::chrono;

int main()
{
    constexpr auto ymwd{Tuesday[2]/11/2021};
    std::cout << ymwd << '\n';
    // conversion d'un format basé sur des champs vers un format basé sur des numéros de série pour ajouter des heures
    constexpr auto sd = sys_days{ymwd} + 24h;
    std::cout << sd << '\n';
    constexpr auto ymd = floor<days>(sd);
    static_assert(ymd == November/10/2021);
}
