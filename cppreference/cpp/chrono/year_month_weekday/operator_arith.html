Modifie le point temporel que *this représente, de la durée dy ou dm.

  1. Équivalent à *this = *this + dy;.

  2. Équivalent à *this = *this + dm;.

  3. Équivalent à *this = *this - dy;.

  4. Équivalent à *this = *this - dm;.

Pour les durées convertibles à la fois en std::chrono::years et en std::chrono::months, les surcharges years (1,3) sont préférées si l'appel serait sinon ambigu.

Exemple

#include <cassert>
#include <chrono>
#include <iostream>

int main()
{
    auto ymwi{1/std::chrono::Wednesday[2]/2021};
    std::cout << ymwi << '\n';

    ymwi += std::chrono::years(5);
    std::cout << ymwi << '\n';
    assert(static_cast<std::chrono::year_month_day>(ymwi) ==
                       std::chrono::year(2026)/1/14);

    ymwi -= std::chrono::months(1);
    std::cout << ymwi << '\n';
    assert(static_cast<std::chrono::year_month_day>(ymwi) ==
                       std::chrono::day(10)/12/2025);
}

Output:

2021/Jan/Wed[2]
2026/Jan/Wed[2]
2025/Dec/Wed[2]
