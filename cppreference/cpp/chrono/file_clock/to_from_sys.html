  1. Convertit le file_time t en un sys_time représentant le même point temporel.

La durée du type de retour est calculée à partir de Duration de manière non spécifiée.

Ces modèles de fonctions sont optionnels : une implémentation peut choisir de fournir à la place to_utc() et from_utc().

Valeur de retour

  1. Un sys_time représentant le même point temporel que l'argument.

  2. Un file_time représentant le même point temporel que l'argument.

Notes

Le code utilisateur devrait généralement utiliser std::chrono::clock_cast, qui fournit une interface générique pour convertir les points temporels entre horloges, plutôt que d'appeler directement ces fonctions.
