std::chrono::sys_info

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <chrono>

struct sys_info;  // (depuis C++20)

La classe sys_info décrit les informations de fuseau horaire associées à un fuseau horaire à un instant donné (représenté soit par un std::chrono::sys_time, soit par un std::chrono::local_time). Il s'agit d'une structure de données de bas niveau, généralement non utilisée directement par le code utilisateur.

Objets membres

Objet membre Type

  • begin, end — std::chrono::sys_seconds
  • offset — std::chrono::seconds
  • save — std::chrono::minutes
  • abbrev — std::string

Les membres de données begin et end indiquent l'intervalle [begin,end) dans lequel offset et abbrev sont en vigueur pour le fuseau horaire associé à ce sys_info.

Les membres de données offset et abbrev indiquent respectivement le décalage UTC et l'abréviation du fuseau horaire en vigueur pour le fuseau horaire associé et std::chrono::time_point. Notez que les abréviations de fuseaux horaires ne sont pas uniques.

Le membre de données save, s'il est non nul, indique que le fuseau horaire est à l'heure d'été au point temporel spécifié. Dans ce cas, offset - save est une suggestion du décalage que ce fuseau horaire pourrait utiliser s'il n'était pas à l'heure d'été. Toutefois, cette information n'a pas valeur d'autorité : la seule façon de connaître le décalage réel est d'interroger le fuseau horaire avec un point temporel qui n'est effectivement pas à l'heure d'été (c'est-à-dire qui renvoie un sys_info tel que save == 0min).

Fonctions non membres

  • operator<< (C++20) — envoie un sys_info dans un flux (modèle de fonction)

Classes auxiliaires

  • std::formatter<std::chrono::sys_info> (C++20) — prise en charge du formatage pour sys_info (spécialisation de modèle de classe)
