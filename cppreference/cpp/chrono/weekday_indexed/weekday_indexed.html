constexpr weekday_indexed( const std::chrono::weekday& wd, unsigned index ) noexcept;  // (2) (depuis C++20)

Construit un weekday_indexed.

Le constructeur par défaut laisse non initialisés à la fois le std::chrono::weekday et la valeur de l'index 1).

  1. Construit un weekday_indexed stockant le jour de la semaine wd et l'indice index. Les valeurs contenues sont non spécifiées si !wd.ok() || index > 7.

Notes

Une façon plus pratique de construire un weekday_indexed est d'utiliser weekday, à savoir operator[], soit wd[index].

Exemple

#include <chrono>
#include <iostream>
using namespace std::chrono;

int main()
{
    constexpr auto third_friday = weekday_indexed(Friday, 3); // utilise le constructeur (2)
    static_assert(third_friday == Friday[3]);

    weekday_indexed wdi = Tuesday[2]; // représente le 2e mardi
    std::cout << year_month_day{ wdi / October / 2019y } << '\n';
}
