std::chrono::weekday::operator[]

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr std::chrono::weekday_indexed
    operator[]( unsigned index ) const noexcept;  // (1) (depuis C++20)

constexpr std::chrono::weekday_last
    operator[]( std::chrono::last_spec ) const noexcept;  // (2) (depuis C++20)

  1. Construit un weekday_indexed à partir de *this et index. Le résultat représente le index-ième jour de la semaine d'un mois encore non précisé. Si index n'appartient pas à l'intervalle [0,7] ou si !ok(), les valeurs (un jour de la semaine sous-jacent et un indice) contenues dans le résultat sont non spécifiées.

  2. Construit un weekday_last à partir de *this. Le résultat représente le dernier jour de la semaine d'un mois encore non précisé.

Valeur de retour

  1. std::chrono::weekday_indexed(*this, index)

  2. std::chrono::weekday_last(*this)

Exemple

#include <chrono>
#include <iostream>
using namespace std::chrono;

int main()
{
    constexpr auto second_tuesday_in_October_2019 =
        year_month_day{Tuesday[2] / October / 2019y};

    constexpr auto last_tuesday_in_October_2019 =
        year_month_day{Tuesday[last] / October / 2019y};

    std::cout << second_tuesday_in_October_2019 << '\n'
              << last_tuesday_in_October_2019 << '\n';
}
