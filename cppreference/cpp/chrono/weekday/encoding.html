std::chrono::weekday::c_encoding, std::chrono::weekday::iso_encoding

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr unsigned c_encoding() const noexcept;  // (1) (depuis C++20)

constexpr unsigned iso_encoding() const noexcept;  // (2) (depuis C++20)

  1. Renvoie la valeur du jour de la semaine stockée dans *this.

  2. Renvoie la valeur du jour de la semaine stockée dans *this, sauf que le dimanche (stocké comme 0) est interprété comme 7 selon la norme ISO 8601.

Valeur de retour

  1. La valeur du jour de la semaine stockée dans *this.

  2. c_encoding() == 0u ? 7u : c_encoding()

Exemple

#include <chrono>
#include <iostream>

int main()
{
    std::cout << "i: C: ISO: Weekday:\n";

    for (unsigned i{0}; i != 8; ++i)
    {
        const std::chrono::weekday w{i};
        std::cout << i << "  "
                  << w.c_encoding() << "  "
                  << w.iso_encoding() << "    "
                  << w << '\n';
    }
}
