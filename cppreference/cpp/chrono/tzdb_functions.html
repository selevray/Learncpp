Ces fonctions donnent accès à la base de données des fuseaux horaires propre au programme.

  1. Renvoie une référence vers le singleton global std::chrono::tzdb_list. S'il s'agit du premier accès à la base de données, initialise la base de données. Après l'initialisation, la base de données contient un unique objet std::chrono::tzdb initialisé. Cette fonction est thread-safe : des appels simultanés à cette fonction depuis plusieurs threads n'introduisent pas de course aux données.

  2. Renvoie une référence vers le premier objet std::chrono::tzdb contenu dans le singleton tzdb_list. Équivalent à std::chrono::get_tzdb_list().front().

  3. Renvoie une chaîne contenant la dernière version distante de la base de données.

  4. Si remote_version() != get_tzdb().version, ajoute en tête du singleton tzdb_list référencé par get_tzdb_list() un nouvel objet tzdb représentant la base de données distante. Sinon, cette fonction n'a aucun effet. Aucune référence, aucun pointeur ni aucun itérateur n'est invalidé. Appeler cette fonction simultanément avec get_tzdb_list().front() ou get_tzdb_list().erase_after() n'introduit pas de course aux données.

Exceptions

  1. std::runtime_error si, pour une raison quelconque, une référence vers un tzdb_list contenant au moins un tzdb valide ne peut pas être renvoyée.

Valeur de retour

  1. Une référence vers le singleton global std::chrono::tzdb_list.

  2. std::chrono::get_tzdb_list().front().

  3. Une chaîne contenant la dernière version distante de la base de données.

  4. std::chrono::get_tzdb_list().front() (après toute mise à jour effectuée par cette fonction).
