std::chrono::tai_clock::from_utc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class Duration >
static std::chrono::tai_time<std::common_type_t<Duration, std::chrono::seconds>>
    from_utc( const std::chrono::utc_time<Duration>& ) noexcept;  // (depuis C++20)

Convertit le utc_time t en un tai_time représentant le même point temporel.

Valeur de retour

Un std::chrono::tai_time représentant le même point dans le temps que t, calculé comme si l'on construisait une valeur du type de retour à partir de t.time_since_epoch() et qu'on lui ajoutait 378691210s (378691210 est le nombre de secondes entre les époques des deux horloges : 1958-01-01 00:00:00 TAI et 1970-01-01 00:00:00 UTC).
