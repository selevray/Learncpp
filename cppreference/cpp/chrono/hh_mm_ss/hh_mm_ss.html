std::chrono::hh_mm_ss<Duration>::hh_mm_ss

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr hh_mm_ss() noexcept : hh_mm_ss{Duration::zero()} {}  // (1)

constexpr explicit hh_mm_ss( Duration d );  // (2)

Construit un objet hh_mm_ss.

  1. Construit un objet hh_mm_ss correspondant à Duration::zero().

  2. Construit un objet hh_mm_ss correspondant à d :

  • is_negative() renvoie d < Duration::zero().
  • hours() renvoie std::chrono::duration_cast<std::chrono::hours>(abs(d)).
  • minutes() renvoie std::chrono::duration_cast<std::chrono::minutes>(abs(d) - hours()).
  • seconds() renvoie
    std::chrono::duration_cast<std::chrono::seconds>(abs(d) - hours() - minutes()).
  • subseconds() renvoie abs(d) - hours() - minutes() - seconds() si std::chrono::treat_as_floating_point_v<precision::rep> vaut true ; sinon il renvoie std::chrono::duration_cast<precision>(abs(d) - hours() - minutes() - seconds()).

Paramètres

  • d — la durée à décomposer

Exemple

#include <chrono>
#include <print>

int main()
{
    std::println("Default constructor: {}", std::chrono::hh_mm_ss<std::chrono::minutes>{});

    std::chrono::time_point now = std::chrono::system_clock::now();
    std::chrono::hh_mm_ss time_of_day{now - std::chrono::floor<std::chrono::days>(now)};
    std::println("The time of day is: {}", time_of_day);
}
