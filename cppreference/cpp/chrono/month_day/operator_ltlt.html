std::chrono::operator<<(std::chrono::month_day)

Défini dans l'en-tête <chrono>

template< class CharT, class Traits >
std::basic_ostream<CharT, Traits>&
    operator<<( std::basic_ostream<CharT, Traits>& os, const std::chrono::month_day& md );  // (depuis C++20)

Écrit une représentation textuelle de md dans le flux os, comme si par

os << std::format(os.getloc(), STATICALLY_WIDEN<CharT>("{:L}/{}"), md.month(), md.day())

où STATICALLY_WIDEN<CharT>("{:L}/{}") vaut "{:L}/{}" si CharT est char, et L"{:L}/{}" si CharT est wchar_t.
