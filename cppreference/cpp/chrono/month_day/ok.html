std::chrono::month_day::ok

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr bool ok() const noexcept;  // (depuis C++20)

Détermine si ce month_day stocke une combinaison mois-jour valide.

La combinaison est valide si month() représente un mois valide (month().ok() == true), unsigned{day()} >= 1, et unsigned{day()} <= D, où D est le nombre de jours du mois représenté par month(). Le nombre de jours de février est considéré comme égal à 29.

Valeur de retour

true si la combinaison mois-jour est valide, sinon false.

Exemple

#include <chrono>
#include <iostream>

int main()
{
    std::cout << std::boolalpha;

    constexpr auto md1{std::chrono::July/15};
    std::cout << (md1.ok()) << ' ';
    constexpr std::chrono::month_day md2{std::chrono::month(14), std::chrono::day(42)};
    std::cout << (md2.ok()) << ' ';
    constexpr auto md3{std::chrono::February/29};
    std::cout << (md3.ok()) << '\n';
}

Output:

true false true
