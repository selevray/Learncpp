Ajoute ou soustrait 1 à la valeur d'année.

1,2) Effectue *this += std::chrono::years{1};.

3,4) Effectue *this -= std::chrono::years{1};.

Paramètres

(aucune)

Valeur de retour

1,3) Une référence à ce year après modification.

2,4) Une copie du year effectuée avant modification.

Notes

Si le résultat se situait hors de l'intervalle [-32767,32767], la valeur réellement stockée est non spécifiée.

Exemple

#include <chrono>
#include <iostream>

int main()
{
    std::cout << std::boolalpha;

    std::chrono::year y{2020};
    std::cout << (++y == std::chrono::year(2021)) << ' ';
    std::cout << (--y == std::chrono::year(2020)) << '\n';

    using namespace std::literals::chrono_literals;
    y = 32767y;
    y++; //← non spécifié, voir ↑ Notes ↑
    std::cout << static_cast<int>(y) << '\n';
}
