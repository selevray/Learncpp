1,2) Ajoute ys.count() années à y.

  1. Soustrait ys.count() années de y.

  2. Retourne la différence en années entre y1 et y2.

Valeur de retour

1,2) std::chrono::year(int(y) + ys.count())

  1. std::chrono::year(int(y) - ys.count())

  2. std::chrono::years(int(y1) - int(y2))

Notes

Si la valeur d'année résultante pour (1-3) est en dehors de l'intervalle [-32767,32767], la valeur réelle stockée est non spécifiée.

Le résultat de la soustraction de deux valeurs year est une durée de type std::chrono::years. Cette unité de durée représente la longueur de l'année grégorienne moyenne, et la durée résultante n'a aucun rapport avec le nombre de jours des années particulières représentées par les opérandes. Par exemple, le résultat de 2018y - 2017y est std::chrono::years(1), ce qui représente 365.2425 jours, et non 365 jours.

Exemple

#include <cassert>
#include <chrono>

int main()
{
    std::chrono::year y{2020};

    y = std::chrono::years(12) + y; // surcharge (2) : durée + point temporel
    assert(y == std::chrono::year(2032));

    y = y - std::chrono::years(33); // surcharge (3) : point temporel - durée
    assert(y == std::chrono::year(1999));

    // y = std::chrono::years(33) - y; // non pris en charge : durée - point temporel

    using namespace std::chrono;
    constexpr std::chrono::years ys = 2025y - 2020y; // overload (4)
    static_assert(ys == std::chrono::years(5));
}
