std::chrono::year::ok

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr bool ok() const noexcept;  // (depuis C++20)

Vérifie si la valeur d'année stockée dans *this est dans l'intervalle valide, c'est-à-dire [-32767,32767].

Valeur de retour

true si la valeur d'année stockée dans *this est dans l'intervalle [-32767,32767]. Sinon false.

Implémentation possible

Voir les implémentations dans libstdc++, libc++ et le fichier date.h de Howard Hinnant.

class Year
{
    short year_;   // exposition uniquement

public:

    bool ok() const noexcept { return year_ != std::numeric_limits<short>::min(); }

    /*...*/
};

Exemple

#include <chrono>
#include <iomanip>
#include <iostream>

int main()
{
    std::cout << "input year │ internal value │ ok()\n" << std::boolalpha;

    for (const int i : {2020, 0x8000, 0x8001, 0xFFFF, 0x18000})
    {
        const std::chrono::year y{i};
        std::cout << std::setw(10) << i << " │ "
                  << std::setw(14) << static_cast<int>(y) << " │ "
                  << y.ok() << '\n';
    }
}
