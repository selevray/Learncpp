std::chrono::operator<<(std::chrono::year)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <chrono>

template< class CharT, class Traits >
std::basic_ostream<CharT, Traits>&
    operator<<( std::basic_ostream<CharT, Traits>& os, const std::chrono::year& y );  // (depuis C++20)

Forme un std::basic_string<CharT> s constitué de la valeur d'année stockée dans y, formatée en nombre décimal, complétée à gauche par 0 jusqu'à quatre chiffres si le résultat aurait sinon moins de quatre chiffres. Ensuite, si !y.ok(), ajoute " is not a valid year" à la chaîne formatée. Insère cette chaîne dans os.

Équivalent à

return os << (y.ok() ? std::format(STATICALLY_WIDEN<CharT>("{:%Y}"), y) : std::format(STATICALLY_WIDEN<CharT>("{:%Y} is not a valid year"), y));

où STATICALLY_WIDEN<CharT>("...") vaut "..." si CharT est char, et L"..." si CharT est wchar_t.

Valeur de retour

os

Exemple

#include <chrono>
#include <iostream>

int main()
{
    constexpr std::chrono::year y1{2020}, y2{-020}, y3{98304};
    std::cout << y1 << '\n'
              << y2 << '\n'
              << y3 << '\n';
}

Sortie possible :

2020
-0016
-32768 is not a valid year
