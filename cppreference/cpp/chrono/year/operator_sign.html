constexpr std::chrono::year operator+() noexcept;  // (1) (depuis C++20)

constexpr std::chrono::year operator-() noexcept;  // (2) (depuis C++20)

Applique les opérateurs unaires à la valeur d'année.

  1. Retourne une copie de *this.

  2. Retourne un year dont la valeur d'année est l'opposée de celle de *this.

Valeur de retour

  1. *this

  2. std::chrono::year(-int(*this))

Exemple

#include <chrono>
#include <iostream>

int main()
{
    constexpr std::chrono::year y{2020};
    constexpr auto ny = -y;
    std::cout << "The year " << (int)y << " negated is " << (int)ny << '\n';
}

Output:

The year 2020 negated is -2020
