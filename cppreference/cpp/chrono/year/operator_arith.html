std::chrono::year::operator+=, std::chrono::year::operator-=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr std::chrono::year& operator+=( const std::chrono::years& y ) noexcept;  // (1) (depuis C++20)

constexpr std::chrono::year& operator-=( const std::chrono::years& y ) noexcept;  // (2) (depuis C++20)

Ajoute ou soustrait y.count() années à la valeur d'année.

  1. Équivalent à *this = *this + y;.

  2. Équivalent à *this = *this - y;.

Valeur de retour

Une référence à ce year après modification.

Notes

Si le résultat se situait hors de l'intervalle [-32767,32767], la valeur réellement stockée est non spécifiée.

Exemple

#include <chrono>
#include <iostream>

int main()
{
    using namespace std::literals::chrono_literals;
    std::cout << std::boolalpha;

    std::chrono::year y{2020};

    y += std::chrono::years(12);
    std::cout << (y == 2032y) << ' ';

    y -= std::chrono::years(33);
    std::cout << (y == 1999y) << '\n';
}

Output:

true true
