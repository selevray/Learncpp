std::chrono::file_clock

Défini dans l'en-tête <chrono>

using file_clock = /* voir ci-dessous */;  // (depuis C++20)

std::chrono::file_clock est un alias de l'horloge utilisée pour std::filesystem::file_time_type. Son époque est non spécifiée.

file_clock satisfait aux exigences TrivialClock.

Types membres

Type membre Définition

  • rep — type arithmétique signé représentant le nombre de ticks dans la durée de l'horloge
  • period — un type std::ratio représentant la période d'un tick de l'horloge, en secondes
  • duration — std::chrono::duration<rep, period>, capable de représenter des durées négatives
  • time_point — std::chrono::time_point<std::chrono::file_clock>

Constantes membres

  • constexpr bool is_steady [statique] — true si le temps entre deux ticks est toujours constant, c'est-à-dire si les appels à now() renvoient des valeurs qui croissent de manière monotone même en cas d'ajustement externe de l'horloge, false (constante membre statique publique)
