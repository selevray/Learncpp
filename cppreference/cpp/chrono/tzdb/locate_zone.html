std::chrono::tzdb::locate_zone

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

const std::chrono::time_zone* locate_zone( std::string_view tz_name ) const;  // (depuis C++20)

Obtient un pointeur vers une std::chrono::time_zone de cette base de données qui représente le fuseau horaire désigné par tz_name. Si p est le pointeur renvoyé, alors soit p->name() == tz_name, soit il existe une std::chrono::time_zone_link l dans cette base de données telle que p->name() == l.target() && l.name() == tz_name.

Valeur de retour

Un pointeur vers la std::chrono::time_zone de cette base de données qui représente le fuseau horaire désigné par tz_name.

Exceptions

Lève std::runtime_error si aucun time_zone de ce type ne peut être trouvé.
