std::literals::chrono_literals::operator""us

Défini dans l'en-tête <chrono>

constexpr std::chrono::microseconds
    operator""us( unsigned long long us );  // (1) (depuis C++14)

constexpr std::chrono::duration</*unspecified*/, std::micro>
    operator""us( long double us );  // (2) (depuis C++14)

Forme un littéral std::chrono::duration représentant des microsecondes.

  1. Littéral entier, renvoie exactement std::chrono::microseconds(us).

  2. Littéral à virgule flottante, renvoie une durée à virgule flottante équivalente à std::chrono::microseconds.

Paramètres

  • us — le nombre de microsecondes

Valeur de retour

Le littéral std::chrono::duration.

Implémentation possible

constexpr std::chrono::microseconds operator""us(unsigned long long us)
{
    return std::chrono::microseconds(us);
}
constexpr std::chrono::duration<long double, std::micro> operator""us(long double us)
{
    return std::chrono::duration<long double, std::micro>(us);
}

Notes

Cet opérateur est déclaré dans l'espace de noms std::literals::chrono_literals, où literals et chrono_literals sont des espaces de noms en ligne. L'accès à cet opérateur peut être obtenu avec :

  • using namespace std::literals,
  • using namespace std::chrono_literals, or
  • using namespace std::literals::chrono_literals.

De plus, dans l'espace de noms std::chrono, la directive using namespace literals::chrono_literals; est fournie par la bibliothèque standard, de sorte que si un programmeur utilise using namespace std::chrono; pour accéder aux classes de la bibliothèque chrono, les opérateurs littéraux correspondants deviennent également visibles.

Exemple

#include <chrono>
#include <iostream>

int main()
{
    using namespace std::chrono_literals;
    auto d1 = 250us;
    std::chrono::microseconds d2 = 1ms;
    std::cout << d1 << " = " << d1.count() << " microseconds\n"
              << 1ms << " = " << d2.count() << " microseconds\n";
}

Output:

250us = 250 microseconds
1ms = 1000 microseconds
