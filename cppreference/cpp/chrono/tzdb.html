std::chrono::tzdb

Défini dans l'en-tête <chrono>

struct tzdb;  // (depuis C++20)

La classe tzdb représente une copie de la base de données des fuseaux horaires IANA. Les utilisateurs ne peuvent pas construire un tzdb et ne peuvent obtenir qu'un accès en lecture seule à un tel objet, via les fonctions non membres std::chrono::get_tzdb_list et std::chrono::get_tzdb.

Objets membres

Objet membre Description

  • version — Un std::string qui contient la version de la base de données
  • zones — Un std::vector<std::chrono::time_zone> trié contenant la description des fuseaux horaires
  • links — Un std::vector<std::chrono::time_zone_link> trié contenant la description des noms alternatifs des fuseaux horaires (liens)
  • leap_seconds — Un std::vector<std::chrono::leap_second> trié contenant la description des secondes intercalaires

Fonctions membres

  • locate_zone — localise un fuseau horaire avec le nom donné (fonction membre publique)
  • current_zone — renvoie le fuseau horaire local (fonction membre publique)
