std::chrono::current_zone

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <chrono>

const std::chrono::time_zone* current_zone();  // (depuis C++20)

Fonction pratique permettant d'obtenir le fuseau horaire local depuis la base de données des fuseaux horaires. Équivalent à std::chrono::get_tzdb().current_zone().

Exceptions

std::runtime_error si c'est la première référence à la base de données des fuseaux horaires et que celle-ci ne peut pas être initialisée.

Notes

Un appel à cette fonction qui constitue la première référence à la base de données des fuseaux horaires entraîne son initialisation.

Exemple

#include <chrono>
#include <iostream>

int main() {
    const std::chrono::zoned_time cur_time{ std::chrono::current_zone(),
                                            std::chrono::system_clock::now() };
    std::cout << cur_time << '\n';
}
