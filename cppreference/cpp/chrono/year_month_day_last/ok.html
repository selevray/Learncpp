std::chrono::year_month_day_last::ok

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr bool ok() const noexcept;  // (depuis C++20)

Vérifie si *this représente une date valide. Comme un year_month_day_last représente le dernier jour d'un mois donné, il représente une date valide tant que l'année et le mois sont valides.

Valeur de retour

year().ok() && month().ok()

Exemple

#include <cassert>
#include <chrono>

int main()
{
    auto ymdl{std::chrono::last/11/2020};
    assert(ymdl.ok());
    ymdl = std::chrono::year(2020)/std::chrono::month(13)/std::chrono::last;
    assert(not ymdl.ok());
}
