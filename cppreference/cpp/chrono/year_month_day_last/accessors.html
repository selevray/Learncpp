Récupère les valeurs de champs stockées dans cet objet year_month_day_last.

Valeur de retour

  1. Renvoie la valeur std::chrono::year stockée.

  2. Renvoie la valeur std::chrono::month stockée.

  3. Une std::chrono::day correspondant au dernier jour de l'année et du mois stockés. Si this->ok() est false, la valeur de retour n'est pas spécifiée.

  4. Une std::chrono::month_day_last construite à partir de month().

Exemple

#include <chrono>

int main()
{
    constexpr auto ymdl{std::chrono::last/11/2020};
    static_assert
    (
        ymdl.day() == std::chrono::day(30) &&
        ymdl.month() == std::chrono::November &&
        ymdl.year() == std::chrono::year(2020) &&
        ymdl.month_day_last() == std::chrono::November/std::chrono::last
    );
}
