final spécificateur (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Indique qu'une fonction virtuelle ne peut pas être surchargée dans une classe dérivée, ou qu'une classe ne peut pas être dérivée.

Syntaxe

Lorsqu'il est appliqué à une fonction membre, l'identifiant final apparaît immédiatement après le déclarateur dans la syntaxe d'une déclaration ou d'une définition de fonction membre à l'intérieur d'une définition de classe.

Lorsqu'il est appliqué à une classe (y compris struct et union), l'identifiant final apparaît au début de la définition de la classe, immédiatement après le nom de la classe, et ne peut pas apparaître dans une déclaration de classe.

| | | | declarator virt-specifier-seq ﻿*(facultatif)* pure-specifier ﻿*(facultatif)* | (1) | | | | declarator virt-specifier-seq ﻿*(facultatif)* function-body | (2) | | | | class-key attr ﻿*(optional)* class-head-name class-virt-specifier ﻿*(optional)* base-clause ﻿*(optional)* | (3) | | |

  1. Dans une déclaration de fonction membre, final peut apparaître dans virt-specifier-seq immédiatement après le déclarateur, et avant le pure-specifier, si utilisé.

  2. Dans une définition de fonction membre à l'intérieur d'une définition de classe, final peut apparaître dans virt-specifier-seq immédiatement après le déclarateur et juste avant function-body.

  3. Dans une définition de classe, final peut apparaître sous la forme class-virt-specifier immédiatement après le nom de la classe, juste avant les deux-points qui commencent la base-clause, si utilisé.

Dans les cas (1,2), virt-specifier-seq, si utilisé, est soit override soit final, ou final override ou override final. Dans le cas (3), la seule valeur autorisée de class-virt-specifier, si utilisé, est final.

Explication

Lorsqu'il est utilisé dans une déclaration ou définition de fonction virtuelle, le spécificateur final garantit que la fonction est virtuelle et indique qu'elle ne peut pas être surchargée par les classes dérivées. Le programme est mal formé (une erreur de compilation est générée) sinon.

Lorsqu'il est utilisé dans une définition de classe, final indique que cette classe ne peut pas apparaître dans la base-specifier-list d'une autre définition de classe (autrement dit, elle ne peut pas être dérivée). Le programme est mal formé sinon (une erreur de compilation est générée). final peut aussi être utilisé avec une définition de union, auquel cas il n'a aucun effet(sauf sur le résultat de std::is_final) (depuis C++14), puisque les unions ne peuvent pas être dérivées.

final est un identifiant ayant une signification particulière lorsqu'il est utilisé dans une déclaration de fonction membre ou dans l'en-tête d'une classe. Dans les autres contextes, il n'est pas réservé et peut être utilisé pour nommer des objets et des fonctions.

Note

Dans une suite des jetons suivants :

  1. l'un de class, struct et union
  2. un identifiant éventuellement qualifié
  3. final
  4. l'un de : et {

le troisième jeton final de la suite est toujours considéré comme un spécificateur plutôt qu'un identifiant.

struct A;
struct A final {}; // OK, définition de la structure A,
                   // pas une initialisation par valeur de la variable final

struct X
{
    struct C { constexpr operator int() { return 5; } };
    struct B final : C{}; // OK, définition de la classe imbriquée B,
                          // pas une déclaration du membre de champ de bits final
};

// Utilisation anormale de final.

struct final final // OK, définition d'une structure nommée `final` dont
{                  // on ne peut pas hériter
};

// struct final final {}; // Erreur : redéfinition de `struct final`, PAS une
                          // définition d'une variable `final` utilisant un spécificateur de type
                          // de type élaboré `struct final` suivi d'une
                          // initialisation d'agrégat

// struct override : final {}; // Erreur : impossible de dériver d'un type de base final;
                               // `override` dans le contexte donné est un nom ordinaire
void foo()
{
    [[maybe_unused]]
    final final; // OK, déclaration d'une variable nommée `final` de type
                 // `struct final`
}

struct final final; // OK, déclaration d'une variable nommée `final` de type
                    // `struct final` utilisant un spécificateur de type élaboré
int main()
{
}

Mots-clés

final

Exemple

struct Base
{
    virtual void foo();
};

struct A : Base
{
    void foo() final; // Base::foo est surchargée et A::foo est la surcharge finale
    void bar() final; // Erreur : bar ne peut pas être final car elle n'est pas virtuelle
};

struct B final : A // struct B est final
{
    void foo() override; // Erreur : foo ne peut pas être surchargée car elle est final dans A
};

struct C : B {}; // Erreur : B est final
