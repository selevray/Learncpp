Littéraux booléens

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Syntaxe

| | | | true | (1) | | | | false | (2) | | |

Explication

Les littéraux booléens sont les mots-clés true et false. Ce sont des prvalues de type bool.

Notes

Voir Conversions entières pour les conversions implicites de bool vers d'autres types, et conversions booléennes pour les conversions implicites d'autres types vers bool.

Mots-clés

false, true

Exemple

#include <iostream>

int main()
{
    std::cout << std::boolalpha
              << true << '\n'
              << false << '\n'
              << std::noboolalpha
              << true << '\n'
              << false << '\n';
}

Output:

true
false
1
0
