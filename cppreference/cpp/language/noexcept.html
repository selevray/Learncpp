opérateur noexcept (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

L'opérateur noexcept effectue une vérification à la compilation qui renvoie true si une expression est déclarée comme ne levant aucune exception.

Il peut être utilisé dans le noexcept spécificateur d'un modèle de fonction pour déclarer que la fonction lèvera des exceptions pour certains types mais pas pour d'autres.

Syntaxe

| | | | noexcept( expression ) | | | |

Renvoie une prvalue de type bool. Le résultat vaut true si [l'ensemble des exceptions potentielles de expression est vide (jusqu'à C++17) | expression est spécifié comme ne levant pas d'exception (depuis C++17)], et false sinon.

expression est un opérande non évalué.

Si expression est une prvalue, une matérialisation temporaire est appliquée.

(depuis C++17)

Notes

Même si noexcept(expr) est true, l'évaluation de expr peut tout de même lever une exception à cause de la rencontre d'un comportement indéfini.

Si expression est d'un type classe ou d'un tableau (éventuellement multidimensionnel) de tels types, la matérialisation temporaire exige que le destructeur ne soit pas supprimé et soit accessible.

(depuis C++17)

Mots-clés

noexcept

Exemple

#include <iostream>
#include <utility>
#include <vector>

void may_throw();
void no_throw() noexcept;
auto lmay_throw = []{};
auto lno_throw = []() noexcept {};

class T
{
public:
    ~T(){} // le destructeur empêche le constructeur de déplacement
           // le constructeur de copie est noexcept
};

class U
{
public:
    ~U(){} // le destructeur empêche le constructeur de déplacement
           // le constructeur de copie est noexcept(false)
    std::vector<int> v;
};

class V
{
public:
    std::vector<int> v;
};

int main()
{
    T t;
    U u;
    V v;

    std::cout << std::boolalpha <<
        "may_throw() is noexcept(" << noexcept(may_throw()) << ")\n"
        "no_throw() is noexcept(" << noexcept(no_throw()) << ")\n"
        "lmay_throw() is noexcept(" << noexcept(lmay_throw()) << ")\n"
        "lno_throw() is noexcept(" << noexcept(lno_throw()) << ")\n"
        "~T() is noexcept(" << noexcept(std::declval<T>().~T()) << ")\n"
        // note : les tests suivants exigent aussi que ~T() soit noexcept, car
        // l'expression à l'intérieur de noexcept construit et détruit un temporaire
        "T(rvalue T) is noexcept(" << noexcept(T(std::declval<T>())) << ")\n"
        "T(lvalue T) is noexcept(" << noexcept(T(t)) << ")\n"
        "U(rvalue U) is noexcept(" << noexcept(U(std::declval<U>())) << ")\n"
        "U(lvalue U) is noexcept(" << noexcept(U(u)) << ")\n"
        "V(rvalue V) is noexcept(" << noexcept(V(std::declval<V>())) << ")\n"
        "V(lvalue V) is noexcept(" << noexcept(V(v)) << ")\n";
}

Output:

may_throw() is noexcept(false)
no_throw() is noexcept(true)
lmay_throw() is noexcept(false)
lno_throw() is noexcept(true)
~T() is noexcept(true)
T(rvalue T) is noexcept(true)
T(lvalue T) is noexcept(true)
U(rvalue U) is noexcept(false)
U(lvalue U) is noexcept(false)
V(rvalue V) is noexcept(true)
V(lvalue V) is noexcept(false)
