Instruction continue

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Provoque le saut de la partie restante de la boucle for, range-for, while ou do-while englobante.

Utilisé lorsqu'il est autrement malaisé d'ignorer la partie restante de la boucle à l'aide d'instructions conditionnelles.

Syntaxe

| | | | attr ﻿*(facultatif)* continue ; | | | |

Explication

L'instruction continue provoque un saut, comme par goto vers la fin du corps de la boucle (elle ne peut apparaître que dans le corps des boucles for, range-for, while et do-while).

Plus précisément,

Pour une boucle while, elle agit comme

while (/* ... */)
{
   // ...
   continue; // agit comme goto contin;
   // ...
   contin:;
}

Pour une boucle do-while, elle agit comme :

do
{
    // ...
    continue; // agit comme goto contin;
    // ...
    contin:;
} while (/* ... */);

Pour les boucles for et range-for, elle agit comme suit :

for (/* ... */)
{
    // ...
    continue; // agit comme goto contin;
    // ...
    contin:;
}

Mots-clés

continue

Exemple

#include <iostream>

int main()
{
    for (int i = 0; i < 10; ++i)
    {
        if (i != 5)
            continue;
        std::cout << i << ' ';      // cette instruction est ignorée à chaque fois que i != 5
    }
    std::cout << '\n';

    for (int j = 0; 2 != j; ++j)
        for (int k = 0; k < 5; ++k) // seule cette boucle est affectée par continue
        {
            if (k == 3)
                continue;
            // cette instruction est ignorée à chaque fois que k == 3 :
            std::cout << '(' << j << ',' << k << ") ";
        }
    std::cout << '\n';
}

Output:

5
(0,0) (0,1) (0,2) (0,4) (1,0) (1,1) (1,2) (1,4)
