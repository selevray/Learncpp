Historique de C++

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Premier C++

  • 1979 : première implémentation de C with Classes
  1. Nouveautés : classes, fonctions membres, classes dérivées, compilation séparée, contrôle d'accès public et privé, amis, vérification des types des arguments de fonction, arguments par défaut, fonctions inline, opérateur d'affectation surchargé, constructeurs, destructeurs, f() identique à f(void), call-function et return-function (fonctionnalités de synchronisation, absentes de C++)
  2. Bibliothèques : la bibliothèque de tâches concurrentes (absente de C++)
  • 1982 : publication du manuel de référence de C with Classes
  • 1984 : implémentation de C84, publication du manuel de référence
  • 1985: Cfront 1.0
  1. Nouveautés : fonctions virtuelles, surcharge de fonctions et d'opérateurs, références, opérateurs new et delete, le mot-clé const, opérateur de résolution de portée
  2. Ajouts à la bibliothèque : nombres complexes, string (version AT&T), flux d'E/S
  • 1985 : The C++ Programming Language, 1re édition
  • 1986 : l'article « whatis? » documentant les objectifs de conception restants, dont l'héritage multiple, la gestion des exceptions et les modèles.
  • 1987 : prise en charge de C++ dans GCC 1.15.3
  • 1989: Cfront 2.0
  1. Nouveautés : héritage multiple, pointeurs vers des membres, accès protégé, liaison sûre en termes de types, classes abstraites, fonctions membres static et qualifiées const, new et delete propres aux classes
  2. Ajouts à la bibliothèque : manipulateurs d'E/S
  • 1990 : The Annotated C++ Reference Manual

Ce livre décrivait le langage tel qu'il avait été conçu, y compris certaines fonctionnalités non encore implémentées. Il a servi de standard de facto jusqu'à l'ISO.

  1. Nouveautés : espaces de noms, gestion des exceptions, classes imbriquées, modèles
  • 1991: Cfront 3.0
  • 1991 : The C++ Programming Language, 2e édition

C++ standard

  • 1990 : fondation du comité ANSI C++
  • 1991 : fondation du comité ISO C++
  • 1992 : STL implémentée en C++

Période C++98/03

  • 1998 : C++98 (ISO/IEC 14882:1998)
  1. Nouveautés : RTTI (dynamic_cast, typeid), types de retour covariants, opérateurs de conversion, mutable, bool, déclarations dans les conditions, instanciations de modèles, modèles membres, export
  2. Ajouts à la bibliothèque : locales, bitset, valarray, auto_ptr, chaîne de caractères templatisée, flux d'E/S, et nombres complexes.
  3. Basé sur la STL : conteneurs, algorithmes, itérateurs, objets fonctions
  • 1998 : The C++ Programming Language, 3e édition
  • 1999 : Boost fondée par les membres du comité pour produire de nouvelles bibliothèques candidates de haute qualité pour le standard.
  • 2003 : C++03 (ISO/IEC 14882:2003)

Il s'agissait d'une révision mineure, destinée à n'être guère plus qu'un correctif technique. Cette révision introduit la définition de l'initialisation par valeur.

  • 2006 : rapport technique sur les performances (ISO/IEC TR 18015:2006) (boutique ISO) (projet de 2006)

Ce rapport technique traite du coût de diverses abstractions du C++, fournit des indications d'implémentation, aborde l'utilisation du C++ dans les systèmes embarqués et introduit une <hardware> interface vers le TR ISO/IEC 18037:2008 <iohw.h> du C.

  • 2007 : extension de la bibliothèque TR1 (ISO/IEC TR 19768:2007) (boutique ISO) (projet de 2005).

Ce rapport technique est une extension de la bibliothèque C++, qui ajoute à la bibliothèque standard C++ les éléments suivants :

  1. De Boost : reference_wrapper, pointeurs intelligents, fonction membre, result_of, bind, function, traits de types, aléatoire, fonctions spéciales mathématiques, tuple, array, conteneurs non ordonnés (y compris hash), et expressions régulières.
  2. De C99 : fonctions mathématiques de <math.h> introduites en C99, classe de caractères blank, environnement à virgule flottante, hexfloat manipulateur d'E/S, types entiers de taille fixe, le type long long, va_copy, les familles de fonctions snprintf() et vfscanf(), et les spécificateurs de conversion C99 pour les familles de fonctions printf() et scanf().

L'ensemble de TR1, à l'exception des fonctions spéciales, a été inclus dans C++11, avec des modifications mineures.

  • 2010 : fonctions spéciales mathématiques (ISO/IEC 29124:2010) (boutique ISO) (projet de 2010)

Cette norme internationale est une extension de la bibliothèque standard C++, qui ajoute les fonctions spéciales faisant partie de TR1 mais non incluses dans C++11 : intégrales elliptiques, intégrale exponentielle, polynômes de Laguerre, polynômes de Legendre, polynômes de Hermite, fonctions de Bessel, fonctions de Neumann, fonction bêta et fonction zêta de Riemann. Cette norme a été intégrée à C++17.

Période C++11

  • 2011 : C++11 (ISO/IEC 14882:2011) (boutique ISO) (projet de 2012 post-publication).

Article principal : C++11

De nombreuses modifications ont été introduites pour à la fois normaliser les pratiques existantes et améliorer les abstractions disponibles pour les programmeurs C++

  • 2011 : rapport technique sur les nombres décimaux à virgule flottante (ISO/IEC TR 24733:2011) (boutique ISO) (projet de 2009)

Ce rapport technique implémente les types décimaux à virgule flottante de la norme IEEE 754-2008 pour l'arithmétique à virgule flottante : std::decimal::decimal32, std::decimal::decimal64 et std::decimal::decimal128.

  • 2012 : The Standard C++ Foundation fondée
  • 2013 : The C++ Programming Language, 4e édition

Période C++14

  • 2014 : C++14 (boutique ISO) (boutique ANSI) (projet final de 2014)

Article principal : C++14

Révision mineure de la norme C++

  • 2015 : spécification technique de la bibliothèque de systèmes de fichiers (ISO/IEC TS 18822:2015) (boutique ISO) (projet de 2014)

Cette spécification technique est une extension expérimentale de la bibliothèque C++ qui définit une bibliothèque de systèmes de fichiers basée sur boost.filesystem V3 (avec quelques modifications et extensions). Cette spécification technique a été intégrée à C++17.

  • 2015 : extensions de parallélisme, spécification technique (ISO/IEC TS 19570:2015) (boutique ISO) (projet de 2015)

Cette spécification technique normalise une API parallèle et vectorielle-parallèle pour tous les algorithmes de la bibliothèque standard, et ajoute de nouveaux algorithmes tels que reduce, transform_reduce ou exclusive_scan. Cette spécification technique a été intégrée à C++17.

  • 2015 : extensions de mémoire transactionnelle, spécification technique (ISO/IEC TS 19841:2015) (boutique ISO) ([projet de 2015)

Cette spécification technique étend le noyau du langage C++ avec des blocs synchronisés et atomiques, ainsi que des fonctions sûres pour les transactions, qui implémentent la sémantique de la mémoire transactionnelle.

  • 2015 : extensions de la bibliothèque des fondamentaux, spécification technique (ISO/IEC TS 19568:2015) (boutique ISO) (projet de 2015)

Cette spécification technique ajoute plusieurs nouveaux composants à la bibliothèque standard C++ : optional, any, string_view, sample, search, apply, allocateurs polymorphes, et modèles de variables pour les traits de types. Cette spécification technique a été intégrée à C++17.

  • 2015 : extensions des concepts, spécification technique (ISO/IEC TS 19217:2015) (boutique ISO) (projet de 2015)

Cette spécification technique étend le noyau du langage C++ avec les concepts (exigences nommées sur les types) et les contraintes (limites sur les types autorisés dans les déclarations de modèles, de fonctions et de variables), ce qui facilite la métaprogrammation et simplifie les diagnostics d'instanciation de modèles ; voir concepts. Cette spécification technique a été intégrée à C++20, à l'exception de certaines omissions.

  • 2016 : Extensions for Concurrency TS (ISO/IEC TS 19571:2016) (boutique ISO) (brouillon de 2015)

Ce TS étend la bibliothèque C++ pour inclure plusieurs extensions à std::future, latches et barriers, ainsi que des pointeurs intelligents atomiques.

Période C++17

  • 2017 : C++17 (boutique ISO) (boutique ANSI) (brouillon final n4659 du 2017-03-21)

Article principal : C++17

La révision majeure de la norme C++ après C++11

  • 2017 : Extensions for Ranges TS (ISO/IEC TS 21425:2017) (boutique ISO) (brouillon de 2017)

Ce TS étend la bibliothèque C++ pour inclure des intervalles, une nouvelle abstraction, plus puissante, destinée à remplacer les paires d'itérateurs, ainsi que des vues d'intervalles, des intervalles sentinelles, des projections pour des transformations à la volée, de nouveaux adaptateurs d'itérateurs et de nouveaux algorithmes. Cette extension rend enfin possible le tri d'un vector avec sort(v);

  • 2017 : Extensions for Coroutines TS (ISO/IEC TS 22277:2017) (boutique ISO) (brouillon de 2017)

Ce TS étend le noyau du langage C++ et la bibliothèque standard pour inclure les coroutines sans pile (fonctions reprenables). Cela ajoute les mots-clés co_await, co_yield et co_return.

  • 2018 : Extensions for Networking TS (ISO/IEC TS 19216:2018) (boutique ISO) (brouillon de 2017)

Ce TS étend la bibliothèque C++ pour inclure la mise en réseau TCP/IP basée sur boost.asio.

  • 2018 : Extensions for modules TS (ISO/IEC TS 21544:2018) (boutique ISO) (brouillon de 2018)

Ce TS étend le noyau du langage C++ pour inclure les modules. Cela ajoute les identifiants spéciaux module, import, et réintroduit le mot-clé export avec une nouvelle signification.

  • 2018 : Extensions for Parallelism version 2 TS (ISO/IEC TS 19570:2018) (boutique ISO) (brouillon de 2018)

Ce TS étend la bibliothèque C++ pour inclure deux nouvelles politiques d'exécution (unseq et vec), des algorithmes parallèles supplémentaires tels que reduction_plus ou for_loop_strided, des blocs de tâches pour le lancement et la synchronisation de tâches parallèles, ainsi que des types SIMD et des opérations sur ces types.

Période C++20

  • 2020 : C++20 (boutique ISO) (brouillon final n4860 du 2020-03-31)

Article principal : C++20

La révision majeure de la norme C++ après C++17

  • 2021 : Reflection TS (ISO/IEC TS 23619:2021) (boutique ISO) (brouillon de 2020)

Ce TS étend C++ avec les moyens d'inspecter les entités du programme telles que les variables, les énumérations, les classes et leurs membres, les lambdas et leurs captures, etc.
