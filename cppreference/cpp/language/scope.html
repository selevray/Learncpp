Portée

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Chaque déclaration apparaissant dans un programme C++ n'est visible que dans certaines portées éventuellement discontinues.

Au sein d'une portée, la recherche de nom non qualifiée peut être utilisée pour associer un nom à sa déclaration.

Généralités

Chaque programme possède une portée globale, qui contient l'ensemble du programme.

Toute autre portée S est introduite par

  • une déclaration,
  • un paramètre dans une liste de paramètres,
  • une instruction, ou
  • un gestionnaire.

S apparaît toujours dans une autre portée, qui contient alors S.

Une portée englobante en un point du programme est toute portée qui le contient ; la plus petite de ces portées est dite portée immédiate en ce point.

Une portée intervient entre un point du programme P et une portée S (qui ne contient pas P) si elle est ou contient S mais ne contient pas P.

La portée parente de toute portée S qui n'est pas une portée de paramètre de modèle est la plus petite portée qui contient S et qui n'est pas une portée de paramètre de modèle.

Sauf indication contraire :

  • Une déclaration réside dans la portée immédiate à son locus.
  • La portée cible d'une déclaration est la portée dans laquelle elle réside.
  • Tous les noms (ré)introduits par une déclaration sont liés à celle-ci dans sa portée cible.

Une entité appartient à une portée S si S est la portée cible d'une déclaration de l'entité.

//                portée globale  portée  portée
//                portée     S      T
int x;         //   ─┐                 // point de programme X
               //    │
{              //    │     ─┐
    {          //    │      │     ─┐
        int y; //    │      │      │   // point de programme Y
    }          //    │      │     ─┘
}              //   ─┘     ─┘

Dans le programme ci-dessus :

  • La portée globale, la portée S et la portée T contiennent le point de programme Y.

    • En d'autres termes, ces trois portées sont toutes des portées englobantes au point de programme Y.

  • La portée globale contient les portées S et T, et la portée S contient la portée T.

    • Par conséquent, la portée T est la plus petite des trois, ce qui signifie que :
      • La portée T est la portée immédiate au point de programme Y.
      • La déclaration de la variable y réside dans la portée T à son locus.
      • La portée T est la portée cible de la déclaration de y.
      • La variable y appartient à la portée T.
    • La portée S est la portée parente de la portée T, et la portée globale est la portée parente de la portée S.

  • La portée S s'interpose entre le point de programme X et la portée T.

Portée de bloc

Chaque

  • instruction de sélection (if, switch),
  • instruction d'itération (for, range-for (depuis C++11), while, do-while),
  • gestionnaire, ou
  • instruction composée qui n'est pas le compound-statement d'un gestionnaire

introduit une portée de bloc qui englobe l'instruction ou le gestionnaire.

Une variable appartenant à une portée de bloc est une variable de bloc.

int i = 42;
int a[10];

for (int i = 0; i < 10; i++) // « i » interne réside dans la portée de bloc
    a[i] = i;                // introduite par l'instruction for

int j = i; // j = 42

Les déclarations de extern dans une portée de bloc ciblent une portée englobante plus grande, mais lient un nom dans leur portée immédiate.

Si une déclarationqui n'est pas une déclaration de nom indépendant et (depuis C++26) qui lie un nom dans la portée de bloc S de

  • le compound-statement d'un corps de fonction ou d'un bloc try de fonction,
  • l'instruction composée { body } d'une expression lambda,

(depuis C++11)

  • une sous-instruction d'une instruction de sélection ou d'itération qui n'est pas elle-même une instruction de sélection ou d'itération, ou
  • un gestionnaire d'un bloc try de fonction

entre en conflit potentiel avec une déclaration dont la portée cible est la portée parente de S, le programme est mal formé.

if (int x = f())  // déclare « x »
{ // le bloc if est une sous-instruction de l'instruction if
    int x;        // erreur : redéclaration de « x »
}
else
{ // le bloc else est également une sous-instruction de l'instruction if
    int x;        // erreur : redéclaration de « x »
}

void g(int i)
{
    extern int i; // erreur : redéclaration de « i »
}

Portée des paramètres de fonction

Chaque déclaration de paramètre P introduit une portée de paramètre de fonction qui englobe P.

  • Si le paramètre déclaré fait partie de la liste de paramètres d'une déclaration de fonction :
    • Si la déclaration de fonction est une définition de fonction, la portée introduite s'étend jusqu'à la fin de la définition de la fonction.
    • Sinon (la déclaration de fonction est un prototype de fonction), la portée introduite s'étend jusqu'à la fin du déclarateur de fonction.
    • Dans les deux cas, la portée n'inclut pas le locus de la déclaration de fonction.
  • Si le paramètre déclaré fait partie de la liste de paramètres d'une expression lambda, la portée introduite s'étend jusqu'à la fin de { body }.

(depuis C++11)

  • Si le paramètre déclaré fait partie de la liste de paramètres d'un guide de déduction, la portée introduite s'étend jusqu'à la fin de ce guide de déduction.

(depuis C++17)

  • Si le paramètre déclaré fait partie de la liste de paramètres d'une expression requires, la portée introduite s'étend jusqu'à la fin de { requirement-seq }.

(depuis C++20)

int f(int n) // la déclaration du paramètre « n »
{            // introduit une portée de paramètres de fonction
    /* ... */
}            // la portée des paramètres de fonction se termine ici

Portée lambda

Chaque expression lambda introduit une portée lambda qui commence immédiatement après [captures ﻿] et s'étend jusqu'à la fin de { body }.

Les captures avec initialisateurs d'une expression lambda E résident dans la portée lambda introduite par E.

auto lambda = [x = 1, y]() // cette expression lambda introduit une portée lambda,
{                          // c'est la portée cible de la capture « x »
    /* ... */
};                         // la portée lambda se termine avant le point-virgule

(depuis C++14)

Portée d'espace de noms

Chaque définition d'espace de noms pour un espace de noms N introduit une portée d'espace de noms S qui inclut le declarations de chaque définition d'espace de noms pour N.

Pour chaque redéclaration ou spécialisation non amie dont la portée cible est S ou est contenue dans S, les parties suivantes sont également incluses dans la portée S :

  • Pour une redéclaration de classe (modèle de classe) ou une spécialisation de modèle de classe, la partie qui suit son class-head-name.
  • Pour une redéclaration d'énumération, la partie qui suit son enum-head-name.
  • Pour toute autre redéclaration ou spécialisation, la partie qui suit le unqualified-id ou qualified-id du déclarateur.

La portée globale est la portée d'espace de noms de l'espace de noms global.

namespace V   // la définition d'espace de noms de « V »
{             // introduit une portée d'espace de noms « S »
    // la première partie de la portée « S » commence ici
    void f();
    // la première partie de la portée « S » se termine ici
}

void V::f()   // la partie après « f » fait aussi partie de la portée « S »
{
    void h(); // déclare V::h
}             // la seconde partie de la portée « S » se termine ici

Portée de classe

Chaque déclaration d'une classe ou d'un modèle de classe C introduit une portée de classe S qui inclut le member-specification de la définition de classe de C.

Pour chaque redéclaration ou spécialisation non amie dont la portée cible est S ou est contenue dans S, les parties suivantes sont également incluses dans la portée S :

  • Pour une redéclaration de classe (modèle de classe) ou une spécialisation de modèle de classe, la partie qui suit son class-head-name.
  • Pour une redéclaration d'énumération, la partie qui suit son enum-head-name.
  • Pour toute autre redéclaration ou spécialisation, la partie qui suit le unqualified-id ou qualified-id du déclarateur.
class C       // la définition de classe de « C »
{             // introduit une portée de classe « S »
    // la première partie de la portée « S » commence ici
    void f();
    // la première partie de la portée « S » se termine ici
}

void C::f()   // la partie après « f » fait aussi partie de la portée « S »
{
    /* ... */
}             // la seconde partie de la portée « S » se termine ici

Portée d'énumération

Chaque déclaration d'une énumération E introduit une portée d'énumération qui inclut le enumerator-list de la déclaration d'énumération non opaque (depuis C++11) de E (si elle est présente).

enum class E // la déclaration d'énumération de « E »
{            // introduit une portée d'énumération « S »
    // la portée « S » commence ici
    e1, e2, e3
    // la portée « S » se termine ici
}

Portée de paramètre de modèle

Chaque paramètre de modèle template introduit une portée de paramètre de modèle qui inclut toute la liste de paramètres de modèleet les clauses require (depuis C++20) de ce paramètre de modèle template.

Chaque déclaration de modèle D introduit une portée de paramètre de modèle S qui s'étend du début de la liste de paramètres de modèle de D jusqu'à la fin de D. Toute déclaration située en dehors de la liste de paramètres de modèle qui résiderait dans S réside à la place dans la même portée que D.

// la déclaration de modèle de classe de « X »
// introduit une portée de paramètres de modèle « S1 »
template
<
    // la portée « S1 » commence ici
    template // le paramètre de modèle template « T »
             // introduit une autre portée de paramètres de modèle « S2 »
    <
        typename T1
        typename T2
    > requires std::convertible_from<T1, T2> // la portée « S2 » se termine ici
    class T,
    typename U
>
class X; // la portée « S1 » se termine avant le point-virgule

Point de déclaration

En général, un nom est visible après le locus de sa première déclaration, lequel se situe comme suit.

Le locus d'un nom déclaré dans une déclaration simple se situe immédiatement après le déclarateur de ce nom et avant son initialisateur, le cas échéant.

int x = 32; // le x externe est dans la portée

{
    int x = x; // le x interne est dans la portée avant l'initialiseur (= x)
               // cela n'initialise pas le x interne avec la valeur du x externe (32),
               // cela initialise le x interne avec sa propre valeur (indéterminée)
}

std::function<int(int)> f = [&](int n){ return n > 1 ? n * f(n - 1) : n; };
// le nom de la fonction f est dans la portée de la lambda et peut
// être correctement capturé par référence, donnant une fonction récursive

const int x = 2; // le x externe est dans la portée

{
    int x[x] = {}; // le x interne est dans la portée avant l'initialiseur (= {}),
                   // mais après le déclarateur (x[x])
                   // dans le déclarateur, le x externe est encore dans la portée
                   // ceci déclare un tableau de 2 int
}

Le locus d'une déclaration de classe ou de modèle de classe se situe immédiatement après l'identifiant qui nomme la classe (ou le template-id qui nomme la spécialisation de modèle) dans son class-head. Le nom de la classe ou du modèle de classe est déjà dans la portée dans la liste des classes de base.

struct S: std::enable_shared_from_this<S> {}; // S est dans la portée au niveau des deux-points

Le locus d'un spécificateur enumou d'une déclaration d'énumération opaque (depuis C++11) se situe immédiatement après l'identifiant qui nomme l'énumération.

enum E : int // E est dans la portée au niveau des deux-points
{
    A = sizeof(E)
};

Le locus d'une déclaration d'alias de type ou alias de modèle se situe immédiatement après le type-id auquel l'alias fait référence.

using T = int; // le T externe est dans la portée au point-virgule

{
    using T = T*; // le T interne est dans la portée au point-virgule,
                  // le T externe est encore dans la portée avant le point-virgule
                  // identique à T = int*
}

Le locus d'un déclarateur dans une déclaration using qui ne nomme pas un constructeur se situe immédiatement après le déclarateur.

template<int N>
class Base
{
protected:
    static const int next = N + 1;
    static const int value = N;
};

struct Derived: Base<0>, Base<1>, Base<2>
{
    using Base<0>::next,     // next est dans la portée à la virgule
          Base<next>::value; // Derived::value vaut 1
};

Le locus d'un énumérateur se situe immédiatement après sa définition (et non avant l'initialisateur comme pour les variables).

const int x = 12;

{
    enum
    {
        x = x + 1, // l'énumérateur x est dans la portée à la virgule,
                   // le x externe est dans la portée avant la virgule,
                   // l'énumérateur x est initialisé à 13
        y = x + 1  // y est initialisé à 14
    };
}

Le locus d'un nom de classe injecté se situe immédiatement après l'accolade ouvrante de la définition de sa classe (ou de son modèle de classe).

template<typename T>
struct Array
//  : std::enable_shared_from_this<Array> // erreur : le nom de classe injecté n'est pas dans la portée
    : std::enable_shared_from_this< Array<T> > // OK : le nom de modèle Array est dans la portée
{ // le nom de classe injecté Array est désormais dans la portée comme un nom de membre public
    Array* p; // pointeur vers Array<T>
};

Le locus de la déclaration implicite d'une variable prédéfinie locale à une fonction __func__ se situe immédiatement avant le corps de fonction d'une définition de fonction.

(depuis C++11)

Le locus d'une déclaration de liaison structurée se situe immédiatement après le identifier-list, mais les initialisateurs de liaison structurée ne peuvent pas faire référence à l'un des noms en cours de déclaration.

(depuis C++17)

Le locus de la variableou des liaisons structurées (depuis C++17) déclarée dans range-declaration d'une boucle range-for se situe immédiatement après range-expression.

std::vector<int> x;

for (auto x : x) // le vecteur x est dans la portée avant la parenthèse fermante,
                 // auto x est dans la portée à la parenthèse fermante
{
    // l'auto x est dans la portée
}

(depuis C++11)

Le locus d'un paramètre de modèle se situe immédiatement après son paramètre de modèle complet (y compris l'argument par défaut optionnel).

typedef unsigned char T;

template<
    class T = T, // le paramètre de modèle T est dans la portée à la virgule,
                 // le nom de typedef de unsigned char est dans la portée avant la virgule
    T // le paramètre de modèle T est dans la portée
    N = 0
>
struct A
{
};

Le locus d'une définition de concept se situe immédiatement après le nom du concept, mais les définitions de concept ne peuvent pas faire référence au nom du concept en cours de déclaration.

(depuis C++20)

Le locus d'une définition d'espace de noms nommée se situe immédiatement après le nom de l'espace de noms.
