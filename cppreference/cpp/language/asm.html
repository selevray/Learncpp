Déclaration asm

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

asm-declaration permet d'intégrer du code source en langage assembleur dans un programme C++. Cette déclaration est à support conditionnel et *(depuis C++11)*définie par l'implémentation, ce qui signifie qu'elle peut ne pas être présente et, même lorsqu'elle est fournie par l'implémentation, *(depuis C++11)*elle n'a pas de signification fixe.

Syntaxe

| | | | attr ﻿*(facultatif)* asm ( string-literal ) ; | | (jusqu'à C++26) | | | attr ﻿*(facultatif)* asm ( balanced-token-seq ) ; | | (depuis C++26) | |

  • attr — (depuis C++11) un nombre quelconque d'attributs
  • string-literal — identique à celui de littéral de chaîne, y compris les littéraux de chaîne bruts
  • balanced-token-seq — une suite de jetons où parenthèses, crochets et accolades sont équilibrés ; toute restriction sur balanced-token-seq et sa signification est définie par l'implémentation

Explication

balanced-token-seq est généralement un littéral de chaîne représentant un court programme écrit en langage assembleur, exécuté à chaque exécution de cette déclaration. Les différents compilateurs C++ ont des règles très variables pour les asm-declarations et des conventions différentes pour l'interaction avec le code C++ environnant.

Comme les autres déclarations de bloc, cette déclaration peut apparaître à l'intérieur d'un bloc (corps de fonction ou autre instruction composée), et, comme toutes les autres déclarations, elle peut aussi apparaître en dehors d'un bloc.

Exemple

Démontre deux formes de syntaxe d'assembleur en ligne proposées par les compilateurs GCC/Clang. Ce programme ne fonctionne correctement que sur la plateforme x86_64 sous Linux.

#include <iostream>

extern "C" int func(int x);
// la définition de func est écrite en langage assembleur
// un littéral de chaîne brute pourrait être très utile
asm(R"(
.globl func
    .type func, @function
    func:
    .cfi_startproc
    movl %edi, %eax /* x is in RDI, see x86-64 calling convention */
    addl $1, %eax
    ret
    .cfi_endproc
)");

int main()
{
    int n = func(0110);
    // auparavant assembleur en ligne non standard, rendu conforme par P2361R6
    asm ("leal (%0,%0,4),%0"
         : "=r" (n)
         : "0" (n));
    std::cout << "73*5 = " << n << std::endl; // le flush est intentionnel

    // assembleur en ligne standard
    asm ("movq $60, %rax\n" // le numéro de l'appel système exit sous Linux
         "movq $2,  %rdi\n" // ce programme renvoie 2
         "syscall");
}

Output:

73*5 = 365
