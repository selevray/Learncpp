Classe abstraite

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Définit un type abstrait qui ne peut pas être instancié, mais qui peut être utilisé comme classe de base.

Syntaxe

Une fonction virtuelle pure est une fonction virtuelle dont le déclarateur a la syntaxe suivante :

| | | | declarator virt-specifier ﻿*(facultatif)* = 0 | | | |

Ici, la séquence = 0 est appelée pure-specifier, et apparaît soit immédiatement après le declarator, soit après le virt-specifier optionnel (override ou final).

pure-specifier ne peut pas apparaître dans la définition d'une fonction membre ni dans une déclaration friend.

struct Base
{
    virtual int g();
    virtual ~Base() {}
};

struct A : Base
{
    // OK : déclare trois fonctions membres virtuelles, dont deux sont pures
    virtual int f() = 0, g() override = 0, h();

    // OK : le destructeur peut aussi être pur
    ~A() = 0;

    // Erreur : spécificateur pur sur une définition de fonction
    virtual int b() = 0 {}
};

Une classe abstraite est une classe qui définit ou hérite d'au moins une fonction dont le redéfinisseur final est virtuel pur.

Explication

Les classes abstraites servent à représenter des concepts généraux (par exemple Shape, Animal), qui peuvent être utilisés comme classes de base pour des classes concrètes (par exemple Circle, Dog).

Aucun objet d'une classe abstraite ne peut être créé (sauf les sous-objets de base d'une classe qui en dérive), et aucun membre de données non statique dont le type est une classe abstraite ne peut être déclaré.

Les types abstraits ne peuvent pas être utilisés comme types de paramètres, comme types de retour de fonction, ni comme type d'une conversion explicite (notez que cela est vérifié au point de définition et d'appel de fonction, puisqu'au point de déclaration de la fonction les types de paramètres et de retour peuvent être incomplets).

Des pointeurs et des références vers une classe abstraite peuvent être déclarés.

struct Abstract
{
    virtual void f() = 0;  // virtuelle pure
}; // « Abstract » est abstraite

struct Concrete : Abstract
{
    void f() override {}   // virtuelle non pure
    virtual void g();      // virtuelle non pure
}; // « Concrete » est non abstraite

struct Abstract2 : Concrete
{
    void g() override = 0; // redéfinition virtuelle pure
}; // « Abstract2 » est abstraite

int main()
{
    // Abstract a;   // Erreur : classe abstraite
    Concrete b;      // OK
    Abstract& a = b; // OK pour référencer la base abstraite
    a.f();           // appel virtuel dispatché vers Concrete::f()
    // Abstract2 a2; // Erreur : classe abstraite (le redéfinisseur final de g() est pur)
}

La définition d'une fonction virtuelle pure peut être fournie (et doit l'être si la fonction virtuelle pure est le destructeur) : les fonctions membres de la classe dérivée peuvent appeler librement la fonction virtuelle pure de la base abstraite en utilisant un identifiant de fonction qualifié. Cette définition doit être fournie en dehors du corps de la classe (la syntaxe d'une déclaration de fonction ne permet pas à la fois le spécificateur pur = 0 et un corps de fonction).

Effectuer un appel virtuel vers une fonction virtuelle pure depuis un constructeur ou le destructeur de la classe abstraite est un comportement indéfini (qu'elle ait une définition ou non).

struct Abstract
{
    virtual void f() = 0; // virtuelle pure
    virtual void g() {}   // virtuelle non pure

    ~Abstract()
    {
        g();           // OK : appelle Abstract::g()
        // f();        // comportement indéfini
        Abstract::f(); // OK : appel non virtuel
    }
};

// définition de la fonction virtuelle pure
void Abstract::f()
{
    std::cout << "A::f()\n";
}

struct Concrete : Abstract
{
    void f() override
    {
        Abstract::f(); // OK : appelle la fonction virtuelle pure
    }

    void g() override {}

    ~Concrete()
    {
        g(); // OK : appelle Concrete::g()
        f(); // OK : appelle Concrete::f()
    }
};
