Déclaration de tableau

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Déclare un objet de type tableau.

Syntaxe

Une déclaration de tableau est toute déclaration simple dont le déclarateur a la forme

| | | | noptr-declarator [expr ﻿*(optionnel)] attr ﻿(optionnel)* | | | |

  • noptr-declarator — tout declarator valide, mais s'il commence par *, & ou &&, il doit être entouré de parenthèses (sinon tout le déclarateur est traité comme un déclarateur de pointeur ou un déclarateur de référence).
  • expr — [une expression constante intégrale (jusqu'à C++14) | une expression constante convertie de type std::size_t (depuis C++14)], qui s'évalue à une valeur strictement supérieure à zéro
  • attr — (depuis C++11) liste d'attributs

Une déclaration de la forme T a[N]; déclare a comme un objet tableau constitué de N objets de type T alloués de manière contiguë. Les éléments d'un tableau sont numérotés 0, …, N - 1, et peuvent être accédés avec l'opérateur d'indexation [], comme dans a[0], …, a[N - 1].

Les tableaux peuvent être construits à partir de tout type fondamental (sauf void), de pointeurs, de pointeurs vers membres, de classes, d'énumérations, ou d'autres tableaux de borne connue (on parle alors de tableau multidimensionnel). En d'autres termes, seuls les types objets, à l'exception des types tableaux de borne inconnue, peuvent être types d'éléments de tableaux. Les types tableaux dont le type d'élément est incomplet sont également des types incomplets.

Le spécificateur éventuellement contraint (depuis C++20) auto peut être utilisé comme type d'élément de tableau dans la déclaration d'un pointeur ou d'une référence vers un tableau, ce qui déduit le type d'élément à partir de l'initialiseurou de l'argument de fonction (depuis C++14), par exemple auto (*p)[42] = &a; est valide si a est une lvalue de type int[42].

(depuis C++11)

Il n'existe ni tableaux de références ni tableaux de fonctions.

Appliquer des qualificateurs cv à un type tableau (par typedef ou manipulation de types de modèles) applique les qualificateurs au type d'élément, mais tout type tableau dont les éléments sont de type qualifié cv est considéré comme ayant la même qualification cv.

// a et b ont le même type qualifié const « tableau de 5 const char »

typedef const char CC;
CC a[5] = {};

typedef char CA[5];
const CA b = {};

Utilisé avec une expression new[], la taille d'un tableau peut être nulle ; un tel tableau n'a aucun élément :

int* p = new int[0]; // accéder à p[0] ou *p est un comportement indéfini
delete[] p; // nettoyage toujours requis

Affectation

Les objets de type tableau ne peuvent pas être modifiés dans leur ensemble : bien qu'ils soient des lvalues (on peut par exemple prendre l'adresse d'un tableau), ils ne peuvent pas figurer à gauche d'un opérateur d'affectation :

int a[3] = {1, 2, 3}, b[3] = {4, 5, 6};
int (*p)[3] = &a; // correct : l'adresse de a peut être prise
a = b;            // erreur : a est un tableau

struct { int c[3]; } s1, s2 = {3, 4, 5};
s1 = s2; // correct : opérateur d'affectation par copie implicitement défini
         // peut affecter des membres de type tableau

Conversion tableau vers pointeur

Il existe une conversion implicite des lvalues et rvalues de type tableau vers des rvalues de type pointeur : elle construit un pointeur vers le premier élément du tableau. Cette conversion s'applique chaque fois que des tableaux apparaissent dans un contexte où l'on attend des pointeurs et non des tableaux :

#include <iostream>
#include <iterator>
#include <numeric>

void g(int (&a)[3])
{
    std::cout << a[0] << '\n';
}

void f(int* p)
{
    std::cout << *p << '\n';
}

int main()
{
    int a[3] = {1, 2, 3};
    int* p = a;

    std::cout << sizeof a << '\n'  // affiche la taille du tableau
              << sizeof p << '\n'; // affiche la taille d'un pointeur

    // là où les tableaux sont acceptés mais pas les pointeurs, seuls les tableaux peuvent être utilisés
    g(a); // correct : la fonction prend un tableau par référence
//  g(p); // erreur

    for (int n : a)            // correct : les tableaux peuvent être utilisés dans les boucles for sur intervalle
        std::cout << n << ' '; // affiche les éléments du tableau
//  for (int n : p)            // erreur
//      std::cout << n << ' ';

    std::iota(std::begin(a), std::end(a), 7); // correct : begin et end acceptent les tableaux
//  std::iota(std::begin(p), std::end(p), 7); // erreur

    // là où les pointeurs sont acceptés mais pas les tableaux, les deux peuvent être utilisés :
    f(a); // correct : la fonction prend un pointeur
    f(p); // correct : la fonction prend un pointeur

    std::cout << *a << '\n' // affiche le premier élément
              << *p << '\n' // same
              << *(a + 1) << ' ' << a[1] << '\n'  // affiche le second élément
              << *(p + 1) << ' ' << p[1] << '\n'; // same
}

Tableaux multidimensionnels

Lorsque le type d'élément d'un tableau est lui-même un tableau, on dit que le tableau est multidimensionnel :

// tableau de 2 tableaux de 3 int chacun
int a[2][3] = {{1, 2, 3},  // peut être vu comme une matrice 2 × 3
               {4, 5, 6}}; // avec disposition par lignes (row-major)

Notez que lorsque la conversion tableau vers pointeur est appliquée, un tableau multidimensionnel est converti en pointeur vers son premier élément (par exemple un pointeur vers sa première ligne ou vers son premier plan) : la conversion tableau vers pointeur n'est appliquée qu'une seule fois.

int a[2];            // tableau de 2 int
int* p1 = a;         // a se convertit en pointeur vers le premier élément de a

int b[2][3];         // tableau de 2 tableaux de 3 int
// int** p2 = b;     // erreur : b ne se convertit pas en int**
int (*p2)[3] = b;    // b se convertit en pointeur vers la première ligne de 3 éléments de b

int c[2][3][4];      // tableau de 2 tableaux de 3 tableaux de 4 int
// int*** p3 = c;    // erreur : c ne se convertit pas en int***
int (*p3)[3][4] = c; // c se convertit en pointeur vers le premier plan de 3 × 4 éléments de c

Tableaux de borne inconnue

Si expr est omis dans la déclaration d'un tableau, le type déclaré est « tableau de borne inconnue de T », qui est une sorte de type incomplet, sauf lorsqu'il est utilisé dans une déclaration avec un initialiseur d'agrégat :

extern int x[];      // le type de x est « tableau de borne inconnue de int »
int a[] = {1, 2, 3}; // le type de a est « tableau de 3 int »

Comme les éléments d'un tableau ne peuvent pas être des tableaux de borne inconnue, les tableaux multidimensionnels ne peuvent pas avoir une borne inconnue dans une dimension autre que la première :

extern int a[][2]; // correct : tableau de borne inconnue de tableaux de 2 int
extern int b[2][]; // erreur : le tableau a un type d'élément incomplet

S'il existe une déclaration antérieure de l'entité dans la même portée où la borne a été spécifiée, une borne de tableau omise est considérée comme identique à celle de cette déclaration antérieure, et de même pour la définition d'un membre donnée statique d'une classe :

extern int x[10];
struct S
{
    static int y[10];
};

int x[];               // OK : la borne est 10
int S::y[];            // OK : la borne est 10

void f()
{
    extern int x[];
    int i = sizeof(x); // erreur : type objet incomplet
}

Des références et des pointeurs vers des tableaux de borne inconnue peuvent être formés, [mais ne peuvent pas (jusqu'à C++20) | et le peuvent (depuis C++20)] être initialisés ou affectés à partir de tableaux et de pointeurs vers des tableaux de borne connue. Notez qu'en langage C, les pointeurs vers des tableaux de borne inconnue sont compatibles avec les pointeurs vers des tableaux de borne connue, et sont donc convertibles et affectables dans les deux sens.

extern int a1[];

int (&r1)[] = a1;  // okay
int (*p1)[] = &a1; // okay
int (*q)[2] = &a1; // erreur (mais correct en C)

int a2[] = {1, 2, 3};
int (&r2)[] = a2;  // correct (depuis C++20)
int (*p2)[] = &a2; // correct (depuis C++20)

Les pointeurs vers des tableaux de borne inconnue ne peuvent pas intervenir dans l'arithmétique des pointeurs ni être utilisés à gauche de l'opérateur d'indexation, mais ils peuvent être déréférencés.

Rvalues de tableau

Bien que les tableaux ne puissent pas être retournés par valeur depuis des fonctions et ne puissent pas être la cible de la plupart des expressions de conversion, des prvalues de tableaux peuvent être formées en utilisant un alias de type pour construire un tableau temporaire au moyen d'un cast fonctionnel avec initialisation par accolades.

Comme les prvalues de classe, les prvalues de tableau se convertissent en xvalues par matérialisation temporaire lorsqu'elles sont évaluées.

(depuis C++17)

Des xvalues de tableau peuvent être formées directement en accédant à un membre tableau d'une rvalue de classe, ou en utilisant std::move ou un autre transtypage ou appel de fonction qui renvoie une référence de rvalue.

#include <iostream>
#include <type_traits>
#include <utility>

void f(int (&&x)[2][3])
{
    std::cout << sizeof x << '\n';
}

struct X
{
    int i[2][3];
} x;

template<typename T>
using identity = T;

int main()
{
    std::cout << sizeof X().i << '\n';           // taille du tableau
    f(X().i);                                    // correct : se lie à une xvalue
//  f(x.i);                                      // erreur : impossible de se lier à une lvalue

    int a[2][3];
    f(std::move(a));                             // correct : se lie à une xvalue

    using arr_t = int[2][3];
    f(arr_t{});                                  // correct : se lie à une prvalue
    f(identity<int[][3]>{{1, 2, 3}, {4, 5, 6}}); // correct : se lie à une prvalue

}

Output:

24
24
24
24
24

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
CWG 393 C++98 un pointeur ou une référence vers un tableau de borne inconnue ne peut pas être un paramètre de fonction allowed
CWG 619 C++98 lorsqu'elle était omise, la borne d'un tableau ne pouvait pas être déduite d'une déclaration antérieure déduction autorisée
CWG 2099 C++98 la borne d'un membre donnée statique tableau ne pouvait pas être omise même si un initialiseur était fourni omission autorisée
CWG 2397 C++11 auto ne pouvait pas être utilisé comme type d'élément allowed
