Fonctions membres non statiques

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Une fonction membre non statique est une fonction déclarée dans une spécification de membres d'une classe sans spécificateur static ou friend (voir fonctions membres statiques et déclaration d'amitié pour l'effet de ces mots-clés).

class S
{
    int mf1(); // déclaration de fonction membre non statique
    void mf2() volatile, mf3() &&; // peut avoir des qualificateurs cv et/ou un qualificateur de référence
        // la déclaration ci-dessus est équivalente à deux déclarations distinctes :
        // void mf2() volatile;
        // void mf3() &&;

    int mf4() const { return data; } // peut être définie en ligne
    virtual void mf5() final; // peut être virtuelle, peut utiliser final/override
    S() : data(12) {} // les constructeurs sont également des fonctions membres
    int data;
};

int S::mf1() { return 7; } // si elle n'est pas définie en ligne, doit être définie dans l'espace de noms

Les constructeurs, destructeurs et fonctions de conversion utilisent des syntaxes particulières pour leurs déclarations. Les règles décrites sur cette page peuvent ne pas s'appliquer à ces fonctions. Voir leurs pages respectives pour plus de détails.

Une fonction membre à objet explicite est une fonction membre non statique ayant un paramètre d'objet explicite.

(depuis C++23)

Une fonction membre à objet implicite est une fonction membre non statique sans paramètre d'objet explicite (avant C++23, c'était le seul type de fonction membre non statique, et elle était donc désignée par « fonction membre non statique » dans la littérature).

Explication

Toutes les déclarations de fonctions sont autorisées, avec des éléments de syntaxe supplémentaires qui ne sont disponibles que pour les fonctions membres non statiques : pure-spécificateurs, qualificateurs cv, qualificateurs de référence, spécificateurs final et override (depuis C++11), et listes d'initialisation des membres.

Une fonction membre non statique de la classe X peut être appelée

  1. Pour un objet de type X en utilisant l'opérateur d'accès membre de classe

  2. Pour un objet d'une classe dérivée de X

  3. Directement depuis le corps d'une fonction membre de X

  4. Directement depuis le corps d'une fonction membre d'une classe dérivée de X

Appeler une fonction membre non statique de la classe X sur un objet qui n'est pas de type X, ou d'un type dérivé de X, provoque un comportement indéfini.

Dans le corps d'une fonction membre non statique de X, toute id-expression e (par exemple un identifiant) qui désigne un membre non statique non typé de X ou d'une classe de base de X est transformée en une expression d'accès membre (*this).e (sauf si elle fait déjà partie d'une expression d'accès membre). Cela ne se produit pas dans un contexte de définition de modèle, de sorte qu'un nom peut devoir être préfixé explicitement par this-> pour devenir dépendant.

struct S
{
    int n;
    void f();
};

void S::f()
{
    n = 1; // transformée en (*this).n = 1;
}

int main()
{
    S s1, s2;
    s1.f(); // modifie s1.n
}

Dans le corps d'une fonction membre non statique de X, tout unqualified-id qui désigne un membre statique, un énumérateur ou un type imbriqué de X ou d'une classe de base de X est transformé en l'id qualifié correspondant :

struct S
{
    static int n;
    void f();
};

void S::f()
{
    n = 1; // transformée en S::n = 1;
}

int main()
{
    S s1, s2;
    s1.f(); // modifie S::n
}

Fonctions membres avec qualificateurs cv

Une fonction membre à objet implicite peut être déclarée avec une séquence de qualificateur cv (const, volatile, ou une combinaison de const et volatile) ; cette séquence apparaît après la liste des paramètres dans la déclaration de fonction. Les fonctions ayant des séquences de qualificateurs cv différentes (ou aucune) ont des types différents et peuvent donc se surcharger mutuellement.

Dans le corps d'une fonction ayant une séquence de qualificateurs cv, *this est qualifié cv ; par exemple, dans une fonction membre avec qualificateur const, seules d'autres fonctions membres avec qualificateur const peuvent être appelées normalement. Une fonction membre sans qualificateur const peut tout de même être appelée si const_cast est appliqué ou via un chemin d'accès qui n'implique pas this.

#include <vector>

struct Array
{
    std::vector<int> data;
    Array(int sz) : data(sz) {}

    // fonction membre const
    int operator[](int idx) const
    {                     // le pointeur this a le type const Array*
        return data[idx]; // transformée en (*this).data[idx];
    }

    // fonction membre non const
    int& operator[](int idx)
    {                     // le pointeur this a le type Array*
        return data[idx]; // transformée en (*this).data[idx]
    }
};

int main()
{
    Array a(10);
    a[1] = 1;  // OK : le type de a[1] est int&
    const Array ca(10);
    ca[1] = 2; // Error : le type de ca[1] est int
}

Fonctions membres avec qualificateur de référence

Une fonction membre à objet implicite peut être déclarée sans qualificateur de référence, avec un qualificateur de référence lvalue (le jeton & après la liste des paramètres) ou un qualificateur de référence rvalue (le jeton && après la liste des paramètres). Lors de la résolution de surcharge, une fonction membre à objet implicite ayant une séquence de qualificateurs cv de la classe X est traitée comme suit :

  • aucun qualificateur de référence : le paramètre d'objet implicite a pour type référence lvalue vers X qualifié cv, et il est en outre autorisé à lier un argument d'objet implicite rvalue
  • qualificateur de référence lvalue : le paramètre d'objet implicite a pour type référence lvalue vers X qualifié cv
  • qualificateur de référence rvalue : le paramètre d'objet implicite a pour type référence rvalue vers X qualifié cv
#include <iostream>

struct S
{
    void f() &  { std::cout << "lvalue\n"; }
    void f() && { std::cout << "rvalue\n"; }
};

int main()
{
    S s;
    s.f();            // affiche "lvalue"
    std::move(s).f(); // affiche "rvalue"
    S().f();          // affiche "rvalue"
}

Remarque : contrairement à la qualification cv, la qualification de référence ne modifie pas les propriétés du pointeur this : dans une fonction à qualificateur de référence rvalue, *this reste une expression lvalue.

(depuis C++11)

Fonctions virtuelles et fonctions virtuelles pures

Une fonction membre non statique peut être déclarée virtuelle ou virtuelle pure. Voir fonctions virtuelles et classes abstraites pour plus de détails.

Fonctions membres à objet explicite

Pour une fonction membre non statique non virtuelle, non déclarée avec un qualificateur cv ou de référence, son premier paramètre, s'il ne s'agit pas d'un pack de paramètres de fonction, peut être un paramètre d'objet explicite (désigné par le mot-clé préfixé this) :

struct X
{
    void foo(this X const& self, int i); // équivalent à void foo(int i) const &;
//  void foo(int i) const &; // Error : déjà déclarée

    void bar(this X self, int i); // passage de l'objet par valeur : crée une copie de “*this”
};

Pour les modèles de fonctions membres, le paramètre d'objet explicite permet la déduction du type et de la catégorie de valeur ; cette fonctionnalité du langage est appelée « déduction de this » :

struct X
{
    template<typename Self>
    void foo(this Self&&, int);
};

struct D : X {};

void ex(X& x, D& d)
{
    x.foo(1);       // Self = X&
    move(x).foo(2); // Self = X
    d.foo(3);       // Self = D&
}

Cela permet de dédupliquer les fonctions membres const et non const, voir opérateur d'indexation de tableau pour un exemple.

De plus, le paramètre d'objet explicite se déduit vers le type dérivé, ce qui simplifie le CRTP :

// un trait CRTP
struct add_postfix_increment
{
    template<typename Self>
    auto operator++(this Self&& self, int)
    {
        auto tmp = self; // Self se déduit en « some_type »
        ++self;
        return tmp;
    }
};

struct some_type : add_postfix_increment
{
    some_type& operator++() { ... }
};

Dans le corps d'une fonction membre à objet explicite, le pointeur this ne peut pas être utilisé : tout accès membre doit passer par le premier paramètre, comme dans les fonctions membres statiques :

struct C
{
    void bar();

    void foo(this C c)
    {
        auto x = this; // erreur : pas de this
        bar();         // erreur : pas de this-> implicite
        c.bar();       // ok
    }
};

Un pointeur vers une fonction membre à objet explicite est un pointeur de fonction ordinaire, et non un pointeur vers membre :

struct Y
{
    int f(int, int) const&;
    int g(this Y const&, int, int);
};

auto pf = &Y::f;
pf(y, 1, 2);              // erreur : les pointeurs vers fonctions membres ne sont pas appelables
(y.*pf)(1, 2);            // ok
std::invoke(pf, y, 1, 2); // ok

auto pg = &Y::g;
pg(y, 3, 4);              // ok
(y.*pg)(3, 4);            // erreur : « pg » n'est pas un pointeur vers fonction membre
std::invoke(pg, y, 3, 4); // ok

(depuis C++23)

Fonctions membres spéciales

Certaines fonctions membres sont spéciales : dans certaines circonstances, elles sont définies par le compilateur même si l'utilisateur ne les a pas définies. Ce sont :

  • Constructeur par défaut
  • Constructeur de copie
  • Constructeur de déplacement

(depuis C++11)

  • Opérateur d'affectation par copie
  • Opérateur d'affectation par déplacement

(depuis C++11)

  • [Destructeur (jusqu'à C++20) | Destructeur prospectif (depuis C++20)]

Les fonctions membres spéciales ainsi que les opérateurs de comparaison (depuis C++20) sont les seules fonctions pouvant être mises par défaut, c'est-à-dire définies à l'aide de = default au lieu du corps de la fonction (voir leurs pages pour plus de détails).

Notes

Macro de test de fonctionnalité Valeur Std Fonctionnalité
__cpp_ref_qualifiers 200710L (C++11) Qualificateurs de référence
__cpp_explicit_this_parameter 202110L (C++23) paramètre d'objet explicite (déduction de this)

Exemple

#include <exception>
#include <iostream>
#include <string>
#include <utility>

struct S
{
    int data;

    // constructeur convertisseur simple (déclaration)
    S(int val);

    // constructeur explicite simple (déclaration)
    explicit S(std::string str);

    // fonction membre const (définition)
    virtual int getData() const { return data; }
};

// définition du constructeur
S::S(int val) : data(val)
{
    std::cout << "ctor1 called, data = " << data << '\n';
}

// ce constructeur a une clause catch
S::S(std::string str) try : data(std::stoi(str))
{
    std::cout << "ctor2 called, data = " << data << '\n';
}
catch(const std::exception&)
{
    std::cout << "ctor2 failed, string was '" << str << "'\n";
    throw; // la clause catch du constructeur devrait toujours relancer l'exception
}

struct D : S
{
    int data2;
    // constructeur avec un argument par défaut
    D(int v1, int v2 = 11) : S(v1), data2(v2) {}

    // fonction membre virtuelle
    int getData() const override { return data * data2; }

    // opérateur d'affectation réservé aux lvalues
    D& operator=(D other) &
    {
        std::swap(other.data, data);
        std::swap(other.data2, data2);
        return *this;
    }
};

int main()
{
    D d1 = 1;
    S s2("2");

    try
    {
        S s3("not a number");
    }
    catch(const std::exception&) {}

    std::cout << s2.getData() << '\n';

    D d2(3, 4);
    d2 = d1;   // OK : affectation vers une lvalue
//  D(5) = d1; // ERROR : aucune surcharge appropriée de operator=
}

Output:

ctor1 called, data = 1
ctor2 called, data = 2
ctor2 failed, string was 'not a number'
2
ctor1 called, data = 3
