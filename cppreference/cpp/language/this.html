Le pointeur this

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Syntaxe

| | | | this | | | |

L'expression this est une prvalue expression dont la valeur est l'adresse du paramètre objet implicite (objet sur lequel la fonction membre à objet implicite est appelée). Elle peut apparaître dans les contextes suivants :

  1. Dans le corps de toute fonction membre à objet implicite, y compris la liste d'initialisation des membres, et le corps d'expression lambda (depuis C++11).

  2. Dans la déclaration de toute fonction membre à objet implicite, n'importe où après la séquence de qualificateurs cv (optionnelle), y compris la spécification d'exceptionet le type de retour final (depuis C++11).

  1. Dans un initialiseur de membre par défaut.

  2. Dans la liste de capture d'une expression lambda.

(depuis C++11)

Explication

this ne peut être associé qu'à la classe englobante la plus interne de son emplacement, même si cet emplacement est invalide dans le contexte :

class Outer
{
    int a[sizeof(*this)];            // Erreur : pas à l'intérieur d'une fonction membre
    unsigned int sz = sizeof(*this); // OK : dans l'initialiseur de membre par défaut

    void f()
    {
        int b[sizeof(*this)];     // OK

        struct Inner
        {
            int c[sizeof(*this)]; // Erreur : pas à l'intérieur d'une fonction membre de Inner
                                  // « this » n'est pas associé à Outer
                                  // même s'il se trouve à l'intérieur d'une fonction membre de Outer
        };
    }
};

Le type de this dans une fonction membre de la classe X est X* (pointeur vers X). Si la fonction membre est déclarée avec une séquence de qualificateurs cv cv, le type de this est cv X* (pointeur vers X qualifié cv de manière identique). Comme les constructeurs et destructeurs ne peuvent pas être déclarés avec des qualificateurs cv, le type de this dans ceux-ci est toujours X*, même lors de la construction ou de la destruction d'un objet const.

Dans les modèles de classe, this est une expression dépendante, et un usage explicite de this-> peut servir à rendre dépendante une autre expression.

template<typename T>
struct B
{
    int var;
};

template<typename T>
struct D : B<T>
{
    D()
    {
        // var = 1;    // Erreur : « var » n'a pas été déclaré dans cette portée
        this->var = 1; // OK
    }
};

Pendant la construction d'un objet, si la valeur de l'objet ou de l'un de ses sous-objets est accédée via un glvalue non obtenu, directement ou indirectement, à partir du pointeur this du constructeur, la valeur de l'objet ou du sous-objet ainsi obtenue est non spécifiée. En d'autres termes, le pointeur this ne peut pas être aliasé dans un constructeur :

extern struct D d;

struct D
{
    D(int a) : a(a), b(d.a) {} // b(a) ou b(this->a) serait correct
    int a, b;
};

D d = D(1); // parce que b(d.a) n'a pas obtenu a via this, d.b est désormais non spécifié

Il est possible d'exécuter delete this; si le programme peut garantir que l'objet a été alloué par new ; cependant, cela rend invalide tout pointeur vers l'objet désalloué, y compris le pointeur this lui-même : après que delete this; est retourné, une telle fonction membre ne peut pas faire référence à un membre de la classe (puisque cela implique un déréférencement implicite de this) et aucune autre fonction membre ne peut être appelée.

Ceci peut être utilisé dans la fonction membre du pointeur intelligent à comptage de références (par exemple, std::shared_ptr) (depuis C++11) chargé de décrémenter le compteur de références lorsque la dernière référence à l'objet géré sort de sa portée.

class ref
{
    // ...
    void incRef() { ++mnRef; }
    void decRef() { if (--mnRef == 0) delete this; }
};

Mots-clés

this

Exemple

class T
{
    int x;

    void foo()
    {
        x = 6;       // identique à this->x = 6;
        this->x = 5; // utilisation explicite de this->
    }

    void foo() const
    {
    //  x = 7; // Erreur : *this est constant
    }

    void foo(int x) // le paramètre x masque le membre de même nom
    {
        this->x = x; // x non qualifié désigne le paramètre
                     // « this-> » est requis pour la désambiguïsation
    }

    int y;
    T(int x) : x(x),      // utilise le paramètre x pour initialiser le membre x
               y(this->x) // utilise le membre x pour initialiser le membre y
    {}

    T& operator=(const T& b)
    {
        x = b.x;
        return *this; // de nombreux opérateurs surchargés renvoient *this
    }
};

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
CWG 760 C++98 lorsque this est utilisé dans une classe imbriquée, il était non spécifié s'il est associé à la classe imbriquée ou à la classe englobante this est toujours associé à la classe imbriquée la plus interne, qu'il se trouve ou non dans une fonction membre non statique
CWG 2271 C++98 this pouvait être aliasé lors de la construction d'un objet non const l'aliasing est également interdit dans ce cas
CWG 2869 C++98 il n'était pas clair si this pouvait être utilisé dans une fonction membre statique d'une classe non associée rendu clair
