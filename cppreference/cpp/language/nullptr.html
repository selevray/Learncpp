nullptr, le littéral pointeur (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Syntaxe

| | | | nullptr | | | |

Explication

Le mot-clé nullptr désigne le littéral pointeur. C'est une prvalue de type std::nullptr_t. Il existe des conversions implicites de nullptr vers la valeur de pointeur nul de tout type de pointeur et de tout type de pointeur vers membre. Des conversions similaires existent pour toute constante de pointeur nul, qui comprend les valeurs de type std::nullptr_t ainsi que la macro NULL.

Mots-clés

nullptr

Exemple

Démontre que nullptr conserve la signification de constante de pointeur nul même s'il n'est plus un littéral.

#include <cstddef>
#include <iostream>

template<class T>
constexpr T clone(const T& t)
{
    return t;
}

void g(int*)
{
    std::cout << "Function g called\n";
}

int main()
{
    g(nullptr);        // Correct
    g(NULL);           // Correct
    g(0);              // Correct

    g(clone(nullptr)); // Correct
//  g(clone(NULL));    // ERREUR : un zéro non littéral ne peut pas être une constante de pointeur nul
//  g(clone(0));       // ERREUR : un zéro non littéral ne peut pas être une constante de pointeur nul
}

Output:

Function g called
Function g called
