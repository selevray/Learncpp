Déclarations

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les déclarations sont la manière dont les noms sont introduits (ou réintroduits) dans le programme C++. Toutes les déclarations ne déclarent pas réellement quelque chose, et chaque sorte d'entité est déclarée différemment. Les définitions sont des déclarations suffisantes pour utiliser l'entité identifiée par le nom.

Une déclaration est l'une des suivantes :

  • Définition de fonction
  • Déclaration de modèle (y compris spécialisation partielle de modèle)
  • Instanciation explicite de modèle
  • Spécialisation explicite de modèle
  • Définition d'espace de noms
  • Spécification de liaison
  • Déclaration d'attribut (attr ;)

(depuis C++11)

  • Déclaration vide (;)
  • Une déclaration de fonction sans decl-specifier-seq ﻿:

| | | | attr ﻿*(facultatif)* declarator ; | | | |

  • attr — (depuis C++11) suite de un nombre quelconque d'attributs

  • declarator — un déclarateur de fonction Cette déclaration doit déclarer un constructeur, un destructeur ou une fonction de conversion définie par l'utilisateur. Elle ne peut être utilisée que dans le cadre d'une déclaration de modèle, d'une spécialisation explicite ou d'une instanciation explicite.

  • block-declaration (une déclaration pouvant apparaître dans un bloc), qui, à son tour, peut être l'une des suivantes :

    • déclaration asm
  • déclaration d'alias de type

(depuis C++11)

  • définition d'alias d'espace de noms
  • déclaration using
  • directive using
  • déclaration using-enum

(depuis C++20)

  • static_assert déclaration
  • déclaration d'énumération opaque

(depuis C++11)

  • déclaration simple

Déclaration simple

Une déclaration simple est une instruction qui introduit, crée et initialise éventuellement un ou plusieurs identifiants, typiquement des variables.

| | | | decl-specifier-seq init-declarator-list ﻿*(facultatif)* ; | (1) | | | | attr decl-specifier-seq init-declarator-list; | (2) | | |

  • attr — (depuis C++11) suite de un nombre quelconque d'attributs
  • decl-specifier-seq — séquence de spécificateurs (voir ci-dessous)
  • init-declarator-list — liste de déclarateurs séparés par des virgules, avec des initialiseurs optionnels. init-declarator-list est facultatif lors de la déclaration d'une classe, d'une structure, d'une union ou d'une énumération nommée

Une déclaration de liaison structurée est également une déclaration simple. (depuis C++17)

Spécificateurs

Spécificateurs de déclaration (decl-specifier-seq) est une séquence des spécificateurs suivants séparés par des espaces, dans n'importe quel ordre :

  • le spécificateur typedef. S'il est présent, toute la déclaration est une déclaration typedef et chaque déclarateur introduit un nouveau nom de type, et non un objet ou une fonction.
  • spécificateurs de fonction (inline, virtual, explicit), uniquement autorisés dans les déclarations de fonctions.
  • le spécificateur inline est aussi autorisé dans les déclarations de variables.

(depuis C++17)

  • le spécificateur friend, autorisé dans les déclarations de classes et de fonctions.
  • le spécificateur constexpr, uniquement autorisé dans les définitions de variables, les déclarations de fonctions et de modèles de fonctions, et la déclaration de membres de données statiques de type littéral.

(depuis C++11)

  • le spécificateur consteval, uniquement autorisé dans les déclarations de fonctions et de modèles de fonctions.
  • le spécificateur constinit, uniquement autorisé dans la déclaration d'une variable à durée de stockage statique ou thread. Au plus un des spécificateurs constexpr, consteval et constinit peut apparaître dans un decl-specifier-seq.

(depuis C++20)

  • spécificateur de classe de stockage (register, (jusqu'à C++17) static, thread_local, (depuis C++11) extern, mutable). Un seul spécificateur de classe de stockage est autorisé, sauf que thread_local peut apparaître avec extern ou static (depuis C++11).
  • Spécificateurs de type (type-specifier-seq), une séquence de spécificateurs qui désigne un type. Le type de chaque entité introduite par la déclaration est ce type, éventuellement modifié par le déclarateur (voir ci-dessous). Cette séquence de spécificateurs est également utilisée par type-id. Seuls les spécificateurs suivants font partie de type-specifier-seq, dans n'importe quel ordre :
    • spécificateur de classe
    • spécificateur d'énumération
    • spécificateur de type simple
      • char, [char8_t, (depuis C++20) | char16_t, char32_t, (depuis C++11)] wchar_t, bool, short, int, long, signed, unsigned, float, double, void
  • auto
  • spécificateur decltype

(depuis C++11)

  • spécificateur d'indexation de paquet

(depuis C++26)

  • nom de classe déclaré précédemment (éventuellement qualifié)
  • nom d'énumération déclaré précédemment (éventuellement qualifié)
  • typedef-nameou alias de type (depuis C++11) déclaré précédemment (éventuellement qualifié)
  • nom de modèle avec arguments de modèle (éventuellement qualifié, éventuellement avec désambiguïsateur de modèle)
  • nom de modèle sans arguments de modèle (éventuellement qualifié) : voir déduction d'argument de modèle de classe

(depuis C++17)

  • spécificateur de type élaboré

    • le mot-clé class, struct, ou union, suivi de l'identifiant (optionnellement qualifié), précédemment défini comme le nom d'une classe.
    • le mot-clé class, struct, ou union, suivi du nom de modèle avec ses arguments de modèle (optionnellement qualifié, optionnellement en utilisant le désambiguïsateur template), précédemment défini comme le nom d'un modèle de classe.
    • le mot-clé enum suivi de l'identifiant (éventuellement qualifié), précédemment déclaré comme nom d'une énumération.

  • spécificateur typename

  • qualificateur cv un seul spécificateur de type est autorisé dans une decl-specifier-seq, avec les exceptions suivantes :

  • const peut être combiné avec tout spécificateur de type sauf lui-même.

  • volatile peut être combiné avec tout spécificateur de type sauf lui-même.

  • signed ou unsigned peut être combiné avec char, long, short ou int.

  • short ou long peut être combiné avec int.

  • long peut être combiné avec double.

  • long peut être combiné avec long.

(depuis C++11)

Les attributs peuvent apparaître dans decl-specifier-seq, auquel cas ils s'appliquent au type déterminé par les spécificateurs qui précèdent.

La répétition d'un spécificateur dans un decl-specifier-seq, comme const static const ou virtual inline virtual, est une erreur, sauf que long est autorisé à apparaître deux fois (depuis C++11).

Déclarateurs

init-declarator-list est une séquence séparée par des virgules d'un ou plusieurs init-declarators, qui ont la syntaxe suivante :

| | | | declarator initializer ﻿*(facultatif)* | (1) | | | | declarator requires-clause | (2) | (depuis C++20) | |

  • declarator — le déclarateur
  • initializer — initialiseur optionnel (sauf lorsque requis, par exemple lors de l'initialisation de références ou d'objets const). Voir Initialisation pour plus de détails.
  • requires-clause — une clause requires, qui ajoute une contrainte à une déclaration de fonction

Chaque init-declarator dans une séquence init-declarator S D1, D2, D3; est traité comme s'il s'agissait d'une déclaration autonome avec les mêmes spécificateurs : S D1; S D2; S D3;.

Chaque déclarateur introduit exactement un objet, une référence, une fonction ou (pour les déclarations typedef) un alias de type, dont le type est fourni par decl-specifier-seq et éventuellement modifié par des opérateurs tels que & (référence vers) ou [] (tableau de) ou () (fonction retournant) dans le déclarateur. Ces opérateurs peuvent être appliqués récursivement, comme indiqué ci-dessous.

Un declarator est l'un des suivants :

| | | | unqualified-id attr ﻿*(facultatif)* | (1) | | | | qualified-id attr ﻿*(facultatif)* | (2) | | | | ... identifier attr ﻿*(facultatif)* | (3) | (depuis C++11) | | | * attr ﻿*(optionnel)* cv ﻿*(optionnel)* declarator | (4) | | | | nested-name-specifier * attr ﻿*(optionnel)* cv ﻿*(optionnel)* declarator | (5) | | | | & attr ﻿*(facultatif)* declarator | (6) | | | | && attr ﻿*(facultatif)* declarator | (7) | (depuis C++11) | | | noptr-declarator [ constexpr ﻿*(optionnel)* ] attr ﻿*(optionnel)* | (8) | | | | noptr-declarator ( parameter-list ) cv ﻿*(optionnel)* ref ﻿ ﻿*(optionnel)* except ﻿*(optionnel)* attr ﻿*(optionnel)* | (9) | | |

  1. Le nom qui est déclaré.

  2. Un déclarateur qui utilise un identifiant qualifié (qualified-id) définit ou redéclare un membre d'espace de noms ou un membre de classe déclaré précédemment.

  3. Pack de paramètres, n'apparaît que dans les déclarations de paramètres.

  4. Déclarateur de pointeur : la déclaration S * D; déclare D comme un pointeur vers le type déterminé par decl-specifier-seq S.

  5. Déclaration de pointeur vers membre : la déclaration S C::* D; déclare D comme un pointeur vers membre de C de type déterminé par decl-specifier-seq S. nested-name-specifier est une séquence de noms et d'opérateurs de résolution de portée ::

  6. Déclarateur de référence lvalue : la déclaration S & D; déclare D comme une référence lvalue vers le type déterminé par decl-specifier-seq S.

  7. Déclarateur de référence rvalue : la déclaration S && D; déclare D comme une référence rvalue vers le type déterminé par decl-specifier-seq S.

  8. Déclarateur de tableau. noptr-declarator tout déclarateur valide, mais s'il commence par *, &, ou &&, il doit être entouré de parenthèses.

  9. Déclarateur de fonction. noptr-declarator tout déclarateur valide, mais s'il commence par *, &, ou &&, il doit être entouré de parenthèses. Il peut se terminer par le type de retour final optionnel. (depuis C++11)

Dans tous les cas, attr est une séquence optionnelle d'attributs. Lorsqu'il apparaît immédiatement après l'identifiant, il s'applique à l'objet déclaré.

(depuis C++11)

cv est une séquence de qualificateurs const et volatile, où chaque qualificateur peut apparaître au plus une fois dans la séquence.

Notes

Lorsqu'un block-declaration apparaît à l'intérieur d'un bloc, et qu'un identifiant introduit par une déclaration a été déclaré précédemment dans un bloc externe, la déclaration externe est masquée jusqu'à la fin du bloc.

Si une déclaration introduit une variable à durée de stockage automatique, elle est initialisée lorsque son instruction de déclaration est exécutée. Toutes les variables automatiques déclarées dans un bloc sont détruites à la sortie du bloc (quelle que soit la manière dont le bloc est quitté : par une exception, un goto, ou en atteignant sa fin), dans l'ordre inverse de leur ordre d'initialisation.

Exemple

Remarque : cet exemple montre comment certaines déclarations complexes sont analysées selon la grammaire du langage. D'autres mnémoniques populaires sont : la règle en spirale, lecture de l'intérieur vers l'extérieur, et la déclaration reflète l'utilisation. Il existe aussi un analyseur automatique à <https://cdecl.org>.

#include <type_traits>

struct S
{
    int member;
    // decl-specifier-seq est « int »
    // le déclarateur est « member »
} obj, *pObj(&obj);
// decl-specifier-seq est « struct S { int member; } »
// le déclarateur « obj » déclare un objet de type S
// le déclarateur « *pObj » déclare un pointeur vers S,
//     et l'initialiseur « (&obj) » l'initialise

int i = 1, *p = nullptr, f(), (*pf)(double);
// decl-specifier-seq est « int »
// le déclarateur « i » déclare une variable de type int,
//     et l'initialiseur « = 1 » l'initialise
// le déclarateur « *p » déclare une variable de type int*,
//     et l'initialiseur « = nullptr » l'initialise
// le déclarateur « f() » déclare (mais ne définit pas)
//     une fonction ne prenant aucun argument et retournant int
// le déclarateur « (*pf)(double) » déclare un pointeur vers fonction
//     prenant double et retournant int

int (*(*var1)(double))[3] = nullptr;
// decl-specifier-seq est « int »
// le déclarateur est « (*(*var1)(double))[3] »
// l'initialiseur est « = nullptr »

// 1. le déclarateur « (*(*var1)(double))[3] » est un déclarateur de tableau :
//    Le type déclaré est : « (*(*var1)(double)) » tableau de 3 éléments
// 2. le déclarateur « (*(*var1)(double)) » est un déclarateur de pointeur :
//    Le type déclaré est : « (*var1)(double) » pointeur vers tableau de 3 éléments
// 3. le déclarateur « (*var1)(double) » est un déclarateur de fonction :
//    Le type déclaré est : « (*var1) » fonction prenant « (double) »,
//    retournant un pointeur vers tableau de 3 éléments.
// 4. le déclarateur « (*var1) » est un déclarateur de pointeur :
//    Le type déclaré est : « var1 » pointeur vers fonction prenant « (double) »,
//    retournant un pointeur vers tableau de 3 éléments.
// 5. le déclarateur « var1 » est un identifiant.
// Cette déclaration déclare l'objet var1 de type « pointeur vers fonction
// prenant double et retournant pointeur vers tableau de 3 éléments de type int »
// L'initialiseur « = nullptr » fournit la valeur initiale de ce pointeur.

// Syntaxe alternative C++11 :
auto (*var2)(double) -> int (*)[3] = nullptr;
// decl-specifier-seq est « auto »
// le déclarateur est "(*var2)(double) -> int (*)[3]"
// l'initialiseur est « = nullptr »

// 1. le déclarateur "(*var2)(double) -> int (*)[3]" est un déclarateur de fonction :
//    Le type déclaré est : "(*var2)" fonction prenant "(double)", renvoyant "int (*)[3]"
// ...

int main()
{
    static_assert(std::is_same_v<decltype(var1), decltype(var2)>);
}
