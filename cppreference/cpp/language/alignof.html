opérateur alignof (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Interroge les exigences d'alignement d'un type.

Syntaxe

| | | | alignof( type-id ) | | | |

Renvoie une valeur de type std::size_t.

Explication

Renvoie l'alignement, en octets, requis pour toute instance du type indiqué par type-id, qui est soit un type objet complet, un type tableau dont le type d'élément est complet, soit un type référence vers l'un de ces types.

Si le type est un type référence, l'opérateur renvoie l'alignement du type référencé ; si le type est un type tableau, l'exigence d'alignement du type d'élément est renvoyée.

Notes

Voir alignement pour la signification et les propriétés de la valeur renvoyée par alignof.

Mots-clés

alignof

Exemple

#include <iostream>

struct Foo
{
    int   i;
    float f;
    char  c;
};

// Remarque : alignas(alignof(long double)) ci-dessous peut être
// simplifié en alignas(long double) si souhaité.
struct alignas(alignof(long double)) Foo2
{
    // placez votre définition ici
};

struct Empty {};

struct alignas(64) Empty64 {};

#define SHOW(expr) std::cout << #expr << " = " << (expr) << '\n'

int main()
{
    SHOW(alignof(char));
    SHOW(alignof(int*));
    SHOW(alignof(Foo));
    SHOW(alignof(Foo2));
    SHOW(alignof(Empty));
    SHOW(alignof(Empty64));
}

Sortie possible :

alignof(char) = 1
alignof(int*) = 8
alignof(Foo) = 4
alignof(Foo2) = 16
alignof(Empty) = 1
alignof(Empty64) = 64
