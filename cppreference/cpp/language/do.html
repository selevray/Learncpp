boucle do-while

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Exécute de façon conditionnelle une instruction de manière répétée (au moins une fois).

Syntaxe

| | | | attr ﻿*(facultatif)* do statement while ( expression ); | | | |

  • attr — (depuis C++11) un nombre quelconque d'attributs
  • expression — une expression
  • statement — une instruction (typiquement une instruction composée)

Explication

Lorsque le flot de contrôle atteint une instruction do, son statement sera exécuté inconditionnellement.

À chaque fin d'exécution de statement, expression est évalué et converti contextuellement en bool. Si le résultat est true, statement sera de nouveau exécuté.

Si la boucle doit être interrompue à l'intérieur de statement, une instruction break peut être utilisée comme instruction de terminaison.

Si l'itération courante doit être interrompue à l'intérieur de statement, une instruction continue peut être utilisée comme raccourci.

Notes

Dans le cadre de la garantie de progression du C++, le comportement est indéfini si une bouclequi n'est pas une boucle infinie triviale (depuis C++26) sans comportement observable ne se termine pas. Les compilateurs sont autorisés à supprimer de telles boucles.

Mots-clés

do, while

Exemple

#include <algorithm>
#include <iostream>
#include <string>

int main()
{
    int j = 2;
    do // le bloc composé est le corps de la boucle
    {
        j += 2;
        std::cout << j << ' ';
    }
    while (j < 9);
    std::cout << '\n';

    // situation courante dans laquelle la boucle do-while est utilisée
    std::string s = "aba";
    std::sort(s.begin(), s.end());

    do std::cout << s << '\n'; // l'instruction d'expression est le corps de la boucle
    while (std::next_permutation(s.begin(), s.end()));
}

Output:

4 6 8 10
aab
aba
baa
