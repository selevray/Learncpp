Littéral à virgule flottante

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un littéral à virgule flottante définit une constante à la compilation dont la valeur est spécifiée dans le fichier source.

Syntaxe

| | | | digit-sequence decimal-exponent suffix ﻿*(facultatif)* | (1) | | | | digit-sequence . decimal-exponent ﻿*(optional)* suffix ﻿*(optional)* | (2) | | | | digit-sequence ﻿*(optional)* . digit-sequence decimal-exponent ﻿*(optional)* suffix ﻿*(optional)* | (3) | | | | 0x | 0X hex-digit-sequence hex-exponent suffix ﻿*(facultatif)* | (4) | (depuis C++17) | | | 0x | 0X hex-digit-sequence . hex-exponent suffix ﻿*(facultatif)* | (5) | (depuis C++17) | | | 0x | 0X hex-digit-sequence ﻿*(optional)* . hex-digit-sequence hex-exponent suffix ﻿*(optional)* | (6) | (depuis C++17) | |

  1. digit-sequence représentant un nombre entier sans séparateur décimal ; dans ce cas l'exposant n'est pas optionnel : 1e10, 1e-5L.

  2. digit-sequence représentant un nombre entier avec séparateur décimal ; dans ce cas l'exposant est optionnel : 1., 1.e-2.

  3. digit-sequence représentant un nombre fractionnaire. L'exposant est optionnel : 3.14, .1f, 0.1e-1L.

  4. Hexadécimal digit-sequence représentant un nombre entier sans séparateur de base. L'exposant n'est jamais optionnel pour les littéraux à virgule flottante hexadécimaux : 0x1ffp10, 0X0p-1.

  5. Hexadécimal digit-sequence représentant un nombre entier avec séparateur de base. L'exposant n'est jamais optionnel pour les littéraux à virgule flottante hexadécimaux : 0x1.p0, 0xf.p-1.

  6. Hexadécimal digit-sequence représentant un nombre fractionnaire avec séparateur de base. L'exposant n'est jamais optionnel pour les littéraux à virgule flottante hexadécimaux : 0x0.123p-1, 0xa.bp10l.

decimal-exponent a la forme

| | | | e | E exponent-sign ﻿*(facultatif)* digit-sequence | | | |

hex-exponent a la forme

| | | | p | P exponent-sign ﻿*(facultatif)* digit-sequence | | (depuis C++17) | |

exponent-sign, s'il est présent, est soit + soit -

suffix, s'il est présent, est l'un de f, l, F, L, f16, f32, f64, f128, bf16, F16, F32, F64, F128, BF16 (depuis C++23). Le suffixe détermine le type du littéral à virgule flottante :

  • (aucun suffixe) définit double
  • f F définit float
  • l L définit long double
  • f16 F16 définit std::float16_t
  • f32 F32 définit std::float32_t
  • f64 F64 définit std::float64_t
  • f128 F128 définit std::float128_t
  • bf16 BF16 définit std::bfloat16_t

(depuis C++23)

Des guillemets simples facultatifs (') peuvent être insérés entre les chiffres comme séparateur ; ils sont ignorés lors de la détermination de la valeur du littéral.

(depuis C++14)

Explication

La notation scientifique décimale est utilisée, c'est-à-dire que la valeur du littéral à virgule flottante est la mantisse multipliée par 10 élevé à la puissance de decimal-exponent. Par exemple, le sens mathématique de 123e4 est 123×104.

Si le littéral à virgule flottante commence par la séquence de caractères 0x ou 0X, c'est un littéral à virgule flottante hexadécimal. Sinon, c'est un littéral à virgule flottante décimal.

Pour un littéral à virgule flottante hexadécimal, la mantisse est interprétée comme un nombre rationnel hexadécimal, et le digit-sequence de l'exposant est interprété comme la puissance entière (en décimal) de 2 par laquelle la mantisse doit être multipliée.

double d = 0x1.4p3;// hex fraction 1.4 (decimal 1.25) scaled by 23, that is 10.0

(depuis C++17)

Notes

Les littéraux à virgule flottante hexadécimaux ne faisaient pas partie de C++ avant C++17, bien qu'ils puissent être analysés et affichés par les fonctions d'E/S depuis C++11 : à la fois les flux d'E/S C++ lorsque std::hexfloat est activé et les flux d'E/S C : std::printf, std::scanf, etc. Voir std::strtof pour la description du format.

Exemple

#include <iomanip>
#include <iostream>
#include <limits>
#include <typeinfo>

#define OUT(x) '\n' << std::setw(16) << #x << x

int main()
{
    std::cout
        << "Literal" "\t" "Printed value" << std::left
        << OUT( 58.            ) // double
        << OUT( 4e2            ) // double
        << OUT( 123.456e-67    ) // double
        << OUT( 123.456e-67f   ) // float, tronqué à zéro
        << OUT( .1E4f          ) // float
        << OUT( 0x10.1p0       ) // double
        << OUT( 0x1p5          ) // double
        << OUT( 0x1e5          ) // littéral entier, non à virgule flottante
        << OUT( 3.14'15'92     ) // double, guillemets simples ignorés (depuis C++14)
        << OUT( 1.18e-4932l    ) // long double
        << std::setprecision(39)
        << OUT( 3.4028234e38f  ) // float
        << OUT( 3.4028234e38   ) // double
        << OUT( 3.4028234e38l  ) // long double
        << '\n';

    static_assert(3.4028234e38f == std::numeric_limits<float>::max());

    static_assert(3.4028234e38f ==  // se termine par 4
                  3.4028235e38f);   // se termine par 5

    static_assert(3.4028234e38 !=   // se termine par 4
                  3.4028235e38);    // se termine par 5

    // Les deux constantes à virgule flottante ci-dessous valent 3.4028234e38
    static_assert(3.4028234e38f !=  // un float (promu ensuite en double)
                  3.4028234e38);    // un double
}
