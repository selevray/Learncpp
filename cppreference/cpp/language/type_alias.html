Alias de type, modèle d'alias (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un alias de type est un nom qui désigne un type défini précédemment (similaire à typedef).

Un modèle d'alias est un nom qui désigne une famille de types.

Syntaxe

Les déclarations d'alias sont des déclarations de la syntaxe suivante :

using identifier attr ﻿*(facultatif)* = type-id ; | (1)

template < template-parameter-list >

using identifier attr ﻿*(facultatif)* = type-id ;

| (2)

template < template-parameter-list > requires constraint

using identifier attr ﻿*(facultatif)* = type-id ;

| (3) | (depuis C++20)

  • attr — séquence optionnelle d'un nombre quelconque d'attributs
  • identifier — le nom introduit par cette déclaration, qui devient soit un nom de type (1), soit un nom de modèle (2)
  • template-parameter-list — liste des paramètres de modèle, comme dans une déclaration de modèle
  • constraint — une expression de contrainte qui restreint les paramètres de modèle acceptés par ce modèle d'alias
  • type-id — déclarateur abstrait ou tout autre type-id valide (qui peut introduire un nouveau type, comme indiqué dans type-id). Le type-id ne peut pas faire référence directement ou indirectement à identifier. Notez que le point de déclaration de l'identifiant se situe au point-virgule suivant type-id.

Explication

  1. Une déclaration d'alias de type introduit un nom qui peut être utilisé comme synonyme du type désigné par type-id. Elle n'introduit pas de nouveau type et ne peut pas modifier la signification d'un nom de type existant. Il n'y a aucune différence entre une déclaration d'alias de type et une déclaration typedef. Cette déclaration peut apparaître en portée de bloc, en portée de classe ou en portée d'espace de noms.

  2. Un modèle d'alias est un modèle qui, lorsqu'il est spécialisé, équivaut au résultat de la substitution des arguments de modèle de l'alias aux paramètres de modèle dans type-id.

template<class T>
struct Alloc {};

template<class T>
using Vec = vector<T, Alloc<T>>; // le type-id est vector<T, Alloc<T>>

Vec<int> v; // Vec<int> est identique à vector<int, Alloc<int>>

Lorsque le résultat de la spécialisation d'un modèle d'alias est un template-id dépendant, les substitutions ultérieures s'appliquent à ce template-id :

template<typename...>
using void_t = void;

template<typename T>
void_t<typename T::foo> f();

f<int>(); // erreur, int n'a pas de type imbriqué foo

Le type produit par la spécialisation d'un modèle d'alias ne doit pas utiliser directement ou indirectement son propre type :

template<class T>
struct A;

template<class T>
using B = typename A<T>::U; // le type-id est A<T>::U

template<class T>
struct A { typedef B<T> U; };

B<short> b; // erreur : B<short> utilise son propre type via A<short>::U

Les modèles d'alias ne sont jamais déduits par la déduction d'arguments de modèle lors de la déduction d'un paramètre de modèle template.

Il n'est pas possible de spécialiser partiellement ni de spécialiser explicitement un modèle d'alias.

Comme toute déclaration de modèle, un modèle d'alias ne peut être déclaré qu'en portée de classe ou en portée d'espace de noms.

Le type d'une expression lambda apparaissant dans une déclaration de modèle d'alias est différent entre les instanciations de ce modèle, même lorsque l'expression lambda n'est pas dépendante.

template<class T>
using A = decltype([] {}); // A<int> et A<char> désignent des types de fermeture différents

(depuis C++20)

Mots-clés

Exemple

#include <iostream>
#include <string>
#include <type_traits>
#include <typeinfo>

// alias de type, identique à
// typedef std::ios_base::fmtflags flags;
using flags = std::ios_base::fmtflags;
// le nom 'flags' désigne désormais un type :
flags fl = std::ios_base::dec;

// alias de type, identique à
// typedef void (*func)(int, int);
using func = void (*) (int, int);

// le nom 'func' désigne désormais un pointeur vers fonction :
void example(int, int) {}
func f = example;

// modèle d'alias
template<class T>
using ptr = T*;
// le nom 'ptr<T>' est désormais un alias de pointeur vers T
ptr<int> x;

// alias de type utilisé pour masquer un paramètre de modèle
template<class CharT>
using mystring = std::basic_string<CharT, std::char_traits<CharT>>;

mystring<char> str;

// un alias de type peut introduire un nom de typedef membre
template<typename T>
struct Container { using value_type = T; };

// qui peut être utilisé en programmation générique
template<typename ContainerT>
void info(const ContainerT& c)
{
    typename ContainerT::value_type T;
    std::cout << "ContainerT is `" << typeid(decltype(c)).name() << "`\n"
                 "value_type is `" << typeid(T).name() << "`\n";
}

// alias de type utilisé pour simplifier la syntaxe de std::enable_if
template<typename T>
using Invoke = typename T::type;

template<typename Condition>
using EnableIf = Invoke<std::enable_if<Condition::value>>;

template<typename T, typename = EnableIf<std::is_polymorphic<T>>>
int fpoly_only(T) { return 1; }

struct S { virtual ~S() {} };

int main()
{
    Container<int> c;
    info(c); // Container::value_type vaudra int dans cette fonction
//  fpoly_only(c); // erreur : enable_if l'interdit
    S s;
    fpoly_only(s); // OK : enable_if autorise cela
}

Sortie possible :

ContainerT is `struct Container<int>`
value_type is `int`
