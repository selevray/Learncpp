Spécificateur de type élaboré

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les spécificateurs de type élaborés peuvent servir à désigner un nom de classe (class, struct ou union) déjà déclaré ou un nom d'énumération déjà déclaré, même si ce nom a été masqué par une déclaration de non-type. Ils peuvent aussi servir à déclarer de nouveaux noms de classes.

Syntaxe

| | | | class-key class-name | (1) | | | | enum enum-name | (2) | | | | class-key attr ﻿*(facultatif)* identifier ; | (3) | | |

  • class-key — l'un de class, struct, union
  • class-name — le nom d'un type classe déjà déclaré, éventuellement qualifié, ou un identifiant non précédemment déclaré comme nom de type
  • enum-name — le nom d'un type énumération déjà déclaré, éventuellement qualifié
  • attr — (depuis C++11) un nombre quelconque d'attributs

  1. Spécificateur de type élaboré pour un type classe.

  2. Spécificateur de type élaboré pour un type énumération.

  3. Une déclaration constituée uniquement d'un spécificateur de type élaboré déclare toujours un type classe nommé par identifier dans la portée qui contient la déclaration.

Déclaration d'énumération opaque ressemble à la forme (3), mais le type énumération est un type complet après une déclaration d'énumération opaque.

Explication

La forme (3) est un cas particulier de spécificateur de type élaboré, généralement appelé déclaration anticipée de classes ; pour la description de la forme (3), voir Déclaration anticipée. Ce qui suit ne s'applique qu'aux formes (1) et (2).

Le class-name ou enum-name dans le spécificateur de type élaboré peut être soit un simple identifiant, soit un qualified-id. Le nom est recherché à l'aide de la recherche de nom non qualifiée ou de la recherche de nom qualifiée, selon sa position. Mais dans les deux cas, les noms de non-type ne sont pas pris en compte.

class T
{
public:
    class U;
private:
    int U;
};

int main()
{
    int T;
    T t; // error: la variable locale T est trouvée
    class T t; // OK : trouve ::T, la variable locale T est ignorée
    T::U* u; // error: la recherche de T::U trouve le membre de données privé
    class T::U* u; // OK : le membre de données est ignoré
}

Si la recherche de nom ne trouve pas de nom de type déclaré précédemment, le spécificateur de type élaboré est introduit par class, struct ou union (c'est-à-dire pas par enum), et class-name est un identifiant non qualifié, alors le spécificateur de type élaboré est une déclaration de classe du nom de classe.

template<typename T>
struct Node
{
    struct Node* Next; // OK : la recherche de Node trouve le nom de classe injecté
    struct Data* Data; // OK : déclare le type Data dans la portée globale
                       // et déclare aussi le membre de données Data
    friend class ::List; // error : impossible d'introduire un nom qualifié
    enum Kind* kind; // error : impossible d'introduire une énumération
};

Data* p; // OK : la structure Data a été déclarée

Si le nom désigne un nom de typedef, un alias de type, un paramètre de type de modèle, ou une spécialisation d'alias de modèle, le programme est mal formé ; sinon le spécificateur de type élaboré introduit le nom dans la déclaration de la même manière qu'un spécificateur de type simple introduit son nom de type.

template<typename T>
class Node
{
    friend class T; // error : un paramètre de type ne peut pas apparaître dans un spécificateur de type élaboré ;
                    // notez que la déclaration similaire `friend T;` est OK.
};

class A {};
enum b { f, t };

int main()
{
    class A a; // OK : équivalent à 'A a;'
    enum b flag; // OK : équivalent à 'b flag;'
}

Le mot-clé class-key ou enum présent dans le spécificateur de type élaboré doit correspondre à la nature de la déclaration à laquelle le nom du spécificateur fait référence.

  • le mot-clé enum doit être utilisé pour désigner un type énumération (à portée ou non)
  • le mot-clé union class-key doit être utilisé pour désigner une union
  • soit le mot-clé class soit struct class-key doit être utilisé pour désigner un type classe qui n'est pas une union (les mots-clés class et struct sont interchangeables ici).
enum class E { a, b };
enum E x = E::a; // OK
enum class E y = E::b; // error : 'enum class' ne peut pas introduire un spécificateur de type élaboré

struct A {};
class A a; // OK

Utilisé comme argument de modèle, class T est un paramètre de modèle de type nommé T, et non un paramètre non-type sans nom dont le type T est introduit par un spécificateur de type élaboré.

Mots-clés

class, struct, union, enum
