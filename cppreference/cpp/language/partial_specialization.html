Spécialisation partielle de modèle

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Permet de personnaliser les modèles de classe et de variable (depuis C++14) pour une catégorie donnée d'arguments de modèle.

Syntaxe

| | | | template < parameter-list > class-key class-head-name < argument-list > declaration | (1) | | | | template < parameter-list > decl-specifier-seq declarator < argument-list > initializer ﻿*(facultatif)* | (2) | (depuis C++14) | |

où class-head-name identifie le nom d'un modèle de classeprécédemment déclaré et declarator identifie le nom d'un modèle de variable (depuis C++14) précédemment déclaré.

Une spécialisation partielle peut être déclarée dans toute portée où son modèle primaire peut être défini (qui peut être différente de la portée où le modèle primaire est défini ; comme avec une spécialisation hors classe d'un modèle membre). La spécialisation partielle doit apparaître après la déclaration du modèle non spécialisé.

Par exemple,

template<class T1, class T2, int I>
class A {};             // modèle primaire

template<class T, int I>
class A<T, T*, I> {};   // #1 : spécialisation partielle où T2 est un pointeur vers T1

template<class T, class T2, int I>
class A<T*, T2, I> {};  // #2 : spécialisation partielle où T1 est un pointeur

template<class T>
class A<int, T*, 5> {}; // #3 : spécialisation partielle où
                        //     T1 est int, I vaut 5, et T2 est un pointeur

template<class X, class T, int I>
class A<X, T*, I> {};   // #4 : spécialisation partielle où T2 est un pointeur

Parmi les exemples de spécialisations partielles de la bibliothèque standard figure std::unique_ptr, qui possède une spécialisation partielle pour les types tableaux.

La liste d'arguments

Les restrictions suivantes s'appliquent à argument-list d'une spécialisation partielle de modèle :

  1. La liste d'arguments ne peut pas être identique à la liste d'arguments non spécialisée (elle doit spécialiser quelque chose) :
template<class T1, class T2, int I> class B {};        // modèle primaire
template<class X, class Y, int N> class B<X, Y, N> {}; // error

De plus, la spécialisation doit être plus spécialisée que le modèle primaire

template<int N, typename T1, typename... Ts> struct B;
template<typename... Ts> struct B<0, Ts...> {}; // Erreur : n'est pas plus spécialisé

(depuis C++11)

  1. Les arguments par défaut ne peuvent pas apparaître dans la liste d'arguments

  2. Si un argument est un développement de paquet, il doit être le dernier argument de la liste

4)Les expressions d'arguments non typés peuvent utiliser des paramètres de modèle tant que le paramètre apparaît au moins une fois en dehors d'un contexte non déductible (notez que seuls clang et gcc 12 prennent actuellement en charge cette fonctionnalité) :

template<int I, int J> struct A {};
template<int I> struct A<I + 5, I * 2> {}; // erreur, I n'est pas déductible

template<int I, int J, int K> struct B {};
template<int I> struct B<I, I * 2, 2> {};  // OK : le premier paramètre est déductible
  1. Un argument de modèle non typé ne peut pas spécialiser un paramètre de modèle dont le type dépend d'un paramètre de la spécialisation :
template<class T, T t> struct C {}; // modèle primaire
template<class T> struct C<T, 1>;   // erreur : le type de l'argument 1 est T,
                                    // qui dépend du paramètre T

template<int X, int (*array_ptr)[X]> class B {}; // modèle primaire
int array[5];
template<int X> class B<X, &array> {}; // erreur : le type de l'argument &array est
                                       // int(*)[X], qui dépend du paramètre X

Recherche de noms

Les spécialisations partielles de modèle ne sont pas trouvées par recherche de nom. Seulement si le modèle primaire est trouvé par recherche de nom, ses spécialisations partielles sont prises en compte. En particulier, une déclaration using qui rend visible un modèle primaire rend également visibles ses spécialisations partielles :

namespace N
{
    template<class T1, class T2> class Z {}; // modèle primaire
}
using N::Z; // fait référence au modèle primaire

namespace N
{
    template<class T> class Z<T, T*> {};     // spécialisation partielle
}
Z<int, int*> z; // la recherche de nom trouve N::Z (le modèle primaire), la
                // spécialisation partielle avec T = int est alors utilisée

Ordre partiel

Lorsqu'un modèle de classe ou de variable (depuis C++14) est instancié, et que des spécialisations partielles sont disponibles, le compilateur doit décider si le modèle primaire sera utilisé ou l'une de ses spécialisations partielles.

  1. Si une seule spécialisation correspond aux arguments de modèle, cette spécialisation est utilisée

  2. Si plusieurs spécialisations correspondent, les règles d'ordre partiel sont utilisées pour déterminer laquelle est la plus spécialisée. La spécialisation la plus spécialisée est utilisée, si elle est unique (si elle ne l'est pas, le programme ne peut pas être compilé)

  3. Si aucune spécialisation ne correspond, le modèle primaire est utilisé

// étant donné le modèle A tel que défini ci-dessus
A<int, int, 1> a1;   // aucune spécialisation ne correspond, utilise le modèle primaire
A<int, int*, 1> a2;  // utilise la spécialisation partielle #1 (T = int, I = 1)
A<int, char*, 5> a3; // utilise la spécialisation partielle #3, (T = char)
A<int, char*, 1> a4; // utilise la spécialisation partielle #4, (X = int, T = char, I = 1)
A<int*, int*, 2> a5; // erreur : correspond à #2 (T = int, T2 = int*, I= 2)
                     //        correspond à #4 (X = int*, T = int, I = 2)
                     // aucune des deux n'est plus spécialisée que l'autre

Informellement, « A est plus spécialisé que B » signifie « A accepte un sous-ensemble des types que B accepte ».

Formellement, pour établir la relation plus spécialisé que entre des spécialisations partielles, chacune est d'abord convertie en un modèle de fonction fictif comme suit :

  • le premier modèle de fonction a les mêmes paramètres de modèle que la première spécialisation partielle et n'a qu'un seul paramètre de fonction, dont le type est une spécialisation de modèle de classe avec tous les arguments de modèle de la première spécialisation partielle
  • le second modèle de fonction a les mêmes paramètres de modèle que la seconde spécialisation partielle et n'a qu'un seul paramètre de fonction, dont le type est une spécialisation de modèle de classe avec tous les arguments de modèle de la seconde spécialisation partielle.

Les modèles de fonction sont ensuite classés comme pour la surcharge de modèles de fonction.

template<int I, int J, class T> struct X {}; // modèle primaire
template<int I, int J>          struct X<I, J, int>
{
    static const int s = 1;
}; // spécialisation partielle #1
// modèle de fonction fictif pour #1 est
// template<int I, int J> void f(X<I, J, int>); #A

template<int I>                 struct X<I, I, int>
{
    static const int s = 2;
}; // spécialisation partielle #2
// modèle de fonction fictif pour #2 est
// template<int I>        void f(X<I, I, int>); #B

int main()
{
    X<2, 2, int> x; // #1 et #2 correspondent tous deux
// ordonnancement partiel pour les modèles de fonction :
// #A à partir de #B : void(X<I, J, int>) à partir de void(X<U1, U1, int>) : déduction OK
// #B à partir de #A : void(X<I, I, int>) à partir de void(X<U1, U2, int>) : la déduction échoue
// #B est plus spécialisé
// #2 est la spécialisation qui est instanciée
    std::cout << x.s << '\n'; // prints 2
}

Membres des spécialisations partielles

La liste de paramètres de modèle et la liste d'arguments de modèle d'un membre d'une spécialisation partielle doivent correspondre à la liste de paramètres et à la liste d'arguments de la spécialisation partielle.

Tout comme pour les membres des modèles primaires, ils n'ont besoin d'être définis que s'ils sont utilisés dans le programme.

Les membres des spécialisations partielles ne sont pas liés aux membres du modèle primaire.

La spécialisation explicite (complète) d'un membre d'une spécialisation partielle se déclare de la même manière qu'une spécialisation explicite du modèle primaire.

template<class T, int I> // modèle primaire
struct A
{
    void f(); // déclaration de membre
};

template<class T, int I>
void A<T, I>::f() {}     // définition de membre du modèle primaire

// spécialisation partielle
template<class T>
struct A<T, 2>
{
    void f();
    void g();
    void h();
};

// membre de la spécialisation partielle
template<class T>
void A<T, 2>::g() {}

// spécialisation explicite (complète)
// d'un membre de la spécialisation partielle
template<>
void A<char, 2>::h() {}

int main()
{
    A<char, 0> a0;
    A<char, 2> a2;
    a0.f(); // OK, utilise la définition de membre du modèle primaire
    a2.g(); // OK, utilise la définition de membre de la spécialisation partielle
    a2.h(); // OK, utilise la définition entièrement spécialisée de
            // le membre d'une spécialisation partielle
    a2.f(); // erreur : aucune définition de f() dans la spécialisation
            // partielle A<T,2> (le modèle primaire n'est pas utilisé)
}

Si un modèle primaire est un membre d'un autre modèle de classe, ses spécialisations partielles sont membres du modèle de classe englobant. Si le modèle englobant est instancié, la déclaration de chaque spécialisation partielle membre est instanciée également (de la même manière que les déclarations, mais non les définitions, de tous les autres membres d'un modèle sont instanciées).

Si le modèle membre primaire est explicitement (complètement) spécialisé pour une spécialisation (implicite) donnée du modèle de classe englobant, les spécialisations partielles du modèle membre sont ignorées pour cette spécialisation du modèle de classe englobant.

Si une spécialisation partielle du modèle membre est explicitement spécialisée pour une spécialisation (implicite) donnée du modèle de classe englobant, le modèle membre primaire et ses autres spécialisations partielles sont toujours pris en compte pour cette spécialisation du modèle de classe englobant.

template<class T> struct A // modèle de classe englobant
{
    template<class T2>
    struct B {};      // modèle de membre primaire
    template<class T2>
    struct B<T2*> {}; // spécialisation partielle du modèle membre
};

template<>
template<class T2>
struct A<short>::B {}; // spécialisation complète du modèle membre primaire
                       // (la partielle sera ignorée)

A<char>::B<int*> abcip;  // utilise la spécialisation partielle T2=int
A<short>::B<int*> absip; // utilise la spécialisation complète du primaire (ignore la partielle)
A<char>::B<int> abci;    // utilise le primaire

Rapports de défauts

Les rapports de défauts suivants modifiant le comportement ont été appliqués rétroactivement aux normes C++ publiées précédemment.

DR Appliqué à Comportement publié Comportement correct
CWG 727 C++98 spécialisations partielles et complètes non autorisées dans la portée de classe autorisées dans n'importe quelle portée
CWG 1315 C++98 un paramètre de modèle ne pouvait pas être utilisé dans des arguments de modèle non typés autres que des expressions id expressions acceptées tant qu'elles sont déductibles
CWG 1495 C++11 la spécification était peu claire lorsqu'un paquet de paramètres était impliqué la spécialisation doit être plus spécialisée
CWG 1711 C++14 spécification manquante pour les spécialisations partielles de modèles de variable ajout de la prise en charge des modèles de variable
CWG 1819 C++98 portées acceptables pour la définition d'une spécialisation partielle permettre de déclarer une spécialisation partielle dans la même portée que les modèles primaires
CWG 2330 C++14 références aux modèles de variable manquantes ajout de la prise en charge des modèles de variable
