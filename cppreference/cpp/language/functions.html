Fonctions

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les fonctions sont des entités C++ qui associent une suite de instructions (un corps de fonction) à un nom et à une liste de zéro ou plusieurs paramètres de fonction.

// nom de la fonction : "isodd"
// la liste de paramètres contient un seul paramètre, de nom « n » et de type int
// le type de retour est bool
bool isodd(int n)
{                 // le corps de la fonction commence
    return n % 2;
}                 // le corps de la fonction se termine

Lorsqu'une fonction est invoquée, par exemple dans une expression d'appel de fonction, les paramètres sont initialisés à partir des arguments (fournis sur le lieu d'appel ou par défaut) et les instructions du corps de la fonction sont exécutées. Si la liste de paramètres se termine par ..., des arguments supplémentaires peuvent être fournis à la fonction ; une telle fonction est appelée fonction variadique.

int main()
{
    for (int arg : {-3, -2, -1, 0, 1, 2, 3})
        std::cout << isodd(arg) << ' '; // isodd appelée 7 fois, chacune
                                        // fois où n est initialisée par copie à partir de arg
}

Les noms de fonctions non qualifiés dans les expressions d'appel de fonction sont recherchés avec un ensemble supplémentaire de règles appelé « recherche dépendante des arguments » (ADL).

Une fonction peut se terminer en retournant une valeur ou en levant une exception.

Une fonction peut être une coroutine, auquel cas elle peut suspendre son exécution pour la reprendre plus tard.

(depuis C++20)

Une déclaration de fonction peut apparaître dans n'importe quelle portée, mais une définition de fonction ne peut apparaître que dans une portée d'espace de noms ou, pour les fonctions membres et amies, dans une portée de classe. Une fonction déclarée dans le corps d'une classe sans spécificateur friend est une fonction membre de classe. Ces fonctions ont de nombreuses propriétés supplémentaires, voir fonctions membres pour les détails.

Les fonctions ne sont pas des objets : il n'existe pas de tableaux de fonctions, et les fonctions ne peuvent ni être passées par valeur ni être retournées par d'autres fonctions. Les pointeurs et les références vers des fonctions (à l'exception de la fonction mainet la plupart des fonctions de la bibliothèque standard (depuis C++20)) sont autorisés, et peuvent être utilisés là où ces fonctions elles-mêmes ne le peuvent pas. C'est pourquoi on dit que ces fonctions sont « adressables ».

Chaque fonction a un type, constitué du type de retour de la fonction, des types de tous ses paramètres (après les transformations tableau-vers-pointeur et fonction-vers-pointeur, voir liste de paramètres) , selon que la fonction est noexcept ou non (depuis C++17), et, pour les fonctions membres non statiques, de la qualification cvet de la qualification ref (depuis C++11). Les types de fonctions ont également une liaison de langage. Il n'existe pas de types de fonctions qualifiés cv (à ne pas confondre avec les types des fonctions qualifiées cv comme int f() const;, ni avec les fonctions retournant des types qualifiés cv, comme std::string const f();). Tout qualificateur cv est ignoré s'il est ajouté à un alias d'un type de fonction.

Plusieurs fonctions dans la même portée peuvent avoir le même nom, à condition que leurs listes de paramètres et, pour les fonctions membres non statiques, leurs qualifications cv/ref (depuis C++11) soient différentes. C'est ce qu'on appelle la surcharge de fonctions. Les déclarations de fonctions qui ne diffèrent que par le type de retour et la spécification noexcept (depuis C++17) ne peuvent pas être surchargées. L'adresse d'une fonction surchargée est déterminée différemment.

C++ implémente les fonctions anonymes à l'aide d'expressions lambda.

(depuis C++11)

Objets fonctions

Outre les lvalues de fonctions, l'expression d'appel de fonction prend en charge les pointeurs vers des fonctions, ainsi que toute valeur de type classe qui surcharge l'opérateur d'appel de fonction ou est convertible en pointeur de fonction(y compris les expressions lambda) (depuis C++11). Ensemble, ces types sont appelés FunctionObjects, et ils sont utilisés partout dans la bibliothèque standard C++, voir par exemple les utilisations de BinaryPredicate et de Compare.

La bibliothèque standard fournit également un certain nombre de modèles d'objets fonctions prédéfinis, ainsi que les méthodes permettant de composer de nouveaux objets (y compris std::less[, std::mem_fn, std::bind, std::function (depuis C++11) | , std::not_fn (depuis C++17) | , std::bind_front (depuis C++20) | , std::bind_back, std::move_only_function (depuis C++23) | , std::copyable_function, et std::function_ref (depuis C++26)]).
