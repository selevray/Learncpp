Constructeur de conversion

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un constructeur non déclaré avec le spécificateur explicit et pouvant être appelé avec un seul paramètre (jusqu'à C++11) est appelé constructeur de conversion.

Contrairement aux constructeurs explicites, qui ne sont considérés que lors de l'initialisation directe (ce qui inclut les conversions explicites telles que static_cast), les constructeurs de conversion sont aussi considérés lors de l'initialisation par copie, dans le cadre d'une séquence de conversion définie par l'utilisateur.

On dit qu'un constructeur de conversion spécifie une conversion implicite depuis les types de ses arguments (le cas échéant) vers le type de sa classe. Notez qu'une fonction de conversion définie par l'utilisateur non explicite spécifie également une conversion implicite.

Les constructeurs de copie et constructeurs de déplacement implicitement déclarés et définis par l'utilisateur, non explicites, sont des constructeurs de conversion.

Exemple

struct A
{
    A() { }         // constructeur de conversion (depuis C++11)
    A(int) { }      // constructeur de conversion
    A(int, int) { } // constructeur de conversion (depuis C++11)
};

struct B
{
    explicit B() { }
    explicit B(int) { }
    explicit B(int, int) { }
};

int main()
{
    A a1 = 1;      // OK : l'initialisation par copie sélectionne A::A(int)
    A a2(2);       // OK : l'initialisation directe sélectionne A::A(int)
    A a3{4, 5};    // OK : l'initialisation directe par liste sélectionne A::A(int, int)
    A a4 = {4, 5}; // OK : l'initialisation par copie de liste sélectionne A::A(int, int)
    A a5 = (A)1;   // OK : la conversion explicite effectue static_cast, initialisation directe

//  B b1 = 1;      // error : l'initialisation par copie ne considère pas B::B(int)
    B b2(2);       // OK : l'initialisation directe sélectionne B::B(int)
    B b3{4, 5};    // OK : l'initialisation directe par liste sélectionne B::B(int, int)
//  B b4 = {4, 5}; // error : l'initialisation par copie de liste a sélectionné un constructeur explicite
                   //        B::B(int, int)
    B b5 = (B)1;   // OK : la conversion explicite effectue static_cast, initialisation directe
    B b6;          // OK, initialisation par défaut
    B b7{};        // OK, initialisation directe par liste
//  B b8 = {};     // error : l'initialisation par copie de liste a sélectionné un constructeur explicite
                   //        B::B()

    [](...){}(a1, a4, a4, a5, b5); // peut supprimer les avertissements "unused variable"
}
