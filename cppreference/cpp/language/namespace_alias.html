Alias d'espaces de noms

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les alias d'espaces de noms permettent au programmeur de définir un autre nom pour un espace de noms.

Ils sont couramment utilisés comme raccourci pratique pour les espaces de noms longs ou profondément imbriqués.

Syntaxe

| | | | namespace alias_name = ns_name; | (1) | | | | namespace alias_name = ::ns_name; | (2) | | | | namespace alias_name = nested_name::ns_name; | (3) | | |

Explication

Le nouvel alias alias_name fournit une autre méthode pour accéder à ns_name.

alias_name doit être un nom non utilisé auparavant. alias_name est valide pendant toute la durée de la portée dans laquelle il est introduit.

Mots-clés

namespace

Exemple

#include <iostream>

namespace foo
{
    namespace bar
    {
         namespace baz
         {
             int qux = 42;
         }
    }
}

namespace fbz = foo::bar::baz;

int main()
{
    std::cout << fbz::qux << '\n';
}

Output:

42
