Jeu de caractères de traduction

Le jeu de caractères de traduction est constitué des éléments suivants :

  • chaque caractère abstrait auquel est attribué un point de code dans l'espace de codes Unicode, et
  • un caractère distinct pour chaque valeur scalaire Unicode non attribuée à un caractère abstrait.

Le jeu de caractères de traduction est un surensemble du jeu de caractères de base et du jeu de caractères littéraux de base (voir ci-dessous).

(depuis C++23)

Jeu de caractères littéraux de base

Le jeu de caractères littéraux de base est constitué de tous les caractères du jeu de caractères de base, auxquels s'ajoutent les caractères de contrôle suivants :

Unité de code Caractère
U+0000 Nul
U+0007 Sonnerie
U+0008 Retour arrière
U+000D Retour chariot (CR)

Jeu de caractères d'exécution

Le jeu de caractères d'exécution et le jeu de caractères larges d'exécution sont des surensembles du jeu de caractères littéraux de base. Les encodages des jeux de caractères d'exécution et les ensembles d'éléments supplémentaires (le cas échéant) dépendent de la locale. Chaque élément du jeu de caractères larges d'exécution doit être représentable par une wchar_t unité de code distincte.

Unité de code et encodage des littéraux

Une unité de code est une valeur entière de type caractère. Les caractères d'un littéral de caractère autres qu'un littéral multicaractère ou non encodable, ou d'un littéral de chaîne, sont encodés comme une suite d'une ou plusieurs unités de code, déterminée par le préfixe d'encodage ; on parle alors de encodage du littéral respectif.

Un encodage de littéral ou un encodage spécifique à la locale d'un des jeux de caractères d'exécution encode chaque élément du jeu de caractères de base des littéraux comme une unique unité de code de valeur non négative, distincte de l'unité de code de tout autre élément de ce type. Un caractère n'appartenant pas au jeu de caractères de base des littéraux peut être encodé avec plusieurs unités de code ; la valeur d'une telle unité de code peut être identique à celle d'une unité de code d'un élément du jeu de caractères de base des littéraux. Les encodages des jeux de caractères d'exécution peuvent être sans lien avec un encodage de littéral quelconque.

L'encodage des littéraux ordinaires est celui appliqué à un littéral de caractère ou de chaîne ordinaire. L'encodage des littéraux larges est celui appliqué à un littéral de caractère ou de chaîne large.

Le caractère NULL U+0000 est encodé avec la valeur 0. Aucun autre élément du jeu de caractères de traduction n'est encodé avec une unité de code de valeur 0. La valeur de l'unité de code de chaque chiffre décimal après le chiffre 0 (U+0030) doit être supérieure d'une unité à celle du précédent. Les encodages des littéraux ordinaires et larges sont par ailleurs définis par l'implémentation.

Pour un littéral UTF-8, UTF-16 ou UTF-32, la valeur scalaire UCS correspondant à chaque caractère du jeu de caractères de traduction est encodée comme spécifié dans l'ISO/IEC 10646 pour la forme d'encodage UCS respective.
