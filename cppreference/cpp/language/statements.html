Instructions

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les instructions sont des fragments du programme C++ exécutés en séquence. Le corps de toute fonction est une séquence d'instructions. Par exemple :

int main()
{
    int n = 1;                        // instruction de déclaration
    n = n + 1;                        // instruction d'expression
    std::cout << "n = " << n << '\n'; // instruction d'expression
    return 0;                         // instruction return
}

C++ comprend les types d'instructions suivants :

  1. instructions étiquetées ;

  2. instructions d'expression ;

  3. instructions composées ;

  4. instructions de sélection ;

  5. instructions d'itération ;

  6. instructions de saut ;

  7. instructions de déclaration ;

  8. blocs try ;

  9. blocs atomiques et synchronisés (TM TS) .

Instructions étiquetées

Une instruction étiquetée étiquette une instruction à des fins de contrôle de flux.

| | | | label statement | | | |

  • label — l'étiquette appliquée à l'instruction (définie ci-dessous)
  • statement — l'instruction à laquelle s'applique l'étiquette ; il peut s'agir d'une instruction étiquetée elle-même, permettant plusieurs étiquettes

Étiquettes

label est défini comme

| | | | attr ﻿*(facultatif)* identifier : | (1) | | | | attr ﻿*(facultatif)* case constexpr : | (2) | | | | attr ﻿*(facultatif)* default: | (3) | | |

  1. cible pour goto ;

  2. case étiquette dans une instruction switch ;

  3. default étiquette dans une instruction switch.

Une séquence d'attributs attr peut apparaître juste au début de l'étiquette (auquel cas elle s'applique à l'étiquette), ou juste avant l'instruction elle-même, auquel cas elle s'applique à l'instruction entière.

(depuis C++11)

Une étiquette portant un identifiant déclaré dans une fonction correspond à toutes les instructions goto ayant le même identifiant dans cette fonction, dans tous les blocs imbriqués, avant et après sa propre déclaration.

Deux étiquettes d'une fonction ne doivent pas avoir le même identifiant.

Outre leur ajout à une instruction, les étiquettes peuvent aussi être utilisées n'importe où dans les instructions composées.

(depuis C++23)

Les étiquettes ne sont pas trouvées par la recherche non qualifiée : une étiquette peut avoir le même nom que toute autre entité du programme.

void f()
{
    {
        goto label; // étiquette dans la portée bien que déclarée plus tard
        label:      // une étiquette peut apparaître seule à la fin d'un bloc depuis C++23
    }
    goto label; // l'étiquette ignore la portée de bloc
}

void g()
{
    goto label; // erreur : étiquette hors de portée dans g()
}

Instructions à flux de contrôle limité

Les instructions suivantes sont des instructions à flux de contrôle limité :

  • Le compound-statement d'un bloc try.
  • Le compound-statement d'un gestionnaire.
  • Toutes les sous-instructions d'une instruction constexpr if.

(depuis C++17)

  • Toutes les sous-instructions d'une instruction consteval if.

(depuis C++23)

Pour chaque instruction à flux de contrôle limité S :

  • Toutes les étiquettes cibles goto déclarées dans S ne peuvent être référencées que par des instructions dans S.
  • Chaque étiquette case ou default apparaissant dans S ne peut être associée qu'à une instruction switch dans S.

Instructions d'expression

Une instruction d'expression est une expression suivie d'un point-virgule.

| | | | attr (facultatif) expression (facultatif) ; | | | |

  • attr — (depuis C++11) séquence optionnelle d'un nombre quelconque d'attributs
  • expression — une expression

La plupart des instructions d'un programme C++ typique sont des instructions d'expression, comme des affectations ou des appels de fonction.

Une instruction d'expression sans expression est appelée une instruction nulle. Elle est souvent utilisée pour fournir un corps vide à une boucle for ou while. Elle peut aussi servir à porter une étiquette à la fin d'une instruction composée. (jusqu'à C++23)

Instructions composées

Une instruction composée ou bloc regroupe une séquence d'instructions en une seule instruction.

| | | | attr (facultatif) { statement... (facultatif) label... (facultatif) (depuis C++23) } | | | |

Lorsqu'une seule instruction est attendue, mais que plusieurs instructions doivent être exécutées en séquence (par exemple dans une instruction if ou une boucle), on peut utiliser une instruction composée :

if (x > 5)          // début de l'instruction if
{                   // début du bloc
    int n = 1;      // instruction de déclaration
    std::cout << n; // instruction d'expression
}                   // fin du bloc, fin de l'instruction if

Chaque instruction composée introduit sa propre portée de bloc ; les variables déclarées à l'intérieur d'un bloc sont détruites à l'accolade fermante, dans l'ordre inverse :

int main()
{ // début du bloc externe
    {                                // début du bloc interne
        std::ofstream f("test.txt"); // instruction de déclaration
        f << "abc\n";                // instruction d'expression
    }                                // fin du bloc interne, f est vidé et fermé
    std::ifstream f("test.txt"); // instruction de déclaration
    std::string str;             // instruction de déclaration
    f >> str;                    // instruction d'expression
} // fin du bloc externe, str est détruit, f est fermé

Une étiquette placée à la fin d'une instruction composée est traitée comme si elle était suivie d'une instruction nulle.

(depuis C++23)

Instructions de sélection

Une instruction de sélection choisit entre l'un de plusieurs flux de contrôle.

| | | | attr (facultatif) if constexpr(facultatif) ( init-statement (facultatif) condition ) statement | (1) | | | | attr (facultatif) if constexpr(facultatif) ( init-statement (facultatif) condition ) statement else statement | (2) | | | | attr (facultatif) switch ( init-statement (facultatif) condition ) statement | (3) | | | | attr (facultatif) if !(facultatif) consteval compound-statement | (4) | (depuis C++23) | | | attr (facultatif) if !(facultatif) consteval compound-statement else statement | (5) | (depuis C++23) | |

  1. instruction if ;

instruction if avec une clause else ; 2)

  1. instruction switch ;

  2. instruction consteval if ;

  3. instruction consteval if avec une clause else.

Instructions d'itération

Une instruction d'itération exécute répétitivement du code.

| | | | attr ﻿*(facultatif)* while ( condition ) statement | (1) | | | | attr ﻿*(facultatif)* do statement while ( expression ) ; | (2) | | | | attr ﻿*(facultatif)* for ( init-statement condition ﻿*(facultatif)* ; expression ﻿*(facultatif)* ) statement | (3) | | | | attr ﻿*(facultatif)* for ( init-statement ﻿*(facultatif)* (depuis C++20) for-range-decl : for-range-init ) statement | (4) | (depuis C++11) | |

  1. boucle while ;

  2. boucle do-while ;

  3. boucle for ;

  4. boucle range for.

Instructions de saut

Une instruction de saut transfère inconditionnellement le flux de contrôle.

| | | | attr ﻿*(facultatif)* break; | (1) | | | | attr ﻿*(facultatif)* continue; | (2) | | | | attr ﻿*(facultatif)* return expression ﻿*(facultatif)* ; | (3) | | | | attr ﻿*(facultatif)* return braced-init-list ; | (4) | (depuis C++11) | | | attr ﻿*(facultatif)* goto identifier ; | (5) | | |

  1. instruction break ;

  2. instruction continue ;

  3. instruction return avec une expression facultative ;

  4. instruction return utilisant l'initialisation par liste ;

  5. instruction goto.

Note : pour toutes les instructions de saut, le transfert hors d'une boucle, hors d'un bloc, ou en arrière au-delà d'une variable initialisée à durée de stockage automatique entraîne la destruction des objets à durée de stockage automatique qui sont dans la portée du point de départ mais pas du point d'arrivée. Si plusieurs objets ont été initialisés, l'ordre de destruction est l'inverse de l'ordre d'initialisation.

Sous-instructions

Une sous-instruction d'une instruction est l'une des suivantes :

  • Pour une instruction étiquetée, sa statement ﻿.
  • Pour une instruction composée, toute instruction de sa statement... ﻿.
  • Pour une instruction de sélection, l'une quelconque de ses statement ﻿ou compound-statement ﻿ (depuis C++23).
  • Pour une instruction d'itération, sa statement ﻿.

Une instruction S1 englobe une instruction S2 si l'une quelconque des conditions suivantes est satisfaite :

  • S2 est une sous-instruction de S1
  • S1 est une instruction de sélection ou d'itération, et S2 est le init-statement de S1.
  • S1 est un bloc try, et S2 est soit son compound-statement, soit le compound-statement de tout gestionnaire de son handler-seq ﻿.
  • S1 englobe une instruction S3 et S3 englobe S2.

Une instruction S1 est englobée par une instruction S2 si S2 englobe S1.
