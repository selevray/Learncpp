Indexation de paquet (depuis C++26)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Accède à l'élément d'un paquet à un indice spécifié.

Syntaxe

| | | | id-expression ...[ expression ] | (1) | | | | typedef-name ...[ expression ] | (2) | | |

  1. Expression d'indexation de paquet

  2. Spécificateur d'indexation de paquet

  • typedef-name — un identifiant ou un simple-template-id qui désigne un paquet
  • id-expression — une id-expression qui désigne un paquet
  • expression — une expression constante convertie I de type std::size_t désignée comme indice où I est dans l'intervalle [0,sizeof...(P)) pour un certain paquet P dans l'indexation de paquet

Explication

L'indexation de paquet est une expansion de paquet du paquet non étendu suivi d'une ellipse et d'un indice à l'intérieur de l'indice entre crochets. Il existe deux sortes d'indexation de paquet : l'expression d'indexation de paquet et le spécificateur d'indexation de paquet.

Soit P un paquet non vide contenant P0, P1, ..., Pn-1 et I un indice valide, l'instanciation de l'expansion P...[I] donne l'élément PI de P.

L'indexation d'un paquet avec l'indice I qui n'est pas une expression constante n'est pas autorisée.

int runtime_idx();

void bar(auto... args)
{
    auto a = args...[0];
    const int n = 1;
    auto b = args...[n];
    int m = 2;
    auto c = args...[m]; // error: 'm' n'est pas une expression constante
    auto d = args...[runtime_idx()]; // error: 'runtime_idx()' n'est pas une expression constante
}

L'indexation d'un paquet de paramètres de modèle template n'est pas possible.

template <template <typename...> typename... Temps>
using A = Temps...[0]<>; // error: 'Temps' est un pack de paramètres de modèle de modèle

template <template <typename...> typename... Temps>
using B = Temps<>...[0]; // error: 'Temps<>' ne désigne pas un nom de pack
                         // bien qu'il s'agisse d'un simple-template-id

Expression d'indexation de paquet

| | | | id-expression ...[ expression ] | | | |

L'expression d'indexation de paquet désigne l'id-expression, l'expression de l'élément de paquet PI. Le id-expression doit être introduit par la déclaration de :

  • paquet de paramètres de modèle non de type,
  • paquet de paramètres de fonction,
  • paquet de captures d'initialisation de lambda, ou
  • paquet de liaisons structurées.
template <std::size_t I, typename... Ts>
constexpr auto element_at(Ts... args)
{
    // 'args' introduit dans la déclaration du pack de paramètres de fonction
    return args...[I];
}

static_assert(element_at<0>(3, 5, 9) == 3);
static_assert(element_at<2>(3, 5, 9) == 9);
static_assert(element_at<3>(3, 5, 9) == 4); // error:  hors limites
static_assert(element_at<0>() == 1); // error: hors limites, pack vide

template <std::size_t I, typename Tup>
constexpr auto structured_binding_element_at(Tup tup)
{
    auto [...elems] = tup;
    // 'elems' introduit dans la déclaration du pack de liaisons structurées
    return elems...[I];
}

struct A { bool a; int b; };

static_assert(structured_binding_element_at<0>(A {true, 4}) == true);
static_assert(structured_binding_element_at<1>(A {true, 4}) == 4);

// 'Vals' introduit dans la déclaration du pack de paramètres de modèle non typés
template <std::size_t I, std::size_t... Vals>
constexpr std::size_t double_at = Vals...[I] * 2; // OK

template <std::size_t I, typename... Args>
constexpr auto foo(Args... args)
{
    return [...members = args](Args...[I] op)
    {
        // 'members' introduit dans le pack de captures init de lambda
        return members...[I] + op;
    };
}

static_assert(foo<0>(4, "Hello", true)(5) == 9);
static_assert(foo<1>(3, std::string("C++"))("26") == "C++26");

L'indexation d'un paquet d'expressions complexes autres qu'une id-expression n'est pas autorisée.

template <std::size_t I, auto... Vals>
constexpr auto identity_at = (Vals)...[I]; // error
// utilisez 'Vals...[I]' à la place

template <std::size_t I, std::size_t... Vals>
constexpr std::size_t triple_at = (Vals * 3)...[I]; // error
// utilisez 'Vals...[I] * 3' à la place

template <std::size_t I, typename... Args>
constexpr decltype(auto) get(Args&&... args) noexcept
{
    return std::forward<Args>(args)...[I]; // error
    // utilisez 'std::forward<Args...[I]>(args...[I])' à la place
}

L'application de decltype à une expression d'indexation de paquet est identique à l'application de decltype à une id-expression.

void f()
{
    [](auto... args)
    {
        using T0 = decltype(args...[0]);   // 'T0' est 'double'
        using T1 = decltype((args...[0])); // 'T1' est 'double&'
    }(3.14);
}

Spécificateur d'indexation de paquet

| | | | typedef-name ...[ expression ] | | | |

Le spécificateur d'indexation de paquet désigne le computed-type-specifier, le type de l'élément de paquet PI. Le typedef-name doit être introduit par la déclaration de paquet de paramètres de modèle de type.

template <typename... Ts>
using last_type_t = Ts...[sizeof...(Ts) - 1];

static_assert(std::is_same_v<last_type_t<>, int>); // error: hors limites
static_assert(std::is_same_v<last_type_t<int>, int>);
static_assert(std::is_same_v<last_type_t<bool, char>, char>);
static_assert(std::is_same_v<last_type_t<float, int, bool*>, bool*>);

Le spécificateur d'indexation de paquet peut apparaître :

  • un spécificateur de type simple,
  • un spécificateur de classe de base,
  • un spécificateur de nom imbriqué, ou
  • le type d'un appel explicite au destructeur.

Le spécificateur d'indexation de pack peut être utilisé dans la liste des paramètres d'une fonction ou d'un constructeur pour établir des contextes non déduits dans la déduction d'arguments de modèle.

template <typename...>
struct type_seq {};

template <typename... Ts>
auto f(Ts...[0] arg, type_seq<Ts...>)
{
    return arg;
}

// OK: "Hello" est implicitement converti en 'std::string_view'
std::same_as<std::string_view> auto a = f("Hello", type_seq<std::string_view>{});

// Error: "Ok" n'est pas convertible en 'int'
std::same_as<int> auto b = f("Ok", type_seq<int, const char*>{});

Notes

Avant C++26, Ts...[N] était une syntaxe valide pour déclarer un pack de paramètres de fonction de tableaux sans nom de taille N, les types des paramètres étant ensuite ajustés en pointeurs. Depuis C++26, Ts...[1] est interprété comme un spécificateur d'indexation de pack, ce qui modifierait le comportement ci-dessous en #2. Pour préserver le premier comportement, le pack de paramètres de fonction doit être nommé, ou ajusté manuellement en un pack de types pointeurs.

template <typename... Ts>
void f(Ts... [1]);

template <typename... Ts>
void g(Ts... args[1]);

template <typename... Ts>
void h(Ts*...); // plus clair mais plus permissif : Ts... peut contenir des types void ou fonction qualifiés cv

void foo()
{
    f<char, bool>(nullptr, nullptr);
    // comportement #1 (avant C++26) :
    //  appelle void 'f<char, bool>(char*, bool*)' (alias de 'f<char, bool>(char[1], bool[1])')
    // comportement #2 (depuis C++26) :
    //  error: appel supposé de 'void f<char, bool>(bool)'
    //  mais fourni avec 2 arguments au lieu de 1

    g<char, bool>(nullptr, nullptr);
    // appelle 'g<char, bool>(char*, bool*)' (alias de 'g<char, bool>(char[1], bool[1])')

    h<char, bool>(nullptr, nullptr);
    // appelle 'h<char, bool>(char*, bool*)'
}

Exemple

#include <tuple>

template <std::size_t... Indices, typename Decomposable>
constexpr auto splice(Decomposable d)
{
    auto [...elems] = d;
    return std::make_tuple(elems...[Indices]...);
}

struct Point
{
    int x;
    int y;
    int z;
};

int main()
{
    constexpr Point p { .x = 1, .y = 4, .z = 3 };
    static_assert(splice<2, 1, 0>(p) == std::make_tuple(3, 4, 1));
    static_assert(splice<1, 1, 0, 0>(p) == std::make_tuple(4, 4, 1, 1));
}
