Modèle de variable (depuis C++14)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un modèle de variable définit une famille de variables ou de membres de données statiques.

Syntaxe

| | | | template < parameter-list > variable-declaration | (1) | | | | template < parameter-list > requires constraint variable-declaration | (2) | (depuis C++20) | |

  • variable-declaration — une déclaration de variable. Le nom de la variable déclarée devient un nom de modèle.
  • parameter-list — une liste non vide, séparée par des virgules, de paramètres de modèle, chacun étant soit un paramètre non type, un paramètre de type, un paramètre de modèle, ou un pack de paramètres de l'un de ces types.
  • constraint — une expression de contrainte qui restreint les paramètres de modèle acceptés par ce modèle de variable

Explication

Une variable instanciée à partir d'un modèle de variable est appelée une variable instanciée. Un membre de données statique instancié à partir d'un modèle de membre de données statique est appelé un membre de données statique instancié.

Un modèle de variable peut être introduit par une déclaration de modèle à portée d'espace de noms, où variable-declaration déclare une variable.

template<class T>
constexpr T pi = T(3.1415926535897932385L); // modèle de variable

template<class T>
T circular_area(T r) // modèle de fonction
{
    return pi<T> * r * r; // pi<T> est une instanciation de modèle de variable
}

Utilisé dans une portée de classe, un modèle de variable déclare un modèle de membre de données statique.

using namespace std::literals;
struct matrix_constants
{
    template<class T>
    using pauli = hermitian_matrix<T, 2>; // modèle d'alias

    template<class T> // modèle de membre de données statique
    static constexpr pauli<T> sigmaX = {{0, 1}, {1, 0}};

    template<class T>
    static constexpr pauli<T> sigmaY = {{0, -1i}, {1i, 0}};

    template<class T>
    static constexpr pauli<T> sigmaZ = {{1, 0}, {0, -1}};
};

Comme pour les autres membres statiques, la définition d'un modèle de membre de données statique peut être requise. Cette définition est fournie en dehors de la définition de la classe. Une déclaration de modèle d'un membre de données statique à portée d'espace de noms peut aussi être une définition d'un membre de données non modèle d'un modèle de classe :

struct limits
{
    template<typename T>
    static const T min; // déclaration d'un modèle de membre de données statique
};

template<typename T>
const T limits::min = { }; // définition d'un modèle de membre de données statique

template<class T>
class X
{
    static T s; // déclaration d'un membre de données statique non modèle d'un modèle de classe
};

template<class T>
T X<T>::s = 0; // définition d'un membre de données non modèle d'un modèle de classe

Sauf si un modèle de variable a fait l'objet d'une spécialisation explicite ou d'une instanciation explicite, il est instancié implicitement lorsqu'une spécialisation du modèle de variable est référencée dans un contexte qui exige qu'une définition de variable existe, ou si l'existence de la définition affecte la sémantique du programme, c'est-à-dire si la variable est nécessaire à l'évaluation constante par une expression (la définition peut ne pas être utilisée).

L'existence d'une définition d'une variable est considérée comme affectant la sémantique du programme si la variable est nécessaire à l'évaluation constante par une expression, même si l'évaluation constante de l'expression n'est pas requise ou si l'évaluation de l'expression constante n'utilise pas la définition.

Notes

Jusqu'à l'introduction des modèles de variable en C++14, les variables paramétrées étaient généralement implémentées soit comme membres de données statiques de modèles de classe, soit comme modèles de fonction constexpr renvoyant les valeurs désirées.

Les modèles de variable ne peuvent pas être utilisés comme arguments de modèle de modèle.
