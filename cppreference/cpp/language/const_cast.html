Conversion const_cast

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Convertit entre des types ayant des qualifications cv différentes.

Syntaxe

| | | | const_cast< target-type >( expression ) | | | |

Renvoie une valeur de type target-type.

Explication

Seules les conversions suivantes peuvent être effectuées avec const_cast :

  1. Pour deux types de pointeurs vers objet ou de pointeurs vers membre de données similaires T1 et T2, une prvalue de type T1 peut être convertie en T2 si T1 et T2 ne diffèrent que par la qualification cv (formellement, si, en considérant les décompositions de qualification des deux types, chaque P1_i est identique à P2_i pour tout i).
  • Si expression est une valeur de pointeur nul, le résultat est également une valeur de pointeur nul.
  • Si expression est une valeur de pointeur membre nul, le résultat est également une valeur de pointeur membre nul.
  • Si expression pointe vers un objet, le résultat pointe vers le même objet.
  • Si expression pointe au-delà d'un objet, le résultat pointe au-delà du même objet.
  • Si expression pointe vers un membre de données, le résultat pointe vers le même membre de données.

Même si expression est une prvalue, la matérialisation temporaire n'est pas effectuée.

(depuis C++17)

  1. Pour deux types d'objets T1 et T2, si un pointeur vers T1 peut être explicitement converti vers le type « pointeur vers T2 » à l'aide de const_cast<T2*>, alors les conversions suivantes peuvent également être effectuées :
  • Une lvalue de type T1 peut être explicitement convertie en lvalue de type T2 à l'aide de const_cast<T2&>.
  • Une glvalue de type T1 peut être explicitement convertie en xvalue de type T2 à l'aide de const_cast<T2&&>.
  • Si T1 est un type classe ou tableau, une prvalue de type T1 peut être explicitement convertie en xvalue de type T2 à l'aide de const_cast<T2&&>.

(depuis C++11)

La référence résultante fait référence à l'objet d'origine.

(jusqu'à C++17)

Si expression est une glvalue, la référence résultante fait référence à l'objet d'origine. Sinon, la référence résultante fait référence au temporaire matérialisé.

(depuis C++17)

Comme pour toutes les expressions de transtypage, le résultat est :

  • une lvalue si target-type est de type référence lvalueou référence rvalue vers un type fonction (depuis C++11) ;
  • une xvalue si target-type est une référence rvalue vers un type objet ;

(depuis C++11)

  • une prvalue sinon.

Retrait de la constance

Pour deux types différents T1 et T2, une conversion de T1 vers T2 retire la constance s'il existe une décomposition de qualification de T2 de la forme « cv2_0 P2_0 cv2_1 P2_1 ... cv2_n−1 P2_n−1 cv2_n U2 », et qu'il n'existe aucune conversion de qualification qui convertit T1 en « cv2_0 P1_0 cv2_1 P1_1 ... cv2_n−1 P1_n−1 cv2_n U1 » (mêmes composantes cv, composantes P et U différentes).

Si un transtypage d'une prvalue de type T1* vers le type T2* retire la constance, le transtypage d'une expression de type T1 vers une référence vers T2 retire aussi la constance.

Seul const_cast peut être utilisé pour retirer la constance.

« Retrait de la constance » implique « retrait de la volatilité », car les conversions de qualification ne peuvent pas non plus retirer la volatilité.

Notes

Les pointeurs vers fonctions et les pointeurs vers fonctions membres ne sont pas concernés par const_cast.

const_cast permet de former une référence ou un pointeur vers un type non const qui fait en réalité référence à un objet const, ou une référence ou un pointeur vers un type non volatile qui fait en réalité référence à un objet volatile. Modifier un objet const via un chemin d'accès non const, et référencer un objet volatile via une glvalue non volatile, entraîne un comportement indéfini.

Mots-clés

const_cast

Exemple

#include <iostream>

struct type
{
    int i;

    type(): i(3) {}

    void f(int v) const
    {
        // this->i = v;                 // erreur de compilation : this est un pointeur vers const
        const_cast<type*>(this)->i = v; // OK tant que l'objet de ce type n'est pas const
    }
};

int main()
{
    int i = 3;                 // i n'est pas déclaré const
    const int& rci = i;
    const_cast<int&>(rci) = 4; // OK : modifie i
    std::cout << "i = " << i << '\n';

    type t; // si this était de type t qualifié const, alors t.f(4) serait un comportement indéfini
    t.f(4);
    std::cout << "type::i = " << t.i << '\n';

    const int j = 3; // j est déclaré const
    [[maybe_unused]]
    int* pj = const_cast<int*>(&j);
    // *pj = 4;      // comportement indéfini

    [[maybe_unused]]
    void (type::* pmf)(int) const = &type::f; // pointeur vers fonction membre
    // const_cast<void(type::*)(int)>(pmf);   // erreur de compilation : const_cast ne
                                              // fonctionne pas sur les pointeurs de fonction
}

Output:

i = 4
type::i = 4
