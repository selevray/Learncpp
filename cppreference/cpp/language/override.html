override spécificateur (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Indique qu'une fonction virtuelle redéfinit une autre fonction virtuelle.

Syntaxe

L'identifiant override, s'il est utilisé, apparaît immédiatement après le déclarateur dans la syntaxe d'une déclaration de fonction membre ou d'une définition de fonction membre à l'intérieur d'une définition de classe.

| | | | declarator virt-specifier-seq ﻿*(facultatif)* pure-specifier ﻿*(facultatif)* | (1) | | | | declarator virt-specifier-seq ﻿*(facultatif)* function-body | (2) | | |

  1. Dans une déclaration de fonction membre, override peut apparaître dans virt-specifier-seq immédiatement après le déclarateur, et avant le pure-specifier, si utilisé.

  2. Dans une définition de fonction membre à l'intérieur d'une définition de classe, override peut apparaître dans virt-specifier-seq immédiatement après le déclarateur et juste avant function-body.

Dans les deux cas, virt-specifier-seq, s'il est utilisé, est soit override, soit final, ou final override ou override final.

Explication

Dans une déclaration ou définition de fonction membre, le spécificateur override garantit que la fonction est virtuelle et redéfinit une fonction virtuelle d'une classe de base. Le programme est mal formé (une erreur de compilation est générée) si ce n'est pas le cas.

override est un identifiant à signification particulière lorsqu'il est utilisé après les déclarateurs de fonctions membres ; sinon, ce n'est pas un mot-clé réservé.

Mots-clés

override

Exemple

#include <iostream>

struct A
{
    virtual void foo();
    void bar();
    virtual ~A();
};

// définitions des fonctions membres de la struct A :
void A::foo() { std::cout << "A::foo();\n"; }
A::~A() { std::cout << "A::~A();\n"; }

struct B : A
{
//  void foo() const override; // Erreur : B::foo ne redéfinit pas A::foo
                               // (signature différente)
    void foo() override; // OK : B::foo redéfinit A::foo
//  void bar() override; // Erreur : A::bar n'est pas virtuelle
    ~B() override; // OK : `override` peut aussi être appliqué à des
                   // fonctions membres spéciales, par ex. les destructeurs
    void override(); // OK, nom de fonction membre, pas un mot-clé réservé
};

// définitions des fonctions membres de la struct B :
void B::foo() { std::cout << "B::foo();\n"; }
B::~B() { std::cout << "B::~B();\n"; }
void B::override() { std::cout << "B::override();\n"; }

int main()
{
    B b;
    b.foo();
    b.override(); // OK, appelle la fonction membre `override()`
    int override{42}; // OK, définit une variable entière
    std::cout << "override: " << override << '\n';
}

Output:

B::foo();
B::override();
override: 42
B::~B();
A::~A();
