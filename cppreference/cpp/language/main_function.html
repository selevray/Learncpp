Fonction principale

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un programme doit contenir une fonction globale nommée main, qui est le point d'entrée désigné du programme dans un environnement hébergé. Elle doit prendre l'une des formes suivantes :

| | | | int main() { body } | (1) | | | | int main(int argc, char* argv[]) { body } | (2) | | | | int main(/* défini par l'implémentation */) { body } | (3) | | |

  1. Une fonction main s'exécutant indépendamment des arguments fournis par l'environnement.

  2. Une fonction main acceptant des arguments fournis par l'environnement.

Les noms de argc et argv sont arbitraires, de même que la représentation des types des paramètres : int main(int ac, char** av) est tout aussi valide.

  1. Une fonction main d'un type défini par l'implémentation, renvoyant int.

La norme C++ recommande aux fonctions main définies par l'implémentation de placer les paramètres supplémentaires (facultatifs) après argv.

  • argc — Valeur non négative représentant le nombre d'arguments passés au programme depuis l'environnement dans lequel le programme est exécuté.
  • argv — Pointeur vers le premier élément d'un tableau de argc + 1 pointeurs, dont le dernier est un pointeur nul et les précédents, s'il y en a, pointent vers des chaînes multioctets terminées par un caractère nul qui représentent les arguments passés au programme depuis l'environnement d'exécution. Si argv[0] n'est pas un pointeur nul (ou, de manière équivalente, si argc > 0), il pointe vers une chaîne représentant le nom utilisé pour invoquer le programme, ou vers une chaîne vide.
  • body — Le corps de la fonction main.

Explication

La fonction main est appelée au démarrage du programme, après l'initialisation des objets non locaux à durée de stockage statique. C'est le point d'entrée désigné d'un programme exécuté dans un environnement hébergé (c'est-à-dire avec un système d'exploitation). Les points d'entrée des programmes autonomes (chargeurs de démarrage, noyaux de système d'exploitation, etc.) sont définis par l'implémentation.

Les paramètres de la forme à deux paramètres de la fonction main permettent de transmettre depuis l'environnement d'exécution des chaînes multioctets arbitraires (on les appelle généralement arguments de la ligne de commande), les pointeurs argv[1] .. argv[argc - 1] pointent vers les premiers caractères de chacune de ces chaînes. argv[0] (s'il est non nul) est le pointeur vers le premier caractère d'une chaîne multioctet terminée par un caractère nul qui représente le nom utilisé pour invoquer le programme lui-même (ou une chaîne vide "" si cela n'est pas pris en charge par l'environnement d'exécution). Les chaînes sont modifiables, bien que ces modifications ne se propagent pas à l'environnement d'exécution : elles peuvent être utilisées, par exemple, avec std::strtok. La taille du tableau pointé par argv est au moins argc + 1, et son dernier élément, argv[argc], est garanti être un pointeur nul.

La fonction main possède les plusieurs propriétés spéciales suivantes :

  1. Le corps de la fonction main n'a pas besoin de contenir l'return instruction : si le contrôle atteint la fin de main sans rencontrer d'instruction return, l'effet est celui de l'exécution de return 0;.

  2. L'exécution du return (ou le return implicite à la fin de main) équivaut à d'abord quitter la fonction normalement (ce qui détruit les objets à durée de stockage automatique) puis à appeler std::exit avec le même argument que celui du return (std::exit détruit alors les objets statiques et termine le programme).

La fonction main a plusieurs restrictions (dont la violation rend le programme mal formé) :

  1. Elle ne peut pas être nommée à aucun endroit du programme

a) en particulier, elle ne peut pas être appelée récursivement

b) son adresse ne peut pas être prise

c) elle ne peut pas être utilisée dans une expression typeid ou un spécificateur decltype (depuis C++11)

  1. Elle ne peut pas être prédéfinie ni surchargée : en pratique, le nom main dans l'espace de noms global est réservé aux fonctions (bien qu'il puisse servir à nommer des classes, des espaces de noms, des énumérations et toute entité dans un espace de noms non global, sauf qu'une entité nommée main ne peut pas être déclarée avec une liaison de langage C dans quelque espace de noms que ce soit.

  2. Elle ne peut pas être définie comme supprimée ou (depuis C++11) déclarée avec une liaison de langage quelconque[, constexpr (depuis C++11) | , consteval (depuis C++20)], inline, ou static.

  1. Le type de retour de la fonction main ne peut pas être déduit (auto main() {...} n'est pas autorisé).

(depuis C++14)

  1. La fonction main ne peut pas être une coroutine.

(depuis C++20)

  1. La fonction main ne peut pas être rattachée à un module nommé.

(depuis C++20)

Notes

Si la fonction main est définie avec un bloc function try, les exceptions levées par les destructeurs des objets statiques (détruits par l'std::exit implicite) ne sont pas capturées par celui-ci.

La manière dont les arguments fournis sur la ligne de commande du système d'exploitation sont convertis en tableaux de caractères multioctets référencés par argv peut impliquer un traitement défini par l'implémentation :

  • Analyse des arguments de la ligne de commande C++ MSDN
  • Introduction au shell POSIX

Une forme très courante, définie par l'implémentation, de main() possède un troisième argument (en plus de argc et argv), de type char**, pointant vers un tableau de pointeurs vers les variables d'environnement d'exécution.

Exemple

Montre comment informer un programme de l'endroit où trouver ses entrées et où écrire ses résultats.
Un appel possible : ./convert table_in.dat table_out.dat

#include <cstdlib>
#include <iomanip>
#include <iostream>

int main(int argc, char *argv[])
{
    std::cout << "argc == " << argc << '\n';

    for (int ndx{}; ndx != argc; ++ndx)
        std::cout << "argv[" << ndx << "] == " << std::quoted(argv[ndx]) << '\n';
    std::cout << "argv[" << argc << "] == "
              << static_cast<void*>(argv[argc]) << '\n';

    /* ... */

    return argc == 3 ? EXIT_SUCCESS : EXIT_FAILURE; // valeur de retour facultative
}

Sortie possible :

argc == 3
argv[0] == "./convert"
argv[1] == "table_in.dat"
argv[2] == "table_out.dat"
argv[3] == 0
