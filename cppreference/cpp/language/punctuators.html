Voici les symboles de ponctuation du C++. La signification de chaque symbole est détaillée dans les pages liées.

Opérateurs de préprocesseur

Les opérateurs de préprocesseur sont reconnus par les préprocesseurs.

# (y compris %:)

  • Introduit une directive de préprocesseur.
  • L'opérateur de préprocesseur de transformation en chaîne.

## (y compris %:%:)

  • L'opérateur de préprocesseur de concaténation de jetons.

Opérateurs et signes de ponctuation à un seul caractère

{ et } (y compris <% et %>)

  • Dans une définition de classe, délimiter la spécification des membres.
  • Dans une définition d'énumération, délimiter la liste des énumérateurs.
  • Délimiter une instruction composée. L'instruction composée peut faire partie
    • une définition de fonction
    • d'un try bloc
  • d'une expression lambda

(depuis C++11)

  • Partie de la syntaxe [d'initialisation agrégée (jusqu'à C++11) | d'initialisation par liste (depuis C++11)] d'un initialiseur.
  • Dans une définition d'espace de noms, délimiter le corps de l'espace de noms.
  • Dans une spécification de liaison de langage, délimiter les déclarations.
  • Dans une expression requires, délimiter les exigences.
  • Dans une exigence composée, délimiter l'expression.
  • Dans une déclaration d'exportation, délimiter les déclarations.

(depuis C++20)

[ et ] (y compris <: et :>)

  • Opérateur d'indexation ; partie de operator[] dans la surcharge d'opérateurs.
  • Partie du déclarateur de tableau dans une déclaration ou un type-id (par ex. dans une new expression).
  • Partie de l'opérateur new[] dans la surcharge d'opérateurs (fonction d'allocation).
  • Partie de l'opérateur delete[] dans l'expression delete et la surcharge d'opérateurs (fonction de désallocation).
  • Dans une expression lambda, délimiter les captures.
  • Dans un spécificateur d'attribut, délimiter les attributs.

(depuis C++11)

  • Dans une déclaration de liaison structurée, délimiter la liste des identificateurs.

(depuis C++17)

  • Dans un indexage de pack, délimiter l'expression constante convertie représentant un indice.

(depuis C++26)

( and )

  • Dans une expression, indiquer le regroupement.
  • Opérateur d'appel de fonction ; partie de operator() dans la surcharge d'opérateurs.
  • Dans un transtypage de style fonctionnel, délimiter l'expression ou les initialiseurs.
  • Dans un static_cast, const_cast, reinterpret_cast ou dynamic_cast, délimiter l'expression.
  • Délimiter l'opérande des opérateurs suivants :
    • typeid
    • sizeof
  • sizeof...
  • alignof
  • noexcept

(depuis C++11)

  • Dans une expression new de placement, délimiter les arguments de placement.
  • Dans une expression new, délimiter optionnellement le type-id.
  • Dans une expression new, délimiter les initialiseurs.
  • Dans un transtypage de style C, délimiter le type-id.
  • Dans une déclaration ou un type-id, indiquer le regroupement.
  • Délimiter la liste des paramètres dans
    • un déclarateur de fonction (dans une déclaration ou un type-id)
  • d'une expression lambda

(depuis C++11)

  • un guide de déduction défini par l'utilisateur

(depuis C++17)

  • une requires expression

(depuis C++20)

  • Partie de la syntaxe d'initialisation directe d'un initialiseur.
  • Dans une déclaration asm, délimiter le littéral de chaîne.
  • Dans une liste d'initialisation des membres, délimiter les initialiseurs d'une base ou d'un membre.
  • Délimiter la clause de contrôle d'une instruction de sélection ou d'itération, y compris :
    • if(sauf consteval if) (depuis C++23)
    • switch
    • while
    • do-while
    • for
  • for basée sur un intervalle

(depuis C++11)

  • Dans un gestionnaire, délimiter la déclaration du paramètre.
  • Dans une définition de macro de type fonction, délimiter les paramètres de la macro.
  • Dans une invocation de macro de type fonction, délimiter les arguments de la macro ou empêcher que les virgules soient interprétées comme séparateurs d'arguments.
  • Partie de l'opérateur de prétraitement defined[, __has_include (depuis C++17) | , __has_cpp_attribute (depuis C++20)].
  • Dans une déclaration static_assert, délimiter les opérandes.
  • Délimiter l'opérande des spécificateurs suivants :
  • decltype
  • noexcept
  • alignas
  • explicit

(depuis C++20)

  • Dans un attribut, délimiter les arguments de l'attribut.

(depuis C++11)

  • Partie du spécificateur decltype(auto).

(depuis C++14)

  • Délimiter une expression de pliage.

(depuis C++17)

  • Partie du remplacement __VA_OPT__ dans une définition de macro variadique.

(depuis C++20)

;

  • Indiquer la fin
    • d'une instruction
    • d'une déclaration ou d'une déclaration de membre
  • d'une déclaration de module, d'une déclaration d'importation, d'un introducteur de fragment de module global ou d'un introducteur de fragment de module privé
  • d'une exigence

(depuis C++20)

  • Séparer le condition et le statement d'une instruction for.

:

  • Partie de l'opérateur conditionnel.
  • Partie de la déclaration d'étiquette.
  • Dans le base-clause d'une définition de classe, introduire la classe de base.
  • Partie du spécificateur d'accès dans la spécification des membres.
  • Dans une déclaration de membre à champ de bits, introduire la largeur.
  • Dans une définition de constructeur, introduire la liste d'initialisation des membres.
  • Dans une instruction for basée sur un intervalle, séparer le item-declaration et le range-initializer.
  • Dans le enum-base d'une déclaration d'énumération, introduire le type sous-jacent.

(depuis C++11)

  • Dans un spécificateur d'attribut, séparer le attribute-namespace et le attribute-list.

(depuis C++17)

  • Dans une déclaration de module ou une déclaration d'importation de partition de module, introduire le nom de la partition de module.
  • Partie de l'introducteur d'un fragment de module privé (module :private;).

(depuis C++20)

?

  • Partie de l'opérateur conditionnel.

.

  • Opérateur d'accès membre.
  • Dans une initialisation agrégée, introduire un désignateur.
  • Partie d'un nom de module ou nom de partition de module.

(depuis C++20)

~ (y compris compl)

  • Opérateur de complément unaire (aussi appelé opérateur de non bit à bit) ; partie de operator~ dans la surcharge d'opérateurs.
  • Partie d'une expression d'identifiant désignant un destructeur ou un pseudo-destructeur.

! (y compris not)

  • Opérateur de négation logique ; partie de operator! dans la surcharge d'opérateurs.
  • Partie de l'instruction consteval if.

(depuis C++23)

+

  • Opérateur plus unaire ; partie de operator+ dans la surcharge d'opérateurs.
  • Opérateur plus binaire ; partie de operator+ dans la surcharge d'opérateurs.

-

  • Opérateur moins unaire ; partie de operator- dans la surcharge d'opérateurs.
  • Opérateur moins binaire ; partie de operator- dans la surcharge d'opérateurs.

*

  • Opérateur d'indirection ; partie de operator* dans la surcharge d'opérateurs.
  • Opérateur de multiplication ; partie de operator* dans surcharge d'opérateurs.
  • Opérateur de pointeur ou partie de l'opérateur de pointeur vers membre dans un déclarateur ou dans un type-id.
  • Partie de *this dans une liste de capture lambda, pour capturer l'objet courant par copie.

(depuis C++17)

/

  • Opérateur de division ; partie de operator/ dans surcharge d'opérateurs.

%

  • Opérateur modulo ; partie de operator% dans surcharge d'opérateurs.

^ (y compris xor)

  • Opérateur de OU exclusif bit à bit ; partie de operator^ dans surcharge d'opérateurs.

& (y compris bitand)

  • Opérateur d'adresse ; partie de operator& dans surcharge d'opérateurs.
  • Opérateur de ET bit à bit ; partie de operator& dans surcharge d'opérateurs.
  • Opérateur de référence lvalue dans un déclarateur ou dans un type-id.
  • Dans une capture lambda, indique une capture par référence.
  • Qualificateur de référence dans une déclaration de fonction membre.

(depuis C++11)

| (y compris bitor)

  • Opérateur de OU bit à bit ; partie de operator| dans surcharge d'opérateurs.

=

  • Opérateur d'affectation simple ; partie de operator= dans surcharge d'opérateurs, qui peut être une fonction membre spéciale (opérateur d'affectation par copieou opérateur d'affectation par déplacement (depuis C++11)).
  • Partie de l'initialisation par copie et de la syntaxe [initialisation d'agrégat (jusqu'à C++11) | initialisation par copie de liste (depuis C++11)] d'un initialiseur.
  • Dans une déclaration de fonction, introduit un argument par défaut.
  • Dans une liste de paramètres de modèle, introduit un argument de modèle par défaut.
  • Dans une définition d'alias d'espace de noms, sépare l'alias et l'espace de noms aliasé.
  • Dans une définition d'énumération, introduit la valeur de l'énumérateur.
  • Partie de pure-specifier dans une déclaration de fonction virtuelle pure.
  • Capture par défaut dans une capture lambda, pour indiquer une capture par copie.
  • Partie de la définition par défaut (=default;) ou de la définition supprimée (=delete;) dans une définition de fonction.
  • Dans une déclaration d'alias de type, sépare l'alias et le type aliasé.

(depuis C++11)

  • Dans une définition de concept, sépare le nom du concept et l'expression de contrainte.

(depuis C++20)

<

  • Opérateur inférieur à ; partie de operator< dans surcharge d'opérateurs.
  • Dans un static_cast, const_cast, reinterpret_cast ou dynamic_cast, introduit le type-id.
  • Introduit une liste d'arguments de modèle.
  • Introduit une liste de paramètres de modèle dans
    • une déclaration de modèle
    • une spécialisation partielle
  • d'une expression lambda

(depuis C++20)

  • Partie de template<> dans une déclaration de spécialisation de modèle.
  • Introduit un nom d'en-tête dans
    • une directive #include
  • une expression de prétraitement __has_include

(depuis C++17)

  • une déclaration import

(depuis C++20)

>

  • Opérateur supérieur à ; partie de operator> dans surcharge d'opérateurs.
  • Dans un static_cast, const_cast, reinterpret_cast ou dynamic_cast, indique la fin du type-id.
  • Indique la fin d'une liste d'arguments de modèle.
  • Indique la fin d'une liste de paramètres de modèle dans
    • une déclaration de modèle
    • une spécialisation partielle
  • d'une expression lambda

(depuis C++20)

  • Partie de template<> dans une déclaration de spécialisation de modèle.
  • Indique la fin d'un nom d'en-tête dans
    • une directive #include
  • une expression de prétraitement __has_include

(depuis C++17)

  • une déclaration import

(depuis C++20)

,

  • Opérateur virgule ; partie de operator, dans surcharge d'opérateurs.
  • Séparateur de liste dans
    • la liste de déclarateurs d'une déclaration
    • la liste d'initialiseurs dans une initialisation
    • la liste d'arguments de placement d'un new avec placement
    • la liste d'arguments d'une expression d'appel de fonction
    • la liste d'énumérateurs d'une déclaration enum
    • la liste des classes de base d'une déclaration de classe
    • la liste d'initialisation des membres d'une définition de constructeur
    • une liste de paramètres de fonction
    • une liste de paramètres de modèle
    • une liste d'arguments de modèle
  • une liste de captures lambda
  • une liste d'attributs

(depuis C++11)

  • la liste de déclarateurs d'une déclaration using
  • la liste d'identifiants d'une déclaration de liaison structurée

(depuis C++17)

  • la liste d'arguments d'une expression d'indexation à plusieurs arguments

(depuis C++23)

  • la liste de paramètres de macro d'une définition de macro de type fonction
  • la liste d'arguments de macro d'un appel de macro de type fonction, sauf si elle se trouve entre les parenthèses d'un argument
  • Dans une déclaration static_assert, sépare les arguments.

(depuis C++11)

Opérateurs et séparateurs multi-caractères

...

  • Dans la liste de paramètres d'un déclarateur de fonction[ou d'une expression lambda (depuis C++11) | ou d'un guide de déduction défini par l'utilisateur (depuis C++17)], indique une fonction variadique.
  • Dans un gestionnaire, indique un gestionnaire attrape-tout.
  • Dans une définition de macro, indique une macro variadique.
  • Indique la déclaration et l'expansion d'un pack.

(depuis C++11)

  • Dans une expression et un spécificateur d'indexation de pack.

(depuis C++26)

::

  • Opérateur de résolution de portée dans
    • un nom qualifié
    • une déclaration de pointeur vers membre
    • une expression new ou delete, pour indiquer que seules les fonctions d'allocation ou de désallocation globales sont recherchées
  • Dans un attribut, indique la portée de l'attribut.

(depuis C++11)

  • Partie d'une définition d'espace de noms imbriqué.

(depuis C++17)

.*

  • Opérateur d'accès à membre par pointeur.

->

  • Opérateur d'accès à membre ; partie de operator-> dans surcharge d'opérateurs.
  • Dans un déclarateur de fonction ou une expression lambda, introduit le type de retour final.

(depuis C++11)

  • Dans un guide de déduction défini par l'utilisateur, introduit le type de résultat.

(depuis C++17)

  • Dans une exigence composée, introduit l'exigence sur le type de retour.

(depuis C++20)

->*

  • Opérateur d'accès à membre par pointeur ; partie de operator->* dans surcharge d'opérateurs.

+=

  • Opérateur d'affectation composé ; partie de operator+= dans surcharge d'opérateurs.

-=

  • Opérateur d'affectation composé ; partie de operator-= dans surcharge d'opérateurs.

*=

  • Opérateur d'affectation composé ; partie de operator*= dans surcharge d'opérateurs.

/=

  • Opérateur d'affectation composé ; partie de operator/= dans surcharge d'opérateurs.

%=

  • Opérateur d'affectation composé ; partie de operator%= dans surcharge d'opérateurs.

^= (y compris xor_eq)

  • Opérateur d'affectation composé ; partie de operator^= dans surcharge d'opérateurs.

&= (y compris and_eq)

  • Opérateur d'affectation composé ; partie de operator&= dans surcharge d'opérateurs.

|= (y compris or_eq)

  • Opérateur d'affectation composé ; partie de operator|= dans surcharge d'opérateurs.

==

  • Opérateur d'égalité ; partie de operator== dans surcharge d'opérateurs.

!= (y compris not_eq)

  • Opérateur d'inégalité ; partie de operator!= dans surcharge d'opérateurs.

<=

  • Opérateur inférieur ou égal ; partie de operator<= dans surcharge d'opérateurs.

>=

  • Opérateur supérieur ou égal ; partie de operator>= dans surcharge d'opérateurs.

<=>

  • Opérateur de comparaison à trois voies (spaceship) ; partie de operator<=> dans surcharge d'opérateurs.

(depuis C++20)

&& (y compris and)

  • Opérateur et logique ; partie de operator&& dans surcharge d'opérateurs.
  • Opérateur de référence rvalue dans un déclarateur ou dans un type-id.
  • Qualificateur de référence dans une déclaration de fonction membre.

(depuis C++11)

|| (y compris or)

  • Opérateur ou logique ; partie de operator|| dans surcharge d'opérateurs.

<<

  • Opérateur de décalage binaire ; partie de operator<< dans la surcharge d'opérateurs (opérateur binaire ou opérateur d'insertion dans un flux).

>>

  • Opérateur de décalage binaire ; partie de operator>> dans la surcharge d'opérateurs (opérateur binaire ou opérateur d'extraction d'un flux).

<<=

  • Opérateur d'affectation composé ; partie de operator<<= dans surcharge d'opérateurs.

>>=

  • Opérateur d'affectation composé ; partie de operator>>= dans surcharge d'opérateurs.

++

  • Opérateur d'incrémentation ; partie de operator++ dans surcharge d'opérateurs.

--
