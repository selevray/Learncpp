Attribut C++ : maybe_unused (depuis C++17)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Supprime les avertissements sur les entités non utilisées.

Syntaxe

| | | | [[maybe_unused]] | | | |

Explication

Cet attribut peut apparaître dans la déclaration des entités suivantes :

  • class/struct/union : struct [[maybe_unused]] S;
  • typedef, y compris ceux déclarés par déclaration d'alias : [[maybe_unused]] typedef S* PS;, using PS [[maybe_unused]] = S*;
  • variable, y compris membre donnée statique : [[maybe_unused]] int x;
  • membre donnée non statique : union U { [[maybe_unused]] int n; };,
  • fonction : [[maybe_unused]] void f();
  • énumération : enum [[maybe_unused]] E {};
  • enumerator: enum { A [[maybe_unused]], B [[maybe_unused]] = 42 };
  • liaison structurée : [[maybe_unused]] auto [a, b] = std::make_pair(42, 0.23);

Pour les entités déclarées [[maybe_unused]], si les entités ou leurs liaisons structurées ne sont pas utilisées, l'avertissement sur les entités non utilisées émis par le compilateur est supprimé.

Pour les labels déclarés [[maybe_unused]], s'ils ne sont pas utilisés, l'avertissement sur les labels non utilisés émis par le compilateur est supprimé.

(depuis C++26)

Exemple

#include <cassert>

[[maybe_unused]] void f([[maybe_unused]] bool thing1,
                        [[maybe_unused]] bool thing2)
{
    [[maybe_unused]] lb: // le label « lb » n'est pas utilisé, aucun avertissement
    [[maybe_unused]] bool b = thing1 && thing2;
    assert(b); // en mode release, assert est supprimé à la compilation, et « b » n'est pas utilisé
               // aucun avertissement car il est déclaré [[maybe_unused]]
} // les paramètres « thing1 » et « thing2 » ne sont pas utilisés, aucun avertissement

int main() {}
