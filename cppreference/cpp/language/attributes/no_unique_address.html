Attribut C++ : no_unique_address (depuis C++20)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Permet à ce membre donnée de se chevaucher avec d'autres membres données non statiques ou sous-objets de classe de base de sa classe.

Syntaxe

| | | | [[no_unique_address]] | | | |

Explication

S'applique au nom déclaré dans la déclaration d'un membre donnée non statique qui n'est pas un champ de bits.

Rend ce sous-objet membre potentiellement chevauchant, c'est-à-dire qu'il permet à ce membre de se chevaucher avec d'autres membres données non statiques ou sous-objets de classe de base de sa classe. Cela signifie que si le membre a un type de classe vide (par ex. allocateur sans état), le compilateur peut l'optimiser pour qu'il n'occupe aucun espace, comme s'il s'agissait d'une base vide. Si le membre n'est pas vide, tout rembourrage de fin qu'il contient peut également être réutilisé pour stocker d'autres membres données.

Notes

[[no_unique_address]] est ignoré par MSVC même en mode C++20 ; à la place, [[msvc::no_unique_address]] est fourni.

Exemple

#include <iostream>

struct Empty {}; // classe vide

struct X
{
    int i;
    Empty e;
};

struct Y
{
    int i;
    [[no_unique_address]] Empty e;
};

struct Z
{
    char c;
    [[no_unique_address]] Empty e1, e2;
};

struct W
{
    char c[2];
    [[no_unique_address]] Empty e1, e2;
};

int main()
{
    // la taille de tout objet de type classe vide vaut au moins 1
    static_assert(sizeof(Empty) >= 1);

    // au moins un octet supplémentaire est nécessaire pour donner à e une adresse unique
    static_assert(sizeof(X) >= sizeof(int) + 1);

    // membre vide optimisé
    std::cout << "sizeof(Y) == sizeof(int) is " << std::boolalpha
              << (sizeof(Y) == sizeof(int)) << '\n';

    // e1 et e2 ne peuvent pas partager la même adresse car ils ont le
    // même type, bien qu'ils soient marqués [[no_unique_address]].
    // Cependant, l'un ou l'autre peut partager l'adresse de c.
    static_assert(sizeof(Z) >= 2);

    // e1 et e2 ne peuvent pas avoir la même adresse, mais l'un d'eux peut partager avec
    // c[0] et l'autre avec c[1]
    std::cout << "sizeof(W) == 2 is " << (sizeof(W) == 2) << '\n';
}

Sortie possible :

sizeof(Y) == sizeof(int) is true
sizeof(W) == 2 is true
