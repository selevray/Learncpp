Attribut C++ : noreturn (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Indique que la fonction ne retourne pas.

Syntaxe

| | | | [[noreturn]] | | | |

Explication

Indique que la fonction ne rendra pas le contrôle du flot à la fonction appelante après sa fin (par exemple les fonctions qui terminent l'application, lèvent des exceptions, bouclent indéfiniment, etc.). Cet attribut ne s'applique qu'au nom de la fonction déclarée dans les déclarations de fonction.

Si une fonction précédemment déclarée avec [[noreturn]] est invoquée et que cet appel finit par retourner, le comportement est indéfini à l'exécution.

La première déclaration de la fonction doit spécifier cet attribut si une déclaration le spécifie. Si une fonction est déclarée avec [[noreturn]] dans une unité de traduction, et la même fonction est déclarée sans [[noreturn]] dans une autre unité de traduction, le programme est mal formé ; aucun diagnostic requis.

Exemple

[[noreturn]] void f()
{
    throw "error";
    // OK
}

void q [[noreturn]] (int i)
{
    // le comportement est indéfini si appelé avec un argument <= 0
    if (i > 0)
        throw "positive";
}

// void h() [[noreturn]]; // erreur : attribut appliqué au type de fonction de h, et non à h lui-même

int main()
{
    try { f(); } catch(...) {}
    try { q(42); } catch(...) {}
}

Bibliothèque standard

Les fonctions standard suivantes sont déclarées avec l'attribut noreturn :

##### Fonctions de terminaison {#Terminating_functions}

  • _Exit (C++11) — provoque une fin normale du programme sans nettoyage (fonction)
  • abort — provoque une terminaison anormale du programme (sans nettoyage) (fonction)
  • exit — provoque une fin normale du programme avec nettoyage (fonction)
  • quick_exit (C++11) — provoque une fin rapide du programme sans nettoyage complet (fonction)
  • terminate — fonction appelée lorsque la gestion des exceptions échoue (fonction)
  • unexpected (deprecated in C++11) (removed in C++17) — fonction appelée lorsque la spécification d'exception dynamique est violée (fonction)

##### Indications pour le compilateur {#Compiler_hints}

  • unreachable (C++23) — marque un point d'exécution inatteignable (fonction)

##### Fonctions lançant toujours une exception {#Always-throwing_functions}

  • rethrow_exception (C++11) — lève l'exception depuis un std::exception_ptr (fonction)
  • rethrow_nested — lève l'exception stockée (fonction membre publique de std::nested_exception)
  • throw_with_nested (C++11) — lève son argument avec std::nested_exception mélangé à (modèle de fonction)

##### Sauts non locaux (depuis C++17) {#Non-local_jumps_.28since_C.2B.2B17.29}

  • longjmp — saute à l'emplacement spécifié (fonction)
