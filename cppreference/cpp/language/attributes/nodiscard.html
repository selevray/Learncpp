Attribut C++ : nodiscard (depuis C++17)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Si une fonction déclarée nodiscard ou une fonction renvoyant une énumération ou une classe déclarée nodiscard par valeur est appelée depuis une expression à valeur ignorée autre qu'un transtypage vers void, le compilateur est encouragé à émettre un avertissement.

Syntaxe

| | | | [[nodiscard]] | (1) | (depuis C++17) | | | [[nodiscard( string-literal )]] | (2) | (depuis C++20) | |

  • string-literal — une chaîne littérale non évaluée pouvant servir à expliquer la raison pour laquelle le résultat ne doit pas être ignoré

Explication

Apparaît dans une déclaration de fonction, une déclaration d'énumération ou une déclaration de classe.

Si, depuis une expression à valeur ignorée autre qu'un transtypage vers void,

  • une fonction déclarée nodiscard est appelée, ou
  • une fonction renvoyant une énumération ou une classe déclarée nodiscard par valeur est appelée, ou
  • un constructeur déclaré nodiscard est appelé par conversion de type explicite ou static_cast, ou
  • un objet d'un type énumération ou classe déclaré nodiscard est initialisé par conversion de type explicite ou static_cast,

le compilateur est encouragé à émettre un avertissement.

Le string-literal, s'il est spécifié, est généralement inclus dans les avertissements.

(depuis C++20)

Exemple

struct [[nodiscard]] error_info { /*...*/ };

error_info enable_missile_safety_mode() { /*...*/ return {}; }

void launch_missiles() { /*...*/ }

void test_missiles()
{
    enable_missile_safety_mode(); // le compilateur peut émettre un avertissement lorsqu'une valeur nodiscard est ignorée
    launch_missiles();
}

error_info& foo() { static error_info e; /*...*/ return e; }

void f1() { foo(); } // un type nodiscard n'est pas renvoyé par valeur, aucun avertissement

// nodiscard( string-literal ) (depuis C++20) :
[[nodiscard("PURE FUN")]] int strategic_value(int x, int y) { return x ^ y; }

int main()
{
    strategic_value(4, 2); // le compilateur peut émettre un avertissement lorsqu'une valeur nodiscard est ignorée
    auto z = strategic_value(0, 0); // OK : la valeur de retour n'est pas ignorée
    return z;
}
