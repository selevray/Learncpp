Attribut C++ : optimize_for_synchronized (TM TS)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Indique que la définition de la fonction doit être optimisée pour un appel depuis une instruction synchronized.

Syntaxe

| | | | [[optimize_for_synchronized]] | | | |

Explication

S'applique au nom déclaré dans une déclaration de fonction, qui doit être la première déclaration de la fonction.

Indique que la définition de la fonction doit être optimisée pour un appel depuis une instruction synchronized. En particulier, elle évite de sérialiser les blocs synchronized qui appellent une fonction sûre pour les transactions dans la majorité des appels, mais pas dans tous.
