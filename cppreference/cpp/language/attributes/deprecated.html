Attribut C++ : deprecated (depuis C++14)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Indique que le nom ou l'entité déclaré avec cet attribut est obsolète, c'est-à-dire que son utilisation est autorisée, mais déconseillée pour une raison quelconque.

Syntaxe

| | | | [[deprecated]] | (1) | | | | [[deprecated( string-literal )]] | (2) | | |

  • string-literal — un littéral de chaîne non évalué pouvant servir à expliquer la justification de l'obsolescence et/ou à suggérer une entité de remplacement

Explication

Indique que l'utilisation du nom ou de l'entité déclaré avec cet attribut est autorisée, mais déconseillée pour une raison quelconque. Les compilateurs émettent généralement des avertissements pour de tels usages. Le string-literal, s'il est spécifié, figure généralement dans les avertissements.

Cet attribut est autorisé dans les déclarations des noms ou entités suivants :

  • class/struct/union, par exemple struct [[deprecated]] S;,

  • nom de typedef, y compris ceux déclarés par une déclaration d'alias, par exemple,

    • [[deprecated]] typedef S* PS;,
    • using PS [[deprecated]] = S*;,

  • variable (non membre), par exemple [[deprecated]] int x;,

  • membre de donnée statique, par exemple struct S { [[deprecated]] static constexpr char CR{13}; };,

  • membre de donnée non statique, par exemple union U { [[deprecated]] int n; };,

  • fonction, par exemple [[deprecated]] void f();,

  • espace de noms, par exemple namespace [[deprecated]] NS { int x; },

  • énumération, par exemple enum [[deprecated]] E {};,

  • énumérateur, par ex. enum { A [[deprecated]], B [[deprecated]] = 42 };,

(depuis C++17)

  • spécialisation de modèle, par ex. template<> struct [[deprecated]] X<int> {};.

Un nom déclaré non obsolète peut être redéclaré obsolète. Un nom déclaré obsolète ne peut pas être rendu non obsolète en le redéclarant sans cet attribut.

Exemple

#include <iostream>

[[deprecated]]
void TriassicPeriod()
{
    std::clog << "Triassic Period: [251.9 - 208.5] million years ago.\n";
}

[[deprecated("Use NeogenePeriod() instead.")]]
void JurassicPeriod()
{
    std::clog << "Jurassic Period: [201.3 - 152.1] million years ago.\n";
}

[[deprecated("Use calcSomethingDifferently(int).")]]
int calcSomething(int x)
{
    return x * 2;
}

int main()
{
    TriassicPeriod();
    JurassicPeriod();
}
