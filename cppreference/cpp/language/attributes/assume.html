Attribut C++ : assume (depuis C++23)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Indique que l'expression donnée est supposée toujours s'évaluer à true en un point donné, afin de permettre des optimisations du compilateur fondées sur l'information fournie.

Syntaxe

| | | | [[assume( expression )]] | | | |

  • expression — toute expression (sauf les expressions à virgule non parenthésées)

Explication

[[assume]] ne peut être appliqué qu'à une instruction nulle, comme dans [[assume(x > 0)]];. Cette instruction est appelée une hypothèse.

expression est convertie contextuellement en bool, mais elle n'est pas évaluée (elle reste toutefois potentiellement évaluée).

  • Si le expression converti s'évaluerait à true au point où apparaît l'hypothèse, l'hypothèse n'a aucun effet.
  • Dans le cas contraire, l'évaluation de l'hypothèse a un comportement indéfini à l'exécution.

Notes

Les hypothèses entraînant un comportement indéfini à l'exécution si elles ne sont pas vérifiées, elles doivent être utilisées avec parcimonie.

Une façon correcte de les utiliser consiste à faire suivre les assertions par des hypothèses :

assert(x > 0);     // déclencher une assertion lorsque NDEBUG n'est pas défini et que x > 0 est faux
[[assume(x > 0)]]; // offrir des opportunités d'optimisation lorsque NDEBUG est défini

Exemple

#include <cmath>

void f(int& x, int y)
{
    void g(int);
    void h();

    [[assume(x > 0)]]; // Le compilateur peut supposer que x est positif

    g(x / 2); // Code potentiellement plus efficace généré

    x = 3;
    int z = x;

    [[assume((h(), x == z))]]; // Le compilateur peut supposer que x aura la même valeur après
                               // l'appel à h
                               // L'hypothèse n'entraîne pas d'appel à h

    h();
    g(x); // Le compilateur peut remplacer ceci par g(3);

    h();
    g(x); // Le compilateur NE PEUT PAS remplacer ceci par g(3);
          // Une hypothèse ne s'applique qu'au point où elle apparaît

    z = std::abs(y);

    [[assume((g(z), true))]]; // Le compilateur peut supposer que g(z) retournera

    g(z); // En raison des hypothèses ci-dessus et ci-dessous, le compilateur peut remplacer ceci par g(10);

    [[assume(y == -10)]]; // Comportement indéfini si y != -10 à ce point

    [[assume((x - 1) * 3 == 12)]];

    g(x); // Le compilateur peut remplacer ceci par g(5);
}
