Attribut C++ : indeterminate (depuis C++26)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Indique que la variable ou le paramètre de fonction a une valeur indéterminée s'il n'est pas initialisé.

Syntaxe

| | | | [[indeterminate]] | | | |

Explication

[[indeterminate]] peut être appliqué à la définition d'une variable de bloc à durée de stockage automatique ou à une déclaration de paramètre d'une déclaration de fonction. L'attribut précise que les octets composant le stockage d'un objet à durée de stockage automatique sont initialement indéterminés plutôt qu'erronés.

Si un paramètre de fonction est déclaré avec [[indeterminate]], il doit l'être dans la première déclaration de sa fonction. Si un paramètre de fonction est déclaré avec [[indeterminate]] dans la première déclaration de sa fonction dans une unité de traduction, et que la même fonction est déclarée sans [[indeterminate]] sur ce même paramètre dans sa première déclaration dans une autre unité de traduction, le programme est mal formé, aucun diagnostic requis.

Notes

L'attribut [[indeterminate]] rétablit le comportement indéfini qui était implicitement introduit jusqu'à C++26. Il peut amener les compilateurs à considérer comme inatteignable un chemin de code lisant une valeur indéterminée.

Exemple

void f(int);

void g()
{
    int x [[indeterminate]]; // valeur indéterminée
    int y;                   // valeur erronée

    f(x); // comportement indéfini
    f(y); // comportement erroné
}

struct T
{
    T() {}
    int x;
};

void h(T a [[indeterminate]], T b)
{
    f(a.x); // comportement indéfini lorsqu'appelé ci-dessous
    f(b.x); // comportement erroné lorsqu'appelé ci-dessous
}

h(T(), T());
