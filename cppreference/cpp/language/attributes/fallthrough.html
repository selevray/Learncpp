Attribut C++ : fallthrough (depuis C++17)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Indique que le passage à travers le label case précédent est intentionnel et ne doit pas être signalé par un compilateur qui émet un avertissement sur fallthrough.

Syntaxe

| | | | [[fallthrough]] | | | |

Explication

Ne peut s'appliquer qu'à une instruction nulle pour créer une instruction fallthrough ([[fallthrough]];).

Une instruction fallthrough ne peut être utilisée que dans une instruction switch, lorsque l'instruction suivante à exécuter est une instruction portant un label case ou default de ce switch. Si l'instruction fallthrough se trouve dans une boucle, l'instruction suivante (étiquetée) doit faire partie de la même itération de cette boucle.

Exemple

void f(int n)
{
    void g(), h(), i();

    switch (n)
    {
        case 1:
        case 2:
            g();
            [[fallthrough]];
        case 3: // aucun avertissement sur fallthrough
            h();
        case 4: // le compilateur peut émettre un avertissement sur fallthrough
            if (n < 3)
            {
                i();
                [[fallthrough]]; // OK
            }
            else
            {
                return;
            }
        case 5:
            while (false)
            {
                [[fallthrough]]; // mal formé : l'instruction suivante n'est pas
                                 //             partie de la même itération
            }
        case 6:
            [[fallthrough]]; // mal formé, aucun label case ou default suivant
    }
}
