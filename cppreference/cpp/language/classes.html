Classes

Une classe est un type défini par l'utilisateur.

Un type de classe est défini par le class-specifier, qui apparaît dans decl-specifier-seq de la syntaxe de déclaration. Voir déclaration de classe pour la syntaxe du spécificateur de classe.

Une classe peut avoir les genres de membres suivants :

  1. Membres de données :

a) membres de données non statiques, y compris les champs de bits.

b) membres de données statiques

  1. fonctions membres :

a) fonctions membres non statiques

b) fonctions membres statiques

  1. types imbriqués :

a) classes imbriquées et énumérations définies dans la définition de la classe

b) alias de types existants, définis par des déclarations typedef ou type alias (depuis C++11)

c) le nom de la classe dans sa propre définition agit comme alias de type membre public de lui-même à des fins de recherche (sauf lorsqu'il sert à nommer un constructeur) : c'est ce qu'on appelle nom de classe injecté

  1. énumérateurs de toutes les énumérations non scopées définies dans la classe, ou introduits par des déclarations using ou déclarations using enum (depuis C++20)

  2. modèles membres (modèles de variables, *(depuis C++14)*modèles de classes ou modèles de fonctions) peuvent apparaître dans le corps de toute classe/struct/union non locale.

Tous les membres sont définis en une seule fois dans la définition de la classe, ils ne peuvent pas être ajoutés à une classe déjà définie (contrairement aux membres des espaces de noms)

Un membre d'une classe T ne peut pas utiliser T comme nom si le membre est

  • un membre de données statique,
  • une fonction membre,
  • un type membre,
  • un modèle membre,
  • un énumérateur d'une énumération (sauf si l'énumération est à portée) (depuis C++11), ou
  • un membre d'une union anonyme membre.

Cependant, un membre de donnée non statique peut utiliser le nom T tant qu'il n'existe aucun constructeur déclaré par l'utilisateur.

Une classe possédant au moins une fonction membre déclarée ou héritée virtual est polymorphe. Les objets de ce type sont des objets polymorphes et possèdent des informations de type à l'exécution stockées dans la représentation de l'objet, auxquelles on peut accéder avec dynamic_cast et typeid. Les fonctions membres virtuelles participent à la liaison dynamique.

Une classe possédant au moins une fonction membre virtuelle pure déclarée ou héritée est une classe abstraite. Les objets de ce type ne peuvent pas être créés.

Une classe possédant un constructeur constexpr est une LiteralType : les objets de ce type peuvent être manipulés par des fonctions constexpr à la compilation.

(depuis C++11)

Propriétés des classes

Classe trivialement copiable

Une classe trivialement copiable est une classe qui

  • possède au moins un constructeur de copie admissible, constructeur de déplacement, opérateur d'affectation par copie, ou opérateur d'affectation par déplacement,
  • chaque constructeur de copie admissible est trivial
  • chaque constructeur de déplacement admissible est trivial
  • chaque opérateur d'affectation par copie admissible est trivial
  • chaque opérateur d'affectation par déplacement admissible est trivial, et
  • possède un destructeur trivial non supprimé.

Classe triviale

Une classe triviale est une classe qui

  • est trivialement copiable, et
  • possède un ou plusieurs constructeurs par défaut admissibles tels que chacun est trivial.

(obsolète depuis C++26)

Classe à disposition standard

Une classe à disposition standard est une classe qui

  • ne possède aucun membre de donnée non statique de type classe sans disposition standard (ou tableau de tels types) ni de référence,
  • ne possède aucune fonction virtuelle ni aucune classe de base virtuelle,
  • possède le même contrôle d'accès pour tous les membres de donnée non statiques,
  • ne possède aucune classe de base sans disposition standard,
  • seule une classe de la hiérarchie possède des membres de donnée non statiques, et
  • De manière informelle, aucune des classes de base n'a le même type que le premier membre de donnée non statique. Ou, formellement : en notant la classe S, elle ne possède aucun élément de l'ensemble M(S) de types en tant que classe de base, où M(X) pour un type X est défini ainsi :
  • Si X est un type classe non union sans membre de donnée non statique (éventuellement hérité), l'ensemble M(X) est vide.
  • Si X est un type classe non union dont le premier membre de donnée non statique a le type X0 (ce membre pouvant être une union anonyme), l'ensemble M(X) est constitué de X0 et des éléments de M(X0).
  • Si X est un type union, l'ensemble M(X) est l'union de tous les M(Ui) et de l'ensemble contenant tous les Ui, où chaque Ui est le type du i-ème membre de donnée non statique de X.
  • Si X est un type tableau de type d'élément Xe, l'ensemble M(X) est constitué de Xe et des éléments de M(Xe).
  • Si X est un type qui n'est ni une classe ni un tableau, l'ensemble M(X) est vide.

Une structure à disposition standard est une classe à disposition standard définie avec le mot-clé class struct ou le mot-clé class class. Une union à disposition standard est une classe à disposition standard définie avec le mot-clé class union.

(depuis C++11)

Classe à durée de vie implicite

Une classe à durée de vie implicite est une classe qui

  • est un agrégat dont le destructeur n'est pas [déclaré par l'utilisateur (jusqu'à C++11) | défini par l'utilisateur (depuis C++11)], ou
  • possède au moins un constructeur admissible trivial et un destructeur trivial non supprimé.

Remarques : la propriété de durée de vie implicite est précisée par le rapport de défaut P0593R6.

Classe POD

Une classe POD est une classe qui

  • est un agrégat,
  • ne possède aucun opérateur d'affectation par copie déclaré par l'utilisateur,
  • ne possède aucun destructeur déclaré par l'utilisateur, et
  • ne possède aucun membre de donnée non statique de type classe non POD (ou tableau de tels types) ni de référence.

(jusqu'à C++11)

  • est une classe triviale,
  • est une classe à disposition standard, et
  • ne possède aucun membre de donnée non statique de type classe non POD (ou tableau de tels types).

(depuis C++11)

Une structure POD est une classe POD qui n'est pas une union. Une union POD est une union qui est une classe POD.

(obsolète depuis C++20)
