Instruction switch

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Transfère le contrôle à l'une de plusieurs instructions, selon la valeur d'une condition.

Syntaxe

| | | | attr ﻿*(facultatif)* switch ( init-statement ﻿*(facultatif)* condition ) statement | | | |

  • attr — (depuis C++11) un nombre quelconque d'attributs

  • init-statement — (depuis C++17) l'un des éléments suivants :

    • une instruction d'expression (qui peut être une instruction nulle ;)
    • une déclaration simple, généralement une déclaration de variable avec initialiseur, mais elle peut déclarer un nombre quelconque de variables ou de liaisons structurées
    • une déclaration d'alias

    (depuis C++23)

    Notez que toute init-statement doit se terminer par un point-virgule. C'est pourquoi on la décrit souvent informellement comme une expression ou une déclaration suivie d'un point-virgule.

  • condition — une condition

  • statement — une instruction (généralement une instruction composée)

Condition

Une condition peut être soit une expression, soit une déclaration simple.

  • Si elle peut être syntaxiquement interprétée comme une déclaration de liaison structurée, elle est interprétée comme une déclaration de liaison structurée.

(depuis C++26)

  • Si elle peut être syntaxiquement interprétée comme une expression, elle est traitée comme une expression. Sinon, elle est traitée comme une déclarationqui n'est pas une déclaration de liaison structurée (depuis C++26).

Lorsque le contrôle atteint condition, la condition produit une valeur, utilisée pour déterminer vers quelle étiquette le contrôle va passer.

Expression

Si condition est une expression, la valeur qu'elle produit est la valeur de l'expression.

Déclaration

Si condition est une déclaration simple, la valeur qu'elle produit est la valeur de la variable de décision (voir ci-dessous).

Déclaration hors liaison structurée

La déclaration a les restrictions suivantes :

  • Se conforme syntaxiquement à la forme suivante :
  • type-specifier-seq declarator = assignment-expression

(jusqu'à C++11)

  • attribute-specifier-seq(facultatif) decl-specifier-seq declarator brace-or-equal-initializer

(depuis C++11)

  • Le déclarateur ne peut pas spécifier une fonction ni un tableau.
  • La [séquence de spécificateurs de type (jusqu'à C++11) | séquence de spécificateurs de déclaration ne peut contenir que des spécificateurs de type et constexpr, et elle (depuis C++11)] ne peut pas définir une classe ni une énumération.

La variable de décision de la déclaration est la variable déclarée.

Déclaration de liaison structurée

La déclaration a les restrictions suivantes :

  • La expression de son initialiseur ne peut pas être d'un type tableau.
  • La séquence de spécificateurs de déclaration ne peut contenir que des spécificateurs de type et constexpr.

La variable de décision de la déclaration est la variable inventée e introduite par la déclaration.

(depuis C++26)

Type

condition ne peut produire que les types suivants :

  • types entiers
  • types énumérés
  • types classe

Si la valeur produite est de type classe, elle est implicitement convertie en contexte vers un type entier ou énuméré.

Si le type (éventuellement converti) est soumis aux promotions entières, la valeur produite est convertie vers le type promu.

Étiquettes

Toute instruction contenue dans l'instruction switch peut être étiquetée par une ou plusieurs des étiquettes suivantes :

| | | | attr ﻿*(facultatif)* case constant-expression : | (1) | | | | attr ﻿*(facultatif)* default: | (2) | | |

  • attr — (depuis C++11) un nombre quelconque d'attributs
  • constant-expression — une expression constante convertie du type ajusté de la condition de switch

Une étiquette
ou case est associée à l'instruction switch la plus interne qui l'englobe, et default est associée à celle-ci.

Si l'une des conditions suivantes est satisfaite, le programme est mal formé :

  • Une instruction switch est associée à plusieurs étiquettes case dont les constant-expression ont la même valeur après conversions.
  • Une instruction switch est associée à plusieurs étiquettes default.

Transfert du flot de contrôle

Lorsque la condition d'une instruction switch produit une valeur (éventuellement convertie) :

  • Si l'une des constantes d'étiquette case associées a la même valeur, le contrôle passe à l'instruction étiquetée par l'étiquette case correspondante.
  • Sinon, s'il existe une étiquette default associée, le contrôle passe à l'instruction étiquetée par l'étiquette default.
  • Sinon, aucune des instructions de l'instruction switch n'est exécutée.

Les étiquettes case et default ne modifient pas à elles seules le flot de contrôle. Pour sortir d'une instruction switch depuis son milieu, voir les instructions break.

Les compilateurs peuvent émettre des avertissements sur le fallthrough (atteindre l'étiquette case ou default suivante sans break)sauf si l'attribut [[fallthrough]] apparaît immédiatement avant l'étiquette case pour indiquer que le fallthrough est intentionnel (depuis C++17).

switch (1)
{
    case 1:
        std::cout << '1'; // prints "1",
    case 2:
        std::cout << '2'; // puis affiche « 2 »
}

switch (1)
{
    case 1:
        std::cout << '1'; // prints "1"
        break;            // et sort du switch
    case 2:
        std::cout << '2';
        break;
}

switch instructions avec initialisation

Si init-statement est utilisé, l'instruction switch est équivalente à

{
init-statement
switch ( condition ) statement

}

Sauf que les noms déclarés par init-statement (si init-statement est une déclaration) et les noms déclarés par condition (si condition est une déclaration) sont dans la même portée, qui est aussi la portée de statement.

(depuis C++17)

Notes

Comme il n'est pas permis au transfert de contrôle d'entrer dans la portée d'une variable, si une instruction de déclaration est rencontrée à l'intérieur de statement, elle doit être placée dans sa propre instruction composée :

switch (1)
{
    case 1:
        int x = 0; // initialization
        std::cout << x << '\n';
        break;
    default:
        // erreur de compilation : saut vers default:
        // entrerait dans la portée de 'x' sans l'initialiser
        std::cout << "default\n";
        break;
}

switch (1)
{
    case 1:
        {
            int x = 0;
            std::cout << x << '\n';
            break;
        } // la portée de 'x' se termine ici
    default:
        std::cout << "default\n"; // aucune erreur
        break;
}

Mots-clés

switch, case, default

Exemple

Le code suivant montre plusieurs cas d'utilisation de l'instruction switch :

#include <iostream>

int main()
{
    const int i = 2;
    switch (i)
    {
        case 1:
            std::cout << '1';
        case 2:              // l'exécution commence à cette étiquette case
            std::cout << '2';
        case 3:
            std::cout << '3';
            [[fallthrough]]; // attribut C++17 pour faire taire l'avertissement sur le fallthrough
        case 5:
            std::cout << "45";
            break;           // l'exécution des instructions suivantes est interrompue
        case 6:
            std::cout << '6';
    }

    std::cout << '\n';

    switch (i)
    {
        case 4:
            std::cout << 'a';
        default:
            std::cout << 'd'; // aucune expression constante applicable
                              // default est donc exécuté
    }

    std::cout << '\n';

    switch (i)
    {
        case 4:
            std::cout << 'a'; // rien n'est exécuté
    }

    // lorsque des énumérations sont utilisées dans une instruction switch, de nombreux compilateurs
    // émettent des avertissements si l'un des énumérateurs n'est pas traité
    enum color { RED, GREEN, BLUE };
    switch (RED)
    {
        case RED:
            std::cout << "red\n";
            break;
        case GREEN:
            std::cout << "green\n";
            break;
        case BLUE:
            std::cout << "blue\n";
            break;
    }

    // la syntaxe d'init-statement de C++17 peut être utile lorsqu'il y a
    // aucune conversion implicite vers un type entier ou énuméré
    struct Device
    {
        enum State { SLEEP, READY, BAD };
        auto state() const { return m_state; }

        /* ... */

    private:
        State m_state{};
    };

    switch (auto dev = Device{}; dev.state())
    {
        case Device::SLEEP:
            /* ... */
            break;
        case Device::READY:
            /* ... */
            break;
        case Device::BAD:
            /* ... */
            break;
    }

    // exemples pathologiques

    // l'instruction n'a pas besoin d'être une instruction composée
    switch (0)
        std::cout << "this does nothing\n";

    // les étiquettes n'exigent pas non plus une instruction composée
    switch (int n = 1)
        case 0:
        case 1:
            std::cout << n << '\n';
}

Output:

2345
d
red
1
