boucle for

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Exécute conditionnellement une instruction de manière répétée, où l'instruction n'a pas besoin de gérer la condition de boucle.

Syntaxe

| | | | attr ﻿*(facultatif)* for ( init-statement condition ﻿*(facultatif)* ; expression ﻿*(facultatif)* ) statement | | | |

  • attr — (depuis C++11) un nombre quelconque d'attributs

  • init-statement — l'un des

    • une instruction d'expression (qui peut être une instruction nulle ;)
    • une déclaration simple (typiquement une déclaration d'une variable compteur de boucle avec initialiseur), elle peut déclarer un nombre quelconque de variablesou liaisons structurées (depuis C++17)
    • une déclaration d'alias

    (depuis C++23)

    Notez que toute init-statement doit se terminer par un point-virgule. C'est pourquoi on la décrit souvent informellement comme une expression ou une déclaration suivie d'un point-virgule.

  • condition — une condition

  • expression — une expression (typiquement une expression qui incrémente la variable compteur de boucle)

  • statement — une instruction (typiquement une instruction composée)

Condition

Une condition peut être soit une expression, soit une déclaration simple.

  • Si elle peut être syntaxiquement interprétée comme une déclaration de liaison structurée, elle est interprétée comme une déclaration de liaison structurée.

(depuis C++26)

  • Si elle peut être syntaxiquement interprétée comme une expression, elle est traitée comme une expression. Sinon, elle est traitée comme une déclarationqui n'est pas une déclaration de liaison structurée (depuis C++26).

Lorsque le contrôle atteint la condition, celle-ci produit une valeur, qui est utilisée pour déterminer si statement sera exécuté.

Expression

Si condition est une expression, la valeur qu'elle produit est la valeur de l'expression convertie contextuellement en bool. Si cette conversion est mal formée, le programme est mal formé.

Déclaration

Si condition est une déclaration simple, la valeur qu'elle produit est la valeur de la variable de décision (voir ci-dessous) convertie contextuellement en bool. Si cette conversion est mal formée, le programme est mal formé.

Déclaration hors liaison structurée

La déclaration a les restrictions suivantes :

  • Se conforme syntaxiquement à la forme suivante :
  • type-specifier-seq declarator = assignment-expression

(jusqu'à C++11)

  • attribute-specifier-seq(facultatif) decl-specifier-seq declarator brace-or-equal-initializer

(depuis C++11)

  • Le déclarateur ne peut pas spécifier une fonction ni un tableau.
  • La [séquence de spécificateurs de type (jusqu'à C++11) | séquence de spécificateurs de déclaration ne peut contenir que des spécificateurs de type et constexpr, et elle (depuis C++11)] ne peut pas définir une classe ni une énumération.

La variable de décision de la déclaration est la variable déclarée.

Déclaration de liaison structurée

La déclaration a les restrictions suivantes :

  • La expression de son initialiseur ne peut pas être d'un type tableau.
  • La séquence de spécificateurs de déclaration ne peut contenir que des spécificateurs de type et constexpr.

La variable de décision de la déclaration est la variable inventée e introduite par la déclaration.

(depuis C++26)

Explication

Une instruction for équivalente à :

{
init-statement
while ( condition )
{
statement
expression ;
}

}

Sauf que

  • La portée de init-statement et la portée de condition sont les mêmes.
  • La portée de statement et la portée de expression sont disjointes et imbriquées dans la portée de init-statement et condition.
  • Exécuter une instruction continue dans statement évaluera expression.
  • Une condition vide est équivalente à true.

Si la boucle doit être interrompue à l'intérieur de statement, une instruction break peut être utilisée comme instruction de terminaison.

Si l'itération courante doit être interrompue à l'intérieur de statement, une instruction continue peut être utilisée comme raccourci.

Notes

Comme c'est le cas avec la boucle while, si statement n'est pas une instruction composée, la portée des variables qui y sont déclarées est limitée au corps de la boucle, comme s'il s'agissait d'une instruction composée.

for (;;)
    int n;
// n sort de portée

Dans le cadre de la garantie de progression du C++, le comportement est indéfini si une bouclequi n'est pas une boucle infinie triviale (depuis C++26) sans comportement observable ne se termine pas. Les compilateurs sont autorisés à supprimer de telles boucles.

Alors qu'en C, les noms déclarés dans la portée de init-statement et condition peuvent être masqués dans la portée de statement, cela est interdit en C++ :

for (int i = 0;;)
{
    long i = 1;   // valide en C, invalide en C++
    // ...
}

Mots-clés

for

Exemple

#include <iostream>
#include <vector>

int main()
{
    std::cout << "1) typical loop with a single statement as the body:\n";
    for (int i = 0; i < 10; ++i)
        std::cout << i << ' ';

    std::cout << "\n\n" "2) init-statement can declare multiple names, as\n"
                 "long as they can use the same decl-specifier-seq:\n";
    for (int i = 0, *p = &i; i < 9; i += 2)
        std::cout << i << ':' << *p << ' ';

    std::cout << "\n\n" "3) condition may be a declaration:\n";
    char cstr[] = "Hello";
    for (int n = 0; char c = cstr[n]; ++n)
        std::cout << c;

    std::cout << "\n\n" "4) init-statement can use the auto type specifier:\n";
    std::vector<int> v = {3, 1, 4, 1, 5, 9};
    for (auto iter = v.begin(); iter != v.end(); ++iter)
        std::cout << *iter << ' ';

    std::cout << "\n\n" "5) init-statement can be an expression:\n";
    int n = 0;
    for (std::cout << "Loop start\n";
         std::cout << "Loop test\n";
         std::cout << "Iteration " << ++n << '\n')
    {
        if (n > 1)
            break;
    }

    std::cout << "\n" "6) constructors and destructors of objects created\n"
                 "in the loop's body are called per each iteration:\n";
    struct S
    {
        S(int x, int y) { std::cout << "S::S(" << x << ", " << y << "); "; }
        ~S() { std::cout << "S::~S()\n"; }
    };
    for (int i{0}, j{5}; i < j; ++i, --j)
        S s{i, j};

    std::cout << "\n" "7) init-statement can use structured bindings:\n";
    long arr[]{1, 3, 7};
    for (auto [i, j, k] = arr; i + j < k; ++i)
        std::cout << i + j << ' ';
    std::cout << '\n';
}
