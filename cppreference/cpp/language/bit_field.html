Champ de bits

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Déclare un membre de données de classe avec une taille explicite, en bits. Les membres champs de bits adjacents peuvent (ou non) être compactés pour partager et chevaucher les octets individuels.

Une déclaration de champ de bits est une déclaration de membre de données de classe qui utilise le déclarateur suivant :

| | | | identifier ﻿*(facultatif)* attr ﻿*(facultatif)* : size | (1) | | | | identifier ﻿*(facultatif)* attr ﻿*(facultatif)* : size brace-or-equal-initializer | (2) | (depuis C++20) | |

Le type du champ de bits est introduit par le decl-specifier-seq de la syntaxe de déclaration.

  • attr — (depuis C++11) suite de un nombre quelconque d'attributs
  • identifier — le nom du champ de bits en cours de déclaration. Le nom est facultatif : les champs de bits sans nom introduisent le nombre spécifié de bits de remplissage.
  • size — une expression constante entière de valeur supérieure ou égale à zéro. Lorsqu'elle est supérieure à zéro, c'est le nombre de bits qu'occupera ce champ de bits. La valeur zéro n'est autorisée que pour les champs de bits sans nom et a une signification particulière.
  • brace-or-equal-initializer — initialiseur de membre par défaut à utiliser avec ce champ de bits

Explication

Le type d'un champ de bits ne peut être qu'entier (y compris bool) ou de type énumération (éventuellement qualifié cv), un champ de bits sans nom ne peut pas être déclaré avec un type qualifié cv.

Un champ de bits ne peut pas être un membre de données statique.

Il n'existe pas de prvalues de champ de bits : la conversion lvalue-to-rvalue produit toujours un objet du type sous-jacent du champ de bits.

Le nombre de bits d'un champ de bits fixe la limite de l'intervalle de valeurs qu'il peut contenir :

#include <iostream>

struct S
{
    // champ non signé de trois bits, les valeurs autorisées sont 0...7
    unsigned int b : 3;
};

int main()
{
    S s = {6};

    ++s.b; // stocke la valeur 7 dans le champ de bits
    std::cout << s.b << '\n';

    ++s.b; // la valeur 8 ne tient pas dans ce champ de bits
    std::cout << s.b << '\n'; // formellement défini par l'implémentation, généralement 0
}

Sortie possible :

7
0

Plusieurs champs de bits adjacents sont généralement compactés ensemble (bien que ce comportement soit défini par l'implémentation) :

#include <bit>
#include <cstdint>
#include <iostream>

struct S
{
    // occupera généralement 2 octets :
    unsigned char b1 : 3; // les 3 premiers bits (dans le 1er octet) sont b1
    unsigned char    : 2; // les 2 bits suivants (dans le 1er octet) sont bloqués et inutilisés
    unsigned char b2 : 6; // 6 bits pour b2 - ne tiennent pas dans le 1er octet => commence un 2e
    unsigned char b3 : 2; // 2 bits pour b3 - les bits suivants (et derniers) du 2e octet
};

int main()
{
    std::cout << sizeof(S) << '\n'; // affiche généralement 2

    S s;
    // définit des valeurs de champs distinguables
    s.b1 = 0b111;
    s.b2 = 0b101111;
    s.b3 = 0b11;

    // affiche la disposition des champs de S
    auto i = std::bit_cast<std::uint16_t>(s);
    // affiche généralement 1110000011110111
    // └┬┘├┘└┬┘└─┬──┘└┤
    //                b1 u  a   b2  b3
    // où « u » marque les bits inutilisés :2 spécifiés dans la struct, et
    // « a » marque le remplissage ajouté par le compilateur pour aligner le champ suivant sur un octet.
    // L'alignement sur l'octet se produit parce que le type de b2 est déclaré unsigned char ;
    // si b2 était déclaré uint16_t, il n'y aurait pas de « a », et b2 serait collé à « u ».
    for (auto b = i; b; b >>= 1) // affiche du bit de poids faible au bit de poids fort
        std::cout << (b & 1);
    std::cout << '\n';
}

Sortie possible :

2
1110000011110111

Le champ de bits spécial sans nom de taille zéro peut être utilisé pour forcer la rupture du remplissage. Il indique que le champ de bits suivant commence au début de son unité d'allocation :

#include <iostream>

struct S
{
    // occupera généralement 2 octets :
    // 3 bits : valeur de b1
    // 5 bits : inutilisés
    // 2 bits : valeur de b2
    // 6 bits : inutilisés
    unsigned char b1 : 3;
    unsigned char :0; // commence un nouvel octet
    unsigned char b2 : 2;
};

int main()
{
    std::cout << sizeof(S) << '\n'; // affiche généralement 2
                                    // afficherait généralement 1 si ce n'était le
                                    // remplissage qui interrompt la ligne 11
}

Sortie possible :

2

Si la taille spécifiée du champ de bits est supérieure à la taille de son type, la valeur est limitée par le type : un std::uint8_t b : 1000; ne peut toujours contenir que des valeurs dans l'intervalle [0,255]. Les bits supplémentaires sont des bits de remplissage.

Comme les champs de bits ne commencent pas forcément au début d'un octet, l'adresse d'un champ de bits ne peut pas être prise. Les pointeurs et références non const vers des champs de bits sont impossibles. Lors de l'initialisation d'une référence const à partir d'un champ de bits, un temporaire est créé (son type est celui du champ de bits), initialisé par copie avec la valeur du champ de bits, et la référence est liée à ce temporaire.

Il n'existe pas d'initialiseurs de membres par défaut pour les champs de bits : int b : 1 = 0; et int b : 1 {0} sont mal formés.

(jusqu'à C++20)

En cas d'ambiguïté entre la taille du champ de bits et l'initialiseur de membre par défaut, la plus longue suite de jetons formant une taille valide est choisie :

int a;
const int b = 0;

struct S
{
    // cas simples
    int x1 : 8 = 42; // OK ; « = 42 » est un brace-or-equal-initializer
    int x2 : 8 {42}; // OK ; « {42} » est un brace-or-equal-initializer

    // ambiguities
    int y1 : true ? 8 : a = 42;   // OK ; brace-or-equal-initializer est absent
    int y2 : true ? 8 : b = 42;   // erreur : impossible d'affecter une valeur à const int
    int y3 : (true ? 8 : b) = 42; // OK ; « = 42 » est un brace-or-equal-initializer
    int z : 1 || new int{0};      // OK ; brace-or-equal-initializer est absent
};

(depuis C++20)

Notes

Les propriétés suivantes des champs de bits sont définies par l'implémentation :

  • La valeur résultant de l'affectation ou de l'initialisation d'un champ de bits signé avec une valeur hors intervalle, ou de l'incrémentation d'un champ de bits signé au-delà de son intervalle.
  • Tout ce qui concerne les détails réels de l'allocation des champs de bits au sein de l'objet de classe.
    • Par exemple, sur certaines plateformes, les champs de bits ne chevauchent pas les octets, sur d'autres ils le font.
    • De même, sur certaines plateformes, les champs de bits sont compactés de gauche à droite, sur d'autres de droite à gauche.

En langage C, la largeur d'un champ de bits ne peut pas dépasser la largeur du type sous-jacent, et le fait que int champs de bits qui ne sont pas explicitement signed ou unsigned soient signés ou non signés est défini par l'implémentation. Par exemple, int b : 3; peut avoir l'intervalle de valeurs [0,7] ou [-4,3] en C, mais seul ce dernier choix est autorisé en C++.

DR Appliqué à Comportement publié Comportement correct
