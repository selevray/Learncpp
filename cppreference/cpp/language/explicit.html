spécificateur explicit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Syntaxe

| | | | explicit | (1) | | | | explicit ( expression ) | (2) | (depuis C++20) | |

  • expression — expression constante convertie contextuellement de type bool
  1. Indique qu'un constructeur [ou une fonction de conversion (depuis C++11) | ou un guide de déduction (depuis C++17)] est explicit, c'est-à-dire qu'il ne peut pas être utilisé pour des conversions implicites ni pour une initialisation par copie.
  1. Le spécificateur explicit peut être utilisé avec une expression constante. La fonction est explicit si et seulement si cette expression constante s'évalue à true.

(depuis C++20)

Le spécificateur explicit ne peut apparaître que dans la déclaration decl-specifier-seq d'un constructeur ou d'une fonction de conversion (depuis C++11) au sein de la définition de sa classe.

Notes

Un constructeur avec un seul paramètre sans valeur par défaut (jusqu'à C++11) déclaré sans le spécificateur de fonction explicit est appelé constructeur de conversion.

Les constructeurs (autres que de copie / déplacement) et les fonctions de conversion définies par l'utilisateur peuvent être des modèles de fonctions ; la signification de explicit ne change pas.

Un jeton ( qui suit explicit est toujours analysé comme faisant partie du spécificateur explicit :

struct S
{
    explicit (S)(const S&);    // erreur en C++20, OK en C++17
    explicit (operator int)(); // erreur en C++20, OK en C++17
};

(depuis C++20)

Exemple

struct A
{
    A(int) {}      // constructeur de conversion
    A(int, int) {} // constructeur de conversion (C++11)
    operator bool() const { return true; }
};

struct B
{
    explicit B(int) {}
    explicit B(int, int) {}
    explicit operator bool() const { return true; }
};

int main()
{
    A a1 = 1;      // OK : l'initialisation par copie sélectionne A::A(int)
    A a2(2);       // OK : l'initialisation directe sélectionne A::A(int)
    A a3 {4, 5};   // OK : l'initialisation directe par liste sélectionne A::A(int, int)
    A a4 = {4, 5}; // OK : l'initialisation par copie de liste sélectionne A::A(int, int)
    A a5 = (A)1;   // OK : le cast explicite effectue un static_cast
    if (a1) { }    // OK : A::operator bool()
    bool na1 = a1; // OK : l'initialisation par copie sélectionne A::operator bool()
    bool na2 = static_cast<bool>(a1); // OK : static_cast effectue une initialisation directe

//  B b1 = 1;      // error : l'initialisation par copie ne considère pas B::B(int)
    B b2(2);       // OK : l'initialisation directe sélectionne B::B(int)
    B b3 {4, 5};   // OK : l'initialisation directe par liste sélectionne B::B(int, int)
//  B b4 = {4, 5}; // erreur : l'initialisation par copie de liste ne considère pas B::B(int, int)
    B b5 = (B)1;   // OK : le cast explicite effectue un static_cast
    if (b2) { }    // OK : B::operator bool()
//  bool nb1 = b2; // erreur : l'initialisation par copie ne considère pas B::operator bool()
    bool nb2 = static_cast<bool>(b2); // OK : static_cast effectue une initialisation directe

    [](...){}(a4, a5, na1, na2, b5, nb2); // supprime les avertissements «unused variable»
}
