Expressions de pliage (depuis C++17)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Réduit (plie) un paquet sur un opérateur binaire.

Syntaxe

| | | | ( pack op ... ) | (1) | | | | ( ... op pack ) | (2) | | | | ( pack op ... op init ) | (3) | | | | ( init op ... op pack ) | (4) | | |

  1. Pliage droit unaire.

  2. Pliage gauche unaire.

  3. Pliage droit binaire.

  4. Pliage gauche binaire.

  • op — l'un quelconque des 32 opérateurs binaires suivants : + - * / % ^ & | = < > << >> += -= *= /= %= ^= &= |= <<= >>= == != <= >= && || , .* ->*. Dans un pliage binaire, les deux op doivent être identiques.
  • pack — une expression qui contient un paquet non développé et ne contient pas d'opérateur de précédence inférieure à celle du cast au niveau supérieur (formellement, une cast-expression)
  • init — une expression qui ne contient pas de paquet non développé et ne contient pas d'opérateur de précédence inférieure à celle du cast au niveau supérieur (formellement, une cast-expression)

Notez que les parenthèses ouvrante et fermante font partie obligatoire de l'expression de pliage.

Explication

L'instanciation d'une expression de pliage développe l'expression e de la manière suivante :

  1. Pliage droit unaire (E op ...) devient (E1 op (... op (EN-1 op EN)))

  2. Pliage gauche unaire (... op E) devient (((E1 op E2) op ...) op EN)

  3. Pliage droit binaire (E op ... op I) devient (E1 op (... op (EN−1 op (EN op I))))

  4. Pliage gauche binaire (I op ... op E) devient ((((I op E1) op E2) op ...) op EN)

(où N est le nombre d'éléments de l'expansion du paquet)

Par exemple,

template<typename... Args>
bool all(Args... args) { return (... && args); }

bool b = all(true, true, true, false);
// dans all(), le pliage gauche unaire se développe ainsi
//  return ((true && true) && true) && false;
// b vaut false

Lorsqu'un pliage unaire est utilisé avec une expansion de paquet de longueur nulle, seuls les opérateurs suivants sont autorisés :

  1. ET logique (&&). La valeur pour le paquet vide est true.

  2. OU logique (||). La valeur pour le paquet vide est false.

  3. L'opérateur virgule (,). La valeur pour le paquet vide est void().

Notes

Si l'expression utilisée comme init ou comme pack contient un opérateur de précédence inférieure à celle du cast au niveau supérieur, elle doit être entre parenthèses :

template<typename... Args>
int sum(Args&&... args)
{
//  return (args + ... + 1 * 2);   // Erreur : opérateur de précédence inférieure à celle du cast
    return (args + ... + (1 * 2)); // OK
}

Exemple

#include <climits>
#include <concepts>
#include <cstdint>
#include <iostream>
#include <limits>
#include <type_traits>
#include <utility>
#include <vector>

// Utilisation de base, pliage d'arguments variadiques sur operator<<
template<typename... Args>
void printer(Args&&... args)
{
    (std::cout << ... << args) << '\n';
}

// Pliage d'une expression utilisant directement le paquet sur operator,
template<typename... Ts>
void print_limits()
{
    ((std::cout << +std::numeric_limits<Ts>::max() << ' '), ...) << '\n';
}

// Un pliage sur operator&& utilisant le paquet
// et sur operator, utilisant les arguments variadiques
template<typename T, typename... Args>
void push_back_vec(std::vector<T>& v, Args&&... args)
{
    static_assert((std::is_constructible_v<T, Args&&> && ...));
    (v.push_back(std::forward<Args>(args)), ...);
}

// Utilisation d'une séquence d'entiers pour exécuter une expression
// N fois, en pliant une lambda sur operator,
template<class T, std::size_t... dummy_pack>
constexpr T bswap_impl(T i, std::index_sequence<dummy_pack...>)
{
    T low_byte_mask = static_cast<unsigned char>(-1);
    T ret{};
    ([&]
    {
        (void)dummy_pack;
        ret <<= CHAR_BIT;
        ret |= i & low_byte_mask;
        i >>= CHAR_BIT;
    }(), ...);
    return ret;
}

constexpr auto bswap(std::unsigned_integral auto i)
{
    return bswap_impl(i, std::make_index_sequence<sizeof(i)>{});
}

int main()
{
    printer(1, 2, 3, "abc");
    print_limits<uint8_t, uint16_t, uint32_t>();

    std::vector<int> v;
    push_back_vec(v, 6, 2, 45, 12);
    push_back_vec(v, 1, 2, 9);
    for (int i : v)
        std::cout << i << ' ';
    std::cout << '\n';

    static_assert(bswap<std::uint16_t>(0x1234u) == 0x3412u);
    static_assert(bswap<std::uint64_t>(0x0123456789abcdefull) == 0xefcdab8967452301ULL);
}

Output:

123abc
255 65535 4294967295
6 2 45 12 1 2 9
