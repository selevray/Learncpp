Déclaration d'énumération

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Une énumération est un type distinct dont la valeur est restreinte à un intervalle de valeurs (voir ci-dessous pour les détails), qui peut comprendre plusieurs constantes nommées explicitement (« énumérateurs »).

Les valeurs des constantes sont des valeurs d'un type entier appelé type sous-jacent de l'énumération. Une énumération a la même taille, la même représentation des valeurs et les mêmes exigences d'alignement que son type sous-jacent. De plus, chaque valeur d'une énumération a la même représentation que la valeur correspondante du type sous-jacent.

Une énumération est (re)déclarée avec la syntaxe suivante :

| | | | enum-key attr ﻿*(optional)* enum-head-name ﻿*(optional)* enum-base ﻿*(optional)* { enumerator-list ﻿*(optional)* } | (1) | | | | enum-key attr ﻿*(optional)* enum-head-name ﻿*(optional)* enum-base ﻿*(optional)* { enumerator-list , } | (2) | | | | enum-key attr ﻿*(optional)* enum-head-name enum-base ﻿*(optional)* ; | (3) | (depuis C++11) | |

  1. enum-specifier, qui apparaît dans decl-specifier-seq de la syntaxe de déclaration : définit le type énumération et ses énumérateurs.

  2. Une virgule finale peut suivre enumerator-list.

  3. Déclaration d'enum opaque : définit le type énumération mais pas ses énumérateurs : après cette déclaration, le type est un type complet et sa taille est connue.

    enum

    (jusqu'à C++11)

    l'un de enum, enum class ou enum struct

    (depuis C++11)

  • attr — (depuis C++11) séquence optionnelle d'un nombre quelconque d'attributs

  • enum-head-name —

    le nom de l'énumération déclarée, il peut être omis.

    (jusqu'à C++11)

    le nom de l'énumération déclarée, éventuellement précédé d'un nested-name-specifier : séquence de noms et d'opérateurs de résolution de portée ::, se terminant par un opérateur de résolution de portée. Il ne peut être omis que dans les déclarations d'énumération non opaques sans portée.
    nested-name-specifier ne peut apparaître que si le nom de l'énumération est présent et que cette déclaration est une redéclaration. Pour les déclarations d'énumération opaques, nested-name-specifier ne peut apparaître qu'avant le nom de l'énumération dans les déclarations de spécialisation explicite.
    Si nested-name-specifier est présent, le spécificateur enum ne peut pas désigner une énumération simplement héritée ou introduite par une déclaration using, et le spécificateur enum ne peut apparaître que dans un espace de noms englobant la déclaration précédente. Dans de tels cas, nested-name-specifier ne peut pas commencer par un spécificateur decltype.

    (depuis C++11)

  • enum-base — (depuis C++11) deux-points (:), suivi d'un type-specifier-seq désignant un type entier (s'il est qualifié cv, les qualificateurs sont ignorés) qui servira de type sous-jacent fixe pour ce type énumération

  • enumerator-list — liste de définitions d'énumérateurs séparées par des virgules, chacune étant soit simplement un identifier unique, qui devient le nom de l'énumérateur, soit un identifiant unique accompagné d'une expression constante : identifier = constant-expression. Dans les deux cas, identifier peut être directement suivi d'une séquence optionnelle de spécificateurs d'attributs. (depuis C++17)

Il existe deux genres distincts d'énumérations : les énumérations sans portée (déclarées avec enum-key enum) et les énumérations avec portée (déclarées avec enum-key enum class ou enum struct).

Énumérations sans portée

| | | | enum name ﻿*(facultatif)* { enumerator = constant-expression , enumerator = constant-expression , ... } | (1) | | | | enum name ﻿*(facultatif)* : type { enumerator = constant-expression , enumerator = constant-expression , ... } | (2) | (depuis C++11) | | | enum name : type ; | (3) | (depuis C++11) | |

  1. Déclare un type énumération sans portée dont le type sous-jacent n'est pas fixé (dans ce cas, le type sous-jacent est un type entier défini par l'implémentation capable de représenter toutes les valeurs des énumérateurs ; ce type n'est pas plus grand que int, sauf si la valeur d'un énumérateur ne peut pas tenir dans un int ou unsigned int. Si la enumerator-list est vide, le type sous-jacent est celui qu'aurait l'énumération avec un seul énumérateur de valeur 0. Si aucun type entier ne peut représenter toutes les valeurs des énumérateurs, l'énumération est mal formée).

  2. Déclare un type énumération sans portée dont le type sous-jacent est fixé.

  3. La déclaration d'enum opaque pour une énumération sans portée doit spécifier le nom et le type sous-jacent.

Chaque enumerator devient une constante nommée du type de l'énumération (c'est-à-dire name), visible dans la portée englobante, et peut être utilisée chaque fois que des constantes sont requises.

enum Color { red, green, blue };
Color r = red;

switch(r)
{
    case red  : std::cout << "red\n";   break;
    case green: std::cout << "green\n"; break;
    case blue : std::cout << "blue\n";  break;
}

Chaque énumérateur est associé à une valeur du type sous-jacent. Lorsque des = sont fournis dans une enumerator-list, les valeurs des énumérateurs sont définies par ces constant-expression associés. Si le premier énumérateur n'a pas de =, la valeur associée est zéro. Pour tout autre énumérateur dont la définition n'a pas de =, la valeur associée est la valeur de l'énumérateur précédent plus un.

enum Foo { a, b, c = 10, d, e = 1, f, g = f + c };
//a = 0, b = 1, c = 10, d = 11, e = 1, f = 2, g = 12

Le name d'une énumération sans portée peut être omis : une telle déclaration introduit seulement les énumérateurs dans la portée englobante :

enum { a, b, c = 0, d = a + 2 }; // définit a = 0, b = 1, c = 0, d = 2

Lorsqu'une énumération sans portée est un membre de classe, ses énumérateurs peuvent être accédés à l'aide des opérateurs d'accès aux membres de classe . et -> :

struct X
{
    enum direction { left = 'l', right = 'r' };
};
X x;
X* p = &x;

int a = X::direction::left; // autorisé uniquement en C++11 et versions ultérieures
int b = X::left;
int c = x.left;
int d = p->left;

Dans les spécificateurs de déclaration d'une déclaration de membre, la séquence

enum enum-head-name :

est toujours analysée comme faisant partie d'une déclaration d'énumération :

struct S
{
    enum E1 : int {};
    enum E1 : int {}; // erreur : redéclaration de l'énumération,
                      // NON analysé comme un champ de bits de largeur nulle de type enum E1
};

enum E2 { e1 };

void f()
{
    false ? new enum E2 : int(); // OK : 'int' n'est PAS analysé comme le type sous-jacent
}

(depuis C++11)

Nom d'énumération à des fins de liaison

Une énumération sans nom qui n'a pas de nom de typedef à des fins de liaison et qui possède un énumérateur est désignée, à des fins de liaison, par son type sous-jacent et son premier énumérateur ; on dit qu'une telle énumération a un énumérateur comme nom à des fins de liaison.

Énumérations avec portée

enum struct|class name { enumerator = constant-expression , enumerator = constant-expression , ... } | (1)

enum struct|class name : type { enumerator = constant-expression , enumerator = constant-expression , ... } | (2)

enum struct|class name ; | (3)

enum struct|class name : type ; | (4)

  1. déclare un type énumération avec portée dont le type sous-jacent est int (les mots-clés class et struct sont exactement équivalents)

  2. déclare un type énumération avec portée dont le type sous-jacent est type

  3. déclaration d'enum opaque pour une énumération avec portée dont le type sous-jacent est int

  4. déclaration d'enum opaque pour une énumération avec portée dont le type sous-jacent est type

Chaque enumerator devient une constante nommée du type de l'énumération (c'est-à-dire name), contenue dans la portée de l'énumération, et accessible à l'aide de l'opérateur de résolution de portée. Il n'existe aucune conversion implicite des valeurs d'un énumérateur avec portée vers les types entiers, bien que static_cast puisse être utilisé pour obtenir la valeur numérique de l'énumérateur.

#include <iostream>

int main()
{
    enum class Color { red, green = 20, blue };
    Color r = Color::blue;

    switch(r)
    {
        case Color::red  : std::cout << "red\n";   break;
        case Color::green: std::cout << "green\n"; break;
        case Color::blue : std::cout << "blue\n";  break;
    }

    // int n = r; // erreur : pas de conversion implicite d'une enum à portée vers int
    int n = static_cast<int>(r); // OK, n = 21
    std::cout << n << '\n'; // prints 21
}

(depuis C++11)

Une énumération peut être initialisée à partir d'un entier sans conversion explicite, à l'aide d'une initialisation par liste, si toutes les conditions suivantes sont vraies :

  • L'initialisation est une initialisation directe par liste.
  • La liste d'initialisation ne comporte qu'un seul élément.
  • L'énumération est soit avec portée, soit sans portée avec un type sous-jacent fixé.
  • La conversion n'est pas restrictive.

Cela permet d'introduire de nouveaux types entiers (par ex. SafeInt) qui bénéficient des mêmes conventions d'appel existantes que leurs types entiers sous-jacents, même sur les ABI qui pénalisent le passage ou la renvoi de structures par valeur.

enum byte : unsigned char {}; // byte est un nouveau type entier ; voir aussi std::byte (C++17)
byte b{42};        // OK à partir de C++17 (initialisation par liste directe)
byte c = {42};     // error
byte d = byte{42}; // OK à partir de C++17 ; même valeur que b
byte e{-1};        // error

struct A { byte b; };
A a1 = {{42}};     // erreur (initialisation par copie de liste d'un paramètre de constructeur)
A a2 = {byte{42}}; // OK à partir de C++17

void f(byte);
f({42}); // erreur (initialisation par copie de liste d'un paramètre de fonction)

enum class Handle : std::uint32_t { Invalid = 0 };
Handle h{42}; // OK à partir de C++17

(depuis C++17)

déclaration using enum

using enum using-enum-declarator ; | (depuis C++20)

  • declarator — un identifiant (éventuellement qualifié) ou des identifiants de modèle simples

declarator doit désigner un type énumération non dépendant. Les déclarations d'énumération sont trouvées par une recherche ordinaire qualifiée ou non qualifiée ne considérant que les types, selon que declarator est qualifié ou non.

enum E { x };

void f()
{
    int E;
    using enum E; // OK
}

using F = E;
using enum F; // OK

template<class T>
using EE = T;

void g()
{
    using enum EE<E>; // OK
}

Une déclaration using enum introduit les noms des énumérateurs de l'énumération nommée comme si une déclaration using était faite pour chaque énumérateur. Lorsqu'elle se trouve dans une portée de classe, une déclaration using enum ajoute les énumérateurs de l'énumération nommée comme membres de la portée, les rendant accessibles à la recherche de membres.

enum class fruit { orange, apple };

struct S
{
    using enum fruit; // OK : introduit orange et apple dans S
};

void f()
{
    S s;
    s.orange;  // OK : désigne fruit::orange
    S::orange; // OK : désigne fruit::orange
}

Deux déclarations using enum qui introduisent deux énumérateurs de même nom sont en conflit.

enum class fruit { orange, apple };
enum class color { red, orange };

void f()
{
    using enum fruit;    // OK
    // using enum color; // erreur : color::orange et fruit::orange entrent en conflit
}

(depuis C++20)

Notes

Les valeurs d'un type énumération sans portée peuvent être promues ou converties en types entiers :

enum color { red, yellow, green = 20, blue };
color col = red;
int n = blue; // n == 21

Les valeurs de types entiers, à virgule flottante et énumération peuvent être converties vers tout type énumération à l'aide de static_cast. Notez que la valeur obtenue après une telle conversion n'est pas nécessairement égale à l'un des énumérateurs nommés définis pour l'énumération :

enum access_t { read = 1, write = 2, exec = 4 }; // enumerators: 1, 2, 4 range: 0..7
access_t rwe = static_cast<access_t>(7);
assert((rwe & read) && (rwe & write) && (rwe & exec));

access_t x = static_cast<access_t>(8.0); // comportement indéfini depuis CWG 1766
access_t y = static_cast<access_t>(8);   // comportement indéfini depuis CWG 1766

enum foo { a = 0, b = UINT_MAX }; // range: [0, UINT_MAX]
foo x = foo(-1); // comportement indéfini depuis CWG 1766,
                 // même si le type sous-jacent de foo est unsigned int

Mots-clés

enum, struct, class, using

Exemple

#include <cstdint>
#include <iostream>

// énumération sur 16 bits
enum smallenum: std::int16_t
{
    a,
    b,
    c
};

// color peut valoir red (valeur 0), yellow (valeur 1), green (valeur 20) ou blue (valeur 21)
enum color
{
    red,
    yellow,
    green = 20,
    blue
};

// altitude peut valoir altitude::high ou altitude::low
enum class altitude: char
{
    high = 'h',
    low = 'l', // virgule finale autorisée uniquement après CWG 518
};

// la constante d vaut 0, la constante e vaut 1, la constante f vaut 3
enum
{
    d,
    e,
    f = e + 2
};

// les types énumérés (avec et sans portée) peuvent avoir des opérateurs surchargés
std::ostream& operator<<(std::ostream& os, color c)
{
    switch(c)
    {
        case red   : os << "red";    break;
        case yellow: os << "yellow"; break;
        case green : os << "green";  break;
        case blue  : os << "blue";   break;
        default    : os.setstate(std::ios_base::failbit);
    }
    return os;
}

std::ostream& operator<<(std::ostream& os, altitude al)
{
    return os << static_cast<char>(al);
}

// L'énumération à portée (C++11) peut être émulée partiellement dans les révisions antérieures de C++ :

enum struct E11 { x, y }; // depuis C++11

struct E98 { enum { x, y }; }; // OK en pré-C++11

namespace N98 { enum { x, y }; } // OK en pré-C++11

struct S98 { static const int x = 0, y = 1; }; // OK en pré-C++11

void emu()
{
    std::cout << (static_cast<int>(E11::y) + E98::y + N98::y + S98::y) << '\n'; // 4
}

namespace cxx20
{
    enum class long_long_long_name { x, y };

    void using_enum_demo()
    {
        std::cout << "C++20 `using enum`: __cpp_using_enum == ";
        switch (auto rnd = []{return long_long_long_name::x;}; rnd())
        {
#if defined(__cpp_using_enum)
            using enum long_long_long_name;
            case x: std::cout << __cpp_using_enum << "; x\n"; break;
            case y: std::cout << __cpp_using_enum << "; y\n"; break;
#else
            case long_long_long_name::x: std::cout << "?; x\n"; break;
            case long_long_long_name::y: std::cout << "?; y\n"; break;
#endif
        }
    }
}

int main()
{
    color col = red;
    altitude a;
    a = altitude::low;

    std::cout << "col = " << col << '\n'
              << "a = "   << a   << '\n'
              << "f = "   << f   << '\n';

    cxx20::using_enum_demo();
}
