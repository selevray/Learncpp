alignas spécificateur (depuis C++11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Spécifie l'exigence d'alignement d'un type ou d'un objet.

Syntaxe

| | | | alignas( expression ) | | | | | alignas( type-id ) | | | | | alignas( pack ... ) | | | |

  1. expression doit être une expression constante entière qui s'évalue à zéro, ou à une valeur valide pour un alignement ou un alignement étendu.

  2. Équivalent à alignas(alignof( type-id )).

  3. Équivalent à plusieurs spécificateurs alignas appliqués à la même déclaration, un pour chaque membre du pack de paramètres, qui peut être un pack de paramètres de type ou de paramètre non-type.

Explication

Le spécificateur alignas peut être appliqué à :

  • la déclaration ou la définition d'une classe ;
  • la déclaration d'un membre de donnée de classe qui n'est pas un champ de bits ;
  • la déclaration d'une variable, sauf qu'il ne peut pas être appliqué à ce qui suit :
    • un paramètre de fonction ;
    • le paramètre d'exception d'une clause catch.

L'objet ou le type déclaré par une telle déclaration aura son exigence d'alignement égale à la plus stricte (la plus grande) expression non nulle de tous les spécificateurs alignas utilisés dans la déclaration, sauf si cela affaiblirait l'alignement naturel du type.

Si le plus strict (le plus grand) alignas d'une déclaration est plus faible que l'alignement qu'elle aurait sans aucun spécificateur alignas (c'est-à-dire plus faible que son alignement naturel ou plus faible que alignas sur une autre déclaration du même objet ou type), le programme est mal formé :

struct alignas(8) S {};
struct alignas(1) U { S s; }; // erreur : l'alignement de U aurait été 8 sans alignas(1)

Les alignements non nuls invalides, tels que alignas(3), sont mal formés.

Les alignements non nuls valides plus faibles qu'un autre alignas sur la même déclaration sont ignorés.

alignas(0) est toujours ignoré.

Notes

Depuis la norme ISO C11, le langage C possède le mot-clé _Alignas et définit alignas comme une macro du préprocesseur se développant en ce mot-clé dans l'en-tête <stdalign.h>.

En C++, c'est un mot-clé, et

les en-têtes <stdalign.h> et <cstdalign> ne définissent pas une telle macro. Ils définissent cependant la constante macro __alignas_is_defined.

(jusqu'à C++20)

l'en-tête <stdalign.h> ne définit pas une telle macro. Il définit cependant la constante macro __alignas_is_defined.

(depuis C++20)

Exemple

#include <iostream>

// Chaque objet de type struct_float sera aligné
// sur une frontière alignof(float) (généralement 4) :
struct alignas(float) struct_float
{
    // votre définition ici
};

// Chaque objet de type sse_t sera aligné sur une frontière de 32 octets :
struct alignas(32) sse_t
{
    float sse_data[4];
};

int main()
{
    struct default_aligned
    {
        float data[4];
    } a, b, c;
    sse_t x, y, z;

    std::cout
        << "alignof(struct_float) = " << alignof(struct_float) << '\n'
        << "sizeof(sse_t) = " << sizeof(sse_t) << '\n'
        << "alignof(sse_t) = " << alignof(sse_t) << '\n'
        << std::hex << std::showbase
        << "&a: " << &a << "\n"
           "&b: " << &b << "\n"
           "&c: " << &c << "\n"
           "&x: " << &x << "\n"
           "&y: " << &y << "\n"
           "&z: " << &z << '\n';
}
