Déclaration de classe

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les classes sont des types définis par l'utilisateur, définis par un class-specifier, qui apparaît dans decl-specifier-seq de la syntaxe de déclaration.

Syntaxe

Le spécificateur de classe a la syntaxe suivante :

| | | | class-key attr ﻿*(facultatif)* class-head-name final(facultatif) base-clause ﻿*(facultatif)* { member-specification } | (1) | | | | class-key attr ﻿*(facultatif)* base-clause ﻿*(facultatif)* { member-specification } | (2) | | |

  1. Définition de classe nommée

  2. Définition de classe anonyme

  • class-key — l'un de class, struct et union. Les mots-clés class et struct sont identiques, sauf pour l'accès aux membres par défaut et l'accès aux classes de base par défaut. S'il s'agit de union, la déclaration introduit un type union.
  • attr — (depuis C++11) un nombre quelconque d'attributs, pouvant inclure un spécificateur alignas
  • class-head-name — le nom de la classe en cours de définition, éventuellement qualifié
  • final — (depuis C++11) si présent, la classe ne peut pas être dérivée
  • base-clause — liste d'une ou plusieurs classes de base et le modèle d'héritage utilisé pour chacune (voir classe dérivée)
  • member-specification — liste de spécificateurs d'accès, de déclarations et définitions de membres de données et de fonctions membres (voir ci-dessous)

Déclaration anticipée

Une déclaration de la forme suivante

| | | | class-key attr identifier ; | | | |

Déclare un type classe qui sera défini plus loin dans cette portée. Tant que la définition n'apparaît pas, ce nom de classe a un type incomplet. Cela permet aux classes de se référencer mutuellement :

class Vector; // déclaration anticipée

class Matrix
{
    // ...
    friend Vector operator*(const Matrix&, const Vector&);
};

class Vector
{
    // ...
    friend Vector operator*(const Matrix&, const Vector&);
};

et si un fichier source donné n'utilise que des pointeurs et des références vers la classe, cela permet de réduire les dépendances #include :

// Dans MyStruct.h
#include <iosfwd> // contains forward declaration of std::ostream

struct MyStruct
{
    int value;
    friend std::ostream& operator<<(std::ostream& os, const S& s);
    // définition fournie dans le fichier MyStruct.cpp qui utilise #include <ostream>
};

Si la déclaration anticipée apparaît dans une portée locale, elle masque la classe, la variable, la fonction et toutes les autres déclarations de même nom pouvant apparaître dans les portées englobantes, déclarées précédemment :

struct s { int a; };
struct s; // ne fait rien (s est déjà définie dans cette portée)

void g()
{
    struct s; // déclaration anticipée d'un nouveau struct local « s »
              // cela masque la structure globale s jusqu'à la fin de ce bloc

    s* p; // pointeur vers la structure locale s

    struct s { char* p; }; // définitions de la structure locale s
}

Notez qu'un nouveau nom de classe peut aussi être introduit par un spécificateur de type elaboré qui apparaît dans le cadre d'une autre déclaration, mais seulement si la recherche de nom ne trouve pas de classe déclarée précédemment avec le même nom.

class U;

namespace ns
{
    class Y f(class T p); // déclare la fonction ns::f et déclare ns::T et ns::Y

    class U f(); // U fait référence à ::U

    // peut utiliser des pointeurs et des références vers T et Y
    Y* p;
    T* q;
}

Spécification des membres

La spécification des membres, ou le corps d'une définition de classe, est une suite entre accolades d'un nombre quelconque des éléments suivants :

  1. Déclarations de membres de la forme

| | | | attr ﻿*(facultatif)* decl-specifier-seq ﻿*(facultatif)* member-declarator-list ﻿*(facultatif)* ; | | | |

  • attr — (depuis C++11) un nombre quelconque d'attributs
  • decl-specifier-seq — suite de spécificateurs. Elle n'est facultative que dans les déclarations de constructeurs, de destructeurs et de fonctions de conversion de types définis par l'utilisateur
  • member-declarator-list — similaire à une init-declarator-list, mais permettant en outre les déclarations de champs de bits, le pure-specifier, et les virt-specifier (override ou final) (depuis C++11), et n'autorise pas la syntaxe d'initialisation directe sans liste.

Cette déclaration peut déclarer des membres de données statiques ou non statiques et des fonctions membres, des typedefs membres, des énumérations membres et des classes imbriquées. Elle peut aussi être une déclaration friend.

class S
{
    int d1;             // membre de données non statique
    int a[10] = {1, 2}; // membre de données non statique avec initialiseur (depuis C++11)

    static const int d2 = 1; // membre de données statique avec initialiseur

    virtual void f1(int) = 0; // fonction membre virtuelle pure

    std::string d3, *d4, f2(int); // deux membres de données et une fonction membre

    enum { NORTH, SOUTH, EAST, WEST };

    struct NestedS
    {
        std::string s;
    } d5, *d6;

    typedef NestedS value_type, *pointer_type;
};
  1. Définitions de fonctions, qui déclarent et définissent à la fois des fonctions membres ou des fonctions amies. Un point-virgule après une définition de fonction membre est facultatif. Toutes les fonctions définies dans le corps d'une classe sont automatiquement inline, sauf si elles sont rattachées à un module nommé (depuis C++20).
class M
{
    std::size_t C;
    std::vector<int> data;
public:
    M(std::size_t R, std::size_t C) : C(C), data(R*C) {} // définition de constructeur

    int operator()(std::size_t r, std::size_t c) const // définition de fonction membre
    {
        return data[r * C + c];
    }

    int& operator()(std::size_t r, std::size_t c) // définition d'une autre fonction membre
    {
        return data[r * C + c];
    }
};
  1. Spécificateurs d'accès public:, protected: et private:
class S
{
public:
    S();          // constructeur public
    S(const S&);  // constructeur de copie public
    virtual ~S(); // destructeur virtuel public
private:
    int* ptr; // membre de données privé
};
  1. Déclarations using :
class Base
{
protected:
    int d;
};

class Derived : public Base
{
public:
    using Base::d;    // rend le membre protégé d de Base un membre public de Derived
    using Base::Base; // hérite de tous les constructeurs des bases (depuis C++11)
};
  1. static_assert declarations:
template<typename T>
struct Foo
{
    static_assert(std::is_floating_point<T>::value, "Foo<T>: T must be floating point");
};
  1. Déclarations de modèles membres :
struct S
{
    template<typename T>
    void f(T&& n);

    template<class CharT>
    struct NestedS
    {
        std::basic_string<CharT> s;
    };
};
  1. Déclarations d'alias :
template<typename T>
struct identity
{
    using type = T;
};

(depuis C++11)

  1. Guides de déduction des modèles de classes membres :
struct S
{
    template<class CharT>
    struct NestedS
    {
        std::basic_string<CharT> s;
    };

    template<class CharT>
    NestedS(std::basic_string<CharT>) -> NestedS<CharT>;
};

(depuis C++17)

  1. Déclarations using enum :
enum class color { red, orange, yellow };

struct highlight
{
    using enum color;
};

(depuis C++20)

Classes locales

Une déclaration de classe peut apparaître dans le corps d'une fonction, auquel cas elle définit une classe locale. Le nom d'une telle classe n'existe que dans la portée de la fonction et n'est pas accessible à l'extérieur.

  • Les membres d'une classe locale ne peuvent être déclarés que dans la définition de cette classe, sauf que les membres qui sont des classes imbriquées peuvent aussi être déclarés dans la portée de bloc englobante la plus proche de cette classe.
  • Une classe imbriquée dans une classe locale est aussi une classe locale.
  • Une classe locale ne peut pas avoir de membres de données statiques.
  • Les fonctions membres d'une classe locale n'ont pas de liaison.
  • Les fonctions membres d'une classe locale doivent être définies entièrement dans le corps de la classe.
  • Les classes localesautres que les types de fermeture (depuis C++14) ne peuvent pas avoir de modèles membres.
  • Les classes locales ne peuvent pas avoir de modèles d'amitié.
  • Les classes locales ne peuvent pas définir de fonctions amies dans la définition de la classe.
  • Une classe locale définie dans une fonction (y compris une fonction membre) peut accéder aux mêmes noms que ceux auxquels la fonction englobante peut accéder.
  • Les classes locales ne pouvaient pas être utilisées comme arguments de modèle.

(jusqu'à C++11)

#include <algorithm>
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> v{1, 2, 3};

    struct Local
    {
        bool operator()(int n, int m)
        {
            return n > m;
        }
    };

    std::sort(v.begin(), v.end(), Local()); // depuis C++11

    for (int n : v)
        std::cout << n << ' ';
    std::cout << '\n';
}

Output:

3 2 1
