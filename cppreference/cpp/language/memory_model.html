Modèle mémoire

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Définit la sémantique du stockage de la mémoire de l'ordinateur pour les besoins de la machine abstraite C++.

La mémoire disponible pour un programme C++ est constituée d'une ou plusieurs suites contiguës de octets. Chaque octet de la mémoire possède une adresse unique.

Octet

Un octet est la plus petite unité de mémoire adressable. Il est défini comme une suite contiguë de bits, suffisamment grande pour contenir

  • la valeur de n'importe quelle UTF-8 unité de code (256 valeurs distinctes) et de
  • n'importe quel membre du jeu de caractères d'exécution de base.

(jusqu'à C++23)

  • l'encodage ordinaire de littéral de n'importe quel élément du jeu de caractères littéraux de base.

(depuis C++23)

Comme C, C++ prend en charge des octets de taille égale ou supérieure à 8 bits.

Les types char, unsigned char et signed char utilisent un octet pour le stockage et la représentation de valeur. Le nombre de bits d'un octet est accessible via CHAR_BIT ou std::numeric_limits<unsigned char>::digits.

Emplacement mémoire

Un emplacement mémoire est le stockage occupé par la représentation d'objet soit d'un objet de type scalaire qui n'est pas un champ de bits, soit de la plus grande suite contiguë de champs de bits de longueur non nulle.

Note : diverses fonctionnalités du langage, comme les références et les fonctions virtuelles, peuvent impliquer des emplacements mémoire supplémentaires, inaccessibles aux programmes mais gérés par l'implémentation.

struct S
{
    char a;     // emplacement mémoire #1
    int b : 5;  // emplacement mémoire #2
    int c : 11, // emplacement mémoire #2 (suite)
          : 0,
        d : 8;  // emplacement mémoire #3
    struct
    {
        int ee : 8; // emplacement mémoire #4
    } e;
} obj; // L'objet “obj” est constitué de 4 emplacements mémoire distincts
