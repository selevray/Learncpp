spécificateur consteval (depuis C++20)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

  • consteval - indique qu'une fonction est une fonction immédiate, c'est-à-dire que chaque appel à la fonction doit produire une constante de compilation

Explication

Le spécificateur consteval déclare une fonction ou un modèle de fonction comme fonction immédiate, c'est-à-dire que chaque appel potentiellement évalué à la fonction doit (directement ou indirectement) produire une expression constante à la compilation.

Une fonction immédiate est une fonction constexpr, soumise à ses exigences selon le cas. Comme constexpr, un spécificateur consteval implique inline. Cependant, il ne peut pas être appliqué aux destructeurs, aux fonctions d'allocation ni aux fonctions de désallocation.

Une déclaration de fonction ou de modèle de fonction spécifiant consteval ne peut pas aussi spécifier constexpr, et toute redéclaration de cette fonction ou de ce modèle de fonction doit aussi spécifier consteval.

Une invocation potentiellement évaluée d'une fonction immédiate dont la portée de bloc la plus interne n'est pas une portée de paramètres de fonction d'une fonction immédiate ou la branche vraie d'une instruction if consteval (depuis C++23) doit produire une expression constante ; une telle invocation est appelée une invocation immédiate.

consteval int sqr(int n)
{
    return n*n;
}
constexpr int r = sqr(100); // OK

int x = 100;
int r2 = sqr(x);            // Error: l'appel ne produit pas une constante

consteval int sqrsqr(int n)
{
    return sqr(sqr(n));     // Pas une expression constante à ce stade, mais OK
}

constexpr int dblsqr(int n)
{
    return 2 * sqr(n);      // Error: la fonction englobante n'est pas consteval
                            // et sqr(n) n'est pas une constante
}

Une expression d'identifiant qui désigne une fonction immédiate ne peut apparaître que dans une sous-expression d'une invocation immédiate ou dans un contexte de fonction immédiate (c'est-à-dire un contexte mentionné ci-dessus, dans lequel un appel à une fonction immédiate n'a pas besoin d'être une expression constante). Un pointeur ou une référence vers une fonction immédiate peut être obtenu, mais ne peut pas sortir de l'évaluation de l'expression constante :

consteval int f() { return 42; }
consteval auto g() { return &f; }
consteval int h(int (*p)() = g()) { return p(); }
constexpr int r = h();  // OK
constexpr auto e = g(); // mal formé : un pointeur vers une fonction immédiate est
                        // pas un résultat autorisé d'une expression constante

Exemple

#include <iostream>

// Cette fonction peut être évaluée à la compilation, si l'entrée
// est connue à la compilation. Sinon, elle est exécutée à l'exécution.
constexpr unsigned factorial(unsigned n)
{
    return n < 2 ? 1 : n * factorial(n - 1);
}

// Avec consteval, nous imposons que la fonction soit évaluée à la compilation.
consteval unsigned combination(unsigned m, unsigned n)
{
    return factorial(n) / factorial(m) / factorial(n - m);
}

static_assert(factorial(6) == 720);
static_assert(combination(4, 8) == 70);

int main(int argc, const char*[])
{
    constexpr unsigned x{factorial(4)};
    std::cout << x << '\n';

    [[maybe_unused]]
    unsigned y = factorial(argc); // OK
//  unsigned z = combination(argc, 7); // erreur : 'argc' n'est pas une expression constante
}

Output:

24
