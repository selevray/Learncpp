Conversion static_cast

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Convertit entre types en combinant des conversions implicites et définies par l'utilisateur.

Syntaxe

| | | | static_cast<target-type ﻿>(expression ﻿) | | | |

Renvoie une valeur de type target-type.

Explication

Seules les conversions suivantes peuvent être effectuées avec static_cast, sauf lorsque ces conversions supprimeraient la constness (ou la volatilité).

  1. Si expression est une lvalue de type « cv1 Base » et que target-type est « référence vers cv2 Derived », le résultat désigne l'objet de type Derived englobant expression si toutes les conditions suivantes sont satisfaites :
  • Derived est un type classe complet.
  • Base est une classe de base de Derived.
  • cv1 n'est pas une qualification cv plus forte que cv2.

Si l'une des conditions suivantes est satisfaite, le programme est mal formé :

  • Base est une classe de base virtuelle de Derived.
  • Base est une classe de base d'une classe de base virtuelle de Derived.
  • Aucune conversion standard valide de « pointeur vers Derived » en « pointeur vers Base » n'existe.

Si expression n'est en réalité pas un sous-objet de classe de base d'un objet de type Derived, le comportement est indéfini.

struct B {};
struct D : B { B b; };

D d;
B& br1 = d;
B& br2 = d.b;

static_cast<D&>(br1); // OK, lvalue désignant l'objet « d » d'origine
static_cast<D&>(br2); // UB : le sous-objet « b » n'est pas un sous-objet de classe de base

  1. Si target-type est « référence rvalue vers Derived » et que expression est une xvalue de type « (éventuellement qualifié cv) Base » tel que Base soit une classe de base de Derived, le résultat et les contraintes de cette conversion sont les mêmes que celles de la conversion « Base lvalue vers Derived référence ».

  2. Si target-type est un type référence rvalue et que le type référencé est compatible par référence avec le type de expression, static_cast convertit la valeur de [glvalue, prvalue de classe ou prvalue de tableau (jusqu'à C++17) | toute lvalue (depuis C++17)] expression en xvalue désignant le même objet que l'expression, ou son sous-objet de classe de base (selon target-type).[1]

Si target-type est une base inaccessible ou ambiguë du type de expression, le programme est mal formé.

Si expression est une lvalue de champ de bits, elle est d'abord convertie en prvalue du type sous-jacent.

(depuis C++11)

  1. Si target-type est le (éventuellement qualifié cv) void, la conversion n'a pas de résultat. Dans ce cas, expression est une expression de valeur rejetée.

  2. Sinon, expression peut être explicitement converti en target-type si

la déclaration target-type temp(expression ﻿); est bien formée pour une variable temporaire fictive temp.

L'effet d'une telle conversion explicite est le même que celui de la déclaration et de l'initialisation, puis d'utilisation de temp comme résultat de la conversion. Le expression ﻿ est utilisé comme [une lvalue (jusqu'à C++11) | une glvalue (depuis C++11)] si et seulement si l'initialisation l'utilise comme [une lvalue (jusqu'à C++11) | une glvalue (depuis C++11)].

(jusqu'à C++17)

l'une des conditions suivantes est satisfaite :

  • Il existe une séquence de conversion implicite de expression vers target-type.
  • La résolution de surcharge pour une initialisation directe d'un objet ou d'une référence de type target-type à partir de expression trouverait au moins une fonction viable.
  • target-type est un type agrégat dont le premier élément est x, et il existe une séquence de conversion implicite de expression vers le type de x.

(depuis C++20)

La conversion explicite est définie comme suit :

  • Si target-type est un type référence, l'effet est le même que celui de la déclaration et de l'initialisation target-type temp(expression ﻿); pour une variable temporaire inventée temp, puis de l'utilisation de temp comme résultat de la conversion.
  • Sinon, l'objet résultat est initialisé directement à partir de expression ﻿.

(depuis C++17)

  1. Sinon, si la conversion de expression vers target-type est l'inverse d'une séquence de conversion standard, et que la séquence de conversion ne contient aucune des conversions suivantes, la conversion peut être effectuée par static_cast :
  • conversion lvalue vers rvalue
  • conversion tableau vers pointeur
  • conversion fonction vers pointeur
  • conversion de pointeur nul
  • conversion de pointeur membre nul
  • conversion booléenne
  • conversion de pointeur de fonction

(depuis C++17)

Si un programme utilise static_cast pour effectuer l'inverse d'une séquence de conversion standard mal formée, le programme est mal formé.

  1. Sinon, les conversions lvalue vers rvalue, tableau vers pointeur et fonction vers pointeur sont appliquées à expression. Après ces conversions, seules les conversions suivantes peuvent être effectuées par static_cast :

a) Une valeur de type énumération à portée peut être convertie en type entier ou à virgule flottante.

  • Si target-type est (éventuellement qualifié cv) bool, le résultat est false si la valeur originale de expression est zéro, et true pour toutes les autres valeurs.
  • Si target-type est un type entier autre que (éventuellement qualifié cv) bool, la valeur est inchangée si la valeur originale de expression peut être représentée par target-type. Sinon, la valeur résultante est non spécifiée.

(jusqu'à C++20)

  • Si target-type est un type entier, le résultat est le même que celui de la conversion vers le type sous-jacent de l'énumération, puis vers target-type.

(depuis C++20)

  • Si target-type est un type à virgule flottante, le résultat est le même que celui de la conversion de la valeur originale vers target-type.

(depuis C++11)

b) Une valeur de type entier ou énumération peut être convertie en tout type énumération complet.

  • Si target-type a un type sous-jacent fixe, expression est d'abord converti vers ce type par promotion intégrale ou conversion intégrale, si nécessaire, puis vers target-type.
  • Si target-type n'a pas de type sous-jacent fixe, la valeur de expression est inchangée si la valeur originale se trouve dans l'intervalle des valeurs de l'énumération, sinon le comportement est indéfini.

c) Une valeur de type à virgule flottante peut aussi être convertie en tout type énumération complet. Le résultat est le même que celui de la conversion de la valeur originale de expression d'abord vers le type sous-jacent de target-type, puis vers target-type lui-même.

d) Une prvalue de type à virgule flottante peut être explicitement convertie en tout autre type à virgule flottante.

  • Si la valeur source de expression peut être représentée exactement dans target-type, elle ne change pas.
  • Sinon, si la valeur source de expression se situe entre deux valeurs représentables de target-type, le résultat de la conversion est un choix défini par l'implémentation parmi ces deux valeurs.[2]
  • Dans le cas contraire, le comportement est indéfini.

(depuis C++23)

e) [Une rvalue (jusqu'à C++11) | Une prvalue (depuis C++11)] de type « pointeur vers cv1 Base » peut être explicitement convertie en type « pointeur vers cv2 Derived » si toutes les conditions suivantes sont satisfaites :

  • Derived est un type classe complet.
  • Base est une classe de base de Derived.
  • cv1 n'est pas une qualification cv plus forte que cv2.

Si expression est une valeur de pointeur nul, le résultat est une valeur de pointeur nul de type target-type. Sinon, le résultat est un pointeur vers l'objet de type Derived englobant l'objet de type Base pointé par expression.

Si l'une des conditions suivantes est satisfaite, le programme est mal formé :

  • Base est une classe de base virtuelle de Derived.
  • Base est une classe de base d'une classe de base virtuelle de Derived.
  • Aucune conversion standard valide de « pointeur vers Derived » en « pointeur vers Base » n'existe.

Si expression n'est pas une valeur de pointeur nul et ne pointe pas réellement vers un sous-objet de classe de base d'un objet de type Derived, le comportement est indéfini.

f) [Une rvalue (jusqu'à C++11) | Une prvalue (depuis C++11)] de type « pointeur vers membre de Derived de type cv1 T » peut être explicitement convertie en type « pointeur vers membre de Base de type cv2 T » si toutes les conditions suivantes sont satisfaites :

  • Derived est un type classe complet.
  • Base est une classe de base de Derived.
  • cv1 n'est pas une qualification cv plus forte que cv2.

Si expression est une valeur de pointeur membre nul, le résultat est une valeur de pointeur membre nul de type target-type. Sinon, le résultat est un pointeur vers le membre original (éventuellement indirect) de la classe Base.

Si aucune conversion standard valide de « pointeur vers membre de Base de type T » en « pointeur vers membre de Derived de type T » n'existe, le programme est mal formé.

Si expression n'est pas une valeur de pointeur membre nul et que le membre qu'il désigne n'est pas un membre (éventuellement indirect) de la classe Base, le comportement est indéfini.

g) [Une rvalue (jusqu'à C++11) | Une prvalue (depuis C++11)] de type « pointeur vers cv1 void » peut être explicitement convertie en type « pointeur vers cv2 T » si T est un type objet et que cv1 n'est pas une qualification cv plus forte que cv2.

  • Si expression est une valeur de pointeur nul, le résultat est une valeur de pointeur nul de type target-type.
  • Si expression représente l'adresse A d'un octet en mémoire et que A satisfait l'exigence d'alignement de T, alors la valeur de pointeur résultante représente également A.
  • Le résultat de toute autre conversion de pointeur de ce type est non spécifié.
  • Si expression est le résultat d'une conversion antérieure depuis un objet de type « pointeur vers cv3 T », le résultat a la valeur originale.

(jusqu'à C++17)

  • Si expression représente l'adresse A d'un octet en mémoire mais que A ne satisfait pas l'exigence d'alignement de T, la valeur de pointeur résultante est non spécifiée.
  • Sinon, si expression pointe vers un objet a, et qu'il existe un objet b de type T (sans tenir compte de la qualification cv) qui est interconvertible par pointeur (voir ci-dessous) avec a, le résultat est un pointeur vers b.
  • Sinon, la valeur du pointeur est inchangée par la conversion.

(depuis C++17)

Comme pour toutes les expressions de transtypage, le résultat est :

  • une lvalue si target-type est de type référence lvalueou référence rvalue vers un type fonction (depuis C++11) ;
  • une xvalue si target-type est une référence rvalue vers un type objet ;

(depuis C++11)

  • une prvalue sinon.
  1. ↑ Ce type de static_cast est utilisé pour implémenter la sémantique de déplacement dans std::move.
  2. ↑ Si l'arithmétique IEEE est prise en charge, l'arrondi est par défaut au plus proche.

Objets interconvertibles par pointeur

Deux objets a et b sont interconvertibles par pointeur si :

  • ils sont le même objet, ou
  • l'un est un objet union et l'autre est un membre de donnée non statique de cet objet, ou
  • l'un est un objet de classe standard-layout et l'autre est le premier membre de donnée non statique de cet objet ou tout sous-objet de classe de base de cet objet, ou
  • il existe un objet c tel que a et c sont interconvertibles par pointeur, et c et b sont interconvertibles par pointeur.
union U { int a; double b; } u;
void* x = &u;                        // la valeur de x est « pointeur vers u »
double* y = static_cast<double*>(x); // la valeur de y est « pointeur vers u.b »
char* z = static_cast<char*>(x);     // la valeur de z est « pointeur vers u »

Notes

Les conversions de classe de base vers classe dérivée (downcasts) utilisant static_cast n'effectuent aucune vérification à l'exécution pour s'assurer que le type dynamique de l'objet pointé ou référencé est Derived, et ne peuvent être utilisées en toute sécurité que si cette précondition est garantie par d'autres moyens, par exemple lors de l'implémentation d'un polymorphisme statique. Un downcast sûr peut être réalisé avec dynamic_cast.

static_cast peut également être utilisé pour lever l'ambiguïté des surcharges de fonctions en effectuant une conversion fonction vers pointeur vers un type spécifique, comme dans

std::for_each(files.begin(), files.end(),
              static_cast<std::ostream&(*)(std::ostream&)>(std::flush));

Mots-clés

static_cast

Exemple

#include <iostream>
#include <vector>

struct B
{
    int m = 42;
    const char* hello() const
    {
        return "Hello world, this is B!\n";
    }
};

struct D : B
{
    const char* hello() const
    {
        return "Hello world, this is D!\n";
    }
};

enum class E { ONE = 1, TWO, THREE };
enum EU { ONE = 1, TWO, THREE };

int main()
{
    // 1. conversion statique vers le bas (downcast)
    D d;
    B& br = d; // conversion vers le haut via conversion implicite
    std::cout << "1) " << br.hello();
    D& another_d = static_cast<D&>(br); // downcast
    std::cout << "1) " << another_d.hello();

    // 3. lvalue vers xvalue
    std::vector<int> v0{1, 2, 3};
    std::vector<int> v2 = static_cast<std::vector<int>&&>(v0);
    std::cout << "3) after move, v0.size() = " << v0.size() << '\n';

    // 4. expression à valeur ignorée
    static_cast<void>(v2.size());

    // 5. conversion d'initialisation
    int n = static_cast<int>(3.14);
    std::cout << "5) n = " << n << '\n';
    std::vector<int> v = static_cast<std::vector<int>>(10);
    std::cout << "5) v.size() = " << v.size() << '\n';

    // 6. inverse de la conversion implicite
    void* nv = &n;
    int* ni = static_cast<int*>(nv);
    std::cout << "6) *ni = " << *ni << '\n';

    // 7a. énumération à portée vers int
    E e = E::TWO;
    int two = static_cast<int>(e);
    std::cout << "7a) " << two << '\n';

    // 7b. int vers énumération, énumération vers une autre énumération
    E e2 = static_cast<E>(two);
    [[maybe_unused]]
    EU eu = static_cast<EU>(e2);

    // 7f. conversion vers le haut de pointeur vers membre
    int D::*pm = &D::m;
    std::cout << "7f) " << br.*static_cast<int B::*>(pm) << '\n';

    // 7g. void* vers n'importe quel pointeur d'objet
    void* voidp = &e;
    [[maybe_unused]]
    std::vector<int>* p = static_cast<std::vector<int>*>(voidp);
}

Output:

1) Hello world, this is B!
1) Hello world, this is D!
3) after move, v0.size() = 0
5) n = 3
5) v.size() = 10
6) *ni = 3
7a) 2
7f) 42
