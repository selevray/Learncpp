Modèles de membres

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les déclarations de modèles (class, function, et variables (depuis C++14)) peuvent apparaître dans une spécification de membres de toute classe, structure ou union qui ne sont pas des classes locales.

#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

struct Printer
{
    // foncteur générique
    std::ostream& os;
    Printer(std::ostream& os) : os(os) {}
    template<typename T>
    void operator()(const T& obj) { os << obj << ' '; } // modèle de membre
};

int main()
{
    std::vector<int> v{1,2,3};
    std::for_each(v.begin(), v.end(), Printer(std::cout));
    std::string s{"abc"};
    std::ranges::for_each(s, Printer(std::cout));
}

Output:

1 2 3 a b c

Les spécialisations partielles d'un modèle de membre peuvent apparaître aussi bien dans la portée de la classe que dans la portée de l'espace de noms englobant. Les spécialisations explicites peuvent apparaître dans toute portée où le modèle primaire peut apparaître.

struct A
{
    template<class T> struct B;        // modèle de membre primaire
    template<class T> struct B<T*> {}; // OK : spécialisation partielle
//  template<> struct B<int*> {};      // OK via CWG 727 : spécialisation complète
};
template<> struct A::B<int*> {};       // OK
template<class T> struct A::B<T&> {};  // OK

Si la déclaration de classe englobante est à son tour un modèle de classe, lorsqu'un modèle de membre est défini en dehors du corps de la classe, il prend deux ensembles de paramètres de modèle : un pour la classe englobante, et un autre pour lui-même :

template<typename T1>
struct string
{
    // fonction membre modèle
    template<typename T2>
    int compare(const T2&);
    // les constructeurs peuvent aussi être des modèles
    template<typename T2>
    string(const std::basic_string<T2>& s) { /*...*/ }
};
// définition hors de la classe de string<T1>::compare<T2>
template<typename T1> // pour le modèle de classe englobant
template<typename T2> // pour le modèle de membre
int string<T1>::compare(const T2& s) { /* ... */ }

Modèles de fonctions membres

Destructeurs et constructeurs de copie ne peuvent pas être des modèles. Si un constructeur modèle est déclaré et peut être instancié avec la signature de type d'un constructeur de copie, le constructeur de copie déclaré implicitement est utilisé à la place.

Un modèle de fonction membre ne peut pas être virtuel, et un modèle de fonction membre d'une classe dérivée ne peut pas redéfinir une fonction membre virtuelle de la classe de base.

class Base
{
    virtual void f(int);
};

struct Derived : Base
{
    // ce modèle de membre ne redéfinit pas Base::f
    template<class T> void f(T);

    // une redéfinition non modèle peut appeler le modèle :
    void f(int i) override
    {
         f<>(i);
    }
};

Une fonction membre non modèle et un modèle de fonction membre portant le même nom peuvent être déclarés. En cas de conflit (lorsqu'une spécialisation de modèle correspond exactement à la signature de la fonction non modèle), l'utilisation de ce nom et de ce type désigne le membre non modèle, sauf si une liste explicite d'arguments de modèle est fournie.

template<typename T>
struct A
{
    void f(int); // membre non modèle

    template<typename T2>
    void f(T2); // modèle de membre
};

// définition du membre modèle
template<typename T>
template<typename T2>
void A<T>::f(T2)
{
    // du code
}

int main()
{
    A<char> ac;
    ac.f('c'); // appelle la fonction modèle A<char>::f<char>(char)
    ac.f(1);   // appelle la fonction non modèle A<char>::f(int)
    ac.f<>(1); // appelle la fonction modèle A<char>::f<int>(int)
}

Une définition hors de la classe d'un modèle de fonction membre doit être équivalente à la déclaration à l'intérieur de la classe (voir surcharge des modèles de fonctions pour la définition de l'équivalence), sinon elle est considérée comme une surcharge.

struct X
{
    template<class T> T good(T n);
    template<class T> T bad(T n);
};

template<class T> struct identity { using type = T; };

// OK : déclaration équivalente
template<class V>
V X::good(V n) { return n; }

// Error : non équivalent à aucune des déclarations à l'intérieur de X
template<class T>
T X::bad(typename identity<T>::type n) { return n; }

Modèles de fonctions de conversion

Une fonction de conversion définie par l'utilisateur peut être un modèle.

struct A
{
    template<typename T>
    operator T*(); // conversion vers un pointeur vers n'importe quel type
};

// définition hors de la classe
template<typename T>
A::operator T*() { return nullptr; }

// spécialisation explicite pour char*
template<>
A::operator char*() { return nullptr; }

// instanciation explicite
template A::operator void*();

int main()
{
    A a;
    int* ip = a.operator int*(); // appel explicite à A::operator int*()
}

Lors de la résolution de surcharge, les spécialisations des modèles de fonctions de conversion ne sont pas trouvées par recherche de nom. À la place, tous les modèles de fonctions de conversion visibles sont considérés, et chaque spécialisation produite par la déduction d'arguments de modèle (qui a des règles particulières pour les modèles de fonctions de conversion) est utilisée comme si elle avait été trouvée par la recherche de nom.

Les déclarations using dans les classes dérivées ne peuvent pas désigner des spécialisations de modèles de fonctions de conversion provenant des classes de base.

Un modèle de fonction de conversion défini par l'utilisateur ne peut pas avoir un type de retour déduit :

struct S
{
    operator auto() const { return 10; } // OK
    template<class T> operator auto() const { return 42; } // error
};

(depuis C++14)

Modèles de variables membres

Une déclaration de modèle de variable peut apparaître dans la portée de classe, auquel cas elle déclare un modèle de membre de donnée statique. Voir modèles de variables pour plus de détails.
