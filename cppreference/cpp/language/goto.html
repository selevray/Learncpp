Instruction goto

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Transfère le contrôle de manière inconditionnelle.

Utilisée lorsqu'il est par ailleurs impossible de transférer le contrôle à l'emplacement souhaité à l'aide d'autres instructions.

Syntaxe

| | | | attr ﻿*(facultatif)* goto label ; | | | |

Explication

L'instruction goto transfère le contrôle à l'emplacement spécifié par label. L'instruction goto doit se trouver dans la même fonction que le label auquel elle fait référence ; elle peut apparaître avant ou après l'étiquette.

Si le transfert de contrôle sort de la portée de variables automatiques (par exemple en sautant vers l'arrière à un point situé avant les déclarations de ces variables, ou en sautant vers l'avant hors d'une instruction composée dont les variables ont cette portée), les destructeurs sont appelés pour toutes les variables dont la portée a été quittée, dans l'ordre inverse de leur construction.

L'instruction goto ne peut pas transférer le contrôle dans une instruction à flux de contrôle limité, mais peut transférer le contrôle hors d'une instruction à flux de contrôle limité (les règles ci-dessus concernant les variables automatiques dans la portée s'appliquent).

Si le transfert de contrôle entre dans la portée de variables automatiques (par exemple en sautant vers l'avant par-dessus une instruction de déclaration), le programme est mal formé (ne peut pas être compilé), à moins que toutes les variables dont la portée est atteinte ne soient des types suivants :

  • types scalaires déclarés sans initialiseurs
  • types classes ayant des constructeurs par défaut triviaux et des destructeurs triviaux, déclarés sans initialiseurs
  • versions qualifiées cv de l'un des types ci-dessus
  • tableaux de l'un des types ci-dessus

(Remarque : les mêmes règles s'appliquent à toutes les formes de transfert de contrôle)

Notes

Dans le langage de programmation C, l'instruction goto a moins de restrictions et peut entrer dans la portée de toute variable autre qu'un tableau de taille variable ou qu'un pointeur à type variablement modifié.

Mots-clés

goto

Exemple

#include <iostream>

struct Object
{
    // destructeur non trivial
    ~Object() { std::cout << 'd'; }
};

struct Trivial
{
    double d1;
    double d2;
}; // constructeur et destructeur triviaux

int main()
{
    int a = 10;

    // boucle utilisant goto
label:
    Object obj;
    std::cout << a << ' ';
    a -= 2;

    if (a != 0)
        goto label;  // saute hors de la portée de obj, appelle le destructeur de obj
    std::cout << '\n';

    // goto peut être utilisé pour quitter efficacement des boucles imbriquées à plusieurs niveaux
    for (int x = 0; x < 3; ++x)
        for (int y = 0; y < 3; ++y)
        {
            std::cout << '(' << x << ',' << y << ") " << '\n';
            if (x + y >= 3)
                goto endloop;
        }

endloop:
    std::cout << '\n';

    goto label2; // saute dans la portée de n et t

    [[maybe_unused]] int n; // sans initialiseur

    [[maybe_unused]] Trivial t; // constructeur/destructeur triviaux, sans initialiseur

//  int x = 1;   // erreur : possède un initialiseur
//  Object obj2; // erreur : destructeur non trivial

label2:
    {
        Object obj3;
        goto label3; // saute vers l'avant, hors de la portée de obj3
    }

label3:
    std::cout << '\n';
}
