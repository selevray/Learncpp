Modèle de classe

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un modèle de classe définit une famille de classes.

Syntaxe

| | | | template < parameter-list > class-declaration | (1) | | | | template < parameter-list > requires constraint class-declaration | (2) | (depuis C++20) | | | export template < parameter-list > class-declaration | (3) | (supprimé en C++11) | |

Explication

  • class-declaration — une déclaration de classe. Le nom de classe déclaré devient un nom de modèle.
  • parameter-list — une liste non vide, séparée par des virgules, des paramètres de modèle, chacun étant soit un paramètre non typé, un paramètre de type, un paramètre de modèle, ou un pack de paramètres de l'un de ces types.
  • constraint — une expression de contrainte qui restreint les paramètres de modèle acceptés par ce modèle de classe

export était un modificateur optionnel qui déclarait le modèle comme exporté (utilisé avec un modèle de classe, il déclarait également tous ses membres exportés). Les fichiers qui instanciaient des modèles exportés n'avaient pas besoin d'inclure leurs définitions : la déclaration suffisait. Les implémentations de export étaient rares et ne s'accordaient pas entre elles sur les détails.

(jusqu'à C++11)

Instanciation de modèle de classe

Un modèle de classe n'est pas en soi un type, un objet ni une autre entité. Aucun code n'est généré à partir d'un fichier source ne contenant que des définitions de modèles. Pour qu'un code apparaisse, un modèle doit être instancié : les arguments de modèle doivent être fournis afin que le compilateur puisse générer une classe réelle (ou une fonction, à partir d'un modèle de fonction).

Instanciation explicite

| | | | template class-key template-name < argument-list > ; | (1) | | | | extern template class-key template-name < argument-list > ; | (2) | (depuis C++11) | |

  • class-key — class, struct or union

  1. Définition d'instanciation explicite

  2. Déclaration d'instanciation explicite

Une définition d'instanciation explicite force l'instanciation de la classe, de la structure ou de l'union auxquelles elle fait référence. Elle peut apparaître dans le programme à n'importe quel endroit après la définition du modèle, et pour un argument-list donné, elle n'est autorisée à apparaître qu'une seule fois dans l'ensemble du programme, aucun diagnostic requis.

Une déclaration d'instanciation explicite (un extern template) supprime l'étape d'instanciation implicite : le code qui provoquerait autrement une instanciation implicite utilise à la place la définition d'instanciation explicite fournie ailleurs (ce qui provoque des erreurs d'édition de liens si une telle instanciation n'existe pas). Cela peut servir à réduire les temps de compilation en déclarant explicitement une instanciation de modèle dans tous les fichiers source qui l'utilisent sauf un, et en la définissant explicitement dans le fichier restant.

(depuis C++11)

Les classes, les fonctions, les variables (depuis C++14), et les spécialisations de modèles membres peuvent être instanciées explicitement à partir de leurs modèles. Les fonctions membres, les classes membres et les membres de données statiques de modèles de classes peuvent être instanciés explicitement à partir de leurs définitions de membres.

L'instanciation explicite ne peut apparaître que dans l'espace de noms englobant du modèle, sauf si elle utilise un qualified-id :

namespace N
{
    template<class T>
    class Y // définition de modèle
    {
        void mf() {}
    };
}

// template class Y<int>; // erreur : modèle de classe Y non visible dans l'espace de noms global
using N::Y;
// template class Y<int>; // erreur : instanciation explicite en dehors
                          // de l'espace de noms du modèle
template class N::Y<char*>;       // OK : instanciation explicite
template void N::Y<double>::mf(); // OK : instanciation explicite

L'instanciation explicite n'a aucun effet si une spécialisation explicite est apparue auparavant pour le même ensemble d'arguments de modèle.

Seule la déclaration doit être visible lors de l'instanciation explicite d'un modèle de fonction, d'un modèle de variable (depuis C++14), d'une fonction membre ou d'un membre de données statique d'un modèle de classe, ou d'un modèle de fonction membre. La définition complète doit apparaître avant l'instanciation explicite d'un modèle de classe, d'une classe membre d'un modèle de classe, ou d'un modèle de classe membre, sauf si une spécialisation explicite avec les mêmes arguments de modèle est apparue auparavant.

Si un modèle de fonction, un modèle de variable (depuis C++14), un modèle de fonction membre, ou une fonction membre ou un membre de données statique d'un modèle de classe est instancié explicitement avec une définition d'instanciation explicite, la définition du modèle doit être présente dans la même unité de traduction.

Lorsqu'une instanciation explicite désigne une spécialisation de modèle de classe, elle sert d'instanciation explicite du même type (déclaration ou définition) pour chacun de ses membres non hérités et non modèles qui n'ont pas été explicitement spécialisés auparavant dans l'unité de traduction. Si cette instanciation explicite est une définition, elle n'est aussi une définition d'instanciation explicite que pour les membres définis à ce stade.

Les définitions d'instanciation explicite ignorent les spécificateurs d'accès des membres : les types de paramètres et les types de retour peuvent être privés.

Instanciation implicite

Lorsque du code fait référence à un modèle dans un contexte qui exige un type complètement défini, ou lorsque la complétude du type affecte le code, et que ce type particulier n'a pas été explicitement instancié, une instanciation implicite a lieu. Par exemple, lorsqu'un objet de ce type est construit, mais pas lorsqu'un pointeur vers ce type est construit.

Cela s'applique aux membres du modèle de classe : sauf si le membre est utilisé dans le programme, il n'est pas instancié et ne nécessite pas de définition.

template<class T>
struct Z // définition de modèle
{
    void f() {}
    void g(); // jamais définie
};

template struct Z<double>; // instanciation explicite de Z<double>
Z<int> a;                  // instanciation implicite de Z<int>
Z<char>* p;                // rien n'est instancié ici

p->f(); // l'instanciation implicite de Z<char> et de Z<char>::f() a lieu ici.
        // Z<char>::g() n'est jamais nécessaire et n'est jamais instancié :
        // elle n'a pas besoin d'être définie

Si un modèle de classe a été déclaré mais non défini au point d'instanciation, l'instanciation produit un type de classe incomplet :

template<class T>
class X;    // déclaration, pas définition

X<char> ch; // error: incomplete type X<char>

Classes locales et tous les modèles utilisés dans leurs membres sont instanciés dans le cadre de l'instanciation de l'entité dans laquelle la classe locale ou l'énumération est déclarée.

(depuis C++17)
