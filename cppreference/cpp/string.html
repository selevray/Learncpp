Caractères

Dans la bibliothèque standard C++, un caractère est un objet qui, lorsqu'il est traité séquentiellement, peut représenter du texte.

Ce terme désigne non seulement les objets de types de caractères, mais aussi toute valeur pouvant être représentée par un type qui fournit les définitions spécifiées dans la bibliothèque des chaînes et les bibliothèques suivantes :

  • bibliothèque de localisation
  • bibliothèque d'entrées/sorties
  • bibliothèque des expressions régulières

(depuis C++11)

Dans la bibliothèque des chaîneset la bibliothèque des expressions régulières (depuis C++11), un caractère ne peut être que de types assimilés à char, c'est-à-dire ces types non tableau qui satisfont aux exigences de [ PODType (jusqu'à C++20) | TrivialType et StandardLayoutType (depuis C++20) (jusqu'à C++26) | TriviallyCopyable et StandardLayoutType (depuis C++26)].

Pour tout type T assimilé à char, std::is_trivially_default_constructible_v<T> est true.

(depuis C++26)

Par conséquent, les caractères sont aussi appelés objets assimilés à char dans la bibliothèque des chaîneset la bibliothèque des expressions régulières (depuis C++11).

Certains composants de la bibliothèque standard acceptent des types de conteneurs de caractères. Ce sont aussi des types utilisés pour représenter des caractères individuels. Ces types sont utilisés pour l'un des arguments de modèle de std::char_traits et pour les modèles de classe qui utilisent std::char_traits.

Traits de caractères

De nombreux modèles de classe liés aux caractères (tels que std::basic_string) ont besoin d'un ensemble de types et de fonctions liés pour compléter la définition de leur sémantique. Ces types et fonctions sont fournis sous la forme d'un ensemble de types membres typedef et de fonctions dans le paramètre de modèle Traits utilisé par chacun de ces modèles. Les classes capables de compléter cette sémantique sont CharTraits.

La bibliothèque des chaînes fournit le modèle de classe std::char_traits qui définit des types et des fonctions pour std::basic_stringet std::basic_string_view (depuis C++17).

Les spécialisations suivantes sont définies, toutes satisfont aux exigences CharTraits :

Défini dans l'en-tête <string>

template<> class char_traits<char>;

template<> class char_traits<wchar_t>;

template<> class char_traits<char8_t>;  // (depuis C++20)

template<> class char_traits<char16_t>;  // (depuis C++11)

template<> class char_traits<char32_t>;  // (depuis C++11)

Lorsqu'un type de conteneur de caractères défini par l'utilisateur pour std::basic_stringet std::basic_string_view (depuis C++17) est utilisé, il est également nécessaire de fournir une classe de traits de caractères correspondante (qui peut être une spécialisation de std::char_traits).

Classes de chaînes (std::string etc.)

Le modèle de classe std::basic_string généralise la manière dont les séquences de caractères sont manipulées et stockées. La création, la manipulation et la destruction de chaînes sont toutes assurées par un ensemble pratique de fonctions membres de la classe et de fonctions associées.

Plusieurs spécialisations de std::basic_string sont fournies pour les types couramment utilisés :

Défini dans l'en-tête <string>

Type Définition

  • std::string — std::basic_string<char>
  • std::wstring — std::basic_string<wchar_t>
  • std::u8string (depuis C++20) — std::basic_string<char8_t>
  • std::u16string (depuis C++11) — std::basic_string<char16_t>
  • std::u32string (depuis C++11) — std::basic_string<char32_t>

Classes de vues de chaînes (std::string_view etc.) (depuis C++17)

Le modèle de classe std::basic_string_view fournit un objet léger offrant un accès en lecture seule à une chaîne ou à une partie d'une chaîne, au moyen d'une interface similaire à celle de std::basic_string.

Plusieurs spécialisations de std::basic_string_view sont fournies pour les types couramment utilisés :

Type Définition

  • std::wstring_view — std::basic_string_view<wchar_t>
  • std::u8string_view (depuis C++20) — std::basic_string_view<char8_t>
  • std::u16string_view — std::basic_string_view<char16_t>
  • std::u32string_view — std::basic_string_view<char32_t>

Bibliothèques associées

La bibliothèque de traitement de texte fournit la prise en charge des localisations, des conversions de chaînes (par exemple std::toupper), des fonctions de classification des caractères (par exemple std::isspace) et de la reconnaissance de l'encodage de texte (std::text_encoding).
