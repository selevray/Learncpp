Une implémentation des fonctions d'interface de coroutine utilisées en interne pour prendre en charge operator co_yield.

(yielded est un type référence défini dans std::generator.)

  1. Affecte std::addressof(val) à value_. Renvoie {}.

  2. Renvoie un objet attendable x de type non spécifié qui stocke un objet de type std::remove_cvref_t<yielded>. x est initialisé directement sans liste avec lval, dont les fonctions membres sont configurées de sorte que value_ pointe vers cet objet stocké. Puis suspend la coroutine.

3, 4) Soit x un objet generator quelconque.

Renvoie un objet attendable de type non spécifié dans lequel g.range est déplacé,

  • dont le membre await_ready renvoie false,
  • dont le membre await_suspend empile g.range.coroutine_ dans *x.active_ et
  • reprend l'exécution de la coroutine désignée par g.range.coroutine_, et
  • dont le membre await_resume évalue
    • std::rethrow_exception(except_) si bool(except_) est true.
    • Si bool(except_) est false, le membre await_resume n'a aucun effet.

La coroutine désignée par g.range.coroutine_ doit être suspendue à son point de suspension initial. Sinon, le comportement est indéfini.

  1. Équivalent à :
auto nested = [](std::allocator_arg_t, Alloc, ranges::iterator_t<R> i,
                 ranges::sentinel_t<R> s) ->
    std::generator<yielded, void, Alloc>
{
    for (; i != s; ++i)
        co_yield static_cast<yielded>(*i);
};

return yield_value(ranges::elements_of(nested(
    allocator_arg, r.allocator, ranges::begin(r.range), ranges::end(r.range))));

2,3) Un handle désignant la coroutine dont l'objet promesse est *this doit se trouver au sommet de *active_ d'un objet generator quelconque. Sinon, le comportement est indéfini.

2-5) Une expression yield qui appelle ces surcharges a le type void.

Paramètres

  • val — une valeur qui est le résultat de l'évaluation de l'expression yield
  • lval — une lvalue qui est le résultat de l'évaluation de l'expression yield
  • g — un intervalle d'éléments produits par un generator
  • r — un intervalle d'éléments

Valeur de retour

  1. L'objet attendable de type std::suspend_always.

2-5) Un objet attendable de type non spécifié tel que décrit ci-dessus.

Exceptions

2,5) Peut lever toute exception levée par l'initialisation de l'objet stocké.
