std::generator<Ref,V,Allocator>::promise_type::operator delete

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void operator delete( void* ptr, std::size_t n ) noexcept;  // (depuis C++23)

Désalloue le stockage pointé par ptr à l'aide d'un allocateur équivalent à celui utilisé pour allouer cette mémoire.

Le ptr passé à cette fonction doit être celui renvoyé par un appel de l'une des surcharges operator new avec un argument de taille égal à n. Sinon, le comportement est indéfini.

Paramètres

  • ptr — un pointeur obtenu lors de l'appel précédent à operator new
  • n — la taille du stockage à désallouer
