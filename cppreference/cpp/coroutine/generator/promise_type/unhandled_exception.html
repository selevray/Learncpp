Soit x un objet generator quelconque.

Si un handle désignant la coroutine dont le objet promesse est *this se trouve au sommet de *active_ de x :

  • Si le handle désignant la coroutine dont l'objet promesse est *this est le seul élément de *x.active_, équivalent à throw;.
  • Sinon, affecte std::current_exception() à except_.

Dans le cas contraire, le comportement est indéfini.
