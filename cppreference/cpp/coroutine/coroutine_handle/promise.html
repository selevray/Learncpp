std::coroutine_handle<Promise>::promise

Promise& promise() const;  // (depuis C++20)

Membre de la spécialisation std::coroutine_handle<std::noop_coroutine_promise>

std::noop_coroutine_promise& promise() const noexcept;  // (depuis C++20)

Obtient une référence à l'objet promesse.

Le comportement est indéfini si *this ne fait pas référence à une coroutine dont l'objet promesse n'a pas été détruit.

Cette fonction n'est pas fournie pour la spécialisation std::coroutine_handle<>.

Paramètres

(aucune)

Valeur de retour

Une référence à l'objet promesse.

Notes

L'objet promesse d'une coroutine sans effet n'est pas détruit tant qu'il existe un std::noop_coroutine_handle faisant référence à la coroutine.
