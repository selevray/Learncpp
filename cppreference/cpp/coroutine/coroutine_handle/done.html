constexpr bool done() const noexcept;  // (2) (depuis C++20)

Vérifie si une coroutine suspendue est suspendue à son point de suspension final.

  1. Renvoie true si la coroutine à laquelle *this fait référence est suspendue à son point de suspension final, ou false si la coroutine est suspendue à d'autres points de suspension. Le comportement est indéfini si *this ne fait pas référence à une coroutine suspendue.

  2. Renvoie toujours false.

Paramètres

(aucune)

Valeur de retour

  1. true si la coroutine est suspendue à son point de suspension final, false si elle est suspendue à d'autres points de suspension.

  2. false

Notes

Une coroutine sans effet n'est jamais considérée comme suspendue à son point de suspension final.

Une coroutine dont l'objet promesse est p n'est considérée comme suspendue à son point de suspension final que si, en notant e le résultat de p.final_suspend(), e.await_ready() renvoie false. En particulier, si p.final_suspend() renvoie std::suspend_never, alors done() ne renvoie jamais true.
