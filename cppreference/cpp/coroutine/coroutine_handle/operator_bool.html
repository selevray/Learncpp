std::coroutine_handle<Promise>::operator bool

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr explicit operator bool() const noexcept;  // (depuis C++20)

Vérifie si *this est non nul, c'est-à-dire si la valeur de *this provient de l'objet promesse d'une coroutine. Équivalent à return bool(address());.

Si Promise est std::noop_coroutine_promise, cette fonction de conversion renvoie toujours true.

Paramètres

(aucune)

Valeur de retour

bool(address()), ou true si Promise est std::noop_coroutine_promise.
