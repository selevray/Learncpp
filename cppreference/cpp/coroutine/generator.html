  1. Le modèle de classe std::generator présente un view des éléments produits par l'évaluation d'une coroutine.

  2. Alias de modèle pratique pour generator utilisant l'allocateur polymorphe.

Un std::generator génère une séquence d'éléments en reprenant de façon répétée la coroutine dont il a été renvoyé. À chaque fois qu'une instruction co_yield est évaluée, la coroutine produit un élément de la séquence. Lorsque l'instruction co_yield est de la forme co_yield ranges::elements_of(rng), chaque élément de l'range rng est produit successivement comme élément de la séquence.

std::generator modélise view et input_range.

Le comportement d'un programme qui ajoute une spécialisation pour std::generator est indéfini.

Paramètres de modèle

  • Ref — le type de référence (ranges::range_reference_t) du générateur. Si V est void, le type de référence et le type de valeur sont déduits de Ref
  • V — le type de valeur (ranges::range_value_t) du générateur, ou void
  • Allocator — un type d'allocateur ou void

Si Allocator n'est pas void, alors le comportement est indéfini si Allocator ne satisfait pas les exigences Allocator.

Membres de données

Membre Définition

  • active_ (privé) —

    En interne, chaque instance active de std::generator est associée à une pile (gérée comme un objet de type std::unique_ptr<std::stack<std::coroutine_handle<>>>).

    • Lorsque begin est appelée, une nouvelle pile est créée et le générateur y est ajouté.
    • Lorsque co_yield ranges::elements_of(rng) est évalué dans le corps d'un générateur, rng est converti en générateur et ajouté à la pile qui contient le générateur englobant.
    • Lorsqu'un itérateur de générateur est incrémenté, la coroutine au sommet de la pile associée est reprise.
    • Lorsqu'un générateur se termine (c.-à-d. lorsque promise_type::final_suspend est appelée), il est retiré de la pile. (objet membre exposé uniquement)*

  • coroutine_ (privé) — un handle de type std::coroutine_handle<promise_type> (objet membre exposé uniquement)*

Exemple

#include <generator>
#include <iostream>

template<typename T>
struct Tree
{
    T value;
    Tree *left{}, *right{};

    std::generator<const T&> traverse_inorder() const
    {
        if (left)
            co_yield std::ranges::elements_of(left->traverse_inorder());

        co_yield value;

        if (right)
            co_yield std::ranges::elements_of(right->traverse_inorder());
    }
};

int main()
{
    Tree<char> tree[]
    {
                                    {'D', tree + 1, tree + 2},
        //                            │
        //            ┌───────────────┴────────────────┐
        //            │                                │
                    {'B', tree + 3, tree + 4},       {'F', tree + 5, tree + 6},
        //            │                                │
        //  ┌─────────┴─────────────┐      ┌───────────┴─────────────┐
        //  │                       │      │                         │
          {'A'},                  {'C'}, {'E'},                    {'G'}
    };

    for (char x : tree->traverse_inorder())
        std::cout << x << ' ';
    std::cout << '\n';
}

Output:

A B C D E F G
