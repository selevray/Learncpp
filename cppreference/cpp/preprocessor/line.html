Informations sur le nom de fichier et la ligne

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Modifie le numéro de ligne du code source et, éventuellement, le nom du fichier courant, dans le préprocesseur.

Syntaxe

| | | | #line lineno | (1) | | | | #line lineno "filename" | (2) | | |

Explication

  1. Modifie le numéro de ligne courant du préprocesseur en lineno. Les expansions de la macro __LINE__ au-delà de ce point se développent en lineno plus le nombre de lignes de code source réelles rencontrées depuis.

  2. Modifie également le nom de fichier courant du préprocesseur en filename. Les expansions de la macro __FILE__ à partir de ce point produiront filename.

Tous les jetons de prétraitement (constantes de macro ou expressions) sont admis comme arguments de #line, à condition qu'ils se développent en un entier décimal valide, éventuellement suivi d'une chaîne de caractères valide.

lineno doit être une suite d'au moins un chiffre décimal (sinon le programme est mal formé) et est toujours interprété en décimal (même s'il commence par 0).

Si lineno vaut 0 ou est supérieur à [32767 (jusqu'à C++11) | 2147483647 (depuis C++11)], le comportement est indéfini.

Notes

Cette directive est utilisée par certains outils de génération automatique de code qui produisent des fichiers source C++ à partir d'un fichier écrit dans un autre langage. Dans ce cas, des directives #line peuvent être insérées dans le fichier C++ généré, faisant référence aux numéros de ligne et au nom du fichier source original (modifiable par un humain).

Exemple

#include <cassert>
#define FNAME "test.cc"
int main()
{
#line 777 FNAME
        assert(2+2 == 5);
}

Sortie possible :

test: test.cc:777: int main(): Assertion `2+2 == 5' failed.
