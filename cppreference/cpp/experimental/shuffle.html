std::experimental::shuffle

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/algorithm>

template< class RandomIt >
void shuffle( RandomIt first, RandomIt last );  // (spécification technique library fundamentals v2)

Réordonne les éléments de l'intervalle donné [first,last) de sorte que chaque permutation possible de ces éléments ait une probabilité égale d'apparaître, en utilisant le moteur de nombres aléatoires par thread comme générateur de nombres aléatoires.

Paramètres

  • first, last — l'intervalle d'éléments à mélanger aléatoirement
  • RandomIt doit satisfaire aux exigences de ValueSwappable et de LegacyRandomAccessIterator.

Valeur de retour

(aucune)

Complexité

Linéaire en la distance entre first et last.

Exemple

#include <experimental/algorithm>
#include <iostream>
#include <string>

int main()
{
    std::string sample{"ABCDEF"};

    for (int i = 0; i != 4; ++i)
    {
        std::experimental::shuffle(sample.begin(), sample.end());
        std::cout << sample << '\n';
    }
}
