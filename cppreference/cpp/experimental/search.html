std::experimental::search

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/algorithm>

template< class ForwardIterator, class Searcher >
ForwardIterator search( ForwardIterator first, ForwardIterator last,
                        const Searcher& searcher );  // (TS des fondamentaux de la bibliothèque)

Recherche le motif spécifié dans le constructeur de searcher dans la séquence [first,last).

Exécute effectivement searcher(first, last).

(jusqu'à C++17)

Exécute effectivement searcher(first, last).first.

(depuis C++17)

Searcher n'a pas besoin d'être CopyConstructible.

La bibliothèque standard fournit les chercheurs suivants :

  • default_searcher — implémentation de l'algorithme de recherche de la bibliothèque standard C++ (modèle de classe)
  • boyer_moore_searcher — implémentation de l'algorithme de recherche de Boyer-Moore (modèle de classe)
  • boyer_moore_horspool_searcher — implémentation de l'algorithme de recherche de Boyer-Moore-Horspool (modèle de classe)

Paramètres

Cette section est incomplète

Valeur de retour

Retourne le résultat de searcher.operator(), c'est-à-dire un itérateur vers l'emplacement où la sous-chaîne est trouvée, ou une copie de last si elle n'a pas été trouvée.

Complexité

Dépend du searcher.

Exemple

#include <experimental/algorithm>
#include <experimental/functional>
#include <iostream>
#include <string>

int main()
{
    std::string in = "Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed "
                     "do eiusmod tempor incididunt ut labore et dolore magna aliqua";
    std::string needle = "pisci";
    auto it = std::experimental::search(in.begin(), in.end(),
                  std::experimental::make_boyer_moore_searcher(
                      needle.begin(), needle.end()));
    if (it != in.end())
        std::cout << "The string " << needle << " found at offset "
                  << it - in.begin() << '\n';
    else
        std::cout << "The string " << needle << " not found\n";
}

Output:

The string pisci found at offset 43
