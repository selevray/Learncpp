std::experimental::reflect::get_source_line

template< Object T >
struct get_source_line;  // (TS de réflexion)

Fournit la constante membre value égale au numéro de ligne présumé de la déclaration de l'entité ou du typedef-name reflété par T.

Modèle de variable auxiliaire

template< class T >
constexpr auto get_source_line_v = get_source_line<T>::value;  // (TS de réflexion)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — le numéro de ligne présumé de la déclaration de l'entité ou du typedef-name reflété par T (constante membre statique publique)

Fonctions membres

  • operator std::uint_least32_t — convertit l'objet en std::uint_least32_t, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — std::uint_least32_t
  • type — std::integral_constant<std::uint_least32_t, value>

Exemple

Le code suivant montre la ligne de code source d'un objet ou d'une classe.

#include<experimental/reflect>
#include<iostream>

using refl = std::experimental::reflect;

float f;
struct P{};

int main()
{
    std::cout << refl::get_source_line_v<reflexpr(f)> << '\n';
    std::cout << refl::get_source_line_v<reflexpr(P)> << '\n';
}

Output:

6
7
