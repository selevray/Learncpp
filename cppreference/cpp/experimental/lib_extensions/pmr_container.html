Alias de commodité pour les conteneurs utilisant des allocateurs polymorphes (library fundamentals TS)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les alias de commodité et modèles d'alias suivants pour les conteneurs utilisant des allocateurs polymorphes sont définis dans l'espace de noms std::experimental::pmr.

Chaînes

Alias/modèle d'alias Alias de

Défini dans l'en-tête <experimental/string>

  • template<class CharT, class Traits=std::char_traits<CharT>> using basic_string = — std::basic_string<CharT, Traits, polymorphic_allocator<CharT>>;
  • using string = — pmr::basic_string<char>;
  • using wstring = — pmr::basic_string<wchar_t>;
  • using u16string = — pmr::basic_string<char16_t>;
  • using u32string = — pmr::basic_string<char32_t>;
