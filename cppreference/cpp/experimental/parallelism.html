Politiques d'exécution

Le parallelism TS décrit trois politiques d'exécution : sequential, parallel et parallel+vector, et fournit les types et objets de politique d'exécution correspondants. Les utilisateurs peuvent choisir une politique d'exécution statiquement en invoquant un algorithme parallèle avec un objet de politique d'exécution du type correspondant, ou dynamiquement en utilisant la classe à effacement de type execution_policy.

Les implémentations peuvent définir des politiques d'exécution supplémentaires en tant qu'extension. La sémantique des algorithmes parallèles invoqués avec un objet de politique d'exécution de type défini par l'implémentation est définie par l'implémentation.

Défini dans l'en-tête <experimental/execution_policy>

  • sequential_execution_policyparallel_execution_policyparallel_vector_execution_policy — types de politique d'exécution (classe)
  • seqparpar_vec — objets de politique d'exécution globaux (constante)
  • execution_policy — politique d'exécution dynamique (classe)
  • is_execution_policy — teste si une classe représente une politique d'exécution (modèle de classe)

Nouveaux algorithmes

Défini dans l'en-tête <experimental/algorithm>

  • for_each — similaire à std::for_each sauf qu'elle renvoie void (modèle de fonction)
  • for_each_n — applique un objet fonction aux n premiers éléments d'une séquence (modèle de fonction)

Défini dans l'en-tête <experimental/numeric>

  • reduce (parallelism TS) — similaire à std::accumulate, sauf dans le désordre (modèle de fonction)
  • exclusive_scan — similaire à std::partial_sum, exclut le i-ième élément d'entrée de la i-ième somme (modèle de fonction)
  • inclusive_scan — similaire à std::partial_sum, inclut le i-ième élément d'entrée dans la i-ième somme (modèle de fonction)
  • transform_reduce (parallelism TS) — applique un foncteur, puis réduit dans le désordre (modèle de fonction)
  • transform_exclusive_scan — applique un foncteur, puis calcule le scan exclusif (modèle de fonction)
  • transform_inclusive_scan — applique un foncteur, puis calcule le scan inclusif (modèle de fonction)
