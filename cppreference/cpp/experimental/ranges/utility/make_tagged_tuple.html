Fonction utilitaire permettant de créer un tuple marqué, en déduisant les types des éléments à partir des arguments (les spécificateurs de tag doivent être explicitement spécifiés).

La partie voir ci-dessous du type de retour est decltype(std::make_tuple(std::forward<Types>(t)...)).

Valeur de retour

R(std::forward<Types>(t)...), où R est le type de retour.
