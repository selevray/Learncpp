std::experimental::ranges::TaggedType

template< class T >
concept bool TaggedType = /* défini par l'implémentation */;  // (ranges TS)

Le concept TaggedType<T> est satisfait si et seulement si T est un type de fonction unaire de la forme R(A), où R est un TagSpecifier.

De tels types sont utilisés avec les modèles d'alias de commodité tagged_tuple et tagged_pair.
