std::tuple_size<std::experimental::ranges::tagged>

template< class Base, class... Tags >
struct tuple_size<std::experimental::ranges::tagged<Base, Tags...>>
    : std::tuple_size<Base> {};  // (ranges TS)

La spécialisation partielle de std::tuple_size pour tagged permet d'obtenir le nombre d'éléments d'un objet tagged en utilisant une syntaxe semblable à celle des tuples. Elle délègue simplement à std::tuple_size<Base>.
