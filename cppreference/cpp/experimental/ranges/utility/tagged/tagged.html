Construit un objet tagged.

  1. tagged<Base, Tags...> hérite des constructeurs de Base.

2-4) tagged possède des constructeurs par défaut, de copie et de déplacement par défaut qui invoquent le constructeur correspondant de Base.

  1. Constructeur de déplacement avec conversion depuis Base. Initialise le sous-objet Base avec std::move(that).

  2. Constructeur de copie avec conversion depuis Base. Initialise le sous-objet Base avec that.

  3. Constructeur de déplacement avec conversion depuis une spécialisation tagged différente aux tags correspondants. Initialise le sous-objet Base avec static_cast<Other&&>(that).

  4. Constructeur de copie avec conversion depuis une spécialisation tagged différente aux tags correspondants. Initialise le sous-objet Base avec static_cast<const Other&>(that).
