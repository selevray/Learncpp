Modèle d'alias de commodité pour désigner un ranges::tagged englobant un std::pair.

Un TaggedType est un type de fonction S(T), où S est un TagSpecifier et T est le type de l'élément.

tagged_pair<S1(T1), S2(T2)> est un alias de ranges::tagged<std::pair<T1, T2>, S1, S2>.

Notes

Comme un type de fonction sert à « relier » le spécificateur de tag et le type d'élément correspondant, les ajustements habituels des types de paramètres s'appliquent. En particulier, les qualificateurs cv de premier niveau sont supprimés et les types tableau sont ajustés en pointeurs : tagged_pair<tag::in(const int* const), tag::out(int[])> est ranges::tagged<std::pair<const int*, int*>, tag::in, tag::out>.
