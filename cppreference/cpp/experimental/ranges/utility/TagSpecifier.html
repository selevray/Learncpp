std::experimental::ranges::TagSpecifier

template< class T >
concept bool TagSpecifier = /* défini par l'implémentation */;  // (ranges TS)

Le concept TagSpecifier<T> est satisfait si et seulement si T est un spécificateur de tag destiné à être utilisé avec ranges::tagged.

Le Ranges TS fournit un ensemble de spécificateurs de tag dans <experimental/ranges/algorithm>. Les utilisateurs ne peuvent pas définir leurs propres spécificateurs de tag.
