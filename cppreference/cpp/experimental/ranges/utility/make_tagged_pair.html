Fonction utilitaire permettant de créer une paire marquée, en déduisant les types des éléments à partir des arguments (les spécificateurs de tag doivent être explicitement spécifiés).

La partie voir ci-dessous du type de retour est decltype(std::make_pair(std::forward<T1>(x), std::forward<T2>(y))).

Valeur de retour

R(std::forward<T1>(x), std::forward<T2>(y)), où R est le type de retour.
