std::experimental::ranges::WeaklyIncrementable

template< class I >
concept bool WeaklyIncrementable =
    Semiregular<I> &&
    requires(I i) {
        typename ranges::difference_type_t<I>;
        requires SignedIntegral<ranges::difference_type_t<I>>;
        { ++i } -> Same<I>&; /* non tenu de préserver l'égalité */
        i++; /* non tenu de préserver l'égalité */
    };  // (ranges TS)

Le concept WeaklyIncrementable<I> spécifie les exigences sur un type pouvant être incrémenté (avec les opérateurs d'incrémentation préfixe et postfixe). Les opérations d'incrémentation n'ont pas besoin de préserver l'égalité, et le type n'a pas besoin d'être EqualityComparable.

Soit i un objet de type I. i est dit incrémentable s'il appartient au domaine de l'incrémentation préfixe et postfixe. WeaklyIncrementable<I> n'est satisfait que si :

  • ++i et i++ ont le même domaine ;
  • Si i est incrémentable, alors :
    • ++i et i++ font tous deux avancer i vers l'élément suivant ; et
    • ++i désigne le même objet que i.

Préservation de l'égalité

Une expression est préservant l'égalité si elle produit des sorties égales pour des entrées égales.

  • Les entrées d'une expression sont constituées de ses opérandes.
  • Les sorties d'une expression sont constituées de son résultat et de tous les opérandes modifiés par l'expression (le cas échéant).

Toute expression devant préserver l'égalité doit en outre être stable : deux évaluations d'une telle expression avec les mêmes objets d'entrée doivent produire des sorties égales, en l'absence de toute modification explicite intermédiaire de ces objets d'entrée.

Notes

Pour les types WeaklyIncrementable, a égal à b n'implique pas que ++a soit égal à ++b. Les algorithmes sur de tels types doivent être à passage unique et ne jamais tenter de repasser deux fois par la même valeur.
