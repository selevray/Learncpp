std::experimental::ranges::Incrementable

Défini dans l'en-tête <experimental/ranges/iterator>

template< class I >
concept bool Incrementable =
    Regular<I> &&
    WeaklyIncrementable<I> &&
    requires(I i) {
        { i++ } -> Same<I>&&;
    };  // (ranges TS)

Le concept Incrementable<I> spécifie les exigences sur un type pouvant être incrémenté (avec les opérateurs d'incrémentation préfixe et postfixe). Les opérations d'incrémentation (y compris celles exigées par WeaklyIncrementable) doivent préserver l'égalité, et le type doit être EqualityComparable.

Soient a et b des objets incrémentables de type I. Incrementable<I> est satisfait uniquement si :

  • Si bool(a == b) alors bool(a++ == b).
  • Si bool(a == b) alors bool(void(a++), a) == ++b).

Préservation de l'égalité

Une expression est préservant l'égalité si elle produit des sorties égales pour des entrées égales.

  • Les entrées d'une expression sont constituées de ses opérandes.
  • Les sorties d'une expression sont constituées de son résultat et de tous les opérandes modifiés par l'expression (le cas échéant).

Toute expression devant préserver l'égalité doit en outre être stable : deux évaluations d'une telle expression avec les mêmes objets d'entrée doivent produire des sorties égales, en l'absence de toute modification explicite intermédiaire de ces objets d'entrée.

Sauf indication contraire, toute expression utilisée dans une requires-expression doit préserver l'égalité et être stable, et l'évaluation de l'expression ne peut modifier que ses opérandes non constants. Les opérandes constants ne doivent pas être modifiés.

Notes

L'exigence selon laquelle a égale b implique que ++a égale ++b permet d'utiliser des algorithmes à passages multiples avec des types Incrementable.
