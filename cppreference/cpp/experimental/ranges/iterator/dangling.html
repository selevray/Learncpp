template< Range R >
using safe_iterator_t = std::conditional_t<std::is_lvalue_reference<R>::value,
                                           ranges::iterator_t<R>,
                                           ranges::dangling<ranges::iterator_t<R>>;  // (ranges TS)

Le modèle de classe dangling est un simple wrapper autour d'un objet pour indiquer que l'objet encapsulé peut être dangling, c'est-à-dire qu'il désigne un autre objet dont la durée de vie peut être terminée.

Le modèle d'alias safe_iterator_t renvoie le type d'itérateur de R, encapsulé dans dangling si l'intervalle était un intervalle de rvalue (ce qui est indiqué par le fait que R n'est pas un type de référence lvalue).

Ils sont utilisés par les algorithmes sur intervalles qui acceptent des intervalles de rvalue et renvoient des itérateurs vers ceux-ci.
