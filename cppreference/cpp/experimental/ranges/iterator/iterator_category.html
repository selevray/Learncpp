std::experimental::ranges::iterator_category

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/ranges/iterator>

template< class I >
struct iterator_category {};  // (1)

template< class T >
struct iterator_category<T*>;  // (2)

template< class T >
struct iterator_category<const T> : iterator_category<T> {};  // (3)

template< class T >
    requires requires { typename T::iterator_category; }
struct iterator_category<T>;  // (4)

Calcule la catégorie d'itérateur de la classe I, s'il en existe une. Les utilisateurs peuvent spécialiser iterator_category pour un type défini par le programme.

  1. Le modèle primaire est une structure vide.

  2. Spécialisation pour les pointeurs. Si T est un type objet, fournit un type membre type égal à ranges::random_access_iterator_tag. Sinon, il n'existe pas de membre type.

  3. Spécialisation pour les types qualifiés const.

  4. Spécialisation pour les types qui définissent un type membre public et accessible iterator_category. Si T::iterator_category est identique à l'une des étiquettes de catégorie d'itérateur de l'espace de noms std, ou en dérive, elle est associée à l'étiquette correspondante de l'espace de noms ranges, comme décrit ci-dessous. Sinon, fournit un type membre type égal à T::iterator_category.

  • Si T::iterator_category est identique à std::random_access_iterator_tag ou en dérive, fournit un type membre type égal à ranges::random_access_iterator_tag.
  • Sinon, si T::iterator_category est identique à std::bidirectional_iterator_tag ou en dérive, fournit un type membre type égal à ranges::bidirectional_iterator_tag.
  • Sinon, si T::iterator_category est identique à std::forward_iterator_tag ou en dérive, fournit un type membre type égal à ranges::forward_iterator_tag.
  • Sinon, si T::iterator_category est identique à std::input_iterator_tag ou en dérive, fournit un type membre type égal à ranges::input_iterator_tag.
  • Sinon, si T::iterator_category est identique à std::output_iterator_tag ou en dérive, il n'existe pas de membre type.

Modèle d'alias auxiliaire

template< class T >
using iterator_category_t = typename ranges::iterator_category<T>::type;  // (ranges TS)
