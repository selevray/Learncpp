std::experimental::ranges::InputIterator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/ranges/iterator>

template< class I >
concept bool InputIterator =
    Iterator<I> && Readable<I> &&
    requires { typename ranges::iterator_category_t<I>; } &&
    DerivedFrom<ranges::iterator_category_t<I>, ranges::input_iterator_tag>;  // (ranges TS)

Le concept InputIterator est un affinement de Iterator, ajoutant l'exigence que les valeurs référencées puissent être lues (via Readable) et l'exigence que l'étiquette de catégorie d'itérateur soit présente.

Notes

Contrairement aux exigences sur les itérateurs d'entrée de la norme C++, InputIterator dans le TS Ranges n'exige pas EqualityComparable.
