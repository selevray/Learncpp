std::experimental::ranges::OutputIterator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/ranges/iterator>

template< class I, class T >
concept bool OutputIterator =
    Iterator<I> && Writable<I, T> &&
    requires(I i, T&& t) {
        *i++ = std::forward<T>(t); // non tenu de préserver l'égalité
    };  // (ranges TS)

Le concept OutputIterator est un affinement de Iterator, ajoutant l'exigence qu'il puisse être utilisé pour écrire des valeurs de type et de catégorie de valeur codés par T (via Writable). EqualityComparable n'est pas requis.

Soit E une expression telle que decltype((E)) soit T, et i un objet déréférençable de type I. OutputIterator<I, T> est satisfait uniquement si *i++ = E; a des effets équivalents à *i = E; ++i;.

Préservation de l'égalité

Une expression est préservant l'égalité si elle produit des sorties égales pour des entrées égales.

  • Les entrées d'une expression sont constituées de ses opérandes.
  • Les sorties d'une expression sont constituées de son résultat et de tous les opérandes modifiés par l'expression (le cas échéant).

Toute expression devant préserver l'égalité doit en outre être stable : deux évaluations d'une telle expression avec les mêmes objets d'entrée doivent produire des sorties égales, en l'absence de toute modification explicite intermédiaire de ces objets d'entrée.

Notes

Contrairement aux exigences sur les itérateurs de sortie de la norme C++, OutputIterator dans le TS Ranges n'exige pas que l'étiquette de catégorie d'itérateur soit définie.

Les algorithmes sur les itérateurs de sortie devraient être à passage unique.
