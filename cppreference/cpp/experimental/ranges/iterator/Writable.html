template< class Out, class T >
concept bool Writable =
    requires(Out&& o, T&& t) {
        *o = std::forward<T>(t);
        *std::forward<Out>(o) = std::forward<T>(t);
        const_cast<const ranges::reference_t<Out>&&>(*o) =
            std::forward<T>(t);
        const_cast<const ranges::reference_t<Out>&&>(*std::forward<Out>(o)) =
            std::forward<T>(t);
    };
    /* aucune des quatre expressions ci-dessus n'est tenue de préserver l'égalité */  // (ranges TS)

Le concept Writable<Out, T> spécifie les exigences pour écrire une valeur dont le type et la catégorie de valeur sont codés par T dans l'objet référencé par un itérateur Out.

Soit E une expression telle que decltype((E)) soit T, et o un objet déréférençable de type Out, alors Writable<Out, T> n'est satisfait que si :

  • Si Readable<Out> && Same<ranges::value_type_t<Out>, std::decay_t<T>> est satisfait, alors *o après toute affectation ci-dessus est égal à la valeur de E avant l'affectation.

o n'est pas tenu d'être déréférençable après l'évaluation de l'une des expressions d'affectation ci-dessus. Si E est une xvalue, l'état résultant de l'objet qu'elle désigne est valide mais non spécifié.

Préservation de l'égalité

Une expression est préservant l'égalité si elle produit des sorties égales pour des entrées égales.

  • Les entrées d'une expression sont constituées de ses opérandes.
  • Les sorties d'une expression sont constituées de son résultat et de tous les opérandes modifiés par l'expression (le cas échéant).

Toute expression devant préserver l'égalité doit en outre être stable : deux évaluations d'une telle expression avec les mêmes objets d'entrée doivent produire des sorties égales, en l'absence de toute modification explicite intermédiaire de ces objets d'entrée.

Notes

La seule utilisation valide de operator* est à gauche d'une expression d'affectation. Une affectation par la même valeur d'un type inscriptible ne peut se produire qu'une seule fois.

Les expressions requises avec const_cast empêchent les objets Readable dont les types sont des prvalues reference de satisfaire par accident les exigences syntaxiques de Writable, tout en permettant aux références mandataires de continuer à fonctionner tant que leur constance est superficielle. Voir Ranges TS issue 381.
