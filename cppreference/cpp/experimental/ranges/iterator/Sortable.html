std::experimental::ranges::Sortable

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class I, class R = ranges::less<>, class P = ranges::identity >
concept bool Sortable =
    Permutable<I> &&
    IndirectStrictWeakOrder<R, ranges::projected<I, P>>;  // (ranges TS)

Le concept Sortable spécifie les exigences communes des algorithmes qui permutent des séquences en séquences ordonnées (par exemple, ranges::sort).
