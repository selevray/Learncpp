std::experimental::ranges::Integral

Défini dans l'en-tête <experimental/ranges/concepts>

template< class T >
concept bool Integral = std::is_integral<T>::value;  // (ranges TS)

Le concept Integral<T> est satisfait si et seulement si T est un type entier.

Il n'est pas nécessaire qu'il existe une relation de subsomption entre Integral<T> et std::is_integral<T>::value.
