template< class B >
concept bool Boolean =
    Movable<std::decay_t<B>> &&
    requires(const std::remove_reference_t<B>& b1,
             const std::remove_reference_t<B>& b2, const bool a) {
        { b1 }       -> ConvertibleTo<bool>&&;
        { !b1 }      -> ConvertibleTo<bool>&&;
        { b1 && a }  -> Same<bool>&&;
        { b1 || a }  -> Same<bool>&&;
        { b1 && b2 } -> Same<bool>&&;
        { a && b2  } -> Same<bool>&&;
        { b1 || b2 } -> Same<bool>&&;
        { a || b2  } -> Same<bool>&&;
        { b1 == b2 } -> ConvertibleTo<bool>&&;
        { b1 == a  } -> ConvertibleTo<bool>&&;
        { a == b2  } -> ConvertibleTo<bool>&&;
        { b1 != b2 } -> ConvertibleTo<bool>&&;
        { b1 != a  } -> ConvertibleTo<bool>&&;
        { a != b2  } -> ConvertibleTo<bool>&&;
    };  // (ranges TS)

Le concept Boolean<B> spécifie les exigences pour un type utilisable dans des contextes booléens. Pour que Boolean soit satisfait, les opérateurs logiques doivent avoir le comportement habituel (y compris l'évaluation court-circuitée). Plus précisément, étant donné

  • b1, b2, deux lvalues de type const std::remove_reference_t<B>,

Boolean<B> n'est satisfait que si :

  • bool(b1) == !bool(!b1);
  • b1 && b2, b1 && bool(b2) et bool(b1) && b2 sont tous égaux à bool(b1) && bool(b2) et ont la même évaluation court-circuitée ;
  • b1 || b2, b1 || bool(b2) et bool(b1) || b2 sont tous égaux à bool(b1) || bool(b2) et ont la même évaluation court-circuitée ;
  • bool(b1 == b2), bool(b1 == bool(b2)) et bool(bool(b1) == b2) sont tous égaux à (bool(b1) == bool(b2)) ;
  • bool(b1 != b2), bool(b1 != bool(b2)) et bool(bool(b1) != b2) sont tous égaux à (bool(b1) != bool(b2)).

Préservation de l'égalité

Une expression est préservant l'égalité si elle produit des sorties égales pour des entrées égales.

  • Les entrées d'une expression sont constituées de ses opérandes.
  • Les sorties d'une expression sont constituées de son résultat et de tous les opérandes modifiés par l'expression (le cas échéant).

Toute expression devant préserver l'égalité doit en outre être stable : deux évaluations d'une telle expression avec les mêmes objets d'entrée doivent produire des sorties égales, en l'absence de toute modification explicite intermédiaire de ces objets d'entrée.

Sauf indication contraire, toute expression utilisée dans une requires-expression doit préserver l'égalité et être stable, et l'évaluation de l'expression ne peut modifier que ses opérandes non constants. Les opérandes constants ne doivent pas être modifiés.

Variations implicites d'expressions

Une requires-expression qui utilise une expression non modifiante pour une lvalue constante en opérande exige aussi implicitement des variantes supplémentaires de cette expression acceptant une lvalue non constante ou une rvalue (éventuellement constante) pour l'opérande donné, à moins qu'une telle variante ne soit explicitement exigée avec une sémantique différente. Ces variations implicites d'expressions doivent respecter les mêmes exigences sémantiques que l'expression déclarée. La mesure dans laquelle une implémentation valide la syntaxe de ces variantes n'est pas spécifiée.

Notes

Des exemples de types Boolean incluent bool, std::true_type et std::bitset<N>::reference. Les pointeurs ne sont pas des types Boolean.

Une contrainte de déduction de la forme { expression } -> Same<T>&& impose que decltype((expression))&& soit exactement le même type que T&&. Elle contraint à la fois le type de l'expression et sa catégorie de valeur.
