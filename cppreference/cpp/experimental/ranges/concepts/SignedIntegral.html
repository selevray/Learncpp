std::experimental::ranges::SignedIntegral

Défini dans l'en-tête <experimental/ranges/concepts>

template< class T >
concept bool SignedIntegral = Integral<T> && std::is_signed<T>::value;  // (ranges TS)

Le concept SignedIntegral<T> est satisfait si et seulement si T est un type entier et std::is_signed<T>::value est true.

Il n'est pas nécessaire qu'il existe une relation de subsomption entre SignedIntegral<T> et std::is_signed<T>::value.

Notes

SignedIntegral<T> peut être satisfait par un type qui n'est pas un type entier signé, par exemple char (sur un système où char est signé).
