std::experimental::ranges::Movable

Défini dans l'en-tête <experimental/ranges/concepts>

template< class T >
concept bool Movable =
    std::is_object<T>::value &&
    MoveConstructible<T> &&
    Assignable<T&, T> &&
    Swappable<T>;  // (ranges TS)

Le concept Movable<T> spécifie que T est un type objet qui peut être déplacé (c'est-à-dire qu'il peut être construit par déplacement, affecté par déplacement, et que les lvalues de type T peuvent être échangées).

Il n'est pas nécessaire qu'il existe une relation de subsomption entre Movable<T> et std::is_object<T>::value.
