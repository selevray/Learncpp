std::experimental::ranges::UnsignedIntegral

Défini dans l'en-tête <experimental/ranges/concepts>

template< class T >
concept bool UnsignedIntegral = Integral<T> && !SignedIntegral<T>;  // (ranges TS)

Le concept UnsignedIntegral<T> est satisfait si et seulement si T est un type entier et std::is_signed<T>::value est false.

Notes

UnsignedIntegral<T> peut être satisfait par un type qui n'est pas un type entier non signé, par exemple bool.
