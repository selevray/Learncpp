std::experimental::ranges::Copyable

Défini dans l'en-tête <experimental/ranges/concepts>

template< class T >
concept bool Copyable =
    CopyConstructible<T> &&
    Movable<T> &&
    Assignable<T&, const T&>;  // (ranges TS)

Le concept Copyable<T> spécifie que T est un type objet Movable qui peut aussi être copié (c'est-à-dire qu'il supporte la construction par copie et l'affectation par copie).

Notes

Il est prévu que Copyable<T> exige aussi que Assignable<T&, const T> (affectation depuis une rvalue constante) et Assignable<T&, T&> (affectation depuis une lvalue non constante) soient satisfaits.
