template< class T = void >
    requires StrictTotallyOrdered<T> ||
             Same<T, void> ||

struct less;  // (ranges TS)

template<>

Objet fonction permettant d'effectuer des comparaisons. Le modèle primaire invoque operator< sur des lvalues const de type T. La spécialisation less<void> déduit les types des paramètres de l'opérateur d'appel de fonction à partir des arguments (mais pas le type de retour).

Toutes les spécialisations de less sont Semiregular.

std::experimental::ranges::less::operator()

constexpr bool operator()(const T& x, const T& y) const;  // (1) (membre uniquement du modèle primaire less<T> )

template< class T, class U >
    requires StrictTotallyOrderedWith<T, U> ||
             /* std::declval<T>() < std::declval<U>() resolves to
                a built-in operator comparing pointers */
constexpr bool operator()(T&& t, U&& u) const;  // (2) (membre uniquement de la spécialisation less<void> )

  1. Compare x et y. Équivalent à return ranges::less<>{}(x, y);.

  2. Compare t et u. Équivalent à return std::forward<T>(t) < std::forward<U>(u);, sauf lorsque cette expression se résout en un appel à un operator< intégré comparant des pointeurs.

Lorsqu'un appel à (1) ou (2) invoquerait un opérateur intégré comparant des pointeurs de type P, le résultat est à la place déterminé comme suit :

  • Renvoie true si la valeur (éventuellement convertie) du premier argument précède la valeur (éventuellement convertie) du second argument dans l'ordre total strict défini par l'implémentation sur toutes les valeurs de pointeurs de type P. Cet ordre total strict est cohérent avec l'ordre partiel imposé par les opérateurs intégrés <, >, <= et >=.
  • Sinon, renvoie false.

Le comportement est indéfini sauf si les séquences de conversion de T et de U vers P préservent l'égalité (voir ci-dessous).

Préservation de l'égalité

Une expression est préservant l'égalité si elle produit des sorties égales pour des entrées égales.

  • Les entrées d'une expression sont constituées de ses opérandes.
  • Les sorties d'une expression sont constituées de son résultat et de tous les opérandes modifiés par l'expression (le cas échéant).

Toute expression devant préserver l'égalité doit en outre être stable : deux évaluations d'une telle expression avec les mêmes objets d'entrée doivent produire des sorties égales, en l'absence de toute modification explicite intermédiaire de ces objets d'entrée.

Notes

Contrairement à std::less, ranges::less exige que les six opérateurs de comparaison <, <=, >, >=, == et != soient valides (via les contraintes StrictTotallyOrdered et StrictTotallyOrderedWith).
