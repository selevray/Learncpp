std::experimental::ranges::Range

Défini dans l'en-tête <experimental/ranges/range>

template< class T >
concept bool Range =
    requires(T&& t) {
        ranges::begin(t); /* pas nécessairement préservant l'égalité (voir ci-dessous) */
        ranges::end(t);
    };  // (ranges TS)

Étant donnée une lvalue t de type std::remove_reference_t<T>, Range<T> n'est satisfait que si

  • [ranges::begin(t),ranges::end(t)) désigne une plage ; et
  • ranges::begin(t) et ranges::end(t) sont tous deux à temps constant amorti et sans modification.
  • Si ranges::iterator_t<T> satisfait ForwardIterator, ranges::begin(t) préserve l'égalité.
