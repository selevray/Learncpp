Renvoie le premier élément de l'intervalle [first,last) qui satisfait des critères spécifiques :

  1. find recherche un élément dont la valeur projetée est égale à value (c'est-à-dire value == ranges::invoke(proj, *i)).

  2. find_if recherche un élément pour lequel le prédicat p renvoie true pour sa valeur projetée (c'est-à-dire ranges::invoke(pred, ranges::invoke(proj, *i))) est true).

  3. find_if_not recherche un élément pour lequel le prédicat q renvoie false pour sa valeur projetée (c'est-à-dire ranges::invoke(pred, ranges::invoke(proj, *i))) est false).

2,4,6) Identique à (1,3,5), mais utilise r comme intervalle source, comme si l'on utilisait ranges::begin(r) comme first et ranges::end(r) comme last.

Indépendamment des déclarations présentées ci-dessus, le nombre réel et l'ordre des paramètres de modèle des déclarations d'algorithmes sont non spécifiés. Ainsi, si des arguments de modèle explicites sont utilisés lors de l'appel d'un algorithme, le programme n'est probablement pas portable.

Paramètres

  • first, last — l'intervalle des éléments à examiner
  • r — l'intervalle des éléments à examiner
  • value — valeur à comparer aux éléments projetés
  • pred — prédicat à appliquer aux éléments projetés
  • proj — projection à appliquer aux éléments

Valeur de retour

Itérateur vers le premier élément satisfaisant la condition. Si aucun élément de ce type n'est trouvé, renvoie un itérateur qui compare égal à last.

Complexité

Au plus last - first applications du prédicat et de la projection.

Implémentation possible

Première version

template<InputIterator I, Sentinel<I> S, class T, class Proj = ranges::identity>
    requires IndirectRelation<ranges::equal_to<>, projected<I, Proj>, const T*>
I find(I first, S last, const T& value, Proj proj = Proj{})
{
    for (; first != last; ++first)
        if (ranges::invoke(proj, *first) == value)
            break;
    return first;
}

Deuxième version

template<InputIterator I, Sentinel<I> S, class Proj = ranges::identity,
         IndirectUnaryPredicate<projected<I, Proj>> Pred>
I find_if(I first, S last, Pred pred, Proj proj = Proj{})
{
    for (; first != last; ++first)
        if (ranges::invoke(pred, ranges::invoke(proj, *first)))
            break;
    return first;
}

Troisième version

template<InputIterator I, Sentinel<I> S, class Proj = ranges::identity,
         IndirectUnaryPredicate<projected<I, Proj>> Pred>
I find_if_not(I first, S last, Pred pred, Proj proj = Proj{})
{
    for (; first != last; ++first)
        if (!ranges::invoke(pred, ranges::invoke(proj, *first)))
            break;
    return first;
}
