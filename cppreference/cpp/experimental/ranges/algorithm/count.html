Renvoie le nombre d'éléments de la plage [first,last) satisfaisant des critères spécifiques.

  1. Compte les éléments dont les valeurs projetées sont égales à value (c'est-à-dire ranges::invoke(proj, *i) == value).

  2. Compte les éléments dont les valeurs projetées satisfont le prédicat pred (c'est-à-dire ranges::invoke(pred, ranges::invoke(proj, *i)) != false).

2,4) Identique à (1,3), mais utilise r comme intervalle source, comme si l'on utilisait ranges::begin(r) comme first et ranges::end(r) comme last.

Indépendamment des déclarations présentées ci-dessus, le nombre réel et l'ordre des paramètres de modèle des déclarations d'algorithmes sont non spécifiés. Ainsi, si des arguments de modèle explicites sont utilisés lors de l'appel d'un algorithme, le programme n'est probablement pas portable.

Paramètres

  • first, last — l'intervalle des éléments à examiner
  • r — l'intervalle des éléments à examiner
  • value — la valeur à rechercher
  • pred — prédicat à appliquer aux éléments projetés
  • proj — projection à appliquer aux éléments

Valeur de retour

Nombre d'éléments satisfaisant la condition.

Complexité

Exactement last - first comparaisons / applications du prédicat, et le même nombre d'applications de la projection.

Notes

Pour le nombre d'éléments de la plage [first,last) sans critère supplémentaire, voir ranges::distance.

Implémentation possible

Première version

template<InputIterator I, Sentinel<I> S, class T, class Proj = ranges::identity>
    requires IndirectRelation<ranges::equal_to<>, projected<I, Proj>, const T*>
ranges::difference_type_t<I> count(I first, S last, const T& value, Proj proj = Proj{})
{
    ranges::difference_type_t<I> ret = 0;
    for (; first != last; ++first)
        if (ranges::invoke(proj, *first) == value)
            ++ret;
    return ret;
}

Deuxième version

template<InputIterator I, Sentinel<I> S, class Proj = ranges::identity,
         IndirectUnaryPredicate<projected<I, Proj>> Pred>
ranges::difference_type_t<I> count_if(I first, S last, Pred pred, Proj proj = Proj{})
{
    ranges::difference_type_t<I> ret = 0;
    for (; first != last; ++first)
        if (ranges::invoke(pred, ranges::invoke(proj, *i)))
            ++ret;
    return ret;
}
