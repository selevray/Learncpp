std::experimental::ranges::copy, std::experimental::ranges::copy_if

Copie les éléments de l'intervalle source ([first,last) ou r) dans l'intervalle de destination commençant à result, en partant du premier élément de l'intervalle source jusqu'au dernier.

  1. Copie tous les éléments de l'intervalle [first,last). Pour chaque entier positif ou nul n < (last - first), effectue *(result + n) = *(first + n). Le comportement est indéfini si result se trouve dans l'intervalle [first,last). Dans ce cas, ranges::copy_backward peut être utilisé à la place.

  2. Identique à (1), mais utilise r comme intervalle source, comme si par ranges::copy(ranges::begin(r), ranges::end(r), result); sauf que result ne peut pas être copié.

  3. Copie uniquement les éléments pour lesquels le prédicat pred renvoie true lorsqu'il est appliqué à la valeur de l'élément telle que projetée par la projection proj. L'ordre des éléments copiés est conservé. Le comportement est indéfini si les intervalles source et de destination se chevauchent.

  4. Identique à (3), mais utilise r comme intervalle source, comme si par ranges::copy_if(ranges::begin(r), ranges::end(r), result, pred, proj); sauf que result, pred et proj ne peuvent pas être copiés.

Indépendamment des déclarations présentées ci-dessus, le nombre réel et l'ordre des paramètres de modèle des déclarations d'algorithmes sont non spécifiés. Ainsi, si des arguments de modèle explicites sont utilisés lors de l'appel d'un algorithme, le programme n'est probablement pas portable.

Paramètres

  • first, last — la plage des éléments à copier
  • r — la plage des éléments à copier
  • result — le début de l'intervalle de destination
  • pred — prédicat à appliquer aux éléments projetés
  • proj — projection à appliquer aux éléments

Valeur de retour

Un objet tagged_pair contenant les deux membres suivants :

  • Le premier membre, portant l'étiquette tag::in, est l'itérateur past-the-end de l'intervalle source (c'est-à-dire un itérateur de type I qui compare égal à la sentinelle last).
  • Le second membre, portant l'étiquette tag::out, est l'itérateur past-the-end de l'intervalle de résultat.

Complexité

  1. Exactement ranges::distance(first, last) affectations.

  2. Exactement ranges::distance(r) affectations.

  3. Exactement ranges::distance(first, last) applications de la projection et du prédicat correspondants.

  4. Exactement ranges::distance(r) applications de la projection et du prédicat correspondants.

Implémentations possibles

Première version

template<InputIterator I, Sentinel<I> S, WeaklyIncrementable O>
    requires IndirectlyCopyable<I, O>()
ranges::tagged_pair<tag::in(I), tag::out(O)>
    copy(I first, S last, O result)
{
    for (; first != last; ++first, (void)++result)
        *result = *first;
    return {first, result};
}

Deuxième version

template<InputRange R, WeaklyIncrementable O>
    requires IndirectlyCopyable<ranges::iterator_t<R>, O>()
ranges::tagged_pair<tag::in(ranges::safe_iterator_t<R>), tag::out(O)>
    copy(R&& r, O result)
{
   return ranges::copy(ranges::begin(r), ranges::end(r), result);
}

Troisième version

template<InputIterator I, Sentinel<I> S, WeaklyIncrementable O,
         class Proj = ranges::identity,
         IndirectUnaryPredicate<projected<I, Proj>> Pred>
    requires IndirectlyCopyable<I, O>()
ranges::tagged_pair<tag::in(I), tag::out(O)>
    copy_if(I first, S last, O result, Pred pred, Proj proj = Proj{})
{
    for (; first != last; ++first)
        if (ranges::invoke(pred, ranges::invoke(proj, *first)))
        {
            *result = *first;
            ++result;
        }
    return {first, result};
}

Quatrième version

template<InputRange R, WeaklyIncrementable O,
         class Proj = ranges::identity,
         IndirectUnaryPredicate<projected<ranges::iterator_t<R>, Proj>> Pred>
    requires IndirectlyCopyable<ranges::iterator_t<R>, O>()
ranges::tagged_pair<tag::in(ranges::safe_iterator_t<R>), tag::out(O)>
    copy_if(R&& r, O result, Pred pred, Proj proj = Proj{})
{
    return ranges::copy_if(ranges::begin(r), ranges::end(r), result, pred, proj);
}

Exemple

Le code suivant utilise copy pour copier le contenu d'un vector vers un autre et pour afficher le vector résultant :

#include <experimental/ranges/algorithm>
#include <experimental/ranges/iterator>
#include <iostream>
#include <numeric>
#include <vector>

int main()
{
    // voir https://en.cppreference.com/w/cpp/language/namespace_alias
    namespace ranges = std::experimental::ranges;

    std::vector<int> from_vector(10);
    std::iota(from_vector.begin(), from_vector.end(), 0);

    std::vector<int> to_vector;
    ranges::copy_if(from_vector.begin(), from_vector.end(),
                    ranges::back_inserter(to_vector),
                    [](const auto i)
                    {
                       return i % 3;
                    });
// ou, alternativement,
//  std::vector<int> to_vector(from_vector.size());
//  std::copy(from_vector, to_vector.begin());

    std::cout << "to_vector contains: ";

    ranges::copy(to_vector, ranges::ostream_iterator<int>(std::cout, " "));
    std::cout << '\n';
}

Output:

to_vector contains: 1 2 4 5 7 8
