  1. Renvoie true si l'intervalle [first1,last1) est égal à l'intervalle [first2,last2), et false sinon.

  2. Identique à (1), mais utilise r1 comme premier intervalle source et r2 comme second intervalle source, comme si l'on utilisait ranges::begin(r1) en tant que first1, ranges::end(r1) en tant que last1, ranges::begin(r2) en tant que first2, et ranges::end(r2) en tant que last2.

  3. Identique à (1), sauf que le second intervalle est considéré comme se terminant lorsque le premier intervalle est épuisé ou lorsque la première différence est détectée. Équivalent à return last1 == ranges::mismatch(first1, last1, std::forward<I2>(first2_), comp, proj1, proj2).in1();

  4. Identique à (3), mais utilise r1 comme premier intervalle source, comme si l'on utilisait ranges::begin(r1) comme first1 et ranges::end(r1) comme last1.

Deux intervalles sont considérés comme égaux s'ils ont le même nombre d'éléments et, pour chaque itérateur i de l'intervalle [first1,last1), ranges::invoke(pred, ranges::invoke(proj1, *i), ranges::invoke(proj2, *(first2 + (i - first1)))) est true.

Indépendamment des déclarations présentées ci-dessus, le nombre réel et l'ordre des paramètres de modèle des déclarations d'algorithmes sont non spécifiés. Ainsi, si des arguments de modèle explicites sont utilisés lors de l'appel d'un algorithme, le programme n'est probablement pas portable.

Paramètres

  • first1, last1 — le premier intervalle d'éléments
  • r1 — le premier intervalle d'éléments
  • first2, last2 — le second intervalle d'éléments
  • r2 — le second intervalle d'éléments
  • first2_ — le début du second intervalle des éléments
  • pred — prédicat à appliquer aux éléments projetés
  • proj1 — projection à appliquer aux éléments de la première plage
  • proj2 — projection à appliquer aux éléments de la seconde plage

Valeur de retour

true si les deux intervalles sont égaux, renvoie false sinon.

Notes

ranges::equal ne doit pas être utilisé pour comparer les intervalles formés par les itérateurs de std::unordered_set, std::unordered_multiset, std::unordered_map ou std::unordered_multimap, car l'ordre dans lequel les éléments sont stockés dans ces conteneurs peut être différent, même si les deux conteneurs stockent les mêmes éléments.

Lors de la comparaison de conteneurs entiers pour l'égalité, operator== du conteneur correspondant sont généralement préférés.

Complexité

1,2) Si SizedSentinel<S1, I1> && SizedSentinel<S2, I2> est satisfait et last1 - first1 != last2 - first2, aucune application du prédicat et des projections. Sinon, au plus min(last1 - first1, last2 - first2) applications du prédicat et de chaque projection.

3,4) Au plus last1 - first1 applications du prédicat et de chaque projection.

template<InputIterator I1, Sentinel<I1> S1, InputIterator I2, Sentinel<I2> S2,
         class Pred = ranges::equal_to<>,
         class Proj1 = ranges::identity, class Proj2 = ranges::identity>
    requires IndirectlyComparable<I1, I2, Pred, Proj1, Proj2>
bool equal(I1 first1, S1 last1, I2 first2, S2 last2, Pred pred = Pred{},
           Proj1 proj1 = Proj1{}, Proj2 proj2 = Proj2{})
{
    if (detail::check_size(first1, last1, first2, last2))
        return false;
    for (; first1 != last1 && first2 != last2; (void) ++first1, (void)++first2)
        if (!ranges::invoke(pred, ranges::invoke(proj1, *first1),
                                  ranges::invoke(proj2, *first2)))
            return false;
    return first1 == last1 && first2 == last2;
}
