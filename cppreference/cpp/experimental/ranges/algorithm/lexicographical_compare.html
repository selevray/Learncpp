  1. Vérifie si le premier intervalle [first1,last1) est lexicographiquement inférieur au second intervalle [first2,last2). Les éléments sont comparés à l'aide de la fonction de comparaison binaire donnée comp, après projection avec proj1 et proj2 respectivement.

  2. Identique à (1), mais utilise r1 comme premier intervalle source et r2 comme second intervalle source, comme si l'on utilisait ranges::begin(r1) en tant que first1, ranges::end(r1) en tant que last1, ranges::begin(r2) en tant que first2, et ranges::end(r2) en tant que last2.

La comparaison lexicographique est une opération ayant les propriétés suivantes :

  • Deux intervalles sont comparés élément par élément.
  • Le premier élément différent détermine lequel des intervalles est lexicographiquement inférieur ou supérieur à l'autre.
  • Si un intervalle est préfixe d'un autre, l'intervalle le plus court est lexicographiquement inférieur à l'autre.
  • Si deux intervalles ont des éléments équivalents et sont de même longueur, alors les intervalles sont lexicographiquement égaux.
  • Un intervalle vide est lexicographiquement inférieur à tout intervalle non vide.
  • Deux intervalles vides sont lexicographiquement égaux.

Paramètres

  • first1, last1 — le premier intervalle d'éléments à examiner
  • r1 — le premier intervalle d'éléments à examiner
  • first2, last2 — le second intervalle d'éléments à examiner
  • r2 — le second intervalle d'éléments à examiner
  • comp — fonction de comparaison à appliquer aux éléments projetés
  • proj1 — projection à appliquer aux éléments de la première plage
  • proj2 — projection à appliquer aux éléments de la seconde plage

Valeur de retour

true si le premier intervalle est lexicographiquement inférieur au second.

Complexité

Au plus 2·min(N1, N2) applications de l'opération de comparaison, où N1 = last1 - first1 et N2 = last2 - first2.

Implémentation possible

template<InputIterator I1, Sentinel<I1> S1, InputIterator I2, Sentinel<I2> S2,
         class Proj1 = ranges::identity, class Proj2 = ranges::identity,
         class Comp = ranges::less<>>
    requires IndirectStrictWeakOrder<Comp, projected<I1, Proj1>, projected<I2, Proj2>>
bool lexicographical_compare(I1 first1, S1 last1, I2 first2, S2 last2,
                             Comp comp = Comp{},
                             Proj1 proj1 = Proj1{}, Proj2 proj2 = Proj2{})
{
    for (; (first1 != last1) && (first2 != last2); (void) ++first1, (void) ++first2)
    {
        if (ranges::invoke(comp, ranges::invoke(proj1, *first1),
                                 ranges::invoke(proj2, *first2)))
            return true;
        if (ranges::invoke(comp, ranges::invoke(proj2, *first2),
                                 ranges::invoke(proj1, *first1)))
            return false;
    }
    return (first1 == last1) && (first2 != last2);
}
