std::experimental::ranges::common_reference

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/ranges/type_traits>

template< class... T >
struct common_reference;  // (ranges TS)

Détermine le type référence commun des types T..., c'est-à-dire le type vers lequel tous les types de T... peuvent être convertis ou liés. Si un tel type existe (selon les règles ci-dessous), le membre type désigne ce type. Sinon, il n'existe aucun membre type. Le comportement est indéfini si l'un des types de T... est un type incomplet autre que void (éventuellement qualifié cv).

Pour des types référence, common_reference tente de trouver un type référence auquel tous les types référence fournis peuvent être liés, mais peut renvoyer un type non référence s'il ne trouve pas un tel type référence.

  • Si sizeof...(T) vaut zéro, il n'existe aucun membre type.
  • Si sizeof...(T) vaut un (c'est-à-dire que T... ne contient qu'un seul type T0), le membre type désigne le même type que T0.
  • Si sizeof...(T) vaut deux (c'est-à-dire que T... contient deux types T1 et T2) :
    • Si T1 et T2 sont tous deux des types référence, et que le type référence commun simple S de T1 et T2 (tel que défini ci-dessous) existe, alors le type membre type désigne S ;
    • Sinon, si basic_common_reference<T1R, T2R, T1Q, T2Q>::type existe, où TiR est std::remove_cv_t<std::remove_reference_t<Ti>> et TiQ est un modèle d'alias tel que TiQ<TiR> est Ti, alors le type membre type désigne ce type ;
    • Sinon, si decltype(false? val<T1>() : val<T2>()), où val est un modèle de fonction template<class T> T val();, désigne un type valide, alors le type membre type désigne ce type ;
    • Sinon, si ranges::common_type_t<T1, T2> est un type valide, alors le type membre type désigne ce type ;
    • Sinon, il n'existe aucun type membre.
  • Si sizeof...(T) est supérieur à deux (c'est-à-dire que T... est constitué des types T1, T2, R...), alors, si ranges::common_reference_t<T1, T2> existe, le membre type désigne ranges::common_reference_t<ranges::common_reference_t<T1, T2>, R...> si un tel type existe. Dans tous les autres cas, il n'existe aucun membre type.

Le type référence commun simple de deux types référence T1 et T2 est défini comme suit :

  • Si T1 est cv1 X & et T2 est cv2 Y & (c'est-à-dire que les deux sont des types référence lvalue) : leur type référence commun simple est decltype(false? std::declval<cv12 X &>() : std::declval<cv12 Y &>()), où cv12 est l'union de cv1 et de cv2, si ce type existe et est un type référence.
  • Si T1 et T2 sont tous deux des types référence rvalue : si le type référence commun simple de T1 & et T2 & (déterminé selon le point précédent) existe, alors soit C le type référence rvalue correspondant à ce type. Si std::is_convertible<T1, C>::value et std::is_convertible<T2, C>::value sont tous deux true, alors le type référence commun simple de T1 et T2 est C.
  • Sinon, l'un des deux types doit être un type référence lvalue A & et l'autre un type référence rvalue B && (A et B peuvent être qualifiés cv). Soit D le type référence commun simple de A & et B const &, s'il existe. Si D existe et que std::is_convertible<B &&, D>::value est true, alors le type référence commun simple est D.
  • Sinon, il n'existe aucun type référence commun simple.

Types auxiliaires

template< class... T >

template< class T, class U, template<class> class TQual, template<class> class UQual >
struct basic_common_reference {};

Le modèle de classe basic_common_reference est un point de personnalisation qui permet aux utilisateurs d'influencer le résultat de common_reference pour les types définis par l'utilisateur (typiquement des références mandataires). Le modèle primaire est vide.

Spécialisations

Un programme peut spécialiser basic_common_reference<T, U, TQual, UQual> sur les deux premiers paramètres T et U si std::is_same<T, std::decay_t<T>> et std::is_same<U, std::decay_t<U>> sont tous deux vrais et qu'au moins l'un d'eux dépend d'un type défini par le programme.

Si une telle spécialisation possède un membre nommé type, il doit s'agir d'un type membre public et non ambigu désignant un type vers lequel TQual<T> et UQual<U> sont tous deux convertibles. De plus, ranges::basic_common_reference<T, U, TQual, UQual>::type et ranges::basic_common_reference<U, T, UQual, TQual>::type doivent désigner le même type.

Un programme ne peut pas spécialiser basic_common_reference sur le troisième ou le quatrième paramètre, ni spécialiser common_reference lui-même. Un programme qui ajoute des spécialisations en violation de ces règles a un comportement indéfini.
