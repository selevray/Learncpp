Le modèle de classe std::experimental::optional gère une valeur contenue optionnelle, c'est-à-dire une valeur pouvant être présente ou absente.

Un cas d'usage courant de optional est la valeur de retour d'une fonction susceptible d'échouer. Contrairement à d'autres approches, comme std::pair<T,bool>, optional gère bien les objets coûteux à construire et est plus lisible, car l'intention est exprimée explicitement.

Toute instance de optional<T> contient à tout instant soit une valeur, soit aucune valeur.

Si un optional<T> contient une valeur, cette valeur est garantie d'être allouée dans l'emprise mémoire de l'objet optional, c'est-à-dire qu'aucune allocation dynamique n'a jamais lieu. Ainsi, un objet optional modélise un objet, et non un pointeur, bien que operator*() et operator->() soient définis.

Lorsqu'un objet de type optional<T> est converti contextuellement en bool, la conversion renvoie true si l'objet contient une valeur et false s'il ne contient pas de valeur.

L'objet optional contient une valeur dans les conditions suivantes :

  • L'objet est initialisé avec une valeur de type T.
  • L'objet reçoit l'affectation d'un autre optional qui contient une valeur.

L'objet ne contient pas de valeur dans les conditions suivantes :

  • L'objet est initialisé par défaut.
  • L'objet est initialisé avec une valeur de std::experimental::nullopt_t ou avec un objet optional qui ne contient pas de valeur.
  • L'objet reçoit l'affectation d'une valeur de std::experimental::nullopt_t ou d'un optional qui ne contient pas de valeur.
