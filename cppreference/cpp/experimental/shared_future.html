std::experimental::shared_future

template< class T > class shared_future;  // (1) (TS de concurrence)

Le modèle de classe std::experimental::shared_future étend std::shared_future avec les opérations suivantes :

  • un constructeur de déballage à partir de future<shared_future<T>> ;
  • une fonction membre is_ready pour savoir si l'état partagé associé est prêt ; et
  • une fonction membre then pour attacher une continuation au future.

Il n'y a aucune interaction entre std::experimental::shared_future et std::shared_future.
