std::experimental::lcm

Défini dans l'en-tête <experimental/numeric>

template< class M, class N >
constexpr std::common_type_t<M, N> lcm( M m, N n );  // (spécification technique library fundamentals v2)

Calcule le plus petit commun multiple des entiers m et n.

Paramètres

  • m, n — valeurs entières

Valeur de retour

Si m ou n est égal à zéro, renvoie zéro. Sinon, renvoie le plus petit commun multiple de |m| et |n|.

Remarques

Si M ou N n'est pas un type entier, ou si l'un d'eux est (éventuellement qualifié cv) bool, le programme est mal formé.

Le comportement est indéfini si |m|, |n| ou le plus petit commun multiple de |m| et |n| n'est pas représentable comme valeur de type std::common_type_t<M, N>.

Exceptions

Ne lève aucune exception.
