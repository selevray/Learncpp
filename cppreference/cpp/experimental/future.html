std::experimental::future

Défini dans l'en-tête <experimental/future>

template< class T > class future;  // (1) (TS de concurrence)

template< class T > class future<T&>;  // (2) (TS de concurrence)

template<> class future<void>;  // (3) (TS de concurrence)

Le modèle de classe std::experimental::future étend std::future avec les opérations suivantes :

  • un constructeur de déballage à partir de future<future<T>> ;
  • une fonction membre is_ready pour savoir si l'état partagé associé est prêt ; et
  • une fonction membre then pour attacher une continuation au future.

Cependant, il n'y a aucune interopération entre std::experimental::future et std::future.

Fonctions membres

  • (constructeur) — construire un objet future (fonction membre publique)
  • is_ready — vérifie si l'état partagé est prêt (fonction membre publique)
  • then — attache une continuation à un future (fonction membre publique)
  • operator= — déplace l'objet future (fonction membre publique)

Membres identiques à std::future

Fonctions membres

Notez que share() retourne un std::experimental::shared_future<T>. Le comportement est par ailleurs identique.

  • (destructeur) — détruit l'objet future (fonction membre publique de std::future<T>)
  • share — transfère l'état partagé de *this vers un shared_future et le retourne (fonction membre publique de std::future<T>)

##### Obtention du résultat {#Getting_the_result}

  • get — retourne le résultat (fonction membre publique de std::future<T>)

##### État {#State}

  • valid — vérifie si le future possède un état partagé (fonction membre publique de std::future<T>)
  • wait — attend que le résultat devienne disponible (fonction membre publique de std::future<T>)
  • wait_for — attend le résultat, retourne si celui-ci n'est pas disponible pendant la durée de délai spécifiée (fonction membre publique de std::future<T>)
  • wait_until — attend le résultat, retourne si celui-ci n'est pas disponible avant que le point temporel spécifié soit atteint (fonction membre publique de std::future<T>)
