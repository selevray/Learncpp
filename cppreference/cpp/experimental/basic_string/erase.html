std::experimental::erase (std::basic_string)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/string>

template< class CharT, class Traits, class A, class U >
void erase( std::basic_string<CharT, Traits, A>& c, const U& value );  // (spécification technique library fundamentals v2)

Supprime tous les éléments égaux à value du conteneur. Équivalent à c.erase(std::remove(c.begin(), c.end(), value), c.end());.

Paramètres

  • c — conteneur duquel supprimer
  • value — valeur à supprimer

Complexité

Linéaire.

Exemple

#include <experimental/string>
#include <iostream>

int main()
{
    std::string data{"$$P$A$S$S$$W$O$R$$D$"};
    std::cout << data << '\n';
    auto crack{'$'};
    std::experimental::erase(data, crack);
    std::cout << data << '\n';
}

Output:

$$P$A$S$S$$W$O$R$$D$
PASSWORD
