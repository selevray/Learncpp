std::experimental::erase_if (std::basic_string)

Défini dans l'en-tête <experimental/string>

template< class CharT, class Traits, class Alloc, class Pred >
void erase_if( std::basic_string<CharT, Traits, Alloc>& c, Pred pred );  // (spécification technique library fundamentals v2)

Supprime tous les éléments qui satisfont le prédicat pred du conteneur. Équivalent à c.erase(std::remove_if(c.begin(), c.end(), pred), c.end());.

Paramètres

  • c — conteneur duquel supprimer
  • pred — prédicat déterminant les éléments à supprimer

Complexité

Linéaire.

Exemple

#include <experimental/string>
#include <iomanip>
#include <iostream>

int main()
{
    std::string data{"1337!p_C00L_<a-_HACKER_!@s_(!s#@_w^o%r*d#42"};
    std::cout << "Original string: " << std::quoted(data) << '\n';
    auto crack = [](auto O) { return '`' ^ ('`' & O); };
    std::experimental::erase_if(data, crack);
    std::cout << "After erase_if:  " << std::quoted(data) << '\n';
}

Output:

Original string: "1337!p_C00L_<a-_HACKER_!@s_{!s#@_w^o%r*d#42"
After erase_if:  "password"
