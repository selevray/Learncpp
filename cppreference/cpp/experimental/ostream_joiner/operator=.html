std::experimental::ostream_joiner<DelimT,CharT,Traits>::operator=

template< class T >
ostream_joiner& operator=( const T& value );  // (1) (spécification technique library fundamentals v2)

ostream_joiner& operator=( const ostream_joiner& other ) = default;  // (2) (library fundamentals TS v2) (déclaré implicitement)

ostream_joiner& operator=( ostream_joiner&& other ) = default;  // (3) (library fundamentals TS v2) (déclaré implicitement)
  1. Tout d'abord, si le drapeau privé « premier élément » vaut false, insère le délimiteur delim dans le flux de sortie os associé à cet itérateur, comme par os << delim;.

Puis, définit sans condition le drapeau « premier élément » à false, et insère value dans le flux de sortie comme par os << value;.

Soient out_stream, delim et first_element désignant respectivement les membres privés pointeur de flux, délimiteur et drapeau « premier élément ». Alors cette fonction est équivalente à

if (!first_element)
    *out_stream << delim;
first_element = false;
*out_stream << value;
return *this;

2,3) Opérateur d'affectation par copie/déplacement déclaré implicitement, qui effectue l'affectation par copie/déplacement des membres privés pointeur de flux, délimiteur et drapeau « premier élément ».

Paramètres

  • value — l'objet à écrire dans le flux
  • other — l'objet ostream_joiner à affecter à cet objet

Valeur de retour

*this.

Exemple

#include <experimental/iterator>
#include <iostream>

int main()
{
    auto joiner = std::experimental::make_ostream_joiner(std::cout, ", ");
    joiner = "First";
    joiner = "do no harm.";  // précède avec le délimiteur
}

Output:

First, do no harm.
