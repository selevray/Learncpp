std::experimental::make_ostream_joiner

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/iterator>

template< class CharT, class Traits, class DelimT >
std::experimental::ostream_joiner<std::decay_t<DelimT>, CharT, Traits>
    make_ostream_joiner( std::basic_ostream<CharT, Traits>& os,
                         DelimT&& delimiter );  // (spécification technique library fundamentals v2)

Crée un objet ostream_joiner, en déduisant les arguments de modèle à partir des types des arguments de la fonction.

Paramètres

  • os — l'objet basic_ostream auquel l'itérateur doit être associé
  • delimiter — le délimiteur

Valeur de retour

Un objet ostream_joiner, créé comme par std::experimental::ostream_joiner<std::decay_t<DelimT>, CharT, Traits>(os, std::forward<DelimT>(delimiter))

Exemple

#include <experimental/iterator>
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> x{1, 2, 3, 4};
    std::copy(x.begin(), x.end(),
              std::experimental::make_ostream_joiner(std::cout, ", "));
}

Output:

1, 2, 3, 4
