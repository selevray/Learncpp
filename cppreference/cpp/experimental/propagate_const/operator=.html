std::experimental::propagate_const<T>::operator=

constexpr propagate_const& operator=( propagate_const&& p ) = default;  // (1) (spécification technique library fundamentals v2)

template< class U >
constexpr propagate_const& operator=( propagate_const<U>&& pu );  // (2) (spécification technique library fundamentals v2)

template< class U >
constexpr propagate_const& operator=( U&& u );  // (3) (spécification technique library fundamentals v2)

propagate_const& operator=( const propagate_const& ) = delete;  // (4) (spécification technique library fundamentals v2)

Soit t_ désignant le membre de données privé qui est l'objet de type pointeur encapsulé.

  1. Opérateur d'affectation par déplacement explicitement défaut qui affecte par déplacement this->t_ depuis p.t_.

  2. Affecte std::move(pu.t_) à this->t_.
    Cette surcharge participe à la résolution de surcharge uniquement si U est implicitement convertible en T.

  3. Affecte std::forward<U>(u) à this->t_.
    Cette surcharge participe à la résolution de surcharge uniquement si U est implicitement convertible en T et si std::decay_t<U> n'est pas une spécialisation de propagate_const.

  4. L'opérateur d'affectation par copie est explicitement supprimé. propagate_const n'est pas copiable.

Paramètres

  • p — un autre objet propagate_const à partir duquel déplacer
  • pu — un autre objet propagate_const d'une spécialisation différente à partir duquel déplacer
  • u — un autre objet à affecter au pointeur contenu

Valeur de retour

*this.
