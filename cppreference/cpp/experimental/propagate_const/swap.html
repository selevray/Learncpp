std::experimental::propagate_const<T>::swap

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr void swap( propagate_const & pt ) noexcept(/* voir ci-dessous */);  // (spécification technique library fundamentals v2)

Échange le pointeur encapsulé avec celui de pt. Soit t_ désignant le membre de données privé qui est l'objet de type pointeur encapsulé, alors cette fonction est équivalente à swap(t_, pt.t_), où la résolution de surcharge pour swap est effectuée parmi std::swap et toute déclaration trouvée par les règles de recherche habituelles, comme décrit dans Swappable.

Le comportement est indéfini si les lvalues de T ne satisfont pas Swappable.

Paramètres

  • pt — un autre objet propagate_const avec lequel échanger

Exceptions

noexcept specification:noexcept(noexcept(swap(t_, pt.t_)))La recherche de l'identificateur swap dans la spécification d'exception trouve les surcharges décrites ci-dessus, et ne trouve pas la fonction membre elle-même, ce qui rend la spécification d'exception équivalente à celle de C++17 std::is_nothrow_swappable.
