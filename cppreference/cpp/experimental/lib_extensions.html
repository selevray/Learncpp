Extensions des bibliothèques standard C++

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

La version 1 des extensions C++ pour les fondamentaux de la bibliothèque, ISO/IEC TS 19568:2015, définit les nouveaux composants suivants pour la bibliothèque standard C++ :

Non retenus pour inclusion dans C++17

Les composants suivants de ISO/IEC TS 19568:2015 n'ont pas été retenus pour inclusion dans C++17.

Versions modifiées de classes existantes pour prendre en charge les allocateurs à effacement de type

Défini dans l'en-tête <experimental/functional>

  • function — une version modifiée de std::function prenant en charge les allocateurs à effacement de type (modèle de classe)

Défini dans l'en-tête <experimental/future>

  • promise — une version modifiée de std::promise prenant en charge les allocateurs à effacement de type (modèle de classe)
  • packaged_task — une version modifiée de std::packaged_task prenant en charge les allocateurs à effacement de type (modèle de classe)

Adaptateurs de ressources mémoire

  • resource_adaptor — adapte un allocateur en memory_resource (modèle d'alias)

Utilitaires généraux

Défini dans l'en-tête <experimental/utility>

  • erased_type — type substitut pour l'effacement de type, par exemple dans les allocateurs (classe)

Défini dans l'en-tête <experimental/type_traits>

  • invocation_typeraw_invocation_type — déduit le type de fonction implicite de l'objet appelable lorsqu'il est appelé avec les types d'arguments donnés (modèle de classe)

Intégrés dans C++17

Les composants suivants de ISO/IEC TS 19568:2015 ont été intégrés dans C++17.

objets optional

Défini dans l'en-tête <experimental/optional>

  • optional — un modèle de classe représentant des objets optional (modèle de classe)

classe any

Défini dans l'en-tête <experimental/any>

  • any — un conteneur sûr en types pour des valeurs uniques de tout type (classe)

string_view

Défini dans l'en-tête <experimental/string_view>

  • basic_string_view — une référence non propriétaire à une chaîne (modèle de classe)

Allocateurs à effacement de type et polymorphes

Allocateurs polymorphes et ressources mémoire

Les entités de cette section sont déclarées dans l'espace de noms std::experimental::pmr.

Défini dans l'en-tête <experimental/memory_resource>

  • memory_resource — une interface abstraite pour les classes encapsulant des ressources mémoire (classe)
  • synchronized_pool_resource — un memory_resource thread-safe pour gérer les allocations dans des pools de tailles de blocs différentes (classe)
  • unsynchronized_pool_resource — un memory_resource non thread-safe pour gérer les allocations dans des pools de tailles de blocs différentes (classe)
  • monotonic_buffer_resource — un memory_resource à usage spécifique qui ne libère la mémoire allouée qu'à la destruction de la ressource (classe)
  • polymorphic_allocator — un allocateur prenant en charge le polymorphisme à l'exécution basé sur la memory_resource avec laquelle il est construit (modèle de classe)
  • new_delete_resource — retourne une memory_resource statique à l'échelle du programme qui utilise les operator new et operator delete globaux pour allouer et désallouer la mémoire (fonction)
  • null_memory_resource — renvoie une memory_resource statique qui n'effectue aucune allocation (fonction)
  • get_default_resource — obtient la memory_resource par défaut (fonction)
  • set_default_resource — définit le memory_resource par défaut (fonction)
