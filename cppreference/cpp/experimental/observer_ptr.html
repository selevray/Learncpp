std::experimental::observer_ptr

template< class W >
class observer_ptr;  // (spécification technique library fundamentals v2)

std::experimental::observer_ptr est un pointeur non propriétaire, ou observateur. L'observateur stocke un pointeur vers un second objet, appelé objet observé. Un observer_ptr peut également ne pas avoir d'objet observé.

Un observateur n'est responsable en aucune façon de l'objet observé ; il n'existe aucune relation intrinsèque entre un observateur et l'objet qu'il observe.

Il est destiné à remplacer presque directement les types de pointeurs bruts, avec l'avantage que, en tant que type de vocabulaire, il indique son usage prévu sans nécessiter d'analyse détaillée de la part des lecteurs du code.

Les spécialisations de observer_ptr satisfont aux exigences de CopyConstructible et de CopyAssignable.

Exigences sur les types

  • W ne doit pas être un type référence, mais peut être un type incomplet.

##### Modificateurs {#Modifiers}

  • release — renvoie un pointeur vers l'objet observé et cesse d'observer l'objet (fonction membre publique)
  • reset — remplace l'objet observé (fonction membre publique)
  • swap — échange les objets observés (fonction membre publique)

##### Observateurs {#Observers}

  • get — renvoie un pointeur vers l'objet observé (fonction membre publique)
  • operator bool — vérifie s'il existe un objet observé associé (fonction membre publique)
  • operator*operator-> — déréférence le pointeur vers l'objet observé (fonction membre publique)
