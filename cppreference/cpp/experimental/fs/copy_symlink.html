void copy_symlink( const path& from, const path& to );  // (1) (TS sur le système de fichiers)

void copy_symlink( const path& from, const path& to,
                   error_code& ec );  // (2) (TS sur le système de fichiers)

Copie un lien symbolique vers un autre emplacement.

  1. Appelle effectivement f(read_symlink(from), to) où f vaut create_symlink() ou create_directory_symlink selon que from désigne un fichier ou un répertoire.

  2. Appelle effectivement f(read_symlink(from, ec), to, ec) où f vaut create_symlink() ou create_directory_symlink selon que from désigne un fichier ou un répertoire.

Paramètres

  • from — chemin vers le lien symbolique à copier
  • to — chemin de destination du nouveau lien symbolique
  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

Valeur de retour

(aucune)

Exceptions

La surcharge qui ne prend pas de paramètre error_code& lève filesystem_error en cas d'erreurs de l'API du système d'exploitation sous-jacente, construite avec from comme premier argument, to comme second argument, et le code d'erreur du système d'exploitation comme argument de code d'erreur. std::bad_alloc peut être levée si l'allocation mémoire échoue. La surcharge prenant un paramètre error_code& le fixe au code d'erreur de l'API du système d'exploitation si un appel à cette API échoue, et exécute ec.clear() si aucune erreur ne survient.
