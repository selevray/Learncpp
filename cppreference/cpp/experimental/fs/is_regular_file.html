Vérifie si le statut de fichier ou le chemin donné correspond à un fichier régulier.

  1. Équivalent à s.type() == file_type::regular.

  2. Équivalent à is_regular_file(status(p)).

  3. Équivalent à is_regular_file(status(p, ec)). Renvoie false et affecte à ec un code d'erreur approprié si une erreur survient. Sinon, ec est remis à zéro par un appel à ec.clear().

Paramètres

  • s — statut de fichier à vérifier
  • p — chemin à examiner
  • ec — code d'erreur dans lequel stocker l'état de l'erreur

Valeur de retour

true si le chemin ou le statut de fichier donné correspond à un lien régulier, false sinon.
