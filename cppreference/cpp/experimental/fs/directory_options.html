std::experimental::filesystem::directory_options

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/filesystem>

enum class directory_options {
    none,
    follow_directory_symlink,
    skip_permission_denied
};  // (TS sur le système de fichiers)

Ce type représente les options disponibles qui contrôlent le comportement de directory_iterator et recursive_directory_iterator.

directory_options satisfait les exigences de BitmaskType (ce qui signifie que les opérateurs bit à bit operator&, operator|, operator^, operator~, operator&=, operator|= et operator^= sont définis pour ce type).

Constantes membres

Constante membre Valeur Signification
none 0 (Par défaut) Ignorer les liens symboliques vers des répertoires ; un refus de permission est une erreur.
follow_directory_symlink 1 Suivre les liens symboliques vers des répertoires au lieu de les ignorer.
skip_permission_denied 2 Ignorer les répertoires qui entraîneraient autrement des erreurs de refus de permission.
