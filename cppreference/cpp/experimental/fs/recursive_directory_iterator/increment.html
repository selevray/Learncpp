Fait avancer l'itérateur vers l'entrée suivante.

S'il ne reste plus d'entrées dans le répertoire actuellement parcouru, le parcours reprend dans le répertoire parent. Le processus est répété si le répertoire parent n'a pas d'entrées sœurs pouvant être parcourues. Si le parent de la hiérarchie de répertoires parcourue récursivement est atteint (il n'existe aucune entrée candidate à depth() == 0)), *this est défini comme itérateur de fin.

Sinon, si *this désigne un répertoire, on le parcourt si les conditions suivantes sont remplies :

  • disable_recursion_pending() n'a pas été appelé avant cet incrément, c'est-à-dire recursion_pending() == true.
  • Le répertoire n'est pas un lien symbolique ou le suivi des liens symboliques est activé, c'est-à-dire !is_symlink(this->symlink_status()) || (options() & directory_options::follow_directory_symlink) != 0).
