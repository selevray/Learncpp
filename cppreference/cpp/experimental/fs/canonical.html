std::experimental::filesystem::canonical

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/filesystem>

path canonical( const path& p, const path& base = current_path() );  // (1) (TS sur le système de fichiers)

path canonical( const path& p, error_code& ec );  // (2) (TS sur le système de fichiers)

path canonical( const path& p, const path& base, error_code& ec );  // (3) (TS sur le système de fichiers)

Convertit le chemin p en chemin absolu canonique, c'est-à-dire un chemin absolu ne contenant ni élément point, ni élément point-point, ni lien symbolique.

Si p n'est pas un chemin absolu, la fonction se comporte comme si elle le rendait d'abord absolu par absolute(p, base) ou absolute(p) pour (2).

Le chemin p doit exister.

Paramètres

  • p — un chemin pouvant être absolu ou relatif à base, et qui doit être un chemin existant
  • base — chemin de base à utiliser si p est relatif
  • ec — code d'erreur dans lequel stocker l'état d'erreur

Valeur de retour

Un chemin absolu qui résout vers le même fichier que absolute(p, base) (ou absolute(p) pour (2)).

Exceptions

La surcharge qui ne prend pas de paramètre error_code& lève filesystem_error en cas d'erreurs de l'API du système d'exploitation sous-jacente, construite avec p comme premier argument, base comme second argument, et le code d'erreur du système d'exploitation comme argument de code d'erreur. std::bad_alloc peut être levée si l'allocation mémoire échoue. La surcharge prenant un paramètre error_code& le fixe au code d'erreur de l'API du système d'exploitation si un appel à cette API échoue, et exécute ec.clear() si aucune erreur ne survient. Cette surcharge anoexcept specification:noexcept

Cette fonction est modélisée d'après le realpath POSIX.

Exemple

#include <experimental/filesystem>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    fs::path p = fs::path("..") / ".." / "AppData";
    std::cout << "Current path is " << fs::current_path() << '\n'
              << "Canonical path for " << p << " is " << fs::canonical(p) << '\n';
}

Sortie possible :

Current path is "C:\Users\abcdef\AppData\Local\Temp"
Canonical path for "..\..\AppData" is "C:\Users\abcdef\AppData"
