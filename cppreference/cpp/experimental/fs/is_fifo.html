std::experimental::filesystem::is_fifo

bool is_fifo( file_status s );  // (1) (TS sur le système de fichiers)

bool is_fifo( const path& p );  // (2) (TS sur le système de fichiers)

bool is_fifo( const path& p, error_code& ec );  // (3) (TS sur le système de fichiers)

Vérifie si le statut de fichier ou le chemin donné correspond à un fichier FIFO ou à un tube (pipe).

  1. Équivalent à s.type() == file_type::fifo.

  2. Équivalent à is_fifo(status(p)).

  3. Équivalent à is_fifo(status(p, ec)). Renvoie false et affecte à ec un code d'erreur approprié si une erreur survient. Sinon, ec est remis à zéro par un appel à ec.clear().

Paramètres

  • s — statut de fichier à vérifier
  • p — chemin à interroger
  • ec — code d'erreur à modifier en cas d'erreur

Valeur de retour

true si le chemin ou le statut de fichier donné correspond à un fichier FIFO.

Exceptions

1,3)noexcept specification:noexcept

  1. Lève filesystem_error si une erreur survient. L'objet d'exception est construit avec p comme argument.
