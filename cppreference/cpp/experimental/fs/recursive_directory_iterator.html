std::experimental::filesystem::recursive_directory_iterator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/filesystem>

class recursive_directory_iterator;  // (TS sur le système de fichiers)

recursive_directory_iterator est un LegacyInputIterator qui parcourt les éléments directory_entry d'un répertoire, et, récursivement, les entrées de tous les sous-répertoires. L'ordre de parcours n'est pas spécifié, sauf que chaque entrée de répertoire n'est visitée qu'une seule fois.

Par défaut, les liens symboliques ne sont pas suivis, mais cela peut être activé en spécifiant l'option de répertoire follow_directory_symlink à la construction.

Les chemins spéciaux dot et dot-dot sont ignorés.

Si recursive_directory_iterator est avancé au-delà de la dernière entrée du répertoire de premier niveau, il devient égal à l'itérateur construit par défaut, aussi appelé itérateur de fin. Deux itérateurs de fin sont toujours égaux ; déréférencer ou incrémenter l'itérateur de fin est un comportement indéfini.

Si un fichier ou un répertoire est supprimé ou ajouté à l'arborescence après la création de l'itérateur de répertoire récursif, il n'est pas spécifié si ce changement sera observé par l'itérateur.

Si la structure des répertoires contient des cycles, l'itérateur de fin peut être inaccessible.

Notes

Un recursive_directory_iterator détient typiquement un pointeur à comptage de références (pour satisfaire la sémantique de copie superficielle de LegacyInputIterator) vers un objet d'implémentation, qui contient :

  • un conteneur (tel que std::vector) de directory_iterators non récursifs qui forme la pile de récursion.
  • le compteur de profondeur de récursion (accessible avec depth()).
  • les options de répertoire utilisées à la construction (accessibles avec options()).
  • l'indicateur de récursion en attente (accessible avec recursion_pending(), peut être combiné avec les options de répertoire pour économiser de l'espace).

Exemple

#include <experimental/filesystem>
#include <fstream>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    fs::create_directories("sandbox/a/b");
    std::ofstream("sandbox/file1.txt");
    fs::create_symlink("a", "sandbox/syma");
    for (const fs::directory_entry& entry : fs::recursive_directory_iterator("sandbox"))
        std::cout << entry << '\n';
    fs::remove_all("sandbox");
}

Sortie possible :

"sandbox/a"
"sandbox/a/b"
"sandbox/file1.txt"
"sandbox/syma"
