std::experimental::filesystem::path::is_absolute,is_relative

bool is_absolute() const;  // (1) (TS sur le système de fichiers)

bool is_relative() const;  // (2) (TS sur le système de fichiers)

Vérifie si le chemin est absolu ou relatif. Un chemin absolu est tel que les éléments de root_path() identifient de manière unique un emplacement du système de fichiers. La première version renvoie true si le chemin est absolu, false sinon ; la seconde version fait l'inverse.

Paramètres

(aucune)

Valeur de retour

  1. true si le chemin est absolu, false sinon.

  2. false si le chemin est absolu, true sinon.

Exceptions

Peut lever des exceptions définies par l'implémentation.
