std::experimental::filesystem::path::operator=

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

path& operator=( const path& p );  // (1) (TS sur le système de fichiers)

path& operator=( path&& p );  // (2) (TS sur le système de fichiers)

template< class Source >
path& operator=( const Source& source );  // (3) (TS sur le système de fichiers)

  1. Remplace le contenu de *this par une copie du contenu de p.

  2. Remplace le contenu de *this par p, en utilisant éventuellement la sémantique de déplacement : p est laissé dans un état valide mais non spécifié.

  3. Remplace le contenu de *this par une nouvelle valeur de chemin construite à partir de source comme si par la surcharge (4) du constructeur de path. Équivalent à assign(source).

Paramètres

  • p — un chemin à affecter
  • source — un std::basic_string, un pointeur vers une chaîne de caractères/caractères larges terminée par un caractère nul, ou un itérateur d'entrée pointant vers une séquence de caractères/caractères larges terminée par un caractère nul. Le type de caractère doit être l'un de char, char16_t, char32_t, wchar_t

Valeur de retour

*this

Exceptions

  1. (aucun)

2)noexcept specification:noexcept

  1. (aucun)

Exemple

#include <experimental/filesystem>
namespace fs = std::experimental::filesystem;

int main()
{
    fs::path p = "C:/users/abcdef/AppData/Local";
    p = p / "Temp"; // affectation par déplacement
    const wchar_t* wstr = L"D:/猫.txt";
    p = wstr; // affectation depuis une source
}
