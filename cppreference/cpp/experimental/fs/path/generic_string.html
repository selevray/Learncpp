Renvoie le nom de chemin interne au format générique, converti en type de chaîne spécifique. La conversion, le cas échéant, est spécifiée dans todo. Le caractère / est utilisé comme séparateur de répertoires.

  1. Toutes les allocations mémoire sont effectuées par a.

  2. L'encodage dans le cas de u8string() est toujours UTF-8.

Paramètres

  • a — allocateur avec lequel construire la chaîne
  • CharT doit être l'un des types de caractères encodés (char, wchar_t, char16_t et char32_t)

Valeur de retour

Le nom de chemin interne au format générique, converti dans le type de chaîne spécifié.

Exceptions

Peut lever des exceptions définies par l'implémentation.
