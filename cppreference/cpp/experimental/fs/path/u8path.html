std::experimental::filesystem::u8path

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/filesystem>

template< class Source >
path u8path( const Source& source );  // (1) (TS sur le système de fichiers)

template< class InputIt >
path u8path( InputIt first, InputIt last );  // (2) (TS sur le système de fichiers)

Construit un chemin p à partir d'une séquence de char encodée en UTF-8, fournie soit sous forme de std::string, soit sous forme de chaîne multioctet terminée par un caractère nul, soit sous forme de paire d'itérateurs [first, last).

  • Si path::value_type est char et que l'encodage natif est UTF-8, construit directement un chemin comme par path(source) ou path(first, last). Remarque : c'est la situation typique d'un système POSIX utilisant Unicode, tel que Linux.
  • Sinon, si path::value_type est wchar_t et que l'encodage natif est UTF-16 (c'est la situation sous Windows), ou si path::value_type est char16_t (encodage natif garanti UTF-16) ou char32_t (encodage natif garanti UTF-32), convertit d'abord la séquence de caractères UTF-8 en une chaîne temporaire tmp de type path::string_type, puis le nouveau chemin est construit comme par path(tmp).
  • Sinon (pour les encodages de caractères étroits non UTF-8 et pour wchar_t non UTF-16), convertit d'abord la séquence de caractères UTF-8 en une chaîne temporaire encodée en UTF-32 tmp de type std::u32string, puis le nouveau chemin est construit comme par path(tmp) (ce cas se produit sur un système POSIX avec un système de fichiers à encodage multioctet ou monooctet non Unicode).

Paramètres

  • source — une std::string encodée en UTF-8, un pointeur vers une chaîne multioctet terminée par un caractère nul, ou un itérateur d'entrée dont le type de valeur char pointe vers une chaîne multioctet terminée par un caractère nul
  • first, last — paire de LegacyInputIterators qui spécifient une séquence de caractères encodée en UTF-8

Exigences sur les types

  • InputIt doit satisfaire aux exigences de LegacyInputIterator.
  • Le type de valeur de InputIt doit être char.

Valeur de retour

Le chemin construit à partir de la chaîne d'entrée après conversion de UTF-8 vers l'encodage natif de caractères du système de fichiers.

Exceptions

Peut lever filesystem_error en cas d'erreurs de l'API du système d'exploitation sous-jacent, ou std::bad_alloc si l'allocation mémoire échoue.

Notes

Sur les systèmes dont le format de chemin natif diffère du format de chemin générique (ni Windows ni les systèmes POSIX ne sont des exemples de tels systèmes d'exploitation), si l'argument de cette fonction utilise le format générique, il sera converti en format natif.

Exemple

#include <clocale>
#include <cstdio>
#include <experimental/filesystem>
#include <fstream>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    std::setlocale(LC_ALL, "en_US.utf8");
    std::locale::global(std::locale("en_US.utf8"));

    fs::path p = fs::u8path(u8"要らない.txt");

    // la représentation de chaîne native peut être utilisée avec les API du système d'exploitation
    std::ofstream(p) << "File contents"; // ceci utilise operator string()
    if (std::FILE* f = std::fopen(p.c_str(), "r"))
    {
        int ch;
        while ((ch=fgetc(f))!= EOF) putchar(ch);
        std::fclose(f);
    }

    // les représentations multioctets et larges peuvent être utilisées pour la sortie
    std::cout.imbue(std::locale());
    std::cout << "\nFile name in narrow multibyte encoding: "
              << p.string() << '\n';

    std::wcerr.imbue(std::locale());
    std::wcerr << "File name in wide encoding: "
               << p.wstring() << '\n';

    fs::remove(p);
}
