  1. Ajoute d'abord le séparateur de répertoire préféré à this, sauf si l'une des conditions suivantes est vraie :

  • le séparateur serait redondant (*this se termine déjà par un séparateur).

  • *this est vide, ou l'ajout le transformerait en chemin absolu d'une autre manière.

  • p est un chemin vide.

  • p.native() commence par un séparateur de répertoire.

Ajoute ensuite p.native() au nom de chemin maintenu par *this.

2,3) Identique à (1), mais accepte n'importe quel std::basic_string, chaîne multicaractère terminée par un caractère nul, ou un itérateur d'entrée pointant vers une séquence multicaractère terminée par un caractère nul.

  1. Identique à (1), mais accepte toute paire d'itérateurs désignant une chaîne multicaractère.

Paramètres

  • p — nom de chemin à ajouter
  • source — std::basic_string, chaîne multicaractère terminée par un caractère nul, ou itérateur d'entrée pointant vers une séquence multicaractère terminée par un caractère nul, représentant un nom de chemin (au format portable ou natif)
  • first, last — paire de LegacyInputIterators spécifiant une séquence multicaractère représentant un nom de chemin

Exigences sur les types

  • InputIt doit satisfaire aux exigences de LegacyInputIterator.
  • Le type de valeur de InputIt doit être l'un des types de caractères encodés (char, wchar_t, char16_t et char32_t).

Valeur de retour

*this

Exceptions

Peut lever filesystem_error en cas d'erreurs de l'API du système d'exploitation sous-jacent, ou std::bad_alloc si l'allocation mémoire échoue.

Exemple

#include <experimental/filesystem>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    fs::path p1 = "C:";
    p1 /= "Users"; // n'insère pas de séparateur
                   // "C:Users" est un chemin relatif sous Windows
                   // l'ajout d'un séparateur de répertoire le transformerait en chemin absolu
    std::cout << "\"C:\" / \"Users\" == " << p1 << '\n';
    p1 /= "batman"; // insère fs::path::preferred_separator, '\' sous Windows
    std::cout << "\"C:\" / \"Users\" / \"batman\" == " << p1 << '\n';
}

Sortie possible :

"C:" / "Users" == "C:Users"
"C:" / "Users" / "batman" == "C:Users\batman"
