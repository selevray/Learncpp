std::experimental::filesystem::path::replace_extension

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

path& replace_extension( const path& replacement = path() );  // (1) (TS sur le système de fichiers)

Remplace l'extension par replacement ou la supprime lorsque la valeur par défaut de replacement est utilisée.

Premièrement, si ce chemin possède une extension(), elle est supprimée.

Ensuite, un point est ajouté si replacement n'est pas vide ou ne commence pas par un point.

Puis replacement est ajouté au chemin.

Paramètres

  • replacement — l'extension par laquelle remplacer

Valeur de retour

*this

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <experimental/filesystem>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    fs::path p = "/foo/bar.jpeg";
    std::cout << "Was: " << p << '\n';
    p.replace_extension(".jpg");
    std::cout << "Now: " << p << '\n';
}

Output:

Was: "/foo/bar.jpeg"
Now: "/foo/bar.jpg"
