std::experimental::filesystem::path::stem

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

path stem() const;  // (TS sur le système de fichiers)

Renvoie le nom de fichier identifié par le chemin, privé de son extension.

Renvoie la sous-chaîne allant du début de filename() jusqu'au dernier point (.), non inclus.

Si le nom de fichier est l'un des composants spéciaux du système de fichiers dot ou dot-dot, ou s'il ne contient aucun point, la fonction renvoie la totalité de filename().

Paramètres

(aucune)

Valeur de retour

Le radical du nom de fichier identifié par le chemin.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <experimental/filesystem>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    std::cout << fs::path("/foo/bar.txt").stem() << '\n'
              << fs::path("/foo/.bar").stem() << '\n';

    for (fs::path p = "foo.bar.baz.tar"; !p.extension().empty(); p = p.stem())
        std::cout << p.extension() << '\n';
}

Output:

"bar"
""
".tar"
".baz"
".bar"
