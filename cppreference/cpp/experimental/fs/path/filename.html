std::experimental::filesystem::path::filename

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

path filename() const;  // (TS sur le système de fichiers)

Renvoie le composant nom de fichier du chemin.

Équivalent à empty() ? path() : *--end().

Paramètres

(aucune)

Valeur de retour

Le nom de fichier identifié par le chemin.

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <experimental/filesystem>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    std::cout << fs::path("/foo/bar.txt").filename() << '\n'
              << fs::path("/foo/.bar").filename() << '\n'
              << fs::path("/foo/bar/").filename() << '\n'
              << fs::path("/foo/.").filename() << '\n'
              << fs::path("/foo/..").filename() << '\n'
              << fs::path(".").filename() << '\n'
              << fs::path("..").filename() << '\n'
              << fs::path("/").filename() << '\n';
}

Output:

"bar.txt"
".bar"
"."
"."
".."
"."
".."
"/"
