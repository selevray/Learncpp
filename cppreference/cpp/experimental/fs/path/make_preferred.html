std::experimental::filesystem::path::make_preferred

path& make_preferred()  // (1) (TS sur le système de fichiers)

Convertit tous les séparateurs de répertoires du chemin en le séparateur de répertoires préféré.

Par exemple, sur les systèmes où \ est le séparateur préféré, le chemin foo/bar sera converti en foo\bar.
