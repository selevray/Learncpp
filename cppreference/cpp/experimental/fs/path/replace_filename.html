std::experimental::filesystem::path::replace_filename

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

path& replace_filename( const path& replacement );  // (TS sur le système de fichiers)

Remplace un composant de nom de fichier par replacement.

Équivalent à ce qui suit :

remove_filename();
operator/=(replacement);

Le comportement est indéfini si le chemin n'a pas de composant de nom de fichier (has_filename renvoie false).

Paramètres

(aucune)

Valeur de retour

*this

Exceptions

Peut lever des exceptions définies par l'implémentation.

Exemple

#include <experimental/filesystem>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    std::cout << fs::path("/foo").replace_filename("bar") << '\n'
              << fs::path("/").replace_filename("bar") << '\n';
}

Output:

"/bar"
"bar"
