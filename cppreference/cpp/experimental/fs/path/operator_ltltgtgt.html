Effectue une entrée ou sortie de flux sur le chemin p. std::quoted est utilisé afin que les espaces ne provoquent pas de troncature lors d'une lecture ultérieure par l'opérateur d'entrée de flux.

Paramètres

  • os — flux sur lequel effectuer la sortie
  • is — flux sur lequel effectuer une entrée
  • p — chemin à insérer ou extraire

Valeur de retour

  1. os

  2. is

Exceptions

Peut lever des exceptions définies par l'implémentation.

Implémentation possible

Première version

template<class CharT, class Traits>
std::basic_ostream<CharT,Traits>&
    operator<<(std::basic_ostream<CharT,Traits>& os, const path& p)
{
    os << std::quoted(p.string<CharT,Traits>());
    return os;
}

Deuxième version

template<class CharT, class Traits>
std::basic_istream<CharT,Traits>&
    operator>>(std::basic_istream<CharT,Traits>& is, path& p)
{
    std::basic_string<CharT, Traits> t;
    is >> std::quoted(t);
    p = t;
    return is;
}
