Renvoie ou modifie le chemin courant.

1,2) Renvoie le chemin absolu du répertoire de travail courant, obtenu comme avec POSIX getcwd. (2) renvoie path() si une erreur survient.

3,4) Modifie le répertoire de travail courant pour p, comme avec POSIX chdir.

Paramètres

  • p — chemin vers lequel modifier le répertoire de travail courant
  • ec — paramètre de sortie pour le rapport des erreurs dans les surcharges sans exception

Valeur de retour

1,2) Renvoie le répertoire de travail courant.

3,4) (aucun)

Exceptions

1,2) La surcharge sans paramètre error_code& lève filesystem_error en cas d'erreur de l'API du système sous-jacent, construite avec le code d'erreur du système comme argument de code d'erreur. std::bad_alloc peut être levée si l'allocation mémoire échoue. La surcharge prenant un paramètre error_code& le définit au code d'erreur de l'API du système si un appel à l'API échoue, et exécute ec.clear() si aucune erreur ne survient. Cette surcharge anoexcept specification:noexcept

3,4) La surcharge sans paramètre error_code& lève filesystem_error en cas d'erreur de l'API du système sous-jacent, construite avec p comme premier argument et le code d'erreur du système comme argument de code d'erreur. std::bad_alloc peut être levée si l'allocation mémoire échoue. La surcharge prenant un paramètre error_code& le définit au code d'erreur de l'API du système si un appel à l'API échoue, et exécute ec.clear() si aucune erreur ne survient. Cette surcharge anoexcept specification:noexcept

Notes

Le répertoire de travail courant est le répertoire utilisé comme point de départ lors de la résolution des chemins relatifs. Un seul répertoire de travail courant est associé à l'ensemble du processus.

Le répertoire de travail courant est un état global dangereux du programme. Le comportement de diverses fonctions d'entrée/sortie liées aux fichiers dépend de la valeur du chemin courant. Le chemin courant peut être modifié de façon inattendue par n'importe quel composant du programme, y compris diverses bibliothèques externes ou d'autres threads.
