std::experimental::filesystem::resize_file

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/filesystem>

void resize_file( const path& p, std::uintmax_t new_size );
void resize_file( const path& p, std::uintmax_t new_size, error_code& ec );  // (TS sur le système de fichiers)

Modifie la taille du fichier régulier nommé par p comme le fait POSIX truncate : si la taille du fichier était auparavant supérieure à new_size, le reste du fichier est supprimé. Si le fichier était auparavant plus petit que new_size, sa taille est augmentée et la nouvelle zone apparaît remplie de zéros.

Paramètres

  • p — chemin du fichier à redimensionner
  • new_size — taille que le fichier aura désormais
  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

Valeur de retour

(aucune)

Exceptions

La surcharge qui ne prend pas de paramètre error_code& lève filesystem_error en cas d'erreur de l'API du système d'exploitation sous-jacente, construite avec p comme premier argument et le code d'erreur du système d'exploitation comme argument de code d'erreur. std::bad_alloc peut être levée si l'allocation mémoire échoue. La surcharge prenant un paramètre error_code& le positionne au code d'erreur de l'API du système d'exploitation si un appel échoue, et exécute ec.clear() si aucune erreur ne survient. Cette surcharge anoexcept specification:noexcept

Notes

Sur les systèmes qui prennent en charge les fichiers creux, l'augmentation de la taille du fichier n'augmente pas l'espace qu'il occupe sur le système de fichiers : l'allocation d'espace n'a lieu que lorsque des octets non nuls sont écrits dans le fichier.

Exemple

Démontre l'effet de la création d'un fichier creux sur l'espace libre.

#include <experimental/filesystem>
#include <fstream>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    fs::path p = fs::temp_directory_path() / "example.bin";
    std::ofstream(p).put('a');
    std::cout << "File size:  " << fs::file_size(p) << '\n'
              << "Free space: " << fs::space(p).free << '\n';
    fs::resize_file(p, 64*1024); // redimensionne à 64 Ko
    std::cout << "File size:  " << fs::file_size(p) << '\n'
              << "Free space: " << fs::space(p).free << '\n';
    fs::remove(p);
}
