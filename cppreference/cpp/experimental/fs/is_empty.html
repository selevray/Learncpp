std::experimental::filesystem::is_empty

bool is_empty( const path& p );  // (1) (TS sur le système de fichiers)

bool is_empty( const path& p, error_code& ec );  // (2) (TS sur le système de fichiers)

Vérifie si le chemin donné désigne un fichier ou un répertoire vide.

La seconde version renvoie false et définit ec à un code d'erreur approprié si une erreur survient. Sinon, ec est remis à zéro par un appel à ec.clear().

Paramètres

  • p — chemin à examiner
  • ec — code d'erreur à modifier en cas d'erreur

Valeur de retour

true si p désigne un fichier ou un répertoire vide, false sinon.

Exceptions

  1. filesystem_error si une erreur survient. L'objet d'exception est construit avec p comme argument. Le code d'erreur est défini au code d'erreur approprié à l'erreur ayant causé l'échec.
