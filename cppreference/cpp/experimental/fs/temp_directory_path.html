std::experimental::filesystem::temp_directory_path

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/filesystem>

path temp_directory_path();
path temp_directory_path( error_code& ec );  // (1) (TS sur le système de fichiers)

Renvoie l'emplacement du répertoire adapté aux fichiers temporaires.

Paramètres

(aucune)

Valeur de retour

Un répertoire adapté aux fichiers temporaires. Le chemin est garanti d'exister et d'être un répertoire. La surcharge qui prend error_code& en argument renvoie un chemin vide en cas d'erreur.

Exceptions

La surcharge qui ne prend pas de paramètre error_code& lève filesystem_error en cas d'erreur de l'API du système d'exploitation sous-jacente, construite avec path to be returned comme premier argument et le code d'erreur du système d'exploitation comme argument de code d'erreur. std::bad_alloc peut être levée si l'allocation mémoire échoue. La surcharge prenant un paramètre error_code& le positionne au code d'erreur de l'API du système d'exploitation si un appel échoue, et exécute ec.clear() si aucune erreur ne survient. Cette surcharge anoexcept specification:noexcept

Notes

Sur les systèmes POSIX, le chemin peut être celui spécifié dans les variables d'environnement TMPDIR, TMP, TEMP, TEMPDIR et, si aucune d'elles n'est spécifiée, le chemin "/tmp" est renvoyé.

Sur les systèmes Windows, le chemin est généralement celui renvoyé par GetTempPath.

Exemple

#include <experimental/filesystem>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    std::cout << "Temp directory is " << fs::temp_directory_path() << '\n';
}

Sortie possible :

Temp directory is "C:\Windows\TEMP\"
