Constantes

Constante Signification

  • none — indique que l'état du fichier n'a pas encore été évalué, ou qu'une erreur s'est produite lors de son évaluation
  • not_found — indique que le fichier n'a pas été trouvé (ce n'est pas considéré comme une erreur)
  • regular — un fichier ordinaire
  • directory — un répertoire
  • symlink — un lien symbolique
  • block — un fichier spécial de bloc
  • character — un fichier spécial de caractères
  • fifo — un fichier FIFO (aussi appelé tube)
  • socket — un fichier socket
  • unknown — un fichier inconnu
