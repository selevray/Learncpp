std::experimental::filesystem::space

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/filesystem>

space_info space( const path& p );
space_info space( const path& p, error_code& ec ) noexcept;  // (TS sur le système de fichiers)

Détermine les informations sur le système de fichiers sur lequel se trouve le chemin p, comme le fait POSIX statvfs.

Remplit et renvoie un objet de type space_info, dont les membres sont définis à partir de la structure POSIX struct statvfs comme suit :

  • space_info.capacity est défini comme le fait f_blocks * f_frsize.
  • space_info.free est défini à f_bfree * f_frsize.
  • space_info.available est défini à f_bavail * f_frsize.
  • Tout membre qui n'a pas pu être déterminé est défini à static_cast<std::uintmax_t>(-1).

La surcharge non lançante définit tous les membres à static_cast<std::uintmax_t>(-1) en cas d'erreur.

Paramètres

  • p — chemin à examiner
  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

Valeur de retour

Les informations sur le système de fichiers (un objet space_info).

Exceptions

La surcharge qui ne prend pas de paramètre error_code& lève filesystem_error en cas d'erreur de l'API du système d'exploitation sous-jacente, construite avec p comme premier argument et le code d'erreur du système d'exploitation comme argument de code d'erreur. std::bad_alloc peut être levée si l'allocation mémoire échoue. La surcharge prenant un paramètre error_code& le positionne au code d'erreur de l'API du système d'exploitation si un appel échoue, et exécute ec.clear() si aucune erreur ne survient. Cette surcharge anoexcept specification:noexcept

Notes

space_info.available peut être inférieur à space_info.free.

Exemple

#include <experimental/filesystem>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    fs::space_info devi = fs::space("/dev/null");
    fs::space_info tmpi = fs::space("/tmp");

    std::cout << "         Capacity         Free    Available\n"
              << "/dev:   " << devi.capacity << "   "
              << devi.free << "   " << devi.available << '\n'
              << "/tmp: " << tmpi.capacity << ' '
              << tmpi.free << ' ' << tmpi.available << '\n';
}
