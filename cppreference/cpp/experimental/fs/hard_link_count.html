std::experimental::filesystem::hard_link_count

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/filesystem>

std::uintmax_t hard_link_count( const path& p );
std::uintmax_t hard_link_count( const path& p, error_code& ec );  // (1) (TS sur le système de fichiers)

Renvoie le nombre de liens physiques pour l'objet du système de fichiers identifié par le chemin p.

La surcharge sans exception renvoie static_cast<uintmax_t>(-1) en cas d'erreur.

Paramètres

  • p — chemin à examiner
  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

Valeur de retour

Le nombre de liens physiques pour p.

Exceptions

La surcharge qui ne prend pas de paramètre error_code& lève filesystem_error en cas d'erreur de l'API du système d'exploitation sous-jacente, construite avec p comme premier argument et le code d'erreur du système d'exploitation comme argument de code d'erreur. std::bad_alloc peut être levée si l'allocation mémoire échoue. La surcharge prenant un paramètre error_code& le positionne au code d'erreur de l'API du système d'exploitation si un appel échoue, et exécute ec.clear() si aucune erreur ne survient. Cette surcharge anoexcept specification:noexcept

Exemple

#include <experimental/filesystem>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    // Sur un système de fichiers de type POSIX, chaque répertoire possède au moins 2 liens physiques :
    // lui-même et le membre spécial de chemin "."
    fs::path p = fs::current_path();
    std::cout << "Number of hard links for current path is "
              << fs::hard_link_count(p) << '\n';

    // chaque ".." est un lien physique vers le répertoire parent, donc le nombre total
    // de liens physiques pour tout répertoire vaut 2 plus le nombre de sous-répertoires directs
    p = fs::current_path() / ".."; // chaque double point est un lien physique vers le parent
    std::cout << "Number of hard links for .. is "
              << fs::hard_link_count(p) << '\n';
}

Output:

Number of hard links for current path is 2
Number of hard links for .. is 3
