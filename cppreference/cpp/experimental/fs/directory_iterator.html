std::experimental::filesystem::directory_iterator

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/filesystem>

class directory_iterator;  // (TS sur le système de fichiers)

directory_iterator est un LegacyInputIterator qui itère sur les éléments directory_entry d'un répertoire (sans visiter les sous-répertoires). L'ordre d'itération est non spécifié, sauf que chaque entrée de répertoire n'est visitée qu'une seule fois. Les chemins spéciaux dot et dot-dot sont ignorés.

Si le directory_iterator est avancé au-delà de la dernière entrée de répertoire, il devient égal à l'itérateur construit par défaut, aussi appelé itérateur de fin. Deux itérateurs de fin sont toujours égaux ; déréférencer ou incrémenter l'itérateur de fin est un comportement indéfini.

Si un fichier ou un répertoire est supprimé ou ajouté à l'arborescence de répertoires après la création de l'itérateur de répertoire, il n'est pas spécifié si ce changement sera observé à travers l'itérateur.

Exemple

#include <experimental/filesystem>
#include <fstream>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    fs::create_directories("sandbox/a/b");
    std::ofstream{"sandbox/file1.txt"};
    std::ofstream{"sandbox/file2.txt"};
    for (const fs::directory_entry& entry : fs::directory_iterator{"sandbox"})
        std::cout << entry << '\n';
    fs::remove_all("sandbox");
}
