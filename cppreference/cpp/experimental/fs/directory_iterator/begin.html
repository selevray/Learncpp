std::experimental::filesystem::begin(directory_iterator), std::experimental::filesystem::end(directory_iterator)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

directory_iterator begin( directory_iterator iter );  // (1) (TS sur le système de fichiers)

directory_iterator end( const directory_iterator& );  // (2) (TS sur le système de fichiers)

  1. Renvoie iter sans modification.

  2. Renvoie un directory_iterator construit par défaut, qui sert d'itérateur de fin. L'argument est ignoré.

Ces fonctions non membres permettent d'utiliser des directory_iterator avec les boucles for basées sur un intervalle.

Paramètres

  • iter — a directory_iterator

Valeur de retour

  1. iter restent inchangés.

  2. Itérateur de fin (directory_iterator construit par défaut).

Exceptions

noexcept specification:noexcept

Exemple

#include <experimental/filesystem>
#include <fstream>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    fs::create_directories("sandbox/a/b");
    std::ofstream("sandbox/file1.txt");
    std::ofstream("sandbox/file2.txt");
    for (auto& p : fs::directory_iterator("sandbox"))
        std::cout << p << '\n';
    fs::remove_all("sandbox");
}

Sortie possible :

"sandbox/a"
"sandbox/file1.txt"
"sandbox/file2.txt"
