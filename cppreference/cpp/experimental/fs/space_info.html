std::experimental::filesystem::space_info

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/filesystem>

struct space_info {
    uintmax_t capacity;
    uintmax_t free;
    uintmax_t available;
};  // (TS sur le système de fichiers)

Représente les informations du système de fichiers telles que déterminées par space.

Les membres ont la signification suivante :

  • capacity -- taille totale du système de fichiers, en octets
  • free -- espace libre du système de fichiers, en octets
  • available -- espace libre disponible pour un processus non privilégié (peut être égal ou inférieur à free)

Exemple

#include <experimental/filesystem>
#include <iostream>
namespace fs = std::experimental::filesystem;

int main()
{
    fs::space_info devi = fs::space("/dev/null");
    fs::space_info tmpi = fs::space("/tmp");

    std::cout << "         Capacity         Free    Available\n"
              << "/dev:   " << devi.capacity << "   "
              << devi.free << "   " << devi.available << '\n'
              << "/tmp: " << tmpi.capacity << ' '
              << tmpi.free << ' ' << tmpi.available << '\n';
}
