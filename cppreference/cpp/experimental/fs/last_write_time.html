std::experimental::filesystem::last_write_time

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/filesystem>

file_time_type last_write_time( const path& p );
file_time_type last_write_time( const path& p, error_code& ec )  // (1) (TS sur le système de fichiers)

void last_write_time( const path& p, file_time_type new_time );
void last_write_time( const path& p, file_time_type new_time, error_code& ec );  // (2) (TS sur le système de fichiers)

  1. Renvoie l'heure de la dernière modification de p, déterminée comme en accédant au membre st_mtime de la structure POSIX stat (les liens symboliques sont suivis). La surcharge sans exception renvoie file_time_type::min() en cas d'erreur.

  2. Modifie l'heure de la dernière modification de p, comme par la fonction POSIX futimens (les liens symboliques sont suivis).

Paramètres

  • p — chemin à examiner ou à modifier
  • new_time — nouvelle heure de modification
  • ec — paramètre de sortie pour le signalement d'erreurs dans la surcharge ne levant pas d'exception

Valeur de retour

  1. L'heure de la dernière modification de p.

  2. (aucun)

Exceptions

La surcharge qui ne prend pas de paramètre error_code& lève filesystem_error en cas d'erreur de l'API du système d'exploitation sous-jacente, construite avec p comme premier argument et le code d'erreur du système d'exploitation comme argument de code d'erreur. std::bad_alloc peut être levée si l'allocation mémoire échoue. La surcharge prenant un paramètre error_code& le positionne au code d'erreur de l'API du système d'exploitation si un appel échoue, et exécute ec.clear() si aucune erreur ne survient. Cette surcharge anoexcept specification:noexcept

Notes

Il n'est pas garanti que, immédiatement après la définition de l'heure d'écriture, la valeur renvoyée par (1) soit identique à l'argument passé à (2), car la granularité du système de fichiers peut être plus fine que file_time_type.

Exemple

#include <chrono>
#include <experimental/filesystem>
#include <fstream>
#include <iomanip>
#include <iostream>
namespace fs = std::experimental::filesystem;
using namespace std::chrono_literals;

int main()
{
    fs::path p = fs::current_path() / "example.bin";
    std::ofstream(p.c_str()).put('a'); // créer un fichier
    auto ftime = fs::last_write_time(p);

    std::time_t cftime = decltype(ftime)::clock::to_time_t(ftime); // en supposant system_clock
    std::cout << "File write time is " << std::asctime(std::localtime(&cftime)) << '\n';

    fs::last_write_time(p, ftime + 1h); // déplacer l'heure d'écriture du fichier d'une heure dans le futur
    ftime = fs::last_write_time(p); // relire depuis le système de fichiers

    cftime = decltype(ftime)::clock::to_time_t(ftime);
    std::cout << "File write time is " << std::asctime(std::localtime(&cftime)) << '\n';
    fs::remove(p);
}
