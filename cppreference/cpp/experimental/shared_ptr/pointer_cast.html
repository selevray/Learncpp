Crée une nouvelle instance de std::experimental::shared_ptr dont le pointeur stocké est obtenu à partir du pointeur stocké de r à l'aide d'une expression de conversion. Si r est vide, le nouveau shared_ptr l'est aussi (mais son pointeur stocké n'est pas nécessairement nul).

Sinon, le nouveau shared_ptr partagera la propriété avec r, sauf s'il est vide lorsque le dynamic_cast effectué par dynamic_pointer_cast retourne un pointeur nul.

Soit Y égal à typename std::experimental::shared_ptr<T>::element_type, alors le pointeur stocké du std::experimental::shared_ptr résultant sera obtenu en appelant (dans cet ordre) :

  1. static_cast<Y*>(r.get()).

  2. dynamic_cast<Y*>(r.get()) (si le résultat de l'dynamic_cast est une valeur de pointeur nul, le shared_ptr renvoyé sera vide).

  3. const_cast<Y*>(r.get()).

  4. reinterpret_cast<Y*>(r.get()).

Le comportement de ces fonctions est indéfini sauf si la conversion correspondante de U* vers T* est bien formée :

  1. Le comportement est indéfini sauf si static_cast<T*>((U*)nullptr) est bien formé.

  2. Le comportement est indéfini sauf si dynamic_cast<T*>((U*)nullptr) est bien formé.

  3. Le comportement est indéfini sauf si const_cast<T*>((U*)nullptr) est bien formé.

  4. Le comportement est indéfini sauf si reinterpret_cast<T*>((U*)nullptr) est bien formé.

Paramètres

  • r — le pointeur à convertir
