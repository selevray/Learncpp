std::hash(std::experimental::shared_ptr)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

template< class T > struct hash<std::experimental::shared_ptr<T>>;  // (TS des fondamentaux de la bibliothèque)

La spécialisation de modèle de std::hash pour std::experimental::shared_ptr<T> permet aux utilisateurs d'obtenir les hachages d'objets de type std::experimental::shared_ptr<T>.

Pour un std::experimental::shared_ptr<T> p donné, cette spécialisation garantit que std::hash<std::experimental::shared_ptr<T>>()(p) == std::hash<T*>()(p.get()).
