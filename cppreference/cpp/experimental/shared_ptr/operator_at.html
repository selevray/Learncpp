std::experimental::shared_ptr<T>::operator[]

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

element_type& operator[]( std::ptrdiff_t i ) const noexcept;  // (TS des fondamentaux de la bibliothèque)

Indexe le tableau pointé par le pointeur stocké.

Le comportement est indéfini si le pointeur stocké est nul ou si i est négatif.

Si T (le paramètre de modèle de shared_ptr) est un type tableau U[N], i doit être strictement inférieur à N, sinon le comportement est indéfini.

Paramètres

  • i — l'indice du tableau

Valeur de retour

Une référence vers le i-ième élément du tableau, c'est-à-dire get()[i].

Remarques

Lorsque T n'est pas un type tableau, il n'est pas spécifié si cette fonction est déclarée. Si la fonction est déclarée, son type de retour n'est pas spécifié, sauf que la déclaration (bien que pas nécessairement la définition) de la fonction est garantie légale.
