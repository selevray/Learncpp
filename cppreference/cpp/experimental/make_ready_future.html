std::experimental::make_ready_future

Défini dans l'en-tête <experimental/future>

template< class T >
future<V /* voir ci-dessous */> make_ready_future( T&& value );  // (1) (TS de concurrence)

future<void> make_ready_future();  // (2) (TS de concurrence)
  1. Si std::decay_t<T> est std::reference_wrapper<X>, alors le type V est X&, sinon, V est std::decay_t<T>.

Crée un état partagé de type V immédiatement prêt, avec le résultat construit à partir de std::forward<T>(value), puis renvoie un std::experimental::future associé à cet état partagé.

  1. Crée un état partagé de type void immédiatement prêt, puis renvoie un std::experimental::future associé à cet état partagé.

Valeur de retour

Un std::experimental::future associé à l'état partagé créé.
