Modèles de variables pour les traits de types (library fundamentals TS)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

La version 1 des extensions C++ pour Library Fundamentals fournit un certain nombre de constexpr modèles de variables pour les classes de traits de types, ainsi que d'autres modèles de classes similaires possédant des membres publics ::value.

Sauf indication contraire, les modèles de variables suivants sont définis dans l'espace de noms std::experimental.
