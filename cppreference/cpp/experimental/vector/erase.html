std::experimental::erase (std::vector)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/vector>

template< class T, class A, class U >
void erase( std::vector<T, A>& c, const U& value );  // (spécification technique library fundamentals v2)

Supprime tous les éléments égaux à value du conteneur. Équivalent à c.erase(std::remove(c.begin(), c.end(), value), c.end());.

Paramètres

  • c — conteneur duquel supprimer
  • value — valeur à supprimer

Complexité

Linéaire.

Exemple

#include <experimental/vector>
#include <iostream>

auto show = [](const auto& container)
{
    for (auto e : container)
        std::cout << e;
    std::cout << '\n';
};

int main()
{
    std::vector<int> data{1, 1, 1, 4, 1, 1, 1, 2, 1, 1, 1};
    show(data);
    std::experimental::erase(data, 1);
    show(data);
}

Output:

11141112111
42
