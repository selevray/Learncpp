std::experimental::simd_abi::fixed_size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/simd>

template< int N >
struct fixed_size {};  // (TS de parallélisme v2)

L'étiquette de type simd_abi::fixed_size<N> garantit que les types data-parallel stockent et manipulent N éléments (c.-à-d. simd<T, simd_abi::fixed_size<N>>::size() renvoie N). Une implémentation doit prendre en charge au moins tous les N ∈ [1,32]. De plus, pour chaque simd<T, Abi> pris en charge, où Abi est une étiquette ABI définie par l'implémentation, N = simd<T, Abi>::size() doit être prise en charge.

Notes

Une implémentation peut choisir de renoncer à la compatibilité ABI entre unités de traduction compilées différemment pour les instanciations de simd et simd_mask utilisant la même étiquette simd_abi::fixed_size<N>. Sinon, l'efficacité de simd<T, Abi> est susceptible d'être meilleure que celle de simd<T, fixed_size<simd_size_v<T, Abi>>> (avec Abi non instance de simd_abi::fixed_size).
