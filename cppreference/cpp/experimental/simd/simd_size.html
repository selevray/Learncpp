std::experimental::simd_size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/simd>

template< class T, class Abi = simd_abi::compatible<T> >
struct simd_size;  // (TS de parallélisme v2)

Si T est un type vectorisable et is_abi_tag_v<Abi> vaut true, fournit la constante membre value égale à la largeur (nombre d'éléments) de simd<T, Abi>, que simd<T, Abi> soit pris en charge ou non. Pour tous les autres types T et Abi, il n'existe pas de membre value.

Si le programme ajoute des spécialisations pour std::simd_sizeou std::simd_size_v (depuis C++17), le comportement est indéfini.

Modèle de variable auxiliaire

template< class T, class Abi = simd_abi::compatible<T> >
constexpr std::size_t simd_size_v = simd_size<T, Abi>::value;  // (TS de parallélisme v2)
