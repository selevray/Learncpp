template< class T >

compatible<T> est un alias défini par l'implémentation pour une étiquette ABI.

Notes

L'objectif est d'utiliser l'étiquette ABI produisant l'exécution data-parallel la plus efficace pour le type d'élément T, tout en garantissant la compatibilité ABI entre unités de traduction sur l'architecture cible.
