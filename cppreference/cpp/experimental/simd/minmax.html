template< class T, class Abi >
std::pair<simd<T, Abi>, simd<T, Abi>>
minmax( const simd<T, Abi>& a, const simd<T, Abi>& b ) noexcept;  // (TS de parallélisme v2)

Renvoie à la fois le résultat min élément par élément et le résultat max élément par élément.

Paramètres

  • a — le premier vecteur d'éléments pour minmax
  • b — le second vecteur d'éléments pour minmax

Valeur de retour

Un objet r, où le ie élément de r.first vaut std::min(a[i], b[i]), et le ie élément de r.second vaut std::max(a[i], b[i]).
