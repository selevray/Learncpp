std::experimental::simd_abi::deduce

Défini dans l'en-tête <experimental/simd>

template< class T, std::size_t N, class ...Abis >
struct deduce;  // (TS de parallélisme v2)

Le type deduce<T, N, Abis...>::type est présent si et seulement si :

  • T est un type vectorisable,
  • simd_abi::fixed_size<N> est pris en charge, et
  • chaque type de Abis... est une étiquette ABI.

Notons DA la valeur deduce<T, N, Abis...>::type lorsqu'elle est présente, alors

  • simd_size_v<T, DA> == N,
  • simd<T, DA> est constructible par défaut, c'est-à-dire qu'il est pris en charge,
  • DA vaut simd_abi::scalar si N == 1, sinon il est défini par l'implémentation.

Types membres

Nom Définition

  • type — une étiquette ABI adaptée au type d'élément spécifié T et à la taille N

Types auxiliaires

template< class T, std::size_t N, class ...Abis >
using deduce_t = typename deduce<T, N, Abis...>::type;  // (TS de parallélisme v2)

Notes

simd_abi::deduce est compatible SFINAE.

L'étiquette ABI déduite via cette fonctionnalité est une caractéristique de qualité d'implémentation. Les implémentations peuvent fonder ce choix sur Abis..., mais peuvent aussi ignorer les arguments Abis.... Une implémentation simple peut se contenter de renvoyer fixed_size<N> inconditionnellement. Une implémentation optimisée peut renvoyer une étiquette ABI étendue définie par l'implémentation pour la plupart des entrées. Par conséquent, si vous avez besoin d'une étiquette ABI pour un certain nombre d'éléments, utilisez fixed_size si la stabilité ABI est importante, et préférez deduce_t sinon.
