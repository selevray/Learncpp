std::experimental::is_abi_tag

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/simd>

template< class T >
struct is_abi_tag;  // (TS de parallélisme v2)

Si T est une étiquette ABI de l'espace de noms simd_abi, fournit la constante membre value égale à true. Pour tout autre type, value vaut false.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_abi_tag_v = is_abi_tag<T>::value;  // (TS de parallélisme v2)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est une étiquette ABI, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Exemple

#include <experimental/simd>

static_assert(std::experimental::is_abi_tag_v<stdx::simd_abi::scalar>);
static_assert(!std::experimental::is_abi_tag_v<int>);

int main() {}
