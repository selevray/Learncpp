struct vector_aligned_tag {};
inline constexpr vector_aligned_tag vector_aligned{};  // (TS de parallélisme v2)

Ce type de balise indique que le tampon de copy_from et copy_to est aligné sur memory_alignment_v<T, U>, où l'opération de copie opère sur le type T simd/simd_mask, et le tampon de type d'élément U.

Notes

Ce type de balise permet d'implémenter un chargement et un stockage alignés sur le vecteur.
