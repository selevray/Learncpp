std::experimental::simd_cast, std::experimental::static_simd_cast

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/simd>

template< class V, class T, class Abi >
/*voir ci-dessous*/ simd_cast( const simd<T, Abi>& v ) noexcept;  // (1) (TS de parallélisme v2)

template< class V, class T, class Abi >
/*voir ci-dessous*/ static_simd_cast( const simd<T, Abi>& v ) noexcept;  // (2) (TS de parallélisme v2)

Convertit un objet simd en un autre objet simd. Si V est T, renvoie simd<T, Abi> ; sinon, si V est un type scalaire, renvoie simd<V, simd_abi::fixed_size<simd<T, Abi>::size()>>. Sinon, V doit être un type simd, et la fonction renvoie V.

  1. Cette fonction ne participe pas à la résolution de surcharge à moins que
  • chaque valeur possible de l'élément d'entrée puisse être représentée par l'élément de sortie,
  • soit is_simd_v<V> vaut false, soit V::size() vaut simd<T, Abi>::size().
  1. Cette fonction ne participe pas à la résolution de surcharge à moins que soit is_simd_v<V> vaille false, soit V::size() vaille simd<T, Abi>::size().

Paramètres

  • v — l'objet simd d'entrée

Valeur de retour

Un objet simd dont le i-ème élément est initialisé à static_cast<To>(v[i]), où To est le type d'élément de sortie tel que spécifié.

Notes

La spécification TS ne fournit pas les surcharges simd_cast et static_simd_cast pour simd_mask. L'implémentation libstdc++ fournit les surcharges manquantes dans l'espace de noms std::experimental::__proposed. Si vous utilisez déjà le

namespace stdx = std::experimental;

raccourci, vous pourriez être intéressé à utiliser

namespace stdx {
  using namespace std::experimental;
  using namespace std::experimental::__proposed;
}

à la place. Alternativement, libstdc++ implémente une fonction membre __cvt() dans simd_mask, qui permet la conversion implicite du masque. Voir aussi : <https://github.com/VcDevel/std-simd/issues/41>
