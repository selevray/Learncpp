Défini dans l'en-tête <experimental/simd>

template< class T, class Abi = simd_abi::compatible<T> >
class simd;  // (TS de parallélisme v2)

Le modèle de classe simd est un type data-parallel. La largeur d'une instanciation donnée de simd est une expression constante, déterminée par les paramètres de modèle.

Une balise ABI est un type de l'espace de noms simd_abi qui indique un choix de taille et de représentation binaire pour les objets de type data-parallel.

Paramètres de modèle

  • T — type d'élément ; un type arithmétique autre que bool
  • Abi — type de balise utilisé pour déterminer le nombre d'éléments et le stockage

Alias de modèles auxiliaires

template< class T, int N >
using fixed_size_simd = std::experimental::simd<T, std::experimental::simd_abi::fixed_size<N>>;

template< class T >
using native_simd = std::experimental::simd<T, std::experimental::simd_abi::native<T>>;
