template< class T, class Abi = simd_abi::compatible<T> >
class simd_mask;  // (TS de parallélisme v2)

Le modèle de classe simd_mask est un type data-parallel dont le type d'élément est bool. La largeur d'une instanciation donnée de simd_mask est une expression constante, déterminée par les paramètres de modèle. Plus précisément, simd_mask<T, Abi>::size() vaut toujours simd<T, Abi>::size().

Paramètres de modèle

  • T — le type d'élément simd_mask s'applique à
  • Abi — le type ABI simd_mask s'applique à
