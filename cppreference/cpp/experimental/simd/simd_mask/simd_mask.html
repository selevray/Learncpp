std::experimental::simd_mask<T,Abi>::simd_mask

  1. Construit un simd_mask par initialisation par défaut (construit sans initialiseur) ou par initialisation par valeur (construit avec un initialiseur vide).

  2. Le constructeur de diffusion construit un simd_mask dont toutes les valeurs sont initialisées à value.

  3. Construit un simd_mask dont le i-ème élément est initialisé à other[i] pour tout i dans l'intervalle [0,size()). Cette surcharge ne participe à la résolution de surcharge que si Abi vaut simd_abi::fixed_size<size()>.

  4. Le constructeur de chargement construit un simd_mask dont le i-ème élément est initialisé à mem[i] pour tous les i dans l'intervalle [0,size()).

5,6) Constructeurs de copie et de déplacement déclarés implicitement. Construit un simd_mask dont chaque élément est initialisé à partir des valeurs des éléments de other.

Paramètres

  • value — la valeur utilisée pour l'initialisation de tous les éléments simd_mask
  • other — un autre simd_mask à copier
  • mem — un pointeur vers un tableau où [mem,mem + size()) est un intervalle valide
  • flags — si de type vector_aligned_tag, le constructeur de chargement peut supposer que mem pointe vers un stockage aligné sur memory_alignment_v<simd_mask>

Exigences sur les types

  • is_simd_flag_type_v<Flags> doit être true.

Exemple

#include <algorithm>
#include <cstddef>
#include <experimental/simd>
#include <iostream>
namespace stdx = std::experimental;

int main()
{
    [[maybe_unused]]
    stdx::native_simd_mask<int> a;       // uninitialized
    stdx::native_simd_mask<int> b(true); // tous les éléments initialisés à true
    stdx::native_simd_mask<int> c{};     // tous les éléments initialisés à false

    alignas(stdx::memory_alignment_v<stdx::native_simd_mask<int>>)
        std::array<bool, stdx::native_simd_mask<int>::size() * 2> mem = {};
    std::ranges::generate(mem, [i{0}] mutable -> bool { return i++ & 1; });

    stdx::native_simd_mask<int> d(&mem[0], stdx::vector_aligned);  // {0, 1, 0, 1, ...}
    stdx::native_simd_mask<int> e(&mem[1], stdx::element_aligned); // {1, 0, 1, 0, ...}

    const auto xored = b ^ c ^ d ^ e;

    for (std::size_t i{}; i != xored.size(); ++i)
        std::cout << xored[i] << ' ';
    std::cout << '\n';
}
