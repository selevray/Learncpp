std::experimental::popcount

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/simd>

template< class T, class Abi >
int popcount( const simd_mask<T, Abi>& k ) noexcept;  // (TS de parallélisme v2)

Renvoie le nombre de valeurs true dans le masque k.

Paramètres

  • k — le simd_mask auquel appliquer la réduction

Valeur de retour

Un int dans l'intervalle [0,simd_size_v<T, Abi>).

Exemple

#include <cstddef>
#include <experimental/simd>
#include <iostream>
namespace stdx = std::experimental;

template<typename Abi>
int count_zeros(stdx::simd<int, Abi> v)
{
    return stdx::popcount(v == 0); // v == 0 renvoie un simd_mask
}

void println(auto rem, auto const v)
{
    std::cout << rem << ": ";
    for (std::size_t i = 0; i != v.size(); ++i)
        std::cout << v[i] << ' ';
}

int main()
{
    stdx::simd<int> x{8};
    println("x", x);
    std::cout << "  zeros: " << count_zeros(x) << '\n';

    x[3] = x[1] = false;
    println("x", x);
    std::cout << "  zeros: " << count_zeros(x) << '\n';
}

Sortie possible :

x: 8 8 8 8   zeros: 0
x: 8 0 8 0   zeros: 2
