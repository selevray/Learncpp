std::experimental::memory_alignment

Défini dans l'en-tête <experimental/simd>

template< class T, class U = typename T::value_type >
struct memory_alignment;  // (TS de parallélisme v2)

Si is_simd_mask_v<T> est true et U est bool, ou si is_simd_v<T> est true et U est un type vectorisable, fournit la constante membre value égale à l'alignement minimal d'un pointeur passé à un constructeur de chargement, à la fonction copy_from, ou à la fonction copy_to. Pour tous les autres types T et U, il n'existe aucun membre value.

Si le programme ajoute des spécialisations pour std::memory_alignmentou std::memory_alignment_v (depuis C++17), le comportement est indéfini.
