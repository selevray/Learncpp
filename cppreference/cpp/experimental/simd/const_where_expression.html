template< class M, class V >
class const_where_expression;  // (TS de parallélisme v2)

Le modèle de classe const_where_expression représente la notion d'éléments sélectionnés d'un objet const donné de type arithmétique ou de type data-parallel. Les éléments sélectionnés désignent les éléments data[i] pour tous les i ∈ { j ∈ ℕ | j < M::size() ⋀ mask[j] }.

Paramètres de modèle

  • M — Le type de masque
  • V — La valeur de type M s'applique à

Les combinaisons valides de (M, V) sont : (simd_mask<T, Abi>, const simd<T, Abi>), (simd_mask<T, Abi>, const simd_mask<T, Abi>), (bool, const T).

Fonctions membres

  • operator-operator+operator~ — opérateurs unaires (fonction membre publique)
  • copy_to — stocke les éléments sélectionnés à l'adresse (fonction membre publique)
