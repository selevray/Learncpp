  1. Construit un simd par initialisation par défaut (construit sans initialiseur) ou par initialisation par valeur (construit avec un initialiseur vide).

  2. Le constructeur de diffusion construit un simd dont toutes les valeurs sont initialisées à value. Cette surcharge ne participe à la résolution de surcharge que si la conversion de U vers T est préservant la valeur, ou si U vaut int ou unsigned int lorsque T est un type entier non signé.

  3. Construit un simd dont le i-ème élément est initialisé à static_cast<T>(other[i]) pour tous les i dans l'intervalle [0,size()). Cette surcharge ne participe à la résolution de surcharge que si Abi est simd_abi::fixed_size<size()> et que la conversion de U vers T est préservant la valeur, et, si U et T sont tous deux entiers, le rang de conversion entier de T est supérieur à celui de U.

  4. Le constructeur générateur construit un simd dont le i-ème élément est initialisé à generator(std::integral_constant<std::size_t, i>()). Cette surcharge ne participe à la résolution de surcharge que si simd(gen(std::integral_constant<std::size_t, i>())) est bien formé pour tous les i dans l'intervalle [0,size()). Les appels à generator sont non séquencés les uns par rapport aux autres. Les fonctions de la bibliothèque standard non sûres pour la vectorisation ne peuvent pas être invoquées par generator.

  5. Le constructeur de chargement construit un simd dont le i-ème élément est initialisé à static_cast<T>(mem[i]) pour tous les i dans l'intervalle [0,size()).

6,7) Constructeurs de copie et de déplacement déclarés implicitement. Construit un simd dont chaque élément est initialisé à partir des valeurs des éléments de other.

Paramètres

  • value — la valeur utilisée pour l'initialisation de tous les éléments simd
  • other — un autre simd à copier
  • generator — un objet fonction utilisé pour l'initialisation de chaque élément simd
  • mem — un pointeur vers un tableau où [mem,mem + size()) est un intervalle valide
  • flags — si de type vector_aligned_tag, le constructeur de chargement peut supposer que mem pointe vers un stockage aligné sur memory_alignment_v<simd, U>

Exigences sur les types

  • La conversion de U vers T doit être préservant la valeur. Le constructeur de diffusion (2) autorise en outre U à être int ou à être unsigned int si T est un type entier non signé.
  • is_simd_flag_type_v<Flags> doit être true.

Exemple

#include <cstddef>
#include <experimental/simd>
#include <iostream>
namespace stdx = std::experimental;

int main()
{
    stdx::native_simd<int> a; // uninitialized
    a = 1; // tous les éléments valent 1
    stdx::native_simd<int> b([](int i) { return i; }); // {0, 1, 2, 3, ...}

    alignas(stdx::memory_alignment_v<stdx::native_simd<int>>)
        std::array<int, stdx::native_simd<int>::size() * 2> mem = {};
    for (std::size_t i = 0; i < mem.size(); ++i)
        mem[i] = i & 1;

    stdx::native_simd<int> c(&mem[0], stdx::vector_aligned); // {0, 1, 0, 1, ...}
    stdx::native_simd<int> d(&mem[1], stdx::element_aligned); // {1, 0, 1, 0, ...}

    auto sum = a + b + c + d;

    for (std::size_t i = 0; i < sum.size(); ++i)
        std::cout << sum[i] << ' ';
    std::cout << '\n';
}
