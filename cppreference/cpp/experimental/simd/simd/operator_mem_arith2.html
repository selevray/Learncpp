std::experimental::simd<T,Abi>::operator!,~,+,-

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

mask_type operator!() const noexcept;  // (1) (TS de parallélisme v2)

simd operator~() const noexcept;  // (2) (TS de parallélisme v2)

simd operator+() const noexcept;  // (3) (TS de parallélisme v2)

simd operator-() const noexcept;  // (4) (TS de parallélisme v2)

Applique l'opérateur unaire donné sur chaque élément du simd.

  1. Renvoie un simd_mask<T, Abi> où le ith élément vaut !operator[](i) pour tous les i dans l'intervalle [0,size()).

  2. Renvoie un simd dont chaque bit est l'inverse du bit correspondant de *this. Cette surcharge ne participe à la résolution de surcharge que si T est un type entier.

  3. Renvoie une copie de lui-même.

  4. Renvoie un simd où le ith élément est initialisé à -operator[](i) pour tous les i dans l'intervalle [0,size()).

Exemple

#include <cstddef>
#include <experimental/simd>
#include <iostream>
#include <string_view>
namespace stdx = std::experimental;

void println(std::string_view op, const stdx::native_simd_mask<int> x)
{
    std::cout << op << ": ";
    for (std::size_t i = 0; i < x.size(); ++i)
        std::cout << std::boolalpha << x[i] << ' ';
    std::cout << '\n';
}

void println(std::string_view op, const stdx::native_simd<int> x)
{
    std::cout << op << ": ";
    for (std::size_t i = 0; i < x.size(); ++i)
        std::cout << x[i] << ' ';
    std::cout << '\n';
}

int main()
{
    const stdx::native_simd<int> a([](int i) { return i; });

    println("  a", a);
    println(" !a", !a);
    println(" ~a", ~a);
    println("~~a", ~~a);
    println(" +a", +a);
    println(" -a", -a);
    println("+-a", +-a);
}

Sortie possible :

  a: 0 1 2 3
 !a: true false false false
 ~a: -1 -2 -3 -4
~~a: 0 1 2 3
 +a: 0 1 2 3
 -a: 0 -1 -2 -3
+-a: 0 -1 -2 -3
