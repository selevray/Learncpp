std::experimental::simd<T,Abi>::size

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

static constexpr size_t size() noexcept;  // (TS de parallélisme v2)

Renvoie la largeur (le nombre de valeurs) de simd<T, Abi>.

Exemple

La sortie réelle dépend de la cible et des options du compilateur.

#include <experimental/simd>
#include <cstdint>
#include <iostream>
namespace stdx = std::experimental;

int main()
{
    stdx::native_simd<std::int32_t> a = 1;
    std::cout << a.size() << '\n';
    std::cout << reduce(a) << '\n';
}
