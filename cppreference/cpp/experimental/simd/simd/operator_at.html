std::experimental::simd<T,Abi>::operator[]

reference operator[]( std::size_t i );  // (1) (TS de parallélisme v2)

value_type operator[]( std::size_t i ) const;  // (2) (TS de parallélisme v2)

Les opérateurs d'indexation permettent de lire et d'écrire des éléments individuels d'un simd.

  1. Renvoie un proxy de référence vers le i-ème élément. Ce type de proxy ne doit pas être capturé dans une lvalue. Les lvalues de simd::reference ne peuvent se convertir qu'en value_type. Les rvalues de simd::reference surchargent l'affectation ainsi que tous les opérateurs d'affectation composée, ainsi que swap.

  2. Renvoie une prvalue du i-ème élément. Contrairement aux conteneurs, qui contiennent des objets de type value_type, un simd n'est pas un conteneur d'objets individuels et ne peut donc pas renvoyer une référence lvalue.

Paramètres

  • i — l'indice de l'élément. Doit être strictement inférieur à size()

Exemple

#include <cstddef>
#include <cstdint>
#include <experimental/simd>
#include <iostream>
namespace stdx = std::experimental;

int main()
{
    const stdx::native_simd<std::int64_t> a = 3;
    for (std::size_t i = 0; i != a.size(); ++i)
        std::cout << a[i] << ' ';
    std::cout << '\n';
}
