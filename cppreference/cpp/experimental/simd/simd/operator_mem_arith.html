Applique l'opérateur d'incrémentation ou de décrémentation sur chaque élément de l'simd.

  1. Incrémente toutes les valeurs de simd de 1 et renvoie une référence vers lui-même.

  2. Incrémente toutes les valeurs de simd de 1 et renvoie une copie de lui-même avant l'opération.

  3. Décrémente toutes les valeurs de simd de 1 et renvoie une référence vers lui-même.

  4. Décrémente toutes les valeurs de simd de 1 et renvoie une copie de lui-même avant l'opération.

Exemple

#include <cstddef>
#include <experimental/simd>
#include <iostream>
namespace stdx = std::experimental;

void print(auto rem, auto const& a)
{
    std::cout << rem << ": ";
    for (std::size_t i{}; i != std::size(a); ++i)
        std::cout << a[i] << ' ';
    std::cout << '\n';
}

int main()
{
    stdx::native_simd<int> p = -2;
    print('p', p);

    ++p;
    print('p', p);

    auto q = p--;
    print('p', p);
    print('q', q);
}
