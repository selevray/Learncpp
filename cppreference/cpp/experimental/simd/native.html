template< class T >
using native = /*défini par l'implémentation*/;  // (TS de parallélisme v2)

native<T> est un alias défini par l'implémentation pour une étiquette ABI. C'est l'étiquette ABI principale à utiliser pour une vectorisation explicite efficace.

Notes

L'objectif est d'utiliser l'étiquette ABI produisant l'exécution data-parallel la plus efficace pour le type d'élément T pris en charge sur le système ciblé actuellement. Pour les architectures cibles sans extensions ISA, les alias native<T> et compatible<T> seront probablement identiques. Pour les architectures cibles avec extensions ISA, les options du compilateur peuvent influencer l'alias native<T>, tandis que compatible<T> restera identique quelles que soient ces options.
