std::experimental::is_simd_flag_type

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/simd>

template< class T >
struct is_simd_flag_type;  // (TS de parallélisme v2)

Si T est un type valide pour le second argument de copy_from, copy_to ou des constructeurs de chargement correspondants de simd ou simd_mask, fournit la constante membre value égale à true. Pour tout autre type, value vaut false.

Paramètres de modèle

  • T — un type à vérifier

Modèle de variable auxiliaire

template< class T >
constexpr bool is_simd_flag_type_v = is_simd_flag_type<T>::value;  // (TS de parallélisme v2)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si T est un type d'étiquette d'indicateur de chargement/stockage, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Exemple

#include <experimental/simd>
#include <iostream>

int main()
{
    namespace stdx = std::experimental;
    std::cout << std::boolalpha
              << stdx::is_simd_flag_type_v<stdx::element_aligned_tag> << '\n'
              << stdx::is_simd_flag_type_v<int> << '\n';
}

Output:

true
false
