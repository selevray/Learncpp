  1. Réduit toutes les valeurs de v sur binary_op.

  2. Réduit les valeurs de x dont l'élément de masque associé vaut true sur binary_op.

  3. Renvoie la somme de toutes les valeurs de x dont l'élément de masque associé vaut true.

  4. Renvoie le produit de toutes les valeurs de x dont l'élément de masque associé vaut true.

  5. Renvoie l'agrégation par ET bit à bit de toutes les valeurs de x dont l'élément de masque associé vaut true.

  6. Renvoie l'agrégation par OU bit à bit de toutes les valeurs de x dont l'élément de masque associé vaut true.

  7. Renvoie l'agrégation par OU exclusif bit à bit de toutes les valeurs de x dont l'élément de masque associé vaut true.

  8. Réduit toutes les valeurs de v sur std::min.

  9. Réduit toutes les valeurs de x dont l'élément de masque associé vaut true sur std::min.

  10. Réduit toutes les valeurs de v sur std::max.

  11. Réduit toutes les valeurs de x dont l'élément de masque associé vaut true sur std::max.

Le comportement est non déterministe si binary_op n'est pas associatif ou n'est pas commutatif.

Paramètres

  • v — le vecteur simd auquel appliquer la réduction
  • x — la valeur de retour d'une expression where à laquelle appliquer la réduction
  • identity_element — une valeur qui sert d'élément neutre pour binary_op ; binary_op(identity_element, a) == a doit être vrai pour toutes les valeurs finies a de type V::value_type
  • binary_op — FunctionObject binaire qui sera appliqué dans un ordre non spécifié à des arguments de type V::value_type ou simd<V::value_type, A>, avec la balise ABI non spécifiée A. binary_op(v, v) doit être convertible en V

Valeur de retour

Le résultat de l'opération de type :

1,8,10) T

2-7,9,11) V::value_type

Exemple

#include <array>
#include <cassert>
#include <cstddef>
#include <experimental/simd>
#include <functional>
#include <iostream>
#include <numeric>
namespace stdx = std::experimental;

int main()
{
    using V = stdx::native_simd<double>;

    alignas(stdx::memory_alignment_v<V>) std::array<V::value_type, 1024> data;
    std::iota(data.begin(), data.end(), 0);

    V::value_type acc{};
    for (std::size_t i = 0; i < data.size(); i += V::size())
        acc += stdx::reduce(V(&data[i], stdx::vector_aligned), std::plus{});
    std::cout << "sum of data = " << acc << '\n';

    using W = stdx::fixed_size_simd<int, 4>;
    alignas(stdx::memory_alignment_v<W>) std::array<int, 4> arr{2, 5, 4, 1};
    auto w = W(&arr[0], stdx::vector_aligned);
    assert(stdx::hmin(w) == 1 and stdx::hmax(w) == 5);
}

Output:

sum of data = 523776
