using scalar = /*unspecified*/;  // (TS de parallélisme v2)

Avec la balise ABI scalar, les types data-parallel sont équivalents à un type d'élément unique. Cependant, l'interface complète simd et simd_mask est prise en charge, ce qui facilite le développement de code générique.

Notes

scalar n'est pas un alias de fixed_size<1>.
