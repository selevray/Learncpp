std::experimental::basic_string_view<CharT,Traits>::remove_suffix

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr void remove_suffix( size_type n );  // (TS des fondamentaux de la bibliothèque)

Recule la fin de la vue de n caractères.

Le comportement est indéfini si n > size().

Paramètres

  • n — nombre de caractères à retirer de la fin de la vue

Valeur de retour

(aucune)

Complexité

Constante.

Exemple

#include <experimental/string_view>
#include <iostream>

int main()
{
    char arr[] = {'a', 'b', 'c', 'd', '\0', '\0', '\0'};
    std::experimental::string_view v(arr, sizeof arr);
    auto trim_pos = v.find('\0');
    if (trim_pos != v.npos)
        v.remove_suffix(v.size() - trim_pos);
    std::cout << "Array: '" << arr << "', size=" << sizeof arr << '\n'
              << "View : '" << v << "', size=" << v.size() << '\n';
}

Output:

Array: 'abcd', size=7
View : 'abcd', size=4
