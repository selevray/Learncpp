std::experimental::basic_string_view<CharT,Traits>::operator[]

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr const_reference operator[](size_type pos) const;  // (TS des fondamentaux de la bibliothèque)

Renvoie une référence constante vers le caractère situé à la position pos.

Aucune vérification des bornes n'est effectuée : le comportement est indéfini si pos >= size().

Paramètres

  • pos — position du caractère à renvoyer

Valeur de retour

Référence constante vers le caractère demandé

Exceptions

Ne lève aucune exception

Complexité

Constante.

Notes

Contrairement à std::basic_string::operator[], basic_string_view::operator[](size()) a un comportement indéfini au lieu de renvoyer CharT().

Exemple

#include <iostream>
#include <experimental/string_view>
int main()
{
    std::string str = "Exemplar";
    std::experimental::string_view v = str;
    std::cout << v[2] << '\n';
//  v[2] = 'y'; // Error : impossible de modifier à travers une vue de chaîne
    str[2] = 'y';
    std::cout << v[2] << '\n';
}

Output:

e
y
