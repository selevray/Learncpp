basic_string_view& operator=( const basic_string_view& view ) noexcept = default;  // (TS des fondamentaux de la bibliothèque)

Remplace la vue par celle de view.

Paramètres

  • view — vue à copier

Valeur de retour

*this

Complexité

Constante.

Exemple

#include <iostream>
#include <experimental/string_view>
int main()
{
    std::experimental::string_view v = "Hello, world";
    v = v.substr(7);
    std::cout << v << '\n';
}
