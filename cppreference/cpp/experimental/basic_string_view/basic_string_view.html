std::experimental::basic_string_view<CharT,Traits>::basic_string_view

constexpr basic_string_view() noexcept;  // (1) (TS des fondamentaux de la bibliothèque)

constexpr basic_string_view( const basic_string_view& other ) noexcept = default;  // (2) (TS des fondamentaux de la bibliothèque)

template<class Allocator>
basic_string_view( const std::basic_string<CharT, Traits, Allocator>& str ) noexcept;  // (3) (TS des fondamentaux de la bibliothèque)

constexpr basic_string_view( const CharT* s, size_type count );  // (4) (TS des fondamentaux de la bibliothèque)

constexpr basic_string_view( const CharT* s );  // (5) (TS des fondamentaux de la bibliothèque)

  1. Constructeur par défaut. Construit une basic_string_view vide.

  2. Constructeur de copie. Construit une vue du même contenu que other.

  3. Construit une vue des str.size() premiers caractères du tableau de caractères commençant à l'élément pointé par str.data().

  4. Construit une vue des count premiers caractères du tableau de caractères commençant à l'élément pointé par s. s peut contenir des caractères nuls. Le comportement est indéfini si [s,s + count) n'est pas un intervalle valide (même si le constructeur n'accède à aucun élément de cet intervalle).

  5. Construit une vue de la chaîne de caractères terminée par un caractère nul pointée par s, sans inclure ce caractère nul de fin. La longueur de la vue est déterminée comme si elle était obtenue par Traits::length(s). Le comportement est indéfini si [s,s + Traits::length(s)) n'est pas un intervalle valide (même si le constructeur n'accède à aucun élément de cet intervalle).

Paramètres

  • other — une autre vue servant à initialiser la vue
  • str — un objet chaîne C++ servant à initialiser la vue
  • s — pointeur vers un tableau de caractères ou une chaîne C servant à initialiser la vue
  • count — nombre de caractères à inclure dans la vue

Exceptions

4,5) Ne lève aucune exception.

Complexité

1-4) Constante.

  1. Linéaire en fonction de la longueur de s.

Exemple

#include <experimental/string_view>
#include <iostream>

int main()
{
    std::string cppstr = "Foo";
    char array[3] = {'B', 'a', 'r'};

    std::experimental::string_view cppstr_v(cppstr);
    std::experimental::string_view array_v(array, sizeof array);

    std::experimental::wstring_view wcstr_v = L"xyzzy";

    std::cout << cppstr_v << '\n'
              << array_v << '\n'
              << wcstr_v.size() << '\n';
}

Output:

Foo
Bar
5
