Il s'agit d'une valeur spéciale égale à la valeur maximale représentable par le type size_type. Le sens exact dépend du contexte ; elle est généralement utilisée soit comme indicateur de fin de vue par les fonctions qui attendent un indice de vue, soit comme indicateur d'erreur par les fonctions qui renvoient un indice de vue.
