std::experimental::basic_string_view<CharT,Traits>::substr

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr basic_string_view
    substr(size_type pos = 0, size_type count = npos ) const;

Retourne une vue de la sous-chaîne [pos, pos + rcount), où rcount est le plus petit de count et size() - pos.

Paramètres

  • pos — position du premier caractère
  • count — longueur demandée

Valeur de retour

Vue de la sous-chaîne [pos, pos + rcount).

Exceptions

std::out_of_range if pos > size()

Complexité

Constante.
