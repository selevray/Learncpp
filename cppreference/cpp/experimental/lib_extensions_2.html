Extensions des bibliothèques standard C++, version 2

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

La version 2 des extensions C++ pour les fondamentaux de la bibliothèque, ISO/IEC TS 19568:2017, définit les nouveaux composants suivants pour la bibliothèque standard C++, en plus de ceux définis dans la version 1 :

L'idiome de détection C++

Défini dans l'en-tête <experimental/type_traits>

  • is_detected detected_t detected_or — modèles d'alias qui détectent si un template-id est bien formé (modèle d'alias)
  • nonesuch — type de classe renvoyé par detected_t en cas d'échec (classe)

Un wrapper propageant const pour les objets de type pointeur

Défini dans l'en-tête <experimental/propagate_const>

  • propagate_const — un wrapper propageant const pour les objets de type pointeur (modèle de classe)

Pointeurs non propriétaires

Défini dans l'en-tête <experimental/memory>

  • observer_ptr — une classe représentant un pointeur non propriétaire (modèle de classe)

création std::array

Défini dans l'en-tête <experimental/array>

  • make_array (library fundamentals TS v2) — crée un objet std::array dont la taille et, facultativement, le type d'élément sont déduits des arguments (modèle de fonction)

ostream_joiner

Défini dans l'en-tête <experimental/iterator>

  • ostream_joiner — un itérateur de sortie qui écrit les éléments successifs dans un flux de sortie, en séparant les éléments adjacents par un délimiteur (modèle de classe)

Outils simples de génération de nombres aléatoires

Un moteur par thread de type std::default_random_engine, initialisé dans un état imprévisible, est maintenu pour chaque thread et utilisé par les fonctions ci-dessous.

Défini dans l'en-tête <experimental/random>

  • randint — génère un entier aléatoire dans l'intervalle spécifié (modèle de fonction)
  • reseed — réinitialise la graine du moteur aléatoire par thread (fonction)

Défini dans l'en-tête <experimental/algorithm>

  • sample — sélectionne n éléments aléatoires d'une séquence (modèle de fonction)
  • shuffle — réorganise aléatoirement les éléments d'un intervalle (modèle de fonction)

  • __cpp_lib_experimental_observer_ptr — une valeur d'au moins 201411 indique que observer_ptr est pris en charge (constante macro)

Défini dans l'en-tête <experimental/array>

Défini dans l'en-tête <experimental/iterator>

Intégrés dans C++17

Les composants suivants de Library Fundamentals v2 ont été intégrés à la norme C++17.

Défini dans l'en-tête <experimental/type_traits>

  • void_t — modèle d'alias variadique pour void (modèle d'alias)

Défini dans l'en-tête <experimental/type_traits>

  • conjunction — métafonction ET logique variadique (modèle de classe)
  • disjunction — métafonction OU logique variadique (modèle de classe)
  • negation — métafonction de négation logique (modèle de classe)

Défini dans l'en-tête <experimental/functional>

  • not_fn — crée un objet fonction qui renvoie le complément du résultat de l'objet fonction qu'il contient (modèle de fonction)

Défini dans l'en-tête <experimental/numeric>

  • gcd — constexpr modèle de fonction renvoyant le plus grand commun diviseur de deux entiers (modèle de fonction)
  • lcm — constexpr modèle de fonction retournant le plus petit commun multiple de deux entiers (modèle de fonction)
