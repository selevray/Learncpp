std::experimental::latch::~latch

~latch();  // (TS de concurrence)

Détruit le loquet.

Le comportement est indéfini si un thread est bloqué au point de synchronisation.

Le destructeur peut être appelé même si tous les threads ne sont pas revenus de wait() ou count_down_and_wait(), à condition que le compteur interne soit égal à zéro.

Le destructeur peut bloquer jusqu'à ce que tous les threads soient revenus des fonctions bloquantes.

Aucun thread n'est autorisé à se bloquer sur ce loquet après qu'un thread a invoqué le destructeur.
