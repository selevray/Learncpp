std::experimental::latch

Défini dans l'en-tête <experimental/latch>

class latch;  // (TS de concurrence)

La classe latch est un compteur décroissant de type ptrdiff_t qui peut être utilisé pour synchroniser des threads. La valeur du compteur est initialisée à la création. Des threads peuvent se bloquer sur le loquet jusqu'à ce que le compteur soit décrémenté à zéro. Il n'est pas possible d'augmenter ou de réinitialiser le compteur, ce qui fait du loquet une barrière à usage unique.

Contrairement à std::experimental::barrier, std::experimental::latch peut être décrémenté plusieurs fois par un thread participant.
