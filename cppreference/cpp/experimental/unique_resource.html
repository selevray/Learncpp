std::experimental::unique_resource

Défini dans l'en-tête <experimental/scope>

template< class R, class D >
class unique_resource;  // (spécification technique des fondamentaux de bibliothèque v3)

unique_resource est un wrapper RAII universel pour les descripteurs de ressources, qui possède et gère une ressource par l'intermédiaire d'un descripteur et libère cette ressource lorsque le unique_resource est détruit.

La ressource est libérée à l'aide du destructeur de type D lorsque l'un des cas suivants se produit :

  • l'objet unique_resource gestionnaire est détruit,
  • l'objet unique_resource gestionnaire est affecté à partir d'une autre ressource via operator= ou reset().

Soit le type RS égal à R si R est un type objet, ou std::reference_wrapper<std::remove_reference_t<R>> sinon :

  • unique_resource contient effectivement un sous-objet de type RS qui est ou enveloppe le descripteur de ressource, un destructeur de ressource de type D et un indicateur bool indiquant si le wrapper possède la ressource.
  • À titre explicatif, le sous-objet de type RS est appelé descripteur de ressource stocké, et le R stocké (si R est un type objet) ou enveloppé (si R est un type référence) est appelé descripteur de ressource sous-jacent. Ces deux termes ne sont pas utilisés par le LFTS.

Paramètres de modèle

  • R — type de descripteur de ressource
  • D — type de destructeur de ressource

Exigences sur les types

  • R doit être un type objet ou une référence lvalue vers un type objet. Soit UnrefR égal à std::remove_reference_t<R>, UnrefR doit être MoveConstructible, et si UnrefR n'est pas CopyConstructible, std::is_nothrow_move_constructible_v<UnrefR> doit être true.
  • D doit être un type Destructible et MoveConstructible FunctionObject, et si D n'est pas CopyConstructible, std::is_nothrow_move_constructible_v<D> doit être true. Étant donnée une lvalue d de type D et une lvalue r de type UnrefR, l'expression d(r) doit être bien formée.

Fonctions membres

  • (constructeur) — construit un nouveau unique_resource (fonction membre publique)
  • (destructeur) — libère la ressource gérée, le cas échéant (fonction membre publique)
  • operator= — affecte un unique_resource (fonction membre publique)

##### Modificateurs {#Modifiers}

  • release — libère la propriété (fonction membre publique)
  • reset — élimine ou remplace la ressource gérée (fonction membre publique)

##### Observateurs {#Observers}

  • get — accède au descripteur de ressource sous-jacent (fonction membre publique)
  • get_deleter — accède au destructeur de ressource utilisé pour libérer la ressource gérée (fonction membre publique)
  • operator*operator-> — accède à la cible du pointeur si le handle de ressource est un pointeur (fonction membre publique)

Fonctions non membres

  • make_unique_resource_checked — crée un unique_resource, en vérifiant la valeur invalide (modèle de fonction)

Guides de déduction

Notes

Les types de descripteurs de ressources satisfaisant NullablePointer peuvent également être gérés par std::unique_ptr. Contrairement à unique_ptr, unique_resource n'exige pas NullablePointer.
