Effectue des opérations de comparaison sur les objets optional.

1-6) Compare deux objets optional, lhs et rhs. Les valeurs contenues sont comparées (en utilisant operator== pour (1,2) et operator< pour (3-6)) uniquement si lhs et rhs contiennent toutes deux une valeur. Sinon,

  • lhs est considéré comme égal à rhs si, et seulement si, lhs et rhs ne contiennent pas de valeur.
  • lhs est considéré comme inférieur à rhs si, et seulement si, rhs contient une valeur et lhs n'en contient pas.

7-18) Compare opt avec un nullopt. Équivalent à (1-6) lorsqu'on compare à un optional ne contenant pas de valeur.

19-30) Compare opt avec un value. Les valeurs sont comparées (en utilisant operator== pour (19-22) et operator< pour (23-30)) uniquement si opt contient une valeur. Sinon, opt est considéré comme inférieur à value.

Paramètres

  • lhs, rhs, opt — un objet optional à comparer
  • value — valeur à comparer à la valeur contenue

Exigences sur les types

  • T doit satisfaire les exigences de EqualityComparable pour pouvoir utiliser les surcharges (1,2).

Valeur de retour

  1. Si bool(lhs) != bool(rhs), renvoie false.

Sinon, si bool(lhs) == false (et donc bool(rhs) == false aussi), renvoie true.

Sinon, renvoie *lhs == *rhs.

  1. Renvoie !(lhs == rhs).

  2. Si bool(rhs) == false renvoie false.

Sinon, si bool(lhs) == false, renvoie true.

Sinon renvoie *x < *y.

  1. Renvoie !(rhs < lhs).

  2. Renvoie rhs < lhs.

  3. Renvoie !(lhs < rhs).

7,8) Renvoie !opt.

9,10) Renvoie bool(opt).

  1. Renvoie false.

  2. Renvoie bool(opt).

  3. Renvoie !opt.

  4. Renvoie true.

  5. Renvoie bool(opt).

  6. Renvoie false.

  7. Renvoie true.

  8. Renvoie !opt.

  9. Renvoie bool(opt) ? *opt == value : false.

  10. Renvoie bool(opt) ? value == *opt : false.

  11. Renvoie bool(opt) ? !(*opt == value) : true.

  12. Renvoie bool(opt) ? !(value == *opt) : true.

  13. Renvoie bool(opt) ? *opt < value : true.

  14. Renvoie bool(opt) ? value < *opt : false.

  15. Renvoie !(opt > value).

  16. Renvoie !(value > opt).

  17. Renvoie bool(opt) ? value < *opt : false.

  18. Renvoie bool(opt) ? *opt < value : true.

  19. Renvoie !(opt < value).

  20. Renvoie !(value < opt).
