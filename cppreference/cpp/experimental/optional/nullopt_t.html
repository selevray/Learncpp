std::experimental::nullopt_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/optional>

struct nullopt_t;  // (TS des fondamentaux de la bibliothèque)

std::experimental::nullopt_t est un type de classe vide utilisé pour indiquer un type optional dans un état non initialisé. En particulier, std::experimental::optional possède un constructeur prenant nullopt_t comme unique argument, qui crée un optionnel ne contenant pas de valeur.

std::experimental::nullopt_t doit être un LiteralType et ne peut pas avoir de constructeur par défaut.

Il doit posséder un constructeur constexpr prenant un type littéral défini par l'implémentation.

Notes

nullopt_t n'est pas DefaultConstructible afin de prendre en charge à la fois op = {}; et op = nullopt; comme syntaxes pour désactiver un objet optionnel.

Une implémentation possible de cette classe est

struct nullopt_t
{
    constexpr nullopt_t(int) {}
};
