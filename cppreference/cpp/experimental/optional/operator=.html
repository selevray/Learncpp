std::experimental::optional<T>::operator=

optional& operator=( std::experimental::nullopt_t ) noexcept;  // (1) (TS des fondamentaux de la bibliothèque)

optional& operator=( const optional& other );  // (2) (TS des fondamentaux de la bibliothèque)

optional& operator=( optional&& other ) noexcept(/* voir ci-dessous */);  // (3) (TS des fondamentaux de la bibliothèque)

template< class U >
optional& operator=( U&& value );  // (4) (TS des fondamentaux de la bibliothèque)

Remplace le contenu de *this par le contenu de other.

  1. Si *this contient une valeur avant l'appel, la valeur contenue est détruite en appelant son destructeur, comme si l'on appelait val->T::~T(). *this ne contient pas de valeur après cet appel.

2,3) Affecte l'état de other.

  • Si *this et other ne contiennent tous deux pas de valeur, la fonction n'a aucun effet.
  • Si *this contient une valeur mais que other n'en contient pas, la valeur contenue est détruite en appelant son destructeur. *this ne contient pas de valeur après l'appel.
  • Si other contient une valeur, alors selon que *this contient ou non une valeur, la valeur contenue est soit initialisée directement, soit affectée à partir de *other (2) ou de std::move(*other) (3). Notez qu'un optionnel déplacé contient toujours une valeur.
  1. Affectation parfaitement transmise, réservée à la déduction : selon que *this contient une valeur avant l'appel, la valeur contenue est soit initialisée directement à partir de std::forward<U>(value), soit affectée à partir de std::forward<U>(value). La fonction ne participe pas à la résolution de surcharge sauf si std::is_same<std::decay_t<U>, T>::value est true.

Paramètres

  • other — un autre objet optional dont la valeur contenue doit être affectée
  • value — valeur à affecter à la valeur contenue

Exigences sur les types

  • T doit satisfaire aux exigences de CopyAssignable et de CopyConstructible pour utiliser la surcharge (2).
  • T doit satisfaire aux exigences de MoveAssignable et de MoveConstructible pour utiliser la surcharge (3).

Valeur de retour

*this

Exceptions

2-4) Lève toute exception levée par le constructeur ou l'opérateur d'affectation de T. Si une exception est levée, l'état d'initialisation de *this (et de other dans le cas de (2)) est inchangé, c'est-à-dire que si l'objet contenait une valeur, il en contient toujours une, et inversement. Le contenu de value et les valeurs contenues de *this et other dépendent des garanties de sûreté d'exception de l'opération à l'origine de l'exception (constructeur de copie, affectation par déplacement, etc.).
(3) a la déclaration noexcept suivante :noexcept specification:noexcept(std::is_nothrow_move_assignable<T>::value && std::is_nothrow_move_constructible<T>::value)

Notes

Un objet optionnel op peut être transformé en optionnel vide à l'aide de op = {}; et de op = nullopt;.

Exemple

#include <experimental/optional>
#include <iostream>

int main()
{
    std::experimental::optional<const char*> s1 = "abc", s2; // constructor
    s2 = s1; // assignment
    s1 = "def"; // affectation avec décroissance (U = char[4], T = const char*)
    std::cout << *s2 << ' ' << *s1 << '\n';
}

Output:

abc def
