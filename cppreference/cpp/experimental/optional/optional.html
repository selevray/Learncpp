Construit un nouvel objet optional.

  1. Construit l'objet qui ne contient pas de valeur.

  2. Constructeur de copie : si other contient une valeur, initialise la valeur contenue comme si l'on effectuait une initialisation directe (mais non une initialisation directe par liste) d'un objet de type T avec l'expression *other. Si other ne contient pas de valeur, construit un objet qui ne contient pas de valeur.

  3. Constructeur de déplacement : si other contient une valeur, initialise la valeur contenue comme si l'on effectuait une initialisation directe (mais non une initialisation directe par liste) d'un objet de type T avec l'expression std::move(*other), et ne rend pas other vide : un optional déplacé contient toujours une valeur, mais cette valeur a été déplacée. Si other ne contient pas de valeur, construit un objet qui ne contient pas de valeur.

  4. Construit un objet optional qui contient une valeur, initialisée comme si l'on effectuait une initialisation directe (mais non une initialisation directe par liste) d'un objet de type T avec l'expression value. Ce constructeur est constexpr si le constructeur de T sélectionné par l'initialisation directe est constexpr.

  5. Construit un objet optional qui contient une valeur, initialisée comme si l'on effectuait une initialisation directe (mais non une initialisation directe par liste) d'un objet de type T avec l'expression std::move(value). Ce constructeur est constexpr si le constructeur de T sélectionné par l'initialisation directe est constexpr.

  6. Construit un objet optional qui contient une valeur, initialisée comme si l'on effectuait une initialisation directe (mais non une initialisation directe par liste) d'un objet de type T à partir des arguments std::forward<Args>(args)....

  7. Construit un objet optional qui contient une valeur, initialisée comme si l'on effectuait une initialisation directe (mais non une initialisation directe par liste) d'un objet de type T à partir des arguments ilist, std::forward<Args>(args).... La fonction ne participe pas à la résolution de surcharge si std::is_constructible<T, std::initializer_list<U>&, Args&&...>::value != true.

Paramètres

  • other — un autre objet optional dont la valeur contenue doit être copiée
  • value — valeur avec laquelle initialiser la valeur contenue
  • args... — arguments servant à initialiser la valeur contenue
  • ilist — liste d'initialisation servant à initialiser la valeur contenue

Exigences sur les types

  • T doit satisfaire aux exigences de CopyConstructible pour utiliser les surcharges (2,4).
  • T doit satisfaire aux exigences de MoveConstructible pour utiliser les surcharges (3,5).

Exceptions

  1. Lève toute exception levée par le constructeur de T.

  2. Lève toute exception levée par le constructeur de T. Possède la déclaration suivante noexcept :noexcept specification:noexcept(std::is_nothrow_move_constructible<T>::value)

4-7) Lève toute exception levée par le constructeur de T.

Exemple

#include <experimental/optional>
#include <iostream>
#include <string>

int main()
{
    std::experimental::optional<int> o1,      // empty
                                     o2 = 1,  // initialisation à partir d'une rvalue
                                     o3 = o2; // constructeur de copie

    std::experimental::optional<std::string> o4(std::experimental::in_place,
                                                {'a', 'b', 'c'});

    std::cout << *o2 << ' ' << *o3 << ' ' << *o4 << '\n';
}

Output:

1 1 abc
