std::hash <std::experimental::optional>

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/optional>

template< class T >
struct hash<std::experimental::optional<T>>;  // (TS des fondamentaux de la bibliothèque)

La spécialisation de modèle de std::hash pour la classe std::experimental::optional permet aux utilisateurs d'obtenir les condensés des valeurs contenues dans les objets optional.

Paramètres de modèle

  • T — le type de la valeur contenue dans l'objet optional. La spécialisation std::hash<T> doit satisfaire les exigences du modèle de classe hash.

Exemple

#include <experimental/optional>
#include <iostream>
#include <string>
#include <unordered_set>
using namespace std::literals;

int main()
{
    // hash<optional> permet d'utiliser unordered_set
    std::unordered_set<std::experimental::optional<std::string>> s = {
        "abc"s, std::experimental::nullopt, "def"s
    };

    for (const auto& o : s)
        std::cout << o.value_or("(null)") << ' ';
    std::cout << '\n';
}

Sortie possible :

def abc (null)
