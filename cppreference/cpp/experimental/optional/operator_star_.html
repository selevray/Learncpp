Accède à la valeur contenue.

  1. Renvoie un pointeur vers la valeur contenue.

  2. Renvoie une référence vers la valeur contenue.

Le comportement est indéfini si *this ne contient pas de valeur.

Paramètres

(aucune)

Valeur de retour

Pointeur ou référence vers la valeur contenue.

Exceptions

Ne lève aucune exception.

Notes

Cet opérateur ne vérifie pas si l'optional contient une valeur. Si un accès vérifié est nécessaire, value() ou value_or() peut être utilisé.

Exemple

#include <experimental/optional>
#include <iostream>
#include <string>
using namespace std::literals;

int main()
{
    std::experimental::optional<int> opt1 = 1;
    std::cout << *opt1 << '\n';

    std::experimental::optional<std::string> opt2 = "abc"s;
    std::cout << opt2->size() << '\n';
}

Output:

1
3
