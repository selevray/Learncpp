std::experimental::optional<T>::value

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr T& value() &;
constexpr const T & value() const &;  // (1) (TS des fondamentaux de la bibliothèque)

constexpr T&& value() &&;
constexpr const T&& value() const &&;  // (2) (TS des fondamentaux de la bibliothèque)

Renvoie la valeur contenue.

  1. Équivalent à return bool(*this) ? *val : throw bad_optional_access();.

  2. Équivalent à return bool(*this) ? std::move(*val) : throw bad_optional_access();.

Paramètres

(aucune)

Valeur de retour

Une référence vers la valeur contenue.

Exceptions

std::experimental::bad_optional_access si *this ne contient pas de valeur.

Notes

L'opérateur de déréférencement operator*() ne vérifie pas si cet optional contient une valeur, ce qui peut être plus efficace que value().

Exemple

#include <experimental/optional>
#include <iostream>

int main()
{
    std::experimental::optional<int> opt = {};

    try
    {
        int n = opt.value();
    }
    catch (const std::logic_error& e)
    {
        std::cout << e.what() << '\n';
    }
}
