std::experimental::make_optional

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/optional>

template< class T >
constexpr optional<typename std::decay<T>::type>
    make_optional( T&& value );  // (TS des fondamentaux de la bibliothèque)

Crée un objet optionnel à partir de value. Appelle effectivement optional<typename std::decay<T>::type>(std::forward<T>(value)).

Paramètres

  • value — la valeur avec laquelle construire l'objet optionnel

Valeur de retour

Un objet optionnel ayant value comme valeur contenue.

Exceptions

Lève toute exception levée par le constructeur de T.
