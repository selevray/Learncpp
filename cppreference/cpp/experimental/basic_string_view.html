std::experimental::basic_string_view

Défini dans l'en-tête <experimental/string_view>

template<
    class CharT,
    class Traits = std::char_traits<CharT>
> class basic_string_view;  // (TS des fondamentaux de la bibliothèque)

Le modèle de classe basic_string_view décrit un objet pouvant référencer une séquence contiguë constante d'objets de type char dont le premier élément se trouve à la position zéro.

Une implémentation typique ne contient que deux membres : un pointeur vers CharT constant et une taille.
