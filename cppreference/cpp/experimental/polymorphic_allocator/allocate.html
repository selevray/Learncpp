std::experimental::pmr::polymorphic_allocator<T>::allocate

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

T* allocate( std::size_t n );  // (TS des fondamentaux de la bibliothèque)

Alloue un stockage pour n objets de type T en utilisant la ressource mémoire sous-jacente. Équivalent à

return static_cast<T*>(this->resource()->allocate(n * sizeof(T), alignof(T)));.

Paramètres

  • n — le nombre d'objets pour lesquels allouer un stockage

Valeur de retour

Un pointeur vers le stockage alloué.
