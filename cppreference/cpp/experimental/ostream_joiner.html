std::experimental::ostream_joiner

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/iterator>

template<
    class DelimT,
    class CharT = char,
    class Traits = std::char_traits<CharT>
>
class ostream_joiner;  // (spécification technique library fundamentals v2)

std::experimental::ostream_joiner est un LegacyOutputIterator à passe unique qui écrit successivement des objets dans l'objet std::basic_ostream pour lequel il a été construit, en utilisant operator<<, séparés par un délimiteur. Le délimiteur est écrit dans le flux de sortie entre chaque paire d'objets écrits. L'opération d'écriture est effectuée lorsque l'itérateur (déréférencé ou non) est affecté. L'incrémentation de ostream_joiner ne fait rien.

Dans une implémentation typique, les seuls membres de données de ostream_joiner sont un pointeur vers le std::basic_ostream associé, le délimiteur, et un membre bool indiquant si la prochaine écriture concerne le premier élément de la séquence.

Par rapport à std::ostream_iterator, ostream_joiner affiche la séquence de délimiteur une fois de moins, et n'est pas paramétré par le type de l'objet à afficher.

Exemple

#include <algorithm>
#include <experimental/iterator>
#include <iostream>
#include <iterator>

int main()
{
    int i[] = {1, 2, 3, 4, 5};
    std::copy(std::begin(i),
              std::end(i),
              std::experimental::make_ostream_joiner(std::cout, ", "));
}

Output:

1, 2, 3, 4, 5
