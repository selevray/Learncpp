Le modèle d'alias resource_adaptor adapte le type d'allocateur Alloc à une interface memory_resource. L'allocateur est re-lié à une valeur de type char avant d'être réellement adapté (à l'aide du modèle de classe resource-adaptor-imp), de sorte que l'adaptation de spécialisations du même modèle d'allocateur produise toujours le même type, quel que soit le type de valeur avec lequel le modèle d'allocateur a été initialement instancié.

resource_adaptor est défini dans l'espace de noms std::experimental::pmr, et le type de base memory_resorce de cette page est std::experimental::pmr::memory_resource.

(library fundamentals TS) (jusqu'à library fundamentals TS v3)

resource_adaptor est défini dans l'espace de noms std::pmr::experimental, et le type de base memory_resorce de cette page est std::pmr::memory_resource.

(spécification technique des fondamentaux de bibliothèque v3)

resource-adaptor-imp est un modèle de classe dont les membres sont décrits ci-dessous. Le nom resource-adaptor-imp n'est donné qu'à titre explicatif et n'est pas normatif.

En plus de satisfaire aux exigences Allocator, Alloc doit en outre satisfaire les exigences suivantes :

  • std::allocator_traits<Alloc>::pointer doit être identique à Alloc::value_type*.
  • std::allocator_traits<Alloc>::const_pointer doit être identique à Alloc::value_type const*.
  • std::allocator_traits<Alloc>::void_pointer doit être identique à void*.
  • std::allocator_traits<Alloc>::const_const_pointer doit être identique à void const*.

Désalloue le stockage pointé par p à l'aide de la fonction membre deallocate de l'allocateur encapsulé.

p doit avoir été alloué à l'aide de la fonction membre allocate d'un allocateur égal à l'allocateur encapsulé, et ne doit pas avoir été désalloué par la suite.
