std::experimental::atomic_shared_ptr<T>::load

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

shared_ptr<T> load( std::memory_order order = std::memory_order_seq_cst ) const noexcept;

Charge atomiquement et renvoie la valeur courante du atomic_shared_ptr. La mémoire est affectée selon la valeur de order.

order doit être l'une des valeurs std::memory_order_relaxed, std::memory_order_consume, std::memory_order_acquire ou std::memory_order_seq_cst. Sinon, le comportement est indéfini.

Paramètres

  • order — contraintes d'ordre mémoire à appliquer

Remarques

Tous les incréments use_count associés sont garantis d'être effectués dans le cadre de l'opération atomique.

Valeur de retour

La valeur courante du atomic_shared_ptr.
