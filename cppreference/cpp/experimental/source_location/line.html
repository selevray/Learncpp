std::experimental::source_location::line

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

constexpr std::uint_least32_t line() const noexcept;  // (spécification technique library fundamentals v2)

Renvoie le numéro de ligne représenté par cet objet.

Paramètres

(aucune)

Valeur de retour

Le numéro de ligne représenté par cet objet.

Exemple

#include <experimental/source_location>
#include <iostream>
#include <string_view>
using std::experimental::source_location;

inline void cur_line(
    const std::string_view message = "",
    const source_location& location = source_location::current())
{
    std::cout
        << location.line() // <- la ligne du site d'appel #
        << ") "
        << message;
}

int main()
{
    cur_line("++" "\n");
    cur_line(); std::cout << "Hello," "\n";
    cur_line(); std::cout << "C++20!" "\n";
    cur_line("--" "\n");
}

Output:

18) ++
19) Hello,
20) C++20!
21) --
