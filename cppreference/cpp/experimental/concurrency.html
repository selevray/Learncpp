Extensions pour la concurrence

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les extensions C++ pour la concurrence, ISO/IEC TS 19571:2016, définissent les composants suivants pour la bibliothèque standard C++ :

Continuations et autres extensions pour std::future

Défini dans l'en-tête <experimental/future>

  • future (concurrency TS) — une version de std::future enrichie de continuations et d'autres fonctionnalités (modèle de classe)
  • shared_future (concurrency TS) — une version de std::shared_future enrichie de continuations et d'autres fonctionnalités (modèle de classe)
  • promise (concurrency TS) — une version modifiée de std::promise qui utilise std::experimental::future (modèle de classe)
  • packaged_task (concurrency TS) — une version modifiée de std::packaged_task qui utilise std::experimental::future (modèle de classe)
  • when_all (concurrency TS) — produit un futur qui devient prêt lorsque tous les futurs donnés ou shared_futures sont prêts (modèle de fonction)
  • when_any (concurrency TS) — produit un futur qui devient prêt dès qu'au moins un des futures ou shared_futures donnés est prêt (modèle de fonction)
  • make_ready_future (concurrency TS) — produit un futur qui est immédiatement prêt et contient la valeur donnée (modèle de fonction)
  • make_exceptional_future (concurrency TS) — produit un futur qui est immédiatement prêt et contient l'exception donnée (modèle de fonction)

Macros de test de fonctionnalités

Défini dans l'en-tête <experimental/future>

  • __cpp_lib_experimental_future_continuations — une valeur d'au moins 201505 indique que future::then et les autres extensions sont prises en charge (constante macro)

Défini dans l'en-tête <experimental/latch>

  • __cpp_lib_experimental_latch — une valeur d'au moins 201505 indique que le type latch est pris en charge (constante macro)

Défini dans l'en-tête <experimental/barrier>

  • __cpp_lib_experimental_barrier — une valeur d'au moins 201505 indique que le type barrier est pris en charge (constante macro)

Défini dans l'en-tête <experimental/atomic>

  • __cpp_lib_experimental_atomic_smart_pointers — une valeur d'au moins 201505 indique que les pointeurs intelligents atomiques sont pris en charge (constante macro)

Intégré à C++20

Les composants suivants de la spécification technique Concurrency ont été intégrés à la norme C++20.

Latches et barrières

Défini dans l'en-tête <experimental/latch>

  • latch (concurrency TS) — barrière de threads à usage unique (classe)

Défini dans l'en-tête <experimental/barrier>

  • barrier (concurrency TS) — barrière de thread réutilisable (classe)
  • flex_barrier (concurrency TS) — barrière de thread réutilisable avec comportement personnalisable à la fin (classe)

Pointeurs intelligents atomiques

Ces modèles de classe remplacent les surcharges de fonctions atomiques de shared_ptr

Défini dans l'en-tête <experimental/atomic>

  • atomic_shared_ptr (concurrency TS) — version atomique de std::shared_ptr (modèle de classe)
  • atomic_weak_ptr (concurrency TS) — version atomique de std::weak_ptr (modèle de classe)
