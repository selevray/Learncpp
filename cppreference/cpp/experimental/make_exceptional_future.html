std::experimental::make_exceptional_future

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/future>

template< class T >
future<T> make_exceptional_future( std::exception_ptr ex );  // (1) (TS de concurrence)

template< class T, class E >
future<T> make_exceptional_future( E ex );  // (2) (TS de concurrence)

  1. Crée un état partagé de type T immédiatement prêt, qui stocke le pointeur d'exception ex, puis renvoie un futur associé à cet état partagé, comme si par promise<T> p; p.set_exception(ex); return p.get_future();. Le comportement est indéfini si ex est nul.

  2. Crée un état partagé de type T immédiatement prêt, qui stocke un pointeur d'exception créé à partir de ex, puis renvoie un futur associé à cet état partagé, comme si par promise<T> p; p.set_exception(std::make_exception_ptr(ex)); return p.get_future();.

Valeur de retour

Un future associé à l'état partagé qui a été créé.
