std::experimental::erased_type

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/utility>

struct erased_type { };  // (TS sur les fondamentaux de la bibliothèque) (supprimé dans library fundamentals TS v3)

La classe erased_type est une structure vide qui sert de substitut pour un type dans les situations où le type réel est déterminé à l'exécution. Par exemple, dans les classes qui utilisent des allocateurs à effacement de type, le typedef imbriqué allocator_type est un alias de erased_type.

Notes

erased_type est supprimé dans LFTS v3 car std::pmr::polymorphic_allocator<> est préférable pour l'effacement de type.
