std::experimental::propagate_const

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/propagate_const>

template< class T >
class propagate_const;  // (spécification technique library fundamentals v2)

std::experimental::propagate_const est un enveloppeur de pointeurs et d'objets de type pointeur qui propage la constness. Il traite le pointeur encapsulé comme un pointeur vers const lorsqu'il est accédé par un chemin d'accès const, d'où son nom.

La classe satisfait aux exigences de MoveConstructible et MoveAssignable si le type sous-jacent de type pointeur satisfait l'exigence correspondante, mais propagate_const n'est ni CopyConstructible ni CopyAssignable.

Exigences sur les types

  • T doit être un type pointeur vers objet non qualifié cv ou un type classe de type pointeur non qualifié cv, comme précisé ci-dessous.

Exigences sur les types classe de type pointeur

Si T est un type classe, il doit satisfaire aux exigences de cette sous-section.

Soient

  • t, une expression lvalue modifiable de type T,
  • ct, une lvalue de type const T qui désigne le même objet que t (équivalente à std::as_const(t) depuis C++17),
  • element_type, un type objet.

Les expressions suivantes doivent être valides et avoir les effets spécifiés :

Expression Type de retour Pré-conditions Sémantique opérationnelle
t.get() element_type*
ct.get() element_type* or const element_type* t.get() == ct.get()
*t element_type& t.get() != nullptr *t désigne le même objet que *(t.get())
*ct element_type& or const element_type& ct.get() != nullptr *ct désigne le même objet que *(ct.get())
t.operator->() element_type* t.get() != nullptr t.operator->() == t.get()
ct.operator->() element_type* or const element_type* ct.get() != nullptr ct.operator->() == ct.get()
(bool)t bool (bool)t est équivalent à t.get() != nullptr
(bool)ct bool (bool)ct est équivalent à ct.get() != nullptr

De plus, T et const T doivent être contextuellement convertibles en bool.

En outre, si T est implicitement convertible en element_type*, alors (element_type*)t doit être égal à t.get(). De même, si const T est implicitement convertible en const element_type*, alors (const element_type*)ct doit être égal à ct.get().

Exemple

#include <experimental/propagate_const>
#include <iostream>
#include <memory>

struct X
{
    void g() const { std::cout << "X::g (const)\n"; }
    void g() { std::cout << "X::g (non-const)\n"; }
};

struct Y
{
    Y() : m_propConstX(std::make_unique<X>()), m_autoPtrX(std::make_unique<X>()) {}

    void f() const
    {
        std::cout << "Y::f (const)\n";
        m_propConstX->g();
        m_autoPtrX->g();
    }

    void f()
    {
        std::cout << "Y::f (non-const)\n";
        m_propConstX->g();
        m_autoPtrX->g();
    }

    std::experimental::propagate_const<std::unique_ptr<X>> m_propConstX;
    std::unique_ptr<X> m_autoPtrX;
};

int main()
{
    Y y;
    y.f();

    const Y cy;
    cy.f();
}

Output:

Y::f (non-const)
X::g (non-const)
X::g (non-const)
Y::f (const)
X::g (const)
X::g (non-const)
