std::experimental::reseed

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/random>

void reseed();  // (1) (spécification technique library fundamentals v2)

void reseed( std::default_random_engine::result_type value );  // (2) (spécification technique library fundamentals v2)

Réinitialise le moteur de nombres aléatoires par thread ainsi que toutes les instances std::uniform_int_distribution utilisées par randint.

  1. Place le moteur par thread dans un état imprévisible.

  2. Initialise le moteur par thread g comme si par g.seed(value).

Paramètres

  • value — valeur de la nouvelle graine

Remarques

Les appels ultérieurs à randint ne dépendent pas des valeurs produites par le moteur par thread avant l'appel à reseed.

Exemple

#include <experimental/random>
#include <iostream>

int main()
{
    std::experimental::reseed();

    std::cout << "Random 2-digit decimal numbers: ";

    for (auto i = 0; i != 3; ++i)
        std::cout << std::experimental::randint(10, 99) << ' ';
    std::cout << '\n';
}

Sortie possible :

Random 2-digit decimal numbers: 41 60 56
