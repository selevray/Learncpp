operator==, operator!= (std::experimental::pmr::memory_resource)

bool operator==( const memory_resource& a, const memory_resource& b ) noexcept;  // (1) (TS des fondamentaux de la bibliothèque)

bool operator!=( const memory_resource& a, const memory_resource& b ) noexcept;  // (2) (TS des fondamentaux de la bibliothèque)

Compare les memory_resource a et b pour l'égalité. Deux memory_resource sont égaux si et seulement si la mémoire allouée depuis l'un des memory_resource peut être désallouée depuis l'autre, et réciproquement.

Valeur de retour

  1. &a == &b || a.is_equal(b)

  2. !(a == b)
