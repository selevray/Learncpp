std::experimental::pmr::memory_resource::do_is_equal

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

virtual bool is_equal( const memory_resource& other ) const noexcept = 0;  // (TS des fondamentaux de la bibliothèque)

Compare *this pour l'égalité avec other.

Deux memory_resource sont égaux si et seulement si la mémoire allouée par l'un peut être désallouée par l'autre, et réciproquement, à partir de memory_resource.

Notes

Le type le plus dérivé de other peut ne pas correspondre au type le plus dérivé de *this. Une implémentation de classe dérivée doit donc généralement vérifier si les types les plus dérivés de *this et other correspondent en utilisant dynamic_cast, et renvoyer immédiatement false si le cast échoue.
