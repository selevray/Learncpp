std::experimental::pmr::memory_resource::is_equal

bool is_equal( const memory_resource& other ) const noexcept;  // (TS des fondamentaux de la bibliothèque)

Compare *this pour l'égalité avec other. Deux memory_resource sont égaux si et seulement si la mémoire allouée par l'un memory_resource peut être désallouée par l'autre, et inversement.

Équivalent à return do_is_equal(other);.
