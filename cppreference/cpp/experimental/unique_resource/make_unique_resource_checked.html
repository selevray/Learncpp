std::experimental::make_unique_resource_checked

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/scope>

template< class R, class D, class S = std::decay_t<R> >
std::experimental::unique_resource<std::decay_t<R>, std::decay_t<D>>
    make_unique_resource_checked( R&& r, const S& invalid, D&& d )
    noexcept(/*voir ci-dessous*/);  // (spécification technique des fondamentaux de bibliothèque v3)

Crée un unique_resource, initialise son handle de ressource stocké avec std::forward<R>(r) et son deleter avec std::forward<D>(d). Le unique_resource créé possède la ressource si et seulement si bool(r == invalid) vaut false.

Le programme est mal formé si l'expression r == invalid ne peut pas être convertie contextuellement en bool, et le comportement est indéfini si la conversion entraîne un comportement indéfini ou lève une exception.

Paramètres

  • r — un handle de ressource
  • d — un deleter à utiliser pour libérer la ressource
  • invalid — une valeur indiquant que le handle de ressource est invalide

Valeur de retour

Un unique_resource décrit ci-dessus.

Exceptions

Toute exception levée lors de l'initialisation du descripteur de ressource stocké et du destructeur de ressource.

noexcept specification:noexcept( std::is_nothrow_constructible_v<std::decay_t<R>, R> && std::is_nothrow_constructible_v<std::decay_t<D>, D> )

Notes

make_unique_resource_checked existe pour éviter d'appeler une fonction de destruction avec un argument invalide.

Le descripteur de ressource r est soit copié, soit déplacé dans la valeur de retour, et le unique_resource créé contient toujours un descripteur de ressource sous-jacent de type objet.

Exemple

#include <cstdio>
#include <experimental/scope>

int main()
{
    // évite d'appeler fclose lorsque fopen échoue
    auto file = std::experimental::make_unique_resource_checked(
        std::fopen("potentially_nonexistent_file.txt", "r"),
        nullptr,
        [](std::FILE *fptr) { std::fclose(fptr); }
    );
    if (file.get())
        std::puts("The file exists.");
    else
        std::puts("The file does not exist.");
}

Sortie possible :

The file does not exist.
