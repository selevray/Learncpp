std::experimental::unique_resource<R, D>::reset

void reset() noexcept;  // (1) (spécification technique des fondamentaux de bibliothèque v3)

template< class RR >
void reset( RR&& r );  // (2) (spécification technique des fondamentaux de bibliothèque v3)

  1. Libère la ressource en appelant le destructeur de ressource avec le descripteur de ressource sous-jacent si unique_resource la possède. Le unique_resource ne possède plus la ressource après l'appel.

  2. Remplace la ressource en appelant (1) puis affecte le descripteur de ressource stocké avec std::forward<RR>(r) si std::is_nothrow_assignable_v<RS, RR> est true, sinon std::as_const(r), où RS est le type du descripteur de ressource stocké. Le unique_resource possède la ressource après l'appel.

Si l'affectation par copie du descripteur de ressource stocké lève une exception, appelle del_(r), où del est l'objet destructeur de ressource.

Cette surcharge participe à la résolution de surcharge uniquement si l'expression d'affectation choisie, qui affecte le descripteur de ressource stocké, est bien formée.

Le programme est mal formé si del_(r) est mal formé.

Le comportement est indéfini si del_(r) entraîne un comportement indéfini ou lève une exception.

Paramètres

  • r — descripteur de ressource pour une nouvelle ressource à gérer

Valeur de retour

(aucune)

Exceptions

  1. Toute exception levée lors de l'affectation du descripteur de ressource stocké.

Notes

Le mécanisme garantit l'absence de fuite de ressources.
