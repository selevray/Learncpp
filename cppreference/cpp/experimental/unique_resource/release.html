std::experimental::unique_resource<R, D>::release

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

void release() noexcept;  // (spécification technique des fondamentaux de bibliothèque v3)

Libère la propriété de la ressource gérée, le cas échéant. Le destructeur n'exécutera pas le destructeur de ressource après l'appel, sauf si reset est appelé ultérieurement pour gérer une nouvelle ressource.

Contrairement à std::unique_ptr::release, cette fonction n'est pas tenue de modifier le descripteur de ressource stocké.
