std::experimental::negation

template< class B >
struct negation;  // (1) (spécification technique library fundamentals v2)

Forme la négation logique du trait de type B.

Le type negation<B> est un UnaryTypeTrait dont la caractéristique de base est std::integral_constant<bool, !bool(B::value)>.

Paramètres de modèle

  • B — tout type tel que l'expression bool(B::value) est une expression constante valide

Modèle de variable auxiliaire

template< class B >
constexpr bool negation_v = negation<B>::value;  // (spécification technique library fundamentals v2)

Hérité de std::integral_constant

Constantes membres

  • value [statique] — true si B possède un membre ::value tel que !bool(B::value) est true, false sinon (constante membre statique publique)

Fonctions membres

  • operator bool — convertit l'objet en bool, renvoie value (fonction membre publique)
  • operator() (C++14) — renvoie value (fonction membre publique)

Types membres

Type Définition

  • value_type — bool
  • type — std::integral_constant<bool, value>

Implémentation possible

template<class B>
struct negation : std::integral_constant<bool, !bool(B::value)> {};
