std::experimental::packaged_task (concurrency TS)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Cette page traite de la version modifiée de std::packaged_task fournie par la TS de concurrence, prenant en charge les améliorations std::future apportées par cette TS. Pour la version de packaged_task avec prise en charge d'allocateur à effacement de type fournie par les TS Library Fundamentals, voir std::experimental::fundamentals_v2::packaged_task.

Défini dans l'en-tête <experimental/future>

template< class > class packaged_task; //non défini  // (1) (TS de concurrence)

template< class R, class ...Args >
class packaged_task<R(Args...)>;  // (2) (TS de concurrence)

std::experimental::concurrency_v1::packaged_task est une version modifiée de std::packaged_task fournie par le concurrency TS, qui fonctionne avec std::experimental::future.

Seule modification par rapport à std::packaged_task : la fonction membre get_future() retourne un std::experimental::future<R>.
