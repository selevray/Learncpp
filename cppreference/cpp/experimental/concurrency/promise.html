std::experimental::promise (concurrency TS)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Cette page traite de la version modifiée de std::promise fournie par la TS de concurrence, prenant en charge les améliorations std::future apportées par cette TS. Pour la version de promise avec prise en charge d'allocateur à effacement de type fournie par les TS Library Fundamentals, voir std::experimental::fundamentals_v2::promise.

Défini dans l'en-tête <experimental/future>

template< class R > class promise;  // (1) (TS de concurrence)

template< class R > class promise<R&>;  // (2) (TS de concurrence)

template<>          class promise<void>;  // (3) (TS de concurrence)

std::experimental::concurrency_v1::promise est une version modifiée de std::promise fournie par le concurrency TS, qui fonctionne avec std::experimental::future.

Seule modification par rapport à std::promise : la fonction membre get_future() retourne un std::experimental::future.
