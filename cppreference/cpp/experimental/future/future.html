std::experimental::future<T>::future

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

future() noexcept;  // (1)

future( std::experimental::future<T>&& f ) noexcept;  // (2)

future( const std::experimental::future<T>& ) = delete;  // (3)

future( std::experimental::future<std::experimental::future<T>> && other ) noexcept;  // (4)

  1. Constructeur par défaut. Construit un objet future vide qui ne fait pas référence à un état partagé.

  2. Construit un objet future, en transférant l'état partagé détenu par f, le cas échéant. Après la construction, f.valid() est false.

  3. Le constructeur de copie est supprimé. future ne peut pas être copié.

  4. Constructeur de déballage. Construit un objet future à partir de l'état partagé référencé par other, le cas échéant. Si other.valid() == false avant cet appel, l'objet future construit est vide. Sinon, l'objet future résultant devient prêt lorsque l'une des situations suivantes se produit :

  • other et other.get() sont toutes deux prêtes. La valeur ou l'exception provenant de other.get() est stockée dans l'état partagé associé à l'objet future résultant.
  • other est prêt, mais other.get() est invalide. Une exception de type std::future_error avec une condition d'erreur de std::future_errc::broken_promise est stockée dans l'état partagé associé à l'objet future résultant.

Après le retour de ce constructeur, valid() est égal à la valeur de other.valid() avant cet appel, et other.valid() == false.

Paramètres

  • f — un autre objet future à initialiser avec
  • other — un objet std::experimental::future à déballer
