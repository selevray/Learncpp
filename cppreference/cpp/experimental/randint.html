std::experimental::randint

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <experimental/random>

template< class IntType >
IntType randint( IntType a, IntType b );  // (spécification technique library fundamentals v2)

Génère un entier aléatoire dans l'intervalle fermé [a, b].

Paramètres

  • a, b — valeurs entières spécifiant l'intervalle

Valeur de retour

Un entier aléatoire i dans l'intervalle fermé [a, b], produit à l'aide d'une instance locale au thread de std::uniform_int_distribution<IntType> invoquée avec le moteur de nombres aléatoires par thread.

Remarques

Si IntType n'est aucun de short, int, long, long long, unsigned short, unsigned int, unsigned long ou unsigned long long, le programme est mal formé.

Le comportement est indéfini si a > b.

Exemple

#include <experimental/random>
#include <iostream>

int main()
{
    int random_number = std::experimental::randint(100, 999);
    std::cout << "random 3-digit number: " << random_number << '\n';
}

Sortie possible :

random 3-digit number: 273
