std::experimental::flex_barrier::flex_barrier

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

explicit flex_barrier( std::ptrdiff_t num_threads );  // (1) (TS de concurrence)

template< class F >
flex_barrier( std::ptrdiff_t num_threads, F completion );  // (2) (TS de concurrence)

flex_barrier( const flex_barrier & ) = delete;  // (3) (TS de concurrence)

  1. a le même effet que flex_barrier(num_threads, c), où c est un objet Callable dont l'invocation renvoie -1 et n'a aucun effet de bord.

  2. Construit un flex_barrier pour num_threads threads participants, en utilisant completion pour la phase de complétion. L'ensemble des threads participants est constitué des num_threads premiers threads à atteindre le point de synchronisation.

  3. Le constructeur de copie est supprimé ; flex_barrier n'est pas copiable.

Paramètres

  • num_threads — le nombre de threads participants pour le flex_barrier ; doit être positif ou nul
  • completion — un objet fonction contrôlant la phase de complétion ; doit être Callable sans arguments et de type de retour std::ptrdiff_t, et, lorsqu'il est invoqué, doit renvoyer une valeur non inférieure à -1 et ne doit pas lever d'exception

Exigences sur les types

  • F doit satisfaire aux exigences de CopyConstructible.

Notes

Si num_threads vaut zéro, l'ensemble des threads participants est vide, et flex_barrier ne peut plus qu'être détruit.
