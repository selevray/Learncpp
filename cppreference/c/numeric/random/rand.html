rand

Défini dans l'en-tête <stdlib.h>

int rand();

Renvoie un entier pseudo-aléatoire compris entre 0 et RAND_MAX (0 et RAND_MAX inclus).

srand() initialise le générateur de nombres pseudo-aléatoires utilisé par rand(). Si rand() est utilisé avant tout appel à srand(), rand() se comporte comme s'il avait été initialisé avec srand(1). Chaque fois que rand() est initialisé avec srand(), il doit produire la même suite de valeurs.

rand() n'est pas garanti thread-safe.

Paramètres

(aucune)

Valeur de retour

Entier pseudo-aléatoire compris entre 0 et RAND_MAX, bornes incluses.

Notes

Aucune garantie n'est donnée quant à la qualité de la suite aléatoire produite. Par le passé, certaines implémentations de rand() ont présenté de sérieuses lacunes en matière de caractère aléatoire, de distribution et de période de la suite produite (dans un exemple bien connu, le bit de poids faible alternait simplement entre 1 et 0 d'un appel à l'autre). rand() n'est pas recommandé pour des besoins sérieux de génération de nombres aléatoires, comme la cryptographie.

POSIX exige que la période du générateur de nombres pseudo-aléatoires utilisé par rand soit au moins égale à 232
.

POSIX proposait une version de rand sûre vis-à-vis des threads, appelée rand_r, qui est obsolète au profit de la famille de fonctions drand48.

Exemple

#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void)
{
    srand(time(NULL)); // utilise l'heure courante comme graine pour le générateur aléatoire
    int random_variable = rand();
    printf("Random value on [0,%d]: %d\n", RAND_MAX, random_variable);

    // lancer un dé à 6 faces 20 fois
    for (int n=0; n != 20; ++n) {
        int x = 7;
        while(x > 6)
            x = 1 + rand()/((RAND_MAX + 1u)/6); // Note : 1+rand()%6 est biaisé
        printf("%d ",  x);
    }
}
