Défini dans l'en-tête <tgmath.h>

#define acosh( z )  // (4) (depuis C99)

1-3) Calcule l'arc cosinus hyperbolique complexe d'une valeur complexe z, avec une coupure de branche pour les valeurs inférieures à 1 le long de l'axe réel.

  1. Macro générique par type : si z est de type long double complex, cacoshl est appelée ; si z est de type double complex, cacosh est appelée ; si z est de type float complex, cacoshf est appelée. Si z est réel ou entier, la macro invoque la fonction réelle correspondante (acoshf, acosh, acoshl). Si z est imaginaire, la macro invoque la version complexe correspondante et le type de retour est complexe.

Paramètres

  • z — argument complexe

Valeur de retour

L'arc cosinus hyperbolique complexe de z se trouve dans l'intervalle [0; ∞) le long de l'axe réel et dans l'intervalle [−iπ; +iπ] le long de l'axe imaginaire.

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées conformément à math_errhandling

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • cacosh(conj(z)) == conj(cacosh(z))
  • Si z vaut ±0+0i, le résultat est +0+iπ/2
  • Si z vaut +x+∞i (pour tout x fini), le résultat est +∞+iπ/2
  • Si z vaut +x+NaNi (pour x fini non nul), le résultat est NaN+NaNi et FE_INVALID peut être levé.
  • Si z vaut 0+NaNi, le résultat est NaN±iπ/2, où le signe de la partie imaginaire n'est pas spécifié
  • Si z vaut -∞+yi (pour tout y fini positif), le résultat est +∞+iπ
  • Si z vaut +∞+yi (pour tout y fini positif), le résultat est +∞+0i
  • Si z vaut -∞+∞i, le résultat est +∞+3iπ/4
  • Si z vaut +∞+∞i, le résultat est +∞+iπ/4
  • Si z vaut ±∞+NaNi, le résultat est +∞+NaNi
  • Si z vaut NaN+yi (pour tout y fini), le résultat est NaN+NaNi et FE_INVALID peut être levé.
  • Si z vaut NaN+∞i, le résultat est +∞+NaNi
  • Si z vaut NaN+NaNi, le résultat est NaN+NaNi

Notes

Bien que la norme C nomme cette fonction « arc cosinus hyperbolique complexe », les fonctions inverses des fonctions hyperboliques sont les fonctions d'aire. Leur argument est l'aire d'un secteur hyperbolique, et non un arc. Le nom correct est « cosinus hyperbolique inverse complexe », et, moins courant, « cosinus hyperbolique d'aire complexe ».

Le cosinus hyperbolique inverse est une fonction multivaluée et nécessite une coupure de branche sur le plan complexe. La coupure de branche est conventionnellement placée sur le segment de droite (-∞,+1) de l'axe réel.

La définition mathématique de la valeur principale du cosinus hyperbolique inverse est acosh z = ln(z + √z+1 √z-1)

Pour tout z, acosh(z) =
√z-1
√1-z

acos(z), ou simplement i acos(z) dans le demi-plan supérieur du plan complexe.

Exemple

#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z = cacosh(0.5);
    printf("cacosh(+0.5+0i) = %f%+fi\n", creal(z), cimag(z));

    double complex z2 = conj(0.5); // ou cacosh(CMPLX(0.5, -0.0)) en C11
    printf("cacosh(+0.5-0i) (the other side of the cut) = %f%+fi\n", creal(z2), cimag(z2));

    // dans le demi-plan supérieur, acosh(z) = i*acos(z)
    double complex z3 = casinh(1+I);
    printf("casinh(1+1i) = %f%+fi\n", creal(z3), cimag(z3));
    double complex z4 = I*casin(1+I);
    printf("I*asin(1+1i) = %f%+fi\n", creal(z4), cimag(z4));
}

Output:

cacosh(+0.5+0i) = 0.000000-1.047198i
cacosh(+0.5-0i) (the other side of the cut) = 0.500000-0.000000i
casinh(1+1i) = 1.061275+0.666239i
I*asin(1+1i) = -1.061275+0.666239i
