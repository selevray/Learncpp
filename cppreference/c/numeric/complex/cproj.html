cprojf, cproj, cprojl

float complex       cprojf( float complex z );  // (1) (depuis C99)

double complex      cproj( double complex z );  // (2) (depuis C99)

long double complex cprojl( long double complex z );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define cproj( z )  // (4) (depuis C99)

1-3) Calcule la projection de z sur la sphère de Riemann.

  1. Macro générique par type : si z est de type long double complex, long double imaginary ou long double, cprojl est appelée. Si z est de type float complex, float imaginary ou float, cprojf est appelée. Si z est de type double complex, double imaginary, double, ou tout type entier, cproj est appelée.

Pour la plupart des z, cproj(z)==z, mais tous les infinis complexes, y compris les nombres dont une composante est infinie et l'autre NaN, deviennent l'infini réel positif, INFINITY+0.0*I ou INFINITY-0.0*I. Le signe de la composante imaginaire (nulle) est le signe de cimag(z).

Paramètres

  • z — argument complexe

Valeur de retour

La projection de z sur la sphère de Riemann.

Cette fonction est entièrement spécifiée pour toutes les entrées possibles et n'est soumise à aucune des erreurs décrites dans math_errhandling

Notes

La fonction cproj aide à modéliser la sphère de Riemann en associant toutes les infinités à une seule (au signe du zéro imaginaire près), et doit être utilisée juste avant toute opération, en particulier les comparaisons, susceptible de donner des résultats parasites pour l'une des autres infinités.

Exemple

#include <stdio.h>
#include <complex.h>
#include <math.h>

int main(void)
{
    double complex z1 = cproj(1 + 2*I);
    printf("cproj(1+2i) = %.1f%+.1fi\n", creal(z1),cimag(z1));

    double complex z2 = cproj(INFINITY+2.0*I);
    printf("cproj(Inf+2i) = %.1f%+.1fi\n", creal(z2),cimag(z2));

    double complex z3 = cproj(INFINITY-2.0*I);
    printf("cproj(Inf-2i) = %.1f%+.1fi\n", creal(z3),cimag(z3));
}

Output:

cproj(1+2i) = 1.0+2.0i
cproj(Inf+2i) = inf+0.0i
cproj(Inf-2i) = inf-0.0i
