1-3) Calcule l'arc tangente complexe de z avec des coupures de branche situées en dehors de l'intervalle [−i,+i] le long de l'axe imaginaire.

  1. Macro générique par type : si z a le type long double complex, catanl est appelée ; si z a le type double complex, catan est appelée ; si z a le type float complex, catanf est appelée. Si z est réel ou entier, la macro invoque la fonction réelle correspondante (atanf, atan, atanl). Si z est imaginaire, la macro invoque la version réelle correspondante de la fonction atanh, en implémentant la formule atan(iy) = i atanh(y), et le type de retour de la macro est imaginaire.

Paramètres

  • z — argument complexe

Valeur de retour

Si aucune erreur ne se produit, l'arc tangente complexe de z est renvoyée, dans l'intervalle d'une bande non bornée le long de l'axe imaginaire et dans l'intervalle [−π/2; +π/2] le long de l'axe réel.

Les erreurs et les cas particuliers sont traités comme si l'opération était implémentée par -I * catanh(I*z).

Notes

La tangente inverse (ou arc tangente) est une fonction multivaluée et nécessite une coupure de branche dans le plan complexe. La coupure de branche est conventionnellement placée sur les segments de droite (-∞i,-i) et (+i,+∞i) de l'axe imaginaire.

Exemple

#include <stdio.h>
#include <float.h>
#include <complex.h>

int main(void)
{
    double complex z = catan(2*I);
    printf("catan(+0+2i) = %f%+fi\n", creal(z), cimag(z));

    double complex z2 = catan(-conj(2*I)); // ou CMPLX(-0.0, 2)
    printf("catan(-0+2i) (the other side of the cut) = %f%+fi\n", creal(z2), cimag(z2));

    double complex z3 = 2*catan(2*I*DBL_MAX); // ou CMPLX(0, INFINITY)
    printf("2*catan(+0+i*Inf) = %f%+fi\n", creal(z3), cimag(z3));
}

Output:

catan(+0+2i) = 1.570796+0.549306i
catan(-0+2i) (the other side of the cut) = -1.570796+0.549306i
2*catan(+0+i*Inf) = 3.141593+0.000000i
