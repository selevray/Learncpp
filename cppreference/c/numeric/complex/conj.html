Défini dans l'en-tête <tgmath.h>

#define conj( z )  // (4) (depuis C99)

1-3) Calcule le conjugué complexe de z en inversant le signe de la partie imaginaire.

  1. Macro générique par type : si z est de type long double complex, long double imaginary ou long double, conjl est appelée. Si z est de type float complex, float imaginary ou float, conjf est appelée. Si z est de type double complex, double imaginary, double, ou tout type entier, conj est appelée.

Paramètres

  • z — argument complexe

Valeur de retour

La conjuguée complexe de z.

Notes

Sur les implémentations C99 qui n'implémentent pas I comme _Imaginary_I, conj peut être utilisé pour obtenir des nombres complexes dont la partie imaginaire est un zéro négatif. En C11, la macro CMPLX est utilisée à cette fin.

Exemple

#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z = 1.0 + 2.0*I;
    double complex z2 = conj(z);
    printf("The conjugate of %.1f%+.1fi is %.1f%+.1fi\n",
            creal(z), cimag(z), creal(z2), cimag(z2));

    printf("Their product is %.1f%+.1fi\n", creal(z*z2), cimag(z*z2));
}

Output:

The conjugate of 1.0+2.0i is 1.0-2.0i
Their product is 5.0+0.0i
