1-3) Calcule l'arc sinus complexe de z, avec des coupures de branche à l'extérieur de l'intervalle [−1,+1] le long de l'axe réel.

  1. Macro générique par type : si z est de type long double complex, casinl est appelée ; si z est de type double complex, casin est appelée ; si z est de type float complex, casinf est appelée. Si z est réel ou entier, la macro invoque la fonction réelle correspondante (asinf, asin, asinl). Si z est imaginaire, la macro invoque la version réelle correspondante de la fonction asinh, en implémentant la formule (\small \arcsin({\rm i}y) = {\rm i}{\rm arsinh}(y))arcsin(iy) = i arsinh(y), et le type de retour de la macro est imaginaire.

Paramètres

  • z — argument complexe

Valeur de retour

Si aucune erreur ne se produit, l'arc sinus complexe de z est renvoyé, dans la bande illimitée le long de l'axe imaginaire et dans l'intervalle [−π/2; +π/2] le long de l'axe réel.

Les erreurs et cas particuliers sont traités comme si l'opération était implémentée par -I * casinh(I*z)

Notes

L'arc sinus inverse est une fonction multivaluée et nécessite une coupure de branche sur le plan complexe. La coupure de branche est conventionnellement placée sur les segments de droite (-∞,-1) et (1,∞) de l'axe réel.

La définition mathématique de la valeur principale de l'arc sinus est (\small \arcsin z = -{\rm i}\ln({\rm i}z+\sqrt{1-z^2}))arcsin z = -iln(iz + √1-z2
)

Pour tout z, (\small{ \arcsin(z) = \arccos(-z) - \frac{\pi}{2} })arcsin(z) = acos(-z) -

Exemple

#include <stdio.h>
#include <math.h>
#include <complex.h>

int main(void)
{
    double complex z = casin(-2);
    printf("casin(-2+0i) = %f%+fi\n", creal(z), cimag(z));

    double complex z2 = casin(conj(-2)); // ou CMPLX(-2, -0.0)
    printf("casin(-2-0i) (the other side of the cut) = %f%+fi\n", creal(z2), cimag(z2));

    // pour tout z, asin(z) = acos(-z) - pi/2
    double pi = acos(-1);
    double complex z3 = csin(cacos(conj(-2))-pi/2);
    printf("csin(cacos(-2-0i)-pi/2) = %f%+fi\n", creal(z3), cimag(z3));
}

Output:

casin(-2+0i) = -1.570796+1.316958i
casin(-2-0i) (the other side of the cut) = -1.570796-1.316958i
csin(cacos(-2-0i)-pi/2) = 2.000000+0.000000i
