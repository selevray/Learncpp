1-3) Calcule le cosinus hyperbolique complexe de z.

  1. Macro générique par type : si z a le type long double complex, ccoshl est appelée ; si z a le type double complex, ccosh est appelée ; si z a le type float complex, ccoshf est appelée. Si z est réel ou entier, la macro invoque la fonction réelle correspondante (coshf, cosh, coshl). Si z est imaginaire, la macro invoque la version réelle correspondante de la fonction cos, en implémentant la formule cosh(iy) = cos(y), et le type de retour est réel.

Paramètres

  • z — argument complexe

Valeur de retour

Si aucune erreur ne se produit, le cosinus hyperbolique complexe de z est renvoyé

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées conformément à math_errhandling

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • ccosh(conj(z)) == conj(ccosh(z))
  • ccosh(z) == ccosh(-z)
  • Si z vaut +0+0i, le résultat est 1+0i
  • Si z vaut +0+∞i, le résultat est NaN±0i (le signe de la partie imaginaire n'est pas spécifié) et FE_INVALID est levé
  • Si z vaut +0+NaNi, le résultat est NaN±0i (le signe de la partie imaginaire est non spécifié)
  • Si z vaut x+∞i (pour tout x fini non nul), le résultat est NaN+NaNi et FE_INVALID est levé
  • Si z vaut x+NaNi (pour tout x fini non nul), le résultat est NaN+NaNi et FE_INVALID peut être levé
  • Si z vaut +∞+0i, le résultat est +∞+0i
  • Si z vaut +∞+yi (pour tout y fini non nul), le résultat est +∞cis(y)
  • Si z vaut +∞+∞i, le résultat est ±∞+NaNi (le signe de la partie réelle n'est pas spécifié) et FE_INVALID est levé
  • Si z vaut +∞+NaN, le résultat est +∞+NaN
  • Si z vaut NaN+0i, le résultat est NaN±0i (le signe de la partie imaginaire est non spécifié)
  • Si z vaut NaN+yi (pour tout y fini non nul), le résultat est NaN+NaNi et FE_INVALID peut être levé
  • Si z vaut NaN+NaNi, le résultat est NaN+NaNi

où cis(y) vaut cos(y) + i sin(y)

Notes

La définition mathématique du cosinus hyperbolique est cosh z =
ez +e-z
2

Le cosinus hyperbolique est une fonction entière dans le plan complexe et n'a aucune coupure de branche. Elle est périodique par rapport à la composante imaginaire, de période 2πi

Exemple

#include <stdio.h>
#include <math.h>
#include <complex.h>

int main(void)
{
    double complex z = ccosh(1);  // se comporte comme le cosh réel le long de la droite réelle
    printf("cosh(1+0i) = %f%+fi (cosh(1)=%f)\n", creal(z), cimag(z), cosh(1));

    double complex z2 = ccosh(I); // se comporte comme le cosinus réel le long de la droite imaginaire
    printf("cosh(0+1i) = %f%+fi ( cos(1)=%f)\n", creal(z2), cimag(z2), cos(1));
}

Output:

cosh(1+0i) = 1.543081+0.000000i (cosh(1)=1.543081)
cosh(0+1i) = 0.540302+0.000000i ( cos(1)=0.540302)
