cacosf, cacos, cacosl

Défini dans l'en-tête <tgmath.h>

#define acos( z )  // (4) (depuis C99)

1-3) Calcule l'arc cosinus complexe de z, avec des coupures de branche à l'extérieur de l'intervalle [−1,+1] le long de l'axe réel.

  1. Macro générique par type : si z est de type long double complex, cacosl est appelée ; si z est de type double complex, cacos est appelée ; si z est de type float complex, cacosf est appelée. Si z est réel ou entier, la macro invoque la fonction réelle correspondante (acosf, acos, acosl). Si z est imaginaire, la macro invoque la version complexe correspondante.

Paramètres

  • z — argument complexe

Valeur de retour

Si aucune erreur ne se produit, l'arc cosinus complexe de z est renvoyé, dans une bande non bornée le long de l'axe imaginaire et dans l'intervalle [0 ; π] le long de l'axe réel.

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées conformément à math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • cacos(conj(z)) == conj(cacos(z))
  • Si z vaut ±0+0i, le résultat est π/2-0i
  • Si z vaut ±0+NaNi, le résultat est π/2+NaNi
  • Si z vaut x+∞i (pour tout x fini), le résultat est π/2-∞i
  • Si z vaut x+NaNi (pour tout x fini non nul), le résultat est NaN+NaNi et FE_INVALID peut être levé.
  • Si z vaut -∞+yi (pour tout y fini positif), le résultat est π-∞i
  • Si z vaut +∞+yi (pour tout y fini positif), le résultat est +0-∞i
  • Si z vaut -∞+∞i, le résultat est 3π/4-∞i
  • Si z vaut +∞+∞i, le résultat est π/4-∞i
  • Si z vaut ±∞+NaNi, le résultat est NaN±∞i (le signe de la partie imaginaire est non spécifié)
  • Si z vaut NaN+yi (pour tout y fini), le résultat est NaN+NaNi et FE_INVALID peut être levé
  • Si z vaut NaN+∞i, le résultat est NaN-∞i
  • Si z vaut NaN+NaNi, le résultat est NaN+NaNi

Notes

L'arc cosinus (ou cosinus inverse) est une fonction multivaluée et nécessite une coupure de branche dans le plan complexe. La coupure de branche est classiquement placée sur les segments (-∞,-1) et (1,∞) de l'axe réel.

La définition mathématique de la valeur principale de l'arc cosinus est acos z =
1
2

π + iln(iz + √1-z2
)

Pour tout z, acos(z) = π - acos(-z)

Exemple

#include <stdio.h>
#include <math.h>
#include <complex.h>

int main(void)
{
    double complex z = cacos(-2);
    printf("cacos(-2+0i) = %f%+fi\n", creal(z), cimag(z));

    double complex z2 = cacos(conj(-2)); // ou CMPLX(-2, -0.0)
    printf("cacos(-2-0i) (the other side of the cut) = %f%+fi\n", creal(z2), cimag(z2));

    // pour tout z, acos(z) = pi - acos(-z)
    double pi = acos(-1);
    double complex z3 = ccos(pi-z2);
    printf("ccos(pi - cacos(-2-0i) = %f%+fi\n", creal(z3), cimag(z3));
}

Output:

cacos(-2+0i) = 3.141593-1.316958i
cacos(-2-0i) (the other side of the cut) = 3.141593+1.316958i
ccos(pi - cacos(-2-0i) = 2.000000+0.000000i
