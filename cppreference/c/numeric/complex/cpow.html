cpowf, cpow, cpowl

Défini dans l'en-tête <complex.h>

float complex       cpowf( float complex x, float complex y );  // (1) (depuis C99)

double complex      cpow( double complex x, double complex y );  // (2) (depuis C99)

long double complex cpowl( long double complex x, long double complex y );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define pow( x, y )  // (4) (depuis C99)

1-3) Calcule la fonction puissance complexe xy
, avec une coupure de branche pour le premier paramètre le long de l'axe réel négatif.

  1. Macro générique par type : si un argument a le type long double complex, cpowl est appelée ; si un argument a le type double complex, cpow est appelée ; si un argument a le type float complex, cpowf est appelée. Si les arguments sont réels ou entiers, la macro appelle la fonction réelle correspondante (powf, pow, powl). Si un argument est imaginaire, la version complexe correspondante est appelée.

Paramètres

  • x, y — argument complexe

Valeur de retour

Si aucune erreur ne se produit, la puissance complexe xy
est renvoyée.

Les erreurs et les cas particuliers sont traités comme si l'opération était implémentée par cexp(y*clog(x)), sauf que l'implémentation peut traiter les cas particuliers avec plus de soin.

Exemple

#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z = cpow(1.0+2.0*I, 2);
    printf("(1+2i)^2 = %.1f%+.1fi\n", creal(z), cimag(z));

    double complex z2 = cpow(-1, 0.5);
    printf("(-1+0i)^0.5 = %.1f%+.1fi\n", creal(z2), cimag(z2));

    double complex z3 = cpow(conj(-1), 0.5); // autre côté de la coupure
    printf("(-1-0i)^0.5 = %.1f%+.1fi\n", creal(z3), cimag(z3));

    double complex z4 = cpow(I, I); // i^i = exp(-pi/2)
    printf("i^i = %f%+fi\n", creal(z4), cimag(z4));
}

Output:

(1+2i)^2 = -3.0+4.0i
(-1+0i)^0.5 = 0.0+1.0i
(-1-0i)^0.5 = 0.0-1.0i
i^i = 0.207880+0.000000i
