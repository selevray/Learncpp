CMPLXF, CMPLX, CMPLXL

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <complex.h>

float complex       CMPLXF( float real, float imag );  // (depuis C11)

double complex      CMPLX( double real, double imag );  // (depuis C11)

long double complex CMPLXL( long double real, long double imag );  // (depuis C11)

Chacune de ces macros se développe en une expression dont la valeur est celle du type complexe spécifié, la partie réelle ayant la valeur de real (convertie vers le type d'argument spécifié) et la partie imaginaire ayant la valeur de imag (convertie vers le type d'argument spécifié)

Les expressions peuvent servir d'initialisateurs pour des objets à durée de stockage statique ou thread, à condition que les expressions real et imag le soient également.

Paramètres

  • real — la partie réelle du nombre complexe à renvoyer
  • imag — la partie imaginaire du nombre complexe à renvoyer

Valeur de retour

Un nombre complexe composé de real et imag comme parties réelle et imaginaire.

Notes

Ces macros sont implémentées comme si les types imaginaires étaient pris en charge (même si elles ne le sont pas et que _Imaginary_I est en fait non défini) et comme définies ainsi :

#define CMPLX(x, y) ((double complex)((double)(x) + _Imaginary_I * (double)(y)))
#define CMPLXF(x, y) ((float complex)((float)(x) + _Imaginary_I * (float)(y)))
#define CMPLXL(x, y) ((long double complex)((long double)(x) + \
                      _Imaginary_I * (long double)(y)))

Exemple

#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z = CMPLX(0.0, -0.0);
    printf("z = %.1f%+.1fi\n", creal(z), cimag(z));
}

Output:

z = 0.0-0.0i
