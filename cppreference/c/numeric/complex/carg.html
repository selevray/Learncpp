cargf, carg, cargl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <complex.h>

float       cargf( float complex z );  // (1) (depuis C99)

double      carg( double complex z );  // (2) (depuis C99)

long double cargl( long double complex z );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define carg( z )  // (4) (depuis C99)

1-3) Calcule l'argument (aussi appelé angle de phase) de z, avec une coupure de branche le long de l'axe réel négatif.

  1. Macro générique par type : si z est de type long double complex, long double imaginary ou long double, cargl est appelée. Si z est de type float complex, float imaginary ou float, cargf est appelée. Si z est de type double complex, double imaginary, double, ou tout type entier, carg est appelée.

Paramètres

  • z — argument complexe

Valeur de retour

Si aucune erreur ne se produit, renvoie l'angle de phase de z dans l'intervalle [−π; π].

Les erreurs et cas particuliers sont traités comme si la fonction était implémentée par atan2(cimag(z), creal(z))

Exemple

#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z1 = 1.0+0.0*I;
    printf("phase angle of %.1f%+.1fi is %f\n", creal(z1), cimag(z1), carg(z1));

    double complex z2 = 0.0+1.0*I;
    printf("phase angle of %.1f%+.1fi is %f\n", creal(z2), cimag(z2), carg(z2));

    double complex z3 = -1.0+0.0*I;
    printf("phase angle of %.1f%+.1fi is %f\n", creal(z3), cimag(z3), carg(z3));

    double complex z4 = conj(z3); // ou CMPLX(-1, -0.0)
    printf("phase angle of %.1f%+.1fi (the other side of the cut) is %f\n",
             creal(z4), cimag(z4), carg(z4));
}

Output:

phase angle of 1.0+0.0i is 0.000000
phase angle of 0.0+1.0i is 1.570796
phase angle of -1.0+0.0i is 3.141593
phase angle of -1.0-0.0i (the other side of the cut) is -3.141593
