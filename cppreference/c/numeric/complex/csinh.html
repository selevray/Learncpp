1-3) Calcule le sinus hyperbolique complexe de z.

  1. Macro générique par type : si z est de type long double complex, csinhl est appelée ; si z est de type double complex, csinh est appelée ; si z est de type float complex, csinhf est appelée. Si z est réel ou entier, la macro invoque la fonction réelle correspondante (sinhf, sinh, sinhl). Si z est imaginaire, la macro invoque la version réelle correspondante de la fonction sin, en implémentant la formule sinh(iy) = i sin(y), et le type de retour est imaginaire.

Paramètres

  • z — argument complexe

Valeur de retour

Si aucune erreur ne se produit, le sinus hyperbolique complexe de z est renvoyé

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées conformément à math_errhandling

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • csinh(conj(z)) == conj(csinh(z))
  • csinh(z) == -csinh(-z)
  • Si z vaut +0+0i, le résultat est +0+0i
  • Si z vaut +0+∞i, le résultat est ±0+NaNi (le signe de la partie réelle n'est pas spécifié) et FE_INVALID est levé
  • Si z vaut +0+NaNi, le résultat est ±0+NaNi
  • Si z vaut x+∞i (pour tout x fini positif), le résultat est NaN+NaNi et FE_INVALID est levée
  • Si z vaut x+NaNi (pour tout x fini positif), le résultat est NaN+NaNi et FE_INVALID peut être levée
  • Si z vaut +∞+0i, le résultat est +∞+0i
  • Si z vaut +∞+yi (pour tout y fini positif), le résultat est +∞cis(y)
  • Si z vaut +∞+∞i, le résultat est ±∞+NaNi (le signe de la partie réelle n'est pas spécifié) et FE_INVALID est levé
  • Si z vaut +∞+NaNi, le résultat est ±∞+NaNi (le signe de la partie réelle n'est pas spécifié)
  • Si z vaut NaN+0i, le résultat est NaN+0i
  • Si z vaut NaN+yi (pour tout y fini non nul), le résultat est NaN+NaNi et FE_INVALID peut être levé
  • Si z vaut NaN+NaNi, le résultat est NaN+NaNi

où cis(y) vaut cos(y) + i sin(y)

Notes

La définition mathématique du sinus hyperbolique est sinh z =
ez -e-z

Le sinus hyperbolique est une fonction entière dans le plan complexe et n'a aucune coupure de branche. Il est périodique par rapport à la composante imaginaire, de période 2πi

Exemple

#include <stdio.h>
#include <math.h>
#include <complex.h>

int main(void)
{
    double complex z = csinh(1);  // se comporte comme le sinh réel le long de la droite réelle
    printf("sinh(1+0i) = %f%+fi (sinh(1)=%f)\n", creal(z), cimag(z), sinh(1));

    double complex z2 = csinh(I); // se comporte comme le sinus le long de la droite imaginaire
    printf("sinh(0+1i) = %f%+fi ( sin(1)=%f)\n", creal(z2), cimag(z2), sin(1));
}
