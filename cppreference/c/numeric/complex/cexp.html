1-3) Calcule l'exponentielle complexe de base e de z.

  1. Macro générique par type : si z a le type long double complex, cexpl est appelée ; si z a le type double complex, cexp est appelée ; si z a le type float complex, cexpf est appelée. Si z est réel ou entier, la macro invoque la fonction réelle correspondante (expf, exp, expl). Si z est imaginaire, la version à argument complexe correspondante est appelée.

Paramètres

  • z — argument complexe

Valeur de retour

Si aucune erreur ne se produit, e élevé à la puissance z, (\small e^z)ez
est renvoyé.

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées conformément à math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • cexp(conj(z)) == conj(cexp(z))
  • Si z vaut ±0+0i, le résultat est 1+0i
  • Si z vaut x+∞i (pour tout x fini), le résultat est NaN+NaNi et FE_INVALID est levée.
  • Si z vaut x+NaNi (pour tout x fini), le résultat est NaN+NaNi et FE_INVALID peut être levée.
  • Si z vaut +∞+0i, le résultat est +∞+0i
  • Si z vaut -∞+yi (pour tout y fini), le résultat est +0cis(y)
  • Si z vaut +∞+yi (pour tout y fini non nul), le résultat est +∞cis(y)
  • Si z vaut -∞+∞i, le résultat est ±0±0i (les signes ne sont pas spécifiés)
  • Si z vaut +∞+∞i, le résultat est ±∞+NaNi et FE_INVALID est levée (le signe de la partie réelle n'est pas spécifié)
  • Si z vaut -∞+NaNi, le résultat est ±0±0i (les signes ne sont pas spécifiés)
  • Si z vaut +∞+NaNi, le résultat est ±∞+NaNi (le signe de la partie réelle n'est pas spécifié)
  • Si z vaut NaN+0i, le résultat est NaN+0i
  • Si z vaut NaN+yi (pour tout y non nul), le résultat est NaN+NaNi et FE_INVALID peut être levée
  • Si z vaut NaN+NaNi, le résultat est NaN+NaNi

où (\small{\rm cis}(y))cis(y) vaut (\small \cos(y)+{\rm i}\sin(y))cos(y) + i sin(y)

Notes

La fonction exponentielle complexe (\small e^z)ez
pour (\small z = x + {\rm i}y)z = x+iy vaut (\small e^x {\rm cis}(y))ex
cis(y), soit (\small e^x (\cos(y)+{\rm i}\sin(y)))ex
(cos(y) + i sin(y))

La fonction exponentielle est une fonction entière dans le plan complexe et n'a aucune coupure de branche.

Exemple

#include <stdio.h>
#include <math.h>
#include <complex.h>

int main(void)
{
    double PI = acos(-1);
    double complex z = cexp(I * PI); // Formule d'Euler
    printf("exp(i*pi) = %.1f%+.1fi\n", creal(z), cimag(z));

}

Output:

exp(i*pi) = -1.0+0.0i
