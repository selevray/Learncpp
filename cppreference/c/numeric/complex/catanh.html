#define atanh( z )  // (4) (depuis C99)

1-3) Calcule l'arc tangente hyperbolique complexe de z avec des coupures de branche situées en dehors de l'intervalle [−1; +1] le long de l'axe réel.

  1. Macro générique par type : si z a le type long double complex, catanhl est appelée ; si z a le type double complex, catanh est appelée ; si z a le type float complex, catanhf est appelée. Si z est réel ou entier, la macro invoque la fonction réelle correspondante (atanhf, atanh, atanhl). Si z est imaginaire, la macro invoque la version réelle correspondante de atan, en implémentant la formule atanh(iy) = i atan(y), et le type de retour est imaginaire.

Paramètres

  • z — argument complexe

Valeur de retour

Si aucune erreur ne se produit, l'arc tangente hyperbolique complexe de z est renvoyée, dans l'intervalle d'une demi-bande mathématiquement non bornée le long de l'axe réel et dans l'intervalle [−iπ/2; +iπ/2] le long de l'axe imaginaire.

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées conformément à math_errhandling

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • catanh(conj(z)) == conj(catanh(z))
  • catanh(-z) == -catanh(z)
  • Si z vaut +0+0i, le résultat est +0+0i
  • Si z vaut +0+NaNi, le résultat est +0+NaNi
  • Si z vaut +1+0i, le résultat est +∞+0i et FE_DIVBYZERO est levé
  • Si z vaut x+∞i (pour tout x fini positif), le résultat est +0+iπ/2
  • Si z vaut x+NaNi (pour tout x fini non nul), le résultat est NaN+NaNi et FE_INVALID peut être levé
  • Si z vaut +∞+yi (pour tout y fini positif), le résultat est +0+iπ/2
  • Si z vaut +∞+∞i, le résultat est +0+iπ/2
  • Si z vaut +∞+NaNi, le résultat est +0+NaNi
  • Si z vaut NaN+yi (pour tout y fini), le résultat est NaN+NaNi et FE_INVALID peut être levé
  • Si z vaut NaN+∞i, le résultat est ±0+iπ/2 (le signe de la partie réelle n'est pas spécifié)
  • Si z vaut NaN+NaNi, le résultat est NaN+NaNi

Notes

Bien que la norme C nomme cette fonction « arc tangente hyperbolique complexe », les fonctions inverses des fonctions hyperboliques sont les fonctions d'aire. Leur argument est l'aire d'un secteur hyperbolique, et non un arc. Le nom correct est « arc tangente hyperbolique inverse complexe » et, moins courant, « tangente hyperbolique d'aire complexe ».

La tangente hyperbolique inverse est une fonction multivaluée et nécessite une coupure de branche dans le plan complexe. La coupure de branche est conventionnellement placée sur les segments de droite (-∞,-1] et [+1,+∞) de l'axe réel.

La définition mathématique de la valeur principale de la tangente hyperbolique inverse est atanh z =
ln(1+z)-ln(z-1)
2

.Pour tout z, atanh(z) =
atan(iz)
i

Exemple

#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z = catanh(2);
    printf("catanh(+2+0i) = %f%+fi\n", creal(z), cimag(z));

    double complex z2 = catanh(conj(2)); // ou catanh(CMPLX(2, -0.0)) en C11
    printf("catanh(+2-0i) (the other side of the cut) = %f%+fi\n", creal(z2), cimag(z2));

    // pour tout z, atanh(z) = atan(iz)/i
    double complex z3 = catanh(1+2*I);
    printf("catanh(1+2i) = %f%+fi\n", creal(z3), cimag(z3));
    double complex z4 = catan((1+2*I)*I)/I;
    printf("catan(i * (1+2i))/i = %f%+fi\n", creal(z4), cimag(z4));
}

Output:

catanh(+2+0i) = 0.549306+1.570796i
catanh(+2-0i) (the other side of the cut) = 0.549306-1.570796i
catanh(1+2i) = 0.173287+1.178097i
catan(i * (1+2i))/i = 0.173287+1.178097i
