Défini dans l'en-tête <tgmath.h>

#define asinh( z )  // (4) (depuis C99)

1-3) Calcule l'arc sinus hyperbolique complexe de z, avec des coupures de branche à l'extérieur de l'intervalle [−i; +i] le long de l'axe imaginaire.

  1. Macro générique par type : si z est de type long double complex, casinhl est appelée ; si z est de type double complex, casinh est appelée ; si z est de type float complex, casinhf est appelée. Si z est réel ou entier, la macro invoque la fonction réelle correspondante (asinhf, asinh, asinhl). Si z est imaginaire, la macro invoque la version réelle correspondante de la fonction asin, en implémentant la formule asinh(iy) = i asin(y), et le type de retour est imaginaire.

Paramètres

  • z — argument complexe

Valeur de retour

Si aucune erreur ne se produit, l'arc sinus hyperbolique complexe de z est renvoyé, dans l'intervalle d'une bande mathématiquement non bornée le long de l'axe réel et dans l'intervalle [−iπ/2; +iπ/2] le long de l'axe imaginaire.

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées conformément à math_errhandling

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • casinh(conj(z)) == conj(casinh(z))
  • casinh(-z) == -casinh(z)
  • Si z vaut +0+0i, le résultat est +0+0i
  • Si z vaut x+∞i (pour tout x fini positif), le résultat est +∞+π/2
  • Si z vaut x+NaNi (pour tout x fini), le résultat est NaN+NaNi et FE_INVALID peut être levé
  • Si z vaut +∞+yi (pour tout y fini positif), le résultat est +∞+0i
  • Si z vaut +∞+∞i, le résultat est +∞+iπ/4
  • Si z vaut +∞+NaNi, le résultat est +∞+NaNi
  • Si z vaut NaN+0i, le résultat est NaN+0i
  • Si z vaut NaN+yi (pour tout y fini non nul), le résultat est NaN+NaNi et FE_INVALID peut être levé
  • Si z vaut NaN+∞i, le résultat est ±∞+NaNi (le signe de la partie réelle n'est pas spécifié)
  • Si z vaut NaN+NaNi, le résultat est NaN+NaNi

Notes

Bien que la norme C nomme cette fonction « arc sinus hyperbolique complexe », les fonctions inverses des fonctions hyperboliques sont les fonctions d'aire. Leur argument est l'aire d'un secteur hyperbolique, et non un arc. Le nom correct est « sinus hyperbolique inverse complexe », et, moins courant, « sinus hyperbolique d'aire complexe ».

Le sinus hyperbolique inverse est une fonction multivaluée et nécessite une coupure de branche dans le plan complexe. La coupure de branche est conventionnellement placée sur les segments de droite (-i∞,-i) et (i,i∞) de l'axe imaginaire.

Exemple

#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z = casinh(0+2*I);
    printf("casinh(+0+2i) = %f%+fi\n", creal(z), cimag(z));

    double complex z2 = casinh(-conj(2*I)); // ou casinh(CMPLX(-0.0, 2)) en C11
    printf("casinh(-0+2i) (the other side of the cut) = %f%+fi\n", creal(z2), cimag(z2));

    // pour tout z, asinh(z) = asin(iz)/i
    double complex z3 = casinh(1+2*I);
    printf("casinh(1+2i) = %f%+fi\n", creal(z3), cimag(z3));
    double complex z4 = casin((1+2*I)*I)/I;
    printf("casin(i * (1+2i))/i = %f%+fi\n", creal(z4), cimag(z4));
}

Output:

casinh(+0+2i) = 1.316958+1.570796i
casinh(-0+2i) (the other side of the cut) = -1.316958+1.570796i
casinh(1+2i) = 1.469352+1.063440i
casin(i * (1+2i))/i =  1.469352+1.063440i
