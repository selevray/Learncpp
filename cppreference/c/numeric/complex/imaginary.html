imaginary

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <complex.h>

#define imaginary _Imaginary  // (depuis C99)

Cette macro se développe en le mot-clé _Imaginary.

Il s'agit d'une macro pratique qui permet d'utiliser float imaginary, double imaginary et long double imaginary comme une autre manière d'écrire les trois types C imaginaires purs float _Imaginary, double _Imaginary et long double _Imaginary

Comme pour tout support des nombres purement imaginaires en C, cette macro n'est définie que si les nombres imaginaires sont pris en charge.

Un compilateur qui définit __STDC_IEC_559_COMPLEX__ n'est pas tenu de prendre en charge les nombres imaginaires. POSIX recommande de vérifier si la macro _Imaginary_I est définie pour identifier la prise en charge des nombres imaginaires.

(depuis C99) (jusqu'à C11)

Les nombres imaginaires sont pris en charge si __STDC_IEC_559_COMPLEX__ est défini.

(depuis C11)

Notes

Les programmes peuvent annuler la définition de la macro imaginary et éventuellement la redéfinir.

À ce jour, seul le compilateur C d'Oracle est connu pour avoir implémenté les types imaginaires.

Exemple

#include <stdio.h>
#include <complex.h>

int main(void)
{
    double imaginary i = -2.0*I; // imaginaire pur
    double f = 1.0; // réel pur
    double complex z = f + i; // nombre complexe
    printf("z = %.1f%+.1fi\n", creal(z), cimag(z));
}

Output:

z = 1.0-2.0i
