Défini dans l'en-tête <tgmath.h>

#define sin( z )  // (4) (depuis C99)

1-3) Calcule le sinus complexe de z.

  1. Macro générique par type : si z a le type long double complex, csinl est appelée ; si z a le type double complex, csin est appelée ; si z a le type float complex, csinf est appelée. Si z est réel ou entier, la macro invoque la fonction réelle correspondante (sinf, sin, sinl). Si z est imaginaire, la macro invoque la version réelle correspondante de la fonction sinh, en implémentant la formule sin(iy) = i ∙ sinh(y), et le type de retour de la macro est imaginaire.

Paramètres

  • z — argument complexe

Valeur de retour

Si aucune erreur ne se produit, le sinus complexe de z.

Les erreurs et cas particuliers sont traités comme si l'opération était implémentée par -I * csinh(I*z)

Notes

Le sinus est une fonction entière sur le plan complexe et n'a aucune coupure de branche.

La définition mathématique du sinus est sin z =
eiz -e-iz
2i

Exemple

#include <stdio.h>
#include <math.h>
#include <complex.h>

int main(void)
{
    double complex z = csin(1);  // se comporte comme le sinus réel le long de la droite réelle
    printf("sin(1+0i) = %f%+fi ( sin(1)=%f)\n", creal(z), cimag(z), sin(1));

    double complex z2 = csin(I); // se comporte comme sinh le long de la droite imaginaire
    printf("sin(0+1i) = %f%+fi (sinh(1)=%f)\n", creal(z2), cimag(z2), sinh(1));
}

Output:

sin(1+0i) = 0.841471+0.000000i ( sin(1)=0.841471)
sin(0+1i) = 0.000000+1.175201i (sinh(1)=1.175201)
