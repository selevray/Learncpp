csqrtf, csqrt, csqrtl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <complex.h>

float complex       csqrtf( float complex z );  // (1) (depuis C99)

double complex      csqrt( double complex z );  // (2) (depuis C99)

long double complex csqrtl( long double complex z );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define sqrt( z )  // (4) (depuis C99)

1-3) Calcule la racine carrée complexe de z avec une coupure de branche le long de l'axe réel négatif.

  1. Macro générique par type : si z a le type long double complex, csqrtl est appelée ; si z a le type double complex, csqrt est appelée ; si z a le type float complex, csqrtf est appelée. Si z est réel ou entier, la macro invoque la fonction réelle correspondante (sqrtf, sqrt, sqrtl). Si z est imaginaire, la version à nombre complexe correspondante est appelée.

Paramètres

  • z — argument complexe

Valeur de retour

Si aucune erreur ne se produit, renvoie la racine carrée de z, dans l'intervalle du demi-plan droit, y compris l'axe imaginaire ([0; +∞) le long de l'axe réel et (−∞; +∞) le long de l'axe imaginaire.)

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées conformément à math_errhandling

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • La fonction est continue au niveau de la coupure de branche en tenant compte du signe de la partie imaginaire
  • csqrt(conj(z)) == conj(csqrt(z))
  • Si z vaut ±0+0i, le résultat est +0+0i
  • Si z vaut x+∞i, le résultat est +∞+∞i même si x est NaN
  • Si z vaut x+NaNi, le résultat est NaN+NaNi (sauf si x vaut ±∞) et FE_INVALID peut être levée
  • Si z vaut -∞+yi, le résultat est +0+∞i pour y positif fini
  • Si z vaut +∞+yi, le résultat est +∞+0i) pour y positif fini
  • Si z vaut -∞+NaNi, le résultat est NaN±∞i (le signe de la partie imaginaire n'est pas spécifié)
  • Si z vaut +∞+NaNi, le résultat est +∞+NaNi
  • Si z vaut NaN+yi, le résultat est NaN+NaNi et FE_INVALID peut être levée
  • Si z vaut NaN+NaNi, le résultat est NaN+NaNi

Exemple

#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z1 = csqrt(-4);
    printf("Square root of -4 is %.1f%+.1fi\n", creal(z1), cimag(z1));

    double complex z2 = csqrt(conj(-4)); // ou, en C11, CMPLX(-4, -0.0)
    printf("Square root of -4-0i, the other side of the cut, is "
           "%.1f%+.1fi\n", creal(z2), cimag(z2));
}

Output:

Square root of -4 is 0.0+2.0i
Square root of -4-0i, the other side of the cut, is 0.0-2.0i
