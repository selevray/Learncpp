Défini dans l'en-tête <complex.h>

#define I /* unspecified */  // (depuis C99)

La macro I se développe en _Complex_I ou en _Imaginary_I. Si l'implémentation ne prend pas en charge les types imaginaires, la macro se développe toujours en _Complex_I.

Un programme peut annuler puis éventuellement redéfinir la macro I.

Notes

La macro ne s'appelle pas i, qui est le nom de l'unité imaginaire en mathématiques, car le nom i était déjà utilisé dans de nombreux programmes C, par exemple comme variable de compteur de boucle.

La macro I sert souvent à former des nombres complexes, avec des expressions telles que x + y*I. Si I est défini comme _Complex_I, alors une telle expression peut créer une valeur dont la composante imaginaire vaut +0.0 même lorsque y vaut -0.0, ce qui est important pour les fonctions de nombres complexes à coupures de branche. La macro CMPLX permet de construire un nombre complexe avec précision.

GCC fournit une extension non portable permettant de spécifier des constantes imaginaires avec le suffixe i sur les littéraux entiers : 1.0fi, 1.0i et 1.0li sont des unités imaginaires en GNU C. Une approche similaire fait partie du C++ standard depuis C++14 (1.0if, 1.0i et 1.0il sont les unités imaginaires en C++)

Exemple

#include <stdio.h>
#include <complex.h>

int main(void)
{
    printf("I = %.1f%+.1fi\n", creal(I), cimag(I));

    double complex z1 = I * I;     // carré de l'unité imaginaire
    printf("I * I = %.1f%+.1fi\n", creal(z1), cimag(z1));

    double complex z = 1.0 + 2.0*I; // manière habituelle de former un nombre complexe avant C11
    printf("z = %.1f%+.1fi\n", creal(z), cimag(z));
}

Output:

I = 0.0+1.0i
I * I = -1.0+0.0i
z = 1.0+2.0i
