Défini dans l'en-tête <tgmath.h>

#define tanh( z )  // (4) (depuis C99)

1-3) Calcule la tangente hyperbolique complexe de z.

  1. Macro générique par type : si z est de type long double complex, ctanhl est appelée ; si z est de type double complex, ctanh est appelée ; si z est de type float complex, ctanhf est appelée. Si z est réel ou entier, la macro invoque la fonction réelle correspondante (tanhf, tanh, tanhl). Si z est imaginaire, la macro invoque la version réelle correspondante de la fonction tan, en implémentant la formule tanh(iy) = i tan(y), et le type de retour est imaginaire.

Paramètres

  • z — argument complexe

Valeur de retour

Si aucune erreur ne se produit, la tangente hyperbolique complexe de z est renvoyée

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées conformément à math_errhandling

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • ctanh(conj(z)) == conj(ctanh(z))
  • ctanh(-z) == -ctanh(z)
  • Si z vaut +0+0i, le résultat est +0+0i
  • Si z vaut x+∞i (pour tout x fini[1]), le résultat est NaN+NaNi et FE_INVALID est levée
  • Si z vaut x+NaN (pour tout[2] x fini), le résultat est NaN+NaNi et FE_INVALID peut être levée
  • Si z vaut +∞+yi (pour tout y fini positif), le résultat est 1+0i
  • Si z vaut +∞+∞i, le résultat est 1±0i (le signe de la partie imaginaire est non spécifié)
  • Si z vaut +∞+NaNi, le résultat est 1±0i (le signe de la partie imaginaire est non spécifié)
  • Si z vaut NaN+0i, le résultat est NaN+0i
  • Si z vaut NaN+yi (pour tout y non nul), le résultat est NaN+NaNi et FE_INVALID peut être levée
  • Si z vaut NaN+NaNi, le résultat est NaN+NaNi
  1. ↑ selon DR471, ceci n'est valable que pour x non nul. Si z vaut 0+∞i, le résultat doit être 0+NaNi
  2. ↑ selon DR471, ceci n'est valable que pour x non nul. Si z vaut 0+NaNi, le résultat doit être 0+NaNi

Notes

La définition mathématique de la tangente hyperbolique est tanh z =
ez -e-z
ez +e-z

La tangente hyperbolique est une fonction analytique sur le plan complexe et n'a pas de coupures de branche. Elle est périodique par rapport à la composante imaginaire, de période πi, et possède des pôles d'ordre 1 le long de la droite imaginaire, aux coordonnées (0, π(1/2 + n)). Cependant, aucune représentation courante en virgule flottante ne peut représenter π/2 exactement, il n'existe donc aucune valeur de l'argument pour laquelle une erreur de pôle se produit.

Exemple

#include <stdio.h>
#include <math.h>
#include <complex.h>

int main(void)
{
    double complex z = ctanh(1);  // se comporte comme la tangente hyperbolique réelle le long de la droite réelle
    printf("tanh(1+0i) = %f%+fi (tanh(1)=%f)\n", creal(z), cimag(z), tanh(1));

    double complex z2 = ctanh(I); // se comporte comme la tangente le long de la droite imaginaire
    printf("tanh(0+1i) = %f%+fi ( tan(1)=%f)\n", creal(z2), cimag(z2), tan(1));
}

Output:

tanh(1+0i) = 0.761594+0.000000i (tanh(1)=0.761594)
tanh(0+1i) = 0.000000+1.557408i ( tan(1)=1.557408)
