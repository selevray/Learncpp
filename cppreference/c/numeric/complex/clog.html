clogf, clog, clogl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <complex.h>

float complex       clogf( float complex z );  // (1) (depuis C99)

double complex      clog( double complex z );  // (2) (depuis C99)

long double complex clogl( long double complex z );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define log( z )  // (4) (depuis C99)

1-3) Calcule le logarithme naturel complexe (de base e) de z avec une coupure de branche le long de l'axe réel négatif.

  1. Macro générique par type : si z a le type long double complex, clogl est appelée ; si z a le type double complex, clog est appelée ; si z a le type float complex, clogf est appelée. Si z est réel ou entier, la macro invoque la fonction réelle correspondante (logf, log, logl). Si z est imaginaire, la version à nombre complexe correspondante est appelée.

Paramètres

  • z — argument complexe

Valeur de retour

Si aucune erreur ne se produit, le logarithme naturel complexe de z est renvoyé, dans l'intervalle d'une bande de largeur [−iπ, +iπ] le long de l'axe imaginaire et mathématiquement non borné le long de l'axe réel.

Gestion des erreurs et valeurs spéciales

Les erreurs sont signalées conformément à math_errhandling

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE,

  • La fonction est continue au niveau de la coupure de branche en tenant compte du signe de la partie imaginaire
  • clog(conj(z)) == conj(clog(z))
  • Si z vaut -0+0i, le résultat est -∞+πi et FE_DIVBYZERO est levé
  • Si z vaut +0+0i, le résultat est -∞+0i et FE_DIVBYZERO est levé
  • Si z vaut x+∞i (pour tout x fini), le résultat est +∞+πi/2
  • Si z vaut x+NaNi (pour tout x fini), le résultat est NaN+NaNi et FE_INVALID peut être levé
  • Si z vaut -∞+yi (pour tout y fini positif), le résultat est +∞+πi
  • Si z vaut +∞+yi (pour tout y fini positif), le résultat est +∞+0i
  • Si z vaut -∞+∞i, le résultat est +∞+3πi/4
  • Si z vaut +∞+∞i, le résultat est +∞+πi/4
  • Si z vaut ±∞+NaNi, le résultat est +∞+NaNi
  • Si z vaut NaN+yi (pour tout y fini), le résultat est NaN+NaNi et FE_INVALID peut être levé
  • Si z vaut NaN+∞i, le résultat est +∞+NaNi
  • Si z vaut NaN+NaNi, le résultat est NaN+NaNi

Notes

Le logarithme naturel d'un nombre complexe z de composantes en coordonnées polaires (r,θ) vaut ln r + i(θ+2nπ), avec la valeur principale ln r + iθ

Exemple

#include <stdio.h>
#include <math.h>
#include <complex.h>

int main(void)
{
    double complex z = clog(I); // r = 1, θ = pi/2
    printf("2*log(i) = %.1f%+fi\n", creal(2*z), cimag(2*z));

    double complex z2 = clog(sqrt(2)/2 + sqrt(2)/2*I); // r = 1, θ = pi/4
    printf("4*log(sqrt(2)/2+sqrt(2)i/2) = %.1f%+fi\n", creal(4*z2), cimag(4*z2));

    double complex z3 = clog(-1); // r = 1, θ = pi
    printf("log(-1+0i) = %.1f%+fi\n", creal(z3), cimag(z3));

    double complex z4 = clog(conj(-1)); // ou clog(CMPLX(-1, -0.0)) en C11
    printf("log(-1-0i) (the other side of the cut) = %.1f%+fi\n", creal(z4), cimag(z4));
}

Output:

2*log(i) = 0.0+3.141593i
4*log(sqrt(2)/2+sqrt(2)i/2) = 0.0+3.141593i
log(-1+0i) = 0.0+3.141593i
log(-1-0i) (the other side of the cut) = 0.0-3.141593i
