Mathématiques génériques par type

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

L'en-tête <tgmath.h> inclut les en-têtes <math.h> et <complex.h> et définit plusieurs macros génériques par type qui déterminent quelle fonction réelle ou, le cas échéant, complexe appeler en fonction des types des arguments.

Pour chaque macro, les paramètres dont le type réel correspondant dans la fonction math.h sans suffixe est double sont appelés paramètres génériques (par exemple, les deux paramètres de pow sont des paramètres génériques, mais seul le premier paramètre de scalbn est un paramètre générique).

Lorsqu'une macro <tgmath.h> est utilisée, les types des arguments passés aux paramètres génériques déterminent la fonction sélectionnée par la macro, comme décrit ci-dessous. Si les types des arguments ne sont pas compatibles avec les types des paramètres de la fonction sélectionnée, le comportement est indéfini (par exemple, si un argument complexe est passé à une macro <tgmath.h> réservée aux réels : float complex fc; ceil(fc); ou double complex dc; double d; fmax(dc, d); sont des exemples de comportement indéfini).

Note : les macros génériques par type étaient implémentées de manière définie par l'implémentation en C99, mais le mot-clé C11 _Generic permet d'implémenter ces macros de manière portable.

Macros génériques par type complexe/réel

Pour toutes les fonctions ayant à la fois une version réelle et une version complexe, une macro générique par type XXX existe, qui appelle l'une des fonctions suivantes :

  • fonction réelle :

    • variante XXXf de float
    • variante XXX de double
    • variante XXXl de long double

  • fonction complexe :

    • variante cXXXf de float
    • variante cXXX de double
    • variante cXXXl de long double

Une exception à la règle ci-dessus est la macro fabs (voir le tableau ci-dessous).

La fonction à appeler est déterminée comme suit :

  • Si l'un des arguments des paramètres génériques est imaginaire, le comportement est spécifié individuellement sur la page de référence de chaque fonction (en particulier, sin, cos, tag, cosh, sinh, tanh, asin, atan, asinh et atanh appellent des fonctions réelles, les types de retour de sin, tan, sinh, tanh, asin, atan, asinh et atanh sont imaginaires, et les types de retour de cos et cosh sont réels).
  • Si l'un des arguments des paramètres génériques est complexe, alors la fonction complexe est appelée, sinon la fonction réelle est appelée.
  • Si l'un des arguments des paramètres génériques est long double, alors la variante long double est appelée. Sinon, si l'un des paramètres est double ou entier, alors la variante double est appelée. Sinon, la variante float est appelée.

Fonctions réelles uniquement

Pour toutes les fonctions qui n'ont pas d'équivalent complexe, à l'exception de modf, il existe une macro générique par type XXX, qui appelle l'une des variantes d'une fonction réelle :

  • variante XXXf de float
  • variante XXX de double
  • variante XXXl de long double

La fonction à appeler est déterminée comme suit :

  • Si l'un des arguments des paramètres génériques est long double, alors la variante long double est appelée. Sinon, si l'un des arguments des paramètres génériques est double, alors la variante double est appelée. Sinon, la variante float est appelée.

Fonctions complexes uniquement

Pour toutes les fonctions de nombres complexes qui n'ont pas d'équivalent réel, il existe une macro générique par type cXXX, qui appelle l'une des variantes d'une fonction complexe :

  • variante cXXXf de float complex
  • variante cXXX de double complex
  • variante cXXXl de long double complex

La fonction à appeler est déterminée comme suit :

  • Si l'un des arguments des paramètres génériques est réel, complexe ou imaginaire, alors la fonction complexe appropriée est appelée.

Macro générique par type | Variantes de la fonction complexe

float | double | long double

carg | cargf | carg | cargl

conj | conjf | conj | conjl

creal | crealf | creal | creall

cimag | cimagf | cimag | cimagl

cproj | cprojf | cproj | cprojl

Exemple

#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    int i = 2;
    printf("sqrt(2) = %f\n", sqrt(i)); // type d'argument int, appelle sqrt

    float f = 0.5;
    printf("sin(0.5f) = %f\n", sin(f));   // type d'argument float, appelle sinf

    float complex dc = 1 + 0.5*I;
    float complex z = sqrt(dc);      // type d'argument float complex, appelle csqrtf
    printf("sqrt(1 + 0.5i) = %f+%fi\n",
           creal(z),  // type d'argument float complex, appelle crealf
           cimag(z)); // type d'argument float complex, appelle cimagf
}

Output:

sqrt(2) = 1.414214
sin(0.5f) = 0.479426
sqrt(1 + 0.5i) = 1.029086+0.242934i
