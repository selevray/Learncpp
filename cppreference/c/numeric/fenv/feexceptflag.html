fegetexceptflag, fesetexceptflag

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <fenv.h>

int fegetexceptflag( fexcept_t* flagp, int excepts );  // (1) (depuis C99)

int fesetexceptflag( const fexcept_t* flagp, int excepts );  // (2) (depuis C99)

  1. Tente d'obtenir le contenu complet des indicateurs d'exception de virgule flottante listés dans l'argument masque de bits excepts, qui est un OU bit à bit des macros d'exceptions de virgule flottante.

  2. Tente de copier le contenu complet des indicateurs d'exception à virgule flottante listés dans excepts depuis flagp vers l'environnement à virgule flottante. Ne lève aucune exception, modifie uniquement les indicateurs.

Le contenu complet d'un indicateur d'exception à virgule flottante n'est pas nécessairement une valeur booléenne indiquant si l'exception est levée ou effacée. Par exemple, il peut s'agir d'une struct qui contient l'état booléen et l'adresse du code ayant déclenché l'exception. Ces fonctions obtiennent l'ensemble de ce contenu et le lisent ou l'écrivent dans flagp dans un format défini par l'implémentation.

Paramètres

  • flagp — pointeur vers un objet fexcept_t où les indicateurs seront stockés ou lus
  • excepts — masque de bits listant les indicateurs d'exception à lire ou à définir

Valeur de retour

0 en cas de succès, valeur non nulle sinon.

Exemple

#include <stdio.h>
#include <fenv.h>

#pragma STDC FENV_ACCESS ON

void show_fe_exceptions(void)
{
    printf("current exceptions raised: ");
    if(fetestexcept(FE_DIVBYZERO))     printf(" FE_DIVBYZERO");
    if(fetestexcept(FE_INEXACT))       printf(" FE_INEXACT");
    if(fetestexcept(FE_INVALID))       printf(" FE_INVALID");
    if(fetestexcept(FE_OVERFLOW))      printf(" FE_OVERFLOW");
    if(fetestexcept(FE_UNDERFLOW))     printf(" FE_UNDERFLOW");
    if(fetestexcept(FE_ALL_EXCEPT)==0) printf(" none");
    printf("\n");
}

int main(void)
{
    fexcept_t excepts;

    /* Met en place un ensemble « courant » d'indicateurs d'exception. */
    feraiseexcept(FE_INVALID);
    show_fe_exceptions();

    /* Sauvegarde les indicateurs d'exception courants. */
    fegetexceptflag(&excepts,FE_ALL_EXCEPT);

    /* Lève temporairement deux autres exceptions. */
    feclearexcept(FE_ALL_EXCEPT);
    feraiseexcept(FE_OVERFLOW | FE_INEXACT);
    show_fe_exceptions();

    /* Restaure les indicateurs d'exception précédents. */
    fesetexceptflag(&excepts,FE_ALL_EXCEPT);
    show_fe_exceptions();

    return 0;
}

Output:

current exceptions raised: FE_INVALID
current exceptions raised: FE_INEXACT FE_OVERFLOW
current exceptions raised: FE_INVALID
