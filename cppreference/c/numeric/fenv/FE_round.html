FE_DOWNWARD, FE_TONEAREST, FE_TOWARDZERO, FE_UPWARD

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <fenv.h>

#define FE_DOWNWARD     /*implementation defined*/  // (depuis C99)

#define FE_TONEAREST    /*implementation defined*/  // (depuis C99)

#define FE_TOWARDZERO   /*implementation defined*/  // (depuis C99)

#define FE_UPWARD       /*implementation defined*/  // (depuis C99)

Chacune de ces constantes macro se développe en une expression constante entière non négative, utilisable avec fesetround et fegetround pour indiquer l'un des modes d'arrondi à virgule flottante pris en charge. L'implémentation peut définir des constantes de mode d'arrondi supplémentaires dans <fenv.h>, qui doivent toutes commencer par FE_ suivi d'au moins une lettre majuscule. Chaque macro n'est définie que si elle est prise en charge.

Constante Explication

  • FE_DOWNWARD — arrondi vers moins l'infini
  • FE_TONEAREST — arrondi vers la valeur représentable la plus proche
  • FE_TOWARDZERO — arrondi vers zéro
  • FE_UPWARD — arrondi vers plus l'infini

D'autres modes d'arrondi peuvent être pris en charge par une implémentation.

Le mode d'arrondi courant affecte les éléments suivants :

  • résultats des opérateurs arithmétiques à virgule flottante en dehors des expressions constantes
double x = 1;
x / 10; // 0.09999999999999999167332731531132594682276248931884765625 or
        // 0.1000000000000000055511151231257827021181583404541015625
  • résultats des fonctions mathématiques de la bibliothèque standard
sqrt(2); // 1.41421356237309492343001693370752036571502685546875 or
         // 1.4142135623730951454746218587388284504413604736328125
  • conversions implicites et transtypages de virgule flottante vers virgule flottante
double d = 1 + DBL_EPSILON;
float f = d; // 1.00000000000000000000000 or
             // 1.00000011920928955078125
  • conversions de chaînes telles que strtod ou printf
strtof("0.1", NULL); // 0.0999999940395355224609375 or
                     // 0.100000001490116119384765625
  • les fonctions d'arrondi de la bibliothèque nearbyint, rint, lrint
lrint(2.1); // 2 or 3

Le mode d'arrondi courant n'affecte PAS les éléments suivants :

  • conversion implicite et transtypages de virgule flottante vers entier (toujours vers zéro)
  • résultats des opérateurs arithmétiques à virgule flottante dans les expressions constantes exécutées à la compilation (toujours vers le plus proche)
  • les fonctions de la bibliothèque round, lround, llround, ceil, floor, trunc

Comme pour toute fonctionnalité d'environnement à virgule flottante, l'arrondi n'est garanti que si #pragma STDC FENV_ACCESS ON est positionné.

Les compilateurs qui ne prennent pas en charge le pragma peuvent proposer leurs propres moyens de prendre en charge le mode d'arrondi courant. Par exemple, Clang et GCC disposent de l'option -frounding-math, destinée à désactiver les optimisations qui modifieraient la signification du code sensible à l'arrondi.

Exemple

#include <fenv.h>
#include <math.h>
#include <stdio.h>
#include <stdlib.h>

// #pragma STDC FENV_ACCESS ON

int main()
{
    fesetround(FE_DOWNWARD);
    puts("rounding down: ");
    printf("           pi = %.22f\n", acosf(-1));
    printf("strtof(\"1.1\") = %.22f\n", strtof("1.1", NULL));
    printf("    rint(2.1) = %.22f\n\n", rintf(2.1));
    fesetround(FE_UPWARD);
    puts("rounding up: ");
    printf("           pi = %.22f\n", acosf(-1));
    printf("strtof(\"1.1\") = %.22f\n", strtof("1.1", NULL));
    printf("    rint(2.1) = %.22f\n", rintf(2.1));
}

Output:

rounding down:
           pi = 3.1415925025939941406250
strtof("1.1") = 1.0999999046325683593750
    rint(2.1) = 2.0000000000000000000000

rounding up:
           pi = 3.1415927410125732421875
strtof("1.1") = 1.1000000238418579101563
    rint(2.1) = 3.0000000000000000000000
