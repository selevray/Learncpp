feraiseexcept

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <fenv.h>

int feraiseexcept( int excepts );  // (depuis C99)

Tente de lever toutes les exceptions de virgule flottante listées dans excepts (un OU bit à bit des macros d'exceptions de virgule flottante). Si l'une des exceptions est FE_OVERFLOW ou FE_UNDERFLOW, cette fonction peut en plus lever FE_INEXACT. L'ordre dans lequel les exceptions sont levées n'est pas spécifié, sauf que FE_OVERFLOW et FE_UNDERFLOW sont toujours levées avant FE_INEXACT.

Paramètres

  • excepts — masque de bits listant les indicateurs d'exception à lever

Valeur de retour

0 si toutes les exceptions listées ont été levées, valeur non nulle sinon.

Exemple

#include <stdio.h>
#include <fenv.h>

#pragma STDC FENV_ACCESS ON

void show_fe_exceptions(void)
{
    printf("current exceptions raised: ");
    if(fetestexcept(FE_DIVBYZERO))     printf(" FE_DIVBYZERO");
    if(fetestexcept(FE_INEXACT))       printf(" FE_INEXACT");
    if(fetestexcept(FE_INVALID))       printf(" FE_INVALID");
    if(fetestexcept(FE_OVERFLOW))      printf(" FE_OVERFLOW");
    if(fetestexcept(FE_UNDERFLOW))     printf(" FE_UNDERFLOW");
    if(fetestexcept(FE_ALL_EXCEPT)==0) printf(" none");
    feclearexcept(FE_ALL_EXCEPT);
    printf("\n");
}

double some_computation(void)
{
    /* Le calcul atteint un état qui provoque un dépassement. */
    int r = feraiseexcept(FE_OVERFLOW | FE_INEXACT);
    printf("feraiseexcept() %s\n", (r?"fails":"succeeds"));
    return 0.0;
}

int main(void)
{
    some_computation();
    show_fe_exceptions();

    return 0;
}

Output:

feraiseexcept() succeeds
current exceptions raised:  FE_INEXACT FE_OVERFLOW
