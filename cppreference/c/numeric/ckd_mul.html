#define ckd_mul( result, a, b ) /* implementation-defined */
// interface exposée :
bool ckd_mul( type1* result, type2 a, type3 b );  // (depuis C23)

Calcule la multiplication x × y et stocke le résultat dans *result. La multiplication est effectuée comme si les deux opérandes étaient représentés dans un type entier signé de portée infinie, puis le résultat est converti de ce type entier vers type1. Si la valeur affectée à *result représente correctement le résultat mathématique de l'opération, elle renvoie false. Sinon, elle renvoie true. Dans ce cas, la valeur affectée à *result est le résultat mathématique de l'opération tronqué à la largeur de *result.

Paramètres

  • a, b — valeurs entières
  • result — adresse à laquelle le résultat doit être stocké

Valeur de retour

false si la valeur affectée à *result représente correctement le résultat mathématique de la multiplication, true sinon.

Note

Les deux type2 et type3 doivent être des types entiers quelconques autres que « simple » char, bool, un type entier de précision binaire, ou un type énuméré, et ils peuvent être identiques. *result doit être une lvalue modifiable de type entier quelconque autre que « simple » char, bool, un type entier de précision binaire, ou un type énuméré.

Il est recommandé de produire un message de diagnostic si type2 ou type3 ne sont pas des types entiers adaptés, ou si *result n'est pas une lvalue modifiable d'un type entier adapté.
