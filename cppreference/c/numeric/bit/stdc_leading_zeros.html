generic_return_type stdc_leading_zeros( generic_value_type value ) [[unsequenced]];  // (6) (depuis C23)

1-5) Renvoie le nombre de bits 0 consécutifs dans value, en commençant par le bit de poids fort.

  1. La fonction générique par type (identifiée par son argument generic_value_type) renvoie la valeur appropriée selon le type de la valeur d'entrée, tant qu'il s'agit d'un :
  • type entier non signé standard, à l'exclusion de bool ;
  • type entier non signé étendu ;
  • ou type entier non signé de précision binaire dont la largeur correspond à un type entier standard ou étendu, à l'exclusion de bool.

Le generic_return_type doit être un type entier non signé suffisamment grand pour représenter le résultat calculé.

Paramètres

  • value — valeur de type entier non signé

Valeur de retour

Le nombre de bits 0 consécutifs dans la value, à partir du bit de poids fort.

Exemple

#include <limits.h>
#include <stdbit.h>
#include <stdint.h>
#include <stdio.h>

#define bits_num(value) (sizeof(value) * CHAR_BIT)

#define bin_impl(T, suffix) \
const char* bin_##suffix(T x) \
{ \
    static char buf[bits_num(x) * CHAR_BIT + 1]; \
    for (T i = 0, mask = ((T)1 << (bits_num(x) - 1)); mask; mask >>= 1) \
        buf[i++] = x & mask ? '1' : '0'; \
    buf[bits_num(x)] = '\0'; \
    return buf; \
}

bin_impl(uint8_t, u8)
bin_impl(uint16_t, u16)
bin_impl(uint32_t, u32)
bin_impl(uint64_t, u64)

#define bin(x) _Generic((x), \
    uint8_t: bin_u8, uint16_t: bin_u16, uint32_t: bin_u32, default: bin_u64)(x)

int main()
{
    puts("uint8_t:");
    for (uint8_t x = 0b11000000; ; x >>= 1)
    {
        printf("x = [%s], leading zeros: %d\n", bin(x), stdc_leading_zeros(x));
        if (!x)
            break;
    }

    puts("uint16_t:");
    for (uint16_t x = 0b11000000; ; x >>= 1)
    {
        printf("x = [%s], leading zeros: %d\n", bin(x), stdc_leading_zeros(x));
        if (!x)
            break;
    }
}
