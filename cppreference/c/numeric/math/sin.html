sin, sinf, sinl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       sinf( float arg );  // (1) (depuis C99)

double      sin( double arg );  // (2)

long double sinl( long double arg );  // (3) (depuis C99)

_Decimal32  sind32( _Decimal32 arg );  // (4) (depuis C23)

_Decimal64  sind64( _Decimal64 arg );  // (5) (depuis C23)

_Decimal128 sind128( _Decimal128 arg );  // (6) (depuis C23)

Défini dans l'en-tête <tgmath.h>

#define sin( arg )  // (7) (depuis C99)

1-3) Calcule le sinus de arg (exprimé en radians).

  1. Macro générique par type : si l'argument a le type long double, (3) (sinl) est appelée. Sinon, si l'argument a un type entier ou le type double, (2) (sin) est appelée. Sinon, (1) (sinf) est appelée. Si l'argument est complexe, la macro appelle la fonction complexe correspondante (csinl, csin, csinf).

Les fonctions (4-6) sont déclarées si et seulement si l'implémentation prédéfinit __STDC_IEC_60559_DFP__ (c'est-à-dire si l'implémentation prend en charge les nombres à virgule flottante décimaux).

(depuis C23)

Paramètres

  • arg — valeur à virgule flottante représentant un angle en radians

Valeur de retour

Si aucune erreur ne survient, le sinus de arg (sin(arg)) dans l'intervalle [-1 ; +1] est renvoyé.

Le résultat peut avoir peu ou pas de signification si la valeur absolue de arg est grande.

(jusqu'à C99)

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559) :

  • si l'argument vaut ±0, il est renvoyé sans modification ;
  • si l'argument vaut ±∞, NaN est renvoyé et FE_INVALID est levée ;
  • si l'argument est NaN, NaN est renvoyé.

Notes

Le cas où l'argument est infini n'est pas spécifié comme erreur de domaine en C, mais il est défini comme une erreur de domaine en POSIX.

POSIX précise également qu'en cas de sous-dépassement, arg est renvoyé sans modification, et si cela n'est pas pris en charge, une valeur définie par l'implémentation non supérieure à DBL_MIN, FLT_MIN et LDBL_MIN est renvoyée.

Exemple

#include <errno.h>
#include <fenv.h>
#include <math.h>
#include <stdio.h>

#ifndef __GNUC__
#pragma STDC FENV_ACCESS ON
#endif

int main(void)
{
    const double pi = acos(-1);

    // utilisation typique
    printf("sin(pi/6) = %f\n", sin(pi / 6));
    printf("sin(pi/2) = %f\n", sin(pi / 2));
    printf("sin(-3*pi/4) = %f\n", sin(-3 * pi / 4));

    // valeurs spéciales
    printf("sin(+0) = %f\n", sin(0.0));
    printf("sin(-0) = %f\n", sin(-0.0));

    // gestion des erreurs
    feclearexcept(FE_ALL_EXCEPT);
    printf("sin(INFINITY) = %f\n", sin(INFINITY));
    if (fetestexcept(FE_INVALID))
        puts("    FE_INVALID raised");
}

Sortie possible :

sin(pi/6) = 0.500000
sin(pi/2) = 1.000000
sin(-3*pi/4) = -0.707107
sin(+0) = 0.000000
sin(-0) = -0.000000
sin(INFINITY) = -nan
    FE_INVALID raised
