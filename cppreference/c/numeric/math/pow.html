pow, powf, powl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float powf( float base, float exponent );  // (1) (depuis C99)

double pow( double base, double exponent );  // (2)

long double powl( long double base, long double exponent );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define pow( base, exponent )  // (4) (depuis C99)

1-3) Calcule la valeur de base élevé à la puissance exponent.

  1. Macro générique par type : si un argument a le type long double, powl est appelée. Sinon, si un argument a un type entier ou le type double, pow est appelée. Sinon, powf est appelée. Si au moins un argument est complexe ou imaginaire, la macro appelle la fonction complexe correspondante (cpowf, cpow, cpowl).

Paramètres

  • base — base sous forme de valeur flottante
  • exponent — exposant sous forme de valeur flottante

Valeur de retour

Si aucune erreur ne se produit, base élevé à la puissance de exponent (baseexponent
) est renvoyé.

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

En cas d'erreur de pôle ou d'erreur de portée due à un dépassement de capacité, ±HUGE_VAL, ±HUGE_VALF ou ±HUGE_VALL est retourné.

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si base est fini et négatif et que exponent est fini et non entier, une erreur de domaine se produit et une erreur de portée peut se produire.

Si base est nul et que exponent est nul, une erreur de domaine peut se produire.

Si base est nul et que exponent est négatif, une erreur de domaine ou une erreur de pôle peut se produire.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • pow(+0, exponent), où exponent est un entier impair négatif, renvoie +∞ et lève FE_DIVBYZERO
  • pow(-0, exponent), où exponent est un entier impair négatif, renvoie -∞ et lève FE_DIVBYZERO
  • pow(±0, exponent), où exponent est négatif, fini, et est un entier pair ou un non-entier, renvoie +∞ et lève FE_DIVBYZERO
  • pow(±0, -∞) renvoie +∞ et peut lever FE_DIVBYZERO (jusqu'à C23)
  • pow(+0, exponent), où exponent est un entier impair positif, renvoie +0
  • pow(-0, exponent), où exponent est un entier impair positif, renvoie -0
  • pow(±0, exponent), où exponent est un non-entier positif ou un entier pair positif, renvoie +0
  • pow(-1, ±∞) renvoie 1
  • pow(+1, exponent) renvoie 1 pour tout exponent, même lorsque exponent vaut NaN
  • pow(base, ±0) renvoie 1 pour tout base, même lorsque base vaut NaN
  • pow(base, exponent) renvoie NaN et lève FE_INVALID si base est fini et négatif et que exponent est fini et non entier.
  • pow(base, -∞) renvoie +∞ pour tout |base|<1
  • pow(base, -∞) renvoie +0 pour tout |base|>1
  • pow(base, +∞) renvoie +0 pour tout |base|<1
  • pow(base, +∞) renvoie +∞ pour tout |base|>1
  • pow(-∞, exponent) renvoie -0 si exponent est un entier impair négatif
  • pow(-∞, exponent) renvoie +0 si exponent est un non-entier négatif ou un entier pair négatif
  • pow(-∞, exponent) renvoie -∞ si exponent est un entier impair positif
  • pow(-∞, exponent) renvoie +∞ si exponent est un non-entier positif ou un entier pair positif
  • pow(+∞, exponent) renvoie +0 pour tout exponent négatif
  • pow(+∞, exponent) renvoie +∞ pour tout exponent positif
  • sauf indication contraire ci-dessus, si un argument est NaN, NaN est retourné.

Notes

Bien que pow ne puisse pas être utilisée pour obtenir une racine d'un nombre négatif, cbrt est fournie pour le cas courant où exponent vaut 1 / 3.

Exemple

#include <errno.h>
#include <fenv.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON

int main(void)
{
    // utilisation typique
    printf("pow(2, 10) = %f\n", pow(2, 10));
    printf("pow(2, 0.5) = %f\n", pow(2, 0.5));
    printf("pow(-2, -3) = %f\n", pow(-2, -3));

    // valeurs spéciales
    printf("pow(-1, NAN) = %f\n", pow(-1, NAN));
    printf("pow(+1, NAN) = %f\n", pow(+1, NAN));
    printf("pow(INFINITY, 2) = %f\n", pow(INFINITY, 2));
    printf("pow(INFINITY, -1) = %f\n", pow(INFINITY, -1));

    // gestion des erreurs
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("pow(-1, 1/3) = %f\n", pow(-1, 1.0 / 3));
    if (errno == EDOM)
        perror("    errno == EDOM");
    if (fetestexcept(FE_INVALID))
        puts("    FE_INVALID raised");

    feclearexcept(FE_ALL_EXCEPT);
    printf("pow(-0, -3) = %f\n", pow(-0.0, -3));
    if (fetestexcept(FE_DIVBYZERO))
        puts("    FE_DIVBYZERO raised");
}
