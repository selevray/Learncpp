remainder, remainderf, remainderl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       remainderf( float x, float y );  // (1) (depuis C99)

double      remainder( double x, double y );  // (2) (depuis C99)

long double remainderl( long double x, long double y );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define remainder( x, y )  // (4) (depuis C99)

1-3) Calcule le reste IEEE de l'opération de division flottante x/y.

  1. Macro générique au type : si un argument est de type long double, remainderl est appelée. Sinon, si un argument est de type entier ou de type double, remainder est appelée. Sinon, remainderf est appelée.

Le reste IEEE en virgule flottante de l'opération de division x/y calculé par cette fonction vaut exactement x - n * y, où la valeur n est la valeur entière la plus proche de la valeur exacte x/y. Lorsque |n-x/y| = ½, la valeur n est choisie paire.

Contrairement à fmod(), la valeur retournée n'est pas garantie d'avoir le même signe que x.

Si la valeur renvoyée est 0, elle aura le même signe que x.

Paramètres

  • x, y — valeurs à virgule flottante

Valeur de retour

En cas de succès, retourne le reste IEEE en virgule flottante de la division x/y tel que défini ci-dessus.

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur d'intervalle se produit due à un dépassement inférieur, le résultat correct est renvoyé.

Si y est nul, mais que l'erreur de domaine ne se produit pas, zéro est retourné.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Une erreur de domaine peut se produire si y vaut zéro.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Le mode d'arrondi courant n'a aucun effet.
  • FE_INEXACT n'est jamais levée, le résultat est toujours exact.
  • Si x vaut ±∞ et y n'est pas NaN, NaN est renvoyé et FE_INVALID est levé.
  • Si y vaut ±0 et x n'est pas NaN, NaN est renvoyé et FE_INVALID est levé.
  • Si l'un des arguments est NaN, NaN est renvoyé.

Notes

POSIX exige qu'une erreur de domaine se produise si x est infini ou si y vaut zéro.

fmod, mais pas remainder, est utile pour effectuer un enveloppement silencieux de types à virgule flottante vers des types entiers non signés : (0.0 <= (y = fmod(rint(x), 65536.0)) ? y : 65536.0 + y) est dans l'intervalle [-0.0,65535.0], ce qui correspond à unsigned short, mais remainder(rint(x), 65536.0) est dans l'intervalle [-32767.0,+32768.0], qui est en dehors de l'intervalle de signed short.

Exemple

#include <fenv.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON

int main(void)
{
    printf("remainder(+5.1, +3.0) = %.1f\n", remainder(5.1, 3));
    printf("remainder(-5.1, +3.0) = %.1f\n", remainder(-5.1, 3));
    printf("remainder(+5.1, -3.0) = %.1f\n", remainder(5.1, -3));
    printf("remainder(-5.1, -3.0) = %.1f\n", remainder(-5.1, -3));

    // valeurs spéciales
    printf("remainder(-0.0, 1.0) = %.1f\n", remainder(-0.0, 1));
    printf("remainder(+5.1, Inf) = %.1f\n", remainder(5.1, INFINITY));

    // gestion des erreurs
    feclearexcept(FE_ALL_EXCEPT);
    printf("remainder(+5.1, 0) = %.1f\n", remainder(5.1, 0));
    if (fetestexcept(FE_INVALID))
        puts("    FE_INVALID raised");
}

Output:

remainder(+5.1, +3.0) = -0.9
remainder(-5.1, +3.0) = 0.9
remainder(+5.1, -3.0) = -0.9
remainder(-5.1, -3.0) = 0.9
remainder(+0.0, 1.0) = 0.0
remainder(-0.0, 1.0) = -0.0
remainder(+5.1, Inf) = 5.1
remainder(+5.1, 0) = -nan
    FE_INVALID raised
