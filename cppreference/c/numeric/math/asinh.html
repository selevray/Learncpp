asinh, asinhf, asinhl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       asinhf( float arg );  // (1) (depuis C99)

double      asinh( double arg );  // (2) (depuis C99)

long double asinhl( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define asinh( arg )  // (4) (depuis C99)

1-3) Calcule le sinus hyperbolique inverse de arg.

  1. Macro générique par type : si l'argument a le type long double, asinhl est appelée. Sinon, si l'argument a un type entier ou le type double, asinh est appelée. Sinon, asinhf est appelée. Si l'argument est complexe, la macro appelle la fonction complexe correspondante (casinhf, casinh, casinhl).

Paramètres

  • arg — valeur à virgule flottante représentant l'aire d'un secteur hyperbolique

Valeur de retour

Si aucune erreur ne se produit, le sinus hyperbolique inverse de arg (sinh-1
(arg), ou arsinh(arg)), est retourné.

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si l'argument vaut ±0 ou ±∞, il est renvoyé sans modification.
  • Si l'argument est NaN, NaN est retourné.

Notes

Bien que la norme C nomme cette fonction « arc hyperbolic sine », les fonctions inverses des fonctions hyperboliques sont les fonctions d'aire. Leur argument est l'aire d'un secteur hyperbolique, et non un arc. Le nom correct est « sinus hyperbolique inverse » (utilisé par POSIX) ou « sinus hyperbolique d'aire ».

Exemple

#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("asinh(1) = %f\nasinh(-1) = %f\n", asinh(1), asinh(-1));
    // valeurs spéciales
    printf("asinh(+0) = %f\nasinh(-0) = %f\n", asinh(0.0), asinh(-0.0));
}

Output:

asinh(1) = 0.881374
asinh(-1) = -0.881374
asinh(+0) = 0.000000
asinh(-0) = -0.000000
