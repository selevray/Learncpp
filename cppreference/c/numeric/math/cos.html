cos, cosf, cosl

Défini dans l'en-tête <math.h>

float       cosf( float arg );  // (1) (depuis C99)

double      cos( double arg );  // (2)

long double cosl( long double arg );  // (3) (depuis C99)

_Decimal32  cosd32( _Decimal32 arg );  // (4) (depuis C23)

_Decimal64  cosd64( _Decimal64 arg );  // (5) (depuis C23)

_Decimal128 cosd128( _Decimal128 arg );  // (6) (depuis C23)

Défini dans l'en-tête <tgmath.h>

#define cos( arg )  // (7) (depuis C99)

1-6) Calcule le cosinus de arg (exprimé en radians).

  1. Macro générique par type : si l'argument a le type long double, (3) (cosl) est appelée. Sinon, si l'argument a un type entier ou le type double, (2) (cos) est appelée. Sinon, (1) (cosf) est appelée. Si l'argument est complexe, la macro appelle la fonction complexe correspondante (ccosf, ccos, ccosl).

Les fonctions (4-6) sont déclarées si et seulement si l'implémentation prédéfinit __STDC_IEC_60559_DFP__ (c'est-à-dire si l'implémentation prend en charge les nombres à virgule flottante décimaux).

(depuis C23)

Paramètres

  • arg — valeur à virgule flottante représentant un angle en radians

Valeur de retour

Si aucune erreur ne se produit, le cosinus de arg (cos(arg)) dans l'intervalle [-1 ; +1] est renvoyé.

Le résultat peut avoir peu ou pas de signification si la valeur absolue de arg est grande.

(jusqu'à C99)

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559) :

  • si l'argument vaut ±0, le résultat est 1.0 ;
  • si l'argument vaut ±∞, NaN est renvoyé et FE_INVALID est levée ;
  • si l'argument est NaN, NaN est renvoyé.

Notes

Le cas où l'argument est infini n'est pas spécifié comme erreur de domaine en C, mais il est défini comme une erreur de domaine en POSIX.

Exemple

#include <errno.h>
#include <fenv.h>
#include <math.h>
#include <stdio.h>

#ifndef __GNUC__
#pragma STDC FENV_ACCESS ON
#endif

int main(void)
{
    const double pi = acos(-1);

    // utilisation typique
    printf("cos(pi/3) = %f\n", cos(pi / 3));
    printf("cos(pi/2) = %f\n", cos(pi / 2));
    printf("cos(-3*pi/4) = %f\n", cos(-3 * pi / 4));

    // valeurs spéciales
    printf("cos(+0) = %f\n", cos(0.0));
    printf("cos(-0) = %f\n", cos(-0.0));

    // gestion des erreurs
    feclearexcept(FE_ALL_EXCEPT);
    printf("cos(INFINITY) = %f\n", cos(INFINITY));
    if (fetestexcept(FE_INVALID))
        puts("    FE_INVALID raised");
}

Sortie possible :

cos(pi/3) = 0.500000
cos(pi/2) = 0.000000
cos(-3*pi/4) = -0.707107
cos(+0) = 1.000000
cos(-0) = 1.000000
cos(INFINITY) = -nan
    FE_INVALID raised
