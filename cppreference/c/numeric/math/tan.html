tan, tanf, tanl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       tanf( float arg );  // (1) (depuis C99)

double      tan( double arg );  // (2)

long double tanl( long double arg );  // (3) (depuis C99)

_Decimal32  tand32( _Decimal32 arg );  // (4) (depuis C23)

_Decimal64  tand64( _Decimal64 arg );  // (5) (depuis C23)

_Decimal128 tand128( _Decimal128 arg );  // (6) (depuis C23)

Défini dans l'en-tête <tgmath.h>

#define tan( arg )  // (7) (depuis C99)

1-6) Calcule la tangente de arg (exprimée en radians).

  1. Macro générique par type : si l'argument a le type long double, (3) (tanl) est appelée. Sinon, si l'argument a un type entier ou le type double, (2) (tan) est appelée. Sinon, (1) (tanf) est appelée. Si l'argument est complexe, la macro appelle la fonction complexe correspondante (ctanf, ctan, ctanl).

Les fonctions (4-6) sont déclarées si et seulement si l'implémentation prédéfinit __STDC_IEC_60559_DFP__ (c'est-à-dire si l'implémentation prend en charge les nombres à virgule flottante décimaux).

(depuis C23)

Paramètres

  • arg — valeur à virgule flottante représentant un angle en radians

Valeur de retour

Si aucune erreur ne se produit, la tangente de arg (tan(arg)) est renvoyée.

Le résultat peut avoir peu ou pas de signification si la valeur absolue de arg est grande.

(jusqu'à C99)

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559) :

  • si l'argument vaut ±0, il est renvoyé sans modification ;
  • si l'argument vaut ±∞, NaN est renvoyé et FE_INVALID est levée ;
  • si l'argument est NaN, NaN est renvoyé.

Notes

Le cas où l'argument est infini n'est pas spécifié comme erreur de domaine en C, mais il est défini comme une erreur de domaine en POSIX.

La fonction admet des pôles mathématiques en π(1/2 + n) ; cependant, aucune représentation courante à virgule flottante ne peut représenter π/2 exactement, il n'existe donc aucune valeur de l'argument pour laquelle une erreur de pôle se produit.

Exemple

#include <errno.h>
#include <fenv.h>
#include <math.h>
#include <stdio.h>

#ifndef __GNUC__
#pragma STDC FENV_ACCESS ON
#endif

int main(void)
{
    const double pi = acos(-1);

    // utilisation typique
    printf("tan(pi*1/4) = %+f\n", tan(pi * 1 / 4)); //   45 deg
    printf("tan(pi*3/4) = %+f\n", tan(pi * 3 / 4)); //  135 deg
    printf("tan(pi*5/4) = %+f\n", tan(pi * 5 / 4)); // -135 deg
    printf("tan(pi*7/4) = %+f\n", tan(pi * 7 / 4)); //  -45 deg

    // valeurs spéciales
    printf("tan(+0) = %f\n", tan(0.0));
    printf("tan(-0) = %f\n", tan(-0.0));

    // gestion des erreurs
    feclearexcept(FE_ALL_EXCEPT);
    printf("tan(INFINITY) = %f\n", tan(INFINITY));
    if (fetestexcept(FE_INVALID))
        puts("    FE_INVALID raised");
}

Sortie possible :
