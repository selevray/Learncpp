fdim, fdimf, fdiml

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       fdimf( float x, float y );  // (1) (depuis C99)

double      fdim( double x, double y );  // (2) (depuis C99)

long double fdiml( long double x, long double y );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define fdim( x, y )  // (4) (depuis C99)

1-3) Renvoie la différence positive entre x et y, c'est-à-dire que si x>y, renvoie x-y, sinon (si x≤y), renvoie +0.

  1. Macro générique au type : si un argument est de type long double, fdiml est appelée. Sinon, si un argument est de type entier ou de type double, fdim est appelée. Sinon, fdimf est appelée.

Paramètres

  • x, y — valeur à virgule flottante

Valeur de retour

En cas de succès, renvoie la différence positive entre x et y.

Si une erreur d'intervalle due à un dépassement se produit, +HUGE_VAL, +HUGE_VALF ou +HUGE_VALL est renvoyé.

Si une erreur de plage due à un sous-dépassement se produit, la valeur correcte (après arrondi) est renvoyée.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans Template:rllpt.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si l'un des arguments est NaN, NaN est renvoyé.

Notes

Équivalent à fmax(x-y, 0), à l'exception des exigences de traitement de NaN.

Exemple

#include <errno.h>
#include <fenv.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON

int main(void)
{
    printf("fdim(4, 1) = %f, fdim(1, 4)=%f\n", fdim(4,1), fdim(1,4));
    printf("fdim(4,-1) = %f, fdim(1,-4)=%f\n", fdim(4,-1), fdim(1,-4));
    //gestion des erreurs
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("fdim(1e308, -1e308) = %f\n", fdim(1e308, -1e308));
    if (errno == ERANGE)
        perror("    errno == ERANGE");
    if (fetestexcept(FE_OVERFLOW))
        puts("    FE_OVERFLOW raised");
}

Sortie possible :

fdim(4, 1) = 3.000000, fdim(1, 4)=0.000000
fdim(4,-1) = 5.000000, fdim(1,-4)=5.000000
fdim(1e308, -1e308) = inf
    errno == ERANGE: Numerical result out of range
    FE_OVERFLOW raised
