islessequal

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

#define islessequal(x, y) /* implementation defined */  // (depuis C99)

Détermine si le nombre à virgule flottante x est inférieur ou égal au nombre à virgule flottante y, sans lever d'exceptions en virgule flottante.

Paramètres

  • x — valeur à virgule flottante
  • y — valeur à virgule flottante

Valeur de retour

Valeur entière non nulle si x <= y, 0 sinon.

Notes

L'opérateur intégré operator<= pour les nombres à virgule flottante peut lever FE_INVALID si l'un des arguments ou les deux sont NaN. Cette fonction est une version « silencieuse » de operator<=.

Exemple

#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("islessequal(2.0,1.0)      = %d\n", islessequal(2.0, 1.0));
    printf("islessequal(1.0,2.0)      = %d\n", islessequal(1.0, 2.0));
    printf("islessequal(1.0,1.0)      = %d\n", islessequal(1.0, 1.0));
    printf("islessequal(INFINITY,1.0) = %d\n", islessequal(INFINITY, 1.0));
    printf("islessequal(1.0,NAN)      = %d\n", islessequal(1.0, NAN));

    return 0;
}

Sortie possible :

islessequal(2.0,1.0)      = 0
islessequal(1.0,2.0)      = 1
islessequal(1.0,1.0)      = 1
islessequal(INFINITY,1.0) = 0
islessequal(1.0,NAN)      = 0
