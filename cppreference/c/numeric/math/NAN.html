NAN

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

#define NAN /*implementation defined*/  // (depuis C99)

La macro NAN se développe en une expression constante de type float, qui s'évalue à une valeur NaN silencieuse (QNaN). Si l'implémentation ne prend pas en charge les QNaN, cette constante macro n'est pas définie.

Le style utilisé pour afficher un NaN est défini par l'implémentation.

Notes

Il existe de nombreuses valeurs NaN différentes, distinguées par leur charge utile (payload) et leur bit de signe. Le contenu de la charge utile et le bit de signe du NaN généré par la macro NAN sont définis par l'implémentation.

Exemple

Affiche le style utilisé pour afficher un NaN et le format IEEE.

#include <inttypes.h>
#include <math.h>
#include <stdint.h>
#include <stdio.h>
#include <string.h>

int main(void)
{
    const double f = NAN;
    uint64_t fn;
    memcpy(&fn, &f, sizeof f);
    printf("NAN:   %f %" PRIx64 "\n", f, fn);
}

Sortie possible :

NAN:   nan 7ff8000000000000
