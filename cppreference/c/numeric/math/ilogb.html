ilogb, ilogbf, ilogbl

int ilogbl( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

Défini dans l'en-tête <math.h>

#define FP_ILOGB0    /* implementation-defined */  // (5) (depuis C99)

#define FP_ILOGBNAN  /* implementation-defined */  // (6) (depuis C99)

1-3) Extrait la valeur de l'exposant non biaisé de l'argument à virgule flottante arg, et la retourne sous forme de valeur entière signée.

  1. Macros génériques par type : si arg a le type long double, ilogbl est appelée. Sinon, si arg a un type entier ou le type double, ilogb est appelée. Sinon, ilogbf est appelée.

  2. Se développe en expression constante entière dont la valeur est soit INT_MIN, soit -INT_MAX.

  3. Se développe en expression constante entière dont la valeur est soit INT_MIN, soit +INT_MAX.

Formellement, l'exposant non biaisé est la partie entière de logr|arg| sous forme de valeur entière signée, pour arg non nul, où r vaut FLT_RADIX.

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne se produit, l'exposant non biaisé de arg est renvoyé sous forme de valeur int signée.

Si arg vaut zéro, FP_ILOGB0 est renvoyé.

Si arg est infini, INT_MAX est renvoyé.

Si arg est un NaN, FP_ILOGBNAN est renvoyé.

Si le résultat correct est supérieur à INT_MAX ou inférieur à INT_MIN, la valeur de retour est non spécifiée et une erreur de domaine ou une erreur de dépassement peut se produire.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Une erreur de domaine ou d'intervalle peut se produire si arg vaut zéro, est infini ou NaN.

Si le résultat correct est supérieur à INT_MAX ou inférieur à INT_MIN, une erreur de domaine ou une erreur de dépassement peut se produire

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si le résultat correct est supérieur à INT_MAX ou inférieur à INT_MIN, FE_INVALID est levée.
  • Si arg vaut ±0, ±∞ ou NaN, FE_INVALID est levée.
  • Dans tous les autres cas, le résultat est exact (FE_INEXACT n'est jamais levée) et le mode d'arrondi courant est ignoré.

Notes

Si arg n'est ni nul, ni infini, ni NaN, la valeur renvoyée est exactement équivalente à (int)logb(arg).

POSIX exige qu'une erreur de domaine se produise si arg vaut zéro, est infini, NaN, ou si le résultat correct est en dehors de l'intervalle de int.

POSIX exige également que, sur les systèmes conformes XSI, la valeur renvoyée lorsque le résultat correct est supérieur à INT_MAX soit INT_MAX, et la valeur renvoyée lorsque le résultat correct est inférieur à INT_MIN soit INT_MIN.

Le résultat correct peut être représenté comme int sur toutes les implémentations connues. Pour qu'un dépassement se produise, INT_MAX doit être inférieur à LDBL_MAX_EXP * log2(FLT_RADIX) ou INT_MIN doit être supérieur à LDBL_MIN_EXP - LDBL_MANT_DIG) * log2(FLT_RADIX).

La valeur de l'exposant retournée par ilogb est toujours inférieure de 1 à l'exposant retourné par frexp en raison des différentes exigences de normalisation : pour l'exposant e retourné par ilogb, |argr-e
| est compris entre 1 et r (généralement entre 1 et 2), mais pour l'exposant e retourné par frexp, |arg2-e
| est compris entre 0.5 et 1.

Exemple

#include <fenv.h>
#include <float.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON

int main(void)
{
    double f = 123.45;
    printf("Given the number %.2f or %a in hex,\n", f, f);

    double f3;
    double f2 = modf(f, &f3);
    printf("modf() makes %.0f + %.2f\n", f3, f2);

    int i;
    f2 = frexp(f, &i);
    printf("frexp() makes %f * 2^%d\n", f2, i);

    i = ilogb(f);
    printf("logb()/ilogb() make %f * %d^%d\n", f/scalbn(1.0, i), FLT_RADIX, i);

    // gestion des erreurs
    feclearexcept(FE_ALL_EXCEPT);
    printf("ilogb(0) = %d\n", ilogb(0));
    if (fetestexcept(FE_INVALID))
        puts("    FE_INVALID raised");
}

Sortie possible :

Given the number 123.45 or 0x1.edccccccccccdp+6 in hex,
modf() makes 123 + 0.45
frexp() makes 0.964453 * 2^7
logb()/ilogb() make 1.92891 * 2^6
ilogb(0) = -2147483648
    FE_INVALID raised
