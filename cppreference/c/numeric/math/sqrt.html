sqrt, sqrtf, sqrtl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       sqrtf( float arg );  // (1) (depuis C99)

double      sqrt( double arg );  // (2)

long double sqrtl( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define sqrt( arg )  // (4) (depuis C99)

1-3) Calcule la racine carrée de arg.

  1. Macro générique par type : si arg est de type long double, sqrtl est appelée. Sinon, si arg est de type entier ou de type double, sqrt est appelée. Sinon, sqrtf est appelée. Si arg est complexe ou imaginaire, la macro invoque la fonction complexe correspondante (csqrtf, csqrt, csqrtl).

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne survient, la racine carrée de arg (({\small \sqrt{arg} })√arg) est renvoyée.

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Une erreur de domaine se produit si arg est inférieur à zéro.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si l'argument est inférieur à -0, FE_INVALID est levée et NaN est renvoyé.
  • Si l'argument vaut +∞ ou ±0, il est renvoyé sans modification.
  • Si l'argument est NaN, NaN est retourné.

Notes

sqrt est requise par la norme IEEE d'être correctement arrondie à partir du résultat en précision infinie. En particulier, le résultat exact est produit s'il peut être représenté dans le type à virgule flottante. Les seules autres opérations qui l'exigent sont les opérateurs arithmétiques et la fonction fma. Les autres fonctions, y compris pow, ne sont pas soumises à cette contrainte.

Exemple

#include <errno.h>
#include <fenv.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON

int main(void)
{
    // utilisation normale
    printf("sqrt(100) = %f\n", sqrt(100));
    printf("sqrt(2) = %f\n", sqrt(2));
    printf("golden ratio = %f\n", (1 + sqrt(5)) / 2);

    // valeurs spéciales
    printf("sqrt(-0) = %f\n", sqrt(-0.0));

    // gestion des erreurs
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("sqrt(-1.0) = %f\n", sqrt(-1));
    if (errno == EDOM)
        perror("    errno == EDOM");
    if (fetestexcept(FE_INVALID))
        puts("    FE_INVALID was raised");
}
