exp, expf, expl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       expf( float arg );  // (1) (depuis C99)

double      exp( double arg );  // (2)

long double expl( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define exp( arg )  // (4) (depuis C99)

1-3) Calcule e (le nombre d'Euler, 2.7182818...) élevé à la puissance donnée arg.

  1. Macro générique par type : si arg est de type long double, expl est appelée. Sinon, si arg est de type entier ou de type double, exp est appelée. Sinon, expf est appelée. Si arg est complexe ou imaginaire, la macro invoque la fonction complexe correspondante (cexpf, cexp, cexpl).

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne se produit, l'exponentielle de base e de arg (earg
) est renvoyée.

Si une erreur d'intervalle due à un dépassement se produit, +HUGE_VAL, +HUGE_VALF ou +HUGE_VALL est renvoyé.

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si l'argument vaut ±0, 1 est renvoyé
  • Si l'argument vaut -∞, +0 est renvoyé
  • Si l'argument vaut +∞, +∞ est renvoyé
  • si l'argument est NaN, NaN est renvoyé

Notes

Pour le type double compatible IEEE, un dépassement de capacité est garanti si 709.8 < arg, et un sous-dépassement est garanti si arg < -708.4.

Exemple

#include <errno.h>
#include <fenv.h>
#include <float.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON

int main(void)
{
    printf("exp(1) = %f\n", exp(1));
    printf("FV of $100, continuously compounded at 3%% for 1 year = %f\n",
            100*exp(0.03));
    // valeurs spéciales
    printf("exp(-0) = %f\n", exp(-0.0));
    printf("exp(-Inf) = %f\n", exp(-INFINITY));
    //gestion des erreurs
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("exp(710) = %f\n", exp(710));
    if (errno == ERANGE)
        perror("    errno == ERANGE");
    if (fetestexcept(FE_OVERFLOW))
        puts("    FE_OVERFLOW raised");
}
