trunc, truncf, truncl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       truncf( float arg );  // (1) (depuis C99)

double      trunc( double arg );  // (2) (depuis C99)

long double truncl( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define trunc( arg )  // (4) (depuis C99)

1-3) Calcule l'entier le plus proche dont la valeur absolue n'est pas supérieure à celle de arg.

  1. Macro générique au type : si arg est de type long double, truncl est appelée. Sinon, si arg est de type entier ou de type double, trunc est appelée. Sinon, truncf est appelée.

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne se produit, la valeur entière la plus proche dont la valeur absolue n'est pas supérieure à celle de arg (autrement dit, arg arrondi vers zéro) est renvoyée.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559) :

  • Le mode d'arrondi courant n'a aucun effet.
  • Si arg vaut ±∞, il est renvoyé sans modification.
  • Si arg vaut ±0, il est renvoyé sans modification.
  • Si arg est NaN, NaN est renvoyé.

Notes

FE_INEXACT peut être (mais n'est pas obligée d'être) levée lors de la troncature d'une valeur finie non entière.

Les plus grandes valeurs à virgule flottante représentables sont des entiers exacts dans tous les formats à virgule flottante standard, donc cette fonction ne déborde jamais par elle-même ; toutefois, le résultat peut dépasser tout type entier (y compris intmax_t) lorsqu'il est stocké dans une variable entière.

La conversion implicite des types à virgule flottante vers les types entiers arrondit également vers zéro, mais elle est limitée aux valeurs pouvant être représentées par le type cible.

Exemple

#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("trunc(+2.7) = %+.1f\n", trunc(+2.7));
    printf("trunc(-2.7) = %+.1f\n", trunc(-2.7));
    printf("trunc(-0.0) = %+.1f\n", trunc(-0.0));
    printf("trunc(-Inf) = %+f\n",   trunc(-INFINITY));
}

Sortie possible :

trunc(+2.7) = +2.0
trunc(-2.7) = -2.0
trunc(-0.0) = -0.0
trunc(-Inf) = -inf
