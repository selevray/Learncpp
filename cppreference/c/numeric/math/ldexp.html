ldexp, ldexpf, ldexpl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       ldexpf( float arg, int exp );  // (1) (depuis C99)

double      ldexp( double arg, int exp );  // (2)

long double ldexpl( long double arg, int exp );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define ldexp( arg, exp )  // (4) (depuis C99)

1-3) Multiplie une valeur à virgule flottante arg par le nombre 2 élevé à la puissance exp.

  1. Macro générique par type : si arg a le type long double, ldexpl est appelée. Sinon, si arg a un type entier ou le type double, ldexp est appelée. Sinon, ldexpf est appelée, respectivement.

Paramètres

  • arg — valeur à virgule flottante
  • exp — valeur entière

Valeur de retour

Si aucune erreur ne se produit, arg multiplié par 2 à la puissance exp (arg×2exp
) est renvoyé.

Si une erreur d'intervalle due à un dépassement se produit, ±HUGE_VAL, ±HUGE_VALF ou ±HUGE_VALL est renvoyé.

Si une erreur d'intervalle due à un soupassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Sauf en cas d'erreur d'intervalle, FE_INEXACT n'est jamais levé (le résultat est exact)
  • Sauf en cas d'erreur d'intervalle, le mode d'arrondi courant est ignoré
  • Si arg vaut ±0, il est renvoyé sans modification
  • Si arg vaut ±∞, il est renvoyé sans modification
  • Si exp vaut 0, alors arg est renvoyé sans modification
  • Si arg est NaN, NaN est renvoyé.

Notes

Sur les systèmes binaires (où FLT_RADIX vaut 2), ldexp est équivalent à scalbn.

La fonction ldexp (« load exponent »), avec sa duale frexp, peut être utilisée pour manipuler la représentation d'un nombre à virgule flottante sans manipulation directe des bits.

Sur de nombreuses implémentations, ldexp est moins efficace que la multiplication ou la division par une puissance de deux à l'aide des opérateurs arithmétiques.

Exemple

#include <errno.h>
#include <fenv.h>
#include <float.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON

int main(void)
{
    printf("ldexp(7, -4) = %f\n", ldexp(7, -4));
    printf("ldexp(1, -1074) = %g (minimum positive subnormal double)\n",
            ldexp(1, -1074));
    printf("ldexp(nextafter(1,0), 1024) = %g (largest finite double)\n",
            ldexp(nextafter(1,0), 1024));

    // valeurs spéciales
    printf("ldexp(-0, 10) = %f\n", ldexp(-0.0, 10));
    printf("ldexp(-Inf, -1) = %f\n", ldexp(-INFINITY, -1));

    // gestion des erreurs
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("ldexp(1, 1024) = %f\n", ldexp(1, 1024));
    if (errno == ERANGE)
        perror("    errno == ERANGE");
    if (fetestexcept(FE_OVERFLOW))
        puts("    FE_OVERFLOW raised");
}

Sortie possible :

ldexp(7, -4) = 0.437500
ldexp(1, -1074) = 4.94066e-324 (minimum positive subnormal double)
ldexp(nextafter(1,0), 1024) = 1.79769e+308 (largest finite double)
ldexp(-0, 10) = -0.000000
ldexp(-Inf, -1) = -inf
ldexp(1, 1024) = inf
