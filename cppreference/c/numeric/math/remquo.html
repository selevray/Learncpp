remquo, remquof, remquol

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       remquof( float x, float y, int *quo );  // (1) (depuis C99)

double      remquo( double x, double y, int *quo );  // (2) (depuis C99)

long double remquol( long double x, long double y, int *quo );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define remquo( x, y, quo )  // (4) (depuis C99)

1-3) Calcule le reste en virgule flottante de l'opération de division x/y, comme le fait la fonction remainder(). De plus, le signe et au moins les trois derniers bits de x/y sont stockés dans quo, suffisants pour déterminer l'octant du résultat dans une période.

  1. Macro générique par type : si un argument non pointeur a le type long double, remquol est appelée. Sinon, si un argument non pointeur a un type entier ou le type double, remquo est appelée. Sinon, remquof est appelée.

Paramètres

  • x, y — valeurs à virgule flottante
  • quo — pointeur vers une valeur entière destinée à stocker le signe et quelques bits de x/y

Valeur de retour

En cas de succès, retourne le reste en virgule flottante de la division x/y tel que défini dans remainder, et stocke, dans *quo, le signe et au moins trois des bits de poids faible de x/y (formellement, stocke une valeur dont le signe est celui de x/y et dont la magnitude est congrue modulo 2n
à la magnitude du quotient entier de x/y, où n est un entier défini par l'implémentation supérieur ou égal à 3).

Si y est nul, la valeur stockée dans *quo est non spécifiée.

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur de portée se produit par sous-dépassement, le résultat correct est retourné si les subnormaux sont supportés.

Si y est nul, mais que l'erreur de domaine ne se produit pas, zéro est retourné.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Une erreur de domaine peut se produire si y vaut zéro.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Le mode d'arrondi courant n'a aucun effet.
  • FE_INEXACT n'est jamais levée
  • Si x vaut ±∞ et que y n'est pas NaN, NaN est retourné et FE_INVALID est levé
  • Si y vaut ±0 et que x n'est pas NaN, NaN est retourné et FE_INVALID est levé
  • Si x ou y est NaN, NaN est retourné

Notes

POSIX exige qu'une erreur de domaine se produise si x est infini ou si y vaut zéro.

Cette fonction est utile pour implémenter des fonctions périodiques lorsque la période est exactement représentable en virgule flottante : lors du calcul de sin(πx) pour un x très grand, appeler sin directement peut entraîner une grande erreur, mais si l'argument de la fonction est d'abord réduit avec remquo, les bits de poids faible du quotient peuvent servir à déterminer le signe et l'octant du résultat au sein de la période, tandis que le reste peut servir à calculer la valeur avec une grande précision.

Sur certaines plateformes, cette opération est prise en charge par le matériel (et, par exemple, sur les processeurs Intel, FPREM1 ne laisse que 3 bits de précision dans le quotient).

Exemple

#include <fenv.h>
#include <math.h>
#include <stdio.h>

#ifndef __GNUC__
#pragma STDC FENV_ACCESS ON
#endif

double cos_pi_x_naive(double x)
{
    const double pi = acos(-1);
    return cos(pi * x);
}

// la période est 2, les valeurs sont (0;0.5) positives, (0.5;1.5) négatives, (1.5,2) positives
double cos_pi_x_smart(double x)
{
    const double pi = acos(-1);
    int extremum;
    double rem = remquo(x, 1, &extremum);
    extremum = (unsigned)extremum % 2; // conserver 1 bit pour déterminer l'extremum le plus proche
    return extremum ? -cos(pi * rem) : cos(pi * rem);
}

int main(void)
{
    printf("cos(pi * 0.25) = %f\n", cos_pi_x_naive(0.25));
    printf("cos(pi * 1.25) = %f\n", cos_pi_x_naive(1.25));
    printf("cos(pi * 1000000000000.25) = %f\n", cos_pi_x_naive(1000000000000.25));
    printf("cos(pi * 1000000000001.25) = %f\n", cos_pi_x_naive(1000000000001.25));
    printf("cos(pi * 1000000000000.25) = %f\n", cos_pi_x_smart(1000000000000.25));
    printf("cos(pi * 1000000000001.25) = %f\n", cos_pi_x_smart(1000000000001.25));

    // gestion des erreurs
    feclearexcept(FE_ALL_EXCEPT);
    int quo;
    printf("remquo(+Inf, 1) = %.1f\n", remquo(INFINITY, 1, &quo));
    if (fetestexcept(FE_INVALID))
        puts("    FE_INVALID raised");
}
