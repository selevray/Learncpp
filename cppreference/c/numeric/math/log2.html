log2, log2f, log2l

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       log2f( float arg );  // (1) (depuis C99)

double      log2( double arg );  // (2) (depuis C99)

long double log2l( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define log2( arg )  // (4) (depuis C99)

1-3) Calcule le logarithme de base 2 de arg.

  1. Macro générique au type : si arg est de type long double, log2l est appelée. Sinon, si arg est de type entier ou de type double, log2 est appelée. Sinon, log2f est appelée.

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne se produit, le logarithme en base-2 de arg (log2(arg) ou lb(arg)) est renvoyé.

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur de pôle se produit, -HUGE_VAL, -HUGE_VALF ou -HUGE_VALL est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Une erreur de domaine se produit si arg est inférieur à zéro.

Une erreur de pôle peut se produire si arg est nul.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si l'argument vaut ±0, -∞ est renvoyé et FE_DIVBYZERO est levé.
  • Si l'argument vaut 1, +0 est renvoyé
  • Si l'argument est négatif, NaN est renvoyé et FE_INVALID est levé.
  • Si l'argument vaut +∞, +∞ est renvoyé
  • si l'argument est NaN, NaN est renvoyé

Notes

Pour un entier arg, le logarithme binaire peut être interprété comme l'indice en base zéro du bit 1 le plus significatif de l'entrée.

Exemple

#include <stdio.h>
#include <math.h>
#include <float.h>
#include <errno.h>
#include <fenv.h>
// #pragma STDC FENV_ACCESS ON
int main(void)
{
    printf("log2(65536) = %f\n", log2(65536));
    printf("log2(0.125) = %f\n", log2(0.125));
    printf("log2(0x020f) = %f (highest set bit is in position 9)\n", log2(0x020f));
    printf("base-5 logarithm of 125 = %f\n", log2(125)/log2(5));
    // valeurs spéciales
    printf("log2(1) = %f\n", log2(1));
    printf("log2(+Inf) = %f\n", log2(INFINITY));
    //gestion des erreurs
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("log2(0) = %f\n", log2(0));
    if(errno == ERANGE) perror("    errno == ERANGE");
    if(fetestexcept(FE_DIVBYZERO)) puts("    FE_DIVBYZERO raised");
}

Sortie possible :

log2(65536) = 16.000000
log2(0.125) = -3.000000
log2(0x020f) = 9.041659 (highest set bit is in position 9)
base-5 logarithm of 125 = 3.000000
log2(1) = 0.000000
log2(+Inf) = inf
log2(0) = -inf

    FE_DIVBYZERO raised
