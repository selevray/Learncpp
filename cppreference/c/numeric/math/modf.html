modf, modff, modfl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       modff( float arg, float* iptr );  // (1) (depuis C99)

double      modf( double arg, double* iptr );  // (2)

long double modfl( long double arg, long double* iptr );  // (3) (depuis C99)

1-3) Décompose la valeur à virgule flottante donnée arg en parties entière et fractionnaire, chacune ayant le même type et le même signe que arg. La partie entière (au format à virgule flottante) est stockée dans l'objet pointé par iptr.

Paramètres

  • arg — valeur à virgule flottante
  • iptr — pointeur vers la valeur à virgule flottante où stocker la partie entière

Valeur de retour

Si aucune erreur ne se produit, renvoie la partie fractionnaire de arg avec le même signe que arg. La partie entière est placée dans la valeur pointée par iptr.

La somme de la valeur renvoyée et de la valeur stockée dans *iptr donne arg (à l'arrondi près).

Gestion des erreurs

Cette fonction n'est soumise à aucune des erreurs spécifiées dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si arg vaut ±0, ±0 est renvoyé, et ±0 est stocké dans *iptr.
  • Si arg vaut ±∞, ±0 est renvoyé, et ±∞ est stocké dans *iptr.
  • Si arg est NaN, NaN est renvoyé, et NaN est stocké dans *iptr.
  • La valeur renvoyée est exacte, le mode d'arrondi courant est ignoré.

Notes

Cette fonction se comporte comme si elle était implémentée ainsi :

double modf(double value, double *iptr)
{
#pragma STDC FENV_ACCESS ON
    int save_round = fegetround();
    fesetround(FE_TOWARDZERO);
    *iptr = std::nearbyint(value);
    fesetround(save_round);
    return copysign(isinf(value) ? 0.0 : value - (*iptr), value);
}

Exemple

#include <float.h>
#include <math.h>
#include <stdio.h>

int main(void)
{
    double f = 123.45;
    printf("Given the number %.2f or %a in hex,\n", f, f);

    double f3;
    double f2 = modf(f, &f3);
    printf("modf() makes %.2f + %.2f\n", f3, f2);

    int i;
    f2 = frexp(f, &i);
    printf("frexp() makes %f * 2^%d\n", f2, i);

    i = ilogb(f);
    printf("logb()/ilogb() make %f * %d^%d\n", f / scalbn(1.0, i), FLT_RADIX, i);

    // valeurs spéciales
    f2 = modf(-0.0, &f3);
    printf("modf(-0) makes %.2f + %.2f\n", f3, f2);
    f2 = modf(-INFINITY, &f3);
    printf("modf(-Inf) makes %.2f + %.2f\n", f3, f2);
}

Sortie possible :

Given the number 123.45 or 0x1.edccccccccccdp+6 in hex,
modf() makes 123.00 + 0.45
frexp() makes 0.964453 * 2^7
logb()/ilogb() make 1.92891 * 2^6
modf(-0) makes -0.00 + -0.00
modf(-Inf) makes -INF + -0.00
