erfc, erfcf, erfcl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       erfcf( float arg );  // (1) (depuis C99)

double      erfc( double arg );  // (2) (depuis C99)

long double erfcl( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define erfc( arg )  // (4) (depuis C99)

1-3) Calcule la fonction d'erreur complémentaire de arg, soit 1.0 - erf(arg), mais sans perte de précision pour de grandes valeurs de arg.

  1. Macro générique au type : si arg est de type long double, erfcl est appelée. Sinon, si arg est de type entier ou de type double, erfc est appelée. Sinon, erfcf est appelée.

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne se produit, la valeur de la fonction d'erreur complémentaire de arg, soit (\frac{2}{\sqrt{\pi} }\int_{arg}^{\infty}{e^{-{t^2} }\mathsf{d}t})
2
√π

∫∞
arge-t2dt ou ({\small 1-\operatorname{erf}(arg)})1-erf(arg), est renvoyée.

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si l'argument vaut +∞, +0 est renvoyé.
  • Si l'argument vaut -∞, 2 est renvoyé.
  • Si l'argument est NaN, NaN est retourné.

Notes

Pour le type double compatible IEEE, le sous-dépassement est garanti si arg > 26.55.

Exemple

#include <math.h>
#include <stdio.h>

double normalCDF(double x) // Phi(-∞, x) aussi appelée N(x)
{
    return erfc(-x / sqrt(2)) / 2;
}

int main(void)
{
    puts("normal cumulative distribution function:");
    for (double n = 0; n < 1; n += 0.1)
        printf("normalCDF(%.2f) %5.2f%%\n", n, 100 * normalCDF(n));

    printf("special values:\n"
           "erfc(-Inf) = %f\n"
           "erfc(Inf) = %f\n",
           erfc(-INFINITY),
           erfc(INFINITY));
}
