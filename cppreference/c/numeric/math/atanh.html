atanh, atanhf, atanhl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       atanhf( float arg );  // (1) (depuis C99)

double      atanh( double arg );  // (2) (depuis C99)

long double atanhl( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define atanh( arg )  // (4) (depuis C99)

1-3) Calcule la tangente hyperbolique inverse de arg.

  1. Macro générique par type : si l'argument a le type long double, atanhl est appelée. Sinon, si l'argument a un type entier ou le type double, atanh est appelée. Sinon, atanhf est appelée. Si l'argument est complexe, la macro appelle la fonction complexe correspondante (catanhf, catanh, catanhl).

Paramètres

  • arg — valeur floating_point représentant l'aire d'un secteur hyperbolique

Valeur de retour

Si aucune erreur ne se produit, la tangente hyperbolique inverse de arg (tanh-1
(arg), ou artanh(arg)), est retournée.

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur de pôle se produit, ±HUGE_VAL, ±HUGE_VALF, ou ±HUGE_VALL est retourné (avec le signe correct).

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'argument n'est pas dans l'intervalle [-1,+1], une erreur d'intervalle se produit.

Si l'argument est ±1, une erreur de pôle se produit.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si l'argument est ±0, il est retourné sans modification.
  • Si l'argument vaut ±1, ±∞ est renvoyé et FE_DIVBYZERO est levé.
  • Si |arg|>1, NaN est renvoyé et FE_INVALID est levé.
  • Si l'argument est NaN, NaN est retourné.

Notes

Bien que la norme C nomme cette fonction « arc tangente hyperbolique », les fonctions inverses des fonctions hyperboliques sont les fonctions d'aire. Leur argument est l'aire d'un secteur hyperbolique, et non un arc. Le nom correct est « tangente hyperbolique inverse » (utilisé par POSIX) ou « tangente hyperbolique d'aire ».

POSIX spécifie qu'en cas de sous-dépassement, arg est retourné sans modification, et si cela n'est pas pris en charge, une valeur définie par l'implémentation non supérieure à DBL_MIN, FLT_MIN, et LDBL_MIN est retournée.

Exemple

#include <errno.h>
#include <fenv.h>
#include <float.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON

int main(void)
{
    printf("atanh(0) = %f\natanh(-0) = %f\n", atanh(0), atanh(-0.0));
    printf("atanh(0.9) = %f\n", atanh(0.9));

    // gestion des erreurs
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("atanh(-1) = %f\n", atanh(-1));
    if (errno == ERANGE)
        perror("    errno == ERANGE");
    if (fetestexcept(FE_DIVBYZERO))
        puts("    FE_DIVBYZERO raised");
}
