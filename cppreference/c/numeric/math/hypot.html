hypot, hypotf, hypotl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       hypotf( float x, float y );  // (1) (depuis C99)

double      hypot( double x, double y );  // (2) (depuis C99)

long double hypotl( long double x, long double y );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define hypot( x, y )  // (4) (depuis C99)

1-3) Calcule la racine carrée de la somme des carrés de x et y, sans dépassement ni sous-dépassement excessif aux étapes intermédiaires du calcul.

  1. Macro générique par type : si un argument a le type long double, la version long double de la fonction est appelée. Sinon, si un argument a un type entier ou le type double, la version double de la fonction est appelée. Sinon, la version float de la fonction est appelée.

La valeur calculée par cette fonction est la longueur de l'hypoténuse d'un triangle rectangle de côtés x et y, ou la distance du point (x, y) à l'origine (0, 0), ou le module d'un nombre complexe x+iy.

Paramètres

  • x — valeur à virgule flottante
  • y — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne se produit, l'hypoténuse d'un triangle rectangle, (\scriptsize{\sqrt{x^2+y^2} })√x2
+y2
, est retournée.

Si une erreur d'intervalle due à un dépassement se produit, +HUGE_VAL, +HUGE_VALF ou +HUGE_VALL est renvoyé.

Si une erreur d'intervalle due à un soupassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • hypot(x, y), hypot(y, x) et hypot(x, -y) sont équivalents
  • si l'un des arguments vaut ±0, hypot est équivalent à fabs appelée avec l'argument non nul
  • si l'un des arguments vaut ±∞, hypot retourne +∞ même si l'autre argument est NaN
  • sinon, si l'un des arguments est NaN, NaN est renvoyé.

Notes

Les implémentations garantissent en général une précision inférieure à 1 ulp (unité en dernière position) : GNU, BSD.

hypot(x, y) est équivalent à cabs(x + I*y).

POSIX spécifie que le soupassement ne peut se produire que lorsque les deux arguments sont subnormaux et que le résultat correct est aussi subnormal (ceci interdit les implémentations naïves).

hypot(INFINITY, NAN) retourne +∞, mais sqrt(INFINITY * INFINITY + NAN * NAN) retourne NaN.

Exemple

#include <errno.h>
#include <fenv.h>
#include <float.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON

int main(void)
{
    // utilisation typique
    printf("(1,1) cartesian is (%f,%f) polar\n", hypot(1,1), atan2(1, 1));

    // valeurs spéciales
    printf("hypot(NAN,INFINITY) = %f\n", hypot(NAN, INFINITY));

    // gestion des erreurs
    errno = 0;
    feclearexcept(FE_ALL_EXCEPT);
    printf("hypot(DBL_MAX,DBL_MAX) = %f\n", hypot(DBL_MAX, DBL_MAX));
    if (errno == ERANGE)
        perror("    errno == ERANGE");
    if (fetestexcept(FE_OVERFLOW))
        puts("    FE_OVERFLOW raised");
}
