log10, log10f, log10l

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       log10f( float arg );  // (1) (depuis C99)

double      log10( double arg );  // (2)

long double log10l( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define log10( arg )  // (4) (depuis C99)

1-3) Calcule le logarithme commun (de base 10) de arg.

  1. Macro générique au type : si arg est de type long double, log10l est appelée. Sinon, si arg est de type entier ou de type double, log10 est appelée. Sinon, log10f est appelée.

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne se produit, le logarithme décimal (de base-10) de arg (log10(arg) ou lg(arg)) est renvoyé.

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur de pôle se produit, -HUGE_VAL, -HUGE_VALF ou -HUGE_VALL est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Une erreur de domaine se produit si arg est inférieur à zéro.

Une erreur de pôle peut se produire si arg est nul.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si l'argument vaut ±0, -∞ est renvoyé et FE_DIVBYZERO est levé.
  • Si l'argument vaut 1, +0 est renvoyé
  • Si l'argument est négatif, NaN est renvoyé et FE_INVALID est levé.
  • Si l'argument vaut +∞, +∞ est renvoyé
  • Si l'argument est NaN, NaN est retourné.

Exemple

#include <errno.h>
#include <fenv.h>
#include <float.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON

int main(void)
{
    printf("log10(1000) = %f\n", log10(1000));
    printf("log10(0.001) = %f\n", log10(0.001));
    printf("base-5 logarithm of 125 = %f\n", log10(125) / log10(5));

    // valeurs spéciales
    printf("log10(1) = %f\n", log10(1));
    printf("log10(+Inf) = %f\n", log10(INFINITY));

    // gestion des erreurs
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("log10(0) = %f\n", log10(0));
    if (errno == ERANGE)
        perror("    errno == ERANGE");
    if (fetestexcept(FE_DIVBYZERO))
        puts("    FE_DIVBYZERO raised");
}

Sortie possible :

log10(1000) = 3.000000
log10(0.001) = -3.000000
base-5 logarithm of 125 = 3.000000
log10(1) = 0.000000
log10(+Inf) = inf
log10(0) = -inf
