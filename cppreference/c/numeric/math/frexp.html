frexp, frexpf, frexpl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       frexpf( float arg, int* exp );  // (1) (depuis C99)

double      frexp( double arg, int* exp );  // (2)

long double frexpl( long double arg, int* exp );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define frexp( arg, exp )  // (4) (depuis C99)

1-3) Décompose la valeur à virgule flottante donnée x en une fraction normalisée et une puissance entière de deux.

  1. Macro générique par type : si arg a le type long double, frexpl est appelée. Sinon, si arg a un type entier ou le type double, frexp est appelée. Sinon, frexpf est appelée, respectivement.

Paramètres

  • arg — valeur à virgule flottante
  • exp — pointeur vers la valeur entière où stocker l'exposant

Valeur de retour

Si arg vaut zéro, renvoie zéro et stocke zéro dans *exp.

Sinon (si arg n'est pas nul), si aucune erreur ne se produit, renvoie la valeur x dans l'intervalle (-1;-0.5], [0.5; 1) et stocke une valeur entière dans *exp telle que x×2(*exp)
=arg.

Si la valeur à stocker dans *exp est en dehors de l'intervalle de int, le comportement est non spécifié.

Si arg n'est pas un nombre à virgule flottante, le comportement est non spécifié.

Gestion des erreurs

Cette fonction n'est soumise à aucune des erreurs spécifiées dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si arg vaut ±0, il est renvoyé sans modification, et 0 est stocké dans *exp.
  • Si arg vaut ±∞, il est renvoyé, et une valeur non spécifiée est stockée dans *exp.
  • Si arg est NaN, NaN est renvoyé, et une valeur non spécifiée est stockée dans *exp.
  • Aucune exception à virgule flottante n'est levée.
  • Si FLT_RADIX vaut 2 (ou une puissance de 2), la valeur retournée est exacte, le mode d'arrondi courant est ignoré.

Notes

Sur un système binaire (où FLT_RADIX vaut 2), frexp peut être implémentée comme

{
    *exp = (value == 0) ? 0 : (int)(1 + logb(value));
    return scalbn(value, -(*exp));
}

La fonction frexp, ainsi que sa duale, ldexp, peut être utilisée pour manipuler la représentation d'un nombre à virgule flottante sans manipulation directe de bits.

Exemple

#include <float.h>
#include <math.h>
#include <stdio.h>

int main(void)
{
    double f = 123.45;
    printf("Given the number %.2f or %a in hex,\n", f, f);

    double f3;
    double f2 = modf(f, &f3);
    printf("modf() makes %.0f + %.2f\n", f3, f2);

    int i;
    f2 = frexp(f, &i);
    printf("frexp() makes %f * 2^%d\n", f2, i);

    i = ilogb(f);
    printf("logb()/ilogb() make %f * %d^%d\n", f/scalbn(1.0, i), FLT_RADIX, i);
}

Sortie possible :

Given the number 123.45 or 0x1.edccccccccccdp+6 in hex,
modf() makes 123 + 0.45
frexp() makes 0.964453 * 2^7
logb()/ilogb() make 1.92891 * 2^6
