Défini dans l'en-tête <tgmath.h>

#define atan2( y, x )  // (7) (depuis C99)

1-6) Calcule l'arc tangente de y / x en utilisant les signes des arguments pour déterminer le bon quadrant.

  1. Macro générique par type : si un argument a le type long double, (3) (atan2l) est appelée. Sinon, si un argument a un type entier ou le type double, (2) (atan2) est appelée. Sinon, (1) (atan2f) est appelée.

Les fonctions (4-6) sont déclarées si et seulement si l'implémentation prédéfinit __STDC_IEC_60559_DFP__ (c'est-à-dire si l'implémentation prend en charge les nombres à virgule flottante décimaux).

(depuis C23)

  • x, y — valeur à virgule flottante

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée.

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Une erreur de domaine peut se produire si x et y sont tous deux nuls.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559) :

  • Si x et y valent tous deux zéro, une erreur de domaine ne se produit pas ;
  • Si x et y valent tous deux zéro, aucune erreur de plage ne se produit non plus ;
  • Si y vaut zéro, aucune erreur de pôle ne se produit ;
  • Si y vaut ±0 et x est négatif ou -0, ±π est renvoyé ;
  • Si y vaut ±0 et x est positif ou +0, ±0 est renvoyé ;
  • Si y vaut ±∞ et x est fini, ±π/2 est renvoyé ;
  • Si y vaut ±∞ et x vaut -∞, ±3π/4 est renvoyé ;
  • Si y vaut ±∞ et x vaut +∞, ±π/4 est renvoyé ;
  • Si x vaut ±0 et y est négatif, -π/2 est renvoyé ;
  • Si x vaut ±0 et y est positif, +π/2 est renvoyé ;
  • Si x vaut -∞ et y est fini et positif, +π est renvoyé ;
  • Si x vaut -∞ et y est fini et négatif, -π est renvoyé ;
  • Si x vaut +∞ et y est fini et positif, +0 est renvoyé ;
  • Si x vaut +∞ et y est fini et négatif, -0 est renvoyé ;
  • Si x est NaN ou y est NaN, NaN est retourné.

Notes

atan2(y, x) est équivalent à carg(x + I*y).

POSIX précise qu'en cas de sous-dépassement, y / x est la valeur renvoyée et, si cela n'est pas pris en charge, une valeur définie par l'implémentation, non supérieure à DBL_MIN, FLT_MIN et LDBL_MIN, est renvoyée.

Exemple

#include <math.h>
#include <stdio.h>

int main(void)
{
    // utilisation normale : les signes des deux arguments déterminent le quadrant
    // atan2(1,1) = +pi/4, Quad I
    printf("(+1,+1) cartesian is (%f,%f) polar\n", hypot( 1, 1), atan2( 1, 1));
    // atan2(1, -1) = +3pi/4, Quad II
    printf("(+1,-1) cartesian is (%f,%f) polar\n", hypot( 1,-1), atan2( 1,-1));
    // atan2(-1,-1) = -3pi/4, Quad III
    printf("(-1,-1) cartesian is (%f,%f) polar\n", hypot(-1,-1), atan2(-1,-1));
    // atan2(-1,-1) = -pi/4, Quad IV
    printf("(-1,+1) cartesian is (%f,%f) polar\n", hypot(-1, 1), atan2(-1, 1));

    // valeurs spéciales
    printf("atan2(0, 0) = %f atan2(0, -0)=%f\n", atan2(0,0), atan2(0,-0.0));
    printf("atan2(7, 0) = %f atan2(7, -0)=%f\n", atan2(7,0), atan2(7,-0.0));
}

Output:

(+1,-1) cartesian is (1.414214,2.356194) polar
(-1,-1) cartesian is (1.414214,-2.356194) polar
(-1,+1) cartesian is (1.414214,-0.785398) polar
atan2(0, 0) = 0.000000 atan2(0, -0)=3.141593
atan2(7, 0) = 1.570796 atan2(7, -0)=1.570796
