exp2, exp2f, exp2l

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       exp2f( float n );  // (1) (depuis C99)

double      exp2( double n );  // (2) (depuis C99)

long double exp2l( long double n );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define exp2( n )  // (4) (depuis C99)

1-3) Calcule 2 élevé à la puissance donnée n.

  1. Macro générique au type : si n est de type long double, exp2l est appelée. Sinon, si n est de type entier ou de type double, exp2 est appelée. Sinon, exp2f est appelée.

Paramètres

  • n — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne se produit, l'exponentielle en base 2 de n (2n
) est renvoyée.

Si une erreur d'intervalle due à un dépassement se produit, +HUGE_VAL, +HUGE_VALF ou +HUGE_VALL est renvoyé.

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si l'argument vaut ±0, 1 est renvoyé
  • Si l'argument vaut -∞, +0 est renvoyé
  • Si l'argument vaut +∞, +∞ est renvoyé
  • si l'argument est NaN, NaN est renvoyé

Exemple

#include <errno.h>
#include <fenv.h>
#include <float.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON

int main(void)
{
    printf("exp2(5) = %f\n", exp2(5));
    printf("exp2(0.5) = %f\n", exp2(0.5));
    printf("exp2(-4) = %f\n", exp2(-4));
    // valeurs spéciales
    printf("exp2(-0.9) = %f\n", exp2(-0.9));
    printf("exp2(-Inf) = %f\n", exp2(-INFINITY));
    //gestion des erreurs
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("exp2(1024) = %f\n", exp2(1024));
    if (errno == ERANGE)
        perror("    errno == ERANGE");
    if (fetestexcept(FE_OVERFLOW))
        puts("    FE_OVERFLOW raised");
}
