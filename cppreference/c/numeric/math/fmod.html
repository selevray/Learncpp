fmod, fmodf, fmodl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       fmodf( float x, float y );  // (1) (depuis C99)

double      fmod( double x, double y );  // (2)

long double fmodl( long double x, long double y );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define fmod( x, y )  // (4) (depuis C99)

1-3) Calcule le reste en virgule flottante de l'opération de division x / y.

  1. Macro générique au type : si un argument est de type long double, fmodl est appelée. Sinon, si un argument est de type entier ou de type double, fmod est appelée. Sinon, fmodf est appelée.

Le reste à virgule flottante de l'opération de division x / y calculé par cette fonction vaut exactement la valeur x - n * y, où n est x / y dont la partie fractionnaire a été tronquée.

La valeur renvoyée a le même signe que x et sa valeur absolue est inférieure ou égale à celle de y.

Paramètres

  • x, y — valeurs à virgule flottante

Valeur de retour

En cas de succès, renvoie le reste à virgule flottante de la division x / y tel que défini ci-dessus.

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Une erreur de domaine peut se produire si y vaut zéro.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559) :

  • Si x vaut ±0 et y est non nul, ±0 est renvoyé.
  • Si x vaut ±∞ et y n'est pas NaN, NaN est renvoyé et FE_INVALID est levé.
  • Si y vaut ±0 et x n'est pas NaN, NaN est renvoyé et FE_INVALID est levé.
  • Si y vaut ±∞ et x est fini, x est renvoyé.
  • Si l'un des arguments est NaN, NaN est renvoyé.

Notes

POSIX exige qu'une erreur de domaine se produise si x est infini ou si y vaut zéro.

fmod, mais pas remainder, est utile pour effectuer un enveloppement silencieux de types à virgule flottante vers des types entiers non signés : (0.0 <= (y = fmod(rint(x), 65536.0 )) ? y : 65536.0 + y) est dans l'intervalle [-0.0,65535.0], ce qui correspond à unsigned short, mais remainder(rint(x), 65536.0) est dans l'intervalle [-32767.0,+32768.0], qui est en dehors de l'intervalle de signed short.

La version double de fmod se comporte comme si elle était implémentée de la manière suivante :

double fmod(double x, double y)
{
#pragma STDC FENV_ACCESS ON
    double result = remainder(fabs(x), (y = fabs(y)));
    if (signbit(result))
        result += y;
    return copysign(result, x);
}

Exemple

#include <fenv.h>
#include <math.h>
#include <stdio.h>

// #pragma STDC FENV_ACCESS ON

int main(void)
{
    printf("fmod(+5.1, +3.0) = %.1f\n", fmod(5.1, 3));
    printf("fmod(-5.1, +3.0) = %.1f\n", fmod(-5.1, 3));
    printf("fmod(+5.1, -3.0) = %.1f\n", fmod(5.1, -3));
    printf("fmod(-5.1, -3.0) = %.1f\n", fmod(-5.1, -3));

    // valeurs spéciales
    printf("fmod(+0.0, 1.0) = %.1f\n", fmod(0, 1));
    printf("fmod(-0.0, 1.0) = %.1f\n", fmod(-0.0, 1));
    printf("fmod(+5.1, Inf) = %.1f\n", fmod(5.1, INFINITY));

    // gestion des erreurs
    feclearexcept(FE_ALL_EXCEPT);
    printf("fmod(+5.1, 0) = %.1f\n", fmod(5.1, 0));
    if (fetestexcept(FE_INVALID))
        puts("    FE_INVALID raised");
}
