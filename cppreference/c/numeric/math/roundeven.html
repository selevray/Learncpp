roundeven, roundevenf, roundevenl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       roundevenf( float arg );  // (1) (depuis C23)

double      roundeven( double arg );  // (2) (depuis C23)

long double roundevenl( long double arg );  // (3) (depuis C23)

Défini dans l'en-tête <tgmath.h>

#define roundeven( arg )  // (4) (depuis C23)

1-3) Calcule la valeur entière la plus proche de arg (au format à virgule flottante), en arrondissant les cas intermédiaires à l'entier pair le plus proche, quel que soit le mode d'arrondi courant.

  1. Macro générique par type : si arg a le type long double, roundevenl est appelée. Sinon, si arg a un type entier ou le type double, roundeven est appelée. Sinon, roundevenf est appelée, respectivement.

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne se produit, la valeur entière la plus proche de arg, en arrondissant les cas intermédiaires à l'entier pair le plus proche, est retournée.

Gestion des erreurs

Cette fonction n'est soumise à aucune des erreurs spécifiées dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559) :

  • FE_INEXACT n'est jamais levée.
  • Si arg vaut ±∞, il est renvoyé sans modification.
  • Si arg vaut ±0, il est renvoyé sans modification.
  • Si arg est NaN, NaN est renvoyé.

Exemple

#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("roundeven(+2.4) = %+.1f\n", roundeven(2.4));
    printf("roundeven(-2.4) = %+.1f\n", roundeven(-2.4));
    printf("roundeven(+2.5) = %+.1f\n", roundeven(2.5));
    printf("roundeven(-2.5) = %+.1f\n", roundeven(-2.5));
    printf("roundeven(+2.6) = %+.1f\n", roundeven(2.6));
    printf("roundeven(-2.6) = %+.1f\n", roundeven(-2.6));
    printf("roundeven(+3.5) = %+.1f\n", roundeven(3.5));
    printf("roundeven(-3.5) = %+.1f\n", roundeven(-3.5));
    printf("roundeven(-0.0) = %+.1f\n", roundeven(-0.0));
    printf("roundeven(-Inf) = %+f\n",   roundeven(-INFINITY));
}
