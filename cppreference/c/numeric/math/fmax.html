fmax, fmaxf, fmaxl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       fmaxf( float x, float y );  // (1) (depuis C99)

double      fmax( double x, double y );  // (2) (depuis C99)

long double fmaxl( long double x, long double y );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define fmax( x, y )  // (4) (depuis C99)

1-3) Renvoie le plus grand de deux arguments en virgule flottante, en traitant les NaN comme des données manquantes (entre un NaN et une valeur numérique, la valeur numérique est choisie).

  1. Macro générique au type : si un argument est de type long double, fmaxl est appelée. Sinon, si un argument est de type entier ou de type double, fmax est appelée. Sinon, fmaxf est appelée.

Paramètres

  • x, y — valeurs à virgule flottante

Valeur de retour

En cas de succès, renvoie la plus grande de deux valeurs en virgule flottante. La valeur renvoyée est exacte et ne dépend d'aucun mode d'arrondi.

Gestion des erreurs

Cette fonction n'est soumise à aucune des conditions d'erreur spécifiées dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si l'un des deux arguments est NaN, la valeur de l'autre argument est renvoyée.
  • Un NaN n'est renvoyé que si les deux arguments sont NaN.

Notes

Cette fonction n'est pas tenue d'être sensible au signe de zéro, bien que certaines implémentations imposent en plus que, si un argument vaut +0 et l'autre -0, alors +0 soit renvoyé.

Exemple

#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("fmax(2,1)    = %f\n", fmax(2,1));
    printf("fmax(-Inf,0) = %f\n", fmax(-INFINITY,0));
    printf("fmax(NaN,-1) = %f\n", fmax(NAN,-1));
}

Output:

fmax(2,1)    = 2.000000
fmax(-Inf,0) = 0.000000
fmax(NaN,-1) = -1.000000
