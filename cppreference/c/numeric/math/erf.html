#define erf( arg )  // (4) (depuis C99)

1-3) Calcule la fonction d'erreur de arg.

  1. Macro générique au type : si arg est de type long double, erfl est appelée. Sinon, si arg est de type entier ou de type double, erf est appelée. Sinon, erff est appelée.

Paramètres

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • si l'argument vaut ±0, ±0 est renvoyé
  • si l'argument vaut ±∞, ±1 est renvoyé
  • si l'argument est NaN, NaN est renvoyé

Notes

Un sous-dépassement est garanti si |arg| < DBL_MIN*(sqrt(π)/2).

Exemple

#include <math.h>
#include <stdio.h>

double phi(double x1, double x2)
{
    return (erf(x2 / sqrt(2)) - erf(x1 / sqrt(2))) / 2;
}

int main(void)
{
    puts("normal variate probabilities:");
    for (int n = -4; n < 4; ++n)
        printf("[%2d:%2d]: %5.2f%%\n", n, n + 1, 100 * phi(n, n + 1));

    puts("special values:");
    printf("erf(-0) = %f\n", erf(-0.0));
    printf("erf(Inf) = %f\n", erf(INFINITY));
}
