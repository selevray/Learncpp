abs, labs, llabs, imaxabs

Défini dans l'en-tête <stdlib.h>

int        abs( int n );

long       labs( long n );

long long llabs( long long n );  // (depuis C99)

Défini dans l'en-tête <inttypes.h>

intmax_t imaxabs( intmax_t n );  // (depuis C99)

Calcule la valeur absolue d'un nombre entier. Le comportement est indéfini si le résultat ne peut pas être représenté par le type de retour.

Paramètres

  • n — valeur entière

Valeur de retour

La valeur absolue de n (c.-à-d. |n|), si elle est représentable.

Notes

Dans les systèmes en complément à deux, la valeur absolue de la valeur la plus négative est hors de portée : par exemple, pour le type en complément à deux de 32 bits int, INT_MIN vaut -2147483648, mais le résultat espéré 2147483648 est supérieur à INT_MAX, qui vaut 2147483647.

Exemple

#include <limits.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    printf("abs(+3) = %d\n", abs(+3));
    printf("abs(-3) = %d\n", abs(-3));

//  printf("%+d\n", abs(INT_MIN)); // comportement indéfini sur les systèmes en complément à deux
}

Output:

abs(+3) = 3
abs(-3) = 3
