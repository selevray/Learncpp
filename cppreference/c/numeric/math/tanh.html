tanh, tanhf, tanhl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       tanhf( float arg );  // (1) (depuis C99)

double      tanh( double arg );  // (2)

long double tanhl( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define tanh( arg )  // (4) (depuis C99)

1-3) Calcule la tangente hyperbolique de arg.

  1. Macro générique par type : si l'argument a le type long double, tanhl est appelée. Sinon, si l'argument a un type entier ou le type double, tanh est appelée. Sinon, tanhf est appelée. Si l'argument est complexe, la macro appelle la fonction complexe correspondante (ctanhf, ctanh, ctanhl).

Paramètres

  • arg — valeur à virgule flottante représentant un angle hyperbolique

Valeur de retour

Si aucune erreur ne se produit, la tangente hyperbolique de arg (tanh(arg), ou
earg -e-arg
earg +e-arg

) est renvoyée.

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si l'argument vaut ±0, ±0 est renvoyé.
  • Si l'argument vaut ±∞, ±1 est renvoyé.
  • Si l'argument est NaN, NaN est retourné.

Notes

POSIX spécifie qu'en cas de sous-dépassement, arg est retourné sans modification, et si cela n'est pas pris en charge, une valeur définie par l'implémentation non supérieure à DBL_MIN, FLT_MIN, et LDBL_MIN est retournée.

Exemple

#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("tanh(1) = %f\ntanh(-1) = %f\n", tanh(1), tanh(-1));
    printf("tanh(0.1)*sinh(0.2)-cosh(0.2) = %f\n", tanh(0.1) * sinh(0.2) - cosh(0.2));
    // valeurs spéciales
    printf("tanh(+0) = %f\ntanh(-0) = %f\n", tanh(0.0), tanh(-0.0));
}

Output:

tanh(1) = 0.761594
tanh(-1) = -0.761594
tanh(0.1)*sinh(0.2)-cosh(0.2) = -1.000000
tanh(+0) = 0.000000
tanh(-0) = -0.000000
