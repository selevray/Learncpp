INFINITY

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

#define INFINITY /*implementation defined*/  // (depuis C99)

Si l'implémentation prend en charge les infinis à virgule flottante, la macro INFINITY se développe en expression constante de type float qui vaut l'infini positif ou non signé.

Si l'implémentation ne prend pas en charge les infinis à virgule flottante, la macro INFINITY se développe en une valeur positive garantie de provoquer un dépassement de capacité d'un float à la compilation, et l'utilisation de cette macro génère un avertissement du compilateur.

Le style utilisé pour afficher un infini est défini par l'implémentation.

Exemple

Affiche le style utilisé pour afficher un infini et le format IEEE.

#include <stdio.h>
#include <math.h>
#include <stdint.h>
#include <inttypes.h>
#include <string.h>

int main(void)
{
    double f = INFINITY;
    uint64_t fn; memcpy(&fn, &f, sizeof f);
    printf("INFINITY:   %f %" PRIx64 "\n", f, fn);
}
