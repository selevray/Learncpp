isnormal

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

#define isnormal(arg) /* implementation defined */  // (depuis C99)

Détermine si le nombre à virgule flottante donné arg est normal, c'est-à-dire qu'il n'est ni nul, ni subnormal, ni infini, ni NaN. La macro renvoie une valeur entière.

FLT_EVAL_METHOD est ignoré : même si l'argument est évalué avec une plage et une précision supérieures à son type, il est d'abord converti en son type sémantique, et la classification est basée sur celui-ci.

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Valeur entière non nulle si arg est normal, 0 sinon.

Exemple

#include <float.h>
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("isnormal(NAN)         = %d\n", isnormal(NAN));
    printf("isnormal(INFINITY)    = %d\n", isnormal(INFINITY));
    printf("isnormal(0.0)         = %d\n", isnormal(0.0));
    printf("isnormal(DBL_MIN/2.0) = %d\n", isnormal(DBL_MIN / 2.0));
    printf("isnormal(1.0)         = %d\n", isnormal(1.0));
}

Output:

isnormal(NAN)         = 0
isnormal(INFINITY)    = 0
isnormal(0.0)         = 0
isnormal(DBL_MIN/2.0) = 0
isnormal(1.0)         = 1
