cosh, coshf, coshl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       coshf( float arg );  // (1) (depuis C99)

double      cosh( double arg );  // (2)

long double coshl( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define cosh( arg )  // (4) (depuis C99)

1-3) Calcule le cosinus hyperbolique de arg.

  1. Macro générique par type : si l'argument a le type long double, coshl est appelée. Sinon, si l'argument a un type entier ou le type double, cosh est appelée. Sinon, coshf est appelée. Si l'argument est complexe, la macro appelle la fonction complexe correspondante (ccoshf, ccosh, ccoshl).

Paramètres

  • arg — valeur à virgule flottante représentant un angle hyperbolique

Valeur de retour

Si aucune erreur ne se produit, le cosinus hyperbolique de arg (cosh(arg), ou
earg +e-arg
2

) est renvoyé.

Si une erreur d'intervalle due à un dépassement se produit, +HUGE_VAL, +HUGE_VALF ou +HUGE_VALL est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • si l'argument vaut ±0, 1 est renvoyé
  • si l'argument vaut ±∞, +∞ est renvoyé
  • si l'argument est NaN, NaN est renvoyé

Notes

Pour le type compatible IEEE double, si |arg| > 710.5, alors cosh(arg) déborde.

Exemple

#include <errno.h>
#include <fenv.h>
#include <math.h>
#include <stdio.h>

// #pragma STDC FENV_ACCESS ON
int main(void)
{
    printf("cosh(1) = %f\ncosh(-1)= %f\n", cosh(1), cosh(-1));
    printf("log(sinh(1) + cosh(1))=%f\n", log(sinh(1) + cosh(1)));
    // valeurs spéciales
    printf("cosh(+0) = %f\ncosh(-0) = %f\n", cosh(0.0), cosh(-0.0));
    // gestion des erreurs
    errno = 0;
    feclearexcept(FE_ALL_EXCEPT);
    printf("cosh(710.5) = %f\n", cosh(710.5));
    if (errno == ERANGE)
        perror("    errno == ERANGE");
    if (fetestexcept(FE_OVERFLOW))
        puts("    FE_OVERFLOW raised");
}
