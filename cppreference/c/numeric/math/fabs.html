1-6) Calcule la valeur absolue d'une valeur à virgule flottante arg.

Les fonctions à paramètres en virgule flottante décimale sont déclarées si et seulement si l'implémentation prédéfinit __STDC_IEC_60559_DFP__ (c'est-à-dire si l'implémentation prend en charge les nombres à virgule flottante décimale).

(depuis C23)

  1. Macro générique par type : si l'argument est de type _Decimal128, _Decimal64, _Decimal32, (depuis C23)long double, double, ou float, fabsd128, fabsd64, fabsd32, (depuis C23)fabsl, fabs, ou fabsf, la fonction correspondante est appelée. Sinon, si l'argument est de type entier, fabs est appelée. Sinon, si l'argument est complexe, la macro appelle la fonction complexe correspondante (cabsf, cabs, cabsl). Sinon, le comportement est indéfini.

Paramètres

  • arg — valeur à virgule flottante
  • arith — valeur à virgule flottante ou entière

Valeur de retour

En cas de succès, renvoie la valeur absolue de arg ((\small |arg| )|arg|). La valeur renvoyée est exacte et ne dépend d'aucun mode d'arrondi.

Gestion des erreurs

Cette fonction n'est soumise à aucune des conditions d'erreur spécifiées dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si l'argument vaut ±0, +0 est renvoyé.
  • Si l'argument vaut ±∞, +∞ est renvoyé.
  • Si l'argument est NaN, NaN est retourné.

Exemple

#include <math.h>
#include <stdio.h>

#define PI 3.14159

// Cette intégration numérique suppose que toute l'aire est positive.
double integrate(double f(double),
                 double a, double b, // supposons a < b
                 unsigned steps) // supposons steps > 0
{
    const double dx = (b - a) / steps;
    double sum = 0.0;
    for (double x = a; x < b; x += dx)
        sum += fabs(f(x));
    return dx * sum;
}

int main(void)
{
    printf("fabs(+3) = %f\n", fabs(+3.0));
    printf("fabs(-3) = %f\n", fabs(-3.0));
    // valeurs spéciales
    printf("fabs(-0) = %f\n", fabs(-0.0));
    printf("fabs(-Inf) = %f\n", fabs(-INFINITY));

    printf("Area under sin(x) in [-PI, PI] = %f\n", integrate(sin, -PI, PI, 5101));
}

Output:

fabs(+3) = 3.000000
fabs(-3) = 3.000000
fabs(-0) = 0.000000
fabs(-Inf) = inf
Area under sin(x) in [-PI, PI] = 4.000000
