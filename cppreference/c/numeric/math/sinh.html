sinh, sinhf, sinhl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       sinhf( float arg );  // (1) (depuis C99)

double      sinh( double arg );  // (2)

long double sinhl( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define sinh( arg )  // (4) (depuis C99)

1-3) Calcule le sinus hyperbolique de arg.

  1. Macro générique par type : si l'argument a le type long double, sinhl est appelée. Sinon, si l'argument a un type entier ou le type double, sinh est appelée. Sinon, sinhf est appelée. Si l'argument est complexe, la macro appelle la fonction complexe correspondante (csinhf, csinh, csinhl).

Paramètres

  • arg — valeur à virgule flottante représentant un angle hyperbolique

Valeur de retour

Si aucune erreur ne se produit, le sinus hyperbolique de arg (sinh(arg), ou
earg -e-arg
2

) est renvoyé.

Si une erreur d'intervalle due à un dépassement se produit, ±HUGE_VAL, ±HUGE_VALF ou ±HUGE_VALL est renvoyé.

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • si l'argument est ±0 ou ±∞, il est renvoyé sans modification,
  • si l'argument est NaN, NaN est renvoyé.

Notes

POSIX spécifie qu'en cas de sous-dépassement, arg est retourné sans modification, et si cela n'est pas pris en charge, une valeur définie par l'implémentation non supérieure à DBL_MIN, FLT_MIN, et LDBL_MIN est retournée.

Exemple

#include <errno.h>
#include <fenv.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON

int main(void)
{
    printf("sinh(1) = %f\nsinh(-1)=%f\n", sinh(1), sinh(-1));
    printf("log(sinh(1) + cosh(1))=%f\n", log(sinh(1) + cosh(1)));

    // valeurs spéciales
    printf("sinh(+0) = %f\nsinh(-0)=%f\n", sinh(0.0), sinh(-0.0));

    // gestion des erreurs
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("sinh(710.5) = %f\n", sinh(710.5));
    if (errno == ERANGE)
        perror("    errno == ERANGE");
    if (fetestexcept(FE_OVERFLOW))
        puts("    FE_OVERFLOW raised");
}
