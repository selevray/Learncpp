isnan

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

#define isnan(arg) /* implementation defined */  // (depuis C99)

Détermine si le nombre à virgule flottante donné arg est une valeur non numérique (NaN). La macro renvoie une valeur entière.

FLT_EVAL_METHOD est ignoré : même si l'argument est évalué avec une plage et une précision supérieures à celles de son type, il est d'abord converti dans son type sémantique, et la classification est fondée sur celui-ci (cela importe si le type d'évaluation prend en charge les NaN alors que le type sémantique ne le fait pas).

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Valeur entière non nulle si arg est un NaN, 0 sinon.

Notes

Il existe de nombreuses valeurs NaN différentes, avec des bits de signe et des charges utiles différents, voir nan.

Les valeurs NaN ne sont jamais égales à elles-mêmes ni à d'autres valeurs NaN. La copie d'un NaN peut modifier son motif binaire.

Une autre façon de tester si une valeur à virgule flottante est NaN consiste à la comparer à elle-même : bool is_nan(double x) { return x != x; }

Exemple

#include <float.h>
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("isnan(NAN)         = %d\n", isnan(NAN));
    printf("isnan(INFINITY)    = %d\n", isnan(INFINITY));
    printf("isnan(0.0)         = %d\n", isnan(0.0));
    printf("isnan(DBL_MIN/2.0) = %d\n", isnan(DBL_MIN / 2.0));
    printf("isnan(0.0 / 0.0)   = %d\n", isnan(0.0 / 0.0));
    printf("isnan(Inf - Inf)   = %d\n", isnan(INFINITY - INFINITY));
}

Sortie possible :

isnan(NAN)         = 1
isnan(INFINITY)    = 0
isnan(0.0)         = 0
isnan(DBL_MIN/2.0) = 0
isnan(0.0 / 0.0)   = 1
isnan(Inf - Inf)   = 1
