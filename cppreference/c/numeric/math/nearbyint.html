nearbyint, nearbyintf, nearbyintl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       nearbyintf( float arg );  // (1) (depuis C99)

double      nearbyint( double arg );  // (2) (depuis C99)

long double nearbyintl( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define nearbyint( arg )  // (4) (depuis C99)

1-3) Arrondit l'argument flottant arg à une valeur entière au format flottant, en utilisant le mode d'arrondi courant.

  1. Macro générique par type : si arg a le type long double, nearbyintl est appelée. Sinon, si arg a un type entier ou le type double, nearbyint est appelée. Sinon, nearbyintf est appelée, respectivement.

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

La valeur entière la plus proche de arg, selon le mode d'arrondi courant, est renvoyée.

Gestion des erreurs

Cette fonction n'est soumise à aucune des erreurs spécifiées dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • FE_INEXACT n'est jamais levée.
  • Si arg vaut ±∞, il est renvoyé sans modification.
  • Si arg vaut ±0, il est renvoyé sans modification.
  • Si arg est NaN, NaN est renvoyé.

Notes

La seule différence entre nearbyint et rint est que nearbyint ne lève jamais FE_INEXACT.

Les plus grandes valeurs à virgule flottante représentables sont des entiers exacts dans tous les formats à virgule flottante standard, donc nearbyint ne déborde jamais par lui-même ; cependant le résultat peut déborder de tout type entier (y compris intmax_t) lorsqu'il est stocké dans une variable entière.

Si le mode d'arrondi courant est FE_TONEAREST, cette fonction arrondit au pair dans les cas médians (comme rint, mais contrairement à round).

Exemple

#include <fenv.h>
#include <math.h>
#include <stdio.h>

int main(void)
{
// #pragma STDC FENV_ACCESS ON
    fesetround(FE_TONEAREST);
    printf("rounding to nearest:\nnearbyint(+2.3) = %+.1f  ", nearbyint(2.3));
    printf("nearbyint(+2.5) = %+.1f  ", nearbyint(2.5));
    printf("nearbyint(+3.5) = %+.1f\n", nearbyint(3.5));
    printf("nearbyint(-2.3) = %+.1f  ", nearbyint(-2.3));
    printf("nearbyint(-2.5) = %+.1f  ", nearbyint(-2.5));
    printf("nearbyint(-3.5) = %+.1f\n", nearbyint(-3.5));

    fesetround(FE_DOWNWARD);
    printf("rounding down: \nnearbyint(+2.3) = %+.1f  ", nearbyint(2.3));
    printf("nearbyint(+2.5) = %+.1f  ", nearbyint(2.5));
    printf("nearbyint(+3.5) = %+.1f\n", nearbyint(3.5));
    printf("nearbyint(-2.3) = %+.1f  ", nearbyint(-2.3));
    printf("nearbyint(-2.5) = %+.1f  ", nearbyint(-2.5));
    printf("nearbyint(-3.5) = %+.1f\n", nearbyint(-3.5));

    printf("nearbyint(-0.0) = %+.1f\n", nearbyint(-0.0));
    printf("nearbyint(-Inf) = %+.1f\n", nearbyint(-INFINITY));
}

Output:

rounding to nearest:
nearbyint(+2.3) = +2.0  nearbyint(+2.5) = +2.0  nearbyint(+3.5) = +4.0
nearbyint(-2.3) = -2.0  nearbyint(-2.5) = -2.0  nearbyint(-3.5) = -4.0
rounding down:
nearbyint(+2.3) = +2.0  nearbyint(+2.5) = +2.0  nearbyint(+3.5) = +3.0
nearbyint(-2.3) = -3.0  nearbyint(-2.5) = -3.0  nearbyint(-3.5) = -4.0
nearbyint(-0.0) = -0.0
nearbyint(-Inf) = -inf
