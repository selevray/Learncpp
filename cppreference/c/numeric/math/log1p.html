log1p, log1pf, log1pl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       log1pf( float arg );  // (1) (depuis C99)

double      log1p( double arg );  // (2) (depuis C99)

long double log1pl( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define log1p( arg )  // (4) (depuis C99)

1-3) Calcule le logarithme naturel (de base e) de 1 + arg. Cette fonction est plus précise que l'expression log(1 + arg) lorsque arg est proche de zéro.

  1. Macro générique au type : si arg est de type long double, log1pl est appelée. Sinon, si arg est de type entier ou de type double, log1p est appelée. Sinon, log1pf est appelée.

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne se produit, ln(1 + arg) est renvoyé.

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur de pôle se produit, -HUGE_VAL, -HUGE_VALF ou -HUGE_VALL est renvoyé.

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Une erreur de domaine se produit si arg est inférieur à -1.

Une erreur de pôle peut se produire si arg vaut -1.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si l'argument est ±0, il est retourné sans modification.
  • Si l'argument vaut -1, -∞ est renvoyé et FE_DIVBYZERO est levé.
  • Si l'argument est inférieur à -1, NaN est renvoyé et FE_INVALID est levé.
  • Si l'argument vaut +∞, +∞ est renvoyé.
  • Si l'argument est NaN, NaN est retourné.

Notes

Les fonctions expm1 et log1p sont utiles pour les calculs financiers, par exemple lors du calcul de petits taux d'intérêt quotidiens : (1+x)n
-1 peut s'écrire expm1(n * log1p(x)). Ces fonctions simplifient aussi l'écriture des fonctions hyperboliques inverses précises.

Exemple

#include <errno.h>
#include <fenv.h>
#include <float.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON

int main(void)
{
    printf("log1p(0) = %f\n", log1p(0));
    printf("Interest earned in 2 days on $100, compounded daily at 1%%\n"
           " on a 30/360 calendar = %f\n",
           100*expm1(2*log1p(0.01/360)));
    printf("log(1+1e-16) = %g, but log1p(1e-16) = %g\n",
           log(1+1e-16), log1p(1e-16));

    // valeurs spéciales
    printf("log1p(-0) = %f\n", log1p(-0.0));
    printf("log1p(+Inf) = %f\n", log1p(INFINITY));

    // gestion des erreurs
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("log1p(-1) = %f\n", log1p(-1));
    if (errno == ERANGE)
        perror("    errno == ERANGE");
    if (fetestexcept(FE_DIVBYZERO))
        puts("    FE_DIVBYZERO raised");
}
