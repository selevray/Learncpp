isunordered

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

#define isunordered(x, y) /* implementation defined */  // (depuis C99)

Détermine si les nombres à virgule flottante x et y sont non ordonnés, c'est-à-dire qu'un ou les deux sont NaN et ne peuvent donc pas être comparés de manière significative entre eux.

Paramètres

  • x — valeur à virgule flottante
  • y — valeur à virgule flottante

Valeur de retour

Valeur entière non nulle si x ou y est NaN, 0 sinon.

Exemple

#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("isunordered(NAN,1.0) = %d\n", isunordered(NAN, 1.0));
    printf("isunordered(1.0,NAN) = %d\n", isunordered(1.0, NAN));
    printf("isunordered(NAN,NAN) = %d\n", isunordered(NAN, NAN));
    printf("isunordered(1.0,0.0) = %d\n", isunordered(1.0, 0.0));

    return 0;
}

Sortie possible :

isunordered(NAN,1.0) = 1
isunordered(1.0,NAN) = 1
isunordered(NAN,NAN) = 1
isunordered(1.0,0.0) = 0
