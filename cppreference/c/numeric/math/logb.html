logb, logbf, logbl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       logbf( float arg );  // (1) (depuis C99)

double      logb( double arg );  // (2) (depuis C99)

long double logbl( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define logb( arg )  // (4) (depuis C99)

1-3) Extrait la valeur de l'exposant non biaisé indépendant de la base à partir de l'argument à virgule flottante arg, et la renvoie sous forme de valeur à virgule flottante.

  1. Macros génériques par type : si arg a le type long double, logbl est appelée. Sinon, si arg a un type entier ou le type double, logb est appelée. Sinon, logbf est appelée.

Formellement, l'exposant non biaisé est la partie entière signée de logr|arg| (renvoyée par cette fonction sous forme de valeur à virgule flottante), pour arg non nul, où r vaut FLT_RADIX. Si arg est subnormal, il est traité comme s'il était normalisé.

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne se produit, l'exposant non biaisé de arg est renvoyé sous forme de valeur à virgule flottante signée.

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée.

Si une erreur de pôle se produit, -HUGE_VAL, -HUGE_VALF ou -HUGE_VALL est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Une erreur de domaine ou d'intervalle peut se produire si arg est nul.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559),

  • Si arg vaut ±0, -∞ est renvoyé et FE_DIVBYZERO est levée.
  • Si arg vaut ±∞, +∞ est renvoyé.
  • Si arg est NaN, NaN est renvoyé.
  • Dans tous les autres cas, le résultat est exact (FE_INEXACT n'est jamais levée) et le mode d'arrondi courant est ignoré.

Notes

POSIX exige qu'une erreur de pôle se produise si arg vaut ±0.

La valeur de l'exposant renvoyée par logb est toujours 1 de moins que l'exposant renvoyé par frexp, en raison des exigences de normalisation différentes : pour l'exposant e renvoyé par logb, |argr-e
| est compris entre 1 et r (généralement entre 1 et 2), mais pour l'exposant e renvoyé par frexp, |arg2-e
| est compris entre 0.5 et 1.

Exemple

Compare différentes fonctions de décomposition des nombres à virgule flottante.

#include <fenv.h>
#include <float.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON

int main(void)
{
    double f = 123.45;
    printf("Given the number %.2f or %a in hex,\n", f, f);

    double f3;
    double f2 = modf(f, &f3);
    printf("modf() makes %.0f + %.2f\n", f3, f2);

    int i;
    f2 = frexp(f, &i);
    printf("frexp() makes %f * 2^%d\n", f2, i);

    i = logb(f);
    printf("logb()/logb() make %f * %d^%d\n", f/scalbn(1.0, i), FLT_RADIX, i);

    // gestion des erreurs
    feclearexcept(FE_ALL_EXCEPT);
    printf("logb(0) = %f\n", logb(0));
    if (fetestexcept(FE_DIVBYZERO))
        puts("    FE_DIVBYZERO raised");
}

Sortie possible :

Given the number 123.45 or 0x1.edccccccccccdp+6 in hex,
modf() makes 123 + 0.45
frexp() makes 0.964453 * 2^7
logb()/logb() make 1.928906 * 2^6
logb(0) = -Inf
    FE_DIVBYZERO raised
