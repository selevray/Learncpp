asin, asinf, asinl

_Decimal128 asind128( _Decimal128 arg );  // (6) (depuis C23)

Défini dans l'en-tête <tgmath.h>

#define asin( arg )  // (7) (depuis C99)

1-6) Calcule les valeurs principales de l'arc sinus de arg.

  1. Macro générique par type : si l'argument a le type long double, (3) (asinl) est appelée. Sinon, si l'argument a un type entier ou le type double, (2) (asin) est appelée. Sinon, (1) (asinf) est appelée. Si l'argument est complexe, la macro appelle la fonction complexe correspondante (casinf, casin, casinl).

Les fonctions (4-6) sont déclarées si et seulement si l'implémentation prédéfinit __STDC_IEC_60559_DFP__ (c'est-à-dire si l'implémentation prend en charge les nombres à virgule flottante décimaux).

(depuis C23)

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne se produit, l'arc sinus de arg (arcsin(arg)) dans l'intervalle [-

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Une erreur de domaine se produit si arg est en dehors de l'intervalle [-1.0; 1.0].

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559) :

  • si l'argument vaut ±0, il est renvoyé sans modification ;
  • si |arg| > 1, une erreur de domaine se produit et NaN est renvoyé ;
  • si l'argument est NaN, NaN est renvoyé.

Exemple

#include <errno.h>
#include <fenv.h>
#include <math.h>
#include <stdio.h>
#include <string.h>

#ifndef __GNUC__
#pragma STDC FENV_ACCESS ON
#endif

int main(void)
{
    printf("asin( 1.0) = %+f, 2*asin( 1.0)=%+f\n", asin(1), 2 * asin(1));
    printf("asin(-0.5) = %+f, 6*asin(-0.5)=%+f\n", asin(-0.5), 6 * asin(-0.5));

    // valeurs spéciales
    printf("asin(0.0) = %1f, asin(-0.0)=%f\n", asin(+0.0), asin(-0.0));

    // gestion des erreurs
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("asin(1.1) = %f\n", asin(1.1));
    if (errno == EDOM)
        perror("    errno == EDOM");
    if (fetestexcept(FE_INVALID))
        puts("    FE_INVALID raised");
}
