acos, acosf, acosl

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       acosf( float arg );  // (1) (depuis C99)

double      acos( double arg );  // (2)

long double acosl( long double arg );  // (3) (depuis C99)

_Decimal32  acosd32( _Decimal32 arg );  // (4) (depuis C23)

_Decimal64  acosd64( _Decimal64 arg );  // (5) (depuis C23)

_Decimal128 acosd128( _Decimal128 arg );  // (6) (depuis C23)

Défini dans l'en-tête <tgmath.h>

#define acos( arg )  // (7) (depuis C99)

1-6) Calcule la valeur principale de l'arc cosinus de arg.

  1. Macro générique par type : si l'argument a le type long double, (3) (acosl) est appelée. Sinon, si l'argument a un type entier ou le type double, (2) (acos) est appelée. Sinon, (1) (acosf) est appelée. Si l'argument est complexe, la macro appelle la fonction complexe correspondante (cacosf, cacos, cacosl).

Les fonctions (4-6) sont déclarées si et seulement si l'implémentation prédéfinit __STDC_IEC_60559_DFP__ (c'est-à-dire si l'implémentation prend en charge les nombres à virgule flottante décimaux).

(depuis C23)

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne se produit, l'arc cosinus de arg (arccos(arg)) dans l'intervalle [0 ; π] est renvoyé.

Si une erreur de domaine se produit, une valeur définie par l'implémentation est renvoyée (NaN lorsque pris en charge).

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Une erreur de domaine se produit si arg est en dehors de l'intervalle [-1.0; 1.0].

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559) :

  • Si l'argument est +1, la valeur +0 est renvoyée ;
  • Si |arg| > 1, une erreur de domaine se produit et NaN est renvoyé ;
  • si l'argument est NaN, NaN est renvoyé.

Exemple

#include <errno.h>
#include <fenv.h>
#include <math.h>
#include <stdio.h>
#include <string.h>

#ifndef __GNUC__
#pragma STDC FENV_ACCESS ON
#endif

int main(void)
{
    printf("acos(-1) = %f\n", acos(-1));
    printf("acos(0.0) = %f 2*acos(0.0) = %f\n", acos(0), 2 * acos(0));
    printf("acos(0.5) = %f 3*acos(0.5) = %f\n", acos(0.5), 3 * acos(0.5));
    printf("acos(1) = %f\n", acos(1));

    // gestion des erreurs
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("acos(1.1) = %f\n", acos(1.1));
    if (errno == EDOM)
        perror("    errno == EDOM");
    if (fetestexcept(FE_INVALID))
        puts("    FE_INVALID raised");
}
