tgamma, tgammaf, tgammal

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <math.h>

float       tgammaf( float arg );  // (1) (depuis C99)

double      tgamma( double arg );  // (2) (depuis C99)

long double tgammal( long double arg );  // (3) (depuis C99)

Défini dans l'en-tête <tgmath.h>

#define tgamma( arg )  // (4) (depuis C99)

1-3) Calcule la fonction gamma de arg.

  1. Macro générique au type : si arg est de type long double, tgammal est appelée. Sinon, si arg est de type entier ou de type double, tgamma est appelée. Sinon, tgammaf est appelée.

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne survient, la valeur de la fonction gamma de arg, c'est-à-dire (\Gamma(\mathtt{arg}) = \displaystyle\int_0^\infty!! t^{\mathtt{arg}-1} e^{-t}, dt)∫∞
0targ-1
e-t dt, est renvoyée.

Si une erreur de domaine se produit, une valeur définie par l'implémentation (NaN lorsque pris en charge) est renvoyée.

Si une erreur de pôle se produit, ±HUGE_VAL, ±HUGE_VALF ou ±HUGE_VALL est renvoyé.

Si une erreur d'intervalle due à un dépassement se produit, ±HUGE_VAL, ±HUGE_VALF ou ±HUGE_VALL est renvoyé.

Si une erreur de plage due à un sous-dépassement se produit, la valeur correcte (après arrondi) est renvoyée.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si arg vaut zéro ou est un entier négatif, une erreur de pôle ou une erreur de domaine peut se produire.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559) :

  • Si l'argument vaut ±0, ±∞ est renvoyé et FE_DIVBYZERO est levée.
  • Si l'argument est un entier négatif, NaN est renvoyé et FE_INVALID est levée.
  • Si l'argument vaut -∞, NaN est renvoyé et FE_INVALID est levée.
  • Si l'argument vaut +∞, +∞ est renvoyé.
  • Si l'argument est NaN, NaN est retourné.

Notes

Si arg est un entier naturel, tgamma(arg) est la factorielle de arg - 1. De nombreuses implémentations calculent la factorielle exacte dans le domaine entier si l'argument est un entier suffisamment petit.

Pour le type compatible IEEE double, un dépassement de capacité se produit si 0 < x < 1/DBL_MAX ou si x > 171.7.

POSIX exige qu'une erreur de pôle se produise si l'argument est nul, mais qu'une erreur de domaine se produise lorsque l'argument est un entier négatif. Il précise également qu'à l'avenir, les erreurs de domaine pourront être remplacées par des erreurs de pôle pour les arguments entiers négatifs (auquel cas la valeur de retour dans ces cas passerait de NaN à ±∞).

Il existe une fonction non standard nommée gamma dans diverses implémentations, mais sa définition est incohérente. Par exemple, la version glibc et 4.2BSD de gamma exécute lgamma, mais la version 4.4BSD de gamma exécute tgamma.

Exemple

#include <errno.h>
#include <fenv.h>
#include <float.h>
#include <math.h>
#include <stdio.h>
// #pragma STDC FENV_ACCESS ON

int main(void)
{
    printf("tgamma(10) = %f, 9!=%f\n", tgamma(10), 2 * 3 * 4 * 5 * 6 * 7 * 8 * 9.0);
    printf("tgamma(0.5) = %f, sqrt(pi) = %f\n", tgamma(0.5), sqrt(acos(-1)));

    // valeurs spéciales
    printf("tgamma(+Inf) = %f\n", tgamma(INFINITY));

    // gestion des erreurs
    errno = 0; feclearexcept(FE_ALL_EXCEPT);
    printf("tgamma(-1) = %f\n", tgamma(-1));
    if (errno == ERANGE)
        perror("    errno == ERANGE");
    else
        if (errno == EDOM)   perror("    errno == EDOM");
    if (fetestexcept(FE_DIVBYZERO))
        puts("    FE_DIVBYZERO raised");
    else if (fetestexcept(FE_INVALID))
        puts("    FE_INVALID raised");
}
