Défini dans l'en-tête <tgmath.h>

#define atan( arg )  // (7) (depuis C99)

1-6) Calcule la valeur principale de l'arc tangente de arg.

  1. Macro générique par type : si l'argument a le type long double, (3) (atanl) est appelée. Sinon, si l'argument a un type entier ou le type double, (2) (atan) est appelée. Sinon, (1) (atanf) est appelée. Si l'argument est complexe, la macro appelle la fonction complexe correspondante (catanf, catan, catanl).

Les fonctions (4-6) sont déclarées si et seulement si l'implémentation prédéfinit __STDC_IEC_60559_DFP__ (c'est-à-dire si l'implémentation prend en charge les nombres à virgule flottante décimaux).

(depuis C23)

Paramètres

  • arg — valeur à virgule flottante

Valeur de retour

Si aucune erreur ne se produit, l'arc tangente de arg (arctan(arg)) dans l'intervalle [-

] radians, est retournée.

Si une erreur d'intervalle due à un sous-dépassement se produit, le résultat correct (après arrondi) est renvoyé.

Gestion des erreurs

Les erreurs sont signalées comme spécifié dans math_errhandling.

Si l'implémentation prend en charge l'arithmétique à virgule flottante IEEE (CEI 60559) :

  • si l'argument vaut ±0, il est renvoyé sans modification ;
  • si l'argument vaut +∞, +π/2 est renvoyé ;
  • si l'argument vaut -∞, -π/2 est renvoyé ;
  • si l'argument est NaN, NaN est renvoyé.

Notes

POSIX spécifie qu'en cas de sous-dépassement, arg est retourné sans modification, et si cela n'est pas pris en charge, une valeur définie par l'implémentation non supérieure à DBL_MIN, FLT_MIN, et LDBL_MIN est retournée.

Exemple

#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("atan(1) = %f, 4*atan(1)=%f\n", atan(1), 4 * atan(1));
    // valeurs spéciales
    printf("atan(Inf) = %f, 2*atan(Inf) = %f\n", atan(INFINITY), 2 * atan(INFINITY));
    printf("atan(-0.0) = %+f, atan(+0.0) = %+f\n", atan(-0.0), atan(0));
}

Output:

atan(1) = 0.785398, 4*atan(1)=3.141593
atan(Inf) = 1.570796, 2*atan(Inf) = 3.141593
atan(-0.0) = -0.000000, atan(+0.0) = +0.000000
