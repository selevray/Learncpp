free

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

void free( void *ptr );

Désalloue l'espace précédemment alloué par malloc(), calloc(), aligned_alloc(), (depuis C11) ou realloc().

Si ptr est un pointeur nul, la fonction ne fait rien.

Le comportement est indéfini si la valeur de ptr n'est pas égale à une valeur renvoyée précédemment par malloc(), calloc(), realloc(), ou aligned_alloc() (depuis C11).

Le comportement est indéfini si la zone mémoire désignée par ptr a déjà été désallouée, c'est-à-dire si free(), free_sized(), free_aligned_sized() (depuis C23), ou realloc() a déjà été appelée avec ptr comme argument et qu'aucun appel à malloc(), calloc(), realloc(), ou aligned_alloc() (depuis C11) n'a ensuite produit un pointeur égal à ptr.

Le comportement est indéfini si, après le retour de free(), un accès est effectué via le pointeur ptr (sauf si une autre fonction d'allocation a produit par hasard une valeur de pointeur égale à ptr).

free est thread-safe : il se comporte comme s'il n'accédait qu'aux emplacements mémoire visibles à travers son argument, et non à aucun stockage statique.

Un appel à free qui désalloue une région de mémoire se synchronise avec un appel à toute fonction d'allocation ultérieure qui alloue la même région de mémoire, ou une partie de celle-ci. Cette synchronisation intervient après tout accès à la mémoire par la fonction de désallocation et avant tout accès à la mémoire par la fonction d'allocation. Il existe un ordre total unique de toutes les fonctions d'allocation et de désallocation opérant sur chaque région de mémoire donnée.

(depuis C11)

Paramètres

  • ptr — pointeur vers la mémoire à libérer

Valeur de retour

(aucune)

Notes

La fonction accepte le pointeur nul (et n'y fait rien) afin de réduire le nombre de cas particuliers. Que l'allocation réussisse ou non, le pointeur renvoyé par une fonction d'allocation peut être passé à free().

Exemple

#include <stdlib.h>

int main(void)
{
    int *p1 = malloc(10*sizeof *p1);
    free(p1); // tout pointeur alloué doit être libéré

    int *p2 = calloc(10, sizeof *p2);
    int *p3 = realloc(p2, 1000*sizeof *p3);
    if(p3) // p3 non nul signifie que p2 a été libéré par realloc
       free(p3);
    else // p3 nul signifie que p2 n'a pas été libéré
       free(p2);
}
