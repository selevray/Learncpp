realloc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

void *realloc( void *ptr, size_t new_size );

Réalloue la zone mémoire donnée. Si ptr n'est pas NULL, il doit avoir été alloué précédemment par malloc, calloc ou realloc et ne pas encore avoir été libéré par un appel à free ou realloc. Sinon, les résultats sont indéfinis.

La réallocation s'effectue soit :

a) en agrandissant ou en réduisant la zone existante désignée par ptr, si possible. Le contenu de la zone reste inchangé jusqu'à la plus petite des tailles nouvelle et ancienne. Si la zone est agrandie, le contenu de la nouvelle partie du tableau est indéfini.

b) en allouant un nouveau bloc mémoire de new_size octets, en copiant la zone mémoire d'une taille égale à la plus petite des tailles nouvelle et ancienne, et en libérant l'ancien bloc.

S'il n'y a pas assez de mémoire, l'ancien bloc mémoire n'est pas libéré et un pointeur nul est renvoyé.

Si ptr vaut NULL, le comportement est identique à celui d'un appel à malloc(new_size).

Sinon,

si new_size vaut zéro, le comportement est défini par l'implémentation (un pointeur nul peut être renvoyé (auquel cas l'ancien bloc mémoire peut ou non être libéré), ou un pointeur non nul peut être renvoyé, qui ne peut pas servir à accéder au stockage). Cet usage est obsolète (via C DR 400). (depuis C17)

(jusqu'à C23)

si new_size vaut zéro, le comportement est indéfini.

(depuis C23)

realloc est thread-safe : il se comporte comme s'il n'accédait qu'aux emplacements mémoire visibles à travers son argument, et non à aucun stockage statique.

Un appel précédent à free ou realloc qui désalloue une région de mémoire se synchronise avec un appel à toute fonction d'allocation, y compris realloc, qui alloue la même région de mémoire, ou une partie de celle-ci. Cette synchronisation intervient après tout accès à la mémoire par la fonction de désallocation et avant tout accès à la mémoire par realloc. Il existe un ordre total unique de toutes les fonctions d'allocation et de désallocation opérant sur chaque région de mémoire donnée.

(depuis C11)

Paramètres

  • ptr — pointeur vers la zone mémoire à réallouer
  • new_size — nouvelle taille du tableau en octets

Valeur de retour

En cas de succès, renvoie le pointeur vers le début de la mémoire nouvellement allouée. Pour éviter une fuite mémoire, le pointeur renvoyé doit être désalloué avec free ou realloc. Le pointeur d'origine ptr est invalidé et tout accès à celui-ci est un comportement indéfini (même si la réallocation a été effectuée sur place).

En cas d'échec, renvoie un pointeur nul. Le pointeur d'origine ptr reste valide et peut devoir être désalloué avec free ou realloc.

Notes

À l'origine (en C89), la prise en charge de la taille zéro a été ajoutée pour accueillir du code tel que

OBJ *p = calloc(0, sizeof(OBJ)); // placeholder de « longueur nulle »
/*...*/
while (1)
{
    p = realloc(p, c * sizeof(OBJ)); // réallocations jusqu'à ce que la taille se stabilise
    /* code qui peut modifier c ou sortir de la boucle */
}

Exemple

#include <assert.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

void print_storage_info(const int* next, const int* prev, int ints)
{
    if (next)
        printf("%s location: %p. Size: %d ints (%ld bytes).\n",
               (next != prev ? "New" : "Old"), (void*)next, ints, ints * sizeof(int));
    else
        printf("Allocation failed.\n");
}

int main(void)
{
    const int pattern[] = {1, 2, 3, 4, 5, 6, 7, 8};
    const int pattern_size = sizeof pattern / sizeof(int);
    int *next = NULL, *prev = NULL;

    if ((next = (int*)malloc(pattern_size * sizeof *next))) // alloue un tableau
    {
        memcpy(next, pattern, sizeof pattern); // remplit le tableau
        print_storage_info(next, prev, pattern_size);
    }
    else
        return EXIT_FAILURE;

    // Réalloue en boucle en utilisant les valeurs suivantes comme nouvelle taille de stockage.
    const int realloc_size[] = {10, 12, 512, 32768, 65536, 32768};

    for (int i = 0; i != sizeof realloc_size / sizeof(int); ++i)
    {
        if ((next = (int*)realloc(prev = next, realloc_size[i] * sizeof(int))))
        {
            print_storage_info(next, prev, realloc_size[i]);
            assert(!memcmp(next, pattern, sizeof pattern));  // le motif est-il conservé
        }
        else // si realloc échoue, le pointeur d'origine doit être libéré
        {
            free(prev);
            return EXIT_FAILURE;
        }
    }

    free(next); // enfin, libère le stockage
    return EXIT_SUCCESS;
}
