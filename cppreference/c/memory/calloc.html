calloc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

void* calloc( size_t num, size_t size );

Alloue de la mémoire pour un tableau de num objets de size et initialise tous les octets du stockage alloué à zéro.

Si l'allocation réussit, renvoie un pointeur vers le premier octet du bloc mémoire alloué, aligné de façon adaptée à tout type d'objet avec un alignement fondamental.

Si size vaut zéro, le comportement est défini par l'implémentation (un pointeur nul peut être renvoyé, ou un pointeur non nul pouvant ne pas être utilisé pour accéder au stockage).

calloc est thread-safe : il se comporte comme s'il n'accédait qu'aux emplacements mémoire visibles à travers son argument, et non à aucun stockage statique.

Un appel préalable à free, free_sized et free_aligned_sized (depuis C23) ou à realloc qui libère une région de mémoire se synchronise-avec un appel à calloc qui alloue la même région de mémoire ou une partie de celle-ci. Cette synchronisation intervient après tout accès à la mémoire par la fonction de libération et avant tout accès à la mémoire par calloc. Il existe un ordre total unique de toutes les fonctions d'allocation et de libération opérant sur chaque région de mémoire donnée.

(depuis C11)

Paramètres

  • num — nombre d'objets
  • size — taille de chaque objet

Valeur de retour

En cas de succès, retourne le pointeur vers le début de la mémoire nouvellement allouée. Pour éviter une fuite mémoire, le pointeur retourné doit être libéré avec free() ou realloc().

En cas d'échec, retourne un pointeur nul.

Notes

En raison des exigences d'alignement, le nombre d'octets alloués n'est pas nécessairement égal à num * size.

L'initialisation de tous les bits à zéro ne garantit pas qu'un nombre à virgule flottante ou un pointeur soit initialisé respectivement à 0.0 et à la valeur de pointeur nul (bien que cela soit vrai sur toutes les plateformes courantes).

À l'origine (en C89), la prise en charge de la taille zéro a été ajoutée pour accueillir du code tel que

OBJ* p = calloc(0, sizeof(OBJ)); // placeholder de « longueur nulle »
...
while(1)
{
    p = realloc(p, c * sizeof(OBJ)); // réallocations jusqu'à ce que la taille se stabilise
    ... // code qui peut modifier c ou sortir de la boucle
}

Exemple

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int* p1 = calloc(4, sizeof(int));    // alloue et met à zéro un tableau de 4 int
    int* p2 = calloc(1, sizeof(int[4])); // idem, en nommant directement le type du tableau
    int* p3 = calloc(4, sizeof *p3);     // identique, sans répéter le nom du type

    if (p2)
    {
        for (int n = 0; n < 4; ++n) // afficher le tableau
            printf("p2[%d] == %d\n", n, p2[n]);
    }

    free(p1);
    free(p2);
    free(p3);
}

Output:

p2[0] == 0
p2[1] == 0
p2[2] == 0
p2[3] == 0
