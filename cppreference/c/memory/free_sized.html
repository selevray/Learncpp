free_sized

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

void free_sized( void* ptr, size_t size );  // (depuis C23)

Désalloue l'espace précédemment alloué par malloc(), calloc() ou realloc() (mais pas par aligned_alloc()).
Cette section est incomplète Raison : partager la formulation avec la famille free_*

free_sized est thread-safe : il se comporte comme s'il n'accédait qu'aux emplacements mémoire visibles à travers son argument, et non à aucun stockage statique.

Un appel à free_sized qui désalloue une région de mémoire se synchronise avec un appel à toute fonction d'allocation ultérieure qui alloue la même région de mémoire, ou une partie de celle-ci. Cette synchronisation intervient après tout accès à la mémoire par la fonction de désallocation et avant tout accès à la mémoire par la fonction d'allocation. Il existe un ordre total unique de toutes les fonctions d'allocation et de désallocation opérant sur chaque région de mémoire donnée.

Paramètres

  • ptr — pointeur vers la mémoire à libérer
  • size — taille de la mémoire précédemment passée à une fonction d'allocation

Valeur de retour

(aucune)

Notes
Cette section est incomplète

Implémentation possible

void free_sized(void* ptr, size_t /*size*/)
{
    free(ptr);
}

Exemple

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct
{
    size_t size;     // nombre actuel d'éléments
    size_t capacity; // nombre d'éléments réservés
    void** data;
} PtrVector;

PtrVector vector_create(size_t initial_capacity)
{
    PtrVector ret =
    {
        .capacity = initial_capacity,
        .data = (void**) malloc(initial_capacity * sizeof(void*))
    };
    return ret;
}

void vector_delete(PtrVector* self)
{
    free_sized(self->data, self->capacity * sizeof(void*));
}

void vector_push_back(PtrVector* self, void* value)
{
    if (self->size == self->capacity)
    {
        self->capacity *= 2;
        self->data = (void**) realloc(self->data, self->capacity * sizeof(void*));
    }
    self->data[self->size++] = value;
}

int main()
{
    int data = 42;
    float pi = 3.141592f;
    PtrVector v = vector_create(8);
    vector_push_back(&v, &data);
    vector_push_back(&v, &pi);
    printf("data[0] = %i\n", *(int*)v.data[0]);
    printf("data[1] = %f\n", *(float*)v.data[1]);
    vector_delete(&v);
}

Output:

data[0] = 42
data[1] = 3.141592
