malloc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

void *malloc( size_t size );

Alloue size octets de stockage non initialisé.

En cas de succès, retourne un pointeur correctement aligné pour tout type d'objet ayant un alignement fondamental.

Si size vaut zéro, le comportement de malloc est défini par l'implémentation. Par exemple, un pointeur nul peut être retourné. Sinon, un pointeur non nul peut être retourné ; mais un tel pointeur ne doit pas être déréférencé, et doit être passé à free pour éviter les fuites mémoire.

malloc est thread-safe : il se comporte comme s'il n'accédait qu'aux emplacements mémoire visibles à travers son argument, et non à aucun stockage statique.

Un appel préalable à free, free_sized et free_aligned_sized (depuis C23) ou à realloc qui libère une région de mémoire se synchronise-avec un appel à malloc qui alloue la même région de mémoire ou une partie de celle-ci. Cette synchronisation intervient après tout accès à la mémoire par la fonction de libération et avant tout accès à la mémoire par malloc. Il existe un ordre total unique de toutes les fonctions d'allocation et de libération opérant sur chaque région de mémoire donnée.

(depuis C11)

Paramètres

  • size — nombre d'octets à allouer

Valeur de retour

En cas de succès, retourne le pointeur vers le début de la mémoire nouvellement allouée. Pour éviter une fuite mémoire, le pointeur retourné doit être libéré avec free() ou realloc().

En cas d'échec, retourne un pointeur nul.

Exemple

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *p1 = malloc(4*sizeof(int));  // alloue de quoi stocker un tableau de 4 int
    int *p2 = malloc(sizeof(int[4])); // identique, en nommant directement le type
    int *p3 = malloc(4*sizeof *p3);   // identique, sans répéter le nom du type

    if(p1) {
        for(int n=0; n<4; ++n) // remplit le tableau
            p1[n] = n*n;
        for(int n=0; n<4; ++n) // l'affiche à nouveau
            printf("p1[%d] == %d\n", n, p1[n]);
    }

    free(p1);
    free(p2);
    free(p3);
}

Output:

p1[0] == 0
p1[1] == 1
p1[2] == 4
p1[3] == 9
