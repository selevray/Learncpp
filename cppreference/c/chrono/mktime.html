mktime

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <time.h>

time_t mktime( struct tm* arg );

Renormalise le temps calendaire local exprimé sous forme d'objet struct tm, et le convertit également en temps écoulé depuis l'époque sous forme d'objet time_t. arg->tm_wday et arg->tm_yday sont ignorés. Les valeurs de arg ne sont pas vérifiées quant à un dépassement de plage.

Une valeur négative de arg->tm_isdst amène mktime à tenter de déterminer si l'heure d'été était en vigueur à l'instant indiqué.

Si la conversion vers time_t réussit, l'objet arg est modifié. Tous les champs de arg sont mis à jour pour rentrer dans leurs plages valides. arg->tm_wday et arg->tm_yday sont recalculés à partir des informations disponibles dans les autres champs.

Paramètres

  • arg — pointeur vers un objet tm spécifiant l'heure locale du calendrier à convertir

Valeur de retour

temps écoulé depuis l'époque sous forme d'objet time_t en cas de succès, ou -1 si arg ne peut pas être représenté sous forme d'objet time_t (POSIX exige aussi que EOVERFLOW soit stocké dans errno dans ce cas).

Notes

Si l'objet struct tm a été obtenu à partir de strptime POSIX ou d'une fonction équivalente, la valeur de tm_isdst est indéterminée et doit être définie explicitement avant d'appeler mktime.

Exemple

#define _POSIX_C_SOURCE 200112L // for setenv on gcc
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void)
{
    setenv("TZ", "/usr/share/zoneinfo/America/New_York", 1); // Spécifique à POSIX

    struct tm tm = *localtime(&(time_t){time(NULL)});
    printf("Today is           %s", asctime(&tm));
    printf("(DST is %s)\n", tm.tm_isdst ? "in effect" : "not in effect");
    tm.tm_mon -= 100;  // tm_mon est désormais en dehors de sa plage normale
    mktime(&tm);       // tm_isdst n'est pas défini à -1 ; le statut de l'heure d'été du jour est utilisé
    printf("100 months ago was %s", asctime(&tm));
    printf("(DST was %s)\n", tm.tm_isdst ? "in effect" : "not in effect");
}

Sortie possible :

Today is           Fri Apr 22 11:53:36 2016
(DST is in effect)
100 months ago was Sat Dec 22 10:53:36 2007
(DST was not in effect)
