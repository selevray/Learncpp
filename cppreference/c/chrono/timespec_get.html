timespec_get

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <time.h>

int timespec_get( struct timespec *ts, int base );  // (1) (depuis C11)

#define TIME_UTC /* implementation-defined */  // (2) (depuis C11)

  1. Modifie l'objet timespec pointé par ts pour contenir l'heure calendaire courante dans la base de temps base.

  2. Se développe en une valeur utilisable comme argument base de timespec_get

D'autres constantes macro commençant par TIME_ peuvent être fournies par l'implémentation pour indiquer des bases de temps supplémentaires

Si base vaut TIME_UTC, alors

  • ts->tv_sec est défini au nombre de secondes écoulées depuis une époque définie par l'implémentation, tronqué à une valeur entière
  • Le membre ts->tv_nsec reçoit le nombre entier de nanosecondes, arrondi à la résolution de l'horloge système

Paramètres

  • ts — pointeur vers un objet de type struct timespec
  • base — TIME_UTC ou une autre valeur entière non nulle indiquant la base de temps

Valeur de retour

La valeur de base en cas de succès, zéro sinon.

Notes

La fonction POSIX clock_gettime(CLOCK_REALTIME, ts) peut également être utilisée pour remplir un timespec avec le temps écoulé depuis l'Epoch.

Exemple

#include <stdio.h>
#include <time.h>

int main(void)
{
    struct timespec ts;
    timespec_get(&ts, TIME_UTC);
    char buff[100];
    strftime(buff, sizeof buff, "%D %T", gmtime(&ts.tv_sec));
    printf("Current time: %s.%09ld UTC\n", buff, ts.tv_nsec);
}
