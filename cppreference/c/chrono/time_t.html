typedef /* unspecified */ time_t;

Type arithmétique réel capable de représenter des instants.

Bien que non défini par la norme C, il s'agit presque toujours d'une valeur entière contenant le nombre de secondes (sans compter les secondes intercalaires) écoulées depuis 00:00, le 1er janvier 1970 UTC, correspondant à l'heure POSIX.

Notes

La norme utilise le terme heure calendaire pour désigner une valeur de type time_t.

Exemple

Affiche le début de l'époque.

#include <stdio.h>
#include <time.h>
#include <stdint.h>

int main(void)
{
    time_t epoch = 0;
    printf("%jd seconds since the epoch began\n", (intmax_t)epoch);
    printf("%s", asctime(gmtime(&epoch)));
}

Sortie possible :

0 seconds since the epoch began
Thu Jan  1 00:00:00 1970
