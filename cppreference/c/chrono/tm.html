struct tm;

Structure contenant une date et une heure calendaires décomposées en leurs composantes.

Objets membres

  • int tm_sec — secondes après la minute – [[0,61] (jusqu'à C99) | [0,60] (depuis C99)][note 1] (objet membre public)
  • int tm_min — minutes après l'heure – [0,59] (objet membre public)
  • int tm_hour — heures depuis minuit – [0,23] (objet membre public)
  • int tm_mday — jour du mois – [1,31] (objet membre public)
  • int tm_mon — mois depuis janvier – [0,11] (objet membre public)
  • int tm_year — années depuis 1900 (objet membre public)
  • int tm_wday — jours depuis dimanche – [0,6] (objet membre public)
  • int tm_yday — jours depuis le 1er janvier – [0,365] (objet membre public)
  • int tm_isdst — Indicateur d'heure d'été. La valeur est positive si l'heure d'été est en vigueur, nulle si ce n'est pas le cas, et négative si aucune information n'est disponible (objet membre public)
Notes

La norme impose uniquement la présence des membres susmentionnés, dans un ordre quelconque. Les implémentations ajoutent généralement d'autres membres de données à cette structure.

  1. ↑ L'intervalle autorise une seconde intercalaire positive. Deux secondes intercalaires dans la même minute ne sont pas autorisées (l'intervalle 0..61 de C89 était un défaut)

Exemple

#include <stdio.h>
#include <time.h>

int main(void)
{
    struct tm start = {.tm_year = 2022 - 1900, .tm_mday = 1};
    mktime(&start);
    printf("%s", asctime(&start)); // note : '\n' final implicite
}

Output:

Sat Jan  1 00:00:00 2022
