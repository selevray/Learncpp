atomic_is_lock_free

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdatomic.h>

_Bool atomic_is_lock_free( const volatile A* obj );  // (depuis C11)

Détermine si les opérations atomiques sur tous les objets de type A (le type de l'objet pointé par obj) sont sans verrou (lock-free). Pour une exécution donnée du programme, le résultat de l'appel de atomic_is_lock_free est le même pour tous les pointeurs du même type.

Il s'agit d'une fonction générique définie pour tous les types d'objets atomiques A. L'argument est un pointeur vers un type atomique volatile, afin d'accepter les adresses d'objets atomiques non volatiles et volatiles (par exemple des E/S mappées en mémoire), et la sémantique volatile est préservée lorsque cette opération est appliquée à des objets atomiques volatiles.

Il n'est pas spécifié si le nom d'une fonction générique est une macro ou un identifiant déclaré avec une liaison externe. Si une définition de macro est supprimée afin d'accéder à la fonction réelle (par exemple en la mettant entre parenthèses comme (atomic_is_lock_free)(...)), ou si un programme définit un identifiant externe portant le nom d'une fonction générique, le comportement est indéfini.

Paramètres

  • obj — pointeur vers l'objet atomique à examiner

Valeur de retour

true si les opérations sur tous les objets de type A sont sans verrou, false sinon.

Exemple

#include <stdio.h>
#include <stdatomic.h>

_Atomic struct A { int a[100]; } a;
_Atomic struct B { int x, y; } b;
int main(void)
{
    printf("_Atomic struct A is lock free? %s\n",
            atomic_is_lock_free(&a) ? "true" : "false");
    printf("_Atomic struct B is lock free? %s\n",
            atomic_is_lock_free(&b) ? "true" : "false");
}

Sortie possible :

_Atomic struct A is lock free? false
_Atomic struct B is lock free? true
