typedef struct /* unspecified */ atomic_flag;  // (depuis C11)

atomic_flag est un type booléen atomique. Contrairement aux autres types atomiques, il est garanti sans verrou (lock-free). Contrairement à atomic_bool, atomic_flag ne fournit pas d'opérations de lecture ou d'écriture.
