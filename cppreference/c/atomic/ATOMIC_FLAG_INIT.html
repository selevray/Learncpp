ATOMIC_FLAG_INIT

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdatomic.h>

#define ATOMIC_FLAG_INIT /* unspecified */  // (depuis C11)

Se développe en un initialiseur utilisable pour initialiser le type atomic_flag à l'état clair. La valeur d'un atomic_flag non initialisé à l'aide de cette macro est indéterminée.

Exemple

#include <stdatomic.h>

atomic_flag flag = ATOMIC_FLAG_INIT;
