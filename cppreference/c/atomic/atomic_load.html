atomic_load, atomic_load_explicit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdatomic.h>

C atomic_load( const volatile A* obj );  // (1) (depuis C11)

C atomic_load_explicit( const volatile A* obj, memory_order order );  // (2) (depuis C11)

Lit de manière atomique et renvoie la valeur courante de la variable atomique pointée par obj. L'opération est une opération de lecture atomique.

La première version ordonne les accès mémoire selon memory_order_seq_cst, la seconde version ordonne les accès mémoire selon order. order doit être l'une de memory_order_relaxed, memory_order_consume, memory_order_acquire ou memory_order_seq_cst. Sinon, le comportement est indéfini.

Il s'agit d'un modèle de fonction générique défini pour tous les types d'objets atomiques A. L'argument est un pointeur vers un type atomique volatile afin d'accepter les adresses d'objets atomiques non volatiles et volatiles (par exemple les E/S mappées en mémoire), et la sémantique volatile est préservée lorsque cette opération est appliquée à des objets atomiques volatiles. C est le type non atomique correspondant à A.

Il n'est pas spécifié si le nom d'une fonction générique est une macro ou un identifiant déclaré avec une liaison externe. Si une définition de macro est supprimée afin d'accéder à la fonction réelle (par exemple en la mettant entre parenthèses comme (atomic_load)(...)), ou si un programme définit un identifiant externe portant le nom d'une fonction générique, le comportement est indéfini.

Paramètres

  • obj — pointeur vers l'objet atomique à accéder
  • order — l'ordonnancement de synchronisation mémoire pour cette opération

Valeur de retour

La valeur courante de la variable atomique pointée par obj.
