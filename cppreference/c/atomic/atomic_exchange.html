atomic_exchange, atomic_exchange_explicit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdatomic.h>

C atomic_exchange( volatile A* obj, C desired );  // (1) (depuis C11)

C atomic_exchange_explicit( volatile A* obj, C desired, memory_order order );  // (2) (depuis C11)

Remplace atomiquement la valeur pointée par obj par desired et renvoie la valeur obj détenue précédemment. L'opération est une opération de lecture-modification-écriture. La première version ordonne les accès mémoire selon memory_order_seq_cst, la seconde version ordonne les accès mémoire selon order.

Il s'agit d'un modèle de fonction générique défini pour tous les types d'objets atomiques A. L'argument est un pointeur vers un type atomique volatile afin d'accepter les adresses d'objets atomiques non volatiles et volatiles (par exemple les E/S mappées en mémoire), et la sémantique volatile est préservée lorsque cette opération est appliquée à des objets atomiques volatiles. C est le type non atomique correspondant à A.

Il n'est pas spécifié si le nom d'une fonction générique est une macro ou un identifiant déclaré avec une liaison externe. Si une définition de macro est supprimée afin d'accéder à la fonction réelle (par exemple en la mettant entre parenthèses comme (atomic_exchange)(...)), ou si un programme définit un identifiant externe portant le nom d'une fonction générique, le comportement est indéfini..

Paramètres

  • obj — pointeur vers l'objet atomique à modifier
  • desired — la valeur par laquelle remplacer l'objet atomique
  • order — l'ordonnancement de synchronisation mémoire pour cette opération : toutes les valeurs sont autorisées

Valeur de retour

La valeur détenue précédemment par l'objet atomique pointé par obj.
