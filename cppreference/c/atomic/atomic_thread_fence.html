void atomic_thread_fence( memory_order order );  // (depuis C11)

Établit une synchronisation d'ordre mémoire entre les accès non atomiques et les accès atomiques relâchés, selon ce qu'indique order, sans opération atomique associée. Par exemple, tous les stockages non atomiques et atomiques relâchés qui se produisent avant une barrière memory_order_release dans le thread A seront synchronisés avec les chargements non atomiques et atomiques relâchés des mêmes emplacements effectués dans le thread B après une barrière memory_order_acquire.

Paramètres

  • order — l'ordre mémoire exécuté par cette barrière

Valeur de retour

(aucune)
