atomic_flag_clear, atomic_flag_clear_explicit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdatomic.h>

void atomic_flag_clear( volatile atomic_flag* obj );  // (1) (depuis C11)

void atomic_flag_clear_explicit( volatile atomic_flag* obj, memory_order order );  // (2) (depuis C11)

Modifie de manière atomique l'état d'un atomic_flag pointé par obj pour le remettre à zéro (false). La première version ordonne les accès mémoire selon memory_order_seq_cst, la seconde version ordonne les accès mémoire selon order.

L'argument est un pointeur vers un atomic_flag volatile, afin d'accepter les adresses d'atomic_flag non volatiles et volatiles (par exemple des E/S mappées en mémoire).

Paramètres

  • obj — pointeur vers l'objet atomic_flag à modifier
  • order — l'ordonnancement de synchronisation mémoire pour cette opération : toutes les valeurs sont autorisées

Valeur de retour

(aucune)
