atomic_init

void atomic_init( volatile A* obj, C desired );  // (depuis C11)

Initialise l'objet atomique obj construit par défaut avec la valeur desired. La fonction n'est pas atomique : un accès concurrent depuis un autre thread, même via une opération atomique, constitue une course aux données.

Il s'agit d'un modèle de fonction générique défini pour tous les types d'objets atomiques A. L'argument est un pointeur vers un type atomique volatile afin d'accepter les adresses d'objets atomiques non volatiles et volatiles (par exemple les E/S mappées en mémoire), et la sémantique volatile est préservée lorsque cette opération est appliquée à des objets atomiques volatiles. C est le type non atomique correspondant à A.

Il n'est pas spécifié si le nom d'une fonction générique est une macro ou un identifiant déclaré avec une liaison externe. Si une définition de macro est supprimée afin d'accéder à la fonction réelle (par exemple en la mettant entre parenthèses comme (atomic_init)(...)), ou si un programme définit un identifiant externe portant le nom d'une fonction générique, le comportement est indéfini.

Paramètres

  • obj — pointeur vers un objet atomique à initialiser
  • desired — la valeur avec laquelle initialiser l'objet atomique

Valeur de retour

(aucune)

Notes

atomic_init est le seul moyen d'initialiser des objets atomiques alloués dynamiquement. Par exemple :

_Atomic int *p = malloc(sizeof(_Atomic int));
atomic_init(p, 42);
