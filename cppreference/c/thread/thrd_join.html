thrd_join

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <threads.h>

int thrd_join( thrd_t thr, int *res );  // (depuis C11)

Bloque le thread courant jusqu'à ce que le thread identifié par thr termine son exécution.

Si res n'est pas un pointeur nul, le code de résultat du thread est placé à l'emplacement pointé par res.

La fin du thread synchronizes-with la fin de cette fonction.

Le comportement est indéfini si le thread a été précédemment détaché ou joint par un autre thread.

Paramètres

  • thr — identifiant du thread à joindre
  • res — emplacement où placer le code de résultat

Valeur de retour

thrd_success en cas de succès, thrd_error sinon.
