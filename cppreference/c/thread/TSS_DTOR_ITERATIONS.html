TSS_DTOR_ITERATIONS

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <threads.h>

#define TSS_DTOR_ITERATIONS /* unspecified */  // (depuis C11)

Se développe en une expression constante entière positive définissant le nombre maximal de fois où un destructeur de pointeur de stockage local au thread sera appelé par thrd_exit.

Cette constante est équivalente au PTHREAD_DESTRUCTOR_ITERATIONS de POSIX.
