tss_get

void *tss_get( tss_t tss_key );  // (depuis C11)

Renvoie la valeur contenue dans le stockage propre au thread courant identifié par tss_key. Différents threads peuvent obtenir des valeurs différentes identifiées par la même clé.

Au démarrage d'un thread (voir thrd_create), les valeurs associées à toutes les clés TSS sont NULL. Une valeur différente peut être placée dans le stockage propre au thread avec tss_set.

Paramètres

  • tss_key — clé de stockage propre au thread, obtenue via tss_create et non supprimée par tss_delete

Valeur de retour

La valeur en cas de succès, NULL en cas d'échec.

Notes

L'équivalent POSIX de cette fonction est pthread_getspecific.
