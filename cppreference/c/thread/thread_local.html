Défini dans l'en-tête <threads.h>

#define thread_local _Thread_local  // (depuis C11) (supprimé en C23)

Macro pratique permettant de spécifier qu'un objet a une durée de stockage locale au thread.

Notes

Depuis C23, thread_local est lui-même un mot-clé, qui peut aussi être une macro prédéfinie, donc <threads.h> ne le fournit plus.
