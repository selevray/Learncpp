call_once, once_flag, ONCE_FLAG_INIT

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <threads.h>

void call_once( once_flag* flag, void (*func)(void) );  // (1) (depuis C11)

typedef /* unspecified */ once_flag  // (2) (depuis C11)

#define ONCE_FLAG_INIT /* unspecified */  // (3) (depuis C11)

  1. appelle la fonction func exactement une fois, même si elle est invoquée depuis plusieurs threads. La fin de la fonction func se synchronise avec tous les appels précédents ou suivants à call_once avec la même variable flag.

  2. Type d'objet complet capable de contenir un drapeau utilisé par call_once.

  3. Se développe en une valeur pouvant servir à initialiser un objet de type once_flag.

Paramètres

  • flag — pointeur vers un objet de type call_once utilisé pour garantir que func n'est appelée qu'une seule fois
  • func — la fonction à exécuter une seule fois

Valeur de retour

(aucune)

Notes

L'équivalent POSIX de cette fonction est pthread_once.

Exemple

#include <stdio.h>
#include <threads.h>

void do_once(void) {
    puts("called once");
}

static once_flag flag = ONCE_FLAG_INIT;
int func(void* data)
{
    call_once(&flag, do_once);
}

int main(void)
{
    thrd_t t1, t2, t3, t4;
    thrd_create(&t1, func, NULL);
    thrd_create(&t2, func, NULL);
    thrd_create(&t3, func, NULL);
    thrd_create(&t4, func, NULL);

    thrd_join(t1, NULL);
    thrd_join(t2, NULL);
    thrd_join(t3, NULL);
    thrd_join(t4, NULL);
}

Output:

called once
