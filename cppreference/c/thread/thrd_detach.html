thrd_detach

Défini dans l'en-tête <threads.h>

int thrd_detach( thrd_t thr );  // (depuis C11)

Détache le thread identifié par thr de l'environnement courant. Les ressources détenues par le thread seront libérées automatiquement une fois le thread terminé.

Paramètres

  • thr — identifiant du thread à détacher

Valeur de retour

thrd_success en cas de succès, thrd_error sinon.
