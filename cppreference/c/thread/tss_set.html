tss_set

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <threads.h>

int tss_set( tss_t tss_id, void *val );  // (depuis C11)

Définit la valeur du stockage propre au thread identifié par tss_id pour le thread courant à val. Différents threads peuvent définir des valeurs différentes pour la même clé.

Le destructeur, s'il existe, n'est pas invoqué.

Paramètres

  • tss_id — clé de stockage propre au thread, obtenue via tss_create et non supprimée par tss_delete
  • val — valeur à affecter au stockage propre au thread

Valeur de retour

thrd_success en cas de succès, thrd_error sinon.

Notes

L'équivalent POSIX de cette fonction est pthread_setspecific.

En général, TSS sert à stocker des pointeurs vers des blocs de mémoire allouée dynamiquement, réservés à l'usage du thread appelant.

tss_set peut être appelée dans le destructeur TSS. Si le destructeur se termine avec une valeur non NULL dans le stockage TSS, elle sera réessayée par thrd_exit jusqu'à TSS_DTOR_ITERATIONS fois, après quoi le stockage sera perdu.
