cnd_signal

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <threads.h>

int cnd_signal( cnd_t *cond );  // (depuis C11)

Débloque un thread qui attend actuellement sur la variable de condition pointée par cond. Si aucun thread n'est bloqué, ne fait rien et renvoie thrd_success.

Paramètres

  • cond — pointeur vers une variable de condition

Valeur de retour

thrd_success en cas de succès, thrd_error sinon.
