mtx_lock

Défini dans l'en-tête <threads.h>

int mtx_lock( mtx_t* mutex );  // (depuis C11)

Bloque le thread courant jusqu'à ce que le mutex pointé par mutex soit verrouillé.

Le comportement est indéfini si le thread courant a déjà verrouillé le mutex et que le mutex n'est pas récursif.

Les appels précédents à mtx_unlock sur le même mutex se synchronisent avec cette opération, et toutes les opérations de verrouillage/déverrouillage sur un mutex donné forment un ordre total unique (similaire à l'ordre de modification d'un atomique)

Paramètres

  • mutex — pointeur vers le mutex à verrouiller

Valeur de retour

thrd_success en cas de succès, thrd_error sinon.
