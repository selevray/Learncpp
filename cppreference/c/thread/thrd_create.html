thrd_create

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <threads.h>

int thrd_create( thrd_t *thr, thrd_start_t func, void *arg );  // (depuis C11)

Crée un nouveau thread exécutant la fonction func. La fonction est invoquée comme func(arg).

En cas de succès, l'objet pointé par thr reçoit l'identifiant du nouveau thread.

La fin de cette fonction se synchronise avec le début du thread.

Paramètres

  • thr — pointeur vers l'emplacement mémoire où placer l'identifiant du nouveau thread
  • func — fonction à exécuter
  • arg — argument à passer à la fonction

Valeur de retour

thrd_success si la création du nouveau thread a réussi. Sinon retourne thrd_nomem s'il n'y a pas assez de mémoire, ou thrd_error si une autre erreur est survenue.

Notes

Les identifiants de threads peuvent être réutilisés pour de nouveaux threads une fois le thread terminé et joint ou détaché.

Le type thrd_start_t est un typedef de int(*)(void*), qui diffère de l'équivalent POSIX void*(*)(void*)

Toutes les valeurs de stockage propres au thread (voir tss_create) sont initialisées à NULL.

Le retour de la fonction func équivaut à un appel de thrd_exit avec pour argument la valeur de retour de func.
