cnd_timedwait

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <threads.h>

int cnd_timedwait( cnd_t* restrict cond, mtx_t* restrict mutex,
                   const struct timespec* restrict time_point );  // (depuis C11)

Déverrouille atomiquement le mutex pointé par mutex et se bloque sur la variable de condition pointée par cond jusqu'à ce que le thread soit signalé par cnd_signal ou cnd_broadcast, ou jusqu'à ce que le point temporel basé sur TIME_UTC pointé par time_point soit atteint, ou jusqu'à ce qu'un réveil fallacieux se produise. Le mutex est de nouveau verrouillé avant le retour de la fonction.

Le comportement est indéfini si le mutex n'est pas déjà verrouillé par le thread appelant.

Paramètres

  • cond — pointeur vers la variable de condition sur laquelle se bloquer
  • mutex — pointeur vers le mutex à déverrouiller pendant toute la durée du blocage
  • time_point — pointeur vers un objet spécifiant le délai d'attente jusqu'à atteindre

Valeur de retour

thrd_success en cas de succès, thrd_timedout si le délai d'attente a été atteint avant que le mutex ne soit verrouillé, ou thrd_error si une erreur s'est produite.
