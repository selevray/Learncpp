cnd_init

Défini dans l'en-tête <threads.h>

int cnd_init( cnd_t* cond );  // (depuis C11)

Initialise une nouvelle variable de condition. L'objet pointé par cond reçoit une valeur identifiant la variable de condition.

Paramètres

  • cond — pointeur vers une variable destinée à stocker l'identifiant de la variable de condition

Valeur de retour

thrd_success si la variable de condition a été créée avec succès. Sinon, renvoie thrd_nomem s'il n'y a pas assez de mémoire, ou thrd_error si une autre erreur s'est produite.
