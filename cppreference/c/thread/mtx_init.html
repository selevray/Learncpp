mtx_init

int mtx_init( mtx_t* mutex, int type );  // (depuis C11)

Crée un nouvel objet mutex avec type. L'objet pointé par mutex reçoit un identifiant du mutex nouvellement créé.

type doit prendre l'une des valeurs suivantes :

  • mtx_plain - un mutex simple, non récursif, est créé.
  • mtx_timed - un mutex non récursif, prenant en charge le délai d'attente, est créé.
  • mtx_plain | mtx_recursive - un mutex récursif est créé.
  • mtx_timed | mtx_recursive - un mutex récursif, prenant en charge le délai d'attente, est créé.

Paramètres

  • mutex — pointeur vers le mutex à initialiser
  • type — le type du mutex

Valeur de retour

thrd_success en cas de succès, thrd_error sinon.
