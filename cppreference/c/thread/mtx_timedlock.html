mtx_timedlock

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <threads.h>

int mtx_timedlock( mtx_t *restrict mutex,
                   const struct timespec *restrict time_point );  // (depuis C11)

Bloque le thread courant jusqu'à ce que le mutex pointé par mutex soit verrouillé ou jusqu'à ce que le point temporel absolu du calendrier basé sur TIME_UTC, pointé par time_point, soit atteint.

Cette fonction prenant un temps absolu, si une durée est nécessaire, le point temporel du calendrier doit être calculé manuellement.

Le comportement est indéfini si le thread courant a déjà verrouillé le mutex et que le mutex n'est pas récursif.

Le comportement est indéfini si le mutex ne prend pas en charge les délais d'attente.

Les appels précédents à mtx_unlock sur le même mutex se synchronisent avec cette opération (si cette opération réussit), et toutes les opérations de verrouillage/déverrouillage sur un mutex donné forment un ordre total unique (similaire à l'ordre de modification d'un atomique)

Paramètres

  • mutex — pointeur vers le mutex à verrouiller
  • time_point — pointeur vers le temps absolu du calendrier jusqu'auquel attendre le délai d'attente

Valeur de retour

thrd_success en cas de succès, thrd_timedout si le délai d'attente est atteint avant que le mutex ne soit verrouillé, thrd_error en cas d'erreur.
