mbsinit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <wchar.h>

int mbsinit( const mbstate_t* ps);  // (depuis C95)

Si ps n'est pas un pointeur nul, la fonction mbsinit détermine si l'objet mbstate_t pointé décrit l'état de conversion initial.

Notes

Bien qu'un mbstate_t initialisé à zéro représente toujours l'état de conversion initial, d'autres valeurs de mbstate_t peuvent également représenter l'état de conversion initial.

Paramètres

  • ps — pointeur vers l'objet mbstate_t à examiner

Valeur de retour

0 si ps n'est pas un pointeur nul et ne représente pas l'état de conversion initial, une valeur non nulle sinon.

Exemple

#include <locale.h>
#include <string.h>
#include <stdio.h>
#include <wchar.h>

int main(void)
{
    // permettre à mbrlen() de fonctionner avec l'encodage multioctet UTF-8
    setlocale(LC_ALL, "en_US.utf8");
    // encodage multioctet étroit UTF-8
    const char* str = u8"水"; // ou u8"\u6c34" ou "\xe6\xb0\xb4"
    static mbstate_t mb; // initialisation à zéro
    (void)mbrlen(&str[0], 1, &mb);
    if (!mbsinit(&mb)) {
        printf("After processing the first 1 byte of %s,\n"
               "the conversion state is not initial\n\n", str);
    }

    (void)mbrlen(&str[1], strlen(str), &mb);
    if (mbsinit(&mb)) {
        printf("After processing the remaining 2 bytes of %s,\n"
               "the conversion state is initial conversion state\n", str);
    }
}

Output:

After processing the first 1 byte of 水,
the conversion state is not initial

After processing the remaining 2 bytes of 水,
the conversion state is initial conversion state
