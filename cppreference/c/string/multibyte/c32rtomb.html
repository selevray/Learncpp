c32rtomb

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <uchar.h>

size_t c32rtomb( char* restrict s, char32_t c32, mbstate_t* restrict ps );  // (depuis C11)

Convertit un seul point de code, depuis sa représentation de caractère large de 32 bits à largeur variable (mais généralement UTF-32), vers sa représentation de caractère multioctet étroit.

Si s n'est pas un pointeur nul, la fonction détermine le nombre d'octets nécessaires pour stocker la représentation multioctet de c32 (y compris les éventuelles séquences de décalage, et en tenant compte de l'état de conversion multioctet courant *ps), et stocke cette représentation multioctet dans le tableau de caractères dont le premier élément est pointé par s, en mettant à jour *ps si nécessaire. Au plus MB_CUR_MAX octets peuvent être écrits par cette fonction.

Si s est un pointeur nul, l'appel équivaut à c32rtomb(buf, U'\0', ps) pour un tampon interne buf.

Si c32 est le caractère large nul U'\0', un octet nul est stocké, précédé de toute séquence de décalage nécessaire pour rétablir l'état de décalage initial, et le paramètre d'état de conversion *ps est mis à jour pour représenter l'état de décalage initial.

Si la macro __STDC_UTF_32__ est définie, l'encodage 32 bits utilisé par cette fonction est UTF-32 ; sinon, il est défini par l'implémentation. La macro est toujours définie et l'encodage est toujours UTF-32. (depuis C23) Dans tous les cas, l'encodage de caractères multioctets utilisé par cette fonction est spécifié par la locale C actuellement active.

Paramètres

  • s — pointeur vers le tableau de caractères étroits où le caractère multioctet sera stocké
  • c32 — le caractère large de 32 bits à convertir
  • ps — pointeur vers l'objet d'état de conversion utilisé lors de l'interprétation de la chaîne multioctet

Valeur de retour

En cas de succès, renvoie le nombre d'octets (y compris les éventuelles séquences de décalage) écrits dans le tableau de caractères dont le premier élément est pointé par s. Cette valeur peut être 0, par exemple lors du traitement des char32_t unités initiales d'une séquence de plusieurs char32_t-unités (ce qui ne se produit pas en UTF-32).

En cas d'échec (si c32 n'est pas un caractère large de 32 bits valide), renvoie -1, stocke EILSEQ dans errno et laisse *ps dans un état non spécifié.

Exemple

#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <uchar.h>

mbstate_t state;

int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
    const char32_t in[] = U"zß水🍌"; // ou "z\u00df\u6c34\U0001F34C"
    size_t in_sz = sizeof in / sizeof *in;

    printf("Processing %zu UTF-32 code units: [ ", in_sz);
    for (size_t n = 0; n < in_sz; ++n)
        printf("%#x ", in[n]);
    puts("]");

    char out[MB_CUR_MAX * in_sz];
    char* p = out;
    for (size_t n = 0; n < in_sz; ++n)
    {
        size_t rc = c32rtomb(p, in[n], &state);
        if(rc == (size_t)-1) break;
        p += rc;
    }

    size_t out_sz = p - out;
    printf("into %zu UTF-8 code units: [ ", out_sz);
    for (size_t x = 0; x < out_sz; ++x)
        printf("%#x ", +(unsigned char)out[x]);
    puts("]");
}

Output:

Processing 5 UTF-32 code units: [ 0x7a 0xdf 0x6c34 0x1f34c 0 ]
into 11 UTF-8 code units: [ 0x7a 0xc3 0x9f 0xe6 0xb0 0xb4 0xf0 0x9f 0x8d 0x8c 0 ]
