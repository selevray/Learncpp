char8_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <uchar.h>

typedef unsigned char char8_t;  // (depuis C23)

char8_t est un type entier non signé utilisé pour UTF-8 et il s'agit du même type que unsigned char.

Exemple

#include <stdio.h>
#include <uchar.h>

int main(void)
{
    char8_t str[] = u8"zß水🍌"; // ou "z\u00df\u6c34\U0001f34c"
    size_t str_sz = sizeof str; // sizeof *str == 1 par définition
    printf("%zu UTF-8 code units: [ ", str_sz);
    for (size_t n = 0; n < str_sz; ++n)
        printf("%02X ", str[n]);
    printf("]\n");
}

Sortie possible :

11 UTF-8 code units: [ 7A C3 9F E6 B0 B4 F0 9F 8D 8C 00 ]
