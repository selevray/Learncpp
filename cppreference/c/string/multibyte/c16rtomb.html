c16rtomb

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <uchar.h>

size_t c16rtomb( char* restrict s, char16_t c16, mbstate_t* restrict ps );  // (depuis C11)

Convertit un point de code unique depuis sa représentation de caractère large à 16 bits de longueur variable (généralement UTF-16) vers sa représentation de caractère multioctet étroit.

Si s n'est pas un pointeur nul et que c16 est la dernière unité de code de 16 bits d'un encodage valide à longueur variable d'un point de code, la fonction détermine le nombre d'octets nécessaires pour stocker la représentation multioctet de ce point de code (y compris les éventuelles séquences de décalage, et en tenant compte de l'état de conversion multioctet courant *ps), et stocke cette représentation multioctet dans le tableau de caractères dont le premier élément est pointé par s, en mettant à jour *ps si nécessaire. Au plus MB_CUR_MAX octets peuvent être écrits par cette fonction.

Si s est un pointeur nul, l'appel équivaut à c16rtomb(buf, u'\0', ps) pour un tampon interne buf.

Si c16 est le caractère large nul u'\0', un octet nul est stocké, précédé de toute séquence de décalage nécessaire pour rétablir l'état de décalage initial, et le paramètre d'état de conversion *ps est mis à jour pour représenter l'état de décalage initial.

Si c16 n'est pas l'unité de code finale d'une représentation de 16 bits d'un caractère large, il n'écrit pas dans le tableau pointé par s, seul *ps est mis à jour.

Si la macro __STDC_UTF_16__ est définie, l'encodage 16 bits utilisé par cette fonction est UTF-16 ; sinon, il est défini par l'implémentation. La macro est toujours définie et l'encodage est toujours UTF-16. (depuis C23) Dans tous les cas, l'encodage de caractères multioctets utilisé par cette fonction est spécifié par la locale C actuellement active.

Paramètres

  • s — pointeur vers le tableau de caractères étroits où le caractère multioctet sera stocké
  • c16 — le caractère large de 16 bits à convertir
  • ps — pointeur vers l'objet d'état de conversion utilisé lors de l'interprétation de la chaîne multioctet

Valeur de retour

En cas de succès, renvoie le nombre d'octets (y compris les éventuelles séquences de décalage) écrits dans le tableau de caractères dont le premier élément est pointé par s. Cette valeur peut être 0, par exemple lors du traitement des unités char16_t initiales d'une séquence de plusieurs unités char16_t (cela se produit lors du traitement du substitut initial d'une paire de substituts en UTF-16).

En cas d'échec (si c16 n'est pas une unité de code 16 bits valide), renvoie -1, stocke EILSEQ dans errno et laisse *ps dans un état non spécifié.

Notes

Dans C11 tel que publié, contrairement à mbrtoc16, qui convertit un encodage multioctet de longueur variable (comme UTF-8) en encodage 16 bits de longueur variable (comme UTF-16), cette fonction ne peut convertir que des encodages 16 bits à une seule unité, ce qui signifie qu'elle ne peut pas convertir UTF-16 en UTF-8, bien que ce soit l'intention initiale de cette fonction. Cela a été corrigé par le rapport de défaut post-C11 DR488.

Exemple

Remarque : cet exemple suppose que la correction du rapport de défaut DR488 est appliquée

#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <uchar.h>

mbstate_t state;

int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
    const char16_t in[] = u"zß水🍌"; // ou "z\u00df\u6c34\U0001F34C"
    const size_t in_sz = sizeof in / sizeof *in;

    printf("Processing %zu UTF-16 code units: [ ", in_sz);
    for (size_t n = 0; n < in_sz; ++n)
        printf("%#x ", in[n]);
    puts("]");

    char out[MB_CUR_MAX * in_sz];
    char *p = out;
    for (size_t n = 0; n < in_sz; ++n)
    {
        size_t rc = c16rtomb(p, in[n], &state);
        if (rc == (size_t)-1)
            break;
        p += rc;
    }

    size_t out_sz = p - out;
    printf("into %zu UTF-8 code units: [ ", out_sz);
    for (size_t x = 0; x < out_sz; ++x)
        printf("%#x ", +(unsigned char)out[x]);
    puts("]");
}

Output:

Processing 6 UTF-16 code units: [ 0x7a 0xdf 0x6c34 0xd83c 0xdf4c 0 ]
into 11 UTF-8 code units: [ 0x7a 0xc3 0x9f 0xe6 0xb0 0xb4 0xf0 0x9f 0x8d 0x8c 0 ]
