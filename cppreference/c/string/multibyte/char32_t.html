char32_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <uchar.h>

typedef uint_least32_t char32_t;  // (depuis C11)

char32_t est un type entier non signé utilisé pour les caractères larges de 32 bits et il s'agit du même type que uint_least32_t.

Notes

Sur une plateforme donnée, par définition de uint_least32_t, la largeur du type char32_t peut être supérieure à 32 bits, mais les valeurs réellement stockées dans un objet de type char32_t auront toujours une largeur de 32 bits.

Exemple

#include <stdio.h>
#include <uchar.h>

int main(void)
{
    const char32_t wc[] = U"zß水🍌"; // ou "z\u00df\u6c34\U0001f34c"
    const size_t wc_sz = sizeof wc / sizeof *wc;
    printf("%zu UTF-32 code units: [ ", wc_sz);
    for (size_t n = 0; n < wc_sz; ++n)
        printf("%#x ", wc[n]);
    printf("]\n");
}

Sortie possible :

5 UTF-32 code units: [ 0x7a 0xdf 0x6c34 0x1f34c 0 ]
