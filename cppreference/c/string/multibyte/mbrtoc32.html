mbrtoc32

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <uchar.h>

size_t mbrtoc32( char32_t restrict * pc32, const char * restrict s,
                 size_t n, mbstate_t * restrict ps );  // (depuis C11)

Convertit un seul point de code, depuis sa représentation de caractère multioctet étroit vers sa représentation de caractère large de 32 bits à largeur variable (mais généralement UTF-32).

Si s n'est pas un pointeur nul, examine au plus n octets de la chaîne de caractères multioctets, en commençant par l'octet pointé par s, pour déterminer le nombre d'octets nécessaires à compléter le caractère multioctet suivant (y compris les éventuelles séquences de décalage, et en tenant compte de l'état de conversion multioctet actuel *ps). Si la fonction détermine que le caractère multioctet suivant dans s est complet et valide, elle le convertit en le caractère large de 32 bits correspondant et le stocke dans *pc32 (si pc32 n'est pas nul).

Si le caractère multioctet dans *s correspond à une séquence multi-char32_t (impossible avec UTF-32), alors après le premier appel à cette fonction, *ps est mis à jour de façon à ce que les appels suivants à mbrtoc32 écrivent le char32_t supplémentaire, sans tenir compte de *s.

Si s est un pointeur nul, les valeurs de n et pc32 sont ignorées et l'appel est équivalent à mbrtoc32(NULL, "", 1, ps).

Si le caractère large produit est le caractère nul, l'état de conversion *ps représente l'état de décalage initial.

Si la macro __STDC_UTF_32__ est définie, l'encodage 32 bits utilisé par cette fonction est UTF-32 ; sinon, il est défini par l'implémentation. La macro est toujours définie et l'encodage est toujours UTF-32. (depuis C23) Dans tous les cas, l'encodage de caractères multioctets utilisé par cette fonction est spécifié par la locale C actuellement active.

Paramètres

  • pc32 — pointeur vers l'emplacement où le caractère large de 32 bits résultant sera écrit
  • s — pointeur vers la chaîne de caractères multioctets utilisée en entrée
  • n — limite du nombre d'octets de s pouvant être examinés
  • ps — pointeur vers l'objet d'état de conversion utilisé lors de l'interprétation de la chaîne multioctet

Valeur de retour

Le premier des cas suivants qui s'applique :

  • 0 si le caractère converti depuis s (et stocké dans *pc32 s'il n'est pas nul) était le caractère nul
  • le nombre d'octets [1...n] du caractère multioctet converti avec succès depuis s
  • (size_t)-3 si le char32_t suivant d'un caractère multi-char32_t a maintenant été écrit dans *pc32. Aucun octet n'est traité depuis l'entrée dans ce cas.
  • (size_t)-2 si les n octets suivants constituent un caractère multioctet incomplet, mais jusqu'ici valide. Rien n'est écrit dans *pc32.
  • (size_t)-1 si une erreur d'encodage se produit. Rien n'est écrit dans *pc32, la valeur EILSEQ est stockée dans errno et la valeur de *ps est non spécifiée.

Exemple

#include <stdio.h>
#include <locale.h>
#include <string.h>
#include <uchar.h>
#include <assert.h>

int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
    char in[] = u8"zß水🍌"; // ou "z\u00df\u6c34\U0001F34C"
    const size_t in_size = sizeof in / sizeof *in;

    printf("Processing %zu UTF-8 code units: [ ", in_size);
    for (size_t i = 0; i < in_size; ++i)
        printf("0x%02x ", (unsigned char)in[i]);

    puts("]");

    char32_t out[in_size];
    char32_t *p_out = out;
    char *p_in = in, *end = in + in_size;
    mbstate_t state;
    memset(&state, 0, sizeof(state));
    size_t rc;
    while ((rc = mbrtoc32(p_out, p_in, end - p_in, &state)))
    {
        assert(rc != (size_t)-3); // pas de paires de substitution en UTF-32
        if (rc == (size_t)-1) break; // entrée invalide
        if (rc == (size_t)-2) break; // entrée tronquée
        p_in += rc;
        ++p_out;
    }

    size_t out_size = p_out+1 - out;
    printf("into %zu UTF-32 code units: [ ", out_size);
    for (size_t i = 0; i < out_size; ++i)
        printf("0x%08X ", out[i]);

    puts("]");
}

Output:

Processing 11 UTF-8 code units: [ 0x7a 0xc3 0x9f 0xe6 0xb0 0xb4 0xf0 0x9f 0x8d 0x8c 0x00 ]
into 5 UTF-32 code units: [ 0x0000007A 0x000000DF 0x00006C34 0x0001F34C 0x00000000 ]
