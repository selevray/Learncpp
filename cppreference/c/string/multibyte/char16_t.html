char16_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <uchar.h>

typedef uint_least16_t char16_t;  // (depuis C11)

char16_t est un type entier non signé utilisé pour les caractères larges de 16 bits et il s'agit du même type que uint_least16_t.

Notes

Sur une plateforme donnée, par définition de uint_least16_t, la largeur du type char16_t peut être supérieure à 16 bits, mais les valeurs réellement stockées dans un objet de type char16_t auront toujours une largeur de 16 bits.

Exemple

#include <stdio.h>
#include <uchar.h>

int main(void)
{
    const char16_t wcs[] = u"zß水🍌"; // ou "z\u00df\u6c34\U0001f34c"
    const size_t wcs_sz = sizeof wcs / sizeof *wcs;
    printf("%zu UTF-16 code units: [ ", wcs_sz);
    for (size_t n = 0; n < wcs_sz; ++n)
        printf("%#x ", wcs[n]);
    printf("]\n");
}

Sortie possible :

6 UTF-16 code units: [ 0x7a 0xdf 0x6c34 0xd83c 0xdf4c 0 ]
