struct mbstate_t;  // (depuis C95)

Le type mbstate_t est un type non tableau trivial qui peut représenter l'un quelconque des états de conversion pouvant survenir dans un ensemble de règles d'encodage multioctet supportées et défini par l'implémentation. La valeur initialisée à zéro de mbstate_t représente l'état de conversion initial, bien que d'autres valeurs de mbstate_t puissent exister et représenter également l'état de conversion initial.

Une implémentation possible de mbstate_t est un type struct contenant un tableau représentant le caractère multioctet incomplet, un compteur entier indiquant le nombre d'octets du tableau ayant été traités, et une représentation de l'état de décalage courant.

Les fonctions suivantes ne doivent pas être appelées depuis plusieurs threads sans synchronisation avec l'argument mbstate_t* valant un pointeur nul, en raison de courses de données possibles : mbrlen, mbrtowc, mbsrtowcs, mbtowc, wcrtomb, wcsrtombs, wctomb.
