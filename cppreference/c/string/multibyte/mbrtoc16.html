mbrtoc16

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <uchar.h>

size_t mbrtoc16( char16_t* restrict pc16, const char* restrict s,
                 size_t n, mbstate_t* restrict ps );  // (depuis C11)

Convertit un seul point de code, depuis sa représentation de caractère multioctet étroit vers sa représentation de caractère large de 16 bits à largeur variable (généralement UTF-16).

Si s n'est pas un pointeur nul, examine au plus n octets de la chaîne de caractères multioctets, en commençant par l'octet pointé par s, pour déterminer le nombre d'octets nécessaires à compléter le caractère multioctet suivant (y compris les éventuelles séquences de décalage, et en tenant compte de l'état de conversion multioctet actuel *ps). Si la fonction détermine que le caractère multioctet suivant dans s est complet et valide, elle le convertit en le caractère large de 16 bits correspondant et le stocke dans *pc16 (si pc16 n'est pas nul).

Si le caractère multioctet dans *s correspond à une séquence multi-char16_t (par exemple une paire de substitution en UTF-16), alors après le premier appel à cette fonction, *ps est mis à jour de façon à ce que l'appel suivant à mbrtoc16 écrive les char16_t supplémentaires, sans tenir compte de *s.

Si s est un pointeur nul, les valeurs de n et pc16 sont ignorées et l'appel est équivalent à mbrtoc16(NULL, "", 1, ps).

Si le caractère large produit est le caractère nul, l'état de conversion *ps représente l'état de décalage initial.

Si la macro __STDC_UTF_16__ est définie, l'encodage 16 bits utilisé par cette fonction est UTF-16 ; sinon, il est défini par l'implémentation. La macro est toujours définie et l'encodage est toujours UTF-16. (depuis C23) Dans tous les cas, l'encodage de caractères multioctets utilisé par cette fonction est spécifié par la locale C actuellement active.

Paramètres

  • pc16 — pointeur vers l'emplacement où le caractère large de 16 bits résultant sera écrit
  • s — pointeur vers la chaîne de caractères multioctets utilisée en entrée
  • n — limite du nombre d'octets de s pouvant être examinés
  • ps — pointeur vers l'objet d'état de conversion utilisé lors de l'interprétation de la chaîne multioctet

Valeur de retour

Le premier des cas suivants qui s'applique :

  • 0 si le caractère converti depuis s (et stocké dans *pc16 s'il n'est pas nul) était le caractère nul
  • le nombre d'octets [1...n] du caractère multioctet converti avec succès depuis s
  • (size_t)-3 si le char16_t suivant d'un caractère multi-char16_t (par exemple une paire de substituts) a maintenant été écrit dans *pc16. Aucun octet n'est traité depuis l'entrée dans ce cas.
  • (size_t)-2 si les n octets suivants constituent un caractère multioctet incomplet, mais jusqu'ici valide. Rien n'est écrit dans *pc16.
  • (size_t)-1 si une erreur d'encodage se produit. Rien n'est écrit dans *pc16, la valeur EILSEQ est stockée dans errno et la valeur de *ps est non spécifiée.

Exemple

#include <locale.h>
#include <stdio.h>
#include <uchar.h>

mbstate_t state;

int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
    const char in[] = u8"zß水🍌"; // ou "z\u00df\u6c34\U0001F34C"
    const size_t in_sz = sizeof in / sizeof *in;

    printf("Processing %zu UTF-8 code units: [ ", in_sz);
    for (size_t n = 0; n < in_sz; ++n)
        printf("%#x ", (unsigned char)in[n]);
    puts("]");

    char16_t out[in_sz];
    const char *p_in = in, *end = in + in_sz;
    char16_t *p_out = out;
    for (size_t rc; (rc = mbrtoc16(p_out, p_in, end - p_in, &state));)
    {
        if (rc == (size_t)-1)     // entrée invalide
            break;
        else if(rc == (size_t)-2) // entrée tronquée
            break;
        else if(rc == (size_t)-3) // substitut haut UTF-16
            p_out += 1;
        else
        {
            p_in += rc;
            p_out += 1;
        };
    }

    const size_t out_sz = p_out - out + 1;
    printf("into %zu UTF-16 code units: [ ", out_sz);
    for (size_t x = 0; x < out_sz; ++x)
        printf("%#x ", out[x]);
    puts("]");
}

Output:

Processing 11 UTF-8 code units: [ 0x7a 0xc3 0x9f 0xe6 0xb0 0xb4 0xf0 0x9f 0x8d 0x8c 0 ]
into 6 UTF-16 code units: [ 0x7a 0xdf 0x6c34 0xd83c 0xdf4c 0 ]
