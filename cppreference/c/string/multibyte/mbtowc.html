mbtowc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

int mbtowc( wchar_t*          pwc, const char*          s, size_t n )  // (jusqu'à C99)

int mbtowc( wchar_t* restrict pwc, const char* restrict s, size_t n )  // (depuis C99)

Convertit un caractère multioctet dont le premier octet est pointé par s en un caractère large, écrit dans *pwc si pwc n'est pas nul.

Si s est un pointeur nul, réinitialise l'état de conversion global et détermine si des séquences de décalage sont utilisées.

Notes

Chaque appel à mbtowc met à jour l'état de conversion global interne (un objet statique de type mbstate_t, connu uniquement de cette fonction). Si l'encodage multioctet utilise des états de décalage, il faut veiller à éviter les retours arrière ou les parcours multiples. Dans tous les cas, plusieurs threads ne doivent pas appeler mbtowc sans synchronisation : mbrtowc peut être utilisée à la place.

Paramètres

  • pwc — pointeur vers le caractère large de sortie
  • s — pointeur vers le caractère multioctet
  • n — limite du nombre d'octets de s pouvant être examinés

Valeur de retour

Si s n'est pas un pointeur nul, retourne le nombre d'octets contenus dans le caractère multioctet, ou -1 si les premiers octets pointés par s ne forment pas un caractère multioctet valide, ou 0 si s pointe sur le caractère nul '\0'.

Si s est un pointeur nul, réinitialise son état de conversion interne pour représenter l'état de décalage initial et retourne 0 si l'encodage multioctet courant ne dépend pas d'un état (n'utilise pas de séquences de décalage), ou une valeur non nulle si l'encodage multioctet courant dépend d'un état (utilise des séquences de décalage).

Exemple

#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <wchar.h>

// afficher une chaîne multioctet sur la sortie standard orientée caractères larges
// équivalent à wprintf(L"%s\n", ptr);
void print_mb(const char* ptr)
{
    mbtowc(NULL, NULL, 0); // réinitialiser l'état de conversion
    const char* end = ptr + strlen(ptr);
    int ret = 0;
    for (wchar_t wc; (ret = mbtowc(&wc, ptr, end - ptr)) > 0; ptr += ret)
        wprintf(L"%lc", wc);
    wprintf(L"\n");
}

int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
    // encodage multioctet étroit UTF-8
    print_mb("z\u00df\u6c34\U0001F34C"); // ou "zß水🍌"
}

Output:

zß水🍌
