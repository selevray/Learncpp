mbrlen

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <wchar.h>

size_t mbrlen( const char* s, size_t n, mbstate_t* ps );  // (depuis C95) (jusqu'à C99)

size_t mbrlen( const char* restrict s, size_t n, mbstate_t* restrict ps );  // (depuis C99)

Détermine la taille, en octets, de la représentation d'un caractère multioctet.

Cette fonction est équivalente à l'appel mbrtowc(NULL, s, n, ps ? ps : &internal) pour un objet caché internal de type mbstate_t, sauf que l'expression ps n'est évaluée qu'une seule fois.

Paramètres

  • s — pointeur vers un élément d'une chaîne de caractères multioctets
  • n — limite du nombre d'octets de s pouvant être examinés
  • ps — pointeur vers la variable contenant l'état de conversion

Valeur de retour

Le premier des cas suivants qui s'applique :

  • 0 si les n octets suivants ou moins complètent le caractère nul, ou si s est un pointeur nul. Ces deux cas réinitialisent l'état de conversion.
  • le nombre d'octets [1...n] qui complètent un caractère multioctet valide
  • (size_t)-2 si les n octets suivants font partie d'un caractère multioctet potentiellement valide, encore incomplet après examen de l'ensemble des n octets
  • (size_t)-1 en cas d'erreur d'encodage. La valeur de errno est EILSEQ ; l'état de conversion est non spécifié.

Exemple

#include <locale.h>
#include <stdio.h>
#include <string.h>
#include <wchar.h>

int main(void)
{
    // permettre à mbrlen() de fonctionner avec l'encodage multioctet UTF-8
    setlocale(LC_ALL, "en_US.utf8");

    // encodage multioctet étroit UTF-8
    const char* str = "水";
    size_t sz = strlen(str);

    mbstate_t mb;
    memset(&mb, 0, sizeof mb);
    int len1 = mbrlen(str, 1, &mb);
    if (len1 == -2)
        printf("The first 1 byte of %s is an incomplete multibyte char"
               " (mbrlen returns -2)\n", str);

    int len2 = mbrlen(str + 1, sz - 1, &mb);
    printf("The remaining %zu  bytes of %s hold %d bytes of the multibyte"
           " character\n", sz - 1, str, len2);

    printf("Attempting to call mbrlen() in the middle of %s while in initial"
           " shift state returns %zd\n", str, mbrlen(str + 1, sz - 1, &mb));
}

Output:

The first 1 byte of 水 is an incomplete multibyte char (mbrlen returns -2)
The remaining 2  bytes of 水 hold 2 bytes of the multibyte character
Attempting to call mbrlen() in the middle of 水 while in initial shift state returns -1
