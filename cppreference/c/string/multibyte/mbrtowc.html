mbrtowc

Défini dans l'en-tête <wchar.h>

size_t mbrtowc( wchar_t* pwc, const char* s, size_t n, mbstate_t* ps );  // (depuis C95)

size_t mbrtowc( wchar_t *restrict pwc, const char *restrict s, size_t n,
                mbstate_t *restrict ps );  // (depuis C99)

Convertit un caractère multioctet étroit en sa représentation de caractère large.

Si s n'est pas un pointeur nul, examine au plus n octets de la chaîne de caractères multioctets, en commençant par l'octet pointé par s, pour déterminer le nombre d'octets nécessaires à compléter le caractère multioctet suivant (y compris les éventuelles séquences de décalage, et en tenant compte de l'état de conversion multioctet actuel *ps). Si la fonction détermine que le caractère multioctet suivant dans s est complet et valide, elle le convertit en le caractère large correspondant et le stocke dans *pwc (si pwc n'est pas nul).

Si s est un pointeur nul, les valeurs de n et pwc sont ignorées et l'appel est équivalent à mbrtowc(NULL, "", 1, ps).

Si le caractère large produit est le caractère nul, l'état de conversion stocké dans *ps est l'état de décalage initial.

Si la macro d'environnement __STDC_ISO_10646__ est définie, les valeurs de type wchar_t sont les mêmes que les identifiants courts des caractères de l'ensemble requis Unicode (généralement encodage UTF-32) ; sinon, elles sont définies par l'implémentation. Dans tous les cas, l'encodage de caractères multioctets utilisé par cette fonction est spécifié par la locale C actuellement active.

Paramètres

  • pwc — pointeur vers l'emplacement où le caractère large résultant sera écrit
  • s — pointeur vers la chaîne de caractères multioctets utilisée en entrée
  • n — limite du nombre d'octets de s pouvant être examinés
  • ps — pointeur vers l'état de conversion utilisé lors de l'interprétation de la chaîne de caractères multioctets

Valeur de retour

Le premier des cas suivants qui s'applique :

  • 0 si le caractère converti depuis s (et stocké dans pwc s'il n'est pas nul) était le caractère nul
  • le nombre d'octets [1...n] du caractère multioctet converti avec succès depuis s
  • (size_t)-2 si les n octets suivants constituent un caractère multioctet incomplet, mais jusqu'ici valide. Rien n'est écrit dans *pwc.
  • (size_t)-1 si une erreur d'encodage se produit. Rien n'est écrit dans *pwc, la valeur EILSEQ est stockée dans errno et la valeur de *ps est laissée non spécifiée.

Exemple

#include <stdio.h>
#include <locale.h>
#include <string.h>
#include <wchar.h>

int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
    mbstate_t state;
    memset(&state, 0, sizeof state);
    char in[] = u8"z\u00df\u6c34\U0001F34C"; // ou u8"zß水🍌"
    size_t in_sz = sizeof in / sizeof *in;

    printf("Processing %zu UTF-8 code units: [ ", in_sz);
    for(size_t n = 0; n < in_sz; ++n) printf("%#x ", (unsigned char)in[n]);
    puts("]");

    wchar_t out[in_sz];
    char *p_in = in, *end = in + in_sz;
    wchar_t *p_out = out;
    int rc;
    while((rc = mbrtowc(p_out, p_in, end - p_in, &state)) > 0)
    {
        p_in += rc;
        p_out += 1;
    }

    size_t out_sz = p_out - out + 1;
    printf("into %zu wchar_t units: [ ", out_sz);
    for(size_t x = 0; x < out_sz; ++x) printf("%#x ", out[x]);
    puts("]");
}

Output:

Processing 11 UTF-8 code units: [ 0x7a 0xc3 0x9f 0xe6 0xb0 0xb4 0xf0 0x9f 0x8d 0x8c 0 ]
into 5 wchar_t units: [ 0x7a 0xdf 0x6c34 0x1f34c 0 ]
