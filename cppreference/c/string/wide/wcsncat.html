wcsncat, wcsncat_s

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <wchar.h>

wchar_t *wcsncat( wchar_t *dest, const wchar_t *src, size_t count );  // (depuis C95) (jusqu'à C99)

wchar_t *wcsncat( wchar_t *restrict dest,
                  const wchar_t *restrict src, size_t count );  // (depuis C99)

errno_t wcsncat_s( wchar_t *restrict dest, rsize_t destsz,
                   const wchar_t *restrict src, rsize_t count );  // (2) (depuis C11)
  1. Ajoute au plus count caractères larges de la chaîne large pointée par src, en s'arrêtant si le caractère nul terminal est copié, à la fin de la chaîne de caractères pointée par dest. Le caractère large src[0] remplace le caractère nul terminal à la fin de dest. Le caractère nul terminal est toujours ajouté à la fin (le nombre maximal de caractères larges que la fonction peut écrire est donc count+1).

Le comportement est indéfini si le tableau de destination n'est pas assez grand pour contenir à la fois le contenu de str et de dest ainsi que le caractère large nul terminal.

Le comportement est indéfini si les chaînes se chevauchent.

  1. Identique à (1), sauf que cette fonction peut écraser le reste du tableau de destination (à partir du dernier caractère large écrit dans destsz) et que les erreurs suivantes sont détectées à l'exécution et appellent la fonction gestionnaire de contraintes actuellement installée :
  • src ou dest est un pointeur nul
  • destsz ou count vaut zéro ou est supérieur à RSIZE_MAX/sizeof(wchar_t)
  • il n'existe aucun caractère large nul dans les destsz premiers caractères larges de dest
  • troncature : count ou la longueur de src, selon la plus petite des deux, dépasse l'espace disponible entre le terminateur nul de dest et destsz.
  • un chevauchement se produirait entre la chaîne source et la chaîne de destination Comme pour toutes les fonctions à vérification de bornes, wcsncat_s n'est garantie disponible que si __STDC_LIB_EXT1__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT1__ comme la constante entière 1 avant d'inclure <wchar.h>.

Paramètres

  • dest — pointeur vers la chaîne large terminée par un caractère nul à laquelle ajouter
  • src — pointeur vers la chaîne large terminée par un caractère nul à copier
  • count — nombre maximal de caractères larges à copier
  • destsz — la taille du tampon de destination

Valeur de retour

  1. renvoie une copie de dest

  2. renvoie zéro en cas de succès, une valeur non nulle en cas d'erreur. De plus, en cas d'erreur, écrit L'\0' dans dest[0] (sauf si dest est un pointeur nul ou si destsz vaut zéro ou est supérieur à RSIZE_MAX/sizeof(wchar_t)).

Notes

Bien que la troncature pour tenir dans le tampon de destination soit un risque de sécurité et donc une violation de contraintes à l'exécution pour wcsncat_s, il est possible d'obtenir le comportement tronquant en spécifiant count égal à la taille du tableau de destination moins un : elle copiera les count premiers caractères larges et ajoutera le caractère nul terminal comme toujours : wcsncat_s(dst, sizeof dst/sizeof *dst, src, (sizeof dst/sizeof *dst)-wcsnlen_s(dst, sizeof dst/sizeof *dst)-1);

Exemple

#include <wchar.h>
#include <stdio.h>
#include <locale.h>

int main(void)
{
    wchar_t str[50] = L"Земля, прощай.";
    wcsncat(str, L" ", 1);
    wcsncat(str, L"В добрый путь.", 8); // n'ajouter que les 8 premiers caractères larges
    setlocale(LC_ALL, "en_US.utf8");
    printf("%ls", str);
}
