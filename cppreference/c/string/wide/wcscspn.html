wcscspn

Défini dans l'en-tête <wchar.h>

size_t wcscspn( const wchar_t* dest, const wchar_t* src );  // (depuis C95)

Retourne la longueur du segment initial maximal de la chaîne large pointée par dest, qui ne contient que des caractères non présents dans la chaîne large pointée par src.

Paramètres

  • dest — pointeur vers la chaîne large terminée par un caractère nul à analyser
  • src — pointeur vers la chaîne large terminée par un caractère nul contenant les caractères à rechercher

Valeur de retour

La longueur du plus long segment initial ne contenant que des caractères absents de la chaîne de caractères pointée par src

Exemple

#include <locale.h>
#include <wchar.h>

int main(void)
{
    wchar_t dest[] = L"白猫 黑狗 甲虫";
    /*                      └───┐   */
    const wchar_t *src = L"甲虫,黑狗";

    const size_t len = wcscspn(dest, src);
    dest[len] = L'\0'; /* termine le segment pour l'afficher */

    setlocale(LC_ALL, "en_US.utf8");
    wprintf(L"The length of maximum initial segment is %td.\n"
            L"The segment is \"%ls\".\n", len, dest);
}

Output:

The length of maximum initial segment is 3.
The segment is "白猫 ".
