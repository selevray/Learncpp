wcsncpy, wcsncpy_s

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <wchar.h>

wchar_t* wcsncpy( wchar_t* dest, const wchar_t* src, size_t count );  // (depuis C95) (jusqu'à C99)

wchar_t *wcsncpy( wchar_t *restrict dest, const wchar_t *restrict src, size_t count );  // (depuis C99)

errno_t wcsncpy_s( wchar_t *restrict dest, rsize_t destsz,
                   const wchar_t *restrict src, rsize_t count);  // (2) (depuis C11)
  1. Copie au plus count caractères de la chaîne large pointée par src (y compris le caractère large nul terminal) dans le tableau de caractères larges pointé par dest.

Si count est atteint avant que la chaîne entière src ait été copiée, le tableau de caractères larges résultant n'est pas terminé par un caractère nul.

Si, après la copie du caractère large nul terminal depuis src, count n'est pas atteint, des caractères larges nuls supplémentaires sont écrits dans dest jusqu'à ce que le total de count caractères ait été écrit.

Si les chaînes se chevauchent, le comportement est indéfini.

  1. Identique à (1), sauf que la fonction ne continue pas à écrire des zéros dans le tableau de destination pour le compléter jusqu'à count, elle s'arrête après avoir écrit le caractère nul de fin (s'il n'y avait pas de nul dans la source, elle en écrit un à dest[count] puis s'arrête). De plus, les erreurs suivantes sont détectées à l'exécution et appellent la fonction gestionnaire de contraintes actuellement installée :
  • src ou dest est un pointeur nul
  • destsz ou count vaut zéro ou est supérieur à RSIZE_MAX/sizeof(wchar_t)
  • count est supérieur ou égal à destsz, mais destsz est inférieur ou égal à wcsnlen_s(src, count), autrement dit, une troncature se produirait
  • un chevauchement se produirait entre la chaîne source et la chaîne de destination Comme pour toutes les fonctions à vérification de bornes, wcsncpy_s n'est garantie disponible que si __STDC_LIB_EXT1__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT1__ comme la constante entière 1 avant d'inclure <wchar.h>.

Paramètres

  • dest — pointeur vers le tableau de caractères larges de destination
  • src — pointeur vers la chaîne de caractères larges à copier
  • count — nombre maximal de caractères larges à copier
  • destsz — la taille du tampon de destination

Valeur de retour

  1. renvoie une copie de dest

  2. renvoie zéro en cas de succès, une valeur non nulle en cas d'erreur. De plus, en cas d'erreur, écrit L'\0' dans dest[0] (sauf si dest est un pointeur nul ou si destsz vaut zéro ou est supérieur à RSIZE_MAX/sizeof(wchar_t)) et peut écraser le reste du tableau de destination avec des valeurs non spécifiées.

Notes

En usage typique, count est le nombre d'éléments du tableau de destination.

Bien que la troncature pour tenir dans le tampon de destination soit un risque de sécurité et donc une violation de contraintes à l'exécution pour wcsncpy_s, il est possible d'obtenir le comportement tronquant en spécifiant count égal à la taille du tableau de destination moins un : elle copiera les count premiers caractères larges et ajoutera le caractère nul terminal comme toujours : wcsncpy_s(dst, sizeof dst / sizeof *dst, src, (sizeof dst / sizeof *dst)-1);

Exemple

#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    const wchar_t src[] = L"わゐ";
    wchar_t dest[6] = {L'あ', L'い', L'う', L'え', L'お'};

    wcsncpy(dest, src, 4); // ceci copiera わゐ et répétera L'\0' deux fois

    puts("The contents of dest are: ");
    setlocale(LC_ALL, "en_US.utf8");

    const long dest_size = sizeof dest / sizeof *dest;
    for(wchar_t* p = dest; p-dest != dest_size; ++p) {
        *p ? printf("%lc ", *p)
           : printf("\\0 ");
    }
}
