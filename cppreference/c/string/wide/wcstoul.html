wcstoul, wcstoull

Défini dans l'en-tête <wchar.h>

unsigned long      wcstoul( const wchar_t* str, wchar_t** str_end, int base );  // (depuis C95) (jusqu'à C99)

unsigned long      wcstoul( const wchar_t * restrict str,
                            wchar_t ** restrict str_end, int base );  // (depuis C99)

unsigned long long wcstoull( const wchar_t * restrict str,
                             wchar_t ** restrict str_end, int base );  // (depuis C99)

Interprète une valeur entière non signée dans une chaîne de caractères larges pointée par str.

Ignore les caractères d'espacement (identifiés en appelant iswspace) jusqu'à ce que le premier caractère non espace soit trouvé, puis prend autant de caractères que possible pour former une représentation valide d'entier non signé en base-n (où n=base) et les convertit en valeur entière. La valeur entière non signée valide est constituée des parties suivantes :

  • (facultatif) signe plus ou moins
  • (facultatif) préfixe (0) indiquant la base octale (s'applique uniquement lorsque la base vaut 8 ou 0)
  • (optionnel) préfixe (0x ou 0X) indiquant la base hexadécimale (ne s'applique que lorsque la base vaut 16 ou 0)
  • une suite de chiffres

L'ensemble des valeurs valides pour base est {0, 2, 3, ..., 36}. L'ensemble des chiffres valides pour les entiers en base-2 est {0, 1}, pour les entiers en base-3 est {0, 1, 2}, et ainsi de suite. Pour les bases supérieures à 10, les chiffres valides incluent les caractères alphabétiques, à partir de Aa pour un entier en base-11, jusqu'à Zz pour un entier en base-36. La casse des caractères est ignorée.

Des formats numériques supplémentaires peuvent être acceptés par la locale C actuellement installée.

Si la valeur de base vaut 0, la base numérique est détectée automatiquement : si le préfixe est 0, la base est octale ; si le préfixe est 0x ou 0X, la base est hexadécimale ; sinon, la base est décimale.

Si le signe moins faisait partie de la séquence d'entrée, la valeur numérique calculée à partir de la séquence de chiffres est niée comme par moins unaire dans le type de résultat, ce qui applique les règles de repliement modulo des entiers non signés.

La fonction place le pointeur pointé par str_end sur le caractère large suivant le dernier caractère interprété. Si str_end est un pointeur nul, il est ignoré.

Paramètres

  • str — pointeur vers la chaîne de caractères larges terminée par un caractère nul à interpréter
  • str_end — pointeur vers un pointeur sur un caractère large.
  • base — base de la valeur entière interprétée

Valeur de retour

Valeur entière correspondant au contenu de str en cas de succès. Si la valeur convertie sort de l'intervalle du type de retour correspondant, une erreur d'intervalle se produit et ULONG_MAX ou ULLONG_MAX est renvoyé. Si aucune conversion ne peut être effectuée, 0 est renvoyé.

Exemple

#include <stdio.h>
#include <errno.h>
#include <wchar.h>

int main(void)
{
    const wchar_t *p = L"10 200000000000000000000000000000 30 40";
    printf("Parsing L'%ls':\n", p);
    wchar_t *end;
    for (unsigned long i = wcstoul(p, &end, 10);
         p != end;
         i = wcstoul(p, &end, 10))
    {
        printf("'%.*ls' -> ", (int)(end-p), p);
        p = end;
        if (errno == ERANGE){
            printf("range error, got ");
            errno = 0;
        }
        printf("%lu\n", i);
    }
}

Output:

Parsing '10 200000000000000000000000000000 30 40':
'10' -> 10
' 200000000000000000000000000000' -> range error, got 18446744073709551615
' 30' -> 30
' 40' -> 40
