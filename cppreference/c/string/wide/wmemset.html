wmemset

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <wchar.h>

wchar_t* wmemset( wchar_t* dest, wchar_t ch, size_t count );  // (depuis C95)

Copie le caractère large ch dans chacun des premiers count caractères larges du tableau de caractères larges (ou du tableau d'entiers de type compatible) pointé par dest.

En cas de dépassement, le comportement est indéfini.

Si count vaut zéro, la fonction ne fait rien.

Paramètres

  • dest — pointeur vers le tableau de caractères larges à remplir
  • ch — caractère large de remplissage
  • count — nombre de caractères larges à remplir

Valeur de retour

Renvoie une copie de dest

Notes

Cette fonction ne dépend pas de la locale et ne tient pas compte des valeurs des objets wchar_t qu'elle écrit : les caractères nuls ainsi que les caractères larges invalides sont également écrits.

Exemple

#include <locale.h>
#include <stdio.h>
#include <wchar.h>

int main(void)
{
    wchar_t ar[10] = L"1234567890"; // aucun zéro terminal dans le tableau
    wmemset(ar, L'\U0001f34c', 5); // remplace [12345] par les bananes 🍌
    wmemset(ar + 5, L'蕉', 5); // remplace [67890] par les bananes 蕉

    setlocale(LC_ALL, "en_US.utf8");
    for (size_t n = 0; n < sizeof ar / sizeof *ar; ++n)
        putwchar(ar[n]);
    putwchar(L'\n');
}

Output:

🍌🍌🍌🍌🍌蕉蕉蕉蕉蕉
