wcsspn

Défini dans l'en-tête <wchar.h>

size_t wcsspn( const wchar_t* dest, const wchar_t* src );  // (depuis C95)

Renvoie la longueur du segment initial maximal de la chaîne de caractères larges pointée par dest, qui ne contient que des caractères se trouvant dans la chaîne de caractères larges pointée par src.

Paramètres

  • dest — pointeur vers la chaîne large terminée par un caractère nul à analyser
  • src — pointeur vers la chaîne large terminée par un caractère nul contenant les caractères à rechercher

Valeur de retour

La longueur du segment initial maximal ne contenant que des caractères de la chaîne de caractères larges pointée par src

Exemple

#include <locale.h>
#include <wchar.h>

int main(void)
{
    wchar_t dest[] = L"白猫 黑狗 甲虫";
    const wchar_t src[] = L" 狗猫 白黑 ";
    const size_t len = wcsspn(dest, src);
    dest[len] = L'\0'; /* termine le segment pour l'afficher */

    setlocale(LC_ALL, "en_US.utf8");
    wprintf(L"The length of maximum initial segment is %td.\n"
            L"The segment is \"%ls\".\n", len, dest);
}

Output:

The length of maximum initial segment is 6.
The segment is "白猫 黑狗 ".
