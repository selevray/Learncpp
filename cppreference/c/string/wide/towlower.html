Défini dans l'en-tête <wctype.h>

wint_t towlower( wint_t wc );  // (depuis C95)

Convertit le caractère large donné en minuscule, si possible.

Paramètres

  • wc — caractère large à convertir

Valeur de retour

Version minuscule de wc, ou wc inchangé si aucune version minuscule n'est listée dans la locale C actuelle.

Notes

Seule une correspondance caractère à caractère 1:1 peut être effectuée par cette fonction, par exemple la lettre majuscule grecque 'Σ' possède deux formes minuscules, selon sa position dans un mot : 'σ' et 'ς'. Un appel à towlower ne peut pas être utilisé pour obtenir la forme minuscule correcte dans ce cas.

ISO 30112 spécifie quelles paires de caractères Unicode sont incluses dans cette correspondance.

Exemple

#include <locale.h>
#include <stdio.h>
#include <wchar.h>
#include <wctype.h>

int main(void)
{
    wchar_t wc = L'\u0190'; // E ouvert majuscule latin ('Ɛ')
    printf("in the default locale, towlower(%#x) = %#x\n", wc, towlower(wc));
    setlocale(LC_ALL, "en_US.utf8");
    printf("in Unicode locale, towlower(%#x) = %#x\n", wc, towlower(wc));
}

Output:

in the default locale, towlower(0x190) = 0x190
in Unicode locale, towlower(0x190) = 0x25b
