wcsxfrm

Défini dans l'en-tête <wchar.h>

size_t wcsxfrm( wchar_t* dest, const wchar_t* src, size_t count );  // (jusqu'à C99) (depuis C95)

size_t wcsxfrm( wchar_t* restrict dest, const wchar_t* restrict src, size_t count );  // (depuis C99)

Transforme la chaîne de caractères larges terminée par un caractère nul pointée par src en une forme définie par l'implémentation, de sorte que la comparaison de deux chaînes transformées avec wcscmp donne le même résultat que la comparaison des chaînes originales avec wcscoll, dans la locale C courante.

Les count premiers caractères de la chaîne transformée sont écrits dans destination, y compris le caractère nul de fin, et la longueur de la chaîne transformée complète est retournée, sans compter le caractère nul de fin.

Si count vaut 0, alors dest peut être un pointeur nul.

Notes

La taille correcte du tampon pouvant recevoir la chaîne transformée entière est 1+wcsxfrm(NULL, src, 0)

Cette fonction est utilisée lorsque plusieurs comparaisons dépendantes de la locale sont effectuées sur la même chaîne de caractères larges ou le même ensemble de chaînes, car il est plus efficace d'utiliser wcsxfrm pour transformer toutes les chaînes une seule fois, puis de comparer ensuite les chaînes larges transformées avec wcscmp.

Paramètres

  • dest — pointeur vers le premier élément d'une chaîne de caractères larges terminée par un caractère nul dans laquelle écrire la chaîne transformée
  • src — pointeur vers la chaîne de caractères larges terminée par un caractère nul à transformer
  • count — nombre maximal de caractères à écrire en sortie

Valeur de retour

La longueur de la chaîne de caractères larges transformée, sans le caractère nul de fin.

Exemple

#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "sv_SE.utf8");

    const wchar_t *in1 = L"\u00e5r";
    wchar_t out1[1+wcsxfrm(NULL, in1, 0)];
    wcsxfrm(out1, in1, sizeof out1/sizeof *out1);

    const wchar_t *in2 = L"\u00e4ngel";
    wchar_t out2[1+wcsxfrm(NULL, in2, 0)];
    wcsxfrm(out2, in2, sizeof out2/sizeof *out2);

    printf("In the Swedish locale: ");
    if(wcscmp(out1, out2) < 0)
         printf("%ls before %ls\n", in1, in2);
    else
         printf("%ls before %ls\n", in2, in1);

    printf("In lexicographical comparison: ");
    if(wcscmp(in1, in2) < 0)
         printf("%ls before %ls\n", in1, in2);
    else
         printf("%ls before %ls\n", in2, in1);
}

Output:

In the Swedish locale: år before ängel
In lexicographical comparison: ängel before år
