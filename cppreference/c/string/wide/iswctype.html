iswctype

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <wctype.h>

int iswctype( wint_t wc, wctype_t desc );  // (depuis C95)

Classe le caractère large wc à l'aide de la catégorie LC_CTYPE de la locale C courante, identifiée par desc.

Paramètres

  • wc — le caractère large à classer
  • desc — la catégorie LC_CTYPE, obtenue par un appel à wctype

Valeur de retour

Non nul si le caractère wc possède la propriété identifiée par desc dans la facette LC_CTYPE de la locale C courante, zéro sinon.

Exemple

#include <locale.h>
#include <stdio.h>
#include <wchar.h>
#include <wctype.h>

const char* classify(wchar_t wc, const char* cat)
{
    return iswctype(wc, wctype(cat)) ? "true" : "false";
}

int main(void)
{
    setlocale(LC_ALL, "ja_JP.UTF-8");
    puts("The character \u6c34 is...");
    const char* cats[] = {"digit", "alpha", "space", "cntrl", "jkanji"};
    for (int n = 0; n < 5; ++n)
        printf("%s?\t%s\n", cats[n], classify(L'\u6c34', cats[n]));
}

Output:

The character 水 is...
digit?  false
alpha?  true
space?  false
cntrl?  false
jkanji? true
