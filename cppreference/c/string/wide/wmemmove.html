wmemmove, wmemmove_s

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <wchar.h>

wchar_t* wmemmove( wchar_t* dest, const wchar_t* src, size_t count );  // (1) (depuis C95)

errno_t wmemmove_s( wchar_t *dest, rsize_t destsz,
                    const wchar_t *src, rsize_t count);  // (2) (depuis C11)

  1. Copie exactement count caractères larges successifs du tableau de caractères larges pointé par src vers le tableau de caractères larges pointé par dest. Si count vaut zéro, la fonction ne fait rien. Les tableaux peuvent se chevaucher : la copie s'effectue comme si les caractères larges étaient copiés dans un tableau temporaire puis copiés depuis le tableau temporaire vers dest.

  2. Identique à (1), à ceci près que les erreurs suivantes sont détectées à l'exécution et appellent la fonction constraint handler actuellement installée :

  • src ou dest est un pointeur nul
  • destsz ou count est supérieur à RSIZE_MAX / sizeof(wchar_t)
  • count est supérieur à destsz (un dépassement se produirait) Comme pour toutes les fonctions à vérification de bornes, wmemcpy_s n'est garantie disponible que si __STDC_LIB_EXT1__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT1__ comme la constante entière 1 avant d'inclure <wchar.h>.

Paramètres

  • dest — pointeur vers le tableau de caractères larges de destination
  • src — pointeur vers le tableau de caractères larges à copier
  • destsz — nombre maximal de caractères larges à écrire (la taille du tampon de destination)
  • count — nombre de caractères larges à copier

Valeur de retour

  1. Renvoie une copie de dest

  2. Renvoie zéro en cas de succès, une valeur non nulle en cas d'erreur. De plus, en cas d'erreur, remplit l'intégralité de dst jusqu'à dst+dstsz exclu avec des caractères larges nuls, L'\0' (sauf si dest est nul ou si destsz est supérieur à RSIZE_MAX/sizeof(wchar_t))

Notes

Cette fonction ne dépend pas de la locale et ne tient pas compte des valeurs des objets wchar_t qu'elle copie : les caractères nuls ainsi que les caractères invalides sont également copiés.

Exemple

#include <locale.h>
#include <stdio.h>
#include <wchar.h>

int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");

    wchar_t str[] = L"αβγδεζηθικλμνξοπρστυφχψω";
    printf("%ls\n", str);
    wmemmove(str + 4, str + 3, 3); // copie de [δεζ] vers [εζη]
    printf("%ls\n", str);
}

Output:

αβγδεζηθικλμνξοπρστυφχψω
αβγδδεζθικλμνξοπρστυφχψω
