wcscpy, wcscpy_s

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <wchar.h>

wchar_t* wcscpy( wchar_t* dest, const wchar_t* src );  // (depuis C95) (jusqu'à C99)

wchar_t* wcscpy( wchar_t* restrict dest, const wchar_t* restrict src );  // (depuis C99)

errno_t wcscpy_s( wchar_t* restrict dest, rsize_t destsz,
                  const wchar_t* restrict src );  // (2) (depuis C11)

  1. Copie la chaîne large pointée par src (y compris le caractère large nul terminal) dans le tableau de caractères larges pointé par dest. Le comportement est indéfini si le tableau dest n'est pas assez grand. Le comportement est indéfini si les chaînes se chevauchent.

  2. Identique à (1), à ceci près qu'elle peut écraser le reste du tableau de destination avec des valeurs non spécifiées et que les erreurs suivantes sont détectées à l'exécution et appellent la fonction gestionnaire de contraintes actuellement installée :

  • src ou dest est un pointeur nul
  • destsz vaut zéro ou est supérieur à RSIZE_MAX / sizeof(wchar_t)
  • destsz est inférieur ou égal à wcsnlen_s(src, destsz), autrement dit une troncature se produirait
  • un chevauchement se produirait entre la chaîne source et la chaîne de destination Comme pour toutes les fonctions à vérification de bornes, wcscpy_s n'est garantie disponible que si __STDC_LIB_EXT1__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT1__ comme la constante entière 1 avant d'inclure <wchar.h>.

Paramètres

  • dest — pointeur vers le tableau de caractères larges de destination
  • src — pointeur vers la chaîne large terminée par un caractère nul à copier
  • destsz — nombre maximal de caractères à écrire, généralement la taille du tampon de destination

Valeur de retour

  1. renvoie une copie de dest

  2. renvoie zéro en cas de succès, une valeur non nulle en cas d'erreur. De plus, en cas d'erreur, écrit L'\0' dans dest[0] (sauf si dest est un pointeur nul ou si destsz vaut zéro ou est supérieur à RMAX_SIZE / sizeof(wchar_t)).

Exemple

#include <locale.h>
#include <stdio.h>
#include <wchar.h>

int main(void)
{
    wchar_t* src = L"犬 means dog";
//  src[0] = L'狗' ; // ceci serait un comportement indéfini
    wchar_t dst[wcslen(src) + 1]; // +1 pour le terminateur nul
    wcscpy(dst, src);
    dst[0] = L'狗'; // OK

    setlocale(LC_ALL, "en_US.utf8");
    printf("src = %ls\ndst = %ls\n", src, dst);
}

Output:

src = 犬 means dog
dst = 狗 means dog
