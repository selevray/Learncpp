strpbrk

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <string.h>

char *strpbrk( const char *dest, const char *breakset );  // (1)

/*QChar*/ *strpbrk( /*QChar*/ *dest, const char *breakset );  // (2) (depuis C23)

1 ) Parcourt la chaîne d'octets terminée par un caractère nul pointée par dest à la recherche de n'importe quel caractère de la chaîne d'octets terminée par un caractère nul pointée par breakset, et retourne un pointeur vers ce caractère.

  1. Fonction générique de type équivalente à (1). Soit T un type d'objet caractère non qualifié.
  • Si dest est de type const T*, le type de retour est const char*.
  • Sinon, si dest est de type T*, le type de retour est char*.
  • Dans le cas contraire, le comportement est indéfini. Si la définition de macro de chacune de ces fonctions génériques est supprimée pour accéder à une fonction réelle (par exemple si (strpbrk) ou un pointeur de fonction est utilisé), la déclaration de la fonction réelle (1) devient visible.

Le comportement est indéfini si dest ou breakset n'est pas un pointeur vers une chaîne d'octets terminée par un caractère nul.

Paramètres

  • dest — pointeur vers la chaîne d'octets terminée par un caractère nul à analyser
  • breakset — pointeur vers la chaîne d'octets terminée par un caractère nul contenant les caractères à rechercher

Valeur de retour

Pointeur vers le premier caractère de dest qui se trouve aussi dans breakset, ou pointeur nul si aucun tel caractère n'existe.

Notes

Le nom signifie « string pointer break » (pointeur de chaîne, rupture), car il renvoie un pointeur vers le premier caractère séparateur (« break »).

Exemple

#include <stdio.h>
#include <string.h>

int main(void)
{
    const char* str = "hello world, friend of mine!";
    const char* sep = " ,!";

    unsigned int cnt = 0;
    do
    {
       str = strpbrk(str, sep); // rechercher le séparateur
       if(str) str += strspn(str, sep); // ignorer le séparateur
       ++cnt; // incrémenter le nombre de mots
    }
    while(str && *str);

    printf("There are %u words\n", cnt);
}

Output:

There are 5 words
