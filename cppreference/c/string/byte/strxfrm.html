strxfrm

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <string.h>

size_t strxfrm( char          *dest, const char          *src, size_t count );  // (jusqu'à C99)

size_t strxfrm( char *restrict dest, const char *restrict src, size_t count );  // (depuis C99)

Transforme la chaîne d'octets terminée par un caractère nul pointée par src en une forme définie par l'implémentation, telle que la comparaison de deux chaînes transformées avec strcmp donne le même résultat que la comparaison des chaînes d'origine avec strcoll, dans la locale C courante.

Les count premiers caractères de la chaîne transformée sont écrits dans destination, y compris le caractère nul de fin, et la longueur de la chaîne transformée complète est retournée, sans compter le caractère nul de fin.

Le comportement est indéfini si le tableau dest n'est pas assez grand. Le comportement est indéfini si dest et src se chevauchent.

Si count vaut 0, alors dest peut être un pointeur nul.

Notes

La taille correcte du tampon pouvant recevoir la chaîne transformée entière est 1+strxfrm(NULL, src, 0)

Cette fonction est utilisée lorsqu'on effectue plusieurs comparaisons dépendant de la locale avec la même chaîne ou le même ensemble de chaînes, car il est plus efficace d'utiliser strxfrm pour transformer toutes les chaînes une seule fois, puis de comparer ensuite les chaînes transformées avec strcmp.

Paramètres

  • dest — pointeur vers le premier élément du tableau où la chaîne transformée sera écrite
  • src — pointeur vers le premier caractère d'une chaîne d'octets terminée par un caractère nul à transformer
  • count — nombre maximal de caractères à écrire

Valeur de retour

La longueur de la chaîne transformée, sans compter le caractère nul de fin.

Exemple

#include <stdio.h>
#include <string.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_COLLATE, "cs_CZ.iso88592");

    const char *in1 = "hrnec";
    char out1[1+strxfrm(NULL, in1, 0)];
    strxfrm(out1, in1, sizeof out1);

    const char *in2 = "chrt";
    char out2[1+strxfrm(NULL, in2, 0)];
    strxfrm(out2, in2, sizeof out2);

    printf("In the Czech locale: ");
    if(strcmp(out1, out2) < 0)
         printf("%s before %s\n",in1, in2);
    else
         printf("%s before %s\n",in2, in1);

    printf("In lexicographical comparison: ");
    if(strcmp(in1, in2)<0)
         printf("%s before %s\n",in1, in2);
    else
         printf("%s before %s\n",in2, in1);

}

Sortie possible :

In the Czech locale: hrnec before chrt
In lexicographical comparison: chrt before hrnec
