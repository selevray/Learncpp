memcpy, memcpy_s

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <string.h>

void* memcpy( void *dest, const void *src, size_t count );  // (jusqu'à C99)

void* memcpy( void *restrict dest, const void *restrict src, size_t count );  // (depuis C99)

errno_t memcpy_s( void *restrict dest, rsize_t destsz,
                  const void *restrict src, rsize_t count );  // (2) (depuis C11)
  1. Copie count caractères de l'objet pointé par src vers l'objet pointé par dest. Les deux objets sont interprétés comme des tableaux de unsigned char.

Le comportement est indéfini si un accès a lieu au-delà de la fin du tableau dest. Si les objets se chevauchent(ce qui viole le contrat de restrict) (depuis C99), le comportement est indéfini. Le comportement est indéfini si dest ou src est un pointeur invalide ou nul.

  1. Identique à (1), sauf que les erreurs suivantes sont détectées à l'exécution et entraînent la mise à zéro de toute la plage de destination [dest, dest+destsz) (si dest et destsz sont valides), ainsi que l'appel de la fonction gestionnaire de contraintes actuellement installée :
  • dest ou src est un pointeur nul
  • destsz ou count est supérieur à RSIZE_MAX
  • count est supérieur à destsz (un dépassement de tampon se produirait)
  • la source et la destination se chevauchent

Le comportement est indéfini si la taille du tableau de caractères pointé par dest < count <= destsz ; autrement dit, une valeur erronée de destsz n'expose pas le dépassement de tampon imminent.Comme pour toutes les fonctions à vérification de bornes, memcpy_s n'est garantie disponible que si __STDC_LIB_EXT1__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT1__ comme la constante entière 1 avant d'inclure <string.h>.

Paramètres

  • dest — pointeur vers l'objet de destination de la copie
  • destsz — nombre maximal d'octets à modifier dans la destination (généralement la taille de l'objet de destination)
  • src — pointeur vers l'objet source de la copie
  • count — nombre d'octets à copier

Valeur de retour

  1. Renvoie une copie de dest

  2. Renvoie zéro en cas de succès et une valeur non nulle en cas d'erreur. Également en cas d'erreur, si dest n'est pas un pointeur nul et que destsz est valide, écrit destsz octets nuls dans le tableau de destination.

Notes

memcpy peut être utilisé pour définir le type effectif d'un objet obtenu par une fonction d'allocation.

memcpy est la routine de bibliothèque la plus rapide pour la copie de mémoire à mémoire. Elle est généralement plus efficace que strcpy, qui doit parcourir les données qu'elle copie, ou que memmove, qui doit prendre des précautions pour gérer les entrées qui se chevauchent.

Plusieurs compilateurs C transforment les boucles appropriées de copie mémoire en appels à memcpy.

Lorsque le crénelage strict (strict aliasing) interdit d'examiner la même mémoire comme valeurs de deux types différents, memcpy peut être utilisée pour convertir les valeurs.

Exemple

#define __STDC_WANT_LIB_EXT1__ 1
#include <stdio.h>
#include <stdint.h>
#include <inttypes.h>
#include <string.h>
#include <stdlib.h>

int main(void)
{
    // utilisation simple
    char source[] = "once upon a midnight dreary...", dest[4];
    memcpy(dest, source, sizeof dest);
    for(size_t n = 0; n < sizeof dest; ++n)
        putchar(dest[n]);

    // définition du type effectif de la mémoire allouée comme int
    int *p = malloc(3*sizeof(int));   // la mémoire allouée n'a pas de type effectif
    int arr[3] = {1,2,3};
    memcpy(p,arr,3*sizeof(int));      // la mémoire allouée a désormais un type effectif

    // réinterprétation des données
    double d = 0.1;
//    int64_t n = *(int64_t*)(&d); // violation de l'aliasing strict
    int64_t n;
    memcpy(&n, &d, sizeof d); // OK
    printf("\n%a is %" PRIx64 " as an int64_t\n", d, n);

#ifdef __STDC_LIB_EXT1__
    set_constraint_handler_s(ignore_handler_s);
    char src[] = "aaaaaaaaaa";
    char dst[] = "xyxyxyxyxy";
    int r = memcpy_s(dst,sizeof dst,src,5);
    printf("dst = \"%s\", r = %d\n", dst,r);
    r = memcpy_s(dst,5,src,10);            //  count est supérieur à destsz
    printf("dst = \"");
    for(size_t ndx=0; ndx<sizeof dst; ++ndx) {
        char c = dst[ndx];
        c ? printf("%c", c) : printf("\\0");
    }
    printf("\", r = %d\n", r);
#endif
}
