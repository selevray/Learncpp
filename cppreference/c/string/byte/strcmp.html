strcmp

Défini dans l'en-tête <string.h>

int strcmp( const char* lhs, const char* rhs );

Compare lexicographiquement deux chaînes d'octets terminées par un caractère nul.

Le signe du résultat est celui de la différence entre les valeurs de la première paire de caractères (tous deux interprétés comme unsigned char) qui diffèrent dans les chaînes comparées.

Le comportement est indéfini si lhs ou rhs ne sont pas des pointeurs vers des chaînes d'octets terminées par un caractère nul.

Paramètres

  • lhs, rhs — pointeurs vers les chaînes d'octets terminées par un caractère nul à comparer

Valeur de retour

Valeur négative si lhs apparaît avant rhs dans l'ordre lexicographique.

Zéro si lhs et rhs sont égales.

Valeur positive si lhs apparaît après rhs dans l'ordre lexicographique.

Notes

Cette fonction n'est pas sensible à la locale, contrairement à strcoll et strxfrm.

Exemple

#include <stdio.h>
#include <string.h>

void demo(const char* lhs, const char* rhs)
{
    const int rc = strcmp(lhs, rhs);
    const char* rel = rc < 0 ? "precedes" : rc > 0 ? "follows" : "equals";
    printf("[%s] %s [%s]\n", lhs, rel, rhs);
}

int main(void)
{
    const char* string = "Hello World!";
    demo(string, "Hello!");
    demo(string, "Hello");
    demo(string, "Hello there");
    demo("Hello, everybody!" + 12, "Hello, somebody!" + 11);
}

Output:

[Hello World!] precedes [Hello!]
[Hello World!] follows [Hello]
[Hello World!] precedes [Hello there]
[body!] equals [body!]
