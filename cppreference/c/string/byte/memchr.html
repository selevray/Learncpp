memchr

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <string.h>

void* memchr( const void* ptr, int ch, size_t count );  // (1)

/*QVoid*/ *memchr( /*QVoid*/ *ptr, int ch, size_t count );  // (2) (depuis C23)

  1. Trouve la première occurrence de (unsigned char)ch dans les count premiers octets (chacun interprété comme unsigned char) de l'objet pointé par ptr.

  2. Fonction générique par type équivalente à (1). Soit T un type d'objet non qualifié (y compris void).

  • Si ptr est de type const T*, le type de retour est const void*.
  • Sinon, si ptr est de type T*, le type de retour est void*.
  • Dans le cas contraire, le comportement est indéfini. Si la définition de macro de chacune de ces fonctions génériques est supprimée pour accéder à une fonction réelle (par exemple si (memchr) ou un pointeur de fonction est utilisé), la déclaration de la fonction réelle (1) devient visible.

Le comportement est indéfini si un accès se produit au-delà de la fin du tableau recherché. Le comportement est indéfini si ptr est un pointeur nul.

Cette fonction se comporte comme si elle lisait les octets séquentiellement et s'arrêtait dès qu'un octet correspondant est trouvé : si le tableau pointé par ptr est plus petit que count, mais que la correspondance est trouvée à l'intérieur du tableau, le comportement est bien défini.

(depuis C11)

Paramètres

  • ptr — pointeur vers l'objet à examiner
  • ch — octets à rechercher
  • count — nombre maximal d'octets à examiner

Valeur de retour

Pointeur vers l'emplacement de l'octet, ou pointeur nul si cet octet n'est pas trouvé.

Exemple

#include <stdio.h>
#include <string.h>

int main(void)
{
    const char str[] = "ABCDEFG";
    const int chars[] = {'D', 'd'};
    for (size_t i = 0; i < sizeof chars / (sizeof chars[0]); ++i)
    {
        const int c = chars[i];
        const char *ps = memchr(str, c, strlen(str));
        ps ? printf ("character '%c'(%i) found: %s\n", c, c, ps)
           : printf ("character '%c'(%i) not found\n", c, c);
    }
    return 0;
}

Sortie possible :

character 'D'(68) found: DEFG
character 'd'(100) not found
