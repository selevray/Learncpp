int strcoll( const char* lhs, const char* rhs );

Compare deux chaînes d'octets terminées par un caractère nul selon la locale courante, telle que définie par la catégorie LC_COLLATE.

Paramètres

  • lhs, rhs — pointeurs vers les chaînes d'octets terminées par un caractère nul à comparer

Valeur de retour

  • Valeur négative si lhs est inférieure à (précède) rhs.
  • 0 si lhs est égale à rhs.
  • Valeur positive si lhs est supérieure à (suit) rhs.

Notes

L'ordre de collationnement est l'ordre du dictionnaire : la position de la lettre dans l'alphabet national (sa classe d'équivalence) a une priorité plus élevée que sa casse ou sa variante. Au sein d'une classe d'équivalence, les caractères minuscules se collationnent avant leurs équivalents majuscules, et un ordre propre à la locale peut s'appliquer aux caractères avec signes diacritiques. Dans certaines locales, des groupes de caractères se comparent comme des unités de collationnement uniques. Par exemple, "ch" en tchèque suit "h" et précède "i", et "dzs" en hongrois suit "dz" et précède "g".

Exemple

#include <locale.h>
#include <stdio.h>
#include <string.h>

int main(void)
{
    setlocale(LC_COLLATE, "cs_CZ.utf8");
    // Alternativement, ISO-8859-2 (aussi appelée Latin-2)
    // peut aussi fonctionner sur certains systèmes d'exploitation :
    // setlocale(LC_COLLATE, "cs_CZ.iso88592");

    const char* s1 = "hrnec";
    const char* s2 = "chrt";

    printf("In the Czech locale: ");
    if (strcoll(s1, s2) < 0)
        printf("%s before %s\n", s1, s2);
    else
        printf("%s before %s\n", s2, s1);

    printf("In lexicographical comparison: ");
    if (strcmp(s1, s2) < 0)
        printf("%s before %s\n", s1, s2);
    else
        printf("%s before %s\n", s2, s1);
}

Output:

In the Czech locale: hrnec before chrt
In lexicographical comparison: chrt before hrnec
