strdup

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <string.h>

char *strdup( const char *src );  // (depuis C23)

Renvoie un pointeur vers une chaîne d'octets terminée par un caractère nul, qui est une copie de la chaîne pointée par src. L'espace pour la nouvelle chaîne est obtenu comme si malloc avait été invoqué. Le pointeur renvoyé doit être passé à free pour éviter une fuite mémoire.

En cas d'erreur, un pointeur nul est renvoyé et errno peut être défini.

Paramètres

  • src — pointeur vers la chaîne d'octets terminée par un caractère nul à dupliquer

Valeur de retour

Un pointeur vers la chaîne nouvellement allouée, ou un pointeur nul en cas d'erreur.

Notes

La fonction est identique à strdup de POSIX.

Exemple

#include <string.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char *s1 = "Duplicate me!";
    char *s2 = strdup(s1);
    printf("s2 = \"%s\"\n", s2);
    free(s2);
}

Output:

s2 = "Duplicate me!"
