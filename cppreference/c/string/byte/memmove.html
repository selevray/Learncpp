memmove, memmove_s

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <string.h>

void* memmove( void* dest, const void* src, size_t count );  // (1)

errno_t memmove_s(void* dest, rsize_t destsz, const void* src, rsize_t count);  // (2) (depuis C11)
  1. Copie count caractères de l'objet pointé par src vers l'objet pointé par dest. Les deux objets sont interprétés comme des tableaux de unsigned char. Les objets peuvent se chevaucher : la copie s'effectue comme si les caractères étaient copiés dans un tableau temporaire de caractères, puis copiés depuis ce tableau vers dest.

Le comportement est indéfini si un accès a lieu au-delà de la fin du tableau dest. Le comportement est indéfini si dest ou src est un pointeur invalide ou nul.

  1. Identique à (1), sauf que lors de la détection des erreurs suivantes à l'exécution, elle met à zéro toute la plage de destination [dest, dest + destsz) (si dest et destsz sont valides) et appelle la fonction gestionnaire de contraintes actuellement installée :
  • dest ou src est un pointeur nul
  • destsz ou count est supérieur à RSIZE_MAX
  • count est supérieur à destsz (un dépassement de tampon se produirait)

Le comportement est indéfini si la taille du tableau de caractères pointé par dest < count <= destsz ; autrement dit, une valeur erronée de destsz n'expose pas le dépassement de tampon imminent.Comme pour toutes les fonctions à vérification de bornes, memmove_s n'est garantie disponible que si __STDC_LIB_EXT1__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT1__ comme la constante entière 1 avant d'inclure <string.h>.

Paramètres

  • dest — pointeur vers l'objet de destination de la copie
  • destsz — nombre maximal d'octets à modifier dans la destination (généralement la taille de l'objet de destination)
  • src — pointeur vers l'objet source de la copie
  • count — nombre d'octets à copier

Valeur de retour

  1. Renvoie une copie de dest

  2. Renvoie zéro en cas de succès et une valeur non nulle en cas d'erreur. Également en cas d'erreur, si dest n'est pas un pointeur nul et que destsz est valide, écrit destsz octets nuls dans le tableau de destination.

Notes

memmove peut être utilisé pour définir le type effectif d'un objet obtenu par une fonction d'allocation.

Bien qu'elle soit spécifiée « comme si » un tampon temporaire était utilisé, les implémentations réelles de cette fonction n'engendrent ni surcoût, ni double copie, ni mémoire supplémentaire. Une approche courante (glibc et bsd libc) consiste à copier les octets en avant depuis le début du tampon si la destination commence avant la source, et en arrière depuis la fin sinon, avec un repli vers la plus efficace memcpy lorsqu'il n'y a aucun chevauchement.

Lorsque le crénelage strict (strict aliasing) interdit d'examiner la même mémoire comme valeurs de deux types différents, memmove peut être utilisée pour convertir les valeurs.

Exemple

#define __STDC_WANT_LIB_EXT1__ 1
#include <inttypes.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    char str[] = "1234567890";
    puts(str);
    memmove(str + 4, str + 3, 3); // copie de [4,5,6] vers [5,6,7]
    puts(str);

    // définition du type effectif de la mémoire allouée comme int
    int* p = malloc(3 * sizeof(int)); // la mémoire allouée n'a pas de type effectif
    int arr[3] = {1, 2, 3};
    memmove(p, arr, 3 * sizeof(int)); // la mémoire allouée a désormais un type effectif

    // réinterprétation des données
    double d = 0.1;
    // int64_t n = *(int64_t*)(&d); // violation de l'aliasing strict
    int64_t n;
    memmove(&n, &d, sizeof d); // OK
    printf("%a is %" PRIx64 " as an int64_t\n", d, n);

#ifdef __STDC_LIB_EXT1__
    set_constraint_handler_s(ignore_handler_s);
    char src[] = "aaaaaaaaaa";
    char dst[] = "xyxyxyxyxy";
    int r = memmove_s(dst, sizeof dst, src, 5);
    printf("dst = \"%s\", r = %d\n", dst, r);
    r = memmove_s(dst, 5, src, 10); // count est supérieur à destsz
    printf("dst = \"");
    for (size_t ndx = 0; ndx < sizeof dst; ++ndx)
    {
        char c = dst[ndx];
        c ? printf("%c", c) : printf("\\0");
    }
    printf("\", r = %d\n", r);
#endif
}
