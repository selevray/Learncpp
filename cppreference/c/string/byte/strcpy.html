strcpy, strcpy_s

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <string.h>

char *strcpy( char *dest, const char *src );  // (jusqu'à C99)

char *strcpy( char *restrict dest, const char *restrict src );  // (depuis C99)

errno_t strcpy_s( char *restrict dest, rsize_t destsz, const char *restrict src );  // (2) (depuis C11)
  1. Copie la chaîne d'octets terminée par un caractère nul pointée par src, y compris le caractère nul de fin, dans le tableau de caractères dont le premier élément est pointé par dest.

Le comportement est indéfini si le tableau dest n'est pas assez grand. Le comportement est indéfini si les chaînes se chevauchent. Le comportement est indéfini si l'un des dest n'est pas un pointeur vers un tableau de caractères ou si src n'est pas un pointeur vers une chaîne d'octets terminée par un caractère nul.

  1. Identique à (1), à ceci près qu'elle peut écraser le reste du tableau de destination avec des valeurs non spécifiées et que les erreurs suivantes sont détectées à l'exécution et appellent la fonction gestionnaire de contraintes actuellement installée :
  • src ou dest est un pointeur nul
  • destsz vaut zéro ou est supérieur à RSIZE_MAX
  • destsz est inférieur ou égal à strnlen_s(src, destsz) ; en d'autres termes, une troncature se produirait
  • un chevauchement se produirait entre la chaîne source et la chaîne de destination

Le comportement est indéfini si la taille du tableau de caractères pointé par dest <= strnlen_s(src, destsz) < destsz ; en d'autres termes, une valeur erronée de destsz n'expose pas le dépassement de tampon imminent.Comme pour toutes les fonctions à vérification de bornes, strcpy_s n'est garantie disponible que si __STDC_LIB_EXT1__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT1__ comme la constante entière 1 avant d'inclure <string.h>.

Paramètres

  • dest — pointeur vers le tableau de caractères dans lequel écrire
  • src — pointeur vers la chaîne d'octets terminée par un caractère nul à copier
  • destsz — nombre maximal de caractères à écrire, généralement la taille du tampon de destination

Valeur de retour

  1. renvoie une copie de dest

  2. renvoie zéro en cas de succès, une valeur non nulle en cas d'erreur. De plus, en cas d'erreur, écrit zéro dans dest[0] (sauf si dest est un pointeur nul ou si destsz vaut zéro ou est supérieur à RSIZE_MAX).

Notes

strcpy_s est autorisé à écraser le tableau de destination à partir du dernier caractère écrit jusqu'à destsz afin d'améliorer l'efficacité : il peut copier par blocs multi-octets puis vérifier la présence d'octets nuls.

La fonction strcpy_s est similaire à la fonction BSD strlcpy, à ceci près que

  • strlcpy tronque la chaîne source pour qu'elle tienne dans la destination (ce qui représente un risque pour la sécurité)
  • strlcpy n'effectue pas toutes les vérifications à l'exécution que strcpy_s effectue
  • strlcpy ne rend pas les échecs évidents en définissant la destination comme chaîne nulle ou en appelant un gestionnaire si l'appel échoue.

Bien que strcpy_s interdise la troncature en raison de risques de sécurité potentiels, il est possible de tronquer une chaîne à l'aide de strncpy_s, qui vérifie les bornes.

Exemple

#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char *src = "Take the test.";
//  src[0] = 'M' ; // ceci serait un comportement indéfini
    char dst[strlen(src) + 1]; // +1 pour tenir compte du caractère nul de fin
    strcpy(dst, src);
    dst[0] = 'M'; // OK
    printf("src = %s\ndst = %s\n", src, dst);

#ifdef __STDC_LIB_EXT1__
    set_constraint_handler_s(ignore_handler_s);
    int r = strcpy_s(dst, sizeof dst, src);
    printf("dst = \"%s\", r = %d\n", dst, r);
    r = strcpy_s(dst, sizeof dst, "Take even more tests.");
    printf("dst = \"%s\", r = %d\n", dst, r);
#endif
}

Sortie possible :

src = Take the test.
dst = Make the test.
dst = "Take the test.", r = 0
dst = "", r = 22
