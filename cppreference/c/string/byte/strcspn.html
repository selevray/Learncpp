size_t strcspn( const char *dest, const char *src );

Renvoie la longueur du segment initial maximal de la chaîne d'octets terminée par un caractère nul pointée par dest, qui ne contient que des caractères non présents dans la chaîne d'octets terminée par un caractère nul pointée par src.

Le comportement est indéfini si dest ou src n'est pas un pointeur vers une chaîne d'octets terminée par un caractère nul.

Paramètres

  • dest — pointeur vers la chaîne d'octets terminée par un caractère nul à analyser
  • src — pointeur vers la chaîne d'octets terminée par un caractère nul contenant les caractères à rechercher

Valeur de retour

La longueur du segment initial maximal ne contenant que des caractères absents de la chaîne d'octets terminée par un caractère nul pointée par src

Notes

Le nom de la fonction signifie « étendue complémentaire » car la fonction recherche les caractères absents de src, c'est-à-dire le complément de src.

Exemple

#include <string.h>
#include <stdio.h>

int main(void)
{
    const char *string = "abcde312$#@";
    const char *invalid = "*$#";

    size_t valid_len = strcspn(string, invalid);
    if(valid_len != strlen(string))
       printf("'%s' contains invalid chars starting at position %zu\n",
               string, valid_len);
}

Output:

'abcde312$#@' contains invalid chars starting at position 8
