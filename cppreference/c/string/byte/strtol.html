strtol, strtoll

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

long      strtol( const char*          str, char**          str_end, int base );  // (jusqu'à C99)

long      strtol( const char* restrict str, char** restrict str_end, int base );  // (depuis C99)

long long strtoll( const char* restrict str, char** restrict str_end, int base );  // (depuis C99)

Interprète une valeur entière dans une chaîne d'octets pointée par str.

Ignore tous les caractères d'espacement (tels qu'identifiés par l'appel à isspace) jusqu'à ce que le premier caractère non espace soit trouvé, puis prend autant de caractères que possible pour former une représentation valide d'entier en base base-n (où n=base) et les convertit en valeur entière. La valeur entière valide se compose des parties suivantes :

  • (facultatif) signe plus ou moins
  • (facultatif) préfixe (0) indiquant la base octale (s'applique uniquement lorsque la base vaut 8 ou 0)
  • (optionnel) préfixe (0x ou 0X) indiquant la base hexadécimale (ne s'applique que lorsque la base vaut 16 ou 0)
  • une suite de chiffres

L'ensemble des valeurs valides pour base est {0, 2, 3, ..., 36}. L'ensemble des chiffres valides pour les entiers en base-2 est {0, 1}, pour les entiers en base-3 est {0, 1, 2}, et ainsi de suite. Pour les bases supérieures à 10, les chiffres valides incluent les caractères alphabétiques, à partir de Aa pour un entier en base-11, jusqu'à Zz pour un entier en base-36. La casse des caractères est ignorée.

Des formats numériques supplémentaires peuvent être acceptés par la locale C actuellement installée.

Si la valeur de base vaut 0, la base numérique est détectée automatiquement : si le préfixe est 0, la base est octale ; si le préfixe est 0x ou 0X, la base est hexadécimale ; sinon, la base est décimale.

Si le signe moins faisait partie de la séquence d'entrée, la valeur numérique calculée à partir de la séquence de chiffres est niée comme par moins unaire dans le type de résultat.

Les fonctions font pointer le pointeur désigné par str_end sur le caractère qui suit le dernier caractère numérique interprété. Si str_end est un pointeur nul, il est ignoré.

Si str est vide ou n'a pas la forme attendue, aucune conversion n'est effectuée et (si str_end n'est pas un pointeur nul) la valeur de str est stockée dans l'objet pointé par str_end.

Paramètres

  • str — pointeur vers la chaîne d'octets terminée par un caractère nul à interpréter
  • str_end — pointeur vers un pointeur vers un caractère
  • base — base de la valeur entière interprétée

Valeur de retour

  • En cas de succès, une valeur entière correspondant au contenu de str est renvoyée.
  • Si la valeur convertie sort de l'intervalle du type de retour correspondant, une erreur de dépassement de plage se produit (en mettant errno à ERANGE) et LONG_MAX, LONG_MIN, LLONG_MAX ou LLONG_MIN est renvoyé.
  • Si aucune conversion ne peut être effectuée, 0 est retourné.

Exemple

#include <errno.h>
#include <limits.h>
#include <stdbool.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    // analyse avec gestion des erreurs
    const char* p = "10 200000000000000000000000000000 30 -40 junk";
    printf("Parsing '%s':\n", p);

    for (;;)
    {
        // errno peut être mis à n'importe quelle valeur non nulle par un appel de fonction de la bibliothèque
        // qu'il y ait eu ou non une erreur, il faut donc le remettre à zéro
        // afin de vérifier l'erreur définie par strtol
        errno = 0;
        char* end;
        const long i = strtol(p, &end, 10);
        if (p == end)
            break;

        const bool range_error = errno == ERANGE;
        printf("Extracted '%.*s', strtol returned %ld.", (int)(end-p), p, i);
        p = end;

        if (range_error)
            printf("\n --> Range error occurred.");

        putchar('\n');
    }

    printf("Unextracted leftover: '%s'\n\n", p);

    // analyse sans gestion des erreurs
    printf("\"1010\" in binary  --> %ld\n", strtol("1010", NULL, 2));
    printf("\"12\"   in octal   --> %ld\n", strtol("12",   NULL, 8));
    printf("\"A\"    in hex     --> %ld\n", strtol("A",    NULL, 16));
    printf("\"junk\" in base-36 --> %ld\n", strtol("junk", NULL, 36));
    printf("\"012\"  in auto-detected base --> %ld\n", strtol("012",  NULL, 0));
    printf("\"0xA\"  in auto-detected base --> %ld\n", strtol("0xA",  NULL, 0));
    printf("\"junk\" in auto-detected base --> %ld\n", strtol("junk", NULL, 0));
}
