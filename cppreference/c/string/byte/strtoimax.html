strtoimax, strtoumax

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <inttypes.h>

intmax_t strtoimax( const char* restrict nptr,
                    char** restrict endptr, int base );  // (1) (depuis C99)

uintmax_t strtoumax( const char* restrict nptr,
                     char** restrict endptr, int base );  // (2) (depuis C99)

Interprète une valeur entière dans une chaîne d'octets pointée par nptr.

Ignore tous les caractères d'espacement (tels qu'identifiés par l'appel à isspace) jusqu'à ce que le premier caractère non espace soit trouvé, puis prend autant de caractères que possible pour former une représentation valide d'entier en base base-n (où n=base) et les convertit en valeur entière. La valeur entière valide se compose des parties suivantes :

  • (facultatif) signe plus ou moins
  • (facultatif) préfixe (0) indiquant la base octale (s'applique uniquement lorsque la base vaut 8 ou 0)
  • (optionnel) préfixe (0x ou 0X) indiquant la base hexadécimale (ne s'applique que lorsque la base vaut 16 ou 0)
  • une suite de chiffres

L'ensemble des valeurs valides pour base est {0, 2, 3, ..., 36}. L'ensemble des chiffres valides pour les entiers en base-2 est {0, 1}, pour les entiers en base-3 est {0, 1, 2}, et ainsi de suite. Pour les bases supérieures à 10, les chiffres valides incluent les caractères alphabétiques, à partir de Aa pour un entier en base-11, jusqu'à Zz pour un entier en base-36. La casse des caractères est ignorée.

Des formats numériques supplémentaires peuvent être acceptés par la locale C actuellement installée.

Si la valeur de base vaut 0, la base numérique est détectée automatiquement : si le préfixe est 0, la base est octale ; si le préfixe est 0x ou 0X, la base est hexadécimale ; sinon, la base est décimale.

Si le signe moins faisait partie de la séquence d'entrée, la valeur numérique calculée à partir de la séquence de chiffres est niée comme par moins unaire dans le type de résultat.

La fonction fait pointer le pointeur désigné par endptr vers le caractère situé après le dernier caractère interprété. Si endptr est un pointeur nul, il est ignoré.

Si nptr est vide ou n'a pas la forme attendue, aucune conversion n'est effectuée et (si endptr n'est pas un pointeur nul) la valeur de nptr est stockée dans l'objet pointé par endptr.

Paramètres

  • nptr — pointeur vers la chaîne d'octets terminée par un caractère nul à interpréter
  • endptr — pointeur vers un pointeur vers un caractère
  • base — base de la valeur entière interprétée

Valeur de retour

  • En cas de succès, une valeur entière correspondant au contenu de str est renvoyée.
  • Si la valeur convertie sort de l'intervalle du type de retour correspondant, une erreur de dépassement de plage se produit (en mettant errno à ERANGE) et INTMAX_MAX, INTMAX_MIN, UINTMAX_MAX ou 0 est renvoyé, selon le cas.
  • Si aucune conversion ne peut être effectuée, 0 est retourné.

Exemple

#include <errno.h>
#include <inttypes.h>
#include <stdio.h>
#include <string.h>

int main(void)
{
    char* endptr = NULL;

    printf("%ld\n", strtoimax(" -123junk", &endptr, 10)); // base 10
    printf("%ld\n", strtoimax("11111111", &endptr, 2));   // base 2
    printf("%ld\n", strtoimax("XyZ", &endptr, 36));       // base 36
    printf("%ld\n", strtoimax("010", &endptr, 0));        // détection automatique de l'octal
    printf("%ld\n", strtoimax("10", &endptr, 0));         // détection automatique du décimal
    printf("%ld\n", strtoimax("0x10", &endptr, 0));       // détection automatique de l'hexadécimal

    // erreur de dépassement : LONG_MAX+1 --> LONG_MAX
    errno = 0;
    printf("%ld\n", strtoimax("9223372036854775808", &endptr, 10));
    printf("%s\n", strerror(errno));
}
