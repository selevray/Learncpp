strlen, strnlen_s

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <string.h>

size_t strlen( const char* str );  // (1)

size_t strnlen_s( const char* str, size_t strsz );  // (2) (depuis C11)
  1. Renvoie la longueur de la chaîne d'octets terminée par un nul donnée, c'est-à-dire le nombre de caractères d'un tableau de caractères dont le premier élément est pointé par str, jusqu'au premier caractère nul exclu.

Le comportement est indéfini si str n'est pas un pointeur vers une chaîne d'octets terminée par un nul.

  1. Identique à (1), sauf que la fonction renvoie zéro si str est un pointeur nul et renvoie strsz si le caractère nul n'a pas été trouvé dans les premiers strsz octets de str.

Le comportement est indéfini si str n'est pas un pointeur vers une chaîne d'octets terminée par un nul et si strsz est supérieur à la taille de ce tableau de caractères.Comme pour toutes les fonctions à vérification de bornes, strnlen_s n'est garantie disponible que si __STDC_LIB_EXT1__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT1__ comme la constante entière 1 avant d'inclure <string.h>.

Paramètres

  • str — pointeur vers la chaîne d'octets terminée par un caractère nul à examiner
  • strsz — nombre maximal de caractères à examiner

Valeur de retour

  1. La longueur de la chaîne d'octets terminée par un nul str.

  2. La longueur de la chaîne d'octets terminée par un nul str en cas de succès, zéro si str est un pointeur nul, strsz si le caractère nul n'a pas été trouvé.

Notes

strnlen_s et wcsnlen_s sont les seules fonctions à vérification de bornes qui n'invoquent pas le gestionnaire de contraintes à l'exécution. Ce sont des fonctions utilitaires pures, utilisées pour fournir une prise en charge limitée des chaînes non terminées par un nul.

Exemple

#define __STDC_WANT_LIB_EXT1__ 1
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char str[] = "How many characters does this string contain?";

    printf("without null character: %zu\n", strlen(str));
    printf("with null character:    %zu\n", sizeof str);

#ifdef __STDC_LIB_EXT1__
    printf("without null character: %zu\n", strnlen_s(str, sizeof str));
#endif
}

without null character: 45
with null character:    46
