size_t strspn( const char* dest, const char* src );

Retourne la longueur du segment initial maximal (span) de la chaîne d'octets terminée par un caractère nul pointée par dest, qui ne contient que des caractères présents dans la chaîne d'octets terminée par un caractère nul pointée par src.

Le comportement est indéfini si dest ou src n'est pas un pointeur vers une chaîne d'octets terminée par un caractère nul.

Paramètres

  • dest — pointeur vers la chaîne d'octets terminée par un caractère nul à analyser
  • src — pointeur vers la chaîne d'octets terminée par un caractère nul contenant les caractères à rechercher

Valeur de retour

La longueur du segment initial maximal ne contenant que des caractères de la chaîne d'octets terminée par un caractère nul pointée par src.

Exemple

#include <stdio.h>
#include <string.h>

int main(void)
{
    const char* string = "abcde312$#@";
    const char* low_alpha = "qwertyuiopasdfghjklzxcvbnm";

    size_t spnsz = strspn(string, low_alpha);
    printf("After skipping initial lowercase letters from '%s'\n"
           "The remainder is '%s'\n", string, string + spnsz);
}

Output:

After skipping initial lowercase letters from 'abcde312$#@'
The remainder is '312$#@'
