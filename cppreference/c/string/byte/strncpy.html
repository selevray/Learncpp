strncpy, strncpy_s

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <string.h>

char *strncpy( char *dest, const char *src, size_t count );  // (jusqu'à C99)

char *strncpy( char *restrict dest, const char *restrict src, size_t count );  // (depuis C99)

errno_t strncpy_s( char *restrict dest, rsize_t destsz,
                   const char *restrict src, rsize_t count );  // (2) (depuis C11)
  1. Copie au plus count caractères du tableau de caractères pointé par src (y compris le caractère nul de fin, mais aucun des caractères qui suivent le caractère nul) vers le tableau de caractères pointé par dest.

Si count est atteint avant que tout le tableau src ait été copié, le tableau de caractères résultant n'est pas terminé par un nul.

Si, après la copie du caractère nul de fin depuis src, count n'est pas atteint, des caractères nuls supplémentaires sont écrits dans dest jusqu'à ce que le total de count caractères ait été écrit.

Le comportement est indéfini si les tableaux de caractères se chevauchent, si l'un de dest ou src n'est pas un pointeur vers un tableau de caractères (y compris si dest ou src est un pointeur nul), si la taille du tableau pointé par dest est inférieure à count, ou si la taille du tableau pointé par src est inférieure à count et qu'il ne contient pas de caractère nul.

  1. Identique à (1), sauf que la fonction ne continue pas à écrire des zéros dans le tableau de destination pour le compléter jusqu'à count, elle s'arrête après avoir écrit le caractère nul de fin (s'il n'y avait pas de nul dans la source, elle en écrit un à dest[count] puis s'arrête). De plus, les erreurs suivantes sont détectées à l'exécution et appellent la fonction gestionnaire de contraintes actuellement installée :
  • src ou dest est un pointeur nul
  • destsz vaut zéro ou est supérieur à RSIZE_MAX
  • count est supérieur à RSIZE_MAX
  • count est supérieur ou égal à destsz, mais destsz est inférieur ou égal à strnlen_s(src, count), autrement dit, une troncature se produirait
  • un chevauchement se produirait entre la chaîne source et la chaîne de destination

Le comportement est indéfini si la taille du tableau de caractères pointé par dest < strnlen_s(src, destsz) <= destsz ; autrement dit, une valeur erronée de destsz n'expose pas le dépassement de tampon imminent. Le comportement est indéfini si la taille du tableau de caractères pointé par src < strnlen_s(src, count) < destsz ; autrement dit, une valeur erronée de count n'expose pas le dépassement de tampon imminent.Comme pour toutes les fonctions à vérification de bornes, strncpy_s n'est garantie disponible que si __STDC_LIB_EXT1__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT1__ comme la constante entière 1 avant d'inclure <string.h>.

Paramètres

  • dest — pointeur vers le tableau de caractères de destination
  • src — pointeur vers le tableau de caractères à copier
  • count — nombre maximal de caractères à copier
  • destsz — la taille du tampon de destination

Valeur de retour

  1. renvoie une copie de dest

  2. renvoie zéro en cas de succès, renvoie non nul en cas d'erreur. De plus, en cas d'erreur, écrit zéro dans dest[0] (sauf si dest est un pointeur nul ou si destsz vaut zéro ou est supérieur à RSIZE_MAX) et peut écraser le reste du tableau de destination avec des valeurs non spécifiées.

Notes

Comme corrigé par le rapport de défaut DR 468 postérieur à C11, strncpy_s, contrairement à strcpy_s, ne peut écraser le reste du tableau de destination que si une erreur se produit.

Contrairement à strncpy, strncpy_s ne complète pas le tableau de destination avec des zéros. C'est une source fréquente d'erreurs lors de la conversion de code existant vers la version à vérification de bornes.

Bien que la troncature pour tenir dans le tampon de destination soit un risque de sécurité et donc une violation de contraintes à l'exécution pour strncpy_s, il est possible d'obtenir le comportement de troncature en spécifiant count égal à la taille du tableau de destination moins un : elle copiera les premiers count octets et ajoutera le terminateur nul comme toujours : strncpy_s(dst, sizeof dst, src, (sizeof dst)-1);

Exemple

#define __STDC_WANT_LIB_EXT1__ 1
#include <string.h>
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>

int main(void)
{
    char src[] = "hi";
    char dest[6] = "abcdef"; // pas de caractère de fin de chaîne nul
    strncpy(dest, src, 5); // écrit cinq caractères 'h', 'i', '\0', '\0', '\0' dans dest
    printf("strncpy(dest, src, 5) to a 6-byte dest gives : ");
    for (size_t n = 0; n < sizeof dest; ++n) {
        char c = dest[n];
        c ? printf("'%c' ", c) : printf("'\\0' ");
    }

    printf("\nstrncpy(dest2, src, 2) to a 2-byte dst gives : ");
    char dest2[2];
    strncpy(dest2, src, 2); // troncature : écrit deux caractères 'h', 'i' dans dest2
    for (size_t n = 0; n < sizeof dest2; ++n) {
        char c = dest2[n];
        c ? printf("'%c' ", c) : printf("'\\0' ");
    }
    printf("\n");

#ifdef __STDC_LIB_EXT1__
    set_constraint_handler_s(ignore_handler_s);
    char dst1[6], src1[100] = "hello";
    errno_t r1 = strncpy_s(dst1, 6, src1, 100);  // écrit 0 dans r1, 6 caractères dans dst1
    printf("dst1 = \"%s\", r1 = %d\n", dst1,r1); // 'h','e','l','l','o','\0' dans dst1

    char dst2[5], src2[7] = {'g','o','o','d','b','y','e'};
    errno_t r2 = strncpy_s(dst2, 5, src2, 7);    // la copie dépasse la taille du tableau de destination
    printf("dst2 = \"%s\", r2 = %d\n", dst2,r2); // écrit une valeur non nulle dans r2, '\0' dans dst2[0]

    char dst3[5];
    errno_t r3 = strncpy_s(dst3, 5, src2, 4);    // écrit 0 dans r3, 5 caractères dans dst3
    printf("dst3 = \"%s\", r3 = %d\n", dst3,r3); // 'g', 'o', 'o', 'd', '\0' dans dst3
#endif
}

Sortie possible :

strncpy(dest, src, 5) to a 6-byte dst gives : 'h' 'i' '\0' '\0' '\0' 'f'
strncpy(dest2, src, 2) to a 2-byte dst gives : 'h' 'i'
dst1 = "hello", r1 = 0
dst2 = "", r2 = 22
dst3 = "good", r3 = 0
