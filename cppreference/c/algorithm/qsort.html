qsort, qsort_s

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

void qsort( void* ptr, size_t count, size_t size,
            int (*comp)(const void*, const void*) );  // (1)

errno_t qsort_s( void* ptr, rsize_t count, rsize_t size,
                 int (*comp)(const void*, const void*, void*),
                 void* context );  // (2) (depuis C11)

  1. Trie le tableau donné pointé par ptr par ordre croissant. Le tableau contient count éléments de size octets. La fonction pointée par comp est utilisée pour la comparaison des objets.

  2. Identique à (1), à la différence que le paramètre de contexte supplémentaire context est transmis à comp et que les erreurs suivantes sont détectées à l'exécution, appelant la fonction gestionnaire de contraintes actuellement installée :

  • count ou size est supérieur à RSIZE_MAX
  • ptr ou comp est un pointeur nul (sauf si count vaut zéro) Comme pour toutes les fonctions à vérification de bornes, qsort_s n'est garantie disponible que si __STDC_LIB_EXT1__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT1__ comme la constante entière 1 avant d'inclure <stdlib.h>.

Si comp indique que deux éléments sont équivalents, leur ordre dans le tableau trié résultant n'est pas spécifié.

Paramètres

  • ptr — pointeur vers le tableau à trier

  • count — nombre d'éléments du tableau

  • size — taille de chaque élément du tableau en octets

  • comp — fonction de comparaison qui renvoie un entier négatif si le premier argument est inférieur au second, un entier positif si le premier argument est supérieur au second, et zéro si les arguments sont équivalents.

    La signature de la fonction de comparaison doit être équivalente à la suivante :

    int cmp(const void *a, const void *b);

    La fonction ne doit pas modifier les objets qui lui sont passés et doit renvoyer des résultats cohérents lorsqu'elle est appelée pour les mêmes objets, quelle que soit leur position dans le tableau.

  • context — informations supplémentaires (par exemple, séquence de collationnement), passées à comp comme troisième argument

Valeur de retour

  1. (aucun)

  2. zéro en cas de succès, non nul si une violation de contraintes à l'exécution a été détectée

Notes

Malgré son nom, ni la norme C ni la norme POSIX n'exigent que cette fonction soit implémentée à l'aide de quicksort, ni ne garantissent une complexité ou une stabilité particulière.

Contrairement aux autres fonctions à vérification de bornes, qsort_s ne traite pas les tableaux de taille nulle comme une violation de contraintes à l'exécution et renvoie au contraire un succès sans modifier le tableau (l'autre fonction qui accepte les tableaux de taille nulle est bsearch_s).

L'implémentation de qsort_s dans le CRT Windows est incompatible avec la norme C. La version de Microsoft est déclarée ainsi : void qsort_s(void *base, size_t num, size_t width, int (*compare )(void *, const void *, const void *), void * context);. Elle ne renvoie aucune valeur, et la fonction de comparaison a un ordre des paramètres inversé par rapport à la norme : le context est passé en premier.

Exemple

#include <limits.h>
#include <stdio.h>
#include <stdlib.h>

int compare_ints(const void* a, const void* b)
{
    int arg1 = *(const int*)a;
    int arg2 = *(const int*)b;

    if (arg1 < arg2) return -1;
    if (arg1 > arg2) return 1;
    return 0;

    // return (arg1 > arg2) - (arg1 < arg2); // raccourci possible

    // return arg1 - arg2; // raccourci erroné : comportement indéfini en cas de
                           // dépassement de capacité entier, comme avec INT_MIN ici
}

int main(void)
{
    int ints[] = {-2, 99, 0, -743, 2, INT_MIN, 4};
    int size = sizeof ints / sizeof *ints;

    qsort(ints, size, sizeof(int), compare_ints);

    for (int i = 0; i < size; i++)
        printf("%d ", ints[i]);

    printf("\n");
}

Output:

-2147483648 -743 -2 0 2 4 99
