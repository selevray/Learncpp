Liste de bibliothèques C open source

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

L'objectif de cette page est de constituer une liste complète de bibliothèques C open source, afin que lorsqu'on a besoin d'une implémentation d'une fonctionnalité particulière, on n'ait pas à perdre de temps à chercher sur le web (DuckDuckGo, Google, Bing, etc.)

Si vous connaissez une bibliothèque qui pourrait être utile à d'autres, veuillez ajouter ici un lien vers elle. Aucune restriction n'est imposée quant à ce qui peut être inclus, sauf que le code source de la bibliothèque doit être facilement disponible au téléchargement.

La page est fournie « telle quelle », dans l'espoir qu'elle soit utile, mais sans aucune garantie. Des liens obsolètes, trompeurs ou erronés peuvent apparaître ici. Si vous en remarquez, il serait formidable de corriger l'erreur.
