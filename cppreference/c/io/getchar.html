getchar

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

int getchar( void );

Lit le caractère suivant depuis stdin.

Équivalent à getc(stdin).

Paramètres

(aucune)

Valeur de retour

Le caractère obtenu en cas de succès, ou EOF en cas d'échec.

Si l'échec est dû à une condition de fin de fichier, positionne en plus l'indicateur eof (voir feof()) sur stdin. Si l'échec est dû à une autre erreur, positionne l'indicateur error (voir ferror()) sur stdin.

Exemple

Démontre getchar avec vérification des erreurs

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    for (int ch; (ch = getchar()) != EOF;) // lire/afficher "abcde" depuis stdin
        printf("%c", ch);

    // Teste la raison de l'atteinte de la fin de fichier.
    if (feof(stdin)) // si l'échec est causé par une condition de fin de fichier
        puts("End of file reached");
    else if (ferror(stdin)) // si l'échec est causé par une autre erreur
    {
        perror("getchar()");
        fprintf(stderr, "getchar() failed in file %s at line # %d\n",
                __FILE__, __LINE__ - 9);
        exit(EXIT_FAILURE);
    }

    return EXIT_SUCCESS;
}
