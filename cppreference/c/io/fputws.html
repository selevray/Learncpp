fputws

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <wchar.h>

int fputws( const wchar_t *str, FILE *stream );  // (depuis C95) (jusqu'à C99)

int fputws( const wchar_t * restrict str, FILE * restrict stream );  // (depuis C99)

Écrit chaque caractère de la chaîne large terminée par un caractère nul str dans le flux de sortie stream, comme si l'on exécutait répétitivement fputwc.

Le caractère large nul de fin de str n'est pas écrit.

Paramètres

  • str — chaîne large terminée par un caractère nul à écrire
  • stream — flux de sortie

Valeur de retour

En cas de succès, renvoie une valeur non négative

En cas d'échec, renvoie EOF et positionne l'indicateur error (voir ferror) sur stream.

Exemple

#include <locale.h>
#include <stdio.h>
#include <wchar.h>

int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
    int rc = fputws(L"御休みなさい", stdout);

    if (rc == EOF)
       perror("fputws()"); // POSIX exige que errno soit positionné
}

Output:

御休みなさい
