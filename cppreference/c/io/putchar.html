putchar

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

int putchar( int ch );

Écrit le caractère ch vers stdout. En interne, le caractère est converti en unsigned char juste avant d'être écrit.

Équivalent à putc(ch, stdout).

Paramètres

  • ch — caractère à écrire

Valeur de retour

En cas de succès, renvoie le caractère écrit.

En cas d'échec, renvoie EOF et positionne l'indicateur error (voir ferror()) sur stdout.

Exemple

Affiche putchar avec vérification des erreurs

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int ret_code = 0;
    for (char c = 'a'; (ret_code != EOF) && (c != 'z'); c++)
        ret_code = putchar(c);

    // Teste si EOF a été atteint.
    if (ret_code == EOF && ferror(stdout))
    {
        fprintf(stderr, "putchar() failed in file %s at line # %d\n",
                __FILE__, __LINE__ - 6);
        perror("putchar()");
        exit(EXIT_FAILURE);
    }
    putchar('\n');

    // la valeur de retour de putchar n'est pas égale à l'argument
    int r = 0x1070;
    printf("\n0x%x\n", r);
    r = putchar(r);
    printf("\n0x%x\n", r);
}

Output:

abcdefghijklmnopqrstuvwxy

0x1070
p
0x70
