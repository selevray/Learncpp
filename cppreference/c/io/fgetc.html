fgetc, getc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

int fgetc( FILE* stream );  // (1)

int getc( FILE* stream );  // (2)

  1. Lit le caractère suivant depuis le flux d'entrée donné.

  2. Identique à fgetc, sauf que si getc est implémentée comme une macro, elle peut évaluer le flux plus d'une fois ; l'argument correspondant ne doit donc jamais être une expression avec effets de bord.

Paramètres

  • stream — le flux duquel lire le caractère

Valeur de retour

En cas de succès, renvoie le caractère obtenu, converti en unsigned char puis en int. En cas d'échec, renvoie EOF.

Si l'échec est dû à une condition de fin de fichier, positionne en plus l'indicateur eof (voir feof()) sur stream. Si l'échec est dû à une autre erreur, positionne l'indicateur error (voir ferror()) sur stream.

Exemple

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char* fname = "/tmp/unique_name.txt"; // ou tmpnam(NULL);
    int is_ok = EXIT_FAILURE;

    FILE* fp = fopen(fname, "w+");
    if (!fp)
    {
        perror("File opening failed");
        return is_ok;
    }
    fputs("Hello, world!\n", fp);
    rewind(fp);

    int c; // note : int, et non char, requis pour gérer EOF
    while ((c = fgetc(fp)) != EOF) // boucle standard de lecture de fichier en C avec E/S
        putchar(c);

    if (ferror(fp))
        puts("I/O error when reading");
    else if (feof(fp))
    {
        puts("End of file is reached successfully");
        is_ok = EXIT_SUCCESS;
    }

    fclose(fp);
    remove(fname);
    return is_ok;
}

Sortie possible :

Hello, world!
End of file is reached successfully
