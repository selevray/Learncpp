setvbuf

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

int setvbuf( FILE *         stream, char *         buffer,
             int mode, size_t size );  // (jusqu'à C99)

int setvbuf( FILE *restrict stream, char *restrict buffer,
             int mode, size_t size );  // (depuis C99)

#define _IOFBF     /*unspecified*/
#define _IOLBF     /*unspecified*/
#define _IONBF     /*unspecified*/

Modifie le mode de mise en tampon du flux de fichier donné stream selon l'argument mode. De plus,

  • Si buffer est un pointeur nul, redimensionne le tampon interne à size.
  • Si buffer n'est pas un pointeur nul, demande au flux d'utiliser le tampon fourni par l'utilisateur, de taille size, commençant à buffer. Le flux doit être fermé (avec fclose) avant la durée de vie du tableau pointé par buffer se termine. Le contenu du tableau après un appel réussi à setvbuf est indéterminé, et toute tentative de l'utiliser est un comportement indéfini.

Paramètres

  • stream — le flux de fichier dont le tampon doit être défini

  • buffer — pointeur vers un tampon à utiliser par le flux, ou pointeur nul pour ne modifier que la taille et le mode

  • mode — mode de mise en tampon à utiliser. Il peut s'agir de l'une des valeurs suivantes :

    _IOFBF | mise en tampon complète

    _IOLBF | mise en tampon par ligne

    _IONBF | absence de mise en tampon

  • size — taille du tampon

Valeur de retour

0 en cas de succès, ou valeur non nulle en cas d'échec.

Notes

Cette fonction ne peut être utilisée qu'après que stream a été associé à un fichier ouvert, mais avant toute autre opération (autre qu'un appel échoué à setbuf/setvbuf).

Tous les octets size ne seront pas nécessairement utilisés pour la mise en tampon : la taille effective du tampon est généralement arrondie à un multiple de 2, à un multiple de la taille de page, etc.

Sur de nombreuses implémentations, la mise en tampon par ligne n'est disponible que pour les flux d'entrée des terminaux.

Une erreur courante consiste à définir le tampon de stdin ou stdout comme un tableau dont la durée de vie se termine avant la fin du programme :

int main(void) {
    char buf[BUFSIZ];
    setbuf(stdin, buf);
} // la durée de vie de buf se termine, comportement indéfini

La taille de tampon par défaut BUFSIZ est censée être la taille de tampon la plus efficace pour les E/S de fichiers sur l'implémentation, mais POSIX fstat fournit souvent une meilleure estimation.

Exemple

Un cas d'utilisation de la modification de la taille du tampon est lorsqu'une meilleure taille est connue. (Cet exemple utilise une fonction POSIX, par exemple fileno. Voir aussi SO : #1 et #2).

// Rendre visibles certaines fonctions POSIX, telles que `int fileno(FILE*)` :
#define _POSIX_SOURCE

#include <stdio.h>
#include <stdlib.h>
#include <sys/stat.h>

int main(void)
{
    FILE* fp = fopen("/tmp/test.txt", "w+");
    if (fp == NULL)
    {
        perror("fopen");
        return EXIT_FAILURE;
    }

    struct stat stats;
    if (fstat(fileno(fp), &stats) == -1) // POSIX uniquement
    {
        perror("fstat");
        return EXIT_FAILURE;
    }

    printf("BUFSIZ is %d, but optimal block size is %ld\n", BUFSIZ, stats.st_blksize);
    if (setvbuf(fp, NULL, _IOFBF, stats.st_blksize) != 0)
    {
        perror("setvbuf failed"); // La version POSIX définit errno
        return EXIT_FAILURE;
    }

    int ch;
    while((ch=fgetc(fp)) != EOF); // lire le fichier entier : utiliser truss/strace pour
                                  // observer les appels système read(2) utilisés

    fclose(fp);
    return EXIT_SUCCESS;
}

Sortie possible :

BUFSIZ is 8192, but optimal block size is 65536
