fputwc, putwc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <wchar.h>

wint_t fputwc( wchar_t ch, FILE* stream );  // (1) (depuis C95)

wint_t putwc( wchar_t ch, FILE* stream );  // (2) (depuis C95)

Écrit un caractère large ch dans le flux de sortie donné stream.

  1. Peut être implémentée comme une macro et peut évaluer stream plus d'une fois.

Paramètres

  • ch — caractère large à écrire
  • stream — le flux de sortie

Valeur de retour

Renvoie une copie de ch en cas de succès.

En cas d'échec, renvoie WEOF et positionne l'indicateur error (voir ferror()) sur stream.

Si une erreur d'encodage s'est produite, définit en plus errno à EILSEQ.

Exemple

#include <errno.h>
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <wchar.h>

int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");

    errno = 0;
    if (fputwc(L'🍌', stdout) == WEOF)
    {
        if (errno == EILSEQ)
            puts("Encoding error in fputwc.");
        else
            puts("I/O error in fputwc.");
        return EXIT_FAILURE;
    }
}
