ftell

Défini dans l'en-tête <stdio.h>

long ftell( FILE* stream );

Renvoie l'indicateur de position dans le fichier pour le flux de fichier stream.

Si le flux est ouvert en mode binaire, la valeur obtenue par cette fonction est le nombre d'octets depuis le début du fichier.

Si le flux est ouvert en mode texte, la valeur renvoyée par cette fonction n'est pas spécifiée et n'a de sens que comme entrée de fseek().

Paramètres

  • stream — flux de fichier à examiner

Valeur de retour

Indicateur de position dans le fichier en cas de succès, ou -1L en cas d'échec.

En cas d'erreur, la variable errno est définie à une valeur positive défini par l'implémentation.

Notes

Sous Windows, _ftelli64 peut être utilisé pour travailler avec des fichiers de plus de 2 Gio.

Exemple

Illustre ftell() avec vérification des erreurs. Écrit puis lit quelques valeurs à virgule flottante (FP) dans un fichier.

#include <stdio.h>
#include <stdlib.h>

/* Si la condition n'est pas remplie, quitter le programme avec un message d'erreur. */
void check(_Bool condition, const char* func, int line)
{
    if (condition)
        return;
    perror(func);
    fprintf(stderr, "%s failed in file %s at line # %d\n", func, __FILE__, line - 1);
    exit(EXIT_FAILURE);
}

int main(void)
{
    /* Préparer un tableau de valeurs FP. */
    #define SIZE 5
    double A[SIZE] = {1.1, 2.0, 3.0, 4.0, 5.0};

    /* Écrire le tableau dans un fichier. */
    const char* fname = "/tmp/test.bin";
    FILE* file = fopen(fname, "wb");
    check(file != NULL, "fopen()", __LINE__);

    const int write_count = fwrite(A, sizeof(double), SIZE, file);
    check(write_count == SIZE, "fwrite()", __LINE__);

    fclose(file);

    /* Lire les valeurs FP dans le tableau B. */
    double B[SIZE];
    file = fopen(fname, "rb");
    check(file != NULL, "fopen()", __LINE__);

    long int pos = ftell(file); /* indicateur de position au début du fichier */
    check(pos != -1L, "ftell()", __LINE__);
    printf("pos: %ld\n", pos);

    const int read_count = fread(B, sizeof(double), 1, file); /* lire une valeur FP */
    check(read_count == 1, "fread()", __LINE__);

    pos = ftell(file); /* indicateur de position après la lecture d'une valeur FP */
    check(pos != -1L, "ftell()", __LINE__);
    printf("pos: %ld\n", pos);
    printf("B[0]: %.1f\n", B[0]); /* afficher une valeur FP */

    return EXIT_SUCCESS;
}

Sortie possible :

pos: 0
pos: 8
B[0]: 1.1
