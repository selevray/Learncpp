tmpfile, tmpfile_s

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

FILE* tmpfile( void );  // (1)

errno_t tmpfile_s( FILE* restrict* restrict streamptr );  // (2) (depuis C11)

  1. Crée et ouvre un fichier temporaire. Le fichier est ouvert en tant que fichier binaire en mise à jour (comme avec fopen en mode "wb+"). Le nom de fichier est garanti unique au sein du système de fichiers. Au moins TMP_MAX fichiers peuvent être ouverts pendant la durée de vie d'un programme (cette limite peut être partagée avec tmpnam et davantage limitée par FOPEN_MAX).

  2. Identique à (1), sauf qu'au moins TMP_MAX_S fichiers peuvent être ouverts (la limite peut être partagée avec tmpnam_s), et si streamptr est un pointeur nul, la fonction gestionnaire de contraintes actuellement installée est appelée.Comme pour toutes les fonctions à vérification de bornes, tmpfile_s n'est garantie disponible que si __STDC_LIB_EXT1__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT1__ comme la constante entière 1 avant d'inclure <stdio.h>.

Le fichier temporaire créé par cette fonction est fermé et supprimé à la fin normale du programme. Sa suppression en cas de terminaison anormale est définie par l'implémentation.

Paramètres

  1. (aucun)

  2. pointeur vers un pointeur qui sera mis à jour par cet appel de fonction

Valeur de retour

  1. Pointeur vers le flux de fichier associé au fichier, ou pointeur nul si une erreur s'est produite.

  2. Zéro si le fichier a été créé et ouvert avec succès, non nul si le fichier n'a pas pu être créé ou ouvert, ou si streamptr est un pointeur nul. De plus, le pointeur vers le flux de fichier associé est stocké dans *streamptr en cas de succès, et une valeur de pointeur nul est stockée dans *streamptr en cas d'erreur.

Notes

Sur certaines implémentations (par exemple les anciens Linux), cette fonction crée, ouvre et supprime immédiatement le fichier du système de fichiers : tant qu'un descripteur de fichier ouvert vers un fichier supprimé est détenu par un programme, le fichier existe, mais comme il a été supprimé, son nom n'apparaît dans aucun répertoire, de sorte qu'aucun autre processus ne peut l'ouvrir. Une fois le descripteur de fichier fermé, ou une fois le programme terminé (normalement ou anormalement), l'espace occupé par le fichier est récupéré par le système de fichiers. Les Linux récents (depuis la version 3.11 ou ultérieure, selon le système de fichiers) créent ces fichiers temporaires invisibles en une seule étape, via un indicateur spécial de l'appel système open().

Sur certaines implémentations (par exemple Windows), des privilèges élevés sont requis, car la fonction peut créer le fichier temporaire dans un répertoire système.

Exemple

#define _POSIX_C_SOURCE 200112L
#include <stdio.h>
#include <unistd.h>

int main(void)
{
    printf("TMP_MAX = %d, FOPEN_MAX = %d\n", TMP_MAX, FOPEN_MAX);
    FILE* tmpf = tmpfile();
    fputs("Hello, world", tmpf);
    rewind(tmpf);
    char buf[6];
    fgets(buf, sizeof buf, tmpf);
    printf("got back from the file: '%s'\n", buf);

    // Méthode propre à Linux pour afficher le nom du fichier tmpfile
    char fname[FILENAME_MAX], link[FILENAME_MAX] = {0};
    sprintf(fname, "/proc/self/fd/%d", fileno(tmpf));
    if (readlink(fname, link, sizeof link - 1) > 0)
        printf("File name: %s\n", link);
}
