fgets

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

char* fgets( char*          str, int count, FILE*          stream );  // (jusqu'à C99)

char* fgets( char* restrict str, int count, FILE* restrict stream );  // (depuis C99)

Lit au plus count - 1 caractères depuis le flux de fichier donné et les stocke dans le tableau de caractères pointé par str. L'analyse s'arrête si un caractère de fin de ligne est rencontré (auquel cas str contiendra ce caractère de fin de ligne) ou si une fin de fichier survient. Si des octets sont lus et qu'aucune erreur ne survient, écrit un caractère nul à la position immédiatement après le dernier caractère écrit dans str.

Paramètres

  • str — pointeur vers un élément d'un tableau de char
  • count — nombre maximal de caractères à écrire (généralement la longueur de str)
  • stream — flux de fichier duquel lire les données

Valeur de retour

str en cas de succès, pointeur nul en cas d'échec.

Si la condition de fin de fichier est rencontrée, positionne l'indicateur eof sur stream (voir feof()). Ce n'est un échec que si aucun octet n'a été lu ; dans ce cas, un pointeur nul est renvoyé et le contenu du tableau pointé par str n'est pas modifié (c'est-à-dire que le premier octet n'est pas écrasé par un caractère nul).

Si l'échec a été causé par une autre erreur, positionne l'indicateur error (voir ferror()) sur stream. Le contenu du tableau pointé par str est indéterminé (il peut même ne pas être terminé par un caractère nul).

Notes

POSIX exige en outre que fgets positionne errno si une erreur de lecture survient.

Bien que la spécification de la norme soit peu claire dans les cas où count <= 1, les implémentations courantes font

  • si count < 1, ne rien faire, signaler une erreur,
  • if count == 1,
    • certaines implémentations ne font rien, signalent une erreur,
    • d'autres ne lisent rien, stockent zéro dans str[0], signalent un succès.

Exemple

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    FILE* tmpf = tmpfile();
    fputs("Alan Turing\n", tmpf);
    fputs("John von Neumann\n", tmpf);
    fputs("Alonzo Church\n", tmpf);

    rewind(tmpf);

    char buf[8];
    while (fgets(buf, sizeof buf, tmpf) != NULL)
          printf("\"%s\"\n", buf);

    if (feof(tmpf))
       puts("End of file reached");
}
