ferror

Défini dans l'en-tête <stdio.h>

int ferror( FILE *stream );

Vérifie si le flux donné présente des erreurs.

Paramètres

  • stream — le flux de fichier à vérifier

Valeur de retour

Valeur non nulle si des erreurs se sont produites sur le flux de fichier, 0 sinon

Exemple

#include <stdio.h>
#include <stdlib.h>
#include <locale.h>
#include <wchar.h>

int main(void)
{
    char* fname = tmpnam(NULL);
    FILE* f = fopen(fname, "wb");
    fputs("\xff\xff\n", f); // séquence de caractères UTF-8 non valide
    fclose(f);

    setlocale(LC_ALL, "en_US.utf8");
    f = fopen(fname, "rb");
    wint_t ch;
    while ((ch=fgetwc(f)) != WEOF) // la tentative de lecture en UTF-8 échoue
          printf("%#x ", ch);

    if (feof(f))
        puts("EOF indicator set");
    if (ferror(f))
        puts("Error indicator set");
}

Output:

Error indicator set
