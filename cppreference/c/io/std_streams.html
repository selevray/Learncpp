stdin, stdout, stderr

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

#define stdin  /* implementation-defined */  // (1)

#define stdout /* implementation-defined */  // (2)

#define stderr /* implementation-defined */  // (3)

Trois flux de texte sont prédéfinis. Ces flux sont implicitement ouverts et non orientés au démarrage du programme.

  1. Associé au flux entrée standard, utilisé pour la lecture de l'entrée conventionnelle. Au démarrage du programme, le flux est entièrement tamponné si et seulement s'il peut être déterminé qu'il ne fait pas référence à un périphérique interactif.

  2. Associé au flux sortie standard, utilisé pour l'écriture de la sortie conventionnelle. Au démarrage du programme, le flux est entièrement tamponné si et seulement s'il peut être déterminé qu'il ne fait pas référence à un périphérique interactif.

  3. Associé au flux d'erreur standard, utilisé pour écrire la sortie de diagnostic. Au démarrage du programme, le flux n'est pas entièrement tamponné.

Ce qui constitue un périphérique interactif est défini par l'implémentation.

Ces macros sont développées en expressions de type FILE*.

Notes

Bien que non imposé par POSIX, la convention UNIX veut que stdin et stdout soient tamponnés par ligne s'ils sont associés à un terminal, et que stderr soit sans tampon.

Ces macros peuvent être développées en lvalues modifiables. Si l'une de ces lvalues FILE* est modifiée, les opérations ultérieures sur le flux correspondant entraînent un comportement non spécifié ou indéfini.

Exemple

Cet exemple montre une fonction équivalente à printf.

#include <stdarg.h>
#include <stdio.h>

int my_printf(const char* restrict fmt, ...)
{
    va_list vl;
    va_start(vl, fmt);
    int ret = vfprintf(stdout, fmt, vl);
    va_end(vl);
    return ret;
}

int main(void)
{
    my_printf("Rounding:\t%f %.0f %.32f\n", 1.5, 1.5, 1.3);
    my_printf("Padding:\t%05.2f %.2f %5.2f\n", 1.5, 1.5, 1.5);
    my_printf("Scientific:\t%E %e\n", 1.5, 1.5);
    my_printf("Hexadecimal:\t%a %A\n", 1.5, 1.5);
}
