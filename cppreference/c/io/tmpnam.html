tmpnam, tmpnam_s

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

char *tmpnam( char *filename );  // (1)

errno_t tmpnam_s(char *filename_s, rsize_t maxsize);  // (2) (depuis C11)

#define TMP_MAX        /*unspecified*/

#define TMP_MAX_S      /*unspecified*/  // (depuis C11)

#define L_tmpnam       /*unspecified*/

#define L_tmpnam_s     /*unspecified*/  // (depuis C11)

  1. Crée un nom de fichier valide et unique (d'une longueur maximale de L_tmpnam) et le stocke dans la chaîne de caractères pointée par filename. La fonction peut générer jusqu'à TMP_MAX noms de fichiers uniques, mais certains ou la totalité d'entre eux peuvent être déjà utilisés dans le système de fichiers et donc ne pas constituer des valeurs de retour appropriées.

  2. Identique à (1), sauf que jusqu'à TMP_MAX_S noms peuvent être générés, d'une longueur maximale de L_tmpnam_s, et les erreurs suivantes sont détectées à l'exécution et appellent la fonction gestionnaire de contraintes actuellement installée :

  • filename_s est un pointeur nul
  • maxsize est supérieur à RSIZE_MAX
  • maxsize est inférieur à la chaîne de nom de fichier générée Comme pour toutes les fonctions à vérification de bornes, tmpnam_s n'est garantie disponible que si __STDC_LIB_EXT1__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT1__ comme la constante entière 1 avant d'inclure <stdio.h>.

tmpnam et tmpnam_s modifient un état statique (qui peut être partagé entre ces fonctions) et ne sont pas tenus d'être sûrs vis-à-vis des threads.

Paramètres

  • filename — pointeur vers le tableau de caractères pouvant contenir au moins L_tmpnam octets, utilisé comme tampon de résultat. Si un pointeur nul est passé, un pointeur vers un tampon statique interne est renvoyé.
  • filename_s — pointeur vers le tableau de caractères pouvant contenir au moins L_tmpnam_s octets, utilisé comme tampon de résultat.
  • maxsize — nombre maximal de caractères que la fonction est autorisée à écrire (généralement la taille du tableau filename_s).

Valeur de retour

  1. filename si filename n'était pas un pointeur nul. Sinon, un pointeur vers un tampon statique interne est renvoyé. Si aucun nom de fichier approprié ne peut être généré, un pointeur nul est renvoyé.

  2. Renvoie zéro et écrit le nom de fichier dans filename_s en cas de succès. En cas d'erreur, renvoie une valeur non nulle et écrit le caractère nul dans filename_s[0] (uniquement si filename_s n'est pas nul, que maxsize n'est pas nul et n'est pas supérieur à RSIZE_MAX).

Notes

Bien que les noms générés par tmpnam soient difficiles à deviner, il est possible qu'un fichier portant ce nom soit créé par un autre processus entre le moment où tmpnam retourne et le moment où ce programme tente d'utiliser le nom retourné pour créer un fichier. La fonction standard tmpfile et la fonction POSIX mkstemp n'ont pas ce problème (la création d'un répertoire unique en utilisant uniquement la bibliothèque standard C nécessite toujours l'utilisation de tmpnam).

Les systèmes POSIX définissent en outre la fonction de nom similaire tempnam, qui offre le choix d'un répertoire (qui vaut par défaut la macro P_tmpdir, si elle est définie).

Exemple

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    // Notez que le compilateur ou l'éditeur de liens peut émettre un avertissement de sécurité, par exemple GCC :
    // "warning: the use of `tmpnam' is dangerous, better use `mkstemp'"
    char* name1 = tmpnam(NULL);
    printf("temporary file name: %s\n", name1);

    char name2[L_tmpnam];
    if (tmpnam(name2))
        printf("temporary file name: %s\n", name2);

    // POSIX propose mkstemp. La déclaration suivante pourrait être
    // nécessaire, car mkstemp est absent de l'en-tête standard C <stdlib.h>.
    int mkstemp(char*);

    char name3[] = "/tmp/fileXXXXXX"; // au moins six 'X' requis ^_^
    int file_descriptor = mkstemp(name3);
    if (file_descriptor != -1)
        printf("temporary file name: %s\n", name3);
    else
        perror("mkstemp");
}
