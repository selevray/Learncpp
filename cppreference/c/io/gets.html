gets, gets_s

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

char* gets( char* str );  // (1) (supprimé en C11)

char* gets_s( char* str, rsize_t n );  // (2) (depuis C11)

  1. Lit stdin dans le tableau de caractères pointé par str jusqu'à ce qu'un caractère de fin de ligne soit trouvé ou qu'une fin de fichier survienne. Un caractère nul est écrit immédiatement après le dernier caractère lu dans le tableau. Le caractère de fin de ligne est ignoré mais non stocké dans le tampon.

  2. Lit des caractères depuis stdin jusqu'à ce qu'une fin de ligne soit trouvée ou qu'une fin de fichier survienne. N'écrit au plus que n - 1 caractères dans le tableau pointé par str, et écrit toujours le caractère nul de terminaison (sauf si str est un pointeur nul). Le caractère de fin de ligne, s'il est trouvé, est ignoré et ne compte pas dans le nombre de caractères écrits dans le tampon.

Les erreurs suivantes sont détectées à l'exécution et appellent la fonction gestionnaire de contraintes actuellement installée :

  • n vaut zéro ;
  • n est supérieur à RSIZE_MAX ;
  • str est un pointeur nul ;
  • endline ou eof non rencontré après le stockage de n - 1 caractères dans le tampon.

Dans tous les cas, gets_s termine d'abord la lecture et l'ignorance des caractères de stdin jusqu'au caractère de fin de ligne, à la condition de fin de fichier ou à l'erreur de lecture, avant d'appeler le gestionnaire de contraintes.

Comme pour toutes les fonctions à vérification de bornes, gets_s n'est garantie disponible que si __STDC_LIB_EXT1__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT1__ comme la constante entière 1 avant d'inclure <stdio.h>.

Paramètres

  • str — un tableau de caractères dans lequel les caractères de stdin doivent être écrits
  • n — nombre maximal de caractères pouvant être écrits dans le tableau pointé par str

Valeur de retour

str en cas de succès, un pointeur nul en cas d'échec.

Si l'échec est dû à une condition de fin de fichier, positionne en plus l'indicateur eof (voir feof()) sur stdin. Si l'échec est dû à une autre erreur, positionne l'indicateur error (voir ferror()) sur stdin.

Notes

La fonction gets() n'effectue pas de vérification de bornes ; elle est donc extrêmement vulnérable aux attaques par dépassement de tampon. Elle ne peut pas être utilisée en toute sécurité (sauf si le programme s'exécute dans un environnement qui restreint ce qui peut apparaître sur stdin). Pour cette raison, la fonction a été rendue obsolète dans le troisième corrigendum de la norme C99 et supprimée complètement dans la norme C11. fgets() et gets_s() sont les remplacements recommandés.

AVERTISSEMENT : n'utilisez jamais gets().
