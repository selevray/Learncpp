fwrite

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

size_t fwrite( const void* buffer, size_t size, size_t count,
               FILE* stream );  // (jusqu'à C99)

size_t fwrite( const void* restrict buffer, size_t size, size_t count,
               FILE* restrict stream );  // (depuis C99)

Écrit count d'objets du tableau donné buffer dans le flux de sortie stream. Les objets sont écrits comme si chaque objet était réinterprété en tant que tableau de unsigned char et que fputc était appelée size fois pour chaque objet afin d'écrire ces unsigned char dans stream, dans l'ordre. L'indicateur de position dans le fichier du flux est avancé du nombre de caractères écrits.

En cas d'erreur, la valeur résultante de l'indicateur de position dans le fichier du flux est indéterminée.

Paramètres

  • buffer — pointeur vers le premier objet du tableau à écrire
  • size — taille de chaque objet
  • count — nombre d'objets à écrire
  • stream — pointeur vers le flux de sortie

Valeur de retour

Le nombre d'objets écrits avec succès, qui peut être inférieur à count si une erreur survient.

Si size ou count est nul, fwrite renvoie zéro et n'effectue aucune autre action.

Exemple

#include <assert.h>
#include <stdio.h>
#include <stdlib.h>

enum { SIZE = 5 };

int main(void)
{
    double a[SIZE] = {1, 2, 3, 4, 5};
    FILE* f1 = fopen("file.bin", "wb");
    assert(f1);
    size_t r1 = fwrite(a, sizeof a[0], SIZE, f1);
    printf("wrote %zu elements out of %d requested\n", r1, SIZE);
    fclose(f1);

    double b[SIZE];
    FILE* f2 = fopen("file.bin", "rb");
    size_t r2 = fread(b, sizeof b[0], SIZE, f2);
    fclose(f2);
    printf("read back: ");
    for (size_t i = 0; i < r2; ++i)
        printf("%0.2f ", b[i]);
}

Output:

wrote 5 elements out of 5 requested
read back: 1.00 2.00 3.00 4.00 5.00
