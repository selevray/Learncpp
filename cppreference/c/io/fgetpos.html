fgetpos

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

int fgetpos( FILE*          stream, fpos_t*          pos );  // (jusqu'à C99)

int fgetpos( FILE* restrict stream, fpos_t* restrict pos );  // (depuis C99)

Obtient l'indicateur de position dans le fichier et l'état d'analyse courant (le cas échéant) pour le flux de fichier stream et les stocke dans l'objet pointé par pos. La valeur stockée n'a de sens que comme entrée de fsetpos.

Paramètres

  • stream — flux de fichier à examiner
  • pos — pointeur vers un objet fpos_t où stocker l'indicateur de position dans le fichier

Valeur de retour

0 en cas de succès, valeur non nulle sinon.

Exemple

#include <assert.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    // préparer un fichier contenant 4 valeurs de type double
    enum {SIZE = 4};
    FILE* fp = fopen("test.bin", "wb");
    assert(fp);
    int rc = fwrite((double[SIZE]){1.1, 2.2, 3.3, 4.4}, sizeof(double), SIZE, fp);
    assert(rc == SIZE);
    fclose(fp);

    // démonstration de l'utilisation de fsetpos pour revenir au début d'un fichier
    fp = fopen("test.bin", "rb");
    fpos_t pos;
    fgetpos(fp, &pos);               // enregistrer le début du fichier dans pos
    double d;
    rc = fread(&d, sizeof d, 1, fp); // lire le premier double
    assert(rc == 1);
    printf("First value in the file: %.1f\n", d);
    fsetpos(fp,&pos);                // replacer la position du fichier au début du fichier
    rc = fread(&d, sizeof d, 1, fp); // relire le premier double
    assert(rc == 1);
    printf("First value in the file again: %.1f\n", d);
    fclose(fp);

    // démonstration de la gestion des erreurs
    rc = fsetpos(stdin, &pos);
    if (rc)
        perror("could not fsetpos stdin");
}

Output:

First value in the file: 1.1
First value in the file again: 1.1
could not fsetpos stdin: Illegal seek
