fgetwc, getwc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <wchar.h>

wint_t fgetwc( FILE *stream );  // (depuis C95)

wint_t getwc( FILE *stream );  // (depuis C95)

Lit le caractère large suivant depuis le flux d'entrée donné. getwc() peut être implémentée comme une macro et peut évaluer stream plus d'une fois.

Paramètres

  • stream — depuis lequel lire le caractère large

Valeur de retour

Le caractère large suivant du flux, ou WEOF en cas d'échec.

Si l'échec est dû à une condition de fin de fichier, positionne en plus l'indicateur eof (voir feof()) sur stream. Si l'échec est dû à une autre erreur, positionne l'indicateur error (voir ferror()) sur stream.

Si une erreur d'encodage s'est produite, définit en plus errno à EILSEQ.

Exemple

#include <stdio.h>
#include <stdlib.h>
#include <wchar.h>
#include <errno.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "en_US.utf8");
    FILE *fp = fopen("fgetwc.dat", "w");
    if(!fp) {
        perror("Can't open file for writing");
        return EXIT_FAILURE;
    }
    fputs("кошка\n", fp);
    fclose(fp);

    fp = fopen("fgetwc.dat", "r");
    if(!fp) {
        perror("Can't open file for reading");
        return EXIT_FAILURE;
    }
    wint_t wc;
    errno = 0;
    while ((wc = fgetwc(fp)) != WEOF)
        putwchar(wc);

    if (ferror(fp)) {
        if (errno == EILSEQ)
            puts("Character encoding error while reading.");
        else
            puts("I/O error when reading");
    } else if (feof(fp))
        puts("End of file reached successfully");

    fclose(fp);
}

Output:

кошка
