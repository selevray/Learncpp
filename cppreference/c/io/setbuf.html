setbuf

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

void setbuf( FILE          *stream, char          *buffer );  // (jusqu'à C99)

void setbuf( FILE *restrict stream, char *restrict buffer );  // (depuis C99)

#define BUFSIZ     /*unspecified*/

Définit le tampon interne à utiliser pour les opérations sur le flux. Il doit comporter au moins BUFSIZ caractères.

Si buffer n'est pas nul, équivalent à setvbuf(stream, buffer, _IOFBF, BUFSIZ).

Si buffer est nul, équivalent à setvbuf(stream, NULL, _IONBF, 0), ce qui désactive la mise en tampon.

Paramètres

  • stream — le flux de fichier dont le tampon doit être défini
  • buffer — pointeur vers un tampon à utiliser par le flux. Si un pointeur nul est fourni, la mise en tampon est désactivée

Valeur de retour

Aucun.

Notes

Si BUFSIZ n'est pas la taille de tampon appropriée, setvbuf peut être utilisée pour la modifier.

setvbuf doit également être utilisée pour détecter les erreurs, car setbuf n'indique ni succès ni échec.

Cette fonction ne peut être utilisée qu'après que stream a été associé à un fichier ouvert, mais avant toute autre opération (autre qu'un appel échoué à setbuf/setvbuf).

Une erreur courante consiste à définir le tampon de stdin ou stdout comme un tableau dont la durée de vie se termine avant la fin du programme :

int main(void) {
    char buf[BUFSIZ];
    setbuf(stdin, buf);
} // la durée de vie de buf se termine, comportement indéfini

Exemple

setbuf peut être utilisée pour désactiver la mise en tampon des flux nécessitant une sortie immédiate.

#include <stdio.h>
#include <threads.h>

int main(void)
{
    setbuf(stdout, NULL); // stdout sans tampon
    putchar('a'); // 'a' apparaît immédiatement si stdout n'est pas tamponné
    thrd_sleep(&(struct timespec){.tv_sec=1}, NULL); // attendre 1 seconde
    putchar('b');
}

Output:

ab
