fputs

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

int fputs( const char*          str, FILE*          stream );  // (jusqu'à C99)

int fputs( const char* restrict str, FILE* restrict stream );  // (depuis C99)

Écrit chaque caractère de la chaîne terminée par un caractère nul str dans le flux de sortie stream, comme si l'on exécutait répétitivement fputc.

Le caractère nul de fin de str n'est pas écrit.

Paramètres

  • str — chaîne de caractères terminée par un caractère nul à écrire
  • stream — flux de sortie

Valeur de retour

En cas de succès, renvoie une valeur non négative.

En cas d'échec, renvoie EOF et positionne l'indicateur error (voir ferror()) sur stream.

Notes

La fonction associée puts ajoute un caractère de saut de ligne à la sortie, tandis que fputs écrit la chaîne sans modification.

Les différentes implémentations renvoient des nombres non négatifs différents : certaines renvoient le dernier caractère écrit, certaines renvoient le nombre de caractères écrits (ou INT_MAX si la chaîne était plus longue que cela), d'autres renvoient simplement une constante non négative, telle que zéro.

Exemple

#include <stdio.h>

int main(void)
{
    int rc = fputs("Hello World", stdout);

    if (rc == EOF)
       perror("fputs()"); // POSIX exige que errno soit positionné
}

Output:

Hello World
