puts

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

int puts( const char* str );

Écrit chaque caractère de la chaîne terminée par un caractère nul str, puis un caractère de saut de ligne supplémentaire '\n', dans le flux de sortie stdout, comme si l'on exécutait répétitivement fputc.

Le caractère nul de fin de str n'est pas écrit.

Paramètres

  • str — chaîne de caractères à écrire

Valeur de retour

En cas de succès, renvoie une valeur non négative.

En cas d'échec, renvoie EOF et positionne l'indicateur error (voir ferror()) sur stream.

Notes

La fonction puts ajoute le caractère de saut de ligne à la sortie, alors que la fonction fputs ne le fait pas.

Différentes implémentations renvoient différents nombres non négatifs : certaines renvoient le dernier caractère écrit, d'autres le nombre de caractères écrits (ou INT_MAX si la chaîne était plus longue que cela), d'autres encore une simple constante non négative.

Une cause typique d'échec de puts est le manque d'espace sur le système de fichiers, lorsque stdout est redirigé vers un fichier.

Exemple

#include <stdio.h>

int main(void)
{
    int rc = puts("Hello World");

    if (rc == EOF)
        perror("puts()"); // POSIX exige que errno soit positionné
}

Output:

Hello World
