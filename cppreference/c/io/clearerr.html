Défini dans l'en-tête <stdio.h>

void clearerr( FILE *stream );

Réinitialise les indicateurs d'erreur et l'indicateur EOF pour le flux de fichier donné.

Paramètres

  • stream — le fichier dont les indicateurs d'erreur doivent être réinitialisés

Valeur de retour

(aucune)

Exemple

#include <stdio.h>
#include <assert.h>

int main(void)
{
    FILE* tmpf = tmpfile();
    fputs("cppreference.com\n", tmpf);
    rewind(tmpf);

    for (int ch; (ch = fgetc(tmpf)) != EOF; putchar(ch)) { }

    assert(feof(tmpf)); // la boucle doit normalement se terminer par EOF
    puts("End of file reached");

    clearerr(tmpf); // effacer EOF

    puts(feof(tmpf) ? "EOF indicator set"
                    : "EOF indicator cleared");
}

EOF indicator cleared
