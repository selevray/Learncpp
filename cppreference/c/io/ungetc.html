ungetc

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

int ungetc( int ch, FILE* stream );

Si ch ne vaut pas EOF, pousse le caractère ch (réinterprété en tant que unsigned char) dans le tampon d'entrée associé au flux stream de telle sorte que la lecture suivante depuis stream récupère ce caractère. Le périphérique externe associé au flux n'est pas modifié.

Les opérations de repositionnement de flux fseek, fsetpos et rewind annulent les effets de ungetc.

Si ungetc est appelée plus d'une fois sans lecture ni repositionnement intermédiaire, elle peut échouer (autrement dit, un tampon de retour arrière de taille 1 est garanti, mais tout tampon plus grand est défini par l'implémentation). Si plusieurs ungetc réussis ont été effectués, les opérations de lecture récupèrent les caractères remis en arrière dans l'ordre inverse de ungetc.

Si ch vaut EOF, l'opération échoue et le flux n'est pas modifié.

Un appel réussi à ungetc efface l'indicateur d'état de fin de fichier feof.

Un appel réussi à ungetc sur un flux binaire décrémente de un l'indicateur de position du flux (le comportement est indéterminé si l'indicateur de position du flux valait zéro).

Un appel réussi à ungetc sur un flux texte modifie l'indicateur de position du flux de manière non spécifiée, mais garantit qu'après la récupération de tous les caractères remis par une opération de lecture, l'indicateur de position du flux est égal à sa valeur avant ungetc.

Paramètres

  • ch — caractère à replacer dans le tampon du flux d'entrée
  • stream — flux de fichier dans lequel replacer le caractère

Valeur de retour

En cas de succès, ch est retourné.

En cas d'échec, EOF est retourné et le flux donné reste inchangé.

Notes

La taille du tampon de retour varie en pratique de 4 ko (Linux, MacOS) à seulement 4 (Solaris), voire au minimum garanti de 1 (HPUX, AIX).

La taille apparente du tampon de retour peut être plus grande si le caractère replacé est égal au caractère existant à cette position dans la séquence de caractères externe (l'implémentation peut simplement décrémenter l'indicateur de position de lecture du fichier et éviter de maintenir un tampon de retour).

Exemple

Illustre la raison d'être initiale de ungetc : implémentation de scanf

#include <ctype.h>
#include <stdio.h>

void demo_scanf(const char* fmt, FILE* s)
{
    while (*fmt != '\0')
    {
        if (*fmt == '%')
        {
            int c;
            switch (*++fmt)
            {
                case 'u':
                    while (isspace(c=getc(s))) {}
                    unsigned int num = 0;
                    while (isdigit(c))
                    {
                        num = num*10 + c-'0';
                        c = getc(s);
                    }
                    printf("%%u scanned %u\n", num);
                    ungetc(c, s);
                    break;
                case 'c':
                    c = getc(s);
                    printf("%%c scanned '%c'\n", c);
                    break;
            }
        }
        else
            ++fmt;
    }
}

int main(void)
{
    FILE* f = fopen("input.txt", "w+");
    if (f != NULL)
    {
        fputs("123x", f);
        rewind(f);
        demo_scanf("%u%c", f);
        fclose(f);
    }
    return 0;
}

Output:

%u scanned 123
%c scanned 'x'
