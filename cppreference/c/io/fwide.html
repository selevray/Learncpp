fwide

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <wchar.h>

int fwide( FILE* stream, int mode );  // (depuis C95)

Si mode > 0, tente de rendre stream orienté caractères larges. Si mode < 0, tente de rendre stream orienté octets. Si mode == 0, interroge seulement l'orientation actuelle du flux.

Si l'orientation du flux a déjà été décidée (par l'exécution d'une sortie ou par un appel antérieur à fwide), cette fonction ne fait rien.

Paramètres

  • stream — pointeur vers le flux d'E/S C à modifier ou à interroger
  • mode — valeur entière strictement positive pour rendre le flux large, strictement négative pour le rendre étroit, ou zéro pour une simple interrogation

Valeur de retour

Un entier strictement positif si le flux est orienté caractères larges après cet appel, strictement négatif s'il est orienté octets après cet appel, et zéro si le flux n'a pas d'orientation.

Exemple

Le code suivant définit puis réinitialise l'orientation du flux.

#include <stdio.h>
#include <stdlib.h>
#include <wchar.h>

void show_orientation(int n)
{
    n < 0 ? puts("\tnarrow orientation"):
    n > 0 ? puts("\twide orientation"):
            puts("\tno orientation");
}

void try_read(FILE* fp)
{
    int c = fgetc(fp);
    c == EOF
        ? printf("\tnarrow character read failed\n")
        : printf("\tnarrow character read '%c'\n", c);

    wint_t wc = fgetwc(fp);
    wc == WEOF
        ? printf("\twide character read failed\n")
        : printf("\twide character read '%lc'\n", wc);
}

int main(void)
{
    enum fwide_orientation { narrow = -1, query, wide };

    FILE* fp = fopen("main.cpp", "r");
    if (!fp)
    {
        perror("fopen() failed");
        return EXIT_FAILURE;
    }

    puts("1) A newly opened stream has no orientation.");
    show_orientation(fwide(fp, query));

    puts("2) Establish byte orientation.");
    show_orientation(fwide(fp, narrow));
    try_read(fp);

    puts("3) Only freopen() can reset stream orientation.");
    if (freopen("main.cpp", "r", fp) == NULL)
    {
       perror("freopen() failed");
       return EXIT_FAILURE;
    }

    puts("4) A reopened stream has no orientation.");
    show_orientation(fwide(fp, query));

    puts("5) Establish wide orientation.");
    show_orientation(fwide(fp, wide));
    try_read(fp);

    fclose(fp);
}
