fclose

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

int fclose( FILE* stream );

Ferme le flux de fichier donné. Toutes les données tamponnées non écrites sont vidées vers le système d'exploitation. Toutes les données tamponnées non lues sont abandonnées.

Que l'opération réussisse ou non, le flux n'est plus associé à un fichier, et la mémoire tampon allouée par setbuf ou setvbuf, le cas échéant, est également dissociée et désallouée si une allocation automatique a été utilisée.

Le comportement est indéfini si la valeur du pointeur stream est utilisée après le retour de fclose.

Paramètres

  • stream — le flux de fichier à fermer

Valeur de retour

0 en cas de succès, EOF sinon

Exemple

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char* fname = "/tmp/unique_name.txt"; // ou tmpnam(NULL);
    int is_ok = EXIT_FAILURE;

    FILE* fp = fopen(fname, "w+");
    if (!fp)
    {
        perror("File opening failed");
        return is_ok;
    }
    fputs("Hello, world!\n", fp);
    rewind(fp);

    int c; // note : int, et non char, requis pour gérer EOF
    while ((c = fgetc(fp)) != EOF) // boucle standard de lecture de fichier en C avec E/S
        putchar(c);

    if (ferror(fp))
        puts("I/O error when reading");
    else if (feof(fp))
    {
        puts("End of file is reached successfully");
        is_ok = EXIT_SUCCESS;
    }

    fclose(fp);
    remove(fname);
    return is_ok;
}
