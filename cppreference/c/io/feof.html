Défini dans l'en-tête <stdio.h>

int feof( FILE *stream );

Vérifie si la fin du flux de fichier donné a été atteinte.

Paramètres

  • stream — le flux de fichier à vérifier

Valeur de retour

valeur non nulle si la fin du flux a été atteinte, sinon 0

Notes

Cette fonction ne rapporte que l'état du flux tel que signalé par la dernière opération d'E/S ; elle n'examine pas la source de données associée. Par exemple, si la dernière E/S était un fgetc ayant renvoyé le dernier octet d'un fichier, feof renvoie zéro. Le fgetc suivant échoue et fait passer l'état du flux à fin de fichier. Ce n'est qu'alors que feof renvoie une valeur non nulle.

Dans un usage courant, le traitement d'un flux d'entrée s'arrête à la moindre erreur ; feof et ferror servent alors à distinguer les différentes conditions d'erreur.

Exemple

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char* fname = "/tmp/unique_name.txt"; // ou tmpnam(NULL);
    int is_ok = EXIT_FAILURE;

    FILE* fp = fopen(fname, "w+");
    if (!fp)
    {
        perror("File opening failed");
        return is_ok;
    }
    fputs("Hello, world!\n", fp);
    rewind(fp);

    int c; // note : int, et non char, requis pour gérer EOF
    while ((c = fgetc(fp)) != EOF) // boucle standard de lecture de fichier en C avec E/S
        putchar(c);

    if (ferror(fp))
        puts("I/O error when reading");
    else if (feof(fp))
    {
        puts("End of file is reached successfully");
        is_ok = EXIT_SUCCESS;
    }

    fclose(fp);
    remove(fname);
    return is_ok;
}
