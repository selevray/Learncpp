Numéros d'erreur

Défini dans l'en-tête <errno.h>

  • errno — macro qui se développe en variable de numéro d'erreur locale au thread, compatible POSIX (variable macro)
  • E2BIG, EACCES, ..., EXDEV — macros pour les conditions d'erreur standard compatibles POSIX (constante macro)

Assertions

Défini dans l'en-tête <assert.h>

  • assert — interrompt le programme si la condition spécifiée par l'utilisateur n'est pas true. Peut être désactivée pour les versions de publication (macro fonctionnelle)
  • static_assert (C11) (removed in C23) — émet un diagnostic à la compilation si la valeur d'une expression constante est fausse (macro mot-clé)

Vérification des bornes

La bibliothèque standard fournit des versions à vérification des bornes de certaines fonctions existantes (gets_s, fopen_s, printf_s, strcpy_s, wcscpy_s, mbstowcs_s, qsort_s, getenv_s, etc.). Cette fonctionnalité est facultative et n'est disponible que si __STDC_LIB_EXT1__ est défini. Les macros et fonctions suivantes prennent en charge cette fonctionnalité.

Défini dans l'en-tête <errno.h>

Défini dans l'en-tête <stdio.h>

  • errno_t (C11) — un typedef pour le type int, utilisé pour documenter d'elles-mêmes les fonctions qui renvoient des valeurs errno (typedef)

Défini dans l'en-tête <stddef.h>

Défini dans l'en-tête <string.h>

Défini dans l'en-tête <time.h>

Défini dans l'en-tête <wchar.h>

  • rsize_t (C11) — un typedef pour le même type que size_t, utilisé pour documenter d'elles-mêmes les fonctions qui vérifient leurs paramètres à l'exécution (typedef)

Défini dans l'en-tête <stdint.h>

  • RSIZE_MAX (C11) — taille maximale acceptable pour les fonctions à vérification des bornes, se développe en une constante ou une variable pouvant changer à l'exécution (par exemple lorsque la taille mémoire allouée change) (variable macro)

Défini dans l'en-tête <stdlib.h>

  • set_constraint_handler_s (C11) — définit le rappel d'erreur pour les fonctions à vérification des bornes (fonction)
  • abort_handler_s (C11) — callback d'arrêt pour les fonctions à vérification des bornes (fonction)
  • ignore_handler_s (C11) — rappel d'ignorance pour les fonctions à vérification des bornes (fonction)

Note : des implémentations des fonctions à vérification des bornes sont disponibles sous forme de bibliothèques open source Safe C et Slibc, ainsi que dans le cadre de Watcom C. Il existe aussi un ensemble incompatible de fonctions à vérification des bornes dans Visual Studio.

(depuis C11)

Notes

Depuis C23, static_assert est lui-même un mot-clé, qui peut aussi être une macro prédéfinie, donc <assert.h> ne le fournit plus.
