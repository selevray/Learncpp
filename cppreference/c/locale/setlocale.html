setlocale

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <locale.h>

char* setlocale( int category, const char* locale );

La fonction setlocale installe la locale système spécifiée ou une partie de celle-ci comme nouvelle locale C. Les modifications restent en vigueur et influencent l'exécution de toutes les fonctions de la bibliothèque C sensibles à la locale jusqu'au prochain appel à setlocale. Si locale est un pointeur nul, setlocale interroge la locale C courante sans la modifier.

Paramètres

  • category — identifiant de catégorie de locale, l'une des macros LC_xxx. Peut être nul.
  • locale — identifiant de locale propre au système. Peut être "" pour la locale préférée de l'utilisateur ou "C" pour la locale minimale

Valeur de retour

pointeur vers une chaîne étroite terminée par un caractère nul identifiant la locale C après application des modifications, le cas échéant, ou pointeur nul en cas d'échec.

Une copie de la chaîne renvoyée ainsi que la catégorie utilisée dans cet appel à setlocale peut être utilisée ultérieurement dans le programme pour restaurer la locale à l'état qu'elle avait à la fin de cet appel.

Notes

Au démarrage du programme, l'équivalent de setlocale(LC_ALL, "C"); est exécuté avant l'exécution de tout code utilisateur.

Bien que le type de retour soit char*, modifier les caractères pointés est un comportement indéfini.

Comme setlocale modifie un état global qui affecte l'exécution des fonctions dépendantes de la locale, il est un comportement indéfini de l'appeler depuis un thread pendant qu'un autre thread exécute l'une des fonctions suivantes : fprintf, isprint, iswdigit, localeconv, tolower, fscanf, ispunct, iswgraph, mblen, toupper, isalnum, isspace, iswlower, mbstowcs, towlower, isalpha, isupper, iswprint, mbtowc, towupper, isblank, iswalnum, iswpunct, setlocale, wcscoll, iscntrl, iswalpha, iswspace, strcoll, wcstod, isdigit, iswblank, iswupper, strerror, wcstombs, isgraph, iswcntrl, iswxdigit, strtod, wcsxfrm, islower, iswctype, isxdigit.

POSIX définit également une locale nommée "POSIX", toujours accessible et exactement équivalente à la locale minimale "C" par défaut.

POSIX précise également que le pointeur renvoyé, et pas seulement le contenu de la chaîne pointée, peut être invalidé par des appels ultérieurs à setlocale.

Exemple

#include <locale.h>
#include <stdio.h>
#include <time.h>
#include <wchar.h>

int main(void)
{
    // la locale C sera l'anglais avec prise en charge d'UTF-8 ;
    // le point décimal sera allemand
    // le formatage de la date et de l'heure sera japonais
    setlocale(LC_ALL, "en_US.UTF-8");
    setlocale(LC_NUMERIC, "de_DE.utf8");
    setlocale(LC_TIME, "ja_JP.utf8");

    wchar_t str[100];
    time_t t = time(NULL);
    wcsftime(str, 100, L"%A %c", localtime(&t));
    wprintf(L"Number: %.2f\nDate: %ls\n", 3.14, str);
}
