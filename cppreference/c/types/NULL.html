#define NULL /*implementation-defined*/

La macro NULL est une constante de pointeur nul définie par l'implémentation, qui peut être

  • une expression constante entière de valeur 0
  • une expression constante entière de valeur 0 convertie vers le type void*
  • constante prédéfinie nullptr

(depuis C23)

Une constante de pointeur nul peut être convertie vers tout type de pointeur ; une telle conversion donne la valeur de pointeur nul de ce type.

Notes

POSIX exige que NULL soit défini comme une expression constante entière de valeur 0 convertie en void*.

Implémentation possible

// C++ compatible:
#define NULL 0
// C++ incompatible:
#define NULL (10*2 - 20)
#define NULL ((void*)0)
// depuis C23 (compatible avec C++11 et versions ultérieures)
#define NULL nullptr

Exemple

#include <inttypes.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    // tout type de pointeur peut être mis à NULL
    int* p = NULL;
    struct S *s = NULL;
    void(*f)(int, double) = NULL;
    printf("%p %p %p\n", (void*)p, (void*)s, (void*)(long)f);

    // de nombreuses fonctions renvoyant un pointeur utilisent des pointeurs nuls pour indiquer une erreur
    char *ptr = malloc(0xFULL);
    if (ptr == NULL)
        printf("Out of memory");
    else
        printf("ptr = %#" PRIxPTR"\n", (uintptr_t)ptr);
    free(ptr);
}

Sortie possible :

(nil) (nil) (nil)
ptr = 0xc001cafe
