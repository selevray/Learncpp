offsetof

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stddef.h>

#define offsetof(type, member) /*implementation-defined*/

La macro offsetof se développe en une expression constante entière de type size_t, dont la valeur est le décalage, en octets, depuis le début d'un objet du type spécifié jusqu'à son sous-objet spécifié, y compris le rembourrage éventuel.

Étant donné un objet o de type type à durée de stockage statique, &(o.member) doit être une expression constante d'adresse et pointer vers un sous-objet de o. Sinon, le comportement est indéfini.

Si le nom de type spécifié dans type contient une virgule qui n'est pas située entre des parenthèses correspondantes, le comportement est indéfini.

(depuis C23)

Notes

Si offsetof est appliqué à un membre champ de bits, le comportement est indéfini, car l'adresse d'un champ de bits ne peut pas être prise.

member n'est pas limité à un membre direct. Il peut désigner un sous-objet d'un membre donné, comme un élément d'un membre tableau.

Bien que la norme C23 précise que l'utilisation d'un nouveau type contenant une virgule non parenthésée dans offsetof est un comportement indéfini, une telle utilisation n'est généralement pas prise en charge, même dans les modes antérieurs : offsetof(struct Foo { int a, b; }, a) échoue généralement à la compilation.

typeof peut être utilisé pour éviter les effets néfastes des virgules dans la définition d'un nouveau type, par exemple offsetof(typeof(struct { int i, j; }), i) est bien défini.

(depuis C23)

Exemple

#include <stdio.h>
#include <stddef.h>

struct S {
    char c;
    double d;
};

int main(void)
{
    printf("the first element is at offset %zu\n", offsetof(struct S, c));
    printf("the double is at offset %zu\n", offsetof(struct S, d));
}

Sortie possible :

the first element is at offset 0
the double is at offset 8
