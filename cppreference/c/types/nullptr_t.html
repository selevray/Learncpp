nullptr_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stddef.h>

typedef typeof(nullptr) nullptr_t;  // (depuis C23)

nullptr_t est le type de la constante pointeur nulle prédéfinie, nullptr. C'est un type distinct qui n'est pas lui-même un type pointeur. Il peut être converti implicitement en n'importe quel type pointeur ou bool, et le résultat est la valeur pointeur nul de ce type ou false respectivement. Aucun type autre que nullptr_t lui-même ne peut être converti ou transtypé explicitement en nullptr_t.

sizeof(nullptr_t) et alignof(nullptr_t) sont égaux à sizeof(void*) et alignof(void*) respectivement.

nullptr_t n'a qu'une seule valeur valide, à savoir nullptr. La représentation objet de nullptr est identique à celle de (void*)0. Si une conversion lvalue produit une valeur nullptr_t ayant une représentation objet différente, le comportement est indéfini.

Exemple

Démontrer que nullptr_t est un type distinct.

#include <stddef.h>
#include <stdio.h>

#define DETECT_NULL_POINTER_CONSTANT(e) \
    _Generic(e,                         \
        void* : puts("void*"),          \
        nullptr_t : puts("nullptr_t"),  \
        default : puts("other")         \
    )

int main()
{
    DETECT_NULL_POINTER_CONSTANT(((void*)0));
    DETECT_NULL_POINTER_CONSTANT(0);
    DETECT_NULL_POINTER_CONSTANT(nullptr);
}

Output:

void*
other
nullptr_t
