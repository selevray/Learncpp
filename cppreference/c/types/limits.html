Défini dans l'en-tête <wchar.h>

Défini dans l'en-tête <stdint.h>

  • WCHAR_WIDTH (C23) — largeur en bits d'un objet de type wchar_t (constante macro)
  • WCHAR_MIN (C99) — valeur minimale de wchar_t (constante macro)
  • WCHAR_MAX (C99) — valeur maximale de wchar_t (constante macro)

Notes

Les types de ces constantes, autres que CHAR_BIT et MB_LEN_MAX, doivent correspondre aux résultats des promotions entières appliquées aux objets des types qu'elles décrivent : CHAR_MAX peut avoir le type int ou unsigned int, mais jamais char. De même, USHRT_MAX ne peut pas être d'un type non signé : son type peut être int.

Une implémentation autonome peut ne pas fournir sig_atomic_t et/ou wint_t noms de typedef ; dans ce cas, les macros SIG_ATOMIC_* et/ou WINT_* sont absentes en conséquence.

Exemple

#include <limits.h>
#include <stdint.h>
#include <stdio.h>

int main(void)
{
    printf("CHAR_BIT       = %d\n", CHAR_BIT);
    printf("MB_LEN_MAX     = %d\n\n", MB_LEN_MAX);

    printf("CHAR_MIN       = %+d\n", CHAR_MIN);
    printf("CHAR_MAX       = %+d\n", CHAR_MAX);
    printf("SCHAR_MIN      = %+d\n", SCHAR_MIN);
    printf("SCHAR_MAX      = %+d\n", SCHAR_MAX);
    printf("UCHAR_MAX      = %u\n\n", UCHAR_MAX);

    printf("SHRT_MIN       = %+d\n", SHRT_MIN);
    printf("SHRT_MAX       = %+d\n", SHRT_MAX);
    printf("USHRT_MAX      = %u\n\n", USHRT_MAX);

    printf("INT_MIN        = %+d\n", INT_MIN);
    printf("INT_MAX        = %+d\n", INT_MAX);
    printf("UINT_MAX       = %u\n\n", UINT_MAX);

    printf("LONG_MIN       = %+ld\n", LONG_MIN);
    printf("LONG_MAX       = %+ld\n", LONG_MAX);
    printf("ULONG_MAX      = %lu\n\n", ULONG_MAX);

    printf("LLONG_MIN      = %+lld\n", LLONG_MIN);
    printf("LLONG_MAX      = %+lld\n", LLONG_MAX);
    printf("ULLONG_MAX     = %llu\n\n", ULLONG_MAX);

    printf("PTRDIFF_MIN    = %td\n", PTRDIFF_MIN);
    printf("PTRDIFF_MAX    = %+td\n", PTRDIFF_MAX);
    printf("SIZE_MAX       = %zu\n", SIZE_MAX);
    printf("SIG_ATOMIC_MIN = %+jd\n",(intmax_t)SIG_ATOMIC_MIN);
    printf("SIG_ATOMIC_MAX = %+jd\n",(intmax_t)SIG_ATOMIC_MAX);
    printf("WCHAR_MIN      = %+jd\n",(intmax_t)WCHAR_MIN);
    printf("WCHAR_MAX      = %+jd\n",(intmax_t)WCHAR_MAX);
    printf("WINT_MIN       = %jd\n", (intmax_t)WINT_MIN);

Limites des types à virgule flottante

Défini dans l'en-tête <float.h>

  • FLT_RADIX — la base (base entière) utilisée par la représentation des trois types à virgule flottante (constante macro)

  • DECIMAL_DIG (C99) — la conversion depuis long double vers la décimale avec au moins DECIMAL_DIG chiffres, puis retour vers long double, est la conversion identité : c'est la précision décimale requise pour sérialiser/désérialiser un long double (constante macro)

  • FLT_DECIMAL_DIGDBL_DECIMAL_DIGLDBL_DECIMAL_DIG (C11) — la conversion de float/double/long double vers la décimale avec au moins FLT_DECIMAL_DIG/DBL_DECIMAL_DIG/LDBL_DECIMAL_DIG chiffres, puis retour, est la conversion identité : c'est la précision décimale requise pour sérialiser/désérialiser une valeur à virgule flottante. Définie à au moins 6, 10 et 10 respectivement, ou 9 pour le float IEEE et 17 pour le double IEEE (voir aussi l'analogue C++ : max_digits10) (constante macro)

  • FLT_MINDBL_MINLDBL_MIN — valeur minimale, normalisée et positive de float, double et long double respectivement (constante macro)

  • FLT_TRUE_MINDBL_TRUE_MINLDBL_TRUE_MIN (C11) — valeur positive minimale de float, double et long double respectivement (constante macro)

  • FLT_MAXDBL_MAXLDBL_MAX — valeur finie maximale de float, double et long double respectivement (constante macro)

  • FLT_EPSILONDBL_EPSILONLDBL_EPSILON — différence absolue entre 1.0 et la valeur représentable suivante pour float, double et long double respectivement (constante macro)

  • FLT_DIGDBL_DIGLDBL_DIG — nombre de chiffres décimaux garantis comme préservés dans le passage texte → float/double/long double → texte sans modification due à l'arrondi ou au dépassement (voir l'analogue C++ digits10 pour le détail) (constante macro)

  • FLT_MANT_DIGDBL_MANT_DIGLDBL_MANT_DIG — nombre de chiffres en base FLT_RADIX présents dans la mantisse à virgule flottante et pouvant être représentés sans perte de précision pour float, double et long double respectivement (constante macro)

  • FLT_MIN_EXPDBL_MIN_EXPLDBL_MIN_EXP — plus petit entier négatif tel que FLT_RADIX élevé à la puissance de cet entier diminué de un est un float normalisé, pour double et long double respectivement (constante macro)

  • FLT_MIN_10_EXPDBL_MIN_10_EXPLDBL_MIN_10_EXP — plus petit entier négatif tel que 10 élevé à cette puissance soit un float normalisé, double et long double respectivement (constante macro)

  • FLT_MAX_EXPDBL_MAX_EXPLDBL_MAX_EXP — plus grand entier positif tel que FLT_RADIX élevé à la puissance de cet entier diminué de un est un float fini représentable, pour double et long double respectivement (constante macro)

  • FLT_MAX_10_EXPDBL_MAX_10_EXPLDBL_MAX_10_EXP — plus grand entier positif tel que 10 élevé à cette puissance soit un float fini représentable, double et long double respectivement (constante macro)

  • FLT_ROUNDS — mode d'arrondi des opérations arithmétiques à virgule flottante (constante macro)

  • FLT_EVAL_METHOD (C99) — précise avec quelle précision toutes les opérations arithmétiques sont effectuées (constante macro)

  • FLT_HAS_SUBNORMDBL_HAS_SUBNORMLDBL_HAS_SUBNORM (C11) (deprecated in C23) — indique si le type prend en charge les nombres subnormaux (denormal) : -1 – indéterminable, 0 – absent, 1 – présent (constante macro)

Exemple

#include <float.h>
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("DECIMAL_DIG     = %d\n", DECIMAL_DIG);
    printf("FLT_DECIMAL_DIG = %d\n", FLT_DECIMAL_DIG);
    printf("FLT_RADIX       = %d\n", FLT_RADIX);
    printf("FLT_MIN         = %e\n", FLT_MIN);
    printf("FLT_MAX         = %e\n", FLT_MAX);
    printf("FLT_EPSILON     = %e\n", FLT_EPSILON);
    printf("FLT_DIG         = %d\n", FLT_DIG);
    printf("FLT_MANT_DIG    = %d\n", FLT_MANT_DIG);
    printf("FLT_MIN_EXP     = %d\n", FLT_MIN_EXP);
    printf("FLT_MIN_10_EXP  = %d\n", FLT_MIN_10_EXP);
    printf("FLT_MAX_EXP     = %d\n", FLT_MAX_EXP);
    printf("FLT_MAX_10_EXP  = %d\n", FLT_MAX_10_EXP);
    printf("FLT_ROUNDS      = %d\n", FLT_ROUNDS);
    printf("FLT_EVAL_METHOD = %d\n", FLT_EVAL_METHOD);
    printf("FLT_HAS_SUBNORM = %d\n", FLT_HAS_SUBNORM);
}
