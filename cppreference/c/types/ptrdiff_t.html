ptrdiff_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stddef.h>

typedef /*défini par l'implémentation*/ ptrdiff_t;

ptrdiff_t est le type entier signé du résultat de la soustraction de deux pointeurs.

La largeur en bits de ptrdiff_t n'est pas inférieure à 17.

(depuis C99) (jusqu'à C23)

La largeur en bits de ptrdiff_t n'est pas inférieure à 16.

(depuis C23)

Notes

ptrdiff_t est utilisé pour l'arithmétique des pointeurs et l'indexation de tableaux, si des valeurs négatives sont possibles. Les programmes utilisant d'autres types, comme int, peuvent échouer, par exemple sur des systèmes 64 bits lorsque l'indice dépasse INT_MAX, ou s'ils reposent sur une arithmétique modulaire 32 bits.

Seuls les pointeurs vers des éléments d'un même tableau (y compris le pointeur situé juste après la fin du tableau) peuvent être soustraits l'un de l'autre.

Si un tableau est si grand (supérieur à PTRDIFF_MAX éléments, mais inférieur ou égal à SIZE_MAX octets) que la différence entre deux pointeurs peut ne pas être représentable en tant que ptrdiff_t, le résultat de la soustraction de deux tels pointeurs est indéfini.

Pour les tableaux de char plus courts que PTRDIFF_MAX, ptrdiff_t agit comme l'équivalent signé de size_t : il peut stocker la taille du tableau de n'importe quel type et est, sur la plupart des plates-formes, synonyme de intptr_t).

Implémentation possible

typedef typeof((int*)nullptr - (int*)nullptr) ptrdiff_t; // valide depuis C23

Exemple

#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

int main(void)
{
    const size_t N = 100;
    int numbers[N];

    printf("PTRDIFF_MAX = %ld\n", PTRDIFF_MAX);
    int *p1 = &numbers[18], *p2 = &numbers[23];
    ptrdiff_t diff = p2 - p1;
    printf("p2-p1 = %td\n", diff);
}

Sortie possible :

PTRDIFF_MAX = 9223372036854775807
p2-p1 = 5
