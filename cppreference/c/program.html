Fin du programme

Les fonctions suivantes gèrent la fin du programme et la libération des ressources.

Défini dans l'en-tête <stdlib.h>

  • abort — provoque une terminaison anormale du programme (sans nettoyage) (fonction)
  • exit — provoque une fin normale du programme avec nettoyage (fonction)
  • quick_exit (C11) — provoque une terminaison normale du programme sans nettoyage complet de (fonction)
  • _Exit (C99) — provoque une fin normale du programme sans nettoyage (fonction)
  • atexit — enregistre une fonction à appeler lors de l'invocation normale de exit() (fonction)
  • at_quick_exit (C11) — enregistre une fonction à appeler lors de l'invocation de quick_exit (fonction)
  • EXIT_SUCCESSEXIT_FAILURE — indique l'état d'exécution du programme (constante de macro)

Flux de contrôle inatteignable

Défini dans l'en-tête <stddef.h>

  • unreachable (C23) — marque un point d'exécution inatteignable (macro de fonction)

Communication avec l'environnement

Défini dans l'en-tête <stdlib.h>

  • system — appelle le processeur de commandes de l'environnement hôte (fonction)
  • getenvgetenv_s (C11) — accès à la liste des variables d'environnement (fonction)

Requête d'alignement mémoire

Défini dans l'en-tête <stdlib.h>

  • memalignment (C23) — interroge l'alignement d'une valeur de pointeur (fonction)

Signaux

Plusieurs fonctions et constantes macro pour la gestion des signaux sont fournies.

Défini dans l'en-tête <signal.h>

  • signal — définit un gestionnaire de signal pour un signal particulier (fonction)
  • raise — exécute le gestionnaire de signal pour un signal particulier (fonction)
  • sig_atomic_t — le type entier pouvant être accédé comme une entité atomique depuis un gestionnaire de signal asynchrone (typedef)
  • SIG_DFLSIG_IGN — définit les stratégies de gestion des signaux (constante macro)
  • SIG_ERR — indique qu'une erreur a été rencontrée (constante macro)

##### Types de signaux {#Signal_types}

  • SIGABRTSIGFPESIGILLSIGINTSIGSEGVSIGTERM — définit les types de signaux (constante macro)

Sauts non locaux

Défini dans l'en-tête <setjmp.h>

  • setjmp — sauvegarde le contexte (macro de fonction)
  • longjmp — saute à l'emplacement spécifié (fonction)

##### Types {#Types}

  • jmp_buf — type de contexte d'exécution (typedef)
