setjmp

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <setjmp.h>

#define setjmp(env) /* implementation-defined */

Sauvegarde le contexte d'exécution courant dans une variable env de type jmp_buf. Cette variable peut ensuite être utilisée pour restaurer le contexte d'exécution courant à l'aide de la fonction longjmp. Autrement dit, lorsqu'un appel à la fonction longjmp est effectué, l'exécution reprend au point d'appel précis qui a construit la variable jmp_buf passée à longjmp. Dans ce cas, setjmp renvoie la valeur passée à longjmp.

L'invocation de setjmp ne doit apparaître que dans l'un des contextes suivants :

  1. L'intégralité de l'expression de contrôle de if, switch, while, do-while, for.

    switch(setjmp(env)) { // ...

  2. Un opérande d'un opérateur relationnel ou d'égalité, l'autre opérande étant une expression constante entière, l'expression résultante étant l'intégralité de l'expression de contrôle de if, switch, while, do-while, for.

    if(setjmp(env) > 10) { // ...

  3. L'opérande d'un opérateur unaire ! , l'expression résultante étant l'intégralité de l'expression de contrôle de if, switch, while, do-while, for.

    while(!setjmp(env)) { // ...

  4. L'intégralité de l'expression d'une instruction d'expression (éventuellement convertie en void).

    setjmp(env);

Si setjmp apparaît dans tout autre contexte, le comportement est indéfini.

Au retour dans la portée de setjmp :

  • tous les objets accessibles, les indicateurs d'état de virgule flottante et les autres composants de la machine abstraite ont les mêmes valeurs qu'au moment de l'exécution de longjmp,
  • sauf pour les variables locales non-volatile de la fonction contenant l'appel de setjmp, dont les valeurs sont indéterminées si elles ont été modifiées depuis l'appel setjmp.

Paramètres

  • env — variable dans laquelle sauvegarder l'état d'exécution du programme.

Valeur de retour

0 si la macro a été appelée par le code d'origine et que le contexte d'exécution a été sauvegardé dans env.

Valeur non nulle si un saut non local vient d'être effectué. La valeur de retour est la même que celle passée à longjmp.

Notes

Les exigences ci-dessus interdisent d'utiliser la valeur de retour de setjmp dans le flux de données (par exemple pour initialiser ou affecter un objet avec celle-ci). La valeur de retour ne peut être utilisée que dans le flux de contrôle ou être ignorée.

Exemple

#include <stdio.h>
#include <setjmp.h>
#include <stdnoreturn.h>

jmp_buf my_jump_buffer;

noreturn void foo(int status)
{
    printf("foo(%d) called\n", status);
    longjmp(my_jump_buffer, status + 1); // retournera status+1 depuis setjmp
}

int main(void)
{
    volatile int count = 0; // les variables locales modifiées dans la portée de setjmp doivent être volatile
    if (setjmp(my_jump_buffer) != 5) // comparer à une constante dans un if
        foo(++count);
}

Output:

foo(1) called
foo(2) called
foo(3) called
foo(4) called
