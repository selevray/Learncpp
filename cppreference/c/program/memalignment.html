memalignment

Défini dans l'en-tête <stdlib.h>

size_t memalignment( const void *p );  // (depuis C23)

Renvoie l'alignement maximal satisfait par l'adresse fournie. La valeur de retour peut être supérieure à toute valeur d'alignement prise en charge par l'implémentation. Si p est une valeur de pointeur nul, 0 est renvoyée pour indiquer que le pointeur ne peut pas être utilisé pour accéder à un objet de quelque type que ce soit.

Si la valeur de retour est supérieure ou égale à alignof(T), l'exigence d'alignement du type T est satisfaite par le pointeur.

Une implémentation autonome doit fournir memalignment.

Paramètres

  • p — pointeur dont on veut interroger l'alignement

Valeur de retour

La valeur d'alignement de p, ou 0 si p est une valeur de pointeur nul.

Notes

Sur les plateformes courantes où

  • les pointeurs nuls sont convertis en entier 0,
  • les valeurs de pointeurs sont directement converties en valeurs numériques d'adresses virtuelles, et
  • size_t est identique à uintptr_t,

cette fonction peut être implémentée comme return (size_t)p & -(size_t)p;.

Exemple

#include <stdio.h>
#include <stdlib.h>

int main()
{
    alignas(128) int i = 0;
    printf("%zu\n%zu\n", memalignment(nullptr), memalignment(&i));
}
