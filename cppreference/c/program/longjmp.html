longjmp

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <setjmp.h>

void longjmp( jmp_buf env, int status );  // (jusqu'à C11)

_Noreturn void longjmp( jmp_buf env, int status );  // (depuis C11) (jusqu'à C23)

[[noreturn]] void longjmp( jmp_buf env, int status );  // (depuis C23)

Charge le contexte d'exécution env sauvegardé par un appel précédent à setjmp. Cette fonction ne retourne pas. Le contrôle est transféré au site d'appel de la macro setjmp qui a initialisé env. Cette setjmp renvoie alors la valeur passée comme status.

Si la fonction qui a appelé setjmp s'est terminée (que ce soit par return ou par un autre longjmp plus haut dans la pile), le comportement est indéfini. Autrement dit, seuls les sauts longs vers le haut de la pile d'appels sont autorisés.

Un saut entre threads (si la fonction qui a appelé setjmp a été exécutée par un autre thread) est également un comportement indéfini.

(depuis C11)

Si, au moment de l'appel à setjmp, une VLA ou une autre variable de type à modification variable était dans la portée et que le contrôle a quitté cette portée, longjmp vers ce setjmp provoque un comportement indéfini, même si le contrôle est resté dans la fonction.

En remontant la pile, longjmp ne désalloue aucune VLA ; des fuites mémoire peuvent se produire si leur durée de vie se termine de cette façon :

void g(int n)
{
    int a[n]; // a peut rester alloué
    h(n); // ne retourne pas
}
void h(int n)
{
    int b[n]; // b peut rester alloué
    longjmp(buf, 2); // peut provoquer une fuite mémoire pour b de h et a de g
}

(depuis C99)

Paramètres

  • env — variable désignant l'état d'exécution du programme sauvegardé par setjmp
  • status — la valeur à renvoyer par setjmp. Si elle est égale à 0, 1 est utilisée à la place

Valeur de retour

(aucune)

Notes

longjmp est destiné à gérer des conditions d'erreur inattendues où la fonction ne peut pas retourner de manière significative. Cela ressemble à la gestion des exceptions dans d'autres langages de programmation.

Exemple

#include <stdio.h>
#include <setjmp.h>
#include <stdnoreturn.h>

jmp_buf my_jump_buffer;

noreturn void foo(int status)
{
    printf("foo(%d) called\n", status);
    longjmp(my_jump_buffer, status + 1); // retournera status+1 depuis setjmp
}

int main(void)
{
    volatile int count = 0; // les variables locales modifiées dans la portée de setjmp doivent être volatile
    if (setjmp(my_jump_buffer) != 5) // comparer à une constante dans un if
        foo(++count);
}

Output:

foo(1) called
foo(2) called
foo(3) called
foo(4) called
