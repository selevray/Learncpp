quick_exit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

_Noreturn void quick_exit( int exit_code );  // (depuis C11) (jusqu'à C23)

[[noreturn]] void quick_exit( int exit_code );  // (depuis C23)

Provoque une terminaison normale du programme sans nettoyer complètement les ressources.

Les fonctions passées à at_quick_exit sont appelées dans l'ordre inverse de leur enregistrement. Après l'appel des fonctions enregistrées, appelle _Exit(exit_code).

Les fonctions passées à atexit ou les gestionnaires de signaux passés à signal ne sont pas appelés.

Paramètres

  • exit_code — statut de sortie du programme

Valeur de retour

(aucune)

Exemple

#include <stdlib.h>
#include <stdio.h>

void f1(void)
{
    puts("pushed first");
    fflush(stdout);
}

void f2(void)
{
    puts("pushed second");
}

void f3(void)
{
    puts("won't be called");
}

int main(void)
{
    at_quick_exit(f1);
    at_quick_exit(f2);
    atexit(f3);
    quick_exit(0);
}

Output:

pushed second
pushed first
