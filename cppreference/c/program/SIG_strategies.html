SIG_DFL, SIG_IGN

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <signal.h>

#define SIG_DFL /*implementation defined*/

#define SIG_IGN /*implementation defined*/

Les macros SIG_DFL et SIG_IGN se développent en expressions entières différentes de l'adresse de toute fonction. Ces macros définissent les stratégies de gestion des signaux pour la fonction signal().

Constante Explication

  • SIG_DFL — gestion par défaut des signaux
  • SIG_IGN — le signal est ignoré

Exemple

#include <signal.h>
#include <stdio.h>

int main(void)
{
    /* utilise le gestionnaire de signal par défaut */
    raise(SIGTERM);
    printf("Exit main()\n");   /* jamais atteint */
}

Output:

(none)

Exemple

#include <signal.h>
#include <stdio.h>

int main(void)
{
    /* ignore le signal */
    signal(SIGTERM, SIG_IGN);
    raise(SIGTERM);
    printf("Exit main()\n");
}

Output:

Exit main()
