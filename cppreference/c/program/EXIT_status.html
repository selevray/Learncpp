EXIT_SUCCESS, EXIT_FAILURE

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

#define EXIT_SUCCESS /*implementation defined*/

#define EXIT_FAILURE /*implementation defined*/

Les macros EXIT_SUCCESS et EXIT_FAILURE se développent en expressions constantes entières, utilisables comme arguments de la fonction exit (et donc comme valeurs à renvoyer par la fonction main), et indiquent l'état d'exécution du programme.

Constante Description

  • EXIT_SUCCESS — exécution réussie d'un programme
  • EXIT_FAILURE — exécution échouée d'un programme

Notes

Tant EXIT_SUCCESS que la valeur zéro indiquent un état d'exécution réussi du programme (voir exit), bien qu'il ne soit pas exigé que EXIT_SUCCESS soit égal à zéro.

Exemple

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    FILE* fp = fopen("data.txt", "r");
    if (fp == NULL)
    {
       fprintf(stderr, "fopen() failed in file %s at line #%d", __FILE__, __LINE__);
       exit(EXIT_FAILURE);
    }

    /* L'exécution normale se poursuit ici. */
    fclose(fp);
    printf("Normal Return\n");

    return EXIT_SUCCESS;
}

Output:

fopen() failed in file main.cpp at line #9
