atexit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

int atexit( void (*func)(void) );

Enregistre la fonction pointée par func pour qu'elle soit appelée lors de la terminaison normale du programme (via exit() ou un retour depuis main()). Les fonctions sont appelées dans l'ordre inverse de leur enregistrement, c'est-à-dire que la fonction enregistrée en dernier sera exécutée en premier.

La même fonction peut être enregistrée plus d'une fois.

L'implémentation garantit la prise en charge de l'enregistrement d'au moins 32 fonctions. La limite exacte est définie par l'implémentation.

Paramètres

  • func — pointeur vers une fonction à appeler lors d'une terminaison normale du programme

Valeur de retour

0 si l'enregistrement réussit, une valeur non nulle sinon.

Exemple

#include <stdlib.h>
#include <stdio.h>

void f1(void)
{
    puts("f1");
}

void f2(void)
{
    puts("f2");
}

int main(void)
{
    if ( ! atexit(f1) && ! atexit(f2) && ! atexit(f2) )
        return EXIT_SUCCESS ;

    // échec de l'enregistrement de atexit
    return EXIT_FAILURE ;

}   // <- si l'enregistrement a réussi, appelle f2, f2, f1

Output:

f2
f2
f1
