exit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

void exit( int exit_code );  // (jusqu'à C11)

_Noreturn void exit( int exit_code );  // (depuis C11) (jusqu'à C23)

[[noreturn]] void exit( int exit_code );  // (depuis C23)

Provoque la terminaison normale du programme.

Plusieurs étapes de nettoyage sont effectuées :

  • les fonctions passées à atexit sont appelées, dans l'ordre inverse de leur enregistrement
  • tous les flux C sont vidés et fermés
  • les fichiers créés par tmpfile sont supprimés
  • le contrôle est rendu à l'environnement hôte. Si exit_code vaut zéro ou EXIT_SUCCESS, un statut défini par l'implémentation indiquant une terminaison réussie est renvoyé. Si exit_code vaut EXIT_FAILURE, un statut défini par l'implémentation indiquant une terminaison non réussie est renvoyé. Dans les autres cas, une valeur de statut définie par l'implémentation est renvoyée.

Notes

Les fonctions enregistrées avec at_quick_exit ne sont pas appelées.

Le comportement est indéfini si un programme appelle exit plus d'une fois, ou s'il appelle exit et quick_exit

Le comportement est indéfini si, pendant un appel à une fonction enregistrée avec atexit, la fonction se termine par longjmp.

Le retour depuis la fonction main, que ce soit par une instruction return ou en atteignant la fin de la fonction, exécute exit(), en passant l'argument de l'instruction return (ou 0 si un retour implicite a été utilisé) comme exit_code.

Paramètres

  • exit_code — statut de sortie du programme

Valeur de retour

(aucune)

Exemple

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    FILE *fp = fopen("data.txt","r");
    if (fp == NULL)
    {
       fprintf(stderr, "error opening file data.txt in function main()\n");
       exit( EXIT_FAILURE );
    }
    fclose(fp);
    printf("Normal Return\n");
    return EXIT_SUCCESS ;
}

Sortie possible :

error opening file data.txt in function main()
