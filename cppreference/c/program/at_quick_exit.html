at_quick_exit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

int at_quick_exit( void (*func)(void) );  // (depuis C11)

Enregistre la fonction pointée par func pour qu'elle soit appelée lors d'une terminaison rapide du programme (via quick_exit).

Appeler la fonction depuis plusieurs threads n'induit pas de course de données. L'implémentation garantit la prise en charge de l'enregistrement d'au moins 32 fonctions. La limite exacte est définie par l'implémentation.

Les fonctions enregistrées ne seront pas appelées lors d'une terminaison normale du programme. Si une fonction doit être appelée dans ce cas, atexit doit être utilisé.

Paramètres

  • func — pointeur vers une fonction à appeler lors d'une terminaison rapide du programme

Valeur de retour

0 si l'enregistrement réussit, une valeur non nulle sinon.

Exemple

#include <stdlib.h>
#include <stdio.h>

void f1(void)
{
    puts("pushed first");
    fflush(stdout);
}

void f2(void)
{
    puts("pushed second");
}

int main(void)
{
    at_quick_exit(f1);
    at_quick_exit(f2);
    quick_exit(0);
}

Output:

pushed second
pushed first
