sig_atomic_t

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <signal.h>

typedef /* unspecified */ sig_atomic_t;

Un type entier pouvant être accédé comme une entité atomique, même en présence d'interruptions asynchrones provoquées par des signaux.

Exemple

#include <signal.h>
#include <stdio.h>

volatile sig_atomic_t gSignalStatus = 0;

void signal_handler(int status)
{
    gSignalStatus = status;
}

int main(void)
{
    /* Installe un gestionnaire de signal. */
    signal(SIGINT, signal_handler);

    printf("SignalValue:    %d\n", gSignalStatus);
    printf("Sending signal: %d\n", SIGINT);
    raise(SIGINT);
    printf("SignalValue:    %d\n", gSignalStatus);
}

Sortie possible :

SignalValue:    0
Sending signal: 2
SignalValue:    2
