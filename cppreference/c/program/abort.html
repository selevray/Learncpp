abort

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

void abort(void);  // (jusqu'à C11)

_Noreturn void abort(void);  // (depuis C11) (jusqu'à C23)

[[noreturn]] void abort(void);  // (depuis C23)

Provoque une terminaison anormale du programme, sauf si SIGABRT est interceptée par un gestionnaire de signal passé à signal et que ce gestionnaire ne retourne pas.

Les fonctions passées à atexit() ne sont pas appelées. Que les ressources ouvertes, comme les fichiers, soient fermées est défini par l'implémentation. Un statut défini par l'implémentation indiquant une exécution non réussie est renvoyé à l'environnement hôte.

Paramètres

(aucune)

Valeur de retour

(aucune)

Notes

POSIX précise que la fonction abort() remplace le blocage ou l'ignorance du signal SIGABRT.

Certaines intrinsèques du compilateur, par exemple __builtin_trap (gcc, clang et icc) ou __fastfail/__debugbreak (msvc), peuvent être utilisées pour terminer le programme le plus rapidement possible.

Exemple

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    FILE *fp = fopen("data.txt","r");
    if (fp == NULL)
    {
        fprintf(stderr, "error opening file data.txt in function main()\n");
        abort();
    }

    /* L'exécution normale se poursuit ici. */
    fclose(fp);
    printf("Normal Return\n");
    return 0;
}

Output:

error opening file data.txt in function main()
