jmp_buf

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <setjmp.h>

typedef /* unspecified */ jmp_buf;

Le type jmp_buf est un type tableau adapté au stockage des informations permettant de restaurer un environnement d'appel. Les informations stockées suffisent pour reprendre l'exécution au bon bloc du programme et à l'invocation de ce bloc. L'état des indicateurs d'état à virgule flottante, des fichiers ouverts ou de toute autre donnée n'est pas stocké dans un objet de type jmp_buf.
