SIG_ERR

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <signal.h>

#define SIG_ERR /* implementation defined */

Une valeur de type void (*)(int). Lorsqu'elle est renvoyée par signal, indique qu'une erreur s'est produite.

Exemple

#include <stdio.h>
#include <stdlib.h>
#include <signal.h>

void signal_handler(int sig)
{
    printf("Received signal: %d\n", sig);
}

int main(void)
{
    /* Installe un gestionnaire de signal. */
    if (signal(SIGTERM, signal_handler) == SIG_ERR)
    {
        printf("Error while installing a signal handler.\n");
        exit(EXIT_FAILURE);
    }

    printf("Sending signal: %d\n", SIGTERM);
    if (raise(SIGTERM) != 0)
    {
        printf("Error while raising the SIGTERM signal.\n");
        exit(EXIT_FAILURE);
    }

    printf("Exit main()\n");
    return EXIT_SUCCESS;
}

Output:

Sending signal: 15
Received signal: 15
Exit main()
