_Exit

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

void _Exit( int exit_code );  // (depuis C99) (jusqu'à C11)

_Noreturn void _Exit( int exit_code );  // (depuis C11) (jusqu'à C23)

[[noreturn]] void _Exit( int exit_code );  // (depuis C23)

Provoque une terminaison normale du programme sans nettoyer complètement les ressources.

Les fonctions passées à at_quick_exit() ou atexit() ne sont pas appelées. Que les flux ouverts contenant des données tamponnées non écrites soient vidés, que les flux ouverts soient fermés ou que les fichiers temporaires soient supprimés est défini par l'implémentation.

Si exit_code vaut 0 ou EXIT_SUCCESS, un statut défini par l'implémentation indiquant une terminaison réussie est renvoyé à l'environnement hôte. Si exit_code vaut EXIT_FAILURE, un statut défini par l'implémentation, indiquant une terminaison non réussie, est renvoyé. Dans les autres cas, une valeur de statut définie par l'implémentation est renvoyée.

Paramètres

  • exit_code — statut de sortie du programme

Valeur de retour

(aucune)

Exemple

#include <stdlib.h>
#include <stdio.h>

/* _Exit n'appelle pas les fonctions enregistrées avec atexit. */
void f1(void)
{
    puts("pushed first");
}

void f2(void)
{
    puts("pushed second");
}

int main(void)
{
    printf("Enter main()\n");
    atexit(f1);
    atexit(f2);
    fflush(stdout);   /* _Exit peut ne pas vider les données tamponnées non écrites */
    _Exit(0);
}

Output:

Enter main()
