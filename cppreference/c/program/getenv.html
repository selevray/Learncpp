getenv, getenv_s

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

char *getenv( const char *name );  // (1)

errno_t getenv_s( size_t *restrict len, char *restrict value,
                  rsize_t valuesz, const char *restrict name );  // (2) (depuis C11)
  1. Recherche une variable d'environnement de nom name dans la liste d'environnement spécifiée par l'hôte et renvoie un pointeur vers la chaîne associée à la variable d'environnement trouvée. L'ensemble des variables d'environnement et les méthodes permettant de les modifier sont définis par l'implémentation.

Cette fonction n'est pas tenue d'être thread-safe. Un autre appel à getenv, ainsi qu'un appel aux fonctions POSIX setenv(), unsetenv() et putenv(), peuvent invalider le pointeur renvoyé par un appel précédent ou modifier la chaîne obtenue lors d'un appel précédent.

Modifier la chaîne renvoyée par getenv provoque un comportement indéfini.

  1. Identique à (1), sauf que la valeur de la variable d'environnement est écrite dans le tampon fourni par l'utilisateur value (sauf s'il est nul) et que le nombre d'octets écrits est stocké dans l'emplacement fourni par l'utilisateur *len (sauf s'il est nul). Si la variable d'environnement n'est pas définie, zéro est écrit dans *len (sauf s'il est nul) et '\0' est écrit dans value[0] (sauf s'il est nul). De plus, les erreurs suivantes sont détectées à l'exécution et appellent la fonction gestionnaire de contraintes actuellement installée :
  • name est un pointeur nul
  • valuesz est supérieur à RSIZE_MAX
  • value est un pointeur nul et valuesz n'est pas zéro Comme pour toutes les fonctions à vérification de bornes, getenv_s n'est garantie disponible que si __STDC_LIB_EXT1__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT1__ comme la constante entière 1 avant d'inclure <stdlib.h>.

Paramètres

  • name — chaîne de caractères terminée par un caractère nul identifiant le nom de la variable d'environnement recherchée
  • len — pointeur vers un emplacement fourni par l'utilisateur où getenv_s stockera la longueur de la variable d'environnement
  • value — pointeur vers un tableau de caractères fourni par l'utilisateur où getenv_s stockera le contenu de la variable d'environnement
  • valuesz — nombre maximal de caractères que getenv_s est autorisée à écrire dans dest (taille du tampon)

Valeur de retour

  1. chaîne de caractères identifiant la valeur de la variable d'environnement, ou pointeur nul si cette variable n'est pas trouvée.

  2. zéro si la variable d'environnement a été trouvée, non nul si elle ne l'a pas été ou si une violation de contrainte à l'exécution s'est produite. En cas d'erreur, écrit zéro dans *len (sauf si len est un pointeur nul).

Notes

Sous POSIX, les variables d'environnement sont aussi accessibles via la variable globale environ, déclarée comme extern char **environ; dans <unistd.h>, et via le troisième argument optionnel, envp, de la fonction main.

L'appel de getenv_s avec un pointeur nul pour value et zéro pour valuesz sert à déterminer la taille du tampon nécessaire pour contenir l'intégralité du résultat.

Exemple

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char *name = "PATH";
    const char *env_p = getenv(name);
    if (env_p)
        printf("Your %s is %s\n", name, env_p);
}

Sortie possible :

Your PATH is /home/gamer/.local/bin:/usr/local/bin:/usr/bin:/bin:/usr/share/games
