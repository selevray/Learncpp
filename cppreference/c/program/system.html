system

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdlib.h>

int system( const char *command );

Appelle le processeur de commandes de l'environnement hôte avec le paramètre command. Renvoie une valeur définie par l'implémentation (généralement la valeur retournée par le programme invoqué).

Si command est un pointeur nul, vérifie si l'environnement hôte dispose d'un processeur de commandes et renvoie une valeur non nulle si et seulement si le processeur de commandes existe.

Paramètres

  • command — chaîne de caractères identifiant la commande à exécuter dans le processeur de commandes. Si un pointeur nul est donné, le processeur de commandes est vérifié pour son existence

Valeur de retour

Valeur définie par l'implémentation. Si command est un pointeur nul, renvoie une valeur non nulle si et seulement si le processeur de commandes existe.

Notes

Sur les systèmes POSIX, la valeur de retour peut être décomposée à l'aide de WEXITSTATUS et WSTOPSIG.

La fonction POSIX associée popen rend la sortie générée par command disponible pour l'appelant.

Exemple

Dans cet exemple, on effectue un appel système de la commande unix date +%A et un appel système au compilateur gcc (éventuellement installé) avec l'argument de ligne de commande (--version) :

#include <stdlib.h>

int main(void) {
    system("date +%A");
    system("gcc --version");
}
