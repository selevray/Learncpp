Informations sur le nom de fichier et la ligne

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Modifie le numéro de ligne courant et le nom de fichier courant dans le préprocesseur.

Syntaxe

| | | | #line lineno | (1) | | | | #line lineno "filename" | (2) | | |

Explication

  1. Modifie le numéro de ligne courant du préprocesseur en lineno. Les occurrences de la macro __LINE__ au-delà de ce point se développeront en lineno plus le nombre de lignes de code source réelles rencontrées depuis.

  2. Modifie aussi le nom de fichier courant du préprocesseur en filename. Les occurrences de la macro __FILE__ au-delà de ce point produiront filename.

Tous les jetons de prétraitement (constantes de macro ou expressions) sont admis comme arguments de #line, à condition qu'ils se développent en un entier décimal valide, éventuellement suivi d'une chaîne de caractères valide.

lineno doit être une suite d'au moins un chiffre décimal (sinon le programme est mal formé) et est toujours interprété en décimal (même s'il commence par 0).

Si lineno est 0 ou supérieur à [32767 (jusqu'à C99) | 2147483647 (depuis C99)], le comportement est indéfini.

Notes

Cette directive est utilisée par certains outils de génération automatique de code qui produisent des fichiers source C à partir d'un fichier écrit dans un autre langage. Dans ce cas, des directives #line peuvent être insérées dans le fichier C généré, référençant les numéros de ligne et le nom de fichier du fichier source original (modifiable par un humain).

Le numéro de ligne qui suit la directive #line __LINE__ n'est pas spécifié (deux valeurs possibles peuvent être obtenues pour __LINE__ dans ce cas : le nombre de fins de ligne vues jusqu'ici, ou ce nombre plus la fin de ligne qui termine la directive #line). C'est le résultat de DR 464, qui s'applique rétroactivement.

Exemple

#include <assert.h>
#define FNAME "test.c"
int main(void)
{
#line 777 FNAME
        assert(2+2 == 5);
}

Sortie possible :

test: test.c:777: int main(): Assertion `2+2 == 5' failed.
