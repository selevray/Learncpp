Inclusion conditionnelle

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Le préprocesseur permet la compilation conditionnelle de parties d'un fichier source. Ce comportement est contrôlé par les directives #if, #else, #elif, #ifdef, #ifndef, #elifdef, #elifndef (depuis C23) et #endif.

Syntaxe

| | | | #if expression | | | | | #ifdef identifier | | | | | #ifndef identifier | | | | | #elif expression | | | | | #elifdef identifier | | (depuis C23) | | | #elifndef identifier | | (depuis C23) | | | #else | | | | | #endif | | | |

Explication

Le bloc de préprocessing conditionnel commence par une directive #if, #ifdef ou #ifndef, puis comprend éventuellement un nombre quelconque de directives #elif, #elifdef ou #elifndef (depuis C23), puis comprend éventuellement au plus une directive #else et se termine par la directive #endif. Les blocs de préprocessing conditionnel imbriqués sont traités séparément.

Chacune des directives #if, #ifdef, #ifndef, #elif, #elifdef, #elifndef (depuis C23) et #else contrôle le bloc de code jusqu'à la première directive #elif, #elifdef, #elifndef (depuis C23), #else ou #endif n'appartenant à aucun bloc de préprocessing conditionnel imbriqué.

Les directives #if, #ifdef et #ifndef testent la condition spécifiée (voir ci-dessous) et, si elle est évaluée à vrai, compilent le bloc de code contrôlé. Dans ce cas, les directives #else, #elifdef, #elifndef, (depuis C23) et #elif suivantes sont ignorées. Sinon, si la condition spécifiée est évaluée à faux, le bloc de code contrôlé est ignoré et la directive #else, #elifdef, #elifndef, (depuis C23) ou #elif suivante (le cas échéant) est traitée. Si la directive suivante est #else, le bloc de code contrôlé par la directive #else est compilé sans condition. Sinon, la directive #elif, #elifdef ou #elifndef (depuis C23) agit comme si c'était la directive #if : elle vérifie la condition, compile ou ignore le bloc de code contrôlé selon le résultat, et dans ce dernier cas traite les directives #elif, #elifdef, #elifndef, (depuis C23) et #else suivantes. Le bloc de préprocessing conditionnel se termine par la directive #endif.

Évaluation conditionnelle

#if, #elif

expression est une expression constante, n'utilisant que des constantes et des identificateurs, définis à l'aide de la directive #define. Tout identificateur qui n'est pas un littéral, et qui n'a pas été défini à l'aide de la directive #define, est évalué à 0 sauf true qui est évalué à 1 (depuis C23).

L'expression peut contenir des opérateurs unaires de la forme defined identifier ou defined (identifier) qui valent 1 si le identifier a été défini à l'aide de la directive #define, et 0 sinon. Dans ce contexte, __has_include, __has_embed et __has_c_attribute sont traités comme s'il s'agissait de noms de macros définies. (depuis C23) Si l'expression est évaluée à une valeur non nulle, le bloc de code contrôlé est inclus, sinon il est ignoré. Si un identificateur utilisé n'est pas une constante, il est remplacé par 0.

Dans le contexte d'une directive du préprocesseur, une expression __has_c_attribute détecte si un jeton d'attribut donné est pris en charge, ainsi que sa version prise en charge. Voir Test des attributs.

(depuis C23)

Remarque : jusqu'à DR 412, #if cond1 ... #elif cond2 est différent de #if cond1 ... #else suivi de #if cond3, car si cond1 est vraie, la seconde #if est ignorée et cond3 n'a pas besoin d'être bien formé, alors que #elif de cond2 doit être une expression valide. Depuis DR 412, #elif qui commence le bloc de code ignoré est également ignoré.

Directives combinées

Vérifie si l'identifiant a été défini comme nom de macro.

#ifdef identifier est essentiellement équivalent à #if defined identifier.

#ifndef identifier est essentiellement équivalent à #if !defined identifier.

#elifdef identifier est essentiellement équivalent à #elif defined identifier.

#elifndef identifier est essentiellement équivalent à #elif !defined identifier.

(depuis C23)

Notes

Bien que les directives #elifdef et #elifndef visent C23, les implémentations peuvent les rétroporter aux modes de langage antérieurs en tant qu'extensions conformes.

Exemple

#define ABCD 2
#include <stdio.h>

int main(void)
{

#ifdef ABCD
    printf("1: yes\n");
#else
    printf("1: no\n");
#endif

#ifndef ABCD
    printf("2: no1\n");
#elif ABCD == 2
    printf("2: yes\n");
#else
    printf("2: no2\n");
#endif

#if !defined(DCBA) && (ABCD < 2 * 4 - 3)
    printf("3: yes\n");
#endif

// Directives C23 #elifdef/#elifndef
#ifdef CPU
    printf("4: no1\n");
#elifdef GPU
    printf("4: no2\n");
#elifndef RAM
    printf("4: yes\n"); // sélectionnée en mode C23, peut être sélectionnée en mode antérieur à C23
#else
    printf("4: no3\n"); // peut être sélectionnée en mode antérieur à C23
#endif
}

Sortie possible :

1: yes
2: yes
3: yes
4: yes
