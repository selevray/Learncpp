Commentaires

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les commentaires servent en quelque sorte de documentation intégrée au code. Lorsqu'ils sont insérés dans un programme, ils sont effectivement ignorés par le compilateur ; ils sont uniquement destinés à servir de notes aux humains qui lisent le code source.

Syntaxe

| | | | /* comment */ | (1) | | | | // comment | (2) | (depuis C99) | |

  1. Souvent appelés commentaires « de style C » ou « multiligne ».

  2. Souvent appelés commentaires « de style C++ » ou « sur une ligne ».

Tous les commentaires sont supprimés du programme lors de la phase de traduction 3, en remplaçant chaque commentaire par un unique caractère d'espacement.

Style C

Les commentaires de style C servent généralement à commenter de grands blocs de texte ou de petits fragments de code ; ils peuvent toutefois être utilisés pour commenter une seule ligne. Pour insérer du texte sous forme de commentaire de style C, il suffit d'encadrer le texte par /* et */. Les commentaires de style C indiquent au compilateur d'ignorer tout le contenu compris entre /* et */. Bien que ce ne soit pas une partie de la norme C, /** et **/ sont souvent utilisés pour indiquer des blocs de documentation ; c'est licite, car le second astérisque est simplement traité comme faisant partie du commentaire.

Hormis à l'intérieur d'un littéral de caractère, d'un littéral de chaîne ou d'un commentaire, les caractères /* introduisent un commentaire. Le contenu d'un tel commentaire n'est examiné que pour identifier les caractères multi-octets et trouver les caractères */ qui terminent le commentaire. Les commentaires de style C ne peuvent pas être imbriqués.

Style C++

Les commentaires de style C++ servent généralement à commenter une seule ligne de texte ou de code ; ils peuvent toutefois être placés les uns à la suite des autres pour former des commentaires sur plusieurs lignes. Pour insérer du texte sous forme de commentaire de style C++, il suffit de faire précéder le texte de // et de le faire suivre du caractère de nouvelle ligne. Les commentaires de style C++ indiquent au compilateur d'ignorer tout le contenu compris entre // et une nouvelle ligne.

Hormis à l'intérieur d'un littéral de caractère, d'un littéral de chaîne ou d'un commentaire, les caractères // introduisent un commentaire qui comprend tous les caractères multi-octets jusqu'au caractère de nouvelle ligne suivant, non inclus. Le contenu d'un tel commentaire n'est examiné que pour identifier les caractères multi-octets et trouver le caractère de nouvelle ligne qui termine le commentaire. Les commentaires de style C++ peuvent être imbriqués :

//  y = f(x);   // invoque l'algorithme

Un commentaire de style C peut apparaître à l'intérieur d'un commentaire de style C++ :

//  y = f(x);   /* invoque l'algorithme */

Un commentaire de style C++ peut apparaître à l'intérieur d'un commentaire de style C ; c'est un mécanisme permettant d'exclure un petit bloc de code source :

/*
    y = f(x);   // invoque les algorithmes
    z = g(x);
*/

(depuis C99)

Notes

Comme les commentaires sont supprimés avant l'étape du préprocesseur, une macro ne peut pas former un commentaire, et un commentaire de style C non terminé ne déborde pas à partir d'un fichier inclus avec #include.

/* Une tentative d'utilisation d'une macro pour former un commentaire. */
/* Mais un espace remplace les caractères "//".       */
#ifndef DEBUG
    #define PRINTF //
#else
    #define PRINTF printf
#endif
...
PRINTF("Error in file %s at line %i\n", __FILE__, __LINE__);

Outre la mise en commentaire, d'autres mécanismes utilisés pour exclure du code source sont :

#if 0
    puts("this will not be compiled");
    /* aucun conflit avec les commentaires de style C */
    // aucun conflit avec les commentaires de style C++
#endif

and

if(0) {
    puts("this will be compiled but not be executed");
    /* aucun conflit avec les commentaires de style C */
    // aucun conflit avec les commentaires de style C++
}

L'introduction des commentaires // en C99 a constitué un changement incompatible dans quelques rares circonstances :

a = b //*divisor:*/ c
+ d; /* C89 compile a = b / c + d;
        C99 compile a = b + d; */

Exemple

#include <stdio.h>
/*
Les commentaires de style C peuvent contenir
plusieurs lignes.
*/

/* Ou bien une seule ligne. */

// Les commentaires de style C++ peuvent commenter une ligne.

// Ou bien ils peuvent
// être enchaînés.

int main(void)
{
  // Le code ci-dessous ne sera pas exécuté
  // puts("Hello");

  // Le code ci-dessous sera exécuté
  puts("World");

  // Remarque concernant la barre oblique inversée suivie d'un saut de ligne.
  // Bien qu'appartenant à la phase 2 de traduction (contre la phase 3 pour les commentaires),
  // '\' détermine toujours quelle portion du code source est considérée
  // comme « commentaires » :
  // Ce commentaire sera reporté sur la ligne suivante \
  puts("Ne sera pas exécuté"); // peut émettre un avertissement "multi-line comment"
  puts("Hello, again");
}

Output:

World
Hello, again
