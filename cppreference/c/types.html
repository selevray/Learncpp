Types de base

Types de base supplémentaires et macros pratiques

Défini dans l'en-tête <stddef.h>

  • size_t — type entier non signé renvoyé par l'opérateur sizeof (typedef)
  • ptrdiff_t — type entier signé renvoyé lors de la soustraction de deux pointeurs (typedef)
  • nullptr_t (C23) — le type de la constante pointeur nul prédéfinie nullptr (typedef)
  • NULL — constante de pointeur nul définie par l'implémentation (constante macro)
  • max_align_t (C11) — un type ayant une exigence d'alignement aussi grande que tout autre type scalaire (typedef)
  • offsetof — décalage en octets depuis le début d'un type struct jusqu'au membre spécifié (macro de fonction)

Défini dans l'en-tête <stdbool.h>

  • bool (C99) (removed in C23) — macro pratique, se développe en _Bool (macro de mot-clé)
  • true (C99) (removed in C23) — se développe en constante entière 1 (constante de macro)
  • false (C99) (removed in C23) — se développe en constante entière 0 (constante de macro)
  • __bool_true_false_are_defined (C99) (deprecated in C23) — se développe en constante entière 1 (constante de macro)

Défini dans l'en-tête <stdalign.h>

  • alignas (C11) (removed in C23) — macro pratique, se développe en mot-clé _Alignas (macro de mot-clé)
  • alignof (C11) (removed in C23) — macro pratique, se développe en mot-clé _Alignof (macro de mot-clé)
  • __alignas_is_defined (C11) (removed in C23) — se développe en constante entière 1 (constante de macro)
  • __alignof_is_defined (C11) (removed in C23) — se développe en constante entière 1 (constante de macro)

Défini dans l'en-tête <stdnoreturn.h>

  • noreturn (C11) (deprecated in C23) — macro pratique, se développe en _Noreturn (macro de mot-clé)

Limites numériques

Notes

Le type de true et false est int au lieu de _Bool.

Un programme peut annuler la définition des macros bool, true et false, puis éventuellement les redéfinir. Toutefois, une telle possibilité est une fonctionnalité obsolète.

(depuis C99) (jusqu'à C23)

Le type de true et false est bool. Il n'est pas spécifié si l'une quelconque de bool, _Bool, true ou false est implémentée comme macro prédéfinie.

Si bool, true ou false (mais pas _Bool) est défini comme macro prédéfinie, un programme peut en annuler la définition et éventuellement la redéfinir.

(depuis C23)

Exemple

#include <stdalign.h>
#include <stdbool.h>
#include <stdio.h>

int main(void)
{
    printf("%d %d %d\n", true && false, true || false, !false);
    printf("%d %d\n", true ^ true, true + true);
    printf("%zu\n", alignof(short));
}
