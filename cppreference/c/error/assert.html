assert

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <assert.h>

#ifdef NDEBUG
#define assert(condition) ((void)0)
#else
#define assert(condition) /*implementation defined*/
#endif  // (jusqu'à C23)

#ifdef NDEBUG
#define assert(...) ((void)0)
#else
#define assert(...) /*implementation defined*/
#endif  // (depuis C23)

La définition de la macro assert dépend d'une autre macro, NDEBUG, qui n'est pas définie par la bibliothèque standard.

Si NDEBUG est définie comme nom de macro au point du code source où <assert.h> est inclus, alors assert ne fait rien.

Si NDEBUG n'est pas définie, alors assert vérifie si [son argument (jusqu'à C23) | l'expression synthétisée à partir de __VA_ARGS__ (depuis C23)] (qui doit être de type scalaire, sinon le comportement est indéfini) est égale à zéro. Si c'est le cas, assert écrit des informations de diagnostic propres à l'implémentation sur la sortie d'erreur standard et appelle abort(). Les informations de diagnostic doivent inclure le texte de expression, ainsi que les valeurs de la variable prédéfinie __func__ et de (depuis C99) les macros prédéfinies __FILE__ et __LINE__.

Paramètres

  • condition — expression de type scalaire

Valeur de retour

(aucune)

Notes

Il n'existe pas d'interface standardisée pour ajouter un message supplémentaire aux erreurs de assert. Une manière portable de l'inclure consiste à utiliser un opérateur virgule, ou à utiliser && avec un littéral de chaîne :

assert(("There are five lights", 2 + 2 == 5));
assert(2 + 2 == 5 && "There are five lights");

L'implémentation de assert dans Microsoft CRT n'est pas conforme au C99 et aux révisions ultérieures, car sa fonction sous-jacente (_wassert) ne prend ni __func__ ni un remplacement équivalent.

Bien que le changement de assert en C23 (N2829) ne soit pas un rapport de défaut formel, le comité C recommande aux implémentations de rétroporter ce changement vers les anciens modes.

Exemple

#include <stdio.h>
// décommenter pour désactiver assert()
// #define NDEBUG
#include <assert.h>
#include <math.h>

#define TEST(...) __VA_ARGS__

int main(void)
{
    double x = -1.0;
    assert(x >= 0.0);
    printf("sqrt(x) = %f\n", sqrt(x));

    assert(TEST(x >= 0.0));

    return 0;
}

Sortie possible :

--- Output with NDEBUG not defined: ---
a.out: main.cpp:10: main: Assertion `x >= 0.0' failed.

--- Output with NDEBUG defined: ---
sqrt(x) = -nan
