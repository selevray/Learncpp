static_assert

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <assert.h>

#define static_assert _Static_assert  // (depuis C11) (supprimé en C23)

Cette macro de commodité se développe en le mot-clé _Static_assert.

Exemple

#include <assert.h>

int main(void)
{
    static_assert(2 + 2 == 4, "2+2 isn't 4");   // bien formé

    static_assert(sizeof(int) < sizeof(char),   // erreur à la compilation
                  "this program requires that int is less than char");
}

Notes

Depuis C23, static_assert est lui-même un mot-clé, qui peut aussi être une macro prédéfinie, donc <assert.h> ne le fournit plus.
