qualificateur de type const

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Chaque type individuel du système de types C possède plusieurs versions qualifiées de ce type, correspondant à un, deux ou aux trois qualificateurs const, volatile et, pour les pointeurs vers des types objets, restrict. Cette page décrit les effets du qualificateur const.

Les objets déclarés avec des types qualifiés const peuvent être placés par le compilateur en mémoire en lecture seule, et si l'adresse d'un objet const n'est jamais prise dans un programme, il peut ne pas être stocké du tout.

Toute tentative de modification d'un objet dont le type est qualifié const entraîne un comportement indéfini.

const int n = 1; // objet de type qualifié const
int* p = (int*)&n;
*p = 2; // comportement indéfini

La sémantique de const ne s'applique qu'aux expressions lvalue ; chaque fois qu'une expression lvalue const est utilisée dans un contexte ne nécessitant pas une lvalue, son qualificateur const est perdu (notez que le qualificateur volatile, s'il est présent, n'est pas perdu).

Les expressions lvalue désignant des objets de type qualifié const, ainsi que les expressions lvalue désignant des objets de type struct ou union comportant au moins un membre de type qualifié const (y compris les membres des agrégats ou unions contenus récursivement), ne sont pas des lvalues modifiables. En particulier, elles ne sont pas affectables :

const int n = 1; // objet de type const
n = 2; // erreur : le type de n est qualifié const

int x = 2; // objet de type non qualifié
const int* p = &x;
*p = 3; // erreur : le type de la lvalue *p est qualifié const

struct {int a; const int b; } s1 = {.b=1}, s2 = {.b=2};
s1 = s2; // erreur : le type de s1 est non qualifié, mais il possède un membre const

Un membre d'un type structure ou union qualifié const acquiert la qualification du type auquel il appartient (que l'accès se fasse avec l'opérateur . ou avec l'opérateur ->).

struct s { int i; const int ci; } s;
// le type de s.i est int, le type de s.ci est const int
const struct s cs;
// les types de cs.i et cs.ci sont tous deux const int

Si un type tableau est déclaré avec le qualificateur de type const (par l'intermédiaire de typedef), le type tableau n'est pas qualifié const, mais son type d'élément l'est.

(jusqu'à C23)

Un type tableau et son type d'élément sont toujours considérés comme ayant la même qualification const.

(depuis C23)

typedef int A[2][3];
const A a = {{4, 5, 6}, {7, 8, 9}}; // tableau de tableaux de const int
int* pi = a[0]; // Erreur : a[0] a le type const int*
void *unqual_ptr = a; // OK jusqu'à C23 ; erreur depuis C23
// Notes : clang applique la règle en C++/C23 même en modes C89-C17

Si un type fonction est déclaré avec le qualificateur de type const (par l'intermédiaire de typedef), le comportement est indéfini.

Dans une déclaration de fonction, le mot-clé const peut apparaître à l'intérieur des crochets utilisés pour déclarer un type tableau d'un paramètre de fonction. Il qualifie le type pointeur vers lequel le type tableau est transformé.

Les deux déclarations suivantes déclarent la même fonction :

void f(double x[const], const double y[const]);
void f(double * const x, const double * const y);

(depuis C99)

Les littéraux composés qualifiés const ne désignent pas nécessairement des objets distincts ; ils peuvent partager le stockage avec d'autres littéraux composés et avec des littéraux de chaîne qui ont par hasard la même représentation ou une représentation qui se chevauche.

const int* p1 = (const int[]){1, 2, 3};
const int* p2 = (const int[]){2, 3, 4}; // la valeur de p2 peut être égale à p1+1
_Bool b = "foobar" + 3 == (const char[]){"bar"}; // la valeur de b peut être 1

(depuis C99)

Un pointeur vers un type non const peut être implicitement converti en un pointeur vers la version qualifiée const du même type ou d'un type compatible. La conversion inverse nécessite une expression de transtypage.

int* p = 0;
const int* cp = p; // OK : ajoute des qualificateurs (int vers const int)
p = cp; // Erreur : supprime des qualificateurs (const int vers int)
p = (int*)cp; // OK : transtypage

Notez qu'un pointeur vers un pointeur vers T n'est pas convertible en un pointeur vers un pointeur vers const T ; pour que deux types soient compatibles, leurs qualificateurs doivent être identiques.

char *p = 0;
const char **cpp = &p; // Erreur : char* et const char* ne sont pas des types compatibles
char * const *pcp = &p; // OK, ajoute des qualificateurs (char* vers char*const)

Mots-clés

const

Notes

C a repris le qualificateur const de C++, mais contrairement à C++, les expressions de type qualifié const en C ne sont pas des expressions constantes ; elles ne peuvent pas être utilisées comme étiquettes case ni pour initialiser des objets à durée de stockage static et thread, des énumérateurs ou des tailles de champs de bits. Lorsqu'elles sont utilisées comme tailles de tableaux, les tableaux obtenus sont des VLA.
