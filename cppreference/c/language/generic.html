Sélection générique (depuis C11)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Permet de choisir l'une de plusieurs expressions à la compilation, en fonction du type d'une expression de contrôle

Syntaxe

| | | | _Generic ( controlling-expression , association-list ) | | (depuis C11) | |

où association-list est une liste d'associations séparées par des virgules, chacune ayant la syntaxe

| | | | type-name : expression | | | | | default : expression | | | |

where

  • type-name — tout type objet complet qui n'est pas à taille variable (c'est-à-dire ni VLA ni pointeur vers VLA).
  • controlling-expression — toute expression (sauf l'opérateur virgule) dont le type doit être compatible avec l'un des type-name si l'association default n'est pas utilisée
  • expression — toute expression (sauf l'opérateur virgule) de type et de catégorie de valeur quelconques

Deux type-names de la association-list ne peuvent pas désigner des types compatibles. Il ne peut y avoir qu'une seule association utilisant le mot-clé default. Si default n'est pas utilisé et qu'aucun des type-names n'est compatible avec le type de l'expression de contrôle, le programme ne compilera pas.

Explication

D'abord, le type de controlling-expression subit des conversions lvalue. La conversion s'effectue uniquement dans le domaine des types : elle supprime les qualificateurs cvr de premier niveau et l'atomicité, et applique les transformations tableau-vers-pointeur et fonction-vers-pointeur au type de l'expression de contrôle, sans déclencher d'effets de bord ni calculer de valeurs.

Le type après conversion est comparé aux type-names de la liste des associations.

Si le type est compatible avec le type-name de l'une des associations, alors le type, la valeur et la catégorie de valeur de la sélection générique sont le type, la valeur et la catégorie de valeur de l'expression qui apparaît après les deux-points pour cette type-name.

Si aucun des type-names n'est compatible avec le type du controlling-expression, et que l'association default est fournie, alors le type, la valeur et la catégorie de valeur de la sélection générique sont le type, la valeur et la catégorie de valeur de l'expression qui suit l'étiquette default :.

Notes

L'controlling-expression et les expressions des sélections non choisies ne sont jamais évalués.

En raison des conversions lvalue, "abc" correspond à char* et non à char[4], et (int const){0} correspond à int, et non à const int.

Toutes les catégories de valeur, y compris les désignateurs de fonctions et les expressions void, sont autorisées comme expressions dans une sélection générique, et si elle est choisie, la sélection générique elle-même a la même catégorie de valeur.

Les macros mathématiques génériques par type de <tgmath.h>, introduites en C99, étaient implémentées de manière propre à chaque compilateur. Les sélections génériques, introduites en C11, ont donné aux programmeurs la possibilité d'écrire du code dépendant du type de manière similaire.

La sélection générique est similaire à la surcharge en C++ (où l'une de plusieurs fonctions est choisie à la compilation en fonction des types des arguments), sauf qu'elle choisit entre des expressions arbitraires.

Mots-clés

_Generic, default

Exemple

#include <math.h>
#include <stdio.h>

// Implémentation possible de la macro cbrt de tgmath.h
#define cbrt(X) _Generic((X),     \
              long double: cbrtl, \
                  default: cbrt,  \
                    float: cbrtf  \
              )(X)

int main(void)
{
    double x = 8.0;
    const float y = 3.375;
    printf("cbrt(8.0) = %f\n", cbrt(x));    // sélectionne le cbrt par défaut
    printf("cbrtf(3.375) = %f\n", cbrt(y)); // convertit const float en float,
                                            // puis sélectionne cbrtf
}

Output:

cbrt(8.0) = 2.000000
cbrtf(3.375) = 1.500000
