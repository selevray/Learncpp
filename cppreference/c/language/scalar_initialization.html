Initialisation scalaire

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Lors de l'initialisation d'un objet de type scalaire, l'initialiseur doit être une expression unique

L'initialiseur d'un scalaire (un objet de type entier, y compris booléen et énumération, de type flottant, y compris complexe et imaginaire, ou de type pointeur, y compris pointeur vers fonction) doit être une expression unique, éventuellement entourée d'accolades, ou un initialiseur vide (depuis C23) :

| | | | = expression | (1) | | | | = { expression } | (2) | | | | = { } | (3) | (depuis C23) | |

1,2) L'expression est évaluée, et sa valeur, après conversion comme par affectation vers le type de l'objet, devient la valeur initiale de l'objet initialisé.

  1. L'objet est initialisé à zéro, c'est-à-dire initialisé à zéro numérique pour un objet de type arithmétique ou énumération, ou à la valeur de pointeur nul pour un objet de type pointeur.

Notes

En raison des règles applicables aux conversions comme par affectation, les qualificateurs const et volatile du type déclaré sont ignorés lors de la détermination du type vers lequel convertir la expression.

Voir initialisation pour les règles applicables lorsqu'aucun initialiseur n'est utilisé.

Comme pour toutes les autres initialisations, expression doit être une expression constante lors de l'initialisation d'objets à durée de stockage statique ou thread-local.

L'expression ne peut pas être un opérateur virgule (sauf s'il est entre parenthèses) car la virgule de niveau supérieur serait interprétée comme le début du déclarateur suivant.

Lors de l'initialisation d'objets de type flottant, tous les calculs pour les objets à durée de stockage automatique sont effectués comme à l'exécution et sont affectés par l'arrondi courant ; les erreurs en virgule flottante sont signalées comme spécifié dans math_errhandling. Pour les objets à durée de stockage statique et thread-local, les calculs sont effectués comme à la compilation, et aucune exception n'est levée :

void f(void)
{
#pragma STDC FENV_ACCESS ON
    static float v = 1.1e75; // ne lève pas d'exception : initialisation statique

    float u[] = { 1.1e75 }; // lève FE_INEXACT
    float w = 1.1e75;       // lève FE_INEXACT

    double x = 1.1e75; // peut lever FE_INEXACT (dépend de FLT_EVAL_METHOD)
    float y = 1.1e75f; // peut lever FE_INEXACT (dépend de FLT_EVAL_METHOD)

    long double z = 1.1e75; // ne lève pas d'exception (la conversion est exacte)
}

Exemple

#include <stdbool.h>
int main(void)
{
    bool b = true;
    const double d = 3.14;
    int k = 3.15; // conversion de double vers int
    int n = {12}, // accolades facultatives
       *p = &n,   // expression non constante acceptée pour une variable automatique
       (*fp)(void) = main;
    enum {RED, BLUE} e = RED; // les énumérations sont également des types scalaires
}
