Déclaration de tableau

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un tableau est un type constitué d'une séquence non vide d'objets allouée de manière contiguë, dont le type d'élément est donné. Le nombre de ces objets (la taille du tableau) ne change jamais pendant la durée de vie du tableau.

Syntaxe

Dans la grammaire des déclarations d'une déclaration de tableau, la séquence de spécificateurs de type désigne le type d'élément (qui doit être un type objet complet), et le déclarateur a la forme :

| | | | [ static(facultatif) qualifiers ﻿*(facultatif)* expression ﻿*(facultatif)* ] attr-spec-seq ﻿*(facultatif)* | (1) | | | | [ qualifiers ﻿*(facultatif)* static(facultatif) expression ﻿*(facultatif)* ] attr-spec-seq ﻿*(facultatif)* | (2) | | | | [ qualifiers ﻿*(facultatif)* * ] attr-spec-seq ﻿*(facultatif)* | (3) | | |

1,2) Syntaxe générale du déclarateur de tableau

  1. Déclarateur de VLA de taille non spécifiée (ne peut apparaître que dans la portée du prototype de fonction) où
  • expression — toute expression autre que l'opérateur virgule désigne le nombre d'éléments du tableau
  • qualifiers — toute combinaison des qualificateurs const, restrict ou volatile, autorisée uniquement dans les listes de paramètres de fonction ; ils qualifient le type de pointeur vers lequel ce paramètre tableau est transformé
  • attr-spec-seq — (C23) liste facultative d'attributs, appliquée au tableau déclaré
float fa[11], *afp[17]; // fa est un tableau de 11 float
                        // afp est un tableau de 17 pointeurs vers des float

Explication

Il existe plusieurs variantes de types tableaux : les tableaux de taille constante connue, les tableaux de longueur variable et les tableaux de taille inconnue.

Tableaux de taille constante connue

Si expression dans un déclarateur de tableau est une expression constante entière de valeur strictement positive et que le type d'élément est un type de taille constante connue (c'est-à-dire que les éléments ne sont pas des VLA) (depuis C99), alors le déclarateur déclare un tableau de taille constante connue :

int n[10]; // les constantes entières sont des expressions constantes
char o[sizeof(double)]; // sizeof est une expression constante
enum { MAX_SZ=100 };
int n[MAX_SZ]; // les constantes énumérées sont des expressions constantes

Les tableaux de taille constante connue peuvent utiliser des initialisateurs de tableau pour fournir leurs valeurs initiales :

int a[5] = {1,2,3}; // déclare int[5] initialisé à 1,2,3,0,0
char str[] = "abc"; // déclare char[4] initialisé à 'a','b','c','\0'

Dans les listes de paramètres de fonction, des éléments de syntaxe supplémentaires sont autorisés dans les déclarateurs de tableau : le mot-clé static et qualifiers, qui peuvent apparaître dans n'importe quel ordre avant l'expression de taille (ils peuvent aussi apparaître même lorsque l'expression de taille est omise).

À chaque appel de fonction d'une fonction dont un paramètre tableau utilise le mot-clé static entre [ et ], la valeur du paramètre effectif doit être un pointeur valide vers le premier élément d'un tableau comportant au moins autant d'éléments que ne l'indique expression :

void fadd(double a[static 10], const double b[static 10])
{
    for (int i = 0; i < 10; i++)
    {
        if (a[i] < 0.0) return;
        a[i] += b[i];
    }
}
// un appel à fadd peut effectuer une vérification des bornes à la compilation
// et permet aussi des optimisations telles que le préchargement de 10 double
int main(void)
{
    double a[10] = {0}, b[20] = {0};
    fadd(a, b); // OK
    double x[5] = {0};
    fadd(x, b); // comportement indéfini : l'argument tableau est trop petit
}

Si qualifiers sont présents, ils qualifient le type de pointeur vers lequel le type du paramètre tableau est transformé :

int f(const int a[20])
{
    // dans cette fonction, a a le type const int* (pointeur vers const int)
}
int g(const int a[const 20])
{
    // dans cette fonction, a a le type const int* const (pointeur const vers const int)
}

Ceci est couramment utilisé avec le qualificateur de type restrict :

void fadd(double a[static restrict 10],
          const double b[static restrict 10])
{
    for (int i = 0; i < 10; i++) // la boucle peut être déroulée et réordonnée
    {
        if (a[i] < 0.0)
            break;
        a[i] += b[i];
    }
}

Tableaux de longueur variable

Si expression n'est pas une expression constante entière, le déclarateur est celui d'un tableau de taille variable.

Chaque fois que le flux de contrôle passe par la déclaration, expression est évaluée (et elle doit toujours avoir une valeur strictement positive), puis le tableau est alloué (en conséquence, la durée de vie d'un VLA se termine lorsque la déclaration sort de sa portée). La taille de chaque instance de VLA ne change pas pendant sa durée de vie, mais lors d'un nouveau passage par le même code, il peut être alloué avec une taille différente.

#include <stdio.h>

int main(void)
{
   int n = 1;
label:;
   int a[n]; // réalloué 10 fois, chacune avec une taille différente
   printf("The array has %zu elements\n", sizeof a / sizeof *a);
   if (n++ < 10)
       goto label; // quitter la portée d'un VLA met fin à sa durée de vie
}

Si la taille est *, la déclaration concerne un VLA de taille non spécifiée. Une telle déclaration ne peut apparaître que dans la portée d'un prototype de fonction et déclare un tableau d'un type complet. En fait, tous les déclarateurs VLA dans la portée d'un prototype de fonction sont traités comme si expression était remplacé par *.

void foo(size_t x, int a[*]);
void foo(size_t x, int a[x])
{
    printf("%zu\n", sizeof a); // identique à sizeof(int*)
}

Les tableaux de longueur variable et les types qui en dérivent (pointeurs vers eux, etc.) sont communément appelés « types à modification variable » (VM). Les objets d'un type à modification variable ne peuvent être déclarés que dans une portée de bloc ou dans la portée d'un prototype de fonction.

extern int n;
int A[n];            // Erreur : VLA de portée fichier
extern int (*p2)[n]; // Erreur : VM de portée fichier
int B[100];          // OK : tableau de portée fichier de taille constante connue
void fvla(int m, int C[m][m]); // OK : VLA de portée prototype

Un VLA doit avoir une durée de stockage automatique ou allouée. Les pointeurs vers un VLA, mais pas le VLA lui-même, peuvent aussi avoir une durée de stockage statique. Aucun type VM ne peut avoir de liaison.

void fvla(int m, int C[m][m]) // OK : pointeur de portée bloc/durée auto vers un VLA
{
    typedef int VLA[m][m]; // OK : VLA de portée bloc
    int D[m];              // OK : VLA de portée bloc/durée auto
//  static int E[m]; // Erreur : VLA à durée statique
//  extern int F[m]; // Erreur : VLA avec liaison
    int (*s)[m];     // OK : VM de portée bloc/durée auto
    s = malloc(m * sizeof(int)); // OK : s pointe vers un VLA en stockage alloué
//  extern int (*r)[m]; // Erreur : VM avec liaison
    static int (*q)[m] = &B; // OK : VM de portée bloc/durée statique}
}

Les types à modification variable ne peuvent pas être membres de structures ou d'unions.

struct tag
{
    int z[n]; // Erreur : membre de struct VLA
    int (*y)[n]; // Erreur : membre de struct VM
};

(depuis C99)

Si le compilateur définit la constante de macro __STDC_NO_VLA__ avec la constante entière 1, alors les VLA et les types VM ne sont pas pris en charge.

(depuis C11) (jusqu'à C23)

Si le compilateur définit la constante de macro __STDC_NO_VLA__ avec la constante entière 1, alors les objets VLA à durée de stockage automatique ne sont pas pris en charge.

La prise en charge des types VM et des VLA à durées de stockage allouées est obligatoire.

(depuis C23)

Tableaux de taille inconnue

Si expression dans un déclarateur de tableau est omis, il déclare un tableau de taille inconnue. Sauf dans les listes de paramètres de fonction (où ces tableaux sont transformés en pointeurs) et lorsqu'un initialisateur est disponible, ce type est un type incomplet(notez qu'un VLA de taille non spécifiée, déclaré avec * comme taille, est un type complet) (depuis C99) :

extern int x[]; // le type de x est « tableau de borne inconnue de int »
int a[] = {1,2,3}; // le type de a est « tableau de 3 int »

Dans une définition de struct, un tableau de taille inconnue peut apparaître comme dernier membre (à condition qu'il y ait au moins un autre membre nommé), auquel cas il s'agit d'un cas particulier appelé membre tableau flexible. Voir struct pour plus de détails :

struct s { int n; double d[]; }; // s.d est un membre tableau flexible
struct s *s1 = malloc(sizeof (struct s) + (sizeof (double) * 8)); // comme si d était double d[8]

(depuis C99)

Qualificateurs

Si un type tableau est déclaré avec un qualificateur const, volatile, ou restrict (depuis C99) (ce qui est possible grâce à l'utilisation de typedef), le type tableau n'est pas qualifié, mais son type d'élément l'est :

(jusqu'à C23)

Un type tableau et son type d'élément sont toujours considérés comme ayant les mêmes qualificateurs, sauf qu'un type tableau n'est jamais considéré comme qualifié _Atomic.

(depuis C23)

typedef int A[2][3];
const A a = {{4, 5, 6}, {7, 8, 9}}; // tableau de tableaux de const int
int* pi = a[0]; // Erreur : a[0] a le type const int*
void* unqual_ptr = a; // OK jusqu'à C23 ; erreur depuis C23
// Notes : clang applique la règle en C++/C23 même en modes C89-C17

_Atomic n'est pas autorisé sur un type tableau, bien qu'un tableau d'un type atomique soit autorisé.

typedef int A[2];
// _Atomic A a0 = {0};    // Erreur
// _Atomic(A) a1 = {0};   // Erreur
_Atomic int a2[2] = {0};  // OK
_Atomic(int) a3[2] = {0}; // OK

(depuis C11)

Affectation

Les objets de type tableau ne sont pas des lvalues modifiables et, bien que leur adresse puisse être prise, ils ne peuvent pas figurer à gauche d'un opérateur d'affectation. En revanche, les structures possédant des membres tableaux sont des lvalues modifiables et peuvent être affectées :

int a[3] = {1,2,3}, b[3] = {4,5,6};
int (*p)[3] = &a; // OK, l'adresse de a peut être prise
// a = b;            // erreur, a est un tableau
struct { int c[3]; } s1, s2 = {3,4,5};
s1 = s2; // OK : on peut affecter des structs contenant des membres tableaux

Conversion tableau vers pointeur

Toute expression lvalue de type tableau, lorsqu'elle est utilisée dans un contexte autre que

  • comme opérande de l'opérateur d'adresse
  • comme opérande de sizeof
  • comme opérande de typeof et typeof_unqual (depuis C23)
  • comme littéral de chaîne utilisé pour l'initialisation de tableau
  • comme opérande de [_Alignof (depuis C11) (jusqu'à C23) | alignof (depuis C23)]

(depuis C11)

subit une conversion implicite vers le pointeur vers son premier élément. Le résultat n'est pas une lvalue.

Si le tableau a été déclaré register, le comportement du programme qui tente cette conversion est indéfini.

int a[3] = {1,2,3};
int* p = a;
printf("%zu\n", sizeof a); // affiche la taille du tableau
printf("%zu\n", sizeof p); // affiche la taille d'un pointeur

Lorsqu'un type tableau est utilisé dans une liste de paramètres de fonction, il est transformé en le type pointeur correspondant : int f(int a[2]) et int f(int* a) déclarent la même fonction. Comme le type réel du paramètre de la fonction est un type pointeur, un appel de fonction avec un argument tableau effectue une conversion tableau vers pointeur ; la taille du tableau argument n'est pas disponible pour la fonction appelée et doit être transmise explicitement :

#include <stdio.h>

void f(int a[], int sz) // déclare en fait void f(int* a, int sz)
{
    for (int i = 0; i < sz; ++i)
        printf("%d\n", a[i]);
}

void g(int (*a)[10]) // le pointeur vers un paramètre tableau n'est pas transformé
{
    for (int i = 0; i < 10; ++i)
        printf("%d\n", (*a)[i]);
}

int main(void)
{
    int a[10] = {0};
    f(a, 10); // convertit a en int*, passe le pointeur
    g(&a);    // passe un pointeur vers le tableau (pas besoin de passer la taille)
}

Tableaux multidimensionnels

Lorsque le type d'élément d'un tableau est lui-même un tableau, on dit que le tableau est multidimensionnel :

// tableau de 2 tableaux de 3 int chacun
int a[2][3] = {{1,2,3},  // peut être vu comme une matrice 2x3
               {4,5,6}}; // avec disposition par lignes (row-major)

Notez que, lorsque la conversion tableau vers pointeur est appliquée, un tableau multidimensionnel est converti en un pointeur vers son premier élément, par exemple un pointeur vers la première ligne :

int a[2][3]; // matrice 2x3
int (*p1)[3] = a; // pointeur vers la première ligne de 3 éléments
int b[3][3][3]; // cube 3x3x3
int (*p2)[3][3] = b; // pointeur vers le premier plan 3x3

Les tableaux multidimensionnels peuvent être à modification variable dans toutes leurs dimensionssi les VLA sont pris en charge (depuis C11) :

int n = 10;
int a[n][2*n];

(depuis C99)

Notes

Les déclarations de tableaux de longueur nulle ne sont pas autorisées, même si certains compilateurs les proposent comme extensions (généralement comme implémentation pré-C99 des membres tableaux flexibles).

Si la taille expression d'un VLA a des effets de bord, ils sont garantis d'être produits, sauf lorsqu'elle fait partie d'une expression sizeof dont le résultat n'en dépend pas :

int n = 5, m = 5;
size_t sz = sizeof(int (*[n++])[m++]); // n est incrémenté, m peut ou non être incrémenté
