Les débuts du C

  • 1969 : création de B, basé sur BCPL, pour remplacer l'assembleur du PDP-7 comme langage de programmation système d'Unix

    • ajout des opérateurs ++, --, des affectations composées ; il reste un langage non typé, comme BCPL

  • 1971 : création de NB (« new B ») lors du portage de B sur PDP-11

    • types (int, char, tableaux et pointeurs), conversion tableau-vers-pointeur, compilation en code machine

  • 1972 : le langage est renommé C

    • struct, opérateurs && et ||, préprocesseur, entrées-sorties portables

  • 1973 : réécriture d'Unix en C

    • unsigned, long, union, énumérations, sûreté de typage accrue

  • 1978 : The C Programming Language, 1re édition

C standard

  • 1983 : l'ANSI crée le comité X3J11
  • 1988 : The C Programming Language, 2e édition
  • 1989 : publication de C89, la norme ANSI C
  1. codification des pratiques existantes
  2. nouvelles fonctionnalités : volatile, enum, signed, void, locales
  3. Issu du C++ : const, prototypes de fonctions

  • 1990 : C90, la norme ANSI C adoptée sous le nom ISO/IEC 9899:1990

  • 1994 : corrigendum technique 1 (ISO/IEC 9899:1990/Cor.1:1994)

    • 44 petites modifications

  • 1995 : C95 (ISO/IEC 9899:1990/Amd.1:1995) (boutique en ligne)

  1. prise en charge fortement étendue des caractères larges et multioctets (<wctype.h>, <wchar.h>, ajouts et modifications des flux d'entrée-sortie, etc.)
  2. digrammes, <iso646.h>,

  • 1996 : corrigendum technique 2 (ISO/IEC 9899:1990/Cor.2:1996)

    • 24 petites modifications

  • 1999 : C99 (ISO/IEC 9899:1999)

  1. nouvelles fonctionnalités : bool, long long, <stdint.h>, <inttypes.h>, restrict, littéraux composés, tableaux de longueur variable, membres de tableau flexibles, initialisateurs désignés, <fenv.h>, macros variadiques, nombres complexes, __func__, format de nombres à virgule flottante hexadécimal (%a), formatage monétaire dans lconv, isblank, concaténation de littéraux chaînes étroits et larges, virgule finale dans les énumérations, arguments vides dans les macros de type fonction, pragmas STDC_*, va_copy, retour nul de tmpnam, pointeur nul dans setvbuf, spécificateurs de longueur hh et ll dans printf, snprintf, _Exit, <tgmath.h>, spécificateurs strftime de type POSIX
  2. issu du C++ : inline, mélange de déclarations et de code, déclarations dans la clause d'initialisation de la boucle for, commentaires //, noms de caractères universels dans le code source
  3. suppression des fonctions implicites et du int implicite

  • 2001 : corrigendum technique 1 (ISO/IEC 9899:1999/Cor.1:2001)

    • 11 défauts corrigés

  • 2004 : corrigendum technique 2 (ISO/IEC 9899:1999/Cor.2:2004)

  • 2004 : rapport technique Unicode (ISO/IEC TR 19769:2004) (boutique ISO) (N1040, brouillon du 7 novembre 2003)

  • 2007 : corrigendum technique 3 (ISO/IEC 9899:1999/Cor.3:2007) (N1256, brouillon du 7 septembre 2007)

    • obsolète gets

  • 2007 : rapport technique sur les interfaces de vérification des bornes (ISO/IEC TR 24731-1:2007) (boutique ISO) (N1225, brouillon du 28 mars 2007)

  • 2008 : rapport technique sur les systèmes embarqués (ISO/IEC TR 18037:2008) (boutique ISO) (N1021, brouillon du 24 septembre 2003)

  • 2009 : rapport technique sur les nombres à virgule flottante décimale (ISO/IEC TR 24732:2009) (boutique ISO) (N1241, brouillon du 5 juillet 2007)

  • 2009 : rapport technique sur les fonctions mathématiques spéciales (ISO/IEC TR 24747:2009) (boutique ISO) (N1182, brouillon du 2 août 2006)

  • 2010 : rapport technique sur les fonctions d'allocation dynamique (ISO/IEC TR 24731-2:2010) (boutique ISO) (N1388, brouillon du 1er juin 2009)

  • 2011 : C11 (ISO/IEC 9899:2011) (boutique ISO) (boutique ANSI) (N1570, brouillon du 12 avril 2011)

  1. modèle mémoire conscient des threads, <stdatomic.h>, <threads.h>, fonctions à types génériques, alignas/alignof, noreturn, static_assert, extensions d'analysabilité, extensions aux types complexes et imaginaires, structures et unions anonymes, mode d'ouverture de fichier exclusif, quick_exit
  2. supprimé gets
  3. issu du rapport technique sur les interfaces de vérification des bornes : interfaces de vérification des bornes,
  4. issu du rapport technique Unicode : char16_t, char32_t et <uchar.h>

  • 2012 : corrigendum technique 1 (ISO/IEC 9899:2011/Cor 1:2012) (boutique ISO)

    • Corrige DR 411

  • 2013 : spécification TS sur les règles de codage sécurisé (ISO/IEC TS 17961:2013) (boutique ISO) (N1718, 30 mai 2013)

  • 2014 : TS virgule flottante partie 1 : arithmétique en virgule flottante binaire (ISO/IEC TS 18661-1:2014) (boutique ISO) (N1778, brouillon 2013)

  1. apporte à C11 des modifications (principalement à l'annexe F) couvrant toutes les exigences de base et certaines recommandations de la CEI 60559:2011 (C11 était fondé sur la CEI 60559:1989)
  • 2015 : TS virgule flottante partie 2 : arithmétique en virgule flottante décimale (ISO/IEC TS 18661-2:2015) (boutique ISO) (N1912, brouillon 2015)
  1. apporte à C11 des modifications permettant de satisfaire toutes les exigences, ainsi que certaines recommandations de base, de la CEI 60559:2011 pour l'arithmétique en virgule flottante décimale. Elle remplace l'ISO/IEC TR 24732:2009.
  • 2015 : TS virgule flottante partie 3 : types d'échange et types étendus (ISO/IEC TS 18661-3:2015) (boutique ISO) (N1945, brouillon 2015)
  1. apporte à C11 des modifications permettant de satisfaire les recommandations de la CEI 60559:2011 pour les formats étendus à virgule flottante et les formats d'échange, arithmétiques comme non arithmétiques.
  • 2015 : TS virgule flottante partie 4 : fonctions supplémentaires (ISO/IEC TS 18661-4:2015) (boutique ISO) (N1950, brouillon 2015)
  1. apporte à C11 des modifications permettant de prendre en charge toutes les opérations mathématiques recommandées par la CEI 60559:2011, y compris la trigonométrie en unités de π, la racine carrée inverse, les intérêts composés, etc.
  • 2016 : TS virgule flottante partie 5 : attributs supplémentaires (ISO/IEC TS 18661-5:2016) (boutique ISO) (N2004, brouillon 2016)
  1. apporte à C11 des modifications permettant de prendre en charge tous les attributs supplémentaires (modèle d'évaluation, gestion des exceptions, reproductibilité, etc.) recommandés par la CEI 60559:2011
  • 2018 : C17 (ISO/IEC 9899:2018) (boutique ISO) (brouillon final) Article principal : C17
