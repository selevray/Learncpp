boucle do-while

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Exécute une statement de façon répétée jusqu'à ce que la valeur de la condition expression devienne fausse. Le test a lieu après chaque itération.

Syntaxe

| | | | attr-spec-seq(facultatif) do statement while ( expression ) ; | | | |

  • expression — toute expression de type scalaire. Cette expression est évaluée après chaque itération et, si elle est égale à zéro, la boucle se termine.
  • statement — toute instruction, généralement une instruction composée, qui constitue le corps de la boucle
  • attr-spec-seq — (C23) liste facultative d'attributs, appliquée à l'instruction de boucle

Explication

Une instruction do-while fait exécuter le statement (appelé aussi corps de la boucle) de façon répétée jusqu'à ce que l'expression (appelée aussi expression de contrôle) soit égale à 0. La répétition a lieu que le corps de la boucle soit atteint normalement ou par un goto vers le milieu de statement.

L'évaluation de expression a lieu après chaque exécution de statement (que ce dernier soit atteint normalement ou par un goto). Si l'expression de contrôle doit être évaluée avant le corps de la boucle, on peut utiliser la boucle while ou la boucle for.

Si l'exécution de la boucle doit être interrompue à un moment donné, l'instruction break peut être utilisée comme instruction de fin.

Si l'exécution de la boucle doit se poursuivre à la fin du corps de la boucle, l'instruction continue peut être utilisée comme raccourci.

Un programme comportant une boucle infinie a un comportement indéfini si la boucle n'a aucun effet observable (E/S, accès volatile, opération atomique ou de synchronisation) dans aucune partie de son statement ou de son expression. Cela permet aux compilateurs d'optimiser toutes les boucles non observables sans prouver qu'elles se terminent. Les seules exceptions sont les boucles où expression est une expression constante ; do {...} while(true); est toujours une boucle infinie.

Comme pour toutes les autres instructions de sélection et d'itération, l'instruction do-while établit une portée de bloc : tout identifiant introduit dans le expression sort de portée après l'instruction.

(depuis C99)

Notes

Les expressions booléennes et pointeurs sont souvent utilisées comme expressions de contrôle de boucle. La valeur booléenne false et la valeur de pointeur nul de tout type de pointeur sont égales à zéro.

Mots-clés

do, while

Exemple

#include <stdio.h>
#include <stdlib.h>
enum { SIZE = 8 };
int main(void)
{
    // exemple trivial
    int array[SIZE], n = 0;
    do array[n++] = rand() % 2; // le corps de la boucle est une seule instruction d'expression
    while(n < SIZE);
    puts("Array filled!");
    n = 0;
    do { // le corps de la boucle est une instruction composée
        printf("%d ", array[n]);
        ++n;
    } while (n < SIZE);
    printf("\n");

    // la boucle de itoa() de K&R. La boucle do-while est utilisée
    // car il y a toujours au moins un chiffre à générer
    int num = 1234, i=0;
    char s[10];
    do s[i++] = num % 10 + '0'; // obtenir le chiffre suivant dans l'ordre inverse
    while ((num /= 10) > 0);
    s[i] = '\0';
    puts(s);
}
