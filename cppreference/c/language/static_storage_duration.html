Durée de stockage statique

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un objet dont l'identifiant est déclaré sans le spécificateur de classe de stockage _Thread_local, et soit avec une liaison externe ou interne, soit avec le spécificateur de classe de stockage static, a une durée de stockage statique. Sa durée de vie est toute la durée d'exécution du programme et sa valeur stockée n'est initialisée qu'une seule fois, avant le démarrage du programme.

Notes

Comme sa valeur stockée n'est initialisée qu'une seule fois, un objet à durée de stockage statique peut conserver l'historique des appels d'une fonction.

L'autre utilisation du mot-clé static est la portée de fichier.

Exemple

#include <stdio.h>

void f (void)
{
    static int count = 0;   // variable statique
    int i = 0;              // variable automatique
    printf("%d %d\n", i++, count++);
}

int main(void)
{
    for (int ndx=0; ndx<10; ++ndx)
        f();
}
