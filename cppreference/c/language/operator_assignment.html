Opérateurs d'affectation

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les opérateurs d'affectation et d'affectation composée sont des opérateurs binaires qui modifient la variable à leur gauche en utilisant la valeur à leur droite.

Opérateur Nom de l'opérateur Exemple Description Équivalent de
= affectation simple a = b a devient égal à b N/A
+= affectation par addition a += b a devient égal à l'addition de a et de b a = a + b
-= affectation par soustraction a -= b a devient égal à la soustraction de b à a a = a - b
*= affectation par multiplication a *= b a devient égal au produit de a et de b a = a * b
/= affectation par division a /= b a devient égal à la division de a par b a = a / b
%= affectation du modulo a %= b a devient égal au reste de la division de a par b a = a % b
&= affectation par ET binaire a &= b a devient égal au ET binaire de a et de b a = a & b
` =` affectation par OU binaire `a = b`
^= affectation par OU exclusif binaire a ^= b a devient égal au OU exclusif binaire de a et de b a = a ^ b
<<= affectation par décalage binaire à gauche a <<= b a devient égal à a décalé à gauche de b a = a << b
>>= affectation par décalage binaire à droite a >>= b a devient égal à a décalé à droite de b a = a >> b

Affectation simple

Les expressions d'affectation simple ont la forme

| | | | lhs = rhs | | | |

where

  • lhs — lvalue modifiable expression de tout type objet complet
  • rhs — expression de tout type implicitement convertible en lhs ou compatible avec lhs

L'affectation effectue une conversion implicite de la valeur de rhs vers le type de lhs, puis remplace la valeur de l'objet désigné par lhs par la valeur convertie de rhs.

L'affectation renvoie aussi la même valeur que celle stockée dans lhs (ce qui permet des expressions telles que a = b = c). La catégorie de valeur de l'opérateur d'affectation est non-lvalue (ce qui rend invalides des expressions telles que (a=b)=c).

rhs et lhs doivent satisfaire l'une des conditions suivantes :

  • lhs et rhs ont tous deux un type compatible struct ou union, ou..
  • rhs doit être implicitement convertible en lhs, ce qui implique
    • lhs et rhs ont tous deux des types arithmétiques, auquel cas lhs peut être qualifié volatileou atomic (depuis C11)
    • lhs et rhs ont tous deux un pointeur vers des types compatibles (en ignorant les qualificateurs), ou l'un des pointeurs est un pointeur vers void, et la conversion n'ajouterait pas de qualificateurs au type pointé. lhs peut être volatileou restrict (depuis C99), qualifiéou atomic (depuis C11).
    • lhs est un pointeur (éventuellement qualifiéou atomic (depuis C11)) et rhs est une constante de pointeur nul telle que NULL ou une valeur nullptr_t (depuis C23)
  • lhs a le type (éventuellement qualifiéou atomic (depuis C11)) _Bool et rhs est un pointeur ou une valeur nullptr_t (depuis C23)

(depuis C99)

  • lhs a le type (éventuellement qualifié ou atomic) nullptr_t et rhs a le type nullptr_t

(depuis C23)

Notes

Si rhs et lhs se chevauchent en mémoire (par exemple s'ils sont membres de la même union), le comportement est indéfini, sauf si le chevauchement est exact et que les types sont compatibles.

Bien que les tableaux ne soient pas affectables, un tableau encapsulé dans une struct est affectable à un autre objet de même type struct (ou d'un type struct compatible).

L'effet de bord de la mise à jour de lhs est séquencé après les calculs de valeurs, mais pas les effets de bord de lhs et rhs eux-mêmes, et les évaluations des opérandes sont, comme d'habitude, non séquencées les unes par rapport aux autres (donc les expressions telles que i=++i; ont un comportement indéfini)

L'affectation supprime l'intervalle et la précision supplémentaires des expressions en virgule flottante (voir FLT_EVAL_METHOD).

En C++, les opérateurs d'affectation sont des expressions lvalue, ce qui n'est pas le cas en C.

#include <stdio.h>

int main(void)
{
    // integers
    int i = 1, j = 2, k = 3; // initialisation, et non affectation

    i = j = k;   // les valeurs de i et j valent maintenant 3
//  (i = j) = k; // Erreur : lvalue requise
    printf("%d %d %d\n", i, j, k);

    // pointers
    const char c = 'A'; // initialisation ; et non affectation
    const char *p = &c;  // initialisation ; et non affectation
    const char **cpp = &p; // initialisation ; et non affectation

//  cpp = &p;   // Erreur : char** n'est pas convertible en const char**
    *cpp = &c;  // OK, char* est convertible en const char*
    printf("%c \n", **cpp);
    cpp = 0;    // OK, une constante de pointeur nul est convertible en tout pointeur

    // arrays
    int arr1[2] = {1,2}, arr2[2] = {3, 4};
//  arr1 = arr2; // Erreur : impossible d'affecter à un tableau
    printf("arr1[0]=%d arr1[1]=%d arr2[0]=%d arr2[1]=%d\n",
            arr1[0],   arr1[1],   arr2[0],   arr2[1]);

    struct { int arr[2]; } sam1 = { {5, 6} }, sam2 = { {7, 8} };
    sam1 = sam2; // OK : peut affecter des tableaux encapsulés dans des structures

    printf("%d %d \n", sam1.arr[0], sam1.arr[1]);
}

Output:

3 3 3
A
arr1[0]=1 arr1[1]=2 arr2[0]=3 arr2[1]=4
7 8

Affectation composée

Les expressions d'affectation composée ont la forme

| | | | lhs op rhs | | | |

where

  • op — l'une de *=, /= %=, += -=, <<=, >>=, &=, ^=, |=
  • lhs, rhs — expressions avec des types arithmétiques (où lhs peut être qualifié ou atomic), sauf lorsque op vaut += ou -=, qui acceptent aussi des types pointeurs avec les mêmes restrictions que + et -

L'expression lhs @= rhs est exactement la même que lhs = lhs @ ( rhs ), sauf que lhs n'est évalué qu'une seule fois.

Si lhs a un type atomic, l'opération se comporte comme une seule opération atomique de lecture-modification-écriture avec l'ordre mémoire memory_order_seq_cst.

Pour les types atomiques entiers, l'affectation composée @= est équivalente à :

T1* addr = &lhs;
T2 val = rhs;
T1 old = *addr;
T1 new;
do { new = old @ val } while (!atomic_compare_exchange_strong(addr, &old, new);

(depuis C11)

#include <stdio.h>

int main(void)
{
    int x = 10;
    int hundred = 100;
    int ten = 10;
    int fifty = 50;

    printf("%d %d %d %d\n", x, hundred, ten, fifty);

    hundred *= x;
    ten     /= x;
    fifty   %= x;

    printf("%d %d %d %d\n", x, hundred, ten, fifty);

    return 0;
}

Output:

10 100 10 50
10 1000 1 0
