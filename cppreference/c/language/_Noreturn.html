Spécificateur de fonction _Noreturn (depuis C11)(obsolète en C23)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Indique que la fonction ne retourne pas à son point d'appel.

Syntaxe

| | | | _Noreturn function_declaration | | (depuis C11) (obsolète en C23) | |

Explication

Le mot-clé _Noreturn apparaît dans une déclaration de fonction et indique que la fonction ne retourne pas en exécutant l'instruction return ni en atteignant la fin du corps de la fonction (elle peut retourner en exécutant longjmp). Si la fonction déclarée _Noreturn retourne, le comportement est indéfini. Un diagnostic du compilateur est recommandé si cela peut être détecté.

Le spécificateur _Noreturn peut apparaître plusieurs fois dans la même déclaration de fonction ; le comportement est le même que s'il n'apparaissait qu'une fois.

Ce spécificateur est généralement utilisé via la macro de commodité noreturn, fournie dans l'en-tête <stdnoreturn.h>.

Le spécificateur de fonction _Noreturn est obsolète. L'attribut [[noreturn]] doit être utilisé à la place.

La macro noreturn est également obsolète.

(depuis C23)

Mots-clés

_Noreturn

Bibliothèque standard

Les fonctions suivantes sont noreturn dans la bibliothèque standard :

  • abort()
  • exit()
  • _Exit()
  • quick_exit()
  • thrd_exit()
  • longjmp()

Exemple

#include <stdio.h>
#include <stdlib.h>
#include <stdnoreturn.h>

// provoque un comportement indéfini si i <= 0
// quitte si i > 0
noreturn void exit_now(int i) // ou _Noreturn void exit_now(int i)
{
    if (i > 0)
        exit(i);
}

int main(void)
{
    puts("Preparing to exit...");
    exit_now(2);
    puts("This code is never executed.");
}

Output:

Preparing to exit...
