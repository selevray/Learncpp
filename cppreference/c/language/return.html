instruction return

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Termine la fonction courante et renvoie la valeur spécifiée à la fonction appelante.

Syntaxe

| | | | attr-spec-seq(facultatif) return expression ; | (1) | | | | attr-spec-seq(facultatif) return ; | (2) | | |

  • expression — expression utilisée pour initialiser la valeur de retour de la fonction
  • attr-spec-seq — (C23) liste optionnelle d'attributs, appliquée à l'instruction return

Explication

  1. Évalue le expression, termine la fonction courante et renvoie le résultat de l'expression à la fonction appelante (la valeur renvoyée devient la valeur de l'expression d'appel de fonction). Valide uniquement si le type de retour de la fonction n'est pas void.

  2. Termine la fonction courante. Valide uniquement si le type de retour de la fonction est void.

Si le type de l'expression est différent du type de retour de la fonction, sa valeur est convertie comme par affectation vers un objet dont le type est le type de retour de la fonction, sauf que le chevauchement entre représentations d'objets est autorisé :

struct s { double i; } f(void); // fonction renvoyant la structure s
union { struct { int f1; struct s f2; } u1;
        struct { struct s f3; int f4; } u2; } g;
struct s f(void)
{
    return g.u1.f2;
}
int main(void)
{
// g.u2.f3 = g.u1.f2; // comportement indéfini (chevauchement dans l'affectation)
   g.u2.f3 = f();     // bien défini
}

Si le type de retour est un type flottant réel, le résultat peut être représenté avec une plage et une précision plus grandes que celles impliquées par le nouveau type.

Atteindre la fin d'une fonction renvoyant void équivaut à return;. Atteindre la fin de toute autre fonction renvoyant une valeur est un comportement indéfini si le résultat de la fonction est utilisé dans une expression (il est permis d'ignorer une telle valeur de retour). Pour main, voir la fonction main.

Exécuter l'instruction return dans une fonction sans retour est un comportement indéfini.

(depuis C11)

Exemple
Cette section est incomplète Raison : améliorer 
#include <stdio.h>

void fa(int i)
{
    if (i == 2)
       return;
    printf("fa():   %d\n", i);
} // return; implicite

int fb(int i)
{
    if (i > 4)
       return 4;
    printf("fb():   %d\n", i);
    return 2;
}

int main(void)
{
    fa(2);
    fa(1);
    int i = fb(5);   // la valeur de retour 4 sert à initialiser i
    i = fb(i);       // la valeur de retour 2 sert de membre droit de l'affectation
    printf("main(): %d\n", i);
}

Output:

fa():   1
fb():   4
main(): 2
