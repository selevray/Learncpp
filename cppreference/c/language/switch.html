instruction switch

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Exécute du code selon la valeur d'un argument entier.

Utilisée lorsqu'une ou plusieurs branches parmi de nombreuses doivent être exécutées selon une valeur entière.

Syntaxe

| | | | attr-spec-seq(facultatif) switch ( expression ) statement | | | |

  • attr-spec-seq — (C23) liste optionnelle d'attributs, appliquée à l'instruction switch
  • expression — toute expression de type entier (char, entier signé ou non signé, ou énumération)
  • statement — toute instruction (généralement une instruction composée). Les étiquettes case: et default: sont permises dans statement, et l'instruction break; a une signification particulière.

| | | | case constant-expression : statement | (1) | (jusqu'à C23) | | | attr-spec-seq(facultatif) case constant-expression : statement(facultatif) | (1) | (depuis C23) | | | default : statement | (2) | (jusqu'à C23) | | | attr-spec-seq(facultatif) default : statement(facultatif) | (2) | (depuis C23) | |

  • constant-expression — toute expression constante entière
  • attr-spec-seq — (C23) liste facultative d'attributs, appliqués à l'étiquette

Explication

Le corps d'une instruction switch peut comporter un nombre quelconque d'étiquettes case:, tant que les valeurs de toutes les constant-expressions sont uniques (après conversion vers le type promu de expression). Au plus une étiquette default: peut être présente (bien que les instructions switch imbriquées puissent utiliser leurs propres étiquettes default: ou avoir des étiquettes case: dont les constantes sont identiques à celles utilisées dans le switch englobant).

Si expression prend une valeur égale à celle de l'une des constant-expression après conversion vers le type promu de expression, le contrôle est transféré à l'instruction étiquetée par cette constant-expression.

Si expression prend une valeur qui ne correspond à aucune des étiquettes case:, et que l'étiquette default: est présente, le contrôle est transféré à l'instruction étiquetée par l'étiquette default:.

Si expression prend une valeur qui ne correspond à aucune des étiquettes case:, et que l'étiquette default: est absente, aucune partie du corps du switch n'est exécutée.

L'instruction break, lorsqu'elle est rencontrée n'importe où dans statement, quitte l'instruction switch :

switch(1) {
    case 1 : puts("1"); // prints "1",
    case 2 : puts("2"); // affiche alors « 2 » (« fall-through »)
}

switch(1) {
    case 1 : puts("1"); // prints "1"
             break;     // et sort du switch
    case 2 : puts("2");
             break;
}

Comme pour toutes les autres instructions de sélection et d'itération, l'instruction switch établit une portée de bloc : tout identificateur introduit dans expression sort de portée après statement.

Si un VLA ou un autre identificateur de type à modification variable a une étiquette case: ou default: dans sa portée, toute l'instruction switch doit être dans sa portée (autrement dit, un VLA doit être déclaré soit avant tout le switch, soit après la dernière étiquette) :

switch (expr)
{
        int i = 4; // pas un VLA ; OK pour déclarer ici
        f(i); // jamais appelée
//      int a[i]; // erreur : un VLA ne peut pas être déclaré ici
    case 0:
        i = 17;
    default:
        int a[i]; // OK pour déclarer un VLA ici
        printf("%d\n", i); // affiche 17 si expr == 0, affiche une valeur indéterminée sinon
}

(depuis C99)

Mots-clés

switch, case, default

Exemple

#include <stdio.h>

void func(int x)
{
   printf("func(%d): ", x);
   switch(x)
   {
      case 1: printf("case 1, ");
      case 2: printf("case 2, ");
      case 3: printf("case 3.\n"); break;
      case 4: printf("case 4, ");
      case 5:
      case 6: printf("case 5 or case 6, ");
      default: printf("default.\n");
   }
}

int main(void)
{
   for(int i = 1; i < 9; ++i) func(i);
}

Output:

func(1): case 1, case 2, case 3.
func(2): case 2, case 3.
func(3): case 3.
func(4): case 4, case 5 or case 6, default.
func(5): case 5 or case 6, default.
func(6): case 5 or case 6, default.
func(7): default.
func(8): default.
