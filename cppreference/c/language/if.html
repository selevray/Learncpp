instruction if

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Exécute du code de manière conditionnelle.

Utilisée lorsque du code ne doit être exécuté que si une condition est vraie.

Syntaxe

| | | | attr-spec-seq(facultatif) if ( expression ) statement-true | (1) | | | | attr-spec-seq(facultatif) if ( expression ) statement-true else statement-false | (2) | | |

  • attr-spec-seq — (C23) liste optionnelle d'attributs, appliquée à l'instruction if
  • expression — une expression de tout type scalaire
  • statement-true — toute instruction (souvent une instruction composée), exécutée si expression est différent de 0
  • statement-false — toute instruction (souvent une instruction composée), exécutée si expression est égal à 0

Explication

expression doit être une expression de tout type scalaire.

Si expression est différent de l'entier zéro, statement-true est exécutée.

Dans la forme (2), si expression est égal à l'entier zéro, statement_false est exécutée.

Comme pour toutes les autres instructions de sélection et d'itération, l'instruction if entière a sa propre portée de bloc :

enum {a, b};
int different(void)
{
    if (sizeof(enum {b, a}) != sizeof(int))
        return a; // a == 1
    return b; // b == 0 en C89, b == 1 en C99
}

(depuis C99)

Notes

Le else est toujours associé au if le plus proche qui le précède (autrement dit, si statement-true est également une instruction if, alors cette instruction if interne doit elle aussi contenir une partie else) :

int j = 1;
if (i > 1)
   if(j > 2)
       printf("%d > 1 and %d > 2\n", i, j);
    else // ce else fait partie de if(j>2), et non de if(i>1)
       printf("%d > 1 and %d <= 2\n", i, j);

Si statement-true est atteint par un goto, statement-false n'est pas exécutée.

Mots-clés

if, else

Exemple

#include <stdio.h>

int main(void)
{
    int i = 2;
    if (i > 2) {
        printf("first is true\n");
    } else {
        printf("first is false\n");
    }

    i = 3;
    if (i == 3) printf("i == 3\n");

    if (i != 3) printf("i != 3 is true\n");
    else        printf("i != 3 is false\n");
}

Output:

first is false
i == 3
i != 3 is false
