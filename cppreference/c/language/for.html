boucle for

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Exécute une boucle.

Utilisée comme équivalent plus court de la boucle while.

Syntaxe

| | | | attr-spec-seq (depuis C23) (facultatif) for ( init-clause ; cond-expression ; iteration-expression ) loop-statement | | | |

Explication

Se comporte comme suit :

  • init-clause peut être une expression ou une déclaration (depuis C99).
    • Une init-clause, qui est une expression, est évaluée une fois, avant la première évaluation de cond-expression, et son résultat est ignoré.
  • Une init-clause, qui est une déclaration, est dans la portée de tout le corps de la boucle, y compris le reste de init-clause, la totalité de cond-expression, la totalité de iteration-expression et la totalité de loop-statement. Seuls auto et register spécificateurs de classe de stockage sont autorisés pour les variables déclarées dans cette déclaration.

(depuis C99)

  • cond-expression est évaluée avant le corps de la boucle. Si le résultat de l'expression est zéro, l'instruction de boucle est immédiatement quittée.
  • iteration-expression est évaluée après le corps de la boucle et son résultat est ignoré. Après l'évaluation de iteration-expression, le contrôle est transféré à cond-expression.

init-clause, cond-expression et iteration-expression sont tous facultatifs. Si cond-expression est omise, elle est remplacée par une constante entière non nulle, ce qui rend la boucle infinie :

for(;;) {
   printf("endless loop!");
}

loop-statement n'est pas facultative, mais elle peut être une instruction nulle :

for(int n = 0; n < 10; ++n, printf("%d\n", n))
    ; // instruction nulle

Si l'exécution de la boucle doit être interrompue à un moment donné, une instruction break peut être utilisée n'importe où dans loop-statement.

L'instruction continue utilisée n'importe où dans loop-statement transfère le contrôle à iteration-expression.

Un programme avec une boucle infinie a un comportement indéfini si la boucle n'a aucun comportement observable (E/S, accès volatile, opération atomique ou de synchronisation) dans aucune partie de cond-expression, iteration-expression ou loop-statement. Cela permet aux compilateurs d'optimiser toutes les boucles non observables sans prouver qu'elles se terminent. Les seules exceptions sont les boucles où cond-expression est omise ou est une expression constante ; for(;;) est toujours une boucle infinie.

Comme pour toutes les autres instructions de sélection et d'itération, l'instruction for établit une portée de bloc : tout identifiant introduit dans init-clause, cond-expression ou iteration-expression sort de portée après loop-statement.

(depuis C99)

attr-spec-seq est une liste facultative d'attributs, appliquée à l'instruction for.

(depuis C23)

Mots-clés

for

Notes

L'instruction d'expression utilisée comme loop-statement établit sa propre portée de bloc, distincte de la portée de init-clause, contrairement au C++ :

for (int i = 0; ; ) {
    long i = 1;   // valide en C, invalide en C++
    // ...
}

Il est possible d'entrer dans le corps d'une boucle à l'aide de goto. Lorsqu'on entre dans une boucle de cette manière, init-clause et cond-expression ne sont pas exécutées. (Si le contrôle atteint ensuite la fin du corps de la boucle, la répétition peut avoir lieu, y compris l'exécution de cond-expression.)

Exemple

#include <stdio.h>
#include <stdlib.h>
enum { SIZE = 8 };
int main(void)
{
    int array[SIZE];
    for(size_t i = 0 ; i < SIZE; ++i)
        array [i] = rand() % 2;
    printf("Array filled!\n");
    for (size_t i = 0; i < SIZE; ++i)
        printf("%d ", array[i]);
    putchar('\n');
}
