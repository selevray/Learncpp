Déclarations de fonctions

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Une déclaration de fonction introduit un identifiant qui désigne une fonction et, optionnellement, spécifie les types des paramètres de la fonction (le prototype). Les déclarations de fonctions (contrairement aux définitions) peuvent apparaître aussi bien en portée de bloc qu'en portée de fichier.

Syntaxe

Dans la grammaire des déclarations d'une déclaration de fonction, la séquence type-specifier, éventuellement modifiée par le déclarateur, désigne le type de retour (qui peut être n'importe quel type sauf un type tableau ou fonction), et le declarator prend l'une de trois formes :

| | | | noptr-declarator ( parameter-list ) attr-spec-seq(facultatif) | (1) | | | | noptr-declarator ( identifier-list ) attr-spec-seq(facultatif) | (2) | (jusqu'à C23) | | | noptr-declarator ( ) attr-spec-seq(facultatif) | (3) | | |

where

  • noptr-declarator — tout déclarateur sauf un déclarateur de pointeur non parenthésé. L'identificateur contenu dans ce déclarateur est celui qui devient le désignateur de fonction.
  • parameter-list — soit le mot-clé unique void, soit une liste de paramètres séparés par des virgules, pouvant se terminer par un paramètre d'ellipse
  • identifier-list — liste d'identificateurs séparés par des virgules, possible uniquement si ce déclarateur est utilisé dans le cadre d'une définition de fonction à l'ancien style
  • attr-spec-seq — (C23) une liste facultative d'attributs, appliqués au type de fonction
  1. Déclaration de fonction au nouveau style (C89). Cette déclaration introduit à la fois le désignateur de fonction lui-même et sert également de prototype de fonction pour toutes les expressions d'appel de fonction futures, forçant les conversions des expressions d'arguments vers les types de paramètres déclarés et les vérifications à la compilation du nombre d'arguments.
int max(int a, int b); // declaration
int n = max(12.01, 3.14); // OK, conversion de double vers int
  1. (jusqu'à C23) Définition de fonction à l'ancien style (K&R). Cette déclaration n'introduit pas de prototype et toutes les expressions d'appel de fonction futures effectueront des promotions d'arguments par défaut et invoqueront un comportement indéfini si le nombre d'arguments ne correspond pas au nombre de paramètres.
int max(a, b)
    int a, b; // la définition attend des int ; le second appel est un comportement indéfini
{
    return a > b ? a : b;
}

int n = max(true, (char)'a'); // appelle max avec deux arguments int (après promotions)

int n = max(12.01f, 3.14); // appelle max avec deux arguments double (après promotions)
  1. Déclaration de fonction sans prototype. Cette déclaration n'introduit pas de prototype (jusqu'à C23). Une déclaration de fonction au nouveau style équivalente à parameter-list void (depuis C23).

Explication

Le type de retour de la fonction, déterminé par le spécificateur de type dans specifiers-and-qualifiers et éventuellement modifié par declarator comme d'habitude dans les déclarations, doit être un type objet non tableau ou le type void. Si la déclaration de fonction n'est pas une définition, le type de retour peut être incomplet. Le type de retour ne peut pas être qualifié cvr : tout type de retour qualifié est ramené à sa version non qualifiée pour la construction du type de fonction.

void f(char *s);                    // le type de retour est void
int sum(int a, int b);              // le type de retour de sum est int.
int (*foo(const void *p))[3];       // le type de retour est un pointeur vers un tableau de 3 int

double const bar(void);             // déclare une fonction de type double(void)
double (*barp)(void) = bar;         // OK : barp est un pointeur vers double(void)
double const (*barpc)(void) = barp; // OK : barpc est également un pointeur vers double(void)

Les déclarateurs de fonction peuvent être combinés avec d'autres déclarateurs tant qu'ils peuvent partager leurs spécificateurs de type et leurs qualificateurs

int f(void), *fip(), (*pfi)(), *ap[3]; // déclare deux fonctions et deux objets
inline int g(int), n; // Error: le qualificateur inline ne concerne que les fonctions
typedef int array_t[3];
array_t a, h(); // Error: un type tableau ne peut pas être un type de retour pour une fonction

Si une déclaration de fonction apparaît en dehors de toute fonction, l'identificateur qu'elle introduit a une portée de fichier et une liaison externe, sauf si static est utilisé ou qu'une déclaration static antérieure est visible. Si la déclaration se trouve à l'intérieur d'une autre fonction, l'identificateur a une portée de bloc (et aussi une liaison interne ou externe).

int main(void)
{
    int f(int); // liaison externe, portée de bloc
    f(1); // la définition doit être disponible quelque part dans le programme
}

Les paramètres d'une déclarationqui ne fait pas partie d'une définition de fonction (jusqu'à C23) n'ont pas besoin d'être nommés :

int f(int, int); // declaration
// int f(int, int) { return 7; } // Error : les paramètres doivent être nommés dans les définitions
// Cette définition est autorisée depuis C23

Chaque paramètre d'une parameter-list est une déclaration qui introduit une seule variable, avec les propriétés supplémentaires suivantes :

  • l'identificateur du déclarateur est facultatif (sauf si cette déclaration de fonction fait partie d'une définition de fonction) (jusqu'à C23)
int f(int, double); // OK
int g(int a, double b); // aussi OK
// int f(int, double) { return 1; } // Error : la définition doit nommer les paramètres
// Cette définition est autorisée depuis C23
  • le seul spécificateur de classe de stockage autorisé pour les paramètres est register, et il est ignoré dans les déclarations de fonction qui ne sont pas des définitions
int f(static int x); // Erreur
int f(int [static 10]); // OK (static dans l'indice de tableau n'est pas un spécificateur de classe de stockage)
  • tout paramètre de type tableau est ramené au type pointeur correspondant, qui peut être qualifié s'il y a des qualificateurs entre les crochets du déclarateur de tableau (depuis C99)
int f(int[]); // déclare int f(int*)
int g(const int[10]); // déclare int g(const int*)
int h(int[const volatile]); // déclare int h(int * const volatile)
int x(int[*]); // déclare int x(int*)
  • tout paramètre de type fonction est ramené au type pointeur correspondant
int f(char g(double)); // déclare int f(char (*g)(double))
int h(int(void)); // déclare int h(int (*)(void))
  • la liste de paramètres peut se terminer par , ... ou être ... (depuis C23), voir fonctions variadiques pour plus de détails.
int f(int, ...);
  • les paramètres ne peuvent pas avoir le type void (mais peuvent avoir le type pointeur vers void). La liste de paramètres spéciale constituée uniquement du mot-clé void sert à déclarer des fonctions qui ne prennent aucun paramètre.
int f(void); // OK
int g(void x); // Erreur
  • tout identificateur apparaissant dans une liste de paramètres qui pourrait être traité comme un nom de typedef ou comme un nom de paramètre est traité comme un nom de typedef : int f(size_t, uintptr_t) est analysé comme un déclarateur de fonction au nouveau style prenant deux paramètres sans nom de types size_t et uintptr_t, et non comme un déclarateur à l'ancien style qui commence la définition d'une fonction prenant deux paramètres nommés « size_t » et « uintptr_t »
  • les paramètres peuvent avoir un type incompletet peuvent utiliser la notation VLA [*] (depuis C99) (sauf que dans une définition de fonction, les types de paramètres après ajustement tableau-vers-pointeur et fonction-vers-pointeur doivent être complets)

Les séquences de spécificateurs d'attributs peuvent aussi être appliquées aux paramètres de fonction.

(depuis C23)

Voir opérateur d'appel de fonction pour d'autres détails sur le mécanisme d'un appel de fonction et return pour le retour depuis une fonction.

Notes

Contrairement au C++, les déclarateurs f() et f(void) ont des significations différentes : le déclarateur f(void) est un déclarateur au nouveau style (à prototype) qui déclare une fonction ne prenant aucun paramètre. Le déclarateur f() est un déclarateur qui déclare une fonction prenant un nombre non spécifié de paramètres (sauf s'il est utilisé dans une définition de fonction)

int f(void); // déclaration : ne prend aucun paramètre
int g(); // déclaration : prend un nombre de paramètres inconnu

int main(void) {
    f(1); // erreur à la compilation
    g(2); // comportement indéfini
}

int f(void) { return 1; } // définition réelle
int g(a,b,c,d) int a,b,c,d; { return 2; } // définition réelle

(jusqu'à C23)

Contrairement à une définition de fonction, la liste de paramètres peut être héritée d'un typedef

typedef int p(int q, int r); // p est un type fonction int(int, int)
p f; // déclare int f(int, int)

En C89, specifiers-and-qualifiers était facultatif, et s'il était omis, le type de retour de la fonction valait par défaut int (éventuellement modifié par declarator).

*f() { // fonction renvoyant int*
   return NULL;
}

(jusqu'à C99)
