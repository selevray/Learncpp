Fonction principale

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Tout programme C conçu pour s'exécuter dans un environnement d'exécution hébergé contient la définition (et non le prototype) d'une fonction nommée main, qui constitue le point d'entrée désigné du programme.

| | | | int main (void) { body } | (1) | | | | int main (int argc, char *argv[]) { body } | (2) | | | | /* une autre signature définie par l'implémentation */ (depuis C99) | (3) | | |

Paramètres

  • argc — Valeur non négative représentant le nombre d'arguments passés au programme depuis l'environnement dans lequel le programme est exécuté.
  • argv — Pointeur vers le premier élément d'un tableau de pointeurs argc + 1, dont le dernier est un pointeur nul et dont les précédents, s'il y en a, pointent vers des chaînes représentant les arguments passés au programme par l'environnement hôte. Si argv[0] n'est pas un pointeur nul (ou, de manière équivalente, si argc > 0), il pointe vers une chaîne représentant le nom du programme, laquelle est vide si ce nom n'est pas disponible depuis l'environnement hôte.

Les noms argc et argv signifient « argument count » et « argument vector » ; ils sont traditionnellement utilisés, mais d'autres noms peuvent être choisis pour les paramètres, ainsi que des déclarations différentes mais équivalentes de leur type : int main(int ac, char** av) est tout aussi valide.

Une forme courante de main définie par l'implémentation est int main(int argc, char *argv[], char *envp[]), où un troisième argument, de type char**, pointant vers un tableau de pointeurs vers les variables d'environnement d'exécution, est ajouté.

Valeur de retour

Si l'instruction return est utilisée, la valeur de retour sert d'argument à l'appel implicite de exit() (voir plus bas pour les détails). Les valeurs zéro et EXIT_SUCCESS indiquent une fin réussie, la valeur EXIT_FAILURE indique une fin échouée.

Explication

La fonction main est appelée au démarrage du programme, après l'initialisation de tous les objets à durée de stockage statique. C'est le point d'entrée désigné d'un programme exécuté dans un environnement hébergé (c'est-à-dire disposant d'un système d'exploitation). Le nom et le type du point d'entrée de tout programme autonome (chargeurs de démarrage, noyaux de systèmes d'exploitation, etc.) sont définis par l'implémentation.

Les paramètres de la forme à deux paramètres de la fonction main permettent de transmettre depuis l'environnement d'exécution des chaînes de caractères multi-octets quelconques (on parle généralement de arguments de la ligne de commande). Les pointeurs argv[1] .. argv[argc-1] pointent vers les premiers caractères de chacune de ces chaînes. argv[0] (s'il n'est pas nul) est le pointeur vers le premier caractère d'une chaîne multi-octets terminée par un caractère nul représentant le nom utilisé pour invoquer le programme lui-même (ou, si l'environnement hôte ne le prend pas en charge, argv[0][0] vaut alors zéro par garantie).

Si l'environnement hôte ne peut fournir à la fois des lettres minuscules et majuscules, les arguments de la ligne de commande sont convertis en minuscules.

Les chaînes sont modifiables, et toute modification effectuée persiste jusqu'à la fin du programme, bien que ces modifications ne se propagent pas à l'environnement hôte : elles peuvent être utilisées, par exemple, avec strtok.

La taille du tableau pointé par argv est au moins argc+1, et le dernier élément, argv[argc], est garanti être un pointeur nul.

La fonction main possède plusieurs propriétés particulières :

  1. Un prototype de cette fonction ne peut pas être fourni par le programme.

  2. Si le type de retour de la fonction main est compatible avec int, alors le retour de l'appel initial à main (mais pas le retour de tout appel ultérieur, récursif) est équivalent à l'exécution de la fonction exit, avec la valeur retournée par main passée en argument (laquelle appelle ensuite les fonctions enregistrées avec atexit, vide et ferme tous les flux, supprime les fichiers créés avec tmpfile, et rend le contrôle à l'environnement d'exécution).

Si la fonction main exécute un return ne spécifiant aucune valeur ou, ce qui revient au même, atteint le } final sans exécuter de return, le statut de fin renvoyé à l'environnement hôte est indéfini.

(jusqu'à C99)

Si le type de retour de la fonction main n'est pas compatible avec int (par exemple void main(void)), la valeur renvoyée à l'environnement hôte est non spécifiée. Si le type de retour est compatible avec int et que le contrôle atteint le } final, la valeur renvoyée à l'environnement est la même que celle obtenue en exécutant return 0;.

(depuis C99)

Exemple

Démontre comment informer un programme de l'endroit où trouver ses données d'entrée et où écrire ses résultats. Invocation : ./a.out indatafile outdatafile

#include <stdio.h>

int main(int argc, char *argv[])
{
    printf("argc = %d\n", argc);
    for (int ndx = 0; ndx != argc; ++ndx)
        printf("argv[%d] --> %s\n", ndx, argv[ndx]);
    printf("argv[argc] = %p\n", (void*)argv[argc]);
}

Sortie possible :

argc = 3
argv[0] --> ./a.out
argv[1] --> indatafile
argv[2] --> outdatafile
argv[argc] = (nil)
