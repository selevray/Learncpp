Instructions

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les instructions sont des fragments du programme C exécutés en séquence. Le corps de toute fonction est une instruction composée, qui est à son tour une séquence d'instructions et de déclarations :

int main(void)
{ // début d'une instruction composée
    int n = 1; // déclaration (non une instruction)
    n = n+1; // instruction d'expression
    printf("n = %d\n", n); // instruction d'expression
    return 0; // instruction return
} // fin de l'instruction composée, fin du corps de la fonction

Il existe cinq types d'instructions :

  1. instructions composées

  2. instructions d'expression

  3. instructions de sélection

  4. instructions d'itération

  5. instructions de saut

Une séquence de spécificateurs d'attributs (attr-spec-seq) peut être appliquée à une instruction sans étiquette, auquel cas (sauf pour une instruction d'expression) les attributs sont appliqués à l'instruction correspondante.

(depuis C23)

Étiquettes

Toute instruction peut être étiquetée, en fournissant un nom suivi d'un deux-points avant l'instruction elle-même.

| | | | attr-spec-seq(optionnel) (depuis C23) identifier : | (1) | | | | attr-spec-seq(optionnel) (depuis C23) case constant-expression : | (2) | | | | attr-spec-seq(optionnel) (depuis C23) default : | (3) | | |

  1. Cible de goto.

  2. Étiquette de cas dans une instruction switch.

  3. Étiquette default dans une instruction switch.

Toute instruction (mais pas une déclaration) peut être précédée d'un nombre quelconque d'étiquettes, chacune déclarant identifier comme nom d'étiquette, qui doit être unique dans la fonction englobante (autrement dit, les noms d'étiquettes ont une portée de fonction).

La déclaration d'une étiquette n'a aucun effet en soi, ne modifie pas le flux de contrôle et ne modifie en rien le comportement de l'instruction qui suit.

Une étiquette doit être suivie d'une instruction.

(jusqu'à C23)

Une étiquette peut apparaître sans l'instruction qui la suit. Si une étiquette apparaît seule dans un bloc, elle se comporte comme si elle était suivie d'une instruction nulle.

Le attr-spec-seq optionnel est appliqué à l'étiquette.

(depuis C23)

Instructions composées

Une instruction composée, ou bloc, est une suite d'instructions et de déclarations entourée d'accolades.

| | | | { statement | declaration...(facultatif) } | | (jusqu'à C23) | | | attr-spec-seq(optionnel) { unlabeled-statement | label | declaration...(optionnel) } | | (depuis C23) | |

L'instruction composée permet de regrouper un ensemble de déclarations et d'instructions en une unité pouvant être utilisée partout où une instruction unique est attendue (par exemple, dans une instruction if ou une instruction d'itération) :

if (expr) // début de l'instruction if
{ // début du bloc
  int n = 1; // declaration
  printf("%d\n", n); // instruction d'expression
} // fin du bloc, fin de l'instruction if

Chaque instruction composée introduit sa propre portée de bloc.

Les initialiseurs des variables à durée de stockage automatique déclarées dans un bloc, ainsi que les déclarateurs VLA, sont exécutés lorsque le flux de contrôle passe sur ces déclarations dans l'ordre, comme s'il s'agissait d'instructions :

int main(void)
{ // début du bloc
  { // début du bloc
       puts("hello"); // instruction d'expression
       int n = printf("abc\n"); // déclaration, affiche "abc", stocke 4 dans n
       int a[n*printf("1\n")]; // déclaration, affiche "1", alloue 8*sizeof(int)
       printf("%zu\n", sizeof(a)); // instruction d'expression
  } // fin du bloc, la portée de n et a se termine
  int n = 7; // n peut être réutilisée
}

Instructions d'expression

Une expression suivie d'un point-virgule est une instruction.

| | | | expression(optionnel) ; | (1) | | | | attr-spec-seq expression ; | (2) | (depuis C23) | |

La plupart des instructions d'un programme C typique sont des instructions d'expression, comme des affectations ou des appels de fonction.

Une instruction d'expression sans expression est appelée instruction nulle. Elle sert souvent à fournir un corps vide à une boucle for ou while. Elle peut aussi servir à porter une étiquette à la fin d'une instruction composée ou avant une déclaration :

puts("hello"); // instruction d'expression
char *s;
while (*s++ != '\0')
    ; // instruction nulle

Le attr-spec-seq optionnel est appliqué à l'expression.

Un attr-spec-seq suivi de ; ne forme pas une instruction d'expression. Il forme à la place une déclaration d'attribut.

(depuis C23)

Instructions de sélection

Les instructions de sélection choisissent parmi plusieurs instructions en fonction de la valeur d'une expression.

| | | | attr-spec-seq(optionnel) (depuis C23) if ( expression ) statement | (1) | | | | attr-spec-seq(optionnel) (depuis C23) if ( expression ) statement else statement | (2) | | | | attr-spec-seq(optionnel) (depuis C23) switch ( expression ) statement | (3) | | |

  1. instruction if

instruction if avec une clause else 2)

  1. instruction switch

Instructions d'itération

Les instructions d'itération exécutent répétitivement une instruction.

| | | | attr-spec-seq(optionnel) (depuis C23) while ( expression ) statement | (1) | | | | attr-spec-seq(optionnel) (depuis C23) do statement while ( expression ) ; | (2) | | | | attr-spec-seq(optionnel) (depuis C23) for ( init-clause ; expression(optionnel) ; expression(optionnel) ) statement | (3) | | |

  1. boucle while

  2. boucle do-while

  3. boucle for

Instructions de saut

Les instructions de saut transfèrent inconditionnellement le flux de contrôle.

| | | | attr-spec-seq(optionnel) (depuis C23) break ; | (1) | | | | attr-spec-seq(optionnel) (depuis C23) continue ; | (2) | | | | attr-spec-seq(optionnel) (depuis C23) return expression(optionnel) ; | (3) | | | | attr-spec-seq(optionnel) (depuis C23) goto identifier ; | (4) | | |

  1. instruction break

  2. instruction continue

  3. instruction return avec une expression optionnelle

  4. instruction goto
