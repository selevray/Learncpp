Durée de stockage thread

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un objet dont l'identificateur est déclaré avec le spécificateur de classe de stockage _Thread_local (depuis C11) a une durée de stockage thread. Sa durée de vie est l'exécution complète du thread pour lequel il est créé, et sa valeur stockée est initialisée au démarrage du thread. Il existe un objet distinct par thread, et l'utilisation du nom déclaré dans une expression désigne l'objet associé au thread qui évalue l'expression. Le résultat d'une tentative d'accès indirect à un objet à durée de stockage thread depuis un thread autre que celui auquel l'objet est associé est défini par l'implémentation.

Exemple

const double PI = 3.14159;         /* la variable const est globale à tous les threads  */
_Thread_local unsigned int seed;   /* seed est une variable propre à chaque thread       */

int main(void)
{
    return 0;
}
