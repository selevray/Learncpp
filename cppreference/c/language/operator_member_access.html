Opérateurs d'accès aux membres

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les opérateurs d'accès aux membres permettent d'accéder aux membres de leurs opérandes.

Opérateur Nom de l'opérateur Exemple Description
[] indexation de tableau a[b] accéder au bème élément du tableau a
* déréférencement de pointeur *a déréférencer le pointeur a pour accéder à l'objet ou à la fonction auquel il fait référence
& adresse de &a créer un pointeur qui fait référence à l'objet ou à la fonction a
. accès à un membre a.b accéder au membre b de la struct ou de l'union a
-> accès à un membre via un pointeur a->b accéder au membre b de la struct ou de l'union pointée par a

Indexation

L'expression d'indexation de tableau a la forme

| | | | pointer-expression [ integer-expression ] | (1) | | | | integer-expression [ pointer-expression ] | (2) | | |

where

  • pointer-expression — une expression de type pointeur vers un objet complet
  • integer-expression — une expression de type entier

L'expression d'indexation est une expression lvalue dont le type est celui de l'objet pointé par pointer-expression.

Par définition, l'opérateur d'indexation E1[E2] est exactement identique à *((E1)+(E2)). Si pointer-expression est une expression de tableau, elle subit une conversion lvalue-to-rvalue et devient un pointeur vers le premier élément du tableau.

En raison de la définition de l'addition entre un pointeur et un entier, le résultat est l'élément du tableau dont l'indice est égal au résultat de integer-expression (ou, si pointer-expression pointait sur le i-ème élément d'un tableau, l'indice du résultat est i plus le résultat de integer-expression)

Note : voir tableau pour les détails sur les tableaux multidimensionnels.

#include <stdio.h>
int main(void)
{
    int a[3] = {1,2,3};
    printf("%d %d\n", a[2],  // n == 3
                      2[a]); // identique, n == 3
    a[2] = 7; // les indices sont des lvalues

    int n[2][3] = {{1,2,3},{4,5,6}};
    int (*p)[3] = &n[1]; // les éléments de n sont des tableaux
    printf("%d %d %d\n", (*p)[0], p[0][1], p[0][2]); // accès à n[1][] via p
    int x = n[1][2]; // application de [] à nouveau au tableau n[1]
    printf("%d\n", x);

    printf("%c %c\n", "abc"[2], 2["abc"]); // les littéraux de chaîne sont aussi des tableaux
}

Output:

3 3
4 5 6
6
c c

Déréférencement

L'expression déréférencement ou indirection a la forme

| | | | * pointer-expression | | | |

where

  • pointer-expression — une expression de tout type pointeur

Si pointer-expression est un pointeur vers fonction, le résultat de l'opérateur de déréférencement est un désignateur de fonction pour cette fonction.

Si pointer-expression est un pointeur vers objet, le résultat est une expression lvalue désignant l'objet pointé.

Déréférencer un pointeur nul, un pointeur vers un objet hors de sa durée de vie (pointeur pendant), un pointeur mal aligné ou un pointeur à valeur indéterminée est un comportement indéfini, sauf lorsque l'opérateur de déréférencement est annulé en appliquant l'opérateur d'adresse à son résultat, comme dans &*E.

#include <stdio.h>
int main(void)
{
    int n = 1;
    int* p = &n;
    printf("*p = %d\n", *p); // la valeur de *p est ce qui est stocké dans n
    *p = 7; // *p est une lvalue
    printf("*p = %d\n", *p);
}

Output:

*p = 1
*p = 7

Adresse de

L'expression d'adresse a la forme

| | | | & function | (1) | | | | & lvalue-expression | (2) | | | | & * expression | (3) | | | | & expression [ expression ] | (4) | | |

  1. adresse d'une fonction

  2. adresse d'un objet

  3. cas particulier : & et * s'annulent mutuellement, aucun des deux n'est évalué

  4. cas particulier : & et le * implicite dans [] s'annulent mutuellement, seule l'addition implicite dans [] est évaluée.

where

  • lvalue-expression — une expression lvalue de tout type qui n'est pas un champ de bits et n'a pas la classe de stockage register

L'opérateur d'adresse produit l'adresse non-lvalue de son opérande, adaptée à l'initialisation d'un pointeur vers le type de l'opérande. Si l'opérande est un désignateur de fonction (1), le résultat est un pointeur vers fonction. Si l'opérande est un objet (2), le résultat est un pointeur vers objet.

Si l'opérande est l'opérateur de déréférencement, aucune action n'est effectuée (il est donc permis d'appliquer &* à un pointeur nul), sauf que le résultat n'est pas une lvalue.

Si l'opérande est une expression d'indice de tableau, aucune action n'est effectuée autre que la conversion tableau-en-pointeur et l'addition, donc &a[N] est valide pour un tableau de taille N (obtenir un pointeur juste après la fin est permis, le déréférencer ne l'est pas, mais le déréférencement s'annule dans cette expression).

int f(char c) { return c;}
int main(void)
{
   int n = 1;
   int *p = &n; // adresse de l'objet n
   int (*fp)(char) = &f; // adresse de la fonction f
   int a[3] = {1,2,3};
   int *beg=a, *end=&a[3]; // identique à end = a+3
}

Accès aux membres

L'expression d'accès à un membre a la forme

| | | | expression . member-name | | | |

where

  • expression — une expression de type struct ou union
  • member-name — un identifiant qui désigne un membre de la struct ou union désignée par expression

L'expression d'accès à un membre désigne le membre nommé de la struct ou union désignée par son opérande gauche. Elle a la même catégorie de valeur que son opérande gauche.

Si l'opérande gauche est qualifié const ou volatile, le résultat est aussi qualifié. Si l'opérande gauche est atomic, le comportement est indéfini.

Remarque : outre les identifiants désignant des objets de type struct ou union, les expressions suivantes peuvent avoir un type struct ou union : affectation, appel de fonction, opérateur virgule, opérateur conditionnel et littéral composé.

#include <stdio.h>
struct s {int x;};
struct s f(void) { return (struct s){1}; }
int main(void)
{
    struct s s;
    s.x = 1; // ok, modifie le membre de s
    int n = f().x; // f() est une expression de type struct s
//  f().x = 1; // Erreur : cette expression d'accès au membre n'est pas une lvalue

    const struct s sc;
//  sc.x = 3;  // Erreur : sc.x est const, ne peut pas être affecté

    union { int x; double d; } u = {1};
    u.d = 0.1; // modifie le membre actif de l'union
}

Accès à un membre via un pointeur

L'expression d'accès à un membre a la forme

| | | | expression -> member-name | | | |

where

  • expression — une expression de type pointeur vers struct ou union
  • member-name — un identifiant qui désigne un membre de la struct ou union pointée par expression

L'expression d'accès à un membre via un pointeur désigne le membre nommé du type struct ou union pointé par son opérande gauche. Sa catégorie de valeur est toujours lvalue

Si le type pointé par l'opérande gauche est qualifié const ou volatile, le résultat est aussi qualifié. Si le type pointé par l'opérande gauche est atomic, le comportement est indéfini.

#include <stdio.h>
struct s {int x;};
int main(void)
{
    struct s s={1}, *p = &s;
    p->x = 7; // modifie la valeur de s.x via le pointeur
    printf("%d\n", p->x); // prints 7
}
