opérateur sizeof

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Interroge la taille de l'objet ou du type.

Utilisé lorsque la taille réelle de l'objet doit être connue.

Syntaxe

| | | | sizeof( type ) | (1) | | | | sizeof expression | (2) | | |

Les deux versions renvoient une valeur de type size_t.

Explication

  1. Renvoie la taille, en octets, de la représentation objet de type

  2. Renvoie la taille, en octets, de la représentation objet du type de expression. Aucune conversion implicite n'est appliquée à expression.

Notes

Selon l'architecture de l'ordinateur, un octet peut être composé de 8 bits ou plus, le nombre exact étant fourni par CHAR_BIT.

sizeof(char), sizeof(signed char) et sizeof(unsigned char) renvoient toujours 1.

sizeof ne peut pas être utilisé avec des types fonction, des types incomplets (y compris void), ou des lvalues de champ de bits.

Lorsqu'il est appliqué à un opérande de type structure ou union, le résultat est le nombre total d'octets d'un tel objet, y compris le bourrage interne et final. Le bourrage final est tel que, si l'objet était un élément d'un tableau, l'exigence d'alignement de l'élément suivant de ce tableau serait satisfaite ; autrement dit, sizeof(T) renvoie la taille d'un élément d'un tableau de T[].

Si type est un type VLA et que modifier la valeur de son expression de taille n'affecterait pas le résultat de sizeof, il est non spécifié que l'expression de taille soit évaluée ou non.

(depuis C99)

Sauf si le type de expression est un VLA, (depuis C99)expression n'est pas évalué et l'opérateur sizeof peut être utilisé dans une expression constante entière.

Si le type de expression est un type tableau de longueur variable, expression est évalué et la taille du tableau qui en résulte est calculée à l'exécution.

(depuis C99)

Le nombre d'éléments de tout tableau a y compris VLA (depuis C99) peut être déterminé avec l'expression sizeof a / sizeof a[0]. Notez que si a a un type pointeur (par exemple après la conversion tableau-vers-pointeur ou l'ajustement du type de paramètre de fonction), cette expression divise simplement le nombre d'octets du type pointeur par le nombre d'octets du type pointé.

Mots-clés

sizeof

Exemple

L'exemple de sortie correspond à une plateforme avec des pointeurs 64 bits et des int 32 bits

#include <stdio.h>

int main(void)
{
    short x;
    // argument de type :
    printf("sizeof(float)          = %zu\n", sizeof(float));
    printf("sizeof(void(*)(void))  = %zu\n", sizeof(void(*)(void)));
    printf("sizeof(char[10])       = %zu\n", sizeof(char[10]));
//  printf("sizeof(void(void))     = %zu\n", sizeof(void(void))); // Erreur : type fonction
//  printf("sizeof(char[])         = %zu\n", sizeof(char[])); // Erreur : type incomplet

    // argument d'expression :
    printf("sizeof 'a'             = %zu\n", sizeof 'a'); // le type de 'a' est int
//  printf("sizeof main            = %zu\n", sizeof main); // Erreur : type fonction
    printf("sizeof &main           = %zu\n", sizeof &main);
    printf("sizeof \"hello\"         = %zu\n", sizeof "hello"); // le type est char[6]
    printf("sizeof x               = %zu\n", sizeof x); // le type de x est short
    printf("sizeof (x+1)           = %zu\n", sizeof(x + 1)); // le type de x+1 est int
}

Sortie possible :

sizeof(float)          = 4
sizeof(void(*)(void))  = 8
sizeof(char[10])       = 10
sizeof 'a'             = 4
sizeof &main           = 8
sizeof "hello"         = 6
sizeof x               = 2
sizeof (x+1)           = 4
