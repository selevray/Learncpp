_Alignas (depuis C11)(obsolète en C23), alignas (depuis C23)

Apparaît dans la syntaxe de la déclaration comme l'un des spécificateurs de type permettant de modifier l'exigence d'alignement de l'objet déclaré.

Syntaxe

| | | | _Alignas ( expression ) | (1) | (depuis C11) | | | alignas ( expression ) | (2) | (depuis C23) | | | _Alignas ( type ) | (3) | (depuis C11) | | | alignas ( type ) | (4) | (depuis C23) | |

  • expression — toute expression constante entière dont la valeur est un alignement valide ou zéro
  • type — tout nom de type

Le mot-clé _Alignas est aussi disponible sous forme de macro pratique alignas, disponible dans l'en-tête <stdalign.h>.

(jusqu'à C23)

Explication

Le spécificateur [_Alignas (jusqu'à C23) | alignas (depuis C23)] ne peut être utilisé que lors de la déclaration d'objets qui ne sont pas des champs de bits et qui n'ont pas la classe de stockage register. Il ne peut pas être utilisé dans les déclarations de paramètres de fonction, ni dans un typedef.

Lorsqu'il est utilisé dans une déclaration, l'objet déclaré aura son exigence d'alignement fixée à

1,2) le résultat de expression, sauf s'il est nul

3,4) l'exigence d'alignement de type, c'est-à-dire à [_Alignof(type) (jusqu'à C23) | alignof(type) (depuis C23)]

sauf lorsque cela affaiblirait l'alignement que le type aurait eu naturellement.

Si expression vaut zéro, ce spécificateur n'a aucun effet.

Lorsque plusieurs spécificateurs [_Alignas (jusqu'à C23) | alignas (depuis C23)] apparaissent dans la même déclaration, le plus strict est utilisé.

Le [_Alignas (jusqu'à C23) | alignas (depuis C23)] spécificateur n'a besoin d'apparaître que sur la définition d'un objet, mais si une déclaration utilise [_Alignas (jusqu'à C23) | alignas (depuis C23)], elle doit spécifier le même alignement que le [_Alignas (jusqu'à C23) | alignas (depuis C23)] de la définition. Le comportement est indéfini si des unités de traduction différentes spécifient des alignements différents pour le même objet.

Notes

En C++, le spécificateur alignas peut aussi être appliqué aux déclarations de types class/struct/union et d'énumérations. Ceci n'est pas pris en charge en C, mais l'alignement d'un type struct peut être contrôlé en utilisant [_Alignas (jusqu'à C23) | alignas (depuis C23)] dans une déclaration de membre.

Mots-clés

alignas, _Alignas

Exemple

#include <stdalign.h>
#include <stdio.h>

// chaque objet de type struct sse_t sera aligné sur une frontière de 16 octets
// (note : nécessite la prise en charge de DR 444)
struct sse_t
{
    alignas(16) float sse_data[4];
};

// chaque objet de type struct data sera aligné sur une frontière de 128 octets
struct data
{
    char x;
    alignas(128) char cacheline[128]; // tableau de char sur-aligné,
                                      // et non un tableau de char sur-alignés
};

int main(void)
{
    printf("sizeof(data) = %zu (1 byte + 127 bytes padding + 128-byte array)\n",
           sizeof(struct data));

    printf("alignment of sse_t is %zu\n", alignof(struct sse_t));

    alignas(2048) struct data d; // cette instance de data est alignée de façon encore plus stricte
    (void)d; // supprime l'avertissement « maybe unused »
}

Output:

sizeof(data) = 256 (1 byte + 127 bytes padding + 128-byte array)
alignment of sse_t is 16
