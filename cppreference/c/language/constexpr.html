spécificateur constexpr (depuis C23)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un objet scalaire déclaré avec le spécificateur de classe de stockage constexpr est une constante. Il doit être entièrement et explicitement initialisé selon les règles d'initialisation statique. Il possède toujours la liaison appropriée à sa déclaration et il existe à l'exécution pour que son adresse puisse être prise ; il ne peut simplement pas être modifié à l'exécution de quelque manière que ce soit, c'est-à-dire que le compilateur peut utiliser sa connaissance de la valeur fixe de l'objet dans toute autre expression constante.

De plus, l'expression constante utilisée pour l'initialiseur d'une telle constante est vérifiée à la compilation.

Un initialiseur de type virgule flottante doit être évalué avec l'environnement de virgule flottante de la traduction.

Certaines restrictions s'appliquent au type d'un objet pouvant être déclaré avec constexpr. Notamment, les constructions suivantes ne sont pas autorisées à être constexpr :

  • Pointeurs (sauf que les pointeurs nuls peuvent être constexpr),
  • Types à modification variable,
  • Types atomiques,
  • types volatile,
  • pointeurs restrict.

Mots-clés

constexpr

Notes

Exemple

#include <fenv.h>
#include <stdio.h>

int main(void)
{
    constexpr float f = 23.0f;
    constexpr float g = 33.0f;
    fesetround(FE_TOWARDZERO);
    constexpr float h = f / g; // n'est pas affecté par fesetround() ci-dessus
    printf("%f\n", h);
}

Output:

0.696969
