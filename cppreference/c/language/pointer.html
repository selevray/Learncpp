Déclaration de pointeur

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un pointeur est un type d'objet qui fait référence à une fonction ou à un objet d'un autre type, en ajoutant éventuellement des qualificatifs. Un pointeur peut aussi ne faire référence à rien, ce qui est indiqué par la valeur spéciale de pointeur nul.

Syntaxe

Dans la grammaire de déclaration d'une déclaration de pointeur, la séquence type-specifier désigne le type pointé (qui peut être un type de fonction ou d'objet, et peut être incomplet), et le declarator a la forme :

| | | | * attr-spec-seq ﻿*(optionnel)* qualifiers ﻿*(optionnel)* declarator | | | |

où declarator peut être l'identificateur qui nomme le pointeur déclaré, y compris un autre déclarateur de pointeur (ce qui indiquerait un pointeur vers un pointeur) :

float *p, **pp; // p est un pointeur vers float
                // pp est un pointeur vers un pointeur vers float
int (*fp)(int); // fp est un pointeur vers une fonction de type int(int)

Les qualifiers qui apparaissent entre * et l'identificateur (ou un autre déclarateur imbriqué) qualifient le type du pointeur déclaré :

int n;
const int * pc = &n; // pc est un pointeur non const vers un int const
// *pc = 2; // Erreur : n ne peut pas être modifié via pc sans cast
pc = NULL; // OK : pc lui-même peut être modifié

int * const cp = &n; // cp est un pointeur const vers un int non const
*cp = 2; // OK pour modifier n via cp
// cp = NULL; // Erreur : cp lui-même ne peut pas être modifié

int * const * pcp = &cp; // pointeur non const vers pointeur const vers int non const

Le attr-spec-seq (C23) est une liste optionnelle d'attributs, appliquée au pointeur déclaré.

Explication

Les pointeurs servent à l'indirection, une technique de programmation omniprésente ; ils permettent d'implémenter une sémantique de passage par référence, d'accéder à des objets de durée de stockage dynamique, d'implémenter des types « optionnels » (en utilisant la valeur de pointeur nul), une relation d'agrégation entre structures, des fonctions de rappel (en utilisant des pointeurs vers des fonctions), des interfaces génériques (en utilisant des pointeurs vers void), et bien d'autres usages.

Pointeurs vers des objets

Un pointeur vers un objet peut être initialisé avec le résultat de l'opérateur d'adresse appliqué à une expression de type objet (qui peut être incomplet) :

int n;
int *np = &n; // pointeur vers int
int *const *npp = &np; // pointeur non const vers pointeur const vers int non const

int a[2];
int (*ap)[2] = &a; // pointeur vers tableau d'int

struct S { int n; } s = {1}
int* sp = &s.n; // pointeur vers l'int qui est un membre de s

Les pointeurs peuvent figurer comme opérandes de l'opérateur d'indirection (* unaire), qui renvoie la lvalue identifiant l'objet pointé :

int n;
int* p = &n; // le pointeur p pointe vers n
*p = 7; // stocke 7 dans n
printf("%d\n", *p); // la conversion lvalue-vers-rvalue lit la valeur de n

Les pointeurs vers des objets de type struct et union peuvent aussi figurer comme opérandes gauches de l'opérateur d'accès à un membre par pointeur ->.

En raison de la conversion implicite tableau vers pointeur, un pointeur vers le premier élément d'un tableau peut être initialisé avec une expression de type tableau :

int a[2];
int *p = a; // pointeur vers a[0]

int b[3][3];
int (*row)[3] = b; // pointeur vers b[0]

Certains opérateurs d'addition, de soustraction, d'affectation composée et d'incrémentation et de décrémentation sont définis pour les pointeurs vers des éléments de tableaux.

Des opérateurs de comparaison sont définis pour les pointeurs vers des objets dans certaines situations : deux pointeurs représentant la même adresse se comparent comme égaux, deux valeurs de pointeur nul se comparent comme égales, des pointeurs vers des éléments d'un même tableau se comparent comme les indices de tableau de ces éléments, et des pointeurs vers des membres de structure se comparent selon l'ordre de déclaration de ces membres.

De nombreuses implémentations fournissent également un ordre total strict sur des pointeurs d'origine quelconque, par exemple lorsqu'ils sont implémentés comme des adresses dans un espace d'adressage virtuel continu (« plat »).

Pointeurs vers des fonctions

Un pointeur vers fonction peut être initialisé avec l'adresse d'une fonction. Grâce à la conversion fonction-vers-pointeur, l'opérateur d'adresse est facultatif :

void f(int);
void (*pf1)(int) = &f;
void (*pf2)(int) = f; // identique à &f

Contrairement aux fonctions, les pointeurs vers fonctions sont des objets et peuvent donc être stockés dans des tableaux, copiés, affectés, passés à d'autres fonctions en tant qu'arguments, etc.

Un pointeur vers fonction peut être utilisé à gauche de l'opérateur d'appel de fonction ; cela invoque la fonction pointée :

#include <stdio.h>

int f(int n)
{
    printf("%d\n", n);
    return n * n;
}

int main(void)
{
    int (*p)(int) = f;
    int x = p(7);
}

La déréférence d'un pointeur de fonction donne le désignateur de fonction de la fonction pointée :

int f();
int (*p)() = f;    // le pointeur p pointe vers f
(*p)(); // fonction f invoquée via le désignateur de fonction
p();    // fonction f invoquée directement via le pointeur

Des opérateurs de comparaison d'égalité sont définis pour les pointeurs vers des fonctions (ils sont égaux s'ils pointent vers la même fonction).

Comme la compatibilité des types de fonctions ignore les qualificateurs de niveau supérieur des paramètres de fonction, les pointeurs vers des fonctions dont les paramètres ne diffèrent que par leurs qualificateurs de niveau supérieur sont interchangeables :

int f(int), fc(const int);
int (*pc)(const int) = f; // OK
int (*p)(int) = fc;       // OK
pc = p;                   // OK

Pointeurs vers void

Un pointeur vers un objet de n'importe quel type peut être implicitement converti en pointeur vers void (éventuellement qualifié const ou volatile), et inversement :

int n=1, *p=&n;
void* pv = p; // int* vers void*
int* p2 = pv; // void* vers int*
printf("%d\n", *p2); // prints 1

Les pointeurs vers void servent à transmettre des objets de type inconnu, ce qui est courant dans les interfaces génériques : malloc renvoie void*, qsort attend une fonction de rappel fournie par l'utilisateur acceptant deux arguments const void*. pthread_create attend une fonction de rappel fournie par l'utilisateur qui accepte et renvoie void*. Dans tous les cas, il incombe à l'appelant de convertir le pointeur vers le bon type avant utilisation.

Pointeurs nuls

Les pointeurs de chaque type possèdent une valeur spéciale appelée valeur de pointeur nul de ce type. Un pointeur dont la valeur est nulle ne pointe vers aucun objet ni aucune fonction (déréférencer un pointeur nul est un comportement indéfini), et se compare comme égal à tous les pointeurs du même type dont la valeur est également nulle.

Pour initialiser un pointeur à null ou affecter la valeur nulle à un pointeur existant, on peut utiliser une constante de pointeur nul (NULL, ou toute autre constante entière de valeur zéro). L'initialisation statique initialise également les pointeurs à leurs valeurs nulles.

Les pointeurs nuls peuvent indiquer l'absence d'objet ou servir à signaler d'autres types de conditions d'erreur. En général, une fonction qui reçoit un argument pointeur doit presque toujours vérifier si la valeur est nulle et traiter ce cas différemment (par exemple, free ne fait rien lorsqu'un pointeur nul est passé).

Notes

Bien que tout pointeur vers un objet puisse être converti par cast en pointeur vers un objet d'un autre type, déréférencer un pointeur vers un type différent du type déclaré de l'objet est presque toujours un comportement indéfini. Voir strict aliasing pour plus de détails.

Il est possible d'indiquer à une fonction qui accède à des objets par pointeurs que ces pointeurs ne sont pas en alias. Voir restrict pour plus de détails.

(depuis C99)

Les expressions lvalue de type tableau, lorsqu'elles sont utilisées dans la plupart des contextes, subissent une conversion implicite vers le pointeur sur le premier élément du tableau. Voir array pour plus de détails.

char *str = "abc"; // "abc" est un tableau char[4], str est un pointeur vers 'a'

Les pointeurs vers char sont souvent utilisés pour représenter des chaînes. Pour représenter une chaîne d'octets valide, un pointeur doit pointer vers un char qui est un élément d'un tableau de char, et il doit exister un char de valeur zéro à un indice supérieur ou égal à l'indice de l'élément référencé par le pointeur.
