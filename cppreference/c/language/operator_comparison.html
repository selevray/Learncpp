Opérateurs de comparaison

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les opérateurs de comparaison sont des opérateurs binaires qui testent une condition et renvoient 1 si cette condition est logiquement vraie et 0 si cette condition est fausse.

Opérateur Nom de l'opérateur Exemple Description
== égal à a == b a est égal à b
!= différent de a != b a est différent de b
< inférieur à a < b a est inférieur à b
> supérieur à a > b a est supérieur à b
<= inférieur ou égal à a <= b a est inférieur ou égal à b
>= supérieur ou égal à a >= b a est supérieur ou égal à b

Opérateurs relationnels

Les expressions d'opérateurs relationnels ont la forme

| | | | lhs < rhs | (1) | | | | lhs > rhs | (2) | | | | lhs <= rhs | (3) | | | | lhs >= rhs | (4) | | |

  1. : expression d'infériorité stricte

  2. : expression de supériorité stricte

  3. : expression d'infériorité ou d'égalité

  4. : expression de supériorité ou d'égalité

where

  • lhs, rhs — expressions ayant toutes deux un type réel ou toutes deux un type pointeur vers un objet

Le type de toute expression d'opérateur relationnel est int, et sa valeur (qui n'est pas une lvalue) vaut 1 lorsque la relation spécifiée est vraie et 0 lorsqu'elle est fausse.

Si lhs et rhs sont des expressions de type réel quelconque, alors

  • les conversions arithmétiques usuelles sont effectuées
  • les valeurs des opérandes après conversion sont comparées au sens mathématique usuel (à ceci près que les zéros positif et négatif sont égaux et que toute comparaison impliquant une valeur NaN renvoie zéro)

Notez que les nombres complexes et imaginaires ne peuvent pas être comparés avec ces opérateurs.

Si lhs et rhs sont des expressions de type pointeur, elles doivent être toutes deux des pointeurs vers des objets de types compatibles, à ceci près que les qualificateurs des objets pointés sont ignorés.

  • un pointeur vers un objet qui n'est pas un élément d'un tableau est traité comme s'il pointait vers un élément d'un tableau à un seul élément
  • si deux pointeurs pointent vers le même objet, ou pointent tous deux un élément après la fin du même tableau, ils sont égaux
  • si deux pointeurs pointent vers des éléments différents du même tableau, celui qui pointe vers l'élément d'indice le plus grand est supérieur
  • si un pointeur pointe vers un élément d'un tableau et l'autre pointe un élément après la fin de ce même tableau, le pointeur situé après la fin est supérieur
  • si les deux pointeurs pointent vers des membres de la même struct, le pointeur vers le membre déclaré en dernier dans la définition de la struct est supérieur à celui vers le membre déclaré plus tôt.
  • les pointeurs vers des membres d'une même union sont égaux
  • toutes les autres comparaisons de pointeurs provoquent un comportement indéfini
#include <assert.h>
int main(void)
{
    assert(1 < 2);
    assert(2+2 <= 4.0); // int se convertit en double, deux 4.0 sont égaux

    struct { int x,y; } s;
    assert(&s.x < &s.y); // les membres d'une struct sont comparés dans l'ordre de leur déclaration

    double d = 0.0/0.0; // NaN
    assert( !(d < d) );
    assert( !(d > d) );
    assert( !(d <= d) );
    assert( !(d >= d) );
    assert( !(d == d) );

    float f = 0.1; // f = 0.100000001490116119384765625
    double g = 0.1; // g = 0.1000000000000000055511151231257827021181583404541015625
    assert(f > g); // valeurs différentes
}

Opérateurs d'égalité

Les expressions d'opérateurs d'égalité ont la forme

| | | | lhs == rhs | (1) | | | | lhs != rhs | (2) | | |

  1. : expression d'égalité

  2. : expression de différence

where

  • lhs, rhs — expressions qui

    • ont toutes deux un type arithmétique quelconque (y compris complexe et imaginaire)
    • ont toutes deux le type nullptr_t
    • l'une a le type nullptr_t et l'autre est une constante pointeur nulle

    (depuis C23)

    • sont toutes deux des pointeurs vers des objets ou fonctions de types compatibles, en ignorant les qualificateurs des types pointés
    • l'une est un pointeur vers un objet et l'autre est un pointeur vers void (éventuellement qualifié)
    • l'une est un pointeur vers un objet ou une fonction et l'autre est une constante pointeur nulle telle que NULL ou nullptr (depuis C23)

Le type de toute expression d'opérateur d'égalité est int, et sa valeur (qui n'est pas une lvalue) vaut 1 lorsque la relation spécifiée est vraie et 0 lorsqu'elle est fausse.

  • si les deux opérandes ont des types arithmétiques, les conversions arithmétiques usuelles sont effectuées et les valeurs obtenues sont comparées au sens mathématique usuel (à ceci près que les zéros positif et négatif sont égaux et que toute comparaison impliquant une valeur NaN, y compris l'égalité avec elle-même, renvoie zéro). En particulier, les valeurs de type complexe sont égales si leurs parties réelles sont égales et leurs parties imaginaires sont égales.
  • deux valeurs nullptr_t ou une valeur nullptr_t et une constante pointeur nulle sont égales

(depuis C23)

  • si l'un des opérandes est un pointeur et l'autre une constante pointeur nulle, la constante pointeur nulle est d'abord convertie dans le type du pointeur (ce qui donne une valeur de pointeur nul), et les deux pointeurs sont comparés comme décrit ci-dessous
  • si l'un des opérandes est un pointeur et l'autre un pointeur vers void, le pointeur non void est converti en pointeur vers void et les deux pointeurs sont comparés comme décrit ci-dessous
  • deux pointeurs sont égaux si l'une des conditions suivantes est vraie :
    • ce sont tous deux des valeurs de pointeur nul de leur type
    • ils pointent tous deux vers le même objet ou la même fonction
    • l'un pointe vers un objet struct/union/tableau et l'autre vers son premier membre/un membre quelconque/son premier élément
    • ils pointent tous deux un élément après le dernier élément du même tableau
    • l'un pointe un élément après la fin d'un tableau, et l'autre pointe au début d'un autre tableau (de même type) qui suit le premier dans un tableau plus grand ou dans une struct sans bourrage

(comme pour les opérateurs relationnels, les pointeurs vers des objets qui ne sont élément d'aucun tableau se comportent comme des pointeurs vers des éléments de tableaux de taille 1)

Notes

Les objets de type struct ne sont pas automatiquement égaux, et les comparer avec memcmp n'est pas fiable, car les octets de bourrage peuvent avoir n'importe quelle valeur.

Comme la comparaison de pointeurs fonctionne avec les pointeurs vers void, la macro NULL peut être définie comme (void*)0 en C, bien que cela soit invalide en C++, où les pointeurs void ne se convertissent pas implicitement en pointeurs typés

Il faut prendre garde lors de la comparaison de valeurs en virgule flottante pour l'égalité, car les résultats de nombreuses opérations ne peuvent pas être représentés exactement et doivent être arrondis. En pratique, les nombres en virgule flottante sont généralement comparés en tolérant un écart d'une ou plusieurs unités de la dernière place.

#include <assert.h>
int main(void)
{
    assert(2+2 == 4.0); // int se convertit en double, deux 4.0 sont égaux

    int n[2][3] = {1,2,3,4,5,6};
    int* p1 = &n[0][2]; // dernier élément de la première ligne
    int* p2 = &n[1][0]; // début de la deuxième ligne
    assert(p1+1 == p2); // sont égaux

    double d = 0.0/0.0; // NaN
    assert( d != d ); // NaN n'est pas égal à lui-même

    float f = 0.1; // f = 0.100000001490116119384765625
    double g = 0.1; // g = 0.1000000000000000055511151231257827021181583404541015625
    assert(f != g); // valeurs différentes
}
