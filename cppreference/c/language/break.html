instruction break

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Provoque la fin de la boucle for, while ou do-while englobante, ou de l'instruction switch.

Utilisé lorsqu'il est autrement malaisé de terminer la boucle à l'aide de l'expression de condition et des instructions conditionnelles.

Syntaxe

| | | | attr-spec-seq ﻿*(facultatif)* break ; | | | |

  • attr-spec-seq — (C23) liste optionnelle d'attributs, appliquée à l'instruction break

N'apparaît que dans le statement d'un corps de boucle (while, do-while, for) ou dans le statement d'un switch.

Explication

Après cette instruction, le contrôle est transféré à l'instruction ou à la déclaration qui suit immédiatement la boucle ou le switch englobant, comme si l'on utilisait goto.

Mots-clés

break

Notes

Une instruction break ne peut pas être utilisée pour sortir de plusieurs boucles imbriquées. L'instruction goto peut être utilisée à cette fin.

Exemple

#include <stdio.h>

int main(void)
{
    int i = 2;
    switch (i)
    {
        case 1: printf("1");
        case 2: printf("2");   // i==2, donc l'exécution commence à cette étiquette case
        case 3: printf("3");
        case 4:
        case 5: printf("45");
                break;         // l'exécution des cas suivants est interrompue
        case 6: printf("6");
    }
    printf("\n");

    // Comparez les sorties de ces deux boucles for imbriquées.
    for (int j = 0; j < 2; j++)
        for (int k = 0; k < 5; k++)
            printf("%d%d ", j,k);
    printf("\n");

    for (int j = 0; j < 2; j++)
    {
        for (int k = 0; k < 5; k++) // seule cette boucle est quittée par break
        {
            if (k == 2)
                break;
            printf("%d%d ", j,k);
        }
    }
}
