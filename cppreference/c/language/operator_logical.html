Opérateurs logiques

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les opérateurs logiques appliquent les opérations de l'algèbre booléenne standard à leurs opérandes.

Opérateur Nom de l'opérateur Exemple Résultat
! négation logique !a la négation logique de a
&& ET logique a && b le ET logique de a et b
` ` OU logique

Négation logique

L'expression de négation logique a la forme

| | | | ! expression | | | |

where

  • expression — une expression de tout type scalaire

L'opérateur de négation logique a le type int. Sa valeur est 0 si expression s'évalue à une valeur différente de zéro. Sa valeur est 1 si expression s'évalue à une valeur égale à zéro. (donc !E est identique à (0==E))

#include <stdbool.h>
#include <stdio.h>
#include <ctype.h>
int main(void)
{
    bool b = !(2+2 == 4); // non vrai
    printf("!(2+2==4) = %s\n", b ? "true" : "false");

    int n = isspace('a'); // non nul si 'a' est un espace, zéro sinon
    int x = !!n; // "bang-bang", idiome courant en C pour ramener des entiers à [0,1]
                 // (toutes les valeurs non nulles deviennent 1)
    char *a[2] = {"non-space", "space"};
    puts(a[x]); // x peut maintenant être utilisé en toute sécurité comme indice d'un tableau de 2 chaînes
}

Output:

!(2+2==4) = false
non-space

ET logique

L'expression du ET logique a la forme

| | | | lhs && rhs | | | |

where

  • lhs — une expression de tout type scalaire
  • rhs — une expression de tout type scalaire, qui n'est évaluée que si lhs n'est pas égal à 0

L'opérateur ET logique a le type int et la valeur 1 si lhs et rhs sont tous deux différents de zéro. Sa valeur est 0 sinon (si l'un de lhs ou rhs, ou les deux, sont égaux à zéro).

Il existe un point de séquence après l'évaluation de lhs. Si le résultat de lhs est égal à zéro, alors rhs n'est pas évalué du tout (on parle d'évaluation en court-circuit)

#include <stdbool.h>
#include <stdio.h>
int main(void)
{
    bool b = 2+2==4 && 2*2==4; // b == true

    1 > 2 && puts("this won't print");

    char *p = "abc";
    if(p && *p) // idiome courant en C : si p n'est pas nul
                // ET si p ne pointe pas sur la fin de la chaîne
    {           // (notez que grâce à l'évaluation en court-circuit, ceci
                //  ne tentera pas de déréférencer un pointeur nul)
    // ...      // ... puis effectuer un traitement de la chaîne
    }
}

OU logique

L'expression du OU logique a la forme

| | | | lhs || rhs | | | |

where

  • lhs — une expression de tout type scalaire
  • rhs — une expression de tout type scalaire, qui n'est évaluée que si lhs est égal à 0

L'opérateur OU logique a le type int et la valeur 1 si lhs ou rhs est différent de zéro. Sa valeur est 0 sinon (si lhs et rhs sont tous deux égaux à zéro).

Il existe un point de séquence après l'évaluation de lhs. Si le résultat de lhs est différent de zéro, alors rhs n'est pas évalué du tout (on parle d'évaluation en court-circuit)

#include <stdbool.h>
#include <stdio.h>
#include <string.h>
#include <errno.h>
int main(void)
{
    bool b = 2+2 == 4 || 2+2 == 5; // true
    printf("true or false = %s\n", b ? "true" : "false");

    // le OU logique peut être utilisé de façon similaire au "or die" de Perl, tant que rhs est de type scalaire
    fopen("test.txt", "r") || printf("could not open test.txt: %s\n", strerror(errno));
}

Sortie possible :

true or false = true
could not open test.txt: No such file or directory
