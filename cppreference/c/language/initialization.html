Initialisation

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Une déclaration d'objet peut fournir sa valeur initiale par le processus appelé initialisation.

Pour chaque déclarateur, l'initialiseur, s'il n'est pas omis, peut être l'une des formes suivantes :

| | | | = expression | (1) | | | | = { initializer-list } | (2) | | | | = { } | (3) | (depuis C23) | |

où initializer-list est une liste non vide, séparée par des virgules, de initializers (avec une virgule finale facultative), où chaque initialiseur a l'une des trois formes possibles :

| | | | expression | (1) | | | | { initializer-list } | (2) | | | | { } | (3) | (depuis C23) | | | designator-list = initializer | (4) | (depuis C99) | |

où designator-list est une liste de désignateurs de tableau de la forme [ constant-expression ] ou de désignateurs de membres de struct/union de la forme . identifier ; voir initialisation de tableau et initialisation de struct.

Remarque : en dehors des initialiseurs, des initializer-list entre accolades peuvent apparaître dans des littéraux composés, qui sont des expressions de la forme :

( type ) { initializer-list }

( type ) { } | (depuis C23)

(depuis C99)

Explication

L'initialiseur spécifie la valeur initiale stockée dans un objet.

Initialisation explicite

Si un initialiseur est fourni, voir

  • initialisation scalaire pour l'initialisation des types scalaires
  • initialisation de tableau pour l'initialisation des types tableau
  • initialisation de struct pour l'initialisation des types struct et union.

Initialisation implicite

Si aucun initialiseur n'est fourni :

  • les objets à durée de stockage automatique sont initialisés à des valeurs indéterminées (qui peuvent être des représentations piégées)
  • les objets à durée de stockage statique et thread-local sont initialisés par initialisation vide

Initialisation vide

Un objet est initialisé vide s'il est explicitement initialisé à partir de l'initialiseur = {}.

(depuis C23)

Dans certains cas, un objet est initialisé vide s'il n'est pas initialisé explicitement, c'est-à-dire :

  • les pointeurs sont initialisés à la valeur de pointeur nul de leur type
  • les objets de types entiers sont initialisés à zéro non signé
  • les objets de types flottants sont initialisés à zéro positif
  • tous les éléments des tableaux, tous les membres des struct et les premiers membres des union sont initialisés vides, récursivement, et tous les bits de remplissage sont initialisés à zéro (sur les plateformes où les valeurs de pointeur nul et les zéros flottants ont une représentation dont tous les bits sont à zéro, cette forme d'initialisation pour les objets statiques est généralement implémentée en les allouant dans la section .bss de l'image du programme)

Notes

Lors de l'initialisation d'un objet à durée de stockage statique ou thread-local, chaque expression de l'initialiseur doit être une expression constante ou un littéral de chaîne.

Les initialiseurs ne peuvent pas être utilisés dans les déclarations d'objets de type incomplet, de VLA et d'objets de portée de bloc ayant une liaison.

Les valeurs initiales des paramètres de fonction sont établies comme par affectation à partir des arguments d'un appel de fonction, et non par initialisation.

Si une valeur indéterminée est utilisée comme argument d'un appel à la bibliothèque standard, le comportement est indéfini. Sinon, le résultat de toute expression impliquant des valeurs indéterminées est une valeur indéterminée (par exemple int n;, n peut ne pas être égal à lui-même et peut sembler changer de valeur lors des lectures suivantes)

Il n'existe pas en C de construction spéciale correspondant à l'initialisation par valeur du C++ ; cependant, = {0}(ou (T){0} dans les littéraux composés) (depuis C99) peut être utilisé à la place, car la norme C n'autorise ni struct vides, ni union vides, ni tableaux de longueur nulle.

(jusqu'à C23)

L'initialiseur vide = {} (ou (T){} dans les littéraux composés) peut être utilisé pour obtenir la même sémantique que l'initialisation par valeur en C++.

(depuis C23)

Exemple

#include <stdlib.h>
int a[2]; // initialise a à {0, 0}
int main(void)
{
    int i;          // initialise i à une valeur indéterminée
    static int j;   // initialise j à 0
    int k = 1;      // initialise k à 1

    // initialise int x[3] à 1,3,5
    // initialise int* p à &x[0]
    int x[] = { 1, 3, 5 }, *p = x;

    // initialise w (un tableau de deux struct) à
    // { { {1,0,0}, 0}, { {2,0,0}, 0} }
    struct {int a[3], b;} w[] = {[0].a = {1}, [1].a[0] = 2};

    // une expression d'appel de fonction peut être utilisée pour une variable locale
    char* ptr = malloc(10);
    free(ptr);

//  Error: les objets à durée de stockage statique nécessitent des initialiseurs constants
//  static char* ptr = malloc(10);

//  Error: une VLA ne peut pas être initialisée
//  int vla[n] = {0};
}
