Arguments variadiques

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Les fonctions variadiques sont des fonctions pouvant être appelées avec un nombre d'arguments différent.

Seules les déclarations de fonction prototypées peuvent être variadiques. Ceci est indiqué par le paramètre de la forme ..., qui doit apparaître en dernier dans la liste des paramètreset doit suivre au moins un paramètre nommé (jusqu'à C23). Le paramètre d'ellipse et le paramètre qui le précède doivent être séparés par ,.

// Déclaration prototypée
int printx(const char* fmt, ...); // fonction déclarée de cette manière
printx("hello world");     // peut être appelée avec un
printx("a=%d b=%d", a, b); // ou plusieurs arguments

int printz(...); // OK depuis C23 et en C++
// Erreur jusqu'à C23 : ... doit suivre au moins un paramètre nommé

// int printy(..., const char* fmt); // Erreur : ... doit être le dernier
// int printa(const char* fmt...);   // Erreur en C : ',' est requis ; OK en C++

Lors de l'appel de fonction, chaque argument faisant partie de la liste d'arguments variables subit des conversions implicites particulières appelées promotions d'arguments par défaut.

Dans le corps d'une fonction utilisant des arguments variadiques, les valeurs de ces arguments peuvent être accédées à l'aide des fonctionnalités de la bibliothèque <stdarg.h> :

Défini dans l'en-tête <stdarg.h>

  • va_start — permet l'accès aux arguments d'une fonction variadique (macro de fonction)
  • va_arg — accède au prochain argument de la fonction variadique (macro de fonction)
  • va_copy (C99) — crée une copie des arguments de la fonction variadique (macro de fonction)
  • va_end — termine le parcours des arguments de la fonction variadique (macro de fonction)
  • va_list — contient les informations nécessaires à va_start, va_arg, va_end et va_copy (typedef)

Notes

Bien que les déclarations de fonction à l'ancienne syntaxe (sans prototype) permettent aux appels suivants d'utiliser un nombre quelconque d'arguments, elles ne sont pas autorisées à être variadiques (depuis C89). La définition d'une telle fonction doit spécifier un nombre fixe de paramètres et ne peut pas utiliser les macros stdarg.h.

// déclaration à l'ancienne syntaxe, supprimée en C23
int printx(); // fonction déclarée de cette manière
printx("hello world");     // peut être appelée avec un
printx("a=%d b=%d", a, b); // ou plusieurs arguments
// le comportement d'au moins un de ces appels est indéfini, selon
// le nombre de paramètres que la fonction est définie pour prendre

Exemple

#include <stdio.h>
#include <time.h>
#include <stdarg.h>

void tlog(const char* fmt,...)
{
    char msg[50];
    strftime(msg, sizeof msg, "%T", localtime(&(time_t){time(NULL)}));
    printf("[%s] ", msg);
    va_list args;
    va_start(args, fmt);
    vprintf(fmt, args);
    va_end(args);
}

int main(void)
{
   tlog("logging %d %d %d...\n", 1, 2, 3);
}

Output:

[10:21:38] logging 1 2 3...
