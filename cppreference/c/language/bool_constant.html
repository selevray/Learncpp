Constantes booléennes prédéfinies (depuis C23)

Syntaxe

| | | | true | (1) | (depuis C23) | | | false | (2) | (depuis C23) | |

Explication

Les mots-clés true et false représentent des constantes prédéfinies. Ce sont des non-lvalues de type bool.

Notes

Voir conversions entières pour les conversions implicites de bool vers d'autres types, et conversions booléennes pour les conversions implicites d'autres types vers bool.

Jusqu'à C23, true et false étaient implémentés comme des macros fournies dans <stdbool.h>. Une implémentation peut également définir bool, true et false comme macros prédéfinies en C23 pour assurer la compatibilité.

Exemple

#include <assert.h>

int main()
{
    assert(true == 1 && 0 == false);
}
