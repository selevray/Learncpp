Déclaration de struct

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Une struct est un type constitué d'une suite de membres dont le stockage est alloué dans un ordre séquentiel (contrairement à union, qui est un type constitué d'une suite de membres dont le stockage se chevauche).

Le spécificateur de type d'une struct est identique à celui de union, à l'exception du mot-clé utilisé :

Syntaxe

| | | | struct attr-spec-seq ﻿*(facultatif)* name ﻿*(facultatif)* { struct-declaration-list } | (1) | | | | struct attr-spec-seq ﻿*(facultatif)* name | (2) | | |

  1. Définition de struct : introduit le nouveau type struct name et définit sa signification

  2. Si utilisé seul sur une ligne, comme dans struct name ;, déclare mais ne définit pas la struct name (voir déclaration anticipée ci-dessous). Dans les autres contextes, désigne la struct déjà déclarée, et attr-spec-seq n'est pas autorisé.

  • name — le nom de la struct en cours de définition
  • struct-declaration-list — un nombre quelconque de déclarations de variables, de déclarations de champ de bits et de déclarations static assert. Les membres de type incomplet et les membres de type fonction ne sont pas autorisés (sauf le membre tableau flexible décrit ci-dessous)
  • attr-spec-seq — (C23) liste optionnelle d'attributs, appliquée au type struct

Explication

Dans un objet struct, les adresses de ses éléments (et les adresses des unités d'allocation des champs de bits) augmentent dans l'ordre de définition des membres. Un pointeur vers une struct peut être converti en pointeur vers son premier membre (ou, si ce membre est un champ de bits, vers son unité d'allocation). De même, un pointeur vers le premier membre d'une struct peut être converti en pointeur vers la struct englobante. Un bourrage sans nom peut être présent entre deux membres quelconques d'une struct ou après le dernier membre, mais pas avant le premier membre. La taille d'une struct est au moins égale à la somme des tailles de ses membres.

Si une struct définit au moins un membre nommé, elle peut en outre déclarer son dernier membre avec un type tableau incomplet. Lorsqu'un élément du membre tableau flexible est accédé (dans une expression utilisant . ou -> avec le nom du membre tableau flexible comme opérande de droite), la struct se comporte comme si le membre tableau avait la plus grande taille tenant dans la mémoire allouée à cet objet. Si aucun stockage supplémentaire n'a été alloué, elle se comporte comme un tableau d'un élément, sauf que le comportement est indéfini si cet élément est accédé ou si un pointeur sur l'élément suivant est produit. L'initialisation et l'opérateur d'affectation ignorent le membre tableau flexible. sizeof l'omet, mais peut avoir plus de bourrage final que ne l'impliquerait cette omission. Les structures contenant un membre tableau flexible (ou des unions ayant un membre structure récursif-possiblement contenant un membre tableau flexible) ne peuvent pas apparaître comme éléments de tableau ni comme membres d'autres structures.

struct s { int n; double d[]; }; // s.d est un membre tableau flexible

struct s t1 = { 0 };          // OK, d est comme double d[1], mais comportement indéfini à l'accès
struct s t2 = { 1, { 4.2 } }; // erreur : l'initialisation ignore le tableau flexible

// si sizeof (double) == 8
struct s *s1 = malloc(sizeof (struct s) + 64); // comme si d était double d[8]
struct s *s2 = malloc(sizeof (struct s) + 40); // comme si d était double d[5]

s1 = malloc(sizeof (struct s) + 10); // maintenant comme si d était double d[1]. Deux octets en excès.
double *dp = &(s1->d[0]);    // OK
*dp = 42;                    // OK
s1->d[1]++;                  // Comportement indéfini. 2 octets en excès ne peuvent pas être accédés
                             // comme double.

s2 = malloc(sizeof (struct s) + 6);  // identique, mais comportement indéfini à l'accès car 2 octets sont
                                     // manquants pour compléter 1 double
dp = &(s2->d[0]);            // OK, l'adresse peut être prise sans problème
*dp = 42;                    // comportement indéfini

*s1 = *s2; // copie uniquement s.n, pas aucun élément de s.d
           // sauf ceux pris en compte dans sizeof (struct s)

(depuis C99)

Comme pour union, un membre sans nom d'une struct dont le type est une struct sans name est appelé struct anonyme. Chaque membre d'une struct anonyme est considéré comme un membre de la struct ou union englobante, en conservant sa disposition en mémoire. Ceci s'applique récursivement si la struct ou l'union englobante est également anonyme.

struct v
{
   union // union anonyme
   {
      struct { int i, j; }; // structure anonyme
      struct { long k, l; } w;
   };
   int m;
} v1;

v1.i = 2;   // valid
v1.k = 3;   // invalide : la structure interne n'est pas anonyme
v1.w.k = 5; // valid

Comme pour union, le comportement du programme est indéfini si une struct est définie sans aucun membre nommé (y compris ceux obtenus via des structs ou unions anonymes imbriquées).

(depuis C11)

Déclaration anticipée

Une déclaration de la forme suivante

| | | | struct attr-spec-seq ﻿*(facultatif)* name ; | | | |

masque toute signification précédemment déclarée du nom name dans l'espace de noms des étiquettes et déclare name comme nouveau nom de struct dans la portée courante, qui sera défini plus tard. Tant que la définition n'apparaît pas, ce nom de struct a un type incomplet.

Cela permet aux structs de se référencer mutuellement :

struct y;
struct x { struct y *p; /* ... */ };
struct y { struct x *q; /* ... */ };

Notez qu'un nouveau nom de struct peut aussi être introduit simplement en utilisant une étiquette de struct dans une autre déclaration, mais si une struct précédemment déclarée portant le même nom existe dans l'espace de noms des étiquettes, l'étiquette désignera ce nom

struct s* p = NULL; // une étiquette désignant une struct inconnue la déclare
struct s { int a; }; // définition de la struct pointée par p
void g(void)
{
    struct s; // déclaration anticipée d'une nouvelle struct locale s
              // cela masque la structure globale s jusqu'à la fin de ce bloc
    struct s *p;  // pointeur vers la structure locale s
                  // sans la déclaration anticipée ci-dessus,
                  // ceci pointerait vers le s de portée fichier
    struct s { char* p; }; // définitions de la structure locale s
}

Notes

Voir initialisation de struct pour les règles concernant les initialiseurs des structs.

Comme les membres de type incomplet ne sont pas autorisés, et qu'un type struct n'est complet qu'à la fin de sa définition, une struct ne peut pas avoir de membre de son propre type. Un pointeur vers son propre type est autorisé et est couramment utilisé pour implémenter les nœuds de listes chaînées ou d'arbres.

Comme une déclaration de struct n'établit pas de portée, les types imbriqués, énumérations et énumérateurs introduits par des déclarations à l'intérieur de struct-declaration-list sont visibles dans la portée englobante où la struct est définie.

Exemple

#include <stddef.h>
#include <stdio.h>

int main(void)
{
    // Déclare le type struct.
    struct car
    {
        char* make;
        int year;
    };
    // Déclare et initialise un objet d'un type struct déclaré précédemment.
    struct car c = {.year = 1923, .make = "Nash"};
    printf("1) Car: %d %s\n", c.year, c.make);

    // Déclare un type struct, un objet de ce type, et un pointeur vers celui-ci.
    struct spaceship
    {
        char* model;
        int max_speed;
    } ship = {"T-65 X-wing starfighter", 1050},
    *pship = &ship;
    printf("2) Spaceship: %s. Max speed: %d km/h\n\n", ship.model, ship.max_speed);

    // Les adresses augmentent dans l'ordre de définition. Un bourrage peut être inséré.
    struct A { char a; double b; char c; };
    printf(
        "3) Offset of char a = %zu\n"
        "4) Offset of double b = %zu\n"
        "5) Offset of char c = %zu\n"
        "6) Size of struct A = %zu\n\n",
        offsetof(struct A, a),
        offsetof(struct A, b),
        offsetof(struct A, c),
        sizeof(struct A)
    );
    struct B { char a; char b; double c; };
    printf(
        "7) Offset of char a = %zu\n"
        "8) Offset of char b = %zu\n"
        "9) Offset of double c = %zu\n"
        "A) Size of struct B = %zu\n\n",
        offsetof(struct B, a),
        offsetof(struct B, b),
        offsetof(struct B, c),
        sizeof(struct B)
    );

    // Un pointeur vers une struct peut être converti en pointeur
    // vers son premier membre et réciproquement.
    char** pmodel = (char **)pship;
    printf("B) %s\n", *pmodel);
    pship = (struct spaceship *)pmodel;
}
