instruction goto

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Transfère le contrôle de façon inconditionnelle vers l'emplacement souhaité.

Utilisée lorsqu'il est impossible de transférer le contrôle vers l'emplacement souhaité à l'aide de constructions classiques.

Syntaxe

| | | | attr-spec-seq(facultatif) goto label ; | | | |

  • label — étiquette cible de l'instruction goto
  • attr-spec-seq — (C23) liste optionnelle d'attributs, appliquée à l'instruction goto

Explication

L'instruction goto provoque un saut inconditionnel (transfert de contrôle) vers l'instruction précédée de l'label indiquée (qui doit apparaître dans la même fonction que l'instruction goto), sauf si ce saut entrerait dans la portée d'un tableau à taille variable ou d'un autre type à taille variable. (depuis C99)

Une label est un identifiant suivi d'un deux-points (:)et d'une instruction (jusqu'à C23). Les étiquettes sont les seuls identifiants ayant une portée de fonction : elles peuvent être utilisées (dans une instruction goto) n'importe où dans la même fonction où elles apparaissent. Plusieurs étiquettes peuvent précéder une même instruction.

Il est permis d'entrer dans la portée d'une variable qui n'est pas à taille variable :

goto lab1; // OK : entrée dans la portée d'une variable ordinaire
    int n = 5;
lab1:; // Remarque : n n'est pas initialisé, comme s'il était déclaré par int n;

//   goto lab2;   // Erreur : entrée dans la portée de deux types à taille variable
     double a[n]; // un VLA
     int (*p)[n]; // un pointeur vers VM
lab2:

Si goto quitte la portée d'un VLA, celui-ci est désalloué (et peut être réalloué si son initialisation est de nouveau exécutée) :

{
   int n = 1;
label:;
   int a[n]; // réalloué 10 fois, chacune avec une taille différente
   if (n++ < 10) goto label; // sortie de la portée d'un VM
}

(depuis C99)

Mots-clés

goto

Notes

Les déclarations n'étant pas des instructions, une étiquette placée devant une déclaration doit utiliser une instruction nulle (un point-virgule immédiatement après le deux-points). Il en va de même pour une étiquette placée avant la fin d'un bloc.

(jusqu'à C23)

C++ impose des limitations supplémentaires à l'instruction goto, mais autorise les étiquettes devant les déclarations (qui sont des instructions en C++).

Exemple

#include <stdio.h>

int main(void)
{
    // goto peut être utilisé pour sortir facilement d'une boucle à plusieurs niveaux
    for (int x = 0; x < 3; x++) {
        for (int y = 0; y < 3; y++) {
            printf("(%d;%d)\n",x,y);
            if (x + y >= 3) goto endloop;
        }
    }
endloop:;
}

Output:

(0;0)
(0;1)
(0;2)
(1;0)
(1;1)
(1;2)
