Assembleur en ligne

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

L'assembleur en ligne (généralement introduit par le mot-clé asm) permet d'intégrer du code source en langage d'assemblage dans un programme C.

Contrairement au C++, l'assembleur en ligne est traité comme une extension en C. Il est conditionnellement supporté et défini par l'implémentation, ce qui signifie qu'il peut être absent et que, même lorsqu'il est fourni par l'implémentation, il n'a pas de signification fixe.

Syntaxe

| | | | asm ( string_literal ) ; | | | |

Explication

Ce type de syntaxe d'assembleur en ligne est accepté par le standard C++ et appelé asm-declaration en C++. Le string_literal est typiquement un court programme écrit en langage d'assemblage, exécuté à chaque exécution de cette déclaration. Les différents compilateurs C ont des règles très variées pour les asm-declaration et des conventions différentes pour l'interaction avec le code C environnant.

Une asm-declaration peut apparaître à l'intérieur d'un bloc (corps de fonction ou autre instruction composée) et, comme toutes les autres déclarations, peut aussi apparaître en dehors d'un bloc.

Notes

MSVC ne prend pas en charge l'assembleur en ligne sur les processeurs ARM et x64, et ne prend en charge que la forme introduite par __asm sur les processeurs x86.

Lors de la compilation en mode ISO C avec GCC ou Clang (par exemple avec l'option -std=c11), __asm__ doit être utilisé à la place de asm.

Exemples

Démontre deux types de syntaxe d'assembleur en ligne proposés par le compilateur GCC. Ce programme ne fonctionne correctement que sur la plateforme x86-64 sous Linux. Notez que l'« assembleur en ligne standard » est également traité comme une extension dans la norme C.

#include <stdio.h>

extern int func(void);
// la définition de func est écrite en langage assembleur
__asm__(".globl func\n\t"
        ".type func, @function\n\t"
        "func:\n\t"
        ".cfi_startproc\n\t"
        "movl $7, %eax\n\t"
        "ret\n\t"
        ".cfi_endproc");

int main(void)
{
    int n = func();
    // assembleur en ligne étendu de gcc
    __asm__ ("leal (%0,%0,4),%0"
           : "=r" (n)
           : "0" (n));
    printf("7*5 = %d\n", n);
    fflush(stdout); // le flush est intentionnel

    // assembleur en ligne standard en C++
    __asm__ ("movq $60, %rax\n\t" // le numéro de l'appel système exit sous Linux
             "movq $2,  %rdi\n\t" // ce programme renvoie 2
             "syscall");
}

Output:

7*5 = 35
