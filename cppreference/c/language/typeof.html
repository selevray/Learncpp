opérateurs typeof (depuis C23)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Détermine le type d'un objet.

Syntaxe

| | | | typeof( type ) | (1) | | | | typeof( expression ) | (2) | | | | typeof_unqual( type ) | (3) | | | | typeof_unqual( expression ) | (4) | | |

Explication

  1. produit le nom de type après évaluation de tout spécificateur typeof imbriqué

  2. donne le nom de type représentant le type de son opérande. Aucune conversion implicite n'est appliquée à expression.

3,4) équivaut respectivement à (1) et (2), mais supprime les qualificateurs

Notes

typeof et typeof_unqual sont collectivement appelés opérateurs typeof. Les opérateurs typeof ne peuvent pas être appliqués aux membres de champ de bits. Si le type de l'opérande est un type à modification variable, l'opérande est évalué ; sinon, l'opérande n'est pas évalué. Le résultat de l'opérateur typeof_unqual est le type non atomique et non qualifié qui résulterait de l'opérateur typeof. L'opérateur typeof conserve tous les qualificateurs.
