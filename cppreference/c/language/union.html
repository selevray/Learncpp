Déclaration d'union

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Une union est un type constitué d'une suite de membres dont les zones de stockage se chevauchent (contrairement à struct, qui est un type constitué d'une suite de membres dont le stockage est alloué dans une séquence ordonnée). La valeur d'au plus un des membres peut être stockée dans une union à un instant donné.

Le spécificateur de type d'une union est identique au spécificateur de type struct, à l'exception du mot-clé utilisé :

Syntaxe

| | | | union attr-spec-seq ﻿*(facultatif)* name ﻿*(facultatif)* { struct-declaration-list } | (1) | | | | union attr-spec-seq ﻿*(facultatif)* name | (2) | | |

  • name — le nom de l'union en cours de définition
  • struct-declaration-list — un nombre quelconque de déclarations de variables, de déclarations de champs de bits et de déclarations static_assert. Les membres de type incomplet et les membres de type fonction ne sont pas autorisés.
  • attr-spec-seq — (C23) liste facultative d'attributs, appliquée au type union ; non autorisée pour (2) si cette forme n'est pas suivie d'un ; (c'est-à-dire qu'il ne s'agit pas d'une déclaration anticipée).

Explication

L'union n'occupe que la taille nécessaire pour contenir son plus grand membre (un rembourrage final supplémentaire et sans nom peut également être ajouté). Les autres membres sont alloués dans les mêmes octets, faisant partie de ce plus grand membre.

Un pointeur vers une union peut être converti en pointeur vers chacun de ses membres (si une union possède des membres de champ de bits, le pointeur vers l'union peut être converti en pointeur vers le type sous-jacent du champ de bits). De même, un pointeur vers un membre quelconque d'une union peut être converti en pointeur vers l'union englobante.

Si le membre utilisé pour accéder au contenu d'une union n'est pas le même que le membre utilisé en dernier pour stocker une valeur, la représentation objet de la valeur stockée est réinterprétée comme représentation objet du nouveau type (cela s'appelle le détournement de type). Si la taille du nouveau type est supérieure à celle du type écrit en dernier, le contenu des octets excédentaires est non spécifié (et peut être une représentation piège). Avant C99 TC3 (DR 283), ce comportement était indéfini, mais il était couramment implémenté ainsi.

(depuis C99)

Comme pour struct, un membre sans nom d'une union dont le type est une union sans name est appelé union anonyme. Chaque membre d'une union anonyme est considéré comme un membre de la struct ou union englobante, en conservant leur disposition d'union. Ceci s'applique récursivement si la struct ou union englobante est également anonyme.

struct v
{
   union // union anonyme
   {
       struct { int i, j; }; // structure anonyme
       struct { long k, l; } w;
   };
   int m;
} v1;

v1.i = 2;   // valid
v1.k = 3;   // invalide : la structure interne n'est pas anonyme
v1.w.k = 5; // valid

Comme pour struct, le comportement du programme est indéfini si une union est définie sans aucun membre nommé (y compris ceux obtenus via des structs ou unions imbriquées anonymes).

(depuis C11)

Mots-clés

union

Notes

Voir initialisation des struct pour les règles relatives à l'initialisation des structs et des unions.

Exemple

#include <assert.h>
#include <stdint.h>
#include <stdio.h>

int main(void)
{
    union S
    {
        uint32_t u32;
        uint16_t u16[2];
        uint8_t  u8;
    } s = {0x12345678}; // s.u32 est désormais le membre actif
    printf("Union S has size %zu and holds %x\n", sizeof s, s.u32);
    s.u16[0] = 0x0011;  // s.u16 est désormais le membre actif
    // la lecture de s.u32 ou de s.u8 réinterprète la représentation objet
//  printf("s.u8 is now %x\n", s.u8); // non spécifié, généralement 11 ou 00
//  printf("s.u32 is now %x\n", s.u32); // non spécifié, généralement 12340011 ou 00115678

    // les pointeurs vers tous les membres d'une union se comparent égaux à eux-mêmes et à l'union
    assert((uint8_t*)&s == &s.u8);

    // cette union possède 3 octets de rembourrage final
    union pad
    {
        char  c[5]; // occupe 5 octets
        float f;    // occupe 4 octets, impose un alignement de 4
    } p = { .f = 1.23 }; // la taille est de 8 pour satisfaire l'alignement de float
    printf("size of union of char[5] and float is %zu\n", sizeof p);
}

Sortie possible :

Union S has size 4 and holds 12345678
size of union of char[5] and float is 8
