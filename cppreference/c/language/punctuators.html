Ponctuation

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Ce sont les symboles de ponctuation du C. La signification de chaque symbole est détaillée dans les pages liées.

{ }

  • Dans une définition de struct ou union, délimite la struct-declaration-list.
  • Dans une définition d'enum, délimite la liste des énumérateurs.
  • Délimite une instruction composée. L'instruction composée peut faire partie d'une définition de fonction.
  • Dans une initialisation, délimite les initialiseurs.

[ ]

  • Opérateur d'indice.
  • Fait partie du déclarateur de tableau dans une déclaration ou un type-id.
  • Dans une initialisation, introduit un désignateur pour un élément de tableau. (depuis C99)
  • Dans un spécificateur d'attribut, délimite les attributs. (depuis C23)

#

  • Introduit une directive de préprocesseur.
  • L'opérateur de préprocesseur de transformation en chaîne.

##

  • L'opérateur de préprocesseur de concaténation de jetons.

( )

  • Dans une expression, indiquer le regroupement.
  • Opérateur d'appel de fonction.
  • Dans une expression sizeof[, _Alignof (depuis C11) | , typeof ou typeof_unqual (depuis C23)], délimite l'opérande.
  • Dans un cast explicite, délimite le type-id.
  • Dans un littéral composé, délimite le type-id. (depuis C99)
  • Dans une déclaration ou un type-id, indiquer le regroupement.
  • Dans un déclarateur de fonction (dans une déclaration ou un type-id), délimite la liste des paramètres.
  • Dans une instruction if, switch, while, do-while ou for, délimitez la clause de contrôle.
  • Dans une définition de macro de type fonction, délimiter les paramètres de la macro.
  • Dans une invocation de macro de type fonction, délimiter les arguments de la macro ou empêcher que les virgules soient interprétées comme séparateurs d'arguments.
  • Fait partie d'un opérateur de préprocesseur defined, __has_include, __has_embed ou __has_c_attribute (depuis C23).
  • Fait partie d'une expression de sélection générique. (depuis C11)
  • Dans un spécificateur de type _Atomic, délimite le type-id. (depuis C11)
  • Dans une déclaration d'assertion statique, délimite les opérandes. (depuis C11)
  • Dans un spécificateur _Alignas, délimite l'opérande. (depuis C11)
  • Dans un attribut, délimite les arguments de l'attribut. (depuis C23)
  • Dans un nom de type entier de précision binaire (_BitInt(N)), délimite la taille. (depuis C23)
  • Fait partie du remplacement __VA_OPT__ dans une définition de macro variadique. (depuis C23)
  • Dans un paramètre de préprocesseur utilisé dans les directives #embed et les expressions de préprocesseur __has_embed, délimite la clause de paramètre de préprocesseur. (depuis C23)

;

  • Indiquer la fin

    • une instruction (y compris l'instruction d'initialisation d'une instruction for)
    • une déclaration ou struct-declaration-list

  • Sépare la deuxième et la troisième clause d'une instruction for.

:

  • Partie de l'opérateur conditionnel.
  • Partie de la déclaration d'étiquette.
  • Dans une déclaration de membre à champ de bits, introduire la largeur.
  • Introduit une base d'enum, qui spécifie le type sous-jacent de l'enum. (depuis C23)
  • Dans une association générique, délimite le type-id ou default et l'expression sélectionnée. (depuis C11)

...

  • Dans la liste de paramètres d'un déclarateur de fonction, signale une fonction variadique.
  • Dans une définition de macro, signale une macro variadique. (depuis C99)

?

  • Partie de l'opérateur conditionnel.

::

  • Dans un attribut, indique la portée de l'attribut. (depuis C23)
  • Dans un paramètre de préprocesseur préfixé (utilisé par #embed et __has_embed), indique la portée. (depuis C23)

.

  • Opérateur d'accès membre.
  • Dans l'initialisation, introduire un désignateur pour un membre de struct/union. (depuis C99)

->

  • Opérateur d'accès membre.

~

  • Opérateur de complément unaire (aussi appelé opérateur de négation binaire bit à bit).

!

  • Opérateur de négation logique.

+

  • Opérateur plus unaire.
  • Opérateur plus binaire.

-

  • Opérateur moins unaire.
  • Opérateur moins binaire.

*

  • Opérateur d'indirection.
  • Opérateur de multiplication.
  • Opérateur pointeur dans un déclarateur ou dans un type-id.
  • Espace réservé pour la longueur d'un déclarateur de tableau de longueur variable dans une déclaration de fonction. (depuis C99)

/

  • Opérateur de division.

%

  • Opérateur modulo.

^

  • Opérateur ou exclusif bit à bit.

&

  • Opérateur d'adresse.
  • Opérateur et bit à bit.

|

  • Opérateur ou bit à bit.

=

  • Opérateur d'affectation simple.
  • Dans l'initialisation, délimiter l'objet et la liste d'initialisation.
  • Dans une définition d'enum, introduire la valeur d'une constante d'énumération.

+=

  • Opérateur d'affectation composée.

-=

  • Opérateur d'affectation composée.

*=

  • Opérateur d'affectation composée.

/=

  • Opérateur d'affectation composée.

%=

  • Opérateur d'affectation composée.

^=

  • Opérateur d'affectation composée.

&=

  • Opérateur d'affectation composée.

|=

  • Opérateur d'affectation composée.

==

  • Opérateur d'égalité.

!=

  • Opérateur d'inégalité.

<

  • Opérateur inférieur à.
  • Introduit un nom d'en-tête dans
    • une directive #include
    • une __has_include expression de prétraitement (depuis C23)
    • une #embed directive (depuis C23)
    • une __has_embed expression de prétraitement (depuis C23)
    • emplacements définis par l'implémentation dans une #pragma directive

>

  • Opérateur supérieur à.
  • Indique la fin d'un nom d'en-tête dans
    • une directive #include
    • une __has_include expression de prétraitement (depuis C23)
    • une #embed directive (depuis C23)
    • une __has_embed expression de prétraitement (depuis C23)
    • emplacements définis par l'implémentation dans une #pragma directive

<=

  • Opérateur inférieur ou égal à.

>=

  • Opérateur supérieur ou égal à.

&&

  • Opérateur et logique.

||

  • Opérateur ou logique.

<<

  • Opérateur de décalage bit à bit.

>>

  • Opérateur de décalage bit à bit.

<<=

  • Opérateur d'affectation composée.

>>=

  • Opérateur d'affectation composée.

++

  • Opérateur d'incrémentation.

--

  • Opérateur de décrémentation.

,

  • Opérateur virgule.

  • Séparateur de liste dans

    • la liste de déclarateurs d'une déclaration
    • liste d'initialisation dans l'initialisation, y compris les littéraux composés (depuis C99)
    • la liste d'arguments d'une expression d'appel de fonction
    • la liste d'énumérateurs d'une déclaration enum
    • une liste de paramètres de fonction
    • la liste de paramètres de macro d'une définition de macro de type fonction
    • la liste d'arguments de macro dans un appel de macro de type fonction, sauf si elle se trouve entre un ensemble interne de parenthèses
    • la liste d'associations générique dans une expression de sélection générique (depuis C11)
    • une liste d'attributs (depuis C23)

  • Dans une déclaration d'assertion statique, séparer les arguments. (depuis C11)

  • Dans une expression de sélection générique, séparer l'expression de contrôle et la liste d'associations générique. (depuis C11)
