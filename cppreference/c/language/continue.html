instruction continue

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Provoque le saut de la partie restante du corps de boucle englobante for, while ou do-while.

Utilisé lorsqu'il est autrement malaisé d'ignorer la partie restante de la boucle à l'aide d'instructions conditionnelles.

Syntaxe

| | | | attr-spec-seq(facultatif) continue ; | | | |

  • attr-spec-seq — (C23) liste optionnelle d'attributs, appliquée à l'instruction continue

Explication

L'instruction continue provoque un saut, comme avec goto, vers la fin du corps de boucle (elle ne peut apparaître que dans le corps d'une boucle for, while ou do-while).

Pour une boucle while, elle agit comme

while (/* ... */) {
   // ...
   continue; // agit comme goto contin;
   // ...
   contin:;
}

Pour une boucle do-while, elle agit comme :

do {
    // ...
    continue; // agit comme goto contin;
    // ...
    contin:;
} while (/* ... */);

Pour une boucle for, elle agit comme :

for (/* ... */) {
    // ...
    continue; // agit comme goto contin;
    // ...
    contin:;
}

Mots-clés

continue

Exemple

#include <stdio.h>

int main(void)
{
    for (int i = 0; i < 10; i++) {
        if (i != 5) continue;
        printf("%d ", i);             // cette instruction est ignorée à chaque fois que i != 5
    }

    printf("\n");

    for (int j = 0; j < 2; j++) {
        for (int k = 0; k < 5; k++) { // seule cette boucle est affectée par continue
            if (k == 3) continue;
            printf("%d%d ", j, k);    // cette instruction est ignorée à chaque fois que k == 3
        }
    }
}

Output:

5
00 01 02 04 10 11 12 14
