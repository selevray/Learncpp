Énumérations

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Un type énuméré est un type distinct dont la valeur est une valeur de son type sous-jacent (voir ci-dessous), qui comprend les valeurs des constantes explicitement nommées (constantes d'énumération).

Syntaxe

Un type énuméré est déclaré à l'aide du following spécificateur d'énumération comme type-specifier dans la grammaire des déclarations :

| | | | enum attr-spec-seq ﻿*(facultatif)* identifier ﻿*(facultatif)* { enumerator-list } | (1) | | | | enum attr-spec-seq ﻿*(facultatif)* identifier ﻿*(facultatif)* : type { enumerator-list } | (2) | (depuis C23) | |

  1. Déclare une énumération sans type sous-jacent fixe.

  2. Déclare une énumération de type sous-jacent fixe type.

où enumerator-list est une liste de éléments séparés par des virgules (une virgule finale est autorisée) (depuis C99) de enumerator, chacun ayant la forme :

| | | | enumeration-constant attr-spec-seq ﻿*(facultatif)* | (1) | | | | enumeration-constant attr-spec-seq ﻿*(facultatif)* = constant-expression | (2) | | |

where

  • identifier, enumeration-constant — identifiants introduits par cette déclaration
  • constant-expression — expression constante entière dont la valeur est représentable comme une valeur de type int (jusqu'à C23). Si l'énumération a un type sous-jacent fixe, représentable comme une valeur de type (depuis C23)
  • attr-spec-seq — (C23) liste facultative d'attributs,
    • appliquée à toute l'énumération si elle apparaît après enum,
    • appliquée au enumerator si elle apparaît après enumeration-constant

Comme pour struct ou union, une déclaration qui introduit un type énuméré et une ou plusieurs constantes d'énumération peut aussi déclarer un ou plusieurs objets de ce type ou d'un type qui en dérive.

enum color { RED, GREEN, BLUE } c = RED, *cp = &c;
// introduit le type enum color
// les constantes entières RED, GREEN, BLUE
// l'objet c de type enum color
// l'objet cp de type pointeur vers enum color

Explication

Chaque enumeration-constant figurant dans le corps d'un spécificateur d'énumération devient une constante entière de type int (jusqu'à C23) dans la portée englobante et peut être utilisée partout où des constantes entières sont requises (par exemple comme étiquette de case ou comme taille de tableau non VLA).

Lors du traitement de chaque constante d'énumération dans la liste des énumérateurs, le type de la constante d'énumération doit être :

  • le type précédemment déclaré, s'il s'agit d'une redéclaration de la même constante d'énumération ; ou,
  • le type énuméré, pour une énumération de type sous-jacent fixe ; ou,
  • int, s'il n'y a pas de constantes d'énumération précédentes dans la liste des énumérateurs et pas de = explicite avec une expression constante entière de définition ; ou,
  • int, si donné explicitement avec = et que la valeur de l'expression constante entière est représentable par un int ; ou,
  • le type de l'expression constante entière, si donné explicitement avec = et si la valeur de l'expression constante entière n'est pas représentable par int ; ou,
  • le type de la valeur de la dernière constante d'énumération augmentée de 1. Si une telle expression constante entière provoquait un dépassement de capacité ou un bouclage de la valeur de la constante d'énumération précédente par l'addition de 1, le type prend soit :
  • un type entier signé de taille convenable (à l'exclusion des types entiers signés à précision exacte au bit) capable de représenter la valeur de la constante d'énumération précédente plus 1 ; ou,
  • un type entier non signé de taille convenable (à l'exclusion des types entiers non signés à précision binaire) capable de représenter la valeur de la constante d'énumération précédente plus 1.

Un type entier signé est choisi si la constante d'énumération précédente ajoutée est de type entier signé. Un type entier non signé est choisi si la constante d'énumération précédente est de type entier non signé. S'il n'existe aucun type entier de taille convenable décrit précédemment capable de représenter la nouvelle valeur, alors l'énumération n'a aucun type capable de représenter toutes ses valeurs.

(depuis C23)

enum color { RED, GREEN, BLUE } r = RED;
switch(r)
{
case RED:
    puts("red");
    break;
case GREEN:
    puts("green");
    break;
case BLUE:
    puts("blue");
    break;
}

Si enumeration-constant est suivi de = constant-expression, sa valeur est la valeur de cette expression constante. Si enumeration-constant n'est pas suivi de = constant-expression, sa valeur est égale à la valeur de l'énumérateur précédent de la même énumération, plus un. La valeur du premier énumérateur (s'il n'utilise pas = constant-expression) est zéro.

enum Foo { A, B, C = 10, D, E = 1, F, G = F + C };
// A=0, B=1, C=10, D=11, E=1, F=2, G=12

Le identifier lui-même, s'il est utilisé, devient le nom du type énuméré dans l'espace de noms des balises et nécessite l'utilisation du mot-clé enum (sauf s'il est défini par typedef dans l'espace de noms ordinaire).

enum color { RED, GREEN, BLUE };
enum color r = RED; // OK
// color x = GREEN; // Error: color n'est pas dans l'espace de noms ordinaire
typedef enum color color_t;
color_t x = GREEN; // OK

Chaque type énuméré sans type sous-jacent fixe (depuis C23) est compatible avec l'un des types suivants : char, un type entier signé, ou un type entier non signé (à l'exclusion de bool et des types entiers à précision binaire) (depuis C23). Il est défini par l'implémentation de savoir quel type est compatible avec un type énuméré donné, mais quel que soit ce type, il doit pouvoir représenter toutes les valeurs des énumérateurs de cette énumération. Pour toutes les énumérations avec un type sous-jacent fixe, le type énuméré est compatible avec le type sous-jacent de l'énumération. (depuis C23)

Le type membre d'énumération pour un type énuméré sans type sous-jacent fixe, une fois complété, est :

  • int si toutes les valeurs de l'énumération sont représentables comme int ; ou,
  • le type énuméré.

(depuis C23)

Toutes les énumérations ont un type sous-jacent. Le type sous-jacent peut être spécifié explicitement à l'aide d'un enum-type-specifier et constitue alors son type sous-jacent fixe. S'il n'est pas spécifié explicitement, le type sous-jacent est le type compatible de l'énumération, qui est soit un type entier signé ou non signé, soit char.

(depuis C23)

Les types énumérés sont des types entiers et, à ce titre, peuvent être utilisés partout où d'autres types entiers peuvent l'être, y compris dans les conversions implicites et les opérateurs arithmétiques.

enum { ONE = 1, TWO } e;
long n = ONE; // promotion
double d = ONE; // conversion
e = 1.2; // conversion, e vaut désormais ONE
e = e + 1; // e vaut désormais TWO

Notes

Contrairement à struct ou union, il n'existe pas d'enums déclarées par avance en C :

enum Color; // Error: pas de déclarations anticipées d'enums en C
enum Color { RED, GREEN, BLUE };

Les énumérations permettent de déclarer des constantes nommées de manière plus pratique et structurée que ne le permet #define ; elles sont visibles dans le débogueur, obéissent aux règles de portée et participent au système de types.

#define TEN 10
struct S { int x : TEN; }; // OK

or

enum { TEN = 10 };
struct S { int x : TEN; }; // aussi OK

Depuis C23, constexpr peut être utilisé dans le même but :

constexpr int TEN = 10;
struct S { int x : TEN; }; // aussi OK

De plus, comme une struct ou une union n'établit pas sa portée en C, un type énuméré et ses constantes d'énumération peuvent être introduits dans la spécification des membres du premier, et leur portée est alors la même que celle du premier, par la suite.

struct Element
{
    int z;
    enum State { SOLID, LIQUID, GAS, PLASMA } state;
} oxygen = { 8, GAS };

// le type enum State et ses constantes d'énumération restent visibles ici, par ex.
void foo(void)
{
    enum State e = LIQUID; // OK
    printf("%d %d %d ", e, oxygen.state, PLASMA); // prints 1 2 3
}

Exemple

#include <stdio.h>

int main(void)
{
    enum TV { FOX = 11, CNN = 25, ESPN = 15, HBO = 22, MAX = 30, NBC = 32 };

    printf("List of cable stations:\n");
    printf(" FOX: \t%2d\n", FOX);
    printf(" HBO: \t%2d\n", HBO);
    printf(" MAX: \t%2d\n", MAX);
}

Output:

List of cable stations:
 FOX:   11
 HBO:   22
 MAX:   30
