Déclaration typedef

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

La déclaration typedef permet de déclarer un identifiant comme alias de type, destiné à remplacer un nom de type éventuellement complexe

Le mot-clé typedef est utilisé dans une déclaration, à la place grammaticale d'un spécificateur de classe de stockage, sauf qu'il n'affecte ni le stockage ni la liaison :

typedef int int_t; // déclare int_t comme alias du type int
typedef char char_t, *char_p, (*fp)(void); // déclare char_t comme alias de char
                                           // char_p comme alias de char*
                                           // fp comme alias de char(*)(void)

Explication

Si une déclaration utilise typedef comme spécificateur de classe de stockage, chaque déclarateur qu'elle contient définit un identifiant comme alias du type spécifié. Comme une seule spécification de classe de stockage est autorisée dans une déclaration, une déclaration typedef ne peut pas être static ou extern.

Une déclaration typedef n'introduit pas de type distinct : elle établit seulement un synonyme pour un type existant, de sorte que les noms typedef sont compatibles avec les types qu'ils désignent. Les noms typedef partagent l'espace de noms avec les identifiants ordinaires tels que les énumérateurs, les variables et les fonctions.

Un typedef pour un VLA ne peut apparaître qu'en portée de bloc. La longueur du tableau est évaluée à chaque fois que le flux de contrôle passe par la déclaration typedef, contrairement à la déclaration du tableau lui-même :

void copyt(int n)
{
    typedef int B[n]; // B est un VLA, sa taille est n, évaluée maintenant
    n += 1;
    B a; // la taille de a est n, avant +=1
    int b[n]; // a et b ont des tailles différentes
    for (int i = 1; i < n; i++)
        a[i-1] = b[i];
}

(depuis C99)

Notes

Un nom typedef peut être un type incomplet, qui peut être complété comme d'habitude :

typedef int A[]; // A est int[]
A a = {1, 2}, b = {3,4,5}; // type de a est int[2], type de b est int[3]

Les déclarations typedef sont souvent utilisées pour injecter des noms de l'espace de noms des étiquettes dans l'espace de noms ordinaire :

typedef struct tnode tnode; // tnode dans l'espace de noms ordinaire
                            // est un alias de tnode dans l'espace de noms des étiquettes
struct tnode {
    int count;
    tnode *left, *right; // équivalent à struct tnode *left, *right;
}; // tnode est désormais aussi un type complet
tnode s, *sp; // équivalent à struct tnode s, *sp;

Elles peuvent même éviter complètement d'utiliser l'espace de noms des étiquettes :

typedef struct { double hi, lo; } range;
range z, *zp;

Les noms typedef sont aussi couramment utilisés pour simplifier la syntaxe des déclarations complexes :

// tableau de 5 pointeurs vers des fonctions renvoyant des pointeurs vers des tableaux de 3 int
int (*(*callbacks[5])(void))[3];

// identique avec des typedef
typedef int arr_t[3]; // arr_t est un tableau de 3 int
typedef arr_t* (*fp)(void); // pointeur vers une fonction renvoyant arr_t*
fp callbacks[5];

Les bibliothèques exposent souvent des types dépendants du système ou de la configuration sous forme de noms typedef, afin de présenter une interface cohérente aux utilisateurs ou aux autres composants de bibliothèque :

#if defined(_LP64)
typedef int     wchar_t;
#else
typedef long    wchar_t;
#endif
