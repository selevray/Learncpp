Définitions de fonctions

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Une définition de fonction associe le corps de la fonction (une suite de déclarations et d'instructions) au nom de la fonction et à la liste de paramètres. Contrairement à la déclaration de fonction, les définitions de fonctions ne sont autorisées qu'en portée de fichier (il n'existe pas de fonctions imbriquées).

C prend en charge deux formes différentes de définitions de fonctions :

| | | | attr-spec-seq(facultatif) specifiers-and-qualifiers parameter-list-declarator function-body | (1) | | | | specifiers-and-qualifiers identifier-list-declarator declaration-list function-body | (2) | (jusqu'à C23) | |

where

  • attr-spec-seq — (C23) une liste facultative d'attributs, appliqués à la fonction
  • specifiers-and-qualifiers — une combinaison de
    • spécificateurs de type qui, éventuellement modifiés par le déclarateur, forment le type de retour
    • spécificateurs de classe de stockage, qui déterminent la liaison de l'identificateur (static, extern, ou aucun)
    • spécificateurs de fonction inline, _Noreturn, ou aucun
  • parameter-list-declarator — un déclarateur de type fonction qui utilise une liste de paramètres pour désigner les paramètres de la fonction
  • identifier-list-declarator — un déclarateur de type fonction qui utilise une liste d'identificateurs pour désigner les paramètres de la fonction
  • declaration-list — suite de déclarations qui déclarent chaque identificateur de identifier-list-declarator. Ces déclarations ne peuvent pas utiliser d'initialiseurs et le seul spécificateur de classe de stockage autorisé est register.
  • function-body — une instruction composée, c'est-à-dire une suite de déclarations et d'instructions entre accolades, qui est exécutée à chaque appel de cette fonction
  1. Définition de fonction au nouveau style (C89). Cette définition introduit à la fois la fonction elle-même et sert de prototype de fonction pour toutes les expressions d'appel de fonction futures, forçant les conversions des expressions d'arguments vers les types de paramètres déclarés.
int max(int a, int b)
{
    return a>b?a:b;
}

double g(void)
{
    return 0.1;
}
  1. (jusqu'à C23) Définition de fonction à l'ancien style (K&R). Cette définition ne se comporte pas comme un prototype et toutes les expressions d'appel de fonction futures effectueront des promotions d'arguments par défaut.
int max(a, b)
int a, b;
{
    return a>b?a:b;
}
double g()
{
    return 0.1;
}

Explication

Comme pour les déclarations de fonctions, le type de retour de la fonction, déterminé par le spécificateur de type dans specifiers-and-qualifiers et éventuellement modifié par declarator comme d'habitude dans les déclarations, doit être un type objet complet non tableau ou le type void. Si le type de retour serait qualifié cvr, il est ramené à sa version non qualifiée pour la construction du type de fonction.

void f(char *s) { puts(s); } // le type de retour est void
int sum(int a, int b) { return a+b; } // le type de retour est int
int (*foo(const void *p))[3] { // le type de retour est un pointeur vers un tableau de 3 int
    return malloc(sizeof(int[3]));
}

Comme pour les déclarations de fonctions, les types des paramètres sont ramenés de fonctions vers pointeurs et de tableaux vers pointeurs pour la construction du type de fonction, et les qualificateurs cvr de premier niveau de tous les types de paramètres sont ignorés pour déterminer le type de fonction compatible.

Contrairement aux déclarations de fonctions, les paramètres formels sans nom ne sont pas autorisés (sinon il y aurait des conflits avec les définitions de fonctions à l'ancienne syntaxe (K&R)) : ils doivent avoir un nom même s'ils ne sont pas utilisés dans la fonction. La seule exception est la liste de paramètres spéciale (void).

(jusqu'à C23)

Les paramètres formels peuvent être sans nom dans les définitions de fonctions, car les définitions de fonctions à l'ancienne syntaxe (K&R) ont été supprimées. Les paramètres sans nom sont inaccessibles par leur nom dans le corps de la fonction.

(depuis C23)

int f(int, int); // declaration
// int f(int, int) { return 7; } // Erreur jusqu'à C23, OK depuis C23
int f(int a, int b) { return 7; } // definition
int g(void) { return 8; } // OK : void ne déclare aucun paramètre

Dans le corps de la fonction, chaque paramètre nommé est une expression lvalue ; il a une durée de stockage automatique et une portée de bloc. La disposition des paramètres en mémoire (ou même s'ils sont stockés en mémoire) est non spécifiée : elle fait partie de la convention d'appel.

int main(int ac, char **av)
{
    ac = 2; // les paramètres sont des lvalues
    av = (char *[]){"abc", "def", NULL};
    f(ac, av);
}

Voir opérateur d'appel de fonction pour d'autres détails sur le mécanisme d'un appel de fonction et return pour le retour depuis une fonction.

func

Dans chaque function-body, la variable prédéfinie spéciale __func__, de portée de bloc et de durée de stockage statique, est disponible, comme si elle était définie immédiatement après l'accolade ouvrante par

static const char __func__[] = "function name";

Cet identifiant spécial est parfois utilisé en combinaison avec les constantes macro prédéfinies __FILE__ et __LINE__, par exemple, par assert.

(depuis C99)

Notes

La liste d'arguments doit être explicitement présente dans le déclarateur ; elle ne peut pas être héritée d'un typedef

typedef int p(int q, int r); // p est un type fonction int(int, int)
p f { return q + r; } // Erreur

En C89, specifiers-and-qualifiers était facultatif, et s'il était omis, le type de retour de la fonction valait par défaut int (éventuellement modifié par declarator).

De plus, la définition à l'ancienne syntaxe n'exigeait pas une déclaration pour chaque paramètre dans declaration-list. Tout paramètre dont la déclaration était absente avait le type int

max(a, b) // a et b ont le type int, le type de retour est int
{
    return a>b?a:b;
}

(jusqu'à C99)
