boucle while

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Exécute une statement de manière répétée, jusqu'à ce que la valeur de expression devienne égale à zéro. Le test a lieu avant chaque itération.

Syntaxe

| | | | attr-spec-seq(facultatif) while ( expression ) statement | | | |

  • expression — toute expression de type scalaire. Cette expression est évaluée avant chaque itération, et si elle est égale à zéro, la boucle se termine.
  • statement — toute instruction, typiquement une instruction composée, qui sert de corps de la boucle
  • attr-spec-seq — (C23) liste facultative d'attributs, appliquée à l'instruction de boucle

Explication

Une instruction while fait exécuter de manière répétée le statement (appelé aussi corps de la boucle) jusqu'à ce que l'expression (appelée aussi expression de contrôle) soit égale à zéro. La répétition a lieu que le corps de la boucle soit atteint normalement ou par un goto vers le milieu de statement.

L'évaluation de expression a lieu avant chaque exécution de statement (sauf si l'on entre par un goto). Si l'expression de contrôle doit être évaluée après le corps de la boucle, la boucle do-while peut être utilisée.

Si l'exécution de la boucle doit être interrompue à un moment donné, l'instruction break peut être utilisée comme instruction de terminaison.

Si l'exécution de la boucle doit se poursuivre à la fin du corps de la boucle, l'instruction continue peut être utilisée comme raccourci.

Un programme comportant une boucle infinie a un comportement indéfini si la boucle n'a aucun effet observable (E/S, accès volatile, opération atomique ou de synchronisation) dans aucune partie de son statement ou de son expression. Cela permet aux compilateurs d'optimiser toutes les boucles non observables sans prouver qu'elles se terminent. Les seules exceptions sont les boucles où expression est une expression constante ; while(true) est toujours une boucle infinie.

Comme pour toutes les autres instructions de sélection et d'itération, l'instruction while établit une portée de bloc : tout identifiant introduit dans expression sort de portée après statement.

(depuis C99)

Notes

Les expressions booléennes et pointeurs sont souvent utilisées comme expressions de contrôle de boucle. La valeur booléenne false et la valeur de pointeur nul de tout type de pointeur sont égales à zéro.

Mots-clés

while

Exemple

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
enum { SIZE = 8 };
int main(void)
{
    // exemple trivial
    int array[SIZE], n = 0;
    while(n < SIZE) array[n++] = rand() % 2;
    puts("Array filled!");
    n = 0;
    while(n < SIZE) printf("%d ", array[n++]);
    printf("\n");

    // implémentation classique de strcpy()
    // (copie une chaîne terminée par un caractère nul de src vers dst)
    char src[] = "Hello, world", dst[sizeof src], *p = dst, *q = src;
    while((*p++ = *q++)) // doubles parenthèses (non strictement nécessaires)
                         // utilisées pour supprimer les avertissements, garantissant que c'est bien une
                         // affectation (et non une comparaison) volontairement,
                         // dont le résultat est utilisé comme valeur de vérité
        ; // instruction nulle
    puts(dst);
}

Output:

Array filled!
1 0 1 1 1 1 0 0
Hello, world
