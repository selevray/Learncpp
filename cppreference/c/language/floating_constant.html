Constante flottante

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Permet d'utiliser directement des valeurs de type flottant dans des expressions.

Syntaxe

Une constante flottante est une expression non lvalue de la forme :

| | | | significand exponent ﻿*(facultatif)* suffix ﻿*(facultatif)* | | | |

où significand a la forme

| | | | whole-number (facultatif) .(facultatif) fraction (facultatif) | | | |

exponent a la forme

| | | | e | E exponent-sign ﻿*(facultatif)* digit-sequence | (1) | | | | p | P exponent-sign ﻿*(facultatif)* digit-sequence | (2) | (depuis C99) | |

  1. La syntaxe d'exposant pour une constante flottante décimale

  2. La syntaxe d'exposant pour une constante flottante hexadécimale

Des apostrophes simples (') facultatives peuvent être insérées entre les chiffres comme séparateurs ; elles sont ignorées lors de la compilation.

(depuis C23)

Explication

Si significand commence par la séquence de caractères 0x ou 0X, la constante flottante est une constante flottante hexadécimale. Sinon, c'est une constante flottante décimale.

Pour une constante flottante hexadécimale, significand est interprétée comme un nombre rationnel hexadécimal, et digit-sequence de l'exposant est interprété comme la puissance entière de 2 par laquelle la mantisse doit être multipliée.

double d = 0x1.2p3; // fraction hexadécimale 1.2 (décimal 1.125) multipliée par 2^3, soit 9.0

(depuis C99)

Pour une constante flottante décimale, significand est interprétée comme un nombre rationnel décimal, et digit-sequence de l'exposant est interprété comme la puissance entière de 10 par laquelle la mantisse doit être multipliée.

double d = 1.2e3; // fraction décimale 1.2 multipliée par 10^3, soit 1200.0

Suffixes

Une constante flottante sans suffixe a le type double. Si suffix est la lettre f ou F, la constante flottante a le type float. Si suffix est la lettre l ou L, la constante flottante a le type long double.

Si l'implémentation prédéfinit la macro __STDC_IEC_60559_BFP__, les suffixes suivants et les constantes flottantes correspondantes sont en outre pris en charge :

  • si suffix vaut df ou DF, la constante flottante a le type _Decimal32 ;
  • si suffix vaut dd ou DD, la constante flottante a le type _Decimal64 ;
  • si suffix vaut dl ou DL, la constante flottante a le type _Decimal128.

Les suffixes des types flottants décimaux ne sont pas autorisés dans les constantes flottantes hexadécimales.

(depuis C23)

Parties facultatives

Si l'exposant est présent et que la partie fractionnaire n'est pas utilisée, le séparateur décimal peut être omis :

double x = 1e0; // flottant 1.0 (point non utilisé)

Pour les constantes flottantes décimales, la partie exponent est facultative. Si elle est omise, le point n'est pas facultatif, et l'une des parties whole-number ou fraction doit être présente.

double x = 1.; // flottant 1.0 (partie fractionnaire facultative)
double y = .1; // flottant 0.1 (partie entière facultative)

Pour les constantes flottantes hexadécimales, l'exposant n'est pas facultatif afin d'éviter toute ambiguïté résultant du fait qu'un suffixe f serait confondu avec un chiffre hexadécimal.

(depuis C99)

Valeurs représentables

Le résultat de l'évaluation d'une constante flottante est soit la valeur représentable la plus proche, soit la valeur représentable immédiatement supérieure ou inférieure à la valeur la plus proche, choisie de manière définie par l'implémentation (autrement dit, la direction d'arrondi par défaut lors de la traduction est définie par l'implémentation).

Toutes les constantes flottantes de la même forme source se convertissent dans le même format interne avec la même valeur. Les constantes flottantes de formes sources différentes, par exemple 1.23 et 1.230, n'ont pas nécessairement la même représentation interne ni la même valeur.

Les constantes flottantes peuvent se convertir vers une plage et une précision supérieures à celles indiquées par leur type, si FLT_EVAL_METHOD l'indique. Par exemple, la constante 0.1f peut se comporter comme si elle était 0.1L dans une expression.

Le résultat de l'évaluation d'une constante flottante hexadécimale, si FLT_RADIX vaut 2, est la valeur exacte représentée par la constante flottante, arrondie correctement au type cible.

(depuis C99)

Les constantes flottantes de type flottant décimal qui ont la même valeur numérique (\small x)x mais des exposants de quantum différents, par exemple 1230.dd, 1230.0dd et 1.23e3dd, ont des représentations internes distinguables.

L'exposant de quantum (\small q)q d'une constante flottante d'un type flottant décimal est déterminé de telle sorte que (\small 10^q)10q
représente 1 à la position du dernier chiffre de significand, lorsque c'est possible. Si l'exposant de quantum (\small q)q et le coefficient (\small c = x\cdot 10^{-q})c=x·10-q
déterminés ci-dessus ne peuvent pas être représentés exactement dans le type de la constante flottante, (\small q)q est augmenté au besoin dans la limite du type, et (\small c)c est réduit en conséquence, avec l'arrondi nécessaire. L'arrondi peut donner zéro ou l'infini. Si (\small c)c (éventuellement arrondi) est toujours hors de la plage autorisée une fois que (\small q)q atteint sa valeur maximale, la constante flottante obtenue a pour valeur l'infini positif.

(depuis C23)

Notes

La direction d'arrondi et la précision par défaut sont en vigueur lors de la conversion des constantes flottantes en représentations internes, et les exceptions de virgule flottante ne sont pas levées même si #pragma STDC FENV_ACCESS est actif (pour la conversion à l'exécution de chaînes de caractères, strtod peut être utilisé). Notez que cela diffère des expressions constantes arithmétiques de type flottant.

Les lettres des constantes flottantes ne sont pas sensibles à la casse, sauf que les majuscules et les minuscules ne peuvent pas être utilisées ensemble dans les suffixes des types flottants décimaux (depuis C23) : 0x1.ep+3 et 0X1.EP+3 représentent la même valeur flottante 15.0.

Le point décimal spécifié par setlocale n'a aucun effet sur la syntaxe des constantes flottantes : le caractère de point décimal est toujours le point.

Contrairement aux entiers, toute valeur flottante ne peut pas être représentée directement par une syntaxe de constante décimale [, ni même hexadécimale (depuis C99) | : les macros NAN et INFINITY, ainsi que des fonctions comme nan, offrent des moyens de générer ces valeurs spéciales (depuis C99)]. Notez que 0x1.FFFFFEp128f, qui pourrait sembler être un NaN IEEE, déborde en fait vers l'infini dans ce format.

Il n'existe pas de constantes flottantes négatives ; une expression telle que -1.2 est l'opérateur arithmétique moins unaire appliqué à la constante flottante 1.2. Notez que la valeur spéciale zéro négatif peut être construite avec -0.0.

Exemple

#include <stdio.h>

int main(void)
{
    printf("15.0     = %a\n", 15.0);
    printf("0x1.ep+3 = %f\n", 0x1.ep+3);

    // Constantes en dehors de l'intervalle du type double.
    printf("+2.0e+308 --> %g\n",  2.0e+308);
    printf("+1.0e-324 --> %g\n",  1.0e-324);
    printf("-1.0e-324 --> %g\n", -1.0e-324);
    printf("-2.0e+308 --> %g\n", -2.0e+308);
}

Output:

15.0     = 0x1.ep+3
0x1.ep+3 = 15.000000
+2.0e+308 --> inf
+1.0e-324 --> 0
-1.0e-324 --> -0
-2.0e+308 --> -inf
