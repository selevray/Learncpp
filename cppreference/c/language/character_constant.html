where

  • c-char est soit
    • un caractère du jeu de caractères source de base, à l'exclusion de l'apostrophe ('), de la barre oblique inverse (\) ou du caractère de saut de ligne.
    • séquence d'échappement : l'une des séquences d'échappement de caractères spéciaux \' \" \? \\ \a \b \f \n \r \t \v, des échappements hexadécimaux \x... ou des échappements octaux \..., telles que définies dans séquences d'échappement.
  • nom de caractère universel, \u... ou \U..., tel que défini dans séquences d'échappement.

(depuis C99)

  • c-char-sequence est une séquence de deux c-char ou plus.

  1. constante de caractère entier sur un octet, par ex. 'a', '\n' ou '\13'. Une telle constante a le type int et une valeur égale à la représentation de c-char dans le jeu de caractères d'exécution, sous forme de valeur de type char associée à int. Si c-char ne peut pas être représenté sur un seul octet dans le jeu de caractères d'exécution, la valeur est définie par l'implémentation.

  2. constante de caractère UTF-8, par ex. u8'a'. Une telle constante a le type char8_t et la valeur égale à la valeur de point de code ISO 10646 de c-char, à condition que cette valeur de point de code soit représentable par une seule unité de code UTF-8 (c'est-à-dire que c-char est dans l'intervalle 0x0-0x7F, bornes incluses). Si c-char n'est pas représentable par une seule unité de code UTF-8, le programme est mal formé.

  1. constante de caractère large sur 16 bits, par ex. u'貓', mais pas u'🍌' (u'\U0001f34c'). Une telle constante a le type char16_t et une valeur égale à la valeur de c-char dans l'encodage 16 bits produit par mbrtoc16 (normalement UTF-16). Si c-char n'est pas représentable ou correspond à plus d'un caractère 16 bits, la valeur est définie par l'implémentation.

  2. constante de caractère large sur 32 bits, par ex. U'貓' ou U'🍌'. Une telle constante a le type char32_t et une valeur égale à la valeur de c-char dans l'encodage 32 bits produit par mbrtoc32 (normalement UTF-32). Si c-char n'est pas représentable ou correspond à plus d'un caractère 32 bits, la valeur est définie par l'implémentation.

(jusqu'à C23)

  1. constante de caractère UTF-16, par ex. u'貓', mais pas u'🍌' (u'\U0001f34c'). Une telle constante a le type char16_t et la valeur égale à la valeur de point de code ISO 10646 de c-char, à condition que cette valeur de point de code soit représentable par une seule unité de code UTF-16 (c'est-à-dire que c-char est dans l'intervalle 0x0-0xD7FF ou 0xE000-0xFFFF, bornes incluses). Si c-char n'est pas représentable par une seule unité de code UTF-16, le programme est mal formé.

  2. constante de caractère UTF-32, par ex. U'貓' ou U'🍌'. Une telle constante a le type char32_t et la valeur égale à la valeur de point de code ISO 10646 de c-char, à condition que cette valeur de point de code soit représentable par une seule unité de code UTF-32 (c'est-à-dire que c-char est dans l'intervalle 0x0-0xD7FF ou 0xE000-0x10FFFF, bornes incluses). Si c-char n'est pas représentable par une seule unité de code UTF-32, le programme est mal formé.

(depuis C23)

  1. constante de caractère large, par ex. L'β' ou L'貓. Une telle constante a le type wchar_t et une valeur égale à la valeur de c-char dans le jeu de caractères large d'exécution (c'est-à-dire la valeur que produirait mbtowc). Si c-char n'est pas représentable ou correspond à plus d'un caractère large (par ex. une valeur hors BMP sous Windows où wchar_t est sur 16 bits), la valeur est définie par l'implémentation.

  2. constante multicaractère, par ex. 'AB', a le type int et une valeur définie par l'implémentation.

  3. constante multicaractère large, par ex. L'AB', a le type wchar_t et une valeur définie par l'implémentation.

  4. constante multicaractère 16 bits, par ex. u'CD', a le type char16_t et une valeur définie par l'implémentation.

  5. constante multicaractère 32 bits, par ex. U'XY', a le type char32_t et une valeur définie par l'implémentation.

Notes

Les constantes multicaractères ont été héritées par C du langage B. Bien que non spécifiées par la norme C, la plupart des compilateurs (MSVC est une exception notable) les implémentent comme spécifié dans B : les valeurs de chaque char de la constante initialisent des octets successifs de l'entier résultant, dans l'ordre big-endian, complété à zéro et aligné à droite, par ex. la valeur de '\1' est 0x00000001 et la valeur de '\1\2\3\4' est 0x01020304.

En C++, les littéraux de caractères ordinaires encodables ont le type char, et non int.

Contrairement aux constantes entières, une constante de caractère peut avoir une valeur négative si char est signé : sur de telles implémentations, '\xFF' est un int de valeur -1.

Lorsqu'elles sont utilisées dans une expression de contrôle de #if ou #elif, les constantes de caractères peuvent être interprétées selon le jeu de caractères source, le jeu de caractères d'exécution ou un autre jeu de caractères défini par l'implémentation.

Les constantes multicaractères de 16/32 bits ne sont pas largement prises en charge et sont supprimées en C23. Certaines implémentations courantes (par ex. clang) ne les acceptent pas du tout.

Exemple

#include <stddef.h>
#include <stdio.h>
#include <uchar.h>

int main (void)
{
    printf("constant value     \n");
    printf("-------- ----------\n");

    // constantes de caractères entiers,
    int c1='a'; printf("'a':\t %#010x\n", c1);
    int c2='🍌'; printf("'🍌':\t %#010x\n\n", c2); // défini par l'implémentation

    // constante multicaractère
    int c3='ab'; printf("'ab':\t %#010x\n\n", c3); // défini par l'implémentation

    // constantes de caractères larges de 16 bits
    char16_t uc1 = u'a'; printf("'a':\t %#010x\n", (int)uc1);
    char16_t uc2 = u'¢'; printf("'¢':\t %#010x\n", (int)uc2);
    char16_t uc3 = u'猫'; printf("'猫':\t %#010x\n", (int)uc3);
    // défini par l'implémentation (🍌 correspond à deux caractères de 16 bits)
    char16_t uc4 = u'🍌'; printf("'🍌':\t %#010x\n\n", (int)uc4);

    // constantes de caractères larges de 32 bits
    char32_t Uc1 = U'a'; printf("'a':\t %#010x\n", (int)Uc1);
    char32_t Uc2 = U'¢'; printf("'¢':\t %#010x\n", (int)Uc2);
    char32_t Uc3 = U'猫'; printf("'猫':\t %#010x\n", (int)Uc3);
    char32_t Uc4 = U'🍌'; printf("'🍌':\t %#010x\n\n", (int)Uc4);

    // constantes de caractères larges
    wchar_t wc1 = L'a'; printf("'a':\t %#010x\n", (int)wc1);
    wchar_t wc2 = L'¢'; printf("'¢':\t %#010x\n", (int)wc2);
    wchar_t wc3 = L'猫'; printf("'猫':\t %#010x\n", (int)wc3);
    wchar_t wc4 = L'🍌'; printf("'🍌':\t %#010x\n\n", (int)wc4);
}
