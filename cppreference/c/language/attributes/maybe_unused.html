Attribut C : maybe_unused (depuis C23)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Supprime les avertissements sur les entités non utilisées.

Syntaxe

| | | | [[ maybe_unused ]] [[ __maybe_unused__ ]] | | | |

Explication

Cet attribut peut apparaître dans la déclaration des entités suivantes :

  • struct/union : struct [[maybe_unused]] S;,
  • nom de typedef : [[maybe_unused]] typedef S* PS;,
  • object: [[maybe_unused]] int x;,
  • membre de struct/union : union U { [[maybe_unused]] int n; };,
  • fonction : [[maybe_unused]] void f(void);,
  • énumération : enum [[maybe_unused]] E {};,
  • enumerator: enum { A [[maybe_unused]], B [[maybe_unused]] = 42 };.

Si le compilateur émet des avertissements sur les entités inutilisées, cet avertissement est supprimé pour toute entité déclarée maybe_unused.

Exemple

#include <assert.h>

[[maybe_unused]] void f([[maybe_unused]] _Bool cond1, [[maybe_unused]] _Bool cond2)
{
   [[maybe_unused]] _Bool b = cond1 && cond2;
   assert(b); // en mode release, assert est supprimé à la compilation, et b est inutilisé
              // aucun avertissement car il est déclaré [[maybe_unused]]
} // les paramètres cond1 et cond2 ne sont pas utilisés, aucun avertissement

int main(void)
{
    f(1, 1);
}
