Attribut C : fallthrough (depuis C23)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Indique que le passage à travers le label case précédent est intentionnel et ne doit pas être signalé par un compilateur qui émet un avertissement sur fallthrough.

Syntaxe

| | | | [[ fallthrough ]] [[ __fallthrough__ ]] | | | |

Explication

Ne peut être utilisé que dans une déclaration d'attribut pour créer une déclaration fallthrough ([[fallthrough]];).

Une déclaration fallthrough ne peut être utilisée que dans une instruction switch, où le prochain élément de bloc (instruction, déclaration ou étiquette) rencontré est une instruction précédée d'une étiquette case ou default pour cette instruction switch.

Indique que le passage à travers le label case précédent est intentionnel et ne doit pas être signalé par un compilateur qui émet un avertissement sur fallthrough.

Exemple

#include <stdbool.h>

void g(void) {}
void h(void) {}
void i(void) {}

void f(int n) {
  switch (n) {
    case 1:
    case 2:
      g();
     [[fallthrough]];
    case 3: // aucun avertissement sur fallthrough
      h();
    case 4: // le compilateur peut émettre un avertissement sur fallthrough
      if(n < 3) {
          i();
          [[fallthrough]]; // OK
      }
      else {
          return;
      }
    case 5:
      while (false) {
        [[fallthrough]]; // mal formé : aucune étiquette case ou default ultérieure
      }
    case 6:
      [[fallthrough]]; // mal formé : aucune étiquette case ou default ultérieure
  }
}

int main(void) {}
