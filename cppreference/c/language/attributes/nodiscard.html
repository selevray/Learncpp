Attribut C : nodiscard (depuis C23)

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Si une fonction déclarée nodiscard ou une fonction renvoyant par valeur une struct/union/enum déclarée nodiscard est appelée dans une expression de valeur ignorée autre qu'un cast vers void, le compilateur est encouragé à émettre un avertissement.

Syntaxe

| | | | [[ nodiscard ]] [[ __nodiscard__ ]] | (1) | | | | [[ nodiscard ( string-literal ) ]] [[ __nodiscard__ ( string-literal ) ]] | (2) | | |

  • string-literal — texte pouvant servir à expliquer la raison pour laquelle le résultat ne doit pas être ignoré

Explication

Apparaît dans une déclaration de fonction, une déclaration d'énumération ou une déclaration de struct/union.

Si, depuis une expression à valeur ignorée autre qu'un transtypage vers void,

  • une fonction déclarée nodiscard est appelée, ou
  • une fonction renvoyant une struct/union/enum déclarée nodiscard est appelée,

le compilateur est encouragé à émettre un avertissement.

Le string-literal, s'il est spécifié, est généralement inclus dans les avertissements.

Exemple

struct [[nodiscard]] error_info { int status; /*...*/ };
struct error_info enable_missile_safety_mode() { /*...*/ return (struct error_info){0}; }
void launch_missiles() { /*...*/ }
void test_missiles() {
   enable_missile_safety_mode(); // le compilateur peut émettre un avertissement lorsqu'une valeur nodiscard est ignorée
   launch_missiles();
}
struct error_info* foo() { static struct error_info e; /*...*/ return &e; }
void f1() {
    foo(); // le type nodiscard lui-même n'est pas renvoyé, aucun avertissement
}
// nodiscard( string-literal ) :
[[nodiscard("PURE FUN")]] int strategic_value(int x, int y) { return x ^ y; }

int main()
{
    strategic_value(4,2); // le compilateur peut émettre un avertissement lorsqu'une valeur nodiscard est ignorée
    int z = strategic_value(0,0); // OK : la valeur de retour n'est pas ignorée
    return z;
}
