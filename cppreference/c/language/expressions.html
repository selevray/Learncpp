Expressions

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Une expression est une suite d'opérateurs et de leurs opérandes, qui spécifie un calcul.

L'évaluation d'expressions peut produire un résultat (par exemple, l'évaluation de 2 + 2 produit le résultat 4), peut générer des effets de bord (par exemple, l'évaluation de printf("%d", 4) envoie le caractère '4' vers le flux de sortie standard), et peut désigner des objets ou des fonctions.

Généralités

  • Les catégories de valeurs (lvalue, objet non-lvalue, désignateur de fonction) classent les expressions selon leurs valeurs
  • L'ordre d'évaluation des arguments et des sous-expressions précise l'ordre dans lequel les résultats intermédiaires sont obtenus

Conversions

  • Les conversions implicites ont lieu lorsque les types des opérandes ne correspondent pas aux attentes des opérateurs
  • Les transtypages peuvent être utilisés pour convertir explicitement des valeurs d'un type à un autre.

  • Les expressions constantes peuvent être évaluées à la compilation et utilisées dans un contexte de compilation (non-VLA *(depuis C99)*tailles de tableaux, initialiseurs statiques, etc.)

Expressions primaires

Les opérandes de tout opérateur peuvent être d'autres expressions ou bien des expressions primaires (par exemple, dans 1 + 2 * 3, les opérandes de operator+ sont la sous-expression 2 * 3 et l'expression primaire 1).

Les expressions primaires sont l'une des suivantes :

  1. Les constantes et les littéraux (par exemple 2 ou "Hello, world")

  2. Les identificateurs convenablement déclarés (par exemple n ou printf)

  1. Les sélections génériques

(depuis C11)

Toute expression entre parenthèses est également classée comme expression primaire : cela garantit que les parenthèses ont une priorité supérieure à tout opérateur.

Constantes et littéraux

Les valeurs constantes de certains types peuvent être intégrées dans le code source d'un programme C à l'aide d'expressions spécialisées appelées littéraux (pour les expressions lvalue) et constantes (pour les expressions non-lvalue)

  • Les constantes entières sont des nombres décimaux, octaux ou hexadécimaux de type entier.
  • Les constantes de caractère sont des caractères individuels de type int, convenant à une conversion vers un type caractère, ou de type [char8_t, (depuis C23) | char16_t, char32_t, ou (depuis C11)] wchar_t
  • Les constantes flottantes sont des valeurs de type float, double ou long double
  • Les constantes prédéfinies true/false sont des valeurs de type bool
  • La constante prédéfinie nullptr est une valeur de type nullptr_t

(depuis C23)

  • Les littéraux de chaîne sont des suites de caractères de type char[][, char8_t[] (depuis C23) | , char16_t[], char32_t[], (depuis C11)] ou wchar_t[] qui représentent des chaînes terminées par un caractère nul
  • Les littéraux composés sont des valeurs de type struct, union ou tableau directement intégrées dans le code du programme

(depuis C99)

Expressions non évaluées

Les opérandes de l'opérateur sizeof sont des expressions qui ne sont pas évaluées(sauf s'il s'agit de VLA) (depuis C99). Ainsi, size_t n = sizeof(printf("%d", 4)); n'effectue aucune sortie console.

Les opérandes de l'opérateur [_Alignof (jusqu'à C23) | alignof (depuis C23)], l'expression de contrôle d'une sélection générique, et les expressions de taille des VLA qui sont opérandes de [_Alignof (jusqu'à C23) | alignof (depuis C23)] sont aussi des expressions non évaluées.

(depuis C11)
