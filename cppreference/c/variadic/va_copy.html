va_copy

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdarg.h>

void va_copy( va_list dest, va_list src );  // (depuis C99)

La macro va_copy copie src vers dest.

va_end doit être appelé sur dest avant que la fonction ne retourne ou avant toute réinitialisation ultérieure de dest (via des appels à va_start ou va_copy).

Paramètres

  • dest — une instance du type va_list à initialiser
  • src — la source va_list qui servira à initialiser dest

Valeur développée

(aucune)

Exemple

#include <stdio.h>
#include <stdarg.h>
#include <math.h>

double sample_stddev(int count, ...)
{
    /* Calcule la moyenne avec args1. */
    double sum = 0;
    va_list args1;
    va_start(args1, count);
    va_list args2;
    va_copy(args2, args1);   /* copie l'objet va_list */
    for (int i = 0; i < count; ++i) {
        double num = va_arg(args1, double);
        sum += num;
    }
    va_end(args1);
    double mean = sum / count;

    /* Calcule l'écart type avec args2 et la moyenne. */
    double sum_sq_diff = 0;
    for (int i = 0; i < count; ++i) {
        double num = va_arg(args2, double);
        sum_sq_diff += (num-mean) * (num-mean);
    }
    va_end(args2);
    return sqrt(sum_sq_diff / count);
}

int main(void)
{
    printf("%f\n", sample_stddev(4, 25.0, 27.3, 26.9, 25.7));
}
