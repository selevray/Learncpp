getline, getwline, getdelim, getwdelim

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <stdio.h>

ssize_t getline(char **lineptr, size_t *n, FILE *stream);  // (1) (TR sur la mémoire dynamique)

ssize_t getwline(wchar_t **lineptr, size_t *n, FILE *stream);  // (2) (TR sur la mémoire dynamique)

ssize_t getdelim(char ** restrict lineptr, size_t * restrict n,
                 int delimiter, FILE *stream);  // (3) (TR sur la mémoire dynamique)

ssize_t getwdelim(wchar_t ** restrict lineptr, size_t * restrict n,
                 wint_t delimiter, FILE * stream);  // (4) (TR sur la mémoire dynamique)

  1. Se comporte comme getdelim(lineptr, n, '\n', stream)

  2. Se comporte comme getwdelim(lineptr, n, L'\n', stream)

  3. Lit depuis le flux stream comme avec fgetc, jusqu'à ce que delimiter soit rencontré, en stockant les caractères dans le tampon de taille *n pointé par *lineptr, en augmentant automatiquement sa taille comme avec realloc pour contenir la totalité de l'entrée, y compris le délimiteur, et en ajoutant un terminateur nul. *lineptr peut être nul, auquel cas *n est ignoré et getline alloue un nouveau tampon comme avec malloc. Le comportement est indéfini si delimiter a une valeur hors de l'intervalle de unsigned char ou EOF.

  4. Identique à (3), sauf que les caractères sont lus comme avec fgetwc et que delimiter doit être un wchar_t ou WEOF valide.

Si *lineptr n'est pas nul, le comportement est indéfini si *lineptr n'est pas un pointeur pouvant être passé à free, ou si *n est inférieur à la taille de la mémoire allouée pointée par *lineptr

Comme toutes les fonctions du TR sur la mémoire dynamique, getline n'est garantie disponible que si __STDC_ALLOC_LIB__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT2__ comme la constante entière 1 avant d'inclure stdio.h.

Paramètres

  • lineptr — pointeur vers un pointeur vers le tampon initial ou vers un pointeur nul
  • n — pointeur vers la taille du tampon initial
  • delimiter — le caractère délimiteur
  • stream — flux d'entrée valide, ouvert par fopen

Valeur de retour

Le nombre de caractères stockés dans le tampon, y compris le délimiteur, mais à l'exclusion du terminateur nul.

En cas d'erreur, renvoie -1 et met feof ou ferror à stream.

Notes

Ces fonctions sont identiques à leurs versions POSIX, sauf qu'il est permis, mais non obligatoire, de définir errno en cas d'erreur.

Exemple

#ifdef __STDC_ALLOC_LIB__
#define __STDC_WANT_LIB_EXT2__ 1
#else
#define _POSIX_C_SOURCE 200809L
#endif

#include <stdio.h>
#include <stdlib.h>
void get_y_or_n(void)
{
    char *response = NULL;
    size_t len;
    printf("Continue? [y] n: ");
    if((getline(&response, &len, stdin) < 0) || (len && response[0] == 'n')) {
        free(response);
        exit(0);
    }
    free(response);
    return;
}
int main(void)
{
    get_y_or_n();
}

Output:

Continue? [y] n:
