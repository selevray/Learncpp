strndup

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Défini dans l'en-tête <string.h>

char *strndup( const char *str, size_t size );  // (TR sur la mémoire dynamique)

Renvoie un pointeur vers une chaîne d'octets terminée par un caractère nul, contenant des copies d'au plus size octets de la chaîne pointée par str. Si le caractère nul de fin n'est pas rencontré dans les size premiers octets, il est ajouté à la chaîne dupliquée.

Le pointeur renvoyé doit être passé à free pour éviter une fuite mémoire.

En cas d'erreur, un pointeur nul est renvoyé et errno peut être défini.

Comme toutes les fonctions du TR sur la mémoire dynamique, strndup n'est garantie disponible que si __STDC_ALLOC_LIB__ est défini par l'implémentation et si l'utilisateur définit __STDC_WANT_LIB_EXT2__ comme la constante entière 1 avant d'inclure string.h.

Paramètres

  • str — pointeur vers la chaîne d'octets terminée par un caractère nul à dupliquer
  • size — nombre maximal d'octets à copier depuis str

Valeur de retour

Un pointeur vers la chaîne nouvellement allouée, ou un pointeur nul en cas d'erreur.

Notes

La fonction est identique à strndup de POSIX, sauf qu'il est permis, mais non obligatoire, de définir errno en cas d'erreur.

Exemple

#ifdef __STDC_ALLOC_LIB__
#define __STDC_WANT_LIB_EXT2__ 1
#else
#define _POSIX_C_SOURCE 200809L
#endif

#include <string.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char *s1 = "String";
    char *s2 = strndup(s1, 2);
    printf("strndup(\"String\", 2) == %s\n", s2);
    free(s2);
}
