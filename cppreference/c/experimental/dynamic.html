Extensions de mémoire dynamique

Traduction automatique (Claude Haiku 5.5) de cppreference.com, sous licence CC-BY-SA 3.0.

Extensions à la bibliothèque C, partie II : fonctions d'allocation dynamique, ISO/IEC TR 24731-2:2010, définit les nouveaux composants suivants pour la bibliothèque standard C :

  • STDC_ALLOC_LIB — constante entière de type long indiquant le niveau de conformité (macro constante)

Défini dans l'en-tête <stdio.h>

  • fmemopen (dynamic memory TR) — ouvre un tampon mémoire de taille fixe comme flux d'E/S (fonction)
  • open_memstreamopen_wmemstream (dynamic memory TR) — ouvre un tampon mémoire à taille redimensionnable dynamiquement comme flux d'E/S (fonction)
  • asprintfaswprintfvasprintfvaswprintf (dynamic memory TR) — variantes de sprintf etc. qui écrivent dans un tampon alloué automatiquement et renvoient un pointeur vers celui-ci (fonction)
  • getlinegetwlinegetdelimgetwdelim (dynamic memory TR) — lit depuis un flux dans un tampon redimensionné automatiquement jusqu'au délimiteur ou à la fin de ligne (fonction)

Défini dans l'en-tête <string.h>

  • strdup (dynamic memory TR) — alloue une copie d'une chaîne (fonction)
  • strndup (dynamic memory TR) — alloue une copie d'une chaîne jusqu'à la taille spécifiée (fonction)

Cette extension de bibliothèque introduit aussi le caractère d'allocation par affectation m à utiliser avec les spécificateurs de conversion %s, %[ et %c dans fscanf et dans la famille de fonctions fwscanf.

Notes

Les fonctions fmemopen, open_memstream, open_wmemstream, getdelim, getline, strdup, strndup, ainsi que les extensions de fscanf, sont disponibles dans POSIX (ISO/IEC 9945:2003).

Les fonctions asprintf et vasprintf sont disponibles dans Linux Standard Base (ISO/IEC IS 23360:2006)
