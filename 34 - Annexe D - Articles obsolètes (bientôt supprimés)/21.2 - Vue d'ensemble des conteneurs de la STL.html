21.2 — Vue d'ensemble des conteneurs de la STL

De loin, la fonctionnalité la plus utilisée de la bibliothèque STL est celle des classes conteneurs de la STL. Si vous avez besoin de revoir rapidement les conteneurs, consultez la leçon 23.6 -- Classes conteneurs.

La STL contient de nombreuses classes conteneurs, utilisables dans des situations différentes. D'une manière générale, les classes conteneurs se répartissent en trois grandes catégories : les conteneurs séquentiels (sequence containers), les conteneurs associatifs (associative containers) et les adaptateurs de conteneurs (container adapters). Nous allons simplement faire ici un rapide tour d'horizon des conteneurs.

Conteneurs séquentiels

Les conteneurs séquentiels sont des classes conteneurs qui conservent l'ordre des éléments qu'ils contiennent. Une caractéristique essentielle de ces conteneurs est que vous pouvez choisir la position à laquelle insérer un élément. L'exemple le plus courant de conteneur séquentiel est le tableau : si vous insérez quatre éléments dans un tableau, ces éléments se retrouvent exactement dans l'ordre où vous les avez insérés.

Depuis le C++11, la STL contient 6 conteneurs séquentiels : std::vector, std::deque, std::array, std::list, std::forward_list et std::basic_string.

  • Si vous avez suivi des cours de physique, vous pensez sans doute à un vecteur comme à une entité possédant à la fois une norme et une direction. La classe vector, au nom malheureusement ambigu, de la STL est un tableau dynamique capable de grandir selon les besoins pour contenir ses éléments. La classe vector permet un accès direct à ses éléments via l'opérateur [], et l'insertion ainsi que la suppression d'éléments en fin de vecteur sont généralement rapides.

Le programme suivant insère 6 nombres dans un vecteur, puis utilise l'opérateur [] surchargé pour y accéder dans l'ordre et les afficher.

```cpp #include #include

int main() {

  std::vector<int> vect;
  for (int count=0; count < 6; ++count)
      vect.push_back(10 - count); // insertion en fin de tableau

  for (int index=0; index < vect.size(); ++index)
      std::cout << vect[index] << ' ';

  std::cout << '\n';

} ```

Ce programme produit le résultat :
10 9 8 7 6 5

    • Une list est un type particulier de conteneur séquentiel, appelé liste doublement chaînée, dans lequel chaque élément contient des pointeurs vers l'élément suivant et l'élément précédent de la liste. Les listes ne donnent accès qu'au début et à la fin de la liste : il n'existe pas d'accès direct. Si vous voulez trouver une valeur au milieu, vous devez partir d'une extrémité et « parcourir la liste » jusqu'à atteindre l'élément recherché. L'avantage des listes est que l'insertion d'éléments est très rapide si vous savez déjà où les insérer. On utilise généralement des itérateurs (iterators) pour parcourir la liste.

    Nous reparlerons plus en détail des listes chaînées et des itérateurs dans de prochaines leçons.

    • Bien que les classes string et wstring de la STL ne soient généralement pas considérées comme des conteneurs séquentiels, elles le sont essentiellement, car on peut les voir comme un vecteur dont les éléments sont de type char (ou wchar_t).

Conteneurs associatifs

Les conteneurs associatifs sont des conteneurs qui trient automatiquement leurs données lors de leur insertion. Par défaut, les conteneurs associatifs comparent les éléments à l'aide de l'opérateur <.

  • Un set est un conteneur qui stocke des éléments uniques : les doublons ne sont pas autorisés. Les éléments sont triés selon leurs valeurs.
  • Un multiset est un set dans lequel les doublons sont autorisés.
  • Une map (également appelée tableau associatif) est un conteneur dont chaque élément est une paire appelée paire clé/valeur. La clé sert au tri et à l'indexation des données, et doit être unique. La valeur correspond aux données proprement dites.
  • Une multimap (également appelée dictionnaire) est une map qui autorise les clés en double. Les dictionnaires du monde réel sont des multimaps : la clé est le mot, et la valeur est sa signification. Toutes les clés sont triées par ordre croissant, et vous pouvez retrouver la valeur à partir de la clé. Certains mots peuvent avoir plusieurs significations, ce qui explique pourquoi le dictionnaire est une multimap plutôt qu'une map.

Adaptateurs de conteneurs

Les adaptateurs de conteneurs sont des conteneurs prédéfinis spéciaux, adaptés à des usages particuliers. Ce qui est intéressant avec les adaptateurs de conteneurs, c'est que vous pouvez choisir le conteneur séquentiel qu'ils utilisent.

  • Une stack (pile) est un conteneur dont les éléments fonctionnent selon le principe LIFO (Last In, First Out, dernier entré, premier sorti) : les éléments sont insérés (empilés, ou pushed) et retirés (dépilés, ou popped) par la fin du conteneur. Les piles utilisent par défaut deque comme conteneur séquentiel sous-jacent (ce qui peut sembler étrange, puisque vector paraît un choix plus naturel), mais peuvent aussi utiliser vector ou list.
  • Une queue (file) est un conteneur dont les éléments fonctionnent selon le principe FIFO (First In, First Out, premier entré, premier sorti) : les éléments sont insérés (ajoutés, ou pushed) à l'arrière du conteneur et retirés (ou popped) à l'avant. Les files utilisent par défaut deque, mais peuvent aussi utiliser list.
  • Une priority queue (file de priorité) est un type de file dont les éléments sont maintenus triés (via l'opérateur <). Lors de l'ajout d'un élément, celui-ci est placé à sa position triée dans la file. Retirer un élément en tête de file renvoie l'élément de plus haute priorité.
