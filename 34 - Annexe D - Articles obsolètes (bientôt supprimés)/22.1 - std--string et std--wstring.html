22.1 — std::string et std::wstring

La bibliothèque standard contient de nombreuses classes utiles, mais la plus utile est peut-être std::string. std::string (et std::wstring) est une classe de chaînes de caractères qui fournit de nombreuses opérations pour affecter, comparer et modifier des chaînes. Dans ce chapitre, nous allons étudier en profondeur ces classes de chaînes.

Remarque : les chaînes de style C seront appelées « chaînes de style C », tandis que std::string (et std::wstring) seront simplement appelées « chaînes ».

Motivation pour une classe de chaînes

Dans une leçon précédente, nous avons étudié les chaînes de style C, qui utilisent des tableaux de char pour stocker une suite de caractères. Si vous avez essayé de faire quoi que ce soit avec des chaînes de style C, vous avez très vite conclu qu'elles sont pénibles à manipuler, faciles à mal utiliser et difficiles à déboguer.

Les chaînes de style C présentent de nombreux inconvénients, principalement liés au fait que vous devez gérer vous-même toute la mémoire. Par exemple, si vous voulez affecter la chaîne « hello! » à un tampon, vous devez d'abord allouer dynamiquement un tampon de la bonne longueur :

char* strHello { new char[7] };

N'oubliez pas de prévoir un caractère supplémentaire pour le terminateur nul !

Ensuite, vous devez effectivement copier la valeur :

strcpy(strHello, "hello!");

Espérons que vous avez alloué un tampon suffisamment grand pour éviter tout dépassement de tampon !

Et bien sûr, comme la chaîne est allouée dynamiquement, vous devez penser à la désallouer correctement lorsque vous n'en avez plus besoin :

delete[] strHello;

N'oubliez pas d'utiliser delete[] pour tableau plutôt que delete simple !

De plus, de nombreux opérateurs intuitifs que le C fournit pour manipuler les nombres, comme l'affectation et les comparaisons, ne fonctionnent tout simplement pas avec les chaînes de style C. Parfois, ils semblent fonctionner mais produisent en réalité des résultats incorrects : par exemple, comparer deux chaînes de style C avec == effectue en fait une comparaison de pointeurs, et non une comparaison de chaînes. Affecter une chaîne de style C à une autre avec operator= semble fonctionner au début, mais effectue en réalité une copie de pointeur (copie superficielle), ce qui n'est généralement pas ce que vous voulez. Ce genre de choses peut provoquer des plantages de programme très difficiles à trouver et à déboguer !

En résumé, travailler avec des chaînes de style C exige de se souvenir de nombreuses règles minutieuses sur ce qui est sûr ou non, de mémoriser des fonctions aux noms curieux comme strcat() et strcmp() au lieu d'utiliser des opérateurs intuitifs, et de réaliser beaucoup de gestion mémoire manuelle.

Heureusement, C++ et la bibliothèque standard offrent une bien meilleure façon de traiter les chaînes : les classes std::string et std::wstring. En s'appuyant sur des concepts C++ comme les constructeurs, les destructeurs et la surcharge d'opérateurs, std::string vous permet de créer et de manipuler des chaînes de façon intuitive et sûre ! Plus de gestion mémoire, plus de noms de fonctions étranges, et un risque de catastrophe nettement réduit.

Vue d'ensemble des chaînes

Toutes les fonctionnalités de chaînes de la bibliothèque standard se trouvent dans le fichier d'en-tête <string>. Pour les utiliser, incluez simplement cet en-tête :

    #include <string>

Il existe en réalité 3 classes de chaînes différentes dans l'en-tête string. La première est une classe de base template nommée basic_string<> :

namespace std
{
    template<class charT, class traits = char_traits<charT>, class Allocator = allocator<charT> >
        class basic_string;
}

Vous ne travaillerez pas directement avec cette classe, donc ne vous inquiétez pas pour le moment de ce que sont traits ou Allocator. Les valeurs par défaut suffiront dans presque tous les cas imaginables.

La bibliothèque standard fournit deux variantes de basic_string<> :

namespace std
{
    typedef basic_string<char> string;
    typedef basic_string<wchar_t> wstring;
}

Ce sont les deux classes que vous utiliserez réellement. std::string sert pour les chaînes ASCII standard et UTF-8. std::wstring sert pour les chaînes à caractères larges / Unicode (UTF-16). Il n'existe pas de classe intégrée pour les chaînes UTF-32 (mais vous devriez pouvoir en créer une à partir de basic_string<> si vous en avez besoin).

Bien que vous utiliserez directement std::string et std::wstring, toute la fonctionnalité des chaînes est implémentée dans la classe basic_string<>. string et wstring accèdent directement à cette fonctionnalité grâce à leur nature template. Par conséquent, toutes les fonctions présentées fonctionneront aussi bien pour string que pour wstring. Cependant, comme basic_string est une classe template, le compilateur produira aussi des messages d'erreur de template très impressionnants lorsque vous écrirez quelque chose de syntaxiquement incorrect avec une string ou une wstring. Ne vous laissez pas intimider par ces erreurs : elles paraissent bien pires qu'elles ne le sont !

Bien que les classes de chaînes de la bibliothèque standard offrent beaucoup de fonctionnalités, quelques omissions notables existent :

  • Constructeurs permettant de créer des chaînes à partir de nombres
  • Fonctions de mise en majuscules / minuscules
  • Comparaisons insensibles à la casse
  • Découpage (tokenisation) d'une chaîne en tableau
  • Fonctions simples pour obtenir la partie gauche ou droite d'une chaîne
  • Suppression des espaces en début et en fin de chaîne
  • Formatage d'une chaîne à la manière de sprintf
  • Conversion de l'UTF-8 vers l'UTF-16 ou inversement

Pour la plupart de ces besoins, vous devrez soit écrire vos propres fonctions, soit convertir votre chaîne en chaîne de style C (à l'aide de c_str()) et utiliser les fonctions C qui offrent cette fonctionnalité.
