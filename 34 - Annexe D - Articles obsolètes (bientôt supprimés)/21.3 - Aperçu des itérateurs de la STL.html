21.3 — Aperçu des itérateurs de la STL

Un itérateur (iterator) est un objet capable de parcourir (itérer sur) une classe conteneur sans que l'utilisateur ait besoin de connaître son implémentation. Pour de nombreuses classes (en particulier les listes et les classes associatives), les itérateurs sont le moyen principal d'accéder aux éléments de ces classes.

Un itérateur se représente au mieux comme un pointeur vers un élément donné du conteneur, accompagné d'un ensemble d'opérateurs surchargés fournissant un ensemble de fonctions bien définies :

  • Operator* -- Déréférencer l'itérateur renvoie l'élément que l'itérateur pointe actuellement.
  • Operator++ -- Déplace l'itérateur vers l'élément suivant du conteneur. La plupart des itérateurs fournissent également Operator-- pour revenir à l'élément précédent.
  • Operator== et Operator!= -- Opérateurs de comparaison de base permettant de déterminer si deux itérateurs pointent vers le même élément. Pour comparer les valeurs pointées par deux itérateurs, il faut d'abord les déréférencer, puis utiliser un opérateur de comparaison.
  • Operator= -- Affecte à l'itérateur une nouvelle position (généralement le début ou la fin des éléments du conteneur). Pour affecter la valeur de l'élément pointé par l'itérateur, il faut d'abord le déréférencer, puis utiliser l'opérateur d'affectation.

Chaque conteneur propose quatre fonctions membres de base à utiliser avec Operator= :

  • begin() renvoie un itérateur représentant le début des éléments du conteneur.
  • end() renvoie un itérateur représentant l'élément juste après la fin des éléments.
  • cbegin() renvoie un itérateur constant (en lecture seule) représentant le début des éléments du conteneur.
  • cend() renvoie un itérateur constant (en lecture seule) représentant l'élément juste après la fin des éléments.

Il peut sembler étrange que end() ne pointe pas sur le dernier élément de la liste, mais cela est fait principalement pour faciliter les boucles : on peut itérer sur les éléments jusqu'à ce que l'itérateur atteigne end(), et on sait alors que c'est terminé.

Enfin, tous les conteneurs fournissent (au minimum) deux types d'itérateurs :

  • container::iterator fournit un itérateur en lecture/écriture.
  • container::const_iterator fournit un itérateur en lecture seule.

Voyons quelques exemples d'utilisation des itérateurs.

Parcourir un vector

#include <iostream>
#include <vector>

int main()
{
    std::vector<int> vect;
    for (int count=0; count < 6; ++count)
        vect.push_back(count);

    std::vector<int>::const_iterator it; // déclare un itérateur en lecture seule
    it = vect.cbegin(); // l'affecte au début du vector
    while (it != vect.cend()) // tant qu'on n'a pas atteint la fin
    {
        std::cout << *it << ' '; // affiche la valeur de l'élément pointé
        ++it; // puis passe à l'élément suivant
    }

    std::cout << '\n';
}

Ce programme affiche :


0 1 2 3 4 5

Parcourir une list

Faisons maintenant la même chose avec une list :

#include <iostream>
#include <list>

int main()
{

    std::list<int> li;
    for (int count=0; count < 6; ++count)
        li.push_back(count);

    std::list<int>::const_iterator it; // déclare un itérateur
    it = li.cbegin(); // l'affecte au début de la list
    while (it != li.cend()) // tant qu'on n'a pas atteint la fin
    {
        std::cout << *it << ' '; // affiche la valeur de l'élément pointé
        ++it; // puis passe à l'élément suivant
    }

    std::cout << '\n';
}

Ce programme affiche :


0 1 2 3 4 5

Remarquez que le code est presque identique au cas du vector, alors que vector et list ont des implémentations internes presque totalement différentes !

Parcourir un set

Dans l'exemple suivant, nous créons un set à partir de 6 nombres et utilisons un itérateur pour afficher les valeurs du set :

#include <iostream>
#include <set>

int main()
{
    std::set<int> myset;
    myset.insert(7);
    myset.insert(2);
    myset.insert(-6);
    myset.insert(8);
    myset.insert(1);
    myset.insert(-4);

    std::set<int>::const_iterator it; // déclare un itérateur
    it = myset.cbegin(); // l'affecte au début du set
    while (it != myset.cend()) // tant qu'on n'a pas atteint la fin
    {
        std::cout << *it << ' '; // affiche la valeur de l'élément pointé
        ++it; // puis passe à l'élément suivant
    }

    std::cout << '\n';
}

Ce programme produit le résultat suivant :


-6 -4 1 2 7 8

Notez que, bien que le remplissage du set diffère de celui du vector et de la list, le code utilisé pour parcourir les éléments du set est essentiellement identique.

Parcourir une map

Cet exemple est un peu plus délicat. Les map et multimap manipulent des paires d'éléments (définies comme std::pair). Nous utilisons la fonction utilitaire make_pair() pour créer facilement des paires. std::pair permet d'accéder aux éléments de la paire via les membres first et second. Dans notre map, nous utilisons first comme clé et second comme valeur.

#include <iostream>
#include <map>
#include <string>

int main()
{
    std::map<int, std::string> mymap;
    mymap.insert(std::make_pair(4, "apple"));
    mymap.insert(std::make_pair(2, "orange"));
    mymap.insert(std::make_pair(1, "banana"));
    mymap.insert(std::make_pair(3, "grapes"));
    mymap.insert(std::make_pair(6, "mango"));
    mymap.insert(std::make_pair(5, "peach"));

    auto it{ mymap.cbegin() }; // déclare un itérateur constant et l'affecte au début de la map
    while (it != mymap.cend()) // tant qu'on n'a pas atteint la fin
    {
        std::cout << it->first << '=' << it->second << ' '; // affiche la valeur de l'élément pointé
        ++it; // puis passe à l'élément suivant
    }

    std::cout << '\n';
}

Ce programme produit le résultat :


1=banana 2=orange 3=grapes 4=apple 5=peach 6=mango

Remarquez à quel point les itérateurs facilitent le parcours de chacun des éléments du conteneur. Vous n'avez absolument pas à vous soucier de la manière dont la map stocke ses données !

Conclusion

Les itérateurs offrent un moyen simple de parcourir les éléments d'une classe conteneur sans avoir à comprendre comment elle est implémentée. Combinés aux algorithmes de la STL et aux fonctions membres des classes conteneurs, ils deviennent encore plus puissants. Dans la prochaine leçon, vous verrez un exemple d'utilisation d'un itérateur pour insérer des éléments dans une list (qui ne fournit pas d'operator[] surchargé pour accéder directement à ses éléments).

Un point important à noter : les itérateurs doivent être implémentés classe par classe, car l'itérateur doit connaître le fonctionnement interne de la classe. Les itérateurs sont donc toujours liés à des classes conteneurs spécifiques.
