22.4 — Accès aux caractères de std::string et conversion vers des tableaux de style C

Accès aux caractères

Il existe deux façons quasiment identiques d'accéder aux caractères d'une chaîne. La version la plus simple à utiliser et la plus rapide est l'opérateur surchargé operator[] :

| | | --- | | char& string::operator[] (size_type nIndex) const char& string::operator[] (size_type nIndex) const - Ces deux fonctions renvoient le caractère d'indice nIndex- Passer un indice invalide entraîne un comportement indéfini- Comme le type de retour est char&, vous pouvez utiliser ce mécanisme pour modifier les caractères du tableau Exemple de code : cpp std::string sSource{ "abcdefg" }; std::cout << sSource[5] << '\n'; sSource[5] = 'X'; std::cout << sSource << '\n'; Sortie : f abcdeXg |

Il existe aussi une version qui n'est pas un opérateur. Cette version est plus lente, car elle utilise des exceptions pour vérifier si nIndex est valide. Si vous n'êtes pas certain que nIndex soit valide, vous devriez utiliser cette version pour accéder au tableau :

| | | --- | | char& string::at (size_type nIndex) const char& string::at (size_type nIndex) const - Ces deux fonctions renvoient le caractère d'indice nIndex- Passer un indice invalide entraîne une exception out_of_range- Comme le type de retour est char&, vous pouvez utiliser ce mécanisme pour modifier les caractères du tableau Exemple de code : cpp std::string sSource{ "abcdefg" }; std::cout << sSource.at(5) << '\n'; sSource.at(5) = 'X'; std::cout << sSource << '\n'; Sortie : f abcdeXg |

Conversion vers des tableaux de style C

De nombreuses fonctions (y compris toutes les fonctions du C) attendent que les chaînes soient au format de chaînes de style C plutôt que sous forme de std::string. C'est pourquoi std::string fournit 3 façons différentes de convertir une std::string en chaîne de style C.
const char string::c_str () const* - Renvoie le contenu de la chaîne sous la forme d'une chaîne de style C constante- Un caractère nul de fin est ajouté- La chaîne de style C appartient à la std::string et ne doit pas être supprimée Exemple de code : ```cpp #include

std::string sSource{ "abcdefg" }; std::cout << std::strlen(sSource.c_str()); Sortie : 7 ``` |
const char string::data () const* - Renvoie le contenu de la chaîne sous la forme d'une chaîne de style C constante- Un caractère nul de fin est ajouté. Cette fonction effectue la même action que c_str()- La chaîne de style C appartient à la std::string et ne doit pas être supprimée Exemple de code : ```cpp #include

std::string sSource{ "abcdefg" }; const char* szString{ "abcdefg" }; // memcmp compares the first n characters of two C-style strings and returns 0 if they are equal if (std::memcmp(sSource.data(), szString, sSource.length()) == 0) std::cout << "The strings are equal"; else std::cout << "The strings are not equal"; Sortie : The strings are equal ``` |
size_type string::copy(char szBuf, size_type nLength, size_type nIndex = 0) const* - Les deux variantes copient au plus nLength caractères de la chaîne dans szBuf, à partir du caractère d'indice nIndex- Le nombre de caractères copiés est renvoyé- Aucun caractère nul n'est ajouté. Il incombe à l'appelant de s'assurer que szBuf est initialisé à NULL ou de terminer la chaîne à l'aide de la longueur renvoyée- L'appelant est responsable de ne pas dépasser la taille de szBuf Exemple de code : ```cpp std::string sSource{ "sphinx of black quartz, judge my vow" };

char szBuf[20]; int nLength{ static_cast(sSource.copy(szBuf, 5, 10)) }; szBuf[nLength] = '\0'; // Make sure we terminate the string in the buffer

std::cout << szBuf << '\n'; Sortie : black ``` |

Cette fonction doit être évitée dans la mesure du possible, car elle est relativement dangereuse (il incombe à l'appelant de fournir le caractère nul de fin et d'éviter les dépassements de tampon).
