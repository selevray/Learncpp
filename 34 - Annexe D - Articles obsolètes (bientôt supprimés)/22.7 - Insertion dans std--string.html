22.7 — Insertion dans std::string

Insertion

Vous pouvez insérer des caractères dans une chaîne existante à l'aide de la fonction insert().

| | | --- | | string& string::insert (size_type index, const string& str) string& string::insert (size_type index, const char str)* - Les deux fonctions insèrent les caractères de str dans la chaîne à partir de l'indice index.- Les deux fonctions renvoient *this, ce qui permet de les « chaîner ».- Les deux fonctions lèvent une exception out_of_range si index est invalide.- Les deux fonctions lèvent une exception length_error si le résultat dépasse le nombre maximal de caractères.- Dans la version à chaîne de style C, str ne doit pas être NULL. Exemple de code : ```cpp string sString("aaaa"); cout << sString << endl;

sString.insert(2, string("bbbb")); cout << sString << endl;

sString.insert(4, "cccc"); cout << sString << endl; Sortie : aaaa aabbbbaa aabbccccbbaa ``` |

Voici une version plus élaborée de insert() qui permet d'insérer une sous-chaîne dans une chaîne à un indice quelconque :
string& string::insert (size_type index, const string& str, size_type startindex, size_type num) - Cette fonction insère num caractères de str, à partir de startindex, dans la chaîne à l'indice index.- Renvoie *this, ce qui permet de la « chaîner ».- Lève une exception out_of_range si index ou startindex est hors limites.- Lève une exception length_error si le résultat dépasse le nombre maximal de caractères. Exemple de code : ```cpp string sString("aaaa");

const string sInsert("01234567"); sString.insert(2, sInsert, 3, 4); // insère la sous-chaîne de sInsert comprise dans les indices [3,7) dans sString à l'indice 2 cout << sString << endl; Sortie : aa3456aa ``` |

Il existe une variante de insert() qui insère le début d'une chaîne de style C :
string& string::insert(size_type index, const char str, size_type len)* - Insère len caractères de str dans la chaîne à l'indice index.- Renvoie *this, ce qui permet de la « chaîner ».- Lève une exception out_of_range si l'indice est invalide.- Lève une exception length_error si le résultat dépasse le nombre maximal de caractères.- Ignore les caractères spéciaux (comme ”) Exemple de code : ```cpp string sString("aaaa");

sString.insert(2, "bcdef", 3); cout << sString << endl; Sortie : aabcdaa ``` |

Il existe aussi une variante de insert() qui insère plusieurs fois le même caractère :
string& string::insert(size_type index, size_type num, char c) - Insère num occurrences du caractère c dans la chaîne à l'indice index.- Renvoie *this, ce qui permet de la « chaîner ».- Lève une exception out_of_range si l'indice est invalide.- Lève une exception length_error si le résultat dépasse le nombre maximal de caractères. Exemple de code : ```cpp string sString("aaaa");

sString.insert(2, 4, 'c'); cout << sString << endl; Sortie : aaccccaa ``` |

Enfin, la fonction insert() dispose de trois variantes qui utilisent des itérateurs :
void insert(iterator it, size_type num, char c) iterator string::insert(iterator it, char c) void string::insert(iterator it, InputIterator begin, InputIterator end) - La première fonction insère num occurrences du caractère c avant l'itérateur it.- La deuxième insère un seul caractère c avant l'itérateur it, et renvoie un itérateur vers la position du caractère inséré.- La troisième insère tous les caractères de l'intervalle [begin,end) avant l'itérateur it.- Toutes ces fonctions lèvent une exception length_error si le résultat dépasse le nombre maximal de caractères.
