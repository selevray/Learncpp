18.1 — Trier un tableau avec le tri par sélection

Pourquoi trier

Trier un tableau consiste à disposer tous ses éléments selon un ordre donné.Il existe de nombreux cas où le tri d'un tableau est utile. Par exemple, votre programme de messagerie affiche généralement les courriels par ordre de réception, parce que les messages les plus récents sont en général considérés comme les plus pertinents. Lorsque vous ouvrez votre liste de contacts, les noms sont généralement classés par ordre alphabétique, car il est plus facile de trouver le nom recherché de cette façon. Dans les deux cas, les données sont triées avant d'être présentées.

Trier un tableau peut rendre sa recherche plus efficace, pas seulement pour les humains, mais aussi pour les ordinateurs. Prenons par exemple le cas où nous voulons savoir si un nom figure dans une liste de noms. Pour le savoir, il faudrait examiner chaque élément du tableau afin de voir si le nom s'y trouve. Pour un tableau comportant beaucoup d'éléments, parcourir l'ensemble peut être coûteux.

Supposons maintenant que notre tableau de noms soit trié par ordre alphabétique. Dans ce cas, il suffit de chercher jusqu'à rencontrer un nom alphabétiquement supérieur à celui recherché. À ce stade, si nous n'avons pas trouvé le nom, nous savons qu'il n'existe pas dans le reste du tableau, puisque tous les noms que nous n'avons pas encore examinés sont forcément alphabétiquement supérieurs !

Il existe même des algorithmes encore meilleurs pour rechercher dans un tableau trié. Avec un algorithme simple, nous pouvons chercher dans un tableau trié de 1 000 000 d'éléments en seulement 20 comparaisons ! L'inconvénient est bien sûr que le tri d'un tableau est relativement coûteux. Il n'est souvent pas rentable de trier un tableau pour accélérer la recherche, sauf si l'on doit effectuer de nombreuses recherches.

Dans certains cas, trier un tableau rend même la recherche inutile. Prenons un autre exemple, où nous voulons trouver la meilleure note à un test. Si le tableau n'est pas trié, il faut parcourir tous ses éléments pour trouver la note la plus élevée. Si la liste est triée, la meilleure note se trouve en première ou en dernière position (selon que nous avons trié par ordre croissant ou décroissant), et nous n'avons donc pas besoin de chercher du tout !

Fonctionnement du tri

Le tri consiste en général à comparer répétitivement des paires d'éléments du tableau et à les échanger si elles satisfont un critère prédéfini. L'ordre dans lequel les éléments sont comparés dépend de l'algorithme de tri utilisé. Le critère dépend quant à lui de l'ordre de tri souhaité (par exemple croissant ou décroissant).

Pour échanger deux éléments, nous pouvons utiliser la fonction std::swap() de la bibliothèque standard C++, définie dans l'en-tête utility.

#include <iostream>
#include <utility>

int main()
{
    int x{ 2 };
    int y{ 4 };
    std::cout << "Before swap: x = " << x << ", y = " << y << '\n';
    std::swap(x, y); // swap the values of x and y
    std::cout << "After swap:  x = " << x << ", y = " << y << '\n';

    return 0;
}

Ce programme affiche :


Before swap: x = 2, y = 4
After swap:  x = 4, y = 2

Notez qu'après l'échange, les valeurs de x et y ont été interverties !

Le tri par sélection

Il existe de nombreuses façons de trier un tableau. Le tri par sélection (selection sort) est sans doute le plus simple à comprendre, ce qui en fait un bon candidat pour l'enseignement, même s'il s'agit de l'un des tris les plus lents.

Le tri par sélection effectue les étapes suivantes pour trier un tableau du plus petit au plus grand :

  1. En commençant à l'indice 0 du tableau, parcourir tout le tableau pour trouver la plus petite valeur
  2. Échanger la plus petite valeur trouvée avec la valeur située à l'indice 0
  3. Répéter les étapes 1 et 2 à partir de l'indice suivant

Autrement dit, nous allons rechercher le plus petit élément du tableau et le placer en première position. Puis nous recherchons le deuxième plus petit élément et le plaçons en deuxième position. Ce processus se répète jusqu'à épuisement des éléments.

Voici un exemple de fonctionnement de cet algorithme sur 5 éléments. Partons d'un tableau de départ :

{ 30, 50, 20, 10, 40 }

Tout d'abord, nous cherchons le plus petit élément, à partir de l'indice 0 :

{ 30, 50, 20, 10, 40 }

Nous l'échangeons ensuite avec l'élément d'indice 0 :

{ 10, 50, 20, 30, 40 }

Le premier élément étant maintenant trié, nous pouvons l'ignorer. Cherchons à présent le plus petit élément, à partir de l'indice 1 :

{ 10, 50, 20, 30, 40 }

Et échangeons-le avec l'élément d'indice 1 :

{ 10, 20, 50, 30, 40 }

Nous pouvons maintenant ignorer les deux premiers éléments. Cherchons le plus petit élément à partir de l'indice 2 :

{ 10, 20, 50, 30, 40 }

Et échangeons-le avec l'élément d'indice 2 :

{ 10, 20, 30, 50, 40 }

Cherchons le plus petit élément à partir de l'indice 3 :

{ 10, 20, 30, 50, 40 }

Et échangeons-le avec l'élément d'indice 3 :

{ 10, 20, 30, 40, 50 }

Enfin, cherchons le plus petit élément à partir de l'indice 4 :

{ 10, 20, 30, 40, 50 }

Et échangeons-le avec l'élément d'indice 4 (ce qui ne change rien) :

{ 10, 20, 30, 40, 50 }

Terminé !

{ 10, 20, 30, 40, 50 }

Notez que la dernière comparaison se fait toujours avec l'élément lui-même (ce qui est redondant). On peut donc en réalité s'arrêter un élément avant la fin du tableau.

Le tri par sélection en C++

Voici comment cet algorithme s'implémente en C++ :

#include <iostream>
#include <iterator>
#include <utility>

int main()
{
    int array[]{ 30, 50, 20, 10, 40 };
    constexpr int length{ static_cast<int>(std::size(array)) };

    // Parcourir chaque élément du tableau
    // (sauf le dernier, qui sera déjà trié à ce moment-là)
    for (int startIndex{ 0 }; startIndex < length - 1; ++startIndex)
    {
        // smallestIndex est l'indice du plus petit élément rencontré dans cette itération
        // On suppose d'abord que le plus petit élément est le premier de cette itération
        int smallestIndex{ startIndex };

        // Chercher ensuite un élément plus petit dans le reste du tableau
        for (int currentIndex{ startIndex + 1 }; currentIndex < length; ++currentIndex)
        {
            // Si on a trouvé un élément plus petit que le plus petit trouvé précédemment
            if (array[currentIndex] < array[smallestIndex])
                // alors on mémorise son indice
                smallestIndex = currentIndex;
        }

        // smallestIndex est maintenant l'indice du plus petit élément du reste du tableau
                // on échange l'élément de départ avec le plus petit (il est ainsi placé à sa position définitive)
        std::swap(array[startIndex], array[smallestIndex]);
    }

    // Le tableau entier étant trié, on affiche le résultat pour prouver que cela fonctionne
    for (int index{ 0 }; index < length; ++index)
        std::cout << array[index] << ' ';

    std::cout << '\n';

    return 0;
}

La partie la plus déroutante de cet algorithme est la boucle imbriquée dans une autre boucle (appelée boucle imbriquée). La boucle externe (startIndex) parcourt les éléments un par un. À chaque itération de la boucle externe, la boucle interne (currentIndex) sert à trouver le plus petit élément du reste du tableau (à partir de startIndex + 1). smallestIndex mémorise l'indice du plus petit élément trouvé par la boucle interne. Ensuite, smallestIndex est échangé avec startIndex. Enfin, la boucle externe (startIndex) avance d'un élément, et le processus se répète.

Indice : si vous avez du mal à comprendre le fonctionnement du programme ci-dessus, il peut être utile de dérouler un exemple sur une feuille de papier. Écrivez horizontalement les éléments du tableau non trié en haut de la feuille. Tracez des flèches indiquant les éléments désignés par startIndex, currentIndex et smallestIndex. Exécutez le programme à la main et redessinez les flèches à chaque changement d'indice. Pour chaque itération de la boucle externe, commencez une nouvelle ligne montrant l'état actuel du tableau.

Le tri de noms utilise le même algorithme. Il suffit de remplacer le type du tableau int par std::string et de l'initialiser avec les valeurs appropriées.

std::sort

Le tri de tableaux étant très courant, la bibliothèque standard C++ fournit une fonction de tri nommée std::sort. std::sort se trouve dans l'en-tête <algorithm> et s'utilise sur un tableau de la façon suivante :

#include <algorithm> // pour std::sort
#include <iostream>
#include <iterator> // pour std::size

int main()
{
    int array[]{ 30, 50, 20, 10, 40 };

    std::sort(std::begin(array), std::end(array));

    for (int i{ 0 }; i < static_cast<int>(std::size(array)); ++i)
        std::cout << array[i] << ' ';

    std::cout << '\n';

    return 0;
}

Par défaut, std::sort trie par ordre croissant en utilisant operator< pour comparer des paires d'éléments et les échanger si nécessaire (un peu comme le fait notre exemple de tri par sélection ci-dessus).

Nous reparlerons de std::sort dans un prochain chapitre.

Question n° 2

Réécrivez le code du tri par sélection ci-dessus pour trier par ordre décroissant (les plus grands nombres en premier). Bien que cela semble complexe, c'est en réalité étonnamment simple.

Solution

Il suffit de remplacer :

        if (array[currentIndex] < array[smallestIndex])

par :

        if (array[currentIndex] > array[smallestIndex])

Il serait également judicieux de renommer smallestIndex en largestIndex.

#include <iostream>
#include <iterator> // pour std::size
#include <utility>

int main()
{
    int array[]{ 30, 50, 20, 10, 40 };
    constexpr int length{ static_cast<int>(std::size(array)) }; // C++17
//  constexpr int length{ sizeof(array) / sizeof(array[0]) }; // à utiliser à la place si le compilateur n'est pas compatible C++17

    // Parcourir chaque élément du tableau sauf le dernier
    for (int startIndex{ 0 }; startIndex < length - 1; ++startIndex)
    {
        // largestIndex est l'indice du plus grand élément rencontré jusqu'à présent.
        int largestIndex{ startIndex };

        // Parcourir chaque élément à partir de startIndex + 1
        for (int currentIndex{ startIndex + 1 }; currentIndex < length; ++currentIndex)
        {
            // Si l'élément courant est plus grand que le plus grand trouvé précédemment
            if (array[currentIndex] > array[largestIndex])
                // C'est le nouveau plus grand nombre de cette itération
                largestIndex = currentIndex;
        }

        // Échanger notre élément de départ avec le plus grand
        std::swap(array[startIndex], array[largestIndex]);
    }

    // Afficher le tableau trié pour prouver que cela fonctionne
    for (int index{ 0 }; index < length; ++index)
        std::cout << array[index] << ' ';

    std::cout << '\n';

    return 0;
}

Question n° 3

Celle-ci sera difficile, préparez-vous.

Un autre tri simple est appelé « tri à bulles » (bubble sort). Le tri à bulles fonctionne en comparant des paires d'éléments adjacents et en les échangeant si le critère est satisfait, de sorte que les éléments « remontent » vers la fin du tableau. Il existe plusieurs façons d'optimiser le tri à bulles, mais dans cet exercice, nous nous en tiendrons à la version non optimisée, car c'est la plus simple.

Le tri à bulles non optimisé effectue les étapes suivantes pour trier un tableau du plus petit au plus grand : A) Comparer l'élément d'indice 0 avec l'élément d'indice 1. Si l'élément 0 est plus grand, l'échanger avec l'élément 1. B) Faire de même pour les éléments 1 et 2, puis pour chaque paire suivante jusqu'à atteindre la fin du tableau. À ce stade, le dernier élément du tableau est trié. C) Répéter les deux premières étapes jusqu'à ce que le tableau soit trié.

Écrivez un programme qui trie par bulles le tableau suivant selon les règles ci-dessus :

int array[]{ 6, 3, 2, 9, 7, 1, 5, 4, 8 };

Affichez les éléments triés du tableau à la fin de votre programme.

Indice : si l'on peut placer un élément à sa position définitive à chaque itération, il faut itérer à peu près autant de fois qu'il y a de nombres dans le tableau pour garantir son tri complet. Indice : lors de la comparaison de paires d'éléments, faites attention aux bornes de votre tableau.

Solution 
#include <iostream>
#include <iterator> // pour std::size
#include <utility>

int main()
{
    int array[]{ 6, 3, 2, 9, 7, 1, 5, 4, 8 };
    constexpr int length{ static_cast<int>(std::size(array)) }; // C++17
//  constexpr int length{ sizeof(array) / sizeof(array[0]) }; // à utiliser à la place si le compilateur n'est pas compatible C++17

    // Parcourir chaque élément du tableau (sauf le dernier, qui sera déjà trié à ce moment-là)
    for (int iteration{ 0 }; iteration < length-1; ++iteration)
    {
        // Parcourir tous les éléments jusqu'à la fin du tableau - 1
        // Le dernier élément n'a pas de paire avec laquelle être comparé
        for (int currentIndex{ 0 }; currentIndex < length - 1; ++currentIndex)
        {
            // Si l'élément courant est plus grand que l'élément suivant, on les échange
            if (array[currentIndex] > array[currentIndex+1])
                std::swap(array[currentIndex], array[currentIndex + 1]);
        }
    }

    // Afficher le tableau trié pour prouver que cela fonctionne
    for (int index{ 0 }; index < length; ++index)
        std::cout << array[index] << ' ';

    std::cout << '\n';

    return 0;
}

Question n° 4

Ajoutez deux optimisations à l'algorithme du tri à bulles que vous avez écrit à la question précédente :

  • Remarquez qu'à chaque itération du tri à bulles, le plus grand nombre restant remonte à la fin du tableau. Après la première itération, le dernier élément du tableau est trié. Après la deuxième itération, l'avant-dernier élément est également trié. Et ainsi de suite… À chaque itération, il n'est pas nécessaire de revérifier les éléments dont on sait déjà qu'ils sont triés. Modifiez votre boucle pour ne plus revérifier les éléments déjà triés.
  • Si une itération complète s'effectue sans aucun échange, alors on sait que le tableau est déjà trié. Ajoutez un test pour déterminer si des échanges ont eu lieu pendant l'itération et, si ce n'est pas le cas, interrompez la boucle prématurément. Si la boucle est interrompue prématurément, affichez le numéro de l'itération à laquelle le tri s'est terminé.

Votre sortie doit correspondre à ceci :


Early termination on iteration 6
1 2 3 4 5 6 7 8 9
Solution 
#include <iostream>
#include <iterator> // pour std::size
#include <utility>

int main()
{
    int array[]{ 6, 3, 2, 9, 7, 1, 5, 4, 8 };
    constexpr int length{ static_cast<int>(std::size(array)) }; // C++17
//  constexpr int length{ sizeof(array) / sizeof(array[0]) }; // à utiliser à la place si le compilateur n'est pas compatible C++17

    // Parcourir chaque élément du tableau sauf le dernier
    for (int iteration{ 0 }; iteration < length-1; ++iteration)
    {
        // Le dernier élément étant déjà trié à chaque itération suivante,
        // le tableau "se termine" un élément plus tôt
        int endOfArrayIndex{ length - iteration };

        bool swapped{ false }; // Mémorise si des éléments ont été échangés pendant cette itération

        // Parcourir tous les éléments jusqu'à la fin du tableau - 1
        // Le dernier élément n'a pas de paire avec laquelle être comparé
        for (int currentIndex{ 0 }; currentIndex < endOfArrayIndex - 1; ++currentIndex)
        {
            // Si l'élément courant est plus grand que l'élément suivant
            if (array[currentIndex] > array[currentIndex + 1])
            {
                // On les échange
                std::swap(array[currentIndex], array[currentIndex + 1]);
                swapped = true;
            }
        }

        // Si aucun élément n'a été échangé pendant cette itération, on a terminé plus tôt
        if (!swapped)
        {
            // iteration est indexé à partir de 0, alors que le comptage des itérations commence à 1. On ajoute donc 1 ici.
            std::cout << "Early termination on iteration: " << iteration+1 << '\n';
            break;
        }
    }

    // Afficher le tableau trié pour prouver que cela fonctionne
    for (int index{ 0 }; index < length; ++index)
        std::cout << array[index] << ' ';

    std::cout << '\n';

    return 0;
}
