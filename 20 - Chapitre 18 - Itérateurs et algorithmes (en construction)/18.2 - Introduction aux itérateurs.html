18.2 — Introduction aux itérateurs

Parcourir un tableau (ou une autre structure) de données est une opération très courante en programmation. Jusqu'ici, nous avons vu plusieurs façons de le faire : avec des boucles et un indice (boucles for et while), avec des pointeurs et l'arithmétique des pointeurs, et avec les boucles for basées sur un intervalle (range-based for-loops) :

#include <array>
#include <cstddef>
#include <iostream>

int main()
{
    // En C++17, le type de la variable arr est déduit comme std::array<int, 7>
    // Si vous obtenez une erreur de compilation avec cet exemple, voir l'avertissement ci-dessous
    std::array arr{ 0, 1, 2, 3, 4, 5, 6 };
    std::size_t length{ std::size(arr) };

    // boucle while avec indice explicite
    std::size_t index{ 0 };
    while (index < length)
    {
        std::cout << arr[index] << ' ';
        ++index;
    }
    std::cout << '\n';

    // boucle for avec indice explicite
    for (index = 0; index < length; ++index)
    {
        std::cout << arr[index] << ' ';
    }
    std::cout << '\n';

    // boucle for avec pointeur (Remarque : ptr ne peut pas être const, car nous l'incrémentons)
    for (auto ptr{ &arr[0] }; ptr != (&arr[0] + length); ++ptr)
    {
        std::cout << *ptr << ' ';
    }
    std::cout << '\n';

    // boucle for basée sur un intervalle
    for (int i : arr)
    {
        std::cout << i << ' ';
    }
    std::cout << '\n';

    return 0;
}

Attention

Les exemples de cette leçon utilisent une fonctionnalité de C++17 appelée class template argument deduction, qui permet de déduire les arguments de modèle d'une variable à partir de son initialiseur. Dans l'exemple ci-dessus, lorsque le compilateur rencontre std::array arr{ 0, 1, 2, 3, 4, 5, 6 };, il déduit que nous voulons std::array<int, 7> arr { 0, 1, 2, 3, 4, 5, 6 };.

Si votre compilateur n'est pas configuré pour C++17, vous obtiendrez une erreur du type « missing template arguments before 'arr' ». Dans ce cas, le plus simple est d'activer C++17, comme expliqué dans la leçon 0.12 -- Configurer votre compilateur : choisir une norme du langage. Si ce n'est pas possible, vous pouvez remplacer les lignes utilisant la déduction d'arguments de modèle par des lignes avec des arguments explicites (par exemple, remplacer std::array arr{ 0, 1, 2, 3, 4, 5, 6 }; par std::array<int, 7> arr { 0, 1, 2, 3, 4, 5, 6 };).

Parcourir un tableau à l'aide d'indices demande plus de frappe que nécessaire si l'on n'utilise l'indice que pour accéder aux éléments. Cette méthode ne fonctionne en outre que si le conteneur (par exemple le tableau) permet un accès direct aux éléments, ce que font les tableaux, mais pas certains autres conteneurs, comme les listes.

Parcourir avec des pointeurs et l'arithmétique des pointeurs est verbeux, et peut dérouter les lecteurs qui ne connaissent pas les règles de l'arithmétique des pointeurs. Cette arithmétique ne fonctionne par ailleurs que si les éléments sont consécutifs en mémoire, ce qui est vrai pour les tableaux, mais pas pour d'autres conteneurs, comme les listes, les arbres et les dictionnaires (maps).

Pour les lecteurs avancés

Les pointeurs (sans arithmétique des pointeurs) peuvent aussi servir à parcourir certaines structures non séquentielles. Dans une liste chaînée, chaque élément est relié à l'élément précédent par un pointeur. On peut parcourir la liste en suivant la chaîne de pointeurs.

Les boucles for basées sur un intervalle sont plus intéressantes, car le mécanisme de parcours du conteneur est masqué, et pourtant elles fonctionnent avec toutes sortes de structures (tableaux, listes, arbres, dictionnaires, etc.). Comment cela fonctionne-t-il ? Elles utilisent des itérateurs.

Les itérateurs

Un itérateur (iterator) est un objet conçu pour parcourir un conteneur (par exemple les valeurs d'un tableau, ou les caractères d'une chaîne), en donnant accès à chaque élément au passage.

Un conteneur peut fournir différents types d'itérateurs. Par exemple, un conteneur tableau peut offrir un itérateur avant (forward iterator) qui parcourt le tableau dans l'ordre, et un itérateur inverse (reverse iterator) qui le parcourt dans l'ordre inverse.

Une fois le type d'itérateur approprié créé, le programmeur peut utiliser l'interface de l'itérateur pour parcourir et accéder aux éléments, sans se soucier du type de parcours effectué ni de la façon dont les données sont stockées dans le conteneur. Et comme les itérateurs C++ utilisent généralement la même interface pour le parcours (operator++ pour passer à l'élément suivant) et pour l'accès (operator* pour accéder à l'élément courant), nous pouvons parcourir une grande variété de conteneurs de manière uniforme.

Les pointeurs comme itérateurs

L'itérateur le plus simple est le pointeur, qui (grâce à l'arithmétique des pointeurs) fonctionne pour des données stockées séquentiellement en mémoire. Reprenons un parcours simple de tableau avec un pointeur et l'arithmétique des pointeurs :

#include <array>
#include <iostream>

int main()
{
    std::array arr{ 0, 1, 2, 3, 4, 5, 6 };

    auto begin{ &arr[0] };
    // notez que ceci pointe un emplacement après le dernier élément
    auto end{ begin + std::size(arr) };

    // boucle for avec pointeur
    for (auto ptr{ begin }; ptr != end; ++ptr) // ++ pour passer à l'élément suivant
    {
        std::cout << *ptr << ' '; // Déréférencement pour obtenir la valeur de l'élément courant
    }
    std::cout << '\n';

    return 0;
}

Sortie :


0 1 2 3 4 5 6

Dans le code ci-dessus, nous avons défini deux variables : begin (qui pointe sur le début du conteneur) et end (qui marque la fin). Pour les tableaux, le marqueur de fin est généralement l'emplacement mémoire où se trouverait le dernier élément si le conteneur en contenait un de plus.

Le pointeur parcourt alors l'intervalle entre begin et end, et l'élément courant est accessible en déréférençant le pointeur.

Attention

Vous pourriez être tenté de calculer le marqueur de fin avec l'opérateur d'adresse et la syntaxe de tableau, ainsi :

int* end{ &arr[std::size(arr)] };

Mais cela provoque un comportement indéfini, car arr[std::size(arr)] déréférence implicitement un élément situé après la fin du tableau.

Utilisez plutôt :

int* end{ arr.data() + std::size(arr) }; // data() renvoie un pointeur vers le premier élément

Les itérateurs de la bibliothèque standard

Le parcours étant une opération si courante, tous les conteneurs de la bibliothèque standard offrent un support direct de l'itération. Plutôt que de calculer nous-mêmes les points de début et de fin, nous pouvons demander au conteneur ces points via les fonctions membres begin() et end() :

#include <array>
#include <iostream>

int main()
{
    std::array array{ 1, 2, 3 };

    // Demander à notre tableau les points de début et de fin (via les fonctions membres begin et end).
    auto begin{ array.begin() };
    auto end{ array.end() };

    for (auto p{ begin }; p != end; ++p) // ++ pour passer à l'élément suivant.
    {
        std::cout << *p << ' '; // Déréférencement pour obtenir la valeur de l'élément courant.
    }
    std::cout << '\n';

    return 0;
}

Ce programme affiche :


1 2 3

L'en-tête iterator contient aussi deux fonctions génériques (std::begin et std::end) que l'on peut utiliser.

Astuce

std::begin et std::end pour les tableaux de style C sont définies dans l'en-tête <iterator>.

std::begin et std::end pour les conteneurs qui prennent en charge les itérateurs sont définies dans les fichiers d'en-tête de ces conteneurs (par exemple <array>, <vector>).

#include <array>    // inclut <iterator>
#include <iostream>

int main()
{
    std::array array{ 1, 2, 3 };

    // Utiliser std::begin et std::end pour obtenir les points de début et de fin.
    auto begin{ std::begin(array) };
    auto end{ std::end(array) };

    for (auto p{ begin }; p != end; ++p) // ++ pour passer à l'élément suivant
    {
        std::cout << *p << ' '; // Déréférencement pour obtenir la valeur de l'élément courant
    }
    std::cout << '\n';

    return 0;
}

Ce programme affiche également :


1 2 3

Ne vous souciez pas pour l'instant des types des itérateurs : nous reverrons les itérateurs dans un chapitre ultérieur. L'essentiel est que l'itérateur prend en charge les détails du parcours du conteneur. Il nous suffit de quatre éléments : le point de début, le point de fin, operator++ pour faire avancer l'itérateur vers l'élément suivant (ou la fin), et operator* pour obtenir la valeur de l'élément courant.

operator< ou operator!= pour les itérateurs

Dans la leçon 8.10 -- Les boucles for, nous avons indiqué que operator< était préférable à operator!= pour les comparaisons numériques dans la condition de boucle :

    for (index = 0; index < length; ++index)

Avec les itérateurs, il est d'usage d'utiliser operator!= pour tester si l'itérateur a atteint l'élément de fin :

    for (auto p{ begin }; p != end; ++p)

En effet, certains types d'itérateurs ne sont pas comparables par relation d'ordre. operator!= fonctionne avec tous les types d'itérateurs.

Retour aux boucles for basées sur un intervalle

Tous les types qui possèdent les fonctions membres begin() et end(), ou qui peuvent être utilisés avec std::begin() et std::end(), sont utilisables dans une boucle for basée sur un intervalle.

#include <array>
#include <iostream>

int main()
{
    std::array array{ 1, 2, 3 };

    // Ceci fait exactement la même chose que la boucle utilisée précédemment.
    for (int i : array)
    {
        std::cout << i << ' ';
    }
    std::cout << '\n';

    return 0;
}

En coulisse, la boucle basée sur un intervalle appelle begin() et end() du type à parcourir. std::array possède les fonctions membres begin et end, on peut donc l'utiliser dans une boucle basée sur un intervalle. Les tableaux fixes de style C peuvent être utilisés avec les fonctions std::begin et std::end, on peut donc aussi les parcourir avec une telle boucle. En revanche, les tableaux dynamiques de style C (ou les tableaux de style C ayant perdu leur type, par décroissance en pointeur) ne fonctionnent pas, car il n'existe pas de fonction std::end pour eux (le type ne contient pas la longueur du tableau).

Vous apprendrez plus tard à ajouter ces fonctions à vos propres types, afin qu'ils puissent aussi être utilisés avec les boucles basées sur un intervalle.

Les boucles basées sur un intervalle ne sont pas la seule chose à utiliser les itérateurs. Ils sont aussi employés par std::sort et d'autres algorithmes. Maintenant que vous savez ce qu'ils sont, vous les remarquerez souvent dans la bibliothèque standard.

Invalidation des itérateurs (itérateurs pendants)

Comme les pointeurs et les références, les itérateurs peuvent devenir « pendants » si les éléments parcourus changent d'adresse ou sont détruits. On dit alors que l'itérateur a été invalidé. Accéder à un itérateur invalidé provoque un comportement indéfini.

Certaines opérations qui modifient un conteneur (comme l'ajout d'un élément dans un std::vector) peuvent avoir pour effet de déplacer les éléments du conteneur à d'autres adresses. Dans ce cas, les itérateurs existants vers ces éléments sont invalidés. Une bonne documentation de référence C++ indique quelles opérations peuvent ou vont invalider les itérateurs. Par exemple, consultez la section « Iterator invalidation » de std::vector sur cppreference.

Comme les boucles basées sur un intervalle utilisent des itérateurs en coulisse, nous devons veiller à ne rien faire qui invalide les itérateurs du conteneur que nous parcourons :

#include <vector>

int main()
{
    std::vector v { 0, 1, 2, 3 };

    for (auto num : v) // parcourt implicitement v
    {
        if (num % 2 == 0)
            v.push_back(num + 1); // ceci invalide les itérateurs de v : comportement indéfini
    }

    return 0;
}

Voici un autre exemple d'invalidation d'itérateur :

#include <iostream>
#include <vector>

int main()
{
    std::vector v{ 1, 2, 3, 4, 5, 6, 7 };

    auto it{ v.begin() };

    ++it; // passe au deuxième élément
    std::cout << *it << '\n'; // ok : affiche 2

    v.erase(it); // supprime l'élément actuellement parcouru

    // erase() invalide les itérateurs vers l'élément supprimé (et les suivants)
    // donc l'itérateur « it » est maintenant invalidé

    ++it; // comportement indéfini
    std::cout << *it << '\n'; // comportement indéfini

    return 0;
}

Un itérateur invalidé peut être revalidé en lui affectant un itérateur valide (par exemple begin(), end(), ou la valeur de retour d'une autre fonction renvoyant un itérateur).

La fonction erase() renvoie un itérateur vers l'élément qui suit l'élément supprimé (ou end() si le dernier élément a été supprimé). Nous pouvons donc corriger le code ci-dessus ainsi :

#include <iostream>
#include <vector>

int main()
{
    std::vector v{ 1, 2, 3, 4, 5, 6, 7 };

    auto it{ v.begin() };

    ++it; // passe au deuxième élément
    std::cout << *it << '\n';

    it = v.erase(it); // supprime l'élément actuellement parcouru, et place `it` sur l'élément suivant

    std::cout << *it << '\n'; // maintenant correct, affiche 3

    return 0;
}
