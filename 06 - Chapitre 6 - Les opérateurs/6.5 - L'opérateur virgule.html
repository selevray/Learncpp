6.5 — L'opérateur virgule

Opérateur Symbole Forme Opération
Virgule , x, y Évalue x puis y, renvoie la valeur de y

L'opérateur virgule (,) vous permet d'évaluer plusieurs expressions à tout endroit où une seule expression est autorisée. L'opérateur virgule évalue l'opérande de gauche, puis l'opérande de droite, et renvoie ensuite le résultat de l'opérande de droite.

Par exemple :

#include <iostream>

int main()
{
    int x{ 1 };
    int y{ 2 };

    std::cout << (++x, ++y) << '\n'; // incrémente x et y, s'évalue à l'opérande de droite

    return 0;
}

D'abord, l'opérande de gauche de l'opérateur virgule est évalué, ce qui incrémente x de 1 à 2. Ensuite, l'opérande de droite est évalué, ce qui incrémente y de 2 à 3. L'opérateur virgule renvoie le résultat de l'opérande de droite (3), qui est ensuite affiché dans la console.

Notez que la virgule a la priorité la plus basse de tous les opérateurs, même inférieure à celle de l'affectation. Par conséquent, les deux lignes de code suivantes ne font pas la même chose :

z = (a, b); // évalue d'abord (a, b) pour obtenir le résultat de b, puis affecte cette valeur à la variable z.
z = a, b; // s'évalue comme « (z = a), b », donc z reçoit la valeur de a, et b est évalué puis ignoré.

Cela rend l'opérateur virgule quelque peu dangereux à utiliser.

Dans presque tous les cas, une instruction écrite à l'aide de l'opérateur virgule serait mieux écrite sous forme d'instructions séparées. Par exemple, le code ci-dessus pourrait être écrit ainsi :

#include <iostream>

int main()
{
    int x{ 1 };
    int y{ 2 };

    ++x;
    std::cout << ++y << '\n';

    return 0;
}

La plupart des programmeurs n'utilisent pas du tout l'opérateur virgule, à la seule exception des boucles for, où son utilisation est assez courante. Nous aborderons les boucles for dans une prochaine leçon : 8.10 -- Instructions for.

Bonne pratique

Évitez d'utiliser l'opérateur virgule, sauf dans les boucles for.

La virgule comme séparateur

En C++, le symbole virgule est souvent utilisé comme séparateur, et ces usages n'invoquent pas l'opérateur virgule. Quelques exemples de virgules séparatrices :

void foo(int x, int y) // Virgule séparatrice utilisée pour séparer les paramètres dans la définition de la fonction
{
    add(x, y); // Virgule séparatrice utilisée pour séparer les arguments dans l'appel de fonction
    constexpr int z{ 3 }, w{ 5 }; // Virgule séparatrice utilisée pour séparer plusieurs variables définies sur la même ligne (à ne pas faire)
}

Il n'est pas nécessaire d'éviter les virgules séparatrices (sauf lorsqu'on déclare plusieurs variables, ce qu'il ne faut pas faire).
