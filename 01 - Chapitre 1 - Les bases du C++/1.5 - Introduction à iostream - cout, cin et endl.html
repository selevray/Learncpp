1.5 — Introduction à iostream : cout, cin et endl

Dans cette leçon, nous revenons sur std::cout, que nous avons utilisé dans notre programme Hello world! pour afficher le texte Hello world! dans la console. Nous verrons aussi comment récupérer une saisie de l'utilisateur, ce qui permettra de rendre nos programmes plus interactifs.

La bibliothèque d'entrées/sorties

La bibliothèque d'entrées/sorties (bibliothèque io) fait partie de la bibliothèque standard C++ et gère les entrées et sorties de base. Nous utiliserons ses fonctionnalités pour lire ce que tape l'utilisateur au clavier et pour afficher des données dans la console. La partie io de iostream signifie input/output (entrée/sortie).

Pour utiliser les fonctionnalités définies dans la bibliothèque iostream, nous devons inclure l'en-tête iostream en haut de tout fichier de code qui utilise son contenu, comme ceci :

#include <iostream>

// reste du code qui utilise les fonctionnalités d'iostream ici

std::cout

La bibliothèque iostream contient quelques variables prédéfinies que nous pouvons utiliser. L'une des plus utiles est std::cout, qui permet d'envoyer des données à la console pour les afficher sous forme de texte. cout signifie « character output » (sortie de caractères).

Pour rappel, voici notre programme Hello world :

#include <iostream> // pour std::cout

int main()
{
    std::cout << "Hello world!"; // affiche Hello world! dans la console

    return 0;
}

Dans ce programme, nous avons inclus iostream afin d'avoir accès à std::cout. Dans notre fonction main, nous utilisons std::cout avec l'opérateur d'insertion (<<) pour envoyer le texte Hello world! à la console, qui l'affiche.

std::cout ne sert pas seulement à afficher du texte, il peut aussi afficher des nombres :

#include <iostream> // pour std::cout

int main()
{
    std::cout << 4; // affiche 4 dans la console

    return 0;
}

Ce programme produit le résultat suivant :


4

On peut aussi s'en servir pour afficher la valeur de variables :

#include <iostream> // pour std::cout

int main()
{
    int x{ 5 }; // définit la variable entière x, initialisée avec la valeur 5
    std::cout << x; // affiche la valeur de x (5) dans la console
    return 0;
}

Ce programme produit le résultat suivant :


5

Pour afficher plusieurs éléments sur la même ligne, l'opérateur d'insertion (<<) peut être utilisé plusieurs fois dans une seule instruction afin de concaténer (enchaîner) plusieurs morceaux de sortie. Par exemple :

#include <iostream> // pour std::cout

int main()
{
    std::cout << "Hello" << " world!";
    return 0;
}

Cela utilise l'opérateur << deux fois : d'abord pour afficher Hello, puis pour afficher world.

Ce programme affiche donc :


Hello world!

Astuce

Il peut être utile d'imaginer les opérateurs << (et >>) comme un tapis roulant qui transporte les données dans le sens indiqué. Ici, lorsque le contenu arrive jusqu'à std::cout, il est affiché.

Voici un autre exemple où nous affichons, dans une même instruction, à la fois du texte et la valeur d'une variable :

#include <iostream> // pour std::cout

int main()
{
    int x{ 5 };
    std::cout << "x est égal à : " << x;
    return 0;
}

Ce programme affiche :


x est égal à : 5

Contenu associé

Nous expliquons ce que fait réellement le préfixe std:: dans la leçon 2.9 -- Collisions de noms et introduction aux espaces de noms.

Utiliser std::endl pour afficher un saut de ligne

Quel résultat attendriez-vous de ce programme ?

#include <iostream> // pour std::cout

int main()
{
    std::cout << "Salut !";
    std::cout << "Je m'appelle Alex.";
    return 0;
}

Le résultat peut vous surprendre :


Salut !Je m'appelle Alex.

Des instructions de sortie séparées n'entraînent pas des lignes de sortie séparées dans la console.

Si nous voulons afficher des lignes distinctes dans la console, nous devons indiquer à la console de placer le curseur à la ligne suivante. Pour cela, nous envoyons un saut de ligne. Un saut de ligne (newline) est un caractère, ou une suite de caractères, propre au système d'exploitation, qui place le curseur au début de la ligne suivante.

Une façon d'afficher un saut de ligne est d'envoyer std::endl (abréviation de « end line ») :

#include <iostream> // pour std::cout et std::endl

int main()
{
    std::cout << "Salut !" << std::endl; // std::endl place le curseur à la ligne suivante
    std::cout << "Je m'appelle Alex." << std::endl;

    return 0;
}

Ce programme affiche :


Salut !
Je m'appelle Alex.

Astuce

Dans le programme ci-dessus, le second std::endl n'est pas techniquement nécessaire, puisque le programme se termine juste après. Il sert pourtant à plusieurs choses utiles.

D'abord, il indique que la ligne de sortie forme une « pensée complète » (par opposition à une sortie partielle complétée plus loin dans le code). En ce sens, il joue un rôle proche de celui du point en français.

Ensuite, il place le curseur sur la ligne suivante, de sorte que si nous ajoutons plus tard d'autres lignes de sortie (par exemple, si le programme affiche « à bientôt ! »), ces lignes apparaîtront là où nous les attendons, et non à la suite de la ligne précédente.

Enfin, après l'exécution d'un programme depuis la ligne de commande, certains systèmes d'exploitation n'affichent pas de saut de ligne avant de réafficher l'invite de commande. Si notre programme ne se termine pas avec le curseur en début de ligne, l'invite peut apparaître à la suite de la dernière ligne affichée, au lieu de commencer une nouvelle ligne comme l'utilisateur s'y attend.

Bonne pratique

Affichez un saut de ligne dès qu'une ligne de sortie est complète.

std::cout est bufferisé

Imaginez un manège dans votre parc d'attractions préféré. Les visiteurs arrivent (à un rythme variable) et font la queue. Périodiquement, un train arrive et embarque les visiteurs (jusqu'à sa capacité maximale). Lorsque le train est plein, ou lorsque suffisamment de temps s'est écoulé, il part avec un groupe de visiteurs, et le manège démarre. Les visiteurs qui ne peuvent pas monter dans le train actuel attendent le suivant.

Cette analogie ressemble à la façon dont la sortie envoyée à std::cout est généralement traitée en C++. Les instructions de notre programme demandent que des données soient envoyées à la console. Cependant, ces données ne sont généralement pas envoyées immédiatement. Au lieu de cela, la sortie demandée « fait la queue » et est stockée dans une zone de mémoire réservée à la collecte de ces demandes (appelée tampon, ou buffer). Périodiquement, le tampon est vidé (flushed), c'est-à-dire que toutes les données qu'il contient sont transférées vers leur destination (ici, la console).

Note de l'auteur

Pour reprendre une autre analogie, vider un tampon ressemble un peu à tirer la chasse d'eau. Toute la « sortie » accumulée est transférée vers… l'endroit où elle va ensuite. Beurk.

Cela signifie aussi que si votre programme plante, s'arrête brutalement ou est mis en pause (par exemple pour le déboguer) avant que le tampon soit vidé, toute sortie encore en attente dans le tampon ne sera pas affichée.

Point clé

L'inverse de la sortie bufferisée est la sortie non bufferisée. Avec une sortie non bufferisée, chaque demande de sortie est envoyée directement au périphérique de sortie.

Écrire des données dans un tampon est généralement rapide, alors que transférer un lot de données vers un périphérique de sortie est relativement lent. La bufferisation peut améliorer considérablement les performances en regroupant plusieurs demandes de sortie, ce qui réduit le nombre de fois où il faut envoyer des données au périphérique.

std::endl contre \n

Utiliser std::endl est souvent inefficace, car il accomplit deux tâches : il affiche un saut de ligne (en plaçant le curseur sur la ligne suivante de la console), et il vide le tampon (opération lente). Si nous affichons plusieurs lignes de texte se terminant chacune par std::endl, nous provoquons plusieurs vidages, ce qui est lent et probablement inutile.

Lorsque nous affichons du texte dans la console, nous n'avons généralement pas besoin de vider nous-mêmes le tampon. Le système de sortie de C++ est conçu pour se vider périodiquement, et il est à la fois plus simple et plus efficace de le laisser faire.

Pour afficher un saut de ligne sans vider le tampon, nous utilisons \n (entre apostrophes ou entre guillemets), un symbole spécial que le compilateur interprète comme un caractère de saut de ligne. \n place le curseur à la ligne suivante de la console sans provoquer de vidage, ce qui le rend généralement plus performant. \n est aussi plus court à taper et peut être intégré à un texte déjà entouré de guillemets.

Voici un exemple qui utilise \n de plusieurs façons :

#include <iostream> // pour std::cout

int main()
{
    int x{ 5 };
    std::cout << "x est égal à : " << x << '\n'; // entre apostrophes (seul) (conventionnel)
    std::cout << "Oui." << "\n";                 // entre guillemets (seul) (peu conventionnel mais correct)
    std::cout << "Et voilà, c'est tout !\n";     // entre guillemets dans un texte existant (conventionnel)
    return 0;
}

Ce programme affiche :


x est égal à : 5
Oui.
Et voilà, c'est tout !

Lorsque \n n'est pas intégré à une ligne de texte déjà entourée de guillemets (par exemple "bonjour\n"), il est conventionnellement placé entre apostrophes ('\n').

Pour les lecteurs avancés

En C++, nous utilisons les apostrophes pour représenter un caractère isolé (comme 'a' ou '$'), et les guillemets pour représenter du texte (zéro caractère ou plus).

Bien que ‘\n’ soit écrit dans le code source avec deux symboles, le compilateur le traite comme un seul caractère de fin de ligne (LF, linefeed) de valeur ASCII 10. C'est pourquoi on le place conventionnellement entre apostrophes (sauf lorsqu'il est intégré à un texte entre guillemets). Nous en reparlerons dans la leçon 4.11 -- Les caractères.

Lorsque ‘\n’ est affiché, la bibliothèque qui effectue l'affichage se charge de le traduire en la séquence de fin de ligne appropriée au système d'exploitation considéré. Consultez Wikipédia pour plus d'informations sur les conventions des systèmes d'exploitation concernant les sauts de ligne.

Note de l'auteur

Bien que peu conventionnel, nous estimons qu'il est acceptable (voire préférable) d'utiliser "\n" entre guillemets dans les instructions d'affichage standard.

Cela présente deux avantages principaux :

  1. Il est plus simple de mettre tout le texte affiché entre guillemets plutôt que de devoir déterminer ce qui doit être entre apostrophes ou entre guillemets.
  2. Plus important encore, cela évite les littéraux multicaractères involontaires. Nous présentons les littéraux multicaractères et certaines sorties inattendues qu'ils peuvent produire dans la leçon 4.11 -- Les caractères.

Les apostrophes sont à privilégier dans les autres cas.

Nous verrons plus en détail ce qu'est ‘\n’ lorsque nous aborderons la leçon sur les caractères (4.11 -- Les caractères).

Bonne pratique

Préférez \n à std::endl lorsque vous affichez du texte dans la console.

Attention

'\n' utilise une barre oblique inversée (comme tous les caractères spéciaux en C++), et non une barre oblique normale.

Utiliser une barre oblique normale (par exemple '/n'), ou placer d'autres caractères entre les apostrophes (par exemple ' \n' ou '.\n'), entraînera un comportement inattendu. Par exemple, std::cout << '/n'; affichera souvent 12142, ce qui n'est probablement pas ce que vous attendiez.

std::cin

std::cin est une autre variable prédéfinie de la bibliothèque iostream. Alors que std::cout affiche des données dans la console (en utilisant l'opérateur d'insertion << pour fournir ces données), std::cin (abréviation de « character input », entrée de caractères) lit ce que l'utilisateur tape au clavier. Nous utilisons généralement l'opérateur d'extraction >> pour placer la donnée saisie dans une variable, qui peut ensuite être utilisée dans les instructions suivantes.

#include <iostream>  // pour std::cout et std::cin

int main()
{
    std::cout << "Entrez un nombre : "; // demande un nombre à l'utilisateur

    int x{};       // définit la variable x pour stocker la saisie (et l'initialise à zéro)
    std::cin >> x; // lit un nombre au clavier et le stocke dans la variable x

    std::cout << "Vous avez saisi " << x << '\n';
    return 0;
}

Essayez de compiler ce programme et de l'exécuter vous-même. Lors de l'exécution, la ligne 5 affichera « Entrez un nombre : ». Lorsque le code atteindra la ligne 8, le programme attendra que vous saisissiez une valeur. Une fois que vous aurez saisi un nombre (et appuyé sur Entrée), ce nombre sera affecté à la variable x. Enfin, à la ligne 10, le programme affichera « Vous avez saisi » suivi du nombre que vous venez de taper.

Par exemple (en saisissant la valeur 4) :


Entrez un nombre : 4
Vous avez saisi 4

C'est un moyen simple de récupérer une saisie clavier de l'utilisateur, que nous utiliserons dans de nombreux exemples par la suite.

Astuce

Notez qu'il n'est pas nécessaire d'afficher '\n' lorsque vous acceptez une ligne de saisie, puisque l'utilisateur doit appuyer sur la touche Entrée pour valider sa saisie, ce qui déplace le curseur à la ligne suivante de la console.

  • Si votre écran se ferme immédiatement après la saisie d'un nombre, consultez la leçon 0.8 -- Quelques problèmes courants en C++ pour une solution.
  • Si vous utilisez CLion et que « Vous avez saisi » est précédé d'un espace, il s'agit d'un bogue de CLion. Consultez le suivi des bogues de CLion pour connaître les solutions de contournement.

Tout comme il est possible d'afficher plusieurs morceaux de texte sur une même ligne, il est également possible de saisir plusieurs valeurs sur une même ligne :

#include <iostream>  // pour std::cout et std::cin

int main()
{
    std::cout << "Entrez deux nombres séparés par un espace : ";

    int x{}; // définit la variable x pour stocker la saisie (et l'initialise à zéro)
    int y{}; // définit la variable y pour stocker la saisie (et l'initialise à zéro)
    std::cin >> x >> y; // lit deux nombres et les stocke respectivement dans x et y

    std::cout << "Vous avez saisi " << x << " et " << y << '\n';

    return 0;
}

Ce programme produit la sortie suivante :


Entrez deux nombres séparés par un espace : 5 6
Vous avez saisi 5 et 6

Les valeurs saisies doivent être séparées par des espaces blancs (espaces, tabulations ou sauts de ligne).

Point clé

On débat parfois de la nécessité d'initialiser une variable juste avant de lui donner une valeur fournie par l'utilisateur via une autre source (par exemple std::cin), puisque la valeur saisie écrasera simplement la valeur d'initialisation. Conformément à notre recommandation précédente selon laquelle les variables doivent toujours être initialisées, la bonne pratique consiste à initialiser la variable en premier.

Pour les lecteurs avancés

La bibliothèque d'entrées/sorties de C++ ne fournit pas de moyen de lire une saisie clavier sans que l'utilisateur ait à appuyer sur Entrée. Si vous souhaitez un tel comportement, vous devrez utiliser une bibliothèque tierce. Pour les applications console, nous recommandons pdcurses, FXTUI, cpp-terminal ou notcurses. De nombreuses bibliothèques d'interface graphique proposent leurs propres fonctions pour ce type de traitement.

std::cin est bufferisé

Dans une section précédente, nous avons indiqué que l'envoi de données en sortie est en réalité un processus en deux étapes :

  • Les données de chaque demande de sortie sont ajoutées (à la fin) d'un tampon de sortie.
  • Ensuite, les données sont extraites (depuis le début) du tampon de sortie et transmises au périphérique de sortie (la console).

Point clé

Ajouter des données à la fin d'un tampon et les retirer du début garantit qu'elles sont traitées dans l'ordre dans lequel elles ont été ajoutées. On parle parfois de FIFO (first in, first out, premier entré, premier sorti).

De la même manière, la saisie de données se déroule également en deux étapes :

  • Les caractères que vous saisissez sont ajoutés à la fin d'un tampon d'entrée (à l'intérieur de std::cin). La touche Entrée (utilisée pour valider la saisie) est également stockée sous forme de caractère '\n'.
  • L'opérateur d'extraction >> retire des caractères du début du tampon d'entrée et les convertit en une valeur, qui est affectée (par affectation par copie) à la variable associée. Cette variable peut ensuite être utilisée dans les instructions suivantes.

Point clé

Chaque ligne de saisie présente dans le tampon d'entrée se termine par un caractère '\n'.

Nous allons illustrer cela avec le programme suivant :

#include <iostream>  // pour std::cout et std::cin

int main()
{
    std::cout << "Entrez deux nombres : ";

    int x{};
    std::cin >> x;

    int y{};
    std::cin >> y;

    std::cout << "Vous avez saisi " << x << " et " << y << '\n';

    return 0;
}

Ce programme lit deux valeurs dans deux variables (cette fois dans deux instructions séparées). Nous exécuterons ce programme deux fois.

Exécution n° 1 : lorsque std::cin >> x; est atteint, le programme attend une saisie. Entrez la valeur 4. La saisie 4\n est placée dans le tampon d'entrée, et la valeur 4 est extraite vers la variable x.

Lorsque std::cin >> y; est atteint, le programme attend de nouveau une saisie. Entrez la valeur 5. La saisie 5\n est placée dans le tampon d'entrée, et la valeur 5 est extraite vers la variable y. Enfin, le programme affiche Vous avez saisi 4 et 5.

Rien de surprenant dans cette exécution.

Exécution n° 2 : lorsque std::cin >> x est atteint, le programme attend une saisie. Entrez 4 5. La saisie 4 5\n est placée dans le tampon d'entrée, mais seul le 4 est extrait vers la variable x (l'extraction s'arrête à l'espace).

Lorsque std::cin >> y est atteint, le programme n'attend pas de saisie. À la place, le 5 qui se trouve encore dans le tampon d'entrée est extrait vers la variable y. Le programme affiche alors Vous avez saisi 4 et 5.

Remarquez que, dans l'exécution n° 2, le programme n'a pas attendu que l'utilisateur saisisse de nouvelles données pour l'extraction vers y, car des données déjà présentes dans le tampon d'entrée pouvaient être utilisées.

Point clé

std::cin est bufferisé, car cela nous permet de séparer la saisie des données de leur extraction. Nous pouvons saisir les données une seule fois, puis effectuer plusieurs demandes d'extraction à partir de celles-ci.

Le processus d'extraction de base

Voici une vue simplifiée du fonctionnement de l'opérateur >> pour la saisie.

  1. Si std::cin n'est pas dans un état correct (par exemple, si l'extraction précédente a échoué et que std::cin n'a pas encore été réinitialisé), aucune extraction n'est tentée et le processus d'extraction s'interrompt immédiatement.
  2. Les espaces blancs en début de tampon (espaces, tabulations et sauts de ligne placés au début du tampon) sont supprimés du tampon d'entrée. Cela supprime un caractère de saut de ligne non extrait, qui reste d'une saisie précédente.
  3. Si le tampon d'entrée est maintenant vide, l'opérateur >> attend que l'utilisateur saisisse d'autres données. Les espaces blancs en début de saisie sont alors ignorés.
  4. L'opérateur >> extrait ensuite autant de caractères consécutifs que possible, jusqu'à rencontrer soit un caractère de saut de ligne (marquant la fin de la ligne de saisie), soit un caractère qui n'est pas valide pour la variable cible.

Le résultat du processus d'extraction est le suivant :

  • Si l'extraction a été interrompue à l'étape 1, aucune tentative d'extraction n'a eu lieu. Rien d'autre ne se produit.
  • Si des caractères ont été extraits à l'étape 4 ci-dessus, l'extraction réussit. Les caractères extraits sont convertis en une valeur, qui est ensuite affectée par copie à la variable.
  • Si aucun caractère n'a pu être extrait à l'étape 4 ci-dessus, l'extraction a échoué. L'objet cible reçoit par affectation par copie la valeur 0 (depuis C++11), et toutes les extractions suivantes échoueront immédiatement (jusqu'à ce que std::cin soit réinitialisé).

Les caractères non extraits (y compris les sauts de ligne) restent disponibles pour la tentative d'extraction suivante.

Contenu associé

Nous expliquons comment détecter et gérer les échecs d'extraction, traiter les saisies superflues et réinitialiser std::cin dans la leçon 9.5 -- std::cin et gestion des saisies invalides.

Par exemple, avec l'extrait suivant :

int x{};
std::cin >> x;

Voici ce qui se passe dans trois cas de saisie différents :

  • Si l'utilisateur tape 5a puis Entrée, 5a\n est ajouté au tampon. 5 est extrait, converti en entier et affecté à la variable x. a\n reste dans le tampon d'entrée pour l'extraction suivante.
  • Si l'utilisateur tape ‘b’ puis Entrée, b\n serait ajouté au tampon. Comme b n'est pas un entier valide, aucun caractère ne peut être extrait : c'est un échec d'extraction. La variable x serait mise à 0, et les extractions suivantes échoueront jusqu'à ce que le flux d'entrée soit réinitialisé.
  • Si std::cin n'est pas dans un état correct à cause d'une extraction précédente ayant échoué, rien ne se passe ici. La valeur de la variable x n'est pas modifiée.

Nous explorerons d'autres cas dans le quiz ci-dessous.

operator<< contre operator>>

Les nouveaux programmeurs confondent souvent std::cin, std::cout, l'opérateur d'insertion (<<) et l'opérateur d'extraction (>>). Voici un moyen simple de s'en souvenir :

  • std::cin et std::cout se placent toujours à gauche de l'opérateur.
  • std::cout sert à afficher une valeur (cout = character output, sortie de caractères).
  • std::cin sert à récupérer une valeur saisie (cin = character input, entrée de caractères).
  • << s'utilise avec std::cout et indique le sens de déplacement des données. std::cout << 4 envoie la valeur 4 vers la console.
  • >> s'utilise avec std::cin et indique le sens de déplacement des données. std::cin >> x place dans la variable x la valeur saisie au clavier par l'utilisateur.

Nous reparlerons des opérateurs dans la leçon 1.9 -- Introduction aux littéraux et aux opérateurs.

Quiz

Question n° 1

Considérez le programme suivant, que nous avons utilisé plus haut :

#include <iostream>  // pour std::cout et std::cin

int main()
{
    std::cout << "Entrez un nombre : "; // demande un nombre à l'utilisateur
    int x{}; // définit la variable x pour stocker la saisie
    std::cin >> x; // lit un nombre au clavier et le stocke dans la variable x
    std::cout << "Vous avez saisi " << x << '\n';

    return 0;
}

Le programme attend une valeur entière, puisque la variable x dans laquelle la saisie est placée est une variable entière.

Exécutez ce programme plusieurs fois et décrivez le résultat obtenu lorsque vous saisissez les types de valeurs suivants :

a) Une lettre, par exemple h.

Solution

Résultat : 0 est toujours affiché.
Explication : un entier ne peut pas contenir une lettre, donc l'extraction échoue complètement. x reçoit la valeur 0.

b) Un nombre avec une partie décimale (par exemple 3.2). Essayez des nombres dont la partie décimale est inférieure à 0,5 et supérieure à 0,5 (par exemple 3.2 et 3.7).

Solution

Résultat : la partie décimale est supprimée (elle n'est pas arrondie).
Explication : avec le nombre 3.2, le 3 est extrait, mais . est un caractère invalide, donc l'extraction s'arrête ici. Le .2 reste pour une tentative d'extraction ultérieure.

Si vous vous demandez pourquoi il ne s'agit pas d'une conversion restrictive interdite, sachez que les conversions restrictives ne sont interdites que lors de l'initialisation par liste (qui a lieu à la ligne 6). L'extraction, elle, a lieu à la ligne 7.

c) Un petit entier négatif, par exemple -3.

Solution

Résultat : le nombre saisi est affiché.
Explication : un signe moins au début d'un nombre est acceptable, il est donc extrait. Les chiffres restants sont extraits également.

d) Un mot, par exemple Bonjour.

Solution

Résultat : 0 est toujours affiché.
Explication : un entier ne peut pas contenir une lettre, donc l'extraction échoue complètement. x reçoit la valeur 0.

e) Un très grand nombre (au moins 3 milliards).

Solution

Résultat : vous obtiendrez très probablement le nombre 2147483647.
Explication : x ne peut contenir que des nombres jusqu'à une certaine taille. Si vous saisissez une valeur plus grande que le plus grand nombre que x peut contenir, elle sera fixée à ce plus grand nombre (qui est probablement 2147483647, mais peut être différent sur votre système). Nous approfondissons ce point dans la leçon 4.4 -- Les entiers signés.

f) Un petit nombre suivi de quelques lettres, par exemple 123abc.

Solution

Résultat : la valeur numérique est affichée (par exemple 123).
Explication : 123 est extrait, les caractères restants (ici abc) sont laissés pour une extraction ultérieure.

g) Quelques lettres suivies d'un petit nombre, par exemple abc123.

Solution

Résultat : 0 est toujours affiché.
Explication : un entier ne peut pas contenir une lettre, donc l'extraction échoue complètement. x reçoit la valeur 0.

h) +5 (trois espaces, suivis d'un signe plus et d'un 5).

Solution

Résultat : 5 est affiché.
Explication : les espaces blancs en début de saisie sont ignorés. Le plus est un symbole valide en début de nombre (tout comme le signe moins), il est donc extrait. Le 5 est également extrait.

i) 5b6.

Solution

Résultat : 5 est affiché.
Explication : 5 est extrait. b est invalide, donc l'extraction s'arrête ici. Le b6 reste pour une tentative d'extraction ultérieure.

Question n° 2

Demandez à l'utilisateur de saisir trois valeurs. Le programme doit ensuite afficher ces valeurs. Ajoutez un commentaire approprié au-dessus de la fonction main().

Le programme doit correspondre à la sortie suivante (avec les valeurs 4, 5 et 6 en entrée) :


Entrez trois nombres : 4 5 6
Vous avez saisi 4, 5 et 6.
Indice

Indice : un commentaire placé au-dessus d'une fonction doit décrire ce que fait la fonction.

Indice

Indice : pensez à bien mettre votre sortie entre guillemets.

Solution 
#include <iostream>

// Demande à l'utilisateur de saisir trois valeurs, puis affiche ces valeurs sous forme de phrase.
int main()
{
    std::cout << "Entrez trois nombres : ";

    int x{};
    int y{};
    int z{};
    std::cin >> x >> y >> z;

    std::cout << "Vous avez saisi " << x << ", " << y << " et " << z << ".\n";

    return 0;
}

Notez que ".\n" doit être entre guillemets, puisque nous affichons plus d'un caractère.
