24.x — Résumé du chapitre 24 et quiz

Résumé

L'héritage permet de modéliser une relation « est un » (is-a) entre deux objets. L'objet dont on hérite est appelé classe parente, classe de base ou superclasse. L'objet qui hérite est appelé classe enfant, classe dérivée ou sous-classe.

Lorsqu'une classe dérivée hérite d'une classe de base, elle acquiert tous les membres de la classe de base.

Lorsqu'une classe dérivée est construite, la partie de base de la classe est construite en premier, puis la partie dérivée. Plus précisément :

  1. La mémoire pour la classe dérivée est réservée (suffisamment pour les parties de base et dérivée).
  2. Le constructeur approprié de la classe dérivée est appelé.
  3. L'objet de la classe de base est construit en premier, à l'aide du constructeur de base approprié. Si aucun constructeur de base n'est spécifié, le constructeur par défaut est utilisé.
  4. La liste d'initialisation de la classe dérivée initialise les membres de la classe dérivée.
  5. Le corps du constructeur de la classe dérivée s'exécute.
  6. Le contrôle est rendu à l'appelant.

La destruction se déroule dans l'ordre inverse, de la classe la plus dérivée à la classe la plus à la base.

C++ dispose de 3 spécificateurs d'accès : public, private et protected. Le spécificateur protected permet à la classe à laquelle appartient le membre, aux amies et aux classes dérivées d'accéder aux membres protégés, mais pas au public.

Les classes peuvent hériter d'une autre classe de manière publique, privée ou protégée. Les classes héritent presque toujours de manière publique.

Voici un tableau de toutes les combinaisons de spécificateurs d'accès et de types d'héritage :

| Spécificateur d'accès dans la classe de base | Spécificateur d'accès en héritage public | Spécificateur d'accès en héritage privé | Spécificateur d'accès en héritage protégé | | Public | Public | Private | Protected | | Private | Inaccessible | Inaccessible | Inaccessible | | Protected | Protected | Private | Protected |

Les classes dérivées peuvent ajouter de nouvelles fonctions, modifier le comportement des fonctions existantes de la classe de base, changer le niveau d'accès d'un membre hérité, ou masquer des fonctionnalités.

L'héritage multiple permet à une classe dérivée d'hériter de membres provenant de plusieurs parents. Vous devriez généralement éviter l'héritage multiple, sauf si les alternatives conduisent à plus de complexité.

    std::cout << "My " << a.getName() << " is " << a.getColor() << ".\n";

Solution 
#include <iostream>
#include <string>
#include <string_view>

class Fruit
{
private:
    std::string m_name;
    std::string m_color;

public:
    Fruit(std::string_view name, std::string_view color)
        : m_name{ name }, m_color{ color }
    {
    }

    const std::string& getName() const { return m_name; }
    const std::string& getColor() const { return m_color; }
};

class Apple: public Fruit
{
public:
    Apple(std::string_view color="red")
        : Fruit{ "apple", color }
    {
    }
};

class Banana : public Fruit
{
public:
    Banana()
        : Fruit{ "banana", "yellow" }
    {
    }
};

int main()
{
    Apple a{ "red" };

    std::cout << "My " << a.getName() << " is " << a.getColor() << ".\n";

    return 0;
}

a) Commencez par créer la classe Creature. Ajoutez trois autres fonctions : void reduceHealth(int) réduit les points de vie de la créature d'un entier donné. bool isDead() renvoie true lorsque les points de vie de la créature sont égaux ou inférieurs à 0. void addGold(int) ajoute de l'or à la créature.

#include <iostream>
#include <string>
#include <string_view> // Requiert C++17

class Creature
{
protected:
    std::string m_name;
    char m_symbol {};
    int m_health {};
    int m_damage {};
    int m_gold {};

public:
    Creature(std::string_view name, char symbol, int health, int damage, int gold)
        : m_name{ name }
        , m_symbol{ symbol }
        , m_health{ health }
        , m_damage{ damage }
        , m_gold{ gold }
    {
    }

    const std::string& getName() const { return m_name; }
    char getSymbol() const { return m_symbol; }
    int getHealth() const { return m_health; }
    int getDamage() const { return m_damage; }
    int getGold() const { return m_gold; }

    void reduceHealth(int health) { m_health -= health; }
    bool isDead() const { return m_health <= 0; }
    void addGold(int gold) { m_gold += gold; }
};

int main()
{
    Creature o{ "orc", 'o', 4, 2, 10 };
    o.addGold(5);
    o.reduceHealth(1);

f) Nous sommes enfin prêts à écrire la logique du jeu !

Voici les règles du jeu :

Le joueur rencontre un monstre généré aléatoirement à la fois.
Pour chaque monstre, le joueur a deux choix : (R)un, c'est-à-dire fuir, ou (F)ight, c'est-à-dire combattre.
Si le joueur décide de fuir, il a 50 % de chances de s'échapper.
S'il s'échappe, il passe à la rencontre suivante sans conséquence.
S'il ne s'échappe pas, le monstre bénéficie d'une attaque gratuite, puis le joueur choisit sa prochaine action.
Si le joueur choisit de combattre, il attaque en premier. Les points de vie du monstre sont réduits des dégâts du joueur.
Si le monstre meurt, le joueur récupère l'or que le monstre transporte. Le joueur monte aussi de niveau, ce qui augmente son niveau et ses dégâts de 1.
Si le monstre ne meurt pas, il contre-attaque le joueur. Les points de vie du joueur sont réduits des dégâts du monstre.
La partie se termine lorsque le joueur est mort (défaite) ou a atteint le niveau 20 (victoire).
Si le joueur meurt, le jeu doit lui indiquer le niveau qu'il avait et la quantité d'or qu'il possédait.

  • fightMonster() gère le combat entre le Player et un seul Monster, y compris la question posée au joueur sur ce qu'il veut faire, et le traitement des cas fuite ou combat.

#include "Random.h" // https://www.learncpp.com/cpp-tutorial/global-random-numbers-random-h/
#include <array>
#include <iostream>
#include <string>
#include <string_view>

class Creature
{
protected:
    std::string m_name;
    char m_symbol {};
    int m_health {};
    int m_damage {};
    int m_gold {};

public:
     Creature(std::string_view name, char symbol, int health, int damage, int gold)
        : m_name{ name }
        , m_symbol{ symbol }
        , m_health{ health }
        , m_damage{ damage }
        , m_gold{ gold }
    { }

    char getSymbol() const { return m_symbol; }
    const std::string& getName() const { return m_name; }
    bool isDead() const { return m_health <= 0; }
    int getGold() const { return m_gold; }
    void addGold(int gold) { m_gold += gold; }
    void reduceHealth(int health) { m_health -= health; }
    int getHealth() const { return m_health; }
    int getDamage() const { return m_damage; }
};

class Player : public Creature
{
    int m_level{ 1 };

public:
    Player(const std::string& name)
        : Creature{ name, '@', 10, 1, 0 }
    {
    }

    void levelUp()
    {
        ++m_level;
        ++m_damage;
    }

    int getLevel() const { return m_level; }
    bool hasWon() const { return m_level >= 20; }
};

class Monster : public Creature
{
public:
    enum Type
    {
        dragon,
        orc,
        slime,
        max_types
    };

private:
    inline static Creature monsterData[] {
        Creature { "dragon", 'D', 20, 4, 100 },
        Creature { "orc", 'o', 4, 2, 25 },
        Creature { "slime", 's', 1, 1, 10 }
        };

    static_assert(std::size(monsterData) == max_types);

public:
    Monster(Type type)
        : Creature{ monsterData[type] }
    {
    }

    static Monster getRandomMonster()
    {
        int num{ Random::get(0, max_types - 1) };
        return Monster{ static_cast<Type>(num) };
    }
};

// Cette fonction gère l'attaque du joueur contre le monstre
void attackMonster(Player& player, Monster& monster)
{
    // Si le joueur est mort, il ne peut pas attaquer le monstre
    if (player.isDead())
        return;

    std::cout << "You hit the " << monster.getName() << " for " << player.getDamage() << " damage.\n";

    // Réduit les points de vie du monstre des dégâts du joueur
    monster.reduceHealth(player.getDamage());

    // Si le monstre est maintenant mort, le joueur monte de niveau
    if (monster.isDead())
    {
        std::cout << "You killed the " << monster.getName() << ".\n";
        player.levelUp();
        std::cout << "You are now level " << player.getLevel() << ".\n";
        std::cout << "You found " << monster.getGold() << " gold.\n";
        player.addGold(monster.getGold());
    }
}

// Cette fonction gère l'attaque du monstre contre le joueur
void attackPlayer(const Monster& monster, Player& player)
{
    // Si le monstre est mort, il ne peut pas attaquer le joueur
    if (monster.isDead())
        return;

    // Réduit les points de vie du joueur des dégâts du monstre
    player.reduceHealth(monster.getDamage());
    std::cout << "The " << monster.getName() << " hit you for " << monster.getDamage() << " damage.\n";
}

// Cette fonction gère tout le combat entre un joueur et un monstre généré aléatoirement
void fightMonster(Player& player)
{
    // D'abord, générer aléatoirement un monstre
    Monster monster{ Monster::getRandomMonster() };
    std::cout << "You have encountered a " << monster.getName() << " (" << monster.getSymbol() << ").\n";

    // Tant que le monstre et le joueur sont vivants, le combat continue
    while (!monster.isDead() && !player.isDead())
    {
        std::cout << "(R)un or (F)ight: ";
        char input{};
        std::cin >> input;
        if (input == 'R' || input == 'r')
        {
            // 50 % de chances de fuir avec succès
            if (Random::get(1, 2) == 1)
            {
                std::cout << "You successfully fled.\n";
                return; // la fuite réussie termine rencontre
            }
            else
            {
                // Échec de la fuite : le monstre attaque gratuitement le joueur
                std::cout << "You failed to flee.\n";
                attackPlayer(monster, player);
                continue;
            }
        }

        if (input == 'F' || input == 'f')
        {
            // Le joueur attaque en premier, le monstre ensuite
            attackMonster(player, monster);
            attackPlayer(monster, player);
        }
    }
}

int main()
{
    std::cout << "Enter your name: ";
    std::string playerName;
    std::cin >> playerName;

    Player player{ playerName };
    std::cout << "Welcome, " << player.getName() << '\n';

    // Si le joueur n'est pas mort et n'a pas encore gagné, la partie continue
    while (!player.isDead() && !player.hasWon())
        fightMonster(player);

    // À ce stade, le joueur est mort ou a gagné
    if (player.isDead())
    {
        std::cout << "You died at level " << player.getLevel() << " and with " << player.getGold() << " gold.\n";
        std::cout << "Too bad you can't take it with you!\n";
    }
    else
    {
        std::cout << "You won the game with " << player.getGold() << " gold!\n";
    }

  return 0;
}

#include "Random.h" // https://www.learncpp.com/cpp-tutorial/global-random-numbers-random-h/
#include <array>
#include <iostream>
#include <sstream>
#include <string>
#include <string_view>

class Potion
{
public:
    // Tous les types possibles de potions
    enum Type
    {
        health,
        strength,
        poison,

        // Pour la génération aléatoire de potions
        max_type
    };

    enum Size
    {
        small,
        medium,
        large,

        max_size
    };


private:
    Type m_type{};
    Size m_size{};

public:
    Potion(Type type, Size size)
        : m_type{ type },
        m_size{ size }
    {
    }

    Type getType() const { return m_type; }
    Size getSize() const { return m_size; }

    // Les noms des potions sont des littéraux connus à la compilation, nous pouvons
    // renvoyer un std::string_view.
    static std::string_view getPotionTypeName(Type type)
    {
        static constexpr std::string_view names[] {
          "Health",
          "Strength",
          "Poison"
        };

        return names[type];
    }

    static std::string_view getPotionSizeName(Size size)
    {
        static constexpr std::string_view names[] {
          "Small",
          "Medium",
          "Large"
        };

        return names[size];
    }

    std::string getName() const
    {
        // Nous utilisons un std::stringstream, mais cela pourrait aussi se faire
        // avec std::string.
        // Nous avons utilisé std::stringstream pour la première fois dans la leçon 7.13.
        std::stringstream result{};

        result << getPotionSizeName(getSize()) << " potion of " << getPotionTypeName(getType());

        // On peut extraire la chaîne d'un std::stringstream avec la fonction membre str().
        return result.str();
    }

    static Potion getRandomPotion()
    {
        return Potion{
          static_cast<Type>(Random::get(0, max_type - 1)),
          static_cast<Size>(Random::get(0, max_size - 1))
        };
    }
};

class Player : public Creature

public:

        : Creature{ name, '@', 10, 1, 0 }
    {
    }

    {
        ++m_level;
        ++m_damage;
    }

    // Applique l'effet d'une potion au joueur
    void drinkPotion(const Potion& potion)
    {
        switch (potion.getType())
        {
        case Potion::health:
            // Seule la taille d'une potion de santé influence sa puissance. Toutes les
            // autres potions ne dépendent pas de la taille.
            m_health += ((potion.getSize() == Potion::large) ? 5 : 2);
            break;
        case Potion::strength:
            ++m_damage;
            break;
        case Potion::poison:
            reduceHealth(1);
            break;
            // Traiter max_type pour faire taire l'avertissement du compilateur. N'utilisez pas
            // default: car nous voulons que le compilateur nous avertisse si nous ajoutons une
            // nouvelle potion sans implémenter son effet.
        case Potion::max_type:
            break;
        }
    }

    int getLevel() const { return m_level; }
    bool hasWon() const { return m_level >= 20; }
};
