11.6 — Templates de fonctions

Supposons que vous souhaitiez écrire une fonction calculant le maximum de deux nombres. Vous pourriez procéder ainsi :

int max(int x, int y)
{
    return (x < y) ? y : x;
    // Remarque : nous utilisons < au lieu de > parce que std::max utilise <
}

Bien que l'appelant puisse transmettre des valeurs différentes à la fonction, le type des paramètres est figé : l'appelant ne peut donc transmettre que des valeurs de type int. Cela signifie que cette fonction ne fonctionne réellement bien que pour les entiers (et pour les types pouvant être promus en int).

Que se passe-t-il alors lorsque vous voulez trouver le maximum de deux valeurs double ? Comme C++ exige que l'on précise le type de tous les paramètres de fonction, la solution consiste à créer une nouvelle version surchargée de max dont les paramètres sont de type double :

double max(double x, double y)
{
    return (x < y) ? y: x;
}

Remarquez que le code d'implémentation de la version double de max est exactement le même que celui de la version int ! En fait, cette implémentation fonctionne pour de nombreux types différents : int, double, long, long double, et même pour de nouveaux types que vous avez vous-même créés (nous verrons comment faire dans de prochaines leçons).

Devoir créer des fonctions surchargées ayant la même implémentation pour chaque ensemble de types de paramètres que nous souhaitons prendre en charge est une source de maintenance pénible, une recette pour les erreurs, et une violation évidente du principe DRY (don't repeat yourself, « ne vous répétez pas »). Il existe aussi un défi moins évident : un programmeur qui souhaite utiliser la fonction max peut vouloir l'appeler avec un type d'argument que l'auteur de max n'a pas anticipé (et pour lequel il n'a donc pas écrit de fonction surchargée).

Ce qui nous manque vraiment, c'est un moyen d'écrire une seule version de max capable de travailler avec des arguments de n'importe quel type (même des types qui n'ont peut-être pas été anticipés lors de l'écriture du code de max). Les fonctions ordinaires ne sont tout simplement pas à la hauteur de cette tâche. Heureusement, C++ prend en charge une autre fonctionnalité conçue spécialement pour résoudre ce genre de problème.

Bienvenue dans le monde des templates C++.

Introduction aux templates C++

En C++, le système de templates a été conçu pour simplifier la création de fonctions (ou de classes) capables de travailler avec différents types de données.

Plutôt que de créer manuellement une série de fonctions ou de classes presque identiques (une pour chaque ensemble de types différents), nous créons un seul template. Comme une définition ordinaire, une définition de template décrit à quoi ressemble une fonction ou une classe. Contrairement à une définition ordinaire (où tous les types doivent être précisés), dans un template nous pouvons utiliser un ou plusieurs types de substitution. Un type de substitution (placeholder type) représente un type inconnu au moment de la définition du template, mais qui sera fourni plus tard, au moment de l'utilisation du template.

Une fois le template défini, le compilateur peut l'utiliser pour générer autant de fonctions (ou de classes) surchargées que nécessaire, chacune utilisant des types réels différents !

Le résultat final est le même : nous obtenons une série de fonctions ou de classes presque identiques (une pour chaque ensemble de types différents). Mais nous n'avons à créer et à maintenir qu'un seul template, et le compilateur se charge du travail difficile de créer les autres à notre place.

Point clé

Le compilateur peut utiliser un seul template pour générer une famille de fonctions ou de classes apparentées, chacune utilisant un ensemble différent de types réels.

En complément…

Comme le concept de template peut être difficile à décrire avec des mots, essayons une analogie.

Si vous cherchiez le mot « template » dans un dictionnaire, vous y trouveriez une définition proche de la suivante : « un template est un modèle qui sert de patron pour créer des objets semblables ». Un type de template très facile à comprendre est celui du pochoir pour la peinture. Un pochoir est une fine plaque de matériau (comme du carton ou du plastique) dans laquelle une forme a été découpée (par exemple un visage souriant). En plaçant le pochoir sur un autre objet, puis en projetant de la peinture à travers l'ouverture, vous pouvez reproduire très rapidement la forme découpée. Le pochoir lui-même n'a besoin d'être créé qu'une seule fois, puis il peut être réutilisé autant de fois que souhaité, pour créer la forme découpée dans autant de couleurs différentes que vous le voulez. Mieux encore, la couleur d'une forme réalisée au pochoir n'a pas besoin d'être déterminée avant que le pochoir ne soit effectivement utilisé.

Un template est essentiellement un pochoir permettant de créer des fonctions ou des classes. Nous créons le template (notre pochoir) une seule fois, puis nous pouvons l'utiliser autant de fois que nécessaire, pour découper une fonction ou une classe pour un ensemble de types réels donné. Ces types réels n'ont pas besoin d'être déterminés avant que le template ne soit effectivement utilisé.

Comme les types réels ne sont pas déterminés au moment où le template est utilisé dans un programme (et non au moment où il est écrit), l'auteur du template n'a pas besoin d'anticiper tous les types réels susceptibles d'être utilisés. Cela signifie que le code d'un template peut être utilisé avec des types qui n'existaient même pas au moment où le template a été écrit ! Nous verrons comment cela s'avère utile lorsque nous explorerons la bibliothèque standard C++, qui regorge de code de templates !

Point clé

Les templates peuvent fonctionner avec des types qui n'existaient même pas au moment où le template a été écrit. Cela rend le code de template à la fois souple et pérenne !

Dans la suite de cette leçon, nous allons présenter et explorer en détail la manière de créer des templates de fonctions et décrire leur fonctionnement. Nous reporterons la discussion sur les templates de classes après avoir vu ce que sont les classes.

Templates de fonctions

Un template de fonction (function template) est une définition de type fonction utilisée pour générer une ou plusieurs fonctions surchargées, chacune avec un ensemble différent de types réels. C'est ce qui nous permettra de créer des fonctions capables de travailler avec de nombreux types différents. Le template de fonction initial, qui sert à générer d'autres fonctions, est appelé template primaire (primary template), et les fonctions générées à partir du template primaire sont appelées fonctions instanciées (instantiated functions).

Lorsque nous créons un template de fonction primaire, nous utilisons des types de substitution (technically called type template parameters, informally called template types, en français « paramètres template de type ») pour tous les types de paramètres, types de retour ou types utilisés dans le corps de la fonction que nous voulons laisser à l'utilisateur du template le soin de préciser ultérieurement.

Pour les lecteurs avancés

C++ prend en charge 3 genres différents de paramètres de template :

  • Les paramètres template de type (où le paramètre représente un type).
  • Les paramètres template non-type (où le paramètre représente une valeur constexpr).
  • Les paramètres template template (où le paramètre représente un template).

Les paramètres template de type sont de loin les plus courants, nous nous concentrerons donc d'abord sur eux. Nous aborderons également les paramètres non-type, qui sont de plus en plus utilisés en C++ moderne.

Les templates de fonctions s'apprennent mieux par l'exemple. Transformons donc notre fonction ordinaire max(int, int) de l'exemple précédent en template de fonction. C'est étonnamment simple, et nous expliquerons ce qui se passe au fur et à mesure.

Création d'un template de fonction max()

Voici à nouveau la version int de max() :

int max(int x, int y)
{
    return (x < y) ? y : x;
}

Remarquez que nous utilisons le type int trois fois dans cette fonction : une fois pour le paramètre x, une fois pour le paramètre y, et une fois pour le type de retour de la fonction.

Pour créer un template de fonction pour max(), nous allons faire deux choses. Premièrement, nous remplaçons tous les types réels que nous voulons laisser à préciser ultérieurement par des paramètres template de type. Ici, comme un seul type doit être remplacé (int), nous n'avons besoin que d'un seul paramètre template de type (que nous appellerons T) :

Voici notre nouvelle fonction utilisant un seul type template, où toutes les occurrences du type réel int ont été remplacées par le paramètre template de type T :

T max(T x, T y) // ne compilera pas car nous n'avons pas défini T
{
    return (x < y) ? y : x;
}

C'est un bon début, mais cela ne compilera pas, car le compilateur ne sait pas ce qu'est T ! Et il s'agit toujours d'une fonction ordinaire, pas d'un template de fonction.

Deuxièmement, nous indiquons au compilateur qu'il s'agit d'un template, et que T est un paramètre template de type servant de substitut à n'importe quel type. Ces deux opérations sont réalisées à l'aide d'une déclaration de paramètres template (template parameter declaration), qui définit les paramètres template qui seront utilisés par la suite. La portée d'une déclaration de paramètres template est strictement limitée au template de fonction (ou de classe) qui la suit. Par conséquent, chaque template de fonction ou de classe a besoin de sa propre déclaration de paramètres template.

template <typename T> // déclaration des paramètres template, définissant T comme paramètre template de type
T max(T x, T y) // définition du template de fonction pour max<T>
{
    return (x < y) ? y : x;
}

Dans notre déclaration de paramètres template, nous commençons par le mot-clé template, qui indique au compilateur que nous créons un template. Ensuite, nous spécifions entre chevrons (<>) tous les paramètres template utilisés par notre template. Pour chaque paramètre template de type, nous utilisons le mot-clé typename (préféré) ou class, suivi du nom du paramètre template de type (par exemple T).

Contenu associé

Nous verrons comment créer des templates de fonctions avec plusieurs types template dans la leçon 11.8 -- Templates de fonctions avec plusieurs types template.

En complément…

Il n'y a aucune différence entre les mots-clés typename et class dans ce contexte. Vous verrez souvent les gens utiliser le mot-clé class, puisqu'il a été introduit dans le langage plus tôt. Nous préférons cependant le mot-clé plus récent typename, car il indique plus clairement que le paramètre template de type peut être remplacé par n'importe quel type (comme un type fondamental), et pas seulement par un type classe.

Croyez-le ou non, nous avons terminé ! Nous avons créé une version template de notre fonction max() capable d'accepter des arguments de types différents.

Dans la prochaine leçon, nous verrons comment utiliser notre template de fonction max pour générer une ou plusieurs fonctions max() avec des paramètres de types différents, puis comment appeler ces fonctions.

Nommer les paramètres template

De la même manière que nous utilisons souvent une seule lettre pour les noms de variables dans des situations triviales (par exemple x), il est conventionnel d'utiliser une seule lettre majuscule (à partir de T) lorsque le paramètre template est utilisé de façon triviale ou évidente. Par exemple, dans notre template de fonction max :

template <typename T>
T max(T x, T y)
{
    return (x < y) ? y : x;
}

Nous n'avons pas besoin de donner à T un nom complexe, car c'est manifestement un simple type de substitution pour les valeurs comparées, et T peut être n'importe quel type pouvant être comparé (tel que int, double ou char, mais pas nullptr).

Nos templates de fonctions suivront généralement cette convention de nommage.

Si un paramètre template de type a un usage non évident ou des exigences spécifiques à respecter, il existe deux conventions courantes pour ces noms :

  • Commencer par une majuscule (par exemple Allocator). La bibliothèque standard utilise cette convention.
  • Préfixer par un T, puis commencer par une majuscule (par exemple TAllocator). Cela permet de voir plus facilement qu'il s'agit d'un paramètre template de type.

Le choix entre les deux relève de vos préférences personnelles.

Pour les lecteurs avancés

Par exemple, la bibliothèque standard possède une surcharge de std::max() déclarée ainsi :

template< class T, class Compare >
const T& max( const T& a, const T& b, Compare comp ); // ignorez le & pour l'instant, nous les verrons dans une future leçon

Comme a et b sont de type T, nous savons que peu nous importe le type de a et b : il peut s'agir de n'importe quel type. Comme comp a le type Compare, nous savons que comp doit être un type satisfaisant aux exigences d'un Compare (quelles qu'elles soient).

Lorsqu'un template de fonction est instancié, le compilateur remplace les paramètres template par les arguments template, puis compile la fonction instanciée résultante. La compilation réussit ou non selon la manière dont les objets de chaque type sont utilisés dans la fonction. Les exigences pour un paramètre template donné sont donc essentiellement définies de manière implicite.

Comme il peut être difficile de déduire les exigences à partir de la manière dont les objets du type sont utilisés, c'est un domaine où il est utile de consulter la documentation technique, qui doit énoncer explicitement ces exigences. Par exemple, si nous voulons connaître les exigences d'un Compare, nous pouvons consulter la documentation de std::max (voir par exemple https://en.cppreference.com/w/cpp/algorithm/max), où elles devraient être listées.

Bonne pratique

Utilisez une seule lettre majuscule commençant par T (par exemple T, U, V, etc.) pour nommer les paramètres template de type utilisés de façon triviale ou évidente et représentant « tout type raisonnable ».

Si le paramètre template de type a un usage non évident ou des exigences spécifiques à respecter, un nom plus descriptif est justifié (par exemple Allocator ou TAllocator).

Quiz

Question n° 1

Expliquez pourquoi les plans de construction sont un type de template.

Solution

Le plan de construction n'est qu'une feuille de papier décrivant comment construire un bâtiment. À l'aide de ce plan, les équipes de construction peuvent rapidement ériger de nombreux bâtiments à la structure identique. Cependant, le type de matériau spécifique utilisé pour chaque bâtiment peut varier (par exemple, le matériau employé pour le revêtement extérieur du bâtiment) et n'a pas besoin d'être déterminé avant que les bâtiments ne soient effectivement construits.
