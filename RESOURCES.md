# Ressources C++

## Knowledge

- [Cours : LearnCpp traduit en français (local)](cours/index.html) — Markdown d'origine dans `~/learncpp/cours/`
  Source principale du parcours : 388 leçons dans l'ordre pédagogique, avec quiz et solutions. Use for: le contenu de chaque leçon ; toujours lier la page correspondante (`cours/<chapitre>/<leçon>.html`).
- [Cours : LearnCpp.com (original anglais)](https://www.learncpp.com/)
  Version de référence, mise à jour par l'auteur. Use for: vérifier un passage douteux de la traduction, lire les commentaires des lecteurs.
- [Référence : cppreference.com](https://en.cppreference.com/w/cpp)
  La référence la plus fiable sur le langage et la bibliothèque standard, version par version (C++98 à C++26). Use for: la signature exacte d'une fonction, savoir dans quelle norme une fonctionnalité est apparue (utile pour le C++98 de 42).
- [Cours : « La programmation en C++ moderne » (Zeste de Savoir)](https://zestedesavoir.com/tutoriels/822/la-programmation-en-c-moderne/)
  Cours francophone de qualité, écrit et relu par une communauté exigeante. Use for: une deuxième explication en français quand une notion de LearnCpp reste floue.
- [Guide : C++ Core Guidelines (Stroustrup et Sutter)](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines)
  Les règles de bonne pratique des créateurs du langage. Use for: justifier un « Conseil Claude » sur le style ou les bonnes pratiques.
- [Outil : Compiler Explorer](https://godbolt.org/)
  Compile du code en ligne avec plusieurs compilateurs et normes. Use for: comparer un comportement entre C++98 et C++20, montrer ce que produit le compilateur.
- [Documentation : GDB](https://sourceware.org/gdb/current/onlinedocs/gdb.html/)
  Manuel officiel du débogueur. Use for: les leçons de débogage (points d'arrêt, pas à pas, inspection des variables).

## Wisdom (Communities)

- Pairs de l'école 42 (peer-learning, corrections)
  La communauté la plus directe pour la mission 42. Use for: faire relire son code, comprendre les attentes d'un sujet, s'entraîner aux corrections.
- [r/cpp_questions](https://www.reddit.com/r/cpp_questions/)
  Forum modéré, dédié aux questions de débutants et intermédiaires. Use for: une question précise après avoir cherché seul ; montrer son code pour avoir des avis.
- [Zeste de Savoir — forum Programmation](https://zestedesavoir.com/forums/)
  Forum francophone bienveillant. Use for: poser une question en français.
