20.x — Résumé du chapitre et quiz

Bilan du chapitre

Encore un chapitre de terminé ! Il ne reste plus qu'à passer ce satané quiz…

Les arguments de fonction peuvent être passés par valeur, par référence ou par adresse. Utilisez le passage par valeur pour les types fondamentaux et les énumérateurs. Utilisez le passage par référence pour les structures, les classes, ou lorsque la fonction doit modifier un argument. Utilisez le passage par adresse pour passer des pointeurs ou des tableaux natifs. Rendez les paramètres passés par référence et par adresse const chaque fois que c'est possible.

Les valeurs peuvent être renvoyées par valeur, par référence ou par adresse. La plupart du temps, le renvoi par valeur convient, mais le renvoi par référence ou par adresse peut être utile lorsqu'on travaille avec des données allouées dynamiquement, des structures ou des classes. Si vous renvoyez une référence ou une adresse, assurez-vous de ne pas renvoyer quelque chose qui sortira de portée.

Les pointeurs de fonction permettent de passer une fonction à une autre fonction. Cela peut être utile pour permettre à l'appelant de personnaliser le comportement d'une fonction, par exemple la manière dont une liste est triée.

La mémoire dynamique est allouée sur le tas (heap).

La pile d'appels (call stack) garde la trace de toutes les fonctions actives (celles qui ont été appelées mais ne se sont pas encore terminées), depuis le début du programme jusqu'au point d'exécution courant. Les variables locales sont allouées sur la pile. La taille de la pile est limitée. std::vector peut être utilisé pour implémenter un comportement de pile.

Une fonction récursive est une fonction qui s'appelle elle-même. Toutes les fonctions récursives ont besoin d'une condition de terminaison.

Les arguments de ligne de commande permettent aux utilisateurs ou à d'autres programmes de transmettre des données à notre programme au démarrage. Les arguments de ligne de commande sont toujours des chaînes de style C, et doivent être convertis en nombres si l'on souhaite des valeurs numériques.

Les points de suspension (ellipsis) permettent de passer un nombre variable d'arguments à une fonction. Cependant, les arguments en points de suspension suspendent la vérification des types et ne connaissent pas le nombre d'arguments passés. C'est au programme de garder la trace de ces détails.

Les fonctions lambda sont des fonctions qui peuvent être imbriquées dans d'autres fonctions. Elles n'ont pas besoin de nom et sont très utiles combinées à la bibliothèque d'algorithmes.

Temps du quiz

Question n° 1

Écrivez les prototypes de fonctions pour les cas suivants. Utilisez const si nécessaire.

a) Une fonction nommée max() qui prend deux double et renvoie le plus grand des deux.

Solution 
double max(double x, double y);

b) Une fonction nommée swap() qui échange deux entiers.

Solution 
void swap(int& x, int& y);

c) Une fonction nommée getLargestElement() qui prend un tableau d'entiers alloué dynamiquement et renvoie le plus grand nombre, de manière à ce que l'appelant puisse modifier la valeur de l'élément renvoyé (n'oubliez pas le paramètre de longueur).

Solution 
// Remarque : le tableau ne peut pas être const dans ce cas, car renvoyer une référence non constante vers un élément constant violerait la constance.
int& getLargestElement(int* array, int length);

Question n° 2

Qu'y a-t-il de faux dans ces programmes ?

a)

int& doSomething()
{
    int array[]{ 1, 2, 3, 4, 5 };
    return array[3];
}
Solution

doSomething() renvoie une référence vers une variable locale qui sera détruite lorsque doSomething se termine.

b)

int sumTo(int value)
{
    return value + sumTo(value - 1);
}
Solution

La fonction sumTo() n'a pas de condition de terminaison. La variable value finira par devenir négative, et la fonction bouclera indéfiniment jusqu'au débordement de la pile.

c)

float divide(float x, float y)
{
    return x / y;
}

double divide(float x, float y)
{
    return x / y;
}
Solution

Les deux fonctions divide ne sont pas distinctes, car elles ont le même nom et les mêmes paramètres. Il y a également un risque de division par 0.

d)

#include <iostream>

int main()
{
    int array[100000000]{};

    for (auto x: array)
        std::cout << x << ' ';

    std::cout << '\n';

    return 0;
}
Solution

Le tableau est trop grand pour être alloué sur la pile. Il devrait être alloué dynamiquement.

e)

#include <iostream>

int main(int argc, char* argv[])
{
    int age{ argv[1] };
    std::cout << "The user's age is " << age << '\n';

    return 0;
}
Solution

argv[1] peut ne pas exister. S'il existe, argv[1] est une chaîne de caractères, et ne peut pas être convertie en entier par une simple affectation.

Question n° 3

L'algorithme le plus efficace pour déterminer si une valeur existe dans un tableau trié s'appelle la recherche dichotomique (binary search).

La recherche dichotomique fonctionne ainsi :

  • Regardez l'élément central du tableau (si le tableau contient un nombre pair d'éléments, arrondissez à l'inférieur).
  • Si l'élément central est supérieur à l'élément recherché, écartez la moitié supérieure du tableau (ou appliquez la récursion sur la moitié inférieure).
  • Si l'élément central est inférieur à l'élément recherché, écartez la moitié inférieure du tableau (ou appliquez la récursion sur la moitié supérieure).
  • Si l'élément central est égal à l'élément recherché, renvoyez l'indice de l'élément central.
  • Si vous écartez tout le tableau sans trouver l'élément recherché, renvoyez une sentinelle qui représente « non trouvé » (dans ce cas, nous utiliserons -1, puisque c'est un indice de tableau invalide).

Comme nous pouvons éliminer la moitié du tableau à chaque itération, cet algorithme est très rapide. Même avec un tableau d'un million d'éléments, il ne faut au plus que 20 itérations pour déterminer si une valeur existe ou non dans le tableau ! Cependant, il ne fonctionne que sur des tableaux triés.

Modifier un tableau (par exemple, écarter la moitié de ses éléments) est coûteux, donc on ne modifie généralement pas le tableau. On utilise plutôt deux entiers (min et max) pour contenir les indices des éléments minimum et maximum du tableau que nous souhaitons examiner.

Regardons un exemple de fonctionnement de cet algorithme, avec le tableau { 3, 6, 7, 9, 12, 15, 18, 21, 24 } et une valeur recherchée de 7. Au départ, min = 0 et max = 8, car nous recherchons dans tout le tableau (le tableau a une longueur de 9, donc l'indice du dernier élément est 8).

  • Passe 1) Nous calculons le milieu entre min (0) et max (8), soit 4. L'élément n° 4 a la valeur 12, qui est supérieure à la valeur recherchée. Comme le tableau est trié, nous savons que tous les éléments dont l'indice est supérieur ou égal au milieu (4) sont trop grands. Nous laissons donc min tel quel et plaçons max à 3.
  • Passe 2) Nous calculons le milieu entre min (0) et max (3), soit 1. L'élément n° 1 a la valeur 6, qui est inférieure à la valeur recherchée. Comme le tableau est trié, nous savons que tous les éléments dont l'indice est inférieur ou égal au milieu (1) sont trop petits. Nous plaçons donc min à 2 et laissons max tel quel.
  • Passe 3) Nous calculons le milieu entre min (2) et max (3), soit 2. L'élément n° 2 a la valeur 7, qui est la valeur recherchée. Nous renvoyons donc 2.

En C++20, le calcul du milieu peut être fait en appelant std::midpoint. Avant C++20, vous devez calculer le milieu vous-même : dans ce cas, vous pouvez utiliser min + ((max - min) / 2) pour éviter le débordement (lorsque min et max sont tous deux positifs).

    constexpr int testValues[]{ 0, 3, 12, 13, 22, 26, 43, 44, 48, 49 };

a) Écrivez une version itérative de la fonction binarySearch.

Indice : vous pouvez affirmer sans risque que l'élément recherché n'existe pas lorsque l'indice min est supérieur à l'indice max.

Solution 
#include <cassert>
#include <iostream>
#include <numeric> // pour std::midpoint

// array est le tableau dans lequel effectuer la recherche.
// target est la valeur dont nous cherchons à déterminer si elle existe.
// min est l'indice de la borne inférieure du tableau dans lequel nous cherchons.
// max est l'indice de la borne supérieure du tableau dans lequel nous cherchons.
// binarySearch() doit renvoyer l'indice de l'élément recherché s'il est trouvé, -1 sinon
int binarySearch(const int* array, int target, int min, int max)
{
    assert(array); // vérifier que le tableau existe

    while (min <= max)
    {
        // implémenter ceci de manière itérative
        int midpoint{ std::midpoint(min, max) };
        // Avant C++20
        // int midpoint{ min + ((max-min) / 2) }; // cette façon de calculer le milieu évite le débordement

        if (array[midpoint] > target)
        {
            // si array[midpoint] > target, alors le nombre se trouve forcément dans la moitié inférieure du tableau
            // nous pouvons utiliser midpoint - 1 comme indice supérieur, car nous n'avons pas besoin de retester le milieu à l'itération suivante
            max = midpoint - 1;
        }
        else if (array[midpoint] < target)
        {
            // si array[midpoint] < target, alors le nombre se trouve forcément dans la moitié supérieure du tableau
            // nous pouvons utiliser midpoint + 1 comme indice inférieur, car nous n'avons pas besoin de retester le milieu à l'itération suivante
            min = midpoint + 1;
        }
        else
        {
            return midpoint;
        }
    }

    return -1;
}

b) Écrivez une version récursive de la fonction binarySearch.

Solution 
#include <cassert>
#include <numeric> // pour std::midpoint

// array est le tableau dans lequel effectuer la recherche.
// target est la valeur dont nous cherchons à déterminer si elle existe.
// min est l'indice de la borne inférieure du tableau dans lequel nous cherchons.
// max est l'indice de la borne supérieure du tableau dans lequel nous cherchons.
// binarySearch() doit renvoyer l'indice de l'élément recherché s'il est trouvé, -1 sinon
int binarySearch(const int* array, int target, int min, int max)
{
    assert(array); // vérifier que le tableau existe

    // implémenter ceci de manière récursive

    if (min > max)
        return -1;

    int midpoint{ std::midpoint(min, max) };
    // Avant C++20
    // int midpoint{ min + ((max-min) / 2) }; // cette façon de calculer le milieu évite le débordement

    if (array[midpoint] > target)
    {
        return binarySearch(array, target, min, midpoint - 1);
    }
    else if (array[midpoint] < target)
    {
        return binarySearch(array, target, midpoint + 1, max);
    }

    return midpoint;
}

Astuce

std::binary_search renvoie true si une valeur existe dans une liste triée.
std::equal_range renvoie les itérateurs vers le premier et le dernier élément ayant une valeur donnée.

N'utilisez pas ces fonctions pour résoudre l'exercice, mais utilisez-les à l'avenir si vous avez besoin d'une recherche dichotomique.
