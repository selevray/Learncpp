16.6 — Tableaux et boucles

Dans la leçon d'introduction de ce chapitre (16.1 -- Introduction aux conteneurs et aux tableaux), nous avons présenté les problèmes de passage à l'échelle que pose la gestion de nombreuses variables individuelles liées entre elles. Dans cette leçon, nous reprenons ce problème, puis nous verrons comment les tableaux permettent de le résoudre avec élégance.

Le problème de passage à l'échelle des variables, revisité

Considérons le cas où nous voulons calculer la moyenne des notes d'une classe d'élèves. Pour garder ces exemples concis, nous supposerons que la classe ne compte que 5 élèves.

Voici comment nous pourrions procéder avec des variables individuelles :

#include <iostream>

int main()
{
    // alloue 5 variables entières (chacune avec un nom différent)
    int testScore1{ 84 };
    int testScore2{ 92 };
    int testScore3{ 76 };
    int testScore4{ 81 };
    int testScore5{ 56 };

    int average { (testScore1 + testScore2 + testScore3 + testScore4 + testScore5) / 5 };

    std::cout << "The class average is: " << average << '\n';

    return 0;
}

Cela fait beaucoup de variables et beaucoup de frappe. Imaginez le travail pour 30 élèves, voire 600. De plus, si une nouvelle note est ajoutée, il faut déclarer une nouvelle variable, l'initialiser et l'ajouter au calcul de la moyenne. Et avez-vous pensé à mettre à jour le diviseur ? Si vous l'avez oublié, vous avez maintenant une erreur sémantique. Chaque fois que vous modifiez du code existant, vous risquez d'introduire des erreurs.

Vous savez maintenant que nous devrions utiliser un tableau lorsque nous avons un ensemble de variables liées. Remplaçons donc nos variables individuelles par un std::vector :

#include <iostream>
#include <vector>

int main()
{
    std::vector testScore { 84, 92, 76, 81, 56 };
    std::size_t length { testScore.size() };

    int average { (testScore[0] + testScore[1] + testScore[2] + testScore[3] + testScore[4])
        / static_cast<int>(length) };

    std::cout << "The class average is: " << average << '\n';

    return 0;
}

C'est mieux : nous avons nettement réduit le nombre de variables définies, et le diviseur du calcul de la moyenne est désormais déduit directement de la longueur du tableau.

Mais le calcul de la moyenne pose encore problème, car nous devons lister manuellement chaque élément. Et comme chaque élément doit être cité explicitement, notre calcul ne fonctionne que pour des tableaux comportant exactement autant d'éléments que nous en avons listés. Si nous voulons aussi pouvoir calculer la moyenne de tableaux de longueurs différentes, il faudra écrire un nouveau calcul pour chaque longueur.

Ce dont nous avons vraiment besoin, c'est d'un moyen d'accéder à chaque élément du tableau sans devoir les citer un par un.

Tableaux et boucles

Dans les leçons précédentes, nous avons noté que les indices de tableau n'ont pas besoin d'être des expressions constantes : ce peuvent être des expressions évaluées à l'exécution. Cela signifie que nous pouvons utiliser la valeur d'une variable comme indice.

Remarquez également que les indices utilisés dans le calcul de la moyenne de l'exemple précédent forment une suite croissante : 0, 1, 2, 3, 4. Si nous disposions d'un moyen de faire prendre à une variable, successivement, les valeurs 0, 1, 2, 3 puis 4, nous pourrions utiliser cette variable comme indice au lieu de littéraux. Or nous savons déjà faire cela avec une boucle for.

Contenu associé

Nous avons présenté les boucles for dans la leçon 8.10 -- Instructions for.

Réécrivons l'exemple précédent avec une boucle for, dont la variable de boucle sert d'indice de tableau :

#include <iostream>
#include <vector>

int main()
{
    std::vector testScore { 84, 92, 76, 81, 56 };
    std::size_t length { testScore.size() };

    int average { 0 };
    for (std::size_t index{ 0 }; index < length; ++index) // index va de 0 à length-1
        average += testScore[index];                      // ajoute la valeur de l'élément d'indice `index`
    average /= static_cast<int>(length);                  // calcule la moyenne

    std::cout << "The class average is: " << average << '\n';

    return 0;
}

Cela devrait être assez simple. index commence à 0, testScore[0] est ajouté à average, puis index est incrémenté à 1. testScore[1] est ajouté à average, et index passe à 2. Finalement, lorsque index atteint 5, index < length est faux et la boucle se termine.

À ce moment, la boucle a ajouté à average les valeurs de testScore[0], testScore[1], testScore[2], testScore[3] et testScore[4].

Enfin, nous calculons la moyenne en divisant la somme accumulée par la longueur du tableau.

Cette solution est idéale en termes de maintenabilité. Le nombre d'itérations de la boucle est déterminé par la longueur du tableau, et la variable de boucle sert à toute l'indexation du tableau. Nous n'avons plus besoin de lister manuellement chaque élément.

Si nous voulons ajouter ou retirer une note, il suffit de modifier le nombre d'éléments de l'initialisation : le reste du code fonctionnera encore sans autre modification !

Accéder à chaque élément d'un conteneur dans un certain ordre s'appelle parcours (traversal), ou parcourir le conteneur. Ce parcours est souvent appelé itération, ou itérer sur le conteneur.

Note de l'auteur

Puisque les classes de conteneurs utilisent le type size_t pour les longueurs et les indices, nous ferons de même dans cette leçon. Nous étudierons l'utilisation de longueurs et d'indices signés dans la prochaine leçon 16.7 -- Tableaux, boucles et solutions au défi du signe.

Modèles, tableaux et boucles ouvrent la voie au passage à l'échelle

Les tableaux permettent de stocker plusieurs objets sans avoir à nommer chaque élément.

Les boucles permettent de parcourir un tableau sans avoir à lister explicitement chaque élément.

Les modèles (templates) permettent de paramétrer le type des éléments.

Ensemble, modèles, tableaux et boucles nous permettent d'écrire du code capable de travailler sur un conteneur d'éléments, quel que soit le type des éléments ou le nombre d'éléments du conteneur !

Pour l'illustrer, réécrivons l'exemple précédent en factorisant le calcul de la moyenne dans un modèle de fonction :

#include <iostream>
#include <vector>

// Modèle de fonction calculant la moyenne des valeurs d'un std::vector
template <typename T>
T calculateAverage(const std::vector<T>& arr)
{
    std::size_t length { arr.size() };

    T average { 0 };                                      // si notre tableau contient des éléments de type T, la moyenne doit aussi être de type T
    for (std::size_t index{ 0 }; index < length; ++index) // parcourt tous les éléments
        average += arr[index];                            // additionne tous les éléments
    average /= static_cast<int>(length);                  // divise par le nombre d'éléments (de nature entière)

    return average;
}

int main()
{
    std::vector class1 { 84, 92, 76, 81, 56 };
    std::cout << "The class 1 average is: " << calculateAverage(class1) << '\n'; // calcule la moyenne de 5 int

    std::vector class2 { 93.2, 88.6, 64.2, 81.0 };
    std::cout << "The class 2 average is: " << calculateAverage(class2) << '\n'; // calcule la moyenne de 4 double

    return 0;
}

Cela affiche :


The class 1 average is: 77
The class 2 average is: 81.75

Dans cet exemple, nous avons créé le modèle de fonction calculateAverage(), qui prend un std::vector de n'importe quel type d'élément et de n'importe quelle longueur, et renvoie la moyenne. Dans main(), nous montrons que cette fonction fonctionne aussi bien avec un tableau de 5 éléments int qu'avec un tableau de 4 éléments double !

calculateAverage() fonctionnera pour tout type T qui prend en charge les opérateurs utilisés dans la fonction (operator+=(T), operator/=(int)). Si vous essayez d'utiliser un T qui ne prend pas en charge ces opérateurs, le compilateur produira une erreur lors de la compilation de la fonction instanciée.

Vous vous demandez peut-être pourquoi nous convertissons length en int plutôt qu'en T. Lors du calcul de la moyenne, nous divisons la somme par le nombre d'éléments. Ce nombre d'éléments est une valeur entière. Il est donc sémantiquement plus cohérent de diviser par un int.

Ce que l'on peut faire avec les tableaux et les boucles

Maintenant que nous savons parcourir un conteneur d'éléments à l'aide d'une boucle, voyons les usages les plus courants de ce parcours. On parcourt généralement un conteneur pour faire l'une de ces quatre choses :

  1. Calculer une nouvelle valeur à partir de la valeur des éléments existants (par exemple, la valeur moyenne ou la somme des valeurs).
  2. Rechercher un élément existant (par exemple, vérifier la présence d'une correspondance exacte, compter le nombre de correspondances, trouver la valeur la plus élevée).
  3. Opérer sur chaque élément (par exemple, afficher chaque élément, multiplier tous les éléments par 2).
  4. Réordonner les éléments (par exemple, trier les éléments par ordre croissant).

Les trois premiers cas sont assez directs. Nous pouvons utiliser une seule boucle pour parcourir le tableau, en inspectant ou en modifiant chaque élément selon les besoins.

Réordonner les éléments d'un conteneur est beaucoup plus délicat, car cela implique généralement une boucle imbriquée dans une autre. Bien que nous puissions le faire manuellement, il est généralement préférable d'utiliser un algorithme existant de la bibliothèque standard. Nous étudierons cela plus en détail dans un chapitre ultérieur consacré aux algorithmes.

Tableaux et erreurs de décalage d'une unité

Lorsque vous parcourez un conteneur à l'aide d'un indice, vous devez veiller à ce que la boucle s'exécute le nombre de fois voulu. Les erreurs de décalage d'une unité (off-by-one, où le corps de la boucle s'exécute une fois de trop ou une fois de moins) sont faciles à commettre.

En général, lorsque l'on parcourt un conteneur à l'aide d'un indice, on fait démarrer l'indice à 0 et on boucle tant que index < length.

Les nouveaux programmeurs utilisent parfois par erreur index <= length comme condition de boucle. Cela fait exécuter la boucle lorsque index == length, ce qui produit un indice hors limites et un comportement indéfini.

template <typename T>
int findIndex(const std::vector<T>& arr, T val)
{
    for (std::size_t index{ 0 }; index < arr.size(); ++index)
    {
        if (arr[index] == val)

int getValidNumber()
{
    // Lit d'abord une saisie valide de l'utilisateur
    int num {};
    do
    {
        std::cout << "Enter a number between 1 and 9: ";
        std::cin >> num;

        // si l'utilisateur a saisi un caractère invalide
        if (!std::cin)

Question n° 5

Écrivez un modèle de fonction qui trouve la plus grande valeur d'un std::vector. Si le vecteur est vide, renvoyez la valeur par défaut du type des éléments.

Le code suivant doit pouvoir s'exécuter :

int main()
{
    std::vector data1 { 84, 92, 76, 81, 56 };
    std::cout << findMax(data1) << '\n';

    std::vector data2 { -13.0, -26.7, -105.5, -14.8 };
    std::cout << findMax(data2) << '\n';

    std::vector<int> data3 { };
    std::cout << findMax(data3) << '\n';

    return 0;
}

Et afficher le résultat suivant :


92
-13
0
Indice

Indice : utilisez une variable hors boucle pour mémoriser la valeur la plus élevée rencontrée jusqu'ici.

Solution 
#include <iostream>
#include <vector>

template <typename T>
T findMax(const std::vector<T>& arr)
{
    std::size_t length { arr.size() };

    if (length==0)
        return T{};

    T max { arr[0] }; // La valeur maximale initiale est le premier élément

    // Parcourt les éléments restants à la recherche d'une valeur plus grande
    for (std::size_t index{ 1 }; index < length; ++index)
    {
        if (arr[index] > max)
            max = arr[index];
    }

    return max;
}

int main()
{
    std::vector data1 { 84, 92, 76, 81, 56 };
    std::cout << findMax(data1) << '\n';

    std::vector data2 { -13.0, -26.7, -105.5, -14.8 };
    std::cout << findMax(data2) << '\n';

    std::vector<int> data3 { };
    std::cout << findMax(data3) << '\n';

    return 0;
}

Dans cet exemple, nous utilisons une variable hors boucle appelée max pour mémoriser le score le plus élevé rencontré. Nous l'initialisons avec la valeur du premier élément afin qu'elle démarre avec une valeur légitime. L'initialisation par valeur pourrait sembler tentante, mais elle ferait renvoyer une mauvaise valeur à la fonction si le tableau ne contenait que des valeurs négatives.

Nous parcourons ensuite chaque élément du tableau et, lorsque nous trouvons un score supérieur à tous ceux vus précédemment, nous affectons ce score à max. Ainsi, max représente toujours le score le plus élevé parmi tous les éléments parcourus jusqu'ici. Lorsque nous atteignons la fin du tableau, max contient le score le plus élevé de tout le tableau, que nous pouvons alors renvoyer à l'appelant.

// h/t au lecteur Waldo pour avoir suggéré ce quiz
#include <cassert>
#include <iostream>
#include <string_view>
#include <vector>

void fizzbuzz(int count)
{
    // Nous les rendons statiques afin de n'effectuer l'initialisation qu'une seule fois
    static const std::vector divisors                { 3, 5, 7, 11, 13, 17, 19 };
    static const std::vector<std::string_view> words { "fizz", "buzz", "pop", "bang", "jazz", "pow", "boom" };
    assert(std::size(divisors) == std::size(words) && "fizzbuzz: array sizes don't match");

    // Parcourt chaque nombre entre 1 et count (inclus)
    for (int i{ 1 }; i <= count; ++i)
    {
        bool printed{ false };

        // Compare le nombre courant à chaque diviseur possible
        for (std::size_t j{ 0 }; j < divisors.size(); ++j)
        {
            if (i % divisors[j] == 0)
            {
                std::cout << words[j];
                printed = true;
            }
        }

        // S'il n'y a aucun diviseur
        if (!printed)
            std::cout << i;

        std::cout << '\n';
    }
}

int main()
{
    fizzbuzz(150);

    return 0;
}

Astuce

Comme divisors et words sont des tableaux constants, il serait préférable de les déclarer constexpr, mais nous ne pouvons pas le faire avec un std::vector. Il serait préférable d'utiliser ici un constexpr std::array. Nous étudions std::array dans la leçon 17.1 -- Introduction à std::array.
