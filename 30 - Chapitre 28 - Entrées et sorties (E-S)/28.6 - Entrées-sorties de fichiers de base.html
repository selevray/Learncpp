28.6 — Entrées/sorties de fichiers de base

Les entrées/sorties de fichiers en C++ fonctionnent de manière très semblable aux entrées/sorties ordinaires (avec quelques complications mineures supplémentaires). Il existe 3 classes de base pour les entrées/sorties de fichiers en C++ : ifstream (dérivée de istream), ofstream (dérivée de ostream) et fstream (dérivée de iostream). Ces classes servent respectivement à l'entrée, à la sortie et à l'entrée/sortie de fichiers. Pour utiliser les classes d'entrées/sorties de fichiers, vous devez inclure l'en-tête fstream.

Contrairement aux flux cout, cin, cerr et clog, qui sont déjà prêts à l'emploi, les flux de fichiers doivent être explicitement initialisés par le programmeur. Cependant, c'est extrêmement simple : pour ouvrir un fichier en lecture et/ou en écriture, il suffit d'instancier un objet de la classe d'entrées/sorties de fichiers appropriée, en passant le nom du fichier en paramètre. Vous utilisez ensuite l'opérateur d'insertion (<<) ou d'extraction (>>) pour écrire des données dans le fichier ou en lire. Une fois terminé, plusieurs méthodes permettent de fermer un fichier : appeler explicitement la fonction close(), ou simplement laisser la variable d'entrées/sorties de fichier sortir de sa portée (le destructeur de la classe se chargera alors de fermer le fichier).

Écriture dans un fichier

Pour écrire dans un fichier dans l'exemple suivant, nous allons utiliser la classe ofstream. Cela est extrêmement simple :

#include <fstream>
#include <iostream>

int main()
{
    // ofstream est utilisée pour écrire dans des fichiers
    // Nous allons créer un fichier appelé Sample.txt
    std::ofstream outf{ "Sample.txt" };

    // Si nous n'avons pas pu ouvrir le flux de sortie du fichier en écriture
    if (!outf)
    {
        // Afficher une erreur et quitter
        std::cerr << "Oups, Sample.txt n'a pas pu être ouvert en écriture !\n";
        return 1;
    }

    // Nous allons écrire deux lignes dans ce fichier
    outf << "This is line 1\n";
    outf << "This is line 2\n";

    return 0;

    // Lorsque outf sort de sa portée, le destructeur
    // de ofstream fermera le fichier
}

Si vous regardez dans le répertoire de votre projet, vous devriez voir un fichier appelé Sample.txt. Si vous l'ouvrez avec un éditeur de texte, vous verrez qu'il contient bien les deux lignes que nous avons écrites dans le fichier.

Notez qu'il est également possible d'utiliser la fonction put() pour écrire un seul caractère dans le fichier.

Lecture d'un fichier

Nous allons maintenant reprendre le fichier écrit dans l'exemple précédent et le relire depuis le disque. Notez que ifstream renvoie 0 lorsque nous avons atteint la fin du fichier (EOF). Nous utiliserons ce fait pour déterminer la quantité de données à lire.

#include <fstream>
#include <iostream>
#include <string>

int main()
{
    // ifstream est utilisée pour lire des fichiers
    // Nous allons lire un fichier appelé Sample.txt
    std::ifstream inf{ "Sample.txt" };

    // Si nous n'avons pas pu ouvrir le flux d'entrée du fichier en lecture
    if (!inf)
    {
        // Afficher une erreur et quitter
        std::cerr << "Oups, Sample.txt n'a pas pu être ouvert en lecture !\n";
        return 1;
    }

    // Tant qu'il reste des données à lire
    std::string strInput{};
    while (inf >> strInput)
        std::cout << strInput << '\n';

    return 0;

    // Lorsque inf sort de sa portée, le destructeur
    // de ifstream fermera le fichier
}

Cela produit le résultat :


This
is
line
1
This
is
line
2

Hmmm, ce n'est pas tout à fait ce que nous voulions. Rappelez-vous que l'opérateur d'extraction s'arrête aux espaces. Pour lire des lignes entières, nous devons utiliser la fonction getline().

#include <fstream>
#include <iostream>
#include <string>

int main()
{
    // ifstream est utilisée pour lire des fichiers
    // Nous allons lire un fichier appelé Sample.txt
    std::ifstream inf{ "Sample.txt" };

    // Si nous n'avons pas pu ouvrir le flux d'entrée du fichier en lecture
    if (!inf)
    {
        // Afficher une erreur et quitter
        std::cerr << "Oups, Sample.txt n'a pas pu être ouvert en lecture !\n";
        return 1;
    }

    // Tant qu'il reste des données à lire
    std::string strInput{};
    while (std::getline(inf, strInput))
    std::cout << strInput << '\n';

    return 0;

    // Lorsque inf sort de sa portée, le destructeur
    // de ifstream fermera le fichier
}

Cela produit le résultat :


This is line 1
This is line 2

Sortie tamponnée

La sortie en C++ peut être tamponnée (bufferisée). Cela signifie que ce qui est envoyé à un flux de fichier peut ne pas être écrit immédiatement sur le disque. À la place, plusieurs opérations de sortie peuvent être regroupées et traitées ensemble. Cela se fait principalement pour des raisons de performance. Lorsqu'un tampon est écrit sur le disque, on parle de vidage (flushing) du tampon. Une façon de provoquer le vidage du tampon est de fermer le fichier : le contenu du tampon est alors vidé sur le disque, puis le fichier est fermé.

La mise en tampon ne pose généralement pas de problème, mais dans certaines circonstances elle peut causer des complications pour le programmeur distrait. Le principal coupable est le cas où il reste des données dans le tampon et où le programme se termine immédiatement (soit par un plantage, soit par un appel à exit()). Dans ces cas, les destructeurs des classes de flux de fichiers ne sont pas exécutés, ce qui signifie que les fichiers ne sont jamais fermés, et donc que les tampons ne sont jamais vidés. Les données présentes dans le tampon ne sont alors pas écrites sur le disque et sont perdues à jamais. C'est pourquoi il est toujours judicieux de fermer explicitement tous les fichiers ouverts avant d'appeler exit().

Il est possible de vider le tampon manuellement à l'aide de la fonction ostream::flush() ou en envoyant std::flush au flux de sortie. Ces deux méthodes peuvent être utiles pour s'assurer que le contenu du tampon est écrit immédiatement sur le disque, au cas où le programme planterait.

Notez également que std::endl; vide lui aussi le flux de sortie. Par conséquent, un usage excessif de std::endl (provoquant des vidages inutiles du tampon) peut avoir un impact sur les performances lors d'entrées/sorties tamponnées où les vidages sont coûteux (comme l'écriture dans un fichier). Pour cette raison, les programmeurs attentifs aux performances utilisent souvent '\n' plutôt que std::endl pour insérer un saut de ligne dans le flux de sortie, afin d'éviter des vidages inutiles du tampon.

Modes d'ouverture de fichiers

Que se passe-t-il si nous essayons d'écrire dans un fichier qui existe déjà ? Exécuter à nouveau l'exemple de sortie montre que le fichier d'origine est entièrement écrasé à chaque exécution du programme. Et si, au contraire, nous voulions ajouter des données à la fin du fichier ? Il s'avère que les constructeurs des flux de fichiers acceptent un second paramètre optionnel qui permet de préciser comment le fichier doit être ouvert. Ce paramètre s'appelle mode, et les indicateurs valides qu'il accepte sont définis dans la classe ios.

Mode de fichier ios Signification
app Ouvre le fichier en mode ajout (append)
ate Se positionne à la fin du fichier avant la lecture/écriture
binary Ouvre le fichier en mode binaire (au lieu du mode texte)
in Ouvre le fichier en mode lecture (par défaut pour ifstream)
out Ouvre le fichier en mode écriture (par défaut pour ofstream)
trunc Efface le fichier s'il existe déjà

Il est possible de spécifier plusieurs indicateurs en les combinant par un OU binaire (à l'aide de l'opérateur |). ifstream utilise par défaut le mode std::ios::in. ofstream utilise par défaut le mode std::ios::out. Et fstream utilise par défaut le mode std::ios::in | std::ios::out, ce qui signifie que vous pouvez lire et écrire par défaut.

Astuce

En raison de la manière dont fstream a été conçue, son ouverture peut échouer si std::ios::in est utilisé et que le fichier à ouvrir n'existe pas. Si vous devez créer un nouveau fichier avec fstream, utilisez uniquement le mode std::ios::out.

Écrivons un programme qui ajoute deux lignes supplémentaires au fichier Sample.txt créé précédemment :

#include <iostream>
#include <fstream>

int main()
{
    // Nous passons l'indicateur ios::app pour demander à ofstream d'ajouter
    // les données plutôt que de réécrire le fichier. Nous n'avons pas besoin de passer std::ios::out
    // car ofstream utilise std::ios::out par défaut
    std::ofstream outf{ "Sample.txt", std::ios::app };

    // Si nous n'avons pas pu ouvrir le flux de sortie du fichier en écriture
    if (!outf)
    {
        // Afficher une erreur et quitter
        std::cerr << "Oups, Sample.txt n'a pas pu être ouvert en écriture !\n";
        return 1;
    }

    outf << "This is line 3\n";
    outf << "This is line 4\n";

    return 0;

    // Lorsque outf sort de sa portée, le destructeur
    // de ofstream fermera le fichier
}

Si nous regardons maintenant Sample.txt (à l'aide de l'un des programmes ci-dessus qui affiche son contenu, ou en le chargeant dans un éditeur de texte), nous verrons ceci :


This is line 1
This is line 2
This is line 3
This is line 4

Ouverture explicite de fichiers avec open()

De même qu'il est possible de fermer explicitement un flux de fichier avec close(), il est aussi possible d'ouvrir explicitement un flux de fichier avec open(). open() fonctionne comme les constructeurs des flux de fichiers : elle prend un nom de fichier et un mode d'ouverture optionnel.

Par exemple :

std::ofstream outf{ "Sample.txt" };
outf << "This is line 1\n";
outf << "This is line 2\n";
outf.close(); // fermeture explicite du fichier

// Oups, nous avons oublié quelque chose
outf.open("Sample.txt", std::ios::app);
outf << "This is line 3\n";
outf.close();

Vous trouverez plus d'informations sur la fonction open() ici.
