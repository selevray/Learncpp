28.2 — Entrée avec istream

La bibliothèque iostream est assez complexe, nous ne pourrons donc pas la couvrir entièrement dans ces tutoriels. Nous présenterons toutefois les fonctionnalités les plus couramment utilisées. Dans cette section, nous examinerons différents aspects de la classe d'entrée (istream).

L'opérateur d'extraction

Comme vous l'avez vu dans de nombreuses leçons, nous pouvons utiliser l'opérateur d'extraction (>>) pour lire des informations depuis un flux d'entrée. C++ fournit des opérations d'extraction prédéfinies pour tous les types de données fondamentaux, et vous avez déjà vu comment surcharger l'opérateur d'extraction pour vos propres classes.

Lorsqu'on lit des chaînes, un problème courant avec l'opérateur d'extraction est d'empêcher l'entrée de déborder de votre tampon. Prenons l'exemple suivant :

char buf[10]{};
std::cin >> buf;

Que se passe-t-il si l'utilisateur saisit 18 caractères ? Le tampon déborde, et de mauvaises choses arrivent. D'une manière générale, il est déconseillé de faire des hypothèses sur le nombre de caractères que l'utilisateur va saisir.

Une façon de résoudre ce problème consiste à utiliser des manipulateurs (manipulators). Un manipulateur est un objet qui sert à modifier un flux lorsqu'il est utilisé avec l'opérateur d'extraction (>>) ou d'insertion (<<). Un manipulateur que vous avez déjà rencontré est « std::endl », qui écrit un caractère de saut de ligne et vide le tampon de sortie. C++ fournit un manipulateur appelé setw (dans l'en-tête iomanip) qui permet de limiter le nombre de caractères lus depuis un flux. Pour utiliser setw(), il suffit de fournir en paramètre le nombre maximum de caractères à lire, et de l'insérer dans votre instruction d'entrée comme suit :

#include <iomanip>
char buf[10]{};
std::cin >> std::setw(10) >> buf;

Ce programme ne lira désormais que les 9 premiers caractères du flux (en laissant de la place pour le caractère de fin de chaîne). Les caractères restants resteront dans le flux jusqu'à la prochaine extraction.

Extraction et espaces blancs

Pour rappel, l'opérateur d'extraction ignore les espaces blancs (espaces, tabulations et sauts de ligne).

Examinez le programme suivant :

int main()
{
    char ch{};
    while (std::cin >> ch)
        std::cout << ch;

    return 0;
}

Lorsque l'utilisateur saisit ceci :


Hello my name is Alex

L'opérateur d'extraction ignore les espaces et le saut de ligne. Par conséquent, la sortie est :


HellomynameisAlex

Il arrive souvent que vous souhaitiez récupérer la saisie de l'utilisateur sans ignorer les espaces blancs. Pour cela, la classe istream fournit de nombreuses fonctions qui servent à cet usage.

L'une des plus utiles est la fonction get(), qui lit simplement un caractère depuis le flux d'entrée. Voici le même programme que précédemment, mais utilisant get() :

int main()
{
    char ch{};
    while (std::cin.get(ch))
        std::cout << ch;

    return 0;
}

Maintenant, avec la même saisie :


Hello my name is Alex

La sortie est :


Hello my name is Alex

get() possède aussi une version pour les chaînes, qui prend un nombre maximum de caractères à lire :

int main()
{
    char strBuf[11]{};
    std::cin.get(strBuf, 11);
    std::cout << strBuf << '\n';

    return 0;
}

Si nous saisissons :


Hello my name is Alex

La sortie est :


Hello my n

Notez que nous n'avons lu que les 10 premiers caractères (il fallait en laisser un pour le caractère de fin de chaîne). Les caractères restants sont restés dans le flux d'entrée.

Un point important à noter à propos de get() est qu'il ne lit pas le caractère de saut de ligne ! Cela peut produire des résultats inattendus :

int main()
{
    char strBuf[11]{};
    // Lit jusqu'à 10 caractères
    std::cin.get(strBuf, 11);
    std::cout << strBuf << '\n';

    // Lit jusqu'à 10 caractères de plus
    std::cin.get(strBuf, 11);
    std::cout << strBuf << '\n';
    return 0;
}

Si l'utilisateur saisit :


Hello!

Le programme affichera :


Hello!

puis se terminera ! Pourquoi ne demande-t-il pas 10 caractères de plus ? La réponse est que le premier get() a lu jusqu'au saut de ligne, puis s'est arrêté. Le second get() a constaté qu'il restait encore des données dans le flux cin et a tenté de les lire. Or le premier caractère était le saut de ligne, donc il s'est arrêté immédiatement.

C'est pourquoi il existe une autre fonction, getline(), qui fonctionne de manière similaire à get(), mais extrait (et supprime) le délimiteur.

int main()
{
    char strBuf[11]{};
    // Lit jusqu'à 10 caractères
    std::cin.getline(strBuf, 11);
    std::cout << strBuf << '\n';

    // Lit jusqu'à 10 caractères de plus
    std::cin.getline(strBuf, 11);
    std::cout << strBuf << '\n';
    return 0;
}

Ce code se comportera comme vous vous y attendez, même si l'utilisateur saisit une chaîne contenant un saut de ligne.

Si vous devez savoir combien de caractères ont été extraits lors du dernier appel à getline(), utilisez gcount() :

int main()
{
    char strBuf[100]{};
    std::cin.getline(strBuf, 100);
    std::cout << strBuf << '\n';
    std::cout << std::cin.gcount() << " characters were read" << '\n';

    return 0;
}

gcount() comptabilise aussi les délimiteurs extraits et supprimés.

Une version particulière de getline() pour std::string

Il existe une version particulière de getline() qui n'appartient pas à la classe istream et sert à lire des variables de type std::string. Cette version n'est membre ni de ostream ni de istream, et figure dans l'en-tête string. Voici un exemple d'utilisation :

#include <string>
#include <iostream>

int main()
{
    std::string strBuf{};
    std::getline(std::cin, strBuf);
    std::cout << strBuf << '\n';

    return 0;
}

Quelques autres fonctions utiles de istream

Il existe encore quelques fonctions d'entrée utiles que vous pourriez vouloir utiliser :

ignore() supprime le premier caractère du flux.
ignore(int nCount) supprime les nCount premiers caractères.
peek() permet de lire un caractère du flux sans le retirer du flux.
unget() remet le dernier caractère lu dans le flux, afin qu'il puisse être lu à nouveau lors de l'appel suivant.
putback(char ch) permet de replacer dans le flux le caractère de votre choix, qui sera lu lors de l'appel suivant.

istream contient de nombreuses autres fonctions et variantes des fonctions mentionnées ci-dessus, qui peuvent être utiles selon ce que vous devez faire. Vous pouvez les consulter sur un site de référence tel que https://en.cppreference.com/w/cpp/io/basic_istream.
