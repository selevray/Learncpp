12.9 — Pointeurs et const

Considérons l'extrait de code suivant :

int main()
{
    int x { 5 };
    int* ptr { &x }; // ptr est un pointeur normal (non const)

    int y { 6 };
    ptr = &y; // nous pouvons pointer vers une autre valeur

    *ptr = 7; // nous pouvons modifier la valeur à l'adresse contenue

    return 0;
}

Avec des pointeurs normaux (non const), nous pouvons modifier à la fois ce que le pointeur désigne (en lui affectant une nouvelle adresse à contenir) et la valeur située à l'adresse contenue (en affectant une nouvelle valeur au pointeur déréférencé).

Cependant, que se passe-t-il si la valeur que nous voulons pointer est const ?

int main()
{
    const int x { 5 }; // x est maintenant const
    int* ptr { &x };   // erreur de compilation : impossible de convertir const int* en int*

    return 0;
}

L'extrait ci-dessus ne compile pas : nous ne pouvons pas faire pointer un pointeur normal vers une variable const. Cela a du sens : une variable const est une variable dont la valeur ne peut pas être modifiée. Autoriser le programmeur à faire pointer un pointeur non const vers une valeur const lui permettrait de déréférencer le pointeur et de modifier la valeur. Cela violerait le caractère constant de la variable.

Pointeur vers une valeur const

Un pointeur vers une valeur const (appelé parfois pointer to const en abrégé) est un pointeur (non const) qui pointe vers une valeur constante.

Pour déclarer un pointeur vers une valeur const, utilisez le mot-clé const avant le type de données du pointeur :

int main()
{
    const int x{ 5 };
    const int* ptr { &x }; // correct : ptr pointe vers un "const int"

    *ptr = 6; // interdit : nous ne pouvons pas modifier une valeur const

    return 0;
}

Dans l'exemple ci-dessus, ptr pointe vers un const int. Comme le type de données pointé est const, la valeur pointée ne peut pas être modifiée.

Cependant, comme un pointeur vers const n'est pas lui-même const (il pointe simplement vers une valeur const), nous pouvons modifier ce que le pointeur désigne en lui affectant une nouvelle adresse :

int main()
{
    const int x{ 5 };
    const int* ptr { &x }; // ptr pointe vers le const int x

    const int y{ 6 };
    ptr = &y; // correct : ptr pointe maintenant vers le const int y

    return 0;
}

Tout comme une référence vers const, un pointeur vers const peut aussi pointer vers des variables non const. Un pointeur vers const traite la valeur pointée comme constante, que l'objet situé à cette adresse ait été initialement défini comme const ou non :

int main()
{
    int x{ 5 }; // non const
    const int* ptr { &x }; // ptr pointe vers un "const int"

    *ptr = 6;  // interdit : ptr pointe vers un "const int", nous ne pouvons donc pas modifier la valeur через ptr
    x = 6; // autorisé : la valeur reste non const lorsqu'elle est accédée par l'identifiant non const x

    return 0;
}

Pointeurs const

Nous pouvons aussi rendre le pointeur lui-même constant. Un pointeur const est un pointeur dont l'adresse ne peut pas être modifiée après l'initialisation.

Pour déclarer un pointeur const, utilisez le mot-clé const après l'astérisque dans la déclaration du pointeur :

int main()
{
    int x{ 5 };
    int* const ptr { &x }; // const après l'astérisque : il s'agit d'un pointeur const

    return 0;
}

Dans le cas ci-dessus, ptr est un pointeur const vers une valeur int (non const).

Tout comme une variable const normale, un pointeur const doit être initialisé lors de sa définition, et cette valeur ne peut pas être modifiée par affectation :

int main()
{
    int x{ 5 };
    int y{ 6 };

    int* const ptr { &x }; // correct : le pointeur const est initialisé avec l'adresse de x
    ptr = &y; // erreur : une fois initialisé, un pointeur const ne peut pas être modifié.

    return 0;
}

Cependant, comme la valeur pointée est non const, il est possible de modifier la valeur pointée en déréférençant le pointeur const :

int main()
{
    int x{ 5 };
    int* const ptr { &x }; // ptr pointera toujours vers x

    *ptr = 6; // correct : la valeur pointée est non const

    return 0;
}

Pointeur const vers une valeur const

Enfin, il est possible de déclarer un pointeur const vers une valeur const en utilisant le mot-clé const à la fois avant le type et après l'astérisque :

int main()
{
    int value { 5 };
    const int* const ptr { &value }; // un pointeur const vers une valeur const

    return 0;
}

Un pointeur const vers une valeur const ne peut pas voir son adresse modifiée, et la valeur qu'il pointe ne peut pas non plus être modifiée via le pointeur. Il peut seulement être déréférencé pour obtenir la valeur qu'il désigne.

Récapitulatif sur les pointeurs et const

Pour résumer, vous n'avez besoin de retenir que 4 règles, qui sont assez logiques :

  • Un pointeur non const (par exemple int* ptr) peut se voir affecter une autre adresse pour changer ce qu'il désigne.

  • Un pointeur const (par exemple int* const ptr) pointe toujours vers la même adresse, et cette adresse ne peut pas être modifiée.

  • Un pointeur vers une valeur non const (par exemple int* ptr) peut modifier la valeur qu'il pointe. Ceux-ci ne peuvent pas pointer vers une valeur const.

  • Un pointeur vers une valeur const (par exemple const int* ptr) traite la valeur comme const lorsqu'elle est accédée via le pointeur, et ne peut donc pas modifier la valeur qu'il pointe. Ils peuvent pointer vers des l-values const ou non const (mais pas vers des r-values, qui n'ont pas d'adresse).

Retenir la syntaxe des déclarations peut être un peu difficile :

  • Un const avant l'astérisque (par exemple const int* ptr) est associé au type pointé. Il s'agit donc d'un pointeur vers une valeur const, et la valeur ne peut pas être modifiée via le pointeur.
  • Un const après l'astérisque (par exemple int* const ptr) est associé au pointeur lui-même. Ce pointeur ne peut donc pas se voir affecter une nouvelle adresse.
int main()
{
    int v{ 5 };

    int* ptr0 { &v };             // pointe vers un "int" mais n'est pas const lui-même. Nous pouvons modifier la valeur ou l'adresse.
    const int* ptr1 { &v };       // pointe vers un "const int" mais n'est pas const lui-même. Nous ne pouvons modifier que l'adresse.
    int* const ptr2 { &v };       // pointe vers un "int" et est const lui-même. Nous ne pouvons modifier que la valeur.
    const int* const ptr3 { &v }; // pointe vers un "const int" et est const lui-même. Nous ne pouvons modifier ni la valeur ni l'adresse.

    // si le const est à gauche de *, le const s'applique à la valeur
    // si le const est à droite de *, le const s'applique au pointeur

    return 0;
}
