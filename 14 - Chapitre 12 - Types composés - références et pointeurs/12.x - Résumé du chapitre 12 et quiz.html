12.x — Résumé du chapitre 12 et quiz

Revue rapide

Les types de données composés (aussi appelés types de données composites) sont des types de données qui peuvent être construits à partir de types de données fondamentaux (ou d'autres types composés).

La catégorie de valeur d'une expression indique si cette expression correspond à une valeur, une fonction ou un objet d'un certain genre.

Une lvalue est une expression qui s'évalue en une fonction ou un objet ayant une identité. Un objet ou une fonction possédant une identité a un identifiant ou une adresse mémoire identifiable. Les lvalues se répartissent en deux sous-catégories : les lvalues modifiables, qui peuvent être modifiées, et les lvalues non modifiables, dont la valeur ne peut pas être modifiée (généralement parce qu'elles sont const ou constexpr).

Une rvalue est une expression qui n'est pas une lvalue. Cela inclut les littéraux (à l'exception des littéraux de chaîne) et les valeurs de retour des fonctions ou opérateurs (lorsqu'elles sont retournées par valeur).

Une référence est un alias d'un objet existant. Une fois une référence définie, toute opération effectuée sur la référence s'applique à l'objet référencé. C++ propose deux types de références : les références lvalue et les références rvalue. Une référence lvalue (couramment appelée simplement référence) agit comme un alias d'une lvalue existante (par exemple une variable). Une variable de référence lvalue est une variable qui agit comme une référence vers une lvalue (généralement une autre variable).

Lorsqu'une référence est initialisée avec un objet (ou une fonction), on dit qu'elle est liée (en anglais bound) à cet objet (ou cette fonction). L'objet (ou la fonction) référencé est parfois appelé le référent.

Les références lvalue ne peuvent pas être liées à des lvalues non modifiables ni à des rvalues (sinon, on pourrait modifier ces valeurs par l'intermédiaire de la référence, ce qui violerait leur caractère constant). Pour cette raison, les références lvalue sont parfois appelées références lvalue vers non-const (souvent abrégées en référence non-const).

Une fois initialisée, une référence en C++ ne peut pas être réassignée (en anglais reseated), c'est-à-dire qu'elle ne peut pas être modifiée pour référencer un autre objet.

Lorsque l'objet référencé est détruit avant la référence qui le désigne, la référence reste liée à un objet qui n'existe plus. Une telle référence est appelée référence pendante (en anglais dangling reference). Accéder à une référence pendante entraîne un comportement indéfini.

En utilisant le mot-clé const lors de la déclaration d'une référence lvalue, on indique à cette référence de traiter l'objet référencé comme constant. Une telle référence est appelée référence lvalue vers une valeur const (parfois appelée référence vers const ou référence const). Les références const peuvent se lier à des lvalues modifiables, à des lvalues non modifiables et à des rvalues.

Un objet temporaire (aussi appelé objet sans nom ou objet anonyme) est un objet créé pour un usage temporaire (puis détruit) au sein d'une seule expression.

Lors d'un passage par référence, on déclare un paramètre de fonction comme une référence (ou une référence const) plutôt que comme une variable ordinaire. Lorsque la fonction est appelée, chaque paramètre référence est lié à l'argument correspondant. Comme la référence agit comme un alias de l'argument, aucune copie de cet argument n'est créée.

L'opérateur d'adresse (&) renvoie l'adresse mémoire de son opérande. L'opérateur de déréférencement (*) renvoie, sous forme de lvalue, la valeur située à une adresse mémoire donnée.

Un pointeur est un objet qui contient une adresse mémoire (généralement celle d'une autre variable) comme valeur. Cela permet de stocker l'adresse d'un autre objet pour l'utiliser plus tard. Comme les variables ordinaires, les pointeurs ne sont pas initialisés par défaut. Un pointeur non initialisé est parfois appelé pointeur sauvage (en anglais wild pointer). Un pointeur pendant (en anglais dangling pointer) est un pointeur qui contient l'adresse d'un objet qui n'est plus valide (par exemple parce qu'il a été détruit).

Outre une adresse mémoire, un pointeur peut contenir une autre valeur : la valeur nulle. Une valeur nulle (souvent abrégée en null) est une valeur spéciale signifiant que quelque chose n'a pas de valeur. Lorsqu'un pointeur contient une valeur nulle, cela signifie qu'il ne pointe sur rien. Un tel pointeur est appelé pointeur nul. Le mot-clé nullptr représente le littéral de pointeur nul. On peut utiliser nullptr pour initialiser ou affecter explicitement une valeur nulle à un pointeur.

Un pointeur doit soit contenir l'adresse d'un objet valide, soit être égal à nullptr. Ainsi, il suffit de tester si un pointeur est nul, et on peut considérer que tout pointeur non nul est valide.

Un pointeur vers une valeur const (souvent appelé pointeur vers const en abrégé) est un pointeur (non const) qui pointe vers une valeur constante.

Un pointeur const est un pointeur dont l'adresse ne peut pas être modifiée après l'initialisation.

Un pointeur const vers une valeur const ne peut ni voir son adresse modifiée, ni permettre la modification de la valeur pointée par son intermédiaire.

Avec le passage par adresse, au lieu de fournir un objet comme argument, l'appelant fournit l'adresse d'un objet (via un pointeur). Ce pointeur (qui contient l'adresse de l'objet) est copié dans un paramètre pointeur de la fonction appelée (qui contient alors également l'adresse de l'objet). La fonction peut ensuite déréférencer ce pointeur pour accéder à l'objet dont l'adresse a été transmise.

Le retour par référence renvoie une référence liée à l'objet retourné, ce qui évite de copier la valeur de retour. Le retour par référence présente un inconvénient majeur : le programmeur doit s'assurer que l'objet référencé survit à la fonction qui renvoie la référence. Sinon, la référence renvoyée sera pendante (elle référencera un objet détruit), et son utilisation entraînera un comportement indéfini. Si un paramètre est passé à une fonction par référence, il est sans danger de retourner ce paramètre par référence.

Si une fonction renvoie une référence, et que cette référence est utilisée pour initialiser ou affecter une variable qui n'est pas une référence, la valeur de retour sera copiée (comme si elle avait été retournée par valeur).

La déduction de type pour les variables (via le mot-clé auto) supprime toute qualification de référence ou const de premier niveau du type déduit. Ces qualificateurs peuvent être réappliqués lors de la déclaration de la variable, si besoin.

Le retour par adresse fonctionne presque de la même manière que le retour par référence, si ce n'est qu'un pointeur vers un objet est renvoyé à la place d'une référence vers un objet.

Quiz

Question n° 1

Pour chacune des expressions suivantes situées à droite de l'opérateur <<, indiquez s'il s'agit d'une lvalue ou d'une rvalue :

a)

std::cout << 5;
Solution

Les littéraux sont des rvalues, donc 5 est une rvalue.

b)

int x { 5 };
std::cout << x;
Solution

L'expression x identifie la variable x, cette expression est donc une lvalue.

c)

int x { 5 };
std::cout << x + 1;
Solution

L'expression x + 1 calcule une valeur temporaire, cette expression est donc une rvalue.

d)

int foo() { return 5; }
std::cout << foo();
Solution

La valeur de retour d'une fonction (lorsqu'elle est retournée par valeur) est une rvalue.

e)

int& max(int &x, int &y) { return x > y ? x : y; }
int x { 5 };
int y { 6 };
std::cout << max(x, y);
Solution

max() renvoie une référence lvalue, qui est une lvalue.

Question n° 2

Quelle est la sortie de ce programme ?

#include <iostream>

int main()
{
    int x{ 4 };
    int y{ 6 };

    int& ref{ x };
    ++ref;
    ref = y;
    ++ref;

    std::cout << x << ' ' << y;

    return 0;
}
Solution 

7 6

Rappelez-vous que les références ne peuvent pas être réassignées : ref = y ne fait pas de ref une référence vers y. C'est équivalent à x = y.

Avec des commentaires explicatifs :

#include <iostream>

int main()
{
    int x{ 4 };
    int y{ 6 };

    int& ref{ x }; // ref est maintenant un alias de `x`
    ++ref;   // x vaut maintenant 5
    ref = y; // x vaut maintenant 6
    ++ref;   // x vaut maintenant 7

    std::cout << x << ' ' << y; // affiche 7 6

    return 0;
}

Question n° 3

Donnez deux raisons pour lesquelles nous préférons passer les arguments par référence const plutôt que par référence non-const, chaque fois que c'est possible.

Solution
  1. Un paramètre référence non-const peut servir à modifier la valeur de l'argument. Si nous n'avons pas besoin de cette possibilité, il vaut mieux passer par référence const afin de ne pas modifier l'argument par accident.
  2. Un paramètre référence non-const ne peut accepter en argument qu'une lvalue modifiable. Un paramètre référence const peut accepter en argument une lvalue modifiable, une lvalue non modifiable ou une rvalue.

Question n° 4

Quelle est la différence entre un pointeur const et un pointeur vers const ?

Solution

Un pointeur const est un pointeur dont l'adresse ne peut pas être modifiée (il ne peut pas être redirigé vers un autre objet). En revanche, la valeur de l'objet pointé peut être modifiée. Un pointeur vers const est un pointeur qui pointe vers un objet dont la valeur ne peut pas être modifiée par l'intermédiaire de ce pointeur. En revanche, le pointeur peut être redirigé vers un autre objet.

Question n° 5

Écrivez une fonction nommée sort2 qui permet à l'appelant de passer deux variables int en arguments. Au retour de la fonction, le premier argument doit contenir la plus petite des deux valeurs, et le second argument la plus grande.

Indice : la fonction std::swap() (dans l'en-tête <algorithm>) permet d'échanger les valeurs de deux variables. Par exemple, std::swap(x, y) échange les valeurs des variables x et y.

Le code suivant doit s'exécuter et afficher les valeurs indiquées dans les commentaires :

#include <iostream>

int main()
{
    int x { 7 };
    int y { 5 };

    std::cout << x << ' ' << y << '\n'; // doit afficher 7 5

    sort2(x, y); // vérifie que sort2 fonctionne lorsqu'il faut échanger les valeurs
    std::cout << x << ' ' << y << '\n'; // doit afficher 5 7

    sort2(x, y); // vérifie que sort2 fonctionne lorsqu'il ne faut pas échanger les valeurs
    std::cout << x << ' ' << y << '\n'; // doit afficher 5 7

    return 0;
}
Solution 
#include <algorithm> // pour std::swap
#include <iostream>

void sort2(int& lesser, int& greater)
{
    // Si les valeurs ne sont pas triées, il faut les échanger
    if (lesser > greater)
        std::swap(lesser, greater);

    // Si nous écrivions notre propre échange, nous pourrions procéder ainsi :
    // int swap { lesser };
    // lesser = greater;
    // greater = swap;

}

int main()
{
    int x { 7 };
    int y { 5 };

    std::cout << x << ' ' << y << '\n';

    sort2(x, y); // vérifie que sort2 fonctionne lorsqu'il faut échanger les valeurs
    std::cout << x << ' ' << y << '\n';

    sort2(x, y); // vérifie que sort2 fonctionne lorsqu'il ne faut pas échanger les valeurs
    std::cout << x << ' ' << y << '\n';

    return 0;
}
