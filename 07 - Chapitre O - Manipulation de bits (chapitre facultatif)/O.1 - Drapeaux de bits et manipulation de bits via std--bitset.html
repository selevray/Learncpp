O.1 — Drapeaux de bits et manipulation de bits via std::bitset

Sur les architectures informatiques modernes, la plus petite unité de mémoire adressable est l'octet. Comme tous les objets doivent avoir des adresses mémoire uniques, chaque objet occupe au moins un octet. Pour la plupart des types de variables, cela ne pose aucun problème. En revanche, pour les valeurs booléennes, c'est un gaspillage (jeu de mots intentionnel). Un type booléen ne possède que deux états : vrai (1) ou faux (0). Ces deux états ne nécessitent qu'un seul bit pour être stockés. Pourtant, comme une variable doit occuper au moins un octet, soit 8 bits, un booléen utilise 1 bit et laisse les 7 autres inutilisés.

Dans la grande majorité des cas, cela n'a pas d'importance : nous ne manquons généralement pas de mémoire au point de devoir nous soucier de 7 bits perdus. Nous avons plutôt intérêt à optimiser la lisibilité et la maintenabilité. Toutefois, dans certains cas où le stockage est critique, il peut être utile de « compresser » 8 valeurs booléennes individuelles dans un seul octet afin de gagner de la place.

Ces opérations nécessitent de pouvoir manipuler les objets au niveau du bit. Heureusement, C++ nous fournit les outils pour le faire. La modification de bits individuels dans un objet s'appelle la manipulation de bits (bit manipulation).

Note de l'auteur

La manipulation de bits est très utilisée dans certains contextes de programmation (par exemple l'infographie, le chiffrement, la compression et l'optimisation), mais beaucoup moins en programmation générale.

C'est pourquoi ce chapitre entier est facultatif. N'hésitez pas à le sauter ou à le parcourir rapidement, et à y revenir plus tard.

Drapeaux de bits

Jusqu'ici, nous avons utilisé des variables pour contenir une valeur unique :

int foo { 5 }; // affecte à foo la valeur 5 (utilise probablement 32 bits de stockage)
std::cout << foo; // affiche la valeur 5

Cependant, plutôt que de considérer un objet comme contenant une seule valeur, nous pouvons traiter chaque bit de l'objet comme une valeur booléenne indépendante. Lorsque les bits d'un objet sont utilisés comme des valeurs booléennes, on les appelle des drapeaux de bits (bit flags).

Nomenclature

Un bit valant 0 est dit « faux », « désactivé » ou « non positionné ».
Un bit valant 1 est dit « vrai », « activé » ou « positionné ».
Lorsqu'un bit passe de 0 à 1 ou de 1 à 0, on dit qu'il a été « basculé » ou « inversé ».

En passant…

En informatique, un drapeau (flag) est une valeur qui signale l'existence d'une condition dans un programme. Avec un drapeau de bit, la valeur true signifie que la condition est remplie.

De façon analogue, aux États-Unis, de nombreuses boîtes aux lettres possèdent de petits drapeaux physiques (généralement rouges) fixés sur le côté. Lorsqu'un courrier sortant attend d'être récupéré par le facteur, le drapeau est levé pour signaler la présence de ce courrier.

Pour définir un ensemble de drapeaux de bits, nous utilisons généralement un entier non signé de la taille appropriée (8 bits, 16 bits, 32 bits, etc., selon le nombre de drapeaux nécessaires), ou std::bitset.

#include <bitset> // pour std::bitset

std::bitset<8> mybitset {}; // une taille de 8 bits permet de stocker 8 drapeaux

Bonne pratique

La manipulation de bits est l'un des rares cas où vous devriez, sans ambiguïté, utiliser des entiers non signés (ou std::bitset).

Dans cette leçon, nous montrerons comment réaliser la manipulation de bits de manière simple, grâce à std::bitset. Dans la prochaine série de leçons, nous verrons comment la réaliser de façon plus difficile, mais plus polyvalente.

Numérotation des bits et positions de bits

Pour une séquence de bits, on numérote généralement les bits de droite à gauche, en commençant par 0 (et non par 1). Chaque numéro désigne une position de bit (bit position).


76543210  Position du bit
00000101  Séquence de bits

Pour la séquence de bits 0000 0101, les bits situés aux positions 0 et 2 ont la valeur 1, et les autres bits ont la valeur 0.

Manipuler des bits via std::bitset

Dans la leçon 5.3 -- Systèmes de numération (décimal, binaire, hexadécimal et octal), nous avons déjà montré comment utiliser un std::bitset pour afficher des valeurs en binaire. Toutefois, ce n'est pas la seule chose utile que std::bitset sait faire.

std::bitset fournit 4 fonctions membres essentielles pour la manipulation de bits :

  • test() permet de savoir si un bit vaut 0 ou 1.
  • set() permet d'activer un bit (sans effet si le bit est déjà activé).
  • reset() permet de désactiver un bit (sans effet si le bit est déjà désactivé).
  • flip() permet de basculer la valeur d'un bit de 0 à 1 ou inversement.

Chacune de ces fonctions prend pour unique argument la position du bit sur lequel on souhaite agir.

Voici un exemple :

#include <bitset>
#include <iostream>

int main()
{
    std::bitset<8> bits{ 0b0000'0101 }; // il nous faut 8 bits, on part du motif binaire 0000 0101
    bits.set(3);   // place le bit en position 3 à 1 (on obtient maintenant 0000 1101)
    bits.flip(4);  // bascule le bit 4 (on obtient maintenant 0001 1101)
    bits.reset(4); // remet le bit 4 à 0 (on obtient maintenant 0000 1101)

    std::cout << "All the bits: " << bits<< '\n';
    std::cout << "Bit 3 has value: " << bits.test(3) << '\n';
    std::cout << "Bit 4 has value: " << bits.test(4) << '\n';

    return 0;
}

Ce programme affiche :


All the bits: 00001101
Bit 3 has value: 1
Bit 4 has value: 0

Rappel

Nous avons présenté les fonctions membres dans la leçon 5.7 -- Introduction à std::string. Avec une fonction ordinaire, on appelle function(object). Avec une fonction membre, on appelle object.function().

Nous avons abordé le préfixe de littéral binaire 0b et le séparateur de chiffres ' dans la leçon 5.3 -- Systèmes de numération (décimal, binaire, hexadécimal et octal).

Donner des noms à nos bits peut rendre notre code plus lisible :

#include <bitset>
#include <iostream>

int main()
{
    [[maybe_unused]] constexpr int  isHungry   { 0 };
    [[maybe_unused]] constexpr int  isSad      { 1 };
    [[maybe_unused]] constexpr int  isMad      { 2 };
    [[maybe_unused]] constexpr int  isHappy    { 3 };
    [[maybe_unused]] constexpr int  isLaughing { 4 };
    [[maybe_unused]] constexpr int  isAsleep   { 5 };
    [[maybe_unused]] constexpr int  isDead     { 6 };
    [[maybe_unused]] constexpr int  isCrying   { 7 };

    std::bitset<8> me{ 0b0000'0101 }; // il nous faut 8 bits, on part du motif binaire 0000 0101
    me.set(isHappy);      // place le bit en position 3 à 1 (on obtient maintenant 0000 1101)
    me.flip(isLaughing);  // bascule le bit 4 (on obtient maintenant 0001 1101)
    me.reset(isLaughing); // remet le bit 4 à 0 (on obtient maintenant 0000 1101)

    std::cout << "All the bits: " << me << '\n';
    std::cout << "I am happy: " << me.test(isHappy) << '\n';
    std::cout << "I am laughing: " << me.test(isLaughing) << '\n';

    return 0;
}

Que faire si nous voulons lire ou écrire plusieurs bits à la fois

std::bitset ne facilite pas cette tâche. Pour cela, ou si nous voulons utiliser des entiers non signés comme drapeaux de bits à la place de std::bitset, il faut recourir à des méthodes plus traditionnelles. Nous les verrons dans les deux ou trois prochaines leçons.

La taille de std::bitset

Une surprise possible est que std::bitset est optimisé pour la vitesse, et non pour l'économie de mémoire. La taille d'un std::bitset correspond généralement au nombre d'octets nécessaires pour contenir les bits, arrondi au-dessus au multiple de sizeof(size_t) le plus proche, soit 4 octets sur les machines 32 bits et 8 octets sur les machines 64 bits.

Ainsi, un std::bitset<8> occupera généralement 4 ou 8 octets en mémoire, alors qu'il ne lui faudrait techniquement qu'un seul octet pour stocker 8 bits. std::bitset est donc surtout utile lorsque l'on recherche le confort d'utilisation, et non l'économie de mémoire.

Interroger un std::bitset

Quelques autres fonctions membres sont souvent utiles :

  • size() renvoie le nombre de bits du bitset.
  • count() renvoie le nombre de bits du bitset qui valent true.
  • all() renvoie un booléen indiquant si tous les bits valent true.
  • any() renvoie un booléen indiquant si au moins un bit vaut true.
  • none() renvoie un booléen indiquant si aucun bit ne vaut true.
#include <bitset>
#include <iostream>

int main()
{
    std::bitset<8> bits{ 0b0000'1101 };
    std::cout << bits.size() << " bits are in the bitset\n";
    std::cout << bits.count() << " bits are set to true\n";

    std::cout << std::boolalpha;
    std::cout << "All bits are true: " << bits.all() << '\n';
    std::cout << "Some bits are true: " << bits.any() << '\n';
    std::cout << "No bits are true: " << bits.none() << '\n';

    return 0;
}

Ce programme affiche :


8 bits are in the bitset
3 bits are set to true
All bits are true: false
Some bits are true: true
No bits are true: false
