13.7 — Introduction aux structures, membres et sélection de membres

Il existe de nombreuses situations en programmation où nous avons besoin de plusieurs variables pour représenter une même entité. Comme nous l'avons vu dans l'introduction du chapitre précédent (12.1 -- Introduction aux types composés), une fraction possède un numérateur et un dénominateur, qui sont liés pour former un seul objet mathématique.

Supposons maintenant que nous voulions écrire un programme qui stocke des informations sur les employés d'une entreprise. Nous pourrions souhaiter suivre des attributs tels que le nom de l'employé, son poste, son âge, son identifiant, l'identifiant de son responsable, son salaire, sa date de naissance, sa date d'embauche, etc.

Si nous utilisions des variables indépendantes pour suivre toutes ces informations, cela pourrait ressembler à ceci :

std::string name;
std::string title;
int age;
int id;
int managerId;
double wage;
int birthdayYear;
int birthdayMonth;
int birthdayDay;
int hireYear;
int hireMonth;
int hireDay;

Cette approche pose toutefois plusieurs problèmes. Premièrement, il n'est pas immédiatement évident que ces variables soient liées entre elles (il faudrait lire les commentaires ou observer leur utilisation dans le contexte). Deuxièmement, nous avons désormais 12 variables à gérer. Si nous voulions passer cet employé à une fonction, nous devrions transmettre 12 arguments (dans le bon ordre), ce qui rendrait les prototypes et les appels de fonctions illisibles. Et comme une fonction ne peut renvoyer qu'une seule valeur, comment une fonction pourrait-elle même renvoyer un employé ?

Et si nous voulions plusieurs employés, nous devrions définir 12 nouvelles variables pour chaque employé supplémentaire (chacune avec un nom unique) ! Cette approche ne passe clairement pas à l'échelle. Ce dont nous avons réellement besoin, c'est d'un moyen d'organiser toutes ces données liées ensemble, pour les gérer plus facilement.

Heureusement, C++ propose deux types composés conçus pour répondre à ce problème : les structures (que nous présentons maintenant) et les classes (que nous étudierons bientôt). Une structure (en anglais struct, pour structure) est un type de données défini par le programmeur (13.1 -- Introduction aux types de données définis par le programmeur (user-defined)) qui permet de regrouper plusieurs variables en un seul type. Comme vous le verrez bientôt, cela simplifie considérablement la gestion d'ensembles de variables liées !

Rappel

Une structure est un type classe (tout comme les classes et les unions). À ce titre, tout ce qui s'applique aux types classes s'applique aussi aux structures.

Définir une structure

Comme une structure est un type défini par le programmeur, nous devons d'abord indiquer au compilateur à quoi ressemble notre type de structure avant de pouvoir l'utiliser. Voici un exemple de définition de structure pour un employé simplifié :

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

Le mot-clé struct indique au compilateur que nous définissons une structure, que nous avons nommée Employee (les types définis par le programmeur portent généralement un nom commençant par une majuscule).

Ensuite, entre une paire d'accolades, nous définissons les variables que contiendra chaque objet Employee. Dans cet exemple, chaque Employee que nous créerons comportera 3 variables : un int id, un int age et un double wage. Les variables qui font partie de la structure sont appelées membres de données (ou variables membres).

Astuce

Dans le langage courant, un membre est une personne qui appartient à un groupe. Par exemple, vous pouvez être membre de l'équipe de basket, et votre sœur peut être membre de la chorale.

En C++, un membre est une variable, une fonction ou un type qui appartient à une structure (ou à une classe). Tous les membres doivent être déclarés à l'intérieur de la définition de la structure (ou de la classe).

Nous utiliserons souvent le terme membre dans les leçons à venir, veillez donc à bien retenir sa signification.

De même que nous utilisons une paire d'accolades vide pour l'initialisation par valeur (1.4 -- Affectation et initialisation des variables) des variables ordinaires, les accolades vides placées après chaque variable membre garantissent que les variables membres à l'intérieur de notre Employee sont initialisées par valeur lorsqu'un Employee est créé. Nous en reparlerons lorsque nous aborderons l'initialisation par défaut des membres dans quelques leçons (13.9 -- Initialisation par défaut des membres).

Enfin, nous terminons la définition du type par un point-virgule.

Pour rappel, Employee n'est qu'une définition de type : aucun objet n'est réellement créé à ce stade.

Définir des objets de type structure

Pour utiliser le type Employee, il suffit de définir une variable de ce type :

Employee joe {}; // Employee est le type, joe le nom de la variable

Cela définit une variable de type Employee nommée joe. Lorsque le code est exécuté, un objet Employee est instancié et contient les 3 membres de données. Les accolades vides garantissent que notre objet est initialisé par valeur.

Comme pour tout autre type, il est possible de définir plusieurs variables du même type structure :

Employee joe {}; // crée une structure Employee pour Joe
Employee frank {}; // crée une structure Employee pour Frank

Accéder aux membres

Considérons l'exemple suivant :

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

int main()
{
    Employee joe {};

    return 0;
}

Dans cet exemple, le nom joe désigne l'objet structure entier (qui contient les variables membres). Pour accéder à une variable membre précise, nous utilisons l'opérateur de sélection de membre (operator.) placé entre le nom de la variable de structure et le nom du membre. Par exemple, pour accéder au membre age de Joe, nous utiliserons joe.age.

Les variables membres d'une structure fonctionnent exactement comme des variables ordinaires : il est donc possible d'effectuer sur elles les opérations habituelles, notamment l'affectation, l'arithmétique, la comparaison, etc.

#include <iostream>

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

int main()
{
    Employee joe {};

    joe.age = 32;  // utilise l'opérateur de sélection de membre (.) pour sélectionner le membre age de la variable joe

    std::cout << joe.age << '\n'; // affiche l'âge de joe

    return 0;
}

Ce programme affiche :


32

L'un des plus grands avantages des structures est que nous n'avons besoin de créer qu'un seul nom par variable de structure (les noms des membres sont fixés dans la définition du type structure). Dans l'exemple suivant, nous instancions deux objets Employee : joe et frank.

#include <iostream>

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

int main()
{
    Employee joe {};
    joe.id = 14;
    joe.age = 32;
    joe.wage = 60000.0;

    Employee frank {};
    frank.id = 15;
    frank.age = 28;
    frank.wage = 45000.0;

    int totalAge { joe.age + frank.age };
    std::cout << "Joe and Frank have lived " << totalAge << " total years\n";

    if (joe.wage > frank.wage)
        std::cout << "Joe makes more than Frank\n";
    else if (joe.wage < frank.wage)
        std::cout << "Joe makes less than Frank\n";
    else
        std::cout << "Joe and Frank make the same amount\n";

    // Frank a obtenu une promotion
    frank.wage += 5000.0;

    // Aujourd'hui c'est l'anniversaire de Joe
    ++joe.age; // utilise la pré-incrémentation pour augmenter l'âge de Joe de 1

    return 0;
}

Dans cet exemple, il est très facile de savoir quelles variables membres appartiennent à Joe et lesquelles appartiennent à Frank. Cela offre un niveau d'organisation bien supérieur à celui de variables individuelles. De plus, comme les membres de Joe et de Frank portent les mêmes noms, on obtient une cohérence lorsque l'on dispose de plusieurs variables du même type structure.

Nous poursuivrons notre étude des structures dans la prochaine leçon, notamment en découvrant comment les initialiser.
