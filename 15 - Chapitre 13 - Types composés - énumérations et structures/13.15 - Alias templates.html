13.15 — Alias templates

Dans la leçon 10.7 -- Typedefs and type aliases, nous avons vu comment les alias de types permettent de définir un nom alternatif pour un type existant.

Créer un alias de type pour un modèle de classe dont tous les arguments de modèle sont explicitement spécifiés fonctionne exactement comme un alias de type ordinaire :

#include <iostream>

template <typename T>
struct Pair
{
    T first{};
    T second{};
};

template <typename T>
void print(const Pair<T>& p)
{
    std::cout << p.first << ' ' << p.second << '\n';
}

int main()
{
    using Point = Pair<int>; // création d'un alias de type ordinaire
    Point p { 1, 2 };        // le compilateur remplace ceci par Pair<int>

    print(p);

    return 0;
}

De tels alias peuvent être définis localement (par exemple à l'intérieur d'une fonction) ou globalement.

Alias templates

Dans d'autres cas, nous pouvons vouloir un alias de type pour une classe template dont tous les arguments de modèle ne sont pas fixés dans l'alias (ils seront alors fournis par l'utilisateur de l'alias). Pour cela, nous pouvons définir un alias template (alias de modèle), c'est-à-dire un modèle qui permet d'instancier des alias de types. De même que les alias de types ne définissent pas de types distincts, les alias templates ne définissent pas de types distincts.

Voici un exemple de fonctionnement :

#include <iostream>

template <typename T>
struct Pair
{
    T first{};
    T second{};
};

// Voici notre alias template
// Les alias templates doivent être définis dans la portée globale
template <typename T>
using Coord = Pair<T>; // Coord est un alias de Pair<T>

// Notre fonction template print doit savoir que le paramètre template T de Coord est un paramètre template de type
template <typename T>
void print(const Coord<T>& c)
{
    std::cout << c.first << ' ' << c.second << '\n';
}

int main()
{
    Coord<int> p1 { 1, 2 }; // Avant C++20 : nous devons spécifier explicitement tous les arguments de modèle de type
    Coord p2 { 1, 2 };      // En C++20, nous pouvons utiliser la déduction d'alias template pour déduire les arguments de modèle dans les cas où CTAD fonctionne

    std::cout << p1.first << ' ' << p1.second << '\n';
    print(p2);

    return 0;
}

Dans cet exemple, nous définissons un alias template nommé Coord comme alias de Pair<T>, où le paramètre template de type T sera défini par l'utilisateur de l'alias Coord. Coord est l'alias template, et Coord<T> est l'alias de type instancié pour Pair<T>. Une fois défini, nous pouvons utiliser Coord là où nous utiliserions Pair, et Coord<T> là où nous utiliserions Pair<T>.

Quelques points méritent d'être soulignés à propos de cet exemple.

Premièrement, contrairement aux alias de types ordinaires (qui peuvent être définis dans un bloc), les alias templates doivent être définis dans la portée globale (comme tous les templates).

Deuxièmement, avant C++20, nous devons spécifier explicitement les arguments de modèle lorsque nous instancions un objet à l'aide d'un alias template. À partir de C++20, nous pouvons utiliser la déduction d'alias template (alias template deduction), qui déduit le type des arguments de modèle à partir d'un initialiseur dans les cas où le type aliasé fonctionnerait avec CTAD.

Troisièmement, comme CTAD ne fonctionne pas sur les paramètres de fonction, lorsque nous utilisons un alias template comme paramètre de fonction, nous devons définir explicitement les arguments de modèle utilisés par l'alias template. Autrement dit, nous écrivons :

template <typename T>
void print(const Coord<T>& c)
{
    std::cout << c.first << ' ' << c.second << '\n';
}

et non :

void print(const Coord& c) // ne fonctionnera pas, arguments de modèle manquants
{
    std::cout << c.first << ' ' << c.second << '\n';
}

Ceci ne diffère en rien si nous avions utilisé Pair ou Pair<T> à la place de Coord ou Coord<T>.
