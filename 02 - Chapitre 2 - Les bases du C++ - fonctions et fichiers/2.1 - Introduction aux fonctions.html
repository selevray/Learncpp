2.1 — Introduction aux fonctions

Dans le chapitre précédent, nous avons défini une fonction comme un ensemble d'instructions exécutées séquentiellement. Bien que cela soit tout à fait vrai, cette définition n'explique pas vraiment pourquoi les fonctions sont utiles. Mettons à jour notre définition : une fonction est une séquence d'instructions réutilisable, conçue pour accomplir une tâche particulière.

Vous savez déjà que tout programme exécutable doit contenir une fonction nommée main() (c'est là que le programme commence son exécution lorsqu'il est lancé). Cependant, à mesure que les programmes deviennent de plus en plus longs, placer tout le code dans la fonction main() devient de plus en plus difficile à gérer. Les fonctions nous permettent de découper nos programmes en petits blocs modulaires, plus faciles à organiser, à tester et à utiliser. La plupart des programmes utilisent de nombreuses fonctions. La bibliothèque standard C++ fournit déjà de nombreuses fonctions prêtes à l'emploi, mais il est tout aussi courant d'écrire ses propres fonctions. Les fonctions que vous écrivez vous-même sont appelées fonctions définies par l'utilisateur.

Prenons un cas qui pourrait se produire dans la vie courante : vous lisez un livre lorsque vous vous souvenez que vous devez passer un appel téléphonique. Vous glissez un marque-page dans le livre, passez votre appel, puis, une fois terminé, vous revenez à la page marquée et reprenez votre lecture exactement là où vous vous étiez arrêté.

Les programmes C++ fonctionnent de la même manière (et empruntent une partie de la même terminologie). Un programme exécute séquentiellement des instructions à l'intérieur d'une fonction lorsqu'il rencontre un appel de fonction. Un appel de fonction demande au processeur d'interrompre la fonction courante et d'exécuter une autre fonction. Le processeur « place un marque-page » à l'endroit où il se trouve, exécute la fonction désignée par l'appel, puis revient au point marqué et reprend l'exécution.

Terminologie

La fonction qui effectue l'appel est l'appelante (caller), et la fonction appelée (exécutée) est la appelée (callee). Un appel de fonction est aussi parfois appelé invocation, l'appelante invoquant la fonction appelée.

Un exemple de fonction définie par l'utilisateur

Commençons par la syntaxe la plus élémentaire pour définir une fonction utilisateur. Pendant les prochaines leçons, toutes les fonctions utilisateur auront la forme suivante :

returnType functionName() // Ceci est l'en-tête de la fonction (informe le compilateur de l'existence de la fonction)
{
    // Ceci est le corps de la fonction (indique au compilateur ce que fait la fonction)
}

La première ligne est appelée informellement en-tête de fonction. Elle indique au compilateur l'existence d'une fonction, son nom, et quelques autres informations que nous verrons dans les prochaines leçons (comme le type de retour).

  • Dans cette leçon, nous utiliserons un returnType égal à int (pour la fonction main()) ou à void (dans les autres cas). Pour l'instant, ne vous en préoccupez pas : nous reparlerons des types de retour et des valeurs de retour dans la prochaine leçon (2.2 -- Valeurs de retour des fonctions (fonctions renvoyant une valeur)).
  • Tout comme les variables ont un nom, les fonctions utilisateur également. Le functionName est le nom (identifiant) de votre fonction utilisateur.
  • Les parenthèses qui suivent l'identifiant indiquent au compilateur que nous définissons une fonction.

Les accolades et les instructions qu'elles contiennent forment le corps de la fonction. C'est là que se trouvent les instructions qui déterminent ce que fait votre fonction.

Pour appeler une fonction, on utilise son nom suivi d'une paire de parenthèses (par exemple, functionName() appelle la fonction dont le nom est functionName). Par convention, les parenthèses sont placées immédiatement après le nom de la fonction, sans espace entre elles.

Pour l'instant, une fonction doit être définie avant d'être appelée. Nous verrons comment contourner cette contrainte dans la leçon 2.7 -- Déclarations et définitions anticipées.

Voici un programme d'exemple qui illustre la définition et l'appel d'une fonction utilisateur :

#include <iostream> // pour std::cout

// Définition de la fonction utilisateur doPrint()
// doPrint() est la fonction appelée dans cet exemple
void doPrint()
{
    std::cout << "In doPrint()\n";
}

// Définition de la fonction utilisateur main()
int main()
{
    std::cout << "Starting main()\n";
    doPrint();                        // Interrompt main() en appelant doPrint(). main() est l'appelante.
    std::cout << "Ending main()\n";   // Cette instruction est exécutée après la fin de doPrint()

    return 0;
}

Ce programme produit la sortie suivante :


Starting main()
In doPrint()
Ending main()

Ce programme commence son exécution au début de la fonction main(), et la première ligne exécutée affiche Starting main().

La deuxième ligne de main() est un appel de la fonction doPrint(). On le reconnaît aux parenthèses qui suivent le nom.

Attention

Lors d'un appel de fonction, n'oubliez pas les parenthèses () après le nom de la fonction. Si vous les omettez, votre programme risque de ne pas compiler (et s'il compile, la fonction ne sera pas appelée).

Comme un appel de fonction a été effectué, l'exécution des instructions de main() est suspendue, et l'exécution saute au début de la fonction appelée doPrint(). La première (et unique) ligne de doPrint() affiche In doPrint(). Lorsque doPrint() se termine, l'exécution revient à l'appelante (main()) et reprend juste après l'appel de fonction. Par conséquent, l'instruction suivante exécutée dans main() affiche Ending main().

Appeler une fonction plusieurs fois

L'un des intérêts des fonctions est qu'elles peuvent être appelées plusieurs fois. Voici un programme qui le démontre :

#include <iostream> // pour std::cout

void doPrint()
{
    std::cout << "In doPrint()\n";
}

// Définition de la fonction main()
int main()
{
    std::cout << "Starting main()\n";
    doPrint(); // doPrint() appelée une première fois
    doPrint(); // doPrint() appelée une deuxième fois
    std::cout << "Ending main()\n";

    return 0;
}

Ce programme produit la sortie suivante :


Starting main()
In doPrint()
In doPrint()
Ending main()

Comme main() appelle doPrint() deux fois, doPrint() s'exécute deux fois, et In doPrint() est affiché deux fois (une fois par appel).

Les fonctions peuvent appeler des fonctions qui en appellent d'autres

Vous avez déjà vu que la fonction main() peut appeler d'autres fonctions (comme doPrint() dans l'exemple précédent). Les fonctions appelées par main() peuvent elles aussi appeler d'autres fonctions, qui peuvent à leur tour en appeler d'autres, et ainsi de suite. Dans le programme suivant, main() appelle doA(), qui appelle doB() :

#include <iostream> // pour std::cout

void doB()
{
    std::cout << "In doB()\n";
}


void doA()
{
    std::cout << "Starting doA()\n";

    doB();

    std::cout << "Ending doA()\n";
}

// Définition de la fonction main()
int main()
{
    std::cout << "Starting main()\n";

    doA();

    std::cout << "Ending main()\n";

    return 0;
}

Ce programme produit la sortie suivante :


Starting main()
Starting doA()
In doB()
Ending doA()
Ending main()

Les fonctions imbriquées ne sont pas prises en charge

Une fonction dont la définition est placée à l'intérieur d'une autre fonction est appelée fonction imbriquée. Contrairement à certains autres langages de programmation, en C++, les fonctions ne peuvent pas être imbriquées. Le programme suivant n'est pas valide :

#include <iostream>

int main()
{
    void foo() // Illégal : cette fonction est imbriquée à l'intérieur de la fonction main()
    {
        std::cout << "foo!\n";
    }

    foo(); // appel de la fonction foo()

    return 0;
}

La bonne façon d'écrire le programme ci-dessus est la suivante :

#include <iostream>

void foo() // n'est plus à l'intérieur de main()
{
    std::cout << "foo!\n";
}

int main()
{
    foo();

    return 0;
}

Terminologie

« foo » est un mot sans signification, souvent utilisé comme nom provisoire pour une fonction ou une variable lorsque le nom importe peu pour illustrer un concept. De tels mots sont appelés variables métasyntaxiques (bien que, dans le langage courant, on parle souvent de « noms de substitution », car personne ne se souvient du terme « variable métasyntaxique »). Parmi les autres variables métasyntaxiques courantes en C++, on trouve « bar », « baz », ainsi que des mots de 3 lettres se terminant par « oo », comme « goo », « moo » et « boo ».

Pour les curieux de l'étymologie (l'évolution des mots), la RFC 3092 est une lecture intéressante.
