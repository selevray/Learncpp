Boîte des dernières nouvelles pour le thème Tiga 1.0.2 (mise à jour)

Il y a quelques jours, j'ai ajouté une boîte « dernières nouvelles » à la page d'accueil du site. Elle affiche les articles les plus récents de la catégorie News. C'est le moyen le plus simple de trouver les dernières nouvelles sur le site ou sur le tutoriel C++.

Aujourd'hui, en cherchant comment élargir cette boîte, je me suis aperçu que j'avais utilisé le mauvais style CSS dans le fichier newspage.php. Les marges de la boîte de nouvelles étaient donc égales à la largeur des barres latérales ! Ce n'était évidemment pas le résultat voulu.

Le fichier style.php d'origine ne contenait pas de style adapté à ce type d'ajout, j'ai donc dû en définir un moi-même. J'ai aussi dû mettre à jour le fichier newspage.php pour utiliser ce nouveau style. Puisque je modifiais style.php, j'ai pensé qu'il serait utile de rendre la marge paramétrable. J'ai donc modifié functions.php et ajouté un paramètre au Tigarator. Par conséquent, la procédure ci-dessous comporte désormais une étape supplémentaire, où vous définissez la marge de la boîte depuis le Tigarator.

Pour les fans de Tiga qui souhaitent ajouter leur propre boîte de dernières nouvelles à leur site utilisant le thème Tiga, voici la marche à suivre.

  1. Commencez par installer le plugin customizable post listings. C'est lui qui se charge de lister les articles.
  2. Ensuite, téléchargez le modèle de page newspage et les fichiers associés, puis extrayez-les dans un répertoire local. Ce modèle de page newspage ne fonctionne qu'avec le thème Tiga. REMARQUE : si vous avez déjà modifié functions.php ou style.php à la main, cette opération écrasera vos modifications !
  3. Troisièmement, éditez le fichier newspage.php avec un éditeur de texte (sous Windows, WordPad convient parfaitement). Vous verrez une ligne semblable à celle-ci : <ul><?php c2c_get_recent_posts(5, "<li>%post_date%: %post_URL%</li>", "4"); ?></ul>

Remplacez le « 4 » par l'identifiant de la catégorie dont vous voulez afficher les articles dans la boîte. Si vous voulez afficher des articles de plusieurs catégories, remplacez le « 4 » par une liste d'identifiants de catégories séparés par des espaces.

  1. Déposez le modèle dans votre répertoire wp-content/themes/tiga-06/.
  2. Ouvrez l'administration de WordPress. Pour chaque page où vous souhaitez une boîte d'articles récents : éditez la page. Sur la droite, vous devriez voir une boîte « Page Template ». Sélectionnez « Newspage ». Enregistrez votre page.
  3. Accédez au Tigarator (Presentation -> Tigarator). Vous verrez une nouvelle option nommée « Inner Widget Margin ». C'est la marge de la boîte de nouvelles. Définissez une valeur appropriée, par exemple 50.

Voilà, c'est tout.
