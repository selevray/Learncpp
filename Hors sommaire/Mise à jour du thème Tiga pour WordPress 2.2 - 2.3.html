Mise à jour du thème Tiga pour WordPress 2.2 / 2.3

J'ai mis à jour le thème Tiga (utilisé par ce site) pour le rendre compatible avec WordPress 2.2 et 2.3.

Cette mise à jour :

  • Corrige les problèmes de widgets introduits avec WordPress 2.2 (merci à Otto42 pour une solution plus propre que la mienne).
  • Corrige les problèmes de blogroll introduits avec WordPress 2.3.

J'ai également attribué au thème un nouveau numéro de version : 2.3.

Pour installer ce correctif, il suffit de décompresser les fichiers dans le répertoire du thème tiga-06. Remarque : les anciennes versions de CPanel n'écrasent pas les fichiers déjà existants lors de la décompression. Dans ce cas, décompressez-les dans un répertoire local puis transférez-les par FTP dans le répertoire du thème tiga-06. Vous pouvez aussi essayer ce script, qui fonctionne pour certains utilisateurs.

Vous pouvez télécharger la mise à jour ici.

Remarque : ce correctif semble également fonctionner avec WordPress v2.5.
