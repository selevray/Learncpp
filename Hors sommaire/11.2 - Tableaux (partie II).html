Initialisation des tableaux de taille fixe

Les éléments d'un tableau se comportent comme des variables ordinaires et, à ce titre, ils ne sont pas initialisés lors de leur création.

Une façon d'« initialiser » un tableau consiste à le faire élément par élément :

int prime[5]; // contient les 5 premiers nombres premiers
prime[0] = 2;
prime[1] = 3;
prime[2] = 5;
prime[3] = 7;
prime[4] = 11;

Cette méthode est toutefois fastidieuse, surtout lorsque le tableau devient grand. De plus, il ne s'agit pas d'une initialisation mais d'une affectation. Or les affectations ne fonctionnent pas si le tableau est const.

Heureusement, C++ fournit un moyen plus pratique d'initialiser un tableau entier grâce à une liste d'initialisation (initializer list). L'exemple suivant initialise le tableau avec les mêmes valeurs que précédemment :

int prime[5]{ 2, 3, 5, 7, 11 }; // utilise une liste d'initialisation pour initialiser le tableau de taille fixe

Si la liste contient plus de valeurs d'initialisation que le tableau ne peut en contenir, le compilateur génère une erreur.

En revanche, si la liste contient moins de valeurs d'initialisation que le tableau ne peut en contenir, les éléments restants sont initialisés à 0 (ou à la valeur que 0 représente pour un type fondamental non entier, par exemple 0.0 pour un double). C'est ce qu'on appelle l'initialisation à zéro (zero initialization).

L'exemple suivant illustre ce comportement :

#include <iostream>

int main()
{
    int array[5]{ 7, 4, 5 }; // n'initialise que les 3 premiers éléments

    std::cout << array[0] << '\n';
    std::cout << array[1] << '\n';
    std::cout << array[2] << '\n';
    std::cout << array[3] << '\n';
    std::cout << array[4] << '\n';

    return 0;
}

Ce programme affiche :


7
4
5
0
0

Par conséquent, pour initialiser tous les éléments d'un tableau à 0, vous pouvez écrire :

int array[5]{};          // Initialise tous les éléments à 0
double array[5] {};      // Initialise tous les éléments à 0.0
std::string array[5] {}; // Initialise tous les éléments à une chaîne vide

Si la liste d'initialisation est omise, les éléments ne sont pas initialisés, sauf s'il s'agit de types classe qui s'initialisent eux-mêmes.

int array[5];         // non initialisé (car int ne s'initialise pas lui-même)
double array[5];      // non initialisé (car double ne s'initialise pas lui-même)
std::string array[5]; // Initialise tous les éléments à une chaîne vide

Bonne pratique

Initialisez explicitement vos tableaux (même lorsque le type des éléments s'initialise lui-même).

Longueur omise

Si vous initialisez un tableau de taille fixe à l'aide d'une liste d'initialisation, le compilateur peut déterminer lui-même la longueur du tableau, et vous pouvez omettre de la déclarer explicitement.

Les deux lignes suivantes sont équivalentes :

int array[5]{ 0, 1, 2, 3, 4 }; // définit explicitement la longueur du tableau
int array[]{ 0, 1, 2, 3, 4 }; // laisse la liste d'initialisation déterminer la longueur du tableau

Cela permet non seulement de gagner de la frappe, mais aussi de ne pas avoir à mettre à jour la longueur du tableau si vous ajoutez ou supprimez des éléments par la suite.

Tableaux et énumérations

L'un des gros problèmes de documentation liés aux tableaux tient au fait que les indices entiers ne fournissent aucune information au programmeur sur la signification de l'indice. Prenons l'exemple d'une classe de 5 élèves :

constexpr int numberOfStudents{5};
int testScores[numberOfStudents]{};
testScores[2] = 76;

Qui représente testScores[2] ? Ce n'est pas clair.

On peut résoudre ce problème en définissant une énumération dont chaque énumérateur correspond à l'un des indices possibles du tableau :

enum StudentNames
{
    kenny, // 0
    kyle, // 1
    stan, // 2
    butters, // 3
    cartman, // 4
    max_students // 5
};

int main()
{
    int testScores[max_students]{}; // alloue 5 entiers
    testScores[stan] = 76;

    return 0;
}

De cette manière, on comprend beaucoup mieux ce que représente chaque élément du tableau. Notez qu'un énumérateur supplémentaire nommé max_students a été ajouté. Il sert lors de la déclaration du tableau pour garantir que celui-ci a la bonne longueur (la longueur du tableau doit être supérieure d'une unité au plus grand indice). Cela est utile à la fois pour la documentation et parce que le tableau sera automatiquement redimensionné si un autre énumérateur est ajouté :

enum StudentNames
{
    kenny, // 0
    kyle, // 1
    stan, // 2
    butters, // 3
    cartman, // 4
    wendy, // 5
    max_students // 6
};

int main()
{
    int testScores[max_students]{}; // alloue 6 entiers
    testScores[stan] = 76; // fonctionne toujours

    return 0;
}

Notez que cette « astuce » ne fonctionne que si vous ne modifiez pas manuellement les valeurs des énumérateurs !

Tableaux et énumérations de classe

Les énumérations de classe (enum class) ne possèdent pas de conversion implicite vers les entiers. Si vous essayez donc le code suivant :

enum class StudentNames
{
    kenny, // 0
    kyle, // 1
    stan, // 2
    butters, // 3
    cartman, // 4
    wendy, // 5
    max_students // 6
};

int main()
{
    int testScores[StudentNames::max_students]{}; // alloue 6 entiers
    testScores[StudentNames::stan] = 76;

    return 0;
}

Vous obtiendrez une erreur de compilation. On peut contourner le problème en utilisant un static_cast pour convertir l'énumérateur en entier :

int main()
{
    int testScores[static_cast<int>(StudentNames::max_students)]{}; // alloue 6 entiers
    testScores[static_cast<int>(StudentNames::stan)] = 76;

    return 0;
}

Toutefois, cette approche est quelque peu fastidieuse. Il vaut donc mieux utiliser une énumération standard placée dans un espace de noms (namespace) :

namespace StudentNames
{
    enum StudentNames
    {
        kenny, // 0
        kyle, // 1
        stan, // 2
        butters, // 3
        cartman, // 4
        wendy, // 5
        max_students // 6
    };
}

int main()
{
    int testScores[StudentNames::max_students]{}; // alloue 6 entiers
    testScores[StudentNames::stan] = 76;

    return 0;
}

Passer des tableaux à des fonctions

Bien que le passage d'un tableau à une fonction ressemble, à première vue, au passage d'une variable ordinaire, C++ traite les tableaux différemment en coulisse.

Lorsqu'une variable ordinaire est passée par valeur, C++ copie la valeur de l'argument dans le paramètre de la fonction. Comme le paramètre est une copie, modifier sa valeur ne modifie pas la valeur de l'argument d'origine.

En revanche, la copie de grands tableaux pouvant être très coûteuse, C++ ne copie pas un tableau lorsqu'il est passé à une fonction. C'est le tableau lui-même qui est transmis. Cela a pour effet secondaire de permettre aux fonctions de modifier directement la valeur des éléments du tableau !

L'exemple suivant illustre ce concept :

#include <iostream>

void passValue(int value) // value est une copie de l'argument
{
    value = 99; // donc la modifier ici ne change pas la valeur de l'argument
}

void passArray(int prime[5]) // prime est le tableau lui-même
{
    prime[0] = 11; // donc la modifier ici change l'argument d'origine !
    prime[1] = 7;
    prime[2] = 5;
    prime[3] = 3;
    prime[4] = 2;
}

int main()
{
    int value{ 1 };
    std::cout << "before passValue: " << value << '\n';
    passValue(value);
    std::cout << "after passValue: " << value << '\n';

    int prime[]{ 2, 3, 5, 7, 11 }; // type déduit comme int prime[5]
    std::cout << "before passArray: " << prime[0] << " " << prime[1] << " " << prime[2] << " " << prime[3] << " " << prime[4] << '\n';
    passArray(prime);
    std::cout << "after passArray: " << prime[0] << " " << prime[1] << " " << prime[2] << " " << prime[3] << " " << prime[4] << '\n';

    return 0;
}


before passValue: 1
after passValue: 1
before passArray: 2 3 5 7 11
after passArray: 11 7 5 3 2

Dans l'exemple ci-dessus, value n'est pas modifiée dans main() parce que le paramètre value de la fonction passValue() est une copie de la variable value de la fonction main(), et non la variable elle-même. En revanche, comme le paramètre array de la fonction passArray() est le tableau lui-même, passArray() peut modifier directement la valeur des éléments !

La raison de ce comportement est liée à la façon dont les tableaux sont implémentés en C++, sujet que nous reverrons dans la leçon 17.8 -- Dégradation des tableaux de style C (C-style array decay). Pour l'instant, considérez-le comme une particularité du langage.

Par ailleurs, si vous voulez garantir qu'une fonction ne modifie pas les éléments du tableau qu'elle reçoit, vous pouvez rendre le tableau const :

// même si prime est le tableau lui-même, il doit être traité comme une constante dans cette fonction
void passArray(const int prime[5])
{
    // donc chacune de ces lignes provoquera une erreur de compilation !
    prime[0] = 11;
    prime[1] = 7;
    prime[2] = 5;
    prime[3] = 3;
    prime[4] = 2;
}

Déterminer la longueur d'un tableau

La fonction std::size(), définie dans l'en-tête <iterator>, permet de déterminer la longueur d'un tableau.

Voici un exemple :

#include <iostream>
#include <iterator> // pour std::size

int main()
{
    int array[]{ 1, 1, 2, 3, 5, 8, 13, 21 };
    std::cout << "The array has: " << std::size(array) << " elements\n";

    return 0;
}

Ce programme affiche :


The array has: 8 elements

Notez qu'en raison de la façon dont C++ transmet les tableaux aux fonctions, cela ne fonctionne pas pour les tableaux qui ont été passés à des fonctions !

#include <iostream>
#include <iterator>

void printSize(int array[])
{
    std::cout << std::size(array) << '\n'; // Erreur
}

int main()
{
    int array[]{ 1, 1, 2, 3, 5, 8, 13, 21 };
    std::cout << std::size(array) << '\n'; // affiche la longueur du tableau
    printSize(array);

    return 0;
}

std::size() fonctionne avec d'autres types d'objets (comme std::array et std::vector), et il provoque une erreur de compilation si vous l'utilisez sur un tableau de taille fixe qui a été passé à une fonction ! Notez que std::size renvoie une valeur non signée. Si vous avez besoin d'une valeur signée, vous pouvez soit convertir le résultat, soit, depuis C++20, utiliser std::ssize() (signifie signed size, c'est-à-dire taille signée).

std::size() a été ajoutée en C++17. Si vous utilisez C++11 ou C++14, vous pouvez utiliser cette fonction à la place :

#include <iostream>

template <typename T, std::size_t N>
constexpr std::size_t length(const T(&)[N]) noexcept
{
    return N;
}

int main() {

    int array[]{ 1, 1, 2, 3, 5, 8, 13, 21 };
    std::cout << "The array has: " << length(array) << " elements\n";

    return 0;
}

Dans du code plus ancien, vous pourrez rencontrer une longueur calculée à l'aide de l'opérateur sizeof. Or sizeof n'est pas aussi simple d'emploi que std::size(), et il faut se méfier de plusieurs pièges.

L'opérateur sizeof peut être appliqué à un tableau et renvoie la taille totale de celui-ci (longueur du tableau multipliée par la taille d'un élément).

#include <iostream>

int main()
{
    int array[]{ 1, 1, 2, 3, 5, 8, 13, 21 };
    std::cout << sizeof(array) << '\n'; // affiche la taille du tableau, égale à la longueur multipliée par la taille d'un int
    std::cout << sizeof(int) << '\n';

    return 0;
}

Sur une machine où les entiers occupent 4 octets et les pointeurs 8 octets, ce programme affiche :


32
4

(Vous pouvez obtenir un résultat différent si la taille de vos types est différente.)

Une astuce pratique : on peut déterminer la longueur d'un tableau de taille fixe en divisant la taille de tout le tableau par la taille d'un élément :

#include <iostream>

int main()
{
    int array[]{ 1, 1, 2, 3, 5, 8, 13, 21 };
    std::cout << "The array has: " << sizeof(array) / sizeof(array[0]) << " elements\n";

    return 0;
}

Ce programme affiche


The array has: 8 elements

Comment cela fonctionne-t-il ? Tout d'abord, notez que la taille de l'ensemble du tableau est égale à sa longueur multipliée par la taille d'un élément. Plus brièvement : taille du tableau = longueur du tableau × taille d'un élément.

En utilisant l'algèbre, nous pouvons réarranger cette équation : longueur du tableau = taille du tableau / taille d'un élément. sizeof(array) correspond à la taille du tableau, et sizeof(array[0]) à la taille d'un élément, donc notre équation devient longueur du tableau = sizeof(array) / sizeof(array[0]). Il arrive qu'on utilise *array au lieu de array[0] (nous expliquons ce qu'est *array dans la leçon 17.9 -- Arithmétique des pointeurs et indexation).

Notez que cette méthode ne fonctionne que si le tableau est de longueur fixe et si vous l'utilisez dans la même fonction que celle où le tableau est déclaré (nous expliquerons plus tard dans ce chapitre pourquoi cette restriction existe).

Lorsque sizeof est appliqué à un tableau passé à une fonction, il ne provoque pas d'erreur comme le fait std::size(). Il renvoie à la place la taille d'un pointeur.

#include <iostream>

void printSize(int array[])
{
    std::cout << sizeof(array) / sizeof(array[0]) << '\n';
}

int main()
{
    int array[]{ 1, 1, 2, 3, 5, 8, 13, 21 };
    std::cout << sizeof(array) / sizeof(array[0]) << '\n';
    printSize(array);

    return 0;
}

En supposant à nouveau des pointeurs de 8 octets et des entiers de 4 octets, ce programme affiche


8
2

Note de l'auteur

Un compilateur correctement configuré doit afficher un avertissement si vous essayez d'utiliser sizeof() sur un tableau passé à une fonction.

Le calcul dans main() était correct, mais le sizeof() dans printSize() a renvoyé 8 (la taille d'un pointeur), et 8 divisé par 4 vaut 2.

Pour cette raison, faites attention lorsque vous utilisez sizeof() sur des tableaux !

Remarque : dans l'usage courant, les termes « taille du tableau » (array size) et « longueur du tableau » (array length) désignent le plus souvent tous deux la longueur du tableau (la taille du tableau n'est guère utile dans la plupart des cas, en dehors de l'astuce présentée ci-dessus).

Indexation d'un tableau hors limites

Rappelez-vous qu'un tableau de longueur N possède des éléments dont les indices vont de 0 à N-1. Que se passe-t-il donc si vous accédez à un tableau avec un indice situé en dehors de cette plage ?

Considérez le programme suivant :

int main()
{
    int prime[5]{}; // contient les 5 premiers nombres premiers
    prime[5] = 13;

    return 0;
}

Dans ce programme, notre tableau est de longueur 5, mais nous essayons d'écrire un nombre premier dans le 6e élément (d'indice 5).

C++ ne vérifie pas que vos indices sont valides pour la longueur de votre tableau. Dans l'exemple ci-dessus, la valeur 13 sera donc écrite en mémoire à l'emplacement où se trouverait le 6e élément, s'il existait. Il en résulte un comportement indéfini (undefined behavior) : par exemple, cela peut écraser la valeur d'une autre variable ou faire planter votre programme.

Bien que ce soit plus rare, C++ vous autorise aussi à utiliser un indice négatif, avec des conséquences tout aussi indésirables.

Règle

Lorsque vous utilisez des tableaux, assurez-vous que vos indices sont valides pour la plage de votre tableau !

Quiz

  1. Déclarez un tableau destiné à contenir la température maximale (au dixième de degré près) pour chaque jour d'une année (supposez 365 jours par an). Initialisez le tableau avec la valeur 0.0 pour chaque jour.
  2. Définissez une énumération contenant les noms des animaux suivants : chicken (poulet), dog (chien), cat (chat), elephant (éléphant), duck (canard) et snake (serpent). Placez l'énumération dans un espace de noms. Définissez un tableau comportant un élément pour chacun de ces animaux, et utilisez une liste d'initialisation pour initialiser chaque élément avec le nombre de pattes de cet animal.

Écrivez ensuite une fonction main qui affiche le nombre de pattes d'un éléphant, en utilisant l'énumérateur.

Réponses du quiz

Solution 
double temperature[365] { };
Solution 
#include <iostream>
#include <iterator> // pour std::size

namespace Animals
{
    enum Animals // Le nom de cette énumération pourrait être omis puisqu'il n'est utilisé nulle part
    {
        chicken,
        dog,
        cat,
        elephant,
        duck,
        snake,
        max_animals
    };
}

int main()
{
    int legs[]{ 2, 4, 4, 4, 2, 0 };
    static_assert(std::size(legs) == Animals::max_animals);

    std::cout << "An elephant has " << legs[Animals::elephant] << " legs.\n";

    return 0;
}
