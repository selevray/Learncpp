Boîte « actualités récentes » sur la page d'accueil pour le thème Tiga 1.0.2 (obsolète)

Note : cet article de blog a été remplacé par l'article disponible à l'adresse http://www.learncpp.com/?p=30.

J'ai ajouté une boîte « actualités récentes » à la page d'accueil du site, qui affiche les derniers articles publiés dans la catégorie News. C'est le moyen le plus simple de trouver les dernières nouvelles concernant le site ou le tutoriel C++.

Pour les fans de Tiga qui souhaiteraient ajouter une boîte d'articles récents à leur site utilisant ce thème, voici la marche à suivre.

  1. Commencez par installer le plugin customizable post listings. C'est ce plugin qui se charge de lister les articles.
  2. Ensuite, téléchargez le modèle de page newspage et extrayez-le dans un répertoire local. Ce modèle de page newspage ne fonctionne qu'avec le thème Tiga.
  3. Puis modifiez le fichier newspage.php avec un éditeur de texte (pour les utilisateurs de Windows, WordPad convient parfaitement). Vous verrez une ligne qui ressemble à ceci : <ul><?php c2c_get_recent_posts(5, "<li>%post_date%: %post_URL%</li>", "4"); ?></ul>

Remplacez « 4 » par l'identifiant de la catégorie dont vous souhaitez afficher les articles dans la boîte. Si vous voulez afficher des articles provenant de plusieurs catégories, remplacez « 4 » par une liste d'identifiants de catégories séparés par des espaces.

  1. Envoyez le modèle dans votre répertoire wp-content/themes/tiga-06/.
  2. Rendez-vous dans l'administration de WordPress. Pour chaque page sur laquelle vous souhaitez une boîte d'articles récents : modifiez la page. Sur la droite, vous devriez voir une boîte « Page Template ». Sélectionnez « Newspage ». Enregistrez votre page.

C'est tout.
