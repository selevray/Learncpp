Correctif de widgets pour Tiga 1.0.2 sous WordPress 2.2

Ce site utilise l'excellent thème Tiga 1.0.2, qui fonctionne très bien sous WordPress 2.1.3. Cependant, lorsque j'ai mis le site à niveau vers WordPress 2.2 (qui intègre désormais la gestion des widgets), il est rapidement apparu que les widgets ne fonctionnaient pas correctement avec le thème Tiga 1.0.2. Même si vous pouvez configurer vos widgets, Tiga 1.0.2 ne s'aperçoit pas que vous avez modifié la configuration par défaut, et utilise toujours l'ensemble de widgets par défaut.

Après avoir fouillé dans un tas de code css et php, j'ai réussi à corriger le problème. Comme Tiga est l'un des thèmes les plus populaires, je mets cette solution à la disposition de tous.

Téléchargez le correctif de widgets pour Tiga 1.0.2 sous WordPress 2.2 *(voir la note en bas de l'article).

L'installation est simple. Il suffit de copier le fichier sidebar.php par-dessus celui qui existe déjà dans le dossier de votre thème tiga-06.

Bon blogging !
