Un script PHP pour décompresser des fichiers en écrasant les fichiers existants

De nombreux hébergeurs web utilisent CPanel, qui offre un moyen assez intuitif de gérer son compte. CPanel inclut un gestionnaire de fichiers fonctionnel mais un peu lourd. Bien que CPanel propose un mécanisme d'extraction d'archives (.zip et .gz), celui-ci présente un inconvénient majeur : lors de l'extraction de fichiers .zip, les fichiers existants ne sont pas écrasés. Il devient donc très difficile de mettre à jour un logiciel distribué sous forme d'archives .zip.

Pour contourner cette limitation, j'ai écrit un script PHP qui permet d'extraire des fichiers .zip en écrasant les fichiers existants. Il présente à l'utilisateur la liste de tous les fichiers .zip du répertoire et lui permet d'en soumettre un à l'extraction. L'ensemble du processus est assez intuitif. Voici à quoi ressemble l'interface :

Veuillez choisir un fichier à décompresser :
test.zip
test2.zip

Attention : les fichiers existants seront écrasés.

Le fichier sélectionné est ensuite décompressé.

Pour utiliser le script, suivez simplement cette procédure :

  1. Téléversez ce script par FTP (ou collez le script dans un nouveau fichier) dans le répertoire qui contient le fichier .zip à décompresser.
  2. Lancez votre navigateur web et pointez-le vers le script.
  3. Sélectionnez le fichier à décompresser, puis cliquez sur le bouton « Unzip ».

Et voilà !

Pensez à supprimer le script après l'avoir utilisé, car le laisser sur le serveur pourrait causer un problème de sécurité.

unzip.php :

&lt;?php
    // Le script unzip
    // Créé par Alex sur http://www.learncpp.com
    //
    // Ce script liste tous les fichiers .zip d'un répertoire
    // et vous permet d'en sélectionner un à décompresser. Contrairement au
    // gestionnaire de fichiers de CPanel, il _va_ écraser les fichiers existants.
    //
    // Pour utiliser ce script, téléversez-le par FTP ou collez-le dans un fichier situé dans le répertoire
    // contenant le .zip à décompresser. Puis pointez votre navigateur web vers ce
    // script et choisissez le fichier à décompresser.

    // Vérifier s'il y a un paramètre file dans la chaîne de l'URL
    $file = $_GET['file'];

    if (isset($file))
    {
       echo &quot;Décompression de &quot; . $file . &quot;&lt;br&gt;&quot;;
       system('unzip -o ' . $file);
       exit;
    }

    // créer un gestionnaire pour lire le contenu du répertoire
    $handler = opendir(&quot;.&quot;);

    echo &quot;Veuillez choisir un fichier à décompresser : &quot; . &quot;&lt;br&gt;&quot;;

    // Un champ action vide envoie le formulaire vers lui-même
    echo '&lt;FORM action=&quot;&quot; method=&quot;get&quot;&gt;';

    $found = FALSE; // Sert à savoir s'il existe des fichiers valides

    // continuer jusqu'à ce que tous les fichiers du répertoire aient été lus
    while ($file = readdir($handler))
    {
        if (preg_match (&quot;/.zip$/i&quot;, $file))
        {
            echo '&lt;input type=&quot;radio&quot; name=&quot;file&quot; value=' . $file . '&gt; ' . $file . '&lt;br&gt;';
            $found = true;
        }
    }

    closedir($handler);

    if ($found == FALSE)
        echo &quot;Aucun fichier se terminant par .zip trouvé&lt;br&gt;&quot;;
    else
        echo '&lt;br&gt;Attention : les fichiers existants seront écrasés.&lt;br&gt;&lt;br&gt;&lt;INPUT type=&quot;submit&quot; value=&quot;Unzip!&quot;&gt;';

    echo &quot;&lt;/FORM&gt;&quot;;
?&gt;
