23.5 — Dépendances

Jusqu'à présent, nous avons exploré 3 types de relations : la composition, l'agrégation et l'association. Nous avons gardé la plus simple pour la fin : la dépendance.

Dans la conversation courante, on utilise le terme dépendance pour indiquer qu'un objet a besoin d'un autre objet pour accomplir une tâche donnée. Par exemple, si vous vous cassez le pied, vous dépendez de béquilles pour vous déplacer (mais pas pour autre chose). Les fleurs dépendent des abeilles pour être pollinisées, afin de produire des fruits ou de se reproduire (mais pas pour autre chose).

Une dépendance se produit lorsqu'un objet invoque la fonctionnalité d'un autre objet afin d'accomplir une tâche précise. C'est une relation plus faible qu'une association, mais toute modification de l'objet dont dépend l'appelant peut tout de même casser le fonctionnement de ce dernier (l'objet dépendant). Une dépendance est toujours une relation unidirectionnelle.

Un bon exemple de dépendance que vous avez déjà rencontrée de nombreuses fois est std::ostream. Nos classes qui utilisent std::ostream s'en servent pour accomplir la tâche d'afficher quelque chose dans la console, et uniquement pour cela.

Par exemple :

#include <iostream>

class Point
{
private:
    double m_x{};
    double m_y{};
    double m_z{};

public:
    Point(double x=0.0, double y=0.0, double z=0.0): m_x{x}, m_y{y}, m_z{z}
    {
    }

    friend std::ostream& operator<< (std::ostream& out, const Point& point); // Point dépend de std::ostream ici
};

std::ostream& operator<< (std::ostream& out, const Point& point)
{
    // Comme operator<< est une fonction amie de la classe Point, nous pouvons accéder directement à ses membres.
    out << "Point(" << point.m_x << ", " << point.m_y << ", " << point.m_z << ')';

    return out;
}

int main()
{
    Point point1 { 2.0, 3.0, 4.0 };

    std::cout << point1; // le programme dépend de std::cout ici

    return 0;
}

Dans le code ci-dessus, Point n'est pas directement lié à std::ostream, mais il dépend de std::ostream puisque operator<< utilise std::ostream pour afficher le Point dans la console.

Dépendance et association en C++

Il y a généralement une certaine confusion sur ce qui distingue une dépendance d'une association.

En C++, une association est une relation dans laquelle une classe conserve un « lien » direct ou indirect vers la classe associée, sous forme de membre. Par exemple, une classe Doctor possède, comme membre, un tableau de pointeurs vers ses Patients. Vous pouvez toujours demander au Doctor qui sont ses patients. La classe Driver conserve, dans un membre entier, l'identifiant de la Car que le conducteur possède. Le Driver sait toujours quelle Car lui est associée.

Les dépendances ne sont généralement pas des membres. On instancie plutôt l'objet dont on dépend au besoin (comme ouvrir un fichier pour y écrire des données), ou on le passe à une fonction en tant que paramètre (comme std::ostream dans la surcharge de operator<< ci-dessus).
