23.7 — std::initializer_list

Considérons un tableau d'entiers de taille fixe en C++ :

int array[5];

Si nous voulons initialiser ce tableau avec des valeurs, nous pouvons le faire directement via la syntaxe de liste d'initialisation :

#include <iostream>

int main()
{
    int array[] { 5, 4, 3, 2, 1 }; // liste d'initialisation
    for (auto i : array)
        std::cout << i << ' ';

    return 0;
}

Ce programme affiche :


5 4 3 2 1

Cela fonctionne aussi pour les tableaux alloués dynamiquement :

#include <iostream>

int main()
{
    auto* array{ new int[5]{ 5, 4, 3, 2, 1 } }; // liste d'initialisation
    for (int count{ 0 }; count < 5; ++count)
        std::cout << array[count] << ' ';
    delete[] array;

    return 0;
}

Dans la leçon précédente, nous avons introduit le concept de classes conteneurs, et nous avons présenté un exemple de classe IntArray qui contient un tableau d'entiers :

#include <cassert> // pour assert()
#include <iostream>

class IntArray
{
private:
    int m_length{};
    int* m_data{};

public:
    IntArray() = default;

    IntArray(int length)
        : m_length{ length }
    , m_data{ new int[static_cast<std::size_t>(length)] {} }
    {
    }

    ~IntArray()
    {
        delete[] m_data;
        // inutile de mettre m_data à nul ou m_length à 0 ici, puisque l'objet sera détruit immédiatement après cette fonction de toute façon
    }

    int& operator[](int index)
    {
        assert(index >= 0 && index < m_length);
        return m_data[index];
    }

    int getLength() const { return m_length; }
};

int main()
{
    // Que se passe-t-il si nous essayons d'utiliser une liste d'initialisation avec cette classe conteneur ?
    IntArray array { 5, 4, 3, 2, 1 }; // cette ligne ne compile pas
    for (int count{ 0 }; count < 5; ++count)
        std::cout << array[count] << ' ';

    return 0;
}

Ce code ne compile pas, car la classe IntArray n'a pas de constructeur capable de traiter une liste d'initialisation. Par conséquent, nous sommes contraints d'initialiser les éléments du tableau un par un :

int main()
{
    IntArray array(5);
    array[0] = 5;
    array[1] = 4;
    array[2] = 3;
    array[3] = 2;
    array[4] = 1;

    for (int count{ 0 }; count < 5; ++count)
        std::cout << array[count] << ' ';

    return 0;
}

Ce n'est pas très pratique.

Initialisation d'une classe à l'aide de std::initializer_list

Lorsqu'un compilateur rencontre une liste d'initialisation, il la convertit automatiquement en un objet de type std::initializer_list. Par conséquent, si nous créons un constructeur qui prend un paramètre de type std::initializer_list, nous pouvons créer des objets en utilisant la liste d'initialisation comme entrée.

std::initializer_list se trouve dans l'en-tête <initializer_list>.

Il y a quelques points à connaître à propos de std::initializer_list. Comme pour std::array ou std::vector, vous devez indiquer le type de données contenu dans la liste à l'aide de chevrons, sauf si vous initialisez immédiatement le std::initializer_list. Vous ne verrez donc presque jamais un simple std::initializer_list. Vous verrez plutôt quelque chose comme std::initializer_list<int> ou std::initializer_list<std::string>.

Deuxièmement, std::initializer_list possède une fonction size() (au nom trompeur) qui renvoie le nombre d'éléments de la liste. C'est utile lorsque nous avons besoin de connaître la longueur de la liste passée.

Troisièmement, std::initializer_list est souvent passé par valeur. Comme std::string_view, std::initializer_list est une vue. Copier un std::initializer_list ne copie pas les éléments de la liste.

Mettons à jour notre classe IntArray avec un constructeur qui prend un std::initializer_list.

#include <algorithm> // pour std::copy
#include <cassert> // pour assert()
#include <initializer_list> // pour std::initializer_list
#include <iostream>

class IntArray
{
private:
    int m_length {};
    int* m_data{};

public:
    IntArray() = default;

    IntArray(int length)
        : m_length{ length }
        , m_data{ new int[static_cast<std::size_t>(length)] {} }
    {

    }

    IntArray(std::initializer_list<int> list) // permet d'initialiser IntArray via une liste d'initialisation
        : IntArray(static_cast<int>(list.size())) // utilise un constructeur délégué pour mettre en place le tableau initial
    {
        // Initialisons maintenant notre tableau à partir de la liste
        std::copy(list.begin(), list.end(), m_data);
    }

    ~IntArray()
    {
        delete[] m_data;
        // inutile de mettre m_data à nul ou m_length à 0 ici, puisque l'objet sera détruit immédiatement après cette fonction de toute façon
    }

    IntArray(const IntArray&) = delete; // pour éviter les copies superficielles
    IntArray& operator=(const IntArray& list) = delete; // pour éviter les copies superficielles

    int& operator[](int index)
    {
        assert(index >= 0 && index < m_length);
        return m_data[index];
    }

    int getLength() const { return m_length; }
};

int main()
{
    IntArray array{ 5, 4, 3, 2, 1 }; // liste d'initialisation
    for (int count{ 0 }; count < array.getLength(); ++count)
        std::cout << array[count] << ' ';

    return 0;
}

Ce programme produit le résultat attendu :


5 4 3 2 1

Ça fonctionne ! Explorons maintenant tout cela plus en détail.

Voici notre constructeur de IntArray qui prend un std::initializer_list<int>.

    IntArray(std::initializer_list<int> list) // permet d'initialiser IntArray via une liste d'initialisation
        : IntArray(static_cast<int>(list.size())) // utilise un constructeur délégué pour mettre en place le tableau initial
    {
        // Initialisons maintenant notre tableau à partir de la liste
        std::copy(list.begin(), list.end(), m_data);
    }

Ligne 1 : comme indiqué plus haut, nous devons utiliser des chevrons pour préciser le type des éléments attendus dans la liste. Ici, comme il s'agit d'un IntArray, nous attendons une liste remplie d'int. Notez que nous ne passons pas la liste par référence constante. Comme std::string_view, std::initializer_list est très léger, et les copies sont généralement moins coûteuses qu'une indirection.

Ligne 2 : nous déléguons l'allocation de mémoire pour l'IntArray à l'autre constructeur, via un constructeur délégué (afin de réduire le code redondant). Cet autre constructeur a besoin de connaître la longueur du tableau, nous lui passons donc list.size(), qui contient le nombre d'éléments de la liste. Notez que list.size() renvoie un size_t (non signé), nous devons donc effectuer une conversion vers un int signé ici.

Le corps du constructeur sert à copier les éléments de la liste dans notre classe IntArray. Le moyen le plus simple de le faire est d'utiliser std::copy(), qui se trouve dans l'en-tête <algorithm>.

Accéder aux éléments d'un std::initializer_list

Dans certains cas, vous pouvez souhaiter accéder à chaque élément du std::initializer_list avant de copier cet élément dans le tableau interne (par exemple pour vérifier la validité des valeurs, ou pour les modifier).

Pour une raison inexplicable, std::initializer_list ne fournit pas d'accès aux éléments de la liste via l'opérateur d'indexation (operator[]). Cette omission a été signalée à plusieurs reprises au comité de normalisation, sans jamais être corrigée.

Il existe cependant plusieurs solutions de contournement simples :

  1. Vous pouvez utiliser une boucle for basée sur une plage pour parcourir les éléments de la liste.
  2. Une autre méthode consiste à utiliser la fonction membre begin() pour obtenir un itérateur sur le std::initializer_list. Comme cet itérateur est un itérateur à accès aléatoire, on peut l'indexer :
    IntArray(std::initializer_list<int> list) // permet d'initialiser IntArray via une liste d'initialisation
        : IntArray(static_cast<int>(list.size())) // utilise un constructeur délégué pour mettre en place le tableau initial
    {
        // Initialisons maintenant notre tableau à partir de la liste
        for (std::size_t count{}; count < list.size(); ++count)
        {
            m_data[count] = list.begin()[count];
        }
    }

L'initialisation par liste privilégie les constructeurs de liste par rapport aux autres constructeurs

Une liste d'initialisation non vide privilégiera toujours un constructeur initializer_list correspondant par rapport aux autres constructeurs potentiellement compatibles. Considérons :

IntArray a1(5);   // utilise IntArray(int), alloue un tableau de taille 5
IntArray a2{ 5 }; // utilise IntArray(std::initializer_list<int>), alloue un tableau de taille 1

Le cas a1 utilise l'initialisation directe (qui ne considère pas les constructeurs de liste), donc cette définition appellera IntArray(int), allouant un tableau de taille 5.

Le cas a2 utilise l'initialisation par liste (qui privilégie les constructeurs de liste). IntArray(int) et IntArray(std::initializer_list<int>) sont tous deux des correspondances possibles ici, mais comme les constructeurs de liste sont privilégiés, c'est IntArray(std::initializer_list<int>) qui sera appelé, allouant un tableau de taille 1 (dont l'élément a la valeur 5).

C'est pourquoi notre constructeur délégué ci-dessus utilise l'initialisation directe lorsqu'il délègue :

    IntArray(std::initializer_list<int> list)
        : IntArray(static_cast<int>(list.size())) // utilise l'initialisation directe

Cela garantit que la délégation se fait vers la version IntArray(int). Si nous avions délégué en utilisant l'initialisation par liste, le constructeur aurait tenté de se déléguer à lui-même, ce qui provoquerait une erreur de compilation.

Il en va de même pour std::vector et les autres classes conteneurs qui possèdent à la fois un constructeur de liste et un constructeur avec un type de paramètre similaire :

std::vector<int> array(5); // Appelle std::vector::vector(std::vector::size_type) : 5 éléments initialisés à valeur par défaut : 0 0 0 0 0
std::vector<int> array{ 5 }; // Appelle std::vector::vector(std::initializer_list<int>) : 1 élément : 5

Point clé

L'initialisation par liste privilégie les constructeurs de liste correspondants par rapport aux constructeurs non-liste correspondants.

Bonne pratique

Lorsque vous initialisez un conteneur possédant un constructeur de liste :

  • Utilisez l'initialisation par accolades lorsque vous souhaitez appeler le constructeur de liste (par exemple parce que vos initialiseurs sont des valeurs d'éléments)
  • Utilisez l'initialisation directe lorsque vous souhaitez appeler un constructeur non-liste (par exemple parce que vos initialiseurs ne sont pas des valeurs d'éléments).

Ajouter un constructeur de liste à une classe existante est dangereux

Comme l'initialisation par liste privilégie les constructeurs de liste, ajouter un constructeur de liste à une classe existante qui n'en possédait pas auparavant peut silencieusement modifier le comportement de programmes existants.

Considérons le programme suivant :

#include <initializer_list> // pour std::initializer_list
#include <iostream>

class Foo
{
public:
    Foo(int, int)
    {
        std::cout << "Foo(int, int)" << '\n';
    }
};

int main()
{
    Foo f1{ 1, 2 }; // appelle Foo(int, int)

    return 0;
}

Ce programme affiche :


Foo(int, int)

Ajoutons maintenant un constructeur de liste à cette classe :

#include <initializer_list> // pour std::initializer_list
#include <iostream>

class Foo
{
public:
    Foo(int, int)
    {
        std::cout << "Foo(int, int)" << '\n';
    }

    // Nous avons ajouté un constructeur de liste
    Foo(std::initializer_list<int>)
    {
        std::cout << "Foo(std::initializer_list<int>)" << '\n';
    }

};

int main()
{
    // notez que l'instruction suivante n'a pas changé
    Foo f1{ 1, 2 }; // appelle maintenant Foo(std::initializer_list<int>)

    return 0;
}

Bien que nous n'ayons effectué aucune autre modification du programme, celui-ci affiche maintenant :


Foo(std::initializer_list<int>)

Attention

Ajouter un constructeur de liste à une classe existante qui n'en avait pas peut casser des programmes existants.

Affectation d'une classe à l'aide de std::initializer_list

Vous pouvez également utiliser std::initializer_list pour affecter de nouvelles valeurs à une classe, en surchargeant l'opérateur d'affectation pour qu'il prenne un paramètre de type std::initializer_list. Cela fonctionne de manière analogue à ce qui précède. Nous montrerons un exemple de la façon de le faire dans la solution de l'exercice ci-dessous.

Notez que si vous implémentez un constructeur qui prend un std::initializer_list, vous devez vous assurer de faire au moins l'une des choses suivantes :

  1. Fournir un opérateur d'affectation par liste surchargé
  2. Fournir un opérateur d'affectation par copie correct, réalisant une copie profonde
  3. Supprimer l'opérateur d'affectation par copie

Voici pourquoi : considérons la classe suivante (qui n'a aucune de ces caractéristiques), ainsi qu'une instruction d'affectation par liste :

#include <algorithm> // pour std::copy()
#include <cassert>   // pour assert()
#include <initializer_list> // pour std::initializer_list
#include <iostream>

class IntArray
{
private:
    int m_length{};
    int* m_data{};

public:
    IntArray() = default;

    IntArray(int length)
        : m_length{ length }
        , m_data{ new int[static_cast<std::size_t>(length)] {} }
    {

    }

    IntArray(std::initializer_list<int> list) // permet d'initialiser IntArray via une liste d'initialisation
        : IntArray(static_cast<int>(list.size())) // utilise un constructeur délégué pour mettre en place le tableau initial
    {
        // Initialisons maintenant notre tableau à partir de la liste
        std::copy(list.begin(), list.end(), m_data);
    }

    ~IntArray()
    {
        delete[] m_data;
    }

//  IntArray(const IntArray&) = delete; // pour éviter les copies superficielles
//  IntArray& operator=(const IntArray& list) = delete; // pour éviter les copies superficielles

    int& operator[](int index)
    {
        assert(index >= 0 && index < m_length);
        return m_data[index];
    }

    int getLength() const { return m_length; }
};

int main()
{
    IntArray array{};
    array = { 1, 3, 5, 7, 9, 11 }; // Voici notre instruction d'affectation par liste

    for (int count{ 0 }; count < array.getLength(); ++count)
        std::cout << array[count] << ' '; // comportement indéfini

    return 0;
}

Tout d'abord, le compilateur constate qu'il n'existe pas de fonction d'affectation prenant un std::initializer_list. Il cherche ensuite d'autres fonctions d'affectation utilisables, et découvre l'opérateur d'affectation par copie fourni implicitement. Cependant, cette fonction ne peut être utilisée que s'il peut convertir la liste d'initialisation en IntArray. Comme { 1, 3, 5, 7, 9, 11 } est un std::initializer_list, le compilateur utilise le constructeur de liste pour convertir la liste d'initialisation en un IntArray temporaire. Il appelle ensuite l'opérateur d'affectation implicite, qui effectue une copie superficielle de l'IntArray temporaire dans notre objet array.

À ce stade, le m_data de l'IntArray temporaire et array->m_data pointent vers la même adresse (à cause de la copie superficielle). Vous voyez déjà où cela mène.

À la fin de l'instruction d'affectation, l'IntArray temporaire est détruit. Cela appelle le destructeur, qui libère le m_data de l'IntArray temporaire. Cela laisse array->m_data comme pointeur pendant (dangling pointer). Lorsque vous tentez d'utiliser array->m_data à quelque fin que ce soit (y compris lorsque array sort de sa portée et que le destructeur libère m_data), vous obtenez un comportement indéfini.

Bonne pratique

Si vous fournissez une construction par liste, il est judicieux de fournir également une affectation par liste.

Résumé

Implémenter un constructeur qui prend un paramètre std::initializer_list nous permet d'utiliser l'initialisation par liste avec nos classes personnalisées. Nous pouvons également utiliser std::initializer_list pour implémenter d'autres fonctions qui doivent accepter une liste d'initialisation, comme un opérateur d'affectation.

Quiz

Question n° 1

En utilisant la classe IntArray ci-dessus, implémentez un opérateur d'affectation surchargé qui prend une liste d'initialisation.

Le code suivant doit s'exécuter :

int main()
{
    IntArray array { 5, 4, 3, 2, 1 }; // liste d'initialisation
    for (int count{ 0 }; count < array.getLength(); ++count)
        std::cout << array[count] << ' ';

    std::cout << '\n';

    array = { 1, 3, 5, 7, 9, 11 };

    for (int count{ 0 }; count < array.getLength(); ++count)
        std::cout << array[count] << ' ';

    std::cout << '\n';

    return 0;
}

Il doit afficher :


5 4 3 2 1
1 3 5 7 9 11
Solution 
#include <algorithm> // pour std::copy()
#include <cassert>   // pour assert()
#include <initializer_list> // pour std::initializer_list
#include <iostream>

class IntArray
{
private:
    int m_length {};
    int* m_data {};

public:
    IntArray() = default;

    IntArray(int length)
        : m_length{ length }
        , m_data{ new int[static_cast<std::size_t>(length)] {} }
    {

    }

    IntArray(std::initializer_list<int> list) : // permet d'initialiser IntArray via une liste d'initialisation
        IntArray(static_cast<int>(list.size())) // utilise un constructeur délégué pour mettre en place le tableau initial
    {
        // Initialisons maintenant notre tableau à partir de la liste
        std::copy(list.begin(), list.end(), m_data);
    }

    ~IntArray()
    {
        delete[] m_data;
        // inutile de mettre m_data à nul ou m_length à 0 ici, puisque l'objet sera détruit immédiatement après cette fonction de toute façon
    }

    IntArray(const IntArray&) = delete; // pour éviter les copies superficielles
    IntArray& operator=(const IntArray& list) = delete; // pour éviter les copies superficielles

    IntArray& operator=(std::initializer_list<int> list)
    {
        // Si la nouvelle liste a une taille différente, on réalloue le tableau
        int length { static_cast<int>(list.size()) };
        if (length != m_length)
        {
            delete[] m_data;
            m_length = length;
            m_data = new int[list.size()]{};
        }

        // Initialisons maintenant notre tableau à partir de la liste
        std::copy(list.begin(), list.end(), m_data);

        return *this;
    }

    int& operator[](int index)
    {
        assert(index >= 0 && index < m_length);
        return m_data[index];
    }

    int getLength() const { return m_length; }
};

int main()
{
    IntArray array { 5, 4, 3, 2, 1 }; // liste d'initialisation
    for (int count{ 0 }; count < array.getLength(); ++count)
        std::cout << array[count] << ' ';

    std::cout << '\n';

    array = { 1, 3, 5, 7, 9, 11 };

    for (int count{ 0 }; count < array.getLength(); ++count)
        std::cout << array[count] << ' ';

    std::cout << '\n';

    return 0;
}
