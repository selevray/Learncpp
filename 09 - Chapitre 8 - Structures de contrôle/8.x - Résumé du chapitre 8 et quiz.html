8.x — Résumé du chapitre 8 et quiz

Résumé du chapitre

La séquence précise d'instructions que le processeur exécute dans un programme s'appelle le chemin d'exécution (execution path) du programme. Un programme linéaire (straight-line program) suit le même chemin à chaque exécution.

Les instructions de contrôle de flux (control flow statements, aussi appelées flow control statements) permettent au programmeur de modifier le chemin d'exécution normal. Lorsqu'une instruction de contrôle de flux amène le programme à exécuter une séquence d'instructions non séquentielle, on parle de branchement (branch).

Une instruction conditionnelle (conditional statement) est une instruction qui précise si une ou plusieurs instructions associées doivent être exécutées ou non.

Les instructions if permettent d'exécuter une instruction associée selon que une condition est true. Les instructions else s'exécutent si la condition associée est false. Vous pouvez enchaîner plusieurs instructions if et else.

Un else pendant (dangling else) se produit lorsqu'il est ambigu à quelle instruction if une instruction else est rattachée. Les else pendants sont associés au dernier if non apparié dans le même bloc. On évite donc facilement les else pendants en plaçant toujours le corps d'une instruction if dans un bloc.

Une instruction nulle (null statement) est une instruction composée uniquement d'un point-virgule. Elle ne fait rien ; elle sert lorsque le langage exige la présence d'une instruction mais que le programmeur n'a pas besoin qu'elle fasse quoi que ce soit.

Les instructions switch offrent une méthode plus claire et plus rapide pour choisir parmi plusieurs valeurs possibles. Les instructions switch ne fonctionnent qu'avec des types entiers. Les étiquettes case (case labels) identifient les valeurs auxquelles la condition évaluée doit correspondre. Les instructions placées sous l'étiquette default sont exécutées si aucune étiquette case ne correspond.

Lorsque l'exécution passe des instructions situées sous une étiquette à celles situées sous une étiquette suivante, on parle de fallthrough (poursuite d'exécution). Une instruction break (ou return) permet d'empêcher ce comportement. L'attribut [[fallthrough]] permet de documenter un fallthrough intentionnel.

Les instructions goto permettent au programme de sauter à un autre endroit du code, vers l'avant ou vers l'arrière. Elles doivent généralement être évitées, car elles peuvent produire du code spaghetti (spaghetti code), c'est-à-dire un programme dont le chemin d'exécution ressemble à un bol de spaghettis.

Les boucles while permettent au programme de boucler tant qu'une condition donnée est évaluée à true. La condition est évaluée avant l'exécution de la boucle.

Une boucle infinie (infinite loop) est une boucle dont la condition est toujours évaluée à true. Ces boucles tournent indéfiniment, sauf si une autre instruction de contrôle de flux les interrompt.

Une variable de boucle (loop variable, aussi appelée compteur, counter) est une variable entière utilisée pour compter le nombre d'exécutions d'une boucle. Chaque exécution d'une boucle s'appelle une itération (iteration).

Les boucles do while ressemblent aux boucles while, mais la condition est évaluée après l'exécution de la boucle au lieu d'avant.

Les boucles for sont les boucles les plus utilisées ; elles conviennent idéalement lorsqu'il faut boucler un nombre de fois précis. Une erreur de décalage (off-by-one error) se produit lorsque la boucle effectue une itération de trop ou de trop peu.

Les instructions break permettent de sortir d'un switch, d'une boucle while, do while ou for (ainsi que des boucles range-based for, que nous n'avons pas encore vues). Les instructions continue permettent de passer immédiatement à l'itération suivante de la boucle.

Les arrêts (halts) permettent de terminer le programme. La terminaison normale (normal termination) signifie que le programme s'est terminé de manière attendue (et le status code indique s'il a réussi ou non). std::exit() est appelée automatiquement à la fin de main, ou peut être appelée explicitement pour terminer le programme. Elle effectue un certain nettoyage, mais ne détruit pas les variables locales et ne déroule pas la pile d'appels.

La terminaison anormale (abnormal termination) se produit lorsque le programme rencontre une erreur inattendue et doit être arrêté. std::abort peut être appelée pour provoquer une terminaison anormale.

Un algorithme est une suite finie d'instructions permettant de résoudre un problème ou de produire un résultat utile. Un algorithme est dit avec état (stateful) s'il conserve certaines informations d'un appel à l'autre. À l'inverse, un algorithme sans état (stateless) ne stocke aucune information (et doit recevoir toutes les informations nécessaires à son travail lors de son appel). Appliqué aux algorithmes, le terme état (state) désigne les valeurs courantes des variables avec état.

Un algorithme est dit déterministe (deterministic) si, pour une entrée donnée (la valeur fournie pour start), il produit toujours la même séquence de sortie.

Un générateur de nombres pseudo-aléatoires (pseudo-random number generator, PRNG) est un algorithme qui génère une séquence de nombres dont les propriétés simulent une séquence de nombres aléatoires. Lors de l'instanciation d'un PRNG, on peut fournir une valeur initiale (ou un ensemble de valeurs), appelée graine aléatoire (random seed, ou simplement seed), afin d'initialiser l'état du PRNG. Lorsqu'un PRNG a été initialisé avec une graine, on dit qu'il a été ensemencé (seeded). La taille de la graine peut être inférieure à la taille de l'état du PRNG ; on dit alors que le PRNG est sous-ensemencé (underseeded). La longueur de la séquence avant que le PRNG ne commence à se répéter s'appelle la période (period).

Une distribution de nombres aléatoires (random number distribution) convertit la sortie d'un PRNG en une autre distribution de nombres. Une distribution uniforme (uniform distribution) est une distribution de nombres aléatoires qui produit des valeurs comprises entre deux nombres X et Y (inclus) avec la même probabilité.

Question n° 1

Dans la leçon 4.x -- Résumé du chapitre 4 et quiz, nous avons écrit un programme simulant une balle tombant du sommet d'une tour. Comme nous n'avions pas encore de boucles, la balle ne pouvait tomber que pendant 5 secondes.

Modifiez le programme ci-dessous pour que la balle tombe pendant autant de secondes que nécessaire jusqu'à atteindre le sol. Mettez à jour le programme pour utiliser toutes les bonnes pratiques vues (espaces de noms, constexpr, etc.).

#include <iostream>

// Gets tower height from user and returns it
double getTowerHeight()
{
    std::cout << "Enter the height of the tower in meters: ";
    double towerHeight{};
    std::cin >> towerHeight;
    return towerHeight;
}

// Returns the current ball height after "seconds" seconds
double calculateBallHeight(double towerHeight, int seconds)
{
    const double gravity { 9.8 };

    // Using formula: s = (u * t) + (a * t^2) / 2
    // here u (initial velocity) = 0, so (u * t) = 0
    const double fallDistance { gravity * (seconds * seconds) / 2.0 };
    const double ballHeight { towerHeight - fallDistance };

    // If the ball would be under the ground, place it on the ground
    if (ballHeight < 0.0)
        return 0.0;

    return ballHeight;
}

// Prints ball height above ground
void printBallHeight(double ballHeight, int seconds)
{
    if (ballHeight > 0.0)
        std::cout << "At " << seconds << " seconds, the ball is at height: " << ballHeight << " meters\n";
    else
        std::cout << "At " << seconds << " seconds, the ball is on the ground.\n";
}

// Calculates the current ball height and then prints it
// This is a helper function to make it easier to do this
void calculateAndPrintBallHeight(double towerHeight, int seconds)
{
    const double ballHeight{ calculateBallHeight(towerHeight, seconds) };
    printBallHeight(ballHeight, seconds);
}

int main()
{
    const double towerHeight{ getTowerHeight() };

    calculateAndPrintBallHeight(towerHeight, 0);
    calculateAndPrintBallHeight(towerHeight, 1);
    calculateAndPrintBallHeight(towerHeight, 2);
    calculateAndPrintBallHeight(towerHeight, 3);
    calculateAndPrintBallHeight(towerHeight, 4);
    calculateAndPrintBallHeight(towerHeight, 5);

    return 0;
}
Solution 
#include <iostream>

namespace Constants
{
    constexpr double gravity { 9.8 };
}

// Gets tower height from user and returns it
double getTowerHeight()
{
    std::cout << "Enter the height of the tower in meters: ";
    double towerHeight{};
    std::cin >> towerHeight;
    return towerHeight;
}

// Returns the current ball height after "seconds" seconds
// note: this function could be constexpr, but we haven't covered constexpr functions yet
double calculateBallHeight(double towerHeight, int seconds)
{
    // Using formula: s = (u * t) + (a * t^2) / 2
    // here u (initial velocity) = 0, so (u * t) = 0
    const double fallDistance { Constants::gravity * (seconds * seconds) / 2.0 };
    const double ballHeight { towerHeight - fallDistance };

    if (ballHeight < 0.0)
        return 0.0;

    return ballHeight;
}

// Prints ball height above ground
void printBallHeight(double ballHeight, int seconds)
{
    if (ballHeight > 0.0)
        std::cout << "At " << seconds << " seconds, the ball is at height: " << ballHeight << " meters\n";
    else
        std::cout << "At " << seconds << " seconds, the ball is on the ground.\n";
}

// Calculates the current ball height and then prints it
// This is a helper function to make it easier to do this
double calculateAndPrintBallHeight(double towerHeight, int seconds)
{
    const double ballHeight{ calculateBallHeight(towerHeight, seconds) };
    printBallHeight(ballHeight, seconds);

    return ballHeight;
}

int main()
{
    const double towerHeight{ getTowerHeight() };

    int seconds { 0 };
    while (calculateAndPrintBallHeight(towerHeight, seconds) > 0.0)
    {
        ++seconds;
    }

    return 0;
}

Contenu associé

assert est une macro du préprocesseur qui termine le programme si l'argument associé est évalué à faux. Ainsi, lorsque nous écrivons assert(!isPrime(0)), nous signifions « si isPrime(0) est vrai, alors terminer le programme ». Nous étudions assert plus en détail dans la leçon 9.6 -- Assert et static_assert.

Solution 
// Make sure that assert triggers even if we compile in release mode
#undef NDEBUG

#include <cassert> // for assert
#include <iostream>

// Non-optimized version
bool isPrime(int x)
{
    if (x <= 1) // if x is negative, 0, or 1 then the number is not prime
        return false;

    for (int test{ 2 }; test < x; ++test)
    {
        if (x % test == 0) // if x is evenly divisible
            return false;  // then this number isn't prime
    }

    return true; // if we didn't find any divisors, then x must be prime
}

int main()
{
    assert(!isPrime(0));
    assert(!isPrime(1));
    assert(isPrime(2));
    assert(isPrime(3));
    assert(!isPrime(4));
    assert(isPrime(5));
    assert(isPrime(7));
    assert(!isPrime(9));
    assert(isPrime(11));
    assert(isPrime(13));
    assert(!isPrime(15));
    assert(!isPrime(16));
    assert(isPrime(17));
    assert(isPrime(19));
    assert(isPrime(97));
    assert(!isPrime(99));
    assert(isPrime(13417));

    std::cout << "Success!\n";

    return 0;
}

Crédit supplémentaire :

La boucle for de la solution ci-dessus n'est pas optimale, pour deux raisons :

  • Elle teste les diviseurs pairs. Nous n'en avons pas besoin (sauf pour 2).
  • Elle teste chaque nombre jusqu'à x pour voir s'il s'agit d'un diviseur. Un nombre non premier (un nombre composé) possède au moins un diviseur inférieur ou égal à sa racine carrée ; il est donc inutile de tester les diviseurs au-delà de la racine carrée de x. std::sqrt(x) (dans l'en-tête <cmath>) renvoie la racine carrée de x.

Pour cette dernière optimisation, deux options s'offrent à nous : calculer std::sqrt(x) avant la boucle, puis comparer notre variable de boucle à cette valeur. Ou bien, nous pouvons éliminer std::sqrt(x) de la comparaison en élevant les deux membres au carré (merci au lecteur JJag pour cette suggestion) (voir l'indice si vous avez besoin d'aide à ce sujet). Nous utiliserons cette dernière option dans la solution du quiz.

Indice

Indice : étant donnés deux variables a >= 0 et b >= 0, nous pouvons élever au carré les deux membres de la comparaison a <= sqrt(b) et la comparaison reste vraie. On obtient a * a <= sqrt(b) * sqrt(b), ce qui équivaut à a * a <= b.

Mettez à jour la solution ci-dessus pour implémenter ces deux optimisations.

Solution 
#include <cassert>
#include <cmath> // for std::sqrt
#include <iostream>

// optimized version
bool isPrime(int x)
{
    if (x <= 1)     // if x is negative, 0, or 1 then the number is not prime
        return false;
    if (x == 2)     // the number 2 is the only even prime
        return true;
    if (x % 2 == 0) // any other even number is not prime
        return false;

    // For any number 3 or greater, test odd values (this is why we add 2)
    // between 3 and sqrt(x) to see if they are a divisor
    // Also see https://stackoverflow.com/questions/5811151/why-do-we-check-up-to-the-square-root-of-a-number-to-determine-if-the-number-is
    // Since test >= 0 and x >=0, we can optimize test < std::sqrt(x) to test * text < x
    for (int test{ 3 }; test * test <= x; test += 2)
    {
        if (x % test == 0) // if x is evenly divisible
            return false;  // then this number isn't prime
    }

    return true; // if we didn't find any divisors, then x must be prime
}

int main()
{
    assert(!isPrime(0));
    assert(!isPrime(1));
    assert(isPrime(2));
    assert(isPrime(3));
    assert(!isPrime(4));
    assert(isPrime(5));
    assert(isPrime(7));
    assert(!isPrime(9));
    assert(isPrime(11));
    assert(isPrime(13));
    assert(!isPrime(15));
    assert(!isPrime(16));
    assert(isPrime(17));
    assert(isPrime(19));
    assert(isPrime(97));
    assert(!isPrime(99));
    assert(isPrime(13417));

    std::cout << "Success!\n";

    return 0;
}

Question n° 3

Implémentez un jeu de Hi-Lo. Tout d'abord, votre programme doit choisir un entier aléatoire compris entre 1 et 100. L'utilisateur dispose de 7 tentatives pour deviner ce nombre.

Si l'utilisateur ne devine pas le bon nombre, le programme doit lui indiquer si sa proposition est trop grande ou trop petite. Si l'utilisateur trouve le bon nombre, le programme doit lui annoncer qu'il a gagné. S'il épuise ses tentatives, le programme doit lui annoncer qu'il a perdu et lui révéler le bon nombre. À la fin de la partie, on demande à l'utilisateur s'il veut rejouer. Si l'utilisateur ne saisit ni « y » ni « n », redemandez-lui.

Pour un crédit supplémentaire : faites des valeurs minimale et maximale ainsi que le nombre de tentatives des paramètres configurables.

Solution 
#include <iostream>
#include "Random.h" // https://www.learncpp.com/cpp-tutorial/global-random-numbers-random-h/

// Returns true if the user won, false if they lost
// We don't use the return value in this program, but it doesn't add complexity to have it, and may be useful in a future update
// (e.g. if we wanted to move the won/lost messages out of the function, or conditionalize other behavior based on won/lost)
bool playHiLo(int guesses, int min, int max)
{
    std::cout << "Let's play a game. I'm thinking of a number between " << min << " and " << max << ". You have " << guesses << " tries to guess what it is.\n";
    const int number { Random::get(min, max) }; // this is the number the user needs to guess

    // Loop through all of the guesses
    for (int count{ 1 }; count <= guesses; ++count)
    {
        std::cout << "Guess #" << count << ": ";

        int guess{};
        std::cin >> guess;

        if (guess > number)
            std::cout << "Your guess is too high.\n";
        else if (guess < number)
            std::cout << "Your guess is too low.\n";
        else // guess == number, so the user won
        {
            std::cout << "Correct! You win!\n";
            return true;
        }
    }

    // The user lost
    std::cout << "Sorry, you lose. The correct number was " << number << '\n';
    return false;
}

bool playAgain()
{
    // Keep asking the user if they want to play again until they pick y or n.
    while (true)
    {
        char ch{};
        std::cout << "Would you like to play again (y/n)? ";
        std::cin >> ch;

        switch (ch)
        {
        case 'y': return true;
        case 'n': return false;
        }
    }
}

int main()
{
    constexpr int guesses { 7 }; // the user has this many guesses
    constexpr int min     { 1 };
    constexpr int max     { 100 };

    do
    {
        playHiLo(guesses, min, max);
    } while (playAgain());

    std::cout << "Thank you for playing.\n";

    return 0;
}
